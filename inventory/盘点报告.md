## 5. 对总纲 §4.4 估算的校准

| 估算项 | 总纲原估 | S1 实测校准 |
|---|---|---|
| HTML 页数 | 2.5–4 万 | **22,010**（略低于下限） |
| 正文英文词数 | 1000–2000 万 | **526 万**（约下限一半；本口径排除 pre/code/script/style，总纲原估应含代码块） |
| 公共段削减 | 20–40% | **3.8%**（远低于原估；BoostBook 产物页间重复仅为导航/页脚/admonition 框架，正文唯一性高） |
| LLM 翻译段数/批次 | 数千级批次 | **201,447 段 ≈ 4,029 批**（50 段/批） |
| 中文产出 | 1500–3000 万字 | ≈ **842 万字**（1 英文词≈1.6 中文字折算；TM 去重口径 265 万词 ≈ 424 万字） |

**结论**：全库工作量显著低于总纲最坏假设。4,029 个 LLM 批次为主要工作量；以每会话可稳定完成 300–600 批推算，T1+T2+T3 需 7–14 个工作会话（三账本断点续作）。

## 7. 口径说明

- 词数 = 可译文本节点 + 白名单属性（alt/title/meta description）中含 ASCII 字母的 token；pre/code/script/style 及非白名单属性不计
- 唯一段键 = 段串去标记后规范化文本的 SHA-256（8 字节截断）去重；同键跨页只计 1 次翻译量（TM 幂等）
- 公共段 = 出现于 ≥3 页的键；人工精翻一次存 common_segments.json 机械套用，不进 LLM 批次
- 批次 = LLM 段数 ÷ 50 向上取整；每批 token 量以 S2 试点实测校准
- 段频明细：inventory/segments.jsonl（h / sample / pages / words，按 h 升序）
