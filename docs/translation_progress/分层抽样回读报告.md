## 3. 缺陷类型分析

漏译集中于 6 类系统性小遗漏（非语义缺陷）：

| 类型 | 典型样例 | 数量占比 |
|---|---|---|
| 重载标题后缀 "(N of M overloads)" 兄弟页已译而本页残留 | beast/asio/mqtt5 各 overload 页 | ~35% |
| 许可页脚 "Distributed under the Boost Software License…" 单页残留 | bind/bloom/sort/predef 等 | ~15% |
| TOC/dt 目录条目未译（正文 h3 已译） | signals2/rationale、libraries.html | ~15% |
| doxygen 节标题/页标题样板（Struct Template Reference / Member List / Static Public Attributes 等） | gil/locale 参考页 | ~15% |
| 短小节标题/单句描述残留 | Special Values / Disable SSL v2 / Tested compilers | ~12% |
| 整段散文残留（个别页） | icl implementation.html（8 段）、xpressive appendices | ~8% |

豁免判定（不计缺陷，判例与前会话一致）：代码/签名/公式行、参考文献书目、作者名/论文名、
纯标识符标题、库级一致样板（beast 重载后缀 768/780 未译属库级样板）、构建脚本行、上游转义残留。
