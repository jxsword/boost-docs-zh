### 2.2 收库固定循环（每库/每组）

```bash
python -I pipeline/merge_results.py                          # 回收 results（幂等）
python -I work/scratch/closeout.py <lib1> <lib2> ...         # reemit+assets+四门禁（safe_name 传参，
                                                             #  脚本自动映射 manifest 原始名）
# 全绿后追加 progress.csv 行（lib 用原始名；段数取账本 merged n_items 合计）
```

**⚠️ 库名双轨**：批次/账本/extract/build/closeout 传参用 safe_name（`_root_`⇔`(root)`、
`_book_X_html_`⇔`(book:X.html)`、`404_html`⇔`404.html`、`tool_bcp`⇔`tool:bcp`），
reemit/门禁传原始名（closeout.py 已自动处理）。reemit/qa 报 0 页时优先怀疑库名不匹配。

### 2.3 子代理并发与配额

- **并发窗口 = 1**，一律单代理串行，每代理 ≤70 批，完成即 merge 再续派。
- 配额/并发/超时中断后已写 results 仍有效：直接 merge → 按账本续派剩余批号（§4.13）。
- 平台偶发把启动即失败（0 落盘）——直接重派同一区间；若两轮均 0 落盘（mpl 案），
  第 3 轮派单必须注入"最简流程 + 从第 1 批起每翻完 1 批立即写盘"约束。
- 派单里批号必须以 ledger status=queued 为准（前序代理可能已消化部分批次）。

### 2.4 派单模板要点（全文模板见旧版 §3，核心不变）

- 三份术语规范必读（glossary_术语表 / glossary_ui_strings / 术语增补_T1）。
- 标记保真：⟦tag⟧/⟦/tag⟧ 与 ⦃n⦄ 数量、顺序、编号逐位一致；相邻标记间不容插字。
