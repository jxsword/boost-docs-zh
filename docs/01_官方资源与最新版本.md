## 2. 最新版本 1.92.0 特性摘要

**发布时间**：2026-08-12（GitHub Release 时间戳 2026-08-12T11:41:32Z，与"每年 4/8/12 月三发"节奏一致）。
**本版无新增库**（New Libraries 栏为空）；下述为按官方发布说明归纳的重点（英文原文存档：`data/boost_release_notes_en/boost_org_releases_1_92_0.html`）。

### 2.1 总体注记（General Notes）

- **DLL 安装位置变更**：Windows `.dll` 由 `b2 install` 统一安装到二进制目录（`<PREFIX>/bin`），不再进 `<PREFIX>/lib`（Cygwin 历史行为对齐）；新增 `--dlldir` 选项可覆盖。
- **CMake `find_package` 支持仅头文件库组件**：如 `find_package(Boost REQUIRED COMPONENTS mp11)` 定义 `Boost::mp11` 目标；`COMPONENTS ALL` 少用特性被移除。

### 2.2 亮点归纳（按发布页 What's new 四分类）

| 类别 | 要点 |
|---|---|
| 性能 | `mp11` 多算法提速；`container`/`unordered` 大容量 rehash 优化；`redis` 缓冲区轮转降 CPU |
| 依赖瘦身 | Beast 移除对 Boost.Functional 的依赖；Graph 移除对 Boost.StaticAssert 的依赖；安装布局调整 |
| 安全与可靠性 | URL 库三轮安全复审：修复 `normalize_path` 堆缓冲区溢出、`ipv6_address_rule` 未初始化读、无符号整数溢出等问题；MySQL CI 证书改为动态生成 |
| 开发体验 | C++20 modules 覆盖面扩大：conversion、dll、lexical_cast、pfr、stacktrace、type_index 等库新增 `boost.*` 模块（并含 `import std` 兼容测试） |

### 2.3 库级重点更新（节选）

- **Container**：新增 `boost::container::hub` 容器（Joaquín M. López Muñoz 设计）；`vector`/`static_vector`/`small_vector` 增加 `unchecked_emplace_back`/`unchecked_push_back`；落实 C++23 P1518 推导指引修正。
- **Lockfree**：新增 `boost::lockfree::mpsc_weak_queue`（多生产者单消费者，非严格无锁）与 `boost::lockfree::bounded_ticket_queue`（环形缓冲有界 MPMC）；本版是支持 C++14 的最后版本，后续要求 C++17（Heap 同此）。
- **Asio**：新增 `"scheduler"/"assume_continuation"` 配置参数（线程本地快速队列）；io_uring 后端调优参数；`ssl::stream<>` 缓冲区可配置；`boost/asio/fwd.hpp` 前置声明头；Linux 上的 futex 化"瘦身"互斥量等约 20 项更新。
- **Beast**：一组 HTTP/1.x 报文健壮性/安全收紧（如拒绝 `Content-Length` 与 `Transfer-Encoding` 并存、拒绝非 chunked 结尾的 TE 等）。
- **MSM（backmp11）**：含多项**破坏性变更**（事件不再自动入队、后端不再转发构造参数等）。
- **Graph**：新增 Louvain 社区发现算法；文档全面改版迁移。
- **MultiIndex/Unordered**：fancy pointer 支持扩展（迭代器可入共享内存）；极大容器 rehash 性能修复（Daniel Král 贡献）。
- **Charconv/Decimal/Math**：CUDA 支持（整数 to_chars/from_chars、decimal32_t/64_t/128_t、核函数可用）。
- **工具**：随版发布 b2 5.5.3。

## 4. 发布节奏与版本号规则

- **发布节奏**：每年三次，固定在 4 月、8 月、12 月（官网页脚原文："Boost is publicly released three times a year in April, August, and December"；发布流程详见 release-process.html）。实际日期多落在当月第二个周三附近（如 1.92.0 = 2026-08-12 周三、1.90.0 = 2025-12-10 周三）。
- **版本号规则**：`X.Y.Z`，Z 通常为 0 且对应 git tag `boost-X.Y.Z`；修补重发布加 `-1` 后缀（如 `boost-1.91.0-1`，官网页内写作 1.91.0-1）。
- **beta 预告（不计入统计）**：1.93.0.beta1 已于 2026-11-11 发布（GitHub API 时间戳 2026-11-11T14:28:48Z），正式版 1.93.0 定档 2026-12-09。本文档基线仍冻结于 1.92.0。
- **修补重发布惯例**：版本主号发布后如有打包错误，以 `-1`（更早期还有 `.1` 写法，如 1.46.1、1.65.1）重发布。
