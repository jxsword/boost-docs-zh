Inspect 工具

各种常见错误或 准则违规悄悄混入 Boost 库的情况并不少见. inspect 程序会检测并报告若干常见问题. 它可用于扫描拟提交的 Boost 库, 以识别各种不合规之处.

inspect 程序用 C++ 编写, 以限制工具链依赖, 并且应当可移植到任何系统.

该程序在要扫描错误的目录中运行. 子目录也会包含在扫描之中.

若第一个程序实参为 -help, 则显示一条用法消息, 列出所有可用的程序选项.

程序源文件包括:

  • inspect.hpp 与 inspect.cpp
  • link_check.hpp 与 link_check.cpp
  • path_name_check.hpp 与 path_name_check.cpp
  • tab_check.hpp 与 tab_check.cpp

提供了一个 Jamfile, 用于以 Boost.Build 构建该程序.

提供了一个 Microsoft Visual Studio 解决方案文件以辅助维护. 使用前请先阅读 readme.txt.
