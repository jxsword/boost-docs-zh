元素:

  • 元素 access - 声明类成员的访问规格
  • 元素 boostbook - 定义一个 BoostBook 书籍
  • 元素 class - 声明一个类或类模板
  • 元素 class-specialization - 类模板的一个特化 (部分特化或全特化)
  • 元素 code - 模仿 HTML 中的 code 标签
  • 元素 compile-fail-test - 应当无法通过编译的测试用例
  • 元素 compile-test - 应当能正确编译的测试用例
  • 元素 complexity - 函数的时间/空间等复杂度
  • 元素 constructor - 声明外围类的一个构造函数
  • 元素 copy-assignment - 声明一个拷贝赋值运算符
  • 元素 data-member - 声明类的一个数据成员
  • 元素 default - 函数或模板参数的默认值
  • 元素 description - 构造 (construct) 的详细描述
  • 元素 destructor - 声明外围类的一个析构函数
  • 元素 effects - 声明函数的副作用
  • 元素 enum - 声明一个枚举类型
  • 元素 enumname - 以给定名称引用一个枚举类型
  • 元素 enumvalue - 枚举的一个单独值
  • 元素 free-function-group - 以同一个名字归为一组的一组函数
  • 元素 function - 声明一个函数
  • 元素 functionname - 以给定名称引用一个函数
  • 元素 globalname - 以给定名称引用一个全局 (global)
  • 元素 header - 声明一个具有给定名称的 C++ 头文件
  • 元素 headername - 以给定名称引用一个 C++ 头文件
  • 元素 if-fails - 测试用例失败时意味着什么
  • 元素 inherit - 声明外围类或结构体的一个基类
  • 元素 lib - 一个库依赖
  • 元素 library - 库的顶层元素
  • 元素 library-reference - 声明一个库的参考材料
  • 元素 librarycategory - 声明外围库属于此分类
  • 元素 librarycategorydef - 定义一个新的库分类
  • 元素 librarycategorylist - 库的分类列表
  • 元素 libraryinfo - 提供关于一个库的信息
  • 元素 librarylist - 库的字母序列表的占位符
  • 元素 libraryname - 以给定名称引用一个库
  • 元素 librarypurpose - 用一个简短的句子或短语描述库的用途
  • 元素 link-fail-test - 声明一个应当能编译但无法链接的测试
  • 元素 link-test - 声明一个应当能编译并链接的测试
  • 元素 macroname - 以给定名称引用一个宏
  • 元素 method - 声明一个方法 (即成员函数)
  • 元素 method-group - 以同一个名字归为一组的一组方法
  • 元素 namespace - 声明一个命名空间
  • 元素 notes - 关于函数语义的非规范性注释
  • 元素 overloaded-function - 一个重载函数
  • 元素 overloaded-method - 一个重载方法
  • 元素 parameter - 一个函数参数
  • 元素 paramtype - 函数参数的类型
  • 元素 postconditions - 函数返回之后必须成立的条件
  • 元素 precondition - 执行函数之前必须满足的条件
  • 元素 programlisting - 一段程序代码示例
  • 元素 purpose - 对实体用途的简短描述
  • 元素 rationale - 描述某个特定函数设计的理由
  • 元素 requirement - 测试用例在 Jamfile 中的一个要求/属性
  • 元素 requires - 声明函数的要求
  • 元素 returns - 对函数返回值的描述
  • 元素 run-fail-test - 一个应当能编译、链接但在执行时失败的测试用例
  • 元素 run-test - 一个应当能编译、链接并执行的测试用例
  • 元素 signature - 重载函数或方法的其中一个签名
  • 元素 snippet - 从一个 programlisting 元素中引入代码片段
  • 元素 source - 为一个测试定义源代码
  • 元素 specialization - 为类特化定义特化实参
  • 元素 static-constant - 声明一个静态常量, 例如 const int foo = 5;.
  • 元素 struct - 声明一个 C++ 结构体
  • 元素 struct-specialization - 结构体模板的一个特化 (全特化或部分特化)
  • 元素 template - 声明类或函数的模板参数
  • 元素 template-arg - 特化中的一个模板实参
  • 元素 template-nontype-parameter - 一个非类型模板参数
  • 元素 template-type-parameter - 声明一个模板类型参数
  • 元素 template-varargs - 声明一个可变长度的模板参数列表
  • 元素 testsuite - 描述一个库的测试套件
  • 元素 throws - 对函数抛出的异常的描述
  • 元素 type - 元素的类型或函数的返回类型
  • 元素 typedef - 声明一个 typedef
  • 元素 union - 声明一个 C++ 联合体或联合体模板
  • 元素 union-specialization - 联合体模板的一个特化 (全特化或部分特化)
  • 元素 using-class - 把一个类的方法和函数名注入局部作用域
  • 元素 using-namespace - 把一个命名空间中声明的名字注入局部作用域
