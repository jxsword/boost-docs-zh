BoostBook 元素 boostbook

boostbook — 定义一个 BoostBook 书籍

概要

boostbook ::= (title, (chapter| library)*)

说明

该元素是 boost.xml 为所有 Boost 文档定义的最顶层. 开发者一般不会使用它.

属性

名称 类型 值 用途
last-revision #IMPLIED CDATA 设置为 $Date$ 以使"最后修订"信息与 CVS 变更保持同步
id #IMPLIED CDATA 此元素的全局标识符
xml:base #IMPLIED CDATA XInclude 使用的实现细节
