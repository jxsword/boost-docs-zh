运行 BoostBook

配置好 BoostBook 之后, 我们就可以构建一些文档了. 首先, 切换到目录 $BOOST_ROOT/doc 并删除 (或改为可写) .html 中的 $BOOST_ROOT/doc/html文件. 然后运行 bjam 来构建 HTML 文档. 在从 BoostBook 文档构建 DocBook 文档的过程中, 你会看到若干类似这样的警告:

Cannot find function named 'checked_delete'
Cannot find function named 'checked_array_delete'
Cannot find function named 'next'

当 Boost 文档工具找不到源代码中引用的函数、方法或类的文档时会发出这些警告, 它们没有任何危害. Boost.Jam 执行完成后, Boost 的 HTML 文档将在 $BOOST_ROOT/doc/html中可用. 你也可以用命令行 bjam onehtml在单个 (很大的! ) HTML 文件中创建 HTML 文档, 或用命令行 bjam man创建 Unix 手册页 (man pages) . 输出格式的完整列表见 表 2.1 "BoostBook 输出格式". 可以在一次调用 bjam时传入多种输出格式, 例如 bjam html man docbook 会生成 HTML (多个文件) 、手册页和 DocBook 文档.

表 2.1 BoostBook 输出格式

Format 说明
html

HTML 输出 (多个文件) . 这是默认值
onehtml

单个 HTML 文件中的 HTML 输出.
man

Unix 手册页.
pdf

PDF. 需要 Apache FOP.
ps

Postscript. 需要 Apache FOP.
docbook DocBook.
fo XSL Formatting Objects (XSL 格式化对象)
