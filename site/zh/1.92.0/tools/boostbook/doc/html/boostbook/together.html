BoostBook 中的链接

在 BoostBook 中如何链接到另一个元素, 很大程度上取决于被链接元素的性质以及链接应当呈现的形式. 有三个通用的链接元素: <xref>、<link> 和 <ulink>. 此外, 还有一些用于引用特定类型实体的链接元素, 例如类 (<classname>) 、函数 (<functionname>) 或库 (<libraryname>) .

<xref> 元素引用具有 id 属性和标题的元素. 实际的链接文本由被引用元素的标题和类型组成. 要链接到某个特定 ID, 创建一个 <xref> 元素并把 linkend 属性设为目标 ID 即可. 例如, 本节的 ID 是 boostbook.linking, 因此我们用 <xref linkend="boostbook.linking"/>创建一个指向它的引用, 它在文本中的样子是: "BoostBook 中的链接"一节.

<link> 元素以与 <xref> 相同的方式引用 ID, 区别是 <link> 不会为链接生成任何文本, 因此必须在元素内提供文本. 例如, 我们可以再次链接到本章, 但这次用 <link linkend="boostbook.linking">like this</link>指定我们自己的文本. 这段标记会生成一个指向本章的链接, 看起来 像这样.

<ulink> 元素引用 DocBook 文档之外的 URL. url 属性包含要链接到的 URL, 元素数据提供链接文本. 例如, 我们可以用 <ulink url="http://www.boost.org">Boost</ulink>, 链接到 Boost 网站, 它在文档中显示为: Boost.

在 BoostBook 中, <ulink> 支持一个自定义 URL 方案 (schema) , 用于链接到 boost 发行版内的文件. 做法是把 url 属性设置为 boost: 加上文件的路径. 例如, 我们可以用 <ulink url="boost:/libs/flyweight/index.html">Boost.Flyweight</ulink>链接到 flyweight 库, 它将显示为: Boost.Flyweight. 此方案仅受 BoostBook 的 <ulink> 元素支持, 不适用于任何其他元素, 也不能在 DocBook 中使用.

<classname>、<functionname>、<methodname> 和 <libraryname> 分别链接到类、函数、方法和库. 每个元素的文本既给出要链接到的元素的名称, 也给出链接文本. 例如, 我们可以用 <libraryname>Function</libraryname>链接到 Function 库, 结果如下: Function. 在显示文本与实际名称不同的情况下, 可以指定 alt 属性. 例如, 下面的 XML 元素引用 boost::function 类模板, 但显示文本 function: <classname alt="boost::function">function</classname>.
