BoostBook 元素 library-reference

library-reference — 声明一个库的参考材料

概要

library-reference ::= (title?, section*, (header| library-reference)*)

说明

库的参考文档包含在 <library-reference> 元素中. <library-reference> 元素没有属性, 其子元素只有 <header> 元素.

<header> 元素定义一个 C++ 头文件. 每个 C++ 头文件中包含待文档化的 C++ 构造的定义. <header> 元素的 name 属性给出头文件的名称, 与包含该头文件时指定的名称一致. 例如, Any 库的 <library-reference> 可能如下所示:

<library-reference>
  <header name="boost/any.hpp">
    <!-- C++ constructs in this header -->
  </header>
</library-reference>

如果 Any 库包含多个头文件, 我们会把它们全部列为 <library-reference> 元素的子元素.

library-reference 元素可以嵌套, 使参考材料可以划分为多个独立的小节, 每个小节包含不同的头文件.

属性

名称 类型 值 用途
last-revision #IMPLIED CDATA 设置为 $Date$ 以使"最后修订"信息与 CVS 变更保持同步
id #IMPLIED CDATA 此元素的全局标识符
xml:base #IMPLIED CDATA XInclude 使用的实现细节
