所有系统的手动配置

本节描述如何为 BoostBook 手动配置 Boost Boost version 2 (BBv@) . 如果可以使用自动配置脚本, 就应当使用它. 所有配置都在 BBv2 用户配置文件 user-config.jam中进行. 如果你的主目录中没有该文件的副本, 应当把 tools/build/ 中的那份复制到主目录. 或者, 你也可以直接编辑 tools/build/user-config.jam 或全站范围的 site-config.jam 文件.

配置 xsltproc

要手动配置 xsltproc , 你需要在 user-config.jam 中添加一条指令, 告诉它到哪里查找 xsltproc. 如果该程序在你的路径 (path) 中, 只需在 user-config.jam中加入以下行:

using xsltproc ;

如果 xsltproc 在别处, 请使用这条指令, 其中 XSLTPROC 是指向 xsltproc 的完整路径名 (包括 xsltproc) :

using xsltproc : XSLTPROC ;

配置本地 DocBook XSL 与 DTD 发行版

本节描述如何配置 Boost.Build 以使用 DocBook DTD 和 XSL 样式表的本地副本, 从而缩短处理时间. 首先你需要下载两个包:

  • Norman Walsh 的 DocBook XSL 样式表, 可在 DocBook sourceforge 站点获取. 把 DocBook XSL 样式表解压到硬盘上的某个目录 (我们称之为 DOCBOOK_XSL_DIR) .

  • DocBook DTD, 可在 OASIS DocBook 站点以 ZIP 压缩包形式获取. 该包名为 "DocBook XML 4.2". 把 DocBook DTD 解压到硬盘上的某个目录 (我们称之为 DOCBOOK_DTD_DIR) . 务必把这个压缩包解压到子目录中!

添加以下指令, 告诉 BBv2 到哪里查找 DocBook DTD 和 XSL 样式表:

#  BoostBook configuration
using boostbook 
  : DOCBOOK_XSL_DIR
  : DOCBOOK_DTD_DIR
  ;

每当你修改这条指令时, 都需要删除 BBv2 生成的 bin.v2 目录. 这是由于一个我们正在设法修复的长期缺陷.

此时, 你应当能够为不需要 Doxygen 的库构建 HTML 文档. 要测试这一点, 进入目录 $BOOST_ROOT/libs/function/doc 并运行命令 bjam: 它应当在 html 子目录中为 Boost.Function 库生成 HTML 文档.

配置 Doxygen 以提取文档

若干 Boost 库的文档构建需要 Doxygen. 你需要一个较新版本的 Doxygen (1.3.x 和 1.4.x 的大多数版本都可以) . 把以下指令添加到 user-config.jam来配置 BBv2:

using doxygen : DOXYGEN ;

DOXYGEN 应替换为 doxygen 可执行文件的名称 (含完整路径) . 如果正确的 doxygen 可执行文件可以通过路径找到, 此参数可以省略, 例如

using doxygen ;
重要

user-config.jam / site-config.jam 文件中声明的相对顺序很重要. 特别是, using doxygen 行应当放在 声明 之后 using boostbook .

配置 Apache FOP

要使用 Apache FOP 生成 PDF 和 PostScript 输出, 你需要一个 Java 解释器 以及 Apache FOP (0.20.5 版最佳) . 把 Apache FOP 解压到某个目录. FOP 工具的顶层目录应包含一个主脚本, 在 Unix 上名为 fop.sh , 在 Windows 上名为 fop.bat . 你需要把该脚本的位置和 Java 位置告知 Boost.Build. 把以下内容加入你的 user-config.jam 或者 site-config.jam:

using fop : FOP_COMMAND 
          : JAVA_HOME 
          ;

把 FOP_COMMAND 替换为 FOP 主脚本的完整路径, 把 JAVA_HOME 替换为 Java 安装目录. 如果 JAVA_HOME 环境变量已经设置, 则无需在上述配置中指定它.

在 PDF 中正确生成图像依赖于 Jimi Image Library. 要让 FOP 使用 Jimi, 请从 Jimi SDK 中提取 JimiProClasses.zip 文件并重命名——在 Windows 上重命名为 jimi-1.0.jar, 在 *nix 上重命名为 JimiProClasses.jar——然后把它放到你的 FOP 安装目录的 lib/ 子目录中.

要测试 PDF 生成, 切换到目录 $BOOST_ROOT/libs/function/doc 并执行命令 bjam pdf. 在没有错误的情况下, 将会运行 Apache FOP 把 DocBook 的 XSL:FO 输出转换为 PDF 文件.
