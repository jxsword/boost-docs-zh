BoostBook 中的分节

"分节" (Sectioning) 指的是把文档组织成多个独立的节, 每节有一个标题、一些文本以及可能的子节. 每一节在 BoostBook 中通过 <section> 元素描述. 一个引言小节可能如下所示:

<section id="any.intro">
  <title>Introduction</title>
 
  <para>Introduction to a library...</para>

  <section>
    <title>A Subsection</title>
    <para>Subsection information...</para>
  </section>
</section>

<section> 元素包含逻辑上应归入该节的所有信息. 节的标题放在 <title> 元素中, 节内可以出现段落、程序、列表、表格或子节. <section> 元素的 id 属性为每节赋予唯一的 ID, 以便之后为链接而识别它. 建议所有 ID 都以库的短名加一个句点开头, 这样 ID 在库之间不会冲突.
