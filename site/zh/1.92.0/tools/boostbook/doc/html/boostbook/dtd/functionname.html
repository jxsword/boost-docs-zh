BoostBook 元素 functionname

functionname — 以给定名称引用一个函数

概要

functionname ::= (#PCDATA)

说明

如果找到具有给定名称 (可以带限定) 的函数 (或重载函数) , 这会生成指向该函数的链接. 查找会遵循当前生效的 using-class 以及 using-namespace 指令以辅助搜索, 同时也会在当前作用域内搜索.

属性

名称 类型 值 用途
last-revision #IMPLIED CDATA 设置为 $Date$ 以使"最后修订"信息与 CVS 变更保持同步
alt #IMPLIED CDATA  
id #IMPLIED CDATA 此元素的全局标识符
xml:base #IMPLIED CDATA XInclude 使用的实现细节
