第 1 章 引言

BoostBook 文档格式是 DocBook (一种基于 SGML 或 XML 的文档描述格式) 的扩展. BoostBook 通过提供表达和引用 C++ 构造 (如命名空间、类、重载函数、模板和特化) 的能力, 用语义标记扩充了 DocBook, 以辅助 C++ 库——特别是 Boost C++ 库——的文档化.

BoostBook 提供了一些更专门用于文档化 Boost C++ 库的附加特性. 这些特性旨在消除或减少重复信息的需要, 并帮助文档化 Boost 中那些否则可能没有文档的部分. 以 Boost 为中心的特性示例包括:

  • 测试套件: Boost 中的测试套件通过编写适当的 Jamfile 并把该 Jamfile 包含在 status/Jamfile中来创建. 如果测试套件需要文档化 (如 MultiArray 库中那样) , 文档就必须与测试用例 Jamfile 分开维护, 导致信息重复以及文档与 Jamfile 不同步的可能. BoostBook 包含为这两种目的描述测试套件的元素: BoostBook 样式表既可以为测试用例生成文档, 也可以生成合适的 Jamfile 把测试用例与回归测试系统集成.

  • 示例程序: 文档中的示例程序需要在测试用例中复制一份, 以确保示例能正确编译和执行. 使两份副本保持同步是一项乏味且易出错的工作. 例如, 下面这段代码曾经存在了六个月:

    std::cout << f(5, 3) >> std::endl;

    BoostBook 格式允许通过把文档中示例程序的程序片段编织在一起来生成测试用例. 这一能力与测试套件生成集成在一起, 使示例程序成为 BoostBook 中的普通测试.
