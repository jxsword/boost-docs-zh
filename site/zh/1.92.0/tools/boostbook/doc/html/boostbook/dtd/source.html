BoostBook 元素 source

source — 为一个测试定义源代码

概要

source ::= (#PCDATA| snippet)*

说明

该元素将包含测试用例的源代码, 测试用例将从文档生成. 为减少文本中的转义数量, 建议使用 CDATA 节, 形如:

<![CDATA[
<your program text here: no escaping needed!>
]]>

除 CDATA 节之外, 还可以使用 programlisting 元素从 snippet 元素中引入代码片段.
