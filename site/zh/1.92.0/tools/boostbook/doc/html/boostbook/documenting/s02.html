从 HTML 到 BoostBook

大多数库作者都习惯于编写 HTML 文档. 编写 DocBook 文档 (并推广到 BoostBook 文档) 与编写 HTML 相当类似, 区别在于 BoostBook 使用与 HTML 不同的元素名 (参见 表 3.1 "将 HTML 元素转换为 BoostBook") , 而且 BoostBook XML 是比 HTML 严格得多的格式.

把 HTML 文档转换为 BoostBook 文档最简单的方法之一, 是先用 HTML Tidy 把 HTML 转换成合法的 XHTML (以确保所有元素都被正确闭合) , 然后对 XHTML 文档的 body 应用 表 3.1 "将 HTML 元素转换为 BoostBook" 中列出的转换. 下面的命令使用 HTML Tidy 把 HTML 转换成合法的 XHTML:

  tidy -asxhtml input.html > output.xhtml

从 HTML 把文档转换为 BoostBook 时, 请注意一些在 HTML 中必须手工维护的冗余信息在 BoostBook 中是自动生成的: 例如, "定义 BoostBook 库"一节 中描述的库分类、用途和作者列表既用于库文档本身, 也用于构建已知库的字母序和分类列表; 类似地, 目录 (tables of contents) 会根据 BoostBook 文档中各节的标题自动构建.

表 3.1 将 HTML 元素转换为 BoostBook

HTML BoostBook

<h1>, <h2>, etc.

<section>, <title>; 参见 "BoostBook 中的分节"一节

<i>, <em>

<emphasis>

<b>

<emphasis role="bold">

<ol>

<orderedlist>

<ul>

<itemizedlist>

<li>

<listitem>

<pre>

<programlisting>

<code>

<computeroutput>,<code>

<p>

<para>, <simpara>

<a>

<xref>, <link>, <ulink>;, 参见 "BoostBook 中的链接"一节

<table>, <tr>, <th>, <td>

<table>, <informaltable>, <tgroup>, <thead>, <tfoot>, <tbody>, <row>, <entry>, <entrytbl>; BoostBook 表格等同于 DocBook 表格, 关于后者有一篇很好的 教程
