BoostBook 元素 access

access — 声明类成员的访问规格

概要

access ::= (static-constant| typedef| enum| copy-assignment| constructor| destructor| method-group| method| overloaded-method| data-member| class| class-specialization| struct| struct-specialization| union| union-specialization)+

说明

类成员的访问规格 (public、private 或 protected) 可以通过把它们包围在一个 <access> 元素中来指定.

属性

名称 类型 值 用途
last-revision #IMPLIED CDATA 设置为 $Date$ 以使"最后修订"信息与 CVS 变更保持同步
name #REQUIRED CDATA 访问规格的名称, 例如 "public"、"private" 或 "protected".
id #IMPLIED CDATA 此元素的全局标识符
