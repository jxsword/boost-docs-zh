要使用 Boost 文档工具, 你需要若干工具:

  • xsltproc:

    • Windows 且使用 Cygwin: 选择 libxml2 和 libxslt 包.
    • 不带 Cygwin 的 Windows: 从 Igor Zlatkovic 下载 二进制包 . 至少需要 iconv、zlib、libxml2 和 libxslt.
    • 带 Fink 的 Mac OS X: 获取 libxslt 包.
    • 不带 Fink 的 Mac OS X: 下载 libxslt 二进制文件
    • 任何平台: libxslt 源码.

类 Unix 系统的自动配置

BoostBook 提供了一个近乎自动的配置脚本. 一旦你下载并安装了 xsltproc、 doxygen以及 (可选的) java, 该配置脚本就可以下载所需的 DocBook 样式表、DocBook DTD, 以及 (在启用 Java 时) 用于 PDF 输出的 Apache FOP. 然后它会配置 Boost.Build version 2 来构建 BoostBook 文档.

该脚本需要: sh、 curl 以及 gunzip. 要执行安装, 请在你希望放置最终 XSL、DTD 和 Apache FOP 安装内容的目录中运行脚本 tools/boostbook/setup_boostbook.sh .
