BoostBook 中的分节

BoostBook 是 DocBook (一种用于表示文档的 XML 格式) 的扩展. BoostBook 从 DocBook 继承了许多功能和元素, 此处不再重复说明. 编写 BoostBook 文档时, 请同时参考 DocBook: The Definitive Guide.

定义 BoostBook 库

BoostBook 库文档完全包含在一个 <library> XML 元素内. 要创建一个骨架库, 我们需要新建一个 XML 文档 (不妨称之为 any.xml) , 其中包含关于该库的基本信息. 下面的 BoostBook XML 示例 描述了 Boost.Any 库的基本信息:

示例 3.1 一个骨架 BoostBook 库

<?xml version="1.0" encoding="utf-8"?>
<!DOCTYPE library PUBLIC "-//Boost//DTD BoostBook XML V1.0//EN"
  "http://www.boost.org/tools/boostbook/dtd/boostbook.dtd">
<library name="Any" dirname="any" xmlns:xi="http://www.w3.org/2001/XInclude"
  id="any" last-revision="$Date$">
  <libraryinfo>
    <author>
      <firstname>Kevlin</firstname>
      <surname>Henney</surname>
    </author>
    <librarypurpose>
      Safe, generic container for single values of different value types
    </librarypurpose> 
    <librarycategory name="category:data-structures"/>
  </libraryinfo>
</library>

前三行将此文档标识为 BoostBook XML 文档. DOCTYPE 行声明该文档符合 BoostBook DTD, 且顶层元素是一个 BoostBook <library>.

<library> 元素实际描述了 BoostBook 库文档的各个方面. <library> 元素的属性如下:

<library> 元素的属性

name
库的全名, 例如 "Any"
dirname
库所在目录的名称 (相对于 boost/libs) . 该名称可以是相对路径, 例如 math/octonion, 使用 "/" 作为目录分隔符.
id
库的简短且唯一的名称. 对于目录名简单的库 (例如名称中不含 "/" 的库) , 它应当与 dirname相同. 此 id 将用于标识库; 对于 HTML 输出, 它将用作库文档所在 HTML 文件的基本名 (base name) , 因此只能使用小写字母数字字符和下划线.
last-revision
总是设置为 $Date$, CVS 会把它展开为文件最后一次修改的日期和时间.

在 <library> 元素内部是 <libraryinfo> 元素, 它提供关于库本身的信息. 它包含作者姓名 (可以有多个 <author> 元素) , 随后是库的用途和分类列表. <librarypurpose> 元素应当始终包含对库用途的非常简短的 (单句) 描述, 并且 不 应以句号结尾.

分类列表由一组 <librarycategory> 元素指定. 每个 <librarycategory> 元素都有一个用于标识某个分类的 name 元素. 实际的分类列表在文件 doc/src/boost.xml中.
