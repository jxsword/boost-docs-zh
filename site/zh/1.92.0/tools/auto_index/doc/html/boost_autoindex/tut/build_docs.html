第 7 步: 构建文档

使用 Boost.Build 时, 你可以用以下两种方式之一构建文档:

bjam release > mylibrary_html.log

构建 html 文档, 或者:

bjam pdf release > mylibrary_pdf.log

构建 pdf.

在构建过程中, 你应当会看到 AutoIndex 在日志文件中输出如下消息:

Indexing 990 terms...

如果你没有看到该消息, 或者它索引了 0 个词条, 那么一定出了问题!

同样, 当索引生成完成时, AutoIndex 会输出另一条消息:

38 Index entries were created.

同样, 如果你看到创建了 0 个条目, 那么一定出了问题!

检查日志文件, 如果原因不明显, 请确认你已 <auto-index-verbose>on, 并且脚本文件中包含任何所需的 !debug regular-expression 指令.
