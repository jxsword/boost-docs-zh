第 4 步: 创建 .idx 脚本文件——控制要索引哪些词条

AutoIndex 的工作方式是读取一个脚本文件, 由它告诉 AutoIndex 要索引哪些词条.

如果你的文档以文本为主, 只包含少量简单 C++, 和/或你使用 Doxygen 提供 C++ 参考章节(其中列出 C++ 元素), 和/或你依赖于独立 Doxygen 索引提供的索引, 你可能会认为不需要索引, 只希望索引文本部分.

但如果你希望对 C++ 类、函数、typedef 和/或宏进行 AutoIndex 索引, 脚本文件还可以(可选地)指明要扫描哪些其他 C++ 文件.

最简单的情况下, 它会扫描一个或多个头文件, 查找应在文档中索引的词条. 例如, 要扫描 "myheader.hpp", 脚本文件只需包含:

!scan myheader.hpp
!scan mydetailsheader.hpp

或者(实践中更常见)递归地扫描各个目录, 查找所有 名称匹配特定正则表达式 的待扫描文件:

!scan-path "boost/mylibrary" ".*.hpp" true

每个参数以空白分隔, 并且可以选择用 "双引号" 括起来(推荐).

最后的 true 参数表示除该目录本身之外, 还应递归搜索 /boost/math/mylibrary 中的子目录.

注意

第二个参数 file-name-regex 是一个正则表达式, 而不是文件名 GLOB!

注意

scan-path 会被 <auto-index-prefix> 的任何设置所修改. 这里的示例假定其为 <auto-index-prefix>../../.., 因此 boost/mylibrary 将是你的头文件, libs/mylibrary/doc 将包含你的文档文件, 而 libs/mylibrary/example 将包含你的示例.

你还可以扫描任何示例 (.cpp) 文件, 通常位于文件夹 /mylibrary/lib/example 中.

# All example source files, assuming no sub-folders.
!scan-path "libs/mylibrary/example" ".*.cpp"

通常 scan 或 scan-path 规则会带来过多的待搜索词条, 因此我们还需要能够排除词条:

!exclude type

这会把词条 "type" 排除在索引之外.

我们也可以手工添加词条:

foobar

会对 "foobar" 的出现进行索引, 而:

foobar \<\w*(foo|bar)\w*\>

会对其内包含 "foo" 或 "bar" 的任意整词进行索引, 当你想把许多相似或相关的词收录到同一个条目之下时, 这很有用, 例如:

reflex

只会把 "reflex" 作为整词的出现进行索引, 而:

reflex \<reflex\w*\>

会把 "reflex"、"reflexing" 和 "reflexed" 的出现全部收录到同一个条目 reflex 之下. 你经常需要用它来处理复数及其他词形变化.

这条包含规则还可以把词条限制在某些小节中, 并为词条添加它应归属的索引类别(从而只出现在某些索引中).

最后, 脚本可以添加改写规则, 重命名被自动用作索引条目的小节名称. 例如, 当 AutoIndex 把小节标题用作索引条目时, 我们可能想移除开头的 "A" 或 "The" 前缀:

!rewrite-name "(?i)(?:A|The)\s+(.*)" "\1"
