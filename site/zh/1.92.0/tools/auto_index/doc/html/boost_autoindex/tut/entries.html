第 5 步: 向 Docbook XML 添加手工索引条目(可选)

如果你向 Docbook XML 中添加手工 <indexentry> 标记, 它们会原样通过. 但请注意, 如果你使用 AutoIndex 的内部索引生成, 它只识别 <primary>、<secondary> 和 <tertiary> 元素(这些元素位于 <indexterm> 之内). <see> 和 <seealso> 元素目前不被识别, 若使用这些元素, AutoIndex 会发出警告.

同样, 当 AutoIndex 自行生成索引时, 这些元素可用的属性都不会被使用, <type> 属性除外.

对于 Quickbook 用户, auto_index_helpers.qbk 中有一些模板, 可以在不转写到 Docbook 的情况下辅助添加手工条目.
