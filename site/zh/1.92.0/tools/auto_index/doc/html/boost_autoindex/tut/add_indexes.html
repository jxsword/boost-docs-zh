第 3 步: 向文档添加索引

要向 BoostBook/Docbook 文档(可能用 Quickbook 生成, 也可能还使用 Doxygen 参考章节)添加单个"收录一切"索引, 请在你希望索引出现的位置添加 <index/>. 构建文档时, 该索引会渲染为一个名为 "Index" 的独立小节.

要添加多个索引, 需为每个索引指定标题, 并设置其 type 属性以指明收录哪些词条. 例如, 要把 AutoIndex 索引到的 函数、类、宏或 typedef 名称分别放入独立的索引, 同时保留一个主"收录一切"索引, 可以添加:

<index type="class_name">
<title>Class Index</title>
</index>

<index type="typedef_name">
<title>Typedef Index</title>
</index>

<index type="function_name">
<title>Function Index</title>
</index>

<index type="macro_name">
<title>Macro Index</title>
</index>

<index/>
注释

这样的多索引只有在让 XSL 样式表遵循每个索引的 "type" 属性时才能正确工作, 而默认情况下并非如此. 可以在 Jamfile 中向工程需求添加 <xsl:param>index.on.type=1 来开启该功能.

在 Quickbook 中, 你添加相同的标记, 但要用两个三引号 ''' 转义把它括起来, 如下:

'''<index/>'''

或者通过辅助文件 auto_index_helpers.qbk 更简便地完成, 即给定:

[include auto_index_helpers.qbk]

就可以简单地写作:

[named_index class_name Class Index]
[named_index function_name Function Index]
[named_index typedef_name Typedef Index]
[named_index macro_name Macro Index]
[index]
注释

AutoIndex 并不了解 XML 的 xinclude 元素, 因此如果你直接编写 Docbook XML, 可能需要先通过 XSL 处理器把所有内容扁平化为一个 XML 文件, 再交给 AutoIndex. 不过如果你使用的是 Boostbook 或 quickbook, 这些都会自动完成, 并且 AutoIndex 会索引整个文档, 包括以 xinclude 包含的任何小节.

如果你开启了 AutoIndex 的内部索引生成

<auto-index-internal>on

(通常推荐用于 HTML 输出, 但 并非 默认设置), 那么你还可以决定把生成的索引放入哪种 XML 包裹器中. 默认是一个 <section>...</section> XML 块(它会替换原来的 <index>...</index> 块). 不过, 视文档结构而定, 以及你是否希望索引独占一页——还是出现在目录之后的首页上——你可能想把索引放入其他类型的 XML 块中. 例如, 如果你的文档使用 <chapter> 作为顶层内容而不是 <section>, 那么把索引放在 <chapter> 或 <appendix> 块中可能更合适. 如果愿意, 你也可以把索引放入 <index> 块内, 此时索引不会单独占一页, 而是在 HTML 输出中紧跟目录之后.

你可以通过在 Jamfile 中设置 <auto-index-type>element-name 属性, 或者通过 AutoIndex 本身的 index-type=element-name 命令行选项, 来控制所使用的 XML 块类型. 例如, 要把索引放入附录, 你的 Jamfile 可能如下:

using quickbook ;
using auto-index ;

xml mylibrary : mylibary.qbk ;
boostbook standalone
    :
        mylibrary
    :
        # auto-indexing is on:
        <auto-index>on

        # PDFs rely on the XSL stylesheets to generate the index:
        <format>pdf:<auto-index-internal>off

        # HTML output uses auto-index to generate the index:
        <format>html:<auto-index-internal>on

        # Name of script file to use:
        <auto-index-script>index.idx

        # Set the XML wrapper for HML Indexes to "appendix":
        <format>html:<auto-index-type>appendix

        # Turn on multiple index support:
        <xsl:param>index.on.type=1
