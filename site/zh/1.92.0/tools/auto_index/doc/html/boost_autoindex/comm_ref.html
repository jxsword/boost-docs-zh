命令行参考

AutoIndex 支持以下命令行选项:

--in=infilename

指定待索引的 XML 输入文件的名称.

--out=outfilename

指定要创建的新 XML 文件的名称.

--scan=source-filename

指定应扫描 source-filename 以查找待索引的词条.

--script=script-filename

指定要处理的脚本文件的名称.

--no-duplicates

如果同一词条在同一小节中出现多次, 则只收录一个索引条目.

--internal-index

指定 AutoIndex 应自行生成实际的索引, 而不是插入 <indexterm> 标记并把索引生成留给 XSL 样式表.

--no-section-names

防止 AutoIndex 使用小节名称作为索引条目.

--prefix=pathname

指定一个目录, 作为前缀应用于脚本文件中的所有相对文件路径.

--index-type=element-name

指定用于包裹内部生成索引的 XML 元素的名称: 默认为 section, 但也可以是 appendix 或 chapter, 或其他任何带有正式标题的块级元素.
