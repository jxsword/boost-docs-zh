第 1 步: 构建 AutoIndex 工具

注释

这一步严格来说是可选的, 但非常值得执行, 可以加快构建速度.

cd 进入 tools/auto_index/build 并如下调用 bjam:

bjam release

也可以选择把你要使用的编译器工具集名称传给 bjam:

bjam release gcc

这会构建该工具, 并把一份副本放到当前目录(也就是 tools/auto_index/build)

现在打开你的 user-config.jam 文件, 并在文件末尾添加以下一行:

using auto-index : full-path-to-boost-tree/tools/auto_index/build/auto-index.exe ;
注释

该声明必须放在 user-config.jam 的末尾附近, 或者至少放在 Boostbook 初始化之后.

另请注意, Windows 用户必须在 user-config.jam 的路径中使用正斜杠
