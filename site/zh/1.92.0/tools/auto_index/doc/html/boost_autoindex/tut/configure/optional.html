将 AutoIndex 设为可选

在 Boost.Build 中把 auto-index 的使用设为可选 是一种体贴的做法, 可以让没有安装 AutoIndex 的用户仍然能够构建你的文档.

在你打磨文档的阶段, 这也非常方便, 让你可以自行决定是否构建索引: 构建索引可能耗时很久, 如果你只是在改正错别字, 恐怕不会愿意在反复重建索引上干等!

设置可选 AutoIndex 支持的一种方法, 是把全部 AutoIndex 配置放在一条 bjam if 语句的主体中:

if --enable-index in  [ modules.peek : ARGV ]
  {
     ECHO "Building the  docs with automatic index generation enabled." ;

     using auto-index ;
     project : requirements
          <auto-index>on
          <auto-index-script>index.idx

           ... other AutoIndex options here...

        # And tell Quickbook that it should enable indexing.
        <quickbook-define>enable_index
    ;
  }
  else
  {
     ECHO "Building the my_library docs with automatic index generation disabled. To get an Index, try building with --enable-index." ;
  }

你还需要在 Quickbook 文件的末尾添加一条条件语句, 使得只有在启用索引时, 才会在最后一个小节之后添加索引.

[? enable_index
'''
  <index/>
'''
]

要使用这个 jamfile, 你需要 cd 到你的 docs 文件夹, 例如:

cd \boost-sandbox\guild\mylibrary\libs\mylibrary\doc

然后运行 bjam 以构建不带索引的文档, 例如:

bjam -a html > mylibrary_html.log

或者带索引构建

bjam -a html --enable-index > mylibrary_html_index.log
