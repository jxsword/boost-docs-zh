第 8 步: 迭代以完善索引

创建一个好的索引是一个迭代的过程, 第一步通常只是在脚本文件中添加一条头文件扫描规则, 然后生成文档并查看:

  • 缺失了什么.
  • 收录了哪些不该收录的内容.
  • 哪些内容以不佳的名称收录了.

随后可以向脚本添加更多规则来处理这些情况, 再检查下一次迭代, 依此类推.

提示

如果你不明白某个特定词条为何(或为何没有)出现在索引中, 可以尝试把一条 !debug regular-expression 指令加入 脚本文件.

限制对特定词条索引哪些小节

你可以限制对特定词条索引哪些小节. 假设 docbook 文档的小节 ID 采用通常的层次化命名(例如 Quickbook 生成的就是如此), 你就可以轻松地对检查某个特定词条的小节范围加以约束.

例如, 如果你想索引 Lord Kelvin 之名的出现, 但仅限于引言小节, 可以添加:

Kelvin "" ".*introduction.*"

到脚本文件中, 假定引言部分的小节 ID 为 "some_library_or_chapter_name.introduction".

这样就不会在每次找到 "Kelvin" 时都生成一个索引条目, 否则用户不太可能觉得有用.
