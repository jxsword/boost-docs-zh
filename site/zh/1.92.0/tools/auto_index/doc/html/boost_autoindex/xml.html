XML 处理

AutoIndex 对 XML 的处理相当简单:

  • 在为文档编制索引时, 段落层级的所有块级内容都会被折叠为单个字符串, 用于与表示每个索引词条的正则表达式进行匹配. 换言之, 在编写正则表达式时, 你在大多数情况下可以假设自己是在索引纯文本.
  • 命名 XML 实体 &, ", ', < 或 > 会在索引文本小节之前转换为对应的字符. 不过, 十进制或十六进制转义序列目前不会被转换.
  • 索引词条被视为纯文本(无论它们来自脚本文件还是来自源文件扫描), 字符 &, ", < 和 > 会分别被转义为 &amp; &quot; &lt; 和 &gt;.
