Quickbook 支持

boost-path/tools/auto_index/include 中的文件 auto_index_helpers.qbk 包含多个用于辅助 AutoIndex 支持的 Quickbook 模板. 通常做法是在 Jamfile 中通过 <include>path 语句把上述路径加入你的包含搜索路径, 然后通过以下方式使这些模板可用于你的 Quickbook 源文件:

[include auto_index_helpers.qbk]

语句放在 Quickbook 文件的开头处.

随后可用的模板有:

模板

说明

[index]

创建一个主索引, 未设置 "type" 类别, 其标题就是简单的 "Index".

[named_index type title]

创建一个索引, 其 type 属性设为 "type", 标题则为 "title".
例如, 要创建一个只包含类名的索引, 通常会在 Quickbook 源文件中加入 [named_index class_name Class Index].

[AutoIndex Arg]

创建一个将由 AutoIndex 处理的 Docbook 处理指令, "Arg" 的有效值为 "IgnoreSection" 或 "IgnoreBlock".

[indexterm1 primary-key]

创建一个手工索引条目, 它会链接到当前小节, 并具有单一主键 "primary-key". 注意该索引键不会设置 "type" 属性, 因此只会出现在主索引中.

[indexterm2 primary-key secondary-key]

创建一个手工索引条目, 它会链接到当前小节, 并分别以 "primary-key" 和 "secondary key" 作为主键和次键. 注意该索引键不会设置 "type" 属性, 因此只会出现在主索引中.

[indexterm3 primary-key secondary-key tertiary-key]

创建一个手工索引条目, 它会链接到当前小节, 并具有主键、次键和第三级键: "primary-key"、"secondary key" 和 "tertiary key". 注意该索引键不会设置 "type" 属性, 因此只会出现在主索引中.

[typed_indexterm1 type primary-key]

创建一个手工索引条目, 它会链接到当前小节, 并具有单一主键 "primary-key". 注意该索引键的 "type" 属性会设为 "type" 参数的值, 因此也可能出现在同样设置了 type 属性的命名子索引中.

[typed_indexterm2 type primary-key secondary-key]

创建一个手工索引条目, 它会链接到当前小节, 并分别以 "primary-key" 和 "secondary key" 作为主键和次键. 注意该索引键的 "type" 属性会设为 "type" 参数的值, 因此也可能出现在同样设置了 type 属性的命名子索引中.

[typed_indexterm3 type primary-key secondary-key tertiary-key]

创建一个手工索引条目, 它会链接到当前小节, 并具有主键、次键和第三级键: "primary-key"、"secondary key" 和 "tertiary key". 注意该索引键的 "type" 属性会设为 "type" 参数的值, 因此也可能出现在同样设置了 type 属性的命名子索引中.
