随机访问遍历概念

一个类或内建类型 X 若下列表达式有效且遵循所述语义, 则其模型化 随机访问遍历 概念. 在下表中, Distance 为 iterator_traits<X>::difference_type, n 表示一个 Distance 类型的常量对象.

表达式 返回类型 操作语义 断言/前置条件
r += n X& 
{
  Distance m = n;
  if (m >= 0)
    while (m--)
      ++r;
  else
    while (m++)
      --r;
  return r;
}
