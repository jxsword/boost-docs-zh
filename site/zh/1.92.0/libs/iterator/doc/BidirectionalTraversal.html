双向遍历概念

一个类或内建类型 X 模型化 双向遍历 概念, 如果在 X 满足前向遍历迭代器 (Forward Traversal Iterator) 要求之外, 下列表达式亦有效且遵循所述语义.

双向遍历迭代器要求 (在前向遍历迭代器之外)
表达式 返回类型 断言/语义 / 前置/后置条件
--r X& pre: 存在 s 使得 r == ++s. post: s 可解引用. --(++r) == r. --r == --s 蕴含 r == s. &r == &--r.
r-- 可转换为 const X& 
{
  X tmp = r;
  --r;
  return tmp;
}
