函数输入迭代器

函数输入迭代器 (Function Input Iterator) 允许创建封装一个无参函数对象和一个状态对象的迭代器, 状态对象跟踪迭代器被递增的次数. 函数输入迭代器模型化 InputIterator 概念, 对创建有界输入迭代器很有用.

与生成器迭代器类似, 函数输入迭代器接受一个模型化 Generator 概念的函数 (基本上是一个无参或 0 元函数对象). 函数输入迭代器的每次递增都会调用生成器函数, 并把值存储在迭代器中. 当迭代器被解引用时, 返回存储的值.

函数输入迭代器封装一个状态对象, 该状态对象模型化 Incrementable Concept 与 EqualityComparable 概念. 这些概念在下面描述为:

可递增概念 (Incrementable Concept)

一个类型支持前置与后置递增运算符时, 即模型化可递增概念 (Incrementable Concept). 对于给定的 I 类型对象 i, 以下构造应当有效:

构造 描述 返回类型
i++ 后置递增 i. I
++i 前置递增 i. I&

注意: 可递增 (Incrementable) 类型还应当是 DefaultConstructible.

概要

namespace {
    template <class Function, class State>
    class function_input_iterator;

    template <class Function, class State>
    typename function_input_iterator<Function, State>
    make_function_input_iterator(Function & f);

    struct infinite;
}

函数输入迭代器类

函数输入迭代器类接受两个模板参数 Function 与 State. 这两个模板参数告诉函数输入迭代器要封装的函数的类型, 以及要持有的内部状态值的类型.

在希望控制计数器类型 (该计数器判定两个迭代器是否处于同一状态) 的场合, State 参数很重要. 这允许创建一对迭代器, 界定被封装函数的调用范围.

示例

以下示例展示: 在希望创建有界 (惰性) 生成范围的场合, 如何使用函数输入迭代器类.

struct generator {
    typedef int result_type;
    generator() { srand(time(0)); }
    result_type operator() () const {
        return rand();
    }
};

int main(int argc, char * argv[]) {
    generator f;
    copy(
            make_function_input_iterator(f, 0),
            make_function_input_iterator(f, 10),
            ostream_iterator<int>(cout, " ")
        );
    return 0;
}

这里可以看到, 我们用一个从 0 计数到 10 的 int 界定了调用次数. 假设我们想创建一个无尽的随机数流, 并把它封装在一对整数中, 可以借助 boost::infinite 辅助类实现.

copy(
        make_function_input_iterator(f,infinite()),
        make_function_input_iterator(f,infinite()),
        ostream_iterator<int>(count, " ")
    );

上例中, 我们没有创建巨大的 vector, 而是依靠 STL copy 算法遍历函数输入迭代器, 并在递增迭代器时调用函数对象 f. boost::infinite 的特殊性质在于: 对两个实例判等总是得到 false, 而递增一个 boost::infinite 实例不做任何事情. 这是以高效方式声明: 由两个封装了无穷状态的迭代器所提供的迭代器范围必然是无穷的.
