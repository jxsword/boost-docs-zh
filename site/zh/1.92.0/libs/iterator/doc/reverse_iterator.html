reverse_iterator 概要

template <class Iterator>
class reverse_iterator
{
public:
  typedef iterator_traits<Iterator>::value_type value_type;
  typedef iterator_traits<Iterator>::reference reference;
  typedef iterator_traits<Iterator>::pointer pointer;
  typedef iterator_traits<Iterator>::difference_type difference_type;
  typedef /* see below */ iterator_category;

  reverse_iterator() {}
  explicit reverse_iterator(Iterator x) ;

  template<class OtherIterator>
  reverse_iterator(
      reverse_iterator<OtherIterator> const& r
    , typename enable_if_convertible<OtherIterator, Iterator>::type* = 0 // exposition
  );
  Iterator const& base() const;
  reference operator*() const;
  reverse_iterator& operator++();
  reverse_iterator& operator--();
private:
  Iterator m_iterator; // exposition
};

若 Iterator 模型化随机访问遍历迭代器与可读左值迭代器, 则 iterator_category 可转换为 random_access_iterator_tag. 否则, 若 Iterator 模型化双向遍历迭代器与可读左值迭代器, 则 iterator_category 可转换为 bidirectional_iterator_tag. 否则 iterator_category 可转换为 input_iterator_tag.

reverse_iterator 要求

Iterator 必须是双向遍历迭代器的一个模型. 类型 iterator_traits<Iterator>::reference 必须是 *i 的类型, 其中 i 是 Iterator 类型的对象.

reverse_iterator 模型化的概念

reverse_iterator 的特化模型化其 Iterator 实参所建模的相同迭代器遍历与迭代器访问概念. 此外, 它还可模型化下表所列的旧迭代器概念:

若 I 模型化 则 reverse_iterator<I> 模型化
可读左值迭代器, 双向遍历迭代器 双向迭代器
可写左值迭代器, 双向遍历迭代器 可变双向迭代器
可读左值迭代器, 随机访问遍历迭代器 随机访问迭代器
可写左值迭代器, 随机访问遍历迭代器 可变随机访问迭代器

reverse_iterator<X> 与 reverse_iterator<Y> 可互操作, 当且仅当 X 与 Y 可互操作.

reverse_iterator 操作

除 reverse_iterator 所建模概念要求的操作之外, reverse_iterator 还提供以下操作.

reverse_iterator();

要求:Iterator 必须可默认构造.
效果:构造一个 reverse_iterator 实例, 其 m_iterator 为默认构造.

explicit reverse_iterator(Iterator x);

效果:构造一个 reverse_iterator 实例, 其 m_iterator 由 x 拷贝构造. 
template<class OtherIterator>
reverse_iterator(
    reverse_iterator<OtherIterator> const& r
  , typename enable_if_convertible<OtherIterator, Iterator>::type* = 0 // exposition
);
要求:OtherIterator 可隐式转换为 Iterator.
效果:构造一个 reverse_iterator 实例, 其 m_iterator 子对象由 y.base() 构造.

Iterator const& base() const;

返回:m_iterator

reference operator*() const;

效果: 
Iterator tmp = m_iterator;
return *--tmp;

reverse_iterator& operator++();

效果:--m_iterator
返回:*this

reverse_iterator& operator--();

效果:++m_iterator
返回:*this 
template <class BidirectionalIterator>
reverse_iterator<BidirectionalIterator>n
make_reverse_iterator(BidirectionalIterator x);
返回:一个 reverse_iterator<BidirectionalIterator> 实例, 其 current 由 x 构造.

示例

以下示例使用 reverse_iterator 以相反的顺序打印一个字符数组.

char letters_[] = "hello world!";
const int N = sizeof(letters_)/sizeof(char) - 1;
typedef char* base_iterator;
base_iterator letters(letters_);
std::cout << "original sequence of letters:\t\t\t" << letters_ << std::endl;

boost::reverse_iterator<base_iterator>
  reverse_letters_first(letters + N),
  reverse_letters_last(letters);

std::cout << "sequence in reverse order:\t\t\t";
std::copy(reverse_letters_first, reverse_letters_last,
          std::ostream_iterator<char>(std::cout));
std::cout << std::endl;

std::cout << "sequence in double-reversed (normal) order:\t";
std::copy(boost::make_reverse_iterator(reverse_letters_last),
          boost::make_reverse_iterator(reverse_letters_first),
          std::ostream_iterator<char>(std::cout));
std::cout << std::endl;

输出为:

original sequence of letters:                   hello world!
sequence in reverse order:                      !dlrow olleh
sequence in double-reversed (normal) order:     hello world!
