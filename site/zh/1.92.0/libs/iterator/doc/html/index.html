引言

Boost 迭代器库包含两部分. 第一部分是一个 概念体系, 扩展了 C++ 标准迭代器要求. 第二部分是一个组件框架, 用于基于这些扩展概念构建迭代器, 并包含若干有用的迭代器适配器. 扩展的迭代器概念经过精心设计, 使旧式迭代器能够契合新概念, 也使新式迭代器与旧式算法兼容——不过算法若想充分利用新式迭代器的能力, 可能需要更新. 本库的若干组件已被 C++ 标准技术报告接受. Boost 迭代器库的组件取代了旧的 Boost Iterator Adaptor 库.

新式迭代器

C++98 中定义的迭代器类别极其受限, 因为它们把两个正交的概念捆绑在一起: 遍历与元素访问. 例如, 由于随机访问迭代器被要求在解引用时返回引用 (而非代理), 因此无法用 C++98 类别捕捉 vector<bool>::iterator 的能力. 这就是臭名昭著的 "vector<bool> 不是容器, 其迭代器也不是随机访问迭代器" 的溃败事件, Herb Sutter 为标准委员会就此写过两篇论文 (N1185 与 N1211) 以及一篇 Guru of the Week. 新式迭代器远不止是修补 vector<bool>: 还有许多已在使用的迭代器无法被现有概念充分表达. 关于新迭代器概念的细节, 参见我们的 Standard Proposal for New-Style Iterators.

迭代器外观与适配器

编写符合标准的迭代器颇有技巧性, 但这种需求经常出现. 为了简化新迭代器的实现, Boost.Iterator 库提供了 facade 类模板, 它实现了许多有用的默认行为与编译期检查, 旨在帮助迭代器作者确保其迭代器的正确性.

同样常见的是定义一个与某个底层迭代器或类迭代器类型相似、但修改底层类型行为某些方面的新迭代器. 为此, 本库提供了 adaptor 类模板, 它经过专门设计, 能够尽可能多地利用底层类型的行为.

facade 与 adaptor 以及下文提到的许多 特化适配器 都已被提议标准化 (Standard Proposal For Iterator Facade and Adaptor).

特化适配器

迭代器库提供了一套有用的符合标准的迭代器模板, 基于 Boost iterator facade and adaptor 模板.

  • counting_iterator: 一个遍历连续值序列的迭代器. 实现"惰性序列"
  • filter_iterator: 一个遍历某序列中满足给定谓词的元素子集的迭代器
  • function_input_iterator: 一个包装生成器 (无参函数对象) 的输入迭代器; 每次解引用迭代器时, 都会调用函数对象以取得要返回的值.
  • function_output_iterator: 一个包装一元函数对象的输出迭代器; 每次向解引用后的迭代器写入元素时, 该元素都作为参数传递给函数对象.
  • generator_iterator: 一个包装生成器 (无参函数对象) 的输入迭代器; 每次解引用迭代器时, 都会调用函数对象以取得要返回的值. 是 function_input_iterator 的过时对应物.
  • indirect_iterator: 一个遍历某序列元素所指向对象的迭代器.
  • permutation_iterator: 一个遍历某随机访问序列元素的迭代器, 依照某个整数索引序列重新排列.
  • reverse_iterator: 一个反向遍历某双向序列元素的迭代器. 修正了 C++98 的 std::reverse_iterator 的许多缺陷.
  • shared_container_iterator: 一个遍历某容器元素的迭代器, 该容器的生存期由迭代器中存储的 shared_ptr 维护.
  • transform_iterator: 一个遍历元素的迭代器, 这些元素是对底层序列元素施加某种函数变换的结果. 该组件还取代了旧的 projection_iterator_adaptor.
  • zip_iterator: 一个遍历元组的迭代器, 元组由各底层迭代器对应位置上的元素组成.

迭代器工具

特征

  • pointee.hpp: 提供在泛型代码中推导指针、智能指针与迭代器的引用对象类型的能力. 用于 indirect_iterator.
  • iterator_traits.hpp: 提供与 MPL 兼容的元函数, 用于获取迭代器的特征. 同时修正 std::iterator_traits 的有缺陷实现.

测试与概念检查

  • iterator_concepts.hpp: 新迭代器概念的概念检查类.
  • iterator_archetypes.hpp: 新迭代器概念的概念原型类.

迭代器算法

本库提供若干与迭代器配合使用的泛型算法. 这些算法利用本库定义的新概念, 以提供更好的性能与功能.

  • advance.hpp: 提供 advance() 函数, 用于把迭代器向前或向后前进给定的位置数.
  • distance.hpp: 提供 distance() 函数, 用于计算两个迭代器之间的距离.
  • next_prior.hpp: 提供 next() 与 prior() 函数, 用于获取给定迭代器的下一个与上一个迭代器. 这些函数也与非迭代器类型兼容.
