类型特征

概述

你是否曾经想编写一个能对任何种类的可解引用对象操作的泛型函数? 如果有, 你很可能遇到过如何确定该对象"指向"的类型这一问题:

template <class Dereferenceable>
void f(Dereferenceable p)
{
    *what-goes-here?* value = \*p;
    ...
}

pointee

事实证明, 不可能提出一个完全通用的算法来直接确定 what-goes-here, 但可以要求 pointee<Dereferenceable>::type 是正确的. 自然, pointee 有同样的困难: 它无法可靠地确定合适的 ::type 对所有 Dereferenceable 都成立, 但它做出了非常好的猜测 (它对所有指针、标准与 boost 智能指针以及迭代器都有效), 而当它猜错时, 可以按需特化:

namespace boost
{
  template <class T>
  struct pointee<third_party_lib::smart_pointer<T> >
  {
      typedef T type;
  };
}

indirect_reference

indirect_reference<T>::type 比 pointee 更为特化, 用于转发对其实参类型对象解引用的结果. 大多数可解引用类型只返回指向其被指对象的引用, 但有些返回代理引用或按值返回被指对象. 当需要该信息时, 请调用 indirect_reference.

这两个模板对 indirect_iterator 的正确运作都必不可少.

min_category

min_category 接受一个或多个迭代器类别或迭代器遍历标签, 并返回其中最弱 (即最不高级) 的一个. 例如:

static_assert(
    is_same<
        min_category<
            std::forward_iterator_tag,
            std::random_access_iterator_tag
        >::type,
        std::forward_iterator_tag
    >::value,
    "Unexpected minimum_category result"
);

迭代器类别与遍历标签操作

本库提供若干工具以简化迭代器类别与遍历标签之间的转换:

  • iterator_category_to_traversal<C>::type - 该元函数接受一个迭代器类别 C 并返回对应的遍历标签.
  • iterator_traversal<T>::type - iterator_category_to_traversal<iterator_category<T>::type>::type 的简写.
  • pure_traversal_tag<T>::type - 该元函数接受一个派生自某个迭代器遍历标签的标签 T, 并返回该遍历标签. T 也可以派生自描述该迭代器的其他标签 (例如它是否是 const 迭代器), 这些附加标签不予考虑.
  • pure_iterator_traversal<T>::type - pure_traversal_tag<iterator_traversal<T>::type>::type 的简写.

参考

pointee 

template <class Dereferenceable>
struct pointee
{
    typedef /* see below */ type;
};

要求: 对于对象 x (其类型为 Dereferenceable), *x 必须良构. 若 ++x 非良构, 则它既不应有歧义, 也不应违反访问控制, 且 Dereferenceable::element_type 应为可访问类型. 否则 iterator_traits<Dereferenceable>::value_type 必须良构. [注意: 这些要求不必适用于 pointee 的显式特化或偏特化]

type 按照以下算法确定, 其中 x 是 Dereferenceable 类型的对象:

if ( ++x is ill-formed )
{
    return Dereferenceable::element_type
}
else if (*x is a mutable reference to
         std::iterator_traits<Dereferenceable>::value_type)
{
    return iterator_traits<Dereferenceable>::value_type
}
else
{
    return iterator_traits<Dereferenceable>::value_type const
}

indirect_reference 

template <class Dereferenceable>
struct indirect_reference
{
    typedef /* see below */ type;
};

要求: 对于对象 x (其类型为 Dereferenceable), *x 必须良构. 若 ++x 非良构, 则它既不应有歧义, 也不应违反访问控制, 且 pointee<Dereferenceable>::type& 必须良构. 否则 iterator_traits<Dereferenceable>::reference 必须良构. [注意: 这些要求不必适用于 indirect_reference 的显式特化或偏特化]

type 按照以下算法确定, 其中 x 是 Dereferenceable 类型的对象:

if ( ++x is ill-formed )
    return pointee<Dereferenceable>::type&
else
    std::iterator_traits<Dereferenceable>::reference

minimum_category 

template <typename C1, typename C2>
struct minimum_category
{
    typedef /* see below */ type;
};

要求: C1 与 C2 都应当是标准迭代器类别或迭代器遍历标签.

type 按照以下算法确定, 其中 c1 是 C1 类型的对象, c2 是 C2 类型的对象:

if (c1 is convertible to c2)
    return C2;
else
    return C1;
注释

上述定义依赖于如下事实: 约束更强的类别与遍历标签可转换为约束更弱者.

iterator_category_to_traversal 

template <typename C>
struct iterator_category_to_traversal
{
    typedef /* see below */ type;
};

要求: C 应当是标准迭代器类别或迭代器遍历标签.

若 C 是迭代器遍历标签或可转换为其中之一, 则 type 等价于 C. 否则, type 定义为与 C 匹配的最接近的迭代器遍历标签.

iterator_traversal 

template <typename Iterator>
struct iterator_traversal
{
    typedef typename iterator_category_to_traversal<
        typename iterator_category<Iterator>::type
    >::type type;
};

要求: Iterator 应当是一个迭代器.

pure_traversal_tag 

template <typename T>
struct pure_traversal_tag
{
    typedef /* see below */ type;
};

要求: T 应可转换为迭代器遍历标签.

type 定义为最先进的遍历标签 Tag, 使得 T 可转换为 Tag.

pure_iterator_traversal 

template <typename Iterator>
struct pure_iterator_traversal
{
    typedef typename pure_traversal_tag<
        typename iterator_traversal<Iterator>::type
    >::type type;
};

要求: Iterator 应当是一个迭代器.
