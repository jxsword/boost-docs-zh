函数模板 distance()

函数模板 boost::iterators::distance 是 std::distance 针对 Boost 迭代器 遍历概念 的适配版本.

头文件 
<boost/iterator/distance.hpp>
概要 
template <typename Iterator>
constexpr typename iterator_difference<Iterator>::type
distance(Iterator first, Iterator last);
说明

计算从 first 到 last 的 (有符号) 距离.

要求

Iterator 应模型化 单遍迭代器.

前置条件

若 Iterator 模型化 随机访问遍历迭代器, 则 [first, last) 或 [last, first) 应有效; 否则 [first, last) 应有效.

复杂度

若 Iterator 模型化 随机访问遍历迭代器, 则耗时为常数; 否则耗时为线性.

注释
  • 该函数不是定制点, 并且受保护而不被实参依赖查找 (ADL) 找到.
  • 该函数仅在 C++14 及以后才是 constexpr.
