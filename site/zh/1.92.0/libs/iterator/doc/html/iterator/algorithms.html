函数模板 advance()

函数模板 boost::iterators::advance 是 std::advance 针对 Boost 迭代器 遍历概念 的适配版本.

头文件 
<boost/iterator/advance.hpp>
概要 
template <typename Iterator, typename Distance>
constexpr void advance(Iterator& it, Distance n);
说明

把 it 向前移动 n 个增量 (或向后移动 |n| 个减量, 若 n 为负).

要求

Iterator 应模型化可递增迭代器.

前置条件

设 iti 为如下所得迭代器: 根据 n 的符号, 对 it 施加 i 次递增或递减. 所有迭代器 iti (对于 i = 0, 1, 2, ..., |n|) 都应当有效.

若 Iterator 不模型化 双向遍历迭代器, 则 n 应为非负.

复杂度

若 Iterator 模型化 随机访问遍历迭代器, 则耗时为常数; 否则耗时为线性.

注释
  • 该函数不是定制点, 并且受保护而不被实参依赖查找 (ADL) 找到.
  • 该函数仅在 C++14 及以后才是 constexpr.
