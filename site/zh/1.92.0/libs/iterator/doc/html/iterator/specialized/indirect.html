间接迭代器

indirect_iterator 通过施加 额外 一层嵌入 operator*() 内部的解引用来适配迭代器. 例如, 这个迭代器适配器使查看指针容器 (如 list<foo*>) 如同查看被指向类型的容器 (如 list<foo>) 成为可能. indirect_iterator 依赖两个辅助特征 pointee 与 indirect_reference, 以支持其 value_type 不是迭代器的底层迭代器.

示例

本示例打印一个字符数组, 使用 indirect_iterator 通过指针数组访问字符数组. 接着把 indirect_iterator 与 transform 算法一起使用, 把字符 (加一后) 拷贝到另一个数组. 源使用常量间接迭代器, 目标使用可变间接迭代器. 示例的最后一部分打印原字符数组, 但这次使用 make_indirect_iterator 辅助函数.

char characters[] = "abcdefg";
const int N = sizeof(characters)/sizeof(char) - 1; // -1 since characters has a null char
char* pointers_to_chars[N];                        // at the end.
for (int i = 0; i < N; ++i)
  pointers_to_chars[i] = &characters[i];

// Example of using indirect_iterator

boost::indirect_iterator<char**, char>
  indirect_first(pointers_to_chars), indirect_last(pointers_to_chars + N);

std::copy(indirect_first, indirect_last, std::ostream_iterator<char>(std::cout, ","));
std::cout << std::endl;


// Example of making mutable and constant indirect iterators

char mutable_characters[N];
char* pointers_to_mutable_chars[N];
for (int j = 0; j < N; ++j)
  pointers_to_mutable_chars[j] = &mutable_characters[j];

boost::indirect_iterator<char* const*> mutable_indirect_first(pointers_to_mutable_chars),
  mutable_indirect_last(pointers_to_mutable_chars + N);
boost::indirect_iterator<char* const*, char const> const_indirect_first(pointers_to_chars),
  const_indirect_last(pointers_to_chars + N);

std::transform(const_indirect_first, const_indirect_last,
  mutable_indirect_first, std::bind(std::plus<char>(), 1, std::placeholders::_1));

std::copy(mutable_indirect_first, mutable_indirect_last,
  std::ostream_iterator<char>(std::cout, ","));
std::cout << std::endl;


// Example of using make_indirect_iterator()

std::copy(boost::make_indirect_iterator(pointers_to_chars),
          boost::make_indirect_iterator(pointers_to_chars + N),
          std::ostream_iterator<char>(std::cout, ","));
std::cout << std::endl;

输出为:

a,b,c,d,e,f,g,
b,c,d,e,f,g,h,
a,b,c,d,e,f,g,

本示例的源代码可在 此处 找到.

参考

概要 

template <
    class Iterator
  , class Value = use_default
  , class CategoryOrTraversal = use_default
  , class Reference = use_default
  , class Difference = use_default
>
class indirect_iterator
{
 public:
    typedef /* see below */ value_type;
    typedef /* see below */ reference;
    typedef /* see below */ pointer;
    typedef /* see below */ difference_type;
    typedef /* see below */ iterator_category;

    indirect_iterator();
    indirect_iterator(Iterator x);

    template <
        class Iterator2, class Value2, class Category2
      , class Reference2, class Difference2
    >
    indirect_iterator(
        indirect_iterator<
             Iterator2, Value2, Category2, Reference2, Difference2
        > const& y
      , typename enable_if_convertible<Iterator2, Iterator>::type* = 0 // exposition
    );

    Iterator const& base() const;
    reference operator*() const;
    indirect_iterator& operator++();
    indirect_iterator& operator--();
private:
   Iterator m_iterator; // exposition
};

indirect_iterator 的成员类型按照以下伪代码定义, 其中 V 为 iterator_traits<Iterator>::value_type 

  if (Value is use_default) then
      typedef remove_const<pointee<V>::type>::type value_type;
  else
      typedef remove_const<Value>::type value_type;

  if (Reference is use_default) then
      if (Value is use_default) then
          typedef indirect_reference<V>::type reference;
      else
          typedef Value& reference;
  else
      typedef Reference reference;

  if (Value is use_default) then
      typedef pointee<V>::type* pointer;
  else
      typedef Value* pointer;

  if (Difference is use_default)
      typedef iterator_traits<Iterator>::difference_type difference_type;
  else
      typedef Difference difference_type;

  if (CategoryOrTraversal is use_default)
      typedef iterator-category (
          iterator_traversal<Iterator>::type,reference,value_type
      ) iterator_category;
  else
      typedef iterator-category (
          CategoryOrTraversal,reference,value_type
      ) iterator_category;

要求

表达式 *v (其中 v 是 iterator_traits<Iterator>::value_type 的对象) 必须是有效表达式, 且可转换为 reference. Iterator 应模型化 iterator_category 所指示的遍历概念. Value、Reference 与 Difference 的选取应使 value_type、reference 与 difference_type 满足 iterator_category 所指示的要求.

注意: iterator_traits<Iterator>::value_type 上还有进一步要求——若 Value 参数不是 use_default, 如推导 value_type 成员默认值的算法所蕴含的那样.

概念

除 iterator_category 与 iterator_traversal<indirect_iterator>::type 所指示的概念之外, indirect_iterator 的特化还模型化以下概念, 其中 v 是 iterator_traits<Iterator>::value_type 的对象:

若 reference(*v) 可转换为 value_type, 则为可读迭代器.

若 reference(*v) = t 是有效表达式 (其中 t 是 indirect_iterator::value_type 类型的对象), 则为可写迭代器

若 reference 是引用类型, 则为左值迭代器.

indirect_iterator<X,V1,C1,R1,D1> 可互操作, indirect_iterator<Y,V2,C2,R2,D2> 当且仅当 X 可互操作, Y.

操作

除上述概念所要求的操作之外, indirect_iterator 的特化还提供以下操作:

indirect_iterator();

要求: Iterator 必须可默认构造.
效果: 构造一个 indirect_iterator 实例, 其 m_iterator 为默认构造.

indirect_iterator(Iterator x);

效果: 构造一个 indirect_iterator 实例, 其 m_iterator 由 x 拷贝构造.

template <
    class Iterator2, class Value2, unsigned Access, class Traversal
  , class Reference2, class Difference2
>
indirect_iterator(
    indirect_iterator<
         Iterator2, Value2, Access, Traversal, Reference2, Difference2
    > const& y
  , typename enable_if_convertible<Iterator2, Iterator>::type* = 0 // exposition
);

要求: Iterator2 可隐式转换为 Iterator.
效果: 构造一个 indirect_iterator 实例, 其 m_iterator 子对象由 y.base() 构造.

Iterator const& base() const;

返回: m_iterator 

reference operator*() const;

返回: **m_iterator 

indirect_iterator& operator++();

效果: ++m_iterator
返回: *this 

indirect_iterator& operator--();

效果: --m_iterator
返回: *this
