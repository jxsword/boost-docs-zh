过滤迭代器

过滤迭代器适配器创建迭代器范围的一个视图, 其中范围的某些元素被跳过. 一个谓词函数对象控制哪些元素被跳过. 当谓词应用于某个元素时, 若其返回 true 则该元素被保留, 若返回 false 则该元素被跳过. 在跳过元素时, 过滤适配器必须知道何时停止, 以免越过底层范围的末尾. 因此, 过滤迭代器用一对迭代器来构造, 指示未过滤序列中要遍历的元素范围.

示例

本示例先使用 filter_iterator, 然后使用 make_filter_iterator, 只输出整数数组中的正整数. 随后用 make_filter_iterator 输出大于 -2 的整数.

struct is_positive_number {
  bool operator()(int x) { return 0 < x; }
};

int main()
{
  int numbers_[] = { 0, -1, 4, -3, 5, 8, -2 };
  const int N = sizeof(numbers_)/sizeof(int);

  typedef int* base_iterator;
  base_iterator numbers(numbers_);

  // Example using filter_iterator
  typedef boost::filter_iterator<is_positive_number, base_iterator>
    FilterIter;

  is_positive_number predicate;
  FilterIter filter_iter_first(predicate, numbers, numbers + N);
  FilterIter filter_iter_last(predicate, numbers + N, numbers + N);

  std::copy(filter_iter_first, filter_iter_last, std::ostream_iterator<int>(std::cout, " "));
  std::cout << std::endl;

  // Example using make_filter_iterator()
  std::copy(boost::make_filter_iterator<is_positive_number>(numbers, numbers + N),
            boost::make_filter_iterator<is_positive_number>(numbers + N, numbers + N),
            std::ostream_iterator<int>(std::cout, " "));
  std::cout << std::endl;

  // Another example using make_filter_iterator()
  std::copy(
      boost::make_filter_iterator(
          std::bind(std::greater<int>(), std::placeholders::_1, -2)
        , numbers, numbers + N)

    , boost::make_filter_iterator(
          std::bind(std::greater<int>(), std::placeholders::_1, -2)
        , numbers + N, numbers + N)

    , std::ostream_iterator<int>(std::cout, " ")
  );

  std::cout << std::endl;

  return boost::exit_success;
}

输出为:

4 5 8
4 5 8
0 -1 4 5 8

参考

概要 

template <class Predicate, class Iterator>
class filter_iterator
{
 public:
    typedef iterator_traits<Iterator>::value_type value_type;
    typedef iterator_traits<Iterator>::reference reference;
    typedef iterator_traits<Iterator>::pointer pointer;
    typedef iterator_traits<Iterator>::difference_type difference_type;
    typedef /* see below */ iterator_category;

    filter_iterator();
    filter_iterator(Predicate f, Iterator x, Iterator end = Iterator());
    filter_iterator(Iterator x, Iterator end = Iterator());
    template<class OtherIterator>
    filter_iterator(
        filter_iterator<Predicate, OtherIterator> const& t
        , typename enable_if_convertible<OtherIterator, Iterator>::type* = 0 // exposition
        );
    Predicate predicate() const;
    Iterator end() const;
    Iterator const& base() const;
    reference operator*() const;
    filter_iterator& operator++();
private:
    Predicate m_pred; // exposition only
    Iterator m_iter;  // exposition only
    Iterator m_end;   // exposition only
};

若 Iterator 模型化可读左值迭代器与双向遍历迭代器, 则 iterator_category 可转换为 std::bidirectional_iterator_tag. 否则, 若 Iterator 模型化可读左值迭代器与前向遍历迭代器, 则 iterator_category 可转换为 std::forward_iterator_tag. 否则 iterator_category 可转换为 std::input_iterator_tag.

要求

实参 Iterator 应满足可读迭代器与单遍迭代器的要求, 或应满足输入迭代器的要求.

实参 Predicate 必须可赋值、可拷贝构造, 且表达式 p(x) 必须有效, 其中 p 是 Predicate 类型的对象, x 是 iterator_traits<Iterator>::value_type 类型的对象, 且 p(x) 的类型必须可转换为 bool.

操作

除 filter_iterator 所模型化概念要求的操作之外, filter_iterator 还提供以下操作.

filter_iterator();

要求: Predicate 与 Iterator 必须可默认构造.
效果: 构造一个 filter_iterator , 其成员 m_pred、m_iter 与 m_end 成员均为默认构造.

filter_iterator(Predicate f, Iterator x, Iterator end = Iterator());

效果: 构造一个 filter_iterator, 其中 m_iter 为范围 [x,end) 中使 f(*m_iter) == true 的第一个位置, 否则 m_iter == end. 成员 m_pred 由 f 构造, m_end 由 end 构造.

filter_iterator(Iterator x, Iterator end = Iterator());

要求: Predicate 必须可默认构造, 且 Predicate 是类类型 (而非函数指针).
效果: 构造一个 filter_iterator, 其中 m_iter 为范围 [x,end) 中使 m_pred(*m_iter) == true 的第一个位置, 否则 m_iter == end. 成员 m_pred 为默认构造.

template <class OtherIterator>
filter_iterator(
    filter_iterator<Predicate, OtherIterator> const& t
    , typename enable_if_convertible<OtherIterator, Iterator>::type* = 0 // exposition
    );

要求: OtherIterator 可隐式转换为 Iterator.
效果: 构造一个过滤迭代器, 其成员从 t 拷贝而来.

Predicate predicate() const;

返回: m_pred 

Ierator end() const;

返回: m_end 

Iterator const& base() const;

返回: m_iterator 

reference operator*() const;

返回: *m_iter 

filter_iterator& operator++();

效果: 递增 m_iter, 然后继续递增 m_iter, 直到 m_iter == m_end 或 m_pred(*m_iter) == true 为止.
返回: *this
