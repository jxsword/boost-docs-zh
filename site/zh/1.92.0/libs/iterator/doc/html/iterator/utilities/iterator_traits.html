迭代器特征

std::iterator_traits 提供对任何迭代器五个关联类型的访问: 其 value_type、reference、pointer、iterator_category 与 difference_type. 遗憾的是, 这种"多值"特征模板在元编程语境中可能难以使用. <boost/iterator/iterator_traits.hpp> 使用标准的 metafunctions_ 提供对这些类型的访问.

概要

头文件 <boost/iterator/iterator_traits.hpp>:

template <class Iterator>
struct iterator_value
{
    typedef typename
      std::iterator_traits<Iterator>::value_type
    type;
};

template <class Iterator>
struct iterator_reference
{
    typedef typename
      std::iterator_traits<Iterator>::reference
    type;
};

template <class Iterator>
struct iterator_pointer
{
    typedef typename
      std::iterator_traits<Iterator>::pointer
    type;
};

template <class Iterator>
struct iterator_difference
{
    typedef typename
      detail::iterator_traits<Iterator>::difference_type
    type;
};

template <class Iterator>
struct iterator_category
{
    typedef typename
      detail::iterator_traits<Iterator>::iterator_category
    type;
};
