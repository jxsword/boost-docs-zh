函数模板 next() 与 prior()

某些数据类型, 如 C++ 标准库的前向与双向迭代器, 不通过 operator+() 或 operator-() 提供加法与减法. 这意味着, 即使提供了 operator++() 或 operator--(), 对下一个或上一个值的非修改性计算仍需要临时对象. 它还意味着, 在模板中编写 itr+1 这样的代码会把迭代器类别限制为随机访问迭代器.

next() 与 prior() 函数定义于 boost/next_prior.hpp 中, 为这些问题提供了简单的解决途径.

概要 
template <class T>
T next(T x)
{
    return ++x;
}

template <class T, class Distance>
T next(T x, Distance n)
{
    std::advance(x, n);
    return x;
}

template <class T>
T prior(T x)
{
    return --x;
}

template <class T, class Distance>
T prior(T x, Distance n)
{
    std::advance(x, -n);
    return x;
}
注释

上面的函数实现仅用于说明. 实际实现对于迭代器具有相同效果, 但具有不同的性质, 稍后有说明.

用法

用法很简单:

const std::list<T>::iterator p = get_some_iterator();
const std::list<T>::iterator prev = boost::prior(p);
const std::list<T>::iterator next = boost::next(prev, 2);

距给定迭代器的距离应以绝对值提供. 例如, 位于给定迭代器 p 之前四个位置的迭代器, 可通过 prior(p, 4) 获得.

自 C++11 起, 标准库提供了 std::next() 与 std::prev() 函数模板, 达到同样的目的. 然而, boost::next() 与 boost::prior() 有其优势.

首先, boost::next() 与 boost::prior() 不仅与迭代器兼容, 还与任何提供算术运算符 operator++()、operator--()、operator+()、operator-()、operator+=() 或 operator-=() 的类型兼容. 例如, 下面这样是可行的:

int x = 10;
int y = boost::next(x, 5);
assert(y == 15);

其次, boost::next() 与 boost::prior() 使用 遍历类别 来选择最高效的实现. 对于某些种类的迭代器 (例如 变换迭代器), 标准迭代器类别不能正确反映遍历类别, 因此 std::next() 与 std::prev() 会退回到线性复杂度.
