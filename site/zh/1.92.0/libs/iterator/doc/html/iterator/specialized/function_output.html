函数输出迭代器

函数输出迭代器适配器使创建自定义输出迭代器更加容易. 该适配器接受一个一元函数, 并创建一个输出迭代器 (Output Iterator) 的模型. 赋给输出迭代器的每一项都作为实参传递给该一元函数. 这个迭代器的动机在于: 创建一个符合规范的输出迭代器并非易事, 特别是因为正确的实现通常需要一个代理对象.

示例 

struct string_appender
{
    string_appender(std::string& s)
        : m_str(&s)
    {}

    void operator()(const std::string& x) const
    {
        *m_str += x;
    }

    std::string* m_str;
};

int main(int, char*[])
{
  std::vector<std::string> x;
  x.push_back("hello");
  x.push_back(" ");
  x.push_back("world");
  x.push_back("!");

  std::string s = "";
  std::copy(x.begin(), x.end(),
      boost::make_function_output_iterator(string_appender(s)));

  std::cout << s << std::endl;

  return 0;
}

参考

概要 

template <class UnaryFunction>
class function_output_iterator {
public:
  typedef std::output_iterator_tag iterator_category;
  typedef void                     value_type;
  typedef void                     difference_type;
  typedef void                     pointer;
  typedef void                     reference;

  explicit function_output_iterator();

  explicit function_output_iterator(const UnaryFunction& f);

  /* see below */ operator*();
  function_output_iterator& operator++();
  function_output_iterator& operator++(int);
private:
  UnaryFunction m_f;     // exposition only
};

要求

UnaryFunction 必须可赋值且可拷贝构造.

概念

function_output_iterator 是可写与可递增迭代器概念的模型.

操作 

explicit function_output_iterator(const UnaryFunction& f = UnaryFunction());

效果: 构造一个 function_output_iterator 实例, 其 m_f 由 f 构造.

unspecified_type operator*();

返回: 一个未指定类型的对象 r, 使得 r = t 等价于 m_f(t) 对所有 t 成立.

function_output_iterator& operator++();

返回: *this.

function_output_iterator& operator++(int);

返回: *this.
