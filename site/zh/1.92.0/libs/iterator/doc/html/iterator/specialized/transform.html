变换迭代器

变换迭代器通过修改 operator* 来适配迭代器, 使其对解引用迭代器的结果应用一个函数对象并返回结果.

示例

这是一个使用 transform_iterators 类生成迭代器的简单示例, 这些迭代器把解引用迭代器返回的值乘以 (或加上) 一个数. 若在这个示例中使用 lambda 库会更酷.

int x[] = { 1, 2, 3, 4, 5, 6, 7, 8 };
const int N = sizeof(x)/sizeof(int);

typedef boost::binder1st< std::multiplies<int> > Function;
typedef boost::transform_iterator<Function, int*> doubling_iterator;

doubling_iterator i(x, boost::bind1st(std::multiplies<int>(), 2)),
  i_end(x + N, boost::bind1st(std::multiplies<int>(), 2));

std::cout << "multiplying the array by 2:" << std::endl;
while (i != i_end)
  std::cout << *i++ << " ";
std::cout << std::endl;

std::cout << "adding 4 to each element in the array:" << std::endl;
std::copy(boost::make_transform_iterator(x, boost::bind1st(std::plus<int>(), 4)),
  boost::make_transform_iterator(x + N, boost::bind1st(std::plus<int>(), 4)),
  std::ostream_iterator<int>(std::cout, " "));
std::cout << std::endl;

输出为:

multiplying the array by 2:
2 4 6 8 10 12 14 16
adding 4 to each element in the array:
5 6 7 8 9 10 11 12

参考

概要 

template <class UnaryFunction,
          class Iterator,
          class Reference = use_default,
          class Value = use_default>
class transform_iterator
{
public:
  typedef /* see below */ value_type;
  typedef /* see below */ reference;
  typedef /* see below */ pointer;
  typedef iterator_traits<Iterator>::difference_type difference_type;
  typedef /* see below */ iterator_category;

  transform_iterator();
  transform_iterator(Iterator const& x, UnaryFunction f);

  template<class F2, class I2, class R2, class V2>
  transform_iterator(
        transform_iterator<F2, I2, R2, V2> const& t
      , typename enable_if_convertible<I2, Iterator>::type* = 0      // exposition only
      , typename enable_if_convertible<F2, UnaryFunction>::type* = 0 // exposition only
  );
  UnaryFunction functor() const;
  Iterator const& base() const;
  reference operator*() const;
  transform_iterator& operator++();
  transform_iterator& operator--();
private:
  Iterator m_iterator; // exposition only
  UnaryFunction m_f;   // exposition only
};

若 Reference 为 use_default, 则 reference (transform_iterator 的成员) 为
result_of<const UnaryFunction(iterator_traits<Iterator>::reference)>::type. 否则 reference 为 Reference.

若 Value 为 use_default, 则 value_type 成员为 remove_cv<remove_reference<reference> >::type. 否则 value_type 为 Value.

若 Iterator 模型化可读左值迭代器, 且 Iterator 模型化随机访问遍历迭代器, 则 iterator_category 可转换为 random_access_iterator_tag. 否则, 若 Iterator 模型化双向遍历迭代器, 则 iterator_category 可转换为 bidirectional_iterator_tag. 否则 iterator_category 可转换为 forward_iterator_tag. 若 Iterator 不模型化可读左值迭代器, 则 iterator_category 可转换为 input_iterator_tag.

要求

类型 type UnaryFunction 必须可赋值、可拷贝构造 类型的 const 对象, 且表达式 f(*i) 必须有效, 其中 f 是 UnaryFunction, i 是 Iterator 类型的对象, 且 f(*i) 的类型必须是 result_of<const UnaryFunction(iterator_traits<Iterator>::reference)>::type.

实参 Iterator 应模型化可读迭代器.

概念

所得的 transform_iterator 模型化以下各项中最精化的、且同时被 Iterator 模型化的概念.

  • 若 transform_iterator::reference 是非常量引用, 则为可写左值迭代器.
  • 若 transform_iterator::reference 是常量引用, 则为可读左值迭代器.
  • 否则为可读迭代器.

transform_iterator 模型化 Iterator 实参所建模的最精化的标准遍历概念.

若 transform_iterator 是可读左值迭代器的模型, 则根据 Iterator 实参所模型化的概念, 它模型化以下原有迭代器概念.

若 transform_iterator 模型化可写左值迭代器, 则它是一个可变迭代器 (如旧迭代器要求中所定义).

transform_iterator<F1, X, R1, V1> 可互操作, transform_iterator<F2, Y, R2, V2> 当且仅当 X 可互操作, Y.

操作

除 概念 (即 transform_iterator 所建模者) 要求的操作之外, transform_iterator 还提供以下操作:

transform_iterator();

返回: 一个 transform_iterator 实例, 其 m_f 与 m_iterator 均为默认构造.

transform_iterator(Iterator const& x, UnaryFunction f);

返回: 一个 transform_iterator 实例, 其 m_f 初始化为 f, m_iterator 初始化为 x.

template<class F2, class I2, class R2, class V2>
transform_iterator(
      transform_iterator<F2, I2, R2, V2> const& t
    , typename enable_if_convertible<I2, Iterator>::type* = 0      // exposition only
    , typename enable_if_convertible<F2, UnaryFunction>::type* = 0 // exposition only
);

返回: 一个 transform_iterator 实例, 其 m_f 初始化为 t.functor(), m_iterator 初始化为 t.base().
要求: OtherIterator 可隐式转换为 Iterator.

UnaryFunction functor() const;

返回: m_f 

Iterator const& base() const;

返回: m_iterator 

reference operator*() const;

返回: m_f(*m_iterator) 

transform_iterator& operator++();

效果: ++m_iterator
返回: *this 

transform_iterator& operator--();

效果: --m_iterator
返回: *this
