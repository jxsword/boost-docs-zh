共享容器迭代器

共享容器迭代器类型
共享容器迭代器对象生成器
共享容器迭代器范围生成器

定义于头文件 boost/iterator/shared_container_iterator.hpp.

共享容器迭代器的目的是把容器的生存期与其迭代器的生存期绑定在一起. 换言之, 在其所有迭代器都被销毁之前, 容器不会被删除. 共享容器迭代器通常用于实现这样的函数: 返回一个对象范围上的迭代器, 而这些对象只需在迭代器的生存期内存在. 通过从函数返回一对共享迭代器, 被调方可以返回一个堆分配的对象范围, 其生存期被自动管理.

共享容器迭代器在一个共享容器之上的迭代器上进行了增强. 它维护共享容器的引用计数. 若只有共享容器迭代器持有对容器的引用, 则当最后一个共享容器迭代器被销毁时, 容器的生存期将结束. 无论如何, 共享容器保证在所有迭代器的生存期之后仍然存在. 在其他所有方面, 共享容器迭代器的行为与其基迭代器相同.

概要 

namespace boost {
namespace iterators {
  template <typename Container>
  class shared_container_iterator;

  template <typename Container>
  shared_container_iterator<Container>
  make_shared_container_iterator(typename Container::iterator base,
    std::shared_ptr<Container> const& container);

  std::pair<
    typename shared_container_iterator<Container>,
    typename shared_container_iterator<Container>
  >
  make_shared_container_range(std::shared_ptr<Container> const& container);

  // Backward compatibility with boost::shared_ptr
  template <typename Container>
  shared_container_iterator<Container>
  make_shared_container_iterator(typename Container::iterator base,
    boost::shared_ptr<Container> const& container);

  std::pair<
    typename shared_container_iterator<Container>,
    typename shared_container_iterator<Container>
  >
  make_shared_container_range(boost::shared_ptr<Container> const& container);
}
}
注释

shared_container_iterator 及其工厂函数对持有容器共享引用的智能指针同时支持 std::shared_ptr 与 boost::shared_ptr. 然而, 对 boost::shared_ptr 的支持需要付出把它封装进内部 std::shared_ptr 的代价. 这意味着当从 boost::shared_ptr 构造迭代器时, 该构造必须为 std::shared_ptr 共享状态分配内存, 而这可能失败. 建议直接使用 std::shared_ptr.

共享容器迭代器类型 

template <typename Container> class shared_container_iterator;

类模板 shared_container_iterator 是共享容器迭代器类型. Container 模板类型实参必须模型化 Container 概念.

示例

以下示例演示如何创建一个调节引用计数 std::vector 生存期的迭代器. 尽管原共享指针 ints 在 set_range() 返回后不复存在, shared_counter_iterator 对象仍维持对底层 vector 的引用, 从而延长容器的生存期.

shared_iterator_example1.cpp: 

#include <boost/iterator/shared_container_iterator.hpp>
#include <algorithm>
#include <iostream>
#include <vector>
#include <memory>

using iterator = boost::iterators::shared_container_iterator< std::vector<int> >;


void set_range(iterator& i, iterator& end) {
  std::shared_ptr< std::vector<int> > ints(new std::vector<int>());

  ints->push_back(0);
  ints->push_back(1);
  ints->push_back(2);
  ints->push_back(3);
  ints->push_back(4);
  ints->push_back(5);

  i = iterator(ints->begin(), ints);
  end = iterator(ints->end(), ints);
}


int main() {
  iterator i, end;

  set_range(i, end);

  std::copy(i, end, std::ostream_iterator<int>(std::cout, ","));
  std::cout.put('\n');

  return 0;
}

这一部分的输出是:

0,1,2,3,4,5,

说明

容器

我们希望遍历的容器的类型. 它必须是 Container 概念的模型.

概念

shared_container_iterator 类型模型化与基迭代器 (Container::iterator) 相同的迭代器概念.

操作

shared_container_iterator 类型实现 Random Access Iterator 概念所要求的成员函数与运算符, 但只有为基迭代器定义的操作才有效. 此外它还有以下构造函数:

shared_container_iterator(Container::iterator const& it,
                          std::shared_ptr<Container> const& container)

// Backward compatibility with boost::shared_ptr
shared_container_iterator(Container::iterator const& it,
                          boost::shared_ptr<Container> const& container)

共享容器迭代器对象生成器 

template <typename Container>
shared_container_iterator<Container>

// Backward compatibility with boost::shared_ptr
template <typename Container>
shared_container_iterator<Container>
make_shared_container_iterator(Container::iterator base,
                               boost::shared_ptr<Container> const& container)

该函数提供直接构造 shared_container_iterator 之外的另一种方式. 使用对象生成器, 可以创建 shared_container_iterator 并传递给函数, 而无需显式指定其类型.

示例

本示例与前一个类似, 使用 make_shared_container_iterator() 来创建迭代器.

shared_iterator_example2.cpp: 

#include <boost/iterator/shared_container_iterator.hpp>
#include <algorithm>
#include <iterator>
#include <iostream>
#include <vector>
#include <memory>


template <typename Iterator>
void print_range_nl(Iterator begin, Iterator end) {
  using val = typename std::iterator_traits<Iterator>::value_type;
  std::copy(begin, end, std::ostream_iterator<val>(std::cout, ","));
  std::cout.put('\n');
}

int main() {
  using ints_t = std::shared_ptr< std::vector<int> >;
  {
    ints_t ints(new std::vector<int>());

    ints->push_back(0);
    ints->push_back(1);
    ints->push_back(2);
    ints->push_back(3);
    ints->push_back(4);
    ints->push_back(5);

    print_range_nl(boost::iterators::make_shared_container_iterator(ints->begin(), ints),
                   boost::iterators::make_shared_container_iterator(ints->end(), ints));
  }

  return 0;
}

注意 shared_container_iterator 类型从未被显式命名. 本示例的输出与前一个相同.

共享容器迭代器范围生成器 

template <typename Container>
std::pair<
  shared_container_iterator<Container>,
  shared_container_iterator<Container>
>
make_shared_container_range(std::shared_ptr<Container> const& container);

// Backward compatibility with boost::shared_ptr
template <typename Container>
std::pair<
  shared_container_iterator<Container>,
  shared_container_iterator<Container>
>
make_shared_container_range(boost::shared_ptr<Container> const& container);

类 shared_container_iterator 的主要用途是, 使用迭代器返回一个我们能保证只要迭代器存活就存活的值范围. 这是一个恰好实现该目的的便捷函数. 其在功能上等价于:

std::make_pair(make_shared_container_iterator(container->begin(), container),
               make_shared_container_iterator(container->end(), container));

示例

在以下示例中, 一个值范围以一对 shared_container_iterator 对象的形式返回.

shared_iterator_example3.cpp: 

#include <boost/iterator/shared_container_iterator.hpp>
#include <algorithm>     // for std::copy
#include <iostream>
#include <vector>
#include <memory>
#include <tuple>         // for std::tie


using iterator = boost::iterators::shared_container_iterator< std::vector<int> >;

std::pair<iterator, iterator>
return_range() {
  std::shared_ptr< std::vector<int> > range(new std::vector<int>());
  range->push_back(0);
  range->push_back(1);
  range->push_back(2);
  range->push_back(3);
  range->push_back(4);
  range->push_back(5);
  return boost::iterators::make_shared_container_range(range);
}

int main() {
  iterator i,end;
  std::tie(i, end) = return_range();

  std::copy(i, end, std::ostream_iterator<int>(std::cout, ","));
  std::cout.put('\n');

  return 0;
}

尽管范围对象只在 return_range 调用期间存活, 引用计数的 std::vector 将存活到 i 与 end 都被销毁为止. 本示例的输出与前两个示例相同.
