摘要:

如何使用 std::copy() 用零到一百的数字填充一个 vector? 内建整数类型唯一缺少的迭代器操作是一个返回整数当前值的 operator*(). 计数迭代器适配器把这一关键功能添加到它所包装的任何类型上. 计数迭代器适配器不仅可用于整数类型, 还可用于任何可递增类型.

counting_iterator 通过添加一个返回对象当前值的 operator* 来适配一个对象. 所有其他迭代器操作都被转发给被适配的对象.

counting_iterator 概要

template <
    class Incrementable
  , class CategoryOrTraversal = use_default
  , class Difference = use_default
>
class counting_iterator
{
public:
    typedef Incrementable value_type;
    typedef const Incrementable& reference;
    typedef const Incrementable* pointer;
    typedef /* see below */ difference_type;
    typedef /* see below */ iterator_category;

    counting_iterator();
    counting_iterator(counting_iterator const& rhs);
    explicit counting_iterator(Incrementable x);
    Incrementable const& base() const;
    reference operator*() const;
    counting_iterator& operator++();
    counting_iterator& operator--();
private:
    Incrementable m_inc; // exposition
};

若 Difference 实参为 use_default, 则 difference_type 是某个未指明的有符号整数类型. 否则 difference_type 为 Difference.

iterator_category 按照以下算法确定:

if (CategoryOrTraversal is not use_default)
    return CategoryOrTraversal
else if (numeric_limits<Incrementable>::is_specialized)
    return iterator-category(
        random_access_traversal_tag, Incrementable, const Incrementable&)
else
    return iterator-category(
         iterator_traversal<Incrementable>::type,
         Incrementable, const Incrementable&)
[注意: 鼓励实现者提供
operator- 与一个 difference_type 实现, 以在 std::numeric_limits<Incrementable>::is_specialized 为 true 的情况下避免溢出.]

counting_iterator 要求

Incrementable 实参必须可拷贝构造且可赋值.

若 iterator_category 可转换为 forward_iterator_tag 或 forward_traversal_tag, 则以下内容必须是良构的:

Incrementable i, j;
++i;         // pre-increment
i == j;      // operator equal

若 iterator_category 可转换为 bidirectional_iterator_tag 或 bidirectional_traversal_tag, 则以下表达式还必须是良构的:

--i

若 iterator_category 可转换为 random_access_iterator_tag 或 random_access_traversal_tag, 则以下内容还必须有效:

counting_iterator::difference_type n;
i += n;
n = i - j;
i < j;

counting_iterator 模型化的概念

counting_iterator 的特化模型化可读左值迭代器 (Readable Lvalue Iterator). 此外, 它们还模型化与其 iterator_category 可转换到的迭代器标签相对应的概念. 另外, 若 CategoryOrTraversal 不是 use_default, 则 counting_iterator 模型化与迭代器标签 CategoryOrTraversal 相对应的概念. 否则, 若 numeric_limits<Incrementable>::is_specialized 成立, 则 counting_iterator 模型化随机访问遍历迭代器. 再否则, counting_iterator 模型化与 Incrementable 所建模的相同的迭代器遍历概念.

counting_iterator<X,C1,D1> 与 counting_iterator<Y,C2,D2> 可互操作, 当且仅当 X 与 Y 可互操作.

counting_iterator 操作

除 counting_iterator 所建模概念要求的操作之外, counting_iterator 还提供以下操作.

counting_iterator();

要求:Incrementable 可默认构造.
效果:默认构造成员 m_inc.

counting_iterator(counting_iterator const& rhs);

效果:从 rhs.m_inc 构造成员 m_inc.

explicit counting_iterator(Incrementable x);

效果:从 x 构造成员 m_inc.

reference operator*() const;

返回:m_inc

counting_iterator& operator++();

效果:++m_inc
返回:*this

counting_iterator& operator--();

效果:--m_inc
返回:*this

Incrementable const& base() const;

返回:m_inc 
template <class Incrementable>
counting_iterator<Incrementable> make_counting_iterator(Incrementable x);
返回:一个 counting_iterator<Incrementable> 实例, 其 current 由 x 构造.

示例

本示例用一个数组填充数字, 并用第二个数组存储指向第一个数组的指针, 两项任务都使用 counting_iterator. 最后使用 indirect_iterator 借助通过第二个数组的间接引用打印出第一个数组中的数字.

int N = 7;
std::vector<int> numbers;
typedef std::vector<int>::iterator n_iter;
std::copy(boost::counting_iterator<int>(0),
         boost::counting_iterator<int>(N),
         std::back_inserter(numbers));

std::vector<std::vector<int>::iterator> pointers;
std::copy(boost::make_counting_iterator(numbers.begin()),
          boost::make_counting_iterator(numbers.end()),
          std::back_inserter(pointers));

std::cout << "indirectly printing out the numbers from 0 to "
          << N << std::endl;
std::copy(boost::make_indirect_iterator(pointers.begin()),
          boost::make_indirect_iterator(pointers.end()),
          std::ostream_iterator<int>(std::cout, " "));
std::cout << std::endl;

输出为:

indirectly printing out the numbers from 0 to 7
0 1 2 3 4 5 6
