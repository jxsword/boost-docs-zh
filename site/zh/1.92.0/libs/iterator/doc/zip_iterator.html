摘要: zip 迭代器提供同时并行遍历多个受控序列的能力. zip 迭代器由一个迭代器元组构造. 移动 zip 迭代器会并行移动元组中的所有迭代器. 解引用 zip 迭代器会返回一个元组, 其中包含解引用各个迭代器的结果.

zip_iterator 概要

template<typename IteratorTuple>
class zip_iterator
{

public:
  typedef /* see below */ reference;
  typedef reference value_type;
  typedef value_type* pointer;
  typedef /* see below */ difference_type;
  typedef /* see below */ iterator_category;

  zip_iterator();
  zip_iterator(IteratorTuple iterator_tuple);

  template<typename OtherIteratorTuple>
  zip_iterator(
        const zip_iterator<OtherIteratorTuple>& other
      , typename enable_if_convertible<
              OtherIteratorTuple
            , IteratorTuple>::type* = 0     // exposition only
  );

  const IteratorTuple& get_iterator_tuple() const;

private:
  IteratorTuple m_iterator_tuple;     // exposition only
};

template<typename IteratorTuple>
zip_iterator<IteratorTuple>
make_zip_iterator(IteratorTuple t);

reference 成员 (属于 zip_iterator) 是由 IteratorTuple 实参中各迭代器类型的引用类型组成的元组的类型.

difference_type 成员 (属于 zip_iterator) 是 difference_type, 取自 IteratorTuple 实参中的第一个迭代器类型.

iterator_category 成员 (属于 zip_iterator) 可转换为 IteratorTuple 实参中各迭代器类型的遍历类别中的最小者. 例如, 若 zip_iterator 只持有 vector 迭代器, 则 iterator_category 可转换为 boost::random_access_traversal_tag. 若加入一个 list 迭代器, 则 iterator_category 将可转换为 boost::bidirectional_traversal_tag, 但不再可转换为 boost::random_access_traversal_tag.

zip_iterator 要求

实参 IteratorTuple 中的所有迭代器类型都应模型化可读迭代器.

zip_iterator 模型化的概念

所得的 zip_iterator 模型化可读迭代器.

zip_iterator 只模型化可读迭代器这一事实, 并不妨碍你修改各个迭代器所指向的值. zip_iterator 的 operator* 返回的元组是由各个迭代器的引用类型 (而非其值类型) 构造的元组. 例如, 若 zip_it 是一个 zip_iterator, 其第一个成员迭代器是 std::vector<double>::iterator, 则以下一行将修改 zip_it 的第一个成员迭代器当前指向的值:

zip_it->get<0>() = 42.0;

考虑通过取 IteratorTuple 实参中各个迭代器类型所建模的最精化标准遍历概念而得到的标准遍历概念集合. zip_iterator 模型化该集合中最不精化的标准遍历概念.

zip_iterator<IteratorTuple1> 与 zip_iterator<IteratorTuple2> 可互操作, 当且仅当 IteratorTuple1 与 IteratorTuple2 可互操作.

zip_iterator 操作

除 zip_iterator 所建模概念要求的操作之外, zip_iterator 还提供以下操作.

zip_iterator();

返回:一个 zip_iterator 实例, 其 m_iterator_tuple 为默认构造.

zip_iterator(IteratorTuple iterator_tuple);

返回:一个 zip_iterator 实例, 其 m_iterator_tuple 初始化为 iterator_tuple.

    , typename enable_if_convertible<
            OtherIteratorTuple
          , IteratorTuple>::type* = 0     // exposition only
);
返回:一个 zip_iterator 实例, 它是 other 的拷贝.
要求:OtherIteratorTuple 可隐式转换为 IteratorTuple.

返回:m_iterator_tuple

reference operator*() const;

返回:一个元组, 由解引用 m_iterator_tuple 中所有迭代器的结果组成.

zip_iterator& operator++();

效果:递增 m_iterator_tuple 中的每个迭代器.
返回:*this

zip_iterator& operator--();

效果:递减 m_iterator_tuple 中的每个迭代器.
返回:*this

示例

zip_iterator 主要有两类应用. 第一类关乎运行期效率: 若有若干长度相同的受控序列必须以某种方式处理, 例如用 for_each 算法, 那么只执行一次并行遍历要比分别执行多次遍历更高效. 举例来说, 假设 vect_of_doubles 与 vect_of_ints 是两个长度相等的 vector, 分别包含 double 与 int, 考虑以下两次遍历:

std::vector<double>::const_iterator beg1 = vect_of_doubles.begin();
std::vector<double>::const_iterator end1 = vect_of_doubles.end();
std::vector<int>::const_iterator beg2 = vect_of_ints.begin();
std::vector<int>::const_iterator end2 = vect_of_ints.end();

std::for_each(beg1, end1, func_0());
std::for_each(beg2, end2, func_1());

现在这两次遍历可以如下替换为单次遍历:

std::for_each(
  boost::make_zip_iterator(
    boost::make_tuple(beg1, beg2)
    ),
  boost::make_zip_iterator(
    boost::make_tuple(end1, end2)
    ),
  zip_func()
  );

zip_func 的非泛型实现可能如下:

struct zip_func :
  public std::unary_function<const boost::tuple<const double&, const int&>&, void>
{
  void operator()(const boost::tuple<const double&, const int&>& t) const
  {
    m_f0(t.get<0>());
    m_f1(t.get<1>());
  }

private:
  func_0 m_f0;
  func_1 m_f1;
};

zip_iterator 的第二个重要应用是作为构建组合迭代器的构件. 组合迭代器是一个并行遍历若干受控序列、并在解引用时返回对相应位置上的序列值应用某个仿函数所得结果的迭代器. 这现在可以通过把 zip_iterator 与 transform_iterator 结合使用来实现.

举例来说, 假设你有两个 double 的 vector, 比如说 vect_1 与 vect_2, 而你需要向客户暴露一个受控序列, 其中包含 vect_1 与 vect_2 元素的乘积. 与其把这些乘积放入第三个 vector, 不如使用一个即时计算乘积的组合迭代器. 假设 tuple_multiplies 是一个类似 std::multiplies 工作的仿函数, 只是它的两个实参打包在一个元组中. 那么下面定义的两个迭代器 it_begin 与 it_end 界定了一个受控序列, 其中包含 vect_1 与 vect_2 元素的乘积:

typedef boost::tuple<
  std::vector<double>::const_iterator,
  std::vector<double>::const_iterator
  > the_iterator_tuple;

typedef boost::zip_iterator<
  the_iterator_tuple
  > the_zip_iterator;

typedef boost::transform_iterator<
  tuple_multiplies<double>,
  the_zip_iterator
  > the_transform_iterator;

the_transform_iterator it_begin(
  the_zip_iterator(
    the_iterator_tuple(
      vect_1.begin(),
      vect_2.begin()
      )
    ),
  tuple_multiplies<double>()
  );

the_transform_iterator it_end(
  the_zip_iterator(
    the_iterator_tuple(
      vect_1.end(),
      vect_2.end()
      )
    ),
  tuple_multiplies<double>()
  );
