概述

本库使用户自定义类型 (枚举、结构体和类) 的作者能够描述其枚举项、基类、数据成员和成员函数. 这些信息之后可由其他代码段 (可能由另一位作者编写) 通过提供的原语 describe_enumerators、describe_bases 和 describe_members 进行查询.

要了解如何描述枚举类型, 参见 描述枚举类型.

要了解如何描述类类型 (包括结构体), 参见 描述类类型.

有关此功能用处的示例, 参见 用法示例.

本库的目的是建立一种提供这些反射能力的标准方式. 许多现有库都有各自描述枚举或类的方式, 但在没有标准的情况下, 不同人编写的代码无法互操作.

人们或许希望这些原语最终能进入 C++ 标准, 由编译器自动提供描述类型所需的元数据, 从而无需再手动使用宏进行标注.

修订历史

Boost 1.91.0 中的变更

  • 在 C++20 下, 当外围类尚不完整时, 已描述的嵌套枚举现在也能工作. (感谢 Julien Blanc.)

  • 将 enum_to_string 改为 constexpr. (感谢 Julien Blanc.)

Boost 1.84.0 中的变更

  • 增加了接受字符串视图的 enum_from_string 重载, 以避免需要以空字符结尾.

Boost 1.81.0 中的变更

  • 为了允许包含 enumerators.hpp、bases.hpp 和 members.hpp (在使用选项 -pedantic 的情形下), BOOST_DESCRIBE_ENUM 的调用已从 modifiers.hpp 移至单独的头文件 modifier_description.hpp. 因此, modifiers.hpp 不再包含 enum.hpp. 一直依赖这种隐式包含的代码可能会失败, 需要修正为包含 enum.hpp.

Boost 1.79.0 中的变更

  • 在 BOOST_DESCRIBE_STRUCT 中启用了联合体支持, 并更新了示例以检查 std::is_union<T>.

  • 增加了定义 fmtlib 类格式化器的示例.

  • 增加了定义 fmtlib 枚举格式化器的示例.

  • 增加了打印成员指针的示例.

Boost 1.78.0 中的变更

  • 添加了 has_describe_enumerators、has_describe_bases、has_describe_members.

  • 新增了 enum_to_string 和 enum_from_string.

  • 新增了关系运算符和流插入运算符.

  • 新增了 descriptor_by_name 和 descriptor_by_pointer.

  • 新增了 struct_to_tuple 示例.

描述枚举类型

如果你有一个枚举类型

enum E
{
    v1 = 1,
    v2 = 2,
    v3 = 4,
};

可以通过 BOOST_DESCRIBE_ENUM 宏为其添加反射元数据:

BOOST_DESCRIBE_ENUM(E, v1, v2, v3)

该宏定义于 <boost/describe/enum.hpp>, 且应放在与枚举相同的命名空间中.

如果你的枚举项没有初始化器, 可以不重复它们

enum E2 { a, b, c, d };
BOOST_DESCRIBE_ENUM(E2, a, b, c, d)

而可以使用便利宏

BOOST_DEFINE_ENUM(E2, a, b, c, d)

它会展开为前面两行.

若要定义 enum class E2, 请改用 BOOST_DEFINE_ENUM_CLASS. 若要添加底层类型 (即 enum E3: int 或 enum class E4: unsigned char), 请分别使用 BOOST_DEFINE_FIXED_ENUM 和 BOOST_DEFINE_FIXED_ENUM_CLASS.

如果你的枚举类型嵌套在类或 struct 内部, 请将 BOOST_DESCRIBE_NESTED_ENUM 宏放在 enum 的旁边, 如下所示:

class X
{
private:

    enum class E
    {
        v1,
        v2
    };

    BOOST_DESCRIBE_NESTED_ENUM(E, v1, v2)

public:

    // ...
};

一旦枚举类型 E 完成标注, 就可以使用 describe_enumerators<E> 来获得一个描述符列表. (describe_enumerators 定义在 boost::describe 命名空间中, 位于 <boost/describe/enumerators.hpp> 内.)

描述符列表是一个形如 L<D1, D2, …​, Dn> 的类型, 其中 L 形如 template<class…​ T> struct L {};, 而 Di 形如

struct Di
{
    static constexpr E value;
    static constexpr char const* name;
};

要遍历描述符列表, 可以使用 mp_for_each (来自 Mp11):

boost::mp11::mp_for_each< boost::describe::describe_enumerators<E> >([](auto D){

    std::printf( "%s: %d\n", D.name, D.value );

});

描述类类型

具有公有成员的类类型

如果你有一个 struct

struct X
{
    int m1;
    int m2;
};

使用 BOOST_DESCRIBE_STRUCT 宏来描述它:

BOOST_DESCRIBE_STRUCT(X, (), (m1, m2))

BOOST_DESCRIBE_STRUCT 定义于 <boost/describe/class.hpp>, 且应放在与 struct 相同的命名空间中.

它接受三个参数: struct 的名称、基类列表 (在我们的示例中为空) 以及按名称给出的 (公有) 成员列表 (其中包括数据成员和成员函数.)

由于 BOOST_DESCRIBE_STRUCT 放置在类型之外, 它是非侵入式的, 不需要访问类型的定义, 因此可用于描述第三方类型或定义在系统头文件中的类型.

具有受保护或私有成员的类类型

要描述类类型, 请改用 BOOST_DESCRIBE_CLASS 宏, 并将其放置在类的内部. 这使宏能够访问受保护和私有成员, 但这是侵入式的, 且需要访问类型的定义.

class Y: private X
{
public:

    int m3;

protected:

    int m4;

private:

    int m5;

public:

    int f() const;

private:

    BOOST_DESCRIBE_CLASS(Y, (X), (m3, f), (m4), (m5))
};

它接受三个成员列表, 分别对应公有、受保护和私有成员.

获取类属性

一旦类型 T 完成标注, 其属性即可通过 describe_bases<T, M> 和 describe_members<T, M> 获取 (M 是修饰符的位掩码, 例如 mod_public | mod_static | mod_function).

这些原语定义在命名空间 boost::describe 中, 分别位于头文件 <boost/describe/bases.hpp> 和 <boost/describe/members.hpp> 内.

describe_bases 接受以下可能的修饰符: mod_public、mod_protected、mod_private, 或它们的按位或组合. mod_public 存在时, 结果中会包含公有基类; 不存在时则排除公有基类. 另外两个修饰符的工作方式类似.

describe_members 接受以下可能修饰符的按位或组合: mod_public、mod_protected、mod_private、mod_static、mod_function、mod_any_member、mod_inherited、mod_hidden.

访问修饰符的工作方式与 describe_bases 相同.

(对于用 BOOST_DESCRIBE_STRUCT 标注的类型, 受保护和私有成员列表将为空.)

当 mod_static 存在时, 返回静态成员; 否则返回非静态成员.

当 mod_function 存在时, 返回成员函数; 否则返回数据成员.

当 mod_any_member 存在时, mod_static 和 mod_function 会被忽略, 不论种类如何都会返回所有成员.

当 mod_inherited 存在时, 基类的成员也会被返回.

当 mod_hidden 存在时, 被隐藏的继承成员也会包含在内. 当派生类拥有同名成员时, 基类的成员即被隐藏.

对于上面的类 Y, describe_bases<Y, mod_any_access> 将返回一个类型列表 L<D1>, 其中包含单个基类描述符 D1, 该描述符描述 X:

struct D1
{
    using type = X;
    static constexpr unsigned modifiers = mod_private;
};

describe_members<Y, mod_private> 将返回一个类型列表 L<D2>, 其中包含数据成员 Y::m5 的描述符:

struct D2
{
    static constexpr int Y::* pointer = &Y::m5;
    static constexpr char const * name = "m5";
    static constexpr unsigned modifiers = mod_private;
};

有关如何使用基类和数据成员描述符的示例, 参见 定义一个通用打印函数.

有关如何使用成员函数描述符的示例, 参见 自动 JSON RPC.

重载的成员函数

要描述重载的成员函数, 需要借助更复杂的语法, 因为仅列出其名称 (比如 f) 会使库尝试用 &X::f 构造成员指针, 这会失败, 因为无法确定该表达式指的是哪个 f.

为消除歧义, 可在函数名之前加上用括号括起的函数类型, 如下例所示:

struct X
{
    int f();
    int f() const;
    void f( int x );
};

BOOST_DESCRIBE_STRUCT(X, (), (
    (int ()) f,
    (int () const) f,
    (void (int)) f
))

函数类型与其声明相同, 只是不带名称.

务必保留括号中的函数类型与其名称之间的空格, 因为省略它虽然能在 GCC 和 Clang 上顺利编译, 但在 MSVC 上会因其中非标准的预处理器而产生难以理解的错误.

请注意括号的正确位置, 因为括号放错同样会导致编译错误难以解读, 而且在所有编译器上都是如此.

同样的技巧也适用于 BOOST_DESCRIBE_CLASS 以及静态成员函数:

class Y
{
public:

    static void f( int x );
    static void f( int x, int y );

    BOOST_DESCRIBE_CLASS(Y, (), ((void (int)) f, (void (int, int)) f), (), ())
};

成员函数与静态成员函数同名且函数类型相同的情形目前不受支持.

Usage Examples

用编译期循环打印枚举项

一个简单示例, 仅使用 mp11::mp_for_each 遍历枚举项描述符并将其打印出来.

#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <cstdio>

enum E
{
    v1 = 11,
    v2,
    v3 = 5
};

BOOST_DESCRIBE_ENUM(E, v1, v2, v3)

int main()
{
    boost::mp11::mp_for_each< boost::describe::describe_enumerators<E> >([](auto D){

        std::printf( "%s: %d\n", D.name, D.value );

    });
}

输出示例:

v1: 11
v2: 12
v3: 5

用运行期循环打印枚举项

这与前面的示例类似, 但它先用这些值构建一个 std::array, 然后使用普通的 for 循环而非 mp_for_each 对其进行遍历.

#include <boost/describe.hpp>
#include <cstdio>
#include <array>

template<class E> struct enum_descriptor
{
    E value;
    char const * name;
};

template<class E, template<class... T> class L, class... T>
  constexpr std::array<enum_descriptor<E>, sizeof...(T)>
    describe_enumerators_as_array_impl( L<T...> )
{
    return { { { T::value, T::name }... } };
}

template<class E> constexpr auto describe_enumerators_as_array()
{
    return describe_enumerators_as_array_impl<E>( boost::describe::describe_enumerators<E>() );
}

BOOST_DEFINE_ENUM(E, v1, v2, v3, v4, v5, v6)

int main()
{
    constexpr auto D = describe_enumerators_as_array<E>();

    for( auto const& x: D )
    {
        std::printf( "%s: %d\n", x.name, x.value );
    }
}

输出示例:

v1: 0
v2: 1
v3: 2
v4: 3
v5: 4
v6: 5

enum_to_string

本示例展示了一个函数, 给定一个枚举项值时返回其名称. 如果该值不对应任何具名值, 函数将返回 "(unnamed)".

#include <boost/describe.hpp>
#include <boost/mp11.hpp>

template<class E> char const * enum_to_string( E e )
{
    char const * r = "(unnamed)";

    boost::mp11::mp_for_each< boost::describe::describe_enumerators<E> >([&](auto D){

        if( e == D.value ) r = D.name;

    });

    return r;
}

#include <iostream>

enum E
{
    v1 = 3,
    v2,
    v3 = 11
};

BOOST_DESCRIBE_ENUM(E, v1, v2, v3)

int main()
{
    std::cout << "E(" << v1 << "): " << enum_to_string( v1 ) << std::endl;
    std::cout << "E(" << 0 << "): " << enum_to_string( E(0) ) << std::endl;
}

输出示例:

E(3): v1
E(0): (unnamed)

自 1.78.0 版本起, 本库提供 enum_to_string. 它与示例中的函数的区别在于多出一个第二参数, 该参数决定当值不对应具名枚举项时应返回什么.

string_to_enum

与前一示例相反; 给定枚举项名称时返回枚举项值. 当传入的字符串不对应任何枚举项名称时, 抛出异常.

#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <stdexcept>
#include <typeinfo>
#include <string>
#include <cstring>

[[noreturn]] void throw_invalid_name( char const * name, char const * type )
{
    throw std::runtime_error(
        std::string( "Invalid enumerator name '" ) + name
        + "' for enum type '" + type + "'" );
}

template<class E> E string_to_enum( char const * name )
{
    bool found = false;
    E r = {};

    boost::mp11::mp_for_each< boost::describe::describe_enumerators<E> >([&](auto D){

        if( !found && std::strcmp( D.name, name ) == 0 )
        {
            found = true;
            r = D.value;
        }

    });

    if( found )
    {
        return r;
    }
    else
    {
        throw_invalid_name( name, typeid( E ).name() );
    }
}

#include <iostream>

BOOST_DEFINE_ENUM(E, v1, v2, v3)

int main()
{
    try
    {
        std::cout << "v1: " << string_to_enum<E>( "v1" ) << std::endl;
        std::cout << "v2: " << string_to_enum<E>( "v2" ) << std::endl;
        std::cout << "v3: " << string_to_enum<E>( "v3" ) << std::endl;
        std::cout << "v4: " << string_to_enum<E>( "v4" ) << std::endl;
    }
    catch( std::exception const & x )
    {
        std::cout << x.what() << std::endl;
    }
}

输出示例:

v1: 0
v2: 1
v3: 2
v4: Invalid enumerator name 'v4' for enum type 'enum E'

自 1.78.0 版本起, 本库提供 enum_from_string. 它与示例中函数的区别在于用 bool 返回值来指示失败, 而不是使用异常. 枚举项值会被赋给输出参数.

定义一个通用打印函数

本示例定义了一个通用的 operator<<, 它适用于任何已用 BOOST_DESCRIBE_STRUCT 或 BOOST_DESCRIBE_CLASS 描述过的类或结构体类型.

它首先递归地打印基类, 然后打印所有成员.

(此处使用 C 风格强制转换来访问私有基类. 这并不像乍看之下那样糟糕, 因为我们只是通过打印其成员来查看基类, 这样做不应改变其状态, 因此也不会违反其不变式.)

#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <ostream>

using namespace boost::describe;

template<class T,
    class Bd = describe_bases<T, mod_any_access>,
    class Md = describe_members<T, mod_any_access>,
    class En = std::enable_if_t<!std::is_union<T>::value> >
    std::ostream& operator<<( std::ostream & os, T const & t )
{
    os << "{";

    bool first = true;

    boost::mp11::mp_for_each<Bd>([&](auto D){

        if( !first ) { os << ", "; } first = false;

        using B = typename decltype(D)::type;
        os << (B const&)t;

    });

    boost::mp11::mp_for_each<Md>([&](auto D){

        if( !first ) { os << ", "; } first = false;

        os << "." << D.name << " = " << t.*D.pointer;

    });

    os << "}";
    return os;
}

struct X
{
    int m1 = 1;
};

BOOST_DESCRIBE_STRUCT(X, (), (m1))

struct Y
{
    int m2 = 2;
};

BOOST_DESCRIBE_STRUCT(Y, (), (m2))

class Z: public X, private Y
{
    int m1 = 3;
    int m2 = 4;

    BOOST_DESCRIBE_CLASS(Z, (X, Y), (), (), (m1, m2))
};

#include <iostream>

int main()
{
    std::cout << Z() << std::endl;
}

输出示例:

{{.m1 = 1}, {.m2 = 2}, .m1 = 3, .m2 = 4}

自 1.78.0 版本起, 库本身提供了这个通用的 operator<<, 位于 boost::describe::operators 命名空间中. 可以通过在包含被描述应用程序类型的命名空间中添加一条 using 声明来启用它, 如下例所示:

namespace app
{

struct X
{
    int a = 1;
};

BOOST_DESCRIBE_STRUCT(X, (), (a))

using boost::describe::operators::operator<<;

}

实现 hash_value

本示例定义了一个通用 hash_value 重载, 用于计算已标注结构体或类的哈希值. 它通过遍历已描述的基类和成员并对每一项调用 boost::hash_combine 来实现.

该重载定义在命名空间 app 中, 以便同样适用于定义在 app 中的所有已标注类.

注释
 自 1.81.0 版本起, Boost.ContainerHash 通过提供一个与下文所示非常相似的 boost::hash_value 重载, 为被描述的类提供了自身的内建支持. 因此, 使用 Boost 1.81.0 或更高版本时, 不再需要下面的 hash_value 函数, 否则会造成歧义. 
#include <boost/container_hash/hash.hpp>
#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <boost/variant2/variant.hpp>
#include <boost/version.hpp>
#include <vector>

using namespace boost::describe;

namespace app
{

#if BOOST_VERSION < 108100

template<class T,
    class Bd = describe_bases<T, mod_any_access>,
    class Md = describe_members<T, mod_any_access>,
    class En = std::enable_if_t<!std::is_union<T>::value> >
    std::size_t hash_value( T const & t )
{
    std::size_t r = 0;

    boost::mp11::mp_for_each<Bd>([&](auto D){

        using B = typename decltype(D)::type;
        boost::hash_combine( r, (B const&)t );

    });

    boost::mp11::mp_for_each<Md>([&](auto D){

        boost::hash_combine( r, t.*D.pointer );

    });

    return r;
}

#endif

struct A
{
    int x = 1;
};

BOOST_DESCRIBE_STRUCT(A, (), (x))

struct B
{
    int y = 2;
};

BOOST_DESCRIBE_STRUCT(B, (), (y))

struct C
{
    std::vector<boost::variant2::variant<A, B>> v;
};

BOOST_DESCRIBE_STRUCT(C, (), (v))

} // namespace app

#include <iostream>

int main()
{
    app::C c;

    c.v.push_back( app::A{} );
    c.v.push_back( app::B{} );

    std::cout << boost::hash<app::C>()( c ) << std::endl;
}

输出示例:

12526671134390370097

实现 operator==

本示例定义了一个通用 operator== 重载, 它遍历已描述的基类和成员, 并使用 == 对它们进行相等比较.

该重载定义在命名空间 app 中, 以便同样适用于定义在 app 中的所有已标注类.

#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <boost/variant2/variant.hpp>
#include <vector>

using namespace boost::describe;

namespace app
{
template<class T,
    class Bd = describe_bases<T, mod_any_access>,
    class Md = describe_members<T, mod_any_access>,
    class En = std::enable_if_t<!std::is_union<T>::value> >
    bool operator==( T const& t1, T const& t2 )
{
    bool r = true;

    boost::mp11::mp_for_each<Bd>([&](auto D){

        using B = typename decltype(D)::type;
        r = r && (B const&)t1 == (B const&)t2;

    });

    boost::mp11::mp_for_each<Md>([&](auto D){

        r = r && t1.*D.pointer == t2.*D.pointer;

    });

    return r;
}

struct A
{
    int x = 1;
};

BOOST_DESCRIBE_STRUCT(A, (), (x))

struct B
{
    int y = 2;
};

BOOST_DESCRIBE_STRUCT(B, (), (y))

struct C
{
    std::vector<boost::variant2::variant<A, B>> v;
};

BOOST_DESCRIBE_STRUCT(C, (), (v))

} // namespace app

#include <iostream>

int main()
{
    app::C c1, c2, c3;

    c1.v.push_back( app::A{} );
    c2.v.push_back( app::A{} );
    c3.v.push_back( app::B{} );

    std::cout << std::boolalpha
        << ( c1 == c2 ) << ' '
        << ( c1 == c3 ) << std::endl;
}

输出示例:

true false

自 1.78.0 版本起, 库本身提供了这个通用的 operator==, 位于 boost::describe::operators 命名空间中. 可以通过在包含被描述应用程序类型的命名空间中添加一条 using 声明来启用它, 如下例所示:

namespace app
{

struct X
{
    int a = 1;
};

BOOST_DESCRIBE_STRUCT(X, (), (a))

using boost::describe::operators::operator==;

}

自动转换为 JSON

本示例定义了一个通用 tag_invoke 重载, 它自动把已标注的结构体转换为 Boost.JSON 值, 具体做法是遍历已描述的公有成员并把它们添加到返回的 boost::json::object 中.

该重载定义在命名空间 app 中, 以便同样适用于定义在 app 中的所有已标注类.

私有成员的存在被视为通用转换不适用的一种标志, 因此在这种情况下会使用 std::enable_if_t 禁用该重载.

注释
 自 1.81.0 版本起, Boost.JSON 为被描述的类提供了自身的内建支持. 因此, 使用 Boost 1.81.0 或更高版本时, 不再需要下面的 tag_invoke 函数. 
#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <boost/json.hpp>
#include <boost/version.hpp>
#include <type_traits>
#include <vector>
#include <map>

namespace app
{

#if BOOST_VERSION < 108100

template<class T,
    class D1 = boost::describe::describe_members<T,
        boost::describe::mod_public | boost::describe::mod_protected>,
    class D2 = boost::describe::describe_members<T, boost::describe::mod_private>,
    class En = std::enable_if_t<boost::mp11::mp_empty<D2>::value && !std::is_union<T>::value> >

    void tag_invoke( boost::json::value_from_tag const&, boost::json::value& v, T const & t )
{
    auto& obj = v.emplace_object();

    boost::mp11::mp_for_each<D1>([&](auto D){

        obj[ D.name ] = boost::json::value_from( t.*D.pointer );

    });
}

#endif

    int x;
    int y;

BOOST_DESCRIBE_STRUCT(A, (), (x, y))

自动序列化

本示例定义了一个通用 serialize 函数, 可自动为已标注的类添加 Boost.Serialization 支持.

#define _CRT_SECURE_NO_WARNINGS

#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <boost/serialization/serialization.hpp>
#include <boost/serialization/base_object.hpp>
#include <boost/serialization/vector.hpp>
#include <boost/core/nvp.hpp>
#include <type_traits>
#include <cstdio>
#include <vector>

namespace app
{

template<class Archive, class T,
    class D1 = boost::describe::describe_bases<T, boost::describe::mod_public>,
    class D2 = boost::describe::describe_bases<T,
        boost::describe::mod_protected | boost::describe::mod_private>,
    class D3 = boost::describe::describe_members<T,
        boost::describe::mod_public | boost::describe::mod_protected>,
    class D4 = boost::describe::describe_members<T, boost::describe::mod_private>,
    class En = std::enable_if_t< boost::mp11::mp_empty<D2>::value &&
        boost::mp11::mp_empty<D4>::value && !std::is_union<T>::value> >

    void serialize( Archive & ar, T & t, boost::serialization::version_type )
{
    int k = 0;

    // public bases: use base_object

    boost::mp11::mp_for_each<D1>([&](auto D){

        using B = typename decltype(D)::type;

        char name[ 32 ];
        std::sprintf( name, "base.%d", ++k );

        ar & boost::make_nvp( name, boost::serialization::base_object<B>( t ) );

    });

    // public (and protected) members

    boost::mp11::mp_for_each<D3>([&](auto D){

        ar & boost::make_nvp( D.name, t.*D.pointer );

    });
}

{
    int x;
};

BOOST_DESCRIBE_STRUCT(A1, (), (x))

{
    int y;
};

BOOST_DESCRIBE_STRUCT(A2, (), (y))

    B(): A1(), A2() {}
    B( int x, int y ): A1{ x }, A2{ y } {}
};

BOOST_DESCRIBE_STRUCT(B, (A1, A2), ())

struct C
{

};

BOOST_DESCRIBE_STRUCT(C, (), (v))

} // namespace app

自动 JSON RPC

本示例定义了一个通用的 call 函数, 可用于按名称调用成员函数, 参数通过 Boost.JSON 数组传入. 结果通过 boost::json::value 返回.

#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <boost/json.hpp>
#include <boost/type_traits.hpp>
#include <boost/utility/string_view.hpp>
#include <stdexcept>
#include <string>

template<class C1, class C2, class R, class... A, std::size_t... I>
  boost::json::value
    call_impl_( C1 & c1, R (C2::*pmf)(A...), boost::json::array const & args,
      std::index_sequence<I...> )
{
    return boost::json::value_from(
      (c1.*pmf)(
        boost::json::value_to< boost::remove_cv_ref_t<A> >( args[ I ] )... ) );
}

template<class C1, class C2, class R, class... A>
  boost::json::value
    call_impl( C1 & c1, R (C2::*pmf)(A...), boost::json::array const & args )
{
    if( args.size() != sizeof...(A) )
    {
        throw std::invalid_argument( "Invalid number of arguments" );
    }

    return call_impl_( c1, pmf, args, std::index_sequence_for<A...>() );
}

template<class C>
  boost::json::value
    call( C & c, boost::string_view method, boost::json::array const & args )
{
    using Fd = boost::describe::describe_members<C,
        boost::describe::mod_public | boost::describe::mod_function>;

    bool found = false;
    boost::json::value result;

    boost::mp11::mp_for_each<Fd>([&](auto D){

        if( !found && method == D.name)
        {
            result = call_impl( c, D.pointer, args );
            found = true;
        }

    });

    if( !found )
    {
        throw std::invalid_argument( "Invalid method name" );
    }

    return result;
}

struct Object
{
    std::string greet( std::string const & who )
    {
        return "Hello, " + who + "!";
    }

    int add( int x, int y )
    {
        return x + y;
    }
};

BOOST_DESCRIBE_STRUCT(Object, (), (greet, add))

#include <iostream>

int main()
{
    Object obj;
    std::cout << call( obj, "greet", { "world" } ) << std::endl;
    std::cout << call( obj, "add", { 1, 2 } ) << std::endl;
}

本示例实现了一个交互式控制台, 允许打印和修改变量. 它使用 Boost.JSON 在变量的字符串形式之间进行双向转换.

// get variable

template<class Scope> boost::json::value get( Scope& scope, boost::string_view name )
{
    using Md = boost::describe::describe_members<Scope, boost::describe::mod_public>;

    bool found = false;
    boost::json::value result;

    boost::mp11::mp_for_each<Md>([&](auto D) {

        if( !found && name == D.name )
        {
            result = boost::json::value_from( scope.*D.pointer );
            found = true;
        }

    });

    if( !found )
    {
        throw std::invalid_argument(
            std::string( "'" ) + std::string( name ) + "': no such variable" );
    }

    return result;
}

fmtlib 类格式化器

本示例定义了一个通用的 fmtlib 格式化器, 它适用于任何已用 BOOST_DESCRIBE_STRUCT 或 BOOST_DESCRIBE_CLASS 描述过的类或结构体类型. 它类似于上文展示的通用打印函数.

#include <boost/describe.hpp>
#include <boost/mp11.hpp>
#include <fmt/format.h>
#include <type_traits>

template<class T> struct fmt::formatter<T, char, std::enable_if_t<
    boost::describe::has_describe_bases<T>::value &&
    boost::describe::has_describe_members<T>::value &&
    !std::is_union<T>::value>>
{
    constexpr auto parse( format_parse_context& ctx )
    {
        auto it = ctx.begin(), end = ctx.end();

        if( it != end && *it != '}' )
        {
            throw_format_error( "invalid format" );
        }

        return it;
    }

    auto format( T const& t, format_context& ctx ) const
    {
        using namespace boost::describe;

        using Bd = describe_bases<T, mod_any_access>;
        using Md = describe_members<T, mod_any_access>;

        auto out = ctx.out();

        *out++ = '{';

        bool first = true;

        boost::mp11::mp_for_each<Bd>([&](auto D){

            if( !first )
            {
                *out++ = ',';
            }

            first = false;

            out = fmt::format_to( out, " {}",
                (typename decltype(D)::type const&)t );
        });

        boost::mp11::mp_for_each<Md>([&](auto D){

            if( !first )
            {
                *out++ = ',';
            }

            first = false;

            out = fmt::format_to( out, " .{}={}",
                D.name, t.*D.pointer );
        });

        if( !first )
        {
            *out++ = ' ';
        }

        *out++ = '}';

        return out;
    }
};

fmtlib 枚举格式化器

本示例为被描述的枚举定义了一个 fmtlib 格式化器.

#include <boost/describe.hpp>
#include <fmt/format.h>
#include <type_traits>

template<class T> struct fmt::formatter<T, char, std::enable_if_t<
    boost::describe::has_describe_enumerators<T>::value>>
{
private:

    using U = std::underlying_type_t<T>;

    fmt::formatter<fmt::string_view, char> sf_;
    fmt::formatter<U, char> nf_;

public:

    constexpr auto parse( format_parse_context& ctx )
    {
        auto i1 = sf_.parse( ctx );
        auto i2 = nf_.parse( ctx );

        if( i1 != i2 )
        {
            throw_format_error( "invalid format" );
        }

        return i1;
    }

    auto format( T const& t, format_context& ctx ) const
    {
        char const * s = boost::describe::enum_to_string( t, 0 );

        if( s )
        {
            return sf_.format( s, ctx );
        }
        else
        {
            return nf_.format( static_cast<U>( t ), ctx );
        }
    }
};

enum E1
{
    v1, v2, v3 = 11
};

BOOST_DESCRIBE_ENUM( E1, v1, v2, v3 )

int main()
{
    fmt::print( "{:_^10}\n", E1::v1 );
    fmt::print( "{:_^10}\n", (E1)7 );
}

char const* get_member_name( T C::* pm, int )
{
    char const * name = nullptr;

    boost::mp11::mp_for_each<L>([&](auto D){

        if( equals( D.pointer, pm, 0 ) ) name = D.name;

    });

    return name;
}

template<class T, class C>
char const* get_member_name( T C::* /*pm*/, long )
{
    return nullptr;
}

} // namespace detail

template<class T, class C>
std::string pm_to_string( T C::* pm )
{
    char const * name = ::detail::get_member_name( pm, 0 );

    if( name == nullptr ) name = "(unknown)";

    return "&" + boost::core::type_name<C>() + "::" + name
        + " [" + boost::core::type_name<T>() + "]";
}

template<class T, class C>
std::ostream& operator<<( std::ostream& os, T C::* pm )
{
    os << pm_to_string( pm );
    return os;
}

{

实现特性

依赖

Boost.Mp11.

受支持的编译器

  • GCC 5 或更高版本, 且 -std=c++14 或以上

  • Clang 3.9 或更高版本, 且 -std=c++14 或以上

  • Visual Studio 2015 或更高版本

已在 Github Actions 和 Appveyor 上完成测试.

局限

此实现有如下限制:

  • 枚举项、基类和成员列表最多支持 52 个元素.

  • 当被描述的类是 final 时, 受保护基类无法与私有基类区分, 会被视为私有.

  • 不支持位域. 无法为位域构造成员指针.

  • 不支持引用成员. 无法为引用构造成员指针.

  • 不支持匿名联合体.

其中 vi 是传给宏的相应标识符.

其中 vi 是第 i 个枚举项.

<boost/describe/class.hpp>

#define BOOST_DESCRIBE_STRUCT(Name, Bases, Members) /*...*/
#define BOOST_DESCRIBE_CLASS(Name, Bases, Public, Protected, Private) /*...*/

BOOST_DESCRIBE_STRUCT

BOOST_DESCRIBE_STRUCT 应放置在被描述结构体类型所在的同一命名空间中, 它接受三个参数: 结构体类型的名称、用括号括起的基类列表, 以及用括号括起的公有成员列表.

示例:

struct X
{
};

BOOST_DESCRIBE_STRUCT(X, (), ())

struct Y: public X
{
    int m;
    static void f();
};

BOOST_DESCRIBE_STRUCT(Y, (X), (m, f))

BOOST_DESCRIBE_CLASS

BOOST_DESCRIBE_CLASS 应放置在被描述类型的类定义内部, 它接受五个参数: 类的名称、基类列表、公有成员列表、受保护成员列表和私有成员列表.

示例:

class X
{
    int m1;

    BOOST_DESCRIBE_CLASS(X, (), (), (), (m1))
};

class Y: private X
{
public:

    int m1;
    void f() const {}

protected:

    int m2;

private:

    int m3;

    BOOST_DESCRIBE_CLASS(Y, (X), (m1, f), (m2), (m3))
};

<boost/describe/modifiers.hpp>

namespace boost
{
namespace describe
{

enum modifiers
{
    mod_public = 1,
    mod_protected = 2,
    mod_private = 4,
    mod_virtual = 8,
    mod_static = 16,
    mod_function = 32,
    mod_any_member = 64,
    mod_inherited = 128,
    mod_hidden = 256
};

constexpr modifiers mod_any_access = static_cast<modifiers>( mod_public | mod_protected | mod_private );

} // namespace describe
} // namespace boost

modifiers

枚举类型 modifiers 是一个位掩码类型, 包含以下标志:

  • mod_public - 在描述符列表中包含公有基类或成员

  • mod_protected - 包含受保护基类或成员

  • mod_private - 包含私有基类或成员

  • mod_virtual - 当基类是虚基类时返回

  • mod_static - 返回静态成员 (未给出时返回非静态成员)

  • mod_function - 返回成员函数 (未给出时返回数据成员)

  • mod_any_member - 覆盖 mod_static 和 mod_function, 不论种类如何都返回所有成员

  • mod_inherited - 包含基类的成员

  • mod_hidden - 包含被隐藏的继承成员

<boost/describe/​modifier_description.hpp>

头文件 modifier_description.hpp 包含 modifiers.hpp, 并调用 BOOST_DESCRIBE_ENUM (作用于 modifiers), 使 describe_enumerators<modifiers> 得以工作.

<boost/describe/bases.hpp>

namespace boost {
namespace describe {

template<class T, unsigned M> using describe_bases = /*...*/;

template<class T> using has_describe_bases = /*...*/;

} }

describe_bases<T, M>

M 必须是 mod_public、mod_protected 和 mod_private 的按位或组合, 并充当过滤器.

describe_bases<T, M> 返回 L<D1, D2, …​, Dn>, 其中 L 是一个形如下式的类模板

template<class...> struct L {};

而 Di 是一个形如下式的基类描述符 

struct Di
{
    using type = /*...*/;
    static constexpr unsigned modifiers = /*...*/;
};

其中 type 是基类的类型, modifiers 则是 mod_public、mod_protected、mod_private 和 mod_virtual 的按位或组合, 反映该基类的属性.

如果 T 不是被描述的类类型, describe_bases<T, M> 会导致替换失败.

has_describe_bases<T>

has_describe_bases<T>::value 为 true (当 T 是被描述的类类型时), 否则为 false.

由于本库不提供分别描述基类和成员的方式, has_describe_bases 和 has_describe_members 实际上是同义词. 将它们分开提供只是为了保持一致性.

<boost/describe/members.hpp>

namespace boost {
namespace describe {

template<class T, unsigned M> using describe_members = /*...*/;

template<class T> using has_describe_members = /*...*/;

} }

describe_members<T, M>

M 必须是 mod_public、mod_protected、mod_private、mod_static、mod_function、mod_any_member、mod_inherited 和 mod_hidden 的按位或组合, 并充当过滤器.

describe_members<T, M> 返回 L<D1, D2, …​, Dn>, 其中 L 是一个形如下式的类模板

template<class...> struct L {};

而 Di 是一个形如下式的成员描述符 

struct Di
{
    static constexpr auto pointer = &T::m;
    static constexpr char const * name = "m";
    static constexpr unsigned modifiers = /*...*/;
};

其中 pointer 是标识类成员的成员指针 (对于非静态成员) 或指针 (对于静态成员), name 是成员的名称, modifiers 则是 mod_public、mod_protected、mod_private、mod_static、mod_function、mod_inherited 和 mod_hidden 的按位或组合, 反映该成员的属性.

如果 T 不是被描述的类类型, describe_members<T, M> 会导致替换失败.

has_describe_members<T>

has_describe_members<T>::value 为 true (当 T 是被描述的类类型时), 否则为 false.

由于本库不提供分别描述基类和成员的方式, has_describe_bases 和 has_describe_members 实际上是同义词. 将它们分开提供只是为了保持一致性.

enum_to_string

函数 enum_to_string 返回枚举项 e 的名称. E 必须是被描述的枚举类型. 如果 e 不对应任何一个被描述的值, 函数返回 def.

<boost/describe/​enum_from_string​.hpp>

namespace boost {
namespace describe {

template<class E> bool enum_from_string( char const * name, E & e ) noexcept;
template<class S, class E> bool enum_from_string( S const & name, E & e ) noexcept;

} }

enum_from_string

函数 enum_from_string 向 e 赋予与 name 相对应的枚举项值, 并返回 true. E 必须是被描述的枚举类型. 如果 name 不对应任何一个被描述的值, 函数返回 false.

第二个重载仅在 S 是字符串类类型 (例如 std::string 或 std::string_view) 时才参与重载决议. 字符串类类型通过是否存在嵌套的 value_type 和 traits_type typedef 来识别, 且要求具有一个不抛出的 operator==, 接受 char const* 类型的实参.

template<class T> bool operator>=( T const& t1, T const& t2 );

  std::basic_ostream<Ch, Tr>&
    operator<<( std::basic_ostream<Ch, Tr>& os, T const& t );

} } }

头文件 <boost/describe/operators.hpp> 为被描述的类类型定义了通用运算符. 使用方式是通过 using 声明把它们引入包含被描述类型的命名空间, 如下例所示:

namespace app
{

struct X
{
    int a = 1;
};

BOOST_DESCRIBE_STRUCT(X, (), (a))

using boost::describe::operators::operator==;
using boost::describe::operators::operator!=;
using boost::describe::operators::operator<<;

}

operator==

如果所有基类和成员都相等, 返回 true, 否则返回 false.

operator!=

返回 operator== 的否定结果.

operator<

使用 operator< 按顺序对基类和成员进行字典序比较, 并返回结果.

operator>

返回以相反实参调用 operator< 的结果.

operator<=

返回 operator> 结果的否定.

operator>=

返回 operator< 结果的否定.

operator<<

把 t 的一种表示输出到 os, 具体做法是递归使用 operator<< 先输出所有基类, 再输出所有成员.

<boost/describe/​descriptor_by_name​.hpp>

namespace boost {
namespace describe {

#define BOOST_DESCRIBE_MAKE_NAME(s) /*...*/

BOOST_DESCRIBE_MAKE_NAME

宏 BOOST_DESCRIBE_MAKE_NAME 创建一个标识作为参数给定名称的类型. 其用法如下:

using N = BOOST_DESCRIBE_MAKE_NAME(some_member);

descriptor_by_name

descriptor_by_name<L, N> 在描述符列表 L 中查找名称由 N 标识的成员. N 应当是一个像上例那样由 BOOST_DESCRIBE_MAKE_NAME 创建的类型. L 预期是由 describe_members 返回的列表, 不过由于枚举项描述符也具有 ::name, 因此由 describe_enumerators 返回的列表同样可用.

代码示例 1. 使用 descriptor_by_name
using L = describe_members<SomeType, mod_any_access>;
using N = BOOST_DESCRIBE_MAKE_NAME(some_member);
using D = descriptor_by_name<L, N>; // descriptor for SomeType::some_member

descriptor_by_pointer

descriptor_by_pointer<L, Pm> 在描述符列表 L 中查找成员指针 Pm. L 应当是由 describe_members 返回的列表.
