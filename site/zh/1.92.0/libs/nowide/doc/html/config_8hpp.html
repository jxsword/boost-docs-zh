namespace  boost::nowide
 该命名空间包含标准库函数与类的相应实现, 使它们在 Windows 上接受 UTF-8 字符串. 在其他平台 (即非 Windows 平台) 上, 这些函数与类只是 std 命名空间中对应项的别名, 或行为与之相同.

宏定义文档

◆ BOOST_NOWIDE_USE_FILEBUF_REPLACEMENT

#define BOOST_NOWIDE_USE_FILEBUF_REPLACEMENT   1

定义为 1 时, 使用 <filebuf.hpp> 中在 Windows 上使用的那个类.

  • 在 Windows 上: 无效果, 总是被覆盖为 1
  • 其他平台 (包括 Cygwin): 未设置时默认取 BOOST_NOWIDE_USE_WCHAR_OVERLOADS 的值.

设为 0 时, boost::nowide::basic_filebuf 将是 std::basic_filebuf 的别名.

影响 boost::nowide::basic_filebuf、boost::nowide::basic_ofstream、boost::nowide::basic_ifstream、boost::nowide::basic_fstream

◆ BOOST_NOWIDE_USE_WCHAR_OVERLOADS

#define BOOST_NOWIDE_USE_WCHAR_OVERLOADS   1

是否在 fstream 各类中使用 wchar_t* 重载.

在 Windows 与 Cygwin 上默认启用, 因为后者可能在 filesystem::path 中使用 wchar_t.
