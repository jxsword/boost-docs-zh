template<typename CharType, typename Traits = std::char_traits<CharType>>
class boost::nowide::basic_filebuf< CharType, Traits >

此前向声明定义了 basic_filebuf 类型, 它在设置 BOOST_NOWIDE_USE_FILEBUF_REPLACEMENT 时使用, 例如在 Windows 上.

它只针对 CharType = char 实现并特化, 在标准 C I/O 之上实现 std::filebuf
