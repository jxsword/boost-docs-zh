code_point boost::nowide::utf::utf_traits< CharType, size >::decode ( Iterator & p,
迭代器 e )
static

从范围 [p,e) 读取一个码点并返回它.

  • 如果读取的序列是不完整序列, 则返回 incomplete,
  • 如果检测到非法序列, 则返回 illegal

要求

  • Iterator 是有效的输入迭代器

后置条件

  • p 指向最后消费的字符

把有效的 Unicode 码点 value 转换为 UTF 序列.

要求:

  • value 是有效的码点
  • out 是输出迭代器, 应能接受至少 width(value) 个码元

返回最后一个写入码元之后的迭代器.
