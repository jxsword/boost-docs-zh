Boost.Nowide
变更日志

变更日志

Nowide 11.4.0 (Boost 1.90)

  • 要求至少 Boost 1.66

Nowide 11.3.1 (Boost 1.88)

  • 修复以下宏的重定义: _CRT_SECURE_NO_WARNINGS
  • 使 getenv 线程安全

Nowide 11.3.0 (Boost 1.82)

  • 添加接受字符串的 convert_string 重载
  • 添加 quoted 用于输出 (带引号的) 路径 (std::filesystem 或 boost::filesystem)

Nowide 11.2.0 (Boost 1.80)

  • filebuf: 大幅改进批量 I/O 的性能
  • filebuf: 修复 fflush 失败时 sync 返回值错误的问题
  • filebuf: 修复一个边角情形下可能的未定义行为: 实际上什么都没写入但缓冲区处于 "写" 模式
  • filebuf: 限制字符的放回 (即 pbackfail), 只允许放回已缓冲的字符 (可能只有 1 个字符)
  • 添加缺失的宏定义 NOWIDE_USE_WCHAR_OVERLOADS (仅独立版)

Nowide 11.1.4 (Boost 1.79)

  • 修复以下宏可能的重定义: _LARGEFILE_SOURCE
  • 修复同时定义 BOOST_USE_WINDOWS_H 与 WIN32_LEAN_AND_MEAN 时缺失包含的问题.
  • 修复近期 MinGW-w64 编译器上的编译失败
  • 为传入 (可能为 64 位的) stat 函数的缓冲区大小添加健全性检查
  • 已知问题: 文本文件的读取性能可能比 std 流更差. 二进制文件与写入不受影响.
  • 修复重复使用已关闭的 filebuf 时可能出现的释放后使用

Nowide 11.1.3 (Boost 1.78)

  • 修复发布中缺失配置文件的问题
  • 修复在 filebuf 已分配内部缓冲区之后设置自定义缓冲区 (setbuf) 时可能出现的双重释放
  • 处理一些警告 (主要在 MSVC 上)
  • 已知问题: 文本文件的读取性能已下降. 二进制文件与写入不受影响.

Nowide 11.1.2 (Boost 1.76)

  • 不再定义 __MSVCRT_VERSION__ 版本号, 以修复与 ucrt 的兼容性
  • 已知问题: 文本文件的读取性能已下降. 二进制文件与写入不受影响.

Nowide 11.1.1

  • 修复文本文件流在使用 seek 或 sync 函数且换行符已被转换 (如在 Windows 上) 时丢弃字符的问题
  • 修复重复使用 (经由 open) 已关闭文件流时潜在的释放后使用缺陷
  • 修复使用已移动或交换的文件流时潜在的无效内存访问, 此时源流有放回字符或被设为非缓冲模式
  • 已知问题: 文本文件的读取性能已下降. 二进制文件与写入不受影响.

Nowide 11.1.0

  • 为以下函数添加对 string_view 的支持: narrow 与 widen
  • 添加对以下 UTF 字符类型的支持, 例如 char16_t

Nowide 11.0.0 (Boost 1.74)

  • 要求兼容 C++11 的编译器与标准库
  • LFS: 在底层系统支持时, 添加对 > 2 GB 文件的支持
  • 通用 UTF 转换函数现已在 boost::nowide::utf 命名空间中提供
  • 添加对使用 UTF-8 路径的 stat 的支持

Nowide 10.0.2

  • boost::nowide::cin 现在忽略 CR (\r) 字符, 并把行首的 CTRL+Z 视为 EOF (与 std::cin 行为一致)
  • boost::nowide::cin 支持通过刷新输入与控制台缓冲区来同步

Nowide 10.0.1 (Boost 1.73)

  • 重要: 对 C++03 的支持已弃用, 将在下一个 Boost 发布中移除
  • 修复 trait 中的 -Wctor-dtor-privacy 警告

Nowide 10.0.0

  • Initial Release
