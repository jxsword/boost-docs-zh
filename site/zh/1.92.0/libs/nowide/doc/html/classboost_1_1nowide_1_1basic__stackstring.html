详细说明

template<typename CharOut = wchar_t, typename CharIn = char, size_t BufferSize = 256>
class boost::nowide::basic_stackstring< CharOut, CharIn, BufferSize >

一个可以从宽或窄 UTF 源创建临时宽或窄 UTF 字符串的类.

若字符串足够短则使用栈缓冲区, 否则在堆上分配缓冲区.

无效的 UTF 字符会被替换字符取代, 参见 BOOST_NOWIDE_REPLACEMENT_CHARACTER

若传给构造函数或 convert 方法的指针为 NULL, 则 c_str 将返回 NULL. 同样, 默认构造的 stackstring 在调用 c_str 时也返回 NULL.
