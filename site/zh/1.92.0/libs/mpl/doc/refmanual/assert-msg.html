BOOST_MPL_ASSERT_MSG

概要

#define BOOST_MPL_ASSERT_MSG( condition, message, types ) \
    unspecified token sequence \
/**/

说明

当条件不成立时, 生成一条带有内嵌自定义消息的编译错误.

Header

#include <boost/mpl/assert.hpp>

Parameters

参数 要求 说明
condition 一个整型常量表达式 要断言的条件.
message 一个合法的标识符记号 以合法 C++ 标识符记号形式给出的自定义消息.
types 一个合法的函数参数列表 要在错误消息中显示的类型列表, 括在括号内.

表达式语义

对任意整型常量表达式 expr、合法的 C++ 标识符 message 以及任意类型 t1, t2,... tn:

BOOST_MPL_ASSERT_MSG( expr, message, (t1, t2,... tn) );
Return type:

无.
Precondition:

t1, t2,... tn 均非 void.
语义:

若 expr != true 则生成编译错误, 否则无任何效果.

在编译器诊断能力允许的情况下, 错误消息将包含 message 标识符和括在括号内的 t1, t2,... tn 类型列表, 并具有如下一般形式:

... ************( ...::message )************)(t1, t2,... tn) ...

BOOST_MPL_ASSERT_MSG( expr, message, (types<t1, t2,... tn>) );
Return type:

无.
Precondition:

无.
语义:

若 expr != true 则生成编译错误, 否则无任何效果.

在编译器诊断能力允许的情况下, 错误消息将包含 message 标识符和 t1, t2,... tn 类型列表, 并具有如下一般形式:

... ************( ...::message )************)(types<t1, t2,... tn>) ...

示例 

template< typename T > struct my
{
    // ...
    BOOST_MPL_ASSERT_MSG(
          is_integral<T>::value
        , NON_INTEGRAL_TYPES_ARE_NOT_ALLOWED
        , (T)
        );
};

my<void*> test;

// In instantiation of `my<void*>':
//   instantiated from here
// conversion from `
//   mpl_::failed************(my<void*>::
//   NON_INTEGRAL_TYPES_ARE_NOT_ALLOWED::************)(void*)
//   ' to non-scalar type `mpl_::assert<false>' requested
