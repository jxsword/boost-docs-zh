replace_if

概要

template<
      typename Sequence
    , typename Pred
    , typename NewType
    , typename In = unspecified
    >
struct replace_if
{
    typedef unspecified type;
};

说明

返回原序列的一个副本, 其中每个满足谓词 Pred 的类型都被替换为 NewType.

[注释: 此表述适用于算法的无插入器版本. 有关该算法在所有情形下的精确规范, 参见 表达式语义 小节 — 注毕]

Header

#include <boost/mpl/replace_if.hpp>

模型

可逆算法

Parameters

参数 要求 说明
Sequence Forward Sequence 原始序列.
Pred 一元 lambda 表达式 替换条件.
NewType Any type 用来替换的类型.
In 插入器 一个插入器.

表达式语义

表达式的语义仅在不同于 可逆算法 或其中未作定义之处给出定义.

对任意 前向序列 s、一元 lambda 表达式 pred、插入器 in 以及任意类型 x:

typedef replace_if<s,pred,x,in>::type r;
Return type:

一个类型.
语义:

等价于

typedef lambda<pred>::type p;
typedef transform< s, if_< apply_wrap1<p,_1>,x,_1>, in >::type r;

复杂度

线性. 恰好执行 size<s>::value 次 pred 应用, 至多 size<s>::value 次插入.

示例 

typedef vector_c<int,1,4,5,2,7,5,3,5> numbers;
typedef vector_c<int,1,4,0,2,0,0,3,0> expected;
typedef replace_if< numbers, greater<_,int_<4> >, int_<0> >::type result;

BOOST_MPL_ASSERT(( equal< result,expected, equal_to<_,_> > ));
