iterator_range

概要

template<
      typename First
    , typename Last
    >
struct iterator_range
{
    // unspecified
    // ...
};

说明

一个视图, 观察由一对迭代器所标识的序列元素子集.

Header

#include <boost/mpl/fold.hpp>

模型

  • 前向、双向或 随机访问序列, 视底层迭代器的类别而定.

Parameters

参数 要求 说明
First, Last Forward Iterator 标识视图边界的迭代器.

表达式语义

The semantics of an expression are defined only where they differ from, or are not defined in Forward Sequence.

在下表中, v 是 iterator_range 的一个实例, first 和 last 是指向某个 前向序列 的迭代器, 且 [first, last) 构成有效区间.

表达式 语义 
iterator_range<first,last>
iterator_range<first,last>::type
一个惰性序列, 包含区间 [first, last) 中的所有元素.

示例 

typedef range_c<int,0,100> r;
typedef advance_c< begin<r>::type,10 >::type first;
typedef advance_c< end<r>::type,-10 >::type last;

BOOST_MPL_ASSERT(( equal<
      iterator_range<first,last>
    , range_c<int,10,90>
    > ));
