value_type

概要

template<
      typename Sequence
    , typename X
    >
struct value_type
{
    typedef unspecified type;
};

说明

返回 值, 即元素 X 在 Sequence 中将采用的值.

Header

#include <boost/mpl/value_type.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence Associative Sequence 要查询的序列.
X Any type 要获取其 值 的类型.

表达式语义

对任意 关联序列 s 与任意类型 x:

typedef value_type<s,x>::type v;
Return type:

一个类型.
Precondition:

x 可以放入 s.
语义:

v 是 值, 即 x 在 s 中将采用的值.
Postcondition:

If .. parsed-literal:

has_key< s,key_type<s,x>::type >::type

then .. parsed-literal:

at< s,key_type<s,x>::type >::type

与 value_type<s,x>::type 相同.

复杂度

摊还常量时间.

示例 

typedef value_type< map<>,pair<int,unsigned> >::type v1;
typedef value_type< set<>,pair<int,unsigned> >::type v2;

BOOST_MPL_ASSERT(( is_same< v1,unsigned > ));
BOOST_MPL_ASSERT(( is_same< v2,pair<int,unsigned> > ));

参见

关联序列, key_type, at, set, map
