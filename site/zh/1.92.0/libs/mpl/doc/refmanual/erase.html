erase

概要

template<
      typename Sequence
    , typename First
    , typename Last = unspecified
    >
struct erase
{
    typedef unspecified type;
};

说明

erase 执行一次移除操作, 移除序列中从任意位置开始的一个或多个相邻元素.

Header

#include <boost/mpl/erase.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence 可扩展序列 或 可扩展关联序列 要从中擦除的序列.
First Forward Iterator 指向要擦除区间起始位置的迭代器.
Last Forward Iterator 要擦除区间尾后位置的迭代器.

表达式语义

对任意 可扩展序列 s, 以及指向 s 的迭代器 pos、first 和 last:

typedef erase<s,first,last>::type r;
Return type:

可扩展序列.
Precondition:

[first,last) 是 s 中的一个有效区间.
语义:

r 是一个新的 概念等同 于 s 的序列, 由以下元素组成: [begin<s>::type, pos), [last, end<s>::type).
Postcondition:

r 中元素的相对顺序与 s 中相同;

size<r>::value == size<s>::value - distance<first,last>::value

typedef erase<s,pos>::type r;
Return type:

可扩展序列.
Precondition:

pos 是 s 中可解引用的迭代器.
语义:

等价于

typedef erase< s,pos,next<pos>::type >::type r;

对任意 可扩展关联序列 s 以及指向 s 的迭代器 pos:

typedef erase<s,pos>::type r;
Return type:可扩展序列.
Precondition:pos 是指向 s 的可解引用迭代器.
语义:擦除特定位置 pos 处的元素; 等价于 erase_key<s, deref<pos>::type >::type.
Postcondition:size<r>::value == size<s>::value - 1.

复杂度

序列原型 复杂度 (区间形式)
可扩展关联序列 摊还常量时间.
可扩展序列 最坏情况下为二次, 最好情况下为线性.

示例 

typedef vector_c<int,1,0,5,1,7,5,0,5> values;
typedef find< values, integral_c<int,7> >::type pos;
typedef erase<values,pos>::type result;

BOOST_MPL_ASSERT_RELATION( size<result>::value, ==, 7 );

typedef find<result, integral_c<int,7> >::type iter;
BOOST_MPL_ASSERT(( is_same< iter, end<result>::type > ));

参见

可扩展序列, 可扩展关联序列, erase_key, pop_front, pop_back, insert
