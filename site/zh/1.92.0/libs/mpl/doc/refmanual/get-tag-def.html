BOOST_MPL_GET_TAG_DEF

概要

#define BOOST_MPL_GET_TAG_DEF(name) \
    unspecified token sequence \
/**/

说明

展开为惰性 getter 元函数 get_tag_name 的定义, 使得对任意类型 x, get_tag_name<x>::type is type, 其中 name 是 x 的一个嵌套类型成员.

Header

#include <boost/mpl/get_tag.hpp>

Parameters

参数 要求 说明
name 一个合法的标识符记号 要获取的成员的名称.

表达式语义

对任意合法的 C++ 标识符 name:

BOOST_MPL_GET_TAG_DEF(name)
Precondition:

出现在命名空间作用域.
Return type:

无.
语义:

等价于

namespace boost { namespace mpl {
template<class T>
struct get_##name {
	typedef typename T::name type;
};
}}

示例 

struct test_type_get_tag_def;

BOOST_MPL_GET_TAG_DEF(a_tag);

namespace boost { namespace mpl {

struct test_type_get_tag_def
{
	typedef int a_tag;
};

}}

typedef boost::mpl::get_a_tag<test_type_get_tag_def>::type   got_the_tag;

参见

宏, BOOST_MPL_HAS_XXX_TRAIT_NAMED_DEF
