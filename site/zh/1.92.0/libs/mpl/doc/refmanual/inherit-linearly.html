inherit_linearly

概要

template<
      typename Types
    , typename Node
    , typename Root = empty_base
    >
struct inherit_linearly
    : fold<Types,Root,Node>
{
};

说明

fold 的便利包装, 用于序列驱动的类组合场景. 按顺序返回将二元 Node 相继应用于上一次 Node 调用的结果(若是首次调用则为 Root)以及 前向序列 Types 中每个类型的结果.

Header

#include <boost/mpl/inherit_linearly.hpp>

模型

Metafunction

Parameters

参数 要求 说明
Types Forward Sequence 要继承的类型.
Node 二元 lambda 表达式 一个派生元函数.
Root 一个类类型 要置于类层次结构根部的类型.

表达式语义

对任意 前向序列 types、二元 lambda 表达式 node 以及任意类类型 root:

typedef inherit_linearly<types,node,root>::type r;
Return type:

一个类类型.
语义:

等价于

typedef fold<types,root,node>::type r;

复杂度

线性. 恰好 size<types>::value 次 node 应用.

示例 

template< typename T > struct tuple_field
{
    T field;
};

template< typename T >
inline
T& field(tuple_field<T>& t)
{
    return t.field;
}

typedef inherit_linearly<
      vector<int,char const*,bool>
    , inherit< _1, tuple_field<_2> >
    >::type tuple;


int main()
{
    tuple t;

    field<int>(t) = -1;
    field<char const*>(t) = "text";
    field<bool>(t) = false;

    std::cout
        << field<int>(t) << 'n'
        << field<char const*>(t) << 'n'
        << field<bool>(t) << 'n'
        ;
}

参见
