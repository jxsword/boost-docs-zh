Placeholders

概要

namespace placeholders {
typedef unspecified _;
typedef arg<1>      _1;
typedef arg<2>      _2;
...
typedef arg<n>      _n;
}

using placeholders::_;
using placeholders::_1;
using placeholders::_2;
...
using placeholders::_n;

说明

形式为 _n 的占位符只是相应 arg<n> 特化的同义词. 无名占位符 _ (下划线) 在 bind 和 lambda 表达式中具有特殊含义, 在这些上下文之外没有定义的语义.

通过 using namespace mpl::placeholders; 指令, 占位符名称可在用户命名空间中可用.

Header

#include <boost/mpl/placeholders.hpp>

[注释: 当使用占位符构造 lambda 表达式 以传给 MPL 自己的算法或元函数时, 可以省略该 include: 任何文档声明接受 lambda 表达式的库组件都会使占位符对用户代码隐式可用 — 注毕]

Parameters

无.

表达式语义

对任意整型常量 n (范围 [1, BOOST_MPL_LIMIT_METAFUNCTION_ARITY] 内) 与任意类型 a1,... an:

typedef apply_wrapn<_n,a1,...an>::type x;
Return type:

一个类型.
语义:

等价于

typedef apply_wrapn< arg<n>,a1,...an >::type x;

示例 

typedef apply_wrap5< _1,bool,char,short,int,long >::type t1;
typedef apply_wrap5< _3,bool,char,short,int,long >::type t3;

BOOST_MPL_ASSERT(( is_same< t1, bool > ));
BOOST_MPL_ASSERT(( is_same< t3, short > ));

参见

组合与实参绑定, arg, lambda, bind, apply, apply_wrap
