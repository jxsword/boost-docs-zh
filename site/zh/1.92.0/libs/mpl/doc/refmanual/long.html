long_

概要

template<
      long N
    >
struct long_
{
    // unspecified
    // ...
};

说明

一个 整型常量 包装器, 针对 long 类型.

Header

#include <boost/mpl/long.hpp>

模型

整型常量

Parameters

参数 要求 说明
N An integral constant 要包装的值.

表达式语义

表达式的语义仅在不同于 整型常量 或其中未作定义之处给出定义.

对任意整型常量 n:

表达式 语义
long_<c> 一个 整型常量 x, 满足 x::value == c 且 x::value_type 与 long 相同.

示例 

typedef long_<8> eight;

BOOST_MPL_ASSERT(( is_same< eight::value_type, long > ));
BOOST_MPL_ASSERT(( is_same< eight::type, eight > ));
BOOST_MPL_ASSERT(( is_same< next< eight >::type, long_<9> > ));
BOOST_MPL_ASSERT(( is_same< prior< eight >::type, long_<7> > ));
BOOST_MPL_ASSERT_RELATION( (eight::value), ==, 8 );
assert( eight() == 8 );
