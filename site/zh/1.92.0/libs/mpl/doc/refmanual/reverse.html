reverse

概要

template<
      typename Sequence
    , typename In = unspecified
    >
struct reverse
{
    typedef unspecified type;
};

说明

返回原序列的一个逆序副本. reverse 是 reverse_copy 的同义词.

[注释: 此表述适用于算法的无插入器版本. 有关该算法在所有情形下的精确规范, 参见 表达式语义 小节 — 注毕]

Header

#include <boost/mpl/reverse.hpp>

Parameters

参数 要求 说明
Sequence Forward Sequence 要逆转的序列.
In 插入器 一个插入器.

表达式语义

对任意 前向序列 s 与 插入器 in:

typedef reverse<s,in>::type r;
Return type:

一个类型.
语义:

等价于

typedef reverse_copy<s,in>::type r;

复杂度

线性复杂度.

示例 

typedef vector_c<int,9,8,7,6,5,4,3,2,1,0> numbers;
typedef reverse< numbers >::type result;

BOOST_MPL_ASSERT(( equal< result, range_c<int,0,10> > ));

参见

变换算法, 可逆算法, reverse_copy, copy, copy_if
