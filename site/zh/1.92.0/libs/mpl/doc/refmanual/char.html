char_

概要

template<
      char N
    >
struct char_
{
    // unspecified
    // ...
};

说明

一个 整型常量 包装器, 针对 char 类型.

Header

#include <boost/mpl/char.hpp>

模型

整型常量

Parameters

参数 要求 说明
N 一个字符常量 要包装的值.

表达式语义

表达式的语义仅在不同于 整型常量 或其中未作定义之处给出定义.

对任意字符常量 c:

表达式 语义
char_<c> 一个 整型常量 x, 满足 x::value == c 且 x::value_type 与 char 相同.

示例 

typedef char_<'c'> c;

BOOST_MPL_ASSERT(( is_same< c::value_type, char > ));
BOOST_MPL_ASSERT(( is_same< c::type, c > ));
BOOST_MPL_ASSERT(( is_same< next< c >::type, char_<'d'> > ));
BOOST_MPL_ASSERT(( is_same< prior< c >::type, char_<'b'> > ));
BOOST_MPL_ASSERT_RELATION( (c::value), ==, 'c' );
assert( c() == 'c' );
