distance

概要

template<
      typename First
    , typename Last
    >
struct distance
{
    typedef unspecified type;
};

说明

返回 First 和 Last 迭代器之间的距离, 即一个 整型常量 n, 使得 advance<First,n>::type 与 Last 相同.

Header

#include <boost/mpl/distance.hpp>

Parameters

参数 要求 说明
First, Last Forward Iterator 要计算其间距离的迭代器.

模型

标签分发元函数

表达式语义

对任意 前向迭代器 first 和 last:

typedef distance<first,last>::type n;
Return type:

整型常量.
Precondition:

[first, last) 是一个有效区间.
语义:

等价于

typedef iter_fold<
      iterator_range<first,last>
    , long_<0>
    , next<_1>
    >::type n;
Postcondition:

is_same< advance<first,n>::type, last >::value == true.

复杂度

若 first 和 last 是 随机访问迭代器 则为摊还常量时间, 否则为线性时间.

示例 

typedef range_c<int,0,10>::type range;
typedef begin<range>::type first;
typedef end<range>::type last;

BOOST_MPL_ASSERT_RELATION( (distance<first,last>::value), ==, 10);

参见

迭代器, 标签分发元函数, advance, next, prior
