reverse_remove

概要

template<
      typename Sequence
    , typename T
    , typename In = unspecified
    >
struct reverse_remove
{
    typedef unspecified type;
};

说明

按逆序返回一个新序列, 包含区间 [begin<Sequence>::type, end<Sequence>::type) 中除与 T 相同的元素之外的所有元素.

[注释: 此表述适用于算法的无插入器版本. 有关该算法在所有情形下的精确规范, 参见 表达式语义 小节 — 注毕]

Header

#include <boost/mpl/remove.hpp>

模型

可逆算法

Parameters

参数 要求 说明
Sequence Forward Sequence 原始序列.
T Any type 要移除的类型.
In 插入器 一个插入器.

表达式语义

表达式的语义仅在不同于 可逆算法 或其中未作定义之处给出定义.

对任意 前向序列 s、插入器 in 以及任意类型 x:

typedef reverse_remove<s,x,in>::type r;
Return type:

一个类型.
语义:

等价于

typedef reverse_remove_if< s,is_same<_,x>,in >::type r;

复杂度

线性. 恰好执行 size<s>::value 次相等比较, 至多 size<s>::value 次插入.

示例 

typedef vector<int,float,char,float,float,double>::type types;
typedef reverse_remove< types,float >::type result;

BOOST_MPL_ASSERT(( equal< result, vector<double,char,int> > ));

参见

变换算法, 可逆算法, remove, reverse_remove_if, reverse_copy, transform, replace
