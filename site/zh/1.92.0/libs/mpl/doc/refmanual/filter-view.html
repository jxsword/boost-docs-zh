filter_view

概要

template<
      typename Sequence
    , typename Pred
    >
struct filter_view
{
    // unspecified
    // ...
};

说明

一个视图, 观察 Sequence 中满足谓词 Pred 的元素子集.

Header

#include <boost/mpl/filter_view.hpp>

模型

  • Forward Sequence

参数

参数 要求 说明
Sequence Forward Sequence 要包装的序列.
Pred 一元 lambda 表达式 过滤谓词.

表达式语义

Semantics of an expression is defined only where it differs from, or is not defined in Forward Sequence.

在下表中, v 是 filter_view 的一个实例, s 是任意 前向序列, pred 是一元 lambda 表达式.

表达式 语义 
filter_view<s,pred>
filter_view<s,pred>::type
一个惰性的 前向序列 序列, 包含区间 [begin<s>::type, end<s>::type) 中满足谓词 pred 的所有元素.
size<v>::type v 的大小; size<v>::value == count_if<s,pred>::value; 线性复杂度; 参见 前向序列.

示例

找出序列中最大的浮点类型.

typedef vector<int,float,long,float,char[50],long double,char> types;
typedef max_element<
      transform_view< filter_view< types,boost::is_float<_> >, size_of<_> >
    >::type iter;

BOOST_MPL_ASSERT(( is_same< deref<iter::base>::type, long double > ));

参见

序列, 视图, transform_view, joint_view, zip_view, iterator_range
