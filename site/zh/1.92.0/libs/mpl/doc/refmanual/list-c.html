list_c

说明

list_c 是 list 的一个 整型序列包装器. 因此, 它共享 list 的全部特性与要求, 仅在原始序列内容的指定方式上有所不同.

Header

序列形式 头文件
变参 #include <boost/mpl/list_c.hpp>
带编号 #include <boost/mpl/list/listn_c.hpp>

模型

  • 整型序列包装器
  • 变参序列
  • Forward Sequence
  • 可扩展序列
  • 头部可扩展序列

表达式语义

表达式的语义仅在不同于 list 或其中未作定义之处给出定义.

表达式 语义 
list_c<T,c1,c2,... cn>
listn_c<T,c1,c2,... cn>
一个 list, 由整型常量包装器 integral_c<T,c1>, integral_c<T,c2>, ... integral_c<T,cn> 组成; 参见 整型序列包装器. 
list_c<T,c1,c2,... cn>::type
listn_c<T,c1,c2,... cn>::type
与 listn< integral_c<T,c1>, integral_c<T,c2>, ... integral_c<T,cn> > 相同; 参见 整型序列包装器. 
list_c<T,c1,c2,... cn>::value_type
listn_c<T,c1,c2,... cn>::value_type
与 T 相同; 参见 整型序列包装器.

示例 

typedef list_c<int,1,2,3,5,7,12,19,31> fibonacci;
typedef push_front<fibonacci,int_<1> >::type fibonacci2;

BOOST_MPL_ASSERT_RELATION( front<fibonacci2>::type::value, ==, 1 );

参见

序列, 整型序列包装器, list, integral_c, vector_c, set_c, range_c
