reverse_transform

概要

template<
      typename Seq
    , typename Op
    , typename In = unspecified
    >
struct reverse_transform
{
    typedef unspecified type;
};

template<
      typename Seq1
    , typename Seq2
    , typename BinaryOp
    , typename In = unspecified
    >
struct reverse_transform
{
    typedef unspecified type;
};

说明

reverse_transform 是一个重载名称:

  • reverse_transform<Seq,Op> 返回原序列的一个逆序、变换后副本, 由把一元变换 Op 应用于区间 [begin<Sequence>::type, end<Sequence>::type) 中每个元素得到.
  • reverse_transform<Seq1,Seq2,Op> 返回一个新序列, 由把二元变换 BinaryOp 应用于元素对 (e1, e21) 得到, 元素对取自对应区间 [begin<Seq1>::type, end<Seq1>::type) 与 [begin<Seq2>::type, end<Seq2>::type), 按逆序进行.

[注释: 此表述适用于算法的无插入器版本. 有关该算法在所有情形下的精确规范, 参见 表达式语义 小节 — 注毕]

Header

#include <boost/mpl/transform.hpp>

模型

可逆算法

Parameters

参数 要求 说明
Sequence, Seq1, Seq2 Forward Sequence 要变换的序列.
Op, BinaryOp lambda 表达式 一个变换.
In 插入器 一个插入器.

表达式语义

表达式的语义仅在不同于 可逆算法 或其中未作定义之处给出定义.

对任意 前向序列 s、s1 和 s2、lambda 表达式 op 和 op2 以及 插入器 in:

typedef reverse_transform<s,op,in>::type r;
Return type:

一个类型.
Postcondition:

等价于

typedef lambda<op>::type f;
typedef lambda<in::operation>::type in_op;

typedef reverse_fold<
      s
    , in::state
    , bind< in_op, _1, bind<f, _2> >
    >::type r;

typedef transform<s1,s2,op,in>::type r;
Return type:

一个类型.
Postcondition:

等价于

typedef lambda<op2>::type f;
typedef lambda<in::operation>::type in_op;

typedef reverse_fold<
      pair_view<s1,s2>
    , in::state
    , bind<
          in_op
        , _1
        , bind<f, bind<first<>,_2>, bind<second<>,_2> >
        >
    >::type r;

复杂度

线性. 恰好 size<s>::value / size<s1>::value 次 op / op2 和 in::operation 应用.

示例 

typedef vector<char,short,int,long,float,double> types;
typedef vector<double*,float*,long*,int*,short*,char*> pointers;
typedef reverse_transform< types,boost::add_pointer<_1> >::type result;

BOOST_MPL_ASSERT(( equal<result,pointers> ));
