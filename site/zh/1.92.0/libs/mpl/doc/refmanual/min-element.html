min_element

概要

template<
      typename Sequence
    , typename Pred = less<_1,_2>
    >
struct min_element
{
    typedef unspecified type;
};

说明

返回一个迭代器, 指向 Sequence 中最小的元素.

Header

#include <boost/mpl/min_element.hpp>

Parameters

参数 要求 说明
Sequence Forward Sequence 要查找的序列.
Pred 二元 lambda 表达式 一个比较准则.

表达式语义

对任意 前向序列 s 与二元 lambda 表达式 pred:

typedef min_element<s,pred>::type i;
Return type:

前向迭代器.
语义:

i 是 [begin<s>::type, end<s>::type) 中的第一个迭代器, 使得对每个迭代器 j (位于 [begin<s>::type, end<s>::type) 中),

apply< pred, deref<j>::type, deref<i>::type >::type::value == false

复杂度

线性. 若 s 为空则零次比较, 否则恰好 size<s>::value - 1 次比较.

示例 

typedef vector<bool,char[50],long,double> types;
typedef min_element<
      transform_view< types,sizeof_<_1> >
    >::type iter;

BOOST_MPL_ASSERT(( is_same< deref<iter::base>::type, bool> ));

参见

查询算法, max_element, find_if, upper_bound, find
