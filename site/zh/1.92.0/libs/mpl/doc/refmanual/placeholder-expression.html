占位符表达式

说明

占位符表达式 是这样一个类型: 它要么是一个 占位符, 要么是一个类模板特化, 且其至少一个实参本身是 占位符表达式.

表达式要求

若 X 是类模板, 且 a1,... an 是任意类型, 则 X<a1,...,an> 是 占位符表达式 当且仅当以下所有条件成立:

  • 模板实参 a1,... an 中至少有一个是 占位符 或 占位符表达式.
  • X 的所有模板参数 (包括带默认值的参数) 都是类型.
  • X 的模板参数个数 (包括带默认值的参数) 小于或等于 BOOST_MPL_LIMIT_METAFUNCTION_ARITY 配置宏 的值.

模型

  • _1
  • plus<_, int_<2> >
  • if_< less<_1, int_<7> >, plus<_1,_2>, _1 >

参见

lambda 表达式, 占位符, 元函数, apply, lambda
