元函数类

小结

元函数类是元函数的一种特定表示形式, 用于支持高阶元编程. 更准确地说, 它是一个类, 拥有一个可公开访问的嵌套 元函数, 名为 apply. 相应地, 元函数类的调用被定义为其嵌套 apply 元函数的调用.

表达式要求

在下表及后续规范中, f 是一个 元函数类.

表达式 类型 复杂度
f::apply::type Any type 未指定.
f::apply<>::type Any type 未指定.
f::apply<a1,...an>::type Any type 未指定.

表达式语义

typedef f::apply::type x;
Precondition:f 是零元 元函数类; f::apply::type 是一个类型名.
语义:x 是元函数类调用的结果. 
typedef f::apply<>::type x;
Precondition:f 是零元 元函数类; f::apply<>::type 是一个类型名.
语义:x 是元函数类调用的结果. 
typedef f::apply<a1,...an>::type x;
Precondition:f 是 n 元元函数类; apply 是一个 元函数.
语义:x 是以实际实参 a1,... an 进行元函数类调用的结果.

模型

  • always
  • arg
  • quote
  • numeric_cast
  • unpack_args

参见

元函数, 元函数, lambda 表达式, 调用, apply_wrap, bind, quote
