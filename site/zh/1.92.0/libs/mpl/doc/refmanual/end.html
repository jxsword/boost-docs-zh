end

概要

template<
      typename X
    >
struct end
{
    typedef unspecified type;
};

说明

返回序列的尾后迭代器. 若实参不是 前向序列, 则返回 void_.

Header

#include <boost/mpl/begin_end.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
X Any type 一个类型, 若其 end 迭代器存在, 则返回该迭代器.

表达式语义

对任意类型 x:

typedef end<x>::type last;
Return type:前向迭代器 或 void_.
语义:若 x 是 前向序列, 则 last 是指向 s 中最后一个元素之后位置的迭代器; 否则 last 为 void_.
Postcondition:若 last 是迭代器, 则它是尾后迭代器.

复杂度

摊还常量时间.

示例 

typedef vector<long> v;
typedef begin<v>::type first;
typedef end<v>::type last;

BOOST_MPL_ASSERT(( is_same< next<first>::type, last > ));

参见

迭代器, 前向序列, begin, end, next
