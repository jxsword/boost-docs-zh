inserter (class)

概要

template<
      typename State
    , typename Operation
    >
struct inserter
{
    typedef State state;
    typedef Operation operation;
};

说明

插入器 概念的通用模型.

Header

#include <boost/mpl/inserter.hpp>

模型

插入器

Parameters

参数 要求 说明
State Any type 一个初始状态.
Operation 二元 lambda 表达式 一个输出操作.

表达式语义

表达式的语义仅在不同于 插入器 或其中未作定义之处给出定义.

对任意二元 lambda 表达式 op 与任意类型 state:

表达式 语义
inserter<op,state> 一个 插入器.

复杂度

摊还常量时间.

示例 

template< typename N > struct is_odd : bool_< ( N::value % 2 ) > {};

typedef copy<
      range_c<int,0,10>
    , inserter< // a filtering 'push_back' inserter
          vector<>
        , if_< is_odd<_2>, push_back<_1,_2>, _1 >
        >
    >::type odds;

BOOST_MPL_ASSERT(( equal< odds, vector_c<int,1,3,5,7,9>, equal_to<_,_> > ));
