insert

概要

template<
      typename Sequence
    , typename Pos
    , typename T
    >
struct insert
{
    typedef unspecified type;
};


template<
      typename Sequence
    , typename T
    >
struct insert
{
    typedef unspecified type;
};

说明

insert 是一个重载名称:

  • insert<Sequence,Pos,T> 执行一次插入, 把类型 T 插到任意位置 Pos 处, 位于 Sequence 中. Pos 被忽略, 若 Sequence 是 可扩展关联序列 的模型.
  • insert<Sequence,T> 是 insert<Sequence,Pos,T> 在 Sequence 是 可扩展关联序列 模型情形下的简写记法.

Header

#include <boost/mpl/insert.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence 可扩展序列 或 可扩展关联序列 要插入元素的序列.
Pos Forward Iterator Sequence 中的一个迭代器, 指定插入位置.
T Any type 要插入的元素.

表达式语义

对任意 可扩展序列 s、s 中的迭代器 pos 以及任意类型 x:

typedef insert<s,pos,x>::type r;
Return type:

可扩展序列
Precondition:

pos 是 s 中的迭代器.
语义:

r 是一个 概念等同 于 s 的序列, 由以下元素组成: [begin<s>::type, pos), x, [pos, end<s>::type).
Postcondition:

r 中元素的相对顺序与 s 中相同.

at< r, distance< begin<s>::type,pos >::type >::type

与 x 相同;

size<r>::value == size<s>::value + 1;

对任意 可扩展关联序列 s、s 中的迭代器 pos 以及任意类型 x:

typedef insert<s,x>::type r;
Return type:可扩展关联序列
语义:r 是 概念等同 于 s 且与之等价的, 但 at< r, key_type<s,x>::type >::type 与 value_type<s,x>::type 相同.
Postcondition:size<r>::value == size<s>::value + 1. 
typedef insert<s,pos,x>::type r;
Return type:可扩展关联序列
Precondition:pos 是 s 中的迭代器.
语义:等价于 typedef insert<s,x>::type r; pos 被忽略.

复杂度

序列原型 复杂度
可扩展关联序列 摊还常量时间.
可扩展序列 最坏情况下为线性, 或为摊还常量时间.

示例 

typedef vector_c<int,0,1,3,4,5,6,7,8,9> numbers;
typedef find< numbers,integral_c<int,3> >::type pos;
typedef insert< numbers,pos,integral_c<int,2> >::type range;

BOOST_MPL_ASSERT_RELATION( size<range>::value, ==, 10 );
BOOST_MPL_ASSERT(( equal< range,range_c<int,0,10> > ));

typedef map< mpl::pair<int,unsigned> > m;
typedef insert<m,mpl::pair<char,long> >::type m1;

BOOST_MPL_ASSERT_RELATION( size<m1>::value, ==, 2 );
BOOST_MPL_ASSERT(( is_same< at<m1,int>::type,unsigned > ));
BOOST_MPL_ASSERT(( is_same< at<m1,char>::type,long > ));

参见

可扩展序列, 可扩展关联序列, insert_range, push_front, push_back, erase
