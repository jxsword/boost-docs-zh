bool_

概要

template<
      bool C
    >
struct bool_
{
    // unspecified
    // ...
};

typedef bool_<true>  true_;
typedef bool_<false> false_;

说明

一个布尔 整型常量 包装器.

Header

#include <boost/mpl/bool.hpp>

模型

整型常量

Parameters

参数 要求 说明
C 一个布尔整型常量 要包装的值.

表达式语义

表达式的语义仅在不同于 整型常量 或其中未作定义之处给出定义.

对任意整型常量 c:

表达式 语义
bool_<c> 一个 整型常量 x, 满足 x::value == c 且 x::value_type 与 bool 相同.

示例 

BOOST_MPL_ASSERT(( is_same< bool_<true>::value_type, bool > ));
BOOST_MPL_ASSERT(( is_same< bool_<true>, true_ > )); }
BOOST_MPL_ASSERT(( is_same< bool_<true>::type, bool_<true> > ));
BOOST_MPL_ASSERT_RELATION( bool_<true>::value, ==, true );
assert( bool_<true>() == true );

参见

数据类型, 整型常量, int_, long_, integral_c
