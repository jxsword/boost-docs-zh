Metafunction

说明

元函数是表示编译期可调用函数的类或类模板. 非零元元函数通过用特定模板参数(元函数实参)实例化类模板来调用; 元函数应用的结果可通过该实例化的嵌套 type typedef 访问. 元函数的所有实参都必须是类型 (即只允许类型模板参数). 元函数可以有可变数量的参数. 零元元函数表示为带嵌套 type 类型成员的 (模板) 类.

表达式要求

在下表及后续规范中, f 是一个 元函数.

表达式 类型 复杂度
f::type Any type 未指定.
f<>::type Any type 未指定.
f<a1,..,an>::type Any type 未指定.

表达式语义

typedef f::type x;
Precondition:f 是零元 元函数; f::type 是一个类型名.
语义:x 是元函数调用的结果. 
typedef f<>::type x;
Precondition:f 是零元 元函数; f<>::type 是一个类型名.
语义:x 是元函数调用的结果. 
typedef f<a1,... an>::type x;
Precondition:f 是 n 元 元函数; a1,... an 是类型; f<a1,...an>::type 是一个类型名.
语义:x 是以实际实参 a1,... an 进行元函数调用的结果.

模型

  • identity
  • plus
  • begin
  • insert
  • fold

参见

元函数, 元函数类, lambda 表达式, 调用, apply, lambda, bind
