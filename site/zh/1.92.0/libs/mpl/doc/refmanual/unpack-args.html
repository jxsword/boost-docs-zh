unpack_args

概要

template<
      typename F
    >
struct unpack_args
{
    // unspecified
    // ...
};

说明

一个高阶原语, 把 n 元 lambda 表达式 F 变换为一元 元函数类 g, 后者接受单一的 n 实参序列.

Header

#include <boost/mpl/unpack_args.hpp>

模型

元函数类

Parameters

参数 要求 说明
F lambda 表达式 要采纳的 lambda 表达式.

表达式语义

对任意 lambda 表达式 f 以及任意类型 a1,... an:

typedef unpack_args<f> g;
Return type:

元函数类.
语义:

g 是一元 元函数类, 满足

apply_wrapn< g, vector<a1,...an> >::type

与下者相同

apply<F,a1,...an>::type

示例 

BOOST_MPL_ASSERT(( apply<
      unpack_args< is_same<_1,_2> >
    , vector<int,int>
    > ));

参见

元函数, lambda 表达式, 元函数类, apply, apply_wrap, bind
