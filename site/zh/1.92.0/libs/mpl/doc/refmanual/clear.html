clear

概要

template<
      typename Sequence
    >
struct clear
{
    typedef unspecified type;
};

说明

返回一个 概念等同 于 Sequence 的空序列.

Header

#include <boost/mpl/clear.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence 可扩展序列 或 可扩展关联序列 要获取其空副本的序列.

表达式语义

对任意 可扩展序列 或 可扩展关联序列 s:

typedef clear<s>::type t;
Return type:

可扩展序列 或 可扩展关联序列.
语义:

等价于

typedef erase< s, begin<s>::type, end<s>::type >::type t;
Postcondition:

empty<s>::value == true.

复杂度

摊还常量时间.

示例 

typedef vector_c<int,1,3,5,7,9,11> odds;
typedef clear<odds>::type nothing;

BOOST_MPL_ASSERT(( empty<nothing> ));

参见

可扩展序列, 可扩展关联序列, erase, empty, begin, end
