quote

概要

template<
      template< typename P1 > class F
    , typename Tag = unspecified
    >
struct quote1
{
    // unspecified
    // ...
};

...

template<
      template< typename P1,... typename Pn > class F
    , typename Tag = unspecified
    >
struct quoten
{
    // unspecified
    // ...
};

说明

quoten 是一个高阶原语, 包装 n 元 元函数 以创建相应的 元函数类.

Header

#include <boost/mpl/quote.hpp>

模型

元函数类

Parameters

参数 要求 说明
F Metafunction 要包装的元函数.
Tag Any type 决定包装语义的标签.

表达式语义

对任意 n 元 元函数 f 与任意类型 tag:

typedef quoten<f> g;
typedef quoten<f,tag> g;
Return type:

元函数类
语义:

等价于

struct g
{
    template< typename A1,... typename An > struct apply
        : f<A1,...An>
    {
    };
};

若 f<A1,...An> 拥有嵌套类型成员 ::type, 则; 否则等价于

struct g
{
    template< typename A1,... typename An > struct apply
    {
        typedef f<A1,...An> type;
    };
};

otherwise.

示例 

template< typename T > struct f1
{
    typedef T type;
};

template<
    typename T1, typename T2, typename T3, typename T4, typename T5
    >
struct f5
{
    // no 'type' member!
};

typedef quote1<f1>::apply<int>::type t1;
typedef quote5<f5>::apply<char,short,int,long,float>::type t5;

BOOST_MPL_ASSERT(( is_same< t1, int > ));
BOOST_MPL_ASSERT(( is_same< t5, f5<char,short,int,long,float> > ));

参见

组合与实参绑定, 调用, bind, lambda, protect, apply
