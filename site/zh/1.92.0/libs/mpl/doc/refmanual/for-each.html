for_each

概要

template<
      typename Sequence
    , typename F
    >
void for_each( F f );

template<
      typename Sequence
    , typename TransformOp
    , typename F
    >
void for_each( F f );

说明

for_each 是一组重载函数模板:

  • for_each<Sequence>( f ) 把运行期函数对象 f 应用于 [begin<Sequence>::type, end<Sequence>::type) 区间中的每个元素.
  • for_each<Sequence,TransformOp>( f ) 把运行期函数对象 f 应用于变换 TransformOp 的结果, 针对区间 [begin<Sequence>::type, end<Sequence>::type) 中的每个元素.

Header

#include <boost/mpl/for_each.hpp>

Parameters

参数 要求 说明
Sequence Forward Sequence 要迭代的序列.
TransformOp lambda 表达式 一个变换.
f 一个 一元函数对象 要应用的运行期操作.

表达式语义

对任意 前向序列 s、lambda 表达式 op 以及 一元函数对象 f:

for_each<s>( f );
Return type:

void
Postcondition:

等价于

typedef begin<Sequence>::type i1;
value_initialized< deref<i1>::type > x1;
f(boost::get(x1));

typedef next<i1>::type i2;
value_initialized< deref<i2>::type > x2;
f(boost::get(x2));
...
value_initialized< deref<in>::type > xn;
f(boost::get(xn));
typedef next<in>::type last;

其中 n == size<s>::value 且 last 与 end<s>::type 相同; 若 empty<s>::value == true 则无效果.

 
for_each<s,op>( f );
Return type:

void
Postcondition:

等价于

for_each< transform_view<s,op> >( f );

复杂度

线性. 恰好 size<s>::value 次 op 应用和 f 应用.

示例 

struct value_printer
{
    template< typename U > void operator()(U x)
    {
        std::cout << x << '\n';
    }
};

int main()
{
    for_each< range_c<int,0,10> >( value_printer() );
}

参见
