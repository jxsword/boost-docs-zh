contains

概要

template<
      typename Sequence
    , typename T
    >
struct contains
{
    typedef unspecified type;
};

说明

返回一个取值为真的 整型常量, 若 Sequence 中有一个或多个元素与 T 相同.

Header

#include <boost/mpl/contains.hpp>

Parameters

参数 要求 说明
Sequence Forward Sequence 要检查的序列.
T Any type 要查找的类型.

表达式语义

对任意 前向序列 s 与任意类型 t:

typedef contains<s,t>::type r;
Return type:

整型常量.
语义:

等价于

typedef not_< is_same<
      find<s,t>::type
    , end<s>::type
    > >::type r;

复杂度

线性. 至多 size<s>::value 次同一性比较.

示例 

typedef vector<char,int,unsigned,long,unsigned long> types;
BOOST_MPL_ASSERT_NOT(( contains<types,bool> ));

参见

查询算法, find, find_if, count, lower_bound
