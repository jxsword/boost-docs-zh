string

说明

string 是字符的 变参、双向、可扩展 整型序列包装器, 支持在两端进行摊还常量时间的元素插入和移除, 以及在中间进行线性时间的元素插入和移除. string 的实参是多字符字面量, 为编译期字符串提供了一种较易读的语法. string 也可以作为 c_str 元函数的实参, 后者生成一个空终止字符数组, 便于与运行期字符串处理例程互操作.

Header

序列形式 头文件
变参 #include <boost/mpl/string.hpp>

模型

  • 整型序列包装器
  • 变参序列
  • Bidirectional Sequence
  • 可扩展序列
  • 尾部可扩展序列
  • 头部可扩展序列

表达式语义

在下表中, s 是 string 的一个实例, pos 和 last 是指向 s 的迭代器, r 是由字符组成的 前向序列, n 和 x 是 整型常量, 而 c1,c2,... cn 是任意 (多) 字符.

表达式 语义 
string<c1,c2,... cn>
string, 由字符 c1,c2,... cn 组成; 参见 变参序列. 
string<c1,c2,... cn>::type
与 string<c1,c2,... cn> 相同; 参见 变参序列.
begin<s>::type 指向 s 开头的迭代器; 参见 双向序列.
end<s>::type 指向 s 末尾的迭代器; 参见 双向序列.
size<s>::type s 的大小; 参见 双向序列.
empty<s>::type 一个布尔 整型常量 c, 当且仅当序列为空时 c::value == true; 参见 双向序列.
front<s>::type s 中的第一个元素; 参见 双向序列.
back<s>::type s 中的最后一个元素; 参见 双向序列.
insert<s,pos,x>::type 一个新的 string, 由以下元素组成: [begin<s>::type, pos), x, [pos, end<s>::type); 参见 可扩展序列.
insert_range<s,pos,r>::type 一个新的 string, 由以下元素组成: [begin<s>::type, pos), [begin<r>::type, end<r>::type) [pos, end<s>::type); 参见 可扩展序列.
erase<s,pos>::type 一个新的 string, 由以下元素组成: [begin<s>::type, pos), [next<pos>::type, end<s>::type); 参见 可扩展序列.
erase<s,pos,last>::type 一个新的 string, 由以下元素组成: [begin<s>::type, pos), [last, end<s>::type); 参见 可扩展序列.
clear<s>::type 一个空的 string; 参见 可扩展序列.
push_back<s,x>::type 一个新的 string, 由以下元素组成: [begin<s>::type, end<s>::type), x; 参见 尾部可扩展序列.
pop_back<s>::type 一个新的 string, 由以下元素组成: [begin<s>::type, prior< end<s>::type >::type); 参见 尾部可扩展序列.
push_front<s,x>::type 一个新的 string, 由以下元素组成: [begin<s>::type, end<s>::type), x; 参见 头部可扩展序列.
pop_front<s>::type 一个新的 string, 由以下元素组成: [next< begin<s>::type >::type, end<s>::type); 参见 头部可扩展序列.
c_str<s>::value 一个空终止字节字符串, 满足 c_str<s>::value[n] 等于第 n 个字符 (位于 s 中), 且 c_str<s>::value[size<s>::type::value] 为 '\0'.

示例 

typedef mpl::string<'hell','o wo','rld'> hello;
typedef mpl::push_back<hello, mpl::char_<'!'> >::type hello2;

BOOST_ASSERT(0 == std::strcmp(mpl::c_str<hello2>::value, "hello world!"));
