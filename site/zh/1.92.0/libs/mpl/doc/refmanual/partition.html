partition

概要

template<
      typename Seq
    , typename Pred
    , typename In1 = unspecified
    , typename In2 = unspecified
    >
struct partition
{
    typedef unspecified type;
};

说明

返回一个序列对, 合在一起包含区间 [begin<Seq>::type, end<Seq>::type) 中的所有元素, 按谓词 Pred 分成两组. partition 是 stable_partition 的同义词.

[注释: 此表述适用于算法的无插入器版本. 有关该算法在所有情形下的精确规范, 参见 表达式语义 小节 — 注毕]

Header

#include <boost/mpl/partition.hpp>

模型

可逆算法

Parameters

参数 要求 说明
Seq Forward Sequence 原始序列.
Pred 一元 lambda 表达式 分区谓词.
In1, In2 插入器 输出插入器.

表达式语义

表达式的语义仅在不同于 可逆算法 或其中未作定义之处给出定义.

对任意 前向序列 s、一元 lambda 表达式 pred 以及 插入器 in1 和 in2:

typedef partition<s,pred,in1,in2>::type r;
Return type:

一个 pair.
语义:

等价于

typedef stable_partition<s,pred,in1,in2>::type r;

复杂度

线性. 恰好 size<s>::value 次 pred 应用, 以及合计 size<s>::value 次 in1::operation / in2::operation 应用.

示例 

template< typename N > struct is_odd : bool_<(N::value % 2)> {};

typedef partition<
      range_c<int,0,10>
    , is_odd<_1>
    , back_inserter< vector<> >
    , back_inserter< vector<> >
    >::type r;

BOOST_MPL_ASSERT(( equal< r::first, vector_c<int,1,3,5,7,9> > ));
BOOST_MPL_ASSERT(( equal< r::second, vector_c<int,0,2,4,6,8> > ));

参见
