BOOST_MPL_ASSERT_RELATION

概要

#define BOOST_MPL_ASSERT_RELATION( x, relation, y ) \
    unspecified token sequence \
/**/

说明

用于检查数值条件的专用断言宏. 当条件 ( x relation y ) 不成立时生成编译错误.

Header

#include <boost/mpl/assert.hpp>

Parameters

参数 要求 说明
x An integral constant 被检查关系的左操作数.
y An integral constant 被检查关系的右操作数.
relation 一个 C++ 运算符记号 被检查关系的运算符记号.

表达式语义

对任意整型常量 x, y 以及合法的 C++ 运算符记号 op:

BOOST_MPL_ASSERT_RELATION( x, op, y );
Return type:

无.
语义:

若 ( x op y ) != true 则生成编译错误, 否则无任何效果.

在编译器诊断能力允许的情况下, 错误消息将包含被检查关系的名称和两个操作数的实际值, 并具有如下一般形式:

... ************...assert_relation<op, x, y>::************) ...

示例 

template< typename T, typename U > struct my
{
    // ...
    BOOST_MPL_ASSERT_RELATION( sizeof(T), <, sizeof(U) );
};

my<char[50],char[10]> test;

// In instantiation of `my<char[50], char[10]>':
//   instantiated from here
// conversion from `
//   mpl_::failed************mpl_::assert_relation<less, 50, 10>::************'
//   to non-scalar type `mpl_::assert<false>' requested

参见

断言, BOOST_MPL_ASSERT, BOOST_MPL_ASSERT_NOT, BOOST_MPL_ASSERT_MSG
