Associative Sequence

说明

关联序列 是一种 前向序列, 它允许基于键高效地检索元素. 与 C++ 标准库中的关联容器不同, MPL 关联序列没有与之关联的排序关系. 相反, 它以类型同一性在键上施加等价关系, 并且迭代期间遍历序列元素的顺序不作指定.

定义

  • 键是元素类型的一部分, 用于在序列中标识和检索该元素.
  • 值是元素类型的一部分, 通过键从序列中检索得到.

表达式要求

在下表及后续规范中, s 是一个 关联序列, x 是一个序列元素, k 和 def 是任意类型.

除 前向序列 中定义的要求之外, 还必须满足以下要求:

表达式 类型 复杂度
has_key<s,k>::type 布尔 整型常量 Amortized constant time
count<s,k>::type 整型常量 Amortized constant time
order<s,k>::type 整型常量 或 void_ Amortized constant time
at<s,k>::type Any type Amortized constant time
at<s,k,def>::type Any type Amortized constant time
key_type<s,x>::type Any type Amortized constant time
value_type<s,x>::type Any type Amortized constant time

表达式语义

The semantics of an expression are defined only where they differ from, or are not defined in Forward Sequence.

表达式 语义
has_key<s,k>::type 一个布尔 整型常量 c, 其中 c::value == true 当且仅当 s 中存在一个或多个以键 k 索引的元素; 参见 has_key.
count<s,k>::type 键为 k 的元素在 s 中的数量; 参见 count.
order<s,k>::type 一个唯一的无符号 整型常量, 与键 k 在序列 s 中相关联; 参见 order. 
at<s,k>::type
at<s,k,def>::type
与键 k 相关联的、在序列 s 中的第一个元素; 参见 at.
key_type<s,x>::type 元素 x 的键部分, 将被用于在 s 内标识 x; 参见 key_type.
value_type<s,x>::type 元素 x 的值部分, 即 x 在 s 中将采用的部分; 参见 value_type.

模型

  • set
  • map

参见

序列, 可扩展关联序列, has_key, count, order, at, key_type, value_type
