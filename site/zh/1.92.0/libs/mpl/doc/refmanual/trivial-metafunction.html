平凡元函数

说明

平凡元函数 接受一个类类型的单一实参 x, 返回 x 的嵌套类型成员 x::name, 其中 name 是特定元函数实例所访问的实际成员名称的占位记号. 按照约定, MPL 中所有 平凡元函数 都以它们提供访问的成员命名. 例如, 一个 平凡元函数 名为 first, 访问 x 的嵌套成员 ::first.

表达式要求

在下表及后续规范中, name 是 平凡元函数 本身及其所访问成员名称的占位记号, x 是使 x::name 成为有效类型名的类类型.

表达式 类型 复杂度
name<x>::type Any type 常量时间.

表达式语义

typedef name<x>::type r;
Precondition:x::name 是有效的类型名.
语义:is_same<r,x::name>::value == true.

模型

  • first
  • second
  • base

参见

Metafunctions, Trivial Metafunctions, identity
