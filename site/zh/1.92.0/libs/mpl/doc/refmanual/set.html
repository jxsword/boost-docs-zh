set

说明

set 是一种类型的 变参、关联、可扩展 序列, 支持常量时间的元素插入、移除以及成员关系测试. 一个 set 对每个键至多包含一个元素.

Header

序列形式 头文件
变参 #include <boost/mpl/set.hpp>
带编号 #include <boost/mpl/set/setn.hpp>

模型

  • 变参序列
  • Associative Sequence
  • 可扩展关联序列

表达式语义

在下表中, s 是 set 的一个实例, pos 是指向 s 的迭代器, 而 x、k 以及 t1,t2,... tn 是一组唯一的任意类型. [注释: 下文 给出了如何从可能不唯一的类型列表构造 set 的示例 — 注毕]

表达式 语义 
set<t1,t2,... tn>
setn<t1,t2,... tn>
set, 其元素为 t1,t2,... tn; 参见 变参序列. 
set<t1,t2,... tn>::type
setn<t1,t2,... tn>::type
与 setn<t1,t2,... tn> 相同; 参见 变参序列.
begin<s>::type 指向 s 开头的迭代器; 参见 关联序列.
end<s>::type 指向 s 末尾的迭代器; 参见 关联序列.
size<s>::type s 的大小; 参见 关联序列.
empty<s>::type 一个布尔 整型常量 c, 满足 c::value == true 当且仅当 s 为空; 参见 关联序列.
front<s>::type s 中的第一个元素; 参见 关联序列.
has_key<s,k>::type 一个布尔 整型常量 c, 满足 c::value == true 当且仅当 s 中存在一个或多个以键 k 索引的元素; 参见 关联序列.
count<s,k>::type 键为 k 的元素在 s 中的数量; 参见 关联序列.
order<s,k>::type 一个唯一的无符号 整型常量, 与键 k 在 s 中相关联; 参见 关联序列. 
at<s,k>::type
at<s,k,def>::type
在 s 中与键 k 相关联的元素; 参见 关联序列.
key_type<s,x>::type 与 x 相同; 参见 关联序列.
value_type<s,x>::type 与 x 相同; 参见 关联序列.
insert<s,x>::type

一个新的 set, 与 s 等价, 但

at< t, key_type<s,x>::type >::type

与 value_type<s,x>::type 相同.
insert<s,pos,x>::type 等价于 insert<s,x>::type; pos 被忽略.
erase_key<s,k>::type 一个新的 set, 与 s 等价, 但 has_key<t, k>::value == false.
erase<s,pos>::type 等价于 erase<s, deref<pos>::type >::type.
clear<s>::type 一个空的 set; 参见 clear.

示例

set 的基本不变式:

typedef set< int,long,double,int_<5> > s;

BOOST_MPL_ASSERT_RELATION( size<s>::value, ==, 4 );
BOOST_MPL_ASSERT_NOT(( empty<s> ));

BOOST_MPL_ASSERT(( is_same< at<s,int>::type, int > ));
BOOST_MPL_ASSERT(( is_same< at<s,long>::type, long > ));
BOOST_MPL_ASSERT(( is_same< at<s,int_<5> >::type, int_<5> > ));
BOOST_MPL_ASSERT(( is_same< at<s,char>::type, void_ > ));

从可能不唯一的类型列表构造 set:

typedef fold<
      vector<int,int,long,long>
    , set0<>
    , insert<_1,_2>
    >::type s;

BOOST_MPL_ASSERT_RELATION( size<s>::value, ==, 2 );
