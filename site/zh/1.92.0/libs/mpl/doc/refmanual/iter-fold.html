iter_fold

概要

template<
      typename Sequence
    , typename State
    , typename ForwardOp
    >
struct iter_fold
{
    typedef unspecified type;
};

说明

按顺序返回将二元 ForwardOp 相继应用于上一次 ForwardOp 调用的结果(若是首次调用则为 State)以及区间 [begin<Sequence>::type, end<Sequence>::type) 中每个迭代器的结果.

Header

#include <boost/mpl/iter_fold.hpp>

Parameters

参数 要求 说明
Sequence Forward Sequence 要迭代的序列.
State Any type 第一次 ForwardOp 应用所用的初始状态.
ForwardOp 二元 lambda 表达式 在前向遍历中执行的操作.

表达式语义

对任意 前向序列 s、二元 lambda 表达式 op 以及任意类型 state:

typedef iter_fold<s,state,op>::type t;
Return type:

一个类型.
语义:

等价于

typedef begin<s>::type i1;
typedef apply<op,state,i1>::type state1;
typedef next<i1>::type i2;
typedef apply<op,state1,i2>::type state2;
...
typedef apply<op,staten-1,in>::type staten;
typedef next<in>::type last;
typedef staten t;

其中 n == size<s>::value 且 last 与 end<s>::type 相同; 等价于 typedef state t;, 若 empty<s>::value == true.

复杂度

线性. 恰好 size<s>::value 次 op 应用.

示例 

typedef vector_c<int,5,-1,0,7,2,0,-5,4> numbers;
typedef iter_fold<
      numbers
    , begin<numbers>::type
    , if_< less< deref<_1>, deref<_2> >,_2,_1 >
    >::type max_element_iter;

BOOST_MPL_ASSERT_RELATION( deref<max_element_iter>::type::value, ==, 7 );

参见

算法, reverse_iter_fold, fold, reverse_fold, copy
