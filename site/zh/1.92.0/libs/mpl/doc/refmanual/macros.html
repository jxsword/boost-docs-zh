宏

作为一个模板元编程框架, MPL 专注于把一件事做好, 把大多数明显与预处理器相关的任务留给相应的专门库 [PRE]、[Ve03]. 但不管我们喜欢与否, 宏在当今的 C++ 元编程中扮演着重要角色, 某些有用的 MPL 级别功能, 若不把其依赖预处理的实现性质泄漏到库的公共接口中, 就无法实现.

[PRE]Vesa Karvonen, Paul Mensonides, The Boost Preprocessor Metaprogramming library
[Ve03]Vesa Karvonen, The Order Programming Language, 2003.
