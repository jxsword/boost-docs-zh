front_inserter

概要

template<
      typename Seq
    >
struct front_inserter
{
    // unspecified
    // ...
};

说明

在序列开头插入元素.

Header

#include <boost/mpl/front_inserter.hpp>

模型

插入器

Parameters

参数 要求 说明
Seq 头部可扩展序列 绑定插入器所用的序列.

表达式语义

表达式的语义仅在不同于 插入器 或其中未作定义之处给出定义.

对任意 头部可扩展序列 s:

表达式 语义
front_inserter<s>

一个 插入器 in, 等价于

struct in : inserter<s,push_front<_1,_2> > {};

复杂度

摊还常量时间.

示例 

typedef reverse_copy<
      range_c<int,0,5>
    , front_inserter< vector_c<int,5,6,7,8,9> >
    >::type range;

BOOST_MPL_ASSERT(( equal< range, range_c<int,0,10> > ));

参见

算法, 插入器, 可逆算法, inserter (类), back_inserter, push_front
