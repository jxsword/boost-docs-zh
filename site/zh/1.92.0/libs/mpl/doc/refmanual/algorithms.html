算法

MPL 提供了广泛的基础算法, 旨在满足顺序编译期数据处理需求的大多数场景. 这些算法包括许多 STL 算法的编译期对应版本、借鉴自函数式编程语言的迭代算法等等.

与操作隐式迭代器区间的 C++ 标准库算法不同, MPL 中的大多数对应算法接受并返回序列. 这一偏差并非源于 C++ 编译期计算本身函数式的特性, 而是着眼于提高库的总体易用性, 使针对编译期数据结构的编程尽可能愉快.

秉承 STL 的精神, MPL 算法是泛型的, 即它们不绑定于特定的序列类实现, 只要参数满足文档化的要求, 就能作用于广泛的参数类型. 这些要求以概念的形式给出. 在底层, 算法通过操作 迭代器 与具体的序列实现解耦.

所有 MPL 算法可归入三大类: 迭代算法、查询算法和变换算法. 变换算法引入了相关联的 插入器 概念, 它大致相当于标准库中 输出迭代器 的概念. 此外, 每个变换算法都提供 reverse_ 对应版本, 支持更广泛的高效变换 — 这是 可逆算法 概念所文档化的公共功能.
