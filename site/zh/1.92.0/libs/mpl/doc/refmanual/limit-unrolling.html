BOOST_MPL_LIMIT_UNROLLING

概要

#if !defined(BOOST_MPL_LIMIT_UNROLLING)
#   define BOOST_MPL_LIMIT_UNROLLING \
        implementation-defined integral constant \
/**/
#endif

说明

BOOST_MPL_LIMIT_UNROLLING 是一个可覆盖的配置宏, 用于调控库的迭代算法的展开深度. 在本库的这个实现中, BOOST_MPL_LIMIT_UNROLLING 的默认值为 4. 要覆盖默认值, 请在包含任何库头文件之前, 将 BOOST_MPL_LIMIT_UNROLLING 定义为所需的值. [注释: 覆盖只有在库被配置为不使用 预生成头文件 时才会生效. 详见 BOOST_MPL_CFG_NO_PREPROCESSED_HEADERS. — 注毕]

示例

除了影响库的整体性能之外, 覆盖 BOOST_MPL_LIMIT_UNROLLING 的默认值不会产生用户可观察的效果.

参见

配置, BOOST_MPL_CFG_NO_PREPROCESSED_HEADERS
