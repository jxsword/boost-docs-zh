Random Access Iterator

说明

随机访问迭代器 是一种 双向迭代器, 对将迭代器向前或向后移动任意多个位置、以及测量到同一序列中另一迭代器的距离提供常量时间保证.

Refinement of

Bidirectional Iterator

表达式要求

除 双向迭代器 中定义的要求之外, 还必须满足以下要求.

表达式 类型 复杂度
next<i>::type Random Access Iterator Amortized constant time
prior<i>::type Random Access Iterator Amortized constant time
i::category 整型常量, 可转换为 random_access_iterator_tag Constant time
advance<i,n>::type Random Access Iterator Amortized constant time
distance<i,j>::type 整型常量 Amortized constant time

表达式语义

typedef advance<i,n>::type j;
语义:参见 advance 的规范 
typedef distance<i,j>::type n;
语义:参见 distance 的规范

不变式

对任意随机访问迭代器 i 和 j, 以下不变式始终成立:

  • 若 advance<i,n>::type 良定义, 则 advance< advance<i,n>::type, negate<n>::type >::type 是空操作.
