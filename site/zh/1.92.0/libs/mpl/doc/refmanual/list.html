list

说明

list 是一种类型的 变参、前向、可扩展 序列, 支持在开头进行常量时间的元素插入和移除, 以及在末尾和中间进行线性时间的元素插入和移除.

Header

序列形式 头文件
变参 #include <boost/mpl/list.hpp>
带编号 #include <boost/mpl/list/listn.hpp>

模型

  • 变参序列
  • Forward Sequence
  • 可扩展序列
  • 头部可扩展序列

表达式语义

在下表中, l 是一个 list, pos 和 last 是指向 l 的迭代器, r 是一个 前向序列, 而 t1,t2,... tn 和 x 是任意类型.

表达式 语义 
list<t1,t2,... tn>
listn<t1,t2,... tn>
list, 其元素为 t1,t2,... tn; 参见 变参序列. 
list<t1,t2,... tn>::type
listn<t1,t2,... tn>::type
与 listn<t1,t2,... tn> 相同; 参见 变参序列.
begin<l>::type 指向 l 开头的迭代器; 参见 前向序列.
end<l>::type 指向 l 末尾的迭代器; 参见 前向序列.
size<l>::type l 的大小; 参见 前向序列.
empty<l>::type 一个布尔 整型常量 c, 满足 c::value == true 当且仅当 l 为空; 参见 前向序列.
front<l>::type l 中的第一个元素; 参见 前向序列.
insert<l,pos,x>::type 一个新的 list, 由以下元素组成: [begin<l>::type, pos), x, [pos, end<l>::type); 参见 可扩展序列.
insert_range<l,pos,r>::type 一个新的 list, 由以下元素组成: [begin<l>::type, pos), [begin<r>::type, end<r>::type) [pos, end<l>::type); 参见 可扩展序列.
erase<l,pos>::type 一个新的 list, 由以下元素组成: [begin<l>::type, pos), [next<pos>::type, end<l>::type); 参见 可扩展序列.
erase<l,pos,last>::type 一个新的 list, 由以下元素组成: [begin<l>::type, pos), [last, end<l>::type); 参见 可扩展序列.
clear<l>::type 一个空的 list; 参见 可扩展序列.
push_front<l,x>::type 一个新的 list, 以 x 作为其第一个元素; 参见 头部可扩展序列.
pop_front<l>::type 一个新的 list, 按相同顺序包含 l 中除第一个元素外的所有元素; 参见 头部可扩展序列.

示例 

typedef list<float,double,long double> floats;
typedef push_front<floats,int>::type types;

BOOST_MPL_ASSERT(( is_same< front<types>::type, int > ));

参见

序列, 变参序列, 前向序列, 可扩展序列, vector, list_c
