lower_bound

概要

template<
      typename Sequence
    , typename T
    , typename Pred = less<_1,_2>
    >
struct lower_bound
{
    typedef unspecified type;
};

说明

返回已排序的 Sequence 中 T 可以插入而不破坏排序的第一个位置.

Header

#include <boost/mpl/lower_bound.hpp>

Parameters

参数 要求 说明
Sequence Forward Sequence 要在其中查找的已排序序列.
T Any type 要为其查找位置的类型.
Pred 二元 lambda 表达式 查找准则.

表达式语义

对任意已排序的 前向序列 s、二元 lambda 表达式 pred 以及任意类型 x:

typedef lower_bound< s,x,pred >::type i;
Return type:

前向迭代器.
语义:

i 是区间 [begin<s>::type, end<s>::type) 中最远的迭代器, 使得对每个迭代器 j (位于 [begin<s>::type, i) 中),

apply< pred, deref<j>::type, x >::type::value == true

复杂度

比较次数是对数级的: 至多 log2( size<s>::value ) + 1. 若 s 是 随机访问序列, 则跨越区间的步数也是对数级的; 否则, 步数与 size<s>::value 成正比.

示例 

typedef vector_c<int,1,2,3,3,3,5,8> numbers;
typedef lower_bound< numbers, int_<3> >::type iter;

BOOST_MPL_ASSERT_RELATION(
      (distance< begin<numbers>::type,iter >::value), ==, 2
    );

BOOST_MPL_ASSERT_RELATION( deref<iter>::type::value, ==, 3 );

参见

查询算法, upper_bound, find, find_if, min_element
