deque

说明

deque 是一种类型的 变参、随机访问、可扩展 序列, 支持在两端进行常量时间的元素插入和移除, 以及在中间进行线性时间的元素插入和移除. 在本库的这个实现中, deque 是 vector 的同义词.

Header

#include <boost/mpl/deque.hpp>

模型

  • 变参序列
  • Random Access Sequence
  • 可扩展序列
  • 尾部可扩展序列
  • 头部可扩展序列

表达式语义

参见 vector 的规范.

示例 

typedef deque<float,double,long double> floats;
typedef push_back<floats,int>::type types;

BOOST_MPL_ASSERT(( is_same< at_c<types,3>::type, int > ));

参见

序列, vector, list, set
