order

概要

template<
      typename Sequence
    , typename Key
    >
struct order
{
    typedef unspecified type;
};

说明

返回一个唯一的无符号 整型常量, 与键 Key 在 Sequence 中相关联.

Header

#include <boost/mpl/order.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence Associative Sequence 要查询的序列.
Key Any type The queried key.

表达式语义

对任意 关联序列 s 与任意类型 key:

typedef order<s,key>::type n;
Return type:无符号 整型常量.
语义:若 has_key<s,key>::value == true, 则 n 是一个唯一的无符号 整型常量, 与 key 在 s 中相关联; 否则 n 与 void_ 相同.

复杂度

摊还常量时间.

示例 

typedef map< pair<int,unsigned>, pair<char,long> > m;

BOOST_MPL_ASSERT_NOT(( is_same< order<m,int>::type, void_ > ));
BOOST_MPL_ASSERT(( is_same< order<m,long>::type,void_ > ));

参见

关联序列, has_key, count, map
