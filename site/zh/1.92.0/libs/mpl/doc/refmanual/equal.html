equal

概要

template<
      typename Seq1
    , typename Seq2
    , typename Pred = is_same<_1,_2>
    >
struct equal
{
    typedef unspecified type;
};

说明

返回一个取值为真的 整型常量, 若两个序列 Seq1 与 Seq2 逐元素比较完全相同.

Header

#include <boost/mpl/equal.hpp>

Parameters

参数 要求 说明
Seq1, Seq2 Forward Sequence 要比较的序列.
Pred 二元 lambda 表达式 一个比较准则.

表达式语义

对任意 前向序列 s1 和 s2 以及二元 lambda 表达式 pred:

typedef equal<s1,s2,pred>::type c;
Return type:

整型常量
语义:

c::value == true 当且仅当 size<s1>::value == size<s2>::value, 且对每个迭代器 i (位于 [begin<s1>::type, end<s1>::type) 中), deref<i>::type 与下者相同:

advance< begin<s2>::type, distance< begin<s1>::type,i >::type >::type

复杂度

线性. 至多 size<s1>::value 次比较.

示例 

typedef vector<char,int,unsigned,long,unsigned long> s1;
typedef list<char,int,unsigned,long,unsigned long> s2;

BOOST_MPL_ASSERT(( equal<s1,s2> ));

参见

查询算法, find, find_if
