BOOST_MPL_AUX_LAMBDA_SUPPORT

概要

#define BOOST_MPL_AUX_LAMBDA_SUPPORT(arity, fun, params) \
    unspecified token sequence \
/**/

说明

在不支持偏特化或/和模板模板参数的编译器上, 使元函数 fun 可用于 lambda 表达式. 在符合标准的编译器上展开为空.

Header

#include <boost/mpl/aux_/lambda_support.hpp>

Parameters

参数 要求 说明
arity An integral constant 元函数的元数 (arity), 即其模板参数的个数, 包括带默认值的参数.
fun 一个合法的标识符记号 元函数的名称.
params 一个 PP 元组 由元函数参数名组成的元组, 按其原有顺序, 包括带默认值的参数.

表达式语义

对任意整型常量 n、元函数 fun 以及任意类型 A1,... An:

template< typename A1,... typename An > struct fun
{
    // ...

    BOOST_MPL_AUX_LAMBDA_SUPPORT(n, fun, (A1,...An))
};
Precondition:出现在 fun 的作用域内, 且紧随其后的就是作用域结束括号 (}).
Return type:无.
语义:在符合标准的编译器上不展开任何内容且无任何效果. 在不支持偏特化或/和模板模板参数的编译器上, 展开为一个未指定的记号序列, 使 fun 能够以本手册所述的语义参与 lambda 表达式.

示例 

template< typename T, typename U = int > struct f
{
    typedef T type[sizeof(U)];

    BOOST_MPL_AUX_LAMBDA_SUPPORT(2, f, (T,U))
};

typedef apply1< f<char,_1>,long >::type r;
BOOST_MPL_ASSERT(( is_same< r, char[sizeof(long)] > ));
