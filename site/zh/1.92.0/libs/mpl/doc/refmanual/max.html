max

概要

template<
      typename N1
    , typename N2
    >
struct max
{
    typedef unspecified type;
};

说明

返回其两个实参中较大的一个.

Header

#include <boost/mpl/min_max.hpp>

模型

Metafunction

Parameters

参数 要求 说明
N1, N2 Any type 要比较的类型.

表达式语义

对任意类型 x 和 y:

typedef max<x,y>::type r;
Return type:

一个类型.
Precondition:

less<x,y>::value 是良构成的整型常量表达式.
语义:

等价于

typedef if_< less<x,y>,y,x >::type r;

复杂度

常量时间.

示例 

typedef fold<
      vector_c<int,1,7,0,-2,5,-1>
    , int_<10>
    , max<_1,_2>
    >::type r;

BOOST_MPL_ASSERT(( is_same< r, int_<10> > ));

参见

元函数, 比较, min, less, max_element
