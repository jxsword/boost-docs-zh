at

概要

template<
      typename Sequence
    , typename N
    >
struct at
{
    typedef unspecified type;
};

template<
      typename AssocSeq
    , typename Key
    , typename Default = unspecified
    >
struct at
{
    typedef unspecified type;
};

说明

at 是一个重载名称:

  • at<Sequence,N> 返回第 N 个元素 (从 前向序列 Sequence 的开头算起).
  • at<AssocSeq,Key,Default> 返回与 Key 相关联的第一个元素 (位于 关联序列 AssocSeq 中); 若不存在这样的元素, 则返回 Default.

Header

#include <boost/mpl/at.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence Forward Sequence 要检查的序列.
AssocSeq Associative Sequence 要检查的序列.
N 整型常量 距序列开头的偏移量, 指定要检索的元素.
Key Any type 要检索的元素的键.
Default Any type 未找到元素时返回的默认值.

表达式语义

对任意 前向序列 s 与 整型常量 n:

typedef at<s,n>::type t;
Return type:

一个类型.
Precondition:

0 <= n::value < size<s>::value.
语义:

等价于

typedef deref< advance< begin<s>::type,n >::type >::type t;

对任意 关联序列 s 以及任意类型 key 和 x:

typedef at<s,key,x>::type t;
Return type:一个类型.
语义:若 has_key<s,key>::value == true, 则 t 是与 key 相关联的值类型; 否则 t 与 x 相同. 
typedef at<s,key>::type t;
Return type:

一个类型.
语义:

等价于

typedef at<s,key,void_>::type t;

复杂度

序列原型 复杂度
Forward Sequence 线性复杂度.
Random Access Sequence 摊还常量时间.
Associative Sequence 摊还常量时间.

示例 

typedef range_c<long,10,50> range;
BOOST_MPL_ASSERT_RELATION( (at< range, int_<0> >::value), ==, 10 );
BOOST_MPL_ASSERT_RELATION( (at< range, int_<10> >::value), ==, 20 );
BOOST_MPL_ASSERT_RELATION( (at< range, int_<40> >::value), ==, 50 );

typedef set< int const,long*,double > s;

BOOST_MPL_ASSERT(( is_same< at<s,char>::type, void_ > ));
BOOST_MPL_ASSERT(( is_same< at<s,int>::type, int > ));

参见

前向序列, 随机访问序列, 关联序列, at_c, front, back
