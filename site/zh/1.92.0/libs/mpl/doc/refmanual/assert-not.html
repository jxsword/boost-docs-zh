BOOST_MPL_ASSERT_NOT

概要

#define BOOST_MPL_ASSERT_NOT( pred ) \
    unspecified token sequence \
/**/

说明

当谓词为真时生成编译错误.

Header

#include <boost/mpl/assert.hpp>

Parameters

参数 要求 说明
pred 布尔零元 元函数 要断言为假的谓词.

表达式语义

对任意布尔零元 元函数 pred:

BOOST_MPL_ASSERT_NOT(( pred ));
Return type:

无.
语义:

若 pred::type::value != false 则生成编译错误, 否则无任何效果. 注意, 即使条件中没有逗号, 也必须使用双层括号.

在编译器诊断能力允许的情况下, 错误消息将包含谓词的完整类型名, 并具有如下一般形式:

... ************boost::mpl::not_< pred >::************ ...

示例 

template< typename T, typename U > struct my
{
    // ...
    BOOST_MPL_ASSERT_NOT(( is_same< T,U > ));
};

my<void,void> test;

// In instantiation of `my<void, void>':
//   instantiated from here
// conversion from `
//   mpl_::failed************boost::mpl::not_<boost::is_same<void, void>
//   >::************' to non-scalar type `mpl_::assert<false>' requested

参见

断言, BOOST_MPL_ASSERT, BOOST_MPL_ASSERT_MSG, BOOST_MPL_ASSERT_RELATION
