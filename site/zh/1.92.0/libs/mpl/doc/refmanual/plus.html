plus

概要

template<
      typename T1
    , typename T2
    , typename T3 = unspecified
    ...
    , typename Tn = unspecified
    >
struct plus
{
    typedef unspecified type;
};

说明

返回其实参之和.

Header

#include <boost/mpl/plus.hpp>
#include <boost/mpl/arithmetic.hpp>

模型

数值元函数

Parameters

参数 要求 说明
T1, T2,... Tn 整型常量 运算的参数.

[注释: 本规范列出的要求是默认实现所施加的要求. 有关如何为不满足 整型常量 要求的用户自定义数值类型提供实现, 参见 数值元函数 概念中的详细说明. — 注毕]

表达式语义

对任意 整型常量 c1,c2,... cn:

typedef plus<c1,...cn>::type r;
Return type:

整型常量.
语义:

等价于

typedef integral_c<
      typeof(c1::value + c2::value)
    , ( c1::value + c2::value )
    > c;

typedef plus<c,c3,...cn>::type r;

typedef plus<c1,...cn> r;
Return type:

整型常量.
语义:

等价于

struct r : plus<c1,...cn>::type {};

复杂度

摊还常量时间.

示例 

typedef plus< int_<-10>, int_<3>, long_<1> >::type r;
BOOST_MPL_ASSERT_RELATION( r::value, ==, -6 );
BOOST_MPL_ASSERT(( is_same< r::value_type, long > ));

参见

算术运算, 数值元函数, numeric_cast, minus, negate, times
