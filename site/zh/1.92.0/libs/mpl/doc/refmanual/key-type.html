key_type

概要

template<
      typename Sequence
    , typename X
    >
struct key_type
{
    typedef unspecified type;
};

说明

返回 键, 即将用于在 Sequence 中标识 X 的那个键.

Header

#include <boost/mpl/key_type.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence Associative Sequence 要查询的序列.
X Any type 要获取其 键 的类型.

表达式语义

对任意 关联序列 s、s 中的迭代器 pos1 和 pos2 以及任意类型 x:

typedef key_type<s,x>::type k;
Return type:一个类型.
Precondition:x 可以放入 s.
语义:k 是 键, 即将用于在 s 中标识 x 的那个键.
Postcondition:若 key_type< s,deref<pos1>::type >::type 与 key_type< s,deref<pos2>::type >::type 相同, 则 pos1 与 pos2 相同.

复杂度

摊还常量时间.

示例 

typedef key_type< map<>,pair<int,unsigned> >::type k1;
typedef key_type< set<>,pair<int,unsigned> >::type k2;

BOOST_MPL_ASSERT(( is_same< k1,int > ));
BOOST_MPL_ASSERT(( is_same< k2,pair<int,unsigned> > ));

参见

关联序列, value_type, has_key, set, map
