变参序列

说明

变参序列 是同时具有变参形式和带编号形式的序列类家族的一员. 若 seq 是某个 变参序列 的通用名称, 其变参形式允许我们指定一个 n 个元素 t1,t2,... tn 的序列, 其中 n 可取 0 到 预处理器可配置上限 BOOST_MPL_LIMIT_seq_SIZE 之间的任意值, 使用以下记法:

seq<t1,t2,... tn>

相比之下, 每个带编号序列形式只接受确切数量的元素, 该数量编码在相应类模板的名称中:

seqn<t1,t2,... tn>

对带编号形式而言, 除编译器对模板参数数量的限制外, n 没有预定义的上限.

表达式要求

在下表及后续规范中, seq 是实际 变参序列 名称的占位记号.

表达式 类型 复杂度
seq<t1,t2,... tn> Forward Sequence Amortized constant time
seq<t1,t2,... tn>::type Forward Sequence Amortized constant time
seqn<t1,t2,... tn> Forward Sequence Amortized constant time
seqn<t1,t2,... tn>::type Forward Sequence Amortized constant time

表达式语义

typedef seq<t1,t2,... tn> s;
typedef seqn<t1,t2,... tn> s;
语义:s 是由元素 t1,t2,... tn 组成的序列.
Postcondition:size<s>::value == n. 
typedef seq<t1,t2,... tn>::type s;
typedef seqn<t1,t2,... tn>::type s;
语义:s 与 seqn<t1,t2,... tn > 相同.
Postcondition:size<s>::value == n.

模型

  • vector
  • list
  • map

参见

序列, 配置, 整型序列包装器
