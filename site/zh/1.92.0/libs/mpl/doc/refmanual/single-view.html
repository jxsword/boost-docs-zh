single_view

概要

template<
      typename T
    >
struct single_view
{
    // unspecified
    // ...
};

说明

一个视图, 把任意类型 T 当作单元素序列来看待.

Header

#include <boost/mpl/single_view.hpp>

模型

  • Random Access Sequence

Parameters

参数 要求 说明
T Any type 要包装进序列的类型.

表达式语义

表达式的语义仅在不同于 随机访问序列 或其中未作定义之处给出定义.

在下表中, v 是 single_view 的一个实例, x 是任意类型.

表达式 语义 
single_view<x>
single_view<x>::type
一个单元素 随机访问序列 v, 满足 front<v>::type 与 x 相同.
size<v>::type v 的大小; size<v>::value == 1; 参见 随机访问序列.

示例 

typedef single_view<int> view;
typedef begin<view>::type first;
typedef end<view>::type last;

BOOST_MPL_ASSERT(( is_same< deref<first>::type,int > ));
BOOST_MPL_ASSERT(( is_same< next<first>::type,last > ));
BOOST_MPL_ASSERT(( is_same< prior<last>::type,first > ));

BOOST_MPL_ASSERT_RELATION( size<view>::value, ==, 1 );

参见

序列, 视图, iterator_range, filter_view, transform_view, joint_view, zip_view
