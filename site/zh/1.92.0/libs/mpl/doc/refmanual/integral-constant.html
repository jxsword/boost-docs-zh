整型常量

说明

整型常量 是一个持有整型编译期值的持有类. 每个 整型常量 同时也是一个返回自身的零元 元函数. 整型常量对象可隐式转换为被包装整型对应的运行期值.

表达式要求

在下表及后续规范中, n 是 整型常量 的模型.

表达式 类型 复杂度
n::tag integral_c_tag 常量时间.
n::value_type 一个整型 常量时间.
n::value 一个整型常量表达式 常量时间.
n::type 整型常量 常量时间.
next<n>::type 整型常量 常量时间.
prior<n>::type 整型常量 常量时间.
n::value_type const c = n()   常量时间.

表达式语义

表达式 语义
n::tag n 的标签类型; n::tag::value 是 n 的转换等级.
n::value_type n::value 的 cv 限定 stripped 类型.
n::value 被包装整型常量的值.
n::type is_same<n::type,n>::value == true.
next<n>::type 一个 整型常量 c, 其类型为 n::value_type, 满足 c::value == n::value + 1.
prior<n>::type 一个 整型常量 c, 其类型为 n::value_type, 满足 c::value == n::value - 1.
n::value_type const c = n() c == n::value.

模型

  • bool_
  • int_
  • long_
  • char_
  • integral_c

参见

数据类型, 整型序列包装器, integral_c
