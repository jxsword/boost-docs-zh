push_front

概要

template<
      typename Sequence
    , typename T
    >
struct push_front
{
    typedef unspecified type;
};

说明

push_front 在序列开头执行一次插入, 复杂度保证为 O(1).

Header

#include <boost/mpl/push_front.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence 头部可扩展序列 要插入元素的序列.
T Any type 要插入的元素.

表达式语义

对任意 头部可扩展序列 s 与任意类型 x:

typedef push_front<s,x>::type r;
Return type:

头部可扩展序列.
语义:

等价于

typedef insert< s,begin<s>::type,x >::type r;
Postcondition:

size<r>::value == size<s>::value + 1; front<r>::type 与 x 相同.

复杂度

摊还常量时间.

示例 

typedef vector_c<int,1,2,3,5,8,13,21> v;
BOOST_MPL_ASSERT_RELATION( size<v>::value, ==, 7 );

typedef push_front< v,integral_c<int,1> >::type fibonacci;
BOOST_MPL_ASSERT_RELATION( size<fibonacci>::value, ==, 8 );

BOOST_MPL_ASSERT(( equal<
      fibonacci
    , vector_c<int,1,1,2,3,5,8,13,21>
    , equal_to<_,_>
    > ));

参见

头部可扩展序列, insert, pop_front, front, push_back
