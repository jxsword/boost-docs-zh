if_

概要

template<
      typename C
    , typename T1
    , typename T2
    >
struct if_
{
    typedef unspecified type;
};

说明

返回其两个实参之一, 即 T1 或 T2, 视值 C 而定.

Header

#include <boost/mpl/if.hpp>

Parameters

参数 要求 说明
C 整型常量 选择条件.
T1, T2 Any type 供选择的类型.

表达式语义

对任意 整型常量 c 与任意类型 t1、t2:

typedef if_<c,t1,t2>::type t;
Return type:任意类型.
语义:若 c::value == true, 则 t 与 t1 相同; 否则 t 与 t2 相同.

示例 

typedef if_<true_,char,long>::type t1;
typedef if_<false_,char,long>::type t2;

BOOST_MPL_ASSERT(( is_same<t1, char> ));
BOOST_MPL_ASSERT(( is_same<t2, long> ));

// allocates space for an object of class T on heap or "inplace"
// depending on its size
template< typename T > struct lightweight
{
    // ...
    typedef typename if_<
          less_equal< sizeof_<T>, sizeof_<T*> >
        , inplace_storage<T>
        , heap_storage<T>
        >::type impl_t;

    impl_t impl;
};

参见

元函数, 整型常量, if_c, eval_if
