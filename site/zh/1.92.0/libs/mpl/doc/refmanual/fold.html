fold

概要

template<
      typename Sequence
    , typename State
    , typename ForwardOp
    >
struct fold
{
    typedef unspecified type;
};

说明

按顺序返回将二元 ForwardOp 相继应用于上一次 ForwardOp 调用的结果(若是首次调用则为 State)以及区间 [begin<Sequence>::type, end<Sequence>::type) 内序列每个元素的结果.

Header

#include <boost/mpl/fold.hpp>

Parameters

参数 要求 说明
Sequence Forward Sequence 要迭代的序列.
State Any type 第一次 ForwardOp 应用所用的初始状态.
ForwardOp 二元 lambda 表达式 在前向遍历中执行的操作.

表达式语义

对任意 前向序列 s、二元 lambda 表达式 op 以及任意类型 state:

typedef fold<s,state,op>::type t;
Return type:

一个类型.
语义:

等价于

typedef iter_fold<
      s
    , state
    , apply_wrap2< lambda<op>::type, _1, deref<_2> >
    >::type t;

复杂度

线性. 恰好 size<s>::value 次 op 应用.

示例 

typedef vector<long,float,short,double,float,long,long double> types;
typedef fold<
      types
    , int_<0>
    , if_< is_float<_2>,next<_1>,_1 >
    >::type number_of_floats;

BOOST_MPL_ASSERT_RELATION( number_of_floats::value, ==, 4 );

参见

算法, accumulate, reverse_fold, iter_fold, reverse_iter_fold, copy, copy_if
