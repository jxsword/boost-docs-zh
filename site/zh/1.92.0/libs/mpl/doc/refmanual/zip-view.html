zip_view

概要

template<
      typename Sequences
    >
struct zip_view
{
    // unspecified
    // ...
};

说明

提供对多个序列的 "压缩" 视图; 即把多个序列表示为单一序列, 其每个元素又是对应 Sequences 各元素组成的序列.

Header

#include <boost/mpl/zip_view.hpp>

模型

  • Forward Sequence

Parameters

参数 要求 说明
Sequences 一个由 前向序列 组成的 前向序列 要 "压缩" 的序列.

表达式语义

The semantics of an expression are defined only where they differ from, or are not defined in Forward Sequence.

在下表中, v 是 zip_view 的一个实例, seq 是一个 前向序列, 由 n 个 前向序列 组成.

表达式 语义 
zip_view<seq>
zip_view<seq>::type
一个惰性的 前向序列 v, 满足: 对每个 i (位于 [begin<v>::type, end<v>::type) 中) 以及每个 j (位于 [begin<seq>::type, end<seq>::type) 中), deref<i>::type 与 transform< deref<j>::type, deref<_1> >::type 相同.
size<v>::type

v 的大小; size<v>::value 等于

deref< min_element<
      transform_view< seq, size<_1> >
    >::type >::type::value;

线性复杂度; 参见 前向序列.

示例

三个向量的逐元素求和.

typedef vector_c<int,1,2,3,4,5> v1;
typedef vector_c<int,5,4,3,2,1> v2;
typedef vector_c<int,1,1,1,1,1> v3;

typedef transform_view<
      zip_view< vector<v1,v2,v3> >
    , unpack_args< plus<_1,_2,_3> >
    > sum;

BOOST_MPL_ASSERT(( equal< sum, vector_c<int,7,7,7,7,7> > ));

参见

序列, 视图, filter_view, transform_view, joint_view, single_view, iterator_range
