标签分发元函数

摘要

标签分发元函数 是一种 元函数, 其实现中采用标签分发技术, 以构建便于覆盖/扩展元函数行为的基础设施.

记法

符号 Legend
name 特定元函数名称的占位记号.
tag-metafunction 标签元函数名称的占位记号.
tag 标签元函数返回的可能标签类型之一的占位记号.

概要

template< typename Tag > struct name_impl;

template<
      typename X
    [, ...]
    >
struct name
    : name_impl< typename tag-metafunction<X>::type >
        ::template apply<X [, ...]>
{
};

template< typename Tag > struct name_impl
{
    template< typename X [, ...] > struct apply
    {
        // default implementation
    };
};

template<> struct name_impl<tag>
{
    template< typename X [, ...] > struct apply
    {
        // tag-specific implementation
    };
};

说明

覆盖元函数行为的常用机制是类模板特化——给定库定义的元函数 f, 可以为特定类型 user_type 编写 f 的特化, 使其具有所需的语义 [4].

虽然这一机制始终可用, 但它并不总是最便利的, 特别是当希望为相关类型的整个族特化元函数行为时. 一个典型的例子是 MPL 自身序列类的带编号形式 (list0, ..., list50 等), 以及一般意义上的序列类.

标签分发元函数 是库所采用的元函数实现基础设施实例的概念名称, 该基础设施使用户和实现者更容易覆盖库中针对特定类型族进行操作的元函数的行为.

该基础设施构建于通常称为标签分发的技术的一个变体之上 (概念名称由此而来), 涉及三个实体: 元函数本身、产生关联标签的 标签元函数, 以及以 元函数类 模板形式呈现的元函数实现, 该模板由 Tag 类型参数参数化. 元函数通过在标签元函数以原元函数参数产生的标签类型上调用其特化, 把工作转交给它的实现类模板.

[4]通常仍要求这类用户自定义特化保持 f 原有的不变式与复杂度要求.

示例 

#include <boost/mpl/size.hpp>

namespace user {

struct bitset_tag;

struct bitset0
{
    typedef bitset_tag tag;
    // ...
};

template< typename B0 > struct bitset1
{
    typedef bitset_tag tag;
    // ...
};

template< typename B0, ..., typename Bn > struct bitsetn
{
    typedef bitset_tag tag;
    // ...
};

} // namespace user

namespace boost { namespace mpl {
template<> struct size_impl<user::bitset_tag>
{
    template< typename Bitset > struct apply
    {
        typedef typename Bitset::size type;
    };
};
}}
