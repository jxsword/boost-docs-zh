apply_wrap

概要

template<
      typename F
    >
struct apply_wrap0
{
    typedef unspecified type;
};

template<
      typename F, typename A1
    >
struct apply_wrap1
{
    typedef unspecified type;
};

...

template<
      typename F, typename A1,... typename An
    >
struct apply_wrapn
{
    typedef unspecified type;
};

说明

调用 元函数类 F, 参数为 A1,... An.

从本质上说, apply_wrap 各形式不过是对 F::apply<A1,... An>::type / F::apply::type 表达式的语法包装(这也是其名称的由来). 相比其底层构造, 它们提供了更简洁的记法和更高的可移植性, 代价是一次额外的模板实例化.

Header

#include <boost/mpl/apply_wrap.hpp>

Parameters

参数 要求 说明
F 元函数类 要调用的元函数类.
A1,... An Any type 调用参数.

表达式语义

对任意 元函数类 f 与任意类型 a1,... an:

typedef apply_wrapn<f,a1,...an>::type t;
Return type:任意类型.
语义:若 n > 0, 等价于 typedef f::apply<a1,... an>::type t;; 否则等价于 typedef f::apply::type t; 或 typedef f::apply<>::type t;, 视 f::apply 是类还是类模板而定.

示例 

struct f0
{
    template< typename T = int > struct apply
    {
        typedef char type;
    };
};

struct g0
{
    struct apply { typedef char type; };
};

struct f2
{
    template< typename T1, typename T2 > struct apply
    {
        typedef T2 type;
    };
};


typedef apply_wrap0< f0 >::type r1;
typedef apply_wrap0< g0 >::type r2;
typedef apply_wrap2< f2,int,char >::type r3;

BOOST_MPL_ASSERT(( is_same<r1,char> ));
BOOST_MPL_ASSERT(( is_same<r2,char> ));
BOOST_MPL_ASSERT(( is_same<r3,char> ));

参见

元函数, 调用, apply, lambda, quote, bind, protect
