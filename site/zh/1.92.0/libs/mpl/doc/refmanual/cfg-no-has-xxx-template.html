BOOST_MPL_CFG_NO_HAS_XXX_TEMPLATE

概要

// #define BOOST_MPL_CFG_NO_HAS_XXX_TEMPLATE

说明

BOOST_MPL_CFG_NO_HAS_XXX_TEMPLATE 是一个布尔配置宏, 用于指示 BOOST_MPL_HAS_XXX_TEMPLATE_DEF / BOOST_MPL_HAS_XXX_TEMPLATE_NAMED_DEF 内省宏的功能在特定编译器上是否可用.

参见

宏, 配置, BOOST_MPL_HAS_XXX_TEMPLATE_DEF, BOOST_MPL_HAS_XXX_TEMPLATE_NAMED_DEF
