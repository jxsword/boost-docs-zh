可扩展关联序列

说明

可扩展关联序列 是一种支持元素插入和移除的 关联序列. 与 可扩展序列 不同, 可扩展关联序列 不提供在特定位置插入元素的机制.

表达式要求

在下表及后续规范中, s 是一个 关联序列, pos 是指向 s 的迭代器, x 和 k 是任意类型.

除 关联序列 的要求之外, 还必须满足以下要求:

表达式 类型 复杂度
insert<s,x>::type 可扩展关联序列 Amortized constant time
insert<s,pos,x>::type 可扩展关联序列 Amortized constant time
erase_key<s,k>::type 可扩展关联序列 Amortized constant time
erase<s,pos>::type 可扩展关联序列 Amortized constant time
clear<s>::type 可扩展关联序列 Amortized constant time

表达式语义

表达式的语义仅在不同于 关联序列 或其中未作定义之处给出定义.

表达式 语义
insert<s,x>::type

把 x 插入 s; 所得序列 r 与 s 等价, 但

at< r, key_type<s,x>::type >::type

与 value_type<s,x>::type 相同; 参见 insert.
insert<s,pos,x>::type 等价于 insert<s,x>::type; pos 被忽略; 参见 insert.
erase_key<s,k>::type 擦除 s 中与键 k 相关联的元素; 所得序列 r 与 s 等价, 但 has_key<r,k>::value == false; 参见 erase_key.
erase<s,pos>::type 擦除特定位置处的元素; 等价于 erase_key<s, deref<pos>::type >::type; 参见 erase.
clear<s>::type 一个与 s 概念等同的空序列; 参见 clear.

模型

  • set
  • map

参见

序列, 关联序列, insert, erase, clear
