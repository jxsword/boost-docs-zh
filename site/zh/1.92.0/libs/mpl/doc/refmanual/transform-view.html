transform_view

概要

template<
      typename Sequence
    , typename F
    >
struct transform_view
{
    // unspecified
    // ...
};

说明

一个视图, 观察 Sequence 全部元素的变换结果.

Header

#include <boost/mpl/transform_view.hpp>

模型

  • Forward Sequence

Parameters

参数 要求 说明
Sequence Forward Sequence 要包装的序列.
F 一元 lambda 表达式 一个变换.

表达式语义

The semantics of an expression are defined only where they differ from, or are not defined in Forward Sequence.

在下表中, v 是 transform_view 的一个实例, s 是任意 前向序列, 而 f 是一元 lambda 表达式.

表达式 语义 
transform_view<s,f>
transform_view<s,f>::type
一个惰性的 前向序列, 满足: 对每个 i (位于区间 [begin<v>::type, end<v>::type) 中) 以及每个 j (位于区间 [begin<s>::type, end<s>::type) 中), deref<i>::type 与 apply< f, deref<j>::type >::type 相同.
size<v>::type v 的大小; size<v>::value == size<s>::value; 线性复杂度; 参见 前向序列.

示例

找出序列中最大的类型.

typedef vector<int,long,char,char[50],double> types;
typedef max_element<
      transform_view< types, size_of<_> >
    >::type iter;

BOOST_MPL_ASSERT_RELATION( deref<iter>::type::value, ==, 50 );
