joint_view

概要

template<
      typename Sequence1
    , typename Sequence2
    >
struct joint_view
{
    // unspecified
    // ...
};

说明

一个视图, 观察由 Sequence1 与 Sequence2 元素拼接而成的元素序列.

Header

#include <boost/mpl/joint_view.hpp>

模型

  • Forward Sequence

Parameters

参数 要求 说明
Sequence1, Sequence2 Forward Sequence 要创建视图的序列.

表达式语义

The semantics of an expression are defined only where they differ from, or are not defined in Forward Sequence.

在下表中, v 是 joint_view 的一个实例, s1 和 s2 是任意 前向序列.

表达式 语义 
joint_view<s1,s2>
joint_view<s1,s2>::type
一个惰性 前向序列, 包含区间 [begin<s1>::type, end<s1>::type) 与 [begin<s2>::type, end<s2>::type) 中的所有元素.
size<v>::type v 的大小; size<v>::value == size<s1>::value + size<s2>::value; 线性复杂度; 参见 前向序列.

示例 

typedef joint_view<
      range_c<int,0,10>
    , range_c<int,10,15>
    > numbers;

BOOST_MPL_ASSERT(( equal< numbers, range_c<int,0,15> > ));

参见

序列, 视图, filter_view, transform_view, zip_view, iterator_range
