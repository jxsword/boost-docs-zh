erase_key

概要

template<
      typename AssocSeq
    , typename Key
    >
struct erase_key
{
    typedef unspecified type;
};

说明

擦除与键 Key 相关联的元素, 位于 可扩展关联序列 AssocSeq 中.

Header

#include <boost/mpl/erase_key.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
AssocSeq 可扩展关联序列 要从中擦除元素的序列.
Key Any type 要移除元素的键.

表达式语义

对任意 可扩展关联序列 s 与任意类型 key:

typedef erase_key<s,key>::type r;
Return type:可扩展关联序列.
语义:r 是 概念等同 于 s 且与之等价的, 除了 has_key<r,k>::value == false.
Postcondition:size<r>::value == size<s>::value - 1.

复杂度

摊还常量时间.

示例 

typedef map< pair<int,unsigned>, pair<char,long> > m;
typedef erase_key<m,char>::type m1;

BOOST_MPL_ASSERT_RELATION( size<m1>::type::value, ==, 1 );
BOOST_MPL_ASSERT(( is_same< at<m1,char>::type,void_ > ));
BOOST_MPL_ASSERT(( is_same< at<m1,int>::type,unsigned > ));

参见

可扩展关联序列, erase, has_key, insert
