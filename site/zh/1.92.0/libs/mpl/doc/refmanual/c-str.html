c_str

概要

template<
      typename Sequence
    >
struct c_str
{
    typedef unspecified type;
    static char const value[];
};

说明

c_str 把由 整型常量 组成的 前向序列 Sequence 转换为一个包含等价序列的空终止字节字符串.

Header

#include <boost/mpl/string.hpp>

模型

Metafunction

Parameters

参数 要求 说明
Sequence 前向序列 (由 整型常量 组成) 要转换为空终止字节字符串的序列.

表达式语义

对任意 前向序列 (由 整型常量 组成) s,

c_str<s>::value;
Return type:

一个空终止字节字符串.
Precondition:

size<s>::value <= BOOST_MPL_STRING_MAX_LENGTH.
语义:

等价于

char const value[] = {
    at<s, 0>::type::value
  , ...
  , at<s, size<s>::value-1>::type::value
  , '\0'
};

复杂度

序列原型 复杂度
Forward Sequence 线性复杂度.

示例 

typedef vector_c<char,'h','e','l','l','o'> hello;
assert( 0 == std::strcmp( c_str<hello>::value, "hello" ) );

参见

前向序列, 整型常量, string
