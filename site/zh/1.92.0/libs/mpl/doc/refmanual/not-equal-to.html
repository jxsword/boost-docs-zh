not_equal_to

概要

template<
      typename T1
    , typename T2
    >
struct not_equal_to
{
    typedef unspecified type;
};

说明

返回一个取值为真的 整型常量, 若 T1 与 T2 不相等.

Header

#include <boost/mpl/not_equal_to.hpp>
#include <boost/mpl/comparison.hpp>

模型

数值元函数

Parameters

参数 要求 说明
T1, T2 整型常量 运算的参数.

[注释: 本规范列出的要求是默认实现所施加的要求. 有关如何为不满足 整型常量 要求的用户自定义数值类型提供实现, 参见 数值元函数 概念中的详细说明. — 注毕]

表达式语义

对任意 整型常量 c1 和 c2:

typedef not_equal_to<c1,c2>::type r;
Return type:

整型常量.
语义:

等价于

typedef bool_< (c1::value != c2::value) > r;

typedef not_equal_to<c1,c2> r;
Return type:

整型常量.
语义:

等价于

struct r : not_equal_to<c1,c2>::type {};

复杂度

摊还常量时间.

示例 

BOOST_MPL_ASSERT(( not_equal_to< int_<0>, int_<10> > ));
BOOST_MPL_ASSERT(( not_equal_to< long_<10>, int_<0> > ));
BOOST_MPL_ASSERT_NOT(( not_equal_to< long_<10>, int_<10> > ));

参见

比较运算, 数值元函数, numeric_cast, equal_to, less
