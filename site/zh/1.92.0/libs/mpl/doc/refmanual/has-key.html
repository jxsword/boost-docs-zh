has_key

概要

template<
      typename Sequence
    , typename Key
    >
struct has_key
{
    typedef unspecified type;
};

说明

返回一个取值为真的 整型常量, 若 Sequence 包含一个键为 Key 的元素.

Header

#include <boost/mpl/has_key.hpp>

模型

标签分发元函数

Parameters

参数 要求 说明
Sequence Associative Sequence 要查询的序列.
Key Any type The queried key.

表达式语义

对任意 关联序列 s 与任意类型 key:

typedef has_key<s,key>::type c;
Return type:布尔 整型常量.
语义:c::value == true, 若 key 在 s 的键集合中; 否则 c::value == false.

复杂度

摊还常量时间.

示例 

typedef map< pair<int,unsigned>, pair<char,long> > m;
BOOST_MPL_ASSERT_NOT(( has_key<m,long> ));

typedef insert< m, pair<long,unsigned long> > m1;
BOOST_MPL_ASSERT(( has_key<m1,long> ));

参见

关联序列, count, insert, erase_key
