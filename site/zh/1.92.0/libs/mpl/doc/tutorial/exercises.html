练习

1-0.
使用 BOOST_STATIC_ASSERT 为 binary 模板 (1.4.1 节给出) 添加错误检查, 使得 binary<N>::value 在 N 包含 0 或 1 以外的数字时引发编译错误.
1-1.
使用 transform 把 vector_c<int,1,2,3> 变换为元素为 (2,3,4) 的类型序列.
1-2.
使用 transform 把 vector_c<int,1,2,3> 变换为元素为 (1,4,9) 的类型序列.
1-3.
使用 twice 两次, 把 T 变成 T****.
1-4.
把 T 变成 T****, 方法是把 twice 作用于其自身.
1-5.

1.1 节的量纲分析代码仍有一个问题. 提示: 当你执行以下操作时会发生什么:

f = f + m * a;

使用本章展示的技术修复这个示例.

1-6.
构建一个功能等价于 twice 的 lambda 表达式. 提示: mpl::apply 是一个元函数!
1-7*.

你认为以下构造的语义会是什么:

typedef mpl::lambda<mpl::lambda<_1> >::type t1;
typedef mpl::apply<_1,mpl::plus<_1,_2> >::type t2;
typedef mpl::apply<_1,std::vector<int> >::type t3;
typedef mpl::apply<_1,std::vector<_1> >::type t4;
typedef mpl::apply<mpl::lambda<_1>,std::vector<int> >::type t5;
typedef mpl::apply<mpl::lambda<_1>,std::vector<_1> >::type t6;
typedef mpl::apply<mpl::lambda<_1>,mpl::plus<_1,_2> >::type t7;
typedef mpl::apply<_1,mpl::lambda< mpl::plus<_1,_2> > >::type t8;

展示得出答案的步骤, 并编写测试来验证你的假设. 库的行为与你的推理一致吗? 若不一致, 分析失败的测试以发现实际的表达式语义. 解释为什么你的假设有所不同, 你认为哪种行为更连贯, 以及为什么.

1-8*.
我们的量纲分析框架处理了量纲, 但完全忽略了单位问题. 长度可以用英寸、英尺或米表示. 力可以用牛顿或 kg m/sec2 表示. 添加指定单位的能力并测试你的代码. 尽量使你的接口对用户在语法上尽可能友好.
