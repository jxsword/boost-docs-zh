迭代器协议

库不再保证或依赖迭代器类型中直接存在 advance / distance / next / prior / type 成员; 下表总结了新的要求:

Before 现在
i::type deref<i>::type
i::next next<i>::type
i::prior prior<i>::type
i::advance<n>::type advance<i,n>::type
i::distance<j>::type distance<i,j>::type
i::category i::category
