处理占位符

我们的 twice 实现已经可以与元函数类协作. 理想情况下, 我们希望它也能与占位符表达式协作, 与 mpl::transform 允许我们传递任一形式相差无几. 例如, 我们希望能这样写:

template <class X>
struct two_pointers
    : twice<boost::add_pointer<_1>, X>
{};

但当我们查看 boost::add_pointer 的实现时, 就会明白 twice 的当前定义无法那样工作.

template <class T>
struct add_pointer
{
    typedef T* type;
};

要能被 twice 调用, boost::add_pointer<_1> 必须是元函数类, 类似 add_pointer_f. 然而, 它只是一个零元元函数, 返回近乎无意义的类型 _1*. 任何使用 two_pointers 的尝试都会失败: 当 apply1 在 boost::add_pointer<_1> 中寻找嵌套的 ::apply 元函数时, 会发现它并不存在.

我们已经确定无法自动得到想要的行为, 那么下一步呢? 既然 mpl::transform 能做这类事情, 应当也有办法让我们做到——而且确实有.

  • apply 元函数
