高阶元函数

在上一节中, 我们使用了两种不同的形式——元函数类和占位符表达式——来像传递其他元数据一样传递和返回元函数. 把元函数打包为 "一等元数据" 使 transform 能够执行无限多样的不同操作: 在我们的例子中是量纲的乘法和除法. 尽管用函数操纵其他函数的想法看似简单, 但其巨大的威力和灵活性 [Hudak89] 为它赢得了一个华丽的名称: 高阶函数式编程. 操作另一个函数的函数被称为高阶函数. 由此可知, transform 是一个高阶元函数: 操作另一个元函数的元函数.

[Hudak89]Paul Hudak. "Conception, Evolution, and Application of Functional Programming Languages," ACM Computing Surveys 21, no. 3 Pages: 359 - 411. New York: ACM Press. 1989. ISSN:0360-0300. http://doi.acm.org/10.1145/72551.72554.

见识过高阶元函数的威力之后, 能够创建新的高阶元函数就很有意义了. 为了探究其基本机制, 我们来试一个简单的例子. 我们的任务是编写一个名为 twice 的元函数, 它——给定一元元函数 f 和任意元数据 x——计算:

twice(f, x) := f(f(x))

这看起来像是一个平凡的例子, 实际上也确实是. 在真实的代码中你不会找到 twice 的太多用武之地. 但我们希望你耐着性子看下去: 由于 twice 除了接受并调用一个元函数之外几乎不做别的, 它恰好捕捉了 "高阶性" 的全部要素, 而没有任何干扰性的细节.

若 f 是元函数类, twice 的定义很直白:

template <class F, class X>
struct twice
{
    typedef typename F::template apply<X>::type once;    // f(x)
    typedef typename F::template apply<once>::type type; // f(f(x))
};

或者, 应用元函数转发:

template <class F, class X>
struct twice
  : F::template apply<
       typename F::template apply<X>::type
    >
{};

C++ 语言注记

C++ 标准要求: 必须加上 template 关键字, 只要我们使用引用成员模板的依赖名称. F::apply 是否命名一个模板, 取决于传入的具体 F. 更多信息参见本书的附录 B 中关于 template 的介绍.

鉴于需要在我们代码中到处撒上 template 关键字, 减轻调用元函数类的语法负担会很有帮助. 与往常一样, 解决方案是把该模式提取为一个元函数:

template <class UnaryMetaFunctionClass, class Arg>
struct apply1
  : UnaryMetaFunctionClass::template apply<Arg>
{};

现在 twice 只是:

template <class F, class X>
struct twice
  : apply1<F, typename apply1<F,X>::type>
{};

要观察 twice 的实际工作, 我们可以把它应用到一个围绕 add_pointer 元函数构建的小元函数类上:

struct add_pointer_f
{
    template <class T>
    struct apply : boost::add_pointer<T> {};
};

现在我们可以把 twice 与 add_pointer_f 一起使用来构建指针的指针:

BOOST_STATIC_ASSERT((
    boost::is_same<
         twice<add_pointer_f, int>::type
       , int**
    >::value
));
