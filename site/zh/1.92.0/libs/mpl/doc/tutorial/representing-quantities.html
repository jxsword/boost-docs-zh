表示量

上面列出的类型仍是纯粹的元数据; 要对真实计算进行类型检查, 我们需要以某种方式把它们绑定到运行期数据. 一个简单的数值包装器, 以数字类型 T 及其量纲为参数, 正合所需:

template <class T, class Dimensions>
struct quantity
{
    explicit quantity(T x)
       : m_value(x)
    {}

    T value() const { return m_value; }
 private:
    T m_value;
};

现在我们有办法表示与量纲相关联的数字了. 例如, 我们可以说:

quantity<float,length> l( 1.0f );
quantity<float,mass> m( 2.0f );

注意, Dimensions 在 quantity 定义中除了模板参数列表之外没有出现在任何地方; 它的唯一作用是确保 l 和 m 具有不同的类型. 正因如此, 我们不会犯把长度赋给质量的错误:

m = l;    // compile-time type error
