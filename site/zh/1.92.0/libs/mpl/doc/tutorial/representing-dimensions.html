表示量纲

一个名为 Système International d'Unites (国际单位制, SI) 的国际标准把每个量分解为质量、长度 (或位置)、时间、电荷、温度、发光强度和角度这些量纲的组合. 为了具备合理的普适性, 我们的系统必须能够表示七个或更多基本量纲. 它还需要能够表示复合量纲, 比如像力这样通过基本量纲的乘除构建的量纲.

一般而言, 复合量纲是基本量纲幂的乘积. [1] 如果要在运行期表示并操纵这些幂, 我们可以用一个由七个 int 组成的数组, 数组的每个位置存放不同基本量纲的幂:

typedef int dimension[7]; // m  l  t  ...
dimension const mass      = {1, 0, 0, 0, 0, 0, 0};
dimension const length    = {0, 1, 0, 0, 0, 0, 0};
dimension const time      = {0, 0, 1, 0, 0, 0, 0};
...
[1]除数只贡献负指数, 因为 1/x = x-1.

在这种表示下, 力将是:

dimension const force  = {1, 1, -2, 0, 0, 0, 0};

即 mlt-2. 但是, 如果我们想把量纲纳入类型系统, 这些数组是不行的: 它们全都是同一类型! 相反, 我们需要自身表示数字序列的类型, 使两个质量具有相同类型, 而质量与长度是不同的类型.

所幸, MPL 为我们提供了一组类型序列. 例如, 我们可以这样构建内建有符号整型类型的序列:

#include <boost/mpl/vector.hpp>

typedef boost::mpl::vector<
     signed char, short, int, long> signed_types;

如何用类型序列表示数字? 正如数值元函数传递并返回包装类型 (它们带有嵌套的 ::value) 一样, 数值序列实际上是包装类型的序列 (多态的另一个例子). 为了让这类事情更容易, MPL 提供了 int_<N> 类模板, 它把其整型实参呈现为嵌套的 ::value:

#include <boost/mpl/int.hpp>

namespace mpl = boost::mpl; // namespace alias
static int const five = mpl::int_<5>::value;

命名空间别名

namespace alias = namespace-name;

声明 alias 为 namespace-name 的同义词. 本书的许多示例会用 mpl:: 来指代 boost::mpl::, 但会省略使其成为合法 C++ 的别名声明.

事实上, 库包含了一整套整型常量包装器, 如 long_ 和 bool_, 每一个都在类模板中包装不同类型的整型常量.

现在我们可以构建基本量纲了:

typedef mpl::vector<
   mpl::int_<1>, mpl::int_<0>, mpl::int_<0>, mpl::int_<0>
 , mpl::int_<0>, mpl::int_<0>, mpl::int_<0>
> mass;

typedef mpl::vector<
   mpl::int_<0>, mpl::int_<1>, mpl::int_<0>, mpl::int_<0>
 , mpl::int_<0>, mpl::int_<0>, mpl::int_<0>
> length;
...

呼! 这样下去很快就会变得很累. 更糟的是, 它难以阅读和验证: 关键信息——每个基本量纲的幂——被淹没在重复的语法 "噪声" 中. 因此, MPL 提供了整型序列包装器, 让我们可以这样写:

#include <boost/mpl/vector_c.hpp>

typedef mpl::vector_c<int,1,0,0,0,0,0,0> mass;
typedef mpl::vector_c<int,0,1,0,0,0,0,0> length; // or position 
typedef mpl::vector_c<int,0,0,1,0,0,0,0> time;
typedef mpl::vector_c<int,0,0,0,1,0,0,0> charge;
typedef mpl::vector_c<int,0,0,0,0,1,0,0> temperature;
typedef mpl::vector_c<int,0,0,0,0,0,1,0> intensity;
typedef mpl::vector_c<int,0,0,0,0,0,0,1> angle;

尽管类型不同, 你可以把这些 mpl::vector_c 特化视为等价于上面使用 mpl::vector 的更冗长版本.

如果愿意, 我们还可以定义几个复合量纲:

// base dimension:        m l  t ... 
typedef mpl::vector_c<int,0,1,-1,0,0,0,0> velocity;     // l/t
typedef mpl::vector_c<int,0,1,-2,0,0,0,0> acceleration; // l/(t2)
typedef mpl::vector_c<int,1,1,-1,0,0,0,0> momentum;     // ml/t
typedef mpl::vector_c<int,1,1,-2,0,0,0,0> force;        // ml/(t2)

顺带一提, 标量 (比如 pi) 的量纲可以描述为:

typedef mpl::vector_c<int,0,0,0,0,0,0,0> scalar;
