apply 元函数

调用 lambda 的结果是一个如此常见的模式, 以至于 MPL 提供了 apply 元函数专门来做这件事. 使用 mpl::apply, 我们灵活版的 twice 变为:

#include <boost/mpl/apply.hpp>

template <class F, class X>
struct twice
   : mpl::apply<F, typename mpl::apply<F,X>::type>
{};

你可以把 mpl::apply 想成与我们写的 apply1 模板一样, 只是多了两个特性:

  1. apply1 只能作用于元函数类, 而 mpl::apply 的第一个实参可以是任何 lambda 表达式 (包括用占位符构建的那些).

  2. apply1 只接受一个附加实参供元函数类应用, 而 mpl::apply 可以以零到五个附加实参中的任意数量调用其第一个实参. [5] 例如:

    // binary lambda expression applied to 2 additional arguments
mpl::apply<
    mpl::plus<_1,_2>   
  , mpl::int_<6>
  , mpl::int_<7>
>::type::value // == 13
[5]参见the MPL reference manual 的 Configuration Macros 一节, 了解如何更改 mpl::apply 所处理实参的最大数量.

准则

编写会调用其实参之一的元函数时, 请使用 mpl::apply, 以使其能与 lambda 表达式协作.
