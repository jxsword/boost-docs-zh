lambda 与非元函数模板

占位符表达式还有一个我们尚未讨论的细节. MPL 使用一条特殊规则, 使普通模板更容易集成到元程序中: 在所有占位符被替换为实际实参之后, 若所得的模板特化 X 没有嵌套的 ::type, 则结果就是 X 本身.

例如, mpl::apply<std::vector<_>, T> 永远就是 std::vector<T>. 若没有这一行为, 我们将不得不构建平凡的元函数, 才能在 lambda 表达式中创建普通模板特化:

// trivial std::vector generator
template<class U> 
struct make_vector { typedef std::vector<U> type; };

typedef mpl::apply<make_vector<_>, T>::type vector_of_t;

相反, 我们可以简单地写:

typedef mpl::apply<std::vector<_>, T>::type vector_of_t;
