数值元函数协议/基础设施

算术、比较和按位元函数现在是多态的, 可以作用于多种数值类型, 包括有理数、定点数和复数. 它们支持混合算术, 即可以对不同类型的实参执行运算, 结果将给出实参类型中最大/最一般的类型. 该基础设施允许用户自定义数值类型与预定义库类型自由混用. 示例参见 libs/mpl/test/numeric_ops.cpp, 正式的基础设施规范参见参考手册.

如果你曾在自己的、类似于 mpl::int_ 的整型包装类上使用 MPL 数值元函数, 可以通过为你的类扩展以下成员来把它接入新基础设施:

typedef mpl::integral_c_tag tag;

例如:

Before 现在 
template< int n > struct my_int
{
    static int const value = n;
    typedef my_int type;
};

template< int n > struct my_int
{
    typedef mpl::integral_c_tag tag;
    static int const value = n;
    typedef my_int type;
};
