量纲分析

在纸上进行物理计算的第一条规则是: 被操纵的数字并非孤立存在: 大多数量都带有量纲, 无视它们后果自负. 随着计算变得愈发复杂, 跟踪量纲正是防止我们不经意地把质量赋给本应是长度的量、或把加速度加到速度上的手段——它为数字建立了一套类型系统.

人工检查类型既繁琐, 又容易出错. 人在厌倦时注意力会涣散, 往往犯错误. 不过, 类型检查难道不正是计算机擅长的工作吗? 如果能为量纲和量建立一个 C++ 类型框架, 我们也许能在公式中的错误对现实世界造成严重问题之前捕获它们.

防止不同量纲的量互操作并不难; 我们只需把量纲表示为只与同类型量纲协作的类. 这个问题的有趣之处在于, 不同量纲可以通过乘法或除法组合, 产生任意复杂的新量纲. 例如, 考虑把力与质量和加速度联系起来的牛顿定律:

F = ma

由于质量和加速度量纲不同, 力的量纲必须以某种方式捕捉它们的组合. 事实上, 加速度的量纲本身已经是这样一个复合量纲: 速度随时间的变化率:

dv/dt

由于速度只是距离 (l) 随时间 (t) 的变化率, 加速度的基本量纲是:

(l/t)/t = l/t2

确实, 加速度通常以 "米每二次方秒" 度量. 由此可知, 力的量纲必为:

ml/t2

而力通常以 kg(m/s2), 即 "千克·米每二次方秒" 度量. 当质量量与加速度量相乘时, 我们也把它们的量纲相乘并携带结果, 这有助于我们确保结果是有意义的. 这种簿记的正式名称是 量纲分析, 我们的下一个任务将是在 C++ 类型系统中实现其规则. John Barton 和 Lee Nackman 在其开创性著作 Scientific and Engineering C++ [BN94] 中率先展示了如何做到这一点. 我们将在这里以元编程的术语重述他们的方法.
