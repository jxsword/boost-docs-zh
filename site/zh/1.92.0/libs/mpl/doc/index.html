Boost.MPL 库是一个通用的、高层的 C++ 模板元编程框架, 包含编译期算法、序列和元函数. 它提供了概念基础和一整套强大而连贯的工具, 使显式元编程在当前语言允许的范围内尽可能简单、愉快.

熟悉这个库可以从几个不同的起点入手, 取决于你对一般元编程、特别是 C++ 模板元编程的了解程度. 从 Boost 1.32 版开始, MPL 同时附带了讲解其基本概念的深入教程和覆盖库中全部概念与组件的带注释参考手册. 虽然教程只揭示了 C++ 元编程和 MPL 的冰山一角, 但如果你对这个主题只有初步了解, 它是绝佳的起点. 至少, 在读完教程之后, 你能够把这里出现的其余内容放入相应的上下文中. 如果你计划——或者已经在——用这个库进行实际的开发, 参考手册就是最核心的资源; 不过随意翻阅也完全可以, 并且很可能让你对该框架的组织方式和底层思想获得许多洞见. 最后, 你在本文档顶部看到的下面这些高亮的一级章节, 或许也会提供一些有意思的内容.

那么, 欢迎你, 祝元编程愉快!

重要:
自上次公开发布以来, 库的接口发生了一些重大变化, 其中许多都不向后兼容. 如果你是 MPL 的老用户, 请做好在升级后修改代码的准备. 有关这些变更的详细信息, 请参阅 1.32 版变更日志.
