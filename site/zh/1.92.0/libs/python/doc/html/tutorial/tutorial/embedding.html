嵌入

使用解释器

至此, 你应当已经知道如何使用 Boost.Python 从 Python 调用你的 C++ 代码. 然而, 有时你可能需要反其道而行: 从 C++ 侧调用 Python 代码. 这要求你把 Python 解释器嵌入你的 C++ 程序.

目前, Boost.Python 并不直接支持嵌入时你需要的所有东西. 因此你需要使用 Python/C API 来填补空缺. 不过, Boost.Python 已经让嵌入容易得多, 并且在未来版本中, 可能完全无需接触 Python/C API. 敬请期待……

构建嵌入程序

为了能把 Python 嵌入你的程序, 你必须同时链接 Boost.Python 的库和 Python 自身的运行库.

Boost.Python 的库有两种变体. 两者都位于 Boost 的 /libs/python/build/bin-stage 子目录中. 在 Windows 上, 这些变体分别名为 boost_python.lib (用于 release 构建) 和 boost_python_debug.lib (用于调试). 如果找不到这些库, 你可能还没有构建 Boost.Python. 关于如何构建, 参见构建与测试.

Python 的库可以在你的 Python 目录的 /libs 子目录中找到. 在 Windows 上它名为 pythonXY.lib, 其中 X.Y 是你的 Python 主版本号.

此外, 还必须把 Python 的 /include 子目录加入你的包含路径.

在 Jamfile 中, 以上所有内容归结为:

projectroot c:\projects\embedded_program ; # location of the program

# bring in the rules for python
SEARCH on python.jam = $(BOOST_BUILD_PATH) ;
include python.jam ;

exe embedded_program # name of the executable
  : #sources
     embedded_program.cpp
  : # requirements
     <find-library>boost_python <library-path>c:\boost\libs\python
  $(PYTHON_PROPERTIES)
    <library-path>$(PYTHON_LIB_PATH)
    <find-library>$(PYTHON_EMBEDDED_LIBRARY) ;

开始上手

能够构建固然好, 但还没有东西可构建. 把 Python 解释器嵌入你的某个 C++ 程序需要以下 4 个步骤:

  1. #include <boost/python.hpp>
  2. 调用 Py_Initialize() 启动解释器并创建 __main__ 模块.
  3. 调用其他 Python C API 例程来使用解释器.
注释

注意, 目前你不应调用 Py_Finalize() 来停止解释器. 这可能会在未来版本的 boost.python 中修正.

(当然, 在这些步骤之间可以穿插其他 C++ 代码.)

既然可以把解释器嵌入我们的程序, 让我们看看如何把它用起来……

使用解释器

你可能已经知道, Python 中的对象是引用计数的. 自然, Python C API 的 PyObject 也是引用计数的. 不过有一点不同: 虽然 Python 中引用计数完全自动, Python C API 却要求你手动完成. 这很麻烦, 且在有 C++ 异常的情况下尤其难以做对. 幸好 Boost.Python 提供了 handle 和 object 类模板来自动完成这一过程.

运行 Python 代码

Boost.Python 提供三个相关函数来从 C++ 运行 Python 代码.

object eval(str expression, object globals = object(), object locals = object())
object exec(str code, object globals = object(), object locals = object())
object exec_file(str filename, object globals = object(), object locals = object())

eval 求值给定表达式并返回结果值. exec 执行给定代码 (通常是一组语句) 并返回结果, 而 exec_file 执行给定文件中包含的代码.

还有一些重载以 char const* 而非 str 作为第一个参数.

globals 和 locals 参数是 Python 字典, 包含运行代码所在上下文的全局与局部名称. 对大多数用途而言, 两个参数都可以使用 __main__ 模块的命名空间字典.

Boost.Python 提供一个导入模块的函数:

object import(str name)

import 导入一个 Python 模块 (可能先把它加载进运行中的进程), 并返回它.

让我们导入 __main__ 模块, 并在其命名空间中运行一些 Python 代码:

object main_module = import("__main__");
object main_namespace = main_module.attr("__dict__");

object ignored = exec("hello = file('hello.txt', 'w')\n"
                      "hello.write('Hello world!')\n"
                      "hello.close()",
                      main_namespace);

这应当在当前目录中创建一个名为 'hello.txt' 的文件, 内含编程圈子里人尽皆知的一句话.

操纵 Python 对象

我们常常希望有一个类来操纵 Python 对象. 但这样的类我们在上文以及前一节中已经见过: 名副其实的 object 类及其派生类. 我们已经看到它们可以从 handle 构造. 下面的例子将进一步说明这一点:

object main_module = import("__main__");
object main_namespace = main_module.attr("__dict__");
object ignored = exec("result = 5 ** 2", main_namespace);
int five_squared = extract<int>(main_namespace["result"]);

这里我们为 __main__ 模块的命名空间创建一个字典对象. 然后把 5 的平方赋给 result 变量, 并从字典中读取该变量. 达到同样结果的另一种方法是改用 eval, 它直接返回结果:

object result = eval("5 ** 2");
int five_squared = extract<int>(result);

Exception handling

如果 Python 表达式求值时发生异常, 会抛出 error_already_set:

try
{
    object result = eval("5/0");
    // execution will never get here:
    int five_divided_by_zero = extract<int>(result);
}
catch(error_already_set const &)
{
    // handle the exception in some way
}

error_already_set 异常类本身不携带任何信息. 要进一步了解发生的 Python 异常, 你需要在 catch 语句中使用 Python C API 的异常处理函数. 这可以简单到调用 PyErr_Print() 把异常的回溯打印到控制台, 或把异常类型与标准异常的类型比较:

catch(error_already_set const &)
{
    if (PyErr_ExceptionMatches(PyExc_ZeroDivisionError))
    {
        // handle ZeroDivisionError specially
    }
    else
    {
        // print all other errors to stderr
        PyErr_Print();
    }
}

(要从异常中获取更多信息, 可以使用此处列出的其他异常处理函数.)
