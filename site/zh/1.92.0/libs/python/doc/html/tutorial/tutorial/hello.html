构建 Hello World

从头到尾

现在你想做的第一件事就是构建 Hello World 模块, 并亲自在 Python 中试用. 本节将概述实现这一点所需的步骤. 我们将使用每个 boost 发行版都自带的构建工具: bjam.

注释

不用 bjam 构建

除了 bjam, 当然还有其他办法构建你的模块. 这里所写的不应被当作 "唯一的方法". 除了 bjam 当然还有其他构建工具.

但请注意, Boost.Python 首选的构建工具是 bjam. 把构建设置弄错的办法实在太多. 经验表明, 90% 的 "我无法构建 Boost.Python" 问题出自不得不使用其他工具的人.

我们将略过细节. 我们的目标只是创建 hello world 模块并在 Python 中运行它. 关于构建 Boost.Python 的完整参考, 请查阅: building.html. 经过这篇简短的 bjam 教程, 我们应当已经构建出 DLL 并运行了使用该扩展的 Python 程序.

教程示例可在目录 libs/python/example/tutorial 中找到. 在那里, 你可以找到:

  • hello.cpp
  • hello.py
  • Jamroot

hello.cpp 文件是我们的 C++ hello world 示例. Jamroot 是一个极简的 bjam 脚本, 为我们构建 DLL. 最后, hello.py 是我们的 Python 程序, 它使用 hello.cpp 中的扩展.

首先, 你的 boost 目录或路径中的某处应当有 bjam 可执行文件, 使 bjam 能在命令行中执行. 预构建的 Boost.Jam 可执行文件适用于大多数平台. Bjam 可执行文件的完整清单可在此处找到.

来玩 Jam!

这里是我们的极简 Jamroot 文件. 只需复制该文件, 把 use-project boost 调整为你的 boost 根目录所在位置即可.

上面 Jamroot 文件中的注释应当足以让你上手.

运行 bjam

bjam 通过你操作系统的命令行解释器运行.

启动它.

主目录中一个名为 user-config.jam 的文件用于配置你的工具. 在 Windows 中, 输入以下命令可以找到你的主目录:

ECHO %HOMEDRIVE%%HOMEPATH%

到命令提示符窗口. 你的文件至少应当包含你的编译器和 Python 安装的规则. Windows 上的一个具体例子是:

#  MSVC configuration
using msvc : 8.0 ;

#  Python configuration
using python : 2.4 : C:dev/tools/Python ;

第一条规则告诉 Bjam 使用 MSVC 8.0 编译器及相关工具. 第二条规则提供关于 Python、其版本及其位置的信息. 上面假定 Python 安装在 C:dev/tools\/Python. 如果你的平台上有一个相当 "标准" 的 Python 安装, 你可能不需要这样做.

现在我们准备好了…… 确保通过 cd 进入 libs/python/example/tutorial——教程 "hello.cpp" 和 "Jamroot" 所在之处.

最后:

bjam

现在应当正在构建:

cd C:\dev\boost\libs\python\example\tutorial
bjam
...patience...
...found 1101 targets...
...updating 35 targets...

等等…… 最后:

   Creating library path-to-boost_python.dll
   Creating library /path-to-hello_ext.exp/
**passed** ... hello.test
...updated 35 targets...

或类似的内容. 如果一切顺利, 你现在应当已经构建出 DLL 并运行了 Python 程序.

大功告成…… 玩得开心!
