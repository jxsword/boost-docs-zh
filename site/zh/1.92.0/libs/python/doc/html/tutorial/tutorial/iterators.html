迭代器

在 C++ 中, 尤其在 STL 中, 迭代器无处不在. Python 也有迭代器, 但这是两种截然不同的东西.

C++ 迭代器:

  • C++ 有 5 个类型类别 (随机访问、双向、前向、输入、输出)
  • 有 2 个操作类别: 重新定位、访问
  • 需要一对迭代器来表示 (首/尾) 区间.

Python 迭代器:

  • 1 个类别 (前向)
  • 1 个操作类别 (next())
  • 在末尾引发 StopIteration 异常

典型的 Python 迭代协议 for y in x... 如下:

iter = x.__iter__()         # get iterator
try:
    while 1:
    y = iter.next()         # get each item
    ...                     # process y
except StopIteration: pass  # iterator exhausted

Boost.Python 提供一些机制, 使 C++ 迭代器能作为 Python 迭代器良好运作. 我们需要做的是从 C++ 迭代器生成与 Python 迭代协议兼容的适当的 __iter__ 函数. 例如:

object get_iterator = iterator<vector<int> >();
object iter = get_iterator(v);
object first = iter.next();

或在 class_<> 中使用:

.def("__iter__", iterator<vector<int> >())

range

我们可以用 range 函数创建一个懂 Python 的迭代器:

  • range(start, finish)
  • range<Policies,Target>(start, finish)

这里, start/finish 可以是以下之一:

  • 成员数据指针
  • 成员函数指针
  • 可适配的函数对象 (使用 Target 参数)

iterator

  • iterator<T, Policies>()

给定容器 T, iterator 是一个捷径, 只是用 &T::begin 和 &T::end 调用 range.

让我们实际运用…… 下面是一个来自某个假想的 bogon 粒子加速器代码的例子:

f = Field()
for x in f.pions:
    smash(x)
for y in f.bogons:
    count(y)

现在, 我们的 C++ 包装器:

class_<F>("Field")
    .property("pions", range(&F::p_begin, &F::p_end))
    .property("bogons", range(&F::b_begin, &F::b_end));

stl_input_iterator

到目前为止, 我们已经看到如何把 C++ 迭代器和区间暴露给 Python. 不过, 有时我们想反其道而行: 我们想把 Python 序列传给 STL 算法, 或用它初始化 STL 容器. 我们需要让 Python 迭代器看起来像 STL 迭代器. 为此, 我们使用 stl_input_iterator<>. 考虑我们可能如何实现一个把 std::list<int>::assign() 暴露给 Python 的函数:

template<typename T>
void list_assign(std::list<T>& l, object o) {
    // Turn a Python sequence into an STL input range
    stl_input_iterator<T> begin(o), end;
    l.assign(begin, end);
}

// Part of the wrapper for list<int>
class_<std::list<int> >("list_int")
    .def("assign", &list_assign<int>)
    // ...
    ;

现在在 Python 中, 我们可以把任何整数序列赋给 list_int 对象:

x = list_int();
x.assign([1,2,3,4,5])
