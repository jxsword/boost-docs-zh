快速入门

Boost Python 库是一个连接 Python 与 C++ 的框架. 它让你无需任何特殊工具——只用你的 C++ 编译器——就能快速而无缝地把 C++ 类、函数和对象暴露给 Python, 反之亦然. 它设计为以非侵入方式包装 C++ 接口, 因此为了包装你完全不必修改 C++ 代码, 这使 Boost.Python 成为向 Python 暴露第三方库的理想选择. 该库对高级元编程技术的运用为用户简化了语法, 使包装代码呈现出一种声明式接口定义语言 (IDL) 的样子.

Hello World

遵循 C/C++ 的传统, 让我们从 "hello, world" 开始. 一个 C++ 函数:

char const* greet()
{
   return "hello, world";
}

可以通过编写一个 Boost.Python 包装器暴露给 Python:

#include <boost/python.hpp>

BOOST_PYTHON_MODULE(hello_ext)
{
    using namespace boost::python;
    def("greet", greet);
}

就是这样, 大功告成. 我们现在可以把它构建为共享库. 得到的 DLL 现在对 Python 可见. 下面是一个 Python 会话示例:

>>> import hello_ext
>>> print hello_ext.greet()
hello, world
