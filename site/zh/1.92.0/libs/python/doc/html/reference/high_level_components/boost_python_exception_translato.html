boost/python/exception_translator.hpp

函数 register_exception_translator
Example

引言

如此处所述, 必须确保 C++ 代码抛出的异常不会进入 Python 解释器核心. 默认情况下, Boost.Python 把被包装函数和模块初始化函数抛出的所有 C++ 异常转换为 Python 异常, 但默认转换器极为有限: 大多数 C++ 异常在 Python 中会表现为一个表示为 'Unidentifiable C++ Exception' 的 RuntimeError 异常. 为了产生更好的错误消息, 用户可以按下文所述注册额外的异常转换器.

函数 register_exception_translator 

template<class ExceptionType, class Translate>
void register_exception_translator(Translate translate);

Requires

Translate 必须可复制构造 (CopyConstructible), 且以下代码必须是良构的:

void f(ExceptionType x) { translate(x); }

. 表达式 translate(x) 必须要么抛出一个 C++ 异常, 要么随后对 PyErr_Occurred() 的调用必须返回 1.

效果

把 translate 的副本添加到异常转换器序列, 当 Boost.Python 捕获一个即将进入 Python 核心解释器的异常时, 会依次尝试这些转换器. 新转换器将优先获得对与上述 catch 子句匹配的所有异常的 "首次尝试" 机会. 任何随后注册的转换器将被允许更早地转换该异常. 无法转换某个给定 C++ 异常的转换器可以重新抛出它, 它将由更早注册的转换器 (或默认转换器) 处理.

Example 

#include <boost/python/module.hpp>
#include <boost/python/def.hpp>
#include <boost/python/exception_translator.hpp>
#include <exception>

struct my_exception : std::exception
{
  char const* what() throw() { return "One of my exceptions"; }
};

void translate(my_exception const& e)
{
    // Use the Python 'C' API to set up an exception object
    PyErr_SetString(PyExc_RuntimeError, e.what());
}

void something_which_throws()
{
    ...
    throw my_exception();
    ...
}

BOOST_PYTHON_MODULE(exception_translator_ext)
{
  using namespace boost::python;
  register_exception_translator<my_exception>(&translate);

  def("something_which_throws", something_which_throws);
}
