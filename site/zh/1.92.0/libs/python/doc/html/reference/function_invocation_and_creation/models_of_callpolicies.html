类 default_call_policies

default_call_policies 是 CallPolicies 的一个模型, 没有 precall 或 postcall 行为, 其 result_converter 按值处理返回. 除非另有说明, 被包装的 C++ 函数和成员函数 use default_call_policies. 你可能会发现, 派生 CallPolicies 的新模型并以 default_call_policies 为基会很方便.

namespace boost { namespace python
{
    struct default_call_policies
    {
        static bool precall(PyObject*);
        static PyObject* postcall(PyObject*, PyObject* result);
        typedef default_result_converter result_converter;
        template <class Sig> struct extract_return_type : mpl::front<Sig>{};
    };
}}

类 default_result_converter

default_result_converter 是 ResultConverterGenerator 的一个模型, 可用于按值包装返回非指针类型的 C++ 函数, 包括 char const* 和 PyObject*.

namespace boost { namespace python
{
    struct default_result_converter
    {
        template <class T> struct apply;
    };
}}

类 default_result_converter 元函数

Requires

T 不是引用类型. 如果 T 是指针类型, 则 T 为 const char* 或 PyObject*.

Example

本示例来自 Boost.Python 实现本身. 由于 return_value_policy 类模板没有实现 precall 或 postcall 行为, 其默认基类是 default_call_policies:

template <class Handler, class Base = default_call_policies>
struct return_value_policy : Base
{
   typedef Handler result_converter;
};

{
   template <size_t arg_pos=1, class Base = default_call_policies>
   struct return_arg : Base
   {
      static PyObject* postcall(PyObject*, PyObject* result);
      struct result_converter{ template <class T> struct apply; };
      template <class Sig> struct extract_return_type : mpl::at_c<Sig, arg_pos>{};

   };
}}

Example

C++ 模块定义:

#include <boost/python/module.hpp>
#include <boost/python/class.hpp>
#include <boost/python/return_arg.hpp>

struct Widget
{
   Widget() :sensitive_(true){}
   bool get_sensitive() const { return sensitive_; }
   void set_sensitive(bool s) { this->sensitive_ = s; }
 private:
   bool sensitive_;
};

struct Label : Widget
{
   Label() {}

   std::string  get_label() const { return label_; }
   void set_label(const std::string &l){ label_ = l; }

 private:
   std::string label_;
};

using namespace boost::python;
BOOST_PYTHON_MODULE(return_self_ext)
{
   class_<widget>("Widget")
      .def("sensitive", &Widget::get_sensitive)
      .def("sensitive", &Widget::set_sensitive, return_self<>())
      ;

   class_<Label, bases<Widget> >("Label")
      .def("label", &Label::get_label)
      .def("label", &Label::set_label, return_self<>())
      ;
}

Python 代码:

>>> from return_self_ext import *
>>> l1 = Label().label("foo").sensitive(false)
>>> l2 = Label().sensitive(false).label("foo")

引言

return_internal_reference 实例是 CallPolicies 的模型, 它们允许安全地返回指向以下对象的指针和引用——由自由函数或成员函数参数内部持有的对象, 或成员函数的目标对象——而不复制所指对象. 其第一个模板参数的默认值处理常见情形, 即包含对象是被包装成员函数的目标 (*this).

类模板 return_internal_reference

参数

要求

说明

默认值

owner_arg

一个类型为 std::size_t 的正编译期常量.

包含被返回引用或指针所指向对象的参数的索引. 如果用于包装成员函数, 参数 1 是目标对象 (*this). 注意, 如果目标 Python 对象类型不支持弱引用, 当被包装的函数被调用时将引发 Python TypeError 异常.

Base

CallPolicies 的一个模型

用于策略组合. 它提供的任何 result_converter 都会被 return_internal_reference 覆盖, 但其 precall 与 postcall 策略会按这里 CallPolicies 所述进行组合.

default_call_policies 

namespace boost { namespace python
{
   template <std::size_t owner_arg = 1, class Base = default_call_policies>
   struct return_internal_reference : Base
   {
      static PyObject* postcall(PyObject*, PyObject* result);
      typedef reference_existing_object result_converter;
   };
}}

Example

C++ 模块定义:

#include <boost/python/module.hpp>
#include <boost/python/class.hpp>
#include <boost/python/return_internal_reference.hpp>

class Bar
{
 public:
   Bar(int x) : x(x) {}
   int get_x() const { return x; }
   void set_x(int x) { this->x = x; }
 private:
   int x;
};

class Foo
{
 public:
   Foo(int x) : b(x) {}

   // Returns an internal reference
   Bar const& get_bar() const { return b; }

 private:
   Bar b;
};

using namespace boost::python;
BOOST_PYTHON_MODULE(internal_refs)
{
   class_<Bar>("Bar", init<int>())
      .def("get_x", &Bar::get_x)
      .def("set_x", &Bar::set_x)
      ;

   class_<Foo>("Foo", init<int>())
      .def("get_bar", &Foo::get_bar
          , return_internal_reference<>())
      ;
}

Python 代码:

>>> from internal_refs import *
>>> f = Foo(3)
>>> b1 = f.get_bar()
>>> b2 = f.get_bar()
>>> b1.get_x()
3
>>> b2.get_x()
3
>>> b1.set_x(42)
>>> b2.get_x()
42

C++ 模块定义:

#include <boost/python/module.hpp>
#include <boost/python/class.hpp>
#include <boost/python/copy_const_reference.hpp>
#include <boost/python/return_value_policy.hpp>

// classes to wrap
struct Bar { int x; }

struct Foo {
   Foo(int x) : { b.x = x; }
   Bar const& get_bar() const { return b; }
 private:
   Bar b;
};

// Wrapper code
using namespace boost::python;
BOOST_PYTHON_MODULE(my_module)
{
   class_<Bar>("Bar");

   class_<Foo>("Foo", init<int>())
      .def("get_bar", &Foo::get_bar
          , return_value_policy<copy_const_reference>())
      ;
}

Python 代码:

>>> from my_module import *
>>> f = Foo(3)         # create a Foo object
>>> b = f.get_bar()    # make a copy of the internal Bar object

boost/python/with_custodian_and_ward.hpp

类 with_custodian_and_ward
类 with_custodian_and_ward 静态函数
类 with_custodian_and_ward_postcall
类 with_custodian_and_ward_postcall 静态函数
Example

引言

本头文件提供在函数的两个 Python 参数或结果对象之间建立生存期依赖关系的设施. 只要保管者 (custodian) 对象支持弱引用 (Boost.Python 扩展类全都支持弱引用), 被保管者 (ward) 对象就会在保管者之后才销毁. 如果保管者对象不支持弱引用且不是 None, 将抛出适当的异常. 两个类模板 with_custodian_and_ward 与 with_custodian_and_ward_postcall 的区别在于其生效的时间点.

为了减少无意中制造悬空指针的机会, 默认做法是在底层 C++ 对象被调用之前进行生存期绑定. 然而, 在调用之前结果对象尚不可用, 因此提供了 with_custodian_and_ward_postcall 以便在调用之后绑定生存期. 此外, 如果在 with_custodian_and_ward<>::precall 之后、底层 C++ 对象实际存储指针之前抛出了 C++ 异常, 保管者与被保管者对象的生存期将被人为地绑定在一起, 因此视被包装函数的语义, 你可能改为选择 with_custodian_and_ward_postcall.

请注意, 在包装跨越函数调用边界转移裸指针所有权的函数时, 这不是合适的工具. 如果你想那样做, 请参阅常见问题 (FAQ).
