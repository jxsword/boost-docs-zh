函数模板 implicit_convertible
Example

引言

implicitly_convertible 使 Boost.Python 在把 Python 对象匹配到 C++ 参数类型时, 能够隐式利用 C++ 的隐式或显式转换.

函数模板 implicit_convertible 

template <class Source, class Target>
void implicitly_convertible();

参数

说明

Source

隐式转换的源类型

Target

隐式转换的目标类型

Requires

声明 Target t(s); (其中 s 为 Source 类型) 是有效的.

效果

注册一个到 Target 的右值 from_python 转换器, 对任何 PyObject* p 都能成功——当且仅当存在任何能产生 Source 右值的已注册转换器

Rationale

C++ 用户期望在 Python 中获得与在 C++ 中相同的互操作能力.

Example

C++ 中:

#include <boost/python/class.hpp>
#include <boost/python/implicit.hpp>
#include <boost/python/module.hpp>

using namespace boost::python;

struct X
{
    X(int x) : v(x) {}
    operator int() const { return v; }
    int v;
};

int x_value(X const& x)
{
    return x.v;
}

X make_x(int n) { return X(n); }

BOOST_PYTHON_MODULE(implicit_ext)
{
    def("x_value", x_value);
    def("make_x", make_x);

    class_<X>("X",
        init<int>())
        ;

    implicitly_convertible<X,int>();
    implicitly_convertible<int,X>();
}

Python 中:

>>> from implicit_ext import *
>>> x_value(X(42))
42
>>> x_value(42)
42
>>> x = make_x(X(42))
>>> x_value(x)
42
