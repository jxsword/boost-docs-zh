引言

类型 T 的 ResultConverter 是一种类型, 其实例可用于转换类型为 T to_python 的 C++ 返回值. ResultConverterGenerator 是一个 MPL 一元元函数类, 给定 C++ 函数的返回类型, 它返回该类型的 ResultConverter. Boost.Python 中的 ResultConverter 通常会检查库的转换器注册表以找到合适的转换器, 但不使用注册表的转换器也是可能的.
