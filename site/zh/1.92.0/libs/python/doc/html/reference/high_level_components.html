引言

<boost/python/class.hpp> 定义了用户把 C++ 类暴露给 Python 所经由的接口. 它声明了 class_ 类模板, 该模板以被暴露的类类型为参数. 它还暴露了 init、optional 和 bases 实用类模板, 它们与 class_ 配合使用.

<boost/python/class_fwd.hpp> 包含 class_ 类模板的前向声明.

类模板 class_<T, Bases, HeldType, NonCopyable>

HeldType 语义
类模板 class_ 概要
类模板 class_ 构造函数
类模板 class_ 修饰函数

创建一个与作为其第一个参数传入的 C++ 类型相关联的 Python 类. 尽管它有四个模板参数, 但只有第一个是必需的. 三个可选参数实际上可以以任意顺序提供; Boost.Python 从参数的类型判断其角色.

模板参数

要求

语义

默认值

T

A class type.

被包装的类

Bases

bases<...> 的一个特化, 指定 T 之前已暴露的 C++ 基类.

注册 from_python 转换, 从被包装的 T 实例转换到其每个已暴露的直接和间接基类. 对每个多态基类 B, 注册从间接持有的被包装 B 实例到 T 的转换.

bases<>

HeldType

必须是 T、派生自 T 的类, 或一个 Dereferenceable 类型, 对其而言 pointee<HeldType>::type 是 T 或派生自 T 的类.

指定包装 T 实例的 Python 对象在以下时刻实际嵌入的类型: 调用 T 的构造函数时; 或把 T 或 T* 转换为 Python 且未借助 ptr、ref 或 Call Policies (如 return_internal_reference) 时. 更多细节见下文.

T

NonCopyable

如果提供, 必须是 boost::noncopyable.

抑制 to_python 转换的自动注册——即那些复制 T 实例的转换. 当 T 没有可公开访问的复制构造函数时需要它.

boost::noncopyable 以外的某个未指定类型.

HeldType 语义

  1. 如果 HeldType 派生自 T, 其暴露的构造函数必须接受一个作为首参数的 PyObject*, 它回指包含 HeldType 实例的 Python 对象, 如本示例所示. 这个参数不包含在 init-expression (传给 def(init_expr), 见下文) 中, 当创建 T 的 Python 实例时用户也不会显式传入它. 这一习语使将在 Python 中被改写的 C++ 虚函数能够访问 Python 对象, 从而可以调用 Python 方法. Boost.Python 自动注册额外的转换器, 允许把 T 的被包装实例传给期望 HeldType 参数的被包装 C++ 函数.
  2. 由于 Boost.Python 总是允许把 T 的被包装实例替代 HeldType 参数传入, 为 HeldType 指定智能指针使用户能够在期望指向 T 的智能指针之处传入 Python T 实例. 诸如 std::auto_ptr<> 或 boost::shared_ptr<> 这类含有用于指明所指对象类型的嵌套类型 element_type 的智能指针会被自动支持; 通过特化 pointee<HeldType> 可以支持其他智能指针类型.
  3. 如同上面的情形 1, 当 HeldType 是指向派生自 T 的类的智能指针时, HeldType 暴露的所有构造函数都必须提供作为首参数的 PyObject*.
  4. 除情形 1 和 3 之外, 用户还可以选择指定 T 自身用一个类似的首参数 PyObject* 初始化——通过特化 has_back_reference<T>.

类模板 class_ 概要 

namespace boost { namespace python
{
template <class T
    , class Bases = bases<>
          , class HeldType = T
          , class NonCopyable = unspecified
         >
class class_ : public object
{
  // Constructors with default __init__
  class_(char const* name);
  class_(char const* name, char const* docstring);

  // Constructors, specifying non-default __init__
  template <class Init>
  class_(char const* name, Init);
  template <class Init>
  class_(char const* name, char const* docstring, Init);

  // Exposing additional __init__ functions
  template <class Init>
  class_& def(Init);

  // defining methods
  template <class F>
  class_& def(char const* name, F f);
  template <class Fn, class A1>
  class_& def(char const* name, Fn fn, A1 const&);
  template <class Fn, class A1, class A2>
  class_& def(char const* name, Fn fn, A1 const&, A2 const&);
  template <class Fn, class A1, class A2, class A3>
  class_& def(char const* name, Fn fn, A1 const&, A2 const&, A3 const&);

  // declaring method as static
  class_& staticmethod(char const* name);

  // exposing operators
  template <unspecified>
  class_& def(detail::operator_<unspecified>);

  // Raw attribute modification
  template <class U>
  class_& setattr(char const* name, U const&);

  // exposing data members
  template <class D>
  class_& def_readonly(char const* name, D T::*pm);

  template <class D>
  class_& def_readwrite(char const* name, D T::*pm);

  // exposing static data members
  template <class D>
  class_& def_readonly(char const* name, D const& d);
  template <class D>
  class_& def_readwrite(char const* name, D& d);

  // property creation
  template <class Get>
  void add_property(char const* name, Get const& fget, char const* doc=0);
  template <class Get, class Set>
  void add_property(
      char const* name, Get const& fget, Set const& fset, char const* doc=0);

  template <class Get>
  void add_static_property(char const* name, Get const& fget);
  template <class Get, class Set>
  void add_static_property(char const* name, Get const& fget, Set const& fset);

  // pickle support
  template <typename PickleSuite>
  self& def_pickle(PickleSuite const&);
  self& enable_pickling();
};
}}

类模板 class_ 构造函数 

class_(char const* name);
class_(char const* name, char const* docstring);
template <class Init>
class_(char const* name, Init init_spec);
template <class Init>
class_(char const* name, char const* docstring, Init init_spec);

Requires

name 是一个符合 Python 标识符命名规则 的 ntbs. 如果提供了 docstring, 它必须是 ntbs. 如果提供了 init_spec, 它必须是特殊枚举常量 no_init, 或一个 init-expression——与 T 兼容.

效果

构造一个 class_ 对象, 持有一个名为 name 的 Boost.Python 扩展类. 当前作用域 的同名属性被绑定到新的扩展类.

  • 如果提供, docstring 的值会绑定到扩展类的 __doc__ 属性.
  • 如果 init_spec 为 no_init, 会生成一个总是引发 Python 异常的特殊 __init__ 函数. 否则, 调用 this->def(init_spec).
  • 如果未提供 init_spec, 则调用 this->def(init<>()).
Rationale

允许用户在 class_<> 构造函数中指定构造函数参数, 有助于她避免常见的运行期错误——这类错误源于在未暴露 __init__ 函数 (该函数创建所需的 T 实例) 的情况下调用被包装成员函数. 不可默认构造的类型会导致编译期错误, 除非提供了 Init. 用户必须始终提供 name, 因为目前没有可移植的方法从类型本身推导类名文本.

类模板 class_ 修饰函数 

template <class Init>
class_& def(Init init_expr);

Requires

init_expr 是一个 init-expression (与 T 兼容) 的结果.

效果

对每个 有效前缀 P (取自 Init), 向扩展类添加一个接受 P 作为参数的 __init__(...) 函数重载. 生成的每个重载都按上文所述语义构造一个 HeldType 对象, 使用 init_expr 调用策略的一个副本. 如果 Init 的最长 有效前缀 包含 N 个类型且 init_expr 持有 M 个关键字, 则每个重载除前 N - M 个参数外的所有参数都使用关键字的初始序列.

Returns

*this

Rationale

使用户能够轻松地把类的构造函数暴露给 Python.

template <class F>
class_& def(char const* name, Fn fn);
template <class Fn, class A1>
class_& def(char const* name, Fn fn, A1 const& a1);
template <class Fn, class A1, class A2>
class_& def(char const* name, Fn fn, A1 const& a1, A2 const& a2);
template <class Fn, class A1, class A2, class A3>
class_& def(char const* name, Fn fn, A1 const& a1, A2 const& a2, A3 const& a3);

Requires

name 是一个符合 Python 标识符命名规则 的 ntbs. * 如果 a1 是 重载分派表达式 的结果, 则只允许第二种形式, 且 fn 必须是指向函数或成员函数的指针, 其 元数 与 A1 的 最大元数 相同.

效果: 对每个前缀 P (取自 Fn 的参数类型序列, 从长度等于 A1 的 最小元数 的那个开始), 向扩展类添加一个 name(...) 方法重载. 生成的每个重载都用 P 调用 a1 的调用表达式, 使用 a1 调用策略的一个副本. 如果 A1 的最长有效前缀包含 N 个类型且 a1 持有 M 个关键字, 则每个重载除前 N - M 个参数外的所有参数都使用关键字的初始序列.

  • 否则, 围绕 fn 构建单个方法重载, fn 不得为空:
    • 如果 fn 是函数指针, 其第一个参数必须具有 U、U cv&、U cv* 或 U cv* const& 的形式, 其中 T* 可转换为 U*, 且 a1-a3 (如果提供) 可以按任意顺序从下表中选取.
    • 否则, 如果 fn 是成员函数指针, 其目标必须是 T 或 T 的公有基类之一, 且 a1-a3 (如果提供) 可以按任意顺序从下表中选取.

    • 否则, Fn 必须[派生自] object, 且 a1-a2 (如果提供) 可以按任意顺序从下表前两行中选取. 要能派上用场, fn 应当是 可调用对象.

      助记名

      要求/类型性质

      效果

      docstring

      任何 ntbs

      该值将绑定到所生成方法重载的 __doc__ 属性. 如果更早的重载提供了文档字符串, 则会向其追加两个换行符和新的文档字符串.

      policies

      CallPolicies 的一个模型

      其副本将用作所生成方法重载的调用策略.

      keywords

      一个 关键字表达式 的结果, 其指定的参数个数不超过 fn 的 元数.

      其副本将用作所生成方法重载的调用策略.

class_& staticmethod(char const* name);

Requires

name 是一个符合 Python 标识符命名规则 的 ntbs, 并对应于一个其全部重载均已定义的方法.

效果

把既有的具名属性 x 替换为在 Python 中调用 staticmethod(x) 的结果. 指明相应方法是静态的, 因此不会向其传入对象实例. 这等价于 Python 语句:

setattr(self, name, staticmethod(getattr(self, name)))

Note

在调用 staticmethod(name) 之后试图调用 def(name,...) 将引发 RuntimeError.

Returns

*this

class_& def(detail::operator_<unspecified>);

添加一个 Python 特殊方法, 如此处所述.

类模板 bases<T1, T2, ...TN>

类模板 bases 概要

一个 MPL 序列, 可在 class_<...> 实例化中用于指示基类列表.

类模板 bases 概要 

namespace boost { namespace python
{
  template <T1 = unspecified,...Tn = unspecified>
  struct bases
  {};
}}

示例

给定一个 C++ 类声明:

class Foo : public Bar, public Baz
{
 public:
   Foo(int x, char const* y);
   Foo(double);

   std::string const& name() { return m_name; }
   void name(char const*);

   double value; // public data
 private:
   ...
};

可以用以下方式创建相应的 Boost.Python 扩展类:

using namespace boost::python;

class_<Foo,bases<Bar,Baz> >("Foo",
          "This is Foo's docstring."
          "It describes our Foo extension class",

          init<int,char const*>(args("x","y"), "__init__ docstring")
          )
   .def(init<double>())
   .def("get_name", &Foo::get_name, return_internal_reference<>())
   .def("set_name", &Foo::set_name)
   .def_readwrite("value", &Foo::value);
