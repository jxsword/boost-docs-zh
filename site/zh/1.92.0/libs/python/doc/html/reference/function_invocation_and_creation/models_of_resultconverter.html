<boost/python/to_python_indirect.hpp> supplies a way to construct new Python objects that hold wrapped C++ class instances via a pointer or smart pointer.
[endsect]
类 to_python_indirect

类模板 to_python_indirect 使用其第二个参数提供的所有权策略, 把其第一个参数类型的对象作为扩展类实例转换为 Python.

参数

要求

说明

T

要么是 U cv& (其中 cv 是任意可选的 cv 限定), 要么是一个 Dereferenceable 类型, 使得 *x 可转换为 U const&, 其中 U 是类类型.

一个 A 类型, 对使用类模板 class_ 暴露给 Python 的 C++ 类进行解引用.

MakeHolder

h = MakeHolder::execute(p);

一个类, 其静态 execute() 创建一个 instance_holder.

to_python_indirect 的实例是 ResultConverter 的模型.

namespace boost { namespace python
{
  template <class T, class MakeHolder>
  struct to_python_indirect
  {
     static bool convertible();
     PyObject* operator()(T ptr_or_reference) const;
   private:
     static PyTypeObject* type();
  };
}}
类 to_python_indirect 观察者函数 
PyObject* operator()(T x) const;

Requires

x 引用一个对象 (若它是指针类型, 则非空). convertible() == true.

效果

创建一个类型适当的 Boost.Python 扩展类实例, 用 MakeHolder 从 x 创建一个 instance_holder, 把该 instance_holder 安装到新的扩展类实例中, 并返回指向它的指针.

类 to_python_indirect 静态函数 
bool convertible()

效果

当且仅当某个模块已注册了与 U 相对应的 Python 类型时返回 true.

Example

本示例复现了 reference_existing_object 的功能, 但省去了部分编译期错误检查.

struct make_reference_holder
{
   typedef boost::python::objects::instance_holder* result_type;
   template <class T>
   static result_type execute(T* p)
   {
      return new boost::python::objects::pointer_holder<T*, T>(p);
   }
};

struct reference_existing_object
{
   // metafunction returning the ResultConverter
   template <class T>
   struct apply
   {
      typedef boost::python::to_python_indirect<T,make_reference_holder> type;
   };
};

类 to_python_value 观察者函数

to_python_value 是 ResultConverter 的一个模型, 它把其参数复制到一个新的 Python 对象中.

类模板 to_python_value 

namespace boost { namespace python
{
   template <class T>
   struct to_python_value
   {
      typedef typename add_reference<
         typename add_const<T>::type
      >::type argument_type;

      static bool convertible();
      PyObject* operator()(argument_type) const;
   };
}}

类 to_python_value 观察者函数 

static bool convertible();

Returns

true, 当且仅当已注册能把 T 按值转换为 Python 的转换器.

PyObject* operator()(argument_type x) const;

Requires

convertible() == true

效果

把 x 转换为 Python

Returns

所得的 Python 对象, 当且仅当 T 的转换器已注册; 否则为 0.
