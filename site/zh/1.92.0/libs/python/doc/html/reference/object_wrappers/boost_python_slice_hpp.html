引言

暴露一个 TypeWrapper——用于 Python slice 类型.

类 slice

通过包装内建 slice 类型暴露扩展切片协议. 下面定义的构造函数和成员函数的语义, 可以通过阅读 TypeWrapper 概念定义完全理解. 由于 slice 公有派生自 object, 公有的 object 接口同样适用于 slice 实例.

namespace boost { namespace python
{
  class slice : public object
  {
   public:
      slice(); // create an empty slice, equivalent to [::]

      template <typename Int1, typename Int2>
      slice(Int1 start, Int2 stop);

      template <typename Int1, typename Int2, typename Int3>
      slice(Int1 start, Int2 stop, Int3 step);

      // Access the parameters this slice was created with.
      object start();
      object stop();
      object step();

      // The return type of slice::get_indices()
      template <typename RandomAccessIterator>
      struct range
      {
          RandomAccessIterator start;
          RandomAccessIterator stop;
          int step;
      };

      template <typename RandomAccessIterator>
      range<RandomAccessIterator>
      get_indices(
          RandomAccessIterator const& begin,
          RandomAccessIterator const& end);
  };
}}

类 slice 构造函数 

slice();

效果

构造一个使用默认 stop、start 和 step 值的切片. 等价于作为 Python 表达式 base[::] 一部分创建的切片对象.

Throws

nothing 

template <typename Int1, typename Int2>
slice(Int1 start, Int2 stop);

Requires

start、stop 和 step 的类型为 slice_nil, 或可转换为类型 object.

效果

构造一个使用默认 step 值及所提供 start 和 stop 值的新切片. 等价于由 Python 内建函数 slice(start,stop) 创建的切片对象, 或作为 Python 表达式 base[start:stop] 的一部分创建的切片对象.

Throws

error_already_set, 且当参数无法转换为 object 类型时设置 Python TypeError 异常.

template <typename Int1, typename Int2, typename Int3>
slice(Int1 start, Int2 stop, Int3 step);

Requires

start、stop 和 step 为 slice_nil, 或可转换为类型 object.

效果

构造一个使用 start、stop 和 step 值的新切片. 等价于由 Python 内建函数 slice(start,stop,step) 创建的切片对象, 或作为 Python 表达式 base[start:stop:step] 的一部分创建的切片对象.

Throws

error_already_set, 且当参数无法转换为 object 类型时设置 Python TypeError 异常.

类 slice 观察者函数 

object slice::start() const;
object slice::stop() const;
object slice::step() const;

效果

无

Throws

nothing

Returns

创建切片时所用的参数. 如果创建切片时省略了该参数或使用了 slice_nil, 那么该参数将是对 PyNone 的引用, 且与默认构造的 object 比较相等. 原则上, 创建切片对象时可以使用任何对象, 但实践中它们通常是整数.

template <typename RandomAccessIterator>
slice::range<RandomAccessIterator>
slice::get_indices(
    RandomAccessIterator const& begin,
    RandomAccessIterator const& end) const;

参数

一对符合 STL 的随机访问迭代器, 构成一个半开区间.

效果

创建一个 RandomAccessIterator 对, 在其参数的 [begin,end) 区间内定义一个全闭区间. 该函数在换算此切片的索引时, 会考虑任何 PyNone 或负索引以及非单位步长的影响.

Returns

一个 slice::range, 它已用非零的 step 值以及一对 RandomAccessIterator 初始化, 后者指向本函数参数范围内并定义一个闭区间.

Throws

如果此切片的任何参数既不是对 PyNone 的引用也不能转换为 int, 则引发 Python TypeError 异常. 如果所得区间为空, 则抛出 std::invalid_argument. 你应当始终把对 slice::get_indices() 的调用包裹在 try { ...; } catch (std::invalid_argument) {} 中, 以处理这种情况并采取适当的行动.

Rationale

闭区间: 如果使用开区间, 那么对不为 1 的步长而言, 尾迭代器所需的状态将指向越过尾后位置之处或指定区间开头之前. 空切片的异常: 无法在空区间上定义闭区间, 因此必须使用某种其他形式的错误检查来防止未定义行为. 在异常未被捕获的情况下, 它会被默认异常处理机制简单地转换为 Python 异常.

Example 

using namespace boost::python;

// Perform an extended slice of a Python list.
// Warning: extended slicing was not supported for built-in types prior 
// to Python 2.3
list odd_elements(list l)
{
    return l[slice(_,_,2)];
}

// Perform a summation over a slice of a std::vector.
double partial_sum(std::vector<double> const& Foo, const slice index)
{
    slice::range<std::vector<double>::const_iterator> bounds;
    try {
        bounds = index.get_indices<>(Foo.begin(), Foo.end());
    }
    catch (std::invalid_argument) {
        return 0.0;
    }
    double sum = 0.0;
    while (bounds.start != bounds.stop) {
        sum += *bounds.start;
        std::advance( bounds.start, bounds.step);
    }
    sum += *bounds.start;
    return sum;
}
