引言

<boost/python/enum.hpp> 定义了用户把 C++ 枚举类型暴露给 Python 所经由的接口. 它声明了 enum_ 类模板, 该模板以被暴露的枚举类型为参数.

类模板 enum_

创建一个派生自 Python 的 int 类型的 Python 类, 该类与作为其第一个参数传入的 C++ 类型相关联.

namespace boost { namespace python
{
  template <class T>
  class enum_ : public object
  {
    enum_(char const* name, char const* doc = 0);
    enum_<T>& value(char const* name, T);
    enum_<T>& export_values();
  };
}}

类模板 enum_ 构造函数 

enum_(char const* name, char const* doc=0);

Requires

name 是一个符合 Python 标识符命名规则 的 ntbs.

效果

构造一个 enum_ 对象, 持有一个派生自 int、名为 name 的 Python 扩展类型. 当前作用域 的同名属性被绑定到新的扩展类型.

类模板 enum_ 修饰函数 

enum_<T>& value(char const* name, T x);

Requires

name 是一个符合 Python 标识符命名规则 的 ntbs.

效果

把一个值为 x 的被包装枚举类型实例作为具名属性添加到该类型的字典中.

Returns

*this 

enum_<T>& export_values();

效果

在 当前作用域 中设置属性, 其名称和值与迄今为止通过调用 value() 暴露的所有枚举值相同.

Returns

*this

Example

C++ 模块定义

#include <boost/python/enum.hpp>
#include <boost/python/def.hpp>
#include <boost/python/module.hpp>

using namespace boost::python;

enum color { red = 1, green = 2, blue = 4 };

color identity_(color x) { return x; }

BOOST_PYTHON_MODULE(enums)
{
  enum_<color>("color")
    .value("red", red)
    .value("green", green)
    .export_values()
    .value("blue", blue)
    ;

  def("identity", identity_);
}
