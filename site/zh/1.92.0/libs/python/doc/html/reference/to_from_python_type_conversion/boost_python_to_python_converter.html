引言

to_python_converter 注册一个从给定 C++ 类型对象到 Python 对象的转换.

类模板 to_python_converter

类模板 to_python_converter 构造函数

to_python_converter 围绕其第二个模板参数的一个静态成员函数添加包装器, 处理诸如插入转换器注册表之类的底层细节.

在下表中, x 表示 T 类型的对象

参数

要求

说明

T

转换中源对象的 C++ 类型

转换

PyObject* p = Conversion::convert(x), if p == 0, PyErr_Occurred() != 0.

一个类类型, 其静态成员函数 convert 完成转换的实际工作.

bool has_get_pytype=false

PyTypeObject const * p = Conversion::get_pytype()

可选成员——如果 Conversion 有 get_pytype 成员, 为此参数提供 true. 如果存在, get_pytype 用于为使用此转换的函数记录返回类型文档. get_pytype 可以用 pytype_function.hpp 中的类和函数实现. 注意: 为向后兼容, 可以在检查 BOOST_PYTHON_SUPPORTS_PY_SIGNATURES 已定义之后传入此参数 (参见此处).

 
namespace boost { namespace python
{
  template <class T, class Conversion, bool convertion_has_get_pytype_member=false>
  struct to_python_converter
  {
      to_python_converter();
  };
}}

类模板 to_python_converter 构造函数 

to_python_converter();

效果

注册一个 to_python 转换器, 它使用 Conversion::convert() 来完成工作.

Example

本示例假定有人已经实现了 Python 文档中的标准 noddy 示例模块, 并把相应的声明放在 "noddy.h" 中. 由于 noddy_NoddyObject 是最简单不过的扩展类型, 这个示例有点刻意: 它包装了一个函数, 其全部信息都包含在返回值的类型中.

C++ 中:

#include <boost/python/reference.hpp>
#include <boost/python/module.hpp>
#include "noddy.h"

struct tag {};
tag make_tag() { return tag(); }

using namespace boost::python;

struct tag_to_noddy
{
    static PyObject* convert(tag const& x)
    {
        return PyObject_New(noddy_NoddyObject, &noddy_NoddyType);
    }
    static PyTypeObject const* get_pytype()
    {
        return &noddy_NoddyType;
    }
};

BOOST_PYTHON_MODULE(to_python_converter)
{
    def("make_tag", make_tag);
    to_python_converter<tag, tag_to_noddy, true>(); //"true" because tag_to_noddy has member get_pytype
}

Python 中:

>>> import to_python_converter
>>> def always_none():
...     return None
...
>>> def choose_function(x):
...     if (x % 2 != 0):
...         return to_python_converter.make_tag
...     else:
...         return always_none
...
>>> a = [ choose_function(x) for x in range(5) ]
>>> b = [ f() for f in a ]
>>> type(b[0])
<type 'NoneType'>
>>> type(b[1])
<type 'Noddy'>
>>> type(b[2])
<type 'NoneType'>
>>> type(b[3])
<type 'Noddy'>
