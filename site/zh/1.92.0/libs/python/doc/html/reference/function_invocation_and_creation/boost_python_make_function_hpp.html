引言

make_function() 和 make_constructor() 是 def() 和 class_<>::def() 内部使用的函数, 用于生成包装 C++ 函数和成员函数的 Python 可调用对象.

Functions 

template <class F>
object make_function(F f)

template <class F, class Policies>
object make_function(F f, Policies const& policies)

template <class F, class Policies, class KeywordsOrSignature>
object make_function(F f, Policies const& policies, KeywordsOrSignature const& ks)

template <class F, class Policies, class Keywords, class Signature>
object make_function(F f, Policies const& policies, Keywords const& kw, Signature const& sig)

Requires

F 是函数指针或成员函数指针类型. 如果提供了 policies, 它必须是 CallPolicies 的模型. 如果提供了 keywords, 它必须是一个关键字表达式的结果, 且指定的参数个数不超过 f 的元数.

效果

创建一个 Python 可调用对象, 从 Python 调用时它把参数转换为 C++ 并调用 f. 如果 F 是成员函数指针类型, 函数调用的目标对象 (*this) 将取自第一个 Python 参数, 后续的 Python 参数将用作 f 的参数.

  • 如果提供了 policies, 它将按这里的描述应用于该函数.
  • 如果提供了 keywords, 关键字将按顺序应用于结果函数的末尾参数.
  • 如果提供了 Signature, 它应当是一个 MPL 前向可扩展序列的实例, 表示函数的返回类型后跟其参数类型. 在包装签名无法推导的函数对象类型时, 或者当你希望覆盖传给被包装函数的类型时, 传入一个 Signature.
Returns

持有新 Python 可调用对象的 object 实例.

注意事项

如果从 Python 传入 None, 指针类型的参数可以为 0. 常量引用类型的参数可能引用一个临时对象, 该临时对象是从 Python 对象创建的、只在被包装函数调用的持续期间存在的对象, 例如由转换过程从 Python 列表变出的 std::vector. 当需要持久的左值时, 使用非 const 引用参数.

效果

Returns

持有新 Python 可调用对象的 object 实例.

Example

下面暴露的 C++ 函数返回一个可调用对象, 包装两个函数之一.

#include <boost/python/make_function.hpp>
#include <boost/python/module.hpp>

char const* foo() { return "foo"; }
char const* bar() { return "bar"; }

using namespace boost::python;
object choose_function(bool selector)
{
    if (selector)
        return boost::python::make_function(foo);
    else
        return boost::python::make_function(bar);
}

BOOST_PYTHON_MODULE(make_function_test)
{
    def("choose_function", choose_function);
}

在 Python 中可以这样使用:

>>> from make_function_test import *
>>> f = choose_function(1)
>>> g = choose_function(0)
>>> f()
'foo'
>>> g()
'bar'
