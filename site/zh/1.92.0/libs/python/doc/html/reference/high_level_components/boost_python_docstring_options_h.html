引言

Boost.Python 支持用户定义的文档字符串, 并自动附加 C++ 签名. 这些特性默认启用. docstring_options 类可用于选择性地抑制用户定义的文档字符串、签名, 或两者.

类 docstring_options

在实例的生命期内控制被包装函数和成员函数文档字符串的显示. 实例不可复制, 以消除出现意外副作用的可能性.

namespace boost { namespace python {

  class docstring_options : boost::noncopyable
  {
  public:
    docstring_options(bool show_all=true);
    docstring_options(bool show_user_defined, bool show_signatures);
    docstring_options(bool show_user_defined, bool show_py_signatures, bool show_cpp_signatures);
    ~docstring_options();
    void disable_user_defined();
    void enable_user_defined();
    void disable_signatures();
    void enable_signatures();
    void disable_py_signatures();
    void enable_py_signatures();
    void disable_cpp_signatures();
    void enable_cpp_signatures();
    void disable_all();
    void enable_all();
  };
}}

类 dostring_options 构造函数 

docstring_options(bool show_all=true);

效果

构造一个 docstring_options 对象, 控制其后续代码中定义的函数和成员函数文档字符串的显示. 如果 show_all 为 true, 用户定义的文档字符串和自动生成的 Python 与 C++ 签名都会显示. 如果 show_all 为 false, __doc__ 属性为 None.

docstring_options(bool show_user_defined, bool show_signatures);

效果

构造一个 docstring_options 对象, 控制其后续代码中定义的函数和成员函数文档字符串的显示. 当且仅当 show_user_defined 为 true 时, 显示用户定义的文档字符串. 当且仅当 show_signatures 为 true 时, 自动添加 Python 与 C++ 签名. 如果 show_user_defined 与 show_signatures 都为 false, 则 __doc__ 属性为 None.

docstring_options(bool show_user_defined, bool show_py_signatures, bool show_cpp_signatures);

效果

构造一个 docstring_options 对象, 控制其后续代码中定义的函数和成员函数文档字符串的显示. 当且仅当 show_user_defined 为 true 时, 显示用户定义的文档字符串. 当且仅当 show_py_signatures 为 true 时, 自动添加 Python 签名. 当且仅当 show_cpp_signatures 为 true 时, 自动添加 C++ 签名. 如果所有参数都为 false, 则 __doc__ 属性为 None.

类 docstring_options 析构函数 

~docstring_options();

效果

恢复文档字符串选项的先前状态. 特别是, 如果 docstring_options 实例位于嵌套的 C++ 作用域中, 则恢复外围作用域中有效的设置. 如果最后一个 docstring_options 实例离开作用域, 则恢复默认的 "全部开启" 设置.

类 docstring_options 修饰函数 

void disable_user_defined();
void enable_user_defined();
void disable_signatures();
void enable_signatures();
void disable_py_signatures();
void enable_py_signatures();
void disable_cpp_signatures();
void enable_cpp_signatures();
void disable_all();
void enable_all();

这些成员函数动态改变其后续代码中文档字符串的显示. 提供 *_user_defined() 和 *_signatures() 成员函数用于细粒度控制. *_all() 成员函数是同时操纵所有设置的便捷捷径.

编译期定义的文档字符串选项 

#include <boost/python/module.hpp>
#include <boost/python/def.hpp>
#include <boost/python/docstring_options.hpp>

void foo() {}

BOOST_PYTHON_MODULE(demo)
{
    using namespace boost::python;
    docstring_options doc_options(DEMO_DOCSTRING_SHOW_ALL);
    def("foo", foo, "foo doc");
}

如果以 -DDEMO_DOCSTRING_SHOW_ALL=true 编译:

>>> import demo
>>> print demo.foo.__doc__
foo() -> None : foo doc
C++ signature:
    foo(void) -> void

如果以 -DDEMO_DOCSTRING_SHOW_ALL=false 编译:

>>> import demo
>>> print demo.foo.__doc__
None

选择性抑制 

#include <boost/python/module.hpp>
#include <boost/python/def.hpp>
#include <boost/python/args.hpp>
#include <boost/python/docstring_options.hpp>

int foo1(int i) { return i; }
int foo2(long l) { return static_cast<int>(l); }
int foo3(float f) { return static_cast<int>(f); }
int foo4(double d) { return static_cast<int>(d); }

BOOST_PYTHON_MODULE(demo)
{
    using namespace boost::python;
    docstring_options doc_options;
    def("foo1", foo1, arg("i"), "foo1 doc");
    doc_options.disable_user_defined();
    def("foo2", foo2, arg("l"), "foo2 doc");
    doc_options.disable_signatures();
    def("foo3", foo3, arg("f"), "foo3 doc");
    doc_options.enable_user_defined();
    def("foo4", foo4, arg("d"), "foo4 doc");
    doc_options.enable_py_signatures();
    def("foo5", foo4, arg("d"), "foo5 doc");
    doc_options.disable_py_signatures();
    doc_options.enable_cpp_signatures();
    def("foo6", foo4, arg("d"), "foo6 doc");
}

Python 代码:

>>> import demo
>>> print demo.foo1.__doc__
foo1( (int)i) -> int : foo1 doc
C++ signature:
    foo1(int i) -> int
>>> print demo.foo2.__doc__
foo2( (int)l) -> int :
C++ signature:
    foo2(long l) -> int
>>> print demo.foo3.__doc__
None
>>> print demo.foo4.__doc__
foo4 doc
>>> print demo.foo5.__doc__
foo5( (float)d) -> int : foo5 doc
>>> print demo.foo6.__doc__
foo6 doc
C++ signature:
    foo6(double d) -> int

从多个 C++ 作用域包装 

#include <boost/python/module.hpp>
#include <boost/python/def.hpp>
#include <boost/python/args.hpp>
#include <boost/python/docstring_options.hpp>

int foo1(int i) { return i; }
int foo2(long l) { return static_cast<int>(l); }

int bar1(int i) { return i; }
int bar2(long l) { return static_cast<int>(l); }

namespace {

    void wrap_foos()
    {
        using namespace boost::python;
        // no docstring_options here
        //   -> settings from outer C++ scope are in effect
        def("foo1", foo1, arg("i"), "foo1 doc");
        def("foo2", foo2, arg("l"), "foo2 doc");
    }

    void wrap_bars()
    {
        using namespace boost::python;
        bool show_user_defined = true;
        bool show_signatures = false;
        docstring_options doc_options(show_user_defined, show_signatures);
        def("bar1", bar1, arg("i"), "bar1 doc");
        def("bar2", bar2, arg("l"), "bar2 doc");
    }
}

BOOST_PYTHON_MODULE(demo)
{
    boost::python::docstring_options doc_options(false);
    wrap_foos();
    wrap_bars();
}

Python 代码:

>>> import demo
>>> print demo.foo1.__doc__
None
>>> print demo.foo2.__doc__
None
>>> print demo.bar1.__doc__
bar1 doc
>>> print demo.bar2.__doc__
bar2 doc
