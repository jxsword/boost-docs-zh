引言

<boost/python/register_ptr_to_python.hpp> 提供 register_ptr_to_python, 一个为智能指针注册到 Python 转换的函数模板. 所得 Python 对象持有被转换智能指针的一个副本, 但表现得好像它是一个被包装的所指对象副本. 如果所指对象类型有虚函数, 且表示其动态 (最终派生) 类型的类已被包装, Python 对象将是最终派生类型的包装器的实例. 可以为一个所指对象的类注册不止一种智能指针类型.

注意, 要把 Python X 对象转换为 smart_ptr<X>& (非 const 引用), 内嵌的 C++ 对象必须由 smart_ptr<X> 持有; 而当通过从 Python 调用构造函数来创建被包装对象时, 其持有方式由 class_<...> 实例的 HeldType 参数决定.

函数 register_ptr_to_python 

template <class P>
void register_ptr_to_python()

Requires

P 是 Dereferenceable 的.

效果

允许把 P 实例转换为 Python.

Example

下面是一个模块示例, 它包含一个带虚函数的类 A 以及一些使用 boost::shared_ptr<A> 的函数.

C++ 中:

struct A
{
    virtual int f() { return 0; }
};

shared_ptr<A> New() { return shared_ptr<A>( new A() ); }

int Ok( const shared_ptr<A>& a ) { return a->f(); }

int Fail( shared_ptr<A>& a ) { return a->f(); }

struct A_Wrapper: A
{
    A_Wrapper(PyObject* self_): self(self_) {}
    int f() { return call_method<int>(self, "f"); }
    int default_f() { return A::f(); }
    PyObject* self;
};

BOOST_PYTHON_MODULE(register_ptr)
{
    class_<A, A_Wrapper>("A")
        .def("f", &A::f, &A_Wrapper::default_f)
    ;

    def("New", &New);
    def("Ok", &Call);
    def("Fail", &Fail);

    register_ptr_to_python< shared_ptr<A> >();
}

Python 中:

>>> from register_ptr import *
>>> a = A()
>>> Ok(a)     # ok, passed as shared_ptr<A>
0
>>> Fail(a)   # passed as shared_ptr<A>&, and was created in Python!
Traceback (most recent call last):
  File "<stdin>", line 1, in ?
TypeError: bad argument type for built-in operation
>>>
>>> na = New()   # now "na" is actually a shared_ptr<A>
>>> Ok(a)
0
>>> Fail(a)
0
>>>

如果按如下方式注册 shared_ptr<A>:

class_<A, A_Wrapper, shared_ptr<A> >("A")
    .def("f", &A::f, &A_Wrapper::default_f)
;

尝试把 shared_ptr<A> 转换为 shared_ptr<A_Wrapper> 时会出现错误:

>>> a = New()
Traceback (most recent call last):
File "<stdin>", line 1, in ?
TypeError: No to_python (by-value) converter found for C++ type: class boost::shared_ptr<struct A>
>>>
