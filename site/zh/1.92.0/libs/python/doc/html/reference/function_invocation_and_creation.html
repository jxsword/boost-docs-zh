引言

关键字表达式

提供一组重载函数, 用于为被包装的 C++ 函数指定参数关键字.

关键字表达式

关键字表达式的求值结果是一个对象, 它持有一个 ntbs 序列, 且其类型编码了所指定关键字的数目. 关键字表达式可以为其持有的部分或全部关键字包含默认值

类 arg

arg 类的对象是持有一个关键字的关键字表达式 (大小为 1)

namespace boost { namespace python
{
        struct arg
        {
          template <class T>
                  arg &operator = (T const &value);
          explicit arg (char const *name){elements[0].name = name;}
        };

}}

类 arg 构造函数 

arg(char const* name);

Requires

该参数必须是 ntbs.

效果

构造一个 arg 对象, 持有名为 name 的关键字.

类 arg operator= 

template <class T> arg &operator = (T const &value);

Requires

该参数必须可转换为 Python.

效果

为该关键字指定默认值.

Returns

对 this 的引用.

关键字表达式运算符, 

keyword-expression operator , (keyword-expression, const arg &kw) const
keyword-expression operator , (keyword-expression, const char *name) const;

Requires

参数 name 必须是 ntbs.

效果

用一个更多的关键字扩展关键字表达式参数.

Returns

扩展后的关键字表达式.

Example 

#include <boost/python/def.hpp>
using namespace boost::python;

int f(double x, double y, double z=0.0, double w=1.0);

BOOST_PYTHON_MODULE(xxx)
{
  def("f", f, (arg("x"), "y", arg("z")=0.0, arg("w")=1.0));
}
