为 Python http://www.python.org/doc/current/tut/node7.html#SECTION007300000000000000000%60tuple%60 类型暴露一个 TypeWrapper.

类 tuple

暴露 Python 内建 tuple 类型的接口. 下面定义的构造函数和成员函数的语义, 可以通过阅读 TypeWrapper 概念定义完全理解. 由于 tuple 公有派生自 object, 公有的 object 接口同样适用于 tuple 实例.

namespace boost { namespace python
{
   class tuple : public object
   {
      // tuple() -> an empty tuple
      tuple();

      // tuple(sequence) -> tuple initialized from sequence's items
      template <class T>
      explicit tuple(T const& sequence)
  };
}}

函数 make_tuple 

namespace boost { namespace python
{
  tuple make_tuple();

  template <class A0>
  tuple make_tuple(A0 const& a0);

  template <class A0, class A1>
  tuple make_tuple(A0 const& a0, A1 const& a1);
  ...
  template <class A0, class A1,...class An>
  tuple make_tuple(A0 const& a0, A1 const& a1,...An const& an);
}}

效果

构造一个由 object(a0), object(a0),...object(an) 组成的新元组对象.

Example 

using namespace boost::python;
tuple head_and_tail(object sequence)
{
    return make_tuple(sequence[0],sequence[-1]);
}
