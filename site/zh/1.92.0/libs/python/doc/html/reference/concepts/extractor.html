引言

Extractor 是 Boost.Python 可用于从 Python 对象提取 C++ 对象的类, 通常由为 "传统" Python 扩展类型定义 from_python 转换的设施使用.

概念要求

在下表中, X 表示 Extractor 的一个模型, a 表示 Python 对象类型的一个实例.

表达式

类型

语义

X::execute(a)

non-void

返回被提取的 C++ 对象. execute 函数不得重载.

&a.ob_type

PyTypeObject**

指向某个对象的 ob_type 字段, 该对象与 PyObject 布局兼容

注释

通俗地说, Extractor 的 execute 成员必须是一个非重载的静态函数, 其唯一参数是 Python 对象类型. 可接受的 Python 对象类型包括从 PyObject 公有 (且无歧义地) 派生的类型, 以及与 PyObject 布局兼容的 POD 类型.
