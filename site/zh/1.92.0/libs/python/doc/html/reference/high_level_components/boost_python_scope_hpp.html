引言

定义用于查询和控制 Python 作用域 (命名空间) 的设施, 该作用域将包含新的被包装类和函数.

类 scope

scope 类有一个关联的全局 Python 对象, 它控制新的扩展类和被包装函数将以属性形式定义于其中的 Python 命名空间. 默认构造一个新的 scope 对象会把它绑定到关联的全局 Python 对象. 用参数构造 scope 对象会把关联的全局 Python 对象改为该参数持有的对象, 直到 scope 对象的生命期结束, 此时关联的全局 Python 对象恢复为 scope 对象构造之前的状态.

namespace boost { namespace python
{
  class scope : public object
  {
   public:
      scope(scope const&);
      scope(object const&);
      scope();
      ~scope()
   private:
      void operator=(scope const&);
  };
}}

类 scope 构造函数与析构函数 

explicit scope(scope const& x);
explicit scope(object const& x);

保存对当前关联 scope 对象的引用, 并把关联 scope 对象设置为 x.ptr() 所指的对象. object 基类用 x 初始化.

scope();

保存对当前关联 scope 对象的引用. object 基类用当前关联 scope 对象初始化. 在任何模块初始化函数之外, 当前关联的 Python 对象是 None.

~scope()

把当前关联的 Python 对象设置为存储的对象.

Example

下面的例子展示如何用 scope 设置来定义嵌套类.

C++ 模块定义:

#include <boost/python/module.hpp>
#include <boost/python/class.hpp>
#include <boost/python/scope.hpp>
using namespace boost::python;

struct X
{
  void f() {}

  struct Y { int g() { return 42; } };
};

BOOST_PYTHON_MODULE(nested)
{
   // add some constants to the current (module) scope
   scope().attr("yes") = 1;
   scope().attr("no") = 0;

   // Change the current scope 
   scope outer
       = class_<X>("X")
            .def("f", &X::f)
            ;

   // Define a class Y in the current scope, X
   class_<X::Y>("Y")
      .def("g", &X::Y::g)
      ;
}

交互式 Python:

>>> import nested
>>> nested.yes
1
>>> y = nested.X.Y()
>>> y.g()
42
