引言

make_getter() 与 make_setter() 是 class_<>::def_readonly 和 class_<>::def_readwrite 内部使用的函数, 用于生成包装 C++ 数据成员的 Python 可调用对象.

Functions 

template <class C, class D>
object make_getter(D C::*pm);

template <class C, class D, class Policies>
object make_getter(D C::*pm, Policies const& policies);

Requires

Policies 是 CallPolicies 的一个模型.

效果

创建一个 Python 可调用对象, 它接受一个可从 Python (from_python) 转换为 C* 的单参数, 并返回 C 对象相应的 D 成员, 按需转换为 Python (to_python). 如果提供了 policies, 它将按这里的描述应用于该函数. 否则, 库会尝试判断 D 是否为用户定义的类类型, 若是则为 Policies 使用 return_internal_reference<>. 注意, 在 D 是智能指针类型的某些情况下, 该测试可能会不恰当地选择 return_internal_reference<>. 这是一个已知缺陷.

Returns

持有新 Python 可调用对象的 object 实例.

template <class D>
object make_getter(D const& d);
template <class D, class Policies>
object make_getter(D const& d, Policies const& policies);

template <class D>
object make_getter(D const* p);
template <class D, class Policies>
object make_getter(D const* p, Policies const& policies);

Requires

Policies 是 CallPolicies 的一个模型.

效果

创建一个不接受任何参数的 Python 可调用对象, 它返回 d 或 *p, 按需转换为 Python (to_python). 如果提供了 policies, 它将按这里的描述应用于该函数. 否则, 库会尝试判断 D 是否为用户定义的类类型, 若是则为 Policies 使用 reference_existing_object.

Returns

持有新 Python 可调用对象的 object 实例.

template <class C, class D>
object make_setter(D C::*pm);

template <class C, class D, class Policies>
object make_setter(D C::*pm, Policies const& policies);

Requires

Policies 是 CallPolicies 的一个模型.

效果

创建一个 Python 可调用对象, 从 Python 调用时它期望两个参数, 分别可从 Python (from_python) 转换为 C* 和 D const&, 并设置 C 对象相应的 D 成员. 如果提供了 policies, 它将按这里的描述应用于该函数.

Returns

持有新 Python 可调用对象的 object 实例.

template <class D>
object make_setter(D& d);
template <class D, class Policies>
object make_setter(D& d, Policies const& policies);

template <class D>
object make_setter(D* p);
template <class D, class Policies>
object make_setter(D* p, Policies const& policies);

Requires

Policies 是 CallPolicies 的一个模型.

效果

创建一个接受一个参数的 Python 可调用对象, 该参数从 Python 转换为 D const& 并分别写入 d 或 *p. 如果提供了 policies, 它将按这里的描述应用于该函数.

Returns

持有新 Python 可调用对象的 object 实例.

Example

下面的代码使用 make_getter 和 make_setter 把数据成员暴露为函数:

#include <boost/python/data_members.hpp>
#include <boost/python/module.hpp>
#include <boost/python/class.hpp>

struct X
{
    X(int x) : y(x) {}
    int y;
};

using namespace boost::python;

BOOST_PYTHON_MODULE_INIT(data_members_example)
{
    class_<X>("X", init<int>())
       .def("get", make_getter(&X::y))
       .def("set", make_setter(&X::y))
       ;
}

在 Python 中可以这样使用:

>>> from data_members_example import *
>>> x = X(1)
>>> x.get()
1
>>> x.set(2)
>>> x.get()
2
