引言

暴露从泛化 Python 对象提取 C++ 对象值的机制. 注意, extract<...> 也可用于把 object "向下转型" 为某个具体的 ObjectWrapper. 由于用同类型的参数调用可变 Python 类型 (例如 list([1,2]) 通常会复制参数对象, 这可能是访问原对象上 ObjectWrapper 接口的唯一途径.

类模板 extract

extract<T> 可用于从 object 实例提取任意 C++ 类型的值. 支持两种用法:

  1. extract<T>(o) 是一个临时对象, 可隐式转换为 T (也可以通过对象的函数调用运算符显式转换). 然而, 如果没有可用的转换把 o 转换为 T 类型的对象, 将引发 Python TypeError 异常.
  2. extract<T> x(o); 构造一个提取器, 其 check() 成员函数可用于查询是否有可用转换而不引发异常.
namespace boost { namespace python
{
  template <class T>
  struct extract
  {
      typedef unspecified result_type;

      extract(PyObject*);
      extract(object const&);

      result_type operator()() const;
      operator result_type() const;

      bool check() const;
  };
}}

类模板 extract 构造函数与析构函数 

extract(PyObject* p);
extract(object const&);

Requires

第一种形式要求 p 非空.

效果

存储一个指向其构造函数参数所管理的 Python 对象的指针. 特别地, 不递增该对象的引用计数. 用户有责任确保在调用提取器的转换函数之前它不会被销毁.

类模板 extract 观察者函数 

result_type operator()() const;
operator result_type() const;

效果

把存储的指针转换为 result_type, 即 T 或 T const&.

Returns

一个 result_type 对象, 对应于存储指针所引用的对象.

Throws

error_already_set, 且当没有这样的转换可用时设置 TypeError. 也可能发出实际使用的转换器抛出的其他未指定异常.

bool check() const;

Postconditions

无. 特别注意, 返回 true 并不排除 operator result_type() 或 operator()() 抛出异常.

Returns

仅当不存在从存储指针到 T 的转换时才为 false.

Example 

#include <cstdio>
using namespace boost::python;
int Print(str s)
{
   // extract a C string from the Python string object
   char const* c_str = extract<char const*>(s);

   // Print it using printf
   std::printf("%s\n", c_str);

   // Get the Python string's length and convert it to an int
   return extract<int>(s.attr("__len__")())
}

下面的示例展示如何把 extract 与 class_<...> 结合使用, 创建并访问被包装 C++ 类的实例.

struct X
{
   X(int x) : v(x) {}
   int value() { return v; }
 private:
   int v;
};

BOOST_PYTHON_MODULE(extract_ext)
{
    object x_class(
       class_<X>("X", init<int>())
          .def("value", &X::value))
          ;

    // Instantiate an X object through the Python interface. 
    // Its lifetime is now managed by x_obj.
    object x_obj = x_class(3);

    // Get a reference to the C++ object out of the Python object
    X& x = extract<X&>(x_obj);
    assert(x.value() == 3);
}
