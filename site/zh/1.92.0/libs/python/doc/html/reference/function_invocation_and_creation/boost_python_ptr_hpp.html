引言

<boost/python/ptr.hpp> 定义了 ptr() 函数模板, 它允许用户在实现可改写虚函数、调用 Python 可调用对象或把 C++ 对象显式转换为 Python 的语境中, 指定如何把 C++ 指针值转换为 Python. 通常, 在把指针传给 Python 回调时, 指针所指对象会被复制, 以确保 Python 对象永远不会持有悬空引用. 若要指明新的 Python 对象应当只包含指针 p 的一个副本, 用户可以传入 ptr(p) 而不是直接传入 p. 这一接口意在对应 boost::ref() 的用法, 后者同样可用于防止所指对象被复制.

ptr(p) 返回 pointer_wrapper<> 的一个实例, 可以用 is_pointer_wrapper<> 元函数检测它; unwrap_pointer<> 是一个从 pointer_wrapper<> 提取原始指针类型的元函数. 这些类可视为实现细节.

Functions 

template <class T>
pointer_wrapper<T> ptr(T x);

Requires

T 是指针类型.

Returns

pointer_wrapper<T>(x)

Throws

无.

类模板 pointer_wrapper

一种 "类型信封" (type envelope), 由 ptr() 返回, 用于为传给 Python 回调的指针指示引用语义.

namespace boost { namespace python
{
    template<class Ptr> class pointer_wrapper
    {
     public:
        typedef Ptr type;

        explicit pointer_wrapper(Ptr x);
        operator Ptr() const;
        Ptr get() const;
    };
}}

Rationale

pointer_wrapper 旨在充当实际指针类型的替身, 但有时最好有一种显式取回指针的方法.

Metafunctions

类模板 is_pointer_wrapper
类模板 unwrap_pointer

类模板 is_pointer_wrapper

一个一元元函数, 当且仅当其参数是 pointer_wrapper<> 时其值为 true.

namespace boost { namespace python
{
    template<class T> class is_pointer_wrapper
    {
        static unspecified value = ...;
    };
}}

Returns

true, 当且仅当 T 是 pointer_wrapper<> 的特化. value 是可转换为 bool 的未指定类型的整型常量

类模板 unwrap_pointer

一个一元元函数, 从 pointer_wrapper<> 的特化中提取被包装指针类型.

namespace boost { namespace python
{
    template<class T> class unwrap_pointer
    {
        typedef unspecified type;
    };
}}

Returns

T::type, 若 T 是 pointer_wrapper<> 的特化; 否则为 T

Example

本示例演示 ptr() 的用法, 用于防止对象被复制:

#include <boost/python/call.hpp>
#include <boost/python/ptr.hpp>

class expensive_to_copy
{
   ...
};

void pass_as_arg(expensive_to_copy* x, PyObject* f)
{
   // call the Python function f, passing a Python object built around
   // which refers to *x by-pointer.
   //
   // *** Note: ensuring that *x outlives the argument to f() is    ***
   // *** up to the user! Failure to do so could result in a crash! ***

   boost::python::call<void>(f, ptr(x));
}
