boost/python/opaque_pointer_converter.hpp

引言
类模板 opaque 构造函数
宏 BOOST_PYTHON_OPAQUE_SPECIALIZED_TYPE_ID(Pointee)

引言

opaque<> 把自身注册为一个转换器, 在 Python 对象与指向未定义类型的指针之间双向转换.

namespace boost { namespace python
{
    template<class Pointee>
    struct opaque
    {
        opaque();
    };
}}

类模板 opaque 构造函数 

opaque();

效果
  • 把该实例注册为 lvalue_from_pytype 转换器, 从 Python 对象转换为不透明指针. 所创建的 Python 对象以被包装不透明指针所指向的类型命名.
  • 把该实例注册为 to_python_converter, 从不透明指针转换为 Python 对象.
注释

如果另一个模块已经注册了实例, 此实例不会再次尝试注册, 以避免出现多重注册的警告.

宏 BOOST_PYTHON_OPAQUE_SPECIALIZED_TYPE_ID(Pointee)

必须使用这个宏来定义 type_id 函数的特化——它不能为不完整类型实例化.

注释

必须在每个使用不透明转换器的翻译单元中调用该宏.
