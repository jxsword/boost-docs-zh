引言

索引 (Indexing) 是 Boost Python 的一个设施, 用于把可索引 C++ 容器轻松导出到 Python. 可索引容器是允许通过 operator[] 进行随机访问的容器 (例如 std::vector).

虽然 Boost Python 已具备把可索引 C++ 容器 (如无处不在的 std::vector) 暴露给 Python 所需的全部设施, 但这一过程并不像我们希望的那样直接. Python 容器不容易映射到 C++ 容器. 在 C++ 中模拟 Python 容器 (参见 Python 参考手册 模拟容器类型) 并非易事, 即便使用 Boost.Python. 在能把 C++ 容器映射到 Python 之前, 有许多问题需要考虑. 这包括为方法 __len__、__getitem__、__setitem__、__delitem__、__iter__ 和 __contains__ 实现包装函数.

目标:

  • 让可索引 C++ 容器的行为与人们对 Python 容器的预期完全一致.

  • 为容器元素索引 (__getitem__) 提供默认的引用语义, 使 c[i] 可以是可变的. 要求:

    val = c[i]
c[i].m()
val == c[i]

    其中 m 是非常量 (可修改) 成员函数 (方法).

  • 从 __getitem__ 返回安全引用, 使得随后对容器的添加和删除不会导致悬空引用 (不会使 Python 崩溃).
  • 支持切片索引.
  • 在适当之处接受 Python 容器参数 (例如 lists、tuples).
  • 允许通过可重定义的策略类实现扩展性.
  • 为最常见的 STL 及类 STL 可索引容器提供预定义支持.

索引接口

indexing_suite 类是管理要集成到 Python 的 C++ 容器的基类. 其目标是让 C++ 容器的外观、手感与行为都与我们预期的 Python 容器完全一致. 该类自动包装这些特殊的 Python 方法 (取自 Python 参考: 模拟容器类型):

__len__(self)

被调用以实现内建函数 len(). 应返回对象的长度, 一个整数 >= 0. 此外, 未定义 __nonzero__() 方法且其 __len__() 方法返回零的对象, 在布尔上下文中被视为假.

__getitem__(self, key)

被调用以实现 self[key] 的求值. 对序列类型, 接受的键应当是整数和切片对象. 注意, 负索引的特殊解释 (如果类希望模拟序列类型) 由 __getitem__() 方法负责. 如果 key 类型不当, 可能引发 TypeError; 如果值超出序列的索引集合 (在对负值做任何特殊解释之后), 应引发 IndexError. [注意: for 循环预期对非法索引会引发 IndexError, 以便正确检测序列的结束.]

__setitem__(self, key, value)

被调用以实现对 self[key] 的赋值. 注意事项与 __getitem__() 相同. 仅当对象支持更改键对应的值或可以添加新键时, 才应为映射实现它; 仅当元素可以被替换时, 才应为序列实现它. 对不当键值应引发与 __getitem__() 方法相同的异常.

__delitem__(self, key)

被调用以实现删除 self[key]. 注意事项与 __getitem__() 相同. 仅当对象支持移除键时, 才应为映射实现它; 仅当元素可以从序列中移除时, 才应为序列实现它. 对不当键值应引发与 __getitem__() 方法相同的异常.

__iter__(self)

当容器需要迭代器时会调用此方法. 此方法应返回一个新的迭代器对象, 它能遍历容器中的所有对象. 对映射而言, 它应遍历容器的键, 并且还应作为 iterkeys() 方法提供.

迭代器对象也需要实现此方法; 它们必须返回自身. 关于迭代器对象的更多信息, 参见 Iterator Types (见 Python Library Reference).

__contains__(self, item)

被调用以实现成员测试运算符. 若 item 在 self 中应返回 true, 否则返回 false. 对映射对象, 应考虑映射的键, 而不是值或键-值对.

index_suite 子类

indexing_suite 并不打算直接使用. 必须由 indexing_suite 的子类提供几个策略函数. 不过, 将为标准可索引 STL 容器提供一组 indexing_suite 子类; 大多数情况下, 我们可以直接使用现成的预定义套件. 某些情况下, 我们可以精化预定义套件以满足需要.

vector_index_suite

vector_indexing_suite 类是一个预定义的 indexing_suite 派生类, 设计用于包装 std::vector (以及类似 std::vector 的 [即具有 std::vector 接口的] 类). 它提供 indexing_suite 所需的全部策略.

用法示例:

class X {...};
...
class_<std::vector<X> >("XVec")
  .def(vector_indexing_suite<std::vector<X> >())
;

XVec 现在是一个功能完备的 Python 容器 (参见完整示例及其 Python 测试).

map_index_suite

map_indexing_suite 类是一个预定义的 indexing_suite 派生类, 设计用于包装 std::map (以及类似 std::map 的 [即具有 std::map 接口的] 类). 它提供 indexing_suite 所需的全部策略.

用法示例:

class X {...};
...

class_<std::map<X> >("XMap")
    .def(map_indexing_suite<std::map<X> >())
;

默认情况下, 被索引元素通过代理返回. 可以通过提供 true 给 NoProxy 模板参数来禁用这一点. XMap 现在是一个功能完备的 Python 容器 (参见完整示例及其 Python 测试).

    index_type to, size_type len);

这些策略大多不言自明. 然而, convert_index 和 adjust_index 值得解释一下.

convert_index 把 Python 索引转换为容器能处理的 C++ 索引. 例如, 按照约定, Python 中的负索引从右边开始计数 (例如 C1 索引 C 中最右边的元素). convert_index 应当为 C++ 容器处理必要的转换 (例如把 -1 转换为 C.size()-1). convert_index 还应当能把索引的类型 (动态的 Python 类型) 转换为 C++ 容器期望的实际类型.

当容器扩张或收缩时, 持有的元素索引必须加以调整以跟随数据的移动. 例如, 如果我们从 5 元素向量中从索引 0 开始擦除 3 个元素, 原来在索引 4 的元素现在将在索引 1:

[a][b][c][d][e] ---> [d][e]
              ^           ^
              4           1

adjust_index 负责这一调整. 给定当前索引, 当容器中 from..to 索引处的数据被 len 个元素替换时, 该函数应返回调整后的索引.

indexing_suite 的一个子类

vector_indexing_suite 仍可被派生, 以进一步微调任何预定义策略. 通过 CRTP (James Coplien. "Curiously Recurring Template Pattern". C++ Report, Feb. 1995) 实现的静态多态, 使基类 indexing_suite 能够调用最终派生类的策略函数

 
template <class Container,
	  bool NoProxy = false,
          class DerivedPolicies = unspecified_default>
class vector_indexing_suite : unspecified_base
{
public:

    typedef typename Container::value_type data_type;
    typedef typename Container::value_type key_type;
    typedef typename Container::size_type index_type;
    typedef typename Container::size_type size_type;
    typedef typename Container::difference_type difference_type;

    data_type&
    get_item(Container& container, index_type i);

    static object
    get_slice(Container& container, index_type from, index_type to);

    static void
    set_item(Container& container, index_type i, data_type const& v);

    static void
    set_slice(Container& container, index_type from,
        index_type to, data_type const& v);

    template <class Iter>
    static void
    set_slice(Container& container, index_type from,
        index_type to, Iter first, Iter last);

    static void
    delete_item(Container& container, index_type i);

    static void
    delete_slice(Container& container, index_type from, index_type to);

    static size_t
    size(Container& container);

    static bool
    contains(Container& container, key_type const& key);

    static index_type
    convert_index(Container& container, PyObject* i);

    static index_type
    adjust_index(index_type current, index_type from,
        index_type to, size_type len);
};
