引言

暴露把 Python 解释器嵌入 C++ 代码的机制.

函数 eval 

object eval(str expression,
            object globals = object(),
            object locals = object());

效果

在由字典 globals 和 locals 指定的上下文中, 从 expression 求值 Python 表达式.

Returns

持有表达式值的 object 实例.

函数 exec 

object exec(str code,
            object globals = object(),
            object locals = object());

效果

在由字典 globals 和 locals 指定的上下文中, 从 code 执行 Python 源代码.

Returns

持有执行代码结果的 object 实例.

函数 exec_file 

object exec_file(str filename,
                 object globals = object(),
                 object locals = object());

效果

在由字典 globals 和 locals 指定的上下文中, 从 filename 命名的文件执行 Python 源代码.

Returns

持有执行代码结果的 object 实例.

示例

下面的示例演示如何使用 import 和 exec 在 Python 中定义函数, 之后从 C++ 内部调用它.

#include <iostream>
#include <string>

using namespace boost::python;

void greet()
{
  // Retrieve the main module.
  object main = import("__main__");

  // Retrieve the main module's namespace
  object global(main.attr("__dict__"));

  // Define greet function in Python.
  object result = exec(
    "def greet():                   \n"
    "   return 'Hello from Python!' \n",
    global, global);

  // Create a reference to it.
  object greet = global["greet"];

  // Call it.
  std::string message = extract<std::string>(greet());
  std::cout << message << std::endl;
}

def greet():
   return 'Hello from Python!'
