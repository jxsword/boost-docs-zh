引言

<boost/python/def_visitor.hpp> 提供一个通用的访问接口, 通过它 class_ 的 def 成员功能可以以非侵入方式扩展, 避免使 class_ 接口变得杂乱. 它声明了 def_visitor<T> 类模板, 该模板以派生类型 DerivedVisitor 为参数, 后者提供实际的 def 功能, 通过其 visit 成员函数.

类 def_visitor

类 def_visitor 是一个由其派生类参数化的基类. def_visitor 类是一个协议类. 其派生类 DerivedVisitor 应当有一个成员函数 visit. def_visitor 类从不被直接实例化. 相反, 其子类 DerivedVisitor 的实例被作为参数传递给 class_ 的 def 成员函数.

namespace boost { namespace python {

    template <class DerivedVisitor>
    class def_visitor {};
}

visitor.visit(cls)

void

cls 是一个被包装到 Python 的 class_ 实例. visitor 是一个 def_visitor 派生类.

对 cls.def(visitor) 的调用会转发到这个成员函数.

visitor.visit(cls, name, options)

void

cls 是一个 class_ 实例, name 是 C 字符串. visitor 是一个 def_visitor 派生类. options 是特定于上下文的可选参数.

对 cls.def(name, visitor) 或 cls.def(name, visitor, options) 的调用会转发到这个成员函数.

Example 

class X {/*...*/};

class my_def_visitor : boost::python::def_visitor<my_def_visitor>
{
  friend class def_visitor_access;

  template <class classT>
  void visit(classT& c) const
  {
    c.def("foo", &my_def_visitor::foo);
    c.def("bar", &my_def_visitor::bar);
  }

  static void foo(X& self);
  static void bar(X& self);
};

BOOST_PYTHON_MODULE(my_ext)
{
  class_<X>("X")
    .def(my_def_visitor());
}
