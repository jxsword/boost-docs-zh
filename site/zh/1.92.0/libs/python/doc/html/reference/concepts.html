CallPolicies

引言
CallPolicies 组合
概念要求

引言

CallPolicies 概念的模型用于特化 Boost.Python 为被包装 C++ 对象 (如函数指针和成员函数指针) 生成的 Python 可调用对象的行为, 提供三种行为:

  1. precall - 在被包装对象被调用之前的 Python 参数元组管理
  2. result_converter - C++ 返回值处理
  3. postcall - 在被包装对象被调用之后的 Python 参数元组与结果管理
  4. extract_return_type - 从给定签名类型序列提取返回类型的元函数

CallPolicies 组合

为了允许在同一个可调用对象中使用多个 CallPolicies 模型, Boost.Python 的 CallPolicies 类模板提供了一个链接接口, 允许它们被递归组合. 该接口的形式是一个可选模板参数 Base, 其默认值为 default_call_policies. 按约定, precall 函数——属于 Base——在 precall 函数——由 outer 模板提供——之后被调用; 而 postcall 函数——属于 Base——在 postcall 函数——属于 outer 模板——之前被调用. 如果 result_converter 由 outer 模板提供, 它会替换 result_converter——即由 Base 提供的那个. 示例参见 return_internal_reference.

P::result_converter

ResultConverterGenerator 的一个模型.

一个 MPL 一元元函数类, 用于生成 "初步" 结果对象.

x.postcall(a, r)

可转换为 PyObject*

失败时返回 0 和 PyErr_Occurred() != 0. 即使发生异常也必须 "保全引用". 换言之, 如果没有返回 r, 其引用计数必须递减; 如果返回了另一个既有对象, 其引用计数必须递增.

P::extract_return_type

Metafunction 的一个模型.

一个 MPL 一元元函数, 用于从给定签名提取返回类型. 默认情况下它派生自 mpl::front.
