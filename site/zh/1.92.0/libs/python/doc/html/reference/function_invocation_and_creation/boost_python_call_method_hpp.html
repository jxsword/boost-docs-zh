引言

<boost/python/call_method.hpp> 定义了 call_method 系列重载函数模板, 用于从 C++ 调用 Python 对象的可调用属性.

函数 call_method 

template <class R, class A1, class A2, ... class An>
R call_method(PyObject* self, char const* method, A1 const&, A2 const&, ... An const&)

Requires

R 是指针类型、引用类型或具有可访问复制构造函数的完整类型

效果

在 Python 中调用 self.method(a1, a2, ...an), 其中 a1...an 是 call_method() 的参数, 已被转换为 Python 对象. 完整的语义描述参见本页.

Returns

Python 调用的结果, 已转换为 C++ 类型 R.

Rationale

call_method 对实现在 Python 中可改写的 C++ 虚函数至关重要, 如下面的示例所示.

Example

下面的 C++ 代码说明了在包装带有可在 Python 中改写的虚函数的类时 call_method 的用法: C++ 模块定义

#include <boost/python/module.hpp>
#include <boost/python/class.hpp>
#include <boost/python/call_method.hpp>
#include <boost/python/def.hpp>
#include <boost/utility.hpp>
#include <cstring>

// class to be wrapped
class Base
{
 public:
   virtual char const* class_name() const { return "Base"; }
   virtual ~Base() {};
};

bool is_base(Base* b)
{
   return !std::strcmp(b->class_name(), "Base");
}

// Wrapper code begins here
using namespace boost::python;

// Callback class
class Base_callback : public Base
{
 public:
   Base_callback(PyObject* self) : m_self(self) {}

   char const* class_name() const { return call_method<char const*>(m_self, "class_name"); }
   char const* Base_name() const { return Base::class_name(); }
 private:
   PyObject* const m_self;
};

using namespace boost::python;
BOOST_PYTHON_MODULE(my_module)
{
    def("is_base", is_base);

    class_<Base,Base_callback, boost::noncopyable>("Base")
        .def("class_name", &Base_callback::Base_name)
        ;

}

Python 代码:

>>> from my_module import *
>>> class Derived(Base):
...    def __init__(self):
...       Base.__init__(self)
...    def class_name(self):
...       return self.__class__.__name__
...
>>> is_base(Base()) # calls the class_name() method from C++
1
>>> is_base(Derived())
0
