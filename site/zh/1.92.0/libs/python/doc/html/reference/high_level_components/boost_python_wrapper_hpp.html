引言

要包装类 T 使其虚函数可以 "在 Python 中改写"——即当虚函数从 C++ 调用时, Python 派生类的相应方法会被调用——你必须创建一个派生自 T 的 C++ 包装器类, 它改写那些虚函数, 使它们调用进入 Python. 本头文件包含一些可以让这项工作更容易的类.

类 override

封装 C++ 虚函数的一个 Python 改写. override 对象要么持有一个可调用的 Python 对象, 要么持有 None.

namespace boost
{
  class override : object
  {
   public:
      unspecified operator() const;
      template <class A0>
      unspecified operator(A0) const;
      template <class A0, class A1>
      unspecified operator(A0, A1) const;
      ...
      template <class A0, class A1, ...class An>
      unspecified operator(A0, A1, ...An) const;
  };
};

类 override 观察者函数 

unspecified operator() const;
template <class A0>
unspecified operator(A0) const;
template <class A0, class A1>
unspecified operator(A0, A1) const;
...
template <class A0, class A1, ...class An>
unspecified operator(A0, A1, ...An) const;

效果

如果 *this 持有可调用的 Python 对象, 则按这里指定的方式用给定参数调用它. 否则, 抛出 error_already_set.

Returns

一个未指定类型的对象, 持有调用的 Python 结果, 当转换为 C++ 类型 R 时, 尝试把该结果对象转换为 R. 如果转换失败, 抛出 error_already_set.

类模板 wrapper

让你的包装器类同时派生自 T 和 wrapper<T>, 可以使编写该派生类更容易.

namespace boost
{
  class wrapper
  {
   protected:
      override get_override(char const* name) const;
  };
};

类模板 wrapper 观察者函数 

override get_override(char const* name) const;

Requires

name 是一个 ntbs.

Returns

如果 *this 是一个改写了该具名函数的 Python 派生类实例的 C++ 基类子对象, 则返回一个委托给该 Python 改写的 override 对象. 否则, 返回一个持有 None 的 override 对象.

Example 

#include <boost/python/module.hpp>
#include <boost/python/class.hpp>
#include <boost/python/wrapper.hpp>
#include <boost/python/call.hpp>

using namespace boost::python;

// Class with one pure virtual function
struct P
{
    virtual ~P(){}
    virtual char const* f() = 0;
    char const* g() { return "P::g()"; }
};

struct PCallback : P, wrapper<P>
{
    char const* f()
    {
        return this->get_override("f")();
    }
};

// Class with one non-pure virtual function
struct A
{
    virtual ~A(){}
    virtual char const* f() { return "A::f()"; }
};

struct ACallback :  A, wrapper<A>
{
    char const* f()
    {
        if (override f = this->get_override("f"))
            return f();
        return A::f();
    }

    char const* default_f() { return this->A::f(); }
};

BOOST_PYTHON_MODULE_INIT(polymorphism)
{
    class_<PCallback,boost::noncopyable>("P")
        .def("f", pure_virtual(&P::f))
        ;

    class_<ACallback,boost::noncopyable>("A")
        .def("f", &A::f, &ACallback::default_f)
        ;
}
