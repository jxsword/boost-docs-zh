重载分派表达式

定义用于生成重载 Python 函数族和扩展类方法的设施, 来源是带默认参数的 C++ 函数和成员函数, 或类似的 C++ 重载族

重载分派表达式

重载分派表达式用于描述要为扩展类生成的一族重载方法. 它具有以下属性:

文档字符串

一个 ntbs, 其值将绑定到方法的 __doc__ 属性

关键字

一个 关键字表达式, 将用于为所生成方法的 (末尾子序列) 参数命名.

调用策略

建模 CallPolicies 的某个类型的实例.

最小元数

生成的某个方法重载所接受的最小参数个数.

最大元数

生成的某个方法重载所接受的最大参数个数.

OverloadDispatcher 概念

OverloadDispatcher X 是一个具有最小元数和最大元数的类, 并且对它而言, 以下都是有效的重载分派表达式, 其最小与最大元数与该 OverloadDispatcher 相同.

X()
X(docstring)
X(docstring, keywords)
X(keywords, docstring)
X()[policies]
X(docstring)[policies]
X(docstring, keywords)[policies]
X(keywords, docstring)[policies]

* 如果提供了 policies, 它必须是建模 CallPolicies 的类型的实例, 并将用作结果的调用策略. 否则, 结果的调用策略将是 default_call_policies 的实例. * 如果提供了 docstring, 它必须是 ntbs, 并将用作结果的文档字符串. 否则, 结果具有空的文档字符串. * 如果提供了 keywords, 它必须是一个 关键字表达式 的结果, 其长度不大于 X 的最大元数, 并将用作结果的 keywords. 否则, 结果的 keywords 将为空.

Macros 

BOOST_PYTHON_FUNCTION_OVERLOADS(name, func_id, min_args, max_args)

展开为在当前作用域中定义一个名为 name 的 OverloadDispatcher, 它可用于生成以下函数调用:

func_id(a1, a2,...ai);

对所有的 min_args <= i <= max_args.

BOOST_PYTHON_MEMBER_FUNCTION_OVERLOADS(name, member_name, min_args, max_args)

展开为在当前作用域中定义一个名为 name 的 OverloadDispatcher, 它可用于生成以下函数调用:

x.member_name(a1, a2,...ai);

对所有的 min_args <= i <= max_args, 其中 x 是对类类型对象的引用.

Example 

#include <boost/python/module.hpp>
#include <boost/python/def.hpp>
#include <boost/python/args.hpp>
#include <boost/python/tuple.hpp>
#include <boost/python/class.hpp>
#include <boost/python/overloads.hpp>
#include <boost/python/return_internal_reference.hpp>

using namespace boost::python;

tuple f(int x = 1, double y = 4.25, char const* z = "wow")
{
    return make_tuple(x, y, z);
}

BOOST_PYTHON_FUNCTION_OVERLOADS(f_overloads, f, 0, 3)

struct Y {};
struct X
{
    Y& f(int x, double y = 4.25, char const* z = "wow")
    {
        return inner;
    }
    Y inner;
};

BOOST_PYTHON_MEMBER_FUNCTION_OVERLOADS(f_member_overloads, f, 1, 3)

BOOST_PYTHON_MODULE(args_ext)
{
    def("f", f,
        f_overloads(
            args("x", "y", "z"), "This is f's docstring"
        ));


    class_<Y>("Y")
        ;

    class_<X>("X", "This is X's docstring")
        .def("f1", &X::f,
                f_member_overloads(
                    args("x", "y", "z"), "f's docstring"
                )[return_internal_reference<>()]
        )
        ;
}
