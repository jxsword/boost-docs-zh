引言

<boost/python/stl_iterator.hpp> 提供从 Python 可迭代对象 创建 C++ 迭代器的类型.

类模板 stl_input_iterator

stl_input_iterator<T> 的实例持有一个 Python 迭代器并对其进行适配, 使之可用于 STL 算法. stl_input_iterator<T> 满足输入迭代器的要求.

模板参数

要求

语义

默认值

ValueType

ValueType 必须可复制构造 (CopyConstructible).

解引用 stl_input_iterator<ValueType> 的实例将返回一个 ValueType 类型的右值.

无

 
namespace boost { namespace python
{
  template <class ValueType>
  struct stl_input_iterator
  {
      typedef std::ptrdiff_t difference_type;
      typedef ValueType value_type;
      typedef ValueType* pointer;
      typedef ValueType reference;
      typedef std::input_iterator_tag iterator_category;

      stl_input_iterator();
      stl_input_iterator(object const& ob);

      stl_input_iterator& operator++();
      stl_input_iterator operator++(int);

      ValueType operator*() const;

      friend bool operator==(stl_input_iterator const& lhs, stl_input_iterator const& rhs);
      friend bool operator!=(stl_input_iterator const& lhs, stl_input_iterator const& rhs);
  private:
      object it; // For exposition only
      object ob; // For exposition only
  };
}}

类模板 stl_input_iterator 构造函数 

stl_input_iterator()

效果

创建一个尾后输入迭代器, 用于表示序列结束.

Postconditions

this 为尾后

Throws

无.

stl_input_iterator(object const& ob)

效果

调用 ob.attr("__iter__")() 并把得到的 Python 迭代器对象存入 this->it. 然后, 调用 this->it.attr("next")() 并把结果存入 this->ob. 如果序列耗尽, 则把 this->ob 设为 object().

Postconditions

this 可解引用或为尾后.

类模板 stl_input_iterator 修饰函数 

stl_input_iterator &operator++()

效果

调用 this->it.attr("next")() 并把结果存入 this->ob. 如果序列耗尽, 则把 this->ob 设为 object().

Postconditions

this 可解引用或为尾后.

Returns

*this 

stl_input_iterator &operator++(int)

效果

stl_input_iterator tmp = *this; ++*this; return tmp;

Postconditions

this 可解引用或为尾后.

类模板 stl_input_iterator 观察者函数 

ValueType operator*() const

效果

返回序列中的当前元素.

Returns

extract<ValueType>(this->ob); 

friend bool operator==(stl_input_iterator const& lhs, stl_input_iterator const& rhs)

效果

如果两个迭代器都可解引用或都为尾后则返回 true, 否则返回 false.

Returns

(lhs.ob == object()) == (rhs.ob == object()) 

friend bool operator!=(stl_input_iterator const& lhs, stl_input_iterator const& rhs)

效果

如果两个迭代器都可解引用或都为尾后则返回 false, 否则返回 true.

Returns

!(lhs == rhs)

Example 

#include <boost/python/object.hpp>
#include <boost/python/stl_iterator.hpp>

#include <list>

using namespace boost::python;
std::list<int> sequence_to_int_list(object const& ob)
{
    stl_input_iterator<int> begin(ob), end;
    return std::list<int>(begin, end);
}
