引言

<boost/python/type_id.hpp> 提供用于运行期类型识别的类型和函数, 类似 <typeinfo> 的那些. 它的存在主要是为了绕过某些编译器缺陷以及与共享库的平台相关交互.

type_info 实例标识一个类型. 正如 std::type_info 的规定 (但不同于某些编译器中的实现), boost::python::type_info 从不表示顶层引用或 cv 限定 (见 C++ 标准 5.2.8 节). 与 std::type_info 不同, boost::python::type_info 实例可复制, 且比较总是能可靠地跨越共享库边界工作.

namespace boost { namespace python
{
  class type_info : totally_ordered<type_info>
  {
  public:
    // constructor
    type_info(std::type_info const& = typeid(void));

    // comparisons
    bool operator<(type_info const& rhs) const;
    bool operator==(type_info const& rhs) const;

    // observers
    char const* name() const;
  };
}}

类模板 type_info 构造函数 

type_info(std::type_info const& = typeid(void));

效果

构造一个 type_info 对象, 它标识与其参数相同的类型.

Rationale

由于偶尔需要构造 type_info 对象的数组, 提供了一个良性的默认参数. 注意: 此构造函数不修正编译器 typeid() 实现的不合规之处. 见下文 type_id.

类模板 type_info 比较 

bool operator<(type_info const &rhs) const;

效果

在 type_info 对象上给出全序.

bool operator==(type_info const &rhs) const;

Returns

当两个值描述同一类型时为 true.

Note

使用 totally_ordered<type_info> 作为私有基类会提供运算符 <=、>=、> 和 !=

类模板 type_info 观察者函数 

char const* name() const;

Returns

对用于构造该对象的参数调用 name() 的结果.

Functions 

std::ostream& operator<<(std::ostream&s, type_info const&x);

效果

把对 x 所描述类型的说明写入 s.

Rationale

并非每个 C++ 实现都提供真正人类可读的 type_info::name() 字符串, 但对某些实现, 我们也许能解码该字符串并给出合理的表示.

Note

在某些不合规的 C++ 实现上, 代码实际上并不像上面描述的那么简单; 语义被调整为像 C++ 实现合规那样工作.

Example

下面的例子虽然有些无聊, 但展示了 type_id 设施可能的用法

#include <boost/python/type_id.hpp>

// Returns true iff the user passes an int argument
template <class T>
bool is_int(T x)
{
   using boost::python::type_id;
   return type_id<T>() == type_id<int>();
}
