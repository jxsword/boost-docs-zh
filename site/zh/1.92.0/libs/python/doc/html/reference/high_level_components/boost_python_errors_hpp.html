引言

<boost/python/errors.hpp> 提供用于管理 Python 与 C++ 异常并在两者之间转换的类型和函数. 这是相对底层的功能, 主要由 Boost.Python 内部使用. 用户应当很少需要它.

类 error_already_set

error_already_set 是一个异常类型, 可以抛出它以表明发生了 Python 错误. 如果抛出, 前置条件是 PyErr_Occurred() 返回一个可转换为 true 的值. 可移植代码不应直接抛出这个异常类型, 而应使用下文的 throw_error_already_set().

namespace boost { namespace python
{
    class error_already_set {};
}}

Functions 

template <class T> bool handle_exception(T f) throw();
void handle_exception() throw();

Requires

第一种形式要求表达式 function0<void>(f) 有效. 第二种形式要求当前正在处理一个 C++ 异常 (见 C++ 标准第 15.1 节).

效果

第一种形式在 try 块内调用 f(), 该 try 块首先尝试使用所有已注册的 异常转换器. 如果其中没有一个转换该异常, catch 子句随后为捕获到的 C++ 异常设置相应的 Python 异常, 若抛出了异常则返回 true, 否则返回 false. 第二种形式把一个重新抛出当前正在处理的异常的函数传给第一种形式.

Postconditions

没有正在处理的异常

Throws

nothing

Rationale

在跨语言边界处, 必须确保没有 C++ 异常逃逸, 因为调用方语言通常不具备正确展开栈所需的机制. 每当你的 C++ 代码被 Python API 直接调用时, 都应使用 handle_exception 来管理异常转换. 常规的函数包装设施会自动替你完成: make_function()、make_constructor()、def() 和 class_::def(). 第二种形式使用起来可能更方便 (见下面的示例), 但多种编译器在从外层 try 块内重新抛出异常时都有问题.

template <class T> T* expect_non_null(T* x);

Returns

x

Throws

当 x == 0 时抛出 error_already_set().

Rationale

简化调用 Python/C API 中出错时返回 0 的函数时的错误处理.

void throw_error_already_set();

效果

throw error_already_set();

Rationale

简化调用 Python/C API 中出错时返回 0 的函数时的错误处理.

void throw_error_already_set();

效果

throw error_already_set();

Rationale

许多平台和编译器无法一致地捕获跨越共享库边界抛出的异常. 从 Boost.Python 库内使用这个函数可以确保 handle_exception() 中相应的 catch 块能够捕获该异常.

Example 

#include <string>
#include <boost/python/errors.hpp>
#include <boost/python/object.hpp>
#include <boost/python/handle.hpp>

// Returns a std::string which has the same value as obj's "__name__"
// attribute.
std::string get_name(boost::python::object obj)
{
   // throws if there's no __name__ attribute
   PyObject* p = boost::python::expect_non_null(
      PyObject_GetAttrString(obj.ptr(), "__name__"));

   char const* s = PyString_AsString(p);
   if (s != 0)
        Py_DECREF(p);

   // throws if it's not a Python string
   std::string result(
      boost::python::expect_non_null(
         PyString_AsString(p)));

   Py_DECREF(p); // Done with p

   return result;
}

//
// Demonstrate form 1 of handle_exception
//

// Place into result a Python Int object whose value is 1 if a and b have
// identical "__name__" attributes, 0 otherwise.
void same_name_impl(PyObject*& result, boost::python::object a, boost::python::object b)
{
   result = PyInt_FromLong(
      get_name(a) == get_name(a2));
}

object borrowed_object(PyObject* p)
{
   return boost::python::object(
        boost::python::handle<>(
             boost::python::borrowed(a1)));
}

// This is an example Python 'C' API interface function
extern "C" PyObject*
same_name(PyObject* args, PyObject* keywords)
{
   PyObject* a1;
   PyObject* a2;
   PyObject* result = 0;

   if (!PyArg_ParseTuple(args, const_cast<char*>("OO"), &a1, &a2))
      return 0;

   // Use boost::bind to make an object compatible with
   // boost::Function0<void>
   if (boost::python::handle_exception(
         boost::bind<void>(same_name_impl, boost::ref(result), borrowed_object(a1), borrowed_object(a2))))
   {
      // an exception was thrown; the Python error was set by
      // handle_exception()
      return 0;
   }

   return result;
}

//
// Demonstrate form 2 of handle_exception. Not well-supported by all
// compilers.
//
extern "C" PyObject*
same_name2(PyObject* args, PyObject* keywords)
{
   PyObject* a1;
   PyObject* a2;
   PyObject* result = 0;

   if (!PyArg_ParseTuple(args, const_cast<char*>("OO"), &a1, &a2))
      return 0;

   try {
      return PyInt_FromLong(
         get_name(borrowed_object(a1)) == get_name(borrowed_object(a2)));
   }
   catch(...)
   {
      // If an exception was thrown, translate it to Python
      boost::python::handle_exception();
      return 0;
   }
}
