引言

<boost/python/pointee.hpp> 引入特征元函数 template pointee<T>, 可用于从指针或智能指针的类型中提取 "被指向" 类型.

类模板 pointee

pointee<T> 被 class_<...> 模板用于推导所持有的类型——当指针或智能指针类型被用作其 HeldType 参数时.

namespace boost { namespace python
{
   template <class T> struct pointee
   {
      typedef T::element_type type;
   };

   // specialization for pointers
   template <T> struct pointee<T*>
   {
      typedef T type;
   };
}

示例

给定第三方智能指针类型 smart_pointer<T>, 可以部分特化 pointee<smart_pointer<T> >, 使其能用作类包装器的 HeldType:

#include <boost/python/pointee.hpp>
#include <boost/python/class.hpp>
#include <third_party_lib.hpp>

namespace boost { namespace python
{
  template <class T> struct pointee<smart_pointer<T> >
  {
     typedef T type;
  };
}}

BOOST_PYTHON_MODULE(pointee_demo)
{
   class_<third_party_class, smart_pointer<third_party_class> >("third_party_class")
      .def(...)
      ...
      ;
}
