引言

本头文件提供创建 Boost.Python 扩展模块所需的基本设施.

Macros

BOOST_PYTHON_MODULE(name) 用于声明 Python 模块初始化函数. name 参数必须与要初始化的模块名完全匹配, 并必须符合 Python 的 标识符命名规则. 在通常会写

extern "C" void initname()
{
   ...
}

Boost.Python 模块应当用以下方式初始化

BOOST_PYTHON_MODULE(name)
{
   ...
}

这个宏在其使用的作用域中生成两个函数: extern "C" void initname() 和 void init_module_name(), 其函数体必须紧跟宏调用之后. init_name 把 init_module_name 传给 handle_exception(), 使生成的任何 C++ 异常都得到安全处理. 在 init_name 的函数体中, 当前作用域 指的是被初始化的模块.

示例

C++ 模块定义:

#include <boost/python/module.hpp>

BOOST_PYTHON_MODULE(xxx)
{
    throw "something bad happened"
}

交互式 Python:
