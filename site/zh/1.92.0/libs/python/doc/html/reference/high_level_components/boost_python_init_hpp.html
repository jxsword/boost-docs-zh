引言

init 表达式

<boost/python/init.hpp> 定义了把 C++ 构造函数暴露为扩展类 __init__ 函数的接口.

init 表达式

init 表达式用于描述要为扩展类生成的一族 __init__ 方法, 其结果具有以下属性:

文档字符串

一个 ntbs, 其值将绑定到该方法的 __doc__ 属性

关键字

一个 关键字表达式, 将用于为所生成的 __init__ 函数的 (末尾子序列) 参数命名.

调用策略

CallPolicies 之模型的一个实例.

argument_types

一个 C++ 参数类型的 MPL 序列, 将用于构造被包装的 C++ 对象. init 表达式有一个或多个有效前缀, 由其参数类型的前缀序列给出.

类模板 init

类模板 init 构造函数
类模板 init 观察者函数

一个 MPL 序列, 可用于指定一族一个或多个 __init__ 函数. 所提供的最后一个 Ti 可以是 optional<...> 的实例.

namespace boost { namespace python
{
  template <T1 = unspecified,...Tn = unspecified>
  struct init
  {
    init(char const* doc = 0);
    template <class Keywords> init(Keywords const& kw, char const* doc = 0);
    template <class Keywords> init(char const* doc, Keywords const& kw);

    template <class CallPolicies>
    unspecified operator[](CallPolicies const& policies) const
  };
}}

类模板 init 构造函数 

init(char const* doc = 0);
template <class Keywords> init(Keywords const& kw, char const* doc = 0);
template <class Keywords> init(char const* doc, Keywords const& kw);

Requires

如果提供, doc 是一个 ntbs. 如果提供, kw 是一个

效果

结果是一个 init 表达式, 其文档字符串为 doc, 其关键字是对 kw 的引用. 如果使用第一种形式, 所得表达式的关键字为空. 该表达式的调用策略是 default_call_policies 的一个实例. 如果 Tn 是 optional<U1, U2,... Um>, 该表达式的有效前缀由下式给出:

(T1, T2,...Tn-1), (T1, T2,...Tn-1 , U1), (T1, T2,...Tn-1 , U1, U2), ...(T1, T2,...Tn-1 , U1, U2,...Um)

. 否则, 该表达式有一个由用户指定的模板参数给出的有效前缀.

类模板 init 观察者函数 

template <class Policies>
unspecified operator[](Policies const& policies) const

Requires

Policies 是 CallPolicies 的一个模型.

效果

返回一个新的 init-expression, 与 init 对象具有全部相同的属性, 但其调用策略被替换为对 policies 的引用.

类模板 optional

一个 MPL 序列, 可用于指定 __init__ 函数的可选参数.

namespace boost { namespace python
{
  template <T1 = unspecified,...Tn = unspecified>
  struct optional {};
}}

Example

给定以下 C++ 声明:

class Y;
class X
{
 public:
   X(int x, Y* y) : m_y(y) {}
   X(double);
 private:
   Y* m_y;
};

可以用以下方式创建相应的 Boost.Python 扩展类:

using namespace boost::python;

class_<X>("X", "This is X's docstring.",
          init<int,char const*>(args("x","y"), "X.__init__'s docstring")[
                with_custodian_and_ward<1,3>()]
          )
   .def(init<double>())
   ;
