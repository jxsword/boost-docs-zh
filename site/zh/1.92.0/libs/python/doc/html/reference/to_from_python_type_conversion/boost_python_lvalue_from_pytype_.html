引言

<boost/python/lvalue_from_pytype.hpp> 提供从给定类型的 Python 实例内部提取 C++ 对象的设施. 这在处理 "传统" Python 扩展类型时通常很有用.

类模板 lvalue_from_pytype

类模板 lvalue_from_pytype 构造函数

类模板 lvalue_from_pytype 将注册 from_python 转换器, 给定该 Python 类型的对象, 它们能提取指向特定 C++ 类型的引用和指针. 其模板参数为:

In the table below, x denotes an object of type PythonObject&

参数

要求

语义

Extractor

Extractor 的一个模型, 其 execute 函数返回引用类型.

一旦类型得到确认, 就从 Python 对象中提取左值

python_type

一个编译期常量 PyTypeObject*

此转换器可转换实例的 Python 类型. Python 子类型同样可转换.

 
namespace boost { namespace python
{
   template <class Extractor, PyTypeObject const* python_type>
   struct lvalue_from_pytype
   {
       lvalue_from_pytype();
   };
}}

类模板 lvalue_from_pytype 构造函数 

lvalue_from_pytype();

效果

注册能把给定类型的 Python 对象转换为 Extractor::execute 所返回类型的左值的转换器.

类模板 extract_identity

类模板 extract_identity 静态函数

extract_identity 是 Extractor 的一个模型, 可用于常见情形, 即要提取的 C++ 类型与 Python 对象类型相同.

namespace boost { namespace python
{
   template <class InstanceType>
   struct extract_identity
   {
      static InstanceType& execute(InstanceType& c);
   };
}}

类模板 extract_identity 静态函数 

InstanceType& execute(InstanceType& c);

Returns

c

类模板 extract_member

类模板 extract_member 静态函数

extract_member 是 Extractor 的一个模型, 可用于常见情形, 即要提取的 C++ 类型是 Python 对象的一个成员.

namespace boost { namespace python
{
   template <class InstanceType, class MemberType, MemberType (InstanceType::*member)>
   struct extract_member
   {
      static MemberType& execute(InstanceType& c);
   };
}}

类模板 extract_member 静态函数 

static MemberType& execute(InstanceType& c);

Returns

c.*member

Example

本示例假定有人已经实现了 Python 文档中的标准 noddy 示例模块, 而我们想构建一个操纵 Noddy 的模块. 由于 noddy_NoddyObject 简单到不携带任何有趣的信息, 这个示例有点刻意: 它假设你想出于某种原因跟踪一个特定对象. 这个模块必须与定义 noddy_NoddyType 的模块动态链接.

C++ 中:

#include <boost/python/module.hpp>
#include <boost/python/handle.hpp>
#include <boost/python/borrowed.hpp>
#include <boost/python/lvalue_from_pytype.hpp>

// definition lifted from the Python docs
typedef struct {
   PyObject_HEAD
} noddy_NoddyObject;

using namespace boost::python;
static handle<noddy_NoddyObject> cache;

bool is_cached(noddy_NoddyObject* x)
{
   return x == cache.get();
}

void set_cache(noddy_NoddyObject* x)
{
   cache = handle<noddy_NoddyObject>(borrowed(x));
}

BOOST_PYTHON_MODULE(noddy_cache)
{
   def("is_cached", is_cached);
   def("set_cache", set_cache);

   // register Noddy lvalue converter
   lvalue_from_pytype<extract_identity<noddy_NoddyObject>,&noddy_NoddyType>();
}

Python 中:

>>> import noddy
>>> n = noddy.new_noddy()
>>> import noddy_cache
>>> noddy_cache.is_cached(n)
0
>>> noddy_cache.set_cache(n)
>>> noddy_cache.is_cached(n)
1
>>> noddy_cache.is_cached(noddy.new_noddy())
0
