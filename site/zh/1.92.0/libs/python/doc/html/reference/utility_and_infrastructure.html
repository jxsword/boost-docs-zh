引言

<boost/python/has_back_reference.hpp> 定义了谓词元函数 has_back_reference<>, 用户可以特化它, 以表明被包装类实例持有一个与 Python 对象相对应的 PyObject*.

类模板 has_back_reference

一个一元元函数, 当且仅当其参数是 pointer_wrapper<> 时其值为 true.

namespace boost { namespace python
{
    template<class WrappedClass> class has_back_reference
    {
        typedef mpl::false_ type;
    };
}}

一个由 Boost.Python 检查的元函数, 用于确定被包装类可以如何构造.

type::value 是一个可转换为 bool 的未指定类型的整型常量. 特化可以为类型代入一个值为 true 的整型常量包装器, 当且仅当对 class_<WrappedClass>::def(init< type-sequence...>()) 的每次调用以及隐式包装的复制构造函数 (除非它是不可复制的) 而言, 都存在对应的构造函数 WrappedClass::WrappedClass(PyObject*, type-sequence...). 如果存在这样的特化, 每当 WrappedClass 构造函数从 Python 被调用时, 都会向它们传入一个指向相应 Python 对象的 "反向引用" 指针. 提供这个嵌套类型最简单的方式是从 mpl::true_ 派生特化.

示例

C++ 中:

#include <boost/python/class.hpp>
#include <boost/python/module.hpp>
#include <boost/python/has_back_reference.hpp>
#include <boost/python/handle.hpp>
#include <boost/shared_ptr.hpp>

using namespace boost::python;
using boost::shared_ptr;

struct X
{
    X(PyObject* self) : m_self(self), m_x(0) {}
    X(PyObject* self, int x) : m_self(self), m_x(x) {}
    X(PyObject* self, X const& other) : m_self(self), m_x(other.m_x) {}

    handle<> self() { return handle<>(borrowed(m_self)); }
    int get() { return m_x; }
    void set(int x) { m_x = x; }

    PyObject* m_self;
    int m_x;
};

// specialize has_back_reference for X
namespace boost { namespace python
{
  template <>
  struct has_back_reference<X>
    : mpl::true_
  {};
}}

struct Y
{
    Y() : m_x(0) {}
    Y(int x) : m_x(x) {}
    int get() { return m_x; }
    void set(int x) { m_x = x; }

    int m_x;
};

shared_ptr<Y>
Y_self(shared_ptr<Y> self) { return self; }

BOOST_PYTHON_MODULE(back_references)
{
    class_<X>("X")
       .def(init<int>())
       .def("self", &X::self)
       .def("get", &X::get)
       .def("set", &X::set)
       ;

    class_<Y, shared_ptr<Y> >("Y")
       .def(init<int>())
       .def("get", &Y::get)
       .def("set", &Y::set)
       .def("self", Y_self)
       ;
}

下面的 Python 会话说明 x.self() 返回调用它的那个 Python 对象, 而 y.self() 必须创建一个新的 Python 对象, 该对象引用同一个 Y 实例.

Python 中:

>>> from back_references import *
>>> x = X(1)
>>> x2 = x.self()
>>> x2 is x
1
>>> (x.get(), x2.get())
(1, 1)
>>> x.set(10)
>>> (x.get(), x2.get())
(10, 10)
>>>
>>>
>>> y = Y(2)
>>> y2 = y.self()
>>> y2 is y
0
>>> (y.get(), y2.get())
(2, 2)
>>> y.set(20)
>>> (y.get(), y2.get())
(20, 20)
