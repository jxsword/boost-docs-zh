引言

Python 2.5 引入了新的 Py_ssize_t typedef 和两个相关宏 (PEP 353). <boost/python/ssize_t.hpp> 头文件把这些定义导入 boost::python 命名空间, 作为 ssize_t、ssize_t_max 和 ssize_t_min. 并为向后兼容以前的 Python 版本提供了适当的定义.

类型定义

如果可用, 把 Py_ssize_t 导入 boost::python 命名空间; 否则为向后兼容提供适当的 typedef:

#if PY_VERSION_HEX >= 0x02050000
typedef Py_ssize_t ssize_t;
#else
typedef int ssize_t;
#endif

常量

如果可用, 把 PY_SSIZE_T_MAX 和 PY_SSIZE_T_MIN 作为常量导入 boost::python 命名空间; 否则为向后兼容提供适当的常量:

#if PY_VERSION_HEX >= 0x02050000
ssize_t const ssize_t_max = PY_SSIZE_T_MAX;
ssize_t const ssize_t_min = PY_SSIZE_T_MIN;
#else
ssize_t const ssize_t_max = INT_MAX;
ssize_t const ssize_t_min = INT_MIN;
#endif
