第 9 章 术语表

arity

函数或成员函数接受的参数个数. 除非另有说明, 指定元数时不计入成员函数的隐藏 this 参数.

ntbs

空终止字节字符串 (Null-Terminated Byte String), 即 'C' 字符串. C++ 字符串字面量都是 ntbs. ntbs 绝不能为 null.

raise

Python 中的异常是 "引发" (raise) 的, 而不像 C++ 中那样是 "抛出" (throw) 的. 当本文档说在 C++ 代码的上下文中 "引发" 了一个 Python 异常时, 意思是通过 Python/'C' API 设置了相应的 Python 异常, 并调用了 throw_error_already_set().

POD

C++ 标准中的一个技术术语. "Plain Ol'Data" 的缩写: POD-struct 是一种聚合类, 它没有非静态数据成员属于成员指针类型、非 POD-struct、非 POD-union (或此类类型的数组) 或引用, 没有用户定义的复制赋值运算符, 也没有用户定义的析构函数. 类似地, POD-union 是一种聚合联合, 它没有非静态数据成员属于成员指针类型、非 POD-struct、非 POD-union (或此类类型的数组) 或引用, 没有用户定义的复制赋值运算符, 也没有用户定义的析构函数. POD 类是作为 POD-struct 或 POD-union 的类. 聚合 (aggregate) 是一个数组或类 (第 9 条), 没有用户声明的构造函数 (12.1), 没有私有或受保护的非静态数据成员 (第 11 条), 没有基类 (第 10 条), 也没有虚函数 (10.3).

ODR

"单一定义规则" (One Definition Rule), 即 C++ 程序中的任何实体在构成程序的所有翻译单元 (目标文件) 中必须具有相同的定义.
