引言

def() 是可用于在 当前作用域 中把 C++ 函数和可调用对象暴露为 Python 函数的函数.

Functions 

template <class F>
void def(char const* name, F f);

template <class Fn, class A1>
void def(char const* name, Fn fn, A1 const&);

template <class Fn, class A1, class A2>
void def(char const* name, Fn fn, A1 const&, A2 const&);

template <class Fn, class A1, class A2, class A3>
void def(char const* name, Fn fn, A1 const&, A2 const&, A3 const&);

Requires

name 是一个符合 Python 标识符命名规则 的 ntbs.

  • 如果 Fn [派生自] object, 它将作为单个重载添加到 当前作用域. 要能派上用场, fn 应当是 可调用对象.

  • 如果 a1 是 重载分派表达式 的结果, 则只允许第二种形式, 且 fn 必须是指向函数或成员函数的指针, 其 元数 与 A1 的 最大元数 相同.

    效果: 对每个前缀 P (取自 Fn 的参数类型序列, 从长度等于 A1 的 最小元数 的那个开始), 添加一个 name(...) 函数重载到 当前作用域. 生成的每个重载都用 P 调用 a1 的调用表达式, 使用 a1 调用策略的一个副本. 如果 A1 的最长有效前缀包含 N 个类型且 a1 持有 M 个关键字, 则每个重载除前 N - M 个参数外的所有参数都使用关键字的初始序列.

  • 否则, fn 必须是非空的函数或成员函数指针, 并且会向当前作用域添加一个围绕 fn 构建的单个函数重载. 如果提供了 a1-a3 中的任何一个, 它们可以按任意顺序从下表中选取.

    助记名

    要求/类型性质

    效果

    docstring

    任何 ntbs

    该值将绑定到所生成方法重载的 __doc__ 属性.

    policies

    CallPolicies 的一个模型

    其副本将用作所生成方法重载的调用策略.

    keywords

    一个 关键字表达式 的结果, 其指定的参数个数不超过 元数 (该元数属于 fn).

    其副本将用作所生成方法重载的调用策略.

Example 

#include <boost/python/def.hpp>
#include <boost/python/module.hpp>
#include <boost/python/args.hpp>

using namespace boost::python;

char const* foo(int x, int y) { return "foo"; }

BOOST_PYTHON_MODULE(def_test)
{
    def("foo", foo, args("x", "y"), "foo's docstring");
}
