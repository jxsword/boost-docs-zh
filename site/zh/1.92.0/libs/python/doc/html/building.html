Requirements要求

Boost.Python 需要 Python 2.2 [1] 或 更新版本.


[1] 注意, 尽管我们曾用 Python 2.2 测试过 Boost.Python 的早期版本, 并且我们认为我们没有做任何破坏兼容性的事情, 但本版 Boost.Python 可能未在早于 2.4 的 Python 版本上测试过, 因此我们无法百分之百确定支持 python 2.2 和 2.3.
