如何使用 dtype

下面是一个简短教程, 展示如何用内建 Python 数据类型创建 ndarray, 并提取成员变量的类型和值

与之前一样, 首先获取必要的头文件, 设置命名空间, 并初始化 Python 运行时和 numpy 模块:

#include <boost/python/numpy.hpp>
#include <iostream>

namespace p = boost::python;
namespace np = boost::python::numpy;

int main(int argc, char **argv)
{
  Py_Initialize();
  np::initialize();

接着, 我们创建形状和 dtype. 我们使用 get_builtin 方法获取与内建 C++ dtype 对应的 numpy dtype. 这里, 我们将创建一个 3x3 数组, 传入 (3,3) 元组作为大小, 并以 double 作为数据类型

p::tuple shape = p::make_tuple(3, 3);
np::dtype dtype = np::dtype::get_builtin<double>();
np::ndarray a = np::zeros(shape, dtype);

最后, 我们可以使用 Python 命名空间中的 extract 方法打印数组. 这里, 我们先把变量转换为字符串, 然后使用 <char const * > 模板从该 Python 字符串中把它提取为 C++ 字符数组

std::cout << "Original array:\n" << p::extract<char const *>(p::str(a)) << std::endl;

我们还可以通过 ndarray 的 get_dtype 方法打印 ndarray 数据成员的 dtype

std::cout << "Datatype is:\n" << p::extract<char const *>(p::str(a.get_dtype())) << std::endl ;

我们也可以创建自定义 dtype, 并用自定义 dtype 构建 ndarray

我们使用 dtype 构造函数来创建自定义 dtype. 该构造函数接受一个列表作为参数.

该列表应包含一个或多个 (变量名, 变量类型) 格式的元组

因此首先创建一个包含变量名及其 dtype (double) 的元组, 以创建自定义 dtype

p::tuple for_custom_dtype = p::make_tuple("ha",dtype) ;

接着, 创建一个列表, 并把这个元组加入该列表. 然后用该列表创建自定义 dtype

p::list list_for_dtype ;
list_for_dtype.append(for_custom_dtype) ;
np::dtype custom_dtype = np::dtype(list_for_dtype) ;

现在我们可以创建一个由 *shape* 指定维度、且具有自定义 dtype 的 ndarray 了

  np::ndarray new_array = np::zeros(shape,custom_dtype);
}
