如何用裸指针访问数据

ndarray 包装器的优点之一是, 同一份数据可以在 Python 和 C++ 两端使用, 并且改动可以在两端都反映出来. from_data 方法使之成为可能.

与之前一样, 首先获取必要的头文件, 设置命名空间, 并初始化 Python 运行时和 numpy 模块:

#include <boost/python/numpy.hpp>
#include <iostream>

namespace p = boost::python;
namespace np = boost::python::numpy;

int main(int argc, char **argv)
{
  Py_Initialize();
  np::initialize();

在 C++ 中创建一个数组, 并把指向它的指针传给 from_data 方法来创建 ndarray:

int arr[] = {1,2,3,4,5};
np::ndarray py_array = np::from_data(arr, np::dtype::get_builtin<int>(),
                                     p::make_tuple(5),
                                     p::make_tuple(sizeof(int)),
                                     p::object());

打印源 C++ 数组和 ndarray, 检查它们是否相同:

std::cout << "C++ array :" << std::endl;
for (int j=0;j<4;j++)
{
  std::cout << arr[j] << ' ';
}
std::cout << std::endl
          << "Python ndarray :" << p::extract<char const *>(p::str(py_array)) << std::endl;

现在, 改变 Python ndarray 中的一个元素, 并检查源 C++ 数组中的值是否相应改变:

py_array[1] = 5 ;
std::cout << "Is the change reflected in the C++ array used to create the ndarray ? " << std::endl;
for (int j = 0; j < 5; j++)
{
  std::cout << arr[j] << ' ';
}

接着, 改变源 C++ 数组的一个元素, 看它是否反映在 Python ndarray 中:

  arr[2] = 8;
  std::cout << std::endl
            << "Is the change reflected in the Python ndarray ?" << std::endl
            << p::extract<char const *>(p::str(py_array)) << std::endl;
}

可以看到, 改动在两端都有反映. 这是因为 from_data 方法按引用传递 C++ 数组来创建 ndarray, 因此使用相同的存储位置来存放数据.
