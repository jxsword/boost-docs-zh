unary_ufunc 是一个结构体, 用作广播单个参数的中间步骤, 使 C++ 函数能够被转换为类似 ufunc 的函数

<boost/python/numpy/ufunc.hpp> 包含 unary_ufunc 结构体定义

概要

namespace boost
{
namespace python
{
namespace numpy
{

template <typename TUnaryFunctor,
          typename TArgument=typename TUnaryFunctor::argument_type,
          typename TResult=typename TUnaryFunctor::result_type>
struct unary_ufunc
{

  static object call(TUnaryFunctor & self,
                     object const & input,
                     object const & output) ;

  static object make();

};
}
}
}

构造函数

struct example_unary_ufunc
{
  typedef any_valid_type argument_type;
  typedef any_valid_type result_type;
};
要求:

必须用 typedef 把 any_valid 类型定义为有效的 C++ 类型, 才能正确使用该结构体的方法

注释:

必须把该结构体暴露为 Python 类, 并且必须创建该类的实例, 才能使用 call 方法——它对应于 Python 对象的 __call__ 属性

accessors

template <typename TUnaryFunctor,
          typename TArgument=typename TUnaryFunctor::argument_type,
          typename TResult=typename TUnaryFunctor::result_type>
static object call(TUnaryFunctor & self,
                   object const & input,
                   object const & output);
要求:

类型名 TUnaryFunctor, 以及可选的 TArgument (用于参数类型) 和 TResult (用于结果类型)

效果:

在广播其参数后, 把 Python 对象传给底层的 C++ 函子

template <typename TUnaryFunctor,
          typename TArgument=typename TUnaryFunctor::argument_type,
          typename TResult=typename TUnaryFunctor::result_type>
static object make();
要求:

类型名 TUnaryFunctor, 以及可选的 TArgument (用于参数类型) 和 TResult (用于结果类型)

返回:

用于调用结构体中重载的 () 运算符的 Python 函数对象 (在典型用法中)

示例

namespace p = boost::python;
namespace np = boost::python::numpy;

struct UnarySquare
{
  typedef double argument_type;
  typedef double result_type;
  double operator()(double r) const { return r * r;}
};

p::object ud = p::class_<UnarySquare, boost::shared_ptr<UnarySquare> >("UnarySquare").def("__call__", np::unary_ufunc<UnarySquare>::make());
p::object inst = ud();
std::cout << "Square of unary scalar 1.0 is " << p::extract <char const * > (p::str(inst.attr("__call__")(1.0))) << std::endl ;
