创建 ndarray

Boost.Numpy 库暴露了许多创建 ndarray 的方法. ndarray 可以用多种方式创建, 包括空数组和全零数组. ndarray 也可以从任意 Python 序列创建, 以及从数据和 dtype 创建.

本教程将向你介绍创建 ndarray 的一些方式. 这里涵盖的方法包括从任意 Python 序列以及从 C++ 容器创建 ndarray, 既使用单位步长也使用非单位步长

首先, 与之前一样, 初始化必要的命名空间和运行时

#include <boost/python/numpy.hpp>
#include <iostream>

namespace p = boost::python;
namespace np = boost::python::numpy;

int main(int argc, char **argv)
{
  Py_Initialize();
  np::initialize();

现在让我们从一个简单的元组创建 ndarray. 我们先创建一个元组对象, 然后把它传给 array 方法, 生成所需的元组

p::object tu = p::make_tuple('a','b','c');
np::ndarray example_tuple = np::array(tu);

现在让我们用列表做同样的事. 我们创建一个空列表, 用 append 方法添加一个元素, 然后像之前一样调用 array 方法

p::list l;
l.append('a');
np::ndarray example_list = np::array (l);

可选地, 我们还可以为数组指定 dtype

np::dtype dt = np::dtype::get_builtin<int>();
np::ndarray example_list1 = np::array (l,dt);

我们也可以通过提供数据数组和另外几个参数来创建数组.

首先, 创建一个整数数组

int data[] = {1,2,3,4,5};

创建该函数所需的形状和步长

p::tuple shape = p::make_tuple(5);
p::tuple stride = p::make_tuple(sizeof(int));

这里, 形状是 (4,), 步长是 sizeof(int)`. 步长是构造 ndarray 时到达下一个所需元素必须移动的字节数.

该函数还需要一个所有者, 用于跟踪传入的数据数组. 传入 None 是危险的

p::object own;

from_data 函数接受数据数组、数据类型、形状、步长和所有者作为参数, 并返回一个 ndarray

np::ndarray data_ex1 = np::from_data(data,dt, shape,stride,own);

现在让我们打印我们创建的 ndarray

std::cout << "Single dimensional array ::" << std::endl
          << p::extract<char const *>(p::str(data_ex)) << std::endl;

让我们把它变得更有趣一些. 我们用非单位步长从一个多维数组构造一个 3x2 的 ndarray

首先创建一个 3x4 的 8 位整数数组

uint8_t mul_data[][4] = {{1,2,3,4},{5,6,7,8},{1,3,5,7}};

现在让我们创建一个 3x2 元素的数组, 从每行中挑选第 1 和第 3 个元素. 为此, 形状将是 3x2. 步长将是 4x2, 即移动到下一个所需的行需要 4 字节, 移动到下一个所需的列需要 2 字节

shape = p::make_tuple(3,2);
stride = p::make_tuple(sizeof(uint8_t)*2,sizeof(uint8_t));

获取内建 8 位整数数据类型的 numpy dtype

np::dtype dt1 = np::dtype::get_builtin<uint8_t>();

现在让我们先按原样创建并打印 ndarray. 注意我们可以直接把形状和步长传给函数, 连同所有者. 最后这一部分可以这样做, 是因为我们没有任何操纵 "所有者" 对象的需求

np::ndarray mul_data_ex = np::from_data(mul_data, dt1,
                                        p::make_tuple(3,4),
                                        p::make_tuple(4,1),
                                        p::object());
std::cout << "Original multi dimensional array :: " << std::endl
          << p::extract<char const *>(p::str(mul_data_ex)) << std::endl;

现在用该形状和步长创建新的 ndarray, 并打印我们用非单位步长创建的数组

  mul_data_ex = np::from_data(mul_data, dt1, shape, stride, p::object());
  std::cout << "Selective multidimensional array :: "<<std::endl
            << p::extract<char const *>(p::str(mul_data_ex)) << std::endl ;
}

注释

如果由形状及相应步长决定的元素数目不匹配, from_data 方法将抛出 error_already_set
