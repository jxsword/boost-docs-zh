数组简明教程

让我们从一个创建和修改数组的简单教程开始.

获取 numpy 组件所需的头文件, 并设置必要的命名空间:

#include <boost/python/numpy.hpp>
#include <iostream>

namespace p = boost::python;
namespace np = boost::python::numpy;

初始化 Python 运行时和 numpy 模块. 不调用它们会导致段错误:

int main(int argc, char **argv)
{
  Py_Initialize();
  np::initialize();

可以用数组的形状和数据类型作为参数创建全零 n 维数组. 这里, 形状是 3x3, 数据类型是内建 float 类型:

p::tuple shape = p::make_tuple(3, 3);
np::dtype dtype = np::dtype::get_builtin<float>();
np::ndarray a = np::zeros(shape, dtype);

你还可以像这样创建一个空数组

np::ndarray b = np::empty(shape,dtype);

打印原始数组和重塑后的数组. 作为列表的数组 a 首先被转换为字符串, 列表中的每个值用 extract< > 提取:

  std::cout << "Original array:\n" << p::extract<char const *>(p::str(a)) << std::endl;

  // Reshape the array into a 1D array
  a = a.reshape(p::make_tuple(9));
  // Print it again.
  std::cout << "Reshaped array:\n" << p::extract<char const *>(p::str(a)) << std::endl;
}
