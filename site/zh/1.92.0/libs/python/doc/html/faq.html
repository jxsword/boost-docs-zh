如何包装接受函数指针作为参数的函数?

如果你想做的事情类似于:

typedef boost::function<void (string s) > funcptr;

void foo(funcptr fp)
{
  fp("hello,world!");
}

BOOST_PYTHON_MODULE(test)
{
  def("foo",foo);
}

然后:

>>> def hello(s):
...    print s
...
>>> foo(hello)
hello, world!

简短的回答是: "做不到". 这与其说是 Boost.Python 的限制, 不如说是 C++ 的限制. 问题在于 Python 函数实际上是数据, 而把数据与 C++ 函数指针关联的唯一途径是把它存储在该函数的静态变量中. 这样做的问题在于, 每个 C++ 函数只能关联一份数据, 而我们无法为你决定传给 foo 的每个 Python 函数即时编译一个新的 C++ 函数. 换言之, 如果 C++ 函数总是要调用同一个 Python 函数, 这或许可行, 但你多半不希望那样.

如果你有幸可以修改被包装的 C++ 代码, 就改为传给它一个 object 并调用它; 被重载的函数调用运算符将在 object 的背后调用你传入它的 Python 函数.
