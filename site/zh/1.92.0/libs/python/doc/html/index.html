概要

欢迎来到 Boost.Python, 一个使 C++ 与 Python 编程语言能够无缝互操作的 C++ 库. 该库包括以下支持:

  • 引用与指针
  • 全局注册的类型强制转换
  • 自动跨模块类型转换
  • 高效的函数重载
  • C++ 到 Python 的异常转换
  • 默认参数
  • 关键字参数
  • 在 C++ 中操纵 Python 对象
  • 把 C++ 迭代器导出为 Python 迭代器
  • 文档字符串

这些特性的开发部分受以下资助: 给 Boost Consulting 的、来自 Lawrence Livermore 国家实验室 的拨款, 以及来自 Lawrence Berkeley 国家实验室 计算晶体学计划 的资助.
