在你的系统上安装 Boost.Python

由于 Boost.Python 是一个单独编译的库 (区别于 header-only), 其用户依赖于 Boost.Python 库二进制文件提供的服务.

如果你需要在系统上对 Boost.Python 库二进制文件做一次常规安装, Boost 入门指南 将引导你完成创建它的步骤. 如果从源码构建二进制文件, 你可能想把 --with-python 参数提供给 bjam (或把 --with-libraries=python 参数提供给 configure), 这样就只构建 Boost.Python 二进制文件, 而不是所有 Boost 二进制文件.
