给 MinGW (及使用 -mno-cygwin 的 Cygwin) GCC 用户的说明

如果你把早于 2.4.1 的 Python 版本与早于 3.0.0 的 MinGW (含 binutils-2.13.90-20030111-1) 搭配使用, 你需要创建一个 MinGW 兼容版本的 Python 库; Python 自带的那个只能与 Microsoft 兼容的链接器配合工作. 请按照 Installing Python Modules 中 “Building Extensions: Tips And Tricks” 一章 “Non-Microsoft” 一节的说明创建 libpythonXX.a, 其中 XX 对应你的 Python 安装的主版本号和次版本号.
