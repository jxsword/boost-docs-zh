#include 问题

1. 如果你在使用 Boost.Python 的程序的某个翻译单元中确有需要直接 #include "python.h", 请改用 #include "boost/python/detail/wrap_python.hpp". 它处理了若干与 Boost.Python 配合使用所必需的问题, 其中之一将在下一节提及.

2. 务必不要 #include 任何位于 wrap_python.hpp 之前的系统头文件. 这一限制实际上是由 Python 施加的, 更准确地说, 是由 Python 与你的操作系统的交互所施加的. 详情参见 http://docs.python.org/ext/simpleExample.html.
