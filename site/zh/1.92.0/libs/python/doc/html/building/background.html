Background

组合 C++ 与 Python 有两种基本模型:

  • 扩展: 最终用户启动 Python 解释器可执行程序, 并导入以 C++ 编写的 Python “扩展模块”. 想象拿到一个用 C++ 编写的库, 为它加上 Python 接口, 让 Python 程序员可以使用它. 在 Python 看来, 这些模块看上去就像常规的 Python 模块.
  • 嵌入: 最终用户启动一个以 C++ 编写的程序, 该程序再把 Python 解释器当作库子例程来调用. 想象给一个现有应用添加脚本能力.

扩展与嵌入的关键区别在于 C++ main() 函数的位置: 分别位于 Python 解释器可执行程序中, 或位于其他某个程序中. 注意, 即使把 Python 嵌入另一个程序, 扩展模块通常也是让 Python 代码得以使用 C/C++ 功能的最佳方式, 因此扩展模块的使用实际上是两种模型的核心.

除少数罕见情况外, 扩展模块被构建为带单一入口点的动态加载库, 这意味着修改它们时无需重新构建其他扩展模块或包含 main() 的可执行文件.
