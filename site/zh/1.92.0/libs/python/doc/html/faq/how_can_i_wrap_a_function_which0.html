如何包装需要取得裸指针所有权的函数?

问: 我正在包装的一个 API 的一部分大致如下:

struct A {}; struct B { void add( A* ); }
where B::add() takes ownership of the pointer passed to it.

然而:

a = mod.A()
b = mod.B()
b.add( a )
del a
del b
# python interpreter crashes
# later due to memory corruption.

即使通过 with_custodian_and_ward 把 a 的生存期绑定到 b, 也无法阻止 Python 对象 a 最终尝试删除它所指向的对象. 有没有办法实现被包装 C++ 对象的 "所有权转移"?

--Bruce Lowery

有: 确保 C++ 对象由 auto_ptr 持有:

class_<A, std::auto_ptr<A> >("A")
  ...
  ;

然后创建一个接受 auto_ptr 参数的薄包装函数:

void b_insert(B &b, std::auto_ptr<A> a)
{
  b.insert(a.get());
  a.release();
}

把它包装为 B.add. 注意, 通过 manage_new_object 返回的指针也将由 auto_ptr 持有, 因而这种所有权转移也能正确工作.
