我收到 "attempt to return dangling reference" 错误. 我做错了什么?

该异常是在保护你免于造成难看的崩溃. 它通常是对类似下面这样的代码做出的反应:

period const &get_floating_frequency() const
{
  return boost::python::call_method<period const &>(
    m_self,"get_floating_frequency");
}

然后你得到:

ReferenceError: Attempt to return dangling reference to object of type:
class period

在这种情况下, 由 call_method 调用的 Python 方法构造了一个新的 Python 对象. 你试图返回对某个 C++ 对象 (class period 的实例) 的引用, 该对象包含在那个 Python 对象之中并由其所有. 由于被调用的方法交回的是一个全新的对象, 对它的唯一引用只在上面 get_floating_frequency() 的持续期间被持有. 当函数返回时, 该 Python 对象将被销毁, 同时销毁 class period 的实例, 从而使返回的引用悬空. 这已经是未定义行为, 如果你试图对该引用做任何事, 很可能导致崩溃. Boost.Python 会在运行期检测到这种情况, 并友好地抛出异常, 而不是任由你那样做.
