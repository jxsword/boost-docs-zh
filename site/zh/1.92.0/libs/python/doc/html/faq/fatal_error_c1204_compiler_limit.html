fatal error C1204:Compiler limit:internal structure overflow

问: 编译一个较大的源文件时出现这条错误消息. 我能做什么?

答: 你有两个选择:

  1. 升级你的编译器 (首选)

  2. 把你的源文件拆分为多个翻译单元.

    my_module.cpp: 

    ...
void more_of_my_module();
BOOST_PYTHON_MODULE(my_module)
{
  def("foo", foo);
  def("bar", bar);
  ...
  more_of_my_module();
}

    more_of_my_module.cpp: 

    void more_of_my_module()
{
  def("baz", baz);
  ...
}

    如果你发现某个 class_<...> 声明无法放进单个源文件而不触发该错误, 你总可以把指向 class_ 对象的引用传给另一个源文件中的函数, 并在该辅助源文件中调用它的一些成员函数 (例如 .def(...)):

    more_of_my_class.cpp: 

    void more_of_my_class(class&lt;my_class&gt;&amp; x)
{
  x
   .def("baz", baz)
   .add_property("xx", &my_class::get_xx, &my_class::set_xx)
   ;
  ...
}
