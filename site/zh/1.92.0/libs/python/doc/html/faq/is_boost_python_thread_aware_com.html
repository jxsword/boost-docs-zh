Boost.Python 是否线程感知/与多个解释器兼容?

Niall Douglas 提供了以下说明:

对这个问题, 快速回答是: 否.

较长的回答是: 可以通过打补丁实现, 但很复杂. 你需要为你的代码每次进入 Boost.Python 的地方 (尤其是每个虚函数改写) 添加自定义的加锁/解锁包装, 还要大量修改 boost/python/detail/invoke.hpp, 为 Boost.Python 每次进入你的代码的地方添加自定义的解锁/加锁包装. 此外, 你还必须注意不要在 Boost.Python 通过 invoke.hpp 调用迭代器变更时解锁/加锁.

C++-SIG 邮件列表档案中发布过一个打补丁的 invoke.hpp, 你可以在 SourceForge 上的 TnFOX 项目 此处 找到完整实现这一切所需机制的真实实现.
