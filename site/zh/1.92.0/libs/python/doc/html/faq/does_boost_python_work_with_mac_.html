Boost.Python 能在 Mac OS X 上工作吗?

已知在 10.2.8 和 10.3 上使用 Apple 的 gcc 3.3 编译器可以工作:

gcc (GCC) 3.3 20030304 (Apple Computer, Inc. build 1493)

在 10.2.8 上, 获取 2003 年 8 月的 gcc 更新 (在 http://connect.apple.com 免费提供). 在 10.3 上, 获取 Xcode Tools v1.0 (同样免费).

需要 Python 2.3. 10.3 自带的 Python 即可. 在 10.2.8 上, 使用以下命令把 Python 安装为框架 (framework):

./configure --enable-framework
make
make frameworkinstall

最后一条命令需要 root 权限, 因为目标目录是 /Library/Frameworks/Python.framework/Versions/2.3. 不过, 该安装不会干扰 10.2.8 自带的 Python 版本.

在开始编译之前增大 stacksize 也至关重要, 例如:

limit stacksize 8192k

如果 stacksize 太小, 构建可能因内部编译器错误而崩溃.

有时 Apple 的编译器会在编译一个 boost::python::class_<your_type> 模板实例化时表现出一个缺陷, 打印出如下错误:

.../inheritance.hpp:44: error: cannot
  dynamic_cast `p' (of type `struct cctbx::boost_python::<unnamed>::add_pair*
  ') to type `void*' (source type is not polymorphic)

我们不知道通用的解决方法, 但如果 your_type 的定义可以修改, 以下做法被发现对迄今为止遇到的所有情况都有效:

struct your_type
{
  // before defining any member data
#if defined(__MACH__) &amp;&amp; defined(__APPLE_CC__) &amp;&amp; __APPLE_CC__ == 1493
  bool dummy_;
#endif
  // now your member data, e.g.
  double x;
  int j;
  // etc.
};
