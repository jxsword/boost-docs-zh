如何包装接受 C++ 容器作为参数的函数?

Ralf W. Grosse-Kunstleve 提供了以下说明:

  1. 使用常规的 class_<> 包装器:

    class_<std::vector<double> >("std_vector_double")
  .def(...)
  ...
;

    这可以移入一个模板, 使多种类型 (double、int、long 等) 都能用同一份代码包装. "scitbx" 包中的文件 scitbx/include/scitbx/array_family/boost_python/flex_wrapper.h 使用了这一技术. 该文件可以轻松修改以包装 std::vector<> 实例. 这种 C++/Python 绑定方式最适合可能包含大量元素 (>10000) 的容器.

  2. 使用自定义右值转换器. Boost.Python 的 "右值转换器" 匹配如下形式的函数签名:

    void foo(std::vector<double> const &array); // pass by const-reference
void foo(std::vector<double> array); // pass by value

    一些自定义右值转换器在文件 scitbx/include/scitbx/boost_python/container_conversions.h 中实现. 这段代码可用于在 std::vector<> 或 std::list<> 等 C++ 容器类型与 Python 元组之间相互转换. 一些简单示例见文件 scitbx/array_family/boost_python/regression_test_module.cpp. C++ 容器 <-> Python 元组的自动转换最适合中等规模的容器. 与上面的方案 1 相比, 这些转换器生成的目标代码要少得多.

使用方案 2 的缺点在于, 算术运算符 +,-,*,/,% 等不可用. 若有自定义右值转换器能转换为 "math_array" 类型而非元组, 将会很有用. 目前尚未实现, 但在即将于未来几周内发布的 Boost.Python V2 框架内是可行的. [编者注: 本文发布于 2002/03/10]

同样有用的是 "自定义左值转换器", 例如 std::vector<> <-> Python 列表. 这类转换器将支持从 C++ 修改 Python 列表. 例如:

C++: 

void foo(std::vector<double> &array)
{
  for(std::size_t i=0;i&lt;array.size();i++) {
    array[i] *= 2;
  }
}

Python: 

>>> l = [1, 2, 3]
>>> foo(l)
>>> print l
[2, 4, 6]

自定义左值转换器需要修改 Boost.Python 核心库, 目前尚不可用.
