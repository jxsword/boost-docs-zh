为什么找不到我的自动到 Python 转换?

Niall Douglas 提供了以下说明:

如果你定义了与上面所示类似的自定义转换器, 那么 def_readonly() 与 def_readwrite() 这两个由 boost::python::class_ 提供的、用于直接访问成员数据的成员函数将不能按预期工作. 这是因为 def_readonly("bar",&foo::bar) 等价于:

.add_property("bar", make_getter(&foo::bar, return_internal_reference()))

类似地, def_readwrite("bar",&foo::bar) 等价于:

.add_property("bar", make_getter(&foo::bar, return_internal_reference()),
                   make_setter(&foo::bar, return_internal_reference())

为了定义与自定义转换兼容的返回值策略, 把 def_readonly() 和 def_readwrite() 替换为 add_property(). 例如:

.add_property("bar", make_getter(&foo::bar, return_value_policy<return_by_value>()),
                   make_setter(&foo::bar, return_value_policy<return_by_value>()))
