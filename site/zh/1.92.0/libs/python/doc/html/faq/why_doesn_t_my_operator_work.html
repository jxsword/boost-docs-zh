为什么我的 *= 运算符不工作?

问: 我已把我的类导出到 Python, 带有许多重载运算符. 一切正常, 唯独 *= 运算符不行. 它总是告诉我 "can't multiply sequence with non int type". 如果我改用 p1.__imul__(p2) 而不用 p1 *= p2, 代码就能成功执行. 我到底哪里错了?

答: 你没有任何错. 这是 Python 2.2 的一个缺陷. 在纯 Python 中可以看到同样的现象 (通过在纯 Python 中摆弄新式类, 你可以学到很多关于 Boost.Python 内部发生的事情).

>>> class X(object):
...     def __imul__(self, x):
...         print 'imul'
...
>>> x = X()
>>> x *= 1

要解决这个问题, 你只需把 Python 升级到 2.2.1 或更高版本.
