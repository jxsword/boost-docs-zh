Boost.MultiIndex 容器库

 
 

教程

Boost Multi-index Containers Library 提供了一个名为 multi_index_container 的类模板, 用于构造维护一个或多个 索引 的容器, 这些索引具有不同的排序与访问语义. 索引提供与 STL 容器相似的接口, 使用起来令人熟悉. 对同一元素集合进行多索引的概念借自关系数据库术语, 在简单集合与映射不够用的场合, 它允许以多重索引关系表的风格描述复杂的数据结构. 库中提供了丰富的索引选择, 仿照 std::set、std::list 与 std::unordered_set 等同类 STL 容器建模.

Boost.MultiIndex 还具备一些附加功能, 如子对象查找、范围查询、元素的原地更新以及排名计算, 即使不需要多索引能力, 它也能作为 std::set 与 set::multiset 的便利替代品.

Boost.MultiIndex 用途多样, 可以描述各种不同的数据结构. 以下是文档中开发的若干可能用法示例:

  • 具有多种迭代顺序与查找准则的集合.
  • 支持快速查找的列表和/或不含重复元素的列表.
  • 双向映射, 即既可按键又可按值查找的映射.
  • MRU (most recently used) 列表, 即保存最后引用的 n 个条目、最新的排在最前的结构.
  • 标准容器的模拟, 充分利用 Boost.MultiIndex 提供的附加功能.
