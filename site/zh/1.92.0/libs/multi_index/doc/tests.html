Boost.MultiIndex 测试套件覆盖了库提供的全部功能. 尽管这些测试并非作为学习指南而设计, 感兴趣的读者查看其源代码或许有助于熟悉 Boost.MultiIndex 提供的一些最少用到的特性.

Boost.MultiIndex 测试套件.
程序 说明
test_alloc_awareness.cpp 检查 分配器感知.
test_basic.cpp 按照教程中研究的 employees 示例的思路编写的简单程序.
test_capacity.cpp empty、size、resize (非基于键的索引) 以及 reserve/capacity (仅随机访问索引).
test_comparison.cpp 索引之间的比较.
test_composite_key.cpp composite_key 与 composite_key_compare.
test_conv_iterators.cpp 检查非常量迭代器到常量迭代器的可转换性.
test_copy_assignment.cpp 各种赋值形式: 复制、operator =、插入、(仅非基于键的索引) assign.
test_hash_ops.cpp 哈希操作.
test_iterators.cpp 常量与非常量迭代器及其反向变体.
test_key.cpp 简洁键规范语法.
test_key_extractors.cpp 覆盖库自带键提取器的所有用例.
test_list_ops.cpp 序列索引与随机访问索引特有的类列表操作.
test_modifiers.cpp 检查插入与擦除操作族.
test_mpl_ops.cpp Boost.MPL 互操作性 (当 BOOST_MULTI_INDEX_ENABLE_MPL_SUPPORT 启用时).
test_node_handling.cpp 涉及节点提取与插入的操作.
test_observers.cpp 检查有序索引与哈希索引的观察者成员函数.
test_projection.cpp 迭代器在各索引之间的投影.
test_range.cpp 演练 range 设施 (仅有序索引).
test_rank_ops.cpp 排名索引的特有操作.
test_rearrange.cpp 序列索引与随机访问索引的重排函数.
test_safe_mode.cpp 全面覆盖安全模式中检查的所有条件.
test_serialization1.cpp
test_serialization2.cpp
test_serialization3.cpp		 序列化支持.
test_set_ops.cpp 有序索引特有的类集合操作.
test_special_set_ops.cpp 使用兼容排序准则的特殊查找操作.
test_update.cpp replace、modify 与 modify_key.
