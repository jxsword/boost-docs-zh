Boost.MultiIndex 致谢


发布说明

索引

来自 Boost 邮件列表的 Fernando Cacciola、Darren Cook、Beman Dawes、Jeremy Maitin-Shepard 和 Daryle Walker 在本库最初几个 alpha 版本期间提供了许多有益的改进建议. Gang Wang 在代码中发现了若干缺陷. Thomas Wenisch 提出了“序列集合”(sequence sets) 的构想, 序列索引正是据此设计的. Giovanni Bajo、Chris Little 和 Maxim Yegorushkin 在多个平台上测试了本库. Daniel Wallin 贡献了针对 MSVC++ 7.0 的修复. 在本库移植到 CW 8.3 的过程中, Ron Liechty 和 Metrowerks 的支持团队提供了协助. 向 VisualAge 6.0 的移植则有赖于 Toon Knapen 的帮助. Markus Schöpflin 协助处理了 Compaq C++ 6.5 和 Tru64 UNIX 上的 GCC 相关问题. Rosa Bernárdez 校对了教程的最后几个版本.

Pavel Voženílek 对本库的每一个部分都进行了彻底的审阅, 给予了极大的帮助; 他还建议增加了若干额外功能, 其中最主要的有范围查询、安全模式、多态键提取器以及 MPL 支持. 谨致谢意!

Boost 正式评审 (Formal Review) 于 2004 年 3 月 20 日至 30 日进行, 评审管理员为 Pavel Voženílek. 感谢所有参与者, 尤其感谢提交评审意见的以下各位: Fredrik Blomqvist、Tom Brinkman、Paul A Bristow、Darren Cook、Jeff Garland、David B. Held、Brian McNamara、Gary Powell、Rob Stewart、Arkadiy Vertleyb、Jörg Walter. 其他 Boost 成员也贡献了不少想法, 特别是与本库命名方案相关的: Pavol Droba、Dave Gomboc、Jeremy Maitin-Shepard、Thorsten Ottosen、Matthew Vogt、Daryle Walker. 如有遗漏, 谨致歉意.

没有 Aleksey Gurtovoy 等人杰出的 Boost MPL Library, Boost.MultiIndex 就无从写就. 此外, Aleksey 处理 MSVC++ 6.0 中 ETI 相关问题的技术也帮助解决了本库的一些内部问题.

Boost 1.33 发布

再次衷心感谢 Pavel Voženílek, 他细致地审阅了新内容并提出了许多改进建议. 哈希索引的设计得益于与多位 Boost 成员的讨论, 尤其是 Howard Hinnant 和 Daniel James. Daniel 还向社区贡献了 Boost.Hash: 哈希索引依赖该库作为其默认的哈希函数提供者. Robert Ramey 的 Boost Serialization Library 提供了非常稳固的框架, Boost.MultiIndex 的序列化能力正是构建于其上. Toon Knapen 协助调整了本库以适配 VisualAge 6.0. Markus Schöpflin 提供了针对 Tru64 UNIX 下 GCC 的 Jamfile 调整.

Boost 1.34 发布

感谢 Pavel Voženílek 在本发布版本开发期间提出的有益评论与建议, 也感谢 Rosa Bernárdez 审阅文档中的新内容. Alo Sarv 建议改进了复合键部分查找的表示法. Maxim Yegorushkin 为有序索引提出了一项宝贵的 空间优化, 并给出了其对元素数量众多的容器的性能影响数据. Caleb Epstein 完成了性能一节所述的在 MSVC++ 8.0 下进行的测试. 以下人员报告了本库先前版本及预发布版本中的缺陷与问题: Alexei Alexandrov、Matías Capeletto、John Eddy、Martin Eigel、Guillaume Lazzara、Felipe Magno de Almeida、Julien Pervillé、Hubert Schmid、Toby Smith.

家中添了新成员! 感谢 Héctor 在漫长的开发过程中的耐心, 以及他对源代码的偶发贡献.

Boost 1.35 发布

global_fun 是应 Markus Werle 的提议而纳入的. Bruno Martínez Aguerre 建议纳入 iterator_to. modify 与 modify_key 的回滚版本源于与 Matías Capeletto 的讨论. Steven Watanabe 发现了一个自本库首个发布版本起即存在的 include guard 缺陷.

Boost 1.36 发布

感谢 Amit Jain 报告分配器管理方面的一个问题. Michael Fawcett 建议为 multi_index_container 增加一个分配器构造函数. Zachary Zhou 的一份报告促成了 改进哈希索引更新函数的行为, 使其符合某些直观预期. Grzegorz Jakacki 发现了一些内部死代码.

Boost 1.56 发布

Stephen Kelly 贡献了移除针对已不再支持的旧编译器的变通代码.
