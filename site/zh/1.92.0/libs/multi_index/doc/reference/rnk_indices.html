索引说明符 ranked_unique 与 ranked_non_unique

这些 索引说明符 分别允许插入 排名索引——分别对应不允许与允许重复元素的情形. ranked_unique 与 ranked_non_unique 的语法一致, 因此我们将它们放在一起描述. ranked_unique 与 ranked_non_unique 依据是否为索引提供标签列表而有两种不同的实例化形式:

template<
  typename KeyFromValue,
  typename Compare=std::less<KeyFromValue::result_type>
>
struct (ranked_unique | ranked_non_unique);

template<
  typename TagList,
  typename KeyFromValue,
  typename Compare=std::less<KeyFromValue::result_type>
>
struct (ranked_unique | ranked_non_unique);

若提供, TagList 必须是类模板 tag 的实例化. 模板实参由相应的索引实现使用; 关于其可接受类型取值的进一步解释, 参见 排名索引 参考一节.

排名索引

排名索引是 有序索引 的一个变种, 额外提供了按排名计算与访问的能力; 元素的 排名 是从索引开头到该元素的距离. 除这一扩展外, 排名索引复刻了有序索引的公开接口, 差别在于复杂度: 提示插入 与 删除 以对数时间而非常量时间完成. 此外, 由于维护排名相关信息所需的内部簿记, 执行时间与内存消耗预计会更差 (count 操作 是一个例外, 它们实际上更快). 与有序索引一样, 排名索引可以是唯一 (不允许重复元素) 或非唯一的: 每个版本关联到不同的索引说明符, 但两种索引类型的接口相同.

在下文中, 我们只描述排名索引提供的额外操作或性能有所改进的操作: 其余部分请参阅 有序索引的文档, 并注意复杂度方面偶有的差异.

复杂度签名

我们沿用 复杂度签名一节 中描述的术语. 排名索引的复杂度签名为:

  • 拷贝: c(n)=n*log(n),
  • 插入: i(n)=log(n),
  • 提示插入: h(n)=log(n),
  • 删除: d(n)=log(n),
  • 替换: r(n)=1 (常量), 若元素位置不变; r(n)=log(n) 否则,
  • 修改: m(n)=1 (常量), 若元素位置不变; m(n)=log(n) 否则.

这些复杂度保证与 有序索引 相同, 唯提示插入与删除例外——此处为 log(n), 而那里是摊还常量.

实例化类型

排名索引在 multi_index_container 内部实例化, 并通过 indexed_by 配合 索引说明符 ranked_unique 与 ranked_non_unique 加以指定. 实例化依赖于以下类型:

  • Value 来自 multi_index_container,
  • Allocator 来自 multi_index_container,
  • TagList 来自索引说明符 (若提供; 否则默认为 tag<>) ,
  • KeyFromValue 来自索引说明符,
  • Compare 来自索引说明符.
这些类型所受的要求与为 有序索引规定者相同.

嵌套类型

iterator
const_iterator
这些类型仅取决于 node_type 以及该索引在 multi_index_container 中的位置.

集合操作

关于 兼容扩展 与 兼容键 概念的解释, 参见有序索引的文档; 下文将引用这些概念.

template<typename CompatibleKey>
size_type count(const CompatibleKey& x)const;
要求: CompatibleKey 是 key_compare 的兼容键.
效果: 返回键与 x 等价的元素个数.
复杂度: O(log(n)).
template<typename CompatibleKey,typename CompatibleCompare>
size_type count(const CompatibleKey& x,const CompatibleCompare& comp)const;
要求: (CompatibleKey, CompatibleCompare) 构成 key_compare 的兼容扩展.
效果: 返回键与 x 等价的元素个数.
复杂度: O(log(n)).

排名操作

排名——针对迭代器 it (属于给定容器 c) 而言, 推广而言也指其所指向元素的排名 (若该迭代器可解引用)——是 std::distance(c.begin(),it).

关于 兼容扩展、兼容键、下界器 与 上界器 概念的解释, 参见有序索引的文档; 下文将引用这些概念.

iterator nth(size_type n)const;
效果: 返回排名为 n 的迭代器, 或 end()——若 n>=size().
复杂度: O(log(n)).
size_type rank(iterator position)const;
要求: position 是该索引的有效迭代器.
效果: 返回 position 的排名.
复杂度: O(log(n)).
template<typename CompatibleKey> size_type find_rank(const CompatibleKey& x)const;
要求: CompatibleKey 是 key_compare 的兼容键.
效果: 等价于 rank(find(k)).
复杂度: O(log(n)).
template<typename CompatibleKey,typename CompatibleCompare>
size_type find_rank(const CompatibleKey& x,const CompatibleCompare& comp)const;
要求: (CompatibleKey, CompatibleCompare) 构成 key_compare 的兼容扩展.
效果: 等价于 rank(find(x,comp)).
复杂度: O(log(n)).
template<typename CompatibleKey>
size_type lower_bound_rank(const CompatibleKey& x)const;
要求: CompatibleKey 是 key_compare 的兼容键.
效果: 等价于 rank(lower_bound(x)).
复杂度: O(log(n)).
template<typename CompatibleKey,typename CompatibleCompare>
size_type lower_bound_rank(const CompatibleKey& x,const CompatibleCompare& comp)const;
要求: (CompatibleKey, CompatibleCompare) 构成 key_compare 的兼容扩展.
效果: 等价于 rank(lower_bound(x,comp)).
复杂度: O(log(n)).
template<typename CompatibleKey>
size_type upper_bound_rank(const CompatibleKey& x)const;
要求: CompatibleKey 是 key_compare 的兼容键.
效果: 等价于 rank(upper_bound(x)).
复杂度: O(log(n)).
template<typename CompatibleKey,typename CompatibleCompare>
size_type upper_bound_rank(const CompatibleKey& x,const CompatibleCompare& comp)const;
要求: (CompatibleKey, CompatibleCompare) 构成 key_compare 的兼容扩展.
效果: 等价于 rank(upper_bound(x,comp)).
复杂度: O(log(n)).
template<typename CompatibleKey>
std::pair<size_type,size_type> equal_range_rank(
  const CompatibleKey& x)const;
要求: CompatibleKey 是 key_compare 的兼容键.
效果: 等价于 make_pair(lower_bound_rank(x),upper_bound_rank(x)).
复杂度: O(log(n)).
template<typename CompatibleKey,typename CompatibleCompare>
std::pair<size_type,size_type> equal_range_rank(
  const CompatibleKey& x,const CompatibleCompare& comp)const;
要求: (CompatibleKey, CompatibleCompare) 构成 key_compare 的兼容扩展.
效果: 等价于 make_pair(lower_bound_rank(x,comp),upper_bound_rank(x,comp)).
复杂度: O(log(n)).
template<typename LowerBounder,typename UpperBounder>
std::pair<size_type,size_type> range_rank(
  LowerBounder lower,UpperBounder upper)const;
要求: LowerBounder 与 UpperBounder 分别是 key_compare 的下界器与上界器.
效果: 等价于 
auto p=range(lower,upper);
return make_pair(rank(p.first),rank(p.second));
复杂度: O(log(n)).
变体: 可以代替 lower 或 upper (或两者) 提供单值 boost::multi_index::unbounded. 它充当一个谓词, 所有 key_type 类型的值都满足它.
