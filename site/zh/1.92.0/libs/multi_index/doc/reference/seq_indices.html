sequenced 索引说明符

该索引说明符允许插入一个 序列索引.

template<typename TagList=tag<> > struct sequenced;

若提供, TagList 必须是 tag 的实例化.

序列索引

序列索引以双向列表 (如 std::list) 的语义为模型. 序列索引中的元素默认按其插入顺序排列: 这意味着通过 multi_index_container 的其他索引插入的新元素会被追加到序列索引的末尾. 此外, 该索引允许像 std::list 那样自由地重排元素. 迭代器 (包括指向索引末端的迭代器) 以及指向元素的指针和引用, 在关联容器的生存期内保持有效 (交换时可能改变), 或直到被引用元素被擦除或提取为止; 指向已提取元素的指针和引用在该元素重新插入后重新变为有效, 但迭代器则不然.

除特别注明或相应接口不存在之处外, 序列索引满足与 std::list 相同的容器要求: 我们只描述那些 std::list 中不存在或行为不同的类型与操作. 一些最重要的差异如下:

  • 某些操作的复杂度 (尤其是插入与删除) 与 std::list 不同.
  • 与 std::list 不同, 向序列索引的插入可能因与其他索引的冲突而失败. 这改变了这些操作相对于 std::list 中对应操作的语义.
  • 序列索引中的元素不可变更, 只能通过 replace 与 modify 成员函数就地修改.

复杂度签名

此处以及序列索引各操作的说明中, 我们采用 复杂度签名一节 所概述的方案. 序列索引的复杂度签名为:

  • 拷贝: c(n)=n*log(n),
  • 插入: i(n)=1 (常量),
  • 提示插入: h(n)=1 (常量),
  • 删除: d(n)=1 (常量) ,
  • 替换: r(n)=1 (常量),
  • 修改: m(n)=1 (常量).

实例化类型

序列索引在 multi_index_container 内部实例化, 并通过 indexed_by 配合 sequenced 索引说明符加以指定. 实例化依赖于以下类型:

  • Allocator 来自 multi_index_container,

要求: mod 是接受 value_type& 类型参数的一元函数对象. position 是该索引的有效可解引用迭代器. mod(e) 的执行——其中 e 是 position 所指向的元素——在 multi_index_container 中 e 被直接修改之后不得调用其任何操作, 或者在修改之前若该操作会使 position 失效亦然.
效果: 调用 mod(e), 其中 e 是 position 所指向的元素, 并把 *position 重排到 multi_index_container 的所有索引中. 序列索引上的重排不改变元素相对于该索引的位置; 其他索引上的重排可能成功也可能失败. 若重排失败, 该元素被擦除.
后置条件: 若操作成功, position 的有效性得到保持.
返回: 若操作成功则为 true, 否则为 false.
复杂度: O(M(n)).
异常安全性: 基本保证. 若某个用户提供的操作 (包括 mod) 抛出异常, 则 position 所指向的元素被擦除.
template<typename Modifier,typename Rollback>
bool modify(iterator position,Modifier mod,Rollback back);
要求: mod 与 back 是接受 value_type& 类型参数的一元函数对象. position 是该索引的有效可解引用迭代器. mod(e) 的执行——其中 e 是 position 所指向的元素——在 multi_index_container 中 e 被直接修改之后不得调用其任何操作, 或者在修改之前若该操作会使 position 失效亦然. back(e) 不得调用 multi_index_container 的任何操作.
效果: 调用 mod(e), 其中 e 是 position 所指向的元素, 并尝试把 *position 重排到 multi_index_container 的所有索引中. 序列索引上的重排不改变元素相对于该索引的位置; 其他索引上的重排可能成功也可能失败. 若重排失败, 则调用 back(e): 若 e 的结果值与其在所有索引中的原位置及约束相一致, 则保留该元素, 否则将其擦除.
后置条件: position 的有效性得到保持, 除非元素在下述条件下被擦除.
返回: 若操作成功则为 true, 否则为 false.
复杂度: O(M(n)).
异常安全性: 强保证, 但若 mod 或 back 抛出异常, 或 back(e) 未能正确恢复该元素, 或在调用 back(e) 之后某个用户提供的操作抛出异常, 则被修改的元素被擦除. 若 back 在处理代码中抛出异常——该处理代码于其他某个用户提供的操作抛出异常后执行——则重新抛出的是 back 所生成的异常.

列表操作

序列索引提供 std::list 中完整的列表操作集合, 并在某些情况下加以扩展, 如 splice; 但这些成员函数的语义通常与 std::list 不同, 因为插入可能因被其他索引禁止而不成功. 类似地, 各操作的复杂度可能取决于同一 multi_index_container 所属的其他索引.

template<typename Index> void splice(const_iterator position,Index&& x);
要求: x 是 节点兼容 的 multi_index_container 中某个索引的非 const 引用. position 是该索引的有效迭代器, 且当源容器与目标容器相同时必须恰为 end().
效果: 
splice(position,x,x.begin(),x.end());
template<typename Index> std::pair<iterator,bool> splice(
  const_iterator position,Index&& x,
  typename std::remove_reference_t<Index>::const_iterator i);
要求: x 是 节点兼容 的 multi_index_container 中某个索引的非 const 引用. 若 get_allocator()!=x.get_allocator(), 则 value_type 必须满足 CopyInsertable 要求, 适用于目标 multi_index_container. position 是该索引的有效迭代器. i 是 x 的有效可解引用迭代器.
效果:
  • (同一容器) 若源容器与目标容器相同, 则把 i 所指向的元素重新定位到 position 之前, 除非两个迭代器引用同一元素.
  • (转移拼接) 否则, 若 get_allocator()==x.get_allocator(), 则把 i 所引用元素的节点转移到目标 multi_index_container 中, 紧靠 position 之前, 前提是该 multi_index_container 的所有其他索引都允许插入.
  • (破坏性拼接) 否则, 尝试把 *i 插入到 position 之前; 若操作成功, 该元素从 x 中被擦除.
后置条件: 若转移成功, 则对于源容器中与目标容器中相应索引具有相同 iterator/const_iterator 类型的任何索引, 引用 *i 的迭代器保持有效, 并表现为目标索引的迭代器.
返回: 返回值是一个 pair p. p.second 当且仅当插入 (通过转移或复制插入) 发生, 或源容器与目标容器相同时为 true. 若 p.second 为 true, 则 p.first 指向被插入的元素, 或当源容器与目标容器相同时指向 *i; 否则, p.first 指向导致插入被禁止的元素. 注意, 可能有不止一个元素导致插入不被允许.
复杂度: 若源容器与目标容器相同, 为常量; 否则为 O(I(n)+D(x.size())).
异常安全性: 若源容器与目标容器相同, 为 nothrow; 否则为强保证.
实现注记: 提供此操作的破坏性变体, 是为了与库先前版本向后兼容——在那些版本中不要求分配器相等.
template<typename Index> void splice(
  const_iterator position,Index&& x,
  typename std::remove_reference_t<Index>::const_iterator first,
  typename std::remove_reference_t<Index>::const_iterator last);
要求: x 是 节点兼容 的 multi_index_container 中某个索引的非 const 引用. 若 get_allocator()!=x.get_allocator(), 则 value_type 必须满足 CopyInsertable 要求, 适用于目标 multi_index_container. position 是该索引的有效迭代器, 且不指向 [first, last) 中的任何元素. [first, last) 是 x 的有效区间.
效果:
  • (同一容器) 若源容器与目标容器相同, 则把区间 [first, last) 中的所有元素按此顺序重新定位到 position 之前.
  • (转移拼接) 否则, 若 get_allocator()==x.get_allocator(), 则对 [first, last) 中的每个节点按此顺序, 把该节点转移到 multi_index_container 中紧靠 position 之前的位置, 前提是该 multi_index_container 的所有其他索引都允许插入.
  • (破坏性拼接) 否则, 对 [first, last) 中的每个元素按此顺序, 尝试插入到 position 之前; 若操作成功, 该元素从 x 中被擦除.
后置条件: 对于源容器中与目标容器中相应索引具有相同 iterator/const_iterator 类型的任何索引, 引用被转移元素的迭代器保持有效, 并表现为目标索引的迭代器.
复杂度: 若 &x==this, 为常量; 否则若源容器与目标容器相同, 为 O(m); 否则为 O(m*(I(n+m)+D(x.size()))), 其中 m 是 [first, last) 中的元素数目.
异常安全性: 若源容器与目标容器相同, 为 nothrow; 否则为基本保证.
实现注记: 提供此操作的破坏性变体, 是为了与库先前版本向后兼容——在那些版本中不要求分配器相等.
void remove(const value_type& value);
效果: 擦除该索引中与 value 比较相等的所有元素.
复杂度: O(n + m*D(n)), 其中 m 是被擦除元素的个数.
异常安全性: 基本保证.
template<typename Predicate> void remove_if(Predicate pred);
效果: 擦除该索引的所有元素 x 中使 pred(x) 成立者.
复杂度: O(n + m*D(n)), 其中 m 是被擦除元素的个数.
异常安全性: 基本保证.
void unique();
效果: 对于迭代器 i 在区间 [first+1, last) 中所指的每个满足 *i==*(i-1) 的相等元素连续组, 消除其中除第一个元素之外的所有元素.
复杂度: O(n + m*D(n)), 其中 m 是被擦除元素的个数.
异常安全性: 基本保证.
template <class BinaryPredicate> void unique(BinaryPredicate binary_pred);
效果: 对于迭代器 i 在区间 [first+1, last) 中所指的每个满足 binary_pred(*i,*(i-1)) 的元素连续组, 消除其中除第一个元素之外的所有元素.
复杂度: O(n + m*D(n)), 其中 m 是被擦除元素的个数.
异常安全性: 基本保证.
void merge(index class name& x);
要求: 以下二者居其一: get_allocator()==x.get_allocator(), 或 value_type 满足 CopyInsertable 要求, 适用于该 multi_index_container. std::less<value_type> 在 value_type 上诱导严格弱序. 该索引与 x 均已按 std::less<value_type> 排序.
效果: 尝试把 x 的每个元素拼接 (splice) 到该索引的相应位置 (按排序顺序). 所得序列是稳定的, 即两个容器中的等价元素保持其相对位置. 在特例 &x==this 下, 不执行任何操作.
后置条件: 索引中的元素与 x 中剩余的元素均已排序. 迭代器与引用的有效性得到保持, 但指向从 x 中移除的元素的迭代器和引用除外——当 get_allocator()!=x.get_allocator() 时.
复杂度: 若 &x==this, 为常量; 否则为 O(n + x.size()*I(n+x.size()) + x.size()*D(x.size())).
异常安全性: 若 &x==this, 为 nothrow; 否则为基本保证.
template <typename Compare> void merge(index class name& x,Compare comp);
要求: 以下二者居其一: get_allocator()==x.get_allocator(), 或 value_type 满足 CopyInsertable 要求, 适用于该 multi_index_container. Compare 在 value_type 上诱导严格弱序. 该索引与 x 均已按 comp 排序.
效果: 尝试把 x 的每个元素拼接 (splice) 到该索引的相应位置 (按 comp). 所得序列是稳定的, 即两个容器中的等价元素保持其相对位置. 在特例 &x==this 下, 不执行任何操作.
后置条件: 索引中的元素与 x 中剩余的元素均已按 comp 排序. 迭代器与引用的有效性得到保持, 但指向从 x 中移除的元素的迭代器和引用除外——当 get_allocator()!=x.get_allocator() 时.
复杂度: 若 &x==this, 为常量; 否则为 O(n + x.size()*I(n+x.size()) + x.size()*D(x.size())).
异常安全性: 若 &x==this, 为 nothrow; 否则为基本保证.
void sort();
要求: std::less<value_type> 在 value_type 上诱导严格弱序.
效果: 按 std::less<value_type> 对该索引排序. 排序是稳定的, 即等价元素保持其相对位置.
后置条件: 迭代器与引用的有效性得到保持.
复杂度: O(n*log(n)).
异常安全性: nothrow, 若 std::less<value_type> 不抛出异常; 否则为基本保证.
template <typename Compare> void sort(Compare comp);
要求: Compare 在 value_type 上诱导严格弱序.
效果: 按 comp 对该索引排序. 排序是稳定的, 即等价元素保持其相对位置.
后置条件: 迭代器与引用的有效性得到保持.
复杂度: O(n*log(n)).
异常安全性: nothrow, 若 comp 不抛出异常; 否则为基本保证.
void reverse()noexcept;
效果: 反转该索引中元素的顺序.
后置条件: 迭代器与引用的有效性得到保持.
复杂度: O(n).

重排操作

这些操作在 std::list 中没有对应物 (尽管 splice 提供了部分重叠的功能), 用于在索引内部对元素进行单个与全局的重定位.

void relocate(iterator position,iterator i);
要求: position 是该索引的有效迭代器. i 是该索引的有效可解引用迭代器.
效果: 把 i 所指向的元素插入到 position 之前. 若 position==i, 则不执行任何操作.
后置条件: 没有任何迭代器或引用失效.
复杂度: 常量.
异常安全性: nothrow.
void relocate(iterator position,iterator first,iterator last);
要求: position 是该索引的有效迭代器. first 与 last 是该索引的有效迭代器. last 可从 first 到达. position 不在区间 [first, last) 中.
效果: 元素区间 [first, last) 被重新定位到紧靠 position 之前.
后置条件: 没有任何迭代器或引用失效.
复杂度: 常量.
异常安全性: nothrow.
template<typename InputIterator> void rearrange(InputIterator first);
要求: 区间 [first, std::advance(first,n))——其中 n 是该索引的大小——是该索引的一个 自由视图.
效果: 元素被重排以匹配前述视图的顺序.
后置条件: 没有任何迭代器或引用失效.
复杂度: O(n).
异常安全性: 基本保证.

序列化

索引本身不能被序列化, 只能作为其所嵌入的 multi_index_container 的一部分被序列化. 描述序列索引就其所在容器序列化而言的附加前置条件与保证时, 我们使用 multi_index_container 序列化一节 中定义的概念.

操作: 保存 multi_index_container m 到输出档案 (XML 档案) ar.
要求: 除容器所施加的要求外无其他要求.
操作: 将 multi_index_container m' 从输入档案 (XML 档案) ar 载入.
要求: 除容器所施加的要求外无附加要求.
后置条件: 载入成功后, 区间 [begin(), end()) 中的每个元素都是区间 [m.get<i>().begin(), m.get<i>().end()) 中对应元素的恢复副本, 其中 i 是序列索引在容器中的位置.
操作: 保存 iterator 或 const_iterator it 到输出档案 (XML 档案) ar.
要求: it 是该索引的有效迭代器. 关联的 multi_index_container 之前已被保存.
操作: 将 iterator 或 const_iterator it' 从输入档案 (XML 档案) ar 载入.
后置条件: 载入成功后, 若 it 原先可解引用, 则 *it' 是 *it 的恢复副本, 否则为 it'==end().
注释: 允许 it 为 const_iterator 而恢复后的 it' 为 iterator, 或反之.
