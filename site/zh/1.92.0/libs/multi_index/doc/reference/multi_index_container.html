类模板 multi_index_container

这是 Boost.MultiIndex 的主要组件. multi_index_container 是一个容器类模板, 保存一个编译期的用户定义 索引 列表. 这些索引为管理 multi_index_container 的元素提供不同的接口. 就其本身而言, multi_index_container 只提供构造以及访问所持索引的基本功能.

multi_index_container 类型以所含元素的类型以及一个非空的 Mp11 list 实例化——后者指定构成该类的索引.

为使用方便, multi_index_container 继承第一个指定索引的所有公有方法与类型. 这也包括与该索引关联的全局运算符与函数 (例如比较与 swap) .

复杂度

在 multi_index_container 各操作的说明中, 我们采用 复杂度签名一节 所概述的方案.

实例化类型

multi_index_container 以以下类型实例化:

  1. Value 是所含元素的类型. Value 必须是 Erasable——来自 multi_index_container.
  2. IndexSpecifierList 指定 multi_index_container 由哪些索引组成. 它必须是一个非空的 Mp11 list——由索引说明符构成. 为语法上的方便, 可以使用 indexed_by 构造.
  3. Allocator 必须是 Value 对象的分配器, 并满足 [allocator.requirements] 中相关的 C++ 要求. 允许对标准要求作如下放宽:
    • 支持不相等的分配器实例: 交换两个不相等的实例不得抛出任何异常.
    • 对每个类型 T 而言, 类型 Allocator::rebind<T>::other::pointer 可以是任何一种随机访问迭代器, 只要它能从字面值 0 (此处充当空指针) 或从任一 p 显式构造——该迭代器的类型为 T*, 指向由某个 Allocator 实例或从 Allocator 重绑而来的某个其他分配器类型所分配的内存区域. pointer 由 p 构造而来时, 对其解引用应得到 *p.
    multi_index_container 实例及其全部迭代器都不会存储指向被分配元素的引用, 除非经由该分配器的指针类型.
构成给定的 multi_index_container 实例化而言, 各索引不能含有重复的 标签——无论是单个索引内部, 还是两个不同索引之间.

在下文中, multi_index_container 的索引数目记为 I.

嵌套类型

ctor_args_list
尽管 ctor_args_list 的确切定义由实现定义, 但从用户的角度看, 该类型可以视为等价于 ::boost::tuple<C0,...,CI-1>, 其中 Ci 是 ctor_args 类型, 对应第 i 个索引——这些索引由 multi_index_container 按指定时的顺序持有. 严格说来, 存在从 const ::boost::tuple<C0,...,CI-1>& 到 const ctor_args_list& 的隐式转换. 该类型用于提供 multi_index_container 各索引的构造参数. ctor_args_list 满足 DefaultConstructible 要求, 前提是其中涉及的所有 ctor_args 类型都满足 DefaultConstructible 要求.
index_specifier_type_list
与 IndexSpecifierList 相同的类型.
index_type_list
一个 Mp11 list, 包含 multi_index_container 所持有的各索引的类型, 顺序与指定时相同.
iterator_type_list
一个 Mp11 list, 包含 multi_index_container 所持有的各索引的迭代器类型, 顺序与指定时相同.
const_iterator_type_list
一个 Mp11 list, 包含 multi_index_container 所持有的各索引的常量迭代器类型, 顺序与指定时相同.
node_type
遵循 [container.node] 中标准规范的节点句柄类 (set 容器版本). multi_index_container 的两个实例化具有兼容节点 (即拥有相同的 node_type), 当且仅当二者形如 multi_index_container<Value,IndexSpecifierList1,Allocator> 与 multi_index_container<Value,IndexSpecifierList2,Allocator>, 索引说明符数目同为 I, 且对 i = 0, ..., I-1 而言, 各自的第 i 个索引说明符都指向同一 索引类型, 而不论 unique/non-unique 变体以及特定的配置类型实参.

嵌套类模板

template<int N> struct nth_index
nth_index<N>::type 产生第 N 个 (从 0 开始) 索引的类型, 该索引由 multi_index_container 按指定时的顺序持有.
要求: 0 <= N < I-1.
template<typename Tag> struct index
index<Tag>::type 产生以 Tag 为关联 标签类型 的索引的类型.
要求: multi_index_container 的某个索引以 Tag 为关联标签类型.
template<int N> struct nth_index_iterator
nth_index_iterator<N>::type 等价于 nth_index<N>::type::iterator.
注释: 使用 nth_index_iterator 已被弃用.
template<int N> struct nth_index_const_iterator
nth_index_const_iterator<N>::type 等价于 nth_index<N>::type::const_iterator.
注释: 使用 nth_index_const_iterator 已被弃用.
template<typename Tag> struct index_iterator
index_iterator<Tag>::type 等价于 index<Tag>::type::iterator.
注释: 使用 index_iterator 已被弃用.
template<typename Tag> struct index_const_iterator
index_const_iterator<Tag>::type 等价于 index<Tag>::type::const_iterator.
注释: 使用 index_const_iterator 已被弃用.

构造函数、拷贝与赋值

multi_index_container();
效果: 构造一个空的 multi_index_container, 使用 ctor_args_list 与 allocator_type 的默认值.
复杂度: 常量.
explicit multi_index_container(
  const ctor_args_list& args_list,
  const allocator_type& al=allocator_type());
效果: 构造一个空的 multi_index_container, 使用指定的实参列表与分配器.
复杂度: 常量.
explicit multi_index_container(const allocator_type& al);
效果: 构造一个空的 multi_index_container, 使用指定的分配器以及 ctor_args_list 的默认值.
复杂度: 常量.
template<typename InputIterator>
multi_index_container(
  InputIterator first,InputIterator last,
  const ctor_args_list& args_list=ctor_args_list(),
  const allocator_type& al=allocator_type());
要求: InputIterator 是输入迭代器. Value 满足 EmplaceConstructible 要求, 即 multi_index_container 可由 *first 构造. last 可从 first 到达.
效果: 构造一个空的 multi_index_container, 使用指定的实参列表与分配器, 并以区间 [first,last) 中的元素填充之. 每个元素的插入是否成功, 取决于该 multi_index_container 的所有索引是否接受它.
复杂度: O(m*H(m)), 其中 m 是 [first,last) 中的元素数目.
multi_index_container(
  std::initializer_list<Value> list,
  const ctor_args_list& args_list=ctor_args_list(),
  const allocator_type& al=allocator_type());
效果: 等价于 multi_index_container(list.begin(),list.end(),args_list,al).
multi_index_container(
  const multi_index_container<Value,IndexSpecifierList,Allocator>& x);
要求: Value 满足 CopyInsertable 要求, 适用于 multi_index_container.
效果: 构造 x 的一个副本, 同时复制其元素及其内部对象 (即 ctor_args_list 中指定的那些与分配器).
后置条件: *this==x. multi_index_container 各索引上的顺序也保持不变.
复杂度: O(x.size()*log(x.size()) + C(x.size())).
multi_index_container(
  multi_index_container<Value,IndexSpecifierList,Allocator>&& x);
效果: 构造一个 multi_index_container, 通过转移 x 的元素而来, 并复制其内部对象 (即 ctor_args_list 中指定的那些与分配器).
后置条件: 若移动前 x==y, 则 *this==y. multi_index_container 各索引上的顺序也保持不变.
复杂度: 常量.
multi_index_container(
  const multi_index_container<Value,IndexSpecifierList,Allocator>& x,
  const allocator_type& al);
要求: Value 满足 CopyInsertable 要求, 适用于 multi_index_container.
效果: 构造 x 的一个副本, 复制其元素及其内部对象 (即 ctor_args_list 中指定的那些), 并使用所提供分配器 al 的副本.
后置条件: *this==x. multi_index_container 各索引上的顺序也保持不变.
复杂度: O(x.size()*log(x.size()) + C(x.size())).
multi_index_container(
  multi_index_container<Value,IndexSpecifierList,Allocator>&& x,
  const allocator_type& al);
要求: Value 满足 MoveInsertable 要求, 适用于 multi_index_container.
效果: 构造一个 multi_index_container, 转移/移动 x 的元素, 复制其内部对象 (即 ctor_args_list 中指定的那些), 并使用所提供分配器 al 的副本. 若 x.get_allocator()==al, 则元素被转移 (不涉及构造), 否则从 x 移动构造而来.
后置条件: 若移动前 x==y, 则 *this==y. multi_index_container 各索引上的顺序也保持不变.
复杂度: 若 x.get_allocator()==al 则为常量, 否则为 O(x.size()*log(x.size()) + C(x.size())).
~multi_index_container()
效果: 销毁该 multi_index_container 及其包含的所有元素. 元素被销毁的顺序未作规定.
复杂度: O(n).
multi_index_container<Value,IndexSpecifierList,Allocator>& operator=(
  const multi_index_container<Value,IndexSpecifierList,Allocator>& x);
要求: Value 满足 CopyInsertable 要求, 适用于 multi_index_container.
效果: 将 ctor_args_list 中指定的内部对象连同该 multi_index_container 的元素一起替换为来自 x 的副本. 内部分配器被替换为 x.get_allocator() 的副本, 当且仅当 std::allocator_traits<allocator_type>::propagate_on_container_copy_assignment::value 为 true.
后置条件: *this==x. multi_index_container 各索引上的顺序也保持不变.
返回: *this.
复杂度: O(n + x.size()*log(x.size()) + C(x.size())).
异常安全性: 强保证, 前提是 ctor_args_list 中各类型的复制与赋值操作均不抛出异常.
multi_index_container<Value,IndexSpecifierList,Allocator>& operator=(
  multi_index_container<Value,IndexSpecifierList,Allocator>&& x);
要求: 若 std::allocator_traits<allocator_type>::propagate_on_container_move_assignment::value 为 true, 则 Value 满足 MoveInsertable 要求, 适用于 multi_index_container.
效果: 替换该 multi_index_container 的元素, 改为 x 的元素, 或改为从 x 的元素移动构造而来的副本. 将内部对象 (即 ctor_args_list 中指定的那些) 替换为来自 x 中相应对象的副本. 将内部分配器替换为 x.get_allocator() 的副本, 当且仅当 std::allocator_traits<allocator_type>::propagate_on_container_move_assignment::value 为 true. x 的元素被转移 (不涉及构造), 当且仅当 x.get_allocator() 被复制, 或等于内部分配器先前的值.
后置条件: 若移动前 x==y, 则 *this==y. multi_index_container 各索引上的顺序也保持不变.
返回: *this.
复杂度: O(n), 若 x 的元素被转移; 否则为 O(n + x.size()*log(x.size()) + C(x.size())).
异常安全性: 强保证, 前提是 ctor_args_list 中各类型的复制与赋值操作均不抛出异常.
multi_index_container<Value,IndexSpecifierList,Allocator>& operator=(
  std::initializer_list<Value> list);
要求: Value 满足 CopyInsertable 要求, 适用于 multi_index_container.
效果: 替换该 multi_index_container 的元素, 改为 list 中各元素的副本, 按指定顺序插入. 每个元素的插入是否成功, 取决于该 multi_index_container 的所有索引是否接受它.
返回: *this.
复杂度: O(n + I(m)), 其中 m 是 list 的元素数目.
异常安全性: 强保证, 前提是 ctor_args_list 中各类型的复制与赋值操作均不抛出异常.

投影操作

给定一个 multi_index_container, 其索引为 i1 与 i2, 我们说 i1 迭代器 it1 与 i2 迭代器 it2 是 等价的, 如果:

  • it1==i1.end() 且 it2==i2.end(), 或
  • 或者 it1 与 it2 指向同一个元素.

序列化

multi_index_container 实例可以通过 Boost.Serialization 进行存档/取回. Boost.MultiIndex 本身不公开序列化接口, 因为该接口由 Boost.Serialization 提供. 普通档案与 XML 档案均受支持.

构成某个给定 multi_index_container 的每个索引都会贡献其自身的前置条件, 以及对取回容器的种种保证. 描述这些内容时将使用以下概念. 类型 T 是 可序列化的 (XML 可序列化亦然), 如果任何 T 类型的对象都能保存到输出档案 (XML 档案) 中, 并在之后从关联到同一存储的输入档案 (XML 档案) 中取回. 若 x' (类型为 T) 是从由另一对象 x 保存的序列化信息载入的, 则我们称 x' 为 恢复副本, 对应于原对象 x. 给定二元谓词 Pred (定义于 (T,T) 上), 以及对象 p 与 q——二者的类型均为 Pred——我们称 q 序列化兼容于 p, 如果

p(x,y) == q(x',y')
对每个 x 与 y (类型为 T ), 以及 x' 与 y' 分别是 x 与 y 的恢复副本.

操作: 保存 multi_index_container m 到输出档案 (XML 档案) ar.
要求: Value 是可序列化的 (XML 可序列化). 此外, m 的每个索引都可能施加其他要求.
异常安全性: 对 m 而言是强保证. 若抛出异常, ar 可能处于不一致状态.
操作: 将 multi_index_container m' 从输入档案 (XML 档案) ar 载入.
要求: Value 是可序列化的 (XML 可序列化). 此外, m' 的每个索引都可能施加其他要求.
异常安全性: 基本保证. 若抛出异常, ar 可能处于不一致状态.
