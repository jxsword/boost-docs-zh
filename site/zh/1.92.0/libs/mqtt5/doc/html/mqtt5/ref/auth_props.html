AUTH 属性

AUTH 报文可变报头 (Variable Header) 中的最后一个字段是一组属性 (Properties). 该组包含一个属性长度, 后跟各属性. 每个属性由标识符 (Identifier) 和值组成.

该类扩展自 prop::properties, 后者为所有属性类提供通用功能. 下面列出可能的 AUTH 属性及其用法说明:

表 1.17. AUTH 属性

标识符

值类型

说明

authentication_method

std::string

UTF-8 编码字符串, 包含用于扩展认证的认证方法名称.

authentication_data

std::string

二进制数据, 包含认证数据. 数据内容由认证方法定义.

reason_string

std::string

UTF-8 编码字符串, 表示与此响应关联的原因.

user_property

std::vector<std::pair<std::string, std::string>>

定义用户属性 (User Property) 的名称-值对 (UTF-8 String Pair). 一个报文中可以有多对. 该属性可用于提供额外的诊断或其他信息.

用法

获得 boost::mqtt5::auth_props 的实例后, 可以使用下标运算符访问属性.

上表所列标识符可在 boost::mqtt5::prop 命名空间中使用, 用于访问属性.

注释

访问属性值时, 对所有属性, 下标运算符将返回值类型的 std::optional; 但 boost::mqtt5::prop::user_property 例外, 它将返回 std::vector<std::pair<std::string, std::string>> 的实例.

示例

以下示例展示如何设置属性值:

boost::mqtt5::auth_props props;
props[boost::mqtt5::prop::authentication_method] = "SCRAM-SHA-1";
props[boost::mqtt5::prop::authentication_data] = "data";
props[boost::mqtt5::prop::user_property].emplace_back("name", "value");

以下示例展示如何获取属性值:

std::optional<std::string> auth_data = props[boost::mqtt5::prop::authentication_data];
if (auth_data.has_value())
    // authentication data property was previously set
else
    // authentication data property was not set

std::vector<std::pair<std::string, std::string>>& user_props = props[boost::mqtt5::prop::user_property];
if (!user_props.empty())
    // user property was previously set
else
    // user property was not set
