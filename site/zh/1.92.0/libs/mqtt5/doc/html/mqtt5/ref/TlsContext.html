TlsContext 概念

TlsContext 表示一个对象, 定义用户建立 TLS/SSL 连接的配置. 若不需要 TLS/SSL, 该参数默认为 std::monostate.

mqtt_client 将 TlsContext 对象视为不透明实体. 它主要用于创建底层传输流, 不会由 mqtt_client 直接操作.

例如, 使用 boost::asio::ssl::stream<boost::asio::ip::tcp::socket> 建立安全连接需要 boost::asio::ssl::context 作为 TlsContext 类型. 相关示例见 hello_world_over_tls.cpp 示例.
