StreamType 概念

StreamType 表示用于传输字节流的传输协议类型.

StreamType 应满足 AsyncStream 概念.

注释

由于 boost::beast::websocket::stream<NextLayer> 不满足 AsyncWriteStream, 要求已放宽, 允许流提供 async_write 操作来替代 async_write_some.

给定 ConstBufferSequence 回调 cb 与 CompletionToken t, s.async_write(cb, t) 应满足 异步操作 的要求, 完成签名为 void(error_code ec, size_t n), 并应将提供的所有数据写入该流.

它应遵循 Asio 的分层流模型: 具有成员类型 lowest_layer_type 与成员函数 lowest_layer, 后者返回 lowest_layer_type&. lowest_layer_type 应继承自 boost::asio::ip::tcp::socket.

此外, 它还应有一个 async_shutdown 函数的重载, 可通过参数依赖查找 (ADL) 发现.

类型 boost::asio::ip::tcp::socket、boost::asio::ssl::stream<boost::asio::ip::tcp::socket> 与 boost::beast::websocket::stream<NextLayer> 满足这些要求.
