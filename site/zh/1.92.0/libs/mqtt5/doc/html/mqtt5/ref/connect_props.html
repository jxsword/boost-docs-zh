CONNECT 属性

CONNECT 报文可变报头 (Variable Header) 中的最后一个字段是一组属性 (Properties). 该组包含一个属性长度, 后跟各属性. 每个属性由标识符 (Identifier) 和值组成.

该类扩展自 prop::properties, 后者为所有属性类提供通用功能. 下面列出可能的 CONNECT 属性及其用法说明:

表 1.5. CONNECT 属性

标识符

值类型

说明

session_expiry_interval

uint32_t

以秒为单位表示会话过期间隔.

receive_maximum

uint16_t

客户端愿意并发处理的 QoS 1 与 QoS 2 发布的最大数量.

maximum_packet_size

uint32_t

规范所定义的、客户端愿意处理的最大 packet size (字节). 默认值: 65536 (64KB)

topic_alias_maximum

uint16_t

客户端接受服务器所发送主题别名的最大值.

request_response_information

uint8_t

值为 0 表示服务器不得在 CONNACK 中返回响应信息. 若值为 1, 则可以返回.

request_problem_information

uint8_t

值为 0 表示服务器可以在 CONNACK 或 DISCONNECT 报文中返回原因字符串 (Reason String) 或用户属性 (User Properties), 但不得在 PUBLISH、CONNACK 或 DISCONNECT 以外的任何报文上发送它们. 若值为 1, 服务器可以在允许之处返回原因字符串或用户属性.

user_property

std::vector<std::pair<std::string, std::string>>

定义用户属性 (User Property) 的名称-值对 (UTF-8 String Pair). 一个报文中可以有多对. 这些属性的含义未由规范定义.

authentication_method

std::string

UTF-8 编码字符串, 包含用于扩展认证的认证方法名称.

authentication_data

std::string

二进制数据, 包含认证数据. 数据内容由认证方法定义.

用法

获得 boost::mqtt5::connect_props 的实例后, 可以使用下标运算符访问属性.

上表所列标识符可在 boost::mqtt5::prop 命名空间中使用, 用于访问属性.

注释

访问属性值时, 对所有属性, 下标运算符将返回值类型的 std::optional; 但 boost::mqtt5::prop::user_property 例外, 它将返回 std::vector<std::pair<std::string, std::string>> 的实例.

示例

以下示例展示如何设置属性值:

boost::mqtt5::connect_props props;
props[boost::mqtt5::prop::session_expiry_interval] = 1200;
props[boost::mqtt5::prop::receive_maximum] = uint16_t(100);
props[boost::mqtt5::prop::user_property].emplace_back("name", "value");

以下示例展示如何获取属性值:

std::optional<std::string> auth_method = props[boost::mqtt5::prop::authentication_method];
if (auth_method.has_value())
    // authentication method property was previously set
else
    // authentication method property was not set

std::vector<std::pair<std::string, std::string>>& user_props = props[boost::mqtt5::prop::user_property];
if (!user_props.empty())
    // user property was previously set
else
    // user property was not set
