boost::mqtt5::prop::properties::visit (1 of 2 overloads)

对每个属性调用访问器函数.

概要 
template<
    typename Func,
    std::enable_if_t< is_visitor< Func >::value, bool > = true>
constexpr bool
visit(
    Func&& func) const noexcept(is_nothrow_visitor< Func >::value);
说明

此函数遍历各属性, 并对每个属性调用所提供的函数, 同时传入编译期常量属性 ID 及其值. 访问器函数应返回一个布尔值, 决定是否继续迭代.

参数

名称

说明

func

要调用的访问器函数. 它必须接受两个参数: 属性 ID 与对应的属性值.
返回值

true — 若访问器函数对所有属性都返回 true; 否则为 false.
