Authenticator 概念

若类型 T 满足下面列出的要求, 则其满足 Authenticator 概念.

操作

类型

参数

 
a.async_auth(step, data, h)

void

step 是 boost::mqtt5::auth_step_e, 指定当前认证阶段.

data 是 std::string, 即服务器的认证数据.

h 是一个 boost::asio::any_completion_handler, 其签名为 void(boost::mqtt5::error_code ec, std::string client_data). 若 ec 非平凡, 则认证中止.

 
a.method()

std::string_view, 认证方法
