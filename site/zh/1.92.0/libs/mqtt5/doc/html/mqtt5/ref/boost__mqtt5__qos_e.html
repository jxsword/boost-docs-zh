boost::mqtt5::qos_e

表示 QoS (服务质量) 属性, 该属性属于 PUBLISH 报文.

概要

定义于头文件 <boost/mqtt5/types.hpp> 

enum class qos_e
    : std::uint8_t;
取值

名称

说明

at_most_once

消息要么恰好到达接收者一次, 要么根本不到达.

at_least_once

确保消息至少到达接收者一次.

exactly_once

所有消息恰好到达接收者一次, 既不丢失也不重复.
说明

决定 PUBLISH 报文如何从发送者投递到接收者.

便捷头文件 <boost/mqtt5.hpp>
