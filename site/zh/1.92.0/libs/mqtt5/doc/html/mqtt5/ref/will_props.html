遗嘱属性

遗嘱属性由决定何时发布 Will 消息的属性, 以及随 Will 消息一同发送的应用消息属性组成. 遗嘱属性包含一个属性长度和各属性. 每个属性由标识符和值组成.

该类扩展自 prop::properties, 后者为所有属性类提供通用功能. 下面列出可能的 Will 属性及其用法说明:

表 1.4. 遗嘱属性

标识符

值类型

说明

will_delay_interval

uint32_t

服务器发布客户端遗嘱消息之前需要经过的延迟时间 (秒).

payload_format_indicator

uint8_t

值为 0 表示遗嘱消息为未指定格式的字节. 值为 1 表示遗嘱消息是 UTF-8 编码的字符数据.

message_expiry_interval

uint32_t

遗嘱消息的生存期 (秒). 发布时将作为发布过期间隔 (Publication Expiry Interval) 发送.

content_type

std::string

描述遗嘱消息内容的 UTF-8 编码字符串.

response_topic

std::string

UTF-8 编码字符串, 用作响应消息的主题名称.

correlation_data

std::string

二进制数据, 请求消息的发送者用它来标识收到的响应消息所对应的请求.

user_property

std::vector<std::pair<std::string, std::string>>

定义用户属性 (User Property) 的名称-值对 (UTF-8 String Pair). 一个报文中可以有多对. 这些属性的含义未由规范定义.

用法

创建 boost::mqtt5::will 的实例后, 可以使用下标运算符访问属性.

上表所列标识符可在 boost::mqtt5::prop 命名空间中使用, 用于访问属性.

注释

访问属性值时, 对所有属性, 下标运算符将返回值类型的 std::optional; 但 boost::mqtt5::prop::user_property 例外, 它将返回 std::vector<std::pair<std::string, std::string>> 的实例.

示例

以下示例展示如何设置属性值:

boost::mqtt5::will will;
will[boost::mqtt5::prop::message_expiry_interval] = 90;
will[boost::mqtt5::prop::content_type] = "Notification";
props[boost::mqtt5::prop::user_property].emplace_back("name", "value");

以下示例展示如何获取属性值:

std::optional<std::string> c_type = will[boost::mqtt5::prop::content_type];
if (c_type.has_value())
    // content type property was previously set
else
    // content type property was not set

std::vector<std::pair<std::string, std::string>>& user_props = props[boost::mqtt5::prop::user_property];
if (!user_props.empty())
    // user property was previously set
else
    // user property was not set
