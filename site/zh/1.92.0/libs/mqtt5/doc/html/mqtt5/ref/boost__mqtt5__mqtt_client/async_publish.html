boost::mqtt5::mqtt_client::async_publish

向代理服务器发送 PUBLISH 报文以传输应用消息.

概要 
template<
    boost::mqtt5::qos_e qos_type,
    typename CompletionToken = typename asio::default_completion_token<boost::mqtt5::mqtt_client::executor_type>::type>
decltype(auto)
async_publish(
    std::string topic,
    std::string payload,
    boost::mqtt5::retain_e retain,
    const publish_props& props,
    CompletionToken&& token = {});
模板参数

类型

说明

qos_type

投递保障的 qos_e 等级.
参数

名称

说明

topic

负载 (Payload) 数据要发布到的信息通道的标识.

payload

正在发布的应用消息.

retain

retain_e 标志.

props

一个 boost::mqtt5::publish_props 实例.

token

将用于生成完成处理器的完成标记. 操作完成时将调用该处理器. 若立即完成, 处理器的调用将以等效于使用 boost::asio::async_immediate 的方式进行.
处理器签名

此操作的处理器签名取决于所指定的 qos_e:

qos == qos_e::at_most_once: 

void (
    boost::mqtt5::error_code    // Result of operation
)

qos == qos_e::at_least_once: 

void (
    boost::mqtt5::error_code,    // Result of operation.
    boost::mqtt5::reason_code,   // Reason Code received from Broker.
    boost::mqtt5::puback_props   // Properties received in the PUBACK packet.
)

qos == qos_e::exactly_once: 

void (
    boost::mqtt5::error_code,    // Result of operation.
    boost::mqtt5::reason_code,   // Reason Code received from Broker.
    boost::mqtt5::pubcomp_props  // Properties received in the PUBCOMP packet.
)
完成条件

根据所指定的 qos_e, 当以下条件之一为真时, 异步操作将完成:

  • 若 qos == qos_e::at_most_once 且客户端已成功将报文写入传输层.
  • 若 qos == qos_e::at_least_once 且报文已发送并通过接收 PUBACK 报文得到确认.
  • 若 qos == qos_e::exactly_once 且报文已发送并通过接收 PUBCOMP 报文得到完整确认.
  • 发生错误. 由处理器中的关联 boost::mqtt5::error_code 指示.
错误码

此操作可能以其结束的所有错误码列表:

  • boost::system::errc::errc_t::success
  • boost::asio::error::operation_aborted
  • boost::asio::error::no_recovery
  • boost::mqtt5::client::error::malformed_packet
  • boost::mqtt5::client::error::packet_too_large
  • boost::mqtt5::client::error::pid_overrun
  • boost::mqtt5::client::error::qos_not_supported
  • boost::mqtt5::client::error::retain_not_available
  • boost::mqtt5::client::error::topic_alias_maximum_reached
  • boost::mqtt5::client::error::invalid_topic

请参阅关于 Error handling 的一节, 以了解每个错误码的根本原因.

逐操作取消

此异步操作支持对以下 boost::asio::cancellation_type 值进行取消:

  • cancellation_type::terminal - 调用 cancel
  • cancellation_type::partial 与 cancellation_type::total - 防止 PUBLISH 报文可能的重发
