CONNACK 属性

CONNACK 报文可变报头 (Variable Header) 中的最后一个字段是一组属性 (Properties). 该组包含一个属性长度, 后跟各属性. 每个属性由标识符 (Identifier) 和值组成.

该类扩展自 prop::properties, 后者为所有属性类提供通用功能. 下面列出可能的 CONNACK 属性及其用法说明:

表 1.6. CONNACK 属性

标识符

值类型

说明

session_expiry_interval

uint32_t

以秒为单位表示会话过期间隔.

receive_maximum

uint16_t

服务器愿意并发处理的 QoS 1 与 QoS 2 发布的最大数量.

maximum_qos

uint8_t

服务器支持的最高 QoS.

retain_available

uint8_t

值为 0 表示不支持保留消息. 值为 1 表示支持.

maximum_packet_size

uint32_t

规范所定义的、服务器愿意接受的最大 packet size (字节).

assigned_client_identifier

std::string

由服务器分配的客户端标识符, 原因是 CONNECT 报文中出现了零长度客户端标识符

topic_alias_maximum

uint16_t

服务器接受客户端所发送主题别名的最大值.

reason_string

std::string

UTF-8 编码字符串, 表示与此响应关联的原因.

user_property

std::vector<std::pair<std::string, std::string>>

定义用户属性 (User Property) 的名称-值对 (UTF-8 String Pair). 一个报文中可以有多对. 这些属性的含义未由规范定义.

wildcard_subscription_available

uint8_t

值为 0 表示不支持通配符订阅. 值为 1 表示支持. 若不出现, 则表示支持.

subscription_identifier_available

uint8_t

值为 0 表示不支持订阅标识符. 值为 1 表示支持. 若不出现, 则表示支持.

shared_subscription_available

uint8_t

值为 0 表示不支持共享订阅. 值为 1 表示支持. 若不出现, 则表示支持.

server_keep_alive

uint16_t

由服务器指定的保持连接时间.

response_information

std::string

UTF-8 编码字符串, 用作创建响应主题 (Response Topic) 的基础.

server_reference

std::string

UTF-8 编码字符串, 客户端可用它来标识要使用的另一个服务器.

authentication_method

std::string

UTF-8 编码字符串, 包含用于扩展认证的认证方法名称.

authentication_data

std::string

二进制数据, 包含认证数据. 数据内容由认证方法定义.

用法

获得 boost::mqtt5::connack_props 的实例后, 可以使用下标运算符访问属性.

上表所列标识符可在 boost::mqtt5::prop 命名空间中使用, 用于访问属性.

注释

访问属性值时, 对所有属性, 下标运算符将返回值类型的 std::optional; 但 boost::mqtt5::prop::user_property 例外, 它将返回 std::vector<std::pair<std::string, std::string>> 的实例.

示例

以下示例展示如何设置属性值:

boost::mqtt5::connack_props props;
props[boost::mqtt5::prop::maximum_packet_size] = 65535;
props[boost::mqtt5::prop::assigned_client_identifier] = "ClientID";
props[boost::mqtt5::prop::user_property].emplace_back("name", "value");

以下示例展示如何获取属性值:

std::optional<std::string> auth_method = props[boost::mqtt5::prop::authentication_method];
if (auth_method.has_value())
    // authentication method property was previously set
else
    // authentication method property was not set

std::vector<std::pair<std::string, std::string>>& user_props = props[boost::mqtt5::prop::user_property];
if (!user_props.empty())
    // user property was previously set
else
    // user property was not set
