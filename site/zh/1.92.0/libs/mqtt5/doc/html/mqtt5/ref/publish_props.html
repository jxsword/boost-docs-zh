PUBLISH 属性

PUBLISH 报文可变报头 (Variable Header) 中的最后一个字段是一组属性 (Properties). 该组包含一个属性长度, 后跟各属性. 每个属性由标识符 (Identifier) 和值组成.

该类扩展自 prop::properties, 后者为所有属性类提供通用功能. 下面列出可能的 PUBLISH 属性及其用法说明:

表 1.7. PUBLISH 属性

标识符

值类型

说明

payload_format_indicator

uint8_t

值为 0 表示负载为未指定格式的字节. 值为 1 表示负载是 UTF-8 编码的字符数据.

message_expiry_interval

uint32_t

应用消息的生存期 (秒).

topic_alias

uint16_t

两字节整数, 表示主题别名, 即用于标识主题 (替代主题名称) 的整数值.

response_topic

std::string

UTF-8 编码字符串, 用作响应消息的主题名称.

correlation_data

std::string

二进制数据, 请求消息的发送者用它来标识收到的响应消息所对应的请求.

user_property

std::vector<std::pair<std::string, std::string>>

定义用户属性 (User Property) 的名称-值对 (UTF-8 String Pair). 一个报文中可以有多对. 这些属性的含义未由规范定义.

subscription_identifier

boost::mqtt5::prop::subscription_identifiers

匹配订阅的标识符. 若有多个匹配的订阅, 可能包含多个标识符.

content_type

std::string

描述应用消息内容的 UTF-8 编码字符串.

用法

获得 boost::mqtt5::publish_props 的实例后, 可以使用下标运算符访问属性.

上表所列标识符可在 boost::mqtt5::prop 命名空间中使用, 用于访问属性.

注释

访问属性值时, 对所有属性, 下标运算符将返回值类型的 std::optional; 但 boost::mqtt5::prop::user_property 与 boost::mqtt5::prop::subscription_identifier 例外, 它们将分别返回 std::vector<std::pair<std::string, std::string>> 与 prop::subscription_identifiers 的实例. prop::subscription_identifiers 具有 boost::container::small_vector 的接口.

示例

以下示例展示如何设置属性值:

boost::mqtt5::publish_props props;
props[boost::mqtt5::prop::payload_format_indicator] = uint8_t(1);
props[boost::mqtt5::prop::topic_alias] = uint16_t(12);
props[boost::mqtt5::prop::response_topic] = "response_topic";
props[boost::mqtt5::prop::subscription_identifier].push_back(40);

以下示例展示如何获取属性值:

std::optional<uint16_t> topic_alias = props[boost::mqtt5::prop::topic_alias];
if (topic_alias.has_value())
    // topic alias property was previously set
else
    // topic alias property was not set

boost::mqtt5::prop::subscription_identifiers& sub_ids = props[boost::mqtt5::prop::subscription_identifier];
if (!sub_ids.empty())
    // subscription identifier property was previously set
else
    // subscription identifier property was not set
