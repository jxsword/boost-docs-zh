boost::mqtt5::mqtt_client::credentials

指定用于连接代理服务器的凭据.

概要 
boost::mqtt5::mqtt_client&
credentials(
    std::string client_id,
    std::string username = "",
    std::string password = "");
说明

凭据由唯一的客户端标识符组成, 可选地包含用户名和密码.

注意

当客户端处于非运行状态 (即 async_run 函数尚未被调用) 时, 此函数会生效. 此外, 在 cancel 函数被调用之后、async_run 函数再次被调用之前, 也可以使用此函数.
