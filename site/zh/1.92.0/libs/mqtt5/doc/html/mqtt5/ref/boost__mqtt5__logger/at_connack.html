boost::mqtt5::logger::at_connack

输出代理服务器发送的 CONNACK 报文的内容.

概要 
void
at_connack(
    boost::mqtt5::reason_code rc,
    bool session_present,
    const connack_props& ca_props);
参数

名称

说明

rc

接收到的 CONNACK 报文中的 Reason Code, 指示 MQTT 握手的结果.

session_present

标志, 指示代理服务器是否已拥有与此连接关联的会话.

ca_props

boost::mqtt5::connack_props, 在 CONNACK 报文中收到.
