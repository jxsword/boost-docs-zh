boost::mqtt5::will::will (2 of 3 overloads)

构造一条遗嘱消息.

概要 
will(
    std::string topic,
    std::string message,
    boost::mqtt5::qos_e qos = boost::mqtt5::qos_e::at_most_once,
    boost::mqtt5::retain_e retain = boost::mqtt5::retain_e::no);
参数

名称

说明

topic

主题, 即遗嘱消息将要发布到的信息通道的标识.

message

将要发布的消息.

qos

发布遗嘱消息时使用的 qos_e 等级.

retain

retain_e 标志, 指定遗嘱消息发布时是否被保留.
