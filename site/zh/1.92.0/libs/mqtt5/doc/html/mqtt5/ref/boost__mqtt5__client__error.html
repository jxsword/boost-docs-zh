boost::mqtt5::client::error

定义与 MQTT 客户端相关的错误码.

概要

定义于头文件 <boost/mqtt5/error.hpp> 

enum class error
    : int;
取值

名称

说明

malformed_packet

报文格式有误.

packet_too_large

报文超过了服务器愿意接受的最大报文大小.

session_expired

客户端的会话不存在或已过期.

pid_overrun

没有更多可用的报文标识符.

invalid_topic

主题无效, 不符合规范.

qos_not_supported

服务器不支持指定的 qos_e.

retain_not_available

服务器不支持保留消息.

topic_alias_maximum_reached

客户端试图发送大于主题别名上限 (Topic Alias Maximum) 的主题别名.

wildcard_subscription_not_available

服务器不支持通配符订阅.

subscription_identifier_not_available

服务器不支持该订阅标识符.

shared_subscription_not_available

服务器不支持共享订阅.

already_running

客户端已在运行, 因为 mqtt_client::async_run 已被调用.
说明

封装客户端侧发生的错误.

便捷头文件 <boost/mqtt5.hpp>
