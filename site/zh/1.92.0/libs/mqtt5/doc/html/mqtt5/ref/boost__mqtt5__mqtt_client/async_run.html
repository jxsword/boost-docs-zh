boost::mqtt5::mqtt_client::async_run

启动客户端.

概要 
template<
    typename CompletionToken = typename asio::default_completion_token<boost::mqtt5::mqtt_client::executor_type>::type>
decltype(auto)
async_run(
    CompletionToken&& token = {});
参数

名称

说明

token

将用于生成完成处理器的完成标记. 操作完成时将调用该处理器.
处理器签名

此操作的处理器签名:

void (boost::mqtt5::error_code)
完成条件

异步操作将以 boost::asio::error::operation_aborted 完成, 情形包括: 客户端被取消 (通过调用 async_disconnect 或 cancel)、客户端被销毁, 或连接尝试期间发生不可恢复错误 (例如访问被拒绝). 若客户端已在运行, 操作将立即以 client::error::already_running 完成.

错误码

此操作可能以其结束的所有错误码列表:

  • boost::asio::error::operation_aborted
  • client::error::already_running
逐操作取消

此异步操作支持对以下 boost::asio::cancellation_type 值进行取消:

  • cancellation_type::terminal - 调用 cancel
