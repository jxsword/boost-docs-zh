SUBSCRIBE 属性

SUBSCRIBE 报文可变报头 (Variable Header) 中的最后一个字段是一组属性 (Properties). 该组包含一个属性长度, 后跟各属性. 每个属性由标识符 (Identifier) 和值组成.

该类扩展自 prop::properties, 后者为所有属性类提供通用功能. 下面列出可能的 SUBSCRIBE 属性及其用法说明:

表 1.12. SUBSCRIBE 属性

标识符

值类型

说明

subscription_identifier

boost::mqtt5::prop::subscription_identifiers

订阅的标识符, 取值范围为 1 到 268,435,455.

user_property

std::vector<std::pair<std::string, std::string>>

定义用户属性 (User Property) 的名称-值对 (UTF-8 String Pair). 一个报文中可以有多对. 此属性可用于将订阅相关的属性从客户端发送到服务器. 这些属性的含义未由规范定义

用法

获得 boost::mqtt5::subscribe_props 的实例后, 可以使用下标运算符访问属性.

上表所列标识符可在 boost::mqtt5::prop 命名空间中使用, 用于访问属性.

注释

访问属性值时, 对所有属性, 下标运算符将返回值类型的 std::optional; 但 boost::mqtt5::prop::user_property 与 boost::mqtt5::prop::subscription_identifier 例外, 它们将分别返回 std::vector<std::pair<std::string, std::string>> 与 prop::subscription_identifiers 的实例. prop::subscription_identifiers 具有 std::optional<int32_t> 的接口.

示例

以下示例展示如何设置属性值:

boost::mqtt5::subscribe_props props;
props[boost::mqtt5::prop::subscription_identifier] = 1234;
props[boost::mqtt5::prop::user_property].emplace_back("name", "value");

以下示例展示如何获取属性值:

boost::mqtt5::prop::subscription_identifiers sub_id = props[boost::mqtt5::prop::subscription_identifier];
if (sub_id.has_value())
    // subscription identifier property was previously set
else
    // subscription identifier property was not set

std::vector<std::pair<std::string, std::string>>& user_props = props[boost::mqtt5::prop::user_property];
if (!user_props.empty())
    // user property was previously set
else
    // user property was not set
