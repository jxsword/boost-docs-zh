分配器

每个异步操作都有一个关联分配器, 旨在操作执行期间为其提供一致且稳定的内存来源. 这部分内存称为逐操作稳定内存资源 (POSM), 在操作的整个生命期内一直保留, 确保随时可用. 异步操作可以通过多种方式使用 POSM. 更多信息请参见 分配器 与 自定义内存分配.

mqtt_client 支持并使用与 async_xxx 的处理器相关联的分配器来存储与操作相关的状态. 具体而言, 分配器用于为 MQTT 控制报文字节 (PUBLISH, SUBSCRIBE, ...) 预留内存, 这些字节由每个 async_xxx 操作请求创建. 此外, mqtt_client 的内部报文队列 (在 通过数据包排队高效利用带宽 一节 (见 优化通信 一节) 中描述) 会将队列中第一个报文的分配器关联到传输层上的底层 Boost.Asio 函数 async_write.

最后, mqtt_client 使用 boost::asio::recycling_allocator 为其内部操作与组件分配内存.
