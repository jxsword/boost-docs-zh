boost::mqtt5::mqtt_client::keep_alive

指定客户端两次传输之间允许经过的最大时间间隔.

概要 
boost::mqtt5::mqtt_client&
keep_alive(
    uint16_t seconds);
说明

非零值将启动发送 PINGREQ 报文的过程, 每次间隔为 seconds. 若未调用此函数, 客户端将假定 Keep Alive 间隔为 60 秒.

参数

名称

说明

seconds

以秒为单位的时间间隔.
备注

若服务器发送 Server Keep Alive, 客户端将发送一个 PINGREQ 报文, 每次间隔 Server Keep Alive 秒.

注意

当客户端处于非运行状态 (即 async_run 函数尚未被调用) 时, 此函数会生效. 此外, 在 cancel 函数被调用之后、async_run 函数再次被调用之前, 也可以使用此函数.
