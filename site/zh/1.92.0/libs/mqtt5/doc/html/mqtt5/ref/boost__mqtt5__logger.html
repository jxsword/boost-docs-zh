boost::mqtt5::logger

一个日志器类, 可由 mqtt_client 使用, 将操作结果输出到 stderr.

概要

定义于头文件 <boost/mqtt5/logger.hpp> 

class logger;
成员函数

名称

说明

at_connack

输出代理服务器发送的 CONNACK 报文的内容.

at_disconnect

输出代理服务器发送的 DISCONNECT 报文的内容.

at_resolve

输出解析操作的结果.

at_tcp_connect

输出 TCP 连接操作的结果.

at_tls_handshake

输出 TLS 握手操作的结果.

at_transport_error

在传输层读或写操作发生错误时输出错误消息.

at_ws_handshake

输出 WebSocket 握手操作的结果.

logger [constructor]

构造一个日志器, 根据指定的日志级别过滤日志消息.
说明

所有函数都在 mqtt_client 内部使用其默认执行器直接调用. 若 mqtt_client 以显式或隐式 strand 初始化, 则任何函数都不会被并发调用.

线程安全

不同对象: 安全.

共享对象: 不安全.

该类 不是线程安全的.

便捷头文件 <boost/mqtt5.hpp>
