boost::mqtt5::mqtt_client

用于连接代理服务器并与之通信的 MQTT 客户端.

概要

定义于头文件 <boost/mqtt5/mqtt_client.hpp> 

template<
    typename StreamType,
    typename TlsContext = std::monostate,
    typename LoggerType = noop_logger>
class mqtt_client;
类型

名称

说明

executor_type

与客户端关联的执行器类型.

rebind_executor

将客户端类型重绑定到另一个执行器.
成员函数

名称

说明

async_disconnect

通过发送带有指定 Reason Code 的 DISCONNECT 报文断开客户端. 此函数具有终结效果.
—
通过发送 Reason Code 为 reason_codes.normal_disconnection 的 DISCONNECT 报文断开客户端. 此函数具有终结效果.

async_publish

向代理服务器发送 PUBLISH 报文以传输应用消息.

async_receive

异步接收应用消息.

async_run

启动客户端.

async_subscribe

向代理服务器发送 SUBSCRIBE 报文, 创建对一个或多个感兴趣主题的订阅.
—
向代理服务器发送 SUBSCRIBE 报文, 创建对一个感兴趣主题的订阅.

async_unsubscribe

向代理服务器发送 UNSUBSCRIBE 报文, 取消对一个或多个主题的订阅.
—
向代理服务器发送 UNSUBSCRIBE 报文, 取消对一个主题的订阅.

authenticator

指定认证器, 客户端将在每次连接代理服务器时将其用于 Enhanced Authentication. 可以通过调用 re_authenticate 发起重认证.

brokers

指定客户端要尝试连接的代理服务器列表.

cancel

取消所有异步操作. 此函数具有终结效果.

connack_properties

检索 boost::mqtt5::connack_props, 其来自最后接收的 CONNACK 报文.

connack_property

从最后接收的 CONNACK 报文中检索特定属性的值.

connect_properties

指定 boost::mqtt5::connect_props, 将随 CONNECT 报文一同发送.

connect_property

指定将随 CONNECT 报文一同发送的属性.

credentials

指定用于连接代理服务器的凭据.

get_executor

获取与该对象关联的执行器.

keep_alive

指定客户端两次传输之间允许经过的最大时间间隔.

mqtt_client [constructor]

以给定参数构造客户端.
—
从另一个对象移动构造 mqtt_client.

operator=

移动赋值运算符.

re_authenticate

发起 Re-authentication, 使用 authenticator 方法中给定的认证器.

tls_context

获取 TLS/SSL 连接中使用的上下文对象.

will

指定 will 消息.

~mqtt_client [destructor]

析构函数.
模板参数

类型

说明

StreamType

用于在客户端与代理服务器之间传输字节流的底层传输协议类型. 该传输必须有序且无损.

TlsContext

TLS/SSL 连接中使用的上下文对象类型.

LoggerType

用于在客户端内记录事件的对象类型.
线程安全

不同对象: 安全.

共享对象: 不安全.

该类 不是线程安全的. 应用还必须确保所有异步操作都在同一个隐式或显式 strand 内执行.
