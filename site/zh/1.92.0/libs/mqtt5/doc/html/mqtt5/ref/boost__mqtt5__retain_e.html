boost::mqtt5::retain_e

表示 RETAIN 标志, 见于 PUBLISH 报文中.

概要

定义于头文件 <boost/mqtt5/types.hpp> 

enum class retain_e
    : std::uint8_t;
取值

名称

说明

yes

服务器将用此消息替换该主题现有的任何保留消息.

no

服务器不会存储此消息, 也不会移除或替换任何现有的保留消息.
说明

此标志告知服务器是否应存储当前消息.

便捷头文件 <boost/mqtt5.hpp>
