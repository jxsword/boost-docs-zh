说明

Reason Code 是一个单字节无符号值, 指示操作的结果. 小于 0x80 的 Reason Code 表示操作成功完成. 成功的常规 Reason Code 是 0. 0x80 或更大的 Reason Code 值表示失败. CONNACK、PUBACK、PUBREC、PUBREL、PUBCOMP、DISCONNECT 与 AUTH 控制报文在可变报头中包含单个 Reason Code. SUBACK 与 UNSUBACK 报文在负载中包含一个或多个 Reason Code 的列表.

参见

此类所有可能实例的完整列表请参见 Reason Codes.
