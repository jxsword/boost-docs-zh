示例

以下列表包含展示 mqtt_client 用法的全部示例:

publisher.cpp

演示如何将 mqtt_client 用作发布者. mqtt_client 每隔 5 seconds 发布一次传感器读数.

receiver.cpp

演示如何将 mqtt_client 用作接收者. mqtt_client 订阅并无限期地从代理服务器接收应用消息 (Application Message).

hello_world_over_tcp.cpp

通过 TCP/IP 发布 “Hello World” 消息.

hello_world_over_tls.cpp

通过 TLS/SSL 发布 “Hello World” 消息.

hello_world_over_websocket_tcp.cpp

通过 Websocket/TLS 发布 “Hello World” 消息.

hello_world_over_websocket_tls.cpp

通过 Websocket/TLS 发布 “Hello World” 消息.

multiflight_client.cpp

演示如何使用 mqtt_client 同时派发多个请求.

timeout_with_parallel_group.cpp

演示如何利用 mqtt_client 对逐操作取消的支持, 使用并行组 (parallel group) 在时间约束下执行操作.

timeout_with_awaitable_operators.cpp

演示如何利用 mqtt_client 对逐操作取消的支持, 使用 awaitable 运算符在时间约束下执行操作.

hello_world_in_multithreaded_env.cpp

演示如何在多线程环境中使用回调 (post/dispatch) 发布 “Hello World” 消息.

hello_world_in_coro_multithreaded_env.cpp

演示如何在多线程环境中使用协程 (co_spawn) 发布 “Hello World” 消息.
