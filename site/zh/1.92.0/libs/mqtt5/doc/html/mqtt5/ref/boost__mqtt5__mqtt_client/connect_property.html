boost::mqtt5::mqtt_client::connect_property

指定将随 CONNECT 报文一同发送的属性.

概要 
template<
    prop::property_type p>
boost::mqtt5::mqtt_client&
connect_property(
    std::integral_constant< prop::property_type, p > prop,
    boost::mqtt5::prop::value_type_t< p > value);
参数

名称

说明

prop

要设置的 boost::mqtt5::connect_props 属性.

value

将赋给该属性的值.
示例 
client.connect_property(prop::session_expiry_interval, 40); // ok
client.connect_property(prop::reason_string, "reason"); // does not compile, not a CONNECT prop!
参见

所有可用属性请参见 boost::mqtt5::connect_props.
