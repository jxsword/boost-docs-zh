boost::mqtt5::mqtt_client::cancel

取消所有异步操作. 此函数具有终结效果.

概要 
void
cancel();
说明

所有未完成的操作将以 boost::asio::error::operation_aborted 完成.

注意

此函数具有终结效果, 将关闭客户端. 在再次调用 async_run 之前, 客户端无法使用.
