boost::mqtt5::prop::subscription_identifiers

保存任意数量订阅标识符的类.

概要

定义于头文件 <boost/mqtt5/property_types.hpp> 

class subscription_identifiers
    : public boost::container::small_vector< int32_t, 1 >;

说明

订阅标识符是一个整数, 可在订阅主题时在 boost::mqtt5::subscribe_props 中设置. 代理服务器会存储该订阅与订阅标识符之间的映射. 当传入的 PUBLISH 消息匹配一个或多个订阅时, 相应的订阅标识符将在所收到消息的 boost::mqtt5::publish_props 中转发.
