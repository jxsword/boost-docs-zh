boost::mqtt5::authority_path

用于存储与 authority 相关信息的数据结构, 例如主机名、端口和路径.

概要

定义于头文件 <boost/mqtt5/types.hpp> 

struct authority_path;
数据成员

名称

说明

host

authority 的主机名, 为域名或 IP 地址.

path

指定与 WebSocket 连接相关的端点路径.

port

用于通信的端口号.

便捷头文件 <boost/mqtt5.hpp>
