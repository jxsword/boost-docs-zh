Boost.MultiArray: 补充说明

编译器支持

Boost.MultiArray 的设计充分考虑了编译器支持问题. 接口上的妥协被保持在最低限度, 但我们仍尽力顾及了编写本库时流行的那些编译器在 C++ 标准符合性方面的问题. 尽管如此, Boost.MultiArray 已在下列编译器上通过了测试:
  1. Gnu C++ 编译器 v2.95.2 (编译时使用 -ftemplate-depth-50)
  2. Gnu C++ 编译器 v3.0.2
  3. Kuck and Associates C++ 编译器 v4.0f
  4. Microsoft Visual C++ v6.0 sp5
  5. Comeau C++ 编译器 v4.2.45 beta 2 (libcomo beta 14)
  6. Intel C++ 编译器 v5.0 (配 MS lib v6.0 sp5)
  7. Metrowerks CodeWarrior C++ 编译器 v7.1
已知 Boost.MultiArray 不能在 Borland C++ v5.5.1 上工作. 对该编译器的支持即将提供.

Future Work

以下是本库最初加入 Boost 发行版之后近期计划开展的工作列表:
  1. 跟进并记录与编译器及实现相关的性能问题.
  2. 更多使用库组件的综合示例.
  3. 大幅重写用户文档, 使其更易于理解.
