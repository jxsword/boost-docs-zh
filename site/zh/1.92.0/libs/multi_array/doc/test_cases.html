Boost.MultiArray: 测试说明

下面描述随 Boost.Multi_Array (B.M) 一同提供的各个测试用例.

术语

下面的列表用于澄清以下描述中各术语的用法:
  • B.M - Boost.MultiArray 的缩写.
  • 主要组件 - 指 boost::multi_array, boost::const_multi_array_ref 与 boost::multi_array_ref.
  • 数组类型 - 指所有主要组件, 外加针对每个主要组件 "array" 的下列类型: array::const_subarray, array::subarray, array::const_array_view 与 array::array_view

验收测试

以下测试演练 Boost.Multi_Array 的各种特性, 以确保其在运行期行为正确.
程序 说明
libs/multi_array/test/constructors.cpp 演练 B.M 主要组件的全部构造函数.
libs/multi_array/test/access.cpp 测试全部 B.M 数组类型的 operator[] 与 operator().
libs/multi_array/test/compare.cpp 测试 B.M 主要组件的所有比较运算符.
libs/multi_array/test/iterators.cpp 测试所有 B.M 数组类型的全部迭代器遍历与访问功能.
libs/multi_array/test/slice.cpp 测试所有 B.M 数组类型的各种子视图生成方式.
libs/multi_array/test/assign.cpp 对各种 B.M 数组类型测试 operator=().
libs/multi_array/test/assign_to_array.cpp 确保 multi_array 可由任何其他数组类型构造.
libs/multi_array/test/index_bases.cpp 测试 B.M 主要组件的重设索引功能.
libs/multi_array/test/storage_order_convert.cpp 测试各存储序数据类型之间的相互转换.
libs/multi_array/test/storage_order.cpp 针对 B.M 主要组件测试 storage_order 的各种变体.
libs/multi_array/test/reshape.cpp 测试 B.M 主要组件的重设形状功能.
libs/multi_array/test/range1.cpp 测试使用 array::index_range 指定索引范围的各种语法.
libs/multi_array/test/idxgen1.cpp 测试 array::index_gen 对象.
libs/multi_array/test/stl_interaction.cpp 测试数组类型与 STL 容器之间的互操作.
libs/multi_array/test/resize.cpp 测试 multi_array 类的调整大小功能.
libs/multi_array/test/concept_checks.cpp 确保所有数组类型都满足所定义的概念.
libs/multi_array/test/assert.cpp 确保库中对 BOOST_ASSERT 的使用可由库用户自定义.
libs/multi_array/test/allocators.cpp 测试对自定义分配器的支持.
libs/multi_array/test/generative_tests.hpp 一种用于简化针对所有数组类型的操作测试的测试装置. 由 slice.cpp、iterators.cpp 与 access.cpp 使用.
