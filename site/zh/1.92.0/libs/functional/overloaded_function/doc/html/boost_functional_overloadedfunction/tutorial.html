重载
不使用 Function Types (函数类型)

本节说明如何使用本库.

重载

考虑下面这些具有不同签名的函数:

const std::string& identity_s(const std::string& x) // Function (as pointer).
    { return x; }

int identity_i_impl(int x) { return x; }
int (&identity_i)(int) = identity_i_impl; // Function reference.

double identity_d_impl(double x) { return x; }
boost::function<double (double)> identity_d = identity_d_impl; // Functor.

本库头文件 boost/functional/overloaded_function.hpp 提供了一个 boost::overloaded_function 类模板, 用于创建单个重载函数对象, 可以用它来调用指定函数, 而不必使用各自的函数名 (另见 functor.cpp 和 identity.hpp):

boost::overloaded_function<
      const std::string& (const std::string&)
    , int (int)
    , double (double)
> identity(identity_s, identity_i, identity_d);

// All calls via single `identity` function.
BOOST_TEST(identity("abc") == "abc");
BOOST_TEST(identity(123) == 123);
BOOST_TEST(identity(1.23) == 1.23);

注意每个函数类型都以下述语法作为 boost::overloaded_function 的模板参数传入 (这也是 Boost.Function 推荐的语法):

result-type (argument1-type, argument2-type, ...)

然后按照指定模板参数的顺序, 将相应的函数指针、函数引用或 单态函数 对象传递给 boost::overloaded_function 构造函数. [2] 在上例中, identity_s 以函数指针形式传入 (编译器自动从函数名取得函数地址), identity_i 以函数引用形式传入, identity_d 以函数对象形式传入.

所有指定函数类型的参数必须彼此不同 (以便本库能够解析重载调用). [3] 要创建重载函数对象, 至少需要指定两个函数类型 (因为一个或零个函数之间无从谈起重载).

不指定函数类型

为方便起见, 本库还提供了 boost::make_overloaded_function 函数模板, 无需显式指定函数类型即可创建重载函数对象. 函数类型会从指定函数自动推导, 相应的 boost::overloaded_function 实例由 boost::make_overloaded_function 返回.

boost::make_overloaded_function 函数模板在与 Boost.Typeof 的 BOOST_AUTO (或 C++11 的 auto) 配合使用时很有用. 例如 (另见 make_decl.cpp 和 identity.hpp):

BOOST_AUTO(identity, boost::make_overloaded_function(
        identity_s, identity_i, identity_d));

BOOST_TEST(identity("abc") == "abc");
BOOST_TEST(identity(123) == 123);
BOOST_TEST(identity(1.23) == 1.23);

注意重载函数对象 identity 的创建方式: 只指定了函数 identity_s、identity_i、identity_d, 而未指定函数类型 const std::string& (const std::string&)、int (int) 和 double (double), 而这正是 boost::overloaded_function 所要求的. 因此, boost::make_overloaded_function 在这种场景下提供了比 boost::overloaded_function 更简洁的语法.

另一个 boost::make_overloaded_function 能派上用场的场景是: 重载函数对象被传递给一个函数模板, 而该模板可以用模板参数保存特定的 boost::overloaded_function 类型. 例如 (另见 make_call.cpp 和 identity.hpp):

template<typename F>
void check(F identity) {
    BOOST_TEST(identity("abc") == "abc");
    BOOST_TEST(identity(123) == 123);
    BOOST_TEST(identity(1.23) == 1.23);
}


check(boost::make_overloaded_function(identity_s, identity_i, identity_d));

boost::make_overloaded_function 的库实现使用 Boost.Typeof 自动推导部分函数类型. 为了在 Boost.Typeof 模拟模式下编译代码, 所有类型都应使用 BOOST_TYPEOF_REGISTER_TYPE 和 BOOST_TYPEOF_REGISTER_TEMPLATE 正确注册, 或包含相应的 Boost.Typeof 头文件 (更多信息见 Boost.Typeof). 对于上面的示例, 只需包含 Boost.Typeof 头文件, 它注册了 std::string (本库不要求注册 boost::function 以进行 Boost.Typeof 模拟):

#include <boost/typeof/std/string.hpp> // No need to register `boost::function`.


[2] 函数指针形如 result-type (*)(argument1-type, ...) (在期望函数指针的语境中, C++ 编译器通常能自动将函数名提升为函数指针, 即使函数名没有以 & 为前缀). 函数引用形如 result-type (&)(argument1-type, ...). 函数类型形如 result-type (argument1-type, ...) (注意与函数指针和函数引用相比, 它们同时缺少 * 和 &). 最后, 单态函数对象是带有非模板调用运算符的类的实例, 其调用运算符形如 result-type operator()(argument1-type, ...). 遗憾的是, 无法支持多态函数对象 (见 http://lists.boost.org/Archives/boost/2012/03/191744.php).

[3] 注意, 在 C++ 中函数结果类型不参与重载决议 (以避免使重载决议依赖于上下文). 因此, 每个指定函数类型至少要有一个函数参数彼此不同.
