本节说明如何搭建使用本库的系统.

编译器与平台

作者最初在以下环境开发和测试本库:

  1. GNU 编译器套件 (GCC) C++ 4.5.3 (在启用与未启用 C++11 特性 -std=c++0x 两种配置下) 于 Cygwin 上.
  2. Microsoft Visual C++ (MSVC) 8.0, 运行于 Windows 7.

有关受支持编译器和平台的详细信息, 请查看本库的 回归测试结果. 请查看本库回归测试 Jamfile.v2, 以了解特定编译器可能需要的特殊配置.

安装

本库仅由头文件组成, 因此没有需要安装的预编译目标文件. 程序员只需告知编译器到哪里查找本库的头文件 (GCC 上是 -I 选项, MSVC 上是 /I 选项, 等等), 然后编译使用本库的代码即可.

可重载函数的最大数量由配置宏 BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_OVERLOAD_MAX 给出. 每个指定函数类型的函数参数最大数量由配置宏 BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_ARITY_MAX 给出. 所有配置宏在未定义时都有适当的默认值.
