本库允许把不同的函数重载进单个函数对象.

引言

考虑下面这些具有不同签名的函数:

const std::string& identity_s(const std::string& x) // Function (as pointer).
    { return x; }

int identity_i_impl(int x) { return x; }
int (&identity_i)(int) = identity_i_impl; // Function reference.

double identity_d_impl(double x) { return x; }
boost::function<double (double)> identity_d = identity_d_impl; // Functor.

不必用它们各自的名字来调用 (这里 BOOST_TEST 等价于 assert): [1] 

BOOST_TEST(identity_s("abc") == "abc");
BOOST_TEST(identity_i(123) == 123);
BOOST_TEST(identity_d(1.23) == 1.23);

可以利用本库创建单个 overloaded 函数对象 (或 functor), 命名为 identity, 它把对具体函数的调用聚合在一起 (另见 functor.cpp 和 identity.hpp):

boost::overloaded_function<
      const std::string& (const std::string&)
    , int (int)
    , double (double)
> identity(identity_s, identity_i, identity_d);

// All calls via single `identity` function.
BOOST_TEST(identity("abc") == "abc");
BOOST_TEST(identity(123) == 123);
BOOST_TEST(identity(1.23) == 1.23);

注意这些函数是如何通过单个重载函数对象 identity 来调用的, 而不是使用它们各自不同的名字 identity_s、identity_i 和 identity_d.


[1] 在本文档展示的大多数示例中, 使用 Boost.Core/LightweightTest (boost/core/lightweight_test.hpp) 的宏 BOOST_TEST 来检查正确性条件 (概念上类似于 assert). 被检查的条件失败时不会中止程序的执行, 而是会让 boost::report_errors 返回非零的程序退出码. 使用 Boost.Core/LightweightTest 可以把这些示例加入库的回归测试, 从而确保它们始终能正确编译和运行.
