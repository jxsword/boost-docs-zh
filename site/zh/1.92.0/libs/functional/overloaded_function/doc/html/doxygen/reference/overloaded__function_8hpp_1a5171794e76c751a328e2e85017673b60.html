函数模板 make_overloaded_function

boost::make_overloaded_function — 在无需显式指定函数类型的情况下构造重载函数对象.

概要

// In header: <boost/functional/overloaded_function.hpp>


template<typename F1, typename F2, ...> 
  overloaded_function< __function_type__< F1 >, __function_type__< F2 >,... > 
  make_overloaded_function(F1 f1, F2 f2, ...);

说明

此函数模板创建并返回一个 overloaded_function 对象, 该对象重载了所有指定的函数 f1、f2 等.

函数类型由模板参数类型在内部确定, 因此无需显式指定. 因此, 与 overloaded_function 相比, 此函数模板通常具有更简洁的语法. 当不需要知道返回的 overloaded_function 对象的确切类型时 (例如, 与 Boost.Typeof 的 BOOST_AUTO 或 C++11 的 auto 一起使用时, 或者当重载函数对象用函数模板参数处理时, 参见 教程一节), 这一点尤其有用.

可重载的函数个数上限由 BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_OVERLOAD_MAX 配置宏给出.

注释: 在本文档中, function_type 是特定于本库实现的某个符号的占位符.

参见: 教程章节, overloaded_function, BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_OVERLOAD_MAX.
