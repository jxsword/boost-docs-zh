宏 BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_ARITY_MAX

BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_ARITY_MAX — 指定被重载函数的实参个数上限.

概要

// In header: <boost/functional/overloaded_function/config.hpp>

BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_ARITY_MAX

说明

如果用户未定义此宏, 其默认值为 5 (增大该数值可能会增加编译时间). 若由用户指定, 此宏必须是非负整数.

参见: 入门, boost::overloaded_function.
