类模板 overloaded_function

boost::overloaded_function — 以不同签名重载函数的函数对象.

概要

// In header: <boost/functional/overloaded_function.hpp>

template<typename F1, typename F2, ...> 
class overloaded_function {
public:

  // public member functions
  overloaded_function(const boost::function< F1 > &, 
                      const boost::function< F2 > &, ...);
  boost::function_traits< F1 >::result_type 
  operator()(typename boost::function_traits< F1 >::arg1_type, 
             typename boost::function_traits< F1 >::arg2_type, ...) const;
  boost::function_traits< F2 >::result_type 
  operator()(typename boost::function_traits< F2 >::arg1_type, 
             typename boost::function_traits< F2 >::arg2_type, ...) const;
};

说明

该函数对象聚合了对所有指定函数类型 F1、F2 等的函数调用, 这些函数类型的函数签名必须彼此不同.

参数:

Fi 每个函数类型必须使用以下语法指定 (这是 Boost.Function 首选的语法): 
result_type (argument1_type, argumgnet2_type, ...)

在某些情况下, make_overloaded_function 函数模板可用于在无需显式指定函数类型的情况下构造重载函数对象.

必须至少指定两个不同的函数类型 (因为在一个或零个函数之间没有可重载的东西). 可重载的函数个数上限由 BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_OVERLOAD_MAX 配置宏给出. 每个指定函数类型的函数参数个数上限由 BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_ARITY_MAX 配置宏给出.

参见: 教程一节, make_overloaded_function, BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_OVERLOAD_MAX, BOOST_FUNCTIONAL_OVERLOADED_FUNCTION_CONFIG_ARITY_MAX, Boost.Function.

overloaded_function 公有成员函数

  1. overloaded_function(const boost::function< F1 > &, 
                    const boost::function< F2 > &, ...);
    构造重载函数对象.

    任何可转换为 boost::function 函数对象的函数指针、函数引用以及单态函数对象都可以作为参数指定.

    注释: 遗憾的是, 无法支持多态函数对象 (如 此处所述).

  2. boost::function_traits< F1 >::result_type 
operator()(typename boost::function_traits< F1 >::arg1_type, 
           typename boost::function_traits< F1 >::arg2_type, ...) const;
    与指定为第 1 个模板参数的函数类型的签名相匹配的调用运算符.

    这将转而调用传递给构造函数的第 1 个函数的调用运算符.

  3. boost::function_traits< F2 >::result_type 
operator()(typename boost::function_traits< F2 >::arg1_type, 
           typename boost::function_traits< F2 >::arg2_type, ...) const;
    与指定为第 2 个模板参数的函数类型的签名相匹配的调用运算符.

    这将转而调用传递给构造函数的第 2 个函数的调用运算符.

    注释: 对于所有指定的函数类型 F1、F2 等都存在类似的调用运算符 (即使本文档未一一列出).
