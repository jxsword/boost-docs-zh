函数对象特征

头文件 functional.hpp 提供两个用于函数与函数对象的特征类模板:

类型 目录 说明
template <typename T>
struct unary_traits		 function_type 函数或函数对象本身的类型 (即 T).
param_type 应用于把函数或函数对象作为参数传递的类型.
result_type 函数或函数对象返回的类型.
argument_type 函数或函数对象的实参类型.
template <typename T>
struct binary_traits		 function_type 函数或函数对象本身的类型 (即 T).
param_type 应用于把函数或函数对象作为参数传递的类型.
result_type 函数或函数对象返回的类型.
first_argument_type 函数或函数对象的第一个实参的类型.
second_argument_type 函数或函数对象的第二个实参的类型.

用法

unary_traits 应以接受单个参数的函数, 或可适配的一元函数对象 (即派生自 std::unary_function 的类, 或提供相同 typedef 的类) 实例化. (参见 C++ 标准 §20.3.1.)

binary_traits 应以接受两个参数的函数, 或可适配的二元函数对象 (即派生自 std::binary_function 的类, 或提供相同 typedef 的类) 实例化. (参见 C++ 标准 §20.3.1.)

这些模板最常见的用法是在函数对象适配器中, 从而使其既能适配函数对象, 也能适配普通函数. 做法是: 在你通常写作 (例如)

typename Operation::argument_type

的地方, 直接写作

typename boost::unary_traits<Operation>::argument_type

即可.

定义的附加类型

除了标准的 result 与 argument typedef 之外, 这些特征模板还定义了两个附加类型.

function_type

这是函数或函数对象本身的类型, 可用于如下形式的声明

template <class Predicate>
class unary_negate : // ...
{
  // ...
  private:
    typename unary_traits<Predicate>::function_type pred;
};

如果不提供该 typedef, 就无法以允许 unary_negate 用函数类型实例化的方式声明 pred (参见 C++ 标准 §14.3.1 ¶3).

param_type

这是一个适合把函数或函数对象作为参数传递给另一个函数的类型. 例如,

template <class Predicate>
class unary_negate : // ...
{
  public:
    explicit unary_negate(typename unary_traits<Predicate>::param_type x)
        :
        pred(x)
    {}
    // ...
};

函数对象按 const 引用传递; 函数指针按值传递.

局限

本库在所有函数对象适配器中都使用这些特征, 理论上使 ptr_fun 成为多余. 然而, 第三方适配器大概率不会利用这一机制, 因此可能仍需要 ptr_fun. 有鉴于此, 本库也提供了 标准函数指针适配器的增强版本.

这些特征模板在缺乏模板偏特化支持的编译器上同样无法工作. 在这种编译器上, 特征模板只能以可适配函数对象实例化, 因此必须使用 ptr_fun, 即便使用的是本库中的函数对象适配器.
