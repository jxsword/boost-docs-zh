统计分布浏览器

一个 Windows 实用工具,使用用户交互提供的参数显示统计分布的属性.

提供的分布有:

  • bernoulli
  • beta_distribution
  • binomial_distribution
  • cauchy
  • chi_squared
  • exponential
  • extreme_value
  • fisher_f
  • gamma_distribution
  • lognormal_distribution
  • negative_binomial_distribution
  • normal_distribution
  • pareto
  • poisson
  • rayleigh
  • students_t
  • triangular
  • uniform
  • weibull

计算的分布属性有:

  • 均值
  • 众数
  • 中位数
  • 方差
  • 标准差
  • 变异系数,
  • 偏度
  • 峰度
  • 超额峰度
  • 支持的范围

根据提供的值计算的有:

  • 概率密度(或概率质量)函数(PDF)
  • 累积分布函数(CDF)及其补
  • 针对典型的风险(alpha)概率(0.001, 0.01, 0.5, 0.1, 0.333)以及用户提供的其他概率计算分位数(百分位数).

可以使用 Save 或 SaveAs 将结果保存到文本文件. 四个标签页上的所有值都会输出到所选文件,并以制表符分隔,便于导入其他程序,例如电子表格或文本编辑器.

注:例如 Excel 默认只显示 10 位十进制数字;要显示最大可能的精度(约 15 位十进制数字),必须将所有单元格格式化为显示此精度. 尽管 Distexplorer 的计算异常精确,但并非所有计算出的值都能达到这样的精度. 显示为 NaN 的值无法从给定的值计算得出,最常见的原因是输入的值超出了该分布的范围.

更多信息(包括下载),请参见

Sourceforge 上的 Distexplorer

这个 Microsoft Windows 32 软件包 distribution.exe 由一个 C# 程序生成,使用 boost_math.dll,后者基于 Boost.Math Toolkit 的 Boost.Math C++ 源代码以 CLI 模式编译生成,包含底层的统计分布类与函数.

所有源代码依据 Boost Open Source License 自由开放查阅与使用.

用于生成 boost_math.dll 的 Math Toolkit C++ 源代码包含在最新的 Boost 发布中,最初为 1.35.0.

它以单个 Windows Installer 安装包 Setupdistex.msi 分发. 将 distexplorer.zip 解压到您选择的临时位置并运行 setup.exe.

(注意:.NET framework 2.0 和 VCredist 是本程序的运行要求. 最新且已更新的 Windows 环境通常已具备这些组件,如有需要,可以从 Microsoft 网站快速、轻松且安全地安装. )

(该软件包目前无法在其他平台上运行,但如果有人愿意承担这项任务,应当可以在任何 C/C++ 平台上构建一个等效的实用工具. )
