二项式系数 

#include <boost/math/special_functions/binomial.hpp>

namespace boost{ namespace math{

template <class T>
T binomial_coefficient(unsigned n, unsigned k);

template <class T, class Policy>
T binomial_coefficient(unsigned n, unsigned k, const Policy&);

}} // namespaces

返回二项式系数: nCk.

要求 k <= n.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

若结果大到无法用类型 T 表示, 可能返回 overflow_error 的结果.

重要

上述函数是模板, 其模板参数 T 无法从传给函数的参数推导. 因此如果你这样写:

boost::math::binomial_coefficient(10, 2);

会得到一个编译错误, 通常提示找不到这样的函数. 你需要显式指定返回类型, 改写为:

boost::math::binomial_coefficient<double>(10, 2);

这样返回类型就是已知的. 此外, 模板参数必须是实值类型 (如 float 或 double) 而非整数类型 — 那样太容易上溢了!

精度

对小参数, 精度与阶乘相同 (即不超过一两个 epsilon); 对较大参数, 精度与 beta 函数相同.

测试

二项式系数的抽检测试使用 Wolfram Alpha 生成的数据.

实现

二项式系数在可能时用阶乘查表计算, 使用:

nCk = n! / (k!(n-k)!)

否则用以下关系式借助 beta 函数实现:

nCk = 1 / (k * beta(k, n-k+1))

以及

nCk = 1 / ((n-k) * beta(k+1, n-k))
