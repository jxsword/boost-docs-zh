理解离散分布的分位数

离散分布在计算分位数时给我们带来一个问题: 我们从一个连续的实值变量 - 概率 - 出发, 但结果 (随机变量的值) 实际上应该是离散的.

以样本大小为 50、成功比例为 0.5 的二项分布为例. 我们可以用多种方式绘制离散分布, 但如果将 PDF 绘制为阶梯函数, 它看起来像这样:

现在假设用户请求对应概率 0.05 的分位数, 如果放大查看该区域的 CDF, 我们看到的是:

可以看出, 没有随机变量对应恰好 0.05 的概率, 因此如图所示我们面临两个选择:

  • 我们可以把结果向下舍入到 18.
  • 我们可以把结果向上舍入到 19.

实际上还有第三种选择: 我们可以"假装"分布是连续的并返回实数值结果: 在这种情况下我们会计算出约 18.701 的结果 (这准确反映了结果更接近 19 而非 18 这一事实).

通过使用策略, 我们可以把上述任何一种作为选项提供, 但这仍然留下一个问题: 究竟怎样做才对?

特别是: 默认应该使用什么策略?

在得出答案时, 我们应当认识到:

  • 计算整数结果通常比计算实数值结果快得多: 实际上在我们的测试中最多快 20 倍.
  • 通常人们计算分位数是为了执行某种检验: "如果随机变量小于 N, 那么我们可以以 90% 的置信度拒绝原假设."

因此计算整数结果既有真正的益处, 也是哲学意义上"正确的事情". 更进一步, 如果有人请求 0.05 的分位数, 我们通常可以假定他们是在要求 至少 有 95% 的概率位于所选值的右侧, 并且 至多 有 5% 的概率位于所选值的左侧.

因此在上面的二项分布示例中, 我们会把结果向下舍入到 18.

相反的规则适用于上分位数: 如果概率大于 0.5, 我们会把分位数向上舍入, 使得 至少 所请求的概率位于返回值的左侧, 并且 至多 有 1 减所请求的概率位于返回值的右侧.

同样, 对于双侧区间, 我们会把下分位数向下舍入, 上分位数向上舍入. 这确保我们 中央区域至少具有所请求的概率, 且 尾部区域至多有 1 减所请求的概率.

例如, 取我们成功比例为 0.5 的 50 样本二项分布, 如果想要 90% 的双侧置信区间, 那么我们会请求 0.05 和 0.95 分位数, 结果 向外舍入, 使得 至少 90% 的概率 位于中央区域:

到目前为止一切顺利, 但实际上有一个陷阱在等着粗心者:

quantile(binomial(50, 0.5), 0.05);

返回 18 作为结果, 这正是我们从上图中预期的; 确实, 不存在大于 18 的 x 使得:

cdf(binomial(50, 0.5), x) <= 0.05;

然而:

quantile(binomial(50, 0.5), 0.95);

返回 31, 并且确实不存在小于 31 的 x 使得:

cdf(binomial(50, 0.5), x) >= 0.95;

我们可能天真地期望对这个对称分布结果会是 32 (因为 32 = 50 - 18), 但我们需要记住, 二项分布的 cdf 对随机变量是 包含 的. 因此虽然左尾区域 包含返回的分位数, 右尾区域却总是排除上分位数值: 因为那个值"属于"中央区域.

看上面的图可以明白这里发生了什么: 下分位数 18 属于左尾, 因此任何 <= 18 的值都在左尾. 另一方面, 上分位数 31 属于中央区域, 因此尾部区域实际上从 32 开始, 任何 > 31 的值都在右尾.

因此, 如果 U 和 L 分别是上分位数和下分位数, 那么当以下条件成立时, 随机变量 X 就处于尾部区域 - 即我们会拒绝原假设的区域:

X <= L || X > U

而当以下条件成立时, 变量 X 位于中央区域:

L < X <= U

这里的教训是 在处理离散分布时始终要非常小心地进行比较, 如果有疑问, 改为以 CDF 为基础进行比较.

其他舍入策略可用

正如你从关于策略的一节中所期望的, 你不会惊讶于还有其他舍入选项可用:

integer_round_outwards

如上所述, 这是默认策略: 下分位数 (概率 < 0.5) 向下舍入, 上分位数 (概率 > 0.5) 向上舍入.

这使尾部区域 至多 具有所请求的概率, 中央区域 至少 具有所请求的概率.

integer_round_inwards

这与默认策略正好相反: 下分位数 (概率 < 0.5) 向上舍入, 上分位数 (概率 > 0.5) 向下舍入.

这使尾部区域 至少 具有所请求的概率, 中央区域 至多 具有所请求的概率.

integer_round_down

无论上分位数还是下分位数, 该策略总是将结果向下舍入

integer_round_up

无论上分位数还是下分位数, 该策略总是将结果向上舍入

integer_round_nearest

无论上分位数还是下分位数, 该策略总是将结果舍入到最接近的整数

real

该策略会为离散分布的分位数返回实数值结果: 这通常比求整数结果慢得多, 但确实允许更精细的舍入策略.

为了理解离散分布的舍入策略可以如何使用, 我们再次使用成功比例为 0.5 的 50 样本二项分布, 并以 0.05 和 0.95 计算所有可能的分位数.

先包含所需的头文件 (以及一些为简洁起见的 using 语句):

#include <iostream>
using std::cout; using std::endl;
using std::left; using std::fixed; using std::right; using std::scientific;
#include <iomanip>
using std::setw;
using std::setprecision;

#include <boost/math/distributions/binomial.hpp>

接下来把所需的声明带入作用域, 并为所有可用的舍入策略定义分布类型:

// Avoid 
// using namespace std; // and 
// using namespace boost::math;
// to avoid potential ambiguity of names, like binomial.
// using namespace boost::math::policies; is small risk, but
// the necessary items are brought into scope thus:

using boost::math::binomial_distribution;
using boost::math::policies::policy;
using boost::math::policies::discrete_quantile;

using boost::math::policies::integer_round_outwards;
using boost::math::policies::integer_round_down;
using boost::math::policies::integer_round_up;
using boost::math::policies::integer_round_nearest;
using boost::math::policies::integer_round_inwards;
using boost::math::policies::real;

using boost::math::binomial_distribution; // Not std::binomial_distribution.

typedef binomial_distribution<
            double,
            policy<discrete_quantile<integer_round_outwards> > >
        binom_round_outwards;

typedef binomial_distribution<
            double,
            policy<discrete_quantile<integer_round_inwards> > >
        binom_round_inwards;

typedef binomial_distribution<
            double,
            policy<discrete_quantile<integer_round_down> > >
        binom_round_down;

typedef binomial_distribution<
            double,
            policy<discrete_quantile<integer_round_up> > >
        binom_round_up;

typedef binomial_distribution<
            double,
            policy<discrete_quantile<integer_round_nearest> > >
        binom_round_nearest;

typedef binomial_distribution<
            double,
            policy<discrete_quantile<real> > >
        binom_real_quantile;

现在让我们着手调用这些分位数:

int main()
{
   cout <<
      "Testing rounding policies for a 50 sample binomial distribution,\n"
      "with a success fraction of 0.5.\n\n"
      "Lower quantiles are calculated at p = 0.05\n\n"
      "Upper quantiles at p = 0.95.\n\n";

   cout << setw(25) << right
      << "Policy"<< setw(18) << right
      << "Lower Quantile" << setw(18) << right
      << "Upper Quantile" << endl;

   // Test integer_round_outwards:
   cout << setw(25) << right
      << "integer_round_outwards"
      << setw(18) << right
      << quantile(binom_round_outwards(50, 0.5), 0.05)
      << setw(18) << right
      << quantile(binom_round_outwards(50, 0.5), 0.95)
      << endl;

   // Test integer_round_inwards:
   cout << setw(25) << right
      << "integer_round_inwards"
      << setw(18) << right
      << quantile(binom_round_inwards(50, 0.5), 0.05)
      << setw(18) << right
      << quantile(binom_round_inwards(50, 0.5), 0.95)
      << endl;

   // Test integer_round_down:
   cout << setw(25) << right
      << "integer_round_down"
      << setw(18) << right
      << quantile(binom_round_down(50, 0.5), 0.05)
      << setw(18) << right
      << quantile(binom_round_down(50, 0.5), 0.95)
      << endl;

   // Test integer_round_up:
   cout << setw(25) << right
      << "integer_round_up"
      << setw(18) << right
      << quantile(binom_round_up(50, 0.5), 0.05)
      << setw(18) << right
      << quantile(binom_round_up(50, 0.5), 0.95)
      << endl;

   // Test integer_round_nearest:
   cout << setw(25) << right
      << "integer_round_nearest"
      << setw(18) << right
      << quantile(binom_round_nearest(50, 0.5), 0.05)
      << setw(18) << right
      << quantile(binom_round_nearest(50, 0.5), 0.95)
      << endl;

   // Test real:
   cout << setw(25) << right
      << "real"
      << setw(18) << right
      << quantile(binom_real_quantile(50, 0.5), 0.05)
      << setw(18) << right
      << quantile(binom_real_quantile(50, 0.5), 0.95)
      << endl;
} // int main()
