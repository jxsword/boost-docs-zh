估计二项分布的样本量.

设想你有一个关键部件, 你知道它每 N 次 "使用" 中会有 1 次失效 (对 "使用" 有某种合适的定义). 你可能想为该部件安排例行更换, 使其在两次例行更换之间发生失效的概率小于 P%. 如果失效服从二项分布 (每次部件被 "使用" 时要么失效要么不失效), 那么静态成员函数 binomial_distibution<>::find_maximum_number_of_trials 可用于估计该部件在某个可接受风险级别 alpha 下的最大 "使用" 次数.

示例程序 binomial_sample_sizes.cpp 演示了它的用法. 其核心是一个例程, 打印各种概率阈值下的最大样本量表:

void find_max_sample_size(
   double p,              // success ratio.
   unsigned successes)    // Total number of observed successes permitted.
{

该例程随后声明一个概率阈值表: 这些是观察到 successes 次或更少事件的最大可接受概率. 在我们的例子中, successes 总是零, 因为我们不希望任何部件失效; 但在其他情况下, 非零值可能很合理.

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

程序其余部分大多是美化输出, 重要的部分是对每个 alpha 值计算允许的最大试验次数:

for(unsigned i = 0; i < sizeof(alpha)/sizeof(alpha[0]); ++i)
{
   // Confidence value:
   cout << fixed << setprecision(3) << setw(10) << right << 100 * (1-alpha[i]);
   // calculate trials:
   double t = binomial::find_maximum_number_of_trials(
                  successes, p, alpha[i]);
   t = floor(t);
   // Print Trials:
   cout << fixed << setprecision(5) << setw(15) << right << t << endl;
}

注意, 由于我们计算的是允许的最大试验次数, 我们会偏于安全, 对结果向下取整. 假如我们计算的 最小 试验次数是为了观察到一定数目的 successes, 并且使用的是 find_minimum_number_of_trials, 那么就会改为向上取整.

最后我们来看一些示例输出, 首先是每次使用部件失效概率为千分之一的情况:
