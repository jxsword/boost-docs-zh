用 tanh-sinh 求积处理端点附近变化剧烈的函数

Tanh-sinh 求积有一个独特的特性, 使它非常适合处理在一个或两个端点附近有奇点或剧烈变化的积分: 事实证明, 当我们计算并存储将要求值函数的横坐标值时, 同样可以很好地计算横坐标值与最近端点之间的差. 这使得可以在任意接近端点处进行求积, 而不会遭受抵消误差. 但注意, 我们从未真正到达端点, 因此任何端点奇点总是被排除在求积之外.

tanh_sinh 积分例程在执行区间变换时会在内部使用这一附加信息, 因此例如, 当区间的一端为零 (或无穷) 时, 我们的变换可以任意接近端点而没有精度损失.

然而, 有些积分的全部面积可能靠近 两个端点, 或者靠近非零端点, 在这种情况下确实存在精度损失的风险. 例如:

tanh_sinh<double> integrator;
auto f = [](double x) { return sqrt(x / (1 - x * x); };
double Q = integrator.integrate(f, 0.0, 1.0);

结果精度非常低, 因为积分的全部面积都靠近 1, 且 1 - x * x 项在这里遭受抵消误差.

然而, tanh_sinh 的两个积分例程都会自动处理双参数函子: 此时第一个参数仍为横坐标值, 第二个参数是到最近端点的距离, 即在 (a,b) 上积分时的 a - x 或 b - x. 你总能区分这两种情形, 因为当我们更靠近左端点时第二个参数为负.

了解这一点后, 我们可以改写 lambda 表达式以利用这一附加信息:

tanh_sinh<double> integrator;
auto f = [](double x, double xc) { return x <= 0.5 ? sqrt(x) / sqrt(1 - x * x) : sqrt(x / ((x + 1) * (xc))); };
double Q = integrator.integrate(f, 0.0, 1.0);

这种形式不仅精确到完整的机器精度, 而且收敛到结果的速度也更快.
