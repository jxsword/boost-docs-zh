最小宽度浮点 typedef

typedef float_least#_t (其中 # 为宽度) 指定一个 宽度至少为 # 位的浮点类型, 且不存在尺寸更小却至少具有该指定宽度的浮点类型. 因此, float_least32_t 表示宽度至少 32 位的最小浮点类型.

对给定平台上所有现有的精确宽度浮点类型, 都提供了对应的最小宽度浮点类型.

例如, 若平台支持 float32_t 与 float64_t, 那么 float_least32_t 与 float_least64_t 也将受支持, 等等.
