求 Airy 函数的零点

概要

#include <boost/math/special_functions/airy.hpp>

这些函数既可以获取 Airy 函数的单个零点(根),也可以通过提供输出迭代器将多个零点放入 std::vector 之类的容器.

单值函数的签名为:

template <class T>
BOOST_MATH_GPU_ENABLED T airy_ai_zero(
         int m);         // 1-based index of zero.

template <class T>
BOOST_MATH_GPU_ENABLED T airy_bi_zero(
         int m);         // 1-based index of zero.

多个零点的签名为:

template <class T, class OutputIterator>
BOOST_MATH_GPU_ENABLED OutputIterator airy_ai_zero(
                     int start_index,           // 1-based index of first zero.
                     unsigned number_of_zeros,  // How many zeros to generate.
                     OutputIterator out_it);    // Destination for zeros.

template <class T, class OutputIterator>
BOOST_MATH_GPU_ENABLED OutputIterator airy_bi_zero(
                     int start_index,           // 1-based index of zero.
                     unsigned number_of_zeros,  // How many zeros to generate
                     OutputIterator out_it);    // Destination for zeros.

还有允许控制错误处理与精度 Policies 的版本.

 template <class T>
 BOOST_MATH_GPU_ENABLED T airy_ai_zero(
          int m,          // 1-based index of zero.
          const Policy&); // Policy to use.

 template <class T>
 BOOST_MATH_GPU_ENABLED T airy_bi_zero(
          int m,          // 1-based index of zero.
          const Policy&); // Policy to use.


template <class T, class OutputIterator>
BOOST_MATH_GPU_ENABLED OutputIterator airy_ai_zero(
                     int start_index,           // 1-based index of first zero.
                     unsigned number_of_zeros,  // How many zeros to generate.
                     OutputIterator out_it,     // Destination for zeros.
                     const Policy& pol);        // Policy to use.

template <class T, class OutputIterator>
BOOST_MATH_GPU_ENABLED OutputIterator airy_bi_zero(
                     int start_index,           // 1-based index of zero.
                     unsigned number_of_zeros,  // How many zeros to generate.
                     OutputIterator out_it,     // Destination for zeros.
                     const Policy& pol);        // Policy to use.
说明

Airy Ai 与 Bi 函数在负实轴上有无穷多个零点. 负实轴上的实零点可以通过求解以下方程的根得到:

Ai(xm) = 0

Bi(ym) = 0

这里,xm 表示 Airy Ai 函数的 mth 个根,ym 表示 Airy Bi 函数的 mth 个根.

Airy Ai 与 Bi 函数的零点(根)——即 x 的值,函数在这些值处穿过水平 y = 0 轴——由两个函数计算:airy_ai_zero 和 airy_bi_zero.

每种情况下返回的零点的索引(序号)都从 1 开始计数,即:

airy_ai_zero(1);

返回 Ai 的第一个零点.

传入 start_index <= 0 将引发 domain_error.

这些函数返回的前几个零点的近似值如下:

求 Airy 零点的示例

本示例演示如何计算 Airy 函数的零点. 它还展示了如何组合 Boost.Math 与 Boost.Multiprecision 以提供多位十进制精度. 要获得 50 位十进制精度,需要包含

#include <boost/multiprecision/cpp_dec_float.hpp>

以及一个 typedef(针对 float_type)可能更方便(允许快速切换以按内建 double 或其他精度重新计算)

typedef boost::multiprecision::cpp_dec_float_50 float_type;

要使用这些求函数零点的函数,我们需要

#include <boost/math/special_functions/airy.hpp>

本示例展示如何获取 Airy 函数的单个零点,以及随后通过提供迭代器将多个零点放入 std::vector 之类的容器. 单值 Airy Ai 函数的签名为:

template <class T>
T airy_ai_zero(unsigned m); // 1-based index of the zero.

多零点 Airy Ai 函数的签名为:

template <class T, class OutputIterator>
OutputIterator airy_ai_zero(
                         unsigned start_index, // 1-based index of the zero.
                         unsigned number_of_zeros, // How many zeros to generate.
                         OutputIterator out_it); // Destination for zeros.

还有允许控制错误处理与精度 Policies 的版本.

template <class T, class OutputIterator, class Policy>
OutputIterator airy_ai_zero(
                         unsigned start_index, // 1-based index of the zero.
                         unsigned number_of_zeros, // How many zeros to generate.
                         OutputIterator out_it, // Destination for zeros.
                         const Policy& pol);  // Policy to use.
提示

将使用 Boost.Math 的代码放入 try'n'catch 块中总是明智的;这可以确保在出现异常情况时显示有用的错误消息.

首先,求单个 Airy 零点.

精度由模板参数 T 控制,因此本示例具有 double 精度,即至少 15 位、至多 17 位十进制数字(对于常见的 64 位 double).

double aiz1 = boost::math::airy_ai_zero<double>(1);
std::cout << "boost::math::airy_ai_zero<double>(1) = " << aiz1 << std::endl;
double aiz2 = boost::math::airy_ai_zero<double>(2);
std::cout << "boost::math::airy_ai_zero<double>(2) = " << aiz2 << std::endl;
double biz3 = boost::math::airy_bi_zero<double>(3);
std::cout << "boost::math::airy_bi_zero<double>(3) = " << biz3 << std::endl;

airy_ai_zero 和 airy_bi_zero 的其他版本允许一次调用计算多个零点,并将结果放入容器中,通常是 std::vector. 例如,生成并显示前五个 double 根 Wolfram Airy Functions Zeros.

unsigned int n_roots = 5U;
std::vector<double> roots;
boost::math::airy_ai_zero<double>(1U, n_roots, std::back_inserter(roots));
std::cout << "airy_ai_zeros:" << std::endl;
std::copy(roots.begin(),
          roots.end(),
          std::ostream_iterator<double>(std::cout, "\n"));

Ai(x) 的前几个实根约为 -2.33811, -4.08795, -5.52056, -6.7867144, -7.94413, -9.02265 ...

或者,我们可以使用 Boost.Multiprecision 生成 50 位十进制数字的根.

我们设置输出流的精度,并显示末尾的零以展示固定的 50 位十进制数字.

std::cout.precision(std::numeric_limits<float_type>::digits10); // float_type has 50 decimal digits.
std::cout << std::showpoint << std::endl; // Show trailing zeros too.

unsigned int m = 1U;
float_type r = boost::math::airy_ai_zero<float_type>(1U); // 1st root.
std::cout << "boost::math::airy_bi_zero<float_type>(" << m << ")  = " << r << std::endl;
m = 2;
r = boost::math::airy_ai_zero<float_type>(2U); // 2nd root.
std::cout << "boost::math::airy_bi_zero<float_type>(" << m << ")  = " << r << std::endl;
m = 7U;
r = boost::math::airy_bi_zero<float_type>(7U); // 7th root.
std::cout << "boost::math::airy_bi_zero<float_type>(" << m << ")  = " << r << std::endl;

std::vector<float_type> zeros;
boost::math::airy_ai_zero<float_type>(1U, 3, std::back_inserter(zeros));
std::cout << "airy_ai_zeros:" << std::endl;
// Print the roots to the output stream.
std::copy(zeros.begin(), zeros.end(),
          std::ostream_iterator<float_type>(std::cout, "\n"));
