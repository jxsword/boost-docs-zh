逆高斯 (或逆正态) 分布 

#include <boost/math/distributions/inverse_gaussian.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class inverse_gaussian_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;

   BOOST_MATH_GPU_ENABLED inverse_gaussian_distribution(RealType mean = 1, RealType scale = 1);

   BOOST_MATH_GPU_ENABLED RealType mean()const; // mean default 1.
   BOOST_MATH_GPU_ENABLED RealType scale()const; // Optional scale, default 1 (unscaled).
   BOOST_MATH_GPU_ENABLED RealType shape()const; // Shape = scale/mean.
};
typedef inverse_gaussian_distribution<double> inverse_gaussian;

}} // namespace boost // namespace math

逆高斯分布是一种连续概率分布.

该分布也称为 'normal-inverse Gaussian distribution', 以及 'normal Inverse' 分布.

为均值和尺度都提供默认值 1 也是方便的. 这是所有分布的标准形式. 逆高斯分布最初是在研究布朗运动时被研究的. 1956 年 M.C.K. Tweedie 使用了逆高斯这个名称, 因为覆盖单位距离所需的时间与单位时间内覆盖的距离之间存在反比关系. 逆高斯分布属于被称为 Tweedie 分布 的一族分布.

(所以名称中的 inverse 可能引起误导: 它 并不 表示分布的逆).

该分布的尾部比正态分布下降得更慢. 因此它适合对数值上的大值比正态分布情形更可能出现的现象建模. 对于股票市场收益与价格, 一个关键特征是它能刻画: 即使几乎所有的 (正态) 波动都很小, 也可能出现偏离典型值的极大波动 (崩盘).

例如金融资产的收益与湍流风速.

正态逆高斯分布构成广义双曲分布的一个子类.

参见 分布. Weisstein, Eric W. "Inverse Gaussian Distribution." From MathWorld--A Wolfram Web Resource.

如果你想要一个 double 精度的 inverse_gaussian 分布, 可以使用

boost::math::inverse_gaussian_distribution<>

或者, 更方便地, 可以写

using boost::math::inverse_gaussian;
inverse_gaussian my_ig(2, 3);

对于均值参数 μ 与尺度 (也称精度) 参数 λ, 以及随机变量 x, inverse_gaussian 分布由概率密度函数 (PDF) 定义:

f(x;μ, λ) = √(λ/2πx3) e-λ(x-μ)²/2μ²x

以及累积分布函数 (CDF):

F(x;μ, λ) = Φ{√(λx) (xμ-1)} + e2μ/λ Φ{-√(λ/μ) (1+x/μ)}

其中 Φ 是标准正态分布的 CDF.

Tweedie 还给出了另外 3 种参数化, 其中 (μ 与 λ) 被替换为它们的比值 φ = λ/μ 和 1/μ: 这些形式可能更适合贝叶斯应用. 这些内容可在 Seshadri 第 2 页找到, Chhikara 与 Folks 也在第 105 页进行了讨论. 还提供了另一种相关的参数化 __wald_distrib (其中均值 μ 为 1).

成员函数 
BOOST_MATH_GPU_ENABLED inverse_gaussian_distribution(RealType df = 1, RealType scale = 1); // optionally scaled.

构造一个均值为 μ、尺度为 λ 的 inverse_gaussian 分布, 两者的默认值都是 1.

要求均值 μ 参数与尺度 λ 都大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType mean()const;

返回此分布的均值 μ 参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的尺度 λ 参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [0,+∞).

注释

与某些定义不同, 本实现把随机变量等于零作为一种特殊情况支持, 此时 pdf 与 cdf 都返回零.

在此分布中, logpdf 的实现经过专门化, 以提高数值精度.

精度

inverse_gaussian 分布借助指数函数与标准正态分布 N0,1 Φ 实现: 更多信息请参见这些函数的精度数据. 但一般来说, gamma (因而逆 gamma) 的结果常精确到几个 epsilon, 对于 64 位 double 精度超过 14 位十进制数字.
