颜色映射

概要 
#include <boost/math/tools/color_maps.hpp>

namespace boost::math::tools {

template<typename Real>
std::array<Real, 3> viridis(Real x);

template<typename Real>
std::array<Real, 3> plasma(Real x);

template<typename Real>
std::array<Real, 3> black_body(Real x);

template<typename Real>
std::array<Real, 3> inferno(Real x);

template<typename Real>
std::array<Real, 3> smooth_cool_warm(Real x);

template<typename Real>
std::array<Real, 3> kindlmann(Real x);

template<typename Real>
std::array<Real, 3> extended_kindlmann(Real x);

template<typename Real>
std::array<uint8_t, 4> to_8bit_rgba(std::array<Real, 3> const & color);

} // namespaces
说明

抽象地说, 颜色映射是任何把 [0, 1] 映射到 [0, 1]^3 的函数. 如上所述, 这个定义过于宽泛而没有实用价值, 因此在 Boost 中我们只关注对理解科学数据有用的那部分颜色映射. 大量研究 表明, 各种颜色映射在解读定量数据时的有用程度差异极大; 详见 here. 此外, 不同的颜色映射适用于不同的场景. 例如, smooth_cool_warm 颜色映射适合考察嵌入三维空间且其上定义了标量场的曲面, 而 inferno 颜色映射更适合理解二维数据.

尽管按我们的定义, 颜色映射的定义域是 [0, 1], 但如果提供的值落在这个范围之外, 我们并不抛出异常. 原因有两点: 第一, 可视化本身就是极好的调试工具, 如果抛出异常, 计算就无法完成, 也就无法进行可视化调试. 第二, 浮点舍入的微小变化常常会使提供的值仅略低于零, 或仅略高于 1. 因此, 在向颜色表插值之前, 我们会先调用 std::clamp.
