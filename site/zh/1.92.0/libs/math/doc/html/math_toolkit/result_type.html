结果类型的计算

本库中的函数全部重载以接受混合浮点 (或整数与浮点混合) 参数. 因此例如:

foo(1.0, 2.0);
foo(1.0f, 2);
foo(1.0, 2L);

等等都是有效调用, 只要 "foo" 是接受两个浮点参数的函数. 但这留下一个问题:

"给定一个有 N 个参数、类型为 T1, T2, T3 ... TN 的特殊函数, 结果是什么类型?"

如果所有参数都是相同的 (浮点) 类型, 那么结果与参数类型相同.

否则, 结果类型按以下逻辑计算:

  1. 任何非模板参数的参数从后续分析中排除.
  2. 对参数列表中的每个类型, 如果该类型是整数类型, 则在后续分析中把它当作 double 类型处理.
  3. 如果任何参数是用户定义的类类型, 则结果类型是第一个可以从所有其他参数类型构造的此类类型.
  4. 如果任何参数的类型是 long double, 则结果类型为 long double.
  5. 如果任何参数的类型是 double, 则结果类型为 double.
  6. 否则结果类型为 float.

例如:

cyl_bessel(2, 3.0);

返回一个 double 结果, 如同:

cyl_bessel(2, 3.0f);

因为在这种情况下, 整数第一参数被当作 double 处理, 并优先于 float 第二参数. 要得到 float 结果, 我们需要所有参数都是 float 类型:

cyl_bessel_j(2.0f, 3.0f);

当一个或多个参数不是模板参数时, 它完全不影响返回类型, 例如:

sph_bessel(2, 3.0f);

返回一个 float, 因为第一个参数不是模板参数, 因而不影响结果: 没有这条规则, 接受显式整数参数的函数将永远无法返回 float.

而对于用户定义类型, 通常是 Boost.Multiprecision,

以下所有调用都返回一个 boost::multiprecision::cpp_bin_quad_float 结果:

cyl_bessel_j(0, boost::multiprecision::cpp_bin_quad_float(2));

cyl_bessel_j(boost::multiprecision::cpp_bin_quad_float(2), 3);

cyl_bessel_j(boost::multiprecision::cpp_bin_quad_float(2), boost::multiprecision::cpp_bin_quad_float(3));

但依赖于所提供的参数恰好可表示, 从而避免从 double 构造时的精度损失.

提示

所有新项目都应使用 Boost.Multiprecision.

在 Boost.Math 的开发过程中, NTL A Library for doing Number Theory 对创建高精度表格来说是无价的.

以下所有调用都返回一个 NTL::RR 结果:

cyl_bessel_j(0, NTL::RR(2));

cyl_bessel_j(NTL::RR(2), 3);

cyl_bessel_j(NTL::quad_float(2), NTL::RR(3));

在最后一种情形中, quad_float 可转换为 RR, 但反之不行, 因此结果将是一个 NTL::RR. 注意, 这假定你使用的是 patched NTL library.

这些规则的选择是为了与 ISO/IEC 9899:1999 Programming languages - C 的行为以及 Draft Technical Report on C++ Library Extensions, 2005-06-24, section 5.2.1, paragraph 5 保持兼容.
