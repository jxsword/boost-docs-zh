简单连分数 

#include <boost/math/tools/simple_continued_fraction.hpp>
namespace boost::math::tools {

template<typename Real, typename Z = int64_t>
class simple_continued_fraction {
public:
    simple_continued_fraction(Real x);

    Real khinchin_geometric_mean() const;

    Real khinchin_harmonic_mean() const;

    template<typename T, typename Z_>
    friend std::ostream& operator<<(std::ostream& out, simple_continued_fraction<T, Z>& scf);
};
}

Boost 提供的 simple_continued_fraction 类可以将浮点数转换为简单连分数. 此外, 借助这种表示, 我们可以对相应的数回答一些问题.

下面是一个最小可运行示例:

using boost::math::constants::pi;
using boost::math::tools::simple_continued_fraction;
auto cfrac = simple_continued_fraction(pi<long double>());
std::cout << "π ≈ " << cfrac << "\n";
// Prints:
// π ≈ [3; 7, 15, 1, 292, 1, 1, 1, 2, 1, 3, 1, 14, 2, 1, 1, 2]

该类在使用改进的 Lentz 算法计算收敛项的同时计算部分分母. 一旦某个收敛项与输入值相差不超过几个 ulps, 计算即停止.

注意, 每个浮点数都是有理数, 而这个精确的有理数可以精确地转换为有限连分数. 这完全是合理的行为, 但我们在这里并不这样做. 这是因为在考察像 π 这样的已知值时, 即使二进制表示的每一位都正确, 它也会产生大量不正确的部分分母.

少数不正确的部分收敛项可能是无害的, 但我们计算连分数是因为想用它做点什么. 一件合理的事情是问这个数在某种意义上是否“随机”; 这个问题可以通过计算 Khinchin 几何平均来部分回答

以及 Khinchin 调和平均

如果在部分分母的个数趋于无穷时它们逼近 Khinchin 常数 K0 和 K-1, 那么这个数在该刻画下就是“没有特别之处”的. 如果展开式中包含太多不正确的部分分母, 这些违背就会被掩盖掉.

注意: 这些平均收敛到 Khinchin 极限的速度极其缓慢; 我们用了 π 的 30,000 位十进制数字, 结果与 K0 只有两位数字相符. 不过, 明显的违背是很显然的, 例如 √2 的连分数展开, 其 Khinchin 几何平均恰好为 2.
