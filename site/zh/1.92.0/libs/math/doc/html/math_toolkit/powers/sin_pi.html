sin_pi 

#include <boost/math/special_functions/sin_pi.hpp>

namespace boost{ namespace math{

template <class T>
calculated-result-type sin_pi(T x);

template <class T, class Policy>
calculated-result-type sin_pi(T x, const Policy&);

}} // namespaces

返回 π x 的正弦.

该函数的返回类型按 结果类型计算规则 确定: 返回 double, 条件是 x 为整数类型, 否则返回 T.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

该函数在计算 π⋅x 的正弦之前执行精确的全整数算术参数归约.
