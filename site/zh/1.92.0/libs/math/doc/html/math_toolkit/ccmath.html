Constexpr CMath

说明

对 Constexpr 和 <cmath> 中<cstdlib> 提案给 C++23 的功能提供 实现. 在 constexpr 语境下, 这些函数将使用 boost 中定义的实现. 若语境不是 constexpr, 则功能直接来自编译器所用 <cmath> 的 STL 实现. 所有接受 Integer 类型并返回 double 的函数只是把 Integer 实参转换为 double. 以下所有函数都要求 C++17 或更高版本.

概要 

#include <boost/math/ccmath/ccmath.hpp>

namespace boost::math::ccmath {

    inline constexpr int abs(T x);

    inline constexpr Real ldexp(Real arg, int exp);
