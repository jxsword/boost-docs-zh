估计负二项分布的样本量.

设想你有一个事件 (姑且称之为 "失败"——不过如果我们认为它是 '好' 事件, 也完全可以称之为成功), 你知道它在 N 次试验中会发生 1 次. 你可能想知道需要进行多少次试验, 才能有 P% 的把握观察到至少 k 次这样的失败. 如果失败事件服从负二项分布 (每次试验要么成功要么失败), 那么静态成员函数 negative_binomial_distibution<>::find_minimum_number_of_trials 可用于估计为以 P% 的把握观察到期望的失败次数所需的最小试验次数.

示例程序 neg_binomial_sample_sizes.cpp 演示了它的用法.

其核心是一个例程, 打印各种概率阈值下的最小样本量 (试验次数) 表:

void find_number_of_trials(double failures, double p);

首先定义一个显著性水平表: 这些是观察到 failure 次或更少事件的最大可接受概率.

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

以百分比表示的置信值为 (1 - alpha) * 100, 因此 alpha 0.05 == 观察到期望失败次数的 95% 置信度. 这些值从非常低的 0.5 (50% 置信度) 一直到极高的 99.999.

程序其余部分大多是美化输出, 重要的部分是使用如下代码为每个 alpha 值计算所需的最小试验次数:

(int)ceil(negative_binomial::find_minimum_number_of_trials(failures, p, alpha[i]);

find_minimum_number_of_trials 返回一个 double, 因此 ceil 把它向上取整, 以确保我们得到整数的最小试验次数.

void find_number_of_trials(double failures, double p)
{
   // trials = number of trials
   // failures = number of failures before achieving required success(es).
   // p        = success fraction (0 <= p <= 1.).
   //
   // Calculate how many trials we need to ensure the
   // required number of failures DOES exceed "failures".

  cout << "\n""Target number of failures = " << (int)failures;
  cout << ",   Success fraction = " << fixed << setprecision(1) << 100 * p << "%" << endl;
   // Print table header:
   cout << "____________________________\n"
           "Confidence        Min Number\n"
           " Value (%)        Of Trials \n"
           "____________________________\n";
   // Now print out the data for the alpha table values.
  for(unsigned i = 0; i < sizeof(alpha)/sizeof(alpha[0]); ++i)
   { // Confidence values %:
      cout << fixed << setprecision(3) << setw(10) << right << 100 * (1-alpha[i]) << "      "
      // find_minimum_number_of_trials
      << setw(6) << right
      << (int)ceil(negative_binomial::find_minimum_number_of_trials(failures, p, alpha[i]))
      << endl;
   }
   cout << endl;
} // void find_number_of_trials(double failures, double p)

最后, 我们可以为所选置信水平生成一些最小试验次数表:

int main()
{
    find_number_of_trials(5, 0.5);
    find_number_of_trials(50, 0.5);
    find_number_of_trials(500, 0.5);
    find_number_of_trials(50, 0.1);
    find_number_of_trials(500, 0.1);
    find_number_of_trials(5, 0.9);

    return 0;
} // int main()
注释

由于我们计算的是所需的 最小 试验次数, 我们会偏于安全, 对结果向上取整. 假如我们计算的是观察少于一定次数 failures 所允许的 最大 试验次数, 那么就会改为向下取整. 我们也会这样调用 find_minimum_number_of_trials:

floor(negative_binomial::find_minimum_number_of_trials(failures, p, alpha[i]))

这会给出我们所能进行的最多次数试验, 同时在成功概率为 p 时, 仍有 P% 的把握观察到 failures or less 次失败事件.

最后我们来看一些示例输出. 首先, 假设我们希望观察至少 5 次 "失败", 成功与失败的概率各为 50% (0.5):

Target number of failures = 5,   Success fraction = 50%

____________________________
Confidence        Min Number
 Value (%)        Of Trials
____________________________
    50.000          11
    75.000          14
    90.000          17
    95.000          18
    99.000          22
    99.900          27
    99.990          31
    99.999          36

因此 18 次或更多试验将有 95% 的概率观察到至少我们所需的 5 次失败.

把它与成功率为 90% 时的情形比较:

Target number of failures = 5.000,   Success fraction = 90.000%

____________________________
Confidence        Min Number
 Value (%)        Of Trials
____________________________
    50.000          57
    75.000          73
    90.000          91
    95.000         103
    99.000         127
    99.900         159
    99.990         189
    99.999         217

因此现在需要 103 次试验, 才能以 95% 的把握观察到至少 5 次失败.
