导航

Boost.Math 文档提供 HTML 和 PDF 两种格式.

  • 教程列于 目录中, 并包含许多应能帮助你快速上手的示例.
  • 众多 示例的源代码 (见各 示例) 往往是你最快的起点.
  • 索引 (通用索引) 包含全部条目.
  • 特定索引只列出函数、类签名、宏和 typedef.
使用索引

主索引通常很有帮助, 尤其当你知道一个描述其功能的词、而无需知道函数选定的确切名称时.

提示

使用索引时请记住: 点击索引条目只会带你到包含该索引条目的 章节. 该章节可能长达数页, 所以你可能需要使用浏览器或 PDF 阅读器的 查找功能来定位索引条目本身.

提示

PDF 阅读器通常支持 全局查找; 如果你期望被索引的术语不是作者选定的那个, 这会非常有用. 你可能会发现, 在 PDF 版本中搜索、同时在 HTML 版本中查看, 能找到难以捉摸的条目.
