累积分布函数 
template <class RealType, class Policy>
RealType cdf(const Distribution-Type<RealType, Policy>& dist, const RealType& x);

累积分布函数是变量取值小于或等于 x 的概率. 它等价于 概率密度函数 从 -infinity 到 x 的积分.

若随机变量在分布的定义范围之外, 此函数可能返回 domain_error.

累积分布函数的补 
template <class Distribution, class RealType>
RealType cdf(const Unspecified-Complement-Type<Distribution, RealType>& comp);

累积分布函数的补是变量取值大于 x 的概率. 它等价于 概率密度函数 从 x 到无穷的积分, 或 1 减去 x 处的 累积分布函数.

这也称为生存函数.

若随机变量在分布的定义范围之外, 此函数可能返回 domain_error.

在本库中, 通过把 cdf 函数的参数包装在 complement 调用中来获得, 例如:

// standard normal distribution object:
boost::math::normal norm;
// print survival function for x=2.0:
std::cout << cdf(complement(norm, 2.0)) << std::endl;

概率密度函数 
template <class RealType, class Policy>
RealType pdf(const Distribution-Type<RealType, Policy>& dist, const RealType& x);

对于连续函数, 概率密度函数 (pdf) 返回变量取值为 x 的概率. 由于对连续分布而言单点处的概率实际上为零, 该概率更适合表示为 pdf 在两点之间的积分: 参见 累积分布函数.

对于离散分布, pdf 是变量取值为 x 的概率.

分位数 
template <class RealType, class Policy>
RealType quantile(const Distribution-Type<RealType, Policy>& dist, const RealType& p);

分位数最好理解为 累积分布函数 的反函数, 它返回一个值 x 使得 cdf(dist, x) == p.

这也称为 百分位点函数、百分位数 或 分位数点, 它也与计算分布的 下临界值 相同.

若概率在 [0,1] 之外, 此函数返回 domain_error. 若不存在具有指定概率的有限值, 该函数可能返回 overflow_error.

下图展示了标准正态分布的分位数函数:

概率之补的分位数.

另见 补集.

template <class Distribution, class RealType>
RealType quantile(const Unspecified-Complement-Type<Distribution, RealType>& comp);

这是 累积分布函数的补 的反函数. 它通过把分位数函数的参数包装在 complement 调用中来计算. 例如:

// define a standard normal distribution:
boost::math::normal norm;
// print the value of x for which the complement
// of the probability is 0.05:
std::cout << quantile(complement(norm, 0.05)) << std::endl;

该函数计算一个值 x 使得 cdf(complement(dist, x)) == q, 其中 q 是概率的补.

为何使用补集?

此函数也称为反生存函数, 与计算分布的 上临界值 相同.

若概率在 [0,1] 之外, 此函数返回 domain_error. 若不存在具有指定概率的有限值, 该函数可能返回 overflow_error.

支持域 
template<class RealType, class Policy>
std::pair<RealType, RealType> support(const Distribution-Type<RealType, Policy>& dist);

返回分布 dist 上随机变量的支持范围.

当分布位于 "其补集概率为零的最小闭集" 上时, 称该分布在此范围上被"支持". 非数学专业者可以理解为: 随机变量 x 的 cdf 从零到 1 的"有意义"的最小范围. 在此之外是 pdf 为零、cdf 为零或 1 的无意义区域.

峰度 
template <class RealType, class Policy>
RealType kurtosis(const Distribution-Type<RealType, Policy>& dist);

返回分布 dist 的"正规"峰度 (归一化四阶矩).

kurtosis = β2= μ4 / μ22

其中 μi 是分布的 i 阶中心矩, 特别地 μ2 是分布的方差.

峰度是分布"尖峰程度"的度量.

注意文献中峰度的定义很混乱. 这里采用的定义与 Wolfram MathWorld 等所用的一致 (其中包含各种分布超额峰度的公式表), 但与 Wikipedia 使用的峰度定义不同, 后者把"kurtosis"与"kurtosis excess"视为同一个量.

kurtosis_excess = 'proper' kurtosis - 3

减去 3 很方便, 这样正态分布的 超额峰度 为零.

若分布没有定义的峰度, 此函数可能返回 domain_error.

"正规"峰度的取值可以从 0 到 + infinity.

超额峰度 
template <class RealType, Policy>
RealType kurtosis_excess(const Distribution-Type<RealType, Policy>& dist);

返回分布 dist 的超额峰度.

kurtosis excess = γ2= μ4 / μ22- 3 = kurtosis - 3

其中 μi 是分布的 i 阶中心矩, 特别地 μ2 是分布的方差.

超额峰度是分布"尖峰程度"的度量, 比"正规峰度"使用更广泛. 其定义为使正态分布的超额峰度为零.

若分布没有定义的超额峰度, 此函数可能返回 domain_error.

超额峰度的取值可以从 -2 到 + infinity.

kurtosis = kurtosis_excess +3;

正态分布的超额峰度为零.

P 与 Q

术语 P 与 Q 有时分别用来指代 累积分布函数 及其 补集. 小写 p 与 q 有时用来指代这些函数返回的值.

百分位点函数或百分位数

百分位点函数, 也称百分位数, 与 分位数相同.

反 CDF 函数.

累积分布函数的反函数, 与 分位数相同.

反生存函数.

生存函数的反函数, 与计算 概率之补的分位数相同.

概率质量函数

概率质量函数与 概率密度函数相同.

术语"质量函数"通常用于离散分布, 而 概率密度函数 用于连续分布.

下临界值.

下临界值根据分布左尾下的面积计算随机变量的值. 它等价于计算 分位数.

上临界值.

上临界值根据分布右尾下的面积计算随机变量的值. 它等价于计算 概率之补的分位数.

参见 累积分布函数的补.
