Log Gamma

概要 
#include <boost/math/special_functions/gamma.hpp>

namespace boost{ namespace math{

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type lgamma(T z);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type lgamma(T z, const Policy&);

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type lgamma(T z, int* sign);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type lgamma(T z, int* sign, const Policy&);

}} // namespaces

该函数的第二种形式接受一个指向整数的指针: 如果该指针非空, 输出时会被设置为 tgamma(z) 的符号.

这些函数的返回类型使用 结果类型计算规则 计算: 当 T 是整数类型时, 结果类型为 double; 否则为类型 T.

当 z 非常接近 1 或 2 时, Lanczos approximation 的对数版本会遭受非常严重的抵消误差: 实际上, 对于足够接近 1 或 2 的值, 可能得到任意大的相对误差 (即使绝对误差极小).

对于精度最高到 113 位 (最高到且包括 128 位 long double) 的类型, 在区间 [1,2] 和 [2,3] 上使用 由 JM 设计 的保持根位置的有理近似. 在区间 [2,3] 上, 所用近似形式为:

lgamma(z) = (z-2)(z+1)(Y + R(z-2));

其中 Y 是常量, R(z-2) 是有理近似: 经过优化, 其绝对误差与 Y 相比极小. 此外, 大于 3 的较小的 z 值可以使用递推关系通过参数归约来处理:

lgamma(z+1) = log(z) + lgamma(z);

在区间 [1,2] 上必须使用两个近似, 其中针对较小 z 的一个使用:

lgamma(z) = (z-1)(z-2)(Y + R(z-1));

同样, Y 是常量, R(z-1) 针对与 Y 相比的低绝对误差做了优化. 对于 z > 1.5, 上面的形式不会收敛到极小极大解, 但下面这个类似的形式可以:

lgamma(z) = (2-z)(1-z)(Y + R(2-z));

最后, 对于 z < 1, 可以使用递推关系移动到 z > 1:

lgamma(z) = lgamma(z+1) - log(z);

注意, 虽然这里涉及一次减法, 但它似乎不受抵消误差影响: 当 z 从 1 逐渐减小时, -log(z) 项变为正数的速度远快于 lgamma(z+1) 项变为负数的速度. 因此在这个特定情形中, 有效数字得以保留而非被抵消.
