微步进 / 不收敛

考虑在此情形下从 z0 出发:

一阶导数基本上是无穷大, 而二阶导数接近零 (因此即使使用它也无法提供修正), 结果我们迈出的第一步非常小. 在最坏的情况下, 第一步小到 - 甚至可能小到从 z0 中减去它在当前工作精度下毫无影响 - 以致我们的算法会认为已经到达根并终止. 否则我们会迈出大量永远不会收敛到根的极小步: 我们的算法会通过回退到二分法来防范这种情况.

这种情况的一个例子是尝试求 e-1/z2 的根 - 此函数仅在 z = 0 处有一个根, 但当 z0 < 0 时, 牛顿步和 Halley 步都永远不会收敛到根; 而当 z0 > 0 时, 这些步实际上是发散的.
