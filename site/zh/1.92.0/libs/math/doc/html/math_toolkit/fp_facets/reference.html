刻面 nonfinite_num_put 
template<
  class CharType, class OutputIterator = std::ostreambuf_iterator<CharType>
        >
class nonfinite_num_put;

class nonfinite_num_put<CharType, OutputIterator> 派生自 std::num_put<CharType, OutputIterator>. 因此它是一个格式化数字的刻面. 第一个模板参数是格式化字符串的字符类型, 通常是 char 或 wchar_t. 第二个模板参数是用于写出字符串的迭代器类型, 必须是输出迭代器. 通常使用默认的 std::ostreambuf_iterator. 该类的公有接口只有一个构造函数:

nonfinite_num_put(int flags = 0);

flags 参数 (实际上是可选的, 因为提供了默认值 no_flags) 将在下面讨论. 类模板 nonfinite_num_put 定义在头文件 boost/math/nonfinite_num_facets.hpp 中, 位于命名空间 boost::math.

与 C++ 标准刻面 std::num_put 不同, 刻面 nonfinite_num_put 以一致且可移植的方式格式化 infinity 与 NaN. 它使用以下字符串表示:

Number

字符串

正无穷大

inf

正 NaN

nan

负无穷大

-inf

负 NaN

-nan

数字的类型可以是 float、double 与 long double. 字符串可以全小写或全大写. 正数可以带可选的 + 号. 这可以用 uppercase、lowercase、showpos 与 noshowpos 操纵器控制. 整数、布尔值与有限浮点数的格式化被简单地委托给普通的 std::num_put.

刻面 nonfinite_num_get 
template<class CharType, class InputIterator = std::istreambuf_iterator<CharType> > class nonfinite_num_get;

类 nonfinite_num_get<CharType, InputIterator> 派生自 std::num_get<CharType, IntputIterator>. 因此它是一个解析表示数字的字符串的刻面. 第一个模板参数是字符串的字符类型, 通常是 char 或 wchar_t. 第二个模板参数是用于读取字符串的迭代器类型, 必须是输入迭代器. 通常使用默认值. 该类的公有接口只有一个构造函数:

nonfinite_num_get(int flags = 0);

flags 参数将在下面讨论. class template nonfinite_num_get 定义在头文件 boost/math/nonfinite_num_facets.hpp 中, 位于 namespace boost::math.

与刻面 std::num_get 不同, 刻面 nonfinite_num_get 以一致且可移植的方式解析表示 infinity 与 NaN 的字符串. 它精确识别 C99 标准规定的字符串表示:

Number

字符串

正无穷大

inf, infinity

正 NaN

nan, nan(...)

负无穷大

-inf, -infinity

负 NaN

-nan, -nan(...)

数字的类型可以是 float、double 与 long double. 该刻面不区分大小写. 正数可以带可选的 + 号. nan(...) 中的点号代表任意字符串, 通常包含 NaN 载荷. 表示整数、布尔值与有限浮点数的字符串的解析被委托给 std::num_get.

当刻面在不支持 infinity 的平台上解析表示 infinity 的字符串时, 会设置流的 fail 位.

当刻面在不支持 NaN 的平台上解析表示 NaN 的字符串时, 会设置流的 fail 位.

标志

nonfinite_num_put 与 nonfinite_num_get 的构造函数接受一个可选的位标志参数. 有四个不同的位标志:

  • legacy
  • signed_zero
  • trap_infinity
  • trap_nan

这些标志可以用 OR operator| 组合.

这些标志定义在头文件 boost/math/nonfinite_num_facets.hpp 中, 位于 namespace boost::math.

legacy

legacy 标志对输出刻面 nonfinite_num_put 没有效果.

若 legacy 标志与 nonfinite_num_get 输入刻面一起使用, 则该刻面将识别以下所有表示 infinity 与 NaN 的字符串:

Number

字符串

正无穷大

inf, infinity, one#inf

正 NaN

nan, nan(...), nanq, nans, qnan, snan, one#ind, one#qnan, one#snan

负无穷大

-inf, -infinity, -one#inf

负 NaN

-nan, -nan(...), -nanq, -nans, -qnan, -snan, -one#ind, - one#qnan, -one#snan

  • 数字的类型可以是 float、double 与 long double.
  • 该刻面不区分大小写.
  • 正值可以带可选的 + 符号.
  • nan(...) 中的点号代表任意字符串.
  • one 代表任何能被 std::num_get 解析为数字 1 的字符串, 典型的是 "1.#INF"、"1.QNAN", 也有 "000001.#INF" 等.

该列表包括各种现有 C++ 标准库实现使用的无穷大与 NaN 的多个非标准字符串表示, 也包括其他编程语言使用的字符串表示.

signed_zero

若 signed_zero 标志与 nonfinite_num_put 一起使用, 则该刻面将始终区分正零与负零. 它会把正零格式化为 "0" 或 "+0", 把负零格式化为 "-0". 正零的字符串表示可以用 showpos 与 noshowpos 操纵器控制.

signed_zero flag 对输入刻面 nonfinite_num_get 没有效果. 输入刻面 nonfinite_num_get 始终把 "0" 与 "+0" 解析为正零, 把 "-0" 解析为负零, 大多数 std::num_get 实现也是如此.

注释

若未设置 signed_zero 标志 (默认), 则负零值将以平台通常的方式在输出中显示. 对大多数平台, 它会把正零格式化为 "0" 或 "+0", 把负零格式化为 "-0". 但设置 signed_zero 标志可能更具可移植性.

提示

可以使用 changesign 函数可移植地产生负零值 (changesign)(static_cast<ValType>(0)), 其中 ValType 是 float、double 或 long double, 或用户提供定义的浮点类型 (UDT), 只要该 UDT 有符号且 changesign 函数已实现.

trap_infinity

若 trap_infinity 标志与 nonfinite_num_put 一起使用, 则在试图格式化正无穷或负无穷时, 该刻面将抛出 std::ios_base::failure 类型的异常. 若从流插入运算符调用该刻面, 流会捕获该异常并设置其 fail bit 或 bad bit. 置位的是哪一个取决于平台.

若 trap_infinity 标志与 nonfinite_num_get 一起使用, 则在试图解析表示正无穷或负无穷的字符串时, 该刻面会设置流的 fail bit.

(关于这一不一致性的讨论参见下面的设计原理.)

trap_nan

与 trap_infinity 相同, 但改为捕获正负 NaN.
