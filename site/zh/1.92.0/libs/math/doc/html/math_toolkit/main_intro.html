关于 Math 工具包

本库分为若干相互关联的部分:

浮点实用工具

处理浮点运算的实用函数, 包括浮点分类函数 (fpclassify、isnan、isinf 等) 、符号操作、舍入、比较以及计算浮点数之间的距离.

特定宽度浮点类型

一组 typedef, 类似 <cstdint> 提供的类型, 但面向浮点类型.

数学常量

覆盖范围广泛的高精度常量, 从 π 的各种倍数、分数, 到 Euler 常量等.

这些常量当然可以在模板代码中使用, 或者在更合适的场合以带简化接口的非模板形式使用.

统计分布

提供了一套相当全面的 statistical distributions (统计分布) , 更高层的统计检验可以构建于其上.

最初的重点是中心 univariate distributions (单变量分布) . 同时提供 continuous (连续) 分布 (如 normal 和 Fisher) 与 discrete (离散) 分布 (如 binomial 和 Poisson) .

库提供了一份 comprehensive tutorial is provided (综合教程) , 以及一系列 worked examples (应用示例) , 展示如何使用本库进行统计检验.

数学特殊函数

提供少量高质量 special functions (特殊函数) , 最初集中于统计应用中使用的函数以及 Technical Report on C++ Library Extensions 中的函数.

当前实现的函数族包括 gamma、beta 和 erf 函数, 以及不完全 gamma 和 beta 函数 (各有四个变体) 及其所有可能的反函数, 另有 digamma、各种阶乘函数、Bessel 函数、椭圆积分、sinus cardinals (及其双曲变体) 、反双曲函数、Legendre/Laguerre/Hermite 多项式以及各种特殊的幂函数和对数函数.

所有实现都是完全泛型的, 支持任意“实数”类型, 包括 Boost.Multiprecision, 不过它们针对具有已知 significand (or mantissa) (尾数) 大小的类型做了优化: 通常是 float、double 或 long double.

这些函数也构成 TR1 特殊函数支持的基础.

求根与函数最小化

一套覆盖实数轴的综合求根算法, 支持导数和不支持导数的都有.

此外还有通过 Brent 方法进行的函数最小化.

多项式与有理函数

操作多项式以及高效求值有理式或多项式的工具.

插值

通过重心 (Barycentric) 或三次 B 样条近似的函数插值. 平滑.

数值积分 (求积) 与微分

一套相当全面的积分 (梯形、Gauss-Legendre、Gauss-Kronrod 和双指数) 与微分例程. (另见自动微分. )

积分例程全部可用于返回复数结果的函数——因而也适用于围道积分.

四元数与八元数

四元数与八元数, 作为类似 std::complex 的类模板.

自动微分

Autodiff 是一个仅头文件 C++ 库, 便于对单变量和多变量数学函数进行自动微分 (前向模式) .
