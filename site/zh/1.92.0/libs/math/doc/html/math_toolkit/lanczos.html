Lanczos 逼近

动机

为何基于 Lanczos 逼近来实现 gamma 及类 gamma 函数?

首先必须说明, 对于实数域 (而非复数域) 上的 gamma 函数, Lanczos 逼近 (参见 Wikipedia 或 Mathworld) 相比 Stirling's approximation 等更传统的方法似乎并没有明显优势. Pugh 对各种可用方法做了详尽比较, 发现它们在复杂度和相对误差方面都十分相似. 不过, Lanczos 逼近确实有几个值得进一步考虑的性质:

  • 该逼近的截断误差易于计算, 且对所有 z > 0 都成立. 实践中这意味着可以对所有 z > 0 使用同一个逼近, 并且无论 z 多大或多小, 都可以确信截断误差 至多被某个有限值所界定.
  • 该逼近的形式特别便于解析操作, 尤其是 gamma 或类 gamma 函数的比值无需借助对数即可轻松计算.

正是这两个性质的结合使该逼近颇具吸引力: Stirling 逼近对较大的 z 高度精确, 并具有与 Lanczos 逼近相同的某些解析性质, 但难以在 z 的整个取值范围上使用.

举一个最简单的例子, 考虑两个 gamma 函数的比值: 可以通过 lgamma 来计算:

exp(lgamma(a) - lgamma(b));

然而, 即使 lgamma 一致精确到 0.5ulp, 也可以轻易证明上式的最坏情况相对误差为:

Erel > a * log(a)/2 + b * log(b)/2

当 a 和 b 较小时这不成问题, 但换一种方式表述这一关系: a 和 b 的数值每增大 10 倍, 就会至少损失一位十进制精度.

相比之下, 通过解析地合并 Lanczos 逼近比值中的同类幂次项, 当 a 和 b 较小时这些误差几乎可以完全消除, 而当 a 和 b 非常大 (或非常小) 时也能将其控制在范围内. 当然, 计算高次幂本身就是出了名的难题, 但即便如此, Lanczos 逼近的解析组合往往决定了得到的是有效结果还是纯粹的垃圾. beta 函数的实现说明中有该方法实际应用的例子. 不完全 gamma_p gamma 和 beta 函数也使用类似的幂次项解析组合, 把除以大幂次的 gamma 和 beta 函数合并为单个 (更简单的) 表达式.

选择合适的参数

诀窍在于选择 N 和 g 以达到所需的精度水平: 把 g 取得较小会得到严格收敛的级数, 但收敛缓慢. 把 g 取得较大则会使级数中约前 g-1 项偏大和/或发散, 然后突然“猛地”收敛.

Pugh 已确定了 1 <= N <= 60 范围内各 N 对应的 g 最优值: 遗憾的是, 实践中选用这些值会在 Lanczos 和中引发消去误差, 因为 (交替) 级数中最大项约是结果的 1000 倍. 除非求值时可以使用若干保护位 并且系数以高于结果所需的精度存储, 否则这些最优值在实践中似乎并无用处. 这些值最好留作特定用途, 例如用双精度算术计算到 float 精度.

Godfrey 描述的替代方法是对 N 和 g 参数空间做穷举搜索, 为给定的 p 位浮点类型确定最优组合. 重复这一工作为双精度算术找到了一个不错的逼近 (接近 Godfrey 找到的那个) , 但未能为 80 位或 128 位 long double 找到真正好的逼近. 此外还观察到, 所得逼近倾向于针对用于对照阶乘测试实现的较小 z 值 (1 < z < 200) 进行优化. 用大参数计算 gamma 函数比值时, 观察到会因 Lanczos 级数的截断而产生误差.

Pugh 找出了逼近理论误差达到极小的所有位置, 但遗憾的是只发表了其中最大的极小值. 不过他观察到, 这些极小值与 Lanczos 级数 Sg(z) 中第一个被忽略的项 (aN) 变号的位置几乎重合. 这些位置相当容易定位, 尽管要耗费不少机时. 这些“甜点”只需计算一次、制成表格, 然后在需要时查找, 即可得到能为某个固定精度类型提供所需精度的逼近.

遗憾的是, 沿这条路径未能为 128 位 long double 找到真正好的逼近, 而找到的 64 位和 80 位实数逼近又需要过多项. 这里有两个相互冲突的因素: 高精度要求较大的 g, 而避免求值中的消去误差又要求较小的 g.

此处应注意, Lanczos 和可以化为有理形式 (两个多项式之比, 由部分分式形式经多项式运算得到) , 这样做会改变系数, 使 它们全为正. 这意味着有理形式的和可以在没有消去误差的情况下求值, 尽管对给定的 N 系数数量要翻倍. 再次搜索“甜点”——这次以有理形式求值 Lanczos 和, 并且只测试理论误差小于被测类型机器 epsilon 的“甜点”——为所有被测类型都找到了好的逼近. 所找到的最优值与 Pugh 报告的最佳情形相当接近 (对给定精度, N 略大、g 略小于 Pugh 的报告) ; 尽管化为有理形式会使存储的系数翻倍, 但应注意其中一半是整数 (因此占用较少存储空间) , 而且该逼近所需的 N 比其他情形所需的小, 因此总体上需要的浮点运算可能更少.
