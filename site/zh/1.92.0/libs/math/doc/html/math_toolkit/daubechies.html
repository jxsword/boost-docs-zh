Daubechies 小波与尺度函数

概要 
#include <boost/math/special_functions/daubechies_scaling.hpp>

namespace boost::math {

template<class Real, int p>
class daubechies_scaling {
public:
    daubechies_scaling(int grid_refinements = -1);

    inline Real operator()(Real x) const;

    inline Real prime(Real x) const;

    inline Real double_prime(Real x) const;

    std::pair<Real, Real> support() const;

    int64_t bytes() const;
};

template<class Real, int p, int order>
std::vector<Real> dyadic_grid(int64_t j_max);


#include <boost/math/special_functions/daubechies_wavelet.hpp>
template<class Real, int p>
class daubechies_wavelet {
public:
    daubechies_wavelet(int grid_refinements = -1);

    inline Real operator()(Real x) const;

    inline Real prime(Real x) const;

    inline Real double_prime(Real x) const;

    std::pair<Real, Real> support() const;

    int64_t bytes() const;
};


} // namespaces

Daubechies 小波与尺度函数是以整数 p 为索引的紧支撑函数族, 具有 p 个消失矩和长度为 2p 的关联滤波器. 它们用于信号去噪、PDE 的 Galerkin 方法以及压缩.

关于这些函数的权威参考是 Daubechies 的专著 Ten Lectures on Wavelets, 我们在此尽力遵循其记号约定.

基本用法如下:

auto phi = boost::math::daubechies_scaling<double, 8>();
double y = phi(0.38);
double dydx = phi.prime(0.38);

auto psi = boost::math::daubechies_wavelet<double, 8>();
y = psi(0.38);

注意, 构造函数调用的代价很高, 因为它必须组装一个二进网格 - 即 pφ 在二进有理数 (形如 n/2j 的数) 处的值. 你应在程序的整个生命周期内只实例化此类一次. 该类采用了 pimpl 手法, 其所有成员函数都是线程安全的, 因此可以被廉价地复制并在线程间共享. 默认的网格细化次数经过选择, 使得相对误差被控制在距支撑右端 ~2-3 ULP 之内 - 超过该处后, 函数求值条件数的超指数增长使之不可能实现. 不过, 控制 Daubechies 小波与尺度函数的相对误差比控制绝对误差困难得多, 且相对模式下的内存消耗也高得多. 可以通过以下方式查询该类的内存消耗:

int64_t mem = phi.bytes();

如果认为这大得不可接受, 用户可以选择控制绝对误差, 方法是调用构造函数时把 grid_refinements 参数设为 -2, 即

auto phi = boost::math::daubechies_scaling<double, 8>(-2);

这样得到的尺度函数使绝对误差保持在约等于双精度单元舍入误差的范围内.

如果使用场景不允许在整个程序中复用该类, 那么把精度进一步降低是合理的. 这可以通过指定网格细化次数来实现, 例如,

auto phi = boost::math::daubechies_scaling<double, 8>(12);

会创建一个 Daubechies 尺度函数, 它由计算到深度 j = 12 的二进网格插值得到. 构造函数的调用耗时关于网格细化次数是指数级的, 而调用运算符 .prime 和 .double_prime 是常数时间.

注意, 之所以把它做成一个类而不是自由函数, 唯一的原因是二进网格会使 Boost 源码下载包极其庞大. 因此, 预先计算二进网格并将其转储到 .cpp 文件中可能是有意义的; 这可以通过以下方式实现:

using boost::multiprecision::float128;
int grid_refinements = 12;
constexpr const derivative = 0;
constexpr const p = 8;
std::vector<float128> v = boost::math::dyadic_grid<float128, p, derivative>(grid_refinements);

注意, 无论对二进网格还是尺度函数, quad 精度都是所提供的最精确的精度. 只有在良态区域内, float 和 double 精度才能达到 1ULP 的精度.

只有当小波和尺度函数具有足够的光滑性时, 导数才可用. 如果你试图调用 .prime 于 2φ (它不可微), 但请注意光滑性随消失矩数量增加而提高.

多分辨率分析的公理保证尺度函数的整数平移是多分辨率分析的元素; 一个副作用是 (未平移的) 小波与尺度函数的支撑是任意的. 因此, 我们提供了 .support() 以便你核对我们的约定:

auto [a, b] = phi.support();

不过为明确起见: 尺度函数的支撑总是 [0, 2p - 1], 小波的支撑是 [ -p + 1, p].

Boost.Math 还提供了这些函数的 Fourier 变换的数值计算. 这在以 Fourier 基进行测量的稀疏恢复问题中很有用. 用法如下所示:

#include <boost/math/special_functions/fourier_transform_daubechies_scaling.hpp>
using boost::math::fourier_transform_daubechies_scaling;
// Evaluate the Fourier transform of the 4-vanishing moment Daubechies scaling function at ω=1.8:
std::complex<float> hat_phi = fourier_transform_daubechies_scaling<float, 4>(1.8f);

Fourier 变换约定是酉的, 虚数单位的符号遵循 Daubechies Ten Lectures. 特别地, 这意味着 fourier_transform_daubechies_scaling<float, p>(0.0) 返回 1/sqrt(2π).

该实现计算三角多项式的无穷乘积, 可由恒等式 𝓕[φ](ω) = m(ω/2)𝓕[φ](ω/2) 递归应用得到. 这既不特别快也不特别准, 但关于这个极有用的话题似乎没有文献, 因此只能采用这种朴素方法.
