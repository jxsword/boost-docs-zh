Laguerre(及关联)多项式

概要 
#include <boost/math/special_functions/laguerre.hpp>

namespace boost{ namespace math{

template <class T>
calculated-result-type laguerre(unsigned n, T x);

template <class T, class Policy>
calculated-result-type laguerre(unsigned n, T x, const Policy&);

template <class T>
calculated-result-type laguerre(unsigned n, unsigned m, T x);

template <class T, class Policy>
calculated-result-type laguerre(unsigned n, unsigned m, T x, const Policy&);

template <class T1, class T2, class T3>
calculated-result-type laguerre_next(unsigned n, T1 x, T2 Ln, T3 Lnm1);

template <class T1, class T2, class T3>
calculated-result-type laguerre_next(unsigned n, unsigned m, T1 x, T2 Ln, T3 Lnm1);


}} // namespaces
说明

这些函数的返回类型使用 结果类型计算规则 计算: 注意, 当只有一个模板参数时, 结果与该参数类型相同; 若模板参数为整数类型, 则结果为 double.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

template <class T>
calculated-result-type laguerre(unsigned n, T x);

template <class T, class Policy>
calculated-result-type laguerre(unsigned n, T x, const Policy&);

返回 n 阶 Laguerre 多项式在点 x 处的值:

下图展示了前几个 Laguerre 多项式的行为:

template <class T>
calculated-result-type laguerre(unsigned n, unsigned m, T x);

template <class T, class Policy>
calculated-result-type laguerre(unsigned n, unsigned m, T x, const Policy&);

返回次数为 n、阶数为 m 的关联 Laguerre 多项式在点 x 处的值:

template <class T1, class T2, class T3>
calculated-result-type laguerre_next(unsigned n, T1 x, T2 Ln, T3 Lnm1);

实现 Laguerre 多项式的三项递推关系, 该函数可用于生成在同一 x 处求值、n 递增的一系列值.

例如, 可以用以下代码生成前 10 个多项式值组成的向量:

double x = 0.5;  // Abscissa value
vector<double> v;
v.push_back(laguerre(0, x)).push_back(laguerre(1, x));
for(unsigned l = 1; l < 10; ++l)
   v.push_back(laguerre_next(l, x, v[l], v[l-1]));

正式的参数说明如下:

n

最后计算的多项式的次数 n.

x

横坐标值

Ln

在次数 n 处求值的多项式值.

Lnm1

在次数 n-1 处求值的多项式值.

template <class T1, class T2, class T3>
calculated-result-type laguerre_next(unsigned n, unsigned m, T1 x, T2 Ln, T3 Lnm1);

实现关联 Laguerre 多项式的三项递推关系, 该函数可用于生成在同一 x 处求值、次数 n 递增的一系列值.

例如, 可以用以下代码生成前 10 个多项式值组成的向量:

double x = 0.5;  // Abscissa value
int m = 10;      // order
vector<double> v;
v.push_back(laguerre(0, m, x)).push_back(laguerre(1, m, x));
for(unsigned l = 1; l < 10; ++l)
   v.push_back(laguerre_next(l, m, x, v[l], v[l-1]));

正式的参数说明如下:

n

最后计算的多项式的次数.

m

关联多项式的阶数.

x

横坐标值.

Ln

在次数 n 处求值的多项式值.

Lnm1

在次数 n-1 处求值的多项式值.

注意, 最坏的误差出现在次数增大时, 大于 ~120 的次数值极不可能产生有意义的结果, 尤其是在关联多项式且阶数也很大的情况下. 此外, 当函数值非常接近某个根时, 相对误差可能任意增大.

测试

测试混合使用了利用 functions.wolfram.com 计算的值的抽查与随机生成的测试数据: 测试数据使用 NTL::RR 以 1000 位精度计算.

实现

这些函数使用稳定的三项递推关系实现. 这些递推关系保证较低的绝对误差, 但无法保证在多项式某个根附近具有较低的相对误差.
