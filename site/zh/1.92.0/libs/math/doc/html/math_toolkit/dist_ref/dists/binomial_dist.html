Binomial 分布 

#include <boost/math/distributions/binomial.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class binomial_distribution;

typedef binomial_distribution<> binomial;

template <class RealType, class Policy>
class binomial_distribution
{
public:
   typedef RealType  value_type;
   typedef Policy    policy_type;

   static const unspecified-type clopper_pearson_exact_interval;
   static const unspecified-type jeffreys_prior_interval;

   // construct:
   binomial_distribution(RealType n, RealType p);

   // parameter access::
   RealType success_fraction() const;
   RealType trials() const;

   // Bounds on success fraction:
   static RealType find_lower_bound_on_p(
      RealType trials,
      RealType successes,
      RealType probability,
      unspecified-type method = clopper_pearson_exact_interval);
   static RealType find_upper_bound_on_p(
      RealType trials,
      RealType successes,
      RealType probability,
      unspecified-type method = clopper_pearson_exact_interval);

   // estimate min/max number of trials:
   static RealType find_minimum_number_of_trials(
      RealType k,     // number of events
      RealType p,     // success fraction
      RealType alpha); // risk level

   static RealType find_maximum_number_of_trials(
      RealType k,     // number of events
      RealType p,     // success fraction
      RealType alpha); // risk level
};

}} // namespaces

类类型 binomial_distribution 表示一个binomial distribution: 用于一次试验恰有两个互斥结果的情形. 这两个结果被标记为“成功”和“失败”. Binomial Distribution 用于求在 N 次试验中观察到 k 次成功的概率, 单次试验的成功概率记为 p. 二项分布假定 p 对所有试验都固定不变.

注释

二项分布的随机变量是成功次数 (试验次数是分布的固定属性), 而对负二项分布, 随机变量是给定成功次数下的试验次数.

注意

Binomial 分布是离散分布: 在内部, 像 cdf 和 pdf 这样的函数被“当作”连续函数处理, 但实际上这些函数返回的结果只有在随机变量实参为整数值时才有意义.

分位数函数默认返回向外取整后的整数结果. 也就是说, 下分位数 (概率小于 0.5) 向下取整, 上分位数 (概率大于 0.5) 向上取整. 这种行为确保当请求 X% 分位数时, 中心区域至少具有所请求的覆盖率, 而尾部至多具有所请求的覆盖率.

可以使用策略 (Policies)改变这种行为, 使分位数函数采用不同的取整方式, 甚至返回实数值结果. 强烈建议在 Binomial 分布上使用分位数函数之前阅读教程Understanding Quantiles of Discrete Distributions. reference docs 描述了如何更改这些分布的取整策略.

成员函数
构造 
binomial_distribution(RealType n, RealType p);

构造函数: n 是试验总次数, p 是单次试验的成功概率.

要求 0 <= p <= 1 且 n >= 0, 否则调用 domain_error.

访问器 
RealType success_fraction() const;

返回构造此分布时使用的参数 p.

RealType trials() const;

返回构造此分布时使用的参数 n.

成功比例的下界 
static RealType find_lower_bound_on_p(
   RealType trials,
   RealType successes,
   RealType alpha,
   unspecified-type method = clopper_pearson_exact_interval);

返回成功比例的下界:

trials

进行的试验总次数.

successes

发生的成功次数.

alpha

真实成功比例小于返回值的最大可接受概率.

method

可选参数, 指定计算区间所用的方法 (见下文).

例如, 若你在 n 次试验中观察到 k 次成功, 成功比例的最佳估计就是 k/n; 但如果你想以 95% 的把握确信真实值大于某个值 pmin, 那么:

pmin = binomial_distribution<RealType>::find_lower_bound_on_p(n, k, 0.05);

参见完整示例.

目前 method 可选参数有两个可选值: clopper_pearson_exact_interval 或 jeffreys_prior_interval. 这两个常量都是类模板 binomial_distribution 的成员, 因此用法例如:

p = binomial_distribution<RealType>::find_lower_bound_on_p(
    n, k, 0.05, binomial_distribution<RealType>::jeffreys_prior_interval);

未指定此参数时的默认方法是 Clopper Pearson “精确”区间. 它产生的区间保证至少 100(1-alpha)% 的覆盖率, 但众所周知它过于保守, 有时产生的区间覆盖率远高于所请求的值.

另一种计算方法产生无信息的 Jeffreys 先验区间. 它100(1-alpha)%平均而言只产生 的覆盖率, 尽管通常非常接近所请求的覆盖水平. 它是 Brown、Cai 和 DasGupta 的综述中推荐的主要计算方法之一.

请注意, 我们刻意不提供使用正态近似的“教科书”计算方法 (Wald 区间): 众所周知, 即使样本量大得惊人, 它也会持续给出糟糕的结果. 完整解释参见 Brown、Cai 和 DasGupta. 还有许多其他计算方法可用, 对特定情形可能更合适. 遗憾的是, 统计学家之间似乎对哪种方法“最好”并无共识: 示例参见 Brown、Cai 和 DasGupta 末尾的讨论.

这里提供的两种方法被选中, 主要是因为它们既可用于单侧区间, 也可用于双侧区间. 另见:

Lawrence D. Brown, T. Tony Cai and Anirban DasGupta (2001), Interval Estimation for a Binomial Proportion, Statistical Science, Vol. 16, No. 2, 101-133.

T. Tony Cai (2005), 离散分布中的单侧置信区间, Journal of Statistical Planning and Inference 131, 63-88.

Agresti, A. and Coull, B. A. (1998). 就二项比例的区间估计而言, 近似优于"精确". Amer. Statist. 52 119-126.

Clopper, C. J. and Pearson, E. S. (1934). 以二项分布为例说明置信限与信仰限的使用. Biometrika 26 404-413.

成功比例的上界 
static RealType find_upper_bound_on_p(
   RealType trials,
   RealType successes,
   RealType alpha,
   unspecified-type method = clopper_pearson_exact_interval);

返回成功比例的上界:

trials

进行的试验总次数.

successes

发生的成功次数.

alpha

真实成功比例大于返回值的最大可接受概率.

method

可选参数, 指定计算区间所用的方法. 各方法选项的含义参见上文中 find_upper_bound_on_p 的文档.

例如, 若你在 n 次试验中观察到 k 次成功, 成功比例的最佳估计就是 k/n; 但如果你想以 95% 的把握确信真实值小于某个值 pmax, 那么:

pmax = binomial_distribution<RealType>::find_upper_bound_on_p(n, k, 0.05);

参见完整示例.

注释

为了得到成功比例的双侧界, 你要同时调用 find_lower_bound_on_p 和 find_upper_bound_on_p, 并传入相同的实参.

若真实成功比例落在界之外的可接受风险水平为 α, 则向这些函数传入 α/2.

因此, 例如双侧 95% 置信区间可以通过向每个函数传入 α = 0.025 得到.

参见完整示例.

估计确保一定成功次数所需的试验次数 
static RealType find_minimum_number_of_trials(
   RealType k,     // number of events
   RealType p,     // success fraction
   RealType alpha); // probability threshold

此函数估计所需的试验次数下限, 以确保以 alpha 的风险水平观察到多于 k 个事件 (风险指 k 个或更少事件发生的概率).

k

观察到的成功次数.

p

每次试验的成功概率.

alpha

观察到 k 个或更少事件的最大可接受概率.

例如:

binomial_distribution<RealType>::find_number_of_trials(10, 0.5, 0.05);

返回为达到 95% 把握观察到 10 个发生频率为二分之一的事件所需的最少试验次数.

估计确保不超过一定成功次数的最大试验次数 
static RealType find_maximum_number_of_trials(
   RealType k,     // number of events
   RealType p,     // success fraction
   RealType alpha); // probability threshold

此函数估计可进行的试验次数上限, 以确保观察到 k 次或更少的成功, 超过 k 次的风险为 alpha.

k

观察到的成功次数.

p

每次试验的成功概率.

alpha

观察到多于 k 个事件的最大可接受概率.

例如:

binomial_distribution<RealType>::find_maximum_number_of_trials(0, 1e-6, 0.05);

返回我们可进行的最大试验次数, 同时仍有 95% 的把握不会观察到任何发生频率为百万分之一的事件. 这通常用于失效分析.

参见完整示例.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support.

随机变量 k 的定义域为 0 <= k <= N, 否则返回 domain_error.

值得花点时间弄清楚这些访问器在此分布语境下的确切含义:

函数

含义

Probability Density Function

在 n 次成功比例为 p 的试验中获得恰好 k 次成功的概率. 例如:

pdf(binomial(n, p), k)

Cumulative Distribution Function

在 n 次成功比例为 p 的试验中获得k 次或更少成功的概率. 例如:

cdf(binomial(n, p), k)

累积分布函数的补

在 n 次成功比例为 p 的试验中获得多于 k 次成功的概率. 例如:

cdf(complement(binomial(n, p), k))

Quantile

给定试验次数为 n、成功比例为 p、概率为 P 的二项分布, 求其 CDF 小于 P 的最大成功次数 k. 强烈建议在使用分位数函数之前阅读教程 Understanding Quantiles of Discrete Distributions.

由概率的补求 Quantile

给定试验次数为 n、成功比例为 p、概率为 Q 的二项分布, 求其 CDF 大于 1-Q 的最小成功次数 k. 强烈建议在使用分位数函数之前阅读教程 Understanding Quantiles of Discrete Distributions.

如上数值求得.

均值

p * n

方差

p * n * (1-p)

众数

floor(p * (n + 1))

偏度

(1 - 2 * p) / sqrt(n * p * (1 - p))

峰度

3 - (6 / n) + (1 / (n * p * (1 - p)))

超额峰度

(1 - 6 * p * q) / (n * p * q)
