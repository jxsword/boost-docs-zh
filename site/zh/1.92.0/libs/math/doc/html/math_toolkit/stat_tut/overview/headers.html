头文件与命名空间

本库的全部代码都位于 namespace boost::math 内.

要使用分布 my_distribution, 你需要包含头文件 <boost/math/my_distribution.hpp> (编译更快), 或者 "包含所有分布" 的头文件: <boost/math/distributions.hpp>.

例如, 要使用 Students-t 分布, 包含 <boost/math/students_t.hpp> 或 <boost/math/distributions.hpp> 之一

你还需要把分布名称引入作用域, 例如用一条 using namespace boost::math; 声明,

或者用具体的 using 声明, 如 using boost::math::normal; (推荐).

注意

一些数学函数名也用于 namespace std 中, 因此包含 <random> 可能导致歧义!
