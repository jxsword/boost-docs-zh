沿指定方向查找下一个可表示值 (nextafter)

概要 
#include <boost/math/special_functions/next.hpp>

namespace boost{ namespace math{

template <class FPT>
FPT nextafter(FPT val, FPT direction);

}} // namespaces
说明 - nextafter

这是 C99 标准中 nextafter 函数的一个实现. (它实际上也是 C99 nexttoward 遗留函数的一个实现, 二者区别仅在于它有 long double 方向, 必要时通常可顶替使用. )

注释

C99 函数必须用后缀 f 和 l 来区分 float 和 long double 版本; C++ 则改用模板机制.

返回 x 之后朝 y 方向的下一个可表示值. 若 x == y, 则返回 x. 若 x 非有限, 则返回 domain_error 的结果. 若朝 y 方向不存在这样的值, 则返回 overflow_error.

警告

模板参数 FTP 必须是浮点类型. 例如整型类型会产生一个没什么帮助的错误消息.

提示

几乎总是如此: 你只想要下一个或上一个可表示值, 所以请改用下面的 float_next 或 float_prior.

示例 - nextafter

以 32 位 float 表示、1 两侧的两个表示值为:

The nearest (exact) representation of 1.F is      1.00000000
nextafter(1.F, 999) is                            1.00000012
nextafter(1/f, -999) is                           0.99999994

The nearest (not exact) representation of 0.1F is 0.100000001
nextafter(0.1F, 10) is                            0.100000009
nextafter(0.1F, 10) is                            0.099999994
