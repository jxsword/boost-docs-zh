求第一类和第二类 Bessel 函数的零点

概要

#include <boost/math/special_functions/bessel.hpp>

这些函数既可用于获取 Bessel 函数的单个零点或根, 也可以通过提供输出迭代器把多个零点放入类似 std::vector 的容器中.

单值函数的签名为:

template <class T>
T cyl_bessel_j_zero(
         T v,            // Floating-point value for Jv.
         int m);         // 1-based index of zero.

template <class T>
T cyl_neumann_zero(
         T v,            // Floating-point value for Jv.
         int m);         // 1-based index of zero.

多个零点的签名为:

template <class T, class OutputIterator>
OutputIterator cyl_bessel_j_zero(
                     T v,                       // Floating-point value for Jv.
                     int start_index,           // 1-based index of first zero.
                     unsigned number_of_zeros,  // How many zeros to generate.
                     OutputIterator out_it);    // Destination for zeros.

template <class T, class OutputIterator>
OutputIterator cyl_neumann_zero(
                     T v,                       // Floating-point value for Jv.
                     int start_index,           // 1-based index of zero.
                     unsigned number_of_zeros,  // How many zeros to generate
                     OutputIterator out_it);    // Destination for zeros.

还有允许控制错误处理与精度 Policies 的版本.

 template <class T>
 T cyl_bessel_j_zero(
          T v,            // Floating-point value for Jv.
          int m,          // 1-based index of zero.
          const Policy&); // Policy to use.

 template <class T>
 T cyl_neumann_zero(
          T v,            // Floating-point value for Jv.
          int m,          // 1-based index of zero.
          const Policy&); // Policy to use.


template <class T, class OutputIterator>
OutputIterator cyl_bessel_j_zero(
                     T v,                       // Floating-point value for Jv.
                     int start_index,           // 1-based index of first zero.
                     unsigned number_of_zeros,  // How many zeros to generate.
                     OutputIterator out_it,     // Destination for zeros.
                     const Policy& pol);        // Policy to use.

template <class T, class OutputIterator>

                     T v,                       // Floating-point value for Jv.

                     unsigned number_of_zeros,  // How many zeros to generate.
                     OutputIterator out_it,     // Destination for zeros.
                     const Policy& pol);        // Policy to use.
说明

每个实数阶 ν 的柱面 Bessel 函数和 Neumann 函数在正实轴上都有无穷多个零点. 正实轴上的实零点可以通过求解如下方程的根得到:

Jν(jν, m) = 0

Yν(yν, m) = 0

这里, jν, m 表示第 m 个根, 其阶为 ν 的柱面 Bessel 函数; 而 yν, m 表示第 m 个根, 其阶为 ν 的柱面 Neumann 函数.

Bessel 函数与 Neumann 函数的零点或根 (即 x 处函数穿过水平 y = 0 轴的值) 由两个函数计算: cyl_bessel_j_zero 和 cyl_neumann_zero.

每种情况下返回的零点的索引(序号)都从 1 开始计数,即:

cyl_bessel_j_zero(v, 1);

返回 Bessel J 的第一个零点.

传入 start_index <= 0 将导致抛出 std::domain_error 异常.

然而, 对某些参数而言, 第 0 个根是有定义的且值为零. 例如, J[sub v](x) 的第 0 个根有定义, 且对所有 v > 0 的值以及 v = -n 的负整数值都为零. 类似情形在下文的实现细节中描述.

阶 v (属于 J) 对于 cyl_bessel_j 和 cyl_neumann 函数而言可取正、负和零, 但不能是无穷大或 NaN.

求 Bessel 和 Neumann 零点的示例

本示例演示如何计算 Bessel 函数和 Neumann 函数的零点. 它还展示了如何组合使用 Boost.Math 与 Boost.Multiprecision 以提供多位十进制精度. 要获得 50 位十进制精度, 需要包含

#include <boost/multiprecision/cpp_dec_float.hpp>

以及一个 typedef(针对 float_type)可能更方便(允许快速切换以按内建 double 或其他精度重新计算)

typedef boost::multiprecision::cpp_dec_float_50 float_type;

要使用这些求函数零点的函数,我们需要

#include <boost/math/special_functions/bessel.hpp>

此文件包含零点查找函数的前置声明签名:

//  #include <boost/math/special_functions/math_fwd.hpp>

但更多细节见完整文档, 例如 Boost.Math Bessel functions.

此示例演示既获取 Bessel 函数的单个零点, 又通过提供迭代器把多个零点放入类似 std::vector 的容器.

提示

把使用 Boost.Math 的代码放进 try'n'catch 块中始终是明智的; 这能确保在出现异常情况时显示有用的错误消息.

首先, 求单个 Bessel 零点.

精度由 T 的模板参数 v 的浮点类型控制, 因此本示例具有 double 精度, 即至少 15 位、至多 17 位十进制数字 (对于常见的 64 位 double).

//    double root = boost::math::cyl_bessel_j_zero(0.0, 1);
//    // Displaying with default precision of 6 decimal digits:
//    std::cout << "boost::math::cyl_bessel_j_zero(0.0, 1) " << root << std::endl; // 2.40483
//    // And with all the guaranteed (15) digits:
//    std::cout.precision(std::numeric_limits<double>::digits10);
//    std::cout << "boost::math::cyl_bessel_j_zero(0.0, 1) " << root << std::endl; // 2.40482555769577

但请注意, 由于参数 v 控制结果的精度, v 必须是浮点类型. 因此如果提供整数类型, 比如写 0 而不是 0.0, 那么将无法通过编译, 如下所示:

root = boost::math::cyl_bessel_j_zero(0, 1);

错误消息如下

error C2338: Order must be a floating-point type.

或者, 我们可以选择性地使用策略 (policy) 以 C 风格忽略错误, 返回某个值, 可能是无穷大或 NaN, 或是尽力而为的结果. (参见 user error handling).

创建一个 (可能并不明智!) 忽略所有错误的策略 ignore_all_policy:

typedef boost::math::policies::policy<
  boost::math::policies::domain_error<boost::math::policies::ignore_error>,
  boost::math::policies::overflow_error<boost::math::policies::ignore_error>,
  boost::math::policies::underflow_error<boost::math::policies::ignore_error>,
  boost::math::policies::denorm_error<boost::math::policies::ignore_error>,
  boost::math::policies::pole_error<boost::math::policies::ignore_error>,
  boost::math::policies::evaluation_error<boost::math::policies::ignore_error>
            > ignore_all_policy;

使用此 ignore_all_policy 的示例有

double inf = std::numeric_limits<double>::infinity();
double nan = std::numeric_limits<double>::quiet_NaN();

double dodgy_root = boost::math::cyl_bessel_j_zero(-1.0, 1, ignore_all_policy());
std::cout << "boost::math::cyl_bessel_j_zero(-1.0, 1) " << dodgy_root << std::endl; // 1.#QNAN
double inf_root = boost::math::cyl_bessel_j_zero(inf, 1, ignore_all_policy());
std::cout << "boost::math::cyl_bessel_j_zero(inf, 1) " << inf_root << std::endl; // 1.#QNAN
double nan_root = boost::math::cyl_bessel_j_zero(nan, 1, ignore_all_policy());
std::cout << "boost::math::cyl_bessel_j_zero(nan, 1) " << nan_root << std::endl; // 1.#QNAN

另一个版本的 cyl_bessel_j_zero 允许一次调用计算多个零点, 并把结果放入容器中, 通常是 std::vector. 例如, 生成并显示前五个 double 根 — 即 Jv 在整数阶 2 时的根, 对应 J2(x) 列, 见 Wolfram Bessel Function Zeros 表 1.

unsigned int n_roots = 5U;
std::vector<double> roots;
boost::math::cyl_bessel_j_zero(2.0, 1, n_roots, std::back_inserter(roots));
std::copy(roots.begin(),
          roots.end(),
          std::ostream_iterator<double>(std::cout, "\n"));

或者, 我们可以用 Boost.Multiprecision 生成 Jv 的 50 位十进制数字的根, 此时非整数阶为 v= 71/19 == 3.736842, 该阶表示为精确整数分数, 以便为所有浮点类型生成尽可能准确的值.

我们设置输出流的精度,并显示末尾的零以展示固定的 50 位十进制数字.

std::cout.precision(std::numeric_limits<float_type>::digits10); // 50 decimal digits.
std::cout << std::showpoint << std::endl; // Show trailing zeros.

float_type x = float_type(71) / 19;
float_type r = boost::math::cyl_bessel_j_zero(x, 1); // 1st root.
std::cout << "x = " << x << ", r = " << r << std::endl;

r = boost::math::cyl_bessel_j_zero(x, 20U); // 20th root.
std::cout << "x = " << x << ", r = " << r << std::endl;

std::vector<float_type> zeros;
boost::math::cyl_bessel_j_zero(x, 1, 3, std::back_inserter(zeros));

std::cout << "cyl_bessel_j_zeros" << std::endl;
// Print the roots to the output stream.
std::copy(zeros.begin(), zeros.end(),
          std::ostream_iterator<float_type>(std::cout, "\n"));
使用输出迭代器对 Bessel 函数的零点求和

本示例演示对 Bessel 函数的零点求和. 要使用这些函数的零点查找函数, 我们需要

#include <boost/math/special_functions/bessel.hpp>

我们使用 cyl_bessel_j_zero 输出迭代器参数 out_it, 通过定义自定义输出迭代器来构造 1/zeros2 的和:

template <class T>
struct output_summation_iterator
{
   output_summation_iterator(T* p) : p_sum(p)
   {}
   output_summation_iterator& operator*()
   { return *this; }
    output_summation_iterator& operator++()
   { return *this; }
   output_summation_iterator& operator++(int)
   { return *this; }
   output_summation_iterator& operator = (T const& val)
   {
     *p_sum += 1./ (val * val); // Summing 1/zero^2.
     return *this;
   }
private:
   T* p_sum;
};

对许多值计算该和, 收敛于解析精确值 1/8.

using boost::math::cyl_bessel_j_zero;
double nu = 1.;
double sum = 0;
output_summation_iterator<double> it(&sum);  // sum of 1/zeros^2
cyl_bessel_j_zero(nu, 1, 10000, it);

double s = 1/(4 * (nu + 1)); // 0.125 = 1/8 is exact analytical solution.
std::cout << std::setprecision(6) << "nu = " << nu << ", sum = " << sum
  << ", exact = " << s << std::endl;
// nu = 1.00000, sum = 0.124990, exact = 0.125000

本示例同样展示了如何组合使用 Boost.Math 与 Boost.Multiprecision 以提供多位十进制精度. 要获得 50 位十进制精度, 需要包含

要使用 cyl_neumann 函数的零点查找函数, 我们需要:

#include <boost/math/special_functions/bessel.hpp>

Neumann (Bessel Y) 函数的零点求值方式非常类似:

using boost::math::cyl_neumann_zero;
double zn = cyl_neumann_zero(2., 1);

std::vector<float> nzeros(3); // Space for 3 zeros.

std::cout << "cyl_neumann_zero<float>(2.F, 1, ";
// Print the zeros to the output stream.
std::copy(nzeros.begin(), nzeros.end(),
          std::ostream_iterator<float>(std::cout, ", "));

std::cout << "\n""cyl_neumann_zero(static_cast<float_type>(220)/100, 1) = "
  << cyl_neumann_zero(static_cast<float_type>(220)/100, 1) << std::endl;
// 3.6154383428745996706772556069431792744372398748422

提示

把所有使用 Boost.Math 的代码放进 try'n'catch 块中始终是明智的; 这能确保在出现异常情况时可以显示有用的错误消息.

下面的示例展示了若干会抛出 domain_error 异常的“不良”参数的消息.

try
{ // Try a zero order v.
  float dodgy_root = boost::math::cyl_bessel_j_zero(0.F, 0);
  std::cout << "boost::math::cyl_bessel_j_zero(0.F, 0) " << dodgy_root << std::endl;
  // Thrown exception Error in function boost::math::cyl_bessel_j_zero<double>(double, int):
  // Requested the 0'th zero of J0, but the rank must be > 0 !
}
catch (std::exception& ex)
{
  std::cout << "Thrown exception " << ex.what() << std::endl;
}
注释

错误消息中显示的类型是提升之后的类型, 使用了精度策略 和 内部提升策略, 本例中从 float 提升到 double.

本示例中的提升过程如下:

  1. 参数是 float 和 int.
  2. 把 int “当作” double 处理, 于是参数为 float 和 double.
  3. 公共类型是 double - 这正是我们想要的精度 (也是将要返回的类型).
  4. 内部以 double 求值, 以获得完整的 float 精度.

完整代码中有其他从 double 提升到 long double 的示例.

其他“不良”输入 (如无穷大和 NaN) 的示例见下文. 一些编译器警告表明“不良”值在编译期即被检测到.

实现

有多种方法用于计算 jν, m 和 yν, m 的初始估计; 下文将详细描述.

求出给定根的初始估计后, 随后使用 Boost.Math 的带导数求根工具结合函数 cyl_bessel_j 和 cyl_neumann, 通过 Newton-Raphson 迭代把精度细化到所需水平.

牛顿迭代需要 Jν(x) 或 Yν(x) 以及其导数. Jν(x) 和 Yν(x) 关于 x 的导数由 M. Abramowitz 和 I. A. Stegun, Handbook of Mathematical Functions, NBS (1964) 给出. 具体而言,

d/dx Jν(x) = Jν-1(x) - ν Jν(x) / x

d/dx Yν(x) = Yν-1(x) - ν Yν(x) / x

根的秩 (换言之, 根的索引) 的枚举从 1 开始向上计数, 即 m,=1,2,3,… 第一个根的值总是大于零.

对某些特殊参数, 柱面 Bessel 函数和柱面 Neumann 函数在原点处有根. 例如, Jν(x) 对每个正阶 ν > 0 以及每个负整数阶 ν = -n (其中 n ∈ ℕ + 且 n ≠ 0) 在原点处都有根.

此外, Yν(x) 对每个负半整数阶 ν = -n/2 (其中 n ∈ ℕ + 且 n ≠ 0) 在原点处都有根.

对于这些特殊参数值, 会把取值 x = 0 的原点作为 0第 个根提供, 由 cyl_bessel_j_zero() 和 cyl_neumann_zero() 生成.

在为 Bessel 函数的根计算初始估计时, 会对正阶与负阶加以区分, 并对二者使用不同的方法. 此外, 对第一个根 m = 1 与秩更高的后续根 m ≥ 2 使用不同的算法. 而且, 对阶在截断点 ν = 2.2 之上和之下的 Bessel 函数, 其根的估计也用不同的方法计算.

在 0 ≤ ν < 2.2 时, jν,1 和 yν,1 的估计值使用经实验制表的数值计算. 这些系数由计算机代数系统生成.

在 ν≥ 2.2 时, jν,1 和 yν,1 的估计值使用 M. Abramowitz 和 I. A. Stegun, Handbook of Mathematical Functions, NBS (1964) 中的式 9.5.14 和 9.5.15.

具体而言,

jν,1 ≅ ν + 1.85575 ν⅓ + 1.033150 ν-⅓ - 0.00397 ν-1 - 0.0908 ν-5/3 + 0.043 ν-7/3 + …

以及

yν,1 ≅ ν + 0.93157 ν⅓ + 0.26035 ν-⅓ + 0.01198 ν-1 - 0.0060 ν-5/3 - 0.001 ν-7/3 + …

当秩 m > 2 且 0 ≤ ν < 2.2 时, jν, m 和 yν, m 的估计值使用 McMahon 逼近, 见 M. Abramowitz 和 I. A. Stegan 第 9.5 节和 9.5.12. 具体而言,

jν,m, yν,m ≅

β - (μ-1) / 8β

- 4(μ-1)(7μ - 31) / 3(8β)3

-32(μ-1)(83μ² - 982μ + 3779) / 15(8β)5

-64(μ-1)(6949μ3 - 153855μ² + 1585743μ- 6277237) / 105(8a)7

- …   (5)

其中 μ = 4ν2 且 β = (m + ½ν - ¼)π 对应 jν,m, 而 β = (m + ½ν -¾)π 对应 yν,m

当 ν ≥ 2.2 时, jν, m 和 yν, m 的估计值使用 M. Abramowitz 和 I. A. Stegun, Handbook of Mathematical Functions, NBS (1964) 中式 9.5.22 给出的渐近展开的一项, 以及式 9.5.26 顶行结合式 9.3.39 — 该书对零点的渐近展开给出了显式而易懂的处理. 后两个方程针对大于 1 的自变量 (x) 给出. (Olver 在 §10.21(vi) McMahon's Asymptotic Expansions for Large Zeros 中也给出了这些方程的级数形式 - 只是变量名略有不同).

总结如下,

jν, m ∼ νx(-ζ) + f1(-ζ/ν)

其中 -ζ = ν-2/3am, 而 am 是 Ai(x) 在负实轴上m第 个根的绝对值.

这里 x = x(-ζ) 是如下函数的反函数:

⅔(-ζ)3/2 = √(x² - 1) - cos⁻¹(1/x)

(7)

此外,

f1(-ζ) = ½x(-ζ) {h(-ζ)}² ⋅ b0(-ζ)

其中

h(-ζ) = {4(-ζ) / (x² - 1)}4

以及

b0(-ζ) = -5/(48ζ²) + 1/(-ζ)½ ⋅ { 5/(24(x2-1)3/2) + 1/(8(x2-1)½)}

在上面的式 7 中求解 x(-ζ) 时, 右端对较大的 x 展开为二阶 Taylor 级数. 由此得到

⅔(-ζ)3/2 ≈ x + 1/2x - π/2

所得二次方程的正根用于求初始估计 x(-ζ). 随后用式 7 中若干步 Newton-Raphson 迭代细化该初始估计.

负阶柱面 Bessel 函数在正实轴上的根的估计用交错关系求得. 例如, 柱面 Bessel 函数 j-ν,m 的m第 个根被相应正整数阶 Bessel 函数的m第 个根与(m+1)第 个根夹逼. 换言之,

jnν, m < j-ν, m < jnν, m+1

其中 m > 1, 且 nν 表示 |-ν| 的绝对值向下取整.

类似的夹逼关系也用于求负阶 Neumann 函数的根的估计, 此时需要处理每个负半整数阶处的不连续性.

夹逼关系对负阶柱面 Bessel 函数和柱面 Neumann 函数的第一个根不成立. 因此, 使用迭代算法结合二分求根来定位 j-ν,1 和 y-ν,1.

测试

零点求值的精度以 50 位十进制数字用 cpp_dec_float_50 进行了测试,并与 Wolfram Alpha 计算的抽查值完全一致.
