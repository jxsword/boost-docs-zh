终止条件函子 

template <class T>
struct eps_tolerance
{
   eps_tolerance();
   eps_tolerance(int bits);
   bool operator()(const T& a, const T& b)const;
};

eps_tolerance 是这些求根函数常用的终止条件. 其 operator() 将在 a 与 b 之间的相对距离小于 T 的机器 epsilon 的四倍与 21-bits 两者中的较大者时返回 true. 换言之, 你把 bits 设为希望在结果中得到的精度位数. 要求最小容差为 类型 T 的机器 epsilon 的四倍, 是为了保证我们得到的是一个界定区间, 因为该区间的大小显然必须大于一个 epsilon. 虽然理论上可以达到两倍机器 epsilon 的最大距离, 但在实践中这会导致大量的"抖动", 因为被求根的函数充其量只能精确到 1 个 epsilon.

struct equal_floor
{
   equal_floor();
   template <class T> bool operator()(const T& a, const T& b)const;
};

当你想求得作为真实根之 floor 的整数结果时, 使用该终止条件. 一旦区间两端具有相同的 floor, 它就会立即终止.

struct equal_ceil
{
   equal_ceil();
   template <class T> bool operator()(const T& a, const T& b)const;
};

当你想求得作为真实根之 ceil 的整数结果时, 使用该终止条件. 一旦区间两端具有相同的 ceil, 它就会立即终止.

struct equal_nearest_integer
{
   equal_nearest_integer();
   template <class T> bool operator()(const T& a, const T& b)const;
};

当你想求得与真实根 最接近 的整数结果时, 使用该终止条件. 一旦区间两端舍入到同一个最近整数, 它就会立即终止.
