梯度下降

概要

             class GradEvalPolicy>
auto make_gradient_descent(Objective&& obj,
                           ArgumentContainer& x,
                               RealType& lr,
                               InitializationPolicy&& ip,
                               ObjectiveEvalPolicy&& oep,
                               GradEvalPolicy&& gep)

梯度下降沿目标函数梯度的相反方向迭代更新参数 x (最小化目标).

x[i] -= lr * g[i]

其中 lr 是用户定义的学习率. 关于理论原理更完整的描述, 请参阅 wikipedia 页面

该实现把工作分派出去: - 可微分变量的初始化交给初始化策略 - 目标求值交给目标求值策略 - 梯度计算交给梯度求值策略 - 参数更新交给更新策略

接口的设计意图类似 pytorch: 构造一个优化器对象, 并通过 step() 方法推进它. 还提供了一个辅助的 minimize 方法.

参数
  • Objective&& obj : 要最小化的目标函数
  • ArgumentContainer& x : 要优化的变量
  • RealType& lr : 学习率. 较大的值在下降过程中迈出较大的步子, 收敛更快但更不稳定. 反之, 较小的值更稳定但收敛更慢.
  • InitializationPolicy&& ip : 优化器状态与变量的初始化策略. 用户可以提供自定义初始化策略, 控制参数容器以及任何 AD 特有的运行期状态 (即反向模式磁带的挂载/重置) 如何初始化. 默认情况下, 优化器使用用户在 x 中提供的初始值, 并执行梯度求值所需的标准反向模式 AD 初始化. 自定义初始化策略对随机起点、非 rvar AD 类型或外部提供梯度的情形很有用. 编写自定义策略时, 所需的初始化策略接口参见反向模式自动微分策略文档.
  • ObjectiveEvalPolicy&& oep : 告诉优化器如何求值目标函数. 默认为 reverse_mode_function_eval_policy<RealType>.
  • GradEvalPolicy&& gep : 告诉优化器如何求值目标函数的梯度. 默认为 reverse_mode_gradient_evaluation_policy<RealType>
手动优化的示例

本节我们将展示一个例子: 求约束在 R = 1 球面上的带电粒子的最优构型. 该问题也被称为 Thomson 问题. 概括地说, 我们在寻找受限于 $S^2$ 球面、受 Coulomb 势作用的 N 电子系统的构型. Coulomb 势由下式给出:

下面的代码手动最小化上述 N 个粒子在其两个角位置上的势能函数.

#include <boost/math/differentiation/autodiff_reverse.hpp>
#include <boost/math/optimization/gradient_descent.hpp>
#include <boost/math/optimization/minimizer.hpp>
#include <cmath>
#include <fstream>
#include <iostream>
#include <random>
#include <string>
namespace rdiff = boost::math::differentiation::reverse_mode;
namespace bopt  = boost::math::optimization;
double random_double(double min = 0.0, double max = 1.0)
{
    static thread_local std::mt19937       rng{std::random_device{}()};
    std::uniform_real_distribution<double> dist(min, max);
    return dist(rng);
}

template<typename S>
struct vec3
{
    /**
    * @brief R^3 coordinates of particle on Thomson Sphere
    */
    S x, y, z;
};

template<class S>
static inline vec3<S> sph_to_xyz(const S& theta, const S& phi)
{
    /**
     * convenience overload to convert from [theta,phi] -> x, y, z
     */
    return {sin(theta) * cos(phi), sin(theta) * sin(phi), cos(theta)};
}

template<typename T>
T thomson_energy(std::vector<T>& r)
{
    const size_t N    = r.size() / 2;
    const T      tiny = T(1e-12);

    T E = 0;
    for (size_t i = 0; i < N; ++i) {
        const T& theta_i = r[2 * i + 0];
        const T& phi_i   = r[2 * i + 1];
        auto     ri      = sph_to_xyz(theta_i, phi_i);

        for (size_t j = i + 1; j < N; ++j) {
            const T& theta_j = r[2 * j + 0];
            const T& phi_j   = r[2 * j + 1];
            auto     rj      = sph_to_xyz(theta_j, phi_j);

            T dx = ri.x - rj.x;
            T dy = ri.y - rj.y;
        T dz = ri.z - rj.z;

            T d2 = dx * dx + dy * dy + dz * dz + tiny;
            E += 1.0 / sqrt(d2);
        }
    }
    return E;
}

template<class T>
std::vector<rdiff::rvar<T, 1>> init_theta_phi_uniform(size_t N, unsigned seed = 12345)
{
    const T pi = T(3.1415926535897932384626433832795);

    std::mt19937                      rng(seed);
    std::uniform_real_distribution<T> unif01(T(0), T(1));
    std::uniform_real_distribution<T> unifm11(T(-1), T(1));

    std::vector<rdiff::rvar<T, 1>> u;
    u.reserve(2 * N);

    for (size_t i = 0; i < N; ++i) {
        T z     = unifm11(rng);
        T phi   = (T(2) * pi) * unif01(rng) - pi;
        T theta = std::acos(z);

        u.emplace_back(theta);
        u.emplace_back(phi);
    }
    return u;
}

int main(int argc, char* argv[])
{
    if (argc != 2) {
        std::cerr << "Usage: " << argv[0] << " <N>\n";
        return 1;
    }

    const int    N      = std::stoi(argv[1]);
    const int    NSTEPS = 100000;
    const double lr     = 1e-3;

    auto u_ad = init_theta_phi_uniform<double>(N);

        auto gdopt = bopt::make_gradient_descent(&thomson_energy<rdiff::rvar<double, 1>>, u_ad, lr);

    // filenames
    std::string pos_filename    = "thomson_" + std::to_string(N) + ".csv";
    std::string energy_filename = "energy_" + std::to_string(N) + ".csv";

        std::ofstream pos_out(pos_filename);
        std::ofstream energy_out(energy_filename);

        pos_out << "step,particle,x,y,z\n";
        energy_out << "step,energy\n";

    for (int step = 0; step < NSTEPS; ++step) {
            gdopt.step();
            for (int pi = 0; pi < N; ++pi) {
                double theta = u_ad[2 * pi + 0].item();
                double phi   = u_ad[2 * pi + 1].item();
                auto   r     = sph_to_xyz(theta, phi);
                pos_out << step << "," << pi << "," << r.x << "," << r.y << "," << r.z << "\n";
            }
        auto E = gdopt.objective_value();
        energy_out << step << "," << E << "\n";
        }

        pos_out.close();
        energy_out.close();

        return 0;
}

变量

const int    N      = std::stoi(argv[1]);

是从命令行读取的粒子数

const int    NSTEPS = 100000;

是优化步数

const double lr     = 1e-3;

是优化器学习率. 按代码原样使用, 优化器运行 100000 步. 运行程序时

./thomson_sphere N

即可优化 N 粒子系统. 下面是 N=2,...8 个粒子的若干最优构型的图.

使用 minimize 的示例

通常, 我们并不想真的自己实现步进函数, 即我们关心某些收敛判据. 在上面的示例中, 需要包含 minimizer.hpp 头文件:

#include <boost/math/optimization/minimizer.hpp>

并替换优化循环:

for (int step = 0; step < NSTEPS; ++step) {
           gdopt.step();
           for (int pi = 0; pi < N; ++pi) {
               double theta = u_ad[2 * pi + 0].item();
               double phi   = u_ad[2 * pi + 1].item();
               auto   r     = sph_to_xyz(theta, phi);
               pos_out << step << "," << pi << "," << r.x << "," << r.y << "," << r.z << "\n";
           }
       auto E = gdopt.objective_value();
       energy_out << step << "," << E << "\n";
       }

与

auto result = minimize(gdopt);

minimize 返回一个

optimization_result<typename Optimizer::real_type_t>

, 即一个具有如下字段的结构:

size_t num_iter;
RealType objective_value;
std::vector<RealType> objective_history;
bool converged;

其中 num_iter 是优化器经历的迭代次数, objective_value 是最终目标值, objective_history 是中间目标值, converged 表示收敛判据是否满足. 默认情况下, minimize(optimizer) 使用梯度范数收敛判据. 若 norm(gradient_vector) < 1e-3, 则判据满足. 最大迭代次数设为 100000. 有关如何使用 minimize 的更多信息, 请查阅 minimize 文档. 使用默认参数, 梯度下降在 N=2 问题上用 93799 步完成求解.
