Math-4.2.1 (Boost-1.86)
  • 修正 Bessel 函数在无穷大处的结果, 见 1143.
  • 改善非中心 T 的数值稳定性, 见 scipy20693.
  • 修正 float_next/float_prior 在无穷大处的行为.
  • 防止非中心 beta 中的虚假下溢, 见 scipy20693.
  • 改进 Heuman Lambda 的精度.
  • 改进偏正态分布的求根, 见 1120.
  • 大量小修复与代码覆盖率提升.
Math-4.2.0 (Boost-1.85)
  • 增加对 Single objective real-parameter optimization: Algorithm jSO 的支持.
  • 增加对 Differential Evolution 的支持.
  • 在整个特殊函数范围内做了大量代码覆盖率与测试改进.
  • 让配置宏带上 BOOST_MATH_ 前缀, 这样当 Boost.Math 以独立方式使用但系统中存在 Boost.Config (可能还有其他库) 时, 就不会发生宏名冲突, 见 1098.
  • 针对最新编译器的 cstdfloat.hpp 小修复.
  • 提高 quartic_roots 的精度, 见 1055.
  • 允许在 Gauss-Kronrod 中使用非字面类型, 见 1077.
Math-4.1.1 (Boost-1.84)
  • 改进 ccmath 错误检测.
  • 移除已弃用的 std::numeric_limits<>::has_denorm 的使用, 见 1028.
  • 修正非中心 t 分布不收敛的缺陷, 见 1035.
  • 调整 Bessel 函数对 1F1 的近似, 避免在负整数处调用 tgamma, 见 1034.
  • 避免 ibeta 中的虚假上溢与除零, 见 1006.
  • 改进使用 Sterling 近似计算 tgamma 的精度, 完成 1007 开始的工作.
  • 修复大初始猜测值时 inverse_discrete_quantile 的问题, 见 1007.
  • 改进 Newton 求根, 见 1000.
  • 修复非零中心时 median_absolute_deviation 的问题, 见 997.
  • 为 gcc-14 修正 cstdfloat.hpp.
  • 更新以支持 <stdfloat> 中声明的新类型.
  • 把 hypergeometric_distribution 改用 64 位而非 32 位整数, 以避免不必要的上溢与使用限制.

  • 修复二项分布的边界情形.
  • 改进 ibeta 对极小参数的处理, 见 884.
  • 改进 ibeta 对无穷大与 NaN 的处理, 见 874.
  • 改进 powm1 的错误处理, 见 781.
  • 改进求根器的根区间界定, 在指数超大或超小时更快地界定根区间.
  • 修复求根边界情形, 见 873.
  • 大量杂项警告修复.
  • 在使用需要 C++17 的特性时添加断言, 以便在用较低标准版本调用编译器时得到更好的错误信息.
