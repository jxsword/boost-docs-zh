几何分布 

#include <boost/math/distributions/geometric.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class geometric_distribution;

typedef geometric_distribution<> geometric;

template <class RealType, class Policy>
class geometric_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;
   // Constructor from success_fraction:
   BOOST_MATH_GPU_ENABLED geometric_distribution(RealType p);

   // Parameter accessors:
   BOOST_MATH_GPU_ENABLED RealType success_fraction() const;
   BOOST_MATH_GPU_ENABLED RealType successes() const;

   // Bounds on success fraction:
   BOOST_MATH_GPU_ENABLED static RealType find_lower_bound_on_p(
      RealType trials,
      RealType probability); // alpha
   BOOST_MATH_GPU_ENABLED static RealType find_upper_bound_on_p(
      RealType trials,
      RealType probability); // alpha

   // Estimate min/max number of trials:
   BOOST_MATH_GPU_ENABLED static RealType find_minimum_number_of_trials(
      RealType k,     // Number of failures.
      RealType p,     // Success fraction.
      RealType probability); // Probability threshold alpha.
   BOOST_MATH_GPU_ENABLED static RealType find_maximum_number_of_trials(
      RealType k,     // Number of failures.
      RealType p,     // Success fraction.
      RealType probability); // Probability threshold alpha.
};

}} // namespaces

类类型geometric_distribution表示一个几何分布: 它用于Bernoulli 试验恰好有两种互斥结果的情形: 这两种结果分别标记为 "success" 与 "failure".

对于Bernoulli 试验, 每次成功比例为 p, 几何分布给出在首次成功之前观察到 k 次试验 (失败、事件、发生或到达) 的概率.

注释

对于本实现, 试验集合包含零 (不同于另一种定义, 那里的试验集合从 1 开始, 有时称为移位型).

几何分布假定 success_fraction p 对所有 k 次试验都是固定的.

在首次成功之前有 k 次失败的概率

Pr(Y=k) = (1-p)k p

例如, 掷一颗 6 面骰子时成功概率 p = 1/6 = 0.1666 ̇. 反复投掷直到出现三点, 掷出非三点的次数所服从的概率分布就是几何分布.

几何分布的概率密度函数 PDF 为:

(1-p)k p

下图说明当成功比例 p 取三个示例值时 PDF 与 CDF 如何变化 (把几何分布视为连续函数时),

以及视为离散函数时.

相关分布

几何分布是负二项分布在成功次数参数 r = 1 时的特例, 因此只需要第一个也是唯一一个成功: 于是按定义 geometric(p) == negative_binomial(1, p) 

negative_binomial_distribution(RealType r, RealType success_fraction);
negative_binomial nb(1, success_fraction);
geometric g(success_fraction);
ASSERT(pdf(nb, 1) == pdf(g, 1));

本实现在整个计算过程中都使用实数 (因为它使用了实值的幂函数与指数函数). 因此, 要得到传统的严格离散几何分布, 必须确保为试验次数 (随机变量) k 提供整数值, 并对返回成功次数的函数取整数值 (floor 或 ceil 函数).

注意

几何分布是一种离散分布: 在内部, 诸如cdf与pdf这样的函数被 "当作" 连续函数处理, 但实际上只有当随机变量参数提供整数值时, 这些函数返回的结果才有意义.

分位数函数默认返回向外取整后的整数结果. 也就是说, 下分位数 (概率小于 0.5) 向下取整, 上分位数 (概率大于 0.5) 向上取整. 这种行为确保当请求 X% 分位数时, 中心区域至少具有所请求的覆盖率, 而尾部至多具有所请求的覆盖率.

可以通过Policies改变这一行为, 使分位数函数采用不同的舍入方式, 甚至返回实值结果. 强烈建议在对几何分布使用分位数函数之前, 先阅读教程理解离散分布的分位数. 参考文档说明了如何更改这些分布的舍入策略.

成员函数
构造函数 
geometric_distribution(RealType p);

构造函数: p 或 success_fraction 是单次试验成功的概率.

要求: 0 <= p <= 1.

访问器 
RealType success_fraction() const; // successes / trials (0 <= p <= 1)

返回构造此分布所用的 success_fraction 参数 p.

RealType successes() const; // required successes always one,
// included for compatibility with negative binomial distribution
// with successes r == 1.

返回 1.

下列函数与为负二项分布提供的函数等价 (其中 successes = 1), 但此处提供它们只是为了完整性.

下列函数的最佳计算方法尚有争议: 更多讨论请参见二项分布与负二项分布.

success_fraction 参数 p 的下界
static RealType find_lower_bound_on_p(
  RealType trials,
  RealType alpha) // (0 <= alpha <= 1), 0.05 equivalent to 95% confidence.

返回成功比例的下界:

failures

第 1 次成功之前的失败总次数.

alpha

真实成功比例小于返回值的最大可接受概率.

例如, 如果你观察到 k 次失败 (来自 n 次试验), 那么成功比例的最佳估计就是 1/n; 但如果你想有 95% 的把握认为真值大于某个值 pmin, 那么:

pmin = geometric_distribution<RealType>::
   find_lower_bound_on_p(failures, 0.05);

参见负二项分布置信区间示例.

此函数使用 Clopper-Pearson 方法计算成功比例的下界; 尽管许多文献称该方法给出 "精确" 结果, 但实践中它产生的区间所保证的覆盖率至少满足要求, 并且对某些失败次数与成功次数的组合可能给出偏保守的估计. 参见:

Yong Cai and K. Krishnamoorthy, A Simple Improved Inferential Method for Some Discrete Distributions. Computational statistics and data analysis, 2005, vol. 48, no3, 605-621.

success_fraction 参数 p 的上界 
static RealType find_upper_bound_on_p(
   RealType trials,
   RealType alpha); // (0 <= alpha <= 1), 0.05 equivalent to 95% confidence.

返回成功比例的上界:

trials

进行的试验总次数.

alpha

真实成功比例大于返回值的最大可接受概率.

例如, 若你在 n 次试验中观察到 k 次成功, 成功比例的最佳估计就是 k/n; 但如果你想以 95% 的把握确信真实值小于某个值 pmax, 那么:

pmax = geometric_distribution<RealType>::find_upper_bound_on_p(
                    k, 0.05);

估计试验次数以确保至少达到一定数量的失败 
static RealType find_minimum_number_of_trials(
   RealType k,     // number of failures.
   RealType p,     // success fraction.
   RealType alpha); // probability threshold (0.05 equivalent to 95%).

此函数估计为达到某一概率所需的试验次数, 该概率是指观察到超过 k 次失败的概率.

k

希望观察到的失败次数目标值.

p

每次试验成功的概率.

alpha

可接受的最大风险, 即只观察到 k 次或更少失败.

例如:

geometric_distribution<RealType>::find_minimum_number_of_trials(10, 0.5, 0.05);

返回为了有 95% (1-0.05) 的把握看到 10 次以一半频率发生的失败, 我们必须进行的最少试验次数.

完整示例.

此函数通过对几何分布做数值反演来得到结果: 结果的另一种解释是, 它求出使得观察到 k 次或更少失败的概率为alpha的试验 (失败) 次数.

估计试验次数以确保最多只有一定数量的失败 
static RealType find_maximum_number_of_trials(
   RealType k,     // number of failures.
   RealType p,     // success fraction.
   RealType alpha); // probability threshold (0.05 equivalent to 95%).

此函数估计我们最多能进行多少次试验, 同时使观察到k 次或更少失败的概率达到某一给定值.

k

允许观察到的最大失败次数.

p

每次试验成功的概率.

alpha

可接受的最大风险, 即观察到超过 k 次失败.

例如:

geometric_distribution<RealType>::find_maximum_number_of_trials(0, 1.0-1.0/1000000, 0.05);

返回我们最多能进行多少次试验, 同时仍有 95% 的把握看不到以百万分之一频率发生的失败.

此函数通过对几何分布做数值反演来得到结果: 结果的另一种解释是, 它求出使得观察到超过 k 次失败的概率为alpha的试验次数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

不过, 有必要花一点时间说明这些术语在此分布的语境下究竟意味着什么:

表 5.2. 非成员访问函数的含义.

函数

含义

Probability Density Function

恰好 k 次失败的概率, 即从 k 次成功比例为 p 的试验中得到的概率. 例如:

pdf(geometric(p), k)

Cumulative Distribution Function

k 次或更少失败的概率, 即从 k 次成功比例为 p 且最后一次试验成功的试验中得到的概率. 例如:

cdf(geometric(p), k)

累积分布函数的补

超过 k 次失败的概率, 即从 k 次成功比例为 p 且最后一次试验成功的试验中得到的概率. 例如:

cdf(complement(geometric(p), k))

Quantile

最多的失败次数 k, 预期在 k 次成功比例为 p 的试验中观察到, 概率为 P. 注意返回的值是实数而非整数. 视使用场景, 你可能需要对该实数结果取 floor 或 ceiling. 例如:

quantile(geometric(p), P)

由概率的补求 Quantile

最少的失败次数 k, 预期在 k 次成功比例为 p 的试验中观察到, 概率为 P. 注意返回的值是实数而非整数. 视使用场景, 你可能需要对该实数结果取 floor 或 ceiling. 例如:

quantile(complement(geometric(p), P))

在此分布中, logcdf 的实现经过专门化, 以提高数值精度.

精度

此分布使用 pow 与 exp 函数实现, 因此大多数结果在 RealType 的若干 epsilon 以内是精确的. 对于 double p 的极端取值, 例如 0.9999999999, 精度可能显著下降, 例如降到 10 位十进制数字 (原为 16 位).
