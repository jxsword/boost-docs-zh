这实际上完成了所用的"直接"方法, 其余区域则通过递推关系间接处理. 使用递推关系需要极其小心, 因为它们常常会改变稳定方向, 或者根本不稳定. 有时这是方向上明确而可刻画的改变: 例如当 a,b 和 z 都为正时, 沿 a 通过

的递推会在 2a-b+z 变号时从稳定的前向递推骤变为稳定的后向递推. 因此, 沿 a 的递推, 即便 1F1(a+N, b, z) 严格递增, 当 a → 0 时也需要谨慎处理.

稳定递推关系的这种过渡特性在文献中有充分记载, 例如 (10) 给出了许多例子, 包括首次由 Gauchi 记载的沿 a 和 b 在大 z 下递推的反常行为, 见 (12). Gauchi 还在 (11) 中提供了关于三项递推关系的权威参考文献.

遗憾的是, 并非所有递推稳定性都定义得如此清晰. 例如, 在考虑 1F1(a, -b, z) 时, 使用与递推关系相关联的连分数来计算 1F1(a, -b, z) / 1F1(a, 1-b, z) 会很方便, 然后或者通过沿 b 前向迭代直到 b > 0 并与参考值比较来归一化, 或者使用 Wronskian 来归一化

这当然就是众所周知的 Miller 方法 (12).

遗憾的是, 沿 b 的稳定前向递推只在 |b| << |z| 时稳定; 随着 |b| 数值增大, 它会经过一个双向都不稳定的区域, 最终才变为后向稳定 (至少能稳定一阵子!). 这一过渡并非由递推系数本身变号所主导, 而是由 值 发生变化所主导 - 1F1 从 |b| 较小时的符号交替变为 b 较大时的符号相同. 在实际过渡期间, 1F1 会经过一个零点或极小值, 取决于 b 是偶数还是奇数 (若在 1F1(a, b, z) 处存在极小值, 则在 1F1(a+1, b+1, z) 处必有零点, 参见 该函数的导数). 结果是, 在这一区域内几乎无法对递推关系的行为进行推理, 我们只能依靠启发式方法来"猜测"所处的区域.

在本实现中, 我们按如下方式使用递推关系:

对于大且为正的 a,b,z > 0, 我们可以:

  • 使 0 < a < 1 且 b > z, 然后直接求值定义级数, 或者
  • gamma 函数近似在 2b - 1 < a < 2b < z 上有良好的收敛性和精度, 因此我们可以把 a 和 b 移入该区域, 或者
  • 我们可以只沿 b 递推, 使 b-1 < a < b, 并且只要 z 不太大, 就可使用 A&S 13.3.6.

对于 b < 0 且 a 极小的情形, 我们通常会使用 A&S 13.3.6, 但当它对某些输入不收敛时, 可以使用沿 b 的前向递推关系计算比值 1F1(a, -b, z)/1F1(a, 1-b, z), 然后前向迭代直到 b > 0, 再计算参考值并归一化 (Miller 方法). 在同一区域内, 当 b 接近 -1 时, 可以对 b 使用一次后向递推来计算 1F1(a, -b, z), 从 1F1(a, 2-b, z) 和 1F1(a, 1-b, z) 出发, 尽管严格来说我们是在不稳定方向上递推.

对于 1F1(-N, b, z) 且 N 为整数的情形, 从 1F1(0, b, z) 和 1F1(-1, b, z) 出发的后向递推效果良好.

当 a 或 b < 0 且所有直接方法都失败时, 我们会使用各种后备方案:

对于 1F1(-a, b, z), 只要 b > z, 就可以对 a 使用后向递推; 否则需要一个更复杂的方案: 从 1F1(-a + N, b + M, z) 出发, 以最多 3 个阶段后向递推: 先沿 a, 然后同时沿 a 和 b, 最后只沿 b.

对于 b < 0, 我们在某些区域没有好方法 (参见上面的未解决问题). 不过在某些情况下, 我们可以采用:

  • 如上的三阶段后向递推: 先沿 a, 再同时沿 a 和 b, 最后沿 b.
  • 当 z 较小时, 通过后向递推计算比值 1F1(a, b, z) / 1F1(a-1, b-1, z), 然后用上述 Wronskian 归一化 (Miller 方法).
  • 当 z 较大时, 通过前向递推计算比值 1F1(a, b, z) / 1F1(a+1, b+1, z), 然后迭代直到 b > 1 并与参考值比较来归一化.

后两种方法使用查找表来判定输入属于哪个区域或都不属于. 遗憾的是, 这些方法基本只限于双精度: 比值的计算需要迭代 towards 两方法之间的无人区, 在那里双向迭代都不稳定. 因此, 只能提供需要少量迭代即可算出比值的低精度结果.

如果其他方法都失败, 那么使用带检查的级数求和; 若因相消而损失超过一半的数字, 它将抛出 evaluation_error.
