#include <boost/math/special_functions/expint.hpp>

namespace boost{ namespace math{

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type expint(unsigned n, T z);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type expint(unsigned n, T z, const Policy&);

}} // namespaces

这些函数的返回类型使用 结果类型计算规则 计算: 若 T 是整数类型, 返回类型为 double, 否则为 T.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

测试

这些函数的测试分为两部分: 基本健全性检查使用 Mathworld 在线求值器 计算的抽检值, 而精度检查使用 1000 位精度的 NTL::RR 与本实现计算的高精度测试值. 注意这些函数的通用版本与类型特定版本在内部使用不同的实现, 因此这为我们提供了合理独立的测试数据. 用我们的测试数据测试其他"已知正确"的实现也提供了额外的健全性检查.
