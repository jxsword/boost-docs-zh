非中心 F 分布

非中心 F 分布是 Fisher F 分布 的推广. 它定义为比值

F = (X/v1) / (Y/v2)

其中 X 是非中心 χ2 随机变量, 具有 v1 个自由度, 非中心性参数为 λ; 而 Y 是中心 χ2 随机变量, 具有 v2 个自由度.

BOOST_MATH_GPU_ENABLED static RealType find_non_centrality(const RealType x, const RealType v1, const RealType v2, const RealType p);

此函数返回非中心性参数 lambda, 使得:

cdf(non_central_chi_squared<RealType, Policy>(v1, v2, lambda), x) == p 

template <class A, class B, class C, class D>
BOOST_MATH_GPU_ENABLED static RealType find_non_centrality(const complemented4_type<A,B,C,D>& c);

以参数 boost::math::complement(x, v1, v2, q) 调用时, 此函数返回非中心性参数 lambda, 使得:

cdf(complement(non_central_chi_squared<RealType, Policy>(v1, v2, lambda), x)) == q.

成员函数 
BOOST_MATH_GPU_ENABLED non_central_f_distribution(RealType v1, RealType v2, RealType lambda);

构造一个参数为 v1 与 v2、非中心性参数为 lambda 的非中心 beta 分布.

要求 v1 > 0, v2 > 0 且 lambda >= 0, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom1()const;

返回构造此对象所用的参数 v1.

BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom2()const;

返回构造此对象所用的参数 v2.

BOOST_MATH_GPU_ENABLED RealType non_centrality()const;

返回构造此对象所用的非中心性参数 lambda.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域是 [0, +∞].

精度

此分布借助 非中心 Beta 分布 实现: 精度数据请参见该分布.

测试

由于此分布是通过改造另一个分布实现的, 因此测试由 R-2.5.1 Math library statistical package 及其 pbeta 与 dbeta 函数计算的基本合理性检查组成.

实现

在下表中, v1 与 v2 是分布的第一与第二自由度参数, λ 是非中心性参数, x 是随机变量, p 是概率, 而 q = 1-p.

函数

实现说明

pdf

借助非中心 beta PDF 使用以下关系式实现:

f(x;v1,v2;λ) = (v1/v2) / ((1+y)*(1+y)) * g(y/(1+y);v1/2,v2/2;λ)

其中 g(x; a, b; λ) 是非中心 beta PDF, 并且:

y = x * v1 / v2

cdf

利用关系:

p = By(v1/2, v2/2; λ)

其中 Bx(a, b; λ) 是非中心 beta 分布 CDF, 并且

y = x * v1 / v2

cdf 补函数

利用关系:

q = 1 - By(v1/2, v2/2; λ)

其中 1 - Bx(a, b; λ) 是非中心 beta 分布 CDF 的补, 并且

y = x * v1 / v2

quantile

利用关系:

x = (bx / (1-bx)) * (v1 / v2)

其中

bx = Qp-1(v1/2, v2/2; λ)

以及

Qp-1(v1/2, v2/2; λ)

是非中心 beta 分位数.

quantile

由补函数

利用关系:

x = (bx / (1-bx)) * (v1 / v2)

其中

bx = QCq-1(v1/2, v2/2; λ)

以及

QCq-1(v1/2, v2/2; λ)

是非中心 beta 分位数的补.

均值

v2 * (v1 + l) / (v1 * (v2 - 2))

众数

通过对 PDF 求数值极值.
