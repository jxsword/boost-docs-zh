第一类和第二类 Bessel 函数

概要

#include <boost/math/special_functions/bessel.hpp> 

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_bessel_j(T1 v, T2 x);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_bessel_j(T1 v, T2 x, const Policy&);

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_neumann(T1 v, T2 x);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_neumann(T1 v, T2 x, const Policy&);
说明

函数 cyl_bessel_j 和 cyl_neumann 分别返回第一类和第二类 Bessel 函数的结果:

cyl_bessel_j(v, x) = Jv(x)

cyl_neumann(v, x) = Yv(x) = Nv(x)

其中:

当 T1 和 T2 为不同类型时, 这些函数的返回类型按照 结果类型计算规则 计算. 对于 T1 为整数这一较常见情形, 这些函数也做了优化.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

只要结果未定义或为复数, 这些函数就返回 domain_error 的结果. 对于 cyl_bessel_j 当 x < 0 且 v 不是整数, 或当 x == 0 且 v != 0 时会出现这种情况. 对于 cyl_neumann 当 x <= 0 时会出现.

实现

该实现主要在于过滤掉各种特殊情形:

当 x 为负时, 阶 v 必须是整数, 否则结果为定义域错误. 若阶为整数, 则函数对奇数阶是奇函数、对偶数阶是偶函数, 因此我们把它反射到 x > 0.

当阶 v 为负时, 可以用反射公式转移到 v > 0:

注意, 如果阶为整数, 那么这些公式可化简为:

J-n = (-1)nJn

Y-n = (-1)nYn

然而, 一般而言, 负阶意味着我们需要同时计算 J 和 Y.

当 x 相对于阶 v 较大时, 采用适用于大 x 的 M. Abramowitz 和 I.A. Stegun 《Handbook of Mathematical Functions》 9.2.19 中的渐近展开 (经验证这些展开比 A&S 9.2.5 中的更可靠).

当阶 v 为整数时, 该方法首先把结果关联到 J0, J1, Y0 和 Y1, 依据稳定性选用前向或后向递推 (Miller 算法) 之一. 而 J0, J1, Y0 和 Y1 的值, 在 |x| 较小时用根区间界定区间上的有理 minimax 逼近计算, 在 |x| 较大时用 Hankel 渐近展开. 系数来自:

W.J. Cody, ALGORITHM 715: SPECFUN - A Portable FORTRAN Package of Special Function Routines and Test Drivers, ACM Transactions on Mathematical Software, vol 19, 22 (1993).

以及

J.F. Hart et al, Computer Approximations, John Wiley & Sons, New York, 1968.

这些逼近精确到约 19 位十进制数字: 因此当类型 T 的二进制位数超过 64 时不使用这些方法.

当 x 小于机器 epsilon 时, 可以使用以下针对 Y0(x), Y1(x), Y2(x) 和 Yn(x) 的逼近 (见: http://functions.wolfram.com/03.03.06.0037.01, http://functions.wolfram.com/03.03.06.0038.01, http://functions.wolfram.com/03.03.06.0039.01 和 http://functions.wolfram.com/03.03.06.0040.01):

当 x 相对于 v 较小且 v 不是整数时, 可以对 Yv(x) 使用以下级数逼近; 这也是其他逼近常常收敛太慢而无法使用的领域 (见 http://functions.wolfram.com/03.03.06.0034.01):

当 x 相对于 v 较小时, Jvx 最好直接用级数计算:

一般情形下, 我们同时计算 Jv 和 Yv.

为得到初始值, 令 μ = ν - floor(ν + 1/2), 则 μ 是 ν 的小数部分, 满足 |μ| <= 1/2 (后面收敛时需要这一点). 思路是计算 Jμ(x), Jμ+1(x), Yμ(x), Yμ+1(x), 再用它们得到 Jν(x), Yν(x).
