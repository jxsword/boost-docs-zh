Weibull 分布 

#include <boost/math/distributions/weibull.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class weibull_distribution;

typedef weibull_distribution<> weibull;

template <class RealType, class Policy>
class weibull_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;
   // Construct:
   BOOST_MATH_GPU_ENABLED weibull_distribution(RealType shape, RealType scale = 1)
   // Accessors:
   BOOST_MATH_GPU_ENABLED RealType shape()const;
   BOOST_MATH_GPU_ENABLED RealType scale()const;
};

}} // namespaces

Weibull 分布是一种具有如下 概率密度函数的连续分布:

f(x; α, β) = (α/β) * (x / β)α - 1 * e-(x/β)α

形状参数 α > 0, 尺度参数 β > 0, 且 x > 0.

Weibull 分布常用于故障分析领域; 特别是它可以模拟故障率随时间变化的分布. 如果故障率:

  • 随时间恒定, 则 α = 1, 表明物品因随机事件而失效.
  • 随时间递减, 则 α < 1, 表明"早期失效" (infant mortality).
  • 随时间递增, 则 α > 1, 表明"磨损" — 随时间推移更可能失效.

相关分布

当 α = 3 时, Weibull 分布看起来与 正态分布相似. 当 α = 1 时, Weibull 分布退化为 指数分布. Weibull 只是极值分布类型之一, 这些类型之间的关系在 Extreme Value Distributions, Theory and Applications Samuel Kotz & Saralees Nadarajah 中有讨论.

成员函数 
BOOST_MATH_GPU_ENABLED weibull_distribution(RealType shape, RealType scale = 1);

构造一个 Weibull 分布, 形状为 shape, 尺度为 scale.

要求 shape 与 scale 参数均大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType shape()const;

返回此分布的shape参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的scale参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [0, ∞].

在此分布中, logcdf 和 logpdf 的实现都做了专门化以提升数值精度.

精度

Weibull 分布基于标准库 log 与 exp 函数以及 expm1 与 log1p 实现, 因此误差率应当极低.

实现

在下表中, α 是分布的形状参数, β 是其尺度参数, x 是随机变量, p 是概率, q = 1-p 是其补.

函数

实现说明

pdf

使用关系式: pdf = αβ-α xα - 1 e-(x/beta)alpha

logpdf

log(pdf) = log(α) - α * log(β) + log(x) * (α-1) - pow(x/β, α)

cdf

使用关系式: p = -expm1(-(x/β)α)

logcdf

log(cdf) = log1p(-exp(-pow(x / β, α)))

cdf 补函数

使用关系式: q = e-(x/β)α

quantile

使用关系式: x = β * (-log1p(-p))1/α

由补函数求 quantile

使用关系式: x = β * (-log(q))1/α

均值

β * Γ(1 + 1/α)

方差

β2(Γ(1 + 2/α) - Γ2(1 + 1/α))

众数

β((α - 1) / α)1/α
