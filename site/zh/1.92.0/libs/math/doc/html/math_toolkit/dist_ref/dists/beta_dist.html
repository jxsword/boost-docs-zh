Beta 分布 

#include <boost/math/distributions/beta.hpp>
namespace boost{ namespace math{

 template <class RealType = double,
           class Policy   = policies::policy<> >
class beta_distribution;

// typedef beta_distribution<double> beta;
// Note that this is deliberately NOT provided,
// to avoid a clash with the function name beta.

template <class RealType, class Policy>
class beta_distribution
{
public:
   typedef RealType  value_type;
   typedef Policy    policy_type;
   // Constructor from two shape parameters, alpha & beta:
   BOOST_MATH_GPU_ENABLED beta_distribution(RealType a, RealType b);

   // Parameter accessors:
   BOOST_MATH_GPU_ENABLED RealType alpha() const;
   BOOST_MATH_GPU_ENABLED RealType beta() const;

   // Parameter estimators of alpha or beta from mean and variance.
   BOOST_MATH_GPU_ENABLED static RealType find_alpha(
     RealType mean, // Expected value of mean.
     RealType variance); // Expected value of variance.

   BOOST_MATH_GPU_ENABLED static RealType find_beta(
     RealType mean, // Expected value of mean.
     RealType variance); // Expected value of variance.

   // Parameter estimators from
   // either alpha or beta, and x and probability.

   BOOST_MATH_GPU_ENABLED static RealType find_alpha(
     RealType beta, // from beta.
     RealType x, //  x.
     RealType probability); // cdf

   BOOST_MATH_GPU_ENABLED static RealType find_beta(
     RealType alpha, // alpha.
     RealType x, // probability x.
     RealType probability); // probability cdf.
};

}} // namespaces

类类型 beta_distribution 表示一个beta 概率分布函数.

beta distribution 在贝叶斯分析中用作二项比例的先验分布.

另见: beta distribution 和 Bayesian statistics.

Jeff Grynaviski 讨论了 beta 分布如何用于单参数模型的贝叶斯分析.

定义在区间 [0,1] 上的 beta distribution 的概率密度函数 PDF 由下式给出:

f(x;α,β) = xα - 1 (1 - x)β -1 / B(α, β)

其中 B(α, β) 是beta 函数, 在本库中实现为 beta. 除以 beta 函数可确保 pdf 归一化到 0 到 1 的范围.

下图展示了形状参数取不同值时 pdf 的几个示例. 注意 α = β = 2 (蓝线) 呈拱形, 可以用对称三角形分布近似.

若 α = β = 1, 则它是均匀分布, 在整个区间 x = 0 到 1 上等于 1. 若 α 和 β 均小于 1, 则 pdf 呈 U 形. 若 α ≠ β, 则形状不对称, 可以用以顶点偏离中心 (x = 中点处) 的三角形近似.

成员函数
构造函数 
BOOST_MATH_GPU_ENABLED beta_distribution(RealType alpha, RealType beta);

构造具有形状参数 alpha 和 beta 的 beta 分布.

要求 alpha、beta > 0, 否则调用 domain_error. 注意, 从技术上讲 beta 分布对 alpha、beta >= 0 都有定义, 但尚不清楚是否有程序真能利用这一宽松条件, 或者在此情形下还有多少非成员函数能被有效地定义. 因此目前我们把 alpha 或 beta 为零视为错误.

例如:

beta_distribution<> mybeta(2, 5);

构造 alpha=2、beta=5 的 beta 分布 (见上图中的黄线).

参数访问器 
BOOST_MATH_GPU_ENABLED RealType alpha() const;

返回构造此分布时使用的参数 alpha.

BOOST_MATH_GPU_ENABLED RealType beta() const;

返回构造此分布时使用的参数 beta.

例如:

beta_distribution<> mybeta(2, 5);
assert(mybeta.alpha() == 2.);  // mybeta.alpha() returns 2
assert(mybeta.beta() == 5.);   // mybeta.beta()  returns 5
参数估计器

提供了两对参数估计器.

其中一对由假定的已知均值和方差估计 α 或 β.

另一对由 cdf 和 x 估计 α 或 β.

也可以从“已知”的众数与分位数估计 α 和 β. 例如, Pooled Prevalence Calculator 和 Beta Buster 提供了计算器, 但此处尚未实现.

static RealType find_alpha(
  RealType mean, // Expected value of mean.
  RealType variance); // Expected value of variance.

返回对应于均值 mean 和方差 variance 的 beta 分布的 α 的唯一值.

static RealType find_beta(
  RealType mean, // Expected value of mean.
  RealType variance); // Expected value of variance.

返回对应于均值 mean 和方差 variance 的 beta 分布的 β 的唯一值.

static RealType find_alpha(
  RealType beta, // from beta.
  RealType x, //  x.
  RealType probability); // probability cdf

返回使下式成立的 α 的值: cdf(beta_distribution<RealType>(alpha, beta), x) == probability.

static RealType find_beta(
  RealType alpha, // alpha.
  RealType x, // probability x.
  RealType probability); // probability cdf.

返回使下式成立的 β 的值: cdf(beta_distribution<RealType>(alpha, beta), x) == probability.

非成员访问函数

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

应用

beta 分布可用于建模被限定在由最小值和最大值定义的区间内发生的事件: 因此它被用于项目管理系统.

它也广泛用于贝叶斯统计推断.

相关分布

α 和 β 都为 1 的 beta 分布服从均匀分布.

当可用的信息不太精确时, 使用三角分布.

当 α 和 β 为整数时, 与二项分布密切相关.

当 α 和 β 为整数时, 分布 B(i, j) 就是 i + j + 1 个独立同分布于 [0, 1] 均匀分布的随机变量中第 j 大的那个值的分布. 因此从 0 到 x 的累积概率就是第 j 大的值小于 x 的概率; 或者说, 是至少 i 个随机变量小于 x 的概率, 该概率可通过对其 p 参数设为 x 的Binomial Distribution求和得到.

精度

此分布使用beta 函数 beta 以及不完全 beta 函数 ibeta 和 ibetac 实现; 精度信息请参阅这些函数.
