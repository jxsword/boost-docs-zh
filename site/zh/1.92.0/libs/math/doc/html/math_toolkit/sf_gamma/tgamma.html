说明 
template <class T>

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type tgamma(T z, const Policy&);

返回值 z 的"真 gamma 函数" (tgamma 这个名字由此而来):

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

本函数的返回类型使用 结果类型计算规则 计算: 当 T 是整数类型时, 结果为 double; 否则为 T.

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type tgamma1pm1(T dz);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type tgamma1pm1(T dz, const Policy&);

返回 tgamma(dz + 1) - 1. 实现内部并未利用定义所隐含的加法和减法, 因此即使对于非常小的 dz 也能得到准确的结果.

本函数的返回类型使用 结果类型计算规则 计算: 当 T 是整数类型时, 结果为 double; 否则为 T.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

测试

gamma 函数相对容易测试: 阶乘和半整数阶乘可以用其他方法精确计算, 并与 gamma 函数进行比较. 此外, 一些已知困难区域的精度测试是使用本函数的通用版本以高精度计算出来的.

函数 tgamma1pm1 的测试针对用公式 tgamma(1+dz)-1 非常朴素地计算出的值, 所用 lanczos 近似精确到约 100 位十进制数字.

会被使用. 计算 z * sin(π * z) 部分时必须特别小心: 在乘以 π 之前, 会用一个专门的例程先对 z 进行归约, 以确保结果落在 [0, π/2] 范围内. 否则, 该区域会出现过多的误差 (该区域本来就够难了, 因为负极点附近的变化率 异常 之高).

最后, 如果参数是一个小整数, 则使用阶乘的查表.

函数 tgamma1pm1 使用 由 JM 设计 的有理近似在区域 -0.5 < dz < 2 中实现. 这些近似 (以及内部例程) 与 lgamma 所用的相同, 因此这里不再详述. 近似的结果是 log(tgamma(dz+1)), 可将其送入 expm1 得到所需结果. 在范围 -0.5 < dz < 2 之外, 可以直接使用朴素公式 tgamma1pm1(dz) = tgamma(dz+1)-1.
