相对误差与测试

概要 
#include <boost/math/tools/test.hpp>
重要

头文件 boost/math/tools/test.hpp 位于 libs/math/include_private 下, 默认不会安装到通常位置; 要使用该头文件, 你需要把 libs/math/include_private 加入到编译器的包含路径中.

template <class T>
T relative_error(T a, T b);

template <class A, class F1, class F2>
test_result<see-below> test(const A& a, F1 test_func, F2 expect_func);
说明 
template <class T>
T relative_error(T a, T v);

使用通常的公式返回 a 与 v 之间的相对误差:

此外, 如果满足以下条件, 则返回的值为零:

  • a 和 v 均为无穷大.
  • a 和 v 均为非规格化数或零.

否则, 如果 a 和 v 中只有一个为零, 则返回值为 1.

template <class A, class F1, class F2>
test_result<see-below> test(const A& a, F1 test_func, F2 expect_func);

该函数用于对照表格化的测试数据来测试某个函数.

返回类型包含相对误差的统计数据 (最大值、均值、方差以及测试用例数等), 以及造成最大相对误差的那一行测试数据. test_result 类型的公有成员有:

unsigned worst()const;

返回出现最差误差的那一行.

T min()const;

返回所找到的最小相对误差.

T max()const;

返回所找到的最大相对误差.

T mean()const;

返回所找到的误差均值.

std::uintmax_t count()const;

返回测试用例数.

T variance()const;

返回所找到误差的方差.

T variance1()const;

返回所找到误差的无偏方差.

T rms()const

返回误差的均方根, 或称二次平均.

test_result& operator+=(const test_result& t)

把两个 test_result 合并为一个结果.

test_result 的模板参数与传给函数 test 的二维数组中元素的类型相同, 大致就是 A::value_type::value_type.

参数 a 是测试数据矩阵: 它必须是标准库的 Sequence 类型, 其中包含另一个 Sequence 类型: 通常是 std::array 的二维实例. a 的每一行都应包含传给被测函数的所有参数以及期望结果.

参数 test_func 是被测函数, 它会以 a 中的每一行测试数据来调用. 类型 F1 通常用 Boost.Lambda 创建: 见下面的示例.

参数 expect_func 是一个函数对象, 它从 a 中的一行测试数据里提取期望结果. 类型 F2 通常用 Boost.Lambda 创建: 见下面的示例.

如果被测函数在期望有限结果时返回非有限值, 或者发现严重误差, 则会向 std::cerr 发送一条消息, 并调用 BOOST_ERROR() (这意味着包含该头文件要求你使用 Boost.Test). 这主要是一种调试/开发辅助手段 (也是设置断点的好地方).

示例

假设我们想测试 tgamma 和 lgamma 函数, 我们可以创建一个二维测试数据矩阵, 每一行是一个测试用例, 包含三个元素: 输入值, 以及分别对应 tgamma 和 lgamma 函数的期望结果.

static const std::array<std::array<TestType, 3>, NumberOfTests>
   factorials = {
      /* big array of test data goes here */
   };

现在我们可以调用测试函数来测试 tgamma:

using namespace boost::math::tools;
using namespace boost::lambda;

// get a pointer to the function under test:
TestType (*funcp)(TestType) = boost::math::tgamma;

// declare something to hold the result:
test_result<TestType> result;
//
// and test tgamma against data:
//
result = test(
   factorials,
   bind(funcp, ret<TestType>(_1[0])), // calls tgamma with factorials[row][0]
   ret<TestType>(_1[1])               // extracts the expected result from factorials[row][1]
);
//
// Print out some results:
//
std::cout << "The Mean was " << result.mean() << std::endl;
std::cout << "The worst error was " << (result.max)() << std::endl;
std::cout << "The worst error was at row " << result.worst_case() << std::endl;
//
// same again with lgamma this time:
//
funcp = boost::math::lgamma;
result = test(
   factorials,
   bind(funcp, ret<TestType>(_1[0])), // calls tgamma with factorials[row][0]
   ret<TestType>(_1[2])               // extracts the expected result from factorials[row][2]
);
//
// etc ...
//
