Boost 提供的 tanh-sinh 求积例程是一种针对全纯被积函数的快速收敛数值积分格式. 我们的意思是, 被积函数是某个复可微函数在实数轴上的限制, 且该函数在单位圆盘 |z| < 1 内部有界, 因而属于所谓的 Hardy 空间. 若你的被积函数满足这些条件, 可以证明 tanh-sinh 积分是最优的: 对于 Hardy 空间中的随机元素, 在给定精度下它所需的函数求值次数少于任何其他求积算法.

下面展示了使用 tanh-sinh 求积的一个基本示例:

tanh_sinh<double> integrator;
auto f = [](double x) { return 5*x + 7; };
// Integrate over native bounds of (-1,1):
double Q = integrator.integrate(f);
// Integrate over (0,1.1) instead:
Q = integrator.integrate(f, 0.0, 1.1);

tanh-sinh 求积的基本思想是: 变量变换可以使端点处的导数迅速衰减. 当端点处的导数比 Bernoulli 数的增长衰减得快得多时, Euler-Maclaurin 求和公式告诉我们, 简单的梯形求积会比 h 的任何幂次收敛得更快. 这意味着结果的正确位数大约随每升一级积分 (h 减半) 而翻倍. 因此积分的默认终止条件通常设为机器 epsilon 的平方根. 大多数行为良好的积分在此终止条件下应收敛到完整的机器精度, double 精度下 6 级或更少, quad 精度下 7 级或更少.

tanh-sinh 求积有一个非常好的性质: 它可以处理积分区域端点处的奇点. 例如, 以下被积函数在两个端点处都有奇点, 却可以高效地求值到 100 个二进制位:

auto f = [](Real x) { return log(x)*log1p(-x); };
Real Q = integrator.integrate(f, (Real) 0, (Real) 1);

接下来是注意事项: 如前所述, 被积函数必须属于 Hardy 空间才能保证快速收敛. 试图用 tanh-sinh 积分在单位圆盘上无界的函数可能导致非常慢的收敛. 例如, 取 Runge 函数:

auto f1 = [](double t) { return 1/(1+25*t*t); };
Q = integrator.integrate(f1, (double) -1, (double) 1);

该函数在 ± ⅈ/5 处有极点, 因此在单位圆盘上无界. 然而, 相关函数

auto f2 = [](double t) { return 1/(1+0.04*t*t); };
Q = integrator.integrate(f2, (double) -1, (double) 1);

的极点在单位圆盘之外 (± 5ⅈ 处), 因而在 Hardy 空间中. 我们的基准测试表明, 第二个积分的执行速度比第一个快 22 倍! 如果你不理解被积函数在复平面上的结构, 请在部署前做性能测试.

与梯形求积一样, tanh-sinh 求积在给出所求积分的同时, 还产生积分的 L1 范数的估计. 这是为了建立一个衡量容差的尺度, 并提供求和条件数的估计. 可以按如下方式查询:

tanh_sinh<double> integrator;
auto f = [](double x) { return 5*x + 7; };
double termination = std::sqrt(std::numeric_limits<double>::epsilon());
double error;
double L1;
size_t levels;
double Q = integrator.integrate(f, 0.0, 1.0, termination, &error, &L1, &levels);
double condition_number = L1/std::abs(Q);

如果条件数很大, 计算出的积分就毫无价值: 通常可以假定, 当条件数为 O(10^Q) 时, Q 已损失一位精度. 返回的误差项不是结果的实际误差, 而只是事后误差估计. 它是最后两次近似之间的绝对差, 对于表现良好的积分, 实际误差应远小于此. 下表展示了几个示例积分的误差与条件数的变化情况, 每种情况下终止条件都设为 epsilon 的平方根, 且所有测试都在 double 精度下进行:

尽管 tanh-sinh 求积可以通过变量变换计算无穷域上的积分, 但这些变换可能制造出表现极差的被积函数. 出于这个原因, 我们提供了可以在无穷域上稳定计算的双指数变量变换, 即 exp-sinh 与 sinh-sinh 求积.

复积分

tanh_sinh 积分器支持对返回复结果的函数积分, 例如正弦积分 Si(z) 具有积分表示:

我们可以直接写成如下代码:

template <class Complex>
Complex Si(Complex z)
{
   typedef typename Complex::value_type value_type;
   using std::sin;  using std::cos; using std::exp;
   auto f = [&z](value_type t) { return -exp(-z * cos(t)) * cos(z * sin(t)); };
   boost::math::quadrature::tanh_sinh<value_type> integrator;
   return integrator.integrate(f, 0, boost::math::constants::half_pi<value_type>()) + boost::math::constants::half_pi<value_type>();
}
