策略有合理的默认值

大多数时候, 你可以完全忽略策略框架.

*各策略的默认值如下, 如果这些默认值对你没问题, 那么现在就可以停止阅读了!

定义域错误

抛出 std::domain_error 异常.

极点错误

当在极点处对函数求值时发生: 抛出 std::domain_error 异常.

上溢错误

抛出 std::overflow_error 异常.

下溢

忽略下溢并返回零.

非规格化结果

忽略结果是非规格化的事实并返回它.

舍入错误

抛出 boost::math::rounding_error 异常.

内部求值错误

抛出 boost::math::evaluation_error 异常.

不确定结果错误

返回取决于发生错误的函数的结果.

float 提升为 double

默认会发生 - 给出完整 float 精度的结果.

double 提升为 long double

默认情况下, 如果 long double 比 double 精度更高, 则会发生.

所用近似的精度

默认使用对结果类型而言误差最低的近似.

离散分位数的行为

分位数函数默认返回向外取整后的整数结果. 也就是说, 下分位数 (概率小于 0.5) 向下取整, 上分位数 (概率大于 0.5) 向上取整. 这种行为确保当请求 X% 分位数时, 中心区域至少具有所请求的覆盖率, 而尾部至多具有所请求的覆盖率.

可以使用 Policies 更改此行为, 使分位数函数以不同方式舍入, 甚至返回实数值结果. 强烈建议在离散分布上使用分位数函数之前阅读教程 Understanding Quantiles of Discrete Distributions. reference docs 描述了如何更改这些分布的舍入策略.

此外, 如果你定义自己的策略类型, 它会自动继承未显式设置的任何策略的默认值, 因此给定:

using namespace boost::math::policies;
//
// Define a policy that sets ::errno on overflow, and does
// not promote double to long double internally:

typedef policy
<
  domain_error<errno_on_error>,
  promote_double<false>
> my_policy;

则 my_policy 定义了一个策略, 其中只有上溢错误处理和 double 提升策略与默认值不同.

我们还可以向错误处理策略添加所需的精度, 例如 9 位二进制或 3 位十进制数字, 通常是为了用精度换速度:

typedef policy<domain_error<errno_on_error>, digit2<9> > my_policy;

或者, 如果想进一步修改现有的用户策略, 使用 normalise:

using boost::math::policies::normalise;

typedef normalise<my_policy, digits2<9>>::type my_policy_9; // errno on error, and limited precision.
