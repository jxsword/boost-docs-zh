Boost.Math 对 GPU 编程的支持

GPU 支持

精选的函数、分布、工具等同时支持在主机与设备上运行. 这些函数的各自文档旁会标注 BOOST_MATH_GPU_ENABLED 或 BOOST_MATH_CUDA_ENABLED. 标注为 BOOST_MATH_GPU_ENABLED 的函数使用 CUDA (NVCC 与 NVRTC) 以及 SYCL 测试, 以提供广泛的支持. 标注为 BOOST_MATH_CUDA_ENABLED 的函数数量很少, 但由于其限制, SYCL 不受支持.

策略

所有设备上的默认策略都是忽略错误, 因为设备缺乏抛异常的能力. 用户可以像往常一样指定自己的策略, 但当代码在设备上运行时它会被忽略.

如何以设备支持进行构建

用 CUDA 或 SYCL 编译时, 你必须确保代码在核函数内运行. 仅仅用 NVCC 编译器编译现有代码并不足以让代码在设备上运行. 在 NVCC 上运行 Beta 分布 CDF 的一个简单 CUDA 核函数是:

__global__ void cuda_beta_dist(const double* in, double* out, int num_elements)
{
    const int i = blockDim.x * blockIdx.x + threadIdx.x;

    if (i < num_elements)
    {
        out[i] = cdf(boost::math::beta_distribution<double>(), in[i]);
    }
}

而在 NVRTC 上的 CUDA 中:

const char* cuda_kernel = R"(
#include <boost/math/distributions/beta.hpp>
extern "C" __global__
void test_beta_dist_kernel(const double* in, double* out, int num_elements)
{
    const int i = blockDim.x * blockIdx.x + threadIdx.x;
    if (i < num_elements)
    {
        out[i] = boost::math::cdf(boost::math::beta_distribution<double>(), in[i]);
    }
}
)";

最后是在 SYCL 上:

void sycl_beta_dist(const double* in, double* out, int num_elements, sycl::queue& q)
{
    q.submit([&](sycl::handler& h) {
        h.parallel_for(sycl::range<1>(num_elements), [=](sycl::id<1> i) {
            out[i] = boost::math::cdf(boost::math::beta_distribution<double>(), in[i]);
        });
    });
}

使用 SYCL 时必须定义 BOOST_MATH_ENABLE_SYCL, 因为该平台上的设备支持是可选加入的. 对 NVCC 与 NVRTC, 设备支持是自动启用的.

写好核函数后, 使用框架机制启动核函数.
