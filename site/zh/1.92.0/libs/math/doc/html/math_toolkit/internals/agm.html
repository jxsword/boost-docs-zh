算术-几何平均数

概要 
#include <boost/math/tools/agm.hpp>

namespace boost::math::tools {

template<typename Real>
Real agm(Real a0, Real g0);

} // namespaces

函数 agm 给出该序列的极限值

基本用法是

double G = boost::math::tools::agm(sqrt(2.0), 1.0);

AGM 不等式

表明

我们在内部使用该条件来衡量收敛性; 不过不必担心实参顺序是否正确, 因为按定义我们把 agm 延拓为对称函数. 两个实参都必须非负, 因为对负实参该序列会变为复数. (我们尚未实现复值 AGM 序列.) 函数 agm 是“本质上”一维的, 因为尺度不变性 agm(k*x, k*y) == k*agm(x,y) 总是允许我们把其中一个实参取为单位值. 下面这张 ULP 图是用函数 agm(x, Real(1)) 生成的:

上图显示的是 Boost 实现的 agm(x, Real(1)) 的 ulps 图. 预期约为 2 ULP 的界.
