注意事项

使用 tanh-sinh、exp-sinh 与 sinh-sinh 求积时需要注意以下几点:

这些例程在逼近端点奇点时非常激进. 这可以提取出许多有效数字, 但也带来另一个问题: 舍入误差可能导致函数恰好在端点处被求值. 有几种避免方法: 把积分界限收窄为比如 [a + ε, b - ε], 确保 (a+b)/2 与 (b-a)/2 可表示, 最后, 如果你认为精度与易用性之间的折衷过于偏向精度, 请提交一个 ticket.

exp-sinh 与 sinh-sinh 求积都会在非常大的参数处对传入的函数求值. 你可能理解 x12exp(-x) 在 x12 上溢时应为零, 但 IEEE 浮点运算并不理解. 因此 std::pow(x, 12)*std::exp(-x) 在 std::pow(x, 12) 上溢时是不定式. 所以请确保你的函数具有正确的极限行为; 例如

auto f = [](double x) {
    double t = exp(-x);
    if(t == 0)
    {
        return 0;
    }
    return t*pow(x, 12);
};

对于大的 x 具有正确行为, 但 auto f = [](double x) { return exp(-x)*pow(x, 12); }; 则不然.

振荡积分, 例如 sinc 积分, 用双指数求积逼近的效果很差. 所幸对于这类积分, 误差估计与 L1 范数都非常大, 但振荡积分仍需要不同的技术.

关于跨零点积分需要特别说明: 当一个端点为零时, 我们的区间适配器能保持精度, 但当原点既不在区间中心也不在端点时, 情况就变难了. 考虑积分:

1 / (1 +x^2)

在 (a, ∞) 上. 只要 a >= 0, tanh_sinh 与 exp_sinh 积分器都能很好地处理: 事实上它们为这类积分提供了一种相当高效的方法. 然而, 如果我们有 a < 0, 那么我们不得不以某种方式适配区间, 使得零附近的横坐标值具有 ε 的绝对误差, 由于积分的全部面积都在零附近, 两个积分器都会来回挣扎试图达到目标精度, 但当 a << 0 时实际上永远达不到. 另一方面, 把积分拆成两个区间 (a, 0) 与 (0, b) 并用 tanh-sinh 积分器分别积分的简单办法, 效果很好.

最后, 某些端点奇点太强, tanh_sinh 或等价方法无法处理, 例如考虑积分函数:

double p = some_value;
tanh_sinh<double> integrator;
auto f = [&](double x){ return pow(tan(x), p); };
auto Q = integrator.integrate(f, 0, constants::half_pi<double>());

此函数的第一个问题在于奇点位于 π/2, 因此当我们在 (0, π/2) 上积分时, 永远无法逼近到距奇点小于 ε 的程度, 而对于小于但接近 1 的 p, 我们需要非常接近奇点才能找到函数下的全部面积. 如果回忆起恒等式 tan(π/2 - x) == 1/tan(x), 那么可以把函数改写为:

auto f = [&](double x){ return pow(tan(x), -p); };

现在奇点位于原点, 求值积分时可以逼近得更近: 我们所做的只是交换了积分端点.

这对 p < 0.95 实际上效果很好, 但此后 tanh_sinh 积分器开始来回挣扎, 无法在积分上收敛. 问题实际上出在指数范围不足: 如果简单地用指数范围更大的类型 (80 位 long double 或四精度类型) 替换 double, 那么至少可以达到 p = 0.99. 如果想更进一步, 或者坚持使用 double 类型, 就得动点脑筋了.

最简单的方法是注意到对于小的 x 有 tan(x) ≅ x, 因而我们实际上是在对 x-p 积分. 因此可以在 (0, small) 上使用这一近似, 并从 (small, π/2) 数值积分, 用 ε 作为合适的分界点是合理的:

double p = some_value;
double crossover = std::numeric_limits<double>::epsilon();
tanh_sinh<double> integrator;
auto f = [&](double x){ return pow(tan(x), p); };
auto Q = integrator.integrate(f, crossover, constants::half_pi<double>()) + pow(crossover, 1 - p) / (1 - p);

还有一种更复杂的替代方法, 适用于可以通过取对数求值来简化的表达式. 假设如本例, 图形下的全部面积都无限接近于零, 现在想象我们可以把该区域扩展到横坐标值大得多的范围: 如果我们做变量替换, 把 x 替换为 exp(-x) (注意我们还必须乘以 exp(-x) 的导数), 情形正是如此. 这样零处的奇点移到了 +∞, 而 π/2 的界移到了 -log(π/2). 一开始变量替换后的函数形如:

auto f = [&](double x){ return exp(-x) * pow(tan(exp(-x)), -p); };

这几乎没有任何改善, 因为与之前一样我们仍然会用尽指数范围. 然而, 如果把 tan(exp(-x)) 替换为 exp(-x), 其中 exp(-x) 适当小, 因而有 x > -log(ε), 我们就能大幅简化表达式并用对数求值:

auto f = [&](double x)
{
   static const double crossover = -log(std::numeric_limits<double>::epsilon());
   return x > crossover ? exp((p - 1) * x) : exp(-x) * pow(tan(exp(-x)), -p);
};

这一形式在 (-log(π/2), +∞) 上用 tanh_sinh 或 exp_sinh 类都能顺利积分.
