目录与文件结构

boost/math

/concepts/

原型, 定义了 RealType 类的 核心 特性 (见 real_concept.hpp). 大多数应用将使用 double 作为 RealType (并尽可能将分布的短 typedef 名称保留给此类型), 少数应用会使用 float 或 long double, 但也可以使用诸如 NTL::RR、GNU Multiple Precision Arithmetic Library、GNU MPFR library、Boost.Multiprecision (如 cpp_bin_float_50) 等符合 real_concept 所规定要求的类型.

/constants/

constants.hpp 的模板化定义, 提供一些高度精确的数学常量 (constants.hpp).

/distributions/

数学尤其是统计学中使用的分布: Gaussian、Students-t、Fisher、Binomial 等

/policies/

策略 (policy) 框架, 用于处理用户请求的行为修改.

/special_functions/

通常被视为“特殊”的数学函数, 如 beta、cbrt、erf、gamma、lgamma、tgamma ... (其中一些已在 C++ 以及 C99/TR1 (或许还有 TR2) 中标准化).

/tools/

函数所使用的工具, 如多项式求值、连分数、求根、精度与极限, 以及测试所用的工具. 其中一些在本包之外也有用武之地.

boost/libs

/doc/

Quickbook 格式的文档源文件, 经处理生成 html 和 pdf 格式.

/examples/

使用数学函数与分布的示例和演示.

/performance/

性能测试与调优程序.

/test/

测试文件, 分布在多个 .cpp 文件中, 大多使用 Boost.Test (一些测试数据为 .ipp 文件, 通常使用精度充裕的 NTL RR 类型生成, 以适配该类型, 常常适用于有效数字高达 256 位的实数类型).

/tools/

用于生成测试数据的程序. 还包括对已发布的 NTL 包的修改, 以提供少量额外 (且至关重要) 的特性.
