基数三角插值

概要 

#include <boost/math/interpolators/cardinal_trigonometric.hpp>

namespace boost{ namespace math{ namespace interpolators {

template <class RandomAccessContainer>
class cardinal_trigonometric
{
public:
    cardinal_trigonometric(RandomAccessContainer const & y, Real t0, Real h);

    Real operator()(Real t) const;

    Real prime(Real t) const;

    Real double_prime(Real t) const;

    Real period() const;

    Real integrate() const;

    Real squared_l2() const;
};
}}}

基数三角插值

基数三角插值问题取等间距的均匀采样 yj , 它属于周期函数 f, 定义为 yj = f(t0 + j h) , 并把它们表示为正弦与余弦的线性组合. 若 f 的周期为 T , 数据点数为 n = 2m 或 n = 2m+1 , 我们希望有

f(t) ≈ a0/2 + ∑k = 1m ak cos(2π k (t-t0) /T) + bk sin(2π k (t-t0)/T)

收敛速度取决于 f 的连续导数的数目; 详情参见 Atkinson 或 Kress.

此插值器的一个简单用法如下所示:

#include <vector>
#include <boost/math/interpolators/cardinal_trigonometric.hpp>
using boost::math::interpolators::cardinal_trigonometric;
...
std::vector<double> v(17, 3.2);
auto ct = cardinal_trigonometric(v, /*t0 = */ 0.0, /* h = */ 0.125);
std::cout << "ct(1.3) = " << ct(1.3) << "\n";

// Derivative:
std::cout << ct.prime(1.2) << "\n";
// Second derivative:
std::cout << ct.double_prime(1.2) << "\n";

周期总是由 v.size()*h 给出. 差一错误 (off-by-one) 在编程中很常见, 因此如果你想查询此插值器认为的周期是多少, 可以用 .period() 成员函数查询.

此外, 变换到三角基给出了一种计算函数在一个周期上积分的简便方法; 这通过 .integrate() 成员函数完成. 在此基下计算 L2 范数的平方也很简单; 由 .squared_l2() 成员函数计算.

注意事项

此例程依赖 FFTW3, 因此只能以 float、double、long double 和 quad 精度编译, 这与库中可兼容任意精度算术的绝大部分不同. FFTW 链接器标志必须加入编译步骤, 即 -lm -lfftw3 用于 double 精度, -lm -lfftw3f 用于 float, 依此类推.

导数的求值通过对 Horner 方法求微分完成. 一如既往, 微分会放大噪声; 而且由于 Fourier 系数的计算会产生一些舍入误差, 微分会放大这一误差.
