计算二项分布发生频率的置信限

设想有一个服从二项分布的过程: 对每次进行的试验, 一个事件要么发生要么不发生, 分别称为 "成功" 和 "失败". 如果你想通过实验测量成功发生的频率, 最好的估计由 k / N 简单给出, 其中 k 是 N 次试验中的成功次数. 然而, 我们对这一估计的信心取决于进行了多少次试验、观察到了多少次成功. 静态成员函数 binomial_distribution<>::find_lower_bound_on_p 和 binomial_distribution<>::find_upper_bound_on_p 允许你为发生频率的估计计算置信区间.

示例程序 binomial_confidence_limits.cpp 展示了它们的用法. 它首先定义一个过程, 该过程将打印各种置信程度下的置信限表:

#include <iostream>
#include <iomanip>
#include <boost/math/distributions/binomial.hpp>

void confidence_limits_on_frequency(unsigned trials, unsigned successes)
{
   //
   // trials = Total number of trials.
   // successes = Total number of observed successes.
   //
   // Calculate confidence limits for an observed
   // frequency of occurrence that follows a binomial
   // distribution.
   //
   using namespace std;
   using namespace boost::math;

   // Print out general info:
   cout <<
      "___________________________________________\n"
      "2-Sided Confidence Limits For Success Ratio\n"
      "___________________________________________\n\n";
   cout << setprecision(7);
   cout << setw(40) << left << "Number of Observations" << "=  " << trials << "\n";
   cout << setw(40) << left << "Number of successes" << "=  " << successes << "\n";
   cout << setw(40) << left << "Sample frequency of occurrence" << "=  " << double(successes) / trials << "\n";

该过程接下来定义一个显著性水平表: 这些是真实发生频率落在计算区间之外的概率:

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

接着是对表头的一些美化输出:

cout << "\n\n"
        "_______________________________________________________________________\n"
        "Confidence        Lower CP       Upper CP       Lower JP       Upper JP\n"
        " Value (%)        Limit          Limit          Limit          Limit\n"
        "_______________________________________________________________________\n";

现在到了重要的部分——区间本身: 对每个 alpha 值, 我们调用 find_lower_bound_on_p 和 find_lower_upper_on_p 分别获得下界和上界. 注意, 由于我们计算的是双侧区间, 必须把 alpha 的值一分为二.

请注意, 计算两个各自风险级别为 α 的独立 单侧界, 与计算双侧区间不是一回事. 假如我们计算两个单侧区间, 每个区间都有真实值落在区间之外的风险 α, 那么:

  • 它小于下界的风险是 α.

以及

  • 它大于上界的风险也是 α.

因此它落在 上界或下界 之外的风险是 alpha 的 两倍, 于是它落在界内的概率远没有人们想的高. 这就是为什么在下面的计算中必须使用 α/2.

相反, 假如我们计算的是单侧区间, 例如: "计算一个下界, 使我们有 P% 的把握确信真实发生频率大于某个值", 那么我们 就不会 除以 2.

最后注意, binomial_distribution 提供两种计算方法可供选择, 本例中我们把两种方法的结果都打印出来:

   for(unsigned i = 0; i < sizeof(alpha)/sizeof(alpha[0]); ++i)
   {
      // Confidence value:
      cout << fixed << setprecision(3) << setw(10) << right << 100 * (1-alpha[i]);
      // Calculate Clopper Pearson bounds:
      double l = binomial_distribution<>::find_lower_bound_on_p(
                     trials, successes, alpha[i]/2);
      double u = binomial_distribution<>::find_upper_bound_on_p(
                     trials, successes, alpha[i]/2);
      // Print Clopper Pearson Limits:
      cout << fixed << setprecision(5) << setw(15) << right << l;
      cout << fixed << setprecision(5) << setw(15) << right << u;
      // Calculate Jeffreys Prior Bounds:
      l = binomial_distribution<>::find_lower_bound_on_p(
            trials, successes, alpha[i]/2,
            binomial_distribution<>::jeffreys_prior_interval);
      u = binomial_distribution<>::find_upper_bound_on_p(
            trials, successes, alpha[i]/2,
            binomial_distribution<>::jeffreys_prior_interval);
      // Print Jeffreys Prior Limits:
      cout << fixed << setprecision(5) << setw(15) << right << l;
      cout << fixed << setprecision(5) << setw(15) << right << u << std::endl;
   }
   cout << endl;
}
