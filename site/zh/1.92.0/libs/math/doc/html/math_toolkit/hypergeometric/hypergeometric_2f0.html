#include <boost/math/special_functions/hypergeometric_2F0.hpp>

namespace boost { namespace math {

template <class T1, class T2, class T3>
calculated-result-type hypergeometric_2F0(T1 a1, T2 a2, T3 z);

template <class T1, class T2, class T3, class Policy>
calculated-result-type hypergeometric_2F0(T1 a1, T2 a2, T3 z, const Policy&);

}}
说明

函数 hypergeometric_2F0 返回如下结果

这些函数的返回类型按 结果类型计算规则 确定, 此时要求 T1 和 T2 是不同类型.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

只要结果未定义或为复数, 这些函数就返回 domain_error 的结果. 该函数的有效定义域仅在某一个 a1 或 a2 为负整数时才出现: 即多项式情形.
