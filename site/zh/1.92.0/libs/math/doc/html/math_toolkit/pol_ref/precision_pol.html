精度策略

有两个等效的策略影响用于计算结果的 工作精度, 这些策略都默认为 0 - 意味着以所用类型的最大可用精度计算 - 但可以设置为其他值以使用更低的精度级别. 人们可能想用精度换取求值速度.

namespace boost{ namespace math{ namespace policies{

template <int N>
digits10;

template <int N>
digits2;

}}} // namespaces

如你所预期, digits10 指定使用的十进制位数, digits2 指定二进制位数. 无论使用哪一个, 内部总是将精度转换为 二进制位数.

这些策略在编译期指定, 因为许多特殊函数使用编译期分派, 根据请求的精度和所用的数值类型选择使用哪个近似.

例如, 我们可以用以下方式把 tgamma 计算到约 5 位十进制数字:

#include <boost/math/special_functions/gamma.hpp>
using boost::math::tgamma;
using boost::math::policies::policy;
using boost::math::policies::digits10;

typedef policy<digits10<5> > my_pol_5; // Define a new, non-default, policy
// to calculate tgamma to accuracy of approximately 5 decimal digits.

或者再次使用辅助函数 make_policy:

#include <boost/math/special_functions/gamma.hpp>
using boost::math::tgamma;

using namespace boost::math::policies;

double t = tgamma(12, policy<digits10<5> >());  // Concise make_policy.

而要计算分布的分位数到约 25 位二进制精度:

#include <boost/math/distributions/normal.hpp>
using boost::math::normal_distribution;

using namespace boost::math::policies;

const int bits = 25; // approximate precision.

double q = quantile(
      normal_distribution<double, policy<digits2<bits> > >(),
      0.05); // 5% quantile.
