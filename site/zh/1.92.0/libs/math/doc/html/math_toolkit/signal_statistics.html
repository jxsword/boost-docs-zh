信号统计

概要

namespace boost::math::statistics {

    template<class Container>

说明

文件 boost/math/statistics/signal_statistics.hpp 是一组用于计算信号分析中常用量的设施.

我们的示例使用 std::vector<double> 来存放数据, 但这并非必需. 一般来说, 你可以把数据存放在 Eigen 数组、Armadillo 向量或 std::array 中; 对其中许多例程, 还可以使用 std::forward_list. 这些例程可用于 float、double、long double 和 Boost.Multiprecision 精度, 并且只要计算是良定义的, 也可用于它们的复数扩展.

绝对 Gini 系数

Gini 系数最初用于衡量财富不平等, 也是衡量基展开稀疏性的最佳度量之一. 稀疏展开把其范数的大部分集中在少数几个系数上, 这与财富不平等的联系显而易见. 详情参见 Hurley and Rickard. 然而, 对度量稀疏性而言, 数的相位无关紧要, 因此我们提供了 absolute_gini_coefficient:

using boost::math::statistics::sample_absolute_gini_coefficient;
using boost::math::statistics::absolute_gini_coefficient;
std::vector<std::complex<double>> v{{0,1}, {0,0}, {0,0}, {0,0}};
double abs_gini = sample_absolute_gini_coefficient(v);
// now abs_gini = 1; maximally unequal

std::vector<std::complex<double>> w{{0,1}, {1,0}, {0,-1}, {-1,0}};
abs_gini = absolute_gini_coefficient(w);
// now abs_gini = 0; every element of the vector has equal magnitude

std::vector<double> u{-1, 1, -1};
abs_gini = absolute_gini_coefficient(u);
// now abs_gini = 0
// Alternative call useful for computing over subset of the input:
abs_gini = absolute_gini_coefficient(u.begin(), u.begin() + 1);

对只有一个非零系数的向量, 样本 Gini 系数返回 1. 只有一个非零元素的向量的总体 Gini 系数则依赖于输入的长度.

样本 Gini 系数缺少总体 Gini 系数的一个理想性质, 即 "克隆" 一个向量会得到相同的 Gini 系数; 不过对样本 Gini 系数而言, 克隆性质仍以很高的精度成立, 并且通过一次重新缩放即可轻松恢复.

如果对稀疏性度量来说排序输入数据的开销太大 (反正它也不会完美?), 可以考虑改为计算 Hoyer 稀疏度.

Hoyer 稀疏度

Hoyer 稀疏度度量 ℓ1 范数与 ℓ2 范数的归一化比值. 顾名思义, 它用于度量某个基中展开的稀疏性.

Hoyer 稀疏度计算 (√N - ℓ1(v)/ℓ2(v))/(√N -1). 详情参见 Hoyer 以及 Hurley and Rickard.

几个特殊情形有助于阐明预期用法: 如果 v 只有一个非零系数, 则 Hoyer 稀疏度达到其最大值 1. 如果 v 的系数都具有相同的幅值, 则 Hoyer 稀疏度达到其最小值零. 如果 v 的元素在区间 [0, b] 上均匀分布, 则 Hoyer 稀疏度约为 0.133.

用法:

std::vector<Real> v{1,0,0};
Real hs = boost::math::statistics::hoyer_sparsity(v);
// hs = 1
std::vector<Real> v{1,-1,1};
Real hs = boost::math::statistics::hoyer_sparsity(v.begin(), v.end());
// hs = 0

容器必须可前向迭代, 且其内容不会被修改. 接受实数、复数和整数输入. 如果输入是整数类型, 则输出为双精度浮点数.

Oracle 信噪比

函数 oracle_snr 计算比值 ‖ s ‖22 / ‖ s - x ‖22, 其中 s 是信号, x 是含噪信号. 函数 oracle_snr_db 计算 10log10(‖ s ‖2 / ‖ s - x ‖2). 之所以这样命名, 是因为一般而言人们不知道如何把实信号 x 分解为 s + w, 因此 s 被视为 oracle 信息. 因此此函数主要用于对其他 SNR 估计器作单元测试.

用法:

std::vector<double> signal(500, 3.2);
std::vector<double> noisy_signal(500);
// fill 'noisy_signal' signal + noise
double snr_db = boost::math::statistics::oracle_snr_db(signal, noisy_signal);
double snr = boost::math::statistics::oracle_snr(signal, noisy_signal);

输入可以是实数、复数或整数. 整数输入产生双精度浮点输出. 输入数据不会被修改, 且必须满足 RandomAccessContainer 的要求.

M2M4 SNR 估计

通过 M2M4 方法估计含噪信号的 SNR. 详情参见 Pauluzzi and N.C. Beaulieu 与 Matzner and Englberger.

std::vector<double> noisy_signal(512);
// fill noisy_signal with data contaminated by Gaussian white noise:
double est_snr_db = boost::math::statistics::m2m4_snr_estimator_db(noisy_signal);

M2M4 SNR 估计器是一种 "在役" 估计器, 意思是估计是利用含噪的承载数据的信号作出的, 不需要背景估计. 已经发现, 该估计器在大约 -3 到 15db 之间工作得最好, 在 -3db 以下倾向于高估噪声, 在 15db 以上倾向于低估噪声. 详情参见 Xue et al.

M2M4 SNR 估计器默认假设信号的峰度为 1, 噪声的峰度为 3, 后者对应于高斯噪声. 不过, 这些参数可以被覆盖:

std::vector<double> noisy_signal(512);
// fill noisy_signal with the data:
double signal_kurtosis = 1.5;
// Noise is assumed to follow Laplace distribution, which has kurtosis of 6:
double noise_kurtosis = 6;
double est_snr = boost::math::statistics::m2m4_snr_estimator_db(noisy_signal, signal_kurtosis, noise_kurtosis);

严格来说, 该方法是一种 "盲 SNR 估计器", 意思是使用该方法不需要关于信号的任何 先验 信息. 然而, 如果你能对信号峰度和噪声峰度给出更好的估计, 该方法的性能会 大幅 提升. 如何做到这一点? 假设我们知道 SNR 远大于 1, 那么可以直接用含噪信号的峰度来估计信号峰度. 如果 SNR 远小于 1, 该方法会失效, 因为含噪信号的峰度会趋于噪声峰度——不过在这个极限下, 我们恰好得到了噪声峰度的极佳估计器! 此外, 如果你对信号应有的样子有模型, 就可以预先计算信号峰度. 例如, 正弦信号的峰度为 1.5. 一项研究 (见 此处) 使用此类估计来提升 M2M4 估计器的性能.

Nota bene: SNR 的传统定义 不是 均值不变的. 意思是, 如果给信号的每个样本都加上一个常数, SNR 就会改变. 例如, 给信号加上直流偏置会改变其 SNR. 对大多数用例而言, 这确实不是你想要的结果; 例如, 由零加上高斯噪声构成的信号 SNR 为零, 而带有恒定直流偏置和随机高斯噪声的信号却可能有非常大的 SNR.

M2M4 SNR 估计器由均值不变量计算得到, 因此它实际上应当与均值不变的 SNR 相比较.

Nota bene: 这一计算需要求解一个包含噪声峰度、信号峰度以及数据的二阶矩和四阶矩的二次方程组. 无法保证该方程组对这些参数的所有取值都有解; 事实上, 对某些数据可以很容易地证明无解. 如果方程组无解, 则通过返回 NaN 来报告失败. 这种情况发生得令人懊恼地频繁; 如果用户知道任何不存在这一缺陷的盲 SNR 估计器, 请在 github 上开一个 ticket 告知我们.

作者尚未能完整刻画存在 S > 0 且 N >0 的实数解的条件. 不过, 一个非常直观的例子说明了为什么可能无解. 假设信号峰度与噪声峰度相等, 那么该方法无法区分信号与噪声, 解不唯一.
