Arcsine 分布 

#include <boost/math/distributions/arcsine.hpp>
namespace boost{ namespace math{

 template <class RealType = double,
           class Policy   = policies::policy<> >
class arcsine_distribution;

typedef arcsine_distribution<double> arcsine; // double precision standard arcsine distribution [0,1].

template <class RealType, class Policy>
class arcsine_distribution
{
public:
   typedef RealType  value_type;
   typedef Policy    policy_type;

   // Constructor from two range parameters, x_min and x_max:
   BOOST_MATH_GPU_ENABLED arcsine_distribution(RealType x_min = 0, RealType x_max = 1);

   // Range Parameter accessors:
   BOOST_MATH_GPU_ENABLED RealType x_min() const;
   BOOST_MATH_GPU_ENABLED RealType x_max() const;
};
}} // namespaces

类类型 arcsine_distribution 表示一个arcsine 概率分布函数. 之所以称为 arcsine 分布, 是因为其 CDF 使用了反正弦 sin-1 (arcsine).

它实现为推广版本, 支撑区间从 x_min 到 x_max, 默认提供“标准 arcsine 分布”, 即 x_min = 0 且 x_max = 1. (少数实现者对“标准”另有选择).

arcsine 分布被 Wolfram 和 Wikipedia 推广到任意有界支撑 a <= x <= b; Virtual Laboratories in Probability and Statistics 则使用 location 和 scale 参数对其进行推广, 见 Arcsine distribution. 端点版本更简单也更直观, 因此我们实现该版本. 如有需要, this 概述了如何用 Beta Distribution 增加形状因子.

定义在区间 [x_min, x_max] 上的 arcsine distribution 的probability density function PDF 由下式给出:

f(x; x_min, x_max) = 1 /(π⋅√((x - x_min)⋅(x_max - x_min))

例如, Wolfram Alpha 的 arcsine distribution, 输入为

N[PDF[arcsinedistribution[0, 1], 0.5], 50]

计算出 PDF 值

0.63661977236758134307553505349005744813783858296183

推广 arcsine 分布的概率密度函数 (PDF) 是对称的 U 形曲线, 中心在 (x_max - x_min)/2, 在两个端点附近最高 (无穷大), 而在中央区域相当平坦.

若随机变量 x 为 x_min 或 x_max, 则 PDF 为无穷大. 若随机变量 x 为 x_min, 则 CDF 为零; 若 x 为 x_max, 则 CDF 为 1.

图中蓝色为“标准” (0, 1) arcsine 分布, 并给出了其他 x 范围的一些推广示例.

累积分布函数 CDF 定义为

F(x) = 2⋅arcsin(√((x-x_min)/(x_max - x))) / π

构造函数 
arcsine_distribution(RealType x_min, RealType x_max);

构造一个具有范围参数 x_min 和 x_max 的 arcsine 分布.

要求 x_min < x_max, 否则调用 domain_error.

例如:

arcsine_distribution<> myarcsine(-2, 4);

构造 x_min = -2 且 x_max = 4 的 arcsine 分布.

默认值 x_min = 0 和 x_max = 1 以及 typedef arcsine_distribution<double> arcsine; 意味着

arcsine as;

构造一个“标准 01” arcsine 分布.

参数访问器 
BOOST_MATH_GPU_ENABLED RealType x_min() const;
BOOST_MATH_GPU_ENABLED RealType x_max() const;

返回构造此分布时所用的参数 x_min 或 x_max.

例如:

using boost::math::arcsine_distribution;

arcsine_distribution<> as(2, 5); // Constructs a double arcsine distribution.
BOOST_MATH_ASSERT(as.x_min() == 2.);  // as.x_min() returns 2.
BOOST_MATH_ASSERT(as.x_max() == 5.);   // as.x_max()  returns 5.
非成员访问函数

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

注释

总有 两个 众数 值, 分别位于 x_min 和 x_max (默认 0 和 1), 因此我们改为抛出异常 domain_error. 在这些极值处, PDF 为无穷大, CDF 为零或 1.

应用

arcsine 分布可用于描述随机游走(包括醉汉行走)、布朗运动、Weiner 过程、Bernoulli 试验, 及其在解决股市和其他毁灭性赌博游戏问题中的应用.

随机变量 x 被限制在 x_min 和 x_max 之间 (对我们的“标准”分布即 0 和 1), 通常是某个比例. 对任何其他 x_min 和 x_max, 可以用下式从 x 得到比例:

fraction = (x - x_min) / (x_max - x_min)

最简单的例子是公平抛硬币的正面与反面, 用来建模输赢的风险. 在中线的左边或右边移动的行走者 (分子、醉汉...) 是另一个常见例子.

随机变量 x 是花在“赢”一侧的时间比例. 若一半时间在“赢”的一侧 (另一半在“输”的一侧), 则 x = 1/2.

对大量抛掷, 这由 (标准 [0,1]) arcsine 分布建模, PDF 可如下计算:

std::cout << pdf(as, 1. / 2) << std::endl; // 0.637
// pdf has a minimum at x = 0.5

从 PDF 图像可以清楚看到 x = ½ 是曲线的最小值, 因而是最不可能出现的情形. (考虑到公平抛掷最终必然打成平手, 这非常违反直觉. 而事实证明, 这个最终不只是很长, 而是无限长!).

最可能的情形则靠近极值, 即 x = 0 或 x = 1.

若在左侧的时间比例为 ¼, 其可能性只稍高一点, 因为曲线底部相当平坦.

std::cout << pdf(as, 1. / 4) << std::endl; // 0.735

如果我们考虑进行 100 天的公平抛硬币游戏 (假设连续进行以“处于极限”), 那么在第 5 天后领先的人在 0.144 的比例的场合中将不会改变.

我们很容易通过设置 x = 5./100 = 0.05 来计算这一点.

std::cout << cdf(as, 0.05) << std::endl; // 0.144

类似地, 我们可以从比例 0.05/2 = 0.025 (减半是因为同时考虑赢家和输家) 计算, 对应于位于原点同一侧的赌徒 (行走者、粒子...) 占 1 - 0.025 即 97.5%.

std::cout << 2 * cdf(as, 1 - 0.975) << std::endl; // 0.202

(使用补函数会更清晰一些, 并在 x 接近 1 时避免潜在的精度损失, 参见 why complements?).

std::cout << 2 * cdf(complement(as, 0.975)) << std::endl; // 0.202

或者我们可以反向计算: 假设一侧的时间比例, 比如比例 0.2,

std::cout << quantile(as, 1 - 0.2 / 2) << std::endl; //  0.976

std::cout << quantile(complement(as, 0.2 / 2)) << std::endl; // 0.976

总结: 每次抛掷的赔率都相同, 因此平均而言我们输赢的机会相同.

但对单独的一局而言这并不成立 - 一个人将大多处于糟糕或良好的连胜期.

这对大多数人来说相当违反直觉, 但数学是清楚的, 而赌徒们还在不断提供佐证.

寓意: 如果你正处于连败期, 就退出游戏. (因为恢复到良好连胜期的几率很小).

相关分布

x_min = 0 且 x_max = 1 的 arcsine 分布是 α = 1/2、β = 1/2 时 Beta Distribution 的特例.

精度

此分布使用 sqrt、正弦、余弦以及反正弦和反余弦三角函数实现, 这些函数通常精确到几个机器 epsilon以内. 但当 x 接近 x_max 时, 所有值都会出现精度损失或消去误差. 例如, 对标准 [0, 1] arcsine 分布 as 而言, pdf 关于随机变量 x = 0.5 对称, 因此人们会期望 pdf(as, 0.01) == pdf(as, 0.99). 但当 x 接近 1 时, 精度损失越来越严重. 为了抵消这一点, CDF 和分位数的补函数版本改用 cos-1 而不是 sin-1 的替代表达式实现. 关于何时使用补函数以避免精度损失的指导, 用户应参阅 why complements?.

实现

在下表中, a 和 b 是参数 x_min 和 x_max, x 是随机变量, p 是概率, 其补为 q = 1-p.

函数

实现说明

支撑

x ∈ [a, b], 默认 x ∈ [0, 1]

pdf

f(x; a, b) = 1/(π⋅√(x - a)⋅(b - x))

cdf

F(x) = 2/π⋅sin-1(√(x - a) / (b - a) )

补函数的 cdf

2/(π⋅cos-1(√(x - a) / (b - a)))

quantile

-a⋅sin2(½π⋅p) + a + b⋅sin2(½π⋅p)

由补函数求 quantile

-a⋅cos2(½π⋅p) + a + b⋅cos2(½π⋅q)

均值

½(a+b)

中位数

½(a+b)

众数

x ∈ [a, b], 因此抛出 domain_error (返回 NaN).

方差

(b - a)2 / 8

偏度

0

超额峰度

-3/2

峰度

kurtosis_excess + 3

分位数是使用 Wolfram Alpha 反解 CDF 公式得到的表达式计算的, 如下

solve [p - 2/pi sin^-1(sqrt((x-a)/(b-a))) = 0, x]

其被解释为

Solve[p - (2 ArcSin[Sqrt[(-a + x)/(-a + b)]])/Pi == 0, x, MaxExtraConditions -> Automatic]

并产生最终的表达式

x = -a sin^2((pi p)/2)+a+b sin^2((pi p)/2)
