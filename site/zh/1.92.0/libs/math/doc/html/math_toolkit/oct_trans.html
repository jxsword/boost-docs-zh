八元数超越函数

本实现没有为八元数提供 log 或 sqrt, 且 pow 同样被限制为指数的整数次幂. 这样做的理由有几条: 一方面, 八元数的解析延拓等价物 ("分支切割") 仍有待深入研究 (至少对我而言...), 而且我们希望避免标准中引入的复数的复数次幂那种胡闹 (它是良定义的, 但标准中并非如此...). 说到胡闹, 宣称 pow(0,0) 是"由实现定义"简直是彻底的脑残...

不过, 我们确实提供了若干超越函数, 其中最主要的是指数函数. 它允许"封闭公式"是作者的结果 (而指数函数的存在性与定义, 包括在八元数上, 则已有几个世纪的历史). 基本上, 任何在 C 上允许封闭公式的实系数收敛幂级数都可以移植到 O. 后续修订中可应要求添加更多此类超越函数. 需要注意的是, 正是这些函数造成了对 boost/math/special_functions/sinc.hpp 和 boost/math/special_functions/sinhc.hpp 头文件的依赖.

exp 
template<typename T>
octonion<T> exp(octonion<T> const & o);

计算八元数的指数.

cos 
template<typename T>
octonion<T> cos(octonion<T> const & o);

计算八元数的余弦

sin 
template<typename T>
octonion<T> sin(octonion<T> const & o);

计算八元数的正弦.

tan 
template<typename T>
octonion<T> tan(octonion<T> const & o);

计算八元数的正切.

cosh 
template<typename T>
octonion<T> cosh(octonion<T> const & o);

计算八元数的双曲余弦.

sinh 
template<typename T>
octonion<T> sinh(octonion<T> const & o);

计算八元数的双曲正弦.

tanh 
template<typename T>
octonion<T> tanh(octonion<T> const & o);

计算八元数的双曲正切.

pow 
template<typename T>
octonion<T>  pow(octonion<T> const & o, int n);

计算八元数 q 的 n 次幂.
