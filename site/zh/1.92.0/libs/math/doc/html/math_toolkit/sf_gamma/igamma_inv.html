不完全 Gamma 函数的反函数

概要 
#include <boost/math/special_functions/gamma.hpp>

namespace boost{ namespace math{

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inv(T1 a, T2 q);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inv(T1 a, T2 q, const Policy&);

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inv(T1 a, T2 p);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inv(T1 a, T2 p, const Policy&);

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inva(T1 x, T2 q);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inva(T1 x, T2 q, const Policy&);

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inva(T1 x, T2 p);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inva(T1 x, T2 p, const Policy&);

}} // namespaces
说明

共有四个 incomplete gamma function 反函数, 它们要么根据 a 和 p 或 q 计算 x, 要么根据 x 以及 p 或 q 计算 a.

当 T1 和 T2 是不同类型时, 这些函数的返回类型使用 结果类型计算规则 计算; 否则返回类型就是 T1.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

提示

当人们通常谈到不完全 gamma 函数的反函数时, 他们指的是对参数 x 求逆. 它们在这里的实现是 gamma_p_inv 和 gamma_q_inv, 并且是本文介绍的反函数中效率最高的.

对 a 参数求逆的反函数在某些统计应用中有所用处, 但必须用相当暴力的数值技术来计算, 因此慢了几倍. 它们在这里的实现是 gamma_p_inva 和 gamma_q_inva.

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inv(T1 a, T2 q);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inv(T1 a, T2 q, const Policy&);

返回一个值 x, 使得: q = gamma_q(a, x);

要求: a > 0 且 1 >= p,q >= 0.

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inv(T1 a, T2 p);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inv(T1 a, T2 p, const Policy&);

返回一个值 x, 使得: p = gamma_p(a, x);

要求: a > 0 且 1 >= p,q >= 0.

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inva(T1 x, T2 q);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_q_inva(T1 x, T2 q, const Policy&);

返回一个值 a, 使得: q = gamma_q(a, x);

要求: x > 0 且 1 >= p,q >= 0.

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inva(T1 x, T2 p);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_inva(T1 x, T2 p, const Policy&);

返回一个值 a, 使得: p = gamma_p(a, x);

要求: x > 0 且 1 >= p,q >= 0.

精度

这些函数的精度随平台或类型 T 的变化不大. 鉴于这些函数通过迭代方法计算, 它们被刻意"调低"以避免过于精确: 无论如何, 这些函数都不可能比常规的正向不完全 gamma 函数更精确. 实际上, 这些函数的精度与 gamma_p 和 gamma_q 函数非常接近:

测试

测试分为两组:

  • 基本的健全性检查尝试从 a 和 x "往返"到 p 或 q 再返回. 这些测试的容差相当宽松: 一般而言, 不完全 gamma 函数及其反函数变化如此之快, 以致于无法往返恢复到多于几位有效数字. 当 p 或 q 非常接近 1 时尤其如此: 在这种情况下, 反函数的输入中没有足够的"信息量"让你回到起点.
  • 使用高精度测试值的精度检查. 这些检查在给定精确输入值的情况下度量结果的精度.
实现

函数 gamma_p_inv 和 gamma_q_inv 共享同一个实现.

首先使用下述文献中描述的方法计算一个初始近似:

A. R. Didonato and A. H. Morris, Computation of the Incomplete Gamma Function Ratios and their Inverse, ACM Trans. Math. Software 12 (1986), 377-393.

最后, 使用 Halley 迭代清理最后几位; 迭代上限被设为 T 的位数的 2/3, 实验表明这足以保证反函数的精度至少与常规的不完全 gamma 函数相当. 在测试中, 产生与正向不完全 gamma 函数同样精确的结果所需迭代不超过 3 次, 许多情况下只需一次迭代.

函数 gamma_p_inva 和 gamma_q_inva 也共享同一个实现, 但与 gamma_p_inv 和 gamma_q_inv 分开处理.

对 a 的初始近似计算得非常粗糙, 使得 gamma_p(a, x) ~ 0.5; 该值随后被用作通用无导数求根算法的起点. 因此, 这两个函数的计算代价比 gamma_p_inv 或 gamma_q_inv 函数高不少. 即便如此, 通常也只需不到 10 次迭代即可找到根.
