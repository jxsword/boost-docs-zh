求根示例 (带与不带导数)

用与不用导数求立方根
使用 C++11 Lambda
计算五次根
使用 Boost.Multiprecision 求根
推广到计算 n 次根
更复杂的示例 - 反演椭圆积分

这些示例演示如何使用各种 求根 工具.

我们从简单的立方根函数 cbrt (C++ 标准函数名 cbrt) 开始, 展示 不带导数 的求根.

然后我们展示如何使用导数来提高收敛速度.

(但这些示例只是演示, 并不尝试进行"工业级"实现的终极改进, 例如 boost::math::cbrt, 主要通过在 cbrt.hpp 使用计算得更好的初始"猜测").

然后我们展示如何计算更高次根 (五次根) 5√, 以及 root_finding_n_example.cpp 中在编译期构造导数的 n 次根 通用方法.

这些方法应当适用于其他可以轻松求导的函数.
