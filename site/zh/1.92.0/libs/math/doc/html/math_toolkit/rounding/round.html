舍入函数 

#include <boost/math/special_functions/round.hpp>
template <class T>
T round(const T& v);

template <class T, class Policy>
T round(const T& v, const Policy&);

template <class T>
int iround(const T& v);

template <class T, class Policy>
int iround(const T& v, const Policy&);

template <class T>
long lround(const T& v);

template <class T, class Policy>
long lround(const T& v, const Policy&);

template <class T>
long long llround(const T& v);

template <class T, class Policy>
long long llround(const T& v, const Policy&);

这些函数返回最接近参数 v 的整数.

对恰在中间的情形, 无论当前舍入方向如何, 都按远离零的方向舍入.

如果参数 v 不是有限的, 或者超出了结果类型的范围, 则返回 rounding_error 的结果: 默认情况下, 这会抛出一个 boost::math::rounding_error 实例.
