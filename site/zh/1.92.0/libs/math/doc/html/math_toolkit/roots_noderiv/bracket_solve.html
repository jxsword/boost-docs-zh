界定区间并求解根 

template <class F, class T, class Tol>
std::pair<T, T>
   bracket_and_solve_root(
      F f,
      const T& guess,
      const T& factor,
      bool rising,
      Tol tol,
      std::uintmax_t& max_iter);

template <class F, class T, class Tol, class Policy>
std::pair<T, T>
   bracket_and_solve_root(
      F f,
      const T& guess,
      const T& factor,
      bool rising,
      Tol tol,
      std::uintmax_t& max_iter,
      const Policy&);

bracket_and_solve_root 是一个便捷函数, 它内部调用 TOMS 748 algorithm 来求 f(x) 的根. 使用本函数通常比直接使用 TOMS 748 algorithm 容易得多, 因为它替你完成了界定根的繁重工作. 它的界定例程相当稳健, 通常比自制例程更不易出错, 除非你能通过分析函数得到紧致的区间.

注意, 本例程只能在以下情况下使用:

  • 在包含 guess 的半个实轴上, f(x) 是单调的.
  • 初始猜测值必须与根同号: 函数在搜索根时 绝不会跨越原点.
  • 根的位置至少应当近似已知: 如果根的位置与 guess 相差多个数量级, 那么尽管有专门防范这种情况的启发式方法, 仍需要很多次迭代才能界定根. 一个典型例子是把初始猜测值设为 0.1, 而根其实在 1e-300.

bracket_and_solve_root 的参数为:

f

一元函子 (或 C++ lambda), 即要求解其根的函数. f(x) 在 x 上必须一致地递增或递减.

guess

对根的一个初始近似.

factor

用于界定根的缩放因子: guess 的值会乘以 (或在适当时除以) factor, 直到找到界定根的两个值. 像 2 这样的值是 factor 的典型选择. 此外, factor 每迭代 32 次还会被乘以 2: 这是为了防范极其糟糕的初始猜测值, 这种情况通常出现在已知结果非常大或非常小、但不知确切数量级时.

rising

如果 f(x) 在 x 上是上升的, 则设为 true; 如果 f(x) 在 x 上是下降的, 则设为 false. 该值与 f(guess) 的结果一起用于判断 guess 位于根的上方还是下方.

tol

二元函子 (或 C++ lambda), 用于确定根搜索的终止条件. tol 在每一步都会收到当前的区间; 当它返回 true 时, 当前区间将作为 pair 结果返回. 另参见 predefined termination functors.

max_iter

搜索根时要执行的函数调用次数上限. 退出时被设置为实际执行的调用次数.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

返回: 一对界定根的值 r, 满足:

f(r.first) * f(r.second) <= 0

并且满足二者之一

tol(r.first, r.second) == true

或者

max_iter >= m

其中 m 是传递给函数的 max_iter 初始值.

换言之, 由调用者负责判断终止是因为超过了 max_iter 次函数调用 (只需在函数返回时检查 max_iter 的值即可), 还是因为终止条件 tol 得到满足.
