log1p 

#include <boost/math/special_functions/log1p.hpp>

namespace boost{ namespace math{

template <class T>
calculated-result-type log1p(T x);

template <class T, class Policy>
calculated-result-type log1p(T x, const Policy&);

}} // namespaces

返回 x+1 的自然对数.

该函数的返回类型按 结果类型计算规则 确定: 返回 double, 条件是 x 为整数类型, 否则返回 T.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

在许多情形下, 需要计算 log(x+1). 然而, 对于小的 x, x+1 会遭受灾难性消去误差, 使得 x+1 == 1 且 log(x+1) == 0, 而事实上对于非常小的 x, 对 log(x+1) 的最佳近似是 x. log1p 使用 Taylor 级数展开计算 log(1+x) 的最佳近似 (精度优于 2ɛ). 另外可以注意到, 也有更快速的方法可用, 例如利用等价关系:

log(1+x) == (log(1+x) * x) / ((1+x) - 1)

然而, 经验表明, 一旦打开编译器优化, 这些方法往往会相当戏剧性地失败, 因此只在已知不会对特定编译器造成破坏时才使用它们. 相比之下, 级数展开方法看起来对优化器引发的误差有相当的免疫力.

最后, 当定义了宏 BOOST_HAS_LOG1P 时, 该模板的 float/double/long double 特化只是转发到平台的该函数原生 (POSIX) 实现.
