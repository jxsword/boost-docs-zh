附加功能/未来方向

添加额外的位置与尺度参数

在一些建模应用中, 我们需要具有特定位置与尺度的分布: 这通常对应特定的均值与标准差, 尽管对许多分布而言这些性质与位置、尺度参数之间的关系并不简单. 更多信息参见 http://www.itl.nist.gov/div898/handbook/eda/section3/eda364.htm.

显而易见的处理方式是通过一个适配器模板:

template <class Dist>
class scaled_distribution
{
   scaled_distribution(
     const Dist dist,
     typename Dist::value_type location,
     typename Dist::value_type scale = 0);
};

它随后会为非成员访问函数提供自己的一组重载.

"any_distribution" 类

很容易添加一个把分布的实际类型虚拟化的分布对象, 从而可以容纳"任意"符合分布概念要求的对象:

template <class RealType>
class any_distribution
{
public:
   template <class Distribution>
   any_distribution(const Distribution& d);
};

// Get the cdf of the underlying distribution:
template <class RealType>
RealType cdf(const any_distribution<RealType>& d, RealType x);
// etc....

这样的类将便于编写能适用于任何分布类型的非模板代码.

Windows 上的 Statistical Distribution Explorer 工具就是一个使用示例.

不过目前尚不清楚是否存在令人信服的用例. 拟合优度检验或许能提供这样的用例: 这需要进一步研究.

更高层的假设检验

与 Mathematica Hypothesis Tests 包大致对应的高层检验可以相当容易地添加, 例如:

template <class InputIterator>
typename std::iterator_traits<InputIterator>::value_type
   test_equal_mean(
     InputIterator a,
     InputIterator b,
     typename std::iterator_traits<InputIterator>::value_type expected_mean);

返回序列 [a,b) 中的数据具有均值 expected_mean的概率.

与统计累加器集成

Eric Niebler 的累加器框架 (同样在开发中) 提供了从实验数据计算各种统计性质的方法. 将来某个时候有机会把统计检验与该框架集成:

// Define an accumulator, all required statistics to calculate the test
// are calculated automatically:
accumulator_set<double, features<tag::test_expected_mean> > acc(expected_mean=4);
// Pass our data to the accumulator:
acc = std::for_each(mydata.begin(), mydata.end(), acc);
// Extract the result:
double p = probability(acc);
