说明

连分数是常见的逼近方法. 这些函数都对由 generator 类型实参所描述的连分数求值. 带 “_a” 后缀的函数对下式求值:

带 “_b” 后缀的函数则对下式求值:

后一种形式更自然一些, 因为它与连分数的通常定义一致, 但要注意生成器返回的第一个 a 值会被丢弃. 此外, 连分数中的第一个 a 和 b 值往往与其余项有不同的定义方程, 这可能使得 “_a” 后缀形式更为合适.

表达式

说明

Gen::result_type

调用 operator() 所得结果的类型. 它可以是算术类型或复数类型, 也可以是算术类型或复数类型的 std::pair<>.

g()

返回一个 Gen::result_type 类型的对象.

每次调用该运算符都会返回下一对 a 和 b 值. 或者, 如果 result_type 是算术类型, 则返回下一个 b 值, 并假定所有 a 值均为 1.

在所有连分数求值函数中, tolerance 参数是结果所需的精度; 连分数的求值会持续进行, 直到最后求值的项使结果的相对误差小于 tolerance. 已弃用的接口在这里接受数字位数精度, 它们在内部只是将其转换为容差后再转发调用.

如果指定了可选的 max_terms 参数, 那么对生成器的调用不会超过 max_terms 次, 并且在输出时, max_terms 会被设置为实际发生的调用次数. 在剖析连分数的收敛性时, 这一设施尤为有用.

实现

在内部, 这些算法都使用改进的 Lentz 算法: 更多信息请参阅 Numeric Recipes in C++, W. H. Press et al, 第 5 章 (特别是 5.2 Evaluation of continued fractions, p 175 - 179), 另见 Lentz, W.J. 1976, Applied Optics, vol. 15, pp. 668-671.

示例

所有这些示例都在 continued_fractions.cpp 中.

黄金比 phi = 1.618033989... 可以由最简单的连分数计算得到:

我们首先定义一个生成器函数:

template <class T>
struct golden_ratio_fraction
{
   typedef T result_type;

   result_type operator()()
   {
      return 1;
   }
};

然后可以用下式以双精度计算黄金比:

golden_ratio_fraction<double> func;
double gr = continued_fraction_a(
   func,
   std::numeric_limits<double>::epsilon());
std::cout << "The golden ratio is: " << gr << std::endl;

不过更常见的是, 在用连分数求特殊函数的值时必须同时定义 a 和 b, 例如 tan 函数由下式定义:

因此其生成器对象如下所示:

template <class T>
struct tan_fraction
{
private:
   T a, b;
public:
   tan_fraction(T v)
      : a(-v * v), b(-1)
   {}

   typedef std::pair<T, T> result_type;

   std::pair<T, T> operator()()
   {
      b += 2;
      return std::make_pair(a, b);
   }
};

注意, 如果像这里这样从 b 项中减去连分数式, 那么生成器返回的所有 a 项都将为负数. 现在可以用下式求正切函数的值:

template <class T>
T tan(T a)
{
   tan_fraction<T> fract(a);
   return a / continued_fraction_b(fract, std::numeric_limits<T>::epsilon());
}

注意, 这次我们使用 “_b” 后缀版本来对连分数求值: 求值时我们去掉开头的 a 项, 因为它与所有其他项不同.

现在我们来看几个复数示例, 首先是可通过下式计算的指数积分:

因此我们的函数对象如下:

template <class T>
struct expint_fraction
{
   typedef std::pair<T, T> result_type;
   expint_fraction(unsigned n_, T z_) : b(z_ + T(n_)), i(-1), n(n_) {}
   std::pair<T, T> operator()()
   {
      std::pair<T, T> result = std::make_pair(-static_cast<T>((i + 1) * (n + i)), b);
      b += 2;
      ++i;
      return result;
   }
private:
   T b;
   int i;
   unsigned n;
};

我们可以把所有内容包装到一个函数中来完成该示例:

template <class T>
inline std::complex<T> expint_as_fraction(unsigned n, std::complex<T> const& z)
{
   std::uintmax_t max_iter = 1000;
   expint_fraction<std::complex<T> > f(n, z);
   std::complex<T> result = boost::math::tools::continued_fraction_b(
      f,
      std::complex<T>(std::numeric_limits<T>::epsilon()),
      max_iter);
   result = exp(-z) / result;
   return result;
}

注意终止条件仍表示为复数, 只不过其虚部为零.

最后一个示例将使用 continued_fraction_a, 实际上我们的代码中只有一个特殊函数使用该变体, 即上不完全 gamma 函数 (Q), 它可通过下式计算:

在这种情况下, 前几项与其余项不同, 因此我们的连分数将从第一个“常规”a 项开始:

template <class T>
struct upper_incomplete_gamma_fract
{
private:
   typedef typename T::value_type scalar_type;
   T z, a;
   int k;
public:
   typedef std::pair<T, T> result_type;

   upper_incomplete_gamma_fract(T a1, T z1)
      : z(z1 - a1 + scalar_type(1)), a(a1), k(0)
   {
   }

   result_type operator()()
   {
      ++k;
      z += scalar_type(2);
      return result_type(scalar_type(k) * (a - scalar_type(k)), z);
   }
};

现在我们可以实现 Q, 这次使用 continued_fraction_a:

template <class T>
inline std::complex<T> gamma_Q_as_fraction(const std::complex<T>& a, const std::complex<T>& z)
{
   upper_incomplete_gamma_fract<std::complex<T> > f(a, z);
   std::complex<T> eps(std::numeric_limits<T>::epsilon());
   return pow(z, a) / (exp(z) *(z - a + T(1) + boost::math::tools::continued_fraction_a(f, eps)));
}
