Jacobi Theta 函数概述

Jacobi Theta 函数是一组四个相互关联的 x 周期函数, 以参数 q (也称为 nome) 或与之密切相关的值 τ 表示 [8] [9] [10].

经过适当的乘除组合, 这四个 theta 函数可用于实现 Jacobi 椭圆函数; 但并不真正推荐这样做, 因为现有的 Boost 实现可能更快也更精确.

大多数应用会希望使用这些函数的 q 参数化版本: jacobi_theta1、jacobi_theta2、jacobi_theta3 和 jacobi_theta4, 其中 q 被限制在定义域 (0, 1) 内. 这四个函数等价于 Mathematica 的 EllipticTheta 函数 (其第一个参数是函数编号).

精度考量

τ 参数化的目的是在 q 可表示为指数或非常接近 1 时提供更高的精度. 例如, 与其:

jacobi_theta1(x, exp(-a));

不如利用 τ 进行更精确的计算:

jacobi_theta1tau(x, a / boost::math::constants::pi<T>());

在内部, Boost 实现 q 参数化的方式是取 q 的对数并传给 τ 参数化; 因此, 直接使用 τ 参数化通常会获得更高的精度. 另一个例子是, 若 q 的补数已知得很精确, 则与其:

jacobi_theta1(x, 1-q_complement);

不如使用 log1p 并将结果传给 τ 版本, 这样更为精确:

jacobi_theta1tau(x, -boost::math::log1p(-q_complement) / boost::math::constants::pi<T>());

还提供了第三个和第四个 theta 函数的附加"减 1"版本. 其设计思想与 expm1 类似: 这些函数返回求值结果减 1, 并在 q 较小时提供更高的精度.

测试

theta 函数的结果对照 Wolfram Alpha 数据以及以高精度计算的随机值进行测试. 此外, 测试还验证了 DLMF Chapter 20.7 中描述的大多数恒等式.
