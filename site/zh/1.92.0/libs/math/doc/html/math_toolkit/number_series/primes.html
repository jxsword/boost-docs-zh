素数

概要 
#include <boost/math/special_functions/prime.hpp>

namespace boost { namespace math {

template <class Policy>
constexpr std::uint32_t prime(unsigned n, const Policy& pol);

constexpr std::uint32_t prime(unsigned n);

static const unsigned max_prime = 10000;

}} // namespaces
说明

函数 prime 提供对前 10000 个素数的快速表查找 (从 2 作为第 0 个素数开始, 因为 1 在实践中没什么用处). 有两种函数签名, 其中一种接受可选的 Policy 作为第二个参数来控制错误处理.

常量 max_prime 是可以传给 prime 而不引发错误的最大值.

传递大于 max_prime 的值会导致引发 domain_error.

仅当编译器支持 C++14 constexpr 函数时, 该函数才为 constexpr.
