检验样本均值与 "真实" 均值的差异

在校准或比较某种科学仪器或测量方法时, 我们想回答这样一个问题: "观测到的样本均值是否以任何显著方式不同于 "真实" 均值?" 如果确实如此, 那么我们就有系统性差异的证据. 这个问题可以用 Student t 检验回答: 更多信息可参见 NIST 站点.

当然, 把 "真实" 指派给某个均值可能相当随意, 通常这不过是一种 "传统" 的测量方法.

以下示例代码取自示例程序 students_t_single_sample.cpp.

我们先定义一个过程, 确定在给定显著性水平下哪些可能的假设被拒绝或不被拒绝:

注释

非统计学家可能会说 "不被拒绝" 意味着 "被接受" (通常指零假设), 错误地暗示确实 不存在 差异; 但统计学家回避这种说法, 以避免暗示存在 "无差异" 的正面证据. 这里的 "不被拒绝" 意味着 没有 差异的证据, 但仍然很可能存在差异. 例如, 参见 argument from ignorance 和 Absence of evidence does not constitute evidence of absence.

该过程大部分是美化输出, 因此我们只关注计算. 我们先计算 t 统计量:

// Difference in means:
double diff = Sm - M;
// Degrees of freedom:
unsigned v = Sn - 1;
// t-statistic:
double t_stat = diff * sqrt(double(Sn)) / Sd;

最后从 t 统计量计算概率. 如果我们只关心是否存在差异 (无论更小还是更大), 我们不在乎 t 统计量的符号, 并取概率的补集与显著性水平比较:

students_t dist(v);
double q = cdf(complement(dist, fabs(t_stat)));

该过程随后打印可以进行的各种检验的结果, 它们可以汇总为下表:

假设

检验

零假设: 均值 没有差异

若 |t| 的 CDF 补集 < 显著性水平 / 2 则拒绝:

cdf(complement(dist, fabs(t))) < alpha / 2

备择假设: 均值 存在差异

若 |t| 的 CDF 补集 > 显著性水平 / 2 则拒绝:

cdf(complement(dist, fabs(t))) > alpha / 2

备择假设: 样本均值 小于 真实均值.

若 t 的 CDF > 1 - 显著性水平则拒绝:

cdf(complement(dist, t)) < alpha

备择假设: 样本均值 大于 真实均值.

若 t 的 CDF 补集 < 显著性水平则拒绝:

cdf(dist, t) < alpha

注释

注意, 对双侧检验, 比较是针对 alpha / 2 进行的; 对单侧检验则是针对 alpha

你会注意到有一行说差异源于偶然的概率为零. 当然, 从哲学角度看, 概率永远不可能达到零. 然而, 在本例中, 计算出的概率小于可表示的最小双精度数, 因此这里显示为零. 无论其 "真实" 值是多少, 我们知道它必定极其小, 因此备择假设——均值存在差异——未被拒绝.

可以看到, 测量次数少 (3) 导致真实均值位置有很大的不确定性. 因此, 尽管样本均值与期望的真实均值之间似乎存在差异, 我们仍得出结论: 没有显著差异, 且无法拒绝零假设. 但是, 如果我们把接受门槛降低到 alpha = 0.1 (90% 置信水平), 我们会看到不同的输出:
