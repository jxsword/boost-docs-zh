}} // namespaces
说明

返回 x 的 digamma 或 psi 函数. Digamma 定义为 gamma 函数的对数导数:

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

本函数的返回类型使用 结果类型计算规则 计算: 当 T 是整数类型时, 结果类型为 double; 否则为类型 T.

测试

测试分为两组: 抽点值使用 functions.wolfram.com 上的在线计算器计算, 而随机测试值使用高精度参考实现生成 (即求导后的 Lanczos approximation, 见下文).

实现

实现划分为以下几个定义域:

对于负参数, 使用反射公式:

digamma(1-x) = digamma(x) + pi/tan(pi*x);

把 x 变为正数.

对于 [0,1] 范围内的参数, 使用递推关系:

digamma(x) = digamma(x+1) - 1/x

把求值移到 [1,2].

对于 [1,2] 范围内的参数, 使用 由 JM 设计 的有理近似 (见下文).

对于 [2,BIG] 范围内的参数, 使用递推关系:

digamma(x+1) = digamma(x) + 1/x;

把求值移回 [1,2] 范围.

对于大于 BIG 的参数, 渐近展开式

可以使用. 然而, 该展开式在若干项之后发散: 究竟取多少项取决于 x 的大小. 因此 BIG 的值必须选得使级数可以在某个足够小的项处截断, 以致在 BIG 处求值时该项对结果没有任何影响. 对于最高 80 位实数取 BIG=10, 对于 128 位实数取 BIG=20, 即可让级数在适当少的一些项之后截断, 并作为关于 1/(x*x) 的多项式求值.

其中 P(x) 和 Q(x) 是 Lanczos 和的有理形式中的多项式, P'(x) 和 Q'(x) 是它们的一阶导数. 该近似的 Lanczos 部分具有约 100 位十进制数字的理论精度. 然而, 上式求和中的抵消会把精度降低到约 99-(1/y) 位 (如果 y 是结果). 该近似被用于计算 digamma 的正根, 结果与 Cody 使用的值在 25 位上一致 (参见 Cody、Strecok 和 Thacher 的 Math. Comp. 27, 123-127 (1973)), 与 Morris 使用的值在 35 位上一致 (参见 TOMS Algorithm 708).

同样, 少量抽点测试与 functions.wolfram.com 计算的值在 40 位以上保持一致. 这足以保证下文的近似在 double 精度下是准确的. 要达到 128 位 long double 的精度, 需要根的位置精确到约 70 位数字, 而该方法计算出的值是否满足这一要求并不清楚: 困难在于如何独立验证所得到的值.

由 JM 设计 的有理近似采用如下形式针对绝对误差做了优化:

digamma(x) = (x - X0)(Y + R(x - 1));

其中 X0 是 digamma 的正根, Y 是常量, R(x - 1) 是有理近似. 注意, 由于 X0 是无理数, 我们需要 X0 的位数是 x 的两倍, 以避免相减期间的抵消误差 (这里假设 x 是精确值; 若非如此, 则一切都不好说). 这意味着, 即使 x 是舍入到最近可表示值的根, digamma(x) 的结果 也不会为零.
