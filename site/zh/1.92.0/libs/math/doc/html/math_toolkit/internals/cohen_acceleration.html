Cohen 加速

概要 
#include <boost/math/tools/cohen_acceleration.hpp>

namespace boost::math::tools {

template<class G>
auto cohen_acceleration(G& generator, int64_t n = -1);

} // namespaces

函数 cohen_acceleration 通过 Henri Cohen 等人 开发的技术快速计算交错级数的极限值. 要计算

我们首先定义一个可调用对象, 它在第 k 次调用时产生 ak. 例如, 假设我们希望计算

首先, 我们需要定义一个返回所需项的可调用对象:

template<typename Real>
class G {
public:
    G(){
        k_ = 0;
    }

    Real operator()() {
        k_ += 1;
        return 1/(k_*k_);
    }

private:
    Real k_;
};

然后把它传入函数 cohen_acceleration:

auto gen = G<double>();
double computed = cohen_acceleration(gen);

更多内容参见 cohen_acceleration.cpp (位于 examples 目录).

所消耗的项数由误差模型计算得出

并且必须先验地计算. 如果仔细阅读参考文献, 我们会注意到该误差模型是在如下假设下推导出的: 各项 ak 是正测度在 [0,1] 上的矩. 如果该假设不成立, 那么该方法所选择的项数就是不正确的. 因此我们允许用户提供第二个实参来指定项数:

double computed = cohen_acceleration(gen, 5);

注意: 在试验该选项时, 我们发现增加项数并不能保证更高的精度, 也找不到用户指定项数优于默认值的例子. 此外, 如果让 n 增长得过大, 很容易产生会上溢的中间量. 因此我们建议只把该参数用于减少默认项数以提升速度.

性能

为验证在相同相对精度水平下 Cohen 加速实际上比朴素求和更快, 我们可以运行 reporting/performance/cohen_acceleration_performance.cpp 文件. 该基准计算上文讨论过的交错 Basel 级数:
