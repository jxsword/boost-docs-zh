Logistic 分布 

#include <boost/math/distributions/logistic.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class logistic_distribution;

template <class RealType, class Policy>
class logistic_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;
   // Construct:
   BOOST_MATH_GPU_ENABLED logistic_distribution(RealType location = 0, RealType scale = 1);
   // Accessors:
   BOOST_MATH_GPU_ENABLED RealType location()const; // location.
   BOOST_MATH_GPU_ENABLED RealType scale()const; // scale.

};

typedef logistic_distribution<> logistic;

}} // namespaces

Logistic 分布是一种连续概率分布. 它有两个参数——位置与尺度. Logistic 分布的累积分布函数出现在 logistic 回归与前馈神经网络中. 在其他应用中, 美国国际象棋联合会与 FIDE 用它计算棋手等级分.

下图显示分布如何随参数变化:

成员函数 
BOOST_MATH_GPU_ENABLED logistic_distribution(RealType u = 0, RealType s = 1);

构造一个 logistic 分布, 位置为 u, 尺度为 s.

要求 scale > 0, 否则抛出 domain_error.

BOOST_MATH_GPU_ENABLED RealType location()const;

返回此分布的位置.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的尺度.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [-[max_value], +[min_value]]. 不过, 如果 RealType 允许, pdf 与 cdf 也支持 +∞ 与 -∞ 作为特殊情况输入.

在 p=1 以及 p=0 处, 分位数函数返回 +overflow_error 和 -overflow_error 的结果; 而补分位数函数分别返回 -overflow_error 和 +overflow_error 的结果.

在此分布中, logcdf 的实现经过专门化, 以提高数值精度.

精度

logistic 分布借助 std::exp 与 std::log 函数实现, 因此其精度取决于这些函数在给定平台上实现的准确程度. 在用非零的 position 参数计算分位数时, 可能发生灾难性抵消误差: 在这种情况下只能保证较低的 绝对误差.
