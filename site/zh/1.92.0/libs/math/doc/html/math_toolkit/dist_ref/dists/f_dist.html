F 分布是在检验两个样本是否具有相同方差时出现的连续分布. 若 χ2m 与 χ2n 是相互独立的随机变量, 分别服从自由度为 m 和 n 的卡方分布, 则检验统计量:

Fn,m = (χ2n / n) / (χ2m / m)

成员函数 
BOOST_MATH_GPU_ENABLED fisher_f_distribution(const RealType& df1, const RealType& df2);

构造分子自由度为 df1、分母自由度为 df2 的 F 分布.

要求 df1 和 df2 都大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom1()const;

返回分布的分子自由度参数.

BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom2()const;

返回分布的分母自由度参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域是 [0, +∞].

对以不完全 beta 函数表达的 CDF 直接求微分

得到如下两个公式:

fv1,v2(x) = y * ibeta_derivative(v2 / 2, v1 / 2, v2 / (v2 + v1 * x))

其中 y = (v2 * v1) / ((v2 + v1 * x) * (v2 + v1 * x))

以及

fv1,v2(x) = y * ibeta_derivative(v1 / 2, v2 / 2, v1 * x / (v2 + v1 * x))

其中 y = (z * v1 - x * v1 * v1) / z2

且 z = v2 + v1 * x

当 v1 * x > v2 时使用第一个公式, 否则使用第二个.

其目的是使 ibeta_derivative 的 x 实参远离 1, 以避免舍入误差.

cdf

利用关系:

p = ibeta(v1 / 2, v2 / 2, v1 * x / (v2 + v1 * x))

以及

:p = ibetac(v2 / 2, v1 / 2, v2 / (v2 + v1 * x))

当 v1 * x > v2 时使用第一个公式, 否则使用第二个.

其目的是使 ibeta 的 x 实参远离 1, 以避免舍入误差.

cdf 补函数

利用关系:

p = ibetac(v1 / 2, v2 / 2, v1 * x / (v2 + v1 * x))

以及

p = ibeta(v2 / 2, v1 / 2, v2 / (v2 + v1 * x))

当 v1 * x < v2 时使用第一个公式, 否则使用第二个.

其目的是使 ibeta 的 x 实参远离 1, 以避免舍入误差.

quantile

利用关系:

x = v2 * a / (v1 * b)

其中:

a = ibeta_inv(v1 / 2, v2 / 2, p)

以及

b = 1 - a

量 a 和 b 都由 ibeta_inv 计算, 无需上式所隐含的减法.
