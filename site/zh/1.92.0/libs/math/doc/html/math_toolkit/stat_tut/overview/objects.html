分布即对象

本库中每种分布都是一个类类型——一个带有成员函数的对象.

提示

如果你熟悉使用函数的统计库, 觉得 "分布即对象" 很陌生, 请参见 与其他统计库的比较.

Policy 提供对这些类行为的可选细粒度控制, 允许用户定制诸如错误如何处理、离散分布的分位数如何表现等行为.

把分布做成类类型有两方面的作用:

  • 它把分布的种类封装进 C++ 类型系统; 因此, 例如, Students-t 分布总是与 Chi-Squared 分布不同的 C++ 类型.
  • 分布对象存储与分布相关联的参数: 例如, Students-t 分布有一个控制分布形状的 自由度 参数. 构造 Students-t 对象时必须提供这个 自由度 参数.

尽管本库中的分布类是模板, 但存在基于 double 类型的 typedef, 它们大多采用分布的惯用名称 (除非与同名函数冲突: beta 和 gamma, 这种情况下使用默认模板参数——RealType = double——几乎同样方便). 这些 typedef 大概覆盖了 95% 的用例:

// using namespace boost::math; // Avoid potential ambiguity with names in std <random>
// Safer to declare specific functions with using statement(s):

using boost::math::beta_distribution;
using boost::math::binomial_distribution;
using boost::math::students_t;

// Construct a students_t distribution with 4 degrees of freedom:
students_t d1(4);

// Construct a double-precision beta distribution
// with parameters a = 10, b = 20
beta_distribution<> d2(10, 20); // Note: _distribution<> suffix !

如果你需要用 double 之外的类型来使用这些分布, 可以直接实例化模板: 模板名称与 double typedef 相同, 只是追加了 _distribution, 例如: Students t Distribution 或 Binomial Distribution:

// Construct a students_t distribution, of float type,
// with 4 degrees of freedom:
students_t_distribution<float> d3(4);

// Construct a binomial distribution, of long double type,
// with probability of success 0.3
// and 20 trials in total:
binomial_distribution<long double> d4(20, 0.3);

传给分布的参数可以通过 getter 成员函数访问:

d1.degrees_of_freedom();  // returns 4.0

这些都很好, 但到目前为止还不太有用. 我们通常想要的是能够计算这些分布的 累积分布函数 和 分位数 等.
