四元数超越函数

在本实现中, 四元数没有提供 log 或 sqrt, 并且 pow 同样仅限于指数的整数次幂. 这样做有几个原因: 一方面, 四元数的解析延拓等价物 ("分支切割") 尚待彻底研究 (至少对我而言...); 并且我们希望避免标准中复数的复数幂引入的荒谬结果 (它定义良好, 但标准并非如此...). 说到荒谬, 说 pow(0,0) 是 "由实现定义" 简直就是愚蠢至极...

不过, 我们确实提供了若干超越函数, 其中最主要的是指数函数. 本文作者把 "闭式公式" 的完整证明及其独立发明归于自己 (也有人称该公式早有发明, 例如 Shoemake 教授; 该公式也可能在几个世纪前就已被知晓, 但由于缺乏文献参考, 此事悬而未决, 有待进一步调查; 另一方面, 四元数上指数函数的定义和存在性当然是早已为人所知的事实). 基本上, 任何系数为实数、且在 C 中有闭式公式的收敛幂级数都可以移植到 H. 应请求, 更多此类超越函数可在后续修订中添加. 应当注意, 正是这些函数使得对 boost/math/special_functions/sinc.hpp 和 boost/math/special_functions/sinhc.hpp 头文件产生依赖.

exp 
template<typename T> quaternion<T> exp(quaternion<T> const & q);

计算四元数的指数.

cos 
template<typename T> quaternion<T>  cos(quaternion<T> const & q);

计算四元数的余弦

sin 
template<typename T> quaternion<T>  sin(quaternion<T> const & q);

计算四元数的正弦.

tan 
template<typename T> quaternion<T>  tan(quaternion<T> const & q);

计算四元数的正切.

cosh 
template<typename T> quaternion<T>  cosh(quaternion<T> const & q);

计算四元数的双曲余弦.

sinh 
template<typename T> quaternion<T>  sinh(quaternion<T> const & q);

计算四元数的双曲正弦.

tanh 
template<typename T> quaternion<T>  tanh(quaternion<T> const & q);

计算四元数的双曲正切.

pow 
template<typename T> quaternion<T>  pow(quaternion<T> const & q, int n);

计算四元数 q 的 n 次幂.
