四元数创建函数 

template<typename T> quaternion<T> spherical(T const & rho, T const & theta, T const & phi1, T const & phi2);
template<typename T> quaternion<T> semipolar(T const & rho, T const & alpha, T const & theta1, T const & theta2);
template<typename T> quaternion<T> multipolar(T const & rho1, T const & theta1, T const & rho2, T const & theta2);
template<typename T> quaternion<T> cylindrospherical(T const & t, T const & radius, T const & longitude, T const & latitude);
template<typename T> quaternion<T> cylindrical(T const & r, T const & angle, T const & h1, T const & h2);

这些函数以类似于 polar 构造复数的方式构造四元数, 因为四元数没有与极坐标严格等价的概念.

spherical 是 polar 的简单移植, 它的输入是一个 (正的) 幅值和超球面上的一个点, 该点由三个角度给出. 其中第一个角 theta 的自然范围是 -pi 到 +pi, 另外两个角的自然范围是 -pi/2 到 +pi/2 (与 R3 中通常的球坐标一样). 由于存在大量对称性和周期性, 即使幅值为负或角度超出其自然范围, 也不会发生任何异常. 不过, 预期的退化 (幅值为零时忽略角度设置...) 确实会发生.

cylindrical 同样是 R3 中通常的柱坐标的简单移植, 而柱坐标又是平面极坐标的另一种推广. 前两个输入是四元数第一个 C 分量的极坐标, 第三和第四个输入分别放入四元数的第三和第四个 R 分量.

multipolar 是极坐标的又一个简单推广. 这次, 四元数的两个 C 分量都以极坐标给出.

cylindrospherical 是四元数特有的. 把 H 视为 R 与 R3 的笛卡尔积通常很有意思 (四元数乘法此时具有一种特殊形式, 如这里给出的). 因此该函数从这种表示构造四元数, 其中 R3 分量以 R3 中通常的球坐标给出.

semipolar 是另一个四元数特有的生成器. 它的第一个输入是四元数的幅值, 第二个输入是范围 0 到 +pi/2 内的一个角度, 使得四元数前两个 C 分量的幅值分别是第一个输入与此角的正弦、余弦的乘积; 最后, 第三和第四个输入是范围 -pi/2 到 +pi/2 内的角度, 分别表示四元数第一个和第二个 C 分量的辐角. 一如既往, 即使本应为幅值的量是负数或角度超出自然范围, 也不会发生任何异常, 因为对称性和周期性会起作用.

在本版本的四元数实现中, 没有与复数值运算 arg 类似的运算, 因为情况要复杂一些. 单位四元数既与 R3 中的旋转相关, 也与 R4 中的旋转相关, 对应关系并不太复杂, 但目前缺少可用于实现转换的标准 (事实上的或法律上的) 矩阵库. 这应在后续修订中解决. 在此之前, 这里给出了针对 R3 的实现示例, 以及针对 R4 的示例 (example test file).
