椭圆积分求根算法比较

第二个例子比较四种求根算法, 用于在第一半径为 28、弧长为 300 时定位椭圆的第二半径, 涉及四种浮点类型: float、double、long double 以及一个 Boost.Multiprecision 类型 cpp_bin_float_50.

也就是说, 我们在求解:

4xE(sqrt(1 - 282 / x2)) - 300 = 0

在每种情况下, 目标精度都使用我们"推荐"的精度限制设置 (或至少是能成为良好起点的限制 - 它很可能在不诉诸不必要迭代的情况下给出接近完全精度的结果).

测试使用 Microsoft Visual Studio 2013 (Update 1) 和 GCC 4.9.1, 源码为 root_elliptic_finding.cpp.

计时不确定性 (尤其是使用 MSVC 时) 至少为归一化时间 'Norm' 的 5%.

为标示出"最佳"和"最差"算法, 相应结果以蓝色和红色突出显示. 当归一化时间在误差范围内无法区分时, 可以有不止一个"最佳"结果.

备注:

  • 所求解的函数现在的调用代价适中, 而求导数时的调用代价是不求导数时的两倍. 因此, 从无导数方法转到 Newton 迭代几乎没有改进. 然而, 一旦计算出第一导数, 第二导数几乎是免费的, 因此三阶方法 (Halley) 表现最好.
  • 在两种二阶方法中, 正如预期, Halley 表现最佳: Schroder 方法对 二次 收敛提供更好的保证, 而 Halley 依赖具有单根的光滑函数来给出 三次 收敛. Schroder 迭代为何常常不如 Newton 尚不完全清楚.
