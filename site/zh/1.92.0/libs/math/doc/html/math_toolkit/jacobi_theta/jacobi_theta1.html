Jacobi Theta 函数 θ1

概要 
#include <boost/math/special_functions/jacobi_theta.hpp>

namespace boost { namespace math {
    template <class T, class U>
    calculated-result-type jacobi_theta1(T x, U q);

    template <class T, class U, class Policy>
    calculated-result-type jacobi_theta1(T x, U q, const Policy&);

    template <class T, class U>
    calculated-result-type jacobi_theta1tau(T x, U tau);

    template <class T, class U, class Policy>
    calculated-result-type jacobi_theta1tau(T x, U tau, const Policy&);
}} // namespaces
说明

这些函数计算第一个 Jacobi Theta 函数 的值, 可以用 nome q 参数化:

也可以用虚数 τ 参数化:

nome q 被限制在定义域 (0, 1) 内, 否则返回 domain_error. 下图展示了 theta 函数在不同 q 值下的形态:

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

实现

q 参数化是使用 τ 参数化实现的, 其中 τ=-log(q)/π.
