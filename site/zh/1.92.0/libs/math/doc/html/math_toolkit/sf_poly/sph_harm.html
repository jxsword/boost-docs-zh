说明

当 T1 和 T2 是不同类型时, 这些函数的返回类型使用 结果类型计算规则 计算.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

template <class T1, class T2>
std::complex<calculated-result-type> spherical_harmonic(unsigned n, int m, T1 theta, T2 phi);

template <class T1, class T2, class Policy>
std::complex<calculated-result-type> spherical_harmonic(unsigned n, int m, T1 theta, T2 phi, const Policy&);

返回球谐函数 Ynm(theta, phi) 的值:

球谐函数 Ynm(theta, phi) 是球坐标下 Laplace 方程解的角向部分, 此时不存在方位角对称性.

注意

必须小心正确辨认此函数的参数: θ 取为极角 (余纬) 坐标, θ ∈ [0, π]; φ 取为方位角 (经度) 坐标, φ ∈ [0,2π). 这是物理学中使用的约定, 与 Mathematica 的函数 SpericalHarmonicY 所用的定义一致, 但与通常的数学约定相反.

一些其他来源在此函数的定义中包含了额外的 (-1)m Condon-Shortley 相位因子: 但请注意, 我们对关联 Legendre 多项式的定义已包含此项.

对 m > n, 本实现返回零

对于 [0, π] 之外的 θ 与 [0, 2π] 之外的 φ, 本实现遵循 Mathematica 所用的约定: 函数是周期的, 在 θ 方向上周期为 π, 在 φ 方向上周期为 2π. 请注意, 这不是对函数定义作简单应用所能得到的行为. 谨慎的用户应把 θ 和 φ 分别保持在 [0, π] 和 [0, 2π] 范围内.

参见: Weisstein, Eric W. "Spherical Harmonic." From MathWorld--A Wolfram Web Resource.

实现

这些函数用上文给出的公式相当直接地实现. 在从极坐标转换时采取了一些额外措施来防止舍入误差 (例如, 关联 Legendre 函数所用的 1-x2 项利用 x = cos(theta) 和 1-x2 = sin2(theta) 以无舍入误差的方式计算). 这些函数误差率的限制因素在于需要计算关联 Legendre 函数的根附近的值.
