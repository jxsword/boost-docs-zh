概述

八元数与 四元数 一样, 是复数的近亲.

八元数在理论物理中有一些应用.

实际而言, 八元数只是八个实数 (α,β,γ,δ,ε,ζ,η,θ) 的八元组, 我们可以将其写作 o = α + βi + γj + δk + εe' + ζi' + ηj' + θk' 的形式, 其中 i、j 和 k 与四元数中的对象相同, 而 e'、i'、j' 和 k' 是不同的对象, 它们所扮演的角色与 i (或 j 或 k) 本质上属于同一类.

在八元数集合上定义了加法和乘法, 它们是四元数对应运算的推广. 这一次的主要新颖之处在于 乘法不仅不满足交换律, 现在甚至连结合律都不满足 (即存在八元数 x、y 和 z 使得 x(yz) ≠ (xy)z). 记忆的一种方法是使用下面的乘法表:

一些传统构造, 例如指数, 无需太多改变即可延拓到八元数领域, 但其他一些, 例如取平方根, 则不行 (指数具有封闭形式是作者的结果, 而指数对八元数存在这一事实早在很久以前就已为人所知).
