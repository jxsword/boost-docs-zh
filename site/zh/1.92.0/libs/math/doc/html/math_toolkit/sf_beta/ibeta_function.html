说明

共有四个 incomplete beta functions: 其中两个是归一化版本 (也称为 regularized beta 函数), 返回 [0, 1] 范围内的值; 另外两个未归一化, 返回 [0, beta(a, b)] 范围内的值. 对统计应用感兴趣的用户应当使用归一化 (即 regularized) 版本 (ibeta 和 ibetac).

所有这些函数都要求 0 <= x <= 1.

归一化函数 ibeta 和 ibetac 要求 a,b >= 0, 并且要求 a 和 b 不同时为零.

函数 beta 和 betac 要求 a,b > 0.

当 T1、T2 和 T3 是不同类型时, 这些函数的返回类型使用 结果类型计算规则 计算.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

template <class T1, class T2, class T3>

template <class T1, class T2, class T3, class Policy>

测试分为两组: 抽点测试把取自 Mathworld's online function evaluator 的值与本实现进行比较: 它们为实现提供了基本的"健全性检查", 每个实现定义域中各有一个抽点测试 (见下文的实现说明).

精度测试使用以极高精度生成的数据 (使用 NTL RR class 并设为 1000 位精度), 采用"教科书式"的连分数表示 (参见下文实现讨论中的第一个连分数). 注意, 实现中 并未 使用这个连分数, 因此我们拥有的测试数据与代码完全独立.
