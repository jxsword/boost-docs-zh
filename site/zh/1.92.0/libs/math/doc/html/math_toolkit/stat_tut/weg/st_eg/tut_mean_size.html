估计为使单样本 Student t 检验给出显著结果样本量需要多大

设想你对单个样本进行了 Student t 检验以检查测量中的系统误差. 设想结果处于临界状态. 此时人们可能会去收集更多数据, 但先问一句 "还要多少?" 或许更审慎. students_t_distribution 类的参数估计器可以提供这一信息.

本节基于 students_t_single_sample.cpp 中的示例代码, 我们先定义一个过程, 它将打印各种置信水平下估计样本量的表:

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

现在是重要的部分: 所需的样本量. 类 students_t_distribution 有一个静态成员函数 find_degrees_of_freedom, 它会计算为给出明确结果所需的样本量要多大.

第一个参数是你希望能够检测到的均值之差, 这里是样本均值与真实均值之差的绝对值.

接下来是两个概率值: alpha 和 beta. alpha 是当零假设实际为真时拒绝它的最大可接受风险. beta 是当零假设实际为假时未能拒绝它的最大可接受风险. 另请注意, 对双侧检验, alpha 必须除以 2.

函数的最后一个参数是样本的标准差.

在本例中, 我们假设 alpha 和 beta 相同, 并调用 find_degrees_of_freedom 两次: 一次以 alpha 用于单侧检验, 一次以 alpha/2 用于双侧检验.

   for(unsigned i = 0; i < sizeof(alpha)/sizeof(alpha[0]); ++i)
   {
      // Confidence value:
      cout << fixed << setprecision(3) << setw(10) << right << 100 * (1-alpha[i]);
      // calculate df for single sided test:
      double df = students_t::find_degrees_of_freedom(
         fabs(M - Sm), alpha[i], alpha[i], Sd);
      // convert to sample size:
      double size = ceil(df) + 1;
      // Print size:
      cout << fixed << setprecision(0) << setw(16) << right << size;
      // calculate df for two sided test:
      df = students_t::find_degrees_of_freedom(
         fabs(M - Sm), alpha[i]/2, alpha[i], Sd);
      // convert to sample size:
      size = ceil(df) + 1;
      // Print size:
      cout << fixed << setprecision(0) << setw(16) << right << size << endl;
   }
   cout << endl;
}
