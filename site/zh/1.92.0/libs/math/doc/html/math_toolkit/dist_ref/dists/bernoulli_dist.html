Bernoulli 分布 

#include <boost/math/distributions/bernoulli.hpp>
namespace boost{ namespace math{
 template <class RealType = double,
           class Policy   = policies::policy<> >
 class bernoulli_distribution;

 typedef bernoulli_distribution<> bernoulli;

 template <class RealType, class Policy>
 class bernoulli_distribution
 {
 public:
    typedef RealType  value_type;
    typedef Policy    policy_type;

    BOOST_MATH_GPU_ENABLED bernoulli_distribution(RealType p); // Constructor.
    // Accessor function.
    BOOST_MATH_GPU_ENABLED RealType success_fraction() const
    // Probability of success (as a fraction).
 };
}} // namespaces

Bernoulli 分布是单次试验结果的离散分布, 只有两个结果: 0 (失败) 或 1 (成功), 成功概率为 p.

Bernoulli 分布是最简单的构建块, 独立 Bernoulli 试验序列的其他离散分布都可以建立在它之上.

Bernoulli 分布就是只有一次试验的二项分布 (k = 1, p).

概率密度函数 pdf

f(0) = 1 - p, f(1) = p

累积分布函数

D(k) = if (k == 0) 1 - p else 1

成员函数 
BOOST_MATH_GPU_ENABLED bernoulli_distribution(RealType p);

构造成功比例为 p 的 bernoulli distribution.

BOOST_MATH_GPU_ENABLED RealType success_fraction() const

返回此分布的 success_fraction 参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域是 0 和 1, 有效的支撑范围只有 0 或 1.

在此范围之外, 函数未定义, 或可能抛出 domain_error 异常并提供错误消息.

精度

Bernoulli 分布用简单的算术运算符实现, 因此误差应在一两个 epsilon 之内.
