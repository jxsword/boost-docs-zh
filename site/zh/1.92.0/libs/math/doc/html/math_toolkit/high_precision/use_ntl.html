使用 NTL 库

NTL::RR (一种任意固定精度的浮点数字类型) 可以通过 boost/math/bindings/rr.hpp 中的绑定使用. 详情参见 NTL: A Library for doing Number Theory by Victor Shoup.

建议新项目改用 Boost.Multiprecision.

遗憾的是 NTL::RR 并不完全满足我们的概念要求, 因此有一个非常薄的包装类 boost::math::ntl::RR 定义于 boost/math/bindings/rr.hpp, 你应当用它代替 NTL::RR. 该类旨在作为"真实" NTL::RR 的即插即用替代品, 它添加了一些语法糖以取悦本库, 外加一些 NTL 未实现的标准库函数.

对基于 Lanczos 近似 的那些函数, 绑定定义了多达 61 项、精度约至 3e-113 的一系列近似. 因此这为使用 NTL::RR 时本库定义的大多数函数设置了精度上限.
