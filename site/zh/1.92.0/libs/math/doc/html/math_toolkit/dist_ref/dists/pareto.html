Pareto 分布 

#include <boost/math/distributions/pareto.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class pareto_distribution;

typedef pareto_distribution<> pareto;

template <class RealType, class Policy>
class pareto_distribution
{
public:
   typedef RealType value_type;
   // Constructor:
   BOOST_MATH_GPU_ENABLED pareto_distribution(RealType scale = 1, RealType shape = 1)
   // Accessors:
   BOOST_MATH_GPU_ENABLED RealType scale()const;
   BOOST_MATH_GPU_ENABLED RealType shape()const;
};

}} // namespaces

Pareto 分布 是连续分布, 其 概率密度函数 (pdf) 为:

f(x; α, β) = αβα / xα+ 1

对于形状参数 α > 0 与尺度参数 β > 0, 若 x < β, 则 pdf 为零.

Pareto 分布通常用于描述相对于较小者的较大者. 一个经典例子是: 20% 的人口拥有 80% 的财富.

相关分布
成员函数 
BOOST_MATH_GPU_ENABLED pareto_distribution(RealType scale = 1, RealType shape = 1);

构造一个 pareto 分布, 其形状为 shape, 尺度为 scale.

要求 shape 与 scale 参数均大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的scale参数.

BOOST_MATH_GPU_ENABLED RealType shape()const;

返回此分布的shape参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的支持域为 [scale, ∞].

在此分布中, logcdf 的实现经过专门化, 以提高数值精度.

精度

Pareto 分布基于标准库 exp 函数以及 expm1 实现, 因此误差应当极小, 通常只有几个 epsilon.

当概率接近 1 (或概率的补接近 0) 时, 另见 为何使用补集?.
