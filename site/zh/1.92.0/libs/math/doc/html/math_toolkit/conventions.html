文档约定

本文档旨在使用以下命名与排版约定.

  • C++ 代码位于 fixed width font 中, 并以彩色语法高亮显示, 例如 double.
  • 其他代码位于代码块 teletype fixed-width font 中.
  • 需要你提供的可替换文本位于 italics 中.
  • 如果名称指代自由函数, 其写法如下: free_function(); 也就是说, 它位于 code font 中, 且名称后跟 () 以表明它是自由函数.
  • 如果名称指代类模板, 其写法如下: class_template<>; 也就是说, 它以代码字体呈现, 且名称后跟 <> 以表明它是类模板.
  • 如果名称指代函数式宏, 其写法如下: MACRO(); 也就是说, 它以代码字体的大写形式呈现, 且名称后跟 () 以表明它是函数式宏. 对象式宏则不带结尾的 ().
  • 在泛型编程意义上指代概念的名称 (如模板参数名) 以 CamelCase 书写.
