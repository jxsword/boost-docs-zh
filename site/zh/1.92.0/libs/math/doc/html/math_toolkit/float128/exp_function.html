指数函数

在 GCC 上使用任何 quadmath expq 函数时曾有一个缺陷: GCC bug #60349, 由 mingw-64 bug #368 引起.

为规避该缺陷, boost/cstdfloat.hpp 曾临时提供了 128 位 exp 的替代实现.

mingw 缺陷已于 2014-03-12 修复, GCC 6.1.1 现在按预期工作.

提示

必须链接到 quadmath 库, 例如在 b2/bjam 文件中: <linkflags>-lquadmath
