Lanczos 平滑导数

概要 

#include <boost/math/differentiation/lanczos_smoothing.hpp>

namespace boost::math::differentiation {

    template <class Real, size_t order=1>
    class discrete_lanczos_derivative {
    public:
        discrete_lanczos_derivative(Real spacing,
                                    size_t n = 18,
                                    size_t approximation_order = 3);

        template<class RandomAccessContainer>
        Real operator()(RandomAccessContainer const & v, size_t i) const;

        template<class RandomAccessContainer>
        void operator()(RandomAccessContainer const & v, RandomAccessContainer & dvdt) const;

        template<class RandomAccessContainer>
        RandomAccessContainer operator()(RandomAccessContainer const & v) const;

        Real get_spacing() const;
    };

} // namespaces

说明

discrete_lanczos_derivative 类计算等间距值的有噪序列 v 的导数的有限差分近似. 基本用法是

std::vector<double> v(500);
// fill v with noisy data.
double spacing = 0.001;
using boost::math::differentiation::discrete_lanczos_derivative;
auto lanczos = discrete_lanczos_derivative(spacing);
// Compute dvdt at index 30:
double dvdt30 = lanczos(v, 30);
// Compute derivative of entire vector:
std::vector<double> dvdt = lanczos(v);

还可以计算抑制噪声的二阶导数. 语法如下:

std::vector<double> v(500);
// fill v with noisy data.
auto lanczos = lanczos_derivative<double, 2>(spacing);
// evaluate second derivative at a point:
double d2vdt2 = lanczos(v, 18);
// evaluate second derivative of entire vector:
std::vector<double> d2vdt2 = lanczos(v);

对注重内存的程序员, 可以按如下方式复用导数的内存空间:

std::vector<double> v(500);
std::vector<double> dvdt(500);
// . . . define spacing, create and instance of discrete_lanczos_derivative

// populate dvdt, perhaps in a loop:
lanczos(v, dvdt);

若数据的方差为 σ2, 则计算出的导数的方差约为 σ2p3 n-3 Δ t-2, 即随逼近阶 p 三次方增长, 随数据方差线性增长, 并按滤波器长度 n 的立方衰减. 此外, 我们不能忘记离散化误差, 它是 O(Δ tp): 你可以随意调整逼近阶 p 与滤波器长度 n:

size_t n = 12;
size_t p = 2;
auto lanczos = lanczos_derivative(spacing, n, p);
double dvdt = lanczos(v, i);

若 p=2n, 则离散 Lanczos 导数不平滑: 它退化为标准的 2n+1 点有限差分公式. 当 p>2n 时会触发断言, 因为滤波器无定义.

在我们针对加性高斯白噪声 (AWGN) 的测试中, 我们发现误差随 n 单调递减, 这与上述理论的预期一致. 因此 n 的选择很简单: 在满足速度要求的前提下尽可能大 (更大的 n 意味着更长的滤波器因而更多计算), 同时要权衡过拟合以及对非平稳性求平均的危险.

给定 n 时, 逼近阶 p 的选择更为困难. 若认为你的信号是多项式, 把 p 设得大于多项式次数是没有意义的 - 不过取 p 小于该次数可能是明智的.

对一个被 AWGN 污染的正弦信号, 我们做了一些测试: SNR = 1 时 p = n/8 效果最好; SNR = 10 时 p = n/7 最好; SNR = 100 时 p = n/6 是最合理的选择. SNR = 0.1 时该方法似乎失效. 强烈建议用户谨慎使用这些结果: 它们没有理论依据, 且是从单一情形外推而来的.

遗憾的是, 滤波器是在运行时计算的 - 逼近阶与滤波器长度的组合数量巨大, 使得必须存储的滤波器数量对编译期数据而言过于庞大. 构造函数调用负责计算滤波器. 由于每个滤波器长度为 2n+1, 共有 n 个滤波器, 且每个元素由 p 个求和项组成, 构造函数调用的复杂度为 O(n2p). 这并不便宜 - 尽管大多数情况下只需要较小的 p 和不太大的 n (< 20). 具体而言, 在作者 2.7GHz 的 Intel 笔记本 CPU 上, n=16, p=3 的滤波器需要 9 微秒来计算. 这绝非可以忽略, 因此滤波器可用于多份数据, 甚至可以在线程间共享:

std::vector<double> v1(500);
std::vector<double> v2(500);
// fill v1, v2 with noisy data.
auto lanczos = lanczos_derivative(spacing);
std::vector<double> dv1dt = lanczos(v1); // threadsafe
std::vector<double> dv2dt = lanczos(v2); // threadsafe
// need to use a different spacing?
lanczos.reset_spacing(0.02); // not threadsafe

实现遵循 McDevitt, 2012, 他极大地扩展了 Lanczos 的思想, 为有噪声等间距数据的数值微分创建了一个非常通用的框架.

示例

我们从 LIGO signal 中提取了一些数据, 分别用 (n, p) = (60, 4) 的 Lanczos 平滑导数以及 (n, p) = (4, 8) 的 (非平滑) 导数对其求导.

原始数据为橙色, 平滑导数为蓝色, 非平滑的标准有限差分公式为灰色. (每条时间序列都经过重缩放以画在同一张图中.) 可以看到, 平滑导数很好地跟踪了趋势的上升与下降, 而标准有限差分公式产生胡言乱语并放大噪声.

注意事项

当 p 较大时, 滤波器的计算是病态的. 为缓解这一问题, 我们用更高精度计算滤波器, 再把结果转换为所需类型. 然而这只是把问题推向更大的 p. 实践中这不成问题, 因为大的 p 对应较弱的去噪能力, 但请记住这一点.

此外, -ffast-math 标志对这些函数的速度影响非常大. 在我们的基准测试中, 启用该标志后快了 50%, 远大于我们通常打开此标志所见到的性能提升. 因此, 如果默认性能不够, 可以使用此标志, 尽管它自带一些问题.

这需要 C++17 if constexpr.
