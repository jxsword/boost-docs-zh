按指定表示距离 (ULP) 推进浮点值 float_advance

函数 float_advance 将浮点数推进指定的 ULP 数.

概要 
#include <boost/math/special_functions/next.hpp>

namespace boost{ namespace math{

template <class FPT>
FPT float_advance(FPT val, int distance);

}} // namespaces
说明 - float_advance

返回浮点数 r, 使得 float_distance(val, r) == distance.
