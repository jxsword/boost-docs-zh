从 C# 中使用这些分布

当使用 Microsoft 的公共语言运行时 (CLR) 选项构建时, 本库中的分布可以从 C# 编程语言中使用.

这种用法的示例见 Distribution Explorer 示例. 源代码见 boost-root/libs/math/dot_net_example: 该应用程序由一个包含实际分布的 C++ .dll 和一个允许你探索其属性的 C# GUI 组成.
