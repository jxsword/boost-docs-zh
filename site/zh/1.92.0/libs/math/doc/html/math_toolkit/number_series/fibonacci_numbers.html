Fibonacci 数

Fibonacci numbers (Fn) 遵循线性递推 Fn=Fn-1+Fn-2, 起始为 F0=0、F1=1.

概要 
#include <boost/math/special_functions/fibonacci.hpp>

namespace boost { namespace math {

template <class T, class Policy>
constexpr T fibonacci(unsigned long long n) // Checked version (default policy)

template <class T, class Policy>
constexpr T fibonacci(unsigned long long n, const Policy &pol) // Checked version (policy for errors etc.)

template <typename T>
constexpr T unchecked_fibonacci(unsigned long long n) noexcept(std::is_fundamental<T>::value); {  // Unchecked version (no policy).

}} // namespaces

这些函数返回 Fn, 其中输入为 n, 类型为 T.

说明

带检查的版本在开始计算前检查上溢. 若 n 大到结果无法用类型 T 表示, 则调用 overflow_error. 上溢检查在溢出极限附近容易有差一 (off-by-one) 错误. 关于该检查的更多细节参见下文 Binet 公式.

这些函数从 C++14 起都是 constexpr, 另外当 T 是基本类型时 unchecked_fibonacci 是 noexcept.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

在带检查版本中, 若上溢检查通过, 则调用无检查版本计算所需的 Fn. 带检查版本因上溢检查的开销而较慢.

生成器 
#include <boost/math/special_functions/fibonacci.hpp>

template <typename T>
class fibonacci_generator {
  // returns consecutive fibonacci number starting from 0, 1, 1, 2, ...
  T operator()();
  // reset the generator to start from nth fibonacci number
  void set(unsigned long long n);
}

生成器返回连续的 fibonacci 数, 从 0, 1, 1, 2... 开始.

可以使用 set() 修改生成器的状态, 这会使生成器从第 n[sup th] 个 fibonacci 数开始返回连续的 fibonacci 数.

boost::math::fibonacci_generator<int> gen;
int x = gen(); // x is 0
int y = gen(); // y is 1
for(int i = 0; i < 5; ++i) // this loop is same as gen.set(7);
    gen();
int z = gen(); // z is 13

对所有基本类型, 生成器都不抛出异常, 并且不会检查上溢.

类型要求

该类型必须是支持 +、-、* 的算术类型, 并且可以由平凡整数类型初始化.

示例

文件 reciprocal_fibonacci_constant.cpp 使用 fibonacci_generator 以 1000 位精度计算 fibonacci 常数的倒数, 如下所示:

#include <boost/math/special_functions/fibonacci.hpp>
#include <boost/multiprecision/mpfr.hpp>
#include <iomanip>
#include <iostream>

int main() {
    using Real = boost::multiprecision::mpfr_float_1000;
    boost::math::fibonacci_generator<Real> gen;
    gen.set(1); // start producing values from 1st fibonacci number
    Real ans = 0;
    const int ITR = 1000;
    for (int i = 0; i < ITR; ++i) {
        ans += 1.0 / gen();
    }
    std::cout << std::setprecision(1000) << "Reciprocal fibonacci constant after "
              << ITR << " iterations is: " << ans << std::endl;
}
实现

计算 fibonacci 数的时间复杂度为 O(log n), 不考虑乘法和加法的时间复杂度 (其中 n 是输入参数). 该实现是 Dijkstra's identities 的迭代版本, 只是简单地沿着 n 的各位向下走.

Binet 公式

存在计算 fibonacci 数的封闭形式表达式, 但由于它有精度问题 (使用浮点计算), 故未予实现.

不过, 在带检查的版本中使用了近似公式进行上溢检查.
