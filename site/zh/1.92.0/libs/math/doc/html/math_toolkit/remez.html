Remez 方法

Remez algorithm 是一种定位函数的极小化极大有理近似的方法学. 这篇短文对该方法作了简要概述, 但不应视为全面的理论论述; 为此请查阅你喜爱的教科书.

设想你想用有理函数 R(x) 近似某个函数 f(x), 其中 R(x) 可以是多项式 P(x), 也可以是两个多项式之比 P(x)/Q(x) (有理函数). 我们首先集中讨论多项式情形, 因为它远比其他情形容易处理, 稍后再扩展到完整的有理函数情形.

我们想找到"最佳"有理近似, 其中"最佳"定义为与 f(x) 偏差最小的近似. 我们可以用误差函数度量偏差:

Eabs(x) = f(x) - R(x)

它以绝对误差表示, 但我们同样可以使用相对误差:

Erel(x) = (f(x) - R(x)) / |f(x)|

实际上, 我们可以按任意方式缩放误差函数, 这对数学没有影响, 尽管上面两种形式几乎涵盖了你可能遇到的所有实际情形.

极小化极大有理函数 R(x) 定义为使误差函数的最大值最小的函数. Chebyshev 证明 R(x) 存在唯一的极小化极大解, 具有以下性质:

  • 如果 R(x) 是 N 次多项式, 那么有 N+2 个未知数: 多项式的 N+1 个系数, 以及误差函数的最大值.
  • 误差函数有 N+1 个根, 以及 N+2 个极值 (极小值和极大值).
  • 极值符号交替, 且幅度相同.

这意味着, 如果我们知道误差函数极值的位置, 就可以写出 N+2 个联立方程:

R(xi) + (-1)iE = f(xi)

其中 E 是最大误差项, 而 xi 是误差函数的 N+2 个极值的横坐标值. 之后求解联立方程以得到多项式系数和误差项就是轻而易举的事了.

遗憾的是, 我们并不知道误差函数的极值位于何处!

Remez 方法

Remez 方法是一种迭代技术, 在广泛的假设下, 它会收敛到误差函数的极值, 从而收敛到极小化极大解.

在下面的讨论中, 我们将用一个具体例子来说明 Remez 方法: 函数 ex 在区间 [-1, 1] 上的近似.

在开始 Remez 方法之前, 我们必须获得误差函数极值位置的初始值. 我们可以"猜测"这些值, 但通过先构造 f(x) 的插值多项式近似, 可以获得更接近的第一个近似.

为了获得插值多项式的 N+1 个系数, 我们需要 N+1 个点 /(x0…xN): 让插值形式经过每个点, 得到 N+1 个联立方程:

f(xi) = P(xi) = c0 + c1xi … + cNxiN

可以对其求解 c0 …cN, 即 P(x) 中的系数.

显然这不是极小化极大解, 实际上我们唯一的保证是 f(x) 和 P(x) 在 N+1 个位置相触, 在这些点之外误差可能任意大. 不过, 我们显然希望这个初始近似尽可能接近 f(x), 而事实证明, 使用正交多项式的零点作为初始插值点是一个好选择. 在我们的例子中, 我们将使用 Chebyshev 多项式的零点, 因为它们特别容易计算; 对 4 次多项式插值并度量 相对误差, 我们得到如下误差函数:

虽然这已经是相当好的近似, 但从误差函数的形状来看, 我们显然可以做得更好. 在正式开始 Remez 方法之前, 我们还要执行一步: 找出误差函数的所有极值, 并把这些位置存储为我们的初始 Chebyshev 控制点.

注释

在多项式近似的简单情形中, 通过对 Chebyshev 多项式的根进行插值, 我们实际上创建了该函数的 Chebyshev 近似: 就 绝对误差 而言, 这是插值形式所能达到的最好的先验选择, 并且通常非常接近极小化极大解.

然而, 如果我们想针对 相对误差 优化, 或者近似是一个有理函数, 那么初始 Chebyshev 解可能离理想的极小化极大解相当远.

关于所涉理论的更技术性的讨论可参见这份 online course.

Remez 第 1 步

Remez 方法的第一步, 是在给定当前 N+2 个 Chebyshev 控制点 xi 的条件下, 求解 N+2 个联立方程:

P(xi) + (-1)iE = f(xi)

以获得误差项 E 和多项式 P(x) 的系数.

这给了我们一个对 f(x) 的新近似, 它在每个控制点处具有相同的误差 E, 并且其误差函数在控制点处 符号交替. 但这仍不一定是极小化极大解: 因为控制点可能不在误差函数的极值处. 第一步之后, 我们的近似的误差函数看起来如下:

显然这仍不是极小化极大解, 因为控制点不在极值处, 但最大相对误差现已降至 5.6x10-4.

Remez 第 2 步

第二步是定位新近似的极值, 我们分两个阶段进行: 首先, 由于误差函数在每个控制点处变号, 在 N+2 个控制点的每一对之间必有 N+1 个误差函数的根. 用标准求根技术找到这些根后, 我们知道每对根之间界定了 N 个极值, 加上区间端点与第一个和最后一个根之间各一个, 共 N+2 个. 然后可以用标准函数最小化技术找到这 N+2 个极值.

现在我们面临一个选择: 多点交换, 还是单点交换.

在单点交换中, 我们把最靠近最大极值的控制点移到该极值的横坐标处.

在多点交换中, 我们把所有当前控制点换成极值的位置.

有理近似

如果我们想把 Remez 方法扩展到如下形式的有理近似

f(x) = R(x) = P(x) / Q(x)

其中 P(x) 和 Q(x) 是多项式, 那么我们像之前一样进行, 只是现在如果 P(x) 的阶为 N 而 Q(x) 的阶为 M, 我们就有 N+M+2 个未知数. 这里假定 Q(x) 被规范化, 使其首项系数为 1, 因此多项式系数共有 N+M+1 个, 外加误差项 E.

待解的联立方程现在是:

P(xi) / Q(xi) + (-1)iE = f(xi)

在 N+M+2 个控制点 xi 处求值.

遗憾的是, 这些方程对误差项 E 而言是非线性的: 只有在知道 E 时才能求解它们, 而 E 却是未知数之一!

求解这些方程通常采用的方法是迭代法: 我们猜测 E 的值, 解方程得到 E 的新值 (以及多项式系数), 然后把 E 的新值作为下一次猜测. 重复该方法, 直到 E 收敛到稳定值.

这些复杂因素会相当大地延长开发有理近似所需的运行时间. 尽管如此, 人们常常仍希望获得有理近似而非多项式近似: 与多项式替代方案相比, 有理近似往往能以更高的精度和效率匹配更难近似的函数. 例如, 取我们前面近似 ex 的例子: 用 4 阶多项式获得了 5x10-4 的精度. 如果把两个未知数移入分母, 得到一对 2 阶多项式并重新最小化, 峰值相对误差降至 8.7x10-5. 在总项数相同的情况下, 精度提高了 5 倍.

实践考量

大多数近似论著作到此为止. 然而, 从实践的角度看, 大部分工作在于找到正确的近似形式, 然后说服 Remez 方法收敛到一个解.

到目前为止, 我们使用的是直接近似:

f(x) = R(x)

但只有当 f(x) 光滑时, 这才会收敛到一个有用的近似. 此外, 求值有理形式时的舍入误差意味着它永远无法比机器精度内几个 epsilon 更接近. 因此, 这种直接近似形式通常留给我们想要效率而非精度的情形.

改善这一状况的第一步通常是把 f(x) 拆分成一个可以用其他方法精确计算的主导部分, 和一个变化缓慢、可用有理近似逼近的余项. 我们可能想写成:

f(x) = g(x) + R(x)

其中 g(x) 是 f(x) 的主导部分; 但如果 f(x)/g(x) 在所关心的区间上近似为常数, 那么:

f(x) = g(x)(c + R(x))

会得到好得多的解: 这里 c 是常量, 为 f(x)/g(x) 的近似值, 而 R(x) 与 c 相比通常极小. 在这种情况下, 如果 R(x) 针对绝对误差优化, 那么只要其误差与常量 c 相比很小, 当 R(x) 加到 c 上时, 该误差实际上会被抹掉.

困难之处显然在于为你的函数找到要提取的正确的 g(x): 函数的渐近行为往往会给出线索, 例如函数 erfc 变得正比于 e-x2/x, 此时 x 变大. 因此使用:

erfc(z) = (C + R(x)) e-x2/x

作为近似形式看起来是一个显而易见的尝试, 并且确实能得到有用的近似.

然而, 随后的困难变成了极小化极大解的收敛问题. 遗憾的是, 众所周知, 对某些函数, Remez 方法可能导致发散行为, 即使初始起始近似相当好. 此外, 上文第一步 Remez 求得的解不理想的情况并不罕见: 待解的方程通常"刚性", 常常非常接近奇异; 即使假设确实找到了解, 舍入误差和快速变化的误差函数也可能导致误差函数实际上没有按要求在每个控制点处变号. 如果发生这种情况, 对 Remez 方法是致命的. 还可能得到数学上完全有效但计算上毫无用处的解: 要么因为有理函数的计算中存在不可避免的舍入误差量, 要么因为分母在近似区间上有一个或多个根. 在后一种情况下, 尽管近似在根处可能有正确的极限值, 但该近似仍然无用.

假设近似没有任何致命错误, 唯一的问题是对极小化极大解的充分收敛, 那么目标是在开始 Remez 方法之前尽可能接近极小化极大解. 使用 Chebyshev 多项式的零点进行初始插值是一个好的开始, 但在处理相对误差和/或有理 (而非多项式) 近似时可能并不理想. 一种方法是把初始插值点向一端偏斜: 例如, 如果我们把 Chebyshev 多项式的根提升到大于 1 的正幂, 那么根将偏向 [-1,1] 区间的中部; 而小于 1 的正幂会使它们偏向任一端. 更有用的是, 如果我们先把点重新缩放到 [0,1] 再提升到正幂, 就可以把它们向左或向右偏斜. 回到我们 ex 在 [-1,1] 上的例子, 初始插值形式离极小化极大解还有一段距离:

Remez 方法检查清单

下面列出 Remez 方法出问题时需要检查的一些事项, 这绝不是一个详尽的清单, 但希望它会有用.

  • 函数是否足够光滑? 能否把它更好地分离成快速变化的部分和渐近部分?
  • 被近似的函数中是否有任何"突起"? 在函数改变计算方法时, 或者在某个根或无穷大被约掉时检查问题. 显著迹象是存在一个 Remez 方法不收敛的狭窄区域.
  • 检查你的计算是否有足够的精度: 记住 Remez 方法作用于近似与被近似函数之间的差, 因此你可用的精度位数必须多于所构建近似的精度. 例如在 double 精度下, 你不应指望能得到优于 float 精度的近似.
  • 在开始 Remez 步骤之前, 尝试使初始插值近似偏斜以最小化误差.
  • 如果近似从一个起始位置不收敛或病态, 尝试从另一个位置开始.
  • 如果有理函数不收敛, 可以先最小化一个多项式 (这没有任何问题), 然后把一项从分子轮换到分母再重新最小化. 理论上, 可以一次一项地继续把项从分子移到分母, 然后重新最小化, 并在每个阶段保留最后一组控制点.
  • 尝试使用更小的区间. 也可以先在一个 (小) 区间上优化, 把控制点重新缩放到更大的区间上, 然后重新最小化.
  • 保持横坐标值较小: 使用变量代换把横坐标保持在比如 [0, b] 上, 其中 b 为某个较小的值.
