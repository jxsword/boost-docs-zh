命名空间

所有数学函数和分布都在 namespace boost::math 中.

例如, namespace boost::math 中的 Students-t 分布模板是

template <class RealType> class students_t_distribution

并且可以借助保留名 students_t (用于 RealType double) 来实例化

typedef students_t_distribution<double> students_t;

student_t mydist(10);
警告

一些分布名也用于 std 随机库, 为避免歧义风险, 最好使用显式 using 声明, 例如: using boost::math::students_t_distribution

不打算供应用程序使用的函数位于 boost::math::detail 中.

可能具有更广泛用途的函数, 如 digits (significand, 尾数) 、max_value、min_value 和 epsilon, 位于 boost::math::tools 中.

Policy 与配置信息位于 namespace boost::math::policies.

提示

许多代码片段假定隐式命名空间, 例如 std:: 或 boost::math.
