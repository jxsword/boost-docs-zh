极小极大近似与 Remez 算法

目录 libs/math/minimax 中包含一个交互式命令行程序, 用于使用 Remez 算法生成极小极大近似. 多项式近似和有理近似都受支持, 尽管后者难以收敛: 有理形式收敛失败并不罕见. 多项式近似不存在这类限制, 它们应当总能平滑收敛.

值得强调的是, 为函数开发有理近似往往并非易事, 有许多书专门讨论这一主题. 要使用该工具, 你需要对 Remez 算法是什么, 以及你想要达到的近似的一般形式有合理的把握.

如果你还不熟悉 Remez 方法, 应先阅读 简要介绍 Remez 算法原理的背景文章.

该程序由两部分组成:

main.cpp

包含命令行解析器, 以及对 Remez 代码的所有调用.

f.cpp

包含待近似的函数.

因此要使用该工具, 你必须修改 f.cpp 使其返回待近似的函数. 该工具支持在同一个编译好的程序中包含多个函数近似: 每个近似作为一个单独的变体:

NTL::RR f(const NTL::RR& x, int variant);

返回函数 variant 在点 x 处的值. 因此如果愿意, 你只需在已有示例之后把待近似的函数作为一个新变体添加进去.

除了这两个文件外, 该程序还需要链接到 打过补丁的 NTL 库才能编译.

注意, 函数 f 必须返回近似中的有理部分: 例如, 如果你要近似函数 f(x), 那么常见的做法是使用:

f(x) = g(x)(Y + R(x))

其中 g(x) 是 f(x) 的主导部分, Y 是某个常数, R(x) 是有理近似部分, 通常针对相对于 |Y| 的较小绝对误差进行优化.

在这种情况下, 你会定义 f 返回 f(x)/g(x), 然后把近似的 y 偏移设为 Y (见下面的命令行选项).

还有许多其他形式可行, 但在所有情况下目标都是把 f(x) 拆分为两部分: 一部分是可以用标准数学函数轻松求值的主导部分, 另一部分是平滑且缓慢变化的有理近似部分. 更多示例请参阅你手头的教科书.

该程序的命令行选项如下:

variant N

把当前函数变体设为 N. 这样就能把多个待近似函数编译到同一个可执行文件中. 默认为 0.

range a b

把近似的定义域设为区间 [a,b], 默认为 [0,1].

relative

让 Remez 代码针对相对误差进行优化. 这是程序启动时的默认设置. 注意, 只有当 f(x) 在待优化的范围上没有零点时才能使用相对误差.

absolute

让 Remez 代码针对绝对误差进行优化.

pin [true|false]

“固定”代码, 使有理近似通过原点. 显然, 只有当 R(0) 必须为零时才把它设为 true. 这通常用于既要保留 [0,0] 处的零点, 又要针对相对误差进行优化的场合.

order N D

把近似的阶数设为分子 N 阶、分母 D 阶. 如果 D 为零, 则结果为多项式近似. 总共有 N+D+2 个系数, 如果 pin 被设为 true, 则分子的第一个系数为零, 而分母的第一个系数总是 1.

working-precision N

把 NTL::RR 的工作精度设为 N 个二进制位. 默认为 250.

target-precision N

把打印输出的精度设为 N 个二进制位: 应设为与求值该近似所用的类型相同的位数. 默认为 53 (对应双精度).

skew val

把初始插值控制点向范围的一端或另一端“倾斜”. 正值使初始控制点向范围的左侧倾斜, 负值则向右侧倾斜. 如果某个近似无法收敛 (这是常见情况), 可以试着调整 skew 参数, 直到第一步就得到尽可能小的误差. val 应位于区间 [-100,+100] 内, 默认值为零.

brake val

在每一步上施加制动, 使控制点的变化量按 val% 制动. 默认为 50; 如果近似无法收敛, 可以试试更大的值; 想要更快的收敛则用更小的值.

x-offset val

把 x 偏移设为 val: 近似将针对 f(S * (x + X)) + Y 生成, 其中 X 是 x 偏移, S 是 x 缩放, Y 是 y 偏移. 默认为零. 为避免舍入误差, 请注意指定的值应能精确表示为浮点数.

x-scale val

把 x 缩放设为 val: 近似将针对 f(S * (x + X)) + Y 生成, 其中 S 是 x 缩放, X 是 x 偏移, Y 是 y 偏移. 默认为一. 为避免舍入误差, 请注意指定的值应能精确表示为浮点数.

y-offset val

把 y 偏移设为 val: 近似将针对 f(S * (x + X)) + Y 生成, 其中 X 是 x 偏移, S 是 x 缩放, Y 是 y 偏移. 默认为零. 为避免舍入误差, 请注意指定的值应能精确表示为浮点数.

y-offset auto

把 y 偏移设为 f(x) 在范围的两个端点处以及范围中点处求值的平均值. 计算得到的值会刻意截断到 float 精度 (并且应在代码中存储为 float). 近似将针对 f(x + X) + Y 生成, 其中 X 是 x 偏移, Y 是 y 偏移. 默认为零.

graph N

打印 f(x) 在待优化范围上等间距点处的 N 个求值结果. 如果未指定, 则 N 默认为 3. 用于检查 f(x) 在关注范围上确实光滑.

step N

执行 N 步, 如果未指定 N 则执行一步. 每一步之后打印: 近似误差函数在极值点处的峰值误差, 最后一步解出的理论误差项, 以及 Chebyshev 控制点位置的最大相对变化. 当这两个误差项 (近似) 相等, 且控制点的变化减小到适当小的值时, 近似就收敛到极小极大解.

test [float|double|long]

以 float、double 或 long double 精度测试当前近似. 用于检查在固定精度下对该近似求值时的舍入误差. 测试在近似误差函数的极值点以及误差函数的零点处进行.

test [float|double|long] N

以 float、double 或 long double 精度测试当前近似. 用于检查在固定精度下对该近似求值时的舍入误差. 测试在近似范围上 N 个等间距点处进行. 如果 [float|double|long] 都未指定, 则使用 NTL::RR 测试, 这可以用来获得该近似的误差函数.

rescale a b

取当前的 Chebyshev 控制点, 并把它们重新缩放到新的区间 [a,b] 上. 有时这可以用来为用其他方式无法收敛的近似获得起始控制点.

rotate

把一项从分子移到分母, 但保持 Chebyshev 控制点不变. 有时这可以用来为用其他方式无法收敛的近似获得起始控制点.

info

打印当前近似: 误差函数零点的位置、Chebyshev 控制点的位置、x 与 y 偏移, 当然还有多项式的系数.
