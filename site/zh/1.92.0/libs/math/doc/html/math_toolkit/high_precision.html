将 Boost.Math 与高精度浮点库一起使用

为什么使用高精度库而不是内置浮点类型?
使用 Boost.Multiprecision
与 GCC 的 __float128 数据类型一起使用
与 MPFR 或 GMP 高精度浮点库一起使用
使用 e_float 库
使用 NTL 库
为 Boost.Test 等禁用表达式模板

本库的特殊函数、分布、常数与工具可以与多种高精度库一起使用, 包括:

  • Boost.Multiprecision
  • e_float (TOMS Algorithm 910)
  • NTL A Library for doing Number Theory
  • GNU Multiple Precision Arithmetic Library
  • GNU MPFR library
  • GCC 128-bit floating-point type
  • Intel _Quad 类型

后四者有一些许可证限制; 只有 Boost.Multiprecision 在使用 cpp_float 后端时能提供无限制的 Boost 许可证.

目前, 自由许可证的代价是速度略低.

当然, 更高精度的主要代价是计算速度大幅下降 (通常至少降低百倍) 以及内存使用大幅增加.

一些库提供真正的 任意精度算术, 其精度只受可用内存与计算时间的限制, 但大多数库以某个任意固定的精度使用, 比如 100 位十进制数字, 例如 Boost.Multiprecision cpp_dec_float_100.

Boost.Multiprecision 两种方式都可以, 但最常见的选择可能是约一百位十进制数字, 尽管已有计算约一百万位数字的示例.
