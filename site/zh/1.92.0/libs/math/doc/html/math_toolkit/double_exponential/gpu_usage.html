求积还可以在 CUDA (NVCC 与 NVRTC) 平台上运行. 主要区别已在上面的函数签名中列出. 在设备上使用时, 这些是独立函数, 而不像主机上那样使用 OOP. 横坐标与权重的表存储在设备上的共享只读内存中, 而不是在类构造时初始化. 一个示例用例是有限元方法中计算刚度矩阵, 因为它由许多不同的函数组成.
