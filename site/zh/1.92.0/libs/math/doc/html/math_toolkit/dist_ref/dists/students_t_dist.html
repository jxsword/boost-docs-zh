Student's t 分布是 William Gosset 于 1908 年发表的一种统计分布. 他的雇主 Guinness 啤酒厂要求他以笔名发表 (可能是为了隐瞒他们在使用统计学改进啤酒质量), 于是他选择了“Student”.

Student's t 分布定义为随机变量 t 的分布 — 非常粗略地说 — 它是我们不知道样本真实标准差时所能得到的“最佳”结果. 其 PDF 为:

Student's t 分布只接受一个参数: 样本的自由度. 当自由度为 one 时, 该分布与 Cauchy 分布相同. 当自由度趋于无穷时, 该分布趋于正态分布. 下图展示了 PDF 随自由度 ν 变化的情况:

成员函数 
BOOST_MATH_GPU_ENABLED students_t_distribution(const RealType& v);

构造一个具有 v 个自由度的 Student's t 分布.

要求 v > 0, 包括无穷大 (若 RealType 允许), 否则调用 domain_error. 注意支持非整数自由度, 且在某些情况下这是有意义的.

BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom()const;

返回此分布的自由度.

BOOST_MATH_GPU_ENABLED static RealType find_degrees_of_freedom(
   RealType difference_from_mean,
   RealType alpha,
   RealType beta,
   RealType sd,
   RealType hint = 100);

返回在 Student t 检验中, 当均值与“真实”均值之差为 difference_from_mean 时, 观察到显著结果所需的自由度.

difference_from_mean

我们希望证明显著的真均值与样本均值之差.

alpha

当原假设实际为真时, 拒绝原假设的最大可接受概率.

beta

当原假设实际为假时, 未能拒绝原假设的最大可接受概率.

sd

样本标准差.

hint

开始查找结果的起始位置提示, 一个好的选择是此前一次临界 Student t 检验的样本量.

注释

记住: 对于双侧检验, 调用此函数前必须把 alpha 除以 2.

关于此函数的更多信息, 参见 NIST Engineering Statistics Handbook.

BOOST_MATH_GPU_ENABLED static RealType find_degrees_of_freedom(
   RealType t,
   RealType p);

返回使 CDF(x; ν) = p 成立的自由度 ν. 要求 0 < p < 1 且 x ≠ 0, 否则调用 domain_error.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [-∞, +∞].

实现

在下表中, v 是分布的自由度, t 是随机变量, p 是概率, q = 1-p 是其补.

函数

实现说明

pdf

使用关系式: pdf = (v / (v + t2))(1+v)/2 / (sqrt(v) * beta(v/2, 0.5))

cdf

利用关系:

p = 1 - z iff t > 0

p = z otherwise

其中 z 由下式给出:

ibeta(v / 2, 0.5, v / (v + t2)) / 2 iff v < 2t2

ibetac(0.5, v / 2, t2 / (v + t2) / 2 otherwise

cdf 补函数

使用关系式: q = cdf(-t)

quantile

使用关系式: t = sign(p - 0.5) * sqrt(v * y / x)

其中:

x = ibeta_inv(v / 2, 0.5, 2 * min(p, q))

y = 1 - x

量 x 与 y 都由 ibeta_inv 直接返回, 无需如上式那样做减法.

由补函数求 quantile

使用关系式: t = -quantile(q)

众数

0

均值

0

方差

if (v > 2) v / (v - 2) else NaN

偏度

if (v > 3) 0 else NaN

峰度

if (v > 4) 3 * (v - 2) / (v - 4) else NaN

超额峰度

if (v > 4) 6 / (df - 4) else NaN

使用二阶 Edgeworth 展开作为数值求根算法的初始猜测
