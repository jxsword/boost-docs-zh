使用 Student t 检验比较两个样本的均值

设想我们有两个样本, 想确定它们的均值是否不同. 这种情况经常出现在判断新工艺或新疗法是否优于旧工艺或旧疗法时.

在本例中, 我们将使用 NIST 网站 上的 汽车里程样本数据. 该数据比较美国汽车与日本汽车的每加仑英里数.

示例代码在 students_t_two_samples.cpp 中.

这个检验有两种进行方式: 我们可以假设两个样本的真实标准差相等或不等. 如果假设标准差相等, 那么 t 统计量的计算会大大简化, 因此我们先考察这种情况. 在现实生活中, 我们应当用方差相等的 Chi-Squared 检验来验证这一假设是否成立.

我们先定义一个过程, 在假设方差相等的前提下进行我们的检验:

// Needed headers:
#include <boost/math/distributions/students_t.hpp>
#include <iostream>
#include <iomanip>
// Simplify usage:
using namespace boost::math;
using namespace std;

void two_samples_t_test_equal_sd(
        double Sm1,       // Sm1 = Sample 1 Mean.
        double Sd1,       // Sd1 = Sample 1 Standard Deviation.
        unsigned Sn1,     // Sn1 = Sample 1 Size.
        double Sm2,       // Sm2 = Sample 2 Mean.
        double Sd2,       // Sd2 = Sample 2 Standard Deviation.
        unsigned Sn2,     // Sn2 = Sample 2 Size.
        double alpha)     // alpha = Significance Level.

其中 Sp 是两个样本的 "合并" 标准差, 而 v 是两个合并样本的自由度数目. 现在我们可以写出计算 t 统计量的代码:

// Degrees of freedom:
double v = Sn1 + Sn2 - 2;
cout << setw(55) << left << "Degrees of Freedom" << "=  " << v << "\n";
// Pooled variance:
double sp = sqrt(((Sn1-1) * Sd1 * Sd1 + (Sn2-1) * Sd2 * Sd2) / v);
cout << setw(55) << left << "Pooled Standard Deviation" << "=  " << sp << "\n";
// t-statistic:
double t_stat = (Sm1 - Sm2) / (sp * sqrt(1.0 / Sn1 + 1.0 / Sn2));
cout << setw(55) << left << "T Statistic" << "=  " << t_stat << "\n";

下一步是定义我们的分布对象, 并计算概率的补集.

students_t dist(v);
double q = cdf(complement(dist, fabs(t_stat)));
cout << setw(55) << left << "Probability that difference is due to chance" << "=  "
   << setprecision(3) << scientific << 2 * q << "\n\n";

这里我们使用了 t 统计量的绝对值, 因为我们最初只想知道是否存在差异 (双侧检验). 不过, 我们也可以检验第二个样本的均值是大于还是小于 (单侧检验) 第一个样本: 所有可能的检验汇总在下表中:

假设

检验

零假设: 均值 没有差异

若 |t| 的 CDF 补集 < 显著性水平 / 2 则拒绝:

cdf(complement(dist, fabs(t))) < alpha / 2

备择假设: 均值 存在差异

若 |t| 的 CDF 补集 > 显著性水平 / 2 则拒绝:

cdf(complement(dist, fabs(t))) > alpha / 2

备择假设: 样本 1 均值 小于 样本 2 均值.

若 t 的 CDF > 显著性水平则拒绝:

cdf(dist, t) > alpha

备择假设: 样本 1 均值 大于 样本 2 均值.

若 t 的 CDF 补集 > 显著性水平则拒绝:

cdf(complement(dist, t)) > alpha

注释

对双侧检验, 我们必须与 alpha / 2 而非 alpha 比较.

因此, 由于差异源于偶然的概率仅为 5.273e-030, 我们可以有把握地断定确实存在差异.

对备择假设的检验表明, 我们还必须拒绝样本 1 均值大于样本 2 均值的假设: 在本例中, 样本 1 代表日本车的每加仑英里数, 样本 2 代表美国车的每加仑英里数, 因此我们得出结论: 日本车平均而言更省油.

注释

一些统计软件包把有效自由度截断为整数值: 如果你依赖查找表, 这可能是必要的; 但由于我们的代码完全支持非整数自由度, 在这种情况下无需截断. 另请注意, 当自由度较小时, Welch-Satterthwaite 近似可能是一个重要的误差来源.

把这些公式写成代码, 我们得到:

// Degrees of freedom:
double v = Sd1 * Sd1 / Sn1 + Sd2 * Sd2 / Sn2;
v *= v;
double t1 = Sd1 * Sd1 / Sn1;
t1 *= t1;
t1 /=  (Sn1 - 1);
double t2 = Sd2 * Sd2 / Sn2;
t2 *= t2;
t2 /= (Sn2 - 1);
v /= (t1 + t2);
cout << setw(55) << left << "Degrees of Freedom" << "=  " << v << "\n";
// t-statistic:
double t_stat = (Sm1 - Sm2) / sqrt(Sd1 * Sd1 / Sn1 + Sd2 * Sd2 / Sn2);
cout << setw(55) << left << "T Statistic" << "=  " << t_stat << "\n";

此后代码和检验的执行方式与之前相同. 再次使用我们的汽车里程数据, 输出如下:
