符号操作函数

概要 
#include <boost/math/special_functions/sign.hpp>

namespace boost{ namespace math{

template<class T>
int signbit(T x);

template <class T>
int sign (const T& z);

template <class T, class U>
T copysign (const T& x, const U& y);

template <class T>
calculated-result-type changesign (const T& z);

}} // namespaces
说明 
template<class T>
int signbit(T x);

如果变量 x 的符号位已置位, 则返回一个非零值, 否则返回 0.

重要

此函数的返回值是零或 非零, 而 不是 零或一.

template <class T>
int sign (const T& z);

返回 1, 若 x > 0; 返回 -1, 若 x < 0; 0 若 x 为零.

template <class T, class U>
calculated-result-type copysign (const T& x, const U& y);

把 x 的符号设置为与 y 的符号相同.

更多细节参见 C99 7.12.11.1 The copysign functions.

template <class T>
T changesign (const T& z);

返回一个浮点数, 其二进制表示中的符号位与 x 中的符号位相反, 而其余各位与 x 相同.

此函数广泛可用, 但未在任何标准中作出规定.

设计理由: TR1 未规定此函数, 但 changesign(x) 比下面这种写法更易读, 也更高效:

copysign(x, signbit(x) ? 1.0 : -1.0);

对有限值, 此函数与简单取负 (即赋值 z = -z) 效果相同; 但对非有限值, 即 无穷大 和 NaN, changesign(x) 函数可能是确保符号位被改变的唯一可移植方法.

符号位

浮点数的二进制表示中有一位给出符号, 其余各位给出绝对值. 该位称为符号位. 对负数, 符号位置位 (= 1); 对正数, 符号位不置位 (= 0). (这对现代微处理器所使用的所有浮点数二进制表示都成立.)

C++ TR1 规定了用于访问符号位的 copysign 函数和函数模板.

对用户自定义类型 (UDT), 符号可能以其他某种方式存储. 它们也可能不提供无穷大或 NaN. 要在 UDT 上使用这些函数, 可能需要针对 UDT 类型 T 对它们进行显式特化.

示例 
signbit(3.5) is zero (or false)
signbit(-7.1) is 1 (or true)
copysign(4.2, 7.9) is 4.2
copysign(3.5 -1.4) is -3.5
copysign(-4.2, 1.0) is 4.2
copysign(-8.6, -3.3) is -8.6
changesign(6.9) is -6.9
changesign(-1.8) is 1.8
可移植性

本库支持以下二进制浮点格式:

  • IEEE 754 单精度
  • IEEE 754 双精度
  • 具有 15 位指数位的 IEEE 754 扩展双精度
  • Intel 扩展双精度
  • PowerPC 扩展双精度
  • Motorola 68K 扩展双精度

本库不支持 VAX 浮点格式. (它们在 VMS 上可用, 但 VMS 上的默认格式是 IEEE 754 浮点格式.)

主要的可移植性问题有:

  • 不受支持的浮点格式.
  • 本库依赖头文件 boost/detail/endian.hpp 来确定字节序.
  • 使用诸如 #if defined(__ia64) || defined(__ia64__) || defined(_M_IA64) 之类的代码来确定处理器类型.

本库已在以下平台上通过全部测试:

  • Win32 / MSVC 7.1 / 10.0 / x86 32 位与 64 位, 以及更高版本的 Win32
  • Win32 / Intel C++ 7.1, 8.1, 9.1 / x86
  • Mac OS X / GCC 3.3, 4.0 / ppc
  • Linux / Intel C++ 9.1 / x86, ia64
  • Linux / GCC 3.3 / x86, x64, ia64, ppc, hppa, mips, m68k
  • Linux / GCC 3.4 / x64
  • HP-UX / aCC, GCC 4.1 / ia64
  • HP-UX / aCC / hppa
  • Tru64 / Compaq C++ 7.1 / alpha
  • VMS / HP C++ 7.1 / alpha (IEEE 浮点模式)
  • VMS / HP C++ 7.2 / ia64 (IEEE 浮点模式)
