不完全 Gamma 函数的导数

概要 
#include <boost/math/special_functions/gamma.hpp>

namespace boost{ namespace math{

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_derivative(T1 a, T2 x);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type gamma_p_derivative(T1 a, T2 x, const Policy&);

}} // namespaces
说明

本函数在统计分布中有些用途: 它实现不完全 gamma 函数关于 x 的偏导数.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

注意, 函数 gamma_q 的导数可以通过对本函数的结果取负得到.

当 T1 和 T2 是不同类型时, 本函数的返回类型使用 结果类型计算规则 计算; 否则返回类型就是 T1.

精度

与不完全 gamma 函数 gamma_p 几乎相同: 更多信息请参阅该函数的文档.

实现

本函数只是暴露了不完全 gamma 函数 gamma_p 的一些内部细节: 更多信息请参阅该函数的文档.
