标准差的 Chi-Square 检验

我们用这个检验来确定样本的标准差是否与某个指定值不同. 通常这出现在工艺变更情形中, 我们希望把新工艺的标准差与既定工艺进行比较.

本示例的代码包含在 chi_square_std_dev_test.cpp 中, 我们先定义将打印检验统计量的过程:

void chi_squared_test(
    double Sd,     // Sample std deviation
    double D,      // True std deviation
    unsigned N,    // Sample size
    double alpha)  // Significance level
{

该过程首先打印输入数据的摘要:

using namespace std;
using namespace boost::math;

// Print header:
cout <<
   "______________________________________________\n"
   "Chi Squared test for sample standard deviation\n"
   "______________________________________________\n\n";
cout << setprecision(5);
cout << setw(55) << left << "Number of Observations" << "=  " << N << "\n";
cout << setw(55) << left << "Sample Standard Deviation" << "=  " << Sd << "\n";
cout << setw(55) << left << "Expected True Standard Deviation" << "=  " << D << "\n\n";

检验统计量 (T) 就是样本标准差与 "真" 标准差之比的平方, 乘以自由度数目 (样本量减一):

double t_stat = (N - 1) * (Sd / D) * (Sd / D);
cout << setw(55) << left << "Test Statistic" << "=  " << t_stat << "\n";

我们需要使用的分布是具有 N-1 个自由度的 Chi Squared 分布:

chi_squared dist(N - 1);

可以检验的各种假设汇总在下表中:

假设

检验

零假设: 标准差与指定值没有差异

Reject if T < χ2(1-alpha/2; N-1) or T > χ2(alpha/2; N-1)

备择假设: 标准差与指定值存在差异

Reject if χ2(1-alpha/2; N-1) >= T >= χ2(alpha/2; N-1)

备择假设: 标准差小于指定值

Reject if χ2(1-alpha; N-1) <= T

备择假设: 标准差大于指定值

Reject if χ2(alpha; N-1) >= T

其中 χ2(alpha; N-1) 是 Chi Squared 分布的上临界值, 而 χ2(1-alpha; N-1) 是下临界值.

回想一下, 下临界值与分位数相同, 而上临界值与从概率补集求得的分位数相同, 这为我们给出计算临界值的如下代码:

double ucv = quantile(complement(dist, alpha));
double ucv2 = quantile(complement(dist, alpha / 2));
double lcv = quantile(dist, alpha);
double lcv2 = quantile(dist, alpha / 2);
cout << setw(55) << left << "Upper Critical Value at alpha: " << "=  "
   << setprecision(3) << scientific << ucv << "\n";
cout << setw(55) << left << "Upper Critical Value at alpha/2: " << "=  "
   << setprecision(3) << scientific << ucv2 << "\n";
cout << setw(55) << left << "Lower Critical Value at alpha: " << "=  "
   << setprecision(3) << scientific << lcv << "\n";
cout << setw(55) << left << "Lower Critical Value at alpha/2: " << "=  "
   << setprecision(3) << scientific << lcv2 << "\n\n";

有了临界值之后, 我们可以把它们与检验统计量比较, 并打印每个假设和检验的结果:

cout << setw(55) << left <<
   "Results for Alternative Hypothesis and alpha" << "=  "
   << setprecision(4) << fixed << alpha << "\n\n";
cout << "Alternative Hypothesis              Conclusion\n";

cout << "Standard Deviation != " << setprecision(3) << fixed << D << "            ";
if((ucv2 < t_stat) || (lcv2 > t_stat))
   cout << "ACCEPTED\n";
else
   cout << "REJECTED\n";

cout << "Standard Deviation  < " << setprecision(3) << fixed << D << "            ";
if(lcv > t_stat)
   cout << "ACCEPTED\n";
else
   cout << "REJECTED\n";

cout << "Standard Deviation  > " << setprecision(3) << fixed << D << "            ";
if(ucv < t_stat)
   cout << "ACCEPTED\n";
else
   cout << "REJECTED\n";
cout << endl << endl;

为了看一些示例输出, 我们将使用 NIST/SEMATECH e-Handbook of Statistical Methods. 中的 齿轮数据. 该数据代表某制造过程中齿轮直径的测量值. 程序输出经过精心设计, 以镜像 NIST Handbook Example 中所示的 DATAPLOT 输出.

在本例中我们检验样本标准差是否为 0.1, 零假设被拒绝, 因此我们得出结论: 标准差 不是 0.1.

作为另一个示例, 再次考虑 NIST/SEMATECH e-Handbook of Statistical Methods. 中的 硅晶圆数据. 在该场景中, 一家 100 ohm.cm 硅晶圆供应商声称其制造工艺能生产出一致性足够的晶圆, 使该批次电阻率的标准差不超过 10 ohm.cm. 从该批次抽取的 N = 10 片晶圆样本的标准差为 13.97 ohm.cm, 我们问自己的问题是: "供应商的说法正确吗?"

程序输出现在如下所示:

______________________________________________
Chi Squared test for sample standard deviation
______________________________________________

Number of Observations                                 =  10
Sample Standard Deviation                              =  13.97000
Expected True Standard Deviation                       =  10.00000

Test Statistic                                         =  17.56448
CDF of test statistic:                                 =  9.594e-001
Upper Critical Value at alpha:                         =  1.692e+001
Upper Critical Value at alpha/2:                       =  1.902e+001
Lower Critical Value at alpha:                         =  3.325e+000
Lower Critical Value at alpha/2:                       =  2.700e+000

Results for Alternative Hypothesis and alpha           =  0.0500

Alternative Hypothesis              Conclusion
Standard Deviation != 10.000            REJECTED
Standard Deviation  < 10.000            REJECTED
Standard Deviation  > 10.000            ACCEPTED

在本例中, 我们的零假设是样本的标准差小于 10: 上面的分析拒绝了这个假设, 因此我们拒绝制造商的说法.
