Gegenbauer 多项式

概要 
#include <boost/math/special_functions/gegenbauer.hpp>

namespace boost{ namespace math{

template<typename Real>
BOOST_MATH_GPU_ENABLED Real gegenbauer(unsigned n, Real lambda, Real x);

template<typename Real>
BOOST_MATH_GPU_ENABLED Real gegenbauer_prime(unsigned n, Real lambda, Real x);

template<typename Real>
BOOST_MATH_GPU_ENABLED Real gegenbauer_derivative(unsigned n, Real lambda, Real x, unsigned k);

}} // namespaces

Gegenbauer 多项式是一族正交多项式.

基本用法如下:

using boost::math::gegenbauer;
double x = 0.5;
double lambda = 0.5;
unsigned n = 3;
double y = gegenbauer(n, lambda, x);

Gegenbauer 多项式的各阶导数均可用. 第 k 阶导数对第 n 个 Gegenbauer 多项式由下式给出:

using boost::math::gegenbauer_derivative;
double x = 0.5;
double lambda = 0.5;
unsigned n = 3;
unsigned k = 2;
double y = gegenbauer_derivative(n, lambda, x, k);

为与库的其余部分保持一致, 还提供了 gegenbauer_prime, 它只是简单地返回 gegenbauer_derivative(n, lambda, x,1 ).

实现

实现使用 Gegenbauer 多项式的三项递推, 按递增方向计算.

注意事项

一些程序通过重新归一化来定义 λ = 0 的 Gegenbauer 多项式 (这使其成为 Chebyshev 多项式). 我们不遵循这一约定: 在这种情况下, 只有第零个 Gegenbauer 多项式非零.
