在非模板代码中使用

在非模板代码中以你选择的固定精度使用数学常数时, 你只需添加一条 using namespace 声明, 例如 using namespace boost::math::double_constants, 使适合你代码精度的常数在当前作用域可见, 然后把每个常数 当作简单变量使用——不带括号:

#include <boost/math/constants/constants.hpp>

double area(double r)
{
   using namespace boost::math::double_constants;
   return pi * r * r;
}

假如我们的函数写成了接受 float 而非 double, 我们本可以这样写:

#include <boost/math/constants/constants.hpp>

float area(float r)
{
   using namespace boost::math::float_constants;
   return pi * r * r;
}

同样, 适合以 long double 精度使用的常数可在命名空间 boost::math::long_double_constants 中找到.

可用常数的完整列表见 math_toolkit.constants.

使用常数的一些示例见 constants_eg1.
