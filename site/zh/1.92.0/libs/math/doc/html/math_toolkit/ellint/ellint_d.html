椭圆积分 D - Legendre 形式

概要 
#include <boost/math/special_functions/ellint_d.hpp>

namespace boost { namespace math {

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_d(T1 k, T2 phi);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_d(T1 k, T2 phi, const Policy&);

template <class T1>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_d(T1 k);

template <class T1, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_d(T1 k, const Policy&);

}} // namespaces
说明

这两个函数求值不完全椭圆积分 D(φ, k) 及其对应的完全形式 D(k) = D(π/2, k).

当参数类型不同时, 这些函数的返回类型使用 结果类型计算规则 计算: 若为相同类型, 则结果与参数类型相同.

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_d(T1 k, T2 phi);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_3(T1 k, T2 phi, const Policy&);

返回不完全椭圆积分:

要求 k2sin2(phi) < 1, 否则返回 domain_error 的结果 (在此范围之外结果将为复数).

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

template <class T1>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_d(T1 k);

template <class T1, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type ellint_d(T1 k, const Policy&);

返回完全椭圆积分 D(k) = D(π/2, k)

要求 -1 <= k <= 1, 否则返回 domain_error 的结果 (在此范围之外结果将为复数).

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

精度

这些函数由其他椭圆积分平凡地计算得到, 误差率通常极低 (几个 epsilon), 除非参数 φ 非常大, 此时通常的三角函数参数约化问题同样适用.

实现

D(φ, k) 的实现首先用以下关系式做参数约化:

D(-φ, k) = -D(φ, k)

以及

D(nπ+φ, k) = 2nD(k) + D(φ, k)

把 φ 移到范围 [0, π/2] 内.
