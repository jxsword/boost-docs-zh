Jacobi Zeta 函数

概要 
#include <boost/math/special_functions/jacobi_zeta.hpp>

namespace boost { namespace math {

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type jacobi_zeta(T1 k, T2 phi);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type jacobi_zeta(T1 k, T2 phi, const Policy&);

}} // namespaces
说明

该函数求值 Jacobi Zeta 函数 Z(φ, k)

请注意参数使用 φ 与 k, 该函数常被定义为 Z(φ, m), 其中 m = k2, 例如参见 Weisstein, Eric W. "Jacobi Zeta Function." From MathWorld--A Wolfram Web Resource. 或者定义为 Z(x, k), 其中 φ = am(x, k), 而 am 是 Jacobi 幅角函数, 等价于 asin(jacobi_elliptic(k, x)).

当参数类型不同时, 此函数的返回类型使用 结果类型计算规则 计算: 若为相同类型, 则结果与参数类型相同.

要求 -1 <= k <= 1, 否则返回 domain_error 的结果 (在此范围之外结果将为复数).

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

注意此函数没有完全形式的对应版本 (φ = π / 2 时), 因为此时它对所有 k 都取值 0.

精度

这些函数由其他椭圆积分平凡地计算得到, 误差率通常极低 (几个 epsilon), 除非参数 φ 非常大, 此时通常的三角函数参数约化问题同样适用.
