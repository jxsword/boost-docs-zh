致谢

注释

本节应与“新增功能”一节配合阅读, 后者详细介绍了每个版本的变更.

Hubert Holin 开创了 Boost.Math 库. Quaternions、Octonions、反双曲函数以及 sinc 函数都是他的作品.

Daryle Walker 编写了整数 gcd 和 lcm 函数.

John Maddock 开创了特殊函数; beta、gamma、erf、多项式和阶乘函数是他的作品, “工具箱”一节和许多统计分布也是如此.

Paul A. Bristow 在 A Proposal to add Mathematical Functions for Statistics to the C++ Standard Library 中发起挑战, 要求加入关键数学函数, 尤其是统计学所必需的函数. 在 JM 接受并解决了这些难题之后 - 不仅在数值上, 而且以完整的 C++ 模板风格 - PAB 实现了其中一些统计分布. PAB 还不知疲倦地为 JM 抛给他的所有内容做校对 (因此所有残留的编辑错误都是他的过错).

Xiaogang Zhang 在其 2006 年 Google Summer of Code 项目中研究了 Bessel 函数和椭圆积分.

Bruno Lalande 提交了“运行期底的编译期幂”代码.

Johan Råde 编写了优化的浮点分类与操作代码, 以及允许以 C99 格式输出无穷大和 NaN 的 nonfinite 刻面. (nonfinite 刻面直到 Boost 1.47 才加入, 但此前已在 Boost.Spirit 中使用). 此库基于 Boost.Serialization 的作者 Robert Ramey 的建议. Paul A. Bristow 表达了对 Input & Output of NaN and infinity for the C++ Standard Library 更好处理的需求, 并建议遵循 C99 格式.

Antony Polukhin 改进了 lexical_cast, 避免使用 stringstream, 从而不再需要使用全局 C99 刻面来处理非有限数.

Håkan Ardö、Boris Gubenko、John Maddock、Markus Schöpflin 和 Olivier Verdier 测试了浮点库; Martin Bonner、Peter Dimov 和 John Maddock 提供了宝贵的建议.

Gautam Sewani 在 2008 年 Google Summer of Code 项目中编写了 logistic 分布.

M. A. (Thijs) van den Berg 编写了 Laplace 分布. (Thijs 还扬言要实现一些多元分布).

Thomas Mang 为贝叶斯应用请求了卡方分布中的逆 gamma 函数, 参与了实现, 并提供了一个很好的使用示例.

感谢 Nico Temme 教授对不完全 beta 逆函数的建议.

Victor Shoup for NTL, 若没有它, 生成高精度常量、尤其是用于测试的精确值表格会困难得多.

我们感谢 Joel Guzman 帮助我们对他的 Boost.Quickbook 程序 (用于生成本文档的 html 和 pdf 版本) 进行压力测试, 途中还新增了若干特性.

函数与分布的图像以 W3C 标准的 Scalable Vector Graphic (SVG) 格式制作, 使用的是 Jacob Voytko 在 Google Summer of Code (2007) 期间创建的程序. 自 2012 年起, 所有最新版的互联网浏览器都支持渲染 SVG (质量参差不齐). 较旧的版本, 尤其是 (IE 9 之前的 Microsoft Internet Explorer) 缺少原生 SVG 支持, 但可以通过 Adobe's free SVG viewer 插件使其工作. SVG 文件可以使用 Inkscape 转换为 JPEG 或 PNG.

我们还要感谢 Matthias Schabel 主持了本库的 Boost 正式评审, 并感谢所有评审者 - 包括 Guillaume Melquiond、Arnaldur Gylfason、John Phillips、Stephan Tolksdorf 和 Jeff Garland - 的许多有益意见.

感谢 Mark Coleman 和 Georgi Boshnakov 提供 Wolfram Mathematica 的抽检测试值, 当然也感谢 Eric Weisstein 用心维护 Wolfram MathWorld 这一宝贵资源.

Skew-normal 分布和 Owen's t 函数由 Benjamin Sobotta 编写.

我们感谢 Thomas Mang 说服我们允许 t 分布具有无穷自由度, 并参与了关于如何提高大非中心参数和/或大自由度下精度的长时间讨论.

Christopher Kormanyos 编写了 e_float 多精度库 TOMS Algorithm 910: A Portable C++ Multiple-Precision System for Special-Function Calculations, 它构成了 Boost.Multiprecision 库的基础; 如今该库可使大多数函数和分布以用户选择的精度计算, 不再局限于 double 等内建浮点类型. (也感谢 Topher Cooper 让我们注意到 Christopher 的 e_float).

Christopher Kormanyos 编写了一些使用 Boost.Multiprecision 的示例, 并增加了求 Bessel 函数零点的方法.

Marco Guazzone 提供了超几何分布.

Rocco Romeo 发现了大量小缺陷, 并对特殊函数代码进行了近乎毁灭性的压力测试!

Jeremy William Murphy 添加了多项式算术工具.

Thomas Luu 改进了非中心卡方分布分位数的计算. 以及他的学位论文 * Fast and accurate parallel computation of quantile functions for random number generation, 2016

以及他的论文:

Luu, Thomas; (2015), Efficient and Accurate Parallel Inversion of the Gamma Distribution, SIAM Journal on Scientific Computing , 37 (1) C122 - C141, https://doi.org/10.1137/14095875X.

这些工作还有望帮助改进若干分布分位数计算的算法, 尤其是使用 GPU 的并行计算.

Nicolas Thompson 添加了大量处理求积与插值的代码以及更多统计工具.

Matthew Pulver 提供了加入 Boost.Math 的自动微分一节.
