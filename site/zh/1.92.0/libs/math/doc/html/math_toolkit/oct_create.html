八元数创建函数 

template<typename T> octonion<T> spherical(T const & rho, T const & theta, T const & phi1, T const & phi2, T const & phi3, T const & phi4, T const & phi5, T const & phi6);
template<typename T> octonion<T> multipolar(T const & rho1, T const & theta1, T const & rho2, T const & theta2, T const & rho3, T const & theta3, T const & rho4, T const & theta4);
template<typename T> octonion<T> cylindrical(T const & r, T const & angle, T const & h1, T const & h2, T const & h3, T const & h4, T const & h5, T const & h6);

这些函数以类似于 polar 构建复数的方式构建八元数, 因为对八元数而言并不存在与极坐标严格等价的概念.

spherical 是对 polar 的简单移植, 它接受一个 (正的) 模长和超球面上的一个点 (由三个角度给出) 作为输入. 其中第一个角度 theta 的自然范围是 -pi 到 +pi, 另外两个角度的自然范围是 -pi/2 到 +pi/2 (正如 R3 中通常球面坐标的情形). 由于存在许多对称性和周期性, 即使模长为负或角度超出其自然范围, 也不会发生任何异常. 但预期的退化情形 (模长为零时忽略角度设置...) 确实会发生.

cylindrical 同样是对 R3 中通常柱面坐标的简单移植, 而柱面坐标又是平面极坐标的另一种派生. 前两个输入是八元数第一个 C 分量的极坐标. 第三个和第四个输入分别放入八元数的第三个和第四个 R 分量.

multipolar 是极坐标的又一个简单推广. 这次, 八元数的两个 C 分量都以极坐标给出.

在我们这一版八元数实现中, 没有复数值运算 arg 的类似物, 因为情况要更复杂一些.
