误差函数的反函数

概要 
#include <boost/math/special_functions/erf.hpp>

namespace boost{ namespace math{

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type erf_inv(T p);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type erf_inv(T p, const Policy&);

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type erfc_inv(T p);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type erfc_inv(T p, const Policy&);

}} // namespaces

这些函数的返回类型使用 结果类型计算规则 计算: 若 T 是整数类型, 返回类型为 double, 否则为 T.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

说明 
template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type erf_inv(T z);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type erf_inv(T z, const Policy&);

返回 z 的 反误差函数, 即满足下式的值 x:

p = erf(x); 

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type erfc_inv(T z);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type erfc_inv(T z, const Policy&);

返回 z 的误差函数之补的反函数, 即满足下式的值 x:

p = erfc(x);

精度

对于最高到 (含) 80 位 long double 的类型, 所用近似的误差小于约 2 个 epsilon. 对于更高精度的类型, 这些函数具有与 正向误差函数 相同的精度.

测试

测试分为两组:

  • 基本的健全性检查尝试从 x "往返"到 p 再返回. 这些测试的容差相当宽松: 一般而言, 误差函数及其反函数在某些地方变化如此之快, 以致于无法往返恢复到多于几位有效数字. 当 p 非常接近 1 时尤其如此: 在这种情况下, 反函数的输入中没有足够的"信息量"让你回到起点.
  • 使用高精度测试值的精度检查. 这些检查在给定 精确 输入值的情况下度量结果的精度.
实现

这些函数使用 由 JM 设计 的一个有理近似来计算结果的初始近似, 其精度约为 10-19; 只有当与 T 的 epsilon 相比该精度不足时, 才使用 Halley iteration 清理结果.

为 erf/erfc 函数构造有理近似实际上出奇地困难, 在高精度下尤其如此. 因此, 我们并未尝试达到适合 128 位实数使用的 10-34 精度.

在下面的讨论中, p 是传递给 erf_inv 的值, q 是传递给 erfc_inv 的值, 因而 p = 1 - q 且 q = 1 - p; 在两种情形下我们要求解的都是同一个结果 x.

对于 p < 0.5, 反 erf 函数相当平滑, 近似式

x = p(p + 10)(Y + R(p))

对于常量 Y 以及针对与 |Y| 相比的低绝对误差做了优化的 R(p), 该式给出良好的结果.

对于 q < 0.5, 情况变得更加棘手; 在区间 0.5 > q > 0.25 上, 下面的近似效果良好:

x = sqrt(-2log(q)) / (Y + R(q))

而对于 q < 0.25, 令

z = sqrt(-log(q))

于是结果由下式给出:

x = z(Y + R(z - B))

与前面一样, Y 是常量, 有理函数 R 针对与 |Y| 相比的低绝对误差做了优化. B 也是常量: 它是每个近似有效的最小 z 值. 这种形式的近似有若干个, 每一个都比前一个略微深入 erfc 函数的尾部 (在 long double 精度下, 与 double 相比更宽的指数范围意味着尾部确实会延续非常远).
