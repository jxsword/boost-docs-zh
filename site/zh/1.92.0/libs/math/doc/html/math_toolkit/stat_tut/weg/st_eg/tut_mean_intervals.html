使用 Student t 分布计算均值的置信区间

假设你有一个样本均值, 你可能想知道可以为该均值设置怎样的置信区间. 通俗地说: "我想要一个我能有 P% 把握包含真实均值的区间". (技术上请注意, 该区间要么包含真实均值, 要么不包含: 置信水平的含义与此通俗说法有微妙的不同. 更多背景信息可在 NIST site 上找到).

注释

量 α 是错误拒绝零假设的最大可接受风险. α 的值越小, 检验的强度越大.

检验的置信水平定义为 1 - α, 通常以百分比表示. 例如, 0.05 的显著性水平等价于 95% 的置信水平. 更多信息参见 NIST/SEMATECH e-Handbook of Statistical Methods. 中的 "什么是置信区间?".

注释

独立同分布 (i.i.d.) 变量和 正态分布 的通常假设当然在此适用, 正如在其他示例中一样.

从公式中应当清楚:

  • 置信区间的宽度随样本量增大而减小.
  • 宽度随标准差增大而增大.
  • 宽度随 置信水平提高 而增大 (从 0.5 到 0.99999——更强).
  • 宽度随 显著性水平降低 而增大 (从 0.5 到 0.00000...01——更强).

以下示例代码取自示例程序 students_t_single_sample.cpp.

我们先定义一个过程来计算各种置信水平的区间; 该过程将以表格形式打印它们:

// Needed includes:
#include <boost/math/distributions/students_t.hpp>
#include <iostream>
#include <iomanip>
// Bring everything into global namespace for ease of use:
using namespace boost::math;
using namespace std;

void confidence_limits_on_mean(
   double Sm,           // Sm = Sample Mean.
   double Sd,           // Sd = Sample Standard Deviation.
   unsigned Sn)         // Sn = Sample Size.
{
   using namespace std;
   using namespace boost::math;

   // Print out general info:
   cout <<
      "__________________________________\n"
      "2-Sided Confidence Limits For Mean\n"
      "__________________________________\n\n";
   cout << setprecision(7);
   cout << setw(40) << left << "Number of Observations" << "=  " << Sn << "\n";
   cout << setw(40) << left << "Mean" << "=  " << Sm << "\n";
   cout << setw(40) << left << "Standard Deviation" << "=  " << Sd << "\n";

我们将定义一个显著性/风险水平表, 我们将为它们计算区间:

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

注意, 这些是置信/概率水平的补集: 0.5, 0.75, 0.9 .. 0.99999).

接下来, 我们声明所需的分布对象, 注意 自由度 参数是样本量减一:

students_t dist(Sn - 1);

程序中接下来大部分是美化输出, 因此让我们专注于区间的计算. 首先, 我们需要 t 统计量, 用 quantile 函数和我们的显著性水平计算. 注意, 由于显著性水平是概率的补集, 我们必须把参数包裹在一次 complement(...) 调用中:

double T = quantile(complement(dist, alpha[i] / 2));

注意, alpha 被除以 2, 因为我们将同时计算上界和下界: 假如我们关心的是单侧区间, 那么就会省略这一步.

现在为完整起见, 我们从 t 统计量得到区间的 (单侧) 宽度: 乘以标准差, 再除以样本量的平方根:

double w = T * Sd / sqrt(double(Sn));

于是双侧区间就是样本均值加减这个宽度.

再加上一些美化输出, 就完成了该过程.
