多项式与有理函数求值

概要 
#include <boost/math/tools/rational.hpp>

// Polynomials:
template <std::size_t N, class T, class V>
V evaluate_polynomial(const T(&poly)[N], const V& val);

template <std::size_t N, class T, class V>
V evaluate_polynomial(const std::array<T,N>& poly, const V& val);

template <class T, class U>
U evaluate_polynomial(const T* poly, U z, std::size_t count);

// Even polynomials:
template <std::size_t N, class T, class V>
V evaluate_even_polynomial(const T(&poly)[N], const V& z);

template <std::size_t N, class T, class V>
V evaluate_even_polynomial(const std::array<T,N>& poly, const V& z);

template <class T, class U>
U evaluate_even_polynomial(const T* poly, U z, std::size_t count);

// Odd polynomials
template <std::size_t N, class T, class V>
V evaluate_odd_polynomial(const T(&a)[N], const V& z);

template <std::size_t N, class T, class V>
V evaluate_odd_polynomial(const std::array<T,N>& a, const V& z);

template <class T, class U>
U evaluate_odd_polynomial(const T* poly, U z, std::size_t count);

// Rational Functions:
template <std::size_t N, class T, class V>
V evaluate_rational(const T(&a)[N], const T(&b)[N], const V& z);

template <std::size_t N, class T, class V>
V evaluate_rational(const std::array<T,N>& a, const std::array<T,N>& b, const V& z);

template <class T, class U, class V>
V evaluate_rational(const T* num, const U* denom, V z, unsigned count);
说明

每个函数都有三种变体: 一对重载函数, 多项式或有理函数的阶在编译期求值; 以及一个接受运行期变量作为系数数组大小的重载. 一般而言, 在编译期求值数组大小会带来更好的类型安全, 更不容易出现程序员错误, 并且可能产生更优化的代码. 多项式求值函数尤其针对各种数组大小做了特化, 允许循环展开, 并有望实现最优内联展开.

template <std::size_t N, class T, class V>
V evaluate_polynomial(const T(&poly)[N], const V& val);

template <std::size_t N, class T, class V>
V evaluate_polynomial(const std::array<T,N>& poly, const V& val);

template <class T, class U>
U evaluate_polynomial(const T* poly, U z, std::size_t count);

对由 多项式 中存储于 poly 的系数描述的对象求值.

如果数组大小在运行期指定, 则多项式的阶必须为 count-1, 具有 count 个系数. 否则它的阶为 N-1, 具有 N 个系数.

系数的存储方式应使得 xi 项的系数位于 poly[i].

系数和变量 z 的类型可以不同, 只要 *poly 可转换为 U 类型. 例如, 这允许系数表在合适时是整数表.

template <std::size_t N, class T, class V>
V evaluate_even_polynomial(const T(&poly)[N], const V& z);

template <std::size_t N, class T, class V>
V evaluate_even_polynomial(const std::array<T,N>& poly, const V& z);

template <class T, class U>
U evaluate_even_polynomial(const T* poly, U z, std::size_t count);

如上, 但求值偶多项式: 即 z 的所有幂都是偶数的多项式. 等价于调用 evaluate_polynomial(poly, z*z, count).

template <std::size_t N, class T, class V>
V evaluate_odd_polynomial(const T(&a)[N], const V& z);

template <std::size_t N, class T, class V>
V evaluate_odd_polynomial(const std::array<T,N>& a, const V& z);

template <class T, class U>
U evaluate_odd_polynomial(const T* poly, U z, std::size_t count);

如上, 但求值所有幂都是奇数的多项式. 等价于 evaluate_polynomial(poly+1, z*z, count-1) * z + poly[0].

template <std::size_t N, class T, class U, class V>
V evaluate_rational(const T(&num)[N], const U(&denom)[N], const V& z);

template <std::size_t N, class T, class U, class V>
V evaluate_rational(const std::array<T,N>& num, const std::array<U,N>& denom, const V& z);

template <class T, class U, class V>
V evaluate_rational(const T* num, const U* denom, V z, unsigned count);

对由 num 和 denom 中存储的系数描述的有理函数 (两个多项式之比) 求值.

如果数组大小在运行期指定, 则两个多项式的阶都必须为 count-1, 各有 count 个系数. 否则两个多项式的阶均为 N-1, 各有 N 个系数.

数组 num 描述分子, demon 描述分母.

系数的存储方式应使得 xi 项的系数位于 num[i] 和 denom[i].

系数和变量 v 的类型可以不同, 只要 *num 和 *denom 可转换为 V 类型. 例如, 这允许一个或两个系数表在合适时是整数表.

这些函数旨在安全地求值结果, 即使值 z 非常大也是如此. 因此它们不利用编译期数组大小做任何优化. 这些函数最好留给 z 可能很大的情形: 如果你能确保不会发生数值上溢, 那么使用编译期数组大小的多项式求值可能提供略好的性能.

实现

多项式用 Horners method 求值. 如果数组大小在编译期已知, 函数会分派到按大小特化的实现, 展开求值循环.

有理函数用 Horners method 求值: 两个多项式并行求值, 以充分利用处理器的浮点流水线. 如果 v 大于 1, 则多项式以 1/v 为变量按相反顺序求值: 这可以在系数较大时避免不必要的数值上溢.

多项式和有理函数求值算法都可以通过各种配置宏进行调优, 以便为特定的编译器与平台组合提供最佳性能. 其中包括对二阶 Horner 方法的支持. 各种选项 documented here. 不过, 在大多数现有硬件上, 由此获得的性能收益微乎其微, 因此在更改默认设置之前, 最好先运行 performance test application.
