Chebyshev 多项式

概要 
#include <boost/math/special_functions/chebyshev.hpp>

namespace boost{ namespace math{

template<class Real1, class Real2, class Real3>
calculated-result-type chebyshev_next(Real1 const & x, Real2 const & Tn, Real3 const & Tn_1);

template<class Real>
calculated-result-type chebyshev_t(unsigned n, Real const & x);

template<class Real, class Policy>
calculated-result-type chebyshev_t(unsigned n, Real const & x, const Policy&);

template<class Real>
calculated-result-type chebyshev_u(unsigned n, Real const & x);

template<class Real, class Policy>
calculated-result-type chebyshev_u(unsigned n, Real const & x, const Policy&);

template<class Real>
calculated-result-type chebyshev_t_prime(unsigned n, Real const & x);

template<class Real1, class Real2>
calculated-result-type chebyshev_clenshaw_recurrence(const Real1* const c, size_t length, Real2 x);

template<typename Real>
Real chebyshev_clenshaw_recurrence(const Real* const c, size_t length, Real a, Real b, Real x);

}} // namespaces

"实分析离不开 Fourier, 复分析离不开 Laurent, 数值分析离不开 Chebyshev" --Lloyd N. Trefethen

第一类 Chebyshev 多项式由如下递推定义: Tn+1(x) := 2xTn(x) - Tn-1(x), n > 0, 其中 T0(x) := 1 且 T1(x) := x. 在 Boost 中可以用以下简单代码计算它们

double x = 0.5;
double T12 = boost::math::chebyshev_t(12, x);

导数的计算也很直接:

double T12_prime = boost::math::chebyshev_t_prime(12, x);

用这些函数计算第 n 个 Chebyshev 多项式的复杂度是线性的. 因此它们不适合用于计算 (比如说) Chebyshev 级数, 因为多个线性复杂度求值之和的复杂度按平方增长. 尽管存在非常复杂的 Chebyshev 级数求值算法, 下面仍给出一个线性时间算法:

double x = 0.5;
std::vector<double> c{14.2, -13.7, 82.3, 96};
double T0 = 1;
double T1 = x;
double f = c[0]*T0/2;
unsigned l = 1;
while(l < c.size())
{
   f += c[l]*T1;
   std::swap(T0, T1);
   T1 = boost::math::chebyshev_next(x, T0, T1);
   ++l;
}

它使用 chebyshev_next 函数以常量时间计算 Chebyshev 级数的每一项. 然而, 当 x 接近 1 时, 这个朴素的算法会出现灾难性的精度损失. Clenshaw 给出了缓解此问题的一种方法, 并在 boost 中实现为

double x = 0.5;
std::vector<double> c{14.2, -13.7, 82.3, 96};
double f = chebyshev_clenshaw_recurrence(c.data(), c.size(), x);

注意: 我们对 Chebyshev 级数首系数的定义与 Clenshaw 原始工作之间存在因子 2 的差别. 这是因为 Chebyshev 级数展开的记法存在两种传统:

boost math 始终使用第二种约定, 即第一个系数上带有因子 1/2.

另一个常见用例是多项式必须在某个区间 [a, b] 上求值. 到区间 [-1, 1] 的变换会带来一些精度问题, 同时也给我们提供了一些机会. 对于这种情况, 我们使用对 Clenshaw 递推的 Reinch 修正, 此处亦有讨论. 用法如下:

double x = 9;
double a = 7;
double b = 12;
std::vector<double> c{14.2, -13.7, 82.3, 96};
double f = chebyshev_clenshaw_recurrence(c.data(), c.size(), a, b, x);

第二类 Chebyshev 多项式可通过 chebyshev_u 求值:

double x = -0.23;
double U1 = boost::math::chebyshev_u(1, x);

已知用三项递推计算 Chebyshev 多项式是 前向-后向混合稳定 的, 适用于 x ∊ [-1, 1]. 然而, 对于 [-1, 1] 之外的 x, 作者不知道是否有类似结果. 出于这个原因, 强烈不建议在 [-1, 1] 之外计算 Chebyshev 多项式. 话虽如此, 计算过程中的微小舍入误差常常会导致这种情况, 而因这些小问题终止计算又非常令人沮丧. 为此, chebyshev_t 和 chebyshev_u 针对 x > 1 和 x < -1 提供了不使用三项递推的代码路径. 这些代码路径 慢得多, 应尽可能避免使用.

Chebyshev 级数的求值相对简单. 真正的挑战在于 Chebyshev 级数的 生成. 为此, boost 提供了 Chebyshev 变换——一个把函数投影到 Chebyshev 多项式有限维张成空间上的投影算子. 但在讨论 API 之前, 让我们先分析为什么可能需要把函数投影到 Chebyshev 多项式的张成空间上.

  • 我们希望有一种数值稳定的方法来计算该函数的导数.
  • 我们要计算的函数求值开销很大, 希望找到一种更便宜的方式来估计其值. 标准库的超越函数就是一例: 这些函数保证求值结果与精确值相差不超过 1 ulp, 但通常并不需要这样的精度. 在精度要求较低时, 向 Chebyshev 多项式投影可以大幅加速这些函数的计算.
  • 我们希望对该函数进行数值积分.

API 如下所示.

#include <boost/math/special_functions/chebyshev_transform.hpp>

namespace boost{ namespace math{

template<class Real>
class chebyshev_transform
{
public:
    template<class F>
    chebyshev_transform(const F& f, Real a, Real b, Real tol=500*std::numeric_limits<Real>::epsilon());

    Real operator()(Real x) const

    Real integrate() const

    const std::vector<Real>& coefficients() const

    Real prime(Real x) const
};

}}// end namespaces

Chebyshev 变换接受一个函数 f, 返回一个 近极小极大 的、对 f 用 Chebyshev 多项式表示的逼近. 所谓 近极小极大, 是指所得的 Chebyshev 多项式与多项式 pn "非常接近", 后者使 f - pn 的一致范数最小化. "非常接近"这一概念可以严格化; 详情参见 Trefethen 的 "Approximation Theory and Approximation Practice".

Chebyshev 变换的工作方式是: 在 Chebyshev 点上对输入函数求值, 生成一个值向量, 然后对该向量执行离散余弦变换. 为了高效地完成这一步, 我们使用了 FFTW3. 因此编译时必须已安装 FFTW3, 并针对双精度链接 -lfftw3, 针对单精度链接 -lfftw3f, 针对 long double 精度链接 -lfftw3l, 针对 quad 精度链接 -lfftw3q (即 __float128). 在得到 Chebyshev 级数的系数之后, 该例程会回过头遍历这些系数, 过滤掉与最大系数之比的绝对值小于构造函数中指定容差的所有系数.
