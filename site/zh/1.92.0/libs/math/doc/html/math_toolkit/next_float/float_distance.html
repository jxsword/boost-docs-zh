计算两个浮点值之间的表示距离 (ULP) float_distance

函数 float_distance 求任意两个浮点值之间的间隔数/位数/ULP 数. 若把浮点数的尾数看作整数, 则它们的差就是相差的 ULP/间隔/位数.

概要 
#include <boost/math/special_functions/next.hpp>

namespace boost{ namespace math{

template <class FPT>
FPT float_distance(FPT a, FPT b);

}} // namespaces
说明 - float_distance

返回 a 与 b 之间的距离: 结果始终是带符号整数值 (以浮点类型 FPT 存储) , 表示 a 与 b 之间不同表示的个数.

注意:

  • float_distance(a, a) 总是返回 0.
  • float_distance(float_next(a), a) 总是返回 -1.
  • float_distance(float_prior(a), a) 总是返回 1.

函数 float_distance 等价于计算 a 与 b 之间的 ULP (最后一位单位) 数, 区别在于它返回带符号的值, 用以指示 a > b 与否.

如果距离过大, 可能无法用类型 FPT 表示为精确整数, 但实践中这不太可能成为问题.
