数学上未定义函数策略

有一些函数是泛型的 (对所有受支持的统计分布都存在), 但对某些分布在数学上可能未定义, 而对另一些分布则有定义.

例如, Cauchy 分布没有有意义的均值, 那么

mean(cauchy<>());

应该返回什么, 这样的表达式甚至应该能编译吗?

默认行为是所有这类函数完全无法编译 - 实际上它们会引发 static assertion - 但通过更改策略, 我们可以让它们改为返回定义域错误的结果 (根据错误处理策略, 这很可能会抛出异常).

此行为由 assert_undefined<> 策略控制:

namespace boost{ namespace math{ namespace policies {

template <bool b>
class assert_undefined;

}}} //namespaces

例如:

#include <boost/math/distributions/cauchy.hpp>

using namespace boost::math::policies;
using namespace boost::math;

// This will not compile, cauchy has no mean!
double m1 = mean(cauchy());

// This will compile, but raises a domain error!
double m2 = mean(cauchy_distribution<double, policy<assert_undefined<false> > >());

policy<assert_undefined<false> 行为也可以通过在文件头部定义宏

#define BOOST_MATH_ASSERT_UNDEFINED_POLICY false

来获得 - 参见 Using Macros to Change the Policy Defaults.
