离散概率分布

注意, 包括二项分布、负二项分布、Poisson 分布和 Bernoulli 分布在内的 离散分布, 在数学上都定义为离散函数: 只考虑 随机变量 的整数值, 且这些函数只在这些整数值处有定义. 然而, 由于计算方法常常使用连续函数, 把它们当作连续函数来处理、并允许其参数取非整数值会更方便.

为了执行严格的数学模型, 用户可以在调用分布函数之前, 对 随机变量 使用 floor 或 ceil 函数来强制取整数值.

出于类似的原因, 在连续分布中, 自由度等看似整数的参数被当作实数值处理 (必要时会从整数提升为浮点数). 不过在这种情形下, 有少数情况中非整数自由度确实具有真实含义.

一般来说, 允许实数值参数不会带来性能损失: 底层特殊函数在适用时包含针对整数值参数的优化.

注意

离散分布的分位数函数默认返回一个 向外舍入 的整数结果. 也就是说, 下分位数 (概率小于 0.5 时) 向下舍入, 上分位数 (概率大于 0.5 时) 向上舍入. 这种行为确保当请求 X% 分位数时, 中心区域 至少 覆盖所请求的覆盖率, 而尾部 至多 覆盖所请求的覆盖率.

可以使用 Policies 更改此行为, 使分位数函数以不同方式舍入, 甚至返回实数值结果. 强烈建议在离散分布上使用分位数函数之前阅读教程 Understanding Quantiles of Discrete Distributions. reference docs 描述了如何更改这些分布的舍入策略.
