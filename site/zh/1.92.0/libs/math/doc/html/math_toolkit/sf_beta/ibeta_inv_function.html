说明

共有六个 incomplete beta function inverses, 它们使你可以从不完全 Beta 函数的结果 (p) 或其补 (q) 出发, 求解不完全 Beta 函数三个参数中的任意一个.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

提示

当人们通常谈到不完全 Beta 函数的反函数时, 他们指的是对参数 x 求逆. 它们在这里的实现是 ibeta_inv 和 ibetac_inv, 并且是本文介绍的反函数中效率最高的.

对 a 和 b 参数求逆的反函数在某些统计应用中有所用处, 但必须用相当暴力的数值技术来计算, 因此慢了几倍. 它们在这里的实现是 ibeta_inva 和 ibeta_invb, 以及补版本 ibetac_inva 和 ibetac_invb.

当以不同类型的参数 T1...TN 调用这些函数时, 其返回类型使用 结果类型计算规则 计算.

返回一个值 x, 使得: p = ibeta(a, b, x);, 并且设置 *py = 1 - x (当 py 参数已提供且非空时). 注意, 该函数在内部计算 x 和 1-x 中较小的一个, 因此赋给 *py 的值不受抵消误差影响. 这意味着, 即使函数返回 1, 存储在 *py 中的值也可能非零, 尽管非常小.

要求: a,b > 0 且 0 <= p <= 1.

精度

这些函数的精度应当与常规的正向不完全 Beta 函数非常接近. 不过请注意, 在其定义域的某些部分, 这些函数对输入的变化可能极其敏感, 特别是当参数 p (或其补 q) 非常接近 0 或 1 时.

测试

测试分为两组:

  • 基本的健全性检查尝试从 a, b 和 x "往返"到 p 或 q 再返回. 这些测试的容差相当宽松: 一般而言, 不完全 Beta 函数及其反函数变化如此之快, 以致于无法往返恢复到多于几位有效数字. 当 p 或 q 非常接近 1 时尤其如此: 在这种情况下, 反函数的输入中没有足够的"信息量"让你回到起点.
  • 使用高精度测试值的精度检查. 这些检查在给定精确输入值的情况下度量结果的精度.
ibeta_inv 和 ibetac_inv 的实现

这两个函数共享同一个实现.

首先计算 x 的一个初始近似, 然后使用 Halley iteration 清理最后几位. 迭代上限被设为 T 的位数的一半, 实验表明这足以保证反函数的精度至少与常规不完全 Beta 函数相当. 在极端情况下可能需要多达 5 次迭代, 但通常只需一两次. 此外, 所需迭代次数随 a 和 b 的增大而减少 (它们通常构成更重要的用例).

对 a 和 b 参数求逆的反函数的实现

这四个函数共享同一个实现.

首先为 a 或 b 计算一个初始近似: 在可能的情况下, 使用负二项分布的 Cornish-Fisher 展开使结果接近到 1 以内. 然而, 当 a 或 b 非常小时, Cornish-Fisher 展开不可用; 在这种情况下, 初始近似的选取使得 Ix(a, b) 位于 [0,1] 范围的中点附近.

随后, 该初始猜测值被用作通用求根算法的起始值. 一旦根被界定, 该算法会迅速收敛于根, 但界定根可能需要几次迭代. 若能为 a 或 b 找到更好的初始近似, 这些函数将得到显著改进: 目前求根需要 10-20 次不完全 Beta 函数调用.
