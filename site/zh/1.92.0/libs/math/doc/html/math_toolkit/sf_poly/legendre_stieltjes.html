Legendre-Stieltjes 多项式

概要 
#include <boost/math/special_functions/legendre_stieltjes.hpp>


namespace boost{ namespace math{

template <class T>
class legendre_stieltjes
{
public:
    legendre_stieltjes(size_t m);

    Real norm_sq() const;

    Real operator()(Real x) const;

    Real prime(Real x) const;

    std::vector<Real> zeros() const;
}

}}
说明

Legendre-Stieltjes 多项式是一族用于生成 Gauss-Konrod 求积公式的多项式. Gauss-Konrod 求积是这样一类算法: 它们对 Gauss 求积加以扩展, 使得在计算更高阶的积分估计时所有横坐标都得到复用, 从而能够高效地计算误差估计. Legendre-Stieltjes 多项式有助于完成这一任务, 因为它们的零点与 Legendre 多项式的零点 交错, 也就是说, 在 n 次 Legendre 多项式的任意两个零点之间, 必存在 n+1 次 Legendre-Stieltjes 多项式的一个零点.

Legendre-Stieltjes 多项式 En+1 由如下性质定义: 它们具有 n 个对振荡测度 Pn 的消失矩, 即

∫ -11 En+1(x)Pn(x) xkdx = 0

对 k = 0, 1, ..., n.

前几个为

E1(x) = P1(x)

E2(x) = P2(x) - 2P0(x)/5

E3(x) = P3(x) - 9P1(x)/14

E4(x) = P4(x) - 20P2(x)/27 + 14P0(x)/891

E5(x) = P5(x) - 35P3(x)/44 + 135P1(x)/12584

其中 Pi 是 Legendre 多项式. 缩放方式遵循 Patterson: 他把 Legendre-Stieltjes 多项式展开为 Legendre 级数, 并取级数中最高阶 Legendre 多项式的系数为 1.

Legendre-Stieltjes 多项式不满足三项递推关系, 也没有特别简单的表示. 因此, 构造函数调用决定了该多项式实际上是什么. 构造函数返回之后, 即可通过 Legendre 级数对多项式求值.

用法示例:

// Call to the constructor determines the coefficients in the Legendre expansion
legendre_stieltjes<double> E(12);
// Evaluate the polynomial at a point:
double x = E(0.3);
// Evaluate the derivative at a point:
double x_p = E.prime(0.3);
// Use the norm_sq to change between scalings, if desired:
double norm = std::sqrt(E.norm_sq());
