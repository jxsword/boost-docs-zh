策略类参考

这里没什么可说的, policy 类只是容纳一组策略的杂集编译期容器:

#include <boost/math/policies/policy.hpp>
namespace boost{
namespace math{
namespace policies

template <class A1 = default_policy,
          class A2 = default_policy,
          class A3 = default_policy,
          class A4 = default_policy,
          class A5 = default_policy,
          class A6 = default_policy,
          class A7 = default_policy,
          class A8 = default_policy,
          class A9 = default_policy,
          class A10 = default_policy,
          class A11 = default_policy,
          class A12 = default_policy,
          class A13 = default_policy>
struct policy
{
public:
   typedef computed-from-template-arguments domain_error_type;
   typedef computed-from-template-arguments pole_error_type;
   typedef computed-from-template-arguments overflow_error_type;
   typedef computed-from-template-arguments underflow_error_type;
   typedef computed-from-template-arguments denorm_error_type;
   typedef computed-from-template-arguments rounding_error_type;
   typedef computed-from-template-arguments evaluation_error_type;
   typedef computed-from-template-arguments indeterminate_result_error_type;
   typedef computed-from-template-arguments precision_type;
   typedef computed-from-template-arguments promote_float_type;
   typedef computed-from-template-arguments promote_double_type;
   typedef computed-from-template-arguments discrete_quantile_type;
   typedef computed-from-template-arguments assert_undefined_type;
};

template <...argument list...>
typename normalise<policy<>, A1>::type make_policy(...argument list..);

          class A1 = default_policy,
          class A2 = default_policy,

struct normalise
{
   typedef computed-from-template-arguments type;
};

类 policy 的成员 typedef 供内部使用, 但为了完整性在此简要说明.

policy<...>::domain_error_type

指定如何处理定义域错误, 将是 boost::math::policies::domain_error<> 的实例, 其模板参数 domain_error 为 error_policy_type 枚举值之一.

policy<...>::pole_error_type

指定如何处理极点错误, 将是 boost::math::policies::pole_error<> 的实例, 其模板参数 pole_error 为 error_policy_type 枚举值之一.

policy<...>::overflow_error_type

指定如何处理上溢错误, 将是 boost::math::policies::overflow_error<> 的实例, 其模板参数 overflow_error 为 error_policy_type 枚举值之一.

policy<...>::underflow_error_type

指定如何处理下溢错误, 将是 boost::math::policies::underflow_error<> 的实例, 其模板参数 underflow_error 为 error_policy_type 枚举值之一.

policy<...>::denorm_error_type

指定如何处理非规格化错误, 将是 boost::math::policies::denorm_error<> 的实例, 其模板参数 denorm_error 为 error_policy_type 枚举值之一.

policy<...>::rounding_error_type

指定如何处理舍入错误, 将是 boost::math::policies::rounding_error<> 的实例, 其模板参数 rounding_error 为 error_policy_type 枚举值之一.

policy<...>::evaluation_error_type

指定如何处理求值错误, 将是 boost::math::policies::evaluation_error<> 的实例, 其模板参数 evaluation_error 为 error_policy_type 枚举值之一.

policy<...>::indeterminate_error_type

指定如何处理不确定结果错误, 将是 boost::math::policies::indeterminate_result_error<> 的实例, 其模板参数 indeterminate_result_error 为 error_policy_type 枚举值之一.

policy<...>::precision_type

指定内部使用的二进制位数精度 (用零表示任何默认精度). 将是 boost::math::policies::digits2<N> 的实例, 后者又继承自 boost::std::integral_constant<int, N>.

policy<...>::promote_float_type

指定是否在内部将 float 参数提升为 double 精度. 将是 boost::math::policies::promote_float<B> 的实例, 后者又继承自 std::integral_constant<bool, B>.

policy<...>::promote_double_type

指定是否在内部将 double 参数提升为 long double 精度. 将是 boost::math::policies::promote_float<B> 的实例, 后者又继承自 std::integral_constant<bool, B>.

policy<...>::discrete_quantile_type

指定如何求值离散分位数, 将是用 boost::math::policies::discrete_quantile<> 实例化、以 discrete_quantile_policy_type 枚举类型之一为参数的结果.

policy<...>::assert_undefined_type

指定数学上未定义的性质是作为编译期错误断言, 还是作为运行期错误处理. 将是 boost::math::policies::assert_undefined<B> 的实例, 后者又继承自 std::integral_constant<bool, B>.

template <...argument list...>
typename normalise<policy<>, A1>::type make_policy(...argument list..);

make_policy 是一个辅助函数, 它把策略列表转换为规范化的 policy 类.

template <class Policy,
          class A1 = default_policy,
          class A2 = default_policy,
          class A3 = default_policy,
          class A4 = default_policy,
          class A5 = default_policy,
          class A6 = default_policy,
          class A7 = default_policy,
          class A8 = default_policy,
          class A9 = default_policy,
          class A10 = default_policy,
          class A11 = default_policy,
          class A12 = default_policy,
          class A13 = default_policy>
struct normalise
{
   typedef computed-from-template-arguments type;
};

normalise 类模板把 policy 类的一种实例化转换为规范化形式. 它在内部用于减少代码膨胀: 使得在 policy<A,B> 或 policy<B,A> 上实例化特殊函数实际上都会在内部生成相同的代码.

此外, normalise 可用于将一个策略与一个或多个策略组合: 例如, 许多特殊函数会用它在转发到实际实现之前, 把它们不使用的策略设置为其默认值. 这样可以减少代码膨胀, 因为实际实现只依赖于它们实际使用的策略类型.
