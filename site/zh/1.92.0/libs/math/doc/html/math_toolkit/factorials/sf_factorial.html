阶乘

概要 
#include <boost/math/special_functions/factorials.hpp>

namespace boost{ namespace math{

template <class T>
T factorial(unsigned i);

template <class T, class Policy>
T factorial(unsigned i, const Policy&);

template <class T>
constexpr T unchecked_factorial(unsigned i);

template <class T>
struct max_factorial;

}} // namespaces
说明
重要

下述函数是模板, 其模板参数 T 无法从传给函数的参数推导. 因此如果你这样写:

boost::math::factorial(2);

会得到一个 (也许令人困惑的) 编译错误, 通常提示找不到这样的函数. 你需要显式指定返回类型, 改写为:

boost::math::factorial<double>(2);

这样返回类型就是已知的.

此外, 模板参数必须是实值类型 (如 float 或 double) 而非整数类型 — 对相当小的参数 i 值那也会轻易上溢!

源代码 static_assert 及其后的注释将是:

static_assert(!std::is_integral<T>::value, "Type T must not be an integral type");
// factorial<unsigned int>(n) is not implemented
// because it would overflow integral type T for too small n
// to be useful. Use instead a floating-point type,
// and convert to an unsigned type if essential, for example:
// unsigned int nfac = static_cast<unsigned int>(factorial<double>(n));
// See factorial documentation for more detail.

template <class T>
T factorial(unsigned i);

template <class T, class Policy>
T factorial(unsigned i, const Policy&);

返回 i!.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

对 i <= max_factorial<T>::value 通过查表实现; 对更大的 i 值, 该函数借助 tgamma 实现.

若 i 大到结果无法用类型 T 表示, 则调用 overflow_error.

template <class T>
constexpr T unchecked_factorial(unsigned i);

返回 i!.

该函数在内部对结果做查表. 此外, 它不对 i 的值做范围检查: 确保满足 i <= max_factorial<T>::value 是调用者的责任. 该函数旨在用于需要对阶乘做快速查表的内层循环, 但需要小心确保参数 i 永远不会增长得太大.

template <class T>
struct max_factorial
{
   static const unsigned value = X;
};

该特征类定义了可以传给 unchecked_factorial 的最大值. 成员 value 可用于需要整型常量表达式的场合: 例如定义依赖于阶乘的其他表的大小.

仅当编译器支持 C++14 constexpr 函数时, 该函数才为 constexpr.

精度

对小于 max_factorial<T>::value 的参数, 结果应当正确舍入. 对更大的参数, 精度与 tgamma 相同.

测试

基本健全性检查与用于核对数据表的抽检值: tgamma 函数的主要测试已经涵盖这些情形.

实现

阶乘函数对小参数用表驱动, 对较大参数借助 tgamma 实现.
