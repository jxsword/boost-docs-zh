#include <boost/math/statistics/t_test.hpp>

template<typename Container>

template<typename ForwardIterator, typename Real = typename std::iterator_traits<ForwardIterator>::value_type>

}

背景

一组与 C++11 兼容的函数, 用于各种 Student t 检验. 输入可以是任何实数或实数集合. 如果输入是整数或整数集合, typename Real 将被推导为双精度类型.

单样本 t 检验

单样本 t 检验试图回答这样一个问题: "给定样本均值, 我的数据的总体均值是否可能是某个特定值?" 检验统计量为

其中 µ0 是假定的均值, s2 是样本方差, n 是样本数. 如果检验统计量的绝对值大, 那么我们对总体均值等于 µ0 的信心就低; 如果检验统计量的绝对值小, 我们就有很高的信心. 现在我们要问: "在这种情况下, 大和小以什么为标准?"

在合理的假设下, 可以认为检验统计量 t 来自 Student t 分布. 由于我们想知道样本均值是否在任一方向上偏离真实均值, 该检验是双尾的. 因此, p 值很容易从具有 n - 1 个自由度的 Student t 分布计算得到, 但无论如何, 在这里计算它很方便.

用法示例如下:

#include <vector>
#include <random>
#include <boost/math/statistics/t_test.hpp>

std::random_device rd;
std::mt19937 gen{rd()};
std::normal_distribution<double> dis{0,1};
std::vector<double> v(1024);
for (auto & x : v) {
  x = dis(gen);
}

auto [t, p] = boost::math::statistics::one_sample_t_test(v, 0.0);

检验统计量是该 pair 的第一个元素, 而 p 值是第二个元素.

用法示例如下:

#include <vector>
#include <random>
#include <boost/math/statistics/t_test.hpp>

std::random_device rd;
std::mt19937 gen{rd()};
std::normal_distribution<double> dis{0,1};
std::vector<double> u(1024);
std::vector<double> v(1024);
for(std::size_t i = 0; i < u.size(); ++i)
{
  u[i] = dis(gen);
  v[i] = dis(gen);
}

auto [t, p] = boost::math::statistics::two_sample_t_test(u, v);

Nota bene: 两组数据的样本大小不必相等.

Nota bene: 实现中使用了 std::distance, 因此 ForwardIterator 的性能低于 RandomAccessIterator.

配对样本的 t 检验

该检验用于样本相关的情况, 例如同一样本被测量两次, 或两个样本已配对. 与独立 t 检验非常相似, 它用于判定两组数据的均值之间是否存在统计上显著的差异.

其中 XD 和 sD 是所有配对之差的均值和标准差.

用法示例如下:

#include <vector>
#include <random>
#include <boost/math/statistics/t_test.hpp>

std::vector<int> first_test {35, 50, 90, 78};
std::vector<int> second_test {67, 46, 86, 91};

auto [t, p] = boost::math::statistics::paired_samples_t_test(first_test, second_test);
