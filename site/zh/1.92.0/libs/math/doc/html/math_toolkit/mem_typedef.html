Quaternion 成员 typedef

value_type

模板版本:

typedef T value_type;

float 特化版本:

typedef float value_type;

double 特化版本:

typedef double value_type;

long double 特化版本:

typedef long double value_type;

这些为模板所基于的类型提供了便捷访问.
