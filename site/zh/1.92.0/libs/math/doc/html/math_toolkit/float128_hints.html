使用 float128 (与 __float128) 的提示

__float128 与 float128 之比较
  • __float128 是 (可选的) 编译器提供的硬件类型, 它是对 C++ 的类 C 扩展, 普通 C++ 对它的支持极少 (没有 IO 流或 numeric_limits 支持, libquadmath 中的函数名都与 std:: 的对应函数不同等等). 所以你可以直接对类型 __float128 编程, 但会更费劲.
  • 类型 float128 使用 __float128 并使其对 C++ 与泛型代码友好, 所有常用的标准 iostream、numeric_limits、complex 在命名空间 std:: 中都可用, 因此强烈推荐在 C++ 中使用.
提示与技巧
  • 确保用正确的类型声明变量, 这里是 float128.
  • 确保把变量传给函数时将其转换为 float128.
  • 确保用正确的后缀声明字面量 — 否则它们会被当作类型 double 处理, 造成灾难性的精度损失. 因此 128 位浮点字面量务必带 Q 后缀.
  • 所有 std 库函数、cmath 函数, 加上所有常数以及 Boost.Math 的特殊函数, 之后都应当直接可用.
  • 确保调用 std 库函数时不加限定, 以便通过 Argument Dependent Lookup (ADL) 找到正确的重载. 所以写 sqrt(variable) 而不是 std::sqrt(variable).
  • 总的来说, 尽量不要重复造轮子 — 使用 Boost.Math 的常数可能比声明自己的更不容易出错, 特殊函数等亦然.

一些可能悄无声息地出错得非常糟糕的示例见 float128_example.cpp.
