标准差的置信区间

计算出数据的标准差之后, 一个合理的问题是: "计算出的标准差有多可靠?" 对于这种情况, 可以使用 Chi Squared 分布来计算标准差的置信区间.

完整示例代码和示例输出见 chi_square_std_dev_test.cpp.

我们先定义将计算并打印置信区间的过程:

void confidence_limits_on_std_deviation(
     double Sd,    // Sample Standard Deviation
     unsigned N)   // Sample size
{

我们先打印一些一般信息:

cout <<
   "________________________________________________\n"
   "2-Sided Confidence Limits For Standard Deviation\n"
   "________________________________________________\n\n";
cout << setprecision(7);
cout << setw(40) << left << "Number of Observations" << "=  " << N << "\n";
cout << setw(40) << left << "Standard Deviation" << "=  " << Sd << "\n";

然后定义一个显著性水平表, 我们将为它们计算区间:

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

计算置信区间所需的分布是具有 N-1 个自由度的 Chi Squared 分布:

chi_squared dist(N - 1);

在代码中, 我们先打印表头:

cout << "\n\n"
        "_____________________________________________\n"
        "Confidence          Lower          Upper\n"
        " Value (%)          Limit          Limit\n"
        "_____________________________________________\n";

然后循环遍历 alpha 的值并计算每个值的区间: 记住下临界值与分位数相同, 而上临界值与从概率补集求得的分位数相同:

for(unsigned i = 0; i < sizeof(alpha)/sizeof(alpha[0]); ++i)
{
   // Confidence value:
   cout << fixed << setprecision(3) << setw(10) << right << 100 * (1-alpha[i]);
   // Calculate limits:
   double lower_limit = sqrt((N - 1) * Sd * Sd / quantile(complement(dist, alpha[i] / 2)));
   double upper_limit = sqrt((N - 1) * Sd * Sd / quantile(dist, alpha[i] / 2));
   // Print Limits:
   cout << fixed << setprecision(5) << setw(15) << right << lower_limit;
   cout << fixed << setprecision(5) << setw(15) << right << upper_limit << endl;
}
cout << endl;

作为观测次数函数的置信区间

类似地, 我们还可以针对不断增加的观测次数, 列出常用置信水平 95% 下标准差的置信区间.

用于计算这些值的标准差为 1, 因此列出的界限是任何特定标准差的 乘数. 例如, 给定上文示例中的标准差 0.0062789; 对 100 次观测, 乘数为 0.8780, 得到置信下限 0.8780 * 0.006728 = 0.00551.

只有 2 次观测时, 界限从 0.445 到 31.9, 因此标准差可能是观测值的约 一半 到观测值的 30 倍!

仅用少数几个值估计标准差会带来非常大的不确定性, 尤其是上限. 特别注意上限相对于最可能标准差的偏斜程度有多大.

即使对于通常被认为合理的 10 次观测, 范围仍在 0.69 到 1.8 之间, 大约是 0.7 到 2 的范围, 并且仍然高度偏斜, 上限是中位数的 两倍.

当有 1000 次观测时, 标准差的估计开始看起来可信, 范围从 0.95 到 1.05——现在接近对称, 但仍约为 ±5%.

只有当重复观测达到 10000 次或更多时, 我们才能开始有相当的信心 (前提是我们确信漂移等其他因素没有悄然混入).

对 10000 次观测, 区间为 0.99 到 1.1——终于得到了真正令人信服的 ±1% 置信度.
