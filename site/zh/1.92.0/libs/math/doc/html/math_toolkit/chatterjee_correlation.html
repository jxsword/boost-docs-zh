Chatterjee 相关系数

概要 

#include <boost/math/statistics/chatterjee_correlation.hpp>

namespace boost::math::statistics {

    C++17:
    template <typename ExecutionPolicy, typename Container>
    auto chatterjee_correlation(ExecutionPolicy&& exec, const Container& u, const Container& v);

    C++11:
    template <typename Container>
    auto chatterjee_correlation(const Container& u, const Container& v);
}

说明

Pearson 相关等经典相关系数主要用于区分一个数据集是否线性依赖于另一个数据集. 然而, Pearson 相关系数有一个已知弱点: 当因变量与自变量之间存在明显的函数关系时, 相关系数的取值却可以是任何值. 正如 Chatterjee 所说:

> 理想情况下, 人们希望有这样一种系数: 当且仅当一个变量看起来越来越像另一个变量的无噪声函数时, 它趋近其最大值; 正如当且仅当一个变量接近另一个变量的无噪声线性函数时, Pearson 相关接近其最大值.

这就是 Chatterjee 系数所解决的问题. 设 X 和 Y 为随机变量, 其中 Y 不是常数, 并设 (X_i, Y_i) 为该分布的样本. 将这些样本重排使得 X_(0) < X_{(1)} < ... X_{(n-1)}, 并构造 (R(X_{(i)}), R(Y_{(i)})). Chatterjee 相关系数由下式给出:

在无穷多 i.i.d 数据的极限下, 该统计量位于 [0, 1] 内. 但如果数据不是无穷的, 该统计量可能为负. 若 X 与 Y 独立, 其值为零; 若 Y 是 X 的可测函数, 则该统计量为 1. 复杂度为 O(n log n).

下面给出一个示例:

std::vector<double> X{1,2,3,4,5};
std::vector<double> Y{1,2,3,4,5};
using boost::math::statistics::chatterjee_correlation;
double coeff = chatterjee_correlation(X, Y);

实现遵循 Chatterjee's paper.

注意: 如果输入是整数类型, 输出将是双精度类型.

不变式

该函数要求至少两个样本、一个非常量向量 Y, 以及与 Y 数目相同的 X. 若 Y 是常数, 结果为 quiet NaN. 数据集必须按 X 值排序. 若 X 的值存在并列, 由于并列被随机打破, 该统计量是随机的. 当然, 内部并不使用随机数, 但不保证在不同系统上结果完全相同.
