非中心卡方分布 

#include <boost/math/distributions/non_central_chi_squared.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class non_central_chi_squared_distribution;

typedef non_central_chi_squared_distribution<> non_central_chi_squared;

template <class RealType, class Policy>
class non_central_chi_squared_distribution
{
public:
   typedef RealType  value_type;
   typedef Policy    policy_type;

   // Constructor:
   BOOST_MATH_GPU_ENABLED non_central_chi_squared_distribution(RealType v, RealType lambda);

   // Accessor to degrees of freedom parameter v:
   BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom()const;

   // Accessor to non centrality parameter lambda:
   BOOST_MATH_GPU_ENABLED RealType non_centrality()const;

   // Parameter finders:
   BOOST_MATH_GPU_ENABLED static RealType find_degrees_of_freedom(RealType lambda, RealType x, RealType p);
   template <class A, class B, class C>
   BOOST_MATH_GPU_ENABLED static RealType find_degrees_of_freedom(const complemented3_type<A,B,C>& c);

   BOOST_MATH_GPU_ENABLED static RealType find_non_centrality(RealType v, RealType x, RealType p);
   template <class A, class B, class C>
   BOOST_MATH_GPU_ENABLED static RealType find_non_centrality(const complemented3_type<A,B,C>& c);
};

}} // namespaces

成员函数 
BOOST_MATH_GPU_ENABLED non_central_chi_squared_distribution(RealType v, RealType lambda);

构造一个自由度为 ν、非中心性参数为 lambda 的卡方分布.

要求 ν > 0 且 lambda >= 0, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom()const;

返回构造此对象所用的参数 ν.

BOOST_MATH_GPU_ENABLED RealType non_centrality()const;

返回构造此对象所用的参数 lambda.

BOOST_MATH_GPU_ENABLED static RealType find_degrees_of_freedom(RealType lambda, RealType x, RealType p);

此函数返回自由度 ν, 使得: cdf(non_central_chi_squared<RealType, Policy>(v, lambda), x) == p 

template <class A, class B, class C>
BOOST_MATH_GPU_ENABLED static RealType find_degrees_of_freedom(const complemented3_type<A,B,C>& c);

以参数 boost::math::complement(lambda, x, q) 调用时, 此函数返回自由度 ν, 使得:

cdf(complement(non_central_chi_squared<RealType, Policy>(v, lambda), x)) == q. 

BOOST_MATH_GPU_ENABLED static RealType find_non_centrality(RealType v, RealType x, RealType p);

此函数返回非中心性参数 lambda, 使得:

cdf(non_central_chi_squared<RealType, Policy>(v, lambda), x) == p 

template <class A, class B, class C>
BOOST_MATH_GPU_ENABLED static RealType find_non_centrality(const complemented3_type<A,B,C>& c);

以参数 boost::math::complement(v, x, q) 调用时, 此函数返回非中心性参数 lambda, 使得:

cdf(complement(non_central_chi_squared<RealType, Policy>(v, lambda), x)) == q.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域是 [0, +∞].

实现

CDF 及其补的计算方式如下:

首先, 我们确定两个值 (CDF 或其补) 中哪一个可能更小: 为此我们可以使用 Temme 给出的关系 (参见 "Asymptotic and Numerical Aspects of the Noncentral Chi-Square Distribution", N. M. Temme, Computers Math. Applic. Vol 25, No. 5, 55-63, 1993):

F(ν,λ;ν+λ) ≈ 0.5

于是当随机变量小于 ν+λ 时计算 CDF, 当随机变量大于 ν+λ 时计算其补. 如有必要, 再用 1 减去算得的值以得到所需结果 (CDF 或其补).

对于非中心性参数较小的情况, 使用 Ding 的方法计算 CDF (参见 "Algorithm AS 275: Computing the Non-Central #2 Distribution Function", Cherng G. Ding, Applied Statistics, Vol. 41, No. 2. (1992), pp. 478-482). 它使用以下级数表示:

对于非中心性参数较大的情况, Ding 的方法在收敛前可能需要多得离谱的项数. 而且, 最大的项并不是第一项, 因此在极端情况下第一项可能为零, 导致结果为零, 即使真值可能非零.

因此, 当非中心性参数大于 200 时, 使用 Krishnamoorthy 的方法 (参见 "连续分布离散混合的计算: 非中心卡方、非中心 t 与样本多重相关系数平方的分布", Denise Benton and K. Krishnamoorthy, Computational Statistics & Data Analysis, 43, (2003), 249-267).
