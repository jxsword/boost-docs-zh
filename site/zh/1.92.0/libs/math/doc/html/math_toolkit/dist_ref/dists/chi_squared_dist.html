卡方分布是统计检验中使用最广泛的分布之一. 若 χi 是 ν 个独立的、均值为 μi、方差为 σi2 的正态分布随机变量, 则随机变量:

服从卡方分布.

卡方分布是 gamma 分布的特例, 只有一个参数 ν, 指定自由度数目. 下图展示了分布随 ν 取不同值的变化:

成员函数 
chi_squared_distribution(RealType v);

构造具有 v 个自由度的卡方分布.

要求 v > 0, 否则调用 domain_error.

RealType degrees_of_freedom()const;

返回构造此对象时使用的参数 v.

static RealType find_degrees_of_freedom(
   RealType difference_from_variance,
   RealType alpha,
   RealType beta,
   RealType variance,
   RealType hint = 100);

估计在等标准差的卡方检验中, 检测与标称方差的差异所需的样本量.

difference_from_variance

要检测的与假定标称方差的差异: 注意此值的符号至关重要, 见下文.

alpha

在原假设实际为真时拒绝原假设的最大可接受风险.

beta

错误地未能拒绝原假设的最大可接受风险.

variance

被检验的标称方差.

hint

关于从何处开始寻找结果的可选提示: 当前的样本量会是一个不错的选择.

注意, 此计算针对的是方差而不是标准差.

参数 difference_from_variance 的符号很重要: 卡方分布是不对称的, 调用者必须事先决定是检验方差大于标称值 (difference_from_variance 为正) 还是检验方差小于标称值 (difference_from_variance 为负). 若为后者, 显然必须满足 variance + difference_from_variance > 0, 因为任何样本的方差都不可能为负!

此过程使用 Diamond, W. J. (1989). Practical Experiment Designs, Van-Nostrand Reinhold, New York 中的方法.

另见 the NIST Engineering Statistics Handbook, Section 7.2.3.2 中关于所需样本量的一节.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

(我们遵循了通常把众数限制在自由度 >= 2 的做法, 但请注意, 对于自由度从 2 降到 0 的情况, pdf 的最大值实际上在零处; 我们在注释中以备选代码的形式提供了一个可避免众数不连续的扩展定义).

随机变量的定义域是 [0, +∞].

实现

在下表中, v 是分布的自由度数目, x 是随机变量, p 是概率, q = 1-p 为其补.

函数

实现说明

pdf

利用关系: pdf = gamma_p_derivative(v / 2, x / 2) / 2

cdf

利用关系: p = gamma_p(v / 2, x / 2)

cdf 补函数

利用关系: q = gamma_q(v / 2, x / 2)

quantile

利用关系: x = 2 * gamma_p_inv(v / 2, p)

利用关系: x = 2 * gamma_q_inv(v / 2, p)
