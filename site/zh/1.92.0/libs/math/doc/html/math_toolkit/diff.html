数值微分

概要 

#include <boost/math/differentiation/finite_difference.hpp>


namespace boost { namespace math { namespace differentiation {

    template <class F, class Real>
    Real complex_step_derivative(const F f, Real x);

    template <class F, class Real, size_t order = 6>
    Real finite_difference_derivative(const F f, Real x, Real* error = nullptr);

}}} // namespaces

说明

函数 finite_difference_derivative 计算函数 f 在点 x 处导数的有限差分近似. 基本用法是

auto f = [](double x) { return std::exp(x); };
double x = 1.7;
double dfdx = finite_difference_derivative(f, x);

有限差分很复杂, 因为微分是无穷病态的. 此外, 对任何以有限精度算术实现的函数而言, “真实”导数几乎处处为 零, 而在可表示点上则未定义. 不过, 一些技巧使得在许多情况下仍能得到合理的结果.

有限差分有两个误差来源: 其一是截断误差, 来自用有限个样本去抵消 Taylor 级数中的高阶项; 其二是求值函数时涉及的舍入误差. 截断误差随 h → 0 而趋于零, 但舍入误差会变得无界. 通过权衡这两个误差来源, 我们可以选择一个使最大总误差最小的 h 值. 出于这个原因, boost 的 finite_difference_derivative 不要求用户输入步长. 关于导数的有限差分近似所涉及的理论误差分析的更多细节, 参见 here.

尽管在为 h 选择合理值上下了功夫, 这个问题在根本上仍然是病态的, 因此误差估计必不可少. 可以按如下方式查询:

double error_estimate;
double d = finite_difference_derivative(f, x, &error_estimate);

注意: 生成误差估计需要额外的函数求值, 因此比单纯求导数更慢. 它还扩大了函数必须可微的定义域, 并要求函数再多两个连续导数. 误差估计是在 f 以 1ULP 精度求值的假设下计算的. 这看似极端, 却是唯一合理假设, 因为例程无法得知函数的舍入误差. 如果函数无法以很高的精度求值, 建议改用 Lanczos 平滑微分.

默认精度阶为 6, 这反映出人们通常关注具有多个连续导数的函数. 如果你的函数没有 7 个连续导数, 使用低阶方法可能有益, 可以通过 (比如)

double d = finite_difference_derivative<decltype(f), Real, 2>(f, x);

这要求计算二阶精度的导数.

需要强调的是, 并非高阶方法总是对光滑函数给出更高的精度. 高阶方法需要更多正负项相加, 这可能导致灾难性消去. 一个非常擅长嘲弄有限差分微分的函数是 exp(x)/(cos(x)3 + sin(x)3). 在双精度下用 finite_difference_derivative 对该函数在 x=5.5 处求导, 在 4、6、8 阶得不到任何正确数字, 但在 2 阶却恢复了 5 位正确数字. 这些是危险水域; 请利用误差估计谨慎前行.

对 k 阶有限差分方法, 误差为 C εk/k+1. 在 k → ∞ 的极限下, 误差趋于 ε, 恢复该类型的全部精度. 然而, 这忽略了高阶方法需要相减更多近乎相等 (可能有噪声) 的项, 因此常数 C 随 k 增长. 由于 C 增长很快而 εk/k+1 缓慢逼近 ε, 可见高阶精度与差商的性态之间存在折中. 实践中我们发现 k=6 似乎是二者之间较好的折中 (并已将其设为默认), 但我们鼓励用户检查误差估计, 为给定问题选择最优的精度阶.

鉴于成功使用有限差分微分必须牢记的种种告诫, 若有可能应尽量避免使用. Boost 提供两种替代: Chebyshev 变换 (见 here) 和复步导数. 如果你的函数是一个全纯函数在实轴上的限制, 且在实自变量处取实值, 那么可以使用复步导数. 思路非常简单: 由于 f 复可微, f(x+ⅈ h) = f(x) + ⅈ hf'(x) - h2f''(x) + 𝑶(h3). 只要 f(x) ∈ ℝ, 便有 f'(x) = ℑ f(x+ⅈ h)/h + 𝑶(h2). 此方法只需一次复函数求值, 且不会遭受困扰有限差分计算的灾难性相减消去.

示例用法:

double x = 7.2;
double e_prime = complex_step_derivative(std::exp<std::complex<double>>, x);
