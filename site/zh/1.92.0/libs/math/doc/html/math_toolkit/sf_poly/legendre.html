Legendre 多项式的零点用 Newton 法计算, 初始猜测由 Tricomi 给出, 根区间界定由 Szego 提供.

由于 Legendre 多项式交替为偶函数和奇函数, 因此只返回非负的零点. 对奇 Legendre 多项式, 第一个零点总是零. 其余零点按递增顺序返回.

注意, 该例程的参数是整数, 而输出是浮点类型, 因此模板参数是必需的. 提取单个根的时间关于 l 是线性的 (这与求值 Legendre 多项式的标度相同), 因此恢复全部根的复杂度为 𝑶(l2). 存在具有线性标度的算法来恢复全部根, 但它们需要一些当前 boost.math 尚未内置的工具. 本实现基于如下假设: 计算这些函数的零点不会成为任何工作流的瓶颈.

注意

这里使用的关联 Legendre 多项式定义包含 (-1)m 的前置 Condon-Shortley 相位因子. 这与 Abramowitz 和 Stegun (8.6.6) 给出的定义一致, 也与 Mathworld 以及 Mathematica 的 LegendreP 函数 所采用的定义一致. 然而, 文献中的用法并不总是包含这个相位因子; 奇怪的是, C++ TR1 中关联 Legendre 函数的规范 (assoc_legendre) 也省略了它, 尽管该规范声明以 Abramowitz 和 Stegun 作为这些问题的最终裁判.

下图展示了前几个第二类 Legendre 函数:

template <class T1, class T2, class T3>
calculated-result-type legendre_next(unsigned l, T1 x, T2 Pl, T3 Plm1);

实现 Legendre 多项式的三项递推关系, 该函数可用于生成在同一 x 处求值、l 递增的一系列值. 此递推关系对第一类和第二类 Legendre 多项式均成立.

例如, 可以用以下代码生成前 10 个多项式值组成的向量:

double x = 0.5;  // Abscissa value
vector<double> v;
v.push_back(legendre_p(0, x));
v.push_back(legendre_p(1, x));
for(unsigned l = 1; l < 10; ++l)
   v.push_back(legendre_next(l, x, v[l], v[l-1]));
// Double check values:
for(unsigned l = 1; l < 10; ++l)
   assert(v[l] == legendre_p(l, x));

正式的参数说明如下:

l

最后计算的多项式的次数.

x

横坐标值

Pl

在次数 l 处求值的多项式值.

Plm1

在次数 l-1 处求值的多项式值.

template <class T1, class T2, class T3>
calculated-result-type legendre_next(unsigned l, unsigned m, T1 x, T2 Pl, T3 Plm1);

实现关联 Legendre 多项式的三项递推关系, 该函数可用于生成在同一 x 处求值、l 递增的一系列值.

例如, 可以用以下代码生成前 m+10 个多项式值组成的向量:

double x = 0.5;  // Abscissa value
int m = 10;      // order
vector<double> v;
v.push_back(legendre_p(m, m, x));
v.push_back(legendre_p(1 + m, m, x));
for(unsigned l = 1; l < 10; ++l)
   v.push_back(legendre_next(l + 10, m, x, v[l], v[l-1]));
// Double check values:
for(unsigned l = 1; l < 10; ++l)
   assert(v[l] == legendre_p(10 + l, m, x));

正式的参数说明如下:

l

最后计算的多项式的次数.

m

关联多项式的阶数.

x

横坐标值

Pl

在次数 l 处求值的多项式值.

Plm1

在次数 l-1 处求值的多项式值.

注意, 最坏的误差出现在阶数增大时, 大于 ~120 的阶数值极不可能产生有意义的结果, 尤其是在关联多项式且次数也很大的情况下. 此外, 当函数值非常接近某个根时, 相对误差可能任意增大.

测试

测试混合使用了利用 functions.wolfram.com 计算的值的抽查与随机生成的测试数据: 测试数据使用 NTL::RR 以 1000 位精度计算.

实现

这些函数使用稳定的三项递推关系实现. 这些递推关系保证较低的绝对误差, 但无法保证在多项式某个根附近具有较低的相对误差.
