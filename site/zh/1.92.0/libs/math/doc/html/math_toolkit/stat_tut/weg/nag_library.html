与 C、R、FORTRAN 风格自由函数的比较

你可能熟悉带有自由函数的统计库, 例如经典的 NAG C library 和对应的 NAG FORTRAN Library、Microsoft Excel BINOMDIST(number_s,trials,probability_s,cumulative)、R、MathCAD pbinom 等.

如果是这样, 你可能会觉得 "分布即对象" 陌生, 甚至怪异.

不过, 不要惊慌, 其定义和用法其实没有太大不同.

下面是一个非常简单的示例, 生成与 NAG C library 对二项分布相同的值. (如果你发现值略有不同, 使用 double 或更好类型的 Boost C++ 版本很可能更精确. 当然, 对该函数的大多数应用来说, 精度通常不是问题).

NAG 函数规范为

void nag_binomial_dist(Integer n, double p, Integer k,
double *plek, double *pgtk, double *peqk, NagError *fail)

调用方式为

g01bjc(n, p, k, &plek, &pgtk, &peqk, NAGERR_DEFAULT);

使用这个 Boost C++ 库的等价写法是:

using namespace boost::math;  // Using declaration avoids very long names.
binomial my_dist(4, 0.5); // c.f. NAG n = 4, p = 0.5

值可以这样输出:

cout
  << my_dist.trials() << " "             // Echo the NAG input n = 4 trials.
  << my_dist.success_fraction() << " "   // Echo the NAG input p = 0.5
  << cdf(my_dist, 2) << "  "             // NAG plek with k = 2
  << cdf(complement(my_dist, 2)) << "  " // NAG pgtk with k = 2
  << pdf(my_dist, 2) << endl;            // NAG peqk with k = 2

cdf(dist, k) 等价于 NAG 库的 plek, 即 <= k 的下尾概率

cdf(complement(dist, k)) 等价于 NAG 库的 pgtk, 即 > k 的上尾概率

pdf(dist, k) 等价于 NAG 库的 peqk, 即 == k 的点概率

详情参见 binomial_example_nag.cpp.
