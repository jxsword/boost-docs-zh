F 分布示例

设想你想比较两个样本的标准差, 以确定它们是否有显著差异; 在这种情况下, 你使用 F 分布并进行 F 检验. 这种情况常出现在工艺变更比较中: "新工艺是否比旧工艺更一致?"

本例中我们将使用来自 http://www.itl.nist.gov/div898/handbook/eda/section4/eda42a1.htm 的陶瓷强度数据. 本案例研究的数据由 NIST 陶瓷部门的 Said Jahanmir 于 1996 年在 NIST/工业陶瓷联合体进行陶瓷强度优化的工作中收集.

示例程序是 f_test.cpp, 程序输出经过刻意设计, 尽可能接近相应 NIST EngineeringStatistics Handbook example 中的 DATAPLOT 输出.

我们先定义执行该检验的过程:

void f_test(
    double sd1,     // Sample 1 std deviation
    double sd2,     // Sample 2 std deviation
    double N1,      // Sample 1 size
    double N2,      // Sample 2 size
    double alpha)  // Significance level
{

该过程首先打印输入数据的摘要:

using namespace std;
using namespace boost::math;

// Print header:
cout <<
   "____________________________________\n"
   "F test for equal standard deviations\n"
   "____________________________________\n\n";
cout << setprecision(5);
cout << "Sample 1:\n";
cout << setw(55) << left << "Number of Observations" << "=  " << N1 << "\n";
cout << setw(55) << left << "Sample Standard Deviation" << "=  " << sd1 << "\n\n";
cout << "Sample 2:\n";
cout << setw(55) << left << "Number of Observations" << "=  " << N2 << "\n";
cout << setw(55) << left << "Sample Standard Deviation" << "=  " << sd2 << "\n\n";

F 检验的检验统计量就是两个标准差平方之比:

F = s12 / s22

其中 s1 是第一个样本的标准差, s2 是第二个样本的标准差. 用代码表示:

double F = (sd1 / sd2);
F *= F;
cout << setw(55) << left << "Test Statistic" << "=  " << F << "\n\n";

此时需要提醒一句: F 分布是非对称的, 因此我们必须小心如何计算检验. 下表汇总了可用的选项:

假设

检验

零假设: 标准差没有差异 (双侧检验)

Reject if F <= F(1-alpha/2; N1-1, N2-1) or F >= F(alpha/2; N1-1, N2-1)

备择假设: 均值存在差异 (双侧检验)

Reject if F(1-alpha/2; N1-1, N2-1) <= F <= F(alpha/2; N1-1, N2-1)

备择假设: 样本 1 的标准差大于样本 2 的标准差

Reject if F < F(alpha; N1-1, N2-1)

备择假设: 样本 1 的标准差小于样本 2 的标准差

Reject if F > F(1-alpha; N1-1, N2-1)

其中 F(1-alpha; N1-1, N2-1) 是自由度为 N1-1 和 N2-1 的 F 分布的下临界值, 而 F(alpha; N1-1, N2-1) 是自由度为 N1-1 和 N2-1 的 F 分布的上临界值.

上临界值和下临界值可以用分位数函数计算:

F(1-alpha; N1-1, N2-1) = quantile(fisher_f(N1-1, N2-1), alpha)

F(alpha; N1-1, N2-1) = quantile(complement(fisher_f(N1-1, N2-1), alpha))

在示例程序中, 我们需要 alpha 和 alpha/2 的上临界值和下临界值:

double ucv = quantile(complement(dist, alpha));
double ucv2 = quantile(complement(dist, alpha / 2));
double lcv = quantile(dist, alpha);
double lcv2 = quantile(dist, alpha / 2);
cout << setw(55) << left << "Upper Critical Value at alpha: " << "=  "
   << setprecision(3) << scientific << ucv << "\n";
cout << setw(55) << left << "Upper Critical Value at alpha/2: " << "=  "
   << setprecision(3) << scientific << ucv2 << "\n";
cout << setw(55) << left << "Lower Critical Value at alpha: " << "=  "
   << setprecision(3) << scientific << lcv << "\n";
cout << setw(55) << left << "Lower Critical Value at alpha/2: " << "=  "
   << setprecision(3) << scientific << lcv2 << "\n\n";

最后一步是执行上面给出的比较, 并打印假设是否被拒绝:

cout << setw(55) << left <<
   "Results for Alternative Hypothesis and alpha" << "=  "
   << setprecision(4) << fixed << alpha << "\n\n";
cout << "Alternative Hypothesis                                    Conclusion\n";

cout << "Standard deviations are unequal (two sided test)          ";
if((ucv2 < F) || (lcv2 > F))
   cout << "ACCEPTED\n";
else
   cout << "REJECTED\n";

cout << "Standard deviation 1 is less than standard deviation 2    ";
if(lcv > F)
   cout << "ACCEPTED\n";
else
   cout << "REJECTED\n";

cout << "Standard deviation 1 is greater than standard deviation 2 ";
if(ucv < F)
   cout << "ACCEPTED\n";
else
   cout << "REJECTED\n";
cout << endl << endl;

在本例中我们无法拒绝零假设, 而必须拒绝备择假设.

相比之下, 让我们看看使用一些不同的 样本数据 时会发生什么, 数据再次来自 NIST Engineering Statistics Handbook: 引入了一种新的设备组装程序并测试其是否能缩短组装时间. 所要解决的问题是新组装过程 (样本 2) 的标准差是否优于 (即小于) 旧组装过程 (样本 1) 的标准差.

Number of Observations                                 =  11.00000
Sample Standard Deviation                              =  4.90820

Sample 2:
Number of Observations                                 =  9.00000

Upper Critical Value at alpha:                         =  3.347e+000

Alternative Hypothesis                                    Conclusion
Standard deviations are unequal (two sided test)          REJECTED

Standard deviation 1 is greater than standard deviation 2 ACCEPTED

在本例中我们把零假设取为 "标准差 1 小于或等于标准差 2", 因为这代表 "无变化" 的情形. 因此我们要把 alpha 处的上临界值 (单侧检验) 与检验统计量比较, 由于 3.35 < 3.6, 这个假设必须被拒绝. 因此我们得出结论: 我们的标准差出现了向好的变化.
