游程测试

概要 

#include <boost/math/statistics/runs_test.hpp>

namespace boost::math::statistics {

template<typename RandomAccessContainer>
std::pair<Real, Real> runs_above_and_below_threshold(RandomAccessContainer const & v, typename RandomAccessContainer::value_type threshold);

template<typename RandomAccessContainer>
std::pair<Real, Real> runs_above_and_below_median(RandomAccessContainer const & v);

}}}

背景

"中位数上下游程测试"试图通过观察超过 (或低于) 序列中位数的连续值的个数来判断序列是否随机. 例如, 给定数据 {5, 2, 0, 4, 7, 9, 10, 6, 1, 8, 3}, 首先求出中位数 (5), 然后根据每个值是大于还是小于中位数, 把向量变换成一个由 + 和 - 组成的列表. (等于中位数的值我们直接忽略, 这是从 R 中出色的 randtests 包继承而来的约定.) 于是我们的数据向量被变换为

{-,-,-,+,+,+,-,+,-}

即 5 个游程, 其中 na = 5 个值高于中位数, nb = 5 个值低于中位数. NIST 给出了游程的期望个数及其方差:

由此我们导出检验统计量

我们将其分布近似为正态分布, 以提取 p 值.

用法示例如下:

#include <vector>
#include <random>
#include <boost/math/statistics/runs_test.hpp>

std::random_device rd;
std::vector<double> v{5, 2, 0, 4, 7, 9, 10, 6, 1, 8, 3};
auto [t, p] = boost::math::statistics::runs_above_and_below_median(v);
// t =  -0.670820393249936919; p = 0.502334954360502017;

我们看到, 如果随机性的零假设为真, 那么观察到这一游程个数的概率约为 50%, 因此随机性的假设看起来是合理的. 与往常一样, 检验统计量是 pair 的第一个元素, p 值是第二个元素.

性能

这里有两种情形: 一种是阈值 (通常是中位数) 已经计算好的情形, 另一种是必须即时计算均值和样本方差的情形. 计算中位数相当昂贵 (需要调用 boost::math::statistics::median), 而且由于必须保留原始数据的顺序, 它必须进行内存分配. 如果你认为你的数据来自均值与中位数重合的分布, 或者你已经在其他分析过程中计算过中位数, 那么你可以按下述方式只调用 runs_above_and_below_threshold:

Real threshold = 5;
auto [t, p] = boost::math::statistics::runs_above_and_below_threshold(v, threshold);
