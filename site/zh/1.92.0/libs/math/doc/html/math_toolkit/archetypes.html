实数与分布的概念原型

可用的概念原型有以下几个:

  • 浮点类型的实数概念.
  • 统计分布的分布概念.
实数概念

std_real_concept 是实数(Real)类型(包括内建的 float、double、long double)的原型.

#include <boost/concepts/std_real_concept.hpp>
namespace boost{
namespace math{
namespace concepts
{
  class std_real_concept;
}
}} // namespaces

提供该类型的主要目的是验证标准库函数是通过 using 声明找到的——即把这些函数引入当前作用域——而不仅仅是因为它们恰好位于全局作用域.

为确保对例如 pow 的调用既能通过实参依赖查找找到,失败时又能在 std 命名空间中找到:对标准库函数的所有调用都不加限定,并通过 using 声明找到 std:: 版本,使其在当前作用域可见. 遗憾的是,人们很容易忘记 using 声明,从而错误地调用恰好位于全局作用域的 double 版本函数.

例如,如果代码调用 ::pow 而不是 std::pow,代码可以顺利编译,但 long double 向 double 的截断会造成显著的精度损失. 相比之下,以 std_real_concept 实例化的模板只有在所用的全部标准库函数都已通过 using 声明引入当前作用域时才能编译.

测试实数概念

有一个测试程序 libs/math/test/std_real_concept_check.cpp,它用类型 std_real_concept 实例化本库中的每个模板,以验证其对标准库函数的用法.

#include <boost/math/concepts/real_concept.hpp>
namespace boost{
namespace math{
namespace concepts{

class real_concept;

}}} // namespaces

real_concept 是用户定义实数类型的原型,它在自己的命名空间中声明其标准库函数:只有不带限定地调用这些函数、允许实参依赖查找定位它们时,才会被找到. 此外,该类型可在运行期使用:这使内建浮点类型无法覆盖的代码路径也能得到测试. 该类型没有 std::numeric_limits<> 支持,因为 numeric_limits 并不是 RealType 的概念要求.

NTL RR 是满足该类型所建模需求的一个类型示例,但注意需要使用一个薄封装类:参见 "Using With NTL - a High-Precision Floating-Point Library".

类型 real_concept 没有专门的测试用例;由于该类型可在运行期使用,每个单独的测试用例在测试 float、double 和 long double 的同时,也测试 real_concept.

分布概念

分布概念(Distribution Concept)对统计分布建模.

#include <boost/math/concepts/distribution.hpp>
namespace boost{
namespace math{
namespace concepts
{
  template <class RealType>
  class distribution_archetype;

  template <class Distribution>
  struct DistributionConcept;

}}} // namespaces

类模板 distribution_archetype 是 Distribution concept 的一个模型.

类模板 DistributionConcept 是分布类型的概念检查类.

测试分布概念

测试程序 distribution_concept_check.cpp 负责使用 DistributionConcept 验证本库中所有分布都符合 Distribution concept.

类模板 DistributionConcept 验证 Distribution concept 所要求的非成员访问器的存在性(而非正确功能). 这些访问器通过如下调用进行检查:

v = pdf(dist, x); // (Result v is ignored).

此外,接受两个参数的那些访问器在参数类型不同时也能正确工作(结果类型始终与分布的 value_type 相同). (这通过 derived_accessors.hpp 中一些额外的转发函数实现,因此无需修改任何代码. 同样,hazard/chf/coefficient_of_variation 函数的样板版本也在那里实现. )
