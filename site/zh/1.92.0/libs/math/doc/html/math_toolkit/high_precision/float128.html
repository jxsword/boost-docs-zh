与 GCC 的 __float128 数据类型一起使用

目前对 GCC 原生 __float128 数据类型的支持极为有限: 数值常数都可以与该类型配合使用, 仅此而已. 若想使用分布或特殊函数, 你需要提供自己的包装头文件, 它应当:

  • 提供 std::numeric_limits<__float128> 支持.
  • 为类型 __float128 提供标准库数学函数的重载, 并转发到 libquadmath 中的对应函数.

归根结底, 这些设施应当由 GCC 与 libstdc++ 提供.
