说明

共有四个 incomplete gamma functions: 其中两个是归一化版本 (也称为 regularized 不完全 gamma 函数), 返回 [0, 1] 范围内的值; 另外两个未归一化, 返回 [0, Γ(a)] 范围内的值. 对统计应用感兴趣的用户应当使用 归一化版本 (gamma_p 和 gamma_q).

所有这些函数都要求 a > 0 且 z >= 0, 否则它们将返回 domain_error 的结果.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

当 T1 和 T2 是不同类型时, 这些函数的返回类型使用 结果类型计算规则 计算; 否则返回类型就是 T1.

测试

测试分为两组: 抽点测试把取自 Mathworld's online evaluator 的值与本实现进行比较, 以进行基本的"健全性检查". 精度测试使用以极高精度生成的数据 (使用 NTL 的 RR 类并设为 1000 位精度), 所用实现带有非常高精度的 60 项 Lanczos approximation, 并禁用了部分 (而非全部) 特殊情形处理. 这并不十分令人满意: 理应使用独立的方法, 但显然完全没有这类方法可用. 我们甚至无法使用不带特殊情形处理的刻意朴素实现, 因为 Legendre 连分数 (见下文) 对于小的 a 和 z 是不稳定的.

以及:

后一个范围对所有最高到 128 位 long double 的类型都有效, 其设计意图是确保结果大于 10-6; 第一个范围只用于最高到 80 位 long double 的类型. 这些定义域比 Temme 或 Didonato 与 Morris 建议的更窄. 然而, 使用更宽的范围会导致较大且不精确 (即计算出的) 的值被传给 exp 和 erfc 函数, 从而使误差率显著增大. 换言之, 在效率与误差之间存在微妙的权衡. 当前的界限应能把 (4) 和 (5) 所需的项数在 double 精度下保持在约 20 项以内.
