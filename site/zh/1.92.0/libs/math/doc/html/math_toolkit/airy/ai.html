Airy Ai 函数

概要 
#include <boost/math/special_functions/airy.hpp>

namespace boost { namespace math {

 template <class T>
 BOOST_MATH_GPU_ENABLED calculated-result-type airy_ai(T x);

 template <class T, class Policy>
 BOOST_MATH_GPU_ENABLED calculated-result-type airy_ai(T x, const Policy&);

}} // namespaces
说明

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

精度

该函数完全通过 Bessel 函数 cyl_bessel_j 与 cyl_bessel_k 实现——详细的精度信息请参阅这两个函数.
