其他提示与技巧

  • 问题历史记录在 Boost Trac, 现已只读.
  • 始终确保你使用的是当前发布版本.
  • 发布版本的当前文档在 here.
  • 正在开发版本的当前文档在 here.
  • 参见 develop 分支, 变更在那里汇集并测试, 为下一次发布做准备.
    你可以自担风险从那里下载新版本.
  • 如果你有新的功能请求, 请提交新的 Boost.Math issue,
  • 如果看起来是实现有误, 请先在 Boost.Math issues 搜索. 条目可能表明解决你问题的更新或修正已在 Boost.Math on Github 中.
  • 如果你有建议的增强或修复, 非常欢迎提交 pull requests.
  • 如果你不理解事物为何如此运作, 请先看 设计理由部分.
  • 如果你对自己的想法/功能/抱怨得不到满意的答案, 请通过 Boost 用户或开发邮件列表 https://www.boost.org/community/groups.html 尽量联系作者, 或提交新的 Boost.Math issue, 或直接给作者发邮件.
