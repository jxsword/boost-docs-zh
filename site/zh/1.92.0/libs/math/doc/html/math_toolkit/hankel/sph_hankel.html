说明

函数 sph_hankel_1 与 sph_hankel_2 分别返回第一类与第二类 球面 Hankel 函数 的结果:

当 T1 和 T2 为不同类型时, 这些函数的返回类型按照 结果类型计算规则 计算. 对于 T1 为整数这一较常见情形, 这些函数也做了优化.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

注意, 虽然这些函数的参数是实数值, 结果却是复数. 这意味着函数只能在类型 float、double 与 long double 上实例化. 这些函数也被扩展到可在 v 与 x 的全范围上运算 (不同于 cyl_bessel_j 与 cyl_neumann).

测试

只有少量抽检测试用于检验各种特例处理 — 主要测试在它们所基于的 Bessel 函数上完成.

精度

参见 cyl_bessel_j 与 cyl_neumann.

实现

这些函数平凡地借助 cyl_hankel_1 与 cyl_hankel_2 实现.
