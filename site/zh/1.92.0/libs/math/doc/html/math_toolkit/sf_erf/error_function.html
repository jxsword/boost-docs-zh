误差函数 erf 及其补函数 erfc

概要 
#include <boost/math/special_functions/erf.hpp>

namespace boost{ namespace math{

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type erf(T z);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type erf(T z, const Policy&);

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type erfc(T z);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type erfc(T z, const Policy&);

}} // namespaces

这些函数的返回类型使用 结果类型计算规则 计算: 若 T 是整数类型, 返回类型为 double, 否则为 T.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

测试

这些函数的测试分为两部分: 基本健全性检查使用 Mathworld 在线求值器 计算的抽检值, 而精度检查使用 1000 位精度的 NTL::RR 与本实现计算的高精度测试值. 注意这些函数的通用版本与类型特定版本在内部使用不同的实现, 因此这为我们提供了合理独立的测试数据. 用我们的测试数据测试其他"已知正确"的实现也提供了额外的健全性检查.

实现

这些函数的所有版本首先使用常见的反射公式把参数变为正数:

erf(-z) = 1 - erf(z);

erfc(-z) = 2 - erfc(z); // -z < -0.5 时首选

erfc(-z) = 1 + erf(z); // -0.5 <= -z < 0 时首选

这些函数的通用版本以不完全 gamma 函数为基础实现.

当有效数字 (尾数) 位数可被识别时 (当前支持 53、64 和 113 位实数, 以及通过提升为 double 来处理的 24 位单精度), 将使用 由 JM 设计 的一系列有理近似.

对于 z <= 0.5, 使用 erf 的一个有理近似, 其依据是 erf 是奇函数, 因此 erf 按下式计算:

erf(z) = z * (C + R(z*z));

其中有理近似 R(z*z) 针对绝对误差做了优化: 只要其绝对误差与常量 C 相比足够小, 那么计算 R(z*z) 时产生的任何舍入误差实际上都会从结果中消失. 因此该区域内 erf 和 erfc 的误差非常低: 仅在极少数情况下最后一位是不正确的.

对于 z > 0.5, 我们观察到, 在小区间 [a, b) 上:

erfc(z) * exp(z*z) * z ~ c

其中 c 为某个常量.

因此, 对于 z > 0.5, 我们使用下式计算 erfc:

erfc(z) = exp(-z*z) * (C + R(z - B)) / z;

同样, R(z - B) 针对绝对误差做了优化, 而常量 C 是在区间端点处取得的 erfc(z) * exp(z*z) * z 的平均值. 再者, 只要 R(z - B) 的绝对误差与 c 相比足够小, 那么 c + R(z - B) 就会被正确舍入, 结果的误差将只取决于 exp 函数的精度. 实际上, 除极少数情况外, 误差都被限制在结果的最后一位. 常量 B 的选取使得有理近似的区间左端点为 0.

对于范围 [a, +∞] 上较大的 z, 上面的近似被修改为:

erfc(z) = exp(-z*z) * (C + R(1 / z)) / z;
