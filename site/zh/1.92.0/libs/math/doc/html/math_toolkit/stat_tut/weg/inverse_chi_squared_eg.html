逆 Chi-Squared 分布 Bayes 示例

缩放逆 Chi-Squared 分布是具有已知期望 (μ) 的正态分布的方差 (σ2) 参数的共轭先验分布. 因此它在贝叶斯统计中有广泛应用:

在 贝叶斯推断 中, 对特定参数取值的信念强度本身通过一个分布来描述. 因此参数本身也被建模并解释为随机变量.

在这个完整示例中, 我们执行这样的贝叶斯分析: 使用缩放逆 Chi-Squared 分布作为正态分布方差参数的先验分布和后验分布.

有关贝叶斯类型分析的更一般信息, 参见:

  • Andrew Gelman, John B. Carlin, Hal E. Stern, Donald B. Rubin, Bayesian Data Analysis, 2003, ISBN 978-1439840955.
  • Jim Albert, Bayesian Computation with R, Springer, 2009, ISBN 978-0387922973.

(由于缩放逆 Chi-Squared 分布是逆 gamma 分布的另一种参数化, 本示例也可以使用逆 gamma 分布).

考虑为高质量滚珠轴承生产滚珠的精密机器. 理想情况下, 每个滚珠的直径都应精确为 3000 μm (3 mm). 假设机器平均而言生产该尺寸的滚珠 (均值), 但单个滚珠会按 (近似) 正态分布在两个方向上略有变化. 取决于各种生产条件 (例如所用原材料、车间温度和湿度、维护频率和质量), 一些机器生产的滚珠围绕 3000 μm 目标分布得更紧凑, 而另一些机器生产的滚珠分布更宽. 因此滚珠尺寸正态分布的方差参数因机器而异. 不过, 精密机械制造商的广泛调查表明, 大多数机器在 15 到 50 之间的方差下运行, 平均接近 25 μm2.

利用这些信息, 我们想对机器的方差建模. 方差严格为正, 因此我们寻找支撑在正实数域上的统计分布. 鉴于滚珠正态分布的期望已知 (3000 μm), 出于共轭性的原因, 贝叶斯统计中的惯常做法是把方差建模为缩放逆 Chi-Squared 分布.

第一步, 我们将尝试利用调查信息来建模制造商测得的机器方差参数的一般知识. 这将为我们提供一个通用先验分布, 当对特定机器没有更多具体了解时适用.

第二步, 我们将在贝叶斯分析中把先验分布信息与某台特定机器的数据相结合, 以推导该机器的后验分布.

第一步: 使用调查信息.

利用调查结果, 我们尝试求缩放逆 Chi-Squared 分布的参数集, 使该分布的性质与结果吻合. 以缩放逆 Chi-Squared 分布的数学性质为指导, 我们看到该分布的均值和众数都近似由分布的尺度参数 (s) 给出. 由于调查中的机器平均在 25 μm2 的方差下运行, 因此我们把先验分布的尺度参数 (sprior) 设为该值. 通过一些试错以及对全局分位数函数的调用, 我们还发现自由度 (νprior) 参数取 20 足以使先验分布的大部分质量位于 15 和 50 之间 (见下图).

我们先用这些值构造先验分布, 然后列出几个分位数:

double priorDF = 20.0;
double priorScale = 25.0;

inverse_chi_squared prior(priorDF, priorScale);
// Using an inverse_gamma distribution instead, we could equivalently write
// inverse_gamma prior(priorDF / 2.0, priorScale * priorDF / 2.0);

cout << "Prior distribution:" << endl << endl;
cout << "  2.5% quantile: " << quantile(prior, 0.025) << endl;
cout << "  50% quantile: " << quantile(prior, 0.5) << endl;
cout << "  97.5% quantile: " << quantile(prior, 0.975) << endl << endl;

这产生如下输出:

Prior distribution:

2.5% quantile: 14.6
50% quantile: 25.9
97.5% quantile: 52.1

基于该分布, 我们现在可以计算机器以异常加工精度 (方差) <= 15 或 > 50 工作的概率. 为此, 我们分别调用 boost::math:: 函数的 cdf 和 complement, 发现每种情况的概率都约为 0.031 (3.1%).

cout << "  probability variance <= 15: " << boost::math::cdf(prior, 15.0) << endl;
cout << "  probability variance <= 25: " << boost::math::cdf(prior, 25.0) << endl;
cout << "  probability variance > 50: "
  << boost::math::cdf(boost::math::complement(prior, 50.0))
<< endl << endl;

这产生如下输出:

probability variance <= 15: 0.031
probability variance <= 25: 0.458
probability variance > 50: 0.0318

因此, 所有精密机器中只有 3.1% 生产方差为 15 或更小的滚珠 (特别精密的机器), 但同样只有 3.2% 的机器生产方差高达 50 或更大的滚珠 (特别不精密的机器). 此外, 略多于一半 (1 - 0.458 = 54.2%) 的机器在大于 25 的方差下工作.

注意这里 贝叶斯分析与 频率学派分析的区别: 因为我们把方差本身建模为随机变量, 我们可以直接计算并直截了当地解释给定参数取值的概率; 而在频率学派世界中, 这种做法是不可能的 (并且在解释上是严格的 禁区).

第 2 步: 考察一台机器

在第二步中, 我们考察一台机器, 该机器生产的滚珠尺寸变异性相当高, 因而被怀疑存在重大故障. 基于通用机械性能的先验分布 (上文推导) 和疑似机器生产的滚珠数据, 我们计算该机器的后验分布, 并利用其性质来判断机器是继续运行还是停机检修.

可以证明, 如果先验分布选为缩放逆 Chi-Squared 分布, 那么后验分布也服从缩放逆 Chi-Squared 分布 (因此先验分布和后验分布是共轭的). 有关共轭性以及推导后验分布参数集的公式的更多细节, 参见 Conjugate prior.

给定先验分布参数和样本数据 (大小为 n), 后验分布参数由下面两个表达式给出:

   νposterior = νprior + n

这给出下文的 posteriorDF, 而

   sposterior = (νpriorsprior + Σni=1(xi - μ)2) / (νprior + n)

经过一些整理后给出下文 posteriorScale 的公式.

机器特定数据由精确测量的 100 个滚珠组成, 显示期望均值 3000 μm 和样本方差 55 (按定义为精确 3000 的样本均值计算). 根据这些数据、先验参数化, 并注意到 Σni=1(xi - μ)2 项等于样本方差乘以 n - 1, 可得方差参数的后验分布是自由度 (νposterior) = 120、尺度 (sposterior) = 49.54 的缩放逆 Chi-Squared 分布.

int ballsSampleSize = 100;
cout <<"balls sample size: " << ballsSampleSize << endl;
double ballsSampleVariance = 55.0;
cout <<"balls sample variance: " << ballsSampleVariance << endl;

double posteriorDF = priorDF + ballsSampleSize;
cout << "prior degrees-of-freedom: " << priorDF << endl;
cout << "posterior degrees-of-freedom: " << posteriorDF << endl;

double posteriorScale =
  (priorDF * priorScale + (ballsSampleVariance * (ballsSampleSize - 1))) / posteriorDF;
cout << "prior scale: " << priorScale  << endl;
cout << "posterior scale: " << posteriorScale << endl;

这里的一个有趣特点是, 只需知道样本的汇总统计量即可参数化后验分布: 100 个单独的滚珠测量值无关紧要, 只要知道样本方差和测量次数就足够了.

这产生如下输出:

balls sample size: 100
balls sample variance: 55
prior degrees-of-freedom: 20
posterior degrees-of-freedom: 120
prior scale: 25
posterior scale: 49.5

为了把通用机械性能与我们的疑似机器比较, 我们再次计算与上文相同的分位数和概率, 发现分布明显向更大的值偏移 (见图).

inverse_chi_squared posterior(posteriorDF, posteriorScale);

 cout << "Posterior distribution:" << endl << endl;
 cout << "  2.5% quantile: " << boost::math::quantile(posterior, 0.025) << endl;
 cout << "  50% quantile: " << boost::math::quantile(posterior, 0.5) << endl;
 cout << "  97.5% quantile: " << boost::math::quantile(posterior, 0.975) << endl << endl;

 cout << "  probability variance <= 15: " << boost::math::cdf(posterior, 15.0) << endl;
 cout << "  probability variance <= 25: " << boost::math::cdf(posterior, 25.0) << endl;
 cout << "  probability variance > 50: "
   << boost::math::cdf(boost::math::complement(posterior, 50.0)) << endl;

这产生如下输出:

Posterior distribution:

   2.5% quantile: 39.1
   50% quantile: 49.8
   97.5% quantile: 64.9

   probability variance <= 15: 2.97e-031
   probability variance <= 25: 8.85e-010
   probability variance > 50: 0.489

事实上, 机器在低方差 (<= 15) 下工作的概率几乎为零, 甚至以平均或更好性能工作的概率也小到可以忽略 (小于千分之一的百万分之一). 另一方面, 该机器以接近一半的概率 (49%) 在 > 50 的极端高方差范围内运行, 这是性能差的机器的特征.

基于这一信息, 该机器被停止使用并进行检修.

总之, 贝叶斯分析使我们能够对所关心的参数作出精确的概率性论断, 从而为我们提供了可直截了当解释的结果.
