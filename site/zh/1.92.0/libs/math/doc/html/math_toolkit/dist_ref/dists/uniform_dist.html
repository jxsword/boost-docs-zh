均匀分布 

#include <boost/math/distributions/uniform.hpp>
namespace boost{ namespace math{
 template <class RealType = double,
           class Policy   = policies::policy<> >
 class uniform_distribution;

 typedef uniform_distribution<> uniform;

 template <class RealType, class Policy>
 class uniform_distribution
 {
 public:
    typedef RealType value_type;

    BOOST_MATH_GPU_ENABLED uniform_distribution(RealType lower = 0, RealType upper = 1); // Constructor.
       : m_lower(lower), m_upper(upper) // Default is standard uniform distribution.
    // Accessor functions.
    BOOST_MATH_GPU_ENABLED RealType lower()const;
    BOOST_MATH_GPU_ENABLED RealType upper()const;
 }; // class uniform_distribution

}} // namespaces

均匀分布, 也称矩形分布, 是一种概率恒定的概率分布.

连续均匀分布是一种具有如下 概率密度函数的分布:

f(x) =1 / (upper - lower)   for lower < x < upper

f(x) =zero   for x < lower or x > upper

在本实现中:

1 / (upper - lower)   for x = lower or x = upper

选择 x = lower 或 x = upper 是因为从统计学使用来看这样判断最可能: 极大似然法就采用此定义.

还有 离散 均匀分布.

参数 lower 与 upper 可以是任意有限值.

随机变量 x 也必须是有限值, 其支持范围为 lower <= x <= upper.

下限参数也称为 位置参数 (即图形原点所在之处), 而 (upper - lower) 也称为 尺度参数.

成员函数 
BOOST_MATH_GPU_ENABLED uniform_distribution(RealType lower = 0, RealType upper = 1);

构造一个 均匀分布, 下限为 lower (a), 上限为 upper (b).

要求 lower 与 upper 参数均为有限值; 否则若为无穷大或 NaN 则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType lower()const;

返回此分布的 lower 参数.

BOOST_MATH_GPU_ENABLED RealType upper()const;

返回此分布的 upper 参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为任意有限值, 但支持范围仅为 lower <= x <= upper.

精度

均匀分布用简单的算术运算符实现, 因此误差应在一两个 epsilon 之内.

在下表中, a 是分布的 lower 参数, b 是 upper 参数, x 是随机变量, p 是概率, q = 1-p 是其补.

函数

实现说明

pdf

使用关系式: 当 x < a 时 pdf = 0, 当 a <= x <= b 时为 1 / (b - a), 当 x > b 时为 0

cdf

使用关系式: 当 x < a 时 cdf = 0, 当 a <= x <= b 时为 (x - a) / (b - a), 当 x > b 时为 1

cdf 补函数

使用关系式: q = 1 - p, (b - x) / (b - a)

quantile

使用关系式: x = p * (b - a) + a;

由补函数求 quantile

x = -q * (b - a) + b

均值

(a + b) / 2

方差

(b - a) 2 / 12

众数

[a, b] 中的任意值, 但选择 a. (NaN 会更好吗?)

偏度

0

超额峰度

-6/5 = -1.2 精确值. (峰度 - 3)

峰度
