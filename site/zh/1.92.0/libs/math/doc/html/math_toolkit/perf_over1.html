性能

总体而言, 本库的性能应能满足大多数需求. 不过, 本库经常需要在精确与快速之间做出选择, 默认情况下它选择精确而非快速. 如果你更想要快速而非完全精确的例程, 请参见 performance section 了解如何实现这一点的信息和示例.

就所用算法而言, 本库力求使用与其他许多库相同的"同类最佳"算法: 主要区别在于本库以 C++ 实现 - 充分利用 C++ 提供的所有抽象机制 - 而大多数传统数值库以 C 或 FORTRAN 实现. 传统上, C 或 FORTRAN 这类语言被认为比 C++ 这类更复杂的语言更容易优化, 所以从某种意义上说, 本库很好地检验了当前的编译器技术, 以及 C++ 相对于其他语言的"抽象惩罚" (如果存在的话).

要确保从本库获得最佳性能, 最重要的三件事是:

  1. 打开编译器优化: "release" 与 "debug" 构建之间的差别很容易达到 20 倍.
  2. 仔细挑选编译器: 例如, 在某些 Windows 编译器之间发现了 高达 8 倍的性能差异.
  3. 禁用 long double 的内部使用, 这会降低精度, 但在现代 x64 硬件/编译器上通常能带来 2 倍加速.

performance section 包含关于本库性能的更多信息、可以如何微调, 以及本库与其他一些开源替代品的比较.
