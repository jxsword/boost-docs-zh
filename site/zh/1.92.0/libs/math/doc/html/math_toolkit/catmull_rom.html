Catmull-Rom 样条

概要 

#include <boost/math/interpolators/catmull_rom.hpp>

namespace boost{ namespace math{

    template<class Point, class RandomAccessContainer = std::vector<Point> >
    class catmull_rom
    {
    public:

        catmull_rom(RandomAccessContainer&& points, bool closed = false, Real alpha = (Real) 1/ (Real) 2)

        catmull_rom(std::initializer_list<Point> l, bool closed = false, typename Point::value_type alpha = (typename Point::value_type) 1/ (typename Point::value_type) 2);

        Point operator()(Real s) const;

        Real max_parameter() const;

        Real parameter_at_point(size_t i) const;

        Point prime(Real s) const;
    };

}}

说明

Catmull-Rom 样条是一族插值曲线, 常用于计算机图形学与动画. Catmull-Rom 样条具有以下性质:

  • 仿射不变性: 插值与仿射变换可交换.
  • 基函数的局部支撑: 这带来稳定性与快速求值.
  • C2-光滑性
  • 对控制点插值 - 即曲线穿过控制点. 许多曲线 (如 Bézier) 是逼近型的 - 它们不穿过控制点. 这使得它们比插值样条更难使用.

Boost.Math 提供的 catmull_rom 类可从任意维度的点数组创建三次 Catmull-Rom 样条. 由于表示 n 维空间中的点的方式很多, 该类通过对点类型模板化来力求灵活. 对点类型的要求在下文有更详细的讨论, 粗略地说: 它必须定义了解引用运算符 (例如 p[0] 不是语法错误), 必须能被解引用直到 dimension -1, 且 p[i] 的类型为 Real, 定义了 value_type, 以及自由函数 size(). std::vector 和 std::array 满足这些要求. 基本用法如下所示:

std::vector<std::array<Real, 3>> points(4);
points[0] = {0,0,0};
points[1] = {1,0,0};
points[2] = {0,1,0};
points[3] = {0,0,1};
catmull_rom<std::array<Real, 3>> cr(std::move(points));
// Interpolate at s = 0.1:
auto point = cr(0.1);

这里, s 在 0 和 cr.max_parameter() 之间变化. 后者的值取决于 alpha 的选择. 要在 /points[i]/ 和 /points[i+1], /s 之间对曲线插值, s 应从 cr.parameter_at_point(i) 取到 cr.parameter_at_point(i+1).

样条可以是开放的或闭合的; 闭合意味着存在某个 s > 0 使得 P(s) = P(0). 默认是开放的, 但这很容易改变:

// closed = true
catmull_rom<std::array<Real, 3>> cr(std::move(points), true);

无论哪种情形, 在 s=0 处求插值器的值都会返回列表中的第一个点.

如果曲线是开放的, 第一段和最后一段可能出现奇怪的行为. 传统的解决办法是在数据前面精心挑选一个控制点, 使第一个数据段 (第二个插值器段) 具有合理的切向量, 然后直接忽略第一个插值器段; 并按类似标准在数据后面附加一个控制点. 不过, 我们建议在证明确有必要之前不要费这个功夫: 对大多数用例而言, 不前置和追加控制点时曲线已经足够好, 而负责任地选取非数据控制点是很困难的.

在 catmull_rom 内部, 曲线以闭合形式表示. 这是因为开放的 Catmull-Rom 曲线是隐式闭合的, 而闭合点是零向量. 没有理由认为零向量比端点 (或其他任何点) 更适合作闭合点, 因此传统上 Catmull-Rom 样条把第一点与第二点之间的段以及倒数第二点与最后一点之间的段留为未定义. 我们觉得传统 Catmull-Rom 样条实现的这一性质令用户恼火且困惑. 因此在内部, 我们把曲线闭合, 使第一段和最后一段有定义. 当然, 这会使第一个点和最后一个点的切向量变得怪异. 这是一个“两害相权”的设计决策 - 要么曲线无法在其第一段和最后一段插值, 要么第一段和最后一段的切向量为无意义的值. 在绝大多数情况下, 这对用户不成问题. 但如果它确实成了问题, 用户应在其认为合理的位置额外添加一个点并闭合曲线.

由于该例程内部把曲线表示为闭合的, 一个问题随之而来: 为什么用户还必须指明曲线是开放还是闭合? 答案是参数化由例程选择, 因此了解在哪些值上会返回有意义的结果对用户是有益的.

Real max_s = cr.max_parameter();

如果你试图在 s > max_s 处插值, 将抛出异常. 若曲线是闭合的, 则 cr(max_s) = p0, 其中 p0 是曲线上的第一个点. 若曲线是开放的, 则 cr(max_s) = pf, 其中 pf 是曲线上的最后一个点.

Catmull-Rom 曲线允许无穷多种参数化. catmull_rom 类的默认参数化是所谓的向心参数化. 已证明这种参数化是唯一一种不会在段内形成尖点或自交的参数化. 不过, 高级用户可以使用 alpha 参数选择其他参数化:

// alpha = 1 is the "chordal" parameterization.
catmull_rom<std::array<double, 3>> cr(std::move(points), false, 1.0);

alpha 参数必须始终位于范围 [0,1] 内.

最后, 曲线上任意点处的切向量可以通过以下方式计算:

double s = 0.1;
Point tangent = cr.prime(s);

由于切向量的幅值依赖于参数化, 它并无意义 (除非用户选择弦参数化 alpha = 1, 即按点之间的欧氏距离参数化). 不过, 无论何种参数化, 其方向都是有意义的, 因此用户可能希望将此结果归一化.

点类型

前面已经讨论过, Point 类型模板实参必须满足某些条件. 下面展示一个可用作 Catmull-Rom 模板实参的 3D 自定义点类型:

template<class Real>
class mypoint3d
{
public:
    // Must define a value_type:
    typedef Real value_type;

    // Regular constructor--need not be of this form.
    mypoint3d(Real x, Real y, Real z) {m_vec[0] = x; m_vec[1] = y; m_vec[2] = z; }

    // Must define a default constructor:
    mypoint3d() {}

    // Must define array access:
    Real operator[](size_t i) const
    {
        return m_vec[i];
    }

    // Must define array element assignment:
    Real& operator[](size_t i)
    {
        return m_vec[i];
    }

private:
    std::array<Real, 3> m_vec;
};


// Must define the free function "size()":
template<class Real>
constexpr size_t size(const mypoint3d<Real>& c)
{
    return 3;
}

std::array 和 std::vector 都满足这些条件; 尽管如此, 定义你自己的点类可能仍有用, 比如 (举例来说) 你可以在其上定义几何距离.

注意事项

Catmull-Rom 插值器需要比用户提供的点多三个的内存. 这会使该类对输入向量调用一次 resize(). 若 v.capacity() >= v.size() + 3, 则不会有任何问题; 没有重分配, 且实践中这一条件几乎总能满足. 但若 v.capacity() < v.size() + 3, 则 realloc 会造成大约 20% 的性能损失.

泛型容器

Point 类型可以存储在与 std::vector 不同的容器中. 例如, 下面演示如何把点存入 Boost.uBLAS 向量:

mypoint3d<Real> p0(0.1, 0.2, 0.3);
mypoint3d<Real> p1(0.2, 0.3, 0.4);
mypoint3d<Real> p2(0.3, 0.4, 0.5);
mypoint3d<Real> p3(0.4, 0.5, 0.6);
mypoint3d<Real> p4(0.5, 0.6, 0.7);
mypoint3d<Real> p5(0.6, 0.7, 0.8);

boost::numeric::ublas::vector<mypoint3d<Real>> u(6);
u[0] = p0;
u[1] = p1;
u[2] = p2;
u[3] = p3;
u[4] = p4;
u[5] = p5;

// Tests initializer_list:
catmull_rom<mypoint3d<Real>, decltype(u)> cat(std::move(u));
