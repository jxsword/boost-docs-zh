使用 Boost.Multiprecision

建议所有新项目使用 Boost.Multiprecision.

使用 Boost.Multiprecision 生成用于 FFT 的高精度正弦系数数组.

Boost.Multiprecision 库可用于需要超出内置类型 (如 float、double 与 long double) 精度的计算. 对扩展精度计算, Boost.Multiprecision 提供一个名为 cpp_bin_float 的模板数据类型. 十进制精度位数通过模板参数在编译期固定.

数学软件中经常需要计算数值表. 为避免 Table-maker's dilemma, 必须用更高的精度类型计算表的值, 使其具有表值类型 (比如 double) 的最近可表示位模式.

本示例是一个程序 fft_since_table.cpp, 它写出头文件 sines.hpp, 其中包含供快速 Fourier 变换 (FFT) 使用的正弦系数数组, 可被 FFT 程序包含.

要使用 Boost.Multiprecision 的高精度浮点类型与常数, 我们需要一些包含:

#include <boost/math/constants/constants.hpp>
// using boost::math::constants::pi;

#include <boost/multiprecision/cpp_bin_float.hpp> // for
// using boost::multiprecision::cpp_bin_float and
// using boost::multiprecision::cpp_bin_float_50;
// using boost::multiprecision::cpp_bin_float_quad;

#include <boost/array.hpp> // or <array> for std::array

#include <iostream>
#include <limits>
#include <vector>
#include <algorithm>
#include <iomanip>
#include <iterator>
#include <fstream>

首先, 本示例定义一个前导文本字符串, 它是带有程序许可证、版权等信息的 C++ 注释 (当然, 你会按自己的需要定制, 包括你的版权声明). 它将出现在写出的头文件 sines.hpp 的顶部.

using boost::multiprecision::cpp_bin_float_50;
using boost::math::constants::pi;

例如, 快速 Fourier 变换 (FFT) 可能在其实现细节中使用 sin(π/2n) 值的表. 为了使 FFT 实现的精度最大化, 列表的三角函数值的精度应超过 FFT 中所用内置浮点类型的精度.

下面的示例计算 1 <= n <= 31 范围内 sin(π/2n) 值的表.

本程序除其他程序元素外, 还使用了 Boost.Multiprecision 中 50 位十进制精度的数据类型 boost::multiprecision::cpp_bin_float_50, 从 Boost.Math 检索的常数 π 的值 (保证以该类型 (这里是 cpp_bin_float_50) 的最后一位精度初始化), 以及与 std::for_each() 组合的 C++11 lambda 函数.

定义正弦数组中值的个数 (32).

std::size_t size = 32U;
//cpp_bin_float_50 p = pi<cpp_bin_float_50>();
cpp_bin_float_50 p = boost::math::constants::pi<cpp_bin_float_50>();

std::vector <cpp_bin_float_50> sin_values (size);
unsigned n = 1U;
// Generate the sine values.
std::for_each
(
  sin_values.begin (),
  sin_values.end (),
  [&n](cpp_bin_float_50& y)
  {
    y = sin( pi<cpp_bin_float_50>() / pow(cpp_bin_float_50 (2), n));
    ++n;
  }
);

为生成的文件定义浮点类型: 内置的 double, float, 或 long double, 或用户定义类型如 cpp_bin_float_50.

std::string fp_type = "double";

std::cout << "Generating an `std::array` or `std::array` for floating-point type: "
  << fp_type << ". " << std::endl;

默认情况下, 输出只显示标准的 6 位十进制数字, 因此设置精度以显示所选浮点类型足够多的有效数字. 对 cpp_bin_float_50 是 50. (50 位十进制数字对大多数应用应当绰绰有余).

std::streamsize precision = std::numeric_limits<cpp_bin_float_50>::digits10;

std::cout << "Sines table precision is " << precision << " decimal digits. " << std::endl;

当然, 也可以为表值选择较低的精度, 例如,

std::streamsize precision = std::numeric_limits<cpp_bin_float_quad>::max_digits10;

128 位 "quad" 精度的 36 位十进制数字对当前使用 128 位的最高精度 long double 实现已足够. 一般而言, 它应当比目标系统浮点类型的 std::numeric_limits<RealType>::max_digits10 多出几位十进制数字 (保护位). (若实现不提供 max_digits10, 则可用 Kahan 公式 std::numeric_limits<RealType>::digits * 3010/10000 + 2 代替).

编译器会把这些值当作十进制数字字符串读取, 并为浮点类型使用最近的表示.

现在把整个正弦表输出到你选择的文件中.

const char sines_name[] = "sines.hpp";  // Assuming in same directory as .exe

std::ofstream fout(sines_name, std::ios_base::out);  // Creates if no file exists,
// & uses default overwrite/ ios::replace.
if (fout.is_open() == false)
{  // failed to open OK!
  std::cout << "Open file " << sines_name << " failed!" << std::endl;
  return EXIT_FAILURE;
}
else
{ // Write prolog etc as a C++ comment.
  std::cout << "Open file " << sines_name << " for output OK." << std::endl;
  fout << prolog
  << "// Table of " << sin_values.size() << " values with "
    << precision << " decimal digits precision,\n"
    "// generated by program fft_sines_table.cpp.\n" << std::endl;

fout << "#include <array> // std::array" << std::endl;

// Write the table of sines as a C++ array.
  fout <<  "\nstatic const std::array<double, " << size << "> sines =\n"
  "{{\n"; // 2nd { needed for some old GCC compiler versions.
  fout.precision(precision);

  for (unsigned int i = 0U; ;)
  {
    fout << "  " << sin_values[i];
    if (i == sin_values.size()-1)
    { // next is last value.
      fout << "\n}};  // array sines\n"; // 2nd } needed for some old GCC compiler versions.
      break;
    }
    else
    {
      fout << ",\n";
      i++;
    }
  } // for

  fout.close();
  std::cout << "Closed file " << sines_name << " for output." << std::endl;
}

生成的输出文件见 ../../example/sines.hpp

输出可以作为文本复制, 并方便地整合进给定源代码. 或者, 输出也可以写入文本文件, 甚至可以像本示例这样用于自己编写的自动代码生成器.

计算机代数系统可用于验证从 Boost.Math 与 Boost.Multiprecision 得到的结果. 例如, Wolfram Mathematica 计算机代数系统可以用以下命令得到类似的表:

Table[N[Sin[Pi / (2^n)], 50], {n, 1, 31, 1}]

Wolfram Alpha 计算知识引擎也可以用来生成这个表. 同样的命令可以粘贴到计算框中.
