Whittaker-Shannon 插值

概要 

#include <boost/math/interpolators/whittaker_shannon.hpp>

namespace boost { namespace math { namespace interpolators {

  template <class RandomAccessContainer>
  class whittaker_shannon
  {
  public:

      using Real = RandomAccessContainer::value_type;

      whittaker_shannon(RandomAccessContainer&& v, Real left_endpoint, Real step_size);

      Real operator()(Real x) const;

      Real prime(Real x) const;
  };

}}} // namespaces

Whittaker-Shannon 插值

Whittaker-Shannon 插值器取等间距数据, 并通过 sinc 函数之和在其间插值. 这种插值稳定且无穷光滑, 但对数据具有线性复杂度, 相对于紧支撑 B 样条而言较慢. 此外, 我们无法把无限多的数据传入类中, 必须把 (也许) 无穷的 sinc 级数截断为有限项. 由于 sinc 函数具有缓慢的 1/x 衰减, 截断级数可能带来很大误差. 因此, 该插值器在处理紧支撑函数的样本时效果最好. 下面是一个对光滑 "bump 函数" 插值的示例:

auto bump = [](double x) { if (std::abs(x) >= 1) { return 0.0; } return std::exp(-1.0/(1.0-x*x)); };

double t0 = -1;
size_t n = 2049;
double h = 2.0/(n-1.0);

std::vector<double> v(n);
for(size_t i = 0; i < n; ++i) {
    double t = t0 + i*h;
    v[i] = bump(t);
}

auto ws = whittaker_shannon(std::move(v), t0, h);

double y = ws(0.3);

插值函数的导数也可以求值, 但精度不那么高:

double yp = ws.prime(0.3);

复杂度与性能

对构造函数的调用需要 𝑶(1) 次操作, 只是把数据移入类中. 对插值函数的每次调用是 𝑶(n), 其中 n 是要插值的点数.
