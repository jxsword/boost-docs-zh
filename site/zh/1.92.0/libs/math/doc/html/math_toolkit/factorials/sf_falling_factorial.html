下降阶乘 

#include <boost/math/special_functions/factorials.hpp>

namespace boost{ namespace math{

template <class T>
calculated-result-type falling_factorial(T x, unsigned i);

template <class T, class Policy>
calculated-result-type falling_factorial(T x, unsigned i, const Policy&);

}} // namespaces

返回 x 与 i 的下降阶乘:

falling_factorial(x, i) = x(x-1)(x-2)(x-3)...(x-i+1)

注意该函数仅对正的 i 有定义, 因而有 unsigned 第二个参数. 不过参数 x 既可为正也可为负.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

若结果大到无法用类型 T 表示, 可能返回 overflow_error 的结果.

这些函数的返回类型使用 结果类型计算规则 计算: 若 T 是整数类型, 结果类型为 double, 否则结果类型为 T.

精度

精度与 tgamma_delta_ratio 函数相同.

测试

下降阶乘的抽检测试使用 functions.wolfram.com 生成的数据.

实现

上升与下降阶乘借助 tgamma_delta_ratio 以 gamma 函数之比实现. 对小整数参数的优化由该函数内部处理.
