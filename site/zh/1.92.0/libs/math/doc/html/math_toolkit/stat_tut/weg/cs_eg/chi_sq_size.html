估计标准差 Chi-Square 检验所需的样本量

假设我们对标准差进行了 Chi Squared 检验, 结果处于临界状态, 一个合理的问题是: "样本量必须多大才能得出明确的结果?"

类模板 chi_squared_distribution 有一个静态方法 find_degrees_of_freedom, 它将针对某些可接受的 I 类错误风险 alpha、II 类错误风险 beta 以及与标准差的差异 diff 计算这个值. 请注意, 所用的方法作用于方差, 而不是 Chi Squared 检验通常使用的标准差.

本示例的代码位于 chi_square_std_dev_test.cpp.

我们先定义一个过程, 打印各种风险水平所需的样本量:

void chi_squared_sample_sized(
     double diff,      // difference from variance to detect
     double variance)  // true variance
{

该过程首先打印输入数据:

using namespace std;
using namespace boost::math;

// Print out general info:
cout <<
   "_____________________________________________________________\n"
   "Estimated sample sizes required for various confidence levels\n"
   "_____________________________________________________________\n\n";
cout << setprecision(5);
cout << setw(40) << left << "True Variance" << "=  " << variance << "\n";
cout << setw(40) << left << "Difference to detect" << "=  " << diff << "\n";

并定义一个显著性水平表, 我们将为它们计算样本量:

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

对每个 alpha 值, 我们可以计算两个样本量: 一个是样本方差比真值小 diff 的情况, 一个是比真值大 diff 的情况. 由于 Chi Squared 分布的非对称性, 这两个值不会相同; 它们计算的差别仅在于 diff 传入 find_degrees_of_freedom 时所带的符号. 最后, 在本例中我们简化处理, 让风险水平 beta 与 alpha 相同:

cout << "\n\n"
        "_______________________________________________________________\n"
        "Confidence       Estimated          Estimated\n"
        " Value (%)      Sample Size        Sample Size\n"
        "                (lower one         (upper one\n"
        "                 sided test)        sided test)\n"
        "_______________________________________________________________\n";
//
// Now print out the data for the table rows.
//
for(unsigned i = 0; i < sizeof(alpha)/sizeof(alpha[0]); ++i)
{
   // Confidence value:
   cout << fixed << setprecision(3) << setw(10) << right << 100 * (1-alpha[i]);
   // calculate df for a lower single sided test:
   double df = chi_squared::find_degrees_of_freedom(
      -diff, alpha[i], alpha[i], variance);
   // convert to sample size:
   double size = ceil(df) + 1;
   // Print size:
   cout << fixed << setprecision(0) << setw(16) << right << size;
   // calculate df for an upper single sided test:
   df = chi_squared::find_degrees_of_freedom(
      diff, alpha[i], alpha[i], variance);
   // convert to sample size:
   size = ceil(df) + 1;
   // Print size:
   cout << fixed << setprecision(0) << setw(16) << right << size << endl;
}
cout << endl;

作为示例输出, 考虑 NIST/SEMATECH e-Handbook of Statistical Methods. 中的 硅晶圆数据. 在该场景中, 一家 100 ohm.cm 硅晶圆供应商声称其制造工艺能生产出一致性足够的晶圆, 使该批次电阻率的标准差不超过 10 ohm.cm. 从该批次抽取的 N = 10 片晶圆样本的标准差为 13.97 ohm.cm, 我们问自己的问题是: "我们的样本必须多大才能可靠地检测出这一差异?"

要使用上面的过程, 我们必须把标准差转换为方差 (取平方), 之后程序输出如下:

在本例中我们关心的是上侧单侧检验. 例如, 如果错误拒绝零假设的最大可接受风险为 0.05 (I 类错误), 且未能拒绝零假设的最大可接受风险也是 0.05 (II 类错误), 我们估计需要 51 的样本量.
