expm1 

#include <boost/math/special_functions/expm1.hpp>

namespace boost{ namespace math{

template <class T>
calculated-result-type expm1(T x);

template <class T, class Policy>
calculated-result-type expm1(T x, const Policy&);

}} // namespaces

返回 ex - 1.

该函数的返回类型按 结果类型计算规则 确定: 返回 double, 条件是 x 为整数类型, 否则返回 T.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

对于小的 x, ex 非常接近 1, 因此计算 ex - 1 会在 x 较小时导致灾难性消去误差. expm1 使用有理近似计算 ex - 1 (最高支持 128 位 long double), 否则在 x 较小时通过级数展开计算 (精度优于 2ɛ).

最后, 当定义了 BOOST_HAS_EXPM1 时, 该模板的 float/double/long double 特化只是转发到平台的该函数原生 (POSIX) 实现.
