极值分布 (Extreme Value) 

#include <boost/math/distributions/extreme.hpp>
template <class RealType = double,
          class Policy   = policies::policy<> >
class extreme_value_distribution;

typedef extreme_value_distribution<> extreme_value;

template <class RealType, class Policy>
class extreme_value_distribution
{
public:
   typedef RealType value_type;

   BOOST_MATH_GPU_ENABLED extreme_value_distribution(RealType location = 0, RealType scale = 1);

   BOOST_MATH_GPU_ENABLED RealType scale()const;
   BOOST_MATH_GPU_ENABLED RealType location()const;
};

存在多种极值分布: 此实现表示最大值情形, 也被称为 Fisher-Tippett 分布、log-Weibull 分布或 Gumbel 分布.

极值理论对评估极不寻常事件 (如百年一遇洪水) 的风险非常重要.

更多信息可在 NIST、Wikipedia、Mathworld 和 Extreme value theory 网站上找到.

Extreme Value Distributions, Theory and Applications Samuel Kotz & Saralees Nadarajah 讨论了各极值分布类型之间的关系 (本分布只是其中之一).

该分布的 PDF 由下式给出:

f(x) = (1/scale) e-(x-location)/scale e-e-(x-location)/scale

在标准情形 (scale = 1, location = 0) 下化简为:

f(x) = e-xe-e-x

成员函数 
BOOST_MATH_GPU_ENABLED extreme_value_distribution(RealType location = 0, RealType scale = 1);

构造具有指定位置和尺度参数的极值分布.

要求 scale > 0, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType location()const;

返回分布的位置参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回分布的尺度参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机参数的定义域是 [-∞, +∞].

在此分布中, logcdf 和 logpdf 的实现都做了专门化以提升数值精度.

精度

极值分布以标准库的 exp 和 log 函数实现, 因此误差率应非常低.

实现

在下表中: a 是位置参数, b 是尺度参数, x 是随机变量, p 是概率, q = 1-p 为其补.

函数

实现说明

pdf

利用关系: pdf = exp((a-x)/b) * exp(-exp((a-x)/b)) / b

logpdf

log(pdf) = log(1/b) + e - exp(e)

cdf

利用关系: p = exp(-exp((a-x)/b))

logcdf

log(cdf) = -exp((a-x)/b)

cdf 补函数

利用关系: q = -expm1(-exp((a-x)/b))

quantile

利用关系: a - log(-log(p)) * b

由补函数求 quantile

利用关系: a - log(-log1p(-q)) * b

均值

a + Euler-Mascheroni-constant * b

标准差

pi * b / sqrt(6)

众数

与位置参数 a 相同.

偏度

12 * sqrt(6) * zeta(3) / pi3

峰度

27 / 5

超额峰度

kurtosis - 3 或 12 / 5
