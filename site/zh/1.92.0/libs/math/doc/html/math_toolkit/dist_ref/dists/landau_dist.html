Landau 分布 

#include <boost/math/distributions/landau.hpp>
template <class RealType = double,
          class Policy   = policies::policy<> >
class landau_distribution;

typedef landau_distribution<> landau;

template <class RealType, class Policy>
class landau_distribution
{
public:
   typedef RealType  value_type;
   typedef Policy    policy_type;

   BOOST_MATH_GPU_ENABLED landau_distribution(RealType location = 0, RealType scale = 1);

   BOOST_MATH_GPU_ENABLED RealType location()const;
   BOOST_MATH_GPU_ENABLED RealType scale()const;
   BOOST_MATH_GPU_ENABLED RealType bias()const;
};

Landau 分布 以 Lev Landau 命名. 它是形状参数 α=1, β=1 的 稳定分布 的特例.

由以下概率分布函数 PDF给出:

位置参数 μ 是分布的位置, 而尺度参数 [c] 决定分布的宽度; 但与其他可缩放分布不同, 它有一个会改变分布位置的特殊之处. 如果位置为零, 尺度为 1, 则结果是标准 landau 分布.

该分布描述带电粒子穿过薄层物质时能量损失的统计性质.

成员函数 
BOOST_MATH_GPU_ENABLED landau_distribution(RealType location = 0, RealType scale = 1);

构造一个 landau 分布, 位置参数为 location, 尺度参数为 scale. 当这些参数取默认值 (location = 0, scale = 1) 时, 结果就是标准 landau 分布.

要求 scale > 0, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType location()const;

返回分布的位置参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回分布的尺度参数.

BOOST_MATH_GPU_ENABLED RealType bias()const;

返回尺度参数带来的平移量.

bias = - 2 / π log(c)

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

不过请注意, landau 分布没有均值、标准差等. 请参见 数学上未定义的函数 以控制这些函数是否应在编译时以 BOOST_STATIC_ASSERTION_FAILURE 失败 (这是默认行为).

或者, 函数 mean, standard deviation, variance, skewness, kurtosis 和 kurtosis_excess 若被调用, 都会返回 domain_error.

随机变量的定义域是 [-[max_value], +[min_value]].
