配置宏

几乎所有配置细节都由 <boost\math\tools\config.hpp> 自动设置.

正常使用时, 可能用到的只有策略配置宏. 参见 policy reference.

作为参考, 下文简要描述了 Boost.Math 内部使用的宏.

表 1.11. Boost.Math 宏

宏

注释

BOOST_MATH_NO_LONG_DOUBLE_MATH_FUNCTIONS

不生成也不使用 long double 函数: 当平台的 long double 或标准库 long double 支持缺失或有缺陷时会设置此宏.

BOOST_MATH_USE_FLOAT128

设置后, 数值常量支持 __float128 数据类型, 常量带有 Q 后缀.

BOOST_MATH_DISABLE_FLOAT128

设置后, 数值常量不使用 __float128 数据类型, 即使编译器看起来支持它.

BOOST_MATH_NO_REAL_CONCEPT_TESTS

不要尝试使用 real concept 测试 (硬件或软件不支持 real_concept 类型).

BOOST_MATH_CONTROL_FP

控制 FP 硬件异常 - 我们的测试在 MSVC 上不支持硬件异常. 可能被设置为类似 _control87(MCW_EM,MCW_EM) 的内容.

BOOST_MATH_NO_DEDUCED_FUNCTION_POINTERS

此宏由我们的测试用例使用; 当把函数模板赋给函数指针需要在函数名上提供显式模板实参时, 它会被设置.

BOOST_MATH_USE_C99

使用 C99 数学函数.

BOOST_NO_NATIVE_LONG_DOUBLE_FP_CLASSIFY

当没有原生的 (或有缺陷的) fpclassify(long double) 时定义此宏, 即使其他 C99 函数是可用的.

BOOST_MATH_SMALL_CONSTANT(x)

我们的测试用例中使用的辅助宏: 当下溢常量会导致编译器问题时, 将其设置为零.

BOOST_MATH_BUGGY_LARGE_FLOAT_CONSTANTS

当常量对 float 而言过大时设置; 这会使“坏”值而非无穷大或足够大的值被存储到数据中.

BOOST_MATH_STD_USING

为许多 std:: (abs 到 sqrt) 以及 boost::math (rounds、modf) 函数提供 using 语句. 这允许无限定地调用这些函数, 这样即使argument-dependent Argument Dependent Lookup未能找到合适的重载, 也会考虑 std:: 版本.

BOOST_FPU_EXCEPTION_GUARD

用于每个特殊函数的入口, 在内部计算之前重置所有 FPU 异常标志, 并在函数退出时合并新旧异常标志. 用作一种变通办法: 某些平台或硬件在调用标准库函数时若设置了任何 FPU 异常标志, 其行为就会异常.

BOOST_MATH_INSTRUMENT

定义此宏以输出数学函数的诊断信息. 它对 Boost.Math 相当“全局”, 粒度很粗, 可能产生大量输出! (尤其因为会输出全精度值). 主要为内部使用和开发而设计.

BOOST_MATH_INSTRUMENT_CODE(x)

输出选定的命名变量, 例如 BOOST_MATH_INSTRUMENT_CODE("guess = " << guess); 由 BOOST_MATH_INSTRUMENT 使用

BOOST_MATH_INSTRUMENT_VARIABLE(name)

输出选定的变量, 例如 BOOST_MATH_INSTRUMENT_VARIABLE(result); 由 BOOST_MATH_INSTRUMENT 使用

BOOST_MATH_INSTRUMENT_FPU

输出 FPU 控制标志的状态.
