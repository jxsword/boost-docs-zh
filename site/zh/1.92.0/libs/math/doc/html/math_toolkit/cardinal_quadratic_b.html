基数二次 B 样条插值

概要 

#include <boost/math/interpolators/cardinal_quadratic_b_spline.hpp>

namespace boost{ namespace math{ namespace interpolators {

template <class Real>
class cardinal_quadratic_b_spline
{
public:
    // If you don't know the value of the derivative at the endpoints, leave them as NaNs and the routine will estimate them.
    // y[0] = y(a), y[n - 1] = y(b), step_size = (b - a)/(n -1).
    cardinal_quadratic_b_spline(const Real* const y,
                                size_t n,
                                Real t0 /* initial time, left endpoint */,
                                Real h  /*spacing, stepsize*/,
                                Real left_endpoint_derivative = std::numeric_limits<Real>::quiet_NaN(),
                                Real right_endpoint_derivative = std::numeric_limits<Real>::quiet_NaN())

    cardinal_quadratic_b_spline(std::vector<Real> const & y,
                                Real t0 /* initial time, left endpoint */,
                                Real h  /*spacing, stepsize*/,
                                Real left_endpoint_derivative = std::numeric_limits<Real>::quiet_NaN(),
                                Real right_endpoint_derivative = std::numeric_limits<Real>::quiet_NaN())

    Real operator()(Real t) const;

    Real prime(Real t) const;
};
}}}

基数二次 B 样条插值

基数二次 B 样条插值器与三次 B 样条插值器几乎相同, 区别在于其基函数由盒函数与自身卷积两次构造而成, 而三次 B 样条是卷积三次.

由于基函数不如三次 B 样条光滑, 你几乎总是希望使用三次 B 样条插值器而非此插值器. 不过, 该插值器偶尔对逼近光滑度较低的函数有用, 因此在 Boost.Math 库内部也有使用.

当你逼近的函数二阶或三阶连续可微、但不是三阶或四阶可微时, 用三次 b 样条插值器来对比测试此插值器是合理的.
