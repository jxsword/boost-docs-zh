Rayleigh 分布 

#include <boost/math/distributions/rayleigh.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class rayleigh_distribution;

typedef rayleigh_distribution<> rayleigh;

template <class RealType, class Policy>
class rayleigh_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;
   // Construct:
   BOOST_MATH_GPU_ENABLED rayleigh_distribution(RealType sigma = 1)
   // Accessors:
   BOOST_MATH_GPU_ENABLED RealType sigma()const;
};

}} // namespaces

Rayleigh 分布是一种连续分布, 其概率密度函数为:

f(x; sigma) = x * exp(-x2/2 σ2) / σ2

其中 sigma 参数 σ > 0, 且 x > 0.

Rayleigh 分布常用于两个正交分量取绝对值的场合, 例如, 可以将风速与风向合成得到风速值, 或者实部与虚部的绝对值服从 Rayleigh 分布.

相关分布

两个独立正态分布 X 与 Y 的绝对值 √ (X2 + Y2) 服从 Rayleigh 分布.

Chi、Rice 与 Weibull 分布都是 Rayleigh 分布 的推广.

成员函数 
BOOST_MATH_GPU_ENABLED rayleigh_distribution(RealType sigma = 1);

构造一个 Rayleigh 分布, 其 σ 为 sigma.

要求 σ 参数大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType sigma()const;

返回此分布的 sigma 参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [0, max_value].

在此分布中, logcdf 和 logpdf 的实现都做了专门化以提升数值精度.

精度

Rayleigh 分布基于标准库 sqrt 与 exp 实现, 因此误差率应当极低. 一些常数 (如偏度与峰度) 使用 150 位精度 (约 50 位十进制数字) 的 NTL RR 类型计算.

实现

在下表中, σ 是分布的 sigma 参数, x 是随机变量, p 是概率, q = 1-p 是其补.

函数

实现说明

pdf

使用关系式: pdf = x * exp(-x2)/2 σ2

logpdf

log(pdf) = -(x2)/(2*σ2) - 2*log(σ) + log(x)

cdf

使用关系式: p = 1 - exp(-x2/2) σ2= -expm1(-x2/2) σ2

logcdf

log(cdf) = log1p(-exp(-x2 / (2*σ2)))

cdf 补函数

使用关系式: q = exp(-x2/ 2) * σ2

quantile

使用关系式: x = sqrt(-2 * σ 2) * log(1 - p)) = sqrt(-2 * σ 2) * log1p(-p))

由补函数求 quantile

使用关系式: x = sqrt(-2 * σ 2) * log(q))
