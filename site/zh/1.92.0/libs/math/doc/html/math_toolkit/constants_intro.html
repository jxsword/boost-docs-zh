引言

Boost.Math 提供了一组数学常量.

为什么使用 Boost.Math 数学常量?

  • 可读性好. 对于大量只需使用 double 等内建类型的工作, 你可以直接写如下形式的表达式:

    double area = pi * r * r;

    (如果这就是你需要的全部, 请直接跳到 use in non-template code!)

  • 省力 - 无需检索参考文献.
  • 既可用于内建浮点类型, 也可用于用户自定义的、可能是扩展精度的类型, 如 NTL、MPFR/GMP、mp_float: 对后者, 常量会按所需精度计算然后缓存.
  • 准确 - 确保对所选浮点类型
    • 不会因中间计算的反复舍入而损失精度.
    • 结果以更高精度计算, 且只舍入一次.
    • 在极端用例处, 函数 pow、三角函数和 log 产生不准确结果的风险更小.
    • 发生消去误差的风险更小.
    的值尽可能准确.
  • 可移植 - 尽可能在使用不同浮点精度的不同系统之间移植: 参见 use in template code.
  • 经过测试 - 与其他已发表来源进行比较, 或以 long double 精度单独计算.

  • 更快 - 可避免在运行时 (重复) 计算.

    • 如果返回的值是内建类型, 则按值返回为 constexpr (C++11 特性, 若可用).
    • 如果值经过计算并缓存 (或从字符串表示构造并缓存), 则以常量引用返回.

    在以下情况下这可能很重要:

    • 使用了 pow、三角函数或 log 函数.
    • 位于内层循环中.
    • 使用 Boost.Multiprecision 之类的高精度 UDT.
    • 内建类型可以进行的编译器优化 (尤其是 double) 不可用.
