Float128 类型的实现

用 float128_t 重载模板函数
指数函数
typeinfo

由于很少有编译器实现真正的 128 位浮点, 且诸如后缀 Q (可能需要选项 -fext-numeric-literals 才能启用) 之类的语言特性以及 C++ 标准库函数在 C++11 中尚缺失或不完整, 该 Boost.Math 实现封装了 GCC 编译器提供的 __float128 (GCC floating-point types) 或 Intel 编译器提供的 _Quad 类型.

提供它是为了展示 (并让用户评估) 更高精度浮点的可行性与收益, 特别是允许以高精度使用完整的 <cmath> 与 Boost.Math 函数和分布库.

(也可以将 Boost.Math 与 Boost.Multiprecision 的十进制与二进制类型一起使用, 但由于这些是纯软件方案, 允许更高精度或任意精度, 速度可能较慢).

我们还提供 (我们认为完整的) <limits>, <cmath> 支持、<iostream> 中的 I/O 流操作, 以及 <complex>.

作为未来 C++ 标准的原型, 我们把所有这些都放在 namespace std 中. 这当然违反了现有的 C++ 标准, 因此选择任何承诺检查一致性的编译器都会失败.

提示

对 GCC, 请用 -std=gnu++11 或 -std=gnu++03 编译, 并且不要使用 -std=stdc++11 或任何 "strict" 选项, 因为它们会关闭对 __float128 的完全支持. 这些要求同样适用于 Linux 上的 Intel 编译器; 对 Windows 上的 Intel 编译器, 你需要用 -Qoption,cpp,--extended_float_type -DBOOST_MATH_USE_FLOAT128 编译以启用 128 位浮点支持.

__float128 类型在 GCC 上由 libquadmath 库 提供, 或在 Intel C++ 上由 Intel 的 FORTRAN 库提供. 它们还在 <cmath> 中提供了一整套 namespace std 函数.

提示

如果你打算使用 Boost.Math 的 develop 分支, 那么请把 -I/c/modular-boost/libs/math/include 设为第一个包含目录.

g++ -O3 -std=gnu++11 test.cpp -I/c/modular-boost/libs/math/include -I/c/modular-boost -lquadmath -o test.exe
注释

到目前为止, 我们注意到的唯一缺失细节是尝试使用 <typeinfo> 时, 例如用于 std::cout << typeid<__float_128>.name();.

Link fails: undefined reference to typeinfo for __float128.

参见 GCC Bug 43622 - no C++ typeinfo for __float128. 但据报道 (Marc Glisse 2015-04-04) 已在 GCC 5 (及以上) 中修复.

例如, 在 GCC6.1.1 上, 这会按预期工作, 得到重整修饰的字符串名与输出 (如果可能 — 并非总是).

const std::type_info& tifu128 = typeid(__float128); // OK.
//std::cout << tifu128.name() << std::endl; // On GCC, aborts (because not printable string).
//std::cout << typeid(__float128).name() << std::endl; // Aborts - string name cannot be output.

const std::type_info& tif128 = typeid(float128); // OK.
std::cout << tif128.name() << std::endl; // OK.
std::cout << typeid(float128).name() << std::endl; // OK.

const std::type_info& tpi = typeid(pi1); // OK GCC 6.1.1 (from GCC 5 according to http://gcc.gnu.org/bugzilla/show_bug.cgi?id=43622)
std::cout << tpi.name() << std::endl; // Output mangled name:
