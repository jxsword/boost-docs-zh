查找下一个更大的可表示值 (float_next)

概要 
#include <boost/math/special_functions/next.hpp>

namespace boost{ namespace math{

template <class FPT>
FPT float_next(FPT val);

}} // namespaces
说明 - float_next

返回大于 x 的下一个可表示值. 若 x 非有限, 则返回 domain_error 的结果. 若不存在大于 x 的值, 则返回 overflow_error.

效果等同于

nextafter(val, (std::numeric_limits<FPT>::max)());
