算法 TOMS 748: Alefeld、Potra 和 Shi: 连续函数零点的界定

这些函数实现 TOMS 算法 748: 它混合使用三次、二次和线性 (割线) 插值来定位 f(x) 的根. 这两对函数仅在于 f(a) 和 f(b) 的值是否已经可用而有所不同.

一般来说, 使用 bracket and solve 比自己尝试像本函数要求的那样界定根更容易 (而且通常更高效).

提供本函数而非 Brent's method 是因为已知它在许多情况下效率更高 (它是已知渐近意义上最高效的算法, 并且已被证明对某些类别的光滑函数是最优的). 它还有一个有用的性质: 每一步都会缩小区间的大小, 不像 Brent 方法只在最后一步才缩小包围区间. 当你需要一个区间两端舍入到同一整数的结果时, 这一点特别有用: 例如在统计应用中就经常出现这种情况. 在这种情形下, 该函数能够以比其他情况下少得多的迭代次数退出.

TOMS 748 algorithm 的参数为:

f

一元函子 (或 C++ lambda), 即要求解其根的函数. f(x) 在 x 上不必单调递增或递减, 也可能有多个根. 但是, 给定的边界必须界定唯一的根.

a

根的初始区间的下界.

b

根的初始区间的上界. 前置条件是 a < b, 且 a 和 b 界定待求的根, 即 f(a) * f(b) < 0.

fa

可选: f(a) 的值.

fb

可选: f(b) 的值.

tol

二元函子 (或 C++ lambda), 用于确定根搜索的终止条件. tol 在每一步都会收到当前的区间; 当它返回 true 时, 当前区间将作为结果返回. 另参见 predefined termination functors.

max_iter

搜索根时要执行的函数调用次数上限. 退出时, max_iter 被设置为实际使用的函数调用次数.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

toms748_solve 返回: 一对界定根的值 r, 满足:

f(r.first) * f(r.second) <= 0

并且满足二者之一

tol(r.first, r.second) == true

或者

max_iter >= m

其中 m 是传递给函数的 max_iter 初始值.

换言之, 由调用者负责判断终止是因为超过了 max_iter 次函数调用 (只需把更新后的 max_iter 值与作为参数传入的先前值比较即可), 还是因为终止条件 tol 得到满足.
