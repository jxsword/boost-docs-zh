四次多项式的根

概要 

#include <boost/math/tools/quartic_roots.hpp>

namespace boost::math::tools {

// Solves ax⁴ + bx³ + cx² + dx + e = 0.
std::array<Real,3> quartic_roots(Real a, Real b, Real c, Real d, Real e);

}

背景

quartic_roots 函数提取四次多项式 ax⁴+ bx³ + cx² + dx + e 的所有实根. 结果是一个 std::array<Real, 4>, 无论多项式拥有多少个实根, 其长度都为四. (这是为了避免分配向量的性能开销, 该开销往往超过提取根所需的时间.) 根按非降序返回. 如果根是复数, 则它被放在数组末尾并设置为 nan.

该算法使用 Ferrari 的经典方法, 并遵循 Graphics Gems V, 外加一个用于根抛光的 Halley 迭代. 四次实根求解器的典型用途是对环面进行光线追踪.

性能与精度

在一台消费级笔记本上, 我们观察到提取根约需 90ns. 文件 reporting/performance/quartic_roots_performance.cpp 可以测定你系统上的速度.
