实现

传统的 beta 函数求值方法要么直接计算 gamma 函数, 要么先取对数再对结果取幂. 然而, 前者即使对于相当小的参数也容易上溢, 后者则容易产生抵消误差. 作为替代方案, 如果我们把 gamma 函数视为一个包含 Lanczos approximation 的白盒, 那么就可以合并幂次项:

这几乎已是理想的解法, 然而, 当 a 或 b 较大时, 几乎所有误差都发生在幂次项的求值上. 如果假设 a > b, 那么两个幂次项中较大的那个可以按因子 b 缩减, 这立即使最大误差减半:

这可能并非最终解法, 但与其他实现方法相比已非常有竞争力.

通用实现 (在没有可用的 Lanczos approximation 近似时) 的实现方式与 gamma 函数的通用版本非常相似, 借助 Sterling 近似完成. 同样, 为避免数值上溢, 位于级数前面的幂次项被合并在一起
