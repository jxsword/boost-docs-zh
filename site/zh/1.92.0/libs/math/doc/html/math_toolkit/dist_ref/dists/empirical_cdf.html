经验累积分布函数

概要 
#include <boost/math/distributions/empirical_cumulative_distribution_function.hpp>

namespace boost{ namespace math{

template <class RandomAccessContainer>
class empirical_cumulative_distribution_function
{
public:
    using Real = typename RandomAccessContainer::value_type;
    empirical_cumulative_distribution_function(RandomAccessContainer && v, bool sorted = false);

    auto operator()(Real t) const;

    RandomAccessContainer&& return_data();
};

}}
经验累积分布函数

经验累积分布函数是由观测数据构造的阶梯函数, 在数据无穷多的极限下收敛于真实的累积分布函数. 此函数是假设检验工作流的基本构件, 这类工作流试图回答“我的数据是否来自某个给定分布?”的问题. 这些检验需要对经验 CDF 和假想 CDF 的某个函数求积分以构造距离度量, 因此有时从数据构造一个连续的可调用对象会很有用.

用法示例如下:

#include <vector>
#include <random>
#include <boost/math/distributions/empirical_cumulative_distribution_function.hpp>
using boost::math::empirical_cumulative_distribution_function;
std::random_device rd;
std::mt19937 gen{rd()};
std::normal_distribution<double> dis(0, 1);
size_t n = 128;
std::vector<double> v(n);
for (size_t i = 0; i < n; ++i) {
  v[i] = dis(gen);
}

auto ecdf = empirical_cumulative_distribution_function(std::move(v));
std::cout << "ecdf(0.0) = " << ecdf(0.0) << "\n";
// should print approximately 0.5 . . .

经验分布函数要求数据已排序. 默认情况下, 构造函数会以 O(Nlog(N)) 的代价替你排序.

如果你的数据已经排序, 可以声明这一点, 构造函数就会简单地把数据移入类中:

std::sort(v.begin(), v.end());
auto ecdf = empirical_cumulative_distribution_function(std::move(v), /* already sorted = */ true);

用完对象后如果想把数据取回, 可使用

v = ecdf.return_data();

此操作会使 ecdf 失效; 它不能再被使用.

调用运算符的复杂度为 O(log(N)), 因为它需要一次 std::upper_bound 调用.

同时支持整数和浮点类型. 若输入数据为整数, 调用运算符的输出为 double. 需要 C++17.
