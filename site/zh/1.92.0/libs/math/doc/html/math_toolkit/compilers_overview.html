如果你的编译器或平台未列于上文, 请尝试运行回归测试: cd 到 boost-root/libs/math/test 并执行:

bjam mytoolset

其中 "mytoolset" 是你的编译器所用的 Boost.Build 工具集的名称. 很可能此阶段许多精度测试都会失败 - 不要惊慌 - 默认的可接受误差容限相当严格, 特别是对于具有扩展指数范围的 long double 类型 (它们会使一些函数执行更极端的测试用例). 你需要浏览失败测试的输出, 自行判断错误率是否可以接受.
