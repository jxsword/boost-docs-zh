正态 (高斯) 分布 

#include <boost/math/distributions/normal.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class normal_distribution;

typedef normal_distribution<> normal;

template <class RealType, class Policy>
class normal_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;
   // Construct:
   BOOST_MATH_GPU_ENABLED normal_distribution(RealType mean = 0, RealType sd = 1);
   // Accessors:
   BOOST_MATH_GPU_ENABLED RealType mean()const; // location.
   BOOST_MATH_GPU_ENABLED RealType standard_deviation()const; // scale.
   // Synonyms, provided to allow generic use of find_location and find_scale.
   BOOST_MATH_GPU_ENABLED RealType location()const;
   BOOST_MATH_GPU_ENABLED RealType scale()const;
};

}} // namespaces

正态分布大概是最著名的统计分布: 它也称为高斯分布. 均值为零、标准差为 1 的正态分布称为 标准正态分布.

成员函数 
BOOST_MATH_GPU_ENABLED normal_distribution(RealType mean = 0, RealType sd = 1);

构造一个正态分布, 均值为 mean, 标准差为 sd.

要求 sd > 0, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType mean()const;
BOOST_MATH_GPU_ENABLED RealType location()const;

两者都返回此分布的 mean.

BOOST_MATH_GPU_ENABLED RealType standard_deviation()const;
BOOST_MATH_GPU_ENABLED RealType scale()const;

两者都返回此分布的 standard deviation. (提供了冗余的 location 与 scale 函数以匹配其他类似分布, 从而可以通用地使用 find_location 与 find_scale 函数).

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [-[max_value], +[min_value]]. 不过, 如果 RealType 允许, 也支持 +∞ 与 -∞ 处的 pdf = 0, 以及 cdf 在 -∞ = 0, cdf 在 +∞ = 1, 补 cdf 在 -∞ = 1 与 +∞ = 0.

精度

正态分布借助 误差函数 实现, 因此误差率应当非常低.

实现

在下表中, m 是分布的均值, s 是其标准差.

函数

实现说明

pdf

使用关系式: pdf = e-(x-m)2/(2s2) / (s * sqrt(2*pi))

logpdf

log(pdf) = -log(s) - log(2*π)/2 - (x-mean)2/(2*s2)

cdf

使用关系式: p = 0.5 * erfc(-(x-m)/(s*sqrt(2)))

cdf 补函数

使用关系式: q = 0.5 * erfc((x-m)/(s*sqrt(2)))

quantile

使用关系式: x = m - s * sqrt(2) * erfc_inv(2*p)

由补函数求 quantile

使用关系式: x = m + s * sqrt(2) * erfc_inv(2*p)
