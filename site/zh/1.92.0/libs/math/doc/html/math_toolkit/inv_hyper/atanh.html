atanh 

#include <boost/math/special_functions/atanh.hpp>

template<class T>
calculated-result-type atanh(const T x);

template<class T, class Policy>
calculated-result-type atanh(const T x, const Policy&);

计算 双曲正切函数 的反函数在 x 处的值.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

如果 x 在 ]-∞;-1[ 范围内或在 ]+1;+∞[ 范围内, 则返回 domain_error 的结果.

如果 x 在 [-1;-1+ε[ 范围内, 则返回 -overflow_error 的结果, 其中 ε 表示 std::numeric_limits<T>::epsilon().

如果 x 在 ]+1-ε;+1] 范围内, 则返回 overflow_error 的结果, 其中 ε 表示 std::numeric_limits<T>::epsilon().

该函数的返回类型按照 结果类型计算规则 计算: 当 T 是整数类型时返回类型为 double, 否则为 T.

精度

在所有受支持的平台上, 精度一般在 1 到 2 个机器 epsilon 以内.
