与 MPFR 或 GMP 高精度浮点库一起使用

本库的特殊函数与工具可以与 MPFR (一种基于 GNU Multiple Precision Arithmetic Library 的任意精度数字类型) 一起使用, 既可通过 boost/math/bindings/mpfr.hpp 中的绑定, 也可通过 boost/math/bindings/mpreal.hpp.

建议新项目改用带 GMP/MPFR 后端的 Boost.Multiprecision.

要使用这些绑定, 你需要已安装 MPFR 及其依赖 GMP library. 你还需要 MPFR 的两个受支持的 C++ 包装之一: gmpfrxx (or mpfr_class) 或 mpfr-C++ (mpreal).

遗憾的是, mpfr_class 与 mpreal 都不完全满足我们的概念要求, 因此 boost/math/bindings/mpfr.hpp 与 boost/math/bindings/mpreal.hpp 中定义了非常薄的一组附加接口与一些辅助 traits, 你应当用它们代替直接包含 "gmpfrxx.h" 或 "mpreal.h". 包含该头文件后, 类 mpfr_class 或 mpreal 即可原样使用, 例如 mpfr_class 提升性能的表达式模板得以保留并被本库完全支持:

#include <boost/math/bindings/mpfr.hpp>
#include <boost/math/special_functions/gamma.hpp>

int main()
{
   mpfr_class::set_dprec(500); // 500 bit precision
   //
   // Note that the argument to tgamma is
   // an expression template - that's just fine here.
   //
   mpfr_class v = boost::math::tgamma(sqrt(mpfr_class(2)));
   std::cout << std::setprecision(50) << v << std::endl;
}

或者与 mpreal 一起使用的样子是:

#include <boost/math/bindings/mpreal.hpp>
#include <boost/math/special_functions/gamma.hpp>

int main()
{
   mpfr::mpreal::set_precision(500); // 500 bit precision
   mpfr::mpreal v = boost::math::tgamma(sqrt(mpfr::mpreal(2)));
   std::cout << std::setprecision(50) << v << std::endl;
}
