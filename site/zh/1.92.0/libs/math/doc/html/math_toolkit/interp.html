解读这些结果

在下面所有表格中, 每一行中表现最好的结果被赋予相对值“1”并以粗体显示, 因此得分为“2”意味着“比表现最好的结果慢一倍”. 每次函数调用的实际耗时 (纳秒) 也在括号中给出. 为了便于阅读结果, 它们按如下方式着色: 最好的结果以及在其 20% 以内的所有结果为绿色, 比最好结果慢一倍以上的为红色, 介于两者之间的为蓝色.

结果是在一台配备 Intel core i7 4710MQ、16Gb RAM 的机器上获得的, 运行的是 Windows 8.1 或 Xubuntu Linux.

注意

跟通常的性能结果一样, 对这些结果应当大打折扣地看待: 众所周知, 相对性能会因所用测试系统的体系结构不同而有相当大的变化. 此外, 我们的性能结果是使用我们自己的测试数据得到的: 这些测试值旨在良好覆盖我们的代码并测试所有适当的边界情况. 它们未必代表“典型”用法 - 无论那是什么!
