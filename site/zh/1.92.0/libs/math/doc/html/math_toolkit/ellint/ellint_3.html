第三类椭圆积分 - Legendre 形式

概要 
#include <boost/math/special_functions/ellint_3.hpp>

namespace boost { namespace math {

template <class T1, class T2, class T3>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n, T3 phi);

template <class T1, class T2, class T3, class Policy>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n, T3 phi, const Policy&);

template <class T1, class T2>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n);

template <class T1, class T2, class Policy>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n, const Policy&);

}} // namespaces
说明

这两个函数求值第三类不完全椭圆积分 Π(n, φ, k) 及其对应的完全形式 Π(n, k) = E(n, π/2, k).

当参数类型不同时, 这些函数的返回类型使用 结果类型计算规则 计算: 若为相同类型, 则结果与参数类型相同.

template <class T1, class T2, class T3>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n, T3 phi);

template <class T1, class T2, class T3, class Policy>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n, T3 phi, const Policy&);

返回第三类不完全椭圆积分 Π(n, φ, k):

要求 k2sin2(phi) < 1 且 n < 1/sin2(φ), 否则返回 domain_error 的结果 (在此范围之外结果将为复数).

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

template <class T1, class T2>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n);

template <class T1, class T2, class Policy>
BOOST_MATH_CUDA_ENABLED calculated-result-type ellint_3(T1 k, T2 n, const Policy&);

返回第一类完全椭圆积分 Π(n, k):

要求 |k| < 1 且 n < 1, 否则返回 domain_error 的结果 (在此范围之外结果将为复数).

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

精度

这些函数只用基本算术运算计算, 因此在不同平台上精度变化不大. 注意只给出系统上最宽浮点类型的结果, 因为较窄类型具有 实际上为零的误差. 所有数值都是以 epsilon 为单位的相对误差.
