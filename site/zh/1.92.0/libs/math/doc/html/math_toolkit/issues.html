已知问题与 TODO 列表

这主要是一份 TODO 列表, 即可能的未来功能增强清单. 标为“高优先级”的条目影响组件的正常功能, 应尽快修复. 标为“中等优先级”的条目是期望的功能增强, 通常与组件的性能有关, 但不影响其精度或功能. 标为“低优先级”的条目大概应在某个时候调查. 这类分类显然非常主观.

如果这里没有列出某个组件, 说明我们没有关于它的已知问题.

tgamma
  • Lanczos 近似 还能再优化吗? (低优先级)
不完全 Beta
  • 调查 Didonato 和 Morris 针对大 a 和 b 的渐近展开 (中等优先级).
反 Gamma
  • 调查在首次近似足够好时能否完全跳过迭代 (中等优先级).
多项式
  • 考虑到 Legendre 多项式和 Laguerre 多项式只用基本算术运算求值, 它们在不用平台上的误差率差异之大令人惊讶. 也许这说明了什么, 也许并没有 (低优先级).
椭圆积分
  • [para Carlson 算法 (主要是 RJ) 在实参非常大或非常小时, 容易发生内部上溢/下溢. 齐次性关系:] [para RF(ka, kb, kc) = k-1/2 RF(a, b, c)] [para 以及] [para RJ(ka, kb, kc, kr) = k-3/2 RJ(a, b, c, r)] [para 可用来规避这里的问题: 前提是问题区域能被准确识别. (中等优先级).]
  • 还有若干个其他积分: Bulirsch 的 el 函数可以用 Carlson 积分来实现 (低优先级).
  • 积分 K(k) 和 E(k) 可以用有理近似来实现 (既可提高效率也可提高精度), 前提是我们能找到这样的近似. (中等优先级).
Owen 的 T 函数

在任意精度下, 当 a 非常接近 1 时存在一个问题区域. 不过请注意, T(h, 1) 的值是已知的且易于计算, 如果我们把级数 T1、T2 或 T4 中的 ak 项替换为 (ak - 1), 那么我们就得到 T(h, a) 与 T(h, 1) 之差. 遗憾的是, 这并不能改善那些级数在该区域的收敛性. 看起来在该区域用 (1-a)k 表示的新级数既可行又值得期待, 但目前仍难以找到.

统计分布
  • Student's t 或许可以改用正态分布, 作为非常大自由度下的更好近似?
