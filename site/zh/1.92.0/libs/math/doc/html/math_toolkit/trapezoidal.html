梯形求积

概要 

#include <boost/math/quadrature/trapezoidal.hpp>
namespace boost{ namespace math{ namespace quadrature {

template<class F, class Real>
auto trapezoidal(F f, Real a, Real b,
                 Real tol = sqrt(std::numeric_limits<Real>::epsilon()),
                 size_t max_refinements = 12,
                 Real* error_estimate = nullptr,
                 Real* L1 = nullptr);

template<class F, class Real, class Policy>
auto trapezoidal(F f, Real a, Real b, Real tol, size_t max_refinements,
                 Real* error_estimate, Real* L1, const Policy& pol);

}}} // namespaces

说明

泛函 trapezoidal 用出奇简单的梯形法则计算函数 f 的积分. 如果我们只假设被积函数二阶连续可微, 我们可以证明复合梯形法则的误差是 𝑶(h2). 因此把区间减半只能把误差大约缩减为四分之一, 这又意味着在达到可接受的精度之前必须多次求值该函数.

然而, 梯形法则有一个惊人的性质: 如果被积函数是周期的, 并且我们在一个周期上积分它, 那么梯形法则的收敛速度快于步长 h 的任何幂次. 通过考察 Euler-Maclaurin 求和公式 可以看出这一点, 该公式把定积分与其梯形和以及正比于函数在端点处导数和 Bernoulli 数的误差项联系起来. 如果函数在端点处的导数相同或为零, 那么误差几乎消失. 因此对周期被积函数而言, 梯形法则本质上是最优的.

用这种方法可以高效积分的其他被积函数类别有 C0∞(∝) bump 函数 以及无穷区间上的钟形积分. 详情参见 Trefethen 的 SIAM 综述.

以最简单的形式, 积分可以用以下代码完成

using boost::math::quadrature::trapezoidal;
auto f = [](double x) { return 1/(5 - 4*cos(x)); };
double I = trapezoidal(f, 0.0, boost::math::constants::two_pi<double>());

被积函数必须接受实数参数, 但可以返回复数. 这对围线积分 (显然是周期的) 和解析函数的高阶数值微分很有用. 这里展示一个使用复 Bessel 函数积分定义的示例:

auto bessel_integrand = [&n, &z](double theta)->std::complex<double>
{
    std::complex<double> z{2, 3};
    using std::cos;
    using std::sin;
    return cos(z*sin(theta) - 2*theta)/pi<double>();
};

using boost::math::quadrature::trapezoidal;
std::complex<double> Jnz = trapezoidal(bessel_integrand, 0.0, pi<Real>());

其他可以用梯形求积在复平面上高效求值的特殊函数还有修正 Bessel 函数和余误差函数. 复值梯形求积的另一个应用是计算高阶数值导数; 详情参见 Lyness 和 Moler.

由于该例程是自适应的, 步长会不断减半, 直到达到容差. 要控制这个容差, 只需带一个附加参数调用该例程

double I = trapezoidal(f, 0.0, two_pi<double>(), 1e-6);

当积分的相继估计 I1 与 I0 之差小于容差乘以函数估计的 L1 范数时, 该例程停止. 容差的一个好选择是 √ε, 这也是默认值. 如果被积函数是周期的, 那么正确数字的个数应当在每次区间减半时翻倍. 因此, 一旦积分例程估计误差为 √ε, 实际误差应当约为 ε. 如果被积函数 不是 周期的, 那么把误差降到 √ε 需要长得多的时间, 但仍然可行, 而不会成为严重的性能问题.

一个问题是, 当相继估计始终不低于容差阈值时该怎么办. 步长会被反复减半, 导致函数求值次数指数爆炸. 因此, 你可以传入一个可选参数 max_refinements, 控制在放弃之前区间可以被减半多少次. 默认情况下, 这个最大细化步数为 12, 在双精度下除非函数不是周期的, 否则不应触及. 不过, 对更高精度的类型, 让算法进行更多细化可能是有意义的:

size_t max_refinements = 15;
long double I = trapezoidal(f, 0.0L, two_pi<long double>(), 1e-9L, max_refinements);

注意, 允许的最大计算时间随 max_refinements 指数增长. 如果在达到最大细化次数时仍未达到所请求的容差, 该例程不会抛出异常. 这是因为计算出的值通常仍然可用. 但是, 对有高可靠性要求的应用, 应当查询误差估计. 这可以通过向例程传递额外的指针来实现:

double error_estimate;
double L1;
double I = trapezoidal(f, 0.0, two_pi<double>(), tolerance, max_refinements, &error_estimate, &L1);
if (error_estimate > tolerance*L1)
{
     double I = some_other_quadrature_method(f, 0, two_pi<double>());
}

最后一个参数是积分的 L1 范数. 它与积分一起计算, 是算法的一个必要组成部分. 首先, L1 范数确立了一个可以用来度量误差的尺度. 其次, L1 范数可用于评估计算的稳定性. 通过定义 求和条件数 可以严格地表述这一点. 求和条件数定义为

κ(Sn) := Σin |xi|/|Σin xi|

如果这个数约为 10k, 那么除了因浮点舍入误差而丢失的数字之外, 预计还会额外丢失 k 位数字. 由于所有数值求积方法都归结为求和, 它们的稳定性由比值 ∫ |f| dt/|∫ f dt | 控制, 不难看出在数值求值时它等价于求和条件数. 因此, 在要求极高精度和可靠性的应用中, 应当同时分析误差估计和求和条件数.

作为一个例子, 我们考虑用梯形求积求值 Bessel 函数. 第一类 Bessel 函数定义为

Jn(x) = 1/2Π ∫-ΠΠ cos(n t - x sin(t)) dt

被积函数是周期的, 因此 Euler-Maclaurin 求和公式保证梯形求积有指数收敛性. 不加仔细考虑的话, 这似乎是一种非常有吸引力的计算 Bessel 函数的方法. 然而, 我们看到, 对大的 n, 被积函数快速振荡, 取正值和负值, 因此梯形和变得病态. 在双精度下, x = 17 和 n = 25 得到的和病态如此严重, 以至于得不到任何正确的数字.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.
