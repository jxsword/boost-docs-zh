typeinfo

对 GCC 4.8.1, 还无法在 GCC 上用 typeinfo 表示 float_128: 见 GCC 43622.

因此这段 (显示重整修饰名的) 代码链接失败 undefined reference to typeinfo for __float128 

std::cout << typeid(boost::float128_t).name() << std::endl;

这妨碍了对 Boost.Math 分布使用现有测试 (除非注释掉几行), 而且如果定义了控制它们的宏 BOOST_MATH_INSTRUMENT, Boost.Math 中的某些诊断显示将无法工作.

不过这只用于显示目的, 在 GCC 5 修复之前可以注释掉.

提示

并非所有受管名字都能显示 (用 std::cout).
