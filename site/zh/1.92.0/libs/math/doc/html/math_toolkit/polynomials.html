   template <class U>
   polynomial& operator -=(const U& value);

   polynomial& operator *=(const U& value);

说明

这是一个用于多项式操作的略显平凡的类.

参见

  • Polynomial 以及
  • Donald E. Knuth, The Art of Computer Programming: Volume 2, Third edition, (1998) Chapter 4.6.1, Algorithm D: Division of polynomials over a field.

目前的实现属于"朴素"类型, 例如使用 𝑶(N2) 的乘法. 该类不应在高性能计算环境中使用: 它旨在对小型多项式 (通常为特殊函数近似而生成) 进行简单操作.

它确实为 域 (此处为浮点、复数等) 上的多项式和唯一分解域 (整数) 上的多项式提供了除法. 域上多项式的除法与 Euclidean GCD 兼容.

UFD 上多项式的除法与用于 GCD 的子结式算法 (实现为 subresultant_gcd) 兼容, 但必须郑重警告: 该算法的中间值膨胀会非常容易导致单精度整数类型上溢. 因此, 尽管该算法可以在单精度整数类型上工作, gcd 函数的重载只针对多精度整数类型的多项式提供, 以避免糟糕的意外. 这通过相当粗糙地为非 POD 整数类型禁用该重载来实现.

高级操作: FFT、因式分解等目前未提供. 当然欢迎提交 :-)

多项式算术示例

首先包含基本的多项式头文件 (以及其他头文件) 来构建示例:

#include <boost/math/tools/polynomial.hpp>

一些 using 语句会带来方便:

using std::string;
using std::exception;
using std::cout;
using std::abs;
using std::pair;

using namespace boost::math;
using namespace boost::math::tools; // for polynomial
using boost::lexical_cast;

以方便访问的方式存储系数, 然后使用从迭代器范围构造的方式创建一些多项式, 最后以"美观"的公式格式输出.

提示

尽管我们习惯上按次数降序从左到右书写多项式, 但 Boost.Math 以 次数升序 存储.

Read/write for humans:    3x^3 - 4x^2 - 6x + 10
Boost polynomial storage: [ 10, -6, -4, 3 ]

std::array<double, 4> const d3a = {{10, -6, -4, 3}};
polynomial<double> const a(d3a.begin(), d3a.end());

// With C++11 and later, you can also use initializer_list construction.
polynomial<double> const b{{-2.0, 1.0}};

// formula_format() converts from Boost storage to human notation.
cout << "a = " << formula_format(a)
<< "\nb = " << formula_format(b) << "\n\n";

输出为:

a = 3x^3 - 4x^2 - 6x + 10
b = x - 2

// Now we can do arithmetic with the usual infix operators: + - * / and %.
polynomial<double> s = a + b;
cout << "a + b = " << formula_format(s) << "\n";
polynomial<double> d = a - b;
cout << "a - b = " << formula_format(d) << "\n";
polynomial<double> p = a * b;
cout << "a * b = " << formula_format(p) << "\n";
polynomial<double> q = a / b;
cout << "a / b = " << formula_format(q) << "\n";
polynomial<double> r = a % b;
cout << "a % b = " << formula_format(r) << "\n";

输出为

a + b = 3x^3 - 4x^2 - 5x + 8
a - b = 3x^3 - 4x^2 - 7x + 12
a * b = 3x^4 - 10x^3 + 2x^2 + 22x - 20
a / b = 3x^2 + 2x - 2
a % b = 6
除法、商与余数

除法是一种可以一石二鸟的特殊情形.

实际上, 由于算法的性质, 商和余数总是被一起计算: 中缀运算符返回其中一个结果并丢弃另一个.

如果你进行大量除法运算且同时需要商和余数, 那么你不会想把必要的工作做两遍.

在这种情况下, 你可以调用底层函数 quotient_remainder, 将两个结果作为一个对一起获得.

  pair< polynomial<double>, polynomial<double> > result;
  result = quotient_remainder(a, b);
// Reassure ourselves that the result is the same.
  BOOST_MATH_ASSERT(result.first == q);
  BOOST_MATH_ASSERT(result.second == r);
