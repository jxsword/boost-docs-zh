说明

函数 hypergeometric_pFq 返回如下结果:

它最自然的使用方式是通过初始化列表, 如下:

double h = hypergeometric_pFq({2,3,4}, {5,6,7,8}, z);  // Calculate 3F4

可选的 p_abs_error 实参根据求和的 L1 范数以及其他一些因素, 估算结果中的绝对误差 (见下文实现).

应将该值除以结果, 以得到 相对误差 的估计.

需要注意, 这些误差估计相当粗略 - 在某些情况下误差可能被显著低估, 而在另一些情况下则被高估.

hypergeometric_pFq_precision 函数会把 pFq 计算到指定的小数位数, 若达到 timeout 则抛出 evaluation_error. 注意, 尽管这些函数定义为模板, 但它们要求类型 Real 是 可变精度 浮点类型: 实际上 (截至 2019 年 7 月) 目前唯一支持的类型是 boost::multiprecision::mpfr_float. 典型用法如下:

typedef boost::multiprecision::mpfr_float mp_type;
//
// Calculate 2F2 to 20 decimal places using a 10 second timeout:
//
mp_type result = boost::math::hypergeometric_pFq_precision(
  { mp_type(a1), mp_type(a2) }, { mp_type(b1), mp_type(b2) }, mp_type(z), 20, 10.0
  );
//
// Convert the result back to a double:
//
double d_result = static_cast<double>(result);
实现

该函数通过对级数直接求和来实现; 求和通常从第零项开始, 但在需要时会从某一项 N 向前跳过并向两侧展开求和 (即同时沿正向和反向). 当部分 b 实参为负数时, 这一点尤为重要, 因为在这种情况下求和会经历“假收敛”, 随后每当每个 bj 越过原点时又会再次发散. 因此, 假如画出求和各项的幅值, 你会看到它们经过一系列极小值和极大值, 最终在无穷远处收敛到零. 对某些 p 和 q 取值, 我们可以算出极大值出现的位置, 从而只对结果有影响的那些项求和. 对其他 p 和 q 取值, 预测极大值的确切位置就不那么容易了, 我们只是在每个 bj 越过原点处重新开始求和: 这最终会覆盖求和的所有重要项, 但关键词很可能是“最终”.

误差项 p_abs_error 通常只是各项绝对值之和乘以类型 Real 的机器 epsilon. 然而, 如果求和必须向前跳过, 则会调整 p_abs_error 以计入通过对数计算第 N 项所固有的误差.
