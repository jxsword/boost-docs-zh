Laplace 分布 

#include <boost/math/distributions/laplace.hpp>

template <class RealType = double,
          class Policy   = policies::policy<> >
class laplace_distribution;

typedef laplace_distribution<> laplace;

template <class RealType, class Policy>
class laplace_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;
   // Construct:
   BOOST_MATH_GPU_ENABLED laplace_distribution(RealType location = 0, RealType scale = 1);

}} // namespaces

Laplace 分布是两个具有相同指数分布的独立变量之差的分布 (Abramowitz and Stegun 1972, p. 930). 它也称为双指数分布.

对于位置参数 μ 与尺度参数 σ , 它由概率密度函数定义:

位置参数与尺度参数分别等价于正态分布 (高斯分布) 的均值与标准差.

成员函数 
BOOST_MATH_GPU_ENABLED laplace_distribution(RealType location = 0, RealType scale = 1);

构造一个 laplace 分布, 位置为 location, 尺度为 scale.

位置参数与随机变量的均值相同.

尺度参数与随机变量的标准差成正比.

要求尺度参数大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType location()const;

返回此分布的 location 参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的scale参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [-∞,+∞].

在此分布中, logcdf 和 logpdf 的实现都做了专门化以提升数值精度.

精度

laplace 分布借助标准库的 log 与 exp 函数实现, 因此误差应当非常小.

实现

在下表中, μ 是分布的位置参数, σ 是其尺度参数, x 是随机变量, p 是概率, 其补为 q = 1-p.

函数

实现说明

pdf

使用关系式: pdf = e-abs(x-μ) / σ / (2 * σ)

logpdf

log(pdf) = -abs(x-μ)/σ - log(σ) - log(2)

cdf

利用关系:

x < μ 时: p = e(x-μ)/σ / σ

x >= μ 时: p = 1 - e(μ-x)/σ / σ

logcdf

log(cdf) =

x < μ 时: p = ((x - μ) / σ) - ln(2)

x >= μ 时: p = log1p(-exp((μ-x) / σ) / 2)

cdf 补函数

利用关系:

-x < μ 时: q = e(-x-μ)/σ / σ

-x >= μ 时: q = 1 - e(μ+x)/σ / σ

quantile

利用关系:

p < 0.5 时: x = μ + σ * log(2*p)

p >= 0.5 时: x = μ - σ * log(2-2*p)

由补函数求 quantile

利用关系:

q > 0.5 时: x = μ + σ*log(2-2*q)

q <=0.5 时: x = μ - σ*log( 2*q )
