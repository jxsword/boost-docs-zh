使用 Boost.Multiprecision 求根

到了这一步, 假定精明的读者可能会问: "我们怎么知道这算出的是'正确'答案?"

遗憾的是, 对大多数值而言, 并不存在'正确'答案. 这是因为值很少能被 C++ 浮点类型 精确表示. 我们真正想要的是'最佳'表示 - 即最接近的 可表示值. (关于数字如何表示的更多信息, 参见 Floating point).

当然, 我们可以像上面那样先找一个外部参考来源, 如 Wolfram Alpha, 但这并非总是可行.

另一种令人安心的方法是以更高精度计算"参考"值, 用于比较我们使用 double 等内置类型进行迭代计算的结果. 它们应在设定的容差内一致.

static_cast (转换) 到 double 的结果, 当源类型是 cpp_bin_float_50 这类更高精度类型时, 保证为 最接近的可表示 double 值.

例如, 我们示例中针对 cbrt(28.) 的立方根函数计算

std::cbrt<double>(28.) = 3.0365889718756627

WolframAlpha 说 3.036588971875662519420809578505669635581453977248111123242141...

static_cast<double>(3.03658897187566251942080957850) = 3.0365889718756627

这个示例 cbrt(28.) = 3.0365889718756627

提示

要确保显示所有可能有效的十进制数字, 请使用 std::numeric_limits<T>::max_digits10 (如果在不支持它的旧平台或编译器上, 请使用 2+std::numeric_limits<double>::digits*3010/10000).

理想情况下, 值应在 std::numeric-limits<T>::digits10 位十进制数字内一致.

这也意味着要 输入 或 static_cast 的"参考"值至少应有 max_digits10 位十进制数字 (64 位 double 为 17 位).

如果我们希望计算 更高精度的值, 那么在某些平台上, 我们或许可以使用 long double, 其精度高于 double, 以便与非常常见的 double 比较和/或与更高效的内置 quad 浮点类型 (如 __float128) 比较.

几乎所有平台都可以轻松使用 Boost.Multiprecision, 例如 cpp_dec_float 或二进制类型 cpp_bin_float, 以非常高的精度计算值.

注释

对多精度类型, 是否使用类型 T 来计算初始猜测是有争议的. 类型 double 对这些示例中用的方法而言足够精确. 这会把可能值的指数范围限制在 double 的范围内. 还有与类型 T 相互转换的成本要考虑. 在这些示例中, double 通过 typedef double guess_type 使用.

由于上面使用的函子和函数以值类型为模板参数, 我们可以非常简单地把它们与任何 Boost.Multiprecision 类型一起使用. 提醒一下, 下面是我们的"玩具"立方根函数, 使用 2 个导数和 C++11 lambda 函数求根:

template <class T>
T cbrt_2deriv_lambda(T x)
{
   // return cube root of x using 1st and 2nd derivatives and Halley.
   //using namespace std;  // Help ADL of std functions.
   using namespace boost::math::tools;
   int exponent;
   frexp(x, &exponent);                                // Get exponent of z (ignore mantissa).
   T guess = ldexp(1., exponent / 3);                    // Rough guess is to divide the exponent by three.
   T min = ldexp(0.5, exponent / 3);                     // Minimum possible value is half our guess.
   T max = ldexp(2., exponent / 3);                      // Maximum possible value is twice our guess.
   const int digits = std::numeric_limits<T>::digits;  // Maximum possible binary digits accuracy for type T.
   // digits used to control how accurate to try to make the result.
   int get_digits = static_cast<int>(digits * 0.4);    // Accuracy triples with each step, so stop when just
   // over one third of the digits are correct.
   std::uintmax_t maxit = 20;
   T result = halley_iterate(
      // lambda function:
      [x](const T& g){ return std::make_tuple(g * g * g - x, 3 * g * g, 6 * g); },
      guess, min, max, get_digits, maxit);
   return result;
}

下面的示例是 50 位十进制的十进制和二进制类型 (以及在某些平台上快得多的 float128 或 quad_float 类型), 我们可以把它们与这些 include 一起使用:

#include <boost/multiprecision/cpp_bin_float.hpp> // For cpp_bin_float_50.
#include <boost/multiprecision/cpp_dec_float.hpp> // For cpp_dec_float_50.
#ifndef _MSC_VER  // float128 is not yet supported by Microsoft compiler at 2013.
#  include <boost/multiprecision/float128.hpp> // Requires libquadmath.
#endif

一些 using 语句简化它们的使用:

  using boost::multiprecision::cpp_dec_float_50; // decimal.
  using boost::multiprecision::cpp_bin_float_50; // binary.
#ifndef _MSC_VER  // Not supported by Microsoft compiler.
  using boost::multiprecision::float128;
#endif

它们可以如下使用:

std::cout.precision(std::numeric_limits<cpp_dec_float_50>::digits10);

cpp_dec_float_50 two = 2; // 
cpp_dec_float_50  r = cbrt_2deriv(two);
std::cout << "cbrt(" << two << ") = " << r << std::endl;

r = cbrt_2deriv(2.); // Passing a double, so ADL will compute a double precision result.
std::cout << "cbrt(" << two << ") = " << r << std::endl;
// cbrt(2) = 1.2599210498948731906665443602832965552806854248047 'wrong' from digits 17 onwards!
r = cbrt_2deriv(static_cast<cpp_dec_float_50>(2.)); // Passing a cpp_dec_float_50, 
// so will compute a cpp_dec_float_50 precision result.
std::cout << "cbrt(" << two << ") = " << r << std::endl;
r = cbrt_2deriv<cpp_dec_float_50>(2.); // Explicitly a cpp_dec_float_50, so will compute a cpp_dec_float_50 precision result.
std::cout << "cbrt(" << two << ") = " << r << std::endl;
// cpp_dec_float_50 1.2599210498948731647672106072782283505702514647015

由 Wolfram Alpha 计算的参考值是

N[2^(1/3), 50]  1.2599210498948731647672106072782283505702514647015

它完全一致.

要 显示 值的完整精度, 需要调整 std::ostream precision 以适合该类型, 例如:

template <typename T>
T show_cube_root(T value)
{ // Demonstrate by printing the root using all definitely significant digits.
  std::cout.precision(std::numeric_limits<T>::digits10);
  T r = cbrt_2deriv(value);
  std::cout << "value = " << value << ", cube root =" << r << std::endl;
  return r;
}

show_cube_root(2.);
show_cube_root(2.L);
show_cube_root(two);

其输出为:

cbrt(2) = 1.2599210498948731647672106072782283505702514647015

value = 2, cube root =1.25992104989487
value = 2, cube root =1.25992104989487
value = 2, cube root =1.2599210498948731647672106072782283505702514647015
提示

请 务必非常小心 传递给求根函数的浮点类型 T. 通过写 cpp_dec_float_50 r = cbrt_2deriv(2); 或 show_cube_root(2); 而不小心传入整数会引发大量警告和编译错误.

甚至 show_cube_root(2.F); 也会产生警告, 因为 typedef double guess_type 把用于计算 guess 和 bracket 值的类型定义为 double.

更隐蔽的是传入一个 double, 如 cpp_dec_float_50 r = cbrt_2deriv(2.);, 它会无声地给出'错误'结果: 先计算一个 double 结果, 然后 转换为 cpp_dec_float_50! max_digits10 之外的所有数字都将不正确. 把 cbrt 类型通过 cbrt_2deriv<cpp_dec_float_50>(2.); 显式化, 将得到期望的 50 位十进制精度的结果.

本示例的完整代码位于 root_finding_multiprecision_example.cpp.
