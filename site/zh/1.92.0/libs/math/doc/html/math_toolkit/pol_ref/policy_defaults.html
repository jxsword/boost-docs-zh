使用宏更改策略默认值

你可以使用下面的各种宏来更改任何 (或全部) 策略.

你可以在函数或分布的 #include 之前 放置宏定义来进行局部更改.

注意

如果向多个源文件添加临时宏, 存在违反单一定义规则 (One-Definition-Rule) 的危险: 必须在 每个编译单元 中设置为相同.

注意

如果把它放在 #include 之后, 它将没有任何效果 (而且只影响其后的其他 #include). 这可能不是你想要的!

如果你想以安装级的方式为 所有 函数和分布更改任何或全部策略的默认值, 可以通过在 boost/math/tools/user.hpp 中定义各种宏来实现.

BOOST_MATH_DOMAIN_ERROR_POLICY

定义发生定义域错误时的行为, 未定义时默认为 throw_on_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_POLE_ERROR_POLICY

定义发生极点错误时的行为, 未定义时默认为 throw_on_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_OVERFLOW_ERROR_POLICY

定义发生上溢错误时的行为, 未定义时默认为 throw_on_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_ROUNDING_ERROR_POLICY

定义发生舍入错误时的行为, 未定义时默认为 throw_on_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_EVALUATION_ERROR_POLICY

定义发生内部求值错误时的行为, 未定义时默认为 throw_on_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_UNDERFLOW_ERROR_POLICY

定义发生上溢错误时的行为, 未定义时默认为 ignore_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_DENORM_ERROR_POLICY

定义发生非规格化错误时的行为, 未定义时默认为 ignore_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_INDETERMINATE_RESULT_ERROR_POLICY

定义结果不确定时的行为, 尽管结果仍存在某种约定. 未定义时默认为 ignore_error, 但可设置为错误处理的任何枚举行动: throw_on_error、errno_on_error、ignore_error 或 user_error.

BOOST_MATH_DIGITS10_POLICY

定义内部计算使用的十进制位数: 默认为 0 - 意味着使用所有可用位数 - 但可以设置为其他十进制值. 由于设置此项可能对精度产生重大影响, 一般不建议将它从默认值更改.

BOOST_MATH_PROMOTE_FLOAT_POLICY

决定 float 类型是否在内部提升为 double 以确保结果的最大精度, 默认为 true, 但可以设置为 false 以关闭 float 的提升.

BOOST_MATH_PROMOTE_DOUBLE_POLICY

决定 double 类型是否在内部提升为 long double 以确保结果的最大精度, 默认为 true, 但可以设置为 false 以关闭 double 的提升.

BOOST_MATH_DISCRETE_QUANTILE_POLICY

决定离散分位数如何返回结果: 以整数还是实数值, 可设置为枚举值之一: real、integer_round_outwards、integer_round_inwards、integer_round_down、integer_round_up、integer_round_nearest. 默认为 integer_round_outwards.

BOOST_MATH_ASSERT_UNDEFINED_POLICY

决定对特定分布在数学上未定义的函数是编译通过还是引发静态 (即编译期) 断言. 默认为 true: 意味着任何数学上未定义的函数都无法编译. 设为 false 时, 函数会编译但返回定义域错误的结果: 这对某些泛型代码很有用, 那些代码需要与所有分布一起工作并在运行期判定某个特定性质是否有定义.

BOOST_MATH_MAX_SERIES_ITERATION_POLICY

决定特殊函数在放弃并返回 evaluation_error 之前允许执行的级数迭代次数: 默认为 1000000.

BOOST_MATH_MAX_ROOT_ITERATION_POLICY

决定特殊函数在放弃并返回 evaluation_error 之前允许执行的求根迭代次数: 默认为 200.

示例

假设我们希望上溢错误设置 ::errno 并返回无穷大, 离散分位数返回实数值结果 (而不是舍入为整数), 并且数学上未定义的函数能编译但返回定义域错误. 那么可以在 boost/math/tools/user.hpp 中加入以下内容:

#define BOOST_MATH_OVERFLOW_ERROR_POLICY errno_on_error
#define BOOST_MATH_DISCRETE_QUANTILE_POLICY real
#define BOOST_MATH_ASSERT_UNDEFINED_POLICY false

或者我们可以把这些定义 放在源 .cpp 文件中如下内容之前 

#include <boost/math/distributions/normal.hpp>
  using boost::math::normal_distribution;

.
