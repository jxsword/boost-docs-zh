概述

四元数是复数的近亲.

四元数实际上是建立在实数之上的一个小结构层级的一部分, 该层级只包含实数集合 (传统上记为 R)、复数集合 (传统上记为 C)、四元数集合 (传统上记为 H) 以及八元数集合 (传统上记为 O), 它们拥有有趣的数学性质 (其中最主要的是它们是 可除代数, 即 下述性质成立: 如果 y 是该代数的一个元素且 不等于零, 那么 yx = yx', 其中 x 和 x' 表示该代数的元素, 蕴含 x = x'). 该层级的每个成员都是前一个成员的超集.

四元数最重要的方面之一是它们提供了一种在 R3 (通常的三维空间) 和 R4 中参数化旋转的高效方式.

实际而言, 四元数只是四个实数 (α,β,γ,δ) 的四元组, 我们可以将其写作 q = α + βi + γj + δk 的形式, 其中 i 与复数中的对象相同, 而 j 和 k 是不同的对象, 它们所扮演的角色与 i 本质上属于同一类.

在四元数集合上定义了加法和乘法, 它们是实数和复数对应运算的推广. 这里的主要新颖之处在于 乘法不满足交换律 (即存在四元数 x 和 y 使得 xy ≠ yx). 帮助记忆的一种好方法是使用公式 i*i = j*j = k*k = -1.

四元数 (及其同类) 在另一份 document (含 errata and addenda) 中有详细得多的描述.

一些传统构造, 例如指数, 无需太多改变即可延拓到四元数领域, 但其他一些, 例如取平方根, 则不行.
