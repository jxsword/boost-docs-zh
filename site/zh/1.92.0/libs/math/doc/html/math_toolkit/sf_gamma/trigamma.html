Trigamma

概要 
#include <boost/math/special_functions/trigamma.hpp>

namespace boost{ namespace math{

template <class T>
BOOST_MATH_GPU_ENABLED calculated-result-type trigamma(T x);

template <class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type trigamma(T x, const Policy&);

}} // namespaces
说明

返回 x 的 trigamma 函数. Trigamma 定义为 digamma 函数的导数:

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

本函数的返回类型使用 结果类型计算规则 计算: 当 T 是整数类型时, 结果类型为 double; 否则为类型 T.
