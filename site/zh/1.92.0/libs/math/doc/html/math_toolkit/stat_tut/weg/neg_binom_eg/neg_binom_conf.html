计算负二项分布发生频率的置信限

设想有一个服从负二项分布的过程: 对每次进行的试验, 一个事件要么发生要么不发生, 分别称为 "成功" 和 "失败". 成功发生的频率有多种称呼: 成功分数、成功率、成功百分比、发生频率或发生概率.

如果想通过实验测量, 成功分数的最佳估计由 k / N 简单给出, 其中 k 是 N 次试验中的成功次数.

然而, 我们对这一估计的信心取决于进行了多少次试验、观察到了多少次成功. 静态成员函数 negative_binomial_distribution<>::find_lower_bound_on_p 和 negative_binomial_distribution<>::find_upper_bound_on_p 允许你为成功分数的估计计算置信区间.

示例程序 neg_binom_confidence_limits.cpp 展示了它们的用法.

首先, 我们需要一些 include 来访问负二项分布 (当然还有一些基本 std 输出).

#include <boost/math/distributions/negative_binomial.hpp>
using boost::math::negative_binomial;

#include <iostream>
using std::cout; using std::endl;
#include <iomanip>
using std::setprecision;
using std::setw; using std::left; using std::fixed; using std::right;

首先定义一个显著性水平表: 这些是真实发生频率落在计算区间之外的概率:

double alpha[] = { 0.5, 0.25, 0.1, 0.05, 0.01, 0.001, 0.0001, 0.00001 };

以百分比表示的置信值为 (1 - alpha) * 100, 因此 alpha 0.05 == 95% 的置信度认为真实发生频率落在计算区间 之内.

我们需要一个函数, 为服从负二项分布的观测发生频率计算并打印置信限.

void confidence_limits_on_frequency(unsigned trials, unsigned successes)
{
   // trials = Total number of trials.
   // successes = Total number of observed successes.
   // failures = trials - successes.
   // success_fraction = successes /trials.
   // Print out general info:
   cout <<
      "______________________________________________\n"
      "2-Sided Confidence Limits For Success Fraction\n"
      "______________________________________________\n\n";
   cout << setprecision(7);
   cout << setw(40) << left << "Number of trials" << " =  " << trials << "\n";
   cout << setw(40) << left << "Number of successes" << " =  " << successes << "\n";
   cout << setw(40) << left << "Number of failures" << " =  " << trials - successes << "\n";
   cout << setw(40) << left << "Observed frequency of occurrence" << " =  " << double(successes) / trials << "\n";

   // Print table header:
   cout << "\n\n"
           "___________________________________________\n"
           "Confidence        Lower          Upper\n"
           " Value (%)        Limit          Limit\n"
           "___________________________________________\n";

现在到了重要的部分——界限本身. 对每个 alpha 值, 我们调用 find_lower_bound_on_p 和 find_upper_bound_on_p 分别获得下界和上界. 注意, 由于我们计算的是双侧区间, 必须把 alpha 的值一分为二. 假如我们计算的是单侧区间, 例如: "计算一个下界, 使我们有 P% 的把握确信真实发生频率大于某个值", 那么我们 就不会 除以 2.

   // Now print out the upper and lower limits for the alpha table values.
   for(unsigned i = 0; i < sizeof(alpha)/sizeof(alpha[0]); ++i)
   {
      // Confidence value:
      cout << fixed << setprecision(3) << setw(10) << right << 100 * (1-alpha[i]);
      // Calculate bounds:
      double lower = negative_binomial::find_lower_bound_on_p(trials, successes, alpha[i]/2);
      double upper = negative_binomial::find_upper_bound_on_p(trials, successes, alpha[i]/2);
      // Print limits:
      cout << fixed << setprecision(5) << setw(15) << right << lower;
      cout << fixed << setprecision(5) << setw(15) << right << upper << endl;
   }
   cout << endl;
} // void confidence_limits_on_frequency(unsigned trials, unsigned successes)

然后以递增的试验次数、但始终相同的成功分数 0.1 (即 10 次中 1 次) 调用 confidence_limits_on_frequency.

int main()
{
  confidence_limits_on_frequency(20, 2); // 20 trials, 2 successes, 2 in 20, = 1 in 10 = 0.1 success fraction.
  confidence_limits_on_frequency(200, 20); // More trials, but same 0.1 success fraction.
  confidence_limits_on_frequency(2000, 200); // Many more trials, but same 0.1 success fraction.

  return 0;
} // int main()
