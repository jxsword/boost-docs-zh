Cauchy-Lorentz 分布 

#include <boost/math/distributions/cauchy.hpp>
template <class RealType = double,
          class Policy   = policies::policy<> >
class cauchy_distribution;

typedef cauchy_distribution<> cauchy;

template <class RealType, class Policy>
class cauchy_distribution
{
public:
   typedef RealType  value_type;
   typedef Policy    policy_type;

   BOOST_MATH_GPU_ENABLED cauchy_distribution(RealType location = 0, RealType scale = 1);

   BOOST_MATH_GPU_ENABLED RealType location()const;
   BOOST_MATH_GPU_ENABLED RealType scale()const;
};

Cauchy-Lorentz distribution 以 Augustin Cauchy 和 Hendrik Lorentz 命名. 它是一种连续概率分布, 其概率分布函数 PDF由下式给出:

位置参数 x0 是分布峰值的位置 (即分布的众数), 而尺度参数 γ 规定 PDF 在半最大高度处的半宽. 若位置为零、尺度为 1, 则结果为标准 Cauchy 分布.

该分布在物理学中很重要, 因为它是描述受迫共振的微分方程的解; 在光谱学中, 它描述谱线的线型.

成员函数 
BOOST_MATH_GPU_ENABLED cauchy_distribution(RealType location = 0, RealType scale = 1);

构造一个 Cauchy 分布, 位置参数为 location, 尺度参数为 scale. 当这些参数取默认值 (location = 0, scale = 1) 时, 结果为标准 Cauchy 分布.

要求 scale > 0, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType location()const;

返回分布的位置参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回分布的尺度参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

但请注意, Cauchy 分布没有均值、标准差等. 参见 mathematically undefined function 以控制这些函数是否应以 BOOST_STATIC_ASSERTION_FAILURE 编译失败 (这是默认行为).

或者, 函数 mean, standard deviation, variance, skewness, kurtosis 和 kurtosis_excess 若被调用, 都会返回 domain_error.

随机变量的定义域是 [-[max_value], +[min_value]].

精度

Cauchy 分布以标准库的 tan 和 atan 函数实现, 因此误差率应非常低.

实现

在下表中, x0 是分布的位置参数, γ 是其尺度参数, x 是随机变量, p 是概率, q = 1-p 为其补.

函数

实现说明

pdf

利用关系: pdf = 1 / (π * γ * (1 + ((x - x0 ) / γ)2))

cdf 及其补

cdf 通常由下式给出:

p = 0.5 + atan(x)/π

但当 x → -∞ 时它会出现消去误差.

因此改用基于 atan2 函数的数学等价表达式:

p = atan2(1, -x)/π

由对称性, 补函数为

q = atan2(1, x)/π

quantile

无论从概率还是其补出发, 都采用相同的过程. 首先把实参 p 缩减到范围 [-0.5, 0.5], 然后用关系式

x = x0 ± γ / tan(π * p)

来得到结果. 是从 x0 加还是减, 取决于我们是否从补函数出发.
