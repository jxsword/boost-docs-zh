sinhc_pi 

#include <boost/math/special_functions/sinhc.hpp>

template<class T>
BOOST_MATH_GPU_ENABLED calculated-result-type sinhc_pi(const T x);

template<class T, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type sinhc_pi(const T x, const Policy&);

template<typename T, template<typename> class U>
U<T> sinhc_pi(const U<T> x);

template<class T, template<typename> class U, class Policy>
U<T> sinhc_pi(const U<T> x, const Policy&);

计算 sinhc 函数, 即 x 的 双曲基数正弦:

sinhc_pi(x) = sinh(x) / x

第二种形式用于复数、四元数、八元数等. 在原点处使用 Taylor 级数以保证精度.

当 T 为整数类型时, 第一种形式的返回类型使用 结果类型计算规则 计算.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.
