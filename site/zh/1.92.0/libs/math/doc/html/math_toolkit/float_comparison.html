浮点比较

浮点值的比较一直是无穷无尽的困难与困惑之源.

与精确的整数值不同, 所有浮点运算都可能产生不精确的结果, 该结果会被舍入到最接近的可用二进制表示. 甚至看似无害的操作, 例如把 0.1 赋给 double, 也会产生不精确的结果 (因为这个十进制数没有精确的二进制表示).

浮点计算还涉及舍入, 因此会引入一些"计算噪声", 结果同样不是精确的 (尽管至少在相同平台与编译选项下是可重复的).

遗憾的是, 这与大多数用户的期望相冲突, 正如许多文章与无数求救帖子所清楚展示的那样.

一些背景阅读材料:

  • Knuth D.E. 《计算机程序设计艺术》第 II 卷 4.2 节, 尤其是"浮点数比较" 4.2.2, 第 198-220 页.
  • David Goldberg, "What Every Computer Scientist Should Know About Floating-Point Arithmetic"
  • Alberto Squassabia, Comparing floats listing
  • Google Floating-Point_Comparison guide
  • Boost.Test Floating-Point_Comparison

Boost 提供了多种比较浮点值以判断它们是否足够接近的方法, 但首先我们必须决定需要哪种比较:

  • 绝对差/误差: 两个值 a 与 b 的绝对差就是 fabs(a-b). 如果我们知道结果可能有抵消误差 (见下文), 这是唯一有意义的比较方式.
  • 两个值之间的编辑距离: 即两个值 a 与 b 之间相隔多少个 (二进制) 浮点值? 这由函数 Boost.Math float_distance 提供, 但可能仅在你已知距离应当非常小时才有用. 该函数的计算有些困难, 且不能扩展到相距非常远的值. 换句话说, 使用时要小心.
  • 两个值之间的相对距离/误差. 这种方法计算快速简便, 通常是检查结果之间是否"足够接近"的首选方法. 然而, 在处理微小差异时它不如编辑距离精确, 并且由于浮点值的编码方式, 相比"真实"编辑距离它可能会有 2 倍的"摆动". 这是下文记录的方法: 如果 float_distance 是外科医生的手术刀, 那么 relative_difference 更像一把瑞士军刀: 两者都有重要但不同的用例.
浮点值的相对比较

#include <boost/math/special_functions/relative_difference.hpp> 

template <class T, class U>
calculated-result-type relative_difference(T a, U b);

template <class T, class U>
calculated-result-type epsilon_difference(T a, U b);

函数 relative_difference 返回两个值之间按下式定义的相对距离/误差 E:

E = fabs((a - b) / min(a,b))

函数 epsilon_difference 是一个便捷函数, 返回 relative_difference(a, b) / eps, 其中 eps 是结果类型的机器 epsilon.

以下特例按如下方式处理:

  • 若 a 或 b 之一是 NaN, 则返回 T 可表示的最大值: 例如对类型 double, 这是 std::numeric_limits<double>::max(), 与 DBL_MAX 或 1.7976931348623157e+308 相同.
  • 若 a 与 b 符号不同, 则返回 T 可表示的最大值.
  • 若 a 与 b 都是无穷大 (同号), 则返回零.
  • 若 a 与 b 中只有一个是无穷大, 则返回 T 可表示的最大值.
  • 若 a 与 b 都为零, 则返回零.
  • 若 a 或 b 中只有一个是零或非规格化值, 则为进行上述计算, 它被视为 T 中可表示的最小 (非规格化) 值.

这些规则主要为辅助我们自己的测试套件而设计, 它们足够稳健, 大多数情况下可以放心盲目使用, 包括预期结果实际上小到无法用类型 T 表示并下溢为零的情形.

示例

一些 using 语句将确保我们需要的函数可访问.

using namespace boost::math;

或者

using boost::math::relative_difference;
using boost::math::epsilon_difference;
using boost::math::float_next;
using boost::math::float_prior;

以下示例显示所有可能有意义的数字的值. 较新的编译器应为此目的提供 std::numeric_limits<FPT>::max_digits10, 这里我们使用 float 精度, 其中 max_digits10 = 9, 以避免显示令人分心的十进制数字位数.

注释

较旧的编译器可以用这个公式计算 max_digits10, 源为 std::numeric_limits<FPT>::digits10: int max_digits10 = 2 + std::numeric_limits<FPT>::digits10 * 3010/10000;

可以设置显示包括所有末尾零 (对本示例有助于显示所有可能有意义的数字), 也可以把 bool 值显示为文字而不是整数:

std::cout.precision(std::numeric_limits<float>::max_digits10);
std::cout << std::boolalpha << std::showpoint << std::endl;

当比较相当接近或近似相等的值时, 我们可以用 float_distance 或 relative_difference/epsilon_difference, 例如对类型 float, 下面这两个值彼此相邻:

float a = 1;
float b = 1 + std::numeric_limits<float>::epsilon();
std::cout << "a = " << a << std::endl;
std::cout << "b = " << b << std::endl;
std::cout << "float_distance = " << float_distance(a, b) << std::endl;
std::cout << "relative_difference = " << relative_difference(a, b) << std::endl;
std::cout << "epsilon_difference = " << epsilon_difference(a, b) << std::endl;

产生的输出为:

a = 1.00000000
b = 1.00000012
float_distance = 1.00000000
relative_difference = 1.19209290e-007
epsilon_difference = 1.00000000

在上面的示例中, 恰好 float_distance 度量的编辑距离与以 epsilon 为单位度量的差相等. 然而, 由于浮点值的表示方式, 情况并非总是如此:

a = 2.0f / 3.0f;   // 2/3 inexactly represented as a float
b = float_next(float_next(float_next(a))); // 3 floating point values above a
std::cout << "a = " << a << std::endl;
std::cout << "b = " << b << std::endl;
std::cout << "float_distance = " << float_distance(a, b) << std::endl;
std::cout << "relative_difference = " << relative_difference(a, b) << std::endl;
std::cout << "epsilon_difference = " << epsilon_difference(a, b) << std::endl;

产生的输出为:

a = 0.666666687
b = 0.666666865
float_distance = 3.00000000
relative_difference = 2.68220901e-007
epsilon_difference = 2.25000000

float_distance 与 relative_difference/epsilon_difference 函数之间还有另一个重要区别: float_distance 返回带符号的结果, 反映哪个参数幅值更大, 而 relative_difference/epsilon_difference 只返回无符号值, 表示两个值相距多远. 例如, 如果我们交换参数的顺序:

std::cout << "float_distance = " << float_distance(b, a) << std::endl;
std::cout << "relative_difference = " << relative_difference(b, a) << std::endl;
std::cout << "epsilon_difference = " << epsilon_difference(b, a) << std::endl;

输出现在为:

float_distance = -3.00000000
relative_difference = 2.68220901e-007
epsilon_difference = 2.25000000

零总是被视为相等, 无穷大也一样, 只要它们符号相同:

a = 0;
b = -0;  // signed zero
std::cout << "relative_difference = " << relative_difference(a, b) << std::endl;
a = b = std::numeric_limits<float>::infinity();
std::cout << "relative_difference = " << relative_difference(a, b) << std::endl;
std::cout << "relative_difference = " << relative_difference(a, -b) << std::endl;

产生的输出为:

relative_difference = 0.000000000
relative_difference = 0.000000000
relative_difference = 3.40282347e+038

注意有限值与无穷大之间总是相距无穷远, 即使这些有限值非常大:

a = (std::numeric_limits<float>::max)();
b = std::numeric_limits<float>::infinity();
std::cout << "a = " << a << std::endl;
std::cout << "b = " << b << std::endl;
std::cout << "relative_difference = " << relative_difference(a, b) << std::endl;
std::cout << "epsilon_difference = " << epsilon_difference(a, b) << std::endl;

产生的输出为:

a = 3.40282347e+038
b = 1.#INF0000
relative_difference = 3.40282347e+038
epsilon_difference = 3.40282347e+038

最后, 所有非规格化值与零都被视为实际上相等:

a = std::numeric_limits<float>::denorm_min();
b = a * 2;
std::cout << "a = " << a << std::endl;
std::cout << "b = " << b << std::endl;
std::cout << "float_distance = " << float_distance(a, b) << std::endl;
std::cout << "relative_difference = " << relative_difference(a, b) << std::endl;
std::cout << "epsilon_difference = " << epsilon_difference(a, b) << std::endl;
a = 0;
std::cout << "a = " << a << std::endl;
std::cout << "b = " << b << std::endl;
std::cout << "float_distance = " << float_distance(a, b) << std::endl;
std::cout << "relative_difference = " << relative_difference(a, b) << std::endl;
std::cout << "epsilon_difference = " << epsilon_difference(a, b) << std::endl;

产生的输出为:

a = 1.40129846e-045
b = 2.80259693e-045
float_distance = 1.00000000
relative_difference = 0.000000000
epsilon_difference = 0.000000000
a = 0.000000000
b = 2.80259693e-045
float_distance = 2.00000000
relative_difference = 0.000000000
epsilon_difference = 0.000000000

注意在上面的示例中, 相距 2 倍的两个非规格化值竟然只相隔一个表示单位!

以上所有示例都包含在 float_comparison_example.cpp 中.

处理绝对误差

设想我们正在测试以下函数:

double myspecial(double x)
{
   return sin(x) - sin(4 * x);
}

该函数有多个根, 其中一些根相当可预测: sin(x) 与 sin(4x) 同时为零. 另一些根的出现是因为这两个函数返回的值恰好完全抵消. 在这些点上, 函数真值与实际返回值之间的相对差可能任意大, 原因是 抵消误差.

在这种情况下, 通过要求 relative_error 或 epsilon_error 返回的值低于某个阈值来测试上面的函数是没有意义的: 我们能做到的最好办法是验证真值与计算值之间的 绝对差低于某个阈值.

当然, 确定该阈值应当是多少往往很难, 但一个好的起点是机器 epsilon 乘以被求和值中的最大者. 在上面的示例中, sin(whatever) 返回的最大值为 1, 因此简单地用机器 epsilon 作为最大绝对差的目标可能是个好的开始 (尽管实践中我们可能需要略高的值 — 需要一些反复试验).
