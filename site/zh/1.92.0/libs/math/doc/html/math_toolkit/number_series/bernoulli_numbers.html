Bernoulli 数

Bernoulli numbers (Bernoulli 数) 是有理数序列, 对 Taylor 级数展开、Euler-Maclaurin 公式和 Riemann zeta 函数很有用.

Bernoulli 数用于求值一些 Boost.Math 函数, 包括 tgamma、lgamma 和 polygamma 函数.

单个 Bernoulli 数
概要 
#include <boost/math/special_functions/bernoulli.hpp>

namespace boost { namespace math {

template <class T>
T bernoulli_b2n(const int n);  // Single Bernoulli number (default policy).

template <class T, class Policy>
T bernoulli_b2n(const int n, const Policy &pol); // User policy for errors etc.

}} // namespaces
说明

二者都返回第 (2 * n)th 个 Bernoulli 数 B2n.

注意, 由于所有奇数编号的 Bernoulli 数都是零 (B1 = -½ 除外) , 接口只返回偶数编号的 Bernoulli 数.

该函数对低索引 Bernoulli 数使用快速查表, 较大值按需计算然后缓存. 缓存机制需要一定的线程安全代码, 因此对性能关键代码 unchecked_bernoulli_b2n 可能提供更好的接口.

最后的 Policy 实参可选, 可用于控制函数行为: 如何处理错误、使用何种精度等.

更多细节参见 Policies.

示例

一个简单例子计算 B4 的值, 返回类型为 double; 注意 bernoulli_b2n 的实参是 2 而非 4, 因为它计算的是 B2N.

try
{ // It is always wise to use try'n'catch blocks around Boost.Math functions
  // so that any informative error messages can be displayed in the catch block.
std::cout
  << std::setprecision(std::numeric_limits<double>::digits10)
  << boost::math::bernoulli_b2n<double>(2) << std::endl;

所以 B4 == -1/30 == -0.0333333333333333

如果使用 Boost.Multiprecision 及其 50 位十进制浮点类型 cpp_dec_float_50, 就可以计算大得多的数 (如 B200) , 并获得高得多的精度.

std::cout
  << std::setprecision(std::numeric_limits<boost::multiprecision::cpp_dec_float_50>::digits10)
  << boost::math::bernoulli_b2n<boost::multiprecision::cpp_dec_float_50>(100) << std::endl;

单个 (无检查) Bernoulli 数
概要 
#include <boost/math/special_functions/bernoulli.hpp>

template <>
struct max_bernoulli_b2n<T>;

template<class T>
inline T unchecked_bernoulli_b2n(unsigned n);

unchecked_bernoulli_b2n 提供 不做任何上溢或无效参数检查的 Bernoulli 数访问. 它实现为直接 (且非常快的) 查表; 虽不建议一般使用, 但在要求极致性能、且把错误检查移到循环之外的内核循环内部会很有用.

能传给 unchecked_bernoulli_b2n<> 的最大值是 max_bernoulli_b2n<>::value: 传入更大的值会导致缓冲区越界错误, 因此使用这个直接接口时, 把错误处理放在自己的代码里显然很重要.

boost::math::max_bernoulli_b2n<T>::value 的值随类型 T 而变; 对类型 float/double/long double, 它是不使目标类型上溢的最大值: 例如 boost::math::max_bernoulli_b2n<double>::value 是 129. 而对多精度类型, 它是结果仍能表示为两个 64 位整数之比的最大值, 例如 boost::math::max_bernoulli_b2n<boost::multiprecision::cpp_dec_float_50>::value 只有 17. 当然可以把更大的索引传给 bernoulli_b2n<T>(n), 但那样就失去了快速查表 (即可能需要计算数值) .

多个 Bernoulli 数
概要 
#include <boost/math/special_functions/bernoulli.hpp>

namespace boost { namespace math {

// Multiple Bernoulli numbers (default policy).
template <class T, class OutputIterator>
OutputIterator bernoulli_b2n(
  int start_index,
  unsigned number_of_bernoullis_b2n,
  OutputIterator out_it);

// Multiple Bernoulli numbers (user policy).
template <class T, class OutputIterator, class Policy>
OutputIterator bernoulli_b2n(
  int start_index,
  unsigned number_of_bernoullis_b2n,
  OutputIterator out_it,
  const Policy& pol);
}} // namespaces
说明

Bernoulli 数函数提供两个版本, 用一次调用计算多个 Bernoulli 数 (一个用默认 policy, 另一个允许用户自定义 policy) .

它们返回一系列 Bernoulli 数:

[B2*start_index, B2*(start_index+1), ..., B2*(start_index+number_of_bernoullis_b2n-1)]

示例

我们可以用一次调用计算并保存全部 float 精度的 Bernoulli 数.

std::vector<float> bn; // Space for 32-bit `float` precision Bernoulli numbers.

// Start with Bernoulli number 0.
boost::math::bernoulli_b2n<float>(0, 32, std::back_inserter(bn)); // Fill vector with even Bernoulli numbers.

for(size_t i = 0; i < bn.size(); i++)
{ // Show vector of even Bernoulli numbers, showing all significant decimal digits.
    std::cout << std::setprecision(std::numeric_limits<float>::digits10)
        << i*2 << ' '
        << bn[i]
        << std::endl;
}

当然, 对任何浮点类型, 都存在一个在上溢之前可计算的最大 Bernoulli 数. 按默认 policy, 若试图计算过高的 Bernoulli 数, 将抛出异常.

try
{
  std::cout
  << std::setprecision(std::numeric_limits<float>::digits10)
  << "Bernoulli number " << 33 * 2 <<std::endl;

  std::cout << boost::math::bernoulli_b2n<float>(33) << std::endl;
}
catch (std::exception ex)
{
  std::cout << "Thrown Exception caught: " << ex.what() << std::endl;
}

并且会得到一条有用的错误消息 (前提是使用了 try'n'catch 块) .

Bernoulli number 66

Overflow evaluating function at 33

本例源码见 bernoulli_example.cpp

精度

对于浮点类型, 所有函数通常都返回一个 ULP (最后一位单位) 以内的值.

实现

实现细节见 bernoulli_details.hpp 和 unchecked_bernoulli.hpp.

对 i <= max_bernoulli_index<T>::value, 这通过从静态初始化的表做简单查表实现; 对更大的 i 值, 则由 Tangent Numbers 算法实现, 该算法见论文: Fast Computation of Bernoulli, Tangent and Secant Numbers, Richard P. Brent and David Harvey, http://arxiv.org/pdf/1108.0286v3.pdf (2011) .

文中还定义了 Tangent (or Zag) numbers (切数, 一种偶交错排列数) 并给出了其生成函数.
