偏正态分布是最广为人知的高斯统计分布的一种变体.

形状为零的偏正态分布类似于 正态分布, 因此后者可视为更一般的偏正态分布的特例.

成员函数 
skew_normal_distribution(RealType location = 0, RealType scale = 1, RealType shape = 0);

构造一个 skew_normal 分布, 位置为 ξ, 尺度为 ω, 形状为 α.

要求 scale > 0, 否则调用 domain_error.

RealType location()const;

返回此分布的位置 ξ,

RealType scale()const;

返回此分布的尺度 ω,

RealType shape()const;

返回此分布的形状 α.

(位置与尺度函数与其他类似分布相匹配, 使得函数 find_location 与 find_scale 可以泛型方式使用).

注释

虽然形状参数可以任意选取 (有限值), 但所得分布的 偏度 实际上限制在约 (-1, 1) 内; 严格地说, 该区间为 (-0.9952717, 0.9952717).

参数 δ 与形状 α 通过 δ = α / (1 + α²) 相关联, 并用于偏度的表达式中

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support.

随机变量的定义域为 -[max_value], +[min_value]. 不支持无穷值.

众数与中位数没有已知的 闭式表达式, 但以下两种情形会进行计算:

  • 众数 - 通过求 PDF 的最大值得到.
  • 中位数 - 通过计算 quantile(1/2) 得到.

PDF 的最大值通过求 f'(x)=0 的根来寻找.

两者都涉及迭代方法, 精度将低于其他估计.

测试

The R Project for Statistical Computing 使用 library(sn), 相关描述见 Skew-Normal Probability Distribution 与 R skew-normal(sn) package.

sn 包提供与偏正态 (SN) 和偏 t (ST) 概率分布相关的函数, 同时涵盖单变量与多变量情形, 包括回归模型.

Wolfram Mathematica 也用于生成一些更精确的抽检数据.

精度

形状为零的 skew_normal 分布作为特例实现, 等价于基于 误差函数的正态分布, 因此应具有极高的精度.

PDF 以及均值、方差、偏度和峰度也使用 解析表达式精确求值. CDF 需要 Owen's T 函数, 它以 Boost C++ Owens T 实现了 M. Patefield 与 D. Tandy 的算法 (Journal of Statistical Software, 5(5), 1-25 (2000)); 该函数复杂的精度问题在 Owens T 中有详细讨论.

中位数与众数通过迭代求根计算, 两者的精度都会较低.
