非中心 T 分布 

#include <boost/math/distributions/non_central_t.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class non_central_t_distribution;

typedef non_central_t_distribution<> non_central_t;

template <class RealType, class Policy>
class non_central_t_distribution
{
public:
   typedef RealType  value_type;
   typedef Policy    policy_type;

   // Constructor:
   non_central_t_distribution(RealType v, RealType delta);

   // Accessor to degrees_of_freedom parameter v:
   RealType degrees_of_freedom()const;

   // Accessor to non-centrality parameter delta:
   RealType non_centrality()const;
};

}} // namespaces

非中心 T 分布是 Students t 分布 的推广. 设 X 服从均值为 δ、方差为 1 的正态分布, 并设 ν S2 服从自由度为 ν 的卡方分布. 假定 X 与 S2 相互独立. tν(δ)=X/S 的分布称为自由度为 ν、非中心性参数为 δ 的非中心 t 分布.

成员函数 
non_central_t_distribution(RealType v, RealType delta);

构造一个非中心 t 分布, 自由度参数为 v, 非中心性参数为 delta.

要求 v > 0 (包括正无穷) 且 delta 有限, 否则调用 domain_error.

RealType degrees_of_freedom()const;

返回构造此对象时使用的参数 v.

RealType non_centrality()const;

返回构造此对象所用的非中心性参数 delta.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support.

随机变量的定义域为 [-∞, +∞].

注意

当前算法的复杂度取决于 δ2: 因此当 δ > 500 时, 计算 CDF 所需的时间会迅速增加; 同样, 对非常大的 δ, 精度也会迅速下降.

分位数与 PDF 函数的精度应大体相似. 众数 是数值确定的, 原则上其精度不可能超过浮点类型 FPT 的 epsilon 的平方根, 后者可用 boost::math::tools::epsilon<FPT>() 访问. 对于 64 位 double, epsilon 约为 1e-16, 因此小数精度被限制在 1e-8.

从 Boost 1.52 起, 当用位于 δ 的正态分布 (等价于中心 Student's t 分布) 代替时, 自由度 ν 可以为 +∞, 以获得精度与速度.

对于 PDF 与 CDF, 当 ν 非常大时, 我们都改用中心在 δ 的 Student's t 分布来近似该分布. 交叉位置似乎出现在 δ/(4ν) < ε 时, 这一位置是通过检视 "A Comparison of Approximations To Percentiles of the Noncentral t-Distribution". H. Sahai and M. M. Ojeda, Revista Investigacion Operacional Vol 21, No 2, 2000, page 123 中的方程 2.6 估计出来的.

方程 2.6 是 Eeden 与 Johnson 给出的 Fisher-Cornish 展开. 第二项包含比值 δ/(4ν), 因此当该项变得可忽略时, 这一项及其后的项都可以忽略, 只剩下中心在 δ 的 Student's t 分布.

这也通过实验测试得到了确认.

分位数通过常用的 无导数求根 方法计算, 初始猜测取非中心 T 的正态近似分布的分位数.

众数没有闭式解, 因此通过对 PDF 求函数极值来计算.

其余函数 (均值、方差等) 使用 Weisstein, Eric W. "Noncentral Student's t-Distribution." From MathWorld--A Wolfram Web Resource. http://mathworld.wolfram.com/NoncentralStudentst-Distribution.html 以及 Mathematica documentation 中给出的公式实现.
