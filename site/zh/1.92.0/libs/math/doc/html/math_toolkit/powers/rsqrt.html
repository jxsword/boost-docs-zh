倒数平方根

概要 
#include <boost/math/special_functions/rsqrt.hpp>

namespace boost::math {

template<class Real>
Real rsqrt(Real const & x);

} // namespaces

函数 rsqrt 计算倒数平方根 1/√x. 游戏编程社区的人可能怀疑这是围绕 rsqrtss 指令的快速低精度封装. 这是不正确的: 我们 尝试过 这条指令, 但发现使用它没有性能收益. 不过, 先计算低精度倒数平方根再通过牛顿法引导到更高精度的 技巧 确实 有效, 但它只对 quad 及更高精度带来性能收益. 当然, 我们也允许你将 rsqrt 用于 float、double 和 long double, 但要注意这样做没有性能收益. 而对 quad 及更高精度, 节省则非常可观.

用法是

using boost::multiprecision::float128;
float128 x = 0.1Q;
float128 y = boost::math::rsqrt(x);

+∞ 的倒数平方根是零, NaN 的倒数平方根是 NaN.
