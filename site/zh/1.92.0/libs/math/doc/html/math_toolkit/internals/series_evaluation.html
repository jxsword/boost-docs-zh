级数求值

概要

说明

这些算法用于无穷级数求和.

每个算法都以一个无参函数对象作为第一个实参: 该函数对象会被反复调用, 以从被求和的级数中取出相继的项.

第二个实参是所需的精度; 当下一项小于结果的 tolerance 倍时, 求和停止. 已弃用版本的 sum_series 在这里接受整数位数 - 它们在内部只是把它转换为容差后再转发调用.

第三个实参 max_terms 设置要计算的级数项数上限. 此外, 退出时该函数会把 max_terms 设为实际计算的级数项数: 这对于剖析新级数的收敛性质尤为有用.

最后一个可选实参 init_value 是求和的初始值, 级数的各项应加到该值上. 这在两种情形下有用:

  • 级数的第一个值与后续项使用不同的公式. 在这种情况下, 可以把级数的第一个值作为最后一个实参传入, 于是函数对象的逻辑就可以简化为只返回后续项.
  • 级数要加到某个其他值上 (或从中减去): 如果把这个其他值作为最后一个实参传入, 级数的终止很可能会快得多. 例如, 有几个函数可以表示为 1 - S(z), 其中 S(z) 是无穷级数. 在这种情况下, 把 -1 作为最后一个实参传入, 然后对求和结果取负, 就得到 1 - S(z) 的结果.

这些算法中两个 kahan_sum_series 变体会维护一个进位项, 用于在求和期间修正舍入误差. 它们受到 Kahan 求和公式 的启发, 该公式出现在 每一位计算机科学家都应了解的浮点运算知识 中. 不过需要指出, 需要以这种方式求和的级数非常少.

示例

这些示例都在 ../../example/series.cpp 中

假设我们想通过无穷级数来实现 log(1+x),

我们首先编写一个小函数对象来返回级数的相继各项:

template <class T>
struct log1p_series
{
   // we must define a result_type typedef:
   typedef T result_type;

   log1p_series(T x)
      : k(0), m_mult(-x), m_prod(-1) {}

   T operator()()
   {
      // This is the function operator invoked by the summation
      // algorithm, the first call to this operator should return
      // the first term of the series, the second call the second
      // term and so on.
      m_prod *= m_mult;
      return m_prod / ++k;
   }

private:
   int k;
   const T m_mult;
   T m_prod;
};

现在实现 log(1+x) 就相当简单了:

template <class T>
T log1p(T x)
{
   // We really should add some error checking on x here!
   BOOST_MATH_ASSERT(std::fabs(x) < 1);

   // Construct the series functor:
   log1p_series<T> s(x);
   // Set a limit on how many iterations we permit:
   std::uintmax_t max_iter = 1000;
   // Add it up, with enough precision for full machine precision:
   return boost::math::tools::sum_series(s, std::numeric_limits<T>::epsilon(), max_iter);
}

这段代码几乎也可以用于复数 - 遗憾的是 epsilon 需要略微不同的定义, 而且在函数对象内部, 复数与整数的混合运算 (截至 C++17) 不受支持, 因此我们需要把整数强制转换为浮点数:

template <class T>
struct log1p_series<std::complex<T> >
{
   // we must define a result_type typedef:
   typedef std::complex<T> result_type;

   log1p_series(std::complex<T> x)
      : k(0), m_mult(-x), m_prod(-1) {}

   std::complex<T> operator()()
   {
      // This is the function operator invoked by the summation
      // algorithm, the first call to this operator should return
      // the first term of the series, the second call the second
      // term and so on.
      m_prod *= m_mult;
      return m_prod / T(++k);
   }

private:
   int k;
   const std::complex<T> m_mult;
   std::complex<T> m_prod;
};


template <class T>
std::complex<T> log1p(std::complex<T> x)
{
   // We really should add some error checking on x here!
   BOOST_MATH_ASSERT(abs(x) < 1);

   // Construct the series functor:
   log1p_series<std::complex<T> > s(x);
   // Set a limit on how many iterations we permit:
   std::uintmax_t max_iter = 1000;
   // Add it up, with enough precision for full machine precision:
   return boost::math::tools::sum_series(s, std::complex<T>(std::numeric_limits<T>::epsilon()), max_iter);
}

当然, 借助几个 traits 类和一点元编程, 我们可以把这两个实现合并为一个, 但那超出了这些示例的范围.
