Gauss-Legendre 求积

概要

#include <boost/math/quadrature/gauss.hpp> 

namespace boost{ namespace math{ namespace quadrature{

template <class Real, unsigned Points, class Policy = boost::math::policies::policy<> >
struct gauss
{
   static const RandomAccessContainer& abscissa();
   static const RandomAccessContainer& weights();

   template <class F>
   static auto integrate(F f, Real* pL1 = nullptr)->decltype(std::declval<F>()(std::declval<Real>()))

   template <class F>
   static auto integrate(F f, Real a, Real b, Real* pL1 = nullptr)->decltype(std::declval<F>()(std::declval<Real>()))
};

}}} // namespaces

描述

类模板 gauss 对某个任意函数 f 执行"一次性"非自适应 Gauss-Legendre 积分, 求值点数由 Points 指定.

这是一个有意为之的非常简单的求积例程, 它不给出误差估计, 也不是自适应的, 但在涉及积分光滑"钟形"函数以及幂级数快速收敛的函数等简单情形时非常高效.

static const RandomAccessContainer& abscissa();
static const RandomAccessContainer& weights();

这些函数提供对执行求积所用横坐标与权重的直接访问: 返回类型取决于 Points 模板参数, 但始终是 RandomAccessContainer 类型. 注意只保存正 (或零) 的横坐标与权重.

template <class F>
static auto integrate(F f, Real* pL1 = nullptr)->decltype(std::declval<F>()(std::declval<Real>()))

在 (-1,1) 上积分 f, 并可选地把 *pL1 设为返回值的 L1 范数: 若它显著大于返回值, 则求和是病态的. 但注意没有误差估计可用.

template <class F>
static auto integrate(F f, Real a, Real b, Real* pL1 = nullptr)->decltype(std::declval<F>()(std::declval<Real>()))

在 (a,b) 上积分 f, 并可选地把 *pL1 设为返回值的 L1 范数: 若它显著大于返回值, 则求和是病态的. 但注意没有误差估计可用. 该函数同时支持有限的与无穷的 a 与 b, 只要满足 a < b.

Gaussian 求积例程同时支持实值与复值求积. 例如, Lambert-W 函数有积分表示

W(z) = 1/2Π ∫-ΠΠ ((1- v cot(v) )^2 + v^2)/(z + v csc(v) exp(-v cot(v))) dv

因此可以用如下代码通过 Gaussian 求积有效计算:

Complex z{2, 3};
auto lw = [&z](Real v)->Complex {
  using std::cos;
  using std::sin;
  using std::exp;
  Real sinv = sin(v);
  Real cosv = cos(v);

  Real cotv = cosv/sinv;
  Real cscv = 1/sinv;
  Real t = (1-v*cotv)*(1-v*cotv) + v*v;
  Real x = v*cscv*exp(-v*cotv);
  Complex den = z + x;
  Complex num = t*(z/pi<Real>());
  Complex res = num/den;
  return res;
};

boost::math::quadrature::gauss<Real, 30> integrator;
Complex W = integrator.integrate(lw, (Real) 0, pi<Real>());

选择点的数量

类 gauss 在内部为 7、15、20、25 与 30 个点预计算了最高 100 位十进制精度的横坐标与权重表. 这意味着例如使用 gauss<double, 30>::integrate 时, 计算横坐标/权重对完全没有设置开销. 当使用精度低于 100 位的多精度类型时, 会有一次性的较小初始成本, 因为横坐标/权重对要从字符串构造.

然而, 对更高精度的类型, 或点数不同于上述给定值的情形, 横坐标/权重对会在首次需要时计算并缓存供将来使用, 这确实会带来可观的额外开销. 如果这可能成为问题, 那么

  • 定义 BOOST_MATH_GAUSS_NO_COMPUTE_ON_DEMAND 将导致编译期错误: 每当使用没有预计算值的数字类型与点数组合时就会报错.
  • 有一个程序 gauss_kronrod_constants.cpp, 它曾用于提供 gauss.hpp 中已有的预计算值. 稍加修改即可让该程序为其他精度与点数生成代码与常数.

示例

我们首先在 (0,1) 上用 7 项 Gauss-Legendre 法则积分 t2 atan(t), 先把被积函数定义为 C++ lambda 表达式:

using namespace boost::math::quadrature;

auto f = [](const double& t) { return t * t * std::atan(t); };

积分只需调用 gauss<double, 7>::integrate 方法:

double Q = gauss<double, 7>::integrate(f, 0, 1);

得到值 0.2106572512, 精确到 1e-10.

要获得更精确的求值, 我们改用多精度类型并使用 20 点积分方案:

using boost::multiprecision::cpp_bin_float_quad;

auto f2 = [](const cpp_bin_float_quad& t) { return t * t * atan(t); };

cpp_bin_float_quad Q2 = gauss<cpp_bin_float_quad, 20>::integrate(f2, 0, 1);

得到 0.2106572512258069881080923020669, 精确到 5e-28.
