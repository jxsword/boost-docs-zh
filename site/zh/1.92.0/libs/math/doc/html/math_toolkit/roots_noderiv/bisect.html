二分法 

template <class F, class T, class Tol>
std::pair<T, T>
   bisect(  // Unlimited iterations.
      F f,
      T min,
      T max,
      Tol tol);

template <class F, class T, class Tol>
std::pair<T, T>
   bisect(  // Limited iterations.
      F f,
      T min,
      T max,
      Tol tol,
      std::uintmax_t& max_iter);

template <class F, class T, class Tol, class Policy>
std::pair<T, T>
   bisect( // Specified policy.
      F f,
      T min,
      T max,
      Tol tol,
      std::uintmax_t& max_iter,
      const Policy&);

这些函数使用 bisection (二分法) 定位根.

bisect 函数的参数为:

f

一元函子 (或 C++ lambda), 即要求根的函数 f(x).

min

已知包含根的区间的左端点.

max

已知包含根的区间的右端点.
前置条件是 min < max 且 f(min)*f(max) <= 0; 若这些前置条件被违反, 函数将抛出 evaluation_error. 出错时采取的动作由 Policy 模板参数控制: 默认行为是抛出 boost::math::evaluation_error. 如果把 Policy 改为不抛出, 则返回 std::pair<T>(min, min).

tol

二元函子 (或 C++ lambda), 用于指定终止条件: 当 tol(min, max) 变为 true 时, 函数将返回当前包围根的区间. 另参见 predefined termination functors.

max_iter

搜索根时对 f(x) 的最大调用次数. 退出时, 该值被更新为实际执行的调用次数.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

返回: 一对界定根的值 r, 满足:

f(r.first) * f(r.second) <= 0

并且满足二者之一

tol(r.first, r.second) == true

或者

max_iter >= m

其中 m 是传递给函数的 max_iter 初始值.

换言之, 由调用者负责判断终止是因为超过了 max_iter 次函数调用 (只需在函数返回时检查更新后的 max_iter 值即可), 还是因为终止条件 tol 得到满足.
