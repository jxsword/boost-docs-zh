非中心 Beta 分布 

#include <boost/math/distributions/non_central_beta.hpp>

class non_central_beta_distribution

   typedef RealType  value_type;

};

}} // namespaces

非中心 Beta 分布是 Beta 分布 的推广.

它定义为比值

X = χm2(λ) / (χm2(λ) + χn2)

其中 χm2(λ) 是非中心 χ2 随机变量, 其自由度为 m , 而 χn2 是中心 χ2 随机变量, 其自由度为 n.

成员函数 
BOOST_MATH_GPU_ENABLED non_central_beta_distribution(RealType a, RealType b, RealType lambda);

构造一个非中心 beta 分布, 形状参数为 a 与 b, 非中心性参数为 lambda.

要求 a > 0, b > 0 且 lambda >= 0, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType alpha()const;

返回构造此对象所用的参数 a.

BOOST_MATH_GPU_ENABLED RealType beta()const;

返回构造此对象所用的参数 b.

BOOST_MATH_GPU_ENABLED RealType non_centrality()const;

返回构造此对象所用的参数 lambda.

非成员访问器

大多数 常用的非成员访问函数 都受支持: 累积分布函数, 概率密度函数, 分位数, 均值, 方差, 标准差, 中位数, 众数, 风险函数, 累积风险函数, 范围 与 支集. 对于此分布, 这些函数都标记有 BOOST_MATH_GPU_ENABLED, 并且可以在主机与设备上运行.

均值与方差使用超几何 pfq 函数以及 Wolfram Noncentral Beta Distribution 中给出的关系式实现.

不过, 下列函数目前尚未实现: skewness, kurtosis 与 kurtosis_excess.

随机变量的定义域为 [0, 1].

实现

CDF 及其补的计算方式如下:

首先, 我们确定两个值 (CDF 或其补) 中哪一个可能更小, 交叉点取为分布的均值: 为此我们使用由下式给出的近似: R. Chattamvelli and R. Shanmugam, "Algorithm AS 310: Computing the Non-Central Beta Distribution Function", Applied Statistics, Vol. 46, No. 1. (1997), pp. 146-156.

然后使用下列关系式计算 CDF 或其补:

求和从 i = λ/2 开始, 然后使用 Poisson PDF 与不完全 beta 函数的常用递推关系向两个方向递推. 这就是由以下文献描述的 "Method 2":

Denise Benton and K. Krishnamoorthy, "连续分布离散混合的计算: 非中心卡方、非中心 t 与样本多重相关系数平方的分布", Computational Statistics & Data Analysis 43 (2003) 249-267.

上述公式在非中心 beta 分布上的具体应用可见:

Russell V. Lenth, "Algorithm AS 226: Computing Noncentral Beta Probabilities", Applied Statistics, Vol. 36, No. 2. (1987), pp. 241-244.

H. Frick, "Algorithm AS R84: A Remark on Algorithm AS 226: Computing Non-Central Beta Probabilities", Applied Statistics, Vol. 39, No. 2. (1990), pp. 311-312.

Ming Long Lam, "Remark AS R95: A Remark on Algorithm AS 226: Computing Non-Central Beta Probabilities", Applied Statistics, Vol. 44, No. 4. (1995), pp. 551-552.

Harry O. Posten, "An Effective Algorithm for the Noncentral Beta Distribution Function", The American Statistician, Vol. 47, No. 2. (May, 1993), pp. 129-131.

R. Chattamvelli, "A Note on the Noncentral Beta Distribution Function", The American Statistician, Vol. 49, No. 2. (May, 1995), pp. 231-234.

在这些文献中, Posten 的文献提供了最完整的概述, 并包含从 λ/2 开始迭代的修改.

本实现与上述文献的主要区别在于: 在最高效时直接计算补, 并把和累加到 -1, 而不是最后从 1 中减去结果: 当结果接近 1 时, 这可以大幅减少所需的迭代次数.
