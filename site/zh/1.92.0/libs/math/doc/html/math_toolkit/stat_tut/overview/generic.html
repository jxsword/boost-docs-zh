所有分布通用的泛型操作都是非成员函数

想计算分布的 PDF (概率密度函数)? 没问题, 只需使用:

pdf(my_dist, x);  // Returns PDF (density) at point x of distribution my_dist.

或者 CDF (累积分布函数) 呢:

cdf(my_dist, x);  // Returns CDF (integral from -infinity to point x)
                  // of distribution my_dist.

分位数也一样:

quantile(my_dist, p);  // Returns the value of the random variable x
                       // such that cdf(my_dist, x) == p.

logcdf (累积分布函数的自然对数) 同样如此:

logcdf(my_dist, x); // Returns logcdf at at point x of distribution my_dist.

logpdf (概率密度函数的自然对数) 也是:

logpdf(my_dist, x); // Returns logpdf at point x of distribution my_dist.

如果你想知道为什么这些不是成员函数, 这是为了让库更易于扩展: 如果你想添加额外的泛型操作——比如说 n 阶矩——那么你所要做的就是添加相应的非成员函数, 并为每个已实现的分布类型提供重载.

logcdf 和 logpdf 函数分别以 log(cdf(my_dist, x)) 和 log(pdf(my_dist, x)) 作最低限度的计算. 以下分布具有 logcdf 的专门实现:

  • 指数级
  • 极值分布
  • Geometric
  • Laplace 分布
  • Logistic 分布
  • Pareto 分布
  • Rayleigh 分布
  • Weibull 分布

以下分布具有 logpdf 的专门实现:

  • 指数级
  • 极值分布
  • Gamma
  • 逆 Gamma 分布
  • 逆高斯分布
  • Laplace 分布
  • 正态分布
  • Poisson 分布
  • Rayleigh 分布
  • Weibull 分布

上面列出的这些专门实现能提供比朴素的泛型方法更高的精度.

提示

近似分布分位数的随机数

如果你想要按特定方式分布 (例如均匀、正态或三角分布) 的随机数, 请参见 Boost.Random.

虽然原则上没有什么能阻止你用分位数函数把均匀分布的随机数转换成其他分布, 但实践中存在专门用于随机数生成的高效得多的算法.

例如, 二项分布有两个参数: n (试验次数) 和 p (单次试验成功的概率).

因此 binomial_distribution 构造函数有两个参数:

binomial_distribution(RealType n, RealType p);

对该分布, 随机变量值 是 k: 观察到的成功次数. 因此概率密度/质量函数 (pdf) 写作 f(k; n, p).

注释

随机变量值与分布参数

随机变量 的概念与术语 随机变量值 密切相关: 随机变量值是随机变量的一个特定取值 (结果). 而 分布参数 按惯例 (例如在 Wikipedia 和 Wolfram MathWorld 中) 用分号或竖线 跟在 随机变量 (其值由你 "选定") 后面来加以区分, 以便把变量值与定义分布形状的参数分开.

例如, 二项分布的概率分布函数 (PDF) 写作 f(k| n, p) = Pr(K = k|n, p) = 在 n 次试验中观察到 k 次成功的概率. K 是 随机变量, k 是 随机变量值, 参数是 n (试验次数) 和 p (概率).

注释

按惯例, 随机变量值 用小写表示, 整数时通常为 k, 实数时为 x; 而 随机变量 用大写表示, 整数时为 K, 实数时为 X. 但本实现把所有这些都当作浮点值处理 RealType, 因此如果你真的想要整数结果, 必须进行舍入: 详情参见下文关于离散概率分布的注释.

如上所述, 非成员函数 pdf 有一个参数用于分布对象, 第二个参数用于随机变量值. 以我们的二项分布示例来说, 应写作:

pdf(binomial_distribution<RealType>(n, p), k);

允许且受支持的 随机变量值 的范围可以用两个函数 range 和 support 来检验.

分布 (实际上是其 随机变量值) 被称为在一个范围内是 "受支持的", 该范围是 "补集概率为零的最小闭集". MathWorld 把这个范围称为 "有定义的". 非数学工作者可能会说, 它指的是随机变量值 x 的 "有趣的" 最小范围, 其中 cdf 从零变到 1. 范围之外是无趣的区域, 在那里 pdf 为零, cdf 为零或 1.

对大多数分布——其概率分布函数可以说 "表现良好"——我们决定, 受支持范围 排除 像精确零这样的随机变量值 当端点不连续时 最为有用. 例如, 当随机变量值 x 趋向零时, Weibull (尺度 1, 形状 1) 分布平滑地趋向 1. 但在 x = 零处, pdf 的值按定义突然精确为零. 我们发现, 如果要绘制 PDF 或进行其他计算, 零并不是受支持下限最有用的取值. 因此对这个分布以及类似的分布, 我们决定使用最接近零的值 min_value 作为受支持范围的界限, 这在数值上最有用. (range 仍保持在距零的位置, 因此你仍会得到 pdf(weibull, 0) == 0). (Exponential 分布和 gamma 分布具有类似的不连续函数).

在数学上, 这些函数在 (+ 或 -) 无穷值下可能仍有意义, 但除了少数特殊情况 (Normal 分布和 Cauchy 分布) 之外, 本实现把随机变量值限制在从 max 到 min 的有限值内, 对应于 RealType. (设计理由参见 Handling of Floating-Point Infinity).

注释

离散概率分布

注意, 包括二项分布、负二项分布、Poisson 分布和 Bernoulli 分布在内的 离散分布, 在数学上都定义为离散函数: 也就是说, 函数 cdf 和 pdf 只对随机变量值的整数值有定义.

然而, 由于计算方法常常使用连续函数, 把它们当作连续函数来处理、并允许其参数取非整数值会更方便.

想要执行严格数学模型的用户, 可以在调用分布函数之前对随机变量值使用 floor 或 ceil 函数.

这些分布的分位数函数很难用一种让所有人始终满意的方式来规定. 默认行为是返回一个被 向外 舍入的整数结果: 也就是说, 下分位数——概率小于 0.5 时——向下舍入, 而上分位数——概率大于 0.5 时——向上舍入. 这种行为确保当请求 X% 分位数时, 中心区域 至少 覆盖所请求的覆盖率, 而尾部 至多 覆盖所请求的覆盖率.

可以使用 Policy 改变这种行为, 使分位数函数以不同方式舍入或返回实数值结果. 强烈建议在对离散分布使用分位数函数之前, 先阅读教程 Understanding Quantiles of Discrete Distributions. 参考文档 描述了如何更改这些分布的舍入策略.

出于类似的原因, 带有 "自由度" 这类看似整数的参数的连续分布被当作实数值处理 (必要时会从整数提升为浮点数). 不过在这种情形下, 有少数情况中非整数自由度确实具有真实含义.
