不完全 Beta 函数的导数

概要 
#include <boost/math/special_functions/beta.hpp>

namespace boost{ namespace math{

template <class T1, class T2, class T3>
BOOST_MATH_GPU_ENABLED calculated-result-type ibeta_derivative(T1 a, T2 b, T3 x);

template <class T1, class T2, class T3, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type ibeta_derivative(T1 a, T2 b, T3 x, const Policy&);

}} // namespaces
说明

本函数在统计分布中有些用途: 它计算 x 方向上不完全 Beta 函数 ibeta 的偏导数.

当 T1、T2 和 T3 是不同类型时, 本函数的返回类型使用 结果类型计算规则 计算.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

精度

与不完全 Beta 函数 ibeta 几乎相同.

实现

本函数只是暴露了不完全 Beta 函数 ibeta 的一些内部细节: 更多信息请参阅该函数的文档.
