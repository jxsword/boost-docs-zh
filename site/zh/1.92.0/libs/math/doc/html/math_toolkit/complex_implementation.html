实现与精度

尽管这些函数都有看似简单的公式, 但直接使用这些公式的朴素实现会对某些输入值产生灾难性失败. 这些函数的 Boost 版本采用 T. E. Hull、Thomas F. Fairgrieve 和 Ping Tak Peter Tang 发表于 ACM Transactions on Mathematical Software, Vol. 23, No. 3, September 1997 的论文 "Implementing the Complex Arcsine and Arccosine Functions Using Exception Handling" 中描述的方法实现. 这意味着这些函数在整个复数范围内都有良好定义, 即使在该范围的极端处也能产生准确的值; 而朴素公式会导致计算过程中发生上溢或下溢, 尽管结果实际上是可表示的值. 对于复平面上每个机器可表示的点, 所有这些函数的最大理论相对误差都小于 9.5ε. 有关实现方法的更多信息, 请参阅头文件本身中的注释以及上述论文.
