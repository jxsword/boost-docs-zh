Gamma (及 Erlang) 分布 

#include <boost/math/distributions/gamma.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class gamma_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;

   BOOST_MATH_GPU_ENABLED gamma_distribution(RealType shape, RealType scale = 1)

   BOOST_MATH_GPU_ENABLED RealType shape()const;
   BOOST_MATH_GPU_ENABLED RealType scale()const;
};

}} // namespaces

gamma 分布是一种连续概率分布. 当形状参数为整数时, 它被称为 Erlang 分布. 它还与 Poisson 分布和卡方分布密切相关.

当形状参数取整数值时, 该分布就是Erlang distribution. 由于只需保证形状参数为大于 0 的整数即可得到它, 因此 Erlang 分布没有单独实现.

注释

为避免与 gamma 函数产生潜在混淆, 此分布不提供该 typedef:

typedef gamma_distribution<double> gamma;

反之, 如果你想要双精度 gamma 分布, 可以写

boost::math::gamma_distribution<> my_gamma(1, 1);

两种形式都很常用: 本库自始至终使用第一种定义. 因此, 要从速率参数构造一个 Gamma Distribution, 应当把速率的倒数作为尺度参数传入.

Erlang Distribution与 Gamma 相同, 只是形状参数为整数. 它常用速率而非尺度作为第二个参数 (请记住速率是尺度的倒数).

在内部, 用于实现 Gamma Distribution 的函数已经针对小整数参数做了优化, 因此一般来说, 使用 Gamma Distribution 而非专用的 Erlang Distribution 不会有明显的性能损失.

成员函数 
BOOST_MATH_GPU_ENABLED gamma_distribution(RealType shape, RealType scale = 1);

构造一个形状为shape、尺度为scale的 gamma 分布.

要求形状参数与尺度参数大于零, 否则调用domain_error.

BOOST_MATH_GPU_ENABLED RealType shape()const;

返回此分布的shape参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的scale参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [0,+∞].

在此分布中, logpdf 的实现经过专门化, 以提高数值精度.

精度

gamma 分布是借助不完全 gamma 函数gamma_p与gamma_q及其反函数gamma_p_inv与gamma_q_inv实现的: 更多信息请参见这些函数的精度数据.

实现

在下表中, k 是该分布的形状参数, θ 是其尺度参数, x 是随机变量, p 是概率, 而q = 1-p.

函数

实现说明

pdf

使用关系式: pdf = gamma_p_derivative(k, x / θ) / θ

logpdf

log(pdf) = -k*log(θ) + (k-1)*log(x) - lgamma(k) - (x/θ)

cdf

使用关系式: p = gamma_p(k, x / θ)

cdf 补函数

使用关系式: q = gamma_q(k, x / θ)

quantile

使用关系式: x = θ * gamma_p_inv(k, p)

由补函数求 quantile

使用关系式: x = θ* gamma_q_inv(k, p)

kθ

方差

kθ2

众数

(k-1)θ (当k>1时), 否则为domain_error
