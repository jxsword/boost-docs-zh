对数正态分布 

#include <boost/math/distributions/lognormal.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class lognormal_distribution;

typedef lognormal_distribution<> lognormal;

template <class RealType, class Policy>
class lognormal_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;
   // Construct:
   BOOST_MATH_GPU_ENABLED lognormal_distribution(RealType location = 0, RealType scale = 1);
   // Accessors:
   BOOST_MATH_GPU_ENABLED RealType location()const;
   BOOST_MATH_GPU_ENABLED RealType scale()const;
};

}} // namespaces

对数正态分布是随机变量的对数服从正态分布时出现的分布. 当变量是大量独立同分布变量的乘积时, 就会得到对数正态分布.

成员函数 
BOOST_MATH_GPU_ENABLED lognormal_distribution(RealType location = 0, RealType scale = 1);

构造一个对数正态分布, 位置为 location, 尺度为 scale.

位置参数与随机变量的对数的均值相同.

尺度参数与随机变量的对数的标准差相同.

要求尺度参数大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType location()const;

返回此分布的 location 参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的scale参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [0,+∞].

精度

对数正态分布借助标准库的 log 与 exp 函数以及 误差函数 实现, 因此误差率应当非常低.

实现

在下表中, m 是分布的位置参数, s 是其尺度参数, x 是随机变量, p 是概率, 而 q = 1-p.

函数

实现说明

pdf

使用关系式: pdf = e-(ln(x) - m)2 / 2s2 / (x * s * sqrt(2pi))

cdf

使用关系式: p = cdf(normal_distribtion<RealType>(m, s), log(x))

cdf 补函数

使用关系式: q = cdf(complement(normal_distribtion<RealType>(m, s), log(x)))

quantile

使用关系式: x = exp(quantile(normal_distribtion<RealType>(m, s), p))

由补函数求 quantile

使用关系式: x = exp(quantile(complement(normal_distribtion<RealType>(m, s), q)))

均值

em + s2 / 2

方差

(es2 - 1) * e2m + s2

众数

em - s2

偏度

sqrt(es2 - 1) * (2 + es2 )

峰度

e4s2 + 2e3s2 + 3e2s2 - 3

超额峰度

e4s2 + 2e3s2 + 3e2s2 - 6
