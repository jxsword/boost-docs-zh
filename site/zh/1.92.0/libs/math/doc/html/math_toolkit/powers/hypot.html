该函数关于 x 和 y 是偶函数且对称, 因此先假定 x,y > 0 且 x > y (如非如此, 我们可以交换参数).

然后, 若 x * ε >= y, 我们可以简单地返回 x.

在三参数情形中, 方法是按最大参数缩放, 然后计算
