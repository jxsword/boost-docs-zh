分布类型的概念要求

一个 DistributionType 是实现以下概念要求并封装一个统计分布的类型.

请注意, 本文档不能替代统计分布的参考文档和教程.

在下表中, d 是类型 DistributionType 的对象, cd 是类型 const DistributionType 的对象, cr 是可转换为 RealType 的类型的对象.

表达式

结果类型

注释

DistributionType::value_type

RealType

分布所操作的实数类型 RealType.

DistributionType::policy_type

RealType

求值依赖此分布的函数时所使用的策略 (Policy).

d = cd

Distribution&

分布类型是可赋值的.

Distribution(cd)

Distribution

分布类型是可拷贝构造的.

pdf(cd, cr)

RealType

返回分布的概率密度函数 (PDF).

cdf(cd, cr)

RealType

返回分布的累积分布函数 (CDF).

cdf(complement(cd, cr))

RealType

返回分布 CDF 的补 (余), 等价于: 1-cdf(cd, cr)

quantile(cd, cr)

RealType

返回分布的分位数 (或百分位数).

quantile(complement(cd, cr))

RealType

从概率的补出发返回分布的分位数 (或百分位数), 等价于: quantile(cd, 1-cr)

chf(cd, cr)

RealType

返回分布的累积风险函数 (cumulative hazard function).

hazard(cd, cr)

RealType

返回分布的风险函数 (hazard function).

kurtosis(cd)

RealType

返回分布的峰度 (kurtosis).

kurtosis_excess(cd)

RealType

返回分布的超额峰度 (kurtosis excess).

mean(cd)

RealType

返回分布的均值.

mode(cd)

RealType

返回分布的众数 (mode).

skewness(cd)

RealType

返回分布的偏度 (skewness).

standard_deviation(cd)

RealType

返回分布的标准差.

variance(cd)

RealType

返回分布的方差.
