第一类和第二类球 Bessel 函数

概要

#include <boost/math/special_functions/bessel.hpp> 

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type sph_bessel(unsigned v, T2 x);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type sph_bessel(unsigned v, T2 x, const Policy&);

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type sph_neumann(unsigned v, T2 x);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type sph_neumann(unsigned v, T2 x, const Policy&);
说明

函数 sph_bessel 和 sph_neumann 分别返回第一类和第二类球 Bessel 函数的结果:

sph_bessel(v, x) = jv(x)

sph_neumann(v, x) = yv(x) = nv(x)

其中:

当只有一个参数类型 T 时, 这些函数的返回类型按照 结果类型计算规则 计算.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

只要结果未定义或为复数, 这些函数就返回 domain_error 的结果: 这发生在 x < 0 时.

类似地, yv 对较大的 x 也是周期性的, 但对较小的 x 趋于 -∞:
