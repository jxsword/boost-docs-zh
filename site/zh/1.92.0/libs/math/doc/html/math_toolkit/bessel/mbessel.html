第一类和第二类变形 Bessel 函数

概要

#include <boost/math/special_functions/bessel.hpp> 

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_bessel_i(T1 v, T2 x);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_bessel_i(T1 v, T2 x, const Policy&);

template <class T1, class T2>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_bessel_k(T1 v, T2 x);

template <class T1, class T2, class Policy>
BOOST_MATH_GPU_ENABLED calculated-result-type cyl_bessel_k(T1 v, T2 x, const Policy&);
说明

函数 cyl_bessel_i 和 cyl_bessel_k 分别返回第一类和第二类变形 Bessel 函数的结果:

cyl_bessel_i(v, x) = Iv(x)

cyl_bessel_k(v, x) = Kv(x)

其中:

当 T1 和 T2 为不同类型时, 这些函数的返回类型按照 结果类型计算规则 计算. 对于 T1 为整数这一较常见情形, 这些函数也做了优化.

最后一个 Policy 参数是可选的,可用于控制函数的行为:如何处理错误、使用什么精度级别等. 详情请参阅 policy 文档.

只要结果未定义或为复数, 这些函数就返回 domain_error 的结果. 对于 cyl_bessel_j 当 x < 0 且 v 不是整数, 或当 x == 0 且 v != 0 时会出现这种情况. 对于 cyl_neumann 当 x <= 0 时会出现.

实现

以下情形会最先作为特殊情形处理:

计算 x < 0 时的 Iv 时, ν 必须是整数, 否则发生定义域错误. 若 ν 是整数, 则函数在 ν 为奇数时是奇函数、ν 为偶数时是偶函数, 于是我们可以把它反射到 x > 0.

v 等于 0、1 或 0.5 的 Iv 作为特殊情形处理.

0 和 1 两种情形使用有限和无穷区间上的多项式逼近. 逼近形式基于 Pavel Holoborodko 的"Rational Approximations for the Modified Bessel Function of the First Kind - I0(x) for Computations with Double Precision", 并由我们扩展到最高 128 位精度 (每种目标精度使用不同的逼近).

当 x 相对于 v 较小时, Ivx 最好直接用级数计算:

一般情形下, 我们先借助反射公式把 ν 规范化到 [0, [inf]).

令 μ = ν - floor(ν + 1/2), 则 μ 是 ν 的小数部分, 满足 |μ| <= 1/2 (后面收敛时需要这一点). 思路是计算 Kμ(x) 和 Kμ+1(x), 再用它们得到 Iν(x) 和 Kν(x).

该算法由 Temme 提出:

N.M. Temme, On the numerical evaluation of the modified bessel function of the third kind, Journal of Computational Physics, vol 19, 324 (1975),

(W.J. Lentz, Generating Bessel functions in Mie scattering calculations using continued fractions, Applied Optics, vol 15, 668 (1976)).

它们的收敛速度取决于 x, 因此对较大的 x 和较小的 x 需要不同的策略.
