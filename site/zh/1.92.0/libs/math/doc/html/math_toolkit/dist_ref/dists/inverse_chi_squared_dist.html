逆卡方分布 

#include <boost/math/distributions/inverse_chi_squared.hpp>
namespace boost{ namespace math{

template <class RealType = double,
          class Policy   = policies::policy<> >
class inverse_chi_squared_distribution
{
public:
   typedef RealType value_type;
   typedef Policy   policy_type;

   BOOST_MATH_GPU_ENABLED inverse_chi_squared_distribution(RealType df = 1); // Not explicitly scaled, default 1/df.
   BOOST_MATH_GPU_ENABLED inverse_chi_squared_distribution(RealType df, RealType scale = 1/df);  // Scaled.

   BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom()const; // Default 1.
   BOOST_MATH_GPU_ENABLED RealType scale()const; // Optional scale [xi] (variance), default 1/degrees_of_freedom.
};

}} // namespace boost // namespace math

逆卡方分布是变量的倒数的连续概率分布, 该变量服从卡方分布.

下面给出的资料用令人困惑的不同公式与不同符号表示该分布的 pdf, 但它们其实是同一个分布, 或者通过变量替换或尺度选择相互关联.

提供两个构造函数, 分别实现带尺度与 (隐式) 不带尺度的版本.

主版本带有显式的尺度参数, 用来实现 scaled inverse chi_squared distribution.

第二个版本的隐式尺度为 1/自由度, 给出 Wikipedia inverse chi_squared distribution 中的第 1 种定义. 通过显式指定尺度 = 1 可以实现 Wikipedia inverse chi_squared distribution 的第 2 种定义.

两种定义在 Wolfram Mathematica 与 The R Project for Statistical Computing (geoR) 中也可用, 其默认尺度为 1/自由度.

inverse_chi_squared 分布用于 贝叶斯统计: 带尺度的逆卡方分布是均值已知、模型参数为 σ² (方差) 的正态分布的共轭先验.

参见 共轭先验, 其中包括分布及其先验的表格.

另请参见 逆 Gamma 分布 与 卡方分布.

inverse_chi_squared 分布是 inverse_gamma 分布的特例, 其 ν (degrees_of_freedom) 对应形状 (α), 尺度为 (β), 其中

α= ν /2 且 β = ½

注释

此分布 确实 提供该 typedef:

typedef inverse_chi_squared_distribution<double> inverse_chi_squared;

如果你想要一个 double 精度的 inverse_chi_squared 分布, 可以使用

boost::math::inverse_chi_squared_distribution<>

或者你可以写 inverse_chi_squared my_invchisqr(2, 3);

对于自由度参数 ν, (未带尺度) 的逆卡方分布由概率密度函数 (PDF) 定义:

f(x;ν) = 2-ν/2 x-ν/2-1 e-1/2x / Γ(ν/2)

以及累积分布函数 (CDF)

F(x;ν) = Γ(ν/2, 1/2x) / Γ(ν/2)

对于自由度参数 ν 与尺度参数 ξ, 带尺度 的逆卡方分布由概率密度函数 (PDF) 定义:

f(x;ν, ξ) = (ξν/2)ν/2 e-νξ/2x x-1-ν/2 / Γ(ν/2)

以及累积分布函数 (CDF)

F(x;ν, ξ) = Γ(ν/2, νξ/2x) / Γ(ν/2)

成员函数 
BOOST_MATH_GPU_ENABLED inverse_chi_squared_distribution(RealType df = 1); // Implicitly scaled 1/df.
BOOST_MATH_GPU_ENABLED inverse_chi_squared_distribution(RealType df = 1, RealType scale); // Explicitly scaled.

构造一个自由度为 ν (df) 的逆卡方分布, 尺度为 scale, 默认值为 1/df.

要求自由度 ν 参数大于零, 否则调用 domain_error.

BOOST_MATH_GPU_ENABLED RealType degrees_of_freedom()const;

返回此分布的 degrees_of_freedom ν 参数.

BOOST_MATH_GPU_ENABLED RealType scale()const;

返回此分布的尺度 ξ 参数.

非成员访问器

对所有分布通用的一系列常规非成员访问函数都受支持: Cumulative Distribution Function, Probability Density Function, Quantile, Hazard Function, Cumulative Hazard Function, __logcdf, __logpdf, mean, median, mode, variance, standard deviation, skewness, kurtosis, kurtosis_excess, range 和 support. 对此分布, 所有非成员访问函数都标记有 BOOST_MATH_GPU_ENABLED 且可在主机和设备上运行.

随机变量的定义域为 [0,+∞].

注释

与某些定义不同, 本实现把随机变量等于零作为一种特殊情况支持, 此时 pdf 与 cdf 都返回零.

精度

逆 gamma 分布的实现与 Inverse Gamma Distribution 一样借助不完全 gamma 函数: 使用 gamma_p 与 gamma_q 及其反函数 gamma_p_inv 与 gamma_q_inv. 更多信息请参见这些函数的精度数据. 但一般来说, gamma (因而逆 gamma) 的结果常精确到几个 epsilon, 对于 64 位 double 精度超过 14 位十进制数字; 除非涉及迭代, 例如估计自由度时.

在下表中, ν 是分布的自由度参数, ξ 是尺度参数, x 是随机变量, p 是概率, 而 q = 1-p 是其补. 逆 gamma 函数用 α 表示形状、β 表示尺度: α = ν/2 且 β = ν * ξ/2.

函数

实现说明

pdf

使用关系式: pdf = gamma_p_derivative(α, β/ x, β) / x * x

cdf

使用关系式: p = gamma_q(α, β / x)

cdf 补函数

使用关系式: q = gamma_p(α, β / x)

quantile

使用关系式: x = β/ gamma_q_inv(α, p)

由补函数求 quantile

使用关系式: x = α/ gamma_p_inv(α, q)

众数

ν * ξ / (ν + 2)

中位数

没有已知的闭式解析方程, 但按 quantile(0.5) 求值

均值

当 ν > 2 时为 νξ / (ν - 2), 否则为 domain_error

方差

当 ν > 4 时为 2 ν² ξ² / ((ν -2)² (ν -4)), 否则为 domain_error

偏度

当 ν > 6 时为 4 √2 √(ν-4) /(ν-6), 否则为 domain_error

kurtosis_excess

当 ν > 8 时为 12 * (5ν - 22) / ((ν - 6) * (ν - 8)), 否则为 domain_error

峰度

当 ν > 8 时为 3 + 12 * (5ν - 22) / ((ν - 6) * (ν-8)), 否则为 domain_error
