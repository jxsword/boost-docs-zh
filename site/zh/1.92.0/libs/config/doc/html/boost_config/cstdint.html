概述

头文件 <boost/cstdint.hpp> 提供对编写需要特定整数宽度的可移植代码有用的 typedef. 所有 typedef 都位于命名空间 boost 中.

这些类型的规格基于 ISO/IEC 9899:1999 C 语言标准头文件 <stdint.h>. C 标准所要求的 64 位类型在 boost 头文件中并非必需, 且可能并非在所有平台/编译器上都提供, 因为 long long [尚未] 被 C++ 标准包含.

测试程序参见 cstdint_test.cpp.

设计理由

Boost.Integer 头文件和类的组织设计旨在利用 1999 C 标准的 <stdint.h> 类型, 同时不按 1998 C++ 标准造成未定义行为. 头文件 <boost/cstdint.hpp> 使标准整数类型在命名空间 boost 中安全可用, 而不向命名空间 std 放入任何名称. 其意图是与 C++ 标准库互补而非竞争. 若未来的某个 C++ 标准包含了 <stdint.h> 和 <cstdint>, 那么 <boost/cstdint.hpp> 仍会继续工作, 但将变得冗余, 并可安全弃用.

由于这些是 boost 头文件, 其名称遵循 boost 头文件命名约定, 而非 C++ 标准库头文件命名约定.

买家自慎 (Caveat emptor)

作为实现上的副产品, 某些 C <limits.h> 宏名可能对 <boost/cstdint.hpp> 的用户可见. 不要使用这些宏; 它们不属于任何 Boost 规定的接口. 请改用 boost::integer_traits<> 或 std::numeric_limits<>.

作为另一个实现上的副产品, 某些 C <stdint.h> typedef 名称可能对 <boost/cstdint.hpp> 的用户在全局命名空间中可见. 不要使用这些名称; 它们不属于任何 Boost 规定的接口. 请改用命名空间 boost 中的相应名称.

精确宽度整数类型

typedef int#_t (其中 # 替换为宽度) 指定恰好 # 位的带符号整数类型; 例如 int8_t 表示 8 位带符号整数类型. 类似地, typedef uint#_t 指定恰好 # 位的无符号整数类型.

这些类型是可选的. 不过, 如果平台支持宽度为 8、16、32、64 位或其任意组合的整数类型, 那么 <boost/cstdint.hpp> 确实会提供相应的 typedef.

int64_t 和 uint64_t 的缺失由宏 BOOST_NO_INT64_T 指示.

最小宽度整数类型

typedef int_least#_t (其中 # 替换为宽度) 指定宽度至少为 # 位的带符号整数类型, 且没有更小尺寸的带符号整数类型具有至少该指定宽度. 因此, int_least32_t 表示宽度至少为 32 位的最小带符号整数类型. 类似地, typedef 名 uint_least#_t 指定宽度至少为 # 位的无符号整数类型, 且没有更小尺寸的无符号整数类型具有至少该指定宽度.

以下最小宽度整数类型为所有平台提供:

  • int_least8_t
  • int_least16_t
  • int_least32_t
  • uint_least8_t
  • uint_least16_t
  • uint_least32_t

以下类型仅在包含 <boost/cstdint.hpp> 之后宏 BOOST_NO_INT64_T 未定义时才可用:

  • int_least64_t
  • uint_least64_t

所有其他最小宽度整数类型都是可选的.

最快最小宽度整数类型

typedef int_fast#_t (其中 # 替换为宽度) 指定宽度至少为 # 位的最快带符号整数类型. 类似地, typedef 名 uint_fast#_t 指定宽度至少为 # 位的最快无符号整数类型.

不保证这些类型对所有用途都是最快的. 但无论如何, 它们满足符号性和宽度要求.

以下最快最小宽度整数类型为所有平台提供:

  • int_fast8_t
  • int_fast16_t
  • int_fast32_t
  • uint_fast8_t
  • uint_fast16_t
  • uint_fast32_t

以下类型仅在包含 <boost/cstdint.hpp> 之后宏 BOOST_NO_INT64_T 未定义时才可用:

  • int_fast64_t
  • uint_fast64_t

所有其他最快最小宽度整数类型都是可选的.

最大宽度整数类型

typedef intmax_t 指定能够表示任何带符号整数类型的任何值的带符号整数类型.

typedef uintmax_t 指定能够表示任何无符号整数类型的任何值的无符号整数类型.

这些类型为所有平台提供.

整数常量宏

包含此头文件后, 以下宏总是有定义; 它们允许声明宽度至少为指定宽度的整数常量: INT8_C, UINT8_C, INT16_C, UINT16_C, INT32_C, UINT32_C, INTMAX_C, UINTMAX_C.

若宏 BOOST_NO_INT64_T 未定义, 则宏 INT64_C 和 UINT64_C 也有定义.

作为实现上的副产品, C99 宏 __STDC_CONSTANT_MACROS 也有定义.

例如:

#include <boost/cstdint.hpp>

// Here the constant 0x1FFFFFFFF has the correct suffix applied:
static const boost::uint64_t c = INT64_C(0x1FFFFFFFF);

用于存储指针的整数类型

typedef intptr_t 和 uintptr_t 分别定义了各自能够存储一个指针的带符号和无符号整数. 当这些类型可用时, 会设置宏 BOOST_HAS_INTPTR_T.
