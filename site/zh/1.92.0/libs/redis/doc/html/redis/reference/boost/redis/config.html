boost::redis::config

配置连接类使用的参数.

概要

声明于 <boost/redis/config.hpp>

struct config;

数据成员

名称

说明

use_ssl

是否使用 TLS 而不是明文连接.

addr

对于 TCP 连接, Redis 服务器的主机名和端口. 使用哨兵 (Sentinel) 时忽略.

unix_socket

服务器监听的 UNIX 域套接字路径.

username

(已弃用) 建立连接期间用于身份验证的用户名.

password

(已弃用) 建立连接期间用于身份验证的密码.

clientname

(已弃用) 建立连接期间使用的客户端名称参数.

database_index

(已弃用) 建立连接期间传递给 SELECT 命令的数据库索引.

health_check_id

健康检查器发送的 PING 命令所使用的消息.

log_prefix

(已弃用) 设置日志器前缀, 即打印在日志消息之前的字符串.

resolve_timeout

允许解析操作耗费的时间跨度. 使用哨兵 (Sentinel) 时, 此设置适用于主服务器和副本.

connect_timeout

允许连接操作耗费的时间跨度. 使用哨兵 (Sentinel) 时, 此设置适用于主服务器和副本.

ssl_handshake_timeout

允许 SSL 握手操作耗费的时间跨度. 使用哨兵 (Sentinel) 时, 此设置适用于主服务器和副本.

health_check_interval

两次健康检查之间的时间跨度. 设为零可禁用健康检查.

reconnect_wait_interval

两次连续连接重试之间等待的时间跨度. 设为零可禁用重连.

max_read_size

套接字读缓冲区的最大大小 (以字节为单位) .

read_buffer_append_size

读缓冲区的增长大小.

use_setup

允许在建立连接期间使用自定义请求.

setup

建立连接后要执行的请求.

sentinel

哨兵 (Sentinel) 的配置值. 仅当 sentinel_config::addresses 非空时才启用 Sentinel.
