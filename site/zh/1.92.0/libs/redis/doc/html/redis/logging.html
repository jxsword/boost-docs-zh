日志

connection::async_run 是一个复杂的算法, 具有内置重连等特性. 这可能使配置问题 (例如主机名配置错误) 难以调试——Boost.Redis 会不断重试连接同一个主机名. 为此, Boost.Redis 内置了轻量级日志方案, 并且默认会将一些状态消息记录到 stderr.

可以通过向连接的构造函数传递 logger 对象来自定义日志. 例如, 可以这样写来禁用日志:

asio::io_context ioc;
connection conn {ioc, logger{logger::level::disabled}};

库记录的每条消息都附有一个 类似 syslog 的严重级别 标签 (一个 logger::level) . 您可以通过创建带有特定级别的 logger 来按严重级别过滤消息:

asio::io_context ioc;

// Logs to stderr messages with severity >= level::error.
// This will hide all informational output.
connection conn {ioc, logger{logger::level::error}};

logger 构造函数接受一个 std::function<void(logger::level, std::string_view)> 作为第二个参数. 如果提供, Boost.Redis 在记录日志时将调用该函数而不是打印到 stderr. 这可用于集成第三方日志库. 示例代码参见我们的 spdlog 集成示例.
