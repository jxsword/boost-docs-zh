boost::redis::request

表示一个 Redis 请求.

概要

声明于 <boost/redis/request.hpp>

class request;

说明

一个请求由一条或多条 Redis 命令组成, 在 Redis 文档中被称为流水线 (pipeline) . 更多信息请参见相关文档.

例如:

request r;
r.push("SET", "k1", "some_value");
r.push("SET", "k2", "other_value");
r.push("GET", "k3");

内部存储使用 std::string.
