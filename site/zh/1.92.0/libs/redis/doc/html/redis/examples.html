示例

下面的示例展示了如何使用本文档中讨论的各项特性:

  • cpp20_intro.cpp: 不使用 awaitable 运算符.

  • cpp20_intro_tls.cpp: 通过 TLS 通信.

  • cpp20_unix_sockets.cpp: 通过 UNIX 域套接字通信.

  • cpp20_containers.cpp: 展示如何发送和接收 STL 容器以及如何使用事务.

  • cpp20_json.cpp: 展示如何使用 Boost.Json 序列化类型.

  • cpp20_protobuf.cpp: 展示如何使用 protobuf 序列化类型.

  • cpp20_sentinel.cpp: 展示如何在哨兵 (Sentinel) 部署中使用本库.

  • cpp20_subscriber.cpp: 展示如何实现带重连重订阅的 pubsub.

  • cpp20_echo_server.cpp: 一个简单的 TCP 回显服务器.

  • cpp20_chat_room.cpp: 基于 Redis pubsub 构建的命令行聊天室.

  • cpp17_intro.cpp: 使用回调并要求 C++17.

  • cpp17_intro_sync.cpp: 在单独线程中运行 async_run 并对 async_exec 执行同步调用.

  • cpp17_spdlog.cpp: 展示如何在 Boost.Redis 中使用 spdlog 等第三方日志库.

一些异步示例中使用的 main 函数已被抽取到 main.cpp 文件中.
