boost::redis::resp3::flat_tree

以连续方式存储数据的泛型响应.

概要

声明于 <boost/redis/resp3/flat_tree.hpp>

class flat_tree;

说明

实现了一个 RESP3 节点容器. 它类似于 boost::redis::resp3::tree, 但节点数据以连续方式存储. 这使得在重用 flat_tree 对象时可以摊销为零分配. 与 tree 一样, 它可以包含对多条 Redis 命令的响应或多个服务器推送. 使用 get_total_msgs 可获取此对象包含多少个响应.

对象通常由用户创建, 并传递给 connection::async_exec 用作响应容器. 填充后, 它们可以用作 resp3::node_view 对象的 const 范围. 提供了常用的随机访问范围方法 (如 at、size 或 front) . 填充后, flat_tree 不能被修改, clear 和赋值除外.

flat_tree 满足 std::ranges::contiguous_range.

flat_tree 在概念上类似于一对 std::vector 对象: 一个持有 resp3::node_view 对象, 另一个拥有这些视图所指向的字符串数据. 节点容量和数据容量就是这两个向量的容量.
