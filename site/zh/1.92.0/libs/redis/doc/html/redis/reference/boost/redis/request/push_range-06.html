boost::redis::request::push_range

向请求末尾追加一条新命令.

概要

声明于 <boost/redis/request.hpp>

template<class Range>
void
push_range(
    std::string_view cmd,
    Range const& range,
    decltype(std::cbegin(range))* = nullptr);

说明

等价于接受 begin 和 end 迭代器范围的重载.

如果传入的范围为空, 则不添加任何命令, 此函数成为空操作.

传入范围的值类型应满足以下条件之一:

  • 该类型可转换为 std::string_view. 范围内的每个元素添加一个参数.

  • 该类型是整数类型. 范围内的每个元素添加一个参数.

  • 该类型支持 boost_redis_to_bulk 函数. 范围内的每个元素添加一个参数. 此函数是一个定制点, 必须通过 ADL 使其可用, 且必须具有签名 void boost_redis_to_bulk(std::string& to, T const& t);.

  • 该类型是 std::pair 的实例化, 且两个实参都支持上述要点之一. 范围内的每个元素添加两个参数. 不允许嵌套的 pair.

  • 该类型是 std::tuple 的实例化, 且每个实参都支持上述要点之一. 范围内的每个元素添加 N 个参数, N 为元组大小. 不允许嵌套的 tuple.

模板参数

名称

说明

Range

可传递给 std::begin() 和 std::end() 以获取迭代器的类型.

参数

名称

说明

cmd

要执行的命令. 它应当是一条 redis 或 sentinel 命令, 例如 "SET".

range

包含命令参数的范围.
