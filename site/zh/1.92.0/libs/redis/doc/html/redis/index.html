引言

Boost.Redis 是一个高层的 Redis 和 Valkey 客户端库, 构建于 Boost.Asio 之上, 实现了 Redis 协议 RESP3.

要求

使用 Boost.Redis 的要求如下:

  • Boost 1.84 或更高版本. 自 Boost 1.84 起 Boost.Redis 已包含在 Boost 安装中.

  • C++17 或更高版本. 支持的编译器包括 gcc 11 及更高版本、clang 11 及更高版本, 以及 Visual Studio 16 (2019) 及更高版本.

  • Redis 6 或更高版本, 或 Valkey (任意版本) . 数据库服务器必须支持 RESP3. 我们打算长期保持与 Redis 和 Valkey 的兼容性.

  • OpenSSL.

本文档假定读者具备关于 Redis 和 Boost.Asio 的基础知识.

构建库

要使用本库, 需要包含以下内容:

#include <boost/redis/src.hpp>

在应用程序中恰好一个源文件中包含上述内容. 除此之外, 本库是仅头文件库.

Boost.Redis 无条件依赖 OpenSSL. 使用 Boost.Redis 的目标需要链接 OpenSSL 库.

教程

下面的代码使用一个短生命周期的连接来 ping 一个 Redis 服务器:

#include <boost/redis/connection.hpp>
#include <boost/asio/co_spawn.hpp>
#include <boost/asio/consign.hpp>
#include <boost/asio/detached.hpp>
#include <iostream>

namespace net = boost::asio;
using boost::redis::request;
using boost::redis::response;
using boost::redis::config;
using boost::redis::connection;

auto co_main(config const& cfg) -> net::awaitable<void>
{
   auto conn = std::make_shared<connection>(co_await net::this_coro::executor);
   conn->async_run(cfg, {}, net::consign(net::detached, conn));

   // A request containing only a ping command.
   request req;
   req.push("PING", "Hello world");

   // Response object.
   response<std::string> resp;

   // Executes the request.
   co_await conn->async_exec(req, resp);
   conn->cancel();

   std::cout << "PING: " << std::get<0>(resp).value() << std::endl;
}

async_run 与 async_exec 函数所扮演的角色如下:

  • connection::async_exec: 执行请求中包含的命令, 并将各个响应存储到响应对象中. 可以在代码中的多个位置并发调用.

  • connection::async_run: 保持连接健康. 它负责主机名解析、会话建立、健康检查、重连以及底层读写操作的协调. 每个连接只应调用一次, 与要执行的请求数量无关.
