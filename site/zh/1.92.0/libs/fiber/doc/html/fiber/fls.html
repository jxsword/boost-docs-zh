纤程局部存储

概要

纤程局部存储允许为每个纤程提供给定数据项的独立实例.

纤程退出时的清理

当纤程退出时, 与每个 fiber_specific_ptr 实例关联的对象都会被销毁. 默认情况下, 指针 p 所指向的对象通过调用 delete p 来销毁, 但对于特定的某个 fiber_specific_ptr 实例, 可以通过向构造函数提供清理例程 func 来覆盖此行为. 在这种情况下, 对象通过调用 func(p) 来销毁. 清理函数的调用顺序未作规定.

fiber_specific_ptr 类

#include <boost/fiber/fss.hpp>

namespace boost {
namespace fibers {

template< typename T >
class fiber_specific_ptr {
public:
    typedef T   element_type;

    fiber_specific_ptr();

    explicit fiber_specific_ptr( void(*fn)(T*) );

    ~fiber_specific_ptr();

    fiber_specific_ptr( fiber_specific_ptr const&) = delete;
    fiber_specific_ptr & operator=( fiber_specific_ptr const&) = delete;

    T * get() const noexcept;

    T * operator->() const noexcept;

    T & operator*() const noexcept;

    T * release();

    void reset( T *);
};

}}

构造函数 

fiber_specific_ptr();
explicit fiber_specific_ptr( void(*fn)(T*) );

要求:

delete this->get() 良构; fn(this->get()) 不抛出异常

效果:

构造一个 fiber_specific_ptr 对象, 用于存储一个指向每个纤程特有的 T 类型对象的指针. 当调用 reset() 或纤程退出时, fiber_specific_ptr 会调用 fn(this->get()). 如果使用无参构造函数, 将使用基于默认 delete 的清理函数来销毁纤程局部对象.

抛出:

如果发生错误则为 fiber_error.

析构函数 

~fiber_specific_ptr();

要求:

与该 fiber_specific_ptr 关联的所有纤程特定实例 (可能与本纤程关联的那个除外) 必须为 nullptr.

效果:

调用 this->reset() 来清理当前纤程的关联值, 并销毁 *this.

备注:

该要求是一项实现上的限制. 如果析构函数承诺删除所有纤程的实例, 实现将不得不维护一个由所有拥有关联特定指针的纤程组成的列表, 这与纤程特定数据的目标相悖. 一般来说, fiber_specific_ptr 应当比使用它的纤程存活得更久.

注释

需要小心确保: 在 fiber_specific_ptr 实例被销毁后仍在运行的任何纤程, 不会在该实例上调用任何成员函数.

Member function get() 

T * get() const noexcept;

返回:

与当前纤程关联的指针.

抛出:

无.

注释

对于每个纤程, fiber_specific_ptr 实例的初始关联值都是 nullptr.

Member function operator->() 

T * operator->() const noexcept;

要求:

this->get() 不是 nullptr.

返回:

this->get()

抛出:

无.

Member function operator*() 

T & operator*() const noexcept;

要求:

this->get() 不是 nullptr.

返回:

*(this->get())

抛出:

无.

Member function release() 

T * release();

效果:

返回 this->get(), 并把 nullptr 存储为与当前纤程关联的指针, 且不调用清理函数.

后置条件:

this->get()==nullptr

抛出:

无.

Member function reset() 

void reset( T * new_value);

效果:

如果 this->get()!=new_value 且 this->get() 不是 nullptr, 则酌情调用 delete this->get() 或 fn(this->get()). 把 new_value 存储为与当前纤程关联的指针.

后置条件:

this->get()==new_value

抛出:

在前一个值的清理期间抛出的异常.
