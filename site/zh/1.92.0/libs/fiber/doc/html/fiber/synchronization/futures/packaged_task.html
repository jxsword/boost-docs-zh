模板 packaged_task<>

一个 packaged_task<> 包装一个返回值的可调用目标, 使返回值可以异步计算.

packaged_task<> 的惯常用法如下:

  1. 实例化 packaged_task<>, 模板参数与可调用对象的签名匹配. 把可调用对象传给 构造函数.
  2. 调用 packaged_task::get_future(), 并捕获返回的 future<> 实例.
  3. 启动一个 fiber 来运行新的 packaged_task<>, 并传入原始可调用对象所需的任何参数.
  4. 调用 fiber::detach() (作用于新启动的 fiber).
  5. 稍后, 从 future<> 中取回结果.

这实际上正是 fibers::async() 所封装的东西.

#include <boost/fiber/future/packaged_task.hpp>

namespace boost {
namespace fibers {

template< class R, typename ... Args >
class packaged_task< R( Args ... ) > {
public:
    packaged_task() noexcept;

    template< typename Fn >
    explicit packaged_task( Fn &&);

    template< typename Fn, typename Allocator >
    packaged_task( std::allocator_arg_t, Allocator const&, Fn &&);

    packaged_task( packaged_task &&) noexcept;

    packaged_task & operator=( packaged_task &&) noexcept;

    packaged_task( packaged_task const&) = delete;

    packaged_task & operator=( packaged_task const&) = delete;

    ~packaged_task();

    void swap( packaged_task &) noexcept;

    bool valid() const noexcept;

    future< R > get_future();

    void operator()( Args ...);

    void reset();
};

template< typename Signature >
void swap( packaged_task< Signature > &, packaged_task< Signature > &) noexcept;

}}
默认构造函数packaged_task() 
packaged_task() noexcept;

效果:

构造一个 packaged_task 类的对象, 不带 共享状态.

抛出:

无.

模板化构造函数packaged_task() 
template< typename Fn >
explicit packaged_task( Fn && fn);

template< typename Fn, typename Allocator >
packaged_task( std::allocator_arg_t, Allocator const& alloc, Fn && fn);

效果:

构造一个 packaged_task 类的对象, 带有一个 共享状态, 并把可调用目标 fn 复制或移动到内部存储中.

抛出:

由内存分配导致的异常.

注释:

的签名应具有可转换为 Fn 的返回类型R.

参见:

std::allocator_arg_t

移动构造函数 
packaged_task( packaged_task && other) noexcept;

效果:

创建 packaged_task, 即把 共享状态 从 other 移动而来.

后置条件:

other 不含有效的共享状态.

抛出:

无.

析构函数 
~packaged_task();

效果:

销毁 *this, 并放弃 共享状态 (若共享状态已就绪); 否则存储 future_error 带错误条件 future_errc::broken_promise, 效果如同调用 promise::set_exception(): 共享状态被置为就绪.

Member function operator=() 

packaged_task & operator=( packaged_task && other) noexcept;

效果:

把 共享状态 的所有权转移给 *this.

后置条件:

other 不含有效的共享状态.

抛出:

无.

Member function swap() 

void swap( packaged_task & other) noexcept;

效果:

在 other 与 之间交换 共享状态*this.

抛出:

无.

Member function valid() 

bool valid() const noexcept;

效果:

返回 true (若 *this 含有 共享状态).

抛出:

无.

Member function get_future() 

future< R > get_future();

返回:

一个 future<>, 带有相同的 共享状态.

抛出:

future_error 带 future_errc::future_already_retrieved 或 future_errc::no_state.

Member function operator()() 

void operator()( Args && ... args);

效果:

调用所存储的可调用目标. 可调用目标抛出的任何异常 fn 都会存入 共享状态, 效果如同 promise::set_exception(). 否则, fn 所返回的值也会如同 promise::set_value() 那样存入共享状态.

抛出:

future_error 带 future_errc::no_state.

Member function reset() 

void reset();

效果:

重置 共享状态 并放弃之前执行的结果. 将构造一个新的共享状态.

抛出:

future_error 带 future_errc::no_state.

Non-member function swap() 

template< typename Signature >
void swap( packaged_task< Signature > & l, packaged_task< Signature > & r) noexcept;

效果:

与 l.swap( r) 相同.
