future

Future
模板 promise<>
模板 packaged_task<>
概述

futures 库提供了一种处理异步未来值的手段, 无论这些值是由另一个纤程生成, 还是在单个纤程上响应外部刺激而生成, 亦或是按需生成.

这是通过提供四个类模板来实现的: future<> 和 shared_future<> 用于获取异步结果, 而 promise<> 和 packaged_task<> 则用于生成异步结果.

一个 future<> 实例持有对结果的唯一引用. 所有权可以通过移动构造函数或移动赋值运算符在实例之间转移, 但至多只有一个实例持有对给定异步结果的引用. 当结果就绪时, 会以右值引用从 future::get() 返回, 以便按类型的需要移动或复制结果.

另一方面, 可以有多个 shared_future<> 实例引用同一个结果. 实例可以自由复制和赋值, 且 shared_future::get() 返回一个 const 引用, 因此多次调用 shared_future::get() 是安全的. 你可以把 future<> 实例移动到 shared_future<> 实例中, 从而转移关联异步结果的所有权, 但反过来不行.

fibers::async() 是一种运行异步任务的简单方式. 调用 async() 会派生一个纤程并返回一个 future<>, 该对象将交付纤程函数的结果.

创建异步值

你可以通过 promise<> 或 packaged_task<> 在 future 中设置值. packaged_task<> 是一个具有 void 返回类型的可调用对象, 它包装了一个返回指定类型的函数或可调用对象. 当 packaged_task<> 被调用时, 它会转而调用所包含的函数, 并用该函数的返回值填充一个 future. 这回答了一个经久不衰的问题: “如何从纤程返回一个值?” 把你想要运行的函数打包为 packaged_task<>, 并把打包任务传给纤程构造函数. 从打包任务获取的 future 随后可用于取得返回值. 若函数抛出异常, 异常将代替返回值存储在 future 中.

int calculate_the_answer_to_life_the_universe_and_everything() {
    return 42;
}

boost::fibers::packaged_task<int()> pt(calculate_the_answer_to_life_the_universe_and_everything);
boost::fibers::future<int> fi=pt.get_future();
boost::fibers::fiber(std::move(pt)).detach(); // launch task on a fiber

fi.wait(); // wait for it to finish

assert(fi.is_ready());
assert(fi.has_value());
assert(!fi.has_exception());
assert(fi.get()==42);

promise<> 则要更底层一些: 它只提供显式函数, 用于把值或异常存入关联的 future. 因此, promise 可用于值可能来自多个来源的情形.

boost::fibers::promise<int> pi;
boost::fibers::future<int> fi;
fi=pi.get_future();

pi.set_value(42);

assert(fi.is_ready());
assert(fi.has_value());
assert(!fi.has_exception());
assert(fi.get()==42);
