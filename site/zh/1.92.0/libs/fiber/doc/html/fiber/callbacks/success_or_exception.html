成功或异常

更符合现代 C++ 实践的封装会使用异常, 而不是 errorcode, 来向调用方传递失败. 基于 write_ec() 来编写这一点非常直接:

void write( AsyncAPI & api, std::string const& data) {
    AsyncAPI::errorcode ec = write_ec( api, data);
    if ( ec) {
        throw make_exception("write", ec);
    }
}

关键在于, 由于每个纤程都有自己的栈, 你无需重复繁琐的样板代码: 普通的封装手段即可奏效.
