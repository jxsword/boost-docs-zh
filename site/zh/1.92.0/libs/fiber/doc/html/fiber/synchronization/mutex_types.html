互斥量类型

mutex 类

#include <boost/fiber/mutex.hpp>

namespace boost {
namespace fibers {

class mutex {
public:
    mutex();
    ~mutex();

    mutex( mutex const& other) = delete;
    mutex & operator=( mutex const& other) = delete;

    void lock();
    bool try_lock();
    void unlock();
};

}}

mutex 提供独占式所有权的互斥量. 在任一时刻, 至多一个纤程可拥有给定 mutex 实例上的锁. 应当允许多个并发调用 lock()、try_lock() 和 unlock().

在 lock() 中被阻塞的纤程将被挂起, 直到持有者纤程通过调用 unlock() 释放锁.

Member function lock() 

void lock();

前置条件:

调用纤程不拥有该互斥量.

效果:

当前纤程阻塞, 直到可以获得所有权.

抛出:

lock_error

错误条件:

resource_deadlock_would_occur: 若 boost::this_fiber::get_id() 已拥有该互斥量.

Member function try_lock() 

bool try_lock();

前置条件:

调用纤程不拥有该互斥量.

效果:

尝试为当前纤程获取所有权而不阻塞.

返回:

true 若已为当前纤程获取所有权; 否则为 false.

抛出:

lock_error

错误条件:

resource_deadlock_would_occur: 若 boost::this_fiber::get_id() 已拥有该互斥量.

Member function unlock() 

void unlock();

前置条件:

当前纤程拥有 *this.

效果:

由当前纤程释放对 *this 的锁.

抛出:

lock_error

错误条件:

operation_not_permitted: 若 boost::this_fiber::get_id() 不拥有该互斥量.

timed_mutex 类

#include <boost/fiber/timed_mutex.hpp>

namespace boost {
namespace fibers {

class timed_mutex {
public:
    timed_mutex();
    ~timed_mutex();

    timed_mutex( timed_mutex const& other) = delete;
    timed_mutex & operator=( timed_mutex const& other) = delete;

    void lock();
    bool try_lock();
    void unlock();

    template< typename Clock, typename Duration >
    bool try_lock_until( std::chrono::time_point< Clock, Duration > const& timeout_time);
    template< typename Rep, typename Period >
    bool try_lock_for( std::chrono::duration< Rep, Period > const& timeout_duration);
};

}}

模板成员函数 try_lock_until() 

template< typename Clock, typename Duration >
bool try_lock_until( std::chrono::time_point< Clock, Duration > const& timeout_time);

前置条件:

调用纤程不拥有该互斥量.

效果:

尝试为当前纤程获取所有权. 阻塞直到可以获得所有权, 或到达指定时间. 若指定时间已过, 则行为如同 timed_mutex::try_lock().

返回:

true 若已为当前纤程获取所有权; 否则为 false.

抛出:

lock_error 及超时相关异常.

错误条件:

resource_deadlock_would_occur: 若 boost::this_fiber::get_id() 已拥有该互斥量.

recursive_mutex 类

#include <boost/fiber/recursive_mutex.hpp>

namespace boost {
namespace fibers {

class recursive_mutex {
public:
    recursive_mutex();
    ~recursive_mutex();

    recursive_mutex( recursive_mutex const& other) = delete;
    recursive_mutex & operator=( recursive_mutex const& other) = delete;

    void lock();
    bool try_lock() noexcept;
    void unlock();
};

}}

recursive_mutex 提供独占式所有权的递归互斥量. 在任一时刻, 至多一个纤程可拥有给定 recursive_mutex 实例上的锁. 应当允许多个并发调用 lock()、try_lock() 和 unlock(). 已独占拥有给定 recursive_mutex 实例的纤程可以调用 lock() 或 try_lock() 来获取该互斥量的额外一层所有权. unlock() 必须按单个纤程所获取的每一层所有权各调用一次, 之后其他纤程才能获取所有权.
