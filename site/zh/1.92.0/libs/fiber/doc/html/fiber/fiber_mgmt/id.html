fiber::id 类 

#include <boost/fiber/fiber.hpp>

namespace boost {
namespace fibers {

class id {
public:
    constexpr id() noexcept;

    bool operator==( id const&) const noexcept;

    bool operator!=( id const&) const noexcept;

    bool operator<( id const&) const noexcept;

    bool operator>( id const&) const noexcept;

    bool operator<=( id const&) const noexcept;

    bool operator>=( id const&) const noexcept;

    template< typename charT, class traitsT >
    friend std::basic_ostream< charT, traitsT > &
    operator<<( std::basic_ostream< charT, traitsT > &, id const&);
};

}}
构造函数 
constexpr id() noexcept;

效果:

表示 not-a-fiber 的一个实例.

抛出:

无.

Member function operator==() 

bool operator==( id const& other) const noexcept;

返回:

true——若 *this 与 other 表示同一个纤程, 或两者都表示 not-a-fiber; 否则为 false.

抛出:

无.

Member function operator!=() 

bool operator!=( id const& other) const noexcept;

返回:

! (other == * this)

抛出:

无.

Member function operator<() 

bool operator<( id const& other) const noexcept;

返回:

true——若 *this != other 为 true, 且 fiber::id 值的实现定义全序把 *this 排在 other 之前; 否则为 false.

抛出:

无.

Member function operator>() 

bool operator>( id const& other) const noexcept;

返回:

other < * this

抛出:

无.

Member function operator<=() 

bool operator<=( id const& other) const noexcept;

返回:

! (other < * this)

抛出:

无.

Member function operator>=() 

bool operator>=( id const& other) const noexcept;

返回:

! (* this < other)

抛出:

无.
