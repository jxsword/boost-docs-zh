Future

future 提供了一种访问异步操作结果的机制.

共享状态

在 promise<> 及其 future<> 背后, 隐藏着一个被称为它们的 共享状态 的未指明对象. 共享状态才是实际保存异步结果 (或异常) 的地方.

共享状态与 promise<> 一同实例化.

除了其来源 promise<> 之外, 一个 future<> 还持有对特定共享状态的唯一引用. 不过, 多个 shared_future<> 实例可以引用同一个底层共享状态.

由于 packaged_task<> 和 fibers::async() 是用 promise<> 实现的, 关于共享状态的讨论同样适用于它们.

枚举 future_status

限时等待操作 (future::wait_for() 和 future::wait_until()) 返回 future 的状态.

enum class future_status {
    ready,
    timeout,
    deferred  // not supported yet
};
ready

效果:

该 共享状态 已就绪.

timeout

效果:

该 共享状态 在超时过去之前未就绪.

注释

不支持 deferred future.

模板 future<>

一个 future<> 包含一个 共享状态, 该状态不与任何其他 future 共享.

#include <boost/fiber/future/future.hpp>

namespace boost {
namespace fibers {

template< typename R >
class future {
public:
    future() noexcept;

    future( future const& other) = delete;

    future & operator=( future const& other) = delete;

    future( future && other) noexcept;

    future & operator=( future && other) noexcept;

    ~future();

    bool valid() const noexcept;

    shared_future< R > share();

    R get();    // member only of generic future template
    R & get();  // member only of future< R & > template specialization
    void get(); // member only of future< void > template specialization

    std::exception_ptr get_exception_ptr();

    void wait() const;

    template< class Rep, class Period >
    future_status wait_for(
        std::chrono::duration< Rep, Period > const& timeout_duration) const;

    template< typename Clock, typename Duration >
    future_status wait_until(
        std::chrono::time_point< Clock, Duration > const& timeout_time) const;
};

}}
默认构造函数 
future() noexcept;

效果:

创建一个没有 共享状态 的 future. 构造之后 false == valid().

抛出:

无.

移动构造函数 
future( future && other) noexcept;

效果:

用 other 的 共享状态 构造一个 future. 构造之后 false == other.valid().

抛出:

无.

析构函数 
~future();

效果:

销毁 future; 所有权被放弃.

注释:

~future() 不会 阻塞调用纤程.

考虑如下这样的序列:

  1. 实例化 promise<>
  2. 获取其 future<>, 经由 promise::get_future()
  3. 启动 fiber, 捕获 promise<>
  4. 销毁 future<>
  5. 调用 promise::set_value()

最后一次 set_value() 调用会成功, 但值被静默丢弃: 不能再获得另一个 future<> (来自该 promise<>).

Member function operator=() 

future & operator=( future && other) noexcept;

效果:

把 other 的 共享状态 移动给 this. 赋值后 false == other.valid().

抛出:

无.

Member function valid() 

bool valid() const noexcept;

效果:

返回 true (若 future 含有 共享状态).

抛出:

无.

Member function share() 

shared_future< R > share();

效果:

把状态移动到一个 shared_future<>.

返回:

一个 shared_future<>, 其 共享状态 原先属于 *this.

后置条件:

false == valid()

抛出:

future_error 带错误条件 future_errc::no_state.

Member function get() 

R get();    // member only of generic future template
R & get();  // member only of future< R & > template specialization
void get(); // member only of future< void > template specialization

前置条件:

true == valid()

返回:

等待直到 promise::set_value() 或 promise::set_exception() 被调用. 若 promise::set_value() 被调用, 则返回该值. 若 promise::set_exception() 被调用, 则抛出所指明的异常.

后置条件:

false == valid()

抛出:

future_error 带错误条件 future_errc::no_state, future_errc::broken_promise. 传给 promise::set_exception() 的任何异常都会被传播.

Member function get_exception_ptr() 

std::exception_ptr get_exception_ptr();

前置条件:

true == valid()

返回:

等待直到 promise::set_value() 或 promise::set_exception() 被调用. 若 set_value() 被调用, 返回一个默认构造的 std::exception_ptr. 若 set_exception() 被调用, 返回传入的 std::exception_ptr.

抛出:

future_error 带错误条件 future_errc::no_state.

注释:

get_exception_ptr() 不会 使 future 失效. 调用 get_exception_ptr() 之后, 你仍然可以调用 future::get().

Member function wait() 

void wait();

效果:

等待直到 promise::set_value() 或 promise::set_exception() 被调用.

抛出:

future_error 带错误条件 future_errc::no_state.

模板成员函数 wait_for() 

template< class Rep, class Period >
future_status wait_for( std::chrono::duration< Rep, Period > const& timeout_duration) const;

效果:

等待直到 promise::set_value() 或 promise::set_exception() 被调用, 或 timeout_duration 已经过去.

结果:

返回一个 future_status, 用于指示返回的原因.

抛出:

future_error 带错误条件 future_errc::no_state, 或超时相关异常.

模板成员函数 wait_until()

future_status wait_until( std::chrono::time_point< Clock, Duration > const& timeout_time) const;

效果:

等待直到 promise::set_value() 或 promise::set_exception() 被调用, 或 timeout_time 已经过去.

结果:

返回一个 future_status, 用于指示返回的原因.

抛出:

future_error 带错误条件 future_errc::no_state, 或超时相关异常.

模板 shared_future<>

一个 shared_future<> 包含一个 共享状态, 该状态可能与其它 shared_future<> 实例共享.

#include <boost/fiber/future/future.hpp>

namespace boost {
namespace fibers {

template< typename R >
class shared_future {
public:
    shared_future() noexcept;

    ~shared_future();

    shared_future( shared_future const& other);

    shared_future( future< R > && other) noexcept;

    shared_future( shared_future && other) noexcept;

    shared_future & operator=( shared_future && other) noexcept;

    shared_future & operator=( future< R > && other) noexcept;

    shared_future & operator=( shared_future const& other) noexcept;

    bool valid() const noexcept;

    R const& get(); // member only of generic shared_future template
    R & get();      // member only of shared_future< R & > template specialization
    void get();     // member only of shared_future< void > template specialization

    std::exception_ptr get_exception_ptr();

    void wait() const;

    template< class Rep, class Period >
    future_status wait_for(
        std::chrono::duration< Rep, Period > const& timeout_duration) const;

    template< typename Clock, typename Duration >
    future_status wait_until(
        std::chrono::time_point< Clock, Duration > const& timeout_time) const;
};

}}
默认构造函数 
shared_future();

效果:

创建一个没有 共享状态 的 shared_future. 构造之后 false == valid().

抛出:

无.

移动构造函数 
shared_future( future< R > && other) noexcept;
shared_future( shared_future && other) noexcept;

效果:

用 other 的 共享状态 构造一个 shared_future. 构造之后 false == other.valid().

抛出:

无.

复制构造函数 
shared_future( shared_future const& other) noexcept;

效果:

用 other 的 共享状态 构造一个 shared_future. 构造之后 other.valid() 保持不变.

抛出:

无.

析构函数 
~shared_future();

效果:

销毁 shared_future; 若未被共享, 则放弃所有权.

注释:

~shared_future() 不会 阻塞调用纤程.

Member function operator=() 

shared_future & operator=( future< R > && other) noexcept;
shared_future & operator=( shared_future && other) noexcept;
shared_future & operator=( shared_future const& other) noexcept;

效果:

把 other 的 共享状态 移动或复制给 this. 赋值后, other.valid() 的状态取决于调用了哪个重载: 接受 shared_future const& 的重载使其保持不变, 否则 false.

抛出:

无.

Member function valid() 

bool valid() const noexcept;

效果:

返回 true (若 shared_future 含有 共享状态).

抛出:

无.

Member function get() 

R const& get(); // member only of generic shared_future template
R & get();      // member only of shared_future< R & > template specialization
void get();     // member only of shared_future< void > template specialization

前置条件:

true == valid()

返回:

等待直到 promise::set_value() 或 promise::set_exception() 被调用. 若 promise::set_value() 被调用, 则返回该值. 若 promise::set_exception() 被调用, 则抛出所指明的异常.

后置条件:

false == valid()

抛出:

future_error 带错误条件 future_errc::no_state, future_errc::broken_promise. 传给 promise::set_exception() 的任何异常都会被传播.

前置条件:

true == valid()

返回:

等待直到 promise::set_value() 或 promise::set_exception() 被调用. 若 set_value() 被调用, 返回一个默认构造的 std::exception_ptr. 若 set_exception() 被调用, 返回传入的 std::exception_ptr.

抛出:

注释:

get_exception_ptr() 不会 使 shared_future 失效. 调用 get_exception_ptr() 之后, 你仍然可以调用 shared_future::get().

void wait();

效果:

Non-member function fibers::async() 

#include <boost/fiber/future/async.hpp>

namespace boost {
namespace fibers {

template< class Function, class ... Args >
future<
    std::result_of_t<
        std::decay_t< Function >( std::decay_t< Args > ... )
    >
>
async( Function && fn, Args && ... args);

template< class Function, class ... Args >
future<
    std::result_of_t<
        std::decay_t< Function >( std::decay_t< Args > ... )
    >
>
async( launch policy, Function && fn, Args && ... args);

template< typename StackAllocator, class Function, class ... Args >
future<
    std::result_of_t<
        std::decay_t< Function >( std::decay_t< Args > ... )
    >
>
async( launch policy, std::allocator_arg_t, StackAllocator salloc,
       Function && fn, Args && ... args);

template< typename StackAllocator, typename Allocator, class Function, class ... Args >
future<
    std::result_of_t<
        std::decay_t< Function >( std::decay_t< Args > ... )
    >
>
async( launch policy, std::allocator_arg_t, StackAllocator salloc,
       Allocator alloc, Function && fn, Args && ... args);

}}

效果:

执行 fn (在一个 fiber 中), 并返回关联的 future<>.

结果:

future<
    std::result_of_t<
        std::decay_t< Function >( std::decay_t< Args > ... )
    >
>

——表示 共享状态 (与 fn 的异步执行相关联).

抛出:

fiber_error 或 future_error (若发生错误).

注释:

接受 std::allocator_arg_t 的重载在构造所启动的 StackAllocator 时使用传入的 fiber. 接受 launch 的重载在构造所启动的 launch 时使用传入的 fiber. 默认 launch 为 post, 与 fiber 构造函数的情形相同.

注释

不支持 deferred future.
