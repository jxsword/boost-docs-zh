通道

有缓冲通道
无缓冲通道

通道是一种通过消息传递来通信和同步 Threads of Execution [2] 的模型.

枚举 channel_op_status

通道操作返回通道的状态.

enum class channel_op_status {
    success,
    empty,
    full,
    closed,
    timeout
};
success

效果:

操作成功.

empty

效果:

通道为空, 操作失败.

full

效果:

通道已满, 操作失败.

closed

效果:

通道已关闭, 操作失败.

timeout

效果:

在指定的超时时间过去之前, 操作未就绪.


[2] 能被调度器独立管理的最小有序指令序列称为 Thread of Execution.
