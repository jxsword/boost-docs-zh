when_any, 一个可疑的替代方案

C++ 中某些话题能激起强烈情绪, 异常也不例外. 我们忍不住要提一句——纯粹出于信息目的——当你只需要若干并发运行纤程中的 首个 结果时, 可以传给参与纤程一个 shared_ptr<promise<>>, 然后让发起纤程在其 future::get() 上调用 future<>. 第一个在该共享 promise::set_value() 上调用 promise 的纤程会成功; 同一 set_value() 实例上后续的 promise 调用将抛出 future_error.

自行斟酌使用这些信息. 当心黑暗面.
