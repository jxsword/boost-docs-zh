模板 promise<>

一个 promise<> 提供了一种存储值 (或异常) 的机制, 该值 (或异常) 之后可从对应的 future<> 对象中取回. promise<> 和 future<> 通过其底层的 共享状态 进行通信.

#include <boost/fiber/future/promise.hpp>

namespace boost {
namespace fibers {

template< typename R >
class promise {
public:
    promise();

    template< typename Allocator >
    promise( std::allocator_arg_t, Allocator);

    promise( promise &&) noexcept;

    promise & operator=( promise &&) noexcept;

    promise( promise const&) = delete;

    promise & operator=( promise const&) = delete;

    ~promise();

    void swap( promise &) noexcept;

    future< R > get_future();

    void set_value( R const&);  // member only of generic promise template
    void set_value( R &&);      // member only of generic promise template
    void set_value( R &);       // member only of promise< R & > template
    void set_value();           // member only of promise< void > template

    void set_exception( std::exception_ptr p);
};

template< typename R >
void swap( promise< R > &, promise< R > &) noexcept;

}
默认构造函数 
promise();

效果:

创建一个带空 共享状态 的 promise.

抛出:

由内存分配导致的异常.

构造函数 
template< typename Allocator >
promise( std::allocator_arg_t, Allocator alloc);

效果:

创建一个带空 共享状态 的 promise (使用 alloc).

抛出:

由内存分配导致的异常.

参见:

std::allocator_arg_t

移动构造函数 
promise( promise && other) noexcept;

效果:

创建 promise 时, 把 共享状态 从 other 移动而来.

后置条件:

other 不含有效的共享状态.

抛出:

无.

析构函数 
~promise();

效果:

销毁 *this, 并放弃 共享状态 (若共享状态已就绪); 否则存储 future_error 带错误条件 future_errc::broken_promise, 效果如同调用 promise::set_exception(): 共享状态被置为就绪.

Member function operator=() 

promise & operator=( promise && other) noexcept;

效果:

把 共享状态 的所有权转移给 *this.

后置条件:

other 不含有效的共享状态.

抛出:

无.

Member function swap() 

void swap( promise & other) noexcept;

效果:

在 other 与 之间交换 共享状态*this.

抛出:

无.

Member function get_future() 

future< R > get_future();

返回:

一个 future<>, 带有相同的 共享状态.

抛出:

future_error 带 future_errc::future_already_retrieved 或 future_errc::no_state.

Member function set_value() 

void set_value( R const& value);  // member only of generic promise template
void set_value( R && value);      // member only of generic promise template
void set_value( R & value);       // member only of promise< R & > template
void set_value();                 // member only of promise< void > template

效果:

把结果存入 共享状态, 并把该状态标记为就绪.

抛出:

future_error 带 future_errc::future_already_satisfied 或 future_errc::no_state.

Member function set_exception() 

void set_exception( std::exception_ptr);

效果:

把一个异常指针存入 共享状态, 并把该状态标记为就绪.

抛出:

future_error 带 future_errc::future_already_satisfied 或 future_errc::no_state.

Non-member function swap() 

template< typename R >
void swap( promise< R > & l, promise< R > & r) noexcept;

效果:

与 l.swap( r) 相同.
