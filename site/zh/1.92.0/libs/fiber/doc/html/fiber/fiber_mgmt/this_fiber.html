this_fiber 命名空间

一般而言, this_fiber 操作既可以从 "main" 纤程——即函数 main() 在其上进入的纤程——中调用, 也可以从显式启动线程的线程函数中调用. 也就是说, 在许多方面, 每个线程的主纤程可以像显式启动的纤程一样对待.

namespace boost {
namespace this_fiber {

fibers::fiber::id get_id() noexcept;
void yield() noexcept;
template< typename Clock, typename Duration >
void sleep_until( std::chrono::time_point< Clock, Duration > const&);
template< typename Rep, typename Period >
void sleep_for( std::chrono::duration< Rep, Period > const&);
template< typename PROPS >
PROPS & properties();

}}

Non-member function this_fiber::get_id() 

#include <boost/fiber/operations.hpp>

namespace boost {
namespace fibers {

fiber::id get_id() noexcept;

}}

返回:

一个 fiber::id 实例, 表示当前正在执行的纤程.

抛出:

无.

Non-member function this_fiber::sleep_until() 

#include <boost/fiber/operations.hpp>

namespace boost {
namespace fibers {

template< typename Clock, typename Duration >
void sleep_until( std::chrono::time_point< Clock, Duration > const& abs_time);

}}

效果:

挂起当前纤程, 直到到达 abs_time 指定的时间点.

抛出:

与超时相关的异常.

注释:

当前纤程在 abs_time 之前不会恢复, 但对于在 abs_time 之后多久恢复没有任何保证.

注释:

"timeout-related exceptions" 的含义如 C++ 标准第 30.2.4 Timing specifications [thread.req.timing] 节所定义: "接受指定超时实参的函数, 如果在其执行期间某个 clock、time point 或 time duration 抛出异常, 该函数将抛出异常. 这类异常被称为 timeout-related exceptions."

Non-member function this_fiber::sleep_for() 

#include <boost/fiber/operations.hpp>

namespace boost {
namespace fibers {

template< class Rep, class Period >
void sleep_for( std::chrono::duration< Rep, Period > const& rel_time);

}}

效果:

挂起当前纤程, 直到 rel_time 指定的时长流逝完毕.

抛出:

与超时相关的异常.

注释:

当前纤程在 rel_time 流逝完毕之前不会恢复, 但对于此后多久恢复没有任何保证.

Non-member function this_fiber::yield() 

#include <boost/fiber/operations.hpp>

namespace boost {
namespace fibers {

void yield() noexcept;

}}

效果:

放弃执行控制权, 允许其他纤程运行.

抛出:

无.

注释:

调用 yield() 的纤程不会被挂起: 它会立即作为就绪可运行状态传递给调度器.

Non-member function this_fiber::properties() 

#include <boost/fiber/operations.hpp>

namespace boost {
namespace fibers {

template< typename PROPS >
PROPS & properties();

}}

前置条件:

use_scheduling_algorithm() 已从本线程被调用, 传入的是 algorithm_with_properties<> 的子类, 其模板实参为相同的 PROPS.

返回:

对当前运行纤程的调度器属性实例的引用.

抛出:

std::bad_cast——如果调用 use_scheduling_algorithm() 时传入的 algorithm_with_properties 子类带有不同于 PROPS 的模板形参.

注释:

algorithm_with_properties<> 为用户编写的调度器提供了一种把扩展属性 (如优先级) 与纤程实例关联起来的方式. 此函数允许访问这些用户提供的属性.

注释:

当从某个线程的主纤程首次调用此函数时, 它可能在内部让出, 允许其他纤程运行.
