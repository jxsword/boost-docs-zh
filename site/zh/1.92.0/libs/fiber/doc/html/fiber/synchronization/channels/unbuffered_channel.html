无缓冲通道

Boost.Fiber 提供了模板 unbuffered_channel, 适合通过同步消息传递来同步纤程 (运行于相同或不同线程). 等待消费值的纤程会阻塞, 直到该值被生产出来. 若纤程试图通过无缓冲通道发送一个值, 而没有纤程在等待接收该值, 通道将阻塞发送纤程.

无缓冲通道表现为一个 rendezvous point.

typedef boost::fibers::unbuffered_channel< int > channel_t;

void send( channel_t & chan) {
    for ( int i = 0; i < 5; ++i) {
        chan.push( i);
    }
    chan.close();
}

void recv( channel_t & chan) {
    int i;
    while ( boost::fibers::channel_op_status::success == chan.pop(i) ) {
        std::cout << "received " << i << std::endl;
    }
}

channel_t chan{ 1 };
boost::fibers::fiber f1( std::bind( send, std::ref( chan) ) );
boost::fibers::fiber f2( std::bind( recv, std::ref( chan) ) );

f1.join();
f2.join();

支持 range-for 语法:

typedef boost::fibers::unbuffered_channel< int > channel_t;

void foo( channel_t & chan) {
    chan.push( 1);
    chan.push( 1);
    chan.push( 2);
    chan.push( 3);
    chan.push( 5);
    chan.push( 8);
    chan.push( 12);
    chan.close();
}

void bar( channel_t & chan) {
    for ( unsigned int value : chan) {
        std::cout << value << " ";
    }
    std::cout << std::endl;
}

模板 unbuffered_channel<> 

#include <boost/fiber/unbuffered_channel.hpp>

namespace boost {
namespace fibers {

template< typename T >
class unbuffered_channel {
public:
    typedef T   value_type;

    class iterator;

    unbuffered_channel();

    unbuffered_channel( unbuffered_channel const& other) = delete;
    unbuffered_channel & operator=( unbuffered_channel const& other) = delete;

    void close() noexcept;

    channel_op_status push( value_type const& va);
    channel_op_status push( value_type && va);
    template< typename Rep, typename Period >
    channel_op_status push_wait_for(
        value_type const& va,
        std::chrono::duration< Rep, Period > const& timeout_duration);
    channel_op_status push_wait_for( value_type && va,
        std::chrono::duration< Rep, Period > const& timeout_duration);
    template< typename Clock, typename Duration >
    channel_op_status push_wait_until(
        value_type const& va,
        std::chrono::time_point< Clock, Duration > const& timeout_time);
    template< typename Clock, typename Duration >
    channel_op_status push_wait_until(
        value_type && va,
        std::chrono::time_point< Clock, Duration > const& timeout_time);

    channel_op_status pop( value_type & va);
    value_type value_pop();
    template< typename Rep, typename Period >
    channel_op_status pop_wait_for(
        value_type & va,
        std::chrono::duration< Rep, Period > const& timeout_duration);
    template< typename Clock, typename Duration >
    channel_op_status pop_wait_until(
        value_type & va,
        std::chrono::time_point< Clock, Duration > const& timeout_time);
};

template< typename T >
unbuffered_channel< T >::iterator begin( unbuffered_channel< T > & chan);

template< typename T >
unbuffered_channel< T >::iterator end( unbuffered_channel< T > & chan);

}}
构造函数 
unbuffered_channel();

效果:

该构造函数构造一个类 unbuffered_channel 的对象.

Member function close() 

void close() noexcept;

效果:

停用该通道. 调用 this->close() 之后不能再放入值. 阻塞在 this->pop()、this->pop_wait_for() 或 this->pop_wait_until() 中的纤程将返回 closed. 阻塞在 this->value_pop() 中的纤程将收到一个异常.

抛出:

无.

注释:

close() 类似于关闭管道. 它通知等待的消费者不会再有值到来.

Member function push() 

channel_op_status push( value_type const& va);
channel_op_status push( value_type && va);

效果:

若通道已关闭, 返回 closed. 否则将值入队到通道中, 唤醒一个阻塞在 this->pop()、this->value_pop()、this->pop_wait_for() 或 this->pop_wait_until() 上的纤程, 并返回 success.

抛出:

由复制或移动操作抛出的异常.

Member function pop() 

channel_op_status pop( value_type & va);

效果:

从通道中出队一个值. 若通道为空, 纤程将被挂起, 直到至少一个新项被 push()ed (返回值 success 且 va 包含出队的值), 或通道被 close()d (返回值 closed).

抛出:

由复制或移动操作抛出的异常.

Member function value_pop() 

value_type value_pop();

效果:

从通道中出队一个值. 若通道为空, 纤程将被挂起, 直到至少一个新项被 push()ed, 或通道被 close()d (此时抛出异常).

抛出:

fiber_error, 若 *this 已关闭, 或由复制或移动操作抛出.

错误条件:

std::errc::operation_not_permitted

Member function pop_wait_for() 

template< typename Rep, typename Period >
channel_op_status pop_wait_for(
    value_type & va,
    std::chrono::duration< Rep, Period > const& timeout_duration)

效果:

接受 std::chrono::duration, 并在内部以 (系统时间 + timeout_duration) 计算超时时间. 若通道非空, 立即从通道中出队一个值. 否则纤程将被挂起, 直到至少一个新项被 push()ed (返回值 success 且 va 包含出队的值), 或通道被 close()d (返回值 closed), 或系统时间到达计算出的超时时间 (返回值 timeout).

抛出:

超时相关异常, 或由复制或移动操作抛出.

Member function pop_wait_until() 

template< typename Clock, typename Duration >
channel_op_status pop_wait_until(
    value_type & va,
    std::chrono::time_point< Clock, Duration > const& timeout_time)

效果:

接受一个 std::chrono::time_point< Clock, Duration >. 若通道非空, 立即从通道中出队一个值. 否则纤程将被挂起, 直到至少一个新项被 push()ed (返回值 success 且 va 包含出队的值), 或通道被 close()d (返回值 closed), 或系统时间到达传入的 time_point (返回值 timeout).

抛出:

超时相关异常, 或由复制或移动操作抛出.

非成员函数 begin( unbuffered_channel< T > &) 
template< typename T >
unbuffered_channel< T >::iterator begin( unbuffered_channel< T > &);

返回:

返回一个范围迭代器 (输入迭代器).

非成员函数 end( unbuffered_channel< T > &) 
template< typename T >
unbuffered_channel< R >::iterator end( unbuffered_channel< T > &);

返回:

返回一个结束范围迭代器 (输入迭代器).
