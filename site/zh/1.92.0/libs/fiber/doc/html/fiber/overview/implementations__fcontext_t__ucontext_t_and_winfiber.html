Implementations: fcontext_t, ucontext_t and WinFiber

Boost.Fiber 使用 call/cc (来自 Boost.Context) 作为构建基块.

fcontext_t

该实现默认使用 fcontext_t. fcontext_t 基于汇编, 并非在所有平台上都可用. 它提供的性能远好于 ucontext_t (上下文切换所需 CPU 周期少两个数量级; 参见 performance 一节) 和 WinFiber.

ucontext_t

作为替代, ucontext_t 可以通过用 BOOST_USE_UCONTEXT 编译并指定 b2 特性 context-impl=ucontext 来使用. ucontext_t 可能在更广泛的 POSIX 平台上可用, 但有一些 缺点 (例如自 POSIX.1-2003 起已弃用, 不符合 C99).

注释

call/cc 支持 Segmented stacks, 但仅当以 ucontext_t 作为其实现时.

WinFiber

配合 BOOST_USE_WINFIB 和 b2 特性 context-impl=winfib, 将使用 Win32-Fibers 作为 call/cc 的实现.

由于 MSDN 并未完整描述 TIB (线程信息块), 可能存在并非所有必需的 TIB 部分都被交换的情况.

注释

首次调用 call/cc 会通过调用 ConvertThreadToFiber() 把线程转换为 Windows 纤程. 如有需要, 用户必须显式调用 ConvertFiberToThread() 来释放 ConvertThreadToFiber() 所分配的资源 (例如在使用 boost.context 之后).
