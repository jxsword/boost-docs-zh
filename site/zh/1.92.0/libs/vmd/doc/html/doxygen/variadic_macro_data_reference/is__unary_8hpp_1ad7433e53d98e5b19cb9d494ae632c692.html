宏 BOOST_VMD_IS_UNARY_D

BOOST_VMD_IS_UNARY_D — 判断序列是否只有一个元素, 这样的序列称为单元素序列. 可重入版本.

概要

// In header: <boost/vmd/is_unary.hpp>

BOOST_VMD_IS_UNARY_D(d, sequence)

说明

d = 下一个可用的 BOOST_PP_WHILE 迭代.
sequence = 一个序列

returns = 如果序列是单元素序列则返回 1, 否则返回 0.

如果序列的大小已知, 那么直接比较该大小是否等于 1 来判断序列是否为单元素序列会更快. 但如果序列的大小未知, 那么调用该宏比先获取大小再进行上述比较来判断序列是否为单元素序列要更快.
