宏 BOOST_VMD_TUPLE_POP_FRONT_Z

BOOST_VMD_TUPLE_POP_FRONT_Z — 从元组开头弹出一个元素. 它以最高效率重入 BOOST_PP_REPEAT.

概要

// In header: <boost/vmd/tuple/pop_front.hpp>

BOOST_VMD_TUPLE_POP_FRONT_Z(z, tuple)

说明

z = 下一个可用的 BOOST_PP_REPEAT 维度.
tuple = 要从中弹出元素的元组.

如果元组是空元组, 结果未定义. 如果元组是单个元素, 结果是一个空元组. 否则结果是移除第一个元素之后的元组.
