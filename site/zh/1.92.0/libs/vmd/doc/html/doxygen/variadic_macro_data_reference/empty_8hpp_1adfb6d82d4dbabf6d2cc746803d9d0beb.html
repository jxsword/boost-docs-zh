宏 BOOST_VMD_EMPTY

BOOST_VMD_EMPTY — 输出空.

概要

// In header: <boost/vmd/empty.hpp>

BOOST_VMD_EMPTY(...)

说明

... = 任意变参参数. 这些参数会被忽略.

该宏用于输出空 (无内容), 无论向它传递什么.

如果你使用该宏来返回结果, 例如随后被调用的 'result BOOST_VMD_EMPTY', 你应该用 BOOST_VMD_IDENTITY_RESULT 把结果包围起来, 以化解 VC++ 的一个问题.
