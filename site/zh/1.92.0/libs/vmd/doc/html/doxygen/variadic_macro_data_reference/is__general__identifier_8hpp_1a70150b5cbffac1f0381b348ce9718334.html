宏 BOOST_VMD_IS_GENERAL_IDENTIFIER

BOOST_VMD_IS_GENERAL_IDENTIFIER — 测试参数是否是一个一般标识符.

概要

// In header: <boost/vmd/is_general_identifier.hpp>

BOOST_VMD_IS_GENERAL_IDENTIFIER(...)

说明

... = 变参参数

第一个变参参数是必需的, 它是要测试的输入.

传递多于一个的变参参数是一个错误.

returns   = 1 if the parameter is any general identifier and only a single variadic argument is given, otherwise 0.

传递给该宏的参数应当是单个可能的标识符, 而不是由预处理记号组成的 VMD 序列.

如果输入不是 VMD 数据类型, 该宏可能导致预处理错误. 这是因为: 在确定输入不为空且不以括号开头之后, 该宏使用预处理器拼接操作来判断输入是否为标识符. 如果被拼接的数据会产生无效的预处理记号, 编译器可能发出预处理错误.
