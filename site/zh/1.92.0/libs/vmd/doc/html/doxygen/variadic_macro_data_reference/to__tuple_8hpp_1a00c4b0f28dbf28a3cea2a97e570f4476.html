宏 BOOST_VMD_TO_TUPLE

BOOST_VMD_TO_TUPLE — 将序列转换为一个 Boost PP 元组, 其元素就是该序列的元素.

概要

// In header: <boost/vmd/to_tuple.hpp>

BOOST_VMD_TO_TUPLE(...)

说明

... = 变参参数.

第一个变参参数是必需的, 它是要转换的序列.

其余可选的变参参数可以是返回类型参数. 返回类型参数允许将序列中的每个元素转换为二元组, 其中第一个元组元素是类型, 第二个元组元素是元素数据.

BOOST_VMD_RETURN_NO_TYPE 是默认值, 它在每个转换后的元素中不返回类型, 而只返回数据. 其余所有选项都以二元组的形式返回类型和数据. 如果指定了 BOOST_VMD_RETURN_TYPE, 则在元组中返回元素的具体类型. 如果指定了 BOOST_VMD_RETURN_TYPE_ARRAY, 则当元素是数组时返回数组类型; 否则当元素是元组时返回元组类型; 否则对非元组数据返回其实际类型. 如果指定了 BOOST_VMD_RETURN_TYPE_LIST, 则当元素是列表时返回列表类型; 否则当元素是元组时返回元组类型; 否则对非元组数据返回其实际类型. 如果指定了 BOOST_VMD_RETURN_TYPE_TUPLE, 则对所有类元组数据返回元组类型, 否则对非元组数据返回其实际类型. 如果指定了多个返回类型可选参数, 则由最后指定的一个决定返回类型.

returns = 一个 Boost PP 元组. 如果序列为空, 则返回空, 因为不存在空元组. 如果指定的可选返回类型不是 BOOST_VMD_RETURN_NO_TYPE, 则每个元素的类型和数据会作为元组元素返回. 否则只将数据作为元组元素返回, 这也是默认行为.
