宏 BOOST_VMD_IS_IDENTIFIER

BOOST_VMD_IS_IDENTIFIER — 测试参数是否是一个标识符.

概要

// In header: <boost/vmd/is_identifier.hpp>

BOOST_VMD_IS_IDENTIFIER(...)

说明

... = 变参参数

第一个变参参数是必需的, 它是要测试的输入.

其余变参参数是可选的, 它们是要匹配的标识符. 该数据可以采取两种形式之一: 或者是一个或多个单个标识符, 或者是单个由标识符组成的 Boost PP 元组.

returns   = 1 if the parameter is an identifier, otherwise 0.
            
            If the parameter is not an identifier, 
            or if optional identifiers are specified and the identifier
            does not match any of the optional identifiers, the macro returns 0.

标识符在 VMD 中通过以下方式注册:

#define BOOST_VMD_REG_XXX (XXX) where XXX is a v-identifier.

该标识符必须经过注册才能被找到.

标识符在 VMD 中通过以下方式预先检测:

#define BOOST_VMD_DETECT_XXX_XXX where XXX is an identifier.

如果你指定了可选的标识符而没有指定对可选标识符的检测, 那么该可选标识符永远不会匹配输入.

如果输入不是 VMD 数据类型, 该宏可能导致预处理错误. 这是因为: 在确定输入不以括号开头之后, 该宏使用预处理器拼接操作来判断输入是否为标识符. 如果被拼接的数据会产生无效的预处理记号, 编译器可能发出预处理错误.
