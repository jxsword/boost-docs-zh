宏 BOOST_VMD_IS_VMD_SEQ

BOOST_VMD_IS_VMD_SEQ — 判断序列是否是一个 VMD seq.

概要

// In header: <boost/vmd/seq/is_vmd_seq.hpp>

BOOST_VMD_IS_VMD_SEQ(sequence)

说明

该宏检查序列是否是一个 VMD seq. VMD seq 可以是 Boost PP seq 或空, 是 Boost PP seq 的超集. 如果它是 VMD seq 则返回 1, 否则返回 0.

sequence = 可能的 Boost PP seq

returns = 如果它是 VMD seq 则返回 1, 否则返回 0.
