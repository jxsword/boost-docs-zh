宏 BOOST_VMD_IDENTITY_RESULT

BOOST_VMD_IDENTITY_RESULT — 包裹任意结果的宏, 这些结果可以使用 BOOST_VMD_IDENTITY 或 'item BOOST_VMD_EMPTY' 来返回其值.

概要

// In header: <boost/vmd/identity.hpp>

BOOST_VMD_IDENTITY_RESULT(result)

说明

result = 使用 BOOST_VMD_IDENTITY 或 'item BOOST_VMD_EMPTY' 时返回的任意单个结果.

该宏存在的原因是化解在 VC++ 中使用 BOOST_VMD_IDENTITY 时出现的问题. 如果你的 BOOST_VMD_IDENTITY 宏可能在以 VC++ 为编译器的环境中使用, 那么你需要用该宏把可能返回结果的宏代码包围起来, 以便 VC++ 能正确处理 BOOST_VMD_IDENTITY.

如果你没有使用 VC++, 则不必使用该宏, 但使用它也无害.
