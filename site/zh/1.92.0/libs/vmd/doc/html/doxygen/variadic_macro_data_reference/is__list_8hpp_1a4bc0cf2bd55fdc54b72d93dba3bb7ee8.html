宏 BOOST_VMD_IS_LIST_D

BOOST_VMD_IS_LIST_D — 判断序列是否是一个 Boost pplib 列表. 可重入版本.

概要

// In header: <boost/vmd/is_list.hpp>

BOOST_VMD_IS_LIST_D(d, sequence)

说明

该宏检查序列是否是一个 pplib 列表. 如果它是列表则返回 1, 否则返回 0.

d = 下一个可用的 BOOST_PP_WHILE 迭代.
sequence = 输入, 作为可能的 Boost PP 列表.

returns = 如果它是列表则返回 1, 否则返回 0.

如果输入的形式是列表, 但其列表结束标记不是标识符, 而是 VMD 无法解析的预处理记号, 该宏将产生一个预处理错误, 例如 '(anything,&BOOST_PP_NIL)' 这个例子是一个有效的元组但不是有效的列表.
