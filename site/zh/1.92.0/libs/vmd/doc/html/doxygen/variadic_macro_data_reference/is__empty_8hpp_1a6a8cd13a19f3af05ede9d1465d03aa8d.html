宏 BOOST_VMD_IS_EMPTY

BOOST_VMD_IS_EMPTY — 测试其输入是否为空.

概要

// In header: <boost/vmd/is_empty.hpp>

BOOST_VMD_IS_EMPTY(...)

说明

该宏检查输入是否为空. 如果输入为空则返回 1, 否则返回 0.

该宏是一个接受任意输入的变参宏. 对于 VC++8 编译器 (VS2005), 该宏只接受单个输入参数进行检查.

对于 C++20 之前的所有 C++ 标准层级, 该宏并不完美, 也不可能完美. 问题出在: 如果待检查的输入是一个类函数宏的名字, 则可能产生编译器错误, 也可能出现错误的结果.

对于 C++20, 由于其支持新的 VA_OPT 预处理器构造, 无论变参输入是什么, 该宏总能正确工作, 因此是 100% 可靠的.

该宏利用变参宏支持, 替代了 Boost PP 库中未写入文档的宏 BOOST_PP_IS_EMPTY. 其代码取自 Paul Mensonides 发帖给出的 BOOST_PP_IS_EMPTY 变参版本, 并经过修改以同时支持 VC++. 该宏的 C++20 实现 (使用 VA_OPT 预处理器构造) 的代码为作者本人所写, 并复用了作者本人添加到 Boost 预处理器库中的代码.

... = 变参输入, 对于 VC++8 必须是单个参数

returns = 如果输入为空则为 1, 否则为 0

建议在待测试的输入后面附加 BOOST_PP_EMPTY(), 以避免某些编译器在输入真正为空时发出关于未向宏传递参数的警告消息.
