宏 BOOST_VMD_IS_ARRAY

BOOST_VMD_IS_ARRAY — 判断序列是否是一个 Boost PP 数组.

概要

// In header: <boost/vmd/is_array.hpp>

BOOST_VMD_IS_ARRAY(sequence)

说明

该宏检查序列是否是一个 Boost PP 数组. 如果它是数组则返回 1, 否则返回 0.

sequence = 可能的 Boost PP 数组.

returns = 如果它是数组则返回 1, 否则返回 0.

如果输入的形式是数组, 但其第一个元组元素不是数, 而是 VMD 无法解析的预处理记号, 该宏将产生一个预处理错误, 例如 '(&2,(0,1))' 这个例子是一个有效的元组但不是有效的数组.
