宏 BOOST_VMD_GET_TYPE

BOOST_VMD_GET_TYPE — 以 VMD 类型的形式返回序列的类型.

概要

// In header: <boost/vmd/get_type.hpp>

BOOST_VMD_GET_TYPE(...)

说明

... = 变参参数.

第一个变参参数是必需的, 它是要获取其类型的序列.

可选的变参参数是返回类型参数.

该宏以 VMD 类型的形式返回序列的类型. 空序列的类型总是 BOOST_VMD_TYPE_EMPTY, 多元素序列的类型总是 BOOST_VMD_TYPE_SEQUENCE. 单元素序列的类型就是该单个元素的类型.

返回的类型可以通过指定可选的返回类型参数来修改.

如果指定了 BOOST_VMD_RETURN_TYPE (默认值), 则返回元素的具体类型.

如果指定了 BOOST_VMD_RETURN_TYPE_ARRAY, 则当元素是数组时返回数组类型; 否则当元素是元组时返回元组类型; 否则对非元组数据返回其实际类型.

如果指定了 BOOST_VMD_RETURN_TYPE_LIST, 则当元素是列表时返回列表类型; 否则当元素是元组时返回元组类型; 否则对非元组数据返回其实际类型.

如果指定了 BOOST_VMD_RETURN_TYPE_TUPLE, 则对所有类元组数据返回元组类型, 否则对非元组数据返回其实际类型.

如果指定了 BOOST_VMD_RETURN_NO_TYPE, 它会被忽略, 因为该宏总是返回序列的类型.

如果指定了多个返回类型可选参数, 则由最后指定的一个决定返回类型.

returns = 以 VMD 类型形式表示的序列类型.
