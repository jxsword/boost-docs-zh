宏 BOOST_VMD_IS_SEQ_D

BOOST_VMD_IS_SEQ_D — 判断序列是否是一个 Boost PP seq. 可重入版本.

概要

// In header: <boost/vmd/is_seq.hpp>

BOOST_VMD_IS_SEQ_D(d, sequence)

说明

该宏检查序列是否是一个 Boost PP seq. 如果它是 seq 则返回 1, 否则返回 0.

d = 下一个可用的 BOOST_PP_WHILE 迭代.
sequence = 可能的 Boost PP seq

returns = 如果它是 seq 则返回 1, 否则返回 0.

带单个元素的单个括号组会被解析为元组而不是 seq. 要被解析为 seq, 输入必须是多于一个连续的括号组, 且每个括号组各含单个数据元素.
