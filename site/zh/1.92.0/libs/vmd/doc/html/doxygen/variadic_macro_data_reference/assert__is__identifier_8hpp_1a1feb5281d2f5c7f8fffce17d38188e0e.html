宏 BOOST_VMD_ASSERT_IS_IDENTIFIER_D

BOOST_VMD_ASSERT_IS_IDENTIFIER_D — 断言该序列是一个标识符. 可重入版本.

概要

// In header: <boost/vmd/assert_is_identifier.hpp>

BOOST_VMD_ASSERT_IS_IDENTIFIER_D(d, ...)

说明

该宏检查序列是否是一个标识符. 如果它不是标识符, 则强制产生一个编译器错误.

该宏通常仅在调试模式下检查标识符. 不过, 最终用户可以通过将宏 BOOST_VMD_ASSERT_DATA 分别定义为 1 或 0, 强制该宏进行检查或不检查.

d = 下一个可用的 BOOST_PP_WHILE 迭代.
... = 变参参数

变参参数为:

sequence = 要作为标识符进行测试的序列.
ids (可选) = 该数据可以采取两种形式之一: 或者是一个或多个单个标识符, 或者是单个由标识符组成的 Boost PP 元组.

returns = Normally the macro returns nothing. 

          If the sequence is an identifier, nothing is 
          output. If optional ids are specified, for the 
          sequence to be an identifier it must be an
          identifier that matches one of the optional
          ids.
          
          For VC++, because there is no sure way of forcing  
          a compiler error from within a macro without producing
          output, if the sequence is not an identifier the 
          macro forces a compiler error by outputting invalid C++.
          
          For all other compilers a compiler error is forced 
          without producing output if the sequence is not an
          identifier.

标识符在 VMD 中通过以下方式注册:

#define BOOST_VMD_REG_XXX (XXX) where XXX is a v-identifier.

该标识符必须经过注册才能被找到.

标识符在 VMD 中通过以下方式预先检测:

#define BOOST_VMD_DETECT_XXX_XXX where XXX is an identifier.

如果你指定了可选的 id 而没有指定对可选 id 的检测, 那么该 id 永远不会匹配任何标识符.
