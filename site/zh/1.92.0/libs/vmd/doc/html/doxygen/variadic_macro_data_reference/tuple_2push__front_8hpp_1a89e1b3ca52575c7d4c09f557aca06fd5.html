宏 BOOST_VMD_TUPLE_PUSH_FRONT

BOOST_VMD_TUPLE_PUSH_FRONT — 在元组开头插入一个元素.

概要

// In header: <boost/vmd/tuple/push_front.hpp>

BOOST_VMD_TUPLE_PUSH_FRONT(tuple, elem)

说明

tuple = 要向其插入元素的元组.
elem = 要插入的元素.

如果元组是空元组, 结果是只含该单个元素的元组. 否则结果是将该元素插入到开头之后的元组.
