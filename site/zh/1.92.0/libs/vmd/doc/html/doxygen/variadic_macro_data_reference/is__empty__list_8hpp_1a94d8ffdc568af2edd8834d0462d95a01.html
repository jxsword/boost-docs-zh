宏 BOOST_VMD_IS_EMPTY_LIST_D

BOOST_VMD_IS_EMPTY_LIST_D — 测试序列是否是一个空的 Boost PP 列表. 可重入版本.

概要

// In header: <boost/vmd/is_empty_list.hpp>

BOOST_VMD_IS_EMPTY_LIST_D(d, sequence)

说明

空的 Boost PP 列表由单个标识符 'BOOST_PP_NIL' 构成. 该标识符也用作非空列表的列表结束标记.

d = 下一个可用的 BOOST_PP_WHILE 迭代
sequence = 一个预处理器参数

returns = 如果序列是一个空的 Boost PP 列表则为 1, 否则为 0.

如果作为空列表标记的输入不是标识符, 而是 VMD 无法解析的预处理记号, 该宏将产生一个预处理错误, 例如 '&BOOST_PP_NIL' 这个例子.
