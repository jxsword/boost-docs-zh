宏 BOOST_VMD_IS_NUMBER

BOOST_VMD_IS_NUMBER — 测试序列是否是一个 Boost PP 数.

概要

// In header: <boost/vmd/is_number.hpp>

BOOST_VMD_IS_NUMBER(sequence)

说明

该宏检查序列是否是一个 Boost PP 数. Boost PP 数是从 0 到 BOOST_PP_LIMIT_MAG 之间的值.

sequence = 可能的数

returns = 如果序列是一个 Boost PP 数则为 1, 否则为 0.

如果输入不是 VMD 数据类型, 该宏可能导致预处理错误. 这是因为: 在确定输入不以括号开头之后, 该宏使用预处理器拼接操作来判断输入是否为数. 如果被拼接的数据会产生无效的预处理记号, 编译器可能发出预处理错误.
