宏 BOOST_VMD_IDENTITY

BOOST_VMD_IDENTITY — 以任意数量的参数调用时展开为其参数的宏.

概要

// In header: <boost/vmd/identity.hpp>

BOOST_VMD_IDENTITY(item)

说明

item = 任意单个参数

当随后以任意数量的参数调用 BOOST_VMD_IDENTITY(item) 时, 它会展开为 'item'. 随后调用该宏的方式是 'BOOST_VMD_IDENTITY(item)(zero_or_more_arguments)'.

该宏等价于 Boost PP 宏 BOOST_PP_IDENTITY(item), 区别在于 BOOST_PP_IDENTITY(item) 总是以无参数的方式调用, 如 'BOOST_VMD_IDENTITY(item)()', 而 BOOST_VMD_IDENTITY 可以以任意数量的参数调用.

该宏旨在用于 BOOST_PP_IF 和 BOOST_PP_IIF 语句中, 此时只有一个子句需要通过调用另一个宏来调用, 而另一个子句则用于返回一个 'item'.

returns = 该宏即 'BOOST_VMD_IDENTITY(item)', 当像 '(zero_or_more_arguments)' 那样以任意数量的参数调用它时, 返回 'item'. 该宏本身返回 'item BOOST_VMD_EMPTY'.
