宏 BOOST_VMD_NOT_EQUAL

BOOST_VMD_NOT_EQUAL — 测试任意两个序列是否不相等.

概要

// In header: <boost/vmd/not_equal.hpp>

BOOST_VMD_NOT_EQUAL(sequence, ...)

说明

sequence = 第一个序列.
... = 变参参数, 最多 2 个.

第一个变参参数是必需的, 它是要测试的第二个序列. 可选的第二个变参参数是作为过滤器使用的 VMD 类型.

该宏测试任意两个序列是否不相等. 两个序列不相等, 要求要么每个序列的 VMD 类型不相等, 要么序列中的各个元素不相等.

单个可选参数是一个过滤器. 该过滤器是一个 VMD 类型, 它规定两个待测试的序列都必须属于该 VMD 类型, 并且彼此相等, 测试才会失败, 否则测试成功.

returns = 成功时为 1, 失败时为 0. 成功表示两个序列不相等, 或者如果指定了可选参数, 表示这两个序列不属于该可选的 VMD 类型; 否则, 如果两个序列相等则返回 0.

该宏实现为 BOOST_VMD_EQUAL 的补, 因此只要 BOOST_VMD_EQUAL 会返回 1, 该宏就返回 0, 只要 BOOST_VMD_EQUAL 会返回 0, 该宏就返回 1.
