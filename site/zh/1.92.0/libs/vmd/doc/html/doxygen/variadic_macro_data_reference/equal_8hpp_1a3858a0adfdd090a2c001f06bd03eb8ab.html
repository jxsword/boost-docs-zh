宏 BOOST_VMD_EQUAL_D

BOOST_VMD_EQUAL_D — 测试任意两个序列是否相等. 可重入版本.

概要

// In header: <boost/vmd/equal.hpp>

BOOST_VMD_EQUAL_D(d, sequence, ...)

说明

d = 下一个可用的 BOOST_PP_WHILE 迭代.
sequence = 第一个序列.
... = 变参参数, 最多 2 个.

第一个变参参数是必需的, 它是要测试的第二个序列. 可选的第二个变参参数是作为过滤器使用的 VMD 类型.

该宏测试任意两个序列是否相等. 两个序列相等要求每个序列的 VMD 类型相等, 并且序列中的各个元素相等. 对于 Boost PP 复合类型, 该宏先测试复合类型是否具有相同的大小, 然后测试复合类型的每个元素是否相等. 这意味着复合类型的所有元素都必须是 VMD 类型, 才能成功使用该宏.

单个可选参数是一个过滤器. 该过滤器是一个 VMD 类型, 它规定两个待测试的序列都必须属于该 VMD 类型, 并且彼此相等, 测试才能成功.

returns = 成功时为 1, 失败时为 0. 成功表示两个序列相等, 并且如果指定了可选参数, 还表示这两个序列属于该可选的 VMD 类型.
