宏 BOOST_VMD_ASSERT_IS_EMPTY

BOOST_VMD_ASSERT_IS_EMPTY — 断言输入为空.

概要

// In header: <boost/vmd/assert_is_empty.hpp>

BOOST_VMD_ASSERT_IS_EMPTY(...)

说明

该宏检查输入是否为空. 如果不为空, 则强制产生一个编译器错误.

该宏是一个接受任意输入的变参宏. 对于 VC++8 编译器 (VS2005), 该宏只接受单个输入参数进行检查, 而不接受变参数据.

该宏通常仅在调试模式下检查是否为空. 不过, 最终用户可以通过将宏 BOOST_VMD_ASSERT_DATA 分别定义为 1 或 0, 强制该宏进行检查或不检查.

.... = 变参输入, 对于 VC++8 必须是单个参数.

returns = Normally the macro returns nothing. 

          If the input is empty, nothing is output.
          
          For VC++, because there is no sure way of forcing  
          a compiler error from within a macro without producing
          output, if the input is not empty the 
          macro forces a compiler error by outputting invalid C++.
          
          For all other compilers a compiler error is forced 
          without producing output if the input is not empty.

建议在待测试的输入后面附加 BOOST_PP_EMPTY(), 以避免某些编译器在输入真正为空时发出关于未向宏传递参数的警告消息.
