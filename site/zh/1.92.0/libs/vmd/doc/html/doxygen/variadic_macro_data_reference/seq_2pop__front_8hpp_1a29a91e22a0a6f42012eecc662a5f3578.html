宏 BOOST_VMD_SEQ_POP_FRONT

BOOST_VMD_SEQ_POP_FRONT — 从 seq 开头弹出一个元素.

概要

// In header: <boost/vmd/seq/pop_front.hpp>

BOOST_VMD_SEQ_POP_FRONT(seq)

说明

seq = 要从中弹出元素的 seq.

如果 seq 是空 seq, 结果未定义. 如果 seq 是单个元素, 结果是一个空 seq. 否则结果是移除第一个元素之后的 seq.
