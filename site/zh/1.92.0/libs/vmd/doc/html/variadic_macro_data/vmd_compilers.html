编译器

经过测试的编译器有:

在 Windows 上: gcc 4.8 至 10.2 各版本. VC++ 8.0 至 14.2 各版本. 以 gcc 为目标的 clang 3.7 至 10.0 各版本, 以 VC++ 为目标的 clang 3.9 至 10.0 各版本

在 Linux 上: gcc 4.4 至 10.2 各版本, clang 3.3 至 10.0 各版本, Intel C++ 12.1 至 19.1 各版本

并非所有版本都能成功编译所有测试.

对于 VC++ 8.0, BOOST_VMD_IS_EMPTY 和 BOOST_VMD_ASSERT_IS_EMPTY 宏只接受单个参数而不是变参数据, 因为该版本的 VC++ 不接受可能为空的变参数据.

支持的编译器是那些以 C99/C++11 及以上模式编译的编译器, 或者那些在 C++98/C++03 模式下编译时同时支持变参宏和传递空预处理数据的编译器.
