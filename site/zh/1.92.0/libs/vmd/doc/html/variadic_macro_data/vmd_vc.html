Visual C++ 定义

微软的 Visual C++ 编译器 (简称 VC++) 是一个非常流行的编译器, 但其默认预处理器在若干方面没有正确实现标准 C++ 预处理器. 因此, 使用 VMD 的程序员在 VC++ 环境下偶尔需要以不同的方式做事. 这些 VC++ 的"怪癖"已经在 VMD 库中尽可能被抚平, 但在后续主题中会有提及, 使用 VMD 的程序员偶尔仍需处理它们.

VMD 有一个宏, 用于指示何时正在使用 VC++ 默认预处理器. 该宏是一个名为 BOOST_VMD_MSVC 的对象式宏. 当使用 VC++ 的默认预处理器时它被设为 1, 未使用 VC++ 的默认预处理器时被设为 0. 只要你包含 VMD 头文件, 就可以在自己的宏代码中使用该宏, 编写可能需要对 VC++ 做特殊处理 (如本文档所述) 的代码. 因此你的宏处理偶尔会呈现如下形式:

#include <boost/vmd/some_header.hpp>

#if BOOST_VMD_MSVC

#define SOME_MACRO ... code for VC++ using its default preprocessor

#else

#define SOME_MACRO ... code for all other compilers

#endif

BOOST_VMD_MSVC 宏只在使用 VC++ 默认预处理器时适用. 当使用 VC++ 新的符合标准的预处理器 (目前通过 /Zc:preprocessor 命令行选项激活) 时, 它不适用.
