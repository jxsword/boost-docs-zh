功能分组

VMD 拥有功能的特定构造可以分为以下几类:

  1. 空
  2. 标识符
  3. 数值
  4. 类型
  5. Boost PP 数据类型 (数组, 列表, seq 和元组)
  6. 序列
  7. 额外的辅助变参宏

前六个类别界定了 VMD 可以解析的数据类型. 最后一个类别给出了额外的宏, 这些宏对于在 VMD 和 Boost PP 中使用变参宏的宏程序员会有所帮助.

每个类别的一般解释将在文档的相应位置给出.

VMD 用于处理上述其所能理解的数据类型的宏可以分为"特定宏"和"通用宏".

特定宏询问某些输入数据是否是特定数据类型. 通用宏将输入数据当作任意数据类型处理, 同时允许程序员单独查询数据的类型.

特定宏和通用宏各有其用武之地, 宏程序员可以根据具体情况决定使用哪一种.
