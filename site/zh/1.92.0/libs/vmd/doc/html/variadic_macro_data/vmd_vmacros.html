使用变参宏

变参宏由 C++11 规定, 是取自 C99 规范的特性. 它们是接受一个以 '...' 表示的最终参数的宏, 该参数把一个或多个最终参数以逗号分隔记号系列的形式传递给宏. 在宏展开中, 一个特殊的关键字 __VA_ARGS__ 表示这些逗号分隔的记号. 我把传给变参宏的这种信息称为"变参宏数据" (variadic macro data), 这也是本库名称的由来. 本文档使用更一般的术语"变参数据" (variadic data) 来表示作为单个宏参数传递给宏、可包含任意数量宏记号的数据, 例如 Boost PP 数据类型中的数据.

该库假定支持变参宏. 如果编译器不支持变参宏, 库中的宏会因预处理错误而失败. 在该库以前的版本中, 变参宏支持由 Boost Preprocessor 库中的 BOOST_PP_VARIADICS 对象式宏的值决定, 如果该宏返回 0, 库中的任何宏都不会被定义. 现在情况不再如此, 因为 Boost 预处理器库本身现在也要求变参宏支持, 且 BOOST_PP_VARIADICS 总是返回 1.

这对最终用户意味着: 编译器必须以 C++11 或更高模式使用, 或者处于 C++98/C++03 模式的编译器支持变参宏. 许多主要编译器, 包括 Visual C++, gcc 和 clang, 确实支持在 C++98/C++03 模式下使用变参宏, 只要不通过编译器的编译器标志开启对 C++98/C++03 标准的严格遵循.
