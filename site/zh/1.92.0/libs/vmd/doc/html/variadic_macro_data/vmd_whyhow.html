为何以及如何使用

VMD 库提供创建这样一种宏的能力: 该宏接受不同类型的参数, 因此可以根据参数类型及其值生成不同的输出.

这等同于重载函数为单一名称的函数提供根据参数类型而变化的功能的方式.

在宏的情况下, 不允许存在同名但宏展开不同的多个宏, 单个宏名可以产生不同的展开.

举个简单的例子:

#include <boost/preprocessor/control/iif.hpp>
#include <boost/vmd/is_seq.hpp>
#include <boost/vmd/is_tuple.hpp>

#define AMACRO(param)                 \
  BOOST_PP_IIF                        \
    (                                 \
    BOOST_VMD_IS_SEQ(param),          \
    Seq,                              \
    BOOST_PP_IIF                      \
      (                               \
      BOOST_VMD_IS_TUPLE(param),      \
      Tuple,                          \
      Unknown                         \
      )                               \
    )

如果传递的 param 是一个 seq, 宏的输出是 'Seq'. 如果传递的 param 是一个元组, 宏的输出是 'Tuple'. 否则宏的输出是 'Unknown'.

显然, 可以创建复杂得多的情形, 其中解析各种参数的类型和值, 以根据输入产生可变的宏输出. 使用变参宏 (即参数数量和类型都可变的宏) 给宏程序员更大的自由来设计灵活的宏.

VMD 库的另一个特性是解析标识符的能力. VMD 既能识别一般标识符, 也能识别经过注册的特定标识符. 一旦某个标识符经过注册, VMD 就可以把它识别为 VMD 序列的一部分. 此外, 一旦使用 VMD 的预先检测标识符系统预先检测了某个特定标识符, VMD 就可以比较标识符的相等或不等.

再举一个简单的例子:

#include <boost/preprocessor/control/iif.hpp>
#include <boost/vmd/is_general_identifier.hpp>

#define AMACRO1(param)                      \
  BOOST_PP_IIF                              \
    (                                       \
    BOOST_VMD_IS_GENERAL_IDENTIFIER(param), \
    AMACRO1_IDENTIFIER,                     \
    AMACRO1_NO_IDENTIFIER                   \
    )                                       \
  (param)

#define AMACRO1_IDENTIFIER(param) AMACRO1_ ## param
#define AMACRO1_NO_IDENTIFIER(param) Parameter is not an identifier
#define AMACRO1_NAME Identifier is a NAME
#define AMACRO1_ADDRESS Identifier is an ADDRESS

这里我们利用 VMD 识别一般标识符的能力来确定并处理我们可能期望作为宏参数的某个特定标识符. 如果 'AMACRO1' 的输入是 'NAME', 输出是 'Identifier is a NAME'. 如果 'AMACRO1' 的输入是 'ADDRESS', 输出是 'Identifier is an ADDRESS'. 否则输出是 'Parameter is not an identifier'.

标识符注册和预先检测让事情更清晰, 允许我们在 VMD 内检测宏输入是否匹配某个特定标识符. 使用与前面示例相同的设置, 但加上标识符注册和预先检测:

#include <boost/preprocessor/control/iif.hpp>
#include <boost/vmd/is_identifier.hpp>

#define BOOST_VMD_REGISTER_NAME (NAME)
#define BOOST_VMD_DETECT_NAME_NAME

#define BOOST_VMD_REGISTER_ADDRESS (ADDRESS)
#define BOOST_VMD_DETECT_ADDRESS_ADDRESS

#define AMACRO2(param)                        \
  BOOST_PP_IIF                                \
    (                                         \
    BOOST_VMD_IS_IDENTIFIER(param,NAME),      \
    AMACRO2_NAME,                             \
    BOOST_PP_IIF                              \
      (                                       \
      BOOST_VMD_IS_IDENTIFIER(param,ADDRESS), \
      AMACRO2_ADDRESS,                        \
      AMACRO2_NO_IDENTIFIER                   \
      )                                       \
    )                                         \
  (param)

#define AMACRO2_NO_IDENTIFIER(param) Parameter is not a NAME or ADDRESS identifier
#define AMACRO2_NAME(param) Identifier is a NAME
#define AMACRO2_ADDRESS(param) Identifier is an ADDRESS

如果 'AMACRO2' 的输入是 'NAME', 输出是 'Identifier is a NAME'. 如果 'AMACRO2' 的输入是 'ADDRESS', 输出是 'Identifier is an ADDRESS'. 否则输出是 'Parameter is not a NAME or ADDRESS identifier'.

VMD 库还有两种始终可以被识别的标识符子类型. 第一种是数, 等同于 Boost PP 中的数, 即范围为 0-BOOST_PP_LIMIT_MAG 的数值. 第二种是 v-type, 即以 BOOST_VMD_TYPE_ 开头、后跟数据类型名称的标识符. 例如, Boost PP 元组的 v-type 是 BOOST_VMD_TYPE_TUPLE, 而 v-type 本身的 v-type 是 BOOST_VMD_TYPE_TYPE. 所有数据类型都有自己的 v-type 标识符; 类型被 VMD 宏识别, 并可以像 VMD 识别的其他任何数据类型一样作为输入数据传递.

VMD 标识符系统甚至提供了一种方式 (稍后解释), 让最终用户创建自己的子类型标识符.

使用 VMD 的另一个原因是 VMD 理解 VMD 数据类型的"序列". 你可以拥有一个由数据类型组成的序列, VMD 可以把该序列转换为任何 Boost PP 数据类型, 或访问序列中的任何独立数据类型. VMD 序列中的标识符必须经过注册才能被识别.

#include <boost/vmd/elem.hpp>
#include <boost/vmd/to_tuple.hpp>

#define BOOST_VMD_REGISTER_NAME (NAME)
#define ASEQUENCE (1,2) NAME 147 BOOST_VMD_TYPE_NUMBER (a)(b)

BOOST_VMD_TO_TUPLE(ASEQUENCE)
BOOST_VMD_ELEM(2,ASEQUENCE)

我们的第一次展开 BOOST_VMD_TO_TUPLE(ASEQUENCE) 返回元组:

((1,2),NAME,147,BOOST_VMD_TYPE_NUMBER,(a)(b))

我们的第二次展开 BOOST_VMD_ELEM(2,ASEQUENCE) 返回序列元素:

147

序列让宏程序员能够接受来自用户、可能更贴近 C++ 构造的输入数据.

使用 VMD 的另一个原因是 VMD 理解数据类型. 除了专门询问某个特定输入是否是特定数据类型之外, 你还可以使用宏 BOOST_VMD_GET_TYPE 获取任何 VMD 数据的类型.

#include <boost/vmd/get_type.hpp>

BOOST_VMD_GET_TYPE((1,2)) // expands to BOOST_VMD_TYPE_TUPLE
BOOST_VMD_GET_TYPE(235)   // expands to BOOST_VMD_TYPE_NUMBER

等等.
