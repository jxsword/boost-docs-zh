数据类型

VMD 库提供了测试和解析预处理数据的功能.

C++ 预处理器将预处理数据定义为预处理记号. 预处理记号的类型可见于 C++ 标准文档的第 2.5 节.

VMD 库将其中两类预处理记号的子集作为"数据类型"来处理. 它们是 "identifier" 和 "pp-number" 预处理记号. VMD 无法解析的预处理记号类型有:

  • header-name
  • character-literal
  • user-defined-characteral-literal
  • string-literal
  • user-defined-string-literal
  • preprocessing-op-or-punc

尽管 VMD 无法解析这些预处理记号类型, 它仍然是一个非常有用的库, 因为宏编程的很大一部分都在与 'identifier' 和 'pp-number' 记号打交道.

VMD 标识符是由字母数字字符和下划线 ( _ ) 字符组成的预处理记号. 这与预处理记号 "identifier" 非常相似, 区别在于 VMD 标识符可以以数字字符开头, 从而使 VMD 标识符也可以是正整数字面量. VMD 提供将 VMD 标识符作为独立元素或在预处理记号序列中进行解析的功能.

VMD 数是 Boost PP 数, 即 0 到 BOOST_PP_LIMIT_MAG (默认为 256) 之间 (含) 的整数的预处理记号. 它们是预处理记号 "pp-number" 的一个小子集. VMD 提供将数作为独立元素或在预处理记号序列中进行解析的功能. VMD 数实际上是 VMD 标识符的一个子集, VMD 为其提供了特定功能. Boost PP 库对数有自己广泛的支持, VMD 不做重复.

VMD v-type 与数类似, 是 VMD 标识符的一个子集, 由以 BOOST_VMD_TYPE_ 开头、后跟一个数据类型助记符的标识符组成. 每个 v-type 都可以被 VMD 功能识别, 因此可以由宏传递或返回. 与任何标识符一样, v-type 既可以作为独立元素解析, 也可以在预处理记号序列中解析.

VMD 还可以测试空, 即作为宏输入传入或从宏返回时不带任何预处理记号的情况.

Boost PP 库支持四种独立的复合数据类型: 数组, 列表, seq 和元组. 这些数据类型都被 VMD 识别和支持. Boost PP 支持的另一种数据类型是变参数据, 它是以逗号分隔的预处理元素分组. 除了 Boost PP 已有的支持之外, VMD 对变参数据没有提供特别的支持.

VMD 具有处理四种 Boost PP 高级数据类型的功能. VMD 可以测试 Boost PP 数据类型, 并在预处理记号序列中对它们进行解析.

VMD 还可以解析序列. 序列由前面提到的零个或多个其他顶级数据类型连续表示. 因此, 序列可以表示 VMD 能解析的任何数据类型, 因为它可以由空, 单个数据类型, 或连续表示的多个数据类型构成.

空, 三种标识符类型, 四种 Boost PP 复合数据类型, 以及 VMD 序列, 就是 VMD 能够理解的数据类型. 其他低级预处理数据类型当然也可以在宏编程中使用, 但 VMD 无法解析这样的预处理数据.
