历史

版本 1.10, Boost 1.75

  • 添加了使用 BOOST_VMD_IS_GENERAL_IDENTIFIER 测试一般标识符语法的支持.

版本 1.9, Boost 1.60

  • 添加了对"空" seq 和元组的支持.

版本 1.8

  • 在对 VMD 进行评审之后, 我大幅简化了主接口, 并以修饰符的形式添加了可选功能. 主要变化是新增了大量用于序列的通用宏, 并将类型扩展为包含 v-type.
    • 添加了 BOOST_VMD_ELEM 宏.
    • 添加了 BOOST_VMD_EQUAL 宏.
    • 添加了 BOOST_VMD_NOT_EQUAL 宏.
    • 添加了 BOOST_VMD_IS_MULTI 宏.
    • 添加了 BOOST_VMD_IS_TYPE 宏.
    • 添加了 BOOST_VMD_ASSERT_IS_TYPE 宏.
    • 添加了 BOOST_VMD_IS_UNARY 宏.
    • 添加了 BOOST_VMD_SIZE 宏.
    • 一批宏已被 BOOST_VMD_ELEM 宏 (配合修饰符使用) 取代. 这些宏是:
      • BOOST_VMD_IDENTIFER
      • BOOST_VMD_BEGIN_IDENTIFIER
      • BOOST_VMD_AFTER_IDENTIFIER
      • BOOST_VMD_IS_BEGIN_IDENTIFIER
      • BOOST_VMD_NUMBER
      • BOOST_VMD_BEGIN_NUMBER
      • BOOST_VMD_AFTER_NUMBER
      • BOOST_VMD_IS_BEGIN_NUMBER
      • BOOST_VMD_ARRAY
      • BOOST_VMD_BEGIN_ARRAY
      • BOOST_VMD_AFTER_ARRAY
      • BOOST_VMD_IS_BEGIN_ARRAY
      • BOOST_VMD_LIST
      • BOOST_VMD_BEGIN_LIST
      • BOOST_VMD_AFTER_LIST
      • BOOST_VMD_IS_BEGIN_LIST
      • BOOST_VMD_SEQ
      • BOOST_VMD_BEGIN_SEQ
      • BOOST_VMD_AFTER_SEQ
      • BOOST_VMD_IS_BEGIN_SEQ
      • BOOST_VMD_TUPLE
      • BOOST_VMD_BEGIN_TUPLE
      • BOOST_VMD_AFTER_TUPLE
      • BOOST_VMD_IS_BEGIN_TUPLE
    • 每个宏都有自己的头文件.

版本 1.7

  • 该库经过重构以提供大幅增加的功能. 这包括:
    • 添加解析 v-type 的功能.
    • 添加解析 v-type 序列的功能.
    • 添加改进的 ASSERT 宏.
    • 添加 BOOST_VMD_EMPTY 和 BOOST_VMD_IDENTITY.

版本 1.6

  • 移除了与 Boost PP 新增的变参宏功能重复的所有功能.
  • 移除了 'native' 与 'pplib' 模式的概念.
  • 改用 Boost PP 库中的 BOOST_PP_VARIADICS 宏来判断变参宏的可用性, 并从该库中移除了用于此判断的 native 宏.
  • 更新了文档, 尤其是补充了 BOOST_VMD_EMPTY 宏的用法, 其缺陷以及与 Visual C++ 一起使用时的更完整信息.
  • 更改了目录结构, 以符合 Modular Boost 结构.

版本 1.5

  • 添加了验证 Boost PP 数据类型的宏.
  • 添加了检测和移除开头括号的宏.
  • 添加了测试参数是否为空的宏.
  • 添加了对独立头文件的支持.
  • 添加了对 'native' 与 'pplib' 模式的支持.
  • 添加了用于控制变参宏可用性, 模式和数据验证的控制宏.

版本 1.4

  • 在使用 VC++ 时移除了对 BOOST_PP_CAT 和 BOOST_PP_ADD 的内部依赖.

版本 1.3

  • 将版本信息和历史移入文档中.
  • 将 build.txt 独立为 doc 子目录下的文件, 并将 readme.txt 放在顶级目录下.
  • 破坏性变更
    • 主头文件的名称缩短为 'vmd.hpp'.
    • 该库遵循 Boost 的约定.
      • 将文件名改为小写字母加下划线.
      • 宏名现在以 BOOST_VMD_ 开头, 而不是以前的 VMD_.

版本 1.2

  • 添加了 readme.txt 文件.
  • 更新了所有 jamfile, 使得可以从库自身的本地目录进行测试和生成文档.

版本 1.1

  • 添加了关于在 Boost PP 与 VMD 中使用变参数据的更好文档.

版本 1.0

该库的初始版本.
