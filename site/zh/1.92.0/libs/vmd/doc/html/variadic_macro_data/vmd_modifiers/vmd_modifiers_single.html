修饰符与单元素序列

单元素序列就是我们在处理宏数据时通常所想的东西. 它是作为输入参数传递给某个宏并按此处理的单一类型的宏数据.

在不带修饰符的基本形式下, BOOST_VMD_ELEM 只是返回序列的特定元素. 对于单元素序列, 元素编号为 0 的 BOOST_VMD_ELEM 只是返回该单元素序列本身. 这对我们的简单序列而言没有提供多少功能. 然而借助修饰符, 我们可以以通用方式对单元素序列做一些事情, 对应于处理单一类型的数据并提取有关它的信息.

使用返回类型修饰符, 我们可以在获得数据的同时获得数据的类型. 当然, 我们也可以使用 BOOST_VMD_GET_TYPE 只获取数据的类型.

使用过滤修饰符, 我们只有在数据属于特定类型时才能获取数据, 否则获取空.

使用标识符修饰符, 我们只有在标识符匹配一个或多个其他标识符时才能获取它, 否则获取空.

使用索引修饰符, 如果标识符匹配一个或多个其他标识符, 我们可以同时获取标识符及其数字索引, 否则在找不到匹配时获取一个两个空元素组成的元组.
