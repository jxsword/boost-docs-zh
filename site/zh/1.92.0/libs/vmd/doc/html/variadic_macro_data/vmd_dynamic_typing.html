作为动态类型的输入

在 VMD 可解析的顶级类型所构成的约束之内, 该库赋予最终用户设计带有动态数据类型的宏的能力. 我的意思是, 宏可以被设计为根据某种约定 (不同宏输入组合具有略微不同的含义) 来处理不同的数据类型. 再加上使用变参参数设计此类宏的能力, 我们就拥有了一套宏创建的预处理系统, 在较小程度上可与模板元编程的 DSL 相媲美. 当然, 预处理器的灵活性远不及 C++ 模板, 但使用 VMD 和底层的 Boost PP 可以进行的这类预处理元编程, 即创建能处理不同数据类型组合的灵活宏, 仍然非常有趣.

当然, 宏需要能被最终用户使用, 因此序列在表示不同类型输入数据方面的语法能力, 必须与使用宏时的易用性和可理解性相平衡. 但由于某些序列可以在一定程度上模仿 C++ 函数调用, 因此可以借助 VMD 把宏表示为一种更接近 C++ 的语言.

在设计一个解析输入以确定调用者向你的宏传递何种数据类型的宏时, 重要的是要了解解析数据类型时的约束. 例如, 如果你设计一个宏, 其中某些输入可以是数, 标识符或其他某种顶级输入数据类型, 那么尝试解析数据以查看它是数还是标识符时, 如果数据不是 VMD 数据类型, 可能会因预处理错误而失败, 从而使你的设计失效. 因此, 在设计带数据类型的宏时, 通常意味着将数据限制为可解析的顶级类型.
