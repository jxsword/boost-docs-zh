从 1.7 版到 1.8 版的转换

由于当前版本的 VMD 为便于使用 VMD 功能而进行了大幅修改, 本节详细介绍先前 1.7 版 VMD 宏的等效功能.

功能上的变化涉及序列的解析. V1.7 的所有功能 (在序列开头查找各种数据类型) 的等效形式, 都由 V1.8 宏 BOOST_VMD_ELEM(0,sequence,...) 涵盖, 其中 '0' 是第一个序列元素, 'sequence' 是序列, 并带有其可选参数.

标识符

V1.7

BOOST_VMD_IDENTIFIER(sequence,keys,...) 在序列开头查找一个标识符, 并返回一个二元组, 其中第一个元素是从 1 开始的匹配索引 (如果没有找到标识符则为 0), 第二个元组元素是序列的其余部分 (如果没有找到标识符则为空).

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,(identifiers),BOOST_VMD_TYPE_IDENTIFIER,BOOST_VMD_RETURN_AFTER,BOOST_VMD_RETURN_INDEX) 返回一个三元组, 其中找到的标识符是第一个元组元素, 序列的其余部分是第二个元组元素, 从 0 开始的匹配索引是第三个元组元素. 如果没有找到标识符, 返回元组的所有元素都为空.

V1.7

BOOST_VMD_BEGIN_IDENTIFIER(sequence,keys,...) 在序列开头查找一个标识符, 并返回从 1 开始的匹配索引 (如果没有找到标识符则为 0).

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,(identifiers),BOOST_VMD_TYPE_IDENTIFIER,BOOST_VMD_RETURN_INDEX) 返回一个二元组, 其中找到的标识符是第一个元组元素, 从 0 开始的匹配索引是第二个元组元素. 如果没有找到标识符, 返回元组的两个元素都为空.

V1.7

BOOST_VMD_AFTER_IDENTIFIER(sequence,keys,...) 在序列开头查找一个标识符, 并返回序列的其余部分 (如果没有找到标识符则为空).

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,(identifiers),BOOST_VMD_TYPE_IDENTIFIER,BOOST_VMD_RETURN_ONLY_AFTER) 是完全等效的形式.

V1.7

BOOST_VMD_IS_BEGIN_IDENTIFIER(sequence,keys,...) 如果输入以一个标识符开头则返回 1, 否则返回 0.

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,(identifiers),BOOST_VMD_TYPE_IDENTIFIER) 返回找到的标识符, 如果没有找到则返回空. 你可以使用 BOOST_PP_COMPL(BOOST_VMD_IS_EMPTY(BOOST_VMD_ELEM(0,sequence,identifiers,BOOST_VMD_TYPE_IDENTIFIER))) 作为完全等效的形式.

数

V1.7

BOOST_VMD_NUMBER(sequence,...) 在序列开头查找一个数, 并返回一个二元组, 其中第一个元素是该数, 第二个元组元素是序列的其余部分. 如果没有找到数, 两个元组元素都为空.

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,BOOST_VMD_TYPE_NUMBER,BOOST_VMD_RETURN_AFTER) 是完全等效的形式.

V1.7

BOOST_VMD_BEGIN_NUMBER(sequence,...) 在序列开头查找一个数, 如果找到则返回该数, 如果没有找到则返回空.

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,BOOST_VMD_TYPE_NUMBER) 是完全等效的形式.

V1.7

BOOST_VMD_AFTER_NUMBER(sequence,...) 在序列开头查找一个数, 并返回序列的其余部分 (如果没有找到数则为空).

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,BOOST_VMD_TYPE_NUMBER,BOOST_VMD_RETURN_ONLY_AFTER) 是完全等效的形式.

V1.7

BOOST_VMD_IS_BEGIN_NUMBER(sequence,...) 如果输入以一个数开头则返回 1, 否则返回 0.

V1.8 等效形式

BOOST_VMD_ELEM(0,sequence,BOOST_VMD_TYPE_NUMBER) 返回找到的数, 如果没有找到则返回空. 你可以使用 BOOST_PP_COMPL(BOOST_VMD_IS_EMPTY(BOOST_VMD_ELEM(0,sequence,BOOST_VMD_TYPE_NUMBER))) 作为完全等效的形式.
