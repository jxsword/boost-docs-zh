Boost PP 可重入版本

VMD 中几乎所有的宏都有等效的可重入版本, 旨在用于 BOOST_PP_WHILE 循环中. 这些版本带有下划线 D 后缀, 把下一个可用的 BOOST_PP_WHILE 迭代作为其第一个参数, 然后具有与其无后缀等效宏完全相同的功能. 它们可以在 BOOST_PP_WHILE 循环中使用以提供略快的预处理, 但正如 BOOST_PP_WHILE 和 BOOST_PP_WHILE_##d 的文档所解释的, 并不强制使用它们.

这些宏是:

数组

  • BOOST_VMD_IS_ARRAY_D
  • BOOST_VMD_IS_EMPTY_ARRAY_D
  • BOOST_VMD_ASSERT_IS_ARRAY_D

标识符

  • BOOST_VMD_IS_IDENTIFIER_D
  • BOOST_VMD_ASSERT_IS_IDENTIFIER_D

列表

  • BOOST_VMD_IS_LIST_D
  • BOOST_VMD_IS_EMPTY_LIST_D
  • BOOST_VMD_ASSERT_IS_LIST_D

序列

  • BOOST_VMD_ELEM_D
  • BOOST_VMD_ENUM_D
  • BOOST_VMD_EQUAL_D
  • BOOST_VMD_GET_TYPE_D
  • BOOST_VMD_IS_MULTI_D
  • BOOST_VMD_IS_UNARY_D
  • BOOST_VMD_NOT_EQUAL_D
  • BOOST_VMD_SIZE_D
  • BOOST_VMD_TO_ARRAY_D
  • BOOST_VMD_TO_LIST_D
  • BOOST_VMD_TO_SEQ_D
  • BOOST_VMD_TO_TUPLE_D

Seq 宏

  • BOOST_VMD_IS_SEQ_D
  • BOOST_VMD_ASSERT_IS_SEQ_D

类型

  • BOOST_VMD_IS_TYPE_D
  • BOOST_VMD_ASSERT_IS_TYPE_D

Other

  • BOOST_VMD_IS_PARENS_EMPTY_D
