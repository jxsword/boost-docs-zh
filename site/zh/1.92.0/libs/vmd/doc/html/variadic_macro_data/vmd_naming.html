命名约定

库中所有的宏都以 BOOST_VMD_ 前缀开头, 其中 VMD 代表 'Variadic Macro Data' (变参宏数据).

在前缀之后, 宏中的某些名称指代本库或 Boost PP 中的数据类型. 这些名称及其数据类型是:

  1. TUPLE = Boost PP 元组数据类型.
  2. ARRAY = Boost PP 数组数据类型.
  3. LIST = Boost PP 列表数据类型.
  4. SEQ = Boost PP seq 数据类型.
  5. IDENTIFIER = 一个 VMD 标识符
  6. NUMBER = 一个 VMD 数, 它是带有一些增强的 Boost PP 数
  7. TYPE = 一个 VMD 类型

我使用上述大多数名称, 是为了尽可能贴近地模仿 Boost PP 的命名. 后续使用的词 'array', 'list', 'seq' 和 'tuple' 指代这些 Boost PP 数据类型, 除非另有说明. 关于这些数据类型的任何解释, 请参见 Boost PP 的帮助文档.

术语 'sequence' 指的是 VMD 数据类型的序列, 与 Boost PP 序列不同, 后者在本文档中始终被称为 'seq'.

术语 'return' 指的是宏的展开. 我使用宏"返回某些数据"的术语, 而不是宏"展开为某些数据"的术语, 即使后者更准确, 因为前者更贴近我认为 C++ 程序员思考宏编程的方式.

术语 'emptiness' 指的是没有预处理数据传给宏或从宏返回. 我避免使用 'nothing' 一词, 因为它的含义过于模糊.

术语 'data type' 指的是 VMD 可以解析、且在上面列出的各种预处理输入类型, 也包括空.

术语 'v-type' 指的是 VMD 类型, 术语 'number' 指的是 VMD 数, 术语 'identifier' 指的是 VMD 标识符. 所有这些都会在各自合适的地方加以解释.

术语 "UB" 代表 C++ 标准中所规定的"未定义行为" (undefined behavior).
