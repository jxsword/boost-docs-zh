Char Delimiters Separator

template <class Char, class Traits = std::char_traits<Char> >
class char_delimiters_separator{

char_delimiters_separator 类是 TokenizerFunction 概念的一个实现, 可用于把文本切分为词法记号. 它是 tokenizer 和 token_iterator_generator 的默认 TokenizerFunction. 下面是一个示例.

示例

// simple_example_4.cpp
#include<iostream>
#include<boost/tokenizer.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "This is,  a test";
   tokenizer<char_delimiters_separator<char> > tok(s);
   for(tokenizer<char_delimiters_separator<char> >::iterator beg=tok.begin(); beg!=tok.end();++beg){
       cout << *beg << "\n";
   }
}

构造与使用

有一个值得关注的构造函数, 如下所示

explicit char_delimiters_separator(bool return_delims = false, 
const Char* returnable = "",const Char* nonreturnable = "" )

参数

说明
return_delims 是否返回已找到的分隔符. 注意并非所有分隔符都能被返回. 解释参见另外两个参数.
returnable 该参数指定可返回的分隔符. 它们是当 return_delims 为 true 时可以作为词法记号返回的分隔符. 由于这些分隔符通常为标点符号, 如果实参为 0, 则可返回分隔符将是所有使 std::ispunct(C) 为真的字符 C. 如果实参为 "", 则表示没有可返回分隔符.
nonreturnable 该参数指定不可返回的分隔符. 它们是不能作为词法记号返回的分隔符. 由于这些分隔符通常为空白字符, 如果实参为 0, 则不可返回分隔符将是所有使 std::isspace(C) 为真的字符 C. 如果实参为 "", 则表示没有不可返回分隔符.

之所以要区分不可返回分隔符与可返回分隔符, 是因为某些分隔符只是用来切分词法记号, 别无他用. 以下面的字符串 "b c +" 为例. 假设你正在编写一个简单的计算器来解析后缀表示法的表达式. 空格和 + 都能分隔词法记号, 但你只对 + 感兴趣, 而对空格不感兴趣. 事实上, 让空格作为词法记号返回只会使代码复杂化. 在这种情况下, 你应把 + 指定为可返回分隔符, 把空格指定为不可返回分隔符.

要使用该类, 在任何需要 TokenizerFunction 对象的地方传入它的一个对象即可.

模板参数

参数 说明
Char 词法记号内元素的类型, 通常为 char.
特征 (Traits) Char 的特征类, 通常为 std::char_traits<Char>
