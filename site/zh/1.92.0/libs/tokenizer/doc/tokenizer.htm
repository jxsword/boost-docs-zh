Tokenizer 类

  template <
        class TokenizerFunc = char_delimiters_separator<char>, 
        class Iterator = std::string::const_iterator,
        class Type = std::string
  >
  class tokenizer

tokenizer 类为序列中包含的一系列词法记号提供容器视图. 你可以在构造时或使用 assign 成员函数来设置要解析的序列以及用于解析该序列的 TokenizerFunction. 注意: 构造时并不会真正执行解析. 解析按需进行, 即当通过 begin 提供的迭代器访问词法记号时才解析.

示例

// simple_example_1.cpp
#include<iostream>
#include<boost/tokenizer.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "This is,  a test";
   tokenizer<> tok(s);
   for(tokenizer<>::iterator beg=tok.begin(); beg!=tok.end();++beg){
       cout << *beg << "\n";
   }
}

simple_example_1 的输出为:

This
is
a
test

模板参数

参数 说明
TokenizerFunc 用于解析该序列的 TokenizerFunction.
Iterator 指定该序列的迭代器的类型.
Type 词法记号的类型, 通常为 string.

 

相关类型

类型

备注
iterator begin 和 end 返回的类型. 注意: 迭代器类别至多为 ForwardIterator. 如果 Iterator 模板参数是 InputIterator, 则为 InputIterator. 对于任何其他类别, 则为 ForwardIterator.
const_iterator 与 iterator 相同的类型.
value_type 与模板参数 Type 相同的类型
reference 与 value_type& 相同的类型
const_reference 与 const 引用相同的类型
pointer 与 value_type* 相同的类型
const_pointer 与 const 指针相同的类型
size_type void
difference_type void

参数

说明
c 一个包含待解析序列的容器. 注意: c.begin() 和 c.end() 必须可转换为模板参数 Iterator.
f 一个作为 TokenizerFunction 模型的函数对象, 将用于解析该序列.
first 表示待解析序列起始位置的迭代器.
last 表示待解析序列末尾之后位置的迭代器.
