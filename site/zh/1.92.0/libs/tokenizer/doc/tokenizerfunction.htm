TokenizerFunction 概念

TokenizerFunction 是一个函数对象, 其目的是解析给定的序列, 直到恰好找到 1 个词法记号或到达序列末尾. 然后它会更新该词法记号, 并告知调用者序列中的位置, 即紧随当前词法记号所解析的最后一个元素之后的下一个元素的位置.

细化自

可赋值 (Assignable)、可拷贝构造 (CopyConstructable)

记法

X 一个作为 TokenizerFunction 模型的类型
func 类型为 X
tok Token 类型的对象
next 指向正在解析的序列中第一个未解析元素的迭代器
end 指向正在解析的序列末尾之后的迭代器

定义

词法记号是解析序列的结果.

有效表达式

除了可赋值 (Assignable) 与可拷贝构造 (CopyConstructable) 中的表达式之外, 以下表达式也是有效的

名称 表达式 返回类型
仿函数 func(next, end, tok) bool
reset reset() void

表达式语义

除了可赋值 (Assignable) 与可拷贝构造 (CopyConstructable) 的表达式语义之外, TokenizerFunction 还有以下表达式语义

名称 表达式 Precondition 语义 Postcondition
operator() func(next, end, tok) next 和 end 是指向同一序列的有效迭代器. next 是函数可以随意修改的引用. tok 已被构造. 返回值指示是否在序列 [next,end) 中找到了新的词法记号 如果返回值为 true, 则新的词法记号被赋给 tok. next 总是被更新为下一次调用应当开始解析的位置.
reset reset() None 清除对象在解析当前序列时所使用的所有状态变量. 可以给出一个新的待解析序列.

复杂度保证

无保证. TokenizerFunction 的模型可以自行定义其复杂度

模型

escaped_list_separator

offset_separator

char_delimiters_separator
