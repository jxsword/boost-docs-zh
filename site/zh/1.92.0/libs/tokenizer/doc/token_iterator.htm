Token 迭代器

template <
        class TokenizerFunc = char_delimiters_separator<char>, 
        class Iterator = std::string::const_iterator,
        class Type = std::string
>
class token_iterator_generator 

template<class Type, class Iterator, class TokenizerFunc>
typename token_iterator_generator<TokenizerFunc,Iterator,Type>::type 
make_token_iterator(Iterator begin, Iterator end,const TokenizerFunc& fun)

token 迭代器用于为解析序列中的词法记号提供迭代器视图.

示例

/// simple_example_5.cpp
#include<iostream>
#include<boost/token_iterator.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "12252001";
   int offsets[] = {2,2,4};
   offset_separator f(offsets, offsets+3);
   typedef token_iterator_generator<offset_separator>::type Iter;
   Iter beg = make_token_iterator<string>(s.begin(),s.end(),f);
   Iter end = make_token_iterator<string>(s.end(),s.end(),f); 
   // The above statement could also have been what is below
   // Iter end;
   for(;beg!=end;++beg){
     cout << *beg << "\n";
   }
}

 

模板参数

参数 说明
TokenizerFunc 用于解析该序列的 TokenizerFunction.
Iterator 指定该序列的迭代器的类型.
Type 词法记号的类型, 通常为 string.

所建模的概念

Iterator 的类别, 最高到前向迭代器 (Forward Iterator) 为止. 更高的类别会被降级为前向迭代器.

相关类型

类型

备注
token_iterator_generator::type token 迭代器的类型.

创建

template<class Type, class Iterator, class TokenizerFunc>
typename token_iterator_generator<TokenizerFunc,Iterator,Type>::type 
make_token_iterator(Iterator begin, Iterator end,const TokenizerFunc& fun)

参数

说明
begin 待解析序列的开头.
end 待解析序列的末尾之后.
fun 一个作为 TokenizerFunction 模型的函数对象
