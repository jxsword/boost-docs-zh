char_separator<Char, Traits>

char_separator 类基于字符分隔符把字符序列切分为词法记号, 方式与 strtok() 大致相同 (但没有不可重入和破坏输入序列这些弊病).

char_separator 类与 token_iterator 或 tokenizer 配合使用以执行分词.

定义

strtok() 函数不会把与字符分隔符的匹配包含在输出的词法记号序列中. 不过, 有时让分隔符出现在输出序列中是有用的, 因此 char_separator 把它作为选项提供. 我们把会作为输出词法记号出现的分隔符称为 保留分隔符, 把不会作为输出词法记号出现的分隔符称为 丢弃分隔符.

当输入序列中两个分隔符相邻出现时, 就产生了是输出一个 空词法记号 还是直接跳过的问题. strtok() 的行为是跳过. char_separator 类则两种选项都提供.

示例

第一个示例展示如何用 char_separator 替代 strtok() 函数. 我们指定了三个字符分隔符, 它们不会作为输出词法记号出现. 我们没有指定任何保留分隔符, 并且默认会忽略所有空词法记号.

// char_sep_example_1.cpp
#include <iostream>
#include <boost/tokenizer.hpp>
#include <string>

int main()
{
  std::string str = ";;Hello|world||-foo--bar;yow;baz|";
  typedef boost::tokenizer<boost::char_separator<char> > 
    tokenizer;
  boost::char_separator<char> sep("-;|");
  tokenizer tokens(str, sep);
  for (tokenizer::iterator tok_iter = tokens.begin();
       tok_iter != tokens.end(); ++tok_iter)
    std::cout << "<" << *tok_iter << "> ";
  std::cout << "\n";
  return EXIT_SUCCESS;
}
输出为: 
<Hello> <world> <foo> <bar> <yow> <baz>

下一个示例展示使用两个丢弃分隔符 '-' 和 ';' 以及一个保留分隔符 '|' 进行分词. 我们还指定了当两个分隔符相邻时, 空词法记号应出现在输出中.

// char_sep_example_2.cpp
#include <iostream>
#include <boost/tokenizer.hpp>
#include <string>

int main()
{
    std::string str = ";;Hello|world||-foo--bar;yow;baz|";
    typedef boost::tokenizer<boost::char_separator<char> > 
        tokenizer;
    boost::char_separator<char> sep("-;", "|", boost::keep_empty_tokens);
    tokenizer tokens(str, sep);
    for (tokenizer::iterator tok_iter = tokens.begin();
         tok_iter != tokens.end(); ++tok_iter)
      std::cout << "<" << *tok_iter << "> ";
    std::cout << "\n";
    return EXIT_SUCCESS;
}
输出为: 
<> <> <Hello> <|> <world> <|> <> <|> <> <foo> <> <bar> <yow> <baz> <|> <>

最后一个示例展示使用 char_separator 的默认构造函数对标点字符和空白字符进行分词.

// char_sep_example_3.cpp
#include <iostream>
#include <boost/tokenizer.hpp>
#include <string>

int main()
{
   std::string str = "This is,  a test";
   typedef boost::tokenizer<boost::char_separator<char> > Tok;
   boost::char_separator<char> sep; // default constructed
   Tok tok(str, sep);
   for(Tok::iterator tok_iter = tok.begin(); tok_iter != tok.end(); ++tok_iter)
     std::cout << "<" << *tok_iter << "> ";
   std::cout << "\n";
   return EXIT_SUCCESS;
}
输出为: 
<This> <is> <,> <a> <test>

模板参数

参数 说明 默认值
Char 词法记号内元素的类型, 通常为 char.  
Traits 字符类型的 char_traits. char_traits<char>

所建模的概念

Tokenizer Function

成员

explicit char_separator(const Char* dropped_delims,
                        const Char* kept_delims = "",
                        empty_token_policy empty_tokens = drop_empty_tokens)

这会创建一个 char_separator 对象, 随后可以用它创建 token_iterator 或 tokenizer 来执行分词. dropped_delims 和 kept_delims 是字符串, 其中每个字符在分词时都用作分隔符. 每当在输入序列中看到分隔符时, 当前词法记号即告结束, 新的词法记号开始. dropped_delims 中的分隔符不会作为词法记号出现在输出中, 而 kept_delims 中的分隔符会作为词法记号出现. 如果 empty_tokens 为 drop_empty_tokens, 则空词法记号不会出现在输出中. 如果 empty_tokens 为 keep_empty_tokens, 则空词法记号会出现在输出中.

explicit char_separator()

函数 std::isspace() 用于识别丢弃分隔符, std::ispunct() 用于识别保留分隔符. 此外, 空词法记号会被丢弃.

template <typename InputIterator, typename Token>
bool operator()(InputIterator& next, InputIterator end, Token& tok)

该函数由 token_iterator 调用以执行分词. 用户通常不会直接调用它.
