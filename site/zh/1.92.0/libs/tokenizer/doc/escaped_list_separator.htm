Escaped List Separator

escaped_list_separator<Char, Traits = std::char_traits<Char> >

escaped_list_separator 类是 TokenizerFunction 的一个实现. escaped_list_separator 解析 csv (逗号分隔值) 格式的超集. 这种格式的示例见下文. 这里假定使用分隔符、引号和转义符的默认字符.

Field 1,Field 2,Field 3
Field 1,"Field 2, with comma",Field 3
Field 1,Field 2 with \"embedded quote\",Field 3
Field 1, Field 2 with \n new line,Field 3
Field 1, Field 2 with embedded \\ ,Field 3

字段通常用逗号分隔. 如果想在字段中放入逗号, 需要为它加上引号. 此外还支持 3 种转义序列

转义序列

结果
<escape><quote> <quote>
<escape>n newline
<escape><escape> <escape>

其中 <quote> 是被指定为引号的任意字符, <escape> 是被指定为转义字符的任意字符.

示例

// simple_example_2.cpp
#include<iostream>
#include<boost/tokenizer.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "Field 1,\"putting quotes around fields, allows commas\",Field 3";
   tokenizer<escaped_list_separator<char> > tok(s);
   for(tokenizer<escaped_list_separator<char> >::iterator beg=tok.begin(); beg!=tok.end();++beg){
       cout << *beg << "\n";
   }
}

 

构造与使用

escaped_list_separator 有 2 个构造函数, 如下所示

explicit escaped_list_separator(Char e = '\\', Char c = ',',Char q = '\"')

参数

说明
e 指定用于转义序列的字符. 默认为 C 风格的 \ (反斜杠). 不过你可以通过传入不同的字符来覆盖它. 想这么做的一个例子是: 当你有许多 Windows 风格文件名的字段时, 不必对路径中的每个 \ 进行转义, 而可以把转义字符换成别的.
c 指定用于分隔字段的字符
q 指定用于引号的字符.

 

escaped_list_separator(string_type e, string_type c, string_type q):

参数

说明
e 字符串 e 中的任何字符都被视为转义字符. 如果给定空字符串, 则没有转义字符.
c 字符串 c 中的任何字符都被视为分隔符. 如果给定空字符串, 则没有分隔符字符.
q 字符串 q 中的任何字符都被视为引号. 如果给定空字符串, 则没有引号字符.

 

要使用该类, 在 Tokenizer 包中任何需要 TokenizerFunction 的地方传入它的一个对象即可.

 

模板参数

参数 说明
Char 词法记号内元素的类型, 通常为 char.
特征 (Traits) Char 类型的特征类. 用于比较 Char. 默认为 std::char_traits<Char>
