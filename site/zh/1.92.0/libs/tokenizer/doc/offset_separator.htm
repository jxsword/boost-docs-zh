Offset Separator

class offset_separator

offset_separator 类是 TokenizerFunction 概念的一个实现, 可与 tokenizer 类一起使用来把文本切分为词法记号. offset_separator 基于偏移量序列把 Char 序列切分为字符串. 例如, 如果你有字符串 "12252001" 和偏移量 (2,2,4), 它会把该字符串切分为 12 25 2001. 下面是一个示例.

示例

// simple_example_3.cpp
#include<iostream>
#include<boost/tokenizer.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "12252001";
   int offsets[] = {2,2,4};
   offset_separator f(offsets, offsets+3);
   tokenizer<offset_separator> tok(s,f);
   for(tokenizer<offset_separator>::iterator beg=tok.begin(); beg!=tok.end();++beg){
     cout << *beg << "\n";
   }
}

 

构造与使用

offset_separator 有 1 个值得关注的构造函数. (默认构造函数只是为了让某些编译器满意). 声明如下

template<typename Iter>
offset_separator(Iter begin,Iter end,bool bwrapoffsets = true, bool breturnpartiallast = true)

参数

说明
begin, end 指定整数偏移量序列.
bwrapoffsets 指定当所有偏移量用尽时是否回绕到偏移量序列的开头. 例如, 字符串 "1225200101012002" 使用偏移量 (2,2,4) 且 bwrapoffsets 为 true 时, 将解析为 12 25 2001 01 01 2002. 若 bwrapoffsets 为 false, 则解析到 12 25 2001 后停止, 因为所有偏移量已用尽.
breturnpartiallast 指定当解析序列在产出当前偏移量所要求的字符数之前结束, 是用已解析的内容创建一个词法记号, 还是忽略它. 例如, 字符串 "122501" 使用偏移量 (2,2,4) 且 breturnpartiallast 设为 true 时, 将解析为 12 25 01. 若设为 false, 则解析到 12 25 后停止, 因为序列中只剩 2 个字符而非应有的 4 个.

要使用该类, 在任何需要 TokenizerFunction 的地方传入它的一个对象即可. 如果默认构造该对象, 它将把解析序列中的每个字符都作为一个词法记号返回 (即默认偏移量为 1, 且 bwrapoffsets 为 true).
