引言

Boost Tokenizer 包提供了一种灵活且易用的方式, 把字符串或其他字符序列切分为一系列词法记号. 下面是一个把短语切分为单词的简单示例.

// simple_example_1.cpp
#include<iostream>
#include<boost/tokenizer.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "This is,  a test";
   tokenizer<> tok(s);
   for(tokenizer<>::iterator beg=tok.begin(); beg!=tok.end();++beg){
       cout << *beg << "\n";
   }
}

你可以通过使用 TokenizerFunction 来选择字符串的解析方式. 如果你不指定任何内容, 默认的 TokenizerFunction 是 char_delimiters_separator<char>, 它默认基于空格和标点切分字符串. 下面是使用另一个名为 escaped_list_separator 的 TokenizerFunction 的示例. 该 TokenizerFunction 解析逗号分隔值 (CSV) 行的超集. 其格式如下:

Field 1,"putting quotes around fields, allows commas",Field 3

下面是一个把上一行切分为三个字段的示例.

// simple_example_2.cpp
#include<iostream>
#include<boost/tokenizer.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "Field 1,\"putting quotes around fields, allows commas\",Field 3";
   tokenizer<escaped_list_separator<char> > tok(s);
   for(tokenizer<escaped_list_separator<char> >::iterator beg=tok.begin(); beg!=tok.end();++beg){
       cout << *beg << "\n";
   }
}

最后, 对于某些 TokenizerFunction, 你必须向构造函数传入一些内容才能做出有意思的事情. offset_separator 就是这样一个例子. 该类基于偏移量把字符串切分为词法记号. 例如, 当使用偏移量 2,2,4 解析 12252001 时, 它变成 12 25 2001. 所用代码如下.

// simple_example_3.cpp
#include<iostream>
#include<boost/tokenizer.hpp>
#include<string>

int main(){
   using namespace std;
   using namespace boost;
   string s = "12252001";
   int offsets[] = {2,2,4};
   offset_separator f(offsets, offsets+3);
   tokenizer<offset_separator> tok(s,f);
   for(tokenizer<offset_separator>::iterator beg=tok.begin(); beg!=tok.end();++beg){
       cout << *beg << "\n";
   }
}
