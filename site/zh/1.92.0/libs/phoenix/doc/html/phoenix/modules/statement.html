惰性语句……

到目前为止介绍的表达式已经足够强大, 可以构建相当精巧的结构. 我们已经介绍了惰性函数和惰性运算符. 那么惰性语句呢? 首先, 来一道开胃菜:

使用std::for_each 打印 STL 容器中所有编号为奇数的内容 (all_odds.cpp) :

std::for_each(c.begin(), c.end(),
    if_(arg1 % 2 == 1)
    [
        cout << arg1 << ' '
    ]
);

咦? 这也是合法的 C++ 吗? 请继续往下读……

是的, 这是合法的 C++. 上面的示例代码已经尽可能贴近 C++ 的语法. 这种风格化的 C++ 语法与真正的 C++ 代码有所不同. 第一, if 带有一个尾部下划线. 第二, 代码块使用方括号而不是我们熟悉的花括号 {}.
