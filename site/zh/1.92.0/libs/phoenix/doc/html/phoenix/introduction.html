引言

Phoenix 库使 FP 技术在 C++ 中成为可能, 例如高阶函数、lambda (无名函数) 、柯里化 (currying) (部分函数应用) 以及惰性求值. 其侧重点在于实用性和可用性, 而非纯粹性、优雅性或对 FP 原则的严格遵循.

FP 是一种完全不受特定语言束缚的编程规范. 事实上, FP 作为一种编程规范可以应用于许多编程语言. 以 C++ 领域为例, 我们正看到越来越多的 FP 技术得到应用. C++ 已经足够丰富, 至少可以支持 FP 的一些最重要的方面. C++ 是一门多范式编程语言. 它不仅是过程式的, 也不仅是面向对象的. 在标准 C++ 库的核心之下, 仔细观察 STL 就能发现 FP 已有雏形. 显然, STL 的作者了解并实践 FP. 在不久的将来, 我们必将看到更多 FP 技术渗透进主流.

事实上, 大多数 FP 技术可以与标准的面向对象和命令式编程范式很好地共存. 例如, 当我们使用 STL 算法和函数对象时, 我们已经在做 FP 了. Phoenix 是进化性的下一步.
