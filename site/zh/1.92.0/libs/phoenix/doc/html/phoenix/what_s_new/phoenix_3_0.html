Phoenix 3.0

这是 Phoenix 作为 Boost 一等公民的首次正式发布. 作为对 Phoenix V2 评审的结果, 内部实现被完全重写. 因此内部扩展机制有所不同.

  • composite<...>、as_composite<...> 和 compose 已被移除并被替代. 深入讨论参见深入 Phoenix一节
  • phoenix.modules.function phoenix::function 现在支持实现Boost.Result Of 协议的函数对象. 这是一项破坏性变更
  • 用于轻松适配已有函数和函数对象的样板宏
  • Bind 与 Boost.Bind 不完全兼容. 相关限制将尽快写入文档.
