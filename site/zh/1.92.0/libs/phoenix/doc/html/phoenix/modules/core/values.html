值 

#include <boost/phoenix/core/value.hpp>

每当我们在部分应用的函数中看到一个常量时, 就会自动为我们创建一个

expression::value<T>::type

(其中 T 是该常量的类型) . 例如:

add(arg1, 6)

传入第二个参数6 时, 一个expression::value<T>::type 会在幕后被隐式创建. 这也等价于add(arg1, val(6)).

val(v)

生成一个expression::value<T>::type, 其中T 是v 的类型. 在大多数情况下, 无需显式使用val, 但正如我们稍后将看到的, 有些情况下这是不可避免的.

求值一个值

与参数一样, 值也是 actor. 因此, 值可以被求值. 调用一个值给出该值的标识. 示例:

cout << val(3)() << val("Hello World")();

输出“3 Hello World”.
