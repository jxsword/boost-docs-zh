Actor 详解

Actor

核心概念是Actor. Actor 是多态函数对象 (Polymorphic Function Object) 概念的一个模型 (可接受 0 到 N 个参数, N 是预定义的最大值) .

一个Actor 包含一个有效的 Phoenix 表达式; 对任一函数调用运算符重载的调用都会启动求值过程.

注释

可以设置BOOST_PHOENIX_LIMIT, 即 actor 可接受的预定义最大元数. 默认情况下, BOOST_PHOENIX_LIMIT 被设为 10.

actor 模板类模拟了Actor 概念:

template <typename Expr>
struct actor
{
    template <typename Sig>
    struct result;

    typename result_of::actor<Expr>::type
    operator()() const;

    template <typename T0>
    typename result_of::actor<Expr, T0 &>::type
    operator()(T0& _0) const;

    template <typename T0>
    typename result_of::actor<Expr, T0 const &>::type
    operator()(T0 const & _0) const;

    //...
};

函数调用运算符

针对 0 到 N 个参数共有 2*N 个函数调用运算符 (N == BOOST_PHOENIX_LIMIT) . actor 类接受这些参数并把它们转发给默认求值动作.

此外, 还存在接受 const 与非 const 引用的各种排列组合的函数调用运算符. 这些运算符为所有 N <= BOOST_PHOENIX_PERFECT_FORWARD_LIMIT 创建 (默认为 3) .

注释

转发函数问题

当前的 C++ 有一个已知问题, 即“转发函数问题”. 问题是:给定任意函数F, 按现行 C++ 语言规则, 无法创建一个转发函数FF 使其透明地承接F 的参数.

Context

在 actor 函数调用中, 在调用求值函数之前, actor 会创建一个上下文. 该上下文由一个Environment 和一个Action 部分组成, 其中包含对给定表达式求值所需的全部信息.

Environment

Environment 是随机访问序列 (Random Access Sequence) 的一个模型.

传给 actor 函数调用运算符的参数被收集在 Environment 中:

库的其他部分 (例如 scope 模块) 扩展了Environment 概念, 以保存其他信息, 例如局部变量等.

Actions

动作 (Actions) 是 Phoenix 中负责赋予实际表达式特定行为的部分. 在遍历 Phoenix 表达式树期间, 只要文法中的指定规则被匹配, 这些动作就会被调用.

struct actions
{
    template <typename Rule>
    struct when;
};

嵌套的when 模板被要求是Proto 原语变换 (Primitive Transform) . 别担心, 你还不必学习Boost.Proto! Phoenix 提供了一些包装器, 让你无需深入 proto 就能定义简单的动作.

Phoenix 自带一个预定义的default_actions 类, 以 C++ 语义对表达式求值:

struct default_actions
{
    template <typename Rule, typename Dummy = void>
    struct when
        : proto::_default<meta_grammar>
    {};
};

有关如何使用 default_actions 类以及如何把自定义动作挂接到求值过程的更多信息, 参见再谈动作 (more on actions) .

求值 
struct evaluator
{
    template <typename Expr, typename Context>
    unspecified operator()(Expr &, Context &);
};

evaluator const eval = {};

Phoenix 表达式的求值通过调用evaluator 的函数调用运算符启动.

在上下文构建完成后, actor 函数运算符重载会调用求值器. 作为参考, 下面是一个接受两个参数的典型actor::operator():

template <typename T0, typename T1>
typename result_of::actor<Expr, T0 &, T1 &>::type
operator()(T0 &t0, T1 &t1) const
{
    fusion::vector2<T0 &, T1 &> env(t0, t1);

    return eval(*this, context(env, default_actions()));
}
result_of::actor

为了与actor::operator() 家族保持对称, 有一个专用于 actor 结果类型计算的元函数, 名为result_of::actor. 该元函数允许我们直接指定传给actor::operator() 函数的参数类型. 下面是一个接受两个参数的典型actor_result:

namespace result_of
{
    template <typename Expr, typename T0, typename T1>
    struct actor
    {
        typedef fusion::vector2<T0, T1>                                           env_tpe;
        typedef typename result_of::context<env_type, default_actions>::type      ctx_type
        typedef typename boost::result_of<evaluator(Expr const&, ctx_type)>::type type;
    };
}
