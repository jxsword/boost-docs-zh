Background

差不多整整一年前, Joel de Guzman 请我接手 Boost Phoenix 的主要维护工作, 我同意了, 但并不真正清楚自己接下的是什么. 最初几个月, 我修复了许多容易修复的问题, 同时学习如何使用 git 保持条理. 随后事情变得更艰难, 因为我开始遇到不那么容易修复的问题. 我还发现自己有些东西理解得不够透彻.

2014 年底, 我重新回到这项任务. 在此期间我学到了很多, 特别是关于 Boost Fusion 和 Boost Proto 的知识, Boost Phoenix 大量使用了它们. 我还学会了如何编辑 QuickBook 文件并重新生成它们.

我仍未解决 Boost Phoenix 中的所有问题. 我想我正在逼近其中一些遗留问题. 我现在知道 Phoenix V3 的一些问题在 Phoenix V2 中同样存在. 这改变了我解决问题的方式, 因为我确信这些问题不可能出在 Boost Proto 的使用上, 因为 V2 并未使用它.

2015 年期间, 我在理解问题所在以及如何避免或绕过它们方面取得了进一步进展. 这给了我信心去探索这段代码的更多应用, 我预计未来几个月这方面会有很大发展.

我想在本文中分享我一直在做的一些事情以及我解决某些问题的方式. 这样做的原因之一是, 也许还有其他人在考虑接手维护一个并非由他们自己编写的库. 我希望我能让人们更容易做到这一点.
