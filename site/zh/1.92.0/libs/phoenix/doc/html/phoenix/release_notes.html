发布说明

  • 版本 3.2.0
  • 新特性:
    • Phoenix 现在以可选扩展的形式提供了惰性列表 实现.
  • 新示例:
    • 新示例bind_goose 展示了boost bind 与boost phoenix bind 之间的兼容性.
  • 已修复的缺陷:
    • #10927 phoenix/test/stdlib/cmath.cpp 中 fabs 缺少 std:: 限定
    • #11085 phoenix/test/function/function_tests.cpp 中 pow 调用缺少限定
    • 修复了bind、lambda 和let 的许多失败用例.
