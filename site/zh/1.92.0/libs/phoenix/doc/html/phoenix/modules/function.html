Function

函数适配

function 类模板提供了一种实现惰性求值函数的机制. 从语法上看, 惰性函数就像普通的 C/C++ 函数. 函数调用的样子很眼熟, 与普通 C++ 函数的感觉相同. 但与普通函数不同, 实际的函数执行被延迟了.

#include <boost/phoenix/function.hpp>

与需要通过 bind 函数显式绑定的普通函数指针或函数对象不同 (参见Bind) , 这些函数的参数类型被自动进行惰性绑定.

为了创建惰性函数, 我们需要实现多态函数对象 (Polymorphic Function Object) 概念的一个模型. 对于接受N 个参数的函数, 多态函数对象 (Polymorphic Function Object) 的模型必须提供:

  • 一个operator(), 接受N 个参数并实现函数逻辑. 这对普通函数指针同样成立.
  • 一个嵌套元函数result<Signature> 或嵌套 typedefresult_type, 遵循Boost.Result Of 协议

例如, 下面的类型实现了 FunctionEval 概念, 以提供一个惰性阶乘函数:

struct factorial_impl
{
    template <typename Sig>
    struct result;

    template <typename This, typename Arg>
    struct result<This(Arg const &)>
    {
        typedef Arg type;
    };

    template <typename Arg>
    Arg operator()(Arg const & n) const
    {
        return (n <= 0) ? 1 : n * (*this)(n-1);
    }
};

(参见factorial.cpp)

实现了factorial_impl 类型之后, 我们可以这样声明并实例化一个惰性factorial 函数:

function<factorial_impl> factorial;

调用像factorial 这样的惰性函数并不会立即执行函数对象factorial_impl. 相反, 会创建一个actor 对象并返回给调用者. 示例:

factorial(arg1)

只不过返回一个 actor. 第二次函数调用将触发实际的阶乘函数. 示例:

std::cout << factorial(arg1)(4);

将输出“24”.

注意, 在某些情况下 (例如对有状态的函数对象) , 可以把多态函数对象 (Polymorphic Function Object) 模型的一个实例传给构造函数. 示例:

function<factorial_impl> factorial(ftor);

其中 ftor 是 factorial_impl 的一个实例 (在这个例子中这样做并非必需, 因为factorial_impl 不需要任何状态) .

重要

不过在使用有状态的函数对象时要当心, 因为它们经常被反复复制, 状态可能在某个副本中发生变化, 而不是在原始对象中.
