算法 

#include <boost/phoenix/stl/algorithm.hpp>

algorithm 模块为<algorithm> 和<numeric> 头文件中的标准算法提供了包装器.

这些算法分为迭代、变换和查询三类, 模拟Boost.MPL 库. 不同类别的算法可以通过以下头文件包含:

#include <boost/phoenix/stl/algorithm/iteration.hpp>
#include <boost/phoenix/stl/algorithm/transformation.hpp>
#include <boost/phoenix/stl/algorithm/querying.hpp>

algorithm 模块的函数在适当之处接受范围 (range) 作为参数. 这与标准库不同, 但很容易上手. 范围在Boost.Range 库中有详细描述.

例如, 使用标准 copy 算法在两个数组之间复制:

int array[] = {1, 2, 3};
int output[3];
std::copy(array, array + 3, output); // We have to provide iterators
                                     // to both the start and end of array

使用 phoenix algorithm 模块的类似代码是:

int array[] = {1, 2, 3};
int output[3];
copy(arg1, arg2)(array, output); // Notice only 2 arguments, the end of
                                 // array is established automatically

Boost.Range 库为标准容器、字符串和数组提供支持, 并且可以扩展以支持更多类型.
