Delete

惰性 delete…… 

#include <boost/phoenix/object/delete.hpp>

惰性地删除堆上的一个对象:

delete_(arg);

其中 arg 被假定为一个指向对象的指针.

示例:

delete_<std::string>(arg1) // note the spelling of delete_ (with trailing underscore)
