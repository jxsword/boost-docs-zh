容器 

#include <boost/phoenix/stl/container.hpp>

container 模块预定义了一组作用于 STL 容器的惰性函数. 这些函数为 STL 容器的公有成员函数提供惰性求值机制. 这些惰性函数是薄包装器, 只是简单转发到 STL 库中对应的函数.

为以下容器的所有成员函数提供了惰性函数:

  • deque
  • list
  • map
  • multimap
  • vector
  • set
  • multiset

实际上, 如果你的类的成员函数与下面列出的名称和签名相同, 那么它将自动获得支持. 概括地说, 为以下成员函数提供了惰性函数:

  • assign
  • at
  • back
  • begin
  • capacity
  • clear
  • empty
  • end
  • erase
  • front
  • get_allocator
  • insert
  • key_comp
  • max_size
  • pop_back
  • pop_front
  • push_back
  • push_front
  • rbegin
  • rend
  • reserve
  • resize
  • size
  • splice
  • value_comp

惰性函数的名称与对应的成员函数相同. 区别在于惰性函数是自由函数, 因此不使用成员“点”语法.

表 1.4 用法示例

“普通”版本

“惰性”版本

my_vector.at(5)

at(arg1, 5)

my_list.size()

size(arg1)

my_vector1.swap(my_vector2)

swap(arg1, arg2)


注意, 与 stl 算法重名的成员函数不在其中. 这些将在 Phoenix 的 algorithm 模块中提供.

这里不提供operator+=、operator[] 等的惰性版本. 这些运算符并非 STL 容器所特有, 因此其惰性版本可在运算符中找到.
