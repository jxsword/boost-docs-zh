列表生成

FC++ 最有趣的能力之一是生成只在需要时才求值的无限惰性列表. 最简单的例子是

enum_from(1)

它返回整数 1,2,3,……直到无穷的生成器.

take(4,enum_from(1))

返回该列表的前 4 个元素组成的列表.

at(enum_from(1),3)

使用从零开始的索引访问返回第四个成员. 返回的两个列表都是惰性的, 只有在访问列表成员时才被求值.
