组织

Phoenix 的设计和实现得到了精心细致的投入.

该库分为四层:

  1. Actor
  2. Value、Reference、Arguments
  3. Function、Operator、Object、Statement、Scope
  4. STL、Fusion、Bind

各模块相互正交, 没有循环依赖. 较低层不依赖较高层. 同一层中的模块不依赖同层的其他模块. 这意味着, 例如, 如果不需要 Bind, 可以完全舍弃它; 或者也可以去掉 Operator 和 Statement, 只使用 Function, 这在纯 FP 应用中可能是理想的.

库已经从最初的 Phoenix 发展壮大, 但仍然只包含头文件. 没有需要链接的目标文件.

Core

最下面两层构成核心.

Actor 是库背后的主要概念. 惰性函数被抽象为 actor.

终结符 (terminal) 提供 Phoenix 内功能的基本构件. 表达式用于把这些终结符组合起来以提供更强大的功能.

表达式由零个或多个 actor 组成. 复合体中的每个 actor 又可以是另一个表达式.

表 1.2 模块

模块

说明

函数

惰性函数支持 (例如add)

运算符

惰性运算符支持 (例如+)

语句

惰性语句 (例如if_、while_)

Object

惰性 cast (例如static_cast_) , 对象创建与销毁 (例如new_、delete_)

Scope

支持作用域、局部变量和 lambda-lambda

Bind

从自由函数、成员函数或成员变量生成惰性函数.

STL 容器

一组作用于 STL 容器和序列的预定义“惰性”函数 (例如push_back) .

STL 算法

STL 算法的一组预定义“惰性”版本 (例如find_if) .

每个模块都定义在一个同名头文件中. 例如, core 模块定义在<boost/phoenix/core.hpp> 中.
