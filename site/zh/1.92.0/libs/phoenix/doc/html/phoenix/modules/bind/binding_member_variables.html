绑定成员变量 

#include <boost/phoenix/bind/bind_member_variable.hpp>

成员变量也可以像成员函数一样绑定. 成员变量不是函数. 然而, 与充当“返回数据引用的零元函数”的ref(x) 一样, 成员变量在绑定后表现得像一个一元函数:接受指向对象的指针或引用作为其参数, 并返回对被绑定成员变量的引用. 例如, 给定:

struct xyz
{
    int v;
};

xyz::v 可以这样绑定:

bind(&xyz::v, obj) // obj is an xyz object

如前所述, 与被绑定的成员函数一样, 被绑定的成员变量同样期望第一个 (也是唯一的) 参数是指向对象的指针或引用. 对象 (引用或指针) 可以被惰性绑定. 示例:

xyz obj;
bind(&xyz::v, arg1)             // arg1.v
bind(&xyz::v, obj)              // obj.v
bind(&xyz::v, arg1)(obj) = 4    // obj.v = 4
