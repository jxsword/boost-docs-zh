值

值是函数! 示例:

val(3)
val("Hello, World")

第一个求值为一个零元函数 (不带参数的函数) , 返回一个int, 3. 第二个求值为一个零元函数, 返回一个char const(&)[13], "Hello, World".

惰性求值

困惑了? 你会说, val 是一个一元函数, 而val(3) 调用了它? 是的. 然而, 请仔细读: “求值为一个零元函数”. val(3) 求值为 (返回) 一个零元函数. 啊哈! val(3) 返回一个函数! 因此, 既然val(3) 返回一个函数, 你就可以调用它. 示例:

std::cout << val(3)() << std::endl;

(参见values.cpp)

更多关于值的内容见这里.

第二次函数调用 (不带参数的那次) 调用该零元函数, 随后返回3. 需要第二次函数调用正是该函数被称为惰性求值的原因. 第一次调用什么也不做. 你需要第二次调用才能最终对它求值. 第一次调用惰性地对该函数求值; 也就是说, 什么也不做, 把求值推迟到以后.

回调

仅看上面的例子, 可能无法立刻看出惰性求值有什么用. 把第一次和第二次函数调用放在同一行确实没有太大用处. 但是, 把val(3) 想成一个回调函数 (在大多数情况下它们实际上就是这样用的) , 问题就清楚了. 示例:

template <typename F>
void print(F f)
{
    cout << f() << endl;
}

int
main()
{
    print(val(3));
    print(val("Hello World"));
    return 0;
}

(参见callback.cpp)
