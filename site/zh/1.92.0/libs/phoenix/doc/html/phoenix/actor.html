Actor

Actor 是本库背后的核心概念. actor 是函数对象. 一个 actor 可以接受 0 到BOOST_PHOENIX_LIMIT 个参数.

注释

可以设置BOOST_PHOENIX_LIMIT, 即 actor 可接受的预定义最大元数. 默认情况下, BOOST_PHOENIX_LIMIT 被设为 10.

Phoenix 提供了一个actor 类模板, 其特化模拟了Actor 概念. actor 有一个模板参数Expr, 用于提供要求值的底层表达式.

template <typename Expr>
struct actor
{
    return_type
    operator()() const;

    template <typename T0>
    return_type
    operator()(T0& _0) const;

    template <typename T0, typename T1>
    return_type
    operator()(T0& _0, T1& _1) const;

    //...
};

actor 类通过一组函数调用运算符接受 0 到BOOST_PHOENIX_LIMIT 元的参数 (暂且不必担心细节. 例如, 注意我们对有关return_type 的细节从简处理) . 参数被传递给求值机制. 更多信息参见Inside Actors.
