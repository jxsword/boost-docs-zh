Tuple

重要

本模块仅在 C++ 14 及以上版本可用.

#include <boost/phoenix/stl/tuple.hpp>

tuple 模块提供了std::get 的惰性版本, 名为get_. 除了std::tuple (和std::pair) 之外, get_<int> 语法也可以与std::array 一起使用, get_<type> 语法可与std::variant 一起使用. 示例如下:

// using namespace boost::phoenix;
auto get_first_item = get_<0>(placeholders::arg1);
auto get_double = get_<double>(placeholders::arg1);
提示

如果为其他类型实现了get, 它们也可以被支持.

它还提供额外的占位符uarg1..uargN, 用于解包第一个参数. 这些占位符定义为:

namespace placeholders {
auto uarg1 = boost::phoenix::get_<0>(arg1);
auto uarg2 = boost::phoenix::get_<1>(arg1);
...
auto uarg10 = boost::phoenix::get_<9>(arg1);
}
