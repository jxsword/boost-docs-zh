添加一个表达式

这不是一个玩具示例. 它实际上是库的一部分. 还记得while 惰性语句吗? 把我们到目前为止学到的所有内容整合起来, 我们在此完整地 (逐字) 呈现它:

BOOST_PHOENIX_DEFINE_EXPRESSION(
    (boost)(phoenix)(while_)
  , (meta_grammar)           // Cond
    (meta_grammar)           // Do
)

namespace boost { namespace phoenix
{
    struct while_eval
    {
        typedef void result_type;

        template <typename Cond, typename Do, typename Context>
        result_type
        operator()(Cond const& cond, Do const& do_, Context & ctx) const
        {
            while(eval(cond, ctx))
            {
                eval(do_, ctx);
            }
        }
    };

    template <typename Dummy>
    struct default_actions::when<rule::while_, Dummy>
        : call<while_eval, Dummy>
    {};

    template <typename Cond>
    struct while_gen
    {
        while_gen(Cond const& cond) : cond(cond) {}

        template <typename Do>
        typename expression::while_<Cond, Do>::type const
        operator[](Do const& do_) const
        {
            return expression::while_<Cond, Do>::make(cond, do_);
        }

        Cond const& cond;
    };

    template <typename Cond>
    while_gen<Cond> const
    while_(Cond const& cond)
    {
        return while_gen<Cond>(cond);
    }
}}

while_eval 是如何求值一个表达式的一个示例. 它在rule::while 动作中被调用. while_gen 和while_ 是表达式模板的前端. 让我们把它拆开来看看发生了什么. 让我们从底部开始, 这样更容易.

当你写下:

while_(cond)

我们生成while_gen<Cond> 的一个实例, 其中Cond 是cond 的类型. cond 可以是任意复杂的 actor 表达式. while_gen 模板类有一个operator[], 可接受另一个表达式. 如果我们写下:

while_(cond)
[
    do_
]

它将生成一个类型如下的恰当复合体:

expression::while_<Cond, Do>::type

其中Cond 是cond 的类型, Do 是do_ 的类型. 注意我们在这里如何使用 Phoenix 的Expression 机制

template <typename Do>
typename expression::while_<Cond, Do>::type const
operator[](Do const& do_) const
{
    return expression::while_<Cond, Do>::make(cond, do_);
}

最后, while_eval 开始发挥作用:

while(eval(cond, ctx))
{
    eval(do_, ctx);
}

cond 和do_ 在此时刻是Actor 的实例. cond 和do_ 是作为参数传递的Actor, 由call 传入, ctx 是Context
