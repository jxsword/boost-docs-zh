参数 

#include <boost/phoenix/core/argument.hpp>

我们使用下面这个的实例:

expression::argument<N>::type

来表示第 N 个函数参数. 参数占位符充当一个虚构的数据槽 (data-bin) , 函数参数将被放到其中.

预定义参数

expression::argument<N>::type 有几个预定义实例, 名为arg1..argN, 以及它的BLL 对应形式_1.._N (其中 N 是预定义的最大值) .

下面是arg1..argN 的一些预置定义示例

namespace placeholders
{
    expression::argument<1>::type const arg1 = {};
    expression::argument<2>::type const arg2 = {};
    expression::argument<3>::type const arg3 = {};
}

以及它的BLL _1.._N 风格对应形式:

namespace placeholders
{
    expression::argument<1>::type const _1 = {};
    expression::argument<2>::type const _2 = {};
    expression::argument<3>::type const _3 = {};
}
注释

可以设置BOOST_PHOENIX_ARG_LIMIT, 即预定义的最大占位符索引. 默认情况下, BOOST_PHOENIX_ARG_LIMIT 被设为BOOST_PHOENIX_LIMIT (参见Actor) .

用户自定义参数

适当时, 你可以定义自己的argument 名称. 例如:

expression::argument<1>::type x; // note one based index

现在x 可以用作惰性函数的参数:

add(x, 6)

它等价于:

add(arg1, 6)
求值一个参数

一个参数在被求值时, 会从客户传入的参数中选出第 N 个.

例如:

char        c = 'A';
int         i = 123;
const char* s = "Hello World";

cout << arg1(c) << endl;        //  Get the 1st argument: c
cout << arg1(i, s) << endl;     //  Get the 1st argument: i
cout << arg2(i, s) << endl;     //  Get the 2nd argument: s

将输出:

A
123
Hello World
额外参数

在 C 和 C++ 中, 函数可以带有一些函数体根本不会使用的额外参数. 这些额外参数会被简单忽略.

Phoenix 也允许传入额外参数. 例如, 回想我们最初的add 函数:

add(arg1, arg2)

我们现在知道, 部分应用这个函数会得到一个期望 2 个参数的函数. 然而, 该库稍显宽容, 允许调用者提供比实际所需更多的参数. 因此, add 实际上允许 2 个或更多参数. 例如, 对于:

add(arg1, arg2)(x, y, z)

第三个参数z 会被忽略. 更进一步, 中间的参数也会被忽略. 示例:

add(arg1, arg5)(a, b, c, d, e)

这里, 参数 b、c 和 d 被忽略. 函数add 接受第一个参数 (arg1) 和第五个参数 (arg5) .

注释

强制严格元数并不可取, 原因有几个. 回调函数就是一个恰当的例子. 典型的回调函数提供的信息往往多于实际所需. lambda 函数经常用作回调.
