块语句

语法:

statement,
statement,
....
statement

基本上, 这些是用逗号分隔的语句. 注意, 与 C/C++ 的分号不同, 逗号是放在语句之间的分隔符. 这更像 Pascal 的分号分隔符, 而不是 C/C++ 的分号终结符. 例如:

statement,
statement,
statement, // ERROR!

是错误的. 最后一条语句不应带逗号. 块语句可以用圆括号分组. 同样, 组中最后一条语句不应有尾部逗号.

statement,
statement,
(
    statement,
    statement
),
statement

在方括号之外, 块语句应当被分组. 例如:

std::for_each(c.begin(), c.end(),
    (
        do_this(arg1),
        do_that(arg1)
    )
);

把逗号运算符链用一对圆括号包起来, 可以阻止它被解释为参数分隔符. 方括号运算符之所以例外, 是因为该运算符总是恰好接受一个参数, 因此它会把任何用逗号运算符链提供多个参数的企图“转换”掉 (并对零个参数的情况报错) .
