扩展 actor

Actor 是库的主要组成部分之一, 也是众多定制点之一. 默认的 actor 实现提供了若干 operator() 重载, 用于处理表达式的求值.

对某些用例而言这可能还不够. 为了方便, 可以考虑提供自定义成员函数来生成新表达式. if_else_ 语句就是一个例子, 它提供了一个额外的 else 成员, 用于生成惰性的 if-else 表达式. 这样一来, 实际的 Phoenix 表达式更具表现力.

另一种场景是赋予 actor 某个众所周知接口或概念的语义. 本教程式的一节将介绍如何实现一个自定义 actor, 使其可以像STL 容器一样使用.

要求

让我们重申一下我们想要的东西:

表达式

语义

a.begin()

返回指向容器中第一个元素的迭代器.

a.end()

返回指向容器中最后一个元素之后位置的迭代器.

a.size()

返回容器的大小, 即其中元素的数量.

a.max_size()

返回该容器可能具有的最大容量.

a.empty()

等价于 a.size() == 0. (但可能更快. )

a.swap(b)

等价于 swap(a,b)

此外, 我们还想要常规 actor 的全部 operator() 重载.

定义 actor

我们的container_actor 接口的第一个版本将展示总体原理. 它将被不断扩展. 为简单起见, 每个成员函数生成器起初都返回nothing.

template <typename Expr>
struct container_actor
	: actor<Expr>
{
	typedef actor<Expr> base_type;
	typedef container_actor<Expr> that_type;
	
	container_actor( base_type const& base )
		: base_type( base ) {}

	expression::null<mpl::void_>::type const begin() const { return nothing; }
	expression::null<mpl::void_>::type const end() const { return nothing; }
	expression::null<mpl::void_>::type const size() const { return nothing; }
	expression::null<mpl::void_>::type const max_size() const { return nothing; }
	expression::null<mpl::void_>::type const empty() const { return nothing; }

	// Note that swap is the only function needing another container.
	template <typename Container>
	expression::null<mpl::void_>::type const swap( actor<Container> const& ) const { return nothing; }
};
使用 actor

虽然这些成员函数现在什么也不做, 我们想测试一下能否使用我们的新 actor.

首先, 让我们创建一个生成器, 把container_actor 包装到任何其他表达式之外:

template <typename Expr>
container_actor<Expr> const
container( actor<Expr> const& expr )
{
    return expr;
}

现在让我们测试一下:

std::vector<int> v;
v.push_back(0);
v.push_back(1);
v.push_back(2);
v.push_back(3);

(container(arg1).size())(v);

诚然, 这并不优雅, 也不太实用 (我们本可以直接使用Phoenix 算法模块中的 phoenix::begin(v), 但我们可以做得更好.

让我们拥有一个可以像 STL 容器那样使用的参数占位符:

container_actor<expression::argument<1>::type> const con1;
// and so on ...

上面的示例可以改写为:

std::vector<int> v;
v.push_back(0);
v.push_back(1);
v.push_back(2);
v.push_back(3);

(con1.size())(v);

哇, 真简单!

为 actor 注入生命力

这个会更简单!

首先, 我们定义一个惰性函数, 用于对我们想实现的表达式求值. 下面是 size 函数的实现:

struct size_impl
{
	// result_of protocol:
	template <typename Sig>
	struct result;

	template <typename This, typename Container>
	struct result<This(Container)>
	{
		// Note, remove reference here, because Container can be anything
		typedef typename boost::remove_reference<Container>::type container_type;

		// The result will be size_type
		typedef typename container_type::size_type type;
	};

	template <typename Container>
	typename result<size_impl(Container const&)>::type
	operator()(Container const& container) const
	{
		return container.size();
	}
};

很好, 这是第一部分. 第二部分是实现container_actor 的 size 成员函数:

template <typename Expr>
struct container_actor
	: actor<Expr>
{
	typedef actor<Expr> base_type;
	typedef container_actor<Expr> that_type;
	
	container_actor( base_type const& base )
		: base_type( base ) {}

	typename expression::function<size_impl, that_type>::type const
	size() const
	{
		function<size_impl> const f = size_impl();
		return f(*this);
	}

	// the rest ...
};
