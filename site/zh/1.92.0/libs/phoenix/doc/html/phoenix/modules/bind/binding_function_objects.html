绑定函数对象 

#include <boost/phoenix/bind/bind_function_object.hpp>

绑定函数对象有两个目的: * 部分函数应用 * 快速适配已存在的函数对象

为了推导函数对象的返回类型, 它必须实现Boost.Result Of 协议. 如果被绑定的函数对象是多态的, 得到的绑定对象也是多态的.
