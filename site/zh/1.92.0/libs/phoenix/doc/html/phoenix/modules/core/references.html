#include <boost/phoenix/core/reference.hpp>

值是不可变常量. 试图修改一个值将导致编译期错误. 当我们希望函数修改参数时, 应改用引用. 例如, 设想一个惰性函数add_assign:

void add_assign(T& x, T y) { x += y; } // pseudo code

这里, 我们希望第一个函数参数 x 是可变的. 显然, 我们不能这样写:

add_assign(1, 2) // error first argument is immutable

在 C++ 中, 我们可以在上面示例的第一个参数处传入对变量的引用. 然而, 默认情况下, 该库强制要求传给部分应用函数的参数是不可变值 (参见值) . 为实现我们的意图, 我们使用:

expression::reference<T>::type

这与前面的expression::value<T>::type 类似, 但它保存的是对变量的引用.

我们通常不直接实例化expression::reference<T>::type 对象, 而是使用:

ref(v)

例如 (其中i 是一个int 变量) :

add_assign(ref(i), 2)
求值一个引用

引用是 actor. 因此, 引用可以被求值. 这种调用给出该引用的标识. 示例:

int i = 3;
char const* s = "Hello World";
cout << ref(i)() << ref(s)();

输出“3 Hello World”

常量引用

另一个自由函数

cref(cv)

也可以使用. cref(cv) 创建一个expression::reference<T const>::type 对象. 它与expression::value<T>::type 类似, 但当要作为参数传给函数的数据体积大、按值复制代价高昂时, cref(cv) 提供了一种更轻量的替代方案.
