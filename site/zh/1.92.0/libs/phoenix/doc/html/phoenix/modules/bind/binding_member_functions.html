绑定成员函数 

#include <boost/phoenix/bind/bind_member_function.hpp>

绑定成员函数的方式类似. 被绑定的成员函数以指向对象的指针或引用作为第一个参数. 例如, 给定:

struct xyz
{
    void foo(int) const;
};

xyz 的foo 成员函数可以这样绑定:

bind(&xyz::foo, obj, arg1) // obj is an xyz object

注意, 惰性成员函数期望第一个参数是指向对象的指针或引用. 对象 (引用或指针) 与参数都可以被惰性绑定. 示例:

xyz obj;
bind(&xyz::foo, arg1, arg2)     // arg1.foo(arg2)
bind(&xyz::foo, obj, arg1)      // obj.foo(arg1)
bind(&xyz::foo, obj, 100)       // obj.foo(100)
