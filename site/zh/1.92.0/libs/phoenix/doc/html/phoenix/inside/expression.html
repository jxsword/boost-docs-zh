Phoenix 表达式

样板宏

Phoenix 表达式是Proto 表达式 (Proto Expression) 概念的一个模型. 这些表达式被包装在Actor 模板内. actor 提供对表达式求值的函数调用运算符. actor 是围绕 Phoenix 表达式的领域特定包装器.

按照设计, Phoenix 表达式不携带任何关于它们将来如何被求值的信息. 它们是Actions 将要处理的数据结构.

库提供了一个便捷模板来定义表达式:

template <template <typename> Actor, typename Tag, typename A0, ..., typename A1>
struct expr_ext
    : proto::transform<expr_ext<Actor, Tag, A0, ..., A1> >
{
    typedef unspecified base_expr;
    typedef Actor<base_expr> type;

    typedef unspecified proto_grammar;

    static type make(A0 a0, ..., A1 a1);
};

template <typename Tag, typename A0, ..., typename A1>
struct expr : expr_ext<actor, Tag, A0, ..., A1> {};

记法

A0...AN

子节点类型

a0...aN

子节点对象

G0...GN

Boost.Proto 文法类型

表达式语义

表达式

语义

expr<Tag, A0...AN>::type

具有标签Tag 和A0...AN 个子节点的 Expression 的类型

expr<Tag, G0...GN>

一个Boost.Proto 文法和Proto 直通变换 (Pass Through Transform)

expr<Tag, A0...AN>::make(a0...aN)

返回一个 Phoenix 表达式
注释

你可能已经注意到模板模板参数Actor 被用在expr_ext 中. 它可以是由用户提供的自定义 Actor, 添加除默认actor 模板之外的其他成员函数或对象. 更多细节见扩展 actor.

meta_grammar

定义表达式只是使其成为有效 Phoenix 表达式的一部分. 为了在 Phoenix 域中使用这些表达式, 我们需要把它们“注册”到我们的文法中.

meta_grammar 正是为此目的而设的一个 struct. 它是一个可开放扩展的Boost.Proto 文法:

struct meta_grammar
    : proto::switch_<meta_grammar>
{
    template <typename Tag, typename Dummy>
    struct case_
        : proto::not_<proto::_>
    {};
};

如你所见, 默认情况下meta_grammar 什么也不匹配. 每包含一个模块, 这个文法就会被各种表达式扩展.

示例

定义一个表达式:

template <typename Lhs, typename Rhs>
struct plus
    : expr<proto::tag::plus, Lhs, Rhs>
{};

并把它加入文法:

template <>
struct meta_grammar::case_<proto::tag::plus>
    : enable_rule<
        plus<
            meta_grammar
          , meta_grammar
        >
    >
{};

定义一个生成器函数, 让我们潜在用户的生活更轻松:

template <typename Lhs, typename Rhs>
typename plus<Lhs, Rhs>::type
plus(Lhs const & lhs, Rhs const & rhs)
{
    return expression::plus<Lhs, Rhs>::make(lhs, rhs);
}

看看它是否真的有效:

plus(6, 5)();

返回 11!

proto::display_expr(plus(5, 6));

输出:

plus(
    terminal(6)
  , terminal(5)
)

完整示例见define_expression.cpp.

注释

这里展示的示例之所以有效, 是因为default_actions 知道如何处理具有proto::tag::plus 和两个子节点的表达式. 这是因为default_actions 使用proto::_default<meta_grammar> 变换来对运算符和函数求值. 更多关于动作的内容见这里.
