局部变量 

#include <boost/phoenix/scope/local_variable.hpp>

我们使用下面这个的实例:

expression::local_variable<Key>::type

来表示一个局部变量. 局部变量充当一个虚构的数据槽, 基于栈的局部数据将放在其中. Key 是用于标识该局部变量的任意类型. 示例:

struct size_key;
expression::local_variable<size_key>::type size;

预定义局部变量

expression::local_variable<Key>::type 有几个预定义实例, 名为_a.._z, 你已经可以直接使用. 要使用它们, 只需使用namespace boost::phoenix::local_names:

using namespace boost::phoenix::local_names;
