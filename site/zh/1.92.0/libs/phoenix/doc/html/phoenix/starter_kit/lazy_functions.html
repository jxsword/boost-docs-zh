惰性函数

随着你编写更多 lambda 函数, 你会注意到某些模式, 希望把它们重构为可复用的函数. 到了那个时候, 你会希望普通函数能与 phoenix 函数共存. 遗憾的是, 普通 C++ 函数的立即本性使它们不兼容.

惰性函数是你的朋友. 该库提供了制作惰性函数的设施. 下面的代码是使用该设施重写的is_odd 函数:

struct is_odd_impl
{
    typedef bool result_type;

    template <typename Arg>
    bool operator()(Arg arg1) const
    {
        return arg1 % 2 == 1;
    }
};

function<is_odd_impl> is_odd;
注意事项:
  • 结果类型推导借助 result_of 协议实现. 更多信息参见Boost.Result Of
  • is_odd_impl 实现该函数.
  • is_odd 是function<is_odd_impl> 的一个实例, 它就是那个惰性函数.

现在, is_odd 是一个真正的惰性函数, 可以与 phoenix 的其余部分配合使用. 示例:

std::find_if(c.begin(), c.end(), is_odd(arg1));

(参见function.cpp)

预定义惰性函数

该库满满都是涵盖全部 STL 容器、迭代器和算法的 STL 感知预定义惰性函数. 例如, 容器相关操作有惰性版本, 如 assign、at、back、begin、pop_back、pop_front、push_back、push_front 等 (参见STL) .
