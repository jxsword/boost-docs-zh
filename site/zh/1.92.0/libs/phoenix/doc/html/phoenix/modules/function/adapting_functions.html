函数适配

BOOST_PHOENIX_ADAPT_FUNCTION_NULLARY
BOOST_PHOENIX_ADAPT_FUNCTION
BOOST_PHOENIX_ADAPT_CALLABLE_NULLARY
BOOST_PHOENIX_ADAPT_CALLABLE

如果想适配已存在的函数或函数对象, 这将成为重复性工作. 因此, 提供了以下样板宏来帮助你适配已有函数, 从而减少对phoenix.modules.bind 函数的需求.

BOOST_PHOENIX_ADAPT_FUNCTION_NULLARY
说明

BOOST_PHOENIX_ADAPT_FUNCTION_NULLARY 是一个宏, 可用于生成使任意零元函数成为惰性函数所需的全部样板代码.

注释

这些宏不会生成全局对象. 得到的惰性函数是真正的函数, 会创建惰性函数表达式对象

概要 
BOOST_PHOENIX_ADAPT_FUNCTION_NULLARY(
    RETURN_TYPE
  , LAZY_FUNCTION
  , FUNCTION
)
语义

上面的宏生成全部必要的代码, 得到一个零元惰性函数LAZY_FUNCTION, 它调用零元函数FUNCTION, 后者返回类型为RETURN_TYPE

头文件 
#include <boost/phoenix/function/adapt_function.hpp>
示例 
namespace demo
{
    int foo()
    {
        return 42;
    }
}

BOOST_PHOENIX_ADAPT_FUNCTION_NULLARY(int, foo, demo::foo)

int main()
{
    using boost::phoenix::placeholders::_1;

    assert((_1 + foo())(1) == 43);
}
BOOST_PHOENIX_ADAPT_FUNCTION
说明

BOOST_PHOENIX_ADAPT_FUNCTION 是一个宏, 可用于生成使任意函数成为惰性函数所需的全部样板代码.

概要 
BOOST_PHOENIX_ADAPT_FUNCTION(
    RETURN_TYPE
  , LAZY_FUNCTION
  , FUNCTION
  , FUNCTION_ARITY
)
语义

上面的宏生成全部必要的代码, 得到一个惰性函数LAZY_FUNCTION, 它调用FUNCTION, 后者返回类型为RETURN_TYPE、参数个数为FUNCTION_ARITY.

头文件 
#include <boost/phoenix/function/adapt_function.hpp>
示例 
namespace demo
{
    int plus(int a, int b)
    {
        return a + b;
    }

    template <typename T>
    T
    plus(T a, T b, T c)
    {
        return a + b + c;
    }
}

BOOST_PHOENIX_ADAPT_FUNCTION(int, plus, demo::plus, 2)

BOOST_PHOENIX_ADAPT_FUNCTION(
    typename remove_reference<A0>::type
  , plus
  , demo::plus
  , 3
)

int main()
{
    using boost::phoenix::arg_names::arg1;
    using boost::phoenix::arg_names::arg2;

    int a = 123;
    int b = 256;

    assert(plus(arg1, arg2)(a, b) == a+b);
    assert(plus(arg1, arg2, 3)(a, b) == a+b+3);
}
BOOST_PHOENIX_ADAPT_CALLABLE_NULLARY
说明

BOOST_PHOENIX_ADAPT_CALLABLE_NULLARY 是一个宏, 可用于生成使任意零元函数对象成为惰性函数所需的全部样板代码.

概要 
BOOST_PHOENIX_ADAPT_CALLABLE_NULLARY(
    LAZY_FUNCTION
  , CALLABLE
)
语义

上面的宏生成全部必要的代码以创建LAZY_FUNCTION, 后者创建一个表示对CALLABLE 的零元调用的惰性函数对象. 返回类型由CALLABLE 指定, 符合Boost.Result Of 协议.

头文件 
#include <boost/phoenix/function/adapt_callable.hpp>
示例 
namespace demo
{
    struct foo
    {
        typedef int result_type;

        result_type operator()() const
        {
            return 42;
        }
    }
}

BOOST_PHOENIX_ADAPT_CALLABLE_NULLARY(foo, demo::foo)

int main()
{
    using boost::phoenix::placeholders::_1;

    assert((_1 + foo())(1) == 43);
}
BOOST_PHOENIX_ADAPT_CALLABLE
说明

BOOST_PHOENIX_ADAPT_CALLABLE 是一个宏, 可用于生成使任意函数对象成为惰性函数所需的全部样板代码.

概要 
BOOST_PHOENIX_ADAPT_CALLABLE(
    LAZY_FUNCTION
  , FUNCTION_NAME
  , FUNCTION_ARITY
)
语义

上面的宏生成全部必要的代码以创建LAZY_FUNCTION, 后者创建一个表示对CALLABLE 的带FUNCTION_ARITY 个参数调用的惰性函数对象. 返回类型由CALLABLE 指定, 符合Boost.Result Of 协议.

头文件 
#include <boost/phoenix/function/adapt_callable.hpp>
示例 
namespace demo
{
    struct plus
    {
        template <typename Sig>
        struct result;

        template <typename This, typename A0, typename A1>
        struct result<This(A0, A1)>
            : remove_reference<A0>
        {};

        template <typename This, typename A0, typename A1, typename A2>
        struct result<This(A0, A1, A2)>
            : remove_reference<A0>
        {};

        template <typename A0, typename A1>
        A0 operator()(A0 const & a0, A1 const & a1) const
        {
            return a0 + a1;
        }

        template <typename A0, typename A1, typename A2>
        A0 operator()(A0 const & a0, A1 const & a1, A2 const & a2) const
        {
            return a0 + a1 + a2;
        }
    };
}

BOOST_PHOENIX_ADAPT_CALLABLE(plus, demo::plus, 2)

BOOST_PHOENIX_ADAPT_CALLABLE(plus, demo::plus, 3)

int main()
{
    using boost::phoenix::arg_names::arg1;
    using boost::phoenix::arg_names::arg2;

    int a = 123;
    int b = 256;

    assert(plus(arg1, arg2)(a, b) == a+b);
    assert(plus(arg1, arg2, 3)(a, b) == a+b+3);
}
