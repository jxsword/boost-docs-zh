while_ 语句 

#include <boost/phoenix/statement/while.hpp>

语法是:

while_(conditional_expression)
[
    sequenced_statements
]

示例:这段代码将每个元素递减直至为零, 并在每一步打印出该数值. 换行符终结每个值的打印.

std::for_each(c.begin(), c.end(),
    (
        while_(arg1--)
        [
            cout << arg1 << ", "
        ],
        cout << val("\n")
    )
);
