惰性语句

惰性语句? 当然有. 我们都知道并喜爱的 C++ 语句都有惰性版本. 例如:

if_(arg1 > 5)
[
    std::cout << arg1
]

比如说, 我们希望打印 vector 中所有大于 5 的元素 (用逗号分隔) . 可以这样写:

std::for_each(v.begin(), v.end(),
    if_(arg1 > 5)
    [
        std::cout << arg1 << ", "
    ]
);

(参见if.cpp)
