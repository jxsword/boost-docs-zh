运算符 

#include <boost/phoenix/operator.hpp>

该设施提供了一种对运算符进行惰性求值的机制. 从语法上看, 惰性运算符的样子和感觉就像普通的 C/C++ 中缀、前缀或后缀运算符. 运算符的应用看起来也一样. 但与普通运算符不同, 实际的运算符执行被延迟了. 示例:

arg1 + arg2
1 + arg1 * arg2
1 / -arg1
arg1 < 150

我们已经见过惰性运算符的实际运作 (参见快速入门 - 惰性运算符) . 让我们回过头来再仔细考察一下:

std::find_if(c.begin(), c.end(), arg1 % 2 == 1)

通过运算符重载, 表达式arg1 % 2 == 1 实际上会生成一个 actor. 这个 actor 对象被传递给 STL 的find_if 函数. 从 STL 的角度看, 该表达式只是一个函数对象, 期望单个类型为容器 value_type 的参数. 对c 中的每个元素, 该元素都作为参数arg1 传递给 actor (函数对象) . actor 根据表达式arg1 % 2 == 1 (其中 arg1 被容器的元素替换) 检查它是否为奇数值.

与惰性函数一样 (参见Function) , 惰性运算符在被调用时不会立即执行. 相反, 会创建一个 actor (参见Actor) 对象并返回给调用者. 示例:

(arg1 + arg2) * arg3

只不过返回一个 actor. 第二次函数调用才会对实际的运算符求值. 示例:

std::cout << ((arg1 + arg2) * arg3)(4, 5, 6);

将输出“54”.

运算符表达式的惰性求值遵循四条简单规则:

  1. 二元运算符 (->* 除外) 在其操作数中至少有一个是 actor 对象 (参见Actor) 时会被惰性求值.
  2. 一元运算符在其参数是 actor 对象时被惰性求值.
  3. 运算符->* 在其左侧参数是 actor 对象时被惰性求值.
  4. 惰性运算符的结果是一个 actor 对象, 它又可以继续应用规则 1、2 和 3.

例如, 要检查下面的表达式是否被惰性求值:

-(arg1 + 3 + 6)
  1. 根据规则 1, arg1 + 3 被惰性求值, 因为arg1 是一个 actor (参见参数) .
  2. 根据规则 4, 该arg1 + 3 表达式的结果是一个 actor 对象.
  3. 继续, arg1 + 3 + 6 再次被惰性求值. 依据规则 2.
  4. 再次依据规则 4, arg1 + 3 + 6 的结果是一个 actor 对象.
  5. 由于arg1 + 3 + 6 是一个 actor, -(arg1 + 3 + 6) 被惰性求值. 依据规则 2.

惰性运算符的应用具有高度“传染性”. 在大多数情况下, 单个argN actor 会感染一个组 (第一层或括号括起的表达式) 内所有紧邻的邻居.

注意, 任何运算符的至少一个操作数必须是有效的 actor, 惰性求值才能生效. 要强制对普通表达式进行惰性求值, 我们可以使用ref(x)、val(x) 或cref(x) 把操作数转换为有效的 actor 对象 (参见Core) . 例如:

1 << 3;      // Immediately evaluated
val(1) << 3; // Lazily evaluated

三元运算符 
if_else(c, a, b)

三元运算符值得特别一提. 由于 C++ 不允许我们重载条件表达式: c ? a : b, 为此提供了 if_else 伪函数. 其行为完全一致, 只是以惰性方式进行.

成员指针运算符 
a->*member_object_pointer
a->*member_function_pointer

成员指针运算符的左侧必须是一个返回指针类型的 actor. 其右侧可以是指向成员对象的指针, 也可以是指向成员函数的指针.

如果右侧是成员对象指针, 结果是一个 actor, 在求值时返回对该成员的引用. 例如:

struct A
{
    int member;
};

A* a = new A;
...

(arg1->*&A::member)(a); // returns member a->member

如果右侧是成员函数指针, 结果是一个 actor, 在被调用时调用指定的成员函数. 例如:

struct A
{
    int func(int);
};

A* a = new A;
int i = 0;

(arg1->*&A::func)(arg2)(a, i); // returns a->func(i)
