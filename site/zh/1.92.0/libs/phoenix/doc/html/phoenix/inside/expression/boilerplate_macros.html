样板宏

BOOST_PHOENIX_DEFINE_EXPRESSION
BOOST_PHOENIX_DEFINE_EXPRESSION_VARARG
BOOST_PHOENIX_DEFINE_EXPRESSION_EXT
BOOST_PHOENIX_DEFINE_EXPRESSION_EXT_VARARG

当表达式越来越多时, 你会意识到这是一项非常重复的工作. Phoenix 提供了一些样板宏, 让定义 Phoenix 表达式 (如上一节所示) 变得轻而易举.

BOOST_PHOENIX_DEFINE_EXPRESSION
说明

BOOST_PHOENIX_DEFINE_EXPRESSION 是一个宏, 可用于生成创建 Phoenix 表达式所需的全部样板代码

概要 
BOOST_PHOENIX_DEFINE_EXPRESSION(
    (namespace_seq)(name)
  , (child_grammar0)
    (child_grammar1)
    ...
)
语义

上面的宏为表达式name 生成必要的代码, 位于命名空间namespace_seq 中. (child_grammarN) 序列声明该表达式将有多少个子节点以及它们匹配什么proto::grammar.

该宏应在全局作用域使用. namespace_seq 应为命名空间序列, 下列符号将定义于其下:

namespace tag
{
    struct name;
}

namespace expression
{
    template <typename A0, typename A1 ... typename AN>
    struct name
        : boost::phoenix::expr<
            tag::name
          , A0
          , A1
            ...
          , AN
        >
}

namespace rule
{
    struct name
        : boost::phoenix::expr<
            child_grammar0
          , child_grammar1
            ...
          , child_grammarN
        >
    {};
}

namespace functional
{
    struct make_name; // A polymorphic function object that can be called to create the expression node
}

namespace result_of
{
    template <typename A0, typename A1 ... typename AN>
    struct make_name; // The result type of the expression node
}

// convenience polymorphic function to create an expression node
template <typename A0, typename A1 ... typename AN>
result_of::make_name<A0, A1 ... AN>
make_name(A0 const & a0, A1 const & a1 ... AN const & an);

这个宏还会为meta_grammar::case_<tag::name> 添加一个特化, 使该规则可以在动作中进一步使用.

头文件 
#include <boost/phoenix/core/expression.hpp>
示例

上一节的示例可以改写为:

BOOST_PHOENIX_DEFINE_EXPRESSION(
    (plus)
  , (meta_grammar)               // Lhs
    (meta_grammar)               // Rhs
)

template <typename Lhs, typename Rhs>
typename plus<Lhs, Rhs>::type
plus(Lhs const & lhs, Rhs const & rhs)
{
    return expression::plus<Lhs, Rhs>::make(lhs, rhs);
}
BOOST_PHOENIX_DEFINE_EXPRESSION_VARARG
说明

BOOST_PHOENIX_DEFINE_EXPRESSION_VARARG 是一个宏, 可用于生成创建 Phoenix 表达式所需的全部样板代码

概要 
BOOST_PHOENIX_DEFINE_EXPRESSION_VARARG(
    (namespace_seq)(name)
  , (child_grammar0)
    (child_grammar1)
    ...
    (child_grammarN)
  , N
)
语义

上面的宏为表达式name 生成必要的代码, 位于命名空间namespace_seq 中. N 是可变子节点数的最大值. 文法序列中除最后一个元素外的所有元素都是该表达式的必需子节点, 最后一个元素表示数量可变的子节点. 因此, 这类表达式可容纳的子节点数为N-1 加上该序列的大小

该宏应在全局作用域使用. namespace_seq 应为命名空间序列, 下列符号将定义于其下:

namespace tag
{
    struct name;
}

namespace expression
{
    template <typename A0, typename A1 ... typename AN>
    struct name
        : boost::phoenix::expr<
            tag::name
          , A0
          , A1
            ...
          , AN
        >
    {};
}

namespace rule
{
    struct name
        : expression::name<
            child_grammar0
          , child_grammar1
            ...
          , proto::vararg<child_grammarN>
        >
    {};
}

namespace functional
{
    struct make_name; // A polymorphic function object that can be called to create the expression node
}

namespace result_of
{
    template <typename A0, typename A1 ... typename AN>
    struct make_name; // The result type of the expression node
}

// convenience polymorphic function to create an expression node
template <typename A0, typename A1 ... typename AN>
result_of::make_name<A0, A1 ... AN>
make_name(A0 const & a0, A1 const & a1 ... AN const & an);

这个宏还会为meta_grammar::case_<tag::name> 添加一个特化, 使该规则可以在动作中进一步使用.

头文件 
#include <boost/phoenix/core/expression.hpp>
示例 
BOOST_PHOENIX_DEFINE_EXPRESSION_VARARG(
    (boost)(phoenix)(mem_fun_ptr)
  , (meta_grammar)                // Pointer to Object
    (meta_grammar)                // Member pointer
    (meta_grammar)                // Variable number of arguments
  , BOOST_PHOENIX_LIMIT
)

这定义了运算符中描述的成员函数指针运算符表达式.

BOOST_PHOENIX_DEFINE_EXPRESSION_EXT
说明

BOOST_PHOENIX_DEFINE_EXPRESSION_EXT 是一个宏, 可用于生成创建 Phoenix 表达式所需的全部样板代码

概要 
BOOST_PHOENIX_DEFINE_EXPRESSION_EXT(
    actor
  , (namespace_seq)(name)
  , (child_grammar0)
    (child_grammar1)
    ...
    (child_grammarN)
  , N
)
语义

上面的宏为表达式name 生成必要的代码, 位于命名空间namespace_seq 中. (child_grammarN) 序列声明该表达式将有多少个子节点以及它们匹配什么proto::grammar.

namespace tag

namespace expression
{
    template <typename A0, typename A1 ... typename AN>
    struct name
        : boost::phoenix::expr_ext<
            actor
          , tag::name
          , A0
          , A1
            ...
          , AN
        >
}

namespace rule
{
    struct name
        : boost::phoenix::expr<
            child_grammar0
          , child_grammar1
            ...
          , child_grammarN
        >
    {};
}

namespace functional
{
    struct make_name; // A polymorphic function object that can be called to create the expression node
}

namespace result_of
{
    template <typename A0, typename A1 ... typename AN>
    struct make_name; // The result type of the expression node

template <typename A0, typename A1 ... typename AN>
result_of::make_name<A0, A1 ... AN>
make_name(A0 const & a0, A1 const & a1 ... AN const & an);

这个宏还会为meta_grammar::case_<tag::name> 添加一个特化, 使该规则可以在动作中进一步使用.

头文件 
#include <boost/phoenix/core/expression.hpp>
示例 
BOOST_PHOENIX_DEFINE_EXPRESSION_EXT(
    if_actor
  , (boost)(phoenix)(if_)
  , (meta_grammar) // Cond
    (meta_grammar) // Then
)

这定义了 if_ 表达式. 自定义 actor 将else_ 定义为一个成员.
