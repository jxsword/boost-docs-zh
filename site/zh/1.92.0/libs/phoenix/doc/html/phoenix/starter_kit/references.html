引用是函数. 它们保存着对存储在某处的值的引用. 例如, 给定:

int i = 3;
char const* s = "Hello World";

我们这样创建references 到i 和s:

ref(i)
ref(s)

与val 一样, 上面的表达式求值为零元函数; 第一个返回一个int&, 第二个返回一个char const*&.
