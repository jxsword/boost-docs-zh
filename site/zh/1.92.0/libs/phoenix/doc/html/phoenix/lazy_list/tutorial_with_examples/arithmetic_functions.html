算术函数

假设有如下值

int a = 123;
int b = 256;

以下都是返回 a+b 的有效表达式

plus(arg1, arg2)(a, b)
plus(arg1, b)(a)
plus(a, arg2)(a,b)
plus(a, arg1)(b)
plus(a, b)()

这些表达式可以像这样组合

plus(minus(a, b),b)()
plus(minus(arg1, b),b)(a)
plus(minus(arg1, arg2),b)(a,b)
plus(minus(arg1, arg2),arg2)(a,b)

其他数值运算符可以这样使用

multiplies(arg1,arg2)(3,6)
divides(arg2,arg1)(3,6)
modulus(arg2,arg1)(4,6)
min(arg1,arg2)(4,6)
max(arg1,arg2)(4,6)
inc(arg1)(a)
dec(arg1)(a)
negate(arg1)(a)
