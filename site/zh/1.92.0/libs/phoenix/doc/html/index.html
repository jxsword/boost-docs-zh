前言

函数式编程之所以如此称呼, 是因为程序完全由函数构成. 主程序本身也被写成一个函数, 它接收程序的输入作为参数, 并交付程序的输出作为结果. 通常, 主函数由其他函数定义, 而这些函数又由更多的函数定义, 如此层层深入, 直到最底层的函数是语言原语.

John Hughes——函数式编程为何重要 (Why Functional Programming Matters)

说明

Phoenix 让 C++ 具备函数式编程 (FP) 能力. Phoenix 的设计与实现深受 Yannis Smaragdakis 和 Brian McNamara 的FC++以及 Jaakko Jaarvi 和 Gary Powell 的BLL (Boost Lambda Library) 的影响. Phoenix 融合了 FC++ 与 BLL, 并采用了Spirit 内联解析器所使用的实现技术.

Phoenix 是一个仅头文件库. 其设计具有极强的模块化:可以只提取并使用整个库的一个小子集——字面意义上把库拆成小片使用——而不必担心这些碎片无法工作. 库被组织成高度独立的模块和层次.

如何使用本手册

Phoenix 库按逻辑模块组织. 本文档为库中的每个模块提供用户指南和参考. 一个简单清晰的代码示例胜过百行文档; 因此, 用户指南配有大量示例, 并逐步加以注解和解释. 用户指南以示例为基础:而且数量众多.

在每个模块的用户手册部分, 我们尽可能避免前向引用信息 (即引用尚未讨论过的特定内容) . 不过在许多情况下, 把高级但相关的主题穿插在正常讨论流程中在所难免. 为缓解这一问题, 归类为“高级”的主题在初读时可以跳过.
