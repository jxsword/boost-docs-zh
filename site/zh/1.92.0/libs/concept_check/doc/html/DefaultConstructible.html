概念 DefaultConstructible

可默认构造

说明

DefaultConstructible 对象只需具有默认构造函数.

记法

X
在 DefaultConstructible 概念中扮演 default-constructible-type 角色的类型.

有效表达式

名称 表达式 类型 语义

构造

X()

X

以默认参数构造该类型的一个实例.

模型

  • int
  • std::vector<double>
