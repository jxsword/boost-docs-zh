概念 BidirectionalIterator

BidirectionalIterator

说明

双向迭代器是一种能够顺次读取一序列值的迭代器. 它可以在序列中沿任一方向移动, 并且既可以是可变的 (其所指向的数据可以被修改), 也可以是不可变的.

迭代器表示序列中的一个位置. 因此, 迭代器可以指向序列内部 (解引用时返回一个值, 并且可以递增), 也可以处于尾后位置 (off-the-end) (既不可解引用也不可递增).

复杂度

所有迭代器操作都必须具有摊还常量时间复杂度.

不变式

前置递减必须返回对象

&i = &(--i)

序列中的唯一路径

i == j 蕴含 --i == --j

递增与递减互为逆操作

++i; --i; 与 --i; ++i; 执行后必须使 i 的值保持不变, 条件是 i 该对操作均有效.
