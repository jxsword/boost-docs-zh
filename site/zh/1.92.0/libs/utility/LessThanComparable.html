LessThanComparable

说明

如果一个类型是有序的, 即能够使用 operator< 比较该类型的两个对象, 且 operator< 是严格弱序关系, 那么该类型是 LessThanComparable 的.

细化自

关联类型

记法

X 是 LessThanComparable 概念的模型的类型
x, y, z 类型为 X

定义

考虑关系 !(x < y) && !(y < x). 若该关系可传递 (即 !(x < y) && !(y < x) && !(y < z) && !(z < y) 蕴含 !(x < z) && !(z < x)), 则它满足等价关系的数学定义. 此时, operator< 是 严格弱序.

若 operator< 是严格弱序, 且每个等价类只含单个元素, 则 operator< 是 全序.

不变式

反自反性 x < x 必须为假.
反对称性 x < y 蕴含 !(y < x) [2]
传递性 x < y 与 y < z 蕴含 x < z [3]

模型

  • int

注释

[1] 只有 operator< 是基本的; 其余不等式运算符本质上是语法糖.

[2] 反对称性是一条定理而非公理: 它由反自反性与传递性推出.

[3] 由于反自反性与传递性, operator< 总是满足 偏序 的定义. 严格弱序 的定义更为严格, 而 全序 的定义还要更严格.
