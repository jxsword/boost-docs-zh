Collection

说明

Collection 是一个 概念, 与 STL Container 概念相似. Collection 提供访问一段元素的迭代器, 并提供关于 Collection 中元素数量的信息. 但 Collection 的要求比 Container 少. 提出 Collection 概念的动机是: 有许多有用的类容器类型并不满足 Container 的全部要求, 而许多算法用这组精简的要求即可编写. 要求的精简归纳如下:

  • 不要求 "拥有" 其元素: Collection 中元素的生存期不必与 Collection 对象的生存期一致, 但元素的生存期应覆盖 Collection 对象的生存期.
  • 复制 Collection 对象的语义未作定义 (可能是深拷贝或浅拷贝, 甚至可能不支持复制).
  • Collection 的关联引用类型不必是真正的 C++ 引用.
由于要求精简, 编写面向所有 Collection 类型的泛型代码时必须多加小心. 特别是, Collection 对象应按引用传递, 因为不能对其拷贝构造函数的行为作任何假定.

关联类型

值类型 X::value_type 存储在 Collection 中的对象的类型. 若 Collection 是 可变的, 则值类型必须满足 Assignable; 否则值类型必须满足 CopyConstructible.
Iterator type X::iterator 用于遍历 Collection 元素的迭代器类型. 迭代器的值类型应为 Collection 的值类型. 迭代器类型到 const 迭代器类型的转换必须存在. 迭代器类型必须是 InputIterator.
Const iterator type X::const_iterator 一种可用于检查但不能修改 Collection 元素的迭代器类型.
引用类型 X::reference 行为类似于指向 Collection 值类型的引用的类型. [1]
常量引用类型 X::const_reference 行为类似于指向 Collection 值类型的 const 引用的类型.
指针类型 X::pointer 行为类似于指向 Collection 值类型的指针的类型.
Distance type X::difference_type 用于表示 Collection 的两个迭代器之间距离的有符号整数类型. 该类型必须与迭代器的距离类型 (distance type) 相同.
Size type X::size_type 无符号整数类型, 可表示 Collection 距离类型 (distance type) 的任意非负值.

记法

X Collection 概念的模型的类型.
a, b 类型为 X 的对象.
T X 的值类型.

有效表达式

The following expressions must be valid.

名称 表达式 返回类型
Beginning of range a.begin() iterator (当 a 可变时), 否则为 const_iterator
End of range a.end() iterator (当 a 可变时), 否则为 const_iterator
大小 a.size() size_type
空的 Collection a.empty() 可转换为 bool
交换 a.swap(b) void

表达式语义

名称 表达式 语义 后置条件
Beginning of range a.begin() 返回指向 Collection 中第一个元素的迭代器. a.begin() 或可解引用, 或为越过末尾 (past-the-end). 当且仅当 a.size() == 0 时它为越过末尾.
End of range a.end() 返回指向 Collection 最后一个元素之后位置的迭代器. a.end() 为越过末尾 (past-the-end).
大小 a.size() 返回 Collection 的大小, 即其元素数量. a.size() >= 0
空的 Collection a.empty() 等价于 a.size() == 0. (但可能更快.)  
交换 a.swap(b) 等价于 swap(a,b)  

复杂度保证

begin() 与 end() 为均摊常量时间.

size() 至多与 Collection 的大小呈线性关系. empty() 为均摊常量时间.

swap() 至多与两个 collection 的大小之和呈线性关系.

不变式

有效范围 对任意 Collection a, [a.begin(), a.end()) 是有效范围.
范围大小 a.size() 等于从 a.begin() 到 a.end() 的距离.
完整性 遍历范围 [a.begin(), a.end()) 的算法将经过 a 的每个元素.

模型

  • array
  • array_ptr
  • vector<bool>

Collection 的精化

有不少概念精化 (refine) 了 Collection 概念, 类似于精化 Container 概念的那些概念. 下面是对这些精化概念的简要概览.

ForwardCollection

元素按某种顺序排列, 且该顺序不会在两次遍历之间自发改变. 因此, ForwardCollection 是 EqualityComparable 与 LessThanComparable. 此外, ForwardCollection 的迭代器类型是 MultiPassInputIterator, 它就是一个 InputIterator, 外加两项要求: 迭代器可用于对范围进行多次遍历; 并且若 it1 == it2 且 it1 可解引用, 则 ++it1 == ++it2. ForwardCollection 还拥有 front() 方法.

名称 表达式 返回类型 语义
首元素 a.front() reference (当 a 可变时),
否则为 const_reference.		 等价于 *(a.begin()).

ReversibleCollection

该容器提供可双向 (正向与反向) 遍历的迭代器. 迭代器类型必须满足 BidirectionalIterator 的全部要求, 唯一例外是其引用类型不必是真正的 C++ 引用. ReversibleCollection 在 ForwardCollection 的要求之上新增以下要求.

名称 表达式 返回类型 语义
Beginning of range a.rbegin() reverse_iterator (当 a 可变时), 否则为 const_reverse_iterator. 等价于 X::reverse_iterator(a.end()).
End of range a.rend() reverse_iterator (当 a 可变时), 否则为 const_reverse_iterator. 等价于 X::reverse_iterator(a.begin()).
末元素 a.back() reference (当 a 可变时),
否则为 const_reference.		 等价于 *(--a.end()).

SequentialCollection

元素按严格的线性顺序排列. 不要求额外的方法.

RandomAccessCollection

RandomAccessCollection 的迭代器满足 RandomAccessIterator 的全部要求, 唯一例外是其引用类型不必是真正的 C++ 引用. 此外, RandomAccessCollection 提供元素访问运算符.

名称 表达式 返回类型 语义
元素访问 a[n] reference (当 a 可变时), 否则为 const_reference. 返回 Collection 的第 n 个元素. n 必须可转换为 size_type. 前置条件: 0 <= n < a.size().

注释

[1] 引用类型不必是真正的 C++ 引用. 引用类型的要求取决于使用 Collection 的上下文. 具体而言, 它取决于该上下文对 Collection 值类型提出的要求. Collection 的引用类型必须满足与值类型相同的要求. 此外, 引用对象必须与 collection 中的值类型对象等价 (若它们是同一对象, 这一点显然成立). 同样, 在可变 Collection 中, 对引用对象的赋值必须导致对 Collection 中对象的赋值 (若它们是同一对象, 这一点同样显然成立; 但当引用类型是代理类时则不然).
