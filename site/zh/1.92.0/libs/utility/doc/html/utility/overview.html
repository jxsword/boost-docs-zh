概述

Boost.Utility 是一组用于语言支持的小型、有用且通用的组件.

随着时间推移,

  • 若干组件已被移至更合适的 Boost 库, 并且
  • 其中许多组件的变体已被接受纳入 C++ 标准

当组件移至另一个 Boost 库后, Boost.Utility 的头文件仍然会指向其他库中的相应头文件.
