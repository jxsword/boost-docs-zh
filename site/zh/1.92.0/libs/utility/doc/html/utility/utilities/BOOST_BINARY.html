引言

宏 BOOST_BINARY 用于表示二进制字面量. 它以一个二进制数作为实参, 该数由任意数量的 1 和 0 组成, 按长度为 1 到 8 的分组排列, 各分组之间以空格分隔. 该宏用作 C++14 采用的 二进制整数字面量 的替代.

所产生的字面量的类型由与 十六进制和八进制字面量 相同的规则确定. 在实现上, 该宏在预处理期间直接展开为一个八进制字面量, 因此运行期没有任何开销, 且结果可用在任何可以使用八进制字面量的地方.

为了直接支持带后缀的二进制字面量, 还提供了 BOOST_BINARY_XXX 形式的附加宏, 其中 XXX 是全大写字母的标准整数后缀.

此外, 在将这些后缀作为扩展提供的编译器中, LL 与 ULL 后缀可用于表示 long long 和 unsigned long long 类型.

BOOST_BINARY 系列宏位于头文件 <boost/utility/binary.hpp> 中.

示例 

void foo( int );

void foo( unsigned long );

void bar()
{
  int value1 = BOOST_BINARY( 100 111000 01 1 110 );

  unsigned long value2 = BOOST_BINARY_UL( 100 001 ); // unsigned long

  long long value3 = BOOST_BINARY_LL( 11 000 ); // long long if supported

  assert(    BOOST_BINARY( 10010 )
          &  BOOST_BINARY( 11000 )
          == BOOST_BINARY( 10000 )
        );

  foo( BOOST_BINARY( 1010 ) ); // calls the first foo

  foo( BOOST_BINARY_LU( 1010 ) ); // calls the second foo
}
