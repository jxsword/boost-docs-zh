压缩对 (Compressed Pair)

引言

<boost/compressed_pair.hpp> 的全部内容都定义在 namespace boost 内部.

类 compressed_pair 与 std::pair 非常相似. 但是, 如果任一模板实参是空类, 则会应用 空基类优化 来压缩该对的大小.

概要 

cpp
template <class T1, class T2>
class compressed_pair
{
public:
    typedef T1                                                 first_type;
    typedef T2                                                 second_type;
    typedef typename call_traits<first_type>::param_type       first_param_type;
    typedef typename call_traits<second_type>::param_type      second_param_type;
    typedef typename call_traits<first_type>::reference        first_reference;
    typedef typename call_traits<second_type>::reference       second_reference;
    typedef typename call_traits<first_type>::const_reference  first_const_reference;
    typedef typename call_traits<second_type>::const_reference second_const_reference;

             compressed_pair() : base() {}
             compressed_pair(first_param_type x, second_param_type y);
    explicit compressed_pair(first_param_type x);
    explicit compressed_pair(second_param_type y);

    compressed_pair& operator=(const compressed_pair&);

    first_reference       first();
    first_const_reference first() const;

    second_reference       second();
    second_const_reference second() const;

    void swap(compressed_pair& y);
};

该对的两个成员可以使用成员函数 first() 和 second() 访问. 注意, 并非所有成员函数都能对所有模板参数类型实例化. 特别是, compressed_pair 可以为引用和数组类型实例化, 但在这些情况下, 可用的构造函数范围受限. 如果类型 T1 和 T2 是同一类型, 则单实参构造函数只有一个版本, 且该构造函数把对中的两个值都初始化为传入的值.

注意, 如果任一成员是 POD 类型, 则 compressed_pair 默认构造函数不会对该成员进行零初始化: 如果你希望这些类型具有默认值, 则需要由你为它们提供初始值.

注意, 如果任一模板实参是联合类型, 则无法实例化 compressed_pair, 除非编译器支持 boost::is_union, 或者 boost::is_union 针对该联合类型进行了特化.

最后, 给 Visual C++ 6 用户一个警告: 如果任一实参是空类型, 那么对该成员赋值会导致内存损坏, 除非该空类型定义了"什么都不做"的赋值运算符. 这是由于 VC6 生成隐式赋值运算符的方式存在缺陷.

参考

头文件 <boost/detail/compressed_pair.hpp>
namespace boost {
  template<typename T1, typename T2> class compressed_pair;

  template<typename T> class compressed_pair<T, T>;
  template<typename T1, typename T2> 
    void swap(compressed_pair< T1, T2 > & x, compressed_pair< T1, T2 > & y);
}
