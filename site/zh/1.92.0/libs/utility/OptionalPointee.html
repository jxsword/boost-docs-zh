概念: OptionalPointee

说明

一个类型是 OptionalPointee 的模型, 如果它指向 (或引用) 一个可能不存在的值. 也就是说, 如果它有一个 被指向对象 (pointee), 该对象可能是 有效 (存在) 的, 也可能是 无效 (不存在) 的; 并且可以测试该被指向对象是否有效. 该模型 并不 蕴含指针语义: 即它既不蕴含浅拷贝, 也不蕴含别名.

记法

T 是 OptionalPointee 概念的模型的类型
t 对象, 其类型为 T 或可能为 const T

定义

有效表达式

名称 表达式 返回类型 语义
值访问  *t  T& 若被指向对象 (pointee) 有效, 则返回对它的引用.
若被指向对象无效, 则结果为 未定义.
值访问  t->xyz  T* 若被指向对象有效, 则返回指向它的内建指针.
若被指向对象无效, 则结果为 未定义 (甚至可能不返回 NULL).
有效性测试  bool(t)  bool 若被指向对象有效, 则返回 true.
若被指向对象无效, 则返回 false.
无效性测试  !t  bool 若被指向对象有效, 则返回 false.
若被指向对象无效, 则返回 true.

模型

  • 指针, 内建与智能指针皆可.
  • boost::optional<>

OptionalPointee 与关系运算

该概念不为关系运算定义任何特定语义, 因此, 满足该概念的类型可能具有浅或深的关系语义.
例如, 作为 OptionalPointee 模型的指针具有浅关系运算符: 指针的比较不涉及被指向对象的比较. 这对指针来说是合理的, 因为它们具有浅拷贝语义.
但另一方面, 同样是 OptionalPointee 模型的 boost::optional<T> 却具有深拷贝与深关系语义.
如果为该概念编写泛型代码, 重要的是不要直接使用关系运算符, 因为其语义可能因实际类型而异.
尽管如此, 该概念本身仍可用于定义 深度 关系测试, 这些测试可用于面向任何满足 OptionalPointee 的类型的泛型代码:

等价关系:

template<class OptionalPointee>
inline
bool equal_pointees ( OptionalPointee const& x, OptionalPointee const& y )
{
  return (!x) != (!y) ? false : ( !x ? true : (*x) == (*y) ) ;
}
template<class OptionalPointee>
struct equal_pointees_t : std::binary_function<OptionalPointee,OptionalPointee,bool>
{
  bool operator() ( OptionalPointee const& x, OptionalPointee const& y ) const
    { return equal_pointees(x,y) ; }
} ;

前述泛型函数与函数对象具有如下语义:
若 x 与 y 均有有效的被指向对象, 则经由 (*x == *y) 比较其值.
若仅一方有有效的被指向对象, 则返回 false.
若双方的被指向对象均无效, 则返回 true.

小于关系:

template<class OptionalPointee>
inline
bool less_pointees ( OptionalPointee const& x, OptionalPointee const& y )
{
  return !y ? false : ( !x ? true : (*x) < (*y) ) ;
}
template<class OptionalPointee>
struct less_pointees_t : std::binary_function<OptionalPointee,OptionalPointee,bool>
{
  bool operator() ( OptionalPointee const& x, OptionalPointee const& y ) const
    { return less_pointees(x,y) ; }
} ;

前述泛型函数与函数对象具有如下语义:
若 y 的被指向对象无效, 则返回 false.
否则, 若 x 的被指向对象无效, 则返回 true.
否则 ( x 与 y 均有有效的被指向对象), 则经由 (*x < *y).


所有这些函数与函数对象都实现于 compare_pointees.hpp

注意: OptionalPointee 并不蕴含别名 (aliasing) (例如 optional<> 就不取别名); 因此, 在为该概念编写的泛型代码中, 不应像指针那样直接使用隐含浅语义别名的关系运算符.
