Boost.Atomic 简介

Boost.Atomic 是一个提供 atomic 数据类型及这些数据类型上的操作的库, 还提供通过原子变量协调多个线程所需的内存序约束. 它实现 C++11 标准定义的接口, 但将该特性提供给缺乏针对这一特定 C++11 特性的系统/编译器支持的平台.

本库的使用者应当已经熟悉一般的并发概念, 以及 "互斥" 等基本概念.

该实现尽可能利用处理器特定的指令 (通过内联汇编、平台库或编译器内置函数), 并退回到通过加锁 "模拟" 原子操作.

目的

对 "普通" 变量的操作不保证是原子的. 这意味着在 int n=0 初始的情况下, 两个线程并发执行

void function()
{
  n ++;
}

可能得到 n==1 而不是 2: 每个线程会把旧值读入处理器寄存器, 递增它, 然后把结果写回. 因此两个线程都可能写入 1, 而没有意识到另一个线程也在做同样的事.

改为声明 atomic<int> n=0, 对该变量的同一操作将总是得到 n==2, 因为对该变量的每个操作都是 原子的: 这意味着每个操作的行为如同相对于另一个操作被严格顺序化.

原子变量在两方面有用:

  • 作为通过自定义协调协议协调多个线程的手段
  • 作为对简单变量 "加锁" 访问的更快替代

常见模式请参见 示例一节.
