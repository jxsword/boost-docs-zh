概述

Boost.Integer 提供整数类型支持, 对泛型编程特别有帮助. 它提供基于属性 (如位数或所支持的最大值) 选择整数类型的方法, 以及编译期位掩码选择. 它还提供 std::numeric_limits 的一个派生版本, 为 min 和 max 提供整型常量表达式. 最后, 它提供两个编译期算法: 确定编译期值中二的最高次幂, 以及计算常量表达式的 min 和 max.

用途

前置声明.

<boost/integer_fwd.hpp>

类和类模板的前置声明 - 用于只需要类名的场合.

整数特征.

<boost/integer_traits.hpp>

类模板 boost::integer_traits, 派生自 std::numeric_limits 并添加 const_min 和 const_max 成员.

整数类型选择.

<boost/integer.hpp>

基于最大值或位数等属性进行整数类型选择的模板: 当已知最大值或位数等某个属性时, 用于选择整数的类型. 对泛型编程很有用.

最大公约数与最小公倍数.

<boost/integer/common_factor_rt.hpp> and <boost/integer/common_factor_ct.hpp>

函数 gcd 和 lcm, 外加函数对象与编译期版本.

整数掩码.

<boost/integer/integer_mask.hpp>

基于位数选择整数掩码 (单个或最低组) 的模板: 当位位置基于编译期变量时, 用于选择特定的掩码. 对泛型编程很有用.

编译期 log2 计算.

<boost/integer/static_log2.hpp>

求数中二的最高次幂的模板: 用于基于最大值求位大小/范围. 对泛型编程很有用.

编译期 min/max 计算.

<boost/integer/static_min_max.hpp>

求两个数极值的模板: 用于基于最小值或最大值求边界. 对泛型编程很有用.

扩展欧几里得算法.

<boost/integer/extended_euclidean.hpp>

求解 mx + ny = gcd(x,y) 中的 x 和 y.

模乘逆元.

<boost/integer/mod_inverse.hpp>

给定 a 和 m, 求解 ax = 1 mod m 中的 x.
