<boost/integer.hpp> 的类型选择模板允许根据所需特性 (如位数或最大值) 选择整数类型. 该设施对解决泛型编程问题特别有用.

概要 

namespace boost
{
  //  fast integers from least integers
  template<typename LeastInt>
  struct int_fast_t
  {
      typedef implementation-defined-type  type;
  };

  //  signed
  template<int Bits>
  struct int_t
  {
      /* Member exact may or may not be defined depending upon Bits */
      typedef implementation-defined-type  exact;
      typedef implementation-defined-type  least;
      typedef int_fast_t<least>::fast      fast;
  };

  //  unsigned
  template<int Bits>
  struct uint_t
  {
      /* Member exact may or may not be defined depending upon Bits */
      typedef implementation-defined-type  exact;
      typedef implementation-defined-type  least;
      typedef int_fast_t<least>::fast      fast;
  };

  //  signed
  template<long long MaxValue>
  struct int_max_value_t
  {
      typedef implementation-defined-type  least;
      typedef int_fast_t<least>::fast      fast;
  };

  template<long long MinValue>
  struct int_min_value_t
  {
      typedef implementation-defined-type  least;
      typedef int_fast_t<least>::fast      fast;
  };

  //  unsigned
  template<unsigned long long Value>
  struct uint_value_t
  {
      typedef implementation-defined-type  least;
      typedef int_fast_t<least>::fast      fast;
  };
} // namespace boost

最易操作的类型

int_fast_t 类模板将其输入类型映射到处理器最易于操作的次大类型; 若输入类型已是易于操作的类型, 则映射到其自身. 例如, 若在处理前将一批 char 对象转换为 int 对象, 处理可能会更快. 输入类型作为唯一的模板参数传入, 必须是内置整数类型 (bool 除外). 无符号整数类型和有符号整数类型均可使用. 输出类型以嵌套类型 fast 给出.

实现说明: 默认情况下, 输出类型与输入类型相同. 最终, 这段代码的实现应针对每个平台进行定制, 以给出内置类型与最易操作的内置类型之间的准确映射. 此外, 无法保证输出类型确实比输入类型更易于操作.

定宽类型

int_t、uint_t、int_max_value_t、int_min_value_t 和 uint_value_t 类模板为给定的模板参数找到最合适的内置整数类型. 该类型由嵌套类型 least 给出. 该类型的最易操作版本由嵌套类型 fast 给出. 下表描述了各模板的准则.

表 1. 定宽类型类模板的准则

类模板

模板参数映射

boost::int_t<N>::least

至少具有 N 位 (含符号位) 的最小的内置有符号整数类型. 参数应为正数. 若参数大于最大整数类型的位数, 将导致编译期错误.

boost::int_t<N>::fast

至少具有 N 位 (含符号位) 的最易操作的内置有符号整数类型. 参数应为正数. 若参数大于最大整数类型的位数, 将导致编译期错误.

boost::int_t<N>::exact

恰好具有 N 位 (含符号位) 的内置有符号整数类型. 参数应为正数. 注意, 成员 exact 仅在 存在恰好具有 N 位的类型时才有定义.

boost::uint_t<N>::least

至少具有 N 位的最小的内置无符号整数类型. 参数应为正数. 若参数大于最大整数类型的位数, 将导致编译期错误.

boost::uint_t<N>::fast

至少具有 N 位的最易操作的内置无符号整数类型. 参数应为正数. 若参数大于最大整数类型的位数, 将导致编译期错误.

boost::uint_t<N>::exact

恰好具有 N 位的内置无符号整数类型. 参数应为正数. 若参数大于最大整数类型的位数, 将导致编译期错误. 注意, 成员 exact 仅在 存在恰好具有 N 位的类型时才有定义.

boost::int_max_value_t<V>::least

能够容纳闭区间 0 - V 内所有值的最小的内置有符号整数类型. 参数应为正数.

boost::int_max_value_t<V>::fast

能够容纳闭区间 0 - V 内所有值的最易操作的内置有符号整数类型. 参数应为正数.

boost::int_min_value_t<V>::least

能够容纳闭区间 V - 0 内所有值的最小的内置有符号整数类型. 参数应为负数.

boost::int_min_value_t<V>::fast

能够容纳闭区间 V - 0 内所有值的最易操作的内置有符号整数类型. 参数应为负数.

boost::uint_value_t<V>::least

能够容纳直至并包括 V 的所有正值的最小的内置无符号整数类型. 参数应为正数.

boost::uint_value_t<V>::fast

能够容纳直至并包括 V 的所有正值的最易操作的内置无符号整数类型. 参数应为正数.

示例 

#include <boost/integer.hpp>

//...

int main()
{
    boost::int_t<24>::least my_var;  // my_var has at least 24-bits
    //...
    // This one is guaranteed not to be truncated:
    boost::int_max_value_t<1000>::least my1000 = 1000;
    //...
    // This one is guaranteed not to be truncated, and as fast
    // to manipulate as possible, its size may be greater than
    // that of my1000:
    boost::int_max_value_t<1000>::fast my_fast1000 = 1000;
}

演示程序

程序 integer_test.cpp 简单演示了定宽类型类模板的多种实例化示例的结果.

设计理由

该头文件中模板的设计理由包括:

  • 避免递归, 因为 C++ 保证的递归深度有限 (17).
  • 出于一般性原则避免使用宏.
  • 尽量保持设计简单.

替代方案

如果所需的位数事先已知, 使用 <boost/cstdint.hpp> 提供的类型可能更合适.
