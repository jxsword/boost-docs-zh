引言

<boost/math/common_factor.hpp> 中的类模板和函数模板提供两个整数的最大公约数 (GCD) 或最小公倍数 (LCM) 的运行期与编译期求值. 这些设施对许多面向数值的泛型编程问题很有用.

概要 

namespace boost
{
namespace integer
{

template < typename IntegerType >
   class gcd_evaluator;
template < typename IntegerType >
   class lcm_evaluator;

template < typename IntegerType >
   constexpr IntegerType  gcd( IntegerType const &a, IntegerType const &b );
template < typename IntegerType >
   constexpr IntegerType  lcm( IntegerType const &a, IntegerType const &b );
template < typename IntegerType, typename... Args >
   constexpr IntegerType  gcd( IntegerType const &a, IntegerType const &b, Args const&... );
template < typename IntegerType, typename... Args >
   constexpr IntegerType  lcm( IntegerType const &a, IntegerType const &b, Args const&... );

template <typename I>
std::pair<typename std::iterator_traits<I>::value_type, I>
   gcd_range(I first, I last);
template <typename I>
std::pair<typename std::iterator_traits<I>::value_type, I>
   lcm_range(I first, I last);

typedef see-below static_gcd_type;

template < static_gcd_type Value1, static_gcd_type Value2 >
   struct static_gcd;
template < static_gcd_type Value1, static_gcd_type Value2 >
   struct static_lcm;

}
}

GCD 函数对象

头文件: <boost/integer/common_factor_rt.hpp> 

template < typename IntegerType >
class boost::integer::gcd_evaluator
{
public:
   // Types
   typedef IntegerType  result_type;
   typedef IntegerType  first_argument_type;
   typedef IntegerType  second_argument_type;

   // Function object interface
   constexpr result_type  operator ()(
      first_argument_type const &a,
      second_argument_type const &b ) const;
};

boost::integer::gcd_evaluator 类模板定义了一个函数对象类, 用于返回两个整数的最大公约数. 该模板由单一类型参数化, 此处称为 IntegerType. 该类型应为表示整数的数值类型. 即使 operator 的任一实参为负, 函数对象的结果也总是非负的.

该函数对象类模板用于 GCD 函数模板的对应版本. 如果某个数值类型想要自定义其最大公约数的求值, 则该类型应对 gcd_evaluator 类模板进行特化.

注意, 这些函数对象仅在 C++14 及更高版本中是 constexpr 的. 在适当情况下, 它们还被声明为 noexcept.

LCM 函数对象

头文件: <boost/integer/common_factor_rt.hpp> 

template < typename IntegerType >
class boost::integer::lcm_evaluator
{
public:
   // Types
   typedef IntegerType  result_type;
   typedef IntegerType  first_argument_type;
   typedef IntegerType  second_argument_type;

   // Function object interface
   constexpr result_type  operator ()(
     first_argument_type const &a,
     second_argument_type const &b ) const;
};

boost::integer::lcm_evaluator 类模板定义了一个函数对象类, 用于返回两个整数的最小公倍数. 该模板由单一类型参数化, 此处称为 IntegerType. 该类型应为表示整数的数值类型. 即使 operator 的任一实参为负, 函数对象的结果也总是非负的. 如果最小公倍数超出该整数类型的范围, 则结果未定义.

该函数对象类模板用于 LCM 函数模板的对应版本. 如果某个数值类型想要自定义其最小公倍数的求值, 则该类型应对 lcm_evaluator 类模板进行特化.

注意, 这些函数对象仅在 C++14 及更高版本中是 constexpr 的. 在适当情况下, 它们还被声明为 noexcept.

运行期 GCD 与 LCM 计算

头文件: <boost/integer/common_factor_rt.hpp> 

template < typename IntegerType >
constexpr IntegerType  boost::integer::gcd( IntegerType const &a, IntegerType const &b );

template < typename IntegerType >
constexpr IntegerType  boost::integer::lcm( IntegerType const &a, IntegerType const &b );

template < typename IntegerType, typename... Args >
   constexpr IntegerType  gcd( IntegerType const &a, IntegerType const &b, Args const&... );

template < typename IntegerType, typename... Args >
   constexpr IntegerType  lcm( IntegerType const &a, IntegerType const &b, Args const&... );

template <typename I>
std::pair<typename std::iterator_traits<I>::value_type, I>
   gcd_range(I first, I last);

template <typename I>
std::pair<typename std::iterator_traits<I>::value_type, I>
   lcm_range(I first, I last);

boost::integer::gcd 函数模板返回传递给它的两个整数的最大公约数 (非负). boost::integer::gcd_range 是上述 gcd 算法在一个范围上的迭代, 返回所有元素的最大公约数. 当 gcd 达到 1 或到达范围末尾时, 算法终止. 因此它还会返回最后被检查元素之后的迭代器, 因为该位置可能不等于范围的末尾. gcd 的可变参数版本行为类似, 但不指示是哪个输入值使 gcd 达到 1.

boost::integer::lcm 函数模板返回传递给它的两个整数的最小公倍数 (非负). 与 gcd 一样, 针对超过 2 个实参的情形, 该函数也有范围版本和可变参数版本.

注意, 这些函数仅在 C++14 及更高版本中是 constexpr 的. 在适当情况下, 它们还被声明为 noexcept.

编译期 GCD 与 LCM 计算

注释

在支持 C++14 的编译器上, 这些函数已被弃用, 应改用 constexpr 的 gcd 和 lcm.

头文件: <boost/integer/common_factor_ct.hpp> 

typedef unspecified static_gcd_type;

template < static_gcd_type Value1, static_gcd_type Value2 >
struct boost::integer::static_gcd : public mpl::integral_c<static_gcd_type, implementation_defined>
{
};

template < static_gcd_type Value1, static_gcd_type Value2 >
struct boost::integer::static_lcm : public mpl::integral_c<static_gcd_type, implementation_defined>
{
};

类型 static_gcd_type 是编译器所支持的、可用于整型常量表达式中的最宽无符号整数类型. 通常它与 boost::uintmax_t 是同一类型, 但在某些较老的编译器上可能回退为 unsigned long.

boost::integer::static_gcd 和 boost::integer::static_lcm 类模板接受两个以 static_gcd_type 类型表示的基于值的模板参数, 并继承自类型 boost::mpl::integral_c. 通过继承基类, 它们拥有成员 value, 分别为模板实参的最大公因数或最小公倍数. 如果最小公倍数超出 static_gcd_type 的范围, 将发生编译期错误.

示例 

#include <boost/integer/common_factor.hpp>
#include <algorithm>
#include <iterator>
#include <iostream>

int main()
{
   using std::cout;
   using std::endl;

   cout << "The GCD and LCM of 6 and 15 are "
   << boost::integer::gcd(6, 15) << " and "
   << boost::integer::lcm(6, 15) << ", respectively."
   << endl;

   cout << "The GCD and LCM of 8 and 9 are "
   << boost::integer::static_gcd<8, 9>::value
   << " and "
   << boost::integer::static_lcm<8, 9>::value
   << ", respectively." << endl;

   int  a[] = { 4, 5, 6 }, b[] = { 7, 8, 9 }, c[3];
   std::transform( a, a + 3, b, c, boost::integer::gcd_evaluator<int>() );
   std::copy( c, c + 3, std::ostream_iterator<int>(cout, " ") );
}

头文件 <boost/integer/common_factor.hpp>

该头文件只是包含了头文件 <boost/integer/common_factor_ct.hpp> 和 <boost/integer/common_factor_rt.hpp>.

注意, 这是一个遗留头文件: 它过去包含实际实现, 但编译期与运行期设施后来被移到了各自独立的头文件中 (因为二者相互独立).

演示程序

程序 common_factor_test.cpp 演示了运行期 GCD 与 LCM 函数模板以及编译期 GCD 与 LCM 类模板的多种实例化示例的结果. (运行期 GCD 与 LCM 类模板通过运行期函数模板间接测试.)

设计理由

最大公约数与最小公倍数函数在某些数值语境中被大量使用, 包括其他一些 Boost 库. 将这些函数集中到一个头文件中可以改善代码组织并便于维护.
