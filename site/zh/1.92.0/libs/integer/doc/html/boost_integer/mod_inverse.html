模乘逆元

引言

数 a 的模乘逆元是满足 ax = 1 mod p 的数 x. 存在一种基于扩展欧几里得算法的快速算法来计算模乘逆元, Boost 提供了该算法.

概要 

#include <boost/integer/mod_inverse.hpp>

namespace boost { namespace integer {

template<class Z>
Z mod_inverse(Z a, Z m);

}}

用法 

int x = mod_inverse(2, 5);
// prints x = 3:
std::cout << "x = " << x << "\n";

int y = mod_inverse(2, 4);
if (y == 0)
{
    std::cout << "There is no inverse of 2 mod 4\n";
}

当且仅当 a 与 m 互质时, 模乘逆元才存在. 如果 a 与 m 有公因数, 则 mod_inverse(a, m) 返回零.

参考文献

Wagstaff, Samuel S., The Joy of Factoring, Vol. 68. American Mathematical Soc., 2013.
