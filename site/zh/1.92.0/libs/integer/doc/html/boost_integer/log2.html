<boost/integer/static_log2.hpp> 中的类模板确定给定值中最高位的位置. 该设施对解决泛型编程问题很有用.

概要 

namespace boost
{

  typedef implementation-defined static_log2_argument_type;
  typedef implementation-defined static_log2_result_type;

  template <static_log2_argument_type arg>
  struct static_log2
  {
    static const static_log2_result_type value = implementation-defined;
  };


  template < >
  struct static_log2< 0 >
  {
    // The logarithm of zero is undefined.
  };


}  // namespace boost

用法

boost::static_log2 类模板接受一个模板参数, 即一个 static_log2_argument_type 类型的值. 该模板只定义一个成员 value, 它给出模板实参的截断底二对数.

由于任何底的零的对数都无定义, 因此 static_log2 对模板实参为零有一个特化. 该特化没有成员, 所以试图使用零的底二对数会导致编译期错误.

注释:

  • static_log2_argument_type 是一个无符号整数类型 (C++ 标准, 3.9.1p3).
  • static_log2_result_type 是一个整数类型 (C++ 标准, 3.9.1p7).

演示程序

程序 static_log2_test.cpp 简单演示了以二为底对数类模板的多种实例化示例的结果.

设计理由

以二为底的对数 (二进制对数, 缩写为 lb) 函数偶尔用于给出计算机算法的量级估计. 截断对数可以视为一个值中二的最高次幂, 对应于该值 (对于二进制整数) 最高的置位. 在泛型编程中有时会用到最高位的位置, 这要求该位置在编译期静态可用 (即 编译期).
