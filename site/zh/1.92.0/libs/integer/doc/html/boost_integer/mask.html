概述

<boost/integer/integer_mask.hpp> 中的类模板为某个位位置或某个大小的连续比特组提供位掩码. 掩码常量的类型来自 整数类型选择模板 头文件.

概要 

#include <cstddef>  // for std::size_t

namespace boost
{

template <std::size_t Bit>
struct high_bit_mask_t
{
    typedef implementation-defined-type  least;
    typedef implementation-defined-type  fast;

    static const least       high_bit       = implementation-defined;
    static const fast        high_bit_fast  = implementation-defined;

    static const std::size_t bit_position   = Bit;
};

template <std::size_t Bits>
struct low_bits_mask_t
{
    typedef implementation-defined-type  least;
    typedef implementation-defined-type  fast;

    static const least       sig_bits       = implementation-defined;
    static const fast        sig_bits_fast  = implementation-defined;

    static const std::size_t bit_count      = Bits;
};

// Specializations for low_bits_mask_t exist for certain bit counts.

}  // namespace boost

单比特掩码类模板

boost::high_bit_mask_t 类模板为表示某个位置比特的位掩码提供常量. 这些掩码等价于值 2Bit, 其中 Bit 是模板参数. 位位置必须是从零到 Max 的非负数, 其中 Max 比最大无符号内置整数类型支持的位数小一. 下表描述了 high_bit_mask_t 实例化的成员.

表 2. boost::high_bit_mask_t 类模板的成员

成员

含义

least

支持给定位位置的、最小的无符号内置类型.

fast

least 的最易操作版本.

high_bit

一个 least 常量, 其值为 2Bit.

high_bit_fast

fast 版本, 对应于 high_bit.

bit_position

模板参数的值, 以便在类模板的实例化被重命名时仍能取用.

比特组掩码类模板

boost::low_bits_mask_t 类模板为等价于值 (2Bits - 1) 的位掩码提供常量, 其中 Bits 是模板参数. 参数 Bits 必须是从零到 Max 的非负整数, 其中 Max 是最大无符号内置整数类型支持的位数. 下表描述了 low_bits_mask_t 的成员.

表 3. boost::low_bits_mask_t 类模板的成员

成员

含义

least

支持给定位数的、最小的无符号内置类型.

fast

least 的最易操作版本.

sig_bits

具有所需位掩码值的 least 常量.

sig_bits_fast

fast 版本, 对应于 sig_bits.

bit_count

模板参数的值, 以便在类模板的实例化被重命名时仍能取用.

实现说明

当 Bits 恰好是某个内置无符号类型的大小时, 实现必须做出改变以防止未定义行为. 因此, 在那些位数上存在 low_bits_mask_t 的特化.

示例 

#include <boost/integer/integer_mask.hpp>

//...

int main()
{
    typedef boost::high_bit_mask_t<29>  mask1_type;
    typedef boost::low_bits_mask_t<15>  mask2_type;

    mask1_type::least  my_var1;
    mask2_type::fast   my_var2;
    //...

    my_var1 |= mask1_type::high_bit;
    my_var2 &= mask2_type::sig_bits_fast;

    //...
}

演示程序

程序 integer_mask_test.cpp 简单演示了位掩码类模板的多种实例化示例的结果.

设计理由

该头文件中的类模板是 整数类型选择类模板 的扩展. 新的类模板提供相同的定宽类型, 还提供了便捷的掩码, 用于在所含内置类型的位数更多时提取最高有效位或全部有效位. 这可以防止值被高位未使用的比特污染.
