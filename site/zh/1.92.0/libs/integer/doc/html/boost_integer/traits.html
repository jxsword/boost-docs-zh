动机

C++ 标准库的 <limits> 头文件提供了一个类模板 numeric_limits<>, 并为每个基本类型提供特化.

对于整数类型, std::numeric_limits<> 中值得关注的成员有:

static const bool is_specialized;      // Will be true for integer types.
static T min() throw();                // Smallest representable value.
static T max() throw();                // Largest representable value.
static const int digits;               // For integers, the number of value bits.
static const int digits10;             // The number of base 10 digits that can be represented.
static const bool is_signed;           // True if the type is signed.
static const bool is_integer;          // Will be true for all integer types.

对许多用途而言这些已经足够. 但 min() 和 max() 存在问题, 因为它们不是常量表达式 (std::5.19), 而某些用法又要求常量表达式.

模板类 integer_traits 解决了这一问题.

概要 

namespace boost {
  template<class T>
  class integer_traits : public std::numeric_limits<T>
  {
  public:
     static const bool is_integral = false;
     //
     // These members are defined only if T is a built-in
     // integal type:
     //
     static const T const_min = implementation-defined;
     static const T const_max = implementation-defined;
  };
}

说明

模板类 integer_traits 派生自 std::numeric_limits. 主特化添加了唯一的 bool 成员 is_integral, 其编译期常量值为 false. 然而, 对于所有整数类型 T (std::3.9.1/7 [basic.fundamental]), 提供了定义了以下编译期常量的特化:

member

类型

value

is_integral

bool

true

const_min

T

等价于 std::numeric_limits<T>::min()

const_max

T

等价于 std::numeric_limits<T>::max()

注释: 提供 is_integral 标志是因为用户定义的整数类应对 std::numeric_limits<>::is_integer = true 进行特化, 而编译期常量 const_min 和 const_max 不会为该用户定义的类提供, 除非 boost::integer_traits 也被特化.
