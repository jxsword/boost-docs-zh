配置

Boost.WinAPI 识别以下配置宏:

表 1.1. 配置宏

宏名

效果

BOOST_USE_WINAPI_VERSION

如果定义, 指定目标 Windows API 版本. 版本应以十六进制整数给出, 与 _WIN32_WINNT 宏的值相同. 部分版本列于此处. 如果未定义该宏, 版本将从 _WIN32_WINNT 与 WINVER 宏推导 (若它们已定义), 否则选择默认版本. 在支持该版本 SDK 的编译器上, 默认版本目前为 Windows Vista/Server 2008, 其他编译器上为 Windows XP. 默认值在未来的发布中可能变化.

BOOST_USE_NTDDI_VERSION

如果定义, 将目标 Windows API 版本指定到特定 Service Pack. 这个宏提供了比 BOOST_USE_WINAPI_VERSION 更细粒度地定义目标 Windows 版本的方式. 版本应以十六进制整数给出, 与 NTDDI_VERSION 宏的值相同. 部分版本列于此处. 如果未定义该宏, 版本将从 NTDDI_VERSION 与 BOOST_USE_WINAPI_VERSION 宏推导——在后一种情况下默认为所指示 Windows 版本的最新修订版. 如果定义了 BOOST_USE_NTDDI_VERSION, 则 BOOST_USE_WINAPI_VERSION 也应被定义为对应的值.

BOOST_USE_WINAPI_FAMILY

如果定义, 指定要使用的 Windows API 家族. 该家族可设置为 WINAPI_FAMILY 的值之一.

BOOST_USE_WINDOWS_H

该宏属于 Boost.Config. 如果定义, Boost.WinAPI 会包含 <windows.h> 以及按需的其他 Windows SDK 头文件. 否则 Boost.WinAPI 将按需提供自己的 SDK 组件声明, 而不包含 SDK 头文件.

BOOST_NO_ANSI_APIS

该宏由 Boost.Config 在不支持某些 API 窄字符版本的平台定义. 当该宏被定义时, Boost.WinAPI 不会声明窄字符 API.

用户代码可以包含 <boost/winapi/config.hpp> 来定义若干可能有用的宏. 建议任何涉及 Windows API 使用的代码都包含此头文件.

表 1.2. 定义的配置宏

宏名

效果

BOOST_USE_WINAPI_VERSION,
BOOST_USE_NTDDI_VERSION

如果用户未定义, 这些宏由该头文件定义为目标 Windows API 版本.

BOOST_WINAPI_VERSION_NT4,
BOOST_WINAPI_VERSION_WIN2K,
BOOST_WINAPI_VERSION_WINXP,
BOOST_WINAPI_VERSION_WS03,
BOOST_WINAPI_VERSION_WIN6,
BOOST_WINAPI_VERSION_VISTA,
BOOST_WINAPI_VERSION_WS08,
BOOST_WINAPI_VERSION_LONGHORN,
BOOST_WINAPI_VERSION_WIN7,
BOOST_WINAPI_VERSION_WIN8,
BOOST_WINAPI_VERSION_WINBLUE,
BOOST_WINAPI_VERSION_WINTHRESHOLD,
BOOST_WINAPI_VERSION_WIN10

这些宏展开为指示特定 Windows 版本的常量, 可与 BOOST_USE_WINAPI_VERSION 一起在预处理器版本检查中使用.

BOOST_WINAPI_IS_MINGW

当 Windows SDK 由 MinGW 提供时定义.

BOOST_WINAPI_IS_MINGW_W64

当 Windows SDK 由 MinGW-w64 提供时定义. 注意这并不意味着代码是为 64 位 Windows 编译的.

BOOST_WINAPI_IS_CYGWIN

当 Windows SDK 由 Cygwin 的 MinGW 变体提供时定义.
