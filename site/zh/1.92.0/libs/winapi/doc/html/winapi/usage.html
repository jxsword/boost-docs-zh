使用 Boost.WinAPI

为了使用 Boost.WinAPI, 你必须包含 boost/winapi 目录中的一个或多个头文件. 其中每个头文件定义 Windows API 的一部分, 头文件名应当是不言自明的. 每个 Boost.WinAPI 头文件可能在全局命名空间中声明若干符号 (如函数与类型), 模仿 Windows SDK, 并在 boost::winapi 命名空间中声明对应的符号集合. 用户代码应当只使用 boost::winapi 命名空间中的符号.

boost::winapi 中的大多数函数与相应的 Windows API 函数同名同义. 类型与常量在其名称末尾带有下划线 ('_'), 以避免与 Windows SDK 中定义的宏冲突.

注释

Boost.WinAPI 不定义会展开为 char 或 wchar_t 版本函数 (取决于 UNICODE 宏) 的函数名宏. Boost.WinAPI 也不支持 _TCHAR 及相关字符串类型. 用户必须以适当的参数类型显式使用 *A 或 *W 函数. 但要注意, *A 函数在定义了 BOOST_NO_ANSI_APIS 时可能不可用.

例如, 下面展示如何用 Boost.WinAPI 创建与销毁一个信号量:

#include <limits>
#include <boost/winapi/handles.hpp>
#include <boost/winapi/semaphore.hpp>

boost::winapi::HANDLE_ h = boost::winapi::CreateSemaphoreExW(
    NULL,                                                        // security attributes
    0l,                                                          // initial count
    std::numeric_limits< boost::winapi::LONG_ >::max(),          // max count
    L"Local\\MySemaphore",                                       // semaphore name
    0l,                                                          // flags
    boost::winapi::SEMAPHORE_ALL_ACCESS_                         // access mode
);

if (h)
    boost::winapi::CloseHandle(h);

特定函数、类型与常量的文档请参考 MSDN.
