使用 Boost.WinAPI

引言

Boost.WinAPI 库是 Windows API 的抽象层, 供其他 Boost 库在内部使用. Boost.WinAPI 不是面向 Boost 用户的公开库.

使用 Boost.WinAPI 而非直接使用 Windows API 的主要优点是:

  • 避免在库的公开头文件中包含 <windows.h> 或其他 Windows SDK 头文件. 众所周知, Windows SDK 头文件依赖大量必须由用户定义的配置宏. 如果你的库依赖某个特定 API, 你可能无法依赖用户启用它. 另一方面, 你的库也无法强制特定的 Windows SDK 配置, 因为 (a) Windows SDK 头文件可能在你库的头文件之前、以不同的配置宏集合被包含, (b) 你想要的配置可能与用户代码的配置不兼容.
  • 避免处理 Windows SDK 头文件定义的大量宏.
  • 对头文件中包含的 API 进行更细粒度的控制.
  • 允许为 Boost 选择目标 Windows 版本. 该版本可以不同于用户代码针对的版本.
  • 与 Windows SDK 的不同实现 (如 MinGW 与 MinGW-w64) 有更好的兼容性.

Boost.WinAPI 的实现由模仿 Windows SDK 中真实声明的大量函数、类型与常量声明组成. 某些情况下会提供简单的内联函数封装. 因此 Boost.WinAPI 对运行期性能的影响应当为零. Boost.WinAPI 只依赖 Boost.Config 与 Boost.Predef, 并与 C++03 编译器兼容.
