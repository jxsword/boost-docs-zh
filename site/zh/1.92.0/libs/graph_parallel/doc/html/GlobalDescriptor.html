说明

全局描述符是表示某个实体的一种对象, 该实体由某个进程所拥有, 且可能驻留在当前执行进程无法访问的地址空间中. 全局描述符由两部分组成: 实体的 属主, 即实体所在进程的标识符; 以及 本地描述符, 它在属主的地址空间内唯一地标识该实体.

细化自

  • 可默认构造
  • Assignable

记号

X
对全局描述符概念建模的一个类型.
x
类型为 X 的对象

关联类型

进程 ID 类型 process_id_type 由与类型 X 相关联的进程组决定.
本地描述符类型 local_type 由描述符所访问的数据结构决定. 必须对 可相等比较 与 可拷贝构造 建模.

有效表达式

名称 表达式 类型 语义
属主 owner(x) process_id_type 返回 x 的属主.
本地描述符 local(x) local_type 返回唯一标识 x 的本地描述符.
