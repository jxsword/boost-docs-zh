引言

MPI mpi_process_group 是使用消息传递接口 (MPI) 的 进程组 接口的一个实现. 它是目前 Parallel BGL 中使用的主要进程组.

定义位置

头文件 <boost/graph/distributed/mpi_process_group.hpp>

{
public:
  typedef boost::mpi::communicator communicator_type;

由于 mpi_process_group 是 进程组 接口的一个实现, 我们省略原型中大部分函数的说明. 有两个构造函数需要特别提及:

mpi_process_group(communicator_type comm = communicator_type());

该构造函数可以接受一个可选的 MPI 通信器. 默认使用由 MPI_COMM_WORLD 构造的通信器.

mpi_process_group(std::size_t num_headers, std::size_t buffer_size,
                  communicator_type comm = communicator_type());

为了进行性能微调, 可以指定一个消息批量 (batch) 中最大的头数量 (num_headers) 以及批量消息的最大合计大小 (buffer_size). 一个批量的最大消息大小为 16*num_headers+buffer_size. 通过在以太网网络的集群上优化一个典型应用, 找到了合理的默认值: num_header=64k 与 buffer_size=1MB, 批量消息最大总大小为 2MB.
