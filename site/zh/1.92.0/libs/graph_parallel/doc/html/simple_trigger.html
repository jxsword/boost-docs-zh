引言

进程组 接口中的触发器用于异步接收并处理发往分布式数据结构的消息. 触发器接口相当灵活, 允许附加任何函数对象来处理请求. simple_trigger 函数简化了触发器的一个常见情形: 附加一个调用分布式数据结构特定成员函数的触发器.

定义位置

头文件 <boost/graph/parallel/simple_trigger.hpp>

参考

template<typename ProcessGroup, typename Class, typename T>
  void
  simple_trigger(ProcessGroup& pg, int tag, Class* self,
                 void (Class::*pmf)(int source, int tag, const T& data,
                                    trigger_receive_context context))

template<typename ProcessGroup, typename Class, typename T, typename Result>
  void
  simple_trigger(ProcessGroup& pg, int tag, Class* self,
                 Result (Class::*pmf)(int source, int tag, const T& data,
                                      trigger_receive_context context))

simple_trigger 函数注册一个触发器, 每当收到消息时, 该触发器就在对象 self 上调用给定的成员函数 (pmf). 如果该成员函数有返回值, 则该触发器带有回复, 只能通过期待回复的带外发送来使用. 否则, 该成员函数返回 void, 此函数将把它注册为普通触发器.
