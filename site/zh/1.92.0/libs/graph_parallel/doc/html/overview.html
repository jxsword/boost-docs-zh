Parallel Boost Graph Library 概览

Parallel Boost Graph Library (Parallel BGL) 是一个用于图上并行分布式计算的 C++ 库. Parallel BGL 包含分布式图数据结构、分布式图算法、对通信媒介 (如 MPI) 的抽象以及支持性数据结构. 图 (也称 网络) 由一组 顶点 与顶点之间的一组关系组成, 这些关系称为 边. 边可以是 无向 的, 即顶点之间的关系是相互的, 例如 "X 与 Y 相关"; 也可以是 有向 的, 即关系只沿一个方向, 例如 "X 是 Y 的孩子". 下图展示了一个典型的有向图, 其中 a-i 是顶点, 箭头表示边.

Parallel BGL 主要关注 分布式 图. 分布式图在概念上是图, 但其存储分布在多个处理器上. 下图展示了上图的一个分布式版本, 其中图被划分到三个处理器上 (由灰色矩形表示). 图中的边可以是本地的 (两个端点存储在同一处理器上) 或远程的 (边的目标点存储在另一处理器上).

Parallel BGL 是一个泛型库. 其核心是 泛型 的分布式图算法, 只要图数据结构满足某些要求, 这些算法就可以在其上运作. 例如, 算法可能需要枚举当前处理器上存储的顶点集合、枚举某一特定顶点的出边集合, 以及确定每条边的目标点驻留在哪个处理器上. Parallel BGL 中的图算法对于附加到图中边与顶点上的 属性 也是泛型的; 例如, 每条边的权重可以作为图的一部分存储, 也可以分配在完全独立的数据结构中.

Parallel BGL 算法所具备的泛型性使它们能够应用于既有的图数据结构. 然而, 大多数用户会改为编写利用 Parallel BGL 的新代码. Parallel BGL 提供满足其算法要求的分布式图数据结构. 主要的数据结构是 分布式邻接表, 它允许存储与操作一个 (分布式) 图. 图中的顶点被划分到各个处理器上, 从某个顶点出发的每条边都存储在 "拥有" (存储) 该顶点的处理器上. 下图展示了分布式邻接表的表示.

分布式邻接表 把图的结构分布到多个处理器上. 虽然图结构是许多图问题的重要组成部分, 但通常还有其他属性附加在顶点与边上, 例如边权重或顶点在网格中的位置. 这些属性存储在 属性映射 中, 后者把单条数据与图中的每条边或每个顶点相关联. 分布式属性映射把这一概念扩展到分布式计算: 属性存储在与顶点或边相同的处理器上. 下图展示了一个为每个顶点存储颜色 (白、灰、黑) 的属性映射的分布. 除了每个顶点的存储之外, 处理器还存储一些 "幽灵单元", 它们缓存实际存储在其他处理器上的值, 由虚线框表示.

把 Parallel BGL 的所有分布式数据结构联系在一起的是它的进程组与分布式图算法. 进程组通过抽象通信机制来协调多个进程与分布式数据结构之间的交互. 算法通常使用 SPMD 模型 (单程序多数据) 编写, 并同时与分布式数据结构及进程组本身交互. 在算法执行的不同时点, 所有进程执行一个同步点, 这使得所有分布式数据结构能够确保跨进程的适当一致性程度. 下图展示了 Parallel BGL 中分布式算法执行过程中的通信模式. 特别地, 该图展示了一次分布式广度优先搜索中使用的分布式数据结构, 从左上角开始按顺时针方向依次为:

  • 一个用户定义的属性映射, 跟踪从源顶点到所有其他顶点的距离;
  • 一个自动生成的属性映射, 跟踪 (分布式) 图中顶点的 "颜色", 以确定哪些顶点之前已被访问过;
  • 一个分布式队列, 它协调广度优先搜索并分发待搜索的新顶点; 以及
  • 一个分布式图, 广度优先搜索即在其上进行.
