distributedS 分布选择器

Boost Graph Library 的类模板 adjacency_list 支持若干选择器, 用于指示应使用何种数据结构存储边或顶点. 例如, 选择器 vecS 表示存储于 std::vector, 而 listS 表示存储于 std::list. Parallel BGL 的 分布式邻接表 额外支持一个选择器 distributedS, 它表示存储应分布在多个进程上. 该选择器可以把顺序邻接表转换为分布式邻接表.

template<typename ProcessGroup, typename LocalSelector = vecS>
struct distributedS;

模板参数

ProcessGroup:
属性映射所分布其上的进程组的类型, 同时也是通信的媒介. 该类型必须对 进程组 概念建模, 但某些数据结构可能对该参数提出额外要求.
LocalSelector:
一个选择器类型 (例如 vecS), 指示每个进程中顶点或边应如何存储.
