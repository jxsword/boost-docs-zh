strong_components() 函数计算有向图的强连通分量. 分布式强连通分量算法使用 顺序强连通分量 算法来标识处理器本地的分量. 该算法的分布式部分构建在 分布式广度优先搜索 算法之上, 并基于 Fleischer、Hendrickson 与 Pinar 的工作 [FHP00]. 其接口是 BGL 顺序强连通分量 算法接口的超集. 图中强连通分量的数量会返回给所有进程.

分布式强连通分量算法既适用于 directed 图, 也适用于 bidirectional 图. 在双向情形中, 使用反向图适配器产生所需的反向图. 在有向情形中, 会构造一个所有边都被反转的单独图.

参数

IN: const Graph& g
图类型必须是 分布图 的模型. 图类型还必须对 关联图 建模, 且为有向图.
OUT: ComponentMap c
该算法计算图中有多少个强连通分量, 并为每个分量分配一个整数标签. 然后通过在分量属性映射中记录分量编号, 记录图中每个顶点属于哪个分量. ComponentMap 类型必须是 分布式属性映射. 其值类型必须是图的 vertices_size_type, 键类型必须是图的顶点描述符类型.
UTIL: VertexComponentMap r
该算法计算从每个顶点到强连通分量代表顶点的映射, 存储在此属性映射中. VertexComponentMap 类型必须是 分布式属性映射. 其值类型与键类型必须是图的顶点描述符.
IN: const ReverseGraph& gr

g 的反向图 (或转置图), 使得对每条有向边 (u, v) (位于 g 中) 存在有向边 (fr(v), fr(u)) (位于 gr 中), 且其中的每条边 (v', u') (即 gr 中) 在 (rf(u'), rf(v')) (位于 g 中) 存在对应边. 函数 fr 与 rf 把图中的顶点映射到反向图 (或反之), 它们以属性映射参数的形式表示. 对该图类型的概念要求等同于对 Graph 类型的要求, 但两者类型不必相同.

默认: 原图上的一个 reverse_graph 适配器 (如果图类型是双向的, 即对 双向图 概念建模), 或者由输入图构造的一个 分布式邻接表.

IN: IsoMapFR fr

一个属性映射, 把输入图 g 中的顶点映射到反向图 gr 中的顶点. IsoMapFR 类型必须对 可读属性映射 概念建模, 且以图的顶点描述符为键类型, 以反向图的顶点描述符为值类型.

默认: 一个恒等属性映射 (如果图类型是双向的), 或一个分布式 iterator_property_map (如果图类型是有向的).

IN: IsoMapRF rf

一个属性映射, 把反向图 gr 中的顶点映射到输入图 g 中的顶点. IsoMapRF 类型必须对 可读属性映射 概念建模, 且以反向图的顶点描述符为键类型, 以图的顶点描述符为值类型.

默认: 一个恒等属性映射 (如果图类型是双向的), 或一个分布式 iterator_property_map (如果图类型是有向的).

复杂度

算法的本地阶段为 O(V + E). 算法的并行阶段最多需要 O(V) 个超步, 每个超步包含两次广度优先搜索, 每次为 O(V + E).

算法描述

在执行算法的顺序阶段之前, 每个进程标识所有完全本地的强连通分量, 为它们加上标签, 并把它们从并行阶段所考虑的顶点集中移除.

分布式强连通分量算法的并行阶段由一系列超步组成. 每个超步以一个或多个顶点集开始, 这些顶点集保证完全包含任何剩余的强连通分量. 从每个顶点集的第一个顶点开始执行一次 分布式广度优先搜索. 所有这些广度优先搜索由每个处理器以不同的起始顶点调用 breadth_first_search() 来并行执行, 并在必要时在调用算法之前向用于广度优先搜索的 distributed queue 中插入额外的顶点. 以同样的方式在反向图上执行第二次 分布式广度优先搜索. 对每个初始顶点集, 计算后继集 (在前向广度优先搜索中到达的顶点) 与前驱集 (在后向广度优先搜索中到达的顶点). 前驱集与后继集的交集构成一个强连通分量, 并按此标记. 初始顶点集中的剩余顶点被划分为三个子集, 每个子集都保证完全包含任何剩余的强连通分量. 这三个集合是: 前驱集中不属于已识别强连通分量的顶点, 后继集中不属于该强连通分量的顶点, 以及初始顶点集中既不在前驱集也不在后继集中的剩余顶点. 一旦确定了新的顶点集, 算法即开始一个新的超步. 当没有顶点剩余时, 算法停止.

为了在稀疏图中标识小分量时提升性能, 当活跃顶点集中剩余的顶点数少于初始顶点数的给定比例时, 会使用一个过滤图适配器, 把广度优先搜索算法所见限制为活跃顶点.
