Parallel Boost Graph Library

概述

Parallel Boost Graph Library 是 Boost Graph Library (BGL) 面向并行与分布式计算的一个扩展. 它提供分布式图与图算法以利用粗粒度并行性, 并提供利用细粒度并行性的并行算法, 同时保持与 (顺序) BGL 相同的接口. 使用顺序 BGL 编写的代码应当容易用并行 BGL 并行化. 初识 Parallel BGL 的读者应阅读我们的 体系结构概述.
