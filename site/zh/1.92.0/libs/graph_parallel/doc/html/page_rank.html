PageRank

namespace graph {
  template<typename Graph, typename RankMap, typename Done>
  inline void
  page_rank(const Graph& g, RankMap rank_map, Done done,
            typename property_traits<RankMap>::value_type damping = 0.85);

  template<typename Graph, typename RankMap>
  inline void
  page_rank(const Graph& g, RankMap rank_map);
}

page_rank 算法基于有向图的连通性计算图中顶点的排名 [PBMW98]. PageRank 的思想基于网络冲浪者的随机模型: 冲浪者从某个随机网页开始, 然后要么跟随该网页上的一个链接 (从链接中随机选择), 要么跳转到一个完全不同的网页 (不必与当前页面有链接). 每个页面的 PageRank 是随机冲浪者访问该页面的概率.

参数

IN: Graph& g
图类型必须是 分布式顶点列表图 与 分布式边列表图 的模型. 图必须是有向图.
OUT: RankMap rank
保存每个顶点的排名. RankMap 类型必须对 读/写属性映射 概念建模, 并且必须是 分布式属性映射. 其键类型必须是图类型的顶点描述符, 值类型必须是浮点或有理数类型.
IN: Done done

一个决定 PageRank 算法何时应完成的函数对象. 它会接收两个参数: 排名映射与对图的引用, 并应在算法应当终止时返回 true.

默认: graph::n_iterations(20)

IN: typename property_traits<RankMap>::value_type damping

阻尼系数是网络冲浪者选择当前页面的出边链接而非跳转到随机页面的概率.

默认: 0.85

复杂度

PageRank 的每次迭代在 p 个处理器上需要 O((V + E)/p) 的时间, 并执行 O(V) 的通信. 迭代次数取决于算法的输入.
