METIS 是一组用于划分图 (以及其他用途) 的程序. Parallel BGL 可以读取 METIS 图格式与划分格式, 从而可以轻松地把经 METIS 划分的图加载到 Parallel BGL 的数据结构中.

图读取器

class metis_reader
{
 public:
  typedef std::size_t vertices_size_type;
  typedef std::size_t edges_size_type;
  typedef double vertex_weight_type;
  typedef double edge_weight_type;

  class edge_iterator;
  class edge_weight_iterator;

  metis_reader(std::istream& in);

  edge_iterator begin();
  edge_iterator end();
  edge_weight_iterator weight_begin();

  vertices_size_type num_vertices() const;
  edges_size_type num_edges() const;

  std::size_t num_vertex_weights() const;

  vertex_weight_type vertex_weight(vertices_size_type v, std::size_t n);

  bool has_edge_weights() const;
};

用法

METIS 读取器为 METIS 图文件提供迭代器接口. 该迭代器接口在即时构造 Parallel BGL 图时最为有用. 例如, 下面的代码从存储在 argv[1] 中的 METIS 图构建图 g.

std::ifstream in_graph(argv[1]);
metis_reader reader(in_graph);
Graph g(reader.begin(), reader.end(),
        reader.weight_begin(),
        reader.num_vertices());

对 begin() 与 end() 的调用返回图中边的迭代器范围; 对 weight_begin() 的调用返回一个迭代器, 它将枚举图中各边的权重. 对于分布式图, 分布将由图自动确定; 要使用 METIS 划分, 参见 划分读取器 一节.

关联类型

metis_reader::edge_iterator

一个 输入迭代器, 枚举 METIS 图中的边, 适合作 EdgeIterator 用于 adjacency_list. 该迭代器的 value_type 是一对顶点编号.

metis_reader::edge_weight_iterator

一个 输入迭代器, 枚举 METIS 图中的边权重. 该迭代器的 value_type 是 edge_weight_type. 如果 METIS 图中的边不带权重, 对该迭代器解引用的结果将始终为零.

成员函数 

metis_reader(std::istream& in);

构造一个新的 METIS 读取器, 它将从输入流 in 中获取边. 读取器将从流的最开头读取, 为此 in 必须支持定位 (seeking). 如果在初始解析 in 时遇到任何错误, 将抛出 metis_input_exception.

edge_iterator begin();

返回指向 METIS 文件中第一条边的迭代器.

edge_iterator end();

返回指向 METIS 文件中最后一条边之后位置的迭代器.

edge_weight_iterator weight_begin();

返回指向 METIS 文件中第一个边权重的迭代器. 权重迭代器应与边迭代器同步移动; 当边迭代器移动时, 边权重随之改变. 如果图中的边不带权重, 返回的权重将始终为零.

vertices_size_type num_vertices() const;

返回图中的顶点数量.

edges_size_type num_edges() const;

返回图中的边数量.

std::size_t num_vertex_weights() const;

返回附加到每个顶点的权重数量.

vertex_weight_type vertex_weight(vertices_size_type v, std::size_t n);

bool has_edge_weights() const;

当图的边带权重时返回 true, 否则返回 false. 当为 false 时, 边权重迭代器仍然有效, 但对每条边返回的权重为零.

划分读取器

class metis_distribution
{
 public:
  typedef int process_id_type;
  typedef std::size_t size_type;

  metis_distribution(std::istream& in, process_id_type my_id);

  size_type block_size(process_id_type id, size_type) const;
  process_id_type operator()(size_type n);
  size_type local(size_type n) const;
  size_type global(size_type n) const;
  size_type global(process_id_type id, size_type n) const;

 private:
  std::istream& in;
  process_id_type my_id;
  std::vector<process_id_type> vertices;
};

用法

类 metis_distribution 加载 METIS 划分文件, 并将其作为适合与 分布式邻接表 图类型一起使用的分布 (Distribution) 提供. 要使用 METIS 划分加载 METIS 图, 请对图使用 metis_reader 对象, 并对分布使用 metis_distribution 对象, 如下例所示.

std::ifstream in_graph(argv[1]);
metis_reader reader(in_graph);

std::ifstream in_partitions(argv[2]);
metis_distribution dist(in_partitions, process_id(pg));
Graph g(reader.begin(), reader.end(),
        reader.weight_begin(),
        reader.num_vertices(),
        pg,
        dist);

在此示例中, argv[1] 是图, argv[2] 是由 pmetis 生成的划分文件. dist 对象从给定的输入流中加载划分信息, 并用它来分布邻接表. 注意, 输入流必须是 METIS 划分文件格式, 且其划分所针对的进程数量必须与进程组 pg 中的进程数量相同.

成员函数 

metis_distribution(std::istream& in, process_id_type my_id);

从输入流 in 创建一个新的 METIS 分布. my_id 是当前进程在图将分布其上的进程组中的进程 ID.

size_type block_size(process_id_type id, size_type) const;

返回要存储在进程 id 中的顶点数量. 第二个参数 size_type 未被使用, 可为任意值.

process_id_type operator()(size_type n);

返回将存储编号为 n 的顶点的进程的 ID.

size_type local(size_type n) const;

返回编号为 n 的顶点在其属主进程内的本地索引.

size_type global(size_type n) const;

返回当前处理器的本地顶点 n 的全局索引.

size_type global(process_id_type id, size_type n) const;

返回进程 id 的本地顶点 n 的全局索引.
