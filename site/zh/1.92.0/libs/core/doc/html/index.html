引言

Boost.Core 库是核心工具的集合. 纳入标准是该工具组件必须:

  • 简单,
  • 被其他 Boost 库使用, 并且
  • 不依赖于除 Core 自身、Config、Assert 或 ThrowException 之外的任何其他 Boost 模块.
