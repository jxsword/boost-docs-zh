结构体模板 is_reference_wrapper

boost::is_reference_wrapper — 判断类型 T 是否为 reference_wrapper 的实例化.

概要

// In header: <boost/core/ref.hpp>

template<typename T> 
struct is_reference_wrapper {

  // public data members
  static bool value;
};

说明

若类型 T 是 reference_wrapper 的特化, 则 value 静态常量为 true.
