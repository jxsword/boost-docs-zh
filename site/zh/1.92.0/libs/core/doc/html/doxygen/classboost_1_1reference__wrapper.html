类模板 reference_wrapper

boost::reference_wrapper — 保存一个对 T 类型对象的引用.

概要

// In header: <boost/core/ref.hpp>

template<typename T> 
class reference_wrapper {
public:
  // types
  typedef T type;

  // public member functions
  explicit reference_wrapper(T &) noexcept;
  reference_wrapper(T &&) = delete;
  template<typename Y, typename = unspecified> 
    reference_wrapper(reference_wrapper< Y >) noexcept;
  operator T&() const noexcept;
  T & get() const noexcept;
  T * get_pointer() const noexcept;
};

说明

reference_wrapper 主要用于向按值获取形参的函数模板 (算法) “喂入”引用. 它提供到 T& 的隐式转换, 这通常使函数模板无需修改即可作用于引用.

reference_wrapper 公有类型

  1. typedef T type;

    类型 T.

reference_wrapper 公有成员函数

  1. explicit reference_wrapper(T & t) noexcept;

    构造一个 reference_wrapper 对象, 保存对 t 的引用.

    注释

    不抛出异常.

  2. reference_wrapper(T && t) = delete;
    注释

    从临时对象构造被禁用.

  3. template<typename Y, typename = unspecified> 
  reference_wrapper(reference_wrapper< Y > r) noexcept;

    构造一个 reference_wrapper 对象, 保存兼容的 reference_wrapper r 中所存储的引用.

    注释

    仅当 Y* 可转换为 T* 时才会启用.

    注释

    不抛出异常.

  4. operator T&() const noexcept;

    注释

    不抛出异常.

    返回:

    所存储的引用.

    		 
  5. T & get() const noexcept;

    注释

    不抛出异常.

    返回:

    所存储的引用.

    		 
  6. T * get_pointer() const noexcept;

    注释

    不抛出异常.

    返回:

    指向所存储引用所指对象的指针.
