结构体模板 unwrap_reference

boost::unwrap_reference — 在 reference_wrapper 中查找该类型.

概要

// In header: <boost/core/ref.hpp>

template<typename T> 
struct unwrap_reference {
  // types
  typedef T type;
};

说明

typedef 类型为 T::type, 若 T 是一个 reference_wrapper; 否则为 T.
