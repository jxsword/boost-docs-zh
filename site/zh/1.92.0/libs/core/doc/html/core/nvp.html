概述

头文件 <boost/core/nvp.hpp> 提供类模板 boost::nvp, 它把一个名称 (const char*) 与一个值的地址 (T*) 配成一对. 它是先前由 Boost Serialization 库提供的 NVP 类型的新实现. 该类型现位于 Core 库中, 使其他 Boost 库能够支持具名值序列化, 而无需依赖 Serialization 库.

示例

下面的代码片段展示了在成员 serialize 函数中的用法:

template<class A>
void serialize(A& archive, unsigned)
{
    archive & boost::make_nvp("x", x_) & boost::make_nvp("y", y_);
}

参考 

namespace boost {

template<class T>
class nvp {
public:
    nvp(const char* name, T& value) noexcept;

    const char* name() const noexcept;

    T& value() const noexcept;

    const T& const_value() const noexcept;
};

template<class T>
const nvp<T> make_nvp(const char* name, T& value) noexcept;

} /* boost */

#define BOOST_NVP(object) see below

构造函数

nvp(const char* name, T& value) noexcept;

把所存储的名称指针初始化为 name, 把值指针初始化为 addressof(value).

成员

const char* name() const noexcept;

返回指向名称的指针.

T& value() const noexcept;

返回对值的引用.

const T& const_value() const noexcept;

返回对值的引用.

函数

template<class T> const nvp<T> make_nvp(const char* name, T& value) noexcept;

返回 nvp<T>(name, value).

宏

#define BOOST_NVP(object) see below

展开为 boost::make_nvp(BOOST_STRINGIZE(object), object).

历史

Robert Ramey 最初在 Serialization 库中实现了 NVP. Glen Fernandes 在 Core 库中实现了这个新的 (但兼容的) 版本.
