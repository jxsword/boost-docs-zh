作者

头文件 <boost/core/null_deleter.hpp>

头文件 <boost/core/null_deleter.hpp> 定义了 boost::null_deleter 函数对象, 它可用作智能指针 (例如 unique_ptr 或 shared_ptr) 的删除器. 该删除器在释放时对传入的指针不做任何事情, 这使得它在所指对象无需释放或在别处释放时很有用.

示例 

std::shared_ptr< std::ostream > make_stream()
{
    return std::shared_ptr< std::ostream >(&std::cout, boost::null_deleter());
}
