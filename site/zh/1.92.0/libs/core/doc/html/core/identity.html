概述

头文件 <boost/functional/identity.hpp> 提供函数对象 boost::identity, 其 operator() 返回其参数. 它是 C++20 的 std::identity 的一种实现, 支持 C++03 及以上版本.

示例

它常被用作受约束算法中的默认投影 (projection).

template<class Range, class Projection = boost::identity>
void print(Range&& range, Projection projection = {});

参考 

namespace boost {

struct identity {
    using is_transparent = unspecified;

    template<class T>
    T&& operator()(T&& value) const noexcept;
};

} /* boost */

运算符

template<class T> T&& operator()(T&& value) const noexcept;

返回 std::forward<T>(value).
