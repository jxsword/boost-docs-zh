functor

头文件 <boost/core/functor.hpp>

作者

  • Andrey Semashev

头文件 <boost/core/functor.hpp>

注释

该组件要求编译器支持 C++17 或更新版本.

头文件 <boost/core/functor.hpp> 定义了 boost::core::functor 类模板, 它将模板参数中指定的原始函数包装成一个函数对象类. 该函数对象把传递给它的任何实参转发给被包装的函数, 并返回该调用的结果.

当需要函数对象类类型时, functor 封装器会很有用, 例如与诸如 std::unique_ptr 之类的智能指针配合使用的场合: 函数对象的实际逻辑已经实现为一个原始函数, 且该函数可能由第三方库提供. 由于 functor 可默认构造, 并且不在内部存储指向被包装函数的指针, 使用 functor 相比改用函数指针更不易出错, 也更高效. 例如, 使用 std::unique_ptr 时, 无需在 std::unique_ptr 构造函数中传入指向删除器函数的指针, 并且 std::unique_ptr 对象不会存储和调用指向删除器函数的指针. 使用 functor 时, 删除器函数成为 std::unique_ptr 类型的一部分, 从而避免将指针与不兼容的删除器混用.

void my_deleter(void* p);

using malloc_ptr = std::unique_ptr< char, boost::core::functor< std::free > >;
using my_ptr = std::unique_ptr< char, boost::core::functor< my_deleter > >;

my_ptr create_string(std::size_t size);
void consume_string(my_ptr&& str);

malloc_ptr ptr1(static_cast< char* >(std::malloc(size)));
// ptr1 = allocate_string(size); // error, cannot convert my_ptr to malloc_ptr
my_ptr ptr2 = create_string(size); // ok

// consume_string(std::move(ptr1)); // error, cannot convert malloc_ptr&& to my_ptr
consume_string(std::move(ptr2)); // ok

使用 functor 还有助于减小生成代码的体积. 例如, 为了避免在 std::shared_ptr 中存储和调用指向删除器函数的指针, 有人可能会倾向于像下面这样使用 lambda 函数来包装删除器函数的调用:

std::shared_ptr< int > ptr(static_cast< int* >(std::malloc(sizeof(int))), [](int* p) { std::free(p); });

问题在于, 每个 lambda 函数声明都会引入一个唯一的类型, 即使该 lambda 函数的定义与之前声明的某个 lambda 函数完全相同. 因此, 如果在程序的多个位置创建像上面那样的 std::shared_ptr 对象, 共享指针计数器的定义以及相关的代码和数据 (例如虚函数表) 将为每个实例重复一份.

用 functor 替换 lambda 函数, 即可在不牺牲可读性或效率的情况下解决此问题:

std::shared_ptr< int > ptr(static_cast< int* >(std::malloc(sizeof(int))), boost::core::functor< std::free >());

概要 

namespace boost::core {

template< auto Function >
struct functor
{
    template< typename... Args >
    decltype(auto) operator() (Args&&... args) const noexcept(...);
};

} // namespace boost::core

template< typename... Args > decltype(auto) operator() (Args&&... args) const noexcept(...);

  • 效果: return Function(std::forward< Args >(args)...).
  • 抛出: 除非调用 Function 会抛出异常, 否则不抛出任何异常.
  • 注释: 仅当 Function(std::forward< Args >(args)...) 是有效的调用表达式时, 本函数才参与重载决议.
