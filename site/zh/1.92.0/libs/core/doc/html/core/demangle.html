头文件 <boost/core/demangle.hpp>

头文件 <boost/core/demangle.hpp> 定义了几个用于还原符号名称修饰的工具.

概要 

namespace boost
{

namespace core
{
    std::string demangle( char const * name );

    char const * demangle_alloc( char const * name ) noexcept;
    void demangle_free( char const * demangled_name ) noexcept;

    class scoped_demangled_name
    {
    public:
        explicit scoped_demangled_name( char const * name ) noexcept;
        ~scoped_demangled_name() noexcept;
        char const * get() const noexcept;

        scoped_demangled_name( scoped_demangled_name const& ) = delete;
        scoped_demangled_name& operator= ( scoped_demangled_name const& ) = delete;
    };
}

}

常规接口

函数 boost::core::demangle 是获得反修饰符号名的常规方式. 它接受一个经过修饰的字符串 (例如某些实现上由 typeid(T).name() 返回的那些, 如 g++), 并返回其反修饰的、人类可读的形式. 如果反修饰失败 (例如 name 无法被解释为修饰名), 函数返回 name.

示例 
#include <boost/core/demangle.hpp>
#include <typeinfo>
#include <iostream>

template<class T> struct X
{
};

int main()
{
    char const * name = typeid( X<int> ).name();

    std::cout << name << std::endl; // prints 1XIiE
    std::cout << boost::core::demangle( name ) << std::endl; // prints X<int>
}

底层接口

在某些情况下, 可能需要更底层的接口. 例如:

  • 假设符号反修饰可能失败, 用户希望能够处理这类错误.
  • 用户需要对反修饰后的名称进行后处理 (例如移除公共命名空间), 而为完整的反修饰名称分配一个临时字符串会带来显著开销.

函数 boost::core::demangle_alloc 执行名称反修饰, 成功时返回指向带反修饰名称的字符串的指针, 否则返回 nullptr. 返回的指针必须传给 boost::core::demangle_free 以回收资源. 注意, 在某些平台上 boost::core::demangle_alloc 返回的指针可能指向 name 所表示的字符串, 因此在该指针的整个生命期内此字符串必须保持不可变.

boost::core::scoped_demangled_name 类是一个作用域守卫, 它自动完成对 boost::core::demangle_alloc (构造时) 和 boost::core::demangle_free (析构时) 的调用. 带反修饰名称的字符串可通过其 get 方法获得. 注意, 如果反修饰失败, 此方法可能返回 nullptr.

示例 
#include <boost/core/demangle.hpp>
#include <typeinfo>
#include <iostream>

template<class T> struct X
{
};

int main()
{
    char const * name = typeid( X<int> ).name();
    boost::core::scoped_demangled_name demangled( name );

    std::cout << name << std::endl; // prints 1XIiE
    std::cout << (demangled.get() ? demangled.get() : "[unknown]") << std::endl; // prints X<int>
}

致谢

core::demangle 的实现取自 boost/exception/detail/type_info.hpp, 而后者改编自 boost/units/detail/utility.hpp 和 boost/log/utility/type_info_wrapper.hpp.
