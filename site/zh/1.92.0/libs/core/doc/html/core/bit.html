bit

头文件 <boost/core/bit.hpp>

作者

  • Peter Dimov

头文件 <boost/core/bit.hpp>

头文件 <boost/core/bit.hpp> 以可移植的方式实现了 C++20 的 <bit> 头文件.

概要 

namespace boost
{
namespace core
{

// bit_cast

template<class To, class From>
To bit_cast(From const& from) noexcept;

// byteswap

template<class T>
constexpr T byteswap(T x) noexcept;

// Integral powers of 2

template<class T>
constexpr bool has_single_bit(T x) noexcept;

template<class T>
constexpr T bit_ceil(T x) noexcept;

template<class T>
constexpr T bit_floor(T x) noexcept;

template<class T>
constexpr int bit_width(T x) noexcept;

// Rotating

template<class T>
constexpr T rotl(T x, int s) noexcept;

template<class T>
constexpr T rotr(T x, int s) noexcept;

// Counting

template<class T>
constexpr int countl_zero(T x) noexcept;

template<class T>
constexpr int countl_one(T x) noexcept;

template<class T>
constexpr int countr_zero(T x) noexcept;

template<class T>
constexpr int countr_one(T x) noexcept;

template<class T>
constexpr int popcount(T x) noexcept;

// Endian

enum class endian
{
    little = see below,
    big = see below,
    native = see below
};

using endian_type = endian; // portable alias for C++03 code

} // namespace core
} // namespace boost

注释: 尽管在概要中这些函数显示为 constexpr, 但由于它们是通过编译器特定的内建函数实现的, 可移植代码通常不能依赖它们可在常量表达式语境中使用.

bit_cast

template<class To, class From> To bit_cast(From const& from) noexcept;

  • 要求: To 和 From 必须可平凡复制, 并且 sizeof(To) 必须与 sizeof(From) 相同.
  • 返回: 一个类型为 To 的值, 其存储字节复制自 from.

byteswap

template<class T> constexpr T byteswap(T x) noexcept;

  • 要求: T 必须是整数类型 (即 char, signed char, unsigned char, short, unsigned short, int, unsigned int, long, unsigned long, long long, unsigned long long) 且没有填充位.
  • 返回: x 的存储字节被反转后的值.

2 的整数次幂

template<class T> constexpr bool has_single_bit(T x) noexcept;

  • 要求: T 必须是无符号整数类型 (即 unsigned char, unsigned short, unsigned int, unsigned long, unsigned long long).
  • 返回: true 若 x 是二的整数次幂, 否则为 false. (has_single_bit(0u) 为 false.)

template<class T> constexpr T bit_ceil(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: 大于或等于 x 的最小二的整数次幂. 如果该值在 T 中不可表示, 则行为未定义.

template<class T> constexpr T bit_floor(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: 如果 x == 0, 则为 0; 否则为最大值 y 使得 has_single_bit(y) 为 true 且 y <= x.

template<class T> constexpr int bit_width(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: 如果 x == 0, 则为 0; 否则为 x 的以 2 为底的对数加一, 并舍弃任何小数部分.

Rotating

在以下描述中, N 表示 numeric_limits<T>::digits, r 表示 s % N.

template<class T> constexpr T rotl(T x, int s) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: 如果 s 为负, 则为 rotr(x, -s); 如果 r 为 0, 则为 x; 如果 r 为正, 则为 (x << r) | (x >> (N - r)).

template<class T> constexpr T rotr(T x, int s) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: 如果 s 为负, 则为 rotl(x, -s); 如果 r 为 0, 则为 x; 如果 r 为正, 则为 (x >> r) | (x << (N - r)).

Counting

template<class T> constexpr int countl_zero(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: x 的值中从最高有效 (“左”) 位起连续 0 位的数量.

template<class T> constexpr int countl_one(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: x 的值中从最高有效位起连续 1 位的数量.

template<class T> constexpr int countr_zero(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: x 的值中从最低有效 (“右”) 位起连续 0 位的数量.

template<class T> constexpr int countr_one(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: x 的值中从最低有效位起连续 1 位的数量.

template<class T> constexpr int popcount(T x) noexcept;

  • 要求: T 必须是无符号整数类型.
  • 返回: x 的值中 1 位的数量.

Endian

在 C++11 下, endian 定义为 enum class endian, 如概要所示. 在 C++03 下, 其定义为

namespace endian
{
enum type
{
    little = see below,
    big = see below,
    native = see below
};
}

typedef endian::type endian_type;

endian::big 和 endian::little 的值互不相同. endian::native 在大端平台上等于 endian::big 在小端平台上等于 endian::little, 而在既非大端也非小端的平台上则是一个不同的值.

注意不要依赖 little 和 big 具有任何特定值, 因为 C++20 标准将它们留为未指定.
