serialization

头文件 <boost/core/serialization.hpp>

作者

  • Peter Dimov

头文件 <boost/core/serialization.hpp>

头文件 <boost/core/serialization.hpp> 提供了实现 Boost.Serialization 支持所必需的原语, 而无需包含 Boost.Serialization 头文件, 从而避免库依赖于 Boost.Serialization.

概要 

#include <boost/core/nvp.hpp>

namespace boost
{
namespace serialization
{

// forward declarations

template<class T> struct version;
class access;

// core_version_type

struct core_version_type;

} // namespace serialization

namespace core
{

// nvp

using serialization::nvp;
using serialization::make_nvp;

// split_free

template<class Ar, class T> void split_free( Ar& ar, T& t, unsigned int v );

// split_member

template<class Ar, class T> void split_member( Ar& ar, T& t, unsigned int v );

// load_construct_data_adl

template<class Ar, class T> void load_construct_data_adl( Ar& ar, T* t, unsigned int v );

// save_construct_data_adl

template<class Ar, class T> void save_construct_data_adl( Ar& ar, T const* t, unsigned int v );

} // namespace core
} // namespace boost

core_version_type 

struct core_version_type
{
    unsigned int version_;

    core_version_type( unsigned int version ): version_( version ) {}
    operator unsigned int () const { return version_; }
};

core_version_type 是 boost::serialization::version_type 的 Core 重实现, 调用 ADL 序列化原语时需要它, 例如下文的 load_construct_data.

它定义在 serialization 命名空间而非 core 命名空间中, 因为其唯一目的是把 boost::serialization 加入相应调用的关联命名空间列表中.

split_free

template<class Ar, class T> inline void split_free( Ar& ar, T& t, unsigned int v );

boost::core::split_free 是 boost::serialization::split_free 的 Core 重实现.

  • 效果:
    • 若 Ar::is_saving::value 为 true, 则调用 save( ar, t, core_version_type( v ) );
    • 否则, 调用 load( ar, t, core_version_type( v ) ).

split_member

template<class Ar, class T> void split_member( Ar& ar, T& t, unsigned int v );

boost::core::split_member 是 boost::serialization::split_member 的 Core 重实现.

  • 效果:
    • 若 Ar::is_saving::value 为 true, 则调用 t.save( ar, v );
    • 否则, 调用 t.load( ar, v ).

load_construct_data_adl

template<class Ar, class T> void load_construct_data_adl( Ar& ar, T* t, unsigned int v );

boost::core::load_construct_data_adl 是 boost::serialization::load_construct_data_adl 的 Core 重实现.

  • 效果: load_construct_data( ar, t, serialization::core_version_type( v ) );.

save_construct_data_adl

template<class Ar, class T> void save_construct_data_adl( Ar& ar, T const* t, unsigned int v );

boost::core::save_construct_data_adl 是 boost::serialization::save_construct_data_adl 的 Core 重实现.

  • 效果: save_construct_data( ar, t, serialization::core_version_type( v ) );.
