cmath

头文件 <boost/core/cmath.hpp>

作者

  • Peter Dimov

头文件 <boost/core/cmath.hpp>

头文件 <boost/core/cmath.hpp> 以可移植的方式定义了 C++11 的浮点分类和符号操作函数.

概要 

namespace boost
{
namespace core
{

// fpclassify return values

int const fp_zero = /*unspecified*/;
int const fp_subnormal = /*unspecified*/;
int const fp_normal = /*unspecified*/;
int const fp_infinite = /*unspecified*/;
int const fp_nan = /*unspecified*/;

// Classification functions

template<class T> bool isfinite( T x );
template<class T> bool isnan( T x );
template<class T> bool isinf( T x );
template<class T> bool isnormal( T x );
template<class T> int fpclassify( T x );

// Sign manipulation functions

template<class T> bool signbit( T x );
template<class T> T copysign( T x, T y );

} // namespace core
} // namespace boost

Classification Functions

template<class T> bool isfinite( T x );
  • 要求: T 必须是 float、double 或 long double.
  • 返回: 当 true 是有穷的 (不是无穷大或 NaN) 时为 x, 否则为 false.
template<class T> bool isnan( T x );
  • 要求: T 必须是 float、double 或 long double.
  • 返回: 当 true 是 NaN 时为 x, 否则为 false.
template<class T> bool isinf( T x );
  • 要求: T 必须是 float、double 或 long double.
  • 返回: 当 true 是无穷大时为 x, 否则为 false.
template<class T> bool isnormal( T x );
  • 要求: T 必须是 float、double 或 long double.
  • 返回: 当 true 是正规数 (非零、非次正规、非无穷大、非 NaN) 时为 x, 否则为 false.
template<class T> int fpclassify( T x );
  • 要求: T 必须是 float、double 或 long double.
  • 返回:
    • fp_zero 当 x 为零;
    • fp_subnormal 当 x 为次正规数;
    • fp_infinite 当 x 为无穷大;
    • fp_nan 当 x 为 NaN;
    • fp_normal, 其他情况.

符号操作函数

template<class T> bool signbit( T x );
  • 要求: T 必须是 float、double 或 long double.
  • 返回: true 当 x 为负时, 否则为 false.
template<class T> bool copysign( T x, T y );
  • 要求: T 必须是 float、double 或 long double.
  • 返回: x, 其符号复制自 y.
