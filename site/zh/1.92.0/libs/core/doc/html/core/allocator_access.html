概述

头文件 <boost/core/allocator_access.hpp> 提供了用于简化分配器使用的类模板和函数模板. 它提供与 C++ 标准库 std::allocator_traits 相同的功能, 但为每个分配器特性提供单独的模板.

它还添加了用于分配器感知的异常安全数组构造与销毁的附加功能.

这些设施还简化了现有的库, 避免了不得不检查 BOOST_NO_CXX11_ALLOCATOR 并有条件地使用 std::allocator_traits 的麻烦.

示例

以下示例展示了在定义分配器感知的容器类时如何使用这些工具:

template<class T, class A = boost::default_allocator<T> >
class container
    : boost::empty_value<typename boost::allocator_rebind<A, T>::type> {
public:
    typedef T value_type;
    typedef A allocator_type;
    typedef typename boost::allocator_size_type<A>::type size_type;
    typedef typename boost::allocator_difference_type<A>::type difference_type;
    typedef value_type& reference;
    typedef const value_type& const_reference;
    typedef typename boost::allocator_pointer<A>::type pointer;
    typedef typename boost::allocator_const_pointer<A>::type const_pointer;
    // ...
};

在 C++11 或更高版本中, 可以使用诸如 boost::allocator_pointer_t<A> 这样的别名来代替 typename boost::allocator_pointer<A>::type.

以下示例为数组分配存储, 数组由 n 个 T 类型的元素组成, 使用分配器 a, 并在该存储中构造 T 个元素. 如果在构造某个元素期间抛出了异常, 已构造的元素将以相反的顺序销毁.

template<class A>
auto create(A& a, std::size_t n)
{
    auto p = a.allocate(n);
    try {
        boost::allocator_construct_n(a, boost::to_address(p), n);
    } catch (...) {
        a.deallocate(p, n);
        throw;
    }
    return p;
}

类型宏

template<class A> struct allocator_value_type;

成员 type 为 A::value_type.

template<class A> struct allocator_pointer;

成员 type 在有效时为 A::pointer, 否则为 allocator_value_type_t<A>*.

template<class A> struct allocator_const_pointer;

成员 type 在有效时为 A::const_pointer, 否则为 pointer_traits<allocator_pointer_t<A> >::rebind<const allocator_value_type_t<A> >.

template<class A> struct allocator_void_pointer;

成员 type 在有效时为 A::void_pointer, 否则为 pointer_traits<allocator_pointer_t<A> >::rebind<void>.

template<class A> struct allocator_const_void_pointer;

成员 type 在有效时为 A::const_void_pointer, 否则为 pointer_traits<allocator_pointer_t<A> >::rebind<const void>.

template<class A> struct allocator_difference_type;

成员 type 在有效时为 A::difference_type, 否则为 pointer_traits<allocator_pointer_t<A> >::difference_type.

template<class A> struct allocator_size_type;

成员 type 在有效时为 A::size_type, 否则为 std::make_unsigned_t<allocator_difference_type_t<A> >.

template<class A> struct allocator_propagate_on_container_copy_assignment;

成员 type 在有效时为 A::propagate_on_container_copy_assignment, 否则为 std::false_type.

template<class A> struct allocator_propagate_on_container_move_assignment;

成员 type 在有效时为 A::propagate_on_container_move_assignment, 否则为 std::false_type.

template<class A> struct allocator_propagate_on_container_swap;

成员 type 在有效时为 A::propagate_on_container_swap, 否则为 std::false_type.

template<class A> struct allocator_is_always_equal;

成员 type 在有效时为 A::is_always_equal, 否则为 std::is_empty<A>::type.

template<class A, class T> struct allocator_rebind;

成员 type 在有效时为 A::rebind<T>::other, 否则, 当此 A<T, Args> 为 A 时为 A<U, Args>.

函数

template<class A> allocator_pointer_t<A> allocator_allocate(A& a, allocator_size_type_t<A> n);

调用a.allocate(n).

template<class A> allocator_pointer_t<A> allocator_allocate(A& a, allocator_size_type_t<A> n, allocator_const_void_pointer_t<A> hint);

在有效时调用 a.allocate(n, hint), 否则调用 a.allocate(n).

template<class A> void allocator_deallocate(A& a, allocator_pointer_t<A> p, allocator_size_type_t<A> n);

调用a.deallocate(p, n).

template<class A, class T, class... Args> void allocator_construct(A& a, T*p, Args&&... args);

在有效时调用 a.construct(p, std::forward<Args>(args)...), 否则调用 ::new(static_cast<void*>(p)) T(std::forward<Args>(args)...).

template<class A, class T> void alloc_construct_n(A& a, T* p, std::size_t n);

按顺序构造每个第 i 个元素, 方式是调用 boost::allocator_construct(a, &p[i]). 如果抛出异常, 则以相反的顺序销毁每个已构造的第 j 个元素, 方式是调用 boost::allocator_destroy(a, &p[j]).

template<class A, class T> void alloc_construct_n(A& a, T* p, std::size_t n, const T* l, std::size_t m);

按顺序构造每个第 i 个元素, 方式是调用 boost::allocator_construct(a, &p[i], l[i % m]). 如果抛出异常, 则以相反的顺序销毁每个已构造的第 j 个元素, 方式是调用 boost::allocator_destroy(a, &p[j]).

template<class A, class T, class I> void alloc_construct_n(A& a, T* p, std::size_t n, I begin);

按顺序构造每个第 i 个元素, 方式是调用 boost::allocator_construct(a, &p[i], *begin++). 如果抛出异常, 则以相反的顺序销毁每个已构造的第 j 个元素, 方式是调用 boost::allocator_destroy(a, &p[j]).

template<class A, class T> void allocator_destroy(A& a, T* p);

在有效时调用 a.destroy(p), 否则调用 p->~T().

template<class A, class T> void allocator_destroy_n(A& a, T* p, std::size_t n);

以相反的顺序销毁每个第 i 个元素, 方式是调用 boost::allocator_destroy(a, &p[i]).

template<class A> allocator_size_type_t<A> allocator_max_size(const A& a);

在有效时返回 a.max_size(), 否则返回 std::numeric_limits<allocator_size_type_t<A> >::max() / sizeof(allocator_value_type_t<A>).

template<class A> A allocator_select_on_container_copy_construction(const A& a);

在有效时返回 a.select_on_container_copy_construction(), 否则返回 a.
