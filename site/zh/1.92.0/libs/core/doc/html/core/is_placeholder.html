is_placeholder

头文件 <boost/is_placeholder.hpp>

作者

  • Peter Dimov

头文件 <boost/is_placeholder.hpp>

头文件 <boost/is_placeholder.hpp> 定义了类模板 boost::is_placeholder<T>. 它定义了一个嵌套的整型常量 value, 其值为 0, 除非 T 是 boost::bind 占位符类型 (此时取与占位符索引对应的正值).

也就是说, is_placeholder<_1>::value 为 1, is_placeholder<_2>::value 为 2, 依此类推.

is_placeholder 可针对用户类型进行特化. 如果进行了特化, boost::bind 将把这些类型识别为占位符.

概要 

namespace boost
{
    template<class T> struct is_placeholder;
}

示例 

#include <boost/is_placeholder.hpp>
#include <boost/bind.hpp>

struct arg1_type {};
constexpr arg1_type arg1{};

template<> struct boost::is_placeholder<arg1_type>
{
    static constexpr int value = 1;
};

int f( int x ) { return x + 1; }

int main()
{
    return boost::bind( f, arg1 )( -1 );
}
