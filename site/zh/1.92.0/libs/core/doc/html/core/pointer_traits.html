概述

头文件 <boost/core/pointer_traits.hpp> 提供类模板 boost::pointer_traits, 以便使用类指针类型. C++11 标准库引入了 std::pointer_traits 以及一种除普通原始指针之外还支持类指针类型的分配器模型. 本实现还支持 C++98.

它还提供函数模板 boost::to_address, 用于从任何类指针类型的对象获取原始指针.

示例

下面的示例使用分配器分配存储并在该存储中构造一个对象.

template<class Allocator>
void function(Allocator& a)
{
    auto p = a.allocate(1);
    std::allocator_traits<Allocator>::construct(a, boost::to_address(p));
}

参考 

namespace boost {

template<class T>
struct pointer_traits {
    typedef T pointer;
    typedef see below element_type;
    typedef see below difference_type;

    template<class U>
    struct rebind_to {
        typedef see below type;
    };

    template<class U>
    using rebind = typename rebind_to<U>::type;

    static pointer pointer_to(element_type& v);
};

template<class T>
struct pointer_traits<T*> {
    typedef T* pointer;
    typedef T element_type;
    typedef std::ptrdiff_t difference_type;

    template<class U>
    struct rebind_to {
        typedef U* type;
    };

    template<class U>
    using rebind = typename rebind_to<U>::type;

    static pointer pointer_to(see below v) noexcept;
};

template<class T>
constexpr T* to_address(T* v) noexcept;

template<class T>
auto to_address(const T& v) noexcept;

} // boost

概述

若成员类型 element_type 未定义, 则所有其他成员也未定义 (pointer_traits 对 SFINAE 友好).

Member types

typedef 见下文 element_type;

若存在这样的类型, 则为 T::element_type; 否则为 U, 条件是 T 是形如 Pointer<U, Args> 的类模板实例化 (其中 Args 为零个或多个类型实参); 否则该成员未定义.

typedef 见下文 difference_type;

若存在这样的类型, 则为 T::difference_type; 否则为 std::ptrdiff_t.

template<class U> struct rebind_to { typedef 见下文 type; };

type 为 T::rebind<U>, 若存在这样的类型; 否则为 Pointer<V, Args>, 条件是 T 是形如 Pointer<T, Args> 的类模板实例化 (其中 Args 为零个或多个类型实参); 否则, 该成员未定义.

注释

在不支持 C++11 模板别名时, type (针对 rebind) 为 T::rebind<U>::other, 若存在这样的类型.

Member functions

static pointer pointer_traits::pointer_to(element_type& v);

备注

若 element_type 是 void 类型, 或 T::pointer_to(v) 非良构, 则该成员未定义.

返回

指向 v 的指针, 通过调用 T::pointer_to(v) 获得.

static pointer pointer_traits<T*>::pointer_to(element_type& v) noexcept;

备注

若 element_type 是 void 类型, 则该成员未定义.

返回

addressof(v).

可选成员

static element_type* to_address(pointer v) noexcept;

返回

类型为 element_type*、引用与实参 p 相同位置的指针.

注释

该函数应是 pointer_to 的逆操作. 若定义了它, 它将定制非成员函数 to_address 的行为.

自由函数

template<class T> constexpr T* to_address(T* v) noexcept;

返回

v.

template<class T> auto to_address(const T& v) noexcept;

返回

若该表达式良构, 则为 pointer_traits<T>::to_address(v); 否则为 to_address(v.operator->()).
