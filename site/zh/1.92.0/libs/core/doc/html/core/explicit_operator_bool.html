概述

头文件 <boost/core/explicit_operator_bool.hpp> 提供 BOOST_EXPLICIT_OPERATOR_BOOL()、BOOST_EXPLICIT_OPERATOR_BOOL_NOEXCEPT() 和 BOOST_CONSTEXPR_EXPLICIT_OPERATOR_BOOL() 兼容性辅助宏, 它们展开为到 bool 的显式转换运算符. 对于不支持 C++11 引入的显式转换运算符的编译器, 这些宏展开为实现 safe bool 惯用法 的转换运算符. 如果编译器不能很好地处理 safe bool 惯用法, 这些宏则展开为到 bool 的普通转换运算符.

示例

这两个宏都应放在用户的类定义中. 生成的转换运算符将基于 operator!() 实现, 该函数应由用户在此类中定义. 对于 BOOST_CONSTEXPR_EXPLICIT_OPERATOR_BOOL(), 生成的转换运算符将被声明为 constexpr, 这要求对应的 operator!() 也为 constexpr.

template< typename T >
class my_ptr
{
    T* m_p;

public:
    BOOST_EXPLICIT_OPERATOR_BOOL()

    bool operator!() const
    {
        return !m_p;
    }
};

现在可以在条件表达式中使用 my_ptr, 类似于普通指针:

my_ptr< int > p;
if (p)
    std::cout << "true" << std::endl;

历史

  • 新增宏 BOOST_EXPLICIT_OPERATOR_BOOL_NOEXCEPT 和 BOOST_CONSTEXPR_EXPLICIT_OPERATOR_BOOL, 用于定义 noexcept 和 constexpr 运算符.
  • 该头文件已移至 Boost.Core.
