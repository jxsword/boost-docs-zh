概述

头文件 <boost/core/exchange.hpp> 提供函数模板 boost::exchange, 它是 C++14 中引入的 std::exchange 函数的一种实现. boost::exchange(o, v) 将 o 的值替换为 v, 并返回 o 的旧值.

示例

下面的示例展示了使用 boost::exchange 简化移动构造函数实现的方法.

Node(Node&& other)
  : head_(boost::exchange(other.head_, nullptr))
  , tail_(boost::exchange(other.tail_, nullptr)) { }

参考 

namespace boost {
  template<class T, class U = T>
  constexpr T exchange(T& t, U&& u);
}

函数

template<class T, class U = T> constexpr T exchange(T& t, U&& u);

等价于:

T v = std::move(t);
t = std::forward<U>(u);
return v;
