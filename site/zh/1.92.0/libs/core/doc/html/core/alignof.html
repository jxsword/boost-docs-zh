作者

头文件 <boost/core/alignof.hpp>

头文件 <boost/core/alignof.hpp> 定义了宏 BOOST_CORE_ALIGNOF, 它是 C++11 中 alignof 运算符的可移植等价物.

示例 

#include <boost/core/alignof.hpp>
#include <cstddef>

constexpr std::size_t alignment_of_double = BOOST_CORE_ALIGNOF(double);
