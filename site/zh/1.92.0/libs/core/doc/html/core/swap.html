头文件 <boost/core/invoke_swap.hpp>

template<class T> void invoke_swap(T& left, T& right) noexcept(see below);

引言

模板函数 boost::core::invoke_swap 允许交换两个变量的值, 并使用实参相关查找来选择特化的 swap 函数 (若可用). 若没有可用的特化 swap 函数, 则使用 std::swap.

设计理由

泛型 std::swap 函数要求被交换的元素可赋值且可拷贝构造. 它通常以一次拷贝构造和两次赋值来实现 (C++11 用移动取代拷贝操作) — 这往往既造成不必要的限制, 又不必要地缓慢. 此外, 泛型 swap 实现仅提供基本保证, 而特化的 swap 函数通常能够提供不抛出异常保证 (在可能的情况下这样做被视为最佳实践[1].

在这种情况下, 不使用实参相关查找的替代方案是为每个需要特化 swap 的类型提供 std::swap 的模板特化. 尽管这是合法的 C++, 但没有 Boost 库使用这种方法, 而许多 Boost 库都在自己的命名空间中提供特化的 swap 函数.

boost::core::invoke_swap 还支持交换内建数组. 注意 std::swap 最初并不这样做, 但为内建数组添加 std::swap 重载的请求已被 C++ 标准委员会接受[2].

异常安全

boost::core::invoke_swap 提供与所使用的底层 swap 函数相同的异常保证, 但有一个例外: 对于类型为 T[n] 的数组, 其中 n > 1 且 T 的底层 swap 函数提供强异常保证时, boost::core::invoke_swap 仅提供基本异常保证.

在 C++11 及更高版本中, boost::core::invoke_swap 传播与底层 swap 函数中所指定的相同的 noexcept 规格说明.

Requirements要求

满足以下条件之一:

  • T 必须可拷贝赋值 (自 C++11 起: 可移动赋值)
  • T 必须可拷贝构造 (自 C++11 起: 可移动构造)

或满足以下条件之一:

  • 可通过实参相关查找获得具有签名 swap(T&, T&) 的函数

或满足以下条件之一:

  • std::swap 存在针对 T 的模板特化

或满足以下条件之一:

  • T 是一个由可交换元素组成的内建数组

可移植性

一些较旧的编译器不支持实参相关查找. 在这些编译器上, boost::core::invoke_swap 将调用 std::swap, 忽略任何本可作为实参相关查找结果而找到的特化 swap 函数.

Credits致谢

  • Niels Dekker — 实现并记录对内建数组的支持
  • Joseph Gauterin — 提出最初构想, 并完成实现、测试和文档
  • Steven Watanabe — 提出让 boost::swap 的特化程度低于 std::swap 的构想, 从而使该函数可以名为 'swap' 而不引入歧义. 不过, 该函数后来更名为 boost::core::invoke_swap, 以避免潜在的无限递归.
