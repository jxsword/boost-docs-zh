概述

头文件 <boost/core/pointer_in_range.hpp> 提供函数模板 boost::pointer_in_range, 用于检查一个指针是否位于给定范围内. 当编译器具有支持 std::is_constant_evaluated 的内建函数时, 它可在 C++14 或更高版本的常量表达式中使用.

示例

以下是一个分配器释放函数的示例: 若指针落在一段小的自动分配缓冲区内, 则该函数不做任何事情.

template<class T, class N>
void
Allocator<T, N>::deallocate(pointer ptr, size_type)
{
    if (!boost::pointer_in_range(ptr, buffer_, buffer_ + N)) {
        ::operator delete(ptr);
    }
}

参考 

namespace boost {

template<class T>
constexpr bool pointer_in_range(const T* ptr, const T* begin, const T* end);

} /* boost */

函数

template<class T> constexpr bool pointer_in_range(const T* ptr, const T* begin, const T* end);

要求

[begin,end) 是一个有效范围.

返回

true (若 ptr 位于范围 [begin,end) 内), 否则为 false.

注释

若 boost::pointer_in_range 不能用于常量表达式, 则定义宏 BOOST_CORE_NO_CONSTEXPR_POINTER_IN_RANGE.
