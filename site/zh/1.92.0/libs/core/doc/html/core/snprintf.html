snprintf

头文件 <boost/core/snprintf.hpp>

作者

  • Andrey Semashev

头文件 <boost/core/snprintf.hpp>

头文件 <boost/core/snprintf.hpp> 提供 snprintf、vsnprintf 及其对应的 wchar_t 版本的可移植定义. 在标准库支持这些函数的平台上, 这些定义与标准函数等价. 在其他平台 (主要是较旧的 MSVC 版本) 上, 这些函数通过具有类似行为的非标准函数来模拟.

取决于标准库, 某些实现差异会暴露给用户:

  • 模拟不会隐藏字符串格式描述方面的任何非标准行为.
  • 当输出缓冲区过小时, boost::core::snprintf 的返回值可能不等于 “若缓冲区足够大时本应写入的字符数”. 但它等于或大于缓冲区大小, 这仍使调用者能够检测到缓冲区溢出的情况. 在这种情况下, 格式化输出仍会正确地以空字符结尾.
注释

与 snprintf 不同, 当输出缓冲区过小时, swprintf 不返回本应写入的字符数, 而是返回 -1. 此外, 在这种情况下, swprintf 可能会在输出缓冲区中产生字符, 也可能不会.

示例 

char buf[10];
int n = boost::core::snprintf(buf, sizeof(buf), "%d", i);
if (n < 0)
    throw std::runtime_error("Formatting error");
if (n >= sizeof(buf))
    throw std::runtime_error("Formatting buffer overflow");
