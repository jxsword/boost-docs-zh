verbose_terminate_handler

头文件 <boost/core/verbose_terminate_handler.hpp>

作者

  • Peter Dimov

头文件 <boost/core/verbose_terminate_handler.hpp>

头文件 <boost/core/verbose_terminate_handler.hpp> 定义了函数 void boost::core::verbose_terminate_handler(). 其用途是被设置为终止处理器 (terminate handler), 如下所示:

std::set_terminate( boost::core::verbose_terminate_handler );

被调用时, 该函数把关于当前未捕获异常的信息打印到 stderr, 然后调用 std::abort.

概要 

namespace boost
{
namespace core
{

[[noreturn]] void verbose_terminate_handler();

} // namespace core
} // namespace boost

示例 

#include <boost/core/verbose_terminate_handler.hpp>
#include <boost/throw_exception.hpp>
#include <exception>

int main()
{
    std::set_terminate( boost::core::verbose_terminate_handler );
    boost::throw_with_location( std::exception() );
}

输出示例:

    what(): Unknown exception
