typeinfo

头文件 <boost/core/typeinfo.hpp>

作者

  • Peter Dimov

头文件 <boost/core/typeinfo.hpp>

头文件 <boost/core/typeinfo.hpp> 定义了类 boost::core::typeinfo, 在启用 RTTI 时它是 std::type_info 的别名, 在不支持 RTTI 时则是一个合理的替代品.

宏 BOOST_CORE_TYPEID 应用于类型 T 时, 等价于 typeid(T), 并产生对 const typeinfo 对象的引用.

函数 boost::core::demangled_name 接受一个 boost::core::typeinfo const & ti, 当该字符串不需要 demangle 时返回 ti.name(), 需要时则返回 boost::core::demangle(ti.name()). boost::core::demangled_name 的返回类型在第一种情况下为 char const*, 在第二种情况下为 std::string.

概要 

namespace boost
{

namespace core
{
    class typeinfo;
    /* char const* or std::string */ demangled_name( typeinfo const & ti );
}

}

#define BOOST_CORE_TYPEID(T) /*unspecified*/

示例 

#include <boost/core/typeinfo.hpp>
#include <iostream>

template<class T1, class T2> struct X
{
};

int main()
{
    typedef X<void const*, void(*)(float)> T;

    boost::core::typeinfo const & ti = BOOST_CORE_TYPEID(T);

    std::cout << boost::core::demangled_name( ti ) << std::endl;
}
