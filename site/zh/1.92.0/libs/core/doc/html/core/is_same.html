is_same

头文件 <boost/core/is_same.hpp>

作者

  • Peter Dimov

头文件 <boost/core/is_same.hpp>

警告

该组件已弃用, 并将在未来的版本中移除. 建议用户改用 boost::is_same (来自 Boost.TypeTraits), 或改用 std::is_same —— 来自 C++ 标准库 <type_traits> 的对应设施.

头文件 <boost/core/is_same.hpp> 定义了类模板 boost::core::is_same<T1,T2>. 它定义了一个嵌套的整型常量 value, 其值为 true, 条件是 T1 与 T2 为同一类型; 否则为 false.

与 BOOST_TEST_TRAIT_TRUE 和 BOOST_TEST_TRAIT_FALSE 配合使用时, is_same 对于为必须定义特定嵌套类型的特征类编写测试很有用.

概要 

namespace boost
{

namespace core
{
    template<class T1, class T2> struct is_same;
}

}

示例 

#include <boost/core/lightweight_test_trait.hpp>
#include <boost/core/is_same.hpp>

template<class T> struct X
{
    typedef T& type;
};

using boost::core::is_same;

int main()
{
    BOOST_TEST_TRAIT_TRUE(( is_same<X<int>::type, int&> ));
    return boost::report_errors();
}
