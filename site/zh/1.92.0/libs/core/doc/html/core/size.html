size

概述
参考

作者

  • Glen Fernandes

概述

头文件 <boost/core/size.hpp> 提供函数模板 size, 用于获取范围中的元素数量.

参考 

namespace boost {

template<class C>
constexpr auto
size(const C& c) noexcept(noexcept(c.size())) -> decltype(c.size());

template<class T, std::size_t N>
constexpr std::size_t
size(T(&)[N]) noexcept;

} /* boost */

函数

template<class C> constexpr auto size(const C& c) noexcept(noexcept(c.size())) -> decltype(c.size());

返回 c.size().

template<class T, std::size_t N> constexpr std::size_t size(T(&)[N]) noexcept;

返回 N.
