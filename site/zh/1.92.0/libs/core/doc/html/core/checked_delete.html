概述

头文件 <boost/checked_delete.hpp> 定义了两个函数模板 checked_delete 和 checked_array_delete, 以及两个类模板 checked_deleter 和 checked_array_deleter.

C++ 标准在 5.3.5/5 中允许用 delete 表达式删除指向不完整类类型的指针. 当该类具有非平凡析构函数或类特定的 operator delete 时, 行为是未定义的. 一些编译器在删除不完整类型时会发出警告, 但遗憾的是并非所有编译器都会如此, 而程序员有时会忽略或禁用警告.

一个特别麻烦的情况是, 智能指针的析构函数 (例如 boost::scoped_ptr<T>::~scoped_ptr) 以不完整类型实例化时. 这常常会导致无声的、难以追踪的失败.

所提供的函数模板和类模板可用于防止这些问题, 因为它们要求完整类型, 否则会导致编译错误.

概要 

namespace boost
{
    template<class T> void checked_delete(T * p);
    template<class T> void checked_array_delete(T * p);
    template<class T> struct checked_deleter;
    template<class T> struct checked_array_deleter;
}

checked_delete

template<class T> void checked_delete(T * p);

  • 要求: T 必须是完整类型. 表达式 delete p 必须是良构的.
  • 效果: delete p;

checked_array_delete

template<class T> void checked_array_delete(T * p);

  • 要求: T 必须是完整类型. 表达式 delete [] p 必须是良构的.
  • 效果: delete [] p;

checked_deleter 

template<class T> struct checked_deleter
{
    typedef void result_type;
    typedef T * argument_type;
    void operator()(T * p) const;
};

void checked_deleter<T>::operator()(T * p) const;

  • 要求: T 必须是完整类型. 表达式 delete p 必须是良构的.
  • 效果: delete p;

checked_array_deleter 

template<class T> struct checked_array_deleter
{
    typedef void result_type;
    typedef T * argument_type;
    void operator()(T * p) const;
};

void checked_array_deleter<T>::operator()(T * p) const;

  • 要求: T 必须是完整类型. 表达式 delete [] p 必须是良构的.
  • 效果: delete [] p;
