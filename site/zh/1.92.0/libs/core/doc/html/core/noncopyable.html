noncopyable

头文件 <boost/core/noncopyable.hpp>

作者

  • Dave Abrahams

头文件 <boost/core/noncopyable.hpp>

头文件 <boost/core/noncopyable.hpp> 定义了类 boost::noncopyable. 它旨在用作私有基类. boost::noncopyable 的拷贝构造函数和拷贝赋值运算符是私有的 (C++03 下) 或被删除的 (C++11 下), 因而不能被拷贝或赋值; 派生自它的类会继承这些性质.

boost::noncopyable 最初由 Dave Abrahams 贡献.

概要 

namespace boost
{
    class noncopyable;
}

示例 

#include <boost/core/noncopyable.hpp>

class X: private boost::noncopyable
{
};

设计理由

类 noncopyable 的构造函数和析构函数成员是受保护的, 以强调它只应被用作基类. Dave Abrahams 对添加 (即使是平凡的内联) 析构函数声明可能影响编译器优化表示担忧. 他说:

“这种担忧可能并不必要, 因为 noncopyable 大多用于拥有资源、因而具有非平凡析构语义的类.”

在 C++2011 中, 可以通过声明这两者并将它们标记为 default 来强制使用优化的平凡构造函数和类似的析构函数. 当前的实现正是这样做的.
