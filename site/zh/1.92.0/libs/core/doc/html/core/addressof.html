头文件 <boost/core/addressof.hpp>

头文件 <boost/core/addressof.hpp> 定义了函数模板 boost::addressof. boost::addressof(x) 返回 x 的地址. 通常, 这个地址可以通过 &x 获得, 但一元 & 运算符可以被重载. boost::addressof 避免调用用户定义的 operator&().

boost::addressof 最初由 Brad King 基于与 Doug Gregor 讨论得出的想法贡献.

概要 

namespace boost
{
    template<class T> T* addressof( T& x );
}

示例 

#include <boost/core/addressof.hpp>

struct useless_type { };

class nonaddressable {
    useless_type operator&() const;
};

void f() {
    nonaddressable x;
    nonaddressable* xp = boost::addressof(x);
    // nonaddressable* xpe = &x; /* error */
}

注释

在 C++11 及以上版本中, boost::addressof 在可能时有条件地 constexpr. 这一点由 BOOST_CORE_NO_CONSTEXPR_ADDRESSOF 未被定义来表明.

在受支持的编译器上, boost::addressof 借助编译器内建函数总是 constexpr. 这一点由 BOOST_CORE_HAS_BUILTIN_ADDRESSOF 被定义来表明.
