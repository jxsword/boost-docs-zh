引言

Ref 库是一个小型库, 对于向通常按值获取实参副本的函数模板 (算法) 传递引用很有用. 它定义了类模板 boost::reference_wrapper<T>; 两个函数 boost::ref 和 boost::cref, 它们返回 boost::reference_wrapper<T> 的实例; 一个函数 boost::unwrap_ref, 它解包 boost::reference_wrapper<T> 或返回对任何其他类型对象的引用; 以及两个特征类 boost::is_reference_wrapper<T> 和 boost::unwrap_reference<T>.

boost::reference_wrapper<T> 的用途是保存对 T 类型对象的引用. 它主要用于向按值获取形参的函数模板 (算法) “喂入”引用.

为支持这种用法, boost::reference_wrapper<T> 提供到 T& 的隐式转换. 这通常使函数模板无需修改即可作用于引用.

boost::reference_wrapper<T> 同时可拷贝构造 (CopyConstructible) 且可赋值 (Assignable) (普通引用不可赋值).

expression boost::ref(x) 返回一个 boost::reference_wrapper<X>(x), 其中 X 是 x 的类型. 类似地, boost::cref(x) 返回一个 boost::reference_wrapper<X const>(x).

表达式 boost::unwrap_ref(x) 返回一个 boost::unwrap_reference<X>::type&, 其中 X 是 x 的类型.

表达式 boost::is_reference_wrapper<T>::value 为 true, 若 T 是一个 reference_wrapper; 否则为 false.

类型表达式 boost::unwrap_reference<T>::type 为 T::type, 若 T 是一个 reference_wrapper; 否则为 T.

参考

头文件 <boost/core/ref.hpp>

namespace boost {
  template<typename T> struct is_reference_wrapper;

  template<typename T> class reference_wrapper;

  template<typename T> struct unwrap_reference;
  template<typename T> reference_wrapper< T > const ref(T &);
  template<typename T> reference_wrapper< T const > const cref(T const &);
  template<typename T> void ref(T const &&);
  template<typename T> void cref(T const &&);
  template<typename T> unwrap_reference< T >::type & unwrap_ref(T &);
}

致谢

ref 和 cref 最初是 Jaakko Järvi 的 Tuple 库的一部分. 由于它们普遍有用, Peter Dimov 将其“提升为 boost:: 地位”. Douglas Gregor 和 Dave Abrahams 贡献了 is_reference_wrapper 和 unwrap_reference. Frank Mori Hess 和 Ronald Garcia 贡献了 boost::unwrap_ref.
