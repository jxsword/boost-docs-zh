uncaught_exceptions

头文件 <boost/core/uncaught_exceptions.hpp>

作者

  • Andrey Semashev

头文件 <boost/core/uncaught_exceptions.hpp>

头文件 <boost/core/uncaught_exceptions.hpp> 定义了 boost::core::uncaught_exceptions 函数, 它是 C++17 引入的同名函数的一个更可移植的实现. 该函数返回当前挂起异常的数量. 当该函数返回大于 0 的值时, 从析构函数抛出异常可能会终止程序.

遗憾的是, 尽管最常用的编译器都受支持, 但该函数并非能在每个 C++17 之前的编译器上实现. 当编译器不提供必要功能时, 若至少有一个异常挂起 (即不一定是挂起异常的数量), boost::core::uncaught_exceptions 会返回非零值, 并且定义了宏 BOOST_CORE_UNCAUGHT_EXCEPTIONS_EMULATED.

示例 

class my_class
{
private:
    const unsigned int m_exception_count;

public:
    my_class() : m_exception_count(boost::core::uncaught_exceptions())
    {
    }

    ~my_class() noexcept(false)
    {
        if (m_exception_count == boost::core::uncaught_exceptions())
            do_something_potentially_throwing();
    }
};
