头文件 <boost/core/ignore_unused.hpp>

头文件 <boost/core/ignore_unused.hpp> 定义了函数模板 boost::ignore_unused(). 当变量或 typedef 无法被删除或注释掉时 (例如代码的某些块被有条件地启用), 它可用于抑制 “未使用的变量 (unused variable)” 或 “未使用的局部 typedef (unused local typedefs)” 编译器警告. 若受支持, 则使用 C++11 可变参数模板, 否则以重载来模拟.

用法 

boost::ignore_unused(v1, v2, v3);
boost::ignore_unused<T1, T2, T3>();

示例 

int fun( int foo, int bar )
{
    boost::ignore_unused(bar);
#ifdef ENABLE_DEBUG_OUTPUT
    if ( foo < bar )
        std::cerr << "warning! foo < bar";
#endif
    return foo + 2;
}
