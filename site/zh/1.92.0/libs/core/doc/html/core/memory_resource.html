memory_resource

头文件 <boost/core/memory_resource.hpp>

作者

  • Peter Dimov

头文件 <boost/core/memory_resource.hpp>

头文件 <boost/core/memory_resource.hpp> 定义了类 boost::core::memory_resource, 即 C++17 中 std::pmr::memory_resource 的可移植等价物.

这并不是对标准 <memory_resource> 头文件的完整实现; 若需要完整实现, 应使用 Boost.Container. Core 之所以提供这个抽象基类, 只是为了让提供并利用 PMR 设施 (例如内存资源的具体实现, 或 polymorphic_allocator 的实现) 的 Boost 库能够互操作.

概要 

namespace boost
{
namespace core
{

class memory_resource
{
public:

    virtual ~memory_resource() = default;

    [[nodiscard]] void* allocate( std::size_t bytes, std::size_t alignment = max_align );
    void deallocate( void* p, std::size_t bytes, std::size_t alignment = max_align );

    bool is_equal( memory_resource const & other ) const noexcept;

private:

    virtual void* do_allocate( std::size_t bytes, std::size_t alignment ) = 0;
    virtual void do_deallocate( void* p, std::size_t bytes, std::size_t alignment ) = 0;

    virtual bool do_is_equal( memory_resource const& other ) const noexcept = 0;
};

inline bool operator==( memory_resource const& a, memory_resource const& b ) noexcept;
inline bool operator!=( memory_resource const& a, memory_resource const& b ) noexcept;

} // namespace core
} // namespace boost

allocate

[[nodiscard]] void* allocate( std::size_t bytes, std::size_t alignment = max_align );

  • 返回: do_allocate( bytes, alignment ).
  • 备注: 在返回的存储区域内隐式创建对象.

deallocate

void deallocate( void* p, std::size_t bytes, std::size_t alignment = max_align );

  • 效果: do_deallocate( bytes, alignment ).

is_equal

bool is_equal( memory_resource const& other ) const noexcept;

  • 返回: do_is_equal( other ).

do_allocate

void* do_allocate( std::size_t bytes, std::size_t alignment ) = 0;

  • 备注: 派生类应实现该成员函数, 以返回指向所分配存储的指针, 其大小至少为 bytes, 对齐至少为 alignment.
  • 抛出: 当无法获得具有指定大小和对齐的存储时, 抛出适当的异常 (按惯例为 std::bad_alloc 或其派生类).

do_deallocate

void do_deallocate( void* p, std::size_t bytes, std::size_t alignment ) = 0;

  • 备注: 派生类应实现该成员函数, 以释放先前由 do_allocate 分配的存储区域.
  • 抛出: 无.

do_is_equal

bool do_is_equal( memory_resource const& other ) const noexcept = 0;

  • 备注: 派生类必须实现该函数, 使其在如下情况返回 true: 从 *this 分配的内存能够从 other 释放, 反之亦然; 否则返回 false.

operator==

bool operator==( memory_resource const& a, memory_resource const& b ) noexcept;

  • 返回: &a == &b || a.is_equal( b ).

operator!=

bool operator!=( memory_resource const& a, memory_resource const& b ) noexcept;

  • 返回: !( a == b ).
