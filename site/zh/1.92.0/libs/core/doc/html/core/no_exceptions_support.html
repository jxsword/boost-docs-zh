no_exceptions_support

头文件 <boost/core/no_exceptions_support.hpp>

作者

  • Pavel Vozenilek

头文件 <boost/core/no_exceptions_support.hpp>

头文件 <boost/core/no_exceptions_support.hpp> 定义了一些宏, 用于需要可移植到不支持 C++ 异常的环境中的代码.

概要 

#define BOOST_TRY /*unspecified*/
#define BOOST_CATCH(x) /*unspecified*/
#define BOOST_CATCH_END /*unspecified*/
#define BOOST_RETHROW /*unspecified*/

用法示例 

void foo() {
  BOOST_TRY {
    ...
  } BOOST_CATCH(const std::bad_alloc&) {
      ...
      BOOST_RETHROW
  } BOOST_CATCH(const std::exception& e) {
      ...
  }
  BOOST_CATCH_END
}

在启用异常支持时, 它会展开为:

void foo() {
  { try {
    ...
  } catch (const std::bad_alloc&) {
      ...
      throw;
  } catch (const std::exception& e) {
      ...
  }
  }
}

在禁用异常支持时, 它会展开为:

void foo() {
  { if(true) {
    ...
  } else if (false) {
      ...
  } else if (false)  {
      ...
  }
  }
}
