头文件 <boost/core/lightweight_test.hpp>

头文件 <boost/core/lightweight_test.hpp> 是一个轻量级测试框架. 它对于为 Boost.Test 的依赖组件编写 Boost 回归测试很有用.

使用 lightweight_test.hpp 时, 不要忘记 调用 return boost::report_errors() (位于 main 中).

概要 

#define BOOST_TEST(expression) /*unspecified*/
#define BOOST_TEST_NOT(expression) /*unspecified*/
#define BOOST_ERROR(message) /*unspecified*/
#define BOOST_TEST_EQ(expr1, expr2) /*unspecified*/
#define BOOST_TEST_NE(expr1, expr2) /*unspecified*/
#define BOOST_TEST_LT(expr1, expr2) /*unspecified*/
#define BOOST_TEST_LE(expr1, expr2) /*unspecified*/
#define BOOST_TEST_GT(expr1, expr2) /*unspecified*/
#define BOOST_TEST_GE(expr1, expr2) /*unspecified*/
#define BOOST_TEST_CSTR_EQ(expr1, expr2) /*unspecified*/
#define BOOST_TEST_CSTR_NE(expr1, expr2) /*unspecified*/
#define BOOST_TEST_WITH(expr1, expr2, pred) /*unspecified*/
#define BOOST_TEST_ALL_EQ(begin1, end1, begin2, end2) /* unspecified */
#define BOOST_TEST_ALL_WITH(begin1, end1, begin2, end2, predicate) /* unspecified */
#define BOOST_TEST_THROWS(expr, excep) /*unspecified*/
#define BOOST_TEST_NO_THROW(expr) /*unspecified*/

namespace boost
{

int report_errors();

namespace core
{

void lwt_init();

} // namespace core
} // namespace boost

BOOST_TEST 

BOOST_TEST(expression)

若表达式为 false, 则增加错误计数, 并输出包含 expression 的消息.

BOOST_TEST_NOT 

BOOST_TEST_NOT(expression)

若表达式为 true, 则增加错误计数, 并输出包含 !(expression) 的消息.

BOOST_ERROR 

BOOST_ERROR(message)

增加错误计数, 并输出包含 message 的消息.

BOOST_TEST_EQ 

BOOST_TEST_EQ(expr1, expr2)

若 expr1 == expr2 不为 true, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_NE 

BOOST_TEST_NE(expr1, expr2)

若 expr1 != expr2 不为 true, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_LT 

BOOST_TEST_LT(expr1, expr2)

若 expr1 < expr2 不为 true, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_LE 

BOOST_TEST_LE(expr1, expr2)

若 expr1 <= expr2 不为 true, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_GT 

BOOST_TEST_GT(expr1, expr2)

若 expr1 > expr2 不为 true, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_GE 

BOOST_TEST_GE(expr1, expr2)

若 expr1 >= expr2 不为 true, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_CSTR_EQ 

BOOST_TEST_CSTR_EQ(expr1, expr2)

BOOST_TEST_EQ 的特化, 它把 expr1 和 expr2 解释为指向以空字符结尾的字节字符串 (C 字符串) 的指针. 若 std::strcmp(expr1, expr2) != 0, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_CSTR_NE 

BOOST_TEST_CSTR_NE(expr1, expr2)

BOOST_TEST_NE 的特化, 它把 expr1 和 expr2 解释为指向以空字符结尾的字节字符串 (C 字符串) 的指针. 若 std::strcmp(expr1, expr2) == 0, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_WITH 

BOOST_TEST_WITH(expr1, expr2, pred)

若 pred(expr1, expr2) 不为 true, 则增加错误计数, 并输出包含两个表达式的消息.

BOOST_TEST_ALL_EQ 

BOOST_TEST_ALL_EQ(begin1, end1, begin2, end2)

比较两个序列的内容. 若二者大小不同, 或任一对应的元素不同, 则增加错误计数, 并输出一条消息, 其中包含至多 8 个不同的元素.

BOOST_TEST_ALL_WITH 

BOOST_TEST_ALL_WITH(begin1, end1, begin2, end2, predicate)

比较两个序列的内容. 若二者大小不同, 或任一对应的元素不满足该二元谓词, 则增加错误计数, 并输出一条消息, 其中包含至多 8 个不同的元素.

BOOST_TEST_THROWS 

BOOST_TEST_THROWS(expr, excep)

若 BOOST_NO_EXCEPTIONS 未 定义, 且 expr 未抛出 excep 类型的异常, 则增加错误计数, 并输出包含该表达式的消息.

若 BOOST_NO_EXCEPTIONS 已定义, 则该宏展开为空, 且 expr 不会被求值.

BOOST_TEST_NO_THROW 

BOOST_TEST_NO_THROW(expr)

若 BOOST_NO_EXCEPTIONS 未 定义, 且 expr 抛出了异常, 则增加错误计数, 并输出包含该表达式以及 (若可能) 异常消息的消息.

若 BOOST_NO_EXCEPTIONS 已定义, 则会求值 expr.

report_errors 

int boost::report_errors()

从 main 返回错误计数.

lwt_init 

void boost::core::lwt_init()

执行一次性初始化. 它会禁用 Microsoft Windows 调试运行库在 abort 失败、assert 失败以及其他异常程序终止时所显示的交互式消息框 (以便进行无人值守的测试), 并确保在未调用 boost::report_errors 的情况下 (一个常见错误), 程序会以非零退出码结束.

lwt_init 由测试宏自动调用. 无需显式调用它, 除非测试在第一个测试宏被调用之前就因例如断言失败而失败.

示例 

#include <boost/core/lightweight_test.hpp>

int sqr( int x )
{
    return x * x;
}

int main()
{
    BOOST_TEST( sqr(2) == 4 );
    BOOST_TEST_EQ( sqr(-3), 9 );

    return boost::report_errors();
}

Header <boost/core/lightweight_test_trait.hpp>

头文件 <boost/core/lightweight_test_trait.hpp> 定义了几个额外的宏, 用于测试返回布尔值的编译期特征.

概要 

#define BOOST_TEST_TRAIT_TRUE((Trait)) /*unspecified*/
#define BOOST_TEST_TRAIT_FALSE((Trait)) /*unspecified*/
#define BOOST_TEST_TRAIT_SAME(Type1, Type2) /*unspecified*/

BOOST_TEST_TRAIT_TRUE 

BOOST_TEST_TRAIT_TRUE((Trait))

若 Trait::value != true, 则增加错误计数, 并输出包含 Trait 的消息. 注意这里有双重括号; 它们使 Trait 可以包含逗号, 这在模板中很常见.

BOOST_TEST_TRAIT_FALSE 

BOOST_TEST_TRAIT_FALSE((Trait))

若 Trait::value != false, 则增加错误计数, 并输出包含 Trait 的消息. 注意这里有双重括号.

BOOST_TEST_TRAIT_SAME 

BOOST_TEST_TRAIT_SAME(Type1, Type2)

若这两个类型不相同, 则增加错误计数, 并输出包含它们的消息. 该宏要求编译器支持可变参数宏以及 __VA_ARGS__. (注意, 与 BOOST_TEST_TRAIT_TRUE 和 BOOST_TEST_TRAIT_FALSE 不同, 该宏只需要单层括号.)

示例 

#include <boost/core/lightweight_test_trait.hpp>
#include <boost/type_traits/is_same.hpp>

template<class T, class U> struct X
{
    typedef T type;
};

using boost::is_same;

int main()
{
    BOOST_TEST_TRAIT_TRUE(( is_same<X<int, long>::type, int> ));

    BOOST_TEST_TRAIT_SAME( X<int, long>::type, int );

    return boost::report_errors();
}
