quick_exit

头文件 <boost/core/quick_exit.hpp>

作者

  • Peter Dimov

头文件 <boost/core/quick_exit.hpp>

头文件 <boost/core/quick_exit.hpp> 定义了函数 void boost::quick_exit(int code). 若可用, 它会调用标准 C++11 函数 std::quick_exit(code), 否则通过 std::_Exit(code) 或等价方式退出进程.

概要 

namespace boost
{
    [[noreturn]] void quick_exit(int code) noexcept;
}
