作者

头文件 <boost/core/fclose_deleter.hpp>

头文件 <boost/core/fclose_deleter.hpp> 定义了 boost::fclose_deleter 函数对象, 它可用作智能指针的删除器, 例如 unique_ptr 或 shared_ptr (指向 std::FILE. 结构, 由 std::fopen 调用所返回). 该删除器会对传入的指针调用 std::fclose, 从而使文件流被刷新并关闭.

示例 

std::unique_ptr< std::FILE, boost::fclose_deleter > make_file(const char* filename, const char* open_mode)
{
    return { std::fopen(filename, open_mode) };
}
