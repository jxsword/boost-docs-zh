让出原语

头文件 <boost/core/yield_primitives.hpp>

作者

  • Peter Dimov

头文件 <boost/core/yield_primitives.hpp>

头文件 <boost/core/yield_primitives.hpp> 实现了一组原语, 允许当前线程以各种方式让出 CPU.

非常底层、专门化的功能, 通常仅对实现自旋锁有用. 在应用代码中几乎总是应优先使用普通的同步原语.

概要 

namespace boost
{
namespace core
{

void sp_thread_pause() noexcept;
void sp_thread_yield() noexcept;
void sp_thread_sleep() noexcept;

} // namespace core
} // namespace boost

sp_thread_pause

void sp_thread_pause() noexcept;

发出 PAUSE 指令 (x86 上) 或 YIELD 指令 (ARM 上).

GCC 内建函数 __builtin_ia32_pause 的可移植等价物.

sp_thread_yield

void sp_thread_yield() noexcept;

告知调度器当前线程希望放弃其时间片的剩余部分.

POSIX sched_yield 的可移植等价物.

sp_thread_sleep

void sp_thread_sleep() noexcept;

休眠一小段时间, 如同以一个较小的、由实现决定的间隔 (通常为一微秒) 调用 POSIX nanosleep.

比 sp_thread_yield 更强制的让出原语, 因为即使所有其他等待线程的优先级较低, 它通常也不会被忽略.
