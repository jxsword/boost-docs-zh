function_param_limit¶

头文件¶

#include <boost/hof/function_param_limit.hpp>

说明¶

function_param_limit 元函数检索一个函数的最大参数数量. 对函数指针, 它返回参数数量. 对其他一切, 它返回 SIZE_MAX, 但这可以通过用 limit 装饰器为函数作注解来改变.

这是一个继承自 std::integral_constant 的类型特征.

概要¶

template<class F>
struct function_param_limit
: std::integral_constant<std::size_t, ...>
{};
