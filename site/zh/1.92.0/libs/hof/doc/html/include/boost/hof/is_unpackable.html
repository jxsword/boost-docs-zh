is_unpackable¶

头文件¶

#include <boost/hof/is_unpackable.hpp>

这是一个特征, 可用于检测该类型是否可以用 unpack 调用.

概要¶

template<class T>
struct is_unpackable;

示例¶

#include <boost/hof.hpp>
#include <cassert>

int main() {
    static_assert(boost::hof::is_unpackable<std::tuple<int>>::value, "Failed");
}
