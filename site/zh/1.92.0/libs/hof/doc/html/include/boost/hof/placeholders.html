placeholders¶

头文件¶

#include <boost/hof/placeholders.hpp>

说明¶

这些占位符提供与 std::bind 兼容的占位符, 并额外提供创建 bind 表达式的基本 C++ 运算符. 每个 bind 表达式支持 constexpr 函数求值.

概要¶

namespace placeholders {
    placeholder<1> _1 = {};
    placeholder<2> _2 = {};
    placeholder<3> _3 = {};
    placeholder<4> _4 = {};
    placeholder<5> _5 = {};
    placeholder<6> _6 = {};
    placeholder<7> _7 = {};
    placeholder<8> _8 = {};
    placeholder<9> _9 = {};
}

运算符¶

  • Binary operators: +,-,*,/,%,>>,<<,>,<,<=,>=,==,!=,&,^,|,&&,||

  • Assign operators: +=,-=,*=,/=,%=,>>=,<<=,&=,|=,^=

  • Unary operators: !,~,+,-,*,++,–

示例¶

#include <boost/hof.hpp>
#include <cassert>
using namespace boost::hof;

int main() {
    auto sum = _1 + _2;
    assert(3 == sum(1, 2));
}

无名占位符¶

头文件¶

#include <boost/hof/placeholders.hpp>

说明¶

无名占位符可用于从 C++ 运算符构建简单的函数.

注: 由无名占位符产生的函数不是 bind 表达式.

概要¶

namespace placeholders {
    /* unspecified */ _ = {};
}

示例¶

#include <boost/hof.hpp>
#include <cassert>
using namespace boost::hof;

int main() {
    auto sum = _ + _;
    assert(3 == sum(1, 2));
}
