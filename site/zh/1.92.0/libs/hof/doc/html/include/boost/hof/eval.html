eval¶

头文件¶

#include <boost/hof/eval.hpp>

说明¶

eval 函数会对一个 "thunk" 求值. 它可以是一个无参函数, 或者是一个以恒等函数作为第一个参数的一元函数 (这有助于延迟编译期检查). 此外, 可以向 eval 传入附加参数以延迟编译 (使结果可以依赖模板参数).

概要¶

template<class F, class... Ts>
constexpr auto eval(F&& f, Ts&&...);

要求¶

F 必须是:

  • EvaluatableFunctionObject

示例¶

#include <boost/hof.hpp>
#include <cassert>

int main() {
    assert(boost::hof::eval([]{ return 3; }) == 3);
}
