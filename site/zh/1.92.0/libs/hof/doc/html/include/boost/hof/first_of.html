first_of¶

头文件¶

#include <boost/hof/first_of.hpp>

说明¶

first_of 函数适配器把若干函数组合在一起. 若第一个函数不能被调用, 它会尝试调用下一个函数. 当使用模板约束 (如配合 enable_if) 重载函数时, 这非常有用.

注: 这不同于 match 函数适配器, 后者可能导致歧义. first_of 会调用第一个可调用的函数, 而不管是否还有其他同样可调用的函数.

概要¶

template<class... Fs>
constexpr first_of_adaptor<Fs...> first_of(Fs... fs);

要求¶

Fs 必须是:

  • ConstInvocable

  • MoveConstructible

示例¶

#include <boost/hof.hpp>
#include <iostream>
using namespace boost::hof;

struct for_ints
{
    void operator()(int) const
    {
        printf("Int\n");
    }
};

struct for_floats
{
    void operator()(float) const
    {
        printf("Float\n");
    }
};

int main() {
    first_of(for_ints(), for_floats())(3.0);
}

这将打印 Int, 因为 for_floats 函数对象永远不会被调用. 由于 C++ 的转换规则, for_ints 函数可以对 float 调用, 因此被 first_of 优先选中, 即使 for_floats 是更好的匹配.

因此, first_of_adaptor 中函数的顺序对函数如何被选中非常重要.
