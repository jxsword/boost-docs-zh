implicit¶

头文件¶

#include <boost/hof/implicit.hpp>

说明¶

implicit 适配器是一个静态函数适配器, 它使用返回值可转换到的那个类型, 来确定模板参数的类型. 本质上, 它会根据结果被赋值到的变量的类型来推导模板参数的类型. 由于它是静态函数适配器, 该函数必须是默认可构造的.

概要¶

template<template <class...> class F>
class implicit<F>;

语义¶

assert(T(implicit<F>()(xs...)) == F<T>()(xs...));

要求¶

F 必须是一个模板类, 即:

  • ConstFunctionObject

  • 可默认构造

示例¶

#include <boost/hof.hpp>
#include <cassert>
using namespace boost::hof;

template<class T>
struct auto_caster
{
    template<class U>
    T operator()(U x)
    {
        return T(x);
    }
};

static constexpr implicit<auto_caster> auto_cast = {};

struct auto_caster_foo
{
    int i;
    explicit auto_caster_foo(int i_) : i(i_) {}

};

int main() {
    float f = 1.5;
    int i = auto_cast(f);
    auto_caster_foo x = auto_cast(1);
    assert(1 == i);
    assert(1 == x.i);
}
