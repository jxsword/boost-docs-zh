mutable¶

头文件¶

#include <boost/hof/mutable.hpp>

说明¶

mutable 函数适配器允许在 const 函数对象内部使用非 const 的函数对象. 在 Fit 中, 所有函数适配器都使用 const 调用重载, 因此若某函数具有非 const 调用运算符, 就无法直接使用. 所以 mutable_ 允许该函数在调用运算符内部使用.

注: 该函数应谨慎使用, 因为许多函数会被复制, 依赖某些内部共享状态可能容易出错.

概要¶

template<class F>
mutable_adaptor<F> mutable_(F f)

要求¶

F 必须是:

  • MutableFunctionObject

  • MoveConstructible
