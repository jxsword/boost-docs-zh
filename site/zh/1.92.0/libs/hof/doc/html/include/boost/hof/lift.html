BOOST_HOF_LIFT¶

头文件¶

#include <boost/hof/lift.hpp>

说明¶

宏 BOOST_HOF_LIFT 与 BOOST_HOF_LIFT_CLASS 提供一个提升 (lift) 运算符, 它把模板函数包装进函数对象, 使其能传递给高阶函数. BOOST_HOF_LIFT 宏会用泛型 lambda 包装该函数. 因此, 它不会保留 constexpr. BOOST_HOF_LIFT_CLASS 可用于声明一个包装函数的类. 这会保留 constexpr, 且可用于尚不支持泛型 lambda 的较旧编译器.

限制¶

在 C++14 中, BOOST_HOF_LIFT 由于使用泛型 lambda 而不支持 constexpr. 作为替代, 可以使用 BOOST_HOF_LIFT_CLASS. 在 C++17 中没有这种限制.

概要¶

// Wrap the function in a generic lambda
#define BOOST_HOF_LIFT(...)

// Declare a class named `name` that will forward to the function
#define BOOST_HOF_LIFT_CLASS(name, ...)

示例¶

#include <boost/hof.hpp>
#include <cassert>
#include <algorithm>

// Declare the class `max_f`
BOOST_HOF_LIFT_CLASS(max_f, std::max);

int main() {
    auto my_max = BOOST_HOF_LIFT(std::max);
    assert(my_max(3, 4) == std::max(3, 4));
    assert(max_f()(3, 4) == std::max(3, 4));
}
