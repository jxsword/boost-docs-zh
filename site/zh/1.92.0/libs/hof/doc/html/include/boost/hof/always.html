always¶

头文件¶

#include <boost/hof/always.hpp>

说明¶

always 函数返回一个函数对象, 无论向该函数对象传入什么参数, 它总是返回给定的值. 无参版本 (即 always(void)) 将返回 void. 在不支持返回 void 的 constexpr 函数的编译器上, 会改为返回一个私有的空类型. 该返回类型指定为 BOOST_HOF_ALWAYS_VOID_RETURN.

概要¶

template<class T>
constexpr auto always(T value);

template<class T>
constexpr auto always(void);

语义¶

assert(always(x)(xs...) == x);

要求¶

T 必须是:

  • CopyConstructible

示例¶

#include <boost/hof.hpp>
#include <algorithm>
#include <cassert>
using namespace boost::hof;

int main() {
    int ten = 10;
    assert( always(ten)(1,2,3,4,5) == 10 );
}

// Count all
template<class Iterator, class T>
auto count(Iterator first, Iterator last)
{
    return std::count_if(first, last, always(true));
}
