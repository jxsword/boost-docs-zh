decay¶

头文件¶

#include <boost/hof/decay.hpp>

说明¶

decay 函数是一个一元函数对象, 它返回交给它的东西 (其类型经过衰减 decay 之后).

概要¶

struct
{
    template<class T>
    constexpr typename decay<T>::type operator()(T&& x) const
    {
        return boost::hof::forward<T>(x);
    }
} decay;
