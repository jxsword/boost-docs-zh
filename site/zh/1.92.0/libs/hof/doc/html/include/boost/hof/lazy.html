lazy¶

头文件¶

#include <boost/hof/lazy.hpp>

说明¶

lazy 函数适配器为一个函数返回函数对象调用包装器. 调用该包装器等价于调用该函数. 它是 lambda 表达式的一种简单形式, 但对 constexpr 友好. 默认情况下, lazy 按值捕获其所有变量, 就像 bind 一样. std::ref 可用于改为捕获引用.

最终, 调用 lazy(f)(x) 等价于调用 std::bind(f, x), 只是惰性版本还可以在 constexpr 上下文中调用. lazy 适配器与 std::bind 兼容, 因此大多数时候 lazy 与 std::bind 可以互换使用.

概要¶

template<class F>
constexpr lazy_adaptor<F> lazy(F f);

语义¶

assert(lazy(f)(xs...) == std::bind(f, xs...))
assert(lazy(f)(xs...)() == f(xs...))
assert(lazy(f)(_1)(x) == f(x))
assert(lazy(f)(lazy(g)(_1))(x) == f(g(x)))

要求¶

F 必须是:

  • ConstInvocable

  • MoveConstructible

示例¶

#include <boost/hof.hpp>
#include <cassert>
using namespace boost::hof;

int main() {
    auto add = [](auto x, auto y) { return x+y; };
    auto increment = lazy(add)(_1, 1);
    assert(increment(5) == 6);
}
