BOOST_HOF_STATIC_FUNCTION¶

头文件¶

#include <boost/hof/function.hpp>

说明¶

BOOST_HOF_STATIC_FUNCTION 宏允许从 constexpr 表达式初始化一个函数对象. 它采用 N4381 概述的最佳实践. 这包括使用 const 来避免全局状态, 在编译期初始化函数对象以避免 静态初始化顺序灾难, 以及让函数对象的外部地址在各个翻译单元之间相同, 以避免可能的单一定义规则 (ODR) 违例.

在 C++17 中, 这是用 inline 关键字实现的. 不过, 在较旧的编译器上, 它通过引用一个静态成员变量来初始化. 该静态成员变量是默认构造的, 因此无论表达式如何, 用户变量总是被默认构造.

默认情况下, 用 BOOST_HOF_STATIC_FUNCTION 定义的所有函数都使用 boost::hof::reveal 适配器以改进错误消息.

示例¶

#include <boost/hof.hpp>
#include <cassert>

struct sum_f
{
    template<class T, class U>
    T operator()(T x, U y) const
    {
        return x+y;
    }
};

BOOST_HOF_STATIC_FUNCTION(sum) = sum_f();
BOOST_HOF_STATIC_FUNCTION(partial_sum) = boost::hof::partial(sum_f());

int main() {
    assert(sum(1, 2) == partial_sum(1)(2));
}
