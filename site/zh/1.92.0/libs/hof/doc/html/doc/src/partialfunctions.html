部分函数求值¶

本库中的许多适配器 (如 partial 或 pipable) 支持对函数进行可选的部分求值. 例如, 若我们有 sum 函数, 并用 partial 适配器适配它:

auto sum = partial([](int x, int y)
{
    return x+y;
});

所以, 若我们写 sum(1, 2), 它会返回 3; 然而, 若我们写 sum(1), 它会返回一个新函数, 再次调用该新函数时, 它会求值该函数并返回 3:

int i = sum(1, 2); // Returns 3
auto f = sum(1);
int j = f(2); // returns 3

当然, 由于 C++ 的限制, 判断是求值函数还是部分求值, 依据的是函数的可调用性而非元数 (arity). 因此, 若我们调用 sum(1, 2, 3), 它会返回一个函数:

auto f = sum(1, 2, 3);

然而, 这可能失控, 因为函数 f 永远不会被求值. 此外, 最好能在调用函数之处产生错误, 而不是在使用部分函数时产生令人费解的错误. limit 装饰器让我们用最大元数为函数作注解:

auto sum = partial(limit_c<2>([](int x, int y)
{
    return x+y;
}));

这样, 若我们调用 sum(1, 2, 3), 就会得到编译错误. 这改善了情况, 但并非没有限制. 例如, 若我们使用 pipable 适配器定义一个三元和:

auto sum = pipable(limit_c<3>([](int x, int y, int z)
{
    return x+y+z;
}));

于是, 若我们调用 sum(1), 不会有编译错误, 直到我们尝试用管道传入一个值:

auto f = sum(1); // No error here
auto i = 2 | f; // Compile error

当然, 目标可能并不是使用可管道化调用, 而这可能导致一些令人费解的错误. 目前对此尚无好的解决方案.
