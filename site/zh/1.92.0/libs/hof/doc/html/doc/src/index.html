关于¶

HigherOrderFunctions 是一个仅头文件的 C++11/C++14 库, 为函数与函数对象提供工具, 可以用比传统元编程简单得多的构造解决许多问题.

HigherOrderFunctions 具有以下特点:

  • 现代: HigherOrderFunctions 充分利用现代 C++11/C++14 特性. 它同时支持函数的 constexpr 初始化与 constexpr 求值. 它利用类型推导、可变参数模板与完美转发, 提供简单而现代的接口.

  • 相关: HigherOrderFunctions 为函数提供工具, 而不是试图在 C++ 中实现一门函数式语言. 因此, HigherOrderFunctions 解决许多与 C++ 程序员相关的问题, 包括函数对象与 lambda 的初始化、带排序的重载、改进的返回类型推导等等.

  • 轻量: HigherOrderFunctions 在函数对象之上构建简单轻量的抽象. 它不要求你接受整个框架. 只使用你需要的部分.

HigherOrderFunctions 分为三个组件:

  • 函数适配器与装饰器: 它们为函数增加额外能力.

  • 函数: 它们返回达成特定目的的函数.

  • 工具: 这些是在定义或使用函数时有用的通用工具.

Github: https://github.com/pfultz2/higherorderfunctions/

文档: http://pfultz2.github.io/higherorderfunctions/doc/html/

动机¶

  • 提升函数的表现力与能力, 包括把函数重载集作为一等公民、扩展方法、中缀运算符等等.

  • 简化 C++ 中通常需要元编程的构造

  • 支持无点风格编程

  • 规避 C++14 中 lambda 的限制

要求¶

这要求 C++11 编译器. 没有第三方依赖. 已在 clang 3.5-3.8、gcc 4.6-7 以及 Visual Studio 2015 与 2017 上测试.

Constexpr 支持¶

MSVC 与 gcc 4.6 都因 constexpr 实现中的诸多缺陷而只有有限的 constexpr 支持. 不过, 使用 BOOST_HOF_STATIC_FUNCTION 与 BOOST_HOF_STATIC_LAMBDA_FUNCTION 构造时, 支持函数的 constexpr 初始化.

Noexcept 支持¶

在 gcc 4.6 与 gcc 4.7 等较旧编译器上, 由于其实现中的诸多缺陷, noexcept 不被使用. 此外, 大多数编译器不支持对成员函数指针推导 noexcept. 只有较新的 gcc 版本 (4.9 及以上) 支持这一点.
