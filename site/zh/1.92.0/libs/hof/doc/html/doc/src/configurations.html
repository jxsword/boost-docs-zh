配置¶

有若干配置宏控制 Boost.HigherOrderFunctions 库的行为.

名称

说明

BOOST_HOF_CHECK_UNPACK_SEQUENCE

Unpack 带有额外检查, 以确保函数将随该序列一起被调用. 该额外检查有助于改进错误报告, 但会拖慢编译. 默认启用.

BOOST_HOF_NO_EXPRESSION_SFINAE

此项控制本库是否使用表达式 SFINAE 来检测函数的可调用性. 在 MSVC 上默认启用, 因为它对表达式 SFINAE 没有完整支持.

BOOST_HOF_RECURSIVE_CONSTEXPR_DEPTH

由于 C++ 会急切地实例化 constexpr 函数, 使用 constexpr 函数的递归可能使编译器达到其内部极限. 本库使用该设置为递归深度设定上限, 以避免无限的模板实例化. 默认值为 16, 但提高该上限会增加编译时间.
