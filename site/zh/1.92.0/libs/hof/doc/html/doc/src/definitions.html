定义¶

函数适配器¶

函数适配器 接受一个 (或多个) 函数, 返回一个具有增强能力的新函数. 每个适配器都有一个函数形式, 以及对应的在末尾附加 _adaptor 的类:

template<class... Fs>
FunctionAdaptor_adaptor<Fs...> FunctionAdaptor(Fs...);

函数形式与类形式都可用于构造适配器.

静态函数适配器¶

静态函数适配器是没有函数形式的 函数适配器. 它只是一个类. 它有一个附加要求: 该函数是 DefaultConstructible 的:

template<class... Fs>
class StaticFunctionAdaptor;

装饰器¶

装饰器是返回 函数适配器 的函数. 该 函数适配器 可以是未指明的或私有的类型.

template<class... Ts>
FunctionAdaptor Decorator(Ts...);

语义¶

文档的某些部分给出某个表达式的含义 (或等价形式). 以下是这些符号的指南:

  • f、g、fs、gs、p 是函数

  • x、y、xs、ys 是函数的参数

  • T 表示某种类型

  • ... 是参数包, 表示可变参数

签名¶

除在旧编译器上需要显式模板参数的情形外, 所有函数都是全局函数对象. 不过, 文档仍展示传统签名, 因为它清晰得多. 因此, 与其这样写:

struct if_f
{
    template<class IntegralConstant>
    constexpr auto operator()(IntegralConstant) const;
};
const constexpr if_f if_ = {};

直接函数签名照原样写出, 尽管它实际上是像上面那样声明的:

template<class IntegralConstant>
constexpr auto if_(IntegralConstant);

其用法相同, 另外还有一个额外好处: 该函数可以直接传递给另一个函数.
