概念¶

ConstFunctionObject¶

是一个带有 const 调用运算符的对象:

concept ConstFunctionObject
{
    template<class... Ts>
    auto operator()(Ts&&...) const;
};

要求:¶

类型 F 满足 ConstFunctionObject, 如果

  • 类型 F 满足 std::is_object, 并且

Given

  • f, 一个类型为 const F

  • args..., 适当的实参列表, 可以为空

表达式

要求

f(args...)

执行一次函数调用

NullaryFunctionObject¶

是一个带有 const 调用运算符且不接受参数的对象:

concept NullaryFunctionObject
{
    auto operator()() const;
};

要求:¶

  • ConstFunctionObject

Given

  • f, 一个类型为 const F

表达式

要求

f()

执行一次函数调用

UnaryFunctionObject¶

是一个带有 const 调用运算符且接受一个参数的对象:

concept UnaryFunctionObject
{
    template<class T>
    auto operator()(T&&) const;
};

要求:¶

  • ConstFunctionObject

Given

  • f, 一个类型为 const F

  • arg, 单个实参

表达式

要求

f(arg)

执行一次函数调用

BinaryFunctionObject¶

是一个带有 const 调用运算符且接受两个参数的对象:

concept UnaryFunctionObject
{
    template<class T, class U>
    auto operator()(T&&, U&&) const;
};

要求:¶

  • ConstFunctionObject

Given

  • f, 一个类型为 const F

  • arg1, 单个实参

  • arg2, 单个实参

表达式

要求

f(arg1, arg2)

执行一次函数调用

EvaluatableFunctionObject¶

是一个对象, 它要么是 NullaryFunctionObject, 要么是 UnaryFuntionObject, 后者接受 identity 函数作为参数.

要求:¶

  • NullaryFunctionObject

Given

  • f, 一个类型为 const F

表达式

要求

f()

执行一次函数调用

或满足以下条件之一:

  • UnaryFuntionObject

Given

  • f, 一个类型为 const F

  • identity, 即恒等函数

表达式

要求

f(identity)

执行一次函数调用

Invocable¶

是一个可以对其应用 INVOKE 操作的对象.

要求:¶

类型 T 满足 Invocable, 如果

Given

  • f, 一个类型为 T

  • Args..., 适当的实参类型列表

以下表达式必须有效:

表达式

要求

INVOKE(f, std::declval<Args>()...)

该表达式在不求值语境中良构

其中 INVOKE(f, x, xs...) 定义如下:

  • 若 f 是指向类 U 的成员函数的指针:

    • 若 std::is_base_of<U, std::decay_t<decltype(x)>>() 为真, 则 INVOKE(f, x, xs...) 等价于 (x.*f)(xs...)

    • 否则, 若 std::decay_t<decltype(x)> 是 std::reference_wrapper 的特化, 则 INVOKE(f, x, xs...) 等价于 (x.get().*f)(xs...)

    • 否则, 若 x 不满足前面的条目, 则 INVOKE(f, x, xs...) 等价于 ((*x).*f)(xs...).

  • 否则, 若 f 是指向类 U 的数据成员的指针:

    • 若 std::is_base_of<U, std::decay_t<decltype(x)>>() 为真, 则 INVOKE(f, x) 等价于 x.*f

    • 否则, 若 std::decay_t<decltype(x)> 是 std::reference_wrapper 的特化, 则 INVOKE(f, x) 等价于 x.get().*f

    • 否则, 若 x 不满足前面的条目, 则 INVOKE(f, x) 等价于 (*x).*f

  • 否则, INVOKE(f, x, xs...) 等价于 f(x, xs...)

Metafunction¶

Given

  • f, 一个类型或模板

  • args..., 任意适当类型, 可以为空

表达式

要求

f::type

该类型是元函数的结果

f<args...>::type

该类型是元函数的结果

MetafunctionClass¶

Given

  • f, 一个类型或模板

  • args..., 任意适当类型, 可以为空

表达式

要求

f::apply::type

该类型是元函数的结果

f::apply<args...>::type

该类型是元函数的结果
