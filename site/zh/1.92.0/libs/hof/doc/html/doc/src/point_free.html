无点风格编程¶

无点风格编程 (或隐式编程) 是一种不为函数显式定义实参的风格. 函数被定义为其他函数的组合, 由函数适配器操纵函数实参. 在 C++ 中使用无点风格的优点是可以避免与函数实参相关的模板机制.

可变参数打印¶

例如, 若我们想编写一个打印每个实参的可变参数打印函数, 像这样:

print("Hello", "World");

我们可能会写出类似下面的代码, 它用可变参数模板递归地迭代实参:

// Base case
void print()
{}

template<class T, class... Ts>
void print(const T& x, const Ts&... xs)
{
    std::cout << x;
    print(xs...);
}

而用无点风格, 我们可以使用 proj 适配器来写, 它对每个实参调用一个函数. 当然, std::cout 不是函数, 但我们可以用 BOOST_HOF_LIFT 把它变成函数:

BOOST_HOF_STATIC_FUNCTION(simple_print) = BOOST_HOF_LIFT(std::ref(std::cout) << _);

这使用 placeholders 创建一个打印到 std::cout 的函数. 然后我们可以把 simple_print 传给 proj 适配器:

BOOST_HOF_STATIC_FUNCTION(print) = proj(simple_print);

由于 proj 适配器对传入的每个实参调用该函数, b(f)(x, y) 等价于先调用 f(x) 再调用 f(y). 在此例中, 它会先调用 simple_print(x) 再调用 simple_print(y):

print("Hello", "World");

这会打印出:

HelloWorld

当然, 这会把所有输出放在一起, 但我们可以通过组合进一步扩展它, 为每一项打印一个新行:

BOOST_HOF_STATIC_FUNCTION(print_lines) = proj(flow(simple_print, _ << std::integral_constant<char, '\n'>{}));

flow 适配器做函数组合, 但函数从左到右调用. 即 flow(f, g)(x) 等价于 g(f(x)). 因此在本例中, 它会先对该实参调用 simple_print (返回 std::cout), 然后把它传给下一个函数, 由后者以换行符调用流. 上面的代码中我们写 std::integral_constant<char, '\n'>{} 而不是仅写 '\n', 因为该函数是静态定义的, 所以所有值都必须静态定义.

现在调用 print_lines:

print_lines("Hello", "World");

它将打印出:

Hello
World

每个实参各占一行.

可变参数求和¶

另一个例子, 假设我们想编写 max 的可变参数版本. 我们可以这样实现:

// Base case
template<class T>
T max(const T& x)
{
    return x;
}

template<class T, class... Ts>
T max(const T& x, const T& y, const Ts&... xs)
{
    return std::max(x, max(y, xs...));
}

借助无点风格编程, 我们可以认出这是一个 折叠 (fold), 并用 fold 适配器来编写, 它会对可变参数执行折叠:

BOOST_HOF_STATIC_FUNCTION(max) = fold(BOOST_HOF_LIFT(std::max));

BOOST_HOF_LIFT 用于抓取 std::max 函数的整个重载集, 这是必需的, 因为 std::max 是模板化的, 而我们希望可变参数的 std::max 函数同样能处理任何类型. 现在可以这样调用:

auto n = max(1, 2, 4, 3); // Returns 4
auto m = max(0.1, 0.2, 0.5, 0.4); // Returns 0.5

通过使用 fold, max(1, 2, 4, 3) 将调用 std::max, 如同 std::max(std::max(std::max(1, 2), 4), 3); 而 max(0.1, 0.2, 0.5, 0.4) 将如同 std::max(std::max(std::max(0.1, 0.2), 0.5), 0.4) 那样被调用.
