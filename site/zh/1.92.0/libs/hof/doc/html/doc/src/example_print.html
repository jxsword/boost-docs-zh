打印函数¶

举例来说, 我们想编写一个打印函数. 可以从编写使用 std::cout 进行打印的函数开始, 像这样:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(print) = [](const auto& x)
{
    std::cout << x << std::endl;
};

然而, 有很多事物不能直接打印到 std::cout, 例如 std::vector 或 std::tuple. 相反, 我们希望遍历这些数据结构并打印其中的每个元素.

重载¶

Boost.HigherOrderFunctions 提供了若干种重载方式. 其中一种是用 first_of 适配器, 它会选择第一个可调用的函数. 这允许按重要性对函数排序. 于是, 第一个函数会尽可能打印到 std::cout, 否则我们增加一个打印范围的重载:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(print) = first_of(
    [](const auto& x) -> decltype(std::cout << x, void())
    {
        std::cout << x << std::endl;
    },
    [](const auto& range)
    {
        for(const auto& x:range) std::cout << x << std::endl;
    }
);

加入 -> decltype(std::cout << x, void()) 是为了约束该函数: std::cout << x 是否为有效表达式. 然后 void() 用于从函数返回 void. 这样, 现在该函数可以用 vector 调用:

std::vector<int> v = { 1, 2, 3, 4 };
print(v);

这将打印 vector 中的每个元素.

我们也可以约束第二个重载, 这对添加更多重载很重要. for 范围循环调用 begin 和 end 来迭代范围, 但我们需要一些辅助函数才能通过 ADL 查找调用 std::begin:

namespace adl {

using std::begin;

template<class R>
auto adl_begin(R&& r) BOOST_HOF_RETURNS(begin(r));
}

现在可以向第二个函数加入 -> decltype(std::cout << *adl::adl_begin(range), void()), 把它约束到范围:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(print) = first_of(
    [](const auto& x) -> decltype(std::cout << x, void())
    {
        std::cout << x << std::endl;
    },
    [](const auto& range) -> decltype(std::cout << *adl::adl_begin(range), void())
    {
        for(const auto& x:range) std::cout << x << std::endl;
    }
);

现在这样调用就能工作:

std::vector<int> v = { 1, 2, 3, 4 };
print(v);

并打印出:

1
2
3
4

元组¶

我们也可以把它扩展到打印元组. 我们需要组合几个函数来构成一个 for_each_tuple, 让我们能为每个元素调用一个函数. 首先, proj 适配器让我们把一个函数应用到传入的每个实参, 而 unpack 适配器将解包元组的元素并把它们应用到该函数:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(for_each_tuple) = [](const auto& sequence, auto f)
{
    return unpack(proj(f))(sequence);
};

现在如果我们调用:

for_each_tuple(std::make_tuple(1, 2, 3), [](auto i)
{
    std::cout << i << std::endl;
});

这将打印出:

1
2
3

我们可以通过增加一个额外重载, 把它集成到 print 函数中:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(print) = first_of(
    [](const auto& x) -> decltype(std::cout << x, void())
    {
        std::cout << x << std::endl;
    },
    [](const auto& range) -> decltype(std::cout << *adl::adl_begin(range), void())
    {
        for(const auto& x:range) std::cout << x << std::endl;
    },
    [](const auto& tuple)
    {
        for_each_tuple(tuple, [](const auto& x)
        {
            std::cout << x << std::endl;
        });
    }
);

现在我们可以用元组调用 print:

print(std::make_tuple(1, 2, 3));

它将打印出:

1
2
3

递归¶

虽然它能打印范围与元组, 但若我们把一个范围嵌套进元组, 这就不能工作了. 我们需要做的是让函数递归地调用自身. 尽管我们在使用 lambda, 我们可以用 fix 适配器轻松实现递归. 它实现了一个不动点组合子, 会把该函数 (即它自身) 作为第一个实参传入.

现在我们增加一个名为 self 的额外实参, 它就是 print 函数本身. 这个额外实参由 fix 适配器调用, 因此用户仍然用单个实参调用此函数:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(print) = fix(first_of(
    [](auto, const auto& x) -> decltype(std::cout << x, void())
    {
        std::cout << x << std::endl;
    },
    [](auto self, const auto& range) -> decltype(self(*adl::adl_begin(range)), void())
    {
        for(const auto& x:range) self(x);
    },
    [](auto self, const auto& tuple)
    {
        return for_each_tuple(tuple, self);
    }
));

这让我们能打印嵌套结构:

std::vector<int> v = { 1, 2, 3, 4 };
auto t = std::make_tuple(1, 2, 3, 4);
auto m = std::make_tuple(3, v, t);
print(m);

其输出为:

3
1
2
3
4
1
2
3
4

可变参数¶

我们还可以把 print 函数做成可变参数的, 使它打印传入的每个实参. 我们可以使用 proj 适配器, 它已经会对传入的每个实参调用该函数. 首先, 我们只是把原来的 print 函数改名为 simple_print:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(simple_print) = fix(first_of(
    [](auto, const auto& x) -> decltype(std::cout << x, void())
    {
        std::cout << x << std::endl;
    },
    [](auto self, const auto& range) -> decltype(self(*adl::adl_begin(range)), void())
    {
        for(const auto& x:range) self(x);
    },
    [](auto self, const auto& tuple)
    {
        return for_each_tuple(tuple, self);
    }
));

然后把 proj 适配器应用到 simple_print:

BOOST_HOF_STATIC_LAMBDA_FUNCTION(print) = proj(simple_print);

现在我们可以用多个实参调用 print:

print(5, "Hello world");

其输出为:

5
Hello world
