Installation

Boost.Compute 自 1.61 版起随 Boost 提供. 下载说明请访问 http://www.boost.org/users/download/.

编译与使用

Boost.Compute 是一个仅头文件库, 无需链接. 要使用该库, 只需把 include 目录加入编译标志, 并与系统的 OpenCL 库链接. 例如, 使用 GCC:

g++ -I/path/to/compute/include main.cpp -lOpenCL

所有 Boost.Compute 头文件都可通过以下指令包含:

#include <boost/compute.hpp>

如果只想包含核心 OpenCL 封装头文件 (它们对其余 Boost 部分的依赖极小), 请使用以下指令:

#include <boost/compute/core.hpp>

Boost.Compute 中的所有类与函数都位于 boost::compute 命名空间中, 可通过以下方式引入全局作用域:

using namespace boost::compute;

配置宏

Boost.Compute 提供若干可选特性, 可用以下宏进行配置.

宏

说明

BOOST_COMPUTE_DEBUG_KERNEL_COMPILATION

定义该宏后, 若 program::build() 失败, 程序源代码与构建日志将被写入 stdout.

BOOST_COMPUTE_HAVE_THREAD_LOCAL

启用 C++11 thread_local 存储说明符.

BOOST_COMPUTE_THREAD_SAFE

以线程安全模式构建 Boost.Compute. 这要求支持 C++11 thread-local storage (通过定义 BOOST_COMPUTE_HAVE_THREAD_LOCAL 宏) 或与 Boost.Thread 链接.

BOOST_COMPUTE_USE_OFFLINE_CACHE

启用离线缓存, 将已编译的二进制文件存储在磁盘上. 该选项要求与 Boost.Filesystem 和 Boost.System 链接.
