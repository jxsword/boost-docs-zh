互操作性

OpenGL

Boost.Compute 提供了许多设施来简化与其他 C 和 C++ 库的互操作, 包括 OpenGL, OpenCV, Eigen, Qt 和 VTK.

所有互操作头文件都位于 <boost/compute/interop/...> 目录中.

OpenGL

OpenGL 是 3D 图形的标准 API, 与 OpenCL 密切相关.

Boost.Compute 通过 opengl_create_shared_context() 函数提供了创建共享 OpenCL/OpenGL 上下文的简便方法. 该函数创建一个 Boost.Compute context 对象, 可用它创建与 OpenGL 内存对象 (如 VBO) 对应的 OpenCL 内存缓冲区. 这样 OpenCL 内核即可读写数据, 随后这些数据可直接用于 OpenGL 渲染.

Boost.Compute 提供了几个类来管理 OpenGL 对象并使其可被 OpenCL 访问, 包括 opengl_buffer (用于 OpenGL 内存对象) 和 opengl_texture (用于 OpenGL 纹理对象).

共享 OpenCL/OpenGL 内存对象的控制权可通过 opengl_enqueue_acquire_gl_objects() 和 opengl_enqueue_release_gl_objects() 函数在 OpenCL 与 OpenGL 之间转移.

更多信息参见 cl_khr_gl_sharing 扩展的 OpenCL 文档.
