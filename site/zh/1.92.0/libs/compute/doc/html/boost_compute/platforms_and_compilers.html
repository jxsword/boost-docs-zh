Boost.Compute 已在以下编译器上测试:

编译器

  • GCC (>= 4.6)
  • Clang (>= 3.0)
  • MSVC (>= 2010)

Boost.Compute 需要变参宏支持. 大多数现代 C++98 编译器和所有 C++11 编译器都支持变参宏.

要为 Boost.Preprocessor 显式启用变参支持, 请在编译器标志中加入 -DBOOST_PP_VARIADICS=1.

平台

  • Linux
  • Mac OSX
  • Windows

OpenCL 实现

  • NVIDIA (仅 NVIDIA GPU)
  • AMD (CPU 和 AMD GPU)
  • Intel (CPU 和 Intel GPU)
  • POCL (仅 CPU)
  • Beignet (仅 Intel GPU)
  • Apple (CPU 和 GPU)
  • Xilinx (FPGA)

如果你希望看到其他平台也受支持, 请 提交 缺陷报告.
