为何选择 OpenCL

库架构

Boost Compute 库由若干不同组件构成. 核心层在 OpenCL API 之上提供一个"瘦"C++ 封装, 其中包括管理 OpenCL 对象的类, 如 device, kernel 和 command_queue.

核心层之上是 C++ 标准库的部分实现, 提供常见容器 (如 vector<T>, array<T, N>) 以及常见算法 (如 transform() 和 sort()).

该库还提供若干"花式"迭代器 (如 transform_iterator 和 permutation_iterator), 用于增强标准算法的功能.

Boost.Compute 还提供了许多与其他 C 与 C++ 库互操作的设施. 更多信息参见 互操作性 一节.

Boost.Compute 所提供的函数、类和宏的完整列表参见 API 概述 一节.

为何选择 OpenCL

Boost.Compute 使用 OpenCL 作为其在 GPU 与多核 CPU 等并行设备上执行代码的接口.

选择 OpenCL 有以下几个原因:

  • 厂商中立、标准 C/C++, 不需要专用编译器、非标准 pragma 或编译器扩展.
  • 它不只是又一个并行库抽象层, 而是提供对底层硬件的直接访问.
  • 其运行时编译模型允许内核针对运行应用时所在的设备进行动态优化与调优, 而不是针对编译代码时所在的设备 (二者通常不是同一台机器).
  • 使用 OpenCL 使 Boost.Compute 能够直接与其他 OpenCL 库 (如 VexCL 和 OpenCV) 以及现有的 OpenCL 代码互操作.
  • Boost.Compute 提供的"瘦"C++ 封装允许用户在所提供的 API 不适用时跳出来编写自己的自定义内核.
