函数模板 copy

boost::compute::copy

概要

// In header: <boost/compute/algorithm/copy.hpp>


template<typename InputIterator, typename OutputIterator> 
  OutputIterator 
  copy(InputIterator first, InputIterator last, OutputIterator result, 
       command_queue & queue = system::default_queue(), 
       const wait_list & events = wait_list());

说明

把范围 [first, last) 中的值复制到以 result 开始的范围中.

通用的 copy() 函数可用于多种数据传输任务, 并为以下 OpenCL 函数提供标准接口:

  • clEnqueueReadBuffer()

  • clEnqueueWriteBuffer()

  • clEnqueueCopyBuffer()

与上述 OpenCL 函数不同, copy() 还可用于非连续数据结构 (如 std::list<T>) 以及"花式"迭代器 (如 transform_iterator).

例如, 把主机上一个 int 值数组复制到设备上的向量:

// array on the host
int data[] = { 1, 2, 3, 4 };

// vector on the device
boost::compute::vector<int> vec(4, context);

// copy values to the device vector
boost::compute::copy(data, data + 4, vec.begin(), queue);

copy 算法也可与标准容器 (如 std::vector<T>) 配合使用:

std::vector<int> host_vector = ...
boost::compute::vector<int> device_vector = ...

// copy from the host to the device
boost::compute::copy(
    host_vector.begin(), host_vector.end(), device_vector.begin(), queue
);

// copy from the device to the host
boost::compute::copy(
    device_vector.begin(), device_vector.end(), host_vector.begin(), queue
);

空间复杂度: \Omega(1)

参见: copy_n(), copy_if(), copy_async()

参数:

first

要复制范围的第一个元素

last

要复制范围的最后一个元素

result

结果范围的第一个元素

queue

执行操作的命令队列

返回:

OutputIterator, 指向结果范围的末尾
