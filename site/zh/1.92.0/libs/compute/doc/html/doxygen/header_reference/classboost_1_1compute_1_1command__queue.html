说明

命令队列提供与计算设备交互的接口. command_queue 类提供在计算设备与外部之间复制数据以及执行计算内核的方法.

命令队列在计算上下文中为某个计算设备而创建.

例如, 为系统上的默认设备创建上下文与命令队列 (这是几乎所有 OpenCL 程序都会使用的常规初始化代码):

#include <boost/compute/core.hpp>

// get the default compute device
boost::compute::device device = boost::compute::system::default_device();

// set up a compute context and command queue
boost::compute::context context(device);
boost::compute::command_queue queue(context, device);

系统的默认命令队列可通过 system::default_queue() 方法获得.

  69. event enqueue_svm_migrate_memory(const std::vector< const void * > & svm_ptrs, 
                                 const std::vector< size_t > & sizes, 
                                 const cl_mem_migration_flags flags = 0, 
                                 const wait_list & events = wait_list());

    入队一个命令, 指明一组 SVM 分配范围应与哪个设备关联. svm_ptrs[i] 与 sizes[i] 这一对共同定义要迁移范围的起始地址与字节数.

    若 sizes 为空, 则表示每个包含任一 svm_ptrs[i] 的分配都要被迁移. 另外, 若 sizes[i] 为零, 则包含 svm_ptrs[i] 的整个分配都会被迁移.

    仅当 OpenCL 版本为 2.1 或更高时, 此方法才可用.
