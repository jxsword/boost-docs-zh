函数模板 merge

boost::compute::merge

概要

// In header: <boost/compute/algorithm/merge.hpp>


template<typename InputIterator1, typename InputIterator2, 
         typename OutputIterator, typename Compare> 
  OutputIterator 
  merge(InputIterator1 first1, InputIterator1 last1, InputIterator2 first2, 
        InputIterator2 last2, OutputIterator result, Compare comp, 
        command_queue & queue = system::default_queue());

说明

合并范围 [first1, last1) 与范围 [first2, last2) 中的有序值, 并把结果存储到以 result 开始的范围中. 值的比较使用 comp 函数. 若未给出比较函数, 则使用 less.

空间复杂度: \Omega(distance(first1, last1) + distance(first2, last2))

参见: inplace_merge()

参数:

first1

要合并的第一个范围的第一个元素

last1

要合并的第一个范围的最后一个元素

first2

要合并的第二个范围的第一个元素

last2

要合并的第二个范围的最后一个元素

result

结果范围的第一个元素

comp

比较函数 (默认为 less)

queue

执行操作的命令队列

返回:

OutputIterator, 指向结果范围的末尾
