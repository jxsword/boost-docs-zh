函数模板 unique

boost::compute::unique

概要

// In header: <boost/compute/algorithm/unique.hpp>


template<typename InputIterator, typename BinaryPredicate> 
  InputIterator 
  unique(InputIterator first, InputIterator last, BinaryPredicate op, 
         command_queue & queue = system::default_queue());

说明

从范围 [first, last) 中移除所有相邻的重复元素 (由 op 判定). 如果未提供 op, 则使用相等运算符.

空间复杂度: \Omega(4n)

参见: unique_copy()

参数:

first

输入范围的第一个元素

last

输入范围的最后一个元素

op

用于检查唯一性的二元运算符

queue

执行操作的命令队列

返回:

InputIterator, 指向范围新的逻辑末尾
