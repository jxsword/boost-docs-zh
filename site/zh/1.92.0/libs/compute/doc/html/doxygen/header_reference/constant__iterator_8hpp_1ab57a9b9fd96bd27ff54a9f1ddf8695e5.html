函数模板 make_constant_iterator

boost::compute::make_constant_iterator

概要

// In header: <boost/compute/iterator/constant_iterator.hpp>


template<typename T> 
  constant_iterator< T > 
  make_constant_iterator(const T & value, size_t index = 0);

说明

返回一个新的 constant_iterator, 值为 value 且索引为 index.

参数:

value

常量值

index

迭代器的索引

返回:

一个 constant_iterator, 值为 value
