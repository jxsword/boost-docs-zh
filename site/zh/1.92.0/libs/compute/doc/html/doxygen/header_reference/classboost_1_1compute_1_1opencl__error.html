类 opencl_error

boost::compute::opencl_error — 运行期 OpenCL 错误.

概要

// In header: <boost/compute/exception/opencl_error.hpp>


class opencl_error : public std::exception {
public:

  // public member functions
  explicit opencl_error(cl_int);
  ~opencl_error();
  cl_int error_code() const;
  std::string error_string() const;
  const char * what() const;

  // public static functions
  static std::string to_string(cl_int);
};

说明

opencl_error 类表示从 OpenCL 函数返回的错误.

参见: context_error

opencl_error 公有成员函数

  1. explicit opencl_error(cl_int error);
    创建一个新的 opencl_error 异常对象, 对应 error.
  2. ~opencl_error();
    销毁 opencl_error 对象.
  3. cl_int error_code() const;
    返回数值型错误码.
  4. std::string error_string() const;
    返回错误的字符串描述.
  5. const char * what() const;
    返回错误的 C 字符串描述.

opencl_error 公有静态函数

  1. static std::string to_string(cl_int error);

    静态函数, 把数值型 OpenCL 错误码 error 转换为人类可读的字符串.

    例如:

    std::cout << opencl_error::to_string(CL_INVALID_KERNEL_ARGS) << std::endl;

    将打印 "Invalid Kernel Arguments".

    若错误码未知 (例如不是有效的 OpenCL 错误), 则返回一个包含 "Unknown OpenCL Error" 与错误编号的字符串.
