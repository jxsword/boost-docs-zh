函数模板 partition_point

boost::compute::partition_point — partition_point 算法.

概要

// In header: <boost/compute/algorithm/partition_point.hpp>


template<typename InputIterator, typename UnaryPredicate> 
  InputIterator 
  partition_point(InputIterator first, InputIterator last, 
                  UnaryPredicate predicate, 
                  command_queue & queue = system::default_queue());

说明

在已划分范围 [first, last) 中查找 true 值的结尾. 空间复杂度: \Omega(1)

参见: partition() and stable_partition()

参数:

first

指向范围起始处的迭代器

last

指向范围结尾处的迭代器

predicate

应用于每个元素的一元谓词

queue

用于执行的队列

返回:

指向 true 值结尾处的迭代器
