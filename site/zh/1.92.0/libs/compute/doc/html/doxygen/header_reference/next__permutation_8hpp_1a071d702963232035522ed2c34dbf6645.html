函数模板 next_permutation

boost::compute::next_permutation — 置换生成算法.

概要

// In header: <boost/compute/algorithm/next_permutation.hpp>


template<typename InputIterator> 
  bool next_permutation(InputIterator first, InputIterator last, 
                        command_queue & queue = system::default_queue());

说明

把范围 [first, last) 变换为按字典序排列的所有置换中的下一个置换. 空间复杂度: \Omega(1)

参数:

first

指向范围起始处的迭代器

last

指向范围结尾处的迭代器

queue

用于执行的队列

返回:

布尔值, 表示上一个置换是否已越界且范围是否被重置
