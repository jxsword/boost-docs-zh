函数模板 search

boost::compute::search — 子串匹配算法.

概要

// In header: <boost/compute/algorithm/search.hpp>


template<typename TextIterator, typename PatternIterator> 
  TextIterator 
  search(TextIterator t_first, TextIterator t_last, PatternIterator p_first, 
         PatternIterator p_last, 
         command_queue & queue = system::default_queue());

说明

在文本 [t_first, t_last) 中搜索模式 [p_first, p_last) 的第一个匹配. 空间复杂度: \Omega(distance(t_first, t_last))

参数:

t_first

指向文本起始处的迭代器

t_last

指向文本结尾处的迭代器

p_first

指向模式起始处的迭代器

p_last

指向模式结尾处的迭代器

queue

用于执行的队列

返回:

指向首个匹配起始处的迭代器
