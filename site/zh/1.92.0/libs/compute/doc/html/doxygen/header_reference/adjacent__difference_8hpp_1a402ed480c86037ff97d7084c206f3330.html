函数模板 adjacent_difference

boost::compute::adjacent_difference

概要

// In header: <boost/compute/algorithm/adjacent_difference.hpp>


template<typename InputIterator, typename OutputIterator, 
         typename BinaryFunction> 
  OutputIterator 
  adjacent_difference(InputIterator first, InputIterator last, 
                      OutputIterator result, BinaryFunction op, 
                      command_queue & queue = system::default_queue());

说明

把范围 [first, last) 中每对相邻值的差存储到以 result 开始的范围中. 若未提供 op, 则使用 minus<T>.

空间复杂度: \Omega(1)
当 result == first: 时的空间复杂度: \Omega(n)

参见: adjacent_find()

参数:

first

输入范围的第一个元素

last

输入范围的最后一个元素

result

输出范围的第一个元素

op

二元差函数

queue

执行操作的命令队列

返回:

OutputIterator, 指向结果范围的末尾
