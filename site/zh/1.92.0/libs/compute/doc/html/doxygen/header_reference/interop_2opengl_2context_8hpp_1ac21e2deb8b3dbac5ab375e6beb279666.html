函数 opengl_create_shared_context

boost::compute::opengl_create_shared_context

概要

// In header: <boost/compute/interop/opengl/context.hpp>


context opengl_create_shared_context();

说明

为当前活动的 OpenGL 上下文创建共享 OpenCL/OpenGL 上下文.

创建之后, 共享上下文可用于创建能够与 OpenGL 内存对象 (如 VBO) 交互的 OpenCL 内存对象.

抛出:

 unsupported_extension_error, 若未找到支持 CL-GL 共享的设备.
