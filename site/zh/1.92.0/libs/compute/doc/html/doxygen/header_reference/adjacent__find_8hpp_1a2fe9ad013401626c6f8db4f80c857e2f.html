函数模板 adjacent_find

boost::compute::adjacent_find

概要

// In header: <boost/compute/algorithm/adjacent_find.hpp>


template<typename InputIterator, typename Compare> 
  InputIterator 
  adjacent_find(InputIterator first, InputIterator last, Compare compare, 
                command_queue & queue = system::default_queue());

说明

在范围 [first, last) 中搜索两个相同的相邻元素, 并返回指向第一个的迭代器.

空间复杂度: \Omega(1)

参见: find(), adjacent_difference()

参数:

first

要搜索范围的第一个元素

last

要搜索范围的最后一个元素

compare

二元比较函数

queue

执行操作的命令队列

返回:

InputIteratorm, 指向第一个与后续元素相等的元素. 若不存在相等元素, 则返回 last.
