函数模板 accumulate

boost::compute::accumulate

概要

// In header: <boost/compute/algorithm/accumulate.hpp>


template<typename InputIterator, typename T, typename BinaryFunction> 
  T accumulate(InputIterator first, InputIterator last, T init, 
               BinaryFunction function, 
               command_queue & queue = system::default_queue());

说明

返回把 function 应用到范围 [first, last) 中的元素与 init 上的结果.

若未指定函数, 将使用 plus.

在特定情形下, 对 accumulate() 的调用可被自动优化为对更高效的 reduce() 算法的调用. 当二元归约函数被识别为满足结合律时 (如 plus<int> 函数) 会发生这种优化.

注意, 由于浮点加法不满足结合律, 调用 accumulate() 并传入 plus<float> 会执行效率较低的串行归约算法. 如果可以接受轻微的精度损失, 应改用更高效的并行 reduce() 算法.

例如:

// with vec = boost::compute::vector<int>
accumulate(vec.begin(), vec.end(), 0, plus<int>());   // fast
reduce(vec.begin(), vec.end(), &result, plus<int>()); // fast

// with vec = boost::compute::vector<float>
accumulate(vec.begin(), vec.end(), 0, plus<float>());   // slow
reduce(vec.begin(), vec.end(), &result, plus<float>()); // fast

空间复杂度: \Omega(1)
优化为 reduce() 时的空间复杂度: \Omega(n)

参见: reduce()

参数:

first

输入范围的第一个元素

last

输入范围的最后一个元素

init

初始值

function

二元归约函数

queue

执行操作的命令队列

返回:

累加结果值
