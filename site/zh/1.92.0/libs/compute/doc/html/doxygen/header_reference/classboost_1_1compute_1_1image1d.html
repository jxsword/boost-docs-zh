类 image1d

boost::compute::image1d — OpenCL 一维图像对象.

概要

// In header: <boost/compute/image/image1d.hpp>


class image1d : public boost::compute::image_object {
public:

  // public member functions
  image1d();
  image1d(const context &, size_t, const image_format &, 
          cl_mem_flags = read_write, void * = 0);
  image1d(const image1d &);
  image1d & operator=(const image1d &);
  image1d(image1d &&) noexcept;
  image1d & operator=(image1d &&) noexcept;
  ~image1d();
  extents< 1 > size() const;
  extents< 1 > origin() const;
  template<typename T> T get_info(cl_image_info) const;
  template<int Enum> unspecified get_info() const;
  image1d clone(command_queue &) const;

  // public static functions
  static std::vector< image_format > 
  get_supported_formats(const context &, cl_mem_flags = read_write);
  static bool is_supported_format(const image_format &, const context &, 
                                  cl_mem_flags = read_write);
};

说明

警告

仅当 OpenCL 版本为 1.2 或更高时, 此方法才可用.

参见: image_format, image2d

image1d 公有成员函数

  1. image1d();
    创建空的 image1d 对象.
  2. image1d(const context & context, size_t image_width, 
        const image_format & format, cl_mem_flags flags = read_write, 
        void * host_ptr = 0);

    创建一个新的 image1d 对象.

    详细说明参见

  3. image1d(const image1d & other);
    创建一个新的 image1d, 作为 other 的副本.
  4. image1d & operator=(const image1d & other);
    把 image1d 从 other 复制过来.
  5. image1d(image1d && other) noexcept;
    从 other 移动构造一个新的图像对象.
  6. image1d & operator=(image1d && other) noexcept;
    把图像从 other 移动赋值到 *this.
  7. ~image1d();
    销毁 image1d 对象.
  8. extents< 1 > size() const;
    返回图像的大小 (宽度).
  9. extents< 1 > origin() const;
    返回图像的原点 (0).
  10. template<typename T> T get_info(cl_image_info info) const;

    返回关于图像的信息.

    详细说明参见

  11. template<int Enum> unspecified get_info() const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
  12. image1d clone(command_queue & queue) const;

    创建一个新图像, 其中包含 *this 中数据的副本. 使用 queue 执行复制操作.

image1d 公有静态函数

  1. static std::vector< image_format > 
get_supported_formats(const context & context, 
                      cl_mem_flags flags = read_write);

    返回该上下文支持的图像格式.

    详细说明参见

  2. static bool is_supported_format(const image_format & format, 
                                const context & context, 
                                cl_mem_flags flags = read_write);

    返回 true, 若 format 是 context 所支持的一维图像格式.
