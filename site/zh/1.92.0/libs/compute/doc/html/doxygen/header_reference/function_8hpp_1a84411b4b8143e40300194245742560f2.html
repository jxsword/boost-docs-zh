宏 BOOST_COMPUTE_FUNCTION

BOOST_COMPUTE_FUNCTION

概要

// In header: <boost/compute/function.hpp>

BOOST_COMPUTE_FUNCTION(return_type, name, arguments, source)

说明

用 name 和 source 创建函数对象.

函数声明与签名会由宏参数 return_type, name 和 arguments 自动创建.

函数的源代码被解释为 OpenCL C99 源代码, 在调用该函数时会被字符串化并传给 OpenCL 编译器.

例如, 创建一个计算数值平方的函数:

BOOST_COMPUTE_FUNCTION(float, square, (float x),
{
    return x * x;
});

创建一个计算两数之和的函数:

BOOST_COMPUTE_FUNCTION(int, sum_two, (int x, int y),
{
    return x + y;
});

参见: BOOST_COMPUTE_CLOSURE()

参数:

arguments

函数的实参列表.

name

函数的名称.

return_type

函数的返回类型.

source

函数的 OpenCL C 源代码.
