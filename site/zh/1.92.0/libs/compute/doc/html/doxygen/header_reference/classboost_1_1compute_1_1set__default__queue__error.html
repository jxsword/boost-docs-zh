类 set_default_queue_error

boost::compute::set_default_queue_error — 设置默认命令队列失败时抛出的异常.

概要

// In header: <boost/compute/exception/set_default_queue_error.hpp>


class set_default_queue_error : public std::exception {
public:

  // public member functions
  set_default_queue_error();
  ~set_default_queue_error();
  const char * what() const;
};

说明

当 Boost.Compute 无法为系统设置用户提供的默认命令队列时抛出此异常.

set_default_queue_error 公有成员函数

  1. set_default_queue_error();
    创建一个新的 set_default_queue_error 异常对象.
  2. ~set_default_queue_error();
    销毁 set_default_queue_error 对象.
  3. const char * what() const;
    返回包含错误描述的字符串.
