函数模板 find_if_not

boost::compute::find_if_not

概要

// In header: <boost/compute/algorithm/find_if_not.hpp>


template<typename InputIterator, typename UnaryPredicate> 
  InputIterator 
  find_if_not(InputIterator first, InputIterator last, 
              UnaryPredicate predicate, 
              command_queue & queue = system::default_queue());

说明

返回指向范围 [first, last) 中第一个使 predicate 返回 false 的元素的迭代器.

空间复杂度: \Omega(1)

参见: find_if()
