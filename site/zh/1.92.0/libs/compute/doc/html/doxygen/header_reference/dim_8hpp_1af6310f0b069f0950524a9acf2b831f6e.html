函数模板 dim

boost::compute::dim

概要

// In header: <boost/compute/utility/dim.hpp>


template<class... Args> extents< sizeof...(Args)> dim(Args... args);

说明

变参函数 dim() 为创建 extents 对象提供了简洁的语法.

例如,

extents<2> region = dim(640, 480); // region == (640, 480)

参见: extents<N>
