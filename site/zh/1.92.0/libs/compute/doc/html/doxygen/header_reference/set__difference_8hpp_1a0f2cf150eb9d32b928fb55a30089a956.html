函数模板 set_difference

boost::compute::set_difference — 集合差算法.

概要

// In header: <boost/compute/algorithm/set_difference.hpp>


template<typename InputIterator1, typename InputIterator2, 
         typename OutputIterator> 
  OutputIterator 
  set_difference(InputIterator1 first1, InputIterator1 last1, 
                 InputIterator2 first2, InputIterator2 last2, 
                 OutputIterator result, 
                 command_queue & queue = system::default_queue());

说明

计算有序范围 [first1, last1) 相对于有序范围 [first2, last2) 的差集, 并将其存储到以 result 开始的范围中 空间复杂度: \Omega(2(distance(first1, last1) + distance(first2, last2)))

参数:

first1

指向第一个集合起始处的迭代器

last1

指向第一个集合结尾处的迭代器

first2

指向第二个集合起始处的迭代器

last2

指向第二个集合结尾处的迭代器

result

指向将存储差集的范围起始处的迭代器

queue

用于执行的队列

返回:

指向差集末尾的迭代器
