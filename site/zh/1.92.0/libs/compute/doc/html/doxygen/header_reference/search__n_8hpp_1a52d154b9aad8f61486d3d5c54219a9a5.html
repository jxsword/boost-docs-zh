函数模板 search_n

boost::compute::search_n — 子串匹配算法.

概要

// In header: <boost/compute/algorithm/search_n.hpp>


template<typename TextIterator, typename ValueType> 
  TextIterator 
  search_n(TextIterator t_first, TextIterator t_last, size_t n, 
           ValueType value, command_queue & queue = system::default_queue());

说明

在文本 [t_first, t_last) 中搜索 value 连续出现 n 次的首次出现. 空间复杂度: \Omega(distance(t_first, t_last))

参数:

t_first

指向文本起始处的迭代器

t_last

指向文本结尾处的迭代器

n

value 重复的次数

value

要重复的值

queue

用于执行的队列

返回:

指向首个匹配起始处的迭代器
