类 event

boost::compute::event — 与计算设备上的某个操作对应的事件.

概要

// In header: <boost/compute/event.hpp>


class event {
public:

  // public member functions
  event();
  explicit event(cl_event, bool = true);
  event(const event &);
  event & operator=(const event &);
  event(event &&) noexcept;
  event & operator=(event &&) noexcept;
  ~event();
  cl_event & get() const;
  cl_int status() const;
  cl_command_type get_command_type() const;
  template<typename T> T get_info(cl_event_info) const;
  template<int Enum> unspecified get_info() const;
  template<typename T> T get_profiling_info(cl_profiling_info) const;
  void wait() const;

                    cl_int = CL_COMPLETE, void * = 0);

    void set_callback(Function, cl_int = CL_COMPLETE);
  template<typename Duration>

                      cl_profiling_info = CL_PROFILING_COMMAND_END) const;
  bool operator==(const event &) const;
  bool operator!=(const event &) const;
};

说明

事件对象用于跟踪设备上运行的操作 (如内核执行与内存传输). 事件对象由 enqueue_* 方法 (command_queue 类) 返回.

事件可用于同步主机与设备之间的操作. wait() 方法会阻塞主机上的执行, 直至设备上与该事件对应的操作完成. 还可用 status() 方法轮询操作的状态.

事件对象也可用于性能剖析. 要将事件用于剖析, 构造命令队列时必须带 CL_QUEUE_PROFILING_ENABLE 标志. 然后可用 duration() 方法获取该操作在设备上的总耗时:

std::cout << "time = " << e.duration<std::chrono::milliseconds>().count() << "ms\n";

参见: future<T>, wait_list

event 公有成员函数

  1. event();
    创建空事件对象.
  2. explicit event(cl_event event, bool retain = true);
  3. event(const event & other);
    创建一个新事件, 作为 other 的副本.
  4. event & operator=(const event & other);
    把事件对象从 other 复制到 *this.
  5. event(event && other) noexcept;
    从 other 移动构造一个新的事件对象.
  6. event & operator=(event && other) noexcept;
    把事件从 other 移动赋值到 *this.
  7. ~event();
    销毁事件对象.
  8. cl_event & get() const;
    返回对底层 OpenCL 事件对象的引用.
  9. cl_int status() const;
    返回事件的状态.
  10. cl_command_type get_command_type() const;
    返回事件的命令类型.
  11. template<typename T> T get_info(cl_event_info info) const;

    返回关于事件的信息.

    详细说明参见

  12. template<int Enum> unspecified get_info() const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
  13. template<typename T> T get_profiling_info(cl_profiling_info info) const;

    返回事件的性能剖析信息.

    参见: event::duration()

    详细说明参见

  14. void wait() const;

    阻塞直至与该事件对应的操作完成.

  15. void set_callback(void(BOOST_COMPUTE_CL_CALLBACK *callback)(cl_event event, cl_int status, void *user_data), 
                  cl_int status = CL_COMPLETE, void * user_data = 0);

    注册一个函数, 在事件状态变为 status 时调用 (默认为 CL_COMPLETE). 回调会收到 OpenCL 事件对象、事件状态以及指向任意用户数据的指针.

    详细说明参见

  16. template<typename Function> 
  void set_callback(Function callback, cl_int status = CL_COMPLETE);

    注册一个通用函数, 在事件状态变为 status 时调用 (默认为 CL_COMPLETE).

    callback 所指定的函数必须能以零个实参调用 (如 callback()).

    警告

    仅当 OpenCL 版本为 1.1 或更高时, 此方法才可用.

  17. template<typename Duration> 
  Duration duration(cl_profiling_info start = CL_PROFILING_COMMAND_START, 
                    cl_profiling_info end = CL_PROFILING_COMMAND_END) const;

    返回事件从 start 到 end 的总时长.

    例如, 打印事件执行所用的毫秒数:

    std::cout << event.duration<std::chrono::milliseconds>().count() << " ms" << std::endl;

    参见: event::get_profiling_info() 

  18. bool operator==(const event & other) const;
    返回 true, 若事件与 other 相同.
  19. bool operator!=(const event & other) const;
    返回 true, 若事件不同于 other.
