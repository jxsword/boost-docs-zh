类 system

boost::compute::system — 提供对系统上平台与设备的访问.

概要

// In header: <boost/compute/system.hpp>


class system {
public:

  // public static functions
  static device default_device();
  static device find_device(const std::string &);
  static std::vector< device > devices();
  static size_t device_count();
  static context default_context();
  static command_queue & 
  default_queue(const command_queue & = command_queue());
  static void finish();
  static std::vector< platform > platforms();
  static size_t platform_count();
};

说明

system 类包含一组静态函数, 用于访问主机系统上的 OpenCL 平台与计算设备.

default_device() 便捷方法依据一组启发式规则和环境变量自动选择并返回系统的"最佳"计算设备. 这简化了 OpenCL 环境的设置.

参见: platform, device, context

system 公有静态函数

  1. static device default_device();

    返回系统的默认计算设备.

    默认设备基于一组启发式规则选择, 并可通过以下环境变量之一加以影响:

    • BOOST_COMPUTE_DEFAULT_DEVICE - 计算设备的名称 (如 "GTX TITAN")

    • BOOST_COMPUTE_DEFAULT_DEVICE_TYPE 计算设备的类型 (如 "GPU" 或 "CPU")

    • BOOST_COMPUTE_DEFAULT_PLATFORM - 平台的名称 (如 "NVIDIA CUDA")

    • BOOST_COMPUTE_DEFAULT_VENDOR - 设备厂商的名称 (如 "NVIDIA")

    • BOOST_COMPUTE_DEFAULT_ENFORCE - 若此变量被设为 "1", 则当上述任一环境变量已设置但未找到匹配设备时, 抛出 no_device_found() 异常.

    默认设备在首次调用此函数时确定一次. 多次调用此函数总是返回相同的设备.

    若系统上未找到 OpenCL 设备, 则抛出 no_device_found 异常.

    例如, 打印系统上默认计算设备的名称:

    // get the default compute device
boost::compute::device device = boost::compute::system::default_device();

// print the name of the device
std::cout << "default device: " << device.name() << std::endl;


  2. static device find_device(const std::string & name);

    返回具有 name 的设备.

    抛出:

    		 no_device_found, 若未找到具有 name 的设备. 
  3. static std::vector< device > devices();

    返回一个向量, 包含系统上所有计算设备.

    例如, 打印系统上每个可用 OpenCL 设备的名称:

    for(const auto &device : boost::compute::system::devices()){
    std::cout << device.name() << std::endl;
}


  4. static size_t device_count();
    返回系统上计算设备的数量.
  5. static context default_context();

    返回系统的默认上下文.

    默认上下文是为系统上的默认设备创建的 (即 default_device() 返回的设备).

    默认上下文在首次调用此函数时创建一次. 多次调用此函数总是返回同一个上下文对象.

  6. static command_queue & 
default_queue(const command_queue & user_queue = command_queue());

    返回系统的默认命令队列.

    若给出了用户提供的命令队列, 系统级默认上下文与默认设备会被相应设置, 使默认队列与默认上下文和设备相匹配.

    若与用户提供的命令队列关联的 OpenCL 上下文和设备与已设置的默认上下文和设备不匹配, 则抛出 set_default_queue_error 异常. 例如:

    

    默认队列在首次调用此函数时创建一次. 多次调用此函数总是返回同一个命令队列对象.
