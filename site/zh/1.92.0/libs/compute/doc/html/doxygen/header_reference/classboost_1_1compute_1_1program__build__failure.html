类 program_build_failure

boost::compute::program_build_failure — 构建 OpenCL 程序时的失败.

概要

// In header: <boost/compute/exception/program_build_failure.hpp>


class program_build_failure : public boost::compute::opencl_error {
public:

  // public member functions
  explicit program_build_failure(cl_int, const std::string &);
  ~program_build_failure();
  std::string build_log() const;
};

说明

当 OpenCL 程序构建失败时抛出此类的实例. 它扩展了 opencl_error, 会保存程序构建日志, 以便用于测试、调试或日志记录.

参见: opencl_error

program_build_failure 公有成员函数

  1. explicit program_build_failure(cl_int error, const std::string & build_log);

    创建一个新的 program_build_failure 异常对象, 对应 error 和 build_log.

  2. ~program_build_failure();
    销毁 program_build_failure 对象.
  3. std::string build_log() const;
    获取程序构建失败时的日志.
