函数模板 wait_for_all

boost::compute::wait_for_all

概要

// In header: <boost/compute/async/wait.hpp>


template<class... Events> void wait_for_all(Events &&... events);

说明

阻塞直至所有事件完成. 事件可以是 event 对象或 future<T> 对象.

参见: event, wait_list
