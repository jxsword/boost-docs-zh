函数模板 stable_partition

boost::compute::stable_partition — 划分算法.

概要

// In header: <boost/compute/algorithm/stable_partition.hpp>


template<typename Iterator, typename UnaryPredicate> 
  Iterator stable_partition(Iterator first, Iterator last, 
                            UnaryPredicate predicate, 
                            command_queue & queue = system::default_queue());

说明

划分范围 [first, last) 中的元素, 划分依据为 predicate. 元素的顺序保持不变. 空间复杂度: \Omega(3n)

参见: is_partitioned() 和 partition()

参数:

first

指向范围起始处的迭代器

last

指向范围结尾处的迭代器

predicate

应用于每个元素的一元谓词

queue

用于执行的队列

返回:

指向 true 值结尾处的迭代器
