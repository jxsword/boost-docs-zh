类 no_device_found

boost::compute::no_device_found — 找不到 OpenCL 设备时抛出的异常.

概要

// In header: <boost/compute/exception/no_device_found.hpp>


class no_device_found : public std::exception {
public:

  // public member functions
  no_device_found();
  ~no_device_found();
  const char * what() const;
};

说明

当找不到有效的 OpenCL 设备时抛出此异常.

参见: opencl_error

    创建一个新的 no_device_found 异常对象.
  2. ~no_device_found();
    销毁 no_device_found 异常对象.
  3. const char * what() const;
    返回包含人类可读错误信息的字符串.
