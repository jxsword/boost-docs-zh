类 wait_list

boost::compute::wait_list — 存储事件列表.

概要

// In header: <boost/compute/utility/wait_list.hpp>


class wait_list {
public:
  // types
  typedef std::vector< event >::iterator       iterator;      
  typedef std::vector< event >::const_iterator const_iterator;

  // public member functions
  wait_list();
  wait_list(const event &);
  wait_list(const wait_list &);
  wait_list(std::initializer_list< event >);
  wait_list & operator=(const wait_list &);
  wait_list(wait_list &&);
  wait_list & operator=(wait_list &&);
  ~wait_list();
  bool empty() const;
  uint_ size() const;
  void clear();
  const cl_event * get_event_ptr() const;
  void reserve(size_t);
  void insert(const event &);
  template<typename T> void insert(const future< T > &);
  void wait() const;
  const event & operator[](size_t) const;
  event & operator[](size_t);
  iterator begin();
  const_iterator begin() const;
  const_iterator cbegin() const;
  iterator end();
  const_iterator end() const;
  const_iterator cend() const;
};

说明

wait_list 类存储一组事件对象, 可用于为 OpenCL 操作指定依赖, 或在主机上等待直至所有事件完成.

该类还提供与 OpenCL API 交互的便捷函数, 这些 API 通常以 cl_event* 指针和 cl_uint 大小的形式接受事件依赖. 例如:

wait_list events = ...;

clEnqueueNDRangeKernel(..., events.get_event_ptr(), events.size(), ...);

参见: event, future<T>

wait_list 公有成员函数

  1. wait_list();
    创建空等待列表.
  2. wait_list(const event & event);
    创建一个包含 event 的等待列表.
  3. wait_list(const wait_list & other);
    创建一个新的等待列表, 作为 other 的副本.
  4. wait_list(std::initializer_list< event > events);
    从 events 创建等待列表.
  5. wait_list & operator=(const wait_list & other);
    从 other 复制等待列表中的事件.
  6. wait_list(wait_list && other);
    从 other 移动构造一个新的等待列表对象.
  7. wait_list & operator=(wait_list && other);
    把等待列表从 other 移动赋值到 *this.
  8. ~wait_list();
    销毁等待列表.
  9. bool empty() const;
    返回 true, 若等待列表为空.
  10. uint_ size() const;
    返回等待列表中的事件数量.
  11. void clear();
    移除等待列表中的所有事件.
  12. const cl_event * get_event_ptr() const;

    返回指向等待列表中第一个事件的 cl_event 指针. 若等待列表为空, 则返回 0.

    这可用于把等待列表传给期望以 cl_event 指针引用事件列表的 OpenCL 函数.

  13. void reserve(size_t new_capacity);
    为等待列表对象预留至少指定长度的存储.
  14. void insert(const event & event);
    把 event 插入等待列表.
  15. template<typename T> void insert(const future< T > & future);
    把 future 中的事件插入等待列表.
  16. void wait() const;

    阻塞直至等待列表中的所有事件都完成.

    若等待列表为空, 则不执行任何操作.

  17. const event & operator[](size_t pos) const;
    返回指定位置 pos 处事件的引用.
  18. event & operator[](size_t pos);
    返回指定位置 pos 处事件的引用.
  19. iterator begin();
    返回指向等待列表第一个元素的迭代器.
  20. const_iterator begin() const;
    返回指向等待列表第一个元素的迭代器.
  21. const_iterator cbegin() const;
    返回指向等待列表第一个元素的迭代器.
  22. iterator end();
    返回指向等待列表最后一个元素之后元素的迭代器.
  23. const_iterator end() const;
    返回指向等待列表最后一个元素之后元素的迭代器.
  24. const_iterator cend() const;
    返回指向等待列表最后一个元素之后元素的迭代器.
