函数模板 includes

boost::compute::includes — includes 算法.

概要

// In header: <boost/compute/algorithm/includes.hpp>


template<typename InputIterator1, typename InputIterator2> 
  bool includes(InputIterator1 first1, InputIterator1 last1, 
                InputIterator2 first2, InputIterator2 last2, 
                command_queue & queue = system::default_queue());

说明

判断有序范围 [first1, last1) 是否包含有序范围 [first2, last2). 换句话说, 它检查 [first1, last1) 是否为 [first2, last2) 的超集.

空间复杂度: \Omega(distance(first1, last1) + distance(first2, last2))

参数:

first1

指向第一个集合起始处的迭代器

last1

指向第一个集合结尾处的迭代器

first2

指向第二个集合起始处的迭代器

last2

指向第二个集合结尾处的迭代器

queue

用于执行的队列

返回:

若 [first1, last1) 包含 [first2, last2), 则为 True; 否则为 False.
