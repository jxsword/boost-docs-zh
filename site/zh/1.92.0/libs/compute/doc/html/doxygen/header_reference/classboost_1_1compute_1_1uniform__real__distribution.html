类模板 uniform_real_distribution

boost::compute::uniform_real_distribution — 产生均匀分布的随机浮点数.

概要

// In header: <boost/compute/random/uniform_real_distribution.hpp>

template<typename RealType = float> 
class uniform_real_distribution {
public:
  // types
  typedef RealType result_type;

  // public member functions
  uniform_real_distribution(RealType = 0.f, RealType = 1.f);
  ~uniform_real_distribution();
  result_type a() const;
  result_type b() const;
  template<typename OutputIterator, typename Generator> 
    void generate(OutputIterator, OutputIterator, Generator &, 
                  command_queue &);

  // private member functions
   BOOST_STATIC_ASSERT_MSG(boost::is_floating_point< RealType >::value, 
                           "Template argument must be a floating point type");
};

说明

以下示例展示如何配置均匀实数分布, 以产生随机 float 值, 取值介于 1 与 100 之间.



参见: default_random_engine, normal_distribution 









uniform_real_distribution 公有成员函数


    

  1. 

    uniform_real_distribution(RealType a = 0.f, RealType b = 1.f);
    

    创建一个新的均匀分布, 在范围 [a, b) 内产生数值. 要求 a < b
    

    2. 

  2. 

    ~uniform_real_distribution();
    销毁 uniform_real_distribution 对象.
    3. 

  3. 

    result_type a() const;
    返回分布的最小值.
    4. 

  4. 

    result_type b() const;
    返回分布的最大值.
    5. 

  5. 

    template<typename OutputIterator, typename Generator> 
  void generate(OutputIterator first, OutputIterator last, 
                Generator & generator, command_queue & queue);
    

    生成均匀分布的浮点数, 并将其存储到范围 [first, last) 中.
