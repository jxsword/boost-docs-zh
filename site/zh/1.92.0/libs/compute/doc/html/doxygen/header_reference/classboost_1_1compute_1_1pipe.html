类 pipe

boost::compute::pipe — FIFO 数据管道.

概要

// In header: <boost/compute/pipe.hpp>


class pipe : public boost::compute::memory_object {
public:

  // public member functions
  pipe();
  explicit pipe(cl_mem, bool = true);
  pipe(const context &, uint_, uint_, cl_mem_flags = read_write, 
       const cl_pipe_properties * = 0);
  pipe(const pipe &);
  pipe & operator=(const pipe &);
  pipe(pipe &&) noexcept;
  pipe & operator=(pipe &&) noexcept;
  ~pipe();
  uint_ packet_size() const;
  uint_ max_packets() const;
  template<typename T> T get_info(cl_pipe_info) const;
  template<int Enum> unspecified get_info() const;
};

说明

警告

仅当 OpenCL 版本为 2.0 或更高时, 此方法才可用.

参见: memory_object

pipe 公有成员函数

  1. pipe();
    创建空管道对象.
  2. explicit pipe(cl_mem mem, bool retain = true);

    为 mem 创建管道对象. 若 retain 为 true, 则 mem 的引用计数将递增.

  3. pipe(const context & context, uint_ pipe_packet_size, uint_ pipe_max_packets, 
     cl_mem_flags flags = read_write, 
     const cl_pipe_properties * properties = 0);
    在 context 中创建一个新管道.
  4. pipe(const pipe & other);
    创建一个新的管道对象, 作为 other 的副本.
  5. pipe & operator=(const pipe & other);
    把管道对象从 other 复制到 *this.
  6. pipe(pipe && other) noexcept;
    从 other 移动构造一个新的管道对象.
  7. pipe & operator=(pipe && other) noexcept;
    把管道从 other 移动赋值到 *this.
  8. ~pipe();
    销毁管道对象.
  9. uint_ packet_size() const;
    返回包的大小.
  10. uint_ max_packets() const;
    返回包的最大数量.
  11. template<typename T> T get_info(cl_pipe_info info) const;

    返回关于管道的信息.

    详细说明参见

  12. template<int Enum> unspecified get_info() const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
