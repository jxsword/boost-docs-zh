函数模板 generate_n

boost::compute::generate_n

概要

// In header: <boost/compute/algorithm/generate_n.hpp>


template<typename OutputIterator, typename Size, typename Generator> 
  void generate_n(OutputIterator first, Size count, Generator generator, 
                  command_queue & queue = system::default_queue());

说明

把 generator 的结果存储到范围 [first, first + count) 中的每个元素.

空间复杂度: \Omega(1)
