类 unsupported_extension_error

boost::compute::unsupported_extension_error — 尝试使用不受支持的 OpenCL 扩展时抛出的异常.

概要

// In header: <boost/compute/exception/unsupported_extension_error.hpp>


class unsupported_extension_error : public std::exception {
public:

  // public member functions
  explicit unsupported_extension_error(const char *);
  ~unsupported_extension_error();
  std::string extension_name() const;
  const char * what() const;
};

说明

当用户尝试使用平台和/或设备不支持的 OpenCL 扩展时抛出此异常.

例如, 在非 GPU 设备上尝试使用 CL-GL 共享.

参见: opencl_error

unsupported_extension_error 公有成员函数

  1. explicit unsupported_extension_error(const char * extension);

    创建一个新的不受支持扩展错误异常对象, 表明 extension 不受 OpenCL 平台或设备支持.

  2. ~unsupported_extension_error();
    销毁不受支持扩展错误对象.
  3. std::string extension_name() const;
    返回不受支持扩展的名称.
  4. const char * what() const;

    返回包含人类可读错误信息的字符串, 其中含不受支持异常的名称.
