结构体模板 as

boost::compute::as

概要

// In header: <boost/compute/functional/as.hpp>

template<typename T> 
struct as {
  // types
  typedef T result_type;
};

说明

as 函数将其参数转换为 T 类型 (类似于 reinterpret_cast<T>).

参见: convert<T>
