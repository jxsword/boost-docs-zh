类模板 dynamic_bitset

boost::compute::dynamic_bitset — dynamic_bitset 类包含一个可变大小的位数组.

概要

// In header: <boost/compute/container/dynamic_bitset.hpp>

template<typename Block = ulong_, typename Alloc = buffer_allocator<Block> > 
class dynamic_bitset {
public:
  // types
  typedef Block                     block_type;    
  typedef Alloc                     allocator_type;
  typedef vector< Block, Alloc >    container_type;
  typedef container_type::size_type size_type;     

  // public member functions
   BOOST_STATIC_CONSTANT(size_type, 
                         bits_per_block = sizeof(block_type) *CHAR_BIT);
   BOOST_STATIC_CONSTANT(size_type, npos = static_cast< size_type >(-1));
  dynamic_bitset(size_type, command_queue &);
  dynamic_bitset(const dynamic_bitset &);
  dynamic_bitset & operator=(const dynamic_bitset &);
  ~dynamic_bitset();
  size_type size() const;
  size_type num_blocks() const;
  size_type max_size() const;
  bool empty() const;
  size_type count(command_queue &) const;
  void resize(size_type, command_queue &);
  void set(size_type, command_queue &);
  void set(size_type, bool, command_queue &);
  bool test(size_type, command_queue &);
  void flip(size_type, command_queue &);
  bool any(command_queue &) const;
  bool none(command_queue &) const;
  void reset(command_queue &);
  void reset(size_type, command_queue &);
  void clear();
  allocator_type get_allocator() const;
};

说明

例如, 在设备上创建一个可容纳 1000 个位的动态位集:

boost::compute::dynamic_bitset<> bits(1000, queue);

Boost.Compute 的 dynamic_bitset 类提供类 STL 的 API, 其建模自 Boost 中的 boost::dynamic_bitset 类.

参见: vector<T>

dynamic_bitset 公有成员函数

  1.  BOOST_STATIC_CONSTANT(size_type, 
                       bits_per_block = sizeof(block_type) *CHAR_BIT);
  2.  BOOST_STATIC_CONSTANT(size_type, npos = static_cast< size_type >(-1));
  3. dynamic_bitset(size_type size, command_queue & queue);

    创建一个新的动态位集, 为 size 个位分配存储. 将所有位初始化为零.

  4. dynamic_bitset(const dynamic_bitset & other);
    创建一个新的动态位集, 作为 other 的副本.
  5. dynamic_bitset & operator=(const dynamic_bitset & other);
    把数据从 other 复制到 *this.
  6. ~dynamic_bitset();
    销毁动态位集.
  7. size_type size() const;
    返回动态位集的大小.
  8. size_type num_blocks() const;
    返回存储动态位集中各位所需的块数.
  9. size_type max_size() const;
    返回动态位集的最大可能大小.
  10. bool empty() const;
    返回 true, 若动态位集为空 (即 size() == 0).
  11. size_type count(command_queue & queue) const;
    返回位集中被置位 (即 '1') 的位的数量.
  12. void resize(size_type num_bits, command_queue & queue);

    把位集大小调整为包含 num_bits. 若新大小大于当前大小, 则新的位被置为零.

  13. void set(size_type n, command_queue & queue);
    把位置 n 处的位设置为 true.
  14. void set(size_type n, bool value, command_queue & queue);
    把位置 n 处的位设置为 value.
  15. bool test(size_type n, command_queue & queue);
    返回 true, 若位置 n 处的位被置位 (即 '1').
  16. void flip(size_type n, command_queue & queue);
    翻转位置 n 处位的值.
  17. bool any(command_queue & queue) const;
    返回 true, 若位集中任一位被置位 (即 '1').
  18. bool none(command_queue & queue) const;
    返回 true, 若位集中所有位都被置为零.
  19. void reset(command_queue & queue);
    把位集中的所有位都置为零.
  20. void reset(size_type n, command_queue & queue);
    把位置 n 处的位清零.
  21. void clear();
    清空位集 (如 resize(0)).
  22. allocator_type get_allocator() const;
    返回用于为位集分配存储的分配器.
