类 program_cache

boost::compute::program_cache

概要

// In header: <boost/compute/utility/program_cache.hpp>


class program_cache : private boost::noncopyable {
public:

  // public member functions
  program_cache(size_t);
  ~program_cache();
  size_t size() const;
  size_t capacity() const;
  void clear();
  boost::optional< program > get(const std::string &);
  boost::optional< program > get(const std::string &, const std::string &);
  void insert(const std::string &, const program &);
  void insert(const std::string &, const std::string &, const program &);
  program get_or_build(const std::string &, const std::string &, 
                       const std::string &, const context &);

  // public static functions
  static boost::shared_ptr< program_cache > get_global_cache(const context &);
};

说明

program_cache 类把 program 对象存储在 LRU 缓存中.

该类有助于缓解 OpenCL 运行期内核编译模型带来的开销. 常用程序可以持久保存在缓存中, 只在首次使用时编译一次.

程序对象基于用户定义的缓存键以及构建程序时使用的选项 (若有) 来存取.

例如, 把一个程序插入缓存:

cache.insert("foo", foo_program);

之后取回该程序:

boost::optional<program> p = cache.get("foo");
if(p){
    // program found in cache
}

参见: program

program_cache 公有成员函数

  1. program_cache(size_t capacity);

    创建一个新的程序缓存, 可容纳 capacity 个程序对象.

  2. ~program_cache();
    销毁程序缓存.
  3. size_t size() const;
    返回当前存储在缓存中的程序对象数量.
  4. size_t capacity() const;
    返回缓存的总容量.
  5. void clear();
    清空程序缓存.
  6. boost::optional< program > get(const std::string & key);

    返回具有 key 的程序对象. 若缓存中不存在具有 key 的程序, 则返回空 optional.

  7. boost::optional< program > 
get(const std::string & key, const std::string & options);

    返回具有 key 和 options 的程序对象. 若缓存中不存在具有 key 和 options 的程序, 则返回空 optional.

  8. void insert(const std::string & key, const program & program);
    把 program 插入缓存, 键为 key.
  9. void insert(const std::string & key, const std::string & options, 
            const program & program);
    把 program 插入缓存, 键为 key 和 options.
  10. program get_or_build(const std::string & key, const std::string & options, 
                     const std::string & source, const context & context);

    若缓存中存在具有 key 的程序, 则从缓存加载它. 否则用 source 和 options 构建新程序, 将其存入缓存并返回.

    这是一个便捷函数, 用于简化常见模式: 先尝试从缓存加载程序, 若不存在, 则从源代码构建程序并存入缓存.

    等价于:

    boost::optional<program> p = get(key, options);
if(!p){
    p = program::create_with_source(source, context);
    p->build(options);
    insert(key, options, *p);
}
return *p;

program_cache 公有静态函数

  1. static boost::shared_ptr< program_cache > 
get_global_cache(const context & context);

    返回 context 的全局程序缓存.

    此全局缓存由 Boost.Compute 内部用于存储其算法使用的已编译程序对象. 所有 Boost.Compute 程序的缓存键都以 "__boost" 开头. 用户程序应避免使用相同前缀, 以防冲突.
