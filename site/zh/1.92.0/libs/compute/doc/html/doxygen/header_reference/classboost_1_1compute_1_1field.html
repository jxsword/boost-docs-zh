类模板 field

boost::compute::field

概要

// In header: <boost/compute/functional/field.hpp>

template<typename T> 
class field {
public:
  // types
  typedef T result_type;  // Result type. 

  // public member functions
  field(const std::string &);
};

说明

从值中取出指定名称的字段.

模板类型 T 指定该字段的值类型. 注意, 值类型必须与字段的实际类型一致, 否则可能出现运行期编译错误或逻辑错误.

例如, 访问 second (位于 std::pair<int, float> 对象中) 字段:

field<float>("second");

它也可用于向量类型, 以访问单个分量以及执行 swizzle 操作.

例如, 访问 int 向量类型 (如 int4) 的第一个与第三个分量:

field<int2_>("xz");

参见: get<N>

field 公有成员函数

  1. field(const std::string & field);
    用 field 创建一个新的 field 函数对象.
