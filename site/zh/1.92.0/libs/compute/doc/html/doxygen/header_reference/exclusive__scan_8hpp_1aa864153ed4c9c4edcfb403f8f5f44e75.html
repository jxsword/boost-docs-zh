函数模板 exclusive_scan

boost::compute::exclusive_scan

概要

// In header: <boost/compute/algorithm/exclusive_scan.hpp>


template<typename InputIterator, typename OutputIterator, typename T, 
         typename BinaryOperator> 
  OutputIterator 
  exclusive_scan(InputIterator first, InputIterator last, 
                 OutputIterator result, T init, BinaryOperator binary_op, 
                 command_queue & queue = system::default_queue());

说明

对范围 [first, last) 中的元素执行排他扫描, 并把结果存储到以 result 开始的范围中.

输出中的每个元素被赋值为输入中此前所有值之和.

默认操作是把元素累加起来.



但可以改为在 binary_op 处指定其他满足结合律的操作 (如乘法、最大值、最小值). 也可以指定用于初始化扫描序列的值.




GPU 上的空间复杂度: \Omega(n)
 GPU 上当 first == result: 时的空间复杂度: \Omega(2n)
 CPU 上的空间复杂度: \Omega(1)


参见: inclusive_scan()















 参数: 











first


要扫描范围的第一个元素






last


要扫描范围的最后一个元素






result


结果范围的第一个元素






init


用于初始化扫描序列的值






binary_op


满足结合律的二元运算符






queue


执行操作的命令队列











返回:


OutputIterator, 指向结果范围的末尾
