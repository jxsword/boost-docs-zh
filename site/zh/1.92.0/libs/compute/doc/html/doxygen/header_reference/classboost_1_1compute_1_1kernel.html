说明

参见: command_queue, program

kernel 公有成员函数

  1. kernel();
    创建空内核对象.
  2. explicit kernel(cl_kernel kernel, bool retain = true);

    为 kernel 创建新的内核对象. 若 retain 为 true, 则 kernel 的引用计数将递增.

  3. kernel(const program & program, const std::string & name);
    用 name 从 program 创建一个新的内核对象.
  4. kernel(const kernel & other);
    创建一个新的内核对象, 作为 other 的副本.
  5. kernel & operator=(const kernel & other);
    把内核对象从 other 复制到 *this.
  6. kernel(kernel && other) noexcept;
    从 other 移动构造一个新的内核对象.
  7. kernel & operator=(kernel && other) noexcept;
    把内核从 other 移动赋值到 *this.
  8. ~kernel();
    销毁内核对象.
  9. kernel clone();

    基于底层 OpenCL 内核对象的浅拷贝创建新的内核对象.

    警告

    仅当 OpenCL 版本为 2.1 或更高时, 此方法才可用.

  17. template<typename T> 
  T get_arg_info(size_t index, cl_kernel_arg_info info) const;

    返回位置 index 处实参的信息.

    例如, 获取第一个实参的名称:

    std::string arg = kernel.get_arg_info<std::string>(0, CL_KERNEL_ARG_NAME);

    注意, 此函数要求程序以 "-cl-kernel-arg-info" 标志编译. 例如:

    program.build("-cl-kernel-arg-info");
    警告

    仅当 OpenCL 版本为 1.2 或更高时, 此方法才可用.

    详细说明参见

  25. template<typename T> void set_arg(size_t index, const T & value);

    把位置 index 处的实参设置为 value.

    对内建类型 (如 float, int4_), 这等价于调用 set_arg(index, sizeof(type), &value).

    此外, 该方法针对设备内存对象 (如 buffer 与 image2d) 进行了特化, 因此可以直接传递它们, 而无需提取其底层 cl_mem 对象.

    该方法还针对设备容器类型 (如 vector<T> 与 array<T, N>) 进行了特化, 因此可以把它们直接作为内核实参传递, 而无需提取其底层缓冲区.

    设置局部内存实参 (如 "__local float *buf") 时, 可使用 local_buffer<T> 类:

    // set argument to a local buffer with storage for 32 float's
kernel.set_arg(0, local_buffer<float>(32));

    把 NULL 设置给全局与常量内存实参 (C++11):

    kernel.set_arg(0, nullptr);


  26. void set_arg(size_t index, std::nullptr_t nul);
