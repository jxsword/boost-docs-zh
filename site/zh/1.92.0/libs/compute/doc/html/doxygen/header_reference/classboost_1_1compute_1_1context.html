类 context

boost::compute::context — 计算上下文.

概要

// In header: <boost/compute/context.hpp>


class context {
public:

  // public member functions
  context();
  explicit context(const device &, const cl_context_properties * = 0);
  explicit context(const std::vector< device > &, 
                   const cl_context_properties * = 0);
  explicit context(cl_context, bool = true);
  context(const context &);
  context & operator=(const context &);
  context(context &&) noexcept;
  context & operator=(context &&) noexcept;
  ~context();
  cl_context & get() const;
  device get_device() const;
  std::vector< device > get_devices() const;
  template<typename T> T get_info(cl_context_info) const;
  template<int Enum> unspecified get_info() const;
  bool operator==(const context &) const;
  bool operator!=(const context &) const;
};

说明

context 类表示一个计算上下文.

上下文对象管理一组 OpenCL 资源, 包括内存缓冲区与程序对象. 在设备上分配内存或执行内核之前, 必须先建立上下文对象.

为系统上的默认设备创建上下文:

// get the default compute device
boost::compute::device gpu = boost::compute::system::default_device();

// create a context for the device
boost::compute::context context(gpu);

上下文创建后, 即可用 buffer 类分配内存, 并用 command_queue 类执行内核.

参见: device, command_queue

context 公有成员函数

  1. context();
    创建空上下文对象.
  2. explicit context(const device & device, 
                 const cl_context_properties * properties = 0);

    为 device 创建新上下文, 使用 properties.

    详细说明参见

  3. explicit context(const std::vector< device > & devices, 
                 const cl_context_properties * properties = 0);

    为 devices 创建新上下文, 使用 properties.

    详细说明参见

  4. explicit context(cl_context context, bool retain = true);

    为 context 创建新的上下文对象. 若 retain 为 true, 则 context 的引用计数将递增.

  5. context(const context & other);
    创建一个新的上下文对象, 作为 other 的副本.
  6. context & operator=(const context & other);
    把上下文对象从 other 复制到 *this.
  7. context(context && other) noexcept;
    从 other 移动构造一个新的上下文对象.
  8. context & operator=(context && other) noexcept;
    把上下文从 other 移动赋值到 *this.
  9. ~context();
    销毁上下文对象.
  10. cl_context & get() const;
    返回底层 OpenCL 上下文.
  11. device get_device() const;

    返回上下文的设备. 若上下文包含多个设备, 则返回第一个.

  12. std::vector< device > get_devices() const;
    返回上下文的设备向量.
  13. template<typename T> T get_info(cl_context_info info) const;

    返回关于上下文的信息.

    详细说明参见

  14. template<int Enum> unspecified get_info() const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
  15. bool operator==(const context & other) const;
    返回 true, 若上下文与 other 相同.
  16. bool operator!=(const context & other) const;
    返回 true, 若上下文不同于 other.
