函数模板 reduce

boost::compute::reduce

概要

// In header: <boost/compute/algorithm/reduce.hpp>


template<typename InputIterator, typename OutputIterator, 
         typename BinaryFunction> 
  void reduce(InputIterator first, InputIterator last, OutputIterator result, 
              BinaryFunction function, 
              command_queue & queue = system::default_queue());

说明

返回把 function 应用到范围 [first, last) 中元素的结果.

若未指定函数, 将使用 plus.

reduce() 算法假定二元归约函数满足结合律. 若与非满足结合律的函数一起使用, 结果可能是非确定性的, 精度也会有所变化. 特别地, 这会影响 plus<float>() 函数, 因为浮点加法不满足结合律, 可能产生与串行算法略有不同的结果.

此算法对结果实参同时支持主机与设备迭代器. 这使得值可以在一次函数调用中完成归约并复制到主机.

注意, 尽管 reduce() 算法在概念上与 accumulate() 算法相同, 但它在并行硬件上的实现效率显著更高. 更多信息参见 accumulate() 算法的文档.


GPU 上的空间复杂度: \Omega(n)
 CPU 上的空间复杂度: \Omega(1)


参见: accumulate()














 参数:

输入范围的第一个元素






last


输入范围的最后一个元素






result


指向输出的迭代器






function


二元归约函数






queue


执行操作的命令队列
