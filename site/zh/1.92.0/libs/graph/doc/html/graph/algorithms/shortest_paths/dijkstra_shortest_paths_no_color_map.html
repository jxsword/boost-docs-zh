Dijkstra 最短路径(无颜色映射)

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/dijkstra_shortest_paths_no_color_map.hpp>
#include <iostream>
#include <vector>

struct EdgeProps { int weight; };

using Graph = boost::adjacency_list<boost::vecS, boost::vecS, boost::directedS, boost::no_property, EdgeProps>;
using Vertex = boost::graph_traits<Graph>::vertex_descriptor;

int main() {
    Graph g{4};
    boost::add_edge(0, 1, EdgeProps{1}, g);
    boost::add_edge(1, 2, EdgeProps{2}, g);
    boost::add_edge(0, 2, EdgeProps{10}, g);
    boost::add_edge(2, 3, EdgeProps{1}, g);

    std::vector<Vertex> pred(num_vertices(g));
    std::vector<int> dist(num_vertices(g));
    auto idx = get(boost::vertex_index, g);
    auto wt = get(&EdgeProps::weight, g);

    boost::dijkstra_shortest_paths_no_color_map(g, vertex(0, g),
        boost::predecessor_map(boost::make_iterator_property_map(pred.begin(), idx))
        .distance_map(boost::make_iterator_property_map(dist.begin(), idx))
        .weight_map(wt));

    for (auto v : boost::make_iterator_range(vertices(g)))
        std::cout << "dist[" << v << "] = " << dist[v] << "\n";
}
dist[0] = 0
dist[1] = 1
dist[2] = 3
dist[3] = 4

说明

本算法 [7,5] 在带权有向图或无向图上求解单源最短路径问题, 适用于所有边权重非负的情形. 当某些边权重为负时, 请使用 Bellman-Ford 算法. 当所有边权重都等于 1 时, 请改用广度优先搜索而非 Dijkstra 算法. 关于最短路径问题的定义以及该问题的一些背景, 参见 最短路径算法 一节.

dijkstra_shortest_paths_no_color_map 与原版 dijkstra_shortest_paths 算法的区别在于不使用颜色映射来区分顶点是否已发现, 而是改用距离映射: 满足 distance_compare(distance_map[u], distance_infinity) == false 的顶点 u 被视为未发现. 注意, 这意味着权重为无穷大的边在本算法中无法正确工作.

从 dijkstra_shortest_paths_no_color_map() 函数获取输出有两个主要选项. 若通过 distance_map() 参数提供距离属性映射, 则从起始顶点到图中每个其他顶点的最短距离将记录在该距离映射中. 此外, 还可以把最短路径树记录在前驱映射中: 对每个顶点 u in V, p[u] 将是 u 在最短路径树中的前驱(除非 p[u] = u, 此时 u 或者是源顶点, 或者是从源顶点不可达的顶点). 除这两个选项外, 用户还可以提供自定义访问器, 在算法的任意事件点处执行动作.

Dijkstra 算法通过迭代“扩展”已确定最短路径的顶点集合 S, 找出从源顶点到每个其他顶点的所有最短路径. 算法的每一步中, 下一个加入 S 的顶点由优先队列确定. 队列包含 V - S 中的顶点, 按其距离标号排序, 距离标号是迄今每个顶点所见最短路径的长度. 位于优先队列顶部的顶点 u 随后加入 S, 其每条出边被松弛: 若到 u 的距离加上出边 (u,v) 的权重小于 v 的距离标号, 则顶点 v 的估计距离被减小. 随后算法循环回来, 处理优先队列顶部的下一个顶点. 当优先队列为空时算法结束.

以下为 Dijkstra 单源最短路径算法的伪代码. w 为边权重, d 为距离标号, p 为各顶点的前驱, 用于编码最短路径树. Q 是支持 DECREASE-KEY 操作的优先队列. 算法的访问器事件点由右侧的标注指示.

DIJKSTRA(G, s, w)
  d[s] := 0
  INSERT(Q, s)
  while (Q != Ø)
    u := EXTRACT-MIN(Q)
    for each vertex v in Adj[u]
      if (w(u,v) + d[u] < d[v])
        d[v] := w(u,v) + d[u]
        p[v] := u
        if (d[v] was originally infinity)
          INSERT(Q, v)
        else
          DECREASE-KEY(Q, v)
      else
        ...
    end for
  end while
  return (d, p)

参数

IN

const Graph& graph

算法将作用于其上的图对象. 类型 Graph 必须是 顶点列表图 和 关联图 的模型.

IN

vertex_descriptor start_vertex

源顶点. 所有距离都将从该顶点开始计算, 且最短路径树将以该顶点为根.

IN

weight_map(WeightMap weight_map)

图中每条边的权重或“长度”. 所有权重必须非负且非无穷大. 若某条边的权重为负, 算法将抛出 negative_edge 异常. 类型 WeightMap 必须是 可读属性映射 的模型. 图的边描述符类型必须可用作权重映射的键类型. 此映射的值类型必须与距离映射的值类型相同. 默认: get(edge_weight, graph)

IN

index_map(VertexIndexMap index_map)

此映射将每个顶点映射到区间 [0, num_vertices(graph)) 内的一个整数. 当边被松弛时, 这是高效更新堆数据结构 [55] 所必需的. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作该映射的键类型. 默认: get(vertex_index, graph). 注意: 若使用此默认值, 请确保图具有内部 vertex_index 属性. 例如, adjacency_list 与 VertexList=listS 一起使用时没有内部 vertex_index 属性.

OUT

predecessor_map(PredecessorMap predecessor_map)

前驱映射记录最小生成树中的边. 算法完成后, 边 (p[u],u)(对所有 u in V)都在最小生成树中. 若 p[u] = u, 则 u 或是源顶点, 或是从源顶点不可达的顶点. PredecessorMap 类型必须是 读/写属性映射, 其键类型和值类型与图的顶点描述符类型相同. 默认: dummy_property_map

UTIL/OUT

distance_map(DistanceMap distance_map)

从源顶点 start_vertex 到图中各顶点 graph 的最短路径权重记录在此属性映射中. 最短路径权重是沿最短路径的各边权重之和. 类型 DistanceMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作距离映射的键类型. 距离映射的值类型必须是 幺半群 的元素类型, 该幺半群由 distance_weight_combine 函数对象与作为单位元的 distance_zero 对象构成. 此外, 距离值类型还必须具有 严格弱序, 由 distance_compare 函数对象提供. 默认: iterator_property_map, 由 std::vector 构造, 其元素类型为 WeightMap’s value type of size `num_vertices(graph), 并使用 index_map 作为索引映射.

IN

distance_compare(CompareFunction distance_compare)

此函数用于比较距离, 以确定哪个顶点距源顶点更近. DistanceCompareFunction 类型必须是 二元谓词 的模型, 且其参数类型与 DistanceMap 属性映射的值类型相匹配. 默认: std::less<D> 与 D=typename property_traits<DistanceMap>::value_type

IN

distance_combine(CombineFunction distance_weight_combine)

此函数用于合并距离以计算路径的距离. DistanceWeightCombineFunction 类型必须是 二元函数 的模型. 该二元函数的第一个参数类型必须与 DistanceMap 属性映射的值类型相匹配, 第二个参数类型必须与 WeightMap 属性映射的值类型相匹配. 结果类型必须与距离值类型相同. 默认: boost::closed_plus<D> 与 D=typename property_traits<DistanceMap>::value_type

IN

distance_inf(D distance_infinity)

distance_infinity 对象必须是任何 D 对象中的最大值. 即 distance_compare(d, distance_infinity) == true 对任意 d != distance_infinity 成立. 类型 D 是 DistanceMap 的值类型. 假设所有边的权重均小于(按 distance_compare 比较)该值. 默认: std::numeric_limits<D>::max()

IN

distance_zero(D distance_zero)

distance_zero 值必须是 幺半群 的单位元, 该幺半群由距离值与 distance_weight_combine 函数对象构成. 类型 D 是 DistanceMap 的值类型. 默认: D() 与 D=typename property_traits<DistanceMap>::value_type

OUT

visitor(DijkstraVisitor v)

使用此参数指定希望在算法内特定事件点发生的动作. 类型 DijkstraVisitor 必须是 Dijkstra 访问器 概念的模型. 访问器对象按值传递. 默认: dijkstra_visitor<null_visitor>

复杂度

时间复杂度为 O(V log V + E).

访问器事件点

  • vis.initialize_vertex(u, g): 在算法开始之前对图中每个顶点各调用一次.

  • vis.examine_vertex(u, g) 在某顶点从优先队列移除并加入集合 S 时对其调用. 此时可知 (p[u],u) 是一条最短路径树边, 故 d[u] = delta(s,u) = d[p[u]]
    w(p[u],u)    . 并且, 已考察顶点的距离单调递增 d[u1] ⇐ d[u2] ⇐ d[un].

  • vis.examine_edge(e, g) 在顶点被加入集合 S 之后, 立即对其每条出边调用.

  • vis.edge_relaxed(e, g) 对边 (u,v) 调用, 条件是 d[u] + w(u,v) < d[v]. 边 (u,v) 若是对顶点 v 的最后一次松弛所涉及的边, 则它是最短路径树中的一条边.

  • vis.discover_vertex(v, g) 当边 (u,v) 被检查且 v 尚未被发现时(即在对该边尝试松弛之前其距离为无穷大), 对顶点 v 调用. 这也是该顶点被插入优先队列的时机.

  • vis.edge_not_relaxed(e, g): 若边未被松弛 (见上) 则调用.

  • vis.finish_vertex(u, g) 在顶点的所有出边都被检查之后, 对该顶点调用.
