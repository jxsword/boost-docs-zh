压缩稀疏行图

一种紧凑的不可变图表示, 为有向图和双向图的高性能遍历而优化.

定义于: <boost/graph/compressed_sparse_row_graph.hpp>
模型: 图、关联图、邻接图、顶点列表图、边列表图、属性图

概要

namespace boost {

template <typename Directed = directedS,
          typename VertexProperty = no_property,
          typename EdgeProperty = no_property,
          typename GraphProperty = no_property,
          typename Vertex = std::size_t,
          typename EdgeIndex = Vertex>
class compressed_sparse_row_graph { ... };

} // namespace boost

CSR 格式把顶点和边存储在单独的数组中. 边数组按源顶点排序, 只包含目标点. 顶点数组存储指向边数组的偏移, 给出每个顶点第一条出边的位置. 对顶点 i 出边的迭代访问 edge_array[vertex_array[i]]、edge_array[vertex_array[i]+1]、…、edge_array[vertex_array[i+1]]. 内存使用为 O(n + m), 其中 n = 顶点数, m = 边数. 常数因子取决于 Vertex 和 EdgeIndex 整数类型的大小.

  • Directed = directedS 存储一个边方向(默认).

  • Directed = bidirectionalS 存储两个方向(构造函数集合受限).

  • undirectedS 不受支持.

CSR 图在构造之后 不可变. 不能添加或移除单个顶点或边. 更改结构的唯一方式是通过 assign()(它会重建整个图)或增量 add_edges() / add_edges_sorted() 函数(仅限有向). 请谨慎选择合适的构造函数变体.

快速用法

#include <boost/graph/compressed_sparse_row_graph.hpp>
#include <boost/range/iterator_range.hpp>
#include <iostream>
#include <utility>
#include <vector>

struct City { std::string name; };
struct Road { double km; };

int main() {
    using namespace boost;
    using Graph = compressed_sparse_row_graph<directedS, City, Road>;

    std::vector<std::pair<int,int>> edges = {
        {0,1}, {0,2}, {1,2}, {2,3}
    };
    std::vector<Road> props = {
        {460}, {775}, {310}, {200}
    };

    Graph g(edges_are_unsorted, edges.begin(), edges.end(),
            props.begin(), 4);

    g[0].name = "Paris";
    g[1].name = "Lyon";
    g[2].name = "Marseille";
    g[3].name = "Nice";

    for (auto v : make_iterator_range(vertices(g))) {
        for (auto e : make_iterator_range(out_edges(v, g))) {
            std::cout << g[source(e, g)].name << " -> "
                      << g[target(e, g)].name
                      << " (" << g[e].km << " km)\n";
        }
    }
}
Paris -> Lyon (460 km)
Paris -> Marseille (775 km)
Lyon -> Marseille (310 km)
Marseille -> Nice (200 km)

模板参数

参数 说明 默认值

Directed

边方向存储的选择器. 必须是 boost::directedS 或 boost::bidirectionalS. undirectedS 不 受支持.

directedS

VertexProperty

附加到每个顶点的类类型. 若顶点不携带数据, 使用 no_property(或 void).

no_property

EdgeProperty

附加到每条边的类类型. 若边不携带数据, 使用 no_property(或 void).

no_property

GraphProperty

描述图本身属性的嵌套 property 模板.

no_property

Vertex

用作顶点索引和顶点描述符的无符号整数类型. 更大的类型允许更多顶点; 更小的类型节省内存.

std::size_t

EdgeIndex

用作边索引的无符号整数类型. 不得小于 Vertex, 但可以更大(例如 16 位 Vertex 搭配 32 位 EdgeIndex 允许以 CSR 格式表示完全图).

Vertex
CSR 图提供两个内置属性映射: vertex_index(把顶点映射到 [0, n))和 edge_index(把边映射到 [0, m)).

成员函数

构造函数

compressed_sparse_row_graph();

构造一个没有顶点和边的图.

无序边列表构造函数

template <typename InputIterator>
compressed_sparse_row_graph(
    edges_are_unsorted_t,
    InputIterator edge_begin,
    InputIterator edge_end,
    vertices_size_type numverts,
    const GraphProperty& prop = GraphProperty());

构造具有 numverts 个顶点的图, 其边来自 [edge_begin, edge_end). InputIterator 的值类型必须是 std::pair<int,int>(源点, 目标点); 值必须在 [0, numverts) 内. 边 不必 排序. 此构造函数把边数据复制到临时缓冲区, 因此迭代器只需单遍能力.

值 prop 初始化图属性.

template <typename InputIterator, typename EdgePropertyIterator>
compressed_sparse_row_graph(
    edges_are_unsorted_t,
    InputIterator edge_begin,
    InputIterator edge_end,
    EdgePropertyIterator ep_iter,
    vertices_size_type numverts,
    const GraphProperty& prop = GraphProperty());

与上面相同, 但还初始化边属性. EdgePropertyIterator 的值类型必须可转换为 EdgeProperty. 范围 [ep_iter, ep_iter + m) 提供边属性, 其中 m 是从 edge_begin 到 edge_end 的距离. 使用额外内存(单遍).

多遍无序边列表构造函数

template <typename MultiPassInputIterator>
compressed_sparse_row_graph(
    edges_are_unsorted_multi_pass_t,
    MultiPassInputIterator edge_begin,
    MultiPassInputIterator edge_end,
    vertices_size_type numverts,
    const GraphProperty& prop = GraphProperty());

构造具有 numverts 个顶点的图, 边来自范围 [edge_begin, edge_end). MultiPassInputIterator 的值类型必须是 std::pair<int,int>(源点, 目标点); 值必须在 [0, numverts) 内. 边 不必 排序. 会对边范围进行多遍遍历, 因此迭代器必须支持多遍遍历. 不分配额外缓冲区.

值 prop 初始化图属性.

template <typename MultiPassInputIterator, typename EdgePropertyIterator>
compressed_sparse_row_graph(
    edges_are_unsorted_multi_pass_t,
    MultiPassInputIterator edge_begin,
    MultiPassInputIterator edge_end,
    EdgePropertyIterator ep_iter,
    vertices_size_type numverts,
    const GraphProperty& prop = GraphProperty());

与上面相同, 但还初始化边属性. EdgePropertyIterator 的值类型必须可转换为 EdgeProperty. 范围 [ep_iter, ep_iter + m) 提供边属性. 会对边范围和属性范围都进行多遍遍历.

排序边列表构造函数(仅限有向)

template <typename InputIterator>
compressed_sparse_row_graph(
    edges_are_sorted_t,
    InputIterator edge_begin, InputIterator edge_end,
    vertices_size_type numverts,
    edges_size_type numedges = 0,
    const GraphProperty& prop = GraphProperty());

构造具有 numverts 个顶点的图, 边来自排序的边范围 [edge_begin, edge_end). 标签值 edges_are_sorted 选择此构造函数. InputIterator 的值类型必须是 std::pair<int,int>. 边 必须 排序, 使得来自顶点 i 的所有边先于来自任何顶点 j(j > i)的边.

若提供 numedges, 它会预分配存储, 节省内存和时间.

把未排序的边传给此构造函数会产生一个静默损坏的图. 若无法保证排序顺序, 请使用 edges_are_unsorted. 
template <typename InputIterator, typename EdgePropertyIterator>
compressed_sparse_row_graph(
    edges_are_sorted_t,
    InputIterator edge_begin,
    InputIterator edge_end,
    EdgePropertyIterator ep_iter,
    vertices_size_type numverts,
    edges_size_type numedges = 0,
    const GraphProperty& prop = GraphProperty());

与上面相同, 但还从 [ep_iter, ep_iter + m) 初始化边属性.

就地构造函数(仅限有向)

template <typename InputIterator>
compressed_sparse_row_graph(
    construct_inplace_from_sources_and_targets_t,
    std::vector<vertex_descriptor>& sources,
    std::vector<vertex_descriptor>& targets,
    vertices_size_type numverts,
    const GraphProperty& prop = GraphProperty());

构造具有 numverts 个顶点的图, 使用分开的 sources 和 targets 向量. 这些向量按源顶点 就地 排序. 构造之后, 向量包含未指定的值, 但不与图共享存储(可以安全销毁).

sources 和 targets 向量会被修改. 构造之后不要依赖其内容. 
template <typename InputIterator>
compressed_sparse_row_graph(
    construct_inplace_from_sources_and_targets_t,
    std::vector<vertex_descriptor>& sources,
    std::vector<vertex_descriptor>& targets,
    std::vector<EdgeProperty>& edge_props,
    vertices_size_type numverts,
    const GraphProperty& prop = GraphProperty());

与上面相同, 但还从 edge_props 向量初始化边属性. 三个向量都会被就地修改, 并以未指定的值返回.

把来自 [first, last) 的边连同来自 [ep_first, ep_last) 的对应边属性一起添加. InputIterator 的值类型必须是 std::pair<int,int>, 且 EPIter 的值类型必须是边属性类型. 边不需要排序.

template <typename BidirectionalIterator>
void add_edges_sorted( BidirectionalIterator first,
                       BidirectionalIterator last,
                       compressed_sparse_row_graph& g);

(仅限有向)

把来自 [first, last) 的边添加到图中. BidirectionalIterator 的值类型必须是 std::pair<int,int>. 边 必须 按源顶点索引递增排序.

template <typename BidirectionalIterator, typename EPIter>
void add_edges_sorted( BidirectionalIterator first,
                       BidirectionalIterator last,
                       EPIter ep_iter,
                       compressed_sparse_row_graph& g);

(仅限有向)

把来自 [first, last) 的边连同来自 ep_iter 的边属性一起添加. BidirectionalIterator 和 EPIter 都必须建模 BidirectionalIterator. 边 必须 按源顶点索引递增排序.

关联类型

算法是模板. 要为顶点、边或迭代器声明变量, 通过 graph_traits 提取具体类型:

using Graph  = compressed_sparse_row_graph<directedS, MyVP, MyEP>;
using Vertex = graph_traits<Graph>::vertex_descriptor;
using Edge   = graph_traits<Graph>::edge_descriptor;
类型 说明

vertex_descriptor

无符号整数(Vertex 模板参数). 标识一个顶点.

edge_descriptor

包含源顶点和边索引的轻量句柄. 标识一条边.

directed_category

directed_tag. CSR 图总是有向(或双向)的.

edge_parallel_category

allow_parallel_edge_tag. 允许平行边.

traversal_category

建模 incidence_graph_tag、adjacency_graph_tag、vertex_list_graph_tag 和 edge_list_graph_tag.

vertex_iterator

counting_iterator<Vertex>. 遍历所有顶点.

edge_iterator

遍历图中的所有边.

out_edge_iterator

遍历顶点的出边.

in_edge_iterator

遍历顶点的入边(仅限双向; 有向图为 void).

adjacency_iterator

std::vector<Vertex>::const_iterator. 遍历相邻顶点.

vertices_size_type

与 Vertex 相同. 顶点数量.

edges_size_type

与 EdgeIndex 相同. 边数量.

degree_size_type

与 EdgeIndex 相同. 关联边数量.

稳定性与失效

compressed_sparse_row_graph 在构造之后 不可变. 不能在此图类型上调用 add_vertex()、add_edge()、remove_vertex() 或 remove_edge(). 若需要修改图结构, 请使用 assign() 从另一个图重建, 或使用 add_edges() / add_edges_sorted() 增量构造函数(仅限有向). 顶点和边描述符在图对象的生存期内保持有效(它们是简单的整数索引).
