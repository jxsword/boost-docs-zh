VF2 (子)图同构

使用 VF2 算法找出两个图之间所有图-子图同构映射.

复杂度: 最好情形 O(V2), 最坏情形 O(V! * V). 空间: O(V)
定义于: <boost/graph/vf2_sub_graph_iso.hpp>. 所有函数都定义在 boost 命名空间中.

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/vf2_sub_graph_iso.hpp>
#include <iostream>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, bidirectionalS>;

struct first_only_callback {
    bool found = false;
    template <typename Map1, typename Map2>
    bool operator()(Map1, Map2) { found = true; return false; }
};

int main() {
    // Small graph: triangle (0-1-2)
    Graph small(3);
    add_edge(0, 1, small); add_edge(1, 2, small); add_edge(2, 0, small);
    // Large graph: square with diagonal (0-1-2-3, plus 0-2)
    Graph large(4);
    add_edge(0, 1, large); add_edge(1, 2, large);
    add_edge(2, 3, large); add_edge(3, 0, large); add_edge(0, 2, large);

    first_only_callback cb;
    vf2_subgraph_iso(small, large, std::ref(cb));
    std::cout << "Subgraph isomorphism found: " << std::boolalpha
              << cb.found << "\n";
}
Subgraph isomorphism found: true

方向 参数 说明

IN

const GraphSmall& graph_small

要测试同构的图对中 (第一个) 较小的图 (顶点较少). 类型 GraphSmall 必须是 顶点列表图、边列表图、双向图 和 邻接矩阵 的模型. 边描述符 graph_traits<GraphSmall>::edge_descriptor 必须是 可小于比较 的, 另见 下文 的备注.

IN

const GraphLarge& graph_large

要测试的 (第二个) 较大的图. 类型 GraphLarge 必须是 顶点列表图、边列表图、双向图 和 邻接矩阵 的模型. 边描述符 graph_traits<GraphLarge>::edge_descriptor 必须是 可小于比较 的, 另见 下文 的备注.

OUT

SubGraphIsoMapCallback user_callback

发现图-子图同构时将被调用的函数对象. operator() 必须具有如下形式:
template <typename CorrespondenceMap1To2, typename CorrespondenceMap2To1>
bool operator()(CorrespondenceMap1To2 f, CorrespondenceMap2To1 g) const

CorrespondenceMap1To2 和 CorresondenceMap2To1 两种类型都是 可读属性映射 的模型, 它们把等价的顶点在传给 vf2_subgraph_iso (或 vf2_graph_iso 或 vf2_subgraph_mono) 的两个图之间进行映射. 例如, 若 v 来自 graph_small, w 来自 graph_large, 且这两个顶点可视为等价, 则 get(f, v) 将是 w, get(g, w) 将是 v. 如果某个顶点 (比如 v, 它在 graph_small 中) 与 graph_large 中的顶点不匹配, 则 get(f, v) 将是 graph_traits<GraphLarge>::null_vertex(). 对于来自 graph_large 的任何未匹配顶点同理, get(g, w) 将是 graph_traits<GraphSmall>::null_vertex(). 从回调返回 false 将立即中止搜索. 否则, 将探查整个搜索空间. 一个"默认"打印回调以 工具函数 的形式提供.

IN

const VertexOrderSmall& vertex_order_small

较小 (第一个) 图 graph_small 的有序顶点. 匹配过程中按 vertex_order_small 给出的顺序检查顶点. 类型 VertexOrderSmall 必须是 ContainerConcept 的模型, 值类型为 graph_traits<GraphSmall>::vertex_descriptor.
默认: 顶点按入/出度的重数排序.

IN

IndexMapSmall index_map_small

它把每个顶点映射到范围 [0, num_vertices(graph_small)) 内的一个整数. 类型 IndexMapSmall 必须是 可读属性映射 的模型.
默认: get(vertex_index, graph_small)

IN

IndexMapLarge index_map_large

它把每个顶点映射到范围 [0, num_vertices(graph_large)) 内的一个整数. 类型 IndexMapLarge 必须是 可读属性映射 的模型.
默认: get(vertex_index, graph_large)

IN

EdgeEquivalencePredicate edge_comp

该函数对象用于判定两个图 graph_small 与 graph_large 之间的边是否等价. 类型 EdgeEquivalencePredicate 必须是 二元谓词 的模型, 且实参类型为 graph_traits<GraphSmall>::edge_descriptor 和 graph_traits<GraphLarge>::edge_descriptor. 边描述符必须是 可小于比较 的. 返回 true 表示两条边等价.
默认: always_equivalent

IN

VertexEquivalencePredicate vertex_comp

该函数对象用于判定两个图 graph_small 与 graph_large 之间的顶点是否等价. 类型 VertexEquivalencePredicate 必须是 二元谓词 的模型, 且实参类型为 graph_traits<GraphSmall>::vertex_descriptor 和 graph_traits<GraphLarge>::vertex_descriptor. 返回 true 表示两个顶点等价.
默认: always_equivalent

此函数可用于验证 (子)图同构映射 f. 其参数与函数 vf2_subgraph_iso (vf2_graph_iso) 类似.

说明

两个图 G1=(V1, E1) 与 G2=(V2, E2) 之间的同构, 是一个图的顶点到另一个图顶点的双射映射 M, 它保持图的边结构. M 称为图-子图同构, 当且仅当 M 是 G1 与 G2 的一个子图之间的同构. 图 G = (V, E) 的导出子图是一个普通子图 G' = (V', E'), 附加条件是 G 中两端点都在 V' 内的所有边都在 E' 中.

vf2_subgraph_iso 找出图 graph_small 与 graph_large 之间所有导出子图同构, 并将其输出到 user_callback. 它持续进行, 直到 user_callback 返回 false 或搜索空间被完整探查. 若存在图-子图同构, vf2_subgraph_iso 返回 true, 否则返回 false. 谓词 EdgeEquivalencePredicate 和 VertexEquivalencePredicate 用于测试边和顶点是否等价. 要使用属性映射判定等价, 参见 make_property_map_equivalent 函数. 默认使用 always_equivalent, 它对任何一对顶点或边都返回 true.

当前实现基于 Cordella 等人提出的 VF2 算法. 算法的深入描述见 [1] 与 [2] 及其中的参考文献. P. Foggia 及其合作者的原始代码见 [3]. 简言之, 求两个图 G1 与 G2 之间映射的过程, 就是确定同构映射 M, 它把 G1 的顶点与 G2 的顶点关联起来, 反之亦然. 该过程可以用状态空间表示来描述, 算法在以深度优先方式探查搜索图时创建该状态空间. 匹配过程的每个状态 s 都可关联一个部分映射 M(s). 在每一层, 算法计算可加入当前状态 s 的候选顶点对集合. 若顶点对 (v, w) 可行, 则扩展映射并计算关联的后继状态 s'. 然后对状态 s' 重复整个过程.

返回

三个函数 (vf2_subgraph_iso、vf2_graph_iso、vf2_subgraph_mono) 在找到至少一个映射时返回 true, 否则返回 false.

示例 1

在下面的示例中, 定义了一个小图 graph1 和一个较大的图 graph2. 这里的小与大指图的顶点数. vf2_subgraph_iso 计算两个图之间的所有子图同构映射, 并通过 callback 输出它们.

typedef adjacency_list<setS, vecS, bidirectionalS> graph_type;

// Build graph1
int num_vertices1 = 8; graph_type graph1(num_vertices1);
add_edge(0, 6, graph1); add_edge(0, 7, graph1);
add_edge(1, 5, graph1); add_edge(1, 7, graph1);
add_edge(2, 4, graph1); add_edge(2, 5, graph1); add_edge(2, 6, graph1);
add_edge(3, 4, graph1);

// Build graph2
int num_vertices2 = 9; graph_type graph2(num_vertices2);
add_edge(0, 6, graph2); add_edge(0, 8, graph2);
add_edge(1, 5, graph2); add_edge(1, 7, graph2);
add_edge(2, 4, graph2); add_edge(2, 7, graph2); add_edge(2, 8, graph2);
add_edge(3, 4, graph2); add_edge(3, 5, graph2); add_edge(3, 6, graph2);

// Create callback to print mappings
vf2_print_callback<graph_type, graph_type> callback(graph1, graph2);

// Print out all subgraph isomorphism mappings between graph1 and graph2.
// Vertices and edges are assumed to be always equivalent.
vf2_subgraph_iso(graph1, graph2, callback);

完整示例见 examples/vf2_sub_graph_iso_example.cpp.

示例 2

本示例计算多重图之间的子图同构映射. 多重图的顶点和边使用属性映射来区分.

// Define edge and vertex properties
typedef property<edge_name_t, char> edge_property;
typedef property<vertex_name_t, char, property<vertex_index_t, int> > vertex_property;

// Using a vecS graphs => the index maps are implicit.
typedef adjacency_list<vecS, vecS, bidirectionalS, vertex_property, edge_property> graph_type;

// Create graph1
graph_type graph1;
// Add vertices...
add_vertex(vertex_property('a'), graph1);
...
//... and edges
add_edge(0, 1, edge_property('b'), graph1);
add_edge(0, 1, edge_property('b'), graph1);
...

// Create graph2
graph_type graph2;
add_vertex(vertex_property('a'), graph2);
...
add_edge(0, 1, edge_property('a'), graph2);
...

为了用属性映射区分顶点和边, 使用 make_property_map_equivalent 函数创建二元谓词:

// Create the vertex binary predicate
typedef property_map<graph_type, vertex_name_t>::type vertex_name_map_t;
typedef property_map_equivalent<vertex_name_map_t, vertex_name_map_t> vertex_comp_t;
vertex_comp_t vertex_comp =
  make_property_map_equivalent(get(vertex_name, graph1), get(vertex_name, graph2));

// Create the edge binary predicate
typedef property_map<graph_type, edge_name_t>::type edge_name_map_t;
typedef property_map_equivalent<edge_name_map_t, edge_name_map_t> edge_comp_t;
edge_comp_t edge_comp =
  make_property_map_equivalent(get(edge_name, graph1), get(edge_name, graph2));

最后, 创建一个回调函数对象并计算子图同构映射:

// Create callback
vf2_print_callback<graph_type, graph_type> callback(graph1, graph2);

// Print out all subgraph isomorphism mappings between graph1 and graph2.
// Function vertex_order_by_mult is used to compute the order of
// vertices of graph1. This is the order in which the vertices are examined
// during the matching process.
vf2_subgraph_iso(graph1, graph2, callback, vertex_order_by_mult(graph1),
                 edges_equivalent(edge_comp).vertices_equivalent(vertex_comp));

完整示例见 examples/vf2_sub_graph_iso_multi_example.cpp.

注释

如果 EdgeList 允许平行边 (例如 vecS), 算法会对已识别的边做一些簿记. 匹配的边临时存储在以 std::set 作为容器的结构中, 要求 edge_descriptor 是 可小于比较 的. 相反, 如果改为强制不存在平行边 (例如使用 setS), 查找函数会退回到 edge() 而不做任何簿记.
