biconnected_components / articulation_points

计算无向图的双连通分量与关节点.

复杂度: O(V + E)
定义于: <boost/graph/biconnected_components.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/biconnected_components.hpp>
#include <iostream>

struct Edge { int comp; };

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, vecS, undirectedS, no_property, Edge>;

    Graph g(5);
    add_edge(0, 1, g);
    add_edge(1, 2, g);
    add_edge(2, 0, g);  // triangle
    add_edge(2, 3, g);
    add_edge(3, 4, g);
    add_edge(4, 2, g);  // second triangle

    // Bundled component index written via member-pointer property map.
    auto num = biconnected_components(g, get(&Edge::comp, g));

    std::cout << "Biconnected components: " << num << "\n";
    for (auto ei = edges(g).first; ei != edges(g).second; ++ei) {
        std::cout << "  " << source(*ei, g) << "-" << target(*ei, g)
                  << " component " << g[*ei].comp << "\n";
    }
}
Biconnected components: 2
  0-1 component 1
  1-2 component 1
  2-0 component 1
  2-3 component 0
  3-4 component 0
  4-2 component 0

biconnected_components (1)

template <typename Graph, typename ComponentMap, typename OutputIterator,
          typename DiscoverTimeMap, typename LowPointMap>
std::pair<std::size_t, OutputIterator>
biconnected_components(
    const Graph& g, ComponentMap comp, OutputIterator out,
    DiscoverTimeMap discover_time, LowPointMap lowpt);
方向 参数 说明

IN

const Graph& g

一个无向图. 图类型必须是 顶点列表图 和 关联图 的模型.

OUT

ComponentMap comp

该算法计算图中有多少个双连通分量, 并为每个分量指派一个整数标签. 然后算法通过在分量属性映射中记录分量编号, 记录图中每条边属于哪个分量. ComponentMap 类型必须是 可写属性映射 的模型. 值类型应是整数类型, 最好与图的 edges_size_type 相同. 键类型必须是图的边描述符类型.

OUT

OutputIterator out

算法通过此输出迭代器写出关节点, 并返回结果迭代器.
默认: 一个忽略写入值的哑迭代器.

UTIL/OUT

DiscoverTimeMap discover_time

深度优先搜索中每个顶点的发现时间. DiscoverTimeMap 类型必须是 读/写属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.

UTIL/OUT

LowPointMap lowpt

深度优先搜索中每个顶点的低点, 即从给定顶点出发至多经过一条回边可达的最小顶点. LowPointMap 类型必须是 读/写属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.

说明

如果移除任何单个顶点 (以及关联于该顶点的所有边) 都不会使连通图不连通, 则它是 双连通的. 更一般地, 图的双连通分量是顶点的极大子集, 使得从特定分量中移除一个顶点不会使该分量不连通. 与连通分量不同, 一个顶点可以属于多个双连通分量: 属于多于一个双连通分量的顶点称为 关节点, 或等价地称为 割点. 关节点是移除后会增加图中连通分量数的顶点. 因此, 没有关节点的图是双连通的. 下图展示了一个小图的关节点与双连通分量:

顶点可以出现在多个双连通分量中, 但每条边只能包含在一个双连通分量中. biconnected_components 算法的输出在属性映射 comp 中记录每条边的双连通分量编号. 关节点会被输出到 biconnected_components 的 (可选) 输出迭代器实参, 也可以通过 articulation_points 在不使用双连通分量编号映射的情况下计算. 这些函数返回双连通分量的数量、关节点输出迭代器, 或这两者的对, 取决于记录了哪些信息.

所实现的算法出自 Tarjan [36].

返回

取决于重载:

  • biconnected_components 中返回 std::pair<std::size_t, OutputIterator> 的重载返回双连通分量的数量, 以及指向最后写入的关节点之后的输出迭代器.

  • biconnected_components 中返回 std::size_t 的重载返回双连通分量的数量.

  • articulation_points 重载返回指向最后写入的关节点之后的 OutputIterator.

注释

[1] 由于访问器参数按值传递, 如果你的访问器包含状态, 那么算法期间对状态的任何修改都作用于访问器对象的一个副本, 而不是传入的访问器对象. 因此你可能希望访问器以指针或引用的方式持有该状态.
