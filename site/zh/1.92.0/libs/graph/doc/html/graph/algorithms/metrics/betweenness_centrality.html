Brandes 介数中心性

计算图中每个顶点或每条边的介数中心性.

复杂度: 无权图 O(VE); 带权图 O(VE + V(V+E) log V). 空间: O(VE)
定义于: <boost/graph/betweenness_centrality.hpp>

示例

#include <iostream>
#include <vector>
#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/betweenness_centrality.hpp>

int main() {
    using Graph = boost::adjacency_list<boost::vecS, boost::vecS, boost::undirectedS>;
    Graph g{5};
    boost::add_edge(0, 1, g);
    boost::add_edge(1, 2, g);
    boost::add_edge(2, 3, g);
    boost::add_edge(3, 4, g);

    std::vector<double> centrality(num_vertices(g), 0.0);
    boost::brandes_betweenness_centrality(g,
        boost::make_iterator_property_map(centrality.begin(),
            get(boost::vertex_index, g)));

    std::cout << "Betweenness centrality:\n";
    for (std::size_t i = 0; i < centrality.size(); ++i) {
        std::cout << "  Vertex " << i << ": " << centrality[i] << "\n";
    }
}
Betweenness centrality:
  Vertex 0: 0
  Vertex 1: 3
  Vertex 2: 4
  Vertex 3: 3
  Vertex 4: 0

UTIL

IncomingMap incoming

该属性映射记录进入每个顶点、构成从特定源顶点经该顶点的最短路径的边集合, 供算法内部使用. IncomingMap 类型必须是一个 左值属性映射, 其键类型与图的顶点描述符类型相同, 其值类型是包含边描述符的序列 (例如 std::vector).

UTIL

DistanceMap distance

从每个源顶点 s 到图 g 中每个顶点的最短路径权重记录在此属性映射中, 但结果仅在内部使用. 类型 DistanceMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作距离映射的键类型. 距离映射的值类型是一个 幺半群 的元素类型.

UTIL

DependencyMap dependency

供内部使用的属性映射, 用于累加部分介数中心性结果. 类型 DependencyMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作依赖映射的键类型. 依赖映射的值类型必须与中心性映射的值类型兼容.

UTIL

PathCountMap path_count

供内部使用的属性映射, 用于累加经过每个特定顶点的路径数. 类型 PathCountMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作路径计数映射的键类型. 路径计数映射的值类型必须是足以存储图中路径数的整数类型.

IN

VertexIndexMap vertex_index

它把每个顶点映射到范围 [0, num_vertices(g)) 内的一个整数. 这对于松弛边时高效更新堆数据结构是必要的. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.

图中每个顶点或每条边的值. 顶点 v 的介数中心性定义为

其中 是从顶点 s 到顶点 t 的最短路径数, 而 是从顶点 s 到顶点 t 且经过顶点 v 的最短路径数.

边介数中心性对每条边给出该边为其目标 (无向图为多个目标) 贡献的介数中心性. 与 (顶点) 介数中心性类似, 边介数中心性可用于确定大多数最短路径必须经过的边. 一次调用本算法可以计算顶点中心性或边中心性 (或两者).

该算法既可在带权图上运行 (若提供合适的边权重映射), 也可在无权图上运行 (若不提供边权重映射). 结果是绝对介数中心性; 要转换为相对介数中心性 (它把每个绝对中心性乘以 , 其中 n 是图中的顶点数), 请使用 relative_betweenness_centrality. 有了相对介数中心性, 就可以计算 中心点支配度 [50], 它衡量图中任何一点的最大"介数": 对完全图它为 0, 对"轮形"图为 1 (图中存在一个所有路径都包含的中心顶点; 见 图 1). 设 为具有最大相对介数中心性的顶点; 则中心点支配度定义为:

返回

brandes_betweenness_centrality 函数通过 centrality_map 和/或 edge_centrality_map 属性映射输出结果. relative_betweenness_centrality 函数就地修改中心性映射. central_point_dominance 函数返回一个类型为 property_traits<CentralityMap>::value_type 的值, 表示图的中心点支配度.
