Dijkstra 最短路径

在带权有向图或无向图上求解单源最短路径问题, 适用于所有边权重非负的情形.

复杂度: O(V log V + E)
定义于: <boost/graph/dijkstra_shortest_paths.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/dijkstra_shortest_paths.hpp>
#include <boost/graph/visitors.hpp>
#include <iostream>
#include <limits>
#include <vector>

struct City {};
struct Road { int cost; };

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS, City, Road>;
using Vertex = graph_traits<Graph>::vertex_descriptor;

int main() {
    Graph g(4);
    add_edge(0, 1, Road{1}, g);
    add_edge(1, 2, Road{2}, g);
    add_edge(0, 2, Road{10}, g);
    add_edge(2, 3, Road{1}, g);

    // Storage: you control allocation, lifetime, and container type
    std::vector<Vertex> storage_pred(num_vertices(g));
    std::vector<int>    storage_dist(num_vertices(g));

    // Property maps: lightweight views into the storage
    auto index_map       = get(vertex_index, g);
    auto costs_map       = get(&Road::cost, g);
    auto predecessor_map = make_iterator_property_map(storage_pred.begin(), index_map);
    auto distance_map    = make_iterator_property_map(storage_dist.begin(), index_map);

    dijkstra_shortest_paths(g, vertex(0, g),
        predecessor_map, distance_map,
        costs_map, index_map,
        std::less<int>(), std::plus<int>(),
        std::numeric_limits<int>::max(), 0,
        dijkstra_visitor<null_visitor>());

    for (auto v : make_iterator_range(vertices(g)))
        std::cout << "distance to " << v << " = " << storage_dist[v] << "\n";
}
distance to 0 = 0
distance to 1 = 1
distance to 2 = 3
distance to 3 = 4

(1) 位置参数版本

template <typename Graph, typename DijkstraVisitor, typename PredecessorMap,
          typename DistanceMap, typename WeightMap, typename VertexIndexMap,
          typename CompareFunction, typename CombineFunction,
          typename DistInf, typename DistZero, typename ColorMap = default>
void dijkstra_shortest_paths(
    const Graph& g,
    typename graph_traits<Graph>::vertex_descriptor s,
    PredecessorMap predecessor, DistanceMap distance,
    WeightMap weight, VertexIndexMap index_map,
    CompareFunction compare, CombineFunction combine,
    DistInf inf, DistZero zero,
    DijkstraVisitor vis, ColorMap color = default);
方向 参数 说明

IN

const Graph& g

算法将作用于其上的图对象. 类型 Graph 必须是 顶点列表图 和 关联图 的模型.

IN

vertex_descriptor s

源顶点. 所有距离都将从该顶点开始计算, 且最短路径树将以该顶点为根.

OUT

PredecessorMap predecessor

前驱映射记录最短路径树中的边, 该树由对图的遍历计算得到. 算法完成后, 边 (p[u],u)(对所有 u in V)都在树中. 从顶点 s 到图中每个顶点 v 的最短路径由顶点序列 v, p[v], p[p[v]] 等构成, 直至到达 s(按逆序). 该树不保证是最小生成树. 若 p[u] = u, 则 u 或是源顶点, 或是从源顶点不可达的顶点. PredecessorMap 类型必须是 读/写属性映射, 其键类型和值类型与图的顶点描述符类型相同.

UTIL/OUT

DistanceMap distance

从源顶点 s 到图中各顶点 g 的最短路径权重记录在此属性映射中. 最短路径权重是沿最短路径的各边权重之和. 类型 DistanceMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作距离映射的键类型. 距离映射的值类型必须是 幺半群 的元素类型, 该幺半群由 combine 函数对象与作为单位元的 zero 对象构成. 此外, 距离值类型还必须具有 严格弱序, 由 compare 函数对象提供.

IN

WeightMap weight

图中每条边的权重或"长度". 权重必须全部非负, 若某条边为负, 算法将抛出 negative_edge 异常. 类型 WeightMap 必须是 可读属性映射 的模型. 图的边描述符类型必须可用作权重映射的键类型. 此映射的值类型必须与距离映射的值类型相同.

IN

VertexIndexMap index_map

此映射将每个顶点映射到区间 [0, num_vertices(g)) 内的一个整数. 当边被松弛时, 这是高效更新堆数据结构 [55] 所必需的. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作该映射的键类型.

IN

CompareFunction compare

此函数用于比较距离, 以确定哪个顶点距源顶点更近. CompareFunction 类型必须是 二元谓词 的模型, 且其参数类型与 DistanceMap 属性映射的值类型相匹配.

IN

CombineFunction combine

此函数用于合并距离以计算路径的距离. CombineFunction 类型必须是 二元函数 的模型. 该二元函数的第一个参数类型必须与 DistanceMap 属性映射的值类型相匹配, 第二个参数类型必须与 WeightMap 属性映射的值类型相匹配. 结果类型必须与距离值类型相同.

IN

DistInf inf

inf 对象必须是任何 D 对象中的最大值. 即 compare(d, inf) == true 对任意 d != inf 成立. 类型 D 是 DistanceMap 的值类型. 假设各边的权重小于(以 distance_compare 作比较)该值.

IN

DistZero zero

zero 值必须是某个 幺半群 的幺元, 该幺半群由距离值与 combine 函数对象构成. 类型 D 是 DistanceMap 的值类型.

IN

DijkstraVisitor vis

使用此参数指定希望在算法内特定事件点发生的动作. 类型 DijkstraVisitor 必须是 Dijkstra 访问器 概念的模型. 访问器对象按值传递 [2].

UTIL/OUT

ColorMap color

此映射在算法执行期间用于标记顶点. 顶点初始为白色, 插入队列时变为灰色, 从队列移除时再变为黑色. 算法结束时, 从源顶点可达的顶点都将被标为黑色, 其余顶点仍为白色. 类型 ColorMap 必须是 读/写属性映射 的模型. 顶点描述符必须可用作该映射的键类型, 且映射的值类型必须是 颜色值 的模型.

说明

Dijkstra 算法

在带权有向图或无向图上求解单源最短路径问题, 适用于所有边权重非负的情形. 当某些边权重为负时, 请使用 Bellman-Ford 算法. 当所有边权重都等于 1 时, 请改用广度优先搜索而非 Dijkstra 算法. 关于最短路径问题的定义以及该问题的一些背景, 参见 最短路径算法 一节.

从 dijkstra_shortest_paths() 函数获取输出有两个主要选项. 若通过 distance_map() 参数提供距离属性映射, 则从源顶点到图中每个其他顶点的最短距离将记录在该距离映射中. 此外, 还可以把最短路径树记录在前驱映射中: 对每个顶点 u in V, p[u] 将是 u 在最短路径树中的前驱(除非 p[u] = u, 此时 u 或者是源顶点, 或者是从源顶点不可达的顶点). 除这两个选项外, 用户还可以提供自定义访问器, 在算法的任意事件点处执行动作.

Dijkstra 算法通过迭代“扩展”已确定最短路径的顶点集合 S, 找出从源顶点到每个其他顶点的所有最短路径. 算法的每一步中, 下一个加入 S 的顶点由优先队列确定. 队列包含 V - S [1] 中的顶点, 按其距离标号排序, 距离标号是迄今每个顶点所见最短路径的长度. 位于优先队列顶部的顶点 u 随后加入 S, 其每条出边被松弛: 若到 u 的距离加上出边 (u,v) 的权重小于 v 的距离标号, 则顶点 v 的估计距离被减小. 随后算法循环回来, 处理优先队列顶部的下一个顶点. 当优先队列为空时算法结束.

算法使用颜色标记(白、灰、黑)来记录每个顶点属于哪个集合. 黑色顶点属于 S, 白色或灰色顶点属于 V-S. 白色顶点尚未被发现, 灰色顶点位于优先队列中. 默认情况下, 算法会分配一个数组, 为图中每个顶点存储一个颜色标记. 可以通过 color_map() 参数提供自定义的颜色存储与访问方式.

伪代码

以下为 Dijkstra 单源最短路径算法的伪代码. w 为边权重, d 为距离标号, p 为各顶点的前驱, 用于编码最短路径树. Q 是支持 DECREASE-KEY 操作的优先队列. 算法的访问器事件点由右侧的标注指示.

DIJKSTRA(G, s, w)
  for each vertex u in V
      (not run in _no_init)
    d[u] := infinity
    p[u] := u
    color[u] := WHITE
  end for
  color[s] := GRAY
  d[s] := 0
  INSERT(Q, s)
  while (Q != Ø)
    u := EXTRACT-MIN(Q)
    S := S U { u }
    for each vertex v in Adj[u]
      if (w(u,v) + d[u] < d[v])
        d[v] := w(u,v) + d[u]
        p[v] := u
        if (color[v] = WHITE)
          color[v] := GRAY
          INSERT(Q, v)
        else if (color[v] = GRAY)
          DECREASE-KEY(Q, v)
      else
        ...
    end for
    color[u] := BLACK
  end while
  return (d, p)

访问器事件点

  • vis.initialize_vertex(u, g): 在算法开始之前对图中每个顶点各调用一次.

  • vis.examine_vertex(u, g) 在某顶点从优先队列移除并加入集合 S 时对其调用. 此时可知 (p[u],u) 是一条最短路径树边, 故 d[u] = delta(s,u) = d[p[u]] + w(p[u],u). 并且, 已考察顶点的距离单调递增 d[u1] <= d[u2] <= d[un].

  • vis.examine_edge(e, g) 在顶点被加入集合 S 之后, 立即对其每条出边调用.

  • vis.edge_relaxed(e, g) 对边 (u,v) 调用, 条件是 d[u] + w(u,v) < d[v]. 边 (u,v) 若是对顶点 v 的最后一次松弛所涉及的边, 则它是最短路径树中的一条边.

  • vis.discover_vertex(v, g) 当边 (u,v) 被检查且 v 为 WHITE 时, 对顶点 v 调用. 由于顶点被发现时即被标为 GRAY, 每个可达顶点恰好被发现一次. 这也是该顶点被插入优先队列的时机.

  • vis.edge_not_relaxed(e, g): 若边未被松弛 (见上) 则调用.

  • vis.finish_vertex(u, g) 在顶点的所有出边都被检查之后, 对该顶点调用.

注释

[1] 此处使用的算法并不把全部 V - S 顶点一次性放入优先队列, 而只放入 V - S 中已被发现、因而距离小于无穷大的顶点, 以此节省一点空间.

[2] 由于访问器参数按值传递, 若访问器包含状态, 则算法期间对该状态的任何修改都将作用于访问器对象的副本, 而非传入的访问器对象. 因此, 可能需要让访问器以指针或引用持有该状态.
