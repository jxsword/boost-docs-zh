Boyer-Myrvold 平面性测试/嵌入

测试图是否为平面图, 可选地计算平面嵌入或分离出 Kuratowski 子图.

复杂度: 多数情形 O(n); 在稠密图上要求分离 Kuratowski 子图时为 O(n+m)
定义于: <boost/graph/boyer_myrvold_planar_test.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/boyer_myrvold_planar_test.hpp>
#include <iostream>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, undirectedS>;

Graph make_complete(int n) {
    Graph g(n);
    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j)
            add_edge(i, j, g);
    return g;
}

int main() {
    auto k4 = make_complete(4);
    auto k5 = make_complete(5);
    std::cout << "K4 is planar: " << std::boolalpha
              << boyer_myrvold_planarity_test(k4) << "\n";
    std::cout << "K5 is planar: " << std::boolalpha
              << boyer_myrvold_planarity_test(k5) << "\n";
}
K4 is planar: true
K5 is planar: false

(1) 简单平面性测试

template <typename Graph>
bool boyer_myrvold_planarity_test(const Graph& g);
方向 参数 说明

IN

const Graph& g

一个无向图. 类型 Graph 必须是 VertexAndEdgeListGraph 和 IncidenceGraph 的模型.

(2) 命名参数版本

bool boyer_myrvold_planarity_test(
    boyer_myrvold_params::graph = g,
    boyer_myrvold_params::embedding = embedding_pmap,
    boyer_myrvold_params::kuratowski_subgraph = out_itr,
    boyer_myrvold_params::vertex_index_map = vm,
    boyer_myrvold_params::edge_index_map = em);
方向 参数 说明

IN

Graph& g

一个无向图. 类型 Graph 必须是 VertexAndEdgeListGraph 和 IncidenceGraph 的模型. 这是唯一必需的参数.

OUT

PlanarEmbedding embedding

必须符合 PlanarEmbedding 概念. 若图是平面图, 该映射将被填充为从顶点到平面嵌入中邻居顺时针顺序的映射.

OUT

OutputIterator kuratowski_subgraph

一个接受 graph_traits<Graph>::edge_descriptor 类型值的 OutputIterator. 若图不是平面图, 构成阻碍性 Kuratowski 子图的最小边集将被写入此迭代器.

IN

VertexIndexMap vm

一个可读属性映射, 把来自 g 的顶点映射到范围 [0, num_vertices(g)) 内的相异整数.
默认: get(vertex_index, g)

IN

EdgeIndexMap em

一个可读属性映射, 把来自 g 的边映射到范围 [0, num_edges(g)) 内的相异整数. 仅当提供了 kuratowski_subgraph 实参时才使用此参数.
默认: get(edge_index, g)

这些命名参数都属于命名空间 boyer_myrvold_params. 算法会依据存在的参数在编译期进行优化.

说明

函数 boyer_myrvold_planarity_test 实现 Boyer 与 Myrvold [64] 的 平面性测试/嵌入算法. 若输入图是平面图, 它返回 true, 否则返回 false. 作为此测试的附带作用: 若图是平面图, 可以构造一个平面嵌入; 若图不是平面图, 可以找出一组构成 Kuratowski 子图 的最小边集.

boyer_myrvold_planarity_test 接受任何无向图作为输入, 即便它含自环与多重边. 然而, 许多平面图绘制算法对输入图的结构有额外限制 — 例如, 要求输入图是连通的、双连通的, 甚至是极大平面的 (三角剖分). 幸运的是, 任何缺少这些性质之一的 n 顶点平面图, 都可以通过添加额外的边在 O(n) 时间内得到增强以满足该性质 — 函数 make_connected、make_biconnected_planar 和 make_maximal_planar 正是为此而存在. 如果你使用的绘图算法要求 (比如说) 双连通图, 那么你必须使输入图成为双连通图 而后 再传入 boyer_myrvold_planarity_test, 这样计算出的平面嵌入才会包含这些额外的边. 根据起始图的结构, 这可能需要多次调用 boyer_myrvold_planarity_test, 因为 make_biconnected_planar 与 make_maximal_planar 都要求把既有图的平面嵌入作为输入参数.

验证输出

无论输入图是否为平面图, boyer_myrvold_planarity_test 都能产出一个可自动检查的证书, 用于验证函数工作正常.

若图是平面图, 可以产出平面嵌入. 把平面嵌入传给一个平面绘制例程 (例如 chrobak_payne_straight_line_drawing), 并用函数 is_straight_line_drawing 验证所得图是平面图, 即可验证该嵌入.

若图不是平面图, 可以产出一组在原图中构成 Kuratowski 子图的边. 这组边可以传给函数 is_kuratowski_subgraph, 以验证它们可以收缩成 K5 或 K3,3. boyer_myrvold_planarity_test 选择构成 Kuratowski 子图的边集的方式, 使得到 K5 或 K3,3 的收缩可以通过 is_kuratowski_subgraph 文档中描述的一个简单确定性过程完成.

返回

true 若输入图是平面图, 否则 false.

注释

  1. 平面嵌入也称为 组合嵌入.

  1. 如有需要, 此情形下仍可使算法在 O(n) 时间内运行. 欧拉公式 蕴含: 具有 n 个顶点的平面图至多有 3n - 6 条边, 这意味着 n 个顶点的任何非平面图都有一个只含 3n - 5 条边、且包含 Kuratowski 子图的子图. 因此, 若你需要在 O(n) 时间内找出一个边数超过 3n - 5 的图的 Kuratowski 子图, 你可以创建一个由原图任意 3n - 5 条边构成的子图, 并把该图传给 boyer_myrvold_planarity_test.
