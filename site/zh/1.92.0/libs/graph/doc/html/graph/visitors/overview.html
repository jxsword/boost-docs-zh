访问器

BGL 算法不只是返回结果的黑盒. 在运行过程中, 它们会到达 事件点: 发生有趣事情的时刻(顶点被发现、边被松弛、搜索回溯). 访问器 是一个对象, 其方法在这些事件点被调用. 这让你无需修改或重写算法即可向其中注入自定义逻辑.

访问器按值传递. 若你的访问器持有状态(计数器、容器的引用), 算法操作的是副本. 若需要在算法返回后读取状态, 请以指针或引用持有它.

快速上手: 预构建事件访问器

对于常见任务(记录前驱、距离、时间戳), BGL 提供现成的事件访问器. 你挑选所需的, 组合它们, 然后传给算法.

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/breadth_first_search.hpp>
#include <boost/graph/visitors.hpp>
#include <iostream>
#include <vector>

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, vecS, undirectedS>;

    Graph g(6);
    add_edge(0, 1, g);
    add_edge(0, 2, g);
    add_edge(1, 3, g);
    add_edge(2, 4, g);
    add_edge(3, 5, g);

    // Record predecessors and distances using pre-built event visitors.
    // No need to write a visitor class.
    std::vector<int> pred(num_vertices(g), -1);
    std::vector<int> dist(num_vertices(g), 0);

    auto vis = make_bfs_visitor(
        std::make_pair(
            record_predecessors(pred.data(), on_tree_edge()),
            record_distances(dist.data(), on_tree_edge())
        )
    );

    breadth_first_search(g, vertex(0, g), visitor(vis));

    for (std::size_t v = 0; v < num_vertices(g); ++v) {
        std::cout << "vertex " << v
                  << "  predecessor=" << pred[v]
                  << "  distance=" << dist[v] << "\n";
    }
}
vertex 0  predecessor=-1  distance=0
vertex 1  predecessor=0  distance=1
vertex 2  predecessor=0  distance=1
vertex 3  predecessor=1  distance=2
vertex 4  predecessor=2  distance=2
vertex 5  predecessor=3  distance=3

关键模式:

  1. 挑选事件访问器(record_predecessors、record_distances 等)

  2. 把每个绑定到一个事件标签(on_tree_edge、on_discover_vertex 等)

  3. 用 std::make_pair 组合(三个以上时嵌套 pair: std::make_pair(a, std::make_pair(b, c)))

  4. 包装进算法专用适配器(make_bfs_visitor、make_dfs_visitor、make_dijkstra_visitor)

编写自定义访问器

当预构建的访问器不够用时, 编写你自己的类. 从默认访问器继承以获得所有事件点的空实现, 然后只覆盖你关心的那些.

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/breadth_first_search.hpp>
#include <iostream>

// Inherit from default_bfs_visitor to get empty defaults for all events.
// Override only the events you care about.
struct my_visitor : public boost::default_bfs_visitor {
    template <typename Vertex, typename Graph>
    void discover_vertex(Vertex v, const Graph&) const {
        std::cout << "  discovered " << v << "\n";
    }

    template <typename Edge, typename Graph>
    void tree_edge(Edge e, const Graph& g) const {
        std::cout << "  tree edge " << source(e, g)
                  << " -> " << target(e, g) << "\n";
    }
};

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, vecS, undirectedS>;

    Graph g(5);
    add_edge(0, 1, g);
    add_edge(0, 2, g);
    add_edge(1, 3, g);
    add_edge(2, 4, g);

    std::cout << "BFS from vertex 0:\n";
    breadth_first_search(g, vertex(0, g), visitor(my_visitor()));
}

算法适配器

预构建事件访问器不能直接传给算法. 它们必须被包装进算法专用适配器, 该适配器把它们转换为算法期望的完整访问器接口.

适配器 为以下算法包装事件访问器

dijkstra_shortest_paths

make_bellman_ford_visitor(…​)

bellman_ford_shortest_paths

make_astar_visitor(…​)

astar_search

适配器把每个算法事件分派给列表中匹配的事件访问器. 没有匹配访问器的事件被静默忽略.

提前终止

从访问器提前停止算法的唯一方式是抛出异常. 这是单目标搜索的标准 BGL 模式:

struct found_target {};

struct stop_at : public boost::default_bfs_visitor {
    stop_at(Vertex t) : m_target(t) {}
    template <typename V, typename G>
    void discover_vertex(V v, const G&) const {
        if (v == m_target) { throw found_target(); }
    }
    Vertex m_target;
};

try {
    breadth_first_search(g, src, visitor(stop_at(target)));
} catch (const found_target&) {
    // target found, algorithm stopped
}

事件标签

事件标签把事件访问器连接到特定事件点. 每个标签对应一个或多个算法中的一个事件.

标签 触发时机

on_initialize_vertex

顶点在算法开始之前被初始化

on_discover_vertex

顶点首次被到达

on_examine_edge

已发现顶点的一条出边被检查

on_tree_edge

一条边成为搜索树的一部分

on_cycle_edge / on_back_edge

一条边通向一个已发现的顶点

on_forward_or_cross_edge

(仅 DFS)一条边通向一个已完成的顶点

on_finish_vertex

顶点的所有出边都已被检查

on_edge_relaxed

(最短路径)发现到某顶点的更短路径

on_edge_not_relaxed

(最短路径)一条边没有改善当前距离

on_edge_minimized

(Bellman-Ford)一条边的距离在此轮中被最小化

on_edge_not_minimized

(Bellman-Ford)一条边的距离在此轮中未被改善
