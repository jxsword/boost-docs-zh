设计原理

图是一种数学抽象, 对解决计算机科学中的多种问题都很有用. 因此, 这些抽象也必须在计算机程序中表示出来. 一个用于遍历图的标准化泛型接口, 对于促进图算法与数据结构的复用至关重要. Boost Graph Library 的一部分就是一个泛型接口, 它允许访问图的结构, 同时隐藏实现的细节. 这是一个"开放"接口, 任何实现了该接口的图库都可以与 BGL 的泛型算法以及同样使用该接口的其他算法互操作. BGL 提供了一些符合该接口的通用图类, 但它们并不是"唯一"的图类; 在某些情况下肯定会有其他更合适的图类. 我们相信, BGL 的主要贡献就在于这一接口的构造.

BGL 图接口与图组件是 泛型 的, 其意义与标准模板库 (STL) [1] 相同.

STL 中的泛型性

STL 的泛型性体现在三个方面.

算法/数据结构互操作性

首先, 每个算法都以与数据结构无关的方式编写, 使得单个模板函数可以作用于多种不同的容器类. 迭代器概念是这种算法与数据结构解耦的关键要素. 这一技术的效果是将 STL 的代码规模从 O(M*N) 降至 O(M+N), 其中 M 是算法数量, N 是容器数量. 考虑 20 种算法和 5 种数据结构的情形, 这就是写 100 个函数与只写 25 个函数的差别! 而且随着算法与数据结构数量的增加, 这一差距还会越来越快地扩大.

通过函数对象进行扩展

STL 泛型性的第二种体现是其算法与容器是可扩展的. 用户可以通过函数对象来适配和定制 STL. 正是这种灵活性使 STL 成为解决现实问题的利器. 每个编程问题都带来各自需要建模的实体与交互集合. 函数对象为扩展 STL 以处理各问题域的具体情况提供了一种机制.

元素类型参数化

STL 泛型性的第三种体现是其容器按元素类型参数化. 尽管极其重要, 这也许是 STL 泛型性中最不"有趣"的一个方面. 泛型编程常被概括为对参数化列表 (如 std::list<T>) 的简短描述. 但这仅触及皮毛!

Boost Graph Library 中的泛型性

与 STL 类似, BGL 的泛型性也体现在三个方面.

算法/数据结构互操作性

首先, BGL 的图算法面向一个抽象掉了具体图数据结构细节的接口编写. 与 STL 一样, BGL 使用迭代器来定义数据结构遍历接口. 图遍历有三种不同的模式: 遍历图中的所有顶点、遍历所有边, 以及沿图的邻接结构遍历 (从一个顶点到它的每个邻居). 每种遍历模式都有各自的迭代器.

这一泛型接口使 breadth_first_search() 这类模板函数能够作用于种类繁多的图数据结构, 从以指针链接节点实现的图到以数组编码的图. 这种灵活性在图这一领域尤为重要. 图数据结构往往是为特定应用定制的. 传统上, 程序员若想复用某个算法实现, 就必须把他们的图数据转换/复制到图库规定的图结构中. LEDA、GTL、Stanford GraphBase 等库即是如此, 用 Fortran 编写的图算法更是如此. 这严重限制了图算法的复用.

与之相反, 定制 (乃至遗留) 的图结构无需改动即可与 BGL 的泛型图算法配合使用, 方式是 外部适配 (参见 如何将既有图转换为 BGL 一节). 外部适配在不复制数据、也不把数据放进适配器对象的前提下, 为数据结构包上一层新接口. BGL 接口经过精心设计, 使这种适配变得容易. 为了证明这一点, 我们为在 BGL 图算法中使用多种图结构 (LEDA 图、Stanford GraphBase 图, 乃至 Fortran 风格的数组) 编写了接口代码.

通过访问器进行扩展

其次, BGL 的图算法是可扩展的. BGL 引入了 访问器 [15] 概念, 它只是一个带有多个方法的函数对象. 在图算法中, 通常存在若干关键的"事件点", 在这些点上插入用户自定义操作很有用. 访问器对象为每个事件点提供一个不同的方法, 在相应事件点被调用. 具体的事件点及对应的访问器方法取决于具体算法. 其中通常包括 start_vertex()、discover_vertex()、examine_edge()、tree_edge() 和 finish_vertex() 之类的方法.

顶点与边属性多参数化

BGL 泛型性的第三种体现类似于 STL 容器中元素类型的参数化, 不过对图而言情形要复杂一些. 我们需要把值 (称为"属性") 同时关联到图的顶点和边上. 此外, 常常需要为每个顶点和每条边关联多个属性; 这正是我们所说的多参数化. STL 的 std::list<T> 类有一个表示元素类型的参数 T. 类似地, BGL 图类带有用于顶点和边"属性"的模板参数. 属性指定该属性的参数化类型, 并依照 C++ 特征技术 [19] 为其指派一个标识标签. 该标签用于区分一条边或一个顶点可能拥有的多个属性. 附加到特定顶点或边的属性值可以通过 属性映射 获取. 每个属性各有一个属性映射.

传统图库与图结构在图属性参数化方面力不从心. 这正是图数据结构必须为应用定制的主要原因之一. BGL 图类中的属性参数化使其非常适合复用.
