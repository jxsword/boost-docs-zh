外部属性

当数据存于图之外时.

为什么用外部属性?

并非所有数据都属于图对象内部. 把属性存储在外部的常见原因:

  • 算法输出. 距离、前驱和连通分量由算法产生, 无需持久保存在图内部.

  • 临时数据. 颜色映射和其他簿记数据只在一次算法调用期间存在.

  • 可复用存储. 单个预分配的向量可以服务于多次算法运行, 避免重复的堆分配.

  • 自定义分配器. 你控制容器, 因此由你选择分配器、内存布局或后备存储.

带索引映射的向量

这是外部属性的核心模式.

顶点和边描述符是不透明句柄. 它们并不总是整数, 因此不能直接用作数组索引. 索引映射 把描述符桥接到容器中的连续偏移.

auto index = get(vertex_index, g);
std::vector<int> dist(num_vertices(g));
auto dist_map = make_iterator_property_map(dist.begin(), index);

make_iterator_property_map 把一个迭代器(存储的起点)与一个索引映射(描述符到偏移的映射)组合成一个属性映射, 算法通过它用 get(dist_map, v) 和 put(dist_map, v, value) 进行读写.

在创建属性映射之前, 向量的大小必须至少为 num_vertices(g)(边属性为 num_edges(g)). 过小的向量导致未定义行为, 且没有编译期警告. 
#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/dijkstra_shortest_paths.hpp>
#include <boost/property_map/property_map.hpp>
#include <iostream>
#include <limits>
#include <vector>

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, vecS, directedS, no_property,
                                 property<edge_weight_t, int>>;
    using Vertex = graph_traits<Graph>::vertex_descriptor;

    Graph g(4);
    add_edge(0, 1, 1, g);
    add_edge(0, 2, 4, g);
    add_edge(1, 2, 2, g);
    add_edge(1, 3, 6, g);
    add_edge(2, 3, 3, g);

    auto index = get(vertex_index, g);
    std::vector<int> dist(num_vertices(g));
    std::vector<Vertex> pred(num_vertices(g));
    auto dist_map = make_iterator_property_map(dist.begin(), index);
    auto pred_map = make_iterator_property_map(pred.begin(), index);

    dijkstra_shortest_paths(g, vertex(0, g),
        pred_map, dist_map, get(edge_weight, g), index,
        std::less<int>(), closed_plus<int>(),
        std::numeric_limits<int>::max(), 0,
        default_dijkstra_visitor());

    for (auto v : make_iterator_range(vertices(g))) {
        std::cout << "d[" << v << "] = " << dist[v] << "\n";
    }
}
d[0] = 0
d[1] = 1
d[2] = 3
d[3] = 6

裸数组

当 VertexList=vecS 时, 顶点描述符是从零开始的整数. 裸 C 数组和指针可直接用作属性映射, 无需包装.

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/dijkstra_shortest_paths.hpp>
#include <iostream>
#include <limits>

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, vecS, directedS, no_property,
                                 property<edge_weight_t, int>>;

    Graph g(4);
    add_edge(0, 1, 1, g);
    add_edge(0, 2, 4, g);
    add_edge(1, 2, 2, g);
    add_edge(1, 3, 6, g);
    add_edge(2, 3, 3, g);

    int dist[4];
    int pred[4];

    dijkstra_shortest_paths(g, vertex(0, g),
        pred, dist, get(edge_weight, g), get(vertex_index, g),
        std::less<int>(), closed_plus<int>(),
        std::numeric_limits<int>::max(), 0,
        default_dijkstra_visitor());

    for (int i = 0; i < 4; ++i) {
        std::cout << "d[" << i << "] = " << dist[i] << "\n";
    }
}

d[1] = 1
d[2] = 3
d[3] = 6

基于边的外部属性

当你有 edge_index 属性时, 相同的模式也适用于边. 把容量或流量存储在外部数组中, 然后用边索引映射包装它们.

#include <boost/graph/adjacency_list.hpp>
#include <boost/property_map/property_map.hpp>
#include <iostream>

int main() {
    using namespace boost;

    // Graph with edge_index as an internal property
    using Graph = adjacency_list<vecS, vecS, directedS,
                                 no_property,
                                 property<edge_index_t, std::size_t>>;

    Graph g(4);
    // Assign each edge an index manually
    add_edge(0, 1, 0, g);
    add_edge(0, 2, 1, g);
    add_edge(1, 2, 2, g);
    add_edge(1, 3, 3, g);
    add_edge(2, 3, 4, g);

    // External arrays indexed by edge ID
    int capacity[] = {10, 20, 30, 40, 50};
    int flow[]     = { 8, 12, 25, 32, 45};

    auto edge_id = get(edge_index, g);
    auto cap_map  = make_iterator_property_map(capacity, edge_id);
    auto flow_map = make_iterator_property_map(flow, edge_id);

    for (auto ei = edges(g).first; ei != edges(g).second; ++ei) {
        std::cout << source(*ei, g) << " -> " << target(*ei, g)
                  << "  capacity=" << get(cap_map, *ei)
                  << "  flow=" << get(flow_map, *ei) << "\n";
    }
}
0 -> 1  capacity=10  flow=8
0 -> 2  capacity=20  flow=12
1 -> 2  capacity=30  flow=25
1 -> 3  capacity=40  flow=32
2 -> 3  capacity=50  flow=45

非整数键用 std::map

当 VertexList=listS 时, 顶点描述符是指针而非整数. 没有内置的顶点索引映射. 请改用 std::map 配合 make_assoc_property_map.

auto depth_map = make_assoc_property_map(my_map);

这会包装该映射, 使 get(depth_map, v) 和 put(depth_map, v, val) 分别调用 my_map[v] 和 my_map[v] = val.

#include <boost/graph/adjacency_list.hpp>
#include <boost/property_map/property_map.hpp>
#include <iostream>
#include <map>

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, listS, directedS>;
    using Vertex = graph_traits<Graph>::vertex_descriptor;

    Graph g;
    Vertex a = add_vertex(g), b = add_vertex(g);
    Vertex c = add_vertex(g), d = add_vertex(g);
    add_edge(a, b, g);
    add_edge(a, c, g);
    add_edge(b, d, g);
    add_edge(c, d, g);

    std::map<Vertex, int> depth;
    auto depth_map = make_assoc_property_map(depth);

    put(depth_map, a, 0);
    put(depth_map, b, 1);
    put(depth_map, c, 1);
    put(depth_map, d, 2);

    for (auto v : make_iterator_range(vertices(g))) {
        std::cout << "depth = " << get(depth_map, v) << "\n";
    }
}
depth = 0
depth = 1
depth = 1
depth = 2
