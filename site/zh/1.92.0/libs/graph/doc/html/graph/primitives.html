图接口原语

什么是图?

形式上, 图是一个对 G = (V, E), 其中 V 是 顶点 的集合, E 是 边 的集合. 每条边是一个对 (u, v), u, v 属于 V.

  • 在 有向图 中, 边是有序对: 边 (u, v) 从其 源点 顶点 u 指向其 目标点 顶点 v.

  • 在 无向图 中, 边是无序对, 以任一方向连接两个顶点.

顶点、边、源点、目标点 这些术语以及有向与无向的区别直接映射到下面列出的操作.

更完整的介绍(度、路径、环、平面性), 见 图论回顾.

所有 BGL 图类型共享一组用于访问和修改图结构的自由函数. 这些函数是算法与图交互的方式, 无论底层数据结构如何.

#include <boost/graph/adjacency_list.hpp>
#include <boost/range/iterator_range.hpp>
#include <iostream>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS>;

int main() {
    Graph g(4);
    add_edge(0, 1, g);
    add_edge(1, 2, g);
    add_edge(2, 3, g);

    for (auto v : make_iterator_range(vertices(g))) {
        for (auto e : make_iterator_range(out_edges(v, g))) {
            std::cout << source(e, g) << " -> " << target(e, g) << "\n";
        }
    }
}
0 -> 1
1 -> 2
2 -> 3

遍历

函数 返回 概念

vertices(g)

一对顶点迭代器(所有顶点)

顶点列表图

edges(g)

一对边迭代器(所有边)

边列表图

out_edges(v, g)

一对出边迭代器

关联图

in_edges(v, g)

一对入边迭代器

双向图

adjacent_vertices(v, g)

一对邻接迭代器

邻接图
所有这些 pair 都可以与 make_iterator_range 一起用于基于范围的 for 循环(见上面的示例).

边访问

函数 返回 概念

source(e, g)

源顶点, 属于边 e

关联图

target(e, g)

目标顶点, 属于边 e

关联图

edge(u, v, g)

一对 (edge_descriptor, bool). 若边存在, bool 为 true.

邻接矩阵

 
#include <boost/graph/adjacency_list.hpp>
#include <iostream>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS>;

int main() {
    Graph g(3);
    add_edge(0, 1, g);

    auto result = edge(0, 1, g);       // pair of (edge_descriptor, bool)
    if (result.second) {
        std::cout << source(result.first, g) << " -> " << target(result.first, g) << "\n";
    }
}
0 -> 1

计数

函数 返回 概念

num_vertices(g)

顶点数量

顶点列表图

num_edges(g)

边数量

边列表图

out_degree(v, g)

出边数量, 属于顶点 v

关联图

in_degree(v, g)

入边数量, 属于顶点 v

双向图

degree(v, g)

out_degree + in_degree

双向图

 
#include <boost/graph/adjacency_list.hpp>
#include <iostream>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, bidirectionalS>;

int main() {
    Graph g(3);
    add_edge(0, 1, g);
    add_edge(2, 1, g);

    std::cout << "num_vertices: " << num_vertices(g) << "\n";
    std::cout << "num_edges:    " << num_edges(g) << "\n";
    std::cout << "out_degree(0): " << out_degree(0, g) << "\n";
    std::cout << "in_degree(1):  " << in_degree(1, g) << "\n";
    std::cout << "degree(1):     " << degree(1, g) << "\n";
}
num_vertices: 3
num_edges:    2
out_degree(0): 1
in_degree(1):  2
degree(1):     2

修改

函数 效果 概念

add_vertex(g)

添加一个顶点, 返回其描述符

可变图

remove_vertex(v, g)

移除顶点 v 及所有关联边

可变图

add_edge(u, v, g)

添加从 u 到 v 的边, 返回 pair(描述符, bool)

可变图

remove_edge(u, v, g)

移除以下两顶点之间的边: u 与 v

可变图

remove_edge(e, g)

移除特定边 e

可变图

clear_vertex(v, g)

移除所有关联于 v 的边(顶点保留)

可变图
使用 adjacency_list<vecS, vecS, …​> 时, remove_vertex() 会使被移除顶点之后的所有顶点描述符失效. 详情见 图数据结构. 
#include <boost/graph/adjacency_list.hpp>
#include <iostream>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS>;

int main() {
    Graph g(2);
    add_edge(0, 1, g);

    auto v = add_vertex(g);
    add_edge(v, vertex(0, g), g);
    clear_vertex(v, g);    // remove all edges of v
    remove_vertex(v, g);   // remove v itself

    std::cout << "vertices: " << num_vertices(g) << "\n";
}
vertices: 2

属性访问

函数 返回

get(&Struct::member, g)

捆绑属性成员的属性映射

get(map, key)

值: key, 取自属性映射 map

put(map, key, value)

设置值: key, 写入属性映射 map

g[v] or g[e]

直接引用捆绑属性结构: 顶点 v 或边 e

get(tag, g)

内部属性标签的属性映射(旧式, 优先使用捆绑属性)

 
#include <boost/graph/adjacency_list.hpp>
#include <iostream>
#include <string>

using namespace boost;

struct City { std::string name; };
struct Road { double km; };
using Graph = adjacency_list<vecS, vecS, directedS, City, Road>;

int main() {
    Graph g(2);
    add_edge(0, 1, Road{460.0}, g);

    g[0].name = "Paris";                        // direct struct access
    auto km = get(&Road::km, g);                // property map from bundled member
    std::cout << get(km, edge(0, 1, g).first);  // read through property map
}
460

类型

通过 graph_traits<Graph> 获得:

类型 说明

vertex_descriptor

顶点的句柄. 不透明类型, 不要假定它是整数.

edge_descriptor

边的句柄. 包含源点和目标点信息.

vertex_iterator

遍历所有顶点的迭代器.

edge_iterator

遍历所有边的迭代器.

out_edge_iterator

遍历顶点出边的迭代器.

in_edge_iterator

遍历顶点入边的迭代器(要求 bidirectionalS).

adjacency_iterator

遍历顶点相邻顶点的迭代器.

vertices_size_type

用于顶点数量的无符号整数类型.

edges_size_type

用于边数量的无符号整数类型.

degree_size_type

用于顶点度的无符号整数类型.
