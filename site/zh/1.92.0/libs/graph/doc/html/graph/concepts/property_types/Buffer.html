缓冲区

缓冲区概念

缓冲区是可以放入和取出元素的东西. 缓冲区 概念 要求很少. 它不要求元素存储的特定顺序或取出时的出现顺序, 但通常会有某种排序策略.

记法

B

一个建模缓冲区概念的类型.

T

是 B 的值类型.

t

是类型 T 的对象.

成员

类型要建模缓冲区概念, 必须具有以下成员.

成员 说明

value_type

缓冲区中存储对象的类型. 值类型必须是可赋值的.

size_type

用于表示缓冲区中对象数量的无符号整数类型.

void push(const T& t)

把 t 插入缓冲区. size() 将加一.

void pop()

从缓冲区移除一个对象. size() 将减一. 前置条件: empty() 为 false.

T& top()

返回对缓冲区中某个对象的可变引用. 前置条件: empty() 为 false.

const T& top() const

返回对缓冲区中某个对象的 const 引用. 前置条件: empty() 为 false.

size_type size() const

返回缓冲区中对象的数量. 不变式: size() >= 0.

bool empty() const

等价于 b.size() == 0.

复杂度保证

  • push()、pop() 和 size() 的复杂度至多与广义队列的大小成线性关系.

  • top() 和 empty() 必须为均摊常数时间.
