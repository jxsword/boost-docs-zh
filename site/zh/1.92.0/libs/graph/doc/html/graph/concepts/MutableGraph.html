可变图

可变图可以通过添加或移除边和顶点来修改.

细化自

图

记法

G

一个建模图概念的类型.

g

类型 G 的对象.

e

类型 boost::graph_traits<G>::edge_descriptor 的对象.

u,v

是类型 boost::graph_traits<G>::vertex_descriptor 的对象.

iter

是类型 boost::graph_traits<G>::out_edge_iterator 的对象.

p

是一个类型建模 Predicate、且其参数类型与 edge_descriptor 类型相匹配的对象.

有效表达式

add_edge(u, v, g)

把边 (u,v) 插入图中, 返回指向新边的边描述符. 若图不允许平行边且边 (u,v) 已在图中, 则返回的 bool 标志为 false, 且返回的边描述符指向已存在的边. 注意, 对无向图, (u,v) 与 (v,u) 是同一条边, 因此调用函数 add_edge() 之后, 边 (u,v) 会出现在 u 的出边中, 且 (u,v)(等价地 (v,u))会出现在 v 的出边中. 换句话说, v 将与 u 相邻, 且 u 将与 v 相邻.
返回类型: std::pair<edge_descriptor, bool>

remove_edge(u, v, g)

从图中移除边 (u,v). 若图允许平行边, 此操作移除 (u,v) 的所有出现.
返回类型: void
前置条件: u 和 v 是图中的顶点.
后置条件: (u,v) 不再在 g 的边集之中.

remove_edge(e, g)

从图中移除边 e.
返回类型: void
前置条件: e 是图中的一条边.
后置条件: e 不再在 g 的边集之中.

remove_edge(iter, g)

从图中移除 iter 所指向的边. 仅当图同时建模 关联图 时才要求此表达式.
返回类型: void
前置条件: *iter 是图中的一条边.
后置条件: *iter 不再在 g 的边集之中.

remove_edge_if(p, g)

从图 g 中移除使谓词 p 返回 true 的所有边.
返回类型: void

remove_out_edge_if(u, p, g)

移除顶点 u 的所有使谓词 p 返回 true 的出边. 仅当图同时建模 关联图 时才要求此表达式.
返回类型: void

remove_in_edge_if(u, p, g)

移除顶点 u 的所有使谓词 p 返回 true 的入边. 仅当图同时建模 双向图 时才要求此表达式.
返回类型: void

add_vertex(g)

向图中添加一个新顶点. 返回新顶点的 vertex_descriptor.
返回类型: vertex_descriptor

clear_vertex(u, g)

从图中移除与顶点 u 相连的所有边(入边和出边).
返回类型: void
前置条件: u 是 g 的有效顶点描述符.
后置条件: u 不再作为 g 中任何边的源点或目标点出现.

remove_vertex(u, g)

从图的顶点集中移除 u. 注意, 若图中仍有以 u 为目标点的边, 可能导致未定义行为. 通常应先调用 clear_vertex() 函数.
返回类型: void
前置条件: u 是 g 的有效顶点描述符.
后置条件: num_vertices(g) 减一, u 不再出现在图的顶点集中, 且不再是有效的顶点描述符.

复杂度保证

  • 边插入必须是均摊常数时间; 若插入时还检查以防止添加平行边(这是某些图类型的“特性”), 则可以是 O(log(E/V)).

  • 边移除保证为 O(E).

  • 顶点插入保证为均摊常数时间.

  • 清空顶点为 O(E + V).

  • 顶点移除为 O(E + V).

概念检查类

  template <class G>
  struct MutableGraphConcept
  {
    typedef typename boost::graph_traits<G>::edge_descriptor edge_descriptor;
    void constraints() {
      v = add_vertex(g);
      clear_vertex(v, g);
      remove_vertex(v, g);
      e_b = add_edge(u, v, g);
      remove_edge(u, v, g);
      remove_edge(e, g);
    }
    G g;
    edge_descriptor e;
    std::pair<edge_descriptor, bool> e_b;
    typename boost::graph_traits<G>::vertex_descriptor u, v;
    typename boost::graph_traits<G>::out_edge_iterator iter;
  };

  template <class edge_descriptor>
  struct dummy_edge_predicate {
    bool operator()(const edge_descriptor& e) const {
      return false;
    }
  };

  template <class G>
  struct MutableIncidenceGraphConcept
  {
    void constraints() {
      BOOST_CONCEPT_ASSERT(( MutableGraph<G> ));
      remove_edge(iter, g);
      remove_out_edge_if(u, p, g);
    }
    G g;
    typedef typename boost::graph_traits<G>::edge_descriptor edge_descriptor;
    dummy_edge_predicate<edge_descriptor> p;
    typename boost::graph_traits<G>::vertex_descriptor u;
    typename boost::graph_traits<G>::out_edge_iterator iter;
  };

  template <class G>
  struct MutableBidirectionalGraphConcept
  {
    void constraints() {
      BOOST_CONCEPT_ASSERT(( MutableIncidenceGraph<G> ));
      remove_in_edge_if(u, p, g);
    }
    G g;
    typedef typename boost::graph_traits<G>::edge_descriptor edge_descriptor;
    dummy_edge_predicate<edge_descriptor> p;
    typename boost::graph_traits<G>::vertex_descriptor u;
  };

  template <class G>
  struct MutableEdgeListGraphConcept
  {
    void constraints() {
      BOOST_CONCEPT_ASSERT(( MutableGraph<G> ));
      remove_edge_if(p, g);
    }
    G g;
    typedef typename boost::graph_traits<G>::edge_descriptor edge_descriptor;
    dummy_edge_predicate<edge_descriptor> p;
  };
