McGregor 公共子图

使用 McGregor 回溯算法找出两个图之间的所有公共子图.

复杂度: O(V1 * V2)
定义于: <boost/graph/mcgregor_common_subgraphs.hpp>

算法语义

这些函数计算导出公共子图变体: 对每一对被映射的顶点, 一条边必须同时在两个图中存在, 或同时在两个图中不存在. 非边也是结构匹配的一部分, 而不只是边.

这比通常与 McGregor 1982 年论文相关联的非导出 (部分) 公共子图问题更严格; 在后者中, 只要求已存在的边一致, 任一图中的额外边都被忽略. BGL 目前不提供非导出变体.

保留历史名称是因为底层回溯技术出自 McGregor, 尽管这里求解的问题是在后续文献中成为标准的导出变体.

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/mcgregor_common_subgraphs.hpp>
#include <iostream>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, undirectedS>;
using Size = graph_traits<Graph>::vertices_size_type;

struct max_callback {
    Size largest = 0;
    template <typename Map1, typename Map2>
    bool operator()(Map1, Map2, Size subgraph_size) {
        if (subgraph_size > largest) largest = subgraph_size;
        return true;
    }
};

int main() {
    Graph g1(4);
    add_edge(0, 1, g1); add_edge(1, 2, g1);
    add_edge(2, 3, g1); add_edge(3, 0, g1);

    Graph g2(5);
    add_edge(0, 1, g2); add_edge(1, 2, g2);
    add_edge(2, 3, g2); add_edge(3, 4, g2); add_edge(4, 0, g2);

    max_callback cb;
    mcgregor_common_subgraphs(g1, g2, true, std::ref(cb));
    std::cout << "Largest common subgraph size: " << cb.largest << "\n";
}
Largest common subgraph size: 3

mcgregor_common_subgraphs

// named parameter version
template <typename GraphFirst,
          typename GraphSecond,
          typename SubGraphCallback,
          typename Param,
          typename Tag,
          typename Rest>
void mcgregor_common_subgraphs(
    const GraphFirst& graph1,
    const GraphSecond& graph2,
    SubGraphCallback user_callback,
    bool only_connected_subgraphs,
    const bgl_named_params<Param, Tag, Rest>& params);

// non-named parameter version
template <typename GraphFirst,
          typename GraphSecond,
          typename VertexIndexMapFirst,
          typename VertexIndexMapSecond,
          typename EdgeEquivalencePredicate,
          typename VertexEquivalencePredicate,
          typename SubGraphCallback>
void mcgregor_common_subgraphs(
    const GraphFirst& graph1,
    const GraphSecond& graph2,
    const VertexIndexMapFirst vindex_map1,
    const VertexIndexMapSecond vindex_map2,
    EdgeEquivalencePredicate edges_equivalent,
    VertexEquivalencePredicate vertices_equivalent,
    bool only_connected_subgraphs,
    SubGraphCallback user_callback);
方向 参数 说明

IN

const GraphFirst& graph1

要搜索的图对中的第一个图. 类型 GraphFirst 必须是 顶点列表图 和 关联图 的模型. 所有带 “1” 的参数 (即 vindex_map1、correspondence_map_1_to_2) 都以该图的顶点作为键.

IN

const GraphSecond& graph2

要搜索的图对中的第二个图. 类型 GraphSecond 必须是 顶点列表图 和 关联图 的模型. 所有带 “2” 的参数 (即 vindex_map2、correspondence_map_2_to_1) 都以该图的顶点作为键.

IN

bool only_connected_subgraphs

若 true, 则仅当匹配的顶点至少有一条边与现有子图相连时才扩展子图.

OUT

SubGraphCallback user_callback

发现子图时将被调用的函数对象. 细节参见 回调要求.

命名参数 (仅命名参数版本):

方向 命名参数 说明 / 默认

IN

vertex_index1(VertexIndexMapFirst vindex_map1)

把每个顶点映射到范围 [0, num_vertices(graph1)] 内的一个整数. 这对于高效存储子图是必要的. 类型 VertexIndexMapFirst 必须是 可读属性映射 的模型.
默认: get(vertex_index, graph1)

IN

vertex_index2(VertexIndexMapSecond vindex_map2)

把每个顶点映射到范围 [0, num_vertices(graph2)] 内的一个整数. 这对于高效存储子图是必要的. 类型 VertexIndexMapSecond 必须是 可读属性映射 的模型.
默认: get(vertex_index, graph2)

IN

edges_equivalent(EdgeEquivalencePredicate edges_equivalent)

用于判定 graph1 与 graph2 之间的边是否等价. EdgeEquivalencePredicate 类型必须是 二元谓词 的模型, 且实参类型为 graph_traits<GraphFirst>::edge_descriptor 和 graph_traits<GraphSecond>::edge_descriptor. 返回 true 表示两条边等价.
默认: always_equivalent

IN

vertices_equivalent(VertexEquivalencePredicate vertices_equivalent)

用于判定 graph1 与 graph2 之间的顶点是否等价. VertexEquivalencePredicate 类型必须是 二元谓词 的模型, 且实参类型为 graph_traits<GraphFirst>::vertex_descriptor 和 graph_traits<GraphSecond>::vertex_descriptor. 返回 true 表示两个顶点等价.
默认: always_equivalent

工具函数与结构

make_property_map_equivalent

template <typename PropertyMapFirst,
          typename PropertyMapSecond>
property_map_equivalent<PropertyMapFirst, PropertyMapSecond>
make_property_map_equivalent(
    const PropertyMapFirst property_map1,
    const PropertyMapSecond property_map2);

返回一个二元谓词函数对象 (property_map_equivalent<PropertyMapFirst, PropertyMapSecond>), 它使用属性映射比较图之间的顶点或边. 例如, 若 vertex1 和 vertex2 是调用该函数对象时给出的两个参数, 则 operator() 实际上就是: return (get(m_property_map1, vertex1) == get(m_property_map2, vertex2));

always_equivalent

struct always_equivalent;

对任何一对条目都返回 true 的二元函数对象.

fill_membership_map

template <typename GraphSecond,
          typename GraphFirst,
          typename CorrespondenceMapFirstToSecond,
          typename MembershipMapFirst>
void fill_membership_map(
    const GraphFirst& graph1,
    const CorrespondenceMapFirstToSecond correspondence_map_1_to_2,
    MembershipMapFirst membership_map1);

接受一个子图 (表示为对应映射) 并填充顶点成员映射 (顶点 → bool) (true 表示顶点存在于子图中). MembershipMapFirst 必须符合 可写属性映射 概念.

make_membership_filtered_graph

template <typename Graph,
          typename MembershipMap>
typename membership_filtered_graph_traits<Graph, MembershipMap>::graph_type
make_membership_filtered_graph(
    const Graph& graph,
    MembershipMap& membership_map);

从一个子图创建 过滤图, 这里的子图表示为顶点成员映射 (顶点 → bool, 值为 true 表示顶点存在于子图中). 被包含顶点之间的所有边都会保留. 细节参见 编写回调 一节.

说明

该算法找出 graph1 与 graph2 之间的所有公共子图, 并将其输出到 user_callback. 谓词 edges_equivalent 和 vertices_equivalent 用于判定两个图之间边与顶点的等价性. 要使用属性映射来判定等价, 请参见 make_property_map_equivalent 函数. 默认使用 always_equivalent, 它对任何一对边或顶点都返回 true.

McGregor 算法在可能公共子图的空间上进行深度优先搜索. 在每一层, 检查来自 graph1 和 graph2 的每一对未访问顶点, 看它们能否扩展当前子图. 这分三步完成 (设 vertex1 来自 graph1, vertex2 来自 graph2):

  1. 验证 vertex1 与 vertex2 (借助 vertices_equivalent 谓词) 是否等价.

  2. 对于当前子图中的每个顶点对 (existing_vertex1, existing_vertex2), 确保 vertex1 与 existing_vertex1 之间在 graph1 中的任何边, 与 vertex2 与 existing_vertex2 之间在 graph2 中的任何边相匹配 (即要么都存在, 要么都不存在). 若两条边都存在, 则用 edges_equivalent 谓词检查它们的等价性.

  3. 最后 (可选), 确保新的子图顶点至少有一条边与现有子图相连. 当 only_connected_subgraphs 参数为 false 时, 跳过此步骤.

所有函数都定义在 boost 命名空间中.

回调要求

user_callback 函数对象的 operator() 必须具有如下形式:

template <typename CorrespondenceMapFirstToSecond,
          typename CorrespondenceMapSecondToFirst>
bool operator()(CorrespondenceMapFirstToSecond correspondence_map_1_to_2,
                CorrespondenceMapSecondToFirst correspondence_map_2_to_1,
                typename graph_traits<GraphFirst>::vertices_size_type subgraph_size);

CorrespondenceMapFirstToSecond 和 CorrespondenceMapSecondToFirst 两种类型都是 可读属性映射 的模型, 它们把等价的顶点在传给 mcgregor_common_subgraphs 的两个图之间进行映射. 例如, 若 vertex1 来自 graph1, vertex2 来自 graph2, 且这两个顶点在子图中可视为等价, 则 get(correspondence_map_1_to_2, vertex1) 将是 vertex2, get(correspondence_map_2_to_1, vertex2) 将是 vertex1. 如果某个顶点 (比如 vertex1, 它在 graph1 中) 与另一图中的顶点 (本例中的 graph2) 不匹配, 则 get(correspondence_map_1_to_2, vertex1) 将是 graph_traits<GraphSecond>::null_vertex(). 对于来自 graph2 的任何未匹配顶点同理, get(correspondence_map_2_to_1, vertex2) 将是 graph_traits<GraphFirst>::null_vertex().

subgraph_size 参数是子图中的顶点数, 即对应映射中包含的匹配顶点对数. 它可用于快速滤除大小不在期望范围内的子图.

从回调返回 false 将立即中止搜索. 否则, 将探查整个搜索空间 [1].

编写回调

在调用任何 mcgregor_common_subgraphs 算法之前, 必须创建一个充当回调的函数对象:

template <typename GraphFirst,
          typename GraphSecond>
struct print_callback {

  print_callback(const GraphFirst& graph1,
                 const GraphSecond& graph2) :
    m_graph1(graph1), m_graph2(graph2) { }

  template <typename CorrespondenceMapFirstToSecond,
            typename CorrespondenceMapSecondToFirst>
  bool operator()(CorrespondenceMapFirstToSecond correspondence_map_1_to_2,
                  CorrespondenceMapSecondToFirst correspondence_map_2_to_1,
                  typename graph_traits<GraphFirst>::vertices_size_type subgraph_size) {

    // Print out correspondences between vertices
    BGL_FORALL_VERTICES_T(vertex1, m_graph1, GraphFirst) {

      // Skip unmapped vertices
      if (get(correspondence_map_1_to_2, vertex1) != graph_traits<GraphSecond>::null_vertex()) {
        std::cout << vertex1 << " <-> " << get(correspondence_map_1_to_2, vertex1) << std::endl;
      }

    }

    std::cout << "---" << std::endl;

    return (true);
  }

  private:
    const GraphFirst& m_graph1;
    const GraphSecond& m_graph2;

};

// Assuming the graph types GraphFirst and GraphSecond have already been defined
GraphFirst graph1;
GraphSecond graph2;

print_callback<GraphFirst, GraphSecond> my_callback(graph1, graph2);

示例 1

如果图中的所有顶点和边都相同, 可以立即开始枚举子图:

// Print out all connected common subgraphs between graph1 and graph2.
// All vertices and edges are assumed to be equivalent and both graph1 and graph2
// have implicit vertex index properties.
mcgregor_common_subgraphs(graph1, graph2, true, my_callback);

示例 2

如果图的顶点和边可以用属性映射来区分, 可以使用 make_property_map_equivalent 函数创建用于顶点或边等价性的二元谓词:

// Assume both graphs were defined with implicit vertex name,
// edge name, and vertex index properties
property_map<GraphFirst, vertex_name_t> vname_map1 = get(vertex_name, graph1);
property_map<GraphSecond, vertex_name_t> vname_map2 = get(vertex_name, graph2);

property_map<GraphFirst, edge_name_t> ename_map1 = get(edge_name, graph1);
property_map<GraphSecond, edge_name_t> ename_map2 = get(edge_name, graph2);

// Print out all connected common subgraphs between graph1 and graph2.
mcgregor_common_subgraphs(graph1, graph2, true, my_callback,
  edges_equivalent(make_property_map_equivalent(ename_map1, ename_map2)).
  vertices_equivalent(make_property_map_equivalent(vname_map1, vname_map2)));

示例 3

有一些辅助函数可用于从回调中给出的对应映射获得过滤图:

// Assuming we're inside the operator() of the callback with a member
// variable m_graph1 representing the first graph passed to
// mcgregor_common_subgraphs.
// ...

// Step 1: Transform a correspondence map into a membership map.
// Any vertex -> bool property map will work
typedef shared_array_property_map<bool, VertexIndexMap> MembershipMap;
MembershipMap membership_map1(num_vertices(m_graph1), get(vertex_index, m_graph1));

// Fill the membership map for m_graph1. GraphSecond is the type of the
// second graph given to mcgregor_common_subgraphs.
fill_membership_map<GraphSecond>(m_graph1, correspondence_map_1_to_2, membership_map1);

// Step 2: Use the membership map from Step 1 to obtain a filtered graph
typedef typename membership_filtered_graph_traits<GraphFirst, MembershipMap>::graph_type
  MembershipFilteredGraph;

MembershipFilteredGraph subgraph1 = make_membership_filtered_graph(m_graph1, membership_map1);

// The filtered graph can be used like a regular BGL graph...
BGL_FORALL_VERTICES_T(vertex1, subgraph1, MembershipFilteredGraph) {
  std::cout << vertex1 << " is present in the subgraph of graph1" << std::endl;
}

注释
