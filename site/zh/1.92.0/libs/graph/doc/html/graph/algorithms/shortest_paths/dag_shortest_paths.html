DAG 最短路径

在带权有向无环图(DAG)上求解单源最短路径问题, 效率高于 Dijkstra 算法和 Bellman-Ford 算法.

复杂度: O(V + E)
定义于: <boost/graph/dag_shortest_paths.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/dag_shortest_paths.hpp>
#include <iostream>
#include <limits>
#include <vector>

struct Node {};
struct Edge { int weight; };

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS, Node, Edge>;
using Vertex = graph_traits<Graph>::vertex_descriptor;

int main() {
    Graph g{5};
    add_edge(0, 1, Edge{2}, g);
    add_edge(0, 2, Edge{6}, g);
    add_edge(1, 3, Edge{5}, g);
    add_edge(2, 3, Edge{1}, g);
    add_edge(3, 4, Edge{3}, g);

    std::vector<int> dist(num_vertices(g));
    std::vector<Vertex> pred(num_vertices(g));
    std::vector<default_color_type> color(num_vertices(g));

    auto idx = get(vertex_index, g);
    dag_shortest_paths(g, vertex(0, g),
        make_iterator_property_map(dist.begin(), idx),
        get(&Edge::weight, g),
        make_iterator_property_map(color.begin(), idx),
        make_iterator_property_map(pred.begin(), idx),
        dijkstra_visitor<null_visitor>(),
        std::less<int>(), std::plus<int>(),
        (std::numeric_limits<int>::max)(), 0);

    for (auto v : make_iterator_range(vertices(g)))
        std::cout << "distance to " << v << " = " << dist[v] << "\n";
}
distance to 0 = 0
distance to 1 = 2
distance to 2 = 6
distance to 3 = 7
distance to 4 = 10

(1) 位置参数版本

template <class VertexListGraph, class DijkstraVisitor,
          class DistanceMap, class WeightMap, class ColorMap,
          class PredecessorMap,
          class Compare, class Combine,
          class DistInf, class DistZero>
void dag_shortest_paths(
    const VertexListGraph& g,
    typename graph_traits<VertexListGraph>::vertex_descriptor s,
    DistanceMap distance, WeightMap weight, ColorMap color,
    PredecessorMap pred, DijkstraVisitor vis,
    Compare compare, Combine combine, DistInf inf, DistZero zero);
方向 参数 说明

IN

const VertexListGraph& g

算法将作用于其上的图对象. 类型 VertexListGraph 必须是 顶点列表图 的模型.

IN

vertex_descriptor s

源顶点. 所有距离都将从该顶点开始计算, 且最短路径树将以该顶点为根.

UTIL/OUT

DistanceMap distance

从源顶点 s 到图中各顶点 g 的最短路径权重记录在此属性映射中. 最短路径权重是沿最短路径的各边权重之和. 类型 DistanceMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作距离映射的键类型. 距离映射的值类型必须是 幺半群 的元素类型, 该幺半群由 combine 函数对象与作为单位元的 zero 对象构成. 此外, 距离值类型还必须具有 严格弱序, 由 compare 函数对象提供.

IN

WeightMap weight

图中每条边的权重或“长度”. 类型 WeightMap 必须是 可读属性映射 的模型. 图的边描述符类型必须可用作权重映射的键类型. 映射的值类型必须与距离映射的值类型满足 可加.

UTIL/OUT

ColorMap color

此映射在算法执行期间用于标记顶点. 顶点初始为白色, 插入队列时变为灰色, 从队列移除时再变为黑色. 算法结束时, 从源顶点可达的顶点都将被标为黑色, 其余顶点仍为白色. 类型 ColorMap 必须是 读/写属性映射 的模型. 顶点描述符必须可用作该映射的键类型, 且映射的值类型必须是 颜色值 的模型.

OUT

PredecessorMap pred

前驱映射记录最小生成树中的边. 算法完成后, 边 (p[u],u) (对所有 u in V) 都在最小生成树中. 若 p[u] = u, 则 u 要么是源顶点, 要么是从源不可达的顶点. PredecessorMap 类型必须是 读/写属性映射, 其键类型与值类型都与图的顶点描述符类型相同.

IN

DijkstraVisitor vis

使用此参数指定希望在算法内特定事件点发生的动作. 类型 DijkstraVisitor 必须是 Dijkstra 访问器 概念的模型. 访问器对象按值传递 [1].

IN

Compare compare

此函数用于比较距离, 以确定哪个顶点距源顶点更近. Compare 类型必须是 二元谓词 的模型, 且其参数类型与 DistanceMap 属性映射的值类型相匹配.

IN

Combine combine

此函数用于合并距离以计算路径的距离. Combine 类型必须是 二元函数 的模型. 该二元函数的第一个参数类型必须与 DistanceMap 属性映射的值类型相匹配, 第二个参数类型必须与 WeightMap 属性映射的值类型相匹配. 结果类型必须与距离值类型相同.

IN

DistInf inf

inf 对象必须是任何 D 对象中的最大值. 也就是说, compare(d, inf) == true 对任何 d != inf 成立. 类型 D 是 DistanceMap 的值类型.

IN

DistZero zero

zero 值必须是某个 幺半群 的幺元, 该幺半群由距离值与 combine 函数对象构成. 类型 D 是 DistanceMap 的值类型.

IN

const VertexListGraph& g

算法将作用于其上的图对象. 类型 VertexListGraph 必须是 顶点列表图 的模型.

IN

源顶点. 所有距离都将从该顶点开始计算, 且最短路径树将以该顶点为根.

IN

params

通过 bgl_named_params 传入的命名参数. 接受以下参数:
方向 命名参数 说明 / 默认

IN

weight_map(WeightMap w_map)

边权重 (见 (1) 的 WeightMap weight).
默认: get(edge_weight, g)

IN

vertex_index_map(VertexIndexMap i_map)

它把每个顶点映射到范围 [0, num_vertices(g)) 内的一个整数. 这对于松弛边时高效更新堆数据结构是必要的. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.

OUT

predecessor_map(PredecessorMap p_map)

前驱映射 (见 (1) 的 PredecessorMap pred).
默认: dummy_property_map

UTIL/OUT

distance_map(DistanceMap d_map)

距离映射(见 (1) DistanceMap distance).
默认: iterator_property_map, 由 std::vector 构造, 其元素类型为 WeightMap’s value type of size `num_vertices(g), 并使用 i_map 作为索引映射.

IN

distance_compare(CompareFunction cmp)

距离比较函数 (见 (1) 的 Compare compare).
默认: std::less<D> 与 D=typename property_traits<DistanceMap>::value_type

IN

distance_combine(CombineFunction cmb)

距离组合函数 (见 (1) 的 Combine combine).
默认: std::plus<D> 与 D=typename property_traits<DistanceMap>::value_type

IN

distance_inf(D inf)

无穷值 (见 (1) 的 DistInf inf).
默认: std::numeric_limits<D>::max()

IN

distance_zero(D zero)

幺元 (见 (1) 的 DistZero zero).
默认: D() 与 D=typename property_traits<DistanceMap>::value_type

UTIL/OUT

color_map(ColorMap c_map)

颜色映射(见 (1) ColorMap color).
默认: 一个 iterator_property_map, 由 std::vector 构造, 其元素类型为 default_color_type、大小为 num_vertices(g), 并使用 i_map 作为索引映射.

OUT

visitor(DijkstraVisitor v)

访问器 (见 (1) 的 DijkstraVisitor vis).
默认: dijkstra_visitor<null_visitor>

说明

本算法 [5] 在带权有向无环图(DAG)上求解单源最短路径问题. 对 DAG 而言, 本算法比 Dijkstra 算法和 Bellman-Ford 算法都更高效. 当所有边权重都等于 1 时, 应改用广度优先搜索. 关于最短路径问题的定义以及该问题的一些背景, 参见 最短路径算法 一节.

从 dag_shortest_paths() 函数获取输出有两个主要选项. 若通过 distance_map() 参数提供距离属性映射, 则从源顶点到图中每个其他顶点的最短距离将记录在该距离映射中. 此外, 还可以把最短路径树记录在前驱映射中: 对每个顶点 u in V, p[u] 将是 u 在最短路径树中的前驱(除非 p[u] = u, 此时 u 或者是源顶点, 或者是从源顶点不可达的顶点). 除这两个选项外, 用户还可以提供自定义访问器, 在算法的任意事件点处执行动作.

访问器事件点

  • vis.initialize_vertex(u, g): 在算法开始之前对图中每个顶点各调用一次.

  • vis.examine_vertex(u, g) 在某顶点被加入集合 S 时对其调用. 此时可知 (p[u],u) 是一条最短路径树边, 故 d[u] = delta(s,u) = d[p[u]] + w(p[u],u). 并且, 已考察顶点的距离单调递增 d[u1] <= d[u2] <= d[un].

  • vis.examine_edge(e, g) 在顶点被加入集合 S 之后, 立即对其每条出边调用.

  • vis.edge_relaxed(e, g) 对边 (u,v) 调用, 条件是 d[u] + w(u,v) < d[v]. 边 (u,v) 若是对顶点 v 的最后一次松弛所涉及的边, 则它是最短路径树中的一条边.

  • vis.discover_vertex(v, g) 当边 (u,v) 被检查且 v 为 WHITE 时, 对顶点 v 调用. 由于顶点被发现时即被标为 GRAY, 每个可达顶点恰好被发现一次.

  • vis.edge_not_relaxed(e, g): 若边未被松弛 (见上) 则调用.

  • vis.finish_vertex(u, g) 在顶点的所有出边都被检查之后, 对该顶点调用.

使用本算法的示例见 example/dag_shortest_paths.cpp.

注释

[1] 由于访问器参数按值传递, 如果你的访问器包含状态, 那么算法期间对状态的任何修改都作用于访问器对象的一个副本, 而不是传入的访问器对象. 因此你可能希望访问器以指针或引用的方式持有该状态.
