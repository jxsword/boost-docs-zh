[maximum|minimum]_cycle_ratio

使用 Howard 迭代策略算法计算带权有向多重图的最大或最小圈比率.

复杂度: 经验上 O(|E|); 空间 O(7|V|) 外加图的存储
定义于: <boost/graph/howard_cycle_ratio.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/howard_cycle_ratio.hpp>
#include <iostream>
#include <vector>

// Two bundled edge fields replace the nested
// `property<edge_weight_t, double, property<edge_weight2_t, double>>`.
struct Edge { double weight, transit; };

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS, no_property, Edge>;

int main() {
    Graph g(3);
    // Cycle: 0->1->2->0 with weights 3,1,2 and transit times 1,1,1
    add_edge(0, 1, Edge{3.0, 1.0}, g);
    add_edge(1, 2, Edge{1.0, 1.0}, g);
    add_edge(2, 0, Edge{2.0, 1.0}, g);
    add_edge(0, 2, Edge{10.0, 1.0}, g);

    std::vector<graph_traits<Graph>::edge_descriptor> cycle;
    double mcr = minimum_cycle_ratio(g,
        get(vertex_index, g),
        get(&Edge::weight, g),
        get(&Edge::transit, g), &cycle);

    std::cout << "Minimum cycle ratio: " << mcr << "\n";
    std::cout << "Cycle length: " << cycle.size() << " edges\n";
}
Minimum cycle ratio: 2
Cycle length: 3 edges

(1) maximum_cycle_ratio (默认 FloatTraits)

template <typename Graph, typename VertexIndexMap,
          typename EdgeWeight1, typename EdgeWeight2>
double maximum_cycle_ratio(
    const Graph& g, VertexIndexMap vim,
    EdgeWeight1 ewm, EdgeWeight2 ew2m,
    std::vector<typename boost::graph_traits<Graph>::edge_descriptor>* pcc = 0);
方向 参数 说明

IN

const Graph& g

一个带权有向多重图. 图类型必须是 顶点列表图 和 关联图 的模型.

IN

VertexIndexMap vim

把图的每个顶点映射到范围 [0, num_vertices(g)) 内的唯一整数. 必须是 可读属性映射 的模型.

IN

EdgeWeight1 ewm

W1 边权重函数. 必须是 可读属性映射 的模型.

IN

EdgeWeight2 ew2m

W2 边权重函数. 应为非负. 该算法的实际限制是图中每个有向圈的总权重必须为正. 必须是 可读属性映射 的模型.

OUT

std::vector<typename boost::graph_traits<Graph>::edge_descriptor>* pcc

若非零, 则一个临界圈将被存储在 std::vector 中. 默认: 0

IN

FloatTraits

封装浮点类型的可定制 limits 类信息. 该类型 必须 为浮点类型提供一个关联类型 value_type. 默认值是 boost::mcr_float<>, 其定义如下:

[source,cpp] ~~ template <typename Float = double> struct mcr_float { typedef Float value_type;

static Float infinity() { return (std::numeric_limits<value_type>::max)(); }

static Float epsilon() { return Float(-0.005); } }; ~~

值 FloatTraits::epsilon() 控制算法的"容差". 增大 epsilon 的绝对值可以略微缩短执行时间, 但有错过全局最优的风险. 减小绝对值则可能陷入无限循环. 最好的选择是保持此参数不变.

OUT

std::vector<typename boost::graph_traits<Graph>::edge_descriptor>* pcc

template <typename FloatTraits, typename Graph, typename VertexIndexMap,
          typename EdgeWeightMap, typename EdgeIndexMap>
typename FloatTraits::float_type minimum_cycle_mean(
    const Graph& g, VertexIndexMap vim,
    EdgeWeightMap ewm, EdgeIndexMap eim,
    std::vector<typename graph_traits<Graph>::edge_descriptor>* pcc = 0,
    FloatTraits = FloatTraits());

参数与 (5) 相同, 外加 (2) 中描述的 FloatTraits 模板参数.

说明

maximum_cycle_ratio() 函数计算带权有向多重图 G=(V,E,W1,W2) 的最大圈比率, 其中 V 是顶点集, E 是边集, W1 和 W2 是边权重函数, W2 非负. 作为多重图, G 可以有多条边连接一对顶点.

最大 (最小) 圈比率 (mcr) 是图的所有圈中圈比率的最大 (最小) 值. 若一个圈的比率等于 mcr, 则称其为 临界 圈. 若图没有圈, maximum_cycle_ratio()/minimum_cycle_ratio() 返回 -FloatTraits::infinity()/FloatTraits::infinity(). 若 pcc 参数非零, 则一个临界圈会被写入对应的边描述符 std::vector. 向量中的边以使 *pcc[0], *ppc[1], …​, *ppc[n] 成为正确路径的方式存储.

该算法出自 Howard 迭代策略算法, 描述见 [72]. Ali Dasdan、Sandy S. Irani 和 Rajesh K. Gupta 在其论文 Efficient Algorithms for Optimum Cycle Mean and Optimum Cost to Time Ratio Problems [73] 中指出, 这是迄今为止 (1999) 最有效的算法.

为方便起见, 还提供了函数 maximum_cycle_mean() 和 minimum_cycle_mean(). 它们接受一个 EdgeIndexMap, 而不是两个独立的边权重映射 (EdgeWeight1 和 EdgeWeight2).

返回

计算出的最大 (或最小) 圈比率. 若图没有圈, 则返回 -FloatTraits::infinity() (对应 maximum_cycle_ratio) 或 FloatTraits::infinity() (对应 minimum_cycle_ratio).
