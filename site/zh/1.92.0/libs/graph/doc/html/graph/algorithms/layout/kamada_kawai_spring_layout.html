kamada_kawai_spring_layout

面向连通无向图的 Kamada-Kawai 弹簧布局.

定义于: <boost/graph/kamada_kawai_spring_layout.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/kamada_kawai_spring_layout.hpp>
#include <boost/graph/circle_layout.hpp>
#include <boost/graph/topology.hpp>
#include <iostream>
#include <vector>
#include <iomanip>

struct Spring { double length; };

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, vecS, undirectedS, no_property, Spring>;

    Graph g(5);
    add_edge(0, 1, Spring{1.0}, g);
    add_edge(1, 2, Spring{1.0}, g);
    add_edge(2, 3, Spring{1.0}, g);
    add_edge(3, 4, Spring{1.0}, g);
    add_edge(4, 0, Spring{1.0}, g);

    using Topo = rectangle_topology<>;
    Topo topo(0.0, 0.0, 100.0, 100.0);
    using Point = Topo::point_type;

    std::vector<Point> pos(num_vertices(g));
    auto pos_map = make_iterator_property_map(pos.begin(), get(vertex_index, g));

    circle_graph_layout(g, pos_map, 25.0);

    // Bundled spring-length via member pointer — no edge_weight_t tag needed.
    bool ok = kamada_kawai_spring_layout(g, pos_map, get(&Spring::length, g),
        topo, side_length(50.0), layout_tolerance<double>(0.1));

    std::cout << std::fixed << std::setprecision(1);
    std::cout << "converged: " << (ok ? "yes" : "no") << "\n";
    for (auto v : make_iterator_range(vertices(g))) {
        std::cout << "vertex " << v << ": ("
                  << pos[v][0] << ", " << pos[v][1] << ")\n";
    }
}

vertex 1: (7.7, 23.8)
vertex 2: (-20.2, 14.7)

template<typename Topology, typename Graph, typename PositionMap,
         typename WeightMap, typename T, bool EdgeOrSideLength,
         typename Done, typename VertexIndexMap,
         typename DistanceMatrix, typename SpringStrengthMatrix,
         typename PartialDerivativeMap>
bool kamada_kawai_spring_layout(
    const Graph& g,
    PositionMap position,
    WeightMap weight,
    const Topology& space,
    unspecified edge_or_side_length,
    Done done,
    typename property_traits<WeightMap>::value_type spring_constant,
    VertexIndexMap index,
    DistanceMatrix distance,
    SpringStrengthMatrix spring_strength,
    PartialDerivativeMap partial_derivatives);
方向 参数 说明

IN

const Graph& g

图, 其类型 Graph 必须符合 VertexListGraph、EdgeListGraph 和 IncidenceGraph 概念. 图必须是无向且连通的.

OUT

PositionMap position

该属性映射用于存储每个顶点的位置. 类型 PositionMap 必须是 可写属性映射 的模型, 以图的顶点描述符类型为键类型, Topology::point_type 为值类型.

IN

WeightMap weight

图中每条边的权重或"长度". 权重必须全部非负, 若某条边为负, 算法将抛出 negative_edge 异常. 类型 WeightMap 必须是 可读属性映射 的模型. 图的边描述符类型必须可用作权重映射的键类型. 此映射的值类型必须与距离映射的值类型相同.
默认: get(edge_weight, g)

IN

const Topology& space

用于布置顶点的拓扑. 此参数描述布局区域的大小与形状, 以及其维数; 当前实现最多支持三个维度. 拓扑的更详细描述 (含 BGL 提供的拓扑列表) 见 单独的文档.

IN

unspecified edge_or_side_length

提供布局中一条边的单位长度 e 或显示区域一边的长度 s, 且必须相应地为 boost::edge_length(e) 或 boost::side_length(s).

IN

Done done

一个 4 实参函数对象, 被传入 delta_p 的当前值 (即顶点 p 的能量)、顶点 p、图 g, 以及一个布尔标志, 指示 delta_p 是系统中的最大能量 (当 true 时) 还是被移动顶点的能量.
默认: 在权重映射的值类型上实例化的 layout_tolerance.

IN

typename property_traits<WeightMap>::value_type spring_constant

与每根弹簧强度相乘的常数. 较大的值创建能量更多、可能需要更长时间才能稳定的系统; 较小的值创建能量较少、能快速稳定但不一定产生美观布局的系统.
默认: 1.

IN

VertexIndexMap index

从顶点到 0 与 num_vertices(g) 之间索引值的映射.
默认: get(vertex_index,g). 注意: 如果使用此默认值, 请确保你的图拥有内部属性 vertex_index. 例如, adjacency_list (带 VertexList=listS) 就没有内部属性 vertex_index.

UTIL/OUT

DistanceMatrix distance

此参数将用于存储从每个顶点到其他每个顶点的距离, 它在算法的前几个阶段计算. 该值的类型必须是 BasicMatrix 的模型, 值类型等于权重映射的值类型.
默认: 向量的向量.

UTIL/OUT

SpringStrengthMatrix spring_strength

此矩阵将用于存储每对顶点之间弹簧的强度. 该值的类型必须是 BasicMatrix 的模型, 值类型等于权重映射的值类型.
默认: 权重映射值类型的向量的向量.

UTIL

PartialDerivativeMap partial_derivatives

一个属性映射, 用于存储每个顶点相对于其当前坐标的偏导数. 它必须是一个 读/写属性映射, 值类型为 Topology::point_difference_type. 默认是使用图的顶点索引映射构建的迭代器属性映射.
默认: 一个 iterator_property_map, 由 std::vector 的 Topology::point_difference_type 创建.

说明

这个 算法 [52] 对连通无向图执行 (二维) 图布局. 它把图的布局关联到一个动态弹簧系统并最小化该系统内的能量. 两个顶点之间弹簧的强度与这两个顶点之间最短距离 (图论意义) 的平方成反比. 从本质上说, 在图论意义上更接近的顶点 (即沿边跟随更近) 拥有更强的弹簧, 因此会被放置得更靠近.

在调用此算法之前, 建议通过 circle_graph_layout 把顶点沿正 n 边形的顶点放置.

返回

true 若布局成功; 若检测到负权圈或图不连通则为 false.
