邻接矩阵

固定大小、基于矩阵的图, 适用于稠密图, 边插入、移除和查找均为 O(1).

定义于: <boost/graph/adjacency_matrix.hpp>
模型: 顶点与边列表图、关联图、邻接矩阵、可变属性图、可复制构造、可赋值

概要

template <class Directed = directedS,
          class VertexProperty = no_property,
          class EdgeProperty = no_property,
          class GraphProperty = no_property,
          class Allocator = std::allocator<bool>>
class adjacency_matrix { ... };

adjacency_matrix 类使用传统的邻接矩阵存储格式实现 BGL 图接口. 对具有 V 个顶点的图, 使用一个 V x V 矩阵, 其中每个元素 aij 是一个布尔标志, 说明是否存在从顶点 i 到顶点 j 的边.

  • 边的插入、移除和查找均为 O(1).

  • 内存使用为 O(V2) 而非 O(V + E).

  • 对每个顶点的所有出边的遍历(例如 BFS)需要 O(V2) 时间而非 O(V + E).

  • 最适合稠密图(E 接近 V2). 对稀疏图, 优先使用 adjacency_list.

该类对传统数据结构做了扩展, 允许通过 捆绑属性 或 内部属性 把对象附加到顶点和边. 所有属性值类型必须可复制构造、可赋值且可默认构造.

对无向图, 只存储下三角(对角线及以下), 把内存降至 (V2)/2.

adjacency_matrix 不支持 add_vertex() 或 remove_vertex(). 顶点数量在构造时固定.
adjacency_matrix 不支持 bidirectionalS 作为 Directed 模板参数. 只能使用 directedS 或 undirectedS.
邻居迭代(out_edges()、in_edges()、adjacent_vertices())对每个顶点都是 O(V), 即使对稀疏图也是如此, 因为必须检查矩阵行中的每个潜在邻居.

快速用法

#include <boost/graph/adjacency_matrix.hpp>
#include <boost/range/iterator_range.hpp>
#include <iostream>
#include <string>

struct City { std::string name; };
struct Road { double km; };

int main() {
    using namespace boost;
    using Graph = adjacency_matrix<directedS, City, Road>;

    // Vertex count is fixed at construction
    Graph g(4);
    g[0].name = "Paris";
    g[1].name = "Lyon";
    g[2].name = "Marseille";
    g[3].name = "Nice";

    add_edge(0, 1, Road{460}, g);
    add_edge(0, 2, Road{775}, g);
    add_edge(1, 2, Road{310}, g);
    add_edge(2, 3, Road{200}, g);

    // O(1) edge lookup
    auto result = edge(0, 1, g);
    if (result.second) {
        std::cout << "Paris -> Lyon: " << g[result.first].km << " km\n";
    }

    // Traverse
    for (auto v : make_iterator_range(vertices(g))) {
        for (auto e : make_iterator_range(out_edges(v, g))) {
            std::cout << g[source(e, g)].name << " -> "
                      << g[target(e, g)].name
                      << " (" << g[e].km << " km)\n";
        }
    }
}
Paris -> Lyon: 460 km
Paris -> Lyon (460 km)
Paris -> Marseille (775 km)
Lyon -> Marseille (310 km)
Marseille -> Nice (200 km)

结构修改

std::pair<edge_descriptor, bool>
add_edge(vertex_descriptor u, vertex_descriptor v, adjacency_matrix& g)

把边 (u,v) 添加到图中, 并返回新边的边描述符. 若该边已存在, 不添加重复项, 且 bool 标志为 false. 此操作不会使任何迭代器或描述符失效.
(可变图 所要求.)

std::pair<edge_descriptor, bool>
add_edge(vertex_descriptor u,
         vertex_descriptor v,
         const EdgeProperty& p,
         adjacency_matrix& g)

把边 (u,v) 添加到图中, 并把 p 作为该边的内部属性值. 重复边行为见前一个 add_edge().

void remove_edge(vertex_descriptor u, vertex_descriptor v, adjacency_matrix& g)

从图中移除边 (u,v).
(可变图 所要求.)

void remove_edge(edge_descriptor e, adjacency_matrix& g)

从图中移除边 e. 等价于 remove_edge(source(e, g), target(e, g), g).

void clear_vertex(vertex_descriptor u, adjacency_matrix& g)

移除与顶点 u 相连的所有边(入边和出边). 该顶点仍出现在图的顶点集中.
(可变图 所要求.)

关联类型

算法是模板. 要为顶点、边或迭代器声明变量, 通过 graph_traits 提取具体类型:

using Graph = adjacency_matrix<directedS>;
using Vertex = graph_traits<Graph>::vertex_descriptor;
using Edge = graph_traits<Graph>::edge_descriptor;
类型 说明

graph_traits<adjacency_matrix>::vertex_descriptor

顶点描述符类型.(图 所要求.)

graph_traits<adjacency_matrix>::edge_descriptor

边描述符类型.(图 所要求.)

graph_traits<adjacency_matrix>::vertex_iterator

由 vertices() 返回的迭代器. 建模 RandomAccessIterator.(顶点列表图 所要求.)

graph_traits<adjacency_matrix>::edge_iterator

由 edges() 返回的迭代器. 建模 MultiPassInputIterator.(边列表图 所要求.)

graph_traits<adjacency_matrix>::out_edge_iterator

由 out_edges() 返回的迭代器. 建模 MultiPassInputIterator.(关联图 所要求.)

graph_traits<adjacency_matrix>::in_edge_iterator

由 in_edges() 返回的迭代器. 建模 MultiPassInputIterator.(双向图 所要求.)

graph_traits<adjacency_matrix>::adjacency_iterator

由 adjacent_vertices() 返回的迭代器. 建模与出边迭代器相同的概念.(邻接图 所要求.)

graph_traits<adjacency_matrix>::directed_category

directed_tag 或 undirected_tag, 取决于 Directed 参数.(图 所要求.)

graph_traits<adjacency_matrix>::edge_parallel_category

总是 disallow_parallel_edge_tag. 不允许平行边.(图 所要求.)

graph_traits<adjacency_matrix>::vertices_size_type

顶点数量的类型.(顶点列表图 所要求.)

graph_traits<adjacency_matrix>::edges_size_type

边数量的类型.(边列表图 所要求.)

graph_traits<adjacency_matrix>::degree_size_type

顶点出边数量的类型.(关联图 所要求.)

property_map<adjacency_matrix, PropertyTag>::type / const_type

顶点或边属性的映射类型. PropertyTag 必须与 VertexProperty 或 EdgeProperty 中的属性相匹配.(属性图 所要求.)

稳定性与失效

顶点数量在构造时固定. 顶点描述符是 [0, n) 内的整数, 永不改变. add_edge() 和 remove_edge() 不会使任何迭代器或描述符失效.
