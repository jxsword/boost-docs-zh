传递闭包

计算有向图的 传递闭包, 只要存在从 u 到 v 的路径, 就添加边 (u,v).

复杂度: O(|V||E|)
定义于: <boost/graph/transitive_closure.hpp>

示例

#include <iostream>
#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/transitive_closure.hpp>

int main() {
    using Graph = boost::adjacency_list<boost::vecS, boost::vecS, boost::directedS>;
    Graph g;
    boost::add_edge(0, 1, g);
    boost::add_edge(1, 2, g);
    boost::add_edge(2, 3, g);

    Graph tc;
    boost::transitive_closure(g, tc);

    std::cout << "Transitive closure edges:\n";
    for (auto ep = edges(tc); ep.first != ep.second; ++ep.first) {
        std::cout << "  " << source(*ep.first, tc) << " -> " << target(*ep.first, tc) << "\n";
    }
}
Transitive closure edges:
  0 -> 1
  0 -> 2
  0 -> 3
  1 -> 2
  1 -> 3
  2 -> 3

template <typename Graph, typename GraphTC,
          typename G_to_TC_VertexMap, typename VertexIndexMap>
void transitive_closure(
    const Graph& g, GraphTC& tc,
    G_to_TC_VertexMap g_to_tc_map, VertexIndexMap index_map);
方向 参数 说明

IN

const Graph& g

有向图. 类型 Graph 必须建模 顶点列表图、邻接图 和 邻接矩阵 概念.

OUT

GraphTC& tc

要写入传递闭包的有向图. 类型 GraphTC 必须建模 顶点可变图 和 边可变图 概念.

UTIL/OUT

G_to_TC_VertexMap g_to_tc_map

此映射把输入图中的每个顶点映射到输出传递闭包图中对应的新顶点.

IN

VertexIndexMap index_map

此映射将每个顶点映射到区间 [0, num_vertices(g)) 内的一个整数. 仅在使用默认颜色属性映射时才需要此参数. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作该映射的键类型.

它把每个顶点映射到范围 [0, num_vertices(g)) 内的一个整数. 只有在使用默认颜色属性映射时才需要此参数. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.
默认: get(vertex_index, g). 注意: 如果使用此默认值, 请确保你的图拥有内部属性 vertex_index. 例如, adjacency_list (带 VertexList=listS) 就没有内部属性 vertex_index.

说明

图 G = (V,E) 的传递闭包是一个图 G* = (V,E*), 使得 E* 包含边 (u,v) 当且仅当 G 包含一条 路径(至少一条边), 从 u 到 v. transitive_closure() 函数把输入图 g 变换为传递闭包图 tc.

感谢 Vladimir Prus 实现此算法!

注释

实现 transitive_closure() 函数所用算法基于强分量的检测[45, 48]. 下面的讨论描述该算法(以及一些相关背景理论).

一个顶点的 后继集合, 对顶点 v 记作 Succ(v), 是 可达 自顶点 v 的顶点集合. 与 v 在传递闭包 G* 中相邻的顶点集合, 与 v 在原图 G 中的后继集合相同. 计算传递闭包等价于为 G 中的每个顶点计算其后继集合.

同一强分量中的所有顶点具有相同的后继集合(因为分量中每个顶点都可从其他所有顶点到达). 因此, 为强分量中的每个顶点计算后继集合是冗余的; 只需对每个分量计算其中一个顶点的后继集合即可.

以下是算法的概要:

  1. 计算图的 强连通分量.

  2. 构造凝聚图. 凝聚图 是一个图 G'=(V',E'), 基于图 G=(V,E): V' 中每个顶点对应 G 中的一个强连通分量, 而边 (u,v) 属于 E' 当且仅当 E 中存在一条边, 连接 u 分量中的某个顶点与 v 分量中的某个顶点.

  3. 对凝聚图计算传递闭包. 使用以下算法完成:

     for each vertex u in G' in reverse topological order
   for each vertex v in Adj[u]
     if (v not in Succ(u))
       Succ(u) = Succ(u) U { v } U Succ(v)   // "U" means set union

    按逆拓扑序考虑顶点, 以确保在计算顶点 u 的后继集合时, Adj[u] 中每个顶点的后继集合已经计算完毕.

    集合并运算的一种优化实现可提升算法的性能. 因此, 本实现采用 链分解 [46,47]. G 的顶点被划分为链 Z1, ..., Zk, 其中每条链 Zi 是 G 中的一条路径, 且链中顶点的拓扑编号递增. 后继集合 S 于是用与各链的交集的集合表示, 即 S = Ui=1..k (Zi & S). 每个交集可以用路径 Zi 中第一个也属于 S 的顶点表示, 因为路径的其余部分保证也在 S 中. 交集的集合因此由一个长度为 k 的向量表示, 向量的第 i 个元素存储 S 与 Zi 之交中的第一个顶点.

    计算两个后继集合的并 S3 = S1 U S2, 可用以下操作在 O(k) 时间内完成:

      for i = 0...k
    S3[i] = min(S1[i], S2[i]) // where min compares the topological number of the vertices

  4. 创建图 G*, 基于凝聚图 G'* 的传递闭包.
