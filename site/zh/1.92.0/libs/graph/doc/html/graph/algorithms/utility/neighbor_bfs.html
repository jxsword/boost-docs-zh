邻居 BFS

有向图的 BFS 变体, 在每个顶点处同时探索出边和入边. 在有向图的标准 BFS 中, 只沿出边前进. 邻居 BFS 还会沿入边前进, 实际上在遍历期间把图当作无向图处理, 同时保留边的方向信息.

复杂度: O(V + E)
定义于: <boost/graph/neighbor_bfs.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/neighbor_bfs.hpp>
#include <iostream>

struct print_visitor : public boost::neighbor_bfs_visitor<> {
    template <typename Vertex, typename Graph>
    void discover_vertex(Vertex v, const Graph&) const {
        std::cout << v << " ";
    }
};

int main() {
    using namespace boost;
    using Graph = adjacency_list<vecS, vecS, bidirectionalS>;

    Graph g(5);
    add_edge(0, 1, g);
    add_edge(2, 1, g);
    add_edge(3, 0, g);
    add_edge(1, 4, g);

    std::cout << "Neighbor BFS from vertex 1: ";
    neighbor_breadth_first_search(g, vertex(1, g),
        visitor(print_visitor()));
    std::cout << "\n";
}
Neighbor BFS from vertex 1: 1 4 0 2 3

(1) neighbor_breadth_first_search(命名参数版本)

template <typename VertexListGraph, typename P, typename T, typename R>
void neighbor_breadth_first_search(
    const VertexListGraph& g,
    typename graph_traits<VertexListGraph>::vertex_descriptor s,
    const bgl_named_params<P, T, R>& params);

把颜色映射初始化为白色, 然后从 s 开始搜索.

方向 参数 说明

IN

const VertexListGraph& g

必须建模 双向图 和 顶点列表图.

IN

vertex_descriptor s

搜索的源顶点.

IN

params

接受 color_map(ColorMap)、visitor(NeighborBFSVisitor) 和 buffer(Buffer&). 默认值: 一个 two_bit_color_map(按 vertex_index 索引), 一个空的邻居 BFS 访问器, 以及一个 boost::queue<vertex_descriptor>.

(2) neighbor_breadth_first_visit(命名参数版本)

template <typename IncidenceGraph, typename P, typename T, typename R>
void neighbor_breadth_first_visit(
    IncidenceGraph& g,
    typename graph_traits<IncidenceGraph>::vertex_descriptor s,
    const bgl_named_params<P, T, R>& params);

与 (1) 相同, 但 不 初始化颜色映射 — 调用者必须预先填充. 只要求 关联图(加上访问器事件所要求的), 因为无需枚举顶点.

(3) neighbor_bfs_visitor

template <class Visitors = null_visitor>
class neighbor_bfs_visitor;

template <class Visitors>
neighbor_bfs_visitor<Visitors> make_neighbor_bfs_visitor(Visitors vis);

建模 NeighborBFSVisitorConcept 的访问器适配器. 除标准 BFS 事件点(discover_vertex、examine_vertex、examine_out_edge、tree_out_edge 等)之外, 它还对每个顶点的入边分派 examine_in_edge 和 tree_in_edge 事件. 使用 make_neighbor_bfs_visitor(…​) 可从用户提供的访问器(或事件访问器列表)构造一个.

访问器事件点

访问器(建模 NeighborBFSVisitorConcept)的以下成员在遍历期间被调用:

  • vis.initialize_vertex(v, g) — 对每个顶点, 在搜索开始之前调用(仅 (1)).

  • vis.discover_vertex(v, g) — 在顶点首次被遇到时.

  • vis.examine_vertex(v, g) — 在顶点从队列取出时.

  • vis.examine_out_edge(e, g) / vis.examine_in_edge(e, g) — 对被检查顶点的每条出边/入边.

  • vis.tree_out_edge(e, g) / vis.tree_in_edge(e, g) — 对目标此前为白色的每条边.

  • vis.non_tree_out_edge(e, g) / vis.non_tree_in_edge(e, g) — 其他情况.

  • vis.gray_target(e, g) / vis.black_target(e, g) — 当目标为灰色/黑色时.

  • vis.finish_vertex(v, g) — 在 v 的所有关联边都被检查之后.

若只需要在有向图上做无向遍历, 可以考虑使用 make_reverse_graph 获得双向视图, 然后运行标准 BFS.
