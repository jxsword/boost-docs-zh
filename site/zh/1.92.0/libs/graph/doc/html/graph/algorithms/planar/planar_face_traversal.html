平面面遍历

遍历由平面嵌入定义的平面图的所有面, 沿途调用访问器事件点.

复杂度: O(n + m)
定义于: <boost/graph/planar_face_traversal.hpp>

若有多个连通分量, 每个分量会报告自己的外面而非共享的一个外面, 因此计数高出 C - 1 (相对于欧拉的 F = E - V + C + 1). 例如, 两个不相交的三角形会报告四个面, 而正确计数是三个. 要恢复正确值, 需减去 C - 1, 其中 C 只统计至少有一条边的分量 (孤立顶点不增加面, 但 connected_components 会把它们计入).

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/boyer_myrvold_planar_test.hpp>
#include <boost/graph/planar_face_traversal.hpp>
#include <iostream>
#include <vector>

using namespace boost;

struct Edge { int idx; };

using Graph = adjacency_list<vecS, vecS, undirectedS, no_property, Edge>;

struct face_counter : public planar_face_traversal_visitor {
    int count = 0;
    void begin_face() { ++count; }
};

int main() {
    Graph g(4);
    add_edge(0, 1, g); add_edge(1, 2, g);
    add_edge(2, 3, g); add_edge(3, 0, g);
    add_edge(0, 2, g);

    int i = 0;
    for (auto e : make_iterator_range(edges(g))) { g[e].idx = i++; }

    using embedding_t = std::vector<std::vector<graph_traits<Graph>::edge_descriptor>>;
    embedding_t embedding(num_vertices(g));
    boyer_myrvold_planarity_test(boyer_myrvold_params::graph = g,
        boyer_myrvold_params::embedding = &embedding[0]);

    face_counter visitor;
    planar_face_traversal(g, &embedding[0], visitor, get(&Edge::idx, g));
    std::cout << "Number of faces: " << visitor.count << "\n";
}
Number of faces: 3

概要

template <typename Graph, typename PlanarEmbedding,
          typename PlanarFaceVisitor, typename EdgeIndexMap>
void planar_face_traversal(
    const Graph& g,
    PlanarEmbedding embedding,
    PlanarFaceVisitor& visitor,
    EdgeIndexMap em);
方向 参数 说明

IN

const Graph& g

一个无向图. 类型 Graph 必须是 VertexAndEdgeListGraph 的模型.

IN

PlanarEmbedding embedding

PlanarEmbedding 的一个模型.

IN

PlanarFaceVisitor& visitor

PlanarFaceVisitor 的一个模型.

IN

EdgeIndexMap em

一个可读属性映射, 把来自 g 的边映射到范围 [0, num_edges(g)) 内的相异整数.
默认: get(edge_index, g)

说明

若图可以画在二维空间中而任何两条边都不交叉, 则称该图是 平面的. 平面图的任何嵌入都会把平面分成若干相异区域, 这些区域由图中的边序列围成. 这些区域称为 面.

平面图的面的遍历包括: 迭代图的所有面, 并在每个面上迭代该面的所有顶点和边. 对每个面的所有顶点和边的迭代沿着面的边界绕行.

在双连通图中, 每个面由一个圈围成, 每条边恰好属于两个面. 因此, 在双连通图上调用 planar_face_traversal 时, 每条边将恰好被访问两次: 各在两个不同的面上一次, 且任何顶点在特定面上不会被访问超过一次. planar_face_traversal 在非双连通图上的输出不太直观 — 例如, 若图仅由一条顶点路径组成 (因而只有一个面), planar_face_traversal 会 绕着 该路径迭代, 每条边访问两次, 且某些顶点被访问不止一次. planar_face_traversal 不访问孤立顶点.

与 Boost 图库中的其他图遍历算法一样, 平面面遍历是一种泛型遍历, 可以通过重新定义某些访问器事件点来定制. 通过定义合适的访问器, 此遍历可用于枚举平面图的各个面、对平面图三角剖分, 甚至构造平面图的对偶.

例如, 在上面的图上, 下列访问器的实例 my_visitor:

struct output_visitor: public planar_face_traversal_visitor
{
    void begin_face() { std::cout << "New face: "; }
    template <typename Vertex> void next_vertex(Vertex v) { std::cout << v << " "; }
    void finish_face() { std::cout << std::endl; }
};

可以传给 planar_face_traversal 函数:

output_visitor my_visitor;
planar_face_traversal(g, embed, my_visitor); //embed is a planar embedding of g

并可能产生如下输出:

New face: 1 2 5 4
New face: 2 3 4 5
New face: 3 0 1 4
New face: 1 0 3 2

访问器事件点

  • visitor.begin_traversal(): 在访问任何面之前调用一次.

  • visitor.begin_face(): 对每个面调用一次, 在该面的任何顶点或边被访问之前.

  • visitor.end_face(): 对每个面调用一次, 在该面的所有顶点和所有边被访问之后.

  • visitor.next_vertex(Vertex v): 在当前面的每个顶点上各调用一次, 顺序依平面嵌入而定.

  • visitor.next_edge(Edge e): 在当前面的每条边上各调用一次, 顺序依平面嵌入而定.

  • visitor.end_traversal(): 在访问完所有面之后调用一次.

虽然当遍历绕面移动时, next_vertex 保证按序在每个顶点上被调用, next_edge 保证按序在每条边上被调用, 但在 next_vertex 与 next_edge 相互之间的调用顺序上, 于对 begin_face 与 end_face 的调用之间没有任何保证. 这些调用可能交错进行, 也可能所有顶点访问先于所有边访问, 或反之.

planar_face_traversal 迭代输入图边的副本, 因此在访问器事件点期间向图添加边是安全的.
