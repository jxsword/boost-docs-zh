历史

Boost Graph Library 最初是通用图组件库 (Generic Graph Component Library, GGCL), 它是圣母大学 科学计算实验室 (LSC) 的一个软件项目, 由 Andrew Lumsdaine 教授指导. 该实验室的研究方向包括数值线性代数、并行计算以及软件工程 (包括泛型编程).

标准模板库发布后不久, LSC 便开始将泛型编程应用于科学计算. Matrix Template Library (Jeremy Siek 的硕士论文) 是最早的项目之一. 构建 MTL 过程中吸取的许多经验教训被应用到 GGCL 的设计与实现中.

图算法在稀疏矩阵计算中扮演重要角色, 因此 LSC 需要一个好的图库. 然而, 当时可用的图库 (LEDA、GTL、Stanford GraphBase) 都没有采用 STL 的泛型编程风格编写, 因而无法满足 LSC 对灵活性和高性能的要求. 其他一些人也对泛型 C++ 图库表示了兴趣. 在与 Bjarne Stroustrup 的一次会面中, 我们结识了 AT&T 的几位需要这样一个库的人. 在泛型图算法领域此前也已有一些工作, 包括 Alexander Stepanov 编写的一些代码, 以及 Dietmar Kühl 的硕士论文.

带着这些想法, 加上算法课作业的推动, Jeremy 于 1998 年春季开始对一个接口和若干图类进行原型设计. 随后 Lie-Quan Lee 开发了 GGCL 的第一个版本, 该项目成为他的硕士论文课题.

第二年, Jeremy 加入 SGI, 与 Alexander Stepanov 和 Matt Austern 共事. 在此期间, Alex 基于不相交集的连通分量算法被加入 GGCL, Jeremy 开始为 GGCL 编写概念文档, 风格类似于 Matt 的 STL 文档.

在 SGI 工作期间, Jeremy 听说了 Boost, 并兴奋地发现有一群人对创建高质量 C++ 库感兴趣. Boost 中有几位对泛型图算法感兴趣的人, 其中最突出的是 Dietmar Kühl. 关于图结构泛型接口的一些讨论促成了 GGCL 的一次修订, 它与现在的 Boost Graph Library 接口非常接近.

2000 年 9 月 4 日, GGCL 通过了 Boost 正式评审, 成为 Boost Graph Library (BGL). BGL 的首次发布是 2000 年 9 月 27 日.

历史变更日志 (截至 Boost 1.36)

本变更日志冻结于 Boost 1.36 (2008). 现代发布说明见 Boost 发布公告以及 boostorg/graph 的 git 历史. 此处保留它是作为该库早期演进的记录.

1.36.0 版

新算法与组件

  • r_c_shortest_paths, 资源受限最短路径, 来自 Michael Drexl.

1.35.0 版

新算法与组件

  • boykov_kolmogorov_max_flow (原为 kolmogorov_max_flow), 来自 Stephan Diederich, 2006 年 Google Summer of Code 项目的一部分.

  • read_dimacs_max_flow 和 write_dimacs_max_flow, 用于最大流问题, 来自 Stephan Diederich.

  • read_graphml / write_graphml, 用于 GraphML 输入/输出, 来自 Tiago de Paula Peixoto.

  • minimum_cycle_ratio 和 maximum_cycle_ratio, 来自 Dmitry Bufistov 和 Andrey Parfenov.

  • boyer_myrvold_planarity_test, 以及一整套 平面图算法, 来自 Aaron Windsor.

功能增强

  • LEDA 适配器 改进, 来自 Jens Müller.

1.34.1 版

缺陷修复

  • bellman_ford_shortest_paths: 修复了某些负圈未被正确检测到的缺陷.

1.34.0 版

新算法与组件

  • edmonds_maximum_cardinality_matching, 来自 Aaron Windsor.

  • lengauer_tarjan_dominator_tree, 来自 JongSoo Park.

  • compressed_sparse_row_graph, 来自印第安纳大学的 Jeremiah Willcock 和 Douglas Gregor.

  • sorted_erdos_renyi_iterator, 来自印第安纳大学的 Jeremiah Willcock.

功能增强

  • 用于读取 GraphViz 的需编译库现在名为 boost_graph 而不是 bgl-viz.

  • biconnected_components 增加了访问器参数并支持命名参数, 来自 Janusz Piwowarski.

  • adjacency_matrix 现在符合 双向图 概念.

  • adjacency_list 现在可序列化.

  • 新增 edges_size_type 与 vertices_size_type 至 adjacency_list_traits.

  • 向 `adjacency_list's 边描述符添加了 operator< 等.

缺陷修复

  • 修复了导致松弛堆在 x86 Linux 上失败的缺陷.

  • 捆绑属性现在可用于邻接表 I/O.

  • floyd_warshall_all_pairs_shortest_paths 现在正确使用其 compare、inf 和 zero 参数.

  • johnson_all_pairs_shortest_paths 现在支持 compare、combine、inf 和 zero.

  • 修复了 smallest_last_vertex_ordering.hpp 中的一个缺陷, 该缺陷可能导致在桶排序器更新期间把顶点移到错误的桶.

1.33.1 版

缺陷修复

  • fruchterman_reingold_force_directed_layout: 修复了网格力对的枚举, 该问题曾导致沿网格线出现一些奇怪的图形态.

  • king_ordering 和 cuthill_mckee_ordering: 修复了这些算法的多分量版本出现失败的缺陷.

1.33.0 版

新算法与组件

  • 实验性的 Python 绑定, 来自 Doug Gregor 和印第安纳大学.

  • floyd_warshall_all_pairs_shortest_paths, 来自 Lauren Foutz 和 Scott Hill.

  • astar_search, 来自 Kristopher Beevers 和 Jufeng Peng.

  • fruchterman_reingold_force_directed_layout, 来自 Doug Gregor 和印第安纳大学.

  • biconnected_components 和 articulation_points, 来自印第安纳大学.

  • gursoy_atun_layout, 来自印第安纳大学的 Jeremiah Willcock 和 Doug Gregor.

  • king_ordering, 来自印第安纳大学的 D. Kevin McGrath.

  • erdos_renyi_iterator.

  • plod_iterator.

  • small_world_iterator.

功能增强

  • bellman_ford_shortest_paths 现在允许指定起始顶点, 从而自行执行初始化.

  • undirected_dfs 现在是数据递归的, 在某些情况下带来了性能提升, 来自 Synge Todo.

  • dijkstra_shortest_paths 现在使用松弛堆 [55] 作为其优先队列, 把复杂度改进到 O(V log V), 并提升了较大图的实际性能.

  • read_graphviz 现在有了新的基于 Spirit 的解析器, 可用于所有图类型并支持图上的任意属性, 来自 Ron Garcia. 旧的基于 Bison 的 GraphViz 读取器已被弃用, 后来被移除.

  • write_graphviz 现在支持动态属性的输出 (即通过新的 read_graphviz 读入的属性).

  • cuthill_mckee_ordering 已被改写为对 breadth_first_search 的一次调用, 现在支持含多个分量的图.

  • subgraph 现在支持 捆绑属性. get_property 现在指的是子图的属性, 而不是根图的属性.

  • filtered_graph 现在支持 捆绑属性.

  • reverse_graph 现在支持 捆绑属性、set_property 和 get_property.

缺陷修复

  • bellman_ford_shortest_paths 现在能更好地处理不可达顶点.

  • adjacency_list: 使用 OutEdgeListS = listS 去除平行边的问题已修复. 复制与交换的问题已修复.

  • 增量连通分量: 修复了 incremental_components 例程中一个可能导致错误结果的缺陷.

  • remove_out_edge_if 函数 (用于无向 adjacency_list) 已被重写, 不应再解引用奇异迭代器.

  • write_graphviz 现在接受一个 vertex_id 参数, 用于为节点命名.

  • read_graphviz 现在接受空的属性列表.

  • sequential_vertex_coloring 已被更新、测试并编写了文档.
