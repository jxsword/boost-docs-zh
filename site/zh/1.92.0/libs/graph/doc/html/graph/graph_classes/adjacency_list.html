adjacency_list

广义邻接表图, 顶点、边和属性的存储均可配置.

定义于: <boost/graph/adjacency_list.hpp>
序列化: <boost/graph/adj_list_serialize.hpp>
模型: 顶点与边列表图、可变属性图、可复制构造、可赋值、可序列化

概要

template <class OutEdgeList = vecS,
          class VertexList = vecS,
          class Directed = directedS,
          class VertexProperties = no_property,
          class EdgeProperties = no_property,
          class GraphProperties = no_property,
          class EdgeList = listS>
class adjacency_list { ... };

BGL 的通用图类. 每个顶点存储其出边的列表. 前三个模板参数控制最重要的权衡:

  • OutEdgeList: 用哪个容器存储每个顶点的边(vecS 求速度, setS 防重复)

  • VertexList: 用哪个容器存储顶点(vecS 求快速查找, listS 求稳定描述符)

  • Directed: directedS、undirectedS 或 bidirectionalS(入边使每条边的内存翻倍)

这些选择如何影响性能, 见 操作复杂度; 哪些操作会使迭代器失效, 见 稳定性与失效. 形式化数据结构定义见 图论回顾.

快速用法

#include <boost/graph/adjacency_list.hpp>
#include <boost/range/iterator_range.hpp>
#include <iostream>

struct City { std::string name; };
struct Road { double km; };

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS, City, Road>;

void print_graph(const Graph& g) {
    for (auto v : make_iterator_range(vertices(g))) {
        for (auto e : make_iterator_range(out_edges(v, g))) {
            std::cout << "  " << g[source(e, g)].name
                      << " -> " << g[target(e, g)].name
                      << " (" << g[e].km << " km)\n";
        }
    }
}

int main() {
    Graph g;
    auto paris     = add_vertex(City{"Paris"}, g);
    auto lyon      = add_vertex(City{"Lyon"}, g);
    auto marseille = add_vertex(City{"Marseille"}, g);
    add_edge(paris, lyon, Road{460}, g);
    add_edge(paris, marseille, Road{775}, g);
    add_edge(lyon, marseille, Road{310}, g);

    std::cout << "3 vertices, " << num_edges(g) << " edges:\n";
    print_graph(g);

    remove_edge(paris, marseille, g);
    std::cout << "\nAfter remove_edge(paris, marseille):\n";
    print_graph(g);

    auto ei = out_edges(lyon, g).first;
    remove_edge(ei, g);
    std::cout << "\nAfter remove_edge(iterator):\n";
    print_graph(g);
}
3 vertices, 3 edges:
  Paris -> Lyon (460 km)
  Paris -> Marseille (775 km)
  Lyon -> Marseille (310 km)

After remove_edge(paris, marseille):
  Paris -> Lyon (460 km)
  Lyon -> Marseille (310 km)

After remove_edge(iterator):
  Paris -> Lyon (460 km)

模板参数

参数 说明 默认值

OutEdgeList

用于表示每个顶点边列表的容器的选择器.

vecS

VertexList

用于表示图的顶点列表的容器的选择器. 使用 vecS 时, 顶点有一个内置的 vertex_index(位于 [0, num_vertices(g)) 中), 在移除顶点时会重新编号.

vecS

Directed

选择图是有向、无向, 还是有向且具双向边访问(同时可访问出边和入边)的选择器. 选项为 directedS、undirectedS 和 bidirectionalS.

directedS

VertexProperties

顶点数据的捆绑结构或 property<> 标签. 见 属性映射.

no_property

EdgeProperties

边数据的捆绑结构或 property<> 标签. 见 属性映射.

no_property

GraphProperties

图对象的属性存储.

no_property

EdgeList

用于表示图边列表的容器的选择器.

listS
从 adjacency_list 获得的属性映射是 Lvalue 属性映射(图非 const 时可变, 否则为常量).

               EdgeIterator last,

std::pair<edge_iterator, edge_iterator>
edges(const adjacency_list& g)

返回一个迭代器范围, 提供对图 g 边集的访问.

std::pair<adjacency_iterator, adjacency_iterator>
adjacent_vertices(vertex_descriptor u, const adjacency_list& g)

返回一个迭代器范围, 提供对与顶点 u 相邻的顶点(在图 g 中)的访问. 例如, 若 u → v 是图中的一条边, 则 v 会在此迭代器范围内.

std::pair<inv_adjacency_iterator, inv_adjacency_iterator>
inv_adjacent_vertices(vertex_descriptor u, const adjacency_list& g)

返回一个迭代器范围, 提供对图 g 中与 u 相邻的顶点的访问. (inv 用于反向.) 例如, 若 v → u 是图中的一条边, 则 v 会在此迭代器范围内. 此函数仅适用于双向和无向的 `adjacency_list`.

std::pair<out_edge_iterator, out_edge_iterator>
out_edges(vertex_descriptor u, const adjacency_list& g)

返回一个迭代器范围, 提供对顶点 u(在图 g 中)出边的访问. 若图是无向的, 此迭代器范围提供对与顶点 u 关联的所有边的访问. 对有向图和无向图, 对出边 e, 有 source(e, g) == u 且 target(e, g) == v, 其中 v 是相邻于 u 的顶点.

std::pair<in_edge_iterator, in_edge_iterator>
in_edges(vertex_descriptor v, const adjacency_list& g)

返回一个迭代器范围, 提供对顶点 v(在图 g 中)入边的访问. 仅当指定了 bidirectionalS 作为 Directed 模板参数时, 此操作才可用. 对入边 e, 有 target(e, g) == v 和 source(e, g) == u, 其中 u 是相邻于 v 的某个顶点, 无论图是有向的还是无向的.

结构修改

std::pair<edge_descriptor, bool>
add_edge(vertex_descriptor u, vertex_descriptor v, adjacency_list& g)

把边 (u,v) 添加到图中, 并返回新边的边描述符. 对不允许平行边的图, 若该边已在图中, 则不会添加重复项, 且 bool 标志将为 false. 当标志为 false 时, 返回的边描述符指向已存在的边.

新边在出边列表中的位置通常未指定, 不过出边列表的排序可以通过选择 OutEdgeList 来实现.

若 VertexList 选择器为 vecS, 且顶点描述符 u 或 v(它们是整数)的值大于图中当前的顶点数量, 则图会被扩大, 使顶点数量为 std::max(u,v) + 1.

若 OutEdgeList 选择器为 vecS, 则此操作会使任何 out_edge_iterator(属于顶点 u)失效. 若 OutEdgeList 是用户定义的容器, 且该容器在 push(container, x) 被调用时会使其迭代器失效(见 自定义邻接表存储 一节), 同样适用此规则. 若图同时是双向的, 则任何 in_edge_iterator(属于 v)也会失效. 若图是无向的, 则任何 out_edge_iterator(属于 v)也会失效. 若图是有向的, 则 add_edge() 也会使任何 edge_iterator 失效.

std::pair<edge_descriptor, bool>
add_edge(vertex_descriptor u,
         vertex_descriptor v,
         const EdgeProperties& p,
         adjacency_list& g)

把边 (u,v) 添加到图中, 并把 p 作为该边内部属性存储的值. 更多细节另见前一个 add_edge() 非成员函数.

void remove_edge(vertex_descriptor u, vertex_descriptor v, adjacency_list& g)

从图中移除边 (u,v).

此操作会使指向边 (u,v) 的所有未完成的边描述符或迭代器失效. 此外, 若 OutEdgeList 选择器为 vecS, 则此操作会使指向顶点 u 边列表的任何迭代器失效, 在无向和双向情况下也使指向顶点 v 边列表的迭代器失效. 另外, 对有向图, 此操作会使任何 edge_iterator 失效.

void remove_edge(edge_descriptor e, adjacency_list& g)

从图中移除边 e. 在多重图的情况下, 这与 remove_edge(u, v, g) 函数不同. 此 remove_edge(e, g) 函数移除一条边, 而 remove_edge(u, v, g) 函数移除所有边 (u,v).

此操作会使指向描述符 e 所指同一条边的所有未完成的边描述符和迭代器失效. 此外, 此操作会使指向 target(e, g) 边列表的任何迭代器失效. 另外, 对有向图, 此操作会使图的任何 edge_iterator 失效.

void remove_edge(out_edge_iterator iter, adjacency_list& g)

其效果与 remove_edge(*iter, g) 相同. 区别在于此函数对有向图具有常数时间复杂度, 而 remove_edge(e, g) 的时间复杂度为 O(E/V).

template <class Predicate>
void remove_out_edge_if(vertex_descriptor u, Predicate predicate, adjacency_list& g)

从图中移除顶点 u 的所有满足 predicate 的出边. 也就是说, 若谓词应用于边描述符时返回 true, 则该边被移除.

对描述符和迭代器稳定性的影响, 与对每条被移除的边调用 remove_edge() 的效果相同.

template <class Predicate>
void remove_in_edge_if(vertex_descriptor v, Predicate predicate, adjacency_list& g)

从图中移除顶点 v 的所有满足 predicate 的入边. 也就是说, 若谓词应用于边描述符时返回 true, 则该边被移除.

对描述符和迭代器稳定性的影响, 与对每条被移除的边调用 remove_edge() 的效果相同.

此操作适用于无向和双向 adjacency_list 图, 但不适用于有向图.

template <class Predicate>
void remove_edge_if(Predicate predicate, adjacency_list& g)

从图中移除所有满足 predicate 的边. 也就是说, 若谓词应用于边描述符时返回 true, 则该边被移除.

对描述符和迭代器稳定性的影响, 与对每条被移除的边调用 remove_edge() 的效果相同.

vertex_descriptor
add_vertex(adjacency_list& g)

向图中添加一个顶点, 并返回新顶点的顶点描述符.

vertex_descriptor
add_vertex(const VertexProperties& p, adjacency_list& g)

向图中添加一个具有指定属性的顶点. 返回新顶点的顶点描述符.

void clear_vertex(vertex_descriptor u, adjacency_list& g)

移除与顶点 u 相连的所有边(入边和出边). 该顶点仍出现在图的顶点集中.

对描述符和迭代器稳定性的影响, 与对每条边调用 remove_edge()(以 u 为源点或目标点)的效果相同.

void clear_out_edges(vertex_descriptor u, adjacency_list& g)

移除顶点 u 的所有出边. 该顶点仍出现在图的顶点集中.

对描述符和迭代器稳定性的影响, 与对每条边调用 remove_edge()(以 u 为源点)的效果相同.

此操作不适用于无向图(请改用 clear_vertex()).

void clear_in_edges(vertex_descriptor u, adjacency_list& g)

移除顶点 u 的所有入边. 该顶点仍出现在图的顶点集中.

对描述符和迭代器稳定性的影响, 与对每条边调用 remove_edge()(以 u 为目标点)的效果相同.

此操作仅适用于双向图.

void remove_vertex(vertex_descriptor u, adjacency_list& g)

从图的顶点集中移除顶点 u. 假定移除时没有与顶点 u 相连的边. 确保这一点的一种方法是事先调用 clear_vertex().

若 VertexList 模板参数(属于 adjacency_list)为 vecS, 则此操作会使图的所有顶点描述符、边描述符和迭代器失效. 每个顶点的内置 vertex_index_t 属性会重新编号, 使得操作之后顶点索引仍构成连续范围 [0, num_vertices(g)). 若你使用基于内置顶点索引的外部属性存储, 则需要调整外部存储. 另一种选择是不使用内置顶点索引, 而是使用属性来添加自己的顶点索引属性. 若你需要频繁使用 remove_vertex() 函数, 那么 listS 选择器对 VertexList 模板参数是好得多的选择.

关联类型

BGL 算法是模板. 要为顶点、边或迭代器声明变量, 需要来自你特定图的具体类型. graph_traits 提取它们:

using Graph = adjacency_list<vecS, vecS, directedS, City, Road>;
using Vertex = graph_traits<Graph>::vertex_descriptor;
using Edge   = graph_traits<Graph>::edge_descriptor;

Vertex u = vertex(0, g);

要获得稳定描述符, 使用 listS 或 setS; 追求速度用 vecS.

使用 VL=vecS 时, remove_vertex() 会使 一切 失效: 所有描述符, 所有迭代器. 你保存的任何顶点描述符(在向量、前驱映射等中)都会失效. 不能同时迭代和移除: 
using Graph = adjacency_list<listS, vecS>;
Graph g(N);

// WRONG: remove_vertex invalidates vi and vi_end
graph_traits<Graph>::vertex_iterator vi, vi_end;
for (boost::tie(vi, vi_end) = vertices(g); vi != vi_end; ++vi) {
    remove_vertex(*vi, g);  // undefined behavior
}

使用 VL=listS 时, 只有被移除顶点自身的描述符和迭代器失效. 其他迭代器仍然有效:

using Graph = adjacency_list<listS, listS>;
Graph g(N);

// OK: advance iterator before removing
graph_traits<Graph>::vertex_iterator vi, vi_end, next;
boost::tie(vi, vi_end) = vertices(g);
for (next = vi; vi != vi_end; vi = next) {
    ++next;
    remove_vertex(*vi, g);  // only *vi is invalidated
}
