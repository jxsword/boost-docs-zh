核数

计算图的 k-核分解. 每个顶点被指派一个核数: 使该顶点属于一个所有顶点度都 >= k 的子图的最大 k. 更高的核数表示更稠密、更紧密连接的子结构.

复杂度: O(V + E)
定义于: <boost/graph/core_numbers.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/core_numbers.hpp>
#include <iostream>
#include <vector>

// Bundled vertex property
struct VertexProps {
    std::string label;
};

int main() {
    // Undirected graph with bundled vertex properties
    using Graph = boost::adjacency_list<
        boost::vecS, boost::vecS, boost::undirectedS, VertexProps>;
    using Vertex = boost::graph_traits<Graph>::vertex_descriptor;
    using SizeType = boost::graph_traits<Graph>::vertices_size_type;

    Graph g(7);
    g[0].label = "a";
    g[1].label = "b";
    g[2].label = "c";
    g[3].label = "d";
    g[4].label = "e";
    g[5].label = "f";
    g[6].label = "g";

    // Dense 4-clique: a-b-c-d (vertices 0,1,2,3)
    add_edge(0, 1, g);
    add_edge(0, 2, g);
    add_edge(0, 3, g);
    add_edge(1, 2, g);
    add_edge(1, 3, g);
    add_edge(2, 3, g);

    // Peripheral vertices attached loosely
    add_edge(3, 4, g);  // d -- e
    add_edge(4, 5, g);  // e -- f
    add_edge(5, 6, g);  // f -- g

    // Compute core numbers into a vector property map
    std::vector<SizeType> core_nums(boost::num_vertices(g));
    auto core_map = boost::make_iterator_property_map(
        core_nums.begin(), boost::get(boost::vertex_index, g));

    boost::core_numbers(g, core_map);

    std::cout << "Core numbers (k-core decomposition):\n";
    for (Vertex v = 0; v < boost::num_vertices(g); ++v) {
        std::cout << "  vertex " << v
                  << " (" << g[v].label << "): "
                  << core_nums[v] << "\n";
    }
}
Core numbers (k-core decomposition):
  vertex 0 (a): 3
  vertex 1 (b): 3
  vertex 2 (c): 3
  vertex 3 (d): 3
  vertex 4 (e): 1
  vertex 5 (f): 1
  vertex 6 (g): 1

顶点 a-d 构成一个 4-团 (K4), 因此每个顶点的核数都是 3 (团内每个顶点的度都是 3). 顶点 e-f-g 构成附着于该团的一条链, 因此它们的核数是 1.

(1) core_numbers (无权, 默认访问器)

template <typename Graph, typename CoreMap>
typename property_traits<CoreMap>::value_type
core_numbers(Graph& g, CoreMap c);

(2) core_numbers (无权, 自定义访问器)

template <typename Graph, typename CoreMap, typename CoreNumVisitor>
typename property_traits<CoreMap>::value_type
core_numbers(Graph& g, CoreMap c, CoreNumVisitor vis);

(3) core_numbers (带权)

template <typename Graph, typename CoreMap, typename EdgeWeightMap,
          typename VertexIndexMap, typename CoreNumVisitor>
typename property_traits<CoreMap>::value_type
core_numbers(Graph& g, CoreMap c,
             EdgeWeightMap wm, VertexIndexMap vim, CoreNumVisitor vis);

当提供边权重时, 顶点的核数基于带权度 (关联边权重之和) 而非无权度.

(4) weighted_core_numbers (默认访问器)

template <typename Graph, typename CoreMap>
typename property_traits<CoreMap>::value_type
weighted_core_numbers(Graph& g, CoreMap c);

(3) 的便捷包装, 使用 get(edge_weight, g) 作为权重映射, get(vertex_index, g) 作为索引映射, 以及一个 null_visitor.

(5) weighted_core_numbers (自定义访问器)

template <typename Graph, typename CoreMap, typename CoreNumVisitor>
typename property_traits<CoreMap>::value_type
weighted_core_numbers(Graph& g, CoreMap c, CoreNumVisitor vis);

与 (4) 相同, 但带显式访问器.

(6) core_numbers_visitor

template <class Visitors = null_visitor>
class core_numbers_visitor : public bfs_visitor<Visitors>;

template <class Visitors>
core_numbers_visitor<Visitors> make_core_numbers_visitor(Visitors vis);

内部使用的访问器类型. CoreNumbersVisitorConcept 的模型. 派生自 bfs_visitor, 在 k-核剥离期间每次移除顶点时添加 examine_vertex(v, g) 事件. 使用 make_core_numbers_visitor(…​) 从一个适配后的访问器构造.

参数

方向 参数 说明

IN

Graph& g

必须符合 关联图 和 顶点列表图 概念. 对于带权重载, 还必须符合 边列表图 概念.

OUT

CoreMap c

ReadWritePropertyMap. 顶点描述符 → 核数.

IN

EdgeWeightMap wm

(带权) 从边描述符到权重的 ReadablePropertyMap.

IN

VertexIndexMap vim

(带权) 从顶点到范围 [0, num_vertices(g)) 内整数的 ReadablePropertyMap.

IN

CoreNumVisitor vis

CoreNumbersVisitorConcept 的模型. 通常通过 make_core_numbers_visitor 构造.

函数返回被指派的最大核数.
