度量旅行商近似

一种 旅行商 启发式算法, 为边带权且满足三角不等式的完全连通无向图生成顶点巡回.

复杂度: O(E log V)
定义于: <boost/graph/metric_tsp_approx.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/metric_tsp_approx.hpp>
#include <iostream>
#include <vector>

struct Edge { double weight; };

using namespace boost;
using Graph = adjacency_list<vecS, vecS, undirectedS, no_property, Edge>;
using Vertex = graph_traits<Graph>::vertex_descriptor;

int main() {
    const int N = 4;
    Graph g(N);
    double w[][4] = {{0,10,15,20},{10,0,35,25},{15,35,0,30},{20,25,30,0}};
    for (int i = 0; i < N; ++i)
        for (int j = i + 1; j < N; ++j)
            add_edge(i, j, Edge{w[i][j]}, g);

    // Bundled weight via member pointer — the 3-arg overload of
    // metric_tsp_approx_tour takes an explicit WeightMap.
    std::vector<Vertex> tour;
    metric_tsp_approx_tour(g, get(&Edge::weight, g), std::back_inserter(tour));

    std::cout << "TSP tour:";
    for (auto v : tour) { std::cout << " " << v; }
    std::cout << "\n";
}
TSP tour: 0 1 2 3 0

(1) metric_tsp_approx_from_vertex(完整版)

template <typename VertexListGraph,
          typename WeightMap,
          typename VertexIndexMap,
          typename TSPVertexVisitor>
void metric_tsp_approx_from_vertex(
    const VertexListGraph& g,
    typename graph_traits<VertexListGraph>::vertex_descriptor start,
    WeightMap weightmap,
    VertexIndexMap indexmap,
    TSPVertexVisitor vis);
方向 参数 说明

IN

const VertexListGraph& g

无向图. 类型 VertexListGraph 必须是 顶点列表图 和 关联图 [2] 的模型.

IN

vertex_descriptor start

将作为巡回起点(和终点)的顶点.

IN

WeightMap weightmap

图中每条边的权重. 类型 WeightMap 必须是 可读属性映射 的模型. 图的边描述符类型必须可用作权重映射的键类型.

IN

VertexIndexMap indexmap

它把每个顶点映射到范围 [0, num_vertices(g)) 内的一个整数. 这对于松弛边时高效更新堆数据结构是必要的. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.

OUT

TSPVertexVisitor vis

使用此参数指定在算法访问巡回中的顶点时希望发生的动作. 类型 TSPVertexVisitor 必须是 TSP 巡回访问器 概念的模型. 访问器对象按值传递 [1].

说明

这是一种旅行商启发式算法, 为边带权且满足三角不等式的完全连通无向图生成顶点巡回. 当前实现基于 Introduction to Algorithms 第 1029 页给出的算法. 本实现在最坏情况下生成的解的长度为最优巡回的两倍. 伪代码如下.

伪代码

TSP-APPROX(G, w)
  select a vertex r in V[G]
  compute a minimum spanning tree T for G from root r
    using PRIM-MST(G, r, w)
  let L be the list of vertices visited in a preorder traversal of T
  return (the Hamiltonian cycle H that visites the vertices in the order L)

不接受 start 顶点的重载使用 *vertices(g).first 作为默认起始顶点. 不接受 WeightMap 的重载使用 get(edge_weight, g) 作为默认值. 不接受 VertexIndexMap 的重载使用 get(vertex_index, g) 作为默认值 — 若使用此默认值, 请确保图具有内部 vertex_index 属性(例如, adjacency_list 与 VertexList=listS 一起使用时没有内部 vertex_index 属性).

注释

[1] 由于访问器参数按值传递, 如果你的访问器包含状态, 那么算法期间对状态的任何修改都作用于访问器对象的一个副本, 而不是传入的访问器对象. 因此你可能希望访问器以指针或引用的方式持有该状态.

[2] 传入 adjacency_list 时若顶点 未 按 vecS 的选择进行设置, 将导致 O(n2) 的性能.
