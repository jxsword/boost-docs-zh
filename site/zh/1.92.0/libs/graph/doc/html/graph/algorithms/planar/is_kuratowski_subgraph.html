is_kuratowski_subgraph

验证一组边在某图中构成 Kuratowski 子图.

复杂度: O(n)
定义于: <boost/graph/is_kuratowski_subgraph.hpp>

概要

template <typename Graph, typename ForwardIterator,
          typename VertexIndexMap>
bool is_kuratowski_subgraph(
    const Graph& g,
    ForwardIterator begin,
    ForwardIterator end,
    VertexIndexMap vm);
方向 参数 说明

IN

const Graph& g

一个无自环、无平行边的无向图. 类型 Graph 必须是 VertexListGraph 的模型.

IN

ForwardIterator begin, end

一个 ForwardIterator 范围, 其中 value_type 等于 graph_traits<Graph>::edge_descriptor.

IN

VertexIndexMap vm

一个可读属性映射, 把来自 g 的顶点映射到范围 [0, num_vertices(g)) 内的相异整数.
默认: get(vertex_index, g)

说明

is_kuratowski_subgraph(g, begin, end) 返回 true, 当且仅当范围 [begin, end) 定义的边序列构成一个 Kuratowski 子图 (位于图 g 中). 若你需要验证任意图是否有 K5 或 K3,3 次图, 应改用函数 boyer_myrvold_planarity_test 来分离这样的次图, 而不是用本函数. is_kuratowski_subgraph 的存在是为了辅助测试与验证函数 boyer_myrvold_planarity_test; 出于这个原因, 它期望其输入是构成 Kuratowski 子图的一个受限边集, 详见下文.

is_kuratowski_subgraph 由给定的边序列创建一个临时图, 并反复收缩边, 直到最终得到一个所有顶点度数为 3 或所有顶点度数为 4 的图. 然后把最终收缩后的图与 K5 或 K3,3 进行比对, 使用的是 Boost 图库的 isomorphism 函数. 收缩过程首先选择与度数为 1 的顶点相邻的边并收缩它们. 若不再有此类边, 则转至与度数为 2 的顶点相邻的边. 若此阶段之后只剩下度数为 3 的顶点, 则把该图与 K3,3 比对. 否则, 若至少有一个度数为 4 的顶点, 则按需收缩与度数为 3 的顶点相邻的边, 并把最终的图与 K5 比对.

为了使此过程是确定性的, 我们对传给 is_kuratowski_subgraph 的输入图施加以下两条限制:

  1. 产生 Kuratowski 子图所需的任何边收缩都不会造成同一对顶点之间出现多重边 (若 a 与 b 共享一个公共邻居, 则边 {a,b} 在收缩过程的任何时刻都不会被收缩.)

  2. 若图收缩为 K5, 则当图收缩到只剩度数至少为 3 的顶点后, 不存在仅含度数为 3 的顶点的圈.

第二条限制既用于区分目标是 K5 还是 K3,3, 也用于在确定目标是 K5 后确定性地收缩度数为 4 的顶点. 函数 boyer_myrvold_planarity_test 输出的 Kuratowski 子图保证满足上述两条要求.

返回

true 若边范围构成 Kuratowski 子图, 否则 false.
