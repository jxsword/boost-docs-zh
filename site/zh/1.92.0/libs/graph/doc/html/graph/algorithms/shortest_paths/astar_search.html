A* 启发式搜索

在带权有向或无向图上实现启发式搜索, 适用于所有边权重非负的情形.

复杂度: O((E + V) log V)
定义于: <boost/graph/astar_search.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/astar_search.hpp>
#include <iostream>
#include <vector>
#include <limits>

struct Edge { int weight; };

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS, no_property, Edge>;
using Vertex = graph_traits<Graph>::vertex_descriptor;

struct zero_heuristic : public astar_heuristic<Graph, int> {
    int operator()(Vertex) const { return 0; }
};

// Stop when target is found
struct found_target { Vertex v; };
struct target_visitor : public default_astar_visitor {
    target_visitor(Vertex t) : m_target{t} {}
    void examine_vertex(Vertex u, const Graph&) const {
        if (u == m_target) { throw found_target{u}; }
    }
    Vertex m_target;
};

int main() {
    Graph g{4};
    add_edge(0, 1, Edge{2}, g);
    add_edge(1, 2, Edge{3}, g);
    add_edge(0, 2, Edge{8}, g);
    add_edge(2, 3, Edge{1}, g);

    using CostType = int;
    using IndexMap = decltype(get(vertex_index, std::declval<Graph&>()));

    auto n = num_vertices(g);
    std::vector<CostType> dist(n, (std::numeric_limits<CostType>::max)());
    std::vector<CostType> cost(n, (std::numeric_limits<CostType>::max)());
    std::vector<Vertex> pred(n);

    auto index_map = get(vertex_index, g);
    auto dist_map = make_iterator_property_map(dist.begin(), index_map);
    auto cost_map = make_iterator_property_map(cost.begin(), index_map);
    auto pred_map = make_iterator_property_map(pred.begin(), index_map);
    auto weight_map = get(&Edge::weight, g);
    two_bit_color_map<IndexMap> color_map{n, index_map};

    CostType inf = (std::numeric_limits<CostType>::max)();
    CostType zero_val = CostType{};

    try {
        astar_search(g, vertex(0, g), zero_heuristic(),
            target_visitor{3},
            pred_map, cost_map, dist_map, weight_map,
            index_map, color_map,
            std::less<CostType>{}, closed_plus<CostType>{inf},
            inf, zero_val);
    } catch (const found_target&) {}

    for (auto v : make_iterator_range(vertices(g))) {
        std::cout << "distance to " << v << " = " << dist[v] << "\n";
    }
}
distance to 0 = 0
distance to 1 = 2
distance to 2 = 5
distance to 3 = 6

(1) 位置参数版本

template <typename VertexListGraph, typename AStarHeuristic,
          typename AStarVisitor, typename PredecessorMap,
          typename CostMap, typename DistanceMap,
          typename WeightMap, typename VertexIndexMap,
          typename ColorMap,
          typename CompareFunction, typename CombineFunction,
          typename CostInf, typename CostZero>
inline void astar_search(
    const VertexListGraph& g,
    typename graph_traits<VertexListGraph>::vertex_descriptor s,
    AStarHeuristic h, AStarVisitor vis,
    PredecessorMap predecessor, CostMap cost,
    DistanceMap distance, WeightMap weight,
    VertexIndexMap index_map, ColorMap color,
    CompareFunction compare, CombineFunction combine,
    CostInf inf, CostZero zero);
方向 参数 说明

IN

const VertexListGraph& g

算法将作用于其上的图对象. 类型 VertexListGraph 必须是 顶点列表图 和 关联图 的模型.

IN

vertex_descriptor s

搜索的起始顶点. 所有距离都将从该顶点计算, 且最短路径树 (记录在前驱映射中) 将以该顶点为根.

IN

AStarHeuristic h

引导搜索的启发式函数. 类型 AStarHeuristic 必须符合 AStarHeuristic 概念.

IN

AStarVisitor vis

用它来指定你希望发生在算法内某些事件点上的动作. 类型 AStarVisitor 必须符合 AStarVisitor 概念. 访问器对象按值传递 [1].

OUT

PredecessorMap predecessor

前驱映射记录最小生成树中的边. 算法完成后, V 中所有 u 的边 (p[u],u) 都在最小生成树中. 若 p[u] = u, 则 u 要么是起始顶点, 要么是从起点不可达的顶点. PredecessorMap 类型必须是 读/写属性映射, 其键类型与顶点类型都与图的顶点描述符类型相同.

UTIL/OUT

CostMap cost

每个顶点的 f 值. f 值定义为: 从起始顶点到该顶点的代价, 加上从该顶点到目标的估计代价 (由启发式函数 h 返回) 之和. 类型 CostMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作代价映射的键类型. 此映射的值类型必须与距离映射的值类型相同.

UTIL/OUT

DistanceMap distance

从起始顶点 s 到图 g 中每个顶点的最短路径权重记录在此属性映射中. 最短路径权重是沿最短路径的边权重之和. 类型 DistanceMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作距离映射的键类型. 距离映射的值类型是某个 幺半群 的元素类型, 该幺半群由 combine 函数对象与作为幺元的 zero 对象构成. 此外, 距离值类型必须有 严格弱序, 由 compare 函数对象提供.

IN

WeightMap weight

图中每条边的权重或"长度". 权重必须全部非负; 若某条边为负, 算法将抛出 negative_edge 异常. 类型 WeightMap 必须是 可读属性映射 的模型. 图的边描述符类型必须可用作权重映射的键类型. 此映射的值类型必须与距离映射的值类型相同.

IN

VertexIndexMap index_map

它把每个顶点映射到范围 [0, num_vertices(g)) 内的一个整数. 这对于松弛边时高效更新堆数据结构是必要的. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.

UTIL/OUT

ColorMap color

它在算法执行期间用于标记顶点, 表明它们是在 OPEN 还是 CLOSED 列表上. 顶点初始为白色, 插入 OPEN 列表时变为灰色. 随后在被检视并放入 CLOSED 列表时变黑. 算法结束时, 从源顶点可达的顶点将被着为黑色. 所有其他顶点仍为白色. 类型 ColorMap 必须是 读/写属性映射 的模型. 顶点描述符必须可用作映射的键类型, 且映射的值类型必须是 Color Value 的模型.

IN

CompareFunction compare

此函数用于比较距离以判定哪个顶点离起始顶点更近, 并比较 f 值以判定接下来检视 OPEN 列表上的哪个顶点. CompareFunction 类型必须是 二元谓词 的模型, 且实参类型须与 DistanceMap 属性映射的值类型匹配.

IN

CombineFunction combine

此函数用于组合距离以计算路径的距离, 并组合距离与启发式值以计算顶点的 f 值. CombineFunction 类型必须是 二元函数 的模型. 该二元函数的两个实参类型都必须与 DistanceMap 属性映射的值类型匹配 (它与 WeightMap 和 CostMap 属性映射的值类型相同). 结果类型必须与距离值类型相同.

IN

CostInf inf

inf 对象必须是任何 D 对象中的最大值. 也就是说, compare(d, inf) == true 对任何 d != inf 成立. 类型 D 是 DistanceMap 的值类型.

IN

CostZero zero

zero 值必须是某个 幺半群 的幺元, 该幺半群由距离值与 combine 函数对象构成. 类型 D 是 DistanceMap 的值类型.

inline void astar_search_tree(
    const VertexListGraph& g,
    typename graph_traits<VertexListGraph>::vertex_descriptor s,
    AStarHeuristic h, AStarVisitor vis,
    PredecessorMap predecessor, CostMap cost,
    DistanceMap distance, WeightMap weight,

参数与 (1) 相同, 但不带 VertexIndexMap 与 ColorMap. 对算法的树版本, 假定所有顶点始终为白色, 因此重复顶点的检查改用距离映射进行. 若距离映射使用哑值且图含有圈, 算法很可能陷入无限循环.

template <typename VertexListGraph,

void astar_search(

方向 参数 说明

IN

const VertexListGraph& g

图对象. 必须符合 顶点列表图 和 关联图 概念.

IN

vertex_descriptor s

搜索的起始顶点. 所有距离都将从该顶点计算, 且最短路径树将以该顶点为根.

IN

AStarHeuristic h

引导搜索的启发式函数. 类型 AStarHeuristic 必须符合 AStarHeuristic 概念.

IN

params

通过 bgl_named_params 传入的命名参数. 接受以下参数:
方向 命名参数 说明 / 默认

IN

weight_map(WeightMap w_map)

边权重 (见 (1) 的 WeightMap weight).
默认: get(edge_weight, g)

IN

vertex_index_map(VertexIndexMap i_map)

顶点到整数的映射 (见 (1) 的 VertexIndexMap index_map).
默认: get(vertex_index, g). 注意: 如果使用此默认值, 请确保你的图拥有内部属性 vertex_index. 例如, adjacency_list (带 VertexList=listS) 就没有内部属性 vertex_index.

OUT

predecessor_map(PredecessorMap p_map)

前驱映射 (见 (1) 的 PredecessorMap predecessor).
默认: dummy_property_map

UTIL/OUT

distance_map(DistanceMap d_map)

距离映射 (见 (1) 的 DistanceMap distance). 在算法的树版本中, 若图不含有向圈, 此参数可以使用一个返回无穷值的 constant_writable_property_map.
默认: 一个 shared_array_property_map, 值类型与 WeightMap 相同, 大小为 num_vertices(g), 并以 i_map 作为索引映射.

UTIL/OUT

rank_map(CostMap c_map)

每个顶点的 f 值 (见 (1) 的 CostMap cost). 在非树版本中, 类型 CostMap 必须是 读/写属性映射 的模型; 在树版本中是 可写属性映射. 在树版本中, 此参数可以使用 null_property_map.
默认: 一个 shared_array_property_map, 值类型与 DistanceMap 相同, 大小为 num_vertices(g), 并以 i_map 作为索引映射.

UTIL/OUT

color_map(ColorMap c_map)

颜色映射 (见 (1) 的 ColorMap color).
默认: 一个 shared_array_property_map, 值类型为 default_color_type, 大小为 num_vertices(g), 并以 i_map 作为索引映射.

IN

distance_compare(CompareFunction cmp)

距离比较函数 (见 (1) 的 CompareFunction compare).
默认: std::less<D> 与 D=typename property_traits<DistanceMap>::value_type

IN

distance_combine(CombineFunction cmb)

距离组合函数 (见 (1) 的 CombineFunction combine).
默认: std::plus<D> 与 D=typename property_traits<DistanceMap>::value_type

IN

distance_inf(D inf)

无穷值 (见 (1) 的 CostInf inf).
默认: std::numeric_limits<D>::max()

IN

distance_zero(D zero)

幺元 (见 (1) 的 CostZero zero).
默认: D() 与 D=typename property_traits<DistanceMap>::value_type

OUT

visitor(AStarVisitor v)

访问器 (见 (1) 的 AStarVisitor vis).
默认: astar_visitor<null_visitor>

说明

A* 算法

是一种 启发式图搜索算法: A* 搜索由一个 启发式函数 "引导". 启发式函数 h(v) 估计从图中某个非目标状态 (v) 到某个目标状态 g 的代价. 直观地说, A* 沿 (穿过图的) 路径走向目标, 这些路径被启发式函数估计为最好的路径. 与最佳优先搜索不同, A* 考虑了从搜索起点到 v 的已知代价; A* 所走的路径由函数 f(v) = g(v) + h(v) 引导, 其中 h(v) 是启发式函数, g(v) (有时记作 c(s, v)) 是从起点到 v 的已知代价. 显然, A* 的效率很大程度上取决于所用的启发式函数.

A* 算法与 Dijkstra 最短路径算法非常相似. 本实现通过创建一棵搜索树来找出从起始顶点到其他每个顶点的所有最短路径, 并按启发式函数估计的到某个目标的剩余代价来检视顶点. 最常见的用法是用 A* 找出图中某个特定的目标顶点或若干目标顶点, 然后终止搜索.

A* 对搜索 隐式 图特别有用. 隐式图是在搜索开始时尚未完全知道的图. 访问一个顶点时, 它的邻居被"生成"并加入搜索. 隐式图对搜索大型状态空间尤其有用 — 例如在对弈场景 (如国际象棋) 中 — 那里可能无法存储整个图. 使用本 A* 实现执行隐式搜索的方法是: 创建特殊的访问器来生成新扩展顶点的邻居. 请注意, 隐式图必须使用 astar_search_no_init() 或 astar_search_no_init_tree(); 基本的 astar_search() 函数要求图符合 顶点列表图 概念. 两个版本还都要求图类型符合 关联图 概念.

对算法的非树版本, 本 A* 实现基于 OPEN/CLOSED 列表形式. OPEN 列表上的顶点已被算法"发现", 但尚未"扩展" (我们尚未发现它们的相邻顶点). CLOSED 列表上的顶点已被我们的搜索完全检视 (我们已扩展它们并把其子顶点加入 OPEN 列表). 不在任一列表上的顶点在搜索中至今未在任何上下文中遇到. 这种 A* 算法形式相对其他方法的一大优点是避免了状态空间中的"圈"; 搜索不会被图中的环路困住. OPEN/CLOSED 列表用 BGL 的顶点着色机制实现. OPEN 中的顶点着为灰色, CLOSED 中的顶点着为黑色, 未发现的顶点着为白色. 对名称以 _tree 结尾的算法版本, 假定所有顶点始终为白色, 因此重复顶点的检查改用距离映射进行. 若距离映射使用哑值且图含有圈, 算法很可能陷入无限循环.

扩展 OPEN 列表上顶点的准则是: 它在 OPEN 的所有顶点中具有最低的 f(v) = g(v) + h(v) 值. 顶点的代价信息存储在属性映射中.

以下是 A* 启发式搜索算法的伪代码. 在伪代码中, h 是启发式函数, w 是边权重, d 是顶点相对 s 的距离, Q 是按 f (经由某顶点的路径到目标的估计代价) 排序的优先队列. p 是前驱映射. 算法的访问器事件点由右侧的标签标注.

A*(G, s, h)
  for each vertex u in V
    d[u] := f[u] := infinity
    color[u] := WHITE
    p[u] := u
  end for
  color[s] := GRAY
  d[s] := 0
  f[s] := h(s)
  INSERT(Q, s)
  while (Q != O)
    u := EXTRACT-MIN(Q)
    for each vertex v in Adj[u]
      if (w(u,v) + d[u] < d[v])
        d[v] := w(u,v) + d[u]
        f[v] := d[v] + h(v)
        p[v] := u
        if (color[v] = WHITE)
          color[v] := GRAY
          INSERT(Q, v)
        else if (color[v] = BLACK)
          color[v] := GRAY
          INSERT(Q, v)
        end if
      else
        ...
    end for
    color[u] := BLACK
  end while

访问器事件点

  • vis.initialize_vertex(u, g): 在算法开始之前对图中每个顶点各调用一次.

  • vis.discover_vertex(v, g): 在顶点首次被发现并加入 OPEN 列表时调用.

  • vis.examine_vertex(u, g): 在顶点从队列弹出时调用 (即它在 OPEN 列表上代价最低).

  • vis.examine_edge(e, g): 在检视某顶点后立即对其每条出边调用.

  • vis.edge_relaxed(e, g): 若 d[u] + w(u,v) < d[v], 则在边 (u,v) 上调用.

  • vis.edge_not_relaxed(e, g): 若边未被松弛 (见上) 则调用.

  • vis.black_target(e, g): 当 CLOSED 列表上的顶点经由更有效率的路径被"重新发现"并重新加入 OPEN 列表时调用.

  • vis.finish_vertex(u, g): 在顶点被加入 CLOSED 列表时对其调用, 这发生在其所有出边被检视之后.
