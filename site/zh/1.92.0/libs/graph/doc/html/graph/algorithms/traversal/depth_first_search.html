depth_first_search

对有向图中的顶点执行深度优先遍历.

复杂度: O(E + V)
定义于: <boost/graph/depth_first_search.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/depth_first_search.hpp>
#include <iostream>

struct VertexProps { int id; };

using Graph = boost::adjacency_list<boost::vecS, boost::vecS, boost::directedS, VertexProps>;

struct DFSVisitor : boost::default_dfs_visitor {
    void discover_vertex(Graph::vertex_descriptor v, const Graph& g) const {
        std::cout << "discover " << g[v].id << "\n";
    }
    void finish_vertex(Graph::vertex_descriptor v, const Graph& g) const {
        std::cout << "finish   " << g[v].id << "\n";
    }
};

int main() {
    Graph g{4};
    for (int i = 0; i < 4; ++i) { g[i].id = i; }
    boost::add_edge(0, 1, g);
    boost::add_edge(0, 2, g);
    boost::add_edge(1, 3, g);

    boost::depth_first_search(g, boost::visitor(DFSVisitor{}));
}

说明

depth_first_search() 函数对有向图中的顶点执行 深度优先遍历. 在可能的情况下, 深度优先遍历会选择与当前顶点相邻的顶点作为下一个访问对象. 若所有相邻顶点都已被发现, 或没有相邻顶点, 算法就回溯到最后一个仍有未发现邻居的顶点. 一旦所有可达顶点都被访问过, 算法就从其余未发现的顶点中选取一个并继续遍历. 当所有顶点都被访问过后算法结束. 深度优先搜索可用于对图中的边分类, 以及对顶点施加排序. 深度优先搜索 一节描述了 DFS 的各种性质并给出一个示例.

与 BFS 类似, 颜色标记用于记录哪些顶点已被发现. 白色标记尚未发现的顶点, 灰色标记已发现但仍有未发现相邻顶点的顶点. 黑色顶点是已发现且不与任何白色顶点相邻的顶点.

depth_first_search() 函数在算法内的特定事件点调用用户自定义的动作. 这提供了一种机制, 使通用 DFS 算法能够适应其可用的众多场景. 在下面的伪代码中, DFS 的事件点就是右侧的标注. 用户自定义动作必须以访问器对象的形式提供, 即其类型满足 DFS 访问器 要求的对象. 伪代码中展示了算法计算前驱 p、发现时间 d 和完成时间 t. 默认情况下, depth_first_search() 函数不计算这些属性, 但可以使用 predecessor_recorder 和 time_stamper 等预定义访问器来完成.

算法 事件点 
DFS(G)
  for each vertex u in V
    color[u] := WHITE
    p[u] = u
  end for
  time := 0
  if there is a starting vertex s
    call DFS-VISIT(G, s)
  for each vertex u in V
    if color[u] = WHITE
      call DFS-VISIT(G, u)
  end for
  return (p,d_time,f_time)

DFS-VISIT(G, u)
  color[u] := GRAY
  d_time[u] := time := time + 1
  for each v in Adj[u]
    if (color[v] = WHITE)
      p[v] = u
      call DFS-VISIT(G, v)
    else if (color[v] = GRAY)
      ...
    else if (color[v] = BLACK)
      ...
    ...
  end for
  color[u] := BLACK
  f_time[u] := time := time + 1

访问器事件点

  • vis.initialize_vertex(s, g) 在图搜索开始之前对图的每个顶点调用.

  • vis.start_vertex(s, g) 在搜索开始之前对源顶点调用一次.

  • vis.discover_vertex(u, g) 在顶点首次被遇到时调用.

  • vis.examine_edge(e, g) 在每个顶点被发现之后, 对其每条出边调用.

  • vis.tree_edge(e, g) 在每条边成为构成搜索树的边之一时对其调用. 若希望记录前驱, 请在此事件点进行.

  • vis.back_edge(e, g) 对图中的后向边调用.

  • vis.forward_or_cross_edge(e, g) 对图中的前向边或横向边调用. 在无向图中此方法从不被调用.

  • vis.finish_edge(e, g) 对图中的非树边调用, 也对其目标顶点完成之后的每条树边调用.

  • vis.finish_vertex(u, g) 在顶点的所有出边都已加入搜索树且所有相邻顶点都已被发现之后(但在检查它们的出边之前)对该顶点调用.

注释

[1] 由于访问器参数按值传递, 若访问器包含状态, 则算法期间对该状态的任何修改都将作用于访问器对象的副本, 而非传入的访问器对象. 因此, 可能需要让访问器以指针或引用持有该状态.
