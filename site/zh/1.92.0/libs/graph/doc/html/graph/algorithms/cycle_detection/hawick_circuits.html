Hawick 回路

枚举有向多重图中的所有初等回路, 包括自环以及由平行边引起的回路.

复杂度: 最坏情形为指数级; 使用 max_length 限制搜索深度
定义于: <boost/graph/hawick_circuits.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/hawick_circuits.hpp>
#include <iostream>
#include <vector>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS>;
using Vertex = graph_traits<Graph>::vertex_descriptor;

struct circuit_printer {
    template <typename Vertices, typename G>
    void cycle(const Vertices& circuit, const G&) {
        for (auto v : circuit) { std::cout << v << " "; }
        std::cout << "\n";
    }
};

int main() {
    Graph g(4);
    add_edge(0, 1, g); add_edge(1, 2, g);
    add_edge(2, 0, g); add_edge(2, 3, g); add_edge(3, 0, g);

    std::cout << "Circuits:\n";
    circuit_printer visitor;
    hawick_circuits(g, visitor);
}
Circuits:
0 1 2
0 1 2 3

(1) hawick_circuits

template <typename Graph, typename Visitor,
          typename VertexIndexMap>
void hawick_circuits(
    Graph const& graph,
    Visitor visitor,
    VertexIndexMap const& vim = get(vertex_index, graph),
    unsigned int max_length = 0);
方向 参数 说明

IN

Graph const& graph

算法将作用于其上的图. 它必须是 VertexListGraph 和 AdjacencyGraph 概念的模型.

IN

Visitor visitor

每当算法找到一个回路时都会收到通知的访问器. visitor.cycle(circuit, graph) 表达式必须有效, 其中 circuit 是指向随机访问序列的 const 引用, 序列的元素类型为 vertex_descriptor`s. For example, if a circuit `u → v → w → u; 若图中存在该回路, 访问器将以由 (u, v, w) 组成的序列被调用.

IN

VertexIndexMap const& vim

ReadablePropertyMap 概念的一个模型, 把每个 vertex_descriptor 映射到范围 [0, num_vertices(graph)) 内的一个整数.
默认: get(vertex_index, graph)

IN

unsigned int max_length

要考虑的最大回路长度. 超过此长度时会截断深度优先搜索, 通过忽略更长的回路来减少计算时间.
默认: 0 (无上限)

(2) hawick_unique_circuits

template <typename Graph, typename Visitor,
          typename VertexIndexMap>
void hawick_unique_circuits(
    Graph const& graph,
    Visitor visitor,
    VertexIndexMap const& vim = get(vertex_index, graph),
    unsigned int max_length = 0);
方向 参数 说明

IN

Graph const& graph

算法将作用于其上的图. 它必须是 VertexListGraph 和 AdjacencyGraph 概念的模型.

IN

Visitor visitor

每当算法找到一个回路时都会收到通知的访问器. visitor.cycle(circuit, graph) 表达式必须有效, 其中 circuit 是指向随机访问序列的 const 引用, 序列的元素类型为 vertex_descriptor`s. For example, if a circuit `u → v → w → u; 若图中存在该回路, 访问器将以由 (u, v, w) 组成的序列被调用.

IN

VertexIndexMap const& vim

ReadablePropertyMap 概念的一个模型, 把每个 vertex_descriptor 映射到范围 [0, num_vertices(graph)) 内的一个整数.
默认: get(vertex_index, graph)

IN

unsigned int max_length

要考虑的最大回路长度. 超过此长度时会截断深度优先搜索, 通过忽略更长的回路来减少计算时间.
默认: 0 (无上限)

说明

枚举有向多重图中的所有初等回路 (若 max_length 非零, 则回路长度以该值为上限). 具体而言, 自环以及由平行边引起的冗余回路也会被枚举. 如果不想要由平行边引起的冗余回路, 可以使用 hawick_unique_circuits.

该算法在 Enumerating Circuits and Loops in Graphs with Self-Arcs and Multiple-Arcs 中有详细描述.

注释

  • hawick_circuits 枚举所有初等回路, 包括由平行边引起的冗余回路. 使用 hawick_unique_circuits 可抑制这些重复.

  • 访问器按值传递. 如果你的访问器包含状态, 考虑以指针或引用的方式持有它, 使算法期间所做的修改对调用者可见.
