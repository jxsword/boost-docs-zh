Floyd-Warshall 全对最短路径

使用 Floyd-Warshall 算法求图中每对顶点之间的最短距离.

复杂度: O(V3)
定义于: <boost/graph/floyd_warshall_shortest.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/floyd_warshall_shortest.hpp>
#include <iostream>
#include <limits>
#include <vector>

struct Node {};
struct Edge { int weight; };

using namespace boost;
using Graph = adjacency_list<vecS, vecS, directedS, Node, Edge>;

int main() {
    Graph g{3};
    add_edge(0, 1, Edge{2}, g);
    add_edge(1, 2, Edge{3}, g);
    add_edge(0, 2, Edge{7}, g);

    auto n = num_vertices(g);
    std::vector<std::vector<int>> D(n, std::vector<int>(n));

    floyd_warshall_all_pairs_shortest_paths(g, D,
        get(&Edge::weight, g),
        std::less<int>{},
        closed_plus<int>{(std::numeric_limits<int>::max)()},
        (std::numeric_limits<int>::max)(),
        int{0});

    for (std::size_t i = 0; i < n; ++i) {
        for (std::size_t j = 0; j < n; ++j)
            std::cout << D[i][j] << (j + 1 < n ? " " : "");
        std::cout << "\n";
    }
}

(1) floyd_warshall_initialized_all_pairs_shortest_paths(位置参数版本)

template <typename VertexListGraph, typename DistanceMatrix,
          typename BinaryPredicate, typename BinaryFunction,
          typename Infinity, typename Zero>
bool floyd_warshall_initialized_all_pairs_shortest_paths(
    const VertexListGraph& g, DistanceMatrix& d,
    const BinaryPredicate& compare, const BinaryFunction& combine,
    const Infinity& inf, const Zero& zero);
方向 参数 说明

IN

const VertexListGraph& g

有向图或无向图. 图必须是 顶点列表图 的模型.

OUT

DistanceMatrix& d

每对顶点 u,v 之间的最短路径长度存储在矩阵的 D[u][v] 位置. DistanceMatrix 必须是类型 {M, I, V}, 其中 I 具有类型 vertex_descriptor, 而 V 是 weight_map 的类型. 这组类型必须是 基本矩阵 的模型, 但有两点例外: 不要求在常数时间内运行, 且必须是可变的. 传给此函数时矩阵必须已正确初始化.

IN

const BinaryPredicate& compare

用于比较距离的函数, 以确定哪个目标顶点距源顶点更近. 其参数类型必须与 WeightMap 的值类型相匹配.

IN

const BinaryFunction& combine

用于合并距离以计算路径距离的函数. 其参数类型必须与 WeightMap 的值类型相匹配, 结果类型必须与距离值类型相同.

IN

const Infinity& inf

在算法开始前用于初始化每个顶点距离的值, 并用于表示顶点之间不存在路径时的距离. 该值应大于任何可能的有效路径长度. 其参数类型必须与 WeightMap 的值类型相匹配.

IN

const Zero& zero

用于表示顶点到其自身距离的值, 并用于判定某个值是否为负. 其参数类型必须与 WeightMap 的值类型相匹配.

说明

这些算法实现 Floyd-Warshall 算法, 求图中每对顶点之间的最短距离. 每对顶点之间的最短距离存储在距离矩阵 d 中. 两个算法的区别在于距离矩阵是否假定已初始化: floyd_warshall_initialized_all_pairs_shortest_paths 要求调用者在调用函数之前初始化距离矩阵, 而 floyd_warshall_all_pairs_shortest_paths 会自动初始化矩阵.

本算法适用于计算稠密图中每对顶点之间的最短路径. 对稀疏图, 请使用 johnson_all_pairs_shortest_paths.

返回

若图中存在负权环, 这些算法返回 false, 否则返回 true.
