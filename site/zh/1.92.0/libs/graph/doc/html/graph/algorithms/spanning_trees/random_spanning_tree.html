random_spanning_tree

在有向图或无向图上生成随机生成树.

复杂度: 期望 O(tau)(无权情形), 其中 tau 是平均命中时间
定义于: <boost/graph/random_spanning_tree.hpp>

示例

#include <iostream>
#include <vector>
#include <random>
#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/random_spanning_tree.hpp>

int main() {
    using Graph = boost::adjacency_list<boost::vecS, boost::vecS, boost::undirectedS>;
    using Vertex = boost::graph_traits<Graph>::vertex_descriptor;
    Graph g(5);
    boost::add_edge(0, 1, g); boost::add_edge(0, 2, g);
    boost::add_edge(1, 2, g); boost::add_edge(1, 3, g);
    boost::add_edge(2, 3, g); boost::add_edge(3, 4, g);
    boost::add_edge(2, 4, g);

    std::vector<Vertex> pred(num_vertices(g));
    std::vector<boost::default_color_type> color(num_vertices(g));
    std::mt19937 gen(42); // fixed seed for deterministic output
    boost::random_spanning_tree(g, gen, Vertex{0},
        boost::make_iterator_property_map(pred.begin(), get(boost::vertex_index, g)),
        boost::static_property_map<double>(1.0),
        boost::make_iterator_property_map(color.begin(), get(boost::vertex_index, g)));

    std::cout << "Random spanning tree edges:\n";
    for (Vertex v = 0; v < num_vertices(g); ++v) {
        if (pred[v] != boost::graph_traits<Graph>::null_vertex() && pred[v] != v)
            std::cout << "  " << pred[v] << " - " << v << "\n";
    }
}
Random spanning tree edges:
  2 - 1
  0 - 2
  4 - 3
  2 - 4

(1) 位置参数版本

template <class Graph, class Gen, class PredMap,
          class WeightMap, class ColorMap>
void random_spanning_tree(const Graph& g, Gen& gen,
    vertex_descriptor root, PredMap pred,
    WeightMap weight, ColorMap color);
方向 参数 说明

IN

const Graph& g

有向图或无向图. 图类型必须是 关联图 和 顶点列表图 的模型.

IN

Gen& gen

一个随机数生成器. 生成器类型必须是 均匀随机数生成器 的模型, 或是指向该类型的指针或引用.

IN

vertex_descriptor root

要生成的生成树的根.

OUT

PredMap pred

输出时, 此映射将包含图中每个顶点在生成树中的前驱. 值 graph_traits<Graph>::null_vertex() 将用作树根的前驱. 类型 PredMap 必须是 读/写属性映射 的模型. 映射的键类型和值类型都必须是图的顶点类型.

IN

WeightMap weight

此映射包含图中每条边的权重. 算法结果产生任意给定生成树的概率与其边权重之积成正比. 传入类型为 static_property_map<double> 的对象作为权重映射即可选择无权版本. 类型 WeightMap 必须是 可读属性映射 的模型. 映射的键类型必须是图的边类型, 且值类型必须是实数类型(如 double).

UTIL

ColorMap color

算法使用此映射来记录其在图中的行进进度. 类型 ColorMap 必须是 读/写属性映射 的模型, 其键类型必须是图的顶点描述符类型, 且颜色映射的值类型必须建模 颜色值.

(2) 命名参数版本

template <class Graph, class Gen,
          class P, class T, class R>
void random_spanning_tree(Graph& G, Gen& gen,
    const bgl_named_params<P, T, R>& params);
方向 参数 说明

IN

Graph& G

有向图或无向图. 图类型必须是 关联图 和 顶点列表图 的模型.

IN

Gen& gen

一个随机数生成器. 生成器类型必须是 均匀随机数生成器 的模型, 或是指向该类型的指针或引用.

IN

root_vertex(vertex_descriptor root)

此参数给出要生成的树的根, 其类型必须是 Graph 的顶点描述符类型.
默认: *vertices(g).first

UTIL

color_map(ColorMap color)

算法使用此映射来记录其在图中的行进进度. 类型 ColorMap 必须是 读/写属性映射 的模型, 其键类型必须是图的顶点描述符类型, 且颜色映射的值类型必须建模 颜色值.
默认: 一个 two_bit_color_map, 大小为 num_vertices(g), 并使用 i_map 作为索引映射.

IN

vertex_index_map(VertexIndexMap i_map)

此映射将每个顶点映射到区间 [0, num_vertices(g)) 内的一个整数. 仅在使用默认颜色属性映射时才需要此参数. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作该映射的键类型.

OUT

predecessor_map(PredMap pred)

输出时, 此映射将包含图中每个顶点在生成树中的前驱. 值 graph_traits<Graph>::null_vertex() 将用作树根的前驱. 类型 PredMap 必须是 读/写属性映射 的模型. 映射的键类型和值类型都必须是图的顶点类型.

IN

weight_map(WeightMap weight)

此映射包含图中每条边的权重. 算法结果产生任意给定生成树的概率与其边权重之积成正比. 若省略权重映射, 则使用给每条边相等权重的默认值; 同时会调用依赖常数权重的更快算法. 类型 WeightMap 必须是 可读属性映射 的模型. 映射的键类型必须是图的边类型, 且值类型必须是实数类型(如 double).

说明

random_spanning_tree() 函数在有向图或无向图上生成随机生成树. 所用算法为 Wilson 算法(67), 基于 环擦除随机游走. 图中每个非根顶点都必须有到根的路径; 若给定的图不满足此性质, 算法通常会陷入无限循环, 但当搜索到达没有出边的顶点时, 也可能抛出异常 loop_erased_random_walk_stuck.

random_spanning_tree() 的带权版本和无权版本都已实现. 在无权版本中, 所有生成树被选中的概率相同. 在带权版本中, 某棵特定生成树被选中的概率是其边权重之积.

在算法的非命名参数版本中, 传入类型为 static_property_map<double> 的对象作为权重映射即可选择无权版本. 在命名参数版本中, 省略 weight_map 参数具有同样效果.

注释

当随机游走到达没有出边、因而无法继续的顶点时, 抛出 loop_erased_random_walk_stuck 异常. 这通常表明图中并非每个顶点都有到根的路径.
