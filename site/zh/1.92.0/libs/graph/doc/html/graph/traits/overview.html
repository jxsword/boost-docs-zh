特征与迭代器

使泛型 BGL 代码成为可能的元编程工具. 正是它们让单个算法可以作用于 adjacency_list、adjacency_matrix、grid_graph 或用户编写的图类型 — 每个都以不同方式存储数据.

每当你编写接受图的 模板函数, 或每当附加需要预先知道描述符类型的 内部属性 时, 你都会接触本节.

页面 你为何可能打开它

graph_traits<Graph>

每次你想要未知图类型的 vertex_descriptor、edge_descriptor、某个迭代器类型或某个大小类型时. 还提供 null_vertex() 以及有向/遍历类别标签.

adjacency_list_traits<…>

仅当你需要声明一个内部属性, 其值本身是 vertex_descriptor 或 edge_descriptor(例如内部前驱映射)时. 打破图类型与其属性类型之间的“鸡生蛋”编译错误.

property_map<Graph, Tag>

当你想拼出具体属性映射类型时, 通常在函数签名中. 区分 ::type(可变)与 ::const_type(当图是 const 时).

property<Tag, T, Next>

旧式的基于标签的内部属性. 新代码应优先使用捆绑属性(见 捆绑属性); 两者可以共存.

adjacency_iterator_generator

图实现者工具. 合成 adjacency_iterator, 基于现有的 out_edge_iterator. 除非你在编写新图类, 否则跳过.

inv_adjacency_iterator_generator

in_edge_iterator 的同类工具 → 双向图上的反向邻接遍历. 同样仅限图实现者.

为什么用 typename graph_traits<Graph>::… 而不直接用 Graph::…?

若 Graph 是 具体 类型, 两者都可以:

using Graph = boost::adjacency_list<>;
Graph::vertex_descriptor v;                 // OK
boost::graph_traits<Graph>::vertex_descriptor v;  // also OK

若 Graph 是 模板参数, 必须使用 typename graph_traits<…>:: 消歧依赖名称. graph_traits 的间接层还让第三方图类型(没有恰好以此命名的嵌套 typedef)通过特化接入.

描述符: vertex_descriptor 在底层是什么?

选择器(针对 adjacency_list) 具体的 vertex_descriptor 注释

vecS (默认)

std::size_t

可与整数比较. 稳定, 除非你调用 remove_vertex, 它会使被移除顶点之后的每个描述符失效.

listS

实现定义的指针/迭代器类型

不透明. 不要 与 0 比较或用作向量索引. 描述符在 remove_vertex 之后仍然有效. 若任何算法需要索引映射, 你必须把 vertex_index_t 作为内部属性添加.

setS, hash_setS

实现定义

与 listS 的处理相同.

表示“无顶点”的可移植哨兵是 graph_traits<Graph>::null_vertex()(对 vecS 而言它恰好是 std::numeric_limits<std::size_t>::max(), 但不要依赖这一点).

常见编译错误解读

错误片段 可能原因

no matching function for call to 'get(…)'

你的图没有 vertex_index(或 edge_index)属性, 或者你传入了 const Graph& 而算法期望非常量映射. 修复: 通过捆绑属性或 property<vertex_index_t, int> 声明属性, 或改用 property_map<G, tag>::const_type.

incomplete type — 使用 property<…, Traits::vertex_descriptor>

你使用 graph_traits<Graph> 获取 vertex_descriptor 的位置恰好在 Graph 的声明之内. 请改用 adjacency_list_traits.

模板错误, 提到 readable_property_map_tag

你试图写入一个 const_type 属性映射. 从图引用中移除 const, 或使用其他映射.

edge_index 不存在 / num_edges 与索引方式不匹配

与 vertex_index_t(由 vecS 自动提供)不同, edge_index_t 从不自动提供. 请把它声明为内部边属性, 并在调用 add_edge 时自行赋值.
