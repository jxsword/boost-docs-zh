fruchterman_reingold_force_directed_layout

使用 Fruchterman-Reingold 算法对无权无向图进行力导向布局.

复杂度: 每次迭代 O(|V|2 + |E|) (最坏情形); 网格变体的平均情形为 O(|V| + |E|)
定义于: <boost/graph/fruchterman_reingold.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/fruchterman_reingold.hpp>
#include <boost/graph/topology.hpp>
#include <iostream>
#include <vector>

using namespace boost;
using Graph = adjacency_list<vecS, vecS, undirectedS>;
using Point = rectangle_topology<>::point_type;

int main() {
    Graph g(5);
    add_edge(0, 1, g); add_edge(1, 2, g);
    add_edge(2, 3, g); add_edge(3, 4, g); add_edge(4, 0, g);

    minstd_rand gen(42);
    rectangle_topology<> topology(gen, 0.0, 0.0, 100.0, 100.0);

    std::vector<Point> positions(num_vertices(g));
    for (auto& p : positions) { p = topology.random_point(); }
    auto pos_map = make_iterator_property_map(positions.begin(), get(vertex_index, g));

    fruchterman_reingold_force_directed_layout(g, pos_map, topology);

    for (auto v : make_iterator_range(vertices(g))) {
        auto& p = positions[v];
        std::cout << "vertex " << v << ": (" << p[0] << ", " << p[1] << ")\n";
    }
}
vertex 0: (3.22949, 44.7223)
vertex 1: (27.9055, 95.3527)
vertex 2: (83.7227, 87.5095)
vertex 3: (93.4898, 32.0392)
vertex 4: (43.7456, 5.54459)

template<typename Graph, typename PositionMap, typename Topology,
         typename Param, typename Tag, typename Rest>
void fruchterman_reingold_force_directed_layout(
    const Graph& g,
    PositionMap position,
    const Topology& space,
    const bgl_named_params<Param, Tag, Rest>& params);
方向 参数 说明

IN

const Graph& g

算法将作用于其上的图对象. 类型 Graph 必须是 顶点与边列表图 的模型.

IN/OUT

PositionMap position

存储每个顶点位置的属性映射. 通常应以随机位置的顶点对其初始化 (使用 random_graph_layout). 类型 PositionMap 必须是 左值属性映射 的模型, 使得 Graph 的顶点描述符类型可转换为其键类型. 其值类型必须是 Topology::point_type, 表示顶点的坐标.

IN

const Topology& space

用于布置顶点的拓扑. 此参数描述布局区域的大小和形状. 拓扑的更详细描述 (含 BGL 提供的拓扑列表) 见 单独的文档.

IN

params

通过 bgl_named_params 传入的命名参数. 接受以下参数:
方向 参数 说明

IN

attractive_force(AttractiveForce fa)

计算两个相邻顶点之间引力的模. 函数对象 fa 必须接受四个参数: 边描述符、k、顶点之间的距离, 以及图. k 是显示面积与顶点数之比的平方根.
默认: square_distance_attractive_force(), 它按 dist^2/k 计算引力.

IN

repulsive_force(RepulsiveForce fr)

计算任意两个顶点之间斥力的模. 函数对象 fr 必须接受五个参数: 两个顶点描述符、k、顶点之间的距离, 以及图. k 是显示面积与顶点数之比的平方根.
默认: square_distance_repulsive_force(), 它按 k^2/dist 计算斥力.

IN

force_pairs(ForcePairs fp)

枚举应施加斥力的顶点对. fp 是一个接受两个参数的函数对象: 图 g 和一个二元函数对象, 后者会被传入每个要考虑的顶点对. Fruchterman-Reingold 算法的基本形式计算所有顶点对之间的斥力 (此参数传入 all_force_pairs()), 这对非连通图是可用的, 但往往会把连通分量推向显示区域的边缘. 该算法的网格变体在显示区域上放置一个网格, 只计算网格中每个矩形内顶点之间的斥力. 网格变体可以比基本形式更高效, 且往往能为非连通图产生更好的布局, 但整体上并不更好: 此参数传入 make_grid_force_pairs(width, height, position, g) 即可使用网格变体. 其他枚举策略可能对特定图产生更好的结果.
默认: make_grid_force_pairs(width, height, position, g)

IN

cooling(Cooling cool)

确定算法的冷却调度, 它影响顶点的移动速率和算法的终止. cool 参数是一个无参函数对象 (即不接受任何实参), 返回当前迭代的温度. 当返回的温度为零时, 算法终止. 冷却调度应以某个初始温度开始, 并逐渐把温度降到零.
默认: linear_cooling<double>(100)

UTIL

displacement_map(DisplacementMap displacement)

位移映射用于计算每个顶点在每一步中移动的量. DisplacementMap 类型必须是一个属性映射, 其键类型为图的顶点类型, 值类型为 Topology::point_difference_type.
默认: 一个 iterator_property_map, 具有指定的值类型并使用给定的顶点索引映射.

IN

vertex_index_map(VertexIndexMap i_map)

它把每个顶点映射到范围 [0, num_vertices(g)) 内的一个整数. 只有在未提供位移映射时才需要. 类型 VertexIndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.
默认: get(vertex_index, g) 注意: 如果使用此默认值, 请确保你的图拥有内部属性 vertex_index. 例如, adjacency_list (带 VertexList=listS) 就没有内部属性 vertex_index.

说明

这个 算法 [53] 对无权无向图执行布局. 与 Kamada-Kawai 布局算法不同, 该算法直接支持非连通图的布局 (但请参阅 force_pairs 命名参数). 它是一种 力导向 算法, 即顶点布局由把顶点拉近和推开的力决定. 引力只出现在相邻顶点之间, 而斥力出现在每一对顶点之间. 每次迭代计算每个顶点上各力之和, 然后把顶点移动到新位置. 顶点的移动由该次迭代系统的 温度 缓和: 随着算法经历相继的迭代, 温度应下降, 使顶点安定下来. 冷却调度、引力和斥力都可由用户提供.

在执行此算法之前, 通常通过 random_graph_layout 随机放置顶点.
