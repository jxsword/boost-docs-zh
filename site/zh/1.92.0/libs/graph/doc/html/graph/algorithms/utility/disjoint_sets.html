不相交集合

带 按秩合并 和 路径压缩 的并查集数据结构. 维护一组不相交集合, 每个集合由一个代表元素标识. 由 connected_components、incremental_components 和 kruskal_minimum_spanning_tree 在内部使用.

定义于: <boost/pending/disjoint_sets.hpp>

示例

#include <boost/pending/disjoint_sets.hpp>
#include <boost/property_map/property_map.hpp>
#include <iostream>
#include <vector>

int main() {
    const int N = 6;
    std::vector<int> rank(N, 0);
    std::vector<int> parent(N);

    boost::disjoint_sets<int*, int*> ds(rank.data(), parent.data());

    // Make each element its own set
    for (int i = 0; i < N; ++i) {
        ds.make_set(i);
    }

    // Union some sets: {0,1,2} and {3,4}
    ds.union_set(0, 1);
    ds.union_set(1, 2);
    ds.union_set(3, 4);

    // Find representatives
    for (int i = 0; i < N; ++i) {
        std::cout << "find(" << i << ") = " << ds.find_set(i) << "\n";
    }

    // Check connectivity
    std::cout << "0 and 2 same set? " << (ds.find_set(0) == ds.find_set(2)) << "\n";
    std::cout << "0 and 5 same set? " << (ds.find_set(0) == ds.find_set(5)) << "\n";
}
find(0) = 1
find(1) = 1
find(2) = 1
find(3) = 4
find(4) = 4
find(5) = 5
0 and 2 same set? 1
0 and 5 same set? 0

模板参数

Rank

必须是 ReadWritePropertyMap 的模型, 值类型为整数, 键类型等于集合的元素类型.

Parent

必须是 ReadWritePropertyMap 的模型, 键类型和值类型与集合的元素类型相同.

FindCompress

应为查找代表元素和路径压缩函数对象之一.

成员

成员 说明

disjoint_sets(Rank r, Parent p)

构造函数.

disjoint_sets(const disjoint_sets& x)

拷贝构造函数.

template <class Element>
void make_set(Element x)

创建包含元素 x 的单元素集合.

template <class Element>
void link(Element x, Element y)

合并两个集合, 其 代表元素为 x 和 y.

template <class Element>

合并 包含元素 x 和 y 的两个集合. 这等价于 link(find_set(x),find_set(y)).

template <class Element>
Element find_set(Element x)

返回包含元素 x 的集合的代表元素.

template <class ElementIterator>
std::size_t count_sets(ElementIterator first, ElementIterator last)

返回不相交集合的数量.

template <class ElementIterator>
void compress_sets(ElementIterator first, ElementIterator last)

压平双亲树, 使每个元素的双亲都是其代表元素.

复杂度

时间复杂度为 O(m alpha(m,n)), 其中 alpha 是反 Ackermann 函数, m 是不相交集合操作的次数(make_set()、find_set() 和 link()), n 是元素数量. alpha 函数增长极慢, 远慢于 log 函数.

disjoint_sets_with_storage

disjoint_sets_with_storage<ID,InverseID,FindCompress>

此类在内部管理秩和双亲属性的存储. 存储位于数组中, 按元素 ID 索引, 因此需要 ID 和 InverseID 函数对象. 秩和双亲属性在构造期间初始化, 使每个元素各自属于一个集合(因此无需用 initialize_incremental_components() 函数初始化此类的对象). 当计算不提供顶点属性存储位置的 edge_list 图的(动态)连通分量时, 此类特别有用.

模板参数

参数 说明 默认值

ID

必须是 ReadablePropertyMap 的模型, 把元素映射到 0 与 N 之间的整数, N 为集合中元素总数.

boost::identity_property_map

InverseID

必须是 ReadablePropertyMap 的模型, 把整数映射到元素.

boost::identity_property_map

template <class ElementIterator>
void disjoint_sets_with_storage::

此操作重新排列代表元素, 使每个集合的代表元素是 ID 最小的元素.
后置条件: v >= parent[v]
前置条件: 不相交集合结构必须已被压缩.

representative_with_path_halving

representative_with_path_halving<Parent>

这是一个函数对象, 查找与元素 x 处于同一连通分量的代表顶点. 在沿代表树向上遍历时, 该函数对象还应用路径折半技术来降低树高.
