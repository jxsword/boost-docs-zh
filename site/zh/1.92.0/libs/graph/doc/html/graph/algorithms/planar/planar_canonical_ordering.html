平面规范排序

计算极大平面图顶点的一个规范排序.

复杂度: O(n + m)
定义于: <boost/graph/planar_canonical_ordering.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/boyer_myrvold_planar_test.hpp>
#include <boost/graph/planar_canonical_ordering.hpp>
#include <iostream>
#include <vector>

using namespace boost;

struct Edge { int idx; };

using Graph = adjacency_list<vecS, vecS, undirectedS, no_property, Edge>;
using Vertex = graph_traits<Graph>::vertex_descriptor;
using Descriptor = graph_traits<Graph>::edge_descriptor;

int main() {
    // Start with a triangle (already maximal planar for 3 vertices)
    Graph g(3);
    add_edge(0, 1, g); add_edge(1, 2, g); add_edge(0, 2, g);

    int i = 0;
    for (auto e : make_iterator_range(edges(g))) { g[e].idx = i++; }

    std::vector<std::vector<Descriptor>> storage(num_vertices(g));
    auto embedding = make_iterator_property_map(storage.begin(), get(vertex_index, g));
    boyer_myrvold_planarity_test(boyer_myrvold_params::graph = g,
        boyer_myrvold_params::embedding = embedding);

    std::vector<Vertex> order;
    planar_canonical_ordering(g, embedding, std::back_inserter(order),
        get(vertex_index, g));

    std::cout << "Planar canonical ordering:";
    for (auto v : order) { std::cout << " " << v; }
    std::cout << "\n";
}
Planar canonical ordering: 0 1 2

概要

template <typename Graph, typename PlanarEmbedding,
          typename OutputIterator, typename VertexIndexMap>
void planar_canonical_ordering(
    const Graph& g,
    PlanarEmbedding embedding,
    OutputIterator ordering,
    VertexIndexMap vm);
方向 参数 说明

IN

const Graph& g

一个无向图. 类型 Graph 必须是 VertexAndEdgeListGraph 的模型. 图必须是极大平面图且至少有两个顶点.

IN

PlanarEmbedding embedding

PlanarEmbedding 的一个模型.

OUT

OutputIterator ordering

一个 OutputIterator, 其中 value_type 等于 graph_traits<Graph>::vertex_descriptor. 规范排序将写入此迭代器.

IN

VertexIndexMap vm

一个可读属性映射, 把来自 g 的顶点映射到范围 [0, num_vertices(g)) 内的相异整数.
默认: get(vertex_index, g)

说明

所谓 平面规范排序, 是图顶点的一个排序 v1, v2, …​, vn, 该图为 极大 平面 图, 排序具有如下性质: 对每个 k, 3 <= k < n, 由 v1, v2, …​, vk 导出的图:

  • 是双连通的, 且在其外面上包含边 {v1, v2}.

  • v1, v2, …​, vk 中与 v(k+1) 在其外面上相邻的任何顶点, 构成沿外圈的一条路径.

设 Gk 为由规范排序中前 k 个顶点 (连同前 k 个顶点之间的所有边) 导出的图. 画出 Gk 之后, 第 (k+1) 个顶点可以轻松地无交叉绘出, 因为它只与 Gk 外圈上一个连续的顶点序列相邻.

每个至少有 2 个顶点的极大平面图都存在平面规范排序. planar_canonical_ordering 期望输入图至少有 2 个顶点.

平面规范排序在一些平面图绘制算法中用作输入, 尤其是那些创建直线嵌入的算法. de Fraysseix、Pach 和 Pollack [66] 首先证明了这种排序的存在性, 并展示了如何在 n 个顶点的极大平面图上以 O(n) 时间计算出一个.

另见 example/canonical_ordering.cpp.
