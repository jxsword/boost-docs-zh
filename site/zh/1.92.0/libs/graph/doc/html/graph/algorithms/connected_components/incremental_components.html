增量连通分量

一族使用不相交集增量计算无向图连通分量的函数与类.

复杂度: O(V + E * alpha(E, V))
定义于: <boost/graph/incremental_components.hpp>

示例

#include <iostream>
#include <vector>
#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/incremental_components.hpp>
#include <boost/pending/disjoint_sets.hpp>

int main() {
    using Graph = boost::adjacency_list<boost::vecS, boost::vecS, boost::undirectedS>;
    Graph g(5);
    std::vector<std::size_t> rank(5, 0);
    std::vector<std::size_t> parent(5);
    boost::disjoint_sets<std::size_t*, std::size_t*> ds(rank.data(), parent.data());
    for (std::size_t i = 0; i < 5; ++i) ds.make_set(i);

    auto add_and_report = [&](int u, int v) {
        boost::add_edge(u, v, g);
        ds.union_set(static_cast<std::size_t>(u), static_cast<std::size_t>(v));
        // Count components
        std::size_t count = 0;
        for (std::size_t i = 0; i < 5; ++i)
            if (ds.find_set(i) == i) ++count;
        std::cout << "  After adding " << u << "-" << v << ": " << count << " components\n";
    };

    std::cout << "Incremental connected components:\n";
    add_and_report(0, 1);
    add_and_report(2, 3);
    add_and_report(1, 2);
    add_and_report(3, 4);
}
Incremental connected components:
  After adding 0-1: 4 components
  After adding 2-3: 3 components
  After adding 1-2: 2 components
  After adding 3-4: 1 components

component_index

component_index<Index>

component_index 类为图的分量提供了一个类似 STL 容器的视图. 每个分量都是一个类似容器的对象, 通过 operator[] 提供访问. 一个 component_index 对象用由 incremental_components() 函数算出的不相交集中的 parents 属性来初始化. 也可以传入一个顶点到索引的属性映射 (默认使用 identity_property_map).

说明

本节描述一族协同计算无向图连通分量的函数与类. 这里使用的算法基于 不相交集 (快速 union-find) 数据结构 [5,22], 对于图不断增长 (不断添加边) 且需要反复更新连通分量信息的情形, 它是一种很好的方法. 该方法不涵盖既添加又删除边的情形, 因此称为 增量 方法 [42] (而非完全动态). 不相交集类在 不相交集 一节中描述.

下面五个操作是你将用来计算和维护连通分量的主要函数. 这里使用的对象是图 g、不相交集结构 ds, 以及顶点 u 和 v.

  • initialize_incremental_components(g, ds) — 不相交集结构的基本初始化. 图 g 中的每个顶点各自属于一个集合.

  • incremental_components(g, ds) — 基于图 g 中的边计算连通分量, 并把信息嵌入 ds 中.

  • ds.find_set(v) — 从不相交集中提取顶点 v 的分量信息.

  • ds.union_set(u, v) — 当边 (u,v) 加入图时更新不相交集结构.

initialize_incremental_components 通过使图中每个顶点成为其自身分量 (或集合) 的成员, 为增量连通分量算法准备不相交集数据结构.

incremental_components 计算图的连通分量, 并把结果嵌入不相交集数据结构中.

same_component 判定 u 与 v 是否在同一分量中.
