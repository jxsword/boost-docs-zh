图绘制拓扑

与图布局算法配合使用的各种拓扑, 为顶点布置提供不同的空间结构.

定义于: <boost/graph/topology.hpp>

说明

这里提供了多种拓扑, 可为图布局算法产生不同而有趣的结果. 例如, 方形拓扑 可用于图的正常显示, 或为进程阵列上的并行计算分配顶点. 其他拓扑, 如 球面拓扑 (或 N 维 球形拓扑), 对不同的问题更有意义, 而 心形拓扑 纯粹是为了好玩. 也可以 定义拓扑 以满足其他特定需求.

拓扑是对可执行布局的空间的描述. 这里提供了一些常见的二维、三维和多维拓扑, 你也可以创建自己的拓扑, 只要它满足 Topology 概念 的要求.

Topology 概念

设 Topology 是 Topology 概念的一个模型, space 是类型 Topology 的一个对象. p1 和 p2 是关联类型 point_type 的对象 (见下文). 下列表达式必须有效:

表达式 类型 说明

Topology::point_type

类型

空间中点的类型.

space.random_point()

point_type

返回空间内的一个随机点 (通常均匀分布).

space.distance(p1, p2)

double

获取一个量, 表示沿完全位于空间内部的路径 p1 与 p2 之间的距离. 它只需与实际距离具有相同的 < 关系, 不必满足 Banach 空间中范数的其他性质.

space.move_position_toward(p1, fraction, p2)

point_type

返回一个点, 它位于从 p1 到 p2 的一部分路程处, 按距离度量沿空间中的一条"直线"移动. fraction 是一个介于 0 与 1 之间 (含端点) 的 double.

类模板 convex_topology

类模板 convex_topology 为 Dims 维的任何凸拓扑实现基本的距离与点移动函数. 它本身不是拓扑, 而是打算作为任何凸拓扑都可以派生的基类. 派生的拓扑只需提供一个合适的 random_point 函数, 返回空间内的一个随机点.

template<std::size_t Dims>
class convex_topology
{
  struct point
  {
    point() { }
    double& operator[](std::size_t i) {return values[i];}
    const double& operator[](std::size_t i) const {return values[i];}

  private:
    double values[Dims];
  };

 public:
  typedef point point_type;

  double distance(point a, point b) const;
  point move_position_toward(point a, double fraction, point b) const;
};

类模板 hypercube_topology

类模板 hypercube_topology 实现一个 Dims 维超立方体. 它是一个凸拓扑, 其点取自类型为 RandomNumberGenerator 的随机数生成器. hypercube_topology 可以用一个给定的随机数生成器构造; 若省略, 将使用一个新的默认构造的随机数生成器. 得到的布局将包含在超立方体内, 其边长为 2*scaling (每个维度中点落在 [-scaling, scaling] 范围内).

template<std::size_t Dims,
         typename RandomNumberGenerator = minstd_rand>
class hypercube_topology : public convex_topology<Dims>
{
public:
  explicit hypercube_topology(double scaling = 1.0);
  hypercube_topology(RandomNumberGenerator& gen, double scaling = 1.0);
  point_type random_point() const;
};

类模板 square_topology

类模板 square_topology 是一个二维超立方体拓扑.

template<typename RandomNumberGenerator = minstd_rand>

 public:
  explicit square_topology(double scaling = 1.0);
  square_topology(RandomNumberGenerator& gen, double scaling = 1.0);

类模板 ball_topology

类模板 ball_topology 实现一个 Dims 维球. 它是一个凸拓扑, 其点取自类型为 RandomNumberGenerator 的随机数生成器, 但位于球内. ball_topology 可以用一个给定的随机数生成器构造; 若省略, 将使用一个新的默认构造的随机数生成器. 得到的布局将包含在具有给定 radius 的球内.

template<std::size_t Dims,
         typename RandomNumberGenerator = minstd_rand>
class ball_topology : public convex_topology<Dims>
{
public:
  explicit ball_topology(double radius = 1.0);
  ball_topology(RandomNumberGenerator& gen, double radius = 1.0);
  point_type random_point() const;
};

类模板 heart_topology

类模板 heart_topology 是心形的拓扑. 它作为布局用非凸、非平凡拓扑的一个示例.

template<typename RandomNumberGenerator = minstd_rand>
class heart_topology
{
 public:
  typedef unspecified point_type;

  heart_topology();
  heart_topology(RandomNumberGenerator& gen);
  point_type random_point() const;
  double distance(point_type a, point_type b) const;
  point_type move_position_toward(point_type a, double fraction, point_type b) const;
};
