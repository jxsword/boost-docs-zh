Prim 最小生成树

使用 Prim 算法求解边带权无向图的最小生成树问题.

复杂度: O(E log V)
定义于: <boost/graph/prim_minimum_spanning_tree.hpp>

示例

// Prim Minimum Spanning Tree example
#include <iostream>
#include <vector>
#include <limits>
#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/prim_minimum_spanning_tree.hpp>

struct EdgeWeight { int weight; };

using Graph = boost::adjacency_list<
    boost::vecS, boost::vecS, boost::undirectedS, boost::no_property, EdgeWeight>;
using Vertex = boost::graph_traits<Graph>::vertex_descriptor;

int main() {
    Graph g{5};
    auto add = [&](int u, int v, int w) { boost::add_edge(u, v, EdgeWeight{w}, g); };
    add(0, 1, 2); add(0, 3, 1); add(1, 2, 3);
    add(1, 3, 2); add(2, 4, 4); add(3, 4, 6);

    auto n = boost::num_vertices(g);
    std::vector<Vertex> pred(n);
    std::vector<int> dist(n);
    auto index_map = boost::get(boost::vertex_index, g);
    auto pred_map = boost::make_iterator_property_map(pred.begin(), index_map);
    auto dist_map = boost::make_iterator_property_map(dist.begin(), index_map);
    auto weight_map = boost::get(&EdgeWeight::weight, g);

    boost::prim_minimum_spanning_tree(g, *boost::vertices(g).first,
        pred_map, dist_map, weight_map, index_map,
        boost::default_dijkstra_visitor{});

    std::cout << "Predecessor map (vertex : parent):\n";
    for (Vertex v = 0; v < boost::num_vertices(g); ++v) {
        std::cout << "  " << v << " : " << pred[v] << "\n";
    }
}

template <typename Graph, typename DijkstraVisitor,
          typename PredecessorMap, typename DistanceMap,
          typename WeightMap, typename IndexMap>
void prim_minimum_spanning_tree(
    const Graph& g,
    typename graph_traits<Graph>::vertex_descriptor s,
    PredecessorMap predecessor, DistanceMap distance, WeightMap weight,
    IndexMap index_map, DijkstraVisitor vis);
方向 参数 说明

IN

const Graph& g

无向图. 类型 Graph 必须是 顶点列表图 和 关联图 的模型. 图中不应有平行边.

IN

vertex_descriptor s

最小生成树的根顶点. 根顶点的选择是任意的.

OUT

PredecessorMap predecessor

前驱映射记录最小生成树中的边. 算法完成后, 边 (p[u],u)(对所有 u in V)都在最小生成树中. 若 p[u] = u, 则 u 或是树的根, 或是从根不可达的顶点. PredecessorMap 类型必须是 读/写属性映射, 其键类型和顶点类型与图的顶点描述符类型相同.

UTIL/OUT

DistanceMap distance

通向图中每个顶点 g 的生成树边的权重记录在此属性映射中, 边的方向背离生成树根. 类型 DistanceMap 必须是 读/写属性映射 的模型. 图的顶点描述符类型必须可用作距离映射的键类型, 且值类型必须与 WeightMap 参数的值类型相同.

IN

WeightMap weight

图中每条边的权重或“长度”. 类型 WeightMap 必须是 可读属性映射 的模型. 图的边描述符类型必须可用作权重映射的键类型. 映射的值类型必须与距离映射的值类型相同, 且该类型必须是 可小于比较 的.

IN

IndexMap index_map

它把每个顶点映射到范围 [0, num_vertices(g)) 内的一个整数. 这对于松弛边时高效更新堆数据结构是必要的. 类型 IndexMap 必须是 可读属性映射 的模型. 映射的值类型必须是整数类型. 图的顶点描述符类型必须可用作映射的键类型.

IN

DijkstraVisitor vis

使用此参数指定希望在算法内特定事件点发生的动作. 类型 DijkstraVisitor 必须是 Dijkstra 访问器 概念的模型. 访问器对象按值传递 [1].

此映射在算法执行期间用于标记顶点. 顶点初始为白色, 插入队列时变为灰色, 从队列移除时再变为黑色. 算法结束时, 从源顶点可达的顶点都将被标为黑色, 其余顶点仍为白色. 类型 ColorMap 必须是 读/写属性映射 的模型. 顶点描述符必须可用作该映射的键类型, 且映射的值类型必须是 颜色值 的模型.
默认: 一个 iterator_property_map, 由 std::vector 构造, 其元素类型为 default_color_type、大小为 num_vertices(g), 并使用 i_map 作为索引映射.

使用此参数指定希望在算法内特定事件点发生的动作. 类型 DijkstraVisitor 必须是 Dijkstra 访问器 概念的模型. 访问器对象按值传递 [1].
默认: dijkstra_visitor<null_visitor>

说明

这是 Prim 算法

用于求解边带权无向图的最小生成树问题. MST 是连接图中所有顶点的边集合, 且树中边的总权重最小. 更多细节见 最小生成树问题 一节. 该实现只是对 dijkstra_shortest_paths() 的一次调用, 选用恰当的比较和合并函数对象. Prim 算法的伪代码如下. Boost.Graph 中实现的该算法在含平行边的图上不会产生正确结果.

伪代码

PRIM-MST(G, s, w)
  for each vertex u in V[G]
    color[u] := WHITE
    d[u] := infinity
  end for
  color[s] := GRAY
  d[s] := 0
  ENQUEUE(PQ, s)
  p[s] := s
  while (PQ != Ø)
    u := DEQUEUE(PQ)
    for each v in Adj[u]
      if (w(u,v) < d[v])
        d[v] := w(u,v)
        p[v] := u
        if (color[v] = WHITE)
          ENQUEUE(PQ, v)
          color[v] := GRAY
        else if (color[v] = GRAY)
          UPDATE(PQ, v)
      else
        do nothing
    end for
    color[u] := BLACK
  end while
  return (p, d)

访问器事件点

  • vis.initialize_vertex(u, g): 在算法开始之前对图中每个顶点各调用一次.

  • vis.examine_vertex(u, g) 在某顶点从优先队列移除时对其调用.

  • vis.examine_edge(e, g) 在顶点的每条出边被检查之后立即对其调用.

  • vis.edge_relaxed(e, g) 对边 (u,v) 调用, 条件是 w(u,v) < d[v]. 边 (u,v) 若是对顶点 v 的最后一次松弛所涉及的边, 则它是最小生成树中的一条边.

  • vis.discover_vertex(v, g) 当边 (u,v) 被检查且 v 为 WHITE 时, 对顶点 v 调用. 由于顶点被发现时即被标为 GRAY, 每个可达顶点恰好被发现一次. 这也是该顶点被插入优先队列的时机.

  • vis.edge_not_relaxed(e, g): 若边未被松弛 (见上) 则调用.

  • vis.finish_vertex(u, g) 在顶点的所有出边都被检查之后, 对该顶点调用.

注释

[1] 由于访问器参数按值传递, 如果你的访问器包含状态, 那么算法期间对状态的任何修改都作用于访问器对象的一个副本, 而不是传入的访问器对象. 因此你可能希望访问器以指针或引用的方式持有该状态.
