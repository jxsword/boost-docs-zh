两图公共生成树

使用 Minty、Read 和 Tarjan 的 MRT 算法求两个无向图的所有公共生成树.

定义于: <boost/graph/two_graphs_common_spanning_trees.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/two_graphs_common_spanning_trees.hpp>
#include <iostream>
#include <vector>

using Graph = boost::adjacency_list<boost::vecS, boost::vecS, boost::undirectedS>;
using Edge = boost::graph_traits<Graph>::edge_descriptor;

int count = 0;

struct CountTrees {
    void operator()(const std::vector<bool>& inL) {
        ++count;
        std::cout << "  Tree " << count << ": edges";
        for (std::size_t i = 0; i < inL.size(); ++i) {
            if (inL[i]) { std::cout << " " << i; }
        }
        std::cout << "\n";
    }
};

int main() {
    // Two identical triangle graphs (3 vertices, 3 edges)
    Graph g1(3), g2(3);
    boost::add_edge(0, 1, g1); boost::add_edge(1, 2, g1); boost::add_edge(0, 2, g1);
    boost::add_edge(0, 1, g2); boost::add_edge(1, 2, g2); boost::add_edge(0, 2, g2);

    std::vector<bool> inL(num_edges(g1), false);
    std::cout << "Common spanning trees:\n";
    boost::two_graphs_common_spanning_trees(g1, g2, CountTrees{}, inL);
    std::cout << "Total: " << count << "\n";
}
Common spanning trees:
  Tree 1: edges 0 1
  Tree 2: edges 0 2
  Tree 3: edges 1 2
Total: 3

template <typename Graph, typename Order,
          typename Func, typename Seq>
void two_graphs_common_spanning_trees(
    const Graph& iG,
    Order iG_map,
    const Graph& vG,
    Order vG_map,
    Func func,
    Seq inL);
方向 参数 说明

IN

const Graph& iG

要分析的第一个图. 类型 Graph 必须是 VertexAndEdgeListGraphConcept 和 IncidenceGraphConcept 的模型. 此外, directed_category 的类型应为 undirected_tag.

IN

Order iG_map

对边的引用的列表, 定义访问 iG 边列表的优先顺序. 类型 Order 必须是 RandomAccessContainer 的模型.

IN

const Graph& vG

要分析的第二个图. 类型 Graph 必须是 VertexAndEdgeListGraphConcept 和 IncidenceGraphConcept 的模型. 此外, directed_category 的类型应为 undirected_tag.

IN

Order vG_map

对边的引用的列表, 定义访问 vG 边列表的优先顺序. 类型 Order 必须是 RandomAccessContainer 的模型.

IN

Func func

算法为找到的每个公共生成树调用的回调. 类型 Func 必须是 UnaryFunction 的模型, 返回值为 void, 参数为类型 typeof(inL) 的对象.

IN/OUT

Seq inL

标记哪些边属于公共生成树的序列. 类型 Seq 必须是 Mutable_RandomAccessContainer 的模型. 此外, value_type 的类型应为 bool. 若第 i 条边或 inL[i] 为 true, 则它属于公共生成树, 否则不属于. 此参数的用途详见 [1].

说明

MRT 算法基于 Minty、Read 和 Tarjan 的一篇学术文章, 是求解公共生成树问题的高效算法. 这类算法在电子学中应用广泛, 是电路分析的基础. 另一个可能的应用领域是网络.

公共生成树问题很容易描述. 设想我们有两个图, 都表示为边的列表. 公共生成树是一个索引集合, 它同时为两个图中的第一个和第二个标识出一棵生成树. 尽管用边列表表示图很容易做到, 但用邻接表表示却在直观上难以实现. 原因在于必须用一个绝对索引来表示一条边.

注意, 两图的公共生成树集合既是最初那个图的生成树集合的子集, 也是第二个图的生成树集合的子集.

所提出的算法接收若干参数并通过回调工作. 重载 (1) 接受两个图的显式边顺序, 而重载 (2) 使用默认的边迭代顺序.

文件 examples/two_graphs_common_spanning_trees.cpp 包含一个求两个无向图公共生成树的补充示例.

注释

[1] inL 的存在看似没有意义. 算法本可使用内部生成的占位符向量. 然而, 这样做对回调函数有更大的灵活性. 此外, 由于该算法大量应用于电子学领域, 存在某些边必须强制出现在每棵树中的情形(即想搜索所有具有相同根的树): 采用此方案, 问题很容易解决. 从上面的描述可以直观看出, inL 的大小必须等于 (V-1), 其中 V 是图的顶点数.
