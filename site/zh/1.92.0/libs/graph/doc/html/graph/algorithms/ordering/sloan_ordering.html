sloan_ordering

通过重排顶点索引减小无向图的轮廓与波前.

复杂度: O(log(m)|E|), 其中 m = max { degree(v) | v in V }
定义于: <boost/graph/sloan_ordering.hpp>

示例

#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/sloan_ordering.hpp>
#include <iostream>
#include <vector>

using namespace boost;

struct VertexData {
    default_color_type color{};
    int degree = 0;
    double priority = 0.0;
};

using Graph = adjacency_list<setS, vecS, undirectedS, VertexData>;
using Vertex = graph_traits<Graph>::vertex_descriptor;

int main() {
    Graph g(6);
    add_edge(0, 1, g); add_edge(0, 2, g); add_edge(1, 3, g);
    add_edge(2, 3, g); add_edge(3, 4, g); add_edge(4, 5, g);

    // Populate degrees; sloan_ordering reads them to pick a start vertex.
    auto deg = get(&VertexData::degree, g);
    for (auto v : make_iterator_range(vertices(g))) {
        put(deg, v, static_cast<int>(out_degree(v, g)));
    }

    // Bundled scratch fields replace the three vertex property tags.
    std::vector<Vertex> order(num_vertices(g));
    sloan_ordering(g, order.begin(),
        get(&VertexData::color, g), deg,
        get(&VertexData::priority, g));

    std::cout << "Sloan ordering:";
    for (auto v : order) { std::cout << " " << v; }
    std::cout << "\n";
}
Sloan ordering: 5 4 3 2 1 0

(1) 带起始/终止顶点与权重

          class ColorMap, class DegreeMap,
          class PriorityMap, class Weight>
OutputIterator sloan_ordering(
    Graph& g,
    typename graph_traits<Graph>::vertex_descriptor s,
    typename graph_traits<Graph>::vertex_descriptor e,
    OutputIterator permutation,
    ColorMap color,
    DegreeMap degree,
    PriorityMap priority,
    Weight W1,
    Weight W2);

IN

IN

Weight W1

Sloan 算法的第一个启发式权重.

IN

Weight W2

Sloan 算法的第二个启发式权重.

说明

Sloan 排序算法 [77, 78] 的目标是通过重排各顶点被指派的索引来减小图的轮廓与波前. Sloan 算法需要一个起始顶点和一个终止顶点. 这些顶点可以手动指定. 但也有一个算法 sloan_starting_nodes, 通常能提供相当好的起始与终止顶点. 每个顶点被指派一个优先级. 该优先级是顶点到终止顶点距离的加权和 (一个全局准则), 称为顶点的当前度. 当前度基本反映了某顶点邻域内重编号的状态 (一个局部准则). 因此 Sloan 算法 (与 McKee 不同) 在重编号序列中同时考虑局部与全局准则. 可以调整相对权重, 但 Sloan 提出的默认值 (weight1/weight2=1/2) 在大多数情况下效果相当好.

重载 (1) 让用户选择起始与终止顶点, 而重载 (2) 使用 sloan_starting_node 算法找出一个好的起始顶点. 这些顶点的选择对排序质量可能有显著影响. 重载 (3) 与 (4) 分别与 (1) 和 (2) 相同, 只是使用标准权重 W1=1 与 W2=2.

算法的输出是新顺序下的顶点. 根据你使用的输出迭代器类型, 可以得到 Sloan 顺序或反向 Sloan 顺序. 例如, 若使用向量的反向迭代器把输出存入向量, 你得到的就是反向 Sloan 顺序.

std::vector<vertex_descriptor> inv_perm(num_vertices(G));
sloan_ordering(G, inv_perm.rbegin());

无论哪种方式, 把输出存入向量都会得到从新顺序到旧顺序的排列.

inv_perm[new_index[u]] == u

有时你想要的是相反的排列, 即从旧索引到新索引的排列. 可以按如下方式轻松计算.

for (size_type i = 0; i != inv_perm.size(); ++i)
  perm[old_index[inv_perm[i]]] = i;

通常 Cuthill-McKee 算法需要反向顺序, 而 Sloan 算法需要正向顺序.

返回

一个 OutputIterator, 指向排列输出末尾之后.
