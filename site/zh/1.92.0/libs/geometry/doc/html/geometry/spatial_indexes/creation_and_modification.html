创建与修改

模板参数

R-tree 有 5 个参数, 但只有 2 个是必需的:

rtree<Value,
      Parameters,
      IndexableGetter = index::indexable<Value>,
      EqualTo = index::equal_to<Value>,
      Allocator = std::allocator<Value> >
  • Value - 将存储在容器中的对象的类型,
  • Parameters - 参数类型, 插入/分裂算法,
  • IndexableGetter - 将 Value 转换为 R-tree 可处理的 Indexable (Point 或 Box) 的函数对象,
  • EqualTo - 比较 Value 的函数对象,
  • Allocator - Value 的分配器, 容器所需的所有分配器都由它创建.
Value 与 Indexable

R-tree 可以存储任何类型的 Value, 只要传入的函数对象知道如何解释这些 Value, 即提取出 R-tree 可处理的 Indexable 并比较 Value. Indexable 是适配到 Point、Box 或 Segment 概念的类型. 下面给出存储 Value (可转换为各种 Indexable) 的 rtree 示例.

rtree<Point, ...>

rtree<Box, ...>

rtree<Segment, ...>

默认情况下, 函数对象 index::indexable<Value> 与 index::equal_to<Value> 已针对一些常用的 Value 类型定义, 这些类型无需定义任何附加类即可存储. 默认情况下, rtree 可以存储纯 Indexable、pair 与 tuple. 对于这两种集合类型, Indexable 必须是第一个存储的类型.

  • Indexable = Point | Box | Segment
  • Value = Indexable | std::pair<Indexable, T> | boost::tuple<Indexable, ...> [ | std::tuple<Indexable, ...> ]

默认情况下, 所有编译器都支持 boost::tuple<...>. 如果编译器支持 C++11 tuple 与变参模板, 那么 std::tuple<...> 也可以“开箱即用”.

默认 Value 类型的示例:

geometry::model::point<...>
geometry::model::point_xy<...>
geometry::model::box<...>
geometry::model::segment<...>
std::pair<geometry::model::box<...>, unsigned>
boost::tuple<geometry::model::point<...>, int, float>

预定义的 index::indexable<Value> 返回对 Indexable (存储于 Value 中) 的 const 引用.

重要

转换在容器内部进行得相当频繁——每次 rtree 需要时都会执行.

预定义的 index::equal_to<Value>:

  • 对于 Point、Box 与 Segment —— 使用 geometry::equals() 比较 Value.
  • 对于 std::pair<...> —— 比较 Value 的两个组件. pair 中存储的第一个值先于第二个值比较. 若 pair 中存储的值是 Geometry, 则使用 geometry::equals(). 对于其他类型, 使用 operator==().
  • 对于 tuple<...> —— 比较 Value 的所有组件. 若组件是 Geometry, 则使用 geometry::equals() 函数. 对于其他类型, 使用 operator==().
平衡算法的编译期参数

Value 可以通过多种不同方式插入 R-tree. R-tree 的最终内部结构取决于插入过程中使用的算法与参数. 最重要的是节点的平衡算法. 目前可以创建三种著名的 R-tree 类型.

Linear - 使用线性复杂度平衡算法的经典 R-tree

index::rtree< Value, index::linear<16> > rt;

Quadratic - 使用二次复杂度平衡算法的经典 R-tree

index::rtree< Value, index::quadratic<16> > rt;

R*-tree - 通过强制重插入使节点重叠最小化的平衡算法

index::rtree< Value, index::rstar<16> > rt;
平衡算法的运行期参数

平衡算法参数可在运行期传递给 R-tree. 要使用 R-tree 的运行期版本, 可以传入名称以 dynamic_ 开头的参数.

// linear
index::rtree<Value, index::dynamic_linear> rt(index::dynamic_linear(16));

// quadratic
index::rtree<Value, index::dynamic_quadratic> rt(index::dynamic_quadratic(16));

// rstar
index::rtree<Value, index::dynamic_rstar> rt(index::dynamic_rstar(16));

明显的缺点是 R-tree 会稍慢.

非默认参数

非默认的 R-tree 参数在参考文档中描述.

复制、移动与交换

R-tree 是可复制且可移动的容器. 移动语义使用 Boost.Move 库实现, 因此在不支持右值引用的编译器上也可以移动该容器.

// default constructor
index::rtree< Value, index::rstar<8> > rt1;

// copy constructor
index::rtree< Value, index::rstar<8> > rt2(r1);

// copy assignment
rt2 = r1;

// move constructor
index::rtree< Value, index::rstar<8> > rt3(boost::move(rt1));

// move assignment
rt3 = boost::move(rt2);

// swap
rt3.swap(rt2);
插入与移除 Value

以下代码使用二次平衡算法创建 R-tree.

using namespace boost::geometry;
typedef std::pair<Box, int> Value;
index::rtree< Value, index::quadratic<16> > rt;

要通过方法调用插入或移除 Value, 可以使用以下代码.

Value v = std::make_pair(Box(...), 0);

rt.insert(v);

rt.remove(v);

要通过函数调用插入或移除 Value, 可以使用以下代码.

Value v = std::make_pair(Box(...), 0);

index::insert(rt, v);

index::remove(rt, v);

通常你会循环执行这些操作, 例如插入若干 Value, 对应存储在另一个容器中的几何对象 (例如 Polygons) .

附加接口

R-tree 允许从范围创建、插入和移除 Value. 范围可以以 [first, last) 迭代器对的形式传入, 或以适配到某个 Boost.Range 概念的范围形式传入.

namespace bgi = boost::geometry::index;
typedef std::pair<Box, int> Value;
typedef bgi::rtree< Value, bgi::linear<32> > RTree;

std::vector<Value> values;
/* vector filling code, here */

// create R-tree with default constructor and insert values with insert(Value const&)
RTree rt1;
BOOST_FOREACH(Value const& v, values)
   rt1.insert(v);

// create R-tree with default constructor and insert values with insert(Iter, Iter)
RTree rt2;
rt2.insert(values.begin(), values.end());

// create R-tree with default constructor and insert values with insert(Range)
RTree rt3;
rt3.insert(values_range);

// create R-tree with constructor taking Iterators
RTree rt4(values.begin(), values.end());

// create R-tree with constructor taking Range
RTree rt5(values_range);

// remove values with remove(Value const&)
BOOST_FOREACH(Value const& v, values)
   rt1.remove(v);

// remove values with remove(Iter, Iter)
rt2.remove(values.begin(), values.end());

// remove values with remove(Range)
rt3.remove(values_range);

此外, 还可以将通过某个 Boost.Range 适配器适配的范围传入 rtree (更完整的示例见 示例 一节) .

// create Rtree containing `std::pair<Box, int>` from a container of Boxes on the fly.
RTree rt6(boxes | boost::adaptors::indexed()
                | boost::adaptors::transformed(pair_maker()));
插入迭代器

存在诸如 std::copy() 之类的函数, 或 R-tree 的将值复制到输出迭代器的查询. 为了在这类函数中向容器插入值, 可以使用插入迭代器. Geometry.Index 提供自己的 bgi::insert_iterator<Container>, 由 bgi::inserter() 函数生成.

namespace bgi = boost::geometry::index;
typedef std::pair<Box, int> Value;
typedef bgi::rtree< Value, bgi::linear<32> > RTree;

std::vector<Value> values;
/* vector filling code, here */

// create R-tree and insert values from the vector
RTree rt1;
std::copy(values.begin(), values.end(), bgi::inserter(rt1));

// create R-tree and insert values returned by a query
RTree rt2;
rt1.spatial_query(Box(/*...*/), bgi::inserter(rt2));
