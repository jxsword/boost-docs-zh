return_buffer

计算几何对象的缓冲区.

说明

自由函数 return_buffer 计算几何对象的缓冲区 (即距离该几何对象不超过指定最大距离的空间点集集合, 为一个多边形). 这个带 return_ 前缀的版本返回缓冲区, 因此调用时必须指定一个模板参数.

概要 

template<typename Output, typename Input, typename Distance>
Output return_buffer(Input const & geometry, Distance const & distance, Distance const & chord_length = -1)

参数

类型

概念

名称

说明

输出

任何满足几何概念 (Geometry Concept) 的类型

-

必须指定

Input const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

Distance const &

数值类型 (int, double, ttmath 等)

distance

用于缓冲区的距离

Distance const &

数值类型 (int, double, ttmath 等)

chord_length

(可选) 在点或拐弯周围生成的弧中弦的长度 (预留, 尚未使用)
返回

计算得到的缓冲区

头文件
