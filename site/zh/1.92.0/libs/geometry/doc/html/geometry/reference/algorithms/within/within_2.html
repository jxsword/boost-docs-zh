within

检查第一个几何对象是否完全位于第二个几何对象内部.

说明

自由函数 within 检查第一个几何对象是否完全位于第二个几何对象内部.

概要 

template<typename Geometry1, typename Geometry2>
bool within(Geometry1 const & geometry1, Geometry2 const & geometry2)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型, 可能位于第二个几何对象内部

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型, 可能包含第一个几何对象
返回

若 geometry1 完全包含于 geometry2 内则为 true, 否则为 false

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/within.hpp>

一致性

函数 within 实现了 OGC Simple Feature Specification 中的 Within 函数.

注释

OGC 将 within 定义为完全在内部且不在边界上. 参见 within / 边界上的说明

注释

在上面的状态矩阵中: 列是第一个参数的类型, 行是第二个参数的类型. 因此可以检查一个点是否位于多边形内, 反之则不行.

注释

如果点恰好位于几何对象的边界上, 结果取决于策略. 默认策略 (Winding (coordinate system agnostic)) 在该情况下返回 false.

如果多边形方向反转 (例如按顺时针定义的多边形实际为逆时针), 结果同样取决于策略. 默认策略在点完全位于反转多边形内部时仍返回 true. 有专门的策略在该情况下返回 false.

示例

演示如何检测点是否在多边形内

#include <iostream>
#include <list>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>


int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type>;

    polygon_type poly;
    boost::geometry::read_wkt(
        "POLYGON((2 1.3,2.4 1.7,2.8 1.8,3.4 1.2,3.7 1.6,3.4 2,4.1 3,5.3 2.6,5.4 1.2,4.9 0.8,2.9 0.7,2 1.3)"
            "(4.0 2.0, 4.2 1.4, 4.8 1.9, 4.4 2.2, 4.0 2.0))", poly);

    point_type p(4, 1);

    std::cout << "within: " << (boost::geometry::within(p, poly) ? "yes" : "no") << std::endl;

    return 0;
}

输出:

within: yes
