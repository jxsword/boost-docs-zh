remove(ConvertibleOrRange const &)

从容器中移除与可转换对象相对应的值, 或一段值范围.

说明

与 std::set 或 std::map erase() 方法不同, 该方法移除与以范围传入的值相等的值. 此外, 对于范围中传入的每个值, 该方法只移除一个值, 而非移除所有相等的值.

概要 
template<typename ConvertibleOrRange>
size_type remove(ConvertibleOrRange const & conv_or_rng)
参数

类型

名称

说明

ConvertibleOrRange const &

conv_or_rng

可转换为 value_type 的类型的对象, 或一段值范围.
返回

移除的值的数量.

抛出
  • 若 Value 的拷贝构造函数或拷贝赋值抛出异常.
  • 若分配抛出异常或返回无效值.
警告

该操作仅保证不会发生内存泄漏. 抛出异常后, R-tree 可能处于不一致的状态, 不得再插入或移除元素. 其他操作是允许的, 但其中某些操作可能返回无效数据.
