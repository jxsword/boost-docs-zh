set_from_radian

为线段或矩形框设置坐标值 (以弧度)

说明

坐标值会被正确设置: 如果点的坐标系以度为单位, 弧度值将被转换为度

概要

void set_from_radian(Geometry & geometry, typename fp_coordinate_type< Geometry >::type const & radians)
