validity_failure_type

枚举几何对象可能的有效性失败类型.

说明

枚举 validity_failure_type 列出了 is_valid 算法判定某个几何对象无效的各种可能原因. 除表示无效的取值外, 另有一个附加取值 (no_failure) 表示有效.

概要 

enum validity_failure_type
{
    no_failure = 0,
    failure_few_points = 10,
    failure_wrong_topological_dimension = 11,
    failure_spikes = 12,
    failure_duplicate_points = 13,
    failure_not_closed = 20,
    failure_self_intersections = 21,
    failure_wrong_orientation = 22,
    failure_interior_rings_outside = 30,
    failure_nested_interior_rings = 31,
    failure_disconnected_interior = 32,
    failure_intersecting_interiors = 40,
    failure_wrong_corner_order = 50,
    failure_invalid_coordinate = 60,
    failure_collinear_points_on_face = 70,
    failure_non_coplanar_points_on_face = 71,
    failure_few_points_on_face = 72,
    failure_inconsistent_orientation = 73,
    failure_invalid_intersection = 74,
    failure_disconnected_surface = 75
};

取值

值

说明

no_failure

几何对象有效

failure_few_points

几何对象的点数过少, 例如: 线串少于 2 个点, 开放环少于 3 个点, 闭合多多边形中包含少于 4 个点的多边形, 等等. (适用于线串、环、多边形、多线串和多多边形)

failure_wrong_topological_dimension

几何对象的拓扑维数小于其维数, 例如: 含 3 个相同点的线串, 内环由 3 个共线点构成的开放多边形, 等等. (适用于线状和面状几何对象, 包括线段和矩形框)

failure_spikes

几何对象包含尖刺 (适用于线状和面状几何对象)

failure_duplicate_points

几何对象存在 (连续的) 重复点 (仅适用于面状几何对象)

failure_not_closed

几何对象定义为闭合, 但起点与终点不相同 (仅适用于面状几何对象)

failure_self_intersections

几何对象存在无效的自相交. (仅适用于面状几何对象)

failure_wrong_orientation

几何对象的实际方向与定义的方向不一致 (仅适用于面状几何对象)

failure_interior_rings_outside

几何对象包含位于外环之外的内环 (仅适用于多边形和多多边形)

failure_nested_interior_rings

几何对象存在嵌套的内环 (仅适用于多边形和多多边形)

failure_disconnected_interior

几何对象的内部不连通 (仅适用于多边形和多多边形)

failure_intersecting_interiors

多多边形中包含内部不相离的多边形 (仅适用于多多边形)

failure_wrong_corner_order

矩形框的右上角按字典序小于其左下角 (仅适用于矩形框)

failure_invalid_coordinate

几何对象至少有一个点的坐标无效 (例如, 坐标为 NaN)

failure_collinear_points_on_face

几何对象的同一面上存在共线点 (仅适用于多面体曲面)

failure_non_coplanar_points_on_face

几何对象的同一面上存在非共面点 这些点不在同一平面上, 因此无法构成一个面 (仅适用于多面体曲面)

failure_few_points_on_face

几何对象的同一面上点数过少 一个面至少需要 3 个点才能被定义 (仅适用于多面体曲面)

failure_inconsistent_orientation

几何对象至少有一条边的方向不一致 该边在其所属的两个面中方向相同 (仅适用于多面体曲面)

failure_invalid_intersection

几何对象的面存在无效相交 各面未以有效方式相交, 即不在公共边上相交 (仅适用于多面体曲面)

failure_disconnected_surface

几何对象的面不连通, 即不连续 (仅适用于多面体曲面)
头文件

#include <boost/geometry/algorithms/validity_failure_type.hpp>

参见

以 validity_failure_type 引用作为第二个参数的 is_valid 算法
