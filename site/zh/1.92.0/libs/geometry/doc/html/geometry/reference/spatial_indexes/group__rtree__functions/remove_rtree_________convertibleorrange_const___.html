remove(rtree<...> &, ConvertibleOrRange const &)

从容器中移除与可转换对象相对应的值, 或一段值范围.

说明

与 std::set 或 std::map erase() 方法不同, 该方法移除与以范围传入的值相等的值. 此外, 对于范围中传入的每个值, 该方法只移除一个值, 而非移除所有相等的值.

它调用 rtree::remove(ConvertibleOrRange const&).

概要 
template<typename Value,
         typename Parameters,
         typename IndexableGetter,
         typename EqualTo,
         typename Allocator,
         typename ConvertibleOrRange>
rtree< Value, Parameters, IndexableGetter, EqualTo, Allocator >::size_type remove(rtree< Value, Parameters, IndexableGetter, EqualTo, Allocator > & tree, ConvertibleOrRange const & conv_or_rng)
参数

类型

名称

说明

rtree< Value, Parameters, IndexableGetter, EqualTo, Allocator > &

tree

空间索引.

ConvertibleOrRange const &

conv_or_rng

可转换为 value_type 的类型的对象, 或值范围.
返回

移除的值的数量.
