buffer_side_selector

枚举缓冲区一侧的选项 (相对于有向线段的左/右)

说明

沿线串, 缓冲区可以定义在左侧或右侧. 围绕多边形 (内部假定为顺时针), 缓冲区或在左侧 (使多边形膨胀), 或在右侧 (使多边形收缩)

概要 

enum buffer_side_selector {buffer_side_left, buffer_side_right};

取值

值

说明

buffer_side_left

buffer_side_right

头文件

#include <boost/geometry/strategies/buffer.hpp>
