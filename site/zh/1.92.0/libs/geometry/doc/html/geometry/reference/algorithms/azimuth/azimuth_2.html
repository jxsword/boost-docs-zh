azimuth

计算由一对点定义的线段的方位角.

概要 

template<typename Point1, typename Point2>
auto azimuth(Point1 const & point1, Point2 const & point2)

参数

类型

概念

名称

说明

Point1 const &

线段第一个点的类型.

point1

线段的第一个点.

Point2 const &

线段第二个点的类型.

point2

线段的第二个点.
返回

以弧度表示的方位角.

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/azimuth.hpp>

一致性

OGC 未定义 azimuth 函数.

注释

PostGIS 含有功能相同的 ST_Azimuth 算法, 但结果可能不同, 例如结果被归一化到 0 至 pi 而不是 -pi 至 pi 的范围. 参见 PostGIS documentation.

行为

该算法计算由一对点定义的线段的方位角.

注释

结果位于 -pi 至 pi 弧度的范围内.

示例

演示如何计算方位角

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;

    point_type p1(0, 0);
    point_type p2(1, 1);

    auto azimuth = boost::geometry::azimuth(p1, p2);

    std::cout << "azimuth: " << azimuth << std::endl;

    return 0;
}

输出:

azimuth: 0.785398
