point_order

定义 value 为指定几何类型点序 (顺时针, 逆时针) 的元函数.

概要 

template<typename Geometry>
struct point_order
      : public std::integral_constant< order_selector, core_dispatch::point_order< tag_t< Geometry >, util::remove_cptrref_t< Geometry > >::value >
{
  // ...
};

模板参数

参数

说明

typename Geometry

任何满足几何概念 (Geometry Concept) 的类型
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/point_order.hpp>

注释

点序对任何几何类型都有定义, 但只对面状几何类型 (环, 多边形, multi_polygon) 有实际意义

复杂度

编译期

示例

检查多边形类型期望的点序

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type, false>;

    boost::geometry::order_selector order = boost::geometry::point_order<polygon_type>::value;

    std::cout << "order: " << order << std::endl
        << "(clockwise = " << boost::geometry::clockwise
        << ", counterclockwise = " << boost::geometry::counterclockwise
        << ") "<< std::endl;

    return 0;
}

输出:

order: 2
(clockwise = 1, counterclockwise = 2)
