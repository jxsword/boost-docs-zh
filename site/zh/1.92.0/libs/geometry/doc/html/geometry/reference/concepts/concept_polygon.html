多边形概念

说明

多边形概念描述多边形类型的要求. Boost.Geometry 中的所有算法都会依据概念要求检查几何参数.

多边形是由一个外部边界和零个或多个内部边界定义的平面表面 (OGC Simple Feature Specification).

因此 Boost.Geometry 多边形的定义与例如 Wiki (那里的多边形没有孔洞) 略有不同. Boost.Geometry 的多边形可以有孔洞, 也可以没有. (无孔洞的多边形在 Boost.Geometry 中是一种 辅助几何, 称为环.)

概念定义

多边形概念定义如下:

  • 必须存在 traits::tag 的特化, 将 polygon_tag 定义为类型
  • 必须存在 traits::ring_mutable_type 的特化, 将其外环与内环的可变类型定义为 type
  • 必须存在 traits::ring_const_type 的特化, 将其外环与内环的常量类型定义为 type
  • traits::ring_mutable_type 和 traits::ring_const_type 必须满足 环概念
  • 必须存在 traits::interior_mutable_type 的特化, 将其内环集合的可变类型定义为 type;
  • 必须存在 traits::interior_const_type 的特化, 将其内环集合的常量类型定义为 type; 每个这样的集合本身必须满足 Boost.Range 随机访问范围概念
  • 必须存在 traits::exterior_ring 的特化, 带有两个名为 get 的函数, 返回外环, 一个为 const, 另一个为非 const
  • 必须存在 traits::interior_rings 的特化, 带有两个名为 get 的函数, 返回内环, 一个为 const, 另一个为非 const
规则

除了编译期检查的概念之外, 有效多边形还必须满足一些其他规则. 这些规则遵循 opengeospatial 规则 (见上面的链接).

  • 多边形是简单的几何对象 (另见 wiki, 但 Boost.Geometry 的多边形允许有孔洞).
  • 如果多边形的 ring_type 定义为顺时针, 外环必须为顺时针方向, 且任何内环必须相对定义的方向反转 (即: 外环为顺时针时内环为逆时针). 如果 ring_type 定义为逆时针, 则相反.
  • 如果多边形的 ring_type 定义为闭合, 所有环都必须闭合: 第一个点必须与最后一个点空间相等.
  • 内部是一个连通点集.
  • 不应有自相交, 但允许自相切 (在外环/内环之间), 只要内部是连通点集.
  • 不应有切割线、尖刺或穿孔.
  • 内环应位于外环之内. 内环之间不得互相嵌套.

intersection, area, centroid, union 等算法不检查有效性. 有一个 is_valid 算法会在运行时依据这些规则检查有效性, (库用户) 可以事先调用它.

如果输入无效, 输出可能也无效. 例如: 如果本应闭合的多边形未闭合, 面积将不正确.

可用模型
  • polygon
  • Boost.Polygon 的 polygon_with_holes_data (需要 #include boost/geometry/geometries/adapted/boost_polygon/polygon.hpp>)
