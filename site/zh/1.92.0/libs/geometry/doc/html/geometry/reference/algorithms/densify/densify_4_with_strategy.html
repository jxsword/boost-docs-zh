densify (with strategy)

使用指定策略加密几何对象.

概要 

template<typename Geometry, typename Distance, typename Strategy>
void densify(Geometry const & geometry, Geometry & out, Distance const & max_distance,
             Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

输入几何, 待加密

Geometry &

任何满足几何概念 (Geometry Concept) 的类型

out

输出几何, 输入几何的加密版本

Distance const &

数值距离度量

max_distance

距离阈值 (单位取决于策略)

Strategy const &

满足 DensifyStrategy 概念的类型

strategy

用于加密的加密策略
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/densify.hpp>

一致性

OGC 未定义 densify 函数.

注释

PostGIS 含有功能相同的 ST_Segmentize 算法. 参见 PostGIS documentation.

行为

该算法将几何对象中长度超过给定距离的分段切分为更小的分段.

注释

距离的单位取决于策略. 若要改变默认行为, 用户必须创建一个策略并显式传入算法.

可用策略
  • 笛卡尔
  • 球面
  • 地理
示例

演示如何在地理坐标系中加密线串

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point.hpp>
#include <boost/geometry/geometries/linestring.hpp>

int main()
{
    namespace bg = boost::geometry;
    using point_type = bg::model::point<double, 2, bg::cs::geographic<bg::degree>>;
    using linestring_type = bg::model::linestring<point_type>;

    linestring_type ls;
    bg::read_wkt("LINESTRING(0 0,1 1)", ls);

    linestring_type res;

    bg::srs::spheroid<double> spheroid(6378137.0, 6356752.3142451793);
    bg::strategy::densify::geographic<> strategy(spheroid);

    boost::geometry::densify(ls, res, 50000.0, strategy);

    std::cout << "densified: " << boost::geometry::wkt(res) << std::endl;

    return 0;
}

输出:

densified: LINESTRING(0 0,0.249972 0.250011,0.499954 0.500017,0.749954 0.750013,1 1)
