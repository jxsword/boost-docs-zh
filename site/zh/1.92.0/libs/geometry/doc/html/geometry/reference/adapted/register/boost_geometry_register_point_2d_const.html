BOOST_GEOMETRY_REGISTER_POINT_2D_CONST

注册二维点类型的宏 (const 版本)

说明

宏 BOOST_GEOMETRY_REGISTER_POINT_2D_CONST 注册一个二维点类型, 使其能被 Boost.Geometry 识别, 从而可以对指定类型使用 Boost.Geometry 功能. const 版本只注册对字段的读取访问, 因此该点类型是只读的. 对于地理坐标系, 务必先指定经度再指定纬度, 以便使用库内置的策略.

概要 

#define BOOST_GEOMETRY_REGISTER_POINT_2D_CONST(Point, CoordinateType, CoordinateSystem,
                                        Field0, Field1)

参数

名称

说明

点

要注册的点类型

CoordinateType

点的坐标类型 (例如 double)

CoordinateSystem

坐标系 (例如 cs::cartesian)

Field0

包含第一个坐标 (通常是 x 或经度) 的成员

Field1

包含第二个坐标 (通常是 y 或纬度) 的成员
头文件

#include <boost/geometry/geometries/register/point.hpp>
