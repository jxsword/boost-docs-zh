unique

计算几何对象的最小集合.

说明

自由函数 unique 计算几何对象的最小集合 (移除重复的相邻点).

概要 

template<typename Geometry>
void unique(Geometry & geometry)

参数

类型

概念

名称

说明

Geometry &

任何满足几何概念 (Geometry Concept) 的类型

geometry

将被去重的所指定概念的模型
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/unique.hpp>

一致性

OGC 未定义 unique 函数.

unique 函数与 C++ 标准库的 std::unique 函数保持一致.

行为

情况

行为

点

不发生任何事情, 几何对象保持不变

线段

不发生任何事情, 几何对象保持不变

矩形框

不发生任何事情, 几何对象保持不变

Linestring

移除所有相邻的重复点

Ring

移除所有相邻的重复点

多边形 (Polygon)

移除所有环中相邻的重复点

多点 (Multi Point)

不发生任何事情, 几何对象保持不变. 即使两个相等的点恰好相邻存储, 也会保留

多线串 (Multi Linestring)

移除其中所有线串内相邻的重复点

多多边形 (Multi Polygon)

移除其中所有多边形 (所有环) 内相邻的重复点
复杂度

线性

示例

演示如何通过移除重复点得到多边形的最小集合

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/adapted/boost_tuple.hpp>

BOOST_GEOMETRY_REGISTER_BOOST_TUPLE_CS(cs::cartesian)

int main()
{
    boost::geometry::model::polygon<boost::tuple<double, double>> poly;
    boost::geometry::read_wkt("POLYGON((0 0,0 0,0 5,5 5,5 5,5 5,5 0,5 0,0 0,0 0,0 0,0 0))", poly);
    boost::geometry::unique(poly);
    std::cout << boost::geometry::wkt(poly) << std::endl;

    return 0;
}

输出:

POLYGON((0 0,0 5,5 5,5 0,0 0))
