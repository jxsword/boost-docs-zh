intersection

计算两个几何对象的交集.

说明

自由函数 intersection 计算两个几何对象的空间集合论交集.

概要 

template<typename Geometry1, typename Geometry2, typename GeometryOut>
bool intersection(Geometry1 const & geometry1, Geometry2 const & geometry2, GeometryOut & geometry_out)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型

GeometryOut &

几何对象的集合 (如 std::vector, std::deque, boost::geometry::multi*), 其 value_type 满足点、线串或多边形概念, 或者它就是输出几何 (例如对矩形框而言)

geometry_out

输出几何, 可以是 multi_point, multi_polygon, multi_linestring, 或矩形框 (用于两个矩形框的交集)
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/intersection.hpp>

一致性

函数 intersection 实现了 OGC Simple Feature Specification 中的 Intersection 函数.

行为

情况

行为

GeometryOut 为点

计算输入几何对象的交点

GeometryOut 为线串

计算输入 (多) 线串的相交线串

GeometryOut 为多边形

计算输入 (多) 多边形和/或矩形框的相交多边形
注释

本算法的多边形输入应满足的规则请参见 Polygon Concept

示例

演示两个多边形的交集

#include <iostream>
#include <deque>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>



int main()
{
    using polygon = boost::geometry::model::polygon<boost::geometry::model::d2::point_xy<double>> ;

    polygon green, blue;

    boost::geometry::read_wkt(
        "POLYGON((2 1.3,2.4 1.7,2.8 1.8,3.4 1.2,3.7 1.6,3.4 2,4.1 3,5.3 2.6,5.4 1.2,4.9 0.8,2.9 0.7,2 1.3)"
            "(4.0 2.0, 4.2 1.4, 4.8 1.9, 4.4 2.2, 4.0 2.0))", green);

    boost::geometry::read_wkt(
        "POLYGON((4.0 -0.5 , 3.5 1.0 , 2.0 1.5 , 3.5 2.0 , 4.0 3.5 , 4.5 2.0 , 6.0 1.5 , 4.5 1.0 , 4.0 -0.5))", blue);

    std::deque<polygon> output;
    boost::geometry::intersection(green, blue, output);

    int i = 0;
    std::cout << "green && blue:" << std::endl;
    for (polygon const& p : output)
    {
        std::cout << i++ << ": " << boost::geometry::area(p) << std::endl;
    }


    return 0;
}

输出:

green && blue:
0: 2.50205
