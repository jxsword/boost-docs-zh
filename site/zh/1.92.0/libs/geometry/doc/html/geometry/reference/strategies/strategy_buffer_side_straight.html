strategy::buffer::side_straight

使缓冲区沿线段使用平直边 (默认)

说明

该策略可用作缓冲区算法的 SideStrategy. 它是目前为此目的提供的唯一策略

概要 

class strategy::buffer::side_straight
{
  // ...
};

头文件

#include <boost/geometry/strategies/cartesian/buffer_side_straight.hpp>

示例

其他缓冲区策略的示例参见 join_round
