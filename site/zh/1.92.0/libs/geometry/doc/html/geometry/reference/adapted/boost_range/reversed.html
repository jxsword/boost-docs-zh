Boost.Range reversed

Boost.Range 的 reversed 范围适配器已适配到 Boost.Geometry

说明

Boost.Range 的 reversed 范围适配器用于反转范围.

所属模型

Boost.Range 的 reversed 范围适配器沿用原几何的模型, 原几何可能是:

  • 线串 (linestring)
  • 环 (ring)
  • multi_point (多点)
  • multi_linestring (多线串)
  • multi_polygon (多多边形)
头文件

#include <boost/geometry/geometries/adapted/boost_range/reversed.hpp>

标准头文件 boost/geometry.hpp 不会包含本头文件.

示例

演示如何使用经 Boost.Range 适配器反转的 Boost.Geometry 线串

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/linestring.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/adapted/boost_range/reversed.hpp>

int main()
{
    using xy = boost::geometry::model::d2::point_xy<int>;
    boost::geometry::model::linestring<xy> line;
    line.push_back(xy(0, 0));
    line.push_back(xy(1, 1));

    std::cout
        << boost::geometry::dsv(line | boost::adaptors::reversed)
        << std::endl;

    return 0;
}

输出:

((1, 1), (0, 0))
