de9im::static_mask

DE-9IM 模型交集掩码 (静态版本).

说明

该掩码可用于按维度扩展 9 交集模型 (Dimensionally Extended 9-Intersection Model) 检查空间关系.

概要 

template<char II, char IB, char IE, char BI,
         char BB, char BE, char EI, char EB,
         char EE>
class de9im::static_mask
      : public detail::relate::static_mask< std::integer_sequence< char, ' *', ' *', ' *', ' *', ' *', ' *', ' *', ' *', ' *' >, 3, 3 >
{
  // ...
};
