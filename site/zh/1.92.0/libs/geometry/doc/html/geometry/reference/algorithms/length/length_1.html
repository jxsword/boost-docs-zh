length

计算几何对象的长度.

说明

自由函数 length 计算几何对象的长度 (相邻点之间距离之和). 它使用默认策略, 该策略基于几何对象的坐标系.

概要 

template<typename Geometry>
default_length_result< Geometry >::type length(Geometry const & geometry)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型
返回

计算得到的长度

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/length.hpp>

一致性

函数 length 实现了 OGC Simple Feature Specification 中的 Length 函数.

行为

情况

行为

点状 (如 point)

返回 0

线状 (如 linestring)

返回长度

面状 (如 polygon)

返回 0
复杂度

线性

示例

下面的简单示例演示计算含三个点的线串的长度

#include <iostream>
#include <boost/geometry.hpp>
#include <boost/geometry/geometries/linestring.hpp>
#include <boost/geometry/geometries/point_xy.hpp>


int main()
{
    using namespace boost::geometry;
    model::linestring<model::d2::point_xy<double>> line;
    read_wkt("linestring(0 0,1 1,4 8,3 2)", line);
    std::cout << "linestring length is "
        << length(line)
        << " units" << std::endl;

    return 0;
}

输出:

linestring length is 15.1127 units
