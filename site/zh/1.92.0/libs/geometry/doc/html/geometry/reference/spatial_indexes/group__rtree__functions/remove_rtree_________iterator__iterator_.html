remove(rtree<...> &, Iterator, Iterator)

从容器中移除一段值范围.

说明

与 std::set 或 std::map erase() 方法不同, 该方法不接收指向此容器中存储的值的迭代器. 它移除与以范围传入的值相等的值. 此外, 对于范围中传入的每个值, 该函数只移除一个值, 而非移除所有相等的值.

它调用 rtree::remove(Iterator, Iterator).

概要

         typename Parameters,
         typename IndexableGetter,
