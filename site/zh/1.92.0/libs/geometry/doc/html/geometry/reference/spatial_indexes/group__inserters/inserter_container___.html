inserter(Container &)

插入迭代器生成器.

说明

返回能够向容器 (空间索引) 插入值的插入迭代器, 该容器须定义了成员函数 insert(value_type const&).

概要 
template<typename Container>
insert_iterator< Container > inserter(Container & c)
参数

类型

名称

说明

Container &

c

对将要插入值的容器 (空间索引) 的引用.
返回

向容器插入值的插入迭代器.
