difference (with strategy)

说明

计算两个几何对象的差集

自由函数 difference 计算两个几何对象的空间集合论差集.

概要 

template<typename Geometry1, typename Geometry2, typename Collection, typename Strategy>
void difference(Geometry1 const & geometry1, Geometry2 const & geometry2, Collection & output_collection,
                Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型

Collection &

输出集合, 可以是多几何 (multi-geometry), 也可以是 std::vector<Geometry> / std::deque<Geometry> 等

output_collection

输出集合

Strategy const &

任何满足差集策略概念 (Difference Strategy Concept) 的类型

strategy

用于差集计算的策略
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/difference.hpp>

一致性

函数 difference 实现了 OGC Simple Feature Specification 中的 Difference 函数.

行为

情况

行为

面状 (如 polygon)

box, ring, polygon, multi_polygon 的所有组合

线状 (如 linestring) / 面状 (如 polygon)

(多) 线串与 (多) 多边形的组合会得到线串集合

线状 (如 linestring)

linestring, multi_linestring 的所有组合; 结果为线串集合

点状 (如 point)

point, multi_point 的所有组合; 结果为点集合

其他几何类型

本版本尚不支持

球面

本版本尚不支持

三维

本版本尚不支持
注释

本算法的多边形输入应满足的规则请参见 Polygon Concept

示例

演示如何从一个多边形中减去另一个多边形

#include <iostream>
#include <list>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>


int main()
{
    using polygon = boost::geometry::model::polygon<boost::geometry::model::d2::point_xy<double>>;

    polygon green, blue;

    boost::geometry::read_wkt(
        "POLYGON((2 1.3,2.4 1.7,2.8 1.8,3.4 1.2,3.7 1.6,3.4 2,4.1 3,5.3 2.6,5.4 1.2,4.9 0.8,2.9 0.7,2 1.3)"
            "(4.0 2.0, 4.2 1.4, 4.8 1.9, 4.4 2.2, 4.0 2.0))", green);

    boost::geometry::read_wkt(
        "POLYGON((4.0 -0.5 , 3.5 1.0 , 2.0 1.5 , 3.5 2.0 , 4.0 3.5 , 4.5 2.0 , 6.0 1.5 , 4.5 1.0 , 4.0 -0.5))", blue);

    std::list<polygon> output;
    boost::geometry::difference(green, blue, output);

    int i = 0;
    std::cout << "green - blue:" << std::endl;
    for (polygon const& p : output)
    {
        std::cout << i++ << ": " << boost::geometry::area(p) << std::endl;
    }


    output.clear();
    boost::geometry::difference(blue, green, output);

    i = 0;
    std::cout << "blue - green:" << std::endl;
    for (polygon const& p : output)
    {
        std::cout << i++ << ": " << boost::geometry::area(p) << std::endl;
    }


    return 0;
}
