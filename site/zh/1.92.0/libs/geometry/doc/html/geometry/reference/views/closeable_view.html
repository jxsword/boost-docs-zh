closeable_view

范围上的视图, 可将其闭合或保持原样.

说明

库内部使用 closeable_view 以相同方式处理所有环 (无论闭合还是开放) . 默认方法为闭合: 所有算法都将环视为闭合的进行处理. 因此, 如果环是开放的, 就会创建一个将其闭合的视图. 库使用者可以使用 closeable_view, 但其主要用途是在库内部.

概要 

template<typename Range, closure_selector Close>
struct closeable_view
{
  // ...
};

模板参数

参数

说明

typename Range

原始范围

closure_selector Close

指定范围是否闭合, 若是, 则不做任何处理. 若是开放的, 则会在最后一个点之后迭代第一个点.
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/views/closeable_view.hpp>
