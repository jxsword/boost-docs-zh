coordinate_system

定义 type 为构成指定几何类型的点类型的坐标系 (笛卡尔, 球面等) 的元函数.

概要 

template<typename Geometry>
struct coordinate_system
{
  // ...
};

模板参数

参数

说明

typename Geometry

任何满足几何概念 (Geometry Concept) 的类型
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/coordinate_system.hpp>

复杂度

编译期

示例

检查点的坐标系

#include <iostream>
#include <typeinfo>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type>;

    using system = boost::geometry::coordinate_system<polygon_type>::type;

    std::cout << "system: " << typeid(system).name() << std::endl;

    return 0;
}

输出 (使用 MSVC):

system: struct boost::geometry::cs::cartesian
