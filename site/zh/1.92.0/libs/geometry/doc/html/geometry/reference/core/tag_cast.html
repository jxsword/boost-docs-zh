tag_cast

定义一个类型的元函数: 该类型为指定标签, 或 (当该类型继承自所指定的某个基标签时) 该基标签.

说明

标签可以相互继承. 例如 multi_point 同时继承 multi_tag 与 pointlike_tag. 不同几何类型之间常常可以共享行为. 由 tag 元函数找到的标签可以被转换为更基础的标签, 然后按该标签分派.

概要 

template<typename Tag, typename ... BaseTags>
struct tag_cast
{
  // ...
};

模板参数

参数

说明

typename Tag

要转换为某个基标签的标签

typename ... BaseTags

基标签
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/tag_cast.hpp>

注释

指定的标签列表按给定顺序处理: 一旦找到继承指定标签的标签, 就将其定义为元函数 typedef type.

注释

如果指定的候选基标签都不是指定标签的基类, 则将该标签本身定义为元函数的 type 结果.

示例

检查 polygon_tag 能否转换为 areal_tag

#include <iostream>
#include <typeinfo>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

namespace geo = boost::geometry;
int main()
{
    using point_type = geo::model::d2::point_xy<double>;
    using polygon_type = geo::model::polygon<point_type>;

    using tag = geo::tag<polygon_type>::type;
    using base_tag = geo::tag_cast<tag, geo::linear_tag, geo::areal_tag>::type;

    std::cout << "tag: " << typeid(tag).name() << std::endl
        << "base tag: " << typeid(base_tag).name() << std::endl;

    return 0;
}

输出 (在 MSVC 中):

tag: struct boost::geometry::polygon_tag
base tag: struct boost::geometry::areal_tag
