buffer

计算几何对象的缓冲区.

说明

自由函数 buffer 计算几何对象的缓冲区 (即距离该几何对象不超过指定最大距离的空间点集集合, 为一个多边形).

概要 

template<typename Input, typename Output, typename Distance>
void buffer(Input const & geometry_in, Output & geometry_out, Distance const & distance,
            Distance const & chord_length = -1)

参数

类型

概念

名称

说明

Input const &

任何满足几何概念 (Geometry Concept) 的类型

geometry_in

所指定概念的一个模型

Output &

任何满足几何概念 (Geometry Concept) 的类型

geometry_out

所指定概念的一个模型

Distance const &

数值类型 (int, double, ttmath 等)

distance

用于缓冲区的距离

Distance const &

数值类型 (int, double, ttmath 等)

chord_length

(可选) 在点或拐弯周围生成的弧中弦的长度
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/buffer.hpp>

注释

这个不带策略的版本仅扩大矩形框. 要缓冲任意几何对象, 请使用 buffer (with strategies)

行为

情况

行为

Box/Box

返回一个新的矩形框, 按指定距离扩大. 允许 “geometry_out” 与 “geometry_in” 为同一对象
