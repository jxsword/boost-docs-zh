centroid_exception

质心异常.

说明

若对无法计算质心的几何对象调用自由函数 centroid, 则会抛出 centroid_exception. 例如: 不含点的线串、不含点的多边形、空的多几何.

概要 

class centroid_exception
      : public exception
{
  // ...
};
