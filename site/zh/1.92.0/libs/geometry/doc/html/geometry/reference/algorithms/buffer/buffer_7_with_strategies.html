buffer (with strategies)

计算几何对象的缓冲区.

说明

自由函数 buffer 计算几何对象的缓冲区 (即距离该几何对象不超过指定最大距离的空间点集集合, 为一个多边形).

概要 

template<typename GeometryIn, typename GeometryOut, typename DistanceStrategy, typename SideStrategy,
         typename JoinStrategy, typename EndStrategy, typename PointStrategy>
void buffer(GeometryIn const & geometry_in, GeometryOut & geometry_out, DistanceStrategy const & distance_strategy,
            SideStrategy const & side_strategy, JoinStrategy const & join_strategy, EndStrategy const & end_strategy,
            PointStrategy const & point_strategy)

参数

类型

概念

名称

说明

GeometryIn const &

任何满足几何概念 (Geometry Concept) 的类型

geometry_in

所指定概念的一个模型

GeometryOut &

满足 GeometryOut 概念的类型

geometry_out

输出几何对象 (例如多多边形), 将包含输入几何对象的缓冲版本

DistanceStrategy const &

定义距离 (或半径) 的策略

distance_strategy

要使用的距离策略

SideStrategy const &

定义沿边生成的策略

side_strategy

要使用的侧向策略

JoinStrategy const &

定义凸角周围生成的策略

join_strategy

要使用的连接策略

EndStrategy const &

定义线串端点处生成的策略

end_strategy

要使用的端点策略

PointStrategy const &

定义点周围生成的策略

point_strategy

要使用的点策略
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/buffer.hpp>

策略

这 5 个策略让用户能够控制生成的缓冲区

  • 凸角可以是圆角或尖角
  • 线端可以是圆头或平头
  • 距离可以对称或非对称, 可以为正或负
  • 点周围的形状可以是圆形或方形
  • 边可以控制 (目前只提供一种选项)

通过为 distance_strategy 指定负距离, 在 (多) 多边形的情况下多边形会变小 (也称为收缩, deflate). 距离不能为 0.

一致性

函数 buffer 实现了 OGC Simple Feature Specification 中的 Buffer 函数.

若与以下策略组合使用, 则符合规范: join_round, end_round, distance_symmetric, point_circle, side_straight

示例

演示如何使用 buffer 算法为线串、多点、多多边形创建缓冲区

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/geometries.hpp>


int main()
{
    using coordinate_type = double;
    using point = boost::geometry::model::d2::point_xy<coordinate_type>;
    using polygon = boost::geometry::model::polygon<point>;

    // Declare strategies
    const double buffer_distance = 1.0;
    const int points_per_circle = 36;
    boost::geometry::strategy::buffer::distance_symmetric<coordinate_type> distance_strategy(buffer_distance);
    boost::geometry::strategy::buffer::join_round join_strategy(points_per_circle);
    boost::geometry::strategy::buffer::end_round end_strategy(points_per_circle);
    boost::geometry::strategy::buffer::point_circle circle_strategy(points_per_circle);
    boost::geometry::strategy::buffer::side_straight side_strategy;

    // Declare output
    boost::geometry::model::multi_polygon<polygon> result;

    // Declare/fill a linestring
    boost::geometry::model::linestring<point> ls;
    boost::geometry::read_wkt("LINESTRING(0 0,4 5,7 4,10 6)", ls);

    // Create the buffer of a linestring
    boost::geometry::buffer(ls, result,
                distance_strategy, side_strategy,
                join_strategy, end_strategy, circle_strategy);


    // Declare/fill a multi point
    boost::geometry::model::multi_point<point> mp;
    boost::geometry::read_wkt("MULTIPOINT((3 3),(4 4),(6 2))", mp);

    // Create the buffer of a multi point
    boost::geometry::buffer(mp, result,
                distance_strategy, side_strategy,
                join_strategy, end_strategy, circle_strategy);


    // Declare/fill a multi_polygon
    boost::geometry::model::multi_polygon<polygon> mpol;
    boost::geometry::read_wkt("MULTIPOLYGON(((0 1,2 5,5 3,0 1)),((1 1,5 2,5 0,1 1)))", mpol);

    // Create the buffer of a multi polygon
    boost::geometry::buffer(mpol, result,
                distance_strategy, side_strategy,
                join_strategy, end_strategy, circle_strategy);


    return 0;
}

可用策略
  • JoinStrategy: join_round (cartesian)
  • JoinStrategy: join_miter (cartesian)
  • EndStrategy: end_round (cartesian)

  • DistanceStrategy: distance_asymmetric
  • PointStrategy: point_circle (cartesian)
  • PointStrategy: point_square (cartesian)

  • SideStrategy: side_straight (cartesian)
