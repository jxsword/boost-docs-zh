svg

将几何对象以 SVG 形式流式输出的操纵器.

概要 

template<typename Geometry>
svg_manipulator< Geometry > svg(Geometry const & geometry, std::string const & style, double size = -1.0)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

std::string const &

style

原样包含 SVG 样式信息的字符串

double

size

以 SVG 像素为单位的可选尺寸 (用于 SVG 点) . 对于线串, 请在 SVG 样式信息中指定线宽
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/io/svg/write.hpp>
