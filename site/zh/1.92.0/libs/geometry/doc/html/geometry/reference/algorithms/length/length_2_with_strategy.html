length (with strategy)

使用指定策略计算几何对象的长度.

说明

自由函数 length 使用指定策略计算几何对象的长度 (相邻点之间距离之和). 指定策略的原因包括: 使用另一种坐标系进行计算; 预先构造策略 (例如传入地球半径); 当同一计算有多种策略可用时进行选择.

概要 

template<typename Geometry, typename Strategy>
default_length_result< Geometry >::type length(Geometry const & geometry, Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

Strategy const &

任何满足距离策略概念 (distance Strategy Concept) 的类型

strategy

用于距离计算的策略
返回

计算得到的长度

一致性

示例

下面的示例演示在球面上测量的长度, 以千米表示. 为此必须在策略的构造函数中指定球的半径.

#include <iostream>
#include <boost/geometry.hpp>
#include <boost/geometry/geometries/linestring.hpp>

int main()
{
    using namespace boost::geometry;
    using P = model::point<float, 2, cs::spherical_equatorial<degree>>;
    model::linestring<P> line;
    line.push_back(P(2, 41));
    line.push_back(P(2, 48));
    line.push_back(P(5, 52));
    double const mean_radius = 6371.0; 
    std::cout << "length is "
        << length(line, strategy::distance::haversine<float>(mean_radius) )
        << " kilometers " << std::endl;

    return 0;
}
