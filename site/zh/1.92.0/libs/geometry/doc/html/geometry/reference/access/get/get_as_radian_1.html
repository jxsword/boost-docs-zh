get_as_radian

获取点的坐标值, 结果以弧度表示

说明

即使源坐标系以度为单位, 结果也以弧度表示

概要 

template<std::size_t Dimension, typename Geometry>
fp_coordinate_type< Geometry >::type get_as_radian(Geometry const & geometry)

参数

类型

概念

名称

说明

Dimension

dimension

-

必须指定

Geometry const &

geometry

geometry

返回

坐标值
