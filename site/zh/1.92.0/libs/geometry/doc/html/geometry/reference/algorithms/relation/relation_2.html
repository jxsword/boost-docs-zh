relation

按 DE-9IM 的定义计算一对几何对象之间的关系.

概要 

template<typename Geometry1, typename Geometry2>
de9im::matrix relation(Geometry1 const & geometry1, Geometry2 const & geometry2)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型
返回

表达几何对象间关系的 DE-9IM 矩阵.

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/relation.hpp>

一致性

该函数是额外提供的, OGC 标准未予描述. 空间关系由 DE-9IM 矩阵表示.

示例

演示如何计算点与多边形之间的空间关系

#include <iostream>
#include <string>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>


int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type>;

    polygon_type poly;
    boost::geometry::read_wkt(
        "POLYGON((2 1.3,2.4 1.7,2.8 1.8,3.4 1.2,3.7 1.6,3.4 2,4.1 3,5.3 2.6,5.4 1.2,4.9 0.8,2.9 0.7,2 1.3)"
            "(4.0 2.0, 4.2 1.4, 4.8 1.9, 4.4 2.2, 4.0 2.0))", poly);

    point_type p(4, 1);

    boost::geometry::de9im::matrix matrix = boost::geometry::relation(p, poly);
    std::string code = matrix.str();

    std::cout << "relation: " << code << std::endl;

    return 0;
}

输出:

relation: 0FFFFF212
