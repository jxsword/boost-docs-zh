model::point

基本点类, 以中立方式定义坐标.

说明

定义一个中立的点类, 满足 Point 概念. 库使用者可以使用该点类, 也可以使用自己的点类. 该点类用于 Boost.Geometry 的大多数示例和测试中. 在库内部, 需要临时点类的地方也会偶尔使用该点类.

示例

声明并使用 Boost.Geometry 的 model::point, 以模拟 Point 概念

#include <iostream>
#include <boost/geometry.hpp>

namespace bg = boost::geometry;

int main()
{
    bg::model::point<double, 2, bg::cs::cartesian> point1;
    bg::model::point<double, 3, bg::cs::cartesian> point2(1.0, 2.0, 3.0); 

    bg::set<0>(point1, 1.0); 
    point1.set<1>(2.0); 

    double x = bg::get<0>(point1); 
    double y = point1.get<1>(); 

    std::cout << x << ", " << y << std::endl;
    return 0;
}
