WKT (Well-Known Text)

from_wkt
read_wkt
to_wkt
to_wkt (with significant digits)
wkt

WKT 是一种基于 ASCII 的通用标记格式. 其详细描述见 Wikipedia

Boost Geometry 支持常见格式 (POINT、LINESTRING、POLYGON、MULTIPOINT、MULTILINESTRING、MULTIPOLYGON) .

由于 Boost.Geometry 还支持并非标准 OGC 几何对象的 Box 与 Segment 几何对象, 因此有一些扩展:

Box
  • 可通过指定多边形 (含 4 个点) 或特定的 BOX 字符串 (非 OGC) 从 WKT 读取
  • 以 POLYGON 形式流式输出为 WKT
Segment
  • 可通过指定线串 (含 2 个点) 或特定的 SEGMENT 字符串 (非 OGC) 从 WKT 读取
  • 以 LINESTRING 形式流式输出为 WKT
Ring
  • 可通过指定多边形 (无孔洞) 从 WKT 读取
  • 以 POLYGON 形式流式输出为 WKT
