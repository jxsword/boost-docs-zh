centroid

计算几何对象的质心.

说明

自由函数 centroid 计算几何对象的几何中心 (即质心). 它使用默认策略, 该策略基于几何对象的坐标系.

概要 

template<typename Geometry, typename Point>
void centroid(Geometry const & geometry, Point & c)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

Point &

任何满足点概念 (Point Concept) 的类型

c

计算得到的质心将赋给该点引用

示例

演示计算多边形质心

#include <iostream>
#include <list>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>


int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type>;

    polygon_type poly;
    boost::geometry::read_wkt(
        "POLYGON((2 1.3,2.4 1.7,2.8 1.8,3.4 1.2,3.7 1.6,3.4 2,4.1 3,5.3 2.6,5.4 1.2,4.9 0.8,2.9 0.7,2 1.3)"
            "(4.0 2.0, 4.2 1.4, 4.8 1.9, 4.4 2.2, 4.0 2.0))", poly);

    point_type p;
    boost::geometry::centroid(poly, p);

    std::cout << "centroid: " << boost::geometry::dsv(p) << std::endl;

    return 0;
}

输出:

centroid: (4.04663, 1.6349)

注意, 质心很可能位于多边形的孔洞内甚至多边形之外.
