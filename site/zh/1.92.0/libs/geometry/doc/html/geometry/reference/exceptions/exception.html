exception

Boost.Geometry 算法的异常基类.

说明

该类从不会被抛出. Boost.Geometry 中抛出的所有异常均派生自 exception, 因此捕获它可能比较方便.

概要 

class exception
      : public std::exception
{
  // ...
};
