R-tree 空间索引.

说明

这是一种自平衡空间索引, 能够存储多种类型的 Value 并支持多种平衡算法.

参数

用户必须传入一个定义 Parameters 的类型, 该类型将在 rtree 创建过程中使用. 例如, 该类型可用于指定平衡算法及其具体参数, 如节点中元素的最小与最大数量.

带编译期参数的预定义算法有:

  • boost::geometry::index::linear,
  • boost::geometry::index::quadratic,
  • boost::geometry::index::rstar.

带运行期参数的预定义算法有:

  • boost::geometry::index::dynamic_linear,
  • boost::geometry::index::dynamic_quadratic,
  • boost::geometry::index::dynamic_rstar.
IndexableGetter

IndexableGetter 类型的对象在 r-tree 需要时将 Value 转换为 Indexable. 每次访问 Value 都会执行此操作. 不应每次都计算 Indexable, 因为这可能损害性能. 默认的 IndexableGetter 可以转换所有适配到 Point、Box 或 Segment 概念的类型 (称为 Indexable) . 此外, 它还能处理 std::pair<Indexable, T>、std::tuple<Indexable, ...> 和 boost::tuple<Indexable, ...>. 例如, 对于类型为 std::pair<Box, int> 的 Value, 默认的 IndexableGetter 会将 std::pair<Box, int> const& 转换为 Box const&.

EqualTo

EqualTo 类型的对象比较 Value, 若相等则返回 true. 它类似于 std::equal_to<>. 默认的 EqualTo 对适配到 Boost.Geometry 中所定义某个几何概念的类型返回 boost::geometry::equals() 的结果, 对其他类型返回 operator== 的结果. Pair 与 Tuple 的各组件按从左到右的顺序进行比较.

头文件

#include <boost/geometry/index/rtree.hpp>

概要 
template<typename Value,
         typename Parameters,
         typename IndexableGetter = index::indexable<Value>,
         typename EqualTo = index::equal_to<Value>,
         typename Allocator = boost::container::new_allocator<Value>>
class rtree
{
  // ...
};
