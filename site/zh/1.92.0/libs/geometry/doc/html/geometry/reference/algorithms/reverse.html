reverse

反转几何对象中的点序.

说明

反转几何对象的通用函数. 它类似于 std::reverse 的功能, 但会考虑几何类型. 只有对环或线串, 它才与 std::reverse 相同.

概要 

template<typename Geometry>
void reverse(Geometry & geometry)

参数

类型

概念

名称

说明

Geometry &

任何满足几何概念 (Geometry Concept) 的类型

geometry

将被反转的所指定概念的模型
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/reverse.hpp>

一致性

OGC 未定义 reverse 函数.

reverse 函数与 C++ 标准库的 std::reverse 函数保持一致.

行为

情况

行为

点

不发生任何事情, 几何对象保持不变

线段

本版本尚不支持

矩形框

不发生任何事情, 几何对象保持不变

Linestring

反转线串

Ring

反转环

多边形 (Polygon)

反转多边形的外环和所有内环

多点 (Multi Point)

不发生任何事情, 几何对象保持不变

多线串 (Multi Linestring)

逐个反转其中包含的线串

多多边形 (Multi Polygon)

逐个反转其中包含的多边形
注释

反转 (多) 多边形或环可能使原本有效的几何变得无效, 因为 (逆) 顺时针方向会反转.

示例

演示如何反转环或多边形

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/ring.hpp>
#include <boost/geometry/geometries/adapted/boost_tuple.hpp>

BOOST_GEOMETRY_REGISTER_BOOST_TUPLE_CS(cs::cartesian)

int main()
{
    using point = boost::tuple<int, int>;
    using polygon = boost::geometry::model::polygon<point>;
    using ring = boost::geometry::model::ring<point>;

    polygon poly;
    boost::geometry::exterior_ring(poly) = {{0, 0}, {0, 9}, {10, 10}, {0, 0}};
    boost::geometry::interior_rings(poly).push_back({{1, 2}, {4, 6}, {2, 8}, {1, 2}});

    double area_before = boost::geometry::area(poly);
    boost::geometry::reverse(poly);
    double area_after = boost::geometry::area(poly);
    std::cout << boost::geometry::dsv(poly) << std::endl;
    std::cout << area_before << " -> " << area_after << std::endl;

    ring r = {{0, 0}, {0, 9}, {8, 8}, {0, 0}};

    area_before = boost::geometry::area(r);
    boost::geometry::reverse(r);
    area_after = boost::geometry::area(r);
    std::cout << boost::geometry::dsv(r) << std::endl;
    std::cout << area_before << " -> " << area_after << std::endl;

    return 0;
}

输出:

(((0, 0), (10, 10), (0, 9), (0, 0)), ((1, 2), (2, 8), (4, 6), (1, 2)))
38 -> -38
((0, 0), (8, 8), (0, 9), (0, 0))
36 -> -36
