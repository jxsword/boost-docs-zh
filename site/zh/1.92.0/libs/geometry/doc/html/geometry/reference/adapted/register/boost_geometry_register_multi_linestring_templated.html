BOOST_GEOMETRY_REGISTER_MULTI_LINESTRING_TEMPLATED

注册模板化 multi_linestring 的宏.

说明

宏 BOOST_GEOMETRY_REGISTER_MULTI_LINESTRING_TEMPLATED 注册一个模板化 multi_linestring, 使其能被 Boost.Geometry 识别, 从而可以对指定类型使用 Boost.Geometry 功能. 该类型必须只有一个模板参数, 且该参数应为线串类型, 注册时不要指定它. Boost.Geometry 会自动插入该模板参数. 因此该模板化 multi_linestring 的所有类型都会被注册, 无论其点类型是什么.

概要 

#define BOOST_GEOMETRY_REGISTER_MULTI_LINESTRING_TEMPLATED(MultiLineString)

参数

名称

说明

MultiLineString

要注册的 multi_linestring 类型 (不带模板参数)
头文件

#include <boost/geometry/geometries/register/multi_linestring.hpp>

示例

[register_multi_linestring_templated] [register_multi_linestring_templated_output]
