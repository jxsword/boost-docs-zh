线段概念

说明

线段概念描述线段类型的要求. Boost.Geometry 中的所有算法都会依据概念要求检查几何参数.

概念定义
  • 必须存在 traits::tag 的特化, 将 segment_tag 定义为类型
  • 必须存在 traits::point_type 的特化以定义底层点类型 (即使它不由点构成, 也应定义该类型, 以表明它可以处理哪些点)
  • 必须存在 traits::indexed_access 的特化, 按索引和维度区分, 带有两个函数:
    • get 用于读取坐标值
    • set 用于设置坐标值 (对 ConstSegment 不检查此项)
注释

线段概念与矩形框概念类似, 使用另一个标签定义. 不过, 矩形框概念假定索引为 min_corner, max_corner, 而线段概念没有这种假定.

可用模型
  • model::segment
  • referring segment
