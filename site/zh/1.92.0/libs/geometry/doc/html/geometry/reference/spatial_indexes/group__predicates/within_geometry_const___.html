within(Geometry const &)

生成 within() 谓词.

说明

生成定义 Value 与 Geometry 关系的谓词. 使用该谓词, 查询返回位于所传入 Geometry 之内的被索引 Value. 若 bg::within(Indexable, Geometry) 返回 true, 则查询返回该 Value.

概要 
template<typename Geometry>
unspecified within(Geometry const & g)
模板参数

参数

说明

Geometry

Geometry 类型.
参数

类型

名称

说明

Geometry const &

g

Geometry 对象.
示例 

bgi::query(spatial_index, bgi::within(box), std::back_inserter(result));
