perimeter

计算几何对象的周长.

说明

函数 perimeter 使用默认距离计算策略返回几何对象的周长

概要 

template<typename Geometry>
default_length_result< Geometry >::type perimeter(Geometry const & geometry)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型
返回

计算得到的周长

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/perimeter.hpp>

一致性

OGC 未定义 perimeter 函数.

注释

PostGIS 含有同名且功能相同的算法. 参见 PostGIS documentation.

行为

情况

行为

点状 (如 point)

返回零

线状 (如 linestring)

返回零

面状 (如 polygon)

返回周长
复杂度

线性

示例

计算多边形的周长

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>

namespace bg = boost::geometry; 

int main()
{
    // Calculate the perimeter of a cartesian polygon
    bg::model::polygon<bg::model::d2::point_xy<double>> poly;
    bg::read_wkt("POLYGON((0 0,3 4,5 -5,-2 -4, 0 0))", poly);
    double perimeter = bg::perimeter(poly);
    std::cout << "Perimeter: " << perimeter << std::endl;

    return 0;
}

便捷的命名空间别名

输出:
