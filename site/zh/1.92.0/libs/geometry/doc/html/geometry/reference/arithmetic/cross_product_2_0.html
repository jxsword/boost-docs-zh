cross_product

计算两个向量的叉积.

说明

所有向量的维度应相同, 为 3 或 2.

概要 

template<typename ResultP, typename P1, typename P2, std::enable_if_t< dimension< ResultP >::value !=3||! traits::make< ResultP >::is_specialized, int >>
ResultP cross_product(P1 const & p1, P2 const & p2)
