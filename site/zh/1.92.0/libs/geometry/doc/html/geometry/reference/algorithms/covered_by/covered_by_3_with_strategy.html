covered_by (with strategy)

使用指定策略检查第一个几何对象是否在第二个几何对象内部或边界上.

说明

自由函数 covered_by 使用指定策略检查第一个几何对象是否在第二个几何对象内部或边界上. 指定策略的原因包括: 使用另一种坐标系进行计算; 预先构造策略 (例如传入地球半径); 当同一计算有多种策略可用时进行选择.

概要 

template<typename Geometry1, typename Geometry2, typename Strategy>
bool covered_by(Geometry1 const & geometry1, Geometry2 const & geometry2, Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型, 可能位于第二个几何对象内部或边界上

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型, 可能覆盖第一个几何对象

Strategy const &

strategy

要使用的策略
返回

若 geometry1 位于 geometry2 内部或边界上则为 true, 否则为 false

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/covered_by.hpp>

一致性

OGC 未定义 covered_by 函数.

注释

PostGIS 和 Oracle 都包含同名且功能相同的算法. 参见 PostGIS documentation.
