is_valid

检查几何对象是否有效 (按 OGC 意义)

概要 

template<typename Geometry>
bool is_valid(Geometry const & geometry)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型
返回

若几何对象有效 (按 OGC 意义) 则返回 true; 此外, 以下几何也被视为有效: 无元素的多几何、含有尖刺 (spike) 的线状几何、含有重复 (连续) 点的面状几何

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/is_valid.hpp>

一致性

OGC 未定义 is_valid 函数.

支持的几何类型

Geometry

状态

点

线段

矩形框

Linestring

Ring

多边形 (Polygon)

MultiPoint

MultiLinestring (多线串)

MultiPolygon

Variant

复杂度

点、线段、矩形框和多点为常数时间

线串和多线串为线性

环为线性对数

目前多边形和多多边形最坏情况为平方级

示例

检查几何对象是否有效

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>


int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type>;

    polygon_type poly;
    boost::geometry::read_wkt("POLYGON((0 0,0 10,10 10,10 0,0 0),(0 0,9 1,9 2,0 0),(0 0,2 9,1 9,0 0),(2 9,9 2,9 9,2 9))", poly);

    std::cout << "is valid? " << (boost::geometry::is_valid(poly) ? "yes" : "no") << std::endl;

    return 0;
}

输出:

is valid? no
