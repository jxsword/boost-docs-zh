simplify

简化几何对象.

概要 

template<typename Geometry, typename GeometryOut, typename Distance>
void simplify(Geometry const & geometry, GeometryOut & out, Distance const & max_distance)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

输入几何, 待简化

GeometryOut &

输出几何

out

输出几何, 输入几何的简化版本

Distance const &

数值类型 (int, double, ttmath 等)

max_distance

顶点与其他分段之间的距离 (以输入坐标为单位), 用于决定是否移除顶点
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/simplify.hpp>

一致性

OGC 未定义 simplify 函数.

注释

PostGIS 含有同名且功能相同的算法. 参见 PostGIS documentation.

注释

SQL Server 含有功能相同的 Reduce() 算法. 参见 MSDN documentation.

行为

简化使用 Douglas-Peucker 算法完成 (若使用默认策略).

注释

使用 simplify 可能使几何对象失效. 简化过程可能产生自相交.

示例

演示如何简化线串的示例

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/linestring.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

int main()
{
    using xy = boost::geometry::model::d2::point_xy<double>;

    const boost::geometry::model::linestring<xy> line
        {{1.1, 1.1}, {2.5, 2.1}, {3.1, 3.1}, {4.9, 1.1}, {3.1, 1.9}};

    // Simplify it, using distance of 0.5 units
    boost::geometry::model::linestring<xy> simplified;
    boost::geometry::simplify(line, simplified, 0.5);
    std::cout
        << "  original: " << boost::geometry::dsv(line) << std::endl
        << "simplified: " << boost::geometry::dsv(simplified) << std::endl;

    return 0;
}

输出:

original: ((1.1, 1.1), (2.5, 2.1), (3.1, 3.1), (4.9, 1.1), (3.1, 1.9))
simplified: ((1.1, 1.1), (3.1, 3.1), (4.9, 1.1), (3.1, 1.9))
