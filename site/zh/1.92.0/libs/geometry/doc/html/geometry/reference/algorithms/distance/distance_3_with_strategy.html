distance (with strategy)

使用指定策略计算两个几何对象之间的距离.

说明

自由函数 distance 使用指定策略计算两个几何对象之间的距离. 指定策略的原因包括: 使用另一种坐标系进行计算; 预先构造策略 (例如传入地球半径); 当同一计算有多种策略可用时进行选择.

概要 

template<typename Geometry1, typename Geometry2, typename Strategy>
auto distance(Geometry1 const & geometry1, Geometry2 const & geometry2, Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型

Strategy const &

任何满足距离策略概念 (Distance Strategy Concept) 的类型

strategy

用于距离计算的策略
返回

计算得到的距离

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/distance.hpp>

可用策略
  • Pythagoras (cartesian)
  • Haversine (spherical)
  • Cross track (spherical, point-to-segment)
  • Projected point (cartesian, point-to-segment)
  • 地理点到点策略之一
