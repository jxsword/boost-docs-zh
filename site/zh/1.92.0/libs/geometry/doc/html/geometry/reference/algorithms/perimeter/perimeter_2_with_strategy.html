perimeter (with strategy)

使用指定策略计算几何对象的周长.

说明

函数 perimeter 使用指定策略返回几何对象的周长

概要 

template<typename Geometry, typename Strategy>
default_length_result< Geometry >::type perimeter(Geometry const & geometry, Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

Strategy const &

任何满足距离策略概念 (distance Strategy Concept) 的类型

strategy

用于距离计算的策略.
返回

计算得到的周长

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/perimeter.hpp>

一致性

OGC 未定义 perimeter 函数.

注释

PostGIS 含有同名且功能相同的算法. 参见 PostGIS documentation.

行为

情况

行为

点状 (如 point)

返回零

线状 (如 linestring)

返回零

面状 (如 polygon)

返回周长
复杂度

线性
