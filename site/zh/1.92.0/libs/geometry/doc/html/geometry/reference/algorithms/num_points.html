num_points

计算几何对象的点数.

说明

自由函数 num_points 计算几何对象的点数.

概要 

template<typename Geometry>
std::size_t num_points(Geometry const & geometry, bool add_for_open = false)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

bool

add_for_open

对未闭合几何 (即未闭合的多边形类型) 加 1
返回

计算得到的点数

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/num_points.hpp>

一致性

函数 num_points 实现了 OGC Simple Feature Specification 中的 NumPoints 函数.

注释

num_points 可用于任何几何对象, 而不只是标准所述的线串

行为

情况

行为

点

返回 1

线段

返回 2

矩形框

返回 2^d, 其中 d 是矩形框的维度

类范围 (linestring, ring)

返回 boost::size(geometry)

其他几何类型

返回其元素点数之和

开放几何

返回其元素点数之和, 若指定则对开放的 (每个环) 加 1

闭合几何

返回其元素点数之和
复杂度

常数或线性

示例

获取几何对象中的点数

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/multi_polygon.hpp>


int main()
{
    boost::geometry::model::multi_polygon
        <
            boost::geometry::model::polygon
                <
                    boost::geometry::model::d2::point_xy<double>
                >
        > mp;
    boost::geometry::read_wkt("MULTIPOLYGON(((0 0,0 10,10 0,0 0),(1 1,1 9,9 1,1 1)),((10 10,10 7,7 10,10 10)))", mp);
    std::cout << "Number of points: " << boost::geometry::num_points(mp) << std::endl;

    return 0;
}

输出:

Number of points: 12
