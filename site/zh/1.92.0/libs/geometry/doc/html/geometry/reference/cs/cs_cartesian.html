cs::cartesian

笛卡尔坐标系.

说明

定义笛卡尔 (直角) 坐标系, 点在二维或三维 (或更多维) 中定义, 通常 (但不总是) 记为 x,y,z

概要 

struct cs::cartesian
{
  // ...
};

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/cs.hpp>
