densify

加密几何对象.

概要 

template<typename Geometry, typename Distance>
void densify(Geometry const & geometry, Geometry & out, Distance const & max_distance)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

输入几何, 待加密

Geometry &

任何满足几何概念 (Geometry Concept) 的类型

out

输出几何, 输入几何的加密版本

Distance const &

数值距离度量

max_distance

距离阈值 (单位取决于坐标系)
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/densify.hpp>

一致性

OGC 未定义 densify 函数.

注释

PostGIS 含有功能相同的 ST_Segmentize 算法. 参见 PostGIS documentation.

行为

该算法将几何对象中长度超过给定距离的分段切分为更小的分段.

注释

距离的单位取决于策略. 若要改变默认行为, 用户必须创建一个策略并显式传入算法.

示例

演示如何加密多边形

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>

int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type>;

    polygon_type poly;
    boost::geometry::read_wkt(
        "POLYGON((0 0,0 10,10 10,10 0,0 0),(1 1,4 1,4 4,1 4,1 1))", poly);

    polygon_type res;

    boost::geometry::densify(poly, res, 6.0);

    std::cout << "densified: " << boost::geometry::wkt(res) << std::endl;

    return 0;
}

输出:

densified: POLYGON((0 0,0 5,0 10,5 10,10 10,10 5,10 0,5 0,0 0),(1 1,4 1,4 4,1 4,1 1))
