set (with index)

设置矩形框 / 线段的坐标值

说明

自由函数 get 和 set 是 Boost.Geometry 最重要的两个函数, 无论对库内部还是对库用户都是如此. 通常用这两个函数从点、矩形框、线段或球体读取以及设置坐标值.

概要 

template<std::size_t Index, std::size_t Dimension, typename Geometry>
void set(Geometry & geometry, coordinate_type_t< Geometry > const & value)

参数

类型

概念

名称

说明

索引

Index, 该模板参数必需. 对矩形框: 取 min_corner 或 max_corner. 对线段: 取 0 或 1 表示首点或末点.

-

必须指定

Dimension

Dimension, 该模板参数必需. 对于 n 维几何应取 [0 .. n-1]

-

必须指定

Geometry &

任何满足矩形框概念 (Box Concept) 或线段概念 (Segment Concept) 的类型

geometry

所指定概念的一个模型

coordinate_type_t< Geometry > const &

value

要设置的坐标值
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/access.hpp>

行为

情况

行为

矩形框

设置矩形框的坐标 (用 min_corner, max_corner 指定设置哪个点)

线段

设置线段的坐标 (用 0, 1 指定设置两个点中的哪一个)
复杂度

常量时间

示例

设置矩形框的坐标

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

namespace bg = boost::geometry;

int main()
{
    bg::model::box<bg::model::d2::point_xy<double>> box;

    bg::set<bg::min_corner, 0>(box, 0);
    bg::set<bg::min_corner, 1>(box, 2);
    bg::set<bg::max_corner, 0>(box, 4);
    bg::set<bg::max_corner, 1>(box, 5);

    std::cout << "Extent: " << bg::dsv(box) << std::endl;

    return 0;
}

输出:

Extent: ((0, 2), (4, 5))
