relate

检查由掩码 (mask) 定义的一对几何对象之间的关系.

概要 

template<typename Geometry1, typename Geometry2, typename Mask>
bool relate(Geometry1 const & geometry1, Geometry2 const & geometry2, Mask const & mask)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型

Mask const &

交集模型 Mask 类型.

mask

交集模型掩码对象.
返回

若关系与掩码相容则为 true, 否则为 false.

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/relate.hpp>

一致性

函数 relate 实现了 OGC Simple Feature Specification 中的 Relate 函数.

示例

演示如何检测点是否在多边形内

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>


int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using polygon_type = boost::geometry::model::polygon<point_type>;

    polygon_type poly;
    boost::geometry::read_wkt(
        "POLYGON((2 1.3,2.4 1.7,2.8 1.8,3.4 1.2,3.7 1.6,3.4 2,4.1 3,5.3 2.6,5.4 1.2,4.9 0.8,2.9 0.7,2 1.3)"
            "(4.0 2.0, 4.2 1.4, 4.8 1.9, 4.4 2.2, 4.0 2.0))", poly);

    point_type p(4, 1);

    boost::geometry::de9im::mask mask("T*F**F***"); // within
    bool check = boost::geometry::relate(p, poly, mask);

    std::cout << "relate: " << (check ? "yes" : "no") << std::endl;

    return 0;
}

输出:

relate: yes
