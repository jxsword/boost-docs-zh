return_envelope (with strategy)

计算几何对象的包络.

说明

自由函数 return_envelope 计算几何对象的包络 (envelope, 也称轴对齐包围盒 aabb 或最小包围矩形 mbr). 这个带 return_ 前缀的版本返回包络, 因此调用时必须指定一个模板参数.

概要 

template<typename Box, typename Geometry, typename Strategy>
Box return_envelope(Geometry const & geometry, Strategy const & strategy)

参数

类型

概念

名称

说明

矩形框

任何满足矩形框概念 (Box Concept) 的类型

-

必须指定

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

Strategy const &

任何满足包络策略概念 (Envelope Strategy Concept) 的类型

strategy

用于包络计算的策略
返回

计算得到的包络

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/envelope.hpp>

一致性

函数 envelope 实现了 OGC Simple Feature Specification 中的 Envelope 函数.

示例

演示如何返回环的包络

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/box.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/ring.hpp>



int main()
{
    using point = boost::geometry::model::d2::point_xy<double>;
    using box = boost::geometry::model::box<point>;

    const boost::geometry::model::ring<point> ring {
        {4.0, -0.5}, {3.5, 1.0}, {2.0, 1.5}, {3.5, 2.0},
        {4.0, 3.5}, {4.5, 2.0}, {6.0, 1.5}, {4.5, 1.0},
        {4.0, -0.5}
    };

    std::cout
        << "return_envelope:"
        << boost::geometry::dsv(boost::geometry::return_envelope<box>(ring))
        << std::endl;


    return 0;
}

输出:

return_envelope:((2, -0.5), (6, 3.5))
