return_centroid (with strategy)

使用指定策略计算几何对象的质心.

说明

自由函数 centroid 计算几何对象的几何中心 (即质心). 这个带 return_ 前缀的版本返回质心, 因此调用时必须指定一个模板参数. 指定策略的原因包括: 使用另一种坐标系进行计算; 预先构造策略 (例如传入地球半径); 当同一计算有多种策略可用时进行选择.

概要 

template<typename Point, typename Geometry, typename Strategy>
Point return_centroid(Geometry const & geometry, Strategy const & strategy)
