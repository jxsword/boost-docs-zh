expand (with strategy)

扩大 (使用策略)

概要 

template<typename Box, typename Geometry, typename Strategy>
void expand(Box & box, Geometry const & geometry, Strategy const & strategy)

参数

类型

概念

名称

说明

Box &

矩形框的类型

box

要用另一个几何对象扩大的矩形框, 可修改

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定几何概念的一个模型, 其包络 (包围框)

Strategy const &

任何满足 expand 策略概念 (expand Strategy Concept) 的类型

strategy

用于 expand 计算的策略将被加入矩形框
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/expand.hpp>

一致性

OGC 未定义 expand 函数.

行为

情况

行为

Box / Point

矩形框被扩大以包含指定点

Box / Box

矩形框被扩大以包含指定矩形框

矩形框 / 其他几何类型

本版本尚不支持
注释

若要将 expand 用于指定之外的其他几何类型, 请使用 expand(make_envelope<box_type>(geometry)

复杂度

线性

示例

演示 expand 的用法

#include <iostream>
#include <list>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/box.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

int main()
{
    using point_type = boost::geometry::model::d2::point_xy<short int>;
    using box_type = boost::geometry::model::box<point_type>;

    using boost::geometry::expand;

    box_type box = boost::geometry::make_inverse<box_type>(); 

    expand(box, point_type(0, 0));
    expand(box, point_type(1, 2));
    expand(box, point_type(5, 4));
    expand(box, boost::geometry::make<box_type>(3, 3, 5, 5));

    std::cout << boost::geometry::dsv(box) << std::endl;

    return 0;
}

expand 之前通常先调用 assign_inverse 或 make_inverse

输出:

((0, 0), (5, 5))
