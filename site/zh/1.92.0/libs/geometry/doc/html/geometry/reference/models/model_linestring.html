model::linestring

线串 (由 OGC 如此命名) 是点的集合 (默认为 vector) .

所属模型

Linestring 概念

概要 

template<typename Point, template< typename, typename > class Container, template< typename > class Allocator>
class model::linestring
      : public std::vector< Point, std::allocator< Point > >
{
  // ...
};

模板参数

参数

默认值

说明

typename Point

任何满足点概念 (Point Concept) 的类型

template< typename, typename > class Container

std::vector

容器类型, 例如 std::vector、std::deque

template< typename > class Allocator

std::allocator

container-allocator-type

头文件

其一

#include <boost/geometry/geometries/geometries.hpp>

或

#include <boost/geometry/geometries/linestring.hpp>

示例

声明并使用 Boost.Geometry 的 model::linestring, 以模拟 Linestring 概念

#include <iostream>
#include <boost/geometry.hpp>
#include <boost/geometry/geometries/geometries.hpp>

namespace bg = boost::geometry;

int main()
{
    using point_t = bg::model::point<double, 2, bg::cs::cartesian>;
    using linestring_t = bg::model::linestring<point_t>;

    linestring_t ls1; 
    linestring_t ls2{{0.0, 0.0}, {1.0, 0.0}, {1.0, 2.0}}; 

    bg::append(ls1, point_t(0.0, 0.0)); 
    bg::append(ls1, point_t(1.0, 0.0));
    bg::append(ls1, point_t(1.0, 2.0));

    double l = bg::length(ls1);

    std::cout << l << std::endl;

    return 0;
}
