查询

查询返回满足某些谓词的 Value. 目前支持三种类型的谓词:

  • 空间谓词——存储的 Value 与某个 Geometry 必须满足的空间条件,
  • 距离谓词——存储的 Value 与某个 Geometry 必须满足的距离条件,
  • 用户定义的一元谓词——检查用户定义条件的函数、函数对象或 lambda 表达式.

例如, 查询可用于检索 Value:

  • 与某个区域相交但不在另一个区域之内,
  • 距某个点最近,
  • 与某个矩形框重叠且具有用户定义的属性.
执行查询

执行查询有多种方式, 如下所示. 所有方式都返回 Value, 它们与某个以 Box 定义的区域相交.

成员函数调用

std::vector<Value> returned_values;
Box box_region(...);
rt.query(bgi::intersects(box_region), std::back_inserter(returned_values));

自由函数调用

std::vector<Value> returned_values;
Box box_region(...);
bgi::query(rt, bgi::intersects(box_region), std::back_inserter(returned_values));

由 operator| 生成的范围

Box box_region(...);
BOOST_FOREACH(Value & v, rt | bgi::adaptors::queried(bgi::intersects(box_region)))
  ; // do something with v

由成员函数返回的查询迭代器

std::vector<Value> returned_values;
Box box_region(...);
std::copy(rt.qbegin(bgi::intersects(box_region)), rt.qend(), std::back_inserter(returned_values));

由自由函数返回的查询迭代器

std::vector<Value> returned_values;
Box box_region(...);
std::copy(bgi::qbegin(rt, bgi::intersects(box_region)), bgi::qend(rt), std::back_inserter(returned_values));
空间查询

使用空间谓词的查询返回与某个 Geometry (矩形框、多边形等) 以某种方式相关的 Value. 空间谓词的名称与 Boost.Geometry 算法 (布尔运算) 的名称对应. 下表中可以找到一些基本查询的示例. 查询区域与结果 Value 以橙色显示.

intersects(Box)

covered_by(Box)

disjoint(Box)

overlaps(Box)

within(Box)

intersects(Segment)

intersects(Box)

disjoint(Box)

intersects(Box)

disjoint(Box)

空间谓词由定义在 boost::geometry::index 命名空间中的函数生成.

rt.query(index::contains(box), std::back_inserter(result));
rt.query(index::covered_by(box), std::back_inserter(result));
rt.query(index::covers(box), std::back_inserter(result));
rt.query(index::disjont(box), std::back_inserter(result));
rt.query(index::intersects(box), std::back_inserter(result));
rt.query(index::overlaps(box), std::back_inserter(result));
rt.query(index::within(box), std::back_inserter(result));

所有空间谓词都可以取反, 例如:

rt.query(!index::intersects(box), std::back_inserter(result));
// the same as
rt.query(index::disjoint(box), std::back_inserter(result));
最近邻查询

最近邻查询返回距某个 Geometry 最近的 Value. 下面给出 k-NN 查询的示例. 距该 Geometry 最近的 5 个 Value 以橙色显示.

nearest(Point, k)

nearest(Box, k)

nearest(Point, k)

nearest(Box, k)

nearest(Segment, k)

nearest(Point, k)

nearest(Box, k)

nearest(Segment, k)

nearest(Segment, k)

要执行 knn 查询, 必须传入最近邻谓词, 该谓词由 nearest() 函数生成, 该函数定义于 boost::geometry::index 命名空间. 对于非点 Indexable, 最短距离使用 bg::comparable_distance() 函数计算. 以下查询返回空间中距某个 Point 最近的 k 个 Value.

std::vector<Value> returned_values;
Point pt(/*...*/);
rt.query(bgi::nearest(pt, k), std::back_inserter(returned_values));

以同样的方式可以使用不同的查询几何对象:

Box box(/*...*/);
rt.query(bgi::nearest(box, k), std::back_inserter(returned_values));

Segment seg(/*...*/);
rt.query(bgi::nearest(seg, k), std::back_inserter(returned_values));
注释

使用 query() 函数执行 k-NN 查询时, 不保证返回的值按距离排序. 而使用 qbegin() 函数返回的查询迭代器执行 k-NN 查询时则不同, 它保证最先迭代最近的 Value.

用户定义的一元谓词

用户可以传入 UnaryPredicate——接收 Value 的 const 引用并返回 bool 的函数、函数对象或 lambda 表达式. 可以将该对象传入查询, 以检查 Value 是否应被查询返回. 为此, 可以使用如下示例中的 index::satisfies() 函数:

bool is_red(Value const& v)
{
  return v.is_red();
}

struct is_red_o
{
  template <typename Value>
  bool operator()(Value const& v)
  {
    return v.is_red();
  }
}

// ...

rt.query(index::intersects(box) && index::satisfies(is_red),
         std::back_inserter(result));

rt.query(index::intersects(box) && index::satisfies(is_red_o()),
         std::back_inserter(result));

rt.query(index::intersects(box) && index::satisfies([](Value const& v) { return v.is_red(); }),
         std::back_inserter(result));

satisfies() 可以取反, 例如:

bool is_red(Value const& v) { return v.is_red(); }
bool is_not_red(Value const& v) { return !v.is_red(); }

// ...

rt.query(index::intersects(box) && index::satisfies(is_red),
         std::back_inserter(result));
// the same as
rt.query(index::intersects(box) && !index::satisfies(is_not_red),
         std::back_inserter(result));
传入谓词集合

可以在一个查询中使用若干谓词, 方法是用 operator&& 将它们连接起来, 例如 Pred1 && Pred2 && Pred3 && ....

这些谓词通过逻辑 AND 连接. 将所有谓词一起传入不仅可以构造高级查询, 而且比分开调用更快, 因为树只被遍历一次. 只有当所有谓词都满足时才继续遍历并返回 Value. 谓词按从左到右的顺序检查, 因此把限制性最强的谓词放在前面应能加速搜索.

rt.query(index::intersects(box1) && !index::within(box2),
         std::back_inserter(result));

rt.query(index::intersects(box1) && !index::within(box2) && index::overlaps(box3),
         std::back_inserter(result));

可以将不同类型的谓词连接在一起.

index::query(rt, index::nearest(pt, k) && index::within(b), std::back_inserter(returned_values));

BOOST_FOREACH(Value & v, rt | index::adaptors::queried(index::nearest(pt, k) && index::covered_by(b)))
  ; // do something with v
迭代式查询

使用查询迭代器执行的查询可以在需要时暂停并恢复, 例如查询耗时过长时; 也可以在收集到所有感兴趣的值后随时停止. 查询迭代器由 qbegin() 成员函数返回, 该函数与 query() 成员函数一样需要传入谓词.

for ( Rtree::const_query_iterator it = tree.qbegin(bgi::nearest(pt, 10000)) ;
      it != tree.qend() ; ++it )
{
    // do something with value
    if ( has_enough_nearest_values() )
        break;
}
警告

对 rtree 的修改 (例如插入或移除 Value) 可能使迭代器失效.

将查询结果插入另一个 R-tree

将查询返回的 Value 插入另一个 R-tree 容器有多种方式. 最基本的方式是为 Value 创建一个临时容器, 之后再插入.

namespace bgi = boost::geometry::index;
typedef std::pair<Box, int> Value;
typedef bgi::rtree< Value, bgi::linear<32, 8> > RTree;

RTree rt1;
/* some inserting into the tree */

std::vector<Value> result;
rt1.query(bgi::intersects(Box(/*...*/)), std::back_inserter(result));
RTree rt2(result.begin(), result.end());

不过还有其他方式. 其中一种方法在“创建与修改”一节中提到过. 插入迭代器可以直接传入查询.

RTree rt3;
rt1.query(bgi::intersects(Box(/*...*/))), bgi::inserter(rt3));

也可以使用 Boost.Range 适配器语法将结果范围直接传入构造函数或 insert() 成员函数.

RTree rt4(rt1 | bgi::adaptors::queried(bgi::intersects(Box(/*...*/)))));
