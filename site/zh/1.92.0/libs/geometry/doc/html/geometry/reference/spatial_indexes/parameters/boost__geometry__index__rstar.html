boost::geometry::index::rstar

R*-tree 创建算法参数.

头文件

#include <boost/geometry/index/parameters.hpp>

概要 
template<size_t MaxElements,
         size_t MinElements = default,
         size_t ReinsertedElements = default,
         size_t OverlapCostThreshold = 32>
struct rstar
{
  // ...
};
模板参数

参数

说明

size_t MaxElements

节点中元素的最大数量.

size_t MinElements

节点中元素的最小数量. 默认: 0.3*Max.

size_t ReinsertedElements

由强制重插入算法重新插入的元素数量. 若为 0 则禁用强制重插入. 最大值为 Max+1-Min, 更大的值会被截断. 默认: 0.3*Max.

size_t OverlapCostThreshold

选择将当前插入的值加入哪个叶节点时, 纳入考虑的最合适叶子的数量. 若该值在 (0, MaxElements) 范围内, 算法计算近似最小重叠代价; 否则分析所有叶子并计算真正的最小重叠代价. 默认: 32.
