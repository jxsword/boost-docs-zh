model::referring_segment

类 segment: 包含两个 (模板化的) 点引用的小型类.

说明

引自 Wikipedia: 在几何学中, 线段是直线上由两个不同端点所界定的部分, 包含其端点之间直线上的每个点.

概要 

template<typename ConstOrNonConstPoint>
class model::referring_segment
{
  // ...
};

模板参数

参数

说明

typename ConstOrNonConstPoint

线段的点类型, 可以是 point 或 const point
构造函数

函数

说明

参数

 

referring_segment(point_type & p1, point_type & p2)

接收第一个点与第二个点的构造函数.

point_type &: p1:

point_type &: p2:
