model::ring

环 (又称线性环) 是不应自相交的闭合线.

所属模型

环概念

概要 

template<typename Point, bool ClockWise, bool Closed, template< typename, typename > class Container,
         template< typename > class Allocator>
class model::ring
      : public std::vector< Point, std::allocator< Point > >
{
  // ...
};

模板参数

参数

默认值

说明

typename Point

点类型

bool ClockWise

true

true 表示顺时针方向, false 表示逆时针方向

bool Closed

true

true 表示闭合多边形 (最后一个点等于第一个点) , false 表示开放点序列

template< typename, typename > class Container

std::vector

容器类型, 例如 std::vector、std::deque

template< typename > class Allocator

std::allocator

container-allocator-type

示例

声明并使用 Boost.Geometry 的 model::ring, 以模拟 Ring 概念

#include <iostream>
#include <boost/geometry.hpp>
#include <boost/geometry/geometries/geometries.hpp>

namespace bg = boost::geometry;

int main()
{
    using point_t = bg::model::point<double, 2, bg::cs::cartesian>;
    using ring_t = bg::model::ring<point_t>; 

    ring_t ring1; 
    ring_t ring2{{0.0, 0.0}, {0.0, 5.0}, {5.0, 5.0}, {5.0, 0.0}, {0.0, 0.0}}; 

    bg::append(ring1, point_t(0.0, 0.0)); 
    bg::append(ring1, point_t(0.0, 5.0));
    bg::append(ring1, point_t(5.0, 5.0));
    bg::append(ring1, point_t(5.0, 0.0));
    bg::append(ring1, point_t(0.0, 0.0));

    double a = bg::area(ring1);

    std::cout << a << std::endl;

    return 0;
}

默认参数: 顺时针、闭合的环.
