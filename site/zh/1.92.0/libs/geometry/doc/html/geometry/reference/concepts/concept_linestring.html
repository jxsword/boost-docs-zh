线串概念

说明

线串概念描述线串类型的要求. Boost.Geometry 中的所有算法都会依据概念要求检查几何参数.

线串是 点之间带线性插值的曲线. (OGC Simple Feature Specification)

概念定义

线串概念定义如下:

  • 必须存在 traits::tag 的特化, 将 linestring_tag 定义为类型
  • 其行为必须类似 Boost.Range 随机访问范围
  • 元函数 range_value<...>::type 定义的类型必须满足 点概念
规则

除了编译期检查的概念之外, 有效线串还必须满足一些规则. 大多数算法可用于任何线串, 无论是否自交. 但是, 对于使用叠加算法 (intersection 与 difference 算法结合多边形) 得到正确结果而言, 自相交会干扰处理并导致错误结果.

可用模型
  • model::linestring
  • std::vector (需要注册)
  • std::deque (需要注册)
注释

另请参见 Boost.Range documentation 中的示例, 展示如何将类型适配为 Boost.Range 以满足线串概念
