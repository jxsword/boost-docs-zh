discrete_frechet_distance (with strategy)

使用指定策略计算两个几何对象之间的离散 Frechet 距离.

说明

自由函数 discrete_frechet_distance 计算两个几何对象之间的离散 Frechet 距离.

概要 

template<typename Geometry1, typename Geometry2, typename Strategy>
auto discrete_frechet_distance(Geometry1 const & geometry1, Geometry2 const & geometry2, Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry1 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry1

所指定概念的一个模型

Geometry2 const &

任何满足几何概念 (Geometry Concept) 的类型

geometry2

所指定概念的一个模型

Strategy const &

任何满足距离策略概念 (Distance Strategy Concept) 的类型

strategy

用于点到点距离计算的策略
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/discrete_frechet_distance.hpp>

一致性

OGC 未定义 discrete_frechet_distance 函数.

注释

PostGIS 含有功能类似的 ST_FrechetDistance 算法. 参见 PostGIS documentation.

支持的几何类型

几何类型

状态

Linestring-Linestring

注释

距离的单位取决于策略. 若要改变默认行为, 用户必须创建一个策略并显式传入算法.

可用策略
  • Pythagoras (cartesian)
  • Haversine (spherical)
  • 地理点到点策略之一
示例

以两个几何对象之间的离散 Frechet 距离作为二者的相似度.

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point.hpp>
#include <boost/geometry/geometries/linestring.hpp>

int main()
{
    namespace bg = boost::geometry;
    using point_type = bg::model::point<double, 2, bg::cs::geographic<bg::degree>>;
    using linestring_type = bg::model::linestring<point_type>;

    linestring_type ls1, ls2;
    bg::read_wkt("LINESTRING(0 0,1 1,1 2,2 1,2 2)", ls1);
    bg::read_wkt("LINESTRING(1 0,0 1,1 1,2 1,3 1)", ls2);

    bg::srs::spheroid<double> spheroid(6378137.0, 6356752.3142451793);
    bg::strategy::distance::geographic<> strategy(spheroid);

    double res = bg::discrete_frechet_distance(ls1, ls2, strategy);

    std::cout << "Discrete Frechet Distance: " << res << std::endl;

    return 0;
}

输出:

Discrete Frechet Distance: 156874
