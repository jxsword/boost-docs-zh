simplify (with strategy)

使用指定策略简化几何对象.

概要 

template<typename Geometry, typename GeometryOut, typename Distance, typename Strategy>
void simplify(Geometry const & geometry, GeometryOut & out, Distance const & max_distance,
              Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

输入几何, 待简化

GeometryOut &

输出几何

out

输出几何, 输入几何的简化版本

Distance const &

数值距离度量

max_distance

顶点与其他分段之间的距离 (以输入坐标为单位), 用于决定是否移除顶点

Strategy const &

满足 SimplifyStrategy 概念的类型

strategy

用于简化的 simplify 策略
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/simplify.hpp>
