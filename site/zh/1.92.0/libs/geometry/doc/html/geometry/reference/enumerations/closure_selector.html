closure_selector

枚举定义多边形开放或闭合的选项.

说明

枚举 closure_selector 描述多边形开放或闭合的选项. 在闭合多边形中, (每个环的) 第一个点应等于最后一个点. 多边形类型的特定闭合属性由 closure 元函数定义. closure 元函数定义一个值, 该值是 closure_selector 中枚举的值之一

概要 

enum closure_selector {open = 0, closed = 1, closure_undetermined = -1};

取值

值

说明

open

环是开放的: 第一个点与最后一个点不同, 算法在处理时显式闭合它们

closed

环是闭合的: 第一个点与最后一个点必须相同.

closure_undetermined

(尚未实现): 算法在处理时先判断环是否需要闭合
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/closure.hpp>
