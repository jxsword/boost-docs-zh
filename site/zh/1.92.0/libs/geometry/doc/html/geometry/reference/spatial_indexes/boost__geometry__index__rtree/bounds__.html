bounds()

返回能够容纳容器中所有值的 box.

说明

返回能够容纳容器中所有值的 box. 若容器为空, 则返回 geometry::assign_inverse() 的结果.

概要 
bounds_type bounds()
修改器 

const

返回

能够容纳容器中所有值的 box; 若容器中没有值, 则返回无效的 box.

抛出

无.
