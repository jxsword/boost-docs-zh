is_simple (with strategy)

检查几何对象是否简单 (simple).

概要 

template<typename Geometry, typename Strategy>
bool is_simple(Geometry const & geometry, Strategy const & strategy)

参数

类型

概念

名称

说明

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

Strategy const &

任何满足 is_simple 策略概念 (Is_simple Strategy Concept) 的类型

strategy

用于 is_simple 计算的策略
返回

若几何对象是简单的则返回 true

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/is_simple.hpp>

一致性

函数 is_simple 实现了 OGC Simple Feature Specification 中的 IsSimple 函数.

支持的几何类型

Geometry

状态

点

线段

矩形框

Linestring

Ring

多边形 (Polygon)

MultiPoint

MultiLinestring (多线串)

MultiPolygon

Variant

复杂度

点、线段和矩形框为常数时间

环、多边形和多多边形为线性

多点、线串和多线串为线性对数

示例

检查几何对象是否简单

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/linestring.hpp>
#include <boost/geometry/geometries/multi_linestring.hpp>


int main()
{
    using point_type = boost::geometry::model::d2::point_xy<double>;
    using linestring_type = boost::geometry::model::linestring<point_type>;
    using multi_linestring_type = boost::geometry::model::multi_linestring<linestring_type>;

    multi_linestring_type multi_linestring;
    boost::geometry::read_wkt("MULTILINESTRING((0 0,0 10,10 10,10 0,0 0),(10 10,20 20))", multi_linestring);

    std::cout << "is simple? "
              << (boost::geometry::is_simple(multi_linestring) ? "yes" : "no")
              << std::endl;

    return 0;
}

输出:

is simple? no
