快速入门

本快速入门一节以带注释、相对简单的代码片段形式展示 Boost.Geometry 的一些特性.

如需较长的独立教程式程序, 请参见仓库的 example/ 目录; 手册各处使用的较小参考型片段请参见 doc/src/examples/.

下面的代码假定已包含 boost/geometry.hpp, 并使用 namespace boost::geometry. Boost.Geometry 是仅头文件库, 因此只需包含头文件即可, 无需与任何库链接.

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>
#include <boost/geometry/geometries/polygon.hpp>

using namespace boost::geometry;

笛卡尔

可以只使用库的一小部分. 例如: 两点间距离是一个常见用例. Boost.Geometry 可以基于各种类型计算它. 使用库自带类型之一:

model::d2::point_xy<int> p1(1, 1), p2(2, 2);
std::cout << "Distance p1-p2 is: " << distance(p1, p2) << std::endl;

如果包含了正确的头文件并且类型绑定到某个坐标系, 各种其他类型都可以用作点: 普通 C 数组、Boost.Array、Boost.Tuple、Boost.Fusion 导入的结构体、你自己的类...

注册并使用 C 数组:

#include <boost/geometry/geometries/adapted/c_array.hpp>

BOOST_GEOMETRY_REGISTER_C_ARRAY_CS(cs::cartesian)


int a[2] = {1,1};
int b[2] = {2,3};
double d = distance(a, b);
std::cout << "Distance a-b is: " << d << std::endl;

另一个常用算法是点在多边形内判断 (point-in-polygon). 它在 Boost.Geometry 中的实现名为 within. 这里演示其用法: 检查一个 Boost.Tuple (作为点) 是否位于一个多边形内, 该多边形由 C 数组点对填充.

但首先必须像 C 数组那样注册 Boost.Tuple:

#include <boost/geometry/geometries/adapted/boost_tuple.hpp>

BOOST_GEOMETRY_REGISTER_BOOST_TUPLE_CS(cs::cartesian)


double points[][2] = {{2.0, 1.3}, {4.1, 3.0}, {5.3, 2.6}, {2.9, 0.7}, {2.0, 1.3}};
model::polygon<model::d2::point_xy<double>> poly;
append(poly, points);
boost::tuple<double, double> p = boost::make_tuple(3.7, 2.0);
std::cout << "Point p is in polygon? " << std::boolalpha << within(p, poly) << std::endl;

我们可以计算多边形的面积:

std::cout << "Area: " << area(poly) << std::endl;

由于这是模板库, 可以混用点类型. 我们再次计算距离, 这次使用一个 C 数组点和一个 Boost.Tuple 点:

double d2 = distance(a, p);
std::cout << "Distance a-p is: " << d2 << std::endl;

上面列出的代码片段生成如下输出:

Distance p1-p2 is: 1.41421
Distance a-b is: 2.23607
Point p is in polygon? true
Area: 3.015
Distance a-p is: 2.87924

非笛卡尔

也可以使用非笛卡尔点, 例如球面上的点. 此时若使用 distance 之类的算法, 库会“检查”出所处理的是球面点, 并沿球面计算距离, 而不是套用毕达哥拉斯定理.

注释

Boost.Geometry 支持地理坐标系, 但它在扩展 (extension) 中, 未随当前 Boost 发布版发布.

我们把地球近似为球体, 计算阿姆斯特丹与巴黎之间的距离:

using spherical_point = boost::geometry::model::point
    <
        double, 2, boost::geometry::cs::spherical_equatorial<boost::geometry::degree>
    >;

spherical_point amsterdam(4.90, 52.37);
spherical_point paris(2.35, 48.86);

double const earth_radius = 3959; // miles
std::cout << "Distance in miles: " << distance(amsterdam, paris) * earth_radius << std::endl;

输出为:

Distance in miles: 267.02

适配的结构体

最后是一个完全不同领域的例子: 开发基于窗口的应用程序, 例如使用 QtWidgets. 一旦 Qt 类在 Boost.Geometry 中注册, 我们就可以使用它们. 例如, 可以检查两个矩形是否重叠, 若重叠则把第二个移到别处:

QRect r1(100, 200, 15, 15);
QRect r2(110, 210, 20, 20);
if (overlaps(r1, r2))
{
    assign_values(r2, 200, 300, 220, 320);
}
