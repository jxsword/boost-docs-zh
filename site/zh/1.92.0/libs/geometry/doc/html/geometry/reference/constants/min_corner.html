min_corner

表示要读取、设置或处理的矩形框的最小角点 (左下)

概要 

int const min_corner = 0;

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/access.hpp>

注释

min_corner 与 max_corner 仅适用于矩形框, 不适用于例如线段

注释

min_corner 应是矩形框的最小角点, 但这一点并无保证. 使用 correct 可使 min_corner 成为最小角点. max_corner 同理.

示例

获取矩形框的坐标

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

namespace bg = boost::geometry;

int main()
{
    bg::model::box<bg::model::d2::point_xy<double>> box;

    bg::assign_values(box, 1, 3, 5, 6);

    std::cout << "Box:"
        << " " << bg::get<bg::min_corner, 0>(box)
        << " " << bg::get<bg::min_corner, 1>(box)
        << " " << bg::get<bg::max_corner, 0>(box)
        << " " << bg::get<bg::max_corner, 1>(box)
        << std::endl;

    return 0;
}

输出:

Box: 1 3 5 6
