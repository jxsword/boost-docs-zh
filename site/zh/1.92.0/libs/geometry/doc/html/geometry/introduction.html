引言

Boost.Geometry (aka Generic Geometry Library, GGL) 是 Boost C++ 库集合的一部分, 为求解几何问题定义了概念、基元与算法.

Boost.Geometry 包含一个维度无关、坐标系无关且可扩展的内核, 基于概念、元函数与标签分派构建. 在该内核之上构建了众多算法: 面积 (area)、长度 (length)、周长 (perimeter)、质心 (centroid)、凸包 (convex hull)、交集/相交 (intersection, 即裁剪)、within (点在多边形内判断)、距离 (distance)、包络 (envelope, 即包围盒)、简化 (simplify)、变换 (transform) 等等. 该库支持高精度算术数, 例如 ttmath.

Boost.Geometry 包含可实例化的几何类, 但库用户也可以使用自己的类型. 借助注册宏或特征类, 用户的几何类型可以适配为满足 Boost.Geometry 概念.

凡是几何发挥作用的领域都可以使用 Boost.Geometry: 制图与 GIS、游戏开发、计算机图形学与界面组件、机器人学、天文学等等. 其核心设计得尽可能通用, 以支持这些领域. 不过目前的开发主要面向 GIS.

该库遵循既有惯例:

  • boost 的惯例
  • std 库的惯例
  • 几何领域 OGC 标准之一的惯例与命名, 更具体地说是 OGC Simple Feature Specification 的惯例与命名

本库最早随 Boost 1.47.0 发布, 从那时起正式成为 Boost C++ 库集合的一部分.

最新的稳定版源代码包含在 Boost packaged releases 中, 也可以从 Boost GitHub repository (master 分支) 下载.

本库的开发上游可从 Boost.Geometry (develop branch) 获取.

请注意, 库的 扩展 (extensions) 不随官方 Boost 发布版分发, 仅在 Boost.Geometry (develop branch) 中可用, 且可能随时变更.

Boost.Geometry 于 November 28, 2009 获得 Boost 接受 (评审报告).

Boost.Geometry 有专门的 邮件列表. 在 Boost Developers list 和 Boost Users list 上也会讨论 Boost.Geometry.
