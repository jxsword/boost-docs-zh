函数

函数

说明

insert(rtree<...> &, Value const &)

向索引插入一个值.

insert(rtree<...> &, Iterator, Iterator)

向索引插入一段值范围.

insert(rtree<...> &, ConvertibleOrRange const &)

向索引插入用可转换对象创建的一个值, 或一段值范围.

remove(rtree<...> &, Value const &)

从容器中移除一个值.

remove(rtree<...> &, Iterator, Iterator)

从容器中移除一段值范围.

remove(rtree<...> &, ConvertibleOrRange const &)

从容器中移除与可转换对象相对应的值, 或一段值范围.

query(rtree<...> const &, Predicates const &, OutIter)

查找满足所传入谓词的值, 例如距某个 Point 最近和/或与某个 Box 相交的值.

qbegin(rtree<...> const &, Predicates const &)

返回指向查询范围起始处的查询迭代器.

qend(rtree<...> const &)

返回指向查询范围末尾的查询迭代器.

begin(rtree<...> const &)

返回指向 rtree 值范围起始处的迭代器.

end(rtree<...> const &)

返回指向 rtree 值范围末尾的迭代器.

clear(rtree<...> &)

从索引中移除所有值.

size(rtree<...> const &)

获取索引中存储的值的数量.

empty(rtree<...> const &)

查询索引中是否没有存储值.

bounds(rtree<...> const &)

获取包含所有存储值的 box; 若索引中没有值, 则返回无效的 box.

swap(rtree<...> &, rtree<...> &)

将容器的内容与 other 的内容交换.
