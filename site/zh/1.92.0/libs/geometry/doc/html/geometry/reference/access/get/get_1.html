get

获取几何对象 (通常是点) 的坐标值

说明

自由函数 get 和 set 是 Boost.Geometry 最重要的两个函数, 无论对库内部还是对库用户都是如此. 通常用这两个函数从点、矩形框、线段或球体读取以及设置坐标值.

概要 

template<std::size_t Dimension, typename Geometry>
coordinate_type_t< Geometry > get(Geometry const & geometry)

参数

类型

概念

名称

说明

Dimension

Dimension, 该模板参数必需. 对于 n 维几何应取 [0 .. n-1]

-

必须指定

Geometry const &

任何满足几何概念 (Geometry Concept) 的类型 (通常是点概念)

geometry

所指定概念的一个模型 (通常是一个点)
返回

指定几何对象在指定维度上的坐标值

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/access.hpp>

行为

情况

行为

点

返回点的坐标

圆或球

返回圆或球心的坐标 (目前在扩展中)

球面

返回点的坐标, 依据指定单位以弧度或度表示
复杂度

常量时间

示例

获取点的坐标

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

namespace bg = boost::geometry;

int main()
{
    bg::model::d2::point_xy<double> point(1, 2);

    double x = bg::get<0>(point);
    double y = bg::get<1>(point);

    std::cout << "x=" << x << " y=" << y << std::endl;

    return 0;
}

输出:

x=1 y=2
