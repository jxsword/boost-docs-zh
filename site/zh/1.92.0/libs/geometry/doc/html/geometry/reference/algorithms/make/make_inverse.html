make_inverse

构造一个坐标为反向无穷大的矩形框.

说明

make_inverse 函数用很大的坐标初始化二维或三维矩形框: 最小角点非常大, 最大角点非常小. 这与 expand 函数结合使用很有用, 可用于确定一系列几何对象的包围框.

概要 

template<typename Geometry>
Geometry make_inverse()

参数

类型

概念

名称

说明

Geometry

任何满足几何概念 (Geometry Concept) 的类型

-

必须指定
返回

构造出的几何对象, 此处为矩形框

头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/make.hpp>

示例

使用 make_inverse 与 expand 便捷地确定多个对象的包围框

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/box.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

using namespace boost::geometry;

int main()
{

    using point = model::d2::point_xy<double>;
    using box = model::box<point>;

    box all = make_inverse<box>();
    std::cout << dsv(all) << std::endl;
    expand(all, make<box>(0, 0, 3, 4));
    expand(all, make<box>(2, 2, 5, 6));
    std::cout << dsv(all) << std::endl;

    return 0;
}

输出:

((1.79769e+308, 1.79769e+308), (-1.79769e+308, -1.79769e+308))
((0, 0), (5, 6))
