set

设置几何对象 (通常是点) 的坐标值

说明

自由函数 get 和 set 是 Boost.Geometry 最重要的两个函数, 无论对库内部还是对库用户都是如此. 通常用这两个函数从点、矩形框、线段或球体读取以及设置坐标值.

概要 

template<std::size_t Dimension, typename Geometry>
void set(Geometry & geometry, coordinate_type_t< Geometry > const & value)

参数

类型

概念

名称

说明

Dimension

Dimension, 该模板参数必需. 对于 n 维几何应取 [0 .. n-1]

-

必须指定

Geometry &

任何满足几何概念 (Geometry Concept) 的类型 (通常是点概念)

geometry

所指定概念的一个模型

coordinate_type_t< Geometry > const &

value

要设置的坐标值
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/access.hpp>

注释

如果同时引入 std:: 库命名空间和 boost::geometry:: 命名空间, set 可能产生歧义, 因为 std::set 是一个容器. 所以不要那样做, 或者显式写成 geometry::set.

行为

情况

行为

点

设置点的坐标

圆或球

设置圆或球心的坐标 (目前在扩展中)

球面

设置点的坐标, 依据指定单位以弧度或度表示
复杂度

常量时间

示例

设置点的坐标

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point_xy.hpp>

namespace bg = boost::geometry;

int main()
{
    bg::model::d2::point_xy<double> point;

    bg::set<0>(point, 1);
    bg::set<1>(point, 2);

    std::cout << "Location: " << bg::dsv(point) << std::endl;

    return 0;
}

输出:

Location: (1, 2)
