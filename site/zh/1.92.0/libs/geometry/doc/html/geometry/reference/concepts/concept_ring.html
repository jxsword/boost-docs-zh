环概念

说明

环概念描述环类型的要求. Boost.Geometry 中的所有算法都会依据概念要求检查几何参数.

注释

也称为线性环 (linear ring), 但这里我们明确指的是填充要素

概念定义

环概念定义如下:

  • 必须存在 traits::tag 的特化, 将 ring_tag 定义为类型
  • 其行为必须类似 Boost.Range 随机访问范围
  • 元函数 range_value<...>::type 定义的类型必须满足 点概念
  • 可以存在 traits::point_order 的特化, 定义其点的顺序或方向, 即 clockwise 或 counterclockwise
  • 可以存在 traits::closure 的特化, 定义其闭合性, 即 open 或 closed
规则

除了编译期检查的概念之外, 有效环还必须满足一些规则. 多边形 (以及环) 应满足的规则详见 多边形概念.

可用模型
  • ring
  • Boost.Polygon 的 polygon_data (需要 #include boost/geometry/geometries/adapted/boost_polygon/ring.hpp>)
注释

另请参见 Boost.Range documentation 中的示例, 展示如何将类型适配为 Boost.Range 以满足环概念
