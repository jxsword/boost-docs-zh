assign_inverse

将矩形框赋为反向无穷大

说明

assign_inverse 函数用一个很大的坐标初始化二维或三维矩形框: 最小角点非常大, 最大角点非常小. 这是收集几何对象最小包围框的便捷起点.

概要 

template<typename Geometry>
void assign_inverse(Geometry & geometry)

参数

类型

概念

名称

说明

Geometry &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/assign.hpp>

示例

使用 assign_inverse 与 expand 便捷地确定两个点的三维包围框

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/box.hpp>
#include <boost/geometry/geometries/point.hpp>

using namespace boost::geometry;

int main()
{
    using point = model::point<float, 3, cs::cartesian>;
    using box = model::box<point>;

    box all;
    assign_inverse(all);
    std::cout << dsv(all) << std::endl;
    expand(all, point(0, 0, 0));
    expand(all, point(1, 2, 3));
    std::cout << dsv(all) << std::endl;

    return 0;
}

输出:

((3.40282e+038, 3.40282e+038, 3.40282e+038), (-3.40282e+038, -3.40282e+038, -3.40282e+038))
((0, 0, 0), (1, 2, 3))
