矩形框概念

说明

矩形框概念描述矩形框类型的要求. Boost.Geometry 中的所有算法都会依据概念要求检查几何参数.

矩形框是具有 (通常) 二维或三维的几何对象, 其轴与坐标系对齐.

矩形框不是 Boost.Geometry 的基本类型 (点、线串、多边形) 之一, 而是一种 辅助类型. 矩形框存在的主要原因在于它对索引很有用 (空间索引, 或把几何切分为单调分区), 并且它是 envelope 算法的输出.

因此, 矩形框是轴对齐的 (包络也称为 aabb, 轴对齐包围盒).

概念定义

矩形框概念定义如下:

  • 必须存在 traits::tag 的特化, 将 box_tag 定义为类型
  • 必须存在 traits::point_type 的特化以定义底层点类型 (即使它不由点构成, 也应定义该类型, 以表明它可以处理哪些点)
  • 必须存在 traits::indexed_access 的特化, 按索引 (min_corner, max_corner) 和维度区分, 带有两个函数:
    • get 用于读取坐标值
    • set 用于设置坐标值 (对 ConstBox 不检查此项)
可用模型
  • model::box
