insert(ConvertibleOrRange const &)

向索引插入用可转换对象创建的一个值, 或一段值范围.

概要 
template<typename ConvertibleOrRange>
void insert(ConvertibleOrRange const & conv_or_rng)
参数

类型

名称

说明

ConvertibleOrRange const &

conv_or_rng

可转换为 value_type 的类型的对象, 或一段值范围.
抛出
  • 若 Value 的拷贝构造函数或拷贝赋值抛出异常.
  • 若分配抛出异常或返回无效值.
警告

该操作仅保证不会发生内存泄漏. 抛出异常后, R-tree 可能处于不一致的状态, 不得再插入或移除元素. 其他操作是允许的, 但其中某些操作可能返回无效数据.
