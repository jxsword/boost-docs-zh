assign_values (4 个坐标值)

为几何对象 (通常是矩形框或线段) 赋四个值

概要 

template<typename Geometry, typename Type>
void assign_values(Geometry & geometry, Type const & c1, Type const & c2,
                   Type const & c3, Type const & c4)

参数

类型

概念

名称

说明

Geometry &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

Type const &

指定坐标的数值类型 (int, double, ttmath 等)

c1

第一个坐标 (通常是 x1)

Type const &

指定坐标的数值类型 (int, double, ttmath 等)

c2

第二个坐标 (通常是 y1)

Type const &

指定坐标的数值类型 (int, double, ttmath 等)

c3

第三个坐标 (通常是 x2)

Type const &

指定坐标的数值类型 (int, double, ttmath 等)

c4

第四个坐标 (通常是 y2)
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/assign.hpp>
