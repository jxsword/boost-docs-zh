快速入门

本快速入门一节展示创建典型 R-tree 并执行空间查询的简单方法.

以下代码假定已包含以下文件并使用相应命名空间.

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/point.hpp>
#include <boost/geometry/geometries/box.hpp>

#include <boost/geometry/index/rtree.hpp>

// to store queries results
#include <vector>

// just for output
#include <iostream>
#include <boost/foreach.hpp>

namespace bg = boost::geometry;
namespace bgi = boost::geometry::index;

通常你会在 R-tree 中存储例如 std::pair<Box, MyGeometryId>. MyGeometryId 将是存储在其他容器中的复杂 Geometry 的某种标识符, 例如存储在 vector 中的 Polygon 的索引类型, 或 Ring 列表的迭代器. 为了简化 Value 的定义, 我们将使用预定义的 Box 与 unsigned int.

typedef bg::model::point<float, 2, bg::cs::cartesian> point;
typedef bg::model::box<point> box;
typedef std::pair<box, unsigned> value;

R-tree 可以使用各种算法与参数创建. 你应选择最适合你目的的算法. 在本例中我们将使用 quadratic 算法. 参数作为模板参数传入. 节点中元素的最大数量设为 16.

// create the rtree using default constructor
bgi::rtree< value, bgi::quadratic<16> > rtree;

通常 Value 会在循环中由例如存储在其他容器中的 Polygon 生成. 在这种情形下, Box 对象很可能会用 geometry::envelope() 函数创建. 但为简单起见, 我们只手动生成一些矩形框, 并使用 insert() 方法将它们插入 R-tree.

// create some values
for ( unsigned i = 0 ; i < 10 ; ++i )
{
    // create a box
    box b(point(i + 0.0f, i + 0.0f), point(i + 0.5f, i + 0.5f));
    // insert new value
    rtree.insert(std::make_pair(b, i));
}

可以执行多种类型的空间查询, 它们甚至可以在一次调用中组合在一起. 为简单起见, 我们使用默认查询. 以下查询返回与某个矩形框相交的值. 结果中 Values 的顺序未指定.

// find values intersecting some area defined by a box
box query_box(point(0, 0), point(5, 5));
std::vector<value> result_s;
rtree.query(bgi::intersects(query_box), std::back_inserter(result_s));

另一种查询是 k 近邻搜索. 它返回距空间中某个点最近的若干值. 默认的 knn 查询可以按如下方式执行. 结果中 Values 的顺序未指定.

// find 5 nearest values to a point
std::vector<value> result_n;
rtree.query(bgi::nearest(point(0, 0), 5), std::back_inserter(result_n));

最后我们将打印结果.

// display results
std::cout << "spatial query box:" << std::endl;
std::cout << bg::wkt<box>(query_box) << std::endl;
std::cout << "spatial query result:" << std::endl;
BOOST_FOREACH(value const& v, result_s)
    std::cout << bg::wkt<box>(v.first) << " - " << v.second << std::endl;

std::cout << "knn query point:" << std::endl;
std::cout << bg::wkt<point>(point(0, 0)) << std::endl;
std::cout << "knn query result:" << std::endl;
BOOST_FOREACH(value const& v, result_n)
    std::cout << bg::wkt<box>(v.first) << " - " << v.second << std::endl;
