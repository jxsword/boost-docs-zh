order_selector

枚举多边形内点序的选项.

说明

枚举 order_selector 描述多边形内点的顺序选项. 多边形可以按顺时针或逆时针排序. 多边形类型的特定顺序由 point_order 元函数定义. point_order 元函数定义一个值, 该值是 order_selector 中枚举的值之一

概要 

enum order_selector {clockwise = 1, counterclockwise = 2, order_undetermined = 0};

取值

值

说明

clockwise

点按顺时针排序.

counterclockwise

点按逆时针排序.

order_undetermined

点可能以任意顺序存储, 算法会在处理时判断 (尚未支持)
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/core/point_order.hpp>

参见

point_order 元函数
