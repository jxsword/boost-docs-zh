Boost.Tuple

元素为算术类型的 Boost.Tuple 元组可以在 Boost.Geometry 中用作点

说明

Boost.Tuple 定长集合 (如 boost::tuple<double, double>) 被 (可选地) 适配到 Boost.Geometry 点概念.

Boost.Tuple 的 pair 或 triple 各元素类型可以互不相同, 如 boost::tuple<float, double>. Boost.Geometry 将第一个类型报告为其 coordinate_type.

Boost.Geometry 支持 Boost.Tuple 的 pair、triple、quadruple 等, 直至 10 个元素的元组 (不过大多数算法不支持这么多维度).

元组可以作为模型 linestring, polygon, segment, box 与 ring 所使用的点类型.

所属模型

点概念

头文件

#include <boost/geometry/geometries/adapted/boost_tuple.hpp>

标准头文件 boost/geometry.hpp 不会包含本头文件.

示例

演示如何在 Boost.Geometry 中使用 Boost.Tuple 点

在 Boost.Geometry 中使用 Boost.Tuple 很直接, 其他多个示例中也有展示.

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/adapted/boost_tuple.hpp>

BOOST_GEOMETRY_REGISTER_BOOST_TUPLE_CS(cs::cartesian)

int main()
{
    boost::geometry::model::polygon<boost::tuple<double, double>> poly;
    poly.outer().push_back(boost::make_tuple(1.0, 2.0));
    poly.outer().push_back(boost::make_tuple(6.0, 4.0));
    poly.outer().push_back(boost::make_tuple(5.0, 1.0));
    poly.outer().push_back(boost::make_tuple(1.0, 2.0));

    std::cout << "Area: " << boost::geometry::area(poly) << std::endl;
    std::cout << "Contains (1.5, 2.5): "
        << std::boolalpha
        << boost::geometry::within(boost::make_tuple(1.5, 2.5), poly)
        << std::endl;

    return 0;
}

输出:

Area: 6.5
Contains (1.5, 2.5): false
