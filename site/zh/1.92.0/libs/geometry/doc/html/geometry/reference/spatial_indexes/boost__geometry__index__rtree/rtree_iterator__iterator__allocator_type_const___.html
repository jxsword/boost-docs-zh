rtree(Iterator, Iterator, allocator_type const &)

构造函数.

说明

该树使用打包算法和临时打包分配器创建.

概要 
template<typename Iterator>
rtree(Iterator first,
      Iterator last,
      allocator_type const & allocator)
参数

类型

名称

说明

Iterator

first

Value 范围的起始.

Iterator

last

Value 范围的末尾.

allocator_type const &

allocator

树中持久数据的分配器对象.
抛出
  • 若分配器的拷贝构造函数抛出异常.
  • 若 Value 的拷贝构造函数或拷贝赋值抛出异常.
  • 若分配抛出异常或返回无效值.
