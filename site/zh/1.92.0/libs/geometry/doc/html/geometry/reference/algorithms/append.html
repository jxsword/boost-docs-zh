append

向线串、环、多边形或多几何追加一个或多个点.

概要 

template<typename Geometry, typename RangeOrPoint>
void append(Geometry & geometry, RangeOrPoint const & range_or_point, signed_size_type ring_index = -1,
            signed_size_type multi_index = 0)

参数

类型

概念

名称

说明

Geometry &

任何满足几何概念 (Geometry Concept) 的类型

geometry

所指定概念的一个模型

RangeOrPoint const &

范围或点, 满足 Boost.Range 概念或 Boost.Geometry 点概念

range_or_point

要添加的点或范围

signed_size_type

ring_index

多边形情况下环的索引: 外环 (-1, 默认值) 或内环索引

signed_size_type

multi_index

要向其追加点的几何的索引
头文件

其一

#include <boost/geometry.hpp>

或

#include <boost/geometry/algorithms/append.hpp>

一致性

OGC 未定义 append 函数.

点

行为

情况

行为

Point, Box, Segment

可编译, 但无操作

Linestring

将点或范围追加到线串末尾

Ring

将点或范围追加到环的末尾 (不显式闭合)

多边形 (Polygon)

将点或范围追加到多边形的末尾 (不显式闭合), 可以是外环 (默认), 也可以为某个内环指定从零开始的索引. 在后一种情况下, 内环不会自动扩容, 因此请确保该索引小于内环数量

多线串 (Multi Linestring)

将点或范围追加到给定 multi 索引所对应线串的末尾. 多线串不会自动扩容, 因此请确保 multi 索引小于多线串中线串的数量.

多多边形 (Multi Polygon)

将点或范围追加到给定 multi 索引所对应多边形的末尾 (不显式闭合). 点或范围被追加到外环末尾 (默认), 或为内环指定从零开始的环索引. 多多边形不会自动扩容, 因此请确保 multi 索引小于多多边形中多边形的数量. 多边形的内环同理: 内环不会自动扩容, 因此请确保从零开始的环索引小于该多边形内环的数量.

线性

示例

演示使用 Boost.Geometry 的 append 向多边形追加点或范围的用法

#include <iostream>

#include <boost/geometry.hpp>
#include <boost/geometry/geometries/polygon.hpp>
#include <boost/geometry/geometries/adapted/boost_tuple.hpp>

BOOST_GEOMETRY_REGISTER_BOOST_TUPLE_CS(cs::cartesian)

int main()
{
    using boost::geometry::append;

    using vector = std::vector<boost::tuple<int, int>>;
    using polygon = boost::geometry::model::polygon<boost::tuple<int, int>>;

    polygon poly;

    // Append a range
    append(poly, vector{{0, 0}, {0, 10}, {11, 11}, {10, 0}}); 
    // Append a point (in this case the closing point)
    append(poly, boost::make_tuple(0, 0));

    // Create an interior ring (append does not do this automatically)
    boost::geometry::interior_rings(poly).resize(1);

    // Append a range to the interior ring
    append(poly, vector{{2, 2}, {2, 5}, {6, 6}, {5, 2}}, 0); 

    // Append a point to the first interior ring
    append(poly, boost::make_tuple(2, 2), 0);

    std::cout << boost::geometry::dsv(poly) << std::endl;

    return 0;
}

vector 建模了一个范围, 因此可用于 boost::geometry::append

最后一个参数 ring_index 0 表示第一个内环

输出:

(((0, 0), (0, 10), (11, 11), (10, 0), (0, 0)), ((2, 2), (2, 5), (6, 6), (5, 2), (2, 2)))
