BOOST_GEOMETRY_REGISTER_POINT_2D

注册二维点类型的宏.

说明

宏 BOOST_GEOMETRY_REGISTER_POINT_2D 注册一个二维点类型, 使其能被 Boost.Geometry 识别, 从而可以对指定类型使用 Boost.Geometry 功能. 对于地理坐标系, 务必先指定经度再指定纬度, 以便使用库内置的策略.

概要 

#define BOOST_GEOMETRY_REGISTER_POINT_2D(Point, CoordinateType, CoordinateSystem,
                                  Field0, Field1)

参数

名称

说明

点

要注册的点类型

CoordinateType

点的坐标类型 (例如 double)

CoordinateSystem

坐标系 (例如 cs::cartesian)

Field0

包含第一个坐标 (通常是 x 或经度) 的成员

Field1

包含第二个坐标 (通常是 y 或纬度) 的成员
头文件

#include <boost/geometry/geometries/register/point.hpp>

注意

在所有命名空间之外使用该宏

注释

点类型可以位于某个命名空间中

示例

展示宏 BOOST_GEOMETRY_REGISTER_POINT_2D 的用法

#include <iostream>
#include <boost/geometry.hpp>
#include <boost/geometry/geometries/register/point.hpp>


struct legacy_point
{
    double x, y;
};

BOOST_GEOMETRY_REGISTER_POINT_2D(legacy_point, double, cs::cartesian, x, y) 

int main()
{
    legacy_point p1, p2;

    namespace bg = boost::geometry;

    
    bg::assign_values(p1, 1, 1);
    bg::assign_values(p2, 2, 2);

    double d = bg::distance(p1, p2);

    std::cout << "Distance: " << d << std::endl;

    return 0;
}

在某处定义了任意旧式点结构体

神奇之处: 将其适配到 Boost.Geometry 点概念

现在任何 Boost.Geometry 函数都可用于该旧式点. 此处: assign_values 和 distance
