集合类型规范符 set_of 与 multiset_of

这些集合类型规范符分别允许插入禁止或允许重复元素的集合. set_of 和 multiset_of 的语法一致, 因此对它们一起进行描述.

[multi]set_of 集合视图是对 bimap 中所含底层元素堆的一个 std::[multi]set 签名兼容接口.

有两种变体: set_of 不允许重复元素 (相对于其关联的比较谓词) , 而 multiset_of 接受这些重复元素. 这两个变体的接口大体相同, 因此将它们一起编写文档, 并在存在差异之处明确注明.

如果你从某一侧看这个 bimap, 你将使用一个 map 视图; 如果你把它作为一个整体来看, 你将使用一个集合视图.

复杂度签名

在这里以及在这个视图的操作描述中, 我们采用 复杂度签名一节 中概述的方案. [multi]set_of 视图的复杂度签名是:

  • 拷贝: c(n) = n * log(n),
  • 插入: i(n) = log(n),
  • 提示插入: h(n) = 1 (常数时间) ——如果提示元素位于插入点之前; 否则为 h(n) = log(n),
  • 删除: d(n) = 1 (均摊常数时间) ,
  • 替换: r(n) = 1 (常数时间) ——如果元素位置不变; 否则为 r(n) = log(n),
  • 修改: m(n) = 1 (常数时间) ——如果元素位置不变; 否则为 m(n) = log(n).
实例化类型

集合视图在 bimap 内部实例化. 实例化依赖于以下类型:

  • Value 来自集合规范符,
  • Allocator 来自 bimap,
  • Compare 来自集合规范符.

Compare 是 严格弱序 (Strict Weak Ordering) , 作用于 Value 的元素之上.

构造函数、拷贝与赋值

集合视图没有公共构造函数或析构函数. 另一方面, 提供了赋值.

this_type & operator=(const this_type & x);
  • 效果: a = b;, 其中 a 和 b 分别是 bimap 对象, *this 和 x 分别属于它们.
  • 返回: *this.
修改器 
std::pair<iterator,bool> insert(const value_type & x);
  • 效果: 把 x 插入到该集合视图所属的 bimap 中, 如果
    • 该集合视图是非唯一的, 或者不存在具有等价键的其他元素,
    • 并且 bimap 的其他集合规范符允许该插入.
  • 返回: 返回值是一个 pair p. p.second 为 true 当且仅当插入确实发生. 插入成功时, p.first 指向被插入的元素; 否则, p.first 指向导致插入被禁止的元素. 注意, 可能有不止一个元素导致插入不被允许.
  • 复杂度: O(I(n)).
  • 异常安全性: 强保证.
iterator insert(iterator position, const value_type & x);
  • 要求: position 是该视图的一个有效迭代器.
  • 效果: position 被用作提示以提高操作的效率. 把 x 插入到该视图所属的 bimap 中, 如果
    • 该集合视图是非唯一的, 或者不存在具有等价键的其他元素,
    • 并且 bimap 的所有其他视图都允许该插入.
  • 返回: 插入成功时, 返回指向新插入元素的迭代器. 否则, 返回指向导致插入被禁止的元素的迭代器. 注意, 可能有不止一个元素导致插入不被允许.
  • 复杂度: O(H(n)).
  • 异常安全性: 强保证.
template< class InputIterator >
void insert(InputIterator first, InputIterator last);
  • 要求: InputIterator 是 输入迭代器 (Input Iterator) 的一个模型, 元素类型为 value_type 或可转换为 value_type 的类型. first 和 last 不是该索引所属的 bimap 的任何视图中的迭代器. last 从 first 可达.
  • 效果: iterator hint = end(); while( first != last ) hint = insert( hint, *first++ );
  • 复杂度: O(m*H(n+m)), 其中 m 是 [first, last) 中的元素个数.
  • 异常安全性: 基本保证.
iterator erase(iterator position);
  • 要求: position 是该集合视图的一个有效可解引用迭代器.
  • 效果: 删除 position 所指向的元素.
  • 返回: 一个指向紧随被删除元素之后的元素的迭代器, 或 end() (如果不存在这样的元素) .
  • 复杂度: O(D(n)).
  • 异常安全性: 不抛出异常.
size_type erase(const key_type & x);
  • 效果: 删除键与 x 等价的所有元素.
  • 返回: 被删除元素的个数.
  • 复杂度: O(log(n) + m*D(n)), 其中 m 是被删除元素的个数.
  • 异常安全性: 基本保证.
iterator erase(iterator first, iterator last);
  • 要求: [first,last) 是该视图的一个有效范围.
  • 效果: 删除 [first,last) 中的元素.
  • 返回: last.
  • 复杂度: O(log(n) + m*D(n)), 其中 m 是 [first,last) 中的元素个数.
  • 异常安全性: 不抛出异常.
bool replace(iterator position, const value_type& x);
  • 要求: position 是该集合视图的一个有效可解引用迭代器.
  • 效果: 把值 x 赋给 position 所指向的元素——该元素属于该集合视图所属的 bimap, 前提是: 对于值 x,
    • 该集合视图是非唯一的, 或者不存在具有等价键的其他元素 (*position 可能除外) ,
    • 并且 bimap 的所有其他视图都允许该替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该集合视图所属的 bimap 保持其原始状态.
template< class CompatibleKey >
bool replace_key(iterator position, const CompatibleKey & x);
  • 要求: position 是该集合视图的一个有效可解引用迭代器. CompatibleKey 可以赋值给 key_type.
  • 效果: 把值 x 赋给 e.first, 其中 e 是 position 所指向的元素——它属于该集合视图所属的 bimap, 前提是
    • 该 map 视图是非唯一的, 或者不存在具有等价键的其他元素 (*position 可能除外) ,
    • 并且 bimap 的所有其他视图都允许该替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该集合视图所属的 bimap 保持其原始状态.
template< class CompatibleData >
bool replace_data(iterator position, const CompatibleData & x);
  • 要求: position 是该集合视图的一个有效可解引用迭代器. CompatibleKey 可以赋值给 mapped_type.
  • 效果: 把值 x 赋给 e.second, 其中 e 是 position 所指向的元素——它属于该集合视图所属的 bimap, 前提是
    • 该 map 视图是非唯一的, 或者不存在具有等价键的其他元素 (*position 可能除外) ,
    • 并且 bimap 的所有其他视图都允许该替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该集合视图所属的 bimap 保持其原始状态.
template< class KeyModifier >
bool modify_key(iterator position, KeyModifier mod);
  • 要求: KeyModifier 是 一元函数 (Unary Function) 的一个模型, 接受类型为 key_type& 的参数; position 是该视图的一个有效可解引用迭代器.
  • 效果: 调用 mod(e.first), 其中 e 是 position 所指向的元素, 并把 *position 重新排列到 bimap 的所有视图中. 如果重新排列失败, 该元素被擦除. 重新排列在以下情况下成功:
    • 该 map 视图是非唯一的, 或者不存在具有等价键的其他元素,
    • 并且 bimap 的所有其他视图都允许该重新排列.
  • 后置条件: 如果操作成功, position 的有效性得到保持.
  • 返回: true 如果操作成功, false 否则.
  • 复杂度: O(M(n)).
  • 异常安全性: 基本保证. 如果某个用户提供的操作 (mod 本身可能除外) 抛出异常, position 所指向的元素将被擦除.
  • 注释: 仅为 map 视图提供.
template< class DataModifier >
bool modify_data(iterator position, DataModifier mod);
  • 要求: DataModifier 是 一元函数 (Unary Function) 的一个模型, 接受类型为 mapped_type& 的参数; position 是该视图的一个有效可解引用迭代器.
  • 效果: 调用 mod(e.second), 其中 e 是 position 所指向的元素, 并把 *position 重新排列到 bimap 的所有视图中. 如果重新排列失败, 该元素被擦除. 重新排列在以下情况下成功:
    • 相对的 map 视图是非唯一的, 或者该视图中不存在具有等价键的其他元素,
    • 并且 bimap 的所有其他视图都允许该重新排列.
  • 后置条件: 如果操作成功, position 的有效性得到保持.
  • 返回: true 如果操作成功, false 否则.
  • 复杂度: O(M(n)).
  • 异常安全性: 基本保证. 如果某个用户提供的操作 (mod 本身可能除外) 抛出异常, position 所指向的元素将被擦除.
  • 注释: 仅为 map 视图提供.
集合操作

[multi]set_of 视图提供 排序关联容器 (Sorted Associative Container) 和 唯一关联容器 (Unique Associative Container) 所要求的完整查找功能, 即 find、count、lower_bound、upper_bound 和 equal_range. 此外, 这些成员函数被模板化以允许非标准参数, 从而扩展了允许的查找操作类型.

类型 CompatibleKey 被称为 兼容键 (相对于 Compare) , 如果 (CompatibleKey, Compare) 是 Compare 的一个兼容扩展. 这意味着 Compare 除了是严格弱序之外, 还接受类型为 CompatibleKey 的参数——这通常意味着它有多个 operator() 的重载.

template< class CompatibleKey >
iterator find(const CompatibleKey & x);

template< class CompatibleKey >
const_iterator find(const CompatibleKey & x) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回一个指向键与 x 等价的元素的指针, 或者——如果这样的元素不存在——返回 end().
  • 复杂度: O(log(n)).
template< class CompatibleKey >
size_type count(const key_type & x) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回键与 x 等价的元素个数.
  • 复杂度: O(log(n) + count(x)).
template< class CompatibleKey >
iterator lower_bound(const key_type & x);

template< class CompatibleKey >
const_iterator lower_bound(const key_type & x) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回指向键不小于 x 的第一个元素的迭代器, 或者——如果这样的元素不存在——返回 end().
  • 复杂度: O(log(n)).
template< class CompatibleKey >
iterator upper_bound(const key_type & x);

template< class CompatibleKey >
const_iterator upper_bound(const key_type & x) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回指向键大于 x 的第一个元素的迭代器, 或者——如果这样的元素不存在——返回 end().
  • 复杂度: O(log(n)).
template< class CompatibleKey >
std::pair<iterator,iterator>
    equal_range(const key_type & x);

template< class CompatibleKey >
std::pair<const_iterator,const_iterator>
    equal_range(const key_type & x) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 等价于 make_pair(lower_bound(x),upper_bound(x)).
  • 复杂度: O(log(n)).
范围操作

成员函数 range 并没有为排序关联容器定义, 但 [multi]set_of map 视图把它作为一个便利工具提供. 范围或区间由下界和上界的两个条件定义, 这两个条件仿照以下概念建模.

考虑一个 严格弱序 (Strict Weak Ordering) Compare (定义在 Key 类型的值上) . 如果类型 LowerBounder 被称为 Compare 的下界器 (lower bounder) , 如果

  • LowerBounder 是 Predicate, 定义于 Key 之上,
  • 如果 lower(k1) 且 !comp(k2,k1), 则 lower(k2),

对于每个 lower (类型为 LowerBounder) 、 comp (类型为 Compare) , 以及 k1 和 k2 (类型均为 Key) . 类似地, 上界器 (upper bounder) 是一个类型 UpperBounder, 使得

  • UpperBounder 是 Predicate, 定义于 Key 之上,
  • 如果 upper(k1) 且 !comp(k1,k2), 则 upper(k2),

对于每个 upper (类型为 UpperBounder) 、 comp (类型为 Compare) , 以及 k1 和 k2 (类型均为 Key) .

template< class LowerBounder, class UpperBounder>
std::pair<const_iterator,const_iterator> range(
    LowerBounder lower, UpperBounder upper) const;
  • 要求: LowerBounder 和 UpperBounder 分别是 key_compare 的下界器和上界器.
  • 效果: 返回一对迭代器, 分别指向同时满足 lower 和 upper 的元素子序列的开头和结尾之后的位置. 如果不存在这样的元素, 两个迭代器都指向满足 lower 的第一个元素; 如果连这个元素也不存在, 则二者都等于 end().
  • 复杂度: O(log(n)).
  • 变体: 可以用单值 boost::bimap::unbounded 代替 lower 或 upper (或两者) . 它充当一个谓词, 所有 key_type 类型的值都满足它.
  • 注释: 仅为 map 视图提供.
at()、info_at() 和 operator[] —— 仅 set_of 
template< class CompatibleKey >
const mapped_type & at(const CompatibleKey & k) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回 mapped_type 类型的引用, 该引用与 k 相关联; 如果这样的键不存在, 则抛出 std::out_of_range.
  • 复杂度: O(log(n)).
  • 注释: 仅在使用 set_of 时提供.

bimap 的对称性对 operator[] 和 at() 的非 const 版本施加了一些 std::maps 中所没有的约束. 只有当另一个集合类型是可变的 (list_of、vector_of 和 unconstrained_set_of) 时才提供它们.

template< class CompatibleKey >
mapped_type & operator[](const CompatibleKey & k);
  • 要求: CompatibleKey 是 key_compare 的一个兼容键. key_type 可以从 const CompatibleKey & 构造.
  • 效果: return insert(value_type(k,mapped_type()))->second;
  • 复杂度: O(log(n)).
  • 注释: 仅在使用 set_of 且另一个集合类型可变时提供.
template< class CompatibleKey >
mapped_type & at(const CompatibleKey & k);
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回 mapped_type 类型的引用, 该引用与 k 相关联; 如果这样的键不存在, 则抛出 std::out_of_range.
  • 复杂度: O(log(n)).
  • 注释: 仅在使用 set_of 且另一个集合类型可变时提供.
template< class CompatibleKey >
info_type & info_at(const CompatibleKey & k);

template< class CompatibleKey >
const info_type & info_at(const CompatibleKey & k) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回 info_type 类型的引用, 该引用与 k 相关联; 如果这样的键不存在, 则抛出 std::out_of_range.
  • 复杂度: O(log(n)).
  • 注释: 仅在使用 set_of 和 info_hook 时提供
序列化

视图本身不能被序列化, 只能作为它们所嵌入的 bimap 的一部分被序列化. 在描述与 [multi]set_of 视图相关的关于其嵌入容器序列化的额外前置条件和保证时, 我们使用 bimap 序列化一节中定义的概念.

操作: 将一个 bimap m 保存到输出档案 (XML 档案) ar.

  • 要求: 除容器所施加的要求之外, 没有额外要求.

操作: 加载一个 bimap m’——从输入档案 (XML 档案) ar.

  • 要求: 除一般要求外, value_comp() 必须与 m.get<i>().value_comp() 序列化兼容, 其中 i 是有序视图在容器中的位置.
  • 后置条件: 加载成功时, [begin(), end()) 的每个元素都是 [m.get<i>().begin(), m.get<i>().end()) 中对应元素的恢复副本.

操作: 将一个迭代器或 const_iterator it 保存到输出档案 (XML 档案) ar.

  • 要求: it 是该视图的一个有效迭代器. 关联的 bimap 此前已被保存.

操作: 从输入档案 (XML 档案) ar 加载一个 iterator 或 const_iterator it’.

  • 后置条件: 加载成功时, 如果 it 原先是可解引用的, 则 *it’ 是 *it 的恢复副本; 否则 it’ == end().
  • 注释: 允许 it 是一个 const_iterator, 而恢复出来的 it’ 是一个迭代器, 或者反过来.
