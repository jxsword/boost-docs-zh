一分钟教程

什么是 bimap?

Bimap 是一种表示两个集合的元素之间双向关系的数据结构. 这个容器被设计成像两个相对的 STL map 一样工作. 集合 X 与集合 Y 之间的 bimap 可以视为从 X 到 Y 的映射 (该视图将被称为 “左 map 视图”) , 也可以视为从 Y 到 X 的映射 (称为 “右 map 视图”) . 此外, bimap 还可以被视为 X 与 Y 之间关系的集合 (称为 “关系集合视图”.

下面的代码创建一个空的 bimap 容器:

typedef bimap<X,Y> bm_type;
bm_type bm;

给定这段代码, 下面是对得到的 bimap 的完整描述. [1]

  • bm.left 与 std::map<X,Y> 签名兼容
  • bm.right 与 std::map<Y,X> 签名兼容
  • bm 与 std::set< relation<X,Y> > 签名兼容

你可以看到 bimap 容器如何在同一双向关系集合之上提供三种视图.

如果我们有任何一个可用于 map 的泛型函数

template< class MapType >
void print_map(const MapType & m)
{
    typedef typename MapType::const_iterator const_iterator;
    for( const_iterator iter = m.begin(), iend = m.end(); iter != iend; ++iter )
    {
        std::cout << iter->first << "-->" << iter->second << std::endl;
    }
}

我们可以将 左 map 视图 和 右 map 视图 用于它

bimap< int, std::string > bm;
...
print_map( bm.left  );
print_map( bm.right );

输出将是

1 --> one
2 --> two
...
one --> 1
two --> 2
...

bimap 的关系与 pair 的布局

relation 类表示两个相关联的元素. 这两个值被命名为 left 和 right, 以体现该类型的对称性. bimap 的 pair 类与 std::pairs 签名兼容.

循序渐进

boost 目录中提供了一个便利头文件:

#include <boost/bimap.hpp>

让我们定义一个整数与字符串之间的双向映射:

typedef boost::bimap< int, std::string > bm_type;
bm_type bm;

关系集合视图

请记住, bm 本身就可以用作关系的集合. 我们可以使用这个视图插入元素或对元素进行迭代.

bm.insert( bm_type::value_type(1, "one" ) );
bm.insert( bm_type::value_type(2, "two" ) );

std::cout << "There are " << bm.size() << "relations" << std::endl;

for( bm_type::const_iterator iter = bm.begin(), iend = bm.end();
    iter != iend; ++iter )
{
    // iter->left  : data : int
    // iter->right : data : std::string

    std::cout << iter->left << " <--> " << iter->right << std::endl;
}

左 map 视图

bm.left 的表现就像一个 std::map< int, std::string >. 我们像使用标准 map 一样使用它.

typedef bm_type::left_map::const_iterator left_const_iterator;

for( left_const_iterator left_iter = bm.left.begin(), iend = bm.left.end();
     left_iter != iend; ++left_iter )
{
    // left_iter->first  : key  : int
    // left_iter->second : data : std::string

    std::cout << left_iter->first << " --> " << left_iter->second << std::endl;
}

bm_type::left_const_iterator left_iter = bm.left.find(2);
assert( left_iter->second ==  "two" );

bm.left.insert( bm_type::left_value_type( 3, "three" ) );

bm.left 的类型是 bm_type::left_map, 而 bm.right 的类型是 bm_type::right_map

bm_type::left_-type- 可以用作更冗长的 bm_type::left_map::-type- 的简写.

这一行产生的效果与 bm.insert( bm_type::value_type(3,"three") ); 相同

右 map 视图

bm.right 的表现就像一个 std::map< std::string, int >. 需要注意的是, 键是第一个类型, 数据是第二个类型, 与标准 map 完全一致.

bm_type::right_const_iterator right_iter = bm.right.find("two");

// right_iter->first  : key  : std::string
// right_iter->second : data : int

assert( right_iter->second ==  2 );

assert( bm.right.at("one") == 1 );

bm.right.erase("two");

bm.right.insert( bm_type::right_value_type( "four", 4 ) );

这一行产生的效果与 bm.insert( bm_type::value_type(4,"four") ); 相同

与 std::map 的区别

bimap 视图与其标准容器对应物之间的主要区别在于, 由于 bimap 的双向性质, 存储在其中的值不能直接通过迭代器修改. 例如, 当解引用一个 std::map<X,Y> 迭代器时, 返回类型是 std::pair<const X, Y>, 因此以下代码是有效的: m.begin()->second = new_value;. 然而, 解引用一个 bimap<X,Y>::left_iterator 返回一个与 签名兼容 的 std::pair<const X, const Y> 类型

bm.left.find(1)->second = "1"; // Compilation error

如果你插入 (1,"one") 和 (1,"1") 于一个 std::map<int,std::string> 中, 第二次插入将不起作用. 在一个 bimap<X,Y> 中, 两个键都必须保持唯一. 插入也可能在其他情况下失败. 我们来看一个例子

bm.clear();

bm.insert( bm_type::value_type( 1, "one" ) );

bm.insert( bm_type::value_type( 1, "1"   ) ); // No effect!
bm.insert( bm_type::value_type( 2, "one" ) ); // No effect!

assert( bm.size() == 1 );

一个简单的例子

看看你如何能复用本打算配合 std::maps 使用的代码, 例如本例中的 print_map 函数.

转到源代码 

#include <string>
#include <iostream>

#include <boost/bimap.hpp>

template< class MapType >
void print_map(const MapType & map,
               const std::string & separator,
               std::ostream & os )
{
    typedef typename MapType::const_iterator const_iterator;

    for( const_iterator i = map.begin(), iend = map.end(); i != iend; ++i )
    {
        os << i->first << separator << i->second << std::endl;
    }
}

int main()
{
    // Soccer World cup

    typedef boost::bimap< std::string, int > results_bimap;
    typedef results_bimap::value_type position;

    results_bimap results;
    results.insert( position("Argentina"    ,1) );
    results.insert( position("Spain"        ,2) );
    results.insert( position("Germany"      ,3) );
    results.insert( position("France"       ,4) );

    std::cout << "The number of countries is " << results.size()
              << std::endl;

    std::cout << "The winner is " << results.right.at(1)
              << std::endl
              << std::endl;

    std::cout << "Countries names ordered by their final position:"
              << std::endl;

    // results.right works like a std::map< int, std::string >

    print_map( results.right, ") ", std::cout );

    std::cout << std::endl
              << "Countries names ordered alphabetically along with"
                    "their final position:"
              << std::endl;

    // results.left works like a std::map< std::string, int >

    print_map( results.left, " ends in position ", std::cout );

    return 0;
}

这个程序的输出如下:

The number of countries is 4

The winner is Argentina

Countries names ordered by their final position:
1) Argentina
2) Spain
3) Germany
4) France

Countries names ordered alphabetically along with their final position:
Argentina ends in position 1
France ends in position 4
Germany ends in position 3
Spain ends in position 2

继续旅程

有关函数签名的信息, 请参阅任何标准库文档, 或阅读本文档的 参考 部分.

注意

请注意, 双向映射只是与标准容器签名兼容. 有些函数可能给出不同的结果, 例如向左 map 插入一个 pair 而其第二个值与容器中已存储的关系冲突的情形. 由于约束的重复, 这些函数在 bimap 中可能更慢. 如果你打算在严肃的项目中使用 bimap, 强烈建议阅读完整教程.


[1] 如果某类型在函数与元数据方面具有相同的签名, 则称它与另一类型签名兼容. 前置条件、后置条件和操作的顺序不必相同.
