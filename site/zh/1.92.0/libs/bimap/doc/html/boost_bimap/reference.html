头文件

以下是 Boost.Bimap 的接口头文件:

便利头文件

  • "boost/bimap.hpp" (包含 "boost/bimap/bimap.hpp" 并把 bimap 类导入 boost 命名空间)

容器

  • "boost/bimap/bimap.hpp" (包含 "boost/bimap/set_of.hpp" 和 "boost/bimap/unconstrained_set_of.hpp")

集合类型

  • "boost/bimap/set_of.hpp"
  • "boost/bimap/multiset_of.hpp"
  • "boost/bimap/unordered_set_of.hpp"
  • "boost/bimap/unordered_multiset_of.hpp"
  • "boost/bimap/list_of.hpp"
  • "boost/bimap/vector_of.hpp"
  • "boost/bimap/unconstrained_set_of.hpp"

Boost 集成

  • "boost/bimap/support/lambda.hpp"
  • "boost/bimap/property_map/set_support.hpp"
  • "boost/bimap/property_map/unordered_set_support.hpp"

使用 Boost.Bimap 的程序因此必须包含 "boost/bimap/bimap.hpp" 以及定义所用集合类型的头文件.

额外的头文件允许 Boost.Bimap 与其他 boost 库集成, 例如 Boost.Lambda 和 Boost.Property_map.

要使用 Boost.Bimap 的序列化功能, 必须链接相应的 Boost.Serialization 库模块. 除此之外, Boost.Bimap 是一个仅头文件库, 不需要额外的目标模块.
