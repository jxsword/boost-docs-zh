unconstrained_set_of 集合视图是一个没有任何约束的视图. 使用这种视图会提升 bimap 的性能, 但该视图无法被访问. 非约束视图是一个空类.

在左 map 视图中:

typedef  Left  key_type;

在右 map 视图中:

typedef  ...  key_type;
typedef  Left mapped_type;

typedef signature-compatible with std::pair< ... , Left > value_type;
复杂度签名

复杂度签名一节. 我们采用其中概述的方案. 用户无法访问非约束视图, 但用于求 bimap 操作阶的公式在以下定义下依然成立. unconstrained_set_of 视图的复杂度签名是:

  • 拷贝: c(n) = 0
  • 插入: i(n) = 0
  • 提示插入: h(n) = 0
  • 删除: d(n) = 0
  • 替换: r(n) = 0
  • 修改: m(n) = 0
序列化

视图本身不能被序列化, 只能作为它们所嵌入的 bimap 的一部分被序列化. 在描述与 list_of 视图相关的关于其嵌入容器序列化的额外前置条件和保证时, 我们使用 bimap 序列化一节中定义的概念.

操作: 将一个 bimap b 保存到输出档案 (XML 档案) ar.

  • 要求: 除容器所施加的要求之外, 没有额外要求.

操作: 从输入档案 (XML 档案) ar 加载一个 bimap b’.

  • 要求: 除容器所施加的要求之外, 没有额外要求.
