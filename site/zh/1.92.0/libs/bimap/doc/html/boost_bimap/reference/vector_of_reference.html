vector_of 视图是自由排序的序列, 具有常数时间的位置访问和随机访问迭代器. vector_of 视图中的元素默认按其插入顺序排列: 这意味着通过 bimap 的另一个视图插入的新元素会被追加到 vector_of 视图的末尾; 此外, 还提供了进一步重排元素的工具. vector_of 视图的公共接口包含 list_of 视图的接口 (操作复杂度有所不同) , 外加用于位置访问 (operator[] 和 at()) 以及容量处理的额外操作. 在所有操作中, 无论容量状态如何, 迭代器和对元素的引用的有效性都得到保持.

与 list_of 视图的情况一样, vector_of 视图相对于 STL 序列容器有如下限制:

  • vector_of 视图不是 可赋值 (Assignable) 的 (和任何其他视图一样) .
  • 向 vector_of 视图的插入可能因为与其他视图的冲突而失败. 这改变了所提供操作相对于 STL 序列容器中对应操作的语义.
  • vector_of 视图中的元素是不可变的, 只能通过 replace 和 modify 成员函数来更改.

考虑到这些限制, vector_of 视图是 随机访问容器 (Random Access Container) 和 后插序列 (Back Insertion Sequence) 的模型. 虽然这些视图不建模 前插序列 (Front Insertion Sequence) (因为前插和前删需要线性时间) , 但仍提供了 front 操作以匹配 list_of 视图的接口. 我们只描述那些在所建模概念中不存在、或与这些容器类型的要求不完全相符的类型和操作.

复杂度签名

在这里以及在 vector_of 视图的操作描述中, 我们采用 复杂度签名一节 中概述的方案. vector_of 视图的复杂度签名是:

  • 拷贝: c(n) = n * log(n),
  • 插入: i(n) = 1 (均摊常数时间) ,
  • 提示插入: h(n) = 1 (均摊常数时间) ,
  • 删除: d(n) = m, 其中 m 是被删元素到序列末尾的距离,
  • 替换: r(n) = 1 (常数时间) ,
  • 修改: m(n) = 1 (常数时间) .

为了方便书写一些复杂度公式, 还使用了以下表达式:

如果 a 非零, 否则为 0. shl(a,b) = a+b 如果 rel(a,b,c) =, a<b, 否则为 c-a, a-b

(shl 和 rel 分别代表 左移 和 重定位. )

构造函数、拷贝与赋值

正如视图概念一节所解释的, 视图没有公共构造函数或析构函数. 另一方面, 提供了赋值.

this_type & operator=(const this_type & x);
  • 效果: a=b;, 其中 a 和 b 分别是 bimap 对象, *this 和 x 分别属于它.
  • 返回: *this.
template< class InputIterator >
void assign(InputIterator first, InputIterator last);
  • 要求: InputIterator 是 输入迭代器 (Input Iterator) 的一个模型, 元素类型为 value_type 或可转换为 value_type 的类型. first 和 last 不是该视图所属的 bimap 的任何视图中的迭代器. last 从 first 可达.
  • 效果: clear(); insert(end(),first,last); 
void assign(size_type n, const value_type & value);
  • 效果: clear(); for(size_type i = 0; i < n; ++n) push_back(v);
容量操作 
size_type capacity() const;
  • 返回: 满足以下条件的元素总数 c: 当 size() < c 时, 后插操作在常数时间内发生 (如 i(n) 所描述的一般情形是 均摊 常数时间. )
  • 注释: 在所有插入操作中, 无论容量状态如何, 迭代器和对元素的引用的有效性都得到保持.
void reserve(size_type m);
  • 效果: 如果 capacity() 的先前值大于或等于 m, 则什么都不做; 否则, 改变内部容量使得 capacity()>=m.
  • 复杂度: 如果容量未改变, 为常数时间; 否则为 O(n).
  • 异常安全性: 如果容量未改变, 则不抛出异常; 否则为强保证.
void resize(size_type n, const value_type & x = value_type());
  • 效果: if( n > size() ) insert(end(), n-size(), x); else if( n<size() ) erase(begin()+n,end());
  • 注释: 如果请求了扩容, 此操作之后视图的大小不保证为 n (其他视图可能会禁止插入) .
修改器 
std::pair<iterator,bool> push_front(const value_type & x);
  • 效果: 如果 bimap 的其他视图不禁止该插入, 则在序列开头插入 x.
  • 返回: 返回值是一个 pair p. p.second 为 true 当且仅当插入确实发生. 插入成功时, p.first 指向被插入的元素; 否则, p.first 指向导致插入被禁止的元素. 注意, 可能有不止一个元素导致插入不被允许.
  • 复杂度: O(n+I(n)).
  • 异常安全性: 强保证.
std::pair<iterator,bool> push_back(const value_type & x);
  • 效果: 在序列末尾插入 x——只要 bimap 的其他视图不禁止该插入.
  • 返回: 返回值是一个 pair p. p.second 为 true 当且仅当插入确实发生. 插入成功时, p.first 指向被插入的元素; 否则, p.first 指向导致插入被禁止的元素. 注意, 可能有不止一个元素导致插入不被允许.
  • 复杂度: O(I(n)).
  • 异常安全性: 强保证.
std::pair<iterator,bool> insert(iterator position, const value_type & x);
  • 要求: position 是该视图的一个有效迭代器.
  • 效果: 在 position 之前插入 x——只要 bimap 的所有其他视图都允许该插入.
  • 返回: 返回值是一个 pair p. p.second 为 true 当且仅当插入确实发生. 插入成功时, p.first 指向被插入的元素; 否则, p.first 指向导致插入被禁止的元素. 注意, 可能有不止一个元素导致插入不被允许.
  • 复杂度: O(shl(end()-position,1) + I(n)).
  • 异常安全性: 强保证.
void insert(iterator position, size_type m, const value_type & x);
  • 要求: position 是该视图的一个有效迭代器.
  • 效果: for(size_type i = 0; i < m; ++i) insert(position, x);
  • 复杂度: O(shl(end()-position,m) + m*I(n+m)).
template< class InputIterator >
void insert(iterator position, InputIterator first, InputIterator last);
  • 要求: position 是该视图的一个有效迭代器. InputIterator 是 输入迭代器 (Input Iterator) 的一个模型, 元素类型为 value_type 或可转换为 value_type 的类型. first 和 last 不是该视图所属的 bimap 的任何视图中的迭代器. last 从 first 可达.
  • 效果: while(first!=last)insert(position,*first++);
  • 复杂度: O(shl(end()-position,m) + m*I(n+m)), 其中 m 是 [first,last) 中的元素个数.
  • 异常安全性: 基本保证.
iterator erase(iterator position);
  • 要求: position 是该视图的一个有效可解引用迭代器.
  • 效果: 删除 position 所指向的元素.
  • 返回: 一个指向紧随被删除元素之后的元素的迭代器, 或 end() (如果不存在这样的元素) .
  • 复杂度: O(D(n)).
  • 异常安全性: 不抛出异常.
iterator erase(iterator first, iterator last);
  • 要求: [first,last) 是该视图的一个有效范围.
  • 效果: 删除 [first,last) 中的元素.
  • 返回: last.
  • 复杂度: O(m*D(n)), 其中 m 是 [first,last) 中的元素个数.
  • 异常安全性: 不抛出异常.
bool replace(iterator position, const value_type & x);
  • 要求: position 是该视图的一个有效可解引用迭代器.
  • 效果: 把值 x 赋给 position 所指向的元素——该元素属于该视图所属的 bimap, 前提是 bimap 的所有其他视图都允许该替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该视图所属的 bimap 保持其原始状态.
template< class CompatibleKey >
bool replace_key(iterator position, const CompatibleKey & x);
  • 要求: position 是该集合视图的一个有效可解引用迭代器. CompatibleKey 可以赋值给 key_type.
  • 效果: 把值 x 赋给 e.first, 其中 e 是 position 所指向的元素——它属于该集合视图所属的 bimap, 前提是 bimap 的所有其他视图都允许替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该集合视图所属的 bimap 保持其原始状态.
template< class CompatibleData >
bool replace_data(iterator position, const CompatibleData & x);
  • 要求: position 是该集合视图的一个有效可解引用迭代器. CompatibleKey 可以赋值给 mapped_type.
  • 效果: 把值 x 赋给 e.second, 其中 e 是 position 所指向的元素——它属于该集合视图所属的 bimap, 前提是 bimap 的所有其他视图都允许替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该集合视图所属的 bimap 保持其原始状态.
template< class KeyModifier >
bool modify_key(iterator position, KeyModifier mod);
  • 要求: KeyModifier 是 一元函数 (Unary Function) 的一个模型, 接受类型为 key_type& 的参数; position 是该视图的一个有效可解引用迭代器.
  • 效果: 调用 mod(e.first), 其中 e 是 position 所指向的元素, 并把 *position 重新排列到 bimap 的所有视图中. 如果重新排列失败, 该元素被擦除. 只有当 bimap 的所有其他视图都允许重新排列时才会成功.
  • 后置条件: 如果操作成功, position 的有效性得到保持.
  • 返回: true 如果操作成功, false 否则.
  • 复杂度: O(M(n)).
  • 异常安全性: 基本保证. 如果某个用户提供的操作 (mod 本身可能除外) 抛出异常, position 所指向的元素将被擦除.
  • 注释: 仅为 map 视图提供.
template< class DataModifier >

  • 要求: DataModifier 是 一元函数 (Unary Function) 的一个模型, 接受类型为 mapped_type& 的参数; position 是该视图的一个有效可解引用迭代器.
  • 效果: 调用 mod(e.second), 其中 e 是 position 所指向的元素, 并把 *position 重新排列到 bimap 的所有视图中. 如果重新排列失败, 该元素被擦除. 只有当 bimap 的所有其他视图都允许重新排列时才会成功.
  • 后置条件: 如果操作成功, position 的有效性得到保持.
  • 返回: true 如果操作成功, false 否则.
  • 复杂度: O(M(n)).
  • 异常安全性: 基本保证. 如果某个用户提供的操作 (mod 本身可能除外) 抛出异常, position 所指向的元素将被擦除.
  • 注释: 仅为 map 视图提供.
列表操作

vector_of 视图复制了 list_of 视图的接口, 而后者又包括 std::list 所提供的列表操作. 这些操作的语法和行为与 list_of 视图完全一致, 但相关的复杂度界限一般有所不同.

void splice(iterator position, this_type & x);
  • 要求: position 是该视图的一个有效迭代器. &x!=this
  • 效果: 在 position 之前插入 x 的内容, 顺序与其在 x 中的顺序相同. 成功插入的那些元素将从 x 中擦除.
  • 复杂度: O(shl(end()-position,x.size()) + x.size()*I(n+x.size()) + x.size()*D(x.size())).
  • 异常安全性: 基本保证.
void splice(iterator position, this_type & x,iterator i);
  • 要求: position 是该视图的一个有效迭代器. i 是 x 的一个有效可解引用迭代器.
  • 效果: 把 i 所指向的元素插入到 position 之前: 如果插入成功, 该元素将从 x 中擦除. 在特殊情况 &x==this 下, 不执行任何拷贝或删除, 操作总是成功. 如果 position==i, 则不执行任何操作.
  • 后置条件: 如果 &x==this, 则没有迭代器或引用失效.
  • 复杂度: 如果 &x==this, 则为 O(rel(position,i,i+1)); 否则为 O(shl(end()-position,1) + I(n) + D(n)).
  • 异常安全性: 如果 &x==this, 则不抛出异常; 否则为强保证.
void splice(iterator position, this_type & x, iterator first, iterator last);
  • 要求: position 是该视图的一个有效迭代器. first 和 last 是 x 的有效迭代器. last 从 first 可达. position 不在范围 [first,last) 中.
  • 效果: 对于范围 [first,last) 中的每个元素, 都尝试在 position 之前插入; 如果操作成功, 该元素将从 x 中擦除. 在特殊情况 &x==this 下, 不执行任何拷贝或删除, 插入总是成功.
  • 后置条件: 如果 &x==this, 则没有迭代器或引用失效.
  • 复杂度: 如果 &x==this, 则为 O(rel(position,first,last)); 否则为 O(shl(end()-position,m) + m*I(n+m) + m*D(x.size())), 其中 m 是 [first,last) 中的元素个数.
  • 异常安全性: 如果 &x==this, 则不抛出异常; 否则为基本保证.
void remove(const value_type & value);
  • 效果: 擦除视图中与 value 比较相等的所有元素.
  • 复杂度: O(n + m*D(n)), 其中 m 是被擦除的元素个数.
  • 异常安全性: 基本保证.
template< class Predicate >
void remove_if(Predicate pred);
  • 效果: 擦除视图中所有元素 x——其中使 pred(x) 成立的那些元素.
  • 复杂度: O(n + m*D(n)), 其中 m 是被擦除的元素个数.
  • 异常安全性: 基本保证.
void unique();
  • 效果: 对于由迭代器 i 在范围 [first+1,last) 中所指的每一组连续相等元素, 消除除第一个之外的所有元素——条件是满足 *i==*(i-1).
  • 复杂度: O(n + m*D(n)), 其中 m 是被擦除的元素个数.
  • 异常安全性: 基本保证.
template< class BinaryPredicate >
void unique(BinaryPredicate binary_pred);
  • 效果: 对于范围 [first+1,last) 中由迭代器 i 所指的每一组连续元素, 消除除第一个之外的所有元素——条件是满足 binary_pred(*i, *(i-1)).
  • 复杂度: O(n + m*D(n)), 其中 m 是被擦除的元素个数.
  • 异常安全性: 基本保证.
void merge(this_type & x);
  • 要求: std::less<value_type> 是一个 严格弱序 (Strict Weak Ordering) , 定义于 value_type 之上. 视图和 x 都按照 std::less<value_type> 排序.
  • 效果: 尝试把 x 的每个元素插入到视图中相应的位置 (按照排序) . 成功插入的元素将从 x 中擦除. 得到的序列是稳定的, 即两个容器中的等价元素保持其相对位置. 在特殊情况 &x==this 下, 不执行任何操作.
  • 后置条件: 视图中的元素和 x 中剩余的元素都已排序. 指向视图的迭代器以及 x 中未被擦除元素的引用的有效性得到保持.
  • 复杂度: 如果 &x==this, 为常数时间; 否则为 O(n + x.size()*I(n+x.size()) + x.size()*D(x.size())).
  • 异常安全性: 如果 &x==this, 则不抛出异常; 否则为基本保证.
template< class Compare >
void merge(this_type & x, Compare comp);
  • 要求: Compare 是定义在 严格弱序 (Strict Weak Ordering) 之上的 value_type. 视图和 x 都按照 comp 排序.
  • 效果: 尝试把 x 的每个元素插入到视图中相应的位置 (按照 comp) . 成功插入的元素将从 x 中擦除. 得到的序列是稳定的, 即两个容器中的等价元素保持其相对位置. 在特殊情况 &x==this 下, 不执行任何操作.

重排操作

这些操作在 std::list 中没有对应物 (尽管 splice 提供了部分重叠的功能) , 它们执行索引内部元素的单独和全局重新定位.

void relocate(iterator position, iterator i);
  • 要求: position 是该视图的一个有效迭代器. i 是该视图的一个有效可解引用迭代器.
  • 效果: 把 i 所指向的元素插入到 position 之前. 如果 position==i, 则不执行任何操作.
  • 后置条件: 没有迭代器或引用失效.
  • 复杂度: 常数.
  • 异常安全性: 不抛出异常.
void relocate(iterator position, iterator first, iterator last);
  • 要求: position 是该视图的一个有效迭代器. first 和 last 是该视图的有效迭代器. last 从 first 可达. position 不在范围 [first,last) 中.
  • 效果: 元素范围 [first,last) 被重新定位到紧靠 position 之前.
  • 后置条件: 没有迭代器或引用失效.
  • 复杂度: 常数.
  • 异常安全性: 不抛出异常.
序列化

视图本身不能被序列化, 只能作为它们所嵌入的 bimap 的一部分被序列化. 在描述与 vector_of 视图相关的关于其嵌入容器序列化的额外前置条件和保证时, 我们使用 bimap 序列化一节中定义的概念.

操作: 将一个 bimap b 保存到输出档案 (XML 档案) ar.

  • 要求: 除容器所施加的要求之外, 没有额外要求.

操作: 从输入档案 (XML 档案) ar 加载一个 bimap b’.

  • 要求: 除容器所施加的要求之外, 没有额外要求.
  • 后置条件: 加载成功时, [begin(), end()) 的每个元素都是 [m.get<i>().begin(), m.get<i>().end()) 中对应元素的恢复副本, 其中 i 是 vector_of 视图在容器中的位置.

操作: 将一个 iterator 或 const_iterator it 保存到输出档案 (XML 档案) ar.

  • 要求: it 是该视图的一个有效迭代器. 关联的 bimap 此前已被保存.

操作: 从输入档案 (XML 档案) ar 加载一个 iterator 或 const_iterator it’.

  • 后置条件: 加载成功时, 如果 it 原先是可解引用的, 则 *it’ 是 *it 的恢复副本; 否则 it’==end().
  • 注释: 允许 it 是一个 const_iterator, 而恢复出来的 it’ 是一个 iterator, 或者反过来.
