解读双向映射

解读双向映射的一种方式是把它看作两个数据集合之间的函数, 我们把它们称为左侧集合和右侧集合. 这个 bimap 中的一个元素是左集合的一个元素与右集合的一个元素之间的关系. 两个集合的类型决定了 bimap 的行为. 我们可以从左侧查看存储的数据, 把它看作左集合的键与右集合数据之间的映射; 也可以从右侧查看, 把它看作右集合的键与左集合数据之间的映射.

Bimap 映射框架

Boost.Bimap 的设计基于 STL, 并以自然的方式扩展了这一框架. 下图展示了新的情形.

注意, 现在 std::maps 是 Boost.Bimap 容器的一个特例, 其中你只能查看关系的一侧, 并且只能控制其中一个集合的约束. Boost.Bimap 允许用户从三个视角查看关系. 你可以从一侧查看, 得到一个 std::map 兼容的容器; 或者你可以直接把关系作为一个整体来操作.

下一张图展示了 bimap 的关系和 pair 的布局. 它就是 一分钟教程 中的那张图

bimap 的 pair 与标准 pair 签名兼容, 但又与它们不同. 正如你将在其他章节看到的, 它们可以用用户自定义名称加标签, 并且可以附加额外的信息. 你可以直接从 std::pairs 转换为 bimap 的 pair, 但不提供反向转换. 这意味着你可以使用像 std::copy 这样的算法, 从 like std::map 容器向 bimap 插入元素, 或者使用 std::make_pair 来添加新元素. 不过, 最好使用 bm.left.insert( bm_type::left_value_type(f,s) ) 而不是 bm.insert( std::make_pair(f,s) ), 以避免对每个类型额外调用一次拷贝构造函数.

注释

你必须使用对视图的引用, 而不是直接使用视图对象. 视图不能脱离它们所属的容器被构造为独立对象, 因此下面这样:

// Wrong: we forgot the & after bm_type::left_type
bm_type::left_map lm = bm.left;

无法编译, 因为它试图构造视图对象 lm. 这是用户代码中常见的错误来源.

template< class Map, class CompatibleKey, class CompatibleData >
void use_it( Map & m,
             const CompatibleKey  & key,
             const CompatibleData & data )
{
    typedef typename Map::value_type value_type;
    typedef typename Map::const_iterator const_iterator;

    m.insert( value_type(key,data) );
    const_iterator iter = m.find(key);
    if( iter != m.end() )
    {
        assert( iter->first  == key  );
        assert( iter->second == data );

        std::cout << iter->first << " --> " << iter->second;
    }
    m.erase(key);
}

int main()
{
    typedef bimap< set_of<std::string>, set_of<int> > bimap_type;
    bimap_type bm;

    // Standard map
    {
        typedef std::map< std::string, int > map_type;
        map_type m;

        use_it( m, "one", 1 );
    }

    // Left map view
    {
        typedef bimap_type::left_map map_type;
        map_type & m = bm.left;

        use_it( m, "one", 1 );
    }

    // Reverse standard map
    {
        typedef std::map< int, std::string > reverse_map_type;
        reverse_map_type rm;

        use_it( rm, 1, "one" );
    }

    // Right map view
    {
        typedef bimap_type::right_map reverse_map_type;
        reverse_map_type & rm = bm.right;

        use_it( rm, 1, "one" );
    }

    return 0;
}
