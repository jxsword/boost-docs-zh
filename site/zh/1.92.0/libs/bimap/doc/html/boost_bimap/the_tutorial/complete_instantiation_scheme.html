完整的实例化方案

总而言之, 这就是完整的实例化方案.

typedef bimap
<
    LeftCollectionType, RightCollectionType

    [ , SetTypeOfRelation  ]  // Default to left_based
    [ , with_info< Info >  ]  // Default to no info
    [ , Allocator          ]  // Default to std::allocator<>

> bm;

{Side}CollectionType 可以直接是一个类型. 其默认值为 set_of<Type>, 也可以是一个 {CollectionType}_of<Type> 规范. 此外, 这两个参数的类型可以加标签, 以指定用户自定义名称来代替通常的 member_at::-Side- 标签.

第一个参数可能的用法如下:

bimap< Type, R >
  • 左侧类型: Type
  • 左侧集合类型: set_of< Type >
  • 左侧标签: member_at::left 
bimap< {CollectionType}_of< Type >, R >
  • 左侧类型: Type
  • 左侧集合类型: {CollectionType}_of< LeftType >
  • 左侧标签: member_at::left 
bimap< tagged< Type, Tag >, R >
  • 左侧类型: Type
  • 左侧集合类型: set_of< LeftType >
  • 左侧标签: Tag 
bimap< {CollectionType}_of< tagged< Type, Tag > >, R >
  • 左侧类型: Type
  • 左侧集合类型: {CollectionType}_of< LeftType >
  • 左侧标签: Tag

第二个参数也有相同的选项.

最后三个参数用于指定关系的集合类型、信息成员和分配器类型.

如果你想在依赖 CollectionTypeOfRelation 默认值的同时指定自定义分配器类型, 只需简单写下 bimap<LeftKeyType, RightKeyType, Allocator> 即可. Boost.Bimap 的内部机制会检测到此处的第三个参数不是指关系类型, 而是指分配器.

以下是实例化 bimap 最后三个参数的可能方式. 你可以省略其中某些参数, 但必须遵守顺序.

bimap< L, R >
  • set_of_relation_type: 基于左侧键类型
  • info: 无信息
  • allocator: std::allocator 
bimap< L, R ,SetOfRelationType>
  • set_of_relation_type: SetOfRelationType
  • info: 无信息
  • allocator: std::allocator 
bimap< L, R , SetOfRelationType, with_info<Info> >
  • set_of_relation_type: SetOfRelationType
  • info: Info
  • allocator: std::allocator 
bimap< L, R , SetOfRelationType, with_info<Info>, Allocator>
  • set_of_relation_type: SetOfRelationType
  • info: Info
  • allocator: Allocator 
bimap< L, R , SetOfRelationType, Allocator>
  • set_of_relation_type: SetOfRelationType
  • info: 无信息
  • allocator: Allocator 
bimap< L, R , with_info<Info> >
  • set_of_relation_type: 基于左侧键类型
  • info: Info
  • allocator: std::allocator 
bimap< L, R , with_info<Info>, Allocator>
  • set_of_relation_type: 基于左侧键类型
  • allocator: Allocator 
bimap< L, R , Allocator>
  • set_of_relation_type: 基于左侧键类型
  • info: 无信息
  • allocator: Allocator
