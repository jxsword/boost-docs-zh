VS 7.1

如果一个 .cpp 文件使用了超过四个不同的 bimap, 编译器会耗尽符号并报内部编译器错误. MSDN 上的官方解决方案是将 .cpp 拆分为多个文件, 或者升级你的编译器.

VS 8.0

VC++ 8.0 会对某些标准库和 API 函数的使用发出警告, 这些函数一旦误用可能导致缓冲区溢出或其他安全问题. 参见 http://msdn.microsoft.com/msdnmag/issues/05/05/SafeCandC/default.aspx 但警告的措辞具有误导性且令人不安: 并不存在可移植的替代函数, 而且 VC++ 8.0 自己的库也在使用这些函数. 要关闭这些警告, 请在 .cpp 文件的开头添加如下定义:

#define _CRT_SECURE_NO_DEPRECATE
#define _SCL_SECURE_NO_DEPRECATE
