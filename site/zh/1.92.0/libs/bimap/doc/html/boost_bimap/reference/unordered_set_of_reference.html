集合类型规范符 unordered_set_of 与 unordered_multiset_of

这些集合类型规范符分别允许创建不带重复元素和带重复元素的集合视图. set_of 和 multiset_of 的语法一致, 因此我们将它们分组描述.

unordered_[multi]set_of 集合视图是对 bimap 中所含底层元素堆的一个 tr1::unordered[multi]set 签名兼容接口.

unordered_[multi]set_of 视图的接口和语义按照 C++ 标准库技术报告 (C++ Standard Library Technical Report) (即所谓的 TR1) 中给出的无序关联容器提案进行建模. 一个 unordered_[multi]set_of 视图根据给定的 Hash 函数对象——它返回键的哈希值——以及充当 Key 类型值上等价关系的二元谓词 Pred 来特化.

有两种变体: unordered_set_of 不允许重复元素 (相对于其关联的比较谓词) , 而 unordered_multiset_of 接受这些重复元素. 这两个变体的接口在很大程度上相同, 因此将它们一起编写文档, 并在存在差异之处明确注明.

如果你从某一侧看这个 bimap, 你将使用一个 map 视图; 如果你把它作为一个整体来看, 你将使用一个集合视图.

除非另有说明, unordered_[multi]set_of 视图 (无论唯一还是非唯一) 都是 Unordered Associative Container 的模型. 在所有情况下, 迭代器和对元素的引用的有效性都得到保持. 有时, 所提供的异常安全保证实际上比扩展草案要求的更强. 我们只提供那些在所建模概念中不存在、或与无序关联容器的要求不完全相符的类型和操作的描述.

复杂度签名

在这里以及在 unordered_[multi]set_of 视图的操作描述中, 我们采用 复杂度签名一节 中概述的方案. unordered_[multi]set_of 视图的复杂度签名是:

  • 拷贝: c(n) = n * log(n),
  • 插入: 平均情况 i(n) = 1 (常数时间) , 最坏情况 i(n) = n,
  • 提示插入: 平均情况 h(n) = 1 (常数时间) , 最坏情况 h(n) = n,
  • 删除: 平均情况 d(n) = 1 (常数时间) , 最坏情况 d(n) = n,
  • 替换:
    • 如果新元素的键与原来的等价, 则为 r(n) = 1 (常数时间) ,
    • 否则, 平均情况为 r(n) = 1 (常数时间) , 最坏情况为 r(n) = n,
  • 修改: 平均情况 m(n) = 1 (常数时间) , 最坏情况 m(n) = n.
实例化类型

unordered_[multi]set_of 视图在 bimap 内部实例化, 通过集合类型规范符和 bimap 本身来指定. 实例化依赖于以下类型:

  • Value 来自 bimap,
  • Allocator 来自 bimap,
  • Hash 来自集合类型规范符,
  • Pred 来自集合类型规范符.

Hash 是 一元函数 (Unary Function) , 接受单个 key_type 类型的参数并返回 std::size_t 类型的值, 取值范围为 [0, std::numeric_limits<std::size_t>::max()). Pred 是 二元谓词 (Binary Predicate) , 在 key_type 的元素上诱导出一个等价关系. 要求 Hash 对象对在 Pred 下等价的键返回相同的值.

const_iterator
local_iterator

这些类型是 前向迭代器 (Forward Iterator) 的模型.

构造函数、拷贝与赋值

正如概念一节所解释的, 视图没有公共构造函数或析构函数. 另一方面, 提供了赋值. 构造完成后, max_load_factor() 为 1.0.

this_type & operator=(const this_type & x);
  • 效果: a = b; 其中 a 和 b 分别是 bimap 对象, *this 和 x 分别属于它们.
  • 返回: *this.
修改器 
std::pair<iterator,bool> insert(const value_type & x);
  • 效果: 把 x 插入到该视图所属的 bimap 中, 如果
    • 该视图是非唯一的, 或者不存在具有等价键的其他元素,
    • 并且 bimap 的所有其他视图都允许该插入.
  • 返回: 返回值是一个 pair p. p.second 为 true 当且仅当插入确实发生. 插入成功时, p.first 指向被插入的元素; 否则, p.first 指向导致插入被禁止的元素. 注意, 可能有不止一个元素导致插入不被允许.
  • 复杂度: O(I(n)).
  • 异常安全性: 强保证.
iterator insert(iterator position, const value_type & x);
  • 要求: position 是该视图的一个有效迭代器.
  • 效果: position 被用作提示以提高操作的效率. 把 x 插入到该视图所属的 bimap 中, 如果
    • 该视图是非唯一的, 或者不存在具有等价键的其他元素,
    • 并且 bimap 的所有其他视图都允许该插入.
  • 返回: 插入成功时, 返回指向新插入元素的迭代器. 否则, 返回指向导致插入被禁止的元素的迭代器. 注意, 可能有不止一个元素导致插入不被允许.
  • 复杂度: O(H(n)).
  • 异常安全性: 强保证.
template< class InputIterator>
void insert(InputIterator first, InputIterator last);
  • 要求: InputIterator 是 输入迭代器 (Input Iterator) 的一个模型, 元素类型为 value_type. first 和 last 不是该视图所属的 bimap 的任何视图中的迭代器. last 从 first 可达.
  • 效果: iterator hint = end(); while(first != last) hint = insert(hint, *first++);
  • 复杂度: O(m*H(n+m)), 其中 m 是 [first, last) 中的元素个数.
  • 异常安全性: 基本保证.
iterator erase(iterator position);
  • 要求: position 是该视图的一个有效可解引用 iterator.
  • 效果: 删除 position 所指向的元素.
  • 返回: 一个 iterator, 指向紧随被删除元素之后的元素, 或者 end() (如果不存在这样的元素) .
  • 复杂度: O(D(n)).
  • 异常安全性: 不抛出异常.
size_type erase(const key_type & x);
  • 效果: 删除键与 x 等价的所有元素.
  • 返回: 被删除元素的个数.
  • 复杂度: 平均情况 O(1 + m*D(n)), 最坏情况 O(n + m*D(n)), 其中 m 是被删除元素的个数.
  • 异常安全性: 基本保证.
iterator erase(iterator first, iterator last);
  • 要求: [first,last) 是该视图的一个有效范围.
  • 效果: 删除 [first,last) 中的元素.
  • 返回: last.
  • 复杂度: O(m*D(n)), 其中 m 是 [first,last) 中的元素个数.
  • 异常安全性: 不抛出异常.
bool replace(iterator position, const value_type & x);
  • 要求: position 是该视图的一个有效可解引用 iterator.
  • 效果: 把值 x 赋给 position 所指向的元素——该元素属于该视图所属的 bimap, 前提是: 对于值 x,
    • 该视图是非唯一的, 或者不存在具有等价键的其他元素 (*position 可能除外) ,
    • 并且 bimap 的所有其他视图都允许该替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该视图所属的 bimap 保持其原始状态.
template< class CompatibleKey >
bool replace_key(iterator position, const CompatibleKey & x);
  • 要求: position 是该集合视图的一个有效可解引用迭代器. CompatibleKey 可以赋值给 key_type.
  • 效果: 把值 x 赋给 e.first, 其中 e 是 position 所指向的元素——它属于该集合视图所属的 bimap, 前提是
    • 该 map 视图是非唯一的, 或者不存在具有等价键的其他元素 (*position 可能除外) ,
    • 并且 bimap 的所有其他视图都允许该替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该集合视图所属的 bimap 保持其原始状态.
template< class CompatibleData >
bool replace_data(iterator position, const CompatibleData & x);
  • 要求: position 是该集合视图的一个有效可解引用迭代器. CompatibleKey 可以赋值给 mapped_type.
  • 效果: 把值 x 赋给 e.second, 其中 e 是 position 所指向的元素——它属于该集合视图所属的 bimap, 前提是
    • 该 map 视图是非唯一的, 或者不存在具有等价键的其他元素 (*position 可能除外) ,
    • 并且 bimap 的所有其他视图都允许该替换.
  • 后置条件: 在所有情况下, position 的有效性都得到保持.
  • 返回: true 如果替换发生了, false 否则.
  • 复杂度: O(R(n)).
  • 异常安全性: 强保证. 如果某个用户提供的操作抛出异常, 该集合视图所属的 bimap 保持其原始状态.
template< class KeyModifier >
bool modify_key(iterator position, KeyModifier mod);
  • 要求: KeyModifier 是 一元函数 (Unary Function) 的一个模型, 接受类型为 key_type& 的参数; position 是该视图的一个有效可解引用迭代器.
  • 效果: 调用 mod(e.first), 其中 e 是 position 所指向的元素, 并把 *position 重新排列到 bimap 的所有视图中. 如果重新排列失败, 该元素被擦除. 重新排列在以下情况下成功:
    • 该 map 视图是非唯一的, 或者不存在具有等价键的其他元素,
    • 并且 bimap 的所有其他视图都允许该重新排列.
  • 后置条件: 如果操作成功, position 的有效性得到保持.
  • 返回: true 如果操作成功, false 否则.
  • 复杂度: O(M(n)).
  • 异常安全性: 基本保证. 如果某个用户提供的操作 (mod 本身可能除外) 抛出异常, position 所指向的元素将被擦除.
  • 注释: 仅为 map 视图提供.
template< class DataModifier >
bool modify_data(iterator position, DataModifier mod);
  • 要求: DataModifier 是 一元函数 (Unary Function) 的一个模型, 接受类型为 mapped_type& 的参数; position 是该视图的一个有效可解引用迭代器.
  • 效果: 调用 mod(e.second), 其中 e 是 position 所指向的元素, 并把 *position 重新排列到 bimap 的所有视图中. 如果重新排列失败, 该元素被擦除. 重新排列在以下情况下成功:
    • 相对的 map 视图是非唯一的, 或者该视图中不存在具有等价键的其他元素,
    • 并且 bimap 的所有其他视图都允许该重新排列.
  • 后置条件: 如果操作成功, position 的有效性得到保持.
  • 返回: true 如果操作成功, false 否则.
  • 复杂度: O(M(n)).
  • 异常安全性: 基本保证. 如果某个用户提供的操作 (mod 本身可能除外) 抛出异常, position 所指向的元素将被擦除.
  • 注释: 仅为 map 视图提供.
查找

unordered_[multi]set_of 视图提供无序关联容器所要求的完整查找功能, 即 find、count 和 equal_range. 此外, 这些成员函数被模板化以允许非标准参数, 从而扩展了允许的查找操作类型. 调用查找成员函数时允许的参数类型由以下概念定义.

类型 CompatibleKey 被称为 兼容键 (相对于 (Hash, Pred)) , 如果 (CompatibleKey, Hash, Pred) 是 (Hash, Pred) 的一个兼容扩展. 这意味着 Hash 和 Pred 接受类型为 CompatibleKey 的参数——这通常意味着它们各自对应的 operator() 成员函数有多个重载.

template< class CompatibleKey >
iterator find(const CompatibleKey & x);

template< class CompatibleKey >
const_iterator find(const CompatibleKey & x) const;
  • 效果: 返回一个指向键与 x 等价的元素的指针, 或者——如果这样的元素不存在——返回 end().
  • 复杂度: 平均情况 O(1) (常数时间) , 最坏情况 O(n).
template< class CompatibleKey >
size_type count(const CompatibleKey & x) const;
  • 效果: 返回键与 x 等价的元素个数.
  • 复杂度: 平均情况 O(count(x)), 最坏情况 O(n).
template< class CompatibleKey >
std::pair<iterator,iterator>
    equal_range(const CompatibleKey & x);

template< class CompatibleKey >
std::pair<const_iterator,const_iterator>
    equal_range(const CompatibleKey & x) const;
  • 效果: 返回一个包含所有键与 x 等价的元素 (且仅包含这些元素) 的范围.
  • 复杂度: 平均情况 O(count(x)), 最坏情况 O(n).
at()、info_at() 和 operator[] —— 仅 set_of 
template< class CompatibleKey >
const mapped_type & at(const CompatibleKey & k) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回 mapped_type 类型的引用, 该引用与 k 相关联; 如果这样的键不存在, 则抛出 std::out_of_range.
  • 复杂度: 平均情况 O(1) (常数时间) , 最坏情况 O(n).
  • 注释: 仅在使用 unordered_set_of 时提供.

bimap 的对称性对 operator[] 和 at() 的非 const 版本施加了一些 std::maps 中所没有的约束. 只有当另一个集合类型是可变的 (list_of、vector_of 和 unconstrained_set_of) 时才提供它们.

template< class CompatibleKey >
mapped_type & operator[](const CompatibleKey & k);
  • 要求: CompatibleKey 是 key_compare 的一个兼容键. key_type 可以从 const CompatibleKey & 构造.
  • 效果: return insert(value_type(k,mapped_type()))->second;
  • 复杂度: 如果执行了插入则为 O(I(n)); 否则: 平均情况 O(1) (常数时间) , 最坏情况 O(n).
  • 注释: 仅在使用 unordered_set_of 且另一个集合类型可变时提供.
template< class CompatibleKey >
mapped_type & at(const CompatibleKey & k);
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回 mapped_type 类型的引用, 该引用与 k 相关联; 如果这样的键不存在, 则抛出 std::out_of_range.
  • 复杂度: 平均情况 O(1) (常数时间) , 最坏情况 O(n).
  • 注释: 仅在使用 unordered_set_of 且另一个集合类型可变时提供.
template< class CompatibleKey >
info_type & info_at(const CompatibleKey & k);

template< class CompatibleKey >
const info_type & info_at(const CompatibleKey & k) const;
  • 要求: CompatibleKey 是 key_compare 的一个兼容键.
  • 效果: 返回 info_type 类型的引用, 该引用与 k 相关联; 如果这样的键不存在, 则抛出 std::out_of_range.
  • 复杂度: 平均情况 O(1) (常数时间) , 最坏情况 O(n).
  • 注释: 仅在使用 unordered_set_of 和 info_hook 时提供
哈希策略 
void rehash(size_type n);
  • 效果: 必要时增加内部桶的数量, 使得 size()/bucket_count() 不超过最大负载因子, 并且 bucket_count()>=n.
  • 后置条件: 指向所含元素的迭代器和引用的有效性得到保持.
  • 复杂度: 平均情况 O(size()), 最坏情况 O(size(n)2).
  • 异常安全性: 强保证.
序列化

视图本身不能被序列化, 只能作为它们所嵌入的 bimap 的一部分被序列化. 在描述与 unordered_[multi]set_of 视图相关的关于其嵌入容器序列化的额外前置条件和保证时, 我们使用 bimap 序列化一节中定义的概念.

操作: 将一个 bimap b 保存到输出档案 (XML 档案) ar.

  • 要求: 除容器所施加的要求之外, 没有额外要求.

操作: 从输入档案 (XML 档案) ar 加载一个 bimap b’.

  • 要求: 除一般要求外, key_eq() 必须与 m.get<i>().key_eq() 序列化兼容, 其中 i 是 unordered_[multi]set_of 视图在容器中的位置.
  • 后置条件: 加载成功时, 范围 [begin(), end()) 包含 [m.get<i>().begin(), m.get<i>().end()) 中每个元素的恢复副本, 尽管顺序不一定相同.

操作: 将一个 iterator 或 const_iterator it 保存到输出档案 (XML 档案) ar.

  • 要求: it 是该视图的一个有效 iterator. 关联的 bimap 此前已被保存.

操作: 从输入档案 (XML 档案) ar 加载一个迭代器或 const_iterator it’.

  • 后置条件: 加载成功时, 如果 it 原先是可解引用的, 则 *it’ 是 *it 的恢复副本; 否则 it’ == end().
  • 注释: 允许 it 是一个 const_iterator, 而恢复出来的 it’ 是一个 iterator, 或者反过来.

操作: 将一个 local_iterator 或 const_local_iterator it 保存到输出档案 (XML 档案) ar.

  • 要求: it 是该视图的一个有效局部迭代器. 关联的 bimap 此前已被保存.

操作: 从输入档案 (XML 档案) ar 加载一个 local_iterator 或 const_local_iterator it’.

  • 后置条件: 加载成功时, 如果 it 原先是可解引用的, 则 *it’ 是 *it 的恢复副本; 如果 it 原先是 m.get<i>().end(n) (对某个 n) , 则 it’ == m’.get<i>().end(n) (其中 b 是原来的 bimap, b’ 是其恢复副本, 而 i 是该索引的序号. )
  • 注释: 允许 it 是一个 const_local_iterator, 而恢复出来的 it’ 是一个 local_iterator, 或者反过来.
