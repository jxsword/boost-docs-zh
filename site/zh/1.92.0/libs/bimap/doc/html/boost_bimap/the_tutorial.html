路线图

  1. Boost.Bimap 是直观的, 因为它基于标准模板库. 不过, 为了把标准 map 扩展为双向映射, 还引入了一些新概念. 第一步是牢固掌握 bimap 框架. 第一节 (认识 bimap 框架) 旨在解释这一点.
  2. Boost.Bimap 提供的远不止一个一对一有序唯一的双向映射. 你可以控制 bimap 所表示关系的每一侧的集合类型, 从而得到一对多容器、哈希双向容器以及其他可能更适合当前任务的容器. 第二节 (控制集合类型) 解释如何用不同的集合约束来实例化 bimap.
  3. 这一节 (关系的集合类型) 解释如何使用自定义集合类型创建新类型的双向映射.
  4. 与标准 map 的差异 一节中, 我们将了解 bimap map 视图与标准 map 之间的细微差别.
  5. 有用的函数 一节提供了关于 bimap 中 STL 所没有的函数的信息.
  6. bimap 的类型可以加标签, 使每一侧可以用比 left 和 right 更贴近问题的名称来访问. 这带来更易读、自文档化的代码. 第四节 (带用户自定义名称的 bimap) 展示如何使用这一特性.
  7. bimap 映射框架允许禁用 bimap 的某个视图, 标准映射容器作为其特例. 非约束集合 一节解释它们如何工作.
  8. 附加信息 一节解释如何把信息附加到 bimap 的每个关系上.
  9. 最后一节 (完整的实例化方案) 总结了 bimap 的实例化, 并解释如何更改要使用的分配器类型.
