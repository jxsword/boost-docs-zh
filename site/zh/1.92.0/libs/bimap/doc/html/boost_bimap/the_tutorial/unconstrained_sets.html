非约束集合

非约束集合允许用户禁用 bimap 的某个视图. 这样做使 bimap 的操作执行得更快, 并减少内存消耗. 这把单向映射作为一种特例包含进来, 从而完善了双向映射框架.

出于以下原因, 非约束集合是有用的:

  • bimap 类型比其标准对应物有更强的保证, 并且包含一些标准所没有的有用函数 (replace、modify) .
  • 你可以把这个映射看作关系的集合.
  • 使用这种 map 使代码非常易于扩展. 如果在开发过程中的某个时刻出现了从映射右侧进行搜索的需求, 唯一需要修改的就是 typedef.

给定这个 bimap 实例,

typedef bimap< std::string, unconstrained_set_of<int> > bm_type;
typedef bm_type::left_map map_type;

bm_type bm;
map_type & m = bm.left;

或者这个标准 map 实例

typedef std::map< std::string, int > map_type;

map_type m;

下面的代码片段是有效的

m["one"] = 1;

assert( m.find("one") != m.end() );

for( map_type::iterator i = m.begin(), iend = m.end(); i != iend; ++i )
{
    ++(i->second);
}

m.erase("one");

bimap 的右侧集合是可变的, 因此它的元素可以使用迭代器修改.

但使用 bimap 有一些好处

typedef map_type::const_iterator const_iterator;
typedef std::pair<const_iterator,const_iterator> const_range;

const_range r = m.range( "one" <= _key, _key <= "two" );
for( const_iterator i = r.first; i != r.second; ++i )
{
    std::cout << i->first << "-->" << i->second << std::endl;
}

m.modify_key( m.begin(), _key = "1" );

这个范围是 BidirectionalRange 的一个模型. 更多信息请阅读 Boost.Range 的文档.
