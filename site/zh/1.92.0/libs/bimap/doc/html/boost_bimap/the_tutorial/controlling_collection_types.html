选择的自由

如前所述, 在 STL map 中, 你只能控制其中一个集合的约束, 即你正在查看的那个. 在 Boost.Bimap 中, 你可以控制两者, 而且和使用 STL 一样简单.

思路是使用与标准中相同的约束名称. 如果你不指定集合类型, Boost.Bimap 会假定该集合是 set. 使用自定义集合类型实例化 bimap 如下所示:

typedef bimap< CollectionType_of<A>, CollectionType_of<B> > bm_type;

下面是所有受支持集合类型的清单.

表 1.2. 键类型集合

哈希、唯一

list_of 和 vector_of map 视图不与任何现有的 STL 关联容器相关联. 它们是非排序关联容器的两个例子. unconstrained_set_of 允许用户忽略某个视图. 这一点稍后解释.

集合类型的选择会影响你可以对 bimap 每一侧执行的可能操作以及每项操作所需的时间. 如果我们有:

typedef bimap< CollectionType_of<A>, CollectionType_of<B> > bm_type;
bm_type bm;

下面描述由此得到的双向映射的各个 map 视图.

  • bm.left 与 LeftMapType<A,B> 签名兼容
  • bm.right 与 RightMapType<B,A> 签名兼容

配置参数

每个集合类型模板都有不同的参数来控制其行为. 例如, 在 set_of 规范中, 你可以传入一个比较两种类型的 Functor 类型. 所有这些参数与标准库容器的参数完全相同, 只是分配器类型除外. 稍后你将学到如何为 bimap 更改分配器.

下表列出了每种集合类型各参数的含义.

name

附加参数

set_of<T,KeyComp>

multiset_of<T,KeyComp>

KeyComp 是一个用小于运算符比较两种类型的 Functor. 默认情况下为 std::less<T>.

unordered_set_of<T,HashFunctor,EqualKey>

unordered_multiset_of<T,HashFunctor,EqualKey>

HashFunctor 把一个 T 对象转换为一个 std::size_t 值. 默认为 boost::hash<T>.

EqualKey 是一个测试两种类型是否相等的 Functor. 默认情况下, 相等运算符为 std::equal_to<T>.

list_of<T>

没有附加参数.

vector_of<T>

没有附加参数.

unconstrained_set_of<T>

没有附加参数.

示例

各国人口

我们想存储各国人口. 要求如下:

  1. 获取按人口递减排序的国家列表.
  2. 给定一个国家, 获取其人口.

让我们创建合适的 bimap.

typedef bimap<

    unordered_set_of< std::string >,
    multiset_of< long, std::greater<long> >

> populations_bimap;

首先, 国家名称是唯一标识符, 而两个国家可能有相同的人口. 这就是我们为人口选择 multiset_of 的原因.

对人口使用 multiset_of 使我们可以对数据进行迭代. 由于按名称排序列出国家不是必需的, 我们可以使用允许常数时间查找的 unordered_set_of.

现在我们在一个完整的例子中使用它

转到源代码 

typedef bimap<

    unordered_set_of< std::string >,
    multiset_of< long, std::greater<long> >

> population_bimap;

typedef population_bimap::value_type population;

population_bimap pop;
pop.insert( population("China",          1321000000) );
pop.insert( population("India",          1129000000) );
pop.insert( population("United States",   301950000) );
pop.insert( population("Indonesia",       234950000) );
pop.insert( population("Brazil",          186500000) );
pop.insert( population("Pakistan",        163630000) );

std::cout << "Countries by their population:" << std::endl;

// First requirement
for( population_bimap::right_const_iterator
        i = pop.right.begin(), iend = pop.right.end();
        i != iend ; ++i )
{
    std::cout << i->second << " with " << i->first << std::endl;
}

// Second requirement
std::cout << "Population of China: " << pop.left.at("China") << std::endl;

右 map 视图的表现就像一个 std::multimap< long, std::string, std::greater<long> >. 我们可以对它进行迭代, 以要求的顺序打印结果.

左 map 视图的表现就像一个 std::unordered_map< std::string, long >. 给定国家名称, 我们可以用它以常数时间查找人口
重复计数器

我们想统计文本中每个单词的重复次数, 并按出现顺序打印它们.

转到源代码 

typedef bimap
<
    unordered_set_of< std::string >,
    list_of< counter > 

> word_counter;

typedef boost::tokenizer<boost::char_separator<char> > text_tokenizer;

std::string text=
    "Relations between data in the STL are represented with maps."
    "A map is a directed relation, by using it you are representing "
    "a mapping. In this directed relation, the first type is related to "
    "the second type but it is not true that the inverse relationship "
    "holds. This is useful in a lot of situations, but there are some "
    "relationships that are bidirectional by nature.";

// feed the text into the container
word_counter   wc;
text_tokenizer tok(text,boost::char_separator<char>(" \t\n.,;:!?'\"-"));

for( text_tokenizer::const_iterator it = tok.begin(), it_end = tok.end();
     it != it_end ; ++it )
{
    ++ wc.left[*it];
}

// list words with counters by order of appearance
for( word_counter::right_const_iterator
        wit = wc.right.begin(), wit_end = wc.right.end();

     wit != wit_end; ++wit )
{
    std::cout << wit->second << ": " << wit->first;
}

counter 是一个在构造函数中初始化为零的整数

由于右侧集合类型是 list_of, 右侧数据不用作键, 可以像标准 map 那样修改.

当我们使用左 map 视图插入元素时, 元素被插到列表的末尾.
