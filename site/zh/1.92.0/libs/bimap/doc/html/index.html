前言

说明

Boost.Bimap 是一个 C++ 双向映射库. 使用 Boost.Bimap, 你可以创建两种类型都可用作键的关联容器. 一个 bimap<X,Y> 可以被看作一个 std::map<X,Y> 和一个 std::map<Y,X> 的组合. 如果你会使用标准容器, bimap 的学习曲线几乎是平坦的. 我们把大量精力投入到将 STL 的命名方案映射到 Boost.Bimap 上. 这个库的设计与常见的 STL 容器保持一致.

影响与相关工作

Boost.Bimap 接口的设计遵循标准模板库. 它深受 Joaquin Lopez Muñoz 的 Boost.MultiIndex 库 (bimap 的心脏) 和 codeproject::bimap 库的影响.
