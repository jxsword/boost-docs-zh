Compatibility

Boost.CallableTraits 是一个用于检视、合成与分解可调用类型的 C++11 仅头文件库. Boost.CallableTraits 的目标是成为 C++17 提案 p0172 最后一段提到的"函数类型的完整类型操纵设施", 并免除针对不同函数签名编写模板特化的需要. 若可用, 还支持 C++17 的 noexcept 与事务性内存 TS.

#include <type_traits>
#include <tuple>
#include <boost/callable_traits.hpp>

namespace ct = boost::callable_traits;

// This function template helps keep our example code neat
template<typename A, typename B>
void assert_same(){ static_assert(std::is_same<A, B>::value, ""); }

// foo is a function object
struct foo {
    void operator()(int, char, float) const {}
};

int main() {

    // Use args_t to retrieve a parameter list as a std::tuple:
    assert_same<
        ct::args_t<foo>,
        std::tuple<int, char, float>
    >();

    // has_void_return lets us perform a quick check for a void return type
    static_assert(ct::has_void_return<foo>::value, "");

    // Detect C-style variadics (ellipses) in a signature (e.g. printf)
    static_assert(!ct::has_varargs<foo>::value, "");

    // pmf is a pointer-to-member function: void (foo::*)(int, char, float) const
    using pmf = decltype(&foo::operator());

    // remove_member_const_t lets you remove the const member qualifier
    assert_same<
        ct::remove_member_const_t<pmf>,
        void (foo::*)(int, char, float) /*no const!*/
    >();

    // Conversely, add_member_const_t adds a const member qualifier
    assert_same<
        pmf,
        ct::add_member_const_t<void (foo::*)(int, char, float)>
    >();

    // is_const_member_v checks for the presence of member const
    static_assert(ct::is_const_member<pmf>::value, "");
}

有了成员函数指针、函数指针、函数引用、函数对象以及 transaction_safe, 事情会变得更加复杂.

诚然, 这类晦涩特化的使用场景在普通应用代码库中几乎不存在. 即使在库代码中, 它们也极为罕见. 然而, 有少数元编程场景只能靠这种模板"轰炸"来解决. 编写、测试并维护这样的代码既繁琐又代价高昂.

Boost.CallableTraits 为这一问题提供了最终的、决定性的库级解决方案, 并完全免除了这些特化 (平台特定的调用约定除外).

关于 Boost.FunctionTypes

Boost.CallableTraits 的特性与 Boost.FunctionTypes 大量重叠. 以下是你可能更偏向 Boost.CallableTraits 的一些原因:

  1. Boost.FunctionTypes 与 Boost.MPL 序列紧密耦合, 而 Boost.CallableTraits 除标准库外没有任何依赖.
  2. Boost.CallableTraits 面向 C++11 及更高版本:
    1. Boost.CallableTraits 把函数对象/lambda 当作一等公民对待.
    2. Boost.CallableTraits 支持左值/右值引用成员限定符.
    3. Boost.CallableTraits 支持 noexcept 与 transaction_safe.
  3. Boost.FunctionTypes 不试图把所有可调用类型都归约到一个统一的、INVOKE 感知的接口中.
  4. Boost.FunctionTypes 大量依赖"标签"类型, 而 Boost.CallableTraits 则遵循 <type_traits> 的风格. 若要在 Boost.FunctionTypes 中支持 C++11 及更高版本, 将需要大量繁衍这些标签.

例如, 从某个成员函数指针类型移除成员 const 的写法, 在 Boost.FunctionTypes 库中如下:

#include <type_traits>
#include <boost/function_types/components.hpp>
#include <boost/function_types/member_function_pointer.hpp>

struct foo {
    void bar() const {}
};

using const_removed = typename boost::function_types::member_function_pointer<
    typename boost::function_types::components<decltype(&foo::bar)>::types,
    boost::function_types::non_const>::type;

static_assert(std::is_same<const_removed, void(foo::*)()>::value, "");

int main(){}

Boost.CallableTraits 让这件事更简单:

#include <type_traits>
#include <boost/callable_traits/remove_member_const.hpp>

struct foo {
        void bar() const {}
};

using const_removed = boost::callable_traits::remove_member_const_t<decltype(&foo::bar)>;

static_assert(std::is_same<const_removed, void(foo::*)()>::value, "");

int main(){}

Boost.FunctionTypes 库包含一个用于生成类型擦除接口的优秀 示例 (实现见 此处). 该示例已 被重新实现 (使用 Boost.CallableTraits), 得到一个 稍微更直观的接口.

Boost.FunctionTypes 是一个不错的库, 但其接口仍有改进空间.

Compatibility

Boost.CallableTraits 在 GCC 4.7.4+、Clang 3.5.2+、XCode 6.4+ 与 Visual Studio 2015+ 上受支持. Intel C++ 编译器不受官方支持, 尽管其 Linux 2017 版能通过少量测试用例.
