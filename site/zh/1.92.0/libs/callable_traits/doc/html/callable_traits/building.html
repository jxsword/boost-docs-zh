构建测试套件

本节包含构建和运行 Boost.CallableTraits 附带的测试用例与文档示例的说明.

注释

某些测试用例使用了在一些受支持编译器上无法工作的语言特性. 这些冲突通过条件编译把 int main(){} 替换为实际测试来"解决".

Dependencies

尽管 Boost.CallableTraits 的头文件不依赖外部依赖项, 运行完整测试套件仍需安装 3.8 或更高版本的 CMake. 构建说明假定 CMake 与 Git 都在你的环境 PATH 中可用. 同时也支持 Boost.Build.

Linux/OSX - 克隆并运行测试套件

打开一个 shell 并输入以下命令:

git clone http://github.com/boostorg/callable_traits
cd callable_traits
mkdir build
cd build
cmake .. -DCMAKE_CXX_COMPILER=/path/to/compiler
make check

Windows - 克隆并运行测试套件

注释

Cygwin 与 MSYS 用户请参考 Linux 一节 (你们知道自己是谁).

启动 cmd.exe 并输入以下命令:

git clone http://github.com/boostorg/callable_traits
cd callable_traits
mkdir build
cd build
cmake ..
path\to\msbuild.exe check.vcxproj /t:build /p:Configuration=Debug /p:Platform=Win32 /v:n /nologo

要用 Clang/C2 而非 MSVC 构建, 请在 CMake 参数后附加 -TLLVM-vs2014 (或类似的支持标志). 仅当你安装了 Clang/C2 时才有效.
