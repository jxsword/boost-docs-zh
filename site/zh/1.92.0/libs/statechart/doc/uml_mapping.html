状态机

  • 定义状态机的方法是: 从 state_machine 或 asynchronous_state_machine 类模板之一派生一个类; 示例

状态

普通状态

  • 状态的定义方法是: 从 simple_state 或 state 类模板之一派生一个类; 示例
  • 状态在状态层次结构中的位置由作为 Context 模板参数传入的内容定义. 最外层状态传入它们所属的 state_machine<> 或 asynchronous_state_machine<> 子类型, 内层状态传入其直接外层状态; 示例
  • 把一个 orthogonal 类模板实例化传入其外层状态, 即可使该状态成为特定正交区域的成员; 示例

初始伪状态

  • 初始进入的状态由模板参数标识, 而不是由从初始伪状态出发的默认转换标识 (Boost.Statechart 中没有这种东西)
  • 对于 state_machine<> 和 asynchronous_state_machine<>, 初始进入的状态需要用 InitialState 模板参数指定; 示例
  • 对于 simple_state<> 和 state<>, 初始进入的内层状态可以用 InnerInitial 模板参数指定; 示例

最终伪状态

  • Boost.Statechart 中没有最终伪状态这种东西
  • 该功能用一个特殊反应 (termination<>) 和特殊反应函数 (simple_state<>::terminate()) 实现; 示例

浅历史伪状态

  • 浅历史转换目标或浅历史内层初始状态的指定工具是 shallow_history<>

深历史伪状态

  • 深历史转换目标或深历史内层初始状态可以用 deep_history<> 指定; 示例

联结点

  • Boost.Statechart 中不存在; 设计理由

动态选择点

  • Boost.Statechart 中尚不 (或暂时不) 存在; 设计理由

汇合与分叉条

  • Boost.Statechart 中不存在; 设计理由

事件

  • 事件的定义方法是: 从 event 类模板派生一个类; 示例
  • 信号事件与调用事件没有区别, 见下文

调用事件

  • 传给 state_machine<>::process_event() 的所有事件都是隐式调用事件

信号事件

  • 传给 simple_state<>::post_event() 或 fifo_scheduler<>::queue_event() 的所有事件都是隐式信号事件

时间事件

  • Boost.Statechart 中不存在
  • 时间事件可以用外部定时器模拟: 在特定状态的进入动作中启动, 在退出动作中停止. 启动定时器时, 指示它在到期时调用 fifo_scheduler<>::queue_event()

变更事件

  • Boost.Statechart 中不存在
  • 变更事件可以这样模拟: 用带 get 和 set 方法的外部包装器把要监视的变量打包起来. 每当调用 set, 包装器就投递一个相应的事件

反应

守卫

  • 守卫可以用 custom_reaction<> 中的选择语句实现; 示例

转换

  • 转换的定义方式: 用 transition<>, 或用对 simple_state<>::transit<> 的调用 (位于 custom_reaction<> 中); 示例

延迟

  • 延迟反应的定义方式: 用 deferral<>, 或用对 simple_state<>::defer_event() 的调用 (位于 custom_reaction<> 中); 示例

内部转换 (状态内反应)

  • 状态内反应的定义方式: 用 in_state_reaction<>, 或用对 simple_state<>::discard_event() 的调用, 所在之处为 custom_reaction<>

动作

进入动作

  • 状态进入动作的定义方法: 给状态类添加构造函数; 示例

退出动作

  • 状态退出动作的定义方法: 给状态类添加析构函数; 示例

转换动作

  • 转换动作的定义方法: 把引用该动作的函数指针传给 transition<> 或 simple_state<>::transit<>(); 示例

do 活动

  • Boost.Statechart 不支持
  • do 活动可以这样模拟: 用一个单独线程, 在特定状态的进入动作中启动, 在退出动作中取消 (!)
