boost::dynamic_bitset

dynamic_bitset 模板表示一个位的集合.

概要

定义于 <boost/dynamic_bitset/dynamic_bitset.hpp>

template<
    typename Block = unsigned long,
    typename AllocatorOrContainer = std::allocator<Block>>
class dynamic_bitset;

模板参数

  • Block 存储位的整数类型. 默认为 unsigned long.

  • AllocatorOrContainer 或者是一个分配器 (用于所有内部内存管理), 或者是一个 Block 的容器. 默认为 std::allocator< Block >.

所模拟的概念

DefaultConstructible, CopyConstructible, CopyAssignable, MoveConstructible, MoveAssignable, EqualityComparable, LessThanComparable.

类型要求

Block 是一个除 bool 之外的 cv 无限定无符号整数类型. AllocatorOrContainer 满足 allocator 的标准要求, 或者是至少提供双向迭代器的类容器类型.
