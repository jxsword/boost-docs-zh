Boost.DynamicBitset

Boost.DynamicBitset 是一个提供位集合的可移植库.

该集合 (dynamic_bitset) 通过 operator[] 提供对单个位的值的访问, 并提供所有可应用于内建整数的位运算符, 例如 operator& 和 operator<<. 位的数量可以在运行期改变.

dynamic_bitset 与 std::bitset 几乎完全相同. 区别在于 dynamic_bitset 的大小 (位的数量) 可以在运行期改变, 而 std::bitset 的大小则通过一个整数模板参数在编译期指定.

dynamic_bitset 旨在解决的主要问题是表示一个有限集合的子集. 每个位表示有限集合的一个元素是否在该子集中. 因此, dynamic_bitset 的位运算, 如 operator& 和 operator|, 对应于集合运算, 如交集和并集.

定义

每个位表示布尔值 true 或 false (1 或 0). 置位 (set) 是指把一个位赋值为 1. 清除或复位 (clear/reset) 一个位是指把它赋值为 0. 翻转 (flip) 一个位是指若其值为 0 则改为 1, 若为 1 则改为 0. 每个位都有一个非负的位置. 位集 x 包含 x.size() 个位, 每个位被赋予 [0, x.size()) 范围内的唯一位置. 位置 0 处的位称为最低有效位, 位置 size() - 1 处的位是最高有效位. 在把 dynamic_bitset 的实例转换为无符号 long n 或从其转换回来时, 位集位置 i 处的位与 (n >> i) & 1 具有相同的值.

设计理由

由于代理引用类型的存在, dynamic_bitset 不是一个 Container, 其迭代器也不满足 LegacyForwardIterator 的要求. 这意味着其迭代器无法与许多标准算法一起使用. 不过, dynamic_bitset 提供了可用于范围 (ranges) 的 C++20 迭代器.

有些人更喜欢用 "toggle" 而不是 "flip" 这个名字. 之所以选择 "flip", 是因为这是 std::bitset 中使用的名称. 事实上, dynamic_bitset 的大多数函数名都是出于这个原因而选择的.

dynamic_bitset 在违反前置条件时不会抛出异常 (在 std::bitset 中就是这样的). 而是使用 BOOST_ASSERT(). 解释请参见错误与异常处理指南. 注意, 与此一致, 成员函数的文档对会引发异常的条件不使用 "precondition" (前置条件) 一词 (C++ 标准在这种情形下使用 "requires" 一词).
