boost::to_string

把 b 的一种表示拷贝到字符串 s 中.

概要

定义于 <boost/dynamic_bitset/dynamic_bitset.hpp>

template<
    typename Block,
    typename AllocatorOrContainer,
    typename StringT>
void
to_string(
    dynamic_bitset<Block, AllocatorOrContainer> const& b,
    StringT& s);

说明

字符串中的字符位置 i 对应位位置 b.size() ‐ 1 ‐ i.

抛出

若内存耗尽, 则抛出来自 s 的分配错误.

设计理由

出于若干历史原因, 此函数不是一个接受零个参数并返回字符串的成员函数. 首先, 这一版本可能稍微更高效, 因为字符串不会被拷贝. 其次, 作为成员函数, 为了在 basic_string 的模板参数方面保持灵活性, 该成员函数将需要显式模板参数. 当时很少有 C++ 程序员熟悉显式模板参数, 而且某些 C++ 编译器不能正确处理它们.

参数

名称

说明

b

要拷贝其表示的位集.

s

要拷贝表示进去的字符串.
