类 segmented_stack

Boost.Coroutine2 支持 segmented_stack, 即栈的大小按需增长. 协程以最小栈大小创建, 并按需增长. 类 segmented_stack 满足 栈分配器概念. 与 protected_fixedsize_stack 和 fixedsize_stack 不同, 它创建按需增长的栈.

注释

分段栈目前仅 gcc 自 4.7 版与 clang 自 3.4 版起支持. 为了使用 分段栈, Boost.Context 必须以属性 segmented-stacks 构建 (例如 toolset=gcc segmented-stacks=on), 并在 b2/bjam 命令行上应用 BOOST_USE_SEGMENTED_STACKS 与 BOOST_USE_UCONTEXT.

#include <boost/coroutine2/segmented_stack.hpp>

struct segmented_stack {
    segmented_stack(std::size_t size = traits_type::default_size());

    stack_context allocate();

    void deallocate( stack_context &);
}
stack_context allocate()

前置条件:

traits_type::minimum:size() <= size 与 ! traits_type::is_unbounded() && ( traits_type::maximum:size() >= size) .

效果:

分配至少 size 字节的内存, 并把指向栈的指针及其实际大小存入 sctx. 视体系结构而定 (栈向下/向上增长), 存储的地址是栈的最高/最低地址.

void deallocate( stack_context & sctx)

前置条件:

sctx.sp 有效, traits_type::minimum:size() <= sctx.size 与 ! traits_type::is_unbounded() && ( traits_type::maximum:size() >= sctx.size) .

效果:

释放栈空间.

注释

若库按分段栈编译, 则 分段栈 是唯一可用的栈分配器.
