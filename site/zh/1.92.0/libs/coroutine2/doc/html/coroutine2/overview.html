概述

Boost.Coroutine2 为广义子例程提供模板, 允许在特定位置挂起和恢复执行. 它保存执行的局部状态, 并允许不止一次地重入子例程 (在跨函数调用保持状态时很有用).

协程可视为一种语言级构造, 提供一种特殊的控制流.

与抢占式的线程不同, coroutine 切换是协作式的 (由程序员控制切换何时发生). 内核不参与协程切换.

实现使用 Boost.Context 进行上下文切换.

要使用这里描述的类和函数, 可以包含每个类或函数说明中指定的具体头文件, 也可以包含库的主头文件:

#include <boost/coroutine2/all.hpp>

该头文件会依次包含所有其他头文件.

所有函数和类都位于命名空间 boost::coroutines2 中.

注释

本库要求 C++11!

重要

Windows 使用 fcontext_t: 关闭全局程序优化 (/GL), 并将 /EHsc 改为 /EHs (编译器假定声明为 extern "C" 的函数从不抛出 C++ 异常; /EHs 则告知编译器: 声明为 extern "C" 的函数可能抛出异常).
