实现: fcontext_t, ucontext_t 与 WinFiber

fcontext_t

实现默认使用 fcontext_t. fcontext_t 基于汇编, 并非在所有平台都可用. 它提供了远优于 ucontext_t (上下文切换所需的 CPU 周期少两个数量级) 与 WinFiber 的性能.

ucontext_t

作为替代, 可以使用 ucontext_t, 方法是以 BOOST_USE_UCONTEXT 编译并使用 b2 属性 context-impl=ucontext. ucontext_t 可能在更广泛的 POSIX 平台上可用, 但存在一些问题 (例如自 POSIX.1-2003 起已被弃用, 不符合 C99).

注释

call/cc 支持 分段栈, 但仅限于以 ucontext_t 作为实现时.

WinFiber

使用 BOOST_USE_WINFIB 与 b2 属性 context-impl=winfib 时, Win32-Fiber 将被用作 call/cc 的实现.

由于 MSDN 并未完整描述 TIB (线程信息块), 可能存在并非所有必需的 TIB 部分都被交换的情况.

注释

第一次调用 call/cc 会通过调用 ConvertThreadToFiber() 把线程转换为 Windows 纤程. 如有需要, 用户必须显式调用 ConvertFiberToThread() 以释放 ConvertThreadToFiber() 分配的资源 (例如在使用 boost.context 之后).
