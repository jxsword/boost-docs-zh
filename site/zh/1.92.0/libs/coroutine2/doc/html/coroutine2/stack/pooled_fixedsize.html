类 pooled_fixedsize_stack

Boost.Coroutine2 提供满足 栈分配器概念 的类 pooled_fixedsize_stack. 与 protected_fixedsize_stack 不同, 它不在每个栈末尾追加保护页. 内存由 boost::pool<> 在内部管理.

#include <boost/coroutine2/pooled_fixedsize_stack.hpp>

struct pooled_fixedsize_stack {
    pooled_fixedsize_stack(std::size_t size = traits_type::default_size());

    stack_context allocate();

    void deallocate( stack_context &);
}
pooled_fixedsize_stack(std::size_t stack_size, std::size_t next_size, std::size_t max_size)

前置条件:

! traits_type::is_unbounded() && ( traits_type::maximum:size() >= stack_size) 与 0 < nest_size .

效果:

分配至少 stack_size 字节的内存, 并把指向栈的指针及其实际大小存入 sctx. 视体系结构而定 (栈向下/向上增长), 存储的地址是栈的最高/最低地址. 参数 next_size 决定 *this 第一次需要分配系统内存时向系统请求的栈数量. 第三个参数 max_size 控制可为栈分配的内存上限 - 值为零表示没有上限.

stack_context allocate()

前置条件:

! traits_type::is_unbounded() && ( traits_type::maximum:size() >= size).

效果:

分配至少 size 字节的内存, 并把指向栈的指针及其实际大小存入 sctx. 视体系结构而定 (栈向下/向上增长), 存储的地址是栈的最高/最低地址.

void deallocate( stack_context & sctx)

前置条件:

sctx.sp 有效, ! traits_type::is_unbounded() && ( traits_type::maximum:size() >= sctx.size) .

效果:

释放栈空间.
