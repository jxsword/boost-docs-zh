类 stack_context

Boost.Coroutine2 提供类 stack_context, 其中将包含栈指针与栈的大小. 对于 segmented_stack, stack_context 还包含一些额外的控制结构.

struct stack_context
{
    void    *   sp;
    std::size_t size;

    // might contain additional control structures
    // for segmented stacks
}
void * sp

值:

指向栈起始位置的指针.

std::size_t size

值:

栈的实际大小.
