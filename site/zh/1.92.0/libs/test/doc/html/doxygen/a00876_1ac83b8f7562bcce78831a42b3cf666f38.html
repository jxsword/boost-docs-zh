函数模板 mismatch

boost::unit_test::utils::mismatch — 该算法在两个集合中搜索第一个不匹配位置, 并以一对迭代器返回: 第一个迭代器指向第一个集合中的不匹配位置, 第二个迭代器指向第二个集合中的位置. 该算法使用给定的谓词比较集合元素

概要

// In header: <boost/test/utils/algorithm.hpp>


template<typename InputIter1, typename InputIter2, typename Predicate> 
  std::pair< InputIter1, InputIter2 > 
  mismatch(InputIter1 first1, InputIter1 last1, InputIter2 first2, 
           InputIter2 last2, Predicate pred);

说明

参数:

first1

- 第一个集合的起始迭代器

last1

- 第一个集合的结束迭代器

first2

- 第二个集合的起始迭代器

last2

- 第二个集合的结束迭代器

pred

- 用于搜索的谓词
