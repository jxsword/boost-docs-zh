类模板 generated_by

boost::unit_test::data::monomorphic::generated_by — 生成器接口.

概要

// In header: <boost/test/data/monomorphic/generate.hpp>

template<typename Generator> 
class generated_by {
public:
  // types
  typedef Generator::sample sample;        
  typedef Generator         generator_type;

  // member classes/structs/unions

  struct iterator {

    // public member functions
    explicit iterator(Generator &);
    sample const & operator*() const;
    void operator++();
  };

  // public member functions
  explicit generated_by(Generator &&);
  generated_by(generated_by &&);
  data::size_t size() const;
  iterator begin() const;

  // public data members
  static const int arity;
};

说明

该类在生成器之上实现数据集概念. 生成器的示例包括:

  • xrange_t

  • random_t

生成器概念如下:

  • 生成的样本类型由字段 sample 给出

  • 成员函数 capacity 应当返回正在生成的集合的大小 (可能是无限的)

  • 成员函数 next 应当把生成器的状态改为下一个生成值

  • 成员函数 reset 应当把对象状态恢复到其实例化之后紧接着的状态

generated_by 公有成员函数

  1. explicit generated_by(Generator && G);
  2. generated_by(generated_by && rhs);
  3. data::size_t size() const;
    底层数据集的大小.
  4. iterator begin() const;
    指向数据集起始位置的迭代器.
