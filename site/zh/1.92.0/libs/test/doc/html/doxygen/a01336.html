类模板 small_with_tolerance

boost::math::fpc::small_with_tolerance — 用于将浮点数与 0 比较的谓词.

概要

// In header: <boost/test/tools/floating_point_comparison.hpp>

template<typename FPT> 
class small_with_tolerance {
public:
  // types
  typedef bool result_type;

  // public member functions
  explicit small_with_tolerance(FPT);
  bool operator()(FPT) const;
};

说明

用途与 boost::math::fpc::close_at_tolerance 相同, 但用于其中一个操作数为零的情况.
