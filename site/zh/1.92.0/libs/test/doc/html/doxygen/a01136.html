类模板 collection

boost::unit_test::data::monomorphic::collection — 来自前向可迭代容器 (集合) 的数据集

概要

// In header: <boost/test/data/monomorphic/collection.hpp>

template<typename C> 
class collection {
public:
  // types
  typedef col_type::value_type     sample;  
  typedef col_type::const_iterator iterator;

  // public member functions
  explicit collection(C &&);
  collection(collection &&);
  C const & col() const;
  data::size_t size() const;
  iterator begin() const;

  // public data members
  static const int arity;
};

说明

该数据集适用于任何实现前向迭代器的容器. 注意, 只有一个元素的容器将被视为单元素数据集 (singleton). 该数据集可以用 boost::unit_test::data::make 函数构造.

collection 公有成员函数

  1. explicit collection(C && col);
    构造函数消耗一个临时集合或存储一个引用.
  2. collection(collection && c);
    移动构造函数.
  3. C const & col() const;
    返回底层集合.
  4. data::size_t size() const;
    数据集接口
  5. iterator begin() const;
