头文件 <boost/test/unit_test.hpp>

单元测试框架的入口点.

该头文件应当是开始使用该框架所需包含的唯一头文件

namespace boost {
  namespace unit_test {
    int unit_test_main(init_unit_test_func init_func, int argc, char * argv);
  }
}
