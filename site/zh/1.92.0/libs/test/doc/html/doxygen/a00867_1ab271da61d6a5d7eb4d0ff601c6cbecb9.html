函数模板 xrange

boost::unit_test::data::xrange — 创建范围 (序列) 数据集.

概要

// In header: <boost/test/data/monomorphic/generators/xrange.hpp>


template<typename SampleType, typename Params> 
  monomorphic::generated_by< monomorphic::xrange_t< SampleType > > 
  xrange(Params const & params);

说明

可用的重载如下:

auto d = xrange();
auto d = xrange(end_val);
auto d = xrange(end_val, param);
auto d = xrange(begin_val, end_val);
auto d = xrange(begin_val, end_val, step_val);
auto d = xrange(param);

  • begin_val 指示序列的起点 (默认为 0).

  • end_val 是序列的终点. 如果省略, 数据集的大小为无限.

  • step_val 是序列中两个相邻元素之间的步长, 默认为 1.

  • param 是描述序列的命名参数. 接受以下参数:

    • begin: 含义相同 begin_val

    • end: 含义与 end_val 相同

    • step: 含义与 step_val 相同

返回值是一个实现数据集 API 的对象.

注释

步长不能为 null, 如果 begin_val < end_val 则应当为正, 否则为负.
