类 output_test_stream

boost::test_tools::output_test_stream — 用于简化对基于 ostream 的输出操作进行测试的类.

概要

// In header: <boost/test/tools/output_test_stream.hpp>


class output_test_stream : public wrap_stringstream::wrapped_stream {
public:

  // public member functions
  explicit output_test_stream(const_string = const_string(), bool = true, 
                              bool = true);
  ~output_test_stream();
  virtual assertion_result is_empty(bool = true);
  virtual assertion_result check_length(std::size_t, bool = true);
  virtual assertion_result is_equal(const_string, bool = true);
  virtual assertion_result match_pattern(bool = true);
  void flush();

  // protected member functions
  virtual std::string get_stream_string_representation() const;

  // private member functions
  std::size_t length();
  virtual void sync();
};

说明

output_test_stream 公有成员函数

  1. explicit output_test_stream(const_string pattern_file_name = const_string(), 
                            bool match_or_save = true, 
                            bool text_or_binary = true);
    构造函数.

    参数:

    pattern_file_name

    指示用于匹配的文件名. 如果字符串为空, 则改用标准输入或输出流 (取决于 match_or_save)

    match_or_save

    如果为 true, 则读取模式文件, 否则写入模式文件

    text_or_binary

    如果为 false, 则以二进制模式打开流. 否则以默认标志打开流, 并忽略回车符.

    		 
  2. ~output_test_stream();
  3. virtual assertion_result is_empty(bool flush_stream = true);
    检查流是否为空.

    参数:

    flush_stream

    如果为 true, 则在调用之后刷新流

    		 
  4. virtual assertion_result 
check_length(std::size_t length, bool flush_stream = true);
    检查流的长度.

    参数:

    length

    目标长度

    flush_stream

    如果为 true, 则在调用之后刷新流. 设为 false 可对相同内容进行额外的检查.

    		 
  5. virtual assertion_result is_equal(const_string arg_, bool flush_stream = true);
    对照字符串检查流的内容.

    参数:

    arg_

    目标流

    flush_stream

    如果为 true, 则在调用之后刷新流.

    		 
  6. virtual assertion_result match_pattern(bool flush_stream = true);
    对照模式文件检查流的内容.

    参数:

    flush_stream

    如果为 true, 则在调用之后刷新/重置流.

    		 
  7. void flush();
    刷新流.

output_test_stream 受保护成员函数

    返回流的字符串表示.

    可以重写此方法, 以便在匹配操作之前修改字符串.

output_test_stream 私有成员函数
