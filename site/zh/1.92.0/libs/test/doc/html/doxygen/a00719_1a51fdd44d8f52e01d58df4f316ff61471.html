宏 BOOST_TEST_DISABLE_ALT_STACK

BOOST_TEST_DISABLE_ALT_STACK — 在编译 Boost.test 框架时禁用对备用栈的支持. 当无法检测到你的编译器缺乏备用栈支持时 (例如 ESXi), 这尤其有用.

概要

// In header: <boost/test/execution_monitor.hpp>

BOOST_TEST_DISABLE_ALT_STACK
