函数模板 find_last_of

boost::unit_test::utils::find_last_of — 该算法在第一个集合中搜索最后一个属于第二个集合的元素

概要

// In header: <boost/test/utils/algorithm.hpp>


template<typename BidirectionalIterator1, typename ForwardIterator2> 
  BidirectionalIterator1 
  find_last_of(BidirectionalIterator1 first1, BidirectionalIterator1 last1, 
               ForwardIterator2 first2, ForwardIterator2 last2);

说明

参数:

first1

- 第一个集合的起始迭代器

last1

- 第一个集合的结束迭代器

first2

- 第二个集合的起始迭代器

last2

- 第二个集合的结束迭代器
