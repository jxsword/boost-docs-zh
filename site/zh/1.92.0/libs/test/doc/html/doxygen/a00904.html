类 execution_exception

boost::execution_exception — 该类用于报告在 execution_monitor 内部执行被监视函数期间发生的任何类型的失败.

概要

// In header: <boost/test/execution_monitor.hpp>


class execution_exception {
public:
  // member classes/structs/unions

  // Simple model for the location of failure in a source code.

  struct location {

    // public member functions
    explicit location(char const * = 0, size_t = 0, char const * = 0);
    explicit location(const_string, size_t = 0, char const * = 0);

    // public data members
    const_string m_file_name;    // File name. 
    size_t m_line_num;    // Line number. 
    const_string m_function;    // Function name. 
  };
  enum error_code;

  // Constructors
  execution_exception(error_code, const_string, location const &);

  // Access methods
  error_code code() const;
  const_string what() const;
  location const & where() const;
};

说明

当检测到失败时, 该类的实例会从 execution_monitor::execute 调用中抛出. 无论发生何种类型的失败, 该实例都会提供统一的捕获和报告方式.

该类的一个重要设计理由是, 在发生致命内存损坏或内存不足情况后仍应能够工作. 为此, 该类从不分配任何内存, 并假定它引用的字符串要么是某些常量, 要么位于某种持久 (预分配) 内存中.
