函数模板 tolerance

boost::test_tools::tolerance

概要

// In header: <boost/test/tools/detail/tolerance_manip.hpp>


template<typename FPT> unspecified tolerance(FPT v);

说明

容差操纵器

这些函数返回一个操纵器, 可与 BOOST_TEST 结合使用, 以指定浮点比较所使用的容差.
