类 execution_monitor

boost::execution_monitor — 函数执行监视器.

概要

// In header: <boost/test/execution_monitor.hpp>


class execution_monitor {
public:

  // public member functions
  execution_monitor();
  int execute(boost::function< int()> const &);
  void vexecute(boost::function< void()> const &);
  void erase_exception_translator(const_string);
  template<typename ExceptionType> 
    void erase_exception_translator(boost::type< ExceptionType > * = 0);

  // private member functions
  int catch_signals(boost::function< int()> const &);

  // public data members
  unit_test::readwrite_property< bool > p_catch_system_errors;  // Should monitor catch system errors. 
  unit_test::readwrite_property< bool > p_auto_start_dbg;  // Should monitor try to attach debugger in case of caught system error. 
  unit_test::readwrite_property< unsigned long int > p_timeout;  // Specifies the seconds that elapse before a timer_error occurs. 
  unit_test::readwrite_property< bool > p_use_alt_stack;  // Should monitor use alternative stack for the signal catching. 
  unit_test::readwrite_property< unsigned > p_detect_fp_exceptions;  // Should monitor try to detect hardware floating point exceptions (!= 0), and which specific exception to catch. 
};

说明

该类用于统一检测并报告多种类型的信号和异常的出现, 将各种错误归约为统一的 execution_exception 并返回给调用者.

execution_monitor 的行为可以通过与 execution_monitor 实例相关联的一组公共参数 (属性) 进行定制. 所有参数都实现为类 execution_monitor 的公共 unit_test::readwrite_property 数据成员.

execution_monitor 公有成员函数

  1. execution_monitor();
    默认构造函数初始化所有执行监视器属性.
  2. int execute(boost::function< int()> const & F);
    针对返回整数值的函数的执行监视器入口点.

    该方法在 try/catch 块内执行给定的函数 F, 还可能包含其他未指定的平台相关的错误检测代码.

    在发生未捕获的 C++ 异常、硬件或软件信号、陷阱或其他用户异常时, 该方法抛出 execution_exception.

    注释

    execute() 不将 F 返回非零值视为错误.

    参见: vexecute

    参数:

    F

    要监视的函数

    返回:

    函数调用 F() 返回的值.

    		 
  3. void vexecute(boost::function< void()> const & F);
    针对返回 void 的函数的执行监视器入口点.

    该方法在语义上与 execution_monitor::execute 相同, 但不产生任何结果码.

    参见: execute

    参数:

    F

    要监视的函数

    		 
  4. void erase_exception_translator(const_string tag);
    基于标签擦除自定义异常转换器.

    使用与转换器注册期间所用的相同标签

    参数:

    tag

    与你要擦除的转换器相关联的标签

    		 
  5. template<typename ExceptionType> 
  void erase_exception_translator(boost::type< ExceptionType > * = 0);
    基于异常类型擦除自定义异常转换器.

    tparam ExceptionType 要为其擦除转换器的异常类型

execution_monitor 私有成员函数

  1. int catch_signals(boost::function< int()> const & F);

execution_monitor 公有数据成员

  1. unit_test::readwrite_property< bool > p_catch_system_errors;

    p_catch_system_errors 属性是一个布尔标志 (默认值为 true), 指定 execution_monitor 是否应捕获系统错误/系统级异常/信号——在常规情况下 (没有 execution_monitor 时) 这些错误会导致程序崩溃. 例如, 如果希望强制生成 coredump 文件, 请将该属性设置为 false. 单元测试框架提供运行期参数 --catch_system_errors=yes 来改变被监视测试用例中的此行为.

  2. unit_test::readwrite_property< bool > p_auto_start_dbg;

    p_auto_start_dbg 属性是一个布尔标志 (默认值为 false), 指定 execution_monitor 在捕获到系统错误时是否应尝试附加调试器.

  3. unit_test::readwrite_property< unsigned long int > p_timeout;

    p_timeout 属性是被监视函数执行的整数超时 (以微秒为单位). 使用该参数监视可能存在死锁或无限循环的代码. 该特性仅在某些操作系统上可用 (尚不支持 Microsoft Windows).

  4. unit_test::readwrite_property< bool > p_use_alt_stack;

    p_use_alt_stack 属性是一个布尔标志 (默认值为 false), 指定 execution_monitor 是否应使用备用栈进行基于 sigaction 的信号捕获. 启用后, 信号会在与当前执行栈不同的栈上传递给 execution_monitor, 在执行栈被被监视函数损坏的情况下这更安全. 有关备用栈处理的更多细节, 请参阅相应的手册.

  5. unit_test::readwrite_property< unsigned > p_detect_fp_exceptions;

    p_detect_fp_exceptions 属性是一个布尔标志 (默认值为 false), 指定 execution_monitor 在支持该特性的平台上是否应为浮点异常安装硬件陷阱.
