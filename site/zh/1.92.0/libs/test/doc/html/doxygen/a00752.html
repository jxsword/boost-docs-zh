头文件 <boost/test/results_reporter.hpp>

定义测试结果报告器接口

该文件定义负责结果报告的接口. 接口以独立函数的形式呈现, 实现于命名空间 result_reporter 中

namespace boost {
  namespace unit_test {
    namespace results_reporter {
      class format;

      // report configuration
      void set_level(report_level);
      void set_stream(std::ostream &);
      void set_format(output_format);
      void set_format(results_reporter::format *);
      std::ostream & get_stream();
      void make_report(report_level l = INV_REPORT_LEVEL, 
                       test_unit_id = INV_TEST_UNIT_ID);
      void confirmation_report(test_unit_id id = INV_TEST_UNIT_ID);
      void short_report(test_unit_id id = INV_TEST_UNIT_ID);
      void detailed_report(test_unit_id id = INV_TEST_UNIT_ID);
    }
  }
}

报告配置

  1. void set_level(report_level l);
    设置报告级别.

    结果报告只有四种可能的级别:

    • 确认报告 (boost::unit_test::CONFIRMATION_REPORT). 该报告级别只产生关于测试模块通过/失败状态的简短确认消息

    • 简短报告 (boost::unit_test::SHORT_REPORT). 该报告级别为失败/通过的断言和测试单元产生简短的摘要报告.

    • 详细报告 (boost::unit_test::DETAILED_REPORT). 该报告级别为每个测试单元产生关于通过/失败断言和未捕获异常的详细报告

    • 无报告 (boost::unit_test::NO_REPORT). 该报告级别不产生结果报告. 用于作为某种持续集成框架的一部分运行的测试模块

    参数:

    l

    报告级别

    		 
  2. void set_stream(std::ostream &);
    设置结果报告的输出流.

    默认使用 std::cerr. 使用该函数设置不同的流. 框架通过引用来使用该流, 因此你需要确保流对象的生命周期超过测试主作用域.

  3. void set_format(output_format of);
    设置一种预定义格式.

    框架实现两种结果报告格式:

    • 简单人类可读格式 (boost::unit_test::OF_CLF)

    • XML 格式 (boost::unit_test::OF_XML)

    参数:

    of

    输出格式的预定义枚举值之一

    		 
  4. void set_format(results_reporter::format * f);
    设置自定义报告格式化器.

    框架接管作为参数传入的指针的所有权. 因此这应当是指向堆分配对象的指针

    参数:

    f

    指向堆分配的自定义报告格式化器类实例的指针

    		 
  5. std::ostream & get_stream();
    访问已配置的结果报告器流.

    使用该流报告关于测试模块执行的附加信息
