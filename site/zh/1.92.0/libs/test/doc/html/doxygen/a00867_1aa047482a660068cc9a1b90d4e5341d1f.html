函数 random

boost::unit_test::data::random — 返回一个无限的随机数序列.

概要

// In header: <boost/test/data/monomorphic/generators/random.hpp>


monomorphic::generated_by< monomorphic::random_t<> > random();

说明

可用的重载如下:

auto d = random();
auto d = random(begin, end);
auto d = random(params);

  • 第一个重载使用默认分布, 该分布是均匀分布, 其元素为 double 类型 (值位于 [0, 1) ).

  • 第二个重载在给定区间内生成数. 分布是均匀的 (对于实数是 [begin, end), 对于整数是 [begin, end]). 分布的类型从 begin 和 end 参数的类型推导得出.

  • 第三个重载使用 params 内的命名参数生成数, 这些参数是:

    • distribution: 所使用的分布. 在此重载中, 由于无法推导样本的类型, 样本类型为 double, 分布是 [0, 1) 内的均匀实数分布.

    • seed: 用于生成值的种子

    • engine: 随机数生成器引擎

该函数返回一个实现数据集 API 的对象.

注释

该函数仅适用于支持 C++11 的编译器.
