类型 error_code

boost::execution_exception::error_code — 这些值有时用作程序返回码. 选择这些特定值是为了避免与常用的程序返回码冲突: 小于 100 的值通常由用户指定, 大于 255 的值有时用于报告系统错误. 值之间的间隙允许有序扩展.

概要

// In header: <boost/test/execution_monitor.hpp>


enum error_code { no_error = 0, user_error = 200, cpp_exception_error = 205, 
                  system_error = 210, timeout_error = 215, 
                  user_fatal_error = 220, system_fatal_error = 225 };

说明

注释

(1) 只有未捕获的 C++ 异常才被视为错误. 如果函数捕获了 C++ 异常, 它永远不会到达 execution_monitor.

由实现决定什么是 system_fatal_error、什么只是 system_exception. 致命错误极有可能已损坏机器状态 (如栈溢出或寻址异常), 以至于继续执行是不合理的.

注释

(2) 这些错误包括 Unix 信号和 Windows 结构化异常. 它们通常由硬件陷阱引发.

no_error
仅为完整性而设; 从不返回
user_error
用户报告的非致命错误
cpp_exception_error
见上文注 (1)
system_error
见上文注 (2)
timeout_error
仅在某些平台上可检测
user_fatal_error
用户报告的致命错误
system_fatal_error
见上文注 (2)
