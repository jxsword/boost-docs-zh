函数模板 replace_all_occurrences_with_wildcards

boost::unit_test::utils::replace_all_occurrences_with_wildcards — 该算法将一个带有基本通配符的字符串的所有出现替换为另一个字符串 (后者也可以包含通配符).

概要

// In header: <boost/test/utils/algorithm.hpp>


template<typename StringClass, typename ForwardIterator> 
  StringClass replace_all_occurrences_with_wildcards(StringClass str, 
                                                     ForwardIterator it_string_to_find, 
                                                     ForwardIterator it_string_to_find_end, 
                                                     ForwardIterator it_string_to_replace, 
                                                     ForwardIterator it_string_to_replace_end);

说明

通配符是符号 '*'. 每个字符串只支持一个唯一的通配符. 替换字符串也可以包含通配符, 此时它被视为源字符串中通配符内容的占位符. 示例:

  • 为了将 'time="some-variable-value"' 的出现替换为常量字符串, 可以使用 'time="*"' 作为要搜索的字符串, 并使用 'time="0.0"' 作为替换字符串.

  • 为了将 'file.cpp(XX)' 的出现替换为 'file.cpp:XX' (其中 XX 是要保留的变量), 可以使用 'file.cpp(*)' 作为要搜索的字符串, 并使用 'file.cpp:*' 作为替换字符串.

参数:

str

- 要变换的字符串

it_string_to_find

- 指向要替换的子串起始位置的迭代器

it_string_to_find_end

- 指向要替换的子串结束位置的迭代器

it_string_to_replace

- 指向用于替换的子串起始位置的迭代器

it_string_to_replace_end

- 指向用于替换的子串结束位置的迭代器
