结构体模板 tolerance_based

boost::math::fpc::tolerance_based — 指示类型是否可以使用容差方案进行比较.

概要

// In header: <boost/test/tools/floating_point_comparison.hpp>

template<typename T> 
struct tolerance_based : public tolerance_based_delegate::type {
};

说明

该元函数应当求值为 mpl::true_, 如果类型 T 可以使用基于容差的方法进行比较 (通常针对浮点类型).

该元函数可以进一步特化, 以声明属于浮点类型的用户类型 (例如 boost.multiprecision).
