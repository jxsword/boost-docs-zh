类模板 close_at_tolerance

boost::math::fpc::close_at_tolerance — 用于比较浮点数的谓词.

概要

// In header: <boost/test/tools/floating_point_comparison.hpp>

template<typename FPT> 
class close_at_tolerance {
public:
  // types
  typedef bool result_type;

  // public member functions
  template<typename ToleranceType> 
    explicit close_at_tolerance(ToleranceType, fpc::strength = FPC_STRONG);
  FPT fraction_tolerance() const;
  fpc::strength strength() const;
  FPT tested_rel_diff() const;
  bool operator()(FPT, FPT) const;
};

说明

该谓词用于比较浮点数. 此外, 比较会产生最大相关差值, 可用于生成详细的错误消息. 浮点数比较的方法在文档中有详细说明. 该方法由构造时给定的 boost::math::fpc::strength 选择.

该谓词不适合与 0 或无穷大进行比较.

close_at_tolerance 公有成员函数

  1. template<typename ToleranceType> 
  explicit close_at_tolerance(ToleranceType tolerance, 
                              fpc::strength fpc_strength = FPC_STRONG);
  2. FPT fraction_tolerance() const;
    返回容差.
  3. fpc::strength strength() const;
    返回比较方法.
  4. FPT tested_rel_diff() const;
    返回失败分数.
  5. bool operator()(FPT left, FPT right) const;

    比较两个浮点数 a 和 b, 使它们的“左”相对差 |a-b|/a 和/或“右”相对差 |a-b|/b 不超过指定的相对 (分数) 容差.

    失败时 tested_rel_diff 报告的内容取决于比较方法:

    • 对于 FPC_STRONG: 为两个分数的最大值

    • 对于 FPC_WEAK: 为两个分数的最小值. 其背后的理由是报告为使测试通过而需要设置的容差.

    参数:

    left

    要比较的第一个浮点数

    right

    要比较的第二个浮点数
