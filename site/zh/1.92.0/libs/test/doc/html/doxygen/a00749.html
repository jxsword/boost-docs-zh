头文件 <boost/test/unit_test_log_formatter.hpp>

定义单元测试日志格式化器接口.

你可以定义一个实现该接口的类, 并将其实例用作单元测试框架的日志格式化器

namespace boost {
  namespace unit_test {
    struct log_checkpoint_data;
    struct log_entry_data;

    class unit_test_log_formatter;
  }
}
