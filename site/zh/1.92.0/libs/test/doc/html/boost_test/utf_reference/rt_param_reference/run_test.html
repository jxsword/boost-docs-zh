run_test

参数 run_test 用于过滤测试期间要执行的测试单元. 单元测试框架 同时支持"选择过滤器" (从可用测试单元集合中选择要启用的测试单元) 与"禁用过滤器" (禁用某些测试单元). 单元测试框架 还支持在编译期启用/禁用测试单元. 这些设置确定了要运行的默认测试单元集合. 参数 run_test 用于改变该默认值. 此参数可重复, 因此必要时可指定多个过滤器. 也可以用 ':' 分隔各个过滤器, 这可用于通过环境变量 BOOST_TEST_RUN_FILTERS 过滤测试 (因为它不能像 --run_test 那样重复).

关于该参数实际应用的更多细节见测试单元过滤一节.

可接受值

String 值, 表示单个过滤器或以':'分隔的一组过滤器. 以下语法产生式描述了过滤器的语法:

filter_set    ::= (filter ':')* filter
filter        ::= relative_spec? test_set
relative_spec ::= '+' | '!'
test_set      ::= label | path
label         ::= '@' identifier
path          ::= (suite '/')? pattern_list
pattern_list  ::= (pattern ',')* pattern
suite         ::= (pattern '/')* pattern
pattern       ::= '*'? identifier '*'?
注意

上面的 pattern_list 指示由 suite 给出的同一测试套件内的测试单元. 这意味着语法 "--run_test=suite1/suite2/A,B,C" 会运行测试用例 A, B 与 C, 它们 位于 suite1/suite2 内. 若要指示多个非兄弟关系的测试单元, 可重复 --run_test 或使用 : 分隔过滤器.

关于这些值的意义见此处.

命令行语法
  • --run_test=<test unit filter spec>
  • -t <test unit filter spec>
环境变量 
BOOST_TEST_RUN_FILTERS
