虽然许多测试日志配置任务可以使用预定义的框架参数在运行期完成, 单元测试框架也提供了编译期接口. 该接口让你完全掌控记录什么、记录到哪里以及如何记录. 日志记录器的接口由单例类boost::unit_test::unit_test_log_t提供, 并可通过指向该类单例的本地文件作用域引用访问

boost::unit_test::unit_test_log

为了安装日志记录器的定制, 单元测试框架提供了BOOST_TEST_GLOBAL_CONFIGURATION设施, 其行为类似于全局夹具.
