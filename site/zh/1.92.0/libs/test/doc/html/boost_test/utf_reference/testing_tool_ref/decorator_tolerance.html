tolerance(装饰器) 

template <typename FPT>
  tolerance(FPT eps);

template <typename FPT>
  tolerance(test_tools::fpc::percent_tolerance_t<FPT> eps)

装饰器 tolerance 为被装饰测试单元中的浮点类型 FTP 指定默认比较容差. 默认容差只适用于特定类型, 因此在比较不同浮点类型时, 提供多个 tolerance 装饰器是有意义的. 带 percent_tolerance 的变体使用值

eps / 100

作为容差.

注释

更多细节见 浮点比较 一节.

示例: 装饰器 tolerance

代码

 
#define BOOST_TEST_MODULE decorator_13
#include <boost/test/included/unit_test.hpp>

namespace utf = boost::unit_test;
namespace fpc = boost::test_tools::fpc;

BOOST_AUTO_TEST_CASE(test1, * utf::tolerance(0.0005))
{
  BOOST_TEST( 0.001 == 0.000 );
  BOOST_TEST( 1.100 == 1.101 );
}

BOOST_AUTO_TEST_CASE(test2, * utf::tolerance(0.005))
{
  BOOST_TEST( 0.001 == 0.000 );
  BOOST_TEST( 1.100 == 1.101 );
}

BOOST_AUTO_TEST_CASE(test3, * utf::tolerance(0.05F))
{
  BOOST_TEST( 0.001 == 0.000 );
  BOOST_TEST( 1.100 == 1.101 );
}

BOOST_AUTO_TEST_CASE(test4,
  * utf::tolerance(fpc::percent_tolerance(0.05)))
{
  BOOST_TEST( 0.001 == 0.000 );
  BOOST_TEST( 1.100 == 1.101 );
}

BOOST_AUTO_TEST_CASE(test5,
  * utf::tolerance(fpc::percent_tolerance(0.5)))
{
  BOOST_TEST( 0.001 == 0.000 );
  BOOST_TEST( 1.100 == 1.101 );
}

在上面的示例中, 在 test1 中, 对 double 的检查失败, 因为它们相差超过了 double 的容差所规定的范围. 在 test2 中, double 的容差更大, 因此检查成功. 在 test3 中, 我们只为类型 float 指定容差, 由于检查使用的是类型 double, 指定的容差并不适用. test4 中的容差等同于 test1 中的容差, 因此其检查同样失败. test5 中的容差等同于 test2 中的容差, 因此其检查同样成功.
