BOOST_<level>_CLOSE_FRACTION 

BOOST_WARN_CLOSE_FRACTION(left, right, tolerance);
BOOST_CHECK_CLOSE_FRACTION(left, right, tolerance);
BOOST_REQUIRE_CLOSE_FRACTION(left, right, tolerance);

这些工具用于依据谓词所定义的强关系检查接近程度

check_is_close(left, right, tolerance)

要检查弱关系, 请使用 BOOST_<level>_PREDICATE 工具族, 并显式调用 check_is_close.

第一个参数是 左侧被比较的值. 第二个参数是 右侧被比较的值. 最后的第三个参数以 被比较绝对值的分数形式定义比较的容差.

注释

要求左参数和右参数具有相同的浮点类型. 需要显式解决任何类型不匹配的问题, 以选择用于比较的类型.

注释

当按前几节所述包含 单元测试框架 时, 浮点比较工具会被自动添加. 这些工具实现在头文件 boost/test/tools/floating_point_comparison.hpp 中.

示例: BOOST_<level>_CLOSE_FRACTION 用法

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>
#include <boost/test/tools/floating_point_comparison.hpp>

BOOST_AUTO_TEST_CASE( test )
{
  double v1 = 1.111e-10;
  double v2 = 1.112e-10;

  BOOST_CHECK_CLOSE_FRACTION( v1, v2, 0.0008999 );
}

输出
