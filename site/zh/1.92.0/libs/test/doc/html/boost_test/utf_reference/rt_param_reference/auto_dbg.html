auto_start_dbg

选项auto_start_dbg指定 Boost.Test 是否应在发生致命系统错误时尝试挂接调试器. 目前该特性仅在少数选定平台上可用: Win32 和 *nix. 这些平台配置有默认调试器. 你可以手动配置其他调试器. 关于如何配置调试器的更多细节见Boost.Test debug API, 特别是函数 boost::debug::set_debugger.

可接受值

Boolean, 默认值no.

命令行语法
  • --auto_debug[=<boolean value>]
  • -d [<boolean value>]
环境变量 
BOOST_TEST_AUTO_START_DBG
