输出流测试工具

你会如何对

operator<< ( std::ostream &, ... )

操作执行正确性测试?

你可以打印到标准输出流并人工检查它是否符合预期. 遗憾的是, 这对回归测试而言并不真正可接受, 也无助于单元测试的长期目标.

你可以使用std::stringstream并把结果输出缓冲区与期望的模式字符串比较, 但每次检查都要执行若干附加操作. 因此很快就会变得乏味.

类boost::test_tools::output_test_stream正是为替你自动化这些任务而设计的. 这是用于测试基于标准std::ostream的输出操作的简单而强大的工具. 类output_test_stream遵循std::ostream接口, 因此可以在任何std::ostream参数的位置使用. 它提供多个测试方法来验证输出内容, 包括与期望输出内容的匹配测试或期望输出长度的测试. 刷新、同步、字符串比较和错误消息生成都由工具实现自动完成.

默认情况下, 所有output_test_stream验证成员函数都会在执行检查后刷新流. 如果想对同一输出执行多次检查, 请指定参数flush_stream为值false [16].

某些情况下, 人工生成期望输出要么过于耗时, 要么因数量巨大而完全不可行. 解决该问题的一种可行方式是把测试分为两步:

  1. 第一步人工检查期望输出
  2. 第二步保存该输出, 确保将来的检查产生同样的输出

类output_test_stream既支持把输出内容与模式文件匹配, 也支持生成该模式文件. 命令行参数save_pattern可用于生成新的模式文件, 或对照现有模式进行检查.

用法

使用类output_test_stream有两种方式:

  1. 显式输出检查, 以及
  2. 模式文件匹配
显式输出检查

把类output_test_stream的实例用作输出流, 并使用工具的方法检查输出内容.

示例: 显式输出检查 - 使用output_test_stream

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>
#include <boost/test/tools/output_test_stream.hpp>
using boost::test_tools::output_test_stream;

BOOST_AUTO_TEST_CASE( test )
{
  output_test_stream output;
  int i=2;
  output << "i=" << i;
  BOOST_TEST( !output.is_empty( false ) );
  BOOST_TEST( output.check_length( 3, false ) );
  BOOST_TEST( output.is_equal( "i=3" ) );
}

输出

 
> example
Running 1 test case...
test.cpp(15): error in "test": check output.is_equal( "i=3" ) has failed. Output content: "i=2"

*** 1 failures is detected in test suite "example"
注释

在头两次调用检查函数时使用false以防止输出刷新. 不过, 除非你想对同一输出执行多次不同的检查, 否则并不需要使用它. 你的测试看起来会是一串输出运算符后跟一次检查.

提示

尽量频繁地执行检查. 这不仅简化了你要比较的模式, 还能让你更接近地定位可能的失败来源.

模式文件匹配

模式文件是一个伴随文件, 包含流应当匹配的模式. 你的测试看起来会是一串输出运算符后跟模式匹配检查, 如此重复多次.

在下面的示例中, 文件pattern_file包含应当匹配的模式.

i=2
File: test.cpp Line:XXX
示例: 模式文件匹配 - 使用output_test_stream

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>
#include <boost/test/tools/output_test_stream.hpp>
using boost::test_tools::output_test_stream;

BOOST_AUTO_TEST_CASE( test )
{
  output_test_stream output( "pattern_file", !boost::unit_test::runtime_config::save_pattern() );
  int i=2;
  output << "i=" << i;
  BOOST_TEST( output.match_pattern() );

  output << "\nFile: " << __FILE__ << " Line:YYY";
  BOOST_TEST( output.match_pattern() ); 
}

这一行生成错误 Line:YYY != Line:XXX

输出

 
> example
Running 1 test case...
test.cpp(16): error in "test": check output.match_pattern() has failed. Mismatch at position 23
...5...
...4...

*** 1 failures is detected in test suite "example"
提示

尽量频繁地执行检查, 因为这能让你更接近地定位可能的失败来源


[16] 所有比较方法都支持该参数, 见类documentation.
