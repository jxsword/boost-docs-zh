timeout(装饰器) 

timeout(unsigned int seconds);

以实际时间 (wall-clock) 为单位, 为 测试用例 或 测试套件 指定超时.

如果测试用例的持续时间超过超时值, 该测试会被标记为失败. 在某些系统上 (见下文), 会强制停止该测试用例.

对于测试套件, 机制类似: 测试套件下的每个测试单元都会被分配一段最长持续时间, 即在之前的测试执行完毕后超时时间的剩余部分. 如果在套件执行期间发生超时, 该套件会被标记为超时, 剩余的测试单元将被跳过.

详见 此处.

注释

如果 Boost.Test 能够强制停止测试用例, 则会定义宏 BOOST_SIGACTION_BASED_SIGNAL_HANDLING.

注释

对测试套件的支持已在 Boost 1.70 / 单元测试框架 v3.10 中添加
