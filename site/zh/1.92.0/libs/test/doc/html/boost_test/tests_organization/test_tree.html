测试树内容

测试树是测试用例和测试套件的层次结构, 连同所有夹具(全局、用例级或套件级)以及所有这些元素内部的相应依赖.

测试树由以下内容构成:

  • 测试用例: 树中包含测试主体的元素, 它们构成树的叶节点.
  • 测试套件: 树的内部节点. 这些元素自身没有任何主体或可执行代码, 但可以给它们附着会执行代码和测试的夹具.
  • 主测试套件: 树的根, 按定义是一个测试套件. 附着到主测试套件的夹具是全局夹具.
  • 夹具: 在上述测试单元之前和/或之后执行的代码单元.

可以为测试套件和测试用例添加装饰, 主测试套件除外. 这些装饰可以改变单元测试框架处理树的方式. 例如, 树本身并未强制规定测试用例的执行顺序(夹具及其关联元素(套件、用例)除外); 装饰可用于指定树中元素之间的特定顺序.

注释

测试树本身不为测试用例的执行给出任何特定顺序. 唯一的隐式顺序由夹具给出. 要指示特定顺序, 应使用特定装饰器.
