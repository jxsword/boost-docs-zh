log_level

参数log_level允许设置单元测试框架的日志级别. 日志级别定义测试模块产生的测试日志的详尽程度. 详尽程度的范围从完整日志(报告所有断言, 包括成功与失败, 并包含关于测试单元开始与结束的所有通知)到空日志(不向测试日志流报告任何内容).

日志级别被设为按层次组织的预定义级别之一, 其中每个级别包含该级别上的所有消息以及更低级别的所有消息. 级别用字符串名称标识, 如下所列.

可接受值

以下是按级别从高到低排列的枚举 log_level 名称列表. 因此每个级别包含该级别上的消息以及下方定义级别上的所有消息.

值

包含的消息

all(JUNIT 默认)

所有日志消息, 包括通过断言的通知

success

与 all 相同

test_suite

测试单元开始/结束通知

message

用户生成的消息(使用BOOST_TEST_MESSAGE工具)

warning

描述WARN级别失败断言的消息(BOOST_TEST_WARN / BOOST_WARN_...工具)

error(HRF 和 XML 默认)

描述CHECK级别失败断言的消息(BOOST_TEST / BOOST_CHECK_...工具)

cpp_exception

报告未捕获 C++ 异常的消息

system_error

报告系统来源非致命错误的消息. 例如超时或浮点异常.

fatal_error

报告用户或系统来源致命错误的消息. 例如内存访问违例. 还包括描述REQUIRE级别失败断言的所有消息(BOOST_TEST_REQUIRE / BOOST_REQUIRE_...工具)

nothing

不报告任何消息.
注意

JUNIT 日志格式不接受日志级别的更改: 由log_level指定的任何内容对 JUNIT 格式都会被忽略.

命令行语法
  • --log_level=<level>
  • -l <level>
环境变量 
BOOST_TEST_LOG_LEVEL
