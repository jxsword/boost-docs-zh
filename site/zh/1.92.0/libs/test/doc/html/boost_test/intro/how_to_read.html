如何阅读本文档

本文档按照你作为用户为成功使用单元测试框架所需要了解的内容来组织, 同时按照你必须做的决策的顺序以及可能遇到的问题的复杂度顺序排列. 如果遇到不清楚的术语, 可以直接跳到术语表一节, 那里汇集了所有用到的术语的简短定义.

通常, 使用单元测试框架编写测试模块时, 你需要经过以下步骤:

  • 你决定如何引入单元测试框架: #include为仅头文件库, 或作为静态库链接, 或作为共享(或动态加载)库使用. 该主题的详情见使用变体一节.
  • 你把一个测试用例添加进测试树. 详情见测试用例一节.
  • 你对被测代码执行正确性检查. 详情见编写单元测试一节.
  • 你在每个测试用例之前对被测代码执行初始化. 详情见夹具一节.
  • 你可能想定制测试失败的报告方式. 详情见控制输出一节.
  • 你可以控制构建出的测试模块的运行期行为(例如只运行选定的测试, 更改输出格式). 这在运行期配置一节中介绍.

如果在上述章节中都找不到问题的答案, 或者你认为自己需要更多配置选项, 可以查看高级用法场景一节.
