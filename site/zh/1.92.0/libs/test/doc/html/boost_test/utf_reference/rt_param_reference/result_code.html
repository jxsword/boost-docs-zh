result_code

选项 [`result_code] 的 "no" 参数值指示单元测试框架总是返回零结果码. 这可用于在 IDE 中执行的测试程序. 默认该参数值为 "yes". 更多细节见使用建议一节.

可接受值

Boolean, 默认值yes.

命令行语法
  • --result_code[=<boolean value>]
  • -c [<boolean value>]
环境变量 
BOOST_TEST_RESULT_CODE
