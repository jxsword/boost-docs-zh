BOOST_TEST_GLOBAL_CONFIGURATION

声明一个类, 它会在测试框架初始化期间被构造, 之后被析构. 框架不会调用除构造函数和析构函数之外的任何其他成员函数. 特别是, 构造函数和析构函数会在全局夹具的建立与拆除之前和之后被调用.

提供此设施是为了执行额外配置, 尤其是对日志记录器和报告器的编程式配置. 更多细节见本节.

警告

构造函数和析构函数中不允许日志记录或任何对框架断言的其他调用, 因为其目的是设置日志记录器/报告器, 而断言会调用日志/报告设施. 执行期间的任何此类断言都会导致测试模块中止.
