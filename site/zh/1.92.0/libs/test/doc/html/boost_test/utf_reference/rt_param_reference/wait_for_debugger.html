wait_for_debugger

选项wait_for_debugger指示单元测试框架在开始执行测试单元之前暂停, 以便你把调试器挂接到运行中的测试模块. 默认该参数关闭.

可接受值

Boolean, 默认值no.

命令行语法
  • --wait_for_debugger[=<boolean value>]
  • -w [<boolean value>]
环境变量 
BOOST_TEST_WAIT_FOR_DEBUGGER
