自定义日志格式支持

可以实现你自己的格式化器: 它应派生自boost::unit_test::unit_test_log_formatter.

可以使用以下两个函数之一, 把你自己的格式化器实例添加到格式集合中:

boost::unit_test::unit_test_log.set_formatter( unit_test_log_formatter* );
boost::unit_test::unit_test_log.add_formatter( unit_test_log_formatter* );
提示

更多细节见boost::unit_test::unit_test_log_t::set_formatter和boost::unit_test::unit_test_log_t::add_formatter

警告

调用boost::unit_test::unit_test_log.set_formatter等价于boost::unit_test::unit_test_log_t::set_format(见此处), 因为它会禁用所有其他格式化器.

提示

关于实现日志格式化的类的更多细节, 可在以下参考章节中找到:

  • boost::unit_test::unit_test_log_formatter定义所有日志记录器的接口. 内置的HRF、XML和JUNIT日志记录器都派生自该类
  • boost::unit_test::test_results定义测试所承载的信息, 用于提供报告和日志.
