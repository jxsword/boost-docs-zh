catch_system_errors

若选项catch_system_errors的值为 "no", 单元测试框架不会尝试捕获异步系统失败(*NIX 平台上的信号或 Windows 上的结构化异常). 这可用于在 IDE 中执行的测试程序, 或为栈分析获取核心转储. 更多细节见使用建议页面.

注释

若单元测试框架检测到当前进程正在调试器下运行, 则自动禁用catch_system_errors.

可接受值

Boolean, 默认值no.

注释

单元测试框架可以用标志BOOST_TEST_DEFAULTS_TO_CORE_DUMP构建, 此时默认值改为yes

命令行语法
  • --catch_system_errors[=<boolean value>]
  • -s [<boolean value>]
环境变量 
BOOST_TEST_CATCH_SYSTEM_ERRORS
