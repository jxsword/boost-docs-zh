以下各节给出所有单元测试框架运行期参数的详细规范. 每个参数规范包括:

  • 完整的参数名.
  • 参数语义与默认值的描述.
  • 可接受的参数值. 参数默认值在可接受值列表中加粗显示.
  • 命令行语法. 所有命令行参数的格式为: <prefix><name>[<separator><value>]. 例如: --param=<value>. 分隔符与值两侧的[]表示参数值可选. 例如: -q[ <value>].
  • 对应的环境变量名.
注释

所有命令行参数格式都支持参数名猜测. 意思是, 如果命令格式如下:

--long_parameter_name=<value>

你实际上可以用参数名的任何无歧义前缀来指定参数. 例如:

--long_param=123

或者

--long_p=123.

如果你选择的参数名前缀有歧义, 框架会告诉你哪些参数匹配该前缀. 例如, 尝试

--log=all
参数值格式

单元测试框架运行期参数取以下类型的值: string、boolean、enumeration、unsigned、long. 这些类型的值所需格式如下:

String、unsigned、long

这些类型的值应以与 C++ 中相同的格式给出.

Boolean

这类类型的值是具有是/否或真/假含义的选项. 真值用不区分大小写的字符串表示: "Y"、"YES"、"TRUE"、"1". 假值用不区分大小写的字符串表示: "N"、"NO"、"FALSE"、"0".

Enumeration

枚举类型的值应为表示枚举值名称且区分大小写的字符串. 每个带枚举值的参数在其描述中列出所有有效名称.
