report_level

参数report_level允许设置单元测试框架生成的测试结果报告的详尽级别. 使用值 "no" 可完全取消结果报告. 不同级别的报告格式描述见报告格式一节.

可接受值

Enumeration report_level 名称:

  • confirm(默认)
  • 否
  • short
  • detailed
命令行语法
  • --report_level=<format>
  • -r <format>
环境变量 
BOOST_TEST_REPORT_LEVEL
