help

参数help显示框架参数的帮助. 该参数接受一个可选参数值:

  • 若存在, 参数值被解释为参数名. 名称猜测同样有效(例如--help=rand会显示参数random的帮助).
  • 若参数名未知或有歧义, 会报告错误,
  • 若参数值缺失, 显示所有框架参数的汇总.
可接受值

可选的参数名string.

命令行语法
  • --help[=<parameter name>]
