编写测试的 API 汇总

Assertions

简要说明

BOOST_TEST, BOOST_TEST_<level>

通用断言宏.

BOOST_<level>

对布尔谓词值的简单验证.

BOOST_<level>_BITWISE_EQUAL

两个元素的按位相等测试.

BOOST_<level>_EQUAL

两个元素的相等测试.

BOOST_<level>_EQUAL_COLLECTIONS

两个集合的逐元素相等测试.

BOOST_<level>_CLOSE

使用偏差百分比的浮点比较.

BOOST_<level>_CLOSE_FRACTION

使用被比较操作数分数的浮点比较.

BOOST_<level>_EXCEPTION

异常检测与验证检查.

BOOST_<level>_GE

两个值的比较(带便捷报告).

BOOST_<level>_GT

两个值的比较(带便捷报告).

BOOST_<level>_LE

两个值的比较(带便捷报告).

BOOST_<level>_LT

两个值的比较(带便捷报告).

BOOST_<level>_MESSAGE

与BOOST_<level>相同, 但失败时带有自定义消息.

BOOST_<level>_NE

两个值的比较(带便捷报告).

BOOST_<level>_NO_THROW

检查表达式不抛出任何异常.

BOOST_<level>_PREDICATE

用谓词仿函数检查一组参数.

BOOST_<level>_SMALL

按容差检查某个值足够小.

BOOST_<level>_THROW

检查表达式抛出特定类型的异常.

BOOST_AUTO_TEST_CASE_EXPECTED_FAILURES

为测试用例指明预期失败数量

BOOST_ERROR

记录一条错误消息, 判定失败但不中止当前测试.

BOOST_FAIL

记录一条错误消息, 判定失败并中止当前测试.

BOOST_IS_DEFINED

在运行期检查所提供的预处理器符号是否已定义.

装饰器

简要说明

expected_failures

指明测试单元的预期失败.

timeout

设置测试单元应耗时的最大时长.

tolerance

为测试单元设置浮点比较容差.

控制宏

简要说明

BOOST_TEST_TOOLS_UNDER_DEBUGGER

定义时, 测试断言以对调试器友好的模式编译.

BOOST_TEST_TOOLS_DEBUGGABLE

定义时, 测试断言以两种模式编译(对调试器友好和全功能), 并在运行期选择所用版本.
