BOOST_DATA_TEST_CASE_F

声明并注册一个数据驱动测试用例, 使用特定的数据集和夹具. 这基本上等同于 BOOST_DATA_TEST_CASE 加上夹具支持.

struct my_fixture {
  my_fixture() : some_string("environment X") {
  }
  std::string some_string;
};

BOOST_DATA_TEST_CASE_F(my_fixture, test_case_name, dataset, var1, var2..., varN)
{
  BOOST_TEST(var1 != 0);
  //...
  BOOST_TEST(varN != 0);
}

该夹具应当实现相应的 接口. 与任何夹具一样, 夹具类中可以包含测试断言.

有关夹具的更多细节见 此处, 有关数据集声明的更多细节见 此处.
