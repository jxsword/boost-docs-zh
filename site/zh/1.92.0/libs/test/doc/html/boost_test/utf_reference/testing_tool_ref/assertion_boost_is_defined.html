BOOST_IS_DEFINED 

BOOST_IS_DEFINED(symbol);

与工具箱中的其他工具不同, 该工具本身不执行记录. 它的唯一用途是在运行期检查给定的预处理器符号是否已定义. 将它与 BOOST_<level> 结合使用, 以执行并记录验证. 任何元数的宏都可以检查. 要检查元数非零的宏定义, 请为其指定哑元 (dummy) 参数. 示例见下文.

该工具唯一的参数是接受验证的预处理器符号.

示例: BOOST_IS_DEFINED 用法

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>

BOOST_AUTO_TEST_CASE( test )
{
  BOOST_TEST( BOOST_IS_DEFINED(SYMBOL1) );
  BOOST_TEST( BOOST_IS_DEFINED(SYMBOL2(arg)) );
}
