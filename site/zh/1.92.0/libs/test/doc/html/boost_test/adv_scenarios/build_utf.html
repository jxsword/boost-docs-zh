构建单元测试框架

如果你想使用共享库变体或静态库变体的单元测试框架, 就需要构建该库. 构建单元测试框架实际上相当容易.

在下文中, 我们定义

  • $boost_path表示 boost 压缩包解压后的位置
  • $boost_installation_prefix表示你希望安装单元测试框架的位置

关于Boost 构建系统的更多文档可在此处找到.

Windows

你需要一套编译工具链. Visual Studio Express就是其中之一, 可从 Microsoft 网站免费获取. 安装完成后, 打开Visual Studio 命令行工具提示符, 构建 Boost 构建程序b2(见上方链接). 之后你就可以用不同变体编译单元测试框架了.

静态变体

要构建 32 位库, 请打开控制台窗口并输入以下命令:

> cd $boost_path
> bootstrap.bat
> b2 address-model=32 architecture=x86 --with-test link=static \
>                     --prefix=$boost_installation_prefix install

要构建 64 位库, 命令变为:

> cd $boost_path
> bootstrap.bat
> b2 address-model=64 architecture=x86 --with-test link=static \
>                    --prefix=$boost_installation_prefix install
共享库变体

要构建共享库变体, 需将上述命令行中的指令link=static替换为link=shared. 例如, 64 位构建的命令变为:

> cd $boost_path
> bootstrap.bat
> b2 address-model=64 architecture=x86 --with-test link=shared --prefix=$boost_installation_prefix install

Linux/OSX

对于 Unix/Linux/OSX 操作系统, 单元测试框架的构建过程与 Windows 上非常相似:

> cd $boost_path
> ./bootstrap.sh
> ./b2 --with-test --prefix=$boost_installation_prefix install
