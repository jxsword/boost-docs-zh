JUNIT 日志格式

JUNIT 格式是众多持续构建/集成工具都支持的日志格式.

此格式把日志级别默认设为General information, 并把默认流设为以主测试套件命名的文件. 日志记录器会尽量不覆盖任何已存在的输出文件, 这一点通常也被持续构建工具所理解.

此格式实际上既是日志格式又是报告格式: 大多数持续构建工具会汇总 JUNIT 文件的内容并显示模块通过/失败测试的概览(报告格式), 同时让用户查看详细日志(日志格式).

注意

JUnit 日志记录器的最小日志级别为non fatal error. 任何设置为更高日志级别的操作都会退回该最小日志级别.

注释

在 Boost 1.64 之前, 日志级别默认为success, 在某些情况下会给日志记录部分带来沉重负载.
