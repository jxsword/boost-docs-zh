测试日志输出

测试日志在测试执行期间生成. 测试日志中的所有条目都被赋予特定的日志级别. 只有级别超过活动日志级别阈值的条目才会实际出现在测试日志输出中. 日志级别按日志条目的"重要性"排列. 以下是按"重要性"递增排列的全部级别列表:

表 4. 消息

通知

含义

成功

此类包括提供成功通过的断言信息的消息

测试树遍历

此类包括由单元测试框架核心产生的消息, 指示当前正在执行或跳过哪些测试套件/用例

一般信息

此类包括大多数情况下由测试模块作者使用宏BOOST_TEST_MESSAGE产生的一般信息消息

警告

此类包括由失败的WARNING级别断言产生的消息

非致命错误

此类包括由失败的CHECK级别断言产生的消息

未捕获的 C++ 异常

此类包括由单元测试框架产生的消息, 提供关于测试用例主体未捕获的 C++ 异常的详细信息.

非致命系统错误

此类包括由单元测试框架自身产生的消息, 提供关于已捕获非致命系统错误的信息. 例如, 包括测试用例超时或捕获到浮点值计算错误时产生的消息.

致命系统错误

此类包括由失败的 require 级别断言产生的消息, 以及单元测试框架在测试用例异常终止时自身产生的消息.

注释

活动日志级别正是作为阈值而非选择器来工作的. 对于给定的活动日志级别阈值, 所有重要性高于阈值的测试日志条目被启用, 所有重要性低于阈值的测试日志条目被禁用.

除上述级别外, 测试日志还定义了两个特殊日志级别. 当前日志级别可以设为:

  • 所有消息
    如果活动日志级别阈值设为此值, 所有测试日志条目都会出现在输出中. 实践上这等价于把活动日志级别阈值设为成功信息消息
  • 无消息
    如果活动日志级别阈值设为此值, 没有任何测试日志条目出现在输出中. 该日志级别用于执行静默测试, 不产生任何测试日志, 只生成指示测试通过或失败的结果码.
