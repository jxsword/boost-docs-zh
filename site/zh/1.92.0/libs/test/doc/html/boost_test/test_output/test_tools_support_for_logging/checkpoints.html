用于精确定位失败的检查点

在大多数情况下, 单元测试框架无法给出系统错误发生或未捕获 C++ 异常抛出的确切位置. 为了尽可能接近地定位, 单元测试框架会跟踪检查点 - 即测试模块经过的位置.

单元测试框架会在测试用例入口、出口、夹具初始化以及测试工具调用点跟踪检查点.

如果你需要更细的粒度以防测试期间发生致命错误, 其他任何检查点都应由你手动输入. 单元测试框架为此提供了两个宏:

  • BOOST_TEST_CHECKPOINT用于指定命名检查点,
  • BOOST_TEST_PASSPOINT用于指定未命名检查点.

检查点对循环中的检查也很方便, 因为它们可以提供关于失败发生位置的更多信息(尽管已被 [links boost_test.test_output.test_tools_support_for_logging.contexts contexts] 取代).

命名检查点

宏BOOST_TEST_CHECKPOINT用于注入命名检查点位置. 宏签名如下:

BOOST_TEST_CHECKPOINT(checkpoint_message);

在检查点位置格式化的消息会被保存, 并由异常日志记录函数(如果发生异常)报告. 与BOOST_TEST_MESSAGE类似, 消息可以由任何符合标准输出流的组件格式化.

示例: BOOST_TEST_CHECKPOINT的用法

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>

extern void foo( int i );

BOOST_AUTO_TEST_CASE( test_external_interface )
{
  for( int i = 3; i >=0; i-- ) {
    BOOST_TEST_CHECKPOINT( "Calling 'foo' with i=" << i );
    foo( i );
  }
}

void goo( int value )
{
  BOOST_TEST_CHECKPOINT( "Inside goo with value '" << value << "'");
}

void foo( int i )
{
  if( i == 1 )
      throw std::runtime_error("Undefined Behaviour ahead!");
  // following line may not raise an exception on some compilers:
  // Undefined Behaviour is implementation specific
  goo( 2/(i-1) );
}

输出

 
> example
Running 1 test case...
unknown location(0): fatal error: in "test_external_interface": std::runtime_error: Undefined Behaviour ahead!
../doc/examples/example22.run-fail.cpp(17): last checkpoint: Calling 'foo' with i=1

*** 1 failure is detected in the test module "example"

未命名检查点

宏BOOST_TEST_PASSPOINT用于注入一个未命名检查点位置. 宏签名如下:

BOOST_TEST_PASSPOINT();

与宏BOOST_TEST_CHECKPOINT不同, 该宏不需要随附任何消息. 它只是一个简单的"来过这里"标记, 记录代码经过的文件名和行号.

示例: BOOST_TEST_PASSPOINT的用法

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>

void foo( int value ) {
  BOOST_TEST_CHECKPOINT("Inside foo with value '" << value << "' (should not be there)");
}

BOOST_AUTO_TEST_CASE( test_case )
{
  int* p = 0;

  BOOST_TEST_PASSPOINT();
  ++p;

  BOOST_TEST_PASSPOINT();
  ++p;

  BOOST_TEST_PASSPOINT();
  foo( *p );
}

输出

 
> example
Running 1 test case...
unknown location(0): fatal error in "test_case": memory access violation at address: 0x00000008: no mapping at fault address
test.cpp(16): last checkpoint

*** 1 failures is detected in test suite "example"
