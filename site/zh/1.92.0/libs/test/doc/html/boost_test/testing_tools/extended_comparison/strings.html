字符串与 C 字符串比较

在一般情况下, 指针按其值比较. 但当指针类型为char*或wchar_t*时, BOOST_TEST会把它们提升为以 null 结尾的char数组, 并改用字符串比较. std::string(或任何std::basic_string)和std::string_view(或任何std::basic_string_view)都可用于字符串比较.

只有当BOOST_TEST中要比较的两个操作数都可视为字符串类型时, 才能使用字符串比较.

提示

在这种形式下, 可以通过向BOOST_TEST提供附加参数来覆盖比较方法和报告方式. 更多细节见集合比较一节, 特别是boost::test_tools::per_element()和boost::test_tools::lexicographic()修饰符.

示例: BOOST_TEST 字符串比较

代码

 
#define BOOST_TEST_MODULE boost_test_strings
#include <boost/test/included/unit_test.hpp>

BOOST_AUTO_TEST_CASE( test_pointers )
{
  float a(0.5f), b(0.5f);
  const float* pa = &a, *pb = &b;
  BOOST_TEST(a == b);
  BOOST_TEST(pa == pb);
}

BOOST_AUTO_TEST_CASE( test_strings )
{
  const char* a = "test1";
  const char* b = "test2";
  const char* c = "test1";
  BOOST_TEST(a == b);
  BOOST_TEST(a == c);
  BOOST_TEST(std::string("test1") == b);
  BOOST_TEST(std::string("test1") < a, boost::test_tools::per_element());
  BOOST_TEST(b < a, boost::test_tools::lexicographic());
}
