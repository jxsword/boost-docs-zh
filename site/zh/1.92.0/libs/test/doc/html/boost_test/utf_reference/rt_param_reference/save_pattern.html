save_pattern

选项save_pattern便于切换测试输出流的操作模式. 关于这类测试的细节见输出测试流一节.

该参数在框架自身内部没有特定用途. 依赖boost::test_tools::output_test_stream实现测试逻辑的测试模块可以使用它. 它有两种操作模式:

  • 保存模式文件(true).
  • 以及对照先前保存的模式文件进行匹配(false).

默认模式为 'match'(false).

你可以通过把参数值传给output_test_stream构造函数来在这些模式之间切换. 命令行参数的值可通过如下调用获得:

bool is_save_pattern_flag_set = boost::unit_test::runtime_config::save_pattern();
可接受值

Boolean, 默认值no.

命令行语法
  • --save_pattern[=<boolean value>]
环境变量 
BOOST_TEST_SAVE_PATTERN
