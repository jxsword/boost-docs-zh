log_sink

参数log_sink允许设置日志接收器 - 框架写入测试日志的位置, 因此它允许轻松地把测试日志重定向到文件或标准流. 默认测试日志指向标准输出流.

可接受值

区分大小写的string:

值

含义

stdout(HRF 和 XML 默认)

测试日志被重定向到标准输出流

stderr

测试日志被重定向到标准错误流

文件名(JUNIT 默认)

测试日志被重定向到该文件
注释

对 JUnit 且未指定时, 日志文件按主测试套件的名称生成.

命令行语法
  • --log_sink=<stream or file name>
  • -k <stream or file name>
环境变量 
BOOST_TEST_LOG_SINK
