主测试套件

如引言一节所定义, 主测试套件是测试树的根节点. 用单元测试框架构建的每个测试模块总是定义有(唯一的)主测试套件. 单元测试框架在内部维护主测试套件实例. 所有其他测试单元都注册为主测试套件的直接或间接子节点.

namespace boost {
namespace unit_test {
class master_test_suite_t : public test_suite
{
  /// implementation details
public:
  int argc;
  char** argv;
};

} // namespace unit_test
} // namespace boost

要访问主测试套件的单例, 使用以下接口:

namespace boost {
namespace unit_test {
namespace framework {

master_test_suite_t& master_test_suite();

} // namespace framework
} // namespace unit_test
} // namespace boost
命令行参数访问接口

主测试套件实现为对常规测试套件的扩展, 因为它维护着对传给测试模块的命令行参数的引用. 要访问命令行参数, 使用

boost::unit_test::framework::master_test_suite().argc
boost::unit_test::framework::master_test_suite().argv

在下面的示例中, 命令行参数的引用既可以作为初始化函数参数访问, 也可以作为主测试套件的成员访问. 两个引用指向相同的值. 使用备选初始化函数规定的测试模块只能通过主测试套件访问命令行参数.

回到自由函数示例, 让我们修改初始化函数以检查测试模块参数是否为空.

示例: 初始化函数中的命令行访问

代码

 
#include <boost/test/included/unit_test.hpp>
using namespace boost::unit_test;

void free_test_function()
{
  BOOST_TEST( true /* test assertion */ );
}

test_suite* init_unit_test_suite( int /*argc*/, char* /*argv*/[] )
{
  if( framework::master_test_suite().argc > 1 )
    return 0;

  framework::master_test_suite().
    add( BOOST_TEST_CASE( &free_test_function ) );

  return 0;
}

输出

 
> example 1
Test setup error: test tree is empty
命名 主测试套件

主测试套件以默认名称Master Test Suite创建. 有两种方法把名称重设为不同的值: 使用宏BOOST_TEST_MODULE, 或在测试模块初始化函数内. 前者用于没有手动实现初始化函数的测试模块. 以下示例展示了这些方法.

示例: 主测试套件命名 - 用宏BOOST_TEST_MODULE

代码

 
#define BOOST_TEST_MODULE my master test suite name
#include <boost/test/included/unit_test.hpp>

BOOST_AUTO_TEST_CASE( free_test_function )
{
  BOOST_TEST( true /* test assertion */ );
}

输出

 
> example --log_level=test_suite
Running 1 test case...
Entering test suite "my master test suite name"
Entering test case "free_test_function"
Leaving test case "free_test_function"; testing time: 1ms
Leaving test suite "my master test suite name"

*** No errors detected

如果定义了宏BOOST_TEST_MODULE, 测试模块初始化函数会被自动生成, 且宏值成为主测试套件的名称. 名称可以包含空格.

示例: 在测试模块初始化函数中显式命名主测试套件

代码

 
#include <boost/test/included/unit_test.hpp>
using namespace boost::unit_test;

BOOST_AUTO_TEST_CASE( free_test_function )
{
  BOOST_TEST( true /* test assertion */ );
}

test_suite* init_unit_test_suite( int /*argc*/, char* /*argv*/[] )
{
  framework::master_test_suite().p_name.value = "my master test suite name";
  return 0;
}

输出

 
> example --log_level=test_suite
Running 1 test case...
Entering test suite "my master test suite name"
Entering test case "free_test_function"
Leaving test case "free_test_function"; testing time: 1ms
Leaving test suite "my master test suite name"

*** No errors detected

在没有定义BOOST_TEST_MAIN和BOOST_TEST_MODULE标志的情况下, 测试模块初始化函数必须手动实现. 主测试套件名可以在该函数内任意位置重设.
