按标签把测试分组为逻辑单元

测试套件和测试用例定义了称为测试树的层次结构, 它对组织测试很有用. 这种组织按照从测试树中提取的子树, 仅通过在测试树上指定一个节点, 就定义了测试单元的隐式分组. 能够指定一组测试, 例如可以只执行这一组测试(在本节中介绍).

不过, 子树未必能反映测试模块的用法所需的全部测试单元分组方式[5].

单元测试框架通过标签提供了灵活的测试单元分组方式, 所用装饰器为label. 一个测试单元可以关联多个标签.

标签可以关联到测试用例和测试套件. 对后者, 标签会被带标签测试套件所定义子树中的所有节点继承: 用标签L装饰测试套件, 等价于用L装饰其内部的每个测试单元.

提示

可以通过 CLI 使用--list_labels开关列出测试模块的全部标签

示例: 装饰器 label

代码

 
#define BOOST_TEST_MODULE decorator_04
#include <boost/test/included/unit_test.hpp>
namespace utf = boost::unit_test;

BOOST_AUTO_TEST_CASE(test1,
  * utf::label("l1"))
{
  BOOST_TEST(false);
}

BOOST_AUTO_TEST_CASE(test2,
  * utf::label("l1")
  * utf::label("l2"))
{
  BOOST_TEST(false);
}

BOOST_AUTO_TEST_CASE(test3)
{
  BOOST_TEST(false);
}

输出
