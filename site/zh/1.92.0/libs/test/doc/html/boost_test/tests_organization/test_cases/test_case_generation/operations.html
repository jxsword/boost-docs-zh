数据集上的操作

如前所述, 使用单元测试框架数据集的主要优势之一在于为其组合提供了大量操作.

为此提供了三个运算符:

  • 用operator+做连接(join)
  • 对数据集用operator^做压缩(zip)
  • 以及用operator*做网格(grid)或笛卡尔积
提示

所有这些运算符都满足结合律, 因此无需括号即可组合. 不过, 语言中运算符的优先级规则仍然适用.

连接

连接(join)记作+, 是对元数相同且类型兼容的两个数据集dsa和dsb的操作, 其结果是这两个数据集拼接而成的dsa与dsb, 顺序按符号+从左到右:

dsa = (a_1, a_2, ... a_i)
dsb = (b_1, b_2, ... b_j)
dsa + dsb = (a_1, a_2, ... a_i, b_1, b_2, ... b_j)

以下性质成立:

  • 结果数据集与操作数数据集元数相同,
  • 返回数据集的大小是被连接数据集大小之和,

  • 该运算满足结合律, 可以在一个表达式中组合两个以上的数据集. 对任意数据集dsa、dsb和dsc, 以下连接等价:

    ( dsa + dsb ) + dsc
== dsa + ( dsb + dsc )
== dsa + dsb + dsc
警告

在表达式dsa + dsb中, dsa和/或dsb可以是无限大小. 结果数据集也将具有无限大小. 若dsa无限, 则dsb的内容永远不会被到达.

示例: 数据集连接示例

代码

 
#define BOOST_TEST_MODULE dataset_example62
#include <boost/test/included/unit_test.hpp>
#include <boost/test/data/test_case.hpp>
#include <boost/test/data/monomorphic.hpp>

namespace data = boost::unit_test::data;

int samples1[] = {1, 2};
int samples2[] = {8, 9, 10};

BOOST_DATA_TEST_CASE(
      test1,
      data::make(samples1) + samples2,
      var)
{
  std::cout << var << std::endl;
}

输出

 
> dataset_example62
Running 5 test cases...
1
2
8
9
10

*** No errors detected
压缩

压缩(zip)记作^, 是对元数相同且大小相同的两个数据集dsa和dsb的操作, 结果是一个数据集, 其中第k个样本(dsa的)与第k个样本(dsb的)配对. 结果数据集样本的顺序遵循符号^的从左到右顺序.

dsa = (a_1, a_2, ... a_i)
dsb = (b_1, b_2, ... b_i)
dsa ^ dsb = ( (a_1, b_1), (a_2, b_2) ... (a_i, b_i) )

以下性质成立:

  • 结果数据集的元数是操作数数据集元数之和,
  • 结果数据集的大小等于各数据集的大小(因为它们应当大小相同), 操作数数据集大小不匹配的情形除外(见下文),

  • 该运算满足结合律, 可以在一个表达式中组合两个以上的数据集,

    ( dsa ^ dsb ) ^ dsc
== dsa ^ ( dsb ^ dsc )
== dsa ^ dsb ^ dsc

若dsa和dsb大小不同, 会执行特殊处理. 规则如下:

  • 若两个被压缩的数据集大小相同, 这就是结果数据集的大小(该大小随后可以是无限的).
  • 否则, 若某个数据集大小为 1(单例)或无限大, 结果大小由另一个数据集决定.
  • 否则在运行期抛出异常
注意

若你的编译器不支持zip操作, 宏BOOST_TEST_NO_ZIP_COMPOSITION_AVAILABLE会被单元测试框架自动设置

示例: 数据集压缩示例

代码

 
#define BOOST_TEST_MODULE dataset_example61
#include <boost/test/included/unit_test.hpp>
#include <boost/test/data/test_case.hpp>
#include <boost/test/data/monomorphic.hpp>

namespace data = boost::unit_test::data;

int samples1[] = {1,2};
char const* samples2[] = {"qwerty", "asdfg"};

BOOST_DATA_TEST_CASE(
      test1,
      data::make(samples1)^samples2,
      integer_values,
      string_value)
{
  std::cout << integer_values << ", " << string_value << std::endl;
}

输出

 
> dataset_example61
Running 2 test cases...
1, qwerty
2, asdfg

*** No errors detected
网格(笛卡尔积)

网格(grid)记作*, 是对任意两个数据集dsa和dsb的操作, 结果数据集中dsa的每个样本与dsb的每个样本恰好配对一次. 结果数据集样本的顺序遵循符号*的从左到右顺序. 最右侧数据集的样本最先被迭代.

dsa = (a_1, a_2, ... a_i)
dsb = (b_1, b_2, ... b_j)
dsa * dsb = ((a_1, b_1), (a_1, b_2) ... (a_1, b_j), (a_2, b_1), ... (a_2, b_j) ... (a_i, b_1), ... (a_i, b_j))

因此网格类似于数学上的笛卡尔积概念[3].

以下性质成立:

  • 结果数据集的元数是操作数数据集元数之和,
  • 结果数据集的大小是各数据集大小的乘积,
  • 该运算满足结合律, 可以在一个表达式中组合两个以上的数据集,
  • 与zip一样, 不要求两个数据集具有相同的样本类型.
注意

若你的编译器不支持grid操作, 宏BOOST_TEST_NO_GRID_COMPOSITION_AVAILABLE会被单元测试框架自动设置

在下面的示例中, 随机数生成器是第二个数据集. 它的状态被求值 6 次(第一个xrange - 第一维 - 3 次, 与之压缩的第二个xrange - 第二维 - 2 次). 注意随机引擎的状态不会在第一维的两次相继求值之间被复制.

示例: 笛卡尔积示例

代码

 
#define BOOST_TEST_MODULE dataset_example64
#include <boost/test/included/unit_test.hpp>
#include <boost/test/data/test_case.hpp>
#include <boost/test/data/monomorphic.hpp>

namespace bdata = boost::unit_test::data;


BOOST_DATA_TEST_CASE(
  test1,
  bdata::xrange(2) * bdata::xrange(3),
  xr1, xr2)
{
  std::cout << "test 1: " << xr1 << ", " << xr2 << std::endl;
  BOOST_TEST((xr1 <= 2 && xr2 <= 3));
}

BOOST_DATA_TEST_CASE(
  test2,
  bdata::xrange(3)
  *
  ( bdata::random(
      bdata::distribution=std::uniform_real_distribution<float>(1, 2))
    ^ bdata::xrange(2)
  ),
  xr, random_sample, index)
{
  std::cout << "test 2: "
    << xr << " / "
    << random_sample << ", " << index
    << std::endl;
  BOOST_TEST(random_sample < 1.7); // 30% chance of failure
}
