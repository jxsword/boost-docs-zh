detect_memory_leaks

参数detect_memory_leaks启用/禁用内存泄漏检测(如果存在于您的构建配置中). 该参数有一个可选的长整数值. 默认值为 1, 即启用内存泄漏检测. 值 0 禁用内存泄漏检测. 任何大于 1 的值 N 被视为泄漏分配编号, 告诉框架在第 N 次堆分配处设置运行期断点. 若省略该值, 则采用默认值.

注释

唯一支持内存泄漏检测的平台是 Microsoft Visual Studio 系列编译器的调试构建.

可接受值
  • 0
  • 1(默认)
  • long integer value > 1
命令行语法
  • --detect_memory_leaks[=<alloc order number>]
环境变量 
BOOST_TEST_DETECT_MEMORY_LEAK
