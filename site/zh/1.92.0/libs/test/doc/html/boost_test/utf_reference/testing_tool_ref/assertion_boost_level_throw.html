BOOST_<level>_THROW 

BOOST_WARN_THROW(expression, exception_type);
BOOST_CHECK_THROW(expression, exception_type);
BOOST_REQUIRE_THROW(expression, exception_type);

这些断言验证 expression 的执行抛出 预期的异常, 即给定 exception_type 类型或其任何子类型的异常.

  • 如果 expression 抛出非预期的异常, 该异常不会被 BOOST_<level>_THROW 断言捕获, 并可能传播到测试主体. 如果完全未被捕获, 框架会捕获它并以 failed 状态终止该测试用例.
  • 如果 expression 未抛出任何异常, 断言将失败.
警告

断言只捕获预期的异常.

提示

可以借助诸如 do { /* ... */} while(0) 块这样的构造来测试复杂表达式.

示例: BOOST_<level>_THROW 用法

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>

class my_exception{};

BOOST_AUTO_TEST_CASE( test )
{
  int i =  0;
  BOOST_CHECK_THROW( i++, my_exception );
}

输出

 
> example
Running 1 test case...
test.cpp(11): error in "test": exception my_exception is expected

*** 1 failures is detected in test suite "example"
