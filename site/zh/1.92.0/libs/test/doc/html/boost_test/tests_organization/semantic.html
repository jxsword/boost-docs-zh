为测试添加语义

有时为测试单元添加语义描述会很有用, 用户可以在空跑(dry run)时查阅它. 用户随后可以基于这些信息选择想运行的测试, 而不必依据测试单元的名称, 也不必查看代码.

单元测试框架为此提供了装饰器description.

装饰器description把任意字符串附着到测试单元. 使用参数list_content运行测试程序时, 可以显示所有附着到测试单元的字符串. 这可用于把信息从测试树的编排者传达给将要运行测试程序的人. 对同一测试单元应用多个装饰器description意味着两条(或更多)字符串会被拼接起来.

示例: 装饰器 description

代码

 
#define BOOST_TEST_MODULE decorator_09
#include <boost/test/included/unit_test.hpp>
namespace utf = boost::unit_test;

BOOST_AUTO_TEST_CASE(test_1,
  * utf::disabled()
  * utf::description("enable only when ODBC is available"))
{
  BOOST_TEST(1 == 1);
}

BOOST_AUTO_TEST_CASE(test_2,
  * utf::description("descriptions ")
  * utf::description("add up"))
{
  BOOST_TEST(2 == 2);
}

输出

 
> decorator_09 --list_content
test_1 : enable only when ODBC is available
test_2*: descriptions add up
