基于容差的比较

单元测试框架中的断言使用两类比较. 对u以绝对容差eps接近零:

abs(u) <= eps; // (abs)

对u和v以相对容差eps接近:

   abs(u - v)/abs(u) <= eps
&& abs(u - v)/abs(v) <= eps; // (rel)

选择这些公式的理由见浮点比较算法一节.

断言BOOST_TEST(在比较浮点数时)使用以下算法:

  • 当值u或v之一为零时, 对另一个值求公式 (abs).
  • 当指定容差为零时, 在u和v之间执行直接(原生)比较.
  • 否则, 对u和v执行公式 (rel).
注释

因此, 要检查一个数是否以某容差接近零, 需要输入:

BOOST_TEST(v == T(0), tt::tolerance(eps));

兼容性断言BOOST_<level>_CLOSE和BOOST_<level>_CLOSE_FRACTION执行公式 (rel).

兼容性断言BOOST_<level>_SMALL执行公式 (abs).

单元测试框架还提供一元谓词small_with_tolerance和二元谓词close_at_tolerance, 分别实现公式 (abs) 和 (rel).

容差: operator<

基于容差的计算也适用于operator<及其他关系运算符. 语义定义如下:

  • 容差下小于 <==> 严格小于且不容差下接近
  • 容差下大于 <==> 严格大于且不容差下接近
  • 容差下小于等于 <==> 严格小于或容差下接近
  • 容差下大于等于 <==> 严格大于或容差下接近
注释

这意味着在任意给定容差下, u < v、u == v、u > v三者中恰有一个会通过BOOST_TEST.

注意

关系容差下小于不是严格弱序, 因为它缺乏等价的传递性; 把它用作std::map或任何基于序的 STL 算法的谓词会导致未定义行为.
