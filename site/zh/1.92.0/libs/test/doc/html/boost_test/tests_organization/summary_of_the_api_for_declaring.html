BOOST_TEST_CASE

BOOST_TEST_CASE_NAME

手动注册测试用例

BOOST_AUTO_TEST_CASE

BOOST_PARAM_TEST_CASE

带参数集合的测试用例的自动声明与注册

BOOST_AUTO_TEST_CASE_TEMPLATE

类型化测试用例的自动声明与注册

BOOST_TEST_CASE_TEMPLATE

以boost::mpl式类型序列注册类型化测试用例

BOOST_TEST_CASE_TEMPLATE_FUNCTION

类型化测试用例主体的声明

BOOST_DATA_TEST_CASE

数据集上测试用例主体的声明

BOOST_DATA_TEST_CASE_F

与BOOST_DATA_TEST_CASE相同, 但支持夹具

BOOST_TEST_DATASET_MAX_ARITY

控制用BOOST_DATA_TEST_CASE声明的数据测试用例的最大元数

BOOST_TEST_SUITE

BOOST_AUTO_TEST_SUITE

自动声明测试套件

BOOST_AUTO_TEST_SUITE_END

自动声明测试套件

BOOST_TEST_DECORATOR

为测试单元添加装饰器

BOOST_FIXTURE_TEST_CASE

声明带夹具的测试用例

BOOST_FIXTURE_TEST_SUITE

为测试套件声明夹具(建立/拆除会为测试套件的每个测试调用)

BOOST_TEST_GLOBAL_FIXTURE

全局地为测试模块声明夹具

Decorator

简要说明

depends_on

创建从一个测试用例到另一个测试用例的依赖(执行顺序和默认运行状态).

description

把语义字符串附着到测试单元, 可从命令行界面查看.

enabled , disabled

无条件启用或禁用测试单元. 这些装饰器的作用可被命令行界面覆盖

enable_if

有条件地启用测试单元. 这些装饰器的作用可被命令行界面覆盖

fixture

把夹具附着到测试单元

label

为测试单元打标签以形成逻辑组

precondition

基于在测试用例执行前刚求值的谓词启用或禁用测试单元.
