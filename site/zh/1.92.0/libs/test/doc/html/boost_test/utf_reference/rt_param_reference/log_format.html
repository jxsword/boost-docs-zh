log_format

参数log_format允许把单元测试框架日志格式设为框架提供的格式之一. 要指定自定义日志格式, 使用自定义日志格式化 API.

此参数唯一可接受的值是框架提供的输出格式名称. 默认情况下框架对测试日志使用人类可读格式(HRF). 该格式类似于编译器错误格式. 或者, 你可以指定 XML 或 JUNIT 作为日志格式, 它们更易于测试自动化工具处理.

可接受值

Enumeration 名称:

  • HRF(默认)
  • XML
  • JUNIT
命令行语法
  • --log_format=<format>
  • -f <format>
环境变量 
BOOST_TEST_LOG_FORMAT
