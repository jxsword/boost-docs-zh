多翻译单元的仅头文件用法

即使测试模块包含多个翻译单元, 也可以使用单元测试框架的仅头文件变体:

  • 一个翻译单元应定义BOOST_TEST_MODULE并包含<boost/test/included/unit_test.hpp>
  • 所有其他翻译单元应包含<boost/test/unit_test.hpp>

一个示例如下:

  • 翻译单元 1, 定义BOOST_TEST_MODULE 

    #define BOOST_TEST_MODULE header-only multiunit test
#include <boost/test/included/unit_test.hpp>

BOOST_AUTO_TEST_CASE( test1 )
{
    int i = 1;
    BOOST_CHECK( i*i == 1 );
}

  • 翻译单元 2, 包含<boost/test/unit_test.hpp>而非<boost/test/included/unit_test.hpp>:

    #include <boost/test/unit_test.hpp>

BOOST_AUTO_TEST_CASE( test2 )
{
    int i = 1;
    BOOST_CHECK( i*i == 1 );
}
