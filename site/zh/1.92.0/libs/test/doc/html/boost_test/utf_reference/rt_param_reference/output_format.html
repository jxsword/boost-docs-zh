output_format

参数output_format组合了report_format和log_format参数的效果. 该参数没有默认值. 唯一可接受的值是输出格式的字符串名称(见下文).

注释

该参数在命令行上优先于report_format和log_format.

可接受值

Enumeration 名称:

  • HRF
  • XML

HRF代表人类可读格式, 而XML专用于自动化输出处理

命令行语法
  • --output_format=<format>
  • -o <format>
环境变量 
BOOST_TEST_OUTPUT_FORMAT
