测试套件进入/退出夹具

可以定义测试套件进入/退出夹具, 使setup函数只在进入测试套件时、运行其中任何测试用例之前被调用一次. 类似地, teardown函数也只在测试套件退出时、其包围的全部测试用例运行完毕之后被调用一次. 这由装饰器 fixture促成.

示例: 测试套件进入/退出夹具

代码

 
#define BOOST_TEST_MODULE fixture_03
#include <boost/test/included/unit_test.hpp>
namespace utf = boost::unit_test;

struct F {
  F()  { BOOST_TEST_MESSAGE( "setup fixture" ); }
  ~F() { BOOST_TEST_MESSAGE( "teardown fixture" ); }
};

BOOST_AUTO_TEST_SUITE(s, * utf::fixture<F>())

  BOOST_AUTO_TEST_CASE(test_case1)
  {
    BOOST_TEST_MESSAGE("running test_case1");
    BOOST_TEST(true);
  }

  BOOST_AUTO_TEST_CASE(test_case2)
  {
    BOOST_TEST_MESSAGE("running test_case2");
    BOOST_TEST(true);
  }

BOOST_AUTO_TEST_SUITE_END()

输出

 
> fixture_03 --log_level=message
Running 2 test cases...
setup fixture
running test_case1
running test_case2
teardown fixture

*** No errors detected

不过, 对这种夹具类型, 无法访问夹具对象的任何成员.

注意

这不等价于使用此处描述的方法.
