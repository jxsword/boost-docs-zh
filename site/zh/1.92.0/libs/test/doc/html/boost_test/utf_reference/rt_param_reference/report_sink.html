report_sink

参数report_sink允许设置结果报告接收器 - 框架写入结果报告的位置, 因此它允许轻松地把结果报告重定向到文件或标准流. 默认测试结果报告指向标准错误流.

可接受值

区分大小写的string:

  • stderr(默认)
  • stdout
  • 任意文件名
命令行语法
  • --report_sink=<stream or file name>
  • -e <stream or file name>
环境变量 
BOOST_TEST_REPORT_SINK
