装饰器

套件级装饰器
显式装饰器声明

"装饰器"是更新自动注册测试单元各种属性的统一机制. 这些属性影响测试模块执行期间测试树的处理方式, 其中包括测试单元描述、浮点容差和预期失败数量等. 它们在以下各节中详细列出.

测试用例装饰器

你可以对同一测试单元应用多个装饰器. 通过把装饰器列表指定为宏BOOST_AUTO_TEST_CASE的第二个参数或宏BOOST_FIXTURE_TEST_CASE的第三个参数, 即可将它应用于测试用例.

示例: 测试单元装饰器

代码

 
#define BOOST_TEST_MODULE decorator_01
#include <boost/test/included/unit_test.hpp>
namespace utf = boost::unit_test;

BOOST_AUTO_TEST_CASE(test_case1, * utf::label("trivial"))
{
  BOOST_TEST(true);
}

BOOST_AUTO_TEST_CASE(test_case2,
  * utf::label("trivial")
  * utf::label("cmp")
  * utf::description("testing equality of ones"))
{
  BOOST_TEST(1 == 1);
}

输出

 
> decorator_01 --run_test=@trivial
Running 2 test cases...

*** No errors detected


> decorator_01 --run_test=@cmp
Running 1 test case...

*** No errors detected

列表中每个装饰器前面都有一个星号(*); 其后的语法类似函数调用, 并为每个装饰器详细规定. 如果列表中有多个装饰器, 它们之间不加额外分隔符直接连接; 每个星号指示一个装饰器的开始. 在上面的示例中, 测试用例test_case1有一个关联的装饰器: label. 这意味着当按标签过滤测试单元时, 该测试用例会匹配标签"trivial". 测试用例test_case2有三个关联装饰器: 两个类型为label, 一个类型为description.
