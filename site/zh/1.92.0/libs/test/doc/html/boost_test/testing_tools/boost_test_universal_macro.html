BOOST_TEST: 通用与多用途断言

单元测试框架通过BOOST_TEST宏, 为大量测试用例场景提供了一个近乎统一的接口. BOOST_TEST的一般形式如下:

BOOST_TEST(statement);
BOOST_TEST_<level>(statement, optional_modifiers)

用法示例可能如下:

示例: BOOST_TEST 概览

代码

 
#define BOOST_TEST_MODULE boost_test_macro_overview
#include <boost/test/included/unit_test.hpp>

BOOST_AUTO_TEST_CASE( test_macro_overview )
{
  namespace tt = boost::test_tools;
  int a = 1;
  int b = 2;
  BOOST_TEST(a != b - 1);
  BOOST_TEST(a + 1 < b);
  BOOST_TEST(b -1 > a, a << " < " << b - 1 << " does not hold");
  BOOST_TEST(a == b, tt::bitwise());
  BOOST_TEST(a + 0.1 == b - 0.8, tt::tolerance(0.01));
}

该工具的主要特性有:

  • statement具有极大的灵活性, 它几乎可以是任何东西: 支持并处理由多个操作组成的完整表达式,
  • 失败时的扩展报告能力: BOOST_TEST不仅报告失败位置和statement本身的副本, 还报告操作数的值, 便于快速定位与失败断言相关的问题,
  • 可以更好地控制检查的行为或报告, 特别是:
    • 浮点比较: 可以提供容差, 既可直接通过BOOST_TEST配合optional_modifiers使用, 也可通过装饰器使用(更多细节见此处),
    • 容器/集合比较: 开箱即用地提供多种比较操作来比较元素集合(默认、逐元素、字典序), 失败时提供扩展诊断(在本节中介绍),
    • 字符串比较: 会自动检测 C 字符串操作数, 比较的执行如同使用了std::string对象,
    • 可选的失败消息,
    • 按位比较, 失败时提供扩展诊断
警告

要获得BOOST_TEST断言家族的全部功能, 需要支持 C++11 的编译器, 特别是要支持auto和decltype关键字以及变参宏. 本文档聚焦于这组编译器. 对于不支持BOOST_TEST全部特性的编译器, 有宏BOOST_TEST_MACRO_LIMITED_SUPPORT.

复杂语句

BOOST_TEST提供了增强的报告能力: 日志中会提供失败操作数和操作的更多细节, 如下例所示:

示例: BOOST_TEST 增强报告

代码

 
#define BOOST_TEST_MODULE boost_test_macro3
#include <boost/test/included/unit_test.hpp>

BOOST_AUTO_TEST_CASE( test_op_reportings )
{
  int a = 13, b = 12;
  BOOST_TEST(a == b);
  BOOST_TEST(a < b);
  BOOST_TEST(a - 1 < b);
  BOOST_TEST(b > a - 1);
}

BOOST_TEST会解析statement并用它构造一个表达式. statement可以是包含 C++ 中几乎所有可重载运算符的复杂表达式:

操作类别

运算符

二元比较

==, !=, <, >, <=, >=

算术组合

+, -, *, /, %

按位组合

|, &, ^, <<, >>

赋值

=, +=, -=, *=, /=, %=, <<=, >>=, &=, ^=, |=

statement会被求值并转换为bool, 就像它作为if语句的参数出现一样: 这就是断言的结果

统一报告

该工具提供三种变体, 分别对应相应的严重级别. 这三个级别的断言会按该节详细描述的方式被报告到测试日志和输出中. 报告的粒度取决于当前日志级别和报告级别.

限制与变通

有少数结构不受支持, 但通常加一对额外的括号即可解决:

  • 包含三目条件的语句: 这类语句应当用圆括号包围, 因为它们无法被重载
  • 包含逗号的语句: 这类语句会被预处理器截获

  • 包含任何逻辑组合||、&&的复合语句. 这些组合被有意禁用, 应当用圆括号包围

    BOOST_TEST((true || false));

    完整细节在本节给出.

示例: BOOST_TEST 的限制与变通

代码

 
#define BOOST_TEST_MODULE boost_test_macro_workaround
#include <boost/test/included/unit_test.hpp>
#include <sstream>

BOOST_AUTO_TEST_CASE( test_logical_not_allowed )
{
  // Boost Unit Test Framework prevents compilation of
  // BOOST_TEST(true && true);
  BOOST_TEST((true && true)); // with extra brackets, it works as expected
}

BOOST_AUTO_TEST_CASE( test_ternary )
{
  int a = 1;
  int b = 2;
  // Boost Unit Test Framework prevents compilation of
  // BOOST_TEST(a == b ? true : false);
  BOOST_TEST((a + 1 == b ? true : false)); // again works as expected with extra brackets
}
