断言严重级别

断言有三种级别, 所有测试工具都以这三种风格/级别提供. 这些级别对测试用例的一致性有不同含义:

  • REQUIRE实现要求(requirements): 这是使断言之后的操作有效性的强条件. 当运行测试的前置条件不满足或测试用例无法继续时, 应使用这类断言. 如果此类断言失败, 测试用例执行立即停止, 且该测试用例被标记为失败.
  • CHECK用于标准检查(checks): 这是最常用的断言级别. 如果语句求值为false, 测试用例被标记为失败, 但其执行继续.
  • WARN表示警告(warnings): 这是提供信息的断言. 测试用例执行继续, 并记录一条警告消息. 警告不改变测试用例的成功状态. 该级别断言可用于验证不如正确性重要的方面: 性能、可移植性、易用性等.

例如:

  • BOOST_REQUIRE_THROW, BOOST_TEST_REQUIRE
  • BOOST_CHECK_THROW, BOOST_TEST [6]
  • BOOST_WARN_THROW, BOOST_TEST_WARN

这三个级别的断言会被框架过滤并报告到测试日志和输出中:

  1. 如果工具所指代的断言通过, 可以在日志输出中打印确认消息[7].
  2. 如果工具所指代的断言失败, 视断言级别[8]而定, 将发生以下情况:
