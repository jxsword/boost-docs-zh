数据集

为了正确定义数据集, 首先应引入样本的概念. 样本定义为多态元组. 按定义, 元组的大小就是样本自身的元数.

数据集是一个样本集合, 它

  • 是前向可迭代的,
  • 可以查询其size, 而后者可以是无限的,
  • 具有一个元数, 即其所含样本的元数.

因此数据集实现了序列的概念.

单元测试框架中数据集的描述能力来自

  • 创建自定义数据集的接口, 相当简单,
  • 它们为组合不同数据集提供的操作
  • 它们与其他类型集合的接口(stl容器、C数组)
  • 可用的内置数据集生成器
提示

只支持"单态"数据集, 即单个数据集内的所有样本类型相同、元数相同[2]. 不过, 样本类型不同的数据集可以用 zip 和笛卡尔积组合在一起.

正如后续各节将看到的, 表示不同类型集合的数据集可以组合在一起(例如zip或grid). 这些操作产生新的数据集, 其样本类型是扩充后的类型.

数据集接口

数据集的接口应实现以下两个函数/字段:

  • iterator begin(), 其中iterator是前向迭代器,
  • boost::unit_test::data::size_t size() const指示数据集的大小. 返回类型是专用类size_t, 可以指示无限数据集大小.
  • 一个static const int数据成员, 名为arity, 指示数据集返回样本的元数

一旦声明了数据集类D, 应通过特化模板类把它注册到框架

boost::unit_test::data::monomorphic::is_dataset

条件是

boost::unit_test::data::monomorphic::is_dataset<D>::value

求值为true.

以下示例实现了一个生成斐波那契序列的自定义数据集.

示例: 自定义数据集示例

代码

 
#define BOOST_TEST_MODULE dataset_example68
#include <boost/test/included/unit_test.hpp>
#include <boost/test/data/test_case.hpp>
#include <boost/test/data/monomorphic.hpp>
#include <sstream>

namespace bdata = boost::unit_test::data;

// Dataset generating a Fibonacci sequence
class fibonacci_dataset {
public:
    // the type of the samples is deduced
    static const int arity = 1;

    struct iterator {

        iterator() : a(1), b(1) {}

        int operator*() const   { return b; }
        void operator++()
        {
            a = a + b;
            std::swap(a, b);
        }
    private:
        int a;
        int b; // b is the output
    };

    fibonacci_dataset()             {}

    // size is infinite
    bdata::size_t   size() const    { return bdata::BOOST_TEST_DS_INFINITE_SIZE; }

    // iterator
    iterator        begin() const   { return iterator(); }
};

namespace boost { namespace unit_test { namespace data { namespace monomorphic {
  // registering fibonacci_dataset as a proper dataset
  template <>
  struct is_dataset<fibonacci_dataset> : boost::mpl::true_ {};
}}}}

// Creating a test-driven dataset, the zip is for checking
BOOST_DATA_TEST_CASE(
    test1,
    fibonacci_dataset() ^ bdata::make( { 1, 2, 3, 5, 8, 13, 21, 35, 56 } ),
    fib_sample, exp)
{
      BOOST_TEST(fib_sample == exp);
}

数据集的创建与延迟创建

如上定义的数据集在测试模块开始执行之前就作为全局对象被构造. 这使得在数据集生成器内部以及迭代期间, 无法访问诸如argc / argv、主测试套件(以及预处理后的argc / argv)或任何在测试模块入口的main之后才实例化的对象.

为克服这一点, 引入了延迟数据集实例化接口. 它有效地把数据集包装在另一个数据集中, 后者以惰性方式实例化数据集.

要实例化延迟数据集, 应使用 boost::unit_test::data::monomorphic::make_delayed 函数, 写在BOOST_DATA_TEST_CASE调用中. 以下代码片段:

BOOST_DATA_TEST_CASE(dataset_test_case,
    boost::unit_test::data::make_delayed<custom_dataset>(arg1, ... ), ...)
{
}

创建了一个带类型为custom_dataset生成器的延迟数据集测试用例. 生成器以惰性方式用arg1、...构造.

提示

延迟创建的详细示例见关于自定义命令行参数的一节.

提示

关于包装对象的更多细节见类monomorphic::delayed_dataset.
