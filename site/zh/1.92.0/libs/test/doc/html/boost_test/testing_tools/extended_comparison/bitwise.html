按位比较

注意

该特性对非 C++11 编译器不可用.

可以把操纵器boost::test_tools::bitwise提供给BOOST_TEST宏, 以对操作数进行按位比较. 此时, 单元测试框架会指出两个操作数不匹配的位索引.

示例: BOOST_TEST 按位比较

代码

 
#define BOOST_TEST_MODULE boost_test_bitwise
#include <boost/test/included/unit_test.hpp>
#include <sstream>

BOOST_AUTO_TEST_CASE(test_bitwise)
{
  namespace tt = boost::test_tools;
  int a = 0xAB;
  BOOST_TEST( a == (a & ~1), tt::bitwise() );
  BOOST_TEST( a == a + 1, tt::bitwise() );
  BOOST_TEST( a != a + 1, tt::bitwise() );
  int b = 0x88;
  BOOST_TEST( a == b, tt::bitwise() );
}
