控制输出的 API 汇总

宏

简要说明

BOOST_TEST_MESSAGE

自定义消息输出

BOOST_TEST_DONT_PRINT_LOG_VALUE

在测试失败时禁用特定类型的打印

BOOST_TEST_CHECKPOINT

指示一个将在失败时打印的命名检查点

BOOST_TEST_PASSPOINT

指示一个将在失败时打印的未命名检查点

BOOST_TEST_INFO

定义一条消息, 若遇到的第一个断言失败, 将其作为该断言上下文的一部分打印

BOOST_TEST_CONTEXT

定义一个作用域和一条消息, 该作用域内每个失败的断言都会把它作为上下文的一部分打印

BOOST_TEST_INFO_SCOPE

定义BOOST_TEST_INFO的粘滞作用域版本, 它附着在此声明之后且在当前作用域内的所有断言上.
