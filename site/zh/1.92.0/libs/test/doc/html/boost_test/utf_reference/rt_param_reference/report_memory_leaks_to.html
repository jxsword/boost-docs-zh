report_memory_leaks_to

参数report_memory_leaks_to允许指定报告内存泄漏的目标文件. 该参数没有默认值. 若未指定, 内存泄漏(如有)会报告到标准错误流.

可接受值

任意文件名string.

命令行语法
  • --report_memory_leaks_to=<file name>
环境变量 
BOOST_TEST_REPORT_MEMORY_LEAKS_TO
