无参数测试用例

最常见的场景是你想编写不带任何参数的测试用例. 单元测试框架同时为你提供了自动和手动注册 API 来声明这类测试用例.

自动注册

要声明无参数且在实现处注册的测试用例, 使用宏BOOST_AUTO_TEST_CASE.

BOOST_AUTO_TEST_CASE(test_case_name);

此 API 的设计尽量贴近无参自由函数声明语法. 与自由函数相比, 你只需省略结果类型和圆括号, 并把测试用例名包进 BOOST_AUTO_TEST_CASE:

示例: 带自动注册的基于无参函数的测试用例

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>

BOOST_AUTO_TEST_CASE( free_test_function )
/* Compare with void free_test_function() */
{
  BOOST_TEST( true /* test assertion */ );
}

输出

 
> example
Running 1 test case...

*** No errors detected

使用该宏, 你无需执行任何其他注册步骤. 该宏会自动创建并注册名为free_test_function的测试用例.

手动注册

单元测试框架支持基于无参自由函数、无参函数对象(包括用boost::bind创建的以及无参boost::function实例)手动创建无参数测试用例. 为此, 使用宏BOOST_TEST_CASE:

BOOST_TEST_CASE(test_function);

BOOST_TEST_CASE创建类boost::unit_test::test_case的一个实例并返回指向所构造实例的指针. 测试用例名从宏参数 test_function 推导. 如果你希望指定不同的测试用例名, 你要么

  • 改用宏BOOST_TEST_CASE_NAME
  • 要么改用底层的make_test_case接口.

要注册新测试用例, 使用方法test_suite::add. 测试用例的创建和注册都在测试模块初始化函数中执行.

下面是手动注册测试用例的最简单示例. 单个测试用例在测试模块初始化例程中创建并注册. 注意自由函数名以地址形式传给宏BOOST_TEST_CASE`.

示例: 手动注册的无参自由函数

代码

 
#include <boost/test/included/unit_test.hpp>
using namespace boost::unit_test;

void free_test_function()
{
  BOOST_TEST( true /* test assertion */ );
}

test_suite* init_unit_test_suite( int /*argc*/, char* /*argv*/[] )
{
  framework::master_test_suite().
    add( BOOST_TEST_CASE( &free_test_function ) );
  framework::master_test_suite().
    add( BOOST_TEST_CASE_NAME( &free_test_function, "second-check-free-test-function" ) );
  return 0;
}

测试用例可以实现为类的方法. 此时需要把指向类实例的指针绑定到测试方法以创建测试用例. 你可以对多个测试用例使用同一个类实例. 单元测试框架不取得类实例的所有权, 你需要自行管理类实例的生命周期.

警告

类实例不能定义在初始化函数作用域内, 因为测试执行一离开该作用域它就失效了. 它需要以静态/全局方式定义, 或用共享指针管理.

示例: 绑定到共享类实例并手动注册的类无参方法

代码

 
#include <boost/test/included/unit_test.hpp>
#include <boost/bind/bind.hpp>
using namespace boost::unit_test;

class test_class
{
public:
  void test_method1()
  {
    BOOST_TEST( true /* test assertion */ );
  }
  void test_method2()
  {
    BOOST_TEST( false /* test assertion */ );
  }
};

test_suite* init_unit_test_suite( int /*argc*/, char* /*argv*/[] )
{
  boost::shared_ptr<test_class> tester( new test_class );

  framework::master_test_suite().
    add( BOOST_TEST_CASE( boost::bind( &test_class::test_method1, tester )));
  framework::master_test_suite().
    add( BOOST_TEST_CASE( boost::bind( &test_class::test_method2, tester )));
  return 0;
}

输出

 
> example
Running 2 test cases...
test.cpp(22): error: in "boost::bind( &test_class::test_method2, tester )": check false has failed

*** 1 failure is detected in the test module "Master Test Suite"
