运行期参数汇总

命令

简要说明

auto_start_dbg

指示框架在系统故障时自动挂接调试器.

build_info

指示框架显示库构建信息.

catch_system_error

指示框架捕获系统错误.

color_output

指示框架产生彩色输出

detect_fp_exceptions

指示框架捕获浮点异常(在受支持的平台上).

detect_memory_leaks

指示框架检测内存泄漏(在受支持的平台上).

help

提供关于单元测试框架参数的帮助.

list_content

列出测试单元、它们在测试树中的组织方式、启用/禁用状态等......

list_labels

列出测试模块中定义的标签.

log_format

指定日志格式

log_level

指定框架的日志级别

log_sink

指定测试日志的写入位置.

logger

指定一个或多个日志记录器的日志级别、格式和接收器.

output_format

指定日志格式与报告格式.

random

指示框架以随机顺序运行测试

report_format

指定报告格式.

report_level

指定框架测试结果报告承载的详细程度.

report_memory_leaks_to

指定内存泄漏报告应重定向到的文件名.

report_sink

指定测试结果报告的写入位置.

result_code

指示框架返回或忽略指示测试中存在错误的结果码.

run_test

允许在运行期过滤要执行的测试单元.

save_pattern

便于对测试输出流进行模式切换.

show_progress

指示框架打印进度信息. 更多细节见此处.

use_alt_stack

指示框架使用备选栈进行信号处理(在受支持的平台上).

usage

显示简短的用法消息.

wait_for_debugger

指示框架在测试开始前暂停测试模块, 以便调试器挂接.
