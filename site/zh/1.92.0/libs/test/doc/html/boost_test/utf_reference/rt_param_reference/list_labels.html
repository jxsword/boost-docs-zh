list_labels

列出当前测试模块中与测试单元关联的标签并退出(不运行任何测试).

提示

关于标签与测试用例逻辑分组的更多细节见本节.

可接受值

Boolean, 默认值no.

命令行语法
  • --list_labels[=<boolean value>]
环境变量 
BOOST_TEST_LIST_LABELS
示例

--list_content的前一个示例给出

> ./boost_runtime_list_content --list_labels
Available labels:
  label1
  label2
