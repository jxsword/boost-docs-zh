日志格式

测试日志输出
HRF: 人类可读日志格式
XML 日志格式
JUNIT 日志格式

单元测试框架支持多种日志格式:

  • HRF: 人类可读格式
  • XML: 机器可解释的日志格式
  • JUNIT: 标准化日志格式, 可被持续构建等自动化工具理解
设计

日志框架支持以下功能:

  • 每个日志记录器管理自己的日志级别. 理由是某些日志格式面向自动化处理, 按设计需要承载全部信息, 供后续的可视化工具消化.
  • 多种日志格式可以同时处于活动状态. 理由是用户可能希望在终端上以人类友好的格式查看非详尽的日志, 同时在文件中保留专用于自动化处理格式的详细完整日志.
  • 每个日志记录器会指示其默认输出流. 某些记录器可能倾向于输出到某个标准流, 而另一些可能倾向于输出到文件.
注释

日志记录器在应使用默认值时指示默认输出流.

默认值

默认情况下, 活动日志级别阈值被设为

  • "非致命错误消息", 且测试日志以人类可读格式生成.
  • "一般信息", 适用于JUNIT日志格式

活动日志级别阈值和输出格式可以在测试模块调用时于运行期配置, 也可以在测试模块内部使用测试日志公共接口于编译期配置. 不过该行为是特定于日志记录器的.
