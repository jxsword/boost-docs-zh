日志输出流重定向

如果要把测试日志输出流重定向到日志记录器默认输出流(通常是std::cout、std::cerr或文件)之外的东西, 使用以下接口:

boost::unit_test::unit_test_log.set_stream( std::ostream& );

或针对特定日志格式:

boost::unit_test::unit_test_log.set_stream( boost::unit_test::output_format, std::ostream& );
提示

更多细节见boost::unit_test::unit_test_log_t::set_stream和 boost::unit_test::output_format

你可以在测试模块初始化期间以及测试用例内部随时重设输出流. 对输出流重设的次数也没有限制.

警告

如果你在全局夹具建立(setup)阶段重定向测试日志输出流, 则必须在拆除(teardown)阶段把它重设回std::cout, 以防止访问悬空引用

示例: 编译期日志输出重定向

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>
#include <fstream>

struct MyConfig {
  MyConfig() : test_log( "example.log" ) {
    boost::unit_test::unit_test_log.set_stream( test_log );
  }
  ~MyConfig() {
    boost::unit_test::unit_test_log.set_stream( std::cout );
  }
  std::ofstream test_log;
};

BOOST_TEST_GLOBAL_CONFIGURATION( MyConfig );

BOOST_AUTO_TEST_CASE( test_case ) {
  BOOST_TEST( false );
}

输出

 
> example

*** 1 failures is detected in test suite "example"
> cat example.log
Running 1 test case...
test.cpp(26): error in "test_case": check false failed
