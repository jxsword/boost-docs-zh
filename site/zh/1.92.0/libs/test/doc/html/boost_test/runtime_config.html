Boost.Test 运行期参数

单元测试框架支持多个影响测试模块执行的参数. 要设置参数值, 你可以在测试模块初始化函数中使用运行期配置子系统接口, 也可以在测试模块调用时在运行期指定该值.

单元测试框架提供两种在运行期设置参数的方式: 指定命令行参数, 或设置环境变量. 命令行参数总是覆盖对应的环境变量.

在测试模块初始化期间, 单元测试框架会解析命令行, 并把属于它的所有参数及其值从参数列表中剔除. 命令行的其余部分会转发给你提供的测试模块初始化函数. 单元测试框架期望的命令行参数格式为:

  --<command_line_argument_name>=<argument_value>

命令行参数名区分大小写, 必须与参数规范中的名称完全一致. '=' 与参数名或参数值之间不能有任何空格.

对应的环境变量名同样区分大小写, 且必须与参数规范中的名称完全一致.

单元测试框架当前支持的全部参数信息汇总在汇总一节中.

测试过滤

单元测试框架提供了强大的过滤设施, 让运行特定测试或测试子集变得容易. 过滤一节给出了命令行接口的全部细节.

此外, 可以使用测试套件和标签以高效便捷的方式构造测试子集, 而装饰器(例如disabled、precondition)可用于设置测试用例的默认运行状态.

自定义运行期参数

通过提供自定义的命令行解释逻辑, 还可以进一步扩展命令行接口. 有多种方式可以把这种逻辑集成进单元测试框架, 详细说明见自定义运行期参数一节.
