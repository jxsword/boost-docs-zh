BOOST_TEST_ALTERNATIVE_INIT_API

警告

该宏应在任何对单元测试框架头文件的包含指令之前定义, 且与宏BOOST_TEST_MODULE互斥.

在自定义测试模块入口点初始化的情况下, 该宏指示单元测试框架使用新 API. 新旧 API 之间的差异在本节描述.

定制测试模块入口点的方式取决于所使用的单元测试框架变体. 文档中有几节专门讨论此主题:

  • 本节, 适用于单头文件变体,
  • 本节, 适用于静态链接变体,
  • 本节, 适用于共享链接变体
