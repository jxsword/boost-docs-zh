use_alt_stack

选项use_alt_stack指示单元测试框架在受支持的平台上使用备选栈进行信号处理. 关于此特性的更多信息见此处. 该特性默认启用, 但可用此参数禁用.

注释

如果你的编译器不支持该特性, 该命令行选项会被静默忽略.

注释

可以用宏BOOST_TEST_DISABLE_ALT_STACK移除对备选栈的支持

可接受值

Boolean, 默认值yes.

命令行语法
  • --use_alt_stack[=<boolean value>]
环境变量 
BOOST_TEST_USE_ALT_STACK
