show_progress

选项show_progress指示单元测试框架显示测试进度信息. 默认不显示参数测试进度. 更多细节见此处.

可接受值

Boolean, 默认值no.

命令行语法
  • --show_progress[=<boolean value>]
  • -p [<boolean value>]
环境变量 
BOOST_TEST_SHOW_PROGRESS
