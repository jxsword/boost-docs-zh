外部测试运行器使用变体

这种使用变体不提供任何测试运行器. 当你只想定义一个测试树以及可能的初始化函数, 并期望另一个(外部)程序来执行这些测试时, 可以采用它. 这个外部程序会带有自己的测试运行器.

如果计划让测试模块搭配外部测试运行器使用, 就需要把它构建为动态库. 你需要定义宏标志BOOST_TEST_DYN_LINK, 写在 makefile 中或包含头文件boost/test/unit_test.hpp之前. 外部测试运行器工具需要与动态库链接.

单元测试框架附带了一个外部测试运行器示例console_test_runner: 给定测试模块(实现为共享库)的名称以及其中定义的初始化函数的名称, 该程序即可运行模块测试树中的所有测试.
