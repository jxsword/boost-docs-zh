random

参数random指示单元测试框架以随机顺序执行测试用例. 该参数接受一个可选的unsigned integer参数作为随机生成器的种子:

  • 默认情况下(值0), 测试用例按测试文件中测试单元的顺序以及测试单元间的依赖所定义的特定顺序执行.
  • 若指定该参数时不带参数值, 或值为1, 测试顺序会基于当前时间随机化.
  • 或者, 任何大于1的正值都会用作本次运行的随机种子.
提示

若指定了--random, 种子的值会用BOOST_TEST_MESSAGE记录, 以便在失败时能够精确重放同样的单元测试序列. 为让种子在日志中可见, 请确保设置了正确的--log_level.

可接受值
  • 0(默认): 不随机化
  • 1: 基于当前时间的随机种子
  • integer value > 1 : 随机数生成器的种子
命令行语法
  • --random=<seed>
环境变量 
BOOST_TEST_RANDOM
