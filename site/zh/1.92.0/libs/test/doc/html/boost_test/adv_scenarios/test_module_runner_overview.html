测试模块运行器

测试模块运行器是一个编排器或驱动器, 给定测试树后, 它确保测试树被初始化、测试被执行并生成必要的报告. 它执行以下操作:

  • 使用给定的初始化函数初始化测试模块;
  • 为测试日志和测试结果报告选择输出介质;
  • 按运行期参数的规定执行测试用例;
  • 生成测试结果报告;
  • 产生相应的返回码.

单元测试框架自带默认测试运行器. 无需显式调用它. 默认生成的测试模块入口点会调用默认测试运行器. 默认测试运行器采用如下签名声明:

namespace boost { namespace unit_test {

  typedef bool (*init_unit_test_func)();

  int unit_test_main( init_unit_test_func init_func, int argc, char* argv[] );

} }

测试运行器可能返回以下值之一:

值

含义

boost::exit_success

  • 测试期间未发生错误, 或
  • 通过命令行参数--[link boost_test.utf_reference.rt_param_reference.result_code result_code]=no强制指定了成功结果.

boost::exit_test_failure

  • 测试期间检测到非致命错误且未抛出未捕获异常, 或
  • 单元测试框架初始化失败.

boost::exit_exception_failure

  • 检测到致命错误, 或
  • 测试期间抛出了未捕获异常.

高级测试运行器可提供更多功能, 包括交互式 GUI 界面、测试覆盖率与性能分析支持.
