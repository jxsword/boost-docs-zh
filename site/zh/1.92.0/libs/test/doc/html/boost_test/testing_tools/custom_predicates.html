自定义谓词支持

尽管提供的测试工具覆盖了广泛的检查类型, 并在某些情况下提供关于错误原因的详细报告, 你有时可能仍希望实现并使用自定义谓词来执行复杂检查, 并在失败时给出智能化的报告. 为满足这一需求, 测试工具实现了自定义谓词支持. 测试工具工具箱实现的自定义谓词支持分为两层: 带与不带自定义错误消息生成.

第一层由BOOST_<level>_PREDICATE测试工具家族支持. 你可以用它检查任何以布尔值报告结果的自定义谓词. 失败时, 谓词参数的值会被工具自动报告.

示例: 自定义谓词支持 - BOOST_<level>_PREDICATE

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>

bool is_even( int i )
{
  return i%2 == 0;
}

BOOST_AUTO_TEST_CASE( test_is_even )
{
  BOOST_CHECK_PREDICATE( is_even, (14) );

  int i = 17;
  BOOST_CHECK_PREDICATE( is_even, (i) );
}

输出

 
> example
Running 1 test case...
test.cpp(13): error in "test_is_even": check is_even( i ) has failed for ( 17 )

*** 1 failures is detected in test suite "example"

要使用第二层, 你的谓词必须返回boost::test_tools::predicate_result.

该类封装了布尔结果值以及你选择报告的任何错误或提示消息.

通常你在谓词函数内部构造类boost::test_tools::predicate_result的实例并按值返回它. 构造函数期望一个参数 - 布尔结果值. 该构造函数是隐式的, 因此你可以简单地从谓词返回布尔值, boost::test_tools::predicate_result会自动构造以保存你的值和空消息. 你也可以向已构造的实例赋布尔值. 可以用operator!或直接访问公共只读属性p_predicate_value来检查当前谓词值. 错误消息存储在公共读写属性p_message中.

示例: 使用类 boost::test_tools::predicate_result 的自定义谓词支持

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>

boost::test_tools::predicate_result
  compare_lists( std::list<int> const& l1, std::list<int> const& l2 )
{
  if( l1.size() != l2.size() )
  {
    boost::test_tools::predicate_result res( false );

    res.message() << "Different sizes [" << l1.size() << "!=" << l2.size() << "]";

    return res;
  }
  return true;
}

BOOST_AUTO_TEST_CASE( test_list_comparison )
{
  std::list<int> l1, l2;
  l1.push_back( 1 );
  l1.push_back( 2 );

  BOOST_TEST( compare_lists( l1, l2 ) );
}

输出

 
Running 1 test case...
test.cpp(28): error in "test_list_comparizon": check compare_lists( l1, l2 ) has failed. Different sizes [2!=0]

*** 1 failures is detected in test suite "example"
