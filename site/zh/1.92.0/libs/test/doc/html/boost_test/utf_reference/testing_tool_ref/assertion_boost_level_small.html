BOOST_<level>_SMALL 

BOOST_WARN_SMALL(value, tolerance);
BOOST_CHECK_SMALL(value, tolerance);
BOOST_REQUIRE_SMALL(value, tolerance);

这些工具用于检查给定值是否足够小. “小”的程度由作为第二个参数提供的容差的绝对值定义. 请谨慎使用这些工具. 要比较两个值的接近程度, 最好改用 BOOST_<level>_CLOSE 工具.

第一个参数是要检查的值. 第二个参数是容差.

注释

当按前几节所述包含 单元测试框架 时, 浮点比较工具会被自动添加. 这些工具实现在头文件 boost/test/tools/floating_point_comparison.hpp 中.

示例: BOOST_<level>_SMALL 用法

代码

 
#define BOOST_TEST_MODULE example
#include <boost/test/included/unit_test.hpp>
#include <boost/test/tools/floating_point_comparison.hpp>

BOOST_AUTO_TEST_CASE( test )
{
  double v = -1.23456e-3;
  BOOST_CHECK_SMALL( v, 0.000001 );
}

输出

 
> example
Running 1 test case...
test.cpp(11): error in "test": absolute value of v{-0.00123456} exceeds 1e-006

*** 1 failures is detected in test suite "example"
