本库应当能在任何符合 C++14 标准的编译器上正确编译和运行.

Safe Numerics 库基于此处描述的一些更基础的软件组件实现. 使用本库无需了解这些组件. 收录这些信息是为了帮助那些想理解库的工作原理的人, 以便他们扩展库、修正其中的缺陷或理解其局限. 这些组件本身也很有趣且可能有用. 基于所有这些原因, 在此对它们加以说明.

概括地说, 本库按以下方式工作:

在编译期:

  • 本库定义了 C++ 原始算术类型 (如 int, unsigned int 等) 的 "safe" 版本.

  • 为这些 "safe" 类型定义了算术运算符. 这些运算符是标准 C/C++ 实现的增强版. 它们在文件 "safe_base.hpp" 和 "safe_base_operations.hpp" 中声明并实现.

  • 对于二元运算符, 验证两个操作数具有相同的提升策略和异常处理策略. 若不是, 则引发编译错误.

  • 调用提升策略来确定运算的结果类型 R.

  • 对每个 T 类型的操作数, 从 std::numeric_limits<T>::min() 和 std::numeric_limits<T>::max() 获取其值范围. 范围是一对值, 表示具有最小值和最大值的闭区间.

  • 这些范围被转换为结果类型 R 的等价值. 值可能无法转换到结果类型, 因此转换结果以 variant 类型返回, 即 checked_result<R> . checked_result<R> 可以保存 R 类型的值, 或保存说明为何无法完成转换的 safe_numerics_error 值. 范围表示为 checked_result<R> 类型的一对值.

  • checked_result<R> 可以视为底层类型 R 的增强版. 对 R 类型的值合法的运算 (如 +、- 等) 对 checked_result<R> 的值同样合法. 区别在于后者可以记录运算失败, 并把失败传播到后续运算.checked_result<R> 实现于头文件 "checked_result.hpp". 此类类型上的运算实现于 "checked_result_operations.hpp".

  • 给定操作数的范围, 使用编译期区间算术确定运算结果的范围. C++14 的 constexpr 设施允许在编译期计算结果的范围. 区间算术实现于头文件 "interval.hpp". 结果的范围同样表示为 checked_result<R> 类型的一对值.

  • 对原始类型的运算通过描述为 受检算术 的独立函数实现. 这些运算将返回 checked_result<R> 的实例.

在运行期:

  • 如果结果类型的范围只包含算术上有效的值, 则保证运算产生算术上正确的结果, 无需运行期检查. 该运算调用原始的内建 C/C++ 运算并返回结果值.

  • 否则, 按照所选提升策略把操作数转换 (cast) 到结果类型 R. 这些 "受检" 转换操作返回 checked_result<R> 类型的值.

  • 如果任一转换操作失败, 则按照异常策略处理异常.

  • 否则, 使用 "受检算术" 执行运算. 这些自由函数与普通运算符 +、-、* 等一一对应, 区别在于它们不返回 R 类型的值, 而是返回 checked_result<R> 类型的值. 它们定义于文件 "checked_default.hpp", "checked_integer.hpp" ,"checked_float.hpp"

  • 如果运算不成功, 则调用指定的异常策略函数.

  • 否则, 结果值将作为 safe<R> 类型返回, 并带有上面计算的结果范围.
