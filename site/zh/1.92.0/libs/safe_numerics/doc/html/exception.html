说明

这里我们描述用于指代可能发生的异常情况的数据类型. 注意, 当我们使用 "exception" 一词时, 我们不是指指代数据类型的 C++ 术语, 而是其通俗意义: 异常、不规则、偏离、特殊情况、孤立示例、独特之处、异常状态、怪事; 不合群、越轨或超出寻常的事件. "exception" 这一概念比人们想象的更复杂, 因此不由单一的简单类型体现. 库中由少数几个类型共同实现这一概念.

我们利用了标准库中的 std::error_code . 我们没有使用它提供的全部设施, 所以它并非完全匹配, 但它有用, 且能满足我们的目的.

enum class safe_numerics_error

以下是数值结果可能返回的值. 它们类似于 C++ 标准异常使用的标准错误码. 这种相似纯属巧合, 它们与任何同名代码毫无关系. 相似的原因是本库开发初期使用标准库的错误码. 但随着开发的进行, 原有的错误码显然不够用, 因此现在它们自成一体. 以下是错误码列表. 其含义的描述为

符号 说明
success 成功的操作 - 未返回错误
positive_overflow_error 正数太大, 无法由该数据类型表示
negative_overflow_error 负数的绝对值太大, 无法由该数据类型表示.
domain_error 运算的结果超出结果的合法范围.
range_error 函数或运算符的实参超出合法范围 - 例如 sqrt(-1).
precision_overflow_error 在执行运算的过程中损失了精度.
underflow_error 数字太接近零, 无法由该数据类型表示.
uninitialized_value 根据 C++ 标准, 结果可能由应用程序定义. 例如 16 >> 10 在大多数机器上会产生预期的结果 0.

上述列出的错误码可以用函数转换为 std::error_code 类型的实例:

std::error_code make_error_code(safe_numerics_error e)

此对象可以

enum class safe_numerics_actions

上述错误码按此类异常应如何处理进行分组. 下表显示错误可能被映射到的动作.

符号 说明
no_action 成功的操作 - 无需任何动作
uninitialized_value 报告试图使用未初始化的值 - 目前未使用
arithmetic_error 报告算术错误
implementation_defined_behavior 报告 C++ 标准允许但未明确规定的运算
undefined_behavior 报告结果被 C++ 标准定义为未定义的运算.

可以用以下函数把 safe_numerics_error 转换为对应的 safe_numerics_action:

constexpr enum  safe_numerics_actions
make_safe_numerics_action(const safe_numerics_error & e);
