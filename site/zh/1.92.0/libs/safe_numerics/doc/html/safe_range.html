说明

此类型在闭范围 [MIN, MAX] 内保存有符号或无符号整数. safe_signed_range<MIN, MAX, PP, EP> 或 safe_unsigned_range<MIN, MAX, PP, EP> 可用于任何允许算术类型的地方. 使用这两种类型中任一种的任何表达式都保证返回算术上正确的值, 或以某种方式设陷.

记法

符号 说明
MIN, MAX 该范围能表示的最小值和最大值.

关联类型

PP 提升策略. 规定使用 safe 类型的表达式结果类型的类型.
EP 异常策略. 包含在无法返回正确结果时被调用的成员的类型

模板参数

参数 要求 说明
T std::is_integer<T>

底层类型. 目前仅支持内建整数类型
MIN 必须是非负字面量 该类型可持有的最小非负整数值
MAX 必须是非负字面量 该类型可持有的最大非负整数值
  MIN <= MAX 必须是有效的闭范围
PP PromotionPolicy<PP>

默认值为 boost::numeric::native
EP Exception Policy<EP>

默认值为 boost::numeric::default_exception_policy

建模

数值

Integer

有效表达式

实现基类型 T 支持的全部表达式且仅这些表达式. 注意所有这些表达式都是 constexpr . 此类表达式的结果类型将是另一个 safe 类型. 此类表达式结果的实际类型取决于具体的提升策略模板参数.

当二元操作应用于 safe_signed_range<MIN, MAX, PP, EP> 或 safe_unsigned_range<MIN, MAX, PP, EP> 的两个实例时, 以下之一必须为真:

  • 两个操作数的提升策略必须相同, 或其中之一为 void

  • 两个操作数的异常策略必须相同, 或其中之一为 void

如果以上任一条件不成立, 将产生编译错误.

#include <exception>
#include <iostream>
#include <type_traits>
#include <boost/safe_numerics/safe_integer.hpp>
#include <boost/safe_numerics/safe_integer_range.hpp>
#include <boost/safe_numerics/safe_integer_literal.hpp>

#include <boost/safe_numerics/utility.hpp>

using namespace boost::safe_numerics;

int main(){
    safe_unsigned_range<7, 24> i;
    
    // since the range is included in [0,255], the underlying type of i
    // will be an unsigned char.
    try{
        i = 0;  // throws out_of_range exception
        std::cout << "fails to detect erroneous assignment" << std::endl;
    }
    catch(std::exception & e){
        // should arrive here
    }
    try{
        i = 9;  // ok - no exception expected
    }
    catch(std::exception & e){
        std::cout << "erroneous error for legal assignment" << std::endl;
    }
    try{
        i *= 9; // fails to compile because result can't fin in range
        std::cout << "fails to out of range result" << std::endl;
    }
    catch(std::exception & e){
        // should arrive here
    }
    try{
        i = -1; // throws out_of_range exception
        std::cout << "fails to detect erroneous assignment" << std::endl;
    }
    catch(std::exception & e){
        // should arrive here
    }
    std::uint8_t j = 4;
    auto k = i + j;

    // if either or both types are safe types, the result is a safe type
    // determined by promotion policy.  In this instance
    // the range of i is [7, 24] and the range of j is [0,255].
    // so the type of k will be a safe type with a range of [7,279]
    static_assert(
        is_safe<decltype(k)>::value
        && std::numeric_limits<decltype(k)>::min() == 7
        && std::numeric_limits<decltype(k)>::max() == 279,
        "k is a safe range of [7,279]"
    );
    return 0;
}
