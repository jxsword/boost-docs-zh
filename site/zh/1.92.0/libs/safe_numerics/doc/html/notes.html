Safe Numerics

背景

本库最初是对 David LeBlanc 的 SafeInt 库 所提供设施的重新实现. 我发现这个库在各方面都做得很好. 我的主要用途是在我的 PC 上为嵌入式系统项目运行单元测试. 不过, 在我看来它有几个问题.

  • 一个头文件中代码量很大 - 6400 行. 理解、修改和维护都非常笨重.

  • 除了头文件中的文档外, 我找不到单独的文档.

  • 它没有使用 Boost 的命名约定.

  • 它需要移植到不同的编译器.

  • 它带有一个很长的许可证.

  • 我找不到该库的测试套件.

使用更新版本的 C++ 及其标准库、模板元编程和 Boost 库, 我设法在不到 2000 行代码内 (重新) 实现了类似的功能. 我把该版本作为可能的提交推荐给 Boost. 我收到的反馈让我确信, 这样的库不会被大多数 C++ 程序员认为是可接受的. 似乎对最高性能的渴望压倒了对程序无缺陷的要求. 到那时, 我对最新版 C++ (C++14) 所提供的机会有了更好的了解, 并决心通过创建一个以最小运行期开销提供全部 safe numerics 设施的库来解决这一问题. 成果就是你现在看到的. 该库现在包含 7000 行代码、约 50 个独立测试和 60 多页文档与示例.

在我写下上述内容之后, David LeBlanc 联系了我. 他一直在更新他的包, 并告知我最新版本:

  • SafeInt 不需要针对不同编译器移植, 在 gcc、clang 和 Visual Studio 上得到完全支持.

  • 许可证已从 MS-PL 更改为 MIT 许可证.

  • SafeInt 除了标准库文件外没有其他外部依赖, 无需安装任何其他东西即可工作.
