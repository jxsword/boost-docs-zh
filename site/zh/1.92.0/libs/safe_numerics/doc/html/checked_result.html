说明

checked_result 是一种特殊类型的 variant 类, 设计用于保存某个操作的结果. 它可以保存操作的结果, 或者保存操作为何未能产生有效结果的信息. 它类似于为 C++ 标准库或 Boost 提议和/或收入的其他类型, 例如 expected, variant, optional 和 outcome . 在某些情况下它可能被称为 "monad".

  • checked_result<R> 的所有实例都是不可变的. 也就是说, 一旦构造, 就不能更改.

  • 没有默认构造函数.

  • checked_result<R> 永不为空.

  • 类型 R 支持的二元运算保证被 checked_result<R> 支持.

  • 当且仅当两个 checked_result<R> 实例的底层类型 (R) 相同时, 才能对它们调用二元运算. 它们将返回 checked_result<R> 类型的值.

  • 可以对 checked_result<R> 实例调用一元运算. 它们将返回 checked_result<R> 类型的值.

  • 比较运算将返回 boost::logic::tribool . 其他二元运算将返回与实参相同类型的值.

把 checked<R> 想成 R 的 "扩展" 版本, 它除了能保存 R 能保存的所有值外, 还能保存其他 "特殊值". 例如, 考虑 checked<int>.

#include <iostream>

#include <boost/safe_numerics/checked_result.hpp>
#include <boost/safe_numerics/checked_result_operations.hpp>

int main(){
    using ext_uint = boost::safe_numerics::checked_result<unsigned int>;
    const ext_uint x{4};
    const ext_uint y{3};

    // operation is a success!
    std::cout << "success! x - y = " << x - y;

    // subtraction would result in -1, and invalid result for an unsigned value
    std::cout << "problem: y - x = " << y - x;

    const ext_uint z = y - x;
    std::cout << "z = " << z;
    // sum of two negative overflows is a negative overflow.
    std::cout << "z + z" << z + z;

    return 0;
}
