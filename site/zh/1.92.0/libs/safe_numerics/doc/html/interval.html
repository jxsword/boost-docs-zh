说明

由一对 R 类型元素表示的闭算术区间. 原则上, 应该可以使用 Boost.Interval 库来实现. 但该库中的函数不是 constexpr . 此外, Boost.Interval 更复杂, 且不支持某些运算 (如位运算). 也许将来某个时候, Boost.Interval 会取代这个 interval<R> 类型.

模板参数

R 必须对 Numeric 的类型需求建模. 注意这原则上包括任何数值类型, 包括浮点数以及 checked_result<R> 的实例.

记法

符号 说明
I 一个区间类型
i, j 区间类型的实例
R 可用于构造区间的数值类型
r 类型 R 的一个实例
p std::pair<R, R> 的一个实例
l, u 区间中的最下值和最上值
os std::basic_ostream<class CharT, class Traits = std::char_traits<CharT>>

关联类型

checked_result 保存运算结果, 或保存其失败原因的信息

使用示例

#include <iostream>
#include <cstdint>
#include <cassert>
#include <boost/numeric/safe_numerics/interval.hpp>

int main(){
    std::cout << "test1" << std::endl;
    interval<std::int16_t> x = {-64, 63};
    std::cout << "x = " << x << std::endl;
    interval<std::int16_t> y(-128, 126);
    std::cout << "y = " << y << std::endl;
    assert(static_cast<interval<std::int16_t>>(add<std::int16_t>(x,x)) == y);
    std::cout << "x + x =" << add<std::int16_t>(x, x) << std::endl;
    std::cout << "x - x = " << subtract<std::int16_t>(x, x) << std::endl;
    return 0;
}
