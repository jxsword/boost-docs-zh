说明

如果一个类型具有整数的性质, 它就满足 Integer 的要求.

更具体地说, 如果存在一个 std::numeric_limits<T> for which std::numeric_limits<T>::is_integer 的特化等于 true . 参见标准库类 numeric_limits 的文档. 标准库为所有内建数值类型提供了这样的特化. 注意, 这一概念不同于 C++ 标准库类型特征 is_integral 和 is_arithmetic . 后者满足 Numeric 概念的要求. 但也存在满足本概念却不满足 is_arithmetic<T>::value == false 的类型. 例如参见 safe<int>
