说明

保存字面量值的 safe 类型. 需要它来以不生成异常码的方式初始化其他 safe 类型. 它在创建 safe 类型的 constexpr 版本时也很有用. 它包含一个在编译期已知的不可变值, 因此可用于任何 constexpr 表达式.

关联类型

PP 规定使用 safe 类型的表达式结果类型的类型.
EP 包含在无法返回正确结果时被调用的成员的类型

模板参数

参数 类型要求 说明
Value Integer 用于初始化字面量的值
PP PromotionPolicy<PP>

可选的提升策略. 默认值为 void
EP Exception Policy<EP>

可选的异常策略. 默认值为 void

建模

数值

Integer

继承的有效表达式

safe 字面量类型是不可变的. 因此它们只继承不改变值的有效表达式. 这不包括赋值、递增和递减, 以及除一元 -、+ 和 ~ 之外的所有一元运算符 . 除此之外, 它们可以用在任何能使用 Value 类型的地方. 注意默认提升策略和异常策略为 void. 这通常很方便, 因为当 safe 字面量用于二元运算时, 它将继承另一类型的策略. 另一方面, 当二元表达式的操作数都是 safe 字面量时, 这可能不便. 由于没有指定的提升和异常策略, 这将无法编译. 解决方法是像本例中那样指定具体策略.

template<typename T>
using compile_time_value = safe_signed_literal<T>;

constexpr compile_time_value<1000> x;
constexpr compile_time_value<0> y;

// should compile and execute without problem
    
std::cout << x << '\n';

// all the following statements should fail to compile because there are 
// no promotion and exception policies specified.
constexpr safe<int> z = x / y;

使用示例

#include <boost/safe_numerics/safe_integer_literal.hp>

constexpr boost::safe_numerics::safe_signed_literal<42> x;

make_safe_literal(n, PP, EP)

这是一个宏, 返回 safe 字面量类型的一个实例. 该实例将保存值 n. 返回值的类型将是能容纳值 n 的最小 safe 类型.
