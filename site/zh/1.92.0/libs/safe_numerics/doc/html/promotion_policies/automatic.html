Safe Numerics

automatic

说明

该类型包含一些元函数, 用于返回具有足够容量以容纳给定二元算术运算结果的类型.

对不同类型操作数执行算术运算的标准 C/C++ 过程是:

  • 使用 C++ 标准定义的相当繁复的规则把操作数转换为某个公共类型.

  • 执行运算.

  • 如果运算结果无法容纳于操作数的公共类型, 则丢弃高位.

automatic 提升策略用以下过程取代标准 C/C++ 过程:

  • 按以下规则把操作数转换为某个公共类型.

    • 对于加法. 若两个操作数都是无符号, 公共类型为无符号. 否则为有符号.

    • 对于减法, 公共类型为有符号.

    • 对于左/右移位, 结果的符号为左操作数的符号.

    • 对于所有其他类型的运算, 若两个操作数都是无符号, 公共类型为无符号. 否则为有符号.

  • 确定能保证容纳结果的最小有符号或无符号类型大小.

  • 如果该大小超过编译器支持的最大大小, 则使用编译器支持的最大大小.

  • 执行运算.

    • 把每个操作数转换为公共类型.

    • 如果结果无法按上述方式容纳于结果类型, 则调用错误过程.

    • 否则, 以公共类型返回结果

此类型提升策略仅适用于基类型为 Integer 类型的 safe 类型.

建模

PromotionPolicy

使用示例

以下示例演示把 automatic 类型作为 safe<int> 类型的模板参数传递.

#include <boost/safe_numerics/safe_integer.hpp> 
#include <boost/safe_numerics/automatic.hpp>
 
int main(){
    using namespace boost::numeric;
    // use automatic promotion policy where C++ standard arithmetic 
    // might lead to incorrect results
    using safe_t = safe<std::int8_t, automatic>;

    // In such cases, there is no runtime overhead from using safe types.
    safe_t x = 127;
    safe_t y = 2;
    // z is guaranteed correct without any runtime overhead or exception.
    auto z = x + y; 
    return 0;
}
