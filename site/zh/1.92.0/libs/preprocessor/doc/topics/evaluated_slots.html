会被求值的槽位

会被求值的槽位机制是一种工具, 用于对常量整数表达式进行完全求值, 并避免预处理器通常执行的惰性求值.

Tutorial

为了理解这种机制的用法, 我将从一个简单的文件迭代示例开始. 考虑以下场景....
for (int i = 0; i < 10; ++i) {
   for (int j = 0; j < i; ++j) {
      // ... use i and j
   }
}
上面是以下多维文件迭代的一个简单运行期模型....
// file.hpp
#if !BOOST_PP_IS_ITERATING
   #ifndef FILE_HPP_
   #define FILE_HPP_

   #include <boost/preprocessor/iteration/iterate.hpp>

   #define BOOST_PP_ITERATION_PARAMS_1 (3, (0, 9, "file.hpp"))
   #include BOOST_PP_ITERATE()

   #endif // FILE_HPP_
#elif BOOST_PP_ITERATION_DEPTH() == 1
   #define I BOOST_PP_ITERATION()

   #define BOOST_PP_ITERATION_PARAMS_2 (3, (0, I, "file.hpp"))
   #include BOOST_PP_ITERATE()

   #undef I
#elif BOOST_PP_ITERATION_DEPTH() == 2
   #define J BOOST_PP_ITERATION()

   // use I and J

   #undef J
#endif
上面的代码有一个问题. 编写者期望 I 指向前一个迭代帧. 然而, 事实并非如此. 当用户引用 I 时, 他实际上引用的是 BOOST_PP_ITERATION(), 而不是 BOOST_PP_ITERATION() 在定义点的值. 相反, 它引用的值与 J 引用的值完全相同.
问题在于预处理器总是用惰性求值来求值一切. 要解决这个问题, 我们需要 I 在此处被 求值:
// ...
#elif BOOST_PP_ITERATION_DEPTH() == 1
   #define I BOOST_PP_ITERATION()
// ...
幸运的是, 本库恰好提供了一个这样的机制: 会被求值的槽位. 以下代码使用该机制来“修复”上面的示例...
// ...
#elif BOOST_PP_ITERATION_DEPTH() == 1
   #define BOOST_PP_VALUE BOOST_PP_ITERATION()
   #include BOOST_PP_ASSIGN_SLOT(1)
   #define I BOOST_PP_SLOT(1)
// ...
为一个会被求值的槽位赋值有两个步骤. 首先, 用户必须定义 命名外部实参 BOOST_PP_VALUE. 该值必须是一个整型常量表达式. 其次, 用户必须 包含 BOOST_PP_ASSIGN_SLOT(x), 其中 x 是要赋值给的具体槽位 (1 到 BOOST_PP_LIMIT_SLOT_COUNT). 这会求值 BOOST_PP_VALUE, 并把结果赋给索引为 x 的槽位.
要取回槽位的值, 用户必须使用 BOOST_PP_SLOT(x).
在上面的例子中, I 仍然是惰性求值的. 然而, 它现在求值为 BOOST_PP_SLOT(1). 这个值 不会再改变, 除非随后调用 BOOST_PP_ASSIGN_SLOT(1).

高级技术

槽位机制还可用于执行计算:
#include <iostream>

#include <boost/preprocessor/slot/slot.hpp>
#include <boost/preprocessor/stringize.hpp>

#define X() 4

#define BOOST_PP_VALUE 1 + 2 + 3 + X()
#include BOOST_PP_ASSIGN_SLOT(1)

#undef X

int main(void) {
   std::cout
      << BOOST_PP_STRINGIZE(BOOST_PP_SLOT(1))
      << &std::endl;
   return 0;
}
实质上, 凡是能在 #if (或 #elif) 预处理器指令中求值的东西都可用, 唯一例外是 defined 运算符.
甚至在重新赋值时也可以使用该槽位本身:
#define BOOST_PP_VALUE 20
#include BOOST_PP_ASSIGN_SLOT(1)

#define BOOST_PP_VALUE 2 * BOOST_PP_SLOT(1)
#include BOOST_PP_ASSIGN_SLOT(1)

BOOST_PP_SLOT(1) // 40
