局部迭代

局部迭代是一种简单的纵向重复构造. 它用用户指定范围内的每个数字展开一个宏. 每次展开各占单独一行.

Tutorial

该机制运行需要两条信息: 要迭代的范围, 以及每次迭代要展开的宏. 该机制通过两个 命名外部实参 获取这些信息. 这些实参被指定为名为 BOOST_PP_LOCAL_LIMITS 和 BOOST_PP_LOCAL_MACRO 的用户定义宏.
BOOST_PP_LOCAL_LIMITS 指定要迭代的值的范围. 它 必须展开为一个包含两个元素——下界和上界——的 元组. 上界和下界都必须是 0 到 BOOST_PP_LIMIT_ITERATION 范围内的数值. 例如, 如果用户希望一个宏用从 0 到 10 的数字展开, 那么 BOOST_PP_LOCAL_LIMITS 应这样定义:
#define BOOST_PP_LOCAL_LIMITS (0, 10)
注意, 宏名之后有一个空白. 该宏 并不接受 两个实参. 在上面的例子中, 如果没有这个空白, 就会发生预处理错误, 因为 0 和 10 不是有效的标识符.
在 BOOST_PP_LOCAL_LIMITS 宏中指定的上界和下界都是 会被求值的形参. 这意味着它们可以包含简单的算术或逻辑表达式. 例如, 上面的定义完全可以写成这样:
#define N() 5
#define BOOST_PP_LOCAL_LIMITS (0, N() + 5)
正因如此, 如果省略宏名后的空白, 该定义在语法上可能是有效的:
#define A 0
#define B 10
#define BOOST_PP_LOCAL_LIMITS(A, B)
   // note:  no whitespace   ^
如果发生这种情况, 该机制在尝试使用这个宏时会在内部产生错误. 由此产生的错误信息可能晦涩难懂, 所以请始终记得加上空白. 上面示例的 正确写法如下:
#define A 0
#define B 10
#define BOOST_PP_LOCAL_LIMITS (A, B)
   // note:  has whitespace  ^
BOOST_PP_LOCAL_MACRO 是由该机制展开的宏. 每次迭代时, 该宏都会用迭代的当前数字展开. 它必须被定义为一元宏, 或者展开为一个可以用一个实参调用的宏:
#define BOOST_PP_LOCAL_MACRO(n) \
   template<> struct sample<n> { }; \
   /**/
...或者...
#define SAMPLE(n) \
   template<> struct sample<n> { }; \
   /**/

#define BOOST_PP_LOCAL_MACRO SAMPLE
这两个宏定义好之后, 通过 包含 BOOST_PP_LOCAL_ITERATE() 即可启动局部迭代.
??=include BOOST_PP_LOCAL_ITERATE()
(??= 记号是 # 的三字符组 (trigraph). 我使用三字符组是为了清楚地表明我是在 包含一个文件, 而不是定义或展开宏, 但这并非必要. 即使是双字符组 (digraph) 版本 %: 也可以使用. 有些编译器不能顺利接受三字符组和双字符组, 请牢记这一点. 除此之外, 用哪个都可以, 随你喜欢.)
为了重复 sample 特化, 必须把这些部件拼在一起....
#define BOOST_PP_LOCAL_MACRO(n) \
   template<> struct sample<n> { }; \
   /**/

#define BOOST_PP_LOCAL_LIMITS (0, 10)
??=include BOOST_PP_LOCAL_ITERATE()
这将为 sample 生成一个特化, 对应 0 到 10 范围内的每个数字. 输出大致如下:
template<> struct sample<0> { };
template<> struct sample<1> { };
template<> struct sample<2> { };

// ...

template<> struct sample<10> { };
局部迭代完成后, BOOST_PP_LOCAL_LIMITS 和 BOOST_PP_LOCAL_MACRO 都会被自动取消定义. 如果这些值需要为将来的局部迭代保留, 就必须间接定义它们:
#define LIMITS (0, 10)

#define SAMPLE(n) \
   template<> struct sample<n> { }; \
   /**/

#define BOOST_PP_LOCAL_LIMITS LIMITS
#define BOOST_PP_LOCAL_MACRO(n) SAMPLE(n)

??=include BOOST_PP_LOCAL_ITERATE()
