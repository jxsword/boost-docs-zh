数组

数组是一种由二元素 元组构成的数据结构. 第一个元素是 数组中的元素个数. 第二个元素是另一个 元组, 包含 数组中的各个元素. 例如,
(3, (a, b, c))
...是一个包含 3 个元素——a、b 和 c——的 数组.
数组的主要优势在于它们存储了自己的大小. 正因如此, 访问元素不需要知道大小, 只要求某个索引处存在元素.
这使得宏形参的大小可以变化, 也使得数据状态可以改变大小, 而无需用户自行显式地跟踪大小.

数组可以为空, 即不含任何元素. 空数组的大小为 0. 空数组的记法是 '(0,())'.

一个 元组拥有 数组 的全部功能, 还知道自己的大小, 语法上也更易用. 数组 相比于 元组 的唯一优势在于 数组 可以为空, 而 元组 总是至少包含一个元素, 因此其大小永远不可能为 0.

一个 数组 的元素可以用 BOOST_PP_ARRAY_ELEM 提取, 而 数组 的大小可以用 BOOST_PP_ARRAY_SIZE 提取, 还可以把一个 数组 转换为更基本的 元组 数据结构, 使用 BOOST_PP_ARRAY_DATA.

原语

  • BOOST_PP_ARRAY_DATA
  • BOOST_PP_ARRAY_ELEM
  • BOOST_PP_ARRAY_SIZE
