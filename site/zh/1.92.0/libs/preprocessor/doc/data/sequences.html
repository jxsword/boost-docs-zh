序列

序列 (缩写为 seq) 是一组相邻的带圆括号元素. 例如,
(a)(b)(c)
...是一个包含 3 个元素——a、b 和 c——的 seq.
序列是兼具 列表 和 元组 双方性质的数据结构, 唯一例外是 seq 与 元组 一样不能为空. 因此, “空”的 seq 被视为一种特殊情况, 必须在 C++ 中单独处理.
#define SEQ (x)(y)(z)
#define REVERSE(s, state, elem) (elem) state
   // append to head                  ^

BOOST_PP_SEQ_FOLD_LEFT(REVERSE, BOOST_PP_EMPTY, SEQ)()
   //                           #1                  #2
   // 1) placeholder for "empty" seq
   // 2) remove placeholder

#define SEQ_B (1)(2)(3)
#define INC(s, state, elem) state (BOOST_PP_INC(elem))
   // append to tail             ^

BOOST_PP_SEQ_FOLD_RIGHT(INC, BOOST_PP_SEQ_NIL, SEQ)
   //                        ^
   // special placeholder that will be "eaten"
   // by appending to the tail
序列极为高效. 元素访问速度接近随机访问——即使对多达 256 个元素的 seq 也是如此. 这是因为元素访问 (以及其他一些操作) 是以迭代而非递归方式实现的. 因此, 即使在最大展开深度较低的预处理器上, 也能访问极高索引处的元素.
seq 的元素可以用 BOOST_PP_SEQ_ELEM 提取.
