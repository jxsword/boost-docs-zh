引言

Boost 预处理库是一个宏库, 支持预处理器元编程. 该库同时支持 C++ 和 C 编译. 它不依赖任何其他 Boost 库, 因此可以作为独立库使用.
该库要求编译器支持 变参宏. 由于变参宏是 C99 或 C++11 特性, 该库表面上至少要求以这些 C 或 C++ 标准级别编译. 许多编译器在更低的级别上支持变参宏, 因此只要不强制严格的 C++98/C++03 合规性, 在该编译级别上使用该库仍然是可能的.
C++ Template Metaprogramming: Concepts, Tools, and Techniques from Boost and Beyond (Dave Abrahams 与 Aleksey Gurtovoy 著) 的一段节选已 可在网上获取. 该节选包含对 Preprocessor 库和预处理器元编程的入门介绍, 对该库的新用户以及有兴趣了解该库所提供的部分设施的用户可能有所帮助.
