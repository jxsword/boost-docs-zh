BOOST_PP_SEQ_FOLD_LEFT 宏从左到右折叠 (或累积) 一个 seq 的各元素.

用法

BOOST_PP_SEQ_FOLD_LEFT(op, state, seq)

实参

op
形如 op(s, state, elem) 的三元运算. seq 中的每个元素都会调用该宏——每次返回一个新的 state. BOOST_PP_SEQ_FOLD_LEFT 会以下一个可用的折叠步骤、当前 state 和当前元素来展开该运算.
state
折叠的初始状态.
seq
要折叠的 seq.

备注

对于 seq (0)(1)(2), 该宏展开为:
op(s, op(s, op(s, state, 0), 1), 2)
为获得最高效率, BOOST_PP_SEQ_FOLD_LEFT 可以用 BOOST_PP_SEQ_FOLD_LEFT_s 重入.

参见

  • BOOST_PP_SEQ_FOLD_LEFT_s

要求

头文件: <boost/preprocessor/seq/fold_left.hpp>

示例代码

#include <boost/preprocessor/cat.hpp>
#include <boost/preprocessor/seq/fold_left.hpp>

#define SEQ (b)(o)(o)(s)(t)

#define OP(s, state, x) BOOST_PP_CAT(state, x)

BOOST_PP_SEQ_FOLD_LEFT(OP, BOOST_PP_SEQ_HEAD(SEQ), BOOST_PP_SEQ_TAIL(SEQ)) // expands to boost
