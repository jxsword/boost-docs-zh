BOOST_PP_APPLY 宏对“实参”与“什么都没有”之间的区别进行了抽象.

用法

BOOST_PP_APPLY(x)

实参

x
被抽象的实参. 该实参必须是 BOOST_PP_NIL, 或者是只有一个元素的 元组——如 (arg) 或 ((a, b)).

备注

若 x 为 BOOST_PP_NIL, 该宏展开为空. 若 x 是单元素 元组, 则展开为该 元组 的内容.

参见

  • BOOST_PP_NIL

要求

头文件: <boost/preprocessor/facilities/apply.hpp>

示例代码

#include <boost/preprocessor/facilities/apply.hpp>
#include <boost/preprocessor/tuple/elem.hpp>

#define CV(i) \
   BOOST_PP_APPLY( \
      BOOST_PP_TUPLE_ELEM( \
         4, i, \
         (BOOST_PP_NIL, (const), (volatile), (const volatile)) \
      ) \
   ) \
   /**/

CV(0) // expands to nothing
CV(1) // expands to const
