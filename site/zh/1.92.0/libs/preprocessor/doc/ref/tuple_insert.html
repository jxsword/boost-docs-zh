BOOST_PP_TUPLE_INSERT 宏向一个 元组 中插入一个元素.

用法

BOOST_PP_TUPLE_INSERT(tuple, i, elem) (v)

实参

tuple
要向其中插入元素的 元组.
i
要插入元素的位置 (在 tuple 中, 从零开始). 有效取值范围从 0 到 BOOST_PP_TUPLE_SIZE(tuple).
elem
要插入的元素.

备注

该宏把 elem 插入到索引 i 处的元素之前.
如果该操作试图创建的 元组 大于 BOOST_PP_LIMIT_TUPLE, 结果未定义.
该宏内部使用 BOOST_PP_WHILE. 因此, 若要使用由 d 形参从其他使用 BOOST_PP_WHILE 的宏传递而来的状态, 请参见 BOOST_PP_TUPLE_INSERT_D.

参见

  • BOOST_PP_TUPLE_INSERT_D

要求

头文件: <boost/preprocessor/tuple/insert.hpp>

示例代码

#include <boost/preprocessor/tuple/insert.hpp>

#define TUPLE (a, b, d)

BOOST_PP_TUPLE_INSERT(TUPLE, 2, c) // expands to (a, b, c, d)
