BOOST_PP_EXPR_IF 宏在其第一个实参非零时展开为其第二个实参, 否则展开为空.

用法

BOOST_PP_EXPR_IF(cond, expr)

实参

cond
决定结果是 expr 还是为空的条件. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
expr
当 cond 非零时的展开结果.

备注

该宏会对其第一个实参进行布尔转换. 如果不需要这种转换, 请改用 BOOST_PP_EXPR_IIF.

参见

  • BOOST_PP_EXPR_IIF
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/control/expr_if.hpp>

示例代码

#include <boost/preprocessor/control/expr_if.hpp>
#include <boost/preprocessor/tuple/elem.hpp>

#define CV(n) \
   BOOST_PP_EXPR_IF( \
      n, \
      BOOST_PP_TUPLE_ELEM( \
         4, n, \
         (..., const, volatile, const volatile) \
      ) \
   ) \
   /**/

CV(0) // expands to nothing
CV(1) // expands to const
