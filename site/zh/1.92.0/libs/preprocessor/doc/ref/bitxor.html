BOOST_PP_BITXOR 宏展开为其操作数的按位 XOR.

用法

BOOST_PP_BITXOR(x, y)

实参

x
运算的左操作数. 该值必须展开为 0 或 1.
y
运算的右操作数. 该值必须展开为 0 或 1.

备注

若 x 或 y 中恰有一个为 1, 该宏展开为 1; 否则展开为 0.
在执行按位 OR 运算之前, 该宏不会对任一操作数进行布尔转换. 如果需要这种转换, 请改用 BOOST_PP_XOR.

参见

  • BOOST_PP_XOR

要求

头文件: <boost/preprocessor/logical/bitxor.hpp>

示例代码

#include <boost/preprocessor/logical/bitxor.hpp>

BOOST_PP_BITXOR(0, 0) // expands to 0
BOOST_PP_BITXOR(0, 1) // expands to 1
BOOST_PP_BITXOR(1, 0) // expands to 1
BOOST_PP_BITXOR(1, 1) // expands to 0
