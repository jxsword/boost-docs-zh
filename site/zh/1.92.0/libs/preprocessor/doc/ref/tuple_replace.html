BOOST_PP_TUPLE_REPLACE 宏替换一个 元组 中的元素.

用法

BOOST_PP_TUPLE_REPLACE(tuple, i, elem) (v)

实参

tuple
要在其中替换元素的 元组.
i
要替换的元素在 tuple 中从零开始的位置. 有效取值范围从 0 到 BOOST_PP_TUPLE_SIZE(tuple) - 1.
elem
替换后的元素.

备注

该宏内部使用 BOOST_PP_WHILE. 因此, 若要使用由 d 形参从其他使用 BOOST_PP_WHILE 的宏传递而来的状态, 请参见 BOOST_PP_TUPLE_REPLACE_D.

参见

  • BOOST_PP_TUPLE_REPLACE_D

要求

头文件: <boost/preprocessor/tuple/replace.hpp>

示例代码

#include <boost/preprocessor/tuple/replace.hpp>

#define TUPLE (a, x, c)

BOOST_PP_TUPLE_REPLACE(TUPLE, 1, b) // expands to (a, b, c))
