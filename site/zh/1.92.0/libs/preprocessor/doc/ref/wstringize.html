BOOST_PP_WSTRINGIZE 宏在其实参展开之后将其宽字符串化.

用法

BOOST_PP_WSTRINGIZE(text)

实参

text
要转换为宽字符串字面量的文本.

备注

预处理器字符串化运算符 (#) 会阻止实参展开. 该宏允许其实参在字符串化之前先展开.

要求

头文件: <boost/preprocessor/wstringize.hpp>

示例代码

#include <boost/preprocessor/wstringize.hpp>

BOOST_PP_WSTRINGIZE(some text) // expands to L"some text"
