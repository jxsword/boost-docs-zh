BOOST_PP_REPEAT_FROM_TO_z 宏表示对 BOOST_PP_REPEAT_FROM_TO 重复构造的一次重入.

用法

BOOST_PP_REPEAT_FROM_TO_ ## z(first, last, macro, data)

实参

z
下一个可用的 BOOST_PP_REPEAT 维度.
first
重复的下界. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
last
重复的上界. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
宏
形如 macro(z, n, data) 的三元运算. BOOST_PP_REPEAT 会以下一个可用的重复深度、当前重复编号以及辅助实参 data 来展开该宏.
data
传递给 macro 的辅助数据.

备注

该宏展开为如下序列:
macro(z, first, data) macro(z, first + 1, data) ... macro(z, last - 1, data)
重复次数 (即 last - first) 不得超过 BOOST_PP_LIMIT_REPEAT.
在某些时候, 可能需要用 BOOST_PP_CAT 而不是预处理器记号粘贴运算符来完成拼接. 当 z 值本身是一个宏调用时就会发生这种情况: 它需要延迟展开. 这种场景下的语法为:
BOOST_PP_CAT(BOOST_PP_REPEAT_FROM_TO_, z)(count, macro, data).

参见

  • BOOST_PP_CAT
  • BOOST_PP_LIMIT_REPEAT
  • BOOST_PP_REPEAT

要求

头文件: <boost/preprocessor/repetition/repeat_from_to.hpp>

示例代码

#include <boost/preprocessor/repetition/repeat_from_to.hpp>

#define TEXT(z, n, data) n data

#define MACRO(z, n, data) \
  ( \
     BOOST_PP_REPEAT_FROM_TO_ ## z( \
        1, 4, \
        TEXT, xyz \
     ) \
  ) \
  /**/

BOOST_PP_REPEAT(3, MACRO, _)
   /*
      expands to:
      (1 xyz 2 xyz 3 xyz)
      (1 xyz 2 xyz 3 xyz)
      (1 xyz 2 xyz 3 xyz)
   */
