BOOST_PP_INTERCEPT 宏拦截一次数值拼接并展开为空.

用法

BOOST_PP_INTERCEPT

备注

该宏用于拦截由库的其他各种构造执行的拼接. 它通常放在其他文本之后, 以使拼接的“吞没”行为展开为空. 该宏只能拦截 0 到 BOOST_PP_LIMIT_MAG 范围内的整数常量.

参见

  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/facilities/intercept.hpp>

示例代码

#include <boost/preprocessor/facilities/intercept.hpp>
#include <boost/preprocessor/repetition/enum_binary_params.hpp>

BOOST_PP_ENUM_BINARY_PARAMS(3, class T, = U)
// expands to class T0 = U0, class T1 = U1, class T2 = U2

BOOST_PP_ENUM_BINARY_PARAMS(3, class T, = int BOOST_PP_INTERCEPT)
// expands to class T0 = int, class T1 = int, class T2 = int
