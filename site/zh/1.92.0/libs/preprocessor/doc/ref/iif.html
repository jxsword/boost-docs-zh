BOOST_PP_IIF 宏根据一个按位条件在两个值之间做出选择.

用法

BOOST_PP_IIF(bit, t, f)

实参

bit
决定结果是 expr 还是为空的条件. 该值必须展开为 0 或 1.
t
当 bit 为 1 时的展开结果.
f
当 bit 为 0 时的展开结果.

备注

该宏不会对其第一个实参进行布尔转换. 如果需要这种转换, 请改用 BOOST_PP_IF.

参见

  • BOOST_PP_IF
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/control/iif.hpp>

示例代码

#include <boost/preprocessor/control/iif.hpp>
#include <boost/preprocessor/logical/or.hpp>

#define OR_IF(p, q, t, f) BOOST_PP_IIF(BOOST_PP_OR(p, q), t, f)

OR_IF(1, 0, abc, xyz) // expands to abc
OR_IF(0, 0, abc, xyz) // expands to xyz
