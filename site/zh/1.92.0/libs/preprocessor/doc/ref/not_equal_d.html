BOOST_PP_NOT_EQUAL_D 宏比较两个值是否不等.

用法

BOOST_PP_NOT_EQUAL_D(d, x, y)

实参

d
该实参被忽略.
x
比较的左操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
比较的右操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 等于 y, 该宏展开为 0; 否则展开为 1.
该宏已被弃用. 它的存在只是为了向后兼容. 请改用 BOOST_PP_NOT_EQUAL.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_NOT_EQUAL

要求

头文件: <boost/preprocessor/comparison/not_equal.hpp>

示例代码

#include <boost/preprocessor/comparison/equal.hpp>

BOOST_PP_NOT_EQUAL_D(1, 4, 3) // expands to 1
BOOST_PP_NOT_EQUAL_D(1, 5, 5) // expands to 0
