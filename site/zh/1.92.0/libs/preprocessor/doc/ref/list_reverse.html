BOOST_PP_LIST_REVERSE 宏展开为一个 列表 的反转.

用法

BOOST_PP_LIST_REVERSE(list)

实参

list
要反转的 列表.

备注

以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_REVERSE_D 效率更高.

参见

  • BOOST_PP_LIST_REVERSE_D

要求

头文件: <boost/preprocessor/list/reverse.hpp>

示例代码

#include <boost/preprocessor/list/reverse.hpp>

#define LIST (0, (1, (2, (3, BOOST_PP_NIL))))

BOOST_PP_LIST_REVERSE(LIST) // expands to (3, (2, (1, (0, BOOST_PP_NIL))))
