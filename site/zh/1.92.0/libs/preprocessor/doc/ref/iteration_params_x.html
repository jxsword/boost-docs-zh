BOOST_PP_ITERATION_PARAMS_x 宏是一个用户定义的 命名外部实参, 由 BOOST_PP_ITERATE 使用. 它表示一次 文件迭代 的下界、上界和文件名. 它还可以可选地表示与一次 文件迭代 相关联的标志.

用法

#define BOOST_PP_ITERATION_PARAMS_x (c, (start, finish, filename [, flags]))

实参

x
下一次 文件迭代 的迭代深度. 该值必须为当前迭代深度 + 1.
c
形参的个数. 如果指定了 flags, 该值必须为 4; 否则必须为 3.
start
一次 文件迭代 的下界 (含). 有效取值范围从 0 到 BOOST_PP_LIMIT_ITERATION.
finish
一次 文件迭代 的上界 (含). 有效取值范围从 0 到 BOOST_PP_LIMIT_ITERATION.
filename
用作 文件迭代 目标的带引号或尖括号的文件名.
[flags]
与这次 文件迭代 相关联的标志, 用于在同一文件中区分不同的 文件迭代.

备注

注意, 宏标识符之后有一个空白字符.
该宏必须被定义为上述两种格式之一 (带或不带 flags) 的实参数组. 它是向 BOOST_PP_ITERATE 传参的主要方法. start 和 finish 都是 会被求值的形参, 这意味着可以使用简单的算术运算.
该宏会被 BOOST_PP_ITERATE 的调用自动取消定义以供复用.
