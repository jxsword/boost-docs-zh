BOOST_PP_ARRAY_INSERT_D 宏向 数组 中插入一个元素. 它以最高效率重入 BOOST_PP_WHILE.

用法

BOOST_PP_ARRAY_INSERT_D(d, array, i, elem)

实参

d
下一个可用的 BOOST_PP_WHILE 迭代.
array
要向其中插入元素的 数组.
i
要插入元素的位置 (在 array 中, 从零开始). 有效取值范围从 0 到 BOOST_PP_ARRAY_SIZE(array).
elem
要插入的元素.

备注

该宏把 elem 插入到索引 i 处的元素之前.
如果该操作试图创建的 数组 大于 BOOST_PP_LIMIT_TUPLE, 结果未定义.

参见
