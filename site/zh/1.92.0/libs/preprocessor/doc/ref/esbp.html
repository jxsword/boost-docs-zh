BOOST_PP_ENUM_SHIFTED_BINARY_PARAMS 宏生成一个以逗号分隔的移位二元形参列表.

用法

BOOST_PP_ENUM_SHIFTED_BINARY_PARAMS(count, p1, p2)

实参

count
要生成的形参个数. 有效取值范围从 0 到 BOOST_PP_LIMIT_REPEAT.
p1
形参第一部分的文本. BOOST_PP_ENUM_SHIFTED_BINARY_PARAMS 通过拼接从 0 到 count - 1 的数字来生成形参.
p2
形参第一部分的文本. BOOST_PP_ENUM_SHIFTED_BINARY_PARAMS 通过拼接从 0 到 count - 1 的数字来生成形参.

备注

该宏展开为如下以逗号分隔的序列:
p1 ## 1 p2 ## 1, p1 ## 2 p2 ## 2, ... p1 ## count - 1 p2 ## count - 1
若要使用其他宏传来的 z 形参 (来自使用 BOOST_PP_REPEAT 的宏), 请参见 BOOST_PP_ENUM_SHIFTED_BINARY_PARAMS_Z.

参见
