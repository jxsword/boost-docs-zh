BOOST_PP_TUPLE_POP_FRONT 宏从一个 元组 的开头弹出一个元素.

用法

BOOST_PP_TUPLE_POP_FRONT(tuple) (v)

实参

tuple
要从中弹出元素的 元组.

备注

该宏在移除第一个元素后返回 tuple. 若 tuple 只有一个元素, 它将保持不变, 因为一个 元组 必须至少有一个元素.
该宏内部使用 BOOST_PP_REPEAT. 因此, 若要使用由 z 形参从其他使用 BOOST_PP_REPEAT 的宏传递而来的状态, 请参见 BOOST_PP_TUPLE_POP_FRONT_Z

参见

  • BOOST_PP_TUPLE_POP_FRONT_Z

要求

头文件: <boost/preprocessor/tuple/pop_front.hpp>

示例代码

#include <boost/preprocessor/tuple/pop_front.hpp>

#define TUPLE (a, b, c)

BOOST_PP_TUPLE_POP_FRONT(TUPLE) // expands to (b, c)
