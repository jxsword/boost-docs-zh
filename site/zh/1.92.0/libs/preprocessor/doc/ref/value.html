BOOST_PP_VALUE 宏是一个用户定义的 命名外部实参, 供 BOOST_PP_ASSIGN_SLOT 使用.

用法

#define BOOST_PP_VALUE value

实参

value
一个要由 BOOST_PP_ASSIGN_SLOT 求值的整型常量表达式.
