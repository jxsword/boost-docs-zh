BOOST_PP_REMOVE_PARENS 宏从输入数据中移除起始圆括号 (若存在) 并展开为结果

用法

BOOST_PP_REMOVE_PARENS(param) (v)

实参

param 输入数据.

备注

如果输入以一个圆括号开头 (括号内可以有任意数据), 该宏会移除该圆括号并展开为结果. 如果输入不以圆括号开头, 该宏展开为输入本身.

参见

  • BOOST_PP_IS_BEGIN_PARENS

要求

头文件: <boost/preprocessor/punctuation/remove_parens.hpp>

示例代码

#include <boost/preprocessor/punctuation/remove_parens.hpp>

#define DATA data
#define DATAP ( data ) more_data

BOOST_PP_REMOVE_PARENS(DATA)     // expands to 'data'
BOOST_PP_REMOVE_PARENS(DATAP)    // expands to 'data more_data'
