BOOST_PP_CHECK_EMPTY 变参宏检查其变参输入是否为空. 若输入为空则展开为 1, 若输入非空则展开为 0. 该宏只在编译处于 C++20 级别且支持 __VA_OPT__ 构造时才存在.

用法

BOOST_PP_CHECK_EMPTY(...) (v)

实参

...
要检查是否为空的 变参数据.

备注

当宏调用 BOOST_PP_VARIADIC_HAS_OPT() 展开为 1 时, 该宏存在并且可以被调用; 否则该宏不存在, 试图调用它会导致找不到该宏的预处理器错误. 由于这一条件, 包含该宏的头文件也包含了 BOOST_PP_VARIADIC_HAS_OPT 宏的头文件.
也可以向该宏传递展开为空的数据, 此时该宏将展开为 1, 就像什么都没有传递一样.

参见

  • BOOST_PP_VARIADIC_HAS_OPT

要求

头文件: <boost/preprocessor/facilities/check_empty.hpp>

示例代码

#include <boost/preprocessor/facilities/check_empty.hpp>

# if BOOST_PP_VARIADIC_HAS_OPT()

#define DATA
#define OBJECT OBJECT2
#define OBJECT2
#define FUNC(x) FUNC2(x)
#define FUNC2(x)
#define FUNC_GEN(x,y) (1,2,3)

BOOST_PP_CHECK_EMPTY(DATA)     // expands to 1
BOOST_PP_CHECK_EMPTY(OBJECT)   // expands to 1
BOOST_PP_CHECK_EMPTY(FUNC(1))  // expands to 1
BOOST_PP_CHECK_EMPTY(FUNC)     // expands to 0
BOOST_PP_CHECK_EMPTY(FUNC_GEN) // expands to 0

#endif
