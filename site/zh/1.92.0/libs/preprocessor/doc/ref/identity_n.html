BOOST_PP_IDENTITY_N 宏在被调用时展开为其第一个实参.

用法

BOOST_PP_IDENTITY_N(item,n)(n-arguments)

实参

item
展开的结果.
n
调用时的实参个数.

备注

该宏设计用于与 BOOST_PP_IF 和 BOOST_PP_IIF 配合, 此时两个子句中只有一个需要被调用.

参见

  • BOOST_PP_IF
  • BOOST_PP_IIF

要求

头文件: <boost/preprocessor/facilities/identity.hpp>

示例代码

#include <boost/preprocessor/control/if.hpp>
#include <boost/preprocessor/facilities/identity.hpp>

#define MACRO_CAT(y,z) y ## z
#define MACRO(n) BOOST_PP_IF(n, BOOST_PP_IDENTITY_N(x,2), MACRO_CAT)(a,b)

MACRO(0) // expands to ab
MACRO(1) // expands to x
