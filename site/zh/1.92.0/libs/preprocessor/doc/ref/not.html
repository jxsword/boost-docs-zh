BOOST_PP_NOT 宏对其操作数执行逻辑 NOT.

用法

BOOST_PP_NOT(x)

实参

x
要转换的值. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 为零, 该宏展开为 1; 否则展开为 0.
该宏在执行逻辑 NOT 运算之前会对其操作数进行布尔转换. 如果不需要这种转换, 请改用 BOOST_PP_COMPL.

参见

  • BOOST_PP_COMPL
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/logical/not.hpp>

示例代码

#include <boost/preprocessor/logical/not.hpp>

BOOST_PP_NOT(55) // expands to 0
BOOST_PP_NOT(0) // expands to 1
