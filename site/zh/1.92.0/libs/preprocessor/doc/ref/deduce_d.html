BOOST_PP_DEDUCE_D 宏手动推导 BOOST_PP_WHILE 构造的状态.

用法

BOOST_PP_DEDUCE_D()

备注

该宏旨在避免在很深的展开深度下使用自动递归. 在这样的深度上, 自动递归在某些预处理器上可能效率低下. 它并非设计用于直接调用带 _D 后缀的宏, 例如:
BOOST_PP_ADD_D(BOOST_PP_DEDUCE_D(), x, y)
如果在这种上下文中使用它, 带 _D 后缀的宏将会失败. 带 _D 后缀的宏会直接与传给它们的 d 形参拼接, 这会阻止 BOOST_PP_DEDUCE_D() 展开. 此外, 在这种情况下使用该宏毫无意义, 因为那时再获取效率已经太迟了.

参见

  • BOOST_PP_WHILE

要求

头文件: <boost/preprocessor/control/deduce_d.hpp>

示例代码

#include <boost/preprocessor/arithmetic/add.hpp>
#include <boost/preprocessor/arithmetic/inc.hpp>
#include <boost/preprocessor/arithmetic/sub.hpp>
#include <boost/preprocessor/control/deduce_d.hpp>
#include <boost/preprocessor/punctuation/comma_if.hpp>
#include <boost/preprocessor/repetition/repeat.hpp>
#include <boost/preprocessor/tuple/elem.hpp>

#define RANGE(first, last) \
   BOOST_PP_REPEAT( \
      BOOST_PP_INC( \
         BOOST_PP_SUB(last, first) \
      ), \
      RANGE_M, \
      (first, BOOST_PP_DEDUCE_D()) \
   ) \
   /**/

#define RANGE_M(z, n, data) \
   RANGE_M_2( \
      n, \
      BOOST_PP_TUPLE_ELEM(2, 0, data), \
      BOOST_PP_TUPLE_ELEM(2, 1, data) \
   ) \
   /**/

#define RANGE_M_2(n, first, d) \
   BOOST_PP_COMMA_IF(n) BOOST_PP_ADD_D(d, n, first) \
   /**/

RANGE(5, 10) // expands to 5, 6, 7, 8, 9, 10
