BOOST_PP_LIST_TO_TUPLE 宏把一个 列表 转换为 元组.

用法

BOOST_PP_LIST_TO_TUPLE(list)

实参

list
要转换的 列表.

备注

例如, 若 list 为 (a, (b, (c, BOOST_PP_NIL))), 该宏将产生:
(a, b, c)
以前, 该宏不能在 BOOST_PP_FOR 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_TO_TUPLE_R 效率更高.

如果要转换的 列表 为空 (表示为 'BOOST_PP_NIL'), 得到的 元组 未定义, 因为 元组 不能为空.

参见

  • BOOST_PP_LIST_TO_TUPLE_R

要求

头文件: <boost/preprocessor/list/to_tuple.hpp>

示例代码

#include <boost/preprocessor/list/to_tuple.hpp>

#define LIST (w, (x, (y, (z, BOOST_PP_NIL))))

BOOST_PP_LIST_TO_TUPLE(LIST) // expands to (w, x, y, z)
