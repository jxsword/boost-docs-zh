BOOST_PP_ASSERT_MSG 宏有条件地插入调试文本.

用法

BOOST_PP_ASSERT_MSG(cond, msg)

实参

cond
决定是否发生断言的条件. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
msg
当 cond 求值为 0 时要显示的消息.

备注

若 cond 展开为 0, 该宏展开为 msg; 否则展开为空.

参见

  • BOOST_PP_ASSERT_MSG
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/debug/assert.hpp>

示例代码

#include <boost/preprocessor/comparison/equal.hpp>
#include <boost/preprocessor/debug/assert.hpp>

// lines are supposed to be counted
// in translation phase 1

#line 9
BOOST_PP_ASSERT_MSG( \
   BOOST_PP_EQUAL(__LINE__, 9), \
   "incorrect line numbering detected" \
)
