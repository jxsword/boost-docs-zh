BOOST_PP_TUPLE_ELEM 宏从一个 元组 中提取一个元素.

用法

BOOST_PP_TUPLE_ELEM(i, tuple) (v)

或

BOOST_PP_TUPLE_ELEM(size, i, tuple) (v)

实参

size
该 元组 的大小. 该大小会被忽略.
i
要提取的元素在 元组 中从零开始的索引. 有效取值范围从 0 到 size - 1.
tuple
要从中提取元素的 元组.

备注

你可以把该变参宏调用为 BOOST_PP_TUPLE_ELEM(i,tuple), 或者为了向后兼容调用为 BOOST_PP_TUPLE_ELEM(size,i,tuple).

参见

  • BOOST_PP_LIMIT_TUPLE

要求

头文件: <boost/preprocessor/tuple/elem.hpp>

示例代码

#include <boost/preprocessor/tuple/elem.hpp>

#define TUPLE (a, b, c, d)

BOOST_PP_TUPLE_ELEM(0, TUPLE) // expands to a in the variadic version
BOOST_PP_TUPLE_ELEM(3, TUPLE) // expands to d in the variadic version
