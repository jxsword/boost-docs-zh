BOOST_PP_LIST_CONS 宏是一个 列表 构造器.

用法

BOOST_PP_LIST_CONS(head, tail)

实参

head
列表 中的一个元素.
tail
要么是一个 列表, 要么是 BOOST_PP_LIST_NIL 或 BOOST_PP_NIL.

备注

该宏把一个新头部追加到既有的 列表 上, 或者创建一个 列表, 其起点为 BOOST_PP_LIST_NIL.
该宏已不再必要. 例如……
BOOST_PP_LIST_CONS(a, BOOST_PP_LIST_CONS(b, BOOST_PP_LIST_NIL)))
……只是下面写法的一种显式形式:
(a, (b, BOOST_PP_NIL))
因此, 该宏已被弃用.

参见

  • BOOST_PP_LIST_NIL
  • BOOST_PP_NIL

要求

头文件: <boost/preprocessor/list/adt.hpp>

示例代码

#include <boost/preprocessor/list/adt.hpp>

#define OLD \
   BOOST_PP_LIST_CONS( \
      a, \
      BOOST_PP_LIST_CONS( \
         b, \
         BOOST_PP_LIST_CONS( \
            c, \
            BOOST_PP_LIST_NIL \
         ) \
      ) \
   ) \
   /**/

#define NEW (a, (b, (c, BOOST_PP_NIL)))

BOOST_PP_LIST_FIRST(OLD) == BOOST_PP_LIST_FIRST(NEW)
   // expands to a == a

BOOST_PP_LIST_REST(OLD) == BOOST_PP_LIST_REST(NEW)
   // expands to (b, (c, BOOST_PP_NIL)) == (b, (c, BOOST_PP_NIL))
