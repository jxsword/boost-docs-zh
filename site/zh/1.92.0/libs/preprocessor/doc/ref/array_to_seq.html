BOOST_PP_ARRAY_TO_SEQ 宏把一个 数组 转换为 seq.

用法

BOOST_PP_ARRAY_TO_SEQ(array)

实参

array
要转换的 数组.

备注

如果要转换的 数组 为空 (表示为 '( 0, () )'), 得到的 seq 未定义, 因为 seq 不能为空.

要求

头文件: <boost/preprocessor/array/to_seq.hpp>

示例代码

#include <boost/preprocessor/array/to_seq.hpp>

BOOST_PP_ARRAY_TO_SEQ((3, (a, b, c))) // expands to (a)(b)(c)
