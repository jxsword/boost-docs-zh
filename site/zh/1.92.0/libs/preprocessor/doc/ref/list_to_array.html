BOOST_PP_LIST_TO_ARRAY 宏把一个 列表 转换为 数组.

用法

BOOST_PP_LIST_TO_ARRAY(list)

实参

list
要转换的 列表.

备注

该宏使用 BOOST_PP_WHILE. 在 BOOST_PP_WHILE 内部, 使用 BOOST_PP_LIST_TO_ARRAY_D 效率更高.

如果要转换的 列表 为空 (表示为 'BOOST_PP_NIL'), 得到的 数组 也为空 (表示为 '( 0, () )').

参见

  • BOOST_PP_LIST_TO_ARRAY_D

要求

头文件: <boost/preprocessor/list/to_array.hpp>

示例代码

#include <boost/preprocessor/list/to_array.hpp>

#define LIST (a, (b, (c, BOOST_PP_NIL)))

BOOST_PP_LIST_TO_ARRAY(LIST) // expands to (3, (a, b, c))
