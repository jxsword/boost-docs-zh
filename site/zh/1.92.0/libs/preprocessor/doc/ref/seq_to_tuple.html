BOOST_PP_SEQ_TO_TUPLE 宏把一个 seq 转换为 元组.

用法

BOOST_PP_SEQ_TO_TUPLE(seq)

实参

seq
要转换的 seq.

要求

头文件: <boost/preprocessor/seq/to_tuple.hpp>

示例代码

#include <boost/preprocessor/seq/to_tuple.hpp>

#define SEQ (a)(b)(c)

BOOST_PP_SEQ_TO_TUPLE(SEQ) // expands to (a, b, c)
