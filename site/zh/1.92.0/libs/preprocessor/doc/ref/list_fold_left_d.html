BOOST_PP_LIST_FOLD_LEFT_d 宏从左到右折叠 (或累积) 一个 列表 的各元素. 它以最高效率重入 BOOST_PP_WHILE.

用法

BOOST_PP_LIST_FOLD_LEFT_ ## d(op, state, list)

实参

d
下一个可用的 BOOST_PP_WHILE 迭代.
op
形如 op(d, state, elem) 的三元运算. list 中的每个元素都会调用该宏——每次返回一个新的 state. BOOST_PP_LIST_FOLD_LEFT 会以下一个可用的 BOOST_PP_WHILE 迭代、当前 state 和当前元素来展开该运算.
state
折叠的初始状态.
list
要折叠的 列表.

备注

对于 列表 (0, (1, (2, BOOST_PP_NIL))), 该宏展开为:
op(d, op(d, op(d, state, 0), 1), 2)

参见

  • BOOST_PP_LIST_FOLD_LEFT

要求

头文件: <boost/preprocessor/list/fold_left.hpp>

示例代码

#include <boost/preprocessor/cat.hpp>
#include <boost/preprocessor/list/fold_left.hpp>

#define L1 (a, (b, (c, BOOST_PP_NIL)))
#define L2 (L1, (L1, (L1, BOOST_PP_NIL)))

#define OP(d, state, x) (BOOST_PP_LIST_FOLD_LEFT_ ## d(OP_2, _, x), state)
#define OP_2(d, state, x) BOOST_PP_CAT(state, x)

BOOST_PP_LIST_FOLD_LEFT(OP, BOOST_PP_NIL, L2)
/*
   expands to:
   (_abc, (_abc, (_abc, BOOST_PP_NIL)))
*/
