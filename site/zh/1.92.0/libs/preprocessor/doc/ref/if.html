BOOST_PP_IF 宏根据一个逻辑条件在两个值之间做出选择.

用法

BOOST_PP_IF(cond, t, f)

实参

cond
决定结果是 expr 还是为空的条件. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
t
当 cond 非零时的展开结果.
f
当 cond 为 0 时的展开结果.

备注

该宏会对其第一个实参进行布尔转换. 如果不需要这种转换, 请改用 BOOST_PP_IIF.

参见

  • BOOST_PP_IIF
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/control/if.hpp>

示例代码

#include <boost/preprocessor/control/if.hpp>

BOOST_PP_IF(10, a, b) // expands to a
BOOST_PP_IF(0, a, b) // expands to b
