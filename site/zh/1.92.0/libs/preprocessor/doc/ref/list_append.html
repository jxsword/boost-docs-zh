BOOST_PP_LIST_APPEND 宏把两个 列表 连接起来.

用法

BOOST_PP_LIST_APPEND(a, b)

实参

a
第一个 列表.
b
第二个 列表.

备注

该宏连接两个列表. 例如, 若 a 为 (1, (2, (3, BOOST_PP_NIL))) 且 b 为 (4, (5, BOOST_PP_NIL)), 该宏将展开为:
(1, (2, (3, (4, (5, BOOST_PP_NIL)))))
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_APPEND_D 效率更高.

参见

  • BOOST_PP_LIST_APPEND_D

要求

头文件: <boost/preprocessor/list/append.hpp>

示例代码

#include <boost/preprocessor/list/append.hpp>

#define L1 (a, (b, (c, BOOST_PP_NIL)))
#define L2 (x, (y, (z, BOOST_PP_NIL)))

BOOST_PP_LIST_APPEND(L1, L2)
   // expands to (a, (b, (c, (x, (y, (z, BOOST_PP_NIL))))))
