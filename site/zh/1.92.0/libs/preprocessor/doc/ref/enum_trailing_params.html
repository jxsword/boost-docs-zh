BOOST_PP_ENUM_TRAILING_PARAMS 宏生成一个带前导逗号的、以逗号分隔的形参列表.

用法

BOOST_PP_ENUM_TRAILING_PARAMS(count, param)

实参

count
要生成的形参个数. 有效取值范围从 0 到 BOOST_PP_LIMIT_REPEAT.
param
形参的文本. BOOST_PP_ENUM_TRAILING_PARAMS 通过拼接从 0 到 count - 1 的数字来生成形参.

备注

该宏展开为如下以逗号分隔的序列:
, param ## 0, param ## 1, ... param ## count - 1
若要使用其他宏传来的 z 形参 (来自使用 BOOST_PP_REPEAT 的宏), 请参见 BOOST_PP_ENUM_TRAILING_PARAMS_Z.

参见

  • BOOST_PP_ENUM_TRAILING_PARAMS_Z
  • BOOST_PP_LIMIT_REPEAT

要求

头文件: <boost/preprocessor/repetition/enum_trailing_params.hpp>

示例代码

#include <boost/preprocessor/repetition/enum_trailing_params.hpp>

class X BOOST_PP_ENUM_TRAILING_PARAMS(2, class T)
   // expands to class X, class T0, class T1, class T2
