BOOST_PP_EXPR_IIF 宏在其第一个实参为 1 时展开为其第二个实参, 在其第一个实参为 0 时展开为空.

用法

BOOST_PP_EXPR_IIF(bit, expr)

实参

bit
决定结果是 expr 还是为空的条件. 该值必须展开为 0 或 1.
expr
当 bit 为 1 时的展开结果.

备注

该宏不会对其第一个实参进行布尔转换. 如果需要这种转换, 请改用 BOOST_PP_EXPR_IF.

参见

  • BOOST_PP_EXPR_IF
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/control/expr_iif.hpp>

示例代码

#include <boost/preprocessor/logical/and.hpp>
#include <boost/preprocessor/control/expr_iif.hpp>

#define INSERT_AND(p, q, text) \
   BOOST_PP_EXPR_IIF( \
      BOOST_PP_AND(p, q), \
      text \
   ) \
   /**/

INSERT_AND(2, 3, abc) // expands to abc
INSERT_AND(0, 7, xyz) // expands to nothing
