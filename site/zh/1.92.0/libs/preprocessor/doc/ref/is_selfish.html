BOOST_PP_IS_SELFISH 宏在 自包含 进行期间处于已定义状态.

用法

#if !defined(BOOST_PP_IS_SELFISH) // ...

备注

如果 自包含 正在进行, 该宏被定义为 1. 这意味着下面的写法同样有效:
#if !BOOST_PP_IS_SELFISH // ...
该宏用于保护文件不被无限包含.
