BOOST_PP_OR 宏展开为其操作数的逻辑 OR.

用法

BOOST_PP_OR(p, q)

实参

p
运算的左操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
q
运算的右操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 p 或 q 非零, 该宏展开为 1; 否则展开为 0.
该宏在执行逻辑 OR 运算之前会对每个操作数进行布尔转换. 如果不需要这种转换, 请改用 BOOST_PP_BITOR.

参见

  • BOOST_PP_BITOR
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/logical/or.hpp>

示例代码

#include <boost/preprocessor/logical/or.hpp>

BOOST_PP_OR(4, 3) // expands to 1
BOOST_PP_OR(5, 0) // expands to 1
