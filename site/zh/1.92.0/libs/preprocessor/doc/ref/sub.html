BOOST_PP_SUB 宏展开为其各实参之差.

用法

BOOST_PP_SUB(x, y)

实参

x
运算的被减数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
运算的减数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 与 y 之差小于 0, 结果将被饱和到 0.
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_SUB_D 效率更高.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_SUB_D

要求

头文件: <boost/preprocessor/arithmetic/sub.hpp>

示例代码

#include <boost/preprocessor/arithmetic/sub.hpp>

BOOST_PP_SUB(4, 3) // expands to 1
