BOOST_PP_LIST_ENUM 宏把一个 列表 转换为以逗号分隔的列表.

用法

BOOST_PP_LIST_ENUM(list)

实参

list
要转换的 列表.

备注

例如, 若 list 为 (a, (b, (c, BOOST_PP_NIL))), 该宏将产生:
a, b, c
以前, 该宏不能在 BOOST_PP_FOR 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_ENUM_R 效率更高.

在 C++ 20 模式下, 若列表为空, 得到的 变参 数据 将为空.

参见

  • BOOST_PP_LIST_ENUM_R

要求

头文件: <boost/preprocessor/list/enum.hpp>

示例代码

#include <boost/preprocessor/list/enum.hpp>

#define LIST (w, (x, (y, (z, BOOST_PP_NIL))))

BOOST_PP_LIST_ENUM(LIST) // expands to w, x, y, z
