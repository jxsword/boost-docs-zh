BOOST_PP_LPAREN 宏展开为一个左圆括号.

用法

BOOST_PP_LPAREN()

备注

预处理器把圆括号解释为宏调用中的定界符. 因此, 圆括号需要特殊处理.

参见

  • BOOST_PP_RPAREN

要求

头文件: <boost/preprocessor/punctuation/paren.hpp>

示例代码

#include <boost/preprocessor/punctuation/paren.hpp>

#define X(x) x
#define MACRO(p, x) X p x )

MACRO(BOOST_PP_LPAREN(), abc) // expands to abc

#define Y(x)

MACRO((10) Y BOOST_PP_LPAREN(), result) // expands to 10
