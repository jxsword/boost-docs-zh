BOOST_PP_SEQ_POP_BACK 宏从一个 seq 的末尾弹出一个元素.

用法

BOOST_PP_SEQ_POP_BACK(seq)

实参

seq
要从中弹出元素的 seq.

备注

该宏在移除最后一个元素后返回 seq.

参见

  • BOOST_PP_SEQ_POP_FRONT

要求

头文件: <boost/preprocessor/seq/pop_back.hpp>

示例代码

#include <boost/preprocessor/seq/pop_back.hpp>

#define SEQ (a)(b)(c)

BOOST_PP_SEQ_POP_BACK(SEQ) // expands to (a)(b)
