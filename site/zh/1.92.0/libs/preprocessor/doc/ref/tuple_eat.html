BOOST_PP_TUPLE_EAT 宏展开为一个“吃掉” 元组 的宏.

用法

BOOST_PP_TUPLE_EAT() (v)

或

BOOST_PP_TUPLE_EAT(size) (v)

实参

size
要“吃掉”的 元组 的大小. 该实参会被忽略.

备注

大小可以完全省略, 这样该宏就能以 BOOST_PP_TUPLE_EAT() 的形式调用; 某些编译器可能会给出警告, 但功能仍然有效. 如果指定了大小, 它会被忽略, 但某些编译器的警告就不会出现.

参见

  • BOOST_PP_LIMIT_TUPLE

要求

头文件: <boost/preprocessor/tuple/eat.hpp>

示例代码

#include <boost/preprocessor/control/if.hpp>
#include <boost/preprocessor/tuple/eat.hpp>

#define OP(a, b) (a b)
#define MACRO(n) BOOST_PP_IF(n, OP, BOOST_PP_TUPLE_EAT())(1, 2)

MACRO(0) // expands to nothing
MACRO(1) // expands to (1, 2)
