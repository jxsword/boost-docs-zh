BOOST_PP_LIST_CAT 宏拼接 列表 中的所有元素.

用法

BOOST_PP_LIST_CAT(list)

实参

list
要拼接其各元素的 列表.

备注

各元素从索引 0 开始从左到右依次拼接.
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_CAT_D 效率更高.

参见

  • BOOST_PP_LIST_CAT_D

要求

头文件: <boost/preprocessor/list/cat.hpp>

示例代码

#include <boost/preprocessor/list/cat.hpp>

#define LIST (a, (b, (c, BOOST_PP_NIL)))

BOOST_PP_LIST_CAT(LIST) // expands to abc
