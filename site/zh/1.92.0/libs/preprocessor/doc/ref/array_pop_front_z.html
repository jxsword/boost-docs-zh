BOOST_PP_ARRAY_POP_FRONT_Z 宏从 数组 开头弹出一个元素. 它以最高效率重入 BOOST_PP_REPEAT.

用法

BOOST_PP_ARRAY_POP_FRONT_Z(z, array)

实参

z
下一个可用的 BOOST_PP_REPEAT 维度.
array
要从中弹出元素的 数组.

备注

该宏在移除第一个元素后返回 array. 若 array 没有元素, 应用该宏的结果未定义.

参见

  • BOOST_PP_ARRAY_POP_FRONT

要求
