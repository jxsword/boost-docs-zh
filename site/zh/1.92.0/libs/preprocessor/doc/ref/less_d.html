BOOST_PP_LESS_D 宏比较两个值的大小 (是否前者更小). 它以最高效率重入 BOOST_PP_WHILE.

用法

BOOST_PP_LESS_D(d, x, y)

实参

d
下一个可用的 BOOST_PP_WHILE 迭代.
x
比较的左操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
比较的右操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 小于 y, 该宏展开为 1; 否则展开为 0.

参见

  • BOOST_PP_LESS
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/comparison/less.hpp>

示例代码

#include <boost/preprocessor/comparison/less.hpp>
#include <boost/preprocessor/list/filter.hpp>

#define LIST (1, (2, (3, (4, (5, BOOST_PP_NIL)))))

#define PRED(d, _, num) BOOST_PP_LESS_D(d, num, 3)

BOOST_PP_LIST_FILTER(PRED, nil, LIST)
   // expands to (1, (2, BOOST_PP_NIL))
