BOOST_PP_ITERATE 宏发起一次 文件迭代.

用法

#include BOOST_PP_ITERATE()

备注

传给该宏的实参以 命名外部实参 的形式通过两种方式之一传递——要么通过 BOOST_PP_FILENAME_x 和 BOOST_PP_ITERATION_LIMITS, 或者 通过 BOOST_PP_ITERATION_PARAMS_x.
执行一次 文件迭代 需要三项信息. 第一, 要迭代的文件名. 它通过 BOOST_PP_FILENAME_x 或 作为 BOOST_PP_ITERATION_PARAMS_x 的一部分传入. 文件迭代 机制会反复包含该文件, 迭代值从下界取到上界——即第二和第三个必需形参. 这两个边界要么通过 BOOST_PP_ITERATION_LIMITS 传入, 或者作为 BOOST_PP_ITERATION_PARAMS_x 的一部分传入.
可选地, 可以传入第四个形参, 把一些标志与一次迭代关联起来. 这些标志主要用于在同一文件中区分不同的迭代. 该形参只能通过 BOOST_PP_ITERATION_PARAMS_x 传入.
当 文件迭代 进行期间, BOOST_PP_IS_ITERATING 被定义为 1.

参见

  • BOOST_PP_FILENAME_x
  • BOOST_PP_IS_ITERATING
  • BOOST_PP_ITERATION_LIMITS
  • BOOST_PP_ITERATION_PARAMS_x

要求

头文件: <boost/preprocessor/iteration/iterate.hpp>

示例代码

// file.h
#if !BOOST_PP_IS_ITERATING

   #ifndef FILE_H_
   #define FILE_H_

   #include <boost/preprocessor/iteration/iterate.hpp>

   #define BOOST_PP_ITERATION_PARAMS_1 (3, (1, 10, "file.h"))
   #include BOOST_PP_ITERATE()

   #define BOOST_PP_FILENAME_1 "file.h"
   #define BOOST_PP_ITERATION_LIMITS (11, 20)
   #include BOOST_PP_ITERATE()

   #endif

#else

   current iteration value is BOOST_PP_ITERATION()

#endif
