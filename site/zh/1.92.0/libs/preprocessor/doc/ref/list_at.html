BOOST_PP_LIST_AT 宏提取 列表 中的一个元素.

用法

BOOST_PP_LIST_AT(list, index)

实参

list
要从中提取元素的 列表. 该 列表 必须至少有 index + 1 个元素.
索引
要提取的元素在 列表 中从零开始的位置.

备注

以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_AT_D 效率更高.

参见

  • BOOST_PP_LIST_AT_D

要求

头文件: <boost/preprocessor/list/at.hpp>

示例代码

#include <boost/preprocessor/list/at.hpp>

#define LIST (a, (b, (c, BOOST_PP_NIL)))

BOOST_PP_LIST_AT(LIST, 0) // expands to a
BOOST_PP_LIST_AT(LIST, 2) // expands to c
