BOOST_PP_TUPLE_SIZE 宏展开为传给它的 元组 的大小.

用法

BOOST_PP_TUPLE_SIZE(tuple) (v)

实参

tuple
要提取其大小的 元组.

要求

头文件: <boost/preprocessor/tuple/size.hpp>

示例代码

#include <boost/preprocessor/tuple/size.hpp>

#define TUPLE (x, y, z)

BOOST_PP_TUPLE_SIZE(TUPLE) // expands to 3
