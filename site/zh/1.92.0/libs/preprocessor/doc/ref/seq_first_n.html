BOOST_PP_SEQ_FIRST_N 宏展开为一个由某个 seq 的前 n 个元素组成的 seq.

用法

BOOST_PP_SEQ_FIRST_N(n, seq)

实参

n
要提取的元素个数.
seq
要从中提取元素的 seq.

备注

该宏从 seq 的开头提取 n 个元素, 并把它们作为一个新的 seq 返回

参见

  • BOOST_PP_SEQ_REST_N

要求

头文件: <boost/preprocessor/seq/first_n.hpp>

示例代码

#include <boost/preprocessor/seq/first_n.hpp>

#define SEQ (a)(b)(c)(d)(e)

BOOST_PP_SEQ_FIRST_N(2, SEQ) // expands to (a)(b)
