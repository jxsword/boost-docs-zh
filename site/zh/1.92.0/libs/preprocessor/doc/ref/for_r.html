BOOST_PP_FOR_r 宏表示对 BOOST_PP_FOR 重复构造的一次重入.

用法

BOOST_PP_FOR_ ## r(state, pred, op, macro)

实参

r
下一个可用的 BOOST_PP_FOR 重复次数.
state
初始状态.
pred
形如 pred(r, state) 的二元谓词. 该宏必须展开为一个处于 0 到 BOOST_PP_LIMIT_MAG 范围内的整数. 当该谓词返回非零值时, BOOST_PP_FOR 反复展开 macro. 该宏以下一个可用的 BOOST_PP_FOR 重复次数和当前 state 被调用.
op
形如 op(r, state) 的二元运算. BOOST_PP_FOR 会以下一个可用的 BOOST_PP_FOR 重复次数和当前 state 来展开该运算. 该宏被反复应用于 state, 每次产生一个新的 state, 直到 pred 返回 0.
宏
形如 macro(r, state) 的二元宏. BOOST_PP_FOR 会以下一个可用的 BOOST_PP_FOR 重复次数和当前 state 来展开该宏. BOOST_PP_FOR 会重复该宏, 直到 pred 返回 0.

备注

该宏展开为如下序列:
macro(r, state) macro(r, op(r, state)) ... macro(r, op(r, ... op(r, state) ... ))
在某些时候, 可能需要用 BOOST_PP_CAT 而不是预处理器记号粘贴运算符来完成拼接. 当 r 值本身是一个宏调用时就会发生这种情况: 它需要延迟展开. 这种场景下的语法为:
BOOST_PP_CAT(BOOST_PP_FOR_, r)(state, pred, op, macro)

参见

  • BOOST_PP_CAT
  • BOOST_PP_FOR
  • BOOST_PP_LIMIT_MAG
  • 带 R 重入形式的宏

要求

头文件: <boost/preprocessor/repetition/for.hpp>

示例代码

#include <boost/preprocessor/arithmetic/dec.hpp>
#include <boost/preprocessor/arithmetic/inc.hpp>
#include <boost/preprocessor/comparison/not_equal.hpp>
#include <boost/preprocessor/punctuation/comma_if.hpp>
#include <boost/preprocessor/repetition/for.hpp>
#include <boost/preprocessor/tuple/elem.hpp>

#define PRED(r, state) \
   BOOST_PP_NOT_EQUAL( \
      BOOST_PP_TUPLE_ELEM(4, 0, state), \
      BOOST_PP_INC( \
         BOOST_PP_TUPLE_ELEM(4, 1, state) \
      ) \
   ) \
   /**/

#define OP(r, state) \
   ( \
      BOOST_PP_INC( \
         BOOST_PP_TUPLE_ELEM(4, 0, state) \
      ), \
      BOOST_PP_TUPLE_ELEM(4, 1, state), \
      BOOST_PP_TUPLE_ELEM(4, 2, state), \
      BOOST_PP_INC( \
         BOOST_PP_TUPLE_ELEM(4, 3, state) \
      ) \
   ) \
   /**/

#define MACRO(r, state) \
   BOOST_PP_COMMA_IF( \
      BOOST_PP_TUPLE_ELEM(4, 3, state) \
   ) template< \
      BOOST_PP_FOR_ ## r( \
         (0, BOOST_PP_TUPLE_ELEM(4, 0, state), _, 0), \
         PRED_2, OP, MACRO_2 \
      ) \
   > class BOOST_PP_CAT( \
      BOOST_PP_TUPLE_ELEM(4, 2, state), \
      BOOST_PP_TUPLE_ELEM(4, 0, state) \
   ) \
   /**/

#define PRED_2(r, state) \
   BOOST_PP_NOT_EQUAL( \
      BOOST_PP_TUPLE_ELEM(4, 0, state), \
      BOOST_PP_TUPLE_ELEM(4, 1, state) \
   ) \
   /**/

#define MACRO_2(r, state) \
   BOOST_PP_COMMA_IF( \
      BOOST_PP_TUPLE_ELEM(4, 0, state) \
   ) class \
   /**/

#define TEMPLATE_TEMPLATE(low, high, name) \
   BOOST_PP_FOR( \
      (low, high, name, 0), \
      PRED, OP, MACRO \
   ) \
   /**/

TEMPLATE_TEMPLATE(2, 4, T)
/*
   expands to...
   template<class, class> class T2,
   template<class, class, class> class T3,
   template<class, class, class, class> class T4
*/
