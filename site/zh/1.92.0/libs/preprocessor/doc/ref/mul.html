BOOST_PP_MUL 宏展开为其各实参的乘积.

用法

BOOST_PP_MUL(x, y)

实参

x
运算的被乘数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
运算的乘数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 与 y 的乘积大于 BOOST_PP_LIMIT_MAG, 结果将被饱和到 BOOST_PP_LIMIT_MAG.
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_MUL_D 效率更高.
当 x 大于等于 y 时, 该宏效率最高. 不过, 为此在调用前实际去比较两个实参并不值得. 换言之, x 应当是最有可能为两操作数中较大者的那个值.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_MUL_D

要求

头文件: <boost/preprocessor/arithmetic/mul.hpp>

示例代码

#include <boost/preprocessor/arithmetic/mul.hpp>

BOOST_PP_MUL(4, 4) // expands to 16
