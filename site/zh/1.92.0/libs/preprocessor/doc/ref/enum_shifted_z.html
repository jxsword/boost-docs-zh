BOOST_PP_ENUM_SHIFTED_z 宏表示对 BOOST_PP_ENUM_SHIFTED 重复构造的一次重入.

用法

BOOST_PP_ENUM_SHIFTED_ ## z(count, macro, data)

实参

z
下一个可用的 BOOST_PP_REPEAT 维度.
count
对 macro 重复调用的次数. 有效取值范围从 0 到 BOOST_PP_LIMIT_REPEAT.
宏
形如 macro(z, n, data) 的三元运算. BOOST_PP_ENUM_SHIFTED 会以下一个可用的重复深度、当前重复编号以及辅助实参 data 来展开该宏.
data
传递给 macro 的辅助数据.

备注

该宏展开为如下序列:
macro(z, 1, data), ... macro(z, count - 1, data)
在某些时候, 可能需要用 BOOST_PP_CAT 而不是预处理器记号粘贴运算符来完成拼接. 当 z 值本身是一个宏调用时就会发生这种情况: 它需要延迟展开. 这种场景下的语法为:
BOOST_PP_CAT(BOOST_PP_ENUM_SHIFTED_, z)(count, macro, data).

参见

  • BOOST_PP_CAT
  • BOOST_PP_ENUM_SHIFTED
  • BOOST_PP_LIMIT_REPEAT

要求

头文件: <boost/preprocessor/repetition/enum_shifted.hpp>

示例代码

#include <boost/preprocessor/arithmetic/inc.hpp>
#include <boost/preprocessor/repetition/enum_shifted.hpp>
#include <boost/preprocessor/repetition/repeat.hpp>

#define TEXT(z, n, text) text

#define MACRO(z, n, data) \
   ( \
      BOOST_PP_ENUM_SHIFTED_ ## z( \
         BOOST_PP_INC(n), \
         TEXT, data \
      ) \
   ) \
   /**/

BOOST_PP_REPEAT(3, MACRO, class) // expands to () (class) (class, class)
