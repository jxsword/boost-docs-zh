BOOST_PP_ARRAY_REPLACE_D 宏替换 数组 中的一个元素. 它以最高效率重入 BOOST_PP_WHILE.

用法

BOOST_PP_ARRAY_REPLACE_D(d, array, i, elem)

实参

d
下一个可用的 BOOST_PP_WHILE 迭代.
array
要在其中替换元素的 数组.
i
要替换的元素在 array 中从零开始的位置. 有效取值范围从 0 到 BOOST_PP_ARRAY_SIZE(array) - 1.
elem
替换后的元素.

参见

  • BOOST_PP_ARRAY_REPLACE

要求
