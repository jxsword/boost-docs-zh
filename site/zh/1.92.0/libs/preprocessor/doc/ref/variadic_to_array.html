BOOST_PP_VARIADIC_TO_ARRAY 变参宏把 变参数据 转换为 数组.

用法

BOOST_PP_VARIADIC_TO_ARRAY(...) (v)

实参

...
待转换的 变参数据.

备注

在 C++ 20 模式下, 变参 数据 可以为空, 结果将是形如 '(0,())' 的空数组.

要求

头文件: <boost/preprocessor/variadic/to_array.hpp>

示例代码

#include <boost/preprocessor/variadic/to_array.hpp>

#define VAR_DATA a, b, c

BOOST_PP_VARIADIC_TO_ARRAY(VAR_DATA) // expands to (3, (a, b, c))
