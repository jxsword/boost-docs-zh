BOOST_PP_ARRAY_ELEM 宏从 数组 中提取一个元素.

用法

BOOST_PP_ARRAY_ELEM(i, array)

实参

i
要提取的元素在 数组 中从零开始的索引.
array
要从中提取元素的 数组. 该 数组 必须至少包含 i + 1 个元素.

要求

头文件: <boost/preprocessor/array/elem.hpp>

示例代码

#include <boost/preprocessor/array/elem.hpp>

#define ARRAY (4, (a, b, c, d))

BOOST_PP_ARRAY_ELEM(0, ARRAY) // expands to a
BOOST_PP_ARRAY_ELEM(3, ARRAY) // expands to d
