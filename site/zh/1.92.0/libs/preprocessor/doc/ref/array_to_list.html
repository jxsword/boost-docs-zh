BOOST_PP_ARRAY_TO_LIST 宏把一个 数组 转换为 列表.

用法

BOOST_PP_ARRAY_TO_LIST(array)

实参

array
要转换的 数组.

备注

如果要转换的 数组 为空 (表示为 '( 0, () )'), 得到的 列表 也为空 (表示为 'BOOST_PP_NIL').

要求

头文件: <boost/preprocessor/array/to_list.hpp>

示例代码

#include <boost/preprocessor/array/to_list.hpp>

BOOST_PP_ARRAY_TO_LIST((3, (x, y, z)))
   // expands to (x, (y, (z, BOOST_PP_NIL)))
