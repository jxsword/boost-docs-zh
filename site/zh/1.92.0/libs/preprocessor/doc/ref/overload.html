BOOST_PP_OVERLOAD 变参宏展开为具有给定形参个数的非变参宏的名字.

用法

BOOST_PP_OVERLOAD(prefix,...) (v)

实参

prefix
非变参宏名字的前缀.
...
变参数据. 变参数据元素的个数 (由 BOOST_PP_VARIADIC_SIZE 确定) 会被追加到前缀之后, 形成输出的非变参宏名字.

备注

该宏创建一个取决于变参数据元素个数的宏名字. 它应以如下形式使用:
BOOST_PP_OVERLOAD(MACRO_NAME_,__VA_ARGS__)(__VA_ARGS__), 以便调用一个非变参宏, 把给定个数的变参数据元素作为非变参实参传入. 这样, 就可以用数量可变的形参调用一个变参宏, 由它转而调用一系列做非常相似事情的非变参宏之一.

在 C++ 20 模式下, 变参 数据 可以为空, 此时给定的形参个数为 0.
要求
头文件: <boost/preprocessor/facilities/overload.hpp>

示例代码

#include <boost/preprocessor/facilities/overload.hpp>
#include <boost/preprocessor/cat.hpp>
#include <boost/preprocessor/facilities/empty.hpp>
#include <boost/preprocessor/arithmetic/add.hpp>

#define MACRO_1(number) MACRO_2(number,10)
#define MACRO_2(number1,number2) BOOST_PP_ADD(number1,number2)

#if !BOOST_PP_VARIADICS_MSVC

#define MACRO_ADD_NUMBERS(...) BOOST_PP_OVERLOAD(MACRO_,__VA_ARGS__)(__VA_ARGS__)

#else

// or for Visual C++'s default preprocessor

#define MACRO_ADD_NUMBERS(...) \
  BOOST_PP_CAT(BOOST_PP_OVERLOAD(MACRO_,__VA_ARGS__)(__VA_ARGS__),BOOST_PP_EMPTY())

#endif

MACRO_ADD_NUMBERS(5) // output is 15
MACRO_ADD_NUMBERS(3,6) // output is 9
