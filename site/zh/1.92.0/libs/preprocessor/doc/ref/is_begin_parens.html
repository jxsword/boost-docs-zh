BOOST_PP_IS_BEGIN_PARENS 判定输入是否以一组圆括号开头.

用法

BOOST_PP_IS_BEGIN_PARENS(...) (v)

实参

... 作为变参数据的输入.

备注

如果输入以一个圆括号开头 (括号内可以有任意数据), 该宏返回 1, 否则返回 0. 起始圆括号之后还可以跟有数据, 该宏仍会返回 1.

对于 Visual Studio 2005 (VC8), 输入数据必须是单个参数, 否则会发生编译错误.

参见

  • BOOST_PP_REMOVE_PARENS

要求

头文件: <boost/preprocessor/punctuation/is_begin_parens.hpp>

示例代码

#include <boost/preprocessor/punctuation/is_begin_parens.hpp>

#define VARDATA more_data , more_params
#define VARDATAP ( data ) more_data , more_params
#define DATA data
#define DATAP ( data ) more_data

BOOST_PP_IS_BEGIN_PARENS(VARDATA)  // expands to 0, compiler error with VC8
BOOST_PP_IS_BEGIN_PARENS(VARDATAP) // expands to 1, compiler error with VC8

BOOST_PP_IS_BEGIN_PARENS(DATA)     // expands to 0
BOOST_PP_IS_BEGIN_PARENS(DATAP)    // expands to 1

BOOST_PP_IS_BEGIN_PARENS()         // expands to 0
