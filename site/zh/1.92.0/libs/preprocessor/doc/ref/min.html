BOOST_PP_MIN 宏展开为其两个实参中较小的一个.

用法

BOOST_PP_MIN(x, y)

实参

x
第一个操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
第二个操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

该宏返回其两个实参中较小的一个; 若两者相等, 则返回该共同的值.
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_MIN_D 效率更高.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_MIN_D

要求

头文件: <boost/preprocessor/selection/min.hpp>

示例代码

#include <boost/preprocessor/selection/min.hpp>

BOOST_PP_MIN(5, 7) // expands to 5
BOOST_PP_MIN(3, 3) // expands to 3
