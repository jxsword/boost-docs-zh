BOOST_PP_TUPLE_ENUM 宏把一个 元组 转换为其以逗号分隔的各元素. 这些以逗号分隔的元素呈 变参数据 的形式.

用法

BOOST_PP_TUPLE_ENUM(tuple) (v)

或

BOOST_PP_TUPLE_ENUM(size,tuple) (v)

实参

size
该 元组 的大小. 该大小会被忽略.
tuple
要转换其各元素的 元组.

备注

你可以把该变参宏 (v) 调用为 BOOST_PP_TUPLE_ENUM(tuple) 或 BOOST_PP_TUPLE_ENUM(size,tuple) 以保持向后兼容.

参见

  • BOOST_PP_LIMIT_TUPLE

要求

头文件: <boost/preprocessor/tuple/enum.hpp>

示例代码

#include <boost/preprocessor/tuple/enum.hpp>

#define TUPLE (B,O,O,S,T)

BOOST_PP_TUPLE_ENUM(TUPLE) // expands to B, O, O, S, T
