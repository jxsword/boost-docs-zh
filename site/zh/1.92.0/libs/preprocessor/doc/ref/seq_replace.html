BOOST_PP_SEQ_REPLACE 宏替换一个 seq 中的元素.

用法

BOOST_PP_SEQ_REPLACE(seq, i, elem)

实参

seq
要在其中替换元素的 seq.
i
要替换的元素在 seq 中从零开始的位置. 有效取值范围从 0 到 BOOST_PP_SEQ_SIZE(seq) - 1.
elem
用于替换 seq 中索引 i 处元素的元素.

备注

该宏在用 elem 替换索引 i 处的元素后返回 seq.

要求

头文件: <boost/preprocessor/seq/replace.hpp>

示例代码

#include <boost/preprocessor/seq/replace.hpp>

#define SEQ (a)(b)(x)(d)

BOOST_PP_SEQ_REPLACE(SEQ, 2, c) // expands to (a)(b)(c)(d)
