BOOST_PP_TUPLE_TO_ARRAY 宏把一个 元组 转换为 数组.

用法

BOOST_PP_TUPLE_TO_ARRAY(tuple) (v)

或

BOOST_PP_TUPLE_TO_ARRAY(size,tuple) (v)

实参

size
该 元组 的大小. 该实参会被忽略.
tuple
要转换的 元组.

备注

你可以把该变参宏 (v) 调用为 BOOST_PP_TUPLE_TO_ARRAY(tuple) 或 BOOST_PP_TUPLE_TO_ARRAY(size,tuple) 以保持向后兼容.

要求

头文件: <boost/preprocessor/tuple/to_array.hpp>

示例代码

#include <boost/preprocessor/tuple/to_array.hpp>

#define TUPLE (a,b,c)

BOOST_PP_TUPLE_TO_ARRAY(TUPLE) // expands to (3, (a, b, c))
