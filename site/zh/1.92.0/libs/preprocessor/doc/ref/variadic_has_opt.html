BOOST_PP_VARIADIC_HAS_OPT 宏判定当前所用编译器的预处理器是否支持 C++20 __VA_OPT__ 构造. 若支持 __VA_OPT__ 构造则展开为 1, 否则展开为 0.

用法

BOOST_PP_VARIADIC_HAS_OPT()

实参

无

备注

只有当编译器以自身的 C++20 级别编译且支持 __VA_OPT__ 时, 该宏才返回 1. 编译器有可能在未以其自身 C++20 级别编译时也支持 __VA_OPT__ 构造, 但在这种情况下该宏仍会返回 0, 即使 __VA_OPT__ 在该级别下通常是被支持的. 原因在于: 这样的编译器可能带有强制严格遵守某个特定 C++ 标准级别的编译器开关, 当在 C++20 级别以下指定 __VA_OPT__ 时会给出警告或错误, 而预处理器库希望避免这种情况发生. 因此, 该宏只会检测 __VA_OPT__ 是否在 C++20 级别受支持, 对所有更低的 C++ 标准级别一律返回 0.

要求

头文件: <boost/preprocessor/variadic/has_opt.hpp>

示例代码

#include <boost/preprocessor/variadic/has_opt.hpp>

#if BOOST_PP_VARIADIC_HAS_OPT()
// Preprocessor code which uses __VA_OPT__
#else
// Preprocessor code which does not use __VA_OPT__
#endif

或在某个宏定义内

#include <boost/preprocessor/control/iif.hpp>
#include <boost/preprocessor/variadic/has_opt.hpp>

#define USE_OPT(...) BOOST_PP_IIF(BOOST_PP_VARIADIC_HAS_OPT(),MACRO_USING_OPT,MACRO_NOT_USING_OPT)(__VA_ARGS__)
#define MACRO_USING_OPT(...) __VA_OPT__( preprocessor tokens ) anything
#define MACRO_NOT_USING_OPT(...) anything
