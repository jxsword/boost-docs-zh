BOOST_PP_VARIADIC_TO_LIST 变参宏把 变参数据 转换为 列表.

用法

BOOST_PP_VARIADIC_TO_LIST(...) (v)

实参

...
待转换的 变参数据.

备注

在 C++ 20 模式下, 变参 数据 可以为空, 结果将是形如 'BOOST_PP_NIL' 的空列表.

要求

头文件: <boost/preprocessor/variadic/to_list.hpp>

示例代码

#include <boost/preprocessor/variadic/to_list.hpp>

BOOST_PP_VARIADIC_TO_LIST(x, y, z)
   // expands to (x, (y, (z, BOOST_PP_NIL)))
