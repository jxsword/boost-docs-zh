BOOST_PP_TUPLE_TO_LIST 宏把一个 元组 转换为 列表.

用法

BOOST_PP_TUPLE_TO_LIST(tuple) (v)

或

BOOST_PP_TUPLE_TO_LIST(size, tuple) (v)

实参

size
要转换的 元组 的大小. 该实参会被忽略.
tuple
要转换的 元组.

备注

你可以把该变参宏 (v) 调用为 BOOST_PP_TUPLE_TO_LIST(tuple) 或 BOOST_PP_TUPLE_TO_LIST(size,tuple) 以保持向后兼容.

参见

  • BOOST_PP_LIMIT_TUPLE

要求

头文件: <boost/preprocessor/tuple/to_list.hpp>

示例代码

#include <boost/preprocessor/tuple/to_list.hpp>

BOOST_PP_TUPLE_TO_LIST((x, y, z))
   // expands to (x, (y, (z, BOOST_PP_NIL)))
