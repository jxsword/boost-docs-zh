BOOST_PP_ARRAY_TO_TUPLE 宏把一个 数组 转换为 元组.

用法

BOOST_PP_ARRAY_TO_TUPLE(array)

实参

array
要转换的 数组.

备注

如果要转换的 数组 为空 (表示为 '( 0, () )'), 得到的 元组 未定义, 因为 元组 不能为空.

要求

头文件: <boost/preprocessor/array/to_tuple.hpp>

示例代码

#include <boost/preprocessor/array/to_tuple.hpp>

#define ARRAY (3,(a, b, c))

BOOST_PP_ARRAY_TO_TUPLE(ARRAY) // expands to (a, b, c)
