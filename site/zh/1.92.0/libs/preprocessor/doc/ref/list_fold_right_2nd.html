BOOST_PP_LIST_FOLD_RIGHT_2ND 宏从右到左折叠 (或累积) 一个 列表 的各元素.

用法

BOOST_PP_LIST_FOLD_RIGHT_2ND(op, state, list)

实参

op
形如 op(d, state, elem) 的三元运算. list 中的每个元素都会调用该宏——每次返回一个新的 state. BOOST_PP_LIST_FOLD_RIGHT 会以下一个可用的 BOOST_PP_WHILE 迭代、当前 state 和当前元素来展开该运算.
state
折叠的初始状态.
list
要折叠的 列表.

备注

该宏的签名与以前不同. 实参已被调换, 以便与 BOOST_PP_LIST_FOLD_LEFT 提供统一的接口.
对于 列表 (0, (1, (2, BOOST_PP_NIL))), 该宏展开为:
op(d, op(d, op(d, state, 0), 1), 2)
该宏已被弃用. 请改用 BOOST_PP_LIST_FOLD_RIGHT_d.

参见

  • BOOST_PP_LIST_FOLD_RIGHT
  • BOOST_PP_LIST_FOLD_RIGHT_d

要求

头文件: <boost/preprocessor/list/fold_right.hpp>

示例代码

#include <boost/preprocessor/cat.hpp>
#include <boost/preprocessor/list/fold_right.hpp>

#define LIST (a, (b, (c, BOOST_PP_NIL)))

#define OP(d, state, x) BOOST_PP_CAT(state, x)

BOOST_PP_LIST_FOLD_RIGHT_2ND(OP, _, LIST) // expands to _cba
