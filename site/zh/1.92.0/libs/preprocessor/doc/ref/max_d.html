BOOST_PP_MAX_D 宏展开为其第二个和第三个实参中较大的一个. 它以最高效率重入 BOOST_PP_WHILE.

用法

BOOST_PP_MAX_D(d, x, y)

实参

d
下一个可用的 BOOST_PP_WHILE 迭代.
x
第一个操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
第二个操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

该宏返回其第一个和第二个实参中较大的一个; 若两者相等, 则返回该共同的值.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_MAX

要求

头文件: <boost/preprocessor/selection/max.hpp>

示例代码

#include <boost/preprocessor/list/fold_left.hpp>
#include <boost/preprocessor/selection/max.hpp>

#define LIST (1, (3, (5, (2, (4, BOOST_PP_NIL)))))

#define OP(d, state, x) BOOST_PP_MAX_D(d, state, x)

#define LIST_MAX(list) BOOST_PP_LIST_FOLD_LEFT(OP, 0, LIST)

LIST_MAX(LIST) // expands to 5
