BOOST_PP_SEQ_FILTER 宏根据给定的准则过滤一个 seq.

用法

BOOST_PP_SEQ_FILTER(pred, data, seq)

实参

pred
形如 pred(s, data, elem) 的三元谓词. BOOST_PP_SEQ_FILTER 会对 seq 中的每个元素展开该谓词, 传给它下一个可用的 BOOST_PP_SEQ_FOLD_LEFT 折叠步骤、辅助数据 data 以及 seq 中的当前元素. 该宏必须返回一个处于 0 到 BOOST_PP_LIMIT_MAG 范围内的整数值. 若该谓词对某个元素展开为非零值, 该元素就会被纳入结果 seq.
data
传递给 pred 的辅助数据.
seq
要过滤的 seq.

备注

该宏对 seq 中的每个元素展开 pred, 并用 pred 返回非零值的那些元素构建一个新的 seq.
为获得最高效率, 请使用 BOOST_PP_SEQ_FILTER_S.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_SEQ_FILTER_S

要求

头文件: <boost/preprocessor/seq/filter.hpp>

示例代码

#include <boost/preprocessor/comparison/less_equal.hpp>
#include <boost/preprocessor/seq/filter.hpp>

#define SEQ (1)(3)(2)(5)

#define PRED(s, data, elem) BOOST_PP_LESS_EQUAL(elem, data)

BOOST_PP_SEQ_FILTER(PRED, 3, SEQ)
   // expands to (1)(3)(2)
