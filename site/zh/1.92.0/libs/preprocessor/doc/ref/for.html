BOOST_PP_FOR 宏表示一个广义的水平重复构造.

用法

BOOST_PP_FOR(state, pred, op, macro)

实参

state
初始状态.
pred
形如 pred(r, state) 的二元谓词. 该宏必须展开为一个处于 0 到 BOOST_PP_LIMIT_MAG 范围内的整数. 当该谓词返回非零值时, BOOST_PP_FOR 反复展开 macro. 该宏以下一个可用的 BOOST_PP_FOR 重复次数和当前 state 被调用.
op
形如 op(r, state) 的二元运算. BOOST_PP_FOR 会以下一个可用的 BOOST_PP_FOR 重复次数和当前 state 来展开该运算. 该宏被反复应用于 state, 每次产生一个新的 state, 直到 pred 返回 0.
宏
形如 macro(r, state) 的二元宏. BOOST_PP_FOR 会以下一个可用的 BOOST_PP_FOR 重复次数和当前 state 来展开该宏. BOOST_PP_FOR 会重复该宏, 直到 pred 返回 0.

备注

该宏展开为如下序列:
macro(r, state) macro(r, op(r, state)) ... macro(r, op(r, ... op(r, state) ... ))
传递给 pred、op 和 macro 的 r 值表示下一个可用的 BOOST_PP_FOR 重复次数. 其他带有 _R 后缀变体的宏内部都使用 BOOST_PP_FOR——例如 BOOST_PP_LIST_FOR_EACH 和 BOOST_PP_LIST_FOR_EACH_R. 严格来说并不必须使用这些 _R 版本, 但把传给 pred、op 和 macro 的 r 值传给这些宏, 可以让它们以最高效率重入 BOOST_PP_FOR.
若要直接使用这个 r 值而不是简单地把它传给另一个宏, 请参见 BOOST_PP_FOR_r.
以前, 该宏不能在 BOOST_PP_FOR 内部递归使用. 这一限制已不复存在, 因为库能够自动检测下一个可用的 BOOST_PP_FOR 重复次数.

参见

  • BOOST_PP_FOR_r
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/repetition/for.hpp>

示例代码

#include <boost/preprocessor/arithmetic/inc.hpp>
#include <boost/preprocessor/comparison/not_equal.hpp>
#include <boost/preprocessor/repetition/for.hpp>
#include <boost/preprocessor/tuple/elem.hpp>

#define PRED(r, state) \
   BOOST_PP_NOT_EQUAL( \
      BOOST_PP_TUPLE_ELEM(2, 0, state), \
      BOOST_PP_INC(BOOST_PP_TUPLE_ELEM(2, 1, state)) \
   ) \
   /**/

#define OP(r, state) \
   ( \
      BOOST_PP_INC(BOOST_PP_TUPLE_ELEM(2, 0, state)), \
      BOOST_PP_TUPLE_ELEM(2, 1, state) \
   ) \
   /**/

#define MACRO(r, state) BOOST_PP_TUPLE_ELEM(2, 0, state)

BOOST_PP_FOR((5, 10), PRED, OP, MACRO) // expands to 5 6 7 8 9 10
