BOOST_PP_SEQ_NIL 宏是一个表示空 seq 的占位宏. 只有当其元素被追加到这个空“seq”的末尾时它才有效.

用法

BOOST_PP_SEQ_NIL

备注

该宏是一个工具宏, 用作向尾部追加内容时的空起点. 它不是一个 nil seq. 当有元素追加到该宏时, 它会展开并让位于该元素——从而移除自身. 例如, BOOST_PP_SEQ_NIL(x) 和 BOOST_PP_SEQ_PUSH_BACK(BOOST_PP_SEQ_NIL, x) 都展开为 x.
如果任何 BOOST_PP_SEQ_* 宏 (BOOST_PP_SEQ_PUSH_BACK 除外) 以包含 BOOST_PP_SEQ_NIL 的实参被调用, 其行为未定义, 并且在多数情况下会导致晦涩的错误.
对于向头部追加而言, 与 BOOST_PP_SEQ_NIL 最接近的东西是 BOOST_PP_EMPTY. 在所有元素都前置完毕之后, 可以对尾部调用空圆括号来移除 BOOST_PP_EMPTY. 与 BOOST_PP_SEQ_NIL 一样, 把包含 BOOST_PP_EMPTY 的实参传给任何 BOOST_PP_SEQ_* 宏 (BOOST_PP_SEQ_PUSH_FRONT 除外) 都属于未定义行为.
(另一种做法是先多放一个元素, 追加完毕后再把它弹出. )
在 C99 中, 这两个宏都不必要, 因为传递空实参是合法的.

参见

  • BOOST_PP_EMPTY

要求

头文件: <boost/preprocessor/seq/seq.hpp>

示例代码

#include <boost/preprocessor/facilities/empty.hpp>
#include <boost/preprocessor/seq/push_back.hpp>
#include <boost/preprocessor/seq/push_front.hpp>
#include <boost/preprocessor/seq/seq.hpp>

#define SEQ_L BOOST_PP_SEQ_NIL
#define SEQ_R BOOST_PP_EMPTY
BOOST_PP_SEQ_PUSH_BACK(
   BOOST_PP_SEQ_PUSH_BACK(SEQ_L, a), b
)

// expands to (a)(b)

BOOST_PP_SEQ_PUSH_FRONT(
   BOOST_PP_SEQ_PUSH_FRONT(SEQ_R, a), b
)()

// expands to (b)(a)
