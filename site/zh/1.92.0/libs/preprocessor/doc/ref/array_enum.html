BOOST_PP_ARRAY_ENUM 宏把一个 数组 转换为其以逗号分隔的各元素. 这些以逗号分隔的元素呈 变参数据 的形式.

用法

BOOST_PP_ARRAY_ENUM(array)

实参

array
要转换其各元素的 数组.

备注

该宏展开为 array 中各元素组成的以逗号分隔的列表. 例如, BOOST_PP_ARRAY_ENUM((3,(x,y,z))) 展开为...
x, y, z

在 C++ 20 模式下, 若数组为空, 得到的 变参 数据 将为空.

要求

头文件: <boost/preprocessor/array/enum.hpp>

示例代码

#include <boost/preprocessor/array/enum.hpp>

#define ARRAY (5,(B,O,O,S,T))

BOOST_PP_ARRAY_ENUM(ARRAY) // expands to B, O, O, S, T
