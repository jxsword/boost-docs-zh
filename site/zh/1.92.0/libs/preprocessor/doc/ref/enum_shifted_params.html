BOOST_PP_ENUM_SHIFTED_PARAMS 宏生成一个以逗号分隔的移位形参列表.

用法

BOOST_PP_ENUM_SHIFTED_PARAMS(count, param)

实参

count
要生成的形参个数. 有效取值范围从 0 到 BOOST_PP_LIMIT_REPEAT.
param
形参的文本. BOOST_PP_ENUM_SHIFTED_PARAMS 通过拼接从 1 到 count - 1 的数字来生成形参.

备注

该宏展开为如下以逗号分隔的序列:
param ## 1, ... param ## count - 1
该宏为库的一种典型用法提供了便利. 移位的形参列表在模板元程序中很常见.
若要使用其他宏传来的 z 形参 (来自使用 BOOST_PP_REPEAT 的宏), 请参见 BOOST_PP_ENUM_SHIFTED_PARAMS_Z.
以前, 该宏不能在 BOOST_PP_REPEAT 内部递归使用. 这一限制已不复存在, 因为库能够自动检测下一个可用的重复深度.

参见

  • BOOST_PP_LIMIT_REPEAT
  • BOOST_PP_SHIFTED_ENUM_PARAMS_z

要求

头文件: <boost/preprocessor/repetition/enum_shifted_params.hpp>

示例代码

#include <boost/preprocessor/repetition/enum_shifted_params.hpp>

BOOST_PP_ENUM_SHIFTED_PARAMS(3, class T) // expands to class T1, class T2
