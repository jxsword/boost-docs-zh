BOOST_PP_EXPAND 宏对其实参执行双重宏展开.

用法

BOOST_PP_EXPAND(x)

实参

x
要展开两次的实参.

备注

当需要延迟以产生正确的宏调用语义时, 该宏很有用. 例如, 当一个宏展开为另一个宏的实参列表时. 该宏会在第一遍展开实参列表, 然后重新扫描以展开更多的宏.

要求

头文件: <boost/preprocessor/facilities/expand.hpp>

示例代码

#include <boost/preprocessor/control/if.hpp>
#include <boost/preprocessor/facilities/expand.hpp>

#define MACRO(a, b, c) (a)(b)(c)
#define ARGS() (1, 2, 3)

BOOST_PP_EXPAND(MACRO ARGS()) // expands to (1)(2)(3)

#define SAMPLE(n) \
   BOOST_PP_EXPAND( \
      MACRO \
      BOOST_PP_IF( \
         n, \
         (x, y, z), \
         (a, b, c) \
      ) \
   ) \
   /**/

SAMPLE(0) // expands to (a)(b)(c)
SAMPLE(1) // expands to (x)(y)(z)
