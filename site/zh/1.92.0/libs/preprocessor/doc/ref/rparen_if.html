BOOST_PP_RPAREN_IF 宏有条件地展开为一个右圆括号.

用法

BOOST_PP_RPAREN_IF(cond)

实参

cond
决定该宏展开为右圆括号还是为空的条件. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 cond 展开为 0, 该宏展开为空; 否则展开为一个右圆括号.
预处理器把圆括号解释为宏调用中的定界符. 因此, 圆括号需要特殊处理.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_LPAREN_IF

要求

头文件: <boost/preprocessor/punctuation/paren_if.hpp>

示例代码

#include <boost/preprocessor/punctuation/paren_if.hpp>

#define MACRO(c, x) BOOST_PP_LPAREN_IF(c) x BOOST_PP_RPAREN_IF(c)

MACRO(0, text) // expands to text
MACRO(1, text) // expands to (text)
