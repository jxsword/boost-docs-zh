BOOST_PP_SEQ_TRANSFORM 宏根据给定的变换处理一个 seq 中的每个元素.

用法

BOOST_PP_SEQ_TRANSFORM(op, data, seq)

实参

op
形如 op(s, data, elem) 的三元谓词. BOOST_PP_SEQ_TRANSFORM 会对 seq 中的每个元素展开该变换, 传给它下一个可用的 BOOST_PP_SEQ_FOLD_LEFT 折叠步骤、辅助数据 data 以及 seq 中的当前元素.
data
传递给 pred 的辅助数据.
seq
要变换的 seq.

备注

该宏对 seq 中的每个元素展开 op, 并用每次调用的结果构建一个新的 seq. 例如, 若 seq 为 (a)(b)(c), 该宏展开为……
(op(d, data, a))(op(d, data, b))(op(d, data, c))
为获得最高效率, 请使用 BOOST_PP_SEQ_TRANSFORM_S.

参见

  • BOOST_PP_SEQ_TRANSFORM_S

要求

头文件: <boost/preprocessor/seq/transform.hpp>

示例代码

#include <boost/preprocessor/arithmetic/dec.hpp>
#include <boost/preprocessor/seq/transform.hpp>

#define SEQ (1)(3)(2)(5)

#define OP(s, data, elem) BOOST_PP_DEC(elem)

BOOST_PP_SEQ_TRANSFORM(OP, 3, SEQ)
   // expands to (0)(2)(1)(4)
