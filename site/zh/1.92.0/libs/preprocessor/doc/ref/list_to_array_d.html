BOOST_PP_LIST_TO_ARRAY_D 宏把一个 列表 转换为 数组. 它以最高效率重入 BOOST_PP_WHILE.

用法

BOOST_PP_LIST_TO_ARRAY_D(d, list)

实参

d
下一个可用的 BOOST_PP_WHILE 迭代.
list
要转换的 列表.

备注

如果要转换的 列表 为空 (表示为 'BOOST_PP_NIL'), 得到的 数组 也为空 (表示为 '( 0, () )').

参见
