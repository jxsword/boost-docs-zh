BOOST_PP_LIST_FIRST_N 宏展开为一个由某个 列表 的前 count 个元素组成的 列表.

用法

BOOST_PP_LIST_FIRST_N(count, list)

实参

count
要提取的元素个数.
list
要从中提取元素的 列表.

备注

该宏从 list 的开头提取 count 个元素, 并把它们作为一个 列表 返回
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_FIRST_N_D 效率更高.

参见

  • BOOST_PP_LIST_FIRST_N_D

要求

头文件: <boost/preprocessor/list/first_n.hpp>

示例代码

#include <boost/preprocessor/list/first_n.hpp>

#define LIST (a, (b, (c, BOOST_PP_NIL)))

BOOST_PP_LIST_FIRST_N(2, LIST) // expands to (a, (b, BOOST_PP_NIL))
