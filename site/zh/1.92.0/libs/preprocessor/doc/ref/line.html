BOOST_PP_LINE 宏在预处理输出中放置以行指令编码的注记.

用法

#line BOOST_PP_LINE(line, file)

实参

line
其后那一行的新行号. 通常使用预定义宏 __LINE__.
file
通常是当前文件的名字. 不过, 任何信息性文本都可以. 该文本在内部会被字符串化, 因此不需要引号.

备注

如果宏 BOOST_PP_CONFIG_EXTENDED_LINE_INFO 被定义为 1 且 文件迭代 正在进行, 该宏会自动插入关于 文件迭代 状态的调试信息. 这些信息会显示所有当前迭代值, 最内层的迭代排在最后.
当错误可能横跨同一源文本的多次迭代时, 这些信息非常有用. 找到这些错误有时并不直观. 使用该宏可以提供让这件事容易得多的信息. 例如, 与其得到若干个这样的错误:
"file.hpp", line 2: error: expected a ";"
"file.hpp", line 4: error: improperly terminated macro invocation
你可能会得到类似这样的输出……
"file.hpp [1]", line 2: error: expected a ";"
"file.hpp [5]", line 4: error: improperly terminated macro invocation
可以立刻看出, 该错误横跨了同一源文本的多次迭代. 如果不是这样, 同样的错误就会在每次迭代中都出现.
但必须指出, 有些编译器不喜欢并非真实文件的文件名. 这些编译器通常会就错误的文件名发出警告. 因此, 最好只在调试时才把 BOOST_PP_CONFIG_EXTENDED_LINE_INFO 定义为 1. 仅当调试时才应如此.

参见

  • BOOST_PP_CONFIG_EXTENDED_LINE_INFO

要求

头文件: <boost/preprocessor/debug/line.hpp>

示例代码

// sample.cpp
#if !defined(BOOST_PP_IS_ITERATING)

   #define BOOST_PP_CONFIG_EXTENDED_LINE_INFO 1

   #include <boost/preprocessor/arithmetic/dec.hpp>
   #include <boost/preprocessor/cat.hpp>
   #include <boost/preprocessor/debug/line.hpp>
   #include <boost/preprocessor/iteration/iterate.hpp>

   namespace sample {

   #define BOOST_PP_ITERATION_PARAMS_1 (3, (1, 5, "sample.cpp"))
   #include BOOST_PP_ITERATE()

   } // sample

   int main(void) {
      return 0;
   }

#else

   #line BOOST_PP_LINE(1, sample.cpp)

   int BOOST_PP_CAT(x, BOOST_PP_ITERATION())); // extra parenthesis
   
   struct BOOST_PP_CAT(s, BOOST_PP_DEC(BOOST_PP_ITERATION()) {
      // missing a parenthesis
      // ...
   };

#endif
