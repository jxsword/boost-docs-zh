BOOST_PP_TUPLE_REM 宏展开为一个移除 元组 圆括号的宏.

用法

BOOST_PP_TUPLE_REM() (v)

或

BOOST_PP_TUPLE_REM(size) (v)

实参

size
要移除其圆括号的 元组 的大小. 该实参会被忽略.

备注

大小可以完全省略, 这样该宏就能以 BOOST_PP_TUPLE_REM() 的形式调用; 某些编译器可能会给出警告, 但功能仍然有效. 如果指定了大小, 它会被忽略, 但某些编译器的警告就不会出现.

注意: 对于 Visual C++ 8.0 (Visual Studio 2005), 必须指定正确的 size 实参, 因为必须使用非变参版本.

参见

  • BOOST_PP_LIMIT_TUPLE

要求

头文件: <boost/preprocessor/tuple/rem.hpp>

示例代码

#include <boost/preprocessor/tuple/rem.hpp>

BOOST_PP_TUPLE_REM()(x, y, z) // expands to x, y, z
