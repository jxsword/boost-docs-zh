BOOST_PP_SEQ_CAT 宏拼接一个 seq 中的所有元素.

用法

BOOST_PP_SEQ_CAT(seq)

实参

seq
要拼接其各元素的 seq.

备注

各元素从索引 0 开始从左到右依次拼接.
为获得最高效率, 请使用 BOOST_PP_SEQ_CAT_S.

参见

  • BOOST_PP_SEQ_CAT_S

要求

头文件: <boost/preprocessor/seq/cat.hpp>

示例代码

#include <boost/preprocessor/seq/cat.hpp>

#define SEQ (a)(b)(c)

BOOST_PP_SEQ_CAT(SEQ) // expands to abc
