BOOST_PP_INC 宏展开为比其实参大 1 的值.

用法

BOOST_PP_INC(x)

实参

x
要递增的值. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 为 BOOST_PP_LIMIT_MAG, 结果被饱和到 BOOST_PP_LIMIT_MAG.

参见

  • BOOST_PP_DEC
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/arithmetic/inc.hpp>

示例代码

#include <boost/preprocessor/arithmetic/inc.hpp>

BOOST_PP_INC(BOOST_PP_INC(6)) // expands to 8
BOOST_PP_INC(4) // expands to 5
