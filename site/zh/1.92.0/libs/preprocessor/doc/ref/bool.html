BOOST_PP_BOOL 宏对其操作数执行布尔转换.

用法

BOOST_PP_BOOL(x)

实参

x
要转换的值. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 为 0, 该宏展开为 0; 否则展开为 1.

参见

  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/logical/bool.hpp>

示例代码

#include <boost/preprocessor/logical/bool.hpp>

BOOST_PP_BOOL(6) // expands to 1
BOOST_PP_BOOL(0) // expands to 0
