BOOST_PP_SEQ_FOR_EACH_PRODUCT_R 宏针对若干 seq 的每个笛卡尔积重复调用一个宏. 它以最高效率重入 BOOST_PP_FOR.

用法

BOOST_PP_SEQ_FOR_EACH_PRODUCT_R(r, macro, seqs)

实参

r
下一个可用的 BOOST_PP_FOR 重复次数.
宏
形如 macro(r, product) 的二元宏. BOOST_PP_FOR_EACH_PRODUCT 会以 seqs 中的每个笛卡尔积展开该宏, 传给它下一个可用的 BOOST_PP_FOR 重复次数以及一个包含笛卡尔积的 seq.
seqs
一个由 seq 组成的 seq, 笛卡尔积即从它取得.

备注

该宏是一个重复构造. 若两个 seq 分别为 (a)(b)(c) 和 (x)(y)(z), 该宏将产生如下序列:
macro(r, (a)(x)) macro(r, (a)(y)) macro(r, (a)(z)) \
macro(r, (b)(x)) macro(r, (b)(y)) macro(r, (b)(z)) \
macro(r, (c)(x)) macro(r, (c)(y)) macro(r, (c)(z))
