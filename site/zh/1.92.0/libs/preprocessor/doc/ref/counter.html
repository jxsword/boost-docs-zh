BOOST_PP_COUNTER 宏展开为当前计数器值.

用法

BOOST_PP_COUNTER

备注

该宏展开为一个整数字面量. 其初始值为 0. 在两次使用 BOOST_PP_UPDATE_COUNTER 之间, BOOST_PP_COUNTER 的值保持不变.

参见

  • BOOST_PP_UPDATE_COUNTER

要求

头文件: <boost/preprocessor/slot/counter.hpp>

示例代码

#include <boost/preprocessor/slot/counter.hpp>

BOOST_PP_COUNTER // 0

#include BOOST_PP_UPDATE_COUNTER()

BOOST_PP_COUNTER // 1

#include BOOST_PP_UPDATE_COUNTER()

BOOST_PP_COUNTER // 2

#include BOOST_PP_UPDATE_COUNTER()

BOOST_PP_COUNTER // 3
