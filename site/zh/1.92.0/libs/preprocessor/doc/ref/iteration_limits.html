BOOST_PP_ITERATION_LIMITS 宏是一个用户定义的 命名外部实参, 由 BOOST_PP_ITERATE 使用. 它表示一次 文件迭代 的下界和上界.

用法

#define BOOST_PP_ITERATION_LIMITS (start, finish)

实参

start
一次 文件迭代 的下界 (含). 有效取值范围从 0 到 BOOST_PP_LIMIT_ITERATION.
finish
一次 文件迭代 的上界 (含). 有效取值范围从 0 到 BOOST_PP_LIMIT_ITERATION.

备注

注意, 宏标识符之后有一个空白字符.
该宏是向 BOOST_PP_ITERATE 传参的次级方法的一部分. 另一部分是 BOOST_PP_FILENAME_x. start 和 finish 都是 会被求值的形参. 这意味着它们可以包含简单的算术运算.
该宏会被 BOOST_PP_ITERATE 的调用自动取消定义以供复用.

参见

  • BOOST_PP_ITERATE
  • BOOST_PP_LIMIT_ITERATION
