BOOST_PP_CONFIG_EXTENDED_LINE_INFO 是一个用户自定义宏, 决定 BOOST_PP_LINE 是否输出扩展的 文件迭代 状态信息.

用法

#define BOOST_PP_CONFIG_EXTENDED_LINE_INFO n

实参

n
决定 BOOST_PP_LINE 是否输出扩展 文件迭代 信息的值. 该值必须为 0 或 1.

备注

若 n 为 1, BOOST_PP_LINE 将输出扩展数据. 默认情况下, 该宏被设为 0.
