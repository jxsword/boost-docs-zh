BOOST_PP_SEQ_HEAD 宏展开为一个 seq 中的第一个元素.

用法

BOOST_PP_SEQ_HEAD(seq)

实参

seq
要从中提取第一个元素的 seq.

参见

  • BOOST_PP_SEQ_TAIL

要求

头文件: <boost/preprocessor/seq/seq.hpp>

示例代码

#include <boost/preprocessor/seq/seq.hpp>

#define SEQ (a)(b)(c)

BOOST_PP_SEQ_HEAD(SEQ) // expands to a
BOOST_PP_SEQ_TAIL(SEQ) // expands to (b)(c)
