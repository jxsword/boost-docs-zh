BOOST_PP_ENUM_TRAILING_z 宏表示对 BOOST_PP_ENUM_TRAILING 重复构造的一次重入.

用法

BOOST_PP_ENUM_TRAILING_ ## z(count, macro, data)

实参

z
下一个可用的 BOOST_PP_REPEAT 维度.
count
对 macro 重复调用的次数. 有效取值范围从 0 到 BOOST_PP_LIMIT_REPEAT.
宏
形如 macro(z, n, data) 的三元运算. BOOST_PP_ENUM 会以下一个可用的重复深度、当前重复编号以及辅助实参 data 来展开该宏.
data
传递给 macro 的辅助数据.

备注

该宏展开为如下序列:
, macro(z, 0, data), macro(z, 1, data), ... macro(z, count - 1, data)
在某些时候, 可能需要用 BOOST_PP_CAT 而不是预处理器记号粘贴运算符来完成拼接. 当 z 值本身是一个宏调用时就会发生这种情况: 它需要延迟展开. 这种场景下的语法为:
BOOST_PP_CAT(BOOST_PP_ENUM_TRAILING_, z)(count, macro, data)

参见

  • BOOST_PP_CAT
  • BOOST_PP_ENUM_TRAILING
  • BOOST_PP_LIMIT_REPEAT

要求

头文件: <boost/preprocessor/repetition/enum_trailing.hpp>

示例代码

#include <boost/preprocessor/repetition/enum.hpp>
#include <boost/preprocessor/repetition/enum_trailing.hpp>

#define TEXT(z, n, text) text

#define TTP(z, n, _) \
   template< \
      class BOOST_PP_ENUM_TRAILING_ ## z(n, TEXT, class) \
   > \
   class T ## n \
   /**/

BOOST_PP_ENUM(3, TTP, nil)
   /*
      expands to...
      template<class> class T0,
      template<class, class> class T1,
      template<class, class, class> class T2
   */
