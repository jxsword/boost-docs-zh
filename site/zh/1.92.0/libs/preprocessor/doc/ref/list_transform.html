BOOST_PP_LIST_TRANSFORM 宏根据给定的变换处理一个 列表 中的每个元素.

用法

BOOST_PP_LIST_TRANSFORM(op, data, list)

实参

op
形如 op(d, data, elem) 的三元谓词. BOOST_PP_LIST_TRANSFORM 会对 list 中的每个元素展开该变换, 传给它下一个可用的 BOOST_PP_WHILE 迭代、辅助数据 data 以及 list 中的当前元素.
data
传递给 pred 的辅助数据.
list
要变换的 列表.

备注

该宏对 list 中的每个元素展开 op, 并用每次调用的结果构建一个新的 列表. 例如, 若 list 为 (a, (b, (c, BOOST_PP_NIL))), 该宏展开为……
(op(d, data, a), (op(d, data, b), (op(d, data, c), BOOST_PP_NIL)))
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_LIST_TRANSFORM_D 效率更高.

参见

  • BOOST_PP_LIST_TRANSFORM_D

要求

头文件: <boost/preprocessor/list/transform.hpp>

示例代码

#include <boost/preprocessor/arithmetic/dec.hpp>
#include <boost/preprocessor/list/transform.hpp>

#define LIST (1, (3, (2, (5, BOOST_PP_NIL))))

#define OP(d, data, elem) BOOST_PP_DEC(elem)

BOOST_PP_LIST_TRANSFORM(OP, 3, LIST)
   // expands to (0, (2, (1, (4, BOOST_PP_NIL))))
