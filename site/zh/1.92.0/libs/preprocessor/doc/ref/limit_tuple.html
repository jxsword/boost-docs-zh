BOOST_PP_LIMIT_TUPLE 宏定义库所支持的最大 元组/数组 大小.

用法

BOOST_PP_LIMIT_TUPLE

备注

该宏默认展开为 64. 对于符合 C++ 标准的预处理器, 最终用户可以在包含任何库头文件之前把该宏定义为 128 或 256 来修改这一值. 如果最终用户修改了该宏的值, BOOST_PP_LIMIT_VARIADIC 宏也会被改为相同的值, 除非最终用户已把 BOOST_PP_LIMIT_VARIADIC 改为更高的值.

要求

头文件: <boost/preprocessor/config/limits.hpp>
