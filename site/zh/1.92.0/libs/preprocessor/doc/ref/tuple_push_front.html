BOOST_PP_TUPLE_PUSH_FRONT 宏把一个元素追加到 元组 的开头.

用法

BOOST_PP_TUPLE_PUSH_FRONT(tuple, elem) (v)

实参

tuple
要向其中追加元素的 元组.
elem
要追加的元素.

要求

头文件: <boost/preprocessor/tuple/push_front.hpp>

示例代码

#include <boost/preprocessor/tuple/push_front.hpp>

#define TUPLE (b, c, d)

BOOST_PP_TUPLE_PUSH_FRONT(TUPLE, a) // expands to (a, b, c, d)
