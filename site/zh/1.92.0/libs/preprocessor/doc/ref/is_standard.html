BOOST_PP_IS_STANDARD 宏指定编译器的预处理器是否符合标准.

用法

BOOST_PP_IS_STANDARD()
备注
该宏是一个不带形参的 函数式 宏. 它用于检查编译器的预处理器是否符合标准. 对最终用户的一个用途是查看 各种限制 是否可以调整, 因为只有对符合标准的预处理器, 调整才会生效. 若编译器的预处理器符合标准, 该宏展开为 1, 否则展开为 0.
要求
头文件: <boost/preprocessor/config/config.hpp>

示例代码

// Beginning of source file

#include <boost/preprocessor/config/config.hpp>

#if BOOST_PP_IS_STANDARD()
#define BOOST_PP_LIMIT_MAG 512
#endif

#include <boost/preprocessor/arithmetic.hpp> // etc.
