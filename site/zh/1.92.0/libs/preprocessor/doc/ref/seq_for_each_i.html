BOOST_PP_SEQ_FOR_EACH_I 宏针对一个 seq 中的每个元素重复调用一个宏.

用法

BOOST_PP_SEQ_FOR_EACH_I(macro, data, seq)

实参

宏
形如 macro(r, data, i, elem) 的宏. BOOST_PP_SEQ_FOR_EACH_I 会以 seq 中的每个元素展开该宏, 传给它下一个可用的 BOOST_PP_FOR 重复次数、辅助数据 data、当前元素的索引以及当前元素.
data
传递给 macro 的辅助数据.
seq
要对其每个元素调用 macro 的 seq.

备注

该宏是一个重复构造. 若 seq 为 (a)(b)(c), 它会展开为如下序列:
macro(r, data, 0, a) macro(r, data, 1, b) macro(r, data, 2, c)
为获得最高效率, 请使用 BOOST_PP_SEQ_FOR_EACH_I_R

参见

  • BOOST_PP_SEQ_FOR_EACH_I_R

要求

头文件: <boost/preprocessor/seq/for_each_i.hpp>

示例代码

#include <boost/preprocessor/cat.hpp>
#include <boost/preprocessor/seq/for_each_i.hpp>

#define SEQ (a)(b)(c)(d)

#define MACRO(r, data, i, elem) BOOST_PP_CAT(elem, BOOST_PP_CAT(data, i))

BOOST_PP_SEQ_FOR_EACH_I(MACRO, _, SEQ) // expands to a_0 b_1 c_2 d_3
