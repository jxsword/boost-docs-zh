BOOST_PP_REPEAT 宏表示一个快速的水平重复构造.

用法

BOOST_PP_REPEAT(count, macro, data)

实参

count
对 macro 重复调用的次数. 有效取值范围从 0 到 BOOST_PP_LIMIT_REPEAT.
宏
形如 macro(z, n, data) 的三元运算. BOOST_PP_REPEAT 会以下一个可用的重复深度、当前重复编号以及辅助实参 data 来展开该宏.
data
传递给 macro 的辅助数据.

备注

该宏展开为如下序列:
macro(z, 0, data) macro(z, 1, data) ... macro(z, count - 1, data)
传递给 macro 的 z 值表示下一个可用的重复维度. 其他带有 _Z 后缀变体的宏内部都使用 BOOST_PP_REPEAT——例如 BOOST_PP_ENUM_PARAMS 和 BOOST_PP_ENUM_PARAMS_Z. 严格来说并不必须使用这些 _Z 版本, 但把传给 macro 的 z 值传给这些宏, 可以让它们以最高效率重入 BOOST_PP_REPEAT.
若要直接使用这个 z 值而不是简单地把它传给另一个宏, 请参见 BOOST_PP_REPEAT_z.
以前, 该宏不能在 BOOST_PP_REPEAT 内部递归使用. 这一限制已不复存在, 因为库能够自动检测下一个可用的重复深度.

参见

  • BOOST_PP_LIMIT_REPEAT
  • BOOST_PP_REPEAT_z

要求

头文件: <boost/preprocessor/repetition/repeat.hpp>

示例代码

#include <boost/preprocessor/repetition/repeat.hpp>

#define DECL(z, n, text) text ## n = n;

BOOST_PP_REPEAT(5, DECL, int x)
