BOOST_PP_ADD_D 宏展开为其第二个和第三个实参之和. 它以最高效率重入 BOOST_PP_WHILE.

用法

BOOST_PP_ADD_D(d, x, y)

实参

d
下一个可用的 BOOST_PP_WHILE 迭代.
x
运算的第一个加数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
运算的第二个加数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 与 y 之和大于 BOOST_PP_LIMIT_MAG, 结果将被饱和到 BOOST_PP_LIMIT_MAG.
当 x 大于等于 y 时, 该宏效率最高. 不过, 为此在调用前实际去比较两个实参并不值得. 换言之, x 应当是最有可能为两操作数中较大者的那个加数.

参见

  • BOOST_PP_ADD
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/arithmetic/add.hpp>

示例代码

#include <boost/preprocessor/arithmetic/add.hpp>
#include <boost/preprocessor/arithmetic/dec.hpp>
#include <boost/preprocessor/control/while.hpp>
#include <boost/preprocessor/tuple/elem.hpp>

#define PRED(d, data) BOOST_PP_TUPLE_ELEM(2, 0, data)

#define OP(d, data) \
   ( \
      BOOST_PP_DEC( \
         BOOST_PP_TUPLE_ELEM(2, 0, data) \
      ), \
      BOOST_PP_ADD_D( \
         d, \
         BOOST_PP_TUPLE_ELEM(2, 1, data), \
         2 \
      ) \
   ) \
   /**/

// increment 'x' by 2 'n' times
#define STRIDE(x, n) BOOST_PP_TUPLE_ELEM(2, 1, BOOST_PP_WHILE(PRED, OP, (n, x)))

STRIDE(10, 2) // expands to 14
STRIDE(51, 6) // expands to 63
