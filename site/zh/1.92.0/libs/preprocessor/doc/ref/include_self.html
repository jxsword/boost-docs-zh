BOOST_PP_INCLUDE_SELF 宏间接地包含一个文件.

用法

#include BOOST_PP_INCLUDE_SELF()

实参

filename
要由 BOOST_PP_INCLUDE_SELF 包含的带引号或尖括号的文件名.

备注

在使用该宏之前必须先定义 BOOST_PP_INDIRECT_SELF.
大多数预处理器不允许一个文件直接包含自身——即使该文件对这种情形做了自我保护. 该宏与 BOOST_PP_INDIRECT_SELF 配合, 允许一个文件间接地包含自身.
在 BOOST_PP_INDIRECT_SELF 被包含期间, BOOST_PP_INCLUDE_SELF 会把宏 BOOST_PP_IS_SELFISH 定义为 1. 当从该包含返回时, BOOST_PP_IS_SELFISH 会被取消定义.

参见

  • BOOST_PP_INDIRECT_SELF
  • BOOST_PP_IS_SELFISH

要求

头文件: <boost/preprocessor/iteration/self.hpp>

示例代码

// file.h
#if !BOOST_PP_IS_SELFISH

   #ifndef FILE_H_
   #define FILE_H_

   #include <boost/preprocessor/iteration/self.hpp>

   #define NAME X
   struct NAME {
      // ...
      #define BOOST_PP_INDIRECT_SELF "file.h"
      #include BOOST_PP_INCLUDE_SELF()
   };

   #define NAME Y
   struct NAME {
      // ...
      #define BOOST_PP_INDIRECT_SELF "file.h"
      #include BOOST_PP_INCLUDE_SELF()
   };

   #define NAME Z
   struct NAME {
      // ...
      #define BOOST_PP_INDIRECT_SELF "file.h"
      #include BOOST_PP_INCLUDE_SELF()
   };

   #endif

#else

      inline bool validate(NAME* p) {
         return true;
      }

      template<class T> bool validate(T* p) {
         return dynamic_cast<NAME*>(p);
      }

   #undef NAME

#endif
