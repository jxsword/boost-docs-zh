BOOST_PP_SEQ_FOR_EACH 宏针对一个 seq 中的每个元素重复调用一个宏.

用法

BOOST_PP_SEQ_FOR_EACH(macro, data, seq)

实参

宏
形如 macro(r, data, elem) 的三元宏. BOOST_PP_SEQ_FOR_EACH 会以 seq 中的每个元素展开该宏, 传给它下一个可用的 BOOST_PP_FOR 重复次数、辅助数据 data 以及当前元素.
data
传递给 macro 的辅助数据.
seq
要对其每个元素调用 macro 的 seq.

备注

该宏是一个重复构造. 若 seq 为 (a)(b)(c), 它会展开为如下序列:
macro(r, data, a) macro(r, data, b) macro(r, data, c)
为获得最高效率, 请使用 BOOST_PP_SEQ_FOR_EACH_R.

参见

  • BOOST_PP_SEQ_FOR_EACH_R

要求

头文件: <boost/preprocessor/seq/for_each.hpp>

示例代码

#include <boost/preprocessor/cat.hpp>
#include <boost/preprocessor/seq/for_each.hpp>

#define SEQ (w)(x)(y)(z)

#define MACRO(r, data, elem) BOOST_PP_CAT(elem, data)

BOOST_PP_SEQ_FOR_EACH(MACRO, _, SEQ) // expands to w_ x_ y_ z_
