BOOST_PP_GREATER 宏比较两个值的大小 (是否前者更大).

用法

BOOST_PP_GREATER(x, y)

实参

x
比较的左操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
比较的右操作数. 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.

备注

若 x 大于 y, 该宏展开为 1; 否则展开为 0.
以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_GREATER_D 效率更高.

参见

  • BOOST_PP_GREATER_D
  • BOOST_PP_LIMIT_MAG

要求

头文件: <boost/preprocessor/comparison/greater.hpp>

示例代码

#include <boost/preprocessor/comparison/greater.hpp>

BOOST_PP_GREATER(4, 3) // expands to 1
BOOST_PP_GREATER(5, 5) // expands to 0
