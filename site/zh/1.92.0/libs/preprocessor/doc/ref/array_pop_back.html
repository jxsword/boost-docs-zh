BOOST_PP_ARRAY_POP_BACK 宏从 数组 末尾弹出一个元素.

用法

BOOST_PP_ARRAY_POP_BACK(array)

实参

array
要从中弹出元素的 数组.

备注

该宏在移除最后一个元素后返回 array. 若 array 没有元素, 应用该宏的结果未定义.
该宏内部使用 BOOST_PP_REPEAT. 因此, 若要使用由 z 形参从其他使用 BOOST_PP_REPEAT 的宏传递而来的状态, 请参见 BOOST_PP_ARRAY_POP_BACK_Z

参见

  • BOOST_PP_ARRAY_POP_BACK_Z

要求

头文件: <boost/preprocessor/array/pop_back.hpp>

示例代码

#include <boost/preprocessor/array/pop_back.hpp>

#define ARRAY (3, (a, b, c))

BOOST_PP_ARRAY_POP_BACK(ARRAY) // expands to (2, (a, b))
