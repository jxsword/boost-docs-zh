BOOST_PP_MOD 宏展开为其各实参取模的结果.

用法

BOOST_PP_MOD(x, y)

实参

x
运算的被除数 (分子). 有效取值范围从 0 到 BOOST_PP_LIMIT_MAG.
y
运算的除数 (分母). 有效取值范围从 1 到 BOOST_PP_LIMIT_MAG.

备注

以前, 该宏不能在 BOOST_PP_WHILE 内部使用. 现在已经没有这种限制了. 不过在这种情况下, 使用 BOOST_PP_MOD_D 效率更高.
若 y 为 0, 结果未定义.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_MOD_D

要求

头文件: <boost/preprocessor/arithmetic/mod.hpp>

示例代码

#include <boost/preprocessor/arithmetic/mod.hpp>

BOOST_PP_MOD(11, 5) // expands to 1
