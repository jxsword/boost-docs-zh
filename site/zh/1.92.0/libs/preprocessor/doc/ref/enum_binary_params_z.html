BOOST_PP_ENUM_BINARY_PARAMS_Z 宏生成一个以逗号分隔的二元形参列表. 它以最高效率重入 BOOST_PP_REPEAT.

用法

BOOST_PP_ENUM_BINARY_PARAMS_Z(z, count, p1, p2)

实参

z
下一个可用的 BOOST_PP_REPEAT 维度.
count
要生成的形参个数. 有效取值范围从 0 到 BOOST_PP_LIMIT_REPEAT.
p1
形参第一部分的文本. BOOST_PP_ENUM_BINARY_PARAMS 通过拼接从 0 到 count - 1 的数字来生成形参.
p2
形参第一部分的文本. BOOST_PP_ENUM_BINARY_PARAMS 通过拼接从 0 到 count - 1 的数字来生成形参.

备注

该宏展开为如下以逗号分隔的序列:
p1 ## 0 p2 ## 0, p1 ## 1 p2 ## 1, ... p1 ## count - 1 p2 ## count - 1
该宏是 BOOST_PP_ENUM_PARAMS_WITH_A_DEFAULT 和 BOOST_PP_ENUM_PARAMS_WITH_DEFAULTS 两者的替代品.

参见

  • BOOST_PP_ENUM_BINARY_PARAMS
  • BOOST_PP_ENUM_PARAMS_WITH_A_DEFAULT
  • BOOST_PP_ENUM_PARAMS_WITH_DEFAULTS
  • BOOST_PP_LIMIT_REPEAT

要求

头文件: <boost/preprocessor/repetition/enum_binary_params.hpp>

示例代码

#include <boost/preprocessor/arithmetic/inc.hpp>
#include <boost/preprocessor/repetition/enum_binary_params.hpp>
#include <boost/preprocessor/repetition/enum_params.hpp>

#define FUNCTION(z, n, _) \
   template<BOOST_PP_ENUM_PARAMS_Z(z, BOOST_PP_INC(n), class T)> \
   void f(BOOST_PP_ENUM_BINARY_PARAMS_Z(z, BOOST_PP_INC(n), T, p)) { \
      /* ... */ \
   } \
   /**/

BOOST_PP_REPEAT(2, FUNCTION, nil)
/*
   expands to...

   template<class T0> void f(T0 p0) { }
   template<class T0, class T1> void f(T0 p0, T1 p1) { }
*/
