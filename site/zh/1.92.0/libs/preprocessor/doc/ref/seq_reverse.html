BOOST_PP_SEQ_REVERSE 宏反转一个 seq.

用法

BOOST_PP_SEQ_REVERSE(seq)

实参

seq
要反转的 seq.

备注

为获得最高效率, 请使用 BOOST_PP_SEQ_REVERSE_S.

参见

  • BOOST_PP_SEQ_REVERSE_S

要求

头文件: <boost/preprocessor/seq/reverse.hpp>

示例代码

#include <boost/preprocessor/seq/reverse.hpp>

#define SEQ (1)(2)(3)

BOOST_PP_SEQ_REVERSE(SEQ) // expands to (3)(2)(1)
