BOOST_PP_TUPLE_REM_CTOR 宏移除一个 元组 的圆括号.

用法

BOOST_PP_TUPLE_REM_CTOR(tuple) (v)

或

BOOST_PP_TUPLE_REM_CTOR(size, tuple) (v)

实参

size
要移除其圆括号的 元组 的大小. 该实参会被忽略.
tuple
要移除其圆括号的 元组.

备注

你可以把该变参宏 (v) 调用为 BOOST_PP_TUPLE_REM_CTOR(tuple) 或 BOOST_PP_TUPLE_REM_CTOR(size,tuple) 以保持向后兼容.

参见

  • BOOST_PP_LIMIT_TUPLE

要求

头文件: <boost/preprocessor/tuple/rem.hpp>

示例代码

#include <boost/preprocessor/tuple/rem.hpp>

BOOST_PP_TUPLE_REM_CTOR((x, y, z)) // expands to x, y, z
