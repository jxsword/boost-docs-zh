BOOST_PP_SEQ_FOLD_RIGHT_s 宏从右到左折叠 (或累积) 一个 seq 的各元素. 它以最高效率重入 BOOST_PP_SEQ_FOLD_RIGHT.

用法

BOOST_PP_SEQ_FOLD_RIGHT_ ## s(op, state, seq)

实参

s
下一个可用的 BOOST_PP_SEQ_FOLD_LEFT 折叠步骤.
op
形如 op(s, state, elem) 的三元运算. seq 中的每个元素都会调用该宏——每次返回一个新的 state. BOOST_PP_SEQ_FOLD_RIGHT 会以下一个可用的折叠步骤、当前 state 和当前元素来展开该运算.
state
折叠的初始状态.
seq
要折叠的 seq.

备注

对于 seq (0)(1)(2), 该宏展开为:
op(s, op(s, op(s, state, 2), 1), 0)

参见

  • BOOST_PP_SEQ_FOLD_RIGHT

要求

头文件: <boost/preprocessor/seq/fold_right.hpp>

示例代码

#include <boost/preprocessor/cat.hpp>
#include <boost/preprocessor/seq/fold_left.hpp>
#include <boost/preprocessor/seq/fold_right.hpp>
#include <boost/preprocessor/seq/seq.hpp>

#define S1 (a)(b)(c)
#define S2 (S1)(S1)(S1)

#define OP(s, state, x) state (BOOST_PP_SEQ_FOLD_RIGHT_ ## s(OP_2, _, x))
#define OP_2(s, state, x) BOOST_PP_CAT(state, x)

BOOST_PP_SEQ_FOLD_LEFT(OP, BOOST_PP_SEQ_NIL, S2)
// expands to (_cba)(_cba)(_cba)
