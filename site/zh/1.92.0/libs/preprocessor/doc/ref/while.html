BOOST_PP_WHILE 宏表示一个循环构造.

用法

BOOST_PP_WHILE(pred, op, state)

实参

pred
形式为 pred(d, state) 的二元谓词. 该谓词由 BOOST_PP_WHILE 以下一个可用迭代 d 和当前 state 展开而得. 该谓词必须展开为 0 到 BOOST_PP_LIMIT_MAG 范围内的值. 该构造持续循环, 直到该谓词返回 0. 当该谓词返回 0, BOOST_PP_WHILE 返回当前 state.
op
形式为 op(d, state) 的二元操作. 该操作由 BOOST_PP_WHILE 以下一个可用迭代 d 和当前 state 展开而得. 该宏被反复应用于 state, 每次产生一个新的 state, 直到 pred 返回 0.
state
初始状态. 该实参通常是一个 元组.

备注

该宏迭代 op(d, state), 只要 pred(d, state) 非零. 换言之, 其展开为:
op(d, ... op(d, op(d, state)) ... ).
d 值 (它同时传递给 pred 和 op) 表示下一个可用迭代. 带有 _D 后缀变体的其他宏在内部使用 BOOST_PP_WHILE——例如 BOOST_PP_ADD 和 BOOST_PP_ADD_D. 使用这些 _D 版本并非严格必要, 但把 d 值 (即传递给 pred 或 op 的那个值) 传给这些宏, 可使它们以最高效率重入 BOOST_PP_WHILE.
要直接使用这个 d 值 (而非简单地把它传给另一个宏), 见 BOOST_PP_WHILE_d.
以前, 该宏不能在 BOOST_PP_WHILE 内部递归使用. 这一限制已不复存在, 因为库现在可以自动检测下一个可用迭代.

参见

  • BOOST_PP_LIMIT_MAG
  • BOOST_PP_WHILE_d

要求

头文件: <boost/preprocessor/control/while.hpp>

示例代码

#include <boost/preprocessor/arithmetic/add.hpp>
#include <boost/preprocessor/control/while.hpp>
#include <boost/preprocessor/tuple/elem.hpp>

#define PRED(n, state) BOOST_PP_TUPLE_ELEM(2, 1, state)

#define OP(d, state) \
   OP_D( \
      d, \
      BOOST_PP_TUPLE_ELEM(2, 0, state), \
      BOOST_PP_TUPLE_ELEM(2, 1, state) \
   ) \
   /**/

#define OP_D(d, res, c) \
   ( \
      BOOST_PP_ADD_D( \
         d, \
         res, \
         BOOST_PP_DEC(c) \
      ), \
      BOOST_PP_DEC(c) \
   ) \
   /**/

#define SUMMATION(n) \
   BOOST_PP_TUPLE_ELEM( \
      2, 0, \
      BOOST_PP_WHILE(PRED, OP, (n, n)) \
   ) \
   /**/

SUMMATION(3) // expands to 6
SUMMATION(4) // expands to 10
