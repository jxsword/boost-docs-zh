std::error_code

类型 std::error_code 被设计得足够小且平凡, 可以廉价传递, 同时又能存储足够的信息, 无冲突地表示世界上任何库/子系统的任何错误情形. 其表示基本上是:

class error_code
{
  error_category* domain; // domain from which the error originates
  int             value;  // numeric value of error within the domain
};

这里, domain 指示错误源自哪个库. 它是一个指向代表给定库/域的全局对象的指针. 不同的库由指向不同全局对象的不同指针表示. 每个域预期由一个派生自 std::error_category 的全局对象表示. 域指针值的唯一性由不同全局对象地址的唯一性保证.

而 value 表示域内特定错误情形的数值. 因此, 不同域可以使用相同数值 1 表示不同错误情形, 但两个 std::error_code 对象仍会不同, 因为表示域的指针不同.

std::error_code 附带额外工具: 一个用于定义带其错误码集合的自定义域的设施, 以及一个用于构建可对错误分类的谓词的设施.

一旦创建并传递 (无论是在抛出的异常内, 还是按值从函数返回), 在任何层级都永远无需更改 error_code 对象的值. 但在不同层级, 可以使用不同的谓词来按程序层恰当地分类错误情形.

当新库需要在 error_code 中表示它自己的错误情形集合时, 它首先必须把数值清单声明为枚举:

enum class ConvertErrc
{
  StringTooLong = 1, // 0 should not represent an error
  EmptyString   = 2,
  IllegalChar   = 3,
};

然后, 它必须放入一些样板代码, 把新枚举接入 std::error_code 系统. 之后, 它就可以把该枚举用作 error_code:

std::error_code ec = ConvertErrc::EmptyString;
assert(ec == ConvertErrc::EmptyString);

成员 value 直接从枚举中的数值映射而来, 成员 domain 从枚举的类型映射而来. 因此这是一种类型擦除, 但它仍允许类型 std::error_code 保持平凡且标准布局.
