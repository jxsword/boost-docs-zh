    3. BOOST_OUTCOME_CO_TRY(var, expr)

      在协程内对一个结果为可理解类型的表达式求值, 成功时把 T 赋给名为 var 的声明, 失败时立即从调用函数返回 try_operation_return_as(X).

  2. Concepts
    1. basic_outcome<T>

      一个布尔 concept, 匹配可转换为 basic_outcome<T, EC, EP, NoValuePolicy> 的类型.

    2. basic_result<T>

      一个布尔 concept, 匹配可转换为 basic_result<T, E, NoValuePolicy> 的类型.

    3. value_or_error<T>

      一个布尔 concept, 匹配具有值或错误的类型.

    4. value_or_none<T>

      一个布尔 concept, 匹配具有可选值的类型.

  3. 转换器
    1. value_or_error<T, U>

      一个可定制的 value_or_error<T, E> concept 匹配类型转换器.

  4. 特征
    1. is_basic_outcome<T>

      对 basic_outcome<T, EC, EP, NoValuePolicy> 类型为真的整型常量类型.

    2. is_basic_result<T>

      对 basic_result<T, E, NoValuePolicy> 类型为真的整型常量类型.

    3. is_error_code_available<T>

      若错误码可以从 T 构造则为真.

    4. is_error_type<E>

      一个可定制的整型常量类型, 对将接受抛错误无值策略的 E 类型为真.

    5. is_error_type_enum<E, Enum>

      一个可定制的整型常量类型, 对 E 类型 (可从 Enum 类型构造) 为真, 这些类型将接受抛错误无值策略.

    6. is_exception_ptr_available<T>

      若 exception ptr 可以从 T 构造则为真.

    7. is_failure_type<T>

      对 failure_type<EC, E = void> 类型为真的整型常量布尔变量.

    8. is_move_bitcopying<T>

      (>= Outcome v2.2.0) 一个可定制的整型常量类型, 对移动位拷贝安全的 T 类型为真.

    9. is_success_type<T>

      对 success_type<T> 类型为真的整型常量布尔变量.

    10. type_can_be_used_in_basic_result<R>

      对可在 basic_result<T, E, NoValuePolicy> 中使用的类型为真的 constexpr 布尔值.

  5. 策略
    1. base

      大多数定义窄观察器策略的策略类的基类.

    2. all_narrow

      规定在不正确的窄与宽值、错误或异常观察时发生硬性未定义行为的策略类. 公开继承自 base.

    3. error_code_throw_as_system_error<T, EC, EP>

      规定在不正确的宽值观察时应尽可能重抛 EP, 然后调用经 ADL 发现的自由函数 outcome_throw_as_system_error_with_payload() 的策略类. 公开继承自 base. 只能与 basic_outcome 一起使用.

    4. error_code_throw_as_system_error<T, EC, void>

      规定在不正确的宽值观察时应调用经 ADL 发现的自由函数 outcome_throw_as_system_error_with_payload() 的策略类. 公开继承自 base. 只能与 basic_result 一起使用.

    5. exception_ptr_rethrow<T, EC, EP>

      规定在不正确的宽值观察时应调用经 ADL 发现的自由函数 rethrow_exception() 的策略类. 公开继承自 base. 只能与 basic_outcome 一起使用.

    6. exception_ptr_rethrow<T, EC, void>

      规定在不正确的宽值观察时应调用经 ADL 发现的自由函数 rethrow_exception() 的策略类. 公开继承自 base. 只能与 basic_result 一起使用.

    7. fail_to_compile_observers

      规定在编译宽值、错误或异常观察时应触发静态断言的策略类. 公开继承自 base.

    8. terminate

      规定在不正确的宽值、错误或异常观察时应调用 std::terminate() 的策略类. 公开继承自 base.

    9. throw_bad_result_access<EC>

      规定在不正确的宽值观察时应抛出 bad_result_access_with<EC> 的策略类. 公开继承自 base.

  6. 类型
    1. basic_outcome<T, EC, EP, NoValuePolicy>

      一种类型, 携带以下之一: (i) 成功的 T (ii) 失望 EC (iii) 失败 EP (iv) 失望 EC 与失败 EP 并存; NoValuePolicy 规定在试图读取不存在的状态时该怎么办.

    2. basic_result<T, E, NoValuePolicy>

      一种和类型, 携带成功的 T 或失望 E 之一; NoValuePolicy 规定在试图读取不存在的状态时该怎么办.

    3. bad_outcome_access

      公开继承自 std::logic_error 的异常类型, 表明发生了不正确的值、错误或异常观察.

    4. bad_result_access_with<EC>

      公开继承自 bad_result_access 的异常类型, 表明发生了不正确的值观察, 并提供错误值.

    5. bad_result_access

      公开继承自 std::logic_error 的异常类型, 表明发生了不正确的值或错误观察.

    6. eager<T, Executor = void>/atomic_eager<T, Executor = void>

      带有 Outcome 定制的急切求值协程 awaitable.

    7. failure_type<EC, EP = void>

      用于构造不成功 result 或 outcome 的类型糖.

    8. generator<T, Executor = void>

      带有 Outcome 定制的惰性求值协程生成器.

    9. in_place_type_t<T>

      要么是 std::in_place_type_t<T>, 要么是本地模拟, 取决于 BOOST_OUTCOME_USE_STD_IN_PLACE_TYPE 宏.

    10. lazy<T, Executor = void>/atomic_lazy<T, Executor = void>

      带有 Outcome 定制的惰性求值协程 awaitable.

    11. success_type<T>

      用于构造成功 result 或 outcome 的类型糖.

  7. 别名
    1. boost_checked<T, E = boost::system::error_code>

      一个类型别名, 指向 basic_result——以 boost::system::error_code 与 policy::throw_bad_result_access<EC> 配置.

    2. boost_outcome<T, EC = boost::system::error_code, EP = boost::exception_ptr, NoValuePolicy = policy::default_policy<T, EC, EP>>

      一个类型别名, 指向 basic_outcome——以 boost::system::error_code、boost::exception_ptr 与 policy::default_policy 配置.

    3. boost_result<T, E = boost::system::error_code, NoValuePolicy = policy::default_policy<T, E, void>>

      一个类型别名, 指向 basic_result——以 boost::system::error_code 与 policy::default_policy 配置.

    4. boost_unchecked<T, E = boost::system::error_code>

      一个类型别名, 指向 basic_result——以 boost::system::error_code 与 policy::all_narrow 配置.

    5. checked<T, E = varies>

      一个类型别名, 指向 std_checked<T, E> (独立版) 或 boost_checked<T, E> (Boost 版).

    6. default_policy<T, EC, EP>

      一个类型别名, 指向基于 T、EC 与 EP 的 traits 匹配所选定的无值策略.

    7. outcome<T, EC = varies, EP = varies, NoValuePolicy = policy::default_policy<T, EC, EP>>

      一个类型别名, 指向 std_outcome<T, EC, EP, NoValuePolicy> (独立版) 或 boost_outcome<T, EC, EP, NoValuePolicy> (Boost 版).

    8. result<T, E = varies, NoValuePolicy = policy::default_policy<T, E, void>>

      一个类型别名, 指向 std_result<T, E, NoValuePolicy> (独立版) 或 boost_result<T, E, NoValuePolicy> (Boost 版).

    9. std_checked<T, E = std::error_code>

      一个类型别名, 指向 basic_result——以 std::error_code 与 policy::throw_bad_result_access<EC> 配置.

    10. std_outcome<T, EC = std::error_code, EP = std::exception_ptr, NoValuePolicy = policy::default_policy<T, EC, EP>>

      一个类型别名, 指向 basic_outcome——以 std::error_code、std::exception_ptr 与 policy::default_policy 配置.

    11. std_result<T, E = std::error_code, NoValuePolicy = policy::default_policy<T, E, void>>

      一个类型别名, 指向 basic_result——以 std::error_code 与 policy::default_policy 配置.

    12. std_unchecked<T, E = std::error_code>

      一个类型别名, 指向 basic_result——以 std::error_code 与 policy::all_narrow 配置.

    13. unchecked<T, E = varies>

      一个类型别名, 指向 std_unchecked<T, E> (独立版) 或 boost_unchecked<T, E> (Boost 版).

  8. 函数
    1. 钩子

      用于挂接 basic_result 与 basic_outcome 功能的函数.

    2. Iostream

      用于打印、序列化与反序列化 basic_result 与 basic_outcome 的函数.

    3. 策略

      用于定制策略类如何运作的函数.

    4. auto failure(T &&, ...)

      返回用于构造不成功 result 或 outcome 的恰当类型糖.

    5. auto success(T &&, ...)

      返回用于构造成功 result 或 outcome 的恰当类型糖.

    6. bool try_operation_has_value(X)

      try_operation_has_value(X) ADL 定制点针对 BOOST_OUTCOME_TRY 的默认实现.

    7. decltype(auto) try_operation_extract_value(X)

      try_operation_extract_value(X) ADL 定制点针对 BOOST_OUTCOME_TRY 的默认实现.

    8. decltype(auto) try_operation_return_as(X)

      try_operation_return_as(X) ADL 定制点针对 BOOST_OUTCOME_TRY 的默认实现.

    9. std::error_code error_from_exception(std::exception_ptr &&ep = std::current_exception(), std::error_code not_matched = std::make_error_code(std::errc::resource_unavailable_try_again)) noexcept

      返回与被抛标准库异常相匹配的错误码.

    10. void strong_swap(bool &all_good, T &a, T &b)

      尝试执行一次强保证 swap.

    11. void try_throw_std_exception_from_error(std::error_code ec, const std::string &msg = std::string{})

      尝试抛出与错误码匹配的标准库异常类型.
