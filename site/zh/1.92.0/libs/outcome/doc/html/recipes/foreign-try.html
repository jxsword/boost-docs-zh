扩展 BOOST_OUTCOME_TRY

Outcome 的 BOOST_OUTCOME_TRY(var, expr) 操作完全可扩展, 可接受任何陌生类型作为输入. 它已经能识别匹配 concepts::value_or_error<T, E> 概念的类型, 即所有具有以下特征的类型:

  • 一个公有 .has_value() 成员函数, 返回 bool.
  • 按优先顺序, 一个公有 .assume_value()/.value() 成员函数.
  • 按优先顺序, 一个公有 .as_failure()/.assume_error()/.error() 成员函数.

这应当能自动处理 std::expected<T, E> 及许多其他类型的输入, 包括在同一翻译单元中混用 Boost.Outcome 与独立版 Outcome.

BOOST_OUTCOME_TRY 具有以下自由函数定制点:

BOOST_OUTCOME_V2_NAMESPACE::try_operation_has_value(X)
返回一个 `bool`, 若 TRY 的输入有值则为 true.
BOOST_OUTCOME_V2_NAMESPACE::try_operation_return_as(X)
返回一个合适的 failure_type<EC, EP = void>, 它被立即返回以引发栈回退. 应当保持右值语义 (即若传入右值, 则把错误状态移动进失败类型).
BOOST_OUTCOME_V2_NAMESPACE::try_operation_extract_value(X)
从输入提取值类型, 供 `TRY` 设置其变量. 应当保持右值语义 (即若传入右值, 则移动该值).

为支持额外输入类型而对这些函数新增的重载, 必须注入 BOOST_OUTCOME_V2_NAMESPACE 命名空间——且要在编译器解析相关 BOOST_OUTCOME_TRY 之前——才能被找到. 这在 C++ 两阶段名字查找模型中称为 “早期绑定”. 之所以选择它而非 “晚期绑定”——即模板化代码中的 BOOST_OUTCOME_TRY 可以查找在解析包含 BOOST_OUTCOME_TRY 的模板之后才引入的重载——是因为它对构建时间的影响低得多: 绑定在解析点只做一次, 而不是在实例化点每次都做. 只要你注意在翻译单元解析早期注入所需的重载, 一切都会顺利.

让我们来走一个应用实例.

一个非常陌生的伪 Expected 类型

这是对一个编写拙劣的伪 Expected 类型的转述, 我曾在某大型跨国公司的生产代码库中遇到过它. 大量代码已在用它, 而且它怪异到难以轻松换掉.

enum Errc
{
  kBadValue
};
template <class T, class E = Errc> struct ForeignExpected
{
  T Value;
  E Error;
  int IsErrored;

  ForeignExpected(T v)
      : Value(v)
      , Error()
      , IsErrored(0)
  {
  }
  ForeignExpected(E e)
      : Value()
      , Error(e)
      , IsErrored(1)
  {
  }
};

我们希望新代码用 Outcome 编写, 同时能够透明地调用旧代码, 像这样:

ForeignExpected<int> old_code(int a)  // old code
{
  if(0 == a)
    return kBadValue;
  return a;
}

outcome::result<int> new_code(int a)  // new code
{
  BOOST_OUTCOME_TRY(auto x, old_code(a));
  return x;
}

把这个怪异的陌生 Expected 告知 Outcome 非常直接:

BOOST_OUTCOME_V2_NAMESPACE_BEGIN
template <class T, class E>  //
inline bool try_operation_has_value(const ForeignExpected<T, E> &v)
{
  return 0 == v.IsErrored;
}
template <class T, class E>  //
inline auto try_operation_return_as(const ForeignExpected<T, E> &v)
{
  switch(v.Error)
  {
  case kBadValue:
    return failure(make_error_code(std::errc::argument_out_of_domain));
  }
  abort();
}
template <class T, class E>  //
inline auto try_operation_extract_value(const ForeignExpected<T, E> &v)
{
  return v.Value;
}
BOOST_OUTCOME_V2_NAMESPACE_END
