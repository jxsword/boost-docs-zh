Tutorial

  1. 基础

    要立即上手 Outcome 所需的绝对最基本知识.

    1. 开始之前

      开始教程之前需了解的基本信息.

    2. result<>

      使用简单成功或失败返回类型编写代码的温和入门.

    3. outcome<>

      失败可取两种形式的成功或失败返回类型: 预期/已处理失败与意外/中止失败.

    4. 无值策略

      描述 NoValuePolicy 的概念以及如何使用无值策略.

    5. 协程

      在 C++ 协程中使用 Outcome

    6. 约定

      为什么你应当在公共 API 中避免自定义 E 类型.

  2. 进阶

    如果你有更多时间, 本节涵盖针对各种使用场景定制与自动化 Outcome 的所有省时方法, 尤其是在由多个第三方库组成的大型代码库中.

    1. 自定义负载

      除错误码之外还附带额外信息的失败的成功或失败返回类型.

    2. 返回 Result 的构造函数

      如何对使用 result 返回失败而非抛出 C++ 异常的对象构造进行元编程.

    3. 挂钩事件

      拦截初始构造、拷贝与移动等有用事件, 以便捕获回溯、触发调试断点等.

    4. 互操作

      与 std::expected 及其他匹配 ValueOrError concept 的类型互操作.
