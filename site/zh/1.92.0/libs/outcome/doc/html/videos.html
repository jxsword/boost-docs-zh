都柏林 C++ 用户组 2018 “Deterministic Disappointment”

对与确定性处理失败相关的 WG21 论文的文献综述, 以及使用 Outcome 等库实现同样目标.


Meeting C++ 2017 “Introduction to proposed std::expected<T, E>“

对与 std::expected 相关的若干 WG21 论文的文献综述.


ACCU 2017 “Mongrel Monads, Dirty, dirty, dirty”

涵盖 C++ 错误处理的历史, 以及 LEWG Expected 的工作方式.
