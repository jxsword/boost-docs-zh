C Results

C 宏 API 头文件 <boost/outcome/experimental/result.h> 提供了一些用于处理任何种类 Result 的宏:

BOOST_OUTCOME_C_DECLARE_RESULT(ident, T, E)
向 C 声明 basic_result 类型, 由 ident 唯一标识. T 可通过成员变量 .value 访问, E 可通过成员变量 .error 访问. 如果你在 C++ 内部调用它, 务必确保它不在 extern "C" 块中!
BOOST_OUTCOME_C_RESULT(ident)
对先前声明的 result 类型的引用, 该类型具有唯一的 ident.
BOOST_OUTCOME_C_RESULT_HAS_VALUE(r)
如果输入的 result 有值, 求值为 1 (true).
BOOST_OUTCOME_C_RESULT_HAS_ERROR(r)
如果输入的 result 有错误, 求值为 1 (true).
BOOST_OUTCOME_C_RESULT_ERROR_IS_ERRNO(r)
如果输入 result 的错误值是 POSIX errno 域中的错误码, 求值为 1 (true).

以上让你能以有些别扭的方式处理任何 C 兼容的 basic_result<T, E>. basic_result<T, E> 是可平凡复制且标准布局的——前提是其 T 与 E 都是如此——并且它具有如下 C 布局:

struct cxx_result_##ident
{
  union
  {
    T value;
    E error;
  };
  unsigned flags;
};

注意, 该布局与 BOOST_OUTCOME_C_DECLARE_STATUS_CODE 的布局不同, 因为 C++ 的 result 在 E 是状态码时具有不同的布局.
