实例教程: 自定义域 (长路径)

下面是一个较长的 Experimental Outcome 使用实例教程. 它展示的示例程序, 与我在 2018 年圣地亚哥 WG21 标准会议上提交的相同——当时委员会请我演示 P1095 如何在一个可供他们研究与讨论的可运行代码示例中实现 P0709.

我们将逐步走完这个实例教程, 详细解释每一部分如何工作. 这将帮助你实现自己的基于 Experimental Outcome 的代码.

大多数用户不需要这种程度的定制, 对他们而言, 前面的 快捷简易方法 要容易得多.

你可能会发现, 现在就在单独的浏览器标签页中打开提案 <system_error2> 的参考 API 文档 (位于 https://ned14.github.io/status-code/, 向下滚动一半) 会很有用. 注释中对 P1028 的引用指向 P1028 SG14 status_code and standard error object for P0709 Zero-overhead deterministic exceptions, 它是针对潜在 <system_error2> 的 WG21 提案论文.

本节的目标

我们将定义一个简单的自定义错误码域, 它规定状态码的负载将由一个 POSIX 错误码, 以及失败发生处的 __FILE__ 与 __LINE__ 组成. 这个自定义状态码将定义一个到类型擦除的 error 的隐式转换, 它为原始状态码动态分配内存, 并输出一个管理该动态分配的 error, 把所有查询等间接转发到被擦除的自定义状态码类型, 使 error 实例表现得与原始对象如出一辙. 这表明 error 同样可以传递一个 std::exception_ptr, 或者说确实可以管理任何指针的生存期.
