TRY 一个 C Result

由于 BOOST_OUTCOME_TRY(var, expr) 的大部分魔法是用 C 预处理器元编程实现的, 我们可以为 C 的 try 运算提供非常相似的体验, 而无需任何以 C++ 编译的支持函数:

result test2(int x)
{
  BOOST_OUTCOME_C_RESULT_SYSTEM_TRY(int v,                                        // what to set to value if successful
                        fprintf(stderr, "Positive numbers only!\n"),  // what cleanup to run if unsuccessful
                        positive_only(x));
  return SUCCESS(v + 1);
}
在 Github 上查看此代码

主要区别是你可以指定在遇到失败时执行的清理例程. 这在 C 中特别有用, 因为 C 没有栈回退 (stack unwinding).

此外, 由于缺乏类型糖 (type sugaring) 与用户定义的隐式转换, 如果调用方的 result 类型与被调用方不同, 你可能需要指明调用方的 result 类型, 以便错误状态能被正确传播.
