C 系统错误 result

在 v2.2.11 中, C Result 支持从二线地位升为一线地位, 现在只需包含 <boost/outcome/experimental/result.h>, 你就可以完全在 C 内部创建、查询与操作一部分 Result 类型.

所支持的子集是那些 result<T, E>——它们是 一个 status_result<T>, 即 E 被硬编码为 experimental::error, 它是任何出错 status_code (其负载不大于一个 intptr_t) 的类型擦除运行期多态持有者. 这是 Outcome Experimental 可能的 Result 类型中最有用的子集, 允许来自任何未知来源的任意自定义错误编码方案与其他所有方案无缝协作, 包括来自系统或第三方库的错误.

C 可用的操作有:

BOOST_OUTCOME_C_DECLARE_RESULT_SYSTEM(ident, T)
向 C 声明 status_result 类型, 由 ident 唯一标识. T 可通过成员变量 .value 访问, struct cxx_status_code_system 可通过成员变量 .error 访问. 在 C++ 中, 它还会实现用于创建此类型的成功与失败 result 的 C extern 函数. 如果你在 C++ 内部调用它, 务必确保它不在 extern "C" 块中!
BOOST_OUTCOME_C_RESULT_SYSTEM(ident)
对先前声明的 status_result 类型的引用, 该类型具有唯一的 ident.
BOOST_OUTCOME_C_MAKE_RESULT_SYSTEM_SUCCESS(ident, expr) (需要其 C++ 对应物链接进最终二进制)
这会调用前述 extern 函数, 创建一个 status_result, 其成功值的类型为 T.
BOOST_OUTCOME_C_MAKE_RESULT_SYSTEM_FAILURE_POSIX(ident, expr) (需要其 C++ 对应物链接进最终二进制)
这会调用前述 extern 函数, 创建一个 status_result, 其失败类型为 posix_code, 表示一个 POSIX errno.
BOOST_OUTCOME_C_MAKE_RESULT_SYSTEM_FAILURE_SYSTEM(ident, expr) (需要其 C++ 对应物链接进最终二进制)
这会调用前述 extern 函数, 在 POSIX 上创建一个 status_result, 其失败类型为 posix_code, 表示一个 POSIX errno; 在 Windows 上则创建一个失败类型为 win32_code 的失败, 表示来自 Windows API 的 Win32 错误码.

BOOST_OUTCOME_C_RESULT_HAS_VALUE(r)
如果输入的 result 有值, 求值为 1 (true).
BOOST_OUTCOME_C_RESULT_HAS_ERROR(r)
如果输入的 result 有错误, 求值为 1 (true).
BOOST_OUTCOME_C_RESULT_ERROR_IS_ERRNO(r)
如果输入 result 的错误值是 POSIX errno 域中的错误码, 求值为 1 (true).

BOOST_OUTCOME_C_RESULT_SYSTEM_TRY(expr)
如果 status_result (由 expr 返回) 出错, 则退出当前函数并返回该 result. 这显然要求当前函数的返回类型与 expr 的匹配.
BOOST_OUTCOME_C_RESULT_SYSTEM_TRY(cleanup, expr)
与上面相同, 但若返回失败, 则在退出函数前执行 cleanup.
BOOST_OUTCOME_C_RESULT_SYSTEM_TRY(var, cleanup, expr)
与上面相同, 但在成功时把 var 设为该 result 的 .value.
BOOST_OUTCOME_C_RESULT_SYSTEM_TRY(var, ident, cleanup, expr)
与上面相同, 但改用 ident 作为返回类型. 这允许调用方函数的返回类型不同于 expr 的返回类型.

BOOST_OUTCOME_C_DECLARE_RESULT_SYSTEM_FROM_ENUM(ident, enum_name, uuid, {enum mapping-sequence, ...})
这向 C 声明一个 extern 函数, 它从 C 枚举创建一个 status_result. 在 C++ 中, 它会为该 C 枚举实现一个 quick_status_code_from_enum 及相关联的 extern 函数, 而你将需要提供 uuid 以及恰当的枚举值映射序列, 按 quick_status_code_from_enum 文档的说明.
BOOST_OUTCOME_C_MAKE_RESULT_SYSTEM_FROM_ENUM(ident, enum_name, expr) (需要其 C++ 对应物链接进最终二进制)
这会调用前述 extern 函数, 从一个 C 枚举创建 status_result.

C++ 可用的操作有:

BOOST_OUTCOME_C_TO_RESULT_SYSTEM_CODE(ident, status_code<T>)
从与之匹配的 C++ status_code 返回先前声明的 C Result. 注意, 不会调用该 C++ status code 的析构函数. 如果这对你的 status code 很重要, 你必须百分之百自行确保你的 C Result 在其生存期结束时重新进入一个 C++ Result.
to_result(any C Result)
这是一个重载的 C++ 自由函数, 返回与其输入 C Result 相匹配的 C++ status_code<T>.
