使用 Result

这建模自 前面的 C++ 使用示例, 得益于我们的辅助 typedef 与宏, 其 C 等价物并没有啰嗦多少:

result positive_only(int x)
{
  if(x < 0)
  {
    return FAILURE(c_enum_bad_argument);
  }
  return SUCCESS(x);
}

bool test(int x)
{
  result r = positive_only(x);
  if(BOOST_OUTCOME_C_RESULT_HAS_ERROR(r))
  {
    if(outcome_status_code_equal_generic(&r.error, EINVAL))
    {
      fprintf(stderr, "Positive numbers only!\n");
      return false;
    }
  }
  return true;
}

为了能链接, BOOST_OUTCOME_C_DECLARE_RESULT_SYSTEM_FROM_ENUM 宏需要至少在 C++ 中被编译一次 (位于最终二进制内), 以生成 C 所需的 extern 函数.
