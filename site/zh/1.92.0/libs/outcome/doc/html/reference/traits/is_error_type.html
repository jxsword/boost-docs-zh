is_error_type<E>

一个可定制的整型常量类型, 对将接受抛错误无值策略的 E 类型为真. 当整型 T 类型与本白名单中的 E 类型组合时, 可用特殊的弱化隐式构造启用——这允许 boost_result<int, boost::system::errc::errc_t 保留其隐式构造函数, 尽管 errc_t 作为 C 枚举有到 int 的隐式转换.

可覆盖: 通过向 trait 命名空间进行模板特化.

默认: 假. 存在为真的特化, 针对:

  • <boost/outcome/boost_result.hpp>

    • boost::system::error_code
    • boost::system::errc::errc_t
    • boost::exception_ptr

  • <boost/outcome/std_result.hpp>

    • std::error_code
    • std::errc
    • std::exception_ptr
