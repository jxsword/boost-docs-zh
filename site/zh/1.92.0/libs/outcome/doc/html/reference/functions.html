    5. void outcome_throw_as_system_error_with_payload(ErrorCodeEnum &&)

      outcome_throw_as_system_error_with_payload() 的特化, 用于 std::is_error_code_enum<ErrorCodeEnum> 或 std::is_error_condition_enum<ErrorCodeEnum> 为真的输入类型.
