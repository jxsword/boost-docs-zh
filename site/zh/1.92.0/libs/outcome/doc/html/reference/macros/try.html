BOOST_OUTCOME_TRY(var, expr)

对一个结果类型匹配以下定制点的表达式求值, 成功时把 T 赋给名为 var 的声明, 失败时立即从调用函数返回 try_operation_return_as(X):

  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_has_value(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_return_as(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_extract_value(X)

这些定制点都有默认重载. 参见 支持给 BOOST_OUTCOME_TRY 陌生输入的配方.

会向编译器提示该表达式将成功. 如果你预期失败, 应改用 BOOST_OUTCOME_TRY_FAILURE_LIKELY(var, expr).

会创建一个保存表达式值的内部临时对象, 这通常会引发一次拷贝/移动. 如果你希望永不拷贝/移动, 可以让该宏把内部临时对象创建为引用.

可覆盖: 不可覆盖.

定义: 大部分机制参见 BOOST_OUTCOME_TRYV(expr).

成功时, var 会被初始化或赋值为表达式结果的 .assume_value() (如果可用), 否则为其 .value(). 这会把引用绑定到表达式所绑定 result 内存储的 T, 但也可能绑定到值观察器函数发出的临时对象.

头文件: <boost/outcome/try.hpp>

遗留: 在 Outcome v2.2 之前, var 总是被声明为自动右值引用. 如果你想保留旧行为, 可以使用向后兼容宏 OUTCOME21_TRY().
