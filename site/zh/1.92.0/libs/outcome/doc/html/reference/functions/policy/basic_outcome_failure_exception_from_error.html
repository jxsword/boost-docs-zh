auto basic_outcome_failure_exception_from_error(const EC &)

从错误类型合成异常类型, 由 exception_type failure() const noexcept 观察器使用. 经 ADL 发现. Outcome 为 std::error_code 与 boost::system::error_code 定义了该函数的默认重载, 分别返回 std::make_exception_ptr(std::system_error(ec)) 与 boost::copy_exception(boost::system::system_error(ec)).

可覆盖: 实参依赖查找.

要求: 无.

命名空间: EC 类型的命名空间.

头文件: <boost/outcome/std_outcome.hpp>, <boost/outcome/boost_outcome.hpp>
