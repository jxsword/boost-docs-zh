is_move_bitcopying<T>

一个可定制的整型常量类型, 对移动位拷贝安全的 T 类型为真. 按 P1029 move bitcopying, 这些是满足以下条件的类型:

  1. 存在内联的、constexpr 可用的默认构造函数.
  2. 移动构造函数的副作用等价于把源逐位 memcpy 到目标, 接着把一个默认构造实例逐位 memcpy 到源.
  3. 默认构造实例的析构没有可见副作用.

这意味着如果你从一个位拷贝类型移动, 你无需调用其析构函数, 即使那是虚析构函数.

如果你把你的类型选入该 trait, Outcome 会跟踪已移动状态, 并且不对已移动源实例调用你的类型的析构函数. 显然, 在当前 C++ 标准下这是未定义行为. 然而它非常显著地改善内联期间的代码生成质量.

可覆盖: 通过向 trait 命名空间进行模板特化.

默认: 假. 存在默认特化, 针对:

  • <boost/outcome/experimental/status_result.hpp>
    • 对 BOOST_OUTCOME_SYSTEM_ERROR2_NAMESPACE::status_code<DomainType> 为真, 如果 trait BOOST_OUTCOME_SYSTEM_ERROR2_NAMESPACE::traits::is_move_bitcopying<BOOST_OUTCOME_SYSTEM_ERROR2_NAMESPACE::status_code<DomainType>>::value 为真.
    • 对 BOOST_OUTCOME_SYSTEM_ERROR2_NAMESPACE::errored_status_code<DomainType> 为真, 如果 trait BOOST_OUTCOME_SYSTEM_ERROR2_NAMESPACE::traits::is_move_bitcopying<BOOST_OUTCOME_SYSTEM_ERROR2_NAMESPACE::errored_status_code<DomainType>>::value 为真.
