basic_outcome(const success_type<T> &)

来自成功类型糖的隐式值拷贝构造函数, 用于消歧值类型的构造. 注意, 如果 T = void, value_type 将被默认构造. 调用 void on_outcome_copy_construction(T *, U &&) noexcept, 传入 this 与 const success_type<T> &.

要求: predicate::enable_compatible_conversion<T, void, void> 为真, 或 T 为 void.

复杂度: 与 value_type 构造函数——接受 T 的那个——相同, 或与 value_type 默认构造函数相同 (当 T 为 void 时). 底层操作的 constexpr、平凡性与 noexcept 会被传播.
