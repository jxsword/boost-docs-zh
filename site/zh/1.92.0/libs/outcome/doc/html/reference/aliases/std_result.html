std_result<T, E = std::error_code, NoValuePolicy = policy::default_policy<T, E, void>>

一个类型别名, 指向 basic_result<T, E, NoValuePolicy>, 以 std::error_code 与 policy::default_policy 配置.

该类型别名总是引用 std 版的对应物, 不像 result<T, E = varies, NoValuePolicy = policy::default_policy<T, E, void>> 会引用本别名或 boost_result<T, E = boost::system::error_code, NoValuePolicy = policy::default_policy<T, E, void>>.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/std_result.hpp>
