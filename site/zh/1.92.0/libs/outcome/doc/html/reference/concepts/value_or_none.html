value_or_none<T>

在 C++ 20 或 Concepts TS 启用时, 是一个布尔 concept, 匹配具有公有 .has_value() 观察器 (返回 bool) 与公有 .value() 观察器函数的类型.

在不启用 Concepts 时, 是一个 static constexpr bool, 对满足相同要求的类型为真, 采用基于 SFINAE 的模拟.

该 concept 匹配类似 optional 的类型, 例如 std::optional<T>. 注意它也匹配 P0323 std::expected<T, E>, 后者同样具有类似 optional 的接口. 因此你可能希望优先匹配 concepts::value_or_error<T, E>——对任何给定的 T 而言.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::concepts

头文件: <boost/outcome/convert.hpp>

遗留: 在 Outcome v2.1 及更早版本中它名为 convert::ValueOrNone<T>. 把 BOOST_OUTCOME_ENABLE_LEGACY_SUPPORT_FOR 定义为小于 220 即可启用.
