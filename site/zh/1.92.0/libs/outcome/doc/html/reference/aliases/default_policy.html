default_policy<T, EC, EP>

一个类型别名, 指向基于 T、EC 与 EP 的 traits 匹配所选定的无值策略. 其定义如下:

  1. 如果 EC 与 EP 是 void, 选择 terminate.

  2. 如果 is_error_code_available<T> 对 EC 为真, 选择 error_code_throw_as_system_error<T, EC, EP> 作为 basic_outcome, 或 error_code_throw_as_system_error<T, EC, void> 作为 basic_result.

  3. 如果 is_exception_ptr_available<T> 对 EC 或 EP 为真, 选择 exception_ptr_rethrow<T, EC, EP> 作为 basic_outcome, 或 exception_ptr_rethrow<T, EC, void> 作为 basic_result.

  4. 否则选择 fail_to_compile_observers, 它会使构建失败并给出有用的消息.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::policy

头文件: <boost/outcome/std_result.hpp>
