basic_outcome<T>

在 C++ 20 或 Concepts TS 启用时, 是一个布尔 concept, 匹配具有 value_type、error_type 与 no_value_policy_type 成员 typedef 的类型; 且该类型可转换为 basic_result<value_type, error_type, no_value_policy_type>; 且 basic_result<value_type, error_type, no_value_policy_type> 是该类型的基类.

在不启用 Concepts 时, 是一个 static constexpr bool, 对满足相同要求的类型为真, 采用基于 SFINAE 的模拟.

该 concept 匹配任何这样的类型: 它提供与 basic_result<T, E, NoValuePolicy> 相同的 typedef, 以该 basic_result 为基类, 并且可隐式转换为 basic_result. 虽无保证, 该类型极有可能是一个 basic_result, 或公开继承自 basic_result. 如果你想要匹配任何值或错误类型的东西, 考虑 value_or_error<T>. 如果你想要精确匹配 basic_outcome 的东西, 使用 is_basic_outcome<T>.
