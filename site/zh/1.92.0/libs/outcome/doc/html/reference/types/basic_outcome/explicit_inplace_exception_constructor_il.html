explicit basic_outcome(in_place_type_t<exception_type_if_enabled>, std::initializer_list<U>, Args ...)

显式原位异常构造函数. 调用 void on_outcome_in_place_construction(T *, in_place_type_t<U>, Args &&...) noexcept, 传入 this、in_place_type<exception_type>、std::initializer_list<U> 与 Args ....

要求: predicate::enable_inplace_exception_constructor<std::initializer_list<U>, Args ...> 为真.

复杂度: 与 exception_type 构造函数——接受 std::initializer_list<U>, Args ... 的那个——相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.

保证: 如果操作期间抛出异常, Args 的状态将处于未确定状态.
