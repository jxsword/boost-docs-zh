bad_result_access_with<EC>

公开继承自 bad_result_access (因而也继承 std::logic_error) 的异常类型, 表明发生了不正确的值观察. 异常抛出时的错误值被移动或拷贝进该类型, 并可通过 .error() 观察器访问——它提供左值引用、const 左值引用、右值引用与 const 右值引用重载.

该异常类型的主要目的是为 P0323 std::expected<T, E> 的 bad_expected_access<E> 站台——后者在不正确的宽值观察时被抛出. 这就是为什么只有 EC 会在仅有值观察时带着 bad_result_access_with<EC> 被抛出, 且仅当有错误可用时. 更多信息参见 throw_bad_result_access<EC> 策略.

要求: 无.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/bad_access.hpp>
