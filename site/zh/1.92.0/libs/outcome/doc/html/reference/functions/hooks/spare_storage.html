uint16_t spare_storage(const basic_result|basic_outcome *) noexcept

返回指定 result 或 outcome 中的 16 位备用存储. 你可以用 void set_spare_storage(basic_result|basic_outcome *, uint16_t) noexcept 设置这些位.

可覆盖: 不可覆盖.

要求: 无.
