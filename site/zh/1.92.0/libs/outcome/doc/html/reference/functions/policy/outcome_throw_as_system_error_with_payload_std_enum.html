void outcome_throw_as_system_error_with_payload(ErrorCodeEnum &&)

outcome_throw_as_system_error_with_payload() 的特化, 用于 std::is_error_code_enum<ErrorCodeEnum> 或 std::is_error_condition_enum<ErrorCodeEnum> 为真的类型. 它执行 BOOST_OUTCOME_THROW_EXCEPTION(expr), 带有一个 std::system_error——由经 ADL 发现的自由函数 make_error_code(ErrorCodeEnum) 的结果构造.

可覆盖: 实参依赖查找.

要求: std::is_error_code_enum<T> 或 std::is_error_condition_enum<T> 对衰变后的 ErrorCodeEnum 之一为真.

命名空间: std

头文件: <boost/outcome/std_result.hpp>
