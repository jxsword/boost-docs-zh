explicit basic_result(basic_result<R, S, P> &&)

来自兼容 basic_result 的显式转换移动构造函数. 调用 void on_result_move_construction(T *, U &&) noexcept, 传入 this 与输入.

要求: predicate::enable_make_error_code_compatible_conversion<R, S, P> 为真.

复杂度: 与底层类型的移动构造函数相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.

保证: 如果操作期间抛出异常, 对象会处于部分完成状态, 与对 struct 执行相同操作的通常规则一致.
