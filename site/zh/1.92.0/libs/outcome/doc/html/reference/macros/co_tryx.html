BOOST_OUTCOME_CO_TRYX(expr)

在协程内对一个结果类型匹配以下定制点的表达式求值, 成功时发出 T, 失败时立即从调用函数返回 try_operation_return_as(X):

  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_has_value(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_return_as(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_extract_value(X)

这些定制点都有默认重载. 参见 支持给 BOOST_OUTCOME_TRY 陌生输入的配方.

会向编译器提示该表达式将成功. 如果你预期失败, 应改用 BOOST_OUTCOME_CO_TRYX_FAILURE_LIKELY(expr).

会创建一个保存表达式值的内部临时对象, 这通常会引发一次拷贝/移动. 如果你希望永不拷贝/移动, 可以让该宏把内部临时对象创建为引用.

可用性: 仅限 GCC 与 clang. 使用 #ifdef BOOST_OUTCOME_CO_TRYX 判断是否可用.

可覆盖: 不可覆盖.

定义: 大部分机制参见 BOOST_OUTCOME_CO_TRYV(expr).

该宏利用 GCC 与 clang 中的一种专有扩展, 从成功的表达式发出 T. 因此你可以直接在表达式中使用 BOOST_OUTCOME_CO_TRYX(expr), 例如 auto x = y + BOOST_OUTCOME_CO_TRYX(foo(z));.

注意, 在保留所发出 T 的右值/左值等属性方面存在编译器怪癖: 具体而言, 拷贝或移动构造函数可能被意外调用, 和/或拷贝消除不按预期工作. 如果这些被证明有问题, 应改用 BOOST_OUTCOME_CO_TRY(var, expr).
