std::istream &operator>>(std::istream &, basic_result<T, E, NoValuePolicy> &)

把 basic_result 从 std::istream 反序列化.

序列化格式为:

<unsigned int flags><space><value_type if set and not void><error_type if set and not void>

可覆盖: 不可覆盖.

要求: operator>> 对 std::istream、T 与 E 是有效表达式.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/iostream_support.hpp> (必须手动显式包含).
