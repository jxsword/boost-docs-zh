std::error_code error_from_exception(std::exception_ptr &&ep = std::current_exception(), std::error_code not_matched = std::make_error_code(std::errc::resource_unavailable_try_again)) noexcept

该函数通过重抛 ep——在一个 try 块内——来省去编写样板代码——带有一长串 catch() 处理器, 每个对应一种在 std::errc 中有近似或精确等价错误码的标准 C++ 异常类型.

如果匹配, ep 被设为默认构造的 std::exception_ptr, 并构造出一个 std::error_code——使用经 ADL 发现的自由函数 make_error_code(), 依据与被抛异常匹配的 std::errc 枚举值.

如果不匹配, ep 保持原样, 改为返回所提供的 not_matched 错误码.

可覆盖: 不可覆盖.

要求: 全局启用 C++ 异常.

命名空间: BOOST_OUTCOME_V2_NAMESPACE
