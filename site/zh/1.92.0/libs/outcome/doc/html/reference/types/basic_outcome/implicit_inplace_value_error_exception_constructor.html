basic_outcome(A1 &&, A2 &&, Args ...)

隐式原位值或错误或异常构造函数. 依据输入委托给相应的显式原位构造函数.

要求: predicate::enable_inplace_value_error_exception_constructor` 为真.

复杂度: 与 value_type 或 error_type 或 exception_type 构造函数——接受 A1, A2, Args ... 的那个——相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.

保证: 如果操作期间抛出异常, Args 的状态将处于未确定状态.
