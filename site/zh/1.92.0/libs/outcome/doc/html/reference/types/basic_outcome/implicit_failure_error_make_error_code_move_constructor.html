basic_outcome(failure_type<EC> &&)

来自失败类型糖的隐式错误移动构造函数, 用于消歧错误类型的构造. 调用 void on_outcome_move_construction(T *, U &&) noexcept, 传入 this 与 failure_type<EC> &&.

要求: predicate::enable_make_error_code_compatible_conversion<void, EC, void, void> 为真.

复杂度: 与 error_type 构造函数——接受 EC 的那个——相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.
