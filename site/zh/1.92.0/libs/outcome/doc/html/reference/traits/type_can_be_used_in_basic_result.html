type_can_be_used_in_basic_result<R>

对可在 basic_result<T, E, NoValuePolicy> 中使用的类型为真的 constexpr 布尔值.

可覆盖: 不可覆盖.

定义: 对满足以下条件的类型为真:

  • 不是引用.
  • 不是 in_place_type_t<T>.
  • 不是 success_type<T>.
  • 不是 failure_type<EC, EP = void>.
  • 不是数组.
  • 要么是 void, 要么是 Object 且为 Destructible.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::trait

头文件: <boost/outcome/trait.hpp>
