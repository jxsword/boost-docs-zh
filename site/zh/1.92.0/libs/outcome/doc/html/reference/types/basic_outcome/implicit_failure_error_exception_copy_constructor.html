basic_outcome(const failure_type<EC, EP> &)

来自失败类型糖的隐式错误与异常拷贝构造函数, 用于消歧错误+异常类型的构造. 调用 void on_outcome_copy_construction(T *, U &&, V &&) noexcept, 传入 this、const failure_type<EC> & 与 const failure_type<EP> &.

要求: predicate::enable_compatible_conversion<void, EC, EP, void> 为真.

复杂度: 与 error_type 和 exception_type 构造函数——接受 EC 和 EP 的那些——相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.
