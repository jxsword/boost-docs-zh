BOOST_OUTCOME_TRYV2_FAILURE_LIKELY(spec, expr)

对一个结果类型匹配以下定制点的表达式求值, 成功时继续执行, 失败时立即从调用函数返回 try_operation_return_as(X):

  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_has_value(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_return_as(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_extract_value(X)

这些定制点都有默认重载. 参见 支持给 BOOST_OUTCOME_TRY 陌生输入的配方.

会向编译器提示该表达式将不成功. 如果你预期成功, 应改用 BOOST_OUTCOME_TRYV(expr).

可覆盖: 不可覆盖.

定义: 首先, 表达式的临时对象被绑定到一个唯一命名的、栈上分配的 spec. 如果该引用所绑定对象的 try_operation_has_value() 为 false, 立即执行 return try_operation_return_as(propagated unique reference);, 并传播原表达式的右值/左值等属性.

头文件: <boost/outcome/try.hpp>
