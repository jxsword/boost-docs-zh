BOOST_OUTCOME_USE_STD_IN_PLACE_TYPE

如何实现 in_place_type_t<T> 与 in_place_type<T>.

如果设为 1, 会包含 <utility> 头文件, 并且 std::in_place_type_t<T> 会被别名进 BOOST_OUTCOME_V2_NAMESPACE::in_place_type_t<T>——连同 std::in_place_type<T> 一起.

如果设为 0, 则使用本地模拟.

可覆盖: 在包含之前定义.

默认: 如果当前编译器实现 C++ 17 或更高, 在未设置时本宏默认为 1, 否则默认为 0.

头文件: <boost/outcome/config.hpp>
