void try_throw_std_exception_from_error(std::error_code ec, const std::string &msg = std::string{})

该函数通过抛出与所提供错误码等价的标准库异常类型来省去编写样板代码, 可带可选的自定义消息.

如果该函数返回, 说明不存在与所提供错误码等价的标准库异常类型. 以下错误码产生如下异常抛出:

EINVAL
std::invalid_argument
EDOM
std::domain_error
E2BIG
std::length_error
ERANGE
std::out_of_range
EOVERFLOW
std::overflow_error
ENOMEM
std::bad_alloc

上文引用 POSIX errno 值的选择反映了匹配算法. 由于 std::errc 精确映射 POSIX errno, 在所有平台上, std::generic_category 错误码都会被该函数匹配. 只有在 POSIX 平台上, std::system_category 错误码才也会被该函数匹配.

可覆盖: 不可覆盖.

要求: 全局启用 C++ 异常.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/utils.hpp>
