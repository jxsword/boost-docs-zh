BOOST_OUTCOME_THROW_EXCEPTION(expr)

抛出 C++ 异常或其等价物.

可覆盖: 在包含之前定义.

默认:

独立版 Outcome (启用 C++ 异常):
为 throw expr
独立版 Outcome (禁用 C++ 异常):
为 BOOST_OUTCOME_V2_NAMESPACE::detail::do_fatal_exit(#expr), 它是一个函数: 先向 stderr 打印有用的错误消息 (含栈回溯, 如可用), 再调用 abort().
Boost.Outcome:
为 BOOST_THROW_EXCEPTION(expr).

头文件: <boost/outcome/config.hpp>
