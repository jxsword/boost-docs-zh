is_error_code_available<T>

::value 为真, 如果错误码可以从 T 构造, 例如存在经 ADL 发现的自由函数 make_error_code(T). ::type 是当 ::value 为真时将产生的类型, 否则为 void.

可覆盖: 通过向 trait 命名空间进行模板特化.

默认: 若 T 是错误码则为真, 否则执行对 make_error_code(T) 进行 ADL 发现的元编程. 注意, STL 为其错误枚举定义了经 ADL 发现的自由函数 std::make_error_code(T) 的多个重载, Boost.System 对 Boost 错误枚举也是如此. 因此该 trait 会为那些错误类型拾取那些自由函数.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::trait

头文件: <boost/outcome/trait.hpp>

变量别名: is_error_code_available_v<T>
