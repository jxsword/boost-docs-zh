base

实现大多数定义窄观察器策略的策略类的基类.

要求: 无.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::policy

头文件: <boost/outcome/policy/base.hpp>

受保护成员函数

特殊

  1. static void _ub(Impl &&)

    引发明显硬性未定义行为的特殊函数.

观察器

  1. static bool _has_value(Impl &&) noexcept

    若传入的实现中存在值则返回 true. constexpr, 永不抛出.

  2. static bool _has_error(Impl &&) noexcept

    若传入的实现中存在错误则返回 true. constexpr, 永不抛出.

  3. static bool _has_exception(Impl &&) noexcept

    若传入的实现中存在异常则返回 true. constexpr, 永不抛出.

  4. static bool _has_error_is_errno(Impl &&) noexcept

    若传入实现中的错误码具有与 POSIX errno 匹配的域或类别则返回 true. constexpr, 永不抛出.

  5. static auto &&_value(Impl &&) noexcept

    返回传入实现中值的引用. constexpr, 永不抛出.

  6. static auto &&_error(Impl &&) noexcept

    返回传入实现中错误的引用. constexpr, 永不抛出.

  7. static auto &&_exception(Impl &&) noexcept

    返回传入实现中异常的引用. constexpr, 永不抛出.

修改器

  1. static void _set_has_value(Impl &&, bool) noexcept

    设置实现是否具有值. constexpr, 永不抛出.

  2. static void _set_has_error(Impl &&, bool) noexcept

    设置实现是否具有错误. constexpr, 永不抛出.

  3. static void _set_has_exception(Impl &&, bool) noexcept

    设置实现是否具有异常. constexpr, 永不抛出.

  4. static void _set_has_exception(Impl &&, bool) noexcept

    设置实现中的错误码是否具有与 POSIX errno 匹配的域或类别. constexpr, 永不抛出.
