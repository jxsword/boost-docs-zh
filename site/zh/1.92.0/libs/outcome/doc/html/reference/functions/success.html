auto success(T &&, ...)

返回用于构造成功 result 或 outcome 的恰当类型糖, 通常是 success_type<T>——带有一个衰变后的 T.

提供两个默认重载: 一个接受单个必选参数与可选备用存储值参数, 返回 success_type<std::decay_t<T>> 并完美转发输入. 另一个重载不接受参数, 返回 success_type<void>, 这通常会使接收方 basic_result 或 basic_outcome 以其值类型的默认构造来构造.

可覆盖: 通过实参依赖查找 (ADL).

要求: 始终可用.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/success_failure.hpp>
