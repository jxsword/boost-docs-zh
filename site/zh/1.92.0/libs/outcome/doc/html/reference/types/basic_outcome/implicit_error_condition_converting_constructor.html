basic_outcome(ErrorCondEnum &&)

隐式 error_type——来自 ErrorCondEnum——构造函数. 调用 void on_outcome_construction(T *, U &&) noexcept, 传入 this 与 ErrorCondEnum.

要求: predicate::enable_error_condition_converting_constructor<R> 为真.

复杂度: 与 error_type 从 make_error_code(ErrorCondEnum) 的结果进行拷贝或移动构造时相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.

保证: 如果操作期间抛出异常, 输入的状态将处于未确定状态.
