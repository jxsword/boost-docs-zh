概念

  1. basic_outcome<T>

    一个布尔 concept, 匹配可转换为 basic_outcome<T, EC, EP, NoValuePolicy> 的类型.

  2. basic_result<T>

    一个布尔 concept, 匹配可转换为 basic_result<T, E, NoValuePolicy> 的类型.

  3. value_or_error<T>

    一个布尔 concept, 匹配具有值或错误的类型.

  4. value_or_none<T>

    一个布尔 concept, 匹配具有可选值的类型.
