bad_outcome_access

公开继承自 std::logic_error 的异常类型, 表明basic_outcome<T, EC, EP, NoValuePolicy> 发生了不正确的值、错误或异常观察.

除 std::logic_error 之外不添加任何成员函数. 典型的 .what() 字符串为:

  • "no value"
  • "no error"
  • "no exception"

要求: 无.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/bad_access.hpp>
