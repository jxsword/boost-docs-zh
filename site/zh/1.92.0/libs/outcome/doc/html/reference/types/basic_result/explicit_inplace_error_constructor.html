explicit basic_result(in_place_type_t<error_type_if_enabled>, Args ...)

显式原位错误构造函数. 调用 void on_result_in_place_construction(T *, in_place_type_t<U>, Args &&...) noexcept, 传入 this、in_place_type<error_type> 与 Args ....

要求: predicate::enable_inplace_error_constructor<Args ...> 为真.

复杂度: 与 error_type 构造函数——接受 Args ... 的那个——相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.

保证: 如果操作期间抛出异常, Args 的状态将处于未确定状态.
