outcome<T, EC = varies, EP = varies, NoValuePolicy = policy::default_policy<T, EC, EP>>

一个类型别名, 指向 std_outcome<T, EC = std::error_code, EP = std::exception_ptr, NoValuePolicy = policy::default_policy<T, EC, EP>> (独立版) 或 boost_outcome<T, EC = boost::system::error_code, EP = boost::exception_ptr, NoValuePolicy = policy::default_policy<T, EC, EP>> (Boost 版) 之一, 以及 policy::default_policy. 这意味着 outcome<T> 会依据正在使用哪一版 Outcome 而采用恰当的默认别名.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/outcome.hpp>
