static void _ub(Impl &&)

这是一个特殊函数, 它做编译器特定的事情来告知编译器: 该函数永远、永远、永远不会被执行. 编译器优化器会坚定假定该函数不可能被执行, 并完全剪除其被执行的可能性. 这通常意味着代码路径戛然而止, 如果执行确实走到这条路径, 它会跑出一个无处可去的分支末端. 你的程序将失去已知状态, 通常会破坏内存与寄存器并崩溃.

这看起来极不合意. 然而, 它也意味着优化器可以进行更强的优化, 只要你确实从不执行该分支, 你确实会得到更高质量的代码生成.

如果未定义 NDEBUG 宏, 会存在一个 BOOST_OUTCOME_ASSERT(false). 这会使试图执行该函数的尝试以非常明显的方式失败, 但它也会生成运行时代码来触发这个明显的失败.

如果定义了 NDEBUG 宏, 且程序使用未定义行为 sanitizer 编译, 试图执行该函数会触发一次未定义行为 sanitizer 动作.

要求: 始终可用.

复杂度: 若定义了 NDEBUG, 保证零运行时开销. 如果该函数返回, 你的程序现在处于已知程序状态的严重丢失中. 通常 (但不总是) 它稍后会在某个点崩溃. 罕见地它会破坏寄存器与内存并继续运行.

保证: 永不抛出异常.
