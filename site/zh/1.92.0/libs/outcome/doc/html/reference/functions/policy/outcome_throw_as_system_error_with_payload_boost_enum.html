void outcome_throw_as_system_error_with_payload(BoostErrorCodeEnum &&)

outcome_throw_as_system_error_with_payload() 的特化, 用于 boost::system::is_error_code_enum<BoostErrorCodeEnum> 或 boost::system::is_error_condition_enum<BoostErrorCodeEnum> 为真的类型. 它执行 BOOST_OUTCOME_THROW_EXCEPTION(expr), 带有一个 boost::system::system_error——由经 ADL 发现的自由函数 make_error_code(BoostErrorCodeEnum) 的结果构造.

可覆盖: 实参依赖查找.

要求: boost::system::is_error_code_enum<T> 或 boost::system::is_error_condition_enum<T> 对衰变后的 BoostErrorCodeEnum 之一为真.

命名空间: boost::system

头文件: <boost/outcome/boost_result.hpp>
