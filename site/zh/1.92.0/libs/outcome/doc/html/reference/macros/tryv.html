BOOST_OUTCOME_TRYV(expr)/BOOST_OUTCOME_TRY(expr)

对一个结果类型匹配以下定制点的表达式求值, 成功时继续执行, 失败时立即从调用函数返回 try_operation_return_as(X):

  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_has_value(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_return_as(X)
  • BOOST_OUTCOME_V2_NAMESPACE::try_operation_extract_value(X)

这些定制点都有默认重载. 参见 支持给 BOOST_OUTCOME_TRY 陌生输入的配方.

BOOST_OUTCOME_TRYV(expr) 版与 BOOST_OUTCOME_TRY(expr) 版的区别在于: 后者在存在两个或更多宏实参时会设置一个变量 (参见 BOOST_OUTCOME_TRY(var, expr)). 前者要求 T 为 void.

会向编译器提示该表达式将成功. 如果你预期失败, 应改用 BOOST_OUTCOME_TRYV_FAILURE_LIKELY(expr).

会创建一个保存表达式值的内部临时对象, 这通常会引发一次拷贝/移动. 如果你希望永不拷贝/移动, 可以让该宏把内部临时对象创建为引用.

可覆盖: 不可覆盖.

定义: 首先, 表达式的临时对象被绑定到一个唯一命名的、栈上分配的 auto &&. 如果该引用所绑定对象的 try_operation_has_value() 为 false, 立即执行 return try_operation_return_as(propagated unique reference);, 并传播原表达式的右值/左值等属性.
