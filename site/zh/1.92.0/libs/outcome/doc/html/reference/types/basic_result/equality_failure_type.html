bool operator==(const failure_type<A, void> &) const

若此 result 不成功, 且其错误与失败类型糖中的错误比较相等则返回 true. 比较使用 operator== 对 error_type 与 A 进行. 若 A 为 void, 该调用即 bool has_error() const noexcept 的别名.

要求: operator== 必须在 error_type 与 A 之间是有效表达式, 或 A 为 void. 若 error_type 为 void, 则 A 亦然.

复杂度: 取决于底层 operator== 所具有者. 底层操作的 constexpr 与 noexcept 会被传播.

保证: 无.
