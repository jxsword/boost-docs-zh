explicit basic_result(concepts::value_or_error<T, E> &&)

来自 concepts::value_or_error<T, E> concept 匹配类型的显式转换构造函数. 委托给 basic_result 的移动构造函数.

要求: convert::value_or_error<T, U> 具有可用的调用运算符, 且如果输入是 basic_result 或 basic_outcome, 则 convert::value_or_error<> 已为该 convert::value_or_error<> 特化启用了那些输入.

复杂度: 与从输入的 .value() 或 .error() 分别进行的拷贝或移动构造相同. 底层操作的 constexpr、平凡性与 noexcept 会被传播.

保证: 如果操作期间抛出异常, 对象会处于部分完成状态, 与对 struct 执行相同操作的通常规则一致.
