auto failure(T &&, ...)

返回用于构造不成功 result 或 outcome 的恰当类型糖, 通常是 failure_type<EC, EP = void>——带有一个衰变后的 T.

提供两个默认重载: 一个接受单个必选参数与可选备用存储值参数, 返回 failure_type<std::decay_t<T>>; 另一个接受两个必选参数与可选备用存储值参数, 返回 failure_type<std::decay_t<T>, std::decay_t<U>>. 两个重载都完美转发其输入.

注意, Outcome 允许 failure() 重载返回 failure_type 以外的东西. 例如, basic_result 的 auto as_failure() const & 返回 failure() 所返回的任何类型, 而 BOOST_OUTCOME_TRY(var, expr) 默认对失败返回 .as_failure() 所返回的东西. 这可用于让 BOOST_OUTCOME_TRY(...} 在失败时对某个特定输入 basic_result 或 basic_outcome 传播自定义的东西.

可覆盖: 通过实参依赖查找 (ADL).

要求: 始终可用.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/success_failure.hpp>
