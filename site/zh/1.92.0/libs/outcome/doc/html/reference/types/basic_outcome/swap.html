void swap(basic_outcome &)

以强保证把一个 basic_outcome 与另一个交换. 当 value_type、error_type 与 exception_type 的移动构造函数与移动赋值都是 noexcept 时为 constexpr.

要求: 始终可用.

复杂度: 若 value_type、error_type 与 exception_type 的移动构造函数与移动赋值都是 noexcept, 复杂度与 swap() 对 value_type、error_type 与 exception_type 的实现相同. 否则复杂度不保持, 因为会改用 strong_swap(bool &all_good, T &a, T &b) 而非 swap(). 本函数默认使用一次移动构造与两次赋值, 并会在发生失败时尝试额外的移动赋值以恢复进入时的状态.

保证: 如果 swap 操作期间抛出异常, 会尝试恢复所有三个操作数进入时的状态, 以实现强保证. 如果这也失败, 标志位会被强制为某种一致的状态, 使得不可能同时出现有值与出错/例外, 或无值与无错/无例外. has_lost_consistency() 标志对两个操作数都变为 true, 它们现在很可能处于不一致状态.
