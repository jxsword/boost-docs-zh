throw_bad_result_access<EC>

规定在不正确的宽值观察时应抛出 bad_result_access_with<EC> 的策略类. 该策略的主要目的是为 P0323 std::expected<T, E> 站台——后者在不正确的宽值观察时抛出 bad_expected_access<E>. 这就是为什么只有 EC 会在仅有值观察时带着 bad_result_access_with<EC> 被抛出, 且仅当有错误可用时.

如果在 basic_outcome 中使用, 且 outcome 带有异常因而没有错误可用, 不正确的宽值观察则改为执行:

BOOST_OUTCOME_THROW_EXCEPTION(bad_result_access("no value"));

不正确的宽错误观察执行:

BOOST_OUTCOME_THROW_EXCEPTION(bad_result_access("no error"));

不正确的宽异常观察执行:

BOOST_OUTCOME_THROW_EXCEPTION(bad_outcome_access("no exception"));

公开继承自 base, 其窄值、错误与异常观察器策略继承自那里.

要求: 无.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::policy

头文件: <boost/outcome/policy/throw_bad_result_access.hpp>
