BOOST_OUTCOME_SYMBOL_VISIBLE

编译器特定标记, 用于把可抛出类型标记为始终具有默认 ELF 符号可见性; 缺少它, 将无法在 ELF 上跨共享库边界捕获此类类型的抛出.

可覆盖: 在包含之前定义.

默认:

独立版 Outcome:
在 GCC 与 clang 上面向 ELF 时为 __attribute__((visibility("default")), 否则为无.
Boost.Outcome:
为 BOOST_SYMBOL_VISIBLE.

头文件: <boost/outcome/config.hpp>
