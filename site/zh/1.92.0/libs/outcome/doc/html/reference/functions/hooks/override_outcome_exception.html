void override_outcome_exception(basic_outcome<T, EC, EP, NoValuePolicy> *, U &&) noexcept

把异常覆盖为与所构造对象不同的东西. 你几乎肯定不想使用这个函数. 覆盖所返回异常的更好得多的办法, 是创建一个自定义无值策略, 在需要时惰性地合成自定义异常对象.

这个函数存在的唯一原因是: 有些人有非常边角的需求——自定义无值策略用不上, 且无法移动构造出一个新的 outcome (以旧的 outcome 为基础并替换其异常状态), 例如类型不可拷贝且不可移动时.

除非你处于不存在其他可行替代方案的情形, 否则不要使用这个函数.

可覆盖: 不可覆盖.

要求: 无.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::hooks

头文件: <boost/outcome/basic_outcome.hpp>
