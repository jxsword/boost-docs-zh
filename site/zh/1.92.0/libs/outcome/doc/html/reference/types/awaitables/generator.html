generator<T, Executor = void>

这是一个经典的协程生成器: 协程被恢复以计算下一个值, 并在产出该值时挂起. 如果被产出的值是 Outcome 类型, 当协程抛出异常时使用特殊语义 (见下文).

Executor 模板参数纯粹是为了与 ASIO 等第三方软件兼容, 该 awaitable 可直接被 ASIO 使用.

使用示例:

generator<int> func(int x)
{
  while(x >= 0)
  {
    co_yield x--;
  }
}
...
// Creates the coroutine, immediately suspending it.
auto f = func(5);
// If the coroutine has another value to yield ...
while(f)
{
  // Get the next value from the coroutine
  int r = f();
  ...
}

generator<T> 具有特殊语义: 如果 T 是能够从 exception_ptr 或 error_code 构造的类型, 函数体内抛出的任何异常都会经由 T 发送, 若 error_from_exception( ) 成功匹配被抛异常, 则优先走错误码路径. 这意味着 basic_result<T, E, NoValuePolicy> 或 basic_outcome<T, EC, EP, NoValuePolicy> (其类型之一兼容时) 的 .error() 或 .exception() 会被设置.

注意, generator<T> 在其他方面不传输异常抛出, 并会把协程体内抛出的任何异常经由协程机制重抛. 这在当前 C++ 编译器中不会产生可靠后果. 因此你应当把协程体包在 try...catch 中, 如果 T 不能自行传输异常.

要求: 你的编译器需支持 C++ 协程.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::awaitables

头文件: <boost/outcome/coroutine_support.hpp>
