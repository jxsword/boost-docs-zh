success_type<T>

用于构造成功 result 或 outcome 的类型糖. 一般不直接构造, 而是经由自由函数 success(T &&, ...). 可用 is_success_type<T> 检测.

这是一个常规包装类型: 默认构造、拷贝与移动构造函数为默认, 赋值为默认, 析构函数为默认.

成员类型别名 value_type 指示 T.

存在一个显式初始化构造函数, 接受任何类型 U (不是 success_type<T>), 并将从其转发构造所含的 T——即从该 U 构造. 如果你希望指定备用存储值, 它还有一个可选参数 spare_storage.

存在一个 .value() 引用观察器, 带有惯常的 constexpr 左值、const 左值、右值与 const 右值重载.

存在特化 success_type<void>, 它不存储任何东西, 也不提供 .value() 观察器.

存在一个 .spare_storage() 观察器, 返回构造该成功类型糖时所用的备用存储值.

要求: 无.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/success_failure.hpp>
