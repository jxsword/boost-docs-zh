bool operator==(const basic_outcome<A, B, C, D> &) const

若此 outcome 与另一个 outcome 比较相等则返回 true. 当两个 outcome 当前所选状态相同时, 使用 operator== 对 value_type 或 error_type 和/或 exception_type 进行比较, 否则返回 false.

要求: operator== 必须在 value_type 与 A 之间、error_type 与 B 之间、exception_type 与 C 之间是有效表达式. 若 value_type 为 void, 则 A 亦然; error_type 与 B 同理; exception_type 与 C 同理.

复杂度: 取决于底层 operator== 所具有者. 底层操作的 constexpr 与 noexcept 会被传播.

保证: 无.
