is_error_type_enum<E, Enum>

一个可定制的整型常量类型, 对 E 类型 (可从 Enum 类型构造) 为真——这些类型将接受抛错误无值策略

可覆盖: 通过向 trait 命名空间进行模板特化.

默认: 假. 存在特化, 针对:

  • <boost/outcome/boost_result.hpp>

    • boost::system::error_code 到 boost::system::is_error_condition_enum<Enum>::value.

  • <boost/outcome/std_result.hpp>

    • std::error_code 到 std::is_error_condition_enum<Enum>::value.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::trait

头文件: <boost/outcome/trait.hpp>
