basic_result(const failure_type<T> &)

来自失败类型糖的隐式错误拷贝构造函数, 用于消歧错误类型的构造. 注意, 如果 T = void, error_type 将被默认构造. 调用 void on_result_copy_construction(T *, U &&) noexcept, 传入 this 与 const failure_type<T> &.

要求: predicate::enable_make_exception_ptr_compatible_conversion<void, T, void> 为真, 或 T 为 void.

复杂度: 与 error_type 构造函数——接受 T 的那个——相同, 或与 error_type 默认构造函数相同 (当 T 为 void 时). 底层操作的 constexpr、平凡性与 noexcept 会被传播.
