decltype(auto) try_operation_return_as(X)

该默认实现优先返回输入类型的 .as_failure() 成员函数所返回的东西. basic_result 与 basic_outcome 提供这样的成员函数, 参见 auto as_failure() const &.

如果 .as_failure() 不可用, 它也会匹配任何 .error() 成员函数, 并用 failure(T &&, ...) 把其包装成失败类型糖.

要求: 表达式 std::declval<T>().as_failure() 和/或 std::declval<T>().error() 是有效表达式.

命名空间: BOOST_OUTCOME_V2_NAMESPACE

头文件: <boost/outcome/try.hpp>
