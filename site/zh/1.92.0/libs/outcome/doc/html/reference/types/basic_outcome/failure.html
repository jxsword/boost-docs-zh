exception_type failure() const noexcept

所存异常或错误的合成观察器. 如果有异常可用, 直接返回其副本. 如果有错误可用 (而非异常), 则调用经 ADL 发现的自由函数 auto basic_outcome_failure_exception_from_error(const EC &). Outcome 为 std::error_code 与 boost::system::error_code 定义了该函数的默认重载, 分别返回 std::make_exception_ptr(std::system_error(ec)) 与 boost::copy_exception(boost::system::system_error(ec)).

要求: traits is_error_code_available<T> 与 is_exception_ptr_available<T> 均为真.

复杂度: 取决于 basic_outcome_failure_exception_from_error(const EC &).

保证: 永不抛出. 如果拷贝异常期间抛出异常, 则改为返回该异常 (来自 std::current_exception()).
