value_or_error<T>

在 C++ 20 或 Concepts TS 启用时, 是一个布尔 concept, 匹配具有公有 .has_value() 观察器 (返回 bool)、公有 .value() 观察器函数与公有 .error() 观察器函数的类型.

在不启用 Concepts 时, 是一个 static constexpr bool, 对满足相同要求的类型为真, 采用基于 SFINAE 的模拟.

该 concept 匹配类似 expected 的类型, 例如 P0323 std::expected<T, E>, 其中之一是 basic_result<T, E, NoValuePolicy>. 注意: 如果它们呈现上文匹配的接口, 该 concept 不区分值或错误类型与值和错误类型.

如果你想要专门匹配 basic_result<T, E, NoValuePolicy> 的 concept, 参见 basic_result<T>.

命名空间: BOOST_OUTCOME_V2_NAMESPACE::concepts

头文件: <boost/outcome/convert.hpp>

遗留: 在 Outcome v2.1 及更早版本中它名为 convert::ValueOrError<T>. 把 BOOST_OUTCOME_ENABLE_LEGACY_SUPPORT_FOR 定义为小于 220 即可启用.
