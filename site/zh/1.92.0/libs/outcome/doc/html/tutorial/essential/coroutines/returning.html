从协程返回 Outcome 类型

eager<T, Executor = void> 与 lazy<T, Executor = void> 及其 atomic 版本是完全标准的 awaitable, 没有特殊行为——除非 T 是 basic_result 或 basic_outcome. 那种情况下会发生以下事情:

如果协程抛出一个协程体内未处理的 C++ 异常, Outcome 的 awaitable 类型会尝试把它转换为正被返回的 Result 或 Outcome 类型能传输的形式. 例如:

  • 如果你的协程返回的是 result<T, std::exception_ptr>, 将返回一个出错的 Result, 携带指向被抛异常的指针.

  • 如果你的协程返回的是 result<T, std::error_code>, exception ptr 会被传给 error_from_exception( ), 看它能否匹配到等价的 std::error_code. 如果能, 将返回带等价错误码的出错 Result.

  • 如果你的协程返回的是 outcome<T, std::error_code, std::exception_ptr>, 将优先选择出错的 Outcome 而非带例外的 Outcome.

  • 如果你的协程返回的是 experimental::status_result<T, system_code>, 由于 Experimental SG14 的 system_code 能传输错误码或 exception ptr (乃至 std::error_code), 将返回一个出错的 Result.
