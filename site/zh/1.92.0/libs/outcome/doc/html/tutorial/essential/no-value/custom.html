自定义无值策略

如果你希望你的 basic_outcome<> 或 basic_result<> 实例在对不含值的对象调用 std::abort() 时、或对不含错误的对象调用 .value() 时调用 .error(), 你需要按如下方式定义自己的无值策略:

struct abort_policy : outcome::policy::base
{
  template <class Impl> static constexpr void wide_value_check(Impl &&self)
  {
    if(!base::_has_value(std::forward<Impl>(self)))
      std::abort();
  }

  template <class Impl> static constexpr void wide_error_check(Impl &&self)
  {
    if(!base::_has_error(std::forward<Impl>(self)))
      std::abort();
  }

  template <class Impl> static constexpr void wide_exception_check(Impl &&self)
  {
    if(!base::_has_exception(std::forward<Impl>(self)))
      std::abort();
  }
};

所有策略都应继承自 base, 以便为你的策略实现提供访问与操纵 result 与 outcome 状态的内部策略 API.

策略定义好后, 你必须在提供自己的 basic_outcome 特化时指定它:

template <typename T>
using strictOutcome =  //
outcome::basic_outcome<T, std::error_code, std::exception_ptr, abort_policy>;
