operator co_await 作为 TRY 运算符

许多人请求重载 operator co_await, 使其在提供 Outcome 类型时表现为 TRY 运算符.

Outcome 不实现该扩展, 也不会接受为此提供支持的 PR. 我们认为你应当使用 BOOST_OUTCOME_CO_TRY(), 因为这会带来更可维护、更能面向未来的代码.

不过, 我们刻意不阻碍你在自己的基于 Outcome 的代码中自行实现该重载. 只是务必把你正在做的事大声而清晰地记录下来, 并注意未来的 C++ 标准可能有正式的 operator try 重载机制.
