检查 result

假设我们将编写函数 print_half, 它接受一个表示整数的 std::string 并打印该整数的一半:

outcome::result<void> print_half(const std::string& text);
在 Github 上查看此代码

类型 result<void> 意味着成功时没有值可返回, 但操作仍可能失败, 而我们可能有兴趣检查失败原因. 类模板 result<> 以属性 [[nodiscard]] 声明, 意味着如果你忘记检查返回的对象, 编译器会警告你 (C++ 17 或更高).

实现将这样做: 如果该整数可由 int 表示, 我们转换为 int 并使用其算术运算. 如果数字过大, 我们回退到使用需要分配内存的自定义 BigInt 实现. 在实现中我们将使用上一节定义的函数 convert.

outcome::result<void> print_half(const std::string& text)
{
  if (outcome::result<int> r = convert(text))         // #1
  {
    std::cout << (r.value() / 2) << std::endl;        // #2
  }
  else
  {
    if (r.error() == ConversionErrc::TooLong)         // #3
    {
      BOOST_OUTCOME_TRY(auto i, BigInt::fromString(text));  // #4
      std::cout << i.half() << std::endl;
    }
    else
    {
      return r.as_failure();                          // #5
    }
  }
  return outcome::success();                          // #6
}

#1. 你测试 result<> 对象——通过到 bool 的语境转换——是否表示一次成功的操作.

#2. 函数 .value() 提取成功返回的 int.

#3. 函数 .error() 允许你检查错误子对象, 它表示关于失败原因的信息.

#4. 宏 BOOST_OUTCOME_TRY 表示一个控制语句. 它隐含第二个实参中的表达式返回一个 result<>. 该函数定义为:

/*static*/ outcome::result<BigInt> BigInt::fromString(const std::string& s)
在 Github 上查看此代码

我们的控制语句含义: 如果 fromString 返回失败, 应当从 print_half 返回同样的错误信息, 即使 result<> 的类型不同. 如果 fromString 返回成功, 我们创建变量 i, 其类型为 BigInt, 值为 fromString 返回的值. 如果控制流走到后续行, 意味着 fromString 成功, 且类型为 BigInt 的变量在作用域内.

#5. 在 return 语句中我们提取错误信息, 并用它初始化 print_half 的返回值. 我们本可以写 return r.error();, 效果相同, 但当从 r.as_failure() 的隐式构造因 E 与 T 存在可构造关系而被禁用时, E 仍然可用.

#6. 函数 success() 返回一个表示成功的 success<void> 类型对象. 所有 result 与 outcome 类型都会把它隐式转换为成功返回, 必要时默认构造任何 T.
