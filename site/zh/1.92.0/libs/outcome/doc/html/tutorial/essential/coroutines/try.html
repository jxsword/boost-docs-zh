协程 TRY 操作

由于无法在协程内调用语句 return, Outcome 对协程支持的第一部分就是 BOOST_OUTCOME_CO_TRYV(expr)/BOOST_OUTCOME_CO_TRY(expr)——它与 BOOST_OUTCOME_TRY() 字面相同, 区别只是用 co_return 而非 return 来提前返回.

eager<result<std::string>> to_string(int x)
{
  if(x >= 0)
  {
    BOOST_OUTCOME_CO_TRY(convert(x));
  }
  co_return "out of range";
}
