TRY 操作

在函数 print_half 的实现中, 我们看到了宏 BOOST_OUTCOME_TRYV(expr)/BOOST_OUTCOME_TRY(expr) 的用法:

BOOST_OUTCOME_TRY (auto i, BigInt::fromString(text));

BOOST_OUTCOME_TRY 宏使用 C 宏重载, 依据输入参数数量在两种实现之间选择. 如果恰好只有一个输入参数, 即没有 i, 控制语句大致等价于:

auto __result = BigInt::fromString(text);
if (!__result)
  return __result.as_failure();

其中 __result 是编译期生成的唯一名称. 顺便说一句, 这种单实参形式等价于 BOOST_OUTCOME_TRYV(expr).

如果有二到八个参数, 该控制语句大致等价于:

auto __result = BigInt::fromString(text);
if (!__result)
  return __result.as_failure();
auto i = __result.value();

此处 i 作为第一个 C 宏参数被设为任何成功 result 的值.

最多为八个实参提供了 C 宏重载. 为防止模板说明中的逗号干扰 C 预处理器、使其误以为实参超过八个, 你应当考虑把第二个实参用括号包起来.

如果你在 C++ 协程内, 应当改用 BOOST_OUTCOME_CO_TRYV(expr)/BOOST_OUTCOME_CO_TRY(expr).

编译器特定扩展: BOOST_OUTCOME_TRYX

注释

该宏利用了 GCC 与 clang 中的一种专有扩展, 不可移植. 该宏在不支持的编译器上不可用, 因此你可以用 #ifdef BOOST_OUTCOME_TRYX 测试其是否存在.

GCC 与 Clang 提供了一个 C++ 扩展, 称为 语句表达式. 它们使使用更方便的宏成为可能: BOOST_OUTCOME_TRYX, 它是一个表达式. 有了上述宏, 上述变量 i 的声明可以改写为:

int i = BOOST_OUTCOME_TRYX (BigInt::fromString(text));

它的优点是你可以在任何能放表达式的地方使用它, 例如在 “简单初始化” 中:

if (int i = BOOST_OUTCOME_TRYX(BigInt::fromString(text)))
  use_a_non_zero_int(i);

或作为更大完整表达式的子表达式:

int ans = BOOST_OUTCOME_TRYX(BigInt::fromString("1")) + BOOST_OUTCOME_TRYX(BigInt::fromString("2"));

如果你在 C++ 协程内, 还有 BOOST_OUTCOME_CO_TRYX(expr) 可用.
