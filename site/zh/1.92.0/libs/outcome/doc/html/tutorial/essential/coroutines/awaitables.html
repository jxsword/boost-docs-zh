协程 awaitable

支持的第二部分由头文件 <boost/outcome/coroutine_support.hpp> 提供 (如果你想要 Experimental Outcome 的协程支持则为 <boost/outcome/experimental/coroutine_support.hpp>). 它向命名空间 BOOST_OUTCOME_V2_NAMESPACE::awaitables (或 BOOST_OUTCOME_V2_NAMESPACE::experimental::awaitables) 添加这些适合从协程化函数返回的 awaitable 类型:

  • eager<T, Executor = void>

    急切求值的协程: 对返回这种类型的函数执行 co_await 会立即开始函数的执行. 如果函数从不挂起, 开销与调用普通函数相似.

  • lazy<T, Executor = void>

    惰性求值的协程 (在大多数 C++ 协程文献中常名为 task<T>): 对返回这种类型的函数执行 co_await 会使函数在执行一开始就被立即挂起. 只有恢复协程的执行才会继续执行.

  • generator<T, Executor = void>

    值的惰性求值生成器: 协程被恢复以生成下一个值, 随即挂起, 直到下一次迭代.

  • atomic_eager<T, Executor = void>

    eager<T> 在恢复依赖协程时不使用线程同步——如果你在挂起-恢复周期中不跨越内核线程, 这没有问题. 但如果你在挂起-恢复期间可能跨越内核线程, 你应当改用 atomic_eager<T>——它使用原子操作同步状态的设置与检查以保证正确性.

  • atomic_lazy<T, Executor = void>

    lazy<T> 之于 atomic_eager<T>, 如同 eager<T> 之于其对应版本.
