协程

在 v2.1.2 中, Outcome 发布了对在 C++ 协程中使用 Outcome 的官方支持. 本页记录该支持.

所有标准 C++ 协程都具有如下形式:

// Coroutine functions MUST return an AWAITABLE type
AWAITABLE<int> function_name(Args ...)
{
  ... ordinary C++ ...
  if(!...)
  {
    co_return 5;  // CANNOT use ordinary 'return' from coroutines
  }
  ...
  // Possibly suspend this coroutine's execution until the
  // awaitable resumes execution of dependent code
  auto x = co_await expr_resulting_in_AWAITABLE;
  ...
}

类型 AWAITABLE<T> 是任何发布 Coroutine 协议的类型, 它告诉 C++ 如何挂起与恢复一个返回 T 的协程的执行. 记录如何做到这一点超出了本页的范围, 但请注意, 下面的 eager<T, Executor = void> 与 lazy<T, Executor = void> 类型是完全通用的 awaitable, 适合在任何代码中使用. 它们只有在 T (awaitable 返回的类型) 是 Outcome 类型 (例如 outcome::basic_result 或 outcome::basic_outcome) 时才有不同行为.
