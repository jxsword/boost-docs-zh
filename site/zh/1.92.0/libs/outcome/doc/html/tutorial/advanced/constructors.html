返回 Result 的构造函数

在关于 Expected/Outcome 的会议演讲中, 一个常被问到的问题是: 如何只用 result 来实现构造函数失败. 之所以这样问, 是因为虽然类中几乎每个成员函数都能返回 result, 但构造函数不返回值, 因此无法返回 result. 这意味着人们无法避免抛出 C++ 异常来中止构造.

与 C++ 中的大多数事情一样, 你可以通过大量额外键入样板代码, 加上一点点简单的 C++ 元编程, 实现零异常抛出的对象构造. 本节向那些绝对排斥抛异常、或因 C++ 异常被全局禁用而无法抛异常的人展示如何实现这些.

此处描述的技术不适用于不可拷贝且不可移动的类型. 还假定移动你的类型是廉价的.
