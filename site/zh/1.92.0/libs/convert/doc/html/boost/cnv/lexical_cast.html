boost::cnv::lexical_cast — 基于 boost::lexical_cast 的转换器

概要

// In header: <boost/convert/lexical_cast.hpp>


struct lexical_cast {

  // public member functions
  template<typename TypeOut, typename TypeIn> 
    void operator()(TypeIn const &, boost::optional< TypeOut > &) const;
};

说明

该转换器的目的是

  • 利用许多人已经习惯并感到舒适的 boost::lexical_cast 功能与性能;

  • 展示现有的独立转换相关设施可以如何被组合使用. 该转换器可以轻松替代 boost::lexical_cast, 并增加灵活性与便利性.
