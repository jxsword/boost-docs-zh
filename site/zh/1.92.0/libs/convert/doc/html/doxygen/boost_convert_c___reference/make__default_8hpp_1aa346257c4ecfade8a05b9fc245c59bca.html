函数模板 make_default

boost::make_default

概要

// In header: <boost/make_default.hpp>


template<typename T> T make_default();

说明

相当多的库要求提供一个类的实例 (创建并初始化存储). 例如,

Type result;
...
istream >> result;

在泛型代码中, 这导致对要与之配合使用的每个类型 'Type' 施加默认可构造性 (Default Constructibility) 要求. 不可避免地, 该要求 a) 或者把由于各种原因不满足该要求的所有类排除在外, 或者 b) 将某种 (未必理想的) 设计/实现强加给相应的类.

部署 boost::make_default() 可消除默认可构造性要求:

Type result = boost::make_default<Type>();
...
istream >> result;

没有默认构造函数的类现在可以通过 boost::make_default() 特化纳入:

namespace boost
{
    template<> inline Type make_default<Type>() { return Type(parameters); }
}
