受支持的编译器

Boost.Convert 利用 SFINAE 根据上下文正确部署 boost::convert(). 遗憾的是, SFINAE 支持的正确性与完备性因编译器及其版本而异. 因此, 一些编译器无法编译 Boost.Convert API (尽管转换器本身提供的实际功能也许可以通过其他非标准手段使用). Boost.Convert 已通过 Boost 回归测试框架进行测试, 结果如下:

  • CLANG. 从 2.9 到 3.6 的版本测试成功;
  • GCC. 从 4.2.1 到 5.0 的版本测试成功. 更早的版本未测试;
  • Intel C++ 编译器. 从 12.1 起的版本测试成功. 更早的版本因缺乏完整的 SFINAE 支持而无法编译 Boost.Convert;
  • MSVC. 从 MSVC 2013 (msvc-12.0) 起测试成功. 更早的版本因缺乏完整的 SFINAE 支持而禁用了某些组件;

最新可用报告请访问 Boost.Convert 回归测试摘要.
