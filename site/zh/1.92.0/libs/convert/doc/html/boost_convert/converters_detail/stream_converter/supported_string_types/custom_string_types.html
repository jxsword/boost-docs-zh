自定义字符串类型

boost::cnv::stream 接受自定义字符串类及类字符串类型作为输入或输出, 只要它们满足特定要求.

boost::cnv::cstream cnv;
my_string        my_str("123");

cnv(std::setprecision(2))(std::fixed);

BOOST_TEST(convert<int>(my_str, cnv).value_or(0) == 123);

BOOST_TEST(convert<my_string>( 99.999, cnv).value_or("bad") == "100.00");
BOOST_TEST(convert<my_string>( 99.949, cnv).value_or("bad") ==  "99.95");
BOOST_TEST(convert<my_string>(-99.949, cnv).value_or("bad") == "-99.95");

当类字符串类型是源时, 它需要是一个 连续序列, 由对应字符类型 (char 或 wchar_t) 组成, 并可通过 begin() 和 end() 访问.

std::stringstream 完全以 std::basic_streambuf 实现, 而后者在 连续字符序列 (也称为 缓冲区) 上操作 (详情见 std::basic_streambuf). 出于效率考虑, boost::cnv::stream 把提供的 (只读) 输入字符串用作 缓冲区, 因此要求所提供的输入字符串是连续字符序列.

当字符串是目标时, 所述 连续字符序列 要求不适用. 任何提供了

MyType::MyType(char const* beg, char const* end)

构造函数的类型都可以用于类型到字符串的转换.
