引言

Boost.Convert 建立在 boost::lexical_cast 的经验之上, 并把这些与类型转换/变换相关的想法进一步发展为

  • 适用于更广泛的与转换相关的部署场景,
  • 提供一个更灵活、可配置、可扩展的类型转换框架,
  • 提供泛型的一致行为,
  • 把各种转换设施 统一并统一部署, 通过一个一致的接口.

Boost.Convert 提供新的以及为人熟知的与转换/变换相关的功能, 如:

  • 部署不满足 默认可构造性要求的类型的手段;
  • 四种转换失败 检测方式:
    • 作为同一流程的一部分——基本与泛型的;
    • 作为分支流程——基于异常与基于函数的;
  • 立即或延迟抛异常以及不抛异常的转换失败 处理选项;
  • 转换失败 处理的灵活性, 通过:
    • 抛出一个异常;
    • 返回回退值;
    • 调用回退函数;
  • 支持标准算法.

Boost.Convert 由两个组件构成:

  • boost::convert() 接口;
  • 一个可扩展的可插拔转换器集合.

boost::convert() 接口

  • 宣告、提供并确保某种 一致行为;
  • 为各种转换设施统一并提供 一个一致的接口.

可插拔转换器集合独立于 boost::convert() API 门面, 其设计是 可扩展 的, 并会随时间被扩展. 当前提供以下转换器:

  • 基于 boost::lexical_cast 的,
  • 基于 printf/scanf 的,
  • 受 strtol 启发的,
  • 基于 std::stringstream 的,
  • 基于 boost::spirit 的.

这些转换器提供新的以及为人熟知的功能, 并展示现有的独立转换设施可以如何被纳入 Boost.Convert 框架. 例如, 基于 std::stream 的转换器借助标准 std::streams 功能并提供:

  • 字符串到类型与类型到字符串的转换;
  • 格式化支持 (基于 std::ios 的精度、进制、大小写、科学计数法等);
  • 对不同 locale 的支持;
  • char 与 wchar_t 支持.

以下代码演示如何从整数的文本 十六进制 表示转换一个整数数组. 它为转换失败的元素赋值 -1:

std::array<char const*, 3> strs = {{ " 5", "0XF", "not an int" }};
std::vector<int>           ints;
boost::cnv::cstream         cnv;

// Configure converter to read hexadecimal, skip (leading) white spaces.
cnv(std::hex)(std::skipws);

std::transform(strs.begin(), strs.end(), std::back_inserter(ints),
    boost::cnv::apply<int>(std::cref(cnv)).value_or(-1));

BOOST_TEST(ints.size() == 3); // Number of values processed.
BOOST_TEST(ints[0] ==  5);    // " 5"
BOOST_TEST(ints[1] == 15);    // "0XF"
BOOST_TEST(ints[2] == -1);    // "not an int"
