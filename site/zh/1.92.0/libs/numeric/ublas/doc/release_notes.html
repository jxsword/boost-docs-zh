Boost 基本线性代数 - 发布说明

返回 uBLAS 主页

Release 1.70.0

改进

  • 增加了对 GPU 加速运算的支持, 途径是 Boost.Compute
  • 增加对新的 (任意阶) 张量类型及相关运算的支持.

Release 1.52.0

改进

  • [4024] 改进 inplace_solve 的性能
  • [6511] 除以标量应使用 enable_if<>
  • [7297] 使自由函数 'num_columns' 和 'num_rows' 支持 uBLAS traits 系统, 并更好地配合表达式类型工作

缺陷修复

  • [7296] 修复并改进测试工具函数
  • [7363] 修复 gcc 4.7 及其他环境下 coordinate_matrix::sort() 的问题

Release 1.43.0

缺陷修复

  • [3968] 修复 MSVC10 上 coordinate_matrix 的排序问题
  • [3539] 对复数类型把 norm_inf 的计算改为符合数学定义.
    注释: 这可能导致性能下降, 因为现在对每个向量元素都要调用 std::abs(z). 旧实现使用 std::max(std::abs(real(z)),std::abs(imag(z)). 此外, norm_inf 和 norm_1 现在对复向量会返回相同的值.
  • [3501] 把 concepts.hpp 中的自由函数移入匿名命名空间.

Release 1.41.1

新特性

  • 向量/矩阵容器赋值的移动语义已经实现. 可以通过设置 BOOST_UBLAS_MOVE_SEMANTICS 来启用. 更多细节见 预处理器选项页面.
  • 引入新的自由函数. 参见 [3449]、libs/numeric/ublas/test 中的新测试, 以及 boost/numeric/ublas/operation/ 中各文件的内联文档.

缺陷修复

  • [3293] 修复 identity_matrix 中的大小调整问题
  • [3499] 在概念检查中加入 DefaultConstructible

Release 1.40.0 及更早

  • 此形式的发布说明当时不可用.
