矩阵

说明

模板类 matrix<T, F, A> 是稠密矩阵的基础容器适配器. 对于一个 (m x n) 维矩阵, 当 0 <= i < m, 0 <= j < n 时, 每个元素 mi, j 在行主序下被映射到容器的第 (i x n + j)-个元素, 在列主序下被映射到容器的第 (i + j x m)-个元素.

示例

#include <boost/numeric/ublas/matrix.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    matrix<double> m (3, 3);
    for (unsigned i = 0; i < m.size1 (); ++ i)
        for (unsigned j = 0; j < m.size2 (); ++ j)
            m (i, j) = 3 * i + j;
    std::cout << m << std::endl;
}

单位矩阵

说明

模板类 identity_matrix<T, ALLOC> 表示单位矩阵. 对于一个 (m x n) 维单位矩阵, 当 0 <= i < m, 0 <= j < n 时, 有 idi, j = 0 (若 i <> j), 且 idi, i= 1.

示例

#include <boost/numeric/ublas/matrix.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    identity_matrix<double> m (3);
    std::cout << m << std::endl;
}
