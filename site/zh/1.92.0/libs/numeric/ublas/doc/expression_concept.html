向量表达式

说明

向量表达式 (Vector Expression) 是可对向量求值的表达式. Vector Expression 提供 Indexed Bidirectional Iterator 或 Indexed Random Access Iterator .

细化自

可默认构造.

关联类型

公有基类 vector_expression<V> V 必须派生自这个公有基类型.
值类型 value_type 向量表达式的元素类型.
引用类型 reference 访问向量表达式的元素时的返回类型.
可转换为 value_type.
常量引用类型 const_reference 访问常量向量表达式的元素时的返回类型.
可转换为 value_type.
Size type size_type 向量表达式的索引类型. 用于表示大小和索引值的无符号整型.
能表示 difference_type 的任意非负值.
Distance type difference_type 用于表示向量表达式两个迭代器之间距离的有符号整型.
Const iterator type const_iterator 可用于检查向量表达式元素的迭代器类型.
Iterator type iterator 可用于修改向量表达式元素的迭代器类型.
Const reverse iterator type const_reverse_iterator 一种 Reverse Iterator 适配器, 其基础迭代器类型是向量表达式的 const 迭代器类型.
反向迭代器类型 reverse_iterator 一种 Reverse Iterator 适配器, 其基础迭代器类型是向量表达式的迭代器类型.

表达式语义

仅在表达式与 Default Constructible 不同或未在其中定义之处, 才给出其语义.

名称 表达式 前置条件 语义 后置条件
Beginning of range v.begin ()   返回指向向量表达式第一个元素的迭代器. v.begin () 或者可解引用, 或者是越末尾的 (past-the-end). 当且仅当 v.size () == 0 时它是越末尾的.

反向范围的末尾 v.rend ()   等价于 reverse_iterator (v.begin ()). v.rend () 是越末尾的.

复杂度保证

begin () 和 end () 的运行期复杂度由被求值的向量表达式决定, 通常为均摊常数时间.

size () 的运行期复杂度为常数时间.

swap () 的运行期复杂度由被求值的向量表达式决定, 通常为常数时间.

rbegin () 和 rend () 的运行期复杂度由被求值的向量表达式决定, 通常为均摊常数时间.

元素访问的运行期复杂度由被求值的向量表达式决定, 稠密情形通常为均摊常数时间, 稀疏情形为对数时间.

算术运算的运行期复杂度由被求值的向量表达式决定, 通常与表达式的大小呈线性关系.

不变式

有效范围 对任何向量表达式 v, [v.begin (), v.end ()) 是一个有效范围.
完整性 遍历范围 [v.begin (), v.end ()) 的算法将经过 v 的每个元素 .
Valid reverse range [v.rbegin (), v.rend ()) 是一个有效范围.
范围的等价性 从 v.begin () 到 v.end () 的距离与从 v.rbegin () 到 v.rend () 的距离相同.

矩阵表达式

说明

矩阵表达式 (Matrix Expression) 是可对矩阵求值的表达式. Matrix Expression 提供 Indexed Bidirectional Column/Row Iterator 或 Indexed Random Access Column/Row Iterator .

细化自

可默认构造.

可转换为 value_type.

能表示 difference_type 的任意非负值.
Distance type difference_type 用于表示矩阵表达式两个迭代器之间距离的有符号整型.
const 迭代器类型 const_iterator1 可用于检查矩阵表达式元素的列迭代器类型.

复杂度保证

begin1 ()、begin2 ()、end1 () 和 end2 () 的运行期复杂度由被求值的矩阵表达式决定.

size1 () 和 size2 () 的运行期复杂度为常数时间.

swap () 的运行期复杂度由被求值的矩阵表达式决定, 通常为常数时间.

rbegin1 ()、rbegin2 ()、rend1 () 和 rend2 () 的运行期复杂度由被求值的矩阵表达式决定.

元素访问的运行期复杂度由被求值的矩阵表达式决定, 稠密情形通常为均摊常数时间, 稀疏情形为对数时间.

算术运算的运行期复杂度由被求值的矩阵表达式决定, 通常与代理 (proxy) 的大小呈平方关系.

不变式

有效范围 对任何矩阵表达式 m, [m.begin1 (), m.end1 ()) 和 [m.begin2 (), m.end2 ()) 是有效范围.
完整性 遍历范围 [m.begin1 (), m.end1 ()) 的算法将经过 m 的每一行, 遍历范围 [m.begin2 (), m.end2 ()) 的算法将经过 m 的每一列 .
Valid reverse range [m.rbegin1 (), m.rend1 ()) 和 [m.rbegin2 (), m.rend2 ()) 是有效范围.
范围的等价性 从 m.begin1 () 到 m.end1 () 的距离与从 m.rbegin1 () 到 m.rend1 () 的距离相同, 且从 m.begin2 () 到 m.end2 () 的距离与从 m.rbegin2 () 到 m.rend2 () 的距离相同.
