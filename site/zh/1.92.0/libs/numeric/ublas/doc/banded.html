带状矩阵

说明

模板类 banded_matrix<T, F, A> 是带状矩阵的基础容器适配器. 对于一个 (m x n) 维、具有 l 条下对角线和 u 条上对角线的带状矩阵, 当 0 <= i < m, 0 <= j < n 时, 有 bi, j = 0 (若 i > j + l 或 i < j - u). 带状矩阵的存储是压缩的.

示例

#include <boost/numeric/ublas/banded.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    banded_matrix<double> m (3, 3, 1, 1);
    for (signed i = 0; i < signed (m.size1 ()); ++ i)
        for (signed j = std::max (i - 1, 0); j < std::min (i + 2, signed (m.size2 ())); ++ j)
            m (i, j) = 3 * i + j;
    std::cout << m << std::endl;
}

带状适配器

说明

模板类 banded_adaptor<M> 是用于其他矩阵的带状矩阵适配器.

示例

#include <boost/numeric/ublas/banded.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    matrix<double> m (3, 3);
    banded_adaptor<matrix<double> > ba (m, 1, 1);
    for (signed i = 0; i < signed (ba.size1 ()); ++ i)
        for (signed j = std::max (i - 1, 0); j < std::min (i + 2, signed (ba.size2 ())); ++ j)
            ba (i, j) = 3 * i + j;
    std::cout << ba << std::endl;
}
