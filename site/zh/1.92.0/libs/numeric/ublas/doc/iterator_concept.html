迭代器概念

Iterator 是一种受限的、类似指针的对象, 指向向量或矩阵容器内部.

索引双向迭代器

说明

索引双向迭代器 (Indexed Bidirectional Iterator) 是一种容器迭代器, 可以解引用、递增、递减, 并携带索引信息.

细化自

Assignable, Equality Comparable, Default Constructible.

关联类型

值类型 解引用一个索引双向迭代器所得到的值的类型
容器类型 索引双向迭代器所指向的容器的类型.

记法

I 一个作为 Indexed Bidirectional Iterator 模型的类型
T 值类型, 属于 I
C 容器类型, 属于 I
it, itt, it1, it2 Objects of type I
t Object of type T
c Object of type C

定义

索引双向迭代器可以是 可变的 (mutable), 即该类型对象所引用的值可以被修改; 也可以是 常量 (constant), 即不可以被修改. 如果一个迭代器类型是可变的, 这蕴含着它的值类型是 Assignable 的模型; 但反之不一定成立.

索引双向迭代器可以具有 奇异 (singular) 值, 即大多数操作 (包括相等比较) 的结果都是未定义的. 唯一保证支持的操作是把一个非奇异迭代器赋给一个奇异迭代器.

索引双向迭代器可以具有 可解引用 (dereferenceable) 的值, 即对它解引用会得到一个良定义的值. 可解引用的迭代器总是非奇异的, 但反之不然.

如果索引双向迭代器指向容器最后一个元素之后的位置, 它就是 越末尾的 (past-the-end). 越末尾的值是非奇异的且不可解引用.

索引随机访问迭代器

说明

索引随机访问迭代器 (Indexed Random Access Iterator) 是一种容器迭代器, 可以解引用、前移、后移, 并携带索引信息.

细化自

LessThanComparable, Indexed Bidirectional Iterator .

关联类型

值类型 值类型, 由解引用一个索引随机访问迭代器得到
容器类型 容器类型, 即索引随机访问迭代器所指向的容器.

记法

I 一个作为 Indexed Random Access Iterator 模型的类型
T 值类型, 属于 I
C 容器类型, 属于 I
it, itt, it1, it2 Objects of type I
t Object of type T
n Object of type C::difference_type

定义

索引随机访问迭代器 it1 是 可达 (reachable) 于索引随机访问迭代器 it2 的, 意指把 operator ++ 施加到 it2 上有限次之后, 有 it1 == it2.

有效表达式

除了 Indexed Bidirectional Iterator 所定义的表达式之外, 以下表达式必须有效.

名称 表达式 类型要求 返回类型
前向移动 it += n   I &
迭代器加法 it + n   I
后向移动 i -= n   I &
迭代器减法 it - n   I 
差 it1 - it2   C::difference_type
元素运算符 it [n]   可转换为 T.
元素赋值 it [n] = t I 是可变的 可转换为 T.

表达式语义

仅在表达式与 Indexed Bidirectional Iterator 不同或未在其中定义之处, 才给出其语义.

名称 表达式 前置条件 语义 后置条件
前向移动 it += n 包括 it 本身, 必须有 n 个可解引用或越末尾的迭代器位于 it 之后或之前, 取决于 n 是正还是负. 若 n > 0, 等价于执行 ++ it 共 n 次. 若 n < 0, 等价于执行 -- it 共 n 次. 若 n == 0, 则这是空操作. it 可解引用或越末尾.
迭代器加法 it + n 与 i += n 相同. 等价于
{
 I itt = it;
 return itt += n;
}		 结果是可解引用的或越末尾的.
后向移动 it -= n 包括 it 本身, 必须有 n 个可解引用或越末尾的迭代器位于 it 之前或之后, 取决于 n 是正还是负. 等价于 it += (-n). it 可解引用或越末尾.
迭代器减法 it - n 与 i -= n 相同. 等价于
{
 I itt = it;
 return itt -= n;
}		 结果是可解引用的或越末尾的.
差 it1 - it2 要么 it1 从 it2 可达, 要么 it2 从 it1 可达, 或两者皆可. 返回一个数 n 使得 it1 == it2 + n  
元素运算符 it [n] it + n 存在且可解引用. 等价于 *(it + n)  
元素赋值 i[n] = t 与 it [n] 相同. 等价于 *(it + n) = t  

复杂度保证

索引随机访问迭代器上操作的复杂度保证为均摊常数时间.

不变式

加法与减法的对称性 若 it + n 是良定义的, 则 it += n; it -= n; 和 (it + n) - n 是空操作. 类似地, 若 it - n 是良定义的, 则 it -= n; it += n; 和 (it - n) + n 是空操作.
距离与加法的关系 若 it1 - it2 是良定义的, 则 it1 == it2 + (it1 - it2).
可达性与距离 若 it1 从 it2 可达, 则 it1 - it2 >= 0.

模型

  • vector::iterator

复杂度保证

索引双向列/行迭代器上操作的复杂度保证为对数时间, 取决于容器的大小. 其中一个迭代器的复杂度 (取决于存储布局) 可以提升为均摊常数时间. 另一个迭代器的复杂度 (取决于存储布局和容器) 可以对第一行/第一列提升为均摊常数时间.

若 it 是行迭代器且 it2 = it.begin (), 则 it2.index1 () < it2t.index1 () 对所有 it2t 成立, 且它们满足 it2t () == it2 () 和 it2t ().index2 () == it2 ().index2 ().
迭代器列/行结束与迭代器索引之间的关系 若 it 是列迭代器且 it2 = it.end (), 则 it2.index2 () > it2t.index2 () 对所有 it2t 成立, 且它们满足 it2t () == it2 () 和 it2t ().index1 () == it2 ().index1 ().

若 it 是行迭代器且 it2 = it.end (), 则 it2.index1 () > it2t.index1 () 对所有 it2t 成立, 且它们满足 it2t () == it2 () 和 it2t ().index2 () == it2 ().index2 ().
