矩阵代理

矩阵行

说明

模板类 matrix_row<M> 允许寻址矩阵的一行.

示例

#include <boost/numeric/ublas/matrix.hpp>
#include <boost/numeric/ublas/matrix_proxy.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    matrix<double> m (3, 3);
    for (unsigned i = 0; i < m.size1 (); ++ i) {
        matrix_row<matrix<double> > mr (m, i);
        for (unsigned j = 0; j < mr.size (); ++ j)
            mr (j) = 3 * i + j;
        std::cout << mr << std::endl;
    }
}

定义

定义于头文件 matrix_proxy.hpp 中.

模板参数

参数 说明 默认值
M 被引用矩阵的类型.

所建模的概念

Vector Expression .

如果指定的行落在矩阵的行索引范围之外, 则 matrix_row 不是一个良构的 Vector Expression. 也就是说, 访问矩阵之外的元素是 未定义的.

类型要求

除 Vector Expression 概念的要求外, 别无其他.

自由函数 project 支持矩阵范围的构造. 已有的 matrix_range 可以与更多的范围组合. 所得范围用这些已有范围的 compose 函数计算.

原型


    template<class M>
    matrix_range<M> project (M &data, const range &r1, const range &r2);
    template<class M>
    const matrix_range<const M> project (const M &data, const range &r1, const range &r2);
    template<class M>
    matrix_range<M> project (matrix_range<M> &data, const range &r1, const range &r2);
    template<class M>
    const matrix_range<M> project (const matrix_range<M> &data, const range &r1, const range &r2);

定义

定义于头文件 matrix_proxy.hpp 中.

类型要求

  • M 是 Matrix Expression 的模型 .

复杂度

与范围的大小呈平方关系.

示例

#include <boost/numeric/ublas/matrix.hpp>
#include <boost/numeric/ublas/matrix_proxy.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    matrix<double> m (3, 3);
    for (unsigned i = 0; i < m.size1 (); ++ i)
        for (unsigned j = 0; j < m.size2 (); ++ j)
            project (m, range (0, 3), range (0, 3)) (i, j) = 3 * i + j;
    std::cout << project (m, range (0, 3), range (0, 3)) << std::endl;
}

矩阵切片

说明

模板类 matrix_slice<M> 允许寻址矩阵的一个切片子矩阵.

示例

#include <boost/numeric/ublas/matrix.hpp>
#include <boost/numeric/ublas/matrix_proxy.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    matrix<double> m (3, 3);
    matrix_slice<matrix<double> > ms (m, slice (0, 1, 3), slice (0, 1, 3));
    for (unsigned i = 0; i < ms.size1 (); ++ i)
        for (unsigned j = 0; j < ms.size2 (); ++ j)
            ms (i, j) = 3 * i + j;
    std::cout << ms << std::endl;
}

定义

定义于头文件 matrix_proxy.hpp 中.

模板参数

参数 说明 默认值
M 被引用矩阵的类型.

所建模的概念

Matrix Expression .

如果指定的切片落在矩阵的索引范围之外, 则 matrix_slice 不是一个良构的 Matrix Expression. 也就是说, 访问矩阵之外的元素是 未定义的.

类型要求

除 Matrix Expression 概念的要求外, 别无其他.

公有基类

matrix_expression<matrix_slice<M> >
