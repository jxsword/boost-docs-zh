定义

X, Y, Z 是张量
A, B, C 是矩阵
u, v, w 是向量
i, j, k 是整数值
t, t1, t2 是标量值
r, r1, r2 是 range, 例如 range(0, 3)
s, s1, s2 是 slice, 例如 slice(0, 1, 3)

基本线性代数

标准运算: 加法、减法、与标量相乘


X = Y + Z; X = Y - Z; X = -Y;
C = A + B; C = A - B; C = -A;
w = u + v; w = u - v; w = -u;
X = t * Y; Y = X * t; X = Y / t;
C = t * A; C = A * t; C = A / t;
w = t * u; w = u * t; w = u / t;

计算式赋值


X += Y; X -= Y; 
C += A; C -= A; 
w += u; w -= u; 
X *= t; X /= t; 
C *= t; C /= t; 
w *= t; w /= t;

内积、外积及其他乘积


t = inner_prod(u, v);
C = outer_prod(u, v);
w = prod(A, u); w = prod(u, A); w = prec_prod(A, u); w = prec_prod(u, A);
C = prod(A, B); C = prec_prod(A, B);
w = element_prod(u, v); w = element_div(u, v);
C = element_prod(A, B); C = element_div(A, B);

Z = prod(X, v, t);

范数


t = norm_inf(v); i = index_norm_inf(v);

乘积


axpy_prod(A, u, w, true);  // w = A * u
axpy_prod(A, u, w, false); // w += A * u
axpy_prod(u, A, w, true);  // w = trans(A) * u
axpy_prod(u, A, w, false); // w += trans(A) * u
axpy_prod(A, B, C, true);  // C = A * B
axpy_prod(A, B, C, false); // C += A * B

注释: 最后一个参数 (bool init) 属于 axpy_prod, 它是可选的. 目前它默认为 true, 但将来可能改变. 把 init 设为 true 等价于先调用 w.clear() 再调用 axpy_prod. 压缩矩阵的乘积有一些特化, 与 prod 相比可带来大幅提速.


w = block_prod<matrix_type, 64> (A, u); // w = A * u
w = block_prod<matrix_type, 64> (u, A); // w = trans(A) * u
C = block_prod<matrix_type, 64> (A, B); // C = A * B

注释: 块大小可以是任意整数. 但是, 实际速度在很大程度上取决于块大小、CPU 和编译器的组合. 函数 block_prod 是为大型稠密矩阵设计的.

秩 k 更新


opb_prod(A, B, C, true);  // C = A * B
opb_prod(A, B, C, false); // C += A * B

注释: 最后一个参数 (bool init) 属于 opb_prod, 它是可选的. 目前它默认为 true, 但将来可能改变. 如果 A 的列数少于行数, 该函数可能会带来提速, 因为乘积是作为外积之和计算的.

子矩阵与子向量

经 代理使用 project 函数访问子矩阵和子向量:


w = project(u, r);         // the subvector of u specifed by the index range r
w = project(u, s);         // the subvector of u specifed by the index slice s
C = project(A, r1, r2);    // the submatrix of A specified by the two index ranges r1 and r2
C = project(A, s1, s2);    // the submatrix of A specified by the two index slices s1 and s2
w = row(A, i); w = column(A, j);    // a row or column of matrix as a vector

经 代理使用 project 函数给子矩阵和子向量赋值:


project(u, r) = w;         // assign the subvector of u specifed by the index range r
project(u, s) = w;         // assign the subvector of u specifed by the index slice s
project(A, r1, r2) = C;    // assign the submatrix of A specified by the two index ranges r1 and r2
project(A, s1, s2) = C;    // assign the submatrix of A specified by the two index slices s1 and s2
row(A, i) = w; column(A, j) = w;    // a row or column of matrix as a vector

注释: range r = range(start, stop) 包含索引 i, 其中 start <= i < stop 成立. slice 则更为一般. slice s = slice(start, stride, size) 包含索引 start, start+stride, ..., start+(size-1)*stride. 步长可以是 0 或负数! 如果对 range 有 start >= stop 或对 slice 有 size == 0, 则它不包含任何元素.

向量与矩阵的子 range 和子 slice 可以直接用 subrange 和 sublice 函数创建:


w = subrange(u, 0, 2);         // the 2 element subvector of u
w = subslice(u, 0, 1, 2);      // the 2 element subvector of u
C = subrange(A, 0,2, 0,3);     // the 2x3 element submatrix of A
C = subslice(A, 0,1,2, 0,1,3); // the 2x3 element submatrix of A
subrange(u, 0, 2) = w;         // assign the 2 element subvector of u
subslice(u, 0, 1, 2) = w;      // assign the 2 element subvector of u
subrange(A, 0,2, 0,3) = C;     // assign the 2x3 element submatrix of A
subrange(A, 0,1,2, 0,1,3) = C; // assigne the 2x3 element submatrix of A

还有两种把某些矩阵元素当作向量访问的方法:

matrix_vector_range<matrix_type> (A, r1, r2);
matrix_vector_slice<matrix_type> (A, s1, s2);

注释: 这些矩阵代理取矩阵的一段元素序列, 并允许你把它们当作向量访问. 特别是 matrix_vector_slice 可以以非常一般的方式做到这一点. matrix_vector_range 用处较小, 因为元素必须沿一条对角线排列.

示例: 要访问矩阵某个子列的前两个元素, 我们用步长为 1 的 slice 访问行, 用步长为 0 的 slice 访问列, 即:
matrix_vector_slice<matrix_type> (A, slice(0,1,2), slice(0,0,2));

速度改进

矩阵 / 向量赋值

如果你确信左侧表达式和右侧表达式没有公共存储, 那么赋值就没有 别名问题. 此时可以指定一种更高效的赋值:

noalias(C) = prod(A, B);

这避免了在普通赋值中创建临时矩阵的需要. 'noalias' 赋值要求左边和右边尺寸一致.

稀疏元素访问

当作用于稀疏矩阵或稀疏向量时, 矩阵元素访问函数 A(i1,i2) 或等价的向量元素访问函数 (v(i) or v[i]) 通常会创建 '稀疏元素代理'. 这些 代理允许访问元素而不必担心 C++ 中引用失效之类的麻烦问题.

当作用于 const 对象时, 这些 '稀疏元素代理' 可以实现得更高效. 遗憾的是, 在 C++ 中无法区分赋值左侧和右侧的元素访问. 右侧的元素大多数情况下不会被修改, 因此最好使用 const 代理. 我们可以在访问元素之前把矩阵或向量变为 const 来做到这一点. 例如:

value = const_cast<const VEC>(v)[i];   // VEC is the type of V

如果需要访问多个元素, 出于同样的原因应优先使用 const_iterator 而不是 iterator. 更大胆的做法是, 通过定义配置宏 BOOST_UBLAS_NO_ELEMENT_PROXIES 可以在 uBLAS 中完全关闭 '稀疏元素代理'.

控制嵌套乘积的复杂度

计算下式所需的复杂度 (加法和乘法运算的次数) 是多少?

 R = prod(A, prod(B,C));

首先, 复杂度取决于矩阵大小. 而且由于 prod 是传递的 (非交换的), 括号顺序会影响复杂度.

uBLAS 求值表达式时不使用矩阵或向量临时对象, 并遵守括号结构. 然而, 对嵌套乘积避免使用临时对象会不必要地增加复杂度. 反过来, 显式使用临时矩阵可以降低嵌套乘积的复杂度.

为此 uBLAS 提供了 3 种可选语法:

 temp_type T = prod(B,C); R = prod(A,T);   // Preferable if T is preallocated

 prod(A, temp_type(prod(B,C));

 prod(A, prod<temp_type>(B,C));

'temp_type' 很重要. 设 A、B、C 都是同一类型, 比如 matrix<float>, 选择就很容易. 但是如果 value_type 是混合的 (int 与 float 或 double), 或矩阵类型是混合的 (sparse 与 symmetric), 最佳解决方案就不那么明显了. 这取决于你! 它取决于 A 的数值属性以及 prod(B,C) 的结果.
