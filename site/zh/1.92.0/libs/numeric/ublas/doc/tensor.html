张量

张量

说明

模板类 tensor<value_t,format_t,storage_t> 是稠密张量的基础容器适配器. $p$ 阶 $(n_1 \times n_2 \times \cdots \times n_p)$ 维张量 $T$ 的每个元素 $t_{i_1,i_2,\dots,i_p}$ 都被映射到一维容器的第 $j$ 个元素, 其中 $j = \sum_{r=1}^p i_r \cdot w_r$, 且对 $1 \leq r \leq p$ 有 $1 \leq i_r \leq n_r $. 对于一阶取向 (first-order), $w_1 = 1$ 且对 $k > 1$ 有 $w_k = n_{k-1} \cdot w_{k-1}$. 对于末阶取向 (last-order), $w_p = 1$ 且对 $k < p$ 有 $ w_k = n_{k+1} \cdot w_{k+1}$.

示例

#include <boost/numeric/ublas/tensor.hpp>

int main () {
  using namespace boost::numeric::ublas;
  tensor<double> t{4,2,3};
  for (auto k = 0ul; k < t.size (2); ++ k)
    for (auto j = 0ul; j < t.size (1); ++ j)
      for (auto i = 0ul; i < t.size (0); ++ i)
        t.at(i,j,k) = 3*i + 2*j + 5*k;
        
  std::cout << t << std::endl;
}

定义

定义于头文件 tensor/tensor.hpp 中.

所建模的概念

张量

类型要求

除 Tensor 概念的要求外, 别无其他.

公有基类

tensor_container<tensor<value_t,format_t,storage_t> >

模板参数

参数 说明 默认值
value_t 张量中存储对象的类型.
format_t 存储组织. [1] first_order
storage_t Storage 数组的类型. [2] std::vector<value_t>

成员类型

成员类型 说明
value_type 张量元素的类型 value_t.
layout_type 张量的格式, 为 first_order 或 last_order.
array_type 存储所有张量元素并可用单个索引访问的序列容器类型.
strides_type 步长 (strides) 向量 basic_strides<std::size_t,layout_type> 的类型, 该向量存储所有张量元素并可用单个索引访问.
extents_type 维度大小 (extents) 向量 shape 的类型, 该向量存储所有张量元素并可用单个索引访问.
size_type 无符号整数, 通常为 std::size_t.
difference_type 无符号整数, 通常为 std::ptrdiff_t.
reference 引用类型 storage_type::reference, 在大多数情况下为 value_type&.
const_reference 常量引用类型 storage_type::const_reference, 在大多数情况下为 const value_type&.
pointer 指针类型 storage_type::pointer, 在大多数情况下为 value_type*.
const_pointer 常量引用类型 storage_type::const_reference, 在大多数情况下为 const value_type*.
iterator RandomAccessIterator storage_type::iterator.
const_iterator 常量 RandomAccessIterator storage_type::const_iterator.
reverse_iterator 反向 RandomAccessIterator storage_type::reverse_iterator.
const_reverse_iterator 反向 RandomAccessIterator storage_type::const_reverse_iterator.
matrix_type 与该张量类型交互的矩阵 matrix<value_type,layout_type,array_type> 的类型.
vector_type 与该张量类型交互的向量 matrix<value_type,layout_type,array_type> 的类型.

别名模板

别名模板 说明
template<class derived_type>
using tensor_expression_type = detail::tensor_expression<self_type,derived_type>		 tensor_expression 的类型, 其中 self_type 是 tensor 类型.
template<class derived_type>
using matrix_expression_type = matrix_expression<derived_type>		 matrix_expression 的类型.
template<class derived_type>
using vector_expression_type = vector_expression<derived_type>		 vector_expression 的类型.

成员函数

构造

成员函数 说明
tensor () 构造一个未初始化的 tensor, 保存零个元素.
tensor (std::initializer_list<size_type> list) 构造一个未初始化的 tensor, 其中 list 指定维度 extents.
tensor (extents_type const& s) 构造一个未初始化的 tensor, 其中 s 指定维度 extents.
tensor (extents_type const& e, array_type const& a) 构造一个未初始化的 tensor, 其中 e 指定维度 extents, a 指定张量的数据元素.
tensor (tensor<value_type,other_layout&rt; const& other) 通过从 other 复制元素来构造张量, 其布局与本布局类型不同.
tensor (tensor const& other) 通过从 other 复制元素来构造张量.
tensor (tensor && other) 通过从 other 移动元素来构造张量.
tensor (matrix_type const& other) 通过从 other matrix 复制元素来构造张量. 张量的阶将为 2.
tensor (matrix_type && other) 通过从 other matrix 移动元素来构造张量. 张量的阶将为 2.
tensor (vector_type const& other) 通过从 other vector 复制元素来构造张量. 张量的阶将为 1.
tensor (vector_type && other) 通过从 other vector 移动元素来构造张量. 张量的阶将为 1.
tensor (tensor_expression_type<derived_type> const& expr) 通过求值 tensor expression expr 并复制结果的所有元素来构造张量.
tensor (matrix_expression_type<derived_type> const& expr) 通过求值 matrix expression expr 并复制结果的所有元素来构造张量.
tensor (vector_expression_type<derived_type> const& expr) 通过求值 vector expression expr 并复制结果的所有元素来构造张量.

赋值

成员函数 说明
tensor& operator=(tensor_expression_type<derived_type> const& expr) 求值 tensor expression expr 并复制结果的所有元素.
tensor& operator=(tensor other) 复制或移动 other 的元素.
tensor& operator=(const_reference v) 用 v 初始化张量的所有元素.

修改器

成员函数 说明
void reshape(extents_type const& e, value_type v = value_type{}) 按 e 的维度大小重塑张量. 若 e.product() 大于 tensor::size(), 则张量用 v 调整大小.

注释

[1] 存储组织支持的参数是 first_order 和 last_order.

[2] 存储数组常用的参数是 std::array<N,T> 和 std::vector<T>.
