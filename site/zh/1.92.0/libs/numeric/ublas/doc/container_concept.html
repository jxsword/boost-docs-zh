容器概念

向量

说明

Vector 描述稠密、紧凑和稀疏向量的共同特性.

细化自

DefaultConstructible, Vector Expression [1].

关联类型

除 Vector Expression

公有基类 vector_container<V> V 必须派生自这个公有基类型.
存储数组 V::array_type 仅限稠密向量. 用于存储元素的底层存储数组的类型. array_type 必须满足 Storage 概念.

记法

V 一个作为 Vector 模型的类型
v Objects of type V
n, i 对象, 其类型可转换为 size_type
t 对象, 其类型可转换为 value_type
p 对象, 其类型可转换为 bool

定义

有效表达式

除了 DefaultConstructible 和 Vector Expression 中定义的表达式之外, 以下表达式必须有效.

名称 表达式 类型要求 返回类型
指定大小的构造函数 V v (n)   V
插入 v.insert_element (i, t) v 是可变的. void
擦除 v.erase_element (i) v 是可变的. void
清空 v.clear () v 是可变的. void
调整大小 v.resize (n)
v.resize (n, p)		 v 是可变的. void
存储 v.data() v 是可变且稠密的. array_type& (若 v 可变), const array_type& (否则)

表达式语义

仅在表达式与 Vector Expression 不同或未在其中定义之处, 才给出其语义 .

名称 表达式 前置条件 语义 后置条件
指定大小的构造函数 V v (n) n >= 0 分配一个n 个元素的向量. v.size () == n.
元素访问 [2] v[n] 0<n>v.size() 返回 v 中第 n 个元素  
插入 v.insert_element (i, t) 0 <= i < v.size (). 在 v (i) 处插入一个值为 t 的元素. Vector 的存储需求可能增加. v (i) 等于 t.
擦除 v.erase_element (i) 0 <= i < v.size () 销毁位于 v (i) 的元素, 并用默认的 value_type () 替换它. Vector 的存储需求可能减少. v (i) 等于 value_type ().
清空 v.clear ()   等价于
for (i = 0; i < v.size (); ++ i)
v.erase_element (i);		  
调整大小 v.resize (n)
v.resize (n, p)		   重新分配向量, 使其能容纳 n 个元素.
擦除或追加元素, 使向量达到规定的大小. 追加的元素是 value_type() 的副本.
当 p == false 时, 既有元素不被保留, 元素也不会像通常那样被追加. 相反, 向量将处于与经过等价的指定大小构造函数之后相同的状态.		 v.size () == n.
存储 v.data() 返回指向底层稠密存储的引用.  

复杂度保证

指定大小构造函数的运行期复杂度与向量的大小呈线性关系.

insert_element 和 erase_element 的运行期复杂度由 Vector 模型决定, 并取决于存储需求的增减.

resize 的运行期复杂度与向量的大小呈线性关系.

不变式

模型

  • vector, bounded_vector, c_vector
  • unit_vector, zero_vector, scalar_vector
  • mapped_vector;, compressed_vector, coordinate_vector

注释

[1] 作为用户, 你无需关心 Vector 是 VectorExpression 的细化. 是 VectorExpression 的细化只对模板表达式引擎重要, 对用户并不重要.

[2] 加入 operator[] 纯粹是为了方便以及与 std::vector 兼容. 不过在 uBLAS 中, 一般使用 operator() 进行索引, 因为它对向量和矩阵都适用.

矩阵

说明

Matrix 描述稠密、紧凑和稀疏矩阵的共同特性.

细化自

DefaultConstructible, Matrix Expression [1] .

关联类型

除 Matrix Expression

公有基类 matrix_container<M> M 必须派生自这个公有基类型.
存储数组 M::array_type 仅限稠密矩阵. 用于存储元素的底层存储数组的类型. array_type 必须满足 Storage 概念.

记法

M 一个作为 Matrix 模型的类型
m Objects of type M
n1, n2, i, j 对象, 其类型可转换为 size_type
t 对象, 其类型可转换为 value_type
p 对象, 其类型可转换为 bool

定义

有效表达式

除了 Matrix Expression 中定义的表达式之外, 以下表达式必须有效.

名称 表达式 类型要求 返回类型
指定大小的构造函数 M m (n1, n2)   M
插入 m.insert_element (i, j, t) m 是可变的. void
擦除 m.erase_element (i, j) m 是可变的. void
清空 m.clear () m 是可变的. void
调整大小 m.resize (n1, n2)
m.resize (n1, n2, p)		 m 是可变的. void
存储 m.data() m 是可变且稠密的. array_type& (若 m 可变), const array_type& (否则)

表达式语义

仅在表达式与 Matrix Expression 不同或未在其中定义之处, 才给出其语义 .

名称 表达式 前置条件 语义 后置条件
指定大小的构造函数 M m (n1, n2) n1 >= 0 and n2 >= 0 分配一个 n1 行 n2 列的矩阵. m.size1 () == n1 与 m.size2 () == n2.
插入 m.insert_element (i, j, t) 0 <= i < m.size1 (),
0 <= j < m.size2 ().		 在 m (i, j) 处插入一个值为 t 的元素. Matrix 的存储需求可能增加. m (i, j) 等于 t.
擦除 m.erase_element (i, j) 0 <= i < m.size1 ()and
0 <= j < m.size2		 销毁位于 m (i, j) 的元素, 并用默认的 value_type () 替换它. Matrix 的存储需求可能减少. m (i, j) 等于 value_type ().
清空 m.clear ()   等价于
for (i = 0; i < m.size1 (); ++ i)
for (j = 0; j < m.size2 (); ++ j)
m.erase_element (i, j);		  
调整大小 m.resize (n1, n2)
m.resize (n1, n2, p) 		  重新分配矩阵, 使其能容纳 n1 行 n2 列.
擦除或追加元素, 使矩阵达到规定的大小. 追加的元素是 value_type() 的副本.
当 p == false 时, 既有元素不被保留, 元素也不会像通常那样被追加. 相反, 矩阵将处于与经过等价的指定大小构造函数之后相同的状态.		 m.size1 () == n1 与 m.size2 () == n2.
存储 m.data() 返回指向底层稠密存储的引用.  

复杂度保证

指定大小构造函数的运行期复杂度与矩阵的大小呈平方关系.

insert_element 和 erase_element 的运行期复杂度由 Matrix 模型决定, 并取决于存储需求的增减.

resize 的运行期复杂度与矩阵的大小呈平方关系.

不变式

模型

  • matrix, bounded_matrix, c_matrix
  • identity_matrix , zero_matrix , scalar_matrix
  • triangular_matrix , symmetric_matrix , banded_matrix
  • mapped_matrix , compressed_matrix , coordinate_matrix

注释

[1] 作为用户, 你无需关心 Matrix 是 MatrixExpression 的细化. 是 MatrixExpression 的细化只对模板表达式引擎重要, 对用户并不重要.

张量

说明

Tensor 描述稠密多维数组的共同特性.

细化自

DefaultConstructible, Tensor Expression [1] .

关联类型

除 Tensor Expression

公有基类 tensor_container<tensor_t> tensor_t 必须派生自这个公有基类型.
存储数组 tensor_t::array_type Dense tensor ONLY. The type of underlying storage array used to store the elements. The array_type must model the Storage concept.

Notation

tensor_t 一个作为 Tensor 模型的类型
t Objects of type tensor_t
n1, n2, np, m1, m2, mq 维度对象, 其类型可转换为 size_type
i1, i2, ip, j, k 索引对象, 其类型可转换为 size_type
v 对象, 其类型可转换为 value_type

定义

有效表达式

除了 Tensor Expression 中定义的表达式之外, 以下表达式必须有效.

名称 表达式 类型要求 返回类型
指定大小的构造函数 T t(n1, n2, ..., np)   T
写入 t.at(i1, i2, ..., ip) t 是可变的. void
读取 t.at(i1, i2, ..., ip) t 是可变的. v
清空 t.clear () t 是可变的. void
调整大小 t.resize(m1, m2, ... , mq) t 是可变的. void
存储 t.data() t 是可变且稠密的. pointer (若 t 可变), const_pointer (否则)

表达式语义

仅在表达式与 Tensor Expression 不同或未在其中定义之处, 才给出其语义 .

名称 表达式 前置条件 语义 后置条件
指定大小的构造函数 T t(n1, n2, ..., np) $n_r \geq 1$ for $1\leq 1 \leq p $ 分配一个 $n_1,n_2,\dots,n_p$ 维的 p 阶张量. t.size(r)==nr for $1\leq r \leq p$.
写入 t.at(i1,i2,...,ip)=v $0 \leq i_r < n_r$ for $1 \leq r \leq p$. 在多索引位置 $i_1,i_2,\dots,i_p$ 写入一个值为 v 的元素. t(i1,i2,...,ip) 等于 v.
读取 v=t.at(i1,i2,...,ip) $0 \leq i_r < n_r$ for $1 \leq r \leq p$. 读取多索引位置 $(i_1,i2_,\dots,i_p)$ 处的元素并返回一个 v 值. t(i1,i2,...,ip) 等于 v.
清空 t.clear()   从容器中移除所有元素.  
调整大小 t.resize(m1, m2, ..., mq) $m_r \geq 1$ for $1\leq 1 \leq q $ 重新分配张量, 使其能容纳 $m_1\times m_2\times \cdots \times m_q$ 个元素.
擦除或追加元素, 使张量达到规定的大小. 追加的元素是 value_type() 的副本.		 t.size(r) == mr for $1\leq r \leq q$.
存储 m.data() 返回指向底层稠密存储的引用.  

复杂度保证

构造函数的运行期复杂度与张量的大小 $n_1 \times n_2 \times \cdots \times n_p$ 呈线性关系.

write() 和 read() 的运行期复杂度与张量的阶呈线性关系.

resize 的运行期复杂度与张量的大小 $m_1 \times m_2 \times \cdots \times n_q$ 至多呈线性关系.

不变式

模型

  • tensor

注释

[1] 作为用户, 你无需关心 Tensor 是 TensorExpression 的细化. 是 TensorExpression 的细化只对模板表达式引擎重要, 对用户并不重要.
