Range 与 Slice 存储

Range<SizeType,DistanceType>

说明

类 range 指定一个索引范围. range 是从起始值到终止值的索引序列. 索引每次递增 1, 且不包含终止值. range 因此可用于指定向量和矩阵元素的 range.

示例

#include <boost/numeric/ublas/storage.hpp>

int main () {
    using namespace boost::numeric::ublas;
    range r (0, 3);
    for (unsigned i = 0; i < r.size (); ++ i) {
        std::cout << r (i) << std::endl;
    }
}

定义

定义于头文件 storage.hpp 中.

所建模的概念

Reversible Container.

类型要求

除 Reversible Container 概念的要求外, 别无其他.

公有基类

无.

成员

成员 说明
range (size_type start, size_type stop) 构造一个从 start 到 stop (excluded) 的索引 range .
size_type start () const 返回 range 的开头.
size_type size () const 返回 range 的大小.
const_reference operator [] (size_type i) const 返回值 start + i, 属于第 i 个元素.
range compose (const range &r) const 返回从 start + r.start () 到 start + r.start () + r.size () 的复合 range.
bool operator == (const range &r) const 测试两个 range 是否相等.
bool operator != (const range &r) const 测试两个 range 是否不等.
const_iterator begin () const 返回一个 const_iterator, 指向 range 的开头.
const_iterator end () const 返回一个 const_iterator, 指向 range 的末尾.
const_reverse_iterator rbegin () const 返回一个 const_reverse_iterator, 指向反转后的 range 的开头.
const_reverse_iterator rend () const 返回一个 const_reverse_iterator, 指向反转后的 range 的末尾.

前置条件

  • start () <= stop ()

Slice<SizeType,DistanceType>

说明

类 slice 指定索引的一个 'slice'. slice 比 range 更一般: 步长 (stride) 允许索引序列在元素之间按指定数量递增或递减. slice 因此可用于指定向量和矩阵元素的 slice.

示例

#include <boost/numeric/ublas/storage.hpp>

int main () {
    using namespace boost::numeric::ublas;
    slice s (0, 1, 3);
    for (unsigned i = 0; i < s.size (); ++ i) {
        std::cout << s (i) << std::endl;
    }
}

定义

定义于头文件 storage.hpp 中.

所建模的概念

Reversible Container.

类型要求

除 Reversible Container 概念的要求外, 别无其他.

公有基类

无.

成员

成员 说明
slice (size_type start, size_type stride, size_type size) 构造一个 slice start,start+stride,start+2*stride..., 具有 size 个元素.
size_type start () const 返回 slice 的开头.
size_type stride () const 返回 slice 的步长.
size_type size () const 返回 slice 的大小.
const_reference operator [] (size_type i) const 返回第 start + i * stride 个元素的值 i.
slice compose (const range &r) const 返回从 start + stride * r.start () 到 start + stride * (r.start () + r.size ())、步长为 stride 的复合 slice.
slice compose (const slice &s) const 返回从 start + stride * s.start () 到 start + stride * s.stride () * (s.start () + s.size ())、步长为 stride * s.stride () 的复合 slice .
bool operator == (const slice &s) const 测试两个 slice 是否相等.
bool operator != (const slice &s) const 测试两个 slice 是否不等.
const_iterator begin () const 返回一个 const_iterator, 指向 slice 的开头.
const_iterator end () const 返回一个 const_iterator, 指向 slice 的末尾.
const_reverse_iterator rbegin () const 返回一个 const_reverse_iterator, 指向反转后的 slice 的开头.
const_reverse_iterator rend () const 返回一个 const_reverse_iterator, 指向反转后的 slice 的末尾.

前置条件

  • 所有步长都是有效的. 但是, 当返回一个索引或解引用一个迭代器时, 其值必须可以用 size_type 表示.
