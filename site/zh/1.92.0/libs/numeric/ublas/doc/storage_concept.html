Storage 概念

说明

Storage 是一种大小可变的容器, 其元素按严格的线性顺序排列.

Storage 用一些类似 STL Sequence 的功能扩展了 STL Container 概念. 但与 Sequence 概念的主要区别在于: Storage 概念不要求对其元素进行默认初始化.

细化自

Random Access Container 和 Default Constructible

关联类型

除 Random Access Container 定义的类型外无其他类型

记法

X一个作为 Storage 模型的类型
Tvalue_type, 属于 X
t对象, 类型为 T
n对象, 其类型可转换为 X::size_type

定义

有效表达式

除了 Random Access Container 和 Default Constructible 中定义的表达式之外, 以下表达式必须有效:
名称表达式类型要求返回类型
指定大小的构造函数 X(n) T 是 DefaultConstructible X
填充构造函数 X(n,t) X
范围构造函数 X(i, j) i 和 j 是 Input Iterators, 其值类型可转换为 T X
调整大小 a.resize(n, t) a 是可变的 void
调整大小 a.resize(n) a 是可变的 void

表达式语义

名称表达式前置条件语义后置条件
默认构造函数 X() 创建 0 个元素. size()==0
指定大小的构造函数 X(n) n>=0 创建 n 个元素. 元素构造时不带初始化器. 也就是说, 如果 T 是 (可能带 cv 限定的) 非 POD 类类型 (或其数组), 则对象被默认初始化; 否则, 创建的对象具有不确定的值. 参见 ISO C++ 标准 5.3.4 节第 15 段中的句子 "If new initializer is omitted". size()==n
填充构造函数 X(n,t) n>=0 创建 n 个已初始化的元素, 它们是 t size()==n
范围构造函数 X(i, j) [i,j) 是一个有效范围. 把范围 [i,j) 复制到该存储 size() 等于从 i 到 j 的距离. 每个元素都是范围 [i,j) 中对应元素的副本.
调整大小 a.resize(n, t) n <= a.max_size() 修改容器, 使其恰好有 n 个元素.
如果容器大小改变, 它可能被重新分配. 既有元素的值被保留, 新增元素是 t 的副本.		 a.size() == n
调整大小 a.resize(n) n <= a.max_size() 修改容器, 使其恰好有 n 个元素.
如果容器大小改变, 它可能被重新分配. 元素值未初始化. 也就是说, 每个元素值可能是先前赋的值, 或者是 T 的默认构造值.		 a.size() == n
