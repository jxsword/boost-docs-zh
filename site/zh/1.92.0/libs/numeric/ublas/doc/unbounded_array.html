无界数组存储

无界数组

说明

模板类 unbounded_array<T, ALLOC> 使用分配器实现一个无界存储数组. 无界数组类似于 std::vector, 因为它可以增长到超过任何固定界限的大小. 然而 unbounded_array 以最佳性能为目标. 因此 unbounded_array 不像 Sequence 那样是一个 std::vector 模型.

调整大小时, 即使新的大小要求更小, unbounded_array 也会重新分配其存储. 因此, 对以下类型调整大小是低效的: unbounded_array

示例

#include <boost/numeric/ublas/storage.hpp>

int main () {
    using namespace boost::numeric::ublas;
    unbounded_array<double> a (3);
    for (unsigned i = 0; i < a.size (); ++ i) {
        a [i] = i;
        std::cout << a [i] << std::endl;
    }
}
