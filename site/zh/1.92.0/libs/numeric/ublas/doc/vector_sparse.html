映射向量

说明

模板类 mapped_vector<T, A> 是使用元素映射的稀疏向量的基础容器适配器. 对于一个 n 维稀疏向量, 当 0 <= i < n 时, 非零元素 vi 被映射到关联容器的连续元素, 即对元素 k = vi1与 k + 1 = vi2, 容器满足 i1 < i2.

示例

#include <boost/numeric/ublas/vector_sparse.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    mapped_vector<double> v (3, 3);
    for (unsigned i = 0; i < v.size (); ++ i)
        v (i) = i;
    std::cout << v << std::endl;
}

压缩向量

说明

模板类 compressed_vector<T, IB, IA, TA> 是压缩向量的基础容器适配器. 对于一个 n 维压缩向量, 当 0 <= i < n 时, 非零元素 vi 被映射到索引容器和值容器的连续元素, 即对元素 k = vi1与 k + 1 = vi2, 这些容器满足 i1 < i2.

示例

#include <boost/numeric/ublas/vector_sparse.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    compressed_vector<double> v (3, 3);
    for (unsigned i = 0; i < v.size (); ++ i)
        v (i) = i;
    std::cout << v << std::endl;
}

说明
