向量范围

说明

模板类 vector_range<V> 允许寻址向量元素的一个子 range.

示例

#include <boost/numeric/ublas/vector.hpp>
#include <boost/numeric/ublas/vector_proxy.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    vector<double> v (3);
    vector_range<vector<double> > vr (v, range (0, 3));
    for (unsigned i = 0; i < vr.size (); ++ i)
        vr (i) = i;
    std::cout << vr << std::endl;
}

定义

定义于头文件 vector_proxy.hpp 中.

模板参数

参数 说明 默认值
V 被引用向量的类型.

所建模的概念

Vector Expression .

如果指定的范围落在向量的索引范围之外, 则 vector_range 不是一个良构的 Vector Expression. 也就是说, 访问向量索引范围之外的元素是 未定义的.

类型要求

除 Vector Expression 概念的要求外, 别无其他.

公有基类

vector_expression<vector_range<V> >

简单投影

说明

自由函数 subrange 支持向量 range 的构造.

原型


    template<class V>
    vector_range<V> subrange (V &data,
       V::size_type start, V::size_type stop);
    template<class V>
    const vector_range<const V> subrange (const V &data,
       V::size_type start, V::size_type stop);

泛型投影

说明

自由函数 project 支持向量 range 的构造. 已有的 matrix_range 可以与另一个 range 组合. 所得 range 用这个已有 range 的 compose 函数计算.

原型


    template<class V>
    vector_range<V> project (V &data, const range &r);
    template<class V>
    const vector_range<const V> project (const V &data, const range &r);
    template<class V>
    vector_range<V> project (vector_range<V> &data, const range &r);
    template<class V>
    const vector_range<V> project (const vector_range<V> &data, const range &r);

定义

定义于头文件 vector_proxy.hpp 中.

类型要求

  • V 是 Vector Expression 的模型 .

复杂度

与 range 的大小呈线性关系.

示例

#include <boost/numeric/ublas/vector.hpp>
#include <boost/numeric/ublas/vector_proxy.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    vector<double> v (3);
    for (int i = 0; i < 3; ++ i)
        project (v, range (0, 3)) (i) = i;
    std::cout << project (v, range (0, 3)) << std::endl;
}

向量切片

说明

模板类 vector_slice<V> 允许寻址向量的一个 slice.

示例

#include <boost/numeric/ublas/vector.hpp>
#include <boost/numeric/ublas/vector_proxy.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    vector<double> v (3);
    vector_slice<vector<double> > vs (v, slice (0, 1, 3));
    for (unsigned i = 0; i < vs.size (); ++ i)
        vs (i) = i;
    std::cout << vs << std::endl;
}
