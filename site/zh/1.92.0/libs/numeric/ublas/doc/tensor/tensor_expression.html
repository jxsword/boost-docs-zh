张量表达式

说明

模板类 tensor_expression<T,E> 被要求是所有类的公有基类. 未定义 Tensor Expression 概念.

定义

定义于头文件 tensor/expression.hpp 中.

所建模的概念

无. 不是 Tensor Expression!

类型要求

无.

公有基类

ublas_expression<E>.

模板参数

参数 说明
T 张量的类型.
E 张量表达式的类型.

成员类型

成员类型 说明
expression_type 派生表达式的类型, 为 E.
type_category 用于分类的标签, 为 tensor_tag.
tensor_type 引用类型, 为 T.

公有成员函数

成员 说明
const expression_type &operator()() const 返回对派生表达式的 const 引用.


逐元素张量运算

二元张量表达式

说明

模板类 binary_tensor_expression<T,EL,ER,OP> 包含对左表达式和右表达式的常量引用, 二者可用访问运算符求值.

定义

定义于头文件 tensor/expression.hpp 中.

所建模的概念

张量表达式

类型要求

无.

公有基类

tensor_expression<T,binary_tensor_expression<T,EL,ER,OP>>

模板参数

参数 说明
T 张量的类型.
EL 左二元张量表达式的类型.
ER 右二元张量表达式的类型.
OP 二元运算的类型.

成员类型

成员类型 说明
expression_type_left 左表达式的类型, 为 EL.
expression_type_right 右表达式的类型, 为 ER.
tensor_type 引用类型, 为 T.
binary_operation 二元运算的类型, 为 OP.

公有成员函数

成员 说明
decltype(auto) operator()(std::size_t i) const 返回表达式的 const 引用, 指向第 i 个元素.

一元张量表达式

说明

模板类 unary_tensor_expression<T,E,OP> 包含对一个表达式的常量引用, 该表达式可用访问运算符求值.

定义

定义于头文件 tensor/expression.hpp 中.

所建模的概念

张量表达式

类型要求

无.

公有基类

tensor_expression<T,unary_tensor_expression<T,E,OP>>

模板参数

参数 说明
T 张量的类型.
E 一元张量表达式的类型.
OP 一元运算的类型.

成员类型

成员类型 说明
expression_type 表达式的类型, 为 E.
tensor_type 引用类型, 为 T.
unary_operation 一元运算的类型, 为 OP.

公有成员函数

成员 说明
decltype(auto) operator()(std::size_t i) const 返回表达式的 const 引用, 指向第 i 个元素.
