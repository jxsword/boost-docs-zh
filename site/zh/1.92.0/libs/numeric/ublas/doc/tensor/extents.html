维度大小

basic_extents<size_type>

说明

模板类 basic_extents 指定一个 tensor 实例的维度大小.

示例

#include <boost/numeric/ublas/tensor/extents.hpp>

int main () {
    using namespace boost::numeric::ublas;
    shape s{4,3,2};
    for (auto i = 0u; i < s.size(); ++i) {
        std::cout << s.at(i) << std::endl;
    }
}

定义

定义于头文件 tensor/extents.hpp 中.

公有基类

无.

特化

using shape = basic_extents<std::size_t>

模板参数

参数 说明
size_type 无符号整数类型.

成员类型

成员类型 说明
value_type 维度大小的类型 size_type.
size_type 无符号整数, 如 std::size_t.
reference 引用类型, 为 value_type&.
const_reference 常量引用类型, 为 const value_type&.
pointer 指针类型, 为 value_type*.
const_pointer 常量引用类型, 为 const value_type*.
