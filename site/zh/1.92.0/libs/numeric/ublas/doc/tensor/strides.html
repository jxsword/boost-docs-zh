步长

basic_strides<size_type, format_type>

说明

模板类 basic_strides 包含给定存储格式的权重, 用于把多索引映射到 tensor 实例的标量内存索引.

示例

#include <boost/numeric/ublas/tensor/strides.hpp>

int main () {
    using namespace boost::numeric::ublas;
    auto wf = strides<first_order>(shape{4,3,2});
    for (auto i = 0u; i < wf.size(); ++i)
        std::cout << wf.at(i) << std::endl;    
        // 1,4,12
        
    auto wl = strides<first_order>(shape{4,3,2});
    for (auto i = 0u; i < wl.size(); ++i)
        std::cout << wl.at(i) << std::endl;    
        // 6,2,1        
}

定义

定义于头文件 tensor/strides.hpp 中.

公有基类

无.

特化

template<class format_t>
using strides = basic_strides<std::size_t,format_t>

模板参数

参数 说明
size_type 无符号整数类型.

成员类型

成员类型 说明
value_type 步长的类型 size_type.
size_type 无符号整数, 如 std::size_t.
reference 引用类型, 为 value_type&.
const_reference 常量引用类型, 为 const value_type&.
pointer 指针类型, 为 value_type*.
const_pointer 常量指针类型, 为 const value_type*.
layout_type 布局类型, 可以是 boost::numeric::ublas::first_order 或 boost::numeric::ublas::last_order.

成员函数

成员函数 说明
basic_strides () 构造 basic_strides 的一个空实例.
basic_strides (basic_extents<value_type> const& be) 根据 be 指定的张量维度大小构造一个实例.
basic_strides (std::vector<value_type> const& v) 构造一个实例, 复制 v 的内容.
basic_strides (std::vector<value_type> && v) 构造一个实例, 移动 v 的内容.
basic_strides (basic_strides const& other) 从 other 构造一个实例, 复制其元素.
basic_strides (basic_strides && other) 从 other 构造一个实例, 移动其元素.
basic_strides& operator= (basic_strides other) 把 other 的元素赋给此实例.
const_pointer data() const 返回指向第一个元素的 const_pointer.
const_reference operator[](size_type i) const 返回一个 const_reference, 指向第 i 个元素.
const_reference at(size_type i) const 返回一个 const_reference, 指向第 i 个元素.
bool empty() 若容器没有元素则返回 true.
size_type size() const 返回元素数量.
void clear() 擦除所有元素.
bool operator==(basic_strides const& b) const 若所有元素相等则返回 true.
bool operator!=(basic_strides const& b) const 若某些元素不相等则返回 true.
const_iterator begin() const 返回指向第一个元素的 const_iterator.
const_iterator end() const 返回一个 const_iterator, 指向最后一个元素之后的位置.
std::vector<size_type> base() const 返回保存所有元素的私有成员序列容器.

非成员函数

函数 说明
access(std::vector<size_type> const& i, strides<layout_type> w) 根据多索引向量 i 和步长 w 返回相对内存位置.
access(size_type sum, strides<layout_type> w, size_type i, size_types ... is) 根据索引 i、is ... 和步长向量 w 返回相对内存位置 (递归函数).
