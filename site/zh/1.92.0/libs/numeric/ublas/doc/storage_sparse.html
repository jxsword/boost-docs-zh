稀疏存储

默认标准映射

说明

模板类 map_std<I, T, ALLOC> 为标准库关联容器 std::map 提供一个包装. 这个包装的目的很简单: 在声明稀疏容器类型时, 允许为 (被适配的数组) 定义默认模板参数.

示例

#include <boost/numeric/ublas/storage_sparse.hpp>

int main () {
    using namespace boost::numeric::ublas;
    map_std<int, double> a (3);
    for (unsigned i = 0; i < a.size (); ++ i) {
        a [i] = i;
        std::cout << a [i] << std::endl;
    }
}

定义

定义于头文件 storage_sparse.hpp 中.

模板参数

参数 说明 默认值
I 数组中存储的索引的类型.
T 数组中存储对象的类型.
ALLOC 一个 STL 分配器 std::allocator

所建模的概念

Reversible Container.

类型要求

除 Reversible Container 概念的要求外, 别无其他.

公有基类

std::map

映射数组

说明

模板类 map_array<I, T, ALLOC> 把一个类似 std::map 的关联容器实现为有序数组. 因此它具有部分 Associative Container 接口, 但语义与 std::map 不同.

任何时刻, map_array 都有一个容量上限, 新元素可以插入到该上限之内. 如果 insert 会使 map_array 的大小超过其容量, 则会 重新分配存储. 迭代器和引用会失效. 可以使用 reserve 成员函数直接控制容量.

示例

#include <boost/numeric/ublas/storage_sparse.hpp>

int main () {
    using namespace boost::numeric::ublas;
    map_array<int, double> a (3);
    for (unsigned i = 0; i < a.size (); ++ i) {
        a [i] = i;
        std::cout << a [i] << std::endl;
    }
}

定义

定义于头文件 storage_sparse.hpp 中.

模板参数

参数 说明 默认值
I 数组中存储的索引的类型.
T 数组中存储对象的类型.
ALLOC 一个 STL 分配器 std::allocator

所建模的概念

Reversible Container.

类型要求

除 Reversible Container 概念的要求外, 别无其他.

公有基类

无.
