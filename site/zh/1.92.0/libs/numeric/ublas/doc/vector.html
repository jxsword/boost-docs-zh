向量

说明

模板类 vector<T, A> 是稠密向量的基础容器适配器. 对于一个 n 维向量, 当 0 <= i < n 时, 每个元素 vi 都被映射到容器的第 i-个元素.

示例

#include <boost/numeric/ublas/vector.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    vector<double> v (3);
    for (unsigned i = 0; i < v.size (); ++ i)
        v (i) = i;
    std::cout << v << std::endl;
}

单位向量

说明

模板类 unit_vector<T, ALLOC> 表示规范单位向量. 对于第 k 个 n 维规范单位向量, 当 0 <= i < n 时, 有 uki = 0 (若 i <> k), 且 uki = 1.

示例

#include <boost/numeric/ublas/vector.hpp>
#include <boost/numeric/ublas/io.hpp>

int main () {
    using namespace boost::numeric::ublas;
    for (int i = 0; i < 3; ++ i) {
        unit_vector<double> v (3, i);
        std::cout << v << std::endl;
    }
}
