简短示例

设想你想对带摩擦的谐振子进行数值积分. 运动方程由 x'' = -x + γ x' 给出. Odeint 只处理不高于 x' 的一阶导数的一阶 ODE. 不过, 通过引入新变量 q=x 和 p=x' 使得 w=(q,p), 任何高阶 ODE 都可以变换为一阶 ODE 组. 要进行数值积分, 首先需要设计方程 w' = f(w) = (p,-q+γ p) 的右端项:

/* The type of container used to hold the state vector */
typedef std::vector< double > state_type;

const double gam = 0.15;

/* The rhs of x' = f(x) */
void harmonic_oscillator( const state_type &x , state_type &dxdt , const double /* t */ )
{
    dxdt[0] = x[1];
    dxdt[1] = -x[0] - gam*x[1];
}

这里我们选择 vector<double> 作为状态类型, 但其他类型也可以, 例如 std::array<double,2>. odeint 的设计使你可以方便地使用自己的状态类型. 接着定义 ODE, 本例中它是一个计算 f(x) 的简单函数. 该函数的参数签名至关重要: 积分方法总是以 f(x, dxdt, t) 的形式调用它们 (某些特殊例程除外). 因此, 即使没有显式的时间依赖, 也必须将 t 定义为函数参数.

现在, 我们必须定义积分的起始初始状态:

state_type x(2);
x[0] = 1.0; // start at x=1.0, p=0.0
x[1] = 0.0;

对于积分本身, 我们将使用 integrate 函数, 这是快速获得结果的便捷方式. 它基于带误差控制的 runge_kutta54_cash_karp 步进器 (5 阶), 并使用自适应步长.

size_t steps = integrate( harmonic_oscillator ,
        x , 0.0 , 10.0 , 0.1 );

integrate 函数期望的参数包括: 如上定义的 ODE 右端项、初始状态 x、积分的起始和结束时间, 以及初始时间步长. 注意, integrate 在积分步中使用自适应步长, 因此各时间点不是等间距的. 积分返回实际执行的步数, 并更新 x, 使其成为积分结束时刻 ODE 的近似解.

也可以将 ODE 系统表示为一个类. 此时右端项必须实现为函数对象 (functor), 即一个重载了函数调用运算符的类:

/* The rhs of x' = f(x) defined as a class */
class harm_osc {

    double m_gam;

public:
    harm_osc( double gam ) : m_gam(gam) { }

    void operator() ( const state_type &x , state_type &dxdt , const double /* t */ )
    {
        dxdt[0] = x[1];
        dxdt[1] = -x[0] - m_gam*x[1];
    }
};

可通过如下方式使用

harm_osc ho(0.15);
steps = integrate( ho ,
        x , 0.0 , 10.0 , 0.1 );

要想在积分步中观察解, 你只需提供一个合适的观察器 (observer). 例如

struct push_back_state_and_time
{
    std::vector< state_type >& m_states;
    std::vector< double >& m_times;

    push_back_state_and_time( std::vector< state_type > &states , std::vector< double > &times )
    : m_states( states ) , m_times( times ) { }

    void operator()( const state_type &x , double t )
    {
        m_states.push_back( x );
        m_times.push_back( t );
    }
};

它将中间步骤存入一个容器. 注意 () 运算符的参数结构: odeint 正是以这种方式调用观察器, 提供当前状态和时间. 现在, 只需把这个容器传给积分函数:

vector<state_type> x_vec;
vector<double> times;

steps = integrate( harmonic_oscillator ,
        x , 0.0 , 10.0 , 0.1 ,
        push_back_state_and_time( x_vec , times ) );

/* output */
for( size_t i=0; i<=steps; i++ )
{
    cout << times[i] << '\t' << x_vec[i][0] << '\t' << x_vec[i][1] << '\n';
}

就这些. 你可以使用 Boost.Lambda 或 Boost.Phoenix 之类的函数式库来简化观察器函数的创建.
