混沌系统与 Lyapunov 指数

本示例展示如何将 odeint 应用于混沌确定性系统性质的研究. 用数学语言来说, "混沌"指扰动 δ x 的指数增长. 为了观察这种指数增长, 通常求解切向动力学的方程, 它同样是一个常微分方程. 这些方程是线性的但依赖于时间, 可通过

d δ x / dt = J(x) δ x

得到, 其中 J 是所研究系统的 Jacobian. δ x 也可以解释为原系统的扰动. 原则上存在 n 个这样的扰动, 它们构成一个超立方体并随时间演化. Lyapunov 指数随后被定义为各扰动的对数增长率. 如果某个 Lyapunov 指数大于零, 相邻轨迹将指数式发散, 因此系统是混沌的. 如果最大 Lyapunov 指数为零, 通常面对的是周期运动. 如果最大 Lyapunov 指数小于零, 则预期收敛到不动点. 关于 Lyapunov 指数和非线性动力系统的更多信息可以在许多教科书中找到, 例如: E. Ott "Chaos is Dynamical Systems", Cambridge.

为了数值计算 Lyapunov 指数, 通常求解 n 个扰动的运动方程, 并每隔 k 步对它们进行正交归一化. Lyapunov 指数是每个扰动拉伸因子对数的平均值.

为了演示如何使用 odeint 确定 Lyapunov 指数, 我们选择 Lorenz 系统. 它是非线性动力学界研究最多的动力系统之一. 对于标准参数, 它拥有一个维数非整数的奇怪吸引子. 其 Lyapunov 指数约为 0.9、0 和 -12.

Lorenz 系统的实现如下

const double sigma = 10.0;
const double R = 28.0;
const double b = 8.0 / 3.0;

typedef std::array< double , 3 > lorenz_state_type;

void lorenz( const lorenz_state_type &x , lorenz_state_type &dxdt , double t )
{
    dxdt[0] = sigma * ( x[1] - x[0] );
    dxdt[1] = R * x[0] - x[1] - x[0] * x[2];
    dxdt[2] = -b * x[2] + x[0] * x[1];
}

我们还需要对扰动集合进行积分. 这要与原系统并行进行, 因此放在同一个系统函数内. 当然, 我们希望使用上面 Lorenz 系统的定义, 因此包含 Lorenz 系统本身和扰动的系统函数定义可以写成:

const size_t n = 3;
const size_t num_of_lyap = 3;
const size_t N = n + n*num_of_lyap;

typedef std::tr1::array< double , N > state_type;
typedef std::tr1::array< double , num_of_lyap > lyap_type;

void lorenz_with_lyap( const state_type &x , state_type &dxdt , double t )
{
    lorenz( x , dxdt , t );

    for( size_t l=0 ; l<num_of_lyap ; ++l )
    {
        const double *pert = x.begin() + 3 + l * 3;
        double *dpert = dxdt.begin() + 3 + l * 3;
        dpert[0] = - sigma * pert[0] + 10.0 * pert[1];
        dpert[1] = ( R - x[2] ) * pert[0] - pert[1] - x[0] * pert[2];
        dpert[2] = x[1] * pert[0] + x[0] * pert[1] - b * pert[2];
    }
}

扰动线性地存储在 state_type 中 Lorenz 系统状态之后的位置. lorenz() 和 lorenz_with_lyap() 状态类型不同的问题可以通过把 Lorenz 系统放进一个参数模板化的函数对象来解决:

struct lorenz
{
    template< class StateIn , class StateOut , class Value >
    void operator()( const StateIn &x , StateOut &dxdt , Value t )
    {
        dxdt[0] = sigma * ( x[1] - x[0] );
        dxdt[1] = R * x[0] - x[1] - x[0] * x[2];
        dxdt[2] = -b * x[2] + x[0] * x[1];
    }
};

void lorenz_with_lyap( const state_type &x , state_type &dxdt , double t )
{
    lorenz()( x , dxdt , t );
    ...
}

这样工作正常, lorenz_with_lyap 可以例如通过如下方式使用

state_type x;
// initialize x..

explicit_rk4< state_type > rk4;
integrate_n_steps( rk4 , lorenz_with_lyap , x , 0.0 , 0.01 , 1000 );

这段代码以固定步长 0.01 执行 1000 步.

计算 Lorenz 系统 Lyapunov 指数的实际用例总是包含一些暂态步骤, 只是为了确保当前状态位于吸引子上, 因此它看起来像

state_type x;
// initialize x
explicit_rk4< state_type > rk4;
integrate_n_steps( rk4 , lorenz , x , 0.0 , 0.01 , 1000 );

现在的问题是, x 是包含扰动的完整状态, 而 integrate_n_steps 并不知道它只应使用 3 个元素. 具体来说, odeint 及其步进器通过确定状态的长度来确定所研究系统的长度. 在经典求解器 (如 Numerical Recipes 中的) 中, 这个问题通过指向状态的指针和适当的长度来解决, 类似于

void lorenz( double* x , double *dxdt , double t, void* params )
{
    ...
}

int system_length = 3;
rk4( x , system_length , t , dt , lorenz );

但 odeint 支持一个类似且精巧得多的概念: Boost.Range. 为使步进器和系统准备好配合 Boost.Range 工作, 系统必须做如下修改:

struct lorenz
{
    template< class State , class Deriv >
    void operator()( const State &x_ , Deriv &dxdt_ , double t ) const
    {
        typename boost::range_iterator< const State >::type x = boost::begin( x_ );
        typename boost::range_iterator< Deriv >::type dxdt = boost::begin( dxdt_ );

        dxdt[0] = sigma * ( x[1] - x[0] );
        dxdt[1] = R * x[0] - x[1] - x[0] * x[2];
        dxdt[2] = -b * x[2] + x[0] * x[1];
    }
};

原则上这就是全部. 现在, 我们只需调用 integrate_n_steps, 传入一个仅包含 x 前 3 个分量的 range:

// explicitly choose range_algebra to override default choice of array_algebra
runge_kutta4< state_type , double , state_type , double , range_algebra > rk4;

// perform 10000 transient steps
integrate_n_steps( rk4 , lorenz() , std::make_pair( x.begin() , x.begin() + n ) , 0.0 , dt , 10000 );

注释

注意, 使用 Boost.Range 时, 我们必须显式配置步进器使用 range_algebra, 否则 odeint 会自动选择 array_algebra, 它与 Boost.Range 的用法不兼容, 因为原始的 state_type 是一个 array.

在积分了足够多的暂态步之后, 我们现在能够计算 Lyapunov 指数:

  1. 初始化扰动. 它们线性地存储在 Lorenz 系统状态之后的位置. 扰动的初始化方式使 p ​ij = δ ​ij, 其中 p ​ij 是第 i 个扰动的第 j 个分量, δ ​ij 是 Kronecker 符号.
  2. 对包含扰动的完整系统积分 100 步
  3. 使用 Gram-Schmidt 正交归一化算法对扰动进行正交归一化.
  4. 重复第 2 步和第 3 步. 每 10000 步写出当前的 Lyapunov 指数.

fill( x.begin()+n , x.end() , 0.0 );
for( size_t i=0 ; i<num_of_lyap ; ++i ) x[n+n*i+i] = 1.0;
fill( lyap.begin() , lyap.end() , 0.0 );

double t = 0.0;
size_t count = 0;
while( true )
{

    t = integrate_n_steps( rk4 , lorenz_with_lyap , x , t , dt , 100 );
    gram_schmidt< num_of_lyap >( x , lyap , n );
    ++count;

    if( !(count % 100000) )
    {
        cout << t;
        for( size_t i=0 ; i<num_of_lyap ; ++i ) cout << "\t" << lyap[i] / t ;
        cout << endl;
    }
}
