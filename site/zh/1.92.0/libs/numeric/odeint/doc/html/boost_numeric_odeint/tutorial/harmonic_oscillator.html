定义 ODE

首先, 你必须指定表示系统状态 x 的数据类型. 在数学上, 这通常是以实数或复数为标量对象的 n 维向量. 对 odeint 而言, 最自然的方式是使用 vector< double > 或 vector< complex< double > > 来表示系统状态. 不过, odeint 也能处理其他容器类型, 例如 std::array< double , N >, 只要它满足下面定义的一些要求.

要对微分方程进行数值积分, 还必须定义方程 x' = f(x) 的右端项. 在 odeint 中, 你以一个实现了 () 运算符、且具有特定参数结构的对象的形式提供该函数. 因此, 直截了当的方式就是只定义一个函数, 例如:

/* The type of container used to hold the state vector */
typedef std::vector< double > state_type;

const double gam = 0.15;

/* The rhs of x' = f(x) */
void harmonic_oscillator( const state_type &x , state_type &dxdt , const double /* t */ )
{
    dxdt[0] = x[1];
    dxdt[1] = -x[0] - gam*x[1];
}

函数的参数必须遵循上面的示例: x 是当前状态, 这里是一个二分量向量, 包含振子的位置 q 和动量 p; dxdt 是导数 x', 应由函数用 f(x) 填充; t 是当前时间. 注意在本例中计算 f 并不需要 t, 但 odeint 期望函数签名恰好有三个参数 (存在例外, 后文讨论).

更精细的做法是将系统实现为一个类, 把右端项函数定义为该类的 () 运算符, 参数结构与上面相同:

/* The rhs of x' = f(x) defined as a class */
class harm_osc {

    double m_gam;

public:
    harm_osc( double gam ) : m_gam(gam) { }

    void operator() ( const state_type &x , state_type &dxdt , const double /* t */ )
    {
        dxdt[0] = x[1];
        dxdt[1] = -x[0] - m_gam*x[1];
    }
};

odeint 可以处理这类类的实例而不只是纯函数, 这让代码更整洁.

步进器类型

数值积分以迭代方式进行, 意思是你从状态 x(t) 出发, 执行长度为 dt 的时间步, 得到近似状态 x(t+dt). 存在许多不同的方法来执行这样的时间步, 每种方法都有一定的阶数 q. 如果方法的阶数是 q, 则它精确到 ~dtq 项, 也就是说这种一步在 x 中引入的误差为 ~dtq+1. odeint 提供多个不同阶数的步进器, 见 步进器概览.

上表中的某些步进器比较特殊: 有些需要 ODE 的 Jacobian, 有些是为特殊 ODE 系统 (如哈密顿系统) 构造的. 我们将在本教程中展示典型示例和用例, 以及应当应用哪类步进器.

以固定步长积分

基本步进器只执行一个时间步, 不提供任何关于所产生误差的信息 (除了你知道它是 q+1 阶的). 这类步进器以固定步长使用, 步长应选得足够小以使误差合理地小. 不过, 你应当对结果进行某种有效性检查 (例如观察守恒量), 因为你没有其他误差控制手段. 下面的示例定义一个基于经典四阶 Runge-Kutta 格式的基本步进器. 步进器的声明要求以状态类型作为模板参数. 现在可以使用 odeint 的 integrate_const( Stepper, System, state, start_time, end_time, step_size ) 函数完成积分:

runge_kutta4< state_type > stepper;
integrate_const( stepper , harmonic_oscillator , x , 0.0 , 10.0 , 0.01 );

该调用使用 RK4 方法对由 harmonic_oscillator 定义的系统积分, 从 t=0 到 10, 步长为 dt=0.01, 初始条件由 x 给出. 结果 x(t=10) 存入 x (就地). 每个步进器都定义了一个 do_step 方法, 它也可以直接使用. 因此, 上面的示例可以写成

const double dt = 0.01;
for( double t=0.0 ; t<10.0 ; t+= dt )
    stepper.do_step( harmonic_oscillator , x , t , dt );

提示

如果你的编译器支持 C++11, 你可以轻松地用 lambda 创建系统函数:

{
runge_kutta4< state_type > stepper;
integrate_const( stepper , []( const state_type &x , state_type &dxdt , double t ) {
        dxdt[0] = x[1]; dxdt[1] = -x[0] - gam*x[1]; }
    , x , 0.0 , 10.0 , 0.01 );
}

以自适应步长积分

为了改进数值结果并尽可能减少计算量, 建议使用步长控制. 步长控制通过额外提供所执行步的误差估计的步进器算法来实现. odeint 提供了多个这样的 ErrorSteppers, 我们将以 explicit_error_rk54_ck 为例展示它们的用法, 它是由 Cash 和 Karp 引入系数的、带四阶误差估计的五阶 Runge-Kutta 方法.

typedef runge_kutta_cash_karp54< state_type > error_stepper_type;

有了误差步进器之后, 还需要一个检查误差并相应调整步长的实例. 在 odeint 中, 这由 ControlledSteppers 完成. 对于 runge_kutta_cash_karp54 步进器, 存在一个 controlled_runge_kutta 步进器, 可通过如下方式使用

typedef controlled_runge_kutta< error_stepper_type > controlled_stepper_type;
controlled_stepper_type controlled_stepper;
integrate_adaptive( controlled_stepper , harmonic_oscillator , x , 0.0 , 10.0 , 0.01 );

与上面一样, 这会对由 harmonic_oscillator 定义的系统进行积分, 但这次使用基于 Runge-Kutta Cash-Karp 54 格式的自适应步长方法, 从 t=0 到 10, 初始步长为 dt=0.01 (将被调整), 初始条件由 x 给出. 结果 x(t=10) 同样会存入 x (就地).

在上面的示例中, 一个误差步进器被嵌套在受控步进器中. 这是一个不错的技巧; 但缺点之一是总是需要定义两个步进器. 你也可以把受控步进器的实例化写进 integrate 函数的调用中, 但仍然需要完全了解底层步进器的类型. 另一点是, 步长控制的误差容限不容易纳入受控步进器. 这两个问题都可以通过使用 make_controlled 解决:

integrate_adaptive( make_controlled< error_stepper_type >( 1.0e-10 , 1.0e-6 ) ,
                    harmonic_oscillator , x , 0.0 , 10.0 , 0.01 );

make_controlled 可以与 odeint 的许多步进器配合使用. 第一个参数是积分期间使用的绝对误差容限 eps_abs, 第二个是相对误差容限 eps_rel. 模板参数决定应从哪个误差步进器实例化受控步进器. make_controlled 的另一种语法是

integrate_adaptive( make_controlled( 1.0e-10 , 1.0e-6 , error_stepper_type() ) ,
                    harmonic_oscillator , x , 0.0 , 10.0 , 0.01 );

对于 Runge-Kutta 控制器, 一步中产生的误差会与 eps_abs + eps_rel * ( ax * |x| + adxdt * dt * |dxdt| ) 进行比较. 如果误差小于该值, 当前步被接受; 否则被拒绝并减小步长. 注意, 如果误差相对上式右端项而言过小, 步长也会被增大. 因此, 带全部参数的 controlled_runge_kutta 完整实例化是

double abs_err = 1.0e-10 , rel_err = 1.0e-6 , a_x = 1.0 , a_dxdt = 1.0;
controlled_stepper_type controlled_stepper(
    default_error_checker< double , range_algebra , default_operations >( abs_err , rel_err , a_x , a_dxdt ) );
integrate_adaptive( controlled_stepper , harmonic_oscillator , x , 0.0 , 10.0 , 0.01 );

使用 make_controlled 时, 参数 ax 和 adxdt 使用其标准值 1.

使用迭代器

odeint 支持用于求解 ODE 的迭代器. 也就是说, 你实例化一对迭代器, 不用带观察器的 integrate 例程, 而是把迭代器放进 C++ 标准库或 Boost.Range 的某个算法中. 例如

std::for_each( make_const_step_time_iterator_begin( stepper , harmonic_oscillator, x , 0.0 , 0.1 , 10.0 ) ,
               make_const_step_time_iterator_end( stepper , harmonic_oscillator, x ) ,
               []( std::pair< const state_type & , const double & > x ) {
                   cout << x.second << " " << x.first[0] << " " << x.first[1] << "\n"; } );

本示例的完整源文件可在此处找到: harmonic_oscillator.cpp
