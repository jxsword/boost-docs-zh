简单辛系统

说明

在大多数哈密顿系统中, 动能项是动量的二次项 Hkin = p^2 / 2m, 而在许多情况下可以重新缩放坐标并取 m=1, 从而得到一个平凡的运动方程:

q'(t) = f(p) = p.

而对于 p' 仍具有一般形式

p'(t) = g(q)

由于这种情况非常常见, 我们引入了一个概念, 只需向辛步进器提供 p' 的非平凡方程即可. 我们称这个概念为 SimpleSymplecticSystem
