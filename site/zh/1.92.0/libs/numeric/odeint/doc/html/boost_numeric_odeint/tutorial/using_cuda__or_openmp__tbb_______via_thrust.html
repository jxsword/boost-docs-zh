通过 Thrust 使用 CUDA (或 OpenMP, TBB, ...)

相位振子系综
大型振子链
参数研究

现代显卡 (图形处理单元, GPU) 可以通过大规模并行化来加速耗时算法. 它们被设计为并行执行许多操作. odeint 可以借助 CUDA 和 Thrust (一个面向原生 CUDA API 的类 STL 接口) 利用 GPU 的能力.

重要

Thrust 还支持使用 OpenMP 和 Intel Threading Building Blocks (TBB) 的并行化. 你可以通过一个简单的编译器开关在 CUDA、OpenMP 和 TBB 并行化之间切换. 因此, 这也提供了一种把基本 OpenMP 并行化引入 odeint 的简便途径. 不过, 下面讨论的示例聚焦于 GPU 并行化.

要将 odeint 与 CUDA 配合使用, 必须考虑几个要点. 首先, 必须选好问题. 试图对三维系统并行化代码是完全没有意义的, 它实在太小, 不值得费力. GPU 上的一次函数调用 (内核执行) 很慢, 但你可以只通过一次调用对海量数据执行操作. 我们的经验是, 被并行化的向量大小应达到 106 量级, 才能充分利用 GPU. 其次, 在实现 ODE 的右端项时必须使用 Thrust 的算法和函数对象. 这可能比较棘手, 因为它涉及某种函数式编程知识.

CUDA 与 odeint 的典型应用是大型系统, 如晶格或 PDE 离散化, 以及参数研究. 现在我们介绍三个示例, 展示如何将 GPU 的能力与 odeint 结合使用.

重要

CUDA 的全部威力只对真正的大型系统可用, 即耦合常微分方程数量达到 N=106 或更大的系统. 对于较小的系统, CPU 通常快得多. 你也可以并行积分由多个互不耦合的 ODE 组成的系综, 如最后一个示例所示.

相位振子系综

第一个示例是上一节的相位振子系综:

dφ​k / dt = ω​k + ε / N Σ​j sin( φ​j - φ​k ).

在振子数 N 趋于无穷的极限下, 它在 ε = 2 处有一个相变. 当 N 有限时, 这一转变被抹平, 但仍然清晰可见.

非常适合这类需要大量粒子 (振子) 的问题的是 Thrust 与 CUDA. 我们先定义状态类型, 它是一个 thrust::device_vector. 这个向量的内容存放在 GPU 上. 如果你对此不熟悉, 我们建议阅读 Getting started 一节, 见 Thrust 网站.

//change this to float if your device does not support double computation
typedef double value_type;

//change this to host_vector< ... > of you want to run on CPU
typedef thrust::device_vector< value_type > state_type;
// typedef thrust::host_vector< value_type > state_type;

Thrust 遵循函数式编程的方法. 如果你想在 GPU 上执行计算, 通常必须调用诸如 thrust::for_each、thrust::reduce 之类的全局函数, 并配上一个执行基本操作的适当的局部函数对象. 例如

struct add_two
{
    template< class T >
    __host__ __device__
    void operator()( T &t ) const
    {
        t += T( 2 );
    }
};

// ...

thrust::for_each( x.begin() , x.end() , add_two() );

这段代码泛型地为容器 x 中的每个元素加 2.

为了积分相位振子系综, 我们需要

  • 计算系统函数, 即 ODE 的右端项;
  • 这涉及计算振子示例的平均场, 即 R 和 θ 的值.

平均场在一个类 mean_field_calculator 中计算

struct mean_field_calculator
{
    struct sin_functor : public thrust::unary_function< value_type , value_type >
    {
        __host__ __device__
        value_type operator()( value_type x) const
        {
            return sin( x );
        }
    };

    struct cos_functor : public thrust::unary_function< value_type , value_type >
    {
        __host__ __device__
        value_type operator()( value_type x) const
        {
            return cos( x );
        }
    };

    static std::pair< value_type , value_type > get_mean( const state_type &x )
    {
        value_type sin_sum = thrust::reduce(
                thrust::make_transform_iterator( x.begin() , sin_functor() ) ,
                thrust::make_transform_iterator( x.end() , sin_functor() ) );
        value_type cos_sum = thrust::reduce(
                thrust::make_transform_iterator( x.begin() , cos_functor() ) ,
                thrust::make_transform_iterator( x.end() , cos_functor() ) );

        cos_sum /= value_type( x.size() );
        sin_sum /= value_type( x.size() );

        value_type K = sqrt( cos_sum * cos_sum + sin_sum * sin_sum );
        value_type Theta = atan2( sin_sum , cos_sum );

        return std::make_pair( K , Theta );
    }
};

在这个类内部定义了两个成员结构 sin_functor 和 cos_functor. 它们计算一个值的正弦和余弦, 并在 transform 迭代器中用于计算 sin(φ​k) 与 cos(φ​k) 的和. 说明符 __host__ 和 __device__ 是 CUDA 特有的, 它们定义一个既可在 GPU 上也可在 CPU 上执行的函数或运算符. 这一行

value_type sin_sum = thrust::reduce(
        thrust::make_transform_iterator( x.begin() , sin_functor() ) ,
        thrust::make_transform_iterator( x.end() , sin_functor() ) );

在 GPU 上 (或 CPU 上, 取决于你的 thrust 配置) 执行这个正弦和的计算.

系统函数通过如下方式定义:

class phase_oscillator_ensemble
{

public:

    struct sys_functor
    {
        value_type m_K , m_Theta , m_epsilon;

        sys_functor( value_type K , value_type Theta , value_type epsilon )
        : m_K( K ) , m_Theta( Theta ) , m_epsilon( epsilon ) { }

        template< class Tuple >
        __host__ __device__
        void operator()( Tuple t )
        {
            thrust::get<2>(t) = thrust::get<1>(t) + m_epsilon * m_K * sin( m_Theta - thrust::get<0>(t) );
        }
    };

    // ...

    void operator() ( const state_type &x , state_type &dxdt , const value_type dt ) const
    {
        std::pair< value_type , value_type > mean_field = mean_field_calculator::get_mean( x );

        thrust::for_each(
                thrust::make_zip_iterator( thrust::make_tuple( x.begin() , m_omega.begin() , dxdt.begin() ) ),
                thrust::make_zip_iterator( thrust::make_tuple( x.end() , m_omega.end() , dxdt.end()) ) ,
                sys_functor( mean_field.first , mean_field.second , m_epsilon )
                );
    }

    // ...
};

这个类在 do_step 和 integrate 方法中使用. 它为每个振子的右端项定义了一个成员结构 sys_functor, 并定义 operator() 以便在 odeint 的步进器和积分器中使用. 该函数对象首先计算 φ​k 的平均场, 然后用这个平均场计算 ODE 的完整右端项. 注意 thrust::tuple 和 thrust::zip_iterator 配合得多么好.

现在我们准备好把所有东西组合起来. 要让 odeint 准备好使用 GPU, 我们只需用 state_type 和 value_type 参数化步进器:

typedef runge_kutta4< state_type , value_type , state_type , value_type > stepper_type;

注释

我们特意定义了四个模板参数, 因为我们必须用 double 覆盖默认参数值 value_type, 以确保在使用 float 作为基本数据类型时程序能正常运行.

你也可以使用受控步进器或稠密输出步进器, 例如

typedef runge_kutta_dopri5< state_type , value_type , state_type , value_type > stepper_type;

然后, 通过创建右端项类的实例并使用积分函数, 积分相位系综就很直接了:

phase_oscillator_ensemble ensemble( N , 1.0 );


size_t steps1 = integrate_const( make_controlled( 1.0e-6 , 1.0e-6 , stepper_type() ) , boost::ref( ensemble ) , x , 0.0 , t_transients , dt );

我们必须在这里使用 boost::ref, 以便按引用而不是按值传递右端项类. 这确保调用 integrate_const 时各振子的固有频率不被复制. 完整示例中比较了 Runge-Kutta-4 与 Dopri5 求解器的性能和结果.

完整示例见 phase_oscillator_example.cu.

大型振子链

下一个示例是一个大型的、由最近邻耦合相位振子组成的一维链, 其运动方程为:

d φ​k / dt = ω​k + sin( φ​k+1 - φ​k ) + sin( φ​k - φ​k-1)

原则上我们可以使用上一个相位振子系综示例中的所有技术, 但必须特别注意振子之间的耦合. 要高效实现耦合, 可以使用一种非常优雅的方式, 即 Thrust 的置换迭代器 (permutation iterator). 置换迭代器的行为类似于向量上的普通迭代器, 但它不按元素通常的顺序迭代, 而是按某个索引映射定义的元素排列迭代. 为了实现最近邻耦合, 我们创建一个在普通迭代器之后一步处行进的置换迭代器, 以及另一个在前面一步处行进的置换迭代器. 完整的系统类是:

//change this to host_vector< ... > if you want to run on CPU
typedef thrust::device_vector< value_type > state_type;
typedef thrust::device_vector< size_t > index_vector_type;
//typedef thrust::host_vector< value_type > state_type;
//typedef thrust::host_vector< size_t > index_vector_type;

class phase_oscillators
{

public:

    struct sys_functor
    {
        template< class Tuple >
        __host__ __device__
        void operator()( Tuple t )  // this functor works on tuples of values
        {
            // first, unpack the tuple into value, neighbors and omega
            const value_type phi = thrust::get<0>(t);
            const value_type phi_left = thrust::get<1>(t);  // left neighbor
            const value_type phi_right = thrust::get<2>(t); // right neighbor
            const value_type omega = thrust::get<3>(t);
            // the dynamical equation
            thrust::get<4>(t) = omega + sin( phi_right - phi ) + sin( phi - phi_left );
        }
    };

    phase_oscillators( const state_type &omega )
        : m_omega( omega ) , m_N( omega.size() ) , m_prev( omega.size() ) , m_next( omega.size() )
    {
        // build indices pointing to left and right neighbours
        thrust::counting_iterator<size_t> c( 0 );
        thrust::copy( c , c+m_N-1 , m_prev.begin()+1 );
        m_prev[0] = 0; // m_prev = { 0 , 0 , 1 , 2 , 3 , ... , N-1 }

        thrust::copy( c+1 , c+m_N , m_next.begin() );
        m_next[m_N-1] = m_N-1; // m_next = { 1 , 2 , 3 , ... , N-1 , N-1 }
    }

    void operator() ( const state_type &x , state_type &dxdt , const value_type dt )
    {
        thrust::for_each(
                thrust::make_zip_iterator(
                        thrust::make_tuple(
                                x.begin() ,
                                thrust::make_permutation_iterator( x.begin() , m_prev.begin() ) ,
                                thrust::make_permutation_iterator( x.begin() , m_next.begin() ) ,
                                m_omega.begin() ,
                                dxdt.begin()
                                ) ),
                thrust::make_zip_iterator(
                        thrust::make_tuple(
                                x.end() ,
                                thrust::make_permutation_iterator( x.begin() , m_prev.end() ) ,
                                thrust::make_permutation_iterator( x.begin() , m_next.end() ) ,
                                m_omega.end() ,
                                dxdt.end()) ) ,
                sys_functor()
                );
    }

private:

    const state_type &m_omega;
    const size_t m_N;
    index_vector_type m_prev;
    index_vector_type m_next;
};

注意, 在系统函数对象中使用置换迭代器可以多么容易地取得左右相邻振子的值. 不过, thrust::for_each 函数的调用看起来相对复杂. ODE 右端项的每一项都由一个迭代器表示, 其打包方式与上面函数对象中的解包方式完全一致.

现在我们把所有东西组合起来. 我们创建随机初始条件和递减的频率, 这样我们应该能得到同步. 我们把频率和初始条件复制到设备上, 最后初始化并执行积分. 作为结果, 我们简单写出当前状态, 即每个振子的相位.

// create initial conditions and omegas on host:
vector< value_type > x_host( N );
vector< value_type > omega_host( N );
for( size_t i=0 ; i<N ; ++i )
{
    x_host[i] = 2.0 * pi * drand48();
    omega_host[i] = ( N - i ) * epsilon; // decreasing frequencies
}

// copy to device
state_type x = x_host;
state_type omega = omega_host;

// create stepper
runge_kutta4< state_type , value_type , state_type , value_type > stepper;

// create phase oscillator system function
phase_oscillators sys( omega );

// integrate
integrate_const( stepper , sys , x , 0.0 , 10.0 , dt );

thrust::copy( x.begin() , x.end() , std::ostream_iterator< value_type >( std::cout , "\n" ) );
std::cout << std::endl;

完整示例见 phase_oscillator_chain.cu.

参数研究

Thrust 与 CUDA 的另一个重要用例是对相对较小的系统进行参数研究. 例如考虑上一节混沌系统示例中的三维 Lorenz 系统, 它有三个参数. 如果想研究该系统在不同参数下的行为, 通常必须对许多参数值分别积分该系统. 使用 thrust 和 odeint, 你可以并行执行这些积分, 即积分一个完整的 Lorenz 系统系综, 其中每个个体实现具有不同的参数值.

下面我们将展示如何使用 Thrust 积分上述 Lorenz 系统系综. 我们只变化参数 β, 但同样直接的做法也可以变化其他参数, 甚至两个或全部三个参数. 此外, 我们将使用最大 Lyapunov 指数来量化系统的行为 (混沌程度).

我们先定义要研究的参数范围. state_type 同样是一个 thrust::device_vector< value_type >.

vector< value_type > beta_host( N );
const value_type beta_min = 0.0 , beta_max = 56.0;
for( size_t i=0 ; i<N ; ++i )
    beta_host[i] = beta_min + value_type( i ) * ( beta_max - beta_min ) / value_type( N - 1 );

state_type beta = beta_host;

接下来必须实现的是不带扰动的 Lorenz 系统. 稍后还会实现带扰动的系统, 用于计算 Lyapunov 指数. 我们将采用一种方案, 其中每个 device 函数计算 Lorenz 系综的一个具体实现

struct lorenz_system
{
    struct lorenz_functor
    {
        template< class T >
        __host__ __device__
        void operator()( T t ) const
        {
            // unpack the parameter we want to vary and the Lorenz variables
            value_type R = thrust::get< 3 >( t );
            value_type x = thrust::get< 0 >( t );
            value_type y = thrust::get< 1 >( t );
            value_type z = thrust::get< 2 >( t );
            thrust::get< 4 >( t ) = sigma * ( y - x );
            thrust::get< 5 >( t ) = R * x - y - x * z;
            thrust::get< 6 >( t ) = -b * z + x * y ;

        }
    };

    lorenz_system( size_t N , const state_type &beta )
    : m_N( N ) , m_beta( beta ) { }

    template< class State , class Deriv >
    void operator()(  const State &x , Deriv &dxdt , value_type t ) const
    {
        thrust::for_each(
                thrust::make_zip_iterator( thrust::make_tuple(
                        boost::begin( x ) ,
                        boost::begin( x ) + m_N ,
                        boost::begin( x ) + 2 * m_N ,
                        m_beta.begin() ,
                        boost::begin( dxdt ) ,
                        boost::begin( dxdt ) + m_N ,
                        boost::begin( dxdt ) + 2 * m_N  ) ) ,
                thrust::make_zip_iterator( thrust::make_tuple(
                        boost::begin( x ) + m_N ,
                        boost::begin( x ) + 2 * m_N ,
                        boost::begin( x ) + 3 * m_N ,
                        m_beta.begin() ,
                        boost::begin( dxdt ) + m_N ,
                        boost::begin( dxdt ) + 2 * m_N ,
                        boost::begin( dxdt ) + 3 * m_N  ) ) ,
                lorenz_functor() );
    }
    size_t m_N;
    const state_type &m_beta;
};

作为 state_type, 使用 thrust::device_vector 或某个 Boost.Range, 其元素为 device_vector. 状态的长度是 3N, 其中 N 是系统的数量. 系统按如下方式编码进该向量: 所有 x 分量排在前, 然后是所有 y 分量, 最后是所有 z 分量. 实现 device 函数就成为一个简单任务, 你只需分解来自 zip 迭代器的元组.

除了不带扰动的系统之外, 我们还需要计算包含支配小扰动时间演化的线性化方程的系统. 使用上面的方法这很直接, 只有一个小困难: Thrust 的元组最大元数为 10. 但这只是个小问题, 因为我们可以创建一个用 zip 迭代器打包的 zip 迭代器. 于是顶层 zip 迭代器包含一个用于状态的 zip 迭代器、一个用于参数的普通迭代器, 以及一个用于导数的 zip 迭代器. 在系统函数中访问这个元组的元素也很直接, 用 thrust::get<>() 解包元组即可. 我们在此不展示代码, 它太长了. 它可以在 这里 找到, 而且容易理解.

此外, 我们还需要一个观察器, 它确定扰动的范数, 对其归一化, 并对范数的对数取平均. 该观察器中使用的 device 函数对象定义如下:

struct lyap_functor
{
    template< class T >
    __host__ __device__
    void operator()( T t ) const
    {
        value_type &dx = thrust::get< 0 >( t );
        value_type &dy = thrust::get< 1 >( t );
        value_type &dz = thrust::get< 2 >( t );
        value_type norm = sqrt( dx * dx + dy * dy + dz * dz );
        dx /= norm;
        dy /= norm;
        dz /= norm;
        thrust::get< 3 >( t ) += log( norm );
    }
};

注意, 这个函数对象会修改状态, 即扰动.

现在我们补全计算 Lyapunov 指数的完整代码. 首先, 必须定义一个状态向量. 该向量包含 6N 个条目: 状态 x,y,z 及其扰动 dx,dy,dz. 我们按 x=y=z=10、dx=1、dy=dz=0 初始化它们. 我们定义一个步进器类型, 即受控 Runge-Kutta Dormand-Prince 5 步进器. 我们先做一段积分以克服暂态行为. 为此, 我们不涉及扰动, 只在状态 x,y,z 上运行算法, 不带任何观察器. 注意 Boost.Range 如何用于对状态向量中不带扰动的部分 (整个状态的前一半) 进行部分积分. 暂态之后, 对带扰动的完整系统积分, 计算出 Lyapunov 指数并写入 stdout.

state_type x( 6 * N );

// initialize x,y,z
thrust::fill( x.begin() , x.begin() + 3 * N , 10.0 );

// initial dx
thrust::fill( x.begin() + 3 * N , x.begin() + 4 * N , 1.0 );

// initialize dy,dz
thrust::fill( x.begin() + 4 * N , x.end() , 0.0 );


// create error stepper, can be used with make_controlled or make_dense_output
typedef runge_kutta_dopri5< state_type , value_type , state_type , value_type > stepper_type;


lorenz_system lorenz( N , beta );
lorenz_perturbation_system lorenz_perturbation( N , beta );
lyap_observer obs( N , 1 );

// calculate transients
integrate_adaptive( make_controlled( 1.0e-6 , 1.0e-6 , stepper_type() ) , lorenz , std::make_pair( x.begin() , x.begin() + 3 * N ) , 0.0 , 10.0 , dt );

// calculate the Lyapunov exponents -- the main loop
double t = 0.0;
while( t < 10000.0 )
{
    integrate_adaptive( make_controlled( 1.0e-6 , 1.0e-6 , stepper_type() ) , lorenz_perturbation , x , t , t + 1.0 , 0.1 );
    t += 1.0;
    obs( x , t );
}

vector< value_type > lyap( N );
obs.fill_lyap( lyap );

for( size_t i=0 ; i<N ; ++i )
    cout << beta_host[i] << "\t" << lyap[i] << "\n";

完整示例见 lorenz_parameters.cu.
