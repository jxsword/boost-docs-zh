使用矩阵作为状态类型

odeint 与多种不同的状态类型配合良好. 它不限于纯向量型类型, 如 vector< double >、array< double , N >、fusion::vector< double , double > 等, 也支持拓扑不同于简单向量的类型. 这里我们展示如何以矩阵作为状态类型使用 odeint, 下一节将展示如何用它求解定义在复杂网络上的 ODE.

默认情况下, odeint 可以使用 ublas::matrix< T > 作为矩阵的状态类型. 一个简单的例子是耦合相位振子的二维晶格. 其他矩阵类型如 mtl::dense_matrix 或 blitz 数组与矩阵也可以使用, 但需要某种激活才能与 odeint 配合工作. 该激活将在以下小节中介绍,

系统的定义为

typedef boost::numeric::ublas::matrix< double > state_type;

struct two_dimensional_phase_lattice
{
    two_dimensional_phase_lattice( double gamma = 0.5 )
    : m_gamma( gamma ) { }

    void operator()( const state_type &x , state_type &dxdt , double /* t */ ) const
    {
        size_t size1 = x.size1() , size2 = x.size2();

        for( size_t i=1 ; i<size1-1 ; ++i )
        {
            for( size_t j=1 ; j<size2-1 ; ++j )
            {
                dxdt( i , j ) =
                        coupling_func( x( i + 1 , j ) - x( i , j ) ) +
                        coupling_func( x( i - 1 , j ) - x( i , j ) ) +
                        coupling_func( x( i , j + 1 ) - x( i , j ) ) +
                        coupling_func( x( i , j - 1 ) - x( i , j ) );
            }
        }

        for( size_t i=0 ; i<x.size1() ; ++i ) dxdt( i , 0 ) = dxdt( i , x.size2() -1 ) = 0.0;
        for( size_t j=0 ; j<x.size2() ; ++j ) dxdt( 0 , j ) = dxdt( x.size1() -1 , j ) = 0.0;
    }

    double coupling_func( double x ) const
    {
        return sin( x ) - m_gamma * ( 1.0 - cos( x ) );
    }

    double m_gamma;
};

原则上这就是全部. 请注意, 上面的代码远非最优. 如果每个相互作用只计算一次, 并使用针对行和列的迭代器, 可以获得更好的性能. 下面是这个晶格方程演化的一些可视化.
