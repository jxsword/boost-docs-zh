引力与能量守恒

本教程的下一个示例是外太阳系的模拟, 由太阳、木星、土星、天王星、海王星和冥王星组成.

每个行星当然还有太阳都用质点表示. 各天体之间的相互作用力是引力, 可以写成

F​ij = -γ m​i m​j ( q​i - q​j ) / | q​i - q​j | 3

其中 γ 是引力常数, m​i 和 m​j 是质量, q​i 和 q​j 是两个天体的位置. 运动方程为

dq​i / dt = p​i

dp​i / dt = 1 / m​i Σ​ji F​ij

其中 p​i 是天体 i 的动量. 运动方程也可以从哈密顿量

H = Σ​i p​i2 / ( 2 m​i ) + Σ​j V( q​i , q​j )

导出, 其中相互作用势为 V(q​i,q​j). 哈密顿方程给出运动方程

dq​i / dt = dH / dp​i

dp​i / dt = -dH / dq​i

在时间无关的哈密顿系统中, 能量和相空间体积是守恒的, 必须应用特殊的积分方法来确保这些守恒律. odeint 库为可分离哈密顿系统提供了相应的类, 这类系统可以写成 H = Σ p​i2 / (2m​i) + H​q(q) 的形式, 其中 H​q(q) 只依赖于坐标. 虽然这种函数形式看起来有点随意, 但它几乎涵盖了所有有惯性、无耗散的经典力学系统, 以及运动方程可以写成 dq​i / dt = p​i / m​i、dp​i / dt = f( q​i ) 形式的系统.

注释

一条简短的物理注记: 虽然二体问题已知是可积的, 即可以用纯解析技术求解, 但三体问题已经不可解. 这是 H. Poincare 在 19 世纪末发现的, 并由此催生了全新的 混沌理论 学科.

定义系统函数

为实现这个系统, 我们定义一个 3D 点类型, 它既表示空间位置也表示速度. 为此, 我们使用 Boost.Operators 的运算符:

/*the point type */
template< class T , size_t Dim >
class point :
    boost::additive1< point< T , Dim > ,
    boost::additive2< point< T , Dim  > , T ,
    boost::multiplicative2< point< T , Dim > , T
    > > >
    {
    public:

        const static size_t dim = Dim;
        typedef T value_type;
        typedef point< value_type , dim > point_type;

        // ...
        // constructors

        // ...
        // operators

    private:

        T m_val[dim];
    };

    //...
    // more operators

下一步是定义一个容器类型来存储 q 和 p 的值, 并定义系统函数. 作为容器类型, 我们使用 std::array 

// we simulate 5 planets and the sun
const size_t n = 6;

typedef point< double , 3 > point_type;
typedef std::array< point_type , n > container_type;
typedef std::array< double , n > mass_type;

container_type 与 ODE 的状态类型不同. ODE 的状态类型就是一个 pair< container_type , container_type >, 因为它需要坐标和动量的信息.

接下来我们定义系统的方程. 由于我们将使用能处理系统哈密顿 (能量守恒) 特性的步进器, 必须以不同于通常情形 (只是一个函数) 的方式定义右端项. 该步进器将利用可分离性, 这意味着系统将由两个对象定义, 分别表示 f(p) = -dH/dq 和 g(q) = dH/dp:

const double gravitational_constant = 2.95912208286e-4;

struct solar_system_coor
{
    const mass_type &m_masses;

    solar_system_coor( const mass_type &masses ) : m_masses( masses ) { }

    void operator()( const container_type &p , container_type &dqdt ) const
    {
        for( size_t i=0 ; i<n ; ++i )
            dqdt[i] = p[i] / m_masses[i];
    }
};


struct solar_system_momentum
{
    const mass_type &m_masses;

    solar_system_momentum( const mass_type &masses ) : m_masses( masses ) { }

    void operator()( const container_type &q , container_type &dpdt ) const
    {
        const size_t n = q.size();
        for( size_t i=0 ; i<n ; ++i )
        {
            dpdt[i] = 0.0;
            for( size_t j=0 ; j<i ; ++j )
            {
                point_type diff = q[j] - q[i];
                double d = abs( diff );
                diff *= ( gravitational_constant * m_masses[i] * m_masses[j] / d / d / d );
                dpdt[i] += diff;
                dpdt[j] -= diff;

            }
        }
    }
};

一般而言, 三体系统是混沌的, 因此我们不能期望系统的任意初始条件会给出可与太阳系动力学相比的解. 也就是说, 我们必须定义适当的初始条件, 这些条件取自 Hairer、Wannier、Lubich 的书 [4] .

如上所述, 为了保持相空间体积, 我们需要使用一些特殊的积分器. 这类积分器有一个著名家族, 即所谓的 Runge-Kutta-Nystroem 求解器, 这里我们以 symplectic_rkn_sb3a_mclachlan 步进器的形式应用它:

typedef symplectic_rkn_sb3a_mclachlan< container_type > stepper_type;
const double dt = 100.0;

integrate_const(
        stepper_type() ,
        make_pair( solar_system_coor( masses ) , solar_system_momentum( masses ) ) ,
        make_pair( boost::ref( q ) , boost::ref( p ) ) ,
        0.0 , 200000.0 , dt , streaming_observer( cout ) );

这些积分例程被用来绘制上面的太阳系草图. 注意, 本示例有两个特别之处. 首先, 辛步进器的状态不是 container_type 而是一对 container_type. 因此, 我们必须把这样的 pair 传给 integrate 函数. 由于我们想按引用传递它们, 可以简单地把它们打包进 Boost.Ref. 第二点关于观察器, 它以状态类型 (即一对 container_type) 被调用. 引用包装器同样会被传入, 但这完全不成问题:

struct streaming_observer
{
    std::ostream& m_out;

    streaming_observer( std::ostream &out ) : m_out( out ) { }

    template< class State >
    void operator()( const State &x , double t ) const
    {
        container_type &q = x.first;
        m_out << t;
        for( size_t i=0 ; i<q.size() ; ++i ) m_out << "\t" << q[i];
        m_out << "\n";
    }
};
