通过 VexCL 使用 OpenCL

上一节展示了 odeint 与 Thrust 配合使用的情形. 本节我们展示如何将 OpenCL 与 odeint 配合使用. odeint 的要点不在于实现自己的底层数据结构和算法, 而在于使用高层库来完成这些任务. 这里, 我们将使用 VexCL 框架来使用 OpenCL. VexCL 是一个用于通用计算的出色库, 它大量使用表达式模板. 借助 VexCL, 可以编写非常紧凑且富有表现力的应用程序.

注释

vexcl 需要 C++11 特性! 因此你必须启用 C++11 支持进行编译.

要使用 VexCL, 需要额外包含一个头文件, 其中包含 vexcl 的数据类型和算法以及对 odeint 的适配. 这里对 odeint 的适配只是指把 VexCL 的调整大小功能适配到 odeint.

#include <boost/numeric/odeint/external/vexcl/vexcl.hpp>

为了演示 VexCL 的使用, 我们对一个 Lorenz 系统系综进行积分. 该示例与上一节的 Lorenz 系统参数研究非常相似, 只是我们不计算 Lyapunov 指数. 同样, 我们变化 Lorenz 系统的参数 R, 并行求解整个 Lorenz 系统系综 (每个具有不同的参数 R). 首先, 我们定义状态类型和一个向量类型

typedef vex::vector< double >    vector_type;
typedef vex::multivector< double, 3 > state_type;

vector_type 用于表示参数 R. state_type 是由三个子向量组成的多向量, 用于表示状态. 该多向量的第一个分量表示 Lorenz 系统的所有 x 分量, 第二个表示所有 y 分量, 第三个表示所有 z 分量. 该向量的分量可以通过如下方式获得:

auto &x = X(0);
auto &y = X(1);
auto &z = X(2);

如前所述, VexCL 支持表达式模板, 我们将用它们来实现 Lorenz 系综的系统函数:

const double sigma = 10.0;
const double b = 8.0 / 3.0;

struct sys_func
{
    const vector_type &R;

    sys_func( const vector_type &_R ) : R( _R ) { }

    void operator()( const state_type &x , state_type &dxdt , double t ) const
    {
        dxdt(0) = -sigma * ( x(0) - x(1) );
        dxdt(1) = R * x(0) - x(1) - x(0) * x(2);
        dxdt(2) = - b * x(2) + x(0) * x(1);
    }
};

非常简单, 不是吗? 这三行小程序替你完成了所有计算. 无需编写自己的 OpenCL 内核. VexCL 替你搞定一切. 接下来我们必须编写主应用程序. 我们初始化参数 (R) 向量和初始状态. 注意 VexCL 要求 vector_space_algebra, 但 odeint 会在内部自动推导并配置它, 所以我们只需在实例化步进器时指定 state_type 即可:

// setup the opencl context
vex::Context ctx( vex::Filter::Type(CL_DEVICE_TYPE_GPU) );
std::cout << ctx << std::endl;

// set up number of system, time step and integration time
const size_t n = 1024 * 1024;
const double dt = 0.01;
const double t_max = 1000.0;

// initialize R
double Rmin = 0.1 , Rmax = 50.0 , dR = ( Rmax - Rmin ) / double( n - 1 );
std::vector<double> x( n * 3 ) , r( n );
for( size_t i=0 ; i<n ; ++i ) r[i] = Rmin + dR * double( i );
vector_type R( ctx.queue() , r );

// initialize the state of the lorenz ensemble
state_type X(ctx.queue(), n);
X(0) = 10.0;
X(1) = 10.0;
X(2) = 10.0;

// create a stepper
runge_kutta4< state_type > stepper;

// solve the system
integrate_const( stepper , sys_func( R ) , X , 0.0 , t_max , dt );
