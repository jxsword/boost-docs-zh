系统

说明

System 概念为 ODE x' = f(x,t) 的右端项的算法实现建模. 本概念的唯一要求是它能够以特定的参数语法被调用 (见下文). 系统通常实现为函数或函数对象. 所有 Runge-Kutta 步进器以及 Bulirsch-Stoer 步进器都需要满足本概念的系统. 不过, 辛步进器和隐式步进器使用其他系统概念, 见 辛系统 和 隐式系统.
