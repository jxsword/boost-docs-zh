类 failed_step_checker

boost::numeric::odeint::failed_step_checker — 在步长调整中对失败步计数执行溢出检查的类.

概要

// In header: <boost/numeric/odeint/integrate/max_step_checker.hpp>


class failed_step_checker : public boost::numeric::odeint::max_step_checker {
public:

  // public member functions
  failed_step_checker(const int = 500);
  void operator()(void);
  void reset();
};

说明

在稠密输出步进器和积分例程内部使用.

failed_step_checker 公有成员函数

  1. failed_step_checker(const int max_steps = 500);
    构造 failed_step_checker. max_steps 是抛出 runtime_error 之前允许的最大迭代次数.
  2. void operator()(void);
    递增计数器并执行迭代检查.
  3. void reset();
    通过将内部计数器置为 0 来重置 max_step_checker.
