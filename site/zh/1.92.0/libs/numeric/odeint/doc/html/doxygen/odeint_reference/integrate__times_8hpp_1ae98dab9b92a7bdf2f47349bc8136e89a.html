函数模板 integrate_times

boost::numeric::odeint::integrate_times — 积分 ODE, 并在给定时间点调用观察器.

概要

// In header: <boost/numeric/odeint/integrate/integrate_times.hpp>


template<typename Stepper, typename System, typename State, 
         typename TimeIterator, typename Time, typename Observer> 
  size_t integrate_times(Stepper stepper, System system, State & start_state, 
                         TimeIterator times_start, TimeIterator times_end, 
                         Time dt, Observer observer);

说明

用给定的步进器积分 system 给出的 ODE. 此函数在范围 times_start、times_end 给定的后续时间点处调用观察器. 若步进器无步长控制, 步长可能偶尔减小, 以确保恰好在给定序列的时间点处调用观察器. 若步进器是 ControlledStepper, 步长会被调整以满足误差界限, 但也可能偶尔减小以确保正确调用观察器. 若提供 DenseOutputStepper, 则使用稠密输出功能在给定时间处调用观察器. 积分的结束时间始终为 *(end_time-1). 若提供 max_step_checker 作为 StepOverflowChecker, 当在观察器调用之间执行了过多无进展的步 (默认: 500) 时, 会抛出 no_progress_error. 若未提供检查器, 则不执行此类溢出检查.

参数:

stepper

用于数值积分的步进器.

system

定义 ODE 右端项的函数/函数对象.

start_state

初始条件 x0.

times_start

指向起始时间的迭代器

times_end

指向结束时间的迭代器

dt

观察器调用之间的时间步, 不一定是积分的时间步.

observer

在等距时间间隔处调用的函数/函数对象.

返回:

已执行的步数.
