全部示例

下表给出全部示例的概览.

表 1.4. 示例概览

File

简要说明

bind_member_functions.cpp

此示例展示如何在 odeint 中把成员函数用作系统函数.

bind_member_functions_cpp11.cpp

此示例展示在 C++11 中如何借助 std::bind 把成员函数用作 odeint 的系统函数.

bulirsch_stoer.cpp

展示 Bulirsch-Stoer 方法的用法.

chaotic_system.cpp

混沌系统示例对 Lorenz 系统进行积分并计算 Lyapunov 指数.

elliptic_functions.cpp

使用带稠密输出的 Bulirsch-Stoer 和 Runge-Kutta-Dopri5 步进器计算椭圆函数的示例.

fpu.cpp

Fermi-Pasta-Ulam (FPU) 示例展示如何使用 odeint 对晶格系统进行积分.

generation_functions.cpp

展示如何实现自己的工厂函数的骨架代码.

harmonic_oscillator.cpp

谐振子示例简要介绍 odeint, 并展示经典 Runge-Kutta 求解器的用法.

harmonic_oscillator_units.cpp

此示例展示如何将 Boost.Units 与 odeint 配合使用.

heun.cpp

Heun 示例展示如何用 odeint 的泛型 Runge-Kutta 方法创建自定义 Runge-Kutta 步进器.

list_lattice.cpp

使用 std::list 作为状态类型进行相格点 (phase lattice) 积分的示例.

lorenz_point.cpp

使用自定义 point3d 数据类型作为状态类型对 Lorenz 系统进行积分的另一种方式.

my_vector.cpp

展示如何让 odeint 配合自定义向量类型工作的简单示例.

phase_oscillator_ensemble.cpp

相位振子系综示例展示如何分析全局耦合振子, 以及如何在积分过程中计算统计量.

resizing_lattice.cpp

通过在扩展晶格上模拟哈密顿系统, 展示 odeint 内存管理的能力.

simple1d.cpp

对一个简单的一维 ODE 进行积分, 展示 integrate 函数与生成函数的用法.

solar_system.cpp

太阳系示例展示辛求解器的用法.

stepper_details.cpp

展示多个步进器类可用性的简单示例.

stiff_system.cpp

刚性系统示例展示使用系统函数 Jacobian 的刚性求解器的用法.

stochastic_euler.cpp

实现自定义步进器 (随机 Euler), 用于求解随机微分方程.

stuart_landau.cpp

Stuart-Landau 示例展示 odeint 如何与复数状态类型配合使用.

two_dimensional_phase_lattice.cpp

二维相位振子示例展示二维晶格如何配合 odeint 工作, 以及矩阵类型如何用作 odeint 中的状态类型.

van_der_pol_stiff.cpp

这个刚性系统示例再次通过对 van der Pol 振子进行积分, 展示刚性求解器的用法.

gmpxx/lorenz_gmpxx.cpp

此示例使用任意精度类型对 Lorenz 系统进行积分.

mtl/gauss_packet.cpp

MTL-Gauss-packet 示例展示如何轻松地将 MTL 与 odeint 配合使用.

mtl/implicit_euler_mtl.cpp

此示例展示 MTL 隐式 Euler 方法配合稀疏矩阵类型的用法.

thrust/phase_oscillator_ensemble.cu

Thrust 相位振子系综示例展示如何利用 Thrust 和 CUDA 分析全局耦合振子, 借助现代图形设备的强大能力.

thrust/phase_oscillator_chain.cu

Thrust 相位振子链示例展示如何用 Thrust 和 odeint 对最近邻耦合振子链进行积分.

thrust/lorenz_parameters.cu

Lorenz 参数示例展示如何借助 Thrust 求解常微分方程系综, 以研究 ODE 对某些参数的依赖关系.

thrust/relaxation.cu

Thrust 用法的另一个示例.

ublas/lorenz_ublas.cpp

此示例展示 ublas 向量类型如何与 odeint 配合使用.

vexcl/lorenz_ensemble.cpp

此示例展示 VexCL (一个 OpenCL 计算框架) 如何与 odeint 配合使用.

openmp/lorenz_ensemble_simple.cpp

使用连续数据的 OpenMP Lorenz 吸引子参数研究.

openmp/lorenz_ensemble.cpp

使用拆分数据的 OpenMP Lorenz 吸引子参数研究.

openmp/lorenz_ensemble_nested.cpp

使用嵌套 vector_space_algebra 的 OpenMP Lorenz 吸引子参数研究.

openmp/phase_chain.cpp

具有连续状态的 OpenMP 最近邻耦合相位链.

openmp/phase_chain_omp_state.cpp

具有拆分状态的 OpenMP 最近邻耦合相位链.

mpi/phase_chain.cpp

MPI 最近邻耦合相位链.

2d_lattice/spreading.cpp

此示例展示 vector< vector< T > > 如何用作 odeint 的状态类型, 以及如何实现该状态的调整大小机制.

quadmath/black_hole.cpp

此示例展示 gcc libquadmath 如何与 odeint 配合使用. 它提供一种高精度浮点类型, 本示例中将其适配到 odeint.

molecular_dynamics.cpp

使用 Velocity-Verlet 方法的非常基础的分子动力学模拟.
