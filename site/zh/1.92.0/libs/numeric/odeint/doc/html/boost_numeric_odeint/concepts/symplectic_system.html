辛系统

说明

本概念描述如何定义以广义坐标 q 和广义动量 p 写出的辛系统:

q'(t) = f(p)

p'(t) = g(q)

这种情况典型地出现在具有可分离哈密顿量的哈密顿系统中:

H(p,q) = Hkin(p) + V(q)

由此得到运动方程:

q'(t) = dHkin / dp = f(p)

p'(t) = dV / dq = g(q)

这种情况的算法实现由一对针对 f 和 g 的可调用对象描述, 它们具有特定的参数签名. 这样的系统应实现为函数或函数对象的 std::pair. 辛系统用于 symplectic_rkn_sb3a_mclachlan 等辛步进器中.
