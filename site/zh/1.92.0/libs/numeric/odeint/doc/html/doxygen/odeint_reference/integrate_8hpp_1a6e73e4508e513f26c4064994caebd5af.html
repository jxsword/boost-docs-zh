函数模板 integrate

boost::numeric::odeint::integrate — 积分 ODE 且不调用观察器.

概要

// In header: <boost/numeric/odeint/integrate/integrate.hpp>


template<typename System, typename State, typename Time> 
  size_t integrate(System system, State & start_state, Time start_time, 
                   Time end_time, Time dt);

说明

以 start_state 为初始条件、dt 为初始时间步长, 用 system 给出的 ODE 从 start_time 积分到 end_time. 此函数使用稠密输出 dopri5 步进器, 执行带步长控制的自适应积分, 因此 dt 在积分期间会变化. 此方法使用 1E-6 的标准误差界限. 不调用观察器.

重要

此函数模板还有第二个版本, 它显式要求将值类型作为模板参数, 即 integrate< double >( sys , x , t0 , t1 , dt );

参数:

system

待求解的系统函数, 即常微分方程的右端项.

start_state

初始状态.

start_time

积分的起始时间.

end_time

积分的结束时间.

dt

初始步长, 会在积分期间调整.

返回:

已执行的步数.
