说明

Bulirsch-Stoer 是一种同时调整步长和方法阶数的受控步进器. 该算法使用改进中点法和多项式外推来计算解.

模板参数

  1. typename State

    状态类型.

  2. typename Value = double

    值类型.

  3. typename Deriv = State

    表示状态的时间导数的类型.

  4. typename Time = Value

    表示自变量 - 时间 - 的时间类型.

  5. typename Algebra = typename algebra_dispatcher< State >::algebra_type

    代数类型.

  6. typename Operations = typename operations_dispatcher< State >::operations_type

    运算类型.

  7. typename Resizer = initially_resizer

    调整大小策略类型.

  2. template<typename System, typename StateInOut> 
  controlled_step_result 
  try_step(System system, StateInOut & x, time_type & t, time_type & dt);
    尝试执行一步.

    此方法尝试以步长 dt 执行一步. 如果误差估计过大, 该步将被拒绝, 方法返回 fail, 且步长 dt 会被减小. 如果误差估计足够小, 则执行该步, 返回 success, 并且 dt 可能会增大以使步长尽可能大. 若执行了该步, 此方法还会更新 t. 此外, 如有需要还会调整步进器的内部阶数.

    参数:

    system

    待求解的系统函数, 即 ODE 的右端项. 它必须满足 Simple System 概念.

    x

    待求解 ODE 的状态. 若该步成功则被覆写.

    t

    时间值. 若该步成功则更新.

    dt

    步长. 会被更新.

    返回:

    若该步被接受则为 success, 否则为 fail.
