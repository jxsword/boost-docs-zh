说明

Runge-Kutta Cash-Karp 方法是求解常微分方程的标准方法之一, 见 en.wikipedia.org/wiki/Cash-Karp_method. 该方法是显式的, 满足 Error Stepper 概念. 提供步长控制, 但此方法不提供连续输出.

本类派生自 explicit_error_stepper_base, 并通过 CRTP (当前递归模板模式) 继承其接口. 本类直接实现该方法, 因此不使用泛型 Runge-Kutta 算法.

    状态类型.

  2. typename Value = double

    值类型.

  3. typename Deriv = State

    表示状态的时间导数的类型.

  4. typename Time = Value

    表示自变量 - 时间 - 的时间类型.

  5. typename Algebra = typename algebra_dispatcher< State >::algebra_type

    代数类型.

  6. typename Operations = typename operations_dispatcher< State >::operations_type

    运算类型.

  7. typename Resizer = initially_resizer

    调整大小策略类型.

  2. template<typename System, typename StateIn, typename DerivIn, 
         typename StateOut, typename Err> 
  void do_step_impl(System system, const StateIn & in, const DerivIn & dxdt, 
                    time_type t, StateOut & out, time_type dt, Err & xerr);
    此方法执行一步. 导数 dxdt, 即 in 在时间 t 处的导数, 传递给该方法.

    结果以非原地方式更新, 即输入在 in 中, 输出在 out 中. 此外, 误差估计存储在 xerr 中. 此步进功能由 explicit_error_stepper_base 提供, 不应直接调用 do_step_impl.

    参数:

    system

    待求解的系统函数, 即 ODE 的右端项. 它必须满足 Simple System 概念.

    in

    待求解 ODE 的状态. 此方法不修改 in

    dxdt

    x 在 t 处的导数.

    t

    执行该步的时间值.

    out

    该步的结果写入 out.

    dt

    步长.

    xerr

    误差估计的结果写入 xerr.
