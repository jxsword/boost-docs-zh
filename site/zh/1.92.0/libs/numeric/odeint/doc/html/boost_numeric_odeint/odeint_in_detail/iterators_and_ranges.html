示例

odeint 支持沿常微分方程近似解进行迭代的迭代器. 迭代器为你提供了 integrate 函数之外的另一种选择. 此外, C++ 标准库和 Boost.Range 中的许多标准算法都可以配合 odeint 的迭代器使用.

与 integrate 函数 保持一致, 这里提供了多种迭代器类型, 即 const_step_iterator、adaptive_step_iterator、n_step_iterator 和 times_iterator -- 每种都有两个版本: 要么只以 state 为值类型, 要么以 std::pair<state,time> 为值类型. 它们都是单遍迭代器. 下面我们给出几个示例, 展示如何将这些迭代器与 std 算法配合使用.

runge_kutta4< state_type > stepper;
state_type x = {{ 10.0 , 10.0 , 10.0 }};
double res = std::accumulate( make_const_step_iterator_begin( stepper , lorenz() , x , 0.0 , 1.0 , 0.01 ) ,
                              make_const_step_iterator_end( stepper , lorenz() , x ) ,
                              0.0 ,
                              []( double sum , const state_type &x ) {
                                  return sum + x[0]; } );
cout << res << endl;

本示例对解的所有 x 值进行累加. 注意, 对迭代器解引用会得到 ODE 的当前状态 x (accumulate lambda 的第二个参数). 迭代器本身没有直接出现在本示例中, 而是由工厂函数 make_const_step_iterator_begin 和 make_const_step_iterator_end 生成. odeint 还支持 Boost.Range, 借助工厂函数 make_const_step_range 可以用更紧凑的形式书写上面的示例, 但现在使用的是来自 __bost_range 的 boost::accumulate:

runge_kutta4< state_type > stepper;
state_type x = {{ 10.0 , 10.0 , 10.0 }};
double res = boost::accumulate( make_const_step_range( stepper , lorenz() , x , 0.0 , 1.0 , 0.01 ) , 0.0 ,
                                []( double sum , const state_type &x ) {
                                    return sum + x[0]; } );
cout << res << endl;

第二种迭代器类型同样是固定步长的迭代器. 但这种迭代器的值类型由 ODE 解的时间和状态组成的 pair. 例如

runge_kutta4< state_type > stepper;
state_type x = {{ 10.0 , 10.0 , 10.0 }};
double res = boost::accumulate( make_const_step_time_range( stepper , lorenz() , x , 0.0 , 1.0 , 0.01 ) , 0.0 ,
                                []( double sum , const std::pair< const state_type &, double > &x ) {
                                    return sum + x.first[0]; } );
cout << res << endl;

此时的工厂函数是 make_const_step_time_iterator_begin、make_const_step_time_iterator_end 和 make_const_step_time_range. 注意, lambda 现在期望一个 std::pair, 因为这是 const_step_time_iterator 的值类型.

接下来我们讨论自适应迭代器, 它们与固定步长迭代器完全类似, 但基于自适应步进器例程, 因此会在迭代过程中调整步长. 例如

auto stepper = make_controlled( 1.0e-6 , 1.0e-6 , runge_kutta_cash_karp54< state_type >() );
state_type x = {{ 10.0 , 10.0 , 10.0 }};
double res = boost::accumulate( make_adaptive_range( stepper , lorenz() , x , 0.0 , 1.0 , 0.01 ) , 0.0 ,
                                []( double sum , const state_type& x ) {
                                    return sum + x[0]; } );
cout << res << endl;


auto stepper = make_controlled( 1.0e-6 , 1.0e-6 , runge_kutta_cash_karp54< state_type >() );
state_type x = {{ 10.0 , 10.0 , 10.0 }};
double res = boost::accumulate( make_adaptive_time_range( stepper , lorenz() , x , 0.0 , 1.0 , 0.01 ) , 0.0 ,
                                []( double sum , const pair< const state_type& , double > &x ) {
                                    return sum + x.first[0]; } );
cout << res << endl;

注释

'adaptive_iterator and adaptive_time_iterator' 只能与 受控步进器 或 稠密输出步进器 配合使用.

一般而言, 可以说对 const_step_iterator 的某个范围进行迭代, 其行为类似于一次 integrate_const 函数调用; adaptive_iterator 与 integrate_adaptive、n_step_iterator 与 integrate_n_steps, 以及最后的 times_iterator 与 integrate_times 也同样如此.

下面列出现有迭代器最重要的性质:

const_step_iterator

  • 定义: const_step_iterator< Stepper , System , State >
  • value_type 是 State
  • reference_type 是 State const&
  • 工厂函数
    • make_const_step_iterator_begin( stepper , system , state , t_start , t_end , dt )
    • make_const_step_iterator_end( stepper , system , state )
    • make_const_step_range( stepper , system , state , t_start , t_end , dt )
  • 此迭代器可与所有满足 Stepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • state 的值是迭代过程中 ODE 的当前状态.

const_step_time_iterator

  • 定义: const_step_time_iterator< Stepper , System , State >
  • value_type 是 std::pair< State , Stepper::time_type >
  • reference_type 是 std::pair< State const& , Stepper::time_type > const&
  • 工厂函数
    • make_const_step_time_iterator_begin( stepper , system , state , t_start , t_end , dt )
    • make_const_step_time_iterator_end( stepper , system , state )
    • make_const_step_time_range( stepper , system , state , t_start , t_end , dt )
  • 此迭代器可与所有满足 Stepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • 此迭代器会更新 state 的值. state 的值是迭代过程中 ODE 的当前状态.

adaptive_step_iterator

  • 定义: adaptive_iterator< Stepper , System , State >
  • value_type 是 State
  • reference_type 是 State const&
  • 工厂函数
    • make_adaptive_iterator_begin( stepper , system , state , t_start , t_end , dt )
    • make_adaptive_iterator_end( stepper , system , state )
    • make_adaptive_range( stepper , system , state , t_start , t_end , dt )
  • 此迭代器可与所有满足 ControlledStepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • 对于满足 ControlledStepper 概念的步进器, state 会根据 ODE 的当前状态被修改. 对于 DenseOutputStepper, 出于性能优化的考虑, 被修改的不是状态而是步进器本身.

adaptive_step_time_iterator

  • 定义: adaptive_iterator< Stepper , System , State >
  • value_type 是 std::pair< State , Stepper::time_type >
  • reference_type 是 std::pair< State const& , Stepper::time_type > const&
  • 工厂函数
    • make_adaptive_time_iterator_begin( stepper , system , state , t_start , t_end , dt )
    • make_adaptive_time_iterator_end( stepper , system , state )
    • make_adaptive_time_range( stepper , system , state , t_start , t_end , dt )
  • 此迭代器可与所有满足 ControlledStepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • 对于满足 ControlledStepper 概念的步进器, state 会根据 ODE 的当前状态被修改. 对于 DenseOutputStepper, 出于性能优化的考虑, 被修改的不是状态而是步进器本身.

n_step_iterator

  • 定义: n_step_iterator< Stepper , System , State >
  • value_type 是 State
  • reference_type 是 State const&
  • 工厂函数
    • make_n_step_iterator_begin( stepper , system , state , t_start , dt , num_of_steps )
    • make_n_step_iterator_end( stepper , system , state )
    • make_n_step_range( stepper , system , state , t_start , dt , num_of_steps )
  • 此迭代器可与所有满足 Stepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • state 的值是迭代过程中 ODE 的当前状态.

n_step_time_iterator

  • 定义: n_step_time_iterator< Stepper , System , State >
  • value_type 是 std::pair< State , Stepper::time_type >
  • reference_type 是 std::pair< State const& , Stepper::time_type > const&
  • 工厂函数
    • make_n_step_time_iterator_begin( stepper , system , state , t_start , dt , num_of_steps )
    • make_n_step_time_iterator_end( stepper , system , state )
    • make_n_step_time_range( stepper , system , state , t_start , dt , num_of_steps )
  • 此迭代器可与所有满足 Stepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • 此迭代器会更新 state 的值. state 的值是迭代过程中 ODE 的当前状态.

times_iterator

  • 定义: times_iterator< Stepper , System , State , TimeIterator >
  • value_type 是 State
  • reference_type 是 State const&
  • 工厂函数
    • make_times_iterator_begin( stepper , system , state , t_start , t_end , dt )
    • make_times_iterator_end( stepper , system , state )
    • make_times_range( stepper , system , state , t_start , t_end , dt )
  • 此迭代器可与所有满足 Stepper 概念、ControlledStepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • state 的值是迭代过程中 ODE 的当前状态.

times_time_iterator

  • 定义: times_time_iterator< Stepper , System , State , TimeIterator>
  • value_type 是 std::pair< State , Stepper::time_type >
  • reference_type 是 std::pair< State const& , Stepper::time_type > const&
  • 工厂函数
    • make_times_time_iterator_begin( stepper , system , state , t_start , t_end , dt )
    • make_times_time_step_iterator_end( stepper , system , state )
    • make_times_time_range( stepper , system , state , t_start , t_end , dt )
  • 此迭代器可与所有满足 Stepper 概念、ControlledStepper 概念或 DenseOutputStepper 概念的步进器配合工作.
  • 此迭代器会更新 state 的值. state 的值是迭代过程中 ODE 的当前状态.
