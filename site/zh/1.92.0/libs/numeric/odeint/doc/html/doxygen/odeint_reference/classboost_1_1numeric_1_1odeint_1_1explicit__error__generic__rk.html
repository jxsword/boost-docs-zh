类模板 explicit_error_generic_rk

boost::numeric::odeint::explicit_error_generic_rk — 带误差估计的显式 Runge-Kutta 算法的泛型实现. 本类是所有带误差估计的显式 Runge-Kutta 步进器的基类.

概要

// In header: <boost/numeric/odeint/stepper/explicit_error_generic_rk.hpp>

template<size_t StageCount, size_t Order, size_t StepperOrder, 
         size_t ErrorOrder, typename State, typename Value = double, 
         typename Deriv = State, typename Time = Value, 
         typename Algebra = typename algebra_dispatcher< State >::algebra_type, 
         typename Operations = typename operations_dispatcher< State >::operations_type, 
         typename Resizer = initially_resizer> 
class explicit_error_generic_rk : public explicit_error_stepper_base {
public:
  // types

  typedef stepper_base_type::time_type          time_type;

说明

本类以泛型方式实现带误差估计的显式 Runge-Kutta 算法. Butcher 表传递给步进器, 步进器借助模板元编程算法构造步进方案. 待办: 添加示例!

本类派生自 explicit_error_stepper_base, 后者提供步进器接口.

模板参数

  1. size_t StageCount

    Runge-Kutta 算法的级数.

  2. size_t Order

    步进器在无误差估计使用时的阶数.

  3. size_t StepperOrder

    步进器在带误差估计使用时单步的阶数. 通常 Order 与 StepperOrder 取相同值.

  4. size_t ErrorOrder

    步进器在带误差估计使用时误差步的阶数.

  5. typename State

    表示 ODE 状态的类型.

  6. typename Value = double

    计算中使用的浮点类型.

  7. typename Deriv = State
  8. typename Time = Value

    表示 ODE 自变量 - 时间 - 的类型.

  9. typename Algebra = typename algebra_dispatcher< State >::algebra_type

    代数类型.

  10. typename Operations = typename operations_dispatcher< State >::operations_type

    运算类型.

  11. typename Resizer = initially_resizer

    调整大小策略类型.

explicit_error_generic_rk 公有成员函数

  1. explicit_error_generic_rk(const coef_a_type & a, const coef_b_type & b, 
                          const coef_b_type & b2, const coef_c_type & c, 
                          const algebra_type & algebra = algebra_type());
    用给定参数 a、b、b2 和 c 构造 explicit_error_generik_rk 类. 系数的详细信息参见示例一节.

    参数:

    a

    Butcher 表中参数 b 的三角矩阵.

    b

    Butcher 表的最后一行.

    b2

    用于估计误差的低阶求值参数.

    c

    用于计算 Butcher 表中时间点的参数.

    algebra

    在 explicit_stepper_base 内部制作并存储 algebra 的一个副本.

    		 
  2. template<typename System, typename StateIn, typename DerivIn, 
         typename StateOut, typename Err> 
  void do_step_impl(System system, const StateIn & in, const DerivIn & dxdt, 
                    time_type t, StateOut & out, time_type dt, Err & xerr);
    此方法执行一步. 导数 dxdt, 即 in 在时间 t 处的导数, 传递给该方法. 结果以非原地方式更新, 即输入在 in 中, 输出在 out 中. 此外, 误差估计存储在 xerr 中. explicit_error_stepper_base 使用 do_step_impl.

    参数:

    system

    待求解的系统函数, 即 ODE 的右端项. 它必须满足 Simple System 概念.

    in

    待求解 ODE 的状态. 此方法不修改 in

    dxdt

    x 在 t 处的导数.

    t

    执行该步的时间值.

    out

    该步的结果写入 out.

    dt

    步长.

    xerr

    误差估计的结果写入 xerr.
