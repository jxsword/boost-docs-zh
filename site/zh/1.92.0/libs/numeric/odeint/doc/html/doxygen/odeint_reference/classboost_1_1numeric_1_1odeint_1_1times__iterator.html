类模板 times_iterator

boost::numeric::odeint::times_iterator — 具有给定求值点的 ODE 迭代器. 此迭代器的值类型是步进器的状态类型.

概要

// In header: <boost/numeric/odeint/iterator/times_iterator.hpp>

template<typename Stepper, typename System, typename State, 
         typename TimeIterator> 
class times_iterator {
public:

  // public member functions
  times_iterator(Stepper, System, State &, TimeIterator, TimeIterator, 
                 time_type);
  times_iterator(Stepper, System, State &);
};

说明

实现一个迭代器, 表示从 *t_start 到 *t_end 的 ODE 解, 在由序列 t_start 到 t_end 给定的时间点处求值. t_start 和 t_end 是表示时间点序列的迭代器, ODE 的解应在这些时间点处求值. 每次迭代后, 迭代器解引用为下一时间 *t_start++ 处的状态 x, 直到到达 t_end. 此迭代器可与 Stepper、ControlledStepper 和 DenseOutputStepper 一起使用, 并且总是充分利用给定步进器的所有能力. 对这种迭代器范围执行 for_each 的行为类似于 integrate_times 例程.

times_iterator 是单遍迭代器的一个模型.

此迭代器的值类型是步进器的状态类型. 因此只能访问状态, 而不能访问当前时间.

模板参数

  1. typename Stepper

    迭代期间应使用的步进器类型.

  2. typename System

    待求解系统函数 (ODE) 的类型.

  3. typename State

    ODE 的状态类型.

  4. typename TimeIterator

    时间点序列的迭代器类型.

times_iterator 公有成员函数

  1. times_iterator(Stepper stepper, System sys, State & s, TimeIterator t_start, 
               TimeIterator t_end, time_type dt);
  2. times_iterator(Stepper stepper, System sys, State & s);
