用法、编译、头文件

odeint 是一个仅头文件库, 无需链接预编译代码. 通过如下方式包含

#include <boost/numeric/odeint.hpp>

它会包含本库的所有头文件. odeint 的所有函数和类都位于命名空间

using namespace boost::numeric::odeint;

也可以只包含库的一部分. 这是推荐的方式, 因为可以节省大量编译时间.

  • #include <boost/numeric/odeint/stepper/XYZ.hpp> - 所有步进器的包含路径, XYZ 是步进器的占位符.
  • #include <boost/numeric/odeint/algebra/XYZ.hpp> - 所有代数.
  • #include <boost/numeric/odeint/util/XYZ.hpp> - 诸如 is_resizeable、same_size 或 resize 之类的实用函数.
  • #include <boost/numeric/odeint/integrate/XYZ.hpp> - integrate 例程.
  • #include <boost/numeric/odeint/iterator/XYZ.hpp> - range 与迭代器函数.
  • #include <boost/numeric/odeint/external/XYZ.hpp> - 面向外部库的各种绑定器.
