注释

以下内容不适用于 implicit_euler 或 Rosenbrock 4 等隐式步进器, 因为在这些步进器中 state_type 不能从 ublas::vector 更改, 且不使用代数/运算.

说明

State、Algebra 和 Operations 共同定义了一个概念, 描述步进器算法所需的数学向量运算如何执行. 步进器内部完成的典型向量运算是

y = Σ αi xi.

State 表示 ODE 的状态变量, 通常记作 x. 在算法实现上, 状态通常实现为 vector< double > 或 array< double , N >, 不过, 得益于 odeint 的泛型性, 基本上任何东西都可以用作状态类型. 这类数学表达式的算法对应物分为两部分. 第一, Algebra 用于处理方程的向量特性. 当状态类型是 vector 时, 这意味着 Algebra 负责对所有向量元素进行迭代. 第二, Operations 用于表示施加到每个向量元素上的实际运算. 于是, Algebra 遍历 State 的所有元素, 并对每个元素调用取自 Operations 的一个运算. 这正是 State、Algebra 和 Operations 必须协同工作才能使 odeint 运行的地方. 请查看 range_algebra 和 default_operations, 以了解其实现示例.

下文将描述 State、Algebra 和 Operations 在步进器实现中如何协同使用.

预定义实现

作为标准配置, odeint 使用 range_algebra 和 default_operations, 这足以应对大多数情况. 不过, 还存在其他一些选择, 或者能获得更好的性能, 或者能确保与其他库的互操作性. 下文列出可在步进器中使用的现有 Algebra/Operations 配置.
