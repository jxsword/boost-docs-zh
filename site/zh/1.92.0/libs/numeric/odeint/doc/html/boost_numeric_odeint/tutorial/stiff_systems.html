刚性系统

一类重要的常微分方程是所谓的刚性系统, 其特征在于两个或多个量级不同的时间尺度. 此类系统的一个例子见于化学系统, 其中各子反应的反应速率可能相差很大, 例如:

d S​1 / dt = - 101 S​2 - 100 S​1

d S​2 / dt = S​1

为了高效地数值求解刚性系统, 需要 Jacobian

J = d f​i / d x​j

下面是上述例子的定义

typedef boost::numeric::ublas::vector< double > vector_type;
typedef boost::numeric::ublas::matrix< double > matrix_type;

struct stiff_system
{
    void operator()( const vector_type &x , vector_type &dxdt , double /* t */ )
    {
        dxdt[ 0 ] = -101.0 * x[ 0 ] - 100.0 * x[ 1 ];
        dxdt[ 1 ] = x[ 0 ];
    }
};

struct stiff_system_jacobi
{
    void operator()( const vector_type & /* x */ , matrix_type &J , const double & /* t */ , vector_type &dfdt )
    {
        J( 0 , 0 ) = -101.0;
        J( 0 , 1 ) = -100.0;
        J( 1 , 0 ) = 1.0;
        J( 1 , 1 ) = 0.0;
        dfdt[0] = 0.0;
        dfdt[1] = 0.0;
    }
};

状态类型必须是 ublas::vector, 矩阵类型必须是 ublas::matrix, 因为刚性积分器只接受这些类型. 不过, 你可能也想在这个系统上使用非刚性积分器 (后面我们会为演示这样做). 因此, 我们希望通过把 operator() 模板化, 让同一函数也能配合其他 state_type 使用:

typedef boost::numeric::ublas::vector< double > vector_type;
typedef boost::numeric::ublas::matrix< double > matrix_type;

struct stiff_system
{
    template< class State >
    void operator()( const State &x , State &dxdt , double t )
    {
        ...
    }
};

struct stiff_system_jacobi
{
    template< class State , class Matrix >
    void operator()( const State &x , Matrix &J , const double &t , State &dfdt )
    {
        ...
    }
};

现在你可以将 stiff_system 与 std::vector 或 std::array 配合使用. 在示例中, f(x,t) 的显式时间导数在 Jacobian 中单独引入. 如果 df / dt = 0, 只需将 dfdt 填为零.

刚性系统的一个著名求解器是 Rosenbrock 方法. 它具有步长控制和稠密输出功能, 可以像所有其他步进器一样使用:

vector_type x( 2 , 1.0 );

size_t num_of_steps = integrate_const( make_dense_output< rosenbrock4< double > >( 1.0e-6 , 1.0e-6 ) ,
        make_pair( stiff_system() , stiff_system_jacobi() ) ,
        x , 0.0 , 50.0 , 0.01 ,
        cout << phoenix::arg_names::arg2 << " " << phoenix::arg_names::arg1[0] << "\n" );

积分过程中执行了 71 步. 与经典 Runge-Kutta 求解器相比, 这是一个非常好的结果. 例如, 带步长控制和稠密输出的 Dormand-Prince 5 方法需要 1531 步.

vector_type x2( 2 , 1.0 );

size_t num_of_steps2 = integrate_const( make_dense_output< runge_kutta_dopri5< vector_type > >( 1.0e-6 , 1.0e-6 ) ,
        stiff_system() , x2 , 0.0 , 50.0 , 0.01 ,
        cout << phoenix::arg_names::arg2 << " " << phoenix::arg_names::arg1[0] << "\n" );

注意, 我们使用了 Boost.Phoenix (一个出色的函数式编程库) 来创建和组合观察器.
