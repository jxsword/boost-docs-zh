稠密输出步进器

本概念规定了稠密输出步进器在 integrate 函数 中使用时必须满足的接口.

说明

遵循本稠密输出步进器 (Dense Output Stepper) 概念的稠密输出步进器, 能够对 ODE 的解 x(t) 执行单步, 得到 x(t+dt). 步长 dt 可能因误差控制而自动调整. 稠密输出步进器还能对解进行插值, 以计算状态 x(t') 在任意点 t <= t' <= t+dt 处的值.

Associated types

  • state_type

    Stepper::state_type

    刻画 ODE 状态的类型, 即 x.

  • deriv_type

    Stepper::deriv_type

    刻画 ODE 导数的类型, 即 d x/dt.

  • time_type

    Stepper::time_type

    刻画 ODE 因变量的类型, 即时间 t.

  • value_type

    Stepper::value_type

    步进器内部使用的数值数据类型, 例如 float、double、complex&lt; double &gt;.

  • stepper_category

    Stepper::stepper_category

    表征步进器类别的标签类型. 该类型必须可转换为 dense_output_stepper_tag.

记法约定

stepper

Stepper 类型的对象

x0, x

State 类型的对象

t0, dt0, t

Stepper::time_type 类型的对象

sys

定义 ODE 的对象, 应当是 系统、辛系统、简单辛系统 或 隐式系统 的一个模型.

语义

初始化积分

stepper.initialize( x0 , t0 , dt0 )

void

用初值 x0、t0 和 dt0 初始化步进器.

执行一步

stepper.do_step( sys )

std::pair< Stepper::time_type , Stepper::time_type >

使用由 sys 定义的 ODE 执行一步. 步长可能因误差控制而在内部被改变. 该函数返回一个 pair, 其中包含 t 和 t+dt, 表示可执行插值的区间.

执行插值

stepper.calc_state( t_inter , x )

void

执行插值以计算 /x(tinter/), 其中 /t <= tinter <= t+dt/.

获取当前时间

stepper.current_time()

const Stepper::time_type&

返回步进器的当前时间 t+dt, 即上一步的结束时间, 也是下一次调用 do_step 的起始时间

获取当前状态

stepper.current_state()

const Stepper::state_type&

返回步进器的当前状态, 即 x(t+dt), 也就是 stepper.current_time() 所返回时刻的状态

获取当前时间步

stepper.current_time_step()

const Stepper::time_type&

返回步进器的当前步长, 即 dt
