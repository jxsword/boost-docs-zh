State Wrapper

说明

State Wrapper 概念描述了 odeint 创建临时状态对象以在步进器的 do_step 方法中保存中间结果的方式.

记法约定

State

作为 ODE 的 state_type 的一个类型

WrappedState

针对状态类型 State 的、作为 State Wrapper 模型的一个类型.

x

State 类型的对象

w

WrappedState 类型的对象

语义

获取可调整大小性

is_resizeable< State >

std::false_type 或者 std::true_type

返回 std::true_type, 如果 State 可调整大小; 否则返回 std::false_type.

创建 WrappedState 类型

state_wrapper< State >

WrappedState

创建用于 WrappedState 的类型, 对应状态类型 State

构造函数

WrappedState()

WrappedState

以空状态构造一个 state wrapper

复制构造函数

WrappedState( w )

WrappedState

构造一个 state wrapper, 其状态与 w 中的状态大小相同

获取状态

w.m_v

State

返回此 state wrapper 的 State 对象.
