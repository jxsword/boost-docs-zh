复数状态类型

到目前为止, 我们看到的几个示例都是针对实数值定义的. odeint 也能处理复数状态类型, 即定义在复向量空间上的 ODE. 一个例子是 Stuart-Landau 振子

d Ψ / dt = ( 1 + i η ) Ψ + ( 1 + i α ) | Ψ |2 Ψ

其中 Ψ 是复变量, i 为虚数单位. 使用 complex< double > 作为状态类型的该 ODE 的 C++ 定义可能如下所示

typedef complex< double > state_type;

struct stuart_landau
{
    double m_eta;
    double m_alpha;

    stuart_landau( double eta = 1.0 , double alpha = 1.0 )
    : m_eta( eta ) , m_alpha( alpha ) { }

    void operator()( const state_type &x , state_type &dxdt , double ) const
    {
        const complex< double > I( 0.0 , 1.0 );
        dxdt = ( 1.0 + m_eta * I ) * x - ( 1.0 + m_alpha * I ) * norm( x ) * x;
    }
};

也可以用函数而不是函数对象来实现它

double eta = 1.0;
double alpha = 1.0;

void stuart_landau( const state_type &x , state_type &dxdt , double t )
{
    const complex< double > I( 0.0 , 1.0 );
    dxdt = ( 1.0 + m_eta * I ) * x - ( 1.0 + m_alpha * I ) * norm( x ) * x;
}

我们强烈建议使用第一种方案. 在这种情况下, 你可以显式控制系统参数, 而不必局限于使用全局变量来参数化振子.

选择步进器类型时, 必须考虑到这种"非寻常"的状态类型: 它是一个单一的 complex<double>, 而不是前面示例中使用的向量类型. 这意味着步进器算法内部不必对向量元素进行迭代. Odeint 已经能检测到这一点, 并自动使用 vector_space_algebra 进行计算. 你可以通过为步进器提供额外的模板参数 (包括 vector_space_algebra) 来强制这一点. 代数用法的细节见 适配你自己的状态类型 一节.

state_type x = complex< double >( 1.0 , 0.0 );

const double dt = 0.1;

typedef runge_kutta4< state_type > stepper_type;

integrate_const( stepper_type() , stuart_landau( 2.0 , 1.0 ) , x , 0.0 , 10.0 , dt , streaming_observer( cout ) );

Stuart-Landau 示例的完整 cpp 文件可在此处找到 stuart_landau.cpp
