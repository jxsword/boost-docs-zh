函数模板 integrate_n_steps

boost::numeric::odeint::integrate_n_steps — 与上面相同的函数, 但不带检查器.

概要

// In header: <boost/numeric/odeint/integrate/integrate_n_steps.hpp>


template<typename Stepper, typename System, typename State, typename Time, 
         typename Observer> 
  Time integrate_n_steps(Stepper stepper, System system, State & start_state, 
                         Time start_time, Time dt, size_t num_of_steps, 
                         Observer observer);

说明

以恒定步长积分 ODE.

此函数与 integrate_const 类似. 观察器在等距时间间隔 t0 + n*dt 处调用. 若 Stepper 是无步长控制的普通步进器, dt 也用于数值格式. 若提供的是 ControlledStepper, 算法可能减小步长以满足误差界限, 但确保始终在等距时间点 t0 + n*dt 处调用观察器. 若使用 DenseOutputStepper, 步长同样可以变化, 并使用稠密输出在等距时间点调用观察器. 最终积分时间始终为 t0 + num_of_steps*dt. 若提供 max_step_checker 作为 StepOverflowChecker, 当在观察器调用之间执行了过多无进展的步 (默认: 500) 时, 会抛出 no_progress_errror. 若未提供检查器, 则不执行此类溢出检查.

参数:

stepper

用于数值积分的步进器.

system

定义 ODE 右端项的函数/函数对象.

start_state

初始条件 x0.

start_time

初始时间 t0.

dt

观察器调用之间的时间步, 不一定是积分的时间步.

num_of_steps

要执行的步数

observer

在等距时间间隔处调用的函数/函数对象.

返回:

已执行的步数.
