使用任意精度浮点类型

有时需要比标准浮点类型更高精度的结果. 由于 odeint 允许配置基本数值类型, 它非常适合配合任意精度类型运行. 为此, 只需要一个提供任意精度数值表示及其基本运算的库. Boost.Multiprecision 正是这样做的 boost 库. 如以下示例所示, 利用 Boost.Multiprecision 配合 odeint 求解 ODE 非常简单.

这里我们使用 cpp_dec_float_50 作为基本值类型, 它确保精确计算到 50 位十进制数字.

#include <boost/numeric/odeint.hpp>
#include <boost/multiprecision/cpp_dec_float.hpp>

using namespace std;
using namespace boost::numeric::odeint;

typedef boost::multiprecision::cpp_dec_float_50 value_type;

typedef std::array< value_type , 3 > state_type;

示例 ODE 再次选择 Lorenz 系统, 但这里必须确保所有常量都初始化为高精度值.

struct lorenz
{
    void operator()( const state_type &x , state_type &dxdt , value_type t ) const
    {
        const value_type sigma( 10 );
        const value_type R( 28 );
        const value_type b( value_type( 8 ) / value_type( 3 ) );

        dxdt[0] = sigma * ( x[1] - x[0] );
        dxdt[1] = R * x[0] - x[1] - x[0] * x[2];
        dxdt[2] = -b * x[2] + x[0] * x[1];
    }
};

实际的积分随后就很简单了:

state_type x = {{ value_type( 10.0 ) , value_type( 10.0 ) , value_type( 10.0 ) }};

cout.precision( 50 );
integrate_const( runge_kutta4< state_type , value_type >() ,
        lorenz() , x , value_type( 0.0 ) , value_type( 10.0 ) , value_type( value_type( 1.0 ) / value_type( 10.0 ) ) ,
        streaming_observer( cout ) );

完整示例见 lorenz_mp.cpp. 另一个比较高精度类型与标准 double 精度的示例见 cmp_precision.cpp.

此外, odeint 也可以与其他多精度库配合运行, 例如 gmp. 相关示例见 lorenz_gmpxx.cpp.
