说明

Runge-Kutta Dormand-Prince 5 方法是求解 ODE 的非常流行的方法, 见 . 该方法是显式的, 满足 Error Stepper 概念. 提供步长控制, 且连续输出可用, 这使该方法适合许多应用.

本类派生自 explicit_error_stepper_fsal_base, 并通过 CRTP (当前递归模板模式) 继承其接口. 该方法具有 FSAL (首尾相同, first-same-as-last) 性质. 更多细节参见 explicit_error_stepper_fsal_base.

模板参数

  1. typename State

    状态类型.

  2. typename Value = double

    值类型.

  3. typename Deriv = State

    表示状态的时间导数的类型.

  4. typename Time = Value

    表示自变量 - 时间 - 的时间类型.

  5. typename Algebra = typename algebra_dispatcher< State >::algebra_type

    代数类型.

  6. typename Operations = typename operations_dispatcher< State >::operations_type

    运算类型.

  7. typename Resizer = initially_resizer

    调整大小策略类型.

  1. runge_kutta_dopri5(const algebra_type & algebra = algebra_type());
    构造 runge_kutta_dopri5 类. 若 algebra 有默认构造函数, 此构造函数可用作默认构造函数.

    参数:

    algebra

    在 explicit_stepper_base 内部制作并存储 algebra 的一个副本.

    		 
  2. template<typename System, typename StateIn, typename DerivIn, 
         typename StateOut, typename DerivOut> 
  void do_step_impl(System system, const StateIn & in, 
                    const DerivIn & dxdt_in, time_type t, StateOut & out, 
                    DerivOut & dxdt_out, time_type dt);
    此方法执行一步. 导数 dxdt_in, 即 in 在时间 t 处的导数, 传递给该方法. 结果以非原地方式更新, 即输入在 in 中, 输出在 out 中. 此外, 导数也以非原地方式更新, 即假定输入在 dxdt_in 中, 输出在 dxdt_out 中. 此步进功能由 explicit_error_stepper_fsal_base 提供, 不应直接调用 do_step_impl.

    参数:

    system

    待求解的系统函数, 即 ODE 的右端项. 它必须满足 Simple System 概念.

    in

    待求解 ODE 的状态. 此方法不修改 in

    dxdt_in

    x 在 t 处的导数. 此方法不修改 dxdt_in

    t

    执行该步的时间值.

    out

    该步的结果写入 out.

    dxdt_out

    时间 t+dt 处新导数的结果.

    dt

    步长.

  4. template<typename StateOut, typename StateIn1, typename DerivIn1, 
         typename StateIn2, typename DerivIn2> 
  void calc_state(time_type t, StateOut & x, const StateIn1 & x_old, 
                  const DerivIn1 & deriv_old, time_type t_old, 
                  const StateIn2 &, const DerivIn2 & deriv_new, 
                  time_type t_new) const;
    此方法用于连续输出, 它计算状态 x 在时间 t 处的值, 所依据的是两个状态 old_state 和 current_state (分别位于时间点 t_old 和 t_new). 它还使用内部变量来计算结果. 因此, 此方法必须在两次成功的 do_step 调用之后调用.
