说明

Adams-Bashforth 方法是一种步数可配置的多步预测-校正算法. 步数由模板参数 Steps 指定, 随后它会使用前 Steps 步的结果. 另见 en.wikipedia.org/wiki/Linear_multistep_method. 目前最多支持 Steps=8. 该方法是显式的, 满足 Stepper 概念. 不提供步长控制或连续输出.

本类派生自 algebra_base, 并通过 CRTP (当前递归模板模式) 继承其接口. 更多细节参见 algebra_stepper_base.

模板参数

  1. size_t Steps

    步数 (最大为 8).

  2. typename State

    状态类型.

  3. typename Value = double

    值类型.

  4. typename Deriv = State

    表示状态的时间导数的类型.

  5. typename Time = Value

    表示自变量 - 时间 - 的时间类型.

  6. typename Algebra = typename algebra_dispatcher< State >::algebra_type

    代数类型.

  7. typename Operations = typename operations_dispatcher< State >::operations_type

    运算类型.

  8. typename Resizer = initially_resizer

    调整大小策略类型.

  9. typename InitializingStepper = runge_kutta4< State , Value , Deriv , Time , Algebra , Operations, Resizer >

    用于前两步的步进器.

    构造 adams_bashforth 类. 若 algebra 有默认构造函数, 此构造函数可用作默认构造函数.

  3. order_type order(void) const;
    返回算法的阶数, 它等于步数+1.

    返回:

    方法的阶数.

    		 
  4. template<typename System, typename StateInOut> 
  void do_step(System system, StateInOut & x, time_type t, time_type dt);
    此方法执行一步. 它原地变换结果.

    参数:

    system

    待求解的系统函数, 即常微分方程的右端项. 它必须满足 Simple System 概念.

    x

    待求解 ODE 的状态. 调用 do_step 后, 结果在 x 中更新.

    t

    执行该步的时间值.

    dt

    步长.

  void do_step(System system, const StateIn & in, time_type t, 
               const StateOut & out, time_type dt);
    该方法用由 Stepper 传入的步进器执行一步. ODE 的状态以非原地方式更新.

    参数:
