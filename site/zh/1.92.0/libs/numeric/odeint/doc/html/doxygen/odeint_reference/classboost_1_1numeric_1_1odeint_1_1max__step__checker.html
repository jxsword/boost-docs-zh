类 max_step_checker

boost::numeric::odeint::max_step_checker — 在积分函数中对步数执行溢出检查的类.

概要

// In header: <boost/numeric/odeint/integrate/max_step_checker.hpp>


class max_step_checker {
public:

  // public member functions
  max_step_checker(const int = 500);
  void reset();
  void operator()(void);
};

说明

如果想在积分例程期间执行了过多无进展的步时抛出运行时错误, 请向积分函数提供本类的实例.

max_step_checker 公有成员函数

  1. max_step_checker(const int max_steps = 500);
    构造 max_step_checker. max_steps 是抛出 runtime_error 之前允许的最大迭代次数.
  2. void reset();
    通过将内部计数器置为 0 来重置 max_step_checker.
  3. void operator()(void);
    递增计数器并执行迭代检查.
