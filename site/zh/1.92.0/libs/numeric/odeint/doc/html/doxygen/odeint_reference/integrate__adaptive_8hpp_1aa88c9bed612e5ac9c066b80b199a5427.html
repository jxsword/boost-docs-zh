函数模板 integrate_adaptive

boost::numeric::odeint::integrate_adaptive — 以自适应步长积分 ODE.

概要

// In header: <boost/numeric/odeint/integrate/integrate_adaptive.hpp>


template<typename Stepper, typename System, typename State, typename Time, 
         typename Observer> 
  size_t integrate_adaptive(Stepper stepper, System system, 
                            State & start_state, Time start_time, 
                            Time end_time, Time dt, Observer observer);

说明

此函数用给定的步进器积分 system 给出的 ODE. 每步之后都会调用观察器. 若步进器无误差控制, 步长保持恒定, 观察器在等距时间点 t0+n*dt 处调用. 若步进器是 ControlledStepper, 步长会被调整, 观察器以非等距间隔调用.

参数:

stepper

用于数值积分的步进器.

system

定义 ODE 右端项的函数/函数对象.

start_state

初始条件 x0.

start_time

初始时间 t0.

end_time

最终积分时间 tend.

dt

观察器调用之间的时间步, 不一定是积分的时间步.

observer

在等距时间间隔处调用的函数/函数对象.

返回:

已执行的步数.
