概述

odeint 是一个用于求解常微分方程初值问题 (IVP) 的库. 在数学上, 这些问题表述如下:

x'(t) = f(x,t), x(0) = x0.

x 和 f 可以是向量, 解是同时满足上述两个方程的某个函数 x(t). 下文中我们也将 x'(t) 记作 dxdt, 这也是源代码中导数的记号.

常微分方程几乎出现在自然科学的各个领域. 例如, 整个牛顿力学都由二阶微分方程描述. 可以肯定, 你在任何学科中都会遇到它们. 偏微分方程 (PDE) 离散化后也会产生常微分方程, 此时会出现耦合的常微分方程组, 有时也称为格点 ODE.

解 x(t) 的数值近似通过迭代计算. 最简单的算法是 Euler 格式: 从 x(0) 出发, 得到 x(dt) = x(0) + dt f(x(0),0). 然后可以用 x(dt) 以类似方式得到 x(2dt), 依此类推. Euler 方法是 1 阶的, 即每一步的误差为 ~ dt2. 这当然不能令人满意, 因此 Euler 方法很少用于实际问题, 只是作为一个说明性示例.

odeint 的主要目标是提供这样的数值方法: 其实现方式使算法与表示状态 x 所用的数据结构完全无关. 这样一来, odeint 适用于各种各样的情形, 并可与许多其他库配合使用. 除了状态定义为 std::vector 或 std::array 的常见情况外, 我们还为以下库提供原生支持:

  • Boost.uBLAS
  • Thrust, 使 odeint 天然地运行在 CUDA 设备上
  • gsl_vector, 以与 GSL 中的众多数值函数兼容
  • Boost.Range
  • Boost.Fusion (状态类型可以是 fusion vector)
  • Boost.Units
  • Intel Math Kernel Library, 用于获得最佳性能
  • VexCL, 用于 OpenCL
  • Boost.Graph (仍属实验性)
