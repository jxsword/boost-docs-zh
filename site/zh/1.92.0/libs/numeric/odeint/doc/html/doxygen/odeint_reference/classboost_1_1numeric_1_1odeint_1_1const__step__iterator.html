类模板 const_step_iterator

boost::numeric::odeint::const_step_iterator — 具有恒定步长的 ODE 迭代器. 此迭代器的值类型是步进器的状态类型.

概要

// In header: <boost/numeric/odeint/iterator/const_step_iterator.hpp>

template<typename Stepper, typename System, typename State> 
class const_step_iterator {
public:

  // public member functions
  const_step_iterator(Stepper, System, State &, time_type, time_type, 
                      time_type);
  const_step_iterator(Stepper, System, State &);
};

说明

实现一个迭代器, 表示从 t_start 到 t_end 的 ODE 解, 以恒定步长 dt 逐步求值. 每次迭代后, 迭代器解引用为下一时间 t+dt 处的状态 x. 此迭代器可与 Stepper 和 DenseOutputStepper 一起使用, 并且总是充分利用给定步进器的所有能力. 对这种迭代器范围执行 for_each 的行为类似于 integrate_const 例程.

const_step_iterator 是单遍迭代器的一个模型.

此迭代器的值类型是步进器的状态类型. 因此只能访问状态, 而不能访问当前时间.

模板参数

  1. typename Stepper

    迭代期间应使用的步进器类型.

  2. typename System

    待求解系统函数 (ODE) 的类型.

  3. typename State

    ODE 的状态类型.

const_step_iterator 公有成员函数

  1. const_step_iterator(Stepper stepper, System sys, State & s, time_type t_start, 
                    time_type t_end, time_type dt);
  2. const_step_iterator(Stepper stepper, System sys, State & s);
