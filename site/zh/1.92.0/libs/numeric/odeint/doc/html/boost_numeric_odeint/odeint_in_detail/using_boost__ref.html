使用 boost::ref

在 odeint 中, 所有系统函数和观察器都按值传递. 例如, 如果你调用某个步进器的 do_step 方法或 integrate 函数, 你的系统和步进器都会按值传递:

rk4.do_step( sys , x , t , dt );   // pass sys by value

这种行为适合大多数系统, 特别是当你的系统不包含任何数据或只包含少量参数时. 不过, 在某些情况下, 你的系统函数可能携带大量数据, 这时按值传递并不可取, 因为数据会被复制.

在这种情况下, 你可以方便地使用 boost::ref (及其同类 boost::cref), 它们按引用 (或常量引用) 传递参数. odeint 会解包这些参数, 你的系统对象完全不会被复制:

rk4.do_step( boost::ref( sys ) , x , t , dt );   // pass sys as references

同样的机制也可用于 integrate 函数中的观察器.

提示

如果你使用 C++11, 还可以使用 std::ref 和 std::cref
