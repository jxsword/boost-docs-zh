使用 boost::range

odeint 中的大多数步进器也接受以 range 形式给出的状态. range 是由 range 概念建模的值序列. 现有概念和 range 示例的概览见 Boost.Range. 这意味着不必非得用步进器的 state_type 来调用 do_step 方法.

odeint 中 Boost.Range 的一个用例已在 混沌系统 中展示: 状态由两部分组成, 一部分属于原系统, 另一部分属于扰动. range 用于只初始化 (求解) 系统部分而不触碰扰动部分, 即使用只由系统部分构成的 range. 之后, 再对包括扰动在内的完整状态求解.

另一个用例是由耦合单元构成的系统, 你希望用未耦合单元的 ODE 分别初始化每个单元. 一个例子是耦合 van-der-Pol 振子链, 它们用未耦合的 van-der-Pol 振子一致地初始化. 然后你可以使用 Boost.Range 只求解链中的单个振子.

简而言之, 你可以使用 Boost.Range 在两个期望不同大小状态的系统函数之间共用一个状态.

混沌系统 教程中给出了一个示例. 使用 Boost.Range 通常意味着你的系统函数需要适配 Boost.Range 的迭代器. 也就是说, 你的函数会以 range 被调用, 你需要从该 range 获取迭代器. 这很容易做到. 你必须把系统实现为类或结构体, 并把 operator() 模板化. 然后你可以使用 range_iterator 元函数以及 boost::begin 和 boost::end 来获取 range 的迭代器:

class sys
{
    template< class State , class Deriv >
    void operator()( const State &x_ , Deriv &dxdt_ , double t ) const
    {
         typename boost::range_iterator< const State >::type x = boost::begin( x_ );
         typename boost::range_iterator< Deriv >::type dxdt = boost::begin( dxdt_ );

         // fill dxdt
    }
};

如果你的 range 是随机访问 range, 还可以对迭代器应用方括号运算符来访问 range 中的元素:

class sys
{
    template< class State , class Deriv >
    void operator()( const State &x_ , Deriv &dxdt_ , double t ) const
    {
         typename boost::range_iterator< const State >::type x = boost::begin( x_ );
         typename boost::range_iterator< Deriv >::type dxdt = boost::begin( dxdt_ );

         dxdt[0] = f1( x[0] , x[1] );
         dxdt[1] = f2( x[0] , x[1] );
    }
};
