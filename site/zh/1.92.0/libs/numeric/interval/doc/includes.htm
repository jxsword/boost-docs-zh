头文件包含

访问本库最简单的方式是包含主头文件:

#include <boost/numeric/interval.hpp>

该头文件会包含几乎所有其他头文件 (列为扩展的除外). 不过, 你可能并不想访问库的全部功能. 因此本页充当整个库结构的备忘. <boost/numeric/interval.hpp> 是唯一直接位于 boost/numeric 之下的头文件; 其他所有头文件都位于子目录 boost/numeric/interval 中. 本文档中每次提到 interval/something.hpp, 指的都是 <boost/numeric/interval/something.hpp>.

另请注意: 下列所有头文件都是独立的, 必要时可以轻松预编译 (当然, 针对支持预编译头文件的编译器).

函数定义

下列头文件包含 interval 类的定义以及所有相关函数和运算符.

interval/interval.hpp

该头文件包含 interval 类的定义和声明. 然而, 该类是模板类, 其默认模板参数并不能通过该头文件获得. 特别是, 该头文件不提供 interval 类针对浮点类型 (interval<float>, interval<double> 和 interval<long double>) 的默认特化. 因此, 除非你使用自己的策略, 该头文件单独使用并没有太大用处.

interval/utility.hpp

该头文件包含所有不要求基础数类型具有任何算术性质的函数. 它只要求边界是有序的; 不过这应当不会让你意外, 因为这是整个库的要求. 在该头文件中可以找到访问及相关函数的定义: lower, upper, checked_lower, checked_upper, median, width, widen. 还有类集合函数: in, zero_in, empty, subset, proper_subset, overlap, singleton, equal, intersect, hull, bisect. 最后, abs, min 和 max 均有定义.

interval/arith.hpp

这里是二元运算符 +, -, *, / 和一元运算符 -.

interval/arith2.hpp

该头文件定义了 fmod, square, sqrt, pow 和 root.

interval/arith3.hpp

第三个算术头文件: 它提供函数 add, sub, mul 和 div. 其参数的类型是基础数类型.

interval/transc.hpp

这是最后一个包含数学函数的头文件; 它提供下列函数: cos, sin, tan, acos, asin, atan, cosh, sinh, tanh, acosh, asinh, atanh, exp 和 log.

策略

下列头文件定义了一些策略. 即使你使用默认策略, 也可能需要它们.

interval/rounded_arith.hpp

该头文件为算术函数定义了三个现成的舍入策略: rounded_arith_std, rounded_arith_opp, rounded_arith_exact.

interval/rounded_transc.hpp

该头文件为超越函数定义了三个现成的舍入策略: rounded_transc_std, rounded_transc_opp, rounded_transc_exact. 它与 rounded_arith.hpp 分开, 因为舍入策略的超越函数部分多半不如算术部分常用.

interval/hw_rounding.hpp

这里是针对基本浮点类型的完整舍入策略. 这些策略依赖处理器; 为了使用户代码可移植, 它们只定义硬件可用函数的公共子集, 即舍入策略的算术函数.

interval/checking.hpp

该头文件提供预定义的检查策略: checking_base, checking_no_empty, checking_no_nan, checking_catch_nan 和 checking_strict.

interval/policies.hpp

这里定义了操作策略的辅助工具. 它包含 policies (因此使用默认策略时需要它), change_rounding, change_checking, unprotect 等.

比较

interval/compare.hpp

该头文件包含下列所有头文件. 它们提供一些预定义的比较命名空间.

interval/compare/certain.hpp

这里是 compare::certain.

interval/compare/possible.hpp

这里是它的伙伴 compare::possible.

interval/compare/explicit.hpp

显式比较函数 cerlt, posge 等定义于该头文件中.

interval/compare/lexicographic.hpp

该头文件提供 compare::lexicographic.

interval/compare/set.hpp

该头文件提供 compare::set.

扩展

下列头文件不会被 interval.hpp 包含, 它们通常提供一些并不总是合乎需要的功能.

interval/io.hpp

这里定义了基本的流运算符 << 和 >>. 它们只应作为初步手段使用, 之后应替换为定制版本.

interval/limits.hpp

针对区间类型适配的 std::numeric_limits 特化.

interval/compare/tribool.hpp

该头文件提供一个特别适合三态布尔的比较命名空间 compare::tribool.

interval/ext/integer.hpp

该头文件提供区间与整数之间的混合运算. 其实现方式是把整数转换为基础数类型. 由于这种转换并不总是正确的 (一个大的 int 可能无法精确转换为 float), 该头文件不会被自动包含, 用户应确认这种行为与其意图相容 (若只是想把一些区间乘以 2, 包含该头文件多半是好事).

interval/ext/x86_fast_rounding_control.hpp

该头文件定义了一种新的舍入策略, 用于规避 x86 处理器的精度问题 (从而加速计算). 然而, 它只是一种部分解决方案; 当存在下溢或上溢的可能性时不应使用它.
