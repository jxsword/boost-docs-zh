区间算术库的 TODO 列表

评审过程中的意见

  • 若能有一个仅基于 LIA-1、不附带 IEEE 754 之类额外要求的 100% 可移植 Rounding 策略类就太好了.
  • 对于 pi 及其他常量, 应在 Math constants 库就绪后从那里获取.

其他事项

  • 支持 g++ 的 -mfpmath=sse 选项以生成 Pentium IV 优化代码. 这需要一个不同的舍入策略类.
  • 用 SSE2 指令为 interval<double> 提供一个优化的特化? 有难度.
  • 为 interval<MPFR> 及其他非内建数值类型编写 traits 特化.
  • 在内建浮点类型之上 (例如借助 MPFR) 提供稳健的超越函数实现?
  • 从 interval<double> 到 interval<float> 的安全转换? 需要偏特化.
  • 若能利用表达式模板机制, 自动对小的子表达式使用更高效的非保护舍入模式版本就太好了 (不过更大的表达式可以手工完成).
