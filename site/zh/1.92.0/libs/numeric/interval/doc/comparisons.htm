比较

如前所述, 比较运算符的定义带来一个小问题. 依据返回类型或期望的序不同, 定义它们的方式有很多种. 这正是运算符的含义不被一次性固定下来的原因.

运算符的定义方式本可以像舍入和检查那样由一种策略来决定. 然而, 比较更多是该类的一种外部属性而非内部属性. 它们被设计为可以独立于区间类型进行局部修改.

运算符 <, <=, >, >=, ==, != 每次都会被定义; 并且与算术运算符一样, 它们可以接受基础类型的参数. 然而, 由于技术上的限制, 该基础类型只能是第二个参数; 因此很遗憾, 这些运算符不是完全对称的. 返回类型并不总是 bool, 因为使用三态返回类型可以获得一些有趣的结果. 下面是这些运算符的公共签名:

template<class T, class Policies1, class Policies2>
return_type operator== (const interval<T, Policies1>&, const interval<T, Policies2>&);

template<class T, class Policies>
return_type operator== (const interval<T, Policies>&, const T&);

提供的比较

默认比较

若未作任何指定, 比较运算符的含义就是基础类型上相应运算符的扩展. 更准确地说, 若任一参数无效或区间为空, 则抛出异常. 若参数有效, 则应用下列规则来确定 [a,b] op [c,d] (只需考虑 c == d (若第二个参数的类型为 T):

  • 若 ∀ x ∈ [a,b] ∀ y ∈ [c,d] (x op y), 则 true
  • 若 ∀ x ∈ [a,b] ∀ y ∈ [c,d] !(x op y), 则 false
  • 否则抛出异常.

这种比较允许用区间类型替换基础类型而不改变程序的含义. 的确, 若不抛出异常, 结果与以前相同; 若抛出异常, 则说明原先的比较本就是不确定的, 应当重写.

其他比较

其他比较通过使用命名空间来选择. 这些命名空间位于 boost::numeric::interval_lib::compare 之下, 通过如下方式启用:

using namespace boost::numeric::interval_lib::compare::the_comparison_to_select;

这一行之后, 运算符的默认含义将被该命名空间中的含义取代. 请注意: 由于 C++ 的查找规则, 无法接连使用两个命名空间, 它们必须用于不同的块层次结构中. 否则编译器会报运算符歧义错误. 概括如下:

// example 1: BAD
using namespace compare1;
...
using namespace compare2;
...

// example 2: GOOD
{ using namespace compare1;
  ...                       }
{ using namespace compare2;
  ...                       }

// example 3: BAD
using namespace compare1;
...
{ using namespace compare2;
  ...                       }

下面列出所提供的各种比较. 它们分别位于 <boost/numeric/interval/compare/...> 之下各自的头文件中. 与默认比较一样, 若传入无效值, 这些运算符通常也会抛出异常来报错.

  • certain: 这种比较等价于默认方案, 只是异常情形被映射为 false. 因此, 仅当比较对所有元素对都成立时, 这些运算符才回答 true.
  • possible: 这一次, 异常情形被映射为 true. 只要比较对某一元素对成立, 这些运算符就回答 true.
  • lexicographic: 字典序 (先比较下边界, 若不足以确定结果, 再比较上边界). 这种序在区间算术中没有意义. 不过, 由于它是 (全序) 数对上的自然全序, 在某些情况下可能很方便.
  • set: 集合包含偏序. 此时, 空区间不再被视为无效 (但无效数仍然无效). <= 和 < 是子集与真子集关系; >= 和 > 是超集与真超集关系.
  • tribool: 这种比较依赖 Boost 三态布尔库, 它修改默认运算符, 使第三种情形返回一个显式的 indeterminate 值而不是抛出异常.

显式比较函数

在某些情况下, 你可能希望直接对边界进行比较, 以避免默认运算符出现的不确定情形. 库为此提供了一些函数. 它们要求参数有效, 并且只经过一次比较就返回结果. 其名称由 cer (表示 "certain": 若默认比较为真, 结果即为真) 或 pos (表示 "possible": 若默认比较为假, 结果即为假) 加上 lt, le, gt, ge, eq 或 ne 构成. 它们位于 <boost/numeric/interval/compare/explicit.hpp> 中. 这些函数各接受两个参数并返回布尔值; 参数应为有效值, 否则可能导致未定义行为. 例如, "certainly less than" 比较的定义如下:

namespace boost {
namespace numeric {
namespace interval_lib {

template<class T, class Policies1, class Policies2>
bool cerlt(const interval<T, Policies1>& x, const interval<T, Policies2>& y);

template<class T, class Policies>
bool cerlt(const interval<T, Policies>& x, const T& y);

template<class T, class Policies>
bool cerlt(const T& x, const interval<T, Policies>& y);

} // namespace interval_lib
} // namespace numeric
} // namespace boost
