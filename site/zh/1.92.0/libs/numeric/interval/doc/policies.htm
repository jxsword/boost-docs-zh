策略

该 interval 模板需要两个参数. 第一个是为边界选择的基础类型. 第二个定义新构造类的 rounding 和 checking 行为. 第二个参数不是必需的, 但可能需要一些定制. 为了便于操作, interval/policies.hpp 中提供了一些辅助模板.

namespace boost {
namespace numeric {
namespace interval_lib {

template<class Rounding, class Checking>
struct policies {
  typedef Rounding rounding;
  typedef Checking checking;
};

template<class OldInterval, class NewRounding>
struct change_rounding {
  typedef ... type;
};

template<class OldInterval, class NewChecking>
struct change_checking {
  typedef ... type;
};

template<class OldInterval>
struct unprotect {
  typedef ... type;
};

} // namespace interval_lib
} // namespace numeric
} // namespace boost

每当用户需要为某个 policies 类定义策略结构时, 都应使用 interval 模板. change_rounding 和 change_checking 可用于通过更改旧区间的一个策略来获得新区间的类型; 新类型通过类型定义 type 获得. 最后, unprotect 看起来像 change_rounding, 它直接把区间的舍入更改为其非保护版本 (更详细的解释见此处).
