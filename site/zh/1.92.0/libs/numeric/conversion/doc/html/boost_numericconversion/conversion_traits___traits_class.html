模板类 is_subranged<> 

namespace boost { namespace numeric {

    template <class T, class S>
    struct is_subranged : mpl::bool_<impl-def-value> {} ;

} } // namespace boost::numeric

指示目标类型 T 的取值范围是否为源类型 S 取值范围的子集. 也就是说: 是否存在某些超出目标类型取值范围的源值.

它是一个布尔型 MPL 整型常量 .

它并不指示某次特定转换是否实际上超出范围; 它指示的是某些转换可能超出范围, 因为并非所有源值都可以用目标类型表示.

模板类 conversion_traits<> 

namespace boost { namespace numeric {

    template <class T, class S>
    struct conversion_traits
    {
        mpl::integral_c<int_float_mixture_enum  , ...> int_float_mixture ;
        mpl::integral_c<sign_mixture_enum       , ...> sign_mixture;
        mpl::integral_c<udt_builtin_mixture_enum, ...> udt_builtin_mixture ;

        mpl::bool_<...> subranged ;
        mpl::bool_<...> trivial ;

        typedef T target_type   ;
        typedef S source_type   ;
        typedef ... argument_type ;
        typedef ... result_type   ;
        typedef ... supertype     ;
        typedef ... subtype       ;
    } ;

} } // namespace numeric, namespace boost

该特征类指示一次数值转换 方向的某些属性: 即从源类型 S 到目标类型 T. 它并不指示一次特定 转换的属性, 而是转换方向的属性. 详情参见 定义 一节.

该特征类提供下列枚举类型的 MPL 整型常量. 它们表达源类型与目标类型某些属性的组合 (因此称为混合类别 (mixture)):

int_float_mixture

与特征类 int_float_mixture 给出的相同

sign_mixture

与特征类 sign_mixture 给出的相同

udt_builtin_mixture

与特征类 udt_builtin_mixture 给出的相同

该特征类提供下列布尔类型的 MPL 整型常量, 它们间接指示源类型取值范围与目标类型取值范围之间的关系 (详情参见 定义).

subranged

与 is_subranged 给出的相同

trivial

指示源类型与目标类型 (不带 cv 限定符) 是否为同一类型.

其 ::value 为布尔类型.

该特征类提供下列类型. 它们是经过分类和限定、用于不同用途的源类型与目标类型.

target_type

模板参数 T (不带 cv 限定符)

source_type

模板参数 S (不带 cv 限定符)

argument_type

该类型为 source_type 或 source_type const&.

它表示 converter 成员函数的最优参数类型.

若 S 为内建类型, 则为 source_type, 否则为 source_type const&.

result_type

该类型为 target_type 或 target_type const&

它表示 converter 成员函数的返回类型.

若 T==S, 则为 target_type const&, 否则为 target_type.

supertype

若转换是 subranged 的, 则为 source_type, 否则为 target_type

subtype

若转换是 subranged 的, 则为 target_type, 否则为 source_type

示例 

#include <cassert>
#include <typeinfo>
#include <boost/numeric/conversion/conversion_traits.hpp>

int main()
{

    // A trivial conversion.
    typedef boost::numeric::conversion_traits<short,short> Short2Short_Traits ;
    assert ( Short2Short_Traits::trivial::value ) ;

    // A subranged conversion.
    typedef boost::numeric::conversion_traits<double,unsigned int> UInt2Double_Traits ;
    assert (  UInt2Double_Traits::int_float_mixture::value == boost::numeric::integral_to_float ) ;
    assert (  UInt2Double_Traits::sign_mixture::value == boost::numeric::unsigned_to_signed ) ;
    assert ( !UInt2Double_Traits::subranged::value ) ;
    assert ( typeid(UInt2Double_Traits::supertype) == typeid(double) ) ;
    assert ( typeid(UInt2Double_Traits::subtype) == typeid(unsigned int) ) ;

    // A doubly subranged conversion.
    assert ( (boost::numeric::conversion_traits<short, unsigned short>::subranged::value) );
    assert ( (boost::numeric::conversion_traits<unsigned short, short>::subranged::value) );

    return 0;
}
