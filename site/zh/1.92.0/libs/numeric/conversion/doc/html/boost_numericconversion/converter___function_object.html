概要 

namespace boost { namespace numeric {


    template<class T,
             class S,
             class Traits,          = conversion_traits<T,S>
             class OverflowHandler  = def_overflow_handler,
             class Float2IntRounder = Trunc< typename Traits::source_type >,
             class RawConverter     = raw_converter<Traits>,
             class UserRangeChecker = UseInternalRangeChecker
            >
    struct converter
    {
        typedef Traits traits ;

        typedef typename Traits::source_type   source_type   ;
        typedef typename Traits::argument_type argument_type ;
        typedef typename Traits::result_type   result_type   ;

        static result_type convert ( argument_type s ) ;

        result_type operator() ( argument_type s ) const ;

        // Internal member functions:

        static range_check_result out_of_range      ( argument_type s ) ;
        static void               validate_range    ( argument_type s ) ;
        static result_type        low_level_convert ( argument_type s ) ;
        static source_type        nearbyint         ( argument_type s ) ;

    } ;

} } // namespace numeric, boost

boost::numeric::converter<> 是一个 一元函数对象, 封装了执行数值转换的代码, 转换的方向和属性由 Traits 模板参数指定. 它还可以选择接受若干 策略, 用于定制其行为. Traits 参数不是策略, 而是定义该转换的参数.

Template parameters

T

该 数值类型 是转换的 目标.

S

该 数值类型 是转换的 源.

Traits

这必须是一个具有 boost::numeric::conversion_traits 接口的转换 traits 类.

OverflowHandler

无状态策略, 用于管理范围检查的结果.

它是一个 函数对象, 接收 out_of_range() 的结果, 并在 converter 暴露的 validate_range() 静态成员函数内部被调用.

Float2IntRounder

无状态策略, 指定 float 到整数转换所使用的舍入模式.

它提供 converter 暴露的 nearbyint() 静态成员函数.

RawConverter

无状态策略, 用于执行实际转换.

它提供 converter 暴露的 low_level_convert() 静态成员函数.

UserRangeChecker

特殊且可选 的 无状态策略, 可用于覆盖内部的范围检查逻辑.

如果给出, 则为 converter 暴露的 out_of_range() 和 validate_range() 静态成员函数提供替代代码.

Member functions

static result_type converter<>::convert ( argument_type s ) ; // throw

该静态成员函数把 source_type 类型的右值转换为 target_type 类型的右值.

如果转换需要, 它会在转换前执行范围检查, 并把检查结果传递给溢出处理器策略 (默认策略在检测到超出范围时抛出异常)

该函数的实现实际上由这些策略构建而成, 基本如下:

result_type converter<>::convert ( argument_type s )
{
    validate_range(s); // Implemented by the internal range checking logic
                       // (which also calls the OverflowHandler policy)
                       // or externally supplied by the UserRangeChecker policy.

    s = nearbyint(s); // Externally supplied by the Float2IntRounder policy.
                      // NOTE: This is actually called only for float to int conversions.

    return low_level_convert(s); // Externally supplied by the RawConverter policy.
}

converter<>::operator() const 仅调用 convert()

static range_check_result numeric_converter<>::out_of_range ( argument_type s ) ;

该 内部静态成员函数判断值 s 是否能在不溢出的情况下由目标类型表示.

它不判断转换是否 精确; 也就是说, 它不检测 不精确 转换, 只检测 超出范围 转换 (详见定义).

返回值的枚举类型为 boost::numeric::range_check_result

范围检查逻辑的实际代码针对源类型和目标类型的组合属性做了优化. 例如, 非子范围转换 (即 int->float) 不需要范围检查, 因此 out_of_range() 直接返回 cInRange. 更多细节见下面的表格.

如果用户提供了 UserRangeChecker 策略, 则由该策略实现此函数, 因此实现由用户定义, 但它应执行相同的概念检查并返回适当的结果.

static void numeric_converter<>::validate_range ( argument_type s ) ; // no throw

该 内部静态成员函数调用 out_of_range(s), 并把结果传递给 OverflowHandler 策略类.

对于不需要范围检查的 Target/Source 组合, 这是一个空的内联函数.

如果用户提供了 UserRangeChecker 策略, 则由该策略实现此函数, 因此实现由用户定义, 但它应执行与默认策略相同的操作. 特别是, 它应把检查结果传递给溢出处理器.

static result_type numeric_converter<>::low_level_convert ( argument_type s ) ;

该 内部静态成员函数执行实际转换.

该函数由 RawConverter 策略类在外部提供.

static source_type converter<>::nearbyint ( argument_type s ) ;

该 内部静态成员函数 仅用于 float 到 int 的转换, 它根据某种舍入方向返回一个 整数 值, 其类型为 浮点类型.

该函数由 Float2IntRounder 策略类在外部提供, 该类封装了具体的舍入模式.

内部成员函数

这些静态成员函数构建 convert() 所使用的实际转换代码. 如果调用 convert(), 用户无需调用它们, 因为 convert() 会在内部调用它们, 但如有特定需要也可以单独调用它们.

范围检查逻辑

下表总结了针对 Source 与 Target 属性的每种组合所执行的内部范围检查逻辑.

LowestT/HighestT 分别表示 Target 类型的最高值和最低值.

S(n) 是 static_cast<S>(n) 的简写 (S 表示 Source 类型).

NONE 表示此种情况不进行范围检查.


int_to_int    |--> sig_to_sig     |--> subranged     |--> ( s >= S(LowestT) ) && ( s <= S(HighestT) )
              |                   |--> not subranged |--> NONE
              |
              |--> unsig_to_unsig |--> subranged     |--> ( s >= S(LowestT) ) && ( s <= S(HighestT) )
              |                   |--> not subranged |--> NONE
              |
              |--> sig_to_unsig   |--> pos subranged     |--> ( s >= S(0) ) && ( s <= S(HighestT) )
              |                   |--> not pos subranged |--> ( s >= S(0) )
              |
              |--> unsig_to_sig   |--> subranged     |--> ( s <= S(HighestT) )
              |                   |--> not subranged |--> NONE


int_to_float   |--> NONE


float_to_int   |--> round_to_zero         |--> ( s >  S(LowestT)-S(1)   ) && ( s <  S(HighestT)+S(1)   )
               |--> round_to_even_nearest |--> ( s >= S(LowestT)-S(0.5) ) && ( s <  S(HighestT)+S(0.5) )
               |--> round_to_infinity     |--> ( s >  S(LowestT)-S(1)   ) && ( s <= S(HighestT)        )
               |--> round_to_neg_infinity |--> ( s >= S(LowestT)        ) && ( s <  S(HighestT)+S(1)   )


float_to_float |--> subranged     |--> ( s >= S(LowestT) ) && ( s <= S(HighestT) )
               |--> not subranged |--> NONE

示例 

#include <cassert>
#include <boost/numeric/conversion/converter.hpp>

int main() {

    typedef boost::numeric::converter<int,double> Double2Int ;

    int x = Double2Int::convert(2.0);
    assert ( x == 2 );

    int y = Double2Int()(3.14); // As a function object.
    assert ( y == 3 ) ; // The default rounding is trunc.

    try
    {
        double m = boost::numeric::bounds<double>::highest();
        int z = Double2Int::convert(m); // By default throws positive_overflow()
    }
    catch ( boost::numeric::positive_overflow const& )
    {
    }

    return 0;
}
