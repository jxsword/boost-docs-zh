概述

Boost Numeric Conversion 库是一组用于描述和执行不同 数值类型 的值之间转换的工具.

该库包含 std::numeric_limits<> 一个子集的特殊替代品: bounds<> traits 类, 它提供了一种一致的方式来获取数值类型 范围 的 边界 值.

它还包含一组 traits 类, 用于描述从源数值类型到目标数值类型的转换的编译期属性. 算术类型 和 用户定义数值类型 均可使用.

库还提供了一个基于策略的 converter 对象, 它使用 conversion_traits 来选择优化的实现. 该实现使用适合源/目标组合的最优范围检查代码.

  • converter 的超出范围行为可以通过 OverflowHandler 策略定制.
  • 对于浮点数到整数的转换, 可以通过 Float2IntRounder 策略选择舍入模式.
  • 自定义的底层转换例程 (例如用于 UDT) 可以通过 RawConverter 策略传入.
  • 优化后的自动范围检查逻辑可以通过 UserRangeChecker 策略覆盖.
