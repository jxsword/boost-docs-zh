如果我们想要最大性能, 我们希望用 virtual_ptr 来代替普通指针或引用. 不过, 我们也可能希望使用智能指针进行生命周期管理; 例如 std::unique_ptr, std::shared_ptr 或 boost::intrusive_ptr.

这是否意味着我们必须在 virtual_ptr 的性能与 std::unique_ptr 的便利之间做出选择? 或者同时携带两种类型的智能指针? 幸运的是, 并非如此. virtual_ptr 可以与智能指针互操作.

若 virtual_ptr 识别出其模板实参是一个智能指针类, 它就会使用该智能指针而不是普通指针来跟踪底层对象. virtual_ptr<const Node> 和 virtual_ptr<std::unique_ptr<const Node>> 都指向一个 const Node; 前者使用普通 const Node*, 而后者使用 std::unique_ptr<const Node>. 两者携带相同的 v-table 指针.

智能 virtual_ptr 会自动转换为其非智能的 "普通" 对应物, 例如从 virtual_ptr<std::unique_ptr<const Node>> 转换为 virtual_ptr<const Node>. 方法和覆写器通常使用普通 virtual_ptr, 尽管并非总是如此[1].

反向转换 (从普通到智能) 并不存在, 因为它有可能意外地创建智能指针. 同样, 一个智能 virtual_ptr 可以从智能指针构造, 但不能直接从普通引用或指针构造.

该库为标准智能指针提供了别名:

  • unique_virtual_ptr<Class> 是 virtual_ptr<std::unique_ptr<Class>>

  • shared_virtual_ptr<Class> 是 virtual_ptr<std::shared_ptr<Class>>

对 boost::intrusive_ptr 的支持也可用:

  • boost_intrusive_virtual_ptr<Class> 是 virtual_ptr<boost::intrusive_ptr<Class>>

标准库提供 std::make_unique 和 std::make_shared 来创建智能指针. 它们使用方便, 在异常存在的情况下依然稳健, 而且 (就 std::shared_ptr 而言) 更高效. OpenMethod 提供了这些对应物:

  • make_unique_virtual

  • make_shared_virtual

  • make_boost_intrusive_virtual

由于这些函数创建对象, 它们确切地知道对象的准确类型. 因此, 它们无需执行哈希表查找来找到相应的 v-table, 只需从静态变量中读取即可. 由此, 它们不要求 Class 是多态的.

这些别名和 make_* 函数在 namespace boost::openmethod::aliases 中同样有别名, 便于导入可能一起使用的构造.

智能 virtual_ptr 在各自的头文件中实现, 位于 interop 子目录中. 例如, 对 std::unique_ptr 的支持提供在 <boost/openmethod/interop/std_unique_ptr.hpp> 中, 对 boost::intrusive_ptr 的支持提供在 <boost/openmethod/interop/boost_intrusive_ptr.hpp> 中. <boost/openmethod.hpp> 不包含智能指针头文件, 因此必须显式包含它们.

下面是 AST 示例的一个变体, 它使用动态分配和 unique 指针:

#include <boost/openmethod.hpp>
#include <boost/openmethod/interop/std_unique_ptr.hpp>

using namespace boost::openmethod::aliases;

struct Node {
    virtual ~Node() {}
    virtual int value() const = 0;
};

struct Variable : Node {
    Variable(int value) : v(value) {}
    int value() const override { return v; }
    int v;
};

struct Plus : Node {
    Plus(unique_virtual_ptr<const Node> left, unique_virtual_ptr<const Node> right)
        : left(std::move(left)), right(std::move(right)) {}
    int value() const override { return left->value() + right->value(); }
    unique_virtual_ptr<const Node> left, right;
};

struct Times : Node {
    Times(unique_virtual_ptr<const Node> left, unique_virtual_ptr<const Node> right)
        : left(std::move(left)), right(std::move(right)) {}
    int value() const override { return left->value() * right->value(); }
    unique_virtual_ptr<const Node> left, right;
};

#include <iostream>

BOOST_OPENMETHOD(postfix, (virtual_ptr<const Node> node, std::ostream& os), void);

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Variable> var, std::ostream& os), void) {
    os << var->v;
}

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Plus> plus, std::ostream& os), void) {
    postfix(plus->left, os);
    os << ' ';
    postfix(plus->right, os);
    os << " +";
}

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Times> times, std::ostream& os), void) {
    postfix(times->left, os);
    os << ' ';
    postfix(times->right, os);
    os << " *";
}

BOOST_OPENMETHOD_CLASSES(Node, Variable, Plus, Times);

#include <boost/openmethod/initialize.hpp>

int main() {
    boost::openmethod::initialize();

    auto a = std::make_unique<Variable>(2);
    auto b = std::make_unique<Variable>(3);
    auto c = std::make_unique<Variable>(4);
    auto d = make_unique_virtual<Plus>(std::move(a), std::move(b));
    auto e = make_unique_virtual<Times>(std::move(d), std::move(c));

    postfix(e, std::cout);
    std::cout << " = " << e->value() << "\n"; // 2 3 + 4 * = 20
}
1. 例如, 考虑矩阵的 transpose 方法. 如果矩阵是对称的, 覆写器应当返回其实参. 这可以通过向方法传递一个 virtual_ptr<std::shared_ptr<const Matrix>> 来实现.
