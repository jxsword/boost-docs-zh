virtual_ptr 的替代方案

虚实参也可以以普通引用、普通指针或智能指针的形式传递, 即不使用 virtual_ptr. 在方法声明中, 类型被类模板 virtual_ 包裹的参数会参与覆写器的选择 (与 virtual_ptr 参数一起).

例如, Node 示例可以重写如下:

struct Node {
    virtual int value() const = 0;
};

struct Variable : Node {
    Variable(int value) : v(value) {}
    int value() const override { return v; }
    int v;
};

struct Plus : Node {
    Plus(const Node& left, const Node& right) : left(left), right(right) {}
    int value() const override { return left.value() + right.value(); }
    const Node& left; const Node& right;
};

struct Times : Node {
    Times(const Node& left, const Node& right) : left(left), right(right) {}
    int value() const override { return left.value() * right.value(); }
    const Node& left; const Node& right;
};

#include <boost/openmethod.hpp>
#include <boost/openmethod/initialize.hpp>

using boost::openmethod::virtual_;

BOOST_OPENMETHOD(postfix, (virtual_<const Node&> node, std::ostream& os), void);

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (const Variable& var, std::ostream& os), void) {
    os << var.v;
}

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (const Plus& plus, std::ostream& os), void) {
    postfix(plus.left, os);
    os << ' ';
    postfix(plus.right, os);
    os << " +";
}

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (const Times& times, std::ostream& os), void) {
    postfix(times.left, os);
    os << ' ';
    postfix(times.right, os);
    os << " *";
}

BOOST_OPENMETHOD_CLASSES(Node, Variable, Plus, Times);

auto main() -> int {
    boost::openmethod::initialize();
    Variable a{2}, b{3}, c{4};
    Plus d{a, b};
    Times e{d, c};
    postfix(e, std::cout);
    std::cout << " = " << e.value() << "\n"; // 2 3 + 4 * = 20
}

注意, virtual_ 并未在覆写器中使用. 它只是方法中使用的一个修饰符. 它也会从方法的签名中移除. BOOST_OPENMETHOD 生成:

inline auto postfix(const Node& node, std::ostream& os) -> void {
    // examine the type of node
    // select an overrider
    // call it
}

boost_openmethod_vptr

就其本身而言, virtual_ 并不带来任何好处. 以引用传递虚实参所编译出的代码, 与创建一个 virtual_ptr、用它进行一次调用然后丢弃几乎相同. 唯一的区别是虚实参作为一个指针而不是两个指针传递.

不过, 我们现在可以定制 vptr 的获取方式. 当方法看到一个 virtual_ 参数时, 它会寻找一个 boost_openmethod_vptr 函数, 该函数可以以虚实参 (以 const 引用传入) 和一个指向注册表的指针进行调用, 并返回一个 vptr_type. 若找到这样的函数, 就调用它来获取 vptr.

在下面的示例中, 我们把 vptr 嵌入到对象中, 就像原生虚函数的 vptr 一样. 已注册类的 v-table 可以通过一个变量模板 static_vptr 找到, 它嵌套在类 default_registry 中. 在 virtual_ 参数中使用的类无需在 C++ 意义上是多态的. 这次我们把 value 实现为一个开放方法. Node 不再拥有任何虚函数.

struct Node {
    boost::openmethod::vptr_type vptr;
    using registry = boost::openmethod::default_registry; // short alias

    friend auto boost_openmethod_vptr(const Node& node, registry*) {
        return node.vptr;
    }

    Node() {
        vptr = registry::static_vptr<Node>;
    }
};

struct Variable : Node {
    Variable(int value) : v(value) {
        vptr = registry::static_vptr<Variable>;
    }

    int v;
};

struct Plus : Node {
    Plus(const Node& left, const Node& right) : left(left), right(right) {
        vptr = registry::static_vptr<Plus>;
    }

    const Node& left;
    const Node& right;
};

struct Times : Node {
    Times(const Node& left, const Node& right) : left(left), right(right) {
        vptr = registry::static_vptr<Times>;
    }

    const Node& left;
    const Node& right;
};

#include <boost/openmethod/initialize.hpp>

using boost::openmethod::virtual_;

BOOST_OPENMETHOD(value, (virtual_<const Node&> node), int);

BOOST_OPENMETHOD_OVERRIDE(value, (const Variable& var), int) {
    return var.v;
}

BOOST_OPENMETHOD_OVERRIDE(value, (const Plus& plus), int) {
    return value(plus.left) + value(plus.right);
}

BOOST_OPENMETHOD_OVERRIDE(value, (const Times& times), int) {
    return value(times.left) * value(times.right);
}

BOOST_OPENMETHOD_CLASSES(Node, Variable, Plus, Times);

auto main() -> int {
    boost::openmethod::initialize();
    Variable a{2}, b{3}, c{4};
    Plus d{a, b};
    Times e{d, c};
    std::cout << value(e) << "\n"; // 20
}

int call_value(const Node& node) {
    return value(node);
}

inplace_vptr

inplace_vptr_base 和 inplace_vptr_derived 自动化嵌入式 vptr 的创建和管理. 它们都是 CRTP mixin 类.

inplace_vptr_base 用于层次结构的根部. 它定义一个 vptr 成员变量, 以及一个返回其值的 boost_openmethod_vptr 友元函数, 就像前一个示例中那样. inplace_vptr_derived 用于派生类. 它们的构造函数把 vptr 成员设置为指向该类的 v-table.

警告

inplace_vptr_derived 必须在层次结构的每一层使用, 并反映实际的继承关系. 否则, vptr 将不会被正确设置, 可能会调用错误的覆写器.

struct Node : boost::openmethod::inplace_vptr_base<Node> {
};

struct Variable : Node, boost::openmethod::inplace_vptr_derived<Variable, Node> {
    Variable(int value) : v(value) {}

    int v;
};

struct Plus : Node, boost::openmethod::inplace_vptr_derived<Plus, Node> {
    Plus(const Node& left, const Node& right) : left(left), right(right) {}

    const Node& left;
    const Node& right;
};

struct Times : Node, boost::openmethod::inplace_vptr_derived<Times, Node> {
    Times(const Node& left, const Node& right) : left(left), right(right) {}

    const Node& left;
    const Node& right;
};

程序的其余部分与之前相同, 只是无需调用 BOOST_OPENMETHOD_CLASSES: inplace_vptr_base 和 inplace_vptr_derived 会负责注册类及其继承关系.

inplace_vptr_derived 支持多重继承: 可以在所定义的类之后列出多个基类.

inplace_vptr_derived 的析构函数把基类的 vptr 恢复为基类的 v-table, 就像 C++ 对其原生 vptr 所做的那样.

inplace_vptr_base 和 inplace_vptr_derived 在 namespace boost::openmethod::aliases 中有别名.
