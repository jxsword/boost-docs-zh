注释

本节使用覆写器容器, 相关内容在头文件与实现文件一节中描述.

BOOST_OPENMETHOD 在当前命名空间中定义一个方法. BOOST_OPENMETHOD_OVERRIDE 则可跨命名空间工作. 覆写器并不要求与其所覆写的方法位于同一个命名空间中. 该宏会把覆写器添加到一个能以与覆写器相同的实参进行调用的方法上, 该方法可能通过实参相关查找定位.

覆写器容器会被添加到当前命名空间中. 因此, 同一个方法可以在多个不同命名空间的容器中拥有覆写器. 在显式调用覆写器时必须考虑到这一点. 我们把 Employee 和 Salesman 放到它们各自的命名空间中:

// roles.hpp

#ifndef ROLES_HPP
#define ROLES_HPP

#include <boost/openmethod.hpp>

namespace employees {

struct Employee {
    virtual ~Employee() = default;
};

BOOST_OPENMETHOD(pay, (boost::openmethod::virtual_ptr<const Employee>), double);

BOOST_OPENMETHOD_INLINE_OVERRIDE(
    pay, (boost::openmethod::virtual_ptr<const Employee>), double) {
    return 5000.0;
}

}

namespace sales {

struct Salesman : employees::Employee {
    double sales = 0.0;
};

} // namespace sales
#endif // ROLES_HPP

当我们尝试编译 salesman.cpp 时:

BOOST_OPENMETHOD_OVERRIDE(
    pay, (boost::openmethod::virtual_ptr<const Salesman> emp), double) {
    return BOOST_OPENMETHOD_OVERRIDER(
               pay, (boost::openmethod::virtual_ptr<const Employee> emp),
               double)::fn(emp) +
        emp->sales * 0.05; // base + commission
}

我们会得到类似这样的错误:

error: implicit instantiation of undefined template
'sales::pay_boost_openmethod_overriders<
    double (boost::openmethod::virtual_ptr<const employees::Employee>)>

这是因为针对 pay 的覆写器容器位于命名空间 sales 中, 它为 Salesman 特化, 但没有为 Employee 特化. Employee 的覆写器位于另一个容器的特化中, 在命名空间 employees 里.

解决办法是用 employees 命名空间限定覆写器容器:

namespace sales {

BOOST_OPENMETHOD_OVERRIDE(
    pay, (boost::openmethod::virtual_ptr<const Salesman> emp), double) {
    return employees::BOOST_OPENMETHOD_OVERRIDER(
               pay, (boost::openmethod::virtual_ptr<const employees::Employee> emp),
               double)::fn(emp) +
        emp->sales * 0.05; // base + commission
}

BOOST_OPENMETHOD_CLASSES(employees::Employee, Salesman);

} // namespace sales
