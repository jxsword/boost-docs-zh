BOOST_OPENMETHOD_DECLARE_OVERRIDER

概要

定义于 <boost/openmethod/macros.hpp>.

#define BOOST_OPENMETHOD_DECLARE_OVERRIDER(NAME, (PARAMETERS...), RETURN_TYPE)

说明

为方法声明一个覆写器, 但不开始其定义. 该宏可用于头文件中.

ID 是该覆写器所加入的方法的标识符.

ID 必须是一个标识符. 不允许使用限定名.

PARAMETERS 是一个以逗号分隔的类型列表, 其后可跟参数名, 与函数声明中的写法相同.

该宏会尝试定位一个能以与该覆写器相同的实参列表进行调用的方法, 也可能通过实参相关查找 (argument dependent lookup) 定位.

方法的参数列表中的每个 virtual_ptr<T> 必须在覆写器参数列表的相同位置有一个对应的 virtual_ptr<U> 参数, 使得 U 与 T 相同, 或以 T 作为可访问的无歧义基类.

方法的参数列表中的每个 virtual_<T> 必须在覆写器参数列表的相同位置有一个对应的 U 参数, 使得 U 与 T 相同, 或以 T 作为可访问的无歧义基类.

实现说明

该宏会在当前作用域中创建额外的实体.

  • 一个类模板声明, 用作当前作用域中该方法所有覆写器的容器:

template<typename...> struct BOOST_OPENMETHOD_OVERRIDERS(NAME);

  • 针对该覆写器的容器特化:

    struct BOOST_OPENMETHOD_OVERRIDERS(ID)<RETURN_TYPE(PARAMETERS...)> {
    static auto fn(PARAMETERS...) -> RETURN_TYPE;
    static auto has_next() -> bool;
    template<typename... Args>
    static auto next(typename... Args) -> RETURN_TYPE;
};
