头文件

通用头文件

以下头文件足以满足该库的大多数基本用途.

  • <boost/openmethod.hpp> 用于使用便利宏定义开放方法和覆写器.

  • <boost/openmethod/initialize.hpp> 用于初始化该库. 通常只在包含 main 的翻译单元中包含它.

以下头文件使得在虚参数中使用标准智能指针成为可能:

  • <boost/openmethod/interop/std_shared_ptr.hpp> 用于在虚参数中使用 std::shared_ptr.

  • <boost/openmethod/interop/std_unique_ptr.hpp> 用于在虚参数中使用 std::unique_ptr.

高层头文件

<boost/openmethod/core.hpp>

定义该库的主要构造: 方法、覆写器和虚指针, 以及实现它们的机制. 除 BOOST_OPENMETHOD_DEFAULT_REGISTRY (若其尚未定义) 外, 不定义任何公共宏.

<boost/openmethod/macros.hpp>

定义该库的公共宏, 例如 BOOST_OPENMETHOD, BOOST_OPENMETHOD_CLASSES 等.

直接包含此头文件意义不大, 因为其效果与包含 boost/openmethod.hpp 相同, 而后者更简短.

<boost/openmethod.hpp>

包含 core.hpp 和 macros.hpp.

<boost/initialize.hpp>

提供 initialize 和 finalize 函数. 此头文件通常包含在含有 main 的翻译单元中. 动态加载或卸载共享库的翻译单元也可能需要调用这些函数.

<boost/openmethod/interop/std_shared_ptr.hpp>

提供一个 virtual_traits 特化, 使得可以在虚参数中使用 std::shared_ptr 来代替原始指针或引用.

<boost/openmethod/interop/std_unique_ptr.hpp>

提供一个 virtual_traits 特化, 使得可以在虚参数中使用 std::unique_ptr 来代替原始指针或引用.

<boost/openmethod/interop/boost_intrusive_ptr.hpp>

提供一个 virtual_traits 特化, 使得可以在虚参数中使用 boost::intrusive_ptr 来代替原始指针或引用.

核心之前的头文件

以下头文件可以在 core.hpp 之前包含, 用于定义自定义注册表和策略, 并通过定义 BOOST_OPENMETHOD_DEFAULT_REGISTRY 来覆盖默认注册表.

<boost/openmethod/preamble.hpp>

定义 registry 和内置策略类别. 还定义了 registry 定义所需的全部类型和函数.

<boost/openmethod/policies/std_rtti.hpp>

提供使用标准 RTTI 的 rtti 策略实现.

<boost/openmethod/policies/fast_perfect_hash.hpp>

提供使用快速完美哈希函数的 hash 策略实现.

<boost/openmethod/policies/vptr_vector.hpp>

提供一种 vptr 策略实现, 它把 v-table 指针存储在一个以类型 id (可能经过哈希) 为索引的 std::vector 中.

<boost/openmethod/policies/default_error_handler.hpp>

提供一种 error_handler 策略实现, 它在遇到错误时、且在该库中止程序之前调用一个 std::function<void(openmethod_error)>.

<boost/openmethod/policies/stderr_output.hpp>

提供一种 output 策略实现, 它把诊断信息写入 C 标准错误流 (不使用 iostream).

<boost/openmethod/default_registry.hpp>

定义默认注册表, 它包含上面列出的所有内置策略. 并包含本节到目前为止列出的所有头文件.

<boost/openmethod/policies/static_rtti.hpp>

提供不依赖标准 RTTI 的 rtti 策略的最小实现.

<boost/openmethod/policies/throw_error_handler.hpp>

提供以异常形式抛出错误的 error_handler 策略实现.

<boost/openmethod/policies/vptr_map.hpp>

提供一种 vptr 策略实现, 它把 v-table 指针存储在一个以类型 id 为索引的 map (默认为 std::map) 中.
