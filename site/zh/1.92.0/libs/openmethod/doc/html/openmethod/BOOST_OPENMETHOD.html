BOOST_OPENMETHOD

概要

定义于 <boost/openmethod/macros.hpp>.

BOOST_OPENMETHOD(ID, (PARAMETERS...), RETURN_TYPE [, REGISTRY]);

说明

声明一个名为 ID 的方法, 带有给定的 PARAMETERS 和 RETURN_TYPE, 并将其添加到 REGISTRY.

PARAMETERS 是一个以逗号分隔的类型列表, 其后可跟参数名, 与函数声明中的写法相同. 类型形如 virtual_ptr<T> 或 virtual_<T> 的参数称为虚参数. 传入虚参数的实参的动态类型决定调用哪个覆写器, 所遵循的规则与重载函数决议相同:

  1. 构造所有可应用的覆写器的集合. 若某个覆写器能够以传给方法的实参进行调用, 则它是可应用的.

  2. 若该集合为空, 则调用错误处理器 (若注册表中存在), 然后以 abort 终止程序.

  3. 移除被集合中其他覆写器支配的覆写器. 若覆写器 A 的某个虚形参比 B 的更特化, 且 B 的任何虚参数都不比 A 的更特化, 则称 A 支配 B.

  4. 若所得集合恰好包含一个覆写器, 则调用它.

若不存在唯一的最特化覆写器, 程序将通过 abort 终止. 若注册表包含 error_handler 策略, 则会先以一个描述错误的对象调用其 error 函数, 然后再调用 abort. error 可以通过抛出异常来阻止程序终止.

对于每个虚实参 arg, 分发机制会调用 virtual_traits::peek(arg), 并从 result 推导 v-table 指针, 采用以下方法中最先适用者:

  1. 若 result 是 virtual_ptr, 则从中获取指向 v-table 的指针.

  2. 若 boost_openmethod_vptr 能以 result 和一个 Registry* 被调用, 且其返回 vptr_type, 则调用它.

  3. 调用 Registry::vptr::dynamic_vptr(result).

该宏在当前作用域中创建一个普通内联函数, 参数类型中的 virtual_ 修饰符会被移除, 而 virtual_ptr 则保留.

ID 必须是一个标识符. 不允许使用限定名.
REGISTRY 的默认值是 BOOST_OPENMETHOD_DEFAULT_REGISTRY 在 <boost/openmethod/core.hpp> 被包含之时的值. 在此之后更改该符号的值不会产生任何影响.

实现说明

该宏还会创建若干额外的构造:

  • 一个 struct 前向声明, 用作该方法的标识符:

struct BOOST_OPENMETHOD_ID(ID);

  • 一个类模板声明, 用作当前作用域中该方法所有覆写器的容器:

template<typename...> struct BOOST_OPENMETHOD_OVERRIDERS(NAME);

  • 一个用于将覆写器与方法进行匹配的引导函数:

auto BOOST_OPENMETHOD_ID(ID)_guide(...)
    -> ::boost::openmethod::method<
        BOOST_OPENMETHOD_ID(ID)(PARAMETERS...), RETURN_TYPE [, REGISTRY]>;

  • 一个把该方法添加到注册表的注册器.
