boost::openmethod::method

实现一个方法

概要

声明于 <boost/openmethod/core.hpp>

template<
    typename Id,
    typename Fn,
    class Registry = boost::openmethod::default_registry>
class method;

说明

方法通过以一个标识符、一个函数类型以及可选的一个注册表来特化 method 类模板而创建.

Id 是一个类型, 通常是一个以方法用途命名的未完成 (incomplete) 类声明. 它用于允许具有相同签名的不同方法共存.

Fn 是一个函数类型, 即形如 ReturnType(Parameters...) 的类型.

Registry 是类模板 registry 的一个实例化. 方法只能使用已在同一注册表中注册的类作为虚参数和实参. 注册表还包含一组策略, 这些策略影响分发机制的多个方面, 例如如何为对象获取 v‐table 指针、如何报告错误、是否执行健全性检查等.

Registry 的默认值是 default_registry, 但可以通过定义预处理器符号 BOOST_OPENMETHOD_DEFAULT_REGISTRY 来覆盖它, 条件是在包含 <boost/openmethod/core.hpp> 之前定义. 之后再设置该符号不会有任何效果.

method 的特化只有一个实例: 静态成员 fn, 它拥有一个转发到适当覆写器的 operator(). 其选择方式与重载函数决议相同:

1. 构造所有可应用的覆写器的集合. 若某个覆写器能够以传给方法的实参进行调用, 则它是可应用的.

2. 若该集合为空, 则调用错误处理器 (若注册表中存在), 然后以 abort 终止程序.

3. 移除被集合中其他覆写器支配的覆写器. 若覆写器 A 的至少一个虚形参比 B 的更特化, 且 B 的任何虚参数都不比 A 的更特化, 则称 A 支配 B.

4. 若所得集合恰好包含一个覆写器, 则调用它.

若不存在唯一的最特化覆写器, 程序将通过 abort 终止. 若注册表包含 error_handler 策略, 则会先以一个描述错误的对象调用其 error 函数, 然后再调用 abort. error 可以通过抛出异常来阻止程序终止.

对于每个虚实参 arg, 分发机制会调用 virtual_traits::peek(arg), 并从 result 推导 v‐table 指针, 采用以下方法中最先适用者:

1. 若 result 是 virtual_ptr, 则从中获取指向 v‐table 的指针.

2. 若 boost_openmethod_vptr 能以 result 和一个 Registry* 被调用, 且其返回 vptr_type, 则调用它.

3. 调用 Registry::rtti::dynamic_vptr(result).

N2216 对歧义调用的处理

若 Registry 以 N2216 选项初始化, 则歧义调用不算错误. 作为替代, 会采取以下额外步骤来选择覆写器:

1. 若返回类型是已注册的多态类型, 则移除所有返回类型不如其他覆写器具体的覆写器.

2. 若所得集合只包含一个覆写器, 则调用它.

3. 否则, 调用剩余覆写器中的一个. 选择哪个覆写器并未规定, 但对于具有相同实参类型的调用, 所选的覆写器是相同的.
