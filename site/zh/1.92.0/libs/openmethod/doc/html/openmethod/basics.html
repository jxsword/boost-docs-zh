一个开放方法 (open-method) 是一种独立函数, 它拥有一个或多个虚 参数. 调用它时, 它会通过检查虚参数的动态类型, 从一个集合中选出一个覆写器并转发到该覆写器.

如果这听起来像虚函数, 那是因为带一个虚参数的开放方法确实等价于虚函数, 只是有一个重大区别: 它存在于类之外.

虚参数的形式为 virtual_ptr<Class>. 它是一个指针式类, 指向 Class 的实例. virtual_ptr 定义在该库的主命名空间 boost::openmethod 中.

为了创建实现 postfix 操作的开放方法, 我们使用 BOOST_OPENMETHOD 宏:

BOOST_OPENMETHOD(
    postfix, (virtual_ptr<const Node> node, std::ostream& os), void);

postfix 是该方法的名称. 它接受一个虚参数 node 和一个非虚参数 os, 返回 void. 该宏生成以下函数:

inline auto postfix(virtual_ptr<const Node> node, std::ostream& os) -> void {
    // examine the type of *node
    // select an overrider
    // call it
}

在调用该方法之前, 我们需要定义覆写器. 为此我们使用 BOOST_OPENMETHOD_OVERRIDE 宏:

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Variable> var, std::ostream& os), void) {
    os << var->v;
}

覆写器必须在与方法相同的位置上具有虚参数. 方法虚参数中的类必须是覆写器中类的可访问且无歧义的基类. 注意, 这排除了重复继承. 除这一限制外, 多重继承和虚继承都是受支持的.

非虚参数的类型必须与方法中的类型完全相同.

我们来看另一个覆写器:

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Plus> plus, std::ostream& os), void) {
    postfix(plus->left, os);
    os << ' ';
    postfix(plus->right, os);
    os << " +";
}

这个覆写器递归调用 postfix 来打印左右子表达式. 注意, 我们调用该方法的方式与调用普通函数完全一样.

postfix 期望一个 virtual_ptr<const Node>, 而我们传给它的是一个普通 引用, 指向一个 Node 对象. 之所以可行, 是因为 virtual_ptr 提供了从对象的普通引用或指针、或从其他 virtual_ptr 转换而来的转换构造函数.

我们还需要做两件事.

OpenMethod 是一个库, 而不是编译器. 它需要被告知所有可能用作虚参数以及在方法调用中使用的类, 以及它们的继承关系. 我们通过 BOOST_OPENMETHOD_CLASSES 宏提供这些信息:

BOOST_OPENMETHOD_CLASSES(Node, Variable, Plus, Times);

类可以被多次注册, 顺序任意, 并且可以增量进行. 每个类的每个直接基类都必须与它一起出现在至少一次 BOOST_OPENMETHOD_CLASSES 调用中. 这使库能够推导出完整的继承格 (inheritance lattice).

本例中使用的构造要求这些类在标准 C++ 意义上是多态的, 即它们必须至少有一个虚函数. 该库也可以用于非多态类, 但有一些限制.

最后, 我们需要在首次调用开放方法之前调用 boost::openmethod::initialize(). 这会构建方法调用期间所使用的分发表. 这通常只在 main 的最开始处执行一次, 并且需要包含 <boost/openmethod/initialize.hpp>.

#include <boost/openmethod/initialize.hpp>

int main() {
    boost::openmethod::initialize();
    // ...
}

把所有内容合在一起:

struct Node {
    virtual ~Node() {}
    virtual int value() const = 0;
};

struct Variable : Node {
    Variable(int value) : v(value) {}
    int value() const override { return v; }
    int v;
};

struct Plus : Node {
    Plus(const Node& left, const Node& right) : left(left), right(right) {}
    int value() const override { return left.value() + right.value(); }
    const Node& left; const Node& right;
};

struct Times : Node {
    Times(const Node& left, const Node& right) : left(left), right(right) {}
    int value() const override { return left.value() * right.value(); }
    const Node& left; const Node& right;
};

// ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
// library code
// =============================================================================
// application code
// vvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvvv

#include <boost/openmethod.hpp>
#include <boost/openmethod/initialize.hpp>
#include <iostream>

using boost::openmethod::virtual_ptr;

BOOST_OPENMETHOD(postfix, (virtual_ptr<const Node> node, std::ostream& os), void);

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Variable> var, std::ostream& os), void) {
    os << var->v;
}

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Plus> plus, std::ostream& os), void) {
    postfix(plus->left, os);
    os << ' ';
    postfix(plus->right, os);
    os << " +";
}

BOOST_OPENMETHOD_OVERRIDE(
    postfix, (virtual_ptr<const Times> times, std::ostream& os), void) {
    postfix(times->left, os);
    os << ' ';
    postfix(times->right, os);
    os << " *";
}

BOOST_OPENMETHOD_CLASSES(Node, Variable, Plus, Times);

int main() {
    boost::openmethod::initialize();
    Variable a{2}, b{3}, c{4};
    Plus d{a, b}; Times e{d, c};
    postfix(e, std::cout);
    std::cout << " = " << e.value() << "\n"; // 2 3 + 4 * = 20
}
