boost::openmethod::policies

策略所在的命名空间.

说明

具有 snake_case 名称的类是 "蓝图", 即仅用于说明 (exposition‐only) 的类, 描述给定类别的策略所需满足的要求. 实现这些蓝图的类必须提供一个符合蓝图要求的 fn<Registry> 元函数.

类型

名称

说明

ErrorHandlerFn

error_handler 元函数的蓝图 (仅用于说明).

InitializeClass

用于初始化策略的类信息 (仅用于说明).

InitializeContext

用于初始化策略的上下文 (仅用于说明).

OutputFn

output 元函数的蓝图 (仅用于说明).

RttiFn

rtti 元函数的蓝图 (仅用于说明).

TypeHashFn

type_hash 元函数的蓝图 (仅用于说明).

VptrFn

vptr 元函数的蓝图 (仅用于说明).

default_error_handler

以该错误调用一个 std::function.

deferred_static_rtti

延迟类型 id 收集的策略.

error_handler

错误处理策略.

fast_perfect_hash

使用快速完美哈希函数对类型 id 进行哈希.

indirect_vptr

为指向 v‐table 的指针增加一层间接的策略.

output

写出诊断与跟踪信息的策略.

rtti

操作类型信息的策略.

runtime_checks

初始化后运行期检查的策略.

static_rtti

rtti 策略的最小实现.

std_rtti

使用标准 RTTI 实现 rtti 策略.

stderr_output

Writes (输出到 C 标准错误流).

throw_error_handler

以异常形式抛出错误.

type_hash

对类型 id 进行哈希的策略.

vptr

获取 v‐table 指针的策略.

vptr_map

把 v‐table 指针存储在以 `type_id` 为键的 map 中.

vptr_vector

把 v‐table 指针存储在一个 vector 中.

参见

registry 包含注册表与策略的完整解释.
