实用层面

interval_sets(maps) 可用作元素(元素值对)的集合(映射)

分段信息可用. 例如参见 月份与周的时间网格

在基本方面

  • 一个 interval 部分地实现了一个元素集合.
  • 一个 interval_set 实现了一个元素集合.
  • 一个 interval_map 实现了一个元素值对映射.

在分段方面

  • 一个 interval_set 实现了一个区间集合.
  • 一个 interval_map 实现了一个区间值对映射.
