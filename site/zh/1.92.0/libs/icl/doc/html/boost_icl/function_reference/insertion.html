插入

插入 (由 insert 实现) 与 相加 (由 add 和 operator += 实现) 对于 icl 的所有集合类型, 效果相同.

对于映射类型, insert 提供 stl 的插入语义, 而 add 和 operator += 则实现一种广义相加, 在键值相撞或键区间重叠时执行聚合. 映射上的 insert 在待插入对象的键与映射中已有键重叠或相撞的点上, 不改变映射的内容.

Setting values

使用 operator[] 像下面这样覆盖值

my_map[key] = new_value;

is not provided for interval_maps because an operator[] is not implemented for them. As a substitute a function T& T::set(const P&) can be used to achieve the same effect: 

my_map.set(make_pair(overwrite_this, new_value));

带提示的插入

函数 J T::insert(J prior, const P& addend) 允许在 常量时间 内完成插入, 前提是 addend 能在不发生相撞的情况下直接插入到迭代器 prior 之后. 如果做不到这一点, 复杂度特性如上文非提示插入所述. 带提示的插入可用于以下类型组合:

// overload table for insertion with hint        T\P| e i b p  
J T::insert(J pos, const P&)                     ---+--------
J insert(T&, J pos, const P&)                     s | s
                                                  m |     m
                                                  S |   S
                                                  M |       M
