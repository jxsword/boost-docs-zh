可加性, 可减性与重叠时的聚合

虽然 相加 与 相减 在 Sets 上被实现为 集合并集 和 集合差集, 但对于 Maps, 我们希望在 (键元素的) 相撞或 (键区间的) 重叠情形下对关联值实现 聚合, 这在上文已被称为 重叠时的聚合. 这种 Addability 与 Subtractability 使得只需通过添加和减去值对, 就能在一个 interval_map's 关联值上计算大量有用的聚合结果. 重叠时的聚合 的各种示例见 示例一节. 此外, 这种 Addability 与 Subtractability 的概念把键值对的经典 Insertability 与 Erasability 作为特例包含在内, 因此它在提供更宽泛的新语义的同时, 不丢失 经典 语义.

聚合对函数 add 和 subtract 的实现方式是: 传递一个 Combiner 函数对象来合并类型为 CodomainT 的关联值. 标准 Combiner 被设为默认模板参数 template<class>class Combine = inplace_plus, 而后者又由 operator += 对所有可加 (Addable) 类型进行了泛型实现.

对于 Combine 函数对象, Icl 提供了一个 inverse 函数对象.

元函数 inverse 对除默认函数对象 Functor 之外的所有函数对象都是成对实现的, 使得例如 inverse<inplace_minus<T> >::type 产生 inplace_plus<T>. 但并非在每种情况下, 例如 max/min, inverse 函数对象都反转其前身的效应. 不过对默认情形确实如此:

_add<Combine<CodomainT> >((k,x))

_subtract<inverse<Combine<CodomainT> >::type>((k,x))

实例

_add<inplace_plus<int> >((k,x))

_subtract<inplace_minus<int> >((k,x))

在重叠时相减 x. 这反转了此前 add 对 x 在 k 上产生的效应

如前所述, 聚合 Addability 和 Subtractability 于 Maps 上, 已把键值对的 经典 Insertability 和 Erasability 作为特例包含在内:

等价的 经典 函数

_add<inplace_identity<CodomainT> >(const value_type&)

insert(const value_type&)

_subtract<inplace_erasure<CodomainT> >(const value_type&)

erase(const value_type&)

聚合成员函数模板 _add 和 _subtract 不在 interval_maps 的公有接口中, 因为 Combine 函数对象被设计为 interval_map's 模板实例的不变量, 以避免客户端因意外调用不同的聚合函数对象而破坏聚合. 但你可以实例化一个 interval_map, 以这种方式获得 insert/erase 语义:

interval_map<int,int,partial_absorber,
             std::less,
             inplace_identity //Combine parameter specified
            > m;
interval<int>::type itv = interval<int>::rightopen(2,7);
m.add(make_pair(itv,42));      //same as insert
m.subtract(make_pair(itv,42)); //same as erase

当然, 这只是一个说明性的示例. 成员函数 insert 和 erase 在 interval_map's 接口中可用, 因此可以直接调用它们.
