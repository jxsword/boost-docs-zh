iterator T::find(const domain_type& x)

s m

在容器中搜索元素 x, 如果找到 x 则返回指向它的迭代器. 否则 find 返回迭代器 end().

const_iterator find
(T&, const domain_type& x)

S M

对于区间容器 c, c.find(x) 或 icl::find(c,x) 搜索一个键元素 x 并返回指向包含元素 x 的区间的迭代器.

const_iterator T::find
(const interval_type& x)const

const_iterator find
(T&, const interval_type& x)

S M

对于区间容器 c, c.find(y) 或 icl::find(c,y) 搜索一个区间 y 并返回指向 c 中第一个与 y 重叠的区间的迭代器.
