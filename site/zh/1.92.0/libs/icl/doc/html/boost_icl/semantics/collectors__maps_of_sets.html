收集器: 集合的映射

Icl 的 Collectors 的行为类似于 Sets. 如果我们考虑到每一个集合的映射都可以变换为一个等价的序对集合, 这一点就很容易理解. 例如在下面的伪代码中, 映射 m 

icl::map<int,set<int> >  m = {(1->{1,2}), (2->{1})};

等价于集合 s 

icl::set<pair<int,int> > s = {(1,1),(1,2),   //representing 1->{1,2}
                              (2,1)       }; //representing 2->{1}

而且, 对 map m 和 set s 执行 add、subtract 等运算的结果也 几乎 完美地保持了容器的等价性:

m += (1,3);
m == {(1->{1,2,3}), (2->{1})}; //aggregated on collision of key value 1
s += (1,3);
s == {(1,1),(1,2),(1,3),   //representing 1->{1,2,3}
      (2,1)             }; //representing 2->{1}

m 与 s 的等价性, 只有在 m 因减去一个值对而出现空集合时才会被破坏:

m -= (2,1);
m == {(1->{1,2,3}), (2->{})}; //aggregated on collision of key value 2
s -= (2,1);
s == {(1,1),(1,2),(1,3)   //representing 1->{1,2,3}
                       }; //2->{} is not represented in s

这个问题可以用两种方式处理.

  1. 当其关联值变成中性值或 identity_element 时, 将该值对从收集器中删除.
  2. 使用另一种相等 — 在待验证的定律中称为相异相等. 相异相等只考虑其值不等于 identity_element 的值对.

方案 (1) 促成了映射特征的引入, 特别是特征 partial_absorber, 它是所有 icl 映射模板中的默认设置.

方案 (2) 应用于检验 partial_enricher 特性下 icl::Maps 的语义, 该特性不会删除携带单位元的值对. 相异相等由一个名为 is_distinct_equal 的非成员函数实现. 在本章的伪代码与定律记法中, 相异相等一律记作 =d= 运算符.

构成 Set 语义的这组定律的有效性现在应当相当明显了. 因此下文给出对所有 Collector 类型 C 验证的定律, 即 icl::map<D,S,T>、interval_map<D,S,T> 与 split_interval_map<D,S,T>, 其中 CodomainT 类型 S 是 Set 的模型, 且 Trait 类型 T 是 partial_absorber 或 partial_enricher.

集合并、集合交与集合差的定律 

Associativity<C,+,== >: C a,b,c; a+(b+c) == (a+b)+c
Neutrality<C,+,== >   : C a;       a+C() == a
Commutativity<C,+,== >: C a,b;       a+b == b+a

Associativity<C,&,== >: C a,b,c; a&(b&c) ==(a&b)&c
Commutativity<C,&,== >: C a,b;       a&b == b&a

RightNeutrality<C,-,== >: C a;   a-C() ==  a
Inversion<C,-,=v= >     : C a;   a - a =v= C()

对于实例化为集合的映射或收集器的所有 icl 映射, 全部基本定律都得到了验证. 正如预期, 只有当映射不是 partial_absorber 时, 求逆定律才对相异相等成立.

                             +    &    -
Associativity                ==   ==
Neutrality                   ==        ==
Commutativity                ==   ==
Inversion partial_absorber             ==
          partial_enricher             =d=

分配律 

     Distributivity<C,+,&,=v= > : C a,b,c; a + (b & c) =v= (a + b) & (a + c)
     Distributivity<C,&,+,=v= > : C a,b,c; a & (b + c) =v= (a & b) + (a & c)
RightDistributivity<C,+,-,=v= > : C a,b,c; (a + b) - c =v= (a - c) + (b - c)
RightDistributivity<C,&,-,=v= > : C a,b,c; (a & b) - c =v= (a - c) & (b - c)

分配律的结果与集合的验证几乎相同, 唯一区别是: 对于 partial_enricher map, 定律 (a & b) - c == (a - c) & (b - c) 对字典序相等成立.

                                                   +,&    &,+
     Distributivity  joining                       ==     ==
                     splitting   partial_absorber  =e=    =e=
                                 partial_enricher  =e=    ==

                                                   +,-    &,-
RightDistributivity  joining                       ==     ==
                     splitting                     =e=    ==

DeMorgan 定律与对称差 

DeMorgan<C,+,&,=v= > : C a,b,c; a - (b + c) =v= (a - b) & (a - c)
DeMorgan<C,&,+,=v= > : C a,b,c; a - (b & c) =v= (a - b) + (a - c)


                         +,&     &,+
DeMorgan  joining        ==      ==
          splitting      ==      =e=


SymmetricDifference<C,== > : C a,b,c; (a + b) - (a * b) == (a - b) + (b - a)

回顾上面的有效性表可以看出, icl Sets 与 icl Maps of Sets 在 吸收单位元 情形下的有效定律集合完全相同. 正如预期, 只有对于把空集合表示为关联值的集合的映射 — 即所谓 充实单位元 — 才存在细微的语义差异.
