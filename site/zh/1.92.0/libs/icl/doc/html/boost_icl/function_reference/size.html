对于 icl 容器, std 容器中已知的单个 size 函数分化为三到五个不同的成员函数. 上表展示了 size 函数所针对的类型及其 复杂度. 线性复杂度 O(n) 指的是容器的 iterative_size:

n = y.iterative_size()

下表简要定义了各个不同的大小函数.

说明

size_type interval_count(const T&)

S M

区间容器的区间数量.

size_type iterative_size(const T&)

S M s m

icl 容器中可被迭代遍历的对象数量.

difference_type length(const T&)

i S M

一个区间的长度, 或区间容器的各区间长度之和, 即 domain_type 有一个 difference_type.

i S M s m

区间或容器的元素数量. 对于连续数据类型, 基数可以是 无限 的.
