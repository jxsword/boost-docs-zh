字典序排序

所有常见的相等与比较运算符都对 icl 的所有对象有定义. 对于所有 icl 容器, 相等与比较运算符实现的是字典序相等与字典序比较, 它取决于模板参数 Compare 的相等性. 这包括区间上的 less 排序, 区间可被看作其下边界与上边界之间的元素序列. 区间中这种广义的字典序比较也可以这样表述:

x < y

:=

x 在 y 之前开始, 或者当起点相同时 x 在 y 之前结束.

其余运算符可以按通常方式推导

x > y

:=

y < x

x <= y

:=

!(y < x)

x >= y

:=

!(x < y)

x == y

:=

!(x < y) && !(y < x) 所诱导的等价

x != y

:=

!(x == y)

相等与比较运算符对所有 icl 对象都有定义, 但不同类型之间没有重载.

分段不同的容器是不同的, 即使其元素相同:

split_interval_set<time> w1, w2; //Pseudocode
w1 = {[Mon       ..       Sun)}; //split_interval_set containing a week
w2 = {[Mon .. Fri)[Sat .. Sun)}; //Same week split in work and week end parts.
w1 == w2;                        //false: Different segmentation
is_element_equal(w1,w2);         //true:  Same elements contained

复杂度 是 线性 的, 以被比较的较短容器的 iterative_size 为度.

顺序元素排序

顺序元素排序 抽象掉了区间容器的元素聚集成区间的方式, 即其 分段.

因此这些相等与比较运算可以应用于区间容器类型之内. 可接受的类型组合总结在下面的重载表中.

// overload tables for
bool is_element_equal  (const T&, const P&)
bool is_element_less   (const T&, const P&)
bool is_element_greater(const T&, const P&)

element containers:     interval containers:
T\P| s m                T\P| S1 S2 S3 M1 M3
---+----                ---+---------------
s  | 1                  S1 | 1  1  1
m  |   1                S2 | 1  1  1
                        S3 | 1  1  1
                        M1 |          1  1
                        M3 |          1  1

对于元素容器, 字典序相等与顺序元素相等是相同的.

顺序元素比较函数的 复杂度 是 线性 的, 以较大容器的 iterative_size 为度.

相异相等

相异相等 是一个可用于 icl::maps 和 interval_maps 的相等谓词. 如果两个映射在顺序元素意义上相等, 但存在关联值为单位元的值对除外, 则它产生 true.

复杂度 对被比较的较大容器而言, 在其 iterative_size 上是线性的.
