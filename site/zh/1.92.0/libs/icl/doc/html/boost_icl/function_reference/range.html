上表展示了区间与区间容器上函数 hull, lower, upper, first 和 last 的可用性, 它们都具有 常量时间复杂度. 函数的描述及一些简单性质见下文.

类型

说明

interval_type hull(const T&)

S M

hull(x) 返回包含区间容器 x 中所有区间的最小区间.

T hull(const T&, const T&)

S M

hull(i,j) 返回包含区间 i abd 'j' 的最小区间.

domain_type lower(const T&)

i S M

lower(x) 返回区间或区间容器 x 的下边界.

domain_type upper(const T&)

i S M

upper(x) 返回区间或区间容器 x 的上边界.

domain_type first(const T&)

i S M

first(x) 返回区间或区间容器 x 的第一个元素. first(const T&) 仅对离散的 domain_type 有定义.

domain_type last(const T&)

i S M

last(x) 返回区间或区间容器 x 的最后一个元素. last(const T&) 仅对离散的 domain_type 有定义.

 

// for interval_containers x:
lower(hull(x)) == lower(x)
upper(hull(x)) == upper(x)
first(hull(x)) == first(x)
last(hull(x))  == last(x)
