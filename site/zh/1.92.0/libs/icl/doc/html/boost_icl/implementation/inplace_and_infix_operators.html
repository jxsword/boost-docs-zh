原地运算符与中缀运算符

对于 相加, 相减, 交集 — icl 容器的这些主要运算 — 以及 对称差, 提供了原地 operator 形式 += |=, -=, &= 和 ^=.

对于每个 原地 运算符

T& operator o= (T& object, const P& operand)

icl 都提供相应的 中缀 运算符.

T operator o (T object, const P& operand){ return object o= operand; }
T operator o (const P& operand, T object){ return object o= operand; }

对于中缀 operator o 的这一实现, 编译器有望使用返回值优化 (RVO), 不创建临时对象, 并对第一个参数 object 执行一次复制.

注意

与 原地 operator o= 相比, 每次使用 中缀 operator o 都需要一次 额外复制 第一个参数 object (传入容器者).

仅在以下情况才使用中缀运算符:

  • 效率不关键, 例如被复制的容器很小.
  • 在你的场景中, 简洁而短的记法比效率更重要.
  • 你反正需要运算符 o= 的结果作为一个副本.
中缀 operators o 的时间复杂度

icl 的所有中缀运算符的时间复杂度都受 object 参数额外复制的影响. 因此所有中缀 operators o 都是 线性 的, 至少在 n = object.iterative_size() 上如此. 考虑到这一点, 所有中缀运算符的复杂度都可以由其所依赖的相应原地 operators o= 来确定.
