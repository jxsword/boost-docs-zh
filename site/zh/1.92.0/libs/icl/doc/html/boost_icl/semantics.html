概念归纳

“美是对复杂性的终极防御” -- David Gelernter

在 icl 中, 我们秉持这样一种观念: 一个 概念 或 抽象数据类型 的语义可以用 定律 来表达. 我们针对区间容器表述定律, 对于定律中包含的变量的一个给定实例化, 这些定律可以求值. 下面的伪代码给出了这类定律的一种简写记法.

Commutativity<T,+>:
T a, b; a + b == b + a;

当然, 这也可以编写成一个真正的 C++ 类模板 — 为了验证 icl 我们确实这样做了. 为简单起见, 这里我们使用伪代码.

描述 icl 各类模板语义的定律是用基于定律的测试自动机 LaBatea 验证的, 该工具为定律的变量生成实例, 然后检验定律的有效性. 由于 icl 处理的是集合、映射与关系这类众所周知的数学对象, 我们使用的定律大多是 回收再利用 的. 这些定律中还有一些被归入诸如 序关系 或 代数结构 之类的概念.

序关系与等价关系

字典序与相等

在 icl 的所有集合与映射容器上, 都有一个 operator <, 它实现一个 严格弱序. operator < 的语义与 stl 的 SortedAssociativeContainer (特别是 stl::set 和 stl::map) 的语义相同:

Irreflexivity<T,< > : T a;     !(a<a)
Asymmetry<T,< >     : T a,b;   a<b implies !(b<a)
Transitivity<T,< >  : T a,b,c; a<b && b<c implies a<c

Operator < 依赖于 icl::container 的模板参数 Compare, 该参数实现一个 严格弱序, 作用于容器的 domain_type. 对于给定的 Compare 次序, operator < 在 icl::containers 上实现字典序比较, 它使用 Compare 次序在容器中确立一个唯一的值序列.

由 operator < 诱导出的等价关系是字典序相等, 它实现为 operator ==.

//equivalence induced by strict weak ordering <
!(a<b) && !(b<a) implies a == b;

这同样遵循 stl 的语义. 字典序相等强于元素的相等. 两个包含相同元素的容器, 如果其元素的排序方式不同, 则可能在字典序上不相等. 字典序比较属于 分段性 方面. 在对无序集合与映射有效的所有不同序列中, 由元素的 Compare 次序选出其中一个序列. 基于这一选择, 就可以进行唯一的迭代.

子集序与元素相等

在基本方面, 重要的只是元素的隶属关系, 而不是它们的序列. 因此有函数 contained_in 与 element_equal 来实现子集关系和元素层面的相等. 然而, contained_in 与 is_element_equal 函数并非真正工作在元素层面上. 它们还基于容器模板的 Compare 参数工作. 实际而言, 如果我们使用区间拆分型区间容器, 就需要区分字典序相等 operator == 与元素的相等 is_element_equal:

split_interval_set<time> w1, w2; //Pseudocode
w1 = {[Mon       ..       Sun)}; //split_interval_set containing a week
w2 = {[Mon .. Fri)[Sat .. Sun)}; //Same week split in work and week end parts.
w1 == w2;                        //false: Different segmentation
is_element_equal(w1,w2);         //true:  Same elements contained

对于键元素上恒定的 Compare 次序, 为所有 icl::containers 定义的成员函数 contained_in 在 icl::containers 上实现一个 偏序.

with <= for contained_in,
    =e= for is_element_equal:
Reflexivity<T,<= >     : T a;     a <= a
Antisymmetry<T,<=,=e=> : T a,b;   a <= b && b <= a implies a =e= b
Transitivity<T,<= >    : T a,b,c; a <= b && b <= c implies a <= c

其诱导出的等价关系是元素的相等, 该相等通过函数 is_element_equal 实现.

//equivalence induced by the partial ordering contained_in on icl::container a,b
a.contained_in(b) && b.contained_in(a) implies is_element_equal(a, b);
