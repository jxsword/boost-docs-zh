集合与映射

集合概念

在基本方面, 所有 interval_sets 都是一个概念 Set 的模型. Interval Template Library 的 Set 概念指的是集合的数学概念.

Sets 上的相等性并未实现为 operator ==, 因为 operator == 被用于段上更强的字典序相等性, 它把元素的分段考虑在内.

作为概念 Set 的模型, std::set 以及所有 interval_sets 都实现了这些运算, 并在 Sets 上遵循相关定律. 例如参见 此处的集合代数.

使区间完备

一个 interval 也被视为一个元素集合. 但相对于上文给出的 Set 概念, interval 只部分地实现了该概念. 原因在于无法在 intervals 上定义相加与相减. 两个区间 [1,2] 与 [4,5] 无法相加成一个 单一 的新 interval. 换言之, intervals 就并与差而言是不完备的. Interval_sets 可以被定义为区间在并运算与差运算上的 完备化.

当我们声称无法在区间上定义相加或相减时, 我们并未考虑诸如区间算术之类的情形, 在那些情形中这些运算虽可定义, 但语义不同.

映射概念

在基本方面, icl::map 与所有 interval_maps 都是一个概念 Map 的模型. 由于 map 是一个 set of pairs, 我们尝试使 Map 概念与上述 Set 概念保持一致.

可以看到, 在抽象内核上, icl 的 Set 与 Map 概念的签名除类型名外完全相同. 虽然签名相同, 但有效定律的集合却不同, 这将在 icl 集合的语义 与 映射 各节中更详细地描述. 这些语义差异主要基于针对元素与区间的关键成员函数 add 和 subtract 的实现, 而这些函数又服务于 operator += 和 operator -= 的实现.
