集合

对于所有集合类型 S, 即作为概念 Set 的模型的 std::set 、interval_set、separate_interval_set 和 split_interval_set, 大多数众所周知的数学 集合定律 都已通过 LaBatea 成功检验. 接下来的几张表按运算分类给出已检验定律的概览. 只要可能, 定律都以较强的字典序相等 (operator ==) 来表述, 这蕴含着定律对较弱的元素相等 is_element_equal 也成立. 在本章中, 凡简写记法有利之处, 我们都把元素相等记作 =e= 而不是 is_element_equal.

集合并的定律

对于运算 集合并 (以 operator +, +=, |, |= 形式提供) 以及中性元素 identity_element<S>::value() (即空集合 S()), 以下定律成立:

Associativity<S,+,== >: S a,b,c; a+(b+c) == (a+b)+c
Neutrality<S,+,== >   : S a;       a+S() == a
Commutativity<S,+,== >: S a,b;       a+b == b+a

集合交的定律

对于运算 集合交 (以 operator &, &= 形式提供), 以下定律已得到验证:

Associativity<S,&,== >: S a,b,c; a&(b&c) == (a&b)&c
Commutativity<S,&,== >: S a,b;       a&b == b&a

集合差的定律

对于集合差, 仅有这些定律. 它既不可结合也不可交换. 其单位元性质是非对称的.

RightNeutrality<S,-,== > : S a;   a-S() == a
Inversion<S,-,== >:        S a;   a - a == S()

下表汇总了把 +、& 与 - 用作单一运算的定律. 对所有已验证的定律, 等式左右两端都字典序相等, 如表格单元格中的 == 所示.

                 +    &   -
Associativity    ==   ==
Neutrality       ==       ==
Commutativity    ==   ==
Inversion                 ==

分配律

像分配律这样使用多个运算的定律, 有时可以针对不同的运算符序列进行实例化, 如下文所示. 在分配律的两个实例化中, 运算符 + 与 & 互换了位置. 因此我们可以用 +,& 与 &,+ 这样的简短运算符签名来描述这类实例化, 下文将采用这种写法. 并非所有分配律实例都对字典序相等成立, 因此下文使用一个 可变 相等 =v= 来表示它们.

     Distributivity<S,+,&,=v= > : S a,b,c; a + (b & c) =v= (a + b) & (a + c)
     Distributivity<S,&,+,=v= > : S a,b,c; a & (b + c) =v= (a & b) + (a & c)
RightDistributivity<S,+,-,=v= > : S a,b,c; (a + b) - c =v= (a - c) + (b - c)
RightDistributivity<S,&,-,=v= > : S a,b,c; (a & b) - c =v= (a - c) & (b - c)

下一张表展示了定律实例、区间合并风格 与所用相等关系之间的关系.

                                  +,&    &,+
     Distributivity  joining      ==     ==
                     separating   ==     ==
                     splitting    =e=    =e=

                                  +,-    &,-
RightDistributivity  joining      ==     ==
                     separating   ==     ==
                     splitting    =e=    ==

该表给出了四个分配律的 12 个实例化的概览, 并展示了各实例化所成立的相等关系. 例如, RightDistributivity 以运算符签名 +,- 针对 split_interval_sets 实例化时, 仅对元素相等成立 (记作 =e=):

RightDistributivity<S,+,-,=e= > : S a,b,c; (a + b) - c =e= (a - c) + (b - c)

RightDistributivity 其余五个实例化对字典序相等 (记作 ==) 也成立.

区间合并风格 按如下方式对应于容器

style       set
joining     interval_set
separating  separate_interval_set
splitting   split_interval_set

最后还有两条定律把全部三种主要集合运算组合在一起: De Morgan 定律与对称差.

DeMorgan 定律

De Morgan 定律在使用一元补运算 ~ 的形式下更为人熟知. ~(a+b) == ~a * ~b. 下面的版本是针对二元集合差 - 的改写, 集合差也称为 相对补.

DeMorgan<S,+,&,=v= > : S a,b,c; a - (b + c) =v= (a - b) & (a - c)
DeMorgan<S,&,+,=v= > : S a,b,c; a - (b & c) =v= (a - b) + (a - c)


                         +,&     &,+
DeMorgan  joining        ==      ==
          separating     ==      =e=
          splitting      ==      =e=

同样, 并非所有定律实例都对字典序相等成立. 只有当区间集为非连接时, 第二个实例化才对元素相等成立.

对称差 

SymmetricDifference<S,== > : S a,b,c; (a + b) - (a & b) == (a - b) + (b - a)

最后, 对称差对所有 icl 集合类型都成立, 且使用字典序相等.
