命名

icl 关注的是集合与映射, 以及利用区间实现集合与映射的一种有用方式. 在 icl 的文档中, 不同的集合与映射类型按多种方式分组. 为了区分这些分组, 我们使用一套命名约定.

概念的名称以大写字母开头. 因此 Set 和 Map 表示集合与映射的 概念, 如 icl 中所定义. 不过当我们谈论 Sets 和 Maps 时, 多数时候谈论的并非概念本身, 而是在 icl 中实现这些概念的那组类型. icl 容器 可划分出的主要分组总结在下表中:

Set

Map

元素容器

std::set

icl::map

区间容器

interval_set, separate_interval_set, split_interval_set

interval_map, split_interval_map

  • 容器 std:set, interval_set, separate_interval_set, split_interval_set 是概念 Set 的模型.
  • 容器 icl::map, interval_map, split_interval_map 是概念 Map 的模型.
  • 使用元素或元素值对加以 实现 的容器称为 元素容器.
  • 使用区间或区间值对 (也称为段) 加以 实现 的容器称为 区间容器.
  • 当我们谈论 Sets 或 Maps 时, 我们不涉及它们的具体实现方式.
  • 当我们谈论 元素容器 或 区间容器 时, 我们指的正是它们的实现方式.
  • std::set 是 icl 的 Set 概念的一个模型.
  • std::map 不是 icl 的 Map 概念的一个模型.
  • icl 的 元素映射总是以限定形式 icl::map 表示, 以避免与 std::map 混淆.
