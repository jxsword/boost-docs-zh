构造, 复制, 析构

说明

T::T()

类型 T 的对象被默认构造.

T::T(const T& src)

类型 T 的对象从对象 src 复制构造.

T& T::operator=(const T& src)

把 src 的内容赋给 *this 对象. 返回被赋值对象的引用.

void T::swap(T& src)

在常量时间内交换内容容器 *this 和 src.

此外, 对于 icl 容器类型, 我们还有构造函数与赋值运算符的重载.
