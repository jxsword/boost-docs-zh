量词: 数的映射

量词上的减法

对于 Sets 和 Collectors, operator - 的语义就是 集合差 的语义, 这意味着你只能减去之前放入容器的内容. 而对于 Quantifiers — 即以某种方式 计数 或 量化 其键值的映射 — operator - 的语义可能不同.

问题在于, 这里的减法应当如何定义?

//Pseudocode:
icl::map<int,some_number> q = {(1->1)};
q -= (2->1);

如果类型 some_number 是 unsigned, 那么 集合差 式的减法是有意义的

icl::map<int,some_number> q = {(1->1)};
q -= (2->1);   // key 2 is not in the map so  
q == {(1->1)}; // q is unchanged by 'aggregate on collision'

如果 some_number 是一个 signed 数值类型, 结果也可以是这种情形

icl::map<int,some_number> q = {(1->1)};
q -= (2->1);             // subtracting works like  
q == {(1->1), (2-> -1)}; // adding the inverse element

正如示例中的注释所言, 如果键尚未存储在映射中, 那么对键值对 (k,v) 的减法显然可以定义为: 为该键加上其 逆元素 (k,-v).

部分与完全量词及无限向量

我们可以想到的另一个概念是: 在一个 Quantifier 中, 每个 key_value 起初都被量化了 0 次, 其中 0 表示数值类型 CodomainT 的中性元素. 这样的 Quantifier 对其 DomainT 类型的所有值都是完全定义的, 可以被设想为一个 InfiniteVector.

要创建一个在其定义域上完全定义的无限向量, 我们可以把映射的 Trait 参数设置为值 total_absorber. total_absorber 特性与 Quantifier 特别契合 — 只要其 CodomainT 拥有逆元素 (所有有符号数值类型都是如此). 正如本节稍后可以看到的, 这种完全的 Quantifier 具有 向量空间 元素所提供的基本性质.

量词上的交集

Collectors 与 Quantifiers 的另一个区别是 operator & 的语义 — 对 Collectors 而言它具有集合交集的含义.

按照 重叠聚合原则, 必须传入运算 &, 以便在区间重叠或键冲突时合并关联值. 对 Quantifiers 这一点无法做到, 因为数值类型没有实现交集.

对于 CodomainT 类型, 若其不是 Sets 的模型, 则 operator & 被定义为 定义域交集上的聚合. 此时聚合运算不使用 codomain_intersect 函数对象, 而是使用 codomain_combine:

//Pseudocode example for partial Quantifiers p, q:
interval_map<int,int> p, q;
p     = {[1     3)->1   };
q     = {   ([2    4)->1};
p & q =={    [2 3)->2   };

因此关联值的加法或聚合与 operator + 的做法相同, 但没有公共键的值对不会加入结果.

对于一个 Quantifier — 它是某个 InfiniteVector 的模型, 因而对 DomainT 类型的每个键值都有定义 — operator & 的这个定义退化为与 operaotor + 所实现的相同的语义:

//Pseudocode example for total Quantifiers p, q:
interval_map<int,int> p, q;
p   = {[min   1)[1      3)[3         max]};
          ->0      ->1         ->0
q   = {[min        2)[2      4)[4    max]};
            ->0         ->1       ->0
p&q =={[min   1)[1  2)[2 3)[3 4)[4   max]};
          ->0    ->1   ->2  ->1    ->0

无符号数量词的定律

icl 的数的映射对无符号数与有符号数的语义是不同的. 因此对量词有效的定律集合将取决于把无符号还是有符号数值类型实例化为 CodomainT 参数.

我们再次给出所研究的定律集合, 这次针对的是 Quantifier 类型 Q, 即 icl::map<D,N,T>、interval_map<D,N,T> 与 split_interval_map<D,N,T>, 其中 CodomainT 类型 N 是一个 Number, 而 Trait 类型 T 是 icl 映射特征之一.

Associativity<Q,+,== >: Q a,b,c; a+(b+c) == (a+b)+c
Neutrality<Q,+,== >   : Q a;       a+Q() == a
Commutativity<Q,+,== >: Q a,b;       a+b == b+a

Associativity<Q,&,== >: Q a,b,c; a&(b&c) ==(a&b)&c
Commutativity<Q,&,== >: Q a,b;       a&b == b&a

RightNeutrality<Q,-,== >: Q a;   a-Q() ==  a
Inversion<Q,-,=v= >     : Q a;   a - a =v= Q()

对于 unsigned Quantifier — 即 unsigned numbers 的 icl 映射 — 适用于 Collectors 的相同基本定律同样成立:

                               +    &    -
Associativity                  ==   ==
Neutrality                     ==        ==
Commutativity                  ==   ==
Inversion absorbs_identities             ==
          enriches_identities            =d=

与 operator + 以及中性元素 Q() 相关的那部分定律就是交换幺半群的定律. 这与适用于 CodomainT 类型的概念相同. 由此产生一个假设: icl Map (其建立在一个 CommutativeModoid 之上) 仍是一个 CommutativeModoid.

对 Collectors 成立的其他定律, 对 unsigned Quantifier 不再成立.

有符号数量词的定律

对于有符号数的 Quantifiers, 即 signed Quantifiers, 有效定律的模式略有不同:

                               +    &    -
Associativity                  =v=  =v=
Neutrality                     ==        ==
Commutativity                  ==   ==
Inversion absorbs_identities             ==
          enriches_identities            =d=

这些差异标记为 =v=, 表明结合律不再对单一相等关系 == 唯一成立, 不像 Collector 与 unsigned Quntifier 映射的情形.

差异如下:

                                   +
Associativity         icl::map     ==
                  interval_map     ==
            split_interval_map     =e=

对于 operator +, split_interval_maps 上的结合律只在元素相等 =e= 下成立, 这个约束并不算大, 因为只要求元素相等.

对于 operator &, 所有部分吸收映射的结合律都被破坏. 对完全吸收映射, 结合律在元素相等下成立. 所有具有 充实单位元 特性的映射在字典序相等 == 下都是可结合的.

Associativity                        &
   absorbs_identities && !is_total   false
   absorbs_identities &&  is_total   =e=
   enriches_identities               ==

注意, 为 operator + 与单位元 Q() 建立交换幺半群的全部定律对 signed Quantifiers 都成立. 此外, 对 unsigned Qunatifiers 不成立的对称差对 signed Qunatifiers 却成立.

SymmetricDifference<Q,== > : Q a,b,c; (a + b) - (a & b) == (a - b) + (b - a)

对于 signed TotalQuantifier Qt, 对称差退化成一种平凡形式, 因为 operator & 与 operator + 变得相同

SymmetricDifference<Qt,== > : Qt a,b,c; (a + b) - (a + b) == (a - b) + (b - a) == Qt()

逆元素的存在性

到目前为止, signed Quantifiers Q 关于 operator + 和中性元素 Q() 是交换幺半群. 如果量词的 CodomainT 类型拥有 逆元素 (例如 signed numbers 就有), 那么 CodomainT 类型就是一个 交换群 或 阿贝尔群. 此时, 一个 signed Quantifier 若同时也是 完全的, 就拥有一个 逆, 并且下述定律成立:

InverseElement<Qt,== > : Qt a; (0 - a) + a == 0

这意味着建立在阿贝尔群之上的每个 TotalQuantifier 本身也是一个阿贝尔群.

这也意味着 Quantifier (由 Quantifiers 构成) 仍是一个 Quantifiers, 而 TotalQuantifier (由 TotalQuantifiers 构成) 也是一个 TotalQuantifier.

TotalQuantifiers 部分地类似于向量空间的概念. 如果再加上标量乘法, 这个概念就可以补全成一个向量空间.
