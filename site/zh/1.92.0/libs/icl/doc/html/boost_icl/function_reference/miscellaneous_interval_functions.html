说明

bool touches(const T&, const T&)

touches(x,y) 在不相交的区间 x 与 y 之间没有元素.

T inner_complement(const T&, const T&)

z = inner_complement(x,y) z 是 x 与 y 之间的区间

difference_type distance(const T&, const T&)

d = distance(x,y) 如果区间的定义域类型有 difference_type, 则 d 是 x 与 y 之间的距离.
