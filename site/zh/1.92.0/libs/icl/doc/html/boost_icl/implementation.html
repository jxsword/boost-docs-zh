Inplace and infix operators

前一节概述了 icl 的接口, 介绍了 类模板、关联类型 与多态的 函数与运算符. 为 下一节 做准备——该节将更详细地描述 icl 的 多态函数及其 复杂度特征——本节总结一些关于实现与性能的一般信息.

STL based implementation

icl 容器的 实现基于 std::set 与 std::map. 因此区间容器的底层数据结构是区间或区间值对的红黑树. 元素容器 std::set 与 icl::map 是 std::set 与 std::map 的包装类. 区间容器则使用区间的 std::sets 或区间值对的 icl::maps 作为实现容器. 因此 icl 容器的全部 复杂度特征 都基于且受限于底层 std::AssociativeContainers 的 红黑树实现.

Iterative size

在关于复杂度的全部文档中, 大 O 表达式 (如 O(n) 或 O(m log n)) 指的是容器大小 n 与 m. 在本文档中, 这些大小 并不是 指人们熟悉的 size 函数 (它返回容器的 元素个数). 因为对区间容器而言

interval_set<int> mono;
mono += interval<int>::closed(1,5); // {[1 ... 5]}
mono.size()           == 5;         // true, 5 elements
mono.interval_count() == 1;         // true, only one interval

it's size and the number of contained intervals is usually different. To refer uniformly to a size that matters for iteration, which is the decisive kind of size concerning algorithmic behavior there is a function 

bool T::iterative_size()const; // Number of entities that can be iterated over.

适用于 icl 的全部元素容器与区间容器. 因此在 icl 文档的全部复杂度陈述中, 大小均指 iterative_sizes, 而大 O 表达式 (如 O(m log n)) 指的也是这类大小

n = y.iterative_size();
m = x.iterative_size();

针对容器 y 和 x. 注意

iterative_size

指的是我们可以迭代遍历的主要实体. 对区间容器而言, 这些实体是区间或段.

Itervative_size

对区间容器绝不指元素迭代.
