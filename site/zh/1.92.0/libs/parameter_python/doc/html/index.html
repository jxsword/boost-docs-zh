引言

boost/parameter/python.hpp 引入了一组 def_visitors, 可用于通过 Boost.Python 轻松地把启用 Boost.Parameter 的成员函数暴露给 Python. 它还提供函数模板 def(), 用于暴露启用 Boost.Parameter 的自由函数.

绑定启用 Boost.Parameter 的函数时, 必须指定关键字标签. 此外, 由于启用 Boost.Parameter 的函数是模板, 还必须指定所需的函数签名.

关键字标签及关联的实参类型以 MPL 序列 的形式指定, 使用下文 ParameterSpec 中描述的函数类型语法. 此外, boost::parameter::python::function 和 boost::parameter::python::def 需要一个带转发重载的类. 我们将在下面的教程部分仔细研究如何做到这一点.

教程

本节将概述把一个简单的启用 Boost.Parameter 的成员函数绑定到 Python 所需的步骤. 理解本节需要掌握 Boost.Parameter 的 宏.

我们感兴趣要绑定的类和成员函数如下:

#include <boost/parameter/keyword.hpp>
#include <boost/parameter/preprocessor.hpp>
#include <boost/parameter/python.hpp>
#include <boost/python.hpp>

// First the keywords
BOOST_PARAMETER_KEYWORD(tag, title)
BOOST_PARAMETER_KEYWORD(tag, width)
BOOST_PARAMETER_KEYWORD(tag, height)

class window
{
public:
    BOOST_PARAMETER_MEMBER_FUNCTION(
      (void), open, tag,
      (required (title, (std::string)))
      (optional (width, (unsigned), 400)
                (height, (unsigned), 400))
    )
    {
        … function implementation …
    }
};

它定义了一组名为 open 的重载成员函数, 带有一个必需参数和两个可选参数. 要把这个成员函数绑定到 Python, 我们使用绑定工具 boost::parameter::python::function. boost::parameter::python::function 是一个 def_visitor, 我们将实例化它并传给 boost::python::class_::def().

要使用 boost::parameter::python::function, 我们首先需要定义一个带转发重载的类. 这是必需的, 因为 window::open() 是函数模板, 我们无法以其他方式引用它.

struct open_fwd
{
    template <class A0, class A1, class A2>
    void operator()(
        boost::type<void>, window& self
      , A0 const& a0, A1 const& a1, A2 const& a2
    )
    {
        self.open(a0, a1, a2);
    }
};

第一个参数 boost::type<void> 告诉转发重载返回类型应当是什么. 在本例中我们知道它总是 void, 但在某些情况下, 当我们导出启用 Boost.Parameter 的模板的多个特化时, 需要用该参数来推导返回类型.

window::open() 总共接受 3 个参数, 因此转发函数也需要接受三个参数.

注释

尽管有两个可选参数, 转发类中只需要一个重载. 在某些特殊情况下需要多个重载; 见 special 关键字.

接下来我们定义模块并导出该类:

BOOST_PYTHON_MODULE(my_module)
{
    using namespace boost::python;
    namespace py = boost::parameter::python;
    namespace mpl = boost::mpl;

    class_<window>("window")
        .def(
            "open", py::function<
                open_fwd
              , mpl::vector<
                    void
                  , tag::title(std::string)
                  , tag::width*(unsigned)
                  , tag::height*(unsigned)
                >
            >()
        );
}

py::function 被传入两个参数. 第一个是我们先前定义的带转发重载的类. 第二个是 MPL 序列, 以函数类型的形式给出该函数的关键字标签类型和实参类型. tag::width* 和 tag::height* 中使用的指针语法表示该参数是可选的. MPL 序列 的第一个元素是函数的返回类型, 此处为 void, 它作为第一个实参传给转发类中的 operator().

就是这样! 现在这个类可以在 Python 中以预期的语法使用:

>>> w = my_module.window()
>>> w.open(title = "foo", height = 20)

概念 ParameterSpec

ParameterSpec 是一个函数类型 K(T), 同时描述参数的关键字标签 K 和实参类型 T.

K 可以是:

  • 必需 关键字, 形式为 Tag
  • 或者, 一个 可选 关键字, 形式为 Tag*
  • 或者, 一个 special 关键字, 形式为 Tag**

其中 Tag 是关键字标签类型, 用于 boost::parameter::keyword 的特化中.

元数范围 (针对一个 MPL 序列, 其元素为 ParameterSpec) 定义为闭区间:

[ mpl::size<S> - number of special keyword tags in S, mpl::size<S> ]

例如, 元数范围: mpl::vector2<x(int),y(int)> 是 [2,2]; 元数范围: mpl::vector2<x(int),y*(int)> 是 [2,2]; 元数范围: mpl::vector2<x(int),y**(int)> 是 [1,2].

special 关键字

有时希望某个参数的默认值在类型上不同于该参数. 这项技术可用于基于参数是否出现进行简单的标签分发 (tag-dispatching). 例如:

namespace core
{
  template <class ArgumentPack>
  void dfs_dispatch(ArgumentPack const& args, mpl::false_)
  {
      …compute and use default color map…
  }

  template <class ArgumentPack, class ColorMap>
  void dfs_dispatch(ArgumentPack const& args, ColorMap colormap)
  {
      …use colormap…
  }
}

template <class ArgumentPack>
void depth_first_search(ArgumentPack const& args)
{
    core::dfs_dispatch(args, args[color | mpl::false_()]);
}

在上面的例子中, color 的默认值的类型是 mpl::false_, 这个类型不同于用户可能提供的任何颜色映射.

绑定上述情形时, color 的默认类型将不可转换为参数类型. 因此我们需要把 color 关键字标记为 special 关键字. 做法是在绑定函数时把标签指定为 tag::color** (标记的更多细节见 概念 ParameterSpec). 这样做我们就告诉绑定函数需要生成两个重载: 一个带 color 参数, 一个不带. 若有两个 special 关键字, 则需要生成四个重载. 生成的重载数量等于 2N, 其中 N 是 special 关键字的数量.

类模板 init

定义一个启用命名参数的构造函数.

template <class ParameterSpecs>
struct init : python::def_visitor<init<ParameterSpecs> >
{
    template <class Class>
    void def(Class& class_);

    template <class CallPolicies>
    def_visitor operator[](CallPolicies const& policies) const;
};

init 要求

  • ParameterSpecs 是一个 MPL 序列, 其中每个元素都是 ParameterSpec 的模型.

  • 对每个 N ∈ [U,V] (其中 [U,V] 是 元数范围, 属于 ParameterSpecs), Class 必须支持以下表达式:

    表达式 返回类型 要求
    Class(a0, …, aN) - a0…aN 是带标签的实参.

template <class CallPolicies> operator[](CallPolicies const&)

返回一个等价于 *this 的 def_visitor, 区别在于它在创建绑定时使用 CallPolicies.

示例

#include <boost/parameter/keyword.hpp>
#include <boost/parameter/preprocessor.hpp>
#include <boost/parameter/python.hpp>
#include <boost/python.hpp>
#include <boost/mpl/vector.hpp>

BOOST_PARAMETER_KEYWORD(tag, x)
BOOST_PARAMETER_KEYWORD(tag, y)

struct base
{
    template <class ArgumentPack>
    base(ArgumentPack const& args)
    {
        … use args …
    }
};

class X : base
{
public:
    BOOST_PARAMETER_CONSTRUCTOR(X, (base), tag,
        (required (x, *))
        (optional (y, *))
    )
};

BOOST_PYTHON_MODULE(module name)
{
    using namespace boost::python;
    namespace py = boost::parameter::python;
    namespace mpl = boost::mpl;

    class_<X>("X", no_init)
        .def(
            py::init<
                mpl::vector<tag::x(int), tag::y*(int)>
            >()
        );
}

类模板 call

定义一个 __call__ 运算符, 映射到 C++ 中的 operator().

template <class ParameterSpecs>
struct call : python::def_visitor<call<ParameterSpecs> >
{
    template <class Class>
    void def(Class& class_);

    template <class CallPolicies>
    def_visitor operator[](CallPolicies const& policies) const;
};

call 要求

  • ParameterSpecs 是一个 MPL 序列, 其中除第一个元素外的每个元素都是 ParameterSpec 的模型. 第一个元素是 c(…) 的结果类型.

  • Class 必须支持以下表达式, 其中 c 是 Class 的一个实例:

    表达式 返回类型 要求
    c(a0, …, aN) 可转换为 R a0…aN 是带标签的实参.

    对每个 N ∈ [U,V] (其中 [U,V] 是 元数范围, 属于 ParameterSpecs).

template <class CallPolicies> operator[](CallPolicies const&)

返回一个等价于 *this 的 def_visitor, 区别在于它在创建绑定时使用 CallPolicies.

示例

#include <boost/parameter/keyword.hpp>
#include <boost/parameter/preprocessor.hpp>
#include <boost/parameter/python.hpp>
#include <boost/python.hpp>
#include <boost/mpl/vector.hpp>

BOOST_PARAMETER_KEYWORD(tag, x)
BOOST_PARAMETER_KEYWORD(tag, y)

namespace parameter = boost::parameter;

typedef parameter::parameters<
    parameter::required<tag::x>
  , parameter::optional<tag::y>
> call_parameters;

class X
{
public:
    template <class ArgumentPack>
    int call_impl(ArgumentPack const& args)
    {
        … use args …
    }

    template <class A0>
    int operator()(A0 const& a0)
    {
        return call_impl(call_parameters()(a0));
    }

    template <class A0, class A1>
    int operator()(A0 const& a0, A1 const& a1)
    {
        return call_impl(call_parameters()(a0,a1));
    }
};

BOOST_PYTHON_MODULE(module name)
{
    using namespace boost::python;
    namespace py = parameter::python;
    namespace mpl = boost::mpl;

    class_<X>("X")
        .def(
            py::call<
                mpl::vector<int, tag::x(int), tag::y*(int)>
            >()
        );
}

类模板 function

定义一个启用命名参数的成员函数.

template <class Fwd, class ParameterSpecs>
struct function : python::def_visitor<function<Fwd, ParameterSpecs> >
{
    template <class Class, class Options>
    void def(Class& class_, char const* name, Options const& options);
};

function 要求

  • ParameterSpecs 是一个 MPL 序列, 其中除第一个元素外的每个元素都是 ParameterSpec 的模型. 第一个元素是 c.f(…) 的结果类型, 其中 f 是该成员函数.

  • Fwd 的实例必须支持以下表达式:

    表达式 返回类型 要求
    fwd(boost::type<R>(), self, a0, …, aN) 可转换为 R self 是对应当调用函数的对象的引用. a0…aN 是带标签的实参.

    对每个 N ∈ [U,V] (其中 [U,V] 是 元数范围, 属于 ParameterSpecs).

示例

本示例向 Python 导出成员函数 f(int x, int y = …). ParameterSpec 的序列 mpl::vector2<tag::x(int), tag::y*(int)> 的 元数范围 为 [2,2], 因此我们只需要一个转发重载.

#include <boost/parameter/keyword.hpp>
#include <boost/parameter/preprocessor.hpp>
#include <boost/parameter/python.hpp>
#include <boost/python.hpp>
#include <boost/mpl/vector.hpp>

BOOST_PARAMETER_KEYWORD(tag, x)
BOOST_PARAMETER_KEYWORD(tag, y)

class X
{
public:
    BOOST_PARAMETER_MEMBER_FUNCTION((void), f, tag,
        (required (x, *))
        (optional (y, *, 1))
    )
    {
        …
    }
};

struct f_fwd
{
    template <class A0, class A1>
    void operator()(boost::type<void>, X& self, A0 const& a0, A1 const& a1)
    {
        self.f(a0, a1);
    }
};

BOOST_PYTHON_MODULE(module name)
{
    using namespace boost::python;
    namespace py = boost::parameter::python;
    namespace mpl = boost::mpl;

    class_<X>("X")
        .def("f",
            py::function<
                f_fwd
              , mpl::vector<void, tag::x(int), tag::y*(int)>
            >()
        );
}

函数模板 def

在当前 Python 作用域中定义一个启用命名参数的自由函数.

template <class Fwd, class ParameterSpecs>
void def(char const* name);

def 要求

  • ParameterSpecs 是一个 MPL 序列, 其中除第一个元素外的每个元素都是 ParameterSpec 的模型. 第一个元素是 f(…) 的结果类型, 其中 f 是该函数.

  • Fwd 的实例必须支持以下表达式:

    表达式 返回类型 要求
    fwd(boost::type<R>(), a0, …, aN) 可转换为 R a0…aN 是带标签的实参.

    对每个 N ∈ [U,V] (其中 [U,V] 是 元数范围, 属于 ParameterSpecs).

示例

本示例向 Python 导出函数 f(int x, int y = …). ParameterSpec 的序列 mpl::vector2<tag::x(int), tag::y*(int)> 的 元数范围 为 [2,2], 因此我们只需要一个转发重载.

BOOST_PARAMETER_FUNCTION((void), f, tag,
    (required (x, *))
    (optional (y, *, 1))
)
{
    …
}

struct f_fwd
{
    template <class A0, class A1>
    void operator()(boost::type<void>, A0 const& a0, A1 const& a1)
    {
        f(a0, a1);
    }
};

BOOST_PYTHON_MODULE(…)
{
    def<
        f_fwd
      , mpl::vector<
            void, tag::x(int), tag::y*(int)
        >
    >("f");
}
