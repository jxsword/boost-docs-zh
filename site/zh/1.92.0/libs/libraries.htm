库列表 - 按字母顺序

  • Accumulators - 增量计算框架与统计累加器集合, 作者是 Eric Niebler
  • Algorithm - 实用泛型算法集合, 作者是 Marshall Clow
  • Align - 内存对齐函数、分配器与特征, 作者是 Glen Fernandes
  • Any - 用于存放不同值类型的单个值的安全泛型容器, 作者是 Kevlin Henney
  • Array - 符合 STL 标准的常量长度数组容器封装, 作者是 Nicolai Josuttis
  • Asio - 可移植的网络与其他底层 I/O, 包括套接字、定时器、主机名解析、套接字流、串口、文件描述符与 Windows HANDLE, 作者是 Chris Kohlhoff
  • Assert - 可定制断言宏, 作者是 Peter Dimov
  • Assign - 用常量或生成数据填充容器从未如此轻松, 作者是 Thorsten Ottosen
  • Atomic - C++11 风格的原子类型, 作者是 Helge Bahmann、Tim Blechmann 与 Andrey Semashev
  • Beast - 仅用 C++11 与 Boost.Asio 实现的可移植 HTTP、WebSocket 与网络操作, 作者是 Vinnie Falco
  • Bimap - C++ 双向映射库. 借助 Boost.Bimap 可以创建两种类型都可作键使用的关联容器, 作者是 Matias Capeletto
  • Bind - boost::bind 是标准函数 std::bind1st 和 std::bind2nd 的泛化. 它支持任意函数对象、函数、函数指针与成员函数指针, 能够把任意参数绑定到特定值, 或将输入参数路由到任意位置, 作者是 Peter Dimov
  • Bloom - 布隆过滤器, 作者是 Joaquín M López Muñoz
  • Call Traits - 定义用于传递参数的类型, 作者是 John Maddock、Howard Hinnant 等
  • CallableTraits - Boost.FunctionTypes 的精神后继, 是一个用于在编译期检查与操作所有可调用类型的仅头文件 C++11 库. 额外支持 C++17 特性, 作者是 Barrett Adair
  • CharConv - <charconv> 的 C++11 实现, 作者是 Matt Borland
  • Chrono - 实用的时间工具. C++11, 作者是 Howard Hinnant、Beman Dawes 与 Vicente J. Botet Escriba
  • Circular Buffer - 符合 STL 标准的容器, 也称环形或循环缓冲区, 作者是 Jan Gaspar
  • Cobalt - 协程. 基础算法与类型, 作者是 Klemens Morgenstern
  • Compat - 后续 C++ 标准新增标准组件的 C++11 实现, 作者是 Peter Dimov 与 Christian Mazakas
  • Compressed Pair - 带空成员优化的 pair 类, 作者是 John Maddock、Howard Hinnant 等
  • Compute - 并行/GPU 计算库, 作者是 Kyle Lutz
  • Concept Check - 泛型编程工具, 作者是 Jeremy Siek
  • Config - 帮助 Boost 库开发者适应编译器的各种特性差异; 不面向库用户
  • Container - 标准库容器及其扩展, 作者是 Ion Gaztañaga
  • Container Hash - 兼容 STL 的哈希函数对象, 可扩展以支持用户自定义类型的哈希, 作者是 Daniel James
  • Context - (C++11) 上下文切换库, 作者是 Oliver Kowalke
  • Contract - C++ 契约式编程. 支持全部契约式编程特性: 子契约、类不变式、后置条件 (带旧值与返回值)、前置条件、可定制的断言失败动作 (如终止或抛出异常)、断言的可选编译与检查等, 作者是 Lorenzo Caminiti
  • Conversion - 多态 cast, 作者是 Dave Abrahams 与 Kevlin Henney
  • Convert - 可扩展、可配置的类型转换框架, 作者是 Vladimir Batov
  • Core - 依赖极少的简单核心工具集, 作者是 Peter Dimov、Glen Fernandes 与 Andrey Semashev
  • Coroutine - 协程库, 作者是 Oliver Kowalke
  • Coroutine2 - (C++11) 协程库, 作者是 Oliver Kowalke
  • CRC - Boost CRC 库提供两个 CRC (循环冗余码) 计算对象实现和两个 CRC 计算函数实现. 这些实现均基于模板, 作者是 Daryle Walker
  • Date Time - 一组基于泛型编程概念的日期时间库, 作者是 Jeff Garland
  • Decimal - IEEE754 十进制浮点数的实现, 作者是 Matt Borland 与 Christopher Kormanyos
  • Describe - C++14 反射库, 作者是 Peter Dimov
  • DLL - 便捷操作 DLL 与 DSO 的库, 作者是 Antony Polukhin 与 Renato Tegon Forti
  • Dynamic Bitset - dynamic_bitset 模板表示一个位集合. 它通过 operator[] 访问单个位的值, 并提供可施加于内建整数的全部位运算符, 如 operator& 和 operator<<. 集合的位数可在运行期改变, 作者是 Jeremy Siek 与 Chuck Allison
  • Enable If - 函数模板重载的选择性启用, 作者是 Jaakko Järvi、Jeremiah Willcock 与 Andrew Lumsdaine
  • Endian - 无论处理器字节序如何, 都能正确处理字节序的类型与转换函数, 作者是 Beman Dawes
  • Exception - Boost Exception 库支持在异常对象中携带任意数据, 以及在线程间传递异常, 作者是 Emil Dotchevski
  • Fiber - (C++11) 用户态线程库, 作者是 Oliver Kowalke
  • Filesystem - Boost Filesystem 库提供查询与操作路径、文件和目录的可移植设施, 作者是 Beman Dawes
  • Flyweight - 用于管理大量高度冗余对象的设计模式, 作者是 Joaquín M López Muñoz
  • Foreach - 在 C++ 中, 编写遍历序列的循环十分繁琐. 我们要么使用迭代器 (需要大量样板代码), 要么使用 std::for_each() 算法并把循环体挪进谓词中 (样板代码同样不少, 还迫使我们把逻辑搬离使用它的地方). 相比之下, Perl 等其他语言提供了自动完成这一过程的专用 "foreach" 构造. BOOST_FOREACH 正是 C++ 的这样一种构造: 它替我们遍历序列, 免去直接处理迭代器或编写谓词的负担, 作者是 Eric Niebler
  • Format - format 库提供依据 printf 风格格式串对参数进行格式化的类型安全机制, 作者是 Samuel Krempp
  • Function - 用于延迟调用或回调的函数对象包装器, 作者是 Doug Gregor
  • Function Types - Boost.FunctionTypes 提供对函数、函数指针、函数引用与成员指针类型进行分类、分解与合成的功能, 作者是 Tobias Schwinger
  • Functional - Boost.Function 库包含一族作为函数对象包装器的类模板, 作者是 Mark Rodgers
  • Functional/Factory - 用于动态与静态对象创建的函数对象模板, 作者是 Glen Fernandes 与 Tobias Schwinger
  • Functional/Forward - 让泛型函数对象接受任意实参的适配器, 作者是 Tobias Schwinger
  • Functional/Overloaded Function - 把多个不同的函数重载为单个函数对象, 作者是 Lorenzo Caminiti
  • Fusion - 处理元组的库, 包括多种容器、算法等, 作者是 Joel de Guzman、Dan Marsden 与 Tobias Schwinger
  • Geometry - Boost.Geometry 库提供几何算法、几何图元与空间索引, 作者是 Barend Gehrels、Bruno Lalande、Mateusz Loskot、Adam Wulkiewicz、Menelaos Karavelas 与 Vissarion Fisikopoulos
  • GIL - (C++14) 通用图像库, 作者是 Lubomir Bourdev、Hailin Jin 与 Christian Henning
  • Graph - BGL 图接口与图组件是泛型的, 与标准模板库 (STL) 的泛型性含义相同, 作者是 Jeremy Siek 与圣母大学团队.
  • GraphParallel - PBGL 图接口与图组件是泛型的, 与标准模板库 (STL) 的泛型性含义相同, 作者是 Jeremy Siek、Doug Gregor 与圣母大学团队.
  • Hana - 现代 C++ 元编程库. 它提供操作异构序列的高级算法, 支持以自然语法编写类型层计算, 提供内省用户自定义类型的工具, 以及更多功能, 作者是 Louis Dionne
  • Hash2 - 可扩展的哈希框架, 作者是 Peter Dimov 与 Christian Mazakas
  • Heap - 优先队列数据结构, 作者是 Tim Blechmann
  • Histogram - 面向 C++14 的快速多维直方图, 接口便捷, 作者是 Hans Dembinski
  • HOF - 面向 C++ 的高阶函数库, 作者是 Paul Fultz II
  • ICL - 区间容器库 (Interval Container Library), 区间集合与映射以及关联值的聚合, 作者是 Joachim Faulhaber
  • Identity Type - 用圆括号包裹类型, 使其总能作为宏参数传递, 作者是 Lorenzo Caminiti
  • In Place Factory, Typed In Place Factory - 用变参实参列表对所含对象进行泛型就地构造, 作者是 Fernando Cacciola
  • Integer - boost 整数头文件与类的组织设计旨在利用 1999 年 C 标准的 <stdint.h> 类型, 同时不触犯 1998 年 C++ 标准的未定义行为. 头文件 <boost/cstdint.hpp> 在命名空间 boost 中安全地提供标准整数类型, 且不向命名空间 std 中放置任何名字
  • Interprocess - 共享内存、内存映射文件、进程间共享的互斥量、条件变量、容器与分配器, 作者是 Ion Gaztañaga
  • Interval - 把常规算术函数扩展到数学区间, 作者是 Guillaume Melquiond、Hervé Brönnimann 与 Sylvain Pion
  • Intrusive - 侵入式容器与算法, 作者是 Ion Gaztañaga
  • IO - 标准 I/O 库的实用工具, 作者是 Daryle Walker、Beman Dawes 与 Glen Fernandes
  • Iostreams - Boost.IOStreams 提供定义流、流缓冲区与 I/O 过滤器的框架, 作者是 Jonathan Turkanis
  • Iterator - Boost Iterator 库包含两部分. 第一部分是扩展 C++ 标准迭代器要求的概念体系; 第二部分是基于这些扩展概念构建迭代器的组件框架, 并包括若干实用迭代器适配器, 作者是 Dave Abrahams、Jeremy Siek 与 Thomas Witt
  • JSON - C++11 的 JSON 解析、序列化与 DOM, 作者是 Vinnie Falco 与 Krystian Stasiowski
  • Lambda - 在实际调用处定义小型无名函数对象, 以及更多功能, 作者是 Jaakko Järvi 与 Gary Powell
  • Lambda2 - C++14 lambda 库, 作者是 Peter Dimov
  • LEAF - 面向 C++11 的轻量级错误处理库, 作者是 Emil Dotchevski
  • Lexical Cast - 通用字面文本转换, 例如字符串表示的 int 与其反向转换, 作者是 Kevlin Henney
  • Local Function - 在其他函数内部、即需要它们的所在作用域中局部地定义函数, 作者是 Lorenzo Caminiti
  • Locale - 为 C++ 提供本地化与 Unicode 处理工具, 作者是 Artyom Beilis
  • Lockfree - 无锁数据结构, 作者是 Tim Blechmann
  • Log - 日志库, 作者是 Andrey Semashev
  • Math - Boost.Math 包含数学领域的多项贡献: 浮点工具、特定宽度浮点类型、数学常量、统计分布、特殊函数、求根与函数最小化、多项式与有理函数、插值以及数值积分与微分. 其中许多特性均以模板实现, 同时支持内建类型与扩展宽度类型 (例如 Boost.Multiprecision), 作者是多位贡献者
  • Member Function - 面向函数/对象/指针与成员函数的泛化绑定器, 作者是 Peter Dimov
  • Meta State Machine - 用于表达 UML2 有限状态机的高性能库, 作者是 Christophe Henry

  • Mp11 - C++11 元编程库, 作者是 Peter Dimov
