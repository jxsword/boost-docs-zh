编写新后端

类number 后端的正式要求见参考部分; 但为了帮助加快和简化这一过程, 提供了头文件skeleton_backend.hpp, 其中声明了所有需要编写的方法但没有实现任何内容. 编写新后端的过程于是简化为:

  • 把 skeleton_backend.hpp 以新名称保存, 并相应修改其 #include 保护宏.
  • 查找并把skeleton_backend 替换为新后端类型的名称.
  • 填写类定义和强制性非成员函数中的空白.
  • 别忘了按要求把函数标记为inline,constexpr 和noexcept.
  • 可选地填写一些可选方法 - 头文件以相当冗长的形式声明了它们, 例如为每一种算术类型都提供重载. 没有哪个正常的后端会实现所有这些, 只需选择有意义的方法, 其余留空即可.
  • 为将使用新后端的类number 的实际实例化添加便捷的 typedef.

要测试新后端, 先从基本算术测试开始, 它是libs/math/test 下的一个测试用例, 大致形如:

#include <boost/multiprecision/my_new_number_type.hpp>
#include "test_arithmetic.hpp"

int main()
{
   test<boost::multiprecision::my_new_number_type>();
   return boost::report_errors();
}

这基本上会"实例化一切", 并执行一些运行期健全性检查; 它是检验你所写代码是否合法的绝佳测试!

你还应创建一个"头文件包含测试", 验证新头文件包含了它应该包含的一切, 示例见mpfr_include_test.cpp.

对整数类型, 你还应把新类型至少加入以下测试:

  • test_hash.cpp
  • test_int_io.cpp
  • test_move.cpp
  • test_numeric_limits.cpp
