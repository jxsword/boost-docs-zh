cpp_dec_float 

namespace boost{ namespace multiprecision{

template <unsigned Digits10, class ExponentType = std::int32_t, class Allocator = void>
class cpp_dec_float;

typedef number<cpp_dec_float<50> > cpp_dec_float_50;
typedef number<cpp_dec_float<100> > cpp_dec_float_100;

}} // namespaces

类模板cpp_dec_float 满足Backend 类型的全部要求. 其成员与非成员函数刻意不作文档说明: 它们被视为可能变化的实现细节.

该类接受三个模板参数:

Digits10

该类型应支持的十进制精度位数. 注意, 此类型通常不执行任何动态内存分配, 因此Digits10 模板参数不应设置得过高, 否则类的大小会不合理地膨胀.

ExponentType

表示该数指数的有符号整数类型

Allocator

所使用的分配器: 默认为类型void, 表示所有存储都在类内部, 不执行动态分配; 但若动态分配更合理, 也可以设置为标准库分配器.

number_category<cpp_dec_float<Args...> >::type 的类型是std::integral_constant<int, number_kind_floating_point>.

有关此类型的更多信息见教程.
