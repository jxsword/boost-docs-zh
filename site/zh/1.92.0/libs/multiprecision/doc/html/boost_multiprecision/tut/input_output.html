输入输出

回环测试

回环或往返转换指的是用std::iostream 把一个值写为十进制数字字符串(通常是写到std::stringstream 中), 然后把该字符串读回到另一个值, 并确认两个值完全相同. 使用float 的一个简单示例是:

float write; // Value to round-trip.
std::stringstream ss;  // Read and write std::stringstream.
ss.precision(std::numeric_limits<T>::max_digits10);  // Ensure all potentially significant bits are output.
ss.flags(std::ios_base::fmtflags(std::ios_base::scientific)); // Use scientific format.
ss << write; // Output to string.
float read;  // Expected.
ss >> read; // Read decimal digits string from stringstream.
BOOST_CHECK_EQUAL(write, read); // Should be the same.

并且可以对 32 位 float 的所有可能值循环运行此测试. 对于其他浮点数类型T(包括基本(内建) double), 测试所有值耗时过长, 因此合理的测试策略是使用大量随机值.

T write;
std::stringstream ss;
ss.precision(std::numeric_limits<T>::max_digits10);  // Ensure all potentially significant bits are output.
ss.flags(f); // Changed from default iostream format flags if desired.
ss << write; // Output to stringstream.

T read;
ss >> read; // Get read using operator>> from stringstream.
BOOST_CHECK_EQUAL(read, write);

read = static_cast<T>(ss.str()); // Get read by converting from decimal digits string representation of write.
BOOST_CHECK_EQUAL(read, write);

read = static_cast<T>(write.str(0, f));  // Get read using format specified when written.
BOOST_CHECK_EQUAL(read, write);

位于test_cpp_bin_float_io.cpp 的测试允许用大量相当随机的值对任何浮点数类型进行往返转换. 它还包含把文件中的一组stringdata 测试用例进行比较的测试.

与基本(内建)类型的输出进行比较

可以把它与下面的输出做一些比较:

<number<cpp_bin_float<53, digit_count_2> >

它与 64 位双精度浮点数具有相同数量的有效位(53).

不过, 尽管大多数输出相同, 但 C99 规范C99 ISO/IEC 9899:TC2(由 C++ 吸收)允许的实现相关行为在某些平台上会造成差异.

"对于 e、E、f、F、g 和 G 转换, 若有效十进制位数不超过 DECIMAL_DIG, 则结果应正确舍入. 若有效十进制位数超过 DECIMAL_DIG 但源值可以用 DECIMAL_DIG 位数字精确表示, 则结果应是带末尾零的精确表示. 否则, 源值由两个相邻的十进制字符串 L < U 界定, 二者都有 DECIMAL_DIG 位有效数字; 结果十进制字符串 D 的值应满足 L<= D <= U, 并附加规定: 对于当前舍入方向, 误差应具有正确的符号."

因此, 不仅不要求对全部位数进行正确舍入, 而且即使遵循了可选的推荐做法, 只要值在一定界限内, 最后几位数字的值也是未指定的.

注释

不要期望不同平台的输出完全相同, 但cpp_dec_float,cpp_bin_float(以及其他后端)的输出应当按所设置的精度和格式所要求的位数正确舍入.

宏 BOOST_MP_MIN_EXPONENT_DIGITS

C99 标准 的格式说明符部分, 7.19.6 格式化输入/输出函数要求:

"指数始终至少包含两位数字, 并且只在必要时增加表示指数所需的更多数字."

因此为了符合 C99 标准(由 C++ 吸收)

#define BOOST_MP_MIN_EXPONENT_DIGITS 2

令人困惑的是, Microsoft(以及 MinGW)不符合此标准, 而是提供至少三位数字, 例如1e+001. 因此, 若你希望输出与在使用 Microsoft 运行时的编译器上基本(内建)浮点数类型的输出一致, 请使用:

#define BOOST_MP_MIN_EXPONENT_DIGITS 3

对获得最小指数字段宽度同样有用的是

#define BOOST_MP_MIN_EXPONENT_DIGITS 1

产生类似2e+4 的紧凑输出, 在需要节省空间时很有用.

也支持更大的值, 例如为2e+0004 设置值 4, 这可能有助于确保各列对齐.
