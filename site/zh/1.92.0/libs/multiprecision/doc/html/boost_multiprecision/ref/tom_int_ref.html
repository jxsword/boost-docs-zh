类模板tommath_int 满足Backend 类型的全部要求. 其成员与非成员函数刻意不作文档说明: 它们被视为可能变化的实现细节.

number_category<cpp_int<Args...> >::type 的类型是std::integral_constant<int, number_kind_integer>.
