gmp_rational

#include <boost/multiprecision/gmp.hpp> 

namespace boost{ namespace multiprecision{

class gmp_rational;

typedef number<gmp_rational >         mpq_rational;

}} // namespaces

gmp_rational 后端通过 typedefboost::multiprecision::mpq_rational 使用. 它是围绕GMP mpq_t 的薄封装, 提供可直接替换原生 C++ 数字类型的有理数类型, 但精度无限.

除了可以从算术类型和字符串类型进行常规转换之外,number<gmp_rational> 的实例还可以从下列来源拷贝构造和赋值:

  • GMP 原生类型:mpz_t,mpq_t.
  • number<gmp_int>.

还有一个双参数构造函数, 接受分子和分母(二者类型均为number<gmp_int>).

还有一些非成员函数:

mpz_int numerator(const mpq_rational&);
mpz_int denominator(const mpq_rational&);

它们返回该数的分子和分母.

也可以通过mpq_t 的成员函数data() 访问底层的mpq_rational.

使用此类型时你应当知道的事项:

  • 默认构造的mpq_rational 的值为零(这是GMP 的默认行为).
  • 除以零会导致抛出std::overflow_error.
  • 若字符串无法解释为有效的有理数, 则从字符串转换会抛出std::runtime_error.
  • 不会对GMP 库的全局设置做任何更改, 因此此类型可以与现有GMP 代码共存.
  • 代码同样可以搭配MPIR 作为底层库 - 实际上这是 Win32 上的首选方案.
示例: 
#include <boost/multiprecision/gmp.hpp>
#include <iostream>

int main()
{
   using namespace boost::multiprecision;

   mpq_rational v = 1;

   // Do some arithmetic:
   for(unsigned i = 1; i <= 1000; ++i)
      v *= i;
   v /= 10;

   std::cout << v << std::endl; // prints 1000! / 10
   std::cout << numerator(v) << std::endl;
   std::cout << denominator(v) << std::endl;

   mpq_rational w(2, 3);  // component wise constructor
   std::cout << w << std::endl; // prints 2/3

   // Access the underlying data:
   mpq_t q;
   mpq_init(q);
   mpq_set(q, v.backend().data());
   mpq_clear(q);
   return 0;
}
