从/向cpp_int 和cpp_bin_float

任何以cpp_int_backend 作为实现层的整数数字类型都可以通过两个非成员函数导入或导出其位:

template <std::size_t MinBits, std::size_t MaxBits, cpp_integer_type SignType, cpp_int_check_type Checked, class Allocator,
          expression_template_option ExpressionTemplates, class OutputIterator>
OutputIterator export_bits(
   const number<const cpp_int_backend<MinBits, MaxBits, SignType, Checked, Allocator>, ExpressionTemplates>& val,
   OutputIterator out,
   unsigned chunk_size,
   bool msv_first = true);

template <std::size_t MinBits, std::size_t MaxBits, cpp_integer_type SignType, cpp_int_check_type Checked, class Allocator,
          expression_template_option ExpressionTemplates, class Iterator>
number<cpp_int_backend<MinBits, MaxBits, SignType, Checked, Allocator>, ExpressionTemplates>&
   import_bits(
      number<cpp_int_backend<MinBits, MaxBits, SignType, Checked, Allocator>, ExpressionTemplates>& val,
      Iterator i,
      Iterator j,
      unsigned chunk_size = 0,
      bool msv_first = true);

这些函数设计用于与其他存储格式的数据交换; 由于cpp_bin_float 内部使用cpp_int, 推而广之, 它们也可用于基于该后端的浮点数(见下面的示例). 参数和用法如下:

template <std::size_t MinBits, std::size_t MaxBits, cpp_integer_type SignType, cpp_int_check_type Checked, class Allocator,
          expression_template_option ExpressionTemplates, class OutputIterator>
OutputIterator export_bits(
   const number<const cpp_int_backend<MinBits, MaxBits, SignType, Checked, Allocator>, ExpressionTemplates>& val,
   OutputIterator out,
   unsigned chunk_size,
   bool msv_first = true);

把val 的绝对值导出到 OutputIteratorout. 该函数每次向 OutputIterator 写入chunk_size 个位; 若msv_first 为 true, 则先写最高有效块. 每个chunk_size 块内部的字节序和位序始终是机器的原生格式. 此外, 每个块在被赋给std::uintmax_t 时会存储在一个*out 中.

注释

遗憾的是, 标准的 OutputIterator 概念无法推导要输出的类型, 因为std::iterator_traits<OutputIteratorType>::value_type 的类型是void. 这就是为什么每个块的位数必须手动指定. 这还可能导致编译器发出关于值被收窄的警告.

提示

若你要导出为非原生字节布局, 则可以使用Boost.Endian 创建一个自定义 OutputIterator, 在实际存储结果之前反转每个块的字节序.

template <std::size_t MinBits, std::size_t MaxBits, cpp_integer_type SignType, cpp_int_check_type Checked, class Allocator,
          expression_template_option ExpressionTemplates, class ForwardIterator>
number<cpp_int_backend<MinBits, MaxBits, SignType, Checked, Allocator>, ExpressionTemplates>&
   import_bits(
      number<cpp_int_backend<MinBits, MaxBits, SignType, Checked, Allocator>, ExpressionTemplates>& val,
      ForwardIterator i,
      ForwardIterator j,
      unsigned chunk_size = 0,
      bool msv_first = true);

从迭代器范围[i,j) 导入位并存储到val 中, 产生无符号结果(若结果需要带符号, 你需要单独处理). 当msv_first 为 true 时, 把*i 视为最高有效块. 假定从迭代器范围读取的每个值有chunk_size 个位, 且按机器原生位/字节序排列. 当chunk_size 为零时, 假定每个块包含std::numeric_limits<std::iterator_traits<ForwardIterator>::value_type>::digits; 注意, 若解引用迭代器得到有符号整数类型且符号位有效, 这会给出错误结果(若你期望类型char 包含 8 位值, 则要特别小心, 因为默认情况下若char 是有符号的, 每次只会提取 7 位). 与导出一样, 若外部数据要采用非原生字节序(在每个块内部), 你需要创建一个以原生序呈现数据的迭代器适配器(参见Boost.Endian).

注释

注意, 此函数针对可以把数据从源memcpy 到整数的情况做了优化 - 此时两个迭代器都必须是指针, 且所有数据必须是小端序.

示例

在这个简单示例中, 我们将把 cpp_int 的位导入/导出到一个 8 位无符号值的 vector:

#include <boost/multiprecision/cpp_int.hpp>
#include <iostream>
#include <iomanip>
#include <vector>
#include <iterator>


int main()
{
   using boost::multiprecision::cpp_int;
   // Create a cpp_int with just a couple of bits set:
   cpp_int i;
   bit_set(i, 5000); // set the 5000'th bit
   bit_set(i, 200);
   bit_set(i, 50);
   // export into 8-bit unsigned values, most significant bit first:
   std::vector<unsigned char> v;
   export_bits(i, std::back_inserter(v), 8);
   // import back again, and check for equality:
   cpp_int j;
   import_bits(j, v.begin(), v.end());
   BOOST_MP_ASSERT(i == j);
}

导入或导出 cpp_bin_float 也类似, 但必须通过一个中间整数进行:

#include <boost/multiprecision/cpp_bin_float.hpp>
#include <iostream>
#include <iomanip>
#include <vector>
#include <iterator>


int main()
{
   using boost::multiprecision::cpp_bin_float_100;
   using boost::multiprecision::cpp_int;
   // Create a cpp_bin_float to import/export:
   cpp_bin_float_100 f(1);
   f /= 3;
   // export into 8-bit unsigned values, most significant bit first:
   std::vector<unsigned char> v;
   export_bits(cpp_int(f.backend().bits()), std::back_inserter(v), 8);
   // Grab the exponent as well:
   int e = f.backend().exponent();
   // Import back again, and check for equality, we have to proceed via
   // an intermediate integer:
   cpp_int i;
   import_bits(i, v.begin(), v.end());
   cpp_bin_float_100 g(i);
   g.backend().exponent() = e;
   BOOST_MP_ASSERT(f == g);
}
