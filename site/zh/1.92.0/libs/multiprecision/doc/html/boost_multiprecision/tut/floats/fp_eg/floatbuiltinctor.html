从特定值构造而不损失精度

从内建浮点数类型构造 multiprecision 类型可能产生看似意外但实际正确的结果. 例如, 考虑构造一个cpp_dec_float_50 的实例, 其来源是字面量内建浮点数double 值 11.1.

#include <iomanip>
#include <iostream>
#include <limits>

#include <boost/multiprecision/cpp_dec_float.hpp>

int main()
{
  using my_dec_100 = boost::multiprecision::cpp_dec_float_50;

  const my_dec_100 f11(11.1);

  // On a system with 64-bit double:
  // 11.09999999999999964472863211994990706443786621093750
  std::cout << std::setprecision(std::numeric_limits<my_dec_100>::digits10)
            << std::fixed
            << f11
            << std::endl;
}

在此示例中, 系统具有 64 位内建double 表示. 变量f11 用字面量double 值 11.1 初始化. 回顾一下, 内建浮点表示基于逐次二进制分数逼近. 事实上这些逼近非常接近, 但它们终究是逼近, 具有内建的有限精度.

因此, 11.1 的double 逼近的完整多精度值就是上面显示的那个长值. 观察表明, 在此系统上该值在内建 64 位double 约 15 位十进制精度范围内是可靠的.

若需要 11.1 的精确值(在 multiprecision 类型的更高精度范围内), 则应使用从字面量字符串构造, 或通过有理整数构造/除法序列来构造.

const my_dec_100 f11_str("11.1");
const my_dec_100 f11_n  (my_dec_100(111) / 10);
