转换的舍入规则

一般规则是, 不相关类型之间的所有转换都使用基本算术运算执行; 因此转换要么是精确的, 要么遵循与该类型算术相同的舍入规则.

下表总结了从原生类型转换的情况:

后端

舍入规则

cpp_int

若目标有足够精度, 则从整数类型的转换是精确的; 否则会截断到前 2^MaxBits 位(回绕算术). 从浮点数类型的转换会截断到最近的整数.

gmp_int

转换由 GMP 库执行, 但从long double 的转换是截断式的.

tom_int

从浮点数类型的转换是截断式的; 其余转换由 libtommath 执行且是精确的.

gmp_float

转换由 GMP 库执行, 但从long double 的转换应当是精确的, 前提是目标类型的精度不低于long double.

mpfr_float

所有转换都由底层 MPFR 库执行.

cpp_dec_float

所有转换都使用基本算术运算执行, 且是截断式的.

gmp_rational

见gmp_int

cpp_rational

见cpp_int

tommath_rational

见tom_int
