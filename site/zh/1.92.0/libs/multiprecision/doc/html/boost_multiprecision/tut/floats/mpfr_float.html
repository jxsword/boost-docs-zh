mpfr_float

#include <boost/multiprecision/mpfr.hpp> 

namespace boost{ namespace multiprecision{

enum mpfr_allocation_type
{
   allocate_stack,
   allocate_dynamic
};

template <unsigned Digits10, mpfr_allocation_type AllocateType = allocate_dynamic>
class mpfr_float_backend;

typedef number<mpfr_float_backend<50> >    mpfr_float_50;
typedef number<mpfr_float_backend<100> >   mpfr_float_100;
typedef number<mpfr_float_backend<500> >   mpfr_float_500;
typedef number<mpfr_float_backend<1000> >  mpfr_float_1000;
typedef number<mpfr_float_backend<0> >     mpfr_float;

typedef number<mpfr_float_backend<50, allocate_stack> >    static_mpfr_float_50;
typedef number<mpfr_float_backend<100, allocate_stack> >   static_mpfr_float_100;

}} // namespaces

mpfr_float_backend 类型与number 配合使用: 它是围绕MPFR mpfr_t 的薄封装, 提供可直接替换原生 C++ 浮点数类型的实数类型, 但精度高得多.

类型mpfr_float_backend 可以定点精度使用(指定非零的Digits10 模板参数), 也可以把模板参数设为零以可变精度使用. 类型定义 mpfr_float_50、mpfr_float_100、mpfr_float_500、mpfr_float_1000 分别提供 50、100、500 和 1000 位十进制精度的算术类型. 类型定义 mpfr_float 提供可变精度类型, 其精度可通过number 的成员函数控制.

此外, 第二个模板参数让你可以在动态分配(默认, 使用 MPFR 的常规分配例程)和栈分配(底层类型所需的全部内存都存储在mpfr_float_backend 内)之间选择. 后一种选择可以得到明显更快的代码, 代价是增大mpfr_float_backend 的大小. 它只能在定点精度下使用, 且只应用于较低的位数. 注意, 我们无法保证使用allocate_stack 不会引起对mpfr 分配例程的任何调用, 因为mpfr 可能在自己的代码内部调用这些例程. 下表给出了 50 位十进制精度下性能权衡的概况[2]:

注释

仅当精度在编译期固定时, 此类型才提供numeric_limits 支持.

除了可以从算术类型和字符串类型进行常规转换之外,number<mpfr_float_backend<N> > 的实例还可以从下列来源拷贝构造和赋值:

  • GMP 原生类型mpf_t,mpz_t,mpq_t.
  • MPFR 原生类型mpfr_t.
  • number 围绕这些类型的封装:number<mpfr_float_backend<M> >,number<mpf_float<M> >,number<gmp_int>,number<gmp_rational>.

也可以通过mpfr_t 的 data() 成员函数访问底层的mpfr_float_backend.

使用此类型时你应当知道的事项:

  • 默认构造的mpfr_float_backend 被置为零(注意这并非默认的MPFR 行为).
  • 所有运算都采用就近舍入.
  • 不会对GMP 或MPFR 的全局设置做任何更改, 因此此类型可以与现有MPFR 或GMP 代码共存.
  • 代码同样可以使用MPIR 代替GMP - 实际上这在 Win32 上是首选方案.
  • 此后端支持右值引用并具有移动感知能力, 使得基于此后端实例化的number 也具有移动感知能力.
  • 若字符串无法解释为有效的浮点数, 则从字符串转换会抛出std::runtime_error.
  • 除以零会产生无穷大.
  • 使用可变精度类型mpfr_float 时, 拷贝构造和赋值会复制源变量的精度. 移动构造和赋值同理.
  • 构造可变精度类型mpfr_float 时, 你可以给构造函数指定两个参数 - 第一个是要赋给变量的值, 第二个是指定十进制小数位精度的无符号整数. 成员函数assign 同样有一个双参数重载, 接受要赋的值和精度. 你可以用它来保持目标变量的精度, 写法有点晦涩:a.assign(b, a.precision()), 它把b 赋给a, 但保留a 的精度.
MPFR 示例: 
#include <boost/multiprecision/mpfr.hpp>
#include <boost/math/special_functions/gamma.hpp>
#include <iostream>

int main()
{
   using namespace boost::multiprecision;

   // Operations at variable precision and no numeric_limits support:
   mpfr_float a = 2;
   mpfr_float::default_precision(1000);
   std::cout << mpfr_float::default_precision() << std::endl;
   std::cout << sqrt(a) << std::endl; // print root-2

   // Operations at fixed precision and full numeric_limits support:
   mpfr_float_100 b = 2;
   std::cout << std::numeric_limits<mpfr_float_100>::digits << std::endl;
   // We can use any C++ std lib function:
   std::cout << log(b) << std::endl; // print log(2)
   // We can also use any function from Boost.Math:
   std::cout << boost::math::tgamma(b) << std::endl;
   // These even work when the argument is an expression template:
   std::cout << boost::math::tgamma(b * b) << std::endl;

   // Access the underlying data:
   mpfr_t r;
   mpfr_init(r);
   mpfr_set(r, b.backend().data(), GMP_RNDN);
   mpfr_clear(r);
   return 0;
}
