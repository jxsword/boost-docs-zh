tom_int

#include <boost/multiprecision/tommath.hpp> 

namespace boost{ namespace multiprecision{

class tommath_int;

typedef number<tommath_int >         tom_int;

}} // namespaces

tommath_int 后端通过 typedefboost::multiprecision::tom_int 使用. 它是围绕libtommath tom_int 的薄封装, 提供可直接替换原生 C++ 整数类型的整数类型, 但精度无限.

使用此类型时你应当知道的事项:

  • 默认构造的对象的值为零(这是libtommath 的默认行为).
  • 虽然tom_int 在大多数情况下可以直接替换整数基本(内建)类型, 但应注意它是个相当奇特的东西: 它是有符号类型, 却不是二进制补码类型. 因此, 若任一参数为负, 按位运算| & ^ 会抛出std::runtime_error 异常. 同样, 取反运算符~ 对此类型刻意未实现.
  • 此类型的格式化 IO 不支持负值的八进制或十六进制表示; 因此当参数为负且设置了标志std::ios_base::oct 和std::ios_base::hex 之一时, 对此类型执行格式化输出会抛出std::runtime_error.
  • 若字符串无法解释为有效整数, 则从字符串转换会抛出std::runtime_error.
  • 除以零会导致抛出std::overflow_error.
示例: 
#include <boost/multiprecision/tommath.hpp>
#include <iostream>

int main()
{
   boost::multiprecision::tom_int v = 1;

   // Do some arithmetic:
   for(unsigned i = 1; i <= 1000; ++i)
      v *= i;

   std::cout << v << std::endl; // prints 1000!
   std::cout << std::hex << v << std::endl; // prints 1000! in hex format

   try{
      std::cout << std::hex << -v << std::endl; // Ooops! can't print a negative value in hex format!
   }
   catch(const std::runtime_error& e)
   {
      std::cout << e.what() << std::endl;
   }

   try{
      // v is not a 2's complement type, bitwise operations are only supported
      // on positive values:
      v = -v & 2;
   }
   catch(const std::runtime_error& e)
   {
      std::cout << e.what() << std::endl;
   }

   return 0;
}
