gmp_float

#include <boost/multiprecision/gmp.hpp> 

namespace boost{ namespace multiprecision{

template <unsigned Digits10>
class gmp_float;

typedef number<gmp_float<50> >    mpf_float_50;
typedef number<gmp_float<100> >   mpf_float_100;
typedef number<gmp_float<500> >   mpf_float_500;
typedef number<gmp_float<1000> >  mpf_float_1000;
typedef number<gmp_float<0> >     mpf_float;

}} // namespaces

gmp_float 后端与number 配合使用: 它是围绕GMP mpf_t 的薄封装, 提供可直接替换原生 C++ 浮点数类型的实数类型, 但精度高得多.

类型gmp_float 可以定点精度使用(指定非零的Digits10 模板参数), 也可以把模板参数设为零以可变精度使用. 类型定义 mpf_float_50、mpf_float_100、mpf_float_500、mpf_float_1000 分别提供 50、100、500 和 1000 位十进制精度的算术类型. 类型定义 mpf_float 提供可变精度类型, 其精度可通过number 的成员函数控制.

注释

仅当精度在编译期固定时, 此类型才提供标准库和numeric_limits 支持.

除了可以从算术类型和字符串类型进行常规转换之外,number<mpf_float<N> > 的实例还可以从下列来源拷贝构造和赋值:

  • GMP 原生类型mpf_t,mpz_t,mpq_t.
  • number 围绕这些类型的封装:number<mpf_float<M> >,number<gmp_int>,number<gmp_rational>.

也可以通过mpf_t 的成员函数data() 访问底层的gmp_float.

使用此类型时你应当知道的事项:

  • 默认构造的gmp_float 的值为零(这是GMP 库的默认行为).
  • 不会对GMP 库的全局设置做任何更改, 因此此类型可以与现有GMP 代码安全地混用.
  • 此后端支持右值引用并具有移动感知能力, 使得基于此后端实例化的number 也具有移动感知能力.
  • 无法把此类型的对象与字符串往返转换并得到完全相同的值. 这似乎是GMP 的限制.
  • 由于底层的GMP 类型没有无穷大或 NaN 的概念, 应当注意避免数值溢出或除以零. 后者会导致抛出 std::overflow_error, 而产生过大的指数可能使底层GMP 库不稳定(在测试中, 把一个指数过大或过小的数转换为字符串曾导致GMP 段错误).
  • 此类型同样可以搭配MPIR 作为底层实现 - 实际上这是 Win32 上的推荐选项.
  • 若字符串无法解释为有效的浮点数, 则从字符串转换会抛出std::runtime_error.
  • 除以零会导致抛出std::overflow_error.
GMP 示例: 
#include <boost/multiprecision/gmp.hpp>
#include <boost/math/special_functions/gamma.hpp>
#include <iostream>

int main()
{
   using namespace boost::multiprecision;

   // Operations at variable precision and limited standard library support:
   mpf_float a = 2;
   mpf_float::default_precision(1000);
   std::cout << mpf_float::default_precision() << std::endl;
   std::cout << sqrt(a) << std::endl; // print root-2

   // Operations at fixed precision and full standard library support:
   mpf_float_100 b = 2;
   std::cout << std::numeric_limits<mpf_float_100>::digits << std::endl;
   // We can use any C++ std lib function:
   std::cout << log(b) << std::endl; // print log(2)
   // We can also use any function from Boost.Math:
   std::cout << boost::math::tgamma(b) << std::endl;
   // These even work when the argument is an expression template:
   std::cout << boost::math::tgamma(b * b) << std::endl;

   // Access the underlying representation:
   mpf_t f;
   mpf_init(f);
   mpf_set(f, a.backend().data());
   mpf_clear(f);
   return 0;
}
