tommath_rational

#include <boost/multiprecision/tommath.hpp> 

namespace boost{ namespace multiprecision{

typedef rational_adpater<tommath_int>        tommath_rational;
typedef number<tommath_rational >         tom_rational;

}} // namespaces

tommath_rational 后端通过 typedefboost::multiprecision::tom_rational 使用. 它作为boost::rational<tom_int> 的薄封装, 提供可直接替换原生 C++ 数字类型的有理数类型, 但精度无限.

与直接使用boost::rational<tom_int> 相比, 使用此类型的优势在于它启用了表达式模板, 大大减少了复杂表达式中创建的临时对象数量.

还有一些非成员函数:

tom_int numerator(const tom_rational&);
tom_int denominator(const tom_rational&);

它们返回该数的分子和分母.

使用此类型时你应当知道的事项:

  • 默认构造的tom_rational 的值为零(这是继承自 Boost.Rational 的行为).
  • 除以零会导致抛出std::overflow_error.
  • 若字符串无法解释为有效的有理数, 则从字符串转换会抛出std::runtime_error.
  • 不会对libtommath 的全局状态做任何更改, 因此此类型可以与其他libtommath 代码安全共存.
  • 已发现此类型的性能相当差 - 这需要进一步调查 - 但似乎 Boost.Rational 在这方面也需要一些改进.
示例: 
#include <boost/multiprecision/tommath.hpp>
#include <iostream>

int main()
{
   using namespace boost::multiprecision;

   tom_rational v = 1;

   // Do some arithmetic:
   for(unsigned i = 1; i <= 1000; ++i)
      v *= i;
   v /= 10;

   std::cout << v << std::endl; // prints 1000! / 10
   std::cout << numerator(v) << std::endl;
   std::cout << denominator(v) << std::endl;

   tom_rational w(2, 3); // Component wise constructor
   std::cout << w << std::endl; // prints 2/3

   return 0;
}
