mpfr_float_backend 

namespace boost{ namespace multiprecision{

template <unsigned Digits10>
class mpfr_float_backend;

typedef number<mpfr_float_backend<50> >    mpfr_float_50;
typedef number<mpfr_float_backend<100> >   mpfr_float_100;
typedef number<mpfr_float_backend<500> >   mpfr_float_500;
typedef number<mpfr_float_backend<1000> >  mpfr_float_1000;
typedef number<mpfr_float_backend<0> >     mpfr_float;

}} // namespaces

类模板mpfr_float_backend 满足Backend 类型的全部要求. 其成员与非成员函数刻意不作文档说明: 它们被视为可能变化的实现细节.

该类接受单个模板参数 -Digits10 - 即该类型应支持的十进制精度位数. 当此参数为零时, 精度可以在运行期通过number::default_precision 和number::precision 设置. 注意, 此类型不会以任何方式改变 GMP 或 MPFR 库的全局状态(例如它不会改变 mpfr_t 数据类型的默认精度), 因此可以放心地将此类型与使用 GMP 或 MPFR 的现有代码混合使用, 也可以混合使用不同精度mpfr_float_backend 的实例.

number_category<cpp_int<Args...> >::type 的类型是std::integral_constant<int, number_kind_floating_point>.

有关此类型的更多信息见教程.
