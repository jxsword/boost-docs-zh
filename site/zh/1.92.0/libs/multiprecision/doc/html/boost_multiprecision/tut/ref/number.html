说明 
enum expression_template_option { et_on = 1, et_off = 0 };

此枚举类型用于指定表达式模板是开启(et_on)还是关闭(et_off).

template <class Backend> struct expression_template_default
{ static const expression_template_option value = et_on; };

此特征类指定与特定 Backend 类型一起使用的默认表达式模板选项. 其默认值为et_on.

template <class Backend, expression_template_option ExpressionTemplates = expression_template_default<Backend>::value>
class number;

类number 有两个模板参数:

Backend

实际执行全部算术运算的后端.

ExpressionTemplates

一个布尔值: 当为et_on 时启用表达式模板; 当设置为et_off 时则禁用. 此参数的默认值通过特征类expression_template_default 计算, 其成员value 默认为et_on (除非该特征类已针对特定后端特化).

number();
number(see-below);
number& operator=(see-below);
number& assign(see-below);

类型number 可默认构造, 并且可以从下列来源拷贝构造和赋值:

  • 自身.
  • 作为某个算术运算符结果的表达式模板.
  • 任何基本(内建)算术类型, 只要转换不会造成损失(例如 float 到整数的转换).
  • Backend 可隐式构造或赋值的任何类型.
  • 对另一个number 的右值引用. 若后端也支持右值引用构造, 则构造时使用移动语义. 对于赋值, 只要参数是右值引用, 无论后端如何都始终支持移动语义.
  • 同一家族中的任何类型, 只要不涉及精度损失. 例如从int128_t 到int256_t, 或从cpp_dec_float_50 到cpp_dec_float_100.

类型number 可从下列来源显式构造:

  • 上述任何类型.
  • 一个std::string, 或任何可转换为const char* 的类型.
  • 任何算术类型(包括会造成有损转换的类型).
  • 同一家族中的任何类型, 包括会造成精度损失的转换.
  • Backend 可从之显式构造的任何类型.
  • 存在通用互转的任何类型对: 即整数到整数、整数到有理数、整数到浮点数、有理数到有理数、有理数到浮点数, 或浮点数到浮点数.

assign 成员函数可用于存在显式转换构造函数的任何类型. 它适用于显式赋值生成的临时对象代价高昂的场合, 例如:

mpfr_float_50    f50;
mpfr_float_100   f100;

f50 = static_cast<mpfr_float_50>(f100);  // explicit cast create a temporary
f50.assign(f100);                        // explicit call to assign create no temporary

此外, 若类型具有多个分量(例如有理数或复数类型), 则还有一个双参数构造函数:

number(arg1, arg2);

其中两个参数必须要么是算术类型, 要么是可转换为this 的两个分量的类型. 提供了右值转发重载, 因此后端若能利用右值, 则一个或两个参数都可以是右值引用, 它们会被移动进结果.

最后, 当类型具有可变精度时, 还有以下构造函数:

number(arg1, precision);
number(arg1, arg2, precision);

其中precision 是无符号值; 双参数版本用于标量类型和/或以特定精度拷贝构造, 三参数版本用于复数类型.

类似地,assign 有一个双参数重载, 第二个参数是精度.

这些运算符都采用其通常的算术含义.

这些运算符的参数是以下之一:

  • 另一个number<Backend, ExpressionTemplates>.
  • 派生自number<Backend> 的表达式模板.
  • 可隐式转换为number<Backend, ExpressionTemplates> 的任何类型, 包括类number 的其他实例.

对于左移和右移运算, 参数必须是值为正的基本(内建)整数类型(负值会导致抛出std::runtime_error).

operator convertible-to-bool-type()const;

返回一个不可名状的类型, 可用于布尔上下文(这允许number 用于任何布尔上下文 - if 语句、条件语句, 或作为逻辑运算符的参数 - 而无需类型number 可转换为类型bool).

此运算符还使得number 可与以下任何运算符一起使用:!,||,&& 和?:.

void swap(number& other);

交换*this 与other.

bool is_zero()const;

返回true (当*this 为零时), 否则返回false.

int sign()const;

当*this 为负时返回小于零的值, 当*this 为正时返回大于零的值, 当*this 为零时返回零.

std::string str(std::streamsize digits = 0, std::ios_base::fmtflags f = std::ios_base::fmtflags(0))const;

返回格式化为字符串的数, 至少有precision 位数字; 若提供了f, 则遵循其中的格式标志.

template <class T>
T convert_to()const;

template <class T>
explicit operator T ()const;

提供通用转换机制, 将*this 转换为类型T. 类型T 可以是任何算术类型. 特定的Backend 类型也可以选择支持其他类型.

static unsigned default_precision();
static void default_precision(unsigned digits10);
unsigned precision()const;
void precision(unsigned digits10);

仅当 Backend 模板参数支持运行期更改精度时, 这些函数才可用. 它们分别获取和设置默认精度以及*this 的精度.

int compare(const number<Backend, ExpressionTemplates>& o)const;
template <class V>
typename std::enable_if<std::is_convertible<V, number<Backend, ExpressionTemplates>::value >, int>::type
   compare(const V& other)const;

返回:

  • 小于 0 的值, 对应情况*this < other
  • 大于 0 的值, 对应情况*this > other

  • 零, 对应情况*this == other 

    value_type real()const;
value_type imag()const;

这两个函数分别返回实部和虚部. 若该数不是复数类型, 则虚部始终为零.

template <class T>
void real(const T& val);
template <class T>
void imag(const T& val);

这两个函数分别设置该数的实部和虚部. 若该数不是复数类型, 则设置实部等价于赋值, 而尝试设置虚部会导致编译期错误.

Backend& backend();
const Backend& backend()const;

返回*this 所使用的底层后端实例.

  • number 对其有隐式构造函数的任何类型 - 例如基本(内建)算术类型.

这些运算符的返回类型是以下之一:

  • 一个不可名状的类型 表达式模板类型 (当ExpressionTemplates 为true 时).
  • 当number<Backend, et_off> 为ExpressionTemplates 时, 为类型false.
  • 若运算符是比较运算符, 则为类型bool.

最后注意, 左移和右移运算的第二个参数必须是基本(内建)整数类型, 且参数必须为正(负参数会导致抛出std::runtime_error).

swap 
template <class Backend, ExpressionTemplates>
void swap(number<Backend, ExpressionTemplates>& a, number<Backend, ExpressionTemplates>& b);

交换a 和b.

这些运算符为number 类型及其派生的表达式模板提供格式化输入输出操作.

实际的字符串转换由后端类型实现. 不过, 本库提供的后端支持全部 iostream 格式化标志、字段宽度和精度设置.

此外, 还提供了 C++11 的to_string 函数, 以便在泛型代码中使用:

template <class Backend, expression_template_option ExpressionTemplates>

这是一个小数点后精度为 6 位的字符串, 与std::to_string 的行为一致. 注意, 这是一种定点精度表示, 因此可能返回非常长的字符串.

产生更高精度结果的算术运算 
template <class ResultType, class Source1 class Source2>
ResultType& add(ResultType& result, const Source1& a, const Source2& b);

template <class ResultType, class Source1 class Source2>
ResultType& subtract(ResultType& result, const Source1& a, const Source2& b);

template <class ResultType, class Source1 class Source2>
ResultType& multiply(ResultType& result, const Source1& a, const Source2& b);

这些函数将所指名的运算符作用于参数a 和b 并把结果存入result 中, 返回result. 在所有情况下, 它们的行为都表现得"好像"参数a 和b 先被提升为类型ResultType 再应用该运算符, 尽管特定后端完全可能通过优化避免这一步.

类型ResultType 必须是类number 的实例, 而类型Source1 和Source2 可以是类number 的实例, 也可以是原生整数类型. 后者是一种优化, 允许对原生整数类型执行算术运算并产生扩展精度的结果.

特征类支持 
template <class T>
struct component_type;

若这是一个具有多个分量的类型(例如有理数或复数类型), 则此特征有一个成员type, 即这些分量的类型.

template <class T>
struct number_category;

一个继承自std::integral_constant<int, N> 的特征类, 其中N 是枚举值number_kind_integer,number_kind_floating_point,number_kind_rational,number_kind_fixed_point,number_kind_unknown 之一. 此特征类针对任何具有std::numeric_limits 支持的类型以及本库中的类进行了特化: 这意味着它可以用于既要支持多精度类型、又要支持基本(内建)算术类型的泛型代码.

template <class T>
struct is_number;

一个特征类: 若 T 是std::integral_constant<bool, true> 的实例则继承自number<>, 否则继承自std::integral_constant<bool, false>.

template <class T>
struct is_number_expression;

一个特征类: 若 T 是派生自std::integral_constant<bool, true> 的表达式模板类型则继承自number<>, 否则继承自std::integral_constant<bool, false>.

整数函数

除了可用于本库的类型之外, 这些函数还针对基本(内建)整数类型进行了重载(若你包含<boost/multiprecision/integer.hpp>). 此外, 当与定点精度类型(无论是基本(内建)整数还是多精度类型)一起使用时, 若算法需要, 这些函数会在内部提升到更宽的类型. 针对基本(内建)整数类型重载的版本返回该整数类型而不是表达式模板.

unmentionable-expression-template-type    gcd(const number-or-expression-template-type& a, const number-or-expression-template-type& b);

返回最大整数x (可同时整除a 和b).

unmentionable-expression-template-type    lcm(const number-or-expression-template-type& a, const number-or-expression-template-type& b);

返回最小整数x (可同时被a 和b 整除).

unmentionable-expression-template-type    pow(const number-or-expression-template-type& b, unsigned p);

返回bp (以表达式模板的形式). 注意, 此函数应极其谨慎地使用, 因为结果可能大到需要"实际上无限"的时间来计算, 或者干脆把主机的内存耗尽. 这是此类中唯一没有针对基本(内建)整数类型重载的函数; 此外, 将它与定点精度的cpp_int 一起使用恐怕也不是个好主意.

unmentionable-expression-template-type    powm(const number-or-expression-template-type& b, const number-or-expression-template-type& p, const number-or-expression-template-type& m);

返回bp mod m (以表达式模板的形式). 定点精度类型会在内部提升以确保精度.

unmentionable-expression-template-type    sqrt(const number-or-expression-template-type& a);

返回最大整数x, 使其满足x * x < a.
