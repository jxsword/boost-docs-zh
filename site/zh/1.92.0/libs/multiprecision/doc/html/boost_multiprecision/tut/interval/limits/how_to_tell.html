如何从下列内容判断数字的类型:std::numeric_limits

根据上述信息可以看出, 可以依据std::numeric_limits 中存储的信息区分不同种类的数字. 除此之外, 本库还提供了特征类number_category.

整数类型

对整数类型 T, 以下所有条件都成立:

std::numeric_limits<T>::is_specialized == true
std::numeric_limits<T>::is_integer == true
std::numeric_limits<T>::is_exact == true
std::numeric_limits<T>::min_exponent == 0
std::numeric_limits<T>::max_exponent == 0
std::numeric_limits<T>::min_exponent10 == 0
std::numeric_limits<T>::max_exponent10 == 0

此外, 若以下条件成立, 则该类型是有符号的:

std::numeric_limits<T>::is_signed == true

若类型是任意精度的, 则:

std::numeric_limits<T>::is_bounded == false

否则该类型是有界的, 并从以下返回非零值:

std::numeric_limits<T>::max()

并且具有:

std::numeric_limits<T>::is_modulo == true

若该类型在溢出时实现回绕算术.

有理数类型

有理数类型与整数类似, 但有以下区别:

std::numeric_limits<T>::is_integer == false
定点精度类型

似乎没有办法把它们与有理数类型区分开, 除非它们设置了:

std::numeric_limits<T>::is_exact == false

这是因为这些类型本质上是分母固定的有理数类型.

浮点数类型

对浮点数类型 T, 以下所有条件都成立:

std::numeric_limits<T>::is_specialized == true
std::numeric_limits<T>::is_integer == false
std::numeric_limits<T>::is_exact == false
std::numeric_limits<T>::min_exponent != 0
std::numeric_limits<T>::max_exponent != 0
std::numeric_limits<T>::min_exponent10 != 0
std::numeric_limits<T>::max_exponent10 != 0

此外, 若以下条件成立, 则该类型是有符号的:

std::numeric_limits<T>::is_signed == true

并且根据以下值, 该类型可以是十进制或二进制的:

std::numeric_limits<T>::radix

一般来说, 不存在任意精度浮点数类型, 因此:

std::numeric_limits<T>::is_bounded == false
精确浮点数类型

精确浮点数类型是一个域, 由一个任意精度整数乘以指数缩放构成. 这类类型没有除法运算符, 除以下几点外与浮点数类型相同:

std::numeric_limits<T>::is_exact == true
复数

出于历史原因, 复数不特化std::numeric_limits, 你必须改为检查std::numeric_limits<typename T::value_type>.
