数值极限

std::numeric_limits<> 常量
std::numeric_limits<> 函数
32 位平台的数值极限
如何从下列内容判断数字的类型:std::numeric_limits

Boost.Multiprecision 尽力为所有类型实现std::numeric_limits(在可能且有意义的范围内), 因为 Boost.Math 的经验表明这有助于可移植性.

C++ 标准库 在 18.3.2 节定义了std::numeric_limits.

它又引用了 C 标准SC22/WG11 N507 DRAFT INTERNATIONAL ISO/IEC STANDARD WD 10967-1 (信息技术 与语言无关的算术 第 1 部分: 整数与浮点算术).

该 C 标准又引用了

IEEE754 二进制浮点算术 IEEE 标准

std::numeric_limits 的有用概述可在C++ 参考 找到.

所选后端往往决定了std::numeric_limits 的可用程度.
