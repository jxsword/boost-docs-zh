Visual C++ 调试器可视化工具

重要

与近期的 Visual C++ 版本相比, 本节内容严重过时.

坦白说, 调试 multiprecision 数字很困难 - 仅仅因为我们无法轻松查看这些数的值. Visual C++ 以"可视化工具"的形式提供了部分解决方案, 它们为复杂数据结构提供改进的视图; 这些可视化工具需要添加到[Visualizer] 一节(文件autoexp.dat, 位于 Visual Studio 安装目录Common7/Packages/Debugger 下). 可视化工具的实际代码在沙盒中此处 - 只需把代码剪切并粘贴到你的autoexp.dat 文件中.

注释

这些可视化工具只在 VC10 上测试过; 鉴于有缺陷的可视化工具可能让你的 Visual C++ 调试器崩溃, 使用前请务必备份autoexp.dat 文件!!
