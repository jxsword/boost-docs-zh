cpp_rational

#include <boost/multiprecision/cpp_int.hpp> 

namespace boost{ namespace multiprecision{

typedef rational_adaptor<cpp_int_backend<> >    cpp_rational_backend;

typedef number<cpp_rational_backend>         cpp_rational;

}} // namespaces

cpp_rational_backend 类型通过 typedefboost::multiprecision::cpp_rational 使用. 它提供的有理数类型可直接替换原生 C++ 数字类型, 但精度无限.

除了可以从算术类型和字符串类型进行常规转换之外,cpp_rational 的实例还可以从类型cpp_int 拷贝构造和赋值.

还有一个双参数构造函数, 接受分子和分母: 二者类型均为cpp_int.

还有一些非成员函数:

cpp_int numerator(const cpp_rational&);
cpp_int denominator(const cpp_rational&);

它们返回该数的分子和分母.

使用此类型时你应当知道的事项:

  • 默认构造的cpp_rational 的值为零.
  • 除以零会导致抛出std::overflow_error.
  • 若字符串无法解释为有效的有理数, 则从字符串转换会抛出std::runtime_error.
示例: 
#include <boost/multiprecision/cpp_int.hpp>
#include <iostream>

int main()
{
   using namespace boost::multiprecision;

   cpp_rational v = 1;

   // Do some arithmetic:
   for(unsigned i = 1; i <= 1000; ++i)
      v *= i;
   v /= 10;

   std::cout << v << std::endl; // prints 1000! / 10
   std::cout << numerator(v) << std::endl;
   std::cout << denominator(v) << std::endl;

   cpp_rational w(2, 3);  // component wise constructor
   std::cout << w << std::endl; // prints 2/3
   return 0;
}
