cpp_dec_float

#include <boost/multiprecision/cpp_dec_float.hpp> 

namespace boost { namespace multiprecision {

template <unsigned Digits10, class ExponentType = std::int32_t, class Allocator = void>
class cpp_dec_float;

typedef number<cpp_dec_float<50> > cpp_dec_float_50;
typedef number<cpp_dec_float<100> > cpp_dec_float_100;

} } // namespaces

cpp_dec_float 后端与number 配合使用: 它充当一个纯 C++(仅头文件且无依赖)的浮点数类型, 可直接替换原生 C++ 浮点数类型, 但精度高得多.

类型cpp_dec_float 可以定点精度使用(只需指定非零的Digits10 模板参数). 类型定义cpp_dec_float_50 和cpp_dec_float_100 分别提供 50 位和 100 位十进制精度的算术类型. 此外, 你可以指定用于指数的整数类型; 默认为 32 位整数类型, 对绝大多数用例而言足够大, 但若你需要真正巨大的指数范围, 也可以指定更大的类型如long long. 无论如何, ExponentType 必须是至少 2 字节 16 位宽的基本(内建)有符号整数类型.

通常cpp_dec_float 不分配内存: 其数字所需的全部空间都直接在类内分配. 因此应当注意不要以过高的位数使用该类, 否则栈空间需求可能失控. 若这构成问题, 则把分配器作为最后一个模板参数传入会使cpp_dec_float 动态分配所需内存: 这会显著减小cpp_dec_float 的大小, 并提高可行位数上限, 但以性能为代价. 不过请记住, 随着位数增长, 算术运算的开销会迅速变得非常 高: 目前的实现确实没有针对大位数进行优化或设计.

此类型有完整的标准库和std::numeric_limits 支持.

使用此类型时你应当知道的事项:

  • 默认构造的cpp_dec_float 的值为零.
  • 此类型的基数为 10. 因此它的行为可能与 2 进制类型有细微差别.
  • 此类型在模板参数指定的位数之外还有若干内部保护位. 通常这些对用户不可见.
  • 此类型同时支持无穷大和 NaN. 只要结果会溢出就会生成无穷大, 任何数学上未定义的运算都会生成 NaN.
  • 此类型有std::numeric_limits 特化.
  • 任何基于此类型实例化的number 都可以转换为基于此类型实例化的其他number - 例如你可以从number<cpp_dec_float<50> > 转换为number<cpp_dec_float<SomeOtherValue> >. 收窄转换是截断式的, 且是explicit.
  • 若字符串无法解释为有效的浮点数, 则从字符串转换会抛出std::runtime_error.
  • cpp_dec_float 的实际精度总是略高于模板参数中指定的位数; 具体高多少属于实现细节, 但总是至少多 8 位十进制数字.
  • 涉及cpp_dec_float 的运算总是截断式的. 不过请注意, 由于实际上存在保护位, 这在大多数用例中并不会对精度产生实质影响.
cpp_dec_float 示例: 
#include <boost/multiprecision/cpp_dec_float.hpp>
#include <boost/math/special_functions/gamma.hpp>
#include <iostream>

int main()
{
   using namespace boost::multiprecision;

   // Operations at fixed precision and full numeric_limits support:
   cpp_dec_float_100 b = 2;
   std::cout << std::numeric_limits<cpp_dec_float_100>::digits << std::endl;
   // Note that digits10 is the same as digits, since we're base 10! :
   std::cout << std::numeric_limits<cpp_dec_float_100>::digits10 << std::endl;
   // We can use any C++ std lib function, lets print all the digits as well:
   std::cout << std::setprecision(std::numeric_limits<cpp_dec_float_100>::max_digits10)
      << log(b) << std::endl; // print log(2)
   // We can also use any function from Boost.Math:
   std::cout << boost::math::tgamma(b) << std::endl;
   // These even work when the argument is an expression template:
   std::cout << boost::math::tgamma(b * b) << std::endl;
   // And since we have an extended exponent range we can generate some really large 
   // numbers here (4.0238726007709377354370243e+2564):
   std::cout << boost::math::tgamma(cpp_dec_float_100(1000)) << std::endl;
   return 0;
}
