位运算

在此示例中, 我们将展示如何操作整数中的单个位. 我们先从一个经常需要的计算开始:2n - 1, 显然可以这样实现:

using boost::multiprecision::cpp_int;

cpp_int b1(unsigned n)
{
   cpp_int r(1);
   return (r << n) - 1;
}

调用:

std::cout << std::hex << std::showbase << b1(200) << std::endl;

如预期得到:

0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF

不过, 我们同样可以只设置结果中的第 n 位, 就像这样:

cpp_int b2(unsigned n)
{
   cpp_int r(0);
   return --bit_set(r, n);
}

注意bit_set 函数如何在其参数中设置指定的位, 然后返回对结果的引用 - 我们随后可以简单地对其减一. 调用b2 的结果与调用b1 相同.

我们同样可以测试位: 例如, 从b2 返回的结果的第 n 位不应被置位, 除非我们先做递增:

BOOST_MP_ASSERT(!bit_test(b1(200), 200));     // OK
BOOST_MP_ASSERT(bit_test(++b1(200), 200));    // OK

当然, 若在递增后翻转第 n 位, 则应回到零:

BOOST_MP_ASSERT(!bit_flip(++b1(200), 200));   // OK
