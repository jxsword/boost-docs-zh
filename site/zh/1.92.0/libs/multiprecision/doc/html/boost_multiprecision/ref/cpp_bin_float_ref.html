cpp_bin_float 

namespace boost{ namespace multiprecision{

enum digit_base_type
{
   digit_base_2 = 2,
   digit_base_10 = 10
};

template <unsigned Digits, digit_base_type base = digit_base_10, class Allocator = void, class Exponent = int, ExponentMin = 0, ExponentMax = 0>
class cpp_bin_float;

typedef number<cpp_bin_float<50> > cpp_bin_float_50;
typedef number<cpp_bin_float<100> > cpp_bin_float_100;

typedef number<backends::cpp_bin_float<24, backends::digit_base_2, void, std::int16_t, -126, 127>, et_off>         cpp_bin_float_single;
typedef number<backends::cpp_bin_float<53, backends::digit_base_2, void, std::int16_t, -1022, 1023>, et_off>       cpp_bin_float_double;
typedef number<backends::cpp_bin_float<64, backends::digit_base_2, void, std::int16_t, -16382, 16383>, et_off>     cpp_bin_float_double_extended;
typedef number<backends::cpp_bin_float<113, backends::digit_base_2, void, std::int16_t, -16382, 16383>, et_off>    cpp_bin_float_quad;
typedef number<backends::cpp_bin_float<237, backends::digit_base_2, void, std::int32_t, -262142, 262143>, et_off>  cpp_bin_float_oct;

}} // namespaces

类模板cpp_bin_float 满足Backend 类型的全部要求. 其成员与非成员函数刻意不作文档说明: 它们被视为可能变化的实现细节.

该类接受六个模板参数:

Digits

该类型应支持的精度位数. 通常以 10 进制位数表示, 但可通过第二个模板参数更改.

base

一个枚举值(digit_base_10 或digit_base_2 之一), 用于指示Digits 是 10 进制还是 2 进制

Allocator

所使用的分配器: 默认为类型void, 表示所有存储都在类内部, 不执行动态分配; 但若动态分配更合理, 也可以设置为标准库分配器.

Exponent

用作指数类型的有符号整数类型 - 默认为int.

ExponentMin

允许的最小(最负)指数, 默认值为零, 意为"在类型的限制与内部要求所允许的前提下定义得尽可能小".

ExponentMax

允许的最大(最正)指数, 默认值为零, 意为"在类型的限制与内部要求所允许的前提下定义得尽可能大".

number_category<cpp_bin_float<Args...> >::type 的类型是std::integral_constant<int, number_kind_floating_point>.

有关此类型的更多信息见教程.

实现说明

在内部, N 位的cpp_bin_float 表示为一个 N 位无符号整数加上指数和符号. 整数部分被规范化, 使其最高有效位始终为 1. 小数点被假定紧跟在整数部分的最高有效位之后. 特殊值零、无穷大和 NaN 的整数部分都置为零, 指数则取最大允许指数之上的 3 个特殊值之一.

乘法很简单: 将两个 N 位整数尾数相乘得到一个 2N 位数, 然后舍入并调整符号与指数.

加法和减法的过程类似 - 若两个值的指数存在重叠, 则将较大的值左移, 得到一个位数在 N 到 2N 之间的数, 然后执行整数加法或减法、舍入并调整指数.

除法过程如下: 先将分子乘以 2 的某个幂, 使整数除法产生 N 位或 N+1 位的结果外加一个余数. 若得到 N 位结果, 则用两倍余数与分母的比较来确定舍入方向. 否则结果中会多出一个额外位, 可用它来确定舍入(此时只有当余数为零且额外位为 1 时才会出现平局).

平方根以与除法类似的方式使用整数平方根.

十进制字符串到二进制的转换过程如下: 首先解析数字, 得到一个整数乘以一个十进制指数. 注意, 一旦解析的位数已达可能影响结果的数目, 我们就停止解析 - 这可以避免在输入位数非常多时整数部分增长过大. 在这一步, 若十进制指数为正, 则结果是一个整数, 原则上只需乘以 10^N 即可得到精确的整数结果. 但实践中这可能产生非常大的整数. 当指数为负时, 我们还需要能够除以 10^N. 因此, 10^N 值的计算以及乘法或除法都使用有限精度整数运算完成, 外加一个指数和一个累计误差记录. 计算结束时, 我们要么能够毫无歧义地舍入, 要么误差大到无法判断舍入方向. 在后一种情况下, 我们直接提高精度重试, 直到得到可以无歧义舍入的结果.

二进制到十进制的转换与上述过程非常相似, 我们的目标是计算mantissa * 2^shift * 10^E, 其中E 是十进制指数,shift 的取值使得在假定结果要打印 N 位数字时, 结果是一个 N 位整数. 与之前一样, 我们使用有限精度算术计算结果, 并在必要时提高精度, 直到结果可以无歧义地正确舍入. 此外, 十进制指数的初始计算可能偏差 1, 在这种情况下我们还必须对其进行修正并循环.
