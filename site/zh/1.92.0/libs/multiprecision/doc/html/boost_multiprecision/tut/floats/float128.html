float128

#include <boost/multiprecision/float128.hpp> 

namespace boost{ namespace multiprecision{

class float128_backend;

typedef number<float128_backend, et_off>    float128;

}} // namespaces

float128 数字类型是围绕 GCC 的__float128 或 Intel 的_Quad 数据类型的一个非常薄的封装, 它提供的实数类型可直接替换原生 C++ 浮点数类型, 但具有 113 位尾数, 并与 FORTRAN 的 128 位 QUAD 实数兼容.

所有常用的标准库和std::numeric_limits 支持均可用, 性能应当与底层原生类型相当: 例如 GCC 的__float128 和boost::multiprecision::float128 的 LINPACK 基准测试都达到了 5.6 MFLOPS[3].

除了可以从算术类型和字符串类型进行常规转换之外,float128 的实例还可以从 GCC 的__float128 和 Intel 的_Quad 数据类型拷贝构造和赋值.

也可以通过__float128 的成员函数_Quad 访问底层的data() 或float128_backend 类型.

使用此类型时你应当知道的事项:

  • 默认构造的float128 的值为零.
  • 此后端支持右值引用并具有移动感知能力, 使得基于此后端实例化的number 也具有移动感知能力.
  • 此类型完全constexpr 感知 - 从 C++14 起支持基本的 constexpr 算术以及比较; 此外, 函数fabs,abs,fpclassify,isnormal,isfinite,isinf 和isnan 也受支持(若编译器实现了 C++20 的std::is_constant_evaluated(), 或者编译器为 GCC).
  • 当使用 Intel C++ 编译器编译并以_Quad 作为底层类型时, 无法把此类型的对象与字符串往返转换并得到完全相同的值: 这是我们代码目前的限制. 以__float128 作为底层类型时则可以往返转换(GCC 和 Intel 均可).
  • 若字符串无法解释为有效的浮点数, 则从字符串转换会抛出std::runtime_error.
  • 除以零会产生无穷大.
  • 类型float128 可用作字面量类型(支持 constexpr).
  • 在 GCC 下从 C++14 起, 类型float128 可用于完整的constexpr 算术. 函数abs,fabs,fpclassify,isnan,isinf,isfinite 和isnormal 也是constexpr 的, 但超越函数不是.
  • 使用 Intel 编译器时, 底层类型默认为__float128 (若可用), 否则为_Quad. 你可以通过定义BOOST_MP_USE_FLOAT128 或BOOST_MP_USE_QUAD 来覆盖默认值.
  • 当底层类型为 Intel 的_Quad 类型时, 代码必须使用编译器选项-Qoption,cpp,--extended_float_type 编译.
  • 使用gcc 编译时, 需要用标志--std=gnu++11/14/17, 因为后缀 'Q' 是 GNU 扩展. 使用标志--std=c++11/14/17 时编译会失败, 除非同时使用-fext-numeric-literals.
  • 你需要用链接命令libquadmath.dll 链接到-lquadmath, 并确保链接器能看到该 DLL. 若你使用 B2/bjam 构建系统, 则需要命令<linkflags>-lQUADMATH 和<linkflags>-L"path/to/lib".
  • std::numeric_limits<float128> 显示的值极其接近但不完全等于 等效精度和范围的 multiprecision 类型std::numeric_limits<cpp_bin_float_quad> 与std::numeric_limits<cpp_dec_float_quad> 的值.

类型 float128 以 128 位精度提供运算, 采用四精度浮点格式, 并有完整的std::numeric_limits 支持:

float128 b = 2;

有 15 位(带偏置)二进制指数和 113 位有效数字精度

std::cout << std::numeric_limits<float128>::digits << std::endl;

即 33 位十进制:

std::cout << std::numeric_limits<float128>::digits10 << std::endl;

我们可以使用任何 C++ 标准库函数, 因此让我们把最多 36 个可能有意义的数字以及末尾的零都显示出来:

 std::cout.setf(std::ios_base::showpoint); // Include any trailing zeros.
std::cout << std::setprecision(std::numeric_limits<float128>::max_digits10)
   << log(b) << std::endl; // Shows log(2) = 0.693147180559945309417232121458176575

我们也可以使用 Boost.Math 的任何函数, 例如"真 gamma"函数tgamma:

std::cout << boost::math::tgamma(b) << std::endl;

由于指数范围很大, 我们可以在这里生成一些真正巨大的数 (4.02387260077093773543702433923004111e+2564):

std::cout << boost::math::tgamma(float128(1000)) << std::endl;

我们可以使用 GCC 或 Intel 的原生类型声明常量, 以及带 Q 后缀的字面量, 并且如有需要可以把它们声明为constexpr:

// std::numeric_limits<float128>::max_digits10 = 36
constexpr float128 pi = 3.14159265358979323846264338327950288Q;
std::cout.precision(std::numeric_limits<float128>::max_digits10);
std::cout << "pi = " << pi << std::endl; //pi = 3.14159265358979323846264338327950280
