圆的面积

泛型数值编程使用模板, 让同一段代码适用于不同的浮点数类型和函数. 考虑半径为 r 的圆的面积 a, 由下式给出

a = π * r2

在泛型编程中, 可以使用 Boost.Math 的常量 π 计算圆的面积, 如下所示:

#include <boost/math/constants/constants.hpp>

template<typename T>
inline T area_of_a_circle(T r)
{
   using boost::math::constants::pi;
   return pi<T>() * r * r;
}

可以把area_of_a_circle() 与内建浮点数类型以及来自 Boost.Multiprecision 的浮点数类型一起使用. 特别地, 考虑一个具有 4 字节单精度 float、8 字节双精度 double 以及来自 Boost.Multiprecision 的具有 50 位十进制精度的cpp_dec_float_50 数据类型的系统.

我们可以用下面的程序计算并打印半径为 123/100 的圆的近似面积, 覆盖float,double 和cpp_dec_float_50 (为何选 123/100 而不是 1.23 见下一节).

#include <iostream>
#include <iomanip>
#include <boost/multiprecision/cpp_dec_float.hpp>

using boost::multiprecision::cpp_dec_float_50;

int main(int, char**)
{
   const float r_f(float(123) / 100);
   const float a_f = area_of_a_circle(r_f);

   const double r_d(double(123) / 100);
   const double a_d = area_of_a_circle(r_d);

   const cpp_dec_float_50 r_mp(cpp_dec_float_50(123) / 100);
   const cpp_dec_float_50 a_mp = area_of_a_circle(r_mp);

   // 4.75292
   std::cout
      << std::setprecision(std::numeric_limits<float>::digits10)
      << a_f
      << std::endl;

   // 4.752915525616
   std::cout
      << std::setprecision(std::numeric_limits<double>::digits10)
      << a_d
      << std::endl;

   // 4.7529155256159981904701331745635599135018975843146
   std::cout
      << std::setprecision(std::numeric_limits<cpp_dec_float_50>::digits10)
      << a_mp
      << std::endl;
}

在后面的示例中, 我们将看到如何在泛型代码中调用标准库和 Boost.Math 函数. 我们还将展示如何处理作为表达式模板而非数字类型的模板参数.

但首先给出一些警告: multiprecision 类型与基本(内建)类型有细微但重要的差别.
