内部支持代码

有一些特征类(traits classes)是编写新后端的作者应当了解的:

namespace boost{ namespace multiprecision{ namespace detail{

template<typename From, typename To>
struct is_explicitly_convertible;

}}}

继承自std::integral_constant<bool,true> (若类型From 具有来自To 的显式转换).

template <class From, class To>
struct is_lossy_conversion
{
   static const bool value = see below;
};

成员value 为 true (当从From 到To 的转换会造成精度损失时), 否则为false.

此特征的默认版本只检查转换的类别(例如从浮点数类型到整数类型)是否天生有损. 注意, 若类型From 或To 中任一个属于未知的数字类别(因为number_category 未针对该类型特化), 则此特征将为true.

template<typename From, typename To>
struct is_restricted_conversion
{
   static const bool value = see below;
};

成员value 为true (当From 只能显式转换为To 而不能隐式转换时), 或当is_lossy_conversion<From, To>::value 为true 时. 否则为false.

注意, 虽然此特征是哪些构造函数被标记为explicit (位于类number 中)的最终裁决者, 但后端类型的作者通常应特化上述特征之一, 而不是直接特化此特征.

template <class T>
is_signed_number;
template <class T>
is_unsigned_number;

这两个特征继承自std::integral_constant<bool, true> 或std::integral_constant<bool, false> 之一; 默认情况下类型被假定是有符号的, 除非is_unsigned_number 已针对该类型特化.
