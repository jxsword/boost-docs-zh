rational_adaptor 

namespace boost{ namespace multiprecision{

template <class IntBackend>
class rational_adpater;

}}

类模板rational_adaptor 是number 的一个后端, 它可以把任何现有整数后端转换为有理数后端.

例如, 给定整数后端类型MyIntegerBackend, 用法类似于:

typedef number<MyIntegerBackend>                    MyInt;
typedef number<rational_adaptor<MyIntegerBackend> > MyRational;

MyRational r = 2;
r /= 3;
MyInt i = numerator(r);
assert(i == 2);
