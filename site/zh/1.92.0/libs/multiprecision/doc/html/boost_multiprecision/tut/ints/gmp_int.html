gmp_int

#include <boost/multiprecision/gmp.hpp> 

namespace boost{ namespace multiprecision{

class gmp_int;

typedef number<gmp_int >         mpz_int;

}} // namespaces

gmp_int 后端通过 typedefboost::multiprecision::mpz_int 使用. 它是围绕GMP mpz_t 的薄封装, 提供可直接替换原生 C++ 整数类型的整数类型, 但精度无限.

除了可以从算术类型和字符串类型进行常规转换之外, 类型mpz_int 还可以从下列来源拷贝构造和赋值:

  • GMP 原生类型:mpf_t,mpz_t,mpq_t.
  • number<T> 中围绕这些类型的封装实例:number<gmp_float<N> >,number<gmp_rational>.

也可以通过mpz_t 的成员函数data() 访问底层的gmp_int.

使用此类型时你应当知道的事项:

  • 不会对 GMP 库的全局设置做任何更改 - 因此可以放心地把此类型与使用GMP 的现有代码混用.
  • 默认构造的gmp_int 的值为零(这是 GMP 的默认行为).
  • 此类型的格式化 IO 不支持负值的八进制或十六进制表示; 因此当参数为负且设置了标志std::ios_base::oct 或std::ios_base::hex 之一时, 对此类型执行格式化输出会抛出std::runtime_error.
  • 若字符串无法解释为有效整数, 则从字符串转换会抛出std::runtime_error.
  • 除以零会导致抛出std::overflow_error.
  • 虽然此类型是对GMP 的封装, 但它与MPIR 配合得同样好. 实际上, 在 Win32 上推荐使用MPIR.
  • 此后端支持右值引用并具有移动感知能力, 使得基于此后端实例化的number 也具有移动感知能力.
示例: 
#include <boost/multiprecision/gmp.hpp>
#include <iostream>

int main()
{
   using namespace boost::multiprecision;

   mpz_int v = 1;

   // Do some arithmetic:
   for(unsigned i = 1; i <= 1000; ++i)
      v *= i;

   std::cout << v << std::endl; // prints 1000!

   // Access the underlying representation:
   mpz_t z;
   mpz_init(z);
   mpz_set(z, v.backend().data());
   mpz_clear(z);
   return 0;
}
