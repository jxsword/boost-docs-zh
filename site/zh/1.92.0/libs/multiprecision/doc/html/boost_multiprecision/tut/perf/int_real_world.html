有趣的是, 表达式模板在这里几乎没有影响 - 或许因为本例中涉及的实际表达式相对简单 - 因此乘法和除法所花的时间趋于主导. GMP 和 tommath 快得多的时间归功于它们好得多的模幂算法 (GMP 的约快 5 倍). 这是 cpp_int 在未来版本中需要解决的问题.
