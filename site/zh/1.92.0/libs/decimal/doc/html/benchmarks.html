基准测试

本节介绍一系列已运行过的性能基准测试 (将本库与标准库进行比较), 以及在需要时如何运行你自己的基准测试.

比值列中的数值是指运行特定操作相比使用 double 的同一操作要多花多少倍的时间.

在几乎所有平台上, 二进制浮点数学都有硬件支持, 所以我们是在比较硬件与软件运行时间; Decimal 会更慢
Intel 与 GCC 类型的结果都来自非常接近但不完全相同的基准测试例程, 因为它们是用 C 而不是 C++ 编写的. 我们假定它们足够接近, 且 C 与 C++ 编译器之间的差异足够小, 可以进行公平比较

如何运行基准测试

要自行运行基准测试, 请进入 test 文件夹, 并在运行测试时定义 BOOST_DECIMAL_RUN_BENCHMARKS. 在 Linux 上使用 b2 的示例: ../../../b2 cxxstd=20 toolset=gcc-13 define=BOOST_DECIMAL_RUN_BENCHMARKS benchmarks -a release, 或 ../../../b2 cxxstd=20 toolset=gcc-13 define=BOOST_DECIMAL_RUN_BENCHMARKS=1,BOOST_DECIMAL_BENCHMARK_CHARCONV=1 benchmarks -a release 以同时运行 <charconv> 基准测试

要运行 GCC 基准测试, 可以使用以下命令: gcc benchmark_libdfp.c -O3 -std=c17, 然后是: ./a.out

要运行 Intel 基准测试, 你需要 Intel 编译器 和 库. 然后可以使用以下命令: icx benchmark_libbid.c -O3 $PATH_TO_LIBBID/libbid.a -std=c17, 然后是: ./a.out. 你也可以用 gcc 代替 icx. 在 Windows 上命令类似: cl benchmark_libbid.c /O2 /std:c17 ..\PATH_TO_LIBBID\cl000libbid.lib, 然后是: .\benchmark_libbid.exe.

Intel 基准测试只能在它们支持的一种架构上运行: IA-32、IA-64 与 Intel x64

测试方法

比较

比较操作的基准测试生成一个包含 20,000,000 个元素的随机向量, 并执行 >、>=、<、<=、== 和 != 运算, 操作对象为 vec[i] and vec[i + 1]. 重复 5 次以生成稳定的结果.

基本数学运算

这些运算的基准测试生成一个包含 2000 万个元素的随机向量, 并执行 +、-、*、/ 运算, 操作对象为 vec[i] and vec[i + 1]. 重复五次以生成稳定的结果.

<charconv>

精确解析与序列化数字是十进制浮点类型的关键特性之一, 因此我们必须比较 <charconv> 的性能. 以下所有比较结果都是针对 2000 万次转换与 STL 提供的 <charconv> 进行对比. 由于 <charconv> 对每种类型都是用软件完全实现的, 内置 float 和 double 与 decimal32_t 和 decimal64_t 之间的性能差距明显小于上文基本运算中看到的硬件与软件性能差距 (或者说十进制性能更好).

要自行运行这些基准测试, 你需要一个完整实现 <charconv> 的编译器, 并在 C++17 或更高版本下运行基准测试. 撰写本文时, 仅限于:

  • GCC 11 或更新版本

  • MSVC 19.24 或更新版本

如果你的编译器不提供功能完整的 <charconv>, 或者语言标准设置为 C++14, 这些基准测试会自动禁用.
