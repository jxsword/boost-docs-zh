<cmath> 支持

Decimal 为 <cmath> 中的所有函数提供了重载, 并且它们具有与内置浮点类型相同的处理方式. 与内置浮点类型 (需要 C++23 或 26) 不同, 它们在 C++14 下也全部是 constexpr. 此外, 所有函数都标记为 noexcept.

所有这些函数都受 舍入模式 中所述的全局舍入模式以及 DEC_FLT_EVAL_METHOD (来自 求值方法) 的影响.

非标准函数

以下是便捷函数, 或是 IEEE 754-2019 规定十进制浮点类型所要求的函数.

issignaling

template <typename Decimal>
constexpr bool issignaling(Decimal x) noexcept;

效果: 若 x 是 sNaN 则返回 true, 否则返回 false. 根据 IEEE 754 第 5.7.2 节, 即使 x 是 sNaN, 该函数也不发出信号.

read_payload

template <typename Decimal>
constexpr auto read_payload(Decimal x) noexcept
    -> typename T::significand_type;

效果: 若 x 是 qNaN 或 sNaN, 则返回该 NaN 的载荷, 否则返回 0.

该函数允许返回由函数 nan 或 snan 设置的 NaN 载荷.

samequantum

#include <boost/decimal/cmath.hpp>

namespace boost {
namespace decimal {

template <typename Decimal>
constexpr bool samequantum(Decimal x, Decimal y) noexcept;

constexpr bool samequantumd32(decimal32_t x, decimal32_t y) noexcept;
constexpr bool samequantumd64(decimal64_t x, decimal64_t y) noexcept;
constexpr bool samequantumd128(decimal128_t x, decimal128_t y) noexcept;

} // namespace decimal
} // namepsace boost

效果: 判断 x 与 y 的量子 (无偏) 指数是否相同.

若 x 与 y 都是 NaN 或无穷大, 则它们具有相同的量子指数.

若恰好一个操作数是无穷大或恰好一个操作数是 NaN, 则它们不具有相同的量子指数.

quantexp

效果: 若 x 是有限值, 则返回其量子指数.

否则, 返回 INT_MIN.

quantized

#include <boost/decimal/cmath.hpp>

namespace boost {
namespace decimal {

template <typename Decimal>
constexpr Decimal quantized(Decimal x, Decimal y) noexcept;

constexpr decimal32_t quantized32(decimal32_t x, decimal32_t y) noexcept;
constexpr decimal64_t quantized64(decimal64_t x, decimal64_t y) noexcept;
constexpr decimal128_t quantized128(decimal128_t x, decimal128_t y) noexcept;

} // namespace decimal
} // namepsace boost

返回: 一个与 x 值相等 (除任何舍入外) 且符号相同的数, 其指数被设置为等于 y 的指数.

如果指数在增大, 则该值会按照当前舍入模式正确舍入;

如果结果与 x 的值不同, 则引发"不精确"浮点异常.

如果指数在减小, 且结果的尾数位数超过该类型所允许的位数, 则引发"无效"浮点异常, 结果为 sNaN.

如果一个或两个操作数为 NaN, 则结果为 sNaN.

否则, 如果只有一个操作数为无穷大, 则引发"无效"浮点异常, 结果为 sNaN.

如果两个操作数都是无穷大, 则结果为无穷大, 符号与 x 相同.

quantize 函数不会发出下溢信号.

decompose

#include <boost/decimal/cmath.hpp>

namespace boost {
namespace decimal {

template <typename Decimal>
struct decimal_components
{
    using significand_type = typename Decimal::significand_type;
    using biased_exponent_type = typename Decimal::biased_exponent_type;

    significand_type sig {};
    biased_exponent_type exp {};
    bool sign {};
};

template <typename Decimal>
constexpr auto decompose(const Decimal value) noexcept -> decimal_components<Decimal>

} // namespace decimal
} // namespace boost

该函数把输入的十进制值分解为一个包含尾数、指数与符号的结构体. 该函数完全不会修改存储的值, 因此它返回的尾数与指数是非规范化的, 即按它们存储时所在的群组返回. 关于规范化形式的进一步讨论参见 群组 页面.

frexp10

#include <boost/decimal/cmath.hpp>

namespace boost {
namespace decimal {

template <typename Decimal>
constexpr auto frexp10(Decimal num, int* expptr) noexcept;

} // namespace decimal
} // namepsace boost

该函数与 frexp 非常相似, 但返回尾数与 10 的整数次幂, 因为本类型的 FLT_RADIX 是 10. 尾数被规范化为该类型的精度位数 (例如对 decimal32_t 而言是 [1'000'000, 9'999'999]). 关于规范化形式的进一步讨论参见 群组 页面.

normalize

#include <boost/decimal/cmath.hpp>

namespace boost {
namespace decimal {

template <typename Decimal>
constexpr Decimal normalize(Decimal val) noexcept;

} // namespace decimal
} // namepsace boost

与上面的 frexp10 函数类似, 但它不返回十进制数的规范化尾数与指数, 而是返回一个规范化的数. 这消除了 群组 对 IEEE 754 兼容类型的影响, 以 decimal32_t 为例, 这意味着尾数将处于范围 [1'000'000, 9'999'999] 内. 该函数对快速类型 没有 任何影响, 因为它们在内部总是规范化的.

示例 1. 这个 示例 演示了 decompose、frexp10 与 normalize 在 IEEE 类型和快速类型上的区别.
// Copyright 2026 Matt Borland
// Distributed under the Boost Software License, Version 1.0.
// https://www.boost.org/LICENSE_1_0.txt
//
// This file demonstrates the difference between decompose, frexp10 and
// normalize, all of which inspect the internal representation of a
// decimal floating point value but expose it in different ways.

#include <boost/decimal/decimal32_t.hpp>    // For the type decimal32_t
#include <boost/decimal/decimal_fast32_t.hpp>// For the type decimal_fast32_t
#include <boost/decimal/cmath.hpp>          // For decompose, frexp10, normalize
#include <boost/decimal/iostream.hpp>       // For decimal support for <iostream>
#include <array>
#include <iostream>

template <typename Decimal>
void show(const Decimal value)
{
    // decompose returns the encoded significand, biased exponent and sign.
    // For IEEE types this preserves the cohort that was used at construction.
    // For fast types the value is normalized in the constructor, so the
    // components always reflect the normalized form.
    const auto components {boost::decimal::decompose(value)};

    // frexp10 returns the cohort-agnostic significand together with the
    // matching exponent written through the pointer argument. The significand
    // is normalized to the full precision of the type (for decimal32_t the
    // range is [1'000'000, 9'999'999]).
    int frexp_exp {};
    const auto frexp_sig {boost::decimal::frexp10(value, &frexp_exp)};

    // normalize returns a decimal of the same type whose representation has
    // had the cohort effects removed. For fast types this is a no-op since
    // they are already normalized.
    const auto normalized {boost::decimal::normalize(value)};

    std::cout << "  value      = " << value << '\n'
              << "  decompose  : sig = " << components.sig
              << ", exp = " << components.exp
              << ", sign = " << components.sign << '\n'
              << "  frexp10    : sig = " << frexp_sig
              << ", exp = " << frexp_exp << '\n'
              << "  normalize  = " << normalized << "\n\n";
}

int main()
{
    // All three values compare equal but use different cohorts.
    constexpr std::array<boost::decimal::decimal32_t, 3> ieee_values {
        boost::decimal::decimal32_t{3, 2},
        boost::decimal::decimal32_t{300, 0},
        boost::decimal::decimal32_t{3000000, -4}
    };

    std::cout << "IEEE decimal32_t (cohort is preserved by the encoding):\n\n";
    for (const auto& v : ieee_values)
    {
        show(v);
    }

    // The same set of inputs given to a fast type all encode identically.
    constexpr std::array<boost::decimal::decimal_fast32_t, 3> fast_values {
        boost::decimal::decimal_fast32_t{3, 2},
        boost::decimal::decimal_fast32_t{300, 0},
        boost::decimal::decimal_fast32_t{3000000, -4}
    };

    std::cout << "decimal_fast32_t (always normalized internally):\n\n";
    for (const auto& v : fast_values)
    {
        show(v);
    }

    return 0;
}

comparetotal

#include <boost/decimal/cmath.hpp>

namespace boost {
namespace decimal {

template <typename DecimalType>
constexpr bool comparetotal(DecimalType x, DecimalType y) noexcept;

} // namespace decimal
} // namespace boost

该函数是常规排序的扩展版本, 会考虑 NaN 的载荷以及规范形式.

效果:

  1. 若 x < y, 返回 true

  2. 若 x > y, 返回 false

  3. 若 x == y:

    1. -0 < +0 为 true

    2. +0 < -0 为 false

    3. 若 x 与 y 符号相同:

      1. comparetotal(x, y) 为 true 当且仅当 x 的指数 >= y 的指数

      2. 否则, 当 x 的指数 <= y 时 comparetotal(x, y) 为 true

  4. 若 x 与 y 因 x 或 y 是 NaN 而无序:

    1. comparetotal(-NAN, y) 为 true

    2. comparetotal(x, +NAN) 为 true

    3. 若 x 与 y 都是 NaN:

      1. comparetotal(-NAN, +NAN) 返回 true

      2. comparetotal(+SNAN, +QNAN) 返回 true

      3. comparetotal(-QNAN, -SNAN) 返回 true

      4. comparetotal(NAN, NAN)

        1. 若 NAN 均为正数, 则返回 true: 当 x 的载荷小于 y

        2. 若 NAN 均为负数, 则返回 true: 当 x 的载荷大于 y
