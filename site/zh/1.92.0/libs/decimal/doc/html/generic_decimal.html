3.2.8 说明

在非十进制类型与十进制类型之间进行二元算术运算时, 算术将在原生类型之间进行, 结果将以与十进制操作数相同的类型返回. (例如 decimal32_t * uint64_t → decimal32_t)

在两个十进制类型之间进行二元算术运算时, 结果将是两者中精度较高的类型 (例如 decimal64_t + decimal32_t → decimal64_t)

3.2.10 说明

支持非有限值

运算符行为

一元加

// 3.2.7 unary arithmetic operators:
constexpr decimal32_t  operator+(decimal32_t rhs) noexcept;
constexpr decimal64_t  operator+(decimal64_t rhs) noexcept;
constexpr decimal128_t operator+(decimal128_t rhs) noexcept;

在所有情况下原样返回 rhs.

一元减

constexpr decimal32_t  operator-(decimal32_t rhs) noexcept;
constexpr decimal64_t  operator-(decimal64_t rhs) noexcept;
constexpr decimal128_t operator-(decimal128_t rhs) noexcept;

在所有情况下返回取负后的 rhs.

加法

// 3.2.8 binary arithmetic operators:
// LHS and RHS can be any integer or decimal type

constexpr /* see 3.2.8 */ operator+(LHS lhs, decimal32_t rhs) noexcept;
constexpr /* see 3.2.8 */ operator+(LHS lhs, decimal64_t rhs) noexcept;
constexpr /* see 3.2.8 */ operator+(LHS lhs, decimal128_t rhs) noexcept;
constexpr /* see 3.2.8 */ operator+(decimal32_t lhs, RHS rhs) noexcept;
constexpr /* see 3.2.8 */ operator+(decimal64_t lhs, RHS rhs) noexcept;
constexpr /* see 3.2.8 */ operator+(decimal128_t lhs, RHS rhs) noexcept;

返回 lhs + rhs 的结果, 但需满足:

  1. 如果 lhs 或 rhs 是 NAN, 返回 QNAN

  2. 如果 lhs 与 rhs 是符号相反的 INF, 返回 QNAN

  3. 如果 lhs 或 rhs 是 INF, 返回同符号的 INF

  4. 如果 lhs + rhs 上溢, 返回 INF

  5. 如果 lhs + rhs 下溢, 返回 0

减法

// 3.2.8 binary arithmetic operators:
// LHS and RHS can be any integer or decimal type

constexpr /* see 3.2.8 */ operator-(LHS lhs, decimal32_t rhs) noexcept;
constexpr /* see 3.2.8 */ operator-(LHS lhs, decimal64_t rhs) noexcept;
constexpr /* see 3.2.8 */ operator-(LHS lhs, decimal128_t rhs) noexcept;
constexpr /* see 3.2.8 */ operator-(decimal32_t lhs, RHS rhs) noexcept;
constexpr /* see 3.2.8 */ operator-(decimal64_t lhs, RHS rhs) noexcept;
constexpr /* see 3.2.8 */ operator-(decimal128_t lhs, RHS rhs) noexcept;

返回 lhs - rhs 的结果, 但需满足:

  1. 如果 lhs 或 rhs 是 NAN, 返回 QNAN

  2. 如果 lhs 与 rhs 是符号相反的 INF, 返回 QNAN

  3. 如果 lhs 或 rhs 是 INF, 返回同符号的 INF

  4. 如果 lhs - rhs 上溢, 返回 INF

  5. 如果 lhs - rhs 下溢, 返回 0

乘法

constexpr /* see 3.2.8 */ operator*(decimal128_t lhs, RHS rhs) noexcept;

返回 lhs * rhs 的结果, 但需满足:

  1. 如果 lhs 或 rhs 是 NAN, 返回 QNAN

  2. 如果 lhs 或 rhs 是 INF 而另一个是 0, 返回 QNAN

  3. 如果 lhs 或 rhs 是 INF, 返回同符号的 INF

  4. 如果 lhs * rhs 上溢, 返回 INF

  5. 如果 lhs * rhs 下溢, 返回 0

除法

// 3.2.8 binary arithmetic operators:
// LHS and RHS can be any integer or decimal type

constexpr /* see 3.2.8 */ operator/(decimal64_t lhs, RHS rhs) noexcept;
constexpr /* see 3.2.8 */ operator/(decimal128_t lhs, RHS rhs) noexcept;

返回 lhs / rhs 的结果, 但需满足:

  1. 如果 lhs 或 rhs 是 NAN, 返回 QNAN

  2. 如果 lhs 是 INF:

    1. 返回 QNAN, 如果 rhs 是 INF

    2. 返回 INF, 如果 rhs 不是 INF

  3. 如果 rhs 是 0, 返回 INF

  4. 如果 rhs 是 INF, 返回 0

  5. 如果 lhs / rhs 上溢, 返回 INF

  6. 如果 lhs / rhs 下溢, 返回 0
