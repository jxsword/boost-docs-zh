配置宏

用户可配置宏

以下配置宏可用:

  • BOOST_DECIMAL_DISABLE_CASSERT: 禁用 <cassert> 及所有运行期断言.

  • BOOST_DECIMAL_DISABLE_IOSTREAM: 禁用 I/O 流并移除所有相关头文件 (例如 <iostream>、<iosfwd>、<cwchar> 等)

  • BOOST_DECIMAL_DISABLE_CLIB: 定义上述两个宏. 在测试中, 这可以减少约 50% 的 ROM 使用量, 在嵌入式平台上运行时可能有用.

  • BOOST_DECIMAL_DISABLE_EXCEPTIONS: 允许用户禁用对 throw 的任何调用. 当存在 -fno-exceptions 或 MSVC 上的各种 /EH 标志时, 该宏也会被自动设置.

  • BOOST_DECIMAL_ALLOW_IMPLICIT_INTEGER_CONVERSIONS: 允许任何整数类型隐式转换为任何十进制类型.

  • BOOST_DECIMAL_ALLOW_IMPLICIT_FLOAT_CONVERSIONS: 允许二进制浮点类型 (例如 double) 隐式转换为十进制浮点类型. 不推荐使用此选项, 但如果你想使用标准库中带有内部转换的特定功能, 它可能有用, 例如:

#define BOOST_DECIMAL_ALLOW_IMPLICIT_CONVERSIONS
#include <boost/decimal.hpp>
#include <complex>

constexpr decimal64_t half {5, -1};
std::complex<decimal64_t> test_val {half, half};
const auto res = std::acos(test_val);

  • BOOST_DECIMAL_ALLOW_IMPLICIT_CONVERSIONS: 同时定义 BOOST_DECIMAL_ALLOW_IMPLICIT_INTEGER_CONVERSIONS 与 BOOST_DECIMAL_ALLOW_IMPLICIT_FLOAT_CONVERSIONS

  • BOOST_DECIMAL_FAST_MATH 执行类似于 -ffast-math 编译器标志的优化, 例如移除所有对非有限值的检查. 此标志可将基本运算 (如加、减、乘、除与比较) 的性能提升多达 20%. 同样, 它必须在包含 decimal 头文件之前定义, 如下所示:

#define BOOST_DECIMAL_FAST_MATH
#include <boost/decimal.hpp>

  • BOOST_DECIMAL_DEC_EVAL_METHOD: 说明参见 <cfloat> 一节

  • BOOST_DECIMAL_ENABLE_CUDA: 定义此宏后, 在使用 NVCC 编译时 (即定义了 __CUDACC__ 时), 类型和选定的函数都可以在主机与设备上运行. 允许的函数在其函数签名中带有 BOOST_DECIMAL_HOST_DEVICE 或 BOOST_DECIMAL_CUDA_CONSTEXPR. 定义此宏还会自动定义 BOOST_DECIMAL_DISABLE_EXCEPTIONS 与 BOOST_DECIMAL_DISABLE_CASSERT, 因为设备代码中既没有异常也没有 <cassert>.

自动配置宏

  • BOOST_DECIMAL_CXX20_CONSTEXPR: 使用 C++20 或更高版本编译时定义为 constexpr, 否则展开为空.

  • BOOST_DECIMAL_HOST_DEVICE: 定义为 __host__ __device__ (当使用 NVCC 编译且 BOOST_DECIMAL_ENABLE_CUDA 已定义时), 否则定义为空. 标注了此宏的公共函数、构造函数、运算符与转换运算符可以在 CUDA 设备代码中不加修改地使用.

  • BOOST_DECIMAL_CUDA_CONSTEXPR: 定义为 __host__ __device__ constexpr (当使用 NVCC 编译且 BOOST_DECIMAL_ENABLE_CUDA 已定义时), 否则定义为 constexpr. 本库的大多数函数都标注了此宏.

  • BOOST_DECIMAL_HAS_STD_CHARCONV: 若头文件 <charconv> 存在且所用语言标准 >= C++17, 则定义此宏

    • 我们只需要该头文件中的结构体与枚举, 因此不关心对特性测试宏的过度限制.

      • 已知支持这一较轻要求的编译器有: GCC >= 10、Clang >= 13 与 MSVC >= 14.2

  • BOOST_DECIMAL_HAS_STD_STRING_VIEW: 若头文件 <string_view> 存在且所用语言标准 >= C++17, 则定义此宏
