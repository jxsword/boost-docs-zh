Boost.Decimal: IEEE 754 十进制浮点数

Matt Borland 与 Chris Kormanyos

说明

Boost.Decimal 是 IEEE 754 与 ISO/IEC DTR 24733 十进制浮点数的一个实现. 本库是仅头文件库, 没有依赖, 并且要求 C++14. 这些类型及许多函数还通过 CUDA 原生支持在 GPU 上运行.

Motivation

当前的 C++ 浮点类型把尾数 (significand, 常被误称为 mantissa) 存储为二进制数字. 众所周知, 这会导致表示误差: https://0.30000000000000004.com. 十进制浮点数通过以 10 为底 (十进制) 存储尾数来避免这一问题. 二进制与十进制浮点类型之间的另一个主要区别是, 后者允许同一个数有多个表示. 例如 1e5 也可以存储为 0.1e6、0.01e7 等等. 这些被称为群组, 二进制浮点没有群组, 因为在二进制浮点中每个数只有一种表示方式. 有关群组的更多信息请参见文档的 群组章节.

使用场景

十进制浮点数的使用场景是舍入误差有重大影响的领域, 例如金融. 在使用整数或定点算术来对抗这一问题的应用中, 十进制浮点数可以提供显著更大的取值范围. 例如, 分配八个十进制数字和两个小数位的定点表示可以表示 123456.78、8765.43、123.00 等数, 而具有八个十进制数字的浮点表示还可以表示 1.2345678、1234567.8、0.000012345678、12345678000000000 等.

支持的编译器

Boost.Decimal 在 Ubuntu (x86_64、s390x 与 aarch64)、macOS (x86_64 与 Apple Silicon) 和 Windows (x32 与 x64) 上进行了原生测试; 还使用 QEMU 模拟了 PPC64LE 与 ARM Cortex-M, 所用编译器如下:

  • GCC 8 及更高版本

  • Clang 6 及更高版本

  • Visual Studio 2019 及更高版本

  • Intel OneAPI DPC++

在 Github Actions 与 Drone 上进行了测试. 覆盖率可在 Codecov 上查看.
