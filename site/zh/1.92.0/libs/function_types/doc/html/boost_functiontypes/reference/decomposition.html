用于类型分解的类模板

result_type
parameter_types

result_type 

template<typename F>
struct result_type;

头文件 

#include <boost/function_types/result_type.hpp>

F

待分析的类型

result_type<F>::type

F 的结果类型

提取可调用体内建类型的结果类型.

如果 F 不是可调用体内建类型, 任何访问 type 成员的尝试都会导致编译错误.

parameter_types 

template<typename F, class ClassTransform = add_reference<_> >
struct parameter_types;

头文件 

#include <boost/function_types/parameter_types.hpp>

F

待分析的类型

ClassTransform

MPL - Lambda Expression, 当 F 是成员函数指针时, 用于变换类类型

parameter_types<F,ClassTransform>

MPL - Front / Back Extensible Random Access Sequence 形式的参数类型

提取可调用体内建类型的参数类型.

如果 F 不是可调用体内建类型, 任何访问该序列的尝试都会导致编译错误.

function_arity 

template<typename F>
struct function_arity;

头文件 

#include <boost/function_types/function_arity.hpp>

F

可调用体内建类型

function_arity<F>

函数参数个数 (MPL - Integral Constant)

function_arity<F>::value

函数参数个数的常量值

提取函数参数个数, 即参数的数量. 成员函数指针的隐藏 this 也计入在内, 换言之, 如果 F 是成员函数指针, 参数个数始终大于或等于一.

如果 F 不是可调用体内建类型, 任何访问该值的尝试都会导致编译错误.

components 

template<typename T, class ClassTransform = add_reference<_> >
struct components;

头文件 

#include <boost/function_types/components.hpp>

T

待分析的类型

ClassTransform

MPL - Lambda Expression, 当 T 是成员函数指针时, 用于变换类类型

components<T,ClassTransform>

MPL - Front / Back Extensible Random Access Sequence 形式的全部组件类型与属性标签

components<T,ClassTransform>::types

带修饰的 MPL 序列, 为优化而公开

提取可调用体内建类型的全部属性, 即结果类型, 其后是参数类型 (对于成员函数指针, 还包括 this 的类型).

如果 T 不是可调用体内建类型, 组件类型是一个空序列, 且标签的含义等同于 null_tag.
