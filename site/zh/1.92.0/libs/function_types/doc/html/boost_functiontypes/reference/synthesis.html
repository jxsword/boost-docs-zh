用于类型合成的类模板

function_type
function_pointer
function_reference
member_function_pointer

function_type 

template<typename Types, typename Tag = null_tag>
struct function_type;

头文件 

#include <boost/function_types/function_type.hpp>

Types

组件类型, 以 MPL - Forward Sequence 形式给出, 或为其他可调用体内建类型

Tag

其余属性

function_type<Types,Tag>::type

合成出的类型

根据给定属性合成一个函数类型.

如果模板参数未描述一个有效类型, 任何访问 type 成员的尝试都会导致编译错误.

member_function_pointer 

template<typename Types, typename Tag = null_tag>
struct member_function_pointer;

头文件 

#include <boost/function_types/member_function_pointer.hpp>

Types

组件类型, 以 MPL - Forward Sequence 形式给出, 或为其他可调用体内建类型

Tag

其余属性

member_function_pointer<Types,Tag>::type

合成出的类型

根据给定属性合成一个成员函数指针类型.

从序列中的第二个类型中去除可选的引用或可能带 cv 限定的指针, 以确定类类型. 结果类型的 cv 限定将作用于该成员函数, 除非属性标签另有显式规定.

如果模板参数未描述一个有效类型, 任何访问 type 成员的尝试都会导致编译错误.
