用例

接受可调用实参的泛型库在 C++ 中很常见. 接受内建类型的可调用实参通常涉及大量重复代码, 因为接受函数要针对不同的函数参数个数进行重载. 此外, 成员函数可能带有 const/volatile 限定符, 函数可能接受可变数量的 (额外的, POD 类型的) 实参 (例如 printf), 并且多个 C++ 实现会在每个函数的类型中编码调用约定, 以支持跨语言或跨 (子) 系统边界的调用.

template<typename R>
void accept_function(R(* func)());

template<typename R>
void accept_function(R(& func)());

template<typename R, typename C>
void accept_function(R(C::* func)());

template<typename R, typename C>
void accept_function(R(C::* func)() const);

template<typename R, typename C>
void accept_function(R(C::* func)() volatile);

template<typename R, typename C>
void accept_function(R(C::* func)() const volatile);

template<typename R>
void accept_function(R(* func)(...));

template<typename R>
void accept_function(R(& func)(...));

template<typename R, typename C>
void accept_function(R(C::* func)(...));

template<typename R, typename C>
void accept_function(R(C::* func)(...) const);

template<typename R, typename C>
void accept_function(R(C::* func)(...) volatile);

template<typename R, typename C>
void accept_function(R(C::* func)(...) const volatile);

// ...

// needs to be repeated for every additional function parameter
// times the number of possible calling conventions

"重载方式"显然扩展性不佳: 一个库中可能有多个接受可调用实参的函数, 而客户代码最终可能使用多个采用这种模式的库. 在开发者这边, 库开发者把时间花在解决相同的问题、绕过相同的可移植性问题上, 并应用类似的优化来降低编译时间.

使用 Boost.FunctionTypes 则可以改为编写单个函数模板:

template<typename F>
void accept_function(F f)
{
  // ... use Boost.FunctionTypes to analyse F
}

与提供调用器组件的元组库 (如 Boost.Fusion) 相结合, 可以构建完全不包含重复代码的灵活回调设施, 如 解释器示例 所示.

当获取重载函数或函数模板的地址时, 必须从表达式所在的上下文中得知函数的类型. 下面的代码展示了三个选择 float(float) 重载 (来自 std::abs) 的示例.

float (*ptr_absf)(float) = & std::abs;


void foo(float(*func)(float));

void bar()
{
  foo(& std::abs);
}


std::transform(b, e, o, static_cast<float(*)(float)>(& std::abs));

本库的类型合成能力可用于自动化重载选择和函数模板的实例化. 给定一个重载的函数模板

template<typename R, typename T0>
R overloaded(T0);

template<typename R, typename T0, typename T1>
R overloaded(T0,T1);

template<typename R. typename T0, typename T1, typename T2>
R overloaded(T0,T1,T2);

我们可以在单个表达式中选取三个重载中的任意一个, 并用来自类型序列的模板实参来实例化该模板:

static_cast<function_pointer<Seq>::type>(& overloaded)

这种技术有时比从函数调用进行模板实参推导更灵活, 因为来自序列的精确类型会用于特化模板 (包括可能带 cv 限定的引用类型和结果类型). 它在 接口示例 中被使用了两次.

可调用体内建类型的另一个有趣特性是, 它们可以是非类型模板参数的有效类型. 这样, 函数可以在编译期被精确定位, 使编译器能够通过内联消除调用. fast_mem_fn 示例 利用了这一特性, 实现了 boost::mem_fn 的一个可能内联的版本, 但仅限于编译期已知的成员函数.
