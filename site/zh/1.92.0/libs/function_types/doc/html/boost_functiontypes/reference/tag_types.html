复合属性标签

最多四个属性标签的组合. 如果各参数对同一属性描述了不同的取值, 则使用最右边参数的取值.

has_property_tag 

template<class Tag, class PropertyTag>
struct has_property_tag;

头文件 

#include <boost/function_types/property_tags.hpp>

Tag

可能为复合的属性标签

PropertyTag

单一属性标签

has_property_tag<Tag,PropertyTag>

针对单一属性标签测试 (可能为复合的) 属性标签

用于测试复合属性标签的组成中是否含有特定单一属性标签的元函数. 如果该特定单一属性标签是复合属性标签的组成部分, 返回布尔值 true, 否则返回 false.

为方便起见, 还有针对内建属性标签的单个元函数, 形式为

template<class Tag>
struct has_'name'_property_tag;

其用法与 has_property_tag 完全相同, 其中 name 可为 variadic,default_cc,const,volatile,cv,或 null. 在这些单个元函数中 const 是 const_qualified 的简写, volatile 是 volatile_qualified 的简写, cv 是 cv_qualified 的简写, 而 null 是 null_tag 的简写.

注释

测试 null_tag 时, 无论使用 has_property_tag<Tag,null_tag> 还是 has_null_property_tag<Tag>, 始终测试 Tag 是否为单一的 null_tag property_tag.
