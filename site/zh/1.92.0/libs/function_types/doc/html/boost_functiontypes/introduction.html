引言

Boost.FunctionTypes 提供对函数、函数指针、函数引用和成员指针类型进行分类、分解与合成的功能.

我们将这些类型统称为可调用体内建类型.

具体而言, 本库可用于:

  • 测试某个类型是否是特定的可调用体内建类型,
  • 从可调用体内建类型中提取全部组成属性, 以及
  • 根据指定的属性创建可调用体内建类型.

本库的设计使其能够与其他 Boost 库良好协作, 并采用了由 Boost 和 TR1 引入且被广泛接受的概念.

封装布尔或数值属性的模板定义了一个名为 value 的静态成员常量.

is_function_pointer< bool(*)(int) >::value // == true 

function_arity< bool(*)(int) >::value // == 1

封装单一类型属性的模板包含一个名为 type 的类型成员.

function_type< mpl::vector<bool,int> >::type // is bool(int)

result_type< bool(&)(int) >::type // is bool

封装类型列表属性的模板以 MPL 兼容的类型序列为模型.

parameter_types< bool(int) > // models an MPL sequence
