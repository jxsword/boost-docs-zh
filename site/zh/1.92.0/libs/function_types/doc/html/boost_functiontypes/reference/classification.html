is_function 

template<typename T, typename Tag = null_tag>
struct is_function;

头文件 

#include <boost/function_types/is_function.hpp>

T

待分析的类型

Tag

得到肯定结果所需的其余属性

is_function<T,Tag>

作为 MPL - Integral Constant 的谓词值

is_function<T,Tag>::value

常量布尔值

判定给定类型是否是一个函数, 并可能带有由属性标签指定的附加属性.
