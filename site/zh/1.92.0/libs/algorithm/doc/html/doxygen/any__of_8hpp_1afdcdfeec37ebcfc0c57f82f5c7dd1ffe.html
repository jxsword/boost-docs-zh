函数模板 any_of

boost::algorithm::any_of

概要

// In header: <boost/algorithm/cxx11/any_of.hpp>


template<typename InputIterator, typename Predicate> 
  BOOST_CXX14_CONSTEXPR bool 
  any_of(InputIterator first, InputIterator last, Predicate p);

说明

注释

对空范围返回 false

参数:

first

输入序列的起点

last

输入序列末端之后的位置

p

用于测试序列元素的谓词

返回:

如果 [first, last) 中有任一元素满足谓词, 则为 true
