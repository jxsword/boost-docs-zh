函数模板 transform_inclusive_scan

boost::algorithm::transform_inclusive_scan — 用 uOp 变换输入范围中的元素, 然后用 bOp 合并这些变换后的元素, 使第 n-1 个元素与第 n 个元素合并. 包含性意味着第 n 个元素包含在第 n 次合并中.

概要

// In header: <boost/algorithm/cxx17/transform_inclusive_scan.hpp>


template<typename InputIterator, typename OutputIterator, 
         typename BinaryOperation, typename UnaryOperation, typename T> 
  OutputIterator 
  transform_inclusive_scan(InputIterator first, InputIterator last, 
                           OutputIterator result, BinaryOperation bOp, 
                           UnaryOperation uOp, T init);

说明

用 uOp 变换输入范围中的元素, 然后用 bOp 合并这些变换后的元素, 使第 n-1 个元素与第 n 个元素合并. 包含性意味着第 n 个元素包含在第 n 次合并中. 第一个值将用作 init.
