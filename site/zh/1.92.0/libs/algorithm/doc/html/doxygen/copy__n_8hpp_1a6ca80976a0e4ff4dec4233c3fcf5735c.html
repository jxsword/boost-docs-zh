函数模板 copy_n

boost::algorithm::copy_n — 把从 first 开始的范围中的恰好 n (n > 0) 个元素复制到从 result 开始的范围.

概要

// In header: <boost/algorithm/cxx11/copy_n.hpp>


template<typename InputIterator, typename Size, typename OutputIterator> 
  BOOST_CXX14_CONSTEXPR OutputIterator 
  copy_n(InputIterator first, Size n, OutputIterator result);

说明

注释

该函数是 C++2011 标准库的一部分.

参数:

first

输入序列的起点

n

要复制的元素个数

result

用于写入结果的输出迭代器

返回:

更新后的输出迭代器
