函数模板 partition_copy

boost::algorithm::partition_copy — 把范围 [first, last) 中满足谓词 p 的元素复制到从 d_first_true 开始的范围, 把不满足 p 的元素复制到从 d_first_false 开始的范围.

概要

// In header: <boost/algorithm/cxx11/partition_copy.hpp>


template<typename InputIterator, typename OutputIterator1, 
         typename OutputIterator2, typename UnaryPredicate> 
  BOOST_CXX14_CONSTEXPR std::pair< OutputIterator1, OutputIterator2 > 
  partition_copy(InputIterator first, InputIterator last, 
                 OutputIterator1 out_true, OutputIterator2 out_false, 
                 UnaryPredicate p);

说明

注释

该函数是 C++2011 标准库的一部分.

参数:

first

输入序列的起点

last

输入序列末端之后的位置

out_true

用于写入满足谓词的元素的输出迭代器

out_false

用于写入不满足谓词的元素的输出迭代器

p

用于划分输入序列元素的谓词.
