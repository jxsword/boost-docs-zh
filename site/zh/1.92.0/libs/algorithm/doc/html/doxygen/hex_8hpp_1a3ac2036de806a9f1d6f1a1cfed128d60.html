函数模板 unhex

boost::algorithm::unhex — 把十六进制字符序列转换为整数序列.

概要

// In header: <boost/algorithm/hex.hpp>


template<typename InputIterator, typename OutputIterator> 
  OutputIterator 
  unhex(InputIterator first, InputIterator last, OutputIterator out);

说明

注释

基于 MySQL 的同名函数

参数:

first

输入序列的起点

last

输入序列末端之后的位置

out

用于写入结果的输出迭代器

返回:

更新后的输出迭代器
