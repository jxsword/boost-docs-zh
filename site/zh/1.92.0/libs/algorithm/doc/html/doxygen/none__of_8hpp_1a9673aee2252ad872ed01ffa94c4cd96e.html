函数模板 none_of

boost::algorithm::none_of

概要

// In header: <boost/algorithm/cxx11/none_of.hpp>


template<typename Range, typename Predicate> 
  BOOST_CXX14_CONSTEXPR bool none_of(const Range & r, Predicate p);

说明

注释

对空范围返回 true

参数:

r

输入范围

p

用于测试范围元素的谓词

返回:

如果范围中没有元素满足谓词 'p', 则为 true
