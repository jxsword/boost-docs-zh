函数模板 boyer_moore_horspool_search

boost::algorithm::boyer_moore_horspool_search — 在语料中搜索模式.

概要

// In header: <boost/algorithm/searching/boyer_moore_horspool.hpp>


template<typename patIter, typename corpusIter> 
  std::pair< corpusIter, corpusIter > 
  boyer_moore_horspool_search(corpusIter corpus_first, corpusIter corpus_last, 
                              patIter pat_first, patIter pat_last);

说明

参数:

corpus_first

要搜索的数据的起点 (随机访问迭代器)

corpus_last

要搜索的数据末端之后的位置

pat_first

要搜索的模式的起点 (随机访问迭代器)

pat_last

要查找的模式末端之后的位置
