函数模板 find_if_not

boost::algorithm::find_if_not — 找出序列中不满足谓词的第一个元素.

概要

// In header: <boost/algorithm/cxx11/find_if_not.hpp>


template<typename Range, typename Predicate> 
  BOOST_CXX14_CONSTEXPR boost::range_iterator< constRange >::type 
  find_if_not(const Range & r, Predicate p);

说明

参数:

r

输入范围

p

用于测试范围元素的谓词

返回:

指向目标元素的迭代器.
