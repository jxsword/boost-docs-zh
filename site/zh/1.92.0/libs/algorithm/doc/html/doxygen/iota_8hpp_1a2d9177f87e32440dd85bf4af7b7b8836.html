函数模板 iota

boost::algorithm::iota — 生成一个递增的值序列, 并存储在 [first, last) 中

概要

// In header: <boost/algorithm/cxx11/iota.hpp>


template<typename ForwardIterator, typename T> 
  BOOST_CXX14_CONSTEXPR void 
  iota(ForwardIterator first, ForwardIterator last, T value);

说明

注释

该函数是 C++2011 标准库的一部分.

参数:

first

输入序列的起点

last

输入序列末端之后的位置

value

要生成的序列的初始值
