函数模板 is_partitioned

boost::algorithm::is_partitioned — 测试序列是否按谓词划分. 换句话说, 序列中所有满足谓词的元素都位于序列的开头.

概要

// In header: <boost/algorithm/cxx11/is_partitioned.hpp>


template<typename Range, typename UnaryPredicate> 
  BOOST_CXX14_CONSTEXPR bool is_partitioned(const Range & r, UnaryPredicate p);

说明

参数:

r

输入范围

p

用于测试值的谓词
