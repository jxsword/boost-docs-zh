说明与设计理由

Boost.Algorithm 是通用算法的集合. 虽然 Boost 包含许多数据结构库, 却没有一个通用算法库. 尽管这些算法普遍有用, 但许多算法往往被认为是"太小"而不值得进入 Boost.

例如, 实现一个 Boyer-Moore 搜索可能需要开发者一周左右的时间 (包括测试用例和文档) . 然而, 安排一次评审把这段代码纳入 Boost 可能要花好几个月, 还会因为"它太小"而遭遇阻力. 尽管如此, 一个经过测试、评审并撰写了文档的算法库可以让开发者的日子好过得多, 这正是本库的目的.

后续计划

我将征求其他开发者的投稿, 也会查阅文献寻找可纳入的现有算法. 例如, Adobe Source Library 包含许多已有文档和测试用例的实用算法. Knuth 的 The Art of Computer Programming 也满是算法描述.

我的目标是定期举行算法评审, 类似 Boost 库评审流程, 但针对更小的代码块.

Dependencies

Boost.Algorithm 使用 Boost.Range、Boost.Assert、Boost.Array、Boost.TypeTraits 和 Boost.StaticAssert.

感谢所有评审过本库并提出改进建议的人. 尤其是 Steven Watanabe 和 Sean Parent, 他们提供了大量帮助.
