C++14 算法

equal
mismatch

equal

头文件 'equal.hpp' 包含 STL 算法 equal 的两种变体. 该算法测试两个序列是否包含相等的值;

在 (提案中的) C++14 之前, 算法 std::equal 接受三个迭代器和一个可选的比较谓词. 前两个迭代器 [first1, last1) 定义一个序列, 第二个迭代器 first2 定义第二个序列的起点. 假定第二个序列与第一个序列长度相同.

C++14 引入了两个新变体, 接受四个迭代器和一个可选的比较谓词. 这四个迭代器显式地定义两个序列 [first1, last1) 和 [first2, last2), 而不是隐式定义第二个序列. 这在更多情况下能得到正确答案 (并在另一些情况下避免未定义行为) .

考虑这两个序列:

auto seq1 = { 0, 1, 2 };
auto seq2 = { 0, 1, 2, 3, 4 };

std::equal ( seq1.begin (), seq1.end (), seq2.begin ()); // true
std::equal ( seq2.begin (), seq2.end (), seq1.begin ()); // Undefined behavior
std::equal ( seq1.begin (), seq1.end (), seq2.begin (), seq2.end ()); // false

可以辩解说 true 是第一种情况下的正确答案, 即使两个序列并不相同. seq2 的前 N 项与 seq1 中的项相同——但这并不是 seq2 的全部内容. 但在第二种情况下, 算法会读取越过 seq1 的末尾, 导致未定义行为 (大地震、错误结果、怀孕的猫等) .

然而, 如果完整地指定两个序列, 就能清楚地看出它们不相等.

接口

函数 equal 在两个序列比较相等时返回 true; 即序列中每个元素都与另一序列中对应的元素比较相等. 一个版本使用 std::equal_to 进行比较; 另一个版本允许调用者传入谓词进行比较.

template <class InputIterator1, class InputIterator2>
bool equal ( InputIterator1 first1, InputIterator1 last1,
             InputIterator2 first2, InputIterator2 last2 );

template <class InputIterator1, class InputIterator2, class BinaryPredicate>
bool equal ( InputIterator1 first1, InputIterator1 last1,
             InputIterator2 first2, InputIterator2 last2, BinaryPredicate pred );

示例

给定容器 c1, 其中包含 { 0, 1, 2, 3, 14, 15 }, 以及 c2, 其中包含 { 1, 2, 3 }, 则

equal ( c1.begin (),     c1.end (),       c2.begin (), c2.end ()) --> false
equal ( c1.begin () + 1, c1.begin () + 3, c2.begin (), c2.end ()) --> true
equal ( c1.end (),       c1.end (),       c2.end (),   c2.end ()) --> true  // empty sequences are alway equal to each other

迭代器要求

equal 适用于除输出迭代器之外的所有迭代器.

复杂度

equal 的两种变体都以 O(N) (线性) 时间运行; 也就是说, 它们对列表中的每个元素比较一次. 如果在任何位置发现序列不相等, 例程会立即终止, 不再检查其余元素.

异常安全

equal 的两种变体都按值接受参数且不依赖任何全局状态. 因此, 本文件中的所有例程都提供强异常保证.

注释
  • 例程 equal 的四迭代器版本是 C++14 标准的一部分. 当 C++14 标准库实现可用时, 应使用标准库中的实现.
  • 对于两个空范围, 无论传入什么谓词进行测试, equal 都返回 true.

mismatch

头文件 'mismatch.hpp' 包含 STL 算法 mismatch 的两种变体. 该算法找出两个序列中第一个不匹配之处.

在 (提案中的) C++14 之前, 算法 std::mismatch 接受三个迭代器和一个可选的比较谓词. 前两个迭代器 [first1, last1) 定义一个序列, 第二个迭代器 first2 定义第二个序列的起点. 假定第二个序列与第一个序列长度相同.

C++14 引入了两个新变体, 接受四个迭代器和一个可选的比较谓词. 这四个迭代器显式地定义两个序列 [first1, last1) 和 [first2, last2), 而不是隐式定义第二个序列. 这在更多情况下能得到正确答案 (并在另一些情况下避免未定义行为) .

考虑这两个序列:

auto seq1 = { 0, 1, 2 };
auto seq2 = { 0, 1, 2, 3, 4 };

std::mismatch ( seq1.begin (), seq1.end (), seq2.begin ()); // <3, 3>
std::mismatch ( seq2.begin (), seq2.end (), seq1.begin ()); // Undefined behavior
std::mismatch ( seq1.begin (), seq1.end (), seq2.begin (), seq2.end ()); // <3, 3>

seq2 的前 N 项与 seq1 中的项相同——但这并不是 seq2 的全部内容. 在第二种情况下, 算法会读取越过 seq1 的末尾, 导致未定义行为 (大地震、错误结果、怀孕的猫等) .

然而, 如果完整地指定两个序列, 不匹配发生之处就很清楚了.

接口

函数 mismatch 返回一对迭代器, 表示每个序列中第一个不匹配的元素. 如果两个序列完全匹配, mismatch 返回它们的末端迭代器. 一个版本使用 std::equal_to 进行比较; 另一个版本允许调用者传入谓词进行比较.

template <class InputIterator1, class InputIterator2>
std::pair<InputIterator1, InputIterator2>
mismatch ( InputIterator1 first1, InputIterator1 last1,
           InputIterator2 first2, InputIterator2 last2 );

template <class InputIterator1, class InputIterator2, class BinaryPredicate>
std::pair<InputIterator1, InputIterator2>
mismatch ( InputIterator1 first1, InputIterator1 last1,
           InputIterator2 first2, InputIterator2 last2, BinaryPredicate pred );

示例

给定容器 c1, 其中包含 { 0, 1, 2, 3, 14, 15 }, 以及 c2, 其中包含 { 1, 2, 3 }, 则

mismatch ( c1.begin(),     c1.end(),       c2.begin(), c2.end()) --> <c1.begin(), c2.begin()> // first elements do not match
mismatch ( c1.begin() + 1, c1.begin() + 4, c2.begin(), c2.end()) --> <c1.begin() + 4, c2.end ()> // all elements of `c2` match
mismatch ( c1.end(),       c1.end(),       c2.end(),   c2.end()) --> <c1.end(), c2.end()> // empty sequences don't match at the end.

迭代器要求

mismatch 适用于除输出迭代器之外的所有迭代器.

复杂度

mismatch 的两种变体都以 O(N) (线性) 时间运行; 也就是说, 它们对列表中的每个元素比较一次. 如果在任何位置发现序列不相等, 例程会立即终止, 不再检查其余元素.

异常安全

mismatch 的两种变体都按值接受参数且不依赖任何全局状态. 因此, 本文件中的所有例程都提供强异常保证.

注释
  • 如果两个序列相等 (或都为空) , mismatch 返回两个序列的末端迭代器.
  • 例程 mismatch 的四迭代器版本是 C++14 标准的一部分. 当 C++14 标准库实现可用时, 应使用标准库中的实现.
