for_each_n

for_each_n 对序列的元素应用函子

transform_inclusive_scan

transform_inclusive_scan 对范围中的每个元素做变换, 然后合并相邻元素以生成输出范围. 包含扫描 (inclusive scan) 意味着第 n 个输入会出现在第 n 个输出中.

transform_exclusive_scan

transform_exclusive_scan 对范围中的每个元素做变换, 然后合并相邻元素以生成输出范围. 排除扫描 (exclusive scan) 意味着第 n 个输入不会出现在第 n 个输出中.
