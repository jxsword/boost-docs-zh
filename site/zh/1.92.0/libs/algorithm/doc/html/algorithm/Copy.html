Copy 的变体

copy_until
copy_while

copy_until

copy_until 从输入范围的开头把元素复制到输出范围, 直到谓词被满足

copy_while

copy_while 从输入范围的开头把元素复制到输出范围, 只要谓词被满足

copy_if_until

[*copy_if_until 从输入范围的开头把满足元素谓词的所有元素复制到输出范围, 直到终止谓词被满足

copy_if_while

[*copy_if_while 从输入范围的开头把满足元素谓词的所有元素复制到输出范围, 只要终止谓词被满足
