all_of

头文件 'boost/algorithm/cxx11/all_of.hpp' 包含单个算法 all_of 的四种变体. 该算法测试序列的所有元素, 如果它们全都具有某个属性, 则返回 true.

例程 all_of 接受一个序列和一个谓词. 如果谓词应用于序列中的每个元素时都返回 true, 则它返回 true.

例程 all_of_equal 接受一个序列和一个值. 如果序列中的每个元素都与传入的值比较相等, 则它返回 true.

这两个例程都有两种形式: 第一种接受两个迭代器来定义范围; 第二种接受单个范围参数, 并使用 Boost.Range 来遍历.

接口

函数 all_of 在谓词对序列中每一项都返回 true 时返回 true. 有两个版本: 一个接受两个迭代器, 另一个接受一个范围.

namespace boost { namespace algorithm {
template<typename InputIterator, typename Predicate>
	bool all_of ( InputIterator first, InputIterator last, Predicate p );
template<typename Range, typename Predicate>
	bool all_of ( const Range &r, Predicate p );
}}

函数 all_of_equal 类似于 all_of, 但它不是接受谓词来测试序列元素, 而是接受一个用于比较的值.

namespace boost { namespace algorithm {
template<typename InputIterator, typename V>
	bool all_of_equal ( InputIterator first, InputIterator last, V const &val );
template<typename Range, typename V>
	bool all_of_equal ( const Range &r, V const &val );
}}

示例

给定容器 c, 其中包含 { 0, 1, 2, 3, 14, 15 }, 则

bool isOdd ( int i ) { return i % 2 == 1; }
bool lessThan10 ( int i ) { return i < 10; }

using boost::algorithm;
all_of ( c, isOdd ) --> false
all_of ( c.begin (), c.end (), lessThan10 ) --> false
all_of ( c.begin (), c.begin () + 3, lessThan10 ) --> true
all_of ( c.end (), c.end (), isOdd ) --> true  // empty range
all_of_equal ( c, 3 ) --> false
all_of_equal ( c.begin () + 3, c.begin () + 4, 3 ) --> true
all_of_equal ( c.begin (), c.begin (), 99 ) --> true  // empty range

迭代器要求

all_of 和 all_of_equal 适用于除输出迭代器之外的所有迭代器.

复杂度

all_of 和 all_of_equal 的所有变体都以 O(N) (线性) 时间运行; 也就是说, 它们对列表中的每个元素比较一次. 如果任何一次比较失败, 算法会立即终止, 不再检查序列中剩余的成员.

异常安全

all_of 和 all_of_equal 的所有变体都按值或 const 引用接受参数, 且不依赖任何全局状态. 因此, 本文件中的所有例程都提供强异常保证.

注释
  • 例程 all_of 也是 C++11 标准的一部分.
  • 对于空范围, 无论传入什么测试对象, all_of 和 all_of_equal 都返回 true. 当序列中没有可测试的元素时, 它们全都满足被测试的条件.
  • all_of_value 的第二个参数是模板参数, 而不是从第一个参数 (std::iterator_traits<InputIterator>::value_type) 推导而来, 因为这为调用者提供了更大的灵活性, 并利用了迭代器所指类型的内建比较. 该函数定义为: 当序列中所有元素使表达式 *iter == val 求值为 true 时返回 true (其中 iter 是指向序列中每个元素的迭代器)

one_of

头文件 'boost/algorithm/cxx11/one_of.hpp' 包含单个算法 one_of 的四种变体. 该算法测试序列的元素, 如果序列中恰好只有一个元素具有特定属性, 则返回 true.

例程 one_of 接受一个序列和一个谓词. 如果谓词对序列中的一个元素返回 true, 则它返回 true.

例程 one_of_equal 接受一个序列和一个值. 如果序列中有一个元素与传入的值比较相等, 则它返回 true.

这两个例程都有两种形式: 第一种接受两个迭代器来定义范围; 第二种接受单个范围参数, 并使用 Boost.Range 来遍历.

接口

函数 one_of 在谓词对序列中的一项返回 true 时返回 true. 有两个版本: 一个接受两个迭代器, 另一个接受一个范围.

namespace boost { namespace algorithm {
template<typename InputIterator, typename Predicate>
	bool one_of ( InputIterator first, InputIterator last, Predicate p );
template<typename Range, typename Predicate>
	bool one_of ( const Range &r, Predicate p );
}}

函数 one_of_equal 类似于 one_of, 但它不是接受谓词来测试序列元素, 而是接受一个用于比较的值.

template<typename Range, typename V>
	bool one_of_equal ( const Range &r, V const &val );
}}

is_sorted

头文件 <boost/algorithm/cxx11/is_sorted.hpp> 包含用于判定序列是否有序的函数.

is_sorted

函数 is_sorted(sequence) 判断序列是否按某种准则完全排序. 如果未指定比较谓词, 则使用 std::less (即测试序列是否非递减)

namespace boost { namespace algorithm {
	template <typename ForwardIterator, typename Pred>
	bool is_sorted ( ForwardIterator first, ForwardIterator last, Pred p );
	
	template <typename ForwardIterator>
	bool is_sorted ( ForwardIterator first, ForwardIterator last );
	
	
	template <typename Range, typename Pred>
	bool is_sorted ( const Range &r, Pred p );
	
	template <typename Range>
	bool is_sorted ( const Range &r );
}}

迭代器要求: is_sorted 函数可用于前向迭代器或更好的迭代器.

is_sorted_until

如果 distance(first, last) < 2, 则 is_sorted ( first, last ) 返回 last. 否则, 它返回 [first,last] 中最后一个迭代器 i, 使得范围 [first,i) 是有序的.

简言之, 它返回序列中"乱序"的元素. 如果整个序列 (按谓词) 是有序的, 则它返回 last.

namespace boost { namespace algorithm {
	template <typename ForwardIterator, typename Pred>
	FI is_sorted_until ( ForwardIterator first, ForwardIterator last, Pred p );
	
	template <typename ForwardIterator>
	ForwardIterator is_sorted_until ( ForwardIterator first, ForwardIterator last );
	
	
	template <typename Range, typename Pred>
	typename boost::range_iterator<const R>::type is_sorted_until ( const Range &r, Pred p );
	
	template <typename Range>
	typename boost::range_iterator<const R>::type is_sorted_until ( const Range &r );
}}

迭代器要求: is_sorted_until 函数可用于前向迭代器或更好的迭代器. 由于它们必须返回输入序列中的一个位置, 输入迭代器是不够的.

复杂度: is_sorted_until 对谓词最多调用 N-1 次 (给定长度为 N 的序列) .

示例:

给定序列 { 1, 2, 3, 4, 5, 3 }, is_sorted_until ( beg, end, std::less<int>()) 将返回指向第二个 3 的迭代器.

给定序列 { 1, 2, 3, 4, 5, 9 }, is_sorted_until ( beg, end, std::less<int>()) 将返回 end.

还有一组用于 is_ordered 的"包装函数", 可方便地查看整个序列是否有序. 这些函数返回一个布尔值表示成功或失败, 而不是返回发现乱序元素之处的迭代器.

测试序列是否递增 (每个元素不小于前一个元素) :

namespace boost { namespace algorithm {
	template <typename Iterator>
	bool is_increasing ( Iterator first, Iterator last );
	
	template <typename R>
	bool is_increasing ( const R &range );
}}

测试序列是否递减 (每个元素不大于前一个元素) :

namespace boost { namespace algorithm {
	template <typename ForwardIterator>
	bool is_decreasing ( ForwardIterator first, ForwardIterator last );
	
	template <typename R>
	bool is_decreasing ( const R &range );
}}

测试序列是否严格递增 (每个元素大于前一个元素) :

namespace boost { namespace algorithm {
	template <typename ForwardIterator>
	bool is_strictly_increasing ( ForwardIterator first, ForwardIterator last );
	
	template <typename R>
	bool is_strictly_increasing ( const R &range );
}}

测试序列是否严格递减 (每个元素小于前一个元素) :

namespace boost { namespace algorithm {
	template <typename ForwardIterator>
	bool is_strictly_decreasing ( ForwardIterator first, ForwardIterator last );
	
	template <typename R>
	bool is_strictly_decreasing ( const R &range );
}}

复杂度: 这些调用只是 is_sorted 的薄封装, 因此它们与 is_sorted 具有相同的复杂度.

注释
  • 例程 is_sorted 和 is_sorted_until 是 C++11 标准的一部分. 使用 C++11 实现编译时, 将使用标准库中的实现.
  • 对于空范围和长度为 1 的范围, is_sorted 和 is_sorted_until 都返回 true.

is_partitioned

头文件 'is_partitioned.hpp' 包含单个算法 is_partitioned 的两种变体. 该算法测试序列是否按谓词划分; 换句话说, 序列中所有满足谓词的元素都位于序列的开头.

例程 is_partitioned 接受一个序列和一个谓词. 如果序列按谓词划分, 则它返回 true.

is_partitioned 有两种形式: 第一种接受两个迭代器来定义范围; 第二种接受单个范围参数, 并使用 Boost.Range 来遍历.

接口

函数 is_partitioned 在序列中的元素按其满足谓词的能力被分隔时返回 true. 有两个版本: 一个接受两个迭代器, 另一个接受一个范围.

template<typename InputIterator, typename Predicate>
	bool is_partitioned ( InputIterator first, InputIterator last, Predicate p );
template<typename Range, typename Predicate>
	bool is_partitioned ( const Range &r, Predicate p );

示例

给定容器 c, 其中包含 { 0, 1, 2, 3, 14, 15 }, 则

bool isOdd ( int i ) { return i % 2 == 1; }
bool lessThan10 ( int i ) { return i < 10; }

is_partitioned ( c, isOdd ) --> false
is_partitioned ( c, lessThan10 ) --> true
is_partitioned ( c.begin (), c.end (), lessThan10 ) --> true
is_partitioned ( c.begin (), c.begin () + 3, lessThan10 ) --> true
is_partitioned ( c.end (), c.end (), isOdd ) --> true  // empty range

迭代器要求

is_partitioned 适用于除输出迭代器之外的所有迭代器.

复杂度

is_partitioned 的两种变体都以 O(N) (线性) 时间运行; 也就是说, 它们对列表中的每个元素比较一次. 如果在任何位置发现序列未按谓词划分, 例程会立即终止, 不再检查其余元素.

异常安全

is_partitioned 的两种变体都按值或 const 引用接受参数, 且不依赖任何全局状态. 因此, 本文件中的所有例程都提供强异常保证.

注释
  • 例程 is_partitioned 的基于迭代器的版本也是 C++11 标准的一部分.
  • 对于空范围和单元素范围, 无论传入什么谓词进行测试, is_partitioned 都返回 true.

is_permutation

头文件 'is_permutation.hpp' 包含单个算法 is_permutation 的六种变体. 该算法测试一个序列是否是另一个序列的排列; 换句话说, 它是否包含全部相同的成员, 只是顺序可能不同.

例程 is_permutation 接受两个序列和一个 (可选的) 谓词. 如果两个序列包含相同的成员, 它返回 true. 如果传入了谓词, 它会用谓词比较序列的元素, 判断它们是否相同.

is_permutation 有三种形式. 第一种接受两个迭代器定义第一个范围, 以及第二个范围的起始迭代器. 第二种形式接受两个迭代器定义第一个范围, 再用两个迭代器定义第二个范围. 第三种形式接受单个范围参数, 并使用 Boost.Range 来遍历.

接口

函数 is_permutation 在两个输入序列包含相同元素时返回 true. 共有六个版本: 两个接受三个迭代器, 两个接受四个迭代器, 另外两个接受两个范围.

一般来说, 应优先选用四迭代器版本而非三迭代器版本. 三迭代器版本必须在内部通过调用 std::advance(first2, std::distance(first1,last1)) 来"创建"第四个迭代器; 如果第二个序列比第一个短, 那就是未定义行为.

template< class ForwardIterator1, class ForwardIterator2 >
bool is_permutation ( ForwardIterator1 first1, ForwardIterator1 last1, ForwardIterator2 first2 );

template< class ForwardIterator1, class ForwardIterator2, class BinaryPredicate >
bool is_permutation ( ForwardIterator1 first1, ForwardIterator1 last1,
                      ForwardIterator2 first2, BinaryPredicate p );


template< class ForwardIterator1, class ForwardIterator2 >
bool is_permutation ( ForwardIterator1 first1, ForwardIterator1 last1, ForwardIterator2 first2, ForwardIterator2 last2 );

template< class ForwardIterator1, class ForwardIterator2, class BinaryPredicate >
bool is_permutation ( ForwardIterator1 first1, ForwardIterator1 last1,
                      ForwardIterator2 first2, ForwardIterator2 last2,
                      BinaryPredicate p );

template <typename Range, typename ForwardIterator>
bool is_permutation ( const Range &r, ForwardIterator first2 );

template <typename Range, typename ForwardIterator, typename BinaryPredicate>
bool is_permutation ( const Range &r, ForwardIterator first2, BinaryPredicate pred );

示例

给定容器 c1, 其中包含 { 0, 1, 2, 3, 14, 15 }, 以及 c2, 其中包含 { 15, 14, 3, 1, 2 }, 则

is_permutation ( c1.begin(),     c1.end (), c2.begin(), c2.end ()) --> false
is_permutation ( c1.begin() + 1, c1.end (), c2.begin(), c2.end ()) --> true

is_permutation ( c1.end (), c1.end (), c2.end(), c2.end ()) --> true  // all empty ranges are permutations of each other

迭代器要求

is_permutation 可用于前向迭代器或更好的迭代器.

复杂度

is_permutation 的所有变体都以 O(N^2) (平方) 时间运行; 也就是说, 它们对列表中的每个元素 (潜在地) 比较 N 次. 如果传入随机访问迭代器, 当两个序列大小不同时, is_permutation 可以快速返回.

异常安全

is_permutation 的所有变体都按值接受参数, 且不依赖任何全局状态. 因此, 本文件中的所有例程都提供强异常保证.

注释
  • 例程 is_permutation 的三迭代器版本也是 C++11 标准的一部分.
  • 例程 is_permutation 的四迭代器版本是 C++14 标准提案的一部分. 当 C++14 标准库可用时, 应将实现改为使用标准库中的实现 (如果有) .
  • 当传入一对空范围时, 无论传入什么谓词进行测试, is_permutation 都返回 true.

partition_point

头文件 'partition_point.hpp' 包含单个算法 partition_point 的两种变体. 给定一个已划分的序列和一个谓词, 该算法找出划分点; 即序列中第一个不满足谓词的元素.

例程 partition_point 接受一个已划分的序列和一个谓词. 它返回一个迭代器, "指向"序列中第一个不满足谓词的元素. 如果序列中所有元素都满足谓词, 则它返回序列最后一个元素之后的位置.

partition_point 有两种形式: 第一种接受两个迭代器来定义范围; 第二种接受单个范围参数, 并使用 Boost.Range 来遍历.

接口

有两个版本: 一个接受两个迭代器, 另一个接受一个范围.

template<typename ForwardIterator, typename Predicate>
	ForwardIterator partition_point ( ForwardIterator first, ForwardIterator last, Predicate p );
template<typename Range, typename Predicate>
	boost::range_iterator<Range> partition_point ( const Range &r, Predicate p );

示例

给定容器 c, 其中包含 { 0, 1, 2, 3, 14, 15 }, 则

bool lessThan10 ( int i ) { return i < 10; }
bool isOdd ( int i ) { return i % 2 == 1; }

partition_point ( c, lessThan10 ) --> c.begin () + 4  (pointing at 14)
partition_point ( c.begin (), c.end (), lessThan10 ) --> c.begin () + 4  (pointing at 14)
partition_point ( c.begin (), c.begin () + 3, lessThan10 ) -> c.begin () + 3 (end)
partition_point ( c.end (), c.end (), isOdd ) --> c.end ()  // empty range

迭代器要求

partition_point 要求前向迭代器或更好的迭代器; 它不能用于输入迭代器或输出迭代器.

复杂度

partition_point 的两种变体都以 O( log (N)) (对数) 时间运行; 也就是说, 谓词将被应用大约 log(N) 次. 然而, 要做到这一点, 算法需要知道序列的大小. 对于前向和双向迭代器, 计算序列大小是一项 O(N) 操作.

异常安全

partition_point 的两种变体都按值或 const 引用接受参数, 且不依赖任何全局状态. 因此, 本文件中的所有例程都提供强异常保证.

注释
  • 例程 partition_point 的基于迭代器的版本也是 C++11 标准的一部分.
  • 对于空范围, 划分点就是范围的末端.
