命名约定

描述 GIL 源代码、测试和示例中使用的既定命名约定.

具体类型

具体 (非泛型) 的 GIL 类型遵循以下命名约定:

ColorSpace + BitDepth + [f | s]+ [c] + [_planar] + [_step] + ClassType + _t

其中:

  • ColorSpace 表示布局和分量的顺序. 例如 rgb、bgr、cmyk、rgba.

  • BitDepth 表示颜色通道的位深. 例如 8、16、32.

  • 默认情况下, 通道类型是无符号整数. s 标记表示有符号整数. f 标记表示浮点类型, 它总是有符号的.

  • 默认情况下, 对象作用于可变像素. c 标记表示作用于不可变像素的对象.

  • _planar 表示平面式组织 (而非交织式).

  • _step 表示以非平凡方式遍历数据的特殊图像视图、定位器和迭代器. 例如反向遍历或每隔一个像素.

  • ClassType 是 _image (图像)、_view (图像视图)、_loc (像素二维定位器) _ptr (像素迭代器)、_ref (像素引用)、_pixel (像素值).

  • _t 后缀表示它是一个类型的名称.

例如:

bgr8_image_t             a;    // 8-bit interleaved BGR image
cmyk16_pixel_t           b;    // 16-bit CMYK pixel value;
cmyk16c_planar_ref_t     c(b); // const reference to a 16-bit planar CMYK pixel.
rgb32f_planar_step_ptr_t d;    // step pointer to a 32-bit planar RGB pixel.
