Boost 通用图像库

通用图像库 (GIL) 是一个 C++14 仅头文件库, 它将图像表示从算法中抽象出来, 允许编写能作用于多种图像的代码, 其性能与针对特定图像类型手写的代码相近.

示例

  • x_gradient.cpp: 编写作用于泛型图像的算法

  • dynamic_image.cpp: 使用属性 (色彩空间、通道类型) 在运行期指定的图像

  • histogram.cpp: 创建直方图

  • interleaved_ptr.cpp、interleaved_ptr.hpp、interleaved_ref.hpp: 创建自己的像素引用和像素迭代器

  • mandelbrot.cpp: 创建由函数定义的合成图像

  • packed_pixel.cpp: 定义位掩码以及通道或像素不按字节对齐的图像

  • resize.cpp: 使用双线性采样重缩放图像 (需要可选的 Numeric 扩展)

  • affine.cpp: 对图像应用仿射变换 (需要可选的 Numeric 扩展)

  • convolution.cpp: 模糊图像 (需要可选的 Numeric 扩展)
