详细说明

template<typename ChannelValue, typename Layout>
struct boost::gil::pixel< ChannelValue, Layout >

表示一个像素值 (通道的容器). 模型: HomogeneousColorBaseValueConcept、PixelValueConcept、HomogeneousPixelBasedConcept.

像素是定义图像中给定点颜色的一组通道. 从概念上讲, 像素与一个元素符合 ChannelConcept 的颜色基相差无几. 类 pixel 定义了一个简单的同质像素值, 用于存储颜色的值. 指向 pixel, pixel& 和 const pixel& 的内建 C++ 引用用于表示交织式图像视图 (所有通道在内存中位于一起的视图) 内部某个像素的引用. 类似地, 内建指针类型 pixel* 和 const pixel* 用作一行交织式同质像素上的标准迭代器.

由于 pixel 继承了颜色基的性质, 兼容的像素之间允许赋值、相等比较和拷贝构造. 这意味着 8 位 RGB 像素可以赋值给 8 位 BGR 像素或 8 位平面式引用. 各通道按语义正确配对.

pixel 类的单通道 (灰度) 实例化 (即 pixel<T,gray_layout_t>) 也可以与通道值相互转换. 这使得灰度像素可以用于更简单的表达式, 如 *gray_pix1 = *gray_pix2, 而不必使用更复杂的 at_c<0>(gray_pix1) = at_c<0>(gray_pix2) 或 get_color<gray_color_t>(gray_pix1) = get_color<gray_color_t>(gray_pix2)
