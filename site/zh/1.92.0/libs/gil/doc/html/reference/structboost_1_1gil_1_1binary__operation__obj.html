template<typename Derived, typename Result = void>
struct boost::gil::binary_operation_obj< Derived, Result >

视图上的泛型二元操作.

为任意图像视图定义操作时, 可将此类用作便利的超类. 当两个视图兼容时, 许多操作会有不同的行为. 此类检查兼容性并调用子类的 apply_compatible(V1,V2) 或 apply_incompatible(V1,V2). 你必须在子类中提供 apply_compatible(V1,V2) 方法, 而 apply_incompatible(V1,V2) 不是必需的, 默认实现会抛出 std::bad_cast.
