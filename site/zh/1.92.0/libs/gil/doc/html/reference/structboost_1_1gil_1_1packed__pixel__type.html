详细说明

template<typename BitField, typename ChannelBitSizes, typename Layout>
struct boost::gil::packed_pixel_type< BitField, ChannelBitSizes, Layout >

给定位域类型、其各通道的位大小及其布局, 返回打包像素的类型.

打包像素的通道覆盖位区间, 但像素本身按字节对齐. RGB565 像素即为一例.

ChannelBitSizes 的大小必须等于给定布局中的通道数. 所有通道的位大小之和必须小于或等于 BitField 的位数 (且不能超过 64). 若该和小于 BitField 的位数, 末尾的若干位将不被使用.
