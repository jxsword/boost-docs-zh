详细说明

适用于降采样的算法.

这些算法在用于降采样时效果最佳. 用于上采样可能得不到好的结果.

lanczos 降采样的单步操作

使用此算法把源图像缩放为质量合理的较小图像. 请务必查看一次输出, 因为结果可能存在振铃伪影.

完整的 Lanczos 算法.

此算法对结果图像做一次完整遍历, 并用原始图像的像素做卷积. 请注意, 查看测试输出可能是个好主意, 因为可能存在振铃伪影. 基于 wikipedia 文章: https://en.wikipedia.org/wiki/Lanczos_resampling, 使用标准化的基数正弦函数 (sinc)
