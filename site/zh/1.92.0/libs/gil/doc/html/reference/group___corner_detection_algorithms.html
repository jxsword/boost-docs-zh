用于查找图像中角点的算法.

这些算法用于从滑动窗口会产生较大强度变化的点中找出特征点

记录 Harris 响应的函数

此算法为由 m11、m12_21、m22 视图表示的结构张量计算 Harris 响应. 注意 m12_21 同时表示条目 (1, 2) 与 (2, 1). 窗口长度表示滑动窗口的大小, 用于计算相应条目之和. k 是相对边缘的判别常数 (通常在 0.04 到 0.06 之间). harris_response 是一个输出参数, 将包含 Harris 响应.
