详细说明

template<typename SrcP>
struct boost::gil::detail::nth_channel_deref_fn< SrcP >

返回给定引用第 N 个通道的灰度引用的函数对象. 符合: PixelDereferenceAdaptorConcept.

若输入为像素值或常量引用, 则该函数对象不可变; 否则为可变 (并返回第 n 个通道的非 const 引用)
