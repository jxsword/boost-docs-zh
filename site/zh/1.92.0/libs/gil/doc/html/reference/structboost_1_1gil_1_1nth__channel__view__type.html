template<typename View>
struct boost::gil::nth_channel_view_type< View >

给定源图像视图类型 View, 返回 View 的单个通道之上的图像视图的类型.

若源视图中的通道在内存中相邻 (如平面式无步进视图或单通道视图), 则返回视图是单通道无步进视图. 若通道不相邻 (交织式和/或步进视图), 则返回视图是单通道步进视图.
