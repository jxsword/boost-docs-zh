详细说明

template<typename... T>
类 boost::gil::histogram< T >

boost::gil 提供的默认直方图类.

该类继承自 STL 提供的 std::unordered_map. 关于如何使用该类的完整示例/教程见文档. 三维直方图的简单调用语法:

histogram<int, int , int> h;
h(1, 1, 1) = 0;

这只是它所能实现的功能的一个起点, 完整演示请参阅文档.
