详细说明

IP 算法的数学运算.

这主要是一组其他图像处理算法所需的数学运算

归一化基数正弦函数

normalized_sinc(x) = sin(pi * x) / (pi * x)

计算 xy 梯度以及二阶 x 与 y 梯度.

Hessian 矩阵定义为偏导数矩阵, 对二维情形为 [[ddxx, dxdy], [dxdy, ddyy]. d 表示导数, x 或 y 表示方向. 例如, dx 表示水平方向的导数 (梯度), ddxx 表示水平方向的二阶导数 https://en.wikipedia.org/wiki/Hessian_matrix

点 x 处的 Lanczos 响应.

Lanczos 响应定义为: x == 0: 1 -a < x && x < a: 0 其他情况: normalized_sinc(x) / normalized_sinc(x / a)
