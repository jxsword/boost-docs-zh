 对图像视图的每个像素应用固定阈值. 通过对给定图像视图的每个像素的通道值做阈值处理来执行图像二值化. 此 threshold_binary 变体会根据通道类型自动推导像素每个通道的最大值. 若 direction 为 regular, 大于 threshold_value 的值将被设为通道的数值上限, 否则设为 0. 若 direction 为 inverse, 大于 threshold_value 的值将被设为 0, 否则设为通道的数值上限.
