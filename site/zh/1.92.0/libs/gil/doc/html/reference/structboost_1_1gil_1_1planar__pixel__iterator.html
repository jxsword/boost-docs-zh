详细说明

template<typename ChannelPtr, typename ColorSpace>
struct boost::gil::planar_pixel_iterator< ChannelPtr, ColorSpace >

平面式像素之上的迭代器. 符合 HomogeneousColorBaseConcept, PixelIteratorConcept, HomogeneousPixelBasedConcept, MemoryBasedIteratorConcept, HasDynamicXStepTypeConcept.

平面式像素的通道数据在内存中不连续. 为对其进行抽象, 我们使用类来表示平面式像素的引用和指针.
