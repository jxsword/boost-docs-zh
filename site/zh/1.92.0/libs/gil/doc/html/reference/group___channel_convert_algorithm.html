详细说明

从一种通道类型转换为另一种.

转换按从一个通道范围到另一个通道范围的简单线性映射完成, 使源通道的最小/最大值映射到目标通道的最小/最大值. 这意味着有符号通道的值 0 可能不被保留!

在创建新的通道模型时, 为通道转换算法提供特化通常是个好主意, 例如用于性能优化. 如果新模型是可带符号的整数类型, 更容易的做法是只为无符号类型定义转换 (channel_converter_unsigned), 并提供 detail::channel_convert_to_unsigned 与 detail::channel_convert_from_unsigned 的特化来在有符号与无符号类型之间转换.

示例:

// float32_t 是取值范围 [0.0f ... 1.0f] 的浮点通道
float32_t src_channel = channel_traits<float32_t>::max_value();
assert(src_channel == 1);
// uint8_t 是 8 位无符号整数通道 (由 unsigned char 别名而来)
uint8_t dst_channel = channel_convert<uint8_t>(src_channel);
assert(dst_channel == 255); // 最大值映射到最大值
