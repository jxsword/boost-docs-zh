详细说明

判定 GIL 构造是否为基本构造. 基本构造是指可以用类型工厂方法 pixel_reference_type、iterator_type、locator_type、view_type 与 image_type 生成的构造. 它们可以是可变/不可变、平面式/交织式、带步进/不带步进的. 它们必须使用 GIL 提供的模型.
