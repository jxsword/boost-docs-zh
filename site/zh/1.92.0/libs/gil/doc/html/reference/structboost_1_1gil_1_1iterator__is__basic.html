template<typename Iterator>
struct boost::gil::iterator_is_basic< Iterator >

判定给定的像素迭代器是否为基础迭代器. 基础迭代器必须使用 gil::pixel (交织式时), gil::planar_pixel_iterator (平面式时) 和 gil::memory_based_step_iterator (步进时). 它们必须遵循标准的 const 性规则.
