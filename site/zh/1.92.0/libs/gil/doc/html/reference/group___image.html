详细说明

N 维容器.

图像是 N 维数据的容器. GIL 只提供一个模型: 二维图像, 其 value_type 是像素.

图像是常规类型 (即它们有默认构造函数、拷贝构造函数、operator=、operator==、operator!= 和 swap) 作为容器, 图像拥有其数据, 也就是说它们在构造函数中分配数据, 在析构函数中释放数据. 其拷贝构造、赋值与相等比较都是深层的 (即操作会传递到值上). 这使得图像按值传递代价高昂, 与视图不同.

而且与视图不同, 图像将其常量性传递给数据. 带 const 限定的图像不允许修改其像素, 也不提供其像素的可变视图.

图像提供两项服务: 管理其数据 (像素) 的所有权, 以及返回其像素上的视图. 算法主要在视图上操作. 这类似于 STL: STL 的容器 (如 std::vector) 提供范围 (vec.begin() 与 vec.end()), 算法通常在范围上操作. GIL 中与范围对应的是图像视图.
