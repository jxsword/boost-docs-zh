制作累积直方图

概述

累积直方图是这样一种直方图: 每个区间 (bin) 存储其自身的计数/频率, 以及所有键比该区间“小”的区间的计数/频率. 因此, 直方图中应存在键之间的排序概念.

GIL 的直方图类能够将自身转换为其累积版本.

由于容器需要先获得键上的排序, 因此在计算累积直方图之前会先进行键排序.

示例:

histogram<int, float> h;
/*
Fill histogram ...
*/
auto h1 = cumulative_histogram(h);

提示: 如果需要把累积直方图存储到别处, 请考虑先创建直方图的副本, 然后调用该函数.
