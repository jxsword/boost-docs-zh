说明

直方图类构建于 std::unordered_map 之上, 以保持与其他 STL 算法的兼容性. 它可以支持任意数量的轴 (在编译期即类实例化时确定). 从 GIL 图像构造到直方图区间键的适当转换例程随该类一同提供.

教程

建议采用以下流程:

  1. 创建直方图

  2. 填充直方图

  3. 制作子直方图

  4. 制作累积直方图

  5. STL 兼容性

  6. 扩展该类

  7. 限制

注释

要试用这些教程, 你需要克隆该仓库, 因为它尚未发布.
