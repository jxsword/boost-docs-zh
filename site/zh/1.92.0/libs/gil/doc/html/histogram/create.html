创建直方图

方法 1 - 使用直方图构造函数

语法:

histogram<Type1, Type2, Type3,... TypeN>

Type1 .. TypeN 对应直方图中 N 个轴的轴类型

示例: 如果我们想要一个三维直方图, 其 Axis1 为 int 类型, Axis2 为 float 类型, Axis3 为 std::string 类型, 可以这样做:

histogram<int, float, std::string> h;

这样就完成了.

方法 2 (TODO) - 使用 make_histogram()

还有一种替代方法可以直接从 GIL 图像视图创建直方图.

用 GIL 图像创建直方图时, 应优先选择此方法而非方法 1, 因为它创建的直方图其轴经过配置, 与 GIL 图像相匹配.

而且它比方法 1 更简单.

语法:

auto h = make_histogram(view(image));

其中 image 可以是从源读取的 gray8_image_t/rgb8_image_t 对象.
