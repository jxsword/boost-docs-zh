填充直方图

  • 概述

  • 基础

  • 高级

概述

我们将演示为 histogram 类的实例填充值的可用选项, 这些选项既能满足最简单的需求, 也能应对可能出现的复杂需求.

基础

  1. 使用 operator()

    任务 - 向直方图中特定的单元格/键/区间添加值

    histogram<int, int> h;
h(1, 2) = 1;

  2. 使用 operator[]

    这要求以直方图内部存储键的格式输入索引, 由于其接口简单, 该格式为 std::tuple.

    任务 - 输出某个区间的值

    histogram<int, int> h;
h(1, 2) = 1;
h[{1, 2}] += 1; // Note the curly braces reqd. to construct a tuple
std::cout<<h[{1, 2}]; // Output - 2

  3. 使用另一个直方图 (拷贝构造或赋值)

    任务 - 用另一个直方图填充直方图

    histogram<int, int> A;
/*
Fill value in A
*/
histogram<int, int> B(A), C;
C = A;

  4. 使用 GIL 图像视图

    也可以使用 GIL 图像直接填充直方图.

    任务 - 使用 GIL 图像视图填充直方图

    gil::gray8_image_t img;
/*
Fill img ...
*/
histogram<int> h;
h.fill(view(img));
// OR
gil::fill_histogram(view(img), h, false); // false if histogram needs to be cleared before filling

高级

  1. 只使用图像的少数几个维度填充直方图

    任务 - 对 rgb 图像的红色和蓝色通道建立直方图

    gil::rgb8_image_t img;
/*
Fill img ...
*/
histogram<int, int> h;
fill_histogram<0, 2>(view(img), h, false); // 0 - red, 1 - green, 2 - blue

  2. 使用 GIL 像素填充直方图

    任务 - 使用 GIL 中的像素构造填充直方图区间

    gil::gray8_image_t img;
/*
Fill img ...
*/
histogram<int> h;
gil::for_each_pixel(view(img), [](gil::gray8_pixel_t const& p){
    ++h[h.key_from_pixel(p)];
});
