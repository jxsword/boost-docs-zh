说明

除 Boost.GIL 提供的默认类之外, 还提供了使用外部容器的支持, 例如 std::vector、std::map、boost::histogram 等. 这些以扩展的形式提供.

扩展

目前可用的有以下几种:

  1. std::vector (1D 直方图支持)

  2. std::map (1D 直方图支持)

  3. std::array (1D 直方图支持)

  4. std::unordered_map (1D 直方图支持)

  5. boost::histogram

添加外部容器

工作流程应为:

  1. 在 extensions/histogram/ 中新建一个文件 (最好以容器类型命名), 为 fill_histogram (必须)、make_histogram (可选) 等提供重载.

  2. 在 test/extensions/histogram 中添加测试.

  3. 在 docs/histogram/extensions 中添加文档.

  4. 其他 cmake、Jamfile、config 等文件的改动.
