直方图匹配

说明

直方图匹配是一种使两幅图像的直方图相匹配的技术.

一个用例是: 同一地点的两幅图像在相同的局部光照下用不同传感器拍摄, 使两幅图像各自呈现出不同的特征.

著名的直方图均衡化是本算法的一个特例, 即参考图像被期望具有均匀直方图的情形.

算法

  1. 计算与输入图像和参考图像对应的直方图.

  2. 如果是多通道图像 (例如 RGB), 将两者都转换到独立的色彩空间 (如 YCbCr、HSV 等).

  3. 然后计算输入图像和参考图像的累积直方图.

  4. 对两个直方图都归一化, 使区间值介于 0-1 之间. 对于多通道图像, 对每个通道独立归一化 (按图像中的像素数).

  5. 如果输入图像的累积直方图为 H(px), 参考图像的累积直方图为 R(px'), px 与 px' 属于 [0, 255], 则应用变换 px' = R-1(H(px))

解释

由于我们要变换图像以匹配参考图像, 我们把图像的累积直方图与参考直方图的累积直方图相匹配.

因此,

=> R(px') = H(px)

=> px' = R-1(H(px))

演示

用法语法:

gray8_image_t inp_img, ref_img;
read_image("your_image.png", inp_img, png_tag{});
read_image("your_ref_image.png", ref_img, png_tag{});
gray8_image_t dst_img(inp_img.dimensions());
histogram_matching(view(inp_img), view(ref_image), view(dst_img));

// To specify mask over input image

vector<vector<bool>> mask(inp_img.height(), vector<bool>(inp_img.width(), true));
histogram_matching(view(inp_img), view(ref_image), view(dst_img), true, mask);

提示

在尝试直方图匹配算法之前, 先将 RGB 图像转换为通道独立的色彩空间.
