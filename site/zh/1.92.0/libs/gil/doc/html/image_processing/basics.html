基础

以下是一些基本概念, 有助于理解本文件夹中编写的文档.

卷积

最简单的理解方式是“对输入进行调整, 使其呈现出所提供的形状”. 具体应用何种调整取决于卷积核.

滤波器、卷积核、权重

这三个词通常指同一事物, 除非上下文明确表明是不同用法. 简单来说, 它们是一些矩阵, 用于在图像上实现某些效果. 我们来看一个简单的例子, 3x3 Scharr 滤波器

ScharrX = [1,0,-1][1,0,-1][1,0,-1]

上面的滤波器与单通道图像 (强度/亮度) 卷积后, 会产生 X (水平) 方向的梯度. 不过有些滤波无法用卷积核完成, 一个典型例子是中值滤波 (均值是算术平均, 而中值是有序数组的中间元素).

导数

图像的导数是两个方向之一上的梯度: x (水平) 和 y (垂直). 计算导数时可以使用 Scharr、Sobel 等梯度滤波器.

曲率

单独使用这个词时, 指的是如果把图像的取值绘制在三维图中将会产生的曲率. X 轴和 Z 轴 (构成水平面) 对应图像的 X 和 Y 索引, Y 轴对应该像素处的值. 稍加想象, 滤波器 (也称卷积核、权重) 可以被视为一幅图像 (或任意二维矩阵). 均值滤波器会画出一个平面, 而高斯滤波器会画出一座山丘, 山丘的陡峭程度取决于其 sigma 值.
