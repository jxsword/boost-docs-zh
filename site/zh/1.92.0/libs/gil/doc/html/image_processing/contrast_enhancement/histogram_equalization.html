直方图均衡化

说明

直方图均衡化也称直方图平坦化, 是一种非线性图像增强算法, 其思想是: 图像不仅应覆盖整个灰度空间, 还应在该范围内均匀分布.

理想的图像是具有平坦直方图的图像.

尽管在对图像直方图应用非线性变换之前应当谨慎, 但平坦直方图之所以是理想目标, 是有充分的数学原因的.

一个简单的场景是像素集中在一个区间内的图像, 此时直方图均衡化通过变换像素来实现平坦的直方图, 从而增强图像对比度.

算法

  1. 首先计算与输入图像对应的直方图.

  2. 如果是多通道图像 (例如 RGB), 先将其转换到独立的色彩空间 (如 YCbCr、HSV 等).

  3. 然后计算输入图像的累积直方图.

  4. 对直方图归一化, 使区间值介于 0-1 之间. 对于多通道图像, 对每个通道独立归一化 (按图像中的像素数).

  5. 如果图像的直方图为 H(px), px 属于 [0, 255], 则应用变换 px' = H(px), 其中 px' 是输出图像中的像素.

解释

由于我们要变换图像以匹配平坦直方图, 我们把图像的累积直方图与平坦直方图的累积直方图相匹配.

平坦图像的累积直方图为 H(px') = px' .

因此,

=> H(px') = H(px)

=> px' = H(px)
