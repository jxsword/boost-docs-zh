仿射区域检测器

检测的是什么?

仿射区域基本上是图像中在仿射变换下保持稳定的任何区域. 它可以是在仿射条件下的边缘、角点 (图像的一小块区域) 或任何其他稳定特征.

可用的检测器

目前已实现以下检测器

  • Harris 检测器

  • Hessian 检测器

这是理解两个角点检测器如何工作的关键概念.

两种算法具有相同的结构:

  1. 计算图像导数

  2. 计算加权和

  3. 计算响应

  4. 阈值处理 (可选)

Harris 与 Hessian 的区别在于它们计算的导数不同. Harris 计算以下导数:

HarrisMatrix = [(dx)^2, dxdy], [dxdy, (dy)^2]

(注意 d(x^2) 和 (dy^2) 是数值幂, 而不是梯度).

为了简化实现, 可以把矩阵的三个不同项分离成三幅图像. 而 Hessian 计算的是二阶导数:

HessianMatrix = [dxdx, dxdy][dxdy, dydy]

加权和对两者而言是相同的. 通常使用高斯模糊矩阵作为权重, 因为角点在梯度中应具有类似山丘的曲率, 而其他权重可能有噪声. 基本做法是: 把权重矩阵覆盖在角点上, 对 s[i,j]=image[x + i, y + j] * weights[i, j] 在 i, j 从零到权重矩阵维度的范围内求和, 然后移动窗口并重新计算, 直到覆盖整幅图像.

响应计算是一种选择. 给定上述两个矩阵的一般形式

[a, b][c, d]

其中一个响应函数是

response = det - k * trace^2 = a * c - b * d - k * (a + d)^2

k 称为判别常数. 常用取值为 0.04 - 0.06.

另一个就是行列式

response = det = a * c - b * d

阈值处理是可选的, 但没有它结果会充满噪声. 对于复杂的图像 (如户外图像), Harris 的阈值将在 100000000 量级, 而 Hessian 将在 10000 量级. 对于较简单的图像, 100 到 1000 量级的值应该就够了. 这些数字假定是 uint8_t 灰度图像.
