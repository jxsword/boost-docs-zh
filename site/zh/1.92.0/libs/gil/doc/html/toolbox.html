ToolBox 扩展

概述

ToolBox 收录了一组 Boost.GIL 扩展, 它们规模太小, 不值得作为独立扩展维护.

Content:

  • 颜色转换器: Gray 到 RGBA

  • 色彩空间: CMYKA, 带 Alpha 的 Gray, HSL, HSV, Lab, XYZ

  • Metafunctions:

    • channel_type

    • channel_type_to_index

    • get_num_bits

    • get_pixel_type

    • is_bit_aligned

    • is_homogeneous

    • is_similar

    • pixel_bit_size

  • 图像类型:

    • indexed_image

希望社区今后能为该扩展添砖加瓦.

由于该扩展是仅头文件库, 用户只需包含其主头文件 #include <boost/gil/extension/toolbox.hpp>.

toolbox 的所有定义都属于 boost::gil 命名空间.

目录结构

toolbox 按以下子目录组织:

  • color_converters

  • color_spaces

  • metafunctions

  • image_types
