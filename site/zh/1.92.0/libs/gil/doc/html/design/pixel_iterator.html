概述

像素迭代器是随机遍历迭代器, 其 value_type models PixelValueConcept.

基础迭代器

像素迭代器提供一些元函数, 用于判断它们是否可变 (即是否允许修改其所引用的像素), 获取该迭代器的不可变 (只读) 类型, 以及判断它们是普通迭代器还是另一像素迭代器之上的适配器:

concept PixelIteratorConcept<RandomAccessTraversalIteratorConcept Iterator>
    : PixelBasedConcept<Iterator>
{
  where PixelValueConcept<value_type>;
  typename const_iterator_type<It>::type;
      where PixelIteratorConcept<const_iterator_type<It>::type>;
  static const bool  iterator_is_mutable<It>::value;
  static const bool  is_iterator_adaptor<It>::value;   // is it an iterator adaptor
};

template <typename Iterator>
concept MutablePixelIteratorConcept : PixelIteratorConcept<Iterator>, MutableRandomAccessIteratorConcept<Iterator> {};

  • PixelIteratorConcept<Iterator>

  • MutablePixelIteratorConcept<Iterator>

模型

指向像素的内置指针 pixel<ChannelValue,Layout>* 是 GIL 在交织式同质像素上的像素迭代器模型. 类似地, packed_pixel<PixelData,ChannelRefVec,Layout>* 是 GIL 在交织式打包像素上的迭代器模型.

对于平面式同质像素, GIL 提供了类 planar_pixel_iterator, 它以通道迭代器和色彩空间为模板参数. 下面是 unsigned char 上标准可变和只读平面式 RGB 迭代器的定义方式:

template <typename ChannelPtr, typename ColorSpace>
struct planar_pixel_iterator;

// GIL provided typedefs
typedef planar_pixel_iterator<const bits8*, rgb_t> rgb8c_planar_ptr_t;
typedef planar_pixel_iterator<      bits8*, rgb_t> rgb8_planar_ptr_t;

planar_pixel_iterator 也是 HomogeneousColorBaseConcept 的模型 (它继承自 homogeneous_color_base), 因此所有颜色基算法都适用于它. 其颜色基的元素类型是通道迭代器. 例如, GIL 实现平面式迭代器的 operator++ 大致如下:

template <typename T>
struct inc : public std::unary_function<T,T>
{
  T operator()(T x) const { return ++x; }
};

template <typename ChannelPtr, typename ColorSpace>
planar_pixel_iterator<ChannelPtr,ColorSpace>&
planar_pixel_iterator<ChannelPtr,ColorSpace>::operator++()
{
  static_transform(*this,*this,inc<ChannelPtr>());
  return *this;
}

由于 static_transform 使用编译期递归, 递增一个 rgb8_planar_ptr_t 实例相当于三次指针递增. GIL 还使用类 bit_aligned_pixel_iterator 作为位对齐像素上像素迭代器的模型. 它在内部记录当前字节和位偏移.

迭代器适配器

迭代器适配器是包装另一个迭代器的迭代器. 它的 is_iterator_adaptor 元函数必须求值为 true, 并且它需要提供一个返回基础迭代器的成员方法、一个获取其类型的元函数, 以及一个重绑定到另一基础迭代器的元函数:

concept IteratorAdaptorConcept<RandomAccessTraversalIteratorConcept Iterator>
{
  where SameType<is_iterator_adaptor<Iterator>::type, mp11::mp_true>;

  typename iterator_adaptor_get_base<Iterator>;
      where Metafunction<iterator_adaptor_get_base<Iterator> >;
      where boost_concepts::ForwardTraversalConcept<iterator_adaptor_get_base<Iterator>::type>;

  typename another_iterator;
  typename iterator_adaptor_rebind<Iterator,another_iterator>::type;
      where boost_concepts::ForwardTraversalConcept<another_iterator>;
      where IteratorAdaptorConcept<iterator_adaptor_rebind<Iterator,another_iterator>::type>;

  const iterator_adaptor_get_base<Iterator>::type& Iterator::base() const;
};

template <boost_concepts::Mutable_ForwardIteratorConcept Iterator>
concept MutableIteratorAdaptorConcept : IteratorAdaptorConcept<Iterator> {};

参见

  • IteratorAdaptorConcept<Iterator>

  • MutableIteratorAdaptorConcept<Iterator>

模型

GIL 提供了 IteratorAdaptorConcept 的几个模型:

  • memory_based_step_iterator<Iterator>: 改变基础迭代器的基本步长的迭代器适配器 (见 Step Iterator)

  • dereference_iterator_adaptor<Iterator,Fn>: 在解引用时应用一元函数 Fn 的迭代器. 例如, 它用于即时颜色转换. 它可以用来构造一个假装具有不同色彩空间或通道深度的浅层图像“视图”. 更多内容见 Image View. 该一元函数 Fn 必须是 PixelDereferenceAdaptorConcept 的模型 (见下文).

像素解引用适配器

像素解引用适配器是可在解引用像素迭代器时应用的一元函数. 其参数类型可以是任何类型 (通常是 PixelConcept), 而结果类型必须可转换为 PixelConcept:

template <boost::UnaryFunctionConcept D>
concept PixelDereferenceAdaptorConcept:
    DefaultConstructibleConcept<D>,
    CopyConstructibleConcept<D>,
    AssignableConcept<D>
{
  typename const_t;         where PixelDereferenceAdaptorConcept<const_t>;
  typename value_type;      where PixelValueConcept<value_type>;
  typename reference;       where PixelConcept<remove_reference<reference>::type>;  // may be mutable
  typename const_reference;   // must not be mutable
  static const bool D::is_mutable;

  where Convertible<value_type, result_type>;
};

模型

GIL 提供了 PixelDereferenceAdaptorConcept 的几个模型:

  • color_convert_deref_fn: 执行颜色转换的函数对象

  • detail::nth_channel_deref_fn: 返回给定像素第 n 个通道对应的灰度像素的函数对象

  • deref_compose: 组合两个 PixelDereferenceAdaptorConcept 模型的函数对象. 与 std::unary_compose 类似, 不同之处在于它需要提取额外 typedef 以满足 PixelDereferenceAdaptorConcept

GIL 使用像素解引用适配器来实现解引用时执行颜色转换或返回底层像素第 N 个通道的图像视图. 它们还可以用来对解引用时执行任意函数的虚拟图像视图建模, 例如 Mandelbrot 集合的视图. dereference_iterator_adaptor<Iterator,Fn> 是像素迭代器 Iterator 之上的迭代器包装, 它在解引用时调用给定的解引用迭代器适配器 Fn.

步进迭代器

有时我们希望以不同于基本像素迭代器所提供的单位步长来遍历像素. 这会有用的例子包括:

  • RGB 交织式图像红色通道的单通道视图

  • 从左到右翻转的图像 (step = -fundamental_step)

  • 下采样视图, 每隔 N 个像素取一个 (step = N*fundamental_step)

  • 沿垂直方向遍历 (step = 每行字节数)

  • 上述情况的任意组合 (步长相乘)

步进迭代器是前向遍历迭代器, 允许改变相邻值之间的步长:

concept StepIteratorConcept<boost_concepts::ForwardTraversalConcept Iterator>
{
  template <Integral D> void Iterator::set_step(D step);
};

concept MutableStepIteratorConcept<boost_concepts::Mutable_ForwardIteratorConcept Iterator>
    : StepIteratorConcept<Iterator>
{};

GIL 目前提供的步进迭代器, 其 value_type models PixelValueConcept. 此外, 步长以内存单位 (字节或位) 指定. 例如, 在实现沿像素列导航的迭代器时这是必要的 - 一行像素的大小有时可能不能被单个像素的大小整除; 例如各行可能是字对齐的.

要以字节/位为单位前进, 基础迭代器必须是 MemoryBasedIteratorConcept 的模型. 基于内存的迭代器有一个固有的内存单位, 要么是位, 要么是字节. 它必须提供以下函数: 返回每个内存单位的位数 (1 或 8)、以内存单位表示的当前步长、两个迭代器之间以内存单位表示的距离, 以及距给定位置指定 memunit 距离处的引用. 它还必须提供一个使迭代器前进指定内存单位距离的函数. memunit_advanced 和 memunit_advanced_ref 有默认实现, 但某些迭代器可能提供更高效的版本:

concept MemoryBasedIteratorConcept
<
    boost_concepts::RandomAccessTraversalConcept Iterator
>
{
  typename byte_to_memunit<Iterator>; where metafunction<byte_to_memunit<Iterator> >;
  std::ptrdiff_t      memunit_step(const Iterator&);
  std::ptrdiff_t      memunit_distance(const Iterator& , const Iterator&);
  void                memunit_advance(Iterator&, std::ptrdiff_t diff);
  Iterator            memunit_advanced(const Iterator& p, std::ptrdiff_t diff) { Iterator tmp; memunit_advance(tmp,diff); return tmp; }
  Iterator::reference memunit_advanced_ref(const Iterator& p, std::ptrdiff_t diff) { return *memunit_advanced(p,diff); }
};

能够在另一个迭代器之上构造步进迭代器是很有用的. 更一般地, 给定一个类型, 我们希望能够构造一个允许动态指定水平步长的等价类型:

concept HasDynamicXStepTypeConcept<typename T>
{
  typename dynamic_x_step_type<T>;
      where Metafunction<dynamic_x_step_type<T> >;
};

GIL 提供的像素迭代器、定位器和图像视图的所有模型都支持 HasDynamicXStepTypeConcept.

参见

  • StepIteratorConcept<Iterator>

  • MutableStepIteratorConcept<Iterator>

  • MemoryBasedIteratorConcept<Iterator>

  • HasDynamicXStepTypeConcept<T>

模型

GIL 目前提供的所有标准基于内存的迭代器都是 MemoryBasedIteratorConcept 的模型. GIL 提供类 memory_based_step_iterator, 它是 PixelIteratorConcept、StepIteratorConcept 和 MemoryBasedIteratorConcept 的模型. 它以基础迭代器为模板参数 (该参数必须是 PixelIteratorConcept 和 MemoryBasedIteratorConcept 的模型), 并允许动态改变步长. GIL 实现中包含基础迭代器和一个 ptrdiff_t, 后者表示一个单位步长要跳过的内存单位数 (字节或位). 它也可以取负数. GIL 提供一个函数, 用基础迭代器和步长创建步进迭代器:

// Iterator models MemoryBasedIteratorConcept, HasDynamicXStepTypeConcept
template <typename Iterator>
typename dynamic_x_step_type<Iterator>::type make_step_iterator(Iterator const& it, std::ptrdiff_t step);

GIL 还提供了虚拟像素数组上迭代器的一个模型 position_iterator. 它是一个步进迭代器, 记录像素位置, 并在解引用时调用函数对象获取像素的值. 它是 PixelIteratorConcept 和 StepIteratorConcept 的模型, 但不是 MemoryBasedIteratorConcept 的模型.
