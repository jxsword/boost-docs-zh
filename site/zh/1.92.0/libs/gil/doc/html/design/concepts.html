概念

GIL 中的所有构造都是 GIL 概念的模型. 概念是一组要求, 一个类型 (或一组相关类型) 必须满足这些要求才能在泛型算法中正确使用. 这些要求包括语法和算法上的保证. 例如, GIL 类 pixel 是 GIL PixelConcept 的一个模型. 用户可以用自己的像素类替换该像素类, 只要它满足 PixelConcept 的要求, 所有其他 GIL 类和算法都可以与之配合使用. 关于概念的更多内容参见 Generic Programming in ConceptC++

本文档将使用 C++ 标准提案文件 [N2081] Concepts 中描述的概念定义语法.

以下是 GIL 将用到的一些常见概念. 其中大多数定义于 ConceptC++ Concept Web:

auto concept DefaultConstructible<typename T>
{
    T::T();
};

auto concept CopyConstructible<typename T>
{
    T::T(T);
    T::~T();
};

auto concept Assignable<typename T, typename U = T>
{
    typename result_type;
    result_type operator=(T&, U);
};

auto concept EqualityComparable<typename T, typename U = T>
{
    bool operator==(T x, U y);
    bool operator!=(T x, U y) { return !(x==y); }
};

concept SameType<typename T, typename U> { /* unspecified */ };
template<typename T> concept_map SameType<T, T> { /* unspecified */ };

auto concept Swappable<typename T>
{
    void swap(T& t, T& u);
};

以下是 GIL 需要的一些其他基础概念:

auto concept Regular<typename T> :
    DefaultConstructible<T>,
    CopyConstructible<T>,
    EqualityComparable<T>,
    Assignable<T>,
    Swappable<T>
{};

auto concept Metafunction<typename T>
{
    typename type;
};
