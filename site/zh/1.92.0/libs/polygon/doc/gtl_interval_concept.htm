区间概念

区间概念的标签是 interval_concept

要将用户自定义类型注册为区间概念的模型, 需为该类型特化 geometry concept 元函数. 在下例中, CInterval 被注册为区间概念的一个模型.

template <>
struct geometry_concept<CInterval> { typedef interval_concept type; };

区间的语义是: 它有一个低坐标和一个高坐标, 且存在不变式 low 小于等于 high. 该不变式由操作区间的泛型库函数强制执行, 并不要求数据类型本身或该数据类型通过特征到区间概念的概念映射来满足. 这样, std::pair<int, int>、boost::tuple<int, int> 或 boost::array<int, 2> 只需通过特征提供对其元素的间接访问, 就都可以成为区间的模型.

下面展示了默认的区间特征. 不符合默认行为的类型需要对这组特征进行特化.

template <typename T>
struct interval_traits {
  typedef typename T::coordinate_type coordinate_type;

  static inline coordinate_type get(const T& interval, direction_1d dir) {
    return interval.get(dir);
  }
};

template <typename T>
struct interval_mutable_traits {
  typedef typename T::coordinate_type coordinate_type;

  static inline void set(T& interval, direction_1d dir,
                         typename interval_traits<T>::coordinate_type value) {
    interval.set(dir, value);
  }
  static inline T construct(typename interval_traits<T>::coordinate_type low_value,
                            typename interval_traits<T>::coordinate_type high_value) {
    return T(low_value, high_value);
  }
};

区间数据

库提供了一个区间概念模型, 声明为template<typename T> interval_data , 其中 T 为坐标类型.

当需要区间时, 库内部会使用该数据类型; 库用户如果觉得使用库的区间数据类型比自己提供更方便, 也可以使用它. 该数据类型的实现便于与库特征配合使用.
