Polygon 赞助者

45 度连通性提取

连通性提取算法构建连通图, 其中输入多边形集合被建模为图节点并分配节点 id, 输入多边形集合之间的重叠/接触则被建模为图边. 受支持的图格式之一是 std::vector<std::set<int> >, 其中节点 id 作为向量索引, 每个索引处的整数集合是图中存在边的那些节点的 id. 要求该向量预先分配足够的元素来存储算法生成的图, 因为内部仅使用 operator[] 来访问图. 另一种受支持的图格式是 std::map<int, std::set<int> >, 它稍微更易使用, 但可能开销更高. 改进接口以支持更泛化的图概念的工作留待后续完成.

下面是连通性提取算法的声明.

template <typename coordinate_type>
class connectivity_extraction_45;

示例代码 connectivity_extraction_usage.cpp 演示了如何使用连通性提取算法在几何对象上构建连通图.

connectivity_extraction_45(
     const connectivity_extraction_45& that)		 拷贝构造.
unsigned int
insert(const polygon_45_set_data<coordinate_type>& ps)		 插入一个多边形集合图节点, 返回值为该图节点的 id.
template <class GeoObjT>
unsigned int insert(const GeoObjT& geoObj)		 插入一个 Polygon 45 集合细化类型的几何对象作为图节点, 返回值为该图节点的 id.
template <class GraphT>
void extract(GraphT& graph)		 接受一个符合上述要求的图对象. 执行连通性提取并填充该图对象.
