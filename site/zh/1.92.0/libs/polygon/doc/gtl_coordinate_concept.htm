坐标概念

坐标概念的标签是 coordinate_concept

要将用户自定义类型注册为坐标概念的模型, 需为该类型特化 geometry concept 元函数. 在下例中, CCoordinate 被注册为坐标概念的一个模型.

template <>
struct geometry_concept<CCoordinate> { typedef coordinate_concept type; };

坐标类型应为整型, 库中已为 float 和 int 等内建数值数据类型提供了概念类型特征的特化. coordinate traits 中为相关类型提供了类型定义, 使库能够在各种情形下选择最佳的转换目标类型. coordinate_traits 的定义及其针对 int 的特化如下所示.

template <typename T>
struct coordinate_traits {};

template <>
struct coordinate_traits<int> {
     typedef int coordinate_type;
     typedef long double area_type;
     typedef long long manhattan_area_type;
     typedef unsigned long long unsigned_area_type;
     typedef long long coordinate_difference;
     typedef long double coordinate_distance;
};

通过利用 int 的 coordinate traits, 库能够避免溢出, 并处理整数几何编程中遇到的常见问题. 对于不寻常的问题, 有一个特殊的元函数为库提供适合精确数值计算的数值类型. 其默认值是多数编译器中精度最高的数据类型 long double, 但可以通过对特定坐标类型进行特化来覆盖. 在通用多边形算法中进行数值稳健的计算时, 建议使用 gmp 多精度有理数或类似数据类型.

template <typename T>
struct high_precision_type {
     typedef long double type;
};

坐标概念上只有一个泛型函数: 欧氏距离.

template <typename coordinate_type_1, typename coordinate_type_2>
coordinate_difference euclidean_distance(coordinate_type_1, coordinate_type_2)

该函数返回两个坐标之差的绝对值.

注释: 旧版本的 STL 定义了一个完全泛化的 distance(T, T) 函数, 用于计算两个迭代器之间的差值. 为避免命名冲突, 我们被迫将距离函数命名为 euclidean_distance.

该 Algorithmic C 的 ac_int<128> 是满足坐标概念的用户自定义坐标数据类型的一个示例. 一般而言, 数据类型应定义 std::numeric_limits 并且行为类似整数. 并非所有算法都支持浮点坐标类型, 浮点坐标类型目前通常也不适合与本库一同使用.
