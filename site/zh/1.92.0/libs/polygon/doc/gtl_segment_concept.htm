线段概念

线段概念的标签是segment_concept

要将用户自定义类型注册为线段概念的模型, 需为该类型特化 geometry concept 元函数. 在下例中, CSegment 被注册为线段概念的一个模型.

template <>
struct geometry_concept<CSegment> { typedef segment_concept type; };

线段的语义是: 它有一个低端点和一个高端点. std::pair<Point, Point>、boost::tuple<Point, Point> 或 boost::array<Point, 2> 都可以通过特征提供对其元素的间接访问而成为线段的模型, 然而, 这些对象不能在同一个编译单元中既成为线段的模型又成为矩形的模型, 原因显而易见: 对 geometry_concept 结构体的重复特化是非法的, 而且如果同一个类型建模多个概念, 也会使按概念重载泛型函数产生歧义.

下面展示了默认的线段特征. 不符合默认行为的类型需要对这组特征进行特化.

template <typename Segment>
struct segment_traits {
  typedef typename Segment::coordinate_type coordinate_type;
  typedef typename Segment::point_type point_type;

  static inline point_type get(const Segment& segment, direction_1d dir) {
    return segment.get(dir);
  }
};

template <typename Segment>
struct segment_mutable_traits {
  typedef typename segment_traits<Segment>::coordinate_type coordinate_type;
  typedef typename segment_traits<Segment>::point_type point_type;

  static inline void set(Segment& segment, direction_1d dir, const point_type& point) {
    segment.set(dir, p);
  }

  static inline Segment construct(const point_type& low, const point_type& high) {
    return Segment(low, high);
  }
};

线段数据

库提供了一个线段概念模型, 声明为template<typename T> segment_data, 其中 T 为坐标类型.

当需要线段时, 库内部会使用该数据类型, 库用户如果觉得使用库的线段数据类型比自己提供更方便, 也可以使用它. 该数据类型的实现便于与库特征配合使用.

线段工具

库提供了几个用于操作线段数据集合的算法. 特别是, 多边形集合运算所使用的泛化线段求交算法通过几个接口公开, 使其可用于任何建模 segment_concept 的对象集合或序列.

函数

template <typename SegmentContainer,
          typename SegmentIterator>
void intersect_segments(
    SegmentContainer* result,
    SegmentIterator first,
    SegmentIterator last) 		把迭代器范围内的线段在其交点处拆分, 并把拆分结果累加到结果容器中. 前置条件: 所有输入结构所使用的线段类型应建模线段概念. 后置条件: 除端点外没有任何线段相交. 可用于满足 voronoi 图构建的前置条件. 关于顶点数 + 交点数, 预期运行期为 n log n, 最坏情形为二次方.
template <typename Segment,
          typename SegmentIterator>
void intersect_segments(
    vector<pair<size_t, Segment>* result,
    SegmentIterator first,
    SegmentIterator last)		 把迭代器范围内的线段在其交点处拆分, 并把拆分结果累加到结果容器中. 前置条件: 所有输入结构所使用的线段类型应建模线段概念. 后置条件: 除端点外没有任何线段相交. 输入线段的索引与其拆分产生的每个结果线段配对, 从而把结果线段与输入线段关联起来. 关于顶点数 + 交点数, 预期运行期为 n log n, 最坏情形为二次方.
template <typename Rectangle,
          typename SegmentIterator>
void envelope_segments(
    Rectangle* rect,
    SegmentIterator first,
    SegmentIterator last) 		计算线段迭代器范围的包围矩形. 前置条件: 输入结构所使用的线段类型与矩形类型应分别建模线段概念与矩形概念. 线性运行期.
