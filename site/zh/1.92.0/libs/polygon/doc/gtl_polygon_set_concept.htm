多边形集合概念

polygon_set 概念的标签是 polygon_set_concept

polygon_set 的语义是: 零个或多个几何区域. 多边形集合概念可以用浮点坐标定义, 但仍会应用一个整数单位的吸附取整距离; 此外, 若几何位于一个整数单位不足以保证稳健性的范围内, 则可能在算法中导致未定义行为. 建议使用整数坐标以获得稳健的操作. 在所表示的数据只含 Manhattan 几何的情形下, 运行期检查会退回到 Manhattan 算法; 其结果与一般算法所得相同, 但效率更高. 在所表示的数据只含 Manhattan 与 45 度几何的情形下, 运行期检查会退回到更快的 45 度算法; 其结果可能与一般算法所得略有差异, 因为非整数交点的处理方式不同.

建议用户使用用户自定义多边形的 std::vector 与 std::list, 或库提供的 polygon_set_data<coordinate_type> 对象. polygon_concept 或 polygon_with_holes_concept 模型的 list 和 vector 会自动成为 polygon_set_concept 的模型.

示例代码 custom_polygon_set.cpp 演示了如何把用户自定义类映射到库的 polygon_set_concept

如果经运行期判定符合相关概念的约束, polygon_set_concept 模型的对象可以被视作 polygon_90_set_concept 或 polygon_45_set_concept 的模型. 这种概念转换通过view_as<>() 函数完成.

view_as<polygon_90_set_concept>(polygon_set_object)
view_as<polygon_45_set_concept>(polygon_set_object)

view_as<>() 的返回值可以传入任何期望其模板参数所指概念类型对象的接口. 多边形集合不能被视作单个多边形或矩形, 因为一般而言, 不把多边形集合转换为多边形就无法知道它是否只含单个多边形.

Operators

某些运算符的返回类型是polygon_set_view 运算符模板类型. 该类型本身就是 polygon 90 集合概念的一个模型, 此外还可用作polygon_set_data 构造函数与赋值运算符的实参. 运算符模板的存在是为了在布尔运算符链接在一起时消除中间结果的临时拷贝.

多边形集合数据对象

polygon 集合数据类型封装了作为实现多边形裁剪布尔运算的扫描线算法输入的内部数据格式. 它还在内部跟踪该数据是否已被排序或扫描, 并维护这样的不变式: 当其标志表明数据已排序或已扫描时, 数据未被改变以致违反该假设. 在上述函数中直接使用 Polygon Set Data 类型可能比使用多边形的 list 和 vector 更高效, 因为它能强制执行一些不变式, 从而有机会让数据保持已排序形式, 而不必一路转换到多边形、再为后续操作重新排序那些顶点.

Polygon Set Data 的声明如下:

template <typename T>
class polygon_set_data;

该类以坐标数据类型为参数. 受益于了解该类所强制不变式的算法以成员函数形式实现, 使其能够访问关于这些不变式的信息.
