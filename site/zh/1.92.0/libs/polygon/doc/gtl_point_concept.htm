点概念

点概念的标签是 point_concept

要将用户自定义类型注册为点概念的模型, 需为该类型特化 geometry concept 元函数. 在下例中, CPoint 被注册为点概念的一个模型.

template <>
struct geometry_concept<CPoint> { typedef point_concept type; };

点的语义是: 它有一个 x 坐标和一个 y 坐标. std::pair<int, int>、boost::tuple<int, int> 或 boost::array<int, 2> 只需通过特征提供对其元素的间接访问, 就都可以成为点的模型. 但是, 这些对象无法在同一个编译单元中同时成为点与区间的模型——明显的原因是对 geometry_concept struct 的重复特化是非法的, 还有一个原因: 如果一个类型建模多个概念, 按概念重载泛型函数就会产生歧义.

下面展示了默认的点特征. 不符合默认行为的类型需要对这组特征进行特化.

template <typename T>
struct point_traits {
     typedef typename T::coordinate_type coordinate_type;

     static coordinate_type get(const T& point, orientation_2d orient) {
          return point.get(orient);
     }
};

template <typename T>
struct point_mutable_traits {
     typedef typename T::coordinate_type coordinate_type;

     static void set(T& point, orientation_2d orient, typename point_traits<T>::coordinate_type value) {
          point.set(orient, value);
     }
     static T construct(typename point_traits<T>::coordinate_type x_value,
                        typename point_traits<T>::coordinate_type y_value) {
          return T(x_value, y_value);
     }
};

点数据

库提供了一个点概念模型, 声明为template<typename T> point_data , 其中 T 为坐标类型.

当需要点时, 库内部会使用该数据类型; 库用户如果觉得使用库的点数据类型比自己提供更方便, 也可以使用它. 该数据类型的实现便于与库特征配合使用.

示例代码 point_usage.cpp 演示了如何使用库提供的点数据类型与函数
