45 度属性合并

下面是属性合并算法的声明.

template <typename coordinate_type, typename property_type>
class property_merge_45;

属性算法计算输入多边形集合的 n 层地图叠加. 每个输入几何随同属性值一起插入. 属性类型可以是任何适合用作 std::set 元素的类型. 多个几何对象可以用相同的属性值分别插入. 要存储此操作的结果需要一个相当复杂的容器. 结果几何与输入几何属性值的唯一子集相关联. 两个适合存储属性合并操作结果的容器是:

std::map<std::set<property_type>, polygon_45_set_data<coordinate_type> >
std::map<std::vector<property_type>, polygon_45_set_data<coordinate_type> >

示例代码 property_merge_usage.cpp 演示了如何对 polygon 90 数据使用 n 层地图叠加算法.

成员函数

property_merge_45() 默认构造函数.
property_merge_45(const property_merge_45& that) 拷贝构造.
void
insert(const polygon_45_set_data<coordinate_type>& ps,
       const property_type& property)		 插入一个带有关联属性的多边形集合. 与所插入顶点数呈线性.
template <class GeoObjT>
void insert(const GeoObjT& geoObj,
       const property_type& property)		 插入一个带有关联属性的、Polygon 45 集合细化类型的几何对象. 与所插入顶点数呈线性.
template <typename result_type>
void merge(result_type& result)		 接受一个符合上述要求的容器对象. 执行属性合并并填充该容器对象. 关于顶点数 + 交点数, 运行期为 O(n log n).
