Polygon 90 概念

polygon_90 概念的标签是 polygon_90_concept

要将用户自定义类型注册为 polygon_90 概念的模型, 需为该类型特化 geometry concept 元函数. 在下例中, CPolygon90 被注册为 polygon_90 概念的一个模型.

template <>
struct geometry_concept<CPolygon90> { typedef polygon_90_concept type; };

polygon_90 的语义是: 它能提供遍历与其水平和垂直边对应的 x、y 坐标的迭代器, 从一个 x 坐标开始. 可变 polygon_90 还必须能够基于这类坐标上的迭代器范围设置其几何形状. 由于多数多边形在内部存储中使用顶点, iterator_points_to_compact.hpp 和 iterator_compact_to_points.hpp 中提供了在点序列与紧凑坐标之间相互转换的迭代器适配器, 以辅助 polygon_90_traits 的特化. std::vector<int> 或 std::list<int> 只需通过特征提供对其迭代器的访问, 就可以成为 polygon_90_concept 的模型. 创建多边形对象的库函数要求这些对象提供默认构造函数.

下面展示了默认的多边形特征. 不符合默认行为的类型需要对这组特征进行特化. 注意, 这些特征还被 polygon_90_with_holes 概念使用.

template <typename T>
struct polygon_90_traits {
     typedef typename T::coordinate_type coordinate_type;
     typedef typename T::compact_iterator_type compact_iterator_type;
     static inline compact_iterator_type begin_compact(const T& t) {
          return t.begin_compact();
     }
     static inline compact_iterator_type end_compact(const T& t) {
          return t.end_compact();
     }
     static inline unsigned int size(const T& t) {
          return t.size();
     }
     static inline winding_direction winding(const T& t) {
          return unknown_winding;
     }
};

template <typename T>
struct polygon_90_mutable_traits {
     template <typename iT>
     static inline T& set_compact(T& t, iT input_begin, iT input_end) {
          t.set_compact(input_begin, input_end);
          return t;
     }
};

如果经运行期判定符合相关概念的约束, polygon_90_concept 模型的对象可以被视作其任一细化概念的模型. 这种概念转换通过view_as<>() 函数完成.

view_as<rectangle_concept>(polygon_90_object)

view_as<>() 的返回值可以传入任何期望其模板参数所指概念类型对象的接口.

Polygon 90 数据

库提供了一个 polygon 90 概念模型, 声明为template<typename T> polygon_90_data , 其中 T 为坐标类型.

当需要 Manhattan 多边形时, 库内部会使用该数据类型; 库用户如果觉得使用库的多边形数据类型比自己提供更方便, 也可以使用它. 该数据类型的实现便于与库特征配合使用.
