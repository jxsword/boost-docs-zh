各向同性

什么是各向同性?

各向同性 - 词性: 形容词 词源: International Scientific Vocabulary
: 沿所有方向的轴测量时取值相同 (如光的传输速度) 的性质 <一种 各向同性的晶体>

在计算几何中, 事物常常在方向与朝向上是对称且不变的. 这种对方向的不变性称为各向同性. 在这种情况下, 将方向或朝向参数化, 编写与应用时所取方向或朝向无关的代码会很方便. 为了有效地做到这一点, 我们提供了一组内部一致的各向同性数据类型, 用于表示描述朝向和方向的程序数据. 这些数据类型是:

  • direction_1d - 具有以下 2 种状态之一: LOW、HIGH
  • orientation_2d - 具有以下 2 种状态之一: HORIZONTAL、VERTICAL
  • direction_2d - 具有以下 4 种状态之一: WEST、EAST、SOUTH、NORTH
  • orientation_3d - 具有以下 3 种状态之一: HORIZONTAL、VERTICAL、PROXIMAL
  • direction_3d - 具有以下 6 种状态之一: WEST、EAST、SOUTH、NORTH、DOWN、UP

这些各向同性类型构成一个系统, 并以多种方式相互作用, 例如类型转换. 它们共同构成一种以程序化方式描述各向同性情形的语言. 例如, 要从 orientation_2d 得到其正向 direction_2d, 需调用 orientation_2d 的成员函数并传入一个 direction_1d:

orientation_2d orient = HORIZONTAL;
direction_2d dir = orient.get_direction(direction_1d(HIGH));
assert(dir == EAST);

提供各向同性数据类型的动机是鼓励在更高的抽象层次上编程, 使程序行为由传入函数调用的程序数据控制, 而非由流程控制语法控制. 各向同性编程风格尤其适用于点、区间和矩形相关的处理. 针对 x 坐标或 y 坐标实现的此类逻辑, 其实现往往完全相同, 只是函数和数据成员的名称以机械方式变化, 这会导致代码重复和膨胀, 进而造成复制粘贴式编程错误, 以及对涉及 x 坐标的代码块所做的修改未同步到涉及 y 的代码块的维护问题. 因此, 各向同性为重构并提升底层几何代码的质量提供了机会, 尤其是在坐标、点、区间和矩形相互关联的方面.

direction_1d

direction_1d 数据类型有两种可能的状态, 即数轴这类连续统上的正方向与负方向. 这些状态可以用若干 direction_1d_enum 值之一来描述: 我们把多边形的顺时针与逆时针绕行朝向作为 direction_1d 值, 而不提供单独的 winding_orientation 数据类型. 这是因为绕行朝向可以视为一维 (尽管是循环的) 空间中的正、负方向. 我们把逆时针指定为一维循环空间中的正向行进, 以符合常被称作"右手定则"的数学约定——该约定给逆时针赋予正法向、给顺时针赋予负法向; 也符合另一个常见约定: 逆时针多边形绕行对应正多边形区域, 而顺时针多边形绕行对应孔洞 (负) 多边形区域.

enum direction_1d_enum {LOW = 0, HIGH = 1,
                        LEFT = 0, RIGHT = 1,
                        CLOCKWISE = 0, COUNTERCLOCKWISE = 1,
                        REVERSE = 0, FORWARD = 1,
                        NEGATIVE = 0, POSITIVE = 1 };

成员函数

direction_1d(direction_1d_enum val = LOW) 构造函数默认为 LOW.
direction_1d(const direction_1d& that) 拷贝构造.
direction_1d(const direction_2d& that) 向下转换 direction_2d, 提取其正或负
direction_1d(const direction_3d& that) 向下转换 direction_3d, 提取其正或负
direction_1d& operator=(const direction_1d dir) 赋值
direction_1d& operator==(const direction_1d dir) const 等价
direction_1d& operator!=(const direction_1d dir) const 不等价
unsigned int to_int() const 转换为当前状态的整数枚举值以用作索引. 出于类型安全的考虑, 不允许自动转换为 int.
direction_1d& backward() 反转方向.
int get_sign() const 若为正方向则返回正 1, 若为负方向则返回负 1.

orientation_2d

orientation_2d 数据类型有两种可能的状态, 即二维笛卡尔坐标系的水平轴与垂直轴. 这些状态可以用两个 orientation_2d_enum 值之一来描述:

enum orientation_2d_enum { HORIZONTAL = 0, VERTICAL = 1 };

成员函数

orientation_2d(orientation_2d_enum val = HORIZONTAL) 构造函数默认为 HORIZONTAL.
orientation_2d(const orientation_2d& that) 拷贝构造.
explicit orientation_2d(const direction_2d& that) 向下转换 direction_2d, 提取其水平或垂直方向类型
orientation_2d& operator=(const orientation_2d o) 赋值
orientation_2d& operator==(const orientation_2d o) const 等价
orientation_2d& operator!=(const orientation_2d o) const 不等价
unsigned int to_int() const 转换为当前状态的整数枚举值以用作索引. 出于类型安全的考虑, 不允许自动转换为 int
orientation_2d& turn_90() 切换到正交朝向
int get_perpendicular() const 返回正交朝向
int get_direction(direction_1d dir) const 根据 dir 的值返回正向或负向 direction_2d

direction_2d

direction_2d 数据类型有四种可能的状态, 即二维笛卡尔坐标系的四个基本方向. 这些状态可以用若干 direction_2d_enum 值之一来描述:

enum direction_2d_enum { WEST = 0, EAST = 1, SOUTH = 2, NORTH = 3 };

成员函数

direction_2d(direction_2d_enum val = WEST) 构造函数默认为 WEST.
direction_2d(const direction_2d& that) 拷贝构造.
direction_1d& operator=(const direction_2d dir) 赋值
direction_1d& operator==(const direction_2d dir) const 等价
direction_1d& operator!=(const direction_2d dir) const 不等价
unsigned int to_int() const 转换为当前状态的整数枚举值以用作索引. 出于类型安全的考虑, 不允许自动转换为 int.
direction_2d& backward() 反转方向.
direction_2d& turn(direction_1d dir) 若 dir 为 LOW 则切换到左侧的 direction_2d, 若为 HIGH 则切换到右侧的 direction_2d
direction_2d& left() 切换到左侧的 direction_2d
direction_2d& right() 切换到右侧的 direction_2d
int is_positive() const 若为 EAST 或 NORTH 则返回 true
int is_negative() const 若为 WEST 或 SOUTH 则返回 true
int get_sign() const 若为正方向则返回正 1, 若为负方向则返回负 1.

orientation_3d

orientation_3d 数据类型有三种可能的状态, 即三维笛卡尔坐标系的水平、垂直与近端 (x, y, z) 轴. 这些状态可以用 orientation_2d_enum 值之一或 orientation_3d_enum 值来描述:

enum orientation_3d_enum { PROXIMAL = 2 };

成员函数

orientation_3d(orientation_2d_enum val = HORIZONTAL) 构造函数默认为 HORIZONTAL.
orientation_3d(const orientation_3d& that) 拷贝构造.
explicit orientation_3d(const direction_2d& that) 提取该方向的朝向
explicit orientation_3d(const direction_3d& that) 提取该方向的朝向
orientation_3d(const orientation_2d& that) 将 orientation_2d 向上转换为 orientation_3d.
orientation_3d(const orientation_3d_enum& that) 从常量值构造
orientation_3d& operator=(const orientation_3d o) 赋值
orientation_3d& operator==(const orientation_3d o) const 等价
orientation_3d& operator!=(const orientation_3d o) const 不等价
unsigned int to_int() const 转换为当前状态的整数枚举值以用作索引. 出于类型安全的考虑, 不允许自动转换为 int
int get_direction(direction_1d dir) const 根据 dir 的值返回正向或负向 direction_2d

direction_3d

direction_3d 数据类型有六种可能的状态, 即三维笛卡尔坐标系的六个基本方向. 这些状态可以用 direction_2d_enum 值之一或 direction_3d_enum 值来描述:

enum direction_3d_enum { DOWN = 4, UP = 5 };

成员函数

direction_3d(direction_2d_enum val = WEST) 构造函数默认为 LOW.
direction_3d(direction_3d_enum that) 从常量值构造

direction_2d& operator!=(const direction_3d dir) const 不等价
unsigned int to_int() const 转换为当前状态的整数枚举值以用作索引. 出于类型安全的考虑, 不允许自动转换为 int.
direction_1d& backward() 反转方向.
int is_positive() const 若方向为 EAST、NORTH 或 UP 则返回 true.
int is_negative() const 若方向为 WEST、SOUTH 或 DOWN 则返回 true
int get_sign() const 若为正方向则返回正 1, 若为负方向则返回负 1.
