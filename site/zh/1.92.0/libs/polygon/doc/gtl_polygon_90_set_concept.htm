Polygon 90 集合概念

polygon_90_set 概念的标签是 polygon_90_set_concept

polygon_90_set 的语义是: 零个或多个 Manhattan 几何区域.

提供 polygon_90_set_concept 的动机是: 它是平面几何中非常常见的特例, 使得可以在一般平面几何算法的基础上实现多种优化. 用 polygon_90_set_concept 处理 Manhattan 几何可以比任意角度多边形操作快 100 倍. 由于性能收益巨大且该特例足够重要, 库为需要这些性能收益的应用领域提供了它们.

建议用户使用用户自定义多边形的 std::vector 与 std::list, 或库提供的 polygon_90_set_data<coordinate_type> 对象. polygon_90_concept、polygon_90_with_holes_concept 或 rectangle_concept 模型的 list 和 vector 会自动成为 polygon_90_set_concept 的模型.

Operators

某些运算符的返回类型是polygon_90_set_view 运算符模板类型. 该类型本身就是 polygon_90_set 概念的一个模型, 此外还可用作polygon_90_set_data 构造函数与赋值运算符的实参. 运算符模板的存在是为了在布尔运算符链接在一起时消除中间结果的临时拷贝.

Polygon 90 集合数据对象

polygon 90 集合数据类型封装了作为实现多边形裁剪布尔运算的扫描线算法输入的内部数据格式. 它还在内部跟踪该数据是否已被排序或扫描, 并维护这样的不变式: 当其标志表明数据已排序或已扫描时, 数据未被改变以致违反该假设. 在上述函数中直接使用 Polygon 90 Set Data 类型可能比使用多边形的 list 和 vector 更高效, 因为它能强制执行一些不变式, 从而有机会让数据保持已排序形式, 而不必一路转换到多边形、再为后续操作重新排序那些顶点.

Polygon 90 Set Data 的声明如下:

template <typename T>
class polygon_90_set_data;

该类以坐标数据类型为参数. 受益于了解该类所强制不变式的算法以成员函数形式实现, 使其能够访问关于这些不变式的信息.

bool operator==(const polygon_90_set_data& p) const 扫描之后, 多边形集合内几何的数据表示处于数学上的规范形式. 因此, 一旦两个集合都处于已扫描状态, 它们之间的比较就是线性时间操作. 将对两个多边形集合都执行扫描并消除重叠. 首次运行关于顶点数 + 交点数为 O( n log n) 复杂度和 O(n) 内存, 之后为线性.

void clear() 使多边形集合变空. 注释: 不释放内存. 要释放内存, 请使用 shrink to fit 惯用法, 并赋以默认构造的多边形集合.
bool empty() const 检查多边形集合是否不含几何. 将执行扫描并消除重叠, 因为减性区域可能使多边形集合变空. 首次运行关于顶点数 + 交点数为 O( n log n) 复杂度和 O(n) 内存, 之后为线性.
orientation_2d orient() const 获取扫描朝向. 取决于数据, 沿特定朝向扫描有时效率更高, 对于 Manhattan 几何数据尤其如此. 常数时间.
void clean() const 扫描并消除重叠. 首次运行关于顶点数 + 交点数为 O( n log n) 复杂度和 O(n) 内存, 之后为常数时间.
