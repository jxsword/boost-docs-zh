矩形概念

矩形概念的标签是 rectangle_concept

要将用户自定义类型注册为 rectangle 概念的模型, 需为该类型特化 geometry concept 元函数. 在下例中, CRectangle 被注册为矩形概念的一个模型.

template <>
struct geometry_concept<CRectangle> { typedef rectangle_concept type; };

矩形的语义是: 它有一个 x 区间和一个 y 区间, 且这两个区间遵循区间的语义, 包括其不变式. 矩形区间上的这一不变式由操作矩形的泛型库函数强制执行, 并不要求数据类型本身或该数据类型通过特征到矩形概念的概念映射来满足. 这样, 只需通过特征提供对其元素的间接访问, 就可以让 boost::tuple<int, int, int, int> 或 boost::array<int, 4> 成为矩形的模型.

下面展示了默认的矩形特征. 不符合默认行为的类型需要对这组特征进行特化. 有兴趣的读者会注意到, 这些特征上使用了 SFINAE, 使得只有提供了 interval_type 成员类型定义的对象才能与默认的只读特征配合使用. 在使用概念细化时这种做法是必要的, 因为在编译期把默认特征匹配到非矩形类型是不可取的. 只要把 gtl_yes 作为 enable 参数提供, 就可以轻松地完成 rectangle_traits 的特化.

template <typename T, typename enable = gtl_yes>
struct rectangle_traits {};

template <typename T>
struct rectangle_traits<T, gtl_no> {};

template <typename T>
struct rectangle_traits<T, typename gtl_same_type<typename T::interval_type, typename T::interval_type>::type> {
     typedef typename T::coordinate_type coordinate_type;
     typedef typename T::interval_type interval_type;
     static inline interval_type get(const T& rectangle, orientation_2d orient) {
          return rectangle.get(orient); }
};

template <typename T>
struct rectangle_mutable_traits {
     template <typename T2>
     static inline void set(T& rectangle, orientation_2d orient, const T2& interval) {
          rectangle.set(orient, interval); }
     template <typename T2, typename T3>
     static inline T construct(const T2& interval_horizontal, const T3& interval_vertical) {
          return T(interval_horizontal, interval_vertical); }
};

矩形数据

库提供了一个矩形概念模型, 声明为template<typename T> rectangle_data , 其中 T 为坐标类型.

当需要矩形时, 库内部会使用该数据类型; 库用户如果觉得使用库的矩形数据类型比自己提供更方便, 也可以使用它. 该数据类型的实现便于与库特征配合使用.
