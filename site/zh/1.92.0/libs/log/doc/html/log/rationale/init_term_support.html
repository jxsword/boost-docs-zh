Boost.Log 是否支持在进程初始化和终止时记录日志?

在应用程序初始化期间使用日志应该没问题 (即在 main() 开始之前). 但 Boost.Log 存在一些已知问题, 妨碍它在进程终止时使用 (即在 main() 函数返回之后), 因此对第二部分的官方回答是否定的. 不过, 在一些非常受限的环境中, 如果遵循以下几条规则, 它可能可以工作:

  • 不要在进程终止时创建任何对象, 包括日志器、属性或接收器. 尽量在应用程序启动后尽快创建并缓存所需对象 (甚至可以在 main() 开始之前).
  • 不要在进程终止时使用全局日志器.
  • 不要在进程终止时调用 logging::core::get(). 尽早获取该指针并保留到进程终止.
  • 不要在终止代码中使用命名作用域.

这些规则并不保证库能在终止上下文中工作, 但它们可能有助于避免问题. 库会得到改进, 以更好地支持这一用例.
