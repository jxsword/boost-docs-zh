为什么 MSVC 2010 链接该库时报错 LNK1123: failure during conversion to COFF: file invalid or corrupt?

如果您安装了多个版本的 Visual Studio, 并且尝试用 Visual Studio 2010 构建库, 编译可能因链接器错误 LNK1123 而失败. 这似乎是一个 已知问题, 由 Visual Studio 2010 与 .NET Framework 4.5 之间的某些冲突引起, 后者随 Visual Studio 2012 安装.

建议的解决方案是将 Visual Studio 2010 升级到 Visual Studio 2010 SP1, 或用 Visual Studio 2010 SP1 或 2012 的对应文件覆盖 "C:\Program Files (x86)\Microsoft Visual Studio 10.0\VC\bin\cvtres.exe".
