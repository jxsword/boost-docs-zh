简单日志

对于那些不想阅读大量深奥手册、只需要一个简单日志工具的人, 请看这里:

#include <boost/log/trivial.hpp>

int main(int, char*[])
{
    BOOST_LOG_TRIVIAL(trace) << "A trace severity message";
    BOOST_LOG_TRIVIAL(debug) << "A debug severity message";
    BOOST_LOG_TRIVIAL(info) << "An informational severity message";
    BOOST_LOG_TRIVIAL(warning) << "A warning severity message";
    BOOST_LOG_TRIVIAL(error) << "An error severity message";
    BOOST_LOG_TRIVIAL(fatal) << "A fatal severity message";

    return 0;
}

查看完整代码.

BOOST_LOG_TRIVIAL 宏接受一个严重级别, 并产生一个支持插入运算符的类流对象. 作为这段代码的结果, 日志消息将被打印到控制台. 如上所示, 这种库使用模式与您使用 std::cout 的方式非常相似. 不过, 该库提供了一些优势:

  1. 除记录消息外, 输出中的每条日志记录都包含时间戳、当前线程标识符和严重级别.
  2. 从不同线程并发写日志是安全的, 日志消息不会被破坏.
  3. 如后文所示, 可以应用过滤.

必须指出, 该宏连同库提供的其他类似宏并非库提供的唯一接口. 如后文所示, 完全可以在不使用任何宏的情况下发出日志记录.
