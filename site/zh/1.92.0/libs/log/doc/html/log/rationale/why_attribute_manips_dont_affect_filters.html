为什么通过流操纵器设置的属性不参与过滤?

可以通过以下方式向日志记录添加属性:

BOOST_LOG(logger) << logging::add_value("MyInt", 10) << logging::add_value("MyString", "string attribute value")
    << "Some log message";

但是, 过滤器将无法使用 MyInt 和 MyString 属性. 这种行为的原因很简单. 流式表达式在过滤 之后执行, 并且 仅当过滤器通过该日志记录时才执行. 此时这些属性尚未添加到记录中. 将属性传递给过滤器最简单的方式是使用作用域属性或标记 (参见 此处).
