类 runtime_error

boost::log::runtime_error — 日志库运行期异常的基类.

概要

// In header: <boost/log/exceptions.hpp>


class runtime_error : public runtime_error {
public:

  // public member functions
  explicit runtime_error(std::string const &);
  ~runtime_error();
};

说明

派生自该类的异常表示可能并非直接由与库交互的用户代码引起的问题, 例如由输入数据引起的错误.

runtime_error 公有成员函数

  1. explicit runtime_error(std::string const & descr);

    初始化构造函数. 创建一个带有指定错误消息的异常.

  2. ~runtime_error();

    析构函数
