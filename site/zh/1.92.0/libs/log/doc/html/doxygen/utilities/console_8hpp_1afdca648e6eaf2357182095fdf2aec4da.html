函数模板 add_console_log

boost::log::add_console_log

概要

// In header: <boost/log/utility/setup/console.hpp>


template<typename CharT, typename... ArgsT> 
  shared_ptr< sinks::synchronous_sink< sinks::basic_text_ostream_backend< CharT > > > 
  add_console_log(std::basic_ostream< CharT > & strm, ArgsT... const & args);

说明

该函数为指定的控制台流构造接收器并将其添加到核心

参数:

strm

标准控制台流之一: std::cout、std::cerr 或 std::clog(或对应的宽字符类似物).

args

用于接收器初始化的可选附加命名参数. 支持以下参数:

  • filter 指定要安装到接收器中的过滤器. 可以是表示过滤器的字符串, 或过滤器 lambda 表达式.

  • format 指定要安装到接收器中的格式化器. 可以是表示格式化器的字符串, 或格式化器 lambda 表达式(流式或类似 Boost.Format 的记法).

  • auto_flush 布尔标志, 指示接收器是否应在每写入一条记录后自动刷新流.

  • auto_newline_mode - 指定自动插入行尾换行符的模式. 必须是 auto_newline_mode 枚举的值. 默认为 auto_newline_mode::insert_if_missing.

返回:

指向构造出的接收器的指针.
