结构体 synchronized_feeding

boost::log::sinks::synchronized_feeding

概要

// In header: <boost/log/sinks/frontend_requirements.hpp>


struct synchronized_feeding {
};

说明

该接收器后端期望预先同步的调用, 所有需要的同步都在前端中实现(换言之, 同一时间只有一个线程向后端传送记录, 但允许多个线程依次写入). 注意, 如果前端支持同步记录传送, 它也会报告能够并发传送记录.
