类 block_on_overflow

boost::log::sinks::block_on_overflow — 处理日志记录队列溢出的阻塞策略.

概要

// In header: <boost/log/sinks/block_on_overflow.hpp>


class block_on_overflow {
};

说明

该策略会在日志记录队列溢出时使入队线程阻塞. 一旦队列中出现空闲空间, 被阻塞的线程就会按其尝试入队的先后顺序被唤醒.
