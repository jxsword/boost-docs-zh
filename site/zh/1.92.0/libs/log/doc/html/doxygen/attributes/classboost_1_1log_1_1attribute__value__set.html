boost::log::attribute_value_set — 属性值集合.

说明

属性值集合是一个关联容器, 以属性名为键、以指向属性值对象的指针为映射类型. 这是键唯一的元素集合, 即集合中给定名称的属性值只能有一个. 就只读能力而言, 该集合的接口与 std::unordered_map 接近.

该集合被设计为只能向其中添加元素. 一旦添加, 属性值便无法从集合中移除.

属性值集合的实例可以由三个属性集合构造. 构造函数会尝试容纳来自这些集合的所有属性的值. 在多个属性集合中发现同名属性的情况是可能的. 这一问题在构造值集合时解决: 在解决冲突时, 三个属性集合具有不同的优先级.

从库的角度看, 这三个来源属性集合分别是全局属性、线程特定属性和日志源特定属性, 其中后者具有最高优先级. 该特性允许用更具体的属性覆盖更大作用域的属性.

出于性能考虑, 构造时并不立即从属性集合获取属性值. 而是在迭代器解引用时或调用 freeze 方法时按需获取. 一旦获取, 属性值便一直留在集合中, 直至集合销毁. 这一细节不影响集合的其他性质, 例如大小或查找能力. 日志核心会在恰当的时机自动冻结集合, 因此除非用户手动创建属性值集合, 否则无需为此操心.

注释

在值集合被冻结之前, 不得修改或销毁用于构造该值集合的属性集合. 否则行为未定义.

attribute_value_set 公有成员函数

  1. explicit attribute_value_set(size_type reserve_count = 8);

    默认构造函数

    该构造函数创建一个空集合, 之后可通过后续调用 insert 方法来填充. 还可以向构造函数传递为待插入元素预留的存储量(可选). 构造出的集合是冻结的.

    参数:

    reserve_count

    要为其预留空间的元素数量.

    		 
  2. attribute_value_set(attribute_value_set && that) noexcept;

    移动构造函数

  3. attribute_value_set(attribute_set const & source_attrs, 
                    attribute_set const & thread_attrs, 
                    attribute_set const & global_attrs, 
                    size_type reserve_count = 8);

    该构造函数将三个属性集合纳入值集合. 当在多个集合中发现同名属性时, source_attrs 属性的优先级最高, global_attrs 最低. 构造出的集合未被冻结.

    参数:

    source_attrs

    日志源特定属性的集合.

    thread_attrs

    线程特定属性的集合.

    global_attrs

    全局属性的集合.

    reserve_count

    除所提供的三个属性集合中的元素之外, 还要为其预留空间的元素数量.

    		 
  4. attribute_value_set(attribute_value_set const & source_attrs, 
                    attribute_set const & thread_attrs, 
                    attribute_set const & global_attrs, 
                    size_type reserve_count = 8);

    该构造函数将三个属性集合纳入值集合. 当在多个集合中发现同名属性时, source_attrs 属性的优先级最高, global_attrs 最低. 构造出的集合未被冻结.

    参数:

    source_attrs

    日志源特定属性的集合.

    thread_attrs

    线程特定属性的集合.

    global_attrs

  19. std::pair< const_iterator, bool > 
insert(key_type key, mapped_type const & mapped);

    向集合中插入一个元素. 该操作的复杂度为摊还常数.

    参数:

    key

    属性名.

    mapped

    属性值.

    要求:

    该集合已被冻结.

    返回:

    若插入成功, 则为指向被插入元素的迭代器及 true. 否则, 若集合已包含同名属性值, 则为指向现有元素的迭代器及 false.
