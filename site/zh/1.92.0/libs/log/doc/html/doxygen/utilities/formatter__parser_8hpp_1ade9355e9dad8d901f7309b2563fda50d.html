函数模板 parse_formatter

boost::log::parse_formatter

概要

// In header: <boost/log/utility/setup/formatter_parser.hpp>


template<typename CharT> 
  basic_formatter< CharT > 
  parse_formatter(const CharT * begin, const CharT * end);

说明

该函数从字符序列解析格式化器

抛出: 若无法在字符序列中识别格式化器, 则抛出 std::exception 系异常.

参数:

begin

指向序列第一个字符的指针

end

指向序列最后一个字符之后位置的指针

要求:

begin <= end, 两个指针都不得为 NULL

返回:

解析出的格式化器.
