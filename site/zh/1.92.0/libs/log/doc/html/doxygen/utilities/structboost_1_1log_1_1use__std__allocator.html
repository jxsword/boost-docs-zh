结构 use_std_allocator

boost::log::use_std_allocator — 标记类型, 用于指示应使用 std::allocator 的特化来分配内存.

概要

// In header: <boost/log/utility/use_std_allocator.hpp>


struct use_std_allocator {
};

说明

此标记类型可用作 Boost.Log 各组件的模板参数. 该类型本身不是分配器类型.
