类模板 basic_text_ostream_backend

boost::log::sinks::basic_text_ostream_backend — 文本输出流日志接收器后端的实现.

概要

// In header: <boost/log/sinks/text_ostream_backend.hpp>

template<typename CharT> 
class basic_text_ostream_backend : public basic_formatted_sink_backend< CharT, combine_requirements< synchronized_feeding, flushing >::type >
{
public:
  // types
  typedef base_type::char_type            char_type;    // Character type. 
  typedef base_type::string_type          string_type;  // String type to be used as a message text holder. 
  typedef std::basic_ostream< char_type > stream_type;  // Output stream type. 

  // public member functions
  basic_text_ostream_backend();
  template<typename... ArgsT> 
    explicit basic_text_ostream_backend(ArgsT... const &);
  ~basic_text_ostream_backend();
  void add_stream(shared_ptr< stream_type > const &);
  void remove_stream(shared_ptr< stream_type > const &);
  void auto_flush(bool = true);
  void set_auto_newline_mode(auto_newline_mode);
  void consume(record_view const &, string_type const &);
  void flush();
};

说明

该接收器后端将已格式化的日志记录放入一个或多个文本流.

basic_text_ostream_backend 公有成员函数

  1. basic_text_ostream_backend();

    构造函数. 构造出的后端未附加任何流, 自动刷新特性被禁用.

  2. template<typename... ArgsT> 
  explicit basic_text_ostream_backend(ArgsT... const & args);

    构造函数. 用指定的命名参数创建接收器后端. 支持以下命名参数:

    • auto_flush - 指定一个标志, 是否在每写入一条日志记录后自动刷新附加的流. 默认为 false.

    • auto_newline_mode - 指定自动插入行尾换行符的模式. 必须是 auto_newline_mode 枚举的值. 默认为 auto_newline_mode::insert_if_missing.

  3. ~basic_text_ostream_backend();

    析构函数

  4. void add_stream(shared_ptr< stream_type > const & strm);

    该方法向接收器添加新的流.

    参数:

    strm

    指向流的指针. 不得为 NULL.

    		 
  5. void remove_stream(shared_ptr< stream_type > const & strm);

    该方法从接收器移除流. 如果该流未附加到接收器, 该方法没有效果.

    参数:

    strm

    指向流的指针. 不得为 NULL.

    		 
  6. void auto_flush(bool enable = true);

    设置标志: 在每条日志记录之后自动刷新所有附加流的缓冲区.

    参数:

    enable

    该标志指示是否应执行自动缓冲区刷新.

    		 
  7. void set_auto_newline_mode(auto_newline_mode mode);

    选择是否应在每条日志记录之后自动插入行尾换行符. 可能的操作模式参见 auto_newline_mode 的描述.

    参数:

    mode

    行尾换行符插入模式.

    		 
  8. void consume(record_view const & rec, string_type const & formatted_message);

    该方法将消息写入接收器.

  9. void flush();

    该方法刷新所有附加的流.
