函数模板 optional_manip

boost::log::optional_manip

概要

// In header: <boost/log/utility/manipulators/optional.hpp>


template<typename OptionalT, typename NoneT> 
  boost::enable_if_c<!is_scalar< OptionalT >::value &&!is_array< OptionalT >::value &&is_scalar< NoneT >::value, optional_manipulator< OptionalT, NoneT > >::type 
  optional_manip(OptionalT const & opt, NoneT none);

说明

optional 操纵器生成器函数.

注释

opt 与 none 对象的生命期都必须长于创建的操纵器对象.

参数:

opt

要输出的 optional 值. 该 optional 值必须支持到 bool 的上下文转换和解引用, 其解引用结果必须支持流输出.

none

用于指示值不存在时的标记. 可选. 若未指定, 当值不存在时不输出任何内容.

返回:

要插入流中的操纵器.
