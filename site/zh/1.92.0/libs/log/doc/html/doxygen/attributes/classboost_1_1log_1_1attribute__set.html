类 attribute_set

boost::log::attribute_set — 属性集合类.

概要

// In header: <boost/log/attributes/attribute_set.hpp>


class attribute_set {
public:
  // types
  typedef attribute_name                           key_type;         // Key type. 
  typedef attribute                                mapped_type;      // Mapped attribute type. 
  typedef std::pair< const key_type, mapped_type > value_type;       // Value type. 
  typedef value_type &                             reference;        // Reference type. 
  typedef value_type const &                       const_reference;  // Const reference type. 
  typedef value_type *                             pointer;          // Pointer type. 
  typedef value_type const *                       const_pointer;    // Const pointer type. 
  typedef std::size_t                              size_type;        // Size type. 
  typedef std::ptrdiff_t                           difference_type;  // Difference type. 
  typedef implementation_defined                   iterator;       
  typedef implementation_defined                   const_iterator; 

  // public member functions
  attribute_set();
  attribute_set(attribute_set const &);
  attribute_set(attribute_set &&) noexcept;
  ~attribute_set() noexcept;
  attribute_set & operator=(attribute_set) noexcept;
  void swap(attribute_set &) noexcept;
  iterator begin() noexcept;
  iterator end() noexcept;
  const_iterator begin() const noexcept;
  const_iterator end() const noexcept;
  size_type size() const noexcept;
  bool empty() const noexcept;
  iterator find(key_type) noexcept;
  const_iterator find(key_type) const noexcept;
  size_type count(key_type) const noexcept;
  unspecified operator[](key_type) noexcept;
  mapped_type operator[](key_type) const noexcept;
  std::pair< iterator, bool > insert(key_type, mapped_type const &);
  std::pair< iterator, bool > insert(const_reference);
  template<typename FwdIteratorT> void insert(FwdIteratorT, FwdIteratorT);
  template<typename FwdIteratorT, typename OutputIteratorT> 
    void insert(FwdIteratorT, FwdIteratorT, OutputIteratorT);
  size_type erase(key_type) noexcept;
  void erase(iterator) noexcept;
  void erase(iterator, iterator) noexcept;
  void clear() noexcept;
};

说明

属性集合是一个关联容器, 以属性名为键、以指向属性的指针为映射值. 该容器对每个不同的键值只允许存储一个元素. 在大多数方面, 属性集合容器提供的接口与 std::unordered_map 类似. 但 operator[] 的语义有所不同, 且在迭代方面做了若干优化. 此外, 属性名以只读的 attribute_name 形式而非 std::string 存储, 从而节省内存和 CPU 时间.

attribute_set 公有类型

  1. typedef implementation_defined iterator;

    迭代器类型. 该迭代器满足双向迭代器要求.

  2. typedef implementation_defined const_iterator;

    常量迭代器类型. 该迭代器满足具有只读能力的双向迭代器要求.

attribute_set 公有成员函数

  1. attribute_set();

    默认构造函数.

    后置条件:

    empty() == true 

  2. attribute_set(attribute_set const & that);

    拷贝构造函数.

    后置条件:

    size() == that.size() && std::equal(begin(), end(), that.begin()) == true 

  3. attribute_set(attribute_set && that) noexcept;

    移动构造函数

  4. ~attribute_set() noexcept;

    析构函数. 释放所有已存储的属性引用.

  5. attribute_set & operator=(attribute_set that) noexcept;

    拷贝赋值运算符.

    后置条件:

    size() == that.size() && std::equal(begin(), end(), that.begin()) == true 

  6. void swap(attribute_set & that) noexcept;

    交换容器的两个实例.

    抛出: 无.

    返回:

    指向容器第一个元素的常量迭代器.

    返回:

    指向容器尾后元素的常量迭代器.

    容器中的元素数量.

    返回:

    若容器中没有元素则为 true, 否则为 false.

    		 
  13. iterator find(key_type key) noexcept;

    该方法按名称查找属性.

    参数:

    key

    属性名.

    返回:

    指向所找到元素的迭代器, 若未找到具有该名称的属性则为 end().

    		 
  14. const_iterator find(key_type key) const noexcept;

    该方法按名称查找属性.

    参数:

    key

    属性名.

    返回:

    指向所找到元素的迭代器, 若未找到具有该名称的属性则为 end().

    		 
  15. size_type count(key_type key) const noexcept;

    该方法统计属性在容器中出现的次数. 由于具有特定键的属性只能有一个, 该方法始终返回 0 或 1.

    参数:

    key

    属性名.

    返回:

    属性在容器中被找到的次数.

    		 
  16. unspecified operator[](key_type key) noexcept;

    组合的查找/插入运算符. 运算符的语义取决于返回引用的后续用法.

    • 如果该引用被用作赋值目标, 则赋值表达式等价于元素插入, 其中元素由 operator[] 的第二个参数作为键、赋值的第二个参数作为映射值组成.

    • 如果返回的引用被用在需要转换为映射类型的上下文中, 转换的结果等价于: 若容器中存在该元素, 则为以 operator[] 的第二个参数为键找到的映射值; 若容器中不存在该元素, 则为默认构造的映射值.

    参数:

    key

    属性名.

    返回:

    未指定类型的智能引用对象.

    		 
  17. mapped_type operator[](key_type key) const noexcept;

    查找运算符

    参数:

    key

    属性名.

    返回:

    如果在容器中找到具有相应属性名的元素, 则返回其映射值. 否则返回默认构造的映射值.

    		 
  18. std::pair< iterator, bool > insert(key_type key, mapped_type const & data);

    插入方法

    参数:

    key

    属性名.

    data

    指向属性的指针. 不得为 NULL.

    返回:

    一对值. 若 second 为 true, 则插入成功, 第一个分量指向被插入的元素. 否则第一个分量指向阻止插入的元素.

    		 
  19. std::pair< iterator, bool > insert(const_reference value);

    插入方法

    参数:

    value

    要插入的元素.

    返回:

    一对值. 若 second 为 true, 则插入成功, 第一个分量指向被插入的元素. 否则第一个分量指向阻止插入的元素.

    		 
  20. template<typename FwdIteratorT> 
  void insert(FwdIteratorT begin, FwdIteratorT end);

    批量插入方法.

    参数:

    begin

    指向要插入的第一个元素的前向迭代器.

    end

    指向要插入元素的尾后位置的前向迭代器.

    		 
  21. template<typename FwdIteratorT, typename OutputIteratorT> 
  void insert(FwdIteratorT begin, FwdIteratorT end, OutputIteratorT out);

    批量插入方法, 并能获取指向被插入元素的迭代器.

    参数:

    begin

    指向要插入的第一个元素的前向迭代器.

    end

    指向要插入元素的尾后位置的前向迭代器.

    out

    接收元素插入结果的输出迭代器

    		 
  22. size_type erase(key_type key) noexcept;

    该方法擦除具有指定名称的所有属性

    参数:

    key

    属性名.

    后置条件:

    指向被擦除元素的所有迭代器都会失效.

    返回:

    被擦除元素的数量

    		 
  23. void erase(iterator it) noexcept;

    该方法擦除指定的属性

    参数:

    it

    指向要擦除元素的有效迭代器.

    后置条件:

    指向被擦除元素的所有迭代器都会失效.

    返回:

    被擦除元素的数量

    		 
  24. void erase(iterator begin, iterator end) noexcept;

    该方法擦除指定范围内的所有属性

    参数:

    begin

    指向要擦除的第一个元素的迭代器.

    end

    指向要擦除元素的尾后位置的迭代器.

    要求:

    end 可从 begin 经有限次递增到达.

    后置条件:

    指向被擦除元素的所有迭代器都会失效.

    		 
  25. void clear() noexcept;

    该方法从容器中移除所有元素

    后置条件:

    empty() == true
