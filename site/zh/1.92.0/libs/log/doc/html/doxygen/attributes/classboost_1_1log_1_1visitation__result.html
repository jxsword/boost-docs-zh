类 visitation_result

boost::log::visitation_result — 该类表示属性值访问结果.

概要

// In header: <boost/log/attributes/value_visitation.hpp>


class visitation_result {
public:

  // Error codes for attribute value visitation. 
  enum error_code { ok, value_not_found, value_has_invalid_type };

  // public member functions
  visitation_result(error_code = ok) noexcept;
  explicit operator bool() const noexcept;
  bool operator!() const noexcept;
  error_code code() const noexcept;
};

说明

该类的主要目的是提供一个便捷接口, 用于检查属性值访问是否成功. 若操作失败, 它还可用于查明失败的实际原因.

visitation_result 公有成员函数

  1. visitation_result(error_code code = ok) noexcept;

    初始化构造函数. 创建一个等价于指定错误码的结果.

  2. explicit operator bool() const noexcept;

    检查访问是否成功.

    返回:

    true, 若值被成功访问; 否则为 false.

    		 
  3. bool operator!() const noexcept;

    检查访问是否未成功.

    返回:

    false, 若值被成功访问; 否则为 true.

    		 
  4. error_code code() const noexcept;

    返回:

    值访问的实际结果码
