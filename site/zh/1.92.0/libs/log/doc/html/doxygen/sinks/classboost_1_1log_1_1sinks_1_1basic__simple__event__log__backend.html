类模板 basic_simple_event_log_backend

boost::log::sinks::basic_simple_event_log_backend — 将事件发入 Windows NT 事件日志的简单日志接收器后端实现.

概要

// In header: <boost/log/sinks/event_log_backend.hpp>

template<typename CharT> 
class basic_simple_event_log_backend :
  public basic_formatted_sink_backend< CharT, concurrent_feeding >
{
public:
  // types
  typedef base_type::char_type   char_type;               // Character type. 
  typedef base_type::string_type string_type;             // String type to be used as a message text holder. 
  typedef unspecified            event_type_mapper_type;  // Mapper type for the event type. 

  // public member functions
  basic_simple_event_log_backend();
  template<typename... ArgsT> 
    explicit basic_simple_event_log_backend(ArgsT... const &);
  ~basic_simple_event_log_backend();
  void set_event_type_mapper(event_type_mapper_type const &);
  void consume(record_view const &, string_type const &);

  // public static functions
  static string_type get_default_log_name();
  static string_type get_default_source_name();
};

说明

该接收器使用 Windows NT 5 (Windows 2000) 及更高版本的事件日志 API 将事件发入事件日志. 就该 API 而言, 该接收器充当事件源, 它实现事件传递所需的全部资源以及 Windows 注册表中的源注册.

该后端执行消息文本格式化. 组合好的文本随后作为事件的第一个也是唯一的字符串参数传递. 嵌入到后端中的资源描述该事件, 使该参数被插入事件描述文本, 从而在事件日志中可见.

该后端允许自定义应用程序严重级别到 Windows 原生事件类型的映射. 即使使用了像这样的操作系统特定接收器, 也可以编写可移植的代码.

注释

由于该后端将自身注册到 Windows 注册表中, 作为包含事件描述的资源文件, 因此将库二进制文件保存在文件系统的稳定位置非常重要. 否则 Windows 可能无法从库中加载事件资源并正确显示事件.

注释

已知 Windows 无法在链接了该库静态构建版本的应用程序可执行文件中找到事件资源. 建议用户使用该库的动态构建版本来解决此问题.

basic_simple_event_log_backend 公有成员函数

  1. basic_simple_event_log_backend();

    默认构造函数. 在 Application 日志中以基于应用程序可执行文件名的名称注册事件源. 如果已存在这样的注册, 则不会覆盖它.

  2. template<typename... ArgsT> 
  explicit basic_simple_event_log_backend(ArgsT... const & args);

    构造函数. 用指定的参数注册事件日志源. 支持以下命名参数:

    • target - 指定日志记录应发送到的远程服务器的 UNC 路径. 若未指定, 将使用本地机器处理日志记录.

    • log_name - 指定源应注册到的日志. 若未指定该参数, 则使用 get_default_log_name 的结果.

    • log_source - 指定源名. 若未指定该参数, 则使用 get_default_source_name 的结果.

    • registration - 指定 Windows 注册表中的事件源注册模式. 可以取 registration_mode 枚举的值. 默认值: on_demand.

    参数:

    args

    一组命名参数.

    		 
  3. ~basic_simple_event_log_backend();

    析构函数. 注销事件源. 日志源描述不会从 Windows 注册表中移除.

  4. void set_event_type_mapper(event_type_mapper_type const & mapper);

    该方法安装将应用程序严重级别映射到 WinAPI 事件类型的函数对象

  5. void consume(record_view const & rec, string_type const & formatted_message);

    该方法将已格式化的消息放入事件日志

basic_simple_event_log_backend 公有静态函数

  1. static string_type get_default_log_name();

    返回:

    默认日志名: Application

    		 
  2. static string_type get_default_source_name();

    返回:

    基于应用程序可执行文件名和接收器名称的默认日志源名
