函数模板 char_decor

boost::log::expressions::char_decor

概要

// In header: <boost/log/expressions/formatters/char_decorator.hpp>


template<typename FromRangeT, typename ToRangeT> 
  unspecified char_decor(FromRangeT const & from, ToRangeT const & to);

说明

该函数返回一个装饰器生成器对象. 该生成器提供 operator[], 可用于构造实际的装饰器.

注释

from 与 to 序列的大小必须相同. 输出中每处 from[i] 子串的出现都会被替换为 to[i].

参数:

from

将在输出中查找的字符串序列.

to

将用作替换内容的字符串序列.
