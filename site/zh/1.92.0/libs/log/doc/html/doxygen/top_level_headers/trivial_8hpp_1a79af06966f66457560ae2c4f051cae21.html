宏 BOOST_LOG_TRIVIAL

BOOST_LOG_TRIVIAL

概要

// In header: <boost/log/trivial.hpp>

BOOST_LOG_TRIVIAL(lvl)

说明

该宏用于发起日志记录. 宏的 lvl 参数指定以下严重级别之一: trace、debug、info、warning、error 或 fatal(参见 severity_level 枚举). 宏之后可以跟一个流式表达式来组合记录消息字符串. 例如:

BOOST_LOG_TRIVIAL(info) << "Hello, world!";
