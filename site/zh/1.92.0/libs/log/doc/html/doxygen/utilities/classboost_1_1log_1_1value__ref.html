类模板 value_ref

boost::log::value_ref — 所存储属性值的引用包装器.

概要

// In header: <boost/log/utility/value_ref.hpp>

template<typename T, typename TagT> 
class value_ref : public type< T, TagT > {
public:
  // types
  typedef T    value_type;  // Referenced value type. 
  typedef TagT tag_type;    // Tag type. 

  // public member functions
  value_ref() = default;
  template<typename U> explicit value_ref(U const &) noexcept;
  explicit operator bool() const noexcept;
  bool operator!() const noexcept;
  bool empty() const noexcept;
  void swap(value_ref &) noexcept;
};

说明

value_ref 类模板提供对所存储属性值的访问. 它不是传统的引用包装器, 因为它可以为空(即不引用任何值), 也可以引用不同类型的值. 因此, 根据使用场景, 其接口和行为结合了 Boost.Ref、Boost.Optional 和 Boost.Variant 的特性.

模板参数 T 可以是单个类型, 也可以是被引用的可能类型的 MPL 序列. 引用包装器将充当可选引用, 或指向指定类型的引用的可选 variant. 无论哪种情况, 被引用的值都不可修改(即 value_ref 始终建模 const 引用).

模板参数 TagT 是可选的. 它可用于自定义对该引用包装器的操作, 例如将引用的值写入日志.

value_ref 公有成员函数

  1. value_ref() = default;

    默认构造函数. 创建一个不引用任何值的引用包装器.

  2. template<typename U> explicit value_ref(U const & val) noexcept;

    初始化构造函数. 创建一个引用指定值的引用包装器.

  3. explicit operator bool() const noexcept;

    该运算符验证包装器是否引用值.

  4. bool operator!() const noexcept;

    该运算符验证包装器是否不引用值.

  5. bool empty() const noexcept;

    返回:

    true, 若包装器不引用值.

    		 
  6. void swap(value_ref & that) noexcept;

    交换两个引用包装器
