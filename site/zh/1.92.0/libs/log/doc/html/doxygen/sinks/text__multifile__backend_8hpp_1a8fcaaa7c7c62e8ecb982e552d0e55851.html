函数模板 as_file_name_composer

boost::log::sinks::file::as_file_name_composer

概要

// In header: <boost/log/sinks/text_multifile_backend.hpp>


template<typename FormatterT> 
  file_name_composer_adapter< FormatterT > 
  as_file_name_composer(FormatterT const & fmt, 
                        std::locale const & loc = std::locale());

说明

该函数将日志记录格式化器采纳为文件名生成器

参数:

fmt

要采纳的格式化器函数对象

loc

用于字符编码转换和格式化的 locale
