结构体模板 severity

boost::log::sources::severity — 严重级别支持特性.

概要

// In header: <boost/log/sources/severity_feature.hpp>

template<typename LevelT = int> 
struct severity {
  // member classes/structs/unions
  template<typename BaseT> 
  struct apply {
    // types
    typedef basic_severity_logger< BaseT, LevelT > type;
  };
};

说明

具有该特性的日志记录器会在构造时注册一个整数值类型的特殊属性. 该属性将通过该日志记录器产生的每条日志记录提供严重级别. 构造日志记录时可以省略严重级别, 此时将使用默认级别. 默认级别也可以通过传递给日志记录器构造函数来自定义.

严重级别属性的类型可以作为模板参数指定给特性模板. 默认情况下将使用 int.
