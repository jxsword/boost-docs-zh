函数 add_common_attributes

boost::log::add_common_attributes — 简单属性初始化例程.

概要

// In header: <boost/log/utility/setup/common_attributes.hpp>


void add_common_attributes();

说明

该函数向日志系统添加常用属性. 具体而言, 以下属性会被全局注册:

  • LineID - 值类型为 unsigned int 的日志记录计数器

  • TimeStamp - 值类型为 boost::posix_time::ptime 的本地时间生成器

  • ProcessID - 值类型为 attributes::current_process_id::value_type 的当前进程标识符

  • ThreadID - 多线程构建中, 值类型为 attributes::current_thread_id::value_type 的当前线程标识符
