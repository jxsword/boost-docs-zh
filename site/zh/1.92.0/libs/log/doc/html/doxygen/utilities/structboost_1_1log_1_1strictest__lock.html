结构模板 strictest_lock

boost::log::strictest_lock — 该元函数从指定的锁类型中选出最严格的一种.

概要

// In header: <boost/log/utility/strictest_lock.hpp>

template<typename... LocksT> 
struct strictest_lock {
  // types
  typedef implementation_defined type;
};

说明

该模板支持 Boost.Thread 库提供的所有锁类型 (upgrade_to_unique_lock 除外), 另外还支持一个表示完全不加锁的伪锁 no_lock. 排他锁被视为最严格, 共享锁较弱, no_lock 则最弱.
