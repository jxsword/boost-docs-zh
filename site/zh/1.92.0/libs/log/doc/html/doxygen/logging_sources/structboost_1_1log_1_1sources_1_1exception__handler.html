boost::log::sources::exception_handler — 异常处理器支持特性.

概要

// In header: <boost/log/sources/exception_handler_feature.hpp>


struct exception_handler {
  // member classes/structs/unions
  template<typename BaseT> 
  struct apply {
    // types
    typedef basic_exception_handler_logger< BaseT > type;
  };
};

说明

具有该特性的日志记录器将提供一个额外的方法来安装异常处理器函数对象. 如果在打开或推送记录期间日志核心抛出异常, 将调用该函数对象.
