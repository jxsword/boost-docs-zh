类 timer

boost::log::attributes::timer — 一种生成自构造以来时间间隔属性值的属性类.

概要

// In header: <boost/log/attributes/timer.hpp>


class timer : public attribute {
public:
  // types
  typedef utc_time_traits::time_type::time_duration_type value_type;  // Attribute value type. 

  // public member functions
  timer();
  explicit timer(cast_source const &);
};

说明

timer 属性计算自构造以来经过的时间, 并在获取值时返回. 属性值类型为 boost::posix_time::time_duration.

在 Windows 平台上该属性有两种实现. 默认实现更精确但稍慢. 此版本使用 QueryPerformanceFrequence/QueryPerformanceCounter API 计算流逝时间.

在某些 CPU 上使用这些函数存在已知问题, 尤其是启用了 Cool'n'Quiet 技术的 AMD Athlon. 有关更多信息及可能的解决方案, 请参阅以下链接:

http://support.microsoft.com/?scid=kb;en-us;895980 http://support.microsoft.com/?id=896256

如果这些解决方案都不适用, 可以自行定义 BOOST_LOG_NO_QUERY_PERFORMANCE_COUNTER 宏, 回退到基于 Boost.DateTime 的另一种实现.

timer 公有成员函数

    构造函数. 开始计时.

  2. explicit timer(cast_source const & source);
