boost::log::record_view — 日志记录视图类.

说明

日志记录封装与单条日志语句相关的全部信息, 特别是属性值视图和日志消息字符串. 该视图是不可变的, 它实现为引用计数实现的包装器.

record_view 公有成员函数

  1. record_view();

    默认构造函数. 创建一个空记录视图, 等价于无效的记录句柄.

    后置条件:

    !*this == true 

  2. record_view(record_view const & that) noexcept;

    复制构造函数

  3. record_view(record_view && that) noexcept;

    移动构造函数. 操作之后源记录的内容未指定.

  4. ~record_view() noexcept;

    析构函数. 销毁记录, 释放处理该记录所涉及的接收器和属性值.

  5. record_view & operator=(record_view const & that) noexcept;

    拷贝赋值

  6. record_view & operator=(record_view && that) noexcept;

    移动赋值. 操作之后源记录的内容未指定.

  7. attribute_value_set const & attribute_values() const noexcept;

    要求:

    !!*this

    返回:

    对附加到此记录的属性值集合的引用

    		 
  8. bool operator==(record_view const & that) const noexcept;

    相等比较

    参数:

    that

    比较对象

    返回:

    true, 若 *this 与 that 标识同一条日志记录, 或两者都未标识任何记录; 否则为 false.

    		 
  9. bool operator!=(record_view const & that) const noexcept;

    不等比较

    参数:

    that

    比较对象

    返回:

    !(*this == that) 

  10. explicit operator bool() const noexcept;

    转换为未指定的布尔类型

    返回:

    true, 若 *this 标识一条日志记录; false, 若 *this 无效

    		 
  11. bool operator!() const noexcept;

    反向转换为未指定的布尔类型

    返回:

    false, 若 *this 标识一条日志记录; true, 若 *this 无效

    		 
  12. void swap(record_view & that) noexcept;

    交换两个句柄

    参数:

    that

    要与之交换的另一条记录 抛出: 无

    		 
  13. void reset() noexcept;

    重置日志记录句柄. 如果没有其他句柄残留, 日志记录会被关闭, 记录引用的所有资源都被释放.

    后置条件:

    !*this == true

    name

    属性名.

    返回:
