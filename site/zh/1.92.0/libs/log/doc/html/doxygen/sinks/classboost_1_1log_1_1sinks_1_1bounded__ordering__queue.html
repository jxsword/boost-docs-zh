类模板 bounded_ordering_queue

boost::log::sinks::bounded_ordering_queue — 有界有序日志记录排队策略.

概要

// In header: <boost/log/sinks/bounded_ordering_queue.hpp>

template<typename OrderT, std::size_t MaxQueueSizeV, 
         typename OverflowStrategyT> 
class bounded_ordering_queue : private OverflowStrategyT {
public:

  // public member functions
  std::chrono::steady_clock::duration get_ordering_window() const;

  // public static functions
  static std::chrono::steady_clock::duration 
  get_default_ordering_window() noexcept;

  // protected member functions
  template<typename ArgsT> explicit bounded_ordering_queue(ArgsT const &);
  void enqueue(record_view const &);
  bool try_enqueue(record_view const &);
  bool try_dequeue_ready(record_view &);
  bool try_dequeue(record_view &);

说明

bounded_ordering_queue 类旨在与 asynchronous_sink 前端一起用作日志记录排队策略.

该策略为记录排队机制提供以下性质:

  • 队列具有由 MaxQueueSizeV 模板参数指定的有限容量.

  • 达到容量上限时, 队列会调用 OverflowStrategyT 模板参数中指定的溢出处理策略来处理这种情况. 库为最常见的情况提供了溢出处理策略: drop_on_overflow 会静默丢弃日志记录, block_on_overflow 会让入队线程等待直到队列中有空间.

  • 队列具有固定的延迟窗口. 这意味着放入队列的每条日志记录通常在一定时间内不会被取出.

  • 队列在延迟窗口内执行稳定的记录排序. 排序谓词可以在 OrderT 模板参数中指定.

  1. static std::chrono::steady_clock::duration 
get_default_ordering_window() noexcept;

    返回默认排序窗口大小. 默认窗口大小取决于操作系统的线程调度机制.

bounded_ordering_queue 受保护成员函数

  1. template<typename ArgsT> explicit bounded_ordering_queue(ArgsT const & args);
    初始化构造函数.
  2. void enqueue(record_view const & rec);
    将日志记录入队到队列.
  3. bool try_enqueue(record_view const & rec);
    尝试将日志记录入队到队列.
  4. bool try_dequeue_ready(record_view & rec);
    尝试从队列中取出一条准备好处理的日志记录, 若队列为空则不阻塞.

    唤醒可能阻塞在 dequeue 方法中的线程.
