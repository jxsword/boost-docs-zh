函数模板 make_collector

boost::log::sinks::file::make_collector

概要

// In header: <boost/log/sinks/text_file_backend.hpp>


template<typename... ArgsT> 
  shared_ptr< collector > make_collector(ArgsT... const & args);

说明

该函数为指定的目标目录创建文件收集器. 每个目标目录由单个文件收集器管理, 因此如果对同一目录多次调用该函数, 它将返回对同一文件收集器的引用. 在不同接收器中使用同一收集器是安全的, 即使在多线程应用程序中也是如此.

可以为存储的文件指定某些限制, 例如最大总大小或目标目录中保留的最小可用空间. 如果未满足任何指定限制, 最旧的存储文件将被删除. 如果用不同的限制多次请求同一收集器, 该收集器将按照所有指定限制中最严格的组合行事.

支持以下命名参数:

  • target - 指定存储文件的目标目录. 此参数是必需的.

  • max_size - 指定收集器将尽量不超过的存储文件的最大总大小(以字节计). 如果大小超过该阈值, 将删除最旧的文件以释放空间. 注意, 如果单个文件的大小超过 max_size 值, 该阈值可能被超过. 若未指定, 不维护该阈值.

  • min_free_space - 指定收集器尝试维持的目标目录最小可用空间(以字节计). 如果超出该阈值, 将删除最旧的文件以释放空间. 若未指定, 不维护该阈值.

  • max_files - 指定存储的日志文件的最大数量. 如果文件数量超过该阈值, 将删除最旧的文件以释放空间. 若未指定, 不维护该阈值.

返回:

文件收集器.
