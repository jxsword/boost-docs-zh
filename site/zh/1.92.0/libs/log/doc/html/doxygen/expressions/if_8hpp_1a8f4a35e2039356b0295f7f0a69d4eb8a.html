函数模板 if_

boost::log::expressions::if_

概要

// In header: <boost/log/expressions/formatters/if.hpp>


template<typename CondT> unspecified if_(CondT const & cond);

说明

该函数返回一个条件格式化器生成器对象. 该生成器提供 operator[], 可用于构造实际的格式化器. 格式化器必须参与流式表达式.

参数:

cond

将用作条件的过滤表达式
