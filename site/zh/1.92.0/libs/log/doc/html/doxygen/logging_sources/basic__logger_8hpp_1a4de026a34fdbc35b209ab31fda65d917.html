宏 BOOST_LOG_DECLARE_LOGGER_TYPE

BOOST_LOG_DECLARE_LOGGER_TYPE — 该宏声明一个继承多个基类的日志记录器类.

概要

// In header: <boost/log/sources/basic_logger.hpp>

BOOST_LOG_DECLARE_LOGGER_TYPE(type_name, char_type, base_seq, threading)

说明

参数:

base_seq

基类模板类型标识符的 Boost.Preprocessor 序列

char_type

日志记录器的字符类型. 预期为 char 或 wchar_t.

threading

线程模型类

type_name

要声明的日志记录器类的名称
