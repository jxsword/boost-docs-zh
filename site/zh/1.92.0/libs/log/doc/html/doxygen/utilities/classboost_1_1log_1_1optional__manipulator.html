类模板 optional_manipulator

boost::log::optional_manipulator

概要

// In header: <boost/log/utility/manipulators/optional.hpp>

template<typename OptionalT, typename NoneT> 
class optional_manipulator {
public:

  // public member functions
  optional_manipulator(stored_optional_type, stored_none_type) noexcept;
  template<typename StreamT> void output(StreamT &) const;
};

说明

用于插入 optional 值的流操纵器.

optional_manipulator 公有成员函数

  1. optional_manipulator(stored_optional_type opt, stored_none_type none) noexcept;
    初始化构造函数.
  2. template<typename StreamT> void output(StreamT & stream) const;
    若值存在则输出该值, 否则输出 "none" 标记.

特化

  • 类模板 optional_manipulator<OptionalT, void>
