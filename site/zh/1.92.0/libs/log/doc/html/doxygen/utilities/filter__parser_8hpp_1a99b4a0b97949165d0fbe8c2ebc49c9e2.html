函数模板 register_filter_factory

boost::log::register_filter_factory

概要

// In header: <boost/log/utility/setup/filter_parser.hpp>


template<typename FactoryT> 
  boost::enable_if_c< is_base_and_derived< filter_factory< typenameFactoryT::char_type >, FactoryT >::value >::type 
  register_filter_factory(attribute_name const & name, 
                          shared_ptr< FactoryT > const & factory);

说明

该函数为指定属性名注册过滤器工厂对象. 在解析过滤字符串时, 该工厂将用于构造过滤器.

参数:

name

要与工厂关联的属性名

factory

过滤器工厂

要求:

name != NULL && factory != NULL, name 指向以零结尾的字符串
