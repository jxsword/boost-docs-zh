结构体 logger

boost::log::trivial::logger — 简单日志记录器标签.

概要

// In header: <boost/log/trivial.hpp>


struct logger {
  // types
  typedef trivial::logger_type logger_type;  // Logger type. 

  // public static functions
  static logger_type & get();
};

说明

该标签可用于获取与简单日志记录宏一起使用的日志记录器. 当日志记录器与其他需要日志记录器的宏一起使用时, 这可能有用.

logger 公有静态函数

  1. static logger_type & get();

    返回对简单日志记录器实例的引用
