函数模板 char_decor

boost::log::expressions::char_decor

概要

// In header: <boost/log/expressions/formatters/char_decorator.hpp>


template<typename RangeT> unspecified char_decor(RangeT const & decorations);

说明

该函数返回一个装饰器生成器对象. 该生成器提供 operator[], 可用于构造实际的装饰器.

参数:

decorations

将用作装饰内容的字符串对序列. 输出中每处 decorations[i].first 子串的出现都会被替换为 decorations[i].second.
