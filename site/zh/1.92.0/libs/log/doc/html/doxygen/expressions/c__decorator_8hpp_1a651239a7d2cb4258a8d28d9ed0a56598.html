全局变量 c_ascii_decor

boost::log::expressions::c_ascii_decor

概要

// In header: <boost/log/expressions/formatters/c_decorator.hpp>

unspecified c_ascii_decor;

说明

C 风格装饰器生成器对象. 行为与 c_decor 类似, 不同之处在于 c_ascii_decor 还会将所有非 ASCII 字符以及非可打印 ASCII 字符(空格字符除外)转换为 C 风格十六进制转义序列. 该生成器提供 operator[], 可用于构造实际的装饰器. 例如:

c_ascii_decor[ stream << attr< std::string >("MyAttr") ]

对于宽字符格式化, 有类似的 wc_ascii_decor 装饰器生成器对象.
