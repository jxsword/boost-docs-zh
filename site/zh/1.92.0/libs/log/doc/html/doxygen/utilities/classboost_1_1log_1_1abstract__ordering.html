类模板 abstract_ordering

boost::log::abstract_ordering — 基于指向记录视图实现数据的不透明指针的排序谓词.

概要

// In header: <boost/log/utility/record_ordering.hpp>

template<typename FunT = less> 
class abstract_ordering : private less {
public:
  // types
  typedef bool result_type;  // Result type. 

  // public member functions
  abstract_ordering();
  explicit abstract_ordering(FunT const &);
  result_type operator()(record_view const &, record_view const &) const;
};

说明

由于记录视图只引用共享的实现数据, 该谓词能够通过比较指向这些数据的指针对视图排序. 因此, 若两个视图引用相同的实现数据, 则认为它们等价. 否则, 在应用谓词之前, 不确定一条记录是否排在另一条之前. 注意, 排序在应用程序每次运行时都可能不同.

如果要将日志记录存储在关联容器中且性能开销尽可能小, 而特定顺序并不重要, 这种排序可能有用.

FunT 模板实参是实际用于比较指针的谓词. 它应能够比较 const void* 指针. 被比较的指针可能指向不同的内存区域, 这些指针不得以任何方式解释.

abstract_ordering 公有成员函数

  1. abstract_ordering();

    默认构造函数. 要求 FunT 可默认构造.

  2. explicit abstract_ordering(FunT const & fun);

    初始化构造函数. 构造 FunT 实例, 作为 fun 参数的副本.

  3. result_type operator()(record_view const & left, record_view const & right) const;

    排序运算符
