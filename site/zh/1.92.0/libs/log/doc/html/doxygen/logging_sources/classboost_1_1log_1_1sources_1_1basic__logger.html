boost::log::sources::basic_logger — 基本日志记录器类.

概要

// In header: <boost/log/sources/basic_logger.hpp>

template<typename CharT, typename FinalT, typename ThreadingModelT> 
class basic_logger : public ThreadingModelT {
public:
  // types
  typedef CharT                      char_type;                   // Character type. 
  typedef FinalT                     final_type;                  // Final logger type.

说明

basic_logger 类模板用作库提供的所有日志记录器的基类. 它也可用作用户自定义日志记录器的基类. 模板参数为:

  • CharT - 日志记录字符类型

  • FinalT - 日志记录器的最终类型, 最终派生自 basic_logger. 在最终类与 basic_logger 之间的层次结构中可能还有其他类.

  • ThreadingModelT - 线程模型策略. 必须提供 basic_logger 类及其层次结构中直到 FinalT 类的所有派生类所用的 Boost.Thread 锁定概念的方法. basic_logger 类本身要求 SharedLockable 概念的方法. 线程模型策略还必须是可默认构造和可拷贝构造的, 并支持成员函数 swap. 当前提供了两种策略: single_thread_model 和 multi_thread_model.

该日志记录器实现日志记录器的基本设施, 例如存储日志源特定属性集合和格式化日志记录消息. 基本日志记录器与日志核心交互, 以应用过滤并将记录传递给接收器.

basic_logger 公有成员函数

    构造函数. 初始化基本日志记录器类的内部数据结构, 获取日志核心的引用.

  2. basic_logger(basic_logger const & that);

    拷贝构造函数. 从源日志记录器复制所有属性.

    注释

    非线程安全. 复制前必须在最终类中对源日志记录器加锁.

    参数:

    that

    源日志记录器

    		 
  3. basic_logger(basic_logger && that);

    移动构造函数. 从源日志记录器移动所有属性.

    注释

    非线程安全. 复制前必须在最终类中对源日志记录器加锁.

    参数:

    that

    带命名参数的构造函数. 该构造函数忽略所有参数. 构造结果等价于默认构造.
