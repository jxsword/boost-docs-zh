函数模板 max_size_decor

boost::log::expressions::max_size_decor

概要

// In header: <boost/log/expressions/formatters/max_size_decorator.hpp>


template<typename CharT> 
  unspecified max_size_decor(std::size_t max_size, 
                             std::basic_string< CharT > const & overflow_marker);

说明

该函数返回一个装饰器生成器对象. 该生成器提供 operator[], 可用于构造实际的装饰器.

参数:

max_size

被装饰的格式化器能生成的最大字符数(即字符串元素对象数).

overflow_marker

若超出 max_size 限制, 附加到输出末尾的标记字符串.

要求:

overflow_marker 的长度不得超过 max_size 限制.
