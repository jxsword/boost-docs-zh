宏 BOOST_LOG_FUNCTION

BOOST_LOG_FUNCTION

概要

// In header: <boost/log/attributes/named_scope.hpp>

BOOST_LOG_FUNCTION()

说明

用于标记函数作用域的宏. 作用域名借助编译器构造, 包含当前函数签名. 该作用域名会被压入当前线程作用域列表的末尾.

并非所有编译器都支持该宏. 作用域名确切的形式可能因编译器而异.
