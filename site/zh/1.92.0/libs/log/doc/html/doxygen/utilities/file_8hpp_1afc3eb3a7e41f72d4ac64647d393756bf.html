函数模板 add_file_log

boost::log::add_file_log

概要

// In header: <boost/log/utility/setup/file.hpp>


template<typename... ArgsT> 
  shared_ptr< sinks::synchronous_sink< sinks::text_file_backend > > 
  add_file_log(ArgsT... const & args);

说明

该函数初始化日志库以将日志写入文件流.

注释

需要 target 命名参数来启用文件收集器以及与目标目录相关联的限制. 若未指定该参数, 将不会创建文件收集器, 也不会维护这些限制.

参数:

args

若干命名参数. 支持以下参数:

  • file_name 活动文件名或其模式. 此参数是必需的.

  • target_file_name - 指定在轮转时、将日志文件传递给文件收集器之前用于重命名日志文件的目标文件名模式. 该模式可以包含与 file_name 参数相同的占位符. 默认情况下不进行重命名, 即写入的日志文件按照 file_name 保留其名称.

  • open_mode 描述文件打开模式的掩码. 参见 std::ios_base::openmode.

  • rotation_size 应发生轮转的文件大小. 参见 basic_text_file_backend.

  • time_based_rotation 基于时间的文件轮转谓词. 参见 basic_text_file_backend.

  • auto_flush 布尔标志, 指示接收器是否应在每写入一条记录后自动刷新文件.

  • auto_newline_mode - 指定自动插入行尾换行符的模式. 必须是 auto_newline_mode 枚举的值. 默认为 auto_newline_mode::insert_if_missing.

  • target 存储轮转文件的目标目录. 启用文件收集器, 若指定还启用与目标目录相关联的限制. 参见 sinks::file::make_collector.

  • max_size 目标目录中轮转文件的最大总大小. 参见 sinks::file::make_collector.

  • min_free_space 目标目录中的最小可用空间. 参见 sinks::file::make_collector.

  • max_files 目标目录中轮转文件的最大总数. 参见 sinks::file::make_collector.

  • scan_method 扫描目标目录查找日志文件的方法. 参见 sinks::file::scan_method.

  • filter 指定要安装到接收器中的过滤器. 可以是表示过滤器的字符串, 或过滤器 lambda 表达式.

  • format 指定要安装到接收器中的格式化器. 可以是表示格式化器的字符串, 或格式化器 lambda 表达式(流式或类似 Boost.Format 的记法).

返回:

指向构造出的接收器的指针.
