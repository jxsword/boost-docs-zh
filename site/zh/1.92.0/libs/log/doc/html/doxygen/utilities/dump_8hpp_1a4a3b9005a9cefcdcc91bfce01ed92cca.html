函数模板 dump_elements

boost::log::dump_elements — 创建一个流操纵器, 它将以十六进制形式转储数组的元素.

概要

// In header: <boost/log/utility/manipulators/dump.hpp>


template<typename T> 
  bounded_dump_manip 
  dump_elements(T * data, std::size_t count, std::size_t max_count);

说明

参数:

data

指向数组开头的指针

count

区域的大小, 以 T 元素的数量计

max_count

要输出的最大元素数量

返回:

要放入流的操纵器
