结构体模板 basic_formatted_sink_backend

boost::log::sinks::basic_formatted_sink_backend — 支持消息格式化的日志接收器后端的基类.

概要

// In header: <boost/log/sinks/basic_sink_backend.hpp>

template<typename CharT, 
         typename FrontendRequirementsT = synchronized_feeding> 
struct basic_formatted_sink_backend : public basic_sink_backend< combine_requirements< synchronized_feeding, formatted_records >::type >
{
  // types
  typedef CharT                            char_type;              // Character type. 
  typedef std::basic_string< char_type >   string_type;            // Formatted string type. 
  typedef base_type::frontend_requirements frontend_requirements;  // Frontend requirements. 
};

说明

basic_formatted_sink_backend 类模板向前端表明该后端需要日志记录格式化.

如果接收器后端要求格式化字符串采用某种特定编码(例如底层 API 只支持窄字符或宽字符), 该类允许请求编码转换. 要执行转换, 应在 TargetCharT 模板参数中指定期望的最终字符类型.
