类 attribute

boost::log::attribute — 属性值工厂的基类.

概要

// In header: <boost/log/attributes/attribute.hpp>


class attribute {
public:
  // member classes/structs/unions

  // A base class for an attribute value factory.

  struct impl : public boost::intrusive_ref_counter< impl > {

    // public member functions
    virtual ~impl();
    virtual attribute_value get_value() = 0;

    // public static functions
    static void * operator new(std::size_t);
    static void operator delete(void *, std::size_t) noexcept;
  };

  // public member functions
  attribute() = default;
  attribute(attribute const &) noexcept;
  attribute(attribute &&) noexcept;
  explicit attribute(intrusive_ptr< impl >) noexcept;
  attribute & operator=(attribute const &) noexcept;
  attribute & operator=(attribute &&) noexcept;
  explicit operator bool() const noexcept;
  bool operator!() const noexcept;
  attribute_value get_value() const;
  void swap(attribute &) noexcept;

  // protected member functions
  impl * get_impl() const noexcept;
  void set_impl(intrusive_ptr< impl >) noexcept;

  // friend functions
  template<typename T> T attribute_cast(attribute const &);
};

说明

每个属性都由一个工厂表示, 该工厂基本上就是一个属性值生成器. 属性的唯一用途是在被请求时返回一个实际值. 最简单的属性可以始终返回其内部存储的同一个值, 但更复杂的属性可能执行相当多的工作才能返回值, 并且每次请求返回的值可能不同.

关于线程安全的一点说明. 属性应当做好被多个线程并发请求值的准备.

attribute 公有成员函数

  1. attribute() = default;

    默认构造函数. 创建一个空的属性值工厂, 在调用 set_impl 之前不可用.

  2. attribute(attribute const & that) noexcept;

    复制构造函数

  3. attribute(attribute && that) noexcept;

    移动构造函数

  4. explicit attribute(intrusive_ptr< impl > p) noexcept;

    初始化构造函数

    参数:

    p

    指向实现的指针. 不得为 NULL.

    		 
  5. attribute & operator=(attribute const & that) noexcept;

    拷贝赋值

  6. attribute & operator=(attribute && that) noexcept;

    移动赋值

  7. explicit operator bool() const noexcept;

    验证工厂不处于空状态

  8. bool operator!() const noexcept;

    验证工厂处于空状态

  9. attribute_value get_value() const;

    返回:

    实际的属性值. 不得返回空值(应使用异常指示错误).

    		 
  10. void swap(attribute & that) noexcept;

    该方法交换两个工厂(即它们的实现).

attribute 受保护成员函数

  1. impl * get_impl() const noexcept;

    返回:

    指向实现的指针

    		 
  2. void set_impl(intrusive_ptr< impl > p) noexcept;

    设置指向工厂实现的指针.

    参数:

    p

    指向实现的指针. 不得为 NULL.

attribute 友元函数

  1. template<typename T> T attribute_cast(attribute const & attr);

    该函数将一个属性工厂转换为另一个
