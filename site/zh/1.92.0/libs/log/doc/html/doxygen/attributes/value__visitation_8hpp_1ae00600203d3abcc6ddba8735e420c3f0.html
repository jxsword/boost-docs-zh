函数模板 visit

boost::log::visit

概要

// In header: <boost/log/attributes/value_visitation.hpp>


template<typename T, typename VisitorT> 
  visitation_result 
  visit(attribute_name const & name, attribute_value_set const & attrs, 
        VisitorT visitor);

说明

该函数将访问器应用于视图中的属性值. 用户必须显式指定要访问的属性值的类型或可能类型的集合.

参数:

name

要访问的属性值的名称.

attrs

在其中查找指定属性值的属性值集合.

visitor

接收属性值的函数对象.

返回:

访问的结果.
