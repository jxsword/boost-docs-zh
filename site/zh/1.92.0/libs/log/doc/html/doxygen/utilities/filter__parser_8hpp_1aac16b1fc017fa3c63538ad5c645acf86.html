函数模板 parse_filter

boost::log::parse_filter

概要

// In header: <boost/log/utility/setup/filter_parser.hpp>


template<typename CharT> filter parse_filter(const CharT * str);

说明

该函数从字符串解析过滤器

抛出: 若无法在字符序列中识别过滤器, 则抛出 std::exception 系异常.

参数:

str

包含过滤器描述的字符串.

要求:

str != NULL, str 指向以零结尾的字符串.

返回:

可用作过滤器的函数对象.
