类 drop_on_overflow

boost::log::sinks::drop_on_overflow — 日志记录丢弃策略.

概要

// In header: <boost/log/sinks/drop_on_overflow.hpp>


class drop_on_overflow {
};

说明

该策略会在有界异步接收器的队列溢出时导致日志记录被丢弃. 如果丢失日志记录不可接受, 则不应使用该策略.
