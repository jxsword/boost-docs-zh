宏 BOOST_LOG_ATTRIBUTE_KEYWORD_TYPE

BOOST_LOG_ATTRIBUTE_KEYWORD_TYPE — 该宏声明一个属性关键字类型.

概要

// In header: <boost/log/expressions/keyword.hpp>

BOOST_LOG_ATTRIBUTE_KEYWORD_TYPE(keyword_, name_, value_type_)

说明

该宏应在命名空间作用域中使用. 它展开为属性关键字类型定义, 包括 tag 命名空间和其中的关键字标签类型, 其布局如下:

namespace tag
{
  struct keyword_ :
    public boost::log::expressions::keyword_descriptor
  {
    typedef value_type_ value_type;
    static boost::log::attribute_name get_name();
  };
}

typedef boost::log::expressions::attribute_keyword< tag::keyword_ > keyword_type;

get_name 方法返回属性名.

注释

该宏只定义关键字的类型. 若还要定义关键字对象, 请改用 BOOST_LOG_ATTRIBUTE_KEYWORD 宏.

参数:

keyword_

关键字名称

name_

属性名字符串

value_type_

属性值类型
