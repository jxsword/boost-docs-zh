类模板 bounded_fifo_queue

boost::log::sinks::bounded_fifo_queue — 有界 FIFO 日志记录排队策略.

概要

// In header: <boost/log/sinks/bounded_fifo_queue.hpp>

template<std::size_t MaxQueueSizeV, typename OverflowStrategyT> 
class bounded_fifo_queue : private OverflowStrategyT {
public:

  // protected member functions
  bounded_fifo_queue();
  template<typename ArgsT> explicit bounded_fifo_queue(ArgsT const &);
  void enqueue(record_view const &);
  bool try_enqueue(record_view const &);
  bool try_dequeue_ready(record_view &);
  bool try_dequeue(record_view &);
  bool dequeue_ready(record_view &);
  void interrupt_dequeue();
};

说明

bounded_fifo_queue 类旨在与 asynchronous_sink 前端一起用作日志记录排队策略.

该策略描述日志记录的排队逻辑. 队列具有有限的容量, 达到容量上限时, 入队操作将调用 OverflowStrategyT 模板参数中指定的溢出处理策略来处理这种情况. 库为最常见的情况提供了溢出处理策略: drop_on_overflow 会静默丢弃日志记录, block_on_overflow 会让入队线程等待直到队列中有空间.

日志记录队列除了元素入队的先后顺序外, 不对排队的元素施加任何排序.

bounded_fifo_queue 受保护成员函数

  1. bounded_fifo_queue();
    默认构造函数.
  2. template<typename ArgsT> explicit bounded_fifo_queue(ArgsT const &);
    初始化构造函数.
  3. void enqueue(record_view const & rec);
    将日志记录入队到队列.
  4. bool try_enqueue(record_view const & rec);
    尝试将日志记录入队到队列.
  5. bool try_dequeue_ready(record_view & rec);
    尝试从队列中取出一条准备好处理的日志记录, 若队列为空则不阻塞.
  6. bool try_dequeue(record_view & rec);
    尝试从队列中取出日志记录, 若队列为空则不阻塞.
  7. bool dequeue_ready(record_view & rec);
    从队列中取出日志记录, 若队列为空则阻塞.
  8. void interrupt_dequeue();
    唤醒可能阻塞在 dequeue 方法中的线程.
