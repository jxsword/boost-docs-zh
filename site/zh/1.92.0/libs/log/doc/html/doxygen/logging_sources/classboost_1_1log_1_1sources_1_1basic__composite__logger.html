类模板 basic_composite_logger

boost::log::sources::basic_composite_logger — 继承多个特性的组合日志记录器.

概要

// In header: <boost/log/sources/basic_logger.hpp>

template<typename CharT, typename FinalT, typename ThreadingModelT, 
         typename FeaturesT> 
class basic_composite_logger :
  public inherit_features< RootT, FeaturesT >::type
{
public:
  // types
  typedef base_type::threading_model threading_model;  // Threading model being used. 
  typedef base_type::swap_lock       swap_lock;        // Lock requirement for the swap_unlocked method. 

  // public member functions
  basic_composite_logger();
  basic_composite_logger(basic_composite_logger const &);
  basic_composite_logger(logger_base &&);
  template<typename ArgsT> explicit basic_composite_logger(ArgsT const &);
  std::pair< attribute_set::iterator, bool > 
  add_attribute(attribute_name const &, attribute const &);
  void remove_attribute(attribute_set::iterator);
  void remove_all_attributes();
  attribute_set get_attributes() const;
  void set_attributes(attribute_set const &);
  record open_record();
  template<typename ArgsT> record open_record(ArgsT const &);
  void push_record(record &&);
  void swap(basic_composite_logger &);

  // protected member functions
  FinalT & assign(FinalT const &);
};

说明

组合日志记录器是一个辅助类, 用于简化将特性组合成最终日志记录器的过程. 用户的日志记录器类应派生自该组合日志记录器类, 并以字符类型、用户的日志记录器类、线程模型和所需特性列表来实例化. 前三个参数传递给 basic_logger 类模板. 特性列表必须是 MPL 类型序列, 其中每个元素都是一个一元 MPL 元函数类, 应用于其参数后会得到一个派生自该参数的日志记录特性类. 库提供的每个日志记录器特性都可以参与该特性列表.

basic_composite_logger 公有成员函数

  1. basic_composite_logger();

    默认构造函数(默认构造所有特性)

  2. basic_composite_logger(basic_composite_logger const & that);

    复制构造函数

  3. basic_composite_logger(logger_base && that);

    移动构造函数

  4. template<typename ArgsT> explicit basic_composite_logger(ArgsT const & args);

    带命名参数的构造函数

  5. std::pair< attribute_set::iterator, bool > 
add_attribute(attribute_name const & name, attribute const & attr);

    该方法将属性添加到日志源特定属性集合. 该属性会被隐式添加到用当前日志记录器产生的每条日志记录中.

    参数:

    name

    属性名.

    attr

    属性工厂.

    返回:

    一对值. 若第二个成员为 true, 则属性已添加, 第一个成员指向该属性. 否则属性未被添加, 第一个成员指向阻止添加的属性.

    		 
  6. void remove_attribute(attribute_set::iterator it);

    该方法从日志源特定属性集合中移除属性.

    参数:

    it

    指向先前添加的属性的迭代器.

    要求:

    该属性是通过对此日志记录器实例调用 add_attribute 添加的.

    后置条件:

    该属性不再注册为此日志记录器的日志源特定属性. 迭代器在移除后失效.

    		 
  7. void remove_all_attributes();

    该方法从日志记录器中移除所有属性. 指向被移除属性的所有迭代器和引用都会失效.

  8. attribute_set get_attributes() const;

    该方法从日志记录器获取包含所有属性的集合的副本.

    返回:

    属性集合的副本. 属性为浅拷贝.

    		 
  9. void set_attributes(attribute_set const & attrs);

    该方法将整个属性集合安装到日志记录器中. 指向前一个集合元素的所有迭代器和引用都会失效. attrs 集合的迭代器不能再与该日志记录器一起使用(也就是说, 完成后日志记录器拥有 attrs 的副本).

    参数:

    attrs

    要安装到日志记录器中的属性集合. 属性为浅拷贝.

    		 
  10. record open_record();

    该方法在日志核心中打开一条新的日志记录.

    返回:

    若日志记录成功打开, 则为有效的记录句柄; 否则为无效句柄.

    		 
  11. template<typename ArgsT> record open_record(ArgsT const & args);

    该方法在日志核心中打开一条新的日志记录.

    参数:

    args

    一组额外的命名参数. 该参数被忽略.

    返回:

    若日志记录成功打开, 则为有效的记录句柄; 否则为无效句柄.

    		 
  12. void push_record(record && rec);

    该方法将构造好的消息推送给日志核心

    参数:

    rec

    带有已格式化消息的日志记录

    		 
  13. void swap(basic_composite_logger & that);

    swap 的线程安全实现

basic_composite_logger 受保护成员函数

  1. FinalT & assign(FinalT const & that);

    最终类的赋值运算符. 线程安全, 提供强异常保证.
