类 text_file_backend

boost::log::sinks::text_file_backend — 文本文件日志接收器后端的实现.

概要

// In header: <boost/log/sinks/text_file_backend.hpp>


class text_file_backend : public basic_formatted_sink_backend< char, combine_requirements< synchronized_feeding, flushing >::type >
{
public:
  // types
  typedef base_type::char_type            char_type;                      // Character type. 
  typedef base_type::string_type          string_type;                    // String type to be used as a message text holder. 
  typedef std::basic_ostream< char_type > stream_type;                    // Stream type. 
  typedef unspecified                     open_handler_type;              // File open handler. 
  typedef unspecified                     close_handler_type;             // File close handler. 
  typedef unspecified                     time_based_rotation_predicate;  // Predicate that defines the time-based condition for file rotation. 

  // public member functions
  text_file_backend();
  template<typename... ArgsT> explicit text_file_backend(ArgsT... const &);
  ~text_file_backend();
  template<typename PathT> void set_file_name_pattern(PathT const &);
  template<typename PathT> void set_target_file_name_pattern(PathT const &);
  void set_open_mode(std::ios_base::openmode);
  void set_file_collector(shared_ptr< file::collector > const &);
  void set_open_handler(open_handler_type const &);
  void set_close_handler(close_handler_type const &);
  void set_rotation_size(uintmax_t);
  void set_time_based_rotation(time_based_rotation_predicate const &);
  void enable_final_rotation(bool);
  void auto_flush(bool = true);
  void set_auto_newline_mode(auto_newline_mode);
  filesystem::path get_current_file_name() const;
  uintmax_t scan_for_files(file::scan_method = file::scan_matching, 
                           bool = true);
  void consume(record_view const &, string_type const &);
  void flush();
  void rotate_file();
};

说明

该接收器后端将已格式化的日志记录放入文本文件. 该接收器支持文件轮转和高级文件控制, 例如大小和文件数量限制.

text_file_backend 公有成员函数

  1. text_file_backend();

    默认构造函数. 构造出的接收器后端使用所有参数的默认值.

  2. template<typename... ArgsT> explicit text_file_backend(ArgsT... const & args);

    构造函数. 用指定的命名参数创建接收器后端. 支持以下命名参数:

    • file_name - 指定实际写入日志的活动文件名模式. 模式可以包含目录和文件名部分, 但只有文件名部分可以包含占位符. 该后端支持 Boost.DateTime 占位符, 用于将当前时间和日期注入文件名. 此外还支持一个额外的 N 占位符, 它将被一个递增的整数文件计数器替换. 该占位符还可以包含 printf 兼容形式的宽度说明(例如 %5N). 打印出的文件计数器将始终以零填充. 若未指定 file_name, 将使用模式 "%5N.log".

    • target_file_name - 指定在轮转时、将日志文件传递给文件收集器之前用于重命名日志文件的目标文件名模式. 该模式可以包含与 file_name 参数相同的占位符. 默认情况下不进行重命名, 即写入的日志文件按照 file_name 保留其名称.

    • open_mode - 文件打开模式. 该模式应以与 std::ios_base::openmode 兼容的掩码形式给出. 若未指定, 将使用 trunc | out.

    • rotation_size - 指定临时文件的大致大小(以写入的字符数计), 达到该大小时文件会被传递给文件收集器. 注意该大小不计入写入文件期间可能发生的任何字符转换. 若未指定, 文件不会因达到任何大小而轮转.

    • time_based_rotation - 指定基于时间的文件轮转谓词. 若未指定, 将不执行基于时间的文件轮转.

    • enable_final_rotation - 指定一个标志, 是否在接收器后端销毁时执行日志文件轮转. 默认为 true.

    • auto_flush - 指定一个标志, 是否在每写入一条日志记录后自动刷新文件. 默认为 false.

    • auto_newline_mode - 指定自动插入行尾换行符的模式. 必须是 auto_newline_mode 枚举的值. 默认为 auto_newline_mode::insert_if_missing.

    注释

    有关文件名模式的注意事项请阅读 sinks::file::collector::scan_for_files 文档.

    析构函数

  4. template<typename PathT> void set_file_name_pattern(PathT const & pattern);

    该方法为正在写入的文件设置活动文件名通配模式. 该通配模式支持将日期和时间注入文件名.

    参数:

    pattern

    正在写入的文件的名称模式.

    		 
  5. template<typename PathT> 
  void set_target_file_name_pattern(PathT const & pattern);

    该方法为正在轮转的文件设置目标文件名通配模式. 该通配模式支持将日期和时间注入文件名.

    当日志文件被轮转时, 将使用该模式重命名刚写入的日志文件(其名称依据 file_name 构造函数参数中的模式或通过调用 set_file_name_pattern 设置), 就在将文件传递给文件收集器之前.

    参数:

    pattern

    正在轮转的文件的名称模式.

    		 
  6. void set_open_mode(std::ios_base::openmode mode);

    该方法设置文件打开模式

    参数:

    mode

    文件打开模式

    		 
  7. void set_file_collector(shared_ptr< file::collector > const & collector);

    该方法设置日志文件收集器函数. 该函数在文件轮转时被调用, 并传入已写入的文件名.

    参数:

    collector

    文件收集器函数对象

    		 
  8. void set_open_handler(open_handler_type const & handler);

    该方法设置文件打开处理器. 每当后端打开新的临时文件时都会调用该处理器. 该处理器可以向打开的文件写入文件头, 以维持文件的有效性.

    参数:

    handler

    文件打开处理器函数对象

    		 
  9. void set_close_handler(close_handler_type const & handler);

    该方法设置文件关闭处理器. 每当后端关闭临时文件时都会调用该处理器. 该处理器可以向打开的文件写入文件尾, 以维持文件的有效性.

    参数:

    handler

    文件关闭处理器函数对象

    		 
  10. void set_rotation_size(uintmax_t size);

    该方法设置最大文件大小. 达到该大小时, 将执行文件轮转.

    注释

    该大小不计入底层 API 中可能发生的任何字符转换. 这可能导致写入文件的实际大小更大.

    参数:

    size

    最大文件大小, 以字符计.

    		 
  11. void set_time_based_rotation(time_based_rotation_predicate const & predicate);

    该方法设置定义文件轮转基于时间的条件的谓词.

    注释

    轮转总是在写入日志记录时发生, 因此轮转并不严格受指定条件的约束.

    参数:

    predicate

    定义文件轮转基于时间的条件的谓词. 若为空, 将不发生基于时间的轮转.

    		 
  12. void enable_final_rotation(bool enable);

    该方法允许启用或禁用接收器销毁时的日志文件轮转.

    默认情况下, 若日志文件已被写入, 接收器后端会在销毁时轮转该日志文件.

    参数:

    enable

    该标志指示是否应执行最终轮转.

    		 
  13. void auto_flush(bool enable = true);

    设置标志: 在每条日志记录之后自动刷新正在写入的文件的写缓冲区.

    参数:

    enable

    该标志指示是否应执行自动缓冲区刷新.

    		 
  14. void set_auto_newline_mode(auto_newline_mode mode);

    选择是否应在每条日志记录之后自动插入行尾换行符. 可能的操作模式参见 auto_newline_mode 的描述.

    参数:

    mode

    行尾换行符插入模式.

    		 
  15. filesystem::path get_current_file_name() const;

    返回:

    当前打开的日志文件的名称. 若没有打开的文件, 返回空路径.

    		 
  16. uintmax_t scan_for_files(file::scan_method method = file::scan_matching, 
                         bool update_counter = true);

    对目标目录执行扫描, 查找应用程序先前运行可能遗留的日志文件. 找到的文件会被文件收集器视作已轮转的文件.

    文件扫描可以以两种方式进行: 或者将目标目录中的所有文件都视为日志文件, 或者只考虑满足目标文件名模式的文件. 更多信息参见 sinks::file::collector::scan_for_files 的文档.

    注释

    该方法实质上委托给文件收集器的同名函数.

    参数:

    method

    文件扫描方法

    update_counter

    若 true 且 method 为 scan_matching, 该方法会尝试根据找到的文件更新内部文件计数器. 否则计数器不受影响.

    要求:

    文件收集器和正确的文件名模式均已设置.

    返回:

    找到的文件数量.

    		 
  17. void consume(record_view const & rec, string_type const & formatted_message);

    该方法将消息写入接收器

  18. void flush();

    该方法刷新当前打开的日志文件

  19. void rotate_file();

    该方法轮转文件
