结构体 collector

boost::log::sinks::file::collector — 文件收集器的基类.

概要

// In header: <boost/log/sinks/text_file_backend.hpp>


struct collector {

  // public member functions
  collector() = default;
  virtual ~collector() = default;
  virtual void store_file(filesystem::path const &) = 0;
  virtual bool is_in_storage(filesystem::path const &) const = 0;
  virtual scan_result 
  scan_for_files(scan_method, filesystem::path const & = filesystem::path()) = 0;
  collector(collector const &) = delete;
  collector & operator=(collector const &) = delete;
};

说明

文件接收器后端支持的所有文件收集器都应继承该类.

collector 公有成员函数

  1. collector() = default;

    默认构造函数

  2. virtual ~collector() = default;

    虚析构函数

  3. virtual void store_file(filesystem::path const & src_path) = 0;

    该函数将指定的文件存储到存储区. 可能导致删除较旧的文件和较长时间的文件移动.

    参数:

    src_path

    要存储的文件的名称

    		 
  4. virtual bool is_in_storage(filesystem::path const & src_path) const = 0;

    该函数检查指定路径是否指向存储区中的现有文件.

    参数:

    src_path

    要检查的路径

    		 
  5. virtual scan_result 
scan_for_files(scan_method method, 
               filesystem::path const & pattern = filesystem::path()) = 0;

    扫描目标目录以查找已存储的文件. 找到的文件会被添加到收集器中, 以便在需要时进行跟踪和删除.

    该函数可以以两种方式扫描目录: 或者将目录中的每个文件都视为日志文件, 或者只考虑名称与指定模式匹配的文件. 模式可以包含以下占位符:

    • y, Y, m, d - 日期组件, 含义同 Boost.DateTime.

    • H, M, S, f - 时间组件, 含义同 Boost.DateTime.

    • N - 数字文件计数器. 也可以包含 printf 兼容形式的宽度说明(例如 %5N). 得到的数字将始终以零填充.

    • %% - 百分号

    不支持所有其他占位符.

    注释

    若 method 为 scan_matching, 该函数的效果高度依赖于 pattern 的定义. 建议选择占位符易于区分的模式(即占位符之间有分隔符). 否则可能错误地找到或找不到某些文件, 进而导致删除非预期的文件.

    参数:

    method

    扫描方法. 若指定为 no_scan, 该调用没有效果.

    pattern

    若 method 为 scan_matching, 则为文件名模式. 否则不使用该参数.

    返回:

    文件系统扫描的结果. 只有当 method 为 scan_matching、pattern 包含 N 占位符且找到至少一个与该模式匹配的文件时, 才会填充最后的文件计数器.

    		 
  6. collector(collector const &) = delete;
  7. collector & operator=(collector const &) = delete;
