函数 current_scope

boost::log::current_scope

概要

// In header: <boost/log/support/exception.hpp>


current_scope_info current_scope();

说明

该函数返回一个包含当前作用域栈的错误信息对象. 该信息随后可附加到异常上, 并在捕获位置提取. 提取出的作用域列表不会受异常传播期间可能发生的任何作用域变化的影响.

注释

有关如何维护作用域列表, 参见 named_scope 属性文档.
