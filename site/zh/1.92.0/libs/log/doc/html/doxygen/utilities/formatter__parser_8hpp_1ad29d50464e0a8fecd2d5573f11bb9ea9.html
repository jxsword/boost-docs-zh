函数模板 register_simple_formatter_factory

boost::log::register_simple_formatter_factory — 该函数注册一个简单格式化器工厂.

概要

// In header: <boost/log/utility/setup/formatter_parser.hpp>


template<typename AttributeValueT, typename CharT> 
  void register_simple_formatter_factory(attribute_name const & attr_name);

说明

该函数注册一个简单格式化器工厂. 已注册的工厂将生成等价于 log::expressions::attr 格式化器的格式化器(即使用原生 operator<< 来格式化属性值). 若指定, 该工厂不使用格式串中的任何参数.

参数:

attr_name

属性名

要求:

!!attr_name.
