函数模板 range_manip

boost::log::range_manip

概要

// In header: <boost/log/utility/manipulators/range.hpp>


template<typename RangeT, typename DelimiterT> 
  boost::disable_if_c< is_scalar< DelimiterT >::value, range_manipulator< RangeT, DelimiterT > >::type 
  range_manip(RangeT const & range, DelimiterT const & delimiter);

说明

范围操纵器生成器函数.

注释

range 与 delimiter 对象的生命期都必须长于创建的操纵器对象.

参数:

range

要输出的元素范围. 该范围必须支持 begin 和 end 迭代器, 其元素必须支持流输出.

delimiter

用于分隔输出中元素的分隔符. 可选. 若未指定, 元素不加分隔地输出.

返回:

要插入流中的操纵器.
