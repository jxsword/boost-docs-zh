类模板 impl_template

boost::log::attributes::function::impl_template — 工厂实现.

概要

// In header: <boost/log/attributes/function.hpp>



// Factory implementation.
template<typename T> 
class impl_template : public function< R >::impl {
public:

  // public member functions
  explicit impl_template(T const &);
  virtual attribute_value get_value();
};

说明

impl_template 公有成员函数

  1. explicit impl_template(T const & fun);

    带所存储委托初始化的构造函数

  2. virtual attribute_value get_value();

    返回:

    实际的属性值. 不得返回空值(应使用异常指示错误).
