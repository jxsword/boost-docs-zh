结构体模板 channel

boost::log::sources::channel — 通道支持特性.

概要

// In header: <boost/log/sources/channel_feature.hpp>

template<typename ChannelT = std::string> 
struct channel {
  // member classes/structs/unions
  template<typename BaseT> 
  struct apply {
    // types
    typedef basic_channel_logger< BaseT, ChannelT > type;
  };
};

说明

具有该特性的日志记录器会在构造时自动注册一个具有指定值的属性, 该值即为通道名. 在日志记录器的生命周期内, 通道名可以通过调用 channel 方法或在日志语句中指定名称来修改.

通道名的类型可以通过将其作为模板参数提供给特性模板来自定义. 默认情况下将使用字符串.
