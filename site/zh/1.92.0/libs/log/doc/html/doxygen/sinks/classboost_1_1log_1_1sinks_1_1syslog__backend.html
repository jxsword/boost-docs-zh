类 syslog_backend

boost::log::sinks::syslog_backend — syslog 接收器后端的实现.

概要

// In header: <boost/log/sinks/syslog_backend.hpp>


class syslog_backend : public basic_formatted_sink_backend< char > {
public:
  // types
  typedef base_type::char_type   char_type;             // Character type. 
  typedef base_type::string_type string_type;           // String type that is used to pass message test. 
  typedef unspecified            severity_mapper_type;  // Syslog severity level mapper type. 

  // public member functions
  syslog_backend();

  void set_target_address(std::string const &, unsigned short = 514);
  void set_target_address(boost::asio::ip::address const &, 
                          unsigned short = 514);
  void consume(record_view const &, string_type const &);
};

说明

该后端提供对 RFC3164 中定义的 syslog 协议的支持. 该后端通过 UDP 将日志记录发送到远程主机. 可以通过调用 set_target_address 方法指定主机名. 默认情况下, 日志记录将被发送到 localhost:514. 也可以通过调用 set_local_address 方法指定本地地址. 默认情况下, syslog 数据包将从任何可用的本地地址发送.

用相同的本地地址创建多个接收器后端是安全的 — 进程内的这些后端将共享同一个套接字. 对于使用 syslog 后端从同一套接字发送记录的不同进程也是如此. 但是, 如果某个第三方设施正在使用该套接字, 则不保证能正常工作.

在具有原生 syslog 实现的系统上, 为了绕过可能生效的安全限制, 最好使用 POSIX syslog API 而不是直接管理套接字. 为此, 必须将 use_impl = native 传递给后端构造函数. 但请注意, 在这种情况下, 只有一次机会指定 syslog 设施和进程标识字符串 — 即在第一个原生 syslog 后端构造时. 其他原生 syslog 后端会忽略这些参数. 显然, set_local_address 和 set_target_address 方法对原生后端没有效果. 在没有原生支持 POSIX syslog API 的平台上使用 use_impl = native 也不会有效果.

syslog_backend 公有成员函数

  1. syslog_backend();

    构造函数. 创建一个使用 syslog::user 设施码的基于 UDP 套接字的后端. 将使用 IPv4 协议.

  2. template<typename... ArgsT> explicit syslog_backend(ArgsT... const & args);

    构造函数. 用指定的命名参数创建接收器后端. 支持以下命名参数:

    • facility - 指定设施码. 若未指定, 将使用 syslog::user.

    • use_impl - 指定后端实现. 可以是以下之一:

    • native - 若可用则使用原生 syslog API. 若原生 API 不可用, 则等价于 udp_socket_based.

    • udp_socket_based - 使用符合 RFC3164 协议规范的基于 UDP 套接字的实现. 这是默认值.

    • ip_version - 若使用基于套接字的实现, 指定要使用的 IP 协议版本. 可以是 v4(默认)或 v6.

    • ident - 进程标识字符串. 该参数仅受原生 syslog 实现支持.

  3. ~syslog_backend();

    析构函数

  4. void set_severity_mapper(severity_mapper_type const & mapper);

    该方法安装将应用程序严重级别映射到 syslog 级别的函数对象

  5. void set_local_address(std::string const & addr, unsigned short port = 514);

    该方法设置日志记录将从其发送的本地主机名. 主机名会被解析以获得最终 IP 地址.

    注释

    若后端被构造为使用原生 syslog API, 则无效

    参数:

    addr

    本地地址

    port

    本地端口号
