类型 scope_name_type

boost::log::attributes::named_scope_entry::scope_name_type — 作用域条目类型.

概要

// In header: <boost/log/attributes/named_scope.hpp>


enum scope_name_type { general, function };

说明

描述作用域名的具体类别

general
作用域名包含一些非结构化字符串, 库不应解释它们.
function
作用域名包含函数签名.
