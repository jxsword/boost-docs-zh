宏 BOOST_LOG_ATTRIBUTE_KEYWORD

BOOST_LOG_ATTRIBUTE_KEYWORD — 该宏声明一个属性关键字.

概要

// In header: <boost/log/expressions/keyword.hpp>

BOOST_LOG_ATTRIBUTE_KEYWORD(keyword_, name_, value_type_)

说明

该宏提供与 BOOST_LOG_ATTRIBUTE_KEYWORD_TYPE 类似的定义, 并额外定义关键字对象.

参数:

keyword_

关键字名称

name_

属性名字符串

value_type_

属性值类型
