类 unbounded_fifo_queue

boost::log::sinks::unbounded_fifo_queue — 无界 FIFO 日志记录排队策略.

概要

// In header: <boost/log/sinks/unbounded_fifo_queue.hpp>


class unbounded_fifo_queue {
public:

  // protected member functions
  unbounded_fifo_queue();
  template<typename ArgsT> explicit unbounded_fifo_queue(ArgsT const &);
  void enqueue(record_view const &);
  bool try_enqueue(record_view const &);
  bool try_dequeue_ready(record_view &);
  bool try_dequeue(record_view &);
  bool dequeue_ready(record_view &);
  void interrupt_dequeue();
};

说明

unbounded_fifo_queue 类旨在与 asynchronous_sink 前端一起用作日志记录排队策略.

该策略实现了线程间日志记录缓冲的最简单逻辑: 队列没有限制, 且除了元素入队的先后顺序外不对排队的元素施加任何排序. 因此该队列提供了不错的性能和可伸缩性, 但如果接收器后端无法足够快地消费日志记录, 队列可能会不受控制地增长. 当这是一个问题时, 建议使用某种有界策略.

unbounded_fifo_queue 受保护成员函数

  1. unbounded_fifo_queue();
    默认构造函数.
  2. template<typename ArgsT> explicit unbounded_fifo_queue(ArgsT const &);
    初始化构造函数.
  3. void enqueue(record_view const & rec);
    将日志记录入队到队列.
  4. bool try_enqueue(record_view const & rec);
    尝试将日志记录入队到队列.
  5. bool try_dequeue_ready(record_view & rec);
    尝试从队列中取出一条准备好处理的日志记录, 若队列为空则不阻塞.
  6. bool try_dequeue(record_view & rec);
    尝试从队列中取出日志记录, 若队列为空则不阻塞.
  7. bool dequeue_ready(record_view & rec);
    从队列中取出日志记录, 若队列为空则阻塞.
  8. void interrupt_dequeue();
    唤醒可能阻塞在 dequeue 方法中的线程.
