致谢

本节谨向直接或间接参与本库设计与开发的各界人士致谢.

衷心感谢我的父母, 感谢他们对我教育以及计算机科学学习的支持.

非常感谢 Andrzej Krzemienski 评审了本库的早期版本, 提供了宝贵的见解, 并就断言要求交流了早期想法.

非常感谢 Vicente J. Botet Escriba 评审了本库的早期版本, 提供了宝贵的见解, 并建议使用专用的 trait 来复制旧值.

感谢 Steven Watanabe 就 C++、SFINAE 和内省机制提供了宝贵的见解.

感谢 Dave Abrahams 主持了本库的 Boost 评审.

感谢 Daniel James 协助将本库文件并入 Boost Git 仓库.

感谢 James E. King III 将本库集成到 Boost 的持续集成 (CI) 体系中.

感谢 David Maley 分享其富有启发性的工作的源码, 该工作在 C++ 中模拟了契约式编程与子契约, 见 [Maley99].

非常感谢 Thorsten Ottosen 在 [N1962] 提案 (及其先前各修订版) 上所做的工作, 并在需要时直接与库作者澄清提案要求.

非常感谢 Bertrand Meyer 在 [Meyer97] 中对契约式编程所做的开创性且全面的工作.

最后, 非常感谢整个 Boost 社区及其 邮件列表 对本库提出了宝贵意见, 并对 C++ 编程语言给出了深刻见解.
