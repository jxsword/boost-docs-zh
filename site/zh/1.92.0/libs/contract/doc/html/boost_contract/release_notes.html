1.0.1 发布

September 12, 2019

清理与小修复:

  1. 从 C++17 编译器起使用 std::uncaught_exceptions (取代现已过时的 std::uncaught_exception).
  2. 修复了若干警告.
  3. 移除了对 Boost.System 的链接 (Boost.System 现在是仅头文件库).
  4. 把本库加入 Boost 的持续集成 (CI).
  5. 修复了文档中的拼写错误.

发布的文件包含于 Boost 1.72.0.

0.5.0 发布

September 2, 2017

不用宏的契约:

  1. 用普通 C++ 代码 (而不是宏) 来编写契约.
    1. 被移除的宏非常难用, 因为它们要求程序员学习一种领域特定的嵌入式语言, 以取代声明函数和类的惯常 C++ 语法.
    2. 被移除的宏还使代码可读性变差, 增加编译时间 (由于大量的预处理器元编程), 并给出晦涩的编译器错误.
    3. 不过, 被移除的宏能更正确地在代码声明 (而非定义) 中指定契约, 并且在契约被禁用时完全移除额外代码 (这两点在当前版本的本库中也能做到, 但代价是手动编写一些样板代码——以前这些由宏自动处理; 参见 分离函数体实现 与 禁用契约编译).
  2. 通过移除一些与契约式编程没有直接关系的额外特性简化了本库, 具体包括:
    1. 移除了循环变体 (因为这些即使有用也极少被使用).
    2. 移除了命名参数和推导参数 (因为这些可以直接用 Boost.Parameter 编程实现).
    3. 移除了概念 (因为这些可以直接用 Boost.ConceptCheck 编程实现).
    4. 移除了对虚说明符 override、final 和 new 的模拟 (因为 override 可以直接用 C++11 编程实现, 而 final 和 new 即使有用也极少被使用).
    5. 移除了对 static_assert 的模拟 (因为这可以直接用 C++11 编程实现, 或使用 Boost.StaticAssert).
  3. 确保即使在与多重继承一起使用子契约时, 旧值和返回值也只复制一次.
  4. 改进了在多重继承下为子契约搜索继承树的模板元编程算法.
  5. 异常说明符和函数 try 块也适用于契约抛出的异常, 而不仅仅是函数体抛出的异常.
  6. 增加了异常保证的契约 (使用 .except(...) 等).
  7. 为 "audit" 和 "axiom" 增加了预定义断言级别.
  8. 增加了 call_if 与 condition_if (断言要求在本库先前修订版中也受支持, 但由契约宏生成的内部代码处理).

发布了文件.

0.4.0 发布

June 4, 2012

简化语法, 增加命名参数和概念:

  1. 通过把多余的括号削减到最低必要程度来简化语法 (使用了最初由 Boost.LocalFunction 引入的一些预处理器解析技巧).
  2. 后置条件旧值只复制 old-of 表达式 (例如只复制 vector 的大小而不是整个 vector). 这提升了性能, 并且只为旧值表达式类型引入 ConstantCopyConstructible 要求 (例如 vector 可能不可复制, 而其大小总是可复制的, 因为它是整数类型). 移除了 copyable 标记.
  3. 函数体在宏之外定义 (因此定义处的编译器错误保留其惯常含义).
  4. 增加了 CONTRACT_CLASS 宏, 并免去了重复声明元素的需要 (不必重复函数声明、不必在函数声明中重复类名等).
  5. 使用 _TPL 宏以减少编译期开销 (而不是在内部把所有模板都做成契约函数以便随意使用 typename).
  6. 重载不再要求参数名唯一.
  7. 增加了类 C++11 的虚说明符.
  8. 增加了常量断言, 以及用于 select 断言 if 条件和循环变体的常量表达式.
  9. 增加了命名参数和推导参数.
  10. 增加了概念检查.
  11. 移除了不使用宏使用本库的接口 (程序员需要为非宏接口编写太多样板代码, 以至于它实际不可用; 而且同时支持宏接口和非宏接口限制了宏能做的事).

0.3.469 发布

February 21, 2010

支持大多数/全部契约式编程特性:

  1. 编写契约时不再使用 self、variable.now 和 variable.old. 对象 this 和变量现在像成员函数中惯常那样访问. 后置条件中用 CONTRACT_OLDOF(variable) 访问旧值.
  2. 增加了 (precondition)、(postcondition) 和 (body), 以便在函数签名序列中指定契约. 如果没有前置条件, 则直接从序列中省略 (precondition) ({...}) (后置条件同理, 而函数体则是必需的). 对于非 void 函数, 用户可以用 (postcondition) (result-name) ({...}) 为结果参数命名.
  3. 把契约类模板改为使用与 Boost.Function 相同的语法 (即 F 函数类型).
  4. 增加了对自由函数和静态成员函数的支持.
  5. 增加了多重继承的子契约支持.
  6. 增加了总是被检查的静态类不变式 (也在构造函数入口、析构函数出口以及静态成员函数中检查).
  7. 增加了块不变式和类 Eiffel 的循环变体.
  8. 增加了自定义契约失败时动作的处理器 (默认为 std::terminate()).
  9. 移除了用 Doxygen 自动生成契约文档的特性 (这与新增的 (precondition)、(postcondition) 和 (body) 不兼容, 因为 Doxygen 预处理器无法处理 Boost.Preprocessor 序列).
  10. 重写了全部文档 (现在使用 Boost.QuickBook 而不是 Doxygen).

发布了文件.

0.2.190 发布

November 21, 2009

在 GCC 和 MSVC 上编译:

  1. 使用 GCC (Linux 和 Cygwin) 和 MSVC (Windows XP) 编译.
