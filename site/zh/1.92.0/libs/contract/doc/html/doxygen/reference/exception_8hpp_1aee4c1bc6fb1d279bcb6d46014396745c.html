类型定义 failure_handler

failure_handler — 断言失败处理器函数的类型 (不带 from 参数).

概要

// In header: <boost/contract/core/exception.hpp>


typedef boost::function< void()> failure_handler;

说明

由该类型指定的断言失败处理器函数必须是返回 void 的零元仿函数. 例如, 这用于为实现检查指定契约失败处理器.

参见: 失败时抛出异常
