宏 BOOST_CONTRACT_STATIC_PUBLIC_FUNCTION

BOOST_CONTRACT_STATIC_PUBLIC_FUNCTION — 为静态公有函数编写可在编译期完全禁用的契约.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_STATIC_PUBLIC_FUNCTION(...)

说明

它与 BOOST_CONTRACT_PRECONDITION、BOOST_CONTRACT_POSTCONDITION、BOOST_CONTRACT_EXCEPT、BOOST_CONTRACT_OLD 和

class u {
    friend class boost::contract::access;

    BOOST_CONTRACT_STATIC_INVARIANT({ // Optional (as for non-static).
        BOOST_CONTRACT_ASSERT(...);
        ...
    })

public:
    static void f(...) {
        BOOST_CONTRACT_OLD_PTR(old_type)(old_var);
        BOOST_CONTRACT_PUBLIC_FUNCTION(u)
            BOOST_CONTRACT_PRECONDITION([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            BOOST_CONTRACT_OLD([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(old_expr);
                ...
            })
            BOOST_CONTRACT_POSTCONDITION([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            BOOST_CONTRACT_EXCEPT([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
        ; // Trailing `;` is required.

        ... // Function body.
    }
    
    ...
};

作为优化, 对于没有前置条件、后置条件和异常保证的静态公有函数, 且所在类没有静态不变式时, 可以省略此调用.

BOOST_CONTRACT_STATIC_PUBLIC_FUNCTION(class_type) 展开为等价于如下所示的代码 (注意当定义了 BOOST_CONTRACT_NO_PUBLIC_FUNCTIONS 时不会生成任何代码):

#ifndef BOOST_CONTRACT_NO_PUBLIC_FUNCTIONS
    boost::contract::check internal_var =
            boost::contract::public_function<class_type>()
#endif

其中:

  • class_type 是包含声明契约的静态公有函数的类的类型. (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

  • internal_var 是本库在内部生成的变量名 (这个名字唯一, 但仅在不同行号上唯一, 因此这个宏不能在同一行上多次展开).

参见: 禁用契约编译、 静态公有函数
