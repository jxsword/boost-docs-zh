结构模板 call_if_statement<false, Then, internal_type>

boost::contract::call_if_statement<false, Then, internal_type> — 处理静态谓词为 false 的模板特化 (在 C++17 编译器上不需要, 改用 if constexpr).

概要

// In header: <boost/contract/call_if.hpp>

template<typename Then> 
struct call_if_statement<false, Then, internal_type> {

  // public member functions
  explicit call_if_statement(Then const &);
  template<typename Else> result_of< Else()>::type else_(Else) const;
  template<bool ElseIfPred, typename ElseIfThen> 
    call_if_statement< ElseIfPred, ElseIfThen > else_if_c(ElseIfThen) const;
  template<typename ElseIfPred, typename ElseIfThen> 
    call_if_statement< ElseIfPred::value, ElseIfThen > 
    else_if(ElseIfThen) const;
};

说明

这个模板特化处理所有 else 分支仿函数模板调用 (无论它们是否返回 void). 通常, 这个类模板只通过 boost::contract::call_if 和 boost::contract::call_if_c 的返回值来实例化.

参见: 断言要求

模板参数

  1. typename Then

    当静态谓词为 true 时要调用的仿函数模板的类型 (对这个模板特化而言永远不会出现这种情况).

call_if_statement 公有成员函数

  1. explicit call_if_statement(Then const & f);
    用 then 分支仿函数模板构造此对象.

    参数:

    f

    then 分支零元仿函数模板. 对这个模板特化而言, 仿函数模板调用 f() 绝不会被编译或执行 (因为 if 语句的静态谓词为 false). f() 的返回类型必须与此 call-if 对象指定的所有其他仿函数模板调用的返回类型相同 (或可隐式转换为后者).

    		 
  2. template<typename Else> result_of< Else()>::type else_(Else f) const;
    指定 else 分支仿函数模板.
    注释

    result_of<Else()>::type 表达式只有当静态谓词已被检查为 false 时才需要求值 (因为只有在这种情况下才需要编译 Else()). 因此, 这个 result-of 表达式是惰性求值的, 且只在该模板特化的实例化中求值.

    参数:

    f

    else 分支零元仿函数模板. 对这个模板特化而言, 仿函数模板调用 f() 实际会被编译并执行 (因为 if 语句的静态谓词为 false). f() 的返回类型必须与此 call-if 对象指定的所有其他仿函数模板调用的返回类型相同 (或可隐式转换为后者).

    返回:

    调用 else 分支仿函数模板 f() 所返回值的一个副本.

    		 
  3. template<bool ElseIfPred, typename ElseIfThen> 
  call_if_statement< ElseIfPred, ElseIfThen > else_if_c(ElseIfThen f) const;
    指定一个 else-if 分支仿函数模板 (使用静态布尔谓词).

    参数:

    f

    else-if 分支零元仿函数模板. 当且仅当 f() 为 ElseIfPred 时, 仿函数模板调用 true 才实际被编译并执行 (因为对这个模板特化而言, if 语句的静态谓词已经是 false). f() 的返回类型必须与此 call-if 对象指定的所有其他仿函数模板调用的返回类型相同 (或可隐式转换为后者).

    模板参数:

    ElseIfPred

    选择编译并执行哪个仿函数模板调用的静态布尔谓词.

    返回:

    一个 call-if 语句, 以便在需要时指定 else 语句和额外的 else-if 语句. 最终, 它将是被编译并执行的那个仿函数模板调用的返回值.

    		 
  4. template<typename ElseIfPred, typename ElseIfThen> 
  call_if_statement< ElseIfPred::value, ElseIfThen > 
  else_if(ElseIfThen f) const;
    指定一个 else-if 分支仿函数模板 (使用零元布尔元函数).

    参数:

    f

    else-if 分支零元仿函数模板. 当且仅当 f() 为 ElseIfPred::value 时, 仿函数模板调用 true 才实际被编译并执行 (因为对这个模板特化而言, if 语句的静态谓词已经是 false). f() 的返回类型必须与此 call-if 对象指定的所有其他仿函数模板调用的返回类型相同 (或可隐式转换为后者).

    模板参数:

    ElseIfPred

    选择编译并执行哪个仿函数模板调用的零元布尔元函数.

    返回:

    一个 call-if 语句, 以便在需要时指定 else 语句和额外的 else-if 语句. 最终, 它将是被编译并执行的那个仿函数模板调用的返回值.
