set_invariant_failure 函数

boost::contract::set_invariant_failure — 设置类不变式的失败处理器 (入口和出口两处).

概要

// In header: <boost/contract/core/exception.hpp>


from_failure_handler const & 
set_invariant_failure(from_failure_handler const & f);

说明

这是为方便起见提供的, 等同于用同一个仿函数参数 boost::contract::set_entry_invariant_failure 同时调用 boost::contract::set_exit_invariant_failure 和 f.

抛出: 此函数被声明为 noexcept (C++11 之前为 throw()).

参见: 失败时抛出异常、 类不变式、 volatile 公有函数

参数:

f

要为入口和出口不变式同时设置的新失败处理器仿函数.

返回:

作为参数传递的同一失败处理器仿函数 f (例如用于串联函数调用).
