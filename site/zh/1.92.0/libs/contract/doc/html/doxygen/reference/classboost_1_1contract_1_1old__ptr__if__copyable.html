类模板 old_ptr_if_copyable

boost::contract::old_ptr_if_copyable — 不要求所指向旧值类型可复制的旧值指针.

概要

// In header: <boost/contract/old.hpp>

template<typename T> 
class old_ptr_if_copyable {
public:
  // types
  typedef T element_type;  // Pointed old value type. 

  // public member functions
  old_ptr_if_copyable();
  old_ptr_if_copyable(old_ptr< T > const &);
  T const & operator*() const;
  T const * operator->() const;
  explicit operator bool() const;
};

说明

可以使用 BOOST_CONTRACT_OLDOF 或 boost::contract::make_old 把此指针设置为指向实际的旧值副本:

template<typename T> // Type `T` might or not be copyable.
class u {
public:
    virtual void f(..., boost::contract::virtual_* v = 0) {
        boost::contract::old_ptr_if_copyable<T> old_var =
                BOOST_CONTRACT_OLDOF(v, old_expr);
        ...
            if(old_var) ... // Always null for non-copyable types.
        ...
    }

    ...
};

参见: 旧值要求

模板参数

  1. typename T

    所指向旧值的类型. 如果该类型不可复制 (即 boost::contract::is_old_value_copyable<T>::value 为 false), 此指针将始终为空 (但本库不会在此指针被解引用时产生编译期错误).

old_ptr_if_copyable 公有成员函数

  1. old_ptr_if_copyable();
    把此旧值指针构造为空.
  2. old_ptr_if_copyable(old_ptr< T > const & other);
    从一个要求旧值类型可复制的旧值指针构造此旧值指针.

    被指向值对象的所有权转移到此指针. 当使用 BOOST_CONTRACT_OLDOF 赋值此类型的对象时, 本库会隐式调用此构造函数 (用户代码通常不会显式调用此构造函数).

    参数:

    other

    要求旧值类型可复制的旧值指针.

    		 
  3. T const & operator*() const;
    解引用此旧值指针.

    如果此指针为空, 这里将产生运行期错误; 但如果所指向类型 T 不可复制 (即 boost::contract::is_old_value_copyable<T>::value 为 false), 则不会产生编译期错误.

    返回:

    所指向的旧值. 契约断言不应改变程序状态, 因此此成员函数是 const 的, 并以对常量对象的引用形式返回旧值 (参见 常量正确性).

    		 
  4. T const * operator->() const;
    以结构解引用方式访问此旧值指针.

    如果所指向类型 T 不可复制 (即 boost::contract::is_old_value_copyable<T>::value 为 false), 这里将返回空, 但不会产生编译期错误.

    返回:

    指向旧值的指针 (如果此旧值指针为空, 则为空). 契约断言不应改变程序状态, 因此此成员函数是 const 的, 并以指向常量对象的指针形式返回旧值 (参见 常量正确性).

    		 
  5. explicit operator bool() const;
    查询此旧值指针是否为空 (safe-bool 运算符).

    (在不支持 C++11 显式类型转换运算符的编译器上, 这使用 safe-bool 模拟实现. )

    返回:

    如果此指针非空则为 true, 否则为 false.
