宏 BOOST_CONTRACT_NAMED_OVERRIDE

BOOST_CONTRACT_NAMED_OVERRIDE — 声明任意名字的覆盖类型特征.

概要

// In header: <boost/contract/override.hpp>

BOOST_CONTRACT_NAMED_OVERRIDE(type_name, func_name)

说明

声明名为 type_name 的覆盖类型特征, 供公有函数覆盖作为显式模板参数传递给 boost::contract::public_function.

参见: 命名覆盖

参数:

func_name

公有函数覆盖的函数名. 即使该函数名被重载, 这个宏也只调用一次 (相同名字的所有重载函数使用同一个覆盖类型特征, 参见 函数重载). (这不是可变参数宏参数, 但它绝不应包含逗号, 因为它是一个标识符. )

type_name

这个宏将声明的覆盖类型特征的名字. (这不是可变参数宏参数, 但它绝不应包含逗号, 因为它是一个标识符. )
