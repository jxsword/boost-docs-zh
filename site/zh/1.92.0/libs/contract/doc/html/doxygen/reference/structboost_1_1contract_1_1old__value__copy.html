结构模板 old_value_copy

boost::contract::old_value_copy — 复制旧值的特征.

概要

// In header: <boost/contract/old.hpp>

template<typename T> 
struct old_value_copy {

  // public member functions
  explicit old_value_copy(T const &);
  T const & old() const;
};

说明

默认情况下, 这个特征的实现使用 T's 复制构造函数对指定值做一次复制. 不过, 程序员可以特化这个特征, 用不同于 T's 复制构造函数的用户自定义操作来复制旧值. 这个特征的默认实现等价于:

template<typename T>
class old_value_copy {
public:
    explicit old_value_copy(T const& old) :
        old_(old) // One single copy of value using T's copy constructor.
    {}

    T const& old() const { return old_; }

private:
    T const old_; // The old value copy.
};

本库只对可复制的旧值类型 T (即 boost::contract::is_old_value_copyable<T>::value 为 true 的类型) 实例化并使用这个特征.

参见: 旧值要求

old_value_copy 公有成员函数

  1. explicit old_value_copy(T const & old);
    通过对指定的旧值做一次复制来构造此对象.

    这是本库中唯一真正复制旧值的操作. 这保证本库对旧值做一次且仅一次复制 (如果它们确实需要被复制, 参见 BOOST_CONTRACT_NO_OLDS).

    参数:

    old

    要复制的旧值.

    		 
  2. T const & old() const;
    返回对被复制旧值的 (常量) 引用.

    契约断言不应改变程序状态, 因此旧值副本以 const 形式返回 (参见 常量正确性).
