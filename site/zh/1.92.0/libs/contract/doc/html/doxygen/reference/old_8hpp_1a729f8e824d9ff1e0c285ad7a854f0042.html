null_old 函数

boost::contract::null_old — 返回一个 "空" 旧值.

概要

// In header: <boost/contract/old.hpp>


old_value null_old();

说明

相关的旧值指针也将为空. 此函数通常只由 BOOST_CONTRACT_OLDOF 展开的代码调用.

参见: 不使用宏

返回:

空旧值.
