函数模板 condition_if_c

boost::contract::condition_if_c — 使用静态布尔谓词选择布尔仿函数模板条件的编译与执行 (在 C++17 编译器上不需要, 改用 if constexpr).

概要

// In header: <boost/contract/call_if.hpp>


template<bool Pred, typename Then> 
  bool condition_if_c(Then f, bool else_ = true);

说明

当且仅当指定的静态布尔谓词 f() 为 Pred 时, 编译并执行零元布尔仿函数模板调用 true; 否则在运行期平凡地返回 else_ (默认为 true).

调用 boost::contract::condition_if_c<Pred>(f, else_) 在逻辑上等价于 boost::contract::call_if_c<Pred>(f, [] { return else_; }) (但其内部实现经过优化, 实际上并不使用 call_if_c).

参见: 断言要求

参数:

f

零元布尔仿函数模板. 当且仅当 f() 为 Pred 时, 编译并执行仿函数模板调用 true.

else_

当 Pred 为 false 时返回的布尔值 (而不是编译并执行仿函数模板调用 f()).

模板参数:

Pred

选择何时编译并执行仿函数模板调用 f() 的静态布尔谓词.

返回:

当静态谓词 f() 为 Pred 时, 由 true 返回的布尔值. 否则平凡地返回 else_.
