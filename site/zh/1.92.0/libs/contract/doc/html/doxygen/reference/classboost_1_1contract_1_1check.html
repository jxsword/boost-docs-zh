check 类

boost::contract::check — 检查契约的 RAII 对象.

概要

// In header: <boost/contract/check.hpp>


class check {
public:

  // public member functions
  template<typename F> check(F const &);
  check(check const &);
  template<typename VirtualResult> 
    check(specify_precondition_old_postcondition_except< VirtualResult > const &);
  template<typename VirtualResult> 
    check(specify_old_postcondition_except< VirtualResult > const &);
  template<typename VirtualResult> 
    check(specify_postcondition_except< VirtualResult > const &);
  check(specify_except const &);
  check(specify_nothing const &);
  ~check();
};

说明

一般而言, 构造此对象时, 它会在入口检查类不变式和前置条件, 并在函数体处复制旧值. 析构此对象时, 它会在出口检查类不变式、后置条件和异常保证. 此对象强制以下各项 (参见 契约式编程概述):

  • 只有当函数体不抛出异常时才检查后置条件.

  • 只有当函数体抛出异常时才检查异常保证.

  • 构造函数入口绝不检查类不变式.

  • 只有当函数体抛出异常时, 析构函数出口才检查类不变式 (尽管在 C++ 中析构函数通常不应被编写为抛出异常, 且自 C++11 起它们被隐式声明为 noexcept).

  • 静态不变式总是在入口和出口检查 (且无论函数体是否抛出异常).

以这种方式使用时, 此对象被构造并初始化为契约函数 boost::contract::function、boost::contract::constructor、boost::contract::destructor 或 boost::contract::public_function 之一的返回值. 除此之外, 当用于编写实现检查时, 此对象还可以从零元仿函数构造.

check 公有成员函数

  1. template<typename F> check(F const & f);
    为实现检查构造此对象.

    这可用于在实现代码 (函数体等) 中编写检查. 此构造函数未被声明为 explicit, 因此初始化可以使用赋值语法 =.

    抛出: 如果程序员指定的契约失败处理器抛出异常而不是终止程序, 这里就可能抛出异常 (参见 失败时抛出异常).

    参数:

    f

    断言实现检查的零元仿函数. 此对象在实现代码中的声明点一经构造, 就会立即调用 f() (参见 实现检查).

    		 
  2. check(check const & other);
    从指定对象复制构造此对象.

    此对象会检查契约, 而被复制的对象则不会 (即契约检查的所有权从被复制对象转移到此构造函数创建的新对象).

    参数:

    other

    被复制的对象.

    		 
  3. template<typename VirtualResult> 
  check(specify_precondition_old_postcondition_except< VirtualResult > const & contract);
    构造此对象以检查指定契约.

    这会在入口检查类不变式 (如果给定契约指定了它们). 此构造函数未被声明为 explicit, 因此初始化可以使用赋值语法 =.

    抛出: 如果程序员指定的契约失败处理器抛出异常而不是终止程序, 这里就可能抛出异常 (参见 失败时抛出异常).

    参数:

    contract

    要检查的契约 (通常是 boost::contract::function 或 boost::contract::public_function 的返回值).

    模板参数:

    VirtualResult

    如果声明契约的外围函数是虚公有函数或覆盖公有函数, 则为该函数的返回类型; 否则此参数总是 void. (通常这个模板参数由 C++ 自动推导, 程序员无需显式指定. )

  7. check(specify_nothing const & contract);
    构造此对象以检查指定契约.

    这会在入口检查类不变式和前置条件, 然后在函数体处复制旧值; 此时此对象的析构函数还会检查后置条件和异常保证 (如果给定契约指定了其中任一项). 此构造函数未被声明为 explicit, 因此初始化可以使用赋值语法 =.

    抛出: 如果程序员指定的契约失败处理器抛出异常而不是终止程序, 这里就可能抛出异常 (参见 失败时抛出异常).

  8. ~check();
    析构此对象.

    这会在出口检查类不变式, 并在外围函数体未抛出异常时检查后置条件、在函数体抛出异常时检查异常保证 (前提是分别为外围类以及构造此对象时给出的契约参数指定了类不变式、后置条件和异常保证).

    抛出: 如果程序员指定的契约失败处理器抛出异常而不是终止程序, 这里就可能抛出异常 (参见 失败时抛出异常). (自 C++11 起此函数被声明为 noexcept(false). )
