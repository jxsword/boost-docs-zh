函数模板 public_function

boost::contract::public_function — 为返回 void 的公有函数覆盖 (无论是否为虚函数) 编写契约.

概要

// In header: <boost/contract/public_function.hpp>


template<typename Override, typename F, typename Class, typename... Args> 
  specify_precondition_old_postcondition_except 
  public_function(virtual_ * v, F f, Class * obj, Args &... args);

说明

这用于为返回 void: 的公有函数覆盖 (无论是否为虚函数) 指定前置条件、后置条件、异常保证、在函数体处复制的旧值, 并检查类不变式.

class u
    #define BASES private boost::contract::constructor_precondition<u>, \
            public b, private w
    : BASES
{
    friend class boost::contract::access;

    typedef BOOST_CONTRACT_BASE_TYPES(BASES) base_types;
    #undef BASES

    void invariant() const { // Optional (as for static and volatile).
        BOOST_CONTRACT_ASSERT(...);
        ...
    }

    BOOST_CONTRACT_OVERRIDES(f)

public:
    // Override from `b::f`.
    void f(t_1 a_1, ..., t_n a_n, boost::contract::virtual_* v = 0) {
        boost::contract::old_ptr<old_type> old_var;
        boost::contract::check c = boost::contract::public_function<
                override_f>(v, &u::f, this, a_1, ..., a_n)
            .precondition([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            .old([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(v, old_expr);
                ...
            })
            .postcondition([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            .except([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
        ;

        ... // Function body.
    }
    
    ...
};

公有函数覆盖应当始终调用 boost::contract::public_function, 否则本库将无法在子契约中正确使用它.

参见: 公有函数覆盖

参数:

v

来自外围公有函数覆盖的尾随参数, 类型为 boost::contract::virtual_*, 默认值为 0.

f

指向声明契约的外围公有函数覆盖的指针 (另参见 函数重载).

obj

来自声明契约的外围公有函数覆盖作用域的对象 this. 此对象可能是可变的 (mutable)、const、volatile 或 const volatile, 取决于外围函数的 cv 限定符 (volatile 公有函数将检查 volatile 类不变式, 参见 volatile 公有函数).

args

传递给声明契约的外围公有函数覆盖的所有实参 (按引用, 并按它们在外围函数声明中出现的顺序), 但不包括尾随参数 v.

模板参数:

Override

使用 override_function-name 或相关宏声明的类型特征 BOOST_CONTRACT_OVERRIDE. 这个模板参数必须显式指定 (因为没有函数实参可供 C++ 自动推导).

F

声明契约的外围公有函数覆盖的函数指针类型. (通常这个模板参数由 C++ 自动推导, 程序员无需显式指定. )

Class

包含声明契约的虚公有函数的类的类型. (通常这个模板参数由 C++ 自动推导, 程序员无需显式指定. )

Args

传递给声明契约的外围公有函数覆盖的所有参数的类型, 但不包括尾随参数类型 boost::contract::virtual_*. 在不支持可变参数模板的编译器上, 本库使用预处理器元编程在内部实现此函数 (此时, 支持的最大实参数量由 BOOST_CONTRACT_MAX_ARGS 定义). (通常这些模板参数由 C++ 自动推导, 程序员无需显式指定. )

返回:

此函数的结果必须被赋给一个类型为 boost::contract::check 的变量, 该变量必须显式声明 (即不使用 C++11 的 auto 声明), 并在公有函数体代码之前就地声明 (否则本库将产生运行期错误, 参见 BOOST_CONTRACT_ON_MISSING_CHECK_DECL).
