结构模板 call_if_statement<true, Then, internal_type>

boost::contract::call_if_statement<true, Then, internal_type> — 在返回 void 和返回非 void 的 then 分支仿函数模板调用之间进行分派的模板特化 (在 C++17 编译器上不需要, 改用 if constexpr).

概要

// In header: <boost/contract/call_if.hpp>

template<typename Then> 
struct call_if_statement<true, Then, internal_type> : public boost::contract::call_if_statement< true, Then, result_of< Then()>::type >
{

  // public member functions
  explicit call_if_statement(Then);
};

说明

其基类是一个 call-if 语句, 以便在需要时指定 else 和 else-if 语句. 通常, 这个类模板只通过 boost::contract::call_if 和 boost::contract::call_if_c 的返回值来实例化.

注释

result_of<Then()>::type 表达式只有当静态谓词已被检查为 true 时才需要求值 (因为只有在这种情况下才需要编译 Then()). 因此, 这个模板特化引入了一个额外的间接层, 它是正确地惰性求值这个 result-of 表达式所必需的.

参见: 断言要求

模板参数

  1. typename Then

    当静态谓词为 true 时要调用的仿函数模板的类型 (正是这个模板特化的情形).

call_if_statement 公有成员函数

  1. explicit call_if_statement(Then f);
    用 then 分支仿函数模板构造此对象.

    参数:

    f

    then 分支零元仿函数模板. 对这个模板特化而言, 仿函数模板调用 f() 会被编译并调用 (因为 if 语句的静态谓词为 true). f() 的返回类型必须与此 call-if 对象指定的所有其他仿函数模板调用的返回类型相同 (或可隐式转换为后者).
