access 类

boost::contract::access — 把此类声明为友元, 以便把不变式和基类型编写为私有成员.

概要

// In header: <boost/contract/core/access.hpp>


class access {
};

说明

把此类声明为指定契约的用户自定义类的友元, 然后不变式函数和基类型 typedef 就可以声明为非公有成员:

class u
    #define BASES public b, private w
    : BASES
{
    friend class boost::contract::access;

    typedef BOOST_CONTRACT_BASE_TYPES(BASES) base_types; // Private.
    #undef BASES

    void invariant() const { ... } // Private (same for static and volatile).

public:
    ...
};

在实际代码中, 程序员很可能会选择把此类声明为友元, 以便完全控制其用户自定义类的公有接口 (本文档的示例为了简洁而未普遍这样做). 此类并不是供程序员直接使用的——除了把它声明为 friend 之外 (这就是此类没有任何公有成员且不可复制的原因).

警告

如果不把此类声明为用户自定义类的友元, 在某些编译器上 (如 MSVC) 会导致编译错误, 因为检查契约所需的私有成员将不可访问. 在其他编译器上 (如 GCC 和 Clang), 私有访问反而会导致 SFINAE 失败, 不报告编译错误, 而不变式与子契约会在运行期被静默跳过. 因此, 程序员必须确保要么把此类声明为友元, 要么始终把不变式函数和基类型 typedef 声明为公有成员.
