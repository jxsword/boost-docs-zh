函数模板 public_function

boost::contract::public_function — 为静态公有函数编写契约.

概要

// In header: <boost/contract/public_function.hpp>


template<typename Class> 
  specify_precondition_old_postcondition_except public_function();

说明

这用于为静态公有函数指定前置条件、后置条件、异常保证、在函数体处复制的旧值, 并检查静态类不变式:

class u {
    friend class boost::contract::access;

    static void static_invariant() { // Optional (as for non-static).
        BOOST_CONTRACT_ASSERT(...);
        ...
    }

public:
    static void f(...) {
        boost::contract::old_ptr<old_type> old_var;
        boost::contract::check c = boost::contract::public_function<u>()
            .precondition([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            .old([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(old_expr);
                ...
            })
            .postcondition([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            .except([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
        ;

        ... // Function body.
    }
    
    ...
};

作为优化, 对于没有前置条件、后置条件和异常保证的静态公有函数, 且所在类没有静态不变式时, 可以省略此调用.

参见: 静态公有函数

模板参数:

Class

包含声明契约的静态公有函数的类的类型. 对于静态公有函数, 这个模板参数必须显式指定 (因为它们没有对象 this, 因此没有可供 C++ 自动推导这个类型模板参数的函数实参).

返回:

此函数的结果必须被赋给一个类型为 boost::contract::check 的变量, 该变量必须显式声明 (即不使用 C++11 的 auto 声明), 并在静态公有函数体代码之前就地声明 (否则本库将产生运行期错误, 参见 BOOST_CONTRACT_ON_MISSING_CHECK_DECL).
