precondition_failure 函数

boost::contract::precondition_failure — 为前置条件调用失败处理器.

概要

// In header: <boost/contract/core/exception.hpp>


void precondition_failure(from where);

说明

这通常只由本库在内部调用.

抛出: 如果程序员指定的失败处理器在契约断言失败时抛出异常 (非默认行为), 这里就可能抛出异常.

参见: 失败时抛出异常、 前置条件

参数:

where

导致契约断言失败的操作 (当本库调用此函数时, 该参数绝不会是 from_destructor, 因为析构函数没有前置条件).
