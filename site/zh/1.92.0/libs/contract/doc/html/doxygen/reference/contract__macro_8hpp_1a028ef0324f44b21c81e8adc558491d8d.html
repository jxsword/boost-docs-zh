宏 BOOST_CONTRACT_CONSTRUCTOR

BOOST_CONTRACT_CONSTRUCTOR — 为构造函数编写可在编译期完全禁用的契约.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_CONSTRUCTOR(...)

说明

它与 BOOST_CONTRACT_POSTCONDITION、BOOST_CONTRACT_EXCEPT 和 BOOST_CONTRACT_OLD 一起使用, 为构造函数指定可在编译期完全禁用的后置条件、异常保证和在函数体处复制的旧值 (为构造函数指定前置条件参见 BOOST_CONTRACT_CONSTRUCTOR_PRECONDITION):

class u {
    friend class boost::contract::access;

    BOOST_CONTRACT_INVARIANT({ // Optional (as for static and volatile).
        BOOST_CONTRACT_ASSERT(...);
        ...
    })

public:
    u(...) {
        BOOST_CONTRACT_OLD_PTR(old_type)(old_var);
        BOOST_CONTRACT_CONSTRUCTOR(this)
            // No `PRECONDITION` (use `CONSTRUCTOR_PRECONDITION` if needed).
            BOOST_CONTRACT_OLD([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(old_epxr);
                ...
            })
            BOOST_CONTRACT_POSTCONDITION([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            BOOST_CONTRACT_EXCEPT([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
        ; // Trailing `;` is required.

        ... // Constructor body.
    }

    ...
};

作为优化, 对于没有后置条件和异常保证的构造函数, 且所在类没有不变式时, 可以省略此调用.

BOOST_CONTRACT_CONSTRUCTOR(obj) 展开为等价于如下所示的代码 (注意当定义了 BOOST_CONTRACT_NO_CONSTRUCTORS 时不会生成任何代码):

#ifndef BOOST_CONTRACT_NO_CONSTRUCTORS
    boost::contract::check internal_var =
            boost::contract::constructor(obj)
#endif

其中:

  • obj 是来自声明契约的外围构造函数作用域的对象 this. 构造函数检查所有类不变式, 包括静态和 volatile 不变式 (参见 BOOST_CONTRACT_INVARIANT、BOOST_CONTRACT_STATIC_INVARIANT 和 BOOST_CONTRACT_INVARIANT_VOLATILE). (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

  • internal_var 是本库在内部生成的变量名 (这个名字唯一, 但仅在不同行号上唯一, 因此这个宏不能在同一行上多次展开).
