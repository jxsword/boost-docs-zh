宏 BOOST_CONTRACT_CONSTRUCTOR_PRECONDITION

BOOST_CONTRACT_CONSTRUCTOR_PRECONDITION — 为构造函数编写可在编译期禁用的前置条件.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_CONSTRUCTOR_PRECONDITION(...)

说明

它与 BOOST_CONTRACT_CONSTRUCTOR 一起使用, 为构造函数指定契约. 没有前置条件的构造函数不使用这个宏. 当类中至少有一个构造函数使用这个宏时, boost::contract::constructor_precondition 必须是声明为其编写前置条件的构造函数的类的第一个且私有的基类:

class u
    #define BASES private boost::contract::constructor_precondition<u>, \
            public b
    : BASES
{
    friend class boost::contract::access;

    typedef BOOST_CONTRACT_BASE_TYPES(BASES) base_types;
    #undef BASES

    ...

public:
    explicit u(unsigned x) :
        BOOST_CONTRACT_CONSTRUCTOR_PRECONDITION(u)([&] {
            BOOST_CONTRACT_ASSERT(x != 0);
        }),
        b(1 / x)
    {
        ...
    }

    ...
};

BOOST_CONTRACT_CONSTRUCTOR_PRECONDITION(class_type)(f) 展开为等价于如下所示的代码 (注意当定义了 BOOST_CONTRACT_NO_PRECONDITIONS 时, 这个宏平凡地展开为一个内部实现为空操作的默认构造函数调用, 因此这应当几乎没有开销):

// Guarded only by NO_PRECONDITIONS (and not also by NO_CONSTRUCTORS)
// because for constructor's preconditions (not for postconditions, etc.).
#ifndef BOOST_CONTRACT_NO_PRECONDITIONS
    boost::contract::constructor_precondition<class_type>(f)
#else // No-op call (likely optimized away, minimal to no overhead).
    boost::contract::constructor_precondition<class_type>()
#endif

其中:

  • class_type 是包含为其编写前置条件的构造函数的类的类型. (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

  • f 是本库调用以检查构造函数前置条件的零元仿函数 f(). 此仿函数调用内的断言通常用 BOOST_CONTRACT_ASSERT 编写, 但调用此仿函数抛出的任何异常都表示契约失败 (并将导致本库调用 boost::contract::precondition_failure). 此仿函数应按 (常量) 值捕获变量, 或者最好按 (常量) 引用捕获以避免额外复制. (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )
