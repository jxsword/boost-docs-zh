宏 BOOST_CONTRACT_PRECONDITION

BOOST_CONTRACT_PRECONDITION — 编写可在编译期完全禁用的前置条件.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_PRECONDITION(...)

说明

BOOST_CONTRACT_PRECONDITION(f) 展开为等价于如下所示的代码 (注意当定义了 BOOST_CONTRACT_NO_PRECONDITIONS 时不会生成任何代码):

#ifndef BOOST_CONTRACT_NO_PRECONDITIONS
    .precondition(f)
#endif

其中:

  • f 是本库调用以检查前置条件的零元仿函数 f(). 此仿函数内的断言通常用 BOOST_CONTRACT_ASSERT 编写, 但调用此仿函数抛出的任何异常都表示契约断言失败 (并将导致本库调用 boost::contract::precondition_failure). 此仿函数应按 (常量) 值捕获变量, 或者最好按 (常量) 引用捕获 (以避免额外复制). (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

参见: 禁用契约编译、 前置条件
