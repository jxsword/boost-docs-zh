except_failure 函数

boost::contract::except_failure — 为异常保证调用失败处理器.

概要

// In header: <boost/contract/core/exception.hpp>


void except_failure(from where);

说明

这通常只由本库在内部调用.

抛出: 如果程序员指定的失败处理器在契约断言失败时抛出异常 (非默认行为), 这里就可能抛出异常; 但是:

警告

当调用这个失败处理器时, 栈上已经有一个活动异常 (即最初触发异常保证检查的那个异常). 因此, 把这个失败处理器编写为再抛出另一个异常将迫使 C++ 自动终止程序.

参见: 失败时抛出异常、 异常保证

参数:

where

导致契约断言失败的操作.
