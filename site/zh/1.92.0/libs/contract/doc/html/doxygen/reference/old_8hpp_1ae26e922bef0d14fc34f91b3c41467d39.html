make_old 函数

boost::contract::make_old — 构造旧值指针 (用于虚公有函数和公有函数覆盖).

概要

// In header: <boost/contract/old.hpp>


old_pointer make_old(virtual_ * v, old_value const & old);

说明

如果指定的旧值确实被复制, 相关的旧值指针将不为空. 此函数通常只由 BOOST_CONTRACT_OLDOF(v, old_expr) 展开的代码按如下方式调用:

boost::contract::make_old(v, boost::contract::copy_old(v) ? old_expr :
        boost::contract::null_old())

参见: 不使用宏

参数:

v

来自声明契约的外围虚公有函数或覆盖公有函数的尾随参数, 类型为 boost::contract::virtual_*, 默认值为 0.

old

旧值, 通常由要复制的用户旧值表达式隐式构造 (使用三元运算符 ?: 在 boost::contract::copy_old(v) 为 false 时完全避免对旧值表达式求值).

返回:

旧值指针 (在用户代码中通常被隐式转换为 boost::contract::old_ptr 或 boost::contract::old_ptr_if_copyable).
