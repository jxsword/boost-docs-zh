宏 BOOST_CONTRACT_STATIC_INVARIANT

BOOST_CONTRACT_STATIC_INVARIANT — 编写可在编译期完全禁用的静态类不变式.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_STATIC_INVARIANT(...)

说明

BOOST_CONTRACT_STATIC_INVARIANT({ ... }) 展开为等价于如下所示的代码 (注意当定义了 BOOST_CONTRACT_NO_INVARIANTS 时不会生成任何代码):

#ifndef BOOST_CONTRACT_NO_INVARIANTS
    static void BOOST_CONTRACT_STATIC_INVARIANT_FUNC() {
        ...
    }
#endif

其中:

  • { ... } 是为静态公有函数检查类不变式的函数的定义 (参见 BOOST_CONTRACT_INVARIANT 与 BOOST_CONTRACT_INVARIANT_VOLATILE). 花括号是必需的. 此函数内的断言通常用 BOOST_CONTRACT_ASSERT 编写, 但调用此函数抛出的任何异常都表示契约断言失败 (并将导致本库调用 boost::contract::entry_invariant_failure 或 boost::contract::exit_invariant_failure 之一). (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

参见: 禁用契约编译、 类不变式
