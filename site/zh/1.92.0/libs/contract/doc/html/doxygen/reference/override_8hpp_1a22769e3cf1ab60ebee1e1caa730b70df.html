宏 BOOST_CONTRACT_OVERRIDES

BOOST_CONTRACT_OVERRIDES — 一次性声明多个覆盖类型特征, 命名为 override_... (为方便起见).

概要

// In header: <boost/contract/override.hpp>

BOOST_CONTRACT_OVERRIDES(...)

说明

提供这个可变参数宏是为了方便, BOOST_CONTRACT_OVERRIDES(f_1, f_2, ..., f_n) 展开为等价于如下所示的代码:

BOOST_CONTRACT_OVERRIDE(f_1)
BOOST_CONTRACT_OVERRIDE(f_2)
...
BOOST_CONTRACT_OVERRIDE(f_n)

在不支持可变参数宏的编译器上, 可以按上面所示对每个函数名逐个调用 BOOST_CONTRACT_OVERRIDE 来等价地编写这些覆盖类型特征.

参见: 公有函数覆盖

参数:

...

以逗号分隔的一个或多个公有函数覆盖的函数名列表. (每个函数名绝不应包含逗号, 因为它是一个标识符. )
