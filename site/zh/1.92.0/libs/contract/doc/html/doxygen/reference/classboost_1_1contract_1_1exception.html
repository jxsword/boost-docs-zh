exception 类

boost::contract::exception — 本库直接抛出的所有异常的公有基类.

概要

// In header: <boost/contract/core/exception.hpp>


class exception {
public:

  // public member functions
  virtual ~exception();
};

说明

此类不继承 std::exception, 因为派生自此类的异常会那样做 (继承自 std::exception、std::bad_cast 等).

参见: boost::contract::assertion_failure、boost::contract::bad_virtual_result_cast 等.

exception 公有成员函数

  1. virtual ~exception();
    析构此对象.

    抛出: 此函数被声明为 noexcept (C++11 之前为 throw()).
