宏 BOOST_CONTRACT_OLDOF

BOOST_CONTRACT_OLDOF — 通常用于复制旧值表达式并把它赋给旧值指针的宏.

概要

// In header: <boost/contract/old.hpp>

BOOST_CONTRACT_OLDOF(...)

说明

这个宏展开的表达式应当被赋给类型为 boost::contract::old_ptr 或 boost::contract::old_ptr_if_copyable 的旧值指针. 这是一个重载的可变参数宏, 可以按以下不同方式使用.

1. 从虚公有函数和公有函数覆盖中:

BOOST_CONTRACT_OLDOF(v, old_expr)

2. 从所有其他操作中:

BOOST_CONTRACT_OLDOF(old_expr)

其中:

  • v 是来自声明契约的外围虚公有函数或公有函数覆盖的额外参数, 类型为 boost::contract::virtual_*, 默认值为 0.

  • old_expr 是要在旧值指针中求值并复制的表达式. (这不是可变参数宏参数, 因此它可能包含的任何逗号都必须用圆括号保护, 而 BOOST_CONTRACT_OLDOF(v, (old_expr)) 则总是可行. )

在不支持可变参数宏的编译器上, 程序员可以不使用这个宏手动复制旧值表达式 (参见 不使用宏 一节).

参见: 旧值
