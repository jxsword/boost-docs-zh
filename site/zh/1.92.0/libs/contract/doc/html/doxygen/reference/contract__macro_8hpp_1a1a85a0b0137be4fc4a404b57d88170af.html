宏 BOOST_CONTRACT_OLD

BOOST_CONTRACT_OLD — 编写可在编译期完全禁用的在函数体处复制的旧值.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_OLD(...)

说明

BOOST_CONTRACT_OLD(f) 展开为等价于如下所示的代码 (注意当定义了 BOOST_CONTRACT_NO_OLDS 时不会生成任何代码):

#ifndef BOOST_CONTRACT_NO_OLDS
    .old(f)
#endif

其中:

  • f 是本库调用的零元仿函数 f(), 在函数体即将执行之前、但在入口不变式 (如果适用) 和前置条件检查之后, 赋值旧值副本. 此仿函数调用内的旧值指针通常用 BOOST_CONTRACT_OLDOF 赋值. 调用此仿函数抛出的任何异常都会导致本库调用 boost::contract::old_failure (因为无法复制旧值来检查后置条件和异常保证). 此仿函数应按引用捕获旧值指针以便能对其赋值 (求值旧值表达式所需的全部其他变量可以按 (常量) 值捕获, 或者最好按 (常量) 引用捕获以避免额外复制). (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

参见: 禁用契约编译、 在函数体处复制的旧值
