类模板 specify_old_postcondition_except

boost::contract::specify_old_postcondition_except — 允许指定在函数体处复制的旧值、后置条件和异常保证.

概要

// In header: <boost/contract/core/specify.hpp>

template<typename VirtualResult = void> 
class specify_old_postcondition_except {
public:

  // public member functions
  ~specify_old_postcondition_except() noexcept(false);
  template<typename F> 
    specify_postcondition_except< VirtualResult > old(F const &);
  template<typename F> specify_except postcondition(F const &);
  template<typename F> specify_nothing except(F const &);
};

说明

允许指定本库将调用以在函数体处复制旧值、检查后置条件和检查异常保证的仿函数. 当用户通过调用 boost::contract::function 等类似函数指定契约时, 本库会在内部构造此对象 (这就是此类没有公有构造函数的原因).

参见: 在函数体处复制的旧值、 后置条件、 异常保证

模板参数

  1. typename VirtualResult = void

    如果声明契约的外围函数是虚公有函数或覆盖公有函数, 则为该函数的返回类型; 否则此参数总是 void. (通常这个模板参数由 C++ 自动推导, 程序员无需显式指定. )

specify_old_postcondition_except 公有成员函数

  1. ~specify_old_postcondition_except() noexcept(false);
    析构此对象.

    抛出: 自 C++11 起此函数被声明为 noexcept(false), 以允许用户编写在契约断言失败时抛出异常的失败处理器 (这不是默认行为, 参见 失败时抛出异常).

  2. template<typename F> 
  specify_postcondition_except< VirtualResult > old(F const & f);
    允许指定在函数体处复制的旧值.

    通常, 在声明旧值指针时立即对其初始化就已足够, 无需使用此函数 (参见 在函数体处复制的旧值).

    参数:

    f

    本库调用这个零元仿函数 f(), 在函数体即将执行之前、但在入口不变式 (如果适用) 和前置条件检查之后, 赋值旧值副本. 此仿函数调用内的旧值指针通常用 BOOST_CONTRACT_OLDOF 赋值. 调用此仿函数抛出的任何异常都会导致本库调用 boost::contract::old_failure (因为无法复制旧值来检查后置条件和异常保证). 此仿函数应按引用捕获旧值指针以便能对其赋值 (求值旧值表达式所需的全部其他变量可以按 (常量) 值捕获, 或者最好按 (常量) 引用捕获以避免额外复制).

    返回:

    指定在函数体处复制的旧值之后, 此函数返回的对象允许选择性地指定后置条件和异常保证.

    		 
  3. template<typename F> specify_except postcondition(F const & f);
    允许指定后置条件.

    参数:

    f

    本库调用这个仿函数来检查后置条件 f() 或 f(result). 此仿函数内的断言通常用 BOOST_CONTRACT_ASSERT 编写, 但调用此仿函数抛出的任何异常都表示契约断言失败 (并将导致本库调用 boost::contract::postcondition_failure). 此仿函数应按 (常量) 引用捕获变量 (以访问它们在函数出口处的值). 当 f() 为 VirtualResult 时, 此仿函数必须是零元仿函数 void; 否则它必须是一元仿函数 f(result), 接受返回值 result 作为类型为 VirtualResult const& 的参数 (以避免返回值的额外复制; 如果返回值的额外复制无关紧要, 也可以是类型 VirtualResult 或 VirtualResult const 的参数).

    返回:

    指定后置条件之后, 此函数返回的对象允许选择性地指定异常保证.

    		 
  4. template<typename F> specify_nothing except(F const & f);
    允许指定异常保证.

    参数:

    f

    本库调用这个零元仿函数来检查异常保证 f(). 此仿函数内的断言通常用 BOOST_CONTRACT_ASSERT 编写, 但调用此仿函数抛出的任何异常都表示契约断言失败 (并将导致本库调用 boost::contract::except_failure). 此仿函数应按 (常量) 引用捕获变量 (以访问它们在函数出口处的值).

    返回:

    指定异常保证之后, 此函数返回的对象不再允许指定任何附加契约.
