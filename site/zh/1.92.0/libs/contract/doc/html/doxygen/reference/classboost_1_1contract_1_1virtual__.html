virtual_ 类

boost::contract::virtual_ — 用于处理虚公有函数契约 (子契约) 的额外函数参数的类型.

概要

// In header: <boost/contract/core/virtual.hpp>


class virtual_ {
};

说明

使用本库声明契约的虚公有函数 (因而也包括公有函数覆盖) 必须在其参数列表的最末尾指定一个额外的函数参数. 该参数必须是指向此类的指针, 且默认值必须是 0 或 nullptr (本文档中这个额外参数常被命名为 v, 但可以使用任何名字):

class u {
public:
    virtual void f(int x, boost::contract::virtual_* v = 0) { // Declare `v`.
        ... // Contract declaration (which will use `v`) and function body.
    }

    ...
};

实际上, 这个额外参数不会改变声明契约的外围函数的调用接口, 因为它总是最后一个参数且带默认值 (因此用户调用该函数时总是可以省略它). 这个额外参数必须传递给 boost::contract::public_function、BOOST_CONTRACT_OLDOF 以及本库所有接受指向 boost::contract::virtual_ 的指针的其他操作. 除此之外, 此类并不是供程序员直接使用的 (这也是此类没有任何公有成员且不可复制的原因).

参见: 虚公有函数、 公有函数覆盖
