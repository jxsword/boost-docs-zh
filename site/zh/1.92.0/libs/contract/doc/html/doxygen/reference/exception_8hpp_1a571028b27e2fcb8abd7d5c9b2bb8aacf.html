类型定义 from_failure_handler

from_failure_handler — 断言失败处理器函数的类型 (带 from 参数).

概要

// In header: <boost/contract/core/exception.hpp>


typedef boost::function< void(from)> from_failure_handler;

说明

由该类型指定的断言失败处理器函数必须是返回 void 且接受单个 boost::contract::from 类型参数的仿函数. 例如, 这用于为类不变式、前置条件、后置条件和异常保证指定契约失败处理器.

参见: 失败时抛出异常
