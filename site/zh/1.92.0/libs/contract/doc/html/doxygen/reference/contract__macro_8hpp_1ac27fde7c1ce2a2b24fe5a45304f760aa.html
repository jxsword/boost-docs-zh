宏 BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE

BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE — 为公有函数覆盖编写可在编译期完全禁用的契约.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE(...)

说明

它与 BOOST_CONTRACT_PRECONDITION、BOOST_CONTRACT_POSTCONDITION、BOOST_CONTRACT_EXCEPT、BOOST_CONTRACT_OLD 和

class u
    #define BASES private boost::contract::constructor_precondition<u>, \
            public b, private w
    : BASES
{
    friend class boost::contract::access;

    typedef BOOST_CONTRACT_BASE_TYPES(BASES) base_types;
    #undef BASES

    BOOST_CONTRACT_INVARIANT({ // Optional (as for static and volatile).
        BOOST_CONTRACT_ASSERT(...);
        ...
    })

    BOOST_CONTRACT_OVERRIDES(f, g)

public:
    // Override from `b::f`, and void.
    void f(t_1 a_1, ..., t_n a_n, boost::contract::virtual_* v = 0) {
        BOOST_CONTRACT_OLD_PTR(old_type)(old_var);
        BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE(override_f)(
                v, &u::f, this, a_1, ..., a_n)
            BOOST_CONTRACT_PRECONDITION([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            BOOST_CONTRACT_OLD([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(v, old_expr);
                ...
            })
            BOOST_CONTRACT_POSTCONDITION([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            BOOST_CONTRACT_EXCEPT([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
        ; // Trailing `;` is required.

        ... // Function body.
    }
    
    // Override from `b::g`, and void.
    t g(t_1 a_1, ..., t_n a_n, boost::contract::virtual_* v = 0) {
        t result;
        BOOST_CONTRACT_OLD_PTR(old_type)(old_var);
        BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE(override_g)(
                v, result, &u::g, this, a_1, ..., a_n)
            ...
            BOOST_CONTRACT_OLD([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(v, old_expr);
                ...
            })
            BOOST_CONTRACT_POSTCONDITION([&] (t const& result) { // Optional
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            ...
        ; // Trailing `;` is required.

        ... // Function body (use `return result = return_expr`).
    }
    
    ...
};

公有函数覆盖应当始终使用 BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE, 否则本库将无法在子契约中正确使用它.

这是一个重载的可变参数宏, 可以按以下不同方式使用 (注意当定义了 BOOST_CONTRACT_NO_PUBLIC_FUNCTIONS 时不会生成任何代码).

1. BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE(override_type)(v, f, obj, ...) 展开为等价于如下所示的代码 (用于返回 void 的公有函数覆盖):

#ifndef BOOST_CONTRACT_NO_PUBLIC_FUNCTIONS
    boost::contract::check internal_var = boost::contract::
            public_function<override_type>(v, f, obj, ...)
#endif

2. BOOST_CONTRACT_PUBLIC_FUNCTION_OVERRIDE(override_type)(v, r, f, obj, ...) 展开为等价于如下所示的代码 (用于不返回 void 的公有函数覆盖):

#ifndef BOOST_CONTRACT_NO_PUBLIC_FUNCTIONS
    boost::contract::check internal_var = boost::contract::
            public_function<override_type>(v, r, f, obj, ...)
#endif

其中 (这些都是可变参数宏参数, 因此它们可以包含未被圆括号保护的逗号):

  • override_type 是类型 override_function-name, 使用 BOOST_CONTRACT_OVERRIDE 或相关宏声明.

  • v 是来自声明契约的外围虚公有函数的额外参数, 类型为 boost::contract::virtual_*, 默认值为 0.

  • r 是对声明契约的外围虚公有函数的返回值的引用. 它通常是外围虚公有函数在契约之前声明的局部变量, 但程序员必须在每个 return 语句处把它设置为函数实际返回的值.

  • f是指向声明契约的外围公有函数覆盖的指针.

  • obj 是来自声明契约的外围公有函数作用域的对象 this. 此对象可能是可变的 (mutable)、const、volatile 或 const volatile, 取决于外围函数的 cv 限定符 (volatile 公有函数将检查 volatile 类不变式, 参见 volatile 公有函数).

  • ... 是一个可变参数宏参数, 列出传递给声明契约的外围公有函数覆盖的所有实参 (按引用, 并按它们在外围函数声明中出现的顺序), 但不包括尾随参数 v.

  • internal_var 是本库在内部生成的变量名 (这个名字唯一, 但仅在不同行号上唯一, 因此这个宏不能在同一行上多次展开).
