宏 BOOST_CONTRACT_HEADER_ONLY

BOOST_CONTRACT_HEADER_ONLY — 当本库被用作仅头文件库时由本库自动定义 (不推荐).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_HEADER_ONLY

说明

这个宏不是配置宏, 如果用户试图直接定义它, 本库将产生编译期错误. 当用户没有定义 BOOST_CONTRACT_DYN_LINK (或 BOOST_ALL_DYN_LINK) 且没有定义 BOOST_CONTRACT_STATIC_LINK 时, 本库会自动定义这个宏. 作为仅头文件库使用时, 本库代码不必与用户代码分开编译, 只需把本库头文件包含进来, 作为用户程序的一部分编译.

警告

定义这个宏时, 不保证本库在运行期始终正确工作 (请改为定义 BOOST_CONTRACT_DYN_LINK 或 BOOST_ALL_DYN_LINK). 不过, 对于在单一程序单元中检查契约的用户代码 (例如只包含静态链接库的单一程序), 可以定义这个宏, 并把本库作为仅头文件库安全使用.
