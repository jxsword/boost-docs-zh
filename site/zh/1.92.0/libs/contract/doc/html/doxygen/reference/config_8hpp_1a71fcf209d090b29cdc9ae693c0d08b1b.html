宏 BOOST_CONTRACT_DISABLE_THREADS

BOOST_CONTRACT_DISABLE_THREADS — 定义此宏以不为线程安全而锁定本库内部数据 (默认未定义).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_DISABLE_THREADS

说明

定义这个宏会使本库的实现代码不具线程安全性, 因此除非本库只被单线程应用使用, 否则不应定义这个宏. 当 Boost 库构建为不含线程时 (例如定义 BOOST_DISABLE_THREADS), 本库会自动定义这个宏.

注释

当这个宏保持未定义时, 本库需要在内部使用某种全局锁 (以确保在其他契约正被检查时全局禁用契约检查, 以及安全地访问失败处理器仿函数). 这可能在某些多线程应用中引入不希望的同步量.
