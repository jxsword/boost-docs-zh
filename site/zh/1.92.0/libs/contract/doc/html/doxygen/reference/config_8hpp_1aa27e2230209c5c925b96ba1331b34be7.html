宏 BOOST_CONTRACT_PERMISSIVE

BOOST_CONTRACT_PERMISSIVE — 禁用本库产生的一些编译期错误 (默认未定义).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_PERMISSIVE

说明

定义这个宏会禁用本库产生的一些静态检查及相关编译期错误, 例如:

  • 名为 BOOST_CONTRACT_STATIC_INVARIANT_FUNC 的静态不变式成员函数必须被声明为 static.

  • 名为 BOOST_CONTRACT_INVARIANT_FUNC 的非静态不变式成员函数必须被声明为 const、const volatile 或 volatile const 之一.

  • 通过 boost::contract::public_function 为一个或多个公有函数覆盖编写契约的派生类, 还必须定义 BOOST_CONTRACT_BASE_TYPES typedef.

一般不建议定义这个宏, 因为这些编译期检查能够防止对本库的误用.
