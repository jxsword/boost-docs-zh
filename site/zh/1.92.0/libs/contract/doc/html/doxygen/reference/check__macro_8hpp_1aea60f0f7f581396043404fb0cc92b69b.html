宏 BOOST_CONTRACT_CHECK

BOOST_CONTRACT_CHECK — 断言实现检查条件的首选方式.

概要

// In header: <boost/contract/core/check_macro.hpp>

BOOST_CONTRACT_CHECK(cond)

说明

首选使用这个宏, 而不是把实现检查编写在传递给 boost::contract::check 构造函数的零元仿函数中, 因为当定义了 BOOST_CONTRACT_NO_CHECKS 时, 这个宏会把实现检查从代码中完全移除:

void f() {
    ...
    BOOST_CONTRACT_CHECK(cond);
    ...
}

BOOST_CONTRACT_CHECK、BOOST_CONTRACT_CHECK_AUDIT 和 BOOST_CONTRACT_CHECK_AXIOM 是本库为实现检查预定义的三个断言级别.

参见: 实现检查

参数:

cond

要在实现代码 (函数体等) 中检查的布尔条件. (这不是可变参数宏参数, 因此它可能包含的任何逗号都必须用圆括号保护, 而 BOOST_CONTRACT_CHECK((cond)) 则总是可行. )
