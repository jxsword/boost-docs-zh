old_value 类

boost::contract::old_value — 把用户指定的表达式转换为旧值.

概要

// In header: <boost/contract/old.hpp>


class old_value {
public:

  // public member functions
  template<typename T> 
    old_value(T const &, 
              typename boost::enable_if< boost::contract::is_old_value_copyable< T > >::type * = 0);
  template<typename T> 
    old_value(T const &, 
              typename boost::disable_if< boost::contract::is_old_value_copyable< T > >::type * = 0);
};

说明

此类通常只被本库隐式使用, 不会显式出现在用户代码中.

在无法正确推导此类声明中所用 boost::contract::is_old_value_copyable 特征的旧编译器上, 程序员可以手动特化该特征, 以确保只有可复制的旧值类型才被实际复制.

参见: 旧值要求

old_value 公有成员函数

  1. template<typename T> 
  old_value(T const & old, 
            typename boost::enable_if< boost::contract::is_old_value_copyable< T > >::type * = 0);
    当旧值类型可复制构造时, 从指定的旧值构造此对象.

    指定的旧值 old 使用 boost::contract::old_value_copy 复制 (仅一次), 此时相关的旧值指针将不为空 (但如果未检查后置条件和异常保证, 则不做复制, 参见 BOOST_CONTRACT_NO_OLDS).

    参数:

    old

    要复制的旧值.

    模板参数:

    T

    旧值类型.

    		 
  2. template<typename T> 
  old_value(T const & old, 
            typename boost::disable_if< boost::contract::is_old_value_copyable< T > >::type * = 0);
    当旧值类型不可复制时, 从指定的旧值构造此对象.

    此时指定的旧值 old 无法复制, 因此不做复制, 相关的旧值指针将始终为空 (因此对此构造函数的调用没有效果, 且很可能被大多数编译器优化掉).

    参数:

    old

    旧值 (此情况下不会被复制).

    模板参数:

    T

    旧值类型.
