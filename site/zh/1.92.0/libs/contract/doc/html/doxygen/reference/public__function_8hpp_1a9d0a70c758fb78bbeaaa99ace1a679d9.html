函数模板 public_function

boost::contract::public_function — 为不覆盖的非 void 虚公有函数编写契约.

概要

// In header: <boost/contract/public_function.hpp>


template<typename VirtualResult, typename Class> 
  specify_precondition_old_postcondition_except< VirtualResult > 
  public_function(virtual_ * v, VirtualResult & r, Class * obj);

说明

这用于为是虚函数、不覆盖且不返回 void: 的公有函数指定前置条件、后置条件、异常保证、在函数体处复制的旧值, 并检查类不变式.

class u {
    friend class boost::contract::access;

    void invariant() const { // Optional (as for static and volatile).
        BOOST_CONTRACT_ASSERT(...);
        ...
    }

public:
    t f(..., boost::contract::virtual_* v = 0) {
        t result;
        boost::contract::old_ptr<old_type> old_var;
        boost::contract::check c = boost::contract::public_function(
                v, result, this)
            .precondition([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            .old([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(v, old_expr);
                ...
            })
            .postcondition([&] (t const& result) { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            .except([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
        ;

        ... // Function body (use `return result = return_expr`).
    }
    
    ...
};

虚公有函数应当始终调用 boost::contract::public_function, 否则本库将无法在子契约中正确使用它.

参见: 虚公有函数

参数:

v

来自外围虚公有函数的尾随参数, 类型为 boost::contract::virtual_*, 默认值为 0.

r

对声明契约的外围虚公有函数的返回值的引用. 它通常是外围虚公有函数在契约之前声明的局部变量, 但程序员必须在每个 return 语句处把它设置为函数实际返回的值.

obj

来自声明契约的外围虚公有函数作用域的对象 this. 此对象可能是可变的 (mutable)、const、volatile 或 const volatile, 取决于外围函数的 cv 限定符 (volatile 公有函数将检查 volatile 类不变式, 参见 volatile 公有函数).

模板参数:

VirtualResult

该类型必须与声明契约的外围虚公有函数的返回类型相同或兼容 (如果这些类型不匹配, 本库可能无法产生编译期错误, 但一般会导致运行期错误或未定义行为). 或者, 也可以使用 boost::optional<return-type> (参见 可选返回值). (通常这个模板参数由 C++ 自动推导, 程序员无需显式指定. )

Class

包含声明契约的虚公有函数的类的类型. (通常这个模板参数由 C++ 自动推导, 程序员无需显式指定. )

返回:

此函数的结果必须被赋给一个类型为 boost::contract::check 的变量, 该变量必须显式声明 (即不使用 C++11 的 auto 声明), 并在公有函数体代码之前就地声明 (否则本库将产生运行期错误, 参见 BOOST_CONTRACT_ON_MISSING_CHECK_DECL).
