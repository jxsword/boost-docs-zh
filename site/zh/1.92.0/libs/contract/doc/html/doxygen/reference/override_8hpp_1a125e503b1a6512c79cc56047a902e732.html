宏 BOOST_CONTRACT_OVERRIDE

BOOST_CONTRACT_OVERRIDE — 声明名为 override_func_name 的覆盖类型特征.

概要

// In header: <boost/contract/override.hpp>

BOOST_CONTRACT_OVERRIDE(func_name)

说明

声明名为 override_func_name 的覆盖类型特征, 供公有函数覆盖作为显式模板参数传递给 boost::contract::public_function. 使用 BOOST_CONTRACT_NAMED_OVERRIDE 可以生成名字不同于 override_func_name 的覆盖类型特征 (通常不需要).

参见: 公有函数覆盖

参数:

func_name

公有函数覆盖的函数名. 即使该函数名被重载, 这个宏也只调用一次 (相同名字的所有重载函数使用同一个覆盖类型特征, 参见 函数重载). (这不是可变参数宏参数, 但它绝不应包含任何逗号, 因为它是一个标识符. )
