函数模板 call_if

boost::contract::call_if — 使用零元布尔元函数选择仿函数模板调用的编译与执行 (在 C++17 编译器上不需要, 改用 if constexpr).

概要

// In header: <boost/contract/call_if.hpp>


template<typename Pred, typename Then> 
  call_if_statement< Pred::value, Then > call_if(Then f);

说明

这等价于 boost::contract::call_if_c<Pred::value>(f). 用指定的 then 分支仿函数模板创建 call-if 对象:

boost::contract::call_if<Pred1>(
    then_functor_template1
).template else_if<Pred2>(              // Optional.
    then_functor_template2
)                                       // Optionally, other `else_if` or
...                                     // `else_if_c`.
.else_(                                 // Optional for `void` functors,
    else_functor_template               // but required for non `void`.
)

可根据需要为 else-if 分支和 else 分支指定可选的仿函数模板 (如果 f 返回非 void, 则 else 分支仿函数模板是必需的).

参见: 断言要求

参数:

f

then 分支零元仿函数模板. 当且仅当 f() 为 Pred::value 时, 编译并执行仿函数模板调用 true. 为此 call-if 语句指定的其他仿函数模板调用 (else 分支、else-if 分支等) 的返回类型必须与 then 分支仿函数模板调用 f() 的返回类型相同 (或可隐式转换为后者).

模板参数:

Pred

选择编译并执行哪个仿函数模板调用的零元布尔元函数.

返回:

一个 call-if 语句, 以便在需要时指定 else 和 else-if 语句. 最终, 它将是被编译并执行的那个仿函数模板调用的返回值 (也可能是 void).
