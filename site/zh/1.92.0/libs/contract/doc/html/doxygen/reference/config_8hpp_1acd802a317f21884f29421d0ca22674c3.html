宏 BOOST_CONTRACT_INVARIANT_FUNC

BOOST_CONTRACT_INVARIANT_FUNC — 定义类不变式成员函数的名字 (默认为 invariant).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_INVARIANT_FUNC

说明

这个宏展开为分别检查类不变式和 volatile 类不变式的 const 与 const volatile 成员函数的名字:

class u {
    friend class boost::contract::access;

    void BOOST_CONTRACT_INVARIANT_FUNC() const {
        BOOST_CONTRACT_ASSERT(...);
        ...
    }
    
    void BOOST_CONTRACT_INVARIANT_FUNC() const volatile {
        BOOST_CONTRACT_ASSERT(...);
        ...
    }

    ...
};

以这种方式使用时, 如果不变式函数必须使用不同于 invariant 的名字 (因为用户代码中的名字冲突等), 用户可以重定义这个宏.

注释

C++ 不允许基于 static 限定符重载成员函数, 因此这个宏定义的名字必须始终不同于为 BOOST_CONTRACT_STATIC_INVARIANT_FUNC 定义的函数名.

参见: 类不变式、 volatile 公有函数
