set_check_failure 函数

boost::contract::set_check_failure — 设置实现检查的失败处理器.

概要

// In header: <boost/contract/core/exception.hpp>


failure_handler const & set_check_failure(failure_handler const & f);

说明

设置新的失败处理器并返回它.

抛出: 此函数被声明为 noexcept (C++11 之前为 throw()).

参见: 失败时抛出异常、 实现检查

参数:

f

要设置的新失败处理器仿函数.

返回:

作为参数传递的同一失败处理器仿函数 f (例如用于串联函数调用).
