函数模板 destructor

boost::contract::destructor — 为析构函数编写契约.

概要

// In header: <boost/contract/destructor.hpp>


template<typename Class> 
  specify_old_postcondition_except destructor(Class * obj);

说明

这用于为析构函数指定后置条件、异常保证、在函数体处复制的旧值, 并检查类不变式 (析构函数不能有前置条件, 参见 析构函数调用):

class u {
    friend class boost::contract::access;

    void invariant() const { // Optional (as for static and volatile).
        BOOST_CONTRACT_ASSERT(...);
        ...
    }

public:
    ~u() {
        boost::contract::old_ptr<old_type> old_var;
        boost::contract::check c = boost::contract::destructor(this)
            // No `.precondition` (destructors have no preconditions).
            .old([&] { // Optional.
                old_var = BOOST_CONTRACT_OLDOF(old_expr);
                ...
            })
            .postcondition([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
            .except([&] { // Optional.
                BOOST_CONTRACT_ASSERT(...);
                ...
            })
        ;

        ... // Destructor body.
    }
    
    ...
};

作为优化, 对于没有后置条件和异常保证的析构函数, 且所在类没有不变式时, 可以省略此调用.

参见: 析构函数

参数:

obj

来自声明契约的外围析构函数作用域的对象 this. (析构函数检查所有类不变式, 包括静态和 volatile 不变式, 参见 类不变式 与 volatile 公有函数).

模板参数:

Class

包含声明契约的析构函数的类的类型. (通常这个模板参数由 C++ 自动推导, 程序员无需显式指定. )

返回:

此函数的结果必须被赋给一个类型为 boost::contract::check 的变量, 该变量必须显式声明 (即不使用 C++11 的 auto 声明), 并在析构函数体代码之前就地声明 (否则本库将产生运行期错误, 参见 BOOST_CONTRACT_ON_MISSING_CHECK_DECL).
