宏 BOOST_CONTRACT_BASES_TYPEDEF

BOOST_CONTRACT_BASES_TYPEDEF — 定义基类型 typedef 的名字 (默认为 base_types).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_BASES_TYPEDEF

说明

这个宏展开为 typedef 的名字, 该类型通过 BOOST_CONTRACT_BASE_TYPES 列出用于子契约的基类:

class u
    #define BASES public b, private w
    : BASES
{
    friend class boost::contract:access;

    typedef BOOST_CONTRACT_BASE_TYPES(BASES) BOOST_CONTRACT_TYPEDEF;
    #undef BASES

    ...
};

以这种方式使用时, 如果 typedef 必须使用不同于 base_types 的名字 (因为用户代码中的名字冲突等), 用户可以重定义这个宏.
