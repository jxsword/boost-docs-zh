specify_nothing 类

boost::contract::specify_nothing — 用于阻止在异常保证之后设置其他契约条件.

概要

// In header: <boost/contract/core/specify.hpp>


class specify_nothing {
public:

  // public member functions
  ~specify_nothing() noexcept(false);
};

说明

此类没有成员函数, 因此用于阻止指定额外的仿函数来检查任何其他契约. 当用户通过调用 boost::contract::function 等类似函数指定契约时, 本库会在内部构造此对象 (这就是此类没有公有构造函数的原因).

参见: 教程

specify_nothing 公有成员函数

  1. ~specify_nothing() noexcept(false);
    析构此对象.

    抛出: 自 C++11 起此函数被声明为 noexcept(false), 以允许用户编写在契约断言失败时抛出异常的失败处理器 (这不是默认行为, 参见 失败时抛出异常).
