宏 BOOST_CONTRACT_NO_ALL

BOOST_CONTRACT_NO_ALL — 当完全不检查契约时由本库自动定义 (规约和实现都不检查).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_NO_ALL

说明

这个宏不是配置宏, 如果用户试图直接定义它, 本库将产生编译期错误. 当用户定义了 BOOST_CONTRACT_NO_INVARIANTS、BOOST_CONTRACT_NO_PRECONDITIONS、BOOST_CONTRACT_NO_POSTCONDITIONS、BOOST_CONTRACT_NO_EXCEPTS、BOOST_CONTRACT_NO_CHECKS 和 #ifndef 的全部时, 本库会自动定义这个宏. 例如, 用户可以借助这个宏在代码中手动编写 boost/contract.hpp 语句, 以完全不包含

#include <boost/contract/core/config.hpp>
#ifndef BOOST_CONTRACT_NO_ALL
    #include <boost/contract.hpp>
#endif

或者, 改用 boost/contract_macro.hpp 头文件及相关宏 (因为 boost/contract_macro.hpp 头文件已经过优化, 在契约不被检查时不会包含本库的其他头文件; 但仅建议在确实需要从生产代码中完全移除契约代码编译的应用中使用).

参见: 禁用契约编译
