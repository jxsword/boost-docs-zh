宏 BOOST_CONTRACT_NO_EXIT_INVARIANTS

BOOST_CONTRACT_NO_EXIT_INVARIANTS — 如果定义, 本库不在出口检查类不变式 (默认未定义).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_NO_EXIT_INVARIANTS

说明

如果定义了这个宏, 本库的内部代码还会进行优化, 以减少与在出口检查类不变式相关的编译期 (而不仅是运行期) 开销. 此外, 用户可以借助这个宏在代码中手动编写 #ifndef 语句来完全禁用出口类不变式的编译, 或使用 boost/contract_macro.hpp 中定义的宏 (仅建议在确实需要从生产代码中完全移除契约代码编译的应用中使用).

当定义了 BOOST_CONTRACT_NO_INVARIANTS 时, 会自动定义这个宏.

参见: 类不变式、 禁用契约检查、 禁用契约编译
