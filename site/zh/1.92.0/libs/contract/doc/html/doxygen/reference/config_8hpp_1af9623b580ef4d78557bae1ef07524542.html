宏 BOOST_CONTRACT_NO_OLDS

BOOST_CONTRACT_NO_OLDS — 当不执行旧值复制时由本库自动定义.

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_NO_OLDS

说明

这个宏不是配置宏, 如果用户试图直接定义它, 本库将产生编译期错误. 当用户同时定义了 BOOST_CONTRACT_NO_POSTCONDITIONS 和 BOOST_CONTRACT_NO_EXCEPTS 时, 本库会自动定义这个宏. 用户可以借助这个宏在代码中手动编写 #ifndef 语句来完全禁用旧值复制的编译, 或使用 boost/contract_macro.hpp 中定义的宏 (仅建议在确实需要从生产代码中完全移除契约代码编译的应用中使用).

参见: 旧值、 在函数体处复制的旧值、 禁用契约编译
