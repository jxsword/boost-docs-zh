结构模板 call_if_statement<true, Then, void>

boost::contract::call_if_statement<true, Then, void> — 处理静态谓词为 true 且 then 分支仿函数模板调用返回 void 的情形的模板特化 (在 C++17 编译器上不需要, 改用 if constexpr).

概要

// In header: <boost/contract/call_if.hpp>

template<typename Then> 
struct call_if_statement<true, Then, void> {

  // public member functions
  explicit call_if_statement(Then);
  template<typename Else> void else_(Else const &) const;
  template<bool ElseIfPred, typename ElseIfThen> 
    call_if_statement< true, Then, void > else_if_c(ElseIfThen const &) const;
  template<typename ElseIfPred, typename ElseIfThen> 
    call_if_statement< true, Then, void > else_if(ElseIfThen const &) const;
};

说明

通常, 这个类模板只通过 boost::contract::call_if 和 boost::contract::call_if_c 的返回值来实例化.

参见: 断言要求

模板参数

  1. typename Then

    当静态谓词为 true 时要调用的仿函数模板的类型 (正是这个模板特化的情形).

call_if_statement 公有成员函数

  1. explicit call_if_statement(Then f);
    用 then 分支仿函数模板构造此对象.

    参数:

    f

    then 分支零元仿函数模板. 对这个模板特化而言, 仿函数模板调用 f() 实际会被编译并执行 (因为 if 语句的静态谓词为 true). 对这个模板特化而言, f() 的返回类型必须是 void (因为 then 分支仿函数模板调用返回 void).

    		 
  2. template<typename Else> void else_(Else const & f) const;
    指定 else 分支仿函数模板.

    参数:

    f

    else 分支零元仿函数模板. 对这个模板特化而言, 仿函数模板调用 f() 绝不会被编译或执行 (因为 if 语句的静态谓词为 true). 对这个模板特化而言, f() 的返回类型必须是 void (因为 then 分支仿函数模板调用返回 void).

    		 
  3. template<bool ElseIfPred, typename ElseIfThen> 
  call_if_statement< true, Then, void > else_if_c(ElseIfThen const & f) const;
    指定一个 else-if 分支仿函数模板 (使用静态布尔谓词).

    参数:

    f

    else-if 分支零元仿函数模板. 对这个模板特化而言, 仿函数模板调用 f() 绝不会被编译或执行 (因为 if 语句的静态谓词为 true). 对这个模板特化而言, f() 的返回类型必须是 void (因为 then 分支仿函数模板调用返回 void).

    模板参数:

    ElseIfPred

    选择编译并执行哪个仿函数模板调用的静态布尔谓词.

    返回:

    一个 call-if 语句, 以便在需要时指定 else 语句和额外的 else-if 语句. 最终, 对这个模板特化而言, 它将返回 void (因为 then 分支仿函数模板调用返回 void).

    		 
  4. template<typename ElseIfPred, typename ElseIfThen> 
  call_if_statement< true, Then, void > else_if(ElseIfThen const & f) const;
    指定一个 else-if 分支仿函数模板 (使用零元布尔元函数).

    参数:

    f

    else-if 分支零元仿函数模板. 对这个模板特化而言, 仿函数模板调用 f() 绝不会被编译或执行 (因为 if 语句的静态谓词为 true). 对这个模板特化而言, f() 的返回类型必须是 void (因为 then 分支仿函数模板调用返回 void).

    模板参数:

    ElseIfPred

    选择编译并执行哪个仿函数模板调用的零元布尔元函数.

    返回:

    一个 call-if 语句, 以便在需要时指定 else 语句和额外的 else-if 语句. 最终, 对这个模板特化而言, 它将返回 void (因为 then 分支仿函数模板调用返回 void).
