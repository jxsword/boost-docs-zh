宏 BOOST_CONTRACT_DYN_LINK

BOOST_CONTRACT_DYN_LINK — 定义此宏以把本库编译为共享库 (推荐).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_DYN_LINK

说明

如果定义了这个宏, 本库会被编译为可以作为共享库 (即动态链接库, DLL) 链接到用户代码的形式. 当 Boost 库构建为共享库时 (例如定义 BOOST_ALL_DYN_LINK 或使用 bjam link=shared ...), 本库会自动定义这个宏.

警告

一般而言, 只有当本库被编译为共享库时, 它才能在运行期正确检查契约, 除非用户代码在单一程序单元中检查契约 (例如只包含静态链接库的单一程序). 因此, 建议通过定义这个宏 (或等价地把所有 Boost 库构建为共享库) 把本库构建为共享库来使用.
