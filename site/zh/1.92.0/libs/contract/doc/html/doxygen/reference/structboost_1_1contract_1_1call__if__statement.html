结构模板 call_if_statement

boost::contract::call_if_statement — 使用静态布尔谓词选择仿函数模板调用的编译与执行 (在 C++17 编译器上不需要, 改用 if constexpr).

概要

// In header: <boost/contract/call_if.hpp>

template<bool Pred, typename Then, typename ThenResult = internal_type> 
struct call_if_statement {
};

说明

这个类模板没有成员, 因为它从不被直接使用, 只是通过其特化来使用. 通常, 这个类模板只通过 boost::contract::call_if 和 boost::contract::call_if_c 的返回值来实例化.

参见: 断言要求

模板参数

  1. bool Pred

    选择编译并执行哪个仿函数模板调用的静态布尔谓词.

  2. typename Then

    当静态谓词 Pred 为 true 时要调用的仿函数模板的类型.

  3. typename ThenResult = internal_type

    then 分支仿函数模板调用的返回类型 (它通常由本库自动推导, 用户从不显式指定, 这就是为什么本文档中常把它标为 internal_type 的原因).
