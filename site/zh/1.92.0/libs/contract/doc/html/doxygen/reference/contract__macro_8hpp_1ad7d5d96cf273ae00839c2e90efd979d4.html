宏 BOOST_CONTRACT_OLD_PTR_IF_COPYABLE

BOOST_CONTRACT_OLD_PTR_IF_COPYABLE — 为不要求可复制的旧值类型编写可在编译期完全禁用的旧值.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(...)

说明

这用于为可能可复制也可能不可复制的类型编写旧值复制:

template<typename T> // Type `T` might or not be copyable.
class u {
public:
    void f(...) {
        BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type_a)(old_var_a);
        BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type_b)(old_var_b,
                old_expr_b);
        BOOST_CONTRACT_PUBLIC_FUNCTION(this)
            ...
            BOOST_CONTRACT_OLD([&] {
                old_var_a = BOOST_CONTRACT_OLDOF(old_expr_a);
                ...
            })
            ... // In postconditions or exception guarantees:
                if(old_var_a) ... // Always null for non-copyable types.
                if(old_var_b) ... // Always null for non-copyable types.
            ...
        ;

        ... // Function body.
    }

    virtual void g(..., boost::contract::virtual_* v = 0) {
        BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type_a)(old_var_a);
        BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type_b)(v, old_var_b,
                old_expr_b);
        BOOST_CONTRACT_PUBLIC_FUNCTION(v, this)
            ...
            BOOST_CONTRACT_OLD([&] {
                old_var_a = BOOST_CONTRACT_OLDOF(v, old_expr_a);
                ...
            })
            ... // In postconditions or exception guarantees:
                if(old_var_a) ... // Always null for non-copyable types.
                if(old_var_b) ... // Always null for non-copyable types.
            ...
        ;

        ... // Function body.
    }

    ...
};

这是一个重载的可变参数宏, 可以按以下不同方式使用 (注意当定义了 BOOST_CONTRACT_NO_OLDS 时不会生成任何代码).

1. BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type)(old_var) 展开为等价于如下所示的代码 (这使旧值指针保持为空):

#ifndef BOOST_CONTRACT_NO_OLDS
    // This declaration does not need to use `v`.
    boost::contract::old_ptr_if_copyable<old_type> old_var
#endif

2. BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type)(old_var, old_expr) 展开为等价于如下所示的代码 (这把指针初始化为旧值副本, 但不可用于虚公有函数和公有函数覆盖):

#ifndef BOOST_CONTRACT_NO_OLDS
    boost::contract::old_ptr_if_copyable<old_type> old_var =
            BOOST_CONTRACT_OLDOF(old_expr)
#endif

3. BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type)(v, old_var, old_expr) 展开为等价于如下所示的代码 (这把指针初始化为虚公有函数和公有函数覆盖的旧值副本):

#ifndef BOOST_CONTRACT_NO_OLDS
    boost::contract::old_ptr_if_copyable<old_type> old_var =
            BOOST_CONTRACT_OLDOF(v, old_expr)
#endif

其中:

  • old_type 是所指向旧值的类型. 如果该类型不可复制 (即 boost::contract::is_old_value_copyable<old_type>::value 为 false), 此指针将始终为空, 但本库不会在此指针被解引用时产生编译期错误 (参见 BOOST_CONTRACT_OLD_PTR). (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

  • v 是来自声明契约的外围虚公有函数或公有函数覆盖的额外尾随参数, 类型为 boost::contract::virtual_*, 默认值为 0. (这不是可变参数宏参数, 但它绝不应包含逗号, 因为它是一个标识符. )

  • old_var 是旧值指针变量的名字. (这不是可变参数宏参数, 但它绝不应包含逗号, 因为它是一个标识符. )

  • old_expr 是要在旧值指针中求值并复制的表达式. (这不是可变参数宏参数, 因此它可能包含的任何逗号都必须用圆括号保护, 而 BOOST_CONTRACT_OLD_PTR_IF_COPYABLE(old_type)(v, old_var, (old_expr)) 则总是可行. )
