宏 BOOST_CONTRACT_BASE_TYPES

BOOST_CONTRACT_BASE_TYPES — 用于编写列出派生类基类的 typedef.

概要

// In header: <boost/contract/base_types.hpp>

BOOST_CONTRACT_BASE_TYPES(...)

说明

为了支持子契约, 为一个或多个覆盖公有函数指定契约的派生类必须使用这个宏声明一个 typedef, 名为 base_types (或 BOOST_CONTRACT_BASES_TYPEDEF), 使用这个宏: @code class u #define BASES public b, protected virtual w1, private w2 : BASES { friend class boost::contract:access; typedef BOOST_CONTRACT_BASE_TYPES(BASES) base_types; #undef BASES ... }; @endcode

这个 typedef 必须是 public 的, 除非使用 boost::contract::access.

参见: 基类

参数:

...

以逗号分隔的基类列表. 每个基类都必须显式指定其访问说明符 public、protected 或 private, 如果存在 virtual 也必须指定 (而在 C++ 中这并非总是必需). 可列出的基类数量上限约为 20 个 (因为本库内部使用的 Boost.MPL 有类似限制). 这是一个可变参数宏参数; 在不支持可变参数宏的编译器上, 可以不用这个宏手动编写基类的 typedef (参见 不使用宏).
