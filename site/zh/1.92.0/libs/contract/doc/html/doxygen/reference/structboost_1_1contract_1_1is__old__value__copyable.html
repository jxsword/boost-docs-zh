结构模板 is_old_value_copyable

boost::contract::is_old_value_copyable — 检查旧值类型能否复制的特征.

概要

// In header: <boost/contract/old.hpp>

template<typename T> 
struct is_old_value_copyable : public boost::is_copy_constructible< T > {
};

说明

默认情况下, 这个一元布尔元函数等价于 boost::is_copy_constructible<T>, 但程序员可以选择针对用户自定义类型对它进行特化 (一般而言, 在不支持 C++11 的编译器上也需要某种特化, 参见 boost::is_copy_constructible):

class u; // Some user-defined type for which old values shall not be copied.

namespace boost { namespace contract {
    template<> // Specialization to not copy old values of type `u`.
    struct is_old_value_copyable<u> : boost::false_type {};
} } // namespace

给定的旧值类型 T 只有当 boost::contract::is_old_value_copyable<T>::value 为 true 时才会被复制. 可复制的旧值类型 V 总是用 boost::contract::old_value_copy<V> 复制. 不可复制的旧值类型 W 在 boost::contract::old_ptr<W> 被解引用时会产生编译期错误; 而 boost::contract::old_ptr_if_copyable<W> 则始终为空 (不产生编译期错误).

参见: 旧值要求
