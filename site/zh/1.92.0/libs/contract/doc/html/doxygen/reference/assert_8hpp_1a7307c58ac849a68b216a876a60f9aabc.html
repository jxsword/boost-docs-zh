宏 BOOST_CONTRACT_ASSERT_AXIOM

BOOST_CONTRACT_ASSERT_AXIOM — 在代码中记录计算上代价高昂到无法承受 (至少与执行函数体的计算开销相比) 的契约条件的首选方式.

概要

// In header: <boost/contract/assert.hpp>

BOOST_CONTRACT_ASSERT_AXIOM(cond)

说明

被断言的条件总是会被编译并在语法上得到验证, 但绝不在运行期检查. 这个宏由等价于以下代码的定义:

#define BOOST_CONTRACT_ASSERT_AXIOM(cond) \
    BOOST_CONTRACT_ASSERT(true || cond)

BOOST_CONTRACT_ASSERT、BOOST_CONTRACT_ASSERT_AUDIT 和 BOOST_CONTRACT_ASSERT_AXIOM 是本库预定义的三个断言级别. 如有需要, 程序员可以通过定义与上面类似的宏来实现自己的断言级别.

参见: 断言级别、 不使用宏

参数:

cond

要检查的布尔契约条件. (这不是可变参数宏参数, 因此它可能包含的任何逗号都必须用圆括号保护, 而 BOOST_CONTRACT_ASSERT_AXIOM((cond)) 则总是可行. )
