old_pointer 类

boost::contract::old_pointer — 把旧值副本转换为旧值指针.

概要

// In header: <boost/contract/old.hpp>


class old_pointer {
public:

  // public member functions
  template<typename T> operator old_ptr_if_copyable< T >();
  template<typename T> operator old_ptr< T >();
};

说明

此类通常只被本库隐式使用, 不会显式出现在用户代码中 (这就是此类没有公有构造函数等的原因).

old_pointer 公有成员函数

  1. template<typename T> operator old_ptr_if_copyable< T >();
    把此对象转换为一个实际的旧值指针, 其旧值类型 T 可以可复制也可以不可复制.

    例如, 在赋值或初始化类型为 boost::contract::old_ptr_if_copyable 的旧值指针时会隐式调用它.

    模板参数:

    T

    所指向旧值的类型. 如果该类型不可复制 (参见 boost::contract::is_old_value_copyable), 旧值指针将始终为空, 但本库不会产生编译期错误.

    		 
  2. template<typename T> operator old_ptr< T >();
    把此对象转换为一个实际的旧值指针, 其旧值类型 T 必须可复制.

    例如, 在赋值或初始化类型为 boost::contract::old_ptr 的旧值指针时会隐式调用它.

    模板参数:

    T

    所指向旧值的类型. 该类型必须可复制 (参见 boost::contract::is_old_value_copyable), 否则本库将在旧值指针被解引用时产生编译期错误.
