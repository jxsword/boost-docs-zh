宏 BOOST_CONTRACT_POSTCONDITION

BOOST_CONTRACT_POSTCONDITION — 编写可在编译期完全禁用的后置条件.

概要

// In header: <boost/contract_macro.hpp>

BOOST_CONTRACT_POSTCONDITION(...)

说明

BOOST_CONTRACT_POSTCONDITION(f) 展开为等价于如下所示的代码 (注意当定义了 BOOST_CONTRACT_NO_POSTCONDITIONS 时不会生成任何代码):

#ifndef BOOST_CONTRACT_NO_POSTCONDITIONS
    .postcondition(f)
#endif

其中:

  • f 是本库调用以检查后置条件的仿函数 f() 或 f(result). 此仿函数内的断言通常用 BOOST_CONTRACT_ASSERT 编写, 但调用此仿函数抛出的任何异常都表示契约断言失败 (并将导致本库调用 boost::contract::postcondition_failure). 此仿函数应按 (常量) 引用捕获变量 (以访问它们在函数出口处的值). 仅对虚公有函数和公有函数覆盖, 此仿函数才以返回值 (最好按 const& 接收) result 作为其唯一参数 f(result); 否则它不接受任何参数 f(). (这是一个可变参数宏参数, 因此它可以包含未被圆括号保护的逗号. )

参见: 禁用契约编译、 后置条件
