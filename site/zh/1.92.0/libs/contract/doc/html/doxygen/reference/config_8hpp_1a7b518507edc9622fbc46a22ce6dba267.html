宏 BOOST_CONTRACT_ON_MISSING_CHECK_DECL

BOOST_CONTRACT_ON_MISSING_CHECK_DECL — 当契约未被赋给 boost::contract::check 变量时执行的代码块 (默认未定义, 执行 BOOST_ASSERT(false)).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_ON_MISSING_CHECK_DECL

说明

一般而言, 当契约未被显式赋给类型为 boost::contract::check 的局部变量、且未使用 C++11 的 auto 声明时, 程序中存在逻辑错误 (因为这是对本库的误用). 因此, 默认情况下 (即未定义这个宏时), 本库在这些情况下会调用 BOOST_ASSERT(false). 如果定义了这个宏, 本库将执行这个宏展开的代码, 而不是调用 BOOST_ASSERT(false) (如果程序员更愿意抛出异常等).

这个宏也可以定义为任意代码块 (并使用空花括号 {} 来不产生错误, 不推荐), 例如 (在 GCC 上):

gcc -DBOOST_CONTRACT_ON_MISSING_CHECK_DECL='{ throw std::logic_error("missing contract check declaration"); }' ...
