宏 BOOST_CONTRACT_ASSERT

BOOST_CONTRACT_ASSERT — 断言契约条件的首选方式.

概要

// In header: <boost/contract/assert.hpp>

BOOST_CONTRACT_ASSERT(cond)

说明

从契约内部 (前置条件、后置条件、异常保证、在函数体处复制的旧值、类不变式等) 抛出的任何异常都被本库解释为契约失败. 因此, 当被断言的条件被检查为 false 时, 用户可以手动编写契约断言抛出异常 (本库随后会调用相应的契约失败处理器 boost::contract::precondition_failure 等). 不过, 首选做法是使用这个宏, 因为它展开的代码会抛出 boost::contract::assertion_failure, 其中带有正确的断言文件名 (使用 FILE)、行号 (使用 LINE) 以及被断言条件的代码, 从而产生信息丰富的错误消息 (此处不使用 C++11 的 func, 因为在大多数情况下它只会展开为用于编写契约条件的 lambda 函数的编译器内部名字, 不会给错误消息增加任何特异性).

BOOST_CONTRACT_ASSERT、BOOST_CONTRACT_ASSERT_AUDIT 和 BOOST_CONTRACT_ASSERT_AXIOM 是本库预定义的三个断言级别.

参见: 前置条件、 后置条件、 异常保证、 类不变式、 不使用宏

参数:

cond

要检查的布尔契约条件. (这不是可变参数宏参数, 因此它可能包含的任何逗号都必须用圆括号保护, 而 BOOST_CONTRACT_ASSERT((cond)) 则总是可行. )
