bad_virtual_result_cast 类

boost::contract::bad_virtual_result_cast — 当传递给被覆盖虚公有函数的返回值不一致时抛出的异常.

概要

// In header: <boost/contract/core/exception.hpp>


class bad_virtual_result_cast :
  public std::bad_cast, public boost::contract::exception
{
public:

  // public member functions
  explicit bad_virtual_result_cast(char const *, char const *);
  ~bad_virtual_result_cast();
  char const * what() const;
};

说明

当程序员传递给本库的派生类公有函数覆盖的返回值参数, 与为基类中被覆盖虚公有函数传递的返回类型参数不一致时, 会抛出此异常. 这使本库能够在这类误用情况下给出更具描述性的错误消息.

此异常由本库在内部抛出, 程序员不需要从用户代码抛出它.

参见: 公有函数覆盖
