宏 BOOST_CONTRACT_ALL_DISABLE_NO_ASSERTION

BOOST_CONTRACT_ALL_DISABLE_NO_ASSERTION — 定义此宏以在检查其他断言期间不禁用任何断言 (默认未定义).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_ALL_DISABLE_NO_ASSERTION

说明

在检查其他断言期间不禁用断言可能导致用户代码中的无限递归, 因此默认不定义这个宏. (定义这个宏自动意味着检查前置条件期间会禁用其他断言检查, 如同同时定义了 BOOST_CONTRACT_PRECONDITIONS_DISABLE_NO_ASSERTION 一样. )
