类模板 old_ptr

boost::contract::old_ptr — 要求所指向旧值类型可复制的旧值指针.

概要

// In header: <boost/contract/old.hpp>

template<typename T> 
class old_ptr {
public:
  // types
  typedef T element_type;  // Pointed old value type. 

  // public member functions
  old_ptr();
  T const & operator*() const;
  T const * operator->() const;
  explicit operator bool() const;
};

说明

可以使用 BOOST_CONTRACT_OLDOF 或 boost::contract::make_old 把此指针设置为指向实际的旧值副本 (这就是此类没有公有非默认构造函数的原因):

class u {
public:
    virtual void f(..., boost::contract::virtual_* v = 0) {
        boost::contract::old_ptr<old_type> old_var = // For copyable `old_type`.
                BOOST_CONTRACT_OLDOF(v, old_expr);
        ...
    }

    ...
};

参见: 旧值

模板参数

  1. typename T

    所指向旧值的类型. 该类型必须可复制 (即 boost::contract::is_old_value_copyable<T>::value 必须为 true), 否则此指针将始终为空, 且本库将在指针被解引用时产生编译期错误.

old_ptr 公有成员函数

  1. old_ptr();
    把此旧值指针构造为空.
  2. T const & operator*() const;
    解引用此旧值指针.

    如果此指针为空, 这里将产生运行期错误; 如果所指向类型 T 不可复制 (即 boost::contract::is_old_value_copyable<T>::value 为 false), 则产生编译期错误.

    返回:

    所指向的旧值. 契约断言不应改变程序状态, 因此此成员函数是 const 的, 并以对常量对象的引用形式返回旧值 (参见 常量正确性).

    		 
  3. T const * operator->() const;
    以结构解引用方式访问此旧值指针.

    如果所指向类型 T 不可复制 (即 boost::contract::is_old_value_copyable<T>::value 为 false), 这里将产生编译期错误.

    返回:

    指向旧值的指针 (如果此旧值指针为空, 则为空). 契约断言不应改变程序状态, 因此此成员函数是 const 的, 并以指向常量对象的指针形式返回旧值 (参见 常量正确性).

    		 
  4. explicit operator bool() const;
    查询此旧值指针是否为空 (safe-bool 运算符).

    (在不支持 C++11 显式类型转换运算符的编译器上, 这使用 safe-bool 模拟实现. )

    返回:

    如果此指针非空则为 true, 否则为 false.
