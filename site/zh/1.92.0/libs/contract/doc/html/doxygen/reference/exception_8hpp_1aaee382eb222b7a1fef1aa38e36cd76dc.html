from 类型

boost::contract::from — 指示契约断言失败所在操作的种类.

概要

// In header: <boost/contract/core/exception.hpp>



enum from { from_constructor, from_destructor, from_function };

说明

它作为参数传递给断言失败处理器函数. 例如, 可能需要知道断言在哪个操作中失败, 以确保从析构函数中绝不抛出异常——即使用户把契约失败处理器编写为抛出异常而不是终止程序.

参见: 失败时抛出异常

from_constructor
检查构造函数契约时断言失败.
from_destructor
检查析构函数契约时断言失败.
from_function
检查函数契约时断言失败 (无论是否为成员函数, 无论是否为公有).
