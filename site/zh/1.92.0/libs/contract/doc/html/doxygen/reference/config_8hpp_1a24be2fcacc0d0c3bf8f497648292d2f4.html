宏 BOOST_CONTRACT_MAX_ARGS

BOOST_CONTRACT_MAX_ARGS — 在不支持可变参数模板的编译器上, 公有函数覆盖的最大实参数量 (默认为 10).

概要

// In header: <boost/contract/core/config.hpp>

BOOST_CONTRACT_MAX_ARGS

说明

在不支持 C++11 可变参数模板的编译器上, 这个宏被定义为公有函数覆盖可以拥有并传递给 boost::contract::public_function 的最大实参数量 (用户可以把这个宏重定义为不同的值). 在支持可变参数模板的编译器上, 这个宏无效.

注释

无论这个宏的取值如何、编译器是否支持可变参数模板, 公有函数覆盖的实参数量可能存在约 18 个的内在上限 (因为本库内部使用的 Boost.MPL 和 Boost.FunctionTypes 有类似限制).

参见: 不使用宏
