copy_old 函数

boost::contract::copy_old — 查询是否需要复制旧值 (用于虚公有函数和公有函数覆盖).

概要

// In header: <boost/contract/old.hpp>


bool copy_old(virtual_ * v);

说明

例如, 当后置条件和异常保证都未被检查时, 此函数总是返回 false (参见 BOOST_CONTRACT_NO_OLDS). 此外, 当本库为支持子契约而后续再次调用被覆盖函数时, 此函数也返回 false. 此函数通常只由 BOOST_CONTRACT_OLDOF 展开的代码调用.

参见: 不使用宏

参数:

v

来自声明契约的外围虚公有函数或覆盖公有函数的尾随参数, 类型为 boost::contract::virtual_*, 默认值为 0.

返回:

如果需要复制旧值则为 true, 否则为 false.
