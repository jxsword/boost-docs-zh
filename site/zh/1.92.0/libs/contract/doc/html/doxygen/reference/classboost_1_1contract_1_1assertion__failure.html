assertion_failure 类

boost::contract::assertion_failure — 通常用于报告契约断言失败的异常.

概要

// In header: <boost/contract/core/exception.hpp>


class assertion_failure :
  public std::exception, public boost::contract::exception
{
public:

  // public member functions
  explicit assertion_failure(char const * = "", unsigned long = 0, 
                             char const * = "");
  explicit assertion_failure(char const *);
  ~assertion_failure();
  char const * what() const;
  char const * file() const;
  unsigned long line() const;
  char const * code() const;
};

说明

此异常由 BOOST_CONTRACT_ASSERT 展开的代码抛出 (但手动编写、不使用该宏的用户代码也可以抛出它). 此异常通常用于报告契约断言失败, 因为它包含关于被断言条件的文件名、行号和源代码的详细信息 (因此本库在处理契约断言失败时可以用它来提供详细的错误消息).

不过, 也可以使用任何其他异常来报告契约断言失败 (包括用户自定义异常). 当检查契约期间抛出此异常或任何其他异常时, 本库会调用相应的契约失败处理器函数 ( boost::contract::precondition_failure 等) (默认情况下, 这些失败处理器函数向 std::cerr 打印错误消息并终止程序, 但可以自定义它们执行任何其他操作).

参见: 失败时抛出异常、 不使用宏

assertion_failure 公有成员函数

  1. explicit assertion_failure(char const * file = "", unsigned long line = 0, 
                           char const * code = "");
    用断言条件的文件名、行号和源代码文本构造此对象 (全部可选).

    这个构造函数也可以用来不指定任何信息 (默认构造函数), 或者只指定文件名和行号而不指定源代码文本 (由于参数的默认值).

    参数:

    file

    包含断言的文件名 (通常用 FILE 设置).

    line

    包含断言的行号 (通常用 LINE 设置).

    code

    列出断言条件源代码的文本.

    		 
  2. explicit assertion_failure(char const * code);
    只用断言条件的源代码文本构造此对象.

    参数:

    code

    列出断言条件源代码的文本.

    		 
  3. ~assertion_failure();
    析构此对象.

    抛出: 此函数被声明为 noexcept (C++11 之前为 throw()).

  4. char const * what() const;
    描述失败断言的字符串.

    抛出: 此函数被声明为 noexcept (C++11 之前为 throw()).

    返回:

    一个格式类似如下的字符串: assertion "`code()`" failed: file "`file()`", line `line()` (其中 `` 表示执行引号). 如果构造此对象时未指定文件、行和代码, 它们将从此字符串中省略.

    		 
  5. char const * file() const;
    包含断言的文件名.

    返回:

    构造时指定的文件名 (如果未指定文件, 则为 "").

    		 
  6. unsigned long line() const;
    包含断言的行号.

    返回:

    构造时指定的行号 (如果未指定行号, 则为 0).

    		 
  7. char const * code() const;
    列出断言条件源代码的文本.

    返回:

    构造时指定的断言条件源代码 (如果未指定源代码文本, 则为 "").
