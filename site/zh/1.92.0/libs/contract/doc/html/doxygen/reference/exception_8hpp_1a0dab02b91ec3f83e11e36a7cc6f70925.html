old_failure 函数

boost::contract::old_failure — 为在函数体处复制的旧值调用失败处理器.

概要

// In header: <boost/contract/core/exception.hpp>


void old_failure(from where);

说明

这通常只由本库在内部调用.

抛出: 如果程序员指定的失败处理器在契约断言失败时抛出异常 (非默认行为), 这里就可能抛出异常.

参见: 失败时抛出异常、 在函数体处复制的旧值

参数:

where

导致旧值复制失败的操作 (例如, 这可能有助于编写从析构函数中绝不抛出异常的失败处理器仿函数——即使用户把它们编写为抛出异常而不是终止程序).
