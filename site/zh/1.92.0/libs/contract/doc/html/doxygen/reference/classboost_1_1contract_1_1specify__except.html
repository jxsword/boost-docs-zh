specify_except 类

boost::contract::specify_except — 允许指定异常保证.

概要

// In header: <boost/contract/core/specify.hpp>


class specify_except {
public:

  // public member functions
  ~specify_except() noexcept(false);
  template<typename F> specify_nothing except(F const &);
};

说明

允许指定本库将调用以检查异常保证的仿函数. 当用户通过调用 boost::contract::function 等类似函数指定契约时, 本库会在内部构造此对象 (这就是此类没有公有构造函数的原因).

参见: 异常保证

specify_except 公有成员函数

  1. ~specify_except() noexcept(false);
    析构此对象.

    抛出: 自 C++11 起此函数被声明为 noexcept(false), 以允许用户编写在契约断言失败时抛出异常的失败处理器 (这不是默认行为, 参见 失败时抛出异常).

  2. template<typename F> specify_nothing except(F const & f);
    允许指定异常保证.

    参数:

    f

    本库调用这个零元仿函数来检查异常保证 f(). 此仿函数内的断言通常用 BOOST_CONTRACT_ASSERT 编写, 但调用此仿函数抛出的任何异常都表示契约断言失败 (并将导致本库调用 boost::contract::except_failure). 此仿函数应按 (常量) 引用捕获变量 (以访问它们在函数出口处的值).

    返回:

    指定异常保证之后, 此函数返回的对象不再允许指定任何附加契约.
