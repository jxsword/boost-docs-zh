syntax_option_type 概述

类型 syntax_option_type 是一种实现特定的位掩码类型 (见 C++ 标准 17.3.2.1.2). 设置其元素会产生下表所列的效果; syntax_option_type 类型的有效值总是恰好设置了元素 normal、basic、extended、awk、grep、egrep、sed、literal 或 perl 中的恰好一个.

注意, 为方便起见, 此处列出的所有常量都在类模板 basic_regex 的作用域内重复定义, 因此你可以使用以下任意一种:

boost::regex_constants::constant_name

或者

boost::regex::constant_name

或者

boost::wregex::constant_name

以可互换的方式使用.
