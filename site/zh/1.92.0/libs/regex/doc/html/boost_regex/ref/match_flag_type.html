match_flag_type

类型 match_flag_type 是一种实现特定的位掩码类型 (见 C++ 标准 17.3.2.1.2), 它控制正则表达式如何与字符序列进行匹配. 格式标志的行为在 格式语法指南 中有更详细的描述.

namespace boost{ namespace regex_constants{

typedef implemenation-specific-bitmask-type match_flag_type;

static const match_flag_type match_default = 0;
static const match_flag_type match_not_bob;
static const match_flag_type match_not_eob;
static const match_flag_type match_not_bol;
static const match_flag_type match_not_eol;
static const match_flag_type match_not_bow;
static const match_flag_type match_not_eow;
static const match_flag_type match_any;
static const match_flag_type match_not_null;
static const match_flag_type match_continuous;
static const match_flag_type match_partial;
static const match_flag_type match_single_line;
static const match_flag_type match_prev_avail;
static const match_flag_type match_not_dot_newline;
static const match_flag_type match_not_dot_null;
static const match_flag_type match_posix;
static const match_flag_type match_perl;
static const match_flag_type match_nosubs;
static const match_flag_type match_extra;

static const match_flag_type format_default = 0;

说明

类型 match_flag_type 是一种实现特定的位掩码类型 (见 C++ 标准 17.3.2.1.2). 当将正则表达式与字符序列 [first, last) 进行匹配时, 设置其元素会产生下表所列的效果:

元素

设置后的效果

match_default

指定正则表达式的匹配按 ECMA-262 (ECMAScript 语言规范, 第 15 章第 10 部分, RegExp (正则表达式) 对象) 中的正常规则进行, 不做任何修改 (FWD.1)

match_not_bob

指定表达式 "\A" 和 "\`" 不应与子序列 [first,first) 匹配.

match_not_eob

指定表达式 "\'、"\z" 和 "\Z" 不应与子序列 [last,last) 匹配.

match_not_bol

指定表达式 "^" 不应与子序列 [first,first) 匹配.

match_not_eol

指定表达式 "$" 不应与子序列 [last,last) 匹配.

match_not_bow

指定表达式 "\<" 和 "\b" 不应与子序列 [first,first) 匹配.

match_not_eow

指定表达式 "\>" 和 "\b" 不应与子序列 [last,last) 匹配.

match_any

指定如果可能存在多个匹配, 则任何一个匹配都是可接受的结果: 这仍会找到最左的匹配, 但未必是该位置上的"最佳"匹配. 如果你在乎匹配速度而不在乎匹配到的内容 (只关心是否存在匹配), 可使用该标志.

match_not_null

指定表达式不能与空序列匹配.

match_continuous

指定表达式必须匹配从 first 开始的子序列.

match_partial

指定如果找不到匹配, 则可以返回一个匹配 [from, last) (其中 from != last), 只要可能存在某个更长的字符序列 [from,to) 使 [from,last) 为其前缀且能形成完整匹配. 匹配不完整或非常长的文本时使用该标志, 更多信息见部分匹配文档.

match_extra

指示匹配引擎保留所有可用的捕获信息; 如果某个捕获组被重复, 则每次重复的信息都可通过 match_results::captures() 或 sub_match_captures() 获取.

match_single_line

等价于 Perl 的 m/ 修饰符的反面; 防止 ^ 在内嵌换行符之后匹配 (使其只在被匹配文本的开头匹配), 并防止 $ 在内嵌换行符之前匹配 (使其只在被匹配文本的结尾匹配).

match_prev_avail

指定 --first 是有效的迭代器位置; 设置该标志后, 正则表达式算法 (RE.7) 和迭代器 (RE.8) 会忽略标志 match_not_bol 和 match_not_bow.

match_not_dot_newline

指定表达式 "." 不匹配换行符. 这是 Perl 的 s/ 修饰符的反面.

match_not_dot_null

指定表达式 "." 不匹配空字符 '\0'.

match_posix

指定无论编译的是何种表达式, 都按 POSIX 最左最长规则 进行匹配. 请注意, 这些规则与许多 Perl 特有特性 (如非贪婪重复) 的配合不佳.

match_perl

指定无论编译的是何种表达式, 都按 Perl 匹配规则 进行匹配.

match_nosubs

使表达式的行为如同没有标记子表达式, 无论实际存在多少个捕获组. match_results 类将只包含关于整体匹配的信息, 而不包含任何子表达式的信息.

format_default

指定当正则表达式匹配需要被替换为新字符串时, 新字符串按 ECMA-262 (ECMAScript 语言规范, 第 15 章第 5.4.11 节 String.prototype.replace) 中 ECMAScript replace 函数所用的规则构造 (FWD.1).

这在功能上与 Perl 格式字符串规则 相同.

此外, 在搜索替换操作中, 正则表达式的所有互不重叠的出现都会被定位并替换, 输入中未匹配表达式的部分则原样复制到输出字符串.

format_sed

指定当正则表达式匹配需要被替换为新字符串时, 新字符串按 IEEE Std 1003.1-2001 (可移植操作系统接口 (POSIX), Shell 与工具) 中 Unix sed 实用工具所用的规则构造. 另见 Sed 格式字符串参考.

format_perl

指定当正则表达式匹配需要被替换为新字符串时, 新字符串按 Perl 5 的相同规则 构造.

format_literal

指定当正则表达式匹配需要被替换为新字符串时, 新字符串是替换文本的字面拷贝.

format_all

指定启用所有语法扩展, 包括条件表达式 (?ddexpression1:expression2) 替换: 更多细节见 格式字符串指南.

format_no_copy

在搜索替换操作中指定时, 被搜索的字符容器序列中与正则表达式匹配的部分不会被复制到输出字符串.

format_first_only

在搜索替换操作中指定时, 只替换正则表达式的第一次出现.
