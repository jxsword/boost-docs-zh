Unicode 与 Boost.Regex

将 Boost.Regex 用于 Unicode 字符串有两种方式:

依赖 wchar_t

如果你平台的 wchar_t 类型能容纳 Unicode 字符串, 且你平台的 C/C++ 运行时能正确处理宽字符常量 (当传递给 std::iswspace std::iswlower 等时), 则可以用 boost::wregex 处理 Unicode. 但这种方式有几个缺点:

  • 可移植性差: wchar_t 的宽度无法保证, 甚至不能保证运行时把宽字符当作 Unicode 处理; 大多数 Windows 编译器会这样做, 但许多 Unix 系统不会.
  • 不支持 Unicode 特有的字符类: [[:Nd:]]、[[:Po:]] 等.
  • 你只能搜索以宽字符序列编码的字符串; 在许多平台上, 无法搜索 UTF-8, 甚至 UTF-16.
使用感知 Unicode 的正则表达式类型.

如果你有 ICU 库, Boost.Regex 提供了一种独特的正则表达式类型 (boost::u32regex), 它既支持 Unicode 特有的字符属性, 又支持搜索以 UTF-8、UTF-16 或 UTF-32 编码的文本. 见: ICU 字符串类支持.
