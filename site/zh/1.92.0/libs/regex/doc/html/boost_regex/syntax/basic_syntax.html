POSIX 基本正则表达式语法

概要

Unix 实用工具 sed 使用 POSIX 基本正则表达式语法, grep 和 emacs 使用其变体. 在 Boost.Regex 中, 向 regex 构造函数传递标志 basic (见 syntax_option_type) 即可构造 POSIX 基本正则表达式, 例如:

// e1 is a case sensitive POSIX-Basic expression:
boost::regex e1(my_expression, boost::regex::basic);
// e2 a case insensitive POSIX-Basic expression:
boost::regex e2(my_expression, boost::regex::basic|boost::regex::icase);

POSIX 基本语法

在 POSIX 基本正则表达式中, 除以下特殊字符外, 所有字符都匹配自身:

.[\*^$
通配符:

在字符集合之外使用时, 单字符 '.' 会匹配任何单个字符, 但以下除外:

  • 当向匹配算法传递标志 match_no_dot_null 时的 NULL 字符.
  • 当向匹配算法传递标志 match_not_dot_newline 时的换行字符.
锚点:

'^' 字符在用作表达式的首字符, 或子表达式的首字符时, 匹配行首.

'$' 字符在用作表达式的末字符, 或子表达式的末字符时, 匹配行尾.

标记子表达式:

以 \( 开始、以 \) 结束的部分充当标记子表达式. 与该子表达式匹配的内容会被匹配算法拆分到单独的字段中. 标记子表达式还可以被重复, 或通过后向引用引用.

重复:

任何原子 (单个字符、标记子表达式或字符类) 都可以用 * 运算符重复.

例如 a* 会匹配重复零次或多次的任意个数的字母 a (原子重复零次匹配空字符串), 因此表达式 a*b 会匹配以下任意一项:

b
ab
aaaaaaaab

原子还可以用有界重复来重复:

a\{n\} 匹配重复恰好 n 次的 'a'.

a\{n,\} 匹配重复 n 次或更多次的 'a'.

a\{n, m\} 匹配重复介于 n 和 m 次之间 (含) 的 'a'.

例如:

^a{2,3}$

会匹配以下之一:

aa
aaa

但不会匹配以下任何一项:

a
aaaa

如果前面的构造不可重复, 则使用重复运算符是错误的, 例如:

a(*)

会引发错误, 因为没有任何内容可供 * 运算符作用.

后向引用:

转义字符后跟一个数字 n (其中 n 在 1-9 范围内) 会匹配与子表达式 n 所匹配相同的字符串. 例如表达式:

^\(a*\)[^a]*\1$

会匹配字符串:

aaabbaaa

但不匹配字符串:

aaabba
字符集合:

字符集合是以 [ 开始、以 ] 结束的括号表达式; 它定义一个字符集合, 并匹配该集合的任意单个成员字符.

括号表达式可以包含以下内容的任意组合:

单个字符:

例如 [abc] 会匹配字符 'a'、'b' 或 'c' 中的任意一个.

字符范围:

例如 [a-c] 会匹配 'a' 到 'c' 范围内的任意单字符. 对 POSIX 基本正则表达式而言, 默认情况下, 字符 x 处于 y 到 z 的范围内, 当且仅当它在该范围内排序时; 这会产生区域相关的行为. 构造正则表达式时取消设置 collate 选项标志可以关闭该行为 - 此时字符是否处于某范围内仅由比较字符的码点决定.

取反:

如果括号表达式以 ^ 字符开头, 则它匹配其所含字符的补集, 例如 [^a-c] 匹配任何不在 a-c 范围内的字符.

字符类:

形如 [[:name:]] 的表达式匹配名为 "name" 的命名字符类, 例如 [[:lower:]] 匹配任意小写字符. 参见 字符类名称.

排序元素:

形如 [[.col.] 的表达式匹配排序元素 col. 排序元素是任何单个字符, 或任何作为单个单元排序的字符序列. 排序元素还可用作范围的端点, 例如: 假设在当前区域设置中 "ae" 被视为单个排序元素, 则 [[.ae.]-c] 匹配字符序列 "ae", 加上 "ae"-c 范围内的任意单字符.

排序元素可以代替转义 (字符集合内通常不允许转义), 例如 [[.^.]abc] 会匹配字符 'abc^' 中的任意一个.

作为扩展, 排序元素还可以通过其符号名称指定, 例如:

[[.NUL.]]

匹配一个 'NUL' 字符. 参见 排序元素名称.

等价类:

形如 [[=col=]] 的表达式匹配任何主排序键与排序元素 col 相同的字符或排序元素; 与排序元素一样, 名称 col 可以是 collating 符号名称. 主排序键是忽略大小写、重音符号或区域特定定制的排序键; 例如 [[=a=]] 匹配以下字符之一: a, À, Á, Â, Ã, Ä, Å, A, à, á, â, ã, ä 和 å. 遗憾的是, 该特性的实现依赖于平台的排序与本地化支持; 不能指望该特性在所有平台之间, 甚至在同一平台的所有区域设置之间, 以可移植的方式正常工作.

组合:

以上所有内容都可以在一个字符集合声明中组合, 例如: [[:digit:]a-c[.NUL.]].

转义

除了上文已说明的转义序列 \{、\}、\( 和 \) 之外, 转义字符后跟任何字符都匹配该字符. 这可用于把特殊字符

.[\*^$

变为"普通"字符. 注意, 转义字符在字符集合内会丧失其特殊含义, 因此 [\^] 会匹配字面 '\' 或 '^'.

匹配到什么

当一个正则表达式有多种匹配方式时, 使用 最左最长规则 获得"最佳"可能的匹配.

变体

Grep

当表达式在设置标志 grep 的情况下编译时, 表达式被视为以换行符分隔的 POSIX 基本表达式 列表; 列表中任意表达式匹配即找到匹配, 例如:

boost::regex e("abc\ndef", boost::regex::grep);

会匹配 POSIX 基本表达式 "abc" 或 "def" 之一.

顾名思义, 该行为与 Unix 实用工具 grep 一致.

emacs

除 POSIX 基本特性 外, 以下字符也是特殊的:

字符

说明

+

把前面的原子重复一次或多次.

?

把前面的原子重复零次或一次.
  • ?

* 的非贪婪版本.

+?

+ 的非贪婪版本.

??

? 的非贪婪版本.

以下转义序列也会被识别:

转义

说明

\|

指定一个分支.

\(?: ... )

一种不产生标记的分组构造 - 允许你在词法上对某个东西分组而不额外产生一个子表达式.

\w

匹配任意单词字符.

\W

匹配任意非单词字符.

\sx

匹配语法组 x 中的任意字符; 支持以下 emacs 语法组: 's'、' '、'_'、'w'、'.'、')'、'('、'"'、'\''、'>' 和 '<'. 详情参阅 emacs 文档.

\Sx

匹配不在语法组 x 中的任意字符.

\c 和 \C

不支持这些.

\`

仅在缓冲区 (或被匹配字符串) 的起始处匹配零个字符.

\'

仅在缓冲区 (或被匹配字符串) 的结尾处匹配零个字符.

\b

在单词边界处匹配零个字符.

\B

匹配零个字符, 且不在单词边界处.

\<

仅在单词的起始处匹配零个字符.

\>

仅在单词的结尾处匹配零个字符.

最后请注意, emacs 风格的正则表达式按 Perl "深度优先搜索"规则 进行匹配. emacs 表达式以这种方式匹配, 是因为它们包含 Perl 式扩展, 而这些扩展与 POSIX 风格的最左最长规则 不能很好地交互.

选项

构造正则表达式时, 多种标志 可以与 basic 和 grep 选项组合; 尤其请注意, newline_alt、no_char_classes、no-intervals、bk_plus_qm 和 bk_plus_vbar 选项都会改变语法, 而 collate 和 icase 选项 则修改大小写和区域设置敏感性的应用方式.
