部分匹配

match_flag_type match_partial 可传递给以下算法: regex_match、regex_search 和 regex_grep, 并可与迭代器 regex_iterator 一起使用. 使用它表示除完整匹配外还应找出部分匹配. 部分匹配是指在文本输入末尾匹配了一个或多个字符、但未匹配整个正则表达式的匹配 (尽管如果输入更多内容, 它本可以匹配完整). 部分匹配通常用于验证数据输入 (检查键盘输入的每个字符), 或搜索因过长而无法载入内存 (甚至无法载入内存映射文件) 或长度不确定的文本 (例如来源可能是套接字或类似物). 部分匹配与完整匹配可按下表区分 (变量 M 表示一个 match_results 实例, 由 regex_match、regex_search 或 regex_grep 填充):

注意, 使用部分匹配有时会导致一些不够完美的行为:

  • 有些表达式 (如 ".*abc") 总是产生部分匹配. 通过仔细构造所用正则表达式, 或设置 match_not_dot_newline 之类的标志使 .* 之类的表达式无法越过行边界, 可以减少这一问题.
  • Boost.Regex 目前优先选择最左匹配而非完整匹配, 例如用 "abc|b" 匹配 "ab" 会得到针对 "ab" 的部分匹配, 而不是针对 "b" 的完整匹配. 这种方式效率更高, 但未必是你在所有情况下想要的行为.
  • 有些情况下即使部分匹配也可能存在, 仍会找到完整匹配: 例如, 如果部分字符串以 "abc" 结尾且正则表达式为 "\w+", 则即使后面可能还有字母字符, 也会找到完整匹配. 这种特殊情况可以通过检查找到的匹配是否终止于当前输入字符串末尾来检测. 但是, 有些情况下无法做到这一点: 例如 "abc.*123" 这样的表达式可能总是有更长的匹配可用, 因为它可能匹配整个输入字符串 (无论它有多长).

下面的示例测试文本是否可能是有效的信用卡号码; 当用户按键时, 输入的字符会被加入正在构建的字符串, 并传递给 is_possible_card_number. 如果返回 true, 则文本可能是有效卡号, 用户界面的 OK 按钮将被启用. 如果返回 false, 则这还不是有效卡号, 但若输入更多内容则可能有效, 用户界面会禁用 OK 按钮. 最后, 如果该过程抛出异常, 则输入永远不可能成为有效号码, 必须丢弃输入的字符, 并向用户显示适当的错误提示.

#include <string>
#include <iostream>
#include <boost/regex.hpp>

boost::regex e("(\\d{3,4})[- ]?(\\d{4})[- ]?(\\d{4})[- ]?(\\d{4})");

bool is_possible_card_number(const std::string& input)
{
   //
   // return false for partial match, true for full match, or throw for
   // impossible match based on what we have so far...
   boost::match_results<std::string::const_iterator> what;
   if(0 == boost::regex_match(input, what, e, boost::match_default | boost::match_partial))
   {
      // the input so far could not possibly be valid so reject it:
      throw std::runtime_error(
         "Invalid data entered - this could not possibly be a valid card number");
   }
   // OK so far so good, but have we finished?
   if(what[0].matched)
   {
      // excellent, we have a result:
      return true;
   }
   // what we have so far is only a partial match...
   return false;
}

在下面的示例中, 文本输入来自包含未知数量文本的流; 该示例只统计流中遇到的 html 标签数量. 文本被载入缓冲区并逐部分搜索; 如果遇到部分匹配, 则该部分匹配会在下一批文本的开头再次被搜索:

#include <iostream>
#include <fstream>
#include <sstream>
#include <string>
#include <boost/regex.hpp>

// match some kind of html tag:
boost::regex e("<[^>]*>");
// count how many:
unsigned int tags = 0;

void search(std::istream& is)
{
   // buffer we'll be searching in:
   char buf[4096];
   // saved position of end of partial match:
   const char* next_pos = buf + sizeof(buf);
   // flag to indicate whether there is more input to come:
   bool have_more = true;

   while(have_more)
   {
      // how much do we copy forward from last try:
      unsigned leftover = (buf + sizeof(buf)) - next_pos;
      // and how much is left to fill:
      unsigned size = next_pos - buf;
      // copy forward whatever we have left:
      std::memmove(buf, next_pos, leftover);
      // fill the rest from the stream:
      is.read(buf + leftover, size);
      unsigned read = is.gcount();
      // check to see if we've run out of text:
      have_more = read == size;
      // reset next_pos:
      next_pos = buf + sizeof(buf);
      // and then iterate:
      boost::cregex_iterator a(
         buf,
         buf + read + leftover,
         e,
         boost::match_default | boost::match_partial);
      boost::cregex_iterator b;

      while(a != b)
      {
         if((*a)[0].matched == false)
         {
            // Partial match, save position and break:
            next_pos = (*a)[0].first;
            break;
         }
         else
         {
            // full match:
            ++tags;
         }

         // move to next match:
         ++a;
      }
   }
}
