regex_search 

#include <boost/regex.hpp>

算法 regex_search 会在由一对双向迭代器表示的范围中搜索给定的正则表达式. 该算法使用多种启发式方法来减少搜索时间: 只有当某个位置有可能成为匹配的起点时才检查是否匹配. 该算法定义如下:

template <class BidirectionalIterator,
         class Allocator, class charT, class traits>
bool regex_search(BidirectionalIterator first, BidirectionalIterator last,
                  match_results<BidirectionalIterator, Allocator>& m,
                  const basic_regex<charT, traits>& e,
                  match_flag_type flags = match_default);

template <class ST, class SA,
         class Allocator, class charT, class traits>
bool regex_search(const basic_string<charT, ST, SA>& s,
                  match_results<
                  typename basic_string<charT, ST,SA>::const_iterator,
                  Allocator>& m,
                  const basic_regex<charT, traits>& e,
                  match_flag_type flags = match_default);

说明 
template <class BidirectionalIterator, class Allocator, class charT, class traits>
bool regex_search(BidirectionalIterator first, BidirectionalIterator last,
                  match_results<BidirectionalIterator, Allocator>& m,
                  const basic_regex<charT, traits>& e,
                  match_flag_type flags = match_default);

要求: 类型 BidirectionalIterator 符合双向迭代器要求 (24.1.4).

效果: 判断 [first,last) 内是否存在与正则表达式 e 匹配的子序列; 参数 flags 用于控制表达式与字符序列的匹配方式. 如果存在这样的子序列则返回 true, 否则返回 false.

抛出: std::runtime_error, 当将表达式与 N 个字符的字符串进行匹配的复杂度开始超过 O(N2), 或者匹配表达式时程序耗尽栈空间 (当 Boost.Regex 以递归模式配置时), 或者匹配器耗尽其允许的内存分配 (当 Boost.Regex 以非递归模式配置时).

后置条件: 如果函数返回 false, 则对参数 m 的影响未定义; 否则对参数 m 的影响在表中给出:

m[n].second

对于所有整数 n < m.size(), 为与子表达式 n 匹配的序列的结尾; 或者, 如果子表达式 n 未参与匹配, 则为 last.

m[n].matched

对于所有整数 n < m.size(), 子表达式 n 参与了匹配则为 true, 否则为 false.

 
template <class charT, class Allocator, class traits>
bool regex_search(const charT* str, match_results<const charT*, Allocator>& m,
                  const basic_regex<charT, traits>& e,
                  match_flag_type flags = match_default);

效果: 返回 regex_search(str, str + char_traits<charT>::length(str), m, e, flags) 的结果.

template <class ST, class SA, class Allocator, class charT,
         class traits>
bool regex_search(const basic_string<charT, ST, SA>& s,
                  match_results<typename basic_string<charT, ST, SA>::const_iterator, Allocator>& m,
                  const basic_regex<charT, traits>& e,
                  match_flag_type flags = match_default);

效果: 返回 regex_search(s.begin(), s.end(), m, e, flags) 的结果.

                  const basic_regex<charT, traits>& e,
                  match_flag_type flags = match_default);

示例

下面的示例以字符串形式读入文件内容, 并搜索文件中所有的 C++ 类声明. 无论 std::string 以何种方式实现, 代码都能工作; 例如它可以很容易地改造为配合使用非连续存储策略的 SGI rope 类.

#include <string>
#include <map>
#include <boost/regex.hpp>

// purpose: 
// takes the contents of a file in the form of a string 
// and searches for all the C++ class definitions, storing 
// their locations in a map of strings/int's 
typedef std::map<std::string, int, std::less<std::string> > map_type;

boost::regex expression(
   "^(template[[:space:]]*<[^;:{]+>[[:space:]]*)?"
   "(class|struct)[[:space:]]*"
   "(\\<\\w+\\>([[:blank:]]*\\([^)]*\\))?"
   "[[:space:]]*)*(\\<\\w*\\>)[[:space:]]*"
   "(<[^;:{]+>[[:space:]]*)?(\\{|:[^;\\{()]*\\{)");

void IndexClasses(map_type& m, const std::string& file)
{
   std::string::const_iterator start, end;
   start = file.begin();
   end = file.end();
      boost::match_results<std::string::const_iterator> what;
   boost::match_flag_type flags = boost::match_default;
   while(regex_search(start, end, what, expression, flags))
   {
      // what[0] contains the whole string 
      // what[5] contains the class name. 
      // what[6] contains the template specialisation if any. 
      // add class name and position to map: 
      m[std::string(what[5].first, what[5].second)
            + std::string(what[6].first, what[6].second)]
         = what[5].first - file.begin();
      // update search position: 
      start = what[0].second;
      // update flags: 
      flags |= boost::match_prev_avail;
      flags |= boost::match_not_bob;
   }
}
