双字符 (Digraphs)

以下内容在用作排序名称时被视为有效的双字符:

"ae", "Ae", "AE", "ch", "Ch", "CH", "ll", "Ll", "LL", "ss", "Ss", "SS", "nj", "Nj", "NJ", "dz", "Dz", "DZ", "lj", "Lj", "LJ".

例如表达式:

[[.ae.]-c]

将匹配排序位于双字符 "ae" 与字符 "c" 之间的任意字符.
