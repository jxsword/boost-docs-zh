Perl 正则表达式语法

概要

Perl 正则表达式语法基于编程语言 Perl 所用的语法. Perl 正则表达式是 Boost.Regex 的默认行为, 或者你可以传递标志 perl 给 basic_regex 构造函数, 例如:

// e1 is a case sensitive Perl regular expression: 
// since Perl is the default option there's no need to explicitly specify the syntax used here:
boost::regex e1(my_expression);
// e2 a case insensitive Perl regular expression:
boost::regex e2(my_expression, boost::regex::perl|boost::regex::icase);

Perl 正则表达式语法

在 Perl 正则表达式中, 除以下特殊字符外, 所有字符都匹配自身:

.[{}()\*+?|^$

其他字符仅在特定情况下才是特殊的 - 例如 ] 仅在开括号 [ 之后才是特殊的.

通配符

在字符集合之外使用时, 单字符 '.' 会匹配任何单个字符, 但以下除外:

  • 当向匹配算法传递 标志 match_not_dot_null 时的 NULL 字符.
  • 当向匹配算法传递 标志 match_not_dot_newline 时的换行字符.
锚点

'^' 字符匹配行首.

'$' 字符匹配行尾.

标记子表达式

以 ( 开始、以 ) 结束的部分充当标记子表达式. 与该子表达式匹配的内容会被匹配算法拆分到单独的字段中. 标记子表达式还可以被重复, 或通过后向引用引用.

不产生标记的分组

标记子表达式对在词法上分组正则表达式的某部分很有用, 但有一个副作用: 会在结果中额外产生一个字段. 作为替代, 你可以用 (?: 和 ) 在词法上分组正则表达式的某部分而不生成标记子表达式; 例如 (?:ab)+ 会重复 ab 而不拆分出任何单独的子表达式.

重复

任何原子 (单个字符、标记子表达式或字符类) 都可以用 *、+、? 和 {} 运算符重复.

* 运算符会把前面的原子匹配零次或多次, 例如表达式 a*b 会匹配以下任意一项:

b
ab
aaaaaaaab

+ 运算符会把前面的原子匹配一次或多次, 例如表达式 a+b 会匹配以下任意一项:

ab
aaaaaaaab

但不会匹配:

b

? 运算符会把前面的原子匹配零次或一次, 例如表达式 ca?b 会匹配以下任意一项:

cb
cab

但不会匹配:

caab

原子还可以用有界重复来重复:

a{n} 匹配重复恰好 n 次的 'a'.

a{n,} 匹配重复 n 次或更多次的 'a'.

a{n, m} 匹配重复介于 n 和 m 次之间 (含) 的 'a'.

例如:

^a{2,3}$

会匹配以下之一:

aa
aaa

但不会匹配以下任何一项:

a
aaaa

注意, 当 "{" 和 "}" 字符用在不是重复的上下文中时, 会被当作普通字面量: 这与 Perl 5.x 的行为一致. 例如在表达式 "ab{1"、"ab1}" 和 "a{b}c" 中, 花括号都被当作字面量, 并且不会报错.

如果前面的构造不可重复, 则使用重复运算符是错误的, 例如:

a(*)

会引发错误, 因为没有任何内容可供 * 运算符作用.

非贪婪重复

普通的重复运算符是"贪婪的", 即它们会尽可能多地消耗输入. 还有非贪婪版本可用, 它们在仍能产生匹配的前提下尽可能少地消耗输入.

*? 匹配前面的原子零次或多次, 同时尽可能少地消耗输入.

+? 匹配前面的原子一次或多次, 同时尽可能少地消耗输入.

?? 匹配前面的原子零次或一次, 同时尽可能少地消耗输入.

{n,}? 匹配前面的原子 n 次或更多次, 同时尽可能少地消耗输入.

{n,m}? 匹配前面的原子介于 n 和 m 次之间, 同时尽可能少地消耗输入.

占有性重复 (Possessive repeats)

默认情况下, 当某个重复模式不匹配时, 引擎会回溯直到找到匹配. 不过这种行为有时并非所愿, 因此还有"占有性"重复: 它们尽可能多地匹配, 并且当表达式其余部分匹配失败时不允许回溯.

*+ 匹配前面的原子零次或多次, 且不退还任何已消耗的输入.

++ 匹配前面的原子一次或多次, 且不退还任何已消耗的输入.

?+ 匹配前面的原子零次或一次, 且不退还任何已消耗的输入.

{n,}+ 匹配前面的原子 n 次或更多次, 且不退还任何已消耗的输入.

{n,m}+ 匹配前面的原子介于 n 和 m 次之间, 且不退还任何已消耗的输入.

后向引用

转义字符后跟一个数字 n (其中 n 在 1-9 范围内) 会匹配与子表达式 n 所匹配相同的字符串. 例如表达式:

^(a*)[^a]*\1$

会匹配字符串:

aaabbaaa

但不匹配字符串:

aaabba

你也可以用 \g 转义实现同样的功能, 例如:

转义

含义

\g1

匹配子表达式 1 所匹配的任意内容

\g{1}

匹配子表达式 1 所匹配的任意内容: 这种形式在像 \g{1}2 这样的情况下, 或像 \g{1234} 那样索引大于 9 时, 可以更安全地解析表达式

\g-1

匹配最后一个开启的子表达式所匹配的任意内容

\g{-2}

匹配最后第二个开启的子表达式所匹配的任意内容

\g{one}

匹配名为 "one" 的子表达式所匹配的任意内容

注意, 后向引用也可以是对尚未出现的子表达式的前向引用 - 这真正有意义的场景只在重复内, 例如 (\2two|(one))+ 会匹配 "oneonetwo".

最后, \k 转义可用于引用命名子表达式, 例如 \k<two> 将匹配名为 "two" 的子表达式所匹配的内容.

分支

| 运算符会匹配其两个参数之一, 例如: abc|def 会匹配 "abc" 或 "def".

括号可用于对分支进行分组, 例如: ab(d|ef) 会匹配 "abd" 或 "abef" 之一.

不允许空分支 (这几乎总是笔误), 但如果你确实需要空分支, 请用 (?:) 作为占位符, 例如:

|abc 不是有效表达式, 但

(?:)|abc 是有效的且与之等价; 同样, 表达式:

(?:abc)?? 有完全相同的效果.

字符集合

字符集合是以 [ 开始、以 ] 结束的括号表达式; 它定义一个字符集合, 并匹配该集合的任意单个成员字符.

括号表达式可以包含以下内容的任意组合:

单个字符

例如 [abc] 会匹配字符 'a'、'b' 或 'c' 中的任意一个.

字符范围

例如 [a-c] 会匹配 'a' 到 'c' 范围内的任意单字符. 对 Perl 正则表达式而言, 默认情况下, 当字符 x 的码点位于范围两端的码点之间时, 它处于 y 到 z 的范围内. 或者, 如果你在构造正则表达式时设置 collate 标志, 则范围是区域相关的.

取反

如果括号表达式以 ^ 字符开头, 则它匹配其所含字符的补集, 例如 [^a-c] 匹配任何不在范围 a-c 内的字符.

字符类

形如 [[:name:]] 的表达式匹配名为 "name" 的命名字符类, 例如 [[:lower:]] 匹配任意小写字符. 参见 字符类名称.

排序元素

形如 [[.col.]] 的表达式匹配排序元素 col. 排序元素是任何单个字符, 或任何作为单个单元排序的字符序列. 排序元素还可用作范围的端点, 例如: 假设在当前区域设置中 "ae" 被视为单个排序元素, 则 [[.ae.]-c] 匹配字符序列 "ae", 加上 "ae"-c 范围内的任意单字符.

作为扩展, 排序元素还可以通过其 符号名称 指定, 例如:

[[.NUL.]]

匹配一个 \0 字符.

等价类

形如 [[=col=]] 的表达式匹配任何主排序键与排序元素 col 相同的字符或排序元素; 与排序元素一样, 名称 col 可以是 符号名称. 主排序键是忽略大小写、重音符号或区域特定定制的排序键; 例如 [[=a=]] 匹配以下字符之一: a, À, Á, Â, Ã, Ä, Å, A, à, á, â, ã, ä 和 å. 遗憾的是, 该特性的实现依赖于平台的排序与本地化支持; 不能指望该特性在所有平台之间, 甚至在同一平台的所有区域设置之间, 以可移植的方式正常工作.

转义字符

所有匹配单个字符或单个字符类的转义序列都允许出现在字符类定义中. 例如 [\[\]] 会匹配 [ 或 ] 之一, 而 [\W\d] 会匹配任意一个或者是"数字"或者 不是"单词"字符的字符.

组合

以上所有内容都可以在一个字符集合声明中组合, 例如: [[:digit:]a-c[.NUL.]].

单词边界

以下转义序列匹配单词边界:

< 匹配单词的起始.

缓冲区边界

以下内容仅在缓冲区边界处匹配: 此处的"缓冲区"指要匹配的全部输入文本 (注意, ^ 和 $ 可以匹配文本中的内嵌换行符).

\` 仅在缓冲区的起始处匹配.

\' 仅在缓冲区的结尾处匹配.

\A 仅在缓冲区的起始处匹配 (同 \`).

\z 仅在缓冲区的结尾处匹配 (同 \').

\Z 匹配由缓冲区结尾处一个可选换行序列构成的零宽度断言: 等价于正则表达式 (?=\v*\z). 注意, 这与 Perl 有微妙差异: Perl 的行为如同匹配 (?=\n?\z).

继续转义

序列 \G 仅在上一次找到的匹配的结尾处匹配; 如果之前没有匹配, 则在被匹配文本的起始处匹配. 当你遍历文本中的匹配、希望每个后续匹配从上一个匹配的结束处开始时, 这个转义很有用.

引用转义 (Quoting escape)

转义序列 \Q 开始一个"引用序列": 其后的所有字符都被视为字面量, 直到正则表达式结束或找到 \E. 例如表达式: \Q*+\Ea+ 会匹配以下之一:

\*+a
\*+aaa
Unicode 转义

\C 匹配单个码点: 在 Boost regex 中, 它与 "." 运算符的效果完全相同. \X 匹配组合字符序列: 即任意非组合字符后跟零个或多个组合字符的序列.

匹配行结束序列

转义序列 \R 匹配任意行结束字符序列; 具体而言, 它与表达式 (?>\x0D\x0A?|[\x0A-\x0C\x85\x{2028}\x{2029}]) 完全相同.

保留部分文本

\K 把 $0 的起始位置重置为当前文本位置: 换句话说, \K 左侧的所有内容都被"保留"而不构成正则表达式匹配的一部分. $` 会相应更新.

例如, 用 foo\Kbar 匹配文本 "foobar" 会为 $0 返回匹配 "bar", 为 $` 返回 "foo". 这可用于模拟可变宽度的后行断言.

任何其他转义

任何其他转义序列都匹配被转义的字符, 例如 \@ 匹配字面 '@'.

Perl 扩展模式

Perl 特有的正则表达式语法扩展都以 (? 开头.

命名子表达式

你可以用以下方式创建命名子表达式:

(?<NAME>expression)

随后即可通过名称 NAME 引用. 或者像下面这样用 'NAME' 界定名称:

(?'NAME'expression)

这些命名子表达式可以在后向引用中用 \g{NAME} 或 \k<NAME> 引用, 也可以按名称在用于搜索替换操作的 Perl 格式字符串中引用, 或在 match_results 成员函数中引用.

注释

(?# ... ) 被视为注释, 其内容被忽略.

修饰符

(?imsx-imsx ... ) 会改变模式内有效的 perl 修饰符; 变更从首次看到该块的位置开始生效, 并延伸到任何包含它的 ). '-' 之前的字母开启对应的 perl 修饰符, 其后的字母关闭它.

(?imsx-imsx:pattern) 仅对 pattern 应用指定的修饰符.

不产生标记的分组

(?:pattern) 在词法上对 pattern 分组, 不生成额外的子表达式.

分支重置

(?|pattern) 会在 pattern 内每个 "|" 分支的起始处重置子表达式计数.

该构造之后的子表达式计数取子表达式最多的那个分支的计数. 当你想把多个候选匹配之一捕获到同一个子表达式索引时, 这个构造很有用.

在以下示例中, 每个子表达式的索引标在表达式下方:

# before  ---------------branch-reset----------- after
/ ( a )  (?| x ( y ) z | (p (q) r) | (t) u (v) ) ( z ) /x
# 1            2         2  3        2     3     4
预查 (前向断言)

(?=pattern) 仅当 pattern 匹配时消耗零个字符.

(?!pattern) 仅当 pattern 不匹配时消耗零个字符.

预查通常用于创建两个正则表达式的逻辑与; 例如密码必须包含一个小写字母、一个大写字母、一个标点符号, 并且至少 6 个字符长, 那么表达式:

(?=.*[[:lower:]])(?=.*[[:upper:]])(?=.*[[:punct:]]).{6,}

可用于验证密码.

后行断言

(?<=pattern) 仅当 pattern 能与当前位置之前的字符匹配时消耗零个字符 (pattern 必须是定长的).

(?<!pattern) 仅当 pattern 不能与当前位置之前的字符匹配时消耗零个字符 (pattern 必须是定长的).

独立子表达式

(?>pattern) 中的 pattern 独立于周围模式进行匹配, 表达式永远不会回溯进 pattern. 独立子表达式通常用于提升性能; 只考虑 pattern 的最佳可能匹配, 如果这无法使整个表达式匹配, 则根本不找到匹配.

递归表达式

(?N) (?-N) (?+N) (?R) (?0) (?&NAME)

(?R) 和 (?0) 递归到整个模式的起始.

(?N) 递归执行子表达式 N, 例如 (?2) 会递归到子表达式 2.

(?-N) 和 (?+N) 是相对递归: 例如 (?-1) 递归到最后声明的子表达式, (?+1) 递归到下一个要声明的子表达式.

(?&NAME) 递归到命名子表达式 NAME.

条件表达式

(?(condition)yes-pattern|no-pattern) 在 condition 为真时尝试匹配 yes-pattern, 否则尝试匹配 no-pattern.

(?(condition)yes-pattern) 在 condition 为真时尝试匹配 yes-pattern, 否则匹配 NULL 字符串.

condition 可以是: 一个前向预查断言; 某个标记子表达式的索引 (当该子表达式已被匹配时条件为真); 或某个递归的索引 (当我们正在指定递归内部直接执行时条件为真).

以下是可能谓词的汇总:

  • (?(?=assert)yes-pattern|no-pattern) 当前向预查断言匹配时执行 yes-pattern, 否则执行 no-pattern.
  • (?(?!assert)yes-pattern|no-pattern) 当前向预查断言不匹配时执行 yes-pattern, 否则执行 no-pattern.
  • (?(N)yes-pattern|no-pattern) 当子表达式 N 已被匹配时执行 yes-pattern, 否则执行 no-pattern.
  • (?(<name>)yes-pattern|no-pattern) 当命名子表达式 name 已被匹配时执行 yes-pattern, 否则执行 no-pattern.
  • (?('name')yes-pattern|no-pattern) 当命名子表达式 name 已被匹配时执行 yes-pattern, 否则执行 no-pattern.
  • (?(R)yes-pattern|no-pattern) 当我们正在某个递归内部执行时执行 yes-pattern, 否则执行 no-pattern.
  • (?(RN)yes-pattern|no-pattern) 当我们正在递归到子表达式 N 的内部执行时执行 yes-pattern, 否则执行 no-pattern.
  • (?(R&name)yes-pattern|no-pattern) 当我们正在递归到命名子表达式 name 的内部执行时执行 yes-pattern, 否则执行 no-pattern.
  • (?(DEFINE)never-exectuted-pattern) 定义一个永不执行且不匹配任何字符的代码块: 它通常用于定义一个或多个命名子表达式, 供模式中的其他位置引用.
回溯控制动词

本库对 Perl 的回溯控制动词提供部分支持; 特别是不支持 (*MARK). 本库与 Perl 的行为细节也可能有差异, 尤其是因为 Perl 的行为文档不足, 实际表现往往有些随机. 支持的动词有:

  • (*PRUNE) 除非被回溯到, 否则无效果; 若被回溯到, 则丢弃此点之前的所有回溯信息.
  • (*SKIP) 行为与 (*PRUNE) 相同, 但假定在被搜索字符串的当前位置之前不可能出现任何匹配. 这可用于优化搜索: 跳过已确定不可能成为匹配的文本块.
  • (*THEN) 除非被回溯到, 否则无效果; 若被回溯到, 则丢弃分支组中所有后续的分支.
  • (*COMMIT) 除非被回溯到, 否则无效果; 若被回溯到, 则放弃所有后续的匹配/搜索尝试.
  • (*FAIL) 使匹配在此点无条件失败, 可用于迫使引擎回溯.
  • (*ACCEPT) 使模式在当前点被视为已匹配. 任何未闭合的子表达式都在当前点闭合.
运算符优先级

运算符的优先级顺序如下:

  1. 排序相关括号符号 [==] [::] [..]
  2. 转义字符 \
  3. 字符集合 (括号表达式) []
  4. 分组 ()
  5. 单字符 ERE 重复 * + ? {m,n}
  6. 连接
  7. 锚点 ^$
  8. 分支 |

匹配到什么

如果把正则表达式看作一个有向 (可能有环) 图, 那么在匹配输入文本时, 找到的"最佳"匹配就是对该图执行深度优先搜索找到的第一个匹配.

或者:

找到的最佳匹配是 最左匹配, 各元素按如下方式匹配;

构造

匹配到的内容

AtomA AtomB

定位 AtomA 的最佳匹配, 该匹配后面还有对 AtomB 的匹配.

Expression1 | Expression2

如果 Expresion1 可以匹配, 则返回该匹配, 否则尝试匹配 Expression2.

S{N}

匹配重复恰好 N 次的 S.

S{N,M}

匹配重复介于 N 和 M 次之间的 S, 并尽可能多地重复.

S{N,M}?

匹配重复介于 N 和 M 次之间的 S, 并尽可能少地重复.

S?, S*, S+

分别与 S{0,1}、S{0,UINT_MAX}、S{1,UINT_MAX} 相同.

S??, S*?, S+?

分别与 S{0,1}?、S{0,UINT_MAX}?、S{1,UINT_MAX}? 相同.

(?>S)

只匹配 S 的最佳匹配本身.

(?=S), (?<=S)

仅匹配 S 的最佳匹配 (只有当 S 内含捕获括号时这个区别才可见).

(?!S), (?<!S)

只考虑 S 是否存在匹配.

(?(condition)yes-pattern | no-pattern)

如果条件为真, 则只考虑 yes-pattern; 否则只考虑 no-pattern.

变体

选项 normal、ECMAScript、JavaScript 和 JScript 都是 perl 的同义词.

选项

构造正则表达式时, 多种标志 可以与 perl 选项组合; 尤其请注意, newline_alt 选项会改变语法, 而 collate、nosubs 和 icase 选项则修改大小写和区域设置敏感性的应用方式.

模式修饰符

perl 的 smix 修饰符既可以通过在正则表达式前加 (?smix-smix) 前缀来应用, 也可以用 regex 编译期标志 no_mod_m、mod_x、mod_s 和 no_mod_s 之一来应用.
