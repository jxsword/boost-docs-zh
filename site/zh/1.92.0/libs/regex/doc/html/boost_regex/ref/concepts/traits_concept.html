traits 类要求

traits 作为 basic_regex 的模板参数有两组要求: 最小接口 (属于 regex 标准化提案的一部分), 以及可选的 Boost 特有增强接口.

最小要求.

在下表中, X 表示为字符容器类型 charT; u 是 X 类型的对象; v 是 const X 类型的对象; p 是 const charT* 类型的值; I1 and I2 是输入迭代器; c 是 const charT 类型的值; s 是 X::string_type 类型的对象; cs 是 const X::string_type 类型的对象; b 是 bool 类型的值; I 是 int 类型的值; F1 and F2 是 const charT* 类型的值; 而 loc 是 X::locale_type 类型的对象.

X::char_type

charT

在类模板 basic_regex 的实现中使用的字符容器类型.

X::size_type

无符号整数类型, 能够容纳以空字符结尾的 charT 字符串的长度.

X::string_type

std::basic_string<charT> or std::vector<charT>

X::locale_type

由实现定义

一种可拷贝构造的类型, 表示 traits 类所用的区域设置.

X::char_class_type

由实现定义

一种位掩码类型, 表示特定的字符分类. 该类型的多个值可以按位或运算合并, 得到一个新的有效值.

X::length(p)

X::size_type

产生满足 p[i] == 0 的最小 i. 复杂度与 i 成线性.

v.translate(c)

X::char_type

返回一个字符, 使得对于任何被视为与 c 等价的字符 d, 都有 v.translate(c) == v.translate(d).

v.translate_nocase(c)

X::char_type

对于所有在不区分大小写进行比较时被视为与 c 等价的字符 C, 都有 v.translate_nocase(c) == v.translate_nocase(C).

v.transform(F1, F2)

X::string_type

返回迭代器范围 [F1, F2) 所指定字符序列的排序键, 使得如果字符序列 [G1, G2) 排在字符序列 [H1, H2) 之前, 则 v.transform(G1, G2) < v.transform(H1, H2).

v.transform_primary(F1, F2)

X::string_type

返回迭代器范围 [F1, F2) 所指定字符序列的排序键, 使得如果在不考虑字符大小写的情况下字符序列 [G1, G2) 排在字符序列 [H1, H2) 之前, 则 v.transform_primary(G1, G2) < v.transform_primary(H1, H2).

v.lookup_classname(F1, F2)

X::char_class_type

将迭代器范围 [F1,F2) 指定的字符序列转换为位掩码类型, 该值随后可传递给 isctype. lookup_classname 返回的值可以安全地进行按位或运算. 如果字符序列不是 X 可识别的字符类名称, 则返回 0. 返回的值应与序列中字符的大小写无关.

v.lookup_collatename(F1, F2)

X::string_type

返回表示由迭代器范围 [F1, F2) 指定的字符序列构成的排序元素的字符序列. 如果该字符序列不是有效的排序元素, 则返回空字符串.

v.isctype(c, v.lookup_classname (F1, F2))

bool

如果字符 c 是迭代器范围 [F1, F2) 所指定字符类的成员则返回 true, 否则返回 false.

v.value(c, I)

int

如果字符 c 是基数为 I 的有效数字, 则返回数字 c 在基数 I 下表示的值; 否则返回 -1. [注意: I 的值只会是 8、10 或 16. - 注释结束]

u.imbue(loc)

X::locale_type

用区域设置 loc imbue u, 返回 u 之前使用的区域设置 (如果有).

v.getloc()

X::locale_type

返回 v 当前使用的区域设置 (如果有).
附加可选要求

以下附加要求严格来说是可选的; 但是为了让 basic_regex 利用这些附加接口, 必须满足以下全部要求; basic_regex 会检测成员 boost_extensions_tag 是否存在, 并据此进行自我配置.

结果

断言 / 注释 / 前置 / 后置条件

X::boost_extensions_tag

一种未指定的类型.

存在该成员时, 本表列出的所有扩展都必须存在.

v.syntax_type(c)

regex_constants::syntax_type

返回 regex_constants::syntax_type 类型的符号值, 表示字符 c 在正则表达式文法中的含义.

v.escape_syntax_type(c)

regex_constants::escape_syntax_type

返回 regex_constants::escape_syntax_type 类型的符号值, 表示当字符 c 前面有转义字符时, c 在正则表达式文法中的含义. 前置条件: 如果 b 是被解析表达式中位于 c 之前的字符, 则: v.syntax_type(b) == syntax_escape

v.translate(c, b)

X::char_type

返回一个字符 d, 使得: 对于任何被视为与 c 等价的字符 d, 都有 v.translate(c,false)==v.translate(d,false). 同样, 对于所有在不区分大小写进行比较时被视为与 c 等价的字符 C, 都有 v.translate(c,true)==v.translate(C,true).

v.toi(I1, I2, i)

能够容纳 charT 或 int 的整数类型.

行为如下: 如果 p == q 或 *p 不是数字字符, 则返回 -1. 否则对序列 [p,q) 执行格式化数值输入并以 int 返回结果. 后置条件: p == q 或 *p 是非数字字符.

v.error_string(I)

std::string

返回错误条件 i 的人类可读错误字符串, 其中 i 是 regex_constants::error_type 类型枚举的值之一. 如果值 I 未被识别, 则返回字符串 "Unknown error" 或其本地化等价物.

v.tolower(c)

X::char_type

将 c 转换为小写, 用于 Perl 风格的 \l 和 \L 格式化操作.

v.toupper(c)

X::char_type

将 c 转换为大写, 用于 Perl 风格的 \u 和 \U 格式化操作.
