头文件

本库使用两个主要头文件: <boost/regex.hpp> 提供对主模板库的完整访问, 而 <boost/cregex.hpp> 提供对 POSIX API 函数的访问.

还有一个只包含前置声明的头文件 <boost/regex_fwd.hpp>, 用于接口依赖 basic_regex 但除此之外不需要完整定义的情形.
