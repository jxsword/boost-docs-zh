POSIX 基本正则表达式的选项

对于 POSIX 基本正则表达式, 必须总是设置以下选项中的恰好一个:

元素

标准化

设置后的效果

basic

是

指定正则表达式引擎识别的文法与 IEEE Std 1003.1-2001 (可移植操作系统接口 (POSIX), 基本定义与头文件, 第 9 节, 正则表达式) 中 POSIX 基本正则表达式 所用的文法相同 (FWD.1).

sed

否

同上.

grep

是

指定正则表达式引擎识别的文法与 IEEE Std 1003.1-2001 (可移植操作系统接口 (POSIX), Shell 与工具, 第 4 节, Utilit\ies, grep) 中 POSIX 实用工具 grep 所用的文法相同 (FWD.1).

即与 POSIX 基本语法 相同, 但换行符充当分支字符; 表达式被当作以换行符分隔的分支列表.

emacs

否

指定识别的文法是 emacs 程序所用的、POSIX 基本语法 的超集.

使用 POSIX 基本正则表达式时还可以设置以下选项:

元素

标准化

设置后的效果

icase

是

指定正则表达式与字符容器序列的匹配应不区分大小写.

nosubs

是

指定当正则表达式与字符容器序列匹配时, 不在提供的 match_results 结构中存储任何子表达式匹配.

optimize

是

指定正则表达式引擎应更加关注匹配正则表达式的速度, 而较少关注构造正则表达式对象的速度. 否则对程序输出没有可察觉的影响. 对 Boost.Regex 而言目前该选项无任何效果.

collate

是

指定形如 [a-b] 的字符范围应区分区域设置. 对 POSIX 基本正则表达式 而言, 该位默认为开, 但可以关闭它以强制仅按码点比较范围.

newline_alt

否

指定 \n 字符与分支运算符 | 效果相同, 允许将以换行符分隔的列表用作分支列表. 如果使用 grep 选项, 该位已经被设置.

no_char_classes

否

设置后不允许使用形如 [[:alnum:]] 的字符类.

no_escape_in_lists

否

设置后转义字符在列表内成为普通字符, 因此 [\b] 会匹配 '\' 或 'b'. 对 POSIX 基本正则表达式 而言, 该位默认为开, 但可以关闭它以强制在列表内识别转义.

no_intervals

否

设置后不允许使用 a{2,3} 这类有界重复.

bk_plus_qm

否

设置后, \? 作为零或一次重复运算符, 而 \+ 作为一次或多次重复运算符.

bk_vbar

否

设置后, \| 作为分支运算符.

no_except

否

防止 basic_regex 在遇到无效表达式时抛出异常.

save_subexpression_location

否

设置后, 各子表达式在原始正则表达式字符串中的位置可以通过 subexpression() (basic_regex 的成员函数) 访问.
