从 MFC 字符串创建正则表达式

提供了以下辅助函数, 用于从 MFC/ATL 字符串类型创建正则表达式:

template <class charT>
basic_regex<charT>
   make_regex(const ATL::CSimpleStringT<charT>& s,
            ::boost::regex_constants::syntax_option_type f = boost::regex_constants::normal);

效果: 返回 basic_regex<charT>(s.GetString(), s.GetString() + s.GetLength(), f);
