始终支持的字符类

Boost.Regex 始终支持以下字符类名称:

名称

POSIX 标准名称

说明

alnum

是

任意字母数字字符.

alpha

是

任意字母字符.

blank

是

任意非行分隔符的空白字符.

cntrl

是

任意控制字符.

d

否

任意十进制数字

digit

是

任意十进制数字.

graph

是

任意图形字符.

l

否

任意小写字符.

lower

是

任意小写字符.

print

是

任意可打印字符.

punct

是

任意标点字符.

s

否

任意空白字符.

space

是

任意空白字符.

unicode

否

码点值大于 255 的任意扩展字符.

u

否

任意大写字符.

upper

是

任意大写字符.

w

否

任意单词字符 (字母数字字符加下划线).

word

否

任意单词字符 (字母数字字符加下划线).

xdigit

是

任意十六进制数字字符.
