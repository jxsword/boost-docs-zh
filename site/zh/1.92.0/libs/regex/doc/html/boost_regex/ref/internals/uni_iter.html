Unicode 迭代器

概要 
#include <boost/regex/pending/unicode_iterator.hpp>
template <class BaseIterator, class U16Type = ::boost::uint16_t>
class u32_to_u16_iterator;

template <class BaseIterator, class U32Type = ::boost::uint32_t>
class u16_to_u32_iterator;

template <class BaseIterator, class U8Type = ::boost::uint8_t>
class u32_to_u8_iterator;

template <class BaseIterator, class U32Type = ::boost::uint32_t>
class u8_to_u32_iterator;

template <class BaseIterator>
class utf16_output_iterator;

template <class BaseIterator>
class utf8_output_iterator;
说明

该头文件包含一组迭代器适配器, 使一种编码的字符序列"看起来像"另一种编码的只读字符序列.

template <class BaseIterator, class U16Type = ::boost::uint16_t>
class u32_to_u16_iterator
{
   u32_to_u16_iterator();
   u32_to_u16_iterator(BaseIterator start_position);

   // Other standard BidirectionalIterator members here...
};

一种双向迭代器适配器, 使底层的 UTF32 字符序列看起来像一个 (只读的) UTF16 字符序列. UTF16 字符按平台本机字节序编码.

template <class BaseIterator, class U32Type = ::boost::uint32_t>
class u16_to_u32_iterator
{
   u16_to_u32_iterator();
   u16_to_u32_iterator(BaseIterator start_position);
   u16_to_u32_iterator(BaseIterator start_position, BaseIterator start_range, BaseIterator end_range);

   // Other standard BidirectionalIterator members here...
};

一种双向迭代器适配器, 使底层的 UTF16 字符序列 (按平台本机字节序) 看起来像一个 (只读的) UTF32 字符序列.

该类的三参构造函数接受底层序列的起点和终点, 以及开始迭代的位置. 该构造函数会验证底层序列的端点具有有效的编码: 这可防止因底层范围端点处的无效 UTF16 码序列而意外地递增/递减越过底层序列的结尾.
