Sed 格式字符串语法

Sed 风格的格式字符串把除以下字符外的所有字符都视为字面量:

字符

description

&

字符 & 在输出流中被替换为正则表达式匹配的全部内容. 使用 \& 输出字面 '&' 字符.

\

指定一个转义序列.

转义字符后跟任意字符 x, 会输出该字符, 除非 x 是下面所示的转义序列之一.

转义

含义

\a

输出响铃字符: '\a'.

\e

输出 ANSI 转义字符 (码点 27).

\f

输出换页字符: '\f'

\n

输出换行字符: '\n'.

\r

输出回车字符: '\r'.

\t

输出制表符: '\t'.

\v

输出垂直制表符: '\v'.

\xDD

输出十六进制码点为 0xDD 的字符

\x{DDDD}

输出十六进制码点为 0xDDDDD 的字符

\cX

输出 ANSI 转义序列 "escape-X".

\D

如果 D 是 1-9 范围内的十进制数字, 则输出与子表达式 D 匹配的文本.
