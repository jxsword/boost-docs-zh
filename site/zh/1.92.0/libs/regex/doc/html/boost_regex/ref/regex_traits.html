regex_traits 

namespace boost{

template <class charT, class implementationT = sensible_default_choice>
struct regex_traits : public implementationT
{
   regex_traits() : implementationT() {}
};

template <class charT>
struct c_regex_traits;

template <class charT>
class cpp_regex_traits;

template <class charT>
class w32_regex_traits;

} // namespace boost
说明

类 regex_traits 只是对实际实现类的一层薄封装, 后者可能是以下之一:

  • c_regex_traits: 该类已弃用; 它封装 C 区域设置, 在平台不是 Win32 且 C++ locale 不可用时用作默认实现.
  • cpp_regex_traits: 非 Win32 平台的默认 traits 类, 允许用 std::locale 实例 imbue regex 类.
  • w32_regex_traits: Win32 平台上的默认 traits 类实现, 允许用 LCID imbue regex 类.

默认行为可以通过在 boost/regex/user.hpp 中定义以下配置宏之一来改变

  • BOOST_REGEX_USE_C_LOCALE: 使 c_regex_traits 成为默认.
  • BOOST_REGEX_USE_CPP_LOCALE: 使 cpp_regex_traits 成为默认.

所有这些 traits 类都满足 traits 类要求.
