Boost.Regex 与 MFC 字符串简介

头文件 <boost/regex/mfc.hpp> 为 MFC 字符串类型提供 Boost.Regex 支持: 注意, 该支持需要 Visual Studio .NET (Visual C++ 7) 或更高版本, 其中所有 MFC 和 ATL 字符串类型都基于 CSimpleStringT 类模板.

在以下文档中, 凡是看到 CSimpleStringT<charT> 的地方, 都可以替换为以下任何 MFC/ATL 类型 (它们都继承自 CSimpleStringT):

CString
CStringA
CStringW
CAtlString
CAtlStringA
CAtlStringW
CStringT<charT,traits>
CFixedStringT<charT,N>
CSimpleStringT<charT>
