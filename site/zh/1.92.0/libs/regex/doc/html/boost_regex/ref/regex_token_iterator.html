regex_token_iterator

模板类 regex_token_iterator 是一种迭代器适配器; 换句话说, 它通过枚举某个序列中正则表达式的所有出现, 并为找到的每个匹配呈现一个或多个字符序列, 从而表示现有迭代器序列的新视图. 迭代器枚举的每个位置都是一个 sub_match 对象, 表示正则表达式中某个特定子表达式的匹配内容. 当类 regex_token_iterator 用于枚举索引为 -1 的单个子表达式时, 迭代器执行字段拆分 (field splitting): 即为字符容器序列中不匹配指定正则表达式的每个部分枚举一个字符序列.

template <class BidirectionalIterator,
         class charT = iterator_traits<BidirectionalIterator>::value_type,
         class traits = regex_traits<charT> >
class regex_token_iterator
{
public:
   typedef          basic_regex<charT, traits>                              regex_type;
   typedef          sub_match<BidirectionalIterator>                        value_type;
   typedef typename iterator_traits<BidirectionalIterator>::difference_type difference_type;
   typedef          const value_type*                                       pointer;
   typedef          const value_type&                                       reference;
   typedef          std::forward_iterator_tag                               iterator_category;

   regex_token_iterator();
   regex_token_iterator(BidirectionalIterator a,
                        BidirectionalIterator b,
                        const regex_type& re,
                        int submatch = 0,
                        match_flag_type m = match_default);
   regex_token_iterator(BidirectionalIterator a,
                        BidirectionalIterator b,
                        const regex_type& re,
                        const std::vector<int>& submatches,
                        match_flag_type m = match_default);
   template <std::size_t N>
   regex_token_iterator(BidirectionalIterator a,
                        BidirectionalIterator b,
                        const regex_type& re,
                        const int (&submatches)[N],
                        match_flag_type m = match_default);
   regex_token_iterator(const regex_token_iterator&);
   regex_token_iterator& operator=(const regex_token_iterator&);
   bool operator==(const regex_token_iterator&)const;
   bool operator!=(const regex_token_iterator&)const;
   const value_type& operator*()const;
   const value_type* operator->()const;
   regex_token_iterator& operator++();
   regex_token_iterator operator++(int);
};

说明 
regex_token_iterator();

效果: 构造一个序列末尾迭代器.

regex_token_iterator(BidirectionalIterator a,
                     BidirectionalIterator b,
                     const regex_type& re,
                     int submatch = 0,
                     match_flag_type m = match_default);

前置条件: !re.empty(). 对象 re 必须在由它构造的迭代器的生命期内存在.

效果: 构造一个 regex_token_iterator, 它为在序列 [a,b) 内找到的表达式 re 的每个正则表达式匹配枚举一个字符串, 使用匹配标志 m (见 match_flag_type). 枚举的字符串是每个找到的匹配的子表达式 submatch; 如果 submatch 为 -1, 则枚举所有未匹配表达式 re 的文本序列 (即执行字段拆分).

抛出: std::runtime_error, 当将表达式与 N 个字符的字符串进行匹配的复杂度开始超过 O(N2), 或者匹配表达式时程序耗尽栈空间 (当 Boost.Regex 以递归模式配置时), 或者匹配器耗尽其允许的内存分配 (当 Boost.Regex 以非递归模式配置时).

regex_token_iterator(BidirectionalIterator a,
                     BidirectionalIterator b,
                     const regex_type& re,
                     const std::vector<int>& submatches,
                     match_flag_type m = match_default);

前置条件: submatches.size() && !re.empty(). 对象 re 必须在由它构造的迭代器的生命期内存在.

效果: 构造一个 regex_token_iterator, 它枚举 submatches.size() 个字符串, 对应于在序列 [a,b) 内找到的表达式 re 的每个正则表达式匹配, 使用匹配标志 m (见 match_flag_type). 对于每个找到的匹配, 会为 submatches 向量中包含的每个子表达式索引枚举一个字符串; 如果 submatches[0] 为 -1, 则为每个匹配枚举的第一个字符串是从上一个匹配的结尾到当前匹配起点的全部文本; 此外, 当找不到更多匹配时还会枚举一个额外的字符串: 从找到的最后一个匹配的结尾到底层序列的结尾.

抛出: std::runtime_error, 当将表达式与 N 个字符的字符串进行匹配的复杂度开始超过 O(N2), 或者匹配表达式时程序耗尽栈空间 (当 Boost.Regex 以递归模式配置时), 或者匹配器耗尽其允许的内存分配 (当 Boost.Regex 以非递归模式配置时).

template <std::size_t N>
regex_token_iterator(BidirectionalIterator a,
                     BidirectionalIterator b,
                     const regex_type& re,
                     const int (&submatches)[R],
                     match_flag_type m = match_default);

前置条件: !re.empty(). 对象 re 必须在由它构造的迭代器的生命期内存在.

效果: 构造一个 regex_token_iterator, 它为在序列 [a,b) 内找到的表达式 re 的每个正则表达式匹配枚举 R 个字符串, 使用匹配标志 m (见 match_flag_type). 对于每个找到的匹配, 会为 submatches 数组中包含的每个子表达式索引枚举一个字符串; 如果 submatches[0] 为 -1, 则为每个匹配枚举的第一个字符串是从上一个匹配的结尾到当前匹配起点的全部文本; 此外, 当找不到更多匹配时还会枚举一个额外的字符串: 从找到的最后一个匹配的结尾到底层序列的结尾.

抛出: std::runtime_error, 当将表达式与 N 个字符的字符串进行匹配的复杂度开始超过 O(N2), 或者匹配表达式时程序耗尽栈空间 (当 Boost.Regex 以递归模式配置时), 或者匹配器耗尽其允许的内存分配 (当 Boost.Regex 以非递归模式配置时).

效果: 如果 *this 与 that 处于同一位置则返回 true.

效果: 返回 !(*this == that).

效果: 返回当前正在枚举的字符序列.

效果: 移动到下一个要枚举的字符序列.

返回: *this.

regex_token_iterator& operator++(int);

效果: 构造 *this 的一个副本 result, 然后调用 ++(*this).

返回: result.

示例

下面的示例接受一个字符串并把它拆分为一系列记号:

#include <iostream>
#include <boost/regex.hpp>

using namespace std;

int main(int argc)
{
   string s;
   do{
      if(argc == 1)
      {
         cout << "Enter text to split (or \"quit\" to exit): ";
         getline(cin, s);
         if(s == "quit") break;
      }
      else
         s = "This is a string of tokens";

      boost::regex re("\\s+");
      boost::sregex_token_iterator i(s.begin(), s.end(), re, -1);
      boost::sregex_token_iterator j;

      unsigned count = 0;
      while(i != j)
      {
         cout << *i++ << endl;
         count++;
      }
      cout << "There were " << count << " tokens found." << endl;

   }while(argc == 1);
   return 0;
}

下面的示例接受一个 html 文件, 并输出所有链接文件的列表:

#include <fstream>
#include <iostream>
#include <iterator>
#include <boost/regex.hpp>

boost::regex e("<\\s*A\\s+[^>]*href\\s*=\\s*\"([^\"]*)\"",
               boost::regex::normal | boost::regbase::icase);

void load_file(std::string& s, std::istream& is)
{
   s.erase();
   //
   // attempt to grow string buffer to match file size,
   // this doesn't always work...
   s.reserve(is.rdbuf()->in_avail());
   char c;
   while(is.get(c))
   {
      // use logarithmic growth strategy, in case
      // in_avail (above) returned zero:
      if(s.capacity() == s.size())
         s.reserve(s.capacity() * 3);
      s.append(1, c);
   }
}

int main(int argc, char** argv)
{
   std::string s;
   int i;
   for(i = 1; i < argc; ++i)
   {
      std::cout << "Findings URL's in " << argv[i] << ":" << std::endl;
      s.erase();
      std::ifstream is(argv[i]);
      load_file(s, is);
      boost::sregex_token_iterator i(s.begin(), s.end(), e, 1);
      boost::sregex_token_iterator j;
      while(i != j)
      {
         std::cout << *i++ << std::endl;
      }
   }
   //
   // alternative method:
   // test the array-literal constructor, and split out the whole
   // match as well as $1....
   //
   for(i = 1; i < argc; ++i)
   {
      std::cout << "Findings URL's in " << argv[i] << ":" << std::endl;
      s.erase();
      std::ifstream is(argv[i]);
      load_file(s, is);
      const int subs[] = {1, 0,};
      boost::sregex_token_iterator i(s.begin(), s.end(), e, subs);
      boost::sregex_token_iterator j;
      while(i != j)
      {
         std::cout << *i++ << std::endl;
      }
   }

   return 0;
}
