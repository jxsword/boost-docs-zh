搜索与替换格式字符串语法

Sed 格式字符串语法
Perl 格式字符串语法
Boost-Extended 格式字符串语法

格式字符串由算法 regex_replace 和 match_results<>::format 使用, 用于将一个字符串转换为另一个字符串.

格式字符串有三种: Sed、Perl 和 Boost-Extended.

或者, 当把标志 format_literal 传递给这些函数之一时, 格式字符串被视为字符串字面量, 并原样复制到输出.
