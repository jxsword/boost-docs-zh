本节介绍本库使用的正则表达式语法; 这是一份程序员指南, 实际呈现给程序用户的语法将取决于表达式编译时使用的标志.

根据构造正则表达式对象的方式不同, 有三种主要语法选项可用:

  • Perl (这是默认行为).
  • POSIX 扩展 (包括 egrep 和 awk 变体).
  • POSIX 基本 (包括 grep 和 emacs 变体).

你也可以构造一个把每个字符都当作字面量的正则表达式, 不过那严格来说算不上一种"语法"!
