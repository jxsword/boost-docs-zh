区域设置与 traits 类选择

以下宏 (见 user.hpp) 控制 Boost.Regex 与用户区域设置的交互方式:

宏

description

BOOST_REGEX_USE_C_LOCALE

强制 Boost.Regex 在其 traits 类支持中使用全局 C 区域设置: 现已被弃用, 改用 C++ locale.

BOOST_REGEX_USE_CPP_LOCALE

强制 Boost.Regex 在其默认 traits 类中使用 std::locale; 正则表达式随后可通过 imbue 使用实例专属的区域设置. 这是非 Windows 平台上的默认行为.

BOOST_REGEX_NO_W32

告知 Boost.Regex 不使用任何 Win32 API (即使可用) (除非设置了 BOOST_REGEX_USE_C_LOCALE, 否则隐含 BOOST_REGEX_USE_CPP_LOCALE).
