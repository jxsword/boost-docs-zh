Boost.Regex 的算法和迭代器都基于迭代器, 并为算法提供了便捷重载, 在内部把标准库字符串类型转换为迭代器对. 如果你想搜索一种非标准字符串类型, 窍门是把它转换为迭代器对: 到目前为止, 我还没遇到过不能这样处理的字符串类型, 即使它们官方上并非基于迭代器. 任何提供内部缓冲区及其长度访问的字符串类型, 肯定可以转换为一对指针 (可用作迭代器).

有些非标准字符串类型非常普遍, 因此已为它们提供了封装: 目前包括 ICU 和 MFC 字符串类类型.
