Unicode 正则表达式类型

头文件 <boost/regex/icu.hpp> 提供了一个处理 UTF-32 字符的正则表达式 traits 类:

class icu_regex_traits;

以及基于它的正则表达式类型:

typedef basic_regex<UChar32,icu_regex_traits> u32regex;

类型 u32regex 是用于所有 Unicode 正则表达式的正则表达式类型; 它在内部使用 UTF-32 码点, 但可以从 UTF-8、UTF-16 或 UTF-32 编码的字符串创建, 并用于搜索这些字符串.

u32regex 的构造函数与 assign 成员函数要求 UTF-32 编码的字符串, 但有一系列名为 make_u32regex 的重载算法, 允许从 UTF-8、UTF-16 或 UTF-32 编码的字符串创建正则表达式:

template <class InputIterator>
u32regex make_u32regex(InputIterator i,
                       InputIterator j,
                       boost::regex_constants::syntax_option_type opt);

效果: 从迭代器序列 [i,j) 创建正则表达式对象. 序列的字符编码由 sizeof(*i) 决定: 1 表示 UTF-8, 2 表示 UTF-16, 4 表示 UTF-32.

u32regex make_u32regex(const char* p,
                       boost::regex_constants::syntax_option_type opt
                           = boost::regex_constants::perl);

效果: 从以空字符结尾的 UTF-8 字符序列 p 创建正则表达式对象.

u32regex make_u32regex(const unsigned char* p,
                       boost::regex_constants::syntax_option_type opt
                           = boost::regex_constants::perl);

效果: 从以空字符结尾的 UTF-8 字符序列 p 创建正则表达式对象.

u32regex make_u32regex(const wchar_t* p,
                       boost::regex_constants::syntax_option_type opt
                           = boost::regex_constants::perl);

效果: 从以空字符结尾的字符序列 p 创建正则表达式对象. 序列的字符编码由 sizeof(wchar_t) 决定: 1 表示 UTF-8, 2 表示 UTF-16, 4 表示 UTF-32.

u32regex make_u32regex(const UChar* p,
                       boost::regex_constants::syntax_option_type opt
                           = boost::regex_constants::perl);

效果: 从以空字符结尾的 UTF-16 字符序列 p 创建正则表达式对象.

template<class C, class T, class A>
u32regex make_u32regex(const std::basic_string<C, T, A>& s,
                       boost::regex_constants::syntax_option_type opt
                           = boost::regex_constants::perl);

效果: 从字符串 s 创建正则表达式对象. 字符串的字符编码由 sizeof(C) 决定: 1 表示 UTF-8, 2 表示 UTF-16, 4 表示 UTF-32.

u32regex make_u32regex(const UnicodeString& s,
                       boost::regex_constants::syntax_option_type opt
                           = boost::regex_constants::perl);

效果: 从 UTF-16 编码的字符串 s 创建正则表达式对象.
