测试与示例程序

测试程序

regress:

一个回归测试程序, 对匹配/搜索算法进行全面演练. 这个程序的存在可以保证库的行为与宣称一致 - 至少就所测试的内容而言; 如果有人发现有任何未被测试之处, 我很乐意听取反馈.

文件:

  • main.cpp
  • basic_tests.cpp
  • test_alt.cpp
  • test_anchors.cpp
  • test_asserts.cpp
  • test_backrefs.cpp
  • test_deprecated.cpp
  • test_emacs.cpp
  • test_escapes.cpp
  • test_grep.cpp
  • test_icu.cpp
  • test_locale.cpp
  • test_mfc.cpp
  • test_non_greedy_repeats.cpp
  • test_operators.cpp
  • test_overloads.cpp
  • test_perl_ex.cpp
  • test_replace.cpp
  • test_sets.cpp
  • test_simple_repeats.cpp
  • test_tricky_cases.cpp
  • test_unicode.cpp

bad_expression_test:

验证"坏"的正则表达式不会导致匹配器陷入无限循环, 而是抛出异常.

文件: bad_expression_test.cpp.

recursion_test:

验证匹配器不会耗尽栈空间 (无论表达式是什么).

文件: recursion_test.cpp.

concepts:

验证该库满足所有已文档化的概念 (仅编译测试).

文件: concept_check.cpp.

captures_test:

针对捕获 (captures) 的测试代码.

文件: captures_test.cpp.

示例程序

grep

一个简单的 grep 实现, 以 -h 命令行选项运行可查看其用法.

文件: grep.cpp

timer.exe

一个简单的交互式表达式匹配程序, 所有匹配的结果都会计时, 使程序员能够在性能关键之处优化其正则表达式.

文件: regex_timer.cpp.

代码片段

这些片段示例包含文档中使用的代码示例:

captures_example.cpp: 演示捕获 (captures) 的用法.

regex_match_example.cpp: 基于 ftp 的 regex_match 示例.

regex_merge_example.cpp: regex_merge 示例: 将 C++ 文件转换为带语法高亮的 HTML.

regex_replace_example.cpp: regex_replace 示例: 将 C++ 文件转换为带语法高亮的 HTML

regex_search_example.cpp: regex_search 示例: 在 cpp 文件中搜索类定义.

regex_token_iterator_eg_1.cpp: 将一个字符串拆分为一系列记号 (token).

regex_token_iterator_eg_2.cpp: 枚举 HTML 文件中的链接 URL.
