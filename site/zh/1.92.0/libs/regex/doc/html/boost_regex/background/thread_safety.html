线程安全

Boost.Regex 库在 Boost 线程安全时也是线程安全的: 你可以通过检查 BOOST_HAS_THREADS 是否定义来验证 Boost 是否处于线程安全模式: 当编译器开启线程支持时, 该宏由 config 系统自动设置.

类 basic_regex 及其 typedef regex 和 wregex 是线程安全的, 即已编译的正则表达式可以安全地在线程间共享. 匹配算法 regex_match、regex_search 和 regex_replace 都是可重入且线程安全的. 类 match_results 现在是线程安全的, 即匹配结果可以安全地从一个线程复制到另一个线程 (例如, 一个线程可以查找匹配并将 match_results 实例推入队列, 而另一个线程从队列另一端取出), 否则请为每个线程使用单独的 match_results 实例.

POSIX API 函数 都是可重入且线程安全的, 用 regcomp 编译的正则表达式也可以在线程间共享.

最后注意, 更改全局区域设置会使所有已编译的正则表达式失效, 因此在一个线程中调用 set_locale 而另一个线程使用正则表达式时, 会产生不可预知的结果.

还要求在 main() 开始之前只有一个线程在执行.
