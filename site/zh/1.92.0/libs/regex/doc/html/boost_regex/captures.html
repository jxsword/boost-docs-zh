理解标记子表达式与捕获

捕获 (captures) 是标记子表达式在正则表达式被匹配时"捕获"的迭代器范围. 如果某个标记子表达式被匹配多次, 则可以产生多个捕获. 本文档解释 Boost.Regex 中捕获与标记子表达式是如何表示和访问的.

标记子表达式

每当 Perl 正则表达式包含一个括号分组 () 时, 就会多产生一个字段, 称为标记子表达式 (marked sub-expression); 例如表达式:

(\w+)\W+(\w+)

它有两个标记子表达式 (分别称为 $1 和 $2); 此外, 完整匹配称为 $&, 第一次匹配之前的所有内容称为 $`, 匹配之后的所有内容称为 $'. 因此, 如果在 "@abc def--" 中搜索上述表达式, 我们得到:

在 Boost.Regex 中, 所有这些都可以通过 match_results 类访问, 该类在调用某个正则表达式匹配算法 ( regex_search、regex_match 或 regex_iterator ) 时被填充. 因此给定:

boost::match_results<IteratorType> m;

在 Boost.Regex 中, 每个子表达式的匹配由一个 sub_match 对象表示; 它基本上只是一对迭代器, 表示子表达式匹配的起止位置, 但还提供了一些附加运算符, 使 sub_match 类型的对象的行为很像一个 std::basic_string: 例如, 它们可以隐式转换为 basic_string, 可以与字符串比较、加到字符串上, 或输出到输出流.

未匹配的子表达式

找到一个正则表达式匹配时, 并不需要所有标记子表达式都参与了匹配; 例如表达式:

(abc)|(def)

它可以匹配 $1 或 $2, 但绝不会同时匹配两者. 在 Boost.Regex 中, 你可以通过访问 sub_match::matched 数据成员来确定哪些子表达式匹配了.

重复捕获

当标记子表达式被重复时, 该子表达式会被"捕获"多次; 但通常只有最后一次捕获可用. 例如, 如果

(?:(\w+)\W+)+

与下式匹配

one fine day

那么 $1 将包含字符串 "day", 而之前所有的捕获都会被遗忘.

不过, Boost.Regex 有一项实验性特性, 允许保留所有捕获信息 - 可以通过 match_results::captures 成员函数或 sub_match::captures 成员函数访问. 这些函数返回一个容器, 其中包含正则表达式匹配期间获得的所有捕获组成的序列. 下面的示例程序展示了如何使用这一信息:

#include <boost/regex.hpp>
#include <iostream>

void print_captures(const std::string& regx, const std::string& text)
{
   boost::regex e(regx);
   boost::smatch what;
   std::cout << "Expression:  \"" << regx << "\"\n";
   std::cout << "Text:        \"" << text << "\"\n";
   if(boost::regex_match(text, what, e, boost::match_extra))
   {
      unsigned i, j;
      std::cout << "** Match found **\n   Sub-Expressions:\n";
      for(i = 0; i < what.size(); ++i)
         std::cout << "      $" << i << " = \"" << what[i] << "\"\n";
      std::cout << "   Captures:\n";
      for(i = 0; i < what.size(); ++i)
      {
         std::cout << "      $" << i << " = {";
         for(j = 0; j < what.captures(i).size(); ++j)
         {
            if(j)
               std::cout << ", ";
            else
               std::cout << " ";
            std::cout << "\"" << what.captures(i)[j] << "\"";
         }
         std::cout << " }\n";
      }
   }
   else
   {
      std::cout << "** No Match found **\n";
   }
}

int main(int , char* [])
{
   print_captures("(([[:lower:]]+)|([[:upper:]]+))+", "aBBcccDDDDDeeeeeeee");
   print_captures("(.*)bar|(.*)bah", "abcbar");
   print_captures("(.*)bar|(.*)bah", "abcbah");
   print_captures("^(?:(\\w+)|(?>\\W+))*$",
      "now is the time for all good men to come to the aid of the party");
   return 0;
}

遗憾的是, 启用该特性会影响性能 (即使你不使用它), 而如果使用它则影响更大; 因此要使用该特性, 你需要:

  • 为所有包含库源代码的翻译单元定义 BOOST_REGEX_MATCH_EXTRA (最佳做法是在 boost/regex/user.hpp 中取消该定义的注释, 然后重新构建所有内容.
  • 向实际需要捕获信息的特定算法传递 match_extra 标志 (regex_search、regex_match 或 regex_iterator).
