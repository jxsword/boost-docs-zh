BOOST_REGEX_BLOCKSIZE

Boost.Regex 使用较大的内存块作为状态机的栈; 块越大, 发生的分配次数越少. 默认值为 4096 字节, 足以匹配绝大多数正则表达式而无需进一步分配; 不过, 你可以根据平台特性选择更小或更大的值.

BOOST_REGEX_MAX_BLOCKS

告知 Boost.Regex 允许使用多少个大小为 BOOST_REGEX_BLOCKSIZE 的块. 如果超过该值, Boost.Regex 将停止尝试查找匹配并抛出 std::runtime_error. 默认值为 1024; 如果你大幅修改 BOOST_REGEX_BLOCKSIZE, 别忘了相应调整该值.

BOOST_REGEX_MAX_CACHE_BLOCKS

告知 Boost.Regex 在其内部缓存中存储多少个内存块 - 内存块从该缓存获取, 而不是调用 ::operator new. 一般而言, 这比每次需要内存块时都调用 ::operator new 快一个数量级左右, 但缺点是 Boost.Regex 最终可能缓存一大块内存 (默认最多 16 个块, 每块大小为 BOOST_REGEX_BLOCKSIZE). 如果内存紧张, 可尝试将其定义为 0 (禁用所有缓存); 如果那样太慢, 则值 1 或 2 可能就足够了. 另一方面, 在大型多处理器、多线程系统上, 你可能需要更高的值.
