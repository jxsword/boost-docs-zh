主要的 Perl 正则表达式教程可在这里找到, 主要特性的简短总结在这里.

关于正则表达式的主要著作是 O'Reilly 出版的 Mastering Regular Expressions.

Boost.Regex 构成了 C++ 库扩展技术报告 中正则表达式一章的基础.

Open Unix 规范 包含大量有用的材料, 包括 POSIX 正则表达式语法.

Pattern Matching Pointers 网站是任何对模式匹配感兴趣的人都"必访"的资源.

Glimpse 和 Agrep 使用简化的正则表达式语法来实现更快的搜索速度.

Udi Manber 和 Ricardo Baeza-Yates 的个人网站上都有一些有用的模式匹配论文可供查阅.
