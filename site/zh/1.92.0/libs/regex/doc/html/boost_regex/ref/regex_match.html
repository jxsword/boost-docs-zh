regex_match 

#include <boost/regex.hpp>

算法 regex_match 判断给定的正则表达式是否匹配由一对双向迭代器表示的字符序列的全部; 该算法定义如下, 此函数的主要用途是数据输入验证.

重要

注意, 只有当表达式匹配输入序列的全部时结果才为 true. 如果你想在序列的某处搜索表达式, 请用 regex_search. 如果你想匹配字符串的前缀, 请使用 regex_search 并设置 match_continuous 标志.

说明 
template <class BidirectionalIterator, class Allocator, class charT, class traits>
bool regex_match(BidirectionalIterator first, BidirectionalIterator last,
                 match_results<BidirectionalIterator, Allocator>& m,
                 const basic_regex <charT, traits>& e,
                 match_flag_type flags = match_default);

要求: 类型 BidirectionalIterator 符合双向迭代器要求 (24.1.4).

效果: 判断正则表达式 e 与全部字符序列 [first, last) 之间是否存在完全匹配; 参数 flags (见 match_flag_type) 用于控制表达式与字符序列的匹配方式. 如果存在这样的匹配则返回 true, 否则返回 false.

抛出: std::runtime_error, 当将表达式与 N 个字符的字符串进行匹配的复杂度开始超过 O(N2), 或者匹配表达式时程序耗尽栈空间 (当 Boost.Regex 以递归模式配置时), 或者匹配器耗尽其允许的内存分配 (当 Boost.Regex 以非递归模式配置时).

后置条件: 如果函数返回 false, 则对参数 m 的影响未定义; 否则对参数 m 的影响在表中给出:

找到完整匹配时为 true, 部分匹配时为 false (因设置 match_partial 标志而找到).

m[n].first

对于所有整数 n < m.size(), 为与子表达式 n 匹配的序列的起点; 或者, 如果子表达式 n 未参与匹配, 则为 last.

m[n].second

对于所有整数 n < m.size(), 为与子表达式 n 匹配的序列的结尾; 或者, 如果子表达式 n 未参与匹配, 则为 last.

m[n].matched

对于所有整数 n < m.size(), 子表达式 n 参与了匹配则为 true, 否则为 false.

bool regex_match(BidirectionalIterator first, BidirectionalIterator last,
               const basic_regex <charT, traits>& e,

效果: 行为"就像"构造一个 match_results<BidirectionalIterator> what 实例, 然后返回 regex_match(first, last, what, e, flags) 的结果.

示例

下面的示例处理一个 ftp 响应:

#include <stdlib.h>
#include <boost/regex.hpp>
#include <string>
#include <iostream>

using namespace boost;

regex expression("([0-9]+)(\\-| |$)(.*)");

// process_ftp: 
// on success returns the ftp response code, and fills 
// msg with the ftp response message. 
int process_ftp(const char* response, std::string* msg)
{
   cmatch what;
   if(regex_match(response, what, expression))
   {
      // what[0] contains the whole string 
      // what[1] contains the response code 
      // what[2] contains the separator character 
      // what[3] contains the text message. 
      if(msg)
         msg->assign(what[3].first, what[3].second);
      return std::atoi(what[1].first);
   }
   // failure did not match 
   if(msg)
      msg->erase();
   return -1;
}
