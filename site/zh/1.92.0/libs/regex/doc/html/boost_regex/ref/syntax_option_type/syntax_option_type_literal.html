字面字符串的选项

要把表达式解释为字面字符串, 必须总是设置以下内容:

元素

标准化

设置后的效果

literal

是

将字符串视为字面量 (无特殊字符).

以下选项还可以与 literal 标志组合:

元素

标准化

设置后的效果

icase

是

指定正则表达式与字符容器序列的匹配应不区分大小写.

optimize

是

指定正则表达式引擎应更加关注匹配正则表达式的速度, 而较少关注构造正则表达式对象的速度. 否则对程序输出没有可察觉的影响. 对 Boost.Regex 而言目前该选项无任何效果.
