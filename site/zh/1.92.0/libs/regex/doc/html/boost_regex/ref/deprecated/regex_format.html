regex_format (已弃用)

算法 regex_format 已弃用; 新代码应改用 match_results<>::format. 现有代码仍可继续编译; 以下文档取自 Boost.Regex 的旧版本, 且不会再更新:

算法 regex_format 
#include <boost/regex.hpp>

算法 regex_format 接受一次匹配的结果, 并根据格式字符串创建新字符串; regex_format 可用于搜索与替换操作:

template <class OutputIterator, class iterator, class Allocator, class Formatter>
OutputIterator regex_format(OutputIterator out,
                           const match_results<iterator, Allocator>& m,
                           Formatter fmt,
                           match_flag_type flags = 0);

该库还定义了 regex_format 的以下便捷变体, 它直接以字符串形式返回结果, 而不是输出到迭代器.

注释

根据编译器的能力, 这个版本可能不可用, 或仅以更受限的形式提供

template <class iterator, class Allocator, class Formatter>
std::basic_string<charT> regex_format
                                 (const match_results<iterator, Allocator>& m,
                                 Formatter fmt,
                                 match_flag_type flags = 0);

主版本函数的参数按如下方式传递:

参数

说明

OutputIterator out

一种输出迭代器类型, 输出字符串会发送到该迭代器. 通常这会是 std::ostream_iterator.

const match_results<iterator, Allocator>& m

从上述某个匹配算法获得的 match_results 实例, 表示匹配到的内容.

Formatter fmt

要么是确定匹配如何转换为新字符串的格式字符串, 要么是根据 m 计算新字符串的函子 (functor) - 见 match_results<>::format.

unsigned flags

可选标志, 描述格式字符串应如何被解释.

格式标志在 match_flag_type 下有所描述.

格式字符串语法 (及可用选项) 在 格式字符串 下有更完整的描述.
