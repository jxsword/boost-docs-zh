basic_regex

概要 
#include <boost/regex.hpp>

模板类 basic_regex 封装了正则表达式的解析与编译. 该类接受两个模板参数:

  • charT: 确定字符类型, 即 char 或 wchar_t; 见 charT concept.
  • traits: 确定字符类型的行为, 例如识别哪些字符类名称. 提供了默认 traits 类: regex_traits<charT>. 另见 traits concept.

为便于使用, 有两个 typedef 定义了两个标准 basic_regex 实例; 除非你想使用自定义 traits 类或非标准字符类型 (例如见 unicode 支持), 否则你不需要使用这些以外的任何东西:

namespace boost{

template <class charT, class traits = regex_traits<charT>  >
class basic_regex;

typedef basic_regex<char>      regex;
typedef basic_regex<wchar_t>   wregex;

}

basic_regex 的定义如下: 它非常贴近类 basic_string 建模, 并满足 charT 常量容器的要求.

   static const regex_constants:: syntax_option_type collate

                                                = regex_constants::newline_alt;
   static const regex_constants:: syntax_option_type no_except
                                                = regex_constants::newline_alt;

   // construct/copy/destroy:
   explicit basic_regex ();
   explicit basic_regex(const  charT* p, flag_type f = regex_constants::normal);
   basic_regex(const charT* p1, const  charT* p2,

   basic_regex(const charT* p, size_type len, flag_type  f);
   basic_regex(const basic_regex&);

               flag_type f = regex_constants::normal);

   ~basic_regex();
   basic_regex& operator=(const basic_regex&);
   basic_regex& operator= (const charT* ptr);

   template <class ST, class SA>
   basic_regex& operator= (const basic_string<charT, ST, SA>& p);
   // iterators: 
   std::pair<const_iterator, const_iterator> subexpression(size_type n) const;
   const_iterator begin() const;
   const_iterator end() const;
   // capacity: 
   size_type size() const;
   size_type max_size() const;
   bool empty() const;
   size_type mark_count()const;
   //
   // modifiers: 
   basic_regex& assign(const basic_regex& that);
   basic_regex& assign(const charT* ptr,
                       flag_type f = regex_constants::normal);
   basic_regex& assign(const charT* ptr, unsigned int len, flag_type f);

   template <class string_traits, class A>
   basic_regex& assign(const basic_string<charT, string_traits, A>& s,
                       flag_type f = regex_constants::normal);

   template <class InputIterator>
   basic_regex& assign(InputIterator first, InputIterator last,
                       flag_type f = regex_constants::normal);

   // const operations:
   flag_type flags() const;
   int status()const;
   basic_string<charT> str() const;
   int compare(basic_regex&) const;
   // locale:
   locale_type imbue(locale_type loc);
   locale_type getloc() const;
   // swap
   void swap(basic_regex&) throw();
};

这些选项的含义在 syntax_option_type 一节中有文档说明.

静态常量成员作为命名空间 boost::regex_constants 中所声明常量的同义词提供; 对于每个类型为 syntax_option_type、声明于命名空间 boost::regex_constants 中的常量, 都会在 basic_regex 作用域内声明一个同名、同类型、同值的常量.

效果: 返回 正则表达式语法标志 的副本, 即传递给对象构造函数或最后一次调用 assign 时所用的值.

int status() const;

效果: 如果表达式包含有效的正则表达式则返回零, 否则返回错误码. 保留该成员函数供无法使用异常处理的环境使用.

basic_string<charT> str() const;

效果: 返回传递给对象构造函数或最后一次调用 assign 的字符序列的副本.

int compare(basic_regex& e)const;

效果: 如果 flags() == e.flags() 则返回 str().compare(e.str()), 否则返回 flags() - e.flags().

locale_type imbue(locale_type l);

效果: 返回 traits_inst.imbue(l) 的结果, 其中 traits_inst 是存储在对象内的模板参数 traits 的 (默认初始化) 实例. 对 imbue 的调用会使当前包含的任何正则表达式失效.

后置条件: empty() == true.

locale_type getloc() const;

效果: 返回 traits_inst.getloc() 的结果, 其中 traits_inst 是存储在对象内的模板参数 traits 的 (默认初始化) 实例.

void swap(basic_regex& e) throw();

效果: 交换两个正则表达式的内容.

后置条件: *this 包含原来在 e 中的正则表达式, e 包含原来在 *this 中的正则表达式.

复杂度: 常数时间.

注释

在实验基础上提供了 basic_regex 对象之间的比较: 请注意, 这些比较并未出现在 C++ 库扩展技术报告 中, 因此如果你编写的代码可能需要移植到 basic_regex 的其他实现, 请谨慎使用.
