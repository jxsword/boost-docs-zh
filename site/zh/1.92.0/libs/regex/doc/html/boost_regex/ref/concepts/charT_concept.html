charT 要求

类型 charT 作为类模板 basic_regex 的模板参数, 必须具有平凡默认构造函数、拷贝构造函数、赋值运算符和析构函数. 此外, 对象必须满足以下要求; c 为 charT 类型, c1 和 c2 为 charT const 类型, i 为 int 类型:

表达式

返回类型

charT c

charT

charT c(c1)

charT

charT 必须可转换为整数类型.

注意: 不要求 charT 类型支持该操作, 如果所用 traits 类支持完整的 Boost 特有接口, 而非最小标准化接口 (见下文的 traits 类要求).

charT c(i);

charT

charT 必须可从整数类型构造.
