POSIX 兼容 C API

注释

这是 POSIX API 函数的简要参考; 提供它们是为了与其他库兼容, 而不是作为新代码中使用的 API (除非你需要从 C++ 之外的语言访问). 这版本的这些函数也应能与其他版本共存, 因为使用的名称是展开为实际函数名的宏.

#include <boost/cregex.hpp>

或者:

#include <boost/regex.h>

以下函数面向需要 POSIX 兼容 C 库的用户, 同时提供 Unicode 和窄字符版本; 标准 POSIX API 名称是宏, 根据是否定义了 UNICODE 而展开为其中之一.

重要

注意, 在 C++ 程序中使用时, 这里定义的所有符号都封装在命名空间 boost 内, 除非你改用 #include <boost/regex.h> - 这种情况下符号仍定义在命名空间 boost 中, 但也在全局命名空间中可用.

这些函数定义如下:

extern "C" {

struct regex_tA;
struct regex_tW;

int regcompA(regex_tA*, const char*, int);
unsigned int regerrorA(int, const regex_tA*, char*, unsigned int);
int regexecA(const regex_tA*, const char*, unsigned int, regmatch_t*, int);
void regfreeA(regex_tA*);

int regcompW(regex_tW*, const wchar_t*, int);
unsigned int regerrorW(int, const regex_tW*, wchar_t*, unsigned int);
int regexecW(const regex_tW*, const wchar_t*, unsigned int, regmatch_t*, int);
void regfreeW(regex_tW*);

#ifdef UNICODE
#define regcomp regcompW
#define regerror regerrorW
#define regexec regexecW
#define regfree regfreeW
#define regex_t regex_tW
#else
#define regcomp regcompA
#define regerror regerrorA
#define regexec regexecA
#define regfree regfreeA
#define regex_t regex_tA
#endif
}

所有函数都操作结构 regex_t, 它暴露两个公开成员:

成员

含义

unsigned int re_nsub

由 regcomp 填充, 表示正则表达式中包含的子表达式数量.

const TCHAR* re_endp

当设置 REG_PEND 标志时, 指向要编译表达式的结尾.
注释

regex_t 实际上是一个 #define - 它要么是 regex_tA 要么是 regex_tW (取决于是否定义了 UNICODE); TCHAR 同样要么是 char 要么是 wchar_t (取决于宏 UNICODE).

regcomp

regcomp 接受一个指向 regex_t 的指针、一个指向要编译表达式的指针, 以及一个可以是以下组合的标志参数:

标志

含义

REG_EXTENDED

编译现代正则表达式. 等价于 regbase::char_classes | regbase::intervals | regbase::bk_refs.

REG_BASIC

编译基本 (已过时) 正则表达式语法. 等价于 regbase::char_classes | regbase::intervals | regbase::limited_ops | regbase::bk_braces | regbase::bk_parens | regbase::bk_refs.

REG_NOSPEC

所有字符都是普通字符, 表达式是字面字符串.

REG_ICASE

编译为忽略字符大小写的匹配.

REG_NOSUB

在本库中无效果.

REG_NEWLINE

设置该标志时, 点号不匹配换行符.

REG_PEND

设置该标志时, regex_t 结构的 re_endp 参数必须指向要编译的正则表达式的结尾.

REG_NOCOLLATE

设置该标志时, 字符范围的区域相关排序被关闭.

REG_ESCAPE_IN_LISTS

设置该标志时, 括号表达式 (字符集合) 中允许使用转义序列.

REG_NEWLINE_ALT

设置该标志时, 换行符等价于分支运算符 |.

REG_PERL

编译类 Perl 的正则表达式.

REG_AWK

类 awk 行为的快捷方式: REG_EXTENDED | REG_ESCAPE_IN_LISTS

REG_GREP

类 grep 行为的快捷方式: REG_BASIC | REG_NEWLINE_ALT

REG_EGREP

类 egrep 行为的快捷方式: REG_EXTENDED | REG_NEWLINE_ALT

regerror

regerror 接受以下参数, 它将错误码映射为人类可读的字符串:

参数

含义

int code

错误码.

const regex_t* e

正则表达式 (可以为空).

char* buf

用于填入错误消息的缓冲区.

unsigned int buf_size

buf 的长度.

如果错误码与 REG_ITOA 按位或, 则产生的消息是该代码的可打印名称而非一条消息, 例如 "REG_BADPAT". 如果代码为 REG_ATIO, 则 e 不能为空, 且 e->re_pend 必须指向某个错误码的可打印名称, 此时返回值是该错误码的值. 对于任何其他 code 值, 返回值是错误消息中的字符数; 如果返回值大于等于 buf_size, 则需要用更大的缓冲区再次调用 regerror.

regexec

regexec 在字符串 buf 中查找表达式 e 的第一次出现. 如果 len 非零, 则用与正则表达式匹配的内容填充 *m: m[0] 包含整个字符串的匹配内容, m[1] 为第一个子表达式, 依此类推; 更多细节见头文件声明中的 regmatch_t. eflags 参数可以是以下组合:

标志

含义

REG_NOTBOL

参数 buf 不表示某行的开头.

REG_NOTEOL

参数 buf 不在某行的结尾处终止.

REG_STARTEND

被搜索的字符串从 buf + pmatch[0].rm_so 开始, 到 buf + pmatch[0].rm_eo 结束.
regfree

regfree 释放由 regcomp 分配的所有内存.
