在 ICU 中使用 Regex 简介

该头文件:

<boost/regex/icu.hpp>

包含在感知 Unicode 的环境中处理正则表达式所需的数据类型和算法.

要使用该头文件, 你需要 ICU 库.

该头文件使你能够:

  • 创建把 Unicode 字符串视为 UTF-32 码点序列的正则表达式.
  • 创建支持各种 Unicode 数据属性 (包括字符分类) 的正则表达式.
  • 透明地搜索以 UTF-8、UTF-16 或 UTF-32 编码的 Unicode 字符串.

使用该头文件时, CMake 用户应链接我们 CMakeLists.txt 中的 Boost::regex_icu 目标, 以便自动处理 ICU 依赖.
