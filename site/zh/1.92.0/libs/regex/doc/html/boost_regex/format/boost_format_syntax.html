Boost-Extended 格式字符串语法

Boost-Extended 格式字符串把除 '$'、'\'、'('、')'、'?' 和 ':' 之外的所有字符都视为字面量.

分组

字符 '(' 和 ')' 执行词法分组, 因此如果要输出字面圆括号, 请使用 \( 和 \).

条件表达式

字符 '?' 开始一个条件表达式, 一般形式为:

?Ntrue-expression:false-expression

其中 N 是十进制数字.

如果子表达式 N 匹配了, 则对 true-expression 求值并发送到输出; 否则对 false-expression 求值并发送到输出.

通常需要用圆括号将条件表达式包围起来, 以避免歧义.

例如, 格式字符串 "(?1foo:bar)" 会在子表达式 $1 匹配时用 "foo" 替换每个找到的匹配, 否则用 "bar" 替换.

对于索引大于 9 的子表达式, 或者要访问命名的子表达式, 使用:

?{INDEX}true-expression:false-expression

或者

?{NAME}true-expression:false-expression

占位符序列

占位符序列指定正则表达式匹配内容中的某部分按如下方式发送到输出:

占位符

含义

$&

输出整个表达式匹配的内容.

$MATCH

同 $&

${^MATCH}

同 $&

$`

输出从上一次找到的匹配的结尾 (如果没有前一个匹配则是文本的开头) 到当前匹配的开头之间的文本.

$PREMATCH

同 $`

${^PREMATCH}

同 $`

$'

输出当前匹配结尾之后的所有文本.

$POSTMATCH

同 $'

${^POSTMATCH}

同 $'

$+

输出正则表达式中最后一个标记子表达式匹配的内容.

$LAST_PAREN_MATCH

同 $+

$LAST_SUBMATCH_RESULT

输出最后一个实际被匹配的子表达式所匹配的内容.

$^N

同 $LAST_SUBMATCH_RESULT

$$

输出字面字符 '$'

$n

输出第 n 个子表达式匹配的内容.

${n}

输出第 n 个子表达式匹配的内容.

$+{NAME}

输出名为 "NAME" 的子表达式所匹配的内容.

上表未列出的任何 $-占位符序列都会使 '$' 被当作字面字符.

转义序列

转义字符后跟任意字符 x, 会输出该字符, 除非 x 是下面所示的转义序列之一.

转义

含义

\a

输出响铃字符: '\a'.

\e

输出 ANSI 转义字符 (码点 27).

\f

输出换页字符: '\f'

\n

输出换行字符: '\n'.

\r

输出回车字符: '\r'.

\t

输出制表符: '\t'.

\v

输出垂直制表符: '\v'.

\xDD

输出十六进制码点为 0xDD 的字符

\x{DDDD}

输出十六进制码点为 0xDDDDD 的字符

\cX

输出 ANSI 转义序列 "escape-X".

\D

如果 D 是 1-9 范围内的十进制数字, 则输出与子表达式 D 匹配的文本.

\l

使下一个要输出的字符以小写形式输出.

\u

使下一个要输出的字符以大写形式输出.

\L

使其后所有字符以小写形式输出, 直到遇到 \E.

\U

使其后所有字符以大写形式输出, 直到遇到 \E.

\E

终止 \L 或 \U 序列.
