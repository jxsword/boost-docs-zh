regex_split (已弃用)

算法 regex_split 已被弃用, 改用迭代器 regex_token_iterator, 后者接口更灵活强大, 并且遵循标准库中更常见的 "拉取" (pull) 而非 "推送" (push) 语义.

使用 regex_split 的代码仍可继续编译; 以下文档取自早期的 Boost.Regex 版本:

#include <boost/regex.hpp>

算法 regex_split 执行与 perl 的 split 操作类似的操作, 并提供三种重载形式:

template <class OutputIterator, class charT, class Traits1, class Alloc1, class Traits2>
std::size_t regex_split(OutputIterator out,
                        std::basic_string<charT, Traits1, Alloc1>& s,
                        const basic_regex<charT, Traits2>& e,
                        boost::match_flag_type flags,
                        std::size_t max_split);

template <class OutputIterator, class charT, class Traits1, class Alloc1, class Traits2>
std::size_t regex_split(OutputIterator out,
                        std::basic_string<charT, Traits1, Alloc1>& s,
                        const basic_regex<charT, Traits2>& e,
                        boost::match_flag_type flags = match_default);

template <class OutputIterator, class charT, class Traits1, class Alloc1>
std::size_t regex_split(OutputIterator out,
                        std::basic_string<charT, Traits1, Alloc1>& s);

效果: 每个版本的算法都接受一个用于输出的输出迭代器和一个用于输入的字符串. 如果表达式不包含标记子表达式, 则算法会对输入中每个不匹配表达式的部分, 向输出迭代器写入一个字符串. 如果表达式确实包含标记子表达式, 则每次找到匹配时, 会为每个标记子表达式向输出迭代器写入一个字符串. 写入输出迭代器的字符串不会超过 max_split 个. 在返回之前, 所有已处理的输入会从字符串 s 中删除 (如果 max_split 未达到, 则 s 将被全部删除). 返回写入输出迭代器的字符串数量. 如果未指定参数 max_split, 则它默认为 UINT_MAX. 如果未指定表达式, 则默认为 "\s+", 并在空白处拆分.

抛出: std::runtime_error, 当将表达式与 N 个字符的字符串进行匹配的复杂度开始超过 O(N2), 或者匹配表达式时程序耗尽栈空间 (当 Boost.Regex 以递归模式配置时), 或者匹配器耗尽其允许的内存分配 (当 Boost.Regex 以非递归模式配置时).

示例 中移除每个记号: 下面的函数会把输入字符串拆分为一系列记号 (token), 并从字符串 s 中移除每个记号:

unsigned tokenise(std::list<std::string>& l, std::string& s)
{
   return boost::regex_split(std::back_inserter(l), s);
}

示例: 下面的短程序会从 html 文件中提取所有 URL, 并把它们打印到 cout:

#include <list>
#include <fstream>
#include <iostream>
#include <boost/regex.hpp>

boost::regex e("<\\s*A\\s+[^>]*href\\s*=\\s*\"([^\"]*)\"",
               boost::regbase::normal | boost::regbase::icase);

void load_file(std::string& s, std::istream& is)
{
   s.erase();
   //
   // attempt to grow string buffer to match file size,
   // this doesn't always work...
   s.reserve(is.rdbuf()-&gtin_avail());
   char c;
   while(is.get(c))
   {
      // use logarithmic growth strategy, in case
      // in_avail (above) returned zero:
      if(s.capacity() == s.size())
         s.reserve(s.capacity() * 3);
      s.append(1, c);
   }
}


int main(int argc, char** argv)
{
   std::string s;
   std::list<std::string> l;

   for(int i = 1; i < argc; ++i)
   {
      std::cout << "Findings URL's in " << argv[i] << ":" << std::endl;
      s.erase();
      std::ifstream is(argv[i]);
      load_file(s, is);
      boost::regex_split(std::back_inserter(l), s, e);
      while(l.size())
      {
         s = *(l.begin());
         l.pop_front();
         std::cout << s << std::endl;
      }
   }
   return 0;
}
