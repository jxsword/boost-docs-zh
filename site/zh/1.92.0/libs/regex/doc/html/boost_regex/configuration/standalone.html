独立模式使用 (不依赖 Boost 其余部分)

本库现在可以以"独立"模式使用, 无需 Boost C++ 库的其余部分; 为此你必须满足以下条件之一:

  • 拥有支持 __has_include 的 C++17 编译器; 此时如果 <boost/config.hpp> 不存在, 则库会自动进入独立模式. 或者:
  • 构建时定义 BOOST_REGEX_STANDALONE.

两种模式的主要区别是: 当 Boost.Config 可用时, 库会自动围绕各种编译器缺陷进行自我配置. 特别地, 要在关闭异常支持的情况下使用该库, 你需要在 include 路径中有一份 Boost.Config, 或者在构建时手动定义 BOOST_NO_EXCEPTIONS.
