Boost 1.38
  • 破坏性变更: 使用 Perl 正则表达式语法时现在允许空表达式和空分支. 此变更是为兼容 Perl 而加入; 当设置新的 syntax_option_type no_empty_expressions 时, 保留旧行为并禁止空表达式. 这是问题 #1081.
  • 新增对格式字符串中 Perl 风格 ${n} 表达式的支持 (问题 #2556).

  • 修复编译器兼容性问题 #2244、#2514 和 #2458.
Boost 1.34
  • 修复非贪婪重复与部分匹配在某些情况下不能正确工作的问题.
  • 修复 VC++ 上非贪婪重复在某些情况下不生效的问题 (缺陷报告 1515830).
  • 修改 match_results::position(), 使其在 *this 表示部分匹配时返回有效结果.
  • 修复 grep 和 egrep 选项, 使换行符与 | 得到同等对待.
Boost 1.33.1
  • 修复损坏的 makefile.
  • 修复配置设置, 使使用 /Zc:wchar_t 时可以用 VC7.1 - STLport-4.6.2 进行构建.
  • 将 static_mutex.hpp 中的声明改为类内 (class-inline) 形式, 以便 SGI Irix 编译器能够处理.
  • 为 fileiter.hpp、regex_workaround.hpp 和 cpp_regex_traits.hpp 添加所需的标准库 #include.
  • 修复一个缺陷: 非贪婪重复在某些奇怪的情况下可能重复超过其最大次数.
  • 修复默认构造对象时 basic_regex<>::empty() 返回的值.
  • 修改 regex_error 的定义, 使其与 Boost-1.32.0 向后兼容.
  • 对 Intel C++ 8.0 及更早版本禁用外部模板 (external templates) - 否则可能出现无法解析的引用.
  • 重写了 gcc 的 extern template 代码, 使其只导出特定的成员函数: 否则在链接并混用调试与非调试代码时可能出现奇怪的无法解析的引用.
  • 初始化 unicode_iterators 的所有数据成员: 这可以避免 gcc 发出不必要的警告.
  • 将 ICU 集成代码移植到 VC6 和 VC7.
  • 确保代码在 STLport 调试模式下干净无误.
  • 修复后行断言 (lookbehind assertions), 使其允许定长重复, 并使正则表达式迭代允许后行断言回望当前搜索范围之前的内容 (即上一次匹配).
  • 修复前向预查断言 (forward lookahead assertions) 内非贪婪重复的奇怪缺陷.
  • 允许在字符集合内使用取反的字符类.
  • 修复回归问题, 使 [a-z-] 再次成为有效表达式.
  • 修复允许某些无效表达式被接受的缺陷.
Boost 1.33.0
  • 完全重写了表达式解析代码和 traits 类支持; 现在符合标准化提案.
  • 破坏性变更: 可传递给 basic_regex 构造函数的语法选项已合理化. 默认选项 (perl) 现在的值为零, 并且现在清楚地文档化了哪些选项适用于哪种正则表达式语法风格 (perl、POSIX-extended、POSIX-basic 等). 一些较为冷僻的选项已被移除, 因此现有代码可能无法编译: 不过等价的功能仍然可用.
  • 破坏性变更: POSIX-extended 和 POSIX-basic 正则表达式现在比以前更严格地遵循 POSIX 标准的字面规定.
  • 新增对 (?imsx-imsx) 构造的支持.
  • 新增对后行断言表达式 (?<=positive-lookbehind) 和 (?<!negative-lookbehind) 的支持.
  • 新增对条件表达式 (?(assertion)true-expression|false-expression) 的支持.
  • 新增 MFC/ATL 字符串封装.
  • 新增 Unicode 支持; 基于 ICU.
  • 修改换行支持, 将 \f 识别为行分隔符 (适用于所有字符类型), 并将 \x85 识别为仅宽字符 / Unicode 下有效的行分隔符.
  • 新增格式标志 format_literal, 它将替换字符串视为字面量, 而非 Perl 或 Sed 风格的格式字符串.
  • 错误现在通过抛出 regex_error 类型的异常来报告. 之前使用的类型 - bad_expression 和 bad_pattern - 现在只是 regex_error 的 typedef. regex_error 类型有两个新成员: code() 用于报告错误码而非字符串, position() 用于报告错误发生在表达式中的位置.
Boost 1.32.1
  • 修复 '.' 的有界重复在部分匹配中的缺陷.
Boost 1.31.0
  • 完全重写了模式匹配代码 - 现在速度最高可达原来的 10 倍.
  • 重新组织了文档.
  • 弃用了所有不属于正则表达式标准化提案的接口.
  • 新增 regex_iterator 和 regex_token_iterator .
  • 新增对 Perl 风格独立子表达式的支持.
  • 为 sub_match 类添加非成员运算符, 使你可以将 sub_match 与字符串比较, 或将其加到字符串上以生成新字符串.
  • 新增对扩展捕获信息的实验性支持.
  • 修改匹配标志使其成为一种独立类型 (而非整数); 如果你试图将匹配标志作为整数而非 match_flag_type 传递给正则表达式算法, 现在会得到编译错误.
