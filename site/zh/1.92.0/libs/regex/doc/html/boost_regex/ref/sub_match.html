sub_match 

#include <boost/regex.hpp>

正则表达式与许多简单的模式匹配算法不同: 它不仅能找到整体匹配, 还能产生子表达式匹配; 每个子表达式在模式中用一对括号 (...) 界定. 必须有某种方法把子表达式匹配报告给用户: 这通过定义一个 match_results 类来实现, 该类充当子表达式匹配的索引集合, 每个子表达式匹配包含在一个 sub_match 类型的对象中.

sub_match 类型的对象只能通过对 match_results 类型的对象进行下标运算来获得.

sub_match 类型的对象可以与 std::basic_string、const charT* 或 const charT 类型的对象比较.

sub_match 类型的对象可以加到 std::basic_string、const charT* 或 const charT 类型的对象上, 产生一个新的 std::basic_string 对象.

当 sub_match 类型对象所表示的标记子表达式参与了正则表达式匹配时, 成员 matched 取值为 true, 成员 first 和 second 表示构成该匹配的字符范围 [first,second). 否则 matched 为 false, 成员 first 和 second 包含未定义的值.

当 sub_match 类型对象所表示的标记子表达式被重复时, sub_match 对象表示由最后一次重复得到的匹配. 所有重复获得的全部捕获可通过 captures() 成员函数访问 (注意: 这对性能有严重影响, 必须显式启用该特性).

如果 sub_match 类型的对象表示子表达式 0 - 即整体匹配 - 则成员 matched 总为 true, 除非得到了 部分匹配 (由于向正则表达式算法传递了标志 match_partial), 此时成员 matched 为 false, 成员 first 和 second 表示构成部分匹配的字符范围.

typedef implementation-private capture_sequence_type;

定义一个实现特定的类型, 它满足标准库序列 (Sequence) 的要求 (21.1.1, 包括可选的表 68 操作), 其 value_type 为 sub_match<BidirectionalIterator>. 该类型恰好是 std::vector<sub_match<BidirectionalIterator> >, 但你不应当真的依赖这一点.

const capture_sequence_type& captures()const;

效果: 返回一个序列, 包含为此子表达式获得的所有捕获.

前置条件: 库必须在定义了 BOOST_REGEX_MATCH_EXTRA 的情况下构建和使用, 并且必须把标志 match_extra 传递给正则表达式匹配函数 ( regex_match、regex_search、regex_iterator 或 regex_token_iterator ), 此成员 #函数才会被定义并返回有用的信息.

设计理由: 启用该特性会带来以下影响:

  • sub_match 占用更多内存, 导致复杂表达式在匹配期间更快地耗尽内存或栈空间.
  • 匹配算法在处理某些特性 (例如独立子表达式) 时效率更低, 即使未使用 match_extra.
  • 使用 match_extra 时, 匹配算法的效率会大幅降低 (即更慢). 这主要是由于必须进行的额外内存分配.

sub_match 的加法运算符允许把一个 sub_match 加到任何可以加 std::string 的类型上, 并得到一个新字符串作为结果.

template <class BidirectionalIterator, class traits, class Allocator>
std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type, traits, Allocator>
   operator + (const std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type,
                                       traits,
                                       Allocator>& s,
               const sub_match<BidirectionalIterator>& m);

效果: 返回 s + m.str() 

template <class BidirectionalIterator, class traits, class Allocator>
std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type, traits, Allocator>
   operator + (const sub_match<BidirectionalIterator>& m,
               const std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type,
                                       traits,
                                       Allocator>& s);

效果: 返回 m.str() + s 

template <class BidirectionalIterator>
std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type>
   operator + (typename iterator_traits<BidirectionalIterator>::value_type const* s,
               const sub_match<BidirectionalIterator>& m);

效果: 返回 s + m.str() 

template <class BidirectionalIterator>
std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type>
   operator + (const sub_match<BidirectionalIterator>& m,
               typename iterator_traits<BidirectionalIterator>::value_type const * s);

效果: 返回 m.str() + s 

template <class BidirectionalIterator>
std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type>
   operator + (typename iterator_traits<BidirectionalIterator>::value_type const& s,
               const sub_match<BidirectionalIterator>& m);

效果: 返回 s + m.str() 

template <class BidirectionalIterator>
std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type>
   operator + (const sub_match<BidirectionalIterator>& m,
               typename iterator_traits<BidirectionalIterator>::value_type const& s);

效果: 返回 m.str() + s 

template <class BidirectionalIterator>
std::basic_string<typename iterator_traits<BidirectionalIterator>::value_type>
   operator + (const sub_match<BidirectionalIterator>& m1,
               const sub_match<BidirectionalIterator>& m2);

效果: 返回 m1.str() + m2.str()

流插入器 
template <class charT, class traits, class BidirectionalIterator>
basic_ostream<charT, traits>&
   operator << (basic_ostream<charT, traits>& os
               const sub_match<BidirectionalIterator>& m);

效果: 返回 (os << m.str())
