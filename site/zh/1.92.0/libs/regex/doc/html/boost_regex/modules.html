模块支持 (实验性)

本库对 C++ 模块 (C++20 或更高) 提供实验性支持; 目前该支持是实验性的, 尤其是因为在撰写本文时 (2025 年), 构建工具尚未跟上模块支持.

要将本库作为模块使用, 你只需把:

import boost.regex;

加入你的代码.

在此之前, 你必须先构建模块, 包含以下步骤:

  • 取决于你的编译器, 你可能需要构建标准库模块, 并将标准模块放在编译器能找到的地方.
  • 把 libs/regex/module/regex.cxx 构建为 boost.regex 模块, 并将模块定义文件放在编译器能找到的地方.
  • 把 libs/regex/module 中的所有源文件 (包括 regex.cxx) 构建成一个库, 并把结果放在链接器能找到的地方.

Visual Studio 用户可以把上述步骤简化为一步: 把 libs/regex/module 中的所有内容放入一个静态库项目, 然后为 regex.cxx 源文件添加 /interface 命令行选项.

已知限制:

  • 截至 2025 年初, 只支持非常新的 clang 和 msvc 版本. GCC 肯定不受支持.
  • regex 库必须始终通过 import boost.regex; 使用, 并且绝不能与 #includes <boost/regex.hpp> 混用.
  • 理想情况下, 标准库应始终通过 import std 使用而不是通过 #include: 较新的编译器大多已能使其工作, 但仍然非常脆弱.
  • 导入的 regex 版本始终是"独立"版本, 不包含任何其他 Boost 头文件.

最后... libs/regex/test/module 中有一些针对 msvc 和 clang 的构建与测试脚本.
