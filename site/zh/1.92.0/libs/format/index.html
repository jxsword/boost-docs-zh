Boost Format 库

format 库提供一个类, 像 printf 一样根据格式化串格式化参数, 但有两个主要区别:

  • format 把参数送入一个内部流, 因此完全类型安全, 并自然地支持所有用户自定义类型.
  • 省略号 (...) 无法在 format 的强类型语境中正确使用, 因此用任意参数调用的函数形式被替换为对 参数喂入 算符 operator%


更多细节请见:

  • 文档 (HTML).
  • 头文件
    • format.hpp: 用户前端.
    • format_fwd.hpp: 用户前向声明.
    • format_class.hpp: 类接口
    • format_implementation.hpp: 成员函数的实现
    • feed_args.hpp: 参数喂入辅助函数
    • free_funcs.hpp: 自由函数定义
    • parsing.hpp: 解析格式化串的代码
    • group.hpp: 用于对参数和操纵器分组的辅助结构
    • exceptions.hpp: 库所使用的异常
    • internals.hpp: 辅助结构 stream_format_state 和 format_item
  • 示例程序
    • 程序 sample_formats.cpp 演示了 format 的简单用法.
    • sample_new_features.cpp 展示了加入 printf 语法的少量格式化特性, 例如简单的位置指令、居中对齐和"制表位".
    • sample_advanced.cpp 演示了高级特性的用法, 例如复用和修改 format 对象等.
    • 而 sample_userType.cpp 展示了 format 库在用户自定义类型上的行为.
