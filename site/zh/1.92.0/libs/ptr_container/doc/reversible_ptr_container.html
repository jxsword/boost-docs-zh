类 reversible_ptr_container

语义

语义: typedef

注意这两个类型有何不同:

  • typedef T* value_type;

    • 注意它是指针类型

  • typedef T& reference;

    • 注意它不是指针类型

这样做是为了能够把指针直接加入容器, 同时对外隐藏指针.

还要注意

  • typedef ... iterator

允许遍历 T& 对象, 而非 T*. 注意:

iterator i = ...;
i.base();

返回一个可遍历 void* 元素的迭代器 (这种情况极少需要, 除非你清楚自己在做什么, 否则不应使用该功能).

  • typedef ... auto_type

该声明隐藏了一个指向指针的指针类型. 你可以信赖以下操作

T* operator->() const;
T& operator*() const;
T* release();
~auto_type();
operator implementation-defined bool();

析构函数将使用容器的克隆分配器删除所存对象 (这解释了为什么我们不能使用 std::auto_ptr<T> 或 std::unique_ptr<T>). 把它当作只是一个 compatible-smart-ptr<T> 或许有助于理解. 你也可以经由 move() 函数从函数返回该指针, 或把它赋给另一个指针

auto_type ptr   = ...;
auto_type other = boost::ptr_container::move( ptr );
return boost::ptr_container::move( other );

语义: 构造/拷贝/销毁

  • reversible_ptr_container();

    • 效果: 构造一个空容器
    • 后置条件: size() == 0

  • explicit reversible_ptr_container( const reversible_ptr_container& r );

    • 效果: 构造容器, 办法是克隆其所有元素, 源自 r

  • template< class Derived > explicit reversible_ptr_container( const reversible_ptr_container<Derived>& r );

    • 效果: 构造容器, 办法是克隆其所有元素, 源自 r
    • 要求: Derived 派生自 T

  • explicit reversible_ptr_container( compatible-smart-ptr< reversible_ptr_container > r );

    • 效果: 通过取得所提供指针的所有权来构造容器

  • template< class InputIterator > reversible_ptr_container( InputIterator first, InputIterator last );

    • 要求: (first,last] 是有效范围
    • 效果: 构造容器, 使用的克隆范围为 (first,last]
    • 后置条件: size() == std::distance( first, last )

  • ~reversible_ptr_container();

    • 效果: 经由克隆分配器删除所存对象
    • 抛出: 无

  • reversible_ptr_container& operator=( const reversible_ptr_container& r );

    • 效果: 赋值为一个克隆, 源自 r
    • 异常安全性: 强保证

  • template<class Derived> reversible_ptr_container& operator=( const reversible_ptr_container<Derived>& r );

    • 效果: 赋值为一个克隆, 源自 r
    • 要求: Derived 派生自 T
    • 异常安全性: 强保证

  • reversible_ptr_container& operator=( compatible-smart-ptr<reversible_ptr_container> r );

    • 效果: 删除所存对象, 然后取得所提供指针的所有权
    • 抛出: 无

  • allocator_type get_allocator() const;

    • 效果: 返回容器对象的分配器副本

语义: 迭代器

参见: 迭代器失效

  • iterator begin();

  • const_iterator begin() const;

    • 效果: 返回可变/不可变迭代器, 其 value_type 为 value_type T
    • 抛出: 无

  • iterator end();

  • const_iterator end() const;

    • 效果: 返回可变/不可变迭代器, 其 value_type 为 value_type T
    • 抛出: 无

  • reverse_iterator rbegin();

  • const_reverse_iterator rbegin() const;

    • 效果: 返回可变/不可变反向迭代器, 其 value_type 为 value_type T
    • 抛出: 无

  • reverse_iterator rend();

  • const_reverse_iterator rend() const;

    • 效果: 返回可变/不可变反向迭代器, 其 value_type 为 value_type T
    • 抛出: 无

语义: 容量

  • size_type size() const;

    • 效果: 返回所存元素的数目
    • 抛出: 无

  • size_type max_size() const;

    • 效果: 返回可存元素的最大数目
    • 抛出: 无

  • bool empty() const;

    • 效果: 返回容器是否为空
    • 抛出: 无

语义: 修改器

  • void swap( reversible_ptr_container& r );

    • 效果: 交换两个容器的内容
    • 抛出: 无

  • void clear();

    • 效果: 销毁容器中的所有对象
    • 后置条件: empty() == true
    • 抛出: 无

  • VoidPtrContainer& base();

  • const VoidPtrContainer& base() const;

    • 返回: 指向被包装容器的引用

语义: 指针容器要求

  • auto_type replace( iterator position, T* x );

    • 要求: not empty() and x != 0
    • 效果: 返回 position 所指的对象, 并用 x 替换它.
    • 抛出: bad_ptr_container_operation, 若容器为空; bad_pointer, 若 x == 0.
    • 异常安全性: 强保证

  • template< class U > auto_type replace( iterator position, compatible-smart-ptr<U> x );

    • 效果: return replace( position, x.release() );

  • compatible-smart-ptr< reversible_ptr_container > clone() const;

    • 效果: 返回容器的一份深拷贝
    • 抛出: std::bad_alloc, 若没有足够的内存来克隆容器
    • 复杂度: 线性

  • compatible-smart-ptr< reversible_ptr_container > release();

    • 效果: 释放容器的所有权. 这是从函数返回容器的一种实用方式.
    • 后置条件: empty() == true
    • 抛出: std::bad_alloc, 若无法分配返回值
    • 异常安全性: 强保证

  • auto_type release( iterator position );

    • 要求: 非 empty();
    • 效果: 释放 position 所指指针的所有权
    • 后置条件: size() 减一
    • 抛出: bad_ptr_container_operation, 若容器为空
    • 异常安全性: 强保证

语义: 比较

这些函数比较的是底层的对象范围. 因此

operation( const ptr_container& l, const ptr_container& r );

会产生与普通标准容器一样的预期效果. 也就是说, 比较的是对象而非指向对象的指针.

语义: 可克隆性

  • template< class T, class CloneAllocator > reversible_ptr_container<T,CA,VPC>* new_clone( const reversible_ptr_container<T,CA,VPC>& r );

    • 效果: return r.clone().release();
    • 备注: 该函数仅为具体的指针容器定义, 不适用于指针容器适配器.

语义: 空判定谓词

  • template< class Iterator > bool is_null( Iterator i );

    • 要求: i 是有效的可解引用迭代器
    • 返回: *i.base() == 0;

语义: 序列化

所有容器都可以通过 Boost.Serialization 序列化. 概述参见 Serialization of Pointer Containers.

template<class Archive, class T, class CA, class VPC>
void serialize( Archive& ar, reversible_ptr_container<T,CA,VPC>& c, const unsigned int version );
  • 效果: 把容器保存到档案或从档案加载.
  • 备注: 该函数由 Boost.Serialization 的流运算符自动调用
  • 异常安全性: 加载提供基本保证
