指针容器库

类 ptr_sequence_adapter

本节描述所有指针序列的全部公共操作:

  • ptr_vector
  • ptr_list
  • ptr_deque

ptr_sequence_adapter 也是一个具体类, 你可以从它创建自定义指针容器.

概要:

namespace boost
{

    template
    <
        class T,
        class VoidPtrSeq,
        class CloneAllocator = heap_clone_allocator
    >
    class ptr_sequence_adapter
    {
    public: // construct/copy/destroy
        template< class InputIterator >
        assign( InputIterator first, InputIterator last );
        template< class InputRange >
        assign( const InputRange& e );

    public: // element access
        T&        front();
        const T&  front() const;
        T&        back();
        const T&  back() const;

    public: // modifiers
        void      push_back( T* x );
        template< class U >
        void      push_back( compatible-smart-ptr<U> x );
        auto_type pop_back();
        iterator  insert( iterator position, T* x );
        template< class U >
        iterator  insert( iterator position, compatible-smart-ptr<U> x );
        template< class InputIterator >
        void      insert( iterator position, InputIterator first, InputIterator last );
        template< class InputRange >
        void      insert( iterator position, const InputRange& r );
        iterator  erase( iterator position );
        iterator  erase( iterator first, iterator last );
        template< class Range >
        iterator  erase( const Range& r );
        void      resize( size_type size );
        void      resize( size_type size, T* to_clone );

    public: // pointer container requirements
        template< class PtrSequence >
        void transfer( iterator before, typename PtrSequence::iterator object,
                       PtrSequence& from );
        template< class PtrSequence >
        void transfer( iterator before, typename PtrSequence::iterator first, typename PtrSequence::iterator last,
                       PtrSequence& from );
        void template< class PtrSequence, class Range >
        void transfer( iterator before, const Range& r, PtrSequence& from );
        template< class PtrSequence >
        void transfer( iterator before, PtrSequence& from );

    public: // algorithms

        void sort();
        void sort( iterator first, iterator last );
        template< class Compare >
        void sort( Compare comp );
        template< class Compare >
        void sort( iterator begin, iterator end, Compare comp );

        void unique();
        void unique( iterator first, iterator last );
        template< class Compare >
        void unique( Compare comp );
        template< class Compare >
        void unique( iterator begin, iterator end, Compare comp );

        template< class Pred >
        void erase_if( Pred pred );
        template< class Pred >
        void erase_if( iterator begin, iterator end, Pred pred );

        void merge( ptr_sequence_adapter& r );
        template< class Compare >
        void merge( ptr_sequence_adapter& r, Compare comp );
        void merge( iterator first, iterator last, ptr_sequence_adapter& from );
        template< class Compare >
        void merge( iterator first, iterator last, ptr_sequence_adapter& from, Compare comp );

    public: // ptr_list interface

    public: // ptr_vector interface

    public: // ptr_deque interface

    }; //  class 'ptr_sequence_adapter'

} // namespace 'boost'

语义

语义: 构造/拷贝/销毁

  • template< class InputIterator > void assign( InputIterator first, InputIterator last );

    • 要求: (first,last] 是有效范围
    • 效果: clear(); insert( first, last );
    • 后置条件: size() == std::distance( first, last );
    • 异常安全性: 强保证

  • template< class InputRange > void assign( const InputRange& r );

    • 效果: assign( boost::begin(r), boost::end(r) );

语义: 元素访问

  • T& front();

    • 要求: 非 empty();
    • 效果: return *begin();

  • const T& front() const;

    • 要求: 非 empty();
    • 效果: return *begin();

  • T& back();

    • 要求: 非 empty();
    • 效果: return *--end();

  • const T& back() const;

    • 要求: 非 empty();
    • 效果: return *--end();

语义: 修改器

  • void push_back( T* x );

    • 要求: x != 0
    • 效果: 把指针插入容器并取得其所有权
    • 抛出: bad_pointer, 若 x == 0
    • 异常安全性: 强保证

  • template< class U > void push_back( compatible-smart-ptr<U> x );

    • 效果: push_back( x.release() );

  • auto_type pop_back();

    • 要求: not empty()
    • 效果: 移除容器中的最后一个元素
    • 后置条件: size() 减一
    • 抛出: bad_ptr_container_operation, 若 empty() == true
    • 异常安全性: 强保证

  • iterator insert( iterator position, T* x );

    • 要求: position 是来自该容器的有效迭代器, 且 x != 0
    • 效果: 在 position 之前插入 x, 并返回指向它的迭代器
    • 抛出: bad_pointer, 若 x == 0
    • 异常安全性: 强保证

  • template< class U > iterator insert( iterator position, compatible-smart-ptr<U> x );

    • 效果: return insert( position, x.release() );

  • template< class InputIterator > void insert( iterator position, InputIterator first, InputIterator last );

    • 要求: position 是来自该容器的有效迭代器
    • 效果: 插入一个克隆的范围, 位置是 position
    • 异常安全性: 强保证

  • template< class InputRange > void insert( iterator position, const InputRange& r );

    • 效果: insert( position, boost::begin(r), boost::end(r) );

  • iterator erase( iterator position );

    • 要求: position 是来自该容器的有效迭代器
    • 效果: 移除由 position 定义的元素, 并返回指向其后一个元素的迭代器
    • 抛出: 无

  • iterator erase( iterator first, iterator last );

    • 要求: [first,last) 是有效范围
    • 效果: 移除由 [first,last) 定义的元素范围, 并返回指向其后一个元素的迭代器
    • 抛出: 无

  • template< class Range > void erase( const Range& r );

    • 效果: erase( boost::begin(r), boost::end(r) );

  • void resize( size_type size );

    • 效果: 调整容器大小. 若有元素被移除, 则从尾部移除. 若有元素被插入, 则在尾部插入.
    • 要求: T 可默认构造
    • 后置条件: size() == size;
    • 异常安全性: 扩展时为基本保证; 其他情况为无异常保证

  • void resize( size_type size, T* to_clone );

    • 效果: 调整容器大小. 若有元素被移除, 则从尾部移除. 若有元素被插入, 则在尾部插入 *to_clone 的克隆.
    • 后置条件: size() == size;
    • 异常安全性: 扩展时为基本保证; 其他情况为无异常保证
    • 备注: 若容器支持空指针, to_clone == 0 是合法的. 容器不取得 to_clone 的所有权.

语义: 指针容器要求

你可以使用 transfer() 在两个同类型容器之间移动元素. 此外, 还可以把元素从 T 类型的容器移动到 U 类型的容器, 条件是 T::value_type 可转换为 U::value_type. 例如从 boost::ptr_vector<Derived> 转移到 boost::ptr_deque<Base>.

(备注: 在两个不同容器之间移动元素时, 确保分配器兼容是你自己的责任. 能够在两个不同容器之间转移这一特殊自由度只对序列可用, 对关联容器不可用.)

  • template< class PtrSequence > void transfer( iterator before, typename PtrSequence::iterator object, PtrSequence& from );

    • 效果: 把由 object 定义的对象插入容器, 并把它从 from 移除. 插入发生在 before 之前.
    • 后置条件: 若 from.empty(), 则什么都不发生. 否则 size() 加一, from.size() 减一.
    • 异常安全性: 强保证

  • template< class PtrSequence > void transfer( iterator before, typename PtrSequence::iterator first, typename PtrSequence::iterator last, PtrSequence& from );

    • 要求: from.size() >= std::distance(first,last)
    • 效果: 把范围 [first,last) 定义的对象插入容器, 并把它们从 from 移除. 插入发生在 before 之前.
    • 后置条件: 若 from.empty(), 则什么都不发生. 否则, 设 N == std::distance(first,last);, 则 size() 加 N, from.size() 减 N.
    • 异常安全性: 强保证
    • 复杂度: 线性或更优

  • void template< class PtrSequence, class Range > void transfer( iterator before, const Range& r, PtrSequence& from );

    • 效果: transfer(before, boost::begin(r), boost::end(r), from);

  • template< class PtrSequence> void transfer( iterator before, PtrSequence& from );

    • 效果: transfer(before, from, from);

语义: 算法

这些算法的总体要求是容器不包含任何空指针.

  • void sort();

  • void sort( iterator first, iterator last );

  • template< class Compare > void sort( Compare comp );

  • template< class Compare > void sort( iterator begin, iterator end, Compare comp );

    • 要求: (不带 Compare 的版本) 已定义 bool operator<( const T&, const T& )
    • 要求: (Compare 版本) Compare 必须接受 const T& 实参
    • 效果: 对整个容器或指定范围排序
    • 异常安全性: 无异常保证 (若比较运算符抛出异常, 行为未定义)
    • 备注: 接受两个迭代器的 sort() 版本不适用于 ptr_list

  • void unique();

  • void unique( iterator first, iterator last );

  • template< class Compare > void unique( Compare comp );

  • template< class Compare > void unique( iterator begin, iterator end, Compare comp );

    • 要求: (不带 Compare 的版本) 已定义 bool operator==( const T&, const T& )
    • 要求: (Compare 版本) Compare 必须接受 const T& 实参
    • 效果: 从整个容器或指定范围中移除相邻且相等的对象
    • 异常安全性: 无异常保证 (若比较运算符抛出异常, 行为未定义)

  • template< class Pred > void erase_if( Pred pred );

  • template< class Pred > void erase_if( iterator begin, iterator end, Pred pred );

    • 要求: Pred 必须接受一个 const T& 实参
    • 效果: 从整个容器或指定范围中移除所有使 pred(t) 返回 true 的元素 t
    • 异常安全性: 无异常保证 (若比较运算符抛出异常, 行为未定义)

  • void merge( ptr_sequence_adapter& r );

  • template< class Compare > void merge( ptr_sequence_adapter& r, Compare comp );

  • void merge( iterator first, iterator last, ptr_sequence_adapter& from );

  • template< class Compare > void merge( iterator first, iterator last, ptr_sequence_adapter& from, Compare comp );

    • 要求: (Compare 版本) Compare 必须接受 const T& 实参
    • 要求: 两个序列都按同一谓词排序
    • 效果: 把整个容器或指定序列转移到容器中, 同时确保新序列也是有序的
    • 后置条件: (容器版本) r.empty()
    • 异常安全性: 无异常保证 (若比较运算符抛出异常, 行为未定义)
