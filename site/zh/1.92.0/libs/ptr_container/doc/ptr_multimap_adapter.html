类 ptr_multimap_adapter

该类用于构建以类 multimap 容器为底层容器的自定义指针容器. 该类的接口是 associative_ptr_container 接口的扩展.

概要:

namespace boost
{
    template
    <
        T,
        class VoidPtrMultiMap,
        class CloneAllocator = heap_clone_allocator
    >
    class ptr_multimap_adapter
    {
    public: // typedefs
        typedef VoidPtrMap::key_type key_type;
        typedef T*                   mapped_type;
        typedef T&                   mapped_reference;
        typedef const T&             const_mapped_reference;
        typedef ...                  value_type;
        typedef ...                  reference;
        typedef ...                  const_reference;
        typedef ...                  pointer;
        typedef ...                  const_pointer;

    public: // modifiers
        iterator  insert( key_type& k, T* x );
        template< class U >
        iterator  insert( const key_type&, compatible-smart-ptr<U> x );

    public: // pointer container requirements
        void      transfer( iterator object, ptr_multimap_adapter& from );
        size_type transfer( iterator first, iterator last, ptr_multimap_adapter& from );
        template< class Range >
        size_type transfer( const Range& r, ptr_multimap_adapter& from );
        void      transfer( ptr_multimap_adapter& from );

    }; //  class 'ptr_multimap_adapter'

} // namespace 'boost'

语义

. typedef 定义:

语义: typedef

以下类型为实现定义:

typedef ... value_type;
typedef ... reference;
typedef ... const_reference;
typedef ... pointer;
typedef ... const_pointer;

不过, 该类型的结构模仿 std::pair, 因此可以使用 first 和 second 成员. 引用类型并非真正的引用, 指针类型也并非真正的指针. 但仍可以写

map_type::value_type       a_value      = *m.begin();
a_value.second->foo();
map_type::reference        a_reference  = *m.begin();
a_reference.second->foo();
map_type::const_reference  a_creference = *const_begin(m);
map_type::pointer          a_pointer    = &*m.begin();
a_pointer->second->foo();
map_type::const_pointer    a_cpointer   = &*const_begin(m);

与 std::map<Key,T*> 的区别在于: 在 const_itertor 中, const 性会传播到指针 (即 second).

语义: 修改器

  • iterator insert( key_type& k, T* x );

    • 要求: x != 0
    • 效果: 取得 x 的所有权, 并返回指向它的迭代器.
    • 抛出: bad_pointer, 若 x == 0
    • 异常安全性: 强保证

  • template< class U > iterator insert( const key_type& k, compatible-smart-ptr<U> x );

    • 等价于 (但不含 const_cast): return insert( const_cast<key_type&>(k), x.release() );

语义: 指针容器要求

  • void transfer( iterator object, ptr_multimap_adapter& from );

    • 要求: not from.empty()
    • 效果: 把由 object 定义的对象插入容器, 并把它从 from 移除.
    • 后置条件: size() 加一, from.size() 减一.
    • 异常安全性: 强保证

  • void transfer( iterator first, iterator last, ptr_multimap_adapter& from );

    • 要求: not from.empty()
    • 效果: 把范围 [first,last) 定义的对象插入容器, 并把它们从 from 移除.
    • 后置条件: 设 N == std::distance(first,last);, 则 size() 加 N, from.size() 减 N.
    • 异常安全性: 基本保证

  • template< class Range > void transfer( const Range& r, ptr_multimap_adapter& from );

    • 效果: transfer( boost::begin(r), boost::end(r), from );

  • void transfer( ptr_multimap_adapter& from );

    • 效果: transfer( from.begin(), from.end(), from );.
    • 后置条件: from.empty();
    • 异常安全性: 基本保证
