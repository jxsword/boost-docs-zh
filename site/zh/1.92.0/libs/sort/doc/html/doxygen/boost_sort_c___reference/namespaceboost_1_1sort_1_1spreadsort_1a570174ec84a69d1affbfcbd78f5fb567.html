函数模板 string_sort

boost::sort::spreadsort::string_sort — 使用随机访问迭代器的字符串排序算法, 允许字符类型重载.
(所有变体在数据规模过小时都会回退到 boost::sort::pdqsort, 即小于 detail::min_sort_size).

概要

// In header: <boost/sort/spreadsort/string_sort.hpp>


template<typename RandomAccessIter, typename Unsigned_char_type> 
  void string_sort(RandomAccessIter first, RandomAccessIter last, 
                   Unsigned_char_type unused);

说明

string_sort 是一种快速的模板化原地混合基数/比较算法, 在测试中, 对于大型测试集 (>=100kB), 其速度往往比 std::sort 快约 50% 到 2 倍.

 最坏情况性能为 O(N * (lg(range)/s + s)) , 因此 string_sort 在渐近意义上快于纯基于比较的算法.

提供了运行时间相对于 n 与 log(range) 的若干性能图:
windows_string_sort
osx_string_sort

警告

抛出异常可能导致数据丢失. 若小型 vector 的 resize 抛出异常, 此处也会抛出, 但这种情况下不会有数据丢失.

警告

无效参数导致未定义行为.

注释

spreadsort 函数提供一个封装, 针对数据类型调用可用的最快排序算法, 从而实现更快的泛型编程.

注释

最坏情况下为 O(N*log(N)) 次比较与 O(N*log(K/S + S)) 次操作中的较小者, 其中:

注释

* N 为 last - first,

注释

* K 为范围的比特对数 (对使用完整范围的 32 位整数为 32),

注释

* S 为一个称为 max_splits 的常数, 默认值为 11 (对于字符串则是字符大小的对数).

参数:

first

指向第一个元素的迭代器指针.

last

指向数据末尾之后一个位置的迭代器.

unused

与 [] 运算符结果同类型的值, 用于定义 Unsigned_char_type. 实际值未使用.

模板参数:

RandomAccessIter

随机访问迭代器

Unsigned_char_type

字符串使用的无符号字符类型.

要求:

[first, last) 是有效范围.

要求:

RandomAccessIter value_type 是可变的.

要求:

RandomAccessIter value_type 是 LessThanComparable

要求:

RandomAccessIter value_type 支持 operator>>, 该操作将整数值按指定位数右移.

后置条件:

[first, last) 范围内的元素按升序排序.

抛出:

 std::exception 若元素比较、元素交换 (或移动)、右移、右移后的元素相减、仿函数或迭代器上的任何操作抛出异常, 则传播异常.
