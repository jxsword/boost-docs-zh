函数模板 float_sort

boost::sort::spreadsort::float_sort

概要

// In header: <boost/sort/spreadsort/float_sort.hpp>


template<typename RandomAccessIter> 
  void float_sort(RandomAccessIter first, RandomAccessIter last);

说明

\brief @c float_sort, 并转换为适当大小. \param[in] first 指向第一个元素的迭代器指针. \param[in] last 指向数据末尾之后一个位置的迭代器.

Some performance plots of runtime vs. n and log(range) are provided:
windows_float_sort
osx_float_sort

对一些浮点数排序的简单示例: 

vector<float> vec;
vec.push_back(1.0);
vec.push_back(2.3);
vec.push_back(1.3);
spreadsort(vec.begin(), vec.end());

排序后的 vector 包含升序值 "1.0 1.3 2.3".
