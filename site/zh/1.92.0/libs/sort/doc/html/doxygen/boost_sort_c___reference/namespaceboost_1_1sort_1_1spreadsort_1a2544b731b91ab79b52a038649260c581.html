函数模板 float_sort

boost::sort::spreadsort::float_sort — 使用随机访问迭代器、仅带右移仿函数的浮点排序算法.

概要

// In header: <boost/sort/spreadsort/float_sort.hpp>


template<typename RandomAccessIter, typename Right_shift> 
  void float_sort(RandomAccessIter first, RandomAccessIter last, 
                  Right_shift rshift);

说明

参数:

first

指向第一个元素的迭代器指针.

last

指向数据末尾之后一个位置的迭代器.

rshift

返回将 value_type 右移指定位数结果的仿函数.
