未使用的 X86 优化

虽然 x86 上理想 max_splits 对 n < 1 million (左右) 似乎 要大得多, 能为这类测试带来约 15% 的提速, 但这一优化并不通用, 也不适用于 n > 1 million. 过大的 max_splits 可能使排序耗时增加一倍以上, 因此应设在合理范围的低端, 即当前的位置.
