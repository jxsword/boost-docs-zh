用法

Pattern-defeating quicksort 可通过两个调用使用: pdqsort 和 pdqsort_branchless. 二者提供的保证、行为与重载都与 std::sort 相同, 唯一的例外是 C++17 并行执行策略参数. 因此你可以把对 std::sort 的调用替换为 boost::sort::pdqsort (位于 boost/sort/pdqsort/pdqsort.hpp), 它只是一个更快的实现. 几乎所有情况下, 直接调用 pdqsort 并忽略 pdqsort_branchless 都是合适的.

对于无分支的比较函数 (原因见下文 '平均情况' 一节), 例如简单的整数或浮点数比较, pdqsort_branchless 运行速度明显快于 pdqsort; 而当比较函数包含分支时则略慢. 使用算术类型和默认比较函数 (std::less 或 std::greater) 时, pdqsort 会自动转调 pdqsort_branchless. 如果你知道自定义比较函数是无分支的, 并希望利用这一提速, 请显式调用 pdqsort_branchless.
