2.4.- flat_stable_sort

说明

Flat_stable_sort 是一种新的稳定排序算法, 由 Francisco Jose Tapia 为 Boost Sort 库设计并实现

该算法的目标是在稳定排序的同时只使用很少的额外内存 (约为数据所用内存的 1%).

大多数编译器和库提供的默认稳定排序算法使用大量额外内存, 通常为待排序数据的一半.

该新算法提供约 80%-90% 的 spinsort 以及编译器和库所提供稳定排序算法的速度.

当数据几乎有序时, 该算法速度很快. 很多时候, 新元素插入到已排序元素的末尾, 或某些元素被修改而破坏了元素的顺序. 在这些情况下, flat_stable_sort 算法非常快.

                 |         |                             |                                |
Algorithm        | Stable  |      Additional Memory      | Best, average, and worst case  |
-----------------+---------+-----------------------------+--------------------------------+
flat_stable_sort |   Yes   | size of the data / 256 + 8K |     N, NlogN , NlogN           |
                 |         |                             |                                |

内存占用

Linux x64 上实测的稳定排序算法内存占用

   Algorithm       | Memory used  |
-------------------+--------------+
std::stable_sort   |   1177 MB    |
spinsort           |   1175 MB    |
