浮点排序

float_sort 是一种快速的模板化原位混合基数/比较算法, 与 integer_sort 非常相似, 但它通过把 IEEE 浮点数 (正数、零、NaN 和负数) 转换为整数来按升序排序. 这之所以可行, 是因为正 IEEE 浮点数与具有相同比特的整数排序方式相同, 而负 IEEE 浮点数按具有相同比特的整数的相反顺序排序. float_sort 大约比 std::sort 快 2 倍.

该算法中基于基数的部分为 -0.0 与 0.0 以及 NaN 给出确定的有序位置, 而基于比较的排序不保证它们的相对位置. 随附的测试避免产生 NaN 与 -0.0, 以便结果与 std::sort 一致——std::sort 处理这些数字的方式并不一致, 因为它们与不同值的数字比较时被视为相等.

如果用户未提供转换仿函数, float_sort 会检查数据类型的大小及其是否可转换, 并选择一个整数类型作为转换目标.

float_mem_cast 把 IEEE 浮点数 (正数、零、NaN 和负数) 转换为整数. 当需要为 float_sort 创建自定义右移仿函数时, 这是一个必备工具. 在此特化方法调用中, 只应使用与要转换到的整数类型相同大小的 IEEE 浮点数. 最坏情况性能为 𝑶(N * (log2(range)/s + s)), 因此 float_sort 在渐近意义上快于纯基于比较的算法. s 是 max_splits, 其默认值为 11, 因此对 32 位整数在默认设置下的最坏情况为 𝑶(N * ((32/11) 轮慢基于基数的迭代 + 11 轮快基于比较的迭代).

浮点排序示例

用 float 键对结构体排序的可运行示例见 floatfunctorsample.cpp:

#define CAST_TYPE int
#define KEY_TYPE float

struct DATA_TYPE {
    KEY_TYPE key;
    std::string data;
};

右移仿函数:

// Casting to an integer before bitshifting
struct rightshift {
  int operator()(const DATA_TYPE &x, const unsigned offset) const {
    return float_mem_cast<KEY_TYPE, CAST_TYPE>(x.key) >> offset;
  }
};

小于比较 operator< 仿函数:

struct lessthan {
  bool operator()(const DATA_TYPE &x, const DATA_TYPE &y) const {
    return x.key < y.key;
  }
};
