2.2.- pdqsort

引言

Pattern-defeating quicksort (pdqsort) 是一种新颖的排序算法, 它结合了随机化快速排序的快速平均情况与堆排序的快速最坏情况, 并对具有某些模式的输入达到线性时间. pdqsort 是 David Musser 的 introsort 的扩展与改进. 其用法与 std::sort 完全相同.
