3.2.- Sample_Sort

这是 Francisco Tapia 为 Boost 库实现的 Samplesort 算法.

它是一种高效的 并行稳定排序, 针对多线程使用做了优化.

所需额外内存与数据大小相同

说明 

                      |       |                        |                              |
Algorithm             |Stable |   Additional memory    |Best, average, and worst case |
----------------------+-------+------------------------+------------------------------+
sample_sort           |  yes  |        N               |     N, N LogN , N LogN       |
                      |       |                        |                              |

其性能可在 基准测试 一章中查看
