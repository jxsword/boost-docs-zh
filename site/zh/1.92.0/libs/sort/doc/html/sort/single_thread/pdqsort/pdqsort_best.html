最好情况

pdqsort 被设计为对几种最好情况模式以线性时间运行. 对于严格升序或降序的输入、只含相等元素的输入、或严格升序后跟一个错位元素的输入, 都能达到线性时间. 这有两种机制在起作用.

对于相等元素, 采用一种巧妙的分区方案, 总是把相等元素放入包含大于主元元素的分区. 选择新主元时, 会将它与前一分区中的最大元素比较. 如果二者相等, 即可断定不存在小于所选主元的元素. 发生这种情况时, 我们对该分区切换策略, 过滤掉所有等于主元的元素.

为了让其他模式也达到线性时间, 我们在每次分区后检查是否发生过交换. 如果没有发生交换且分区相当均衡, 我们会乐观地尝试使用插入排序. 若排序所需移动次数超过常数, 该插入排序会中止.
