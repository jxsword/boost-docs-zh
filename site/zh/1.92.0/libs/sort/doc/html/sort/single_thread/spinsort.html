2.3.- spinsort

说明

Spinsort 是一种新的稳定排序算法, 由 Francisco Tapia 为 Boost Sort 库设计并实现.

该算法结合了用于优化其他稳定排序算法的若干思路.

            |         |                   |                                |
Algorithm   | Stable  | Additional Memory | Best, average, and worst case  |
------------+---------+-------------------+--------------------------------+
spinsort    |   Yes   |      N / 2        |     N, NlogN , NlogN           |
            |         |                   |                                |

当数据接近有序时该算法效率最高. 很多时候, 新元素插入到已排序元素的末尾, 或某些元素被修改而破坏了元素的顺序. 在这些情况下, spinsort 非常快.
