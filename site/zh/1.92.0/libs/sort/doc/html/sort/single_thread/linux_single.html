2.5.- Linux 基准测试

本库包含一个 benchmark 文件夹, 其中的程序用于在你的机器与操作系统上测量算法速度. 这些是简短的基准测试, 用不同种类的数据测试速度 (随机、有序、有序并在末尾追加无序数据...)

测试在 Intel(R) Core(TM) i7-5820K CPU @ 3.30GHz 上运行, 6 核、每核 2 线程、15M 缓存

在 Linux 上使用 GCC 6.3 于 benchmark_numbers 中对整数得到的结果如下:
