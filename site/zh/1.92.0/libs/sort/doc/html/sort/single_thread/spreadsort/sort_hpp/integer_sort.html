整数排序

integer_sort 是一种快速的模板化原位混合基数/比较算法, 在测试中, 对于大型测试 (>=100kB), 往往比 std::sort 快约 50% 到 2 倍. 最坏情况性能为 𝑶(N * (log2(range)/s + s)), 因此 integer_sort 在渐近意义上快于纯基于比较的算法. s 是 max_splits, 其默认值为 11, 因此对 32 位整数在默认设置下的最坏情况为 𝑶(N * ((32/11) 轮慢基于基数的迭代 + 11 轮快基于比较的迭代).
