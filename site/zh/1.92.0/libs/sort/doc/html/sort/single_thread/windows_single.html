2.6.- Windows 基准测试

本库包含一个 benchmark 文件夹, 其中的程序用于在你的机器与操作系统上测量算法速度. 这些是简短的基准测试, 用不同种类的数据测试速度 (随机、有序、有序并在末尾追加无序数据...)

该基准测试在 VirtualBox 虚拟机上运行, 8 线程、16 GB 内存, 宿主机为 Intel(R) Core(TM) i7-5820K CPU @ 3.30GHz, 6 核、每核 2 线程、15M 缓存.

操作系统为 Windows 10 64 位, 编译器为 VC2017

近似有序数据

100 000 000 个 64 位整数的近似有序数据

benchmark/single/benchmark_numbers.cpp : 此基准测试展示了对几种整数 (随机与近似有序) 得到的结果.

字符串与不同大小对象的基准测试未在此展示, 但可通过运行 benchmark_strings.cpp 与 benchmarks_objects.cpp 程序得到.
