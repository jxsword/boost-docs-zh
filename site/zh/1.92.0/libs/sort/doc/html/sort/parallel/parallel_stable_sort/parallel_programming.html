编程

线程规格

该算法有一个整数参数, 指示排序过程中要使用的 线程数, 它始终是调用中的最后一个值.

默认值 (如果未指定) 是程序运行所在机器的硬件线程数, 由 std::thread::hardware_concurrency() 提供. 若该数为 1 或 0, 算法将以单线程运行.

线程数不是固定数值, 而是在每次执行时计算得出. 传入的线程数可以大于机器的硬件线程数: 在只有 4 个硬件线程的机器上可以传入 100 个线程; 同样地, 也可以传入 (std::thread::hardware_concurrency() / 4 ) 这样的函数结果. 若此值为 0, 程序将以单线程执行.

编程

只需包含 boost/sort/sort.hpp 文件即可使用此代码.

该算法位于命名空间 boost::sort 中.

#include <boost/sort/sort.hpp>


template <class iter_t>
void parallel_stable_sort (iter_t first, iter_t last);

template <class iter_t,  typename compare>
void parallel_stable_sort (iter_t first, iter_t last, compare comp);

template <class iter_t>
void parallel_stable_sort (iter_t first, iter_t last, uint32_t num_thread);

template <class iter_t,  typename compare>
void parallel_stable_sort (iter_t first, iter_t last, compare comp, uint32_t num_thread);

该算法需要 符合 C++11 的编译器, 不需要任何其他代码或库. 使用更旧的编译器不保证正确运行.

如果未指定线程数, 则使用 std::thread::hardware_concurrency() 的结果.

该算法使用 比较对象, 方式与标准库排序算法相同. 如果不定义, 比较对象为 std::less, 其内部使用 < 运算符.

该算法是 异常安全的, 即算法产生的异常保证待排序对象的完整性, 但不保证它们的相对顺序. 如果异常由对象内部产生 (在移动构造函数或复制构造函数中...), 结果可能不可预测.
