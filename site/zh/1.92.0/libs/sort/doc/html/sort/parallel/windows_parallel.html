3.5- Windows 基准测试

这些结果来自复杂的基准测试, 因使用非自由软件而未包含在库中. (如果你对细节感兴趣, 请联系 fjtapia@gmail.com)

基准测试有 3 种类型:

  • 64 位整数
  • 字符串
  • 多种大小的对象.

对象是整数数组. 重量级比较对数组中所有元素求和, 轻量级比较只使用数组中的第一个数字.

该基准测试在 VirtualBox 虚拟机上运行, 8 线程、16 GB 内存, 宿主机为 Intel(R) Core(TM) i7-5820K CPU @ 3.30GHz, 6 核、每核 2 线程、15M 缓存.
