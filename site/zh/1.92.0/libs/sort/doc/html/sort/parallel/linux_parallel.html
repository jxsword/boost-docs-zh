3.4- Linux 基准测试

以下结果来自复杂的基准测试, 因使用非自由软件而未包含在库中. (如果你感兴趣, 请联系 fjtapia@gmail.com)

基准测试有 3 种类型:

  • 64 位整数
  • 字符串
  • 多种大小的对象.

对象是整数数组. 重量级比较对数组中所有元素求和, 轻量级比较只使用数组中的第一个数字.

测试在 Intel(R) Core(TM) i7-5820K CPU @ 3.30GHz 上运行, 6 核、每核 2 线程、15M 缓存. 所用编译器为 GCC 6.3 64 位
