复杂 (多种类型)

以下结果来自更复杂的基准测试, 因使用非自由软件而未包含在库中 (如果你对其代码感兴趣, 请联系 fjtapia@gmail.com)

基准测试有 3 种类型:

  • 64 位整数
  • 字符串
  • 多种大小的对象.

对象是整数数组. 重量级比较对数组中所有元素求和, 轻量级比较只使用数组中的第一个数字.

(L) 轻量级: 比较只使用数组的第一个元素作为键
