查找表?

优化这些常数的理想方式是使用精心调优的查找表代替 get_max_count 函数, 但 4 个调优变量更简单, get_max_count 强制执行最坏情况性能最小化规则, 而且这样的查找表很难针对跨平台性能做优化.

另外, 也可以用 get_max_count 生成静态查找表. 出于对跨平台兼容性与灵活性的顾虑, 尚未这样做.
