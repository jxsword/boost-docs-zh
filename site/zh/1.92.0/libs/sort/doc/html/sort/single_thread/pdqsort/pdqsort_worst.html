最坏情况

由于快速排序基于分区, 它在形成模式的输入上天然表现不佳. 选择了糟糕的主元会导致大量比较却几乎无法推进排序进程. 如果模式未被打破, 这种情况可能连续发生多次. 更糟的是, 现实世界的数据中充满了这类模式.

传统上的解决方法是随机化快速排序的主元选择. 虽然这在理论上仍可能出现平方级最坏情况, 但发生概率微乎其微. 后来在 introsort 中, 主元选择保持确定性, 而是在递归深度过大时切换到有保证的 O(n log n) 堆排序. 在 pdqsort 中我们采用混合方法: 当遇到"不良"分区时, (确定性地) 打乱一些元素以打破模式. 如果遇到太多"不良"分区, 则切换到堆排序.
