平均情况

在未检测到模式的平均情况数据上, pdqsort 实际上就是一个使用三数取中主元选择的快速排序, 当待 (递归) 排序的元素数量较小时切换为插入排序. 检测最好情况模式所带来的开销非常小, 处于测量误差范围之内.

在排序大型数组 (1000 个以上元素) 时, pdqsort 相比传统的快速排序实现获得了大幅提速. 这得益于 Stefan Edelkamp 与 Armin Weiss 在 "BlockQuicksort: How Branch Mispredictions don't affect Quicksort" 中描述的一种新技术. 简言之, 我们利用小缓冲区 (完全位于 L1 缓存中) 保存需要交换的元素索引, 从而绕过分支预测器. 我们以无分支的方式填充这些缓冲区, 方式相当优雅 (伪代码如下):

buffer_num = 0; buffer_max_size = 64;
for (int i = 0; i < buffer_max_size; ++i) {
    // With branch:
    if (elements[i] < pivot) { buffer[buffer_num] = i; buffer_num++; }
    // Without:
    buffer[buffer_num] = i; buffer_num += (elements[i] < pivot);
}
