非稳定排序

让 基数排序 变得稳定需要使用数据的外部副本. 稳定的混合算法还需要一个稳定的基于比较的算法, 而这类算法通常较慢. LSD 基数排序 使用数据的外部副本并提供稳定性, 且可能更快 (比稳定的混合排序), 因此对整数和浮点类型而言这可能是更好的选择. 使用外部内存实现一个稳定的 string_sort 版本或许有意义, 但为简单起见暂未提供.
