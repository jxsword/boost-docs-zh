编程

只需包含 boost/sort/sort.hpp 文件即可使用 spinsort.

spinsort 函数位于命名空间 boost::sort 中

#include <boost/sort/sort.hpp>


template <class iter_t,  typename compare>
void spinsort (iter_t first, iter_t last, compare comp = compare());

该算法使用 比较对象, 方式与标准库排序算法相同. 如果不定义, 比较对象默认为 std::less, 其内部使用 < 运算符进行比较.

该算法是 异常安全的, 即算法产生的异常保证待排序对象的完整性, 但不保证它们的相对顺序. 如果异常由对象内部产生 (在移动或复制构造函数中), 则结果未定义.
