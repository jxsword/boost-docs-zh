Spreadsort

头文件 <boost/sort/spreadsort/spreadsort.hpp>

spreadsort 检查所提供的数据类型是整数、可转换的 float、string 还是 wstring.

  • 若数据类型是整数, 则使用 integer_sort.
  • 若数据类型是 float, 则使用 float_sort.
  • 若数据类型是 string 或 wstring, 则使用 string_sort.
  • 对其他数据类型排序需要在 integer_sort、float_sort 与 string_sort 之间直接选择, 因为 spreadsort 不接受没有相应 type traits 的类型.

提供了允许使用用户自定义右移仿函数与比较仿函数的重载变体.

每个函数都针对其参数组合做了优化; 不提供默认仿函数, 以避免任何性能下降的风险.

参见 重载 一节.

设计理由:

spreadsort 函数提供一个封装, 针对数据类型调用可用的最快排序算法, 从而实现更快的泛型编程.

Spreadsort 示例

所有示例见 example 文件夹.

简单可运行的示例见 sample.cpp.

64 位整数排序的示例见 int64.cpp.

此示例把 vector 的元素类型设为 64 位整数

#define DATA_TYPE boost::int64_t

并调用排序

boost::sort::spreadsort::spreadsort(array.begin(), array.end());

一个对 float 排序的简单示例:

vector<float> vec;
vec.push_back(1.0);
vec.push_back(2.3);
vec.push_back(1.3);
...
spreadsort(vec.begin(), vec.end());
//The sorted vector contains "1.0 1.3 2.3 ..."

另见 floatsample.cpp, 它检查异常值.
