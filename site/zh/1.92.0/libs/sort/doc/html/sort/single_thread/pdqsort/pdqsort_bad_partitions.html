不良分区

当主元在分区后所处的位置低于 12.5% (1/8) 分位或高于 87.5% 分位时, 就会发生不良分区——分区高度失衡. 发生这种情况时, 我们会为两个分区分别打乱固定位置上的四个元素. 这能有效打破许多模式. 如果遇到超过 log(n) 次不良分区, 我们将切换到堆排序.

选择 1/8 分位并非任意. 快速排序最坏情况运行时间的上界可由以下递推式在常数因子内近似:

T(n, p) = n + T(p(n-1), p) + T((1-p)(n-1), p)

其中 n 是元素数量, p 是主元在分区后的分位. T(n, 1/2) 是快速排序的最好情况. 在现代系统上, 实测堆排序约比快速排序慢 1.8 到 2 倍. 选取 p 使得当 n 变大时 T(n, 1/2) / T(n, p) ~= 1.9, 可确保只有在堆排序确实能加快排序时才切换过去. p = 1/8 是一个相当接近的值, 而且在所有平台上都可以用一次位移廉价地计算.
