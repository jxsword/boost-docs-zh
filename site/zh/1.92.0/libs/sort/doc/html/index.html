1.- 引言

Boost Sort 库的目标是为用户提供最现代、最快速且内存高效的排序算法.

本库提供稳定与不稳定的排序算法, 均有单线程与并行版本.

这些算法不使用任何其他库或工具, 只需包含 boost/sort/sort.hpp 或某个更具体的头文件即可. 并行算法需要符合 C++11 的编译器.

单线程算法 

                  |       |                            |                                            | Comparison          |
Algorithm         |Stable |   Additional memory        |Best, average, and worst case               | method              |
------------------+-------+----------------------------+--------------------------------------------+---------------------+
spreadsort        |  no   |      key_length            | N, N sqrt(LogN), min(N logN, N key_length) | Hybrid radix sort   |
pdqsort           |  no   |      Log N                 | N, N LogN, N LogN                          | Comparison operator |
spinsort          |  yes  |      N / 2                 | N, N LogN, N LogN                          | Comparison operator |
flat_stable_sort  |  yes  |size of the data / 256 + 8K | N, N LogN, N LogN                          | Comparison operator |
                  |       |                            |                                            |                     |

  • spreadsort 是一种极其快速的混合基数排序算法, 由 Steven Ross 设计并开发.
  • pdqsort 是快速排序算法的一种改进, 由 Orson Peters 设计并开发.
  • spinsort 是一种稳定排序, 对随机或近似有序数据都很快速, 由 Francisco Tapia 设计并开发.
  • flat_stable_sort 是一种稳定排序, 仅使用极少的额外内存 (约为数据大小的 1%), 提供 spinsort 80% - 90% 的速度, 由 Francisco Tapia 设计并开发.
并行算法 

                      |       |                        |                              |
Algorithm             |Stable |   Additional memory    |Best, average, and worst case |
----------------------+-------+------------------------+------------------------------+
block_indirect_sort   |  no   |block_size * num_threads| N, N LogN , N LogN           |
sample_sort           |  yes  |        N               | N, N LogN , N LogN           |
parallel_stable_sort  |  yes  |      N / 2             | N, N LogN , N LogN           |
                      |       |                        |                              |

  • Sample_sort 是 Francisco Tapia 对 Samplesort 算法 的一种实现.
  • Parallel_stable_sort 基于 samplesort 算法, 但只使用 sample_sort 一半的内存, 由 Francisco Tapia 构思并实现.
  • Block_indirect_sort 是一种新颖的高速并行排序算法, 额外内存消耗低, 由 Francisco Tapia 构思并实现.

block_size 是算法的内部参数, 为达到最高速度, 它会根据下一张表中待排序对象的大小而变化. 字符串使用 128 的 block_size.

                                |        |         |         |         |         |         |          |
object size (bytes)             | 1 - 15 | 16 - 31 | 32 - 63 | 64 - 127|128 - 255|256 - 511| 512 -    |
--------------------------------+--------+---------+---------+---------+---------+---------+----------+
block_size (number of elements) |  4096  |  2048   |   1024  |   768   |   512   |   256   |  128     |
                                |        |         |         |         |         |         |          |
