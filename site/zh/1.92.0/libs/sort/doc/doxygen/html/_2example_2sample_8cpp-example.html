使用随机访问迭代器的整数排序算法. 所有变体在数据太小时都会回退到 std::sort. integer_sort 是一种快速的模板化原位混合基数/比较算法, 在测试中, 对于大型测试, 往往比 std::sort 快约 50% 到 2 倍 (>=100kB).
最坏情况性能为 O(N * (lg(range)/s + s)) , 因此 integer_sort 在渐近意义上快于纯基于比较的算法. s 是 max_splits, 其默认值为 11, 因此对 32 位整数在默认设置下的最坏情况为 O(N * ((32/11) 慢基于基数的迭代 快基于比较的迭代).

提供了运行时间相对于 n 与 log(range) 的若干性能图:

模板参数
RandomAccessIter随机访问迭代器
参数
[in]first指向第一个元素的迭代器指针.
[in]last指向数据末尾之后一个位置的迭代器.
前置条件
[first, last) 是有效范围.
RandomAccessIter value_type 是可变的.
RandomAccessIter value_type 是 LessThanComparable
RandomAccessIter value_type 支持 operator>>, 该操作将整数值按指定位数右移.
后置条件
[first, last) 范围内的元素按升序排序.
返回
void.
异常
传播异常, 若元素比较、元素交换 (或移动)、右移、右移后的元素相减、仿函数或迭代器上的任何操作抛出异常.
警告
抛出异常可能导致数据丢失. 若小型 vector 的 resize 抛出异常, 此处也会抛出, 但这种情况下不会有数据丢失.
无效参数导致未定义行为.
注释
spreadsort 函数提供一个封装, 针对数据类型调用可用的最快排序算法, 从而实现更快的泛型编程.
备注
最坏情况下为 O(N*log(N)) 次比较与 O(N*log(K/S + S)) 次操作中的较小者, 其中:
* N 为 last - first,
* K 为范围的比特对数 (对使用完整范围的 32 位整数为 32),
* S 为一个称为 max_splits 的常数, 默认值为 11 (对于字符串则是字符大小的对数).
