33 /*! \brief 使用随机访问迭代器的整数排序算法.
34 (所有变体在数据规模过小 (< @c detail::min_sort_size) 时都会回退到 @c std::sort).
35 
36 \details @c integer_sort 是一种快速的模板化原位混合基数/比较算法,
37 在测试中, 对于大型测试 (>=100kB), 往往比 @c std::sort 快约 50% 到 2 倍. \n
38 最坏情况性能为 <em> O(N * (lg(range)/s + s)) </em>,
39 因此 @c integer_sort 在渐近意义上快于
40 纯基于比较的算法. @c s 即 @c max_splits, 默认值为 11,
41 因此对 32 位整数在默认设置下的最坏情况为
42 <em> O(N * ((32/11) </em> 慢基于基数的迭代 快基于比较的迭代). \n\n
43 提供了运行时间相对于 n 与 log(range) 的若干性能图:\n
44  <a href="../../doc/graph/windows_integer_sort.htm"> windows_integer_sort</a>
45  \n
46  <a href="../../doc/graph/osx_integer_sort.htm"> osx_integer_sort</a>
47 
48 
49 \tparam RandomAccessIter <a href="http://www.cplusplus.com/reference/iterator/RandomAccessIterator/">随机访问迭代器</a>
50 \param[in] first 指向第一个元素的迭代器指针.
51 \param[in] last 指向数据末尾之后一个位置的迭代器.
52 
53 \pre [@c first, @c last) 是有效范围.
54 \pre @c RandomAccessIter @c value_type 是可变的.
55 \pre @c RandomAccessIter @c value_type 是 <a href="http://en.cppreference.com/w/cpp/concept/LessThanComparable">LessThanComparable</a>
56 \pre @c RandomAccessIter @c value_type 支持 @c operator>>,
57 该运算符返回按指定位数右移后的整数类型值.
58 \post [@c first, @c last) 范围内的元素按升序排序.
59 
60 \throws std::exception 若元素比较、元素交换 (或移动)、
61 右移、右移后的元素相减、仿函数或迭代器上的任何操作抛出异常, 则传播异常.
62 
63 \warning 抛出异常可能导致数据丢失. 若小型 vector 的 resize 抛出异常, 此处也会抛出, 但这种情况下不会有数据丢失.
64 \warning 无效参数导致未定义行为.
65 \note @c spreadsort 函数提供一个封装, 针对数据类型调用可用的最快排序算法,
66 从而实现更快的泛型编程.
67 
68 \remark 最坏情况下为 <em> O(N*log(N)) </em> 次比较与 <em> O(N*log(K/S + S)) </em> 次操作中的较小者, 其中:
69 \remark * N 为 @c last - @c first,
70 \remark * K 为范围的比特对数 (对使用完整范围的 32 位整数为 32),
71 \remark * S 为一个称为 max_splits 的常数, 默认值为 11 (对于字符串则是字符大小的对数).
72 
73 */
74  template <class RandomAccessIter>
75  inline void integer_sort(RandomAccessIter first, RandomAccessIter last)
76  {
77 // 若数据太小不值得优化则不排序.
78  if (last - first < detail::min_sort_size)
79  std::sort(first, last);
80  else
81  detail::integer_sort(first, last, *first >> 0);
82  }
