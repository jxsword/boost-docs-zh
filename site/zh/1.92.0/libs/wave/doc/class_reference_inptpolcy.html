引言

输入策略类型可以作为模板参数指定给wave::context 对象, 用于定制被包含文件如何用一对指向结果输入序列开头和结尾的迭代器来表示. 如果在实例化上下文对象时未给出该模板参数, 它默认为iteration_context_policies::load_file_to_string 类型.

头文件 wave/iteration_context.hpp 概要

下面的代码清单不仅展示了所需的接口, 而且出于篇幅考虑还给出了一个完整的输入策略实现, 它把给定文件加载到一个字符串变量中, 并把该字符串的 begin() 和 end() 迭代器提供给Wave 库.

namespace boost {
namespace wave {
namespace iteration_context_policies {

    struct load_file_to_string {
    
        template <typename IterContext>
        class inner {
        
        public:
            // expose the begin and end iterators for the
            // included file
            template <typename Position>
            static 
            void init_iterators(IterContext&iter_ctx, 
                Position const &act_pos)
            {
                typedef typename IterContext::iterator_type iterator_type;
                
                std::ifstream instream(iter_ctx.filename.c_str());
                if (!instream.is_open()) {
                    CPP_THROW(preprocess_exception, bad_include_file, 
                        iter_ctx.filename, act_pos);
                }
                
                iter_ctx.instring = std::string(
                    std::istreambuf_iterator<char>(instream.rdbuf()),
                    std::istreambuf_iterator<char>());

                iter_ctx.first = iterator_type(iter_ctx.instring.begin(), 
                    iter_ctx.instring.end(), 
                    PositionT(iter_ctx.filename));
                iter_ctx.last = iterator_type();
            }

        private:
            std::string instring;
        };
    };

}   // namespace iteration_context_policies
}   // namespace wave 
}   // namespace boost

如你所见, wave::context 对象的input_policy 只需实现一个函数, 即 init_iterators 函数. 所示策略借助一个内嵌类实现, 以避免使用模板模板参数——并非所有系统今天都实现了这一特性. 该内嵌类应当命名为inner.

模板参数

inner 类用一个模板参数实例化, 即迭代上下文类型, 策略是该类型的一部分. 用于访问底层输入流的迭代器类型iterator_type 必须通过所示的 typedef 派生. 要初始化的迭代器对 (可通过iter_ctx.first 和iter_ctx.last 访问) 必须从表示实际输入流的任意迭代器类型初始化.

成员函数

init_iterators

    template <typename Position>
    static void init_iterators(
        IterContext iter_ctx, 
        Position const &act_pos);

在输入记号流中发现指令. 该函数的主要用途是初始化迭代器对iter_ctx.first 和iter_ctx.last, 预处理引擎内部将使用它们访问与要插入的包含文件对应的输入流.
