Wave 库使用了以下Boost [8] 库:

Boost Spirit (把解析器直接表示为内联 C++ 中 EBNF 文法的 LL 解析器框架)
Boost Iterator Adaptor Library (把一个基础类型适配为符合标准的迭代器)
Boost Filesystem Library (可移植路径、目录遍历及其他有用的文件系统操作)
Boost Program options and arguments library

以及不同Boost 库的其他一些小部件.
