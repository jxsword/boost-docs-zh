跟踪设施

如果你曾经需要调试宏展开, 你就会发现你的工具对这项任务几乎不提供任何支持. 为此, Wave 库提供了一项跟踪设施, 可以有选择地获取关于某个或某些宏展开的信息.

宏展开的跟踪可能会生成数量极其庞大的信息, 因此建议只针对相关宏显式启用/禁用跟踪. 这可以借助一条 Wave 特有的特殊 #pragma 来完成:

    #pragma wave trace(enable)    // enable the tracing
    // the macro expansions here will be traced
    // ...
    #pragma wave trace(disable)   // disable the tracing

在 C99 模式下或指定 --variadics 命令行选项时, 你还可以使用 operator _Pragma() 变体来启用/禁用跟踪输出:

    #define CONCAT(x, y) \
        _Pragma("wave trace(enable)") \
        x \
        _Pragma("wave trace(disable)") \
        ## y

这样, 就可以只在宏的一部分展开期间启用跟踪. 在所示示例中, 只跟踪宏实参 'x' 的展开. 注意, operator _Pragma() 指令在宏展开结果内部展开为空.

要看 Wave 驱动程序在展开一个简单宏时生成什么, 让我们看看以下示例的跟踪输出:

    // test.cpp
    #define X(x)          x
    #define Y()           2
    #define CONCAT_(x, y) x ## y
    #define CONCAT(x, y)  CONCAT_(x, y)
    #pragma wave trace(enable)
    // this macro expansion is to be traced
    CONCAT(X(1), Y())     // should expand to 12
    #pragma wave trace(disable)

生成的跟踪输出非常详尽, 但可以据此逐步跟进实际的宏展开过程. 此跟踪示例的第一行包含宏展开起始位置的引用. 此外, 每一次宏展开都包含以下信息:

  • 对要展开的宏首次定义位置 (行号和列号) 的引用 (见第 2、9、21 和 32 行).
  • 为此次宏展开提供的实际参数 (见第 3、10 和 33 行), 该信息在 invoked with 块内跟踪记录, 其中列出了相应的形式参数和实际参数.
  • 所给定实参的展开 (若有, 且这些实参被定义为宏). 这部分会重复实参宏展开的完整跟踪信息, 只是缩进一级. 但请注意, 无论该实参在其展开后是否真的会被插入替换列表, 还是按其初始提供的形式插入, 实参的宏展开都会被跟踪 (参见 C++ 标准 [16.3.1.1]: "替换列表中的参数, 除非前面有 # 或 ## 预处理记号, 或后面跟有 ## 预处理记号, 否则将在其中所包含的所有宏都被展开之后由对应实参替换" [1]).
  • 实参替换的结果 (见第 15、23、29 和 39 行), 即替换后的替换列表.
  • 重扫描过程, 它再次包含对所有发现的宏的完整后续宏展开过程 (参见 C++ 标准 [16.3.4.1]: "在替换列表中的所有参数都被替换之后, 所得的预处理记号序列将与源文件的所有后续预处理记号一起被重新扫描, 以查找更多要替换的宏名." [1]).
  • 实际宏展开的结果 (这是相应重扫描块内的最后一行 - 见第 18、26、42 和 45 行).

每发现一个待展开的宏, 都会在跟踪输出内增加一级额外的缩进.
