引言

文件位置模板用于表示底层输入流中一个具体的记号位置. 该记号位置包含对应的文件名、记号被识别处的行号和列号.

头文件 wave/util/file_position.hpp 概要

namespace boost {
namespace wave {
namespace util {

    template <typename String = std::string>
    class file_position {
 
    public:
        file_position();
        explicit file_position(String const &file, 
            unsigned int line_ = 1, unsigned int column_ = 1);

    // accessors
        String const &get_file() const;
        unsigned int get_line() const;
        unsigned int get_column() const;
    
        void set_file(String const &file);
        void set_line(int line);
        void set_column(int column);
    };

}   // namespace util
}   // namespace wave
}   // namespace boost

模板参数

默认记号类型使用的file_position 模板必须用一个模板参数实例化, 该参数给出用于存储文件位置中文件名成员的字符串类型. 如果未给出该参数, 它默认为std::string. 请注意, 作为模板参数给出的类型必须与std::string. 兼容. 请注意, 作为模板参数给出的类型必须与std::string 兼容.

你可以酌情使用自己的位置类型, 但无论如何它们都应当实现与这里描述的file_position 模板相同的接口.

成员函数

构造函数

        file_position();
        explicit file_position(String const &file, 
            unsigned int line_ = 1, unsigned int column_ = 1);

这些构造函数按给定参数初始化file_position 的新实例. 参数默认为空文件名, 行号和列号设为 1.

get_file、get_line、get_column

        String const &get_file() const;
        unsigned int get_line() const;
        unsigned int get_column() const;

get_... 函数用于访问文件位置成员的当前值:文件名 (get_file) 、行号 (get_line) 和列号 (get_column) .

set_file、set_line、set_column

        void set_file(String const &file);
        void set_line(unsigned int line);
        void set_column(unsigned int column);

set_... 函数用于为文件位置成员设置新值:文件名 (set_file) 、行号 (set_line) 和列号 (set_column) .
