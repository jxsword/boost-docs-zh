宏展开过程

这里描述的宏展开过程最初由Paul Mensonides 开发, 并在Wave 中实现. 它比 C++ 标准[1] 中给出的期望宏展开算法的描述容易理解得多.

宏替换自左向右进行.

如果在扫描 (或重新扫描) 期间发现一个标识符, 将在符号表中查找它. 如果该标识符在符号表中找不到, 它就不是宏, 扫描继续.

如果找到了该标识符, 则使用与该标识符关联的一个标志的值来确定它是否可用于展开. 如果不可用, 该特定记号 (即该标识符的特定实例) 被标记为禁用, 且不展开. 如果该标识符可用于展开, 则使用符号表中与该标识符关联的另一个标志的值来确定它是类对象宏还是类函数宏. 如果是类对象宏, 则展开它. 如果是类函数宏, 则只有当下一个记号是左括号时才展开它.
如果一个标识符未被标记为禁用, 且与该标识符关联的、用于确定它是否可用于展开的标志的值未设置, 则该标识符可用于展开.

(如果宏是类对象宏, 跳过下面两段. )

如果要展开的宏是类函数宏, 其实参个数必须与宏定义要求的形参个数完全一致. 每个实参都被递归地扫描和展开. 替换列表中发现的每个参数名都会被展开后的实参替换 (去掉前导和尾部空白, 并且移除所有 placemarker 记号) , 除非参数名紧跟字符串化运算符 ('#') 之后或与记号粘贴运算符 ('##') 相邻.

如果参数名紧跟字符串化运算符 ('#') 之后, 将插入未展开实参的字符串化版本. 如果参数名与记号粘贴运算符 ('##') 相邻, 则在移除所有 placemarker 记号之后插入未展开的实参.

所有拼接都发生在替换列表中. (如果一次拼接产生多个记号, 行为未定义. 而且, 在普通 C++98 和 C99 模式下, 如果拼接的结果产生多于一个记号, Wave 会报错. 在 C++0x 模式下, Wave 把无关记号的记号粘贴视为良好定义, 并把拼接记号重新解析后的字符串表示插入替换列表. )

符号表条目中与被展开宏的名称关联的标志被设置, 以表明该宏不可用于展开.

替换列表会被重新扫描以进行进一步的宏展开. 替换列表中所有前导和尾部的空白记号都被移除 (placemarker 记号保持不变) .

重新扫描完成后, 符号表条目中与被展开宏的名称关联的标志被清除, 以表明该宏再次可用于展开, 并且构成重新扫描后的替换列表的记号序列被返回到宏的调用点.

如果这个记号序列为空, 则用一个 placemarker 记号替换它. 如果在扫描 (或重新扫描) 期间发现 placemarker, 则忽略它. (此外, 如果分隔参数与字符串化运算符或记号粘贴运算符的唯一内容是一个 placemarker, 则在该上下文中也会忽略它. )

这个记号序列被插入到宏最初被调用的位置, 扫描从新插入的记号序列的最后一个记号开始继续. 也就是说, 扫描向后回看一个记号 (可能是 placemarker 记号) 并继续.
