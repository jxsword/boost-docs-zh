引言

Wave 中的记号类型是信息的主要载体. 它由解引用词法分析组件暴露的迭代器和预处理器组件暴露的迭代器返回. 记号最初由词法分析器生成 (“词法分析器是一种把解析对象在词法上转换为更适合后续解析的对象序列 (称为记号) 的实体”) . Wave 库包含两个不同的、可互换的 C++ 词法分析器, 它们可以作为开发你自己的应用程序时的起点. 词法分析器生成的记号由预处理引擎 (宏展开、包含文件处理等) 变换, 之后返回给Wave 库的用户.

你可以将任意记号类型与你自己的词法分析器配合使用, 只要它们实现某些必需的接口. 必需的记号类型接口在下文描述, 并由wave::cpplexer::lex_token 模板实现; 必需的词法分析器接口在此处描述.

下面描述Wave 库内部预定义的记号类型, 它也与Wave 库包含的两个预定义 C++ 词法分析器配合使用. 如果你需要使用自己的记号类型, 则必须实现下文描述的接口.

头文件 wave/cpplexer/cpp_lex_token.hpp 概要

namespace boost {
namespace wave {
namespace cpplexer {

    template <typename Position>
    class lex_token 
    {
    public:
        typedef std::basic_string<char> string_type;
        typedef Position                position_type;
    
        lex_token();
        lex_token(token_id id, string_type const &value, 
            PositionT const &pos);

    // accessors
        operator token_id() const;
        string_type const &get_value() const;
        position_type const &get_position() const;
        void set_token_id (token_id id);
        void set_value (string_type const &newval);
        void set_position (position_type const &pos);
    };

}   // namespace cpplexer
}   // namespace wave
}   // namespace boost

模板参数

预定义记号类型使用模板参数Position, 允许指定用于携带生成记号内文件位置信息的类型. 你自己的记号类型不必接受这个Position 模板参数, 但请注意, 记号类型无论如何都需要有一个内嵌的类型定义position_type (见下文) .

公共 typedef

记号类型需要定义两个内嵌类型:string_type 和position_type. string_type 必须是与std::basic_string<> 类兼容的类型.

该类型应至少包含记号被识别位置的文件名、行号和列号. 对于预定义记号类型, 它默认为此处描述的简单 file_position 模板类. 注意, 你自己的position_type 也应当遵循为 file_position 模板描述的接口.

成员函数

构造函数

    lex_token();

    lex_token(token_id id, 
        string_t const &value, 
        PositionT const &pos);

第一个 (默认) 构造函数用于生成流末记号, 用于指示底层输入流的结束.

第二个构造函数用其记号 id (有效记号 id 的列表请看此处) 、其值的字符串表示以及描述该记号在输入流中被识别位置信息的文件位置来初始化新创建的记号对象.

访问器函数

operator token_id

    operator token_id() const;

允许访问记号的记号 id. 该访问器允许把Spirit 解析器直接用在 Wave 生成的记号流之上. 可能的记号 id 在此处描述.

该函数在任何情况下都不抛出异常.

get_value

    string_type const &get_value() const;

返回记号在输入流中被识别时的值. 即使是常量记号 (如关键字或运算符等) , 返回的值也反映输入流中发现的字符序列.

该函数在任何情况下都不抛出异常.

get_position

    Position const &get_position() const;

返回记号在输入流中被识别的位置. 该位置包含记号的文件名、行号和列号信息. 默认情况下, Wave 库为此使用一个 file_position 模板, 更详细的描述见此处.

该函数在任何情况下都不抛出异常.

set_token_id

    void set_token_id(token_id id);

把记号的记号 id 更改为新值. 可能的记号 id 在此处描述. 这个函数对库用户来说可能没什么用, 但在某些情况下它是预处理引擎正确运行所必需的.

该函数在任何情况下都不抛出异常.

set_value

    void set_value(string_type const &newval);

把记号内存储的值更改为新值. 这个函数对库用户来说可能没什么用, 但在某些情况下它是预处理引擎正确运行所必需的.

set_position

    void set_position(Position const &newpos);

把记号内存储的位置更改为新值. 例如, 这用于实现#line 指令所需的功能.
