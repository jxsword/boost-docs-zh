预处理器记号标识符表

下表包含要与Wave 预处理引擎配合使用的 C++ 词法分析器应当识别的所有记号. 这些记号被分组归类, 以简化某些内部逻辑以及最终的驱动程序. 记号标识符被定义为一个enum, 建议在你自己的词法分析器实现中复用这个定义.

但请注意, 预处理引擎会做一些记号变换, 因此这里列出的记号标识符并非全部都会出现在预处理迭代器返回的记号中.
