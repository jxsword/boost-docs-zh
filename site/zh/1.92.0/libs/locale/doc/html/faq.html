Boost.Locale
常见问题
  • 某些 Boost.Locale 函数抛出 std::bad_cast 异常?

    答: 你很可能使用了错误的 std::locale 对象. 所有 Boost.Locale 工具都依赖 std::locale 对象的刻面. locale 对象应当用 generator 类生成后传给函数, 或者用 std::locale::global() 函数设置全局 locale, 使全局 locale (以及默认创建的 locale) 具有所需的刻面.
  • 我已安装全局 locale, 但向流写入时输出仍然不对? 例如:
    #include <boost/locale.hpp>
    #include <iostream>
    int main()
    {
    boost::locale::generator gen;
    std::locale::global(gen(""));
    std::cout << boost::locale::as::date << std::time(0) << std::endl;
    }
    boost::locale::generator
    用于 locale 生成的主要类
    定义 generator.hpp:101
    boost::locale::as::date
    std::ios_base & date(std::ios_base &ios)
    格式化日期, 数字被视为 POSIX 时间.
    定义 formatting.hpp:188
    打印出的是数字而不是日期.
    答: 你忘记将 locale 注入 (imbue) 到流中. 修改全局 locale 不会影响已有 iostream 对象的 locale. 因此, 由于 std::out 等全局流在修改全局 locale 之前就已创建, Boost.Locale 操纵器不会生效. 你需要写成:
    #include <boost/locale.hpp>
    #include <iostream>
    int main()
    {
    boost::locale::generator gen;
    std::locale l = gen("");
    std::locale::global(l);
    std::cout.imbue(l);
    std::cout << boost::locale::as::date << std::time(0) << std::endl;
    }
