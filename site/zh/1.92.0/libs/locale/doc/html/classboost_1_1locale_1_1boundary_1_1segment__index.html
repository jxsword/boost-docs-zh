详细说明

template<typename BaseIterator>
class boost::locale::boundary::segment_index< BaseIterator >

该类持有文本范围内 segment 的索引, 并允许对其进行迭代.

该类提供 begin() 和 end() 成员函数, 返回指向 segment 对象的双向迭代器.

它提供两个关于 segment 选取方式的选项:

  • rule(rule_type mask) - 一个掩码, 允许按 word_any 等各种掩码只选取特定类型的 segment.
    默认选取所有类型的边界.
    例如: 使用单词边界分析时, 若提供的掩码为 word_kana, 迭代器将只遍历包含假名字母的单词, 而 word_any 会选取所有类型的单词, 排除由空白和标点符号组成的范围. 因此, 使用 word_any 规则遍历文本 "to be or not to be?" 将返回 segment "to", "be", "or", "not", "to", "be", 而不是默认的 "to", " ", "be", " ", "or", " ", "not", " ", "to", " ", "be", "?".
  • full_select(bool how) - 一个标志, 定义当前一边界点的规则不符合所选规则时范围如何选取.
    例如: 我们想从以下文本中提取全部句子: "Hello! How\nare you?".
    该文本包含三个按不同规则将其分隔为句子的边界点:
    • 感叹号 "!" 结束了句子 "Hello!"
    • 把句子 "How\nare you?" 分成两部分的换行符.
    • 结束第二个句子的问号.
      如果只把 rule() 改为 sentence_term, 那么 segment_index 将提供两个句子 "Hello!" 和 "are you?", 因为只有它们实际以所需的终止符 "!" 或 "?" 结束. 但若把 full_select() 改为 true, 选取的 segment 将包含直到上一个有效边界点的全部文本, 并返回两个预期的句子: "Hello!" 和 "How\nare you?".

该类允许使用 find() 成员函数, 根据范围内的给定迭代器查找 segment.

注释
  • 更改任何选项 - rule() 或 full_select(), 以及重新为文本建立索引, 都会使现有迭代器失效, 之后无法再使用.
  • segment_index 可由 boundary_point_index 或以相同 boundary_type 创建的其他 segment_index 构造. 由于二者共享同一索引, 这是非常快速的操作, 无需重新生成索引.
