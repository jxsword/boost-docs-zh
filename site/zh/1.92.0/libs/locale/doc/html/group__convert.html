详细说明

本模块提供多种字符串操作函数, 如 Unicode 规范化、大小写转换等.

枚举类型文档

◆ norm_type

enum boost::locale::norm_type

定义 规范化形式 的类型

枚举成员
norm_nfd 

规范分解.

norm_nfc 

规范分解后接规范组合.

norm_nfkd 

兼容分解.

norm_nfkc 

兼容分解后接规范组合.

norm_default 

默认规范化 - 规范分解后接规范组合.

◆ normalize() [1/3]

template<typename CharType>
std::basic_string< CharType > boost::locale::normalize ( const CharType * begin,
const CharType * end,
norm_type n = norm_default,
const std::locale & loc = std::locale() )

按 规范化形式 n 对范围 [begin,end) 内的 Unicode 字符串进行规范化

注: 该函数只接受 Unicode 字符串, 即 UTF-8, UTF-16 或 UTF-32. 它不考虑 locale 编码, 因为 Unicode 分解与组合在 Unicode 字符集之外没有意义.

异常
std::bad_castloc 未安装 converter 刻面
