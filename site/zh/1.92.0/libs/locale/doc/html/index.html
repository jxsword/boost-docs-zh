Boost.Locale 是什么?

Boost.Locale 是一个在 C++ 中提供高质量本地化设施的库. 它最初作为 CppCMS (C++ Web 框架项目) 的一部分设计, 后来贡献给了 Boost.

Boost.Locale 为开发跨平台本地化软件提供了强大工具 - 即用用户的语言与之交流的软件.

特性:

  • 正确的大小写转换、大小写折叠与规范化.
  • 排序 (sorting), 包括对 4 个 Unicode 排序级别的支持.
  • 日期、时间、时区与日历操作、格式化与解析, 包括对格里高利历以外历法的透明支持.
  • 字符、单词、句子与换行的边界分析.
  • 数字格式化、拼写与解析.
  • 货币格式化与解析.
  • 强大的消息格式化 (字符串翻译) 功能, 包括对复数形式的支持, 使用 GNU 消息目录.
  • 字符集转换.
  • 对 Latin1 等 8 位字符集的透明支持.
  • 对 char 和 wchar_t 的支持.
  • 对 C++11 char16_t 与 char32_t 字符串和流的实验性支持.

Boost.Local 补充了标准库的 API, 使编写跨平台与"跨文化"软件变得容易.

为实现这一目标, Boost.Locale 使用了最先进的 Unicode 与本地化库: ICU (International Components for Unicode).

Boost.Locale 在 C++ locale 框架、iostreams 与强大的 ICU 库之间建立了自然的粘合.

Boost.Locale 也提供不基于 ICU 的本地化支持. 它基于操作系统原生 API 或标准 C++ 库的支持. 以牺牲一些较次要的特性为代价, Boost.Locale 功能较弱, 但更轻量、更易部署.

字符集转换也可通过轻量的 IConv 库提供. 当其不可用时, 会使用 ICU 或操作系统原生 API.

警告
Apple macOS 上的系统 IConv 库可能不符合 GNU 规范, 在编码转换期间可能导致意外结果. 强烈建议使用 HomeBrew 提供的 GNU IConv.
