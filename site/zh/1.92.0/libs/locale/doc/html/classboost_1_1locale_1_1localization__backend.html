详细说明

该类表示一个可用于应用程序本地化的本地化后端.

后端通常注册在本地化后端管理器中, 支持透明地使用不同后端, 因此用户只需把应用程序链接到正确的后端即可切换后端.

后端可能支持不同的调优选项, 但以下是所有后端都提供给用户的默认选项

  1. locale - POSIX 格式的 locale 名称, 如 en_US.UTF-8
  2. use_ansi_encoding - 在 Windows 下默认使用 ANSI 代码页而非 UTF-8 选择系统 locale
  3. message_path - 消息目录所在位置的路径 (字符串向量)
  4. message_application - 使用消息目录的应用程序名称 (字符串向量)

每个后端可以以不同的默认优先级安装, 因此当你使用两个不同的后端时, 可以指定优先级, 将根据优先级选择此后端.
