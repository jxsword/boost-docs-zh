template<typename Char>
class boost::locale::boundary::boundary_indexing< Char >

该刻面为给定文本的边界分析生成索引.

它为受支持的字符类型实现, 至少包括 char, wchar_t

纯虚

为边界类型 t 创建范围 [begin,end) 内文本的索引

返回值是 index_type 类型的索引. 注意该索引永不为空, 即使范围 [begin,end) 为空, 它也至少由一个偏移量为 0 的边界点组成.
