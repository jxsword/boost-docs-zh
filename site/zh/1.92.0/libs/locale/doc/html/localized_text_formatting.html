Boost.Locale
本地化文本格式化

iostream 操纵器非常有用, 但当我们为用户创建消息时, 有时需要类似久经考验的 printf 或 boost::format 的东西.

遗憾的是, boost::format 在本地化场景中有几个限制:

  1. 它使用全局 locale 而不是目标 ostream locale 渲染所有参数. 例如:
    std::locale::global(std::locale("en_US.UTF-8"));
    output.imbue(std::locale("de_DE.UTF-8"))
    output << boost::format("%1%") % 1234.345;

    这会向输出写入 "1,234.235", 而不是 "de_DE" locale 所期望的 "1.234,234".
  2. 它对 Boost.Locale 操纵器一无所知.
  3. printf-like 语法对格式化复杂的本地化数据非常受限, 不允许格式化日期、时间或货币

因此引入了一个新类 boost::locale::format. 例如:

wcout << wformat(L"Today {1,date} I would meet {2} at home") % time(0) % name <<endl;

每个格式说明符都包含在 {} 括号内, 以逗号 "," 分隔, 并且可以在等号 '=' 之后带有附加选项. 该选项可以是简单的 ASCII 文本或单引号括起的本地化文本. 如果文本中需要插入单引号, 可以用一对单引号字符表示.

下面是一个格式字符串的示例:

    "Ms. {1} had arrived at {2,ftime='%I o''clock'} at home. The exact time is {2,time=full}"

语法由以下文法描述:

    format : '{' parameters '}'
    parameters: parameter | parameter ',' parameters;
    parameter : key ["=" value] ;
    key : [0-9a-zA-Z<>]+ ;
    value : ascii-string-excluding-"}"-and="," | local-string ;
    local-string : quoted-text | quoted-text local-string;
    quoted-text : '[^']*' ;

可以在文本中插入 "{{" 或 "}}" 来包含字面量 '{' 和 '}'.

cout << format(translate("Unexpected `{{' in line {1} in file {2}")) % pos % file;

将显示类似如下内容:

Unexpected `{' in line 5 in file source.cpp

支持以下格式键值对:

  • [0-9]+ - 数字, 被格式化参数的索引 - 必需.
  • num 或 number - 格式化数字. 选项有:
    • hex - 以十六进制格式显示
    • oct – 以八进制格式显示
    • sci 或 scientific – 以科学计数格式显示
    • fix 或 fixed - 以定点格式显示
      例如, number=sci
  • cur 或 currency - 格式化货币. 选项有:
    • iso – 使用 ISO 货币符号显示.
    • nat 或 national - 使用本国货币符号显示.
  • per 或 percent - 格式化百分比值.
  • date, time, datetime 或 dt - 格式化日期、时间或日期与时间. 选项有:
    • s 或 short - 以短格式显示.
    • m 或 medium – 以中等格式显示.
    • l 或 long – 以长格式显示.
    • f 或 full – 以完整格式显示.
  • ftime 带字符串 (带引号) 参数 - 显示方式与 strftime 相同. 见 as::ftime 操纵器.
  • spell 或 spellout – 拼写出数字.
  • ord 或 ordinal - 格式化序数 (1st, 2nd... 等)
  • left 或 < - 左对齐.
  • right 或 > - 右对齐.
  • width 或 w – 设置字段宽度 (需要参数).
  • precision 或 p – 设置精度 (需要参数).
  • locale - 带参数 - 为当前操作切换 locale. 该命令会生成带格式化刻面的 locale, 提供更细粒度的格式化控制. 例如:
    cout << format("This article was published at {1,date=l} (Gregorian) {1,locale=he_IL@calendar=hebrew,date=l} (Hebrew)") % date;
  • timezone 或 tz – 用于显示时间的时区名称. 例如:
    cout << format("Time is: Local {1,time}, ({1,time,tz=EET} Eastern European Time)") % date;
  • local - 以本地时间显示时间
  • gmt - 以 UTC 时标显示时间
    cout << format("Local time is: {1,time,local}, universal time is {1,time,gmt}") % time;

format 类的构造函数可以接受 message 类型的对象, 简化与消息翻译代码的集成.

例如:

cout<< format(translate("Adding {1} to {2}, we get {3}")) % a % b % (a+b) << endl;

可以用 str(std::locale const &loc=std::locale()) 成员函数直接获取格式化后的字符串. 例如:

std::wstring de = (wformat(translate("Adding {1} to {2}, we get {3}")) % a % b % (a+b)).str(de_locale);
std::wstring fr = (wformat(translate("Adding {1} to {2}, we get {3}")) % a % b % (a+b)).str(fr_locale);
注释
boost::format 与 boost::locale::format 之间有一个显著区别: Boost.Locale 的 format 只在写入 ostream 或调用 str() 成员函数时才转换其参数. 它只保存可写入流的对象的引用.

当所有操作都在一条语句中完成时, 这通常不是问题, 例如:

cout << format("Adding {1} to {2}, we get {3}") % a % b % (a+b);

因为 (a+b) 的临时值在格式化数据真正写入流之前一直存在. 但下面的代码是错误的:

format fmt("Adding {1} to {2}, we get {3}");
fmt % a;
fmt % b;
fmt % (a+b);
cout << fmt;

因为 (a+b) 的临时值在 fmt 写入流时已不存在. 正确的解决方案是:

format fmt("Adding {1} to {2}, we get {3}");
fmt % a;
fmt % b;
int a_plus_b = a+b;
fmt % a_plus_b;
cout << fmt;
