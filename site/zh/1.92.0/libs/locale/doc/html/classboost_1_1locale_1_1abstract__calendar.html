详细说明

该类定义通用日历类, 由 date_time 和日历对象在内部使用. 它对最终用户用处不大, 但它是为本地化后端实现而构建的

enum boost::locale::abstract_calendar::update_type

更新值的一种方式.

枚举成员
move 

上下改变值并影响其他字段, 例如 1990-12-31 + 1 天 = 1991-01-01.

roll 

上下改变值而不影响其他字段, 例如 1990-12-31 + 1 天 = 1990-12-01.

枚举成员

该时间段的实际最小值.

greatest_minimum 

该时间段可能的最大最小值.

current 

该时间段的当前值.

least_maximum 

该时间段的最大值下限, 例如格里高利历的日为 28

actual_maximum 

实际最大值, 例如日可根据当前月份为 28, 29, 30, 31.

absolute_maximum 

最大值, 格里高利历的日为 31.

◆ set_value()

virtual void boost::locale::abstract_calendar::set_value ( period::marks::period_mark m,
int value )
纯虚

设置 value 为时间段 p 的特定值, 注意并非所有值都可设置.

调用 set_value 之后, 你可能需要调用 normalize() 函数以确保所有时间段都已更新; 如果你设置了属于同一日期/时间表示的多个字段, 应多次调用 set_value, 然后调用 normalize().

若在 set_value 之后未调用 normalize(), 则行为未定义
