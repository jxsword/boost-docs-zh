Boost.Locale
在 Microsoft Windows 下运行示例

Boost.Locale 自带的所有示例都是针对 UTF-8 设计的; 它是 Boost.Locale 使用的默认编码.

但是, Microsoft Windows 下默认的窄编码不是 UTF-8, 应用程序的输出将无法在控制台中正确显示.

要在 Windows 控制台中使用 UTF-8 编码并正确查看输出, 请执行以下操作:

  1. 打开一个 cmd 窗口
  2. 将默认字体更改为 TrueType 字体: 进入 properties->font (在标题栏上右键->properties->font), 并把字体更改为 Lucida Console 之类的 TrueType 字体
  3. 将默认代码页更改为 65001 (UTF-8): 运行 chcp 65001

现在所有示例都应能正确显示 UTF-8 字符 (前提是字体支持它们).

Visual Studio 用户注意: Microsoft Visual Studio 假定所有源文件都使用类似 1252 的 "ANSI" 代码页编码. 但所有示例默认都使用 UTF-8 编码, 因此宽字符示例在 MSVC 下原样编译无法工作. 要强制它将源文件视为 UTF-8, 需要把文件转换为带 BOM 的 UTF-8, 这很容易做到: 只要用记事本重新保存文件即可, 记事本默认会为 UTF-8 文件添加 BOM.
