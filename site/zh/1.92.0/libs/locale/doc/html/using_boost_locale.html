Boost.Locale
使用 Boost.Locale

本节将主要讨论 ICU 后端, 因为它既是默认后端, 也是本库提供的最强大的本地化后端. 在后续章节中, 我们会说明其他本地化后端所支持的特性.

  • locale 生成
  • 排序
  • 文本转换
  • 数字、时间与货币的格式化与解析
  • 消息格式化 (翻译)
  • 字符集转换
  • 边界分析
  • 本地化文本格式化
  • 处理日期、时间、时区与日历.
  • 获取当前 locale 的信息
  • 使用多个 locale
