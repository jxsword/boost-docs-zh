Boost.Locale
变更日志
  • 1.88.0
    • 修复将浮点格式的数字解析为整数的问题
    • 要求 ICU 4.2 或更高版本
  • 1.86.0
    • 使 to_title 的 ICU 实现线程安全
    • 添加分配器支持到 utf_to_utf
  • 1.85.0
    • 破坏性变更
      • collator 不再派生自 std::collator, 避免可能的类型混淆
      • date_time 在 ICU 后端中以秒精度存储时间, Boost 1.81 中加入/修复了亚秒精度
      • comparator 出错时现在会在构造时抛出, 而不是如文档所述在使用时抛出
      • 使用 IConv 进行字符编码转换时, 若检测到所用 IConv 库有缺陷, 将抛出 std::runtime_error (而不是陷入无限循环)
  • 1.84.0
    • 破坏性变更
      • to_title 对于 WinAPI 后端, 返回原字符串不变, 而不是空字符串
  • 1.83.0
    • 破坏性变更
      • 消息目录文件不再支持位运算/二元运算符 (左/右移位, 按位与/或/异或/非), 以匹配 GNU gettext 的行为
      • 当所请求的 locale 不存在时, Windows 上的 std 后端使用 classic locale 而非系统 locale (现在与其他操作系统上相同)
      • localization_backend_manager::get 已弃用, 应替换为 localization_backend_manager::create 或直接使用生成器
    • 其他改进与修复
      • 引入转换器类, 替代 to_utf/from_utf/between
      • 修复格式化字符串中无效索引导致的未定义行为
      • 修复在无 ICU 的 Windows 上向 iso-2022-jp 等编码的 UTF 转换
      • 使用 long long 作为复数翻译的计数参数
      • 使 localization_backend_manager 可移动
      • 为移动赋值/构造函数补上缺失的 noexcept
  • 1.82.0
    • 破坏性变更
      • get_system_locale 及其依赖现在会按 POSIX 的定义, 正确地优先使用 $LC_ALL 而非 LC_CTYPE
      • utf8_codecvt::out 对尾部 (UTF) 代理项返回 partial
    • 其他改进与修复
      • 添加 boost::locale::util::locale_data 用于解析 locale
      • boost::locale::info::encoding() 的结果按文档为大写, 例如 "UTF-8" 而非 "utf-8"
      • 支持 M49 国家/地区代码, 如 en_001 或 en_150
      • 将 en_US_POSIX 视作 C locale 的别名
  • 1.81.0
    • 破坏性变更
      • 要求 C++11 或更高版本
      • 代码现代化 (以 C++11 特性替代 Boost 替代品, 统一格式化)
      • 使用 -sICU_LINK_LOCALE 和 -sICU_LINK 时报错; 当 -sICU_PATH 不够用时, 改用 -sICU_*_NAME
      • 把 character_facet_type 和 locale_category_type 转换为枚举类 char_facet_t 与 category_t
    • 其他改进与修复
      • 修复使用 iconv 在 macOS 上的构建
      • 修复年份负回绕导致的 int 溢出, 位于 date_time
      • 假定并使用 UTF-16 编码的 Windows wchar_t-codecvt
      • 修复日历时间的舍入问题
      • 使 basic_format 可移动, 允许从函数中返回它
      • 修复 Windows 上 iso-2022-jp 等代码页的转换
      • 添加更多 Windows 代码页, 如 cp1025, 以及各种 ISO 和 IBM 代码页
      • 性能改进
  • 1.80.0
    • 弃用对 C++03 及更早版本的支持, 下一个发布将要求 C++11
    • 提供 -sICU_LINK_LOCALE 作为 -sICU_LINK 的临时替代, 后者与 Boost.Regex 不兼容.
    • -sICU_LINK_LOCALE 与 -sICU_LINK 已弃用, 将由 ICU_*_NAME 选项取代, 以兼容 Boost.Regex
    • 修复 ICU collator 实现在变换空字符串时的未定义行为/断言失败
    • 修复与共享库中类可见性相关的一些问题 (仅 Unix)
    • 修复与 C++20 模式的兼容性
    • 兼容 BOOST_USE_WINDOWS_H
    • 修复因缺少 include 导致的构建失败
    • 处理或抑制许多警告, 使构建日志更整洁
  • 1.67.0
    • 除 C++2003 的 auto_ptr 外, 还添加了对 unique_ptr 接口的支持 - 为了支持 C++2017, 现在你可以使用 BOOST_LOCALE_HIDE_AUTO_PTR 定义从接口中移除 auto_ptr, 并避免出现弃用警告
    • 修复 ICU >60.1 的测试问题
    • 修复 solaris 构建
    • 修复优化构建时的怪异 FreeBSD/clang 问题. 可能是编译器的变通方法
    • 为因 932 代码页 codecvt 问题而失败的 MSVC 测试添加了变通方法
    • 修复缺陷 6851, 12572, 12453
    • 修复 ICU/date_time 失败时缺失的 throw
    • 修复针对 Boost.Thread v4 的构建
    • 修复 ICU 后端格式化中使用周年份而非年份的问题
    • 修复 ICU 56.1 及以上版本的格式化测试
  • 1.60.0
    • 实现通用 codecvt 刻面, 并添加通用用途的 utf8_codecvt 刻面
    • 为 FreeBSD 10.0 及以上版本添加 POSIX locale 支持
    • 修复问题 10017 (SunOS 上的 sun 重定义), 11163 (set_default_messages_domain 行为不正确), 11673 - 构建问题
    • 一些警告清理
    • 修复最新 ICU 版本的测试
    • 为 libc++ 的问题添加变通方法
    • 添加新定义 BOOST_LOCALE_ENABLE_CHAR16_T 和 BOOST_LOCALE_ENABLE_CHAR32_T, 以启用 C++11 的 char16_t 和 char32_t, 替代已弃用的定义
  • 1.53.0 - 缺陷修复: 7743, 7386, 7734, 7701, 7368, 7762:
    • 7743 - 安全相关缺陷修复, 一些无效的 UTF-8 序列曾被当作有效序列接受
    • 7386 - 修复使用了无效的 Windows 代码页名称
    • 7734 - 修复缺失的文档, 由 Doxygen 格式化错误导致
    • 7701 - 修复了部分位置缺失的 std::
    • 7368, 7762 - 拼写、语法、笔误
  • 1.49.0
    • 修复在检测无效输入序列时对 MultiByteToWideChar 的错误使用
  • 1.48.0 - 首次发布
