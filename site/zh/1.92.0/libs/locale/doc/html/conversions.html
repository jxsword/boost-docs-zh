Boost.Locale
文本转换

Boost.Locale 提供了多个用于基本字符串操作的函数:

  • to_upper: 将字符串转换为大写
  • to_lower: 将字符串转换为小写
  • to_title: 将字符串转换为标题式大小写
  • fold_case: 使字符串不区分大小写 (参见 大小写折叠)
  • normalize: 将等价的码点转换为一致的二进制形式 (规范化)

所有这些函数都接收一个 std::locale 对象作为参数, 或默认使用全局 locale.

以下所有示例均使用全局 locale.

大小写处理

例如:

std::string grussen = "grüßEN";
std::cout <<"Upper "<< boost::locale::to_upper(grussen) << std::endl
<<"Lower "<< boost::locale::to_lower(grussen) << std::endl
<<"Title "<< boost::locale::to_title(grussen) << std::endl
<<"Fold "<< boost::locale::fold_case(grussen) << std::endl;

Boost.StringAlgo 库中已有 to_upper 和 to_lower 函数, 但 Boost.Locale 的函数作用于整个字符串, 而不会执行不正确的逐字符转换.

例如:

std::wstring grussen = L"grüßen";
std::wcout << boost::algorithm::to_upper_copy(grussen) << " " << boost::locale::to_upper(grussen) << std::endl;

输出结果为:

GRÜßEN GRÜSSEN

其中第一种情况下, 由于 std::ctype 刻面的限制, 字母 "ß" 未被正确转换为双 S.

在 UTF-8 编码下问题更为严重, 非 US-ASCII 字符根本不会被转换. 例如, 以下代码:

std::string grussen = "grüßen";
std::cout << boost::algorithm::to_upper_copy(grussen) << " " << boost::locale::to_upper(grussen) << std::endl;

只会修改 ASCII 字符

GRüßEN GRÜSSEN

Unicode 规范化

Unicode 规范化是将字符串转换为标准形式的过程, 以便进行文本处理与比较. 例如, 字符 "ü" 既可以用单个码点表示, 也可以用字符 "u" 与分音符 "¨" 的组合表示. 规范化是 Unicode 文本处理的重要组成部分.

Unicode 定义了四种规范化形式. 每种具体形式由传递给 normalize 函数的标志选择:

  • NFD - 规范分解 - boost::locale::norm_nfd
  • NFC - 规范分解后接规范组合 - boost::locale::norm_nfc 或 boost::locale::norm_default
  • NFKD - 兼容分解 - boost::locale::norm_nfkd
  • NFKC - 兼容分解后接规范组合 - boost::locale::norm_nfkc

有关规范化形式的更多细节, 请阅读 unicode.org 上的这份报告.

注释

  • normalize 只能作用于 Unicode 编码的字符串, 即根据字符宽度分别为 UTF-8、UTF-16 和 UTF-32. 因此使用非 UTF 编码时要小心, 它们可能被不正确地处理.
  • fold_case 通常是与 locale 无关的操作, 但它接收一个 locale 作为参数以确定 8 位编码.
  • 所有这些函数都可以处理 STL 字符串、以 NULL 结尾的字符串, 或由两个指针定义的范围. 它们总是返回一个新建的 STL 字符串.
  • 字符串的长度可能改变; 参见上面的示例.
