详细说明

该类表示一个简单的无状态转换器, 对每个单一码点在 UCS-4 与本地编码之间转换.

此类用于创建 std::codecvt 刻面, 将 utf-16/utf-32 编码转换为此转换器支持的编码

请注意, 此转换器应完全无状态. 完全无状态意味着它绝不应假定会按任何特定顺序对文本调用. 即使编码本身看似无状态 (如 windows-1255 或 shift-jis), 某些编码器 (尤其是 iconv) 在发现组合字符时, 实际上也可能把多个码点组合为一个或将其分解. 因此为特定字符集实现这些转换器时要非常小心.

把单个码点 u 转换为目标编码并存储在 [begin,end) 范围内.

若 u 是无效的 Unicode 码点, 或无法正确映射到所表示的字符集, 则应返回 illegal

若 u 可以转换为字节序列 c1, ... , cN (1<= N <= max_len() ), 则

  1. 若 end - begin >= N, 则从 begin 起写入 c1, ... cN 并返回 N
  2. 若 end - begin < N, 则返回 incomplete, [begin,end) 范围内的字节将存储什么内容未作规定

若调用 from_unicode, to_unicode 和 max_len 函数是线程安全的, 则返回 true.

经验法则: 若此类的实现使用不变的简单表, 或像 UTF-8 一样纯算法化 - 即独立的 to_unicode, from_unicode 调用不共享任何可变状态, 则可以将其设为 true; 否则, 例如若你使用 iconv_t 描述符或 UConverter 作为转换对象, 则返回 false, 此对象将在每次使用时被克隆.

◆ to_unicode()

virtual utf::code_point boost::locale::util::base_converter::to_unicode ( const char *& begin,
const char * end )
inlinevirtual

把从 begin 开始、至多在 end 结束的单个字符转换为 Unicode 码点.

若在 [begin,code_point_end) 中找到有效输入序列, 满足 begin < code_point_end && code_point_end <= end, 则将其转换为对应的 Unicode 码点, 并把 begin 设为 code_point_end

若在 [begin,end) 中发现不完整的输入序列, 即可能存在这样的 code_point_end: code_point_end > end 且 [begin, code_point_end) 会是有效输入序列, 则返回 incomplete, begin 保持不变; 例如对于 UTF-8 转换, *begin = 0xc2 且 begin +1 = end 就是这种情况.

若发现无效输入序列, 即存在序列 [begin, code_point_end) 满足 code_point_end <= end 且对此编码非法, 则返回 illegal, begin 保持不变. 例如对于 UTF-8, 若 *begin = 0xFF 且 begin < end, 则返回 illegal.
