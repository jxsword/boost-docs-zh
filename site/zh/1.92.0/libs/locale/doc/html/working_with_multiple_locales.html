Boost.Locale
使用多个 locale

Boost.Locale 允许你在同一进程中安全地使用多个 locale. 如前所述, locale 生成过程的代价不小. 因此, 当我们使用多个 locale 并需要在它们之间切换时, 建议在程序启动时创建所需的全部 locale.

为简化这一过程, boost::locale::generator 类提供了缓存所有已生成 locale 的选项. 启用该选项后, 当你创建一个先前已生成过的 locale 时, 它会从现有的 locale 集合中获取. 该操作是线程安全的.

该选项必须通过调用 locale_cache_enabled 成员函数来显式启用, 它属于 boost::locale::generator, 调用时以 true 作为参数.

例如:

generator gen;
gen.locale_cache_enabled(true);
gen("en_US.UTF-8");
gen("de_DE.UTF-8");
gen("ja_JP.UTF-8");
// 创建所有 locale
std::locale en=gen("en_US.UTF-8");
// 从缓存中获取现有 locale
std::locale ar=gen("ar_EG.UTF-8");
// 由于 ar_EG 不在缓存中, 会生成 (并缓存) 一个新 locale

然后这些 locale 可以被注入到 iostreams, 或直接用作各种函数的参数.
