Boost.Locale
在 Windows 上使用 Gettext 工具

要在 Windows 上获得 msgfmt、msgmerge、xgettext 等 Gettext 工具, 有几种选择:

  • 从 CppCMS 下载软件包 (Boost.Locale 最初就是在那里开发的)
  • 从 MinGW 项目下载一组软件包
  • 自行构建
  • 使用 Cygwin 的软件包

从 CppCMS 获取 Gettext 工具

Boost.Locale 是为 CppCMS 的需求而开发的, 因此 CppCMS 为 Windows 用户托管了一个便捷软件包, 内含预构建、静态链接的 gettext 运行时工具, 如 xgettext、msgfmt 等.

可以从 CppCMS 下载页面下载 zip 文件 gettext-tools-static-XXX.zip, 位于 boost_locale/gettext_for_windows 之下.

解压该文件并使用其中的可执行文件.

通过 MinGW 获取 Gettext

MinGW 项目为 Windows 提供 GNU 工具, 包括 GNU 编译器和各种运行时工具. 因此你始终可以安装包含 gettext 工具的完整 MinGW 发行版. 但如果你想要一个能够提取消息并创建目录的精简运行时版本, 则需要手动下载几个软件包.

要通过 MinGW 安装 Gettext, 你需要下载 GCC 运行时、iconv 库以及 Gettext 本身.

因此请访问 MinGW 的 下载页面 并下载以下文件 (每个软件包选择最新版本):

  • 来源: MinGW/BaseSystem/GCC/Version4/gcc-xxx/
    文件: libgcc-xxx-mingw32-dll-1.tar.lzma
  • 来源 MinGW/Gettext/gettext-yyy/
    文件: gettext-yyy-mingw32-dev.tar.lzma, libgettextpo-yyy-mingw32-dll-0.tar.lzma, libintl-yyy-mingw32-dll-8.tar.lzma
  • 来源 MinGW/libiconv/libiconv-zzz/
    文件: libiconv-zzz-mingw32-dll-2.tar.lzma, libcharset-zzz-mingw32-dll-1.tar.lzma

例如, 2011 年 6 月 23 日时是:

  • GNU 运行时: libgcc-4.5.2-1-mingw32-dll-1.tar.lzma
  • iconv: libiconv-1.13.1-1-mingw32-dll-2.tar.lzma 和 libcharset-1.13.1-1-mingw32-dll-1.tar.lzma
  • gettext: libintl-0.17-1-mingw32-dll-8.tar.lzma, libgettextpo-0.17-1-mingw32-dll-0.tar.lzma 和 gettext-0.17-1-mingw32-dev.tar.lzma.

下载软件包后, 使用 7zip 等工具把所有文件解压到同一目录, 即可得到所需的全部可执行文件和 dll's, 它们都位于 bin 子目录之下.

注释
MinGW 站点上的版本略显过时 (0.17.1), 而 Gettext 当前提供 0.18.1.

自行构建最新版本.

你可以使用 MinGW 环境构建自己的 GNU Gettext 版本. 你需要有一个较新的 gcc 编译器和 shell. 需要先安装 iconv, 然后用它构建 Gettext.

最简单的方式是打开一个 MinGW shell.

构建 iconv:

cd libiconv-SOMEVERSION
./configure --prefix=c:/mygettext --disable-shared
make
make install
cd ..
cd gettext-SOMEVERSION
./configure --prefix=c:/mygettext --disable-shared --with-libiconv-prefix=c:/mygettext
make
make install

现在, c:\mygettextin 中已有所有合适的可执行文件可供使用.

使用 Cygwin

如果你已经有 Cygwin - 直接使用其自带的 Gettext 工具即可.
