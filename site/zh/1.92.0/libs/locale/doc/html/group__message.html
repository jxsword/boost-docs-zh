◆ convert()

template<typename CharType>
virtual const char_type * boost::locale::message_format< CharType >::convert ( const char_type * msg,
string_type & buffer ) const
纯虚

将字符串 msg 转换为目标 locale 的编码. 如果 msg 已是目标编码, 则直接返回它; 否则转换后的字符串存入临时 buffer, 并返回 buffer.c_str().

注: 对于 char16_t, char32_t 和 wchar_t 类型的 char_type, 该操作为空操作, 直接返回 msg

◆ get() [1/2]

template<typename CharType>
virtual const char_type * boost::locale::message_format< CharType >::get ( int domain_id,
const char_type * context,
const char_type * id ) const
纯虚

该函数返回由 context 与标识字符串 id 所定义消息对应的字符串指针. 二者共同构成在 domain_id 所定义域中查找消息的单一键.

如果 context 为 NULL, 则不将其视为键的一部分

若找到翻译后的字符串, 则返回它, 否则返回 NULL
