Boost.Locale
locale 生成

每个 locale 由特定的 locale 标识符定义, 它包含一个必需部分 (Language) 和多个可选部分 (Country, Variant, 关键字以及 std::string 的字符编码). Boost.Locale 对 locale 采用 POSIX 命名约定, 即 locale 定义为 language[_COUNTRY][.encoding][@variant], 其中 lang 是 ISO-639 语言名称, 如 "en" 或 "ru"; COUNTRY 是 ISO-3166 国家/地区标识符, 如 "US" 或 "DE"; encoding 是 8 位字符编码, 如 UTF-8 或 ISO-8859-1; variant 是用于特化 locale 的附加选项, 如 euro 或 calendar=hebrew, 见 变体.

注意, 为正确处理基于 char 的字符串, 每个 locale 都应包含编码.

基础

generator 类提供生成所需 locale 的工具. 使用 generator 最简单的方式是创建一个 locale 并将其设为全局 locale:

#include <boost/locale.hpp>
using namespace boost::locale;
int main()
{
generator gen;
// 创建 locale 生成器
std::locale::global(gen(""));
// "" - 系统默认 locale, 将其设
// 为全局 locale
}

注释
  • 即使你的应用程序处处使用宽字符串, 你也应指定用于 8 位流 I/O 操作 (如 cout 或 fstream) 的 8 位编码.
  • 默认 locale 由环境变量 LC_ALL , LC_CTYPE 和 LANG 按此顺序定义 (即 LC_ALL 优先, LANG 最后). 在 Windows 上, 当这些变量未设置时, 本库还会查询 Win32 API 中的 LOCALE_USER_DEFAULT 选项.

提示: 建议优先使用 UTF-8 Unicode 编码, 而非 ISO-8859-X 等 8 位编码.

默认情况下, 生成的 locale 包含所有支持的类别与字符类型. 不过, 如果你的应用程序只用 8 位编码、只用宽字符编码, 或只用特定刻面, 你可以调用 generator 类的 categories 与 characters 成员函数, 将刻面生成限制在特定类别与字符类型上.

例如:

generator gen;
gen.characters(char_facet_t::wchar_f);
gen.categories(collation_facet | formatting_facet);
std::locale::global(gen("de_DE.UTF-8"));

变体

locale 的变体部分 (@ 符号之后的部分) 取决于本地化 后端.

非 ICU 后端

POSIX 与 std 后端使用各自操作系统专属的命名约定, 并依赖当前操作系统配置. 例如, 典型 Linux 发行版提供 euro 用于选择货币, cyrillic 与 latin 用于指定语言文字.

winapi 后端不支持任何变体.

ICU 后端

ICU 提供了广泛的 locale 变体选项. 详细说明请阅读 这些 ICU 手册页面.

不过总体而言, 它表示为一组以分号 ";" 分隔的 key=value 对. 例如: "@collation=phonebook;calendar=islamic-civil".

目前 ICU 支持以下键:

  • calendar - 当前 locale 使用的日历. 例如: gregorian, japanese, buddhist, islamic, hebrew, chinese, islamic-civil.
  • collation - 该 locale 使用的排序次序, 例如 phonebook, pinyin, traditional, stroke, direct, posix.
  • currency - 该 locale 使用的货币, 标准 3 字母代码, 如 USD 或 JPY.
  • numbers - 使用的记数系统, 例如: latn, arab, thai.

键与值的准确列表请参阅 CLDR 与 ICU 文档:
