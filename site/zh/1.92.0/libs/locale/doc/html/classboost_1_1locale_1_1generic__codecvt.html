详细说明

template<typename CharType, typename CodecvtImpl, int CharSize = sizeof(CharType)>
class boost::locale::generic_codecvt< CharType, CodecvtImpl, CharSize >

通用 codecvt 刻面, 使用 wchar_t, char32_t 和 char16_t 将各种无状态编码转换为 UTF-16 和 UTF-32.

实现应派生自此类, 把自身定义为 CodecvtImpl, 并提供以下成员

  • state_type - 一种特殊对象的类型, 允许存储中间缓存数据, 例如 iconv_t 描述符
  • state_type initial_state(generic_codecvt_base::initial_convertion_state direction) const - 创建初始状态的成员函数
  • int max_encoding_length() const - 表示一个 Unicode 码点的最大长度, 例如 UTF-8 为 4, ISO-8859-1 为 1
  • utf::code_point to_unicode(state_type& state, const char*& begin, const char* end) - 从范围 [begin,end) 内的文本中提取第一个码点; 成功时 begin 将指向下一个要编码为下一码点的字符序列; 序列不完整时返回 utf::incomplete; 输入序列无效时返回 utf::illegal, 且 begin 保持不变
  • utf::len_or_error from_unicode(state_type &state, utf::code_point u, char* begin, const char* end) - 将 Unicode 码点 u 转换为 [begin,end) 处的字符序列. 成功时返回序列长度; 空间不足以编码该码点时返回 utf::incomplete; 无法执行转换时返回 utf::illegal

例如, latin1/ISO-8859-1 字符集的 codecvt 实现

template<typename CharType>
class latin1_codecvt: boost::locale::generic_codecvt<CharType,latin1_codecvt<CharType> >
{
public:
/* 标准 codecvt 构造函数 */
latin1_codecvt(size_t refs = 0): boost::locale::generic_codecvt<CharType,latin1_codecvt<CharType> >(refs)
{
}
/* State 未使用, 但 generic_codecvt 要求它 */
struct state_type {};
state_type initial_state(generic_codecvt_base::initial_convertion_state /*unused*/) const
{
return state_type();
}
int max_encoding_length() const
{
return 1;
}
boost::locale::utf::code_point to_unicode(state_type&, const char*& begin, const char* end) const
{
if(begin == end)
return boost::locale::utf::incomplete;
return *begin++;
}
boost::locale::utf::len_or_error from_unicode(state_type&, boost::locale::utf::code_point u,
char* begin, const char* end) const
{
if(u >= 256)
return boost::locale::utf::illegal;
if(begin == end)
return boost::locale::utf::incomplete;
*begin = u;
return 1;
}
};
