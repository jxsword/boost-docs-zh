Boost.Locale
字符集转换

便捷接口

Boost.Locale 提供 to_utf, from_utf 和 utf_to_utf 函数, 位于 boost::locale::conv 命名空间. 它们是在 UTF-8/16/32 与其他编码之间进行转换的简单便捷函数.

例如:

std::string utf8_string = to_utf<char>(latin1_string,"Latin1");
std::wstring wide_string = to_utf<wchar_t>(latin1_string,"Latin1");
std::string latin1_string = from_utf(wide_string,"Latin1");
std::string utf8_string2 = utf_to_utf<char>(wide_string);

这些函数接受显式的编码名称 (如 "Latin1" 或 "ISO-8859-8"), 或接受用于获取编码的 std::locale. 它们还接受一个策略参数, 用于决定无法执行转换时 (即发现非法或不受支持的字符) 的处理方式. 默认情况下, 这些函数会跳过所有非法字符并尽力而为. 但也可能抛出 conversion_error - 当传入 stop 标志时:

std::wstring s=to_utf<wchar_t>("\xFF\xFF","UTF-8",stop);
// 抛出异常, 因为该字符串在 UTF-8 中非法

std::codecvt 刻面

Boost.Locale 提供基于 std::codecvt 刻面的流代码页转换刻面. 这允许在宽字符编码与 8 位编码 (如 UTF-8, ISO-8859 或 Shift-JIS) 之间进行转换.

大多数编译器都提供此类刻面, 但是:

  • Windows MSVC 完全不支持 UTF-8 编码.
  • 在 Linux 中, 只有生成了所需的 locale 才支持这些编码. 例如, 可能无法创建 he_IL.CP1255 locale, 即使 he_IL locale 可用.

Boost.Locale 提供一个选项, 可生成用于 Boost.Iostreams 过滤器或 std::wfstream 的代码页转换刻面. 例如:

std::locale loc= generator().generate("he_IL.UTF-8");
std::wofstream file;
file.imbue(loc);
file.open("hello.txt");
file << L"שלום!" << endl;

将创建文件 hello.txt, 以 UTF-8 编码, 其中包含 "שלום!" (shalom).

与 Boost.Iostreams 集成

你可以直接使用 std::codecvt 刻面, 但这相当棘手, 需要精确的缓冲区与错误管理.

你可以使用 boost::iostreams::code_converter 类在宽字符集与窄 locale 字符集之间进行面向流的转换.

这是一个对任意流进行宽字符到窄字符转换的示例程序:

#include <boost/iostreams/stream.hpp>
#include <boost/iostreams/categories.hpp>
#include <boost/iostreams/code_converter.hpp>
#include <boost/locale.hpp>
#include <iostream>
namespace io = boost::iostreams;
// 消费转换后文本的设备
// 在本例中它只是写入标准输出
class consumer {
public:
typedef char char_type;
typedef io::sink_tag category;
std::streamsize write(const char* s, std::streamsize n)
{
std::cout.write(s,n);
return n;
}
};
int main()
{
// 该设备将宽字符
// 转换为窄字符
typedef io::code_converter<consumer> converter_device;
// the stream that uses this device
typedef io::stream<converter_device> converter_stream;
consumer cons;
// 设置我们的转换器工作
// 使用 he_IL.UTF-8 locale
converter_device dev;
boost::locale::generator gen;
dev.imbue(gen("he_IL.UTF-8"));
dev.open(cons);
converter_stream stream;
stream.open(dev);
// 现在写入到流中的宽字符
// 将以窄字符的形式交给
// 我们的 consumer,
// 采用 UTF-8 编码
stream << L"שלום" << std::flush;
}

std::codecvt 的局限

标准并未提供关于 std::mbstate_t 的任何可用于保存中间代码页转换状态的信息. 它将该定义留给编译器实现, 导致无法为有状态编码重新实现 std::codecvt<wchar_t,char,mbstate_t>. 因此, Boost.Locale 的 codecvt 刻面实现可用于 UTF-8, ISO-8859 和 Shift-JIS 之类的无状态编码, 但不能用于 UTF-7 或 SCSU 之类的有状态编码.

建议: 在你的应用中, 对基于 char 的字符串和文件优先使用 Unicode UTF-8 编码.

注释

对于 ISO-8859-X 和 UTF-8 这样的单字节编码, codecvt 的实现非常快速高效, 但由于上述无状态问题, 对于 Shift-JIS 这样的双宽度编码, 其性能可能不是最优.
