详细说明

template<typename IteratorType>
class boost::locale::boundary::boundary_point< IteratorType >

该类表示文本中的一个边界点.

它表示一个对 - 迭代器与定义此点的规则.

boundary_point_index 的迭代器会解引用此类型对象. 使用 rule() 成员函数, 你可以得知这个特定边界点被选中的原因.

例如, 使用句子边界分析时, (rule() & sentence_term) != 0 表示此边界点因发现句末终止符 (如 .?!) 而被选中, 而 (rule() & sentence_sep)!=0 表示观察到了换行符或回车符之类的分隔符.

注释
  • 分析范围的开头始终被视为边界点, 且其规则始终为 0.
  • 使用单词边界分析时, 返回的规则与此点之前的文本块有关.
