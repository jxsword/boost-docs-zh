详细说明

template<typename BaseIterator>
class boost::locale::boundary::boundary_point_index< BaseIterator >

该类持有 边界点的索引, 并允许对其进行迭代.

该类提供 begin() 和 end() 成员函数, 返回指向 boundary_point 对象的双向迭代器.

它提供一个影响按不同规则选取边界点的选项: 使用 rule(rule_type mask) 成员函数. 它允许设置一个掩码, 只选取特定类型的边界点, 如 sentence_term.

例如, 对文本 "Hello! How\nare you?" 进行句子边界分析时, 使用默认规则得到的边界点为:

  • "|Hello! How\nare you?"
  • "Hello! |How\nare you?"
  • "Hello! How\n|are you?"
  • "Hello! How\nare you?|"

但如果把 rule() 设为 sentence_term, 则选中的边界点将是:

  • "|Hello! How\nare you?"
  • "Hello! |How\nare you?"
  • "Hello! How\nare you?|"

这样, 由换行符定义的边界点将被忽略.

该类允许使用 find() 成员函数, 根据范围内的给定迭代器查找 boundary_point.

注释
  • 即使是空文本范围 [x,x) 也被视为拥有一个边界点 x.
  • a 和 b 点 (范围 [a,b) 的两端) 始终被视为边界点, 无论使用何种规则.
  • 更改 rule() 等选项或重新为文本建立索引, 都会使现有迭代器失效, 之后无法再使用.
  • boundary_point_index 可由 segment_index 或以相同 boundary_type 创建的其他 boundary_point_index 构造. 由于二者共享同一索引, 这是非常快速的操作, 无需重新生成索引.
