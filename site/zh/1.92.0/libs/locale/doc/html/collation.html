Boost.Locale
排序

Boost.Locale 提供 collator 类, 它派生自 std::collate, 增加了对一级、二级、三级、四级和完全相同比较级别的支持. 这些级别可大致定义为:

  1. 一级 – 忽略重音符号和字符大小写, 仅比较基本字母. 例如 "facade" 与 "Façade" 相同.
  2. 二级 – 忽略字符大小写但考虑重音符号. "facade" 与 "façade" 不同, 但 "Façade" 与 "façade" 相同.
  3. 三级 – 同时考虑大小写和重音符号: "Façade" 与 "façade" 不同. 忽略标点符号.
  4. 四级 – 考虑所有大小写、重音符号和标点符号. 单词在 Unicode 表示上必须完全一致.
  5. 完全相同 – 与四级相同, 但还比较码点.

使用 collator 刻面有两种方式: 直接方式 - 调用其成员函数 compare, transform 和 hash; 或间接方式 - 在 STL 算法中使用 comparator 模板类.

例如:

wstring a=L"Façade", b=L"facade";
bool eq = 0 == use_facet<collator<wchar_t> >(loc).compare(collator_base::secondary,a,b);
wcout << a <<L" and "<<b<<L" are " << (eq ? L"identical" : L"different")<<endl;

std::locale 设计为在 STL 集合和算法中用作比较类. 要获得带比较级别的类似功能, 必须使用 comparator 类.

std::map<std::string,std::string,comparator<char,collator_base::secondary> > strings;
// 现在 strings 使用默认系统 locale 进行字符串比较

创建和使用 comparator 类时, 你也可以设置特定的 locale 或级别:

comparator<char> comp(some_locale,some_level);
std::map<std::string,std::string,comparator<char> > strings(comp);
