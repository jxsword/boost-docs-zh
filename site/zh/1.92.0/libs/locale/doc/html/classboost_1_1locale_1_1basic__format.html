详细说明

template<typename CharType>
class boost::locale::basic_format< CharType >

类似 printf 的类, 支持类型安全且感知 locale 的消息格式化

该类创建类似 printf 或 boost::format 的格式化消息, 并通过 operator % 接收格式化条目.

例如

std::cout << format("Hello {1}, you are {2} years old") % name % age << std::endl;

格式化由花括号 { } 包围, 由格式键 key[=value] 中以逗号分隔的标志列表定义; 值也可以是包含在单引号 ' 之间的文本, 用于允许包含非 ASCII 文本的特殊用途

包含字面量 { 和 } 可以通过相应地指定双花括号 {{ 和 }} 来实现.

例如:

std::cout << format("The height of water at {1,time} is {2,num=fixed,precision=3}") % time % height;

特殊键 – 不带值的数字定义输入参数的位置. 键列表:

  • [0-9]+ – 数字, 即格式化参数的索引 – 必需键.
  • num 或 number – 格式化数字. 可选值为:
    • hex – 以十六进制显示数字
    • oct – 以八进制格式显示
    • sci 或 scientific – 以科学计数格式显示
    • fix 或 fixed – 以定点格式显示
    例如 number=sci
  • cur 或 currency – 格式化货币. 可选值为:
    • iso – 使用 ISO 货币符号显示.
    • nat 或 national – 使用本国货币符号显示.
  • per 或 percent – 格式化百分比值.
  • date, time, datetime 或 dt – 格式化日期、时间或日期与时间. 可选值为:
    • s 或 short – 以短格式显示
    • m 或 medium – 以中等格式显示.
    • l 或 long – 以长格式显示.
    • f 或 full – 以完整格式显示.
  • ftime 带字符串 (带引号) 参数 – 像 strftime 那样显示, 参见 as::ftime 操纵器
  • spell 或 spellout – 拼写出数字.
  • ord 或 ordinal – 格式化序数 (1st, 2nd... 等)
  • left 或 < – 左对齐.
  • right 或 > – 右对齐.
  • width 或 w – 设置字段宽度 (需要参数).
  • precision 或 p – 设置精度 (需要参数).
  • locale – 带参数 – 为当前操作切换 locale. 此命令会生成带有格式化刻面的 locale, 提供对格式化更细粒度的控制. 例如:
    std::cout << format("Today {1,date} ({1,date,locale=he_IL.UTF-8@calendar=hebrew,date} Hebrew Date)") % date;
  • timezone 或 tz – 用于显示时间的时区名称. 例如:
    std::cout << format("Time is: Local {1,time}, ({1,time,tz=EET} Eastern European Time)") % date;
  • local - 以本地时间显示时间
  • gmt - 以 UTC 时标显示时间
    std::cout << format("Local time is: {1,time,local}, universal time is {1,time,gmt}") % time;

无效的格式化字符串会被静默忽略. 这可以防止翻译人员在意外的位置使程序崩溃.

template<typename Formattible>
basic_format & boost::locale::basic_format< CharType >::operator% ( const Formattible & object)
inline

向格式化列表添加新参数. 该对象应为一个定义了表达式 out << object 的类型, 其中 out 是 std::basic_ostream.

会存储对象的引用, 因此不要让格式化对象的存续期超过参数的生命周期. 建议直接打印结果:

basic_format<char> fmt("{0}");
fmt % (5 + 2); // 无效: 悬空引用
int i = 42;
return fmt % i; // 无效: 悬空引用
std::cout << fmt % (5 + 2); // 正确, 立即打印
return (fmt % (5 + 2)).str(); // 正确, 立即转换为字符串
