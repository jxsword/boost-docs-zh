Boost.Locale
获取当前 locale 的信息

std::locale::name 函数提供的 locale 信息非常有限. 这种名称依赖平台和编译器, 对 Boost.Locale 无用. 它无法更改, 因此对于 Boost.Locale 创建的所有 locale, name() 返回的值都与 name() 对 std::locale::classic() 所返回的值相同.

因此创建了一个附加刻面来提供更精确的信息: boost::locale::info. 它有以下成员函数:

  • std::string name() - locale 的完整名称, 例如 en_US.UTF-8
  • std::string language() - 当前 locale 的 ISO-639 语言代码, 如 "en".
  • std::string country() - 当前 locale 的 ISO-3166 国家/地区代码, 如 "US".
  • std::string variant() - 当前 locale 的变体, 如 "euro".
  • std::string encoding() - 用于基于 char 的字符串的编码, 如 "UTF-8"
  • bool utf8() - 快速检查编码是否为 UTF-8 的方式.

例如:

cout << "The language code is " << std::use_facet<boost::locale::info>(some_locale).language() << endl;
