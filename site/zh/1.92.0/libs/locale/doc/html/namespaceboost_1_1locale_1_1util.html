详细说明

该命名空间提供多种实用函数, 对 Boost.Locale 后端的实现很有用.

◆ create_codecvt()

std::locale boost::locale::util::create_codecvt ( const std::locale & in,
std::unique_ptr< base_converter > cvt,
char_facet_t type )

向 locale in 安装 codecvt 刻面, 并返回基于 in 且使用新刻面的新 locale.

codecvt 刻面会使用 cvt 转换器在窄编码与宽字符/char16_t/char32_t 编码之间转换. 如果 cvt 是空指针, 则会使用总是失败的转换, 它在每次首个输入或输出时都会失败.

注: codecvt 刻面同时处理 UTF-16 与 UTF-32 宽编码, 它能正确拆分和组合 0xFFFF 以上的 Unicode 码点与代理对. cvt 无需感知宽编码类型

◆ create_info()

std::locale boost::locale::util::create_info ( const std::locale & in,
const std::string & name )

基于 locale 名称 name 向 locale in 安装信息刻面.

该函数将 boost::locale::info 刻面安装到 locale in 中, 并返回新创建的 locale.

注: 所有信息仅基于对字符串 name 的解析;

名称具有如下格式: language[_COUNTRY][.encoding][@variant], 其中 language 是 ISO-639 语言代码, 如 "en" 或 "ru"; COUNTRY 是 ISO-3166 国家/地区标识符, 如 "US" 或 "RU"; Encoding 是字符集名称, 如 UTF-8 或 ISO-8859-1; Variant 是后端特定的变体, 如 euro 或 calendar=hebrew.

如果缺少某些参数, 则将其指定为空白; 默认编码假定为 US-ASCII, 缺失的语言假定为 "C"

◆ get_system_locale()

std::string boost::locale::util::get_system_locale ( bool use_utf8_on_windows = false)

以 POSIX 格式返回默认系统 locale 名称.

该函数按 LC_ALL, LC_CTYPE 和 LANG 环境变量的顺序尝试检测 locale, 如果全都未设置, 在 POSIX 平台上返回 "C". 在 Windows 上, 除上述环境变量外, 该函数还会尝试根据为用户默认 locale 定义的 ISO-639 和 ISO-3166 国家/地区代码创建 locale 名称. 如果 use_utf8_on_windows 为 true, 则把编码设为 UTF-8; 否则, 如果系统 locale 支持 ANSI 代码页, 则定义 ANSI 编码, 如 windows-1252; 否则 (若 ANSI 代码页不可用) 使用 UTF-8 编码.
