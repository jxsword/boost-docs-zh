Boost.Locale
已测试的编译器与平台

以下编译器经过测试, 已知可与 Boost.Locale 协同工作

  • GCC 3.4 至 4.6
  • Microsoft Visual Studio 2005 至 2010
  • Intel 10 至 12
  • Clang 2.8
  • Path Scale 4
  • Visual Age 10.1

以下操作系统经过 Boost.Locale 测试

  • Linux
  • Windows
  • FreeBSD
  • Solaris
  • Darwin
  • Cygwin
  • AIX

已知问题

  • Path Scale 以及搭配 STLPort 的 MSVC 9 在宽字符文件 I/O 中涉及无效 UTF-8 序列的测试存在一些失败.
  • AIX 平台上的原生 iconv 库不支持所需的字符编码, 因此应使用 ICU 或 GNU iconv 库.
  • Mingw/GCC 需要 4.5 及以上版本才能支持 Boost.Locale 的共享构建——即允许与 libstdc++ 和 libgcc 动态链接的版本. Cygwin 的 gcc-4.3 提供运行库的共享版本, 没有任何问题.
  • 在某些情况下, Darwin 系统上的构建系统无法与 iconv 库链接, 此时应使用 -sICONV_PATH 构建选项显式给出 iconv 库所在位置的路径.
