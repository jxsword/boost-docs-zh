is_default_constructible 

template <class T>
struct is_default_constructible : public true_type-or-false_type {};

继承自: 若 T 可被默认构造, 则继承自 true_type, 否则继承自 false_type. 类型 T 必须是完整类型.

编译器兼容性: 该特征要求 C++11 特性 decltype 支持才能获得完整支持. 在不具备该特性的情况下虽然有一些回退代码, 但此时应将该特征视为损坏.

头文件: #include <boost/type_traits/is_copy_constructible.hpp> 或 #include <boost/type_traits.hpp>
