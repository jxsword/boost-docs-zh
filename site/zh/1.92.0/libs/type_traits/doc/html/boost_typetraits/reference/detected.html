detected 

template<template<class...> class Op, class... Args>
using detected_t = see-below;

别名: Op<Args...> 若它是合法的 template-id, 则为 boost::nonesuch否则为

C++ 标准提案: N4502

编译器兼容性: 要求 C++11 变参模板和 C++11 模板别名.

头文件: #include <boost/type_traits/detected.hpp>

示例:

假设你想判定某个类型是否拥有 size() 的 const 成员函数, 那么给定以下元函数:

template <class T>
using size_member_tester = decltype(std::declval<const T&>().size());

template <class T>
using size_member_t = boost::detected_t<size_member_tester, T >;

则类型 size_member_t<T> 是 size_member_tester<T> 的别名 (若该运算合法); 否则是 boost::nonesuch 的别名.

参见: is_detected, is_detected_convertible, is_detected_exact.
