has_new_operator 

template <class T>
struct has_new_operator : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) 具有重载 new 运算符的类型, 则继承自 true_type, 否则继承自 false_type.

编译器兼容性: 要求可正常工作的 SFINAE (即未设置 BOOST_NO_SFINAE). 只有少数相当老的编译器不支持这一点. 另据所知, 该特征在 Borland/Codegear 编译器上存在问题.

C++ 标准参考:12.5.

头文件: #include <boost/type_traits/has_new_operator.hpp> 或 #include <boost/type_traits.hpp>

示例:

给定:

class A { void* operator new(std::size_t); };
class B { void* operator new(std::size_t, const std::nothrow&); };
class C { void* operator new(std::size_t, void*); };
class D { void* operator new[](std::size_t); };
class E { void* operator new[](std::size_t, const std::nothrow&); };
class F { void* operator new[](std::size_t, void*); };

那么:

has_new_operator<A> 继承自 true_type.

has_new_operator<B> 继承自 true_type.

has_new_operator<C> 继承自 true_type.

has_new_operator<D> 继承自 true_type.

has_new_operator<E> 继承自 true_type.

has_new_operator<F> 继承自 true_type.
