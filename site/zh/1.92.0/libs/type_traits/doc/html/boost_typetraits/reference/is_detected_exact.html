is_detected_exact 

template<class Expected, template<class...> class Op, class... Args>
using is_detected_exact = is_same<Expected, detected_t<Op, Args...> >;

template<class Expected, template<class...> class Op, class... Args>
constexpr bool is_detected_exact_v = is_detected_exact<Op, Args...>::value;

C++ 标准提案: N4502

编译器兼容性: 要求 C++11 变参模板和 C++11 模板别名.

头文件: #include <boost/type_traits/is_detected_exact.hpp>

类型 is_detected_exact<To, Op, Args> 是 true_type 的别名, 前提是 Op<Args> 的结果是类型 To. 否则它是类型 false_type;

示例: 

template<class T>
using difference_t = typename T::difference_type;

static_assert(boost::is_detected_exact_v<std::ptrdiff_t, difference_t, T>);

参见: is_detected, is_detected_convertible.
