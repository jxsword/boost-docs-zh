is_copy_assignable 

template <class T>
struct is_copy_assignable : public true_type-or-false_type {};

继承自: 若 T 为 CopyAssignable (即拥有可访问的显式或隐式拷贝赋值运算符), 则继承自 true_type, 否则继承自 false_type. 类型 T 必须是完整类型.

换句话说, 它会继承自 true_type, 仅当 T 从 const T & 的拷贝赋值未被标记为 = delete, T 不继承自 boost::noncopyable 且未被标记为 BOOST_MOVABLE_BUT_NOT_COPYABLE(T)时才发生.

编译器兼容性: 完整支持需要 C++11 特性 decltype 以及 SFINAE 表达式.

如果你的编译器不支持 C++11 的被删除函数 (= delete), 或者不支持对被删除赋值的 SFINAE, 请让你的类继承自 boost::noncopyable 或将其标记为 BOOST_MOVABLE_BUT_NOT_COPYABLE(T), 以表明该类不可赋值.

该特征不关心访问修饰符, 因此如果你看到类似这样的错误:

'T::operator=(const T&)' is private
boost/type_traits/is_copy_assignable.hpp:68:5: error: within this context

那么你是在对一个具有私有赋值的结构体调用该宏:

struct T {
    // ...
private:
    T &operator=(const T &);
    // ...
};

要修复这一点, 你必须修改你的结构体, 显式地将其标记为不可拷贝 (= delete, boost::noncopyable 或 BOOST_MOVABLE_BUT_NOT_COPYABLE(T)), 或者显式地 特化该特征.

头文件: #include <boost/type_traits/is_copy_assignable.hpp> 或 #include <boost/type_traits.hpp>
