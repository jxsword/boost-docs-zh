is_convertible 

template <class From, class To>
struct is_convertible : public true_type-or-false_type {};

继承自: 若类型 From 的假想右值可以转换为类型 To 则继承自 true_type, 否则继承自 false_type.

类型 From 不能是不完整类型.

类型 To 不能是不完整类型或函数类型.

没有哪个类型被视为可转换为数组类型或抽象类类型.

该模板无法检测转换构造函数是否为 public: 如果类型 To 拥有 private 转换构造函数, 来自类型 From, 那么实例化 is_convertible<From, To> 将导致编译器错误. 因此, is_convertible 不能用于判定某个类型是否拥有 public 拷贝构造函数.

如果转换有歧义, 该模板也会导致编译器错误, 例如:

struct A {};
struct B : A {};
struct C : A {};
struct D : B, C {};
// This produces a compiler error, the conversion is ambiguous:
bool const y = boost::is_convertible<D*,A*>::value;

C++ 标准参考:4 and 8.5.

编译器兼容性: 该特征受所有当前编译器支持.

头文件: #include <boost/type_traits/is_convertible.hpp> 或 #include <boost/type_traits.hpp>

示例:

is_convertible<int, double> 继承自 true_type.

is_convertible<const int, double>::type 是类型 true_type.

is_convertible<int* const, int*>::value 是一个整型常量表达式, 求值为 true.

is_convertible<int const*, int*>::value 是一个整型常量表达式, 求值为 false: 该转换将需要一个 const_cast.

is_convertible<int const&, long>::value 是一个整型常量表达式, 求值为 true.

is_convertible<int, int>::value 是一个整型常量表达式, 求值为 true.

is_convertible<T, T>::value_type 是类型 bool.
