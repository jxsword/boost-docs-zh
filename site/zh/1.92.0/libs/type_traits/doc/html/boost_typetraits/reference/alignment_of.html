alignment_of 

template <class T>
struct alignment_of : public integral_constant<std::size_t, ALIGNOF(T)> {};

继承自: 类模板 alignment_of 继承自 integral_constant<std::size_t, ALIGNOF(T)>, 其中 ALIGNOF(T) 是类型 T 的对齐.

注释: 严格来说, 你只应依赖 ALIGNOF(T) 的值是 T 的真实对齐的倍数这一事实; 尽管在我们所知的所有情形中, 它实际上都会计算出正确的值.

头文件: #include <boost/type_traits/alignment_of.hpp> 或 #include <boost/type_traits.hpp>

示例:

alignment_of<int> 继承自 integral_constant<std::size_t, ALIGNOF(int)>.

alignment_of<char>::type 是类型 integral_constant<std::size_t, ALIGNOF(char)>.

alignment_of<double>::value 是一个整型常量表达式, 其值为 ALIGNOF(double).

alignment_of<T>::value_type 是类型 std::size_t.

重要

Visual C++ 用户应注意, MSVC 对 "对齐" 有多种不同的定义. 例如考虑以下代码:

typedef long long align_t;
assert(boost::alignment_of<align_t>::value % 8 == 0);
align_t a;
assert(((std::uintptr_t)&a % 8) == 0);
char c = 0;
align_t a1;
assert(((std::uintptr_t)&a1 % 8) == 0);

在这段代码中, 尽管 boost::alignment_of<align_t> 报告 align_t 具有 8 字节对齐, 最后的 assert 在 32 位构建中仍会失败, 因为 a1 未按 8 字节边界对齐. 注意, 如果我们使用 MSVC 内建特性 __alignof 代替 boost::alignment_of, 仍会得到相同的结果. 事实上, 对 MSVC 而言, 对齐要求 (和承诺) 实际上只适用于动态存储, 而不适用于栈.
