make_unsigned 

template <class T>
struct make_unsigned
{
   typedef see-below type;
};

template <class T> using make_unsigned_t = typename make_unsigned<T>::type; // C++11 and above

类型: 若 T 是无符号整数类型, 则与 T 相同; 若 T 是有符号整数类型, 则为对应的无符号类型. 否则, 若 T 是枚举或字符类型 (char 或 wchar_t), 则为与 T 宽度相同的无符号整数类型.

若 T 带任何 cv 限定符, 则结果类型上也带有这些限定符.

要求: T 必须是整数或枚举类型, 且不能是类型 bool.

C++ 标准参考:3.9.1.

编译器兼容性: 该特征受所有当前编译器支持.

头文件: #include <boost/type_traits/make_unsigned.hpp> 或 #include <boost/type_traits.hpp>
