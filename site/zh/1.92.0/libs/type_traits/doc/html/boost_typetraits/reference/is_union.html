is_union 

template <class T>
struct is_union : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) union 类型, 则继承自 true_type, 否则继承自 false_type. 目前需要某种编译器支持, 否则 union 会被识别为类.

C++ 标准参考:3.9.2 and 9.5.

编译器兼容性: 如果没有编译器提供某种 (尚不明确的) 帮助, 仅凭标准 C++ 无法区分 union 类型与类类型, 因此该类型将永远不会继承自 true_type, 除非用户针对其用户定义的 union 类型显式特化该模板, 或者编译器提供实现此功能的某种未指明的内建特性. 目前 (2015 年 6 月) 比 Visual C++ 8、clang、GCC-4.3、Greenhills 6.0、Intel-11.0 和 Codegear 更新的编译器都具备必要的编译器 内建特性, 可确保该特征 "直接可用". 你也可以测试所需的 内建特性 是否可用, 方法是检查宏 BOOST_IS_UNION 是否已定义.

头文件: #include <boost/type_traits/is_union.hpp> 或 #include <boost/type_traits.hpp>

示例:

给定 union my_union {}; 则:

is_union<my_union> 继承自 true_type.

is_union<const my_union>::type 是类型 true_type.

is_union<my_union>::value 是一个整型常量表达式, 求值为 true.

is_union<my_union*>::value 是一个整型常量表达式, 求值为 false.

is_union<T>::value_type 是类型 bool.
