has_virtual_destructor 

template <class T>
struct has_virtual_destructor : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) 具有虚析构函数的类型, 则继承自 true_type, 否则继承自 false_type.

编译器兼容性: 目前没有可移植的方式来实现该特征: 默认版本总是继承自 false_type, 并且对于具有虚析构函数的类型必须显式特化——除非所用编译器具备使该特征正确工作的编译器 内建特性. 目前 (2015 年 6 月) 比 Visual C++ 8、GCC-4.3、Greenhills 6.0、Intel-11.0 更新的编译器, 加上 Codegear 和 Clang, 都具备必要的编译器 内建特性, 可确保该特征 "直接可用". 你也可以测试所需的 内建特性 是否可用, 方法是检查宏 BOOST_HAS_VIRTUAL_DESTRUCTOR 是否已定义.

C++ 标准参考:12.4.

头文件: #include <boost/type_traits/has_virtual_destructor.hpp> 或 #include <boost/type_traits.hpp>
