is_nothrow_move_assignable 

template <class T>
struct is_nothrow_move_assignable : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) 具有不抛出异常的移动赋值运算符的类型, 或没有移动赋值运算符但具有不抛出异常的赋值运算符的类型, 则继承自 true_type, 否则继承自 false_type. 类型 T 必须是完整类型.

换句话说, 它会继承自 true_type, 仅当表达式 variable1 = std::move(variable2) 不会抛出异常 (variable1 和 variable2 是类型 T的变量).

编译器兼容性: 如果编译器不支持类模板的偏特化, 则该模板不能用于函数类型.

如果没有编译器 (C++11 的 noexcept 应能正确工作) 的帮助, is_nothrow_move_assignable 将永远不会报告某个 class 或 struct 具有不抛出异常的赋值运算符; 这总是安全的, 尽管可能不是最优的. 目前 (2015 年 6 月) MSVC-12.0、Clang 和 GCC 4.7 具备必要的编译器支持, 可确保该特征 "直接可用".

头文件: #include <boost/type_traits/is_nothrow_move_assignable.hpp> 或 #include <boost/type_traits.hpp>
