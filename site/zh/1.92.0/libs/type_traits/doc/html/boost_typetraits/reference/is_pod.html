is_pod 

template <class T>
struct is_pod : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) POD 类型, 则继承自 true_type, 否则继承自 false_type.

POD 即 "Plain old data" (简单旧数据). 算术类型、枚举类型、指针和成员指针都是 POD. 类和 union 也可以是 POD, 条件是: 没有引用类型或非 POD 类型的非静态数据成员, 没有用户定义的构造函数, 没有用户定义的赋值运算符, 没有私有或受保护的静态数据成员, 没有虚函数, 并且没有基类. 最后, 带 cv 限定的 POD 仍然是 POD, POD 数组亦然.

C++ 标准参考:3.9p10 and 9p4 (Note that POD's are also aggregates, see 8.5.1).

编译器兼容性: 如果没有编译器提供某种 (尚不明确的) 帮助, is_pod 将永远不会报告某个 class 或 struct 是 POD; 这总是安全的, 尽管可能不是最优的. 目前 (2015 年 6 月) 比 Visual C++ 8、Clang-3、GCC-4.3、Greenhills 6.0、Intel-11.0 和 Codegear 更新的编译器都具备必要的编译器 内建特性, 可确保该特征 "直接可用". 你也可以测试所需的 内建特性 是否可用, 方法是检查宏 BOOST_IS_POD 是否已定义.

头文件: #include <boost/type_traits/is_pod.hpp> 或 #include <boost/type_traits.hpp>

示例:

is_pod<int> 继承自 true_type.

is_pod<char*>::type 是类型 true_type.

is_pod<int (*)(long)>::value 是一个整型常量表达式, 求值为 true.

is_pod<MyClass>::value 是一个整型常量表达式, 求值为 false.

is_pod<T>::value_type 是类型 bool.
