is_nothrow_swappable 

template <class T>
struct is_nothrow_swappable : public true_type-or-false_type {};

继承自: 若表达式 swap(declval<T&>(), declval<T&>()) (在 std::swap 可见的上下文中) 合法且不抛出异常, 则继承自 true_type, 否则继承自 false_type.

编译器兼容性: 完整支持要求 C++11. 在没有 C++11 的情况下, 对标量类型 (包括整数、浮点、枚举、指针和成员指针类型) 它会继承自 true_type, 对其他任何类型则继承自 false_type.

头文件: #include <boost/type_traits/is_nothrow_swappable.hpp> 或 #include <boost/type_traits.hpp>
