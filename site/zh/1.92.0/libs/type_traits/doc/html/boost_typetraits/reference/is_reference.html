is_reference 

template <class T>
struct is_reference : public true_type-or-false_type {};

继承自: 若 T 是引用类型 (左值引用或右值引用), 则继承自 true_type, 否则继承自 false_type.

C++ 标准参考:3.9.2 and 8.3.2.

编译器兼容性: 该特征受所有当前编译器支持.

头文件: #include <boost/type_traits/is_reference.hpp> 或 #include <boost/type_traits.hpp>

示例:

is_reference<int&> 继承自 true_type.

is_reference<int const&>::type 是类型 true_type.

is_reference<int const&&>::type 是类型 true_type.

is_reference<int (&)(long)>::value 是一个整型常量表达式, 求值为 true (此处的实参是对函数的引用).

is_reference<T>::value_type 是类型 bool.
