引言

Boost type-traits 库包含一组非常具体的特征类, 其中每一个都封装了 C++ 类型系统中的一个单独的特征; 例如, 某个类型是指针还是引用类型? 或者某个类型是否具有平凡的构造函数, 或 const 限定符?

这些 type-traits 类共享统一的设计: 若类型具有指定的性质, 类就继承自类型 true_type, 否则继承自 false_type.

type-traits 库还包含一组对类型执行特定变换的类; 例如, 它们可以从类型中移除顶层 const 或 volatile 限定符. 每个执行变换的类都定义一个单独的 typedef 成员 type 作为变换的结果.
