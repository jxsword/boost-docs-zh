is_function 

template <class T>
struct is_function : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) 函数类型, 则继承自 true_type, 否则继承自 false_type. 注意, 该模板不会检测 函数指针或 函数引用, 它们分别由 is_pointer 和 is_reference 检测:

typedef int f1();      // f1 is of function type.
typedef int (*f2)();   // f2 is a pointer to a function.
typedef int (&f3)();   // f3 is a reference to a function.

C++ 标准参考:3.9.2p1 and 8.3.5.

编译器兼容性: 该特征受所有当前编译器支持.

头文件: #include <boost/type_traits/is_function.hpp> 或 #include <boost/type_traits.hpp>

示例:

is_function<int (void)> 继承自 true_type.

is_function<long (double, int)>::type 是类型 true_type.

is_function<long (double, int)>::value 是一个整型常量表达式, 求值为 true.

is_function<long (*)(double, int)>::value 是一个整型常量表达式, 求值为 false: 此处的实参是指针类型, 而不是函数类型.

is_function<long (&)(double, int)>::value 是一个整型常量表达式, 求值为 false: 此处的实参是对函数的引用, 而不是函数类型.

is_function<long (MyClass::*)(double, int)>::value 是一个整型常量表达式, 求值为 false: 此处的实参是成员函数指针.

is_function<T>::value_type 是类型 bool.

提示

不要把函数类型与函数指针混淆:

typedef int f(double);

定义一个函数类型,

f foo;

声明一个类型为 f的函数的原型,

f* pf = foo;

f& fr = foo;

声明一个指向函数 foo的指针和引用.

如果你想检测某个类型是否为函数指针, 请使用:

is_function<remove_pointer<T>::type>::value && is_pointer<T>::value

而对于成员函数指针, 你可以直接使用 is_member_function_pointer.
