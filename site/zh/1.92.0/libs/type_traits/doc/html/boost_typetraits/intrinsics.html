编译器内建特性支持

有一些特征无法在当前的 C++ 语言内实现: 要让这些特征对用户定义类型 "直接可用", 需要编译器提供某种额外的帮助. 目前 (2008 年 4 月) Visual C++ 8 和 9、GNU GCC 4.3 以及 MWCW 9 至少提供了部分必要的内建特性 (intrinsics), 其他编译器想必也会在适当时候跟进.

以下特征类始终需要编译器支持, 才能对所有类型给出正确结果 (但如果缺乏该支持, 它们都有安全的回退方案):

  • is_final
  • is_union
  • is_pod
  • is_nothrow_move_assignable
  • is_nothrow_move_constructible
  • has_trivial_constructor
  • has_trivial_copy
  • has_trivial_move_constructor
  • has_trivial_assign
  • has_trivial_move_assign
  • has_trivial_destructor
  • has_nothrow_constructor
  • has_nothrow_copy
  • has_nothrow_assign
  • has_virtual_destructor

以下特征类无法用 C++ 语言可移植地实现, 不过实际上, 就我们所知, 其实现对所有编译器都能给出正确结果:

  • is_empty
  • is_polymorphic
  • is_virtual_base_of

以下特征类依赖于上面列出的一个或多个特征类:

  • is_class
  • is_stateless

编译器内建特性支持的挂钩定义于 boost/type_traits/intrinsics.hpp, 为新编译器添加支持只需定义以下一个或多个宏:

表 1.9. 编译器内建特性宏

BOOST_ALIGNMENT_OF(T)

应求值为类型 T 的对齐要求

BOOST_IS_ABSTRACT(T)

若 T 是抽象类型, 应求值为 true

BOOST_IS_BASE_OF(T,U)

若 T 是 U 的基类, 应求值为 true

BOOST_IS_CLASS(T)

若 T 是类类型, 应求值为 true

BOOST_IS_CONVERTIBLE(T,U)

若 T 可转换为 U, 应求值为 true

BOOST_IS_EMPTY(T)

若 T 是空 struct 或 union, 应求值为 true

BOOST_IS_ENUM(T)

若 T 是枚举, 应求值为 true

BOOST_IS_FINAL(T)

若 T 是以 final 说明符声明的类类型, 应求值为 true

BOOST_IS_NOTHROW_MOVE_ASSIGN(T)

若 T 具有不抛出异常的移动赋值运算符, 应求值为 true

BOOST_IS_NOTHROW_MOVE_CONSTRUCT(T)

若 T 具有不抛出异常的移动构造函数, 应求值为 true

BOOST_IS_POLYMORPHIC(T)

若 T 是多态类型, 应求值为 true

BOOST_IS_POD(T)

若 T 是 POD 类型, 应求值为 true

BOOST_IS_UNION(T)

若 T 是 union 类型, 应求值为 true

BOOST_HAS_NOTHROW_ASSIGN(T)

若 T t, u; t = u 不会抛出异常, 应求值为 true

BOOST_HAS_NOTHROW_CONSTRUCTOR(T)

若 T x; 不会抛出异常, 应求值为 true

BOOST_HAS_NOTHROW_COPY(T)

若 T(t) 不会抛出异常, 应求值为 true

BOOST_HAS_TRIVIAL_ASSIGN(T)

若 T 具有平凡的赋值运算符 (因此可以用对 memcpy 的调用替代), 应求值为 true

BOOST_HAS_TRIVIAL_CONSTRUCTOR(T)

若 T 的默认构造函数是平凡的 (即没有任何效果), 应求值为 true

BOOST_HAS_TRIVIAL_COPY(T)

若 T 具有平凡的拷贝构造函数 (因此可以用对 memcpy 的调用替代), 应求值为 true

BOOST_HAS_TRIVIAL_DESTRUCTOR(T)

若 T 具有平凡的析构函数 (即 ~T() 没有任何效果), 应求值为 true

BOOST_HAS_TRIVIAL_MOVE_CONSTRUCTOR(T)

若 T 具有平凡的移动构造函数 (因此可以用对 memcpy 的调用替代), 应求值为 true

BOOST_HAS_TRIVIAL_MOVE_ASSIGN(T)

若 T 具有平凡的移动赋值运算符 (因此可以用对 memcpy 的调用替代), 应求值为 true

BOOST_HAS_VIRTUAL_DESTRUCTOR(T)

若 T 具有虚析构函数, 应求值为 true
