这些特征都是 值特征, 也就是说这些特征类全部继承自 integral_constant, 并用于访问类型的某种数值属性. 它通常是一个简单的 true 或 false 布尔值, 但在少数情况下也可能是其他整数值 (例如在处理类型对齐或数组边界时: 见 alignment_of, rank 和 extent).
