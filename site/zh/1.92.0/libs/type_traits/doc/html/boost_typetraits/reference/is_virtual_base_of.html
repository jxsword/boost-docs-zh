is_virtual_base_of 

template <class Base, class Derived>
struct is_virtual_base_of : public true_type-or-false_type {};

继承自: 若 Base 是类型 Derived 的虚基类, 则继承自 true_type, 否则继承自 false_type.

类型 Base 和 Derived 不能是不完整类型.

C++ 标准参考:10.

头文件: #include <boost/type_traits/is_virtual_base_of.hpp> 或 #include <boost/type_traits.hpp>

编译器兼容性: 该特征受所有当前编译器支持.

注释

存在少数几种情形, 该特征根本无法工作, 此时尝试实例化该特征会导致编译器错误 (见缺陷报告 #3730 和 11323). 此外, 这些问题很可能因编译器而异. 在这种情况下, 用户应提供该特征的完整特化来规避问题.

示例:

给定: class Base{}; class Derived : public virtual Base{};

is_virtual_base_of<Base, Derived> 继承自 true_type.

is_virtual_base_of<Base, Derived>::type 是类型 true_type.

is_virtual_base_of<Base, Derived>::value 是一个整型常量表达式, 求值为 true.

is_virtual_base_of<SomeClassType, SomeClassType>::value 是一个整型常量表达式, 求值为 true.

is_virtual_base_of<NotAClassType, NotAClassType>::value 是一个整型常量表达式, 求值为 false.

is_virtual_base_of<T, U>::value_type 是类型 bool.
