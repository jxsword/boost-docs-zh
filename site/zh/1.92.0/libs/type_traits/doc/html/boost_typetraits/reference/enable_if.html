enable_if_ 

template<bool B, class T = void>
struct enable_if_;

template<bool B, class T = void>
using enable_if_t = typename enable_if_<B, T>::type;

类型: 若 B 为 true, 则成员 type 被定义为 T. 否则不存在成员 type.

头文件: #include <boost/type_traits/enable_if.hpp>

注释

该特征名为 enable_if_ (末尾带下划线), 但行为类似于 std::enable_if 或 boost::enable_if_c. 名为 boost::enable_if 的既有特征具有不同的接口.

示例:

以下函数可用于销毁数组的每个元素, 并对可平凡析构类型的数组进行特殊处理.

template<class T>
typename boost::enable_if_<!boost::has_trivial_destructor<T>::value>::type
destroy(T* ptr, std::size_t size)
{
    while (size > 0) {
        ptr[--size].~T();
    }
}

template<class T>
typename boost::enable_if_<boost::has_trivial_destructor<T>::value>::type
destroy(T*, std::size_t) { }

编译器兼容性: 该特征受所有当前编译器支持. 类型别名 enable_if_t 仅在编译器支持模板别名时可用.
