MPL 互操作性

本库中所有基于值的特征都符合 MPL 对 整型常量 (Integral Constant) 类型的要求.

请注意, 这些类型不再继承自 mpl::true_ 或 mpl::false_ 等, 本库也不再隐式包含任何 MPL 头文件. 不过, 从 integral_constant 到对应 MPL 类型仍存在隐式转换, 因此在函数重载中使用 MPL 类型进行标签分派 (tag-dispatching) 的做法仍将照常工作.
