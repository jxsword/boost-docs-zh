is_complete 

template <class T>
struct is_complete : public true_type-or-false_type {};

继承自: 若 T 是完整类型, 则继承自 true_type, 否则继承自 false_type.

重要

该特征只设计用于一种用途: 当模板意外地在某个不完整类型上实例化时, 触发一个硬错误 (通过 static_assert). 任何其他用例都会造成 ODR 违规, 因为类型 T 的 "完整性" 可能在当前翻译单元的不同位置、以及不同翻译单元之间有所不同. 尤其, 这个特征绝不应被用于根据类型的完整性来改变代码路径.

头文件: #include <boost/type_traits/is_complete.hpp> 或 #include <boost/type_traits.hpp>

编译器兼容性: 要完整发挥作用, 需要 C++11 SFINAE 表达式. 宏 BOOST_TT_HAS_WORKING_IS_COMPLETE 在该特征完全可用时被定义.
