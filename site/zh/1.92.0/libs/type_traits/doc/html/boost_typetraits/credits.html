Credits致谢

本文档由 John Maddock 整理, 使用了 Boost.Quickbook 和 Boost.DocBook.

本库的最初版本由 Steve Cleary、Beman Dawes、Howard Hinnant 和 John Maddock 创建. John Maddock 是本库当前的维护者.

type traits 库的这一版本基于 Adobe Systems Inc、David Abrahams、Steve Cleary、Beman Dawes、Aleksey Gurtovoy、Howard Hinnant、Jesse Jones、Mat Marcus、Itay Maman、John Maddock、Thorsten Ottosen、Robert Ramey、Jeremy Siek、Antony Polukhin 和 Glen Fernandes 的贡献.

Mat Marcus 和 Jesse Jones 发明了本库中使用的偏特化变通方法, 并 发表了一篇描述这些方法的论文.

Aleksey Gurtovoy 为本库添加了 MPL 集成.

模板 is_convertible 基于 Andrei Alexandrescu 最初设计的代码, 见 "Generic<Programming>: Mappings between Types and Values".
