has_nothrow_constructor 

template <class T>
struct has_nothrow_constructor : public true_type-or-false_type {};

template <class T>
struct has_nothrow_default_constructor : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) 具有不抛出异常的默认构造函数的类型, 则继承自 true_type, 否则继承自 false_type. 类型 T 必须是完整类型.

这两个特征互为同义词.

编译器兼容性: 要么要求 C++11 的 noexcept 和 decltype, 要么需要编译器提供某种 (未指明的) 帮助. 目前 (2015 年 6 月) 比 Visual C++ 8、GCC-4.3、Greenhills 6.0、Intel-11.0 和 Codegear 更新的编译器, 以及所有较新的 GCC 版本, 都具备必要的编译器 内建特性, 可确保该特征 "直接可用". 你可以通过检查 defined(BOOST_HAS_NOTHROW_CONSTRUCTOR) || (!defined(BOOST_NO_CXX11_DECLTYPE) && !defined(BOOST_NO_CXX11_NOEXCEPT)) 是否为 true 来测试所需的支持是否可用.

头文件: #include <boost/type_traits/has_nothrow_constructor.hpp> 或 #include <boost/type_traits.hpp>
