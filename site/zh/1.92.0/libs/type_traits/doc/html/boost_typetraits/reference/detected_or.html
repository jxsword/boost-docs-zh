detected_or 

template<class Default, template<class...> class Op, class... Args>
using detected_or = see-below;

template<class Default, template<class...> class Op, class... Args>
using detected_or_t = typename detected_or<Default, Op, Args...>::type;

别名: 一个未指明的类型, 带有两个公有成员类型定义:

  • value_t 为 true_type 若 Op<Args...> 是合法的 template-id, 否则为 false_type
  • type 为 Op<Args...> 若它是合法的 template-id, 否则为 Default

C++ 标准提案: N4502

编译器兼容性: 要求 C++11 变参模板和 C++11 模板别名.

头文件: #include <boost/type_traits/detected_or.hpp>

示例:

假设我们想声明一个表示类型 T 的两个值之差的类型: 若存在 T::difference_type 则应为它, 否则应为 std::ptrdiff_t:

template<class T>
using difference_t = typename T::difference_type;

template<class T>
using difference_type = boost::detected_or_t<std::ptrdiff_t, difference_t, T>;

现在, 类型 difference_type<T> 给出了我们所需的东西.

参见: is_detected, is_detected_convertible, is_detected_exact.
