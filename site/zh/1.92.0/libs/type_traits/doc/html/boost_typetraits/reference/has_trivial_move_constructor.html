has_trivial_move_constructor 

template <class T>
struct has_trivial_move_constructor : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) 具有平凡移动构造函数的类型, 则继承自 true_type, 否则继承自 false_type.

如果某个类型具有平凡的移动构造函数, 则该构造函数与把一个对象的位复制到另一个对象具有相同的效果: 对该构造函数的调用可以安全地替换为对 memcpy的调用.

编译器兼容性: 如果没有编译器提供某种 (尚不明确的) 帮助, has_trivial_move_constructor 将永远不会报告用户定义的 class 或 struct 具有平凡的构造函数; 这总是安全的, 尽管可能不是最优的. 此外, 要正确支持被删除的 (deleted) 或私有的移动构造函数, 还需要 C++11 的 decltype. 目前 (2015 年 6 月) 具备必要 内建特性 、可确保该特征 "直接可用" 的编译器包括 Clang、GCC-5.1 和 MSVC-12.0. 你也可以测试所需的 内建特性 是否可用, 方法是检查宏 BOOST_HAS_TRIVIAL_MOVE_CONSTRUCTOR 是否已定义.

头文件: #include <boost/type_traits/has_trivial_move_constructor.hpp> 或 #include <boost/type_traits.hpp>

示例:

has_trivial_move_constructor<int> 继承自 true_type.

has_trivial_move_constructor<char*>::type 是类型 true_type.

has_trivial_move_constructor<int (*)(long)>::value 是一个整型常量表达式, 求值为 true.

has_trivial_move_constructor<MyClass>::value 是一个整型常量表达式, 求值为 false.

has_trivial_move_constructor<T>::value_type 是类型 bool.
