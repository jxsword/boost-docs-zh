has_trivial_destructor 

template <class T>
struct has_trivial_destructor : public true_type-or-false_type {};

继承自: 若 T 是 (可能带 cv 限定的) 具有平凡析构函数的类型, 则继承自 true_type, 否则继承自 false_type.

如果某个类型具有平凡的析构函数, 则该析构函数没有任何效果: 对该析构函数的调用可以安全地省略. 注意, 使用元编程来省略单个平凡构造函数的调用没有任何益处. 但是, 如果循环和/或异常处理代码也能一并省略, 则可以在代码大小和速度方面获得一些收益.

编译器兼容性: 如果没有编译器提供某种 (尚不明确的) 帮助, has_trivial_destructor 将永远不会报告用户定义的 class 或 struct 具有平凡的析构函数; 这总是安全的, 尽管可能不是最优的. 此外, 为了正确处理被删除的 (deleted) 或私有的析构函数, 还需要支持 C++11 的 decltype. 目前 (2015 年 6 月) 比 Visual C++ 8、GCC-4.3、Greenhills 6.0、Intel-11.0 和 Codegear 更新的编译器都具备必要的编译器 内建特性, 可确保该特征 "直接可用". 你也可以测试所需的 内建特性 是否可用, 方法是检查宏 BOOST_HAS_TRIVIAL_DESTRUCTOR 是否已定义.

C++ 标准参考:12.4p3.

头文件: #include <boost/type_traits/has_trivial_destructor.hpp> 或 #include <boost/type_traits.hpp>

示例:

has_trivial_destructor<int> 继承自 true_type.

has_trivial_destructor<char*>::type 是类型 true_type.

has_trivial_destructor<int (*)(long)>::value 是一个整型常量表达式, 求值为 true.

has_trivial_destructor<MyClass>::value 是一个整型常量表达式, 求值为 false.

has_trivial_destructor<T>::value_type 是类型 bool.
