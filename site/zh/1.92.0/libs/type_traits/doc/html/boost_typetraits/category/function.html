分解函数类型

类模板 function_traits 从函数类型中提取信息 (另见 is_function). 该特征类可以告诉你一个函数接受多少个实参、这些实参的类型是什么, 以及返回类型是什么.

Synopsis 

template <std::size_t Align>
struct function_traits;
