promote 

template <class T>
struct promote
{
   typedef see-below type;
};

template <class T> using promote_t = typename promote<T>::type; // C++11 and above

类型: 若整型提升或浮点提升可应用于类型 T的右值, 则对 T 应用整型和浮点提升, 并保留 T, 否则 T 保持不变. 另见 integral_promotion 和 floating_point_promotion.

C++ 标准参考:4.5 except 4.5/3 (integral bit-field) and 4.6.

编译器兼容性: 该特征受所有当前编译器支持.

头文件: #include <boost/type_traits/promote.hpp> 或 #include <boost/type_traits.hpp>
