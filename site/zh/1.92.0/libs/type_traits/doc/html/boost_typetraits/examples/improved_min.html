用 common_type 改进 std::min

改进的 std::min 函数可以这样编写:

template <class T, class U>
typename common_type<T, U>::type min(T t, U u)
{
   return t < u ? t : u;
}

而现在, 诸如以下形式的表达式:

min(1, 2.0)

将真正能够编译, 并返回正确的类型!
