is_detected 

template<template<class...> class Op, class... Args>
using is_detected = see-below;

template<template<class...> class Op, class... Args>
constexpr bool is_detected_v = is_detected<Op, Args...>::value;

别名: 若 Op<Args...> 是合法的 template-id, 则别名为 true_type, 否则别名为 false_type.

C++ 标准提案: N4502

编译器兼容性: 要求 C++11 变参模板和 C++11 模板别名.

头文件: #include <boost/type_traits/is_detected.hpp>

示例:

假设我们想 "重置" 一个类型为 T 的值: 如果该类型拥有 clear() 成员函数, 那么应调用它, 否则应赋一个默认构造的值:

template<class T>
using clear_t = decltype(boost::declval<T&>().clear());

template<class T>
void clear(T& value)
{
    if constexpr (boost::is_detected_v<clear_t, T>) {
        value.clear();
    } else {
        value = T();
    }
}

参见: is_detected_convertible, is_detected_exact.
