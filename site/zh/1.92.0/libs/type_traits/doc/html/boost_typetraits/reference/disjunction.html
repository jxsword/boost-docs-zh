disjunction 

template<class... T>
struct disjunction;

继承自: 继承自列表中第一个满足 U 为 bool(U::value) 的类型 true, 如果不存在这样的类型, 则继承自列表中的最后一个类型. 如果 sizeof...(T) 为 0, 则继承自 false_type.

头文件: #include <boost/type_traits/disjunction.hpp>

编译器兼容性: 该特征受所有当前编译器支持. 在缺乏变参模板支持的情况下, disjunction 只有 2 个参数.

示例:

给定: template<int N> struct Int { static const int value = N };

disjunction<> 继承自 false_type.

disjunction<Int<1> > 继承自 Int<1>.

disjunction<Int<1>, Int<2>, Int<3> > 继承自 Int<1>.

disjunction<Int<0>, Int<2>, Int<3> > 继承自 Int<2>.
