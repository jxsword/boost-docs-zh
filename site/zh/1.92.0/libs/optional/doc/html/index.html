引言

类模板 optional 是一个包装器, 用于表示 "可选" (或 "可空") 的对象, 这些对象可能 (尚) 不包含有效值. 可选对象提供完整的值语义; 它们适合按值传递以及在 STL 容器内使用. 这是一个仅头文件的 C++11 库.

问题

假设我们想从配置文件读取一个表示某个整数值的参数, 姑且称之为 "MaxValue". 这个参数可能未被指定; 这种情况并非错误. 不指定该参数是有效的, 此时程序的行为应略有不同. 另外, 假设类型 int 的任何可能取值都是 "MaxValue" 的有效值, 因此我们不能只用 -1 来表示配置文件中没有该参数.

解决方案

用 boost::optional 解决此问题的方法如下:

#include <boost/optional.hpp>

boost::optional<int> getConfigParam(std::string name);  // return either an int or a `not-an-int`

int main()
{
  if (boost::optional<int> oi = getConfigParam("MaxValue")) // did I get a real int?
    runWithMax(*oi);                                        // use my int
  else
    runWithNoMax();
}
