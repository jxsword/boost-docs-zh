可选引用

概述

本库允许模板参数 T 为引用类型: T&, 以及在某种程度上, T const&.

不过, 由于引用并非真正的对象, 存在一些限制, 且某些操作在此情形下不可用:

  • 转换构造函数
  • 转换赋值
  • 就地构造
  • 就地赋值
  • 通过指针访问值

另外, 尽管 optional<T&> 在很大程度上像对待真实值一样对待它包装的伪对象, 但它存储的是一个真正的引用, 因此会发生别名效应:

  • optional<T&> 的副本会复制这些引用, 但所有这些引用仍然指向同一个对象.
  • 值访问实际提供的是对被引用对象的访问, 而不是对引用本身的访问.
注意

在不符合标准 C++ 引用绑定规则的编译器上, 可选引用的某些操作被禁用, 以防止细微的缺陷. 详情见 依赖与可移植性一节.

右值引用

在 C++ 中, 右值引用与到 const 的左值引用能够延长它们所绑定的临时对象的生命期. 可选引用没有这一能力, 因此为避免令人意外的效果, 无法从临时对象初始化可选引用. 可选右值引用被完全禁用. 此外, 从右值引用对到 const 的可选引用进行初始化与赋值也被禁用.

const int& i = 1;            // legal
optional<const int&> oi = 1; // illegal
