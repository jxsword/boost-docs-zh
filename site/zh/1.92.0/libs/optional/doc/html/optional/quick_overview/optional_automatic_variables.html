可选自动变量

我们可以用略微不同的方式编写函数 convert, 使它只有一条 return 语句:

boost::optional<int> convert(const std::string& text)
{
  boost::optional<int> ans;
  std::stringstream s(text);
  int i;
  if ((s >> i) && s.get() == std::char_traits<char>::eof())
    ans = i;

  return ans;
}

optional 的默认构造函数创建一个未初始化的可选对象. 与 int 不同, 你不能让 optional<int> 处于不确定状态. 它的状态总是良定义的. 指令 ans = i 初始化该可选对象. 它使用来自 int 的 "混合" 赋值. 一般而言, 对 optional<T> 而言, 当调用来自 T 的赋值时, 它可能做两件事. 若该可选对象未初始化 (本例即如此), 它用 T 的复制构造函数初始化所含值. 若该可选对象已初始化, 它用 T 的复制赋值把新值赋给它.
