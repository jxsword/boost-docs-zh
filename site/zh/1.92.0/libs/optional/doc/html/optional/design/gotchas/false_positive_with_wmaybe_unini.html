-Wmaybe-uninitialized 的误报

有时, 在 5.1 以下的 GCC 编译器上, 用 -O2 选项编译完全有效的 boost::optional 用法时, 你可能会得到 -Wmaybe-uninitialized 警告. 例如在这个程序中:

#include <boost/optional.hpp>

boost::optional<int> getitem();

int main(int argc, const char *[])
{
  boost::optional<int> a = getitem();
  boost::optional<int> b;

  if (argc > 0)
    b = argc;

  if (a != b)
    return 1;

  return 0;
}

这是编译器的一个缺陷. 作为变通办法 (由 这个 Stack Overflow 问题提供), 请使用以下方式初始化一个不含值的 optional:

boost::optional<int> b = boost::make_optional(false, int());

这显然是多余的, 但能让警告消失.
