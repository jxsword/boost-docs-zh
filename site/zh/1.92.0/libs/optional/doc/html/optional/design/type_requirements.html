类型要求

optional<T> 的最低要求是: T 是完整类型且具有公开可访问的析构函数. T 甚至不需要可构造. 你可以使用一个非常精简的接口:

optional<T> o;     // uninitialized
assert(o == none); // check if initialized
assert(!o);        //
o.value();         // always throws

但这实际上毫无用处. 为了让 optional<T> 能做任何有用的事情并提供访问所含值的全部方式, T 需要至少有一个可访问的构造函数. 此时你需要用函数 emplace() 初始化该可选对象; 若你的编译器不支持它, 则求助于 就地工厂:

optional<T> o;
o.emplace("T", "ctor", "params");

若 T 是 MoveConstructible, 则 optional<T> 也是 MoveConstructible 的, 并且可以轻松地从类型 T 的右值初始化并按值传递:

optional<T> o = make_T();
optional<T> p = optional<T>();

若 T 是 CopyConstructible, 则 optional<T> 也是 CopyConstructible 的, 并且可以轻松地从类型 T 的左值初始化:

T v = make_T();
optional<T> o = v;
optional<T> p = o;

若 T 不是 MoveAssignable, 仍可以重置 optional<T> 的值, 所用函数为 emplace():

optional<const T> o = make_T();
o.emplace(make_another_T());

若 T 是 Moveable (同时是 MoveConstructible 与 MoveAssignable), 则 optional<T> 也是 Moveable 的, 并且额外可以从类型 T 的右值构造与赋值.

类似地, 若 T 是 Copyable (同时是 CopyConstructible 与 CopyAssignable), 则 optional<T> 也是 Copyable 的, 并且额外可以从类型 T 的左值构造与赋值.

T 不 被要求是 DefaultConstructible.
