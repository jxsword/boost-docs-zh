详细语义 

template <class CharType, class CharTrait, class T>
std::basic_ostream<CharType, CharTrait>&
operator<<(std::basic_ostream<CharType, CharTrait>& out, optional<T> const& v);
  • 效果: 输出一个实现定义的字符串. 该输出包含可选对象是否含有值的信息. 若 v 含有值, 则该输出包含调用 out << *v 的结果.
  • 返回: out.

template <class CharType, class CharTrait, class T>
std::basic_ostream<CharType, CharTrait>&
operator<<(std::basic_ostream<CharType, CharTrait>& out, none_t);
  • 效果: 输出一个实现定义的字符串.
  • 返回: out.

template <class CharType, class CharTrait, class T>
std::basic_ostream<CharType, CharTrait>&
operator>>(std::basic_istream<CharType, CharTrait>& in, optional<T>& v);
  • 要求: T 是 DefaultConstructible 且 MoveConstructible.
  • 效果: 从 in 读取可选对象的值. 若该字符串表示表明该可选对象应含有值, 则 v 含有值, 且其所含值这样获得: 如同默认构造一个对象 o (类型为 T), 然后调用 in >> o; 否则 v 不含值, 且先前所含的值 (若有) 已被销毁.
  • 返回: out.
