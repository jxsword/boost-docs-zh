就地工厂

包装器与容器的一个典型问题是: 它们的接口通常提供一个操作, 用于把所含对象初始化或赋值为某个其他对象的副本. 这不仅要求底层类型是 CopyConstructible, 还要求存在一个完整构造的对象 (常常是临时对象), 仅仅为了从中复制:

struct X
{
    X ( int, std::string ) ;
} ;

class W
{
    X wrapped_ ;

    public:

    W ( X const& x ) : wrapped_(x) {}
} ;

void foo()
{
    // Temporary object created.
    W ( X(123,"hello") ) ;
}

该问题的一种解决方案是支持直接在容器的存储中就地构造所含对象. 在该方案中, 用户只需提供用于被包装对象构造的构造函数实参.

class W
{
    X wrapped_ ;

    public:

    W ( X const& x ) : wrapped_(x) {}
    W ( int a0, std::string a1) : wrapped_(a0,a1) {}
} ;

void foo()
{
    // Wrapped object constructed in-place
    // No temporary created.
    W (123,"hello") ;
}

该方法的一个局限是: 对于带多个构造函数的被包装对象, 以及构造函数重载未知的泛型代码, 它的扩展性不佳.

本库给出的解决方案是 InPlaceFactories 与 TypedInPlaceFactories 家族. 这些工厂是一族类, 它们封装数量递增的任意构造函数参数, 并提供一个方法: 使用这些参数在用户通过 placement new 指定的地址上构造给定类型的对象.

例如, 该家族的一个成员看起来像:

template<class T,class A0, class A1>
class TypedInPlaceFactory2
{
    A0 m_a0 ; A1 m_a1 ;

    public:

    TypedInPlaceFactory2( A0 const& a0, A1 const& a1 ) : m_a0(a0), m_a1(a1) {}

    void construct ( void* p ) { new (p) T(m_a0,m_a1) ; }
 } ;

知晓此机制的包装器类可以这样使用它:

class W
{
    X wrapped_ ;

    public:

    W ( X const& x ) : wrapped_(x) {}
    W ( TypedInPlaceFactory2 const& fac ) { fac.construct(&wrapped_) ; }
} ;

void foo()
{
    // Wrapped object constructed in-place via a TypedInPlaceFactory.
    // No temporary created.
    W ( TypedInPlaceFactory2<X,int,std::string>(123,"hello")) ;
}

这些工厂分为两组:

  • TypedInPlaceFactories: 把目标类型作为主模板参数的那些.
  • InPlaceFactories: 带有以目标类型为参数的模板 construct(void*) 成员函数的那些.

在每组之内, 家族各成员仅在允许的参数数量上不同.

本库提供了一组重载的辅助模板函数来构造这些工厂, 而无需多余模板参数:

template<class A0,...,class AN>
InPlaceFactoryN <A0,...,AN> in_place ( A0 const& a0, ..., AN const& aN) ;

template<class T,class A0,...,class AN>
TypedInPlaceFactoryN <T,A0,...,AN> in_place ( T const& a0, A0 const& a0, ..., AN const& aN) ;

就地工厂可以按如下方式被包装器与用户泛型地使用:

class W
{
    X wrapped_ ;

    public:

    W ( X const& x ) : wrapped_(x) {}

    template< class InPlaceFactory >
    W ( InPlaceFactory const& fac ) { fac.template <X>construct(&wrapped_) ; }

} ;

void foo()
{
    // Wrapped object constructed in-place via a InPlaceFactory.
    // No temporary created.
    W ( in_place(123,"hello") ) ;
}

这些工厂实现于头文件: in_place_factory.hpp 与 typed_in_place_factory.hpp

注意

对就地工厂的支持已被弃用. 请改用接受 in_place_init 标签的构造函数与函数 .emplace().
