关于 optional<bool> 的说明

optional<bool> 应特别谨慎并深思熟虑地使用.

首先, 它在功能上类似于三态布尔 (false, maybe, true)——如 boost::tribool——但在三态布尔中, maybe 状态 表示一个有效值, 而未初始化的 optional<bool> 的对应状态则不然. 应仔细考虑是否真的需要 optional<bool> 而不是 tribool.

其次, 尽管 optional<> 在 C++11 中提供到 bool 的按语境转换, 但在较旧的编译器上它会退化为隐式转换. 该转换指的是初始化状态而非所含的值. 使用 optional<bool> 可能由于隐式 bool 转换而导致细微的错误:

void foo ( bool v ) ;
void bar()
{
    optional<bool> v = try();

    // The following intended to pass the value of 'v' to foo():
    foo(v);
    // But instead, the initialization state is passed
    // due to a typo: it should have been foo(*v).
}

唯一的隐式转换是到 bool, 而且它是安全的, 因为典型的整型提升不适用 (即若 foo() 接受 int, 它将无法编译).

第三, 与 bool 的混合比较的工作方式不同于指针与 bool 之间类似的混合比较, 因此结果可能让你意外:

optional<bool> oEmpty(none), oTrue(true), oFalse(false);

if (oEmpty == none);  // renders true
if (oEmpty == false); // renders false!
if (oEmpty == true);  // renders false!

if (oFalse == none);  // renders false
if (oFalse == false); // renders true!
if (oFalse == true);  // renders false

if (oTrue == none);   // renders false
if (oTrue == false);  // renders false
if (oTrue == true);   // renders true

换句话说, 对于 optional<>, 以下断言不成立:

assert((opt == false) == (!opt));
