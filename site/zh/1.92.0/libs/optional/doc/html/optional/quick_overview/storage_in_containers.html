容器中的存储

假设你想请用户选择某个数字 (一个 int). 一种有效回应是什么都不选, 用一个未初始化的 optional<int> 表示. 你想制作一个直方图, 显示每个选择被做出的次数. 你可以使用 std::map:

std::map<boost::optional<int>, int> choices;

for (int i = 0; i < LIMIT; ++i) {
  boost::optional<int> choice = readChoice();
  ++choices[choice];
}

这之所以可行, 是因为 optional<T> 是 LessThanComparable, 只要 T 是 LessThanComparable. 在此情形下, 未初始化状态被视为 T 的又一个值, 它小于 T 的任何值. optional<T> 也可以作为键存储在 std::unordered_map 与 std::unordered_set 中, 因为它为 std::hash 提供了特化.
