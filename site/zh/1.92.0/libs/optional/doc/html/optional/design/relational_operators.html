关系运算符

类型 optional<T> 是 EqualityComparable, 只要 T 是 EqualityComparable. 两个含值的可选对象按其所含值相同的方式进行比较. optional<T> 的未初始化状态被视为一个独特的值: 等于其自身, 不等于类型 T 的任何值:

boost::optional<int> oN = boost::none;
boost::optional<int> o0 = 0;
boost::optional<int> o1 = 1;

assert(oN != o0);
assert(o1 != oN);
assert(o0 != o1);
assert(oN == oN);
assert(o0 == o0);

从 T 以及从 boost::none 进行的转换构造函数, 蕴含了 T 与 optional<T> 之间以及 none_t 与 optional<T> 之间的混合比较的存在性与语义:

assert(oN != 0);
assert(o1 != boost::none);
assert(o0 != 1);
assert(oN == boost::none);
assert(o0 == 0);

这种混合比较有一种实用解释, 偶尔有用:

boost::optional<int> choice = ask_user();
if (choice == 2)
    start_procedure_2();

在上面的示例中, 比较的含义是 '用户选择了数字 2'. 若用户什么都没选, 他就没有选择数字 2.

在 optional<T> 与 none 比较的情形下, 不要求 T 是 EqualityComparable.

类似地, 类型 optional<T> 是 LessThanComparable, 只要 T 是 LessThanComparable. 不含值的可选对象小于 T 的任何值. 为说明这一点, 若 size_t 的默认排序是 {0, 1, 2, ...}, 则 optional<size_t> 的默认排序是 {boost::none, 0, 1, 2, ...}. 这种排序没有实用解释. 其目标是拥有任何语义正确的默认排序, 以便 optional<T> 能用于有序关联容器 (凡 T 可用之处).

混合关系运算是唯一无需使用值访问函数 (operator*、value、value_or) 就能检查可选对象所含值的情形.
