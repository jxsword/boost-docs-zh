详细语义 - std::hash 特化 

namespace std {

template <typename T>
struct hash<boost::optional<T> > ;

template <typename T>
struct hash<boost::optional<T&> > ;

} // namespace std

特化 hash<optional<T>> 当且仅当 hash<remove_const_t<T>> 被启用时才启用. 启用时, 对对象 o (其类型为 optional<T>), 若 o.has_value() == true, 则 hash<optional<T>>()(o) 求值为与 hash<remove_const_t<T>>()(*o) 相同的值; 否则其求值为未指明的值. 不保证这些成员函数是 noexcept 的.

注意

当你的程序为 std::hash<boost::optional<T>> 提供特化时, 你可能会遇到编译器报错. 若发生这种情况, 请定义宏 BOOST_OPTIONAL_CONFIG_DO_NOT_SPECIALIZE_STD_HASH 以禁用本库中 std::hash 的特化.
