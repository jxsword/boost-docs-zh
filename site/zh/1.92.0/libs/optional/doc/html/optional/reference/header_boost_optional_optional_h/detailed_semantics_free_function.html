详细语义 - 自由函数

optional<T> make_optional( T const& v )

  • 返回: optional<T>(v), 其中 被推导 出的类型 T 来自 v.

  • 示例: 

    template<class T> void foo ( optional<T> const& opt ) ;

foo ( make_optional(1+1) ) ; // Creates an optional<int>

optional<std::decay_t<T>> make_optional( T && v )

  • 返回: optional<std::decay_t<T>>(std::move(v)), 其中 被推导 出的类型 T 来自 v.

optional<T> make_optional( bool condition, T const& v )

  • 返回: optional<T>(condition, v), 其中 被推导 出的类型 T 来自 v.

  • 示例: 

    optional<double> calculate_foo()
{
  double val = compute_foo();
  return make_optional(is_not_nan_and_finite(val),val);
}

optional<double> v = calculate_foo();
if ( !v )
  error("foo wasn't computed");

optional<std::decay_t<T>> make_optional( bool condition, T && v )

  • 返回: optional<std::decay_t<T>>(condition, std::move(v)), 其中 被推导 出的类型 T 来自 v.

bool operator == ( optional<T> const& x, optional<T> const& y );

  • 要求: T 应满足 EqualityComparable 的要求.
  • 返回: 若 x 与 y 都已初始化, 则为 (*x == *y). 若只有 x 或 y 已初始化, 则为 false. 若两者都未初始化, 则为 true.
  • 注释: 该定义保证: 不含值的 optional<T> 与任何含值的 optional<T> 比较不相等, 且与任何其他不含值的 optional<T> 比较相等. 指针拥有浅层关系运算符, 而 optional 拥有深层关系运算符. 不要在泛型代码中直接使用 operator==, 该代码期望被给予 optional<T> 或指针; 请改用 equal_pointees()

  • 示例: 

    optional<T> oN, oN_;
optional<T> o1(T(1)), o1_(T(1));
optional<T> o2(T(2));

assert ( oN == oN );  // Identity implies equality
assert ( o1 == o1 );  //

assert ( oN == oN_ ); // Both uninitialized compare equal

assert ( oN != o1 );  // Initialized unequal to initialized.

assert ( o1 == o1_ ); // Both initialized compare as (*lhs == *rhs)
assert ( o1 != o2 );  //

bool operator < ( optional<T> const& x, optional<T> const& y );

  • 要求: 表达式 *x < *y 应当良构, 且其结果应可转换为 bool.
  • 返回: (!y) ? false : (!x) ? true : *x < *y.
  • 注释: 该定义保证: 不含值的 optional<T> 被排序为小于任何含值的 optional<T>, 且等价于任何其他不含值的 optional<T>. 指针拥有浅层关系运算符, 而 optional 拥有深层关系运算符. 不要在泛型代码中直接使用 operator<, 该代码期望被给予 optional<T> 或指针; 请改用 less_pointees(). T 不必是 LessThanComparable. 只需要一个 operator<. 其他关系运算都以它来定义. 若 T 的 operator< 满足 LessThanComparable 的公理 (传递性、反对称性与反自反性), 则 optional<T> 是 LessThanComparable.

  • 示例: 

    optional<T> oN, oN_;
optional<T> o0(T(0));
optional<T> o1(T(1));

assert ( !(oN < oN) );  // Identity implies equivalence
assert ( !(o1 < o1) );

assert ( !(oN < oN_) ); // Two uninitialized are equivalent
assert ( !(oN_ < oN) );

assert ( oN < o0 );     // Uninitialized is less than initialized
assert ( !(o0 < oN) );

assert ( o1 < o2 ) ;    // Two initialized compare as (*lhs < *rhs)
assert ( !(o2 < o1) ) ;
assert ( !(o2 < o2) ) ;

bool operator != ( optional<T> const& x, optional<T> const& y );

  • 返回: !( x == y );

bool operator > ( optional<T> const& x, optional<T> const& y );

  • 返回: ( y < x );

bool operator <= ( optional<T> const& x, optional<T> const& y );

  • 返回: !( y < x );

bool operator >= ( optional<T> const& x, optional<T> const& y );

  • 返回: !( x < y );

bool operator == ( optional<T> const& x, none_t ) noexcept;

bool operator == ( none_t, optional<T> const& x ) noexcept;

  • 返回: !x.
  • 注释: T 不必满足 EqualityComparable 的要求.

bool operator != ( optional<T> const& x, none_t ) noexcept;

bool operator != ( none_t, optional<T> const& x ) noexcept;

  • 返回: bool(x);

auto get_pointer ( optional<T>& o ) -> typename optional<T>::pointer_type ;

auto get_pointer ( optional<T> const& o ) -> typename optional<T>::pointer_const_type ;

  • 返回: o.get_ptr().
  • 抛出: 无.

auto get_optional_value_or ( optional<T>& o, typename optional<T>::reference_type def ) -> typename optional<T>::reference_type ;

auto get_optional_value_or ( optional<T> const& o, typename optional<T>::reference_const_type def ) -> typename optional<T>::reference_const_type ;

  • 返回: o.get_value_or(def).
  • 抛出: 无.
  • 备注: 该函数已被弃用.

void swap ( optional<T>& x, optional<T>& y ) ;

  • 要求: 类型 T 的左值应当可交换 (swappable), 且 T 应当是 MoveConstructible.

  • 效果:

    表 5. []

    *this 含有值

    *this 不含值

    rhs 含有值

    调用 swap(*(*this), *rhs)

    把 *this 的所含值初始化, 如同把一个类型为 T 的对象, 用表达式 std::move(*rhs) 直接初始化, 随后 rhs.val->T::~T(); *this 含有值而 rhs 不含值

    rhs 不含值

    把 rhs 的所含值初始化, 如同把一个类型为 T 的对象, 用表达式 std::move(*(*this)) 直接初始化, 随后 val->T::~T(); *this 含有值而 rhs 不含值

    无效果

  • 后置条件: x 与 y 的状态互换.
  • 抛出: 若两者都已初始化, 则为 swap(T&,T&) 抛出的任何异常. 若只有一个已初始化, 则为 T::T ( T&& ) 抛出的任何异常.

  • 示例: 

    T x(12);
T y(21);
optional<T> def0 ;
optional<T> def1 ;
optional<T> optX(x);
optional<T> optY(y);

boost::swap(def0,def1); // no-op

boost::swap(def0,optX);
assert ( *def0 == x );
assert ( !optX );

boost::swap(def0,optX); // Get back to original values

boost::swap(optX,optY);
assert ( *optX == y );
assert ( *optY == x );

void swap ( optional<T&>& x, optional<T&>& y ) noexcept ;

  • 后置条件: x 引用交换前 y 所引用的对象 (若有). y 引用交换前 x 所引用的任何对象.

  • 示例: 

    T x(12);
T y(21);

optional<T&> opt0;
optional<T&> optX (x);
optional<T&> optY (y);

boost::swap(optX, optY);
assert (addressof(*optX) == addressof(y));
assert (addressof(*optY) == addressof(x));

boost::swap(opt0, optX);
assert ( opt0 );
assert ( !optX );
assert (addressof(*opt0) == addressof(y));
