与 std::optional

表 6. 与 std::optional

boost::optional

std::optional

optional<int> o = none;

optional<int> o = nullopt;

无值标签的名称不同.

optional<X> o {in_place_init, a, b};

optional<int> o {in_place, a, b};

就地初始化标签的名称不同.

optional<vector<int>> o {in_place, {1, 2, 3}};

o.emplace({4, 5, 6});

boost 中没有使用初始化列表的就地初始化.

optional<X> o {in_place_init_if, cond, a, b};

std 中没有条件就地初始化的语法.

optional<X> o {cond, x};

没有从 T 进行条件初始化的语法, 在 std 中.

optional<T> o {U{}};

optional<T> o {optional<U>{}};

optional<T> o = U{};

optional<T> o = optional<U>{}

来自 U 与 optional<U> 的构造函数在 boost 中是显式的, 而在 std 中是隐式的.

optional o = 1;

没有对 optional 模板参数的巧妙推导, 在 boost 的初始化中.

optional<X const&> o;

std 中没有可选引用.

constexpr optional<int> o;

没有 constexpr 接口, 在 boost 中.

o.map(&f);

o.flat_map(&of);

o.transform(&f);

o.and_then(&of);

单子接口函数的名称与签名不同. boost 按值接受回调, std 按万能引用接受.

o.or_else(&of);

没有 or_else 函数, 在 boost 中.

o.value_or_eval(&f);

没有 value_or_eval 函数, 在 std 中.

optional<T>{} == U{};

optional<T>{} == optional<U>{}

没有与 U 或 optional<U> 的比较, 在 boost 中.

make_optional(cond, v);

没有带条件的 make_optional, 在 std 中.

make_optional<T>(a, b);

没有 make_optional (带指定的 T), 在 boost 中.

std::cout << optional<int>{};

std 中没有到 IOStream 的打印.

std::vector<optional<int>> rng;

std::ranges::find(rng, boost::none)

std::vector<optional<int>> rng;

std::ranges::find(rng, boost::optional<int>{})

optional<T> 从不是 std::equality_comparable_with 的 nullopt_t, 在 std 中.

 
void test(vector<optional<T>> rng, T val) {
  std::ranges::find(rng, val);
}

void test(vector<optional<T>> rng, T val) {
  std::ranges::find(rng, make_optional(val));
}

对于 std::optional, 不使用 make_optional() 的代码可以编译, 但这是 未定义行为, 若 T 本身是一个 optional.
