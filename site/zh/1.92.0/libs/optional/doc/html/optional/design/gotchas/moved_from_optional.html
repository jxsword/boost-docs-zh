被移动后的 optional

当一个含值的 optional 对象被移出 (作为移动构造或赋值的来源) 时, 它仍含有一个值, 且其含有的值处于被移动后的状态. 下面的示例可以说明这一点.

optional<std::unique_ptr<int>> opi {std::make_unique<int>(1)};
optional<std::unique_ptr<int>> opj = std::move(opi);
assert (opi);
assert (*opi == nullptr);

相当多的人期望: 当一个含值的对象被移出后, 其含有的值应当被销毁. 出于性能原因, 事实并非如此. 当前语义允许 boost::optional<T> 的实现在 T 为平凡类型时是平凡可复制的.
