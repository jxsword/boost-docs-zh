IO 运算符

可以把 optional<T> 用于 IO 流, 前提是 T 可以用于流. IOStream 运算符定义在一个单独的头文件中.

#include <iostream>
#include <boost/optional/optional_io.hpp>

int main()
{
  boost::optional<int> o1 = 1, oN = boost::none;
  std::cout << o1;
  std::cin >> oN;
}

当前实现不保证任何特定的输出. 它保证的是: 若把 T 先流出再流入得到相同的值, 那么把 optional<T> 先流出再流入也会得到相同的结果:

#include <cassert>
#include <sstream>
#include <boost/optional/optional_io.hpp>

int main()
{
  boost::optional<int> o1 = 1, oN = boost::none;
  boost::optional<int> x1, x2;
  std::stringstream s;
  s << o1 << oN;
  s >> x1 >> x2;
  assert (o1 == x1);
  assert (oN == x2);
}
