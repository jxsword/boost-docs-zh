详细语义 - 可选值

注释

以下一节包含各种 assert(), 它们仅用于以后置条件作为示例代码展示. 这并不意味着类型 T 必须支持每个具体的表达式, 而是说若该表达式受支持, 则所蕴含的条件成立.

constexpr optional<T>::optional() noexcept;

  • 后置条件: *this 不 含有值 (即 "未初始化").
  • 备注: 不初始化所含值. 对每个对象类型 T, 这些构造函数都是核心常量表达式.

  • 示例: 

    optional<T> oN ;
assert ( !oN ) ;

constexpr optional<T>::optional( none_t ) noexcept;

  • 后置条件: *this 不 含有值 (即 "未初始化").
  • 备注: 不初始化所含值. 对每个对象类型 T, 这些构造函数都是核心常量表达式. 表达式 boost::none 表示一个可用作该参数的 boost::none_t 实例.

  • 示例: 

    #include <boost/none.hpp>

optional<T> n(none) ;
assert ( !n ) ;
assert ( n == none ) ;

constexpr optional<T>::optional( T const& v )

  • 要求: is_copy_constructible<T>::value 是 true.
  • 效果: 直接构造一个 optional.
  • 后置条件: *this 是 initialized 的 (已初始化), 其值是 副本, 来自 v.
  • 抛出: T::T( T const& ) 抛出的任何异常.
  • 注释: T::T( T const& ) 被调用.
  • 异常安全: 异常只可能在 T::T( T const& ); 期间被抛出; 此时该构造函数没有任何效果.

  • 示例: 

    T v;
optional<T> opt(v);
assert ( *opt == v ) ;

constexpr optional<T>::optional( T&& v )

  • 要求: is_move_constructible<T>::value 是 true.
  • 效果: 直接移动构造一个 optional.
  • 后置条件: *this 是 initialized 的 (已初始化), 其值从 v 移动构造而来.
  • 抛出: T::T( T&& ) 抛出的任何异常.
  • 注释: T::T( T&& ) 被调用.
  • 异常安全: 异常只可能在 T::T( T&& ); 期间被抛出; 此时 v 的状态由 T::T(T&&) 的异常安全保证决定.

  • 示例: 

    T v1, v2;
optional<T> opt(std::move(v1));
assert ( *opt == v2 ) ;

constexpr optional<T>::optional( bool condition, T const& v ) ;

  • 若条件为真, 等同于:

optional<T>::optional( T const& v )

  • 否则, 等同于:

optional<T>::optional()

constexpr optional<T>::optional( optional const& rhs );

  • 要求: is_copy_constructible<T>::value 是 true.
  • 效果: 复制构造一个 optional.
  • 后置条件: 若 rhs 已初始化, *this 被初始化, 其值是 副本, 来自 rhs 的值; 否则 *this 未初始化.
  • 抛出: T::T( T const& ) 抛出的任何异常.
  • 注释: 若 rhs 已初始化, T::T(T const& ) 被调用.
  • 异常安全: 异常只可能在 T::T( T const& ); 期间被抛出; 此时该构造函数没有任何效果.

  • 示例: 

    optional<T> uninit ;
assert (!uninit);

optional<T> uinit2 ( uninit ) ;
assert ( uninit2 == uninit );

optional<T> init( T(2) );
assert ( *init == T(2) ) ;

optional<T> init2 ( init ) ;
assert ( init2 == init ) ;

constexpr optional<T>::optional( optional&& rhs ) noexcept(见下文);

  • 要求: is_move_constructible<T>::value 是 true.
  • 效果: 移动构造一个 optional.
  • 后置条件: 若 rhs 已初始化, *this 被初始化, 其值从 rhs 移动构造而来; 否则 *this 未初始化.
  • 抛出: T::T( T&& ) 抛出的任何异常.
  • 备注: noexcept 内的表达式等价于 is_nothrow_move_constructible<T>::value.
  • 注释: 若 rhs 已初始化, T::T( T && ) 被调用.
  • 异常安全: 异常只可能在 T::T( T&& ); 期间被抛出; 此时 rhs 保持已初始化, 且 *rhs 的值由 T::T(T&&) 的异常安全性决定.

  • 示例: 

    optional<std::unique_ptr<T>> uninit ;
assert (!uninit);

optional<std::unique_ptr<T>> uinit2 ( std::move(uninit) ) ;
assert ( uninit2 == uninit );

optional<std::unique_ptr<T>> init( std::unique_ptr<T>(new T(2)) );
assert ( **init == T(2) ) ;

optional<std::unique_ptr<T>> init2 ( std::move(init) ) ;
assert ( init );
assert ( *init == nullptr );
assert ( init2 );
assert ( **init2 == T(2) ) ;

template<U> constexpr explicit optional<T>::optional( optional<U> const& rhs );

  • 效果: 复制构造一个 optional.
  • 后置条件: 若 rhs 已初始化, *this 被初始化, 其值是 副本, 来自 rhs 的值转换到类型 T 之后的结果; 否则 *this 未初始化.
  • 抛出: T::T( U const& ) 抛出的任何异常.
  • 注释: T::T( U const& ) 被调用, 若 rhs 已初始化; 这要求从 U 到 T 的有效转换.
  • 异常安全: 异常只可能在 T::T( U const& ); 期间被抛出; 此时该构造函数没有任何效果.

  • 示例: 

    optional<double> x(123.4);
assert ( *x == 123.4 ) ;

optional<int> y(x) ;
assert( *y == 123 ) ;

template<U> constexpr explicit optional<T>::optional( optional<U>&& rhs );

  • 效果: 移动构造一个 optional.
  • 后置条件: 若 rhs 已初始化, *this 被初始化, 其值从 *rhs 移动构造而来; 否则 *this 未初始化.
  • 抛出: T::T( U&& ) 抛出的任何异常.
  • 注释: T::T( U&& ) 被调用, 若 rhs 已初始化; 这要求从 U 到 T 的有效转换.
  • 异常安全: 异常只可能在 T::T( U&& ); 期间被抛出; 此时 rhs 保持已初始化, 且 *rhs 的值由 T::T( U&& ) 的异常安全保证决定.

  • 示例: 

    optional<double> x(123.4);
assert ( *x == 123.4 ) ;

optional<int> y(std::move(x)) ;
assert( *y == 123 ) ;

template<class... Args> constexpr explicit optional<T>::optional( in_place_init_t, Args&&... ars );

  • 要求: is_constructible_v<T, Args&&...> 是 true.
  • 效果: 初始化所含值, 如同对一个类型为 T 的对象, 以实参 std::forward<Args>(args)... 执行直接非列表初始化.
  • 后置条件: *this 已初始化.
  • 抛出: T 被选中的构造函数抛出的任何异常.
  • 注释: T 不必是 MoveConstructible.

  • 示例: 

    // creates an std::mutex using its default constructor
optional<std::mutex> om {in_place_init};
assert (om);

// creates a unique_lock by calling unique_lock(*om, std::defer_lock)
optional<std::unique_lock<std::mutex>> ol {in_place_init, *om, std::defer_lock};
assert (ol);
assert (!ol->owns_lock());

template<class... Args> constexpr explicit optional<T>::optional( in_place_init_if_t, bool condition, Args&&... ars );

  • 要求: is_constructible_v<T, Args&&...> 是 true.
  • 效果: 若 condition 是 true, 初始化所含值, 如同对一个类型为 T 的对象, 以实参 std::forward<Args>(args)... 执行直接非列表初始化.
  • 后置条件: bool(*this) == condition.
  • 抛出: T 被选中的构造函数抛出的任何异常.
  • 注释: T 不必是 MoveConstructible.

  • 示例: 

    optional<std::vector<std::string>> ov1 {in_place_init_if, false, 3, "A"};
assert (!ov1);

optional<std::vector<std::string>> ov2 {in_place_init_if, true, 3, "A"};
assert (ov2);
assert (ov2->size() == 3);

template<InPlaceFactory> explicit optional<T>::optional( InPlaceFactory const& f );

template<TypedInPlaceFactory> explicit optional<T>::optional( TypedInPlaceFactory const& f );

  • 效果: 构造一个 optional, 其值为从工厂获得的 T.
  • 后置条件: *this 是 initialized 的 (已初始化), 其值是 直接给出 自工厂 f 的 (即该值 未被复制).
  • 抛出: 工厂所调用的 T 构造函数抛出的任何异常.
  • 注释: 参见 就地工厂
  • 异常安全: 异常只可能在调用工厂所用的 T 构造函数期间被抛出; 此时该构造函数没有任何效果.

  • 示例: 

    class C { C ( char, double, std::string ) ; } ;

C v('A',123.4,"hello");

optional<C> x( in_place   ('A', 123.4, "hello") ); // InPlaceFactory used
optional<C> y( in_place<C>('A', 123.4, "hello") ); // TypedInPlaceFactory used

assert ( *x == v ) ;
assert ( *y == v ) ;

constexpr optional& optional<T>::operator= ( none_t ) noexcept;

  • 效果: 若 *this 已初始化, 则销毁其含有的值.
  • 后置条件: *this 未初始化.

optional& optional<T>::operator= ( T const& rhs ) ;

  • 效果: 把值 rhs 赋给一个 optional.
  • 后置条件: *this 已初始化, 其值是 副本, 来自 rhs.
  • 抛出: T::operator=( T const& ) 或 T::T(T const&) 抛出的任何异常.
  • 注释: 若 *this 已初始化, 则使用 T 的赋值运算符; 否则使用其复制构造函数.
  • 异常安全: 若发生异常, *this 的初始化状态保持不变, 而就 optional 而言其值是未指明的 (这取决于 T 的 operator=()). 若 *this 初始时未初始化, 且 T 的 复制构造函数 失败, 则 *this 保持恰当的未初始化状态.

  • 示例: 

    T x;
optional<T> def ;
optional<T> opt(x) ;

T y;
def = y ;
assert ( *def == y ) ;
opt = y ;
assert ( *opt == y ) ;

optional& optional<T>::operator= ( T&& rhs ) ;

  • 效果: 把值 rhs 移动到一个 optional.
  • 后置条件: *this 已初始化, 其值从 rhs 移动而来.
  • 抛出: T::operator=( T&& ) 或 T::T(T &&) 抛出的任何异常.
  • 注释: 若 *this 已初始化, 则使用 T 的移动赋值运算符; 否则使用其移动构造函数.
  • 异常安全: 若发生异常, *this 的初始化状态保持不变, 而就 optional 而言其值是未指明的 (这取决于 T 的 operator=()). 若 *this 初始时未初始化, 且 T 的 移动构造函数 失败, 则 *this 保持恰当的未初始化状态.

  • 示例: 

    T x;
optional<T> def ;
optional<T> opt(x) ;

T y1, y2, yR;
def = std::move(y1) ;
assert ( *def == yR ) ;
opt = std::move(y2) ;
assert ( *opt == yR ) ;

optional& optional<T>::operator= ( optional const& rhs ) ;

  • 要求: T 是 CopyConstructible 且 CopyAssignable.

  • 效果:

    表 1. []

    *this 含有值

    *this 不含值

    rhs 含有值

    把 *rhs 赋给所含值

    初始化所含值, 如同对一个类型为 T 的对象, 用 *rhs 直接初始化

    rhs 不含值

    通过调用 val->T::~T() 销毁所含值

    无效果

  • 返回: *this;
  • 后置条件: bool(rhs) == bool(*this).
  • 异常安全: 若抛出任何异常, *this 与 rhs 的初始化状态保持不变. 若在调用 T 的复制构造函数期间抛出异常, 则没有任何效果. 若在调用 T 的复制赋值期间抛出异常, 其所含值的状态由 T 的复制赋值的异常安全保证定义.

  • 示例: 

    T v;
optional<T> opt(v);
optional<T> def ;

opt = def ;
assert ( !def ) ;
// previous value (copy of 'v') destroyed from within 'opt'.

optional& optional<T>::operator= ( optional&& rhs ) noexcept(见下文);

  • 要求: T 是 MoveConstructible 且 MoveAssignable.

  • 效果:

    表 2. []

    *this 含有值

    *this 不含值

    rhs 含有值

    把 std::move(*rhs) 赋给所含值

    初始化所含值, 如同对一个类型为 T 的对象, 用 std::move(*rhs) 直接初始化

    rhs 不含值

    通过调用 val->T::~T() 销毁所含值

    无效果

  • 返回: *this;
  • 后置条件: bool(rhs) == bool(*this).
  • 备注: noexcept 内的表达式等价于 is_nothrow_move_constructible<T>::value && is_nothrow_move_assignable<T>::value.
  • 异常安全: 若抛出任何异常, *this 与 rhs 的初始化状态保持不变. 若在调用 T 的移动构造函数期间抛出异常, *rhs 的状态由 T 的移动构造函数的异常安全保证决定. 若在调用 T 的移动赋值期间抛出异常, **this 与 *rhs 的状态由 T 的移动赋值的异常安全保证决定.

  • 示例: 

    optional<T> opt(T(2)) ;
optional<T> def ;

opt = def ;
assert ( def ) ;
assert ( opt ) ;
assert ( *opt == T(2) ) ;

template<U> optional& optional<T>::operator= ( optional<U> const& rhs ) ;

  • 效果:

    表 3. []

    *this 含有值

    *this 不含值

    rhs 含有值

    把 *rhs 赋给所含值

    初始化所含值, 如同对一个类型为 T 的对象, 用 *rhs 直接初始化

    通过调用 val->T::~T() 销毁所含值

  • 异常安全: 若抛出任何异常, 表达式 bool(*this) 的结果保持不变. 若在调用 T 的构造函数期间抛出异常, 则没有任何效果. 若在调用 T 的赋值期间抛出异常, 其所含值的状态由 T 的复制赋值的异常安全保证定义.

    T v;

template<U> optional& optional<T>::operator= ( optional<U>&& rhs ) ;

  • 效果:

    *this 含有值

    *this 不含值

    rhs 含有值

    把 std::move(*rhs) 赋给所含值

  • 异常安全: 若抛出任何异常, 表达式 bool(*this) 的结果保持不变. 若在调用 T 的构造函数期间抛出异常, 则没有任何效果. 若在调用 T 的赋值期间抛出异常, 其所含值的状态由 T 的复制赋值的异常安全保证定义.

optional<U> opt1;

assert ( opt0 );

template<class... Args> void optional<T>::emplace( Args&&... args );

  • 要求: 编译器支持右值引用与可变参数模板.
  • 效果: 若 *this 已初始化, 则调用 *this = none. 然后就地初始化所含值, 如同对一个类型为 T 的对象, 用 std::forward<Args>(args)... 直接初始化.
  • 后置条件: *this 是 initialized 的 (已初始化).
  • 抛出: 被选中的 T 的构造函数抛出的任何异常.
  • 异常安全: 若在 T 的初始化期间抛出异常, *this 是 未初始化 的.
  • 注释: T 不必是 MoveConstructible 或 MoveAssignable.

  • 示例: 

    T v;
optional<const T> opt;
opt.emplace(0);  // create in-place using ctor T(int)
opt.emplace();   // destroy previous and default-construct another T
opt.emplace(v);  // destroy and copy-construct in-place (no assignment called)

template<InPlaceFactory> optional<T>& optional<T>::operator=( InPlaceFactory const& f );

template<TypedInPlaceFactory> optional<T>& optional<T>::operator=( TypedInPlaceFactory const& f );

  • 效果: 给一个 optional 赋以从工厂获得的 T 值.
  • 后置条件: *this 是 initialized 的 (已初始化), 其值是 直接给出 自工厂 f 的 (即该值 未被复制).
  • 抛出: 工厂所调用的 T 构造函数抛出的任何异常.
  • 注释: 参见 就地工厂
  • 异常安全: 异常只可能在调用工厂所用的 T 构造函数期间被抛出; 此时该 optional 对象将被重置为 未初始化.

void optional<T>::reset( T const& v ) ;

  • 弃用: 同 operator= ( T const& v) ;

constexpr void optional<T>::reset() noexcept ;

  • 效果: 同 operator=( none_t );

constexpr T const& optional<T>::get() const ;

constexpr T& optional<T>::get() ;

inline T const& get ( optional<T> const& ) ;

inline T& get ( optional<T> &) ;

  • 要求: *this 已初始化
  • 返回: 对所含值的引用
  • 抛出: 无.
  • 注释: 该要求通过 BOOST_ASSERT() 断言.

constexpr T const& optional<T>::operator*() const& ;

constexpr T& optional<T>::operator*() &;

  • 要求: *this 已初始化
  • 返回: 对所含值的引用
  • 抛出: 无.
  • 注释: 该要求通过 BOOST_ASSERT() 断言. 在不支持成员函数引用限定符的编译器上, 这两个重载被替换为经典的两员: 一个 const 成员函数与一个非 const 的成员函数.

  • 示例: 

    T v ;
optional<T> opt ( v );
T const& u = *opt;
assert ( u == v ) ;
T w ;
*opt = w ;
assert ( *opt == w ) ;

constexpr T&& optional<T>::operator*() &&;

  • 要求: *this 含有值.
  • 效果: 等价于 return std::move(*val);.
  • 注释: 该要求通过 BOOST_ASSERT() 断言. 在不支持成员函数引用限定符的编译器上, 此重载不存在.

constexpr T const& optional<T>::value() const& ;

constexpr T& optional<T>::value() & ;

  • Effects: Equivalent to return bool(*this) ? *val : throw bad_optional_access();.
  • 注释: 在不支持成员函数引用限定符的编译器上, 这两个重载被替换为经典的两员: 一个 const 成员函数与一个非 const 的成员函数.

  • 示例: 

    T v ;
optional<T> o0, o1 ( v );
assert ( o1.value() == v );

try {
  o0.value(); // throws
  assert ( false );
}
catch(bad_optional_access&) {
  assert ( true );
}

constexpr T&& optional<T>::value() && ;

  • 效果: 等价于 return bool(*this) ? std::move(*val) : throw bad_optional_access();.
  • 注释: 在不支持成员函数引用限定符的编译器上, 此重载不存在.

template<class U = T> constexpr T optional<T>::value_or(U && v) const& ;

  • 效果: 等价于 if (*this) return **this; else return std::forward<U>(v);.
  • 备注: 若 T 不是 CopyConstructible, 或 U && 不能转换为 T, 则程序非良构.
  • 注释: 在不支持成员函数引用限定符的编译器上, 此重载被替换为 const 限定的成员函数. 在不支持右值引用的编译器上, v 的类型变为 U const&.

  • 示例: 

    optional<int> oN, o1(1);

assert (o1.value_or(9) == 1);
assert (oN.value_or(9) == 9);
assert (oN.value_or({}) == 0);

template<class U> constexpr T optional<T>::value_or(U && v) && ;

  • 效果: 等价于 if (*this) return std::move(**this); else return std::forward<U>(v);.
  • 备注: 若 T 不是 MoveConstructible, 或 U && 不能转换为 T, 则程序非良构.
  • 注释: 在不支持成员函数引用限定符的编译器上, 此重载不存在.

template<class F> constexpr T optional<T>::value_or_eval(F f) const& ;

  • 要求: T 是 CopyConstructible 的, 且 F 建模一个 Generator, 其结果类型可转换为 T.
  • 效果: if (*this) return **this; else return f();.
  • 注释: 在不支持成员函数引用限定符的编译器上, 此重载被替换为 const 限定的成员函数.

  • 示例: 

    int complain_and_0()
{
  clog << "no value returned, using default" << endl;
  return 0;
}

optional<int> o1 = 1;
optional<int> oN = none;

int i = o1.value_or_eval(complain_and_0); // fun not called
assert (i == 1);

int j = oN.value_or_eval(complain_and_0); // fun called
assert (i == 0);

template<class F> constexpr T optional<T>::value_or_eval(F f) && ;

  • 要求: T 是 MoveConstructible 的, 且 F 建模一个 Generator, 其结果类型可转换为 T.
  • 效果: if (*this) return std::move(**this); else return f();.
  • 注释: 在不支持成员函数引用限定符的编译器上, 此重载不存在.

template<class F> constexpr auto optional<T>::map(F f) const& -> 见下文 ;

template<class F> constexpr auto optional<T>::map(F f) & -> 见下文 ;

  • 效果: if (*this) return f(**this); else return none;
  • 注释: 这些重载的返回类型是 optional<decltype(f(**this))>. 在不支持成员函数引用限定符的编译器上, 这两个 (以及下一个) 重载被替换为老式的 const 与非 const 重载.

  • 示例: 

    auto length = [](const string& s){ return s.size(); };
optional<string> o1 {}, o2 {"cat"};
optional<size_t> os1 = o1.map(length), os2 = o2.map(length);
assert ( !os1 ) ;
assert ( os2 ) ;
assert ( *os2 == 3 ) ;

template<class F> constexpr auto optional<T>::map(F f) && -> 见下文 ;

  • 效果: if (*this) return f(std::move(**this)); else return none;
  • 注释: 此重载的返回类型是 optional<decltype(f(istd::move(**this)))>.

template<class F> constexpr auto optional<T>::flat_map(F f) const& -> 见下文 ;

template<class F> constexpr auto optional<T>::flat_map(F f) & -> 见下文 ;

  • 要求: 表达式 f(**this) 的返回类型是 optional<U>, 对某个对象或引用类型 U 而言.
  • 效果: if (*this) return f(**this); else return none;
  • 注释: 这些重载的返回类型是 optional<U>. 在不支持成员函数引用限定符的编译器上, 这两个 (以及下一个) 重载被替换为老式的 const 与非 const 重载.

  • 示例: 

    optional<char> first_char(const string& s) {
  return s.empty() ? none : optional<char>(s[0]);
};
optional<string> o1 {}, o2 {"cat"};
optional<char> os1 = o1.flat_map(first_char), os2 = o2.flat_map(first_char);
assert ( !os1 ) ;
assert ( os2 ) ;
assert ( *os2 == 'c' ) ;

template<class F> constexpr auto optional<T>::flat_map(F f) && -> 见下文 ;

  • 要求: 表达式 f(std::move(**this)) 的返回类型是 optional<U>, 对某个对象或引用类型 U 而言.
  • 效果: if (*this) return f(std::move(**this)); else return none;
  • 注释: 此重载的返回类型是 optional<U>.

constexpr optional<T>::operator optional<T&>() & noexcept ;

  • 返回: 若 *this 含有值则为 optional<T&>(**this), 否则为 optional<T&>().

constexpr optional<T>::operator optional<T const&>() const& noexcept ;

  • 返回: 若 *this 含有值则为 optional<T const&>(**this), 否则为 optional<T&>().

  • 示例: 

    const optional<int> oi = 1;
optional<const int&> ri = oi;

T const& optional<T>::get_value_or( T const& default) const ;

T& optional<T>::get_value_or( T& default ) ;

  • 弃用: 请改用 value_or().
  • 返回: 对所含值 (若有) 的引用, 否则为 default.
  • 抛出: 无.

  • 示例: 

    T v, z ;
optional<T> def;
T const& y = def.get_value_or(z);
assert ( y == z ) ;

optional<T> opt ( v );
T const& u = opt.get_value_or(z);
assert ( u == v ) ;
assert ( u != z ) ;

T const* optional<T>::get_ptr() const ;

T* optional<T>::get_ptr() ;

  • 返回: 若 *this 已初始化, 则为指向所含值的指针; 否则为 0 (null).
  • 抛出: 无.
  • 注释: 所含值被永久地存储在 *this 内部, 因此你不应持有也不应删除该指针

  • 示例: 

    T v;
optional<T> opt(v);
optional<T> const copt(v);
T* p = opt.get_ptr() ;
T const* cp = copt.get_ptr();
assert ( p == get_pointer(opt) );
assert ( cp == get_pointer(copt) ) ;

constexpr T const* optional<T>::operator ->() const ;

constexpr T* optional<T>::operator ->() ;

  • 要求: *this 已初始化.
  • 返回: 指向所含值的指针.
  • 抛出: 无.
  • 注释: 该要求通过 BOOST_ASSERT() 断言.

  • 示例: 

    struct X { int mdata ; } ;
X x ;
optional<X> opt (x);
opt->mdata = 2 ;

constexpr explicit optional<T>::operator bool() const noexcept ;

constexpr bool optional<T>::has_value() const noexcept ;

  • 返回: get_ptr() != 0.
  • 注释: 在不支持显式转换运算符的编译器上, 这会退化为 safe-bool 惯用法.

  • 示例: 

    optional<int> oN;
assert (!oN);
assert (!oN.has_value());

optional<int> o1(1);
assert (o1);
assert (o1.has_value());
assert (!!o1);  // the "double-bang" idiom
