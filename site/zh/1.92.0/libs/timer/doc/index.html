Timer 库
版本 2
Timer 主页 CPU 计时器 原始计时器

"我的 C++ 代码要运行多久?"

Boost Timer 库回答了这个问题, 并且做到可移植, 只需一个 #include 和一行附加代码.

Boost Timer 库有两组不同的组件:

  • 如果你刚开始接触本库, 请直接前往版本 2 的 CPU 计时器 页面.
  • 如果你对现已弃用的原始库感兴趣, 请继续阅读下文.

CPU 计时器

这些版本 2 的组件符合当前的 Boost 惯例:

  • 接口及其语义在所有平台上都相同.
  • 内部实现使用操作系统特定的 API 来实现更高的精度, 并提供其他方式无法获得的功能.
  • 头文件位于子目录 <boost/timer/...> 中.
  • 内容位于子命名空间 boost::timer 中.

原始计时器

这些版本 1 的组件已被弃用. 它们源自 Boost 最早的日子, 不符合当前的 Boost 惯例:

  • 接口在所有平台上相同, 但语义因平台而异. 在 Windows 上度量挂钟时间, 而在类 POSIX 系统上度量 CPU 时间.
  • 内部实现仅使用 C/C++ 标准库函数, 因此无法提供理想的精度和功能.
  • 头文件位于 Boost 主头文件目录中.
  • 内容位于命名空间 boost 中.
