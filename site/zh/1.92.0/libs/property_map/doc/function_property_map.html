function_property_map<UnaryFunction, Key, Ref>

该属性映射是一个适配器, 它把一个函数对象转换为 可读属性映射 或 左值属性映射. 属性映射的类别取决于函数的返回类型(由 Ref 给出)是否为非 const 引用类型.

定义位置

boost/property_map/function_property_map.hpp

模型

可读属性映射 或 左值属性映射

模板参数

参数说明默认值
UnaryFunction 必须是 一元函数 (Unary Function) 的模型, 接受一个 Key 类型的对象作为参数并返回 Ref 类型的结果.  
Key 属性映射的键类型.  
Ref 函数的结果类型. boost::result_of<const UnaryFunction(const Key&)>::type

成员

除了 可读属性映射 或 左值属性映射 所要求的方法和函数之外, 该类还具有以下成员: 

property_traits<function_property_map>::value_type
去除任何引用限定符和 cv 限定符后的类型 Ref. 
function_property_map(const UnaryFunction& f = UnaryFunction())
构造函数.

非成员函数

  template <class Key, class UnaryFunction>
  function_property_map<UnaryFunction, Key>
  make_function_property_map(const UnaryFunction& f);
使用给定的函数和键类型返回一个 function_property_map.

  function_property_map<UnaryFunction, Key, Ref>
  make_function_property_map(const UnaryFunction& f);
使用给定的函数以及键类型和引用类型返回一个 function_property_map.
