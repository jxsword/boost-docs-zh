左值属性映射

左值属性映射 (LvaluePropertyMap) 提供 operator[] 和函数 get() 用于访问对值对象的引用. 其返回类型细化了函数 get() 在 ReadablePropertyMap 中的返回类型; 它只能是引用(对于 可变 左值属性映射)或 const 引用(对于 不可变 左值属性映射).

细化自

不可变属性映射对应 ReadablePropertyMap, 可变属性映射对应 ReadWritePropertyMap.

记法

PMap 一个作为左值属性映射 (LvaluePropertyMap) 模型的类型.
pmap 类型为 PMap 的对象.
key 类型为 boost::property_traits<PMap>::key_type 的对象.

关联类型

引用类型 boost::property_traits<PMap>::reference 引用类型, 必须是属性映射值类型的引用或 const 引用.
属性映射类别boost::property_traits<PMap>::category 属性的类别: 一个可转换为 boost::lvalue_property_map_tag 的类型.

有效表达式

名称表达式返回类型说明
访问属性值 pmap[key] 可变时为 value_type&, 否则为 const value_type&. 获取与 key 关联的值的引用.

概念检查类

  template <class PMap, class Key>
  struct LvaluePropertyMapConcept
  {
    typedef typename property_traits<PMap>::category Category;
    typedef boost::lvalue_property_map_tag LvalueTag;
    typedef const typename property_traits<PMap>::value_type& const_reference;
    void constraints() {
      function_requires< ReadWritePropertyMapConcept<PMap, Key> >();
      function_requires< ConvertibleConcept<Category, LvalueTag> >();

      const_reference ref = pmap[k];
    }
    PMap pmap;
    Key k;
  };

  template <class PMap, class Key>
  struct Mutable_LvaluePropertyMapConcept
  {
    typedef typename property_traits<PMap>::category Category;
    typedef boost::lvalue_property_map_tag LvalueTag;
    typedef typename property_traits<PMap>::value_type& reference;
    void constraints() { 
      function_requires< ReadWritePropertyMapConcept<PMap, Key> >();
      function_requires<ConvertibleConcept<Category, LvalueTag> >();

      reference ref = pmap[k];
    }
    PMap pmap;
    Key k;
  };
