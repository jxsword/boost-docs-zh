动态属性映射

摘要

动态属性映射接口通过动态类型化的接口提供对一组属性映射的访问. 算法可以用它来操作属性映射, 而无需在编译期知道它们的键类型或值类型. 类型安全的代码可以使用动态属性映射, 更轻松、更完整地与脚本语言以及其他基于文本的键值数据表示形式对接.

引言

Boost Property Map 库指定了静态类型安全的接口, 泛型算法可以通过它们操作键值对. 通常, 使用属性映射的算法会以其所用的属性映射类型为模板参数, 并使用 Boost Property Map 库指定的接口来操作它们.

下面的泛型函数演示了属性映射的基本用法.

template <typename AgeMap, typename GPAMap>
void
manipulate_freds_info(AgeMap ages, GPAMap gpas) {

  typedef typename boost::property_traits<AgeMap>::key_type name_type;
  typedef typename boost::property_traits<AgeMap>::value_type age_type;
  typedef typename boost::property_traits<GPAMap>::value_type gpa_type;

  name_type fred = "Fred";

  age_type old_age = get(ages, fred);
  gpa_type old_gpa = get(gpas, fred);

  std::cout << "Fred's old age: " << old_age << "\n"
            << "Fred's old gpa: " << old_gpa << "\n";

  age_type new_age = 18;
  gpa_type new_gpa = 3.9;
  put(ages, fred, new_age);
  put(gpas, fred, new_gpa);
}

该函数以两个属性映射类型 AgeMap 和 GPAMap 为模板参数, 并为每种类型接受一个值参数. 该函数使用 property_traits 接口在编译期确定属性映射的值类型和键类型. 代码随后使用 get 函数检索 Fred 的旧信息, 并使用 put 函数更新它. get 函数由可读属性映射概念要求, 而 get 和 put 二者由读/写属性映射概念要求.

上面的函数不仅要求两个类型参数是属性映射概念的模型, 还做一些额外的假定. AgeMap 和 GPAMap 必须具有相同的键类型, 且该类型必须能从字符串构造. 此外, AgeMap 的值类型必须能从 int 构造. 虽然这些要求没有被显式声明, 但它们会在编译期被静态检查, 不满足它们将导致编译期错误.

尽管属性映射接口的静态类型化通常能提供理想的编译期安全性, 某些算法仍需要更动态的属性映射接口. 例如, Boost Graph Library (BGL) 提供了一些函数, 可以通过解读文本形式的图描述(即 GraphML 文件)的内容来初始化一个图. 这类通用图描述语言可以指定任意数量的边属性和顶点属性, 并用字符串表示键值对. 图读取函数应当能够捕获这些任意属性, 但由于函数模板只能以固定数量的属性映射为模板参数, 传统的属性映射处理技术不足以实现它们.

动态属性映射专门满足这样一种需求: 把对属性映射的检查推迟到运行期. 多个组件共同提供对动态属性映射的支持. dynamic_properties 类收集一组异构的对象, 这些对象是 Boost Property Map 库中概念的模型. 每个属性映射在被加入该集合时都会被指派一个基于字符串的键, 并且可以通过该键来访问. 在内部, dynamic_properties 用动态属性映射接口适配每个被包含的属性映射, 该接口提供 get 和 put 函数, 可以用满足少量要求的任意类型的值来调用它们. 在内部, 动态属性映射会转换键和值以满足底层属性映射的要求, 如果无法做到则发出运行期异常.

"Fred 的信息"再探

上面的示例使用 dynamic_properties 接口后如下所示:

void manipulate_freds_info(boost::dynamic_properties& properties)
{
  using boost::get;
  std::string fred = "Fred";

  int old_age = get<int>("age", properties, fred);
  std::string old_gpa = get("gpa", properties, fred);

  std::cout << "Fred's old age: " << old_age << "\n"
            << "Fred's old gpa: " << old_gpa << "\n";

  std::string new_age = "18";
  double new_gpa = 3.9;
  put("age",properties,fred,new_age);
  put("gpa",properties,fred,new_gpa);
}

新函数不是以属性映射类型为模板参数的模板, 而是一个接受 dynamic_properties 对象的具体函数. 此外, 代码不再引用键类型或值类型: 键和值都用字符串表示. 尽管如此, 该函数在有用的地方仍然使用非字符串类型. 例如, Fred 的旧年龄用 int 表示, 其值通过带类型参数调用 get 来检索, 该类型参数决定其返回类型. 最后, get 和 put 函数各自接受一个基于字符串的键, 该键随所关注的属性不同而不同.

下面示例展示如何调用上面的函数.

int main()
{
  using boost::get;

  // build property maps using associative_property_map
  std::map<std::string, int> name2age;
  std::map<std::string, double> name2gpa;
  boost::associative_property_map< std::map<std::string, int> >
    age_map(name2age);
  boost::associative_property_map< std::map<std::string, double> >
    gpa_map(name2gpa);

  std::string fred("Fred");
  // add key-value information
  name2age.insert(make_pair(fred,17));
  name2gpa.insert(make_pair(fred,2.7));

  // build and populate dynamic interface
  boost::dynamic_properties properties;
  properties.property("age",age_map);
  properties.property("gpa",gpa_map);

  manipulate_freds_info(properties);

  std::cout << "Fred's age: " << get(age_map,fred) << "\n"
            << "Fred's gpa: " << get(gpa_map,fred) << "\n";
}

代码首先使用 std::map 和 associative_property_map 适配器创建两个属性映射. 在用键值数据初始化属性映射之后, 它构造一个 dynamic_properties 对象, 并把两个属性映射加入其中, 分别以字符串 "age" 和 "gpa" 为键. 最后把 dynamic_properties 对象传给 manipulate_freds_info, 并显示其修改的结果.

如上所示, dynamic_properties 对象在需要时为属性映射提供动态类型化的接口, 同时又保留了应用程序中其他地方使用属性映射时的静态类型化.

参考

class dynamic_properties

dynamic_properties 类为一组属性映射提供动态类型化的接口. 要使用它, 必须先用 property 成员函数把属性映射装入该类的对象.

成员函数 

dynamic_properties()
dynamic_properties(
  const boost::function<
    boost::shared_ptr<dynamic_property_map> (
      const std::string&, const boost::any&, const boost::any&)
    >& fn)

dynamic_properties 对象可以用一个函数对象来构造, 该函数对象被调用时会创建一个新的属性映射. 库提供了 ignore_other_properties 函数对象, 它让 dynamic_properties 对象忽略任何它尚未准备好记录的属性. 如果试图向一个不存在的 dynamic_properties 键 put 一个键值对, 就会以该 dynamic_properties 键以及预期的属性键和值调用此函数. 如果 dynamic_properties 是默认构造的, 这样的 put 尝试会抛出 property_not_found.

template<typename PropertyMap>
dynamic_properties&
property(const std::string& name, PropertyMap property_map)

该成员函数向所包含的映射集合添加一个属性映射, 以 name 作为其键.

要求: PropertyMap 必须是可读属性映射或读/写属性映射的模型.

void insert(const std::string& name, boost::shared_ptr<dynamic_property_map> pm)

该成员函数直接向集合中添加一个 dynamic_property_map, 以 name 作为其键.

iterator begin()
const_iterator begin() const

该成员函数返回一个迭代器, 遍历 dynamic_properties 对象所持有的属性映射集合.

iterator end()
const_iterator end() const

该成员函数返回一个终止迭代器, 对应 dynamic_properties 对象所持有的动态属性映射集合的末端. 它用于终止对动态属性映射集合的遍历.

iterator lower_bound(const std::string& name)

该成员函数返回一个迭代器, 指向 dynamic_properties 键为 name 的第一个属性映射. 请记住, 多个属性映射可以拥有相同的 dynamic_properties 键, 只要它们的属性映射键类型不同.

不变式: 区间 [ lower_bound(name), end() ) 包含以其 dynamic_properties 键为 name 的每个属性映射.

自由函数

boost::shared_ptr<boost::dynamic_property_map>
ignore_other_properties(const std::string&,
                        const boost::any&,
                        const boost::any&)

当传给 dynamic_properties 构造函数时, 该函数使 dynamic_properties 对象可以忽略向未知键写入值的尝试而不发出错误信号.

template<typename Key, typename Value>
bool put(const std::string& name, dynamic_properties& dp, const Key& key,
         const Value& value)

该函数向名称和键类型都匹配的属性映射添加一个键值对. 如果找不到匹配的属性映射, 行为取决于是否存在属性映射生成器. 如果构造 dynamic_properties 对象时提供了属性映射生成器, 则使用该函数创建新的属性映射. 如果生成器未能生成属性映射(返回空的 shared_ptr), put 函数返回 false. 反之, 如果 dynamic_properties 对象没有属性映射生成器(即它是默认构造的), 则抛出 property_not_found. 如果找到了候选属性映射, 但它不支持 put, 则抛出 dynamic_const_put_error.

template<typename Value, typename Key>
Value get(const std::string& name, const dynamic_properties& dp,
          const Key& key)

该函数从名称与给定名称一致且键类型匹配的属性映射中获取值. 如果 Value 是 std::string, 则属性映射的值类型要么是 std::string, 要么是 OutputStreamable 的模型. 在后一种情况下, get 函数会把值转换为字符串. 如果找不到匹配的属性映射, 则抛出 dynamic_get_failure.

class dynamic_property_map

该类描述 dynamic_properties 用来以多态方式与用户属性映射交互的接口.

boost::any get(const any& key)

给定键的一种表示, 返回与该键关联的值.

要求: 1) 作为键传入的对象必须可转换为映射键类型的值. 该转换的细节未作规定. 2) 要使此表达式有效, 该键必须关联到某个值, 否则结果未定义.

std::string get_string(const any& key)

给定键的一种表示, 返回与该键关联的值的字符串表示.

要求: 1) 作为键传入的对象必须可转换为属性映射的键类型. 该转换的细节未作规定. 2) 要使此表达式有效, 该键必须关联到某个值, 否则结果未定义. 3) 属性映射的值类型必须是 Output Streamable 的模型.

void put(const any& key, const any& value)

给定键的一种表示和值的一种表示, 该键和值在属性映射中建立关联.

要求: 1) 作为键传入的对象必须可转换为属性映射的键类型. 该转换的细节未作规定. 2) 作为值传入的对象必须可转换为属性映射的值类型. 该转换的细节未作规定. 3) 属性映射不必支持此成员函数, 在这种情况下将发出错误信号. 这是可读属性映射概念的运行期类似物.

const std::type_info& key() const

返回一个 type_info 对象, 表示属性映射的键类型.

const std::type_info& value() const

返回一个 type_info 对象, 表示属性映射的值类型.

异常 

struct dynamic_property_exception : public std::exception {
  virtual ~dynamic_property_exception() throw() {}
};

struct property_not_found : public std::exception {
  std::string property;
  property_not_found(const std::string& property);
  virtual ~property_not_found() throw();

  const char* what() const throw();
};

struct dynamic_get_failure : public std::exception {
  std::string property;
  dynamic_get_failure(const std::string& property);
  virtual ~dynamic_get_failure() throw();

  const char* what() const throw();
};

struct dynamic_const_put_error  : public std::exception {
  virtual ~dynamic_const_put_error() throw();

  const char* what() const throw();
};

在某些情况下, 调用 dynamic_properties 的成员函数会抛出上述异常之一. 当不需要更高精度时, 三个具体异常都可以用通用的 dynamic_property_exception 名称捕获. 此外, 上述所有异常都派生自标准的 std::exception, 以便进行更泛化的错误处理. 导致这些异常的具体情形已在上文描述.
