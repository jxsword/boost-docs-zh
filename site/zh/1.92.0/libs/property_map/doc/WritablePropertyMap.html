可写属性映射

可写属性映射具备通过 put() 函数设置与给定键对象关联的值对象的能力.

细化自

同时细化 Copy Constructible

记法

PMap 一个作为可写属性映射 (Writable Property Map) 模型的类型.
pmap 类型为 PMap 的对象.
key 类型为 boost::property_traits<PMap>::key_type 的对象.
val 类型为 boost::property_traits<PMap>::value_type 的对象.

关联类型

值类型 boost::property_traits<PMap>::value_type 属性的类型.
键类型 boost::property_traits<PMap>::key_type 用于查找属性的键对象的类型. 属性映射可能以键类型为模板参数, 此时该 typedef 可以是 void.
属性映射类别 boost::property_traits<PMap>::category 属性的类别: 一个可转换为 writable_property_map_tag 的类型.

有效表达式

名称表达式返回类型说明
写入属性值[1] put(pmap, key, val) void 把 val 赋给与 k 关联的属性.

注释

[1] 函数 put() 最初名为 set(), 但为了避免在使用具有非标准名字查找规则的编译器(Microsoft Visual C++)时与 std::set 类发生名字冲突而更名. 下面的示例演示了这一问题. 
#include <set>
using namespace std;
namespace boost {
  void set() { }
}

概念检查类

  template <class PMap, class Key>
  struct WritablePropertyMapConcept
  {
    typedef typename property_traits<PMap>::key_type key_type;
    typedef typename property_traits<PMap>::category Category;
    typedef boost::writable_property_map_tag WritableTag;
    void constraints() {
      function_requires< ConvertibleConcept<Category, WritableTag> >();
      put(pmap, k, val);
    }
    PMap pmap;
    Key k;
    typename property_traits<PMap>::value_type val;
  };
