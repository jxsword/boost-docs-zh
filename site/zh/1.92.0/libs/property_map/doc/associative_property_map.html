associative_property_map<UniquePairAssociativeContainer>

该属性映射是一个适配器, 它把任何既是 成对关联容器 又是 唯一关联容器 模型的类型(例如 std::map)转换为可变的 左值属性映射. 注意, 该适配器只保留对容器的引用, 因此容器的生存期必须覆盖适配器的使用期.

示例

example1.cpp: 
#include <iostream>
#include <map>
#include <string>
#include <boost/property_map/property_map.hpp>


template <typename AddressMap>
void foo(AddressMap address)
{
  typedef typename boost::property_traits<AddressMap>::value_type value_type;
  typedef typename boost::property_traits<AddressMap>::key_type key_type;

  value_type old_address, new_address;
  key_type fred = "Fred";
  old_address = get(address, fred);
  new_address = "384 Fitzpatrick Street";
  put(address, fred, new_address);

  key_type joe = "Joe";
  value_type& joes_address = address[joe];
  joes_address = "325 Cushing Avenue";
}

int
main()
{
  std::map<std::string, std::string> name2address;
  boost::associative_property_map< std::map<std::string, std::string> >
    address_map(name2address);

  name2address.insert(make_pair(std::string("Fred"), 
				std::string("710 West 13th Street")));
  name2address.insert(make_pair(std::string("Joe"), 
				std::string("710 West 13th Street")));

  foo(address_map);
  
  for (std::map<std::string, std::string>::iterator i = name2address.begin();
       i != name2address.end(); ++i)
    std::cout << i->first << ": " << i->second << "\n";

  return EXIT_SUCCESS;
}

boost/property_map/property_map.hpp

模型

左值属性映射

模板参数

参数说明默认值
UniquePairAssociativeContainer 必须同时是 成对关联容器 和 唯一关联容器 的模型.  

成员

除了 左值属性映射 所要求的方法和函数之外, 该类还具有以下成员. 

property_traits<associative_property_map>::value_type
该类型与 UniquePairAssociativeContainer::data_type 相同. 
associative_property_map()
默认构造函数. 
associative_property_map(UniquePairAssociativeContainer& c)
构造函数. 
data_type& operator[](const key_type& k) const
用于属性访问的下标运算符. key_type 和 data_type 类型来自 UniquePairAssociativeContainer 内部的 typedef.
