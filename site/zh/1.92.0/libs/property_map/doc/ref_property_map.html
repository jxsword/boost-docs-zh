template <typename KeyType, typename ValueType>
class ref_property_map
该属性映射包装对某个特定对象的引用, 并在输入键对象时返回该引用.

定义位置

boost/property_map/property_map.hpp

所建模的概念

左值属性映射

关联类型

类型说明
boost::property_traits<ref_property_map>::value_type 该类型是实例化模板时所用的 ValueType.
boost::property_traits<ref_property_map>::key_type 该类型是实例化模板时所用的 KeyType.
boost::property_traits<ref_property_map>::category 该类型是 boost::lvalue_property_map_tag.

成员函数

成员说明
ref_property_map(ValueType& v) ref_property_map 的构造函数接受一个引用, 属性映射在被查询时将返回它.
ref_property_map(const ref_property_map& x) 拷贝构造函数.
ValueType& operator[](KeyType const&) const 返回所包含的引用.
