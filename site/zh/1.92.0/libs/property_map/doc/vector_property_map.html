template<typename T, typename IndexMap = identity_property_map>
class vector_property_map;

该属性映射用于高效地存储数量可变的元素的属性. 它介于 associative_property_map 和 iterator_property_map 之间. 后者非常快, 但要求在创建属性映射时已知存储元素的数量. 前者没有这一要求, 但较慢, 并且要求存储的元素可比较.

vector_property_map 使用从键到索引的映射, 并允许添加新元素. 它通过把值存储在一个按需扩容的向量中来实现这一点.

注意, vector_property_map 不为存储的值提供引用/指针稳定性.

示例

example3.cpp: 

#include <boost/property_map/vector_property_map.hpp>
#include <string>
#include <iostream>

int main()
{
    boost::vector_property_map<std::string> m;
    
    // Assign string to '4'. 
    m[4] = "e";
    std::cout << "'" << m[4] << "'\n";
    
    // Grab string from '10'. Since none is associated,
    // "" will be returned.
    std::cout << "'" << m[10] << "'\n";
}

定义位置

boost/property_map/vector_property_map.hpp

模型

左值属性映射

模板参数

参数说明默认值
T 属性值的类型. 必须同时是 可赋值 (Assignable) 和 可默认构造 (DefaultConstructible).  
IndexMap 必须是 可读属性映射 的模型, 且其值类型必须可转换为 std::vector<T>::size_type. identity_property_map

成员

除了 左值属性映射 所要求的方法和函数之外, 该类还具有以下成员. 

vector_property_map(const IndexMap& index = IndexMap())
接受一个索引映射的构造函数. 
vector_property_map(unsigned initial_size, const IndexMap& index = IndexMap())
该构造函数版本允许指定将要存储的元素的最大索引. 指定正确的数字可以改善性能, 但语义始终相同. 
vector_property_map(const vector_property_map&)
拷贝构造函数. 副本将共享相同的数据, 对副本的修改会影响原属性映射. 
vector_property_map& operator=(const vector_property_map&)
赋值运算符. 语义与拷贝构造函数相同. 
reference operator[](const key_type& v) const
用于属性访问的下标运算符. 
std::vector<T>::iterator storage_begin()
std::vector<T>::iterator storage_end()
std::vector<T>::const_iterator storage_begin()
std::vector<T>::const_iterator storage_end()

这一组方法提供对底层向量的 begin 和 end 迭代器的访问.

设计理由: 这些方法很方便, 例如, 当需要为一个新创建的属性映射中的所有元素指定单个值时. 这些方法不直接叫 "begin" 和 "end", 因为从概念上讲, vector_property_map 是无界映射, 没有 end 迭代器. 不直接提供对底层方法(向量)的访问, 因为那会削弱封装性, 使未来的性能调优变得危险.

致谢: Matthias Troyer 建议添加这些函数. 

void reserve(unsigned size)
为存储最大索引为 'size' 的元素预留空间. 只要未访问更大索引的元素, 所有访问都将是 O(1) 时间.

非成员函数

template
vector_property_map
make_vector_property_map(IndexMap index)
{
  return vector_property_map(index);
}
