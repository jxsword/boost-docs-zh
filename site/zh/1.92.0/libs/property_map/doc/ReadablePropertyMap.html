可读属性映射

可读属性映射通过调用 get() 函数提供对与给定键关联的值的读取访问. get() 函数的返回类型要么是属性映射的 value_type, 要么是对该类型的(const 或非 const)引用.

记法

PMap 一个建模可读属性映射的类型.
pmap 类型为 PMap 的对象.
key 类型为 boost::property_traits<PMap>::key_type 的对象.

关联类型

值类型 boost::property_traits<PMap>::value_type 属性的类型.
引用类型 boost::property_traits<PMap>::reference 可转换为值类型的类型.
键类型 boost::property_traits<PMap>::key_type 用于查找属性的键对象的类型. 属性映射可能以键类型为模板参数, 此时该 typedef 可以是 void.
属性映射类别 boost::property_traits<PMap>::category 属性的类别: 一个可转换为 readable_property_map_tag 的类型.

概念检查类

  template <class PMap, class Key>
  struct ReadablePropertyMapConcept
  {
    typedef typename property_traits<PMap>::key_type key_type;
    typedef typename property_traits<PMap>::category Category;
    typedef boost::readable_property_map_tag ReadableTag;
    void constraints() {
      function_requires< ConvertibleConcept<Category, ReadableTag> >();

      val = get(pmap, k);
    }
    PMap pmap;
    Key k;
    typename property_traits<PMap>::value_type val;
  };

属性映射概念

设计说明 设计说明

在不同时期, 曾考虑过把"只读"作为这一概念的名称. 然而, 这个名称并不恰当, 因为概念本质上是正向的, 而非负向的. 当我们定义读/写属性映射——它同时细化可读属性映射和可写属性映射概念——时, 这一点变得显而易见. 把"只读"和"只写"概念组合起来没有什么意义!
