shared_array_property_map<ValueType, OffsetMap>

该属性映射是一个适配器, 它包含一个 boost::shared_array 并使用该数组存储属性映射的数据. 所得到的属性映射是 左值属性映射 的模型. OffsetMap 类型负责把键对象转换为可以用作该数组偏移量的整数.

定义位置

boost/property_map/shared_array_property_map.hpp

模型

左值属性映射

模板参数

参数说明默认值
ValueType 属性映射的值类型.  
OffsetMap 必须是 可读属性映射 的模型, 且其值类型必须可转换为 std::size_t.  

成员

除了 左值属性映射 所要求的方法和函数之外, 该类还具有以下成员. 

property_traits<shared_array_property_map>::value_type
该类型与 ValueType 相同. 
shared_array_property_map(size_t n)
构造函数. 构建大小为 n 个元素的属性映射. OffsetMap 采用默认构造. 
shared_array_property_map(size_t n, OffsetMap m)
构造函数. 构建大小为 n 个元素的属性映射.

非成员函数
