SeekableDevice

定义

SeekableDevice 是一种 设备, 其 模式 细化 seekable.

说明

SeekableDevice 提供对给定类型字符序列的读访问、写访问和随机访问, 只有一个可重新定位的读/写头. SeekableDevice 可以两种方式暴露该序列:

  1. 定义成员函数 read、write 与 seek; 或者
  2. 定义成员函数 input_sequence 与 output_sequence, 返回完整界定这些序列的指针对. 这两个函数的返回值必须相同.[1]

SeekableDevice 的模式为 seekable.

注释

要与流和流缓冲配合使用, SeekableDevice 必须满足 Blocking.

示例

SeekableDevice 的模型可按如下方式定义:

struct SeekableDevice {
    typedef char                 char_type;
    typedef seekable_device_tag  category;
    std::streamsize read(char* s, std::streamsize n) 
        {
            // Read up to n characters from the input 
            // sequence into the buffer s, returning   
            // the number of characters read, or -1 
            // to indicate end-of-sequence.
        }
    void write(const char* s, std::streamsize n) 
        {
            // Write up to n characters from the buffer
            // s to the output sequence, returning the 
            // number of characters written
        }
    std::streampos seek(stream_offset off, std::ios_base::seekdir way) 
        {
            // Advances the read/write head by off characters, 
            // returning the new position, where the offset is 
            // calculated from:
            //  - the start of the sequence if way == ios_base::beg
            //  - the current position if way == ios_base::cur
            //  - the end of the sequence if way == ios_base::end
        }
};

此处 seekable_device_tag 是一个 类别标签, 用于将包含类型标识为 SeekableDevice 的模型. 定义新的 SeekableDevice 时, 使用标签 seekable_device_tag 即可. 也可以从辅助类 device<seekable> 或 wdevice<seekable> 派生.

Refinement of

Source、Sink.

关联类型

与 Device 相同, 另有如下附加要求:

类别一个类型, 可转换为 device_tag 与 seekable

记法

D- 一个作为 SeekableDevice 模型的类型
Ch- 字符类型取自 D
dev- 对象, 其类型为 D
s1- 对象, 类型为 Ch*
s2- 对象, 类型为 const Ch*
n- 对象, 其类型为 std::streamsize
off- 对象, 类型为 stream_offset
way- 对象, 其类型为 std::ios_base::seekdir
io- 别名, 指向命名空间 boost::iostreams

有效表达式 / 语义

与 Device 相同, 另有如下附加要求:

表达式Expression Type类别 前置条件语义
io::read(dev, s1, n)
 std::streamsize 不可转换为 direct_tag 读取至多 n 个字符, 来源为由 dev 控制的序列, 目标为 s1, 返回读取的字符数, 或返回 -1 表示序列结束 
io::write(dev, s2, n)
 std::streamsize 写入至多 n 个字符, 来源为从 s2 开始的序列, 目标为由 dev 控制的序列, 返回写入的字符数 
io::seek(dev, off, way)
 std::streampos 将读/写头前移 off 个字符, 返回新位置; 偏移量的计算基准为:
  • 序列起点, 若 way 为 ios_base::beg
  • 当前位置, 若 way 为 ios_base::cur
  • 序列末尾, 若 way 为 ios_base::end 
dev.input_sequence()
 
std::pair<Ch*,Ch*>
 可转换为 direct_tag 返回一对指针, 界定受控序列, 其控制者为 dev 
dev.output_sequence()
 
std::pair<Ch*,Ch*>
 返回一对指针, 界定受控序列, 其控制者为 dev

异常

成员函数 read、write、seek、input_sequence 或 output_sequence 执行期间发生的错误通过抛出异常来指示. 到达序列末尾不是错误, 但试图写入超过序列末尾则是.

抛出异常之后, SeekableDevice 必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为.

模型

  • array, file, file_descriptor, mapped_file.

[1]更优雅的规范只要求一个成员函数 sequence; 之所以选择现在的版本, 是为了简化 stream_buffer 的实现.
