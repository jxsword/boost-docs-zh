DualUseFilter

说明

DualUseFilter 是一种过滤器, 可以充当 InputFilter 或 OutputFilter, 但不能同时充当两者.

DualUseFilter 有助于减少实现特定过滤算法所需的过滤器类型数量. 例如, 通过将 basic_regex_filter 实现为 DualUseFilter, Iostreams 库避免了分别定义模板 basic_regex_input_filter 与 basic_regex_output_filter.

Refinement of

InputFilter、OutputFilter.

关联类型

字符类型过滤后序列中字符的类型
类别 一个类型, 可转换为 filter_tag 与 dual_use
模式 Category 可转换到的唯一的最派生 模式标签

有效表达式 / 语义

与 BidirectionalFilter 相同.

异常

与 BidirectionalFilter 相同.

模型

  • 文本处理过滤器.
  • 压缩与解压过滤器, basic_gzip_decompressor 除外.
