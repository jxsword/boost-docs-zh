设备

说明

设备提供对一个或两个字符序列的访问. 它可以提供对 输入序列 的访问 (用于读取), 对 输出序列 的访问 (用于写入), 或两者兼备. 两个序列之间的关系, 以及可对它们执行的操作, 取决于设备类型.

通常, 设备是定义了一个或多个成员函数 read、write 与 seek 的类类型. 不过, Device 概念的定义略宽泛一些, 以便让既有类型 (如标准流和流缓冲) 也能被视为 Device 的模型, 并让管理内存中序列的设备能够被优化.

每个设备类型都有一个关联的字符类型和类别. 字符类型 是设备的实例所控制的序列中字符的类型. 类别 是一个标签结构, Iostreams 库依靠它来确定设备支持哪些操作. 其作用与 iterator_category 之于 std::iterator_traits 的作用类似.[1]

八种 模式 各有一个 Device 的细化, 且每个这样的细化都有对应的 Filter 细化. 为了简洁地表达这种对应关系, 最好在 Device 自身的定义中纳入 Device 各种细化的要求, 并以类别加以限定. 这样, Device 的各种细化就可以由以下定义精确刻画. 为方便起见, 四种最常见的 Device 细化的要求也单独列出.

概念定义
Source Device 的细化, 其模式可转换为 input
Sink Device 的细化, 其模式可转换为 output
BidirectionalDevice Device 的细化, 其模式可转换为 bidirectional
SeekableDevice Device 的细化, 其模式可转换为 seekable
SeekableSource Device 的细化, 其模式可转换为 input_seekable
SeekableSink Device 的细化, 其模式可转换为 output_seekable
BidirectionalSeekableDevice Device 的细化, 其模式可转换为 bidirectional_seekable
DualSeekableDevice Device 的细化, 其模式可转换为 dual_seekable

注释

要与 Boost Iostreams 库提供的流和流缓冲配合使用, 设备必须满足 Blocking.

标准流与流缓冲

标准流和流缓冲是 Device 的模型. 无法确定任意流或流缓冲的确切 模式, 因此 Iostreams 库必须做出有根据的推测. (参见 类模板 mode_of.) 由于这一推测可能无法准确反映特定流或流缓冲的行为, 因此允许用户在将流或流缓冲添加到 过滤链 时有一定的灵活性. 在这种情况下, 用户须自行确保流或流缓冲的行为与链的 模式 一致.

关联类型

字符类型受控序列中字符的类型
类别 一个类型, 可转换为 device_tag 以及一个唯一的最派生 模式标签
模式 Category 可转换到的唯一的最派生 模式标签

记法

D- 一个作为 Device 模型的类型
Ch- 字符类型取自 D
dev- 对象, 其类型为 D
s1- 对象, 其类型为 Ch*
s2- 对象, 其类型为 const Ch*
n- 对象, 其类型为 std::streamsize
off- 对象, 类型为 stream_offset
way- 对象, 其类型为 std::ios_base::seekdir
which- 对象, 其类型为 std::ios_base::openmode
io- 别名, 指向命名空间 boost::iostreams

有效表达式 — 类型名

表达式Expression Type
typename char_type_of<D>::type typename — 即字符类型
typename category_of<D>::type typename — 即类别

有效表达式 / 语义 — 输入

表达式Expression Type类别 前置条件语义
io::read(dev, s1, n)
 std::streamsize 可转换为 input 但不可转换为 direct_tag 读取至多 n 个字符, 来源为由 dev 控制的序列, 目标为 s1, 返回读取的字符数, 或返回 -1 表示序列结束 
dev.input_sequence()
 
std::pair<Ch*,Ch*>
 可转换为 input 与 direct_tag 返回一对指针, 界定受控序列, 其控制者为 dev

有效表达式 / 语义 — 输出

表达式Expression Type类别 前置条件语义
io::write(dev, s2, n)
 std::streamsize 可转换为 output 但不可转换为 direct_tag 写入至多 n 个字符, 来源为从 s2 开始的序列, 目标为由 dev 控制的序列, 返回写入的字符数 
dev.output_sequence()
 
std::pair<Ch*,Ch*>
 可转换为 output 与 direct_tag 返回一对指针, 界定受控序列, 其控制者为 dev

有效表达式 / 语义 — 随机访问

表达式Expression Type类别 前置条件语义
io::seek(dev, off, way)
 std::streampos 可转换为 seekable 但不可转换为 direct_tag

将读/写头前移 off 个字符, 返回新位置; 偏移量的计算基准为:

  • 序列起点, 若 way 为 ios_base::beg
  • 当前位置, 若 way 为 ios_base::cur
  • 序列末尾, 若 way 为 ios_base::end 
io::seek(dev, off, way, which)
 std::streampos 可转换为 dual_seekable 或 bidirectional_seekable, 但不可转换为 direct_tag

将读头 (若 which 为 std::ios_base::in)、写头 (若 which 为 std::ios_base::out) 或两个头 (若 which 为 std::ios_base::in | std::ios_base::out) 前移 off 个字符, 返回新位置; 偏移量的计算基准为

  • 序列起点, 若 way 为 ios_base::beg
  • 当前位置, 若 way 为 ios_base::cur
  • 序列末尾, 若 way 为 ios_base::end

若 way 为 ios_base::cur 且 which 为 (std::ios_base::in | std::ios_base::out), 则结果未定义.

异常

read、write、seek、input_sequence 或 output_sequence 执行期间发生的错误通过抛出异常来指示. 到达输入序列末尾不是错误, 但试图写入超过输出序列末尾则是.

抛出异常之后, 设备必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为.

模型

参见 Source、Sink、BidirectionalDevice 与 SeekableDevice.
