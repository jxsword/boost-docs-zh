定义

OutputFilter 是一种 过滤器, 其 模式 细化 output.

说明

OutputFilter 操作由 汇 控制的字符序列, 提供对具有相同字符类型的过滤后序列的访问. 它可以两种方式暴露过滤后的序列:

  1. 定义成员函数 put
  2. 定义成员函数 write
第二种备选方案是为了提升性能而提供的. 实现这种备选方案的 OutputFilter 被称为 多字符. (参见 多字符过滤器.)

示例

I. 普通 OutputFilter

以下示例展示了一个 OutputFilter, 它将序列中的每个字符转换为大写.

    #include <ctype.h>                        // toupper
    #include <boost/iostreams/categories.hpp> // output_filter_tag
    #include <boost/iostreams/operations.hpp> // put

    using namespace std;
    namespace io = boost::iostreams;

    struct toupper_output_filter {
        typedef char                   char_type;
        typedef io::output_filter_tag  category;

        template<typename Sink>
        bool put(Sink& snk, char c)
        { 
            return io::put(snk, toupper((unsigned char) c)); 
        }
    };

此处 char_type 是过滤器的 字符类型, output_filter_tag 是一个 类别标签, 用于将过滤器标识为 OutputFilter 的模型, 函数 io::put 向任意汇写入一个字符.[1]

Iostreams 库定义了两个便利类 output_filter 与 output_wfilter, 它们提供成员 typedef — 即 char_type 与 category — 以及若干成员函数的默认实现. 定义新的 OutputFilter 模型时, 通常只需从 output_filter 或 output_wfilter 派生并定义成员函数 put 即可.

II. 多字符 OutputFilter

以下示例展示了一个多字符 OutputFilter, 它执行与示例 I 中过滤器相同的过滤操作.

    #include <ctype.h>                        // toupper
    #include <boost/iostreams/categories.hpp> // output_filter_tag
    #include <boost/iostreams/operations.hpp> // put

    using namespace std;
    namespace io = boost::iostreams;

    struct toupper_filter {
        typedef char                             char_type;
        typedef io::multichar_output_filter_tag  category;

        template<typename Sink>
        std::streamsize write(Sink& snk, const char* s, streamsize n)
        { 
            std::streamsize rest = n;
            while (rest != 0 && io::put(snk, toupper((unsigned char) *s++))
                --rest;
            return n - rest;
        }
    };

此处 multichar_output_filter_tag 是一个 类别标签, 用于将过滤器标识为多字符 OutputFilter.

Iostreams 库定义了两个便利类 multichar_output_filter 与 multichar_output_wfilter, 它们提供成员 typedef — 即 char_type 与 category — 以及若干成员函数的默认实现. 定义新的多字符 OutputFilter 时, 通常只需从 multichar_output_filter 或 multichar_output_wfilter 派生并定义成员函数 write 即可.

Refinement of

Filter.

关联类型

字符类型过滤后序列中字符的类型
类别 一个类型, 可转换为 filter_tag 与 output
模式 Category 可转换到的唯一的最派生 模式标签

记法

F- 一个作为 OutputFilter 模型的类型
D- 一个作为 设备 模型的类型, 其字符类型与 F 相同, 其模式细化的对象为 F
Ch- 字符类型取自 F
Tr- boost::iostreams::char_traits<Ch>
f- 对象, 其类型为 F
d- 对象, 其类型为 D
c- 对象, 其类型为 Ch
s- 对象, 其类型为 const Ch*
n- 对象, 其类型为 std::streamsize
io- 别名, 指向命名空间 boost::iostreams

异常

put 或 write 执行期间发生的错误通过抛出异常来指示. 试图写入超过序列末尾总是错误.

抛出异常之后, OutputFilter 必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为. 此外, 除非它满足 Closable, 否则它必须随时可以开始处理新的字符序列.
