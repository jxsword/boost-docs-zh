Peekable

说明

Peekable 设备 允许将从输入序列读出的字符回退.

该概念的命名基于如下观察: PeekableDevice 允许用户通过调用 get 或 read 再调用 putback, 来窥视其控制的序列中的第一个字符. 曾考虑过 Putbackable 和 InputRevertable 这两个名字, 但被否决.

记法

P-一个作为 Peekable 模型的类型
p-Object of type P
c-对象, 其类型与下者的字符类型相同: P
io-别名, 指向命名空间 boost::iostreams

有效表达式 / 语义

表达式Expression TypePrecondition语义Postcondition
io::putback(p, c)
 bool 已从 p 读取了一个或多个字符, 使用 io::get 或 io::read, 且其间未执行任何 I/O 操作 尝试将 c 回退到 p, 成功时返回 true 若 putback 返回 true, 则接下来从 p 读取的字符 — 使用 io::get 或 io::read — 将等于 c

异常

执行 putback 期间发生的错误通过抛出异常来指示.

模型

  • 标准输入流与流缓冲.
