Filter

说明

过滤器操作由 设备 控制的一个或多个字符序列, 提供对过滤后的输入序列、输出序列或两者的访问. 非正式地说, 当过滤器 f 与设备 d 结合使用时, 从 d 的输入序列读取的数据会先由 f 处理再返回给用户; 写入 d 的输出序列的数据会先由 f 处理; 重定位操作会先由 f 处理再传递给 d.

过滤器是定义了一个或多个成员函数 get、put、read、write 与 seek 的类类型; 每个函数都以对设备的引用作为第一个参数. 每当过滤器用于执行 I/O 操作时, 被过滤设备的引用都会作为函数参数传给过滤器.

每个过滤器类型都有一个关联的字符类型和类别. 字符类型 是输入和输出序列中字符的类型. 类别 是一个标签结构, Iostreams 库依靠它来确定过滤器类型支持哪些操作. 其作用与 iterator_category 之于 std::iterator_traits 的作用类似.[1]

八种 模式 各有一个 Filter 的细化, 且每个这样的细化都对应一个 Device 细化. 为了简洁地表达这种对应关系, 最好在 Filter 自身的定义中纳入 Filter 各种细化的要求, 并以类别加以限定. 这样, Filter 的各种细化就可以由以下定义精确刻画. 为方便起见, 四种最常见的 Filter 细化的要求也单独列出.

概念定义
InputFilter Filter 的细化, 其模式可转换为 input
OutputFilter Filter 的细化, 其模式可转换为 output
BidirectionalFilter Filter 的细化, 其模式可转换为 bidirectional
SeekableFilter Filter 的细化, 其模式可转换为 seekable
InputSeekableFilter Filter 的细化, 其模式可转换为 input_seekable
OutputSeekableFilter Filter 的细化, 其模式可转换为 output_seekable
BidirectionalSeekableFilter Filter 的细化, 其模式可转换为 bidirectional_seekable
DualSeekableFilter Filter 的细化, 其模式可转换为 dual_seekable

Refinement of

关联类型

字符类型过滤后序列中字符的类型
类别 一个类型, 可转换为 filter_tag 以及一个唯一的最派生 模式标签
模式 Category 可转换到的唯一的最派生 模式标签

记法

F- 一个作为 Filter 模型的类型
D- 一个作为 设备 模型的类型, 其字符类型与 F 相同, 其模式细化的对象为 F
Ch- 字符类型取自 F
Tr- boost::iostreams::char_traits<Ch>
f- 对象, 其类型为 F
d- 对象, 其类型为 D
c- 对象, 其类型为 Ch
s1- 对象, 其类型为 Ch*
s2- 对象, 其类型为 const Ch*
n- 对象, 其类型为 std::streamsize
off- 对象, 类型为 stream_offset
way- 对象, 其类型为 std::ios_base::seekdir
which- 对象, 其类型为 std::ios_base::openmode
io- 别名, 指向命名空间 boost::iostreams

有效表达式 — 类型名

表达式Expression Type
typename char_type_of<F>::type typename — 即字符类型
typename category_of<F>::type typename — 即类别

有效表达式 / 语义 — 输入

表达式Expression Type类别 前置条件语义
f.get(d)
 Tr::int_type 可转换为 input 但不可转换为 multichar_tag 返回由 f 控制的输入序列中的下一个字符; 若已到达序列末尾则返回 Tr::eof(), 若输入暂时不可用则返回 Tr::would_block() — 不可用的原因是调用 d 产生的字符少于请求的数量. 由 d 控制的输入序列可使用 io::get、io::read 与 io::putback 访问. 
f.read(d, s1, n)
 
std::streamsize
 可转换为 input 与 multichar_tag 读取至多 n 个字符, 来源为由 f 控制的输入序列, 目标为缓冲区 s1, 返回读取的字符数或 -1 (表示序列结束). 返回值小于 n 的情况仅限于: 已到达序列末尾, 或因调用 d 产生的字符少于请求的数量而导致输入暂时不可用. 由 d 控制的输入序列可使用 io::get、io::read 与 io::putback 访问.

有效表达式 / 语义 — 输出

表达式Expression Type类别 前置条件语义
f.put(d, c)
 bool 可转换为 output 但不可转换为 multichar_tag 尝试将字符 c 写入由 f 控制的输出序列, 返回 false — 如果 c 无法被消费, 原因是调用 d 消费的字符少于请求的数量. 由 d 控制的输出序列可使用 io::put 与 io::write 访问. 
f.write(d, s2, n)
 
std::streamsize
 可转换为 output 与 multichar_tag 写入至多 n 个字符, 来源为缓冲区 s2, 目标为由 d 控制的输出序列, 返回写入的字符数. 返回值小于 n 的情况仅限于: 调用 d 消费的字符少于请求的数量. 由 d 控制的输出序列可使用 io::put 与 io::write 访问.

有效表达式 / 语义 — 随机访问

表达式Expression Type类别 前置条件语义
f.seek(d, off, way)
 std::streampos 可转换为 seekable 但不可转换为 direct_tag

将读/写头前移 off 个字符, 返回新位置; 偏移量的计算基准为:

  • 序列起点, 若 way 为 ios_base::beg
  • 当前位置, 若 way 为 ios_base::cur
  • 序列末尾, 若 way 为 ios_base::end

由 d 控制的输入序列可使用 io::seek 以及 io::write 访问 — 后者的条件是 模式 (F 的模式) 可转换为 output.

 
f.seek(d, off, way, which)
 std::streampos 可转换为 dual_seekable 或 bidirectional_seekable, 但不可转换为 direct_tag

将读头 (若 which 为 std::ios_base::in)、写头 (若 which 为 std::ios_base::out) 或两个头 (若 which 为 std::ios_base::in | std::ios_base::out) 前移 off 个字符, 返回新位置; 偏移量的计算基准为

  • 序列起点, 若 way 为 ios_base::beg
  • 当前位置, 若 way 为 ios_base::cur
  • 序列末尾, 若 way 为 ios_base::end

由 d 控制的输入序列可使用 io::seek 以及 io::write 访问 — 后者的条件是 模式 (F 的模式) 可转换为 output.

若 way 为 ios_base::cur 且 which 为 (std::ios_base::in | std::ios_base::out), 则结果未定义.

异常

get、put、read、write 或 seek 执行期间发生的错误通过抛出异常来指示. 到达输入序列末尾不是错误, 但试图写入超过输出序列末尾则是.

抛出异常之后, 过滤器必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为. 此外, 除非它满足 Closable, 否则它必须随时可以开始处理新的字符序列.

模型

参见 InputFilter、OutputFilter、BidirectionalFilter 与 SeekableFilter.
