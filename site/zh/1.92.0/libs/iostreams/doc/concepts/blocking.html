阻塞

说明

若一种 设备 的 read 请求除流末尾外从不产生少于请求量的字符, 且其 write 请求在任何情况下都从不消费少于请求量的字符, 则该设备是 Blocking 的. 目前 Iostreams 库提供的所有设备都是 Blocking 的. 对非 Blocking 设备的有限支持已被提供, 作为将来更全面支持 异步与非阻塞 I/O 的基础.

Blocking 概念不适用于过滤器. 相反, 要求过滤器是 保持阻塞 的, 即

  • read 请求从不产生少于请求量的字符, 除非已到达流末尾, 或对下游源的 read 请求产生的字符少于请求量; 并且
  • write 请求从不消费少于请求量的字符, 除非对下游汇的 write 请求消费的字符少于请求量.

与其他 Iostreams 库概念不同, Blocking 不与任何 类别标签 相关联. 将来可能会引入 non_blocking_tag.
