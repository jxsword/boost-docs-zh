源

定义

源是一种 设备, 其 模式 细化 input.

说明

源提供对给定类型字符序列的读访问. 一般而言, 源可以两种方式暴露该序列:

  1. 定义成员函数 read; 或者
  2. 定义成员函数 input_sequence, 返回完整界定该序列的指针对.

作为特例, Boost.Iostreams 将标准输入流视为源. (详情参见 read.)

源的模式为 input 或其细化之一.

注释

要与 Boost Iostreams 库提供的流和流缓冲配合使用, 源必须满足 Blocking.

示例

源的模型可按如下方式定义:

struct Source {
    typedef char        char_type;
    typedef source_tag  category;
    std::streamsize read(char* s, std::streamsize n) 
    {
        // Read up to n characters from the input 
        // sequence into the buffer s, returning   
        // the number of characters read, or -1 
        // to indicate end-of-sequence.
    }
};

此处 source_tag 是一个 类别标签, 用于将该类型标识为源的模型. 通常, 源可通过从辅助类 source 或 wsource 派生并定义成员函数 read 来定义.

记法

S- 一个作为 Source 模型的类型
Ch- 字符类型
src- 对象, 其类型为 S
s- 对象, 类型为 Ch*
n- 对象, 其类型为 std::streamsize
io- 别名, 指向命名空间 boost::iostreams

异常

成员函数 read 或 input_sequence 执行期间发生的错误通过抛出异常来指示. 到达序列末尾不是错误.

抛出异常之后, 源必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为.

模型

  • 标准输入流与流缓冲.
  • array_source, file_source, file_descriptor_source, mapped_file_source.
