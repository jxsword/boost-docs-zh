Flushable

说明

Flushable 的汇或 OutputFilter 为用户提供了一种手段, 可请求将所有缓冲字符发送到下游.

Refinement of

关联类型

与 Filter 或 Device 相同, 另有如下附加要求:

类别一个类型, 可转换为 flushable_tag

记法

F-一个作为 Flushable 模型的类型
D-一个类型, 作为 Sink 的模型, 字符类型与下者相同: F
f-Object of type F
d-Object of type D

有效表达式 / 语义

表达式Expression TypePrecondition语义
boost::iostreams::flush(f)
 bool 类别, 可转换为 device_tag 尝试将所有缓冲字符发送到下游, 返回 true, 除非发生错误.[1] 
boost::iostreams::flush(f, d)
 bool 类别, 可转换为 filter_tag

尝试将所有缓冲字符写入 d, 若所有缓冲字符都已写入则返回 true.

异常

执行 flush 期间发生的错误通过抛出异常来指示. 若此类异常在流或流缓冲析构函数执行期间发生, 则会被捕获并忽略.

模型

Iostreams 库提供的若干过滤器和设备是 Flushable 的, 但这是一个实现细节.

[1]在开发后期才注意到, 为了与使用异常报告错误的策略保持一致 (参见 异常), 本应规定 flush 在设备上被调用时返回 void. 在规范更改之前, 设备在刷新时应始终返回 true.
