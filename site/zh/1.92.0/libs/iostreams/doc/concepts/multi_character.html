多字符过滤器

说明

过滤器, 一次提供对受控序列 (或多个序列) 中若干个字符的访问. 多字符过滤器与普通过滤器的区别体现在各过滤器细化的规范中. 参见 例如 InputFilter 与 OutputFilter.

Refinement of

Filter.

关联类型

与 Filter 相同, 另有如下附加要求:

类别一个类型, 可转换为 filter_tag 与 multichar_tag

有效表达式 / 语义

与 Filter 相同.

模型

  • 压缩与解压过滤器
  • basic_regex_filter
  • aggregate_filter
  • symmetric_filter
