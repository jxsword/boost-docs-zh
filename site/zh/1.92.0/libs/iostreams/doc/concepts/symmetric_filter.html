SymmetricFilter

说明

SymmetricFilter 以增量方式在用户提供的缓冲区中处理输入给它的字符序列, 并以增量方式将过滤后的序列输出到第二个用户提供的缓冲区. 它对于定义基于 C 语言 API 的过滤器很有用.

SymmetricFilter 并不细化 Filter. 相反, 可以使用模板 symmetric_filter 从 SymmetricFilter 生成过滤器. 以这种方式生成的过滤器是 DualUseFilters, 并且无论其所基于的 SymmetricFilter 是否满足 CopyConstructible, 它们都满足 CopyConstructible.

SymmetricFilter 概念值得注意之处在于: 其定义不涉及 源或汇的概念.

关联类型

字符类型过滤后序列中字符的类型

记法

F- 一个作为 SymmetricFilter 模型的类型
Ch- 字符类型取自 F
f- 对象, 其类型为 F
i1, i2- 对象, 其类型为 const Ch*
o1, o2- 对象, 其类型为 Ch*
flush- 对象, 其类型为 bool

有效表达式 / 语义 — 类型名

表达式Expression Type
typename char_type_of<F>::type
 typename — 即字符类型

有效表达式 / 语义 — 成员函数

表达式Expression Type语义Postcondition
f.filter(i1, i2, o1, o2, flush)
 bool 尝试过滤序列 [i1, i2), 将结果存储到序列 [o1, o2). 若 flush 为 true, 则尽可能多地向 [o1, o2) 写入输出. 若 flush 为 false, 则返回 false 表示检测到流的"自然"结束. 否则返回 true, 表示还有尚未存入 [o1, o2) 的额外字符可供输出.

i1 指向原始序列 [i1, i2) 中第一个未被消费的字符.

o1 指向原始序列 [o1, o2) 中第一个未被消费的字符.

i1 == i2 或 o1 == o2.

 
f.close()
 void - f 已就绪, 可开始过滤新序列

异常

filter 或 close 执行期间发生的错误通过抛出异常来指示.
