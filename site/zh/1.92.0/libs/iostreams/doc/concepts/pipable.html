Pipable

说明

Pipable 过滤器可以作为 管道 的组件出现.

要使过滤器成为 Pipable, 必须定义 operator| 的特定重载; 这通过调用宏 BOOST_IOSTREAMS_PIPABLE 实现.

Refinement of

Filter.

关联类型

与 Filter 相同.

记法

P-一个作为 Pipable 模型的类型
C-一个类型, 作为 Filter 或 Device 的模型且满足 CopyConstructible[1]
p-Object of type P
c-Object of type C

有效表达式 / 语义

表达式Expression Type语义
f | c
 由实现定义 返回对应于序列 f、c 的管道

异常

无.

模型

  • Iostreams 库提供的所有过滤器.

[1]这一要求防止流和流缓冲在不使用 引用包装器 的情况下出现在管道中. 在 Iostreams 库的未来版本中, 这一限制可能会被移除.
