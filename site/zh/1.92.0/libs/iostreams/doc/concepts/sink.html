汇

定义

汇是一种 设备, 其 模式 细化 output.

说明

汇提供对给定类型字符序列的写访问. 一般而言, 汇可以两种方式暴露该序列:

  1. 定义成员函数 write, 由 Iostreams 库通过函数 boost::iostreams::write 间接调用;
  2. 定义成员函数 output_sequence, 返回完整界定该序列的指针对.

作为特例, Boost.Iostreams 将标准输出流视为汇. (详情参见 write.)

汇的模式为 output 或其细化之一.

注释

要与 Boost Iostreams 库提供的流和流缓冲配合使用, 汇必须满足 Blocking.

示例

汇的模型可按如下方式定义:

struct Sink {
    typedef char      char_type;
    typedef sink_tag  category;
    std::streamsize write(const char* s, std::streamsize n) 
    {
        // Write up to n characters from the buffer
        // s to the output sequence, returning the 
        // number of characters written
    }
};

此处 sink_tag 是一个 类别标签, 用于将该类型标识为汇的模型. 通常, 汇可通过从辅助类 sink 或 wsink 派生并定义成员函数 write 来定义.

Refinement of

设备.

关联类型

与 Device 相同, 另有如下附加要求:

类别一个类型, 可转换为 device_tag 与 output

记法

S- 一个作为 Sink 模型的类型
Ch- 字符类型
snk- 对象, 其类型为 S
s- 对象, 类型为 const Ch*
n- 对象, 其类型为 std::streamsize
io- 别名, 指向命名空间 boost::iostreams

异常

成员函数 write 或 output_sequence 执行期间发生的错误通过抛出异常来指示. 试图写入超过序列末尾总是错误.

抛出异常之后, 汇必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为.

模型

  • 标准输出流与流缓冲.
  • array_sink, file_sink, file_descriptor_sink, mapped_file_sink.
