BidirectionalFilter

定义

BidirectionalFilter 是一种 过滤器, 其 模式 细化 bidirectional.

说明

BidirectionalFilter 操作由 BidirectionalDevice 控制的字符序列, 提供对两个具有相同字符类型的过滤后序列的访问. 它可以两种方式暴露过滤后的序列:

  1. 定义成员函数 get 与 put.
  2. 定义成员函数 read 与 write.
第二种备选方案是为了提升性能而提供的. 实现这种备选方案的 BidirectionalFilter 被称为 多字符过滤器.

Refinement of

InputFilter、OutputFilter.

关联类型

字符类型过滤后序列中字符的类型
类别 一个类型, 可转换为 filter_tag 与 bidirectional
模式 Category 可转换到的唯一的最派生 模式标签

记法

F- 一个作为 BidirectionalFilter 模型的类型
D- 一个作为 设备 模型的类型, 其字符类型与 F 相同, 其模式细化的对象为 F
Ch- 字符类型取自 F
Tr- boost::iostreams::char_traits<Ch>
f- 对象, 其类型为 F
d- 对象, 其类型为 D
c- 对象, 其类型为 Ch
s1- 对象, 其类型为 Ch*
s2- 对象, 其类型为 const Ch*
n- 对象, 其类型为 std::streamsize
io- 别名, 指向命名空间 boost::iostreams

表达式Expression Type类别 前置条件语义

 typename — 即字符类型 -- 
typename category_of<F>::type
 typename — 即类别 -- 
f.get(d)
 Tr::int_type 可转换为 input 但不可转换为 multichar_tag 返回由 f 控制的输入序列中的下一个字符; 若已到达序列末尾则返回 Tr::eof(), 若输入暂时不可用则返回 Tr::would_block() — 不可用的原因是调用 d 产生的字符少于请求的数量. 由 d 控制的输入序列可使用 io::get、io::read 与 io::putback 访问. 
f.put(d, c)
 bool 尝试将字符 c 写入由 f 控制的输出序列, 返回 false — 如果 c 无法被消费, 原因是调用 d 消费的字符少于请求的数量. 由 d 控制的输出序列可使用 io::put 与 io::write 访问. 
f.read(d, s1, n)
 
std::streamsize
 可转换为 input 与 multichar_tag 读取至多 n 个字符, 来源为由 f 控制的输入序列, 目标为缓冲区 s1, 返回读取的字符数或 -1 (表示序列结束). 返回值小于 n 的情况仅限于: 已到达序列末尾, 或因调用 d 产生的字符少于请求的数量而导致输入暂时不可用. 由 d 控制的输入序列可使用 io::get、io::read 与 io::putback 访问. 
f.write(d, s2, n)
 
std::streamsize
 写入至多 n 个字符, 来源为缓冲区 s2, 目标为由 d 控制的输出序列, 返回写入的字符数. 返回值小于 n 的情况仅限于: 调用 d 消费的字符少于请求的数量. 由 d 控制的输出序列可使用 io::put 与 io::write 访问.

异常

成员函数 get、put、read 或 write 执行期间发生的错误通过抛出异常来指示. 到达输入序列末尾不是错误, 但试图写入超过输出序列末尾则是.

抛出异常之后, BidirectionalFilter 必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为. 此外, 除非它满足 Closable, 否则它必须随时可以开始处理新的字符序列.
