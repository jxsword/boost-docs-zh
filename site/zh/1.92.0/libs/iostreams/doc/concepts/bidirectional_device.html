BidirectionalDevice

定义

BidirectionalDevice 是一种 设备, 其 模式 细化 bidirectional.

说明

BidirectionalDevice 提供对给定类型的字符序列的读访问, 并提供对同一类型的另一个独立字符序列的写访问. BidirectionalDevice 可以三种方式暴露这些序列:[1]

  1. 定义成员函数 read 与 write, 由 Iostreams 库通过函数 boost::iostreams::read 与 boost::iostreams::write 间接调用;
  2. 重载或特化 boost::iostreams::read 与 boost::iostreams::write; 或者
  3. 定义成员函数 input_sequence 与 output_sequence, 返回完整界定这两个序列的指针对.

BidirectionalDevice 的 I/O 模式为 bidirectional 或 bidirectional-seekable.

示例

BidirectionalDevice 的模型可按如下方式定义:

struct BidirectionalDevice {
    typedef char                char_type;
    typedef bidirectional_device_tag    category;
    std::streamsize read(char* s, std::streamsize n) 
        {
            // Reads up to n characters from the input 
            // sequence into the buffer s, returning the number 
            // of characters read. Returning a value less than n 
            // indicates end-of-sequence.
        }
    std::streamsize write(const char* s, std::streamsize n) 
        {
            // Write up to n characters from the buffer
            // s to the output sequence, returning the 
            // number of characters written
        }
};

此处 category 是一个标签 struct, 用于将包含类型标识为 BidirectionalDevice 的模型. 定义新的 BidirectionalDevice 时, 使用标签 bidirectional_device_tag 即可. 也可以从辅助类 device<bidirectional> 或 wdevice<bidirectional> 派生.

Refinement of

Source、Sink.

关联类型

与 Device 相同, 另有如下附加要求:

类别一个类型, 可转换为 device_tag 与 bidirectional

记法

D- 一个作为 BidirectionalDevice 模型的类型
Ch- 字符类型取自 D
dev- 对象, 其类型为 D
s1- 对象, 类型为 Ch*
s2- 对象, 类型为 const Ch*
n- 对象, 其类型为 std::streamsize

有效表达式 / 语义

与 Device 相同, 另有如下附加要求:

表达式Expression Type类别 前置条件语义
boost::iostreams::read(dev, s1, n)
 std::streamsize 不可转换为 direct_tag 读取至多 n 个字符, 来源为由 dev 控制的输入序列, 目标为 s1, 返回读取的字符数; 返回值小于 n 表示序列结束 
boost::iostreams::write(dev, s2, n)
 std::streamsize 写入至多 n 个字符, 来源为从 s2 开始的序列, 目标为由 dev 控制的序列, 返回写入的字符数 
dev.input_sequence()
 
std::pair<Ch*,Ch*>
 可转换为 direct_tag 返回一对指针, 界定输入序列, 其控制者为 dev 
dev.output_sequence()
 
std::pair<Ch*,Ch*>
 返回一对指针, 界定输出序列, 其控制者为 dev

异常

成员函数 read、write、input_sequence 或 output_sequence 执行期间发生的错误通过抛出异常来指示. 到达输入序列末尾不是错误, 但试图写入超过输出序列末尾则是.

抛出异常之后, BidirectionalDevice 必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为.
