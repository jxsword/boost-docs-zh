SeekableFilter

定义

SeekableFilter 是一种 过滤器, 其 模式 细化 seekable.

说明

SeekableFilter 操作由 SeekableDevice 控制的字符序列, 提供对具有相同字符类型的过滤后序列的访问. 它可以两种方式暴露过滤后的序列:

  1. 定义成员函数 get、put 与 seek.
  2. 定义成员函数 read、write 与 seek.
第二种备选方案是为了提升性能而提供的. 实现这种备选方案的 SeekableFilter 被称为 多字符. (参见 多字符过滤器.)

Refinement of

InputFilter、OutputFilter.

关联类型

字符类型过滤后序列中字符的类型
类别 一个类型, 可转换为 filter_tag 与 seekable
模式 Category 可转换到的唯一的最派生 模式标签

记法

F- 一个作为 SeekableFilter 模型的类型
D- 一个类型, 作为 设备 的模型, 字符类型与 F 相同, 其模式可转换为 F
Ch- 字符类型取自 F
Tr- boost::iostreams::char_traits<Ch>
f- 对象, 其类型为 F
d- 对象, 其类型为 D
c- 对象, 其类型为 Ch
s1- 对象, 其类型为 Ch*
s2- 对象, 其类型为 const Ch*
n- 对象, 其类型为 std::streamsize
off- 对象, 类型为 stream_offset
way- 对象, 其类型为 std::ios_base::seekdir
which- 对象, 其类型为 std::ios_base::openmode
io- 别名, 指向命名空间 boost::iostreams

f.get(d)

 bool 将字符 c 写入由 f 控制的序列. 由 d 控制的序列可使用 io::write 访问. 
f.read(d, s1, n)
 
std::streamsize
 可转换为 multi_char_tag 读取至多 个字符, 来源为由 f 控制的序列, 目标为缓冲区 s1, 返回读取的字符数. 返回值小于 n 表示序列结束. 由 d 控制的序列可使用 io::read 与 io::putback 访问. 
f.write(d, s2, n)
 
std::streamsize
 将 n 个字符从缓冲区 s2 写入由 f 控制的序列. 由 d 控制的序列可使用 io::write 访问. 
f.seek(d, off, way)
 std::streampos -

将读/写头前移 off 个字符, 返回新位置; 偏移量的计算基准为:

  • 序列起点, 若 way 为 ios_base::beg
  • 当前位置, 若 way 为 ios_base::cur
  • 序列末尾, 若 way 为 ios_base::end

由 d 控制的序列可使用 io::seek 以及 io::write 访问 — 后者的条件是 模式 (F 的模式) 可转换为 output.

异常

get、put、read、write 或 seek 执行期间发生的错误通过抛出异常来指示. 到达序列末尾不是错误, 但试图写入超过序列末尾则是.

抛出异常之后, SeekableFilter 必须处于一致状态; 后续 I/O 操作可以抛出异常, 但必须有明确定义的行为. 此外, 除非它满足 Closable, 否则它必须随时可以开始处理新的字符序列.
