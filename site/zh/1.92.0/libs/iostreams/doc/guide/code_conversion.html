3.5 代码转换

在宽字符序列与窄字符序列之间进行转换的过程称为 代码转换. C++ 标准库定义了一个封装代码转换的 locale 刻面 std::codecvt. 类模板 codecvt 有三个模板参数, 分别表示 内部字符类型、外部字符类型 以及存储 代码转换状态 的类型. 内部字符类型如此命名, 是因为它通常是应用程序用于在内存中存储宽字符以进行处理的类型; 外部字符类型如此命名, 是因为它通常是用于在文件等外部介质中存储字符的字符类型. 大多数情况下, 内部字符类型是 wchar_t, 外部字符类型是 char, 代码转换状态是 std::mbstate_t — C++ 标准规定的一个由实现定义的类型.

流和流缓冲默认不执行代码转换. 在 C++ 标准库定义的流和流缓冲中, 只有基于文件的流执行代码转换. 要编写执行代码转换的流或流缓冲, 请使用类模板 code_converter, 它使用 std::codecvt 刻面执行代码转换.
