概述

头文件 <boost/iostreams/categories.hpp> 包含用于对各种 Filter 与 Device 概念的模型进行分类的 类别标签. 头文件 <boost/iostreams/traits.hpp> 包含元函数 char_type_of 与 category 的定义, 用于将两个基本类型关联到 Filter 或 Device 概念的每个模型:

字符类型

过滤器或设备读取或写入的字符的类型.

类别

一个标签结构, Iostreams 库依靠它来确定过滤器或设备支持哪些操作. 对于给定类型 T, 它指示:

  • T 是 Filter 还是 Device
  • 模式 — T 的模式
  • optional_behavior — T 所实现的

其作用与 iterator_category 之于 std::iterator_traits 的作用类似.[1] 用作类别的类型称为 类别标签.

头文件

<boost/iostreams/categories.hpp>
<boost/iostreams/traits.hpp>

类模板 char_type_of

说明

元函数, 将 字符类型 关联到每个 Filter 或 Device 类型. 虽然 char_type_of 的设计允许针对新的过滤器和设备类型进行特化, 但其默认实现应适合大多数用途.

概要

namespace boost { namespace iostreams {

template<typename T>
struct char_type_of {
    typedef see below type;
};

} } // End namespace boost::io

模板参数

T- 某种 Filter 或 Device 概念的模型

io_traits::type

    typedef see below char_type;

嵌套类型 type 的值取决于模板参数 T, 如下:

Tchar_type
特化: std::back_insert_iterator value_type — 属于迭代器的 container_type
所有其他类型 T::char_type

类模板 int_type_of

说明

元函数, 将整数类型关联到每个 Filter 或 Device 类型. 虽然 int_type_of 的设计允许针对新的过滤器和设备类型进行特化, 但其默认实现应适合大多数用途.

概要

namespace boost { namespace iostreams {

template<typename T>
struct int_type_of {
    typedef see below type;
};

} } // End namespace boost::io

模板参数

T- 某种 Filter 或 Device 概念的模型

io_traits::type

    typedef see below char_type;

等于 std::char_traits<char_type>::int_type, 其中 char_type 为 char_type_of<T>::type.

类模板 category_of

说明

元函数, 将 类别标签 关联到每个 Filter 或 Device 类型. 虽然 category 的设计允许针对新的过滤器和设备类型进行特化, 但其默认实现应适合大多数用途.

概要

namespace boost { namespace iostreams {

template<typename T>
struct category_of {
    typedef see below type;
};

} } // End namespace boost::io

模板参数

T- 某种 Filter 或 Device 概念的模型

category::type

    typedef see below type;

嵌套类型 type 的值取决于模板参数 T, 如下:

Tcategory
std::basic_iostream 的特化, 或派生自这样的特化 iostream_tag
std::basic_istream 的特化, 或派生自这样的特化 istream_tag
std::basic_ostream 的特化, 或派生自这样的特化 ostream_tag
std::basic_streambuf 的特化, 或派生自这样的特化 streambuf_tag
std::back_insert_iterator 的特化, 或派生自这样的特化 insert_iterator_tag
所有其他类型 T::category

更多信息参见 <boost/iostreams/traits.hpp>.

类别标签

除各种 模式标签 外, 头文件 <boost/iostreams/categories.hpp> 还提供下表所示的类别标签. 要生成组合若干现有标签的新类别标签, 只需定义一个扩展现有标签的 struct. 例如, 

    struct category
        : seekable,
          filter_tag, 
          localizable_tag 
        { };
这定义了一个表示 Seekable、Localizable 过滤器 的类别标签.
