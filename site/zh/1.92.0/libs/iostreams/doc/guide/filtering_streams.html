3.4 过滤流与流缓冲

类模板 filtering_streambuf 与 filtering_stream 是 Iostreams 库提供的用于过滤数据的基本组件. 每个 filtering_streambuf 或 filtering_stream 包含一个由零个或多个 过滤器组成、后接可选 设备 的链, 通过类似于 std::stack 的接口访问. 这些链由类模板 chain 表示. 若链以设备结尾, 则称为完整, 可用于执行 I/O.

模式 — 链中每个 stream_buffer 的模式 — 都必须细化 filtering_streambuf 或 filtering_stream 的模式. 例如, 不能将模式为 output 的过滤器或设备与 filtering_streambuf — 其模式为 input — 一起使用.

若 filtering_streambuf 或 filtering_stream 的模式为 input, 数据从链的末端流向链的首端 — 从 源 出发, 经过零个或多个 InputFilter. 若其模式为 output, 数据沿相反方向流动 — 从链的首端出发, 经过零个或多个 OutputFilter, 流向链末端的 汇. 若 filtering_streambuf 或 filtering_stream 同时执行输入和输出, 则数据双向流动.
