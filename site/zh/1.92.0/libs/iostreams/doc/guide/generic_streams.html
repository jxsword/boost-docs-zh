概述

Iostreams 库提供的基本组件是类模板 stream_buffer — std::basic_streambuf 的派生类, 通过委托给所含设备来执行 I/O. 设备实例可关联到 stream_buffer 的实例或与之解除关联 — 使用成员函数 open 与 close. 该接口仿照 std::basic_filebuf 与 std::basic_fstream 设计.

类模板 stream 是一个流模板, 从 std::basic_istream、std::basic_ostream 与 std::basic_iostream 之一派生 — 取决于第一个模板参数的 模式. 与 stream_buffer 一样, 设备实例可关联到 stream 的实例或与之解除关联 — 使用其成员函数 open 与 close.

头文件

<boost/iostreams/stream_buffer.hpp>
<boost/iostreams/stream.hpp>

参考

Class template stream_buffer

说明

流缓冲模板, 通过委托给所含的 设备 执行 I/O. 设备类型被指定为 stream_buffer 的第一个模板参数. 设备类型的实例使用成员函数 open 与 close 附加和分离.

概要

namespace boost { namespace iostreams {

template< typename T, 
          typename Tr = std::char_traits<...>, 
          typename Alloc = std::allocator<...>,
          typename Mode = ... >
class stream_buffer : public std::basic_streambuf<...> {
public:
    typedef typename char_type_of<T>::type  char_type;
    typedef typename Tr                     traits_type;

    [Standard stream buffer typedefs: int_type, off_type, etc.]

    stream_buffer();
    stream_buffer( const T& t,
                   std::streamsize buffer_size = default_value, 
                   std::streamsize pback_size = default_value );

        // Forwarding constructors

    template<typename U>
    stream_buffer([const] U& u);

    template<typename U1, typename U2>
    stream_buffer([const] U1& u1, const U2& u2);

        ...

    template<typename U1, ..., typename UN>
    stream_buffer([const] U1& u1, const U2& u2 ..., const UN& uN);

    void open( const T& t,
               std::streamsize buffer_size = default_value, 
               std::streamsize pback_size = default_value );

        // Forwarding overloads of open()

    template<typename U>
    void open([const] U& u);

    template<typename U1, typename U2>
    void open([const] U1& u1, const U2& u2);
    
        ...

    template<typename U1, ..., typename UN>
    void open([const] U1& u1, const U2& u2, ..., const UN& uN);

    bool is_open() const;
    void close();

        // Device access
    
    T& operator*();
    T* operator->();
};

} } // namespace boost::io

模板参数

T- 某种 设备 概念的 CopyConstructible 模型.
Tr- C++ 标准库字符特征类型 ([ISO], 21.1.1), 其 char_type 等于 T 的 字符类型 Ch. 默认为 std::char_traits<Ch>.
Alloc- C++ 标准库分配器类型 ([ISO], 20.1.5), 用于分配所需的任何字符缓冲区. 默认为 std::allocator<Ch>, 其中 Ch 是 T 的 字符类型.
Mode- 一个模式标签, 可转换为 T 的 模式 . 此参数主要供内部使用. 指定一个被 T 的模式正确细化的 模式标签, 在某些情况下可以避免分配不必要的缓冲区. 默认为 T 的模式.

stream_buffer::stream_buffer

    stream_buffer();

构造一个 stream_buffer, 不关联设备 T 的任何实例. 在该实例可用于 I/O 之前, 必须调用其某个 open() 重载.

stream_buffer::stream_buffer

    stream_buffer( const T& t,
                   std::streamsize buffer_size, 
                   std::streamsize pback_size );

构造一个已就绪可执行 I/O 的 stream_buffer, 各参数的含义如下:
t- T 的一个实例
buffer_size- 需要分配的所有缓冲区的大小
pback_size- 回退缓冲区的大小, 仅当 Mode 细化 input 

    template<typename U>
    stream_buffer([const] U& u);

    template<typename U1, typename U2>
    stream_buffer([const] U1& u1, const U2& u2);

        ...

    template<typename U1, ..., typename UN>
    stream_buffer([const] U1& u1, const U2& u2, ..., const UN& uN);

这些成员中的每一个都构造一个 stream_buffer 实例, 并将其与从给定参数列表构造的设备 T 实例相关联. T 构造函数除第一个参数外必须按值或按 const 引用接受所有参数.

无法使用这些构造函数指定自定义缓冲区大小或回退缓冲区大小.

stream_buffer::open

    void open( const T& t,
               std::streamsize buffer_size, 
               std::streamsize pback_size );

若当前没有已关联的此类实例, 则将给定的 T 实例关联到 this 这个 stream_buffer 实例; 否则抛出 std::ios_base::failure. 第二个参数决定需要分配的缓冲区的大小; 值为零表示 I/O 应无缓冲. 第三个参数决定回退缓冲区的大小; 仅当 Mode 细化 input 时才相关.

    template<typename U>
    void open(const U& u);

    template<typename U1, typename U2>
    void open(const U1& u1, const U2& u2);

        ...

    template<typename U1, ..., typename UN>
    void open(const U1& u1, ..., const UN& uN);

这些成员中的每一个都会向 this 这个 stream_buffer 实例关联一个新构造的设备 T 实例 — 从给定参数列表构造 — 条件是当前没有已关联的此类实例; 否则它们抛出 std::ios_base::failure. T 构造函数除第一个参数外必须按值或按 const 引用接受所有参数.

无法使用这些成员指定自定义缓冲区大小或回退缓冲区大小.

stream_buffer::is_open

    bool is_open() const;

若存在设备 T 的实例与 this 这个 stream_buffer 实例相关联, 则返回 true.

stream_buffer::close

    void close();

解除 this 这个 stream_buffer 实例与当前关联的设备 T 实例之间的关联, 视情况调用清理函数并销毁相关联的 T 实例.

stream_buffer::operator*

    T& operator*();

返回对 T 实例的引用, 该实例关联于此 stream_buffer, 后者必须为 open.

stream_buffer::operator->

    T* operator->();

返回指向 T 实例的指针, 该实例关联于此 stream_buffer, 后者必须为 open.

Class template stream

说明

示例

定义简单的 ofstream

以下示例使用 file_sink 定义一个类似于 std::ofstream 的类. 

    #include <boost/iostreams/device/file.hpp>
    #include <boost/iostreams/stream.hpp>
         
    typedef stream<file_sink> ofstream;

    ofstream out("HeavyArtillery.txt"); // Wilfred Owen
    out << "Reach at that Arrogance which needs thy harm,\n"
           "And beat it down before its sins grow worse.\n";
    out.close();

从数组读取

以下示例使用 array_source 从 C 风格字符串构造输入流. 

    #include <cstring>
    #include <iostream>
    #include <string>
    #include <boost/iostreams/device/array.hpp>
    #include <boost/iostreams/stream.hpp>

    const char*           h = "Hello World!";
    stream<array_source>  in(h, std::strlen(h));
    std::string           hello;
    std::getline(in, hello);
    std::cout << hello << "\n";  // Prints "Hello World!"
