Purpose

Boost.Iostreams 有三个目标:

  • 让为访问新 源 和 汇 而创建标准 C++ 流和流缓冲变得容易.
  • 提供一个框架, 用于定义 过滤器 并将其附加到标准流和流缓冲.
  • 提供一组可直接使用的过滤器、源和汇.

例如, Boost.Iostreams 可用于创建访问 TCP 连接的流, 或用作加密和数据压缩的框架. 该库包含的组件可用于: 访问 内存映射文件; 使用操作系统 文件描述符 访问文件; 代码转换; 使用 正则表达式 进行文本过滤; 行尾转换; 以及以 zlib、gzip 和 bzip2 格式进行压缩与解压.

概述

Boost.Iostreams 的核心是一组 概念和一套模板, 后者将这些概念的模型转化为 C++ 标准库的流和流缓冲.

概念

该库的基本构件是以下概念: Source — 提供对字符序列的读访问; Sink — 提供对字符序列的写访问; InputFilter — 过滤从源读取的输入; 以及 OutputFilter — 过滤写入汇的输出. Source、Sink 及其细化称为 设备. InputFilter、OutputFilter 及其细化称为 过滤器.

泛型流与流缓冲

类模板 stream_buffer 与 stream 实现标准流缓冲和流, 它们通过委托给所含的 设备 执行 I/O. 设备通过成员函数 open、is_open 与 close 访问, 提供类似于标准基于文件的流和流缓冲的接口.

过滤流与流缓冲

在过滤方面, Boost.Iostreams 提供模板 filtering_streambuf 与 filtering_stream. filtering_streambuf 或 filtering_stream 的实例包含 chains — 由过滤器和设备组成, 通过类似于 std::stack 的接口访问.

如何阅读 Iostreams 文档

如果你没有用过本库的预发布版本, 请从阅读 教程 开始. 通读编写 设备 的整节内容, 以及编写 过滤器 的至少前几节. 即使你以前用过本库, 也可能想看看教程, 因为库接口已被修改以支持 异步与非阻塞 I/O.

接下来, 浏览一下 快速参考, 以了解 Boost.Iostream 主要组件的概貌.

最后, 当你有其他章节未解答的问题时, 请查阅 用户指南、参考 与 常见问题 (FAQ). 用户指南由一系列短文组成, 彼此大多相互独立. 参考包含 Boost.Iostreams 每个公共组件的详细文档.

约定

除非另有说明, 文档中介绍的所有类、函数和模板都位于命名空间 boost::iostreams 中. 命名空间限定通常省略.

std::basic_istream 的特化将称为 标准输入流, std::basic_ostream 的特化称为 标准输出流, std::basic_iostream 的特化称为 标准 I/O 流, std::basic_streambuf 的特化称为 标准流缓冲. 标准输入流、标准输出流和标准 I/O 流统称为 标准流. 有时会省略限定词 standard.
