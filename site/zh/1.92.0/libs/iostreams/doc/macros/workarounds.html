概述

Boost Iostreams 库包含若干宏, 对编写能在不支持某些核心语言特性的编译器以及有缺陷的标准库实现 (例如不提供模板流的实现) 上工作的代码很有用.

参考

1. 标准头文件 <ios>

头文件

<boost/iostreams/detail/ios.hpp>

概要

#define BOOST_IOSTREAMS_BASIC_IOS(ch, tr) ...
#define BOOST_IOS ...
#define BOOST_IOSTREAMS_FAILURE ...

BOOST_IOSTREAMS_BASIC_IOS

对于支持模板化流的标准库, 展开为 std::basic_ios<ch, tr>; 否则展开为 std::ios.

BOOST_IOS

若可用则展开为 std::ios_base, 否则展开为 std::ios. 要访问嵌套类 std::ios_base::failure, 请使用 BOOST_IOSTREAMS_FAILURE.

BOOST_IOSTREAMS_FAILURE

若可用则展开为 std::ios_base::failure, 否则展开为 std::exception 的某个合适的派生类.

2. 模板化流

头文件

<boost/iostreams/detail/iostream.hpp>

概要

#define BOOST_IOSTREAMS_BASIC_ISTREAM(ch, tr) ...
#define BOOST_IOSTREAMS_BASIC_OSTREAM(ch, tr) ...
#define BOOST_IOSTREAMS_BASIC_IOSTREAM(ch, tr) ...

BOOST_IOSTREAMS_BASIC_ISTREAM

对于支持模板化流的标准库, 展开为 std::basic_istream<ch, tr>; 否则展开为 std::istream.

BOOST_IOSTREAMS_BASIC_OSTREAM

对于支持模板化流的标准库, 展开为 std::basic_ostream<ch, tr>; 否则展开为 std::ostream.

BOOST_IOSTREAMS_BASIC_IOSTREAM

对于支持模板化流的标准库, 展开为 std::basic_iostream<ch, tr>; 否则展开为 std::iostream.

3. 模板化流缓冲

头文件

<boost/iostreams/detail/streambuf.hpp>

概要

#define BOOST_IOSTREAMS_BASIC_STREAMBUF(ch, tr) ...
#define BOOST_IOSTREAMS_PUBSEEKOFF ...
#define BOOST_IOSTREAMS_PUBSEEKPOS ...
#define BOOST_IOSTREAMS_PUBSYNC ...

BOOST_IOSTREAMS_BASIC_STREAMBUF

展开为 std::basic_streambuf<ch, tr> — 适用于支持 std::basic_streambuf 的标准库 — 否则展开为 std::streambuf.

BOOST_IOSTREAMS_PUBSEEKOFF

展开为 pubseekoff — 适用于支持 std::basic_streambuf::pubseekoff 的标准库 — 否则展开为 seekoff.

BOOST_IOSTREAMS_PUBSEEKPOS

展开为 pubseekpos — 适用于支持 std::basic_streambuf::pubseekpos 的标准库 — 否则展开为 seekpos.

BOOST_IOSTREAMS_PUBSYNC

展开为 pubsync — 适用于支持 std::basic_streambuf::pubsync 的标准库 — 否则展开为 sync.

4. 字符特征

头文件

<boost/iostreams/detail/char_traits.hpp>

概要

#define BOOST_IOSTREAMS_CHAR_TRAITS(ch) ...

BOOST_IOSTREAMS_CHAR_TRAITS

展开为 std::char_traits<ch> — 适用于支持 std::char_traits 的标准库 — 否则展开为 std::char_traits<char> 的替代品.

5. 链组件访问

头文件

<boost/iostreams/chain.hpp>

概要

#define BOOST_IOSTREAMS_COMPONENT_TYPE(chain, n) ...
#define BOOST_IOSTREAMS_COMPONENT(chain, n, t) ...

BOOST_IOSTREAMS_COMPONENT_TYPE

用于替代 chain.component_type(n), 适用于不支持显式指定成员函数模板参数的编译器. chain 可以是 filtering_stream、filtering_streambuf 或 basic_chain 的实例.

此宏已弃用. 请改用 chain.component_type(n).

BOOST_IOSTREAMS_COMPONENT

用于替代 chain.component<t>(n), 适用于不支持显式指定成员函数模板参数的编译器. chain 可以是 filtering_stream、filtering_streambuf 或 basic_chain 的实例.
