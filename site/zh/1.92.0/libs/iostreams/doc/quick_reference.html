核心组件

这些组件构成 Boost.Iostreams 与标准 iostreams 库之间的接口.

名称 头文件[1] 说明
stream stream.hpp 流模板, 使用其第一个模板参数的实例执行 I/O, 该参数必须是 设备 概念的模型. 从 std::basic_istream、std::basic_ostream 或 std::basic_iostream 派生 — 取决于其第一个模板参数是 Source、Sink 还是两者的模型.
stream_buffer stream_buffer.hpp 流缓冲模板, 使用其第一个模板参数的实例执行 I/O, 该参数必须是 设备 概念的模型.
filtering_stream filtering_stream.hpp 流模板, 使用所含的 chain 执行过滤 I/O. 从 std::basic_istream、std::basic_ostream 或 std::basic_iostream 派生 — 取决于其 模式, 该模式由其第一个模板参数指定.
filtering_streambuf filtering_streambuf.hpp 流缓冲模板, 使用所含的 chain 执行过滤 I/O.
chain chain.hpp 由零个或多个 过滤器组成、后接可选 设备 的序列, 通过类栈接口访问. 由 filtering_stream 与 filtering_streambuf 使用.
code_converter code_converter.hpp 设备适配器, 接受窄字符 设备, 通过引入一层 代码转换 生成宽字符 设备.

过滤器

类别 Filter 头文件[3] 说明
压缩 basic_bzip2_compressor,
basic_bzip2_decompressor 		bzip2.hpp 使用 libbzip2 数据压缩库 ([Seward]) 执行压缩与解压.
basic_gzip_compressor,
basic_gzip_decompressor 		gzip.hpp 基于 GZIP 格式 ([Deutsch3]) 执行压缩与解压.
basic_zlib_compressor,
basic_zlib_decompressor 		zlib.hpp 使用 zlib 数据压缩库 ([Gailly]) 执行压缩与解压.
文本 basic_counter counter.hpp 维护字符计数和行计数.
basic_regex_filter regex.hpp 使用 Boost 正则表达式库 的正则表达式执行文本替换.
basic_grep_filter grep.hpp 使用 Boost 正则表达式库 的正则表达式逐行过滤字符序列.
newline_checker newline.hpp 验证字符序列是否符合给定的行尾约定.
newline_filter 在各种操作系统使用的行尾约定之间转换.
辅助工具 basic_line_filter line.hpp 一次一行地过滤字符序列.
basic_stdio_filter stdio.hpp 通过从标准输入读取并向标准输出写入进行过滤.
aggregate_filter aggregate.hpp 一次性过滤整个字符序列.
symmetric_filter symmetric.hpp 使用 SymmetricFilter 的模型进行过滤.

算法

算法 头文件 说明
copy boost/iostreams/copy.hpp

从 Source 读取字符并写入 汇, 直至到达流末尾; 返回写入的字符数.

视图

每个视图由一个或多个类模板以及一个 对象生成器 组成. 参见 视图.

对象生成器 视图模板 头文件[1] 说明
combine combination combine.hpp 接受一对 过滤器 或 设备, 产生一个过滤器或设备: 使用第一个组件执行输入, 使用第二个组件执行输出.
compose composite compose.hpp 接受一个 过滤器 以及第二个 过滤器 或一个 设备, 产生一个过滤器或设备: 其输出按顺序流经这两个组件, 其输入按逆序流经这两个组件.
invert inverse invert.hpp 接受一个 过滤器, 产生一个执行相同过滤算法的过滤器: 若给定组件是 InputFilter, 则为 OutputFilter, 否则为 InputFilter.
restrict
slice		 restriction restrict.hpp
slice.hpp		 接受一个 过滤器 或 设备, 连同一个流偏移量和可选的长度, 产生一个 过滤器 或 设备, 用于访问给定组件的指定子序列
tee tee_device tee.hpp 接受一对 汇, 产生一个汇, 它将所有进入的数据发送到给定的两个汇.
tee_filter 接受一个 过滤器 和一个 汇, 产生一个过滤器, 它在将数据向下游传递之外, 还将所有输出数据发送到该汇.

注释

[1]路径名应相对于目录 boost/iostreams 解释.

[2]路径名应相对于目录 boost/iostreams/device 解释.

[3]路径名应相对于目录 boost/iostreams/filter 解释.
