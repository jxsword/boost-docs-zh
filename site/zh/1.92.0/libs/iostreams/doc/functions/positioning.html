概述

头文件 <boost/iostreams/positioning.hpp> 提供整数类型 boost::iostreams::stream_offset 的定义 — 该类型能够在多数平台上容纳任意流偏移量 — 以及两个函数 offset_to_position 与 position_to_offset 的定义, 用于在 stream_offset 与 std::streampos 之间转换.

类型 std::streampos 需要能够容纳任意流位置, 但它不是整数类型. 尽管 std::streampos 与整数类型 std::streamoff 可以互相转换, 但对于较大的 (64 位) 值, 从 std::streampos 到 std::streamoff 的转换可能不保真. 整数类型 boost::iostreams::stream_offset 旨在替代 std::streamoff, 与 std::streampos 之间的隐式转换将被显式转换函数取代.

offset_to_position 与 position_to_offset 的实现依赖由实现定义的行为; 只有对将 std::streamoff 定义为 64 位类型、或已对 Boost Iostreams 库进行显式配置的标准库, 才能保证其对大值正确工作.

致谢

Gareth Sylvester-Bradley 提出了 Boost Iostreams 库对大流偏移量的处理方式, 并提供了与 Dinkumware 标准库配套使用的 offset_to_position 与 position_to_offset 的实现.

参考

概要

namespace boost { namespace iostreams {

typedef boost::intmax_t stream_offset;
std::streampos offset_to_position(stream_offset n);
stream_offset position_to_offset(std::streampos pos);

} } // End namespace boost::io

函数模板 offset_to_position

std::streampos offset_to_position(stream_offset n);

返回一个 std::streampos, 表示流中的第 n个位置.

函数模板 position_to_offset

stream_offset position_to_offset(std::streampos pos);

返回一个 stream_offset, 表示与 pos 相同的字符位置, 不考虑任何代码转换状态.
