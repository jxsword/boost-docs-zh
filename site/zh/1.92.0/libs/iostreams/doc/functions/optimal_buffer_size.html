概述

函数模板 optimal_buffer_size 返回在未显式指定缓冲区大小时, 库的流、流缓冲和链为过滤器或设备分配的字符缓冲区的大小.

头文件

<boost/iostreams/optimal_buffer_size.hpp>
<boost/iostreams/operations.hpp>

参考

概要

namespace boost { namespace iostreams {
              
template<typename T>
std::streamsize optimal_buffer_size(T& t);

} } // End namespace boost::io

模板参数

T- 一个 Filter 或 Device 模型.
template<typename T>
std::streamsize optimal_buffer_size(T& t);

optimal_buffer_size 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 optimally_buffered_tag 返回 t.optimal_buffer_size().
可转换为 filter_tag 但不可转换为 optimally_buffered_tag 返回 default_filter_buffer_size.
otherwise 返回 default_device_buffer_size.
