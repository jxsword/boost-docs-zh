函数模板 copy

说明
头文件
概要

说明

函数模板 copy 从给定的 Source 模型读取数据, 并将其写入给定的 Sink 模型, 直至到达流末尾. 然后它使用函数模板 close 关闭这两个组件, 并返回写入的字符数.

所用临时缓冲区的大小可作为可选参数提供.

copy 有四个重载, 以涵盖 Source 与 Sink 的所有组合 — 它们以 const 引用传递 — 以及流和流缓冲 — 它们以非 const 引用传递.

头文件

<boost/iostreams/copy.hpp>

概要

namespace boost { namespace iostreams {
              
template<typename Source, typename Sink>
std::streamsize
copy( [const] Source& src, [const] Sink& sink,
      std::streamsize buffer_size = default value );

} } // End namespace boost::io
