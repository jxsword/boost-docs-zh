函数模板 imbue

说明

函数模板 imbue 会被 Iostreams 库自动调用, 触发条件是: 库流或流缓冲的 std::locale 被使用 std::basic_ios::imbue 或 std::basic_streambuf::pubimbue 设置. 当 std::locale 被设置时 — 针对 stream_buffer 或 stream 的实例 — imbue 会在底层设备上被调用; 当 std::locale 被设置时 — 针对 filtering_streambuf 或 filtering_stream — imbue 会在底层链中的每个过滤器和设备上被调用.

头文件

<boost/iostreams/detail/imbue.hpp>
<boost/iostreams/detail/operations.hpp>

参考

概要

namespace boost { namespace iostreams {
              
template<typename T>     
void imbue(T& t, const std::locale& loc);

} } // End namespace boost::io

模板参数

T- 某种 Filter 或 Device 概念的模型

语义

对于过滤器或设备类型, imbue 的语义取决于类型 T 的 类别, 如下:

category_of<T>::type语义
可转换为 streambuf_tag 调用 t.pubimbue(loc)
可转换为 localizable_tag 但不可转换为 streambuf_tag 调用 t.imbue(loc)
其他情况 空操作
