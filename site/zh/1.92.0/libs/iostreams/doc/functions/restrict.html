说明

给定提供对单个字符序列访问的过滤器或设备, 我们可以构造第二个过滤器或设备, 它提供对原序列的连续子序列的访问. 第二个过滤器或设备被称为原设备的限制. 限制由类模板 restriction 的实例表示. 函数模板 resrict 是一个 对象生成器, 传入一个过滤器或设备以及一对指示受限子序列端点的值时, 返回 resriction 的适当实例.

模式 — resriction 的模式 — 与底层组件的模式相同. resriction 满足 Closable、Flushable、Localizable 与 OptimallyBuffered.

函数模板 slice 可作为 restrict 的别名使用, 适用于将 restrict 视为关键字的平台.

概要

namespace boost { namespace iostreams {

template<typename Component>
class restriction {
public:
    typedef typename char_type_of<Component>::type  char_type;
    typedef implementation-defined                  mode;

    restriction( [const] Component& component,
                 stream_offset off, 
                 stream_offset len = -1 );

    // Filter or Device member functions
};

template<typename Component>
restriction<Component> 
restrict( [const] Component& component,
          stream_offset off, 
          stream_offset len = -1 );

} } // End namespace boost::io

类模板 restriction

模板参数

Component- 满足 Filter 或 Device

restriction::restriction

    restriction( [const] Component& component,
                 stream_offset off, 
                 stream_offset len = -1 );

基于给定组件和偏移量构造一个 restriction 实例. 各参数的含义如下:

component- 要加以限制的过滤器或设备. 若 Component 是流或流缓冲类型, 则函数参数是非 const 引用; 否则是 const 引用.
off- 受限字符序列起点的偏移量.
len- 受限字符序列的长度. 值 -1 表示受限序列的末尾应与未限制序列的末尾相同.
