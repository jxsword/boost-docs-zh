说明

类模板 combination 接受一个 InputFilter/OutputFilter 对或一个 Source/Sink 对, 产生一个过滤器或设备: 使用第一个组件执行输入, 使用第二个组件执行输出. 函数模板 combine 接受一个 InputFilter/OutputFilter 对或一个 Source/Sink 对, 返回 combination 的适当特化.

头文件

<boost/iostreams/combine.hpp>

概要

namespace boost { namespace iostreams {
   
template<typename In, typename Out>
class combination;

template<typename In, typename Out>
combination<In, Out> combine(const In& in, const Out& out);

} } // End namespace boost::io
