概述

函数模板 put 提供向 汇 写入字符的统一接口, 供定义新的 过滤器 类型时使用 (参见 示例).

示例

以下代码展示了函数 put 在定义 OutputFilter 时的使用.

    #include <ctype.h>                        // toupper
    #include <boost/iostreams/concepts.hpp>   // output_filter 
    #include <boost/iostreams/operations.hpp> // put

    using namespace std;
    namespace io = boost::iostreams;

    struct toupper_filter : public io::output_filter {
        template<typename Sink>
        bool put(Sink& snk, char c)
        {
            return io::put(snk, toupper((unsigned char) c));
        }
    };

参考

说明

尝试向模板参数 Sink 的给定实例写入一个字符, 成功时返回 true.

概要

namespace boost { namespace iostreams {
              
    template<typename Sink>     
    void put(Sink& snk, typename char_type_of<Sink>::type c);

} } // End namespace boost::io

模板参数

Sink- 一个 间接 的 Sink 模型, 或标准输出流或流缓冲类型.

函数参数

snk- 实例: Sink

语义

    template<typename Sink>     
    void put(Sink& snk, typename char_type_of<Sink>::type c);

put 的语义取决于 类别 — Sink 的类别 — 如下:

category_of<Sink>::type语义
可转换为 direct_tag 编译期错误
可转换为 ostream_tag 调用 snk.put(c)
可转换为 streambuf_tag 但不可转换为 ostream_tag 调用 snk.sputc(c)
otherwise 调用 snk.write(&c, 1)
