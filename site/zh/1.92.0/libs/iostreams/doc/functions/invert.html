说明

类模板 inverse 是一个适配器, 将 InputFilter 转换为 OutputFilter, 或反之. 函数模板 invert 是一个 对象生成器, 传入过滤器时返回 inverse 适当特化的实例.

给定 InputFilter f, f 的逆是一个 多字符 OutputFilter, 其成员函数 write 实现如下. 给定 汇 snk 和一个字符类型缓冲区 s — 其长度为 n — 我们

  • 构造一个 源, 基于缓冲区 s, 并对其执行 compose — 使用 f — 以形成源, 然后
  • 反复从组合源读取字符类型序列并写入 snk, 直至缓冲区 s 耗尽.

类似地, 给定 OutputFilter f, f 的逆是一个 多字符 InputFilter, 其成员函数 read 实现如下. 给定 源 src 和一个字符类型缓冲区 s — 其长度为 n — 我们

  • 构造一个 汇, 基于缓冲区 s, 并对其执行 compose — 使用 f — 以形成汇, 然后
  • 反复从 src 读取字符类型序列并写入组合汇, 直至缓冲区 s 填满.

模式 — inverse 特化的模式 — 等于 output, 若底层过滤器的模式细化 input; 否则等于 input.
