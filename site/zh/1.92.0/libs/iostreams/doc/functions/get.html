概述

函数模板 get 提供从 源 读取字符的统一接口, 供定义新的 过滤器 类型时使用 (参见 示例).

示例

以下代码展示了函数 get 在定义 InputFilter 时的使用.

    #include <ctype.h>                        // tolower    
    #include <boost/iostreams/concepts.hpp>   // input_filter 
    #include <boost/iostreams/operations.hpp> // get, EOF, WOULD_BLOCK

    using namespace std;
    using namespace boost::io;

    struct tolower_filter : public input_filter {
        template<typename Source>
        int get(Source& src)
        {
            int c;
            return (c = boost::iostreams::get(src)) != EOF &&
                    c != WOULD_BLOCK 
                        ?
                tolower((unsigned char) c) :
                c;
        }
    };

参考

说明

尝试从模板参数 Source 的给定实例中提取一个字符, 返回提取的字符或特殊值 traits_type::eof 或 traits_type::would_block 之一, 其中 traits_type 是下者的适当特化: boost::iostreams::char_traits

概要

namespace boost { namespace iostreams {
              
    template<typename Source>     
    typename int_type_of<Source>::type
    get(Source& src);

} } // End namespace boost::io

模板参数

Source- 一个 Source 模型.

函数参数

src- 实例: Source

语义

    template<typename Source>     
    typename int_type_of<Source>::type
    get(Source& src);

get 的语义取决于 类别 — Source 的类别 — 如下:

category_of<Source>::type语义
可转换为 direct_tag 编译期错误
可转换为 istream_tag returns src.get()
可转换为 streambuf_tag 但不可转换为 istream_tag returns src.sbumpc()
otherwise 尝试使用 src.read() 提取单个字符, 成功时返回提取的字符, 否则返回特殊值 traits_type::eof 或 traits_type::would_block 之一, 其中 traits_type 为 boost::iostreams::char_traits<Source>
