概述

函数模板 write 的两个重载提供向 汇 或 OutputFilter 写入字符序列的统一接口.

  • 第一个重载可直接用于定义新的过滤器类型 (参见 示例), 并出现在 Device 概念的规范中.
  • 第二个重载主要供库内部使用.

示例

以下代码展示了函数 write 在定义反转其受控序列的 OutputFilter 时的使用.

    #include <algorithm>                      // reverse 
    #include <vector>
    #include <boost/iostreams/concepts.hpp>   // output_filter 
    #include <boost/iostreams/operations.hpp> // write

    using namespace std;
    using namespace boost::io;

    struct reversing_filter : public multichar_output_filter {
        template<typename Sink>
        std::streamsize write(Sink& snk, const char* s, streamsize n)
        {
            data.insert(data.end(), s, s + n);
            return n;
        }
        template<typename Sink>
        void close(Sink& snk)
        {
            std::reverse(data.begin(), data.end());
            boost::iostreams::write(&data[0], (streamsize) data.size());
            data.clear();
        }
        std::vector<char> data;
    };

参考

说明

尝试向模板参数 T 的给定实例写入一个字符序列, 返回写入的字符数.

概要

namespace boost { namespace iostreams {
              
template<typename T>     
std::streamsize 
write( T& t,
       const typename char_type_of<T>::type* s, 
       std::streamsize n );

template<typename T, typename Sink>
std::streamsize 
write( T& t,
       Sink& snk,
       const typename char_type_of<T>::type* s, 
       std::streamsize n );

} } // End namespace boost::io

模板参数

T- 第一个重载: 某种 汇 概念的模型; 第二个重载: 某种 OutputFilter 概念的模型.
Sink- 一个 汇 模型, 其 字符类型 与 T 相同, 其 模式 细化 T.

函数参数

t- T 的一个实例
s- 包含要写入字符的缓冲区
n- 要写入的字符数
snk- 一个 Sink 实例.

语义 — 设备类型

template<typename T>     
std::streamsize
write( T& t,
       const typename char_type_of<T>::type* s,
       std::streamsize n );

write 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 ostream_tag returns t.rdbuf()->sputn(s, n)
可转换为 streambuf_tag 但不可转换为 ostream_tag returns t.sputn(s, n)
otherwise returns t.write(s, n)

语义 — 过滤器类型

template<typename T, typename Sink>
std::streamsize
write( T& t,
       Sink& snk,
       const typename char_type_of<T>::type* s,
       std::streamsize n );

write 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 multichar_tag returns t.write(snk, s, n)
其他情况 尝试写入 n 个字符, 来自 s, 通过反复调用 t.put(snk, s[m]) — 对 m 在区间 [0, n) 中的每个值 — 若 put 返回 false 则停止. 返回写入的字符数.
