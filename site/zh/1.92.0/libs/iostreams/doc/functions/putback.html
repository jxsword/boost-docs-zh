概述

函数模板 putback 提供将从 Peekable 模型读出的字符回退的统一接口, 供定义 过滤器 时使用.

头文件

<boost/iostreams/operations.hpp>
<boost/iostreams/putback.hpp>

参考

说明

尝试向模板参数 Peekable 的给定实例回退一个字符, 成功时返回 true.

概要

namespace boost { namespace iostreams {
              
    template<typename Peekable>     
    bool putback(Peekable& peekable, typename char_type_of<Peekable>::type c);

} } // End namespace boost::io

模板参数

Peekable- 一个 Peekable 模型.

语义

putback 的语义取决于 类别 — Peekable 的类别 — 如下:

category_of<Peekable>::type语义
可转换为 istream_tag 调用 peekable.rdbuf()->putback(c), 若操作成功则返回 true
可转换为 streambuf_tag 但不可转换为 istream_tag 调用 peekable.sputbackc(c), 若操作成功则返回 true
可转换为 peekable_tag, 但不可转换为 streambuf_tag 或 istream_tag returns peekable.putback(c)
otherwise 编译期错误
