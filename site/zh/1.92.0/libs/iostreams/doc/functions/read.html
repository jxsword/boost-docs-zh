概述

函数模板 read 的两个重载提供从 Source 或 InputFilter 读取字符序列的统一接口.

  • 第一个重载可直接用于定义新的过滤器类型 (参见 示例), 并出现在 Device 概念的规范中.
  • 第二个重载主要供库内部使用.

示例

以下代码展示了函数 read 在定义 多字符 InputFilter 时的使用.

    #include <ctype.h>                        // tolower
    #include <boost/iostreams/concepts.hpp>   // multichar_input_filter 
    #include <boost/iostreams/operations.hpp> // read

    using namespace std;
    namespace io = boost::iostreams;

    struct tolower_filter : public io::multichar_input_filter {
        template<typename Source>
        streamsize read(Source& src, char* s, streamsize n)
        {
            streamsize result;
            if ((result = io::read(src, s, n)) == -1)
                return -1; // EOF
            for (streamsize z = 0; z < result; ++z)
                s[z] = tolower((unsigned char) s[z]);
            return result;
        }
    };

参考

说明

从模板参数 T 的给定实例读取一个字符序列, 返回读取的字符数, 或返回 -1 表示序列结束.

概要

namespace boost { namespace iostreams {
              
template<typename T>     
std::streamsize read( T& t,
                      typename char_type_of<T>::type* s, 
                      std::streamsize n );

template<typename T, typename Source>
std::streamsize read( T& t,
                      Source& src,
                      typename char_type_of<T>::type* s, 
                      std::streamsize n );

} } // End namespace boost::io

模板参数

T- 第一个重载: 某种 Source 模型或标准输入流或流缓冲类型; 第二个重载: 某种 InputFilter 模型.
Source- 一个 间接 的 Source 模型, 其 字符类型 与 T 相同, 其 模式 细化 T. Source 还必须是 Peekable 的模型.

函数参数

t- 一个实例, 其类型为过滤器或设备类型 T
s- 应将字符读入的缓冲区
n- 要读取的最大字符数
src- 实例: Source

语义 — 设备类型

template<typename T>     
std::streamsize read( T& t,
                      typename char_type_of<T>::type* s, 
                      std::streamsize n );

read 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 istream_tag 调用 t.read(s, n) 并返回 t.gcount()
可转换为 streambuf_tag 但不可转换为 istream_tag returns t.sgetn(s, n)
不可转换为 direct_tag returns t.read(s, n)
otherwise 编译期错误

语义 — 过滤器类型

template<typename T>
std::streamsize read( T& t,
                      Source& src,
                      typename char_type_of<T>::type* s,
                      std::streamsize n );

read 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 multichar_tag returns t.read(src, s, n)
otherwise 读取至多 n 个字符到 s — 通过反复调用 t.get(src) — 若返回 traits_typre::eof 或 traits_type::would_block 则停止, 其中 traits_type 为 boost::iostreams::char_traits<Source>. 返回读取的字符数, 或返回 -1 表示序列结束.
