说明

类模板 tee_filter 与 tee_device 提供两种拆分输出序列的方式, 使所有数据同时定向到两个不同位置. tee_filter 是一种 OutputFilter, 它在将数据不加修改地向下游传递之外, 还将所有数据复制到构造时指定的 汇. tee_device 是一种 汇, 它将所有数据复制到构造时指定的两个汇.

重载的函数模板 tee 是一个 对象生成器, 给定一个汇或一对汇, 返回 tee_filter 或 tee_device 的适当特化.

namespace boost { namespace iostreams {

template<typename Sink>
class tee_filter {
public:
    typedef typename char_type_of<Sink>::type  char_type;
    typedef [implementation-defined]           category;

    explicit tee_filter([const] Sink& snk);

    // OutputFilter member functions
};

template<typename Sink1, typename Sink2>
class tee_device {
public:
    typedef typename char_type_of<Sink1>::type  char_type;
    typedef [implementation-defined]            category;

    tee_device([const] const& sink1, [const] Sink2& sink2);

    // Sink member functions
};

template<typename Sink>
tee_filter<Sink> tee([const] Sink& snk);

template<typename Sink1, typename Sink2>
tee_device<Sink1, Sink2> tee([const] Sink1& sink1, [const] Sink2& sink2);


} } // End namespace boost::io

类模板 tee_filter

说明

一种 OutputFilter, 它将流经它的所有数据复制到构造时指定的 汇. tee_filter 满足 Closable、Flushable、Localizable 与 OptimallyBuffered.

模板参数

Sink- 一个 Blocking 的 Sink

tee_filter::tee_filter

explicit tee_filter([const] Sink& sink);

基于给定汇构造一个 tee_filter 实例. 函数参数是非 const 引用 — 若 Sink 是流或流缓冲类型 — 否则是 const 引用.

类模板 tee_device

说明

一种 汇, 它将所有数据复制到构造时指定的两个汇中的每一个. tee_device 满足 Closable、Flushable、Localizable 与 OptimallyBuffered.

模板参数

Sink1- 一个 Blocking 的 Sink
Sink2- 一个 Blocking 的 Sink, 其 字符类型 与下者相同: Sink1

tee_device::tee_device

tee_device([const] const& sink1, [const] Sink2& sink2);

基于给定的一对汇构造一个 tee_device 实例. 若相应的模板参数是流或流缓冲类型, 则每个函数参数是非 const 引用; 否则是 const 引用.
