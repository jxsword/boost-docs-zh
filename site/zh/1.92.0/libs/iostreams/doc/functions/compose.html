说明

给定过滤器 f 与设备 d, 我们可以构造设备 c, 其成员函数通过调用基本 I/O 操作 read、write、等 来实现 — 以 f 为第一个参数, d 为第二个参数. 类似地, 若给定两个过滤器 f1 与 f2, 我们可以构造第三个过滤器 f3, 其成员函数模板通过调用基本 I/O 操作 read、write、等 来实现 — 第一个参数等于 f1, 第二个参数等于将 f2 与给定设备组合的结果.

函数模板 composite 表示按上述方式构造的过滤器或设备. 函数模板 compose 是一个 对象生成器, 给定一对组件, 返回 composite 的适当实例.

模式 被定义为: 对 composite 而言, 提供两个组件共有功能的一个最大子集. composite 满足 Closable、Flushable、Localizable 与 OptimallyBuffered.

参考

概要

namespace boost { namespace iostreams {

template<typename Filter, typename FilterOrDevice>
class composite {
public:
    typedef typename char_type_of<Filter>::type  char_type;
    typedef implementation-defined               mode;

    composite(const Filter& first, [const] FilterOrDevice& second);

    // Filter or Device member functions
};

template<typename Filter, typename FilterOrDevice>
composite<Filter, FilterOrDevice> 
compose(const Filter& first, [const] FilterOrDevice& second);

} } // End namespace boost::io

类模板 composite

模板参数

Filter- 满足 Filter
FilterOrDevice- 满足 Filter 或 Device

composite::composite

    composite(const Filter& first, [const] FilterOrDevice& second);

基于给定组件构造一个 composite 实例. 若 FilterOrDevice 是流或流缓冲类型, 则第二个参数是非 const 引用; 否则是 const 引用.

函数模板 compose

    composite(const Filter& first, [const] FilterOrDevice& second);

模板参数

Filter- 满足 Filter
FilterOrDevice- 满足 Filter 或 Device

返回由给定组件构造的 composite 适当特化的实例. 若 FilterOrDevice 是流或流缓冲类型, 则第二个参数是非 const 引用; 否则是 const 引用.
