概述

Iostreams 库使用函数模板 seek 在 设备 控制的序列内执行随机访问.

头文件

<boost/iostreams/operations.hpp>
<boost/iostreams/seek.hpp>

参考

说明

在给定模板参数 T 实例所控制的序列内重新定位一个或两个头, 返回最终的流位置.

概要

namespace boost { namespace iostreams {
              
template<typename T>
std::streampos 
seek( T&, stream_offset  off, std::ios_base::seekdir way,
      std::ios_base::openmode which =
          std::ios_base::in | std::ios_base::out );

} } // End namespace boost::io

模板参数

T- 某种 设备 概念的模型, 允许随机访问.

函数参数

off- 一个 stream_offset, 指示相应的读头或写头应前移的字符数. 初始位置由参数 way 决定.
way-

决定偏移量 off 所应用的初始位置, 如下:

  • 若 way 为 std::ios_base::beg, 初始位置为流的开头
  • 若 way 为 std::ios_base::cur, 初始位置为当前位置
  • 若 way 为 std::ios_base::end, 初始位置为流的末尾

which- 决定是重定位读头、写头还是两者.

语义

seek 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 istream_tag 或 ostream_tag 返回:
  • t.rdbuf()->pubseekpos(offset_to_position(off)) — 若 way 为 std::ios_base::beg 且 off 在 std::streamoff 的范围之外; 以及
  • t.rdbuf()->pubseekoff(off, way) — 否则
可转换为 streambuf_tag 返回:
  • t.pubseekpos(offset_to_position(off)) — 若 way 为 std::ios_base::beg 且 off 在 std::streamoff 的范围之外; 以及
  • t.pubseekoff(off, way) — 否则
可转换为 input_seekable 但不可转换为 output_seekable returns t.seek(off, way)
可转换为 output_seekable 但不可转换为 input_seekable returns t.seek(off, way)
可转换为 dual_seekable 或 bidirectional_seekable returns t.seek(off, way, which)
可转换为 seekable returns t.seek(off, way)
其他情况 编译期错误

简而言之:

  • 若 T 是标准流或流缓冲类型, 则酌情委托给 std::basic_streambuf::pubseekoff 或 std::basic_streambuf::pubseekpos.
  • 否则, 若 模式 — T 的模式 — 只允许一个读头, 则委托给成员函数 seek — 该函数接受 stream_offset 与 seekdir 但不接受 openmode.
  • 否则, 若 模式 — T 的模式 — 允许带两个读头的随机访问, 则委托给成员函数 seek — 该函数接受 stream_offset、seekdir 与 openmode.
  • 若 T 的 模式 不允许随机访问, 则尝试调用 seek 是编译期错误.
