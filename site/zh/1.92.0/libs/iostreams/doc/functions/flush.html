概述

函数模板 flush 尝试将所有缓冲字符刷新到下游. 提供它是为了便于在一系列输出操作的中途修改过滤链; 具体而言, 它用于实现函数 strict_sync (参见 例如 filtering_stream::strict_sync). 若 strict_sync 成功, 则可以使用 set_auto_close(false) 安全地禁用过滤链的自动关闭特性 (参见 例如 filtering_stream::set_auto_close). 之后即可向链中添加或从中移除过滤器, 并确知没有字符仍留在缓冲区中.

对于非 Flushable 的设备, flush 返回 true, 表示没有发生错误.[1] 但对于非 Flushable 的过滤器, flush 返回 false, 表示可能仍有字符留在缓冲区中.

在处理设备时, flush 可用作 std::basic_ostream::flush() 的通用版本.

参考

说明

尝试将所有缓冲字符刷新到下游. 对于 设备, 返回 true, 除非发生错误.[1]. 对于 过滤器, 返回 true 的条件是: 所有缓冲字符都已成功写入 snk.

概要

namespace boost { namespace iostreams {
              
template<typename T>
bool flush(T& t);

template<typename T, typename Sink>
bool flush(T& t, Sink& snk);

} } // End namespace boost::io

模板参数

T- 第一个重载: 某种 设备 概念的模型; 第二个重载: 某种 Filter 概念的模型.
Sink- 一个 Sink 模型, 其 字符类型 与下者相同: T.

语义 — 设备类型

template<typename T>
bool flush(T& t);

flush 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 ostream_tag 调用 t.rdbuf()->pubsync(), 若操作成功则返回 true.
可转换为 streambuf_tag 但不可转换为 istream_tag 调用 t.pubsync(), 若操作成功则返回 true.
不可转换为 flushable_tag returns t.flush()
otherwise returns true

语义 — 过滤器类型

template<typename T, typename Sink>
bool flush(T& t, Sink& snk);

flush 的语义取决于 类别 — T 的类别 — 如下:

category_of<T>::type语义
可转换为 flushable_tag returns t.flush(snk)
otherwise returns false

[1]在开发后期才注意到, 为了与使用异常报告错误的策略保持一致 (参见 异常), 本应规定 flush 在设备上被调用时返回 void. 在规范更改之前, 设备在刷新时应始终返回 true.
