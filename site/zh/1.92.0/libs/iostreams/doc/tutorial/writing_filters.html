2.2.1. 概述: InputFilter、OutputFilter 与过滤器辅助类

过滤器用于修改字符序列. 例如, 你可以用过滤器把一个单词的所有出现替换为另一个单词, 把所有字母字符转换为小写, 或加密文档. 有时过滤器只是观察者; 此时过滤后的字符序列与未过滤的序列相同. 例如, 你可以用过滤器统计某个单词出现的次数.

InputFilter 与 OutputFilter

Iostreams 库支持两类基本过滤器: InputFilter 与 OutputFilter. InputFilter 表示过滤的"拉"模型: 提供一个未过滤数据的源 — 表示为一个 Source — 并期望过滤器生成过滤后序列的一定数量的字符. 过滤后的序列是增量生成的, 意味着要过滤给定的字符序列, 通常必须多次调用过滤器. OutputFilter 表示过滤的"推"模型: 提供一个未过滤字符序列和一个 汇, 期望过滤器过滤这些字符并将它们写入汇. 与 InputFilter 一样, OutputFilter 也是增量处理数据.

最简单的 InputFilter 和 OutputFilter 一次处理一个字符. 这类过滤器易于编写, 但比一次处理多个字符的过滤器效率低. 一次处理多个字符的过滤器称为 多字符过滤器.

过滤器辅助类

Iostreams 库提供了若干实用工具, 让编写过滤器更容易:

  • aggregate_filter 允许程序员这样定义过滤器: 从一个 std::vector 读取未过滤数据, 并将过滤后的数据写入另一个 std::vector.
  • stdio_filter 允许程序员这样定义过滤器: 从标准输入读取未过滤数据, 并将过滤后的数据写入标准输出.
  • symmetric_filter 允许程序员这样定义过滤器: 从一个数组读取未过滤数据, 并将过滤后的数据写入另一个数组.
  • finite_state_filter 允许程序员将过滤器定义为有限状态机. 该组件随示例过滤器提供; 它目前不是库的正式组成部分.

选择过滤器概念

假设你需要编写一个过滤器来完成给定的过滤任务. 你如何决定是编写 InputFilter 还是 OutputFilter, 还是使用某个过滤器辅助类? 上面提到的前两个过滤器辅助类 aggregate_filter 与 stdio_filter 内存占用较高, 且只能用于具有明确定义终点的字符序列. 不过, 它们允许以非常直白的方式表达过滤算法, 因此是学习过滤的良好入门. 第三个过滤器辅助类 symmetric_filter 适合用于定义基于 C 语言 API 的过滤器, 例如 zlib、libbz2 或 OpenSSL. 如果所有过滤器辅助类都不合适, 通常而言: 若计划用过滤器读取, 应编写 InputFilter; 若计划用它写入, 应编写 OutputFilter. 不过在某些情况下, 把算法表述为 InputFilter 比表述为 OutputFilter 容易得多, 或反之. 此时, 你可以按更简单的方式编写过滤器, 并使用类模板 inverse 或函数模板 invert 把 InputFilter 转换为 OutputFilter 或反之.

在下面的过滤示例中, 除最后一个外, 我都会先展示如何使用 stdio_filter 实现算法, 然后再从零将其实现为 InputFilter 或 OutputFilter.
