2.2.10. 有限状态过滤器

有限状态机

本节展示如何从有限状态机构造 双用途过滤器. 就本节而言, 有限状态机由以下部分组成: 一个 状态集合 (表示为若干 int)、一个特定的 初始状态、一个 转移表、一组 事件处理器 以及一个字符栈. 这些有限状态机的灵感来自随 Boost Metaprogamming library 附带的有限状态机示例. 参见 例如 <libs/mpl/example/player1.cpp>

事件就是一个字符, 就我们而言. 转移表是一个 MPL Forward Sequence, 由 行组成. 每行是一个四元组, 由 当前状态、字符类、下一状态和 事件处理器组成. 在有限状态机运行期间, 会查询其转移表, 以确定机器的状态应如何更新以及应调用哪个事件处理器. 当事件 e 发生时, 会在转移表中搜索第一行 — 其当前状态等于机器的当前状态, 且其字符类匹配 e. 然后机器的状态被更新为该行的下一状态, 并以 e 为参数调用事件处理器.

字符类是一种类类型, 带有一个 static 成员函数 test, 该函数以一个字符和一个 std::locale 为参数. 例如, 

    struct is_any {
        static bool test(char, const std::locale&);
    };

有若干内置的字符类. 字符类 is_any 匹配任何字符. 对任何字符 c, 字符类 is<c> 只匹配 c. 字符类 alnum、is_alpha、is_cntrl、is_digit、is_graph、is_lower、is_print、is_punct、is_space、is_upper、is_xdigit 实现区分 locale 的字符分类.

事件处理器是有限状态机的成员函数, 以单个字符为参数并返回 void. 事件处理器的实现通常检查给定的字符, 并将零个或多个过滤后的数据字符压入栈中. 一个特殊的事件处理器 on_eof 不接受参数, 并在序列中最后一个字符被处理之后自动调用.

有三个内置的事件处理器: on_any、push 与 skip. 当发生的事件未被转移表中的任何行覆盖时, 会自动调用处理器 on_any. on_any 的默认行为是什么也不做. 处理器 push 将给定字符压入栈中. 处理器 skip 忽略当前字符. 处理器 push 与 skip 默认未定义; 为使它们可用, 应在有限状态机的类定义内调用宏 BOOST_IOSTREAM_FSM, 并将状态机的名称作为宏参数传入.

有限状态机必须派生自类模板 boost::iostreams::finite_state_machine — 定义于头文件 <libs/iostreams/example/finite_state_filter.hpp>. finite_state_machine 的第一个模板参数应为派生类本身; 第二个模板参数应为字符类型.

有限状态机的转移表应声明为名为 transition_table 的成员类型. 其事件处理器应实现为成员函数. 有限状态机可以定义一个 static 整数常量, 名为 initial_state — 该常量将被视为机器的初始状态. 或者, 也可以省略初始状态的定义, 此时它默认为 0.

给定一个有限状态机 my_fsm, 你可以按如下方式定义一个 双用途过滤器:

namespace io = boost::iostreams;

typedef io::finite_state_filter<my_fsm> my_finite_state_filter;

dos2unix_fsm

以下状态机可用于将行尾从 DOS 转换为 UNIX. 常量 initial_state、类模板 row 以及字符类 is 与 is_any 都是基类 boost::iostreams::finite_state_machine 的成员.

#include <boost/mpl/vector>
#include <libs/iostreams/example/finite_state_filter.hpp>

namespace io = boost::iostreams;

struct dos2unix_fsm : io::finite_state_machine<dos2unix_fsm> {
    BOOST_IOSTREAMS_FSM(dos2unix_fsm) // Define skip and push.
    typedef dos2unix_fsm self;
    typedef boost::mpl::vector<
                row<initial_state, is<'\r'>, initial_state, &self::skip>,
                row<initial_state, is_any,   initial_state, &self::push>
            > transition_table;
};

该状态机只有一个状态. 其转移表可理解如下: 若当前字符为 '\r', 忽略它; 否则原样转发.

unix2dos_fsm

以下状态机可用于将行尾从 UNIX 转换为 DOS:

#include <boost/mpl/vector>
#include <libs/iostreams/example/finite_state_filter.hpp>

namespace io = boost::iostreams;

struct unix2dos_fsm : io::finite_state_machine<unix2dos_fsm> {
    BOOST_IOSTREAMS_FSM(unix2dos_fsm) // Define skip and push.
    typedef unix2dos_fsm self;

    void on_lf(char) { push('\r'); push('\n'); }

    typedef boost::mpl::vector<
                row<initial_state, is<'\n'>, initial_state, &self::on_lf>,
                row<initial_state, is_any,   initial_state, &self::push>
            > transition_table;
};

该状态机同样只有一个状态. 事件处理器 on_lf 将一个 DOS 行尾序列压入栈中. 其转移表可理解如下: 若当前字符为 '\n', 写入一个 DOS 行尾序列; 否则原样转发.

uncommenting_fsm

以下状态机移除 C 风格注释. 虽然它还不够精细, 不足以处理源代码, 但它是多状态机的一个很好示例.

#include <boost/mpl/vector>
#include <libs/iostreams/example/finite_state_filter.hpp>


namespace io = boost::iostreams;

struct uncommenting_fsm : io::finite_state_machine<uncommenting_fsm> {
    BOOST_IOSTREAMS_FSM(uncommenting_fsm) // Define skip and push.
    typedef uncommenting_fsm self;

    static const int no_comment   = initial_state;
    static const int pre_comment  = no_comment + 1;
    static const int comment      = pre_comment + 1;
    static const int post_comment = comment + 1;

    void push_slash(char c) { push('/'); push(c); }

    typedef boost::mpl::vector<
                row<no_comment,   is<'/'>, pre_comment,  &self::skip>,
                row<no_comment,   is_any,  no_comment,   &self::push>,
                row<pre_comment,  is<'*'>, comment,      &self::skip>,
                row<pre_comment,  is<'/'>, pre_comment,  &self::push>,
                row<pre_comment,  is_any,  no_comment,   &self::push_slash>,
                row<comment,      is<'*'>, post_comment, &self::skip>,
                row<comment,      is_any,  comment,      &self::skip>,
                row<post_comment, is<'/'>, no_comment,   &self::skip>,
                row<post_comment, is<'*'>, post_comment, &self::skip>,
                row<post_comment, is_any,  comment,      &self::skip>
            > transition_table;
};

该状态机有四个状态和一个用户自定义的事件处理器. 它如何工作, 留给读者作为练习.
