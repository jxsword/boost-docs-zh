2.2.9. 双用途过滤器

维护两个独立的过滤器 — 一个用于输入, 另一个用于输出 — 来实现相同的过滤算法, 可能令人困扰. 避免这一点的一种方法是使用上面提到的 过滤器辅助类. 过滤器辅助类生成的过滤器既可用于输入也可用于输出, 但不能同时用于两者. 这类过滤器称为 双用途过滤器.

一个 双用途过滤器 可以通过合并一个 InputFilter 和一个 OutputFilter 的实现, 并给所得的类一个 类别 — 可转换为 dual_use_filter_tag — 来生成. 例如, 你可以按如下方式将 shell 注释过滤器 实现为双用途过滤器:

#include <boost/iostreams/char_traits.hpp> // EOF, WOULD_BLOCK
#include <boost/iostreams/concepts.hpp>    // input_filter
#include <boost/iostreams/operations.hpp>  // get

namespace boost { namespace iostreams { namespace example {

class shell_comments_input_filter : public dual_use_filter {
public:
    explicit shell_comments_input_filter(char comment_char = '#')
        : comment_char_(comment_char), skip_(false)
        { }

    template<typename Source>
    int get(Source& src)
    {
        /* same as shell_comments_input_filter::get() */
    }

    template<typename Sink>
    bool put(Sink& dest, int c)
    {
        /* same as shell_comments_output_filter::put() */
    }

    template<typename Device>
    void close(Device&, std::ios_base::openmode)
    { 
        skip_ = false; 
    }
private:
    char comment_char_;
    bool skip_;
};

} } } // End namespace boost::iostreams:example

当包含 Closable 双用途过滤器 的 过滤流或流缓冲 被关闭时, 过滤器的成员函数 close 会被调用, 其第二个函数参数为 std::ios_base::in 或 std::ios_base::out 之一, 指示过滤器是用于输入还是输出.
