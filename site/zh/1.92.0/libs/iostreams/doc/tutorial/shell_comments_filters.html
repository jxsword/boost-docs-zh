2.2.3. Shell 注释过滤器

假设你想编写一个移除 shell 风格注释的过滤器. 基本算法如下: 你逐个检查字符并原样转发, 直到遇到注释字符 — 通常是 '#'. 找到注释字符后, 你检查并忽略字符, 直到遇到换行字符, 此时算法重新开始. 注意, 该算法由两个子算法组成: 一个用于读取普通文本, 一个用于读取注释.

在下面三节中, 我将把这一算法分别表述为一个 stdio_filter、一个 InputFilter 和一个 OutputFilter. 源代码可在头文件 <libs/iostreams/example/shell_comments_filter.hpp> 中找到. 这些示例的灵感来自 James Kanze 的 UncommentExtractor.hh (参见 [Kanze]).

shell_comments_stdio_filter

你可以将 shell 注释过滤器表述为一个 stdio_filter, 如下:

#include <cstdio>    // EOF
#include <iostream>  // cin, cout
#include <boost/iostreams/filter/stdio.hpp>

class shell_comments_stdio_filter : public stdio_filter {
public:
    explicit shell_comments_stdio_filter(char comment_char = '#')
        : comment_char_(comment_char) 
        { }
private:
    void do_filter()
    {
        bool  skip = false;
        int   c;
        while ((c = std::cin.get()) != EOF) {
            skip = c == comment_char_ ?
                true :
                c == '\n' ?
                    false :
                    skip;
            if (!skip)
                std::cout.put(c);
        }
    }
    char comment_char_;
};

} } } // End namespace boost::iostreams:example

virtual 函数 do_filter 的实现很直接: 局部变量 skip 记录你是否正在处理注释; while 循环读取一个字符 c — 来自 std::cin — 更新 skip 并将 c 写入 std::cout, 除非 skip 为 true.

派生自 stdio_filter 的过滤器是 DualUseFilters, 意味着它们既可用于输出也可用于输入, 但不能同时用于两者. 因此, 在下文中 unix2dos_stdio_filter 可用于替代 shell_comments_input_filter 与 shell_comments_output_filter.

shell_comments_input_filter

接下来, 你将把 shell 注释过滤器表述为一个 InputFilter. 典型的窄字符 InputFilter 如下所示:

#include <boost/iostreams/categories.hpp>  // input_filter_tag
#include <boost/iostreams/char_traits.hpp> // EOF, WOULD_BLOCK
#include <boost/iostreams/operations.hpp>  // get, read, putback

namespace io = boost::iostreams;

class my_input_filter {
public:
    typedef char              char_type;
    typedef input_filter_tag  category;

    template<typename Source>
    int get(Source& src)
    {
        // Attempt to produce one character of filtered
        // data, reading from src as necessary. If successful,
        // return the character; otherwise return EOF to
        // indicate end-of-stream, or WOULD_BLOCK
    }

    /* Other members */
};

函数 get 尝试产生单个过滤后的输出字符. 它通过提供的 源 src 访问未过滤的字符序列, 使用基本 I/O 操作 get、read 与 putback. 若产生了字符, get 返回它; 否则 get 返回状态码 EOF 或 WOULD_BLOCK 之一. EOF 表示流末尾, 是标准头文件 <cstdio> 中定义的宏. WOULD_BLOCK 表示输入暂时不可用, 是命名空间 boost::iostreams 中定义的常量, 见头文件 <boost/iostreams/char_traits.hpp>

你也可以将上面的示例写为如下形式:

#include <boost/iostreams/concepts.hpp>  // input_filter

class my_input_filter : public input_filter {
public:
    template<typename Source>
    int get(Source& src);

    /* Other members */
};

此处 input_filter 是一个便利基类, 它提供成员类型 char_type 与 category, 以及成员函数 close 与 imbue 的空操作实现. 我稍后会讨论 close.

现在你可以将 shell 注释过滤器表述为一个 InputFilter 了:

#include <boost/iostreams/char_traits.hpp> // EOF, WOULD_BLOCK
#include <boost/iostreams/concepts.hpp>    // input_filter
#include <boost/iostreams/operations.hpp>  // get

namespace boost { namespace iostreams { namespace example {

class shell_comments_input_filter : public input_filter {
public:
    explicit shell_comments_input_filter(char comment_char = '#')
        : comment_char_(comment_char), skip_(false)
        { }

    template<typename Source>
    int get(Source& src)
    {
        int c;
        while (true) {
            if ((c = boost::iostreams::get(src)) == EOF || c == WOULD_BLOCK)
                break;
            skip_ = c == comment_char_ ?
                true :
                c == '\n' ?
                    false :
                    skip_;
            if (!skip_)
                break;
        }
        return c;
    }

    template<typename Source>
    void close(Source&) { skip_ = false; }
private:
    char comment_char_;
    bool skip_;
};

} } } // End namespace boost::iostreams:example

此处成员变量 skip_ 扮演与局部变量 skip shell_comments_stdio_filter::do_filter 相同的角色. get 的实现与 shell_comments_stdio_filter::do_filter 的实现非常相似: while 循环读取一个字符 c, 更新 skip_ 并返回 c, 除非 skip_ 为 true. 主要区别在于你必须处理特殊值 WOULD_BLOCK — 它表示当前没有可用输入.

可见, 从零实现一个 InputFilter 比从 stdio_filter 派生要复杂一些. 编写 InputFilter 时, 你必须准备好在算法中途的任意一点被打断; 此时, 你必须记录关于算法当前状态的足够信息, 以便稍后能从上次中断之处精确继续. 对 OutputFilters 也是如此. 事实上, 许多 InputFilter 和 OutputFilter 都可视为有限状态机; 我稍后会将这一想法形式化. 参见 有限状态过滤器.

shell_comments_input_filter 仍有一个问题: 其实例只能使用一次. 这是因为有人可能在设置了 skip_ 标志的情况下关闭流. 如果之后重新打开该流 — 带有新的未过滤数据序列 — 文本的第一行将被过滤掉, 无论它是否被注释.

修复方法是让你的过滤器成为 Closable 的. 为此, 你必须实现成员函数 close. 你还必须给过滤器一个 类别标签 — 可转换为 closable_tag — 以告诉 Iostreams 库你的过滤器实现了 close.

改进后的过滤器如下所示:

namespace boost { namespace iostreams { namespace example {

class shell_comments_input_filter : public input_filter {
public:
    shell_comments_input_filter();

    template<typename Source>
    int get(Source& src);

    template<typename Source>
    void close(Source&) { skip_ = false; }
private:
    bool skip_;
};

} } } // End namespace boost::iostreams:example

此处我从辅助类 input_filter 派生, 它提供成员类型 char_type — 等于 char — 以及可转换为 input_filter_tag 与 closable_tag 的类别标签. close 的实现只是清除 skip_ 标志, 使过滤器可以再次使用.

shell_comments_output_filter

接下来, 我们把 shell 注释过滤器表述为一个 OutputFilter. 典型的窄字符 OutputFilter 如下所示:

#include <boost/iostreams/categories.hpp>  
#include <boost/iostreams/operations.hpp>  // put, write

namespace io = boost::iostreams;

class my_output_filter {
public:
    typedef char               char_type;
    typedef output_filter_tag  category;

    template<typename Sink>
    bool put(Sink& dest, int c)
    {
        // Attempt to consume the given character of unfiltered
        // data, writing filtered data to dest as appropriate. 
        // Return true if the character was successfully consumed.
    }

    /* Other members */
};

函数 put 尝试过滤单个字符 c, 将过滤后的输出写入 汇 dest. 它使用基本 I/O 操作访问 dest — 即 put 与 write. 这两个函数都可能失败: iostreams::put 可以返回 false, 而 iostreams::write 消费的字符可能少于请求的数量. 若发生这种情况, 允许成员函数 put 返回 false, 表示 c 未能被消费. 否则, 它必须消费 c 并返回 true.

你也可以将上面的示例写为如下形式:

#include <boost/iostreams/concepts.hpp>  // output_filter

class my_output_filter : public output_filter {
public:
    template<typename Sink>
    bool put(Sink& dest, int c);

    /* Other members */
};

此处 output_filter 是一个便利基类, 它提供成员类型 char_type 与 category, 以及成员函数 close 与 imbue 的空操作实现.

现在你可以将 shell 注释过滤器表述为一个 OutputFilter 了:

#include <boost/iostreams/concepts.hpp>    // output_filter
#include <boost/iostreams/operations.hpp>  // put

namespace boost { namespace iostreams { namespace example {

class shell_comments_output_filter : public output_filter {
public:
    explicit shell_comments_output_filter(char comment_char = '#')
        : comment_char_(comment_char), skip_(false)
        { }

    template<typename Sink>
    bool put(Sink& dest, int c)
    {
        skip_ = c == comment_char_ ?
            true :
            c == '\n' ?
                false :
                skip_;

        if (skip_)
            return true;

        return iostreams::put(dest, c);
    }

    template<typename Source>
    void close(Source&) { skip_ = false; }
private:
    char comment_char_;
    bool skip_;
};

} } } // End namespace boost::iostreams:example

成员函数 put 先检查给定字符 c 并更新成员变量 skip_; 接着, 除非 skip_ 为 true, 否则它尝试写入 c. 成员函数 close 只是清除 skip_ 标志, 使过滤器可以再次使用.
