2.2.6. 词典过滤器

词典过滤器 是一种按如下方式执行文本替换的过滤器. 它维护一个字符串对的集合: 对的第一分量是单词, 第二分量表示替换文本 — 我将这样的集合称为 词典, 并将其中的对称为 定义. 当词典过滤器遇到一个作为某定义第一分量出现的单词时, 它转发替换文本而非原单词. 其他单词、空白和标点则原样转发.

基本算法如下: 你逐个检查字符, 将它们追加到一个字符串 — 我称之为 当前单词. 当你遇到非字母字符时, 查询词典以确定当前单词是否作为某定义的第一分量出现. 若是, 则转发替换文本, 后跟该非字母字符; 否则, 转发当前单词, 后跟该非字母字符. 到达流末尾时, 再次查询词典, 并视情况转发当前单词或其替换文本.

在下面几节中, 我将把这一算法分别表述为一个 stdio_filter、一个 InputFilter 和一个 OutputFilter. 源代码可在头文件 <libs/iostreams/example/dictionary_filter.hpp> 中找到.

dictionary

你可以用下面的类来表示词典:

#include <map>
#include <string>

namespace boost { namespace iostreams { namespace example {

class dictionary {
public:
    void add(std::string key, const std::string& value);
    void replace(std::string& key);

    /* ... */
};

} } } // End namespace boost::iostreams:example

成员函数 add 将 key 转换为小写, 并将 key、value 这一对添加到词典. 成员函数 replace 搜索第一分量等于将 key 转换为小写之结果的定义. 若找到这样的定义, 则将替换文本赋给 key, 并调整第一个字符的大小写以匹配 key 第一个字符的大小写. 否则, 它什么也不做.

dictionary_stdio_filter

你可以将词典过滤器表述为一个 stdio_filter, 如下:

#include <cstdio>    // EOF
#include <iostream>  // cin, cout
#include <boost/iostreams/filter/stdio.hpp>

namespace boost { namespace iostreams { namespace example {

class dictionary_stdio_filter : public stdio_filter {
public:
    dictionary_stdio_filter(dictionary& d) : dictionary_(d) { }
private:
    void do_filter()
    {
        using namespace std;
        while (true) {
            int c = std::cin.get();
            if (c == EOF || !std::isalpha((unsigned char) c)) {
                dictionary_.replace(current_word_);
                cout.write( current_word_.data(),
                            static_cast<streamsize>(current_word_.size()) );
                current_word_.erase();
                if (c == EOF)
                    break;
                cout.put(c);
            } else {
                current_word_ += c;
            }
        }
    }
    dictionary&  dictionary_;
    std::string  current_word_;
};

} } } // End namespace boost::iostreams:example

do_filter 的实现只是循环, 从 std::cin 读取字符并将它们 appending 到成员变量 current_word_, 直到遇到非字母字符或流末尾指示. 此时, 它使用其词典 — 存储在成员变量 dictionary_ 中 — 在必要时替换当前单词. 最后, 它将当前单词 (后跟非字母字符, 若有) 写入 std::cout.

dictionary_input_filter

你可以将词典过滤器表述为一个 InputFilter, 如下:

#include <boost/iostreams/char_traits.hpp> // EOF, WOULD_BLOCK
#include <boost/iostreams/concepts.hpp>    // input_filter
#include <boost/iostreams/operations.hpp>  // get

namespace boost { namespace iostreams { namespace example {

class dictionary_input_filter : public input_filter {
public:
    dictionary_input_filter(dictionary& d)
        : dictionary_(d), off_(std::string::npos), eof_(false)
        { }

    template<typename Source>
    int get(Source& src);

    template<typename Source>
    void close(Source&);
private:
    dictionary&             dictionary_;
    std::string             current_word_;
    std::string::size_type  off_;
    bool                    eof_;
};

} } } // End namespace boost::iostreams:example

函数 get 的实现如下:

    template<typename Source>
    int get(Source& src)
    {
        // Handle unfinished business.
        if (off_ != std::string::npos && off_ < current_word_.size())
            return current_word_[off_++];
        if (off_ == current_word_.size()) {
            current_word_.erase();
            off_ = std::string::npos;
        }
        if (eof_)
            return EOF;

        // Compute curent word.
        while (true) {
            int c;
            if ((c = iostreams::get(src)) == WOULD_BLOCK)
                return WOULD_BLOCK;

            if (c == EOF || !std::isalpha((unsigned char) c)) {
                dictionary_.replace(current_word_);
                off_ = 0;
                if (c == EOF)
                    eof_ = true;
                else
                    current_word_ += c;
                break;
            } else {
                current_word_ += c;
            }
        }

        return this->get(src); // Note: current_word_ is not empty.
    }

你首先检查是否有上次调用 get 遗留下来的字符. 若有, 则更新一些簿记信息并返回其中第一个字符.

while 循环与 dictionary_stdio_filter::do_filter 的循环非常相似: 它从 源 src 读取字符, 将它们追加到 current_word_, 直到遇到非字母字符、EOF 或 WOULD_BLOCK. 值 WOULD_BLOCK 会传给调用者. 在其余情形中, 会查询词典以确定适当的替换文本.

最后, 递归调用 get 以返回当前单词的第一个字符.

照例, 函数 close 重置过滤器的状态:

    template<typename Source>
    void close(Source&)
    {
        current_word_.erase();
        off_ = std::string::npos;
        eof_ = false;
    }

dictionary_output_filter

你可以将词典过滤器表述为一个 OutputFilter, 如下:

#include <algorithm>                      // swap
#include <boost/iostreams/concepts.hpp>   // output_filter
#include <boost/iostreams/operations.hpp> // write

namespace boost { namespace iostreams { namespace example {

class dictionary_output_filter : public output_filter {
public:
    typedef std::map<std::string, std::string> map_type;
    dictionary_output_filter(dictionary& d)
        : dictionary_(d), off_(std::string::npos)
        { }

    template<typename Sink>
    bool put(Sink& dest, int c);

    template<typename Sink>
    void close(Sink& dest);
private:
    template<typename Sink>
    bool write_current_word(Sink& dest);
    dictionary&             dictionary_;
    std::string             current_word_;
    std::string::size_type  off_;
};

} } } // End namespace boost::iostreams:example

我们先看辅助函数 write_current_word:

    template<typename Sink>
    bool write_current_word(Sink& dest)
    {
        using namespace std;
        streamsize amt = static_cast<streamsize>(current_word_.size() - off_);
        streamsize result =
            iostreams::write(dest, current_word_.data() + off_, amt);
        if (result == amt) {
            current_word_.erase();
            off_ = string::npos;
            return true;
        } else {
            off_ += static_cast<string::size_type>(result);
            return false;
        }
    }

此函数尝试将 current_word_ 从偏移量 off_ 开始写入提供的 汇. 若整个序列写入成功, 则清空 current_word_ 且函数返回 true. 否则, 成员变量 off_ 被更新为指向第一个未写入的字符, 且函数失败.

使用 write_current_word, 你可以按如下方式实现 put:

    template<typename Sink>
    bool put(Sink& dest, int c)
    {
        if (off_ != std::string::npos && !write_current_word(dest))
            return false;
        if (!std::isalpha((unsigned char) c)) {
            dictionary_.replace(current_word_);
            off_ = 0;
        }

        current_word_ += c;
        return true;
    }

与 dictionary_input_filter::get 的实现一样, 你首先检查是否有上次调用 put 遗留下来尚待写入的字符. 若有, 则尝试使用 write_current_word 写入这些字符. 若成功, 接着检查给定字符 c. 若它是非字母字符, 则查询词典以确定适当的替换文本. 无论如何, 你都将 c 追加到 current_word_ 并返回 true.

在此情形下, 函数 close 要做的工作不只是重置过滤器的状态. 除非未过滤序列的最后一个字符恰好是非字母字符, 否则 current_word_ 的内容尚未被写入:

    template<typename Sink>
    void close(Sink& dest)
    {
        // Reset current_word_ and off_, saving old values.
        std::string             current_word;
        std::string::size_type  off = 0;
        current_word.swap(current_word_);
        std::swap(off, off_);

        // Write remaining characters to dest.
        if (off == std::string::npos) {
            dictionary_.replace(current_word);
            off = 0;
        }
        if (!current_word.empty())
            iostreams::write( 
                dest,
                current_word.data() + off, 
                static_cast<std::streamsize>(current_word.size() - off) 
            );
    }

注意, 你可以假定模板参数是 Blocking 的 汇, 并且你必须重置 current_word_ 与 off_ 的值 — 在调用 write 之前 — 以防 write 抛出异常.
