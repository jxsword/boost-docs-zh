2.2.7. UNIX 到 DOS 过滤器

假设你想编写一个将 UNIX 行尾转换为 DOS 行尾的过滤器. 基本思想很简单: 你逐个处理序列中的字符, 每当遇到字符 '\n' 就用两字符序列 '\r'、'\n' 替换它. 在下面几节中, 我将把这一算法实现为一个 stdio_filter、一个 InputFilter 和一个 OutputFilter. 源代码可在头文件 <libs/iostreams/example/unix2dos_filter.hpp>

unix2dos_stdio_filter

你可以将 UNIX 到 DOS 过滤器表述为一个 stdio_filter — 通过从 stdio_filter 派生并覆写 private virtual 函数 do_filter, 如下:

#include <cstdio>    // EOF
#include <iostream>  // cin, cout
#include <boost/iostreams/filter/stdio.hpp>

namespace boost { namespace iostreams { namespace example {

class unix2dos_stdio_filter : public stdio_filter {
private:
    void do_filter()
    {
        int c;
        while ((c = std::cin.get()) != EOF) {
            if (c == '\n')
                std::cout.put('\r');
            std::cout.put(c);
        }
    }
};

} } } // End namespace boost::iostreams:example

函数 do_filter 是对我上述算法的直接实现: 它从标准输入读取字符并原样写入标准输出, 唯一例外是遇到 '\n' 时写入 '\r'、'\n'.

unix2dos_input_filter

现在, 我们把 UNIX 到 DOS 过滤器表述为一个 InputFilter. 

#include <boost/iostreams/categories.hpp> // input_filter_tag
#include <boost/iostreams/operations.hpp> // get

namespace boost { namespace iostreams { namespace example {

class unix2dos_input_filter {
public:
    typedef char              char_type;
    typedef input_filter_tag  category;

    unix2dos_input_filter() : has_linefeed_(false) { }

    template<typename Source>
    int get(Source& src)
    {
        // Handle unfinished business
        if (has_linefeed_) {
            has_linefeed_ = false;
            return '\n';
        }

        // Forward all characters except '\n'
        int c;
        if ((c = iostreams::get(src)) == '\n') {
            has_linefeed_ = true;
            return '\r';
        }

        return c;
    }

    template<typename Source>
    void close(Source&);
private:
    bool has_linefeed_;
};

} } } // End namespace boost::iostreams:example

get 的实现可描述如下. 大多数时候, 你只需从 src 读取一个字符并返回它. 特殊值 EOF 与 WOULD_BLOCK 以相同方式处理: 它们只是被原样转发. 例外情况是 iostreams::get 返回 '\n' 时. 此时, 你改为返回 '\r', 并记下要返回 '\n' — 在下次调用 get 时.

照例, 成员函数 close 重置过滤器的状态:

    template<typename Source>
    void close(Source&) { skip_ = false; }

unix2dos_output_filter

你可以将 UNIX 到 DOS 过滤器表述为一个 OutputFilter, 如下:

#include <boost/iostreams/concepts.hpp>   // output_filter
#include <boost/iostreams/operations.hpp> // put

namespace boost { namespace iostreams { namespace example {

class unix2dos_output_filter : public output_filter {
public:
    unix2dos_output_filter() : has_linefeed_(false) { }

    template<typename Sink>
    bool put(Sink& dest, int c);

    template<typename Sink>
    void close(Sink&) { has_linefeed_ = false; }
private:
    template<typename Sink>
    bool put_char(Sink& dest, int c);

    bool has_linefeed_;
};

} } } // End namespace boost::iostreams:example

此处我从辅助类 output_filter 派生, 它提供成员类型 char_type — 等于 char — 以及可转换为 output_filter_tag 与 closable_tag 的类别标签.

我们先看辅助函数 put_char:

    template<typename Sink>
    bool put_char(Sink& dest, int c)
    {
        bool result;
        if ((result = iostreams::put(dest, c)) == true) {
            has_linefeed_ =
                c == '\r' ?
                    true : 
                    c == '\n' ? 
                        false :
                        has_linefeed_;
        }
        return result;
    }

此函数尝试向汇 dest 写入单个字符, 成功时返回 true. 若成功, 它更新标志 has_linefeed_ — 该标志指示写入 DOS 行尾序列的尝试在第一个字符写入之后失败了.

使用 put_char, 你可以按如下方式实现 put:

    bool put(Sink& dest, int c)
    {
        if (c == '\n') 
            return has_linefeed_ ?
                put_char(dest, '\n') :
                put_char(dest, '\r') ?
                    this->put(dest, '\n') :
                    false;
        return iostreams::put(dest, c);
    }

该实现的工作方式如下:

  1. 如果你处于 DOS 行尾序列的开头 — 即 c 为 'n' 且 has_line_feed_ 为 false — 则尝试写入 '\r' 然后 '\n' 到 dest.
  2. 如果你处于 DOS 行尾序列的中间 — 即 c 为 'n' 且 has_line_feed_ 为 true — 则尝试通过写入 '\n' 来完成它.
  3. 否则, 你尝试将 c 写入 dest.

有两个微妙之处. 其一, 为什么 c == 'n' 与 has_line_feed_ == true 意味着你处于 DOS 行尾序列的中间? 因为当你尝试写入 '\r'、'\n' 但只有第一个字符成功时, 你设置 has_line_feed_ 并返回 false. 这会使过滤器的用户重发触发行尾序列的字符 '\n'. 其二, 注意写入行尾序列的第二个字符时, 你递归调用 put 而不是调用 put_char.

比较 unix2dos_input_filter 与 unix2dos_output_filter 的实现, 你可以看出: 这是一个过滤算法作为 Input 表述比作为 OutputFilter 容易得多的例子. 如果想避免上述定义的复杂性, 你可以使用类模板 inverse 从 unix2dos_input_filter 构造一个 OutputFilter:

#include <boost/iostreams/invert.hpp>   // inverse   

namespace io = boost::iostreams;
namespace ex = boost::iostreams::example;

typedef io::inverse<ex::unix2dos_input_filter> unix2dos_output_filter;

不过, 即便如此仍比必要的做法费事, 因为行尾转换可以用内置组件 newline_filter 轻松处理.
