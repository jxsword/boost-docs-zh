2.1.3. 编写 container_sink

假设你想编写一个向 STL 容器追加字符的设备. 只支持写入的设备称为 汇. 典型的窄字符汇如下所示: 

#include <iosfwd>                          // streamsize
#include <boost/iostreams/categories.hpp>  // sink_tag

namespace io = boost::iostreams;

class my_sink {
public:
    typedef char      char_type;
    typedef sink_tag  category;

    std::streamsize write(const char* s, std::streamsize n)
    {
        // Write up to n characters to the underlying 
        // data sink into the buffer s, returning the 
        // number of characters written
    }

    /* Other members */
};

此处成员类型 char_type 指示 my_source 所处理字符的类型, 几乎总是 char 或 wchar_t. 成员类型 category 指示设备支持哪些基本 I/O 操作. 类别标签 sink_tag 表示仅支持 write.

成员函数 write 将至多 n 个字符写入缓冲区 s 并返回写入的字符数. 一般而言, write 返回的字符可能少于请求的数量, 此时该汇被称为 非阻塞. 不过, 非阻塞设备与标准流和流缓冲的交互不佳, 因此大多数设备应是 Blocking 的. 参见 异步与非阻塞 I/O.

你也可以将上面的示例写为如下形式:

#include <boost/iostreams/concepts.hpp>  // sink

class my_sink : public sink {
public:
    std::streamsize write(const char* s, std::streamsize n);

    /* Other members */
};

此处 sink 是一个便利基类, 它提供成员类型 char_type 与 category, 以及成员函数 close 与 imbue 的空操作实现 — 此处并不需要.

现在你可以开始编写你的 container_sink 了.

#include <algorithm>                       // copy, min
#include <iosfwd>                          // streamsize
#include <boost/iostreams/categories.hpp>  // sink_tag

namespace boost { namespace iostreams { namespace example {

template<typename Container>
class container_sink {
public:
    typedef typename Container::value_type  char_type;
    typedef sink_tag                        category;
    container_sink(Container& container) : container_(container) { }
    std::streamsize write(const char_type* s, std::streamsize n)
    {
        container_.insert(container_.end(), s, s + n);
        return n;
    }
    Container& container() { return container_; }
private:
    Container& container_;
};

} } } // End namespace boost::iostreams:example

此处注意

  • 成员类型 char_type 被定义为等于容器的 value_type;
  • 成员类型 category 告诉 Iostreams 库: container_sink 是 Sink 的模型;
  • container_sink 可以由 Container 的实例构造 — 该实例以引用方式传入并存储, 可经由成员函数 container() 访问; 且
  • write() 的实现只是使用容器的 insert 函数, 将指定缓冲区中的字符追加到底层容器,

可以如下向 container_sink 写入

#include <cassert>
#include <string>
#include <boost/iostreams/stream.hpp>
#include <libs/iostreams/example/container_device.hpp> // container_sink

namespace io = boost::iostreams;
namespace ex = boost::iostreams::example;

int main()
{
    using namespace std;
    typedef ex::container_sink<string> string_sink;

    string                   result;
    io::stream<string_sink>  out(result);
    out << "Hello World!";
    out.flush();
    assert(result == "Hello World!");
}

注意, Iostreams 库默认提供缓冲. 因此, 必须先刷新流 out, 才能保证写入的字符已反映到底层 string 中.

最后, 我应指出 Iostreams 库提供了更简便的向 STL 兼容容器追加数据的方式. 其一, OutputIterator 可以直接添加到 过滤流与流缓冲. 因此可以写:

#include <cassert>
#include <iterator>  // back_inserter
#include <string>
#include <boost/iostreams/filtering_stream.hpp>

namespace io = boost::iostreams;

int main()
{
    using namespace std;

    string                 result;
    io::filtering_ostream  out(back_inserter(result));
    out << "Hello World!";
    out.flush();
    assert(result == "Hello World!");
}

其二, Iostreams 库提供了 back_inserter 的一个版本, 它比 std::back_inserter 略微高效, 因为其返回的汇使用 insert 而非 push_back. 因此可以写:

#include <cassert>
#include <string>
#include <boost/iostreams/device/back_inserter.hpp>
#include <boost/iostreams/filtering_stream.hpp>

namespace io = boost::iostreams;

int main()
{
    using namespace std;

    string                 result;
    io::filtering_ostream  out(io::back_inserter(result));
    out << "Hello World!";
    out.flush();
    assert(result == "Hello World!");
}
