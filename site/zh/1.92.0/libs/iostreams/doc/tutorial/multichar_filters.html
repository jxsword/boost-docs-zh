2.2.8. 多字符过滤器

到目前为止你见过的所有过滤器 — 除派生自 stdio_filter 的那些之外 — 都是一次处理一个字符. 如果你改为一次处理多个字符, 往往可以减少过滤字符序列所需的函数调用次数, 得到更高效的代码. 这正是 多字符过滤器 让你做到的.

多字符 InputFilter

典型的窄字符 多字符 InputFilter 如下所示:

#include <iosfwd>                          // streamsize
#include <boost/iostreams/categories.hpp>  // tags

class my_input_filter {
public:
    typedef char char_type;
    struct category 
        : input_filter_tag,
          multichar_tag
        { };

    template<typename Source>
    std::streamsize read(Source& src, char* s, std::streamsize n)
    {
        // Read up to n filtered characters into the buffer s,
        // returning the number of characters read or -1 for EOF.
        // Use src to access the unfiltered character sequence
    }

    /* Other members */
};

注意, 成员类型 category 是一个 struct, 可转换为 input_filter_tag 与 multichar_tag. 这告诉 Iostreams 库: my_input_filter 是 多字符过滤器 和 InputFilter. 你本可以通过几种方式达到同样效果. 例如,

    struct category 
        : input,
          filter_tag,
          multichar_tag
        { };

        /* or */

    typedef multichar_input_filter_tag category;

(详情参见 模式标签 与 类别标签.)

你也可以将上面的示例写为如下形式:

#include <iosfwd>                       // streamsize
#include <boost/iostreams/concepts.hpp> // multichar_input_filter

class my_input_filter : public multichar_input_filter {
public:
    template<typename Source>
    std::streamsize read(char* s, std::streamsize n);

    /* Other members */
};

此处 multichar_input_filter 是一个便利基类, 它提供成员类型 char_type 与 category, 以及成员函数 close 与 imbue 的空操作实现.

shell_comments_multichar_input_filter

你可以将 shell 注释过滤器 表述为一个 多字符 InputFilter, 如下:

#include <boost/iostreams/char_traits.hpp> // EOF, WOULD_BLOCK
#include <boost/iostreams/concepts.hpp>    // multichar_input_filter
#include <boost/iostreams/operations.hpp>  // get

namespace boost { namespace iostreams { namespace example {

class shell_comments_multichar_input_filter : public multichar_input_filter {
public:
    explicit shell_comments_multichar_input_filter(char comment_char = '#')
        : comment_char_(comment_char), skip_(false)
        { }

    template<typename Source>
    std::streamsize read(Source& src, char* s, std::streamsize n)
    {
        for (std::streamsize z = 0; z < n; ++z) {
            int c;
            while (true) {
                if ((c = boost::iostreams::get(src)) == EOF)
                    return z != 0 ? z : -1;
                else if (c == WOULD_BLOCK)
                    return z;
                skip_ = c == comment_char_ ?
                    true :
                    c == '\n' ?
                        false :
                        skip_;
                if (!skip_)
                    break;
            }
            s[z] = c;
        }
        return n;
    }

    template<typename Source>
    void close(Source&) { skip_ = false; }
private:
    char comment_char_;
    bool skip_;
};

} } } // End namespace boost::iostreams:example

注意, read 的实现与你把 shell_comments_input_filter::get 的实现放进 for 循环 (从 0 迭代到 n) 所得的结果非常相似. 递归调用自身的 InputFilter — 例如 tab_expanding_input_filter — 则很难改造成多字符过滤器.

多字符 OutputFilter

典型的窄字符 多字符 OutputFilter 如下所示:

#include <iosfwd>                          // streamsize
#include <boost/iostreams/categories.hpp>  // tags

class my_output_filter {
public:
    typedef char char_type;
    struct category 
        : output_filter_tag,
          multichar_tag
        { };

    template<typename Sink>
    std::streamsize write(Sink& dest, const char* s, std::streamsize n)
    {
        // Consume up to n filtered characters from the buffer s,
        // writing filtered characters to dest. Return the number
        // of characters consumed.
    }

    /* Other members */
};

注意, 成员类型 category 是一个 struct, 可转换为 keyword 与 multichar_tag. 这告诉 Iostreams 库: my_output_filter 是 多字符过滤器 和 OutputFilter. 与 多字符 InputFilter 一样, 你本可以通过几种不同方式达到同样效果. 例如,

    struct category 
        : output,
          filter_tag,
          multichar_tag
        { };

        /* or */

    typedef multichar_output_filter_tag category;

(详情参见 模式标签 与 类别标签.)

你也可以将上面的示例写为如下形式:

#include <iosfwd>                       // streamsize
#include <boost/iostreams/concepts.hpp> // multichar_output_filter

class my_output_filter : public multichar_output_filter {
public:
    template<typename Sink>
    std::streamsize write(Sink& dest, const char* s, std::streamsize n);

    /* Other members */
};

此处 multichar_output_filter 是一个便利基类, 它提供成员类型 char_type 与 category, 以及成员函数 close 与 imbue 的空操作实现.

shell_comments_multichar_output_filter

你可以将 shell 注释过滤器 表述为一个 多字符 OutputFilter, 如下:

#include <boost/iostreams/char_traits.hpp> // EOF, WOULD_BLOCK
#include <boost/iostreams/concepts.hpp>    // multichar_output_filter
#include <boost/iostreams/operations.hpp>  // get

namespace boost { namespace iostreams { namespace example {

class shell_comments_multichar_output_filter : public multichar_output_filter {
public:
    explicit shell_comments_multichar_output_filter(char comment_char = '#')
        : comment_char_(comment_char), skip_(false)
        { }

    template<typename Sink>
    std::streamsize write(Sink& dest, const char* s, std::streamsize n)
    {
        std::streamsize z;
        for (z = 0; z < n; ++z) {
            int c = s[z];
            skip_ = c == comment_char_ ?
                true :
                c == '\n' ?
                    false :
                    skip_;
            if (skip_)
                continue;
            if (!iostreams::put(dest, c))
                break;
        }
        return z;
    }

    template<typename Source>
    void close(Source&) { skip_ = false; }
private:
    char comment_char_;
    bool skip_;
};

} } } // End namespace boost::iostreams:example

注意, write 的实现与你把 shell_comments_output_filter::put 的实现放进 for 循环 (从 0 迭代到 n) 所得的结果非常相似. 递归调用自身的 OutputFilter — 例如 unix2dos_output_filter — 则很难改造成多字符过滤器.
