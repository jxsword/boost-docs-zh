2.2.5. 制表符展开过滤器

假设你想编写一个将每个制表符替换为一个或多个空格字符的过滤器, 使文档在显示时看起来不变. 基本算法如下: 你逐个检查字符, 将它们原样转发, 同时记录当前列号. 当你遇到制表符时, 用一串空格字符替换它, 其长度取决于当前列计数. 当你遇到换行字符时, 转发它并重置列计数.

在下面三节中, 我将把这一算法分别表述为一个 stdio_filter、一个 InputFilter 和一个 OutputFilter. 源代码可在头文件 <libs/iostreams/example/tab_expanding_filter.hpp> 中找到. 这些示例的灵感来自 James Kanze 的 ExpandTabsInserter.hh (参见 [Kanze]).

tab_expanding_stdio_filter

你可以将制表符展开过滤器表述为一个 stdio_filter, 如下:

#include <cstdio>    // EOF
#include <iostream>  // cin, cout
#include <boost/iostreams/filter/stdio.hpp>

class tab_expanding_stdio_filter : public stdio_filter {
public:
    explicit tab_expanding_stdio_filter(int tab_size = 8)
        : tab_size_(tab_size), col_no_(0)
    {
        assert(tab_size > 0);
    }
private:
    void do_filter();
    void do_close();
    void put_char(int c);
    int  tab_size_;
    int  col_no_;
};

} } } // End namespace boost::iostreams:example

辅助函数 put_char 与 line_wrapping_stdio_filter::put_char 相同. 它将一个字符写入 std::cout 并更新列计数:

    void put_char(int c)
    {
        std::cout.put(c);
        if (c == '\n') {
            col_no_ = 0;
        } else {
            ++col_no_;
        }
    }

使用 put_char, 你可以按如下方式实现 do_filter:

    void do_filter()
    {
        int c;
        while ((c = std::cin.get()) != EOF) {
            if (c == '\t') {
                int spaces = tab_size_ - (col_no_ % tab_size_);
                for (; spaces > 0; --spaces)
                    put_char(' ');
            } else {
                put_char(c);
            }
        }
    }

while 循环从 std::cin 读取一个字符并写入 std::cout — 除非它是制表符, 此时它向 std::cout 写入适当数量的空格字符.

与 line_wrapping_stdio_filter 一样, virtual 函数 do_close 重置过滤器的状态:

    void do_close() { col_no_ = 0; }

tab_expanding_input_filter

你可以将制表符展开过滤器表述为一个 InputFilter, 如下:

#include <boost/iostreams/char_traits.hpp> // EOF, WOULD_BLOCK
#include <boost/iostreams/concepts.hpp>    // input_filter
#include <boost/iostreams/operations.hpp>  // get

namespace boost { namespace iostreams { namespace example {

class tab_expanding_input_filter : public input_filter {
public:
    explicit tab_expanding_input_filter(int tab_size = 8)
        : tab_size_(tab_size), col_no_(0), spaces_(0)
    { 
        assert(tab_size > 0); 
    }

    template<typename Source>
    int get(Source& src);

    template<typename Source>
    void close(Source&);
private:
    int get_char(int c);
    int   tab_size_;
    int   col_no_;
    int   spaces_;
};

} } } // End namespace boost::iostreams:example

我们先看辅助函数 get_char:

    int get_char(int c)
    {
        if (c == '\n') {
            col_no_ = 0;
        } else {
            ++col_no_;
        }
        return c;
    }

此函数根据给定字符 c 更新列计数并返回 c. 使用 get_char, 你可以按如下方式实现 get:

    template<typename Source>
    int get(Source& src)
    {
        if (spaces_ > 0) {
            --spaces_;
            return get_char(' ');
        }

        int c;
        if ((c = iostreams::get(src)) == EOF || c == WOULD_BLOCK)
            return c;

        if (c != '\t')
            return get_char(c);

        // Found a tab. Call this filter recursively.
        spaces_ = tab_size_ - (col_no_ % tab_size_);
        return this->get(src);
    }

该实现与 line_wrapping_input_filter::get 的实现类似. 由于 get 一次只能返回单个字符, 每当必须用一串空格字符替换制表符时, 只能返回第一个空格字符. 其余必须由后续的 get 调用返回. 成员变量 spaces_ 用于存储此类空格字符的数量.

该实现首先检查是否还有待返回的空格字符. 若有, 则递减 spaces_ 并返回一个空格. 否则, 从 src 读取一个字符. 普通字符以及特殊值 EOF 与 WOULD_BLOCK 被原样返回. 遇到制表符时, 记录后续 get 调用必须返回的空格数, 并返回一个空格字符.

照例, 函数 close 重置过滤器的状态:

    void close(Source&)
    {
        col_no_ = 0;
        spaces_ = 0;
    }

tab_expanding_output_filter

你可以将制表符展开过滤器表述为一个 OutputFilter, 如下:

#include <boost/iostreams/concepts.hpp>    // output_filter
#include <boost/iostreams/operations.hpp>  // put

namespace boost { namespace iostreams { namespace example {

class tab_expanding_output_filter : public output_filter {
public:
    explicit tab_expanding_output_filter(int tab_size = 8)
        : tab_size_(tab_size), col_no_(0), spaces_(0)
    { 
        assert(tab_size > 0); 
    }

    template<typename Sink>
    bool put(Sink& dest, int c);

    template<typename Sink>
    void close(Sink&);
private:
    template<typename Sink>
    bool put_char(Sink& dest, int c);
    int  tab_size_;
    int  col_no_;
    int  spaces_;
};

} } } // End namespace boost::iostreams:example

实现辅助函数 put_char 与 line_wrapping_output_filter::put_char 的相同: 它将给定字符写入 std::cout 并递增列号 — 除非该字符是换行符, 此时列号被重置.

    template<typename Sink>
    bool put_char(Sink& dest, int c)
    {
        if (!iostreams::put(dest, c))
            return false;
        if (c != '\n')
            ++col_no_;
        else
            col_no_ = 0;
        return true;
    }

使用 put_char, 你可以按如下方式实现 put:

    template<typename Sink>
    bool put(Sink& dest, int c)
    {
        for (; spaces_ > 0; --spaces_)
            if (!put_char(dest, ' '))
                return false;

        if (c == '\t') {
            spaces_ = tab_size_ - (col_no_ % tab_size_) - 1;
            return this->put(dest, ' ');
        } 

        return put_char(dest, c);
    }

该实现首先尝试写入之前遇到的制表符遗留的空格字符. 若成功, 则检查给定字符 c. 若 c 不是制表符, 则尝试将其写入 dest. 否则, 计算必须插入的空格数并递归调用自身. 这里使用递归使我们不必在代码中两个不同位置递减成员变量 spaces_.

注意, 遇到制表符之后, get 会返回 false, 直到所有关联的空格字符都已写入.

照例, 函数 close 重置过滤器的状态:

    void close(Source&)
    {
        col_no_ = 0;
        spaces_ = 0;
    }
