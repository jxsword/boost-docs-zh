2.1.1. 概述: 设备、stream_buffer 与 stream

使用 Boost Iostreams 库编写新的流或流缓冲类很容易: 你只需编写一个满足 设备 概念的类, 然后将该类用作 stream 或 stream_buffer 的模板参数: 

#include <boost/iostreams/stream.hpp>
#include <boost/iostreams/stream_buffer.hpp>

namespace io = boost::iostreams;

class my_device { /* */ };

typedef io::stream<my_device>         my_stream;
typedef io::stream_buffer<my_device>  my_streambuf;

此处 io::stream_buffer<my_device> 是 std::basic_streambuf 的派生类, 而 io::stream<my_device> 是 std::basic_istream、std::basic_ostream 或 std::basic_iostream 的派生类 — 取决于 my_device 的 模式, 即取决于它支持哪些基本 I/O 操作 read、write 与 seek.

提供模板 io::stream 是为了方便. 始终可以避开 io::stream, 直接将 io::stream_buffer 与标准库的某个流模板一起使用. 例如, 

#include <ostream>
#include <boost/iostreams/device/file.hpp>
#include <boost/iostreams/stream.hpp>

namespace io = boost::iostreams;

int main()
{
    io::stream_buffer<io::file_sink> buf("log.txt");
    std::ostream                     out(&buf);
    // out writes to log.txt
}

在此例中, ostream out 使用 stream_buffer buf 作为其底层数据汇, 因此写入 out 的数据进入文件 log.txt. 同样的效果也可以这样实现: 默认构造 out, 并告诉它使用流缓冲 buf — 通过调用 out.rdbuf(&buf).

使用 Boost Iostreams 库定义新流或流缓冲类的另一种方式是从 filtering_stream 或 filtering_streambuf 派生.
