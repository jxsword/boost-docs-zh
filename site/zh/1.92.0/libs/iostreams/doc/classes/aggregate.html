说明

类模板 aggregate_filter 是一个 DualUseFilter, 供一次性过滤整个字符序列的过滤器用作基类. 由于 aggregate_filter 在开始过滤之前必须将整个字符序列读入内存, 因此它不适合内存受限的场合, 也不适合处理没有自然终点的字符序列, 例如股票行情. 鉴于这些局限, aggregate_filter 最适合用作学习 Iostreams 库时的辅助工具.

用作 InputFilter 时, aggregate_filter 的实例一旦开始接收输入就会一直读到流的末尾. 流的全部内容通过 private virtual 的函数 do_filter 进行过滤. 过滤得到的数据会被存储起来, 用于满足后续所有输入请求, 直至过滤后的数据耗尽.

用作 OutputFilter 时, aggregate_filter 的实例会把写入它的所有数据存储起来而不向下游传递. 流关闭时, 流的全部内容通过 do_filter 进行过滤, 随后过滤后的数据一次性写入下一个下游过滤器或设备.

参考

概要

namespace boost { namespace iostreams {

#include <vector>

template< typename Ch,
          typename Tr = std::char_traits<Ch>,
          typename Alloc = std::allocator<Ch> >
class aggregate_filter  {
public:
    typedef Ch                            char_type;
    typedef implementation-defined        category;
    typedef std::vector<Char, Alloc>      vector_type;
    virtual ~aggregate_filter();
    ...
private:
    virtual void do_filter(const vector_type& src, vector_type& dest) = 0;
};

} } // End namespace boost::io

模板参数

Ch- 字符类型
Tr- 特征类型
Alloc- 标准库分配器类型 ([ISO], 20.1.5), 用于实例化 std::vector

aggregate_filter::do_filter

    virtual void do_filter(const vector_type& src, vector_type& dest) = 0;

从 src 读取未过滤的字符, 并将过滤后的字符追加到 dest, 在 src 中的所有字符都被消费后返回.
