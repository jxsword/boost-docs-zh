说明

过滤流与流缓冲使用链来管理其底层的过滤器和设备序列. 链表示零个或多个过滤器的序列, 末尾可带一个可选的设备. 如果链包含设备, 则视为完整, 可用于执行 I/O. 链用于输出时, 数据依次经过链中的第一个过滤器、第二个过滤器, 最终到达链末尾的设备. 链用于输入时, 数据沿相反方向流动: 从链末尾的设备开始, 按逆序经过各过滤器. 默认情况下, 若链末尾的设备被弹出, 或链在被销毁时是完整的, 则链中的所有过滤器和设备都会通过函数 close 关闭. 这一行为可通过成员函数 set_auto_close 修改.

类模板 chain 以 模式 为参数. 构成链的所有过滤器和设备, 其模式都必须细化该链的模式. 例如, 类 chain<input> 的模式为 input. 推入此类链的所有 过滤器 至少必须是 InputFilters; 推入此类链的任何 设备 至少必须是 Source.

链满足 CopyConstructible 与 Assignable. 链的副本表示与原链相同的过滤器和设备序列; 组件本身不会被复制.

概要

namespace boost { namespace iostreams {

template< typename Mode,
          typename Ch    = char,
          typename Tr    = std::char_traits<Ch>, 
          typename Alloc = std::allocator<Ch> >
class chain;

template< typename Mode,
          typename Ch    = wchar_t,
          typename Tr    = std::char_traits<Ch>, 
          typename Alloc = std::allocator<Ch> >
class wchain;

template< typename Mode,
          typename Ch    = char,
          typename Tr    = std::char_traits<Ch>, 
          typename Alloc = std::allocator<Ch> >
class chain : public implementation-defined stream type {
public:
    typedef Ch                      char_type;
    typedef Tr                      traits_type;
    typedef Mode                    mode;
    typedef Alloc                   allocator_type;
    typedef implementation-defined  size_type;

    chain();
    chain(const chain&);

    std::streamsize read(char_type* s, std::streamsize n);
    std::streamsize write(const char_type* s, std::streamsize n);
    stream_offset seek(stream_offset off, std::ios_base::seekdir way);

    const std::type_info& component_type(int n) const;

    template<typename T>
    T* component(int n) const;

    template<typename T>
    void push( const T& t,
               std::streamsize buffer_size = default value,
               std::streamsize pback_size = default value );

    template<typename StreamOrStreambuf>
    void push( StreamOrStreambuf& t,
               std::streamsize buffer_size = default value,
               std::streamsize pback_size = default value );

    void pop();
    bool empty() const;
    size_type size() const;
    void reset();
    bool is_complete() const;
    bool auto_close() const;
    void set_auto_close(bool close);
    bool sync();
    bool strict_sync();

        // Deprecated members

    template<int N>
    const std::type_info& component_type() const;

    template<int N, typename T>
    T* component() const;
};

} } // End namespace boost::io

类模板 chain

模板参数

Mode- 一个 模式标签.
Ch- 字符类型
Tr- 特征类型
Alloc- 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区

chain::chain

    chain();

构造一个 chain, 其过滤器和设备链为空.

chain::chain

    chain(const chain& rhs);

构造一个 chain, 表示与给定链相同的过滤器和设备序列.

chain::read

    std::streamsize read(char_type* s, std::streamsize n);

对链中第一个过滤器或设备调用 read, 该链必须非空.

chain::write

    std::streamsize write(const char_type* s, std::streamsize n);

对链中第一个过滤器或设备调用 write, 该链必须非空.

chain::seek

    stream_offset seek(stream_offset off, std::ios_base::seekdir way);

对链中第一个过滤器或设备调用 seek, 该链必须非空.

chain::component_type

    const std::type_info& component_type(int n) const;

返回对 std::type_info 实例的引用, 该实例对应链中第 n个过滤器或设备的类型, 链的大小必须至少为 n + 1. 组件从零开始编号.

    // Deprecated
    template<int N>
    const std::type_info& component_type() const;

返回对 std::type_info 实例的引用, 该实例对应链中第 N个过滤器或设备的类型, 链的大小必须至少为 N + 1. 组件从零开始编号. 模板参数 N 无法推导, 因此必须显式指定.

该成员已弃用; 请改用 component_type 的接受 int 参数的重载.

chain::component

    template<typename T>
    T* component(int n) const;

返回指向链中第 n个过滤器或设备的指针, 条件是链的大小至少为 n + 1 且第 n个过滤器或设备的类型等于 T; 否则返回空指针. 模板参数 T 无法推导, 因此必须显式指定.

Microsoft Visual Studio 6.0-7.0 版本的用户必须改用宏 BOOST_IOSTREAMS_COMPONENT 而不是此函数.

    // Deprecated
    template<int N, typename T>
    T* component() const;

返回指向链中第 N个过滤器或设备的指针, 条件是链的大小至少为 N + 1 且第 N个过滤器或设备的类型等于 T; 否则返回空指针. 模板参数 N 与 T 无法推导, 因此必须显式指定.

该成员已弃用; 请改用 component 的接受 int 参数的重载.

chain::push

    template<typename T>
    void push( const T& t,
               std::streamsize buffer_size,
               std::streamsize pback_size );

向此链追加 t 的副本; 此链不得处于 完整 状态. 各参数的含义如下:

T- 某种 Filter 或 Device 概念的模型, 同时满足 CopyConstructible, 其 字符类型 为 Ch 且其 模式 细化 Mode
t- 一个 T
buffer_size- 需要分配的所有缓冲区的大小
pback_size- 回退缓冲区的大小, 仅当 Mode 细化 input

T 类型的过滤器或设备实例若不满足 CopyConstructible, 可通过以下两种方式之一追加到链中:

  • 使用 引用包装器; 或者
  • 若 T 是标准流或流缓冲类型, 则使用 push 的接受非 const 引用的模板化重载.

若 T 是设备, 则此链会在该函数返回时变为完整, 之后即可用于执行 I/O.

    template<typename StreamOrStreambuffer>
    void push( StreamOrStreambuffer& t,
               std::streamsize buffer_size,
               std::streamsize pback_size );

将给定的流或流缓冲追加到此链; 此链不得处于 完整 状态. 各参数的含义如下:

StreamOrStreambuffer- 一种标准流或流缓冲类型, 其 字符类型 为 Ch 且其 模式 细化 Mode
buffer_size- 需要分配的所有缓冲区的大小
pback_size- 回退缓冲区的大小, 仅当 Mode 细化 input

此链会在该函数返回时变为完整, 之后即可用于执行 I/O.

chain::pop

    void pop();

从此链移除最后一个过滤器或设备, 此链必须非空. 若此链是 完整 的, pop 会使用函数 close 关闭链中的每个过滤器和设备, 除非已通过 set_auto_clos 禁用自动关闭特性.

chain::empty

    bool empty() const;

若此链不包含任何过滤器或设备, 则返回 true.

chain::size

    size_type size() const;

返回此链中过滤器和设备的数量.

chain::reset

    void reset();

清空此链. 若此链是 完整 的, reset 会使用函数 close 关闭链中的每个过滤器和设备, 无论是否已通过 set_auto_close 禁用自动关闭特性.

chain::is_complete

    bool is_complete() const;

返回 true, 若此链包含一个 设备. 链是完整的, 当且仅当它能够执行 I/O.

chain::auto_close

    bool auto_close() const;

指示当链处于完整状态时调用 pop 是否会自动关闭链中的过滤器和设备. 返回 true, 除非已通过 set_auto_close 禁用自动关闭特性.

chain::set_auto_close

    void set_auto_close(bool close);

指定当链处于完整状态时调用 pop 是否会自动关闭链中的过滤器和设备. 若链在销毁时是完整的, 该设置不会阻止链中的过滤器和设备被自动关闭.

chain::sync

    bool sync();

对此链 (必须完整) 中的每个过滤器和设备调用函数 flush. 返回 true, 除非这些组件中至少有一个是 Flushable 且在该组件上调用 flush 返回 false. 返回值为 true 表示没有发生错误, 但并不保证所有缓冲数据都已成功转发.

chain::strict_sync

    bool strict_sync();

与 sync 相同, 仅返回值不同: 返回 false, 除非链中的每个过滤器都是 Flushable 且 flush 返回 true, 且须在每个组件上都成立. 返回值为 true 保证所有缓冲数据都已成功转发.

类模板 wchain

template< typename Mode,
          typename Ch    = wchar_t,
          typename Tr    = std::char_traits<Ch>, 
          typename Alloc = std::allocator<Ch> >
class wchain;

与 chain 相同, 仅默认字符类型不同.
