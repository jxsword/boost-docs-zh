概述

类模板 basic_zlib_compressor 与 basic_zlib_decompressor 以 ZLIB 格式 ([Deutsch1]) 执行压缩与解压, 使用的是 Jean-loup Gailly 与 Mark Adler 的 zlib 压缩库 ([Gailly]).

zlib 过滤器是 DualUseFilters, 因此既可用于输入也可用于输出. 不过最常见的用法是: 压缩过滤器用于输出, 解压过滤器用于输入.

致谢

zlib 过滤器受到了 Jeff Garland ([Garland]) 与 Jonathan de Halleux ([de Halleux]) 工作的影响.

感谢 Jean-loup Gailly 与 Mark Adler 以 Boost 兼容 许可证向公众提供其出色的库.

参考

命名空间 boost::iostreams::zlib

命名空间 boost::iostreams::zlib 包含用于配置 zlib 过滤器和报告错误的整数常量. 各常量的含义如下. (更多细节参见 [Gailly].)

常量时间含义
no_compression 压缩级别常量, 指定不应执行压缩. 等于 Z_NO_COMPRESSION.
best_speed 压缩级别常量, 请求最快的压缩. 等于 Z_BEST_SPEED.
best_compression. 压缩级别常量, 请求最佳压缩比. 等于 Z_BEST_COMPRESSION.
default_compression 默认压缩级别. 等于 Z_DEFAULT_COMPRESSION.
deflated 压缩方法常量; 目前唯一受支持的方法. 等于 Z_DEFLATED.
default_strategy 压缩策略常量. 等于 Z_DEFAULT_STRATEGY.
filtered 压缩策略常量. 等于 Z_FILTERED.
huffman_only 压缩策略常量. 等于 Z_HUFFMAN_ONLY.
stream_error 错误码, 用于指示 zlib_params 的某个成员无效; 也可能指示 Iostreams 库内部错误. 等于 Z_STREAM_ERROR.
version_error 错误码, 用于指示数据是用不兼容版本的 zlib 压缩的. 等于 Z_VERSION_ERROR.
data_error 错误码, 用于指示压缩数据流已损坏. 等于 Z_DATA_ERROR.
buf_error 指示 Iostreams 库内部错误的错误码. 等于 Z_BUF_ERROR.

类 zlib_params

说明

封装用于配置 basic_zlib_compressor 与 basic_zlib_decompressor 的参数.

概要

struct zlib_params {

    // Non-explicit constructor
    zlib_params( int level           = zlib::default_compression,
                 int method          = zlib::deflated,
                 int window_bits     = default value, 
                 int mem_level       = default value, 
                 int strategy        = zlib::default_strategy,
                 bool noheader       = false );
    int  level;
    int  method;
    int  window_bits;
    int  mem_level;
    int  strategy;
    bool noheader;
};

zlib_params::zlib_params

    zlib_params( int level           = zlib::default_compression,
                 int method          = zlib::deflated,
                 int window_bits     = default value, 
                 int mem_level       = default value, 
                 int strategy        = zlib::default_strategy,
                 bool noheader       = false );

构造一个 zlib_params 对象, 各参数的含义如下:
level- 压缩级别. 必须等于 zlib::default_compression 或在范围 0-9 内取值. 值 0 表示不压缩, 而 9 表示最佳压缩比. 仅影响压缩.
method- 压缩方法. 必须等于 zlib::deflated. 仅影响压缩.
window_bits- 窗口大小以 2 为底的对数. 必须在 8-15 范围内; 默认为 15.
mem_level- 指定要使用的内存量. 必须在 1-9 范围内; 默认为 8. 仅影响压缩.
strategy- 必须为 zlib::default_strategy、zlib::filtered 或 zlib::huffman_only. 仅影响压缩.
noheader- 若为 true, 则应省略 ZLIB 头部和末尾的 ADLER-32 校验和 (参见 [Deutsch1]). 这将按照 deflate 规范 (参见 [Deutsch2]) 进行压缩.

更多细节参见 [Gailly].

Class template basic_zlib_compressor

说明

DualUseFilter 的模型, 使用 zlib ([Gailly]) 执行压缩.

概要

template<typename Alloc = std::allocator<char> >
struct basic_zlib_compressor {
    typedef char                    char_type;
    typedef implementation-defined  category;

    basic_zlib_compressor( const zlib_params& = zlib::default_compression,
                           std::streamsize buffer_size = default value );

    // DualUseFilter members.
};

typedef basic_zlib_compressor<> zlib_compressor;

模板参数

Alloc- C++ 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区并配置 zlib.

basic_zlib_compressor::basic_zlib_compressor

    basic_zlib_compressor( const zlib_params& = zlib::default_compression,
                           std::streamsize buffer_size = default value );

用给定参数和缓冲区大小构造一个 basic_zlib_compressor 实例. 由于 zlib_params 对象可以从表示压缩级别的 int 隐式构造, 因此可将 int 作为第一个构造函数参数传入.

模板参数

Alloc- C++ 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区并配置 zlib.

basic_zlib_decompressor::basic_zlib_decompressor

    basic_zlib_decompressor( int window_bits = default value, 
                             std::streamsize buffer_size =

类 zlib_error

说明

由 zlib 过滤器用于报告错误.

概要

class zlib_error : public std::ios_base::failure {
public:
    zlib_error(int error);
    int error() const;
};

zlib_error::zlib_error

    zlib_error(int error);

构造一个 zlib_error 实例, 使用来自命名空间 boost::iostreams::zlib 的给定错误码.

zlib_error::error

    void error() const;

返回一个来自命名空间 boost::iostreams::zlib 的错误码.

示例

以下代码从文件解压数据并写入标准输出. 
#include <fstream>
#include <iostream>
#include <boost/iostreams/filtering_streambuf.hpp>
#include <boost/iostreams/copy.hpp>
#include <boost/iostreams/filter/zlib.hpp>

int main() 
{
    using namespace std;

    ifstream file("hello.z", ios_base::in | ios_base::binary);
    filtering_streambuf<input> in;
    in.push(zlib_decompressor());
    in.push(file);
    boost::iostreams::copy(in, cout);
}

安装

zlib 过滤器依赖第三方 zlib 库, 该库不包含在 Boost 发行包中. 预编译的 zlib 二进制文件在多数 UNIX 及类 UNIX 系统上都有提供, Boost 构建系统会自动找到它们. Windows 用户可在 zlib 主页 获取预编译的二进制文件. 用户也可以配置 Boost Iostream 库从源代码构建 zlib, 源代码可在 zlib 主页获取. 关于如何配置构建系统以找到你的 zlib 安装, 请参见 安装.
