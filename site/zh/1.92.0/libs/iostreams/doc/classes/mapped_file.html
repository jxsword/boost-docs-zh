概述

类 mapped_file_source、mapped_file_sink 与 mapped_file 提供对 Windows 与 POSIX 系统上内存映射文件的访问. 这些 设备 的行为与 文件包装器 basic_file_source、basic_file_sink 与 basic_file 非常相似, 但有以下重要区别:

  • 默认情况下, 文件必须在打开之前已存在, 且不会被截断; 试图写入超过文件末尾会导致错误. 要映射尚不存在的文件, 请使用 mapped_file_params::new_file_size.
  • 文件总是以二进制模式打开.
  • 不支持宽字符流.

使用模板 code_converter 可如下定义宽字符版本的内存映射文件设备: 

    #include <boost/iostreams/code_converter.hpp>
    #include <boost/iostreams/device/mapped_file.hpp>

    typedef code_converter<mapped_file_source>  wmapped_file_source;
    typedef code_converter<mapped_file_sink>    wmapped_file_sink;

致谢

内存映射文件设备基于 Craig Henderson 的工作 ([Henderson]). Jonathan Graehl 实现了若干附加特性.

安装

内存映射文件设备依赖源文件 <libs/iostreams/src/mapped_file.cpp>. 该源文件会根据用户的操作系统使用 Windows 或 POSIX 头文件. 安装说明参见 安装.

1. 类 mapped_file_params

说明

封装用于打开内存映射文件的参数的类.

概要

namespace boost { namespace iostreams {

struct mapped_file_params {
    explicit mapped_file_params();
    explicit mapped_file_params(const std::string& path);
    std::string              path;
    mapped_file::mapmode     flags;
    std::ios_base::openmode  mode;  // Deprecated
    stream_offset            offset;
    std::size_t              length;
    stream_offset            new_file_size;
    const char*              hint;
};

} } // End namespace boost::io

mapped_file_params::path

    std::string              path;

要映射的文件的路径名.

mapped_file_params::mode

    std::ios_base::openmode  mode;

指示文件应以读访问、写访问还是两者兼备的方式打开. 被 mapped_file_source 与 mapped_file_sink 忽略. 该成员已弃用. 请在新代码中改用 flags.

mapped_file_params::flags

    mapped_file::mapmode  flags;

指示文件应以读访问、读写访问还是私有访问的方式打开. 以私有访问方式打开的文件可以写入, 但改动不会影响底层文件.

mapped_file_params::offset

    stream_offset            offset;

映射开始的偏移量. 该值必须是操作系统虚拟内存分配粒度的倍数; 该粒度可通过静态成员函数 alignment 获得 — mapped_file_source、mapped_file_sink 或 mapped_file 均提供该函数. 默认为 0.

mapped_file_params::length

    std::size_t              length;

要映射的字节数. 若未指定此参数, 则映射整个文件.

mapped_file_params::new_file_size

    stream_offset            new_file_size;

若此值非零, 则指定要创建的文件的大小. 若具有路径名 path 的文件已存在, 则会被覆盖.

mapped_file_params::hint

    const char*              hint;

为映射的开始位置建议进程地址空间中的一个位置.

2. 类 mapped_file_source

说明

Source 的模型, 提供对 Windows 与 POSIX 系统上内存映射文件的只读访问.

概要

namespace boost { namespace iostreams {

class mapped_file_source {
public:
    typedef char                      char_type;
    typedef [implementation-defined]  category;
    mapped_file_source();
    explicit mapped_file_source(mapped_file_params params);
    explicit mapped_file_source( const std::string& path,
                                 size_type length = max_length,
                                 boost::intmax_t offset = 0 );
    void open(mapped_file_params params);
    void open( const std::string& path,
               size_type length = max_length,
               boost::intmax_t offset = 0 );
    bool is_open() const;
    void close();
    size_type size() const;
    const char* data() const;
    iterator begin() const;
    iterator end() const;
    static int alignment();
};

} } // End namespace boost::io

4. 类 mapped_file

说明

SeekableDevice 的模型, 提供对 Windows 与 POSIX 系统上内存映射文件的读写访问.

概要

namespace boost { namespace iostreams {

class mapped_file {
public:
    typedef char                      char_type;
    typedef [implementation-defined]  category;
    enum mapmode { readonly, readwrite, priv };
    mapped_file();
    explicit mapped_file(mapped_file_params params);
    explicit mapped_file( const std::string& path,
                          std::ios_base::openmode mode =
                              std::ios_base::in | std::ios_base::out,
                          size_type length = max_length,
                          boost::intmax_t offset = 0 );
    explicit mapped_file( const std::string& path,
                          mapmode mode,
                          size_type length = max_length,
                          boost::intmax_t offset = 0 );
    void open(mapped_file_params params);
    void open( const std::string& path,
               std::ios_base::openmode mode = 
                   std::ios_base | std::ios_base,
               size_type length = max_length,
               boost::intmax_t offset = 0 );
    void open( const std::string& path,
               mapmode mode,
               size_type length = max_length,
               boost::intmax_t offset = 0 );
    bool is_open() const;
    mapmode flags() const;
    void close();
    size_type size() const;
    char* data() const;
    const char* const_data() const;
    iterator begin() const;
    const_iterator const_begin() const;
    iterator end() const;
    const_iterator const_end() const;
    static int alignment();
};

} } // End namespace boost::iostreams
