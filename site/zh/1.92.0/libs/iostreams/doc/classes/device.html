说明

Iostreams 库提供类模板 device、其子类 wdevice 以及它们的特化 source、sink、wsource 与 wsink, 以简化各种 设备概念 新模型的定义. 这些模板与 typedef 旨在用作用户自定义设备的基类. 它们提供 Iostreams 库所用的成员类型 char_type 与 category.

所提供的 category 成员可转换为 closable_tag 和 localizable_tag. 借此, 用户只需提供概念 Closable 与 Localizable 模型所需的成员函数 close 与 imbue 的定义即可.

头文件

<boost/iostreams/concepts.hpp>

参考

概要

namespace boost{ namespace iostreams {

template<typename Mode, typename Ch = char>
struct device;

template<typename Mode, typename Ch = wchar_t>
struct wdevice : device<Mode, Ch> { };

typedef device<input>    source;
typedef device<output>   sink;
typedef wdevice<input>   wsource;
typedef wdevice<output>  wsink;

template<typename Mode, typename Ch = char>
struct device {
    typedef Ch         char_type;
    typedef see below  category;
    void close();
    void close(std::ios_base::openmode);
    void imbue(const std::locale&);
};

} } // End namespace boost::io

模板参数

Mode- 一个 模式标签.
Ch- 字符类型

device::category

    typedef see below category;

一个可转换为 Mode、device_tag、closable_tag 与 localizable_tag 的类别标签.

device::close

    void close();
    void close(std::ios_base::openmode);

两个重载都实现为空操作. 仅当 Mode 可转换为 bidirectional 时第二个重载才可用; 仅当 Mode 不可转换为 bidirectional 时第一个重载才可用.

Closable 所要求.

device::imbue

    void imbue(const std::locale&);

实现为空操作. Localizable 所要求.
