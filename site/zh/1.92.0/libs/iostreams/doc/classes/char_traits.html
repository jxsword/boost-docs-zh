说明

类模板 boost::iostreams::char_traits 是 std::char_traits 的派生类, 它多了一个静态函数 would_block, 用于指示读取字符的尝试因当前没有可用输入而失败.

提供常量 WOULD_BLOCK 与 WWOULD_BLOCK 以方便使用.

头文件

<boost/iostreams/char_traits.hpp>

参考

概要

namespace boost { namespace iostreams {

const int WOULD_BLOCK;

const std::wint_t WWOULD_BLOCK;

template<typename Ch>
class char_traits : public std::char_traits<Ch> {
    static typename std::char_traits<Ch>::int_type would_block();
};

} } // End namespace boost::io

常量 WOULD_BLOCK

    const int WOULD_BLOCK;

char_traits<char>::would_block 的返回值. 由函数模板 get 用于指示因输入暂时不可用而无法返回字符.

常量 WWOULD_BLOCK

    const std::wint_t WWOULD_BLOCK;

char_traits<wchar_t>::would_block 的返回值. 由函数模板 get 用于指示因输入暂时不可用而无法返回字符.

类模板 boost::iostreams::char_traits

模板参数

Ch- 字符类型

char_traits::would_block

    static typename std::char_traits<Ch>::int_type would_block();

返回一个 int_type 实例, 由函数模板 get 用于指示从 源 读取字符的尝试因当前没有可用输入而失败. 之后的读取尝试可能成功.
