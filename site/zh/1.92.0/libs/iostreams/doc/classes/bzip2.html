概述

类模板 basic_bzip2_compressor 与 basic_bzip2_decompressor 使用 Julian Seward 的 libbzip2 压缩库 ([Seward]) 执行压缩与解压.

bzip2 过滤器是 DualUseFilters, 因此既可用于输入也可用于输出. 不过最常见的用法是: 压缩过滤器用于输出, 解压过滤器用于输入.

致谢

bzip2 过滤器受到了 Jeff Garland ([Garland]) 与 Jonathan de Halleux ([de Halleux]) 工作的影响.

感谢 Julian Seward 以 Boost 兼容 许可证向公众提供其出色的库.

参考

命名空间 boost::iostreams::bzip2

命名空间 boost::iostreams::bzip2 包含整数错误码. 各常量的含义如下. 更多细节参见 [Seward].

常量时间含义
data_error 表示压缩数据流已损坏. 等于 BZ_DATA_ERROR.
data_error_magic 表示压缩数据流未以 'magic' 序列 'B' 'Z' 'h' 开头. 等于 BZ_DATA_ERROR_MAGIC.
config_error 表示 libbzip2 未针对当前平台正确配置. 等于 BZ_CONFIG_ERROR.

类 bzip2_params

说明

封装用于配置 basic_bzip2_compressor 与 basic_bzip2_decompressor 的参数.

概要

struct bzip2_params {

    // Non-explicit constructor for compression
    bzip2_params( int block_size   = default value,
                  int work_factor  = default value );

    // Constructor for decompression.
    bzip2_params( bool small );

    union {
        int   block_size;    // For compression
        bool  small;         // For decompression
    };
    int       work_factor;   // For compression
};

bzip2_params::bzip2_params

    bzip2_params( int block_size   = default value,
                  int work_factor  = default value );
    bzip2_params( bool small );

第一个成员构造一个 bzip2_params 对象, 用于配置 basic_bzip2_compressor.

block_size- 压缩所用的块大小; 实际块大小为 100000 * block_size. 必须在范围 1-9 内.
work_factor- 控制在最坏情况数据下压缩的行为. 必须在 0-250 范围内.

第二个构造一个 bzip2_params 对象, 用于配置 basic_bzip2_decompressor.

small- 指示是否应使用占用内存更少的较慢解压算法.

参见 [Seward] 了解更多细节.

Class template basic_bzip2_compressor

说明

使用 libbzip2 ([Seward]) 执行压缩的 DualUseFilter 模型.

概要

template<typename Alloc = std::allocator<char> >
struct basic_bzip2_compressor {
    typedef char                    char_type;
    typedef implementation-defined  category;

    basic_bzip2_compressor( const bzip2_params& = bzip2::default_block_size,
                            std::streamsize buffer_size = default value );
    ...
};

typedef basic_bzip2_compressor<> bzip2_compressor;

模板参数

Alloc- C++ 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区并配置 libbzip2.

basic_bzip2_compressor::basic_bzip2_compressor

    basic_bzip2_compressor(const bzip2_params&, std::streamsize buffer_size);

用给定参数和缓冲区大小构造一个 basic_bzip2_compressor 实例. 由于 bzip2_params 对象可以从表示块大小的 int 隐式构造, 因此可将 int 作为第一个构造函数参数传入.

类 bzip2_error

说明

由 bzip2 过滤器用于报告错误.

概要

class bzip2_error : public std::ios_base::failure {
public:
    bzip2_error(int error);
    int error() const;
};

bzip2_error::bzip2_error

    bzip2_error(int error);

构造一个 bzip2_error 实例, 使用来自命名空间 boost::iostreams::bzip2 的给定错误码.

bzip2_error::error

    void error() const;

返回一个来自命名空间 boost::iostreams::bzip2 的错误码.

示例

以下代码从文件解压数据并写入标准输出. 
#include <fstream>
#include <iostream>
#include <boost/iostreams/filtering_streambuf.hpp>
#include <boost/iostreams/copy.hpp>
#include <boost/iostreams/filter/bzip2.hpp>

int main() 
{
    using namespace std;
    using namespace boost::iostreams;

    ifstream file("hello.bz2", ios_base::in | ios_base::binary);
    filtering_streambuf<input> in;
    in.push(bzip2_decompressor());
    in.push(file);
    boost::iostreams::copy(in, cout);
}

安装

bzip2 过滤器依赖第三方 libbz2 库, 该库不包含在 Boost 发行包中. 预编译的 libbz2 二进制文件在多数 UNIX 及类 UNIX 系统上都有提供, Boost 构建系统会自动找到它们. 用户也可以配置 Boost Iostream 库从源代码构建 libbz2, 源代码可在 libbz2 主页 获取. 关于如何配置构建系统以找到你的 libbz2 安装, 请参见 安装.
