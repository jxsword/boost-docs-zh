说明

类模板 basic_counter 是一个 DualUseFilter, 它将数据不加修改地转发给链中的下一个过滤器, 同时记录已处理的字符数和行数.

basic_counter 满足 OptimallyBuffered, 其最佳缓冲区大小为 0, 以保持字符计数和行计数准确. 当 basic_counter 用于输出时, 行计数和字符计数应准确反映已传递给下游过滤器的数据. 当 basic_counter 用于输入时, 由于回退缓冲区的存在, 字符计数可能与已从下游过滤器读取的字符数略有偏差. 行计数应准确反映已从下游读取的行数, 除非正在读取某行的第一个字符 — 此时行计数可能相差 1.

头文件

<boost/iostreams/filter/counter.hpp>

参考

概要

namespace boost { namespace iostreams {

template<typename Ch>
class basic_counter {
public:
    typedef Ch                                char_type;
    typedef typename [implmentation defined]  category;
    explicit basic_counter(int first_line = 0, int first_char = 0);
    int lines() const;
    int characters() const;
    std::streamsize optimal_buffer_size() const;
};

typedef basic_counter<char>     counter;
typedef basic_counter<wchar_t>  wcounter;

} } // End namespace boost::io

模板参数

Ch- 字符类型

counter::counter

    explicit basic_counter(int first_line = 0, int first_char = 0);

用给定的初始计数构造一个 basic_counter.

counter::lines

    int lines() const;

返回当前行计数.

counter::characters

    int characters() const;

返回当前字符计数.

counter::optimal_buffer_size

示例

以下示例展示了在将 basic_counter 添加到过滤链之后获取行计数和字符计数的一种方法: 使用 filtering_stream 的成员函数 component 获取指向 basic_counter 的指针.

#include <boost/iostreams/device/file.hpp>
#include <boost/iostreams/filter/counter.hpp>
#include <boost/iostreams/filtering_stream.hpp>

namespace io = boost::iostreams;

int main()
{
    io::filtering_istream in;
    in.push(io::counter());
    in.push(io::file_source("poem.txt"));
    // read from in
    int lines = in.component<0, counter>()->lines();
    int characters = in.component<0, counter>()->characters();
}

以下示例展示了获取行计数和字符计数的另一种方法: 以引用方式将 basic_counter 添加到过滤链 (使用 boost::ref), 然后直接访问 basic_counter. 

#include <boost/iostreams/device/file.hpp>
#include <boost/iostreams/filter/counter.hpp>
#include <boost/iostreams/filtering_stream.hpp>
#include <boost/ref.hpp>

namespace io = boost::iostreams;

int main()
{
    io::counter cnt;
    io::filtering_ostreams out;
    out.push(boost::ref(cnt));
    out.push(io::file_sink("log.txt"));
    // write to out
    int lines = cnt.lines();
    int characters = cnt.characters();
}
