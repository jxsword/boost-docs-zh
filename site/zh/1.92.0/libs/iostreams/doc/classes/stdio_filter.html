说明

类模板 basic_stdio_filter 是一个 DualUseFilter, 供从标准输入读取未过滤数据、向标准输出写入过滤后数据的过滤器用作基类.

basic_stdio_filter 的实现方式是重定向 std::cin 与 std::cout (或 std::wcin 与 std::wcout). 在调用 do_filter 之前, 整个未过滤数据流会被读取并存储在内存中. 因此, basic_stdio_filter 不适合在内存受限的环境中使用, 也不适合与没有自然终点的数据流 (如股票行情) 结合使用. 鉴于这些局限, basic_stdio_filter 最适合用作学习 Iostreams 库时的辅助工具.

头文件

<boost/iostreams/filter/stdio.hpp>

参考

概要

namespace boost { namespace iostreams {

template<typename Ch>
class basic_stdio_filter {
public:
    typedef Ch                        char_type;
    typedef [implementation-defined]  category;
protected:
    basic_stdio_filter();
public:
    virtual ~basic_stdio_filter();
private:
    virtual void do_filter() = 0;
};

typedef basic_stdio_filter<char>     stdio_filter;
typedef basic_stdio_filter<wchar_t>  wstdio_filter;

} } // End namespace boost::io

模板参数

Ch- 字符类型

counter::do_filter

    virtual void do_filter() = 0;

从标准输入读取并写入标准输出, 直至标准输入耗尽. 若 Ch 为 char, 则使用 std::cin 与 std::cout; 若 Ch 为 wchar_t, 则使用 std::wcin 与 std::wcout.
