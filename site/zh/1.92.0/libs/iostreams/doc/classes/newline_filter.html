概述

Boost.Iostreams 提供两个处理行尾约定的组件: 类模板 newline_filter 在各种行尾约定之间转换, 类模板 newline_checker 验证字符序列是否符合给定的行尾约定.

头文件

<boost/iostreams/filter/newline.hpp>

概要

namespace boost { namespace iostreams {

namespace newline {
                    
const int posix             = 1;    // Use CR as line separator.
const int mac               = 2;    // Use LF as line separator.
const int dos               = 4;    // Use CRLF as line separator.
const int mixed             = 8;    // Mixed line endings.
const int final_newline     = 16;

}   // End namespace boost::iostreams::newline

class newline_filter;
class newline_checker;
class newline_error;

} } // End namespace boost::io

参考

1. 命名空间 boost::iostreams::newline

命名空间 boost::iostreams::newline 包含用于配置 newline_filter 与 newline_checker 以及报告错误的整数常量. 各常量的含义如下.

常量时间含义
posix 用于指示 POSIX 行尾约定.
dos 用于指示 DOS 行尾约定.
mac 用于指示经典 Mac 行尾约定.
mixed 用于描述具有混合行尾的文档.
final_newline 用于指示文档以换行序列结尾.

2. 类 newline_filter

说明

DualUseFilter, 用于在各种操作系统使用的行尾约定之间转换. 其唯一构造函数接受一个整数参数, 用于指定目标格式.

概要

class newline_filter {
public:
    typedef char                      char_type;
    typedef [implementation-defined]  category;
    explicit newline_filter(int target);
};

newline_filter::newline_filter

    explicit newline_filter(int target);

构造一个 newline_filter, 用于转换到指定格式. 参数 target 必须为 newline::posix、newline::dos 或 newline::mac.

3. 类 newline_checker

说明

DualUseFilter, 用于验证字符序列是否符合给定的行尾约定.

概要

class newline_checker {
public:
    typedef char                      char_type;
    typedef [implementation-defined]  category;
    explicit newline_checker(int target = default_value );
    bool is_posix() const;
    bool is_dos() const;
    bool is_mac() const;
    bool is_mixed_posix() const;
    bool is_mixed_dos() const;
    bool is_mixed_mac() const;
    bool is_mixed() const;
    bool has_final_newline() const;
};

newline_checker::newline_checker

    explicit newline_checker(int target = default_value );

构造一个 newline_checker. 若指定了 target, 则一旦遇到不符合 target 的行尾序列, 就会抛出 newline_error. 值 target 必须为 newline::posix、newline::dos 或 newline::mac, 或这些值之一与 newline::final_newline 的按位或.

注释: 若 newline_checker 被用于执行输出, 则字符序列未以换行序列结尾这一点可能要到 newline_checker 被 关闭 时才会发现. 在某些情况下, close 抛出的异常会被 Iostreams 库捕获并忽略. 因此, 执行输出时, 指定 newline::final_newline 作为 target 的一部分可能不起作用. 要检查字符序列是否以换行序列结尾, 请调用 has_final_newline — 在 newline_checker 已被关闭之后.

newline_checker::is_posix

    bool is_posix() const;

若迄今为止检查过的字符中至少包含一个 POSIX 行尾序列, 且不包含任何其他类型的行尾序列, 则返回 true.

newline_checker::is_dos

    bool is_dos() const;

若迄今为止检查过的字符中至少包含一个 DOS 行尾序列, 且不包含任何其他类型的行尾序列, 则返回 true.

newline_checker::is_mac

    bool is_mac() const;

若迄今为止检查过的字符中至少包含一个经典 Mac 行尾序列, 且不包含任何其他类型的行尾序列, 则返回 true.

newline_checker::is_mixed_posix

    bool is_mixed_posix() const;

若迄今为止检查过的字符中至少包含一个 POSIX 行尾序列, 则返回 true.

newline_checker::is_mixed_dos

    bool is_mixed_dos() const;

若迄今为止检查过的字符中至少包含一个 DOS 行尾序列, 则返回 true.

newline_checker::is_mixed_mac

    bool is_mixed_mac() const;

若迄今为止检查过的字符中至少包含一个经典 Mac 行尾序列, 则返回 true.

newline_checker::is_mixed

    bool is_mixed() const;

若迄今为止检查过的字符包含不止一种类型的行尾序列, 则返回 true.

newline_checker::has_final_newline

    bool has_final_newline() const;

返回 true, 若此 newline_checker 已被关闭或已到达流末尾, 且检查过的字符序列以换行序列结尾.

4. 类模板 newline_error

说明

由 newline_checker 用于报告错误.

概要

class newline_error : public std::ios_base::failure {
public:
    bool is_posix() const;
    bool is_dos() const;
    bool is_mac() const;
    bool is_mixed_posix() const;
    bool is_mixed_dos() const;
    bool is_mixed_mac() const;
    bool is_mixed() const;
    bool has_final_newline() const;
};

newline_error::is_posix

    bool is_posix() const;

若抛出此异常的 newline_checker 所检查的字符中至少包含一个 POSIX 行尾序列, 且不包含任何其他类型的行尾序列, 则返回 true.
