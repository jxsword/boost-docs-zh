说明

std::basic_istream、std::basic_ostream 或 std::basic_iostream 的派生类, 用于执行过滤. 每个 filtering_stream 包含一个 链, 其中是零个或多个过滤器, 末尾可带一个可选的设备. 若链中包含设备, 则 filtering_stream 是完整的, 可用于执行 I/O. filtering_stream 用于输出时, 数据依次经过链中的第一个过滤器、第二个过滤器, 最终到达链末尾的设备. filtering_stream 用于输入时, 数据沿相反方向流动: 从链末尾的设备开始, 按逆序经过各过滤器. 默认情况下, 若链末尾的设备被弹出, 或 filtering_stream 在被销毁时是完整的, 则链中的所有过滤器和设备都会通过函数 close 关闭. 这一行为可通过成员函数 set_auto_close 修改.

filtering_stream 派生自 std::basic_istream、std::basic_ostream 或 std::basic_iostream, 取决于其 Mode 参数.

概要

namespace boost { namespace iostreams {

template< typename Mode,
          typename Ch     = char,
          typename Tr     = std::char_traits<Ch>, 
          typename Alloc  = std::allocator<Ch>, 
          typename Access = public_ >
class filtering_stream;

template< typename Mode,
          typename Ch     = wchar_t,
          typename Tr     = std::char_traits<Ch>, 
          typename Alloc  = std::allocator<Ch>, 
          typename Access = public_ >
class filtering_wstream;

typedef filtering_stream<input>    filtering_istream;
typedef filtering_stream<output>   filtering_ostream;
typedef filtering_wstream<input>   filtering_wistream;
typedef filtering_wstream<output>  filtering_wostream;

template< typename Mode,
          typename Ch     = char,
          typename Tr     = std::char_traits<Ch>, 
          typename Alloc  = std::allocator<Ch>, 
          typename Access = public_ >
class filtering_stream : public implementation-defined stream type {
public:
    typedef Ch                      char_type;
    typedef Mode                    mode;
    typedef Alloc                   allocator_type;
    typedef implementation-defined  size_type;

    filtering_stream();

    template<typename T>
    filtering_stream( const T& t,
                      std::streamsize buffer_size = default value,
                      std::streamsize pback_size = default value );

    template<typename StreamOrStreambuf>
    filtering_stream( StreamOrStreambuf& t,
                      std::streamsize buffer_size = default value,
                      std::streamsize pback_size = default value );

    const std::type_info& component_type(int n) const;

    template<typename T>
    T* component(int n) const;

    template<typename T>
    void push( const T& t,
               std::streamsize buffer_size = default value,
               std::streamsize pback_size = default value );

    template<typename StreamOrStreambuf>
    void push( StreamOrStreambuf& t,
               std::streamsize buffer_size = default value,
               std::streamsize pback_size = default value );
    void pop();
    bool empty() const;
    size_type size() const;
    void reset();
    bool is_complete() const;
    bool auto_close() const;
    void set_auto_close(bool close);
    bool sync();
    bool strict_sync();

        // Deprecated members

    template<int N>
    const std::type_info& component_type() const;

    template<int N, typename T>
    T* component() const;
};

} } // End namespace boost::io

类模板 filtering_stream

模板参数

Mode- 一个 模式标签.
Ch- 字符类型
Tr- 特征类型
Alloc- 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区
Access- public_ 或 protected_ 之一, 指示链接口的访问级别. 定义派生类时用于隐藏链接口, 该派生类派生自 filtering_stream

filtering_stream::filtering_stream

    filtering_stream();

构造一个 filtering_stream, 其过滤器和设备链为空.

filtering_stream::filtering_stream

    template<typename T>
    filtering_stream( const T& t,
                      std::streamsize buffer_size,
                      std::streamsize pback_size );

构造一个 filtering_stream, 其链中包含 t 的副本. 各参数的含义如下:

T- 某种 Filter 或 Device 概念的模型, 同时满足 CopyConstructible, 其 字符类型 为 Ch 且其 模式 细化 Mode
t- 一个 T
buffer_size- 需要分配的所有缓冲区的大小
pback_size- 回退缓冲区的大小, 仅当 Mode 细化 input

filtering_stream 可以由 T 类型过滤器或设备实例构造, 若该实例不满足 CopyConstructible, 方式有二:

  • 使用 引用包装器; 或者
  • 若 T 是标准流或流缓冲类型, 则使用接受非 const 引用的构造函数.

若 T 是设备, 则 filtering_stream 会在构造时变为完整, 之后即可用于执行 I/O.

    template<typename StreamOrStreambuffer>
    filering_stream( StreamOrStreambuffer& t,
                     std::streamsize buffer_size,
                     std::streamsize pback_size );

构造一个 filtering_stream, 其链中包含对给定流或流缓冲的引用. 各参数的含义如下:

StreamOrStreambuffer- 一种标准流或流缓冲类型, 其 字符类型 为 Ch 且其 模式 细化 Mode
buffer_size- 需要分配的所有缓冲区的大小
pback_size- 回退缓冲区的大小, 仅当 Mode 细化 input

filtering_stream 会在构造时变为完整, 之后即可用于执行 I/O.

filtering_stream::component_type

    const std::type_info& component_type(int n) const;

返回对 std::type_info 实例的引用, 该实例对应底层链中第 n个过滤器或设备的类型, 底层链的大小必须至少为 n + 1. 组件从零开始编号.

    // Deprecated
    template<int N>
    const std::type_info& component_type() const;

返回对 std::type_info 实例的引用, 该实例对应底层链中第 N个过滤器或设备的类型, 底层链的大小必须至少为 N + 1. 组件从零开始编号. 模板参数 N 无法推导, 因此必须显式指定.

该成员已弃用; 请改用 component_type 的接受 int 参数的重载.

filtering_stream::component

    template<typename T>
    T* component(int n) const;

返回指向底层链中第 n个过滤器或设备的指针, 条件是链的大小至少为 n + 1 且第 n个过滤器或设备的类型等于 T; 否则返回空指针. 模板参数 T 无法推导, 因此必须显式指定.

Microsoft Visual Studio 6.0-7.0 版本的用户必须改用宏 BOOST_IOSTREAMS_COMPONENT 而不是此函数.

    // Deprecated
    template<int N, typename T>
    T* component() const;

返回指向底层链中第 N个过滤器或设备的指针, 条件是链的大小至少为 N + 1 且第 N个过滤器或设备的类型等于 T; 否则返回空指针. 模板参数 N 与 T 无法推导, 因此必须显式指定.

该成员已弃用; 请改用 component 的接受 int 参数的重载.

filtering_stream::push

    template<typename T>
    void push( const T& t,
               std::streamsize buffer_size,
               std::streamsize pback_size );

向底层链追加 t 的副本; 底层链不得处于 完整 状态. 各参数的含义如下:

T- 某种 Filter 或 Device 概念的模型, 同时满足 CopyConstructible, 其 字符类型 为 Ch 且其 模式 细化 Mode
t- 一个 T
buffer_size- 需要分配的所有缓冲区的大小
pback_size- 回退缓冲区的大小, 仅当 Mode 细化 input

T 类型的过滤器或设备实例若不满足 CopyConstructible, 可通过以下两种方式之一追加到链中:

  • 使用 引用包装器; 或者
  • 若 T 是标准流或流缓冲类型, 则使用 push 的接受非 const 引用的模板化重载.

若 T 是设备, 则此 filtering_stream 会在该函数返回时变为完整, 之后即可用于执行 I/O.

    template<typename StreamOrStreambuffer>
    void push( StreamOrStreambuffer& t,
               std::streamsize buffer_size,
               std::streamsize pback_size );

将给定的流或流缓冲追加到底层链; 底层链不得处于 完整 状态. 各参数的含义如下:

StreamOrStreambuffer- 一种标准流或流缓冲类型, 其 字符类型 为 Ch 且其 模式 细化 Mode
buffer_size- 需要分配的所有缓冲区的大小
pback_size- 回退缓冲区的大小, 仅当 Mode 细化 input

此 filtering_stream 会在该函数返回时变为完整, 之后即可用于执行 I/O.

filtering_stream::pop

    void pop();

从底层链移除最后一个过滤器或设备, 底层链必须非空. 若链最初是 完整 的, 则会使用函数 close 关闭链中的每个过滤器和设备, 除非自动关闭特性已被禁用 — 手段为 set_auto_close

filtering_stream::empty

    bool empty() const;

返回 true, 若底层链为空.

filtering_stream::size

    size_type size() const;

返回底层链中过滤器和设备的数量.

filtering_stream::reset

    void reset();

清空底层链. 若链最初是 完整 的, 则会使用函数 close 关闭链中的每个过滤器和设备.

filtering_stream::is_complete

    bool is_complete() const;

返回 true, 若底层链以 设备 结尾.

filtering_stream::auto_close

    bool auto_close() const;

指示当链处于完整状态时调用 pop 是否会自动关闭底层链中的过滤器和设备. 返回 true, 除非已通过 set_auto_close 禁用自动关闭特性.

filtering_stream::set_auto_close

    void set_auto_close(bool close);

指定当链处于完整状态时调用 pop 是否会自动关闭底层链中的过滤器和设备. 若链在销毁时是完整的, 该设置不会阻止链中的过滤器和设备被自动关闭.

filtering_stream::sync

    bool sync();

对底层链 (必须完整) 中的每个过滤器和设备调用函数 flush. 返回 true, 除非这些组件中至少有一个是 Flushable 且在该组件上调用 flush 返回 false. 返回值为 true 表示没有发生错误, 但并不保证所有缓冲数据都已成功转发.

filtering_stream::strict_sync

    bool strict_sync();

与 sync 相同, 仅返回值不同: 返回 false, 除非底层链中的每个过滤器都是 Flushable 且 flush 返回 true, 且须在每个组件上都成立. 返回值为 true 保证所有缓冲数据都已成功转发.
