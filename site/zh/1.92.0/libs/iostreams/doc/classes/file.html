概述

类模板 basic_file_source、basic_file_sink 与 basic_file 是 std::basic_filebuf 的包装器, 满足 CopyConstructible 与 Assignable. 当用户希望访问文件而不管理标准文件流或流缓冲的生命期时, 它们非常有用. 这是因为当流或流缓冲被添加到 filtering_streambuf 或 filtering_stream 时, 它以引用形式存储, 该引用必须保持有效, 直至该流或流缓冲从链中移除.

最常见的特化可通过 typedef file_source、file_sink、file、wfile_source、wfile_sink 与 wfile 访问.

参考

Class template basic_file_source

说明

CopyConstructible 与 Assignable 的包装器, 包装以只读模式打开的 std::basic_filebuf.

概要

namespace boost { namespace iostreams {

template<typename Ch>
class basic_file_source {
public:
    typedef Ch                      char_type;
    typedef implementation-defined  category;
    basic_file_source( const std::string& path,
                       std::ios_base::openmode mode =
                           std::ios_base::in );
    bool is_open() const;
    ...
};

typedef basic_file_source<char>     file_source;
typedef basic_file_source<wchar_t>  wfile_source;

} } // End namespace boost::iostreams

模板参数

Ch- 字符类型.

basic_file_source::basic_file_source

    basic_file_source( const std::string& path,
                       std::ios_base::openmode mode );

构造一个 basic_file_source, 包装按如下方式打开的 std::basic_filebuf buf: 

    mode |= std::ios_base::in;
    mode &= ~std::ios_base::out;
    buf.open(path.c_str(), mode);

basic_file_source::is_open

    bool is_open() const;

返回 true, 若底层 basic_filebuf 实例已成功打开.

Class template basic_file

说明

CopyConstructible 与 Assignable 的包装器, 包装默认以读写模式打开的 std::basic_filebuf.

概要

namespace boost { namespace iostreams {

template<typename Ch>
class basic_file {
public:
    typedef Ch                      char_type;
    typedef implementation-defined  category;
    basic_file( const std::string& path,
                std::ios_base::openmode mode =
                    std::ios_base::in | std::ios_base::out );
    bool is_open() const;
    ...
};

typedef basic_file<char>     file;
typedef basic_file<wchar_t>  wfile;

} } // End namespace boost::iostreams
