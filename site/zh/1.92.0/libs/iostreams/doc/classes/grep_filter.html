说明

类模板 basic_grep_filter 使用构造时提供的正则表达式逐行过滤字符序列, 方式类似于命令行工具 grep ([IEEE]). 该过滤器使用 Boost 正则表达式库 ([Maddock]) 提供的正则表达式.

默认情况下, 过滤后的字符序列由未过滤序列中包含与正则表达式匹配之子序列的那些行组成. 通过在构造时指定适当的选项, 可使 basic_grep_filter 只放行与正则表达式完全匹配的行 (如同向命令行工具传入选项 -x), 或只放行不包含匹配项的行 (如同向命令行工具传入选项 -v).

过滤后字符序列的行数运行计数可通过成员函数 count 获得.

头文件

<boost/iostreams/filter/grep.hpp>

安装

模板 basic_grep_filter 使用 Boost 正则表达式库, 该库必须单独构建. 详情参见 此处.

参考

概要

namespace boost { namespace iostreams {

#include <boost/function.hpp>
#include <boost/regex.hpp>

namespace grep {

const int invert;
const int whole_line;

}

template< typename Ch,
          typename Tr = regex_traits<Ch>,
          typename Alloc = std::allocator<Ch> >
class basic_grep_filter {   
public:
    basic_grep_filter( const basic_regex<Ch, Tr, Alloc>& pattern,
                       regex_constants::match_flag_type flags = 
                           regex_constants::match_default,
                       int options = 0 );
    int count() const;
};

typedef basic_grep_filter<char>     grep_filter;
typedef basic_grep_filter<wchar_t>  wgrep_filter;

} } // End namespace boost::io

模板参数

Ch- 字符类型
Tr- 正则表达式特征类型
Alloc- 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区

basic_grep_filter::basic_grep_filter

    basic_grep_filter( const basic_regex<Ch, Tr, Alloc>& pattern,
                       regex_constants::match_flag_type flags = 
                           regex_constants::match_default,
                       int options = 0 );

由给定的正则表达式、匹配标志和 grep 选项构造一个 basic_grep_filter. 各参数的含义如下:

pattern- 与未过滤数据流进行匹配的正则表达式
flags- 传递给 regex_search 或 regex_match 的标志, 用于指定正则表达式匹配行为
options- 命名空间 boost::iostreams::grep 中零个或多个常量的按位或. 目前可识别两个常量: grep::whole_line 使过滤器只放行与正则表达式完全匹配的行; grep::invert 使过滤器只放行不包含匹配项的行.

basic_grep_filter::count

    int count() const;

返回从未过滤字符序列传递到过滤后字符序列的行数的运行计数. 当过滤器开始处理新的字符序列时, 该计数会自动清零.
