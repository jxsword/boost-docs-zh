概述

类模板 basic_null_source、basic_null_sink 与 basic_null_device 是成员函数全部为平凡实现的设备模型. basic_null_source 是一个 Source, 其成员函数 read 返回 -1, 表示序列结束. basic_null_sink 是一个 Sink, 其成员函数 write 消费并忽略传递给它的字符. basic_null_device 则 — 取决于其模板参数 Mode — 将上述平凡的 read 与 write 函数与一个总是返回无效流位置的成员 seek 组合起来.

此外, 上述每个模板都满足 Closable, 其中 close 实现为空操作.

致谢

此处描述的模板灵感来自 Daryle Walker 的 basic_nullbuf 模板. 参见 断开连接的流.

Class template basic_null_source

说明

Source 的模型, 其成员函数 read 返回 -1, 表示序列结束.

概要

namespace boost { namespace iostreams {

template<typename Ch>
class basic_null_source { 
public:
    typedef Ch                        char_type;
    typedef [implementation-defined]  category;

    basic_null_source();    
    std::streamsize read(char_type* s, std::streamsize n);
    void close();
};

typedef basic_null_source<char>     null_source;
typedef basic_null_source<wchar_t>  wnull_source;

} } // End namespace boost::io

Class template basic_null_device

说明

Device 的模型, 其模式以模板参数指定, 成员函数均为平凡实现, 如下:

  • read 返回 -1, 表示序列结束
  • write 消费但忽略传递给它的字符缓冲区的全部内容
  • seek 返回无效流位置

概要

namespace boost { namespace iostreams {

template<typename Ch, typename Mode>
class basic_null_device {
public:    
    typedef Ch                        char_type;
    typedef [implementation-defined]  category;

    basic_null_device();
    std::streamsize read(char_type* s, std::streamsize n);
    std::streamsize write(const char_type* s, std::streamsize n);
    stream_offset seek( stream_offset off, std::ios_base::seekdir way,
                        std::ios_base::openmode which =
                            std::ios_base::in | std::ios_base::out );
    void close();
};

} } // End namespace boost::io
