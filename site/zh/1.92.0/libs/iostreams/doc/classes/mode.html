类模板 mode_of

说明
头文件

说明

元函数, 返回与 Filter 或 Device 概念之某种模型的 模式 相对应的 模式标签.

头文件

<boost/iostreams/traits.hpp>

参考

概要

namespace boost { namespace iostreams {

template<typename T>
struct mode_of {
    typedef see below type;
};

} } // End namespace boost::io

模板参数

T- Filter 或 Device 概念之某种模型的模型

mode_of::type

    typedef implementation-defined type;

最派生的 模式标签, category_of<T>::type 可转换到该标签. 若不存在这样的最派生标签, 则发生编译期错误.

分配给标准库类型的模式显示在下表中.

Tcategory
std::basic_iostream 的特化, 或派生自这样的特化 seekable
std::basic_istream 的特化, 或派生自这样的特化 input_seekable
std::basic_ostream 的特化, 或派生自这样的特化 output_seekable
std::basic_streambuf 的特化, 或派生自这样的特化 seekable
std::back_insert_iterator 的特化, 或派生自这样的特化 output
