概述

类模板 basic_gzip_compressor 与 basic_gzip_decompressor 基于 GZIP 格式 ([Deutsch3]), 使用 Jean-loup Gailly 与 Mark Adler 的 zlib 压缩库 ([Gailly]) 执行压缩与解压. 它们实现为 Zlib 过滤器 的派生类. GZIP 与 ZLIB 格式的区别在于: GZIP 中的数据包含更多的头部信息和不同的校验和 ([Deutsch1], [Deutsch3]).

目前, basic_gzip_compressor 是 DualUseFilters, 但 basic_gzip_compressor 只是 InputFilter.

致谢

gzip 过滤器受到了 Jeff Garland ([Garland]) 与 Jonathan de Halleux ([de Halleux]) 工作的影响.

感谢 Jean-loup Gailly 与 Mark Adler 以 Boost 兼容 许可证向公众提供其出色的库.

参考

命名空间 boost::iostreams::gzip

命名空间 boost::iostreams::gzip 包含用于配置 gzip 过滤器和报告错误的整数常量. 各常量的含义如下. (更多细节参见 [Deutsch3].)

常量时间含义
zlib_error 发生了 zlib 错误; 使用 gzip_error::zlib_error_code 获取错误码.
bad_crc 记录的 crc 与数据不符.
bad_length 记录的长度与数据不符.
bad_header 文件头格式错误.
bad_footer 压缩数据之后的文件部分格式错误.

类 gzip_params

说明

封装用于配置 basic_gzip_compressor 与 basic_gzip_decompressor 的参数.

概要

struct gzip_params : zlib_params {

    // Non-explicit constructor.
    gzip_params( int level              = default value,
                 int method             = default value,
                 int window_bits        = default value, 
                 int mem_level          = default value, 
                 int strategy           = default value,
                 std::string file_name  = "",
                 std::string comment    = "",
                 std::time_t mtime      = 0 );

    std::string  file_name;
    std::string  comment;
    std::time_t  mtime;
};

gzip_params::gzip_params

    gzip_params( int level              = default value,
                 int method             = default value,
                 int window_bits        = default value, 
                 int mem_level          = default value, 
                 int strategy           = default value,
                 std::string file_name  = "",
                 std::string comment    = "",
                 std::time_t mtime      = 0 );

构造一个 gzip_params 对象, 各参数的含义如下:
level- 压缩级别. 必须等于 zlib::default_compression 或在范围 0-9 内取值. 值 0 表示不压缩, 而 9 表示最佳压缩比. 仅影响压缩.
method- 压缩方法. 必须等于 zlib::deflated. 仅影响压缩.
window_bits- 窗口大小以 2 为底的对数. 必须在 8-15 范围内; 默认为 15.
mem_level- 指定要使用的内存量. 必须在 1-9 范围内; 默认为 8. 仅影响压缩.
strategy- 必须为 zlib::default_strategy、zlib::filtered 或 zlib::huffman_only. 仅影响压缩.
file_name- 表示 GZIP 头部中包含文件名的可选部分.
comment- 表示 GZIP 头部中包含注释的可选部分.
mtime- 表示 GZIP 头部中包含文件修改时间的可选部分.

更多细节参见 [Gailly] 与 [Deutsch1].

Class template basic_gzip_compressor

说明

DualUseFilter 的模型, 以 GZIP 格式 ([Deutsch3]) 压缩数据.

概要

template<typename Alloc = std::allocator<char> >
struct basic_gzip_compressor {
    typedef char                    char_type;
    typedef implementation-defined  category;

    basic_gzip_compressor( const gzip_params& = zlib::default_compression,
                           std::streamsize buffer_size = default value );

    // DualUseFilter members.
};

typedef basic_gzip_compressor<> gzip_compressor;

模板参数

Alloc- C++ 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区并配置 zlib.

basic_gzip_compressor::basic_gzip_compressor

    basic_gzip_compressor( const gzip_params& = zlib::default_compression,
                           std::streamsize buffer_size = default value );

用给定参数和缓冲区大小构造一个 basic_gzip_compressor 实例. 由于 gzip_params 对象可以从表示压缩级别的 int 隐式构造, 因此可将 int 作为第一个构造函数参数传入.

类 gzip_error

说明

由 gzip 过滤器用于报告错误.

概要

class gzip_error : public std::ios_base::failure {
public:
    gzip_error(int error);
    gzip_error(const zlib_error& e);
    int error() const;
    int zlib_error_code() const;
};

gzip_error::gzip_error

    gzip_error(int error);
    gzip_error(const zlib_error& e);

第一个成员构造一个 gzip_error 实例, 使用来自命名空间 boost::iostreams::gzip 的给定错误码. 第二个成员构造一个 gzip_error 实例, 基于 zlib_error 的实例.

gzip_error::error

    void error() const;

返回一个来自命名空间 boost::iostreams::gzip 的错误码.

    void zlib_error_code() const;

返回一个来自命名空间 boost::iostreams::zlib 的错误码. 仅当 error() 返回常量 boost::iostreams::gzip::zlib_error 时才有意义.

示例

以下代码从文件解压数据并写入标准输出. 
#include <fstream>
#include <iostream>
#include <boost/iostreams/filtering_streambuf.hpp>
#include <boost/iostreams/copy.hpp>
#include <boost/iostreams/filter/gzip.hpp>

int main() 
{
    using namespace std;

    ifstream file("hello.gz", ios_base::in | ios_base::binary);
    boost::iostreams::filtering_streambuf<input> in;
    in.push(gzip_decompressor());
    in.push(file);
    boost::iostreams::copy(in, cout);
}

安装

gzip 过滤器依赖第三方 zlib 库, 该库不包含在 Boost 发行包中. 预编译的 zlib 二进制文件在多数 UNIX 及类 UNIX 系统上都有提供, Boost 构建系统会自动找到它们. Windows 用户可在 zlib 主页 获取预编译的二进制文件. 用户也可以配置 Boost Iostream 库从源代码构建 zlib, 源代码可在 zlib 主页获取. 关于如何配置构建系统以找到你的 zlib 安装, 请参见 安装.
