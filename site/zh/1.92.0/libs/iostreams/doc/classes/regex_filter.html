说明

类模板 basic_regex_filter 使用 Boost 正则表达式库 ([Maddock]) 的正则表达式执行文本替换.

每个 basic_regex_filter 存储一个正则表达式和一个格式化函数. 在扫描未过滤数据以查找匹配时, 落在正则表达式匹配之间的数据部分会原样转发. 每当发现一个匹配, 相应的 match_results 对象就被传给格式化函数, 其返回值将替代被匹配的文本被转发.

用户可以构造 basic_regex_filter 的实例, 既可以从 格式化函数 出发, 也可以从 格式串 出发.

由于正则表达式可能需要在字符序列中向前查看任意远, basic_regex_filter 派生自 aggregate_filter, 并一次性处理整个数据序列.

头文件

<boost/iostreams/filter/regex.hpp>

安装

模板 basic_regex_filter 使用 Boost 正则表达式库, 该库必须单独构建. 详情参见 此处.

参考

概要

namespace boost { namespace iostreams {

#include <boost/function.hpp>
#include <boost/regex.hpp>

template< typename Ch,
          typename Tr = regex_traits<Ch>,
          typename Alloc = std::allocator<Ch> >
class basic_regex_filter
    : public aggregate_filter<Ch, std::char_traits<Ch>, Alloc> // Exposition only
{   
public:
    typedef boost::function1<
                std::basic_string<Ch>, 
                const match_results<const Ch*>&
            > 
            formatter;
    basic_regex_filter( const basic_regex<Ch, Tr, Alloc>& pattern,
                        const formatter& replace,
                        regex_constants::match_flag_type flags = 
                            regex_constants::match_default );
    basic_regex_filter( const basic_regex<Ch, Tr, Alloc>& pattern,
                        const std::basic_string<Ch>& fmt,
                        regex_constants::match_flag_type flags = 
                            regex_constants::match_default,
                        regex_constants::match_flag_type fmt_flags = 
                            regex_constants::format_default );
    basic_regex_filter( const basic_regex<Ch, Tr, Alloc>& pattern,
                        const Ch* fmt,
                        regex_constants::match_flag_type flags = 
                            regex_constants::match_default,
                        regex_constants::match_flag_type fmt_flags = 
                            regex_constants::format_default );
};

typedef basic_regex_filter<char>     regex_filter;
typedef basic_regex_filter<wchar_t>  wregex_filter;

} } // End namespace boost::io

模板参数

Ch- 字符类型
Tr- 正则表达式特征类型
Alloc- 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区

basic_regex_filter::formatter

    typedef boost::function1<
                std::basic_string<Ch>, 
                const match_results<const Ch*>&
            > 
            formatter;

basic_regex_filter 用来确定给定正则表达式匹配之替换文本的对象类型. 每当发现一个匹配, 相应的 match_results 对象就被传给 formatter, 由其返回适当的替换文本. 由于 Boost.Function 对象可以从具有正确签名的函数对象隐式构造, 正则表达式过滤器的用户可以定义自己的具有正确签名的函数对象, 并将其传给 basic_regex_filter 构造函数 (它接受一个 formatter). 例如: 

    struct my_formatter {
        std::string operator()(const match_results<const char*>& match)
        {
            // Examine match and return the appropriate replacement text
        }
    };
    int main()
    {
        regex         pattern( ... );
        regex_filter  filter(pattern, my_formatter());
        ...
    }

basic_regex_filter::basic_regex_filter

    basic_regex_filter( const basic_regex<Ch, Tr, Alloc>& pattern,
                        const formatter& replace,
                        regex_constants::match_flag_type flags = 
                            regex_constants::match_default );

由给定的正则表达式、格式化函数和匹配标志构造一个 basic_regex_filter. 各参数的含义如下:

pattern- 与未过滤数据流进行匹配的正则表达式
replace- 一个函数, 会依次接收每个 match_results 对象, 其返回值将被用作替换文本
flags- 用于构造 regex_iterator 

    basic_regex_filter( const basic_regex<Ch, Tr, Alloc>& pattern,

由给定的正则表达式、格式串和一对匹配标志构造一个 basic_regex_filter. 各参数的含义如下:

pattern- 与未过滤数据流进行匹配的正则表达式
fmt- 一个 格式串, 为每个正则表达式匹配指定替换文本, 使用 match_results::format
flags- 用于构造 regex_iterator
fmt_flags- flags 实参, 传递给 match_results::format
