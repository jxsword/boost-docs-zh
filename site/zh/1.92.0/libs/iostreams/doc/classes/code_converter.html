说明

The class templates code_converter is a Device adapter which takes a Device with a narrow character type — typically char — and produces a Device with wide character type — typically wchar_t — by introducing a layer of code conversion. The code conversion is performed using a std::codecvt facet which can either be specified as a template parameter or be fetched from a std::locale provided at runtime.

例如, 我们可以如下定义一个从内存映射文件读取的宽字符设备: 

    #include <boost/iostreams/maped_file.hpp>

    typedef code_converter<mapped_file_source> my_source;
类似地, 我们可以如下定义一个将多字节字符写入内存中字符序列的宽字符设备: 
    #include <boost/iostreams/device/array.hpp>

    typedef code_converter<array_sink> my_sink;

模式 按如下规则由 code_converter 的特化确定. 若窄字符设备是只读的, 所得 code_converter 特化的模式为 input. 若窄字符设备是只写的, 所得 code_converter 特化的模式为 output. 若窄字符设备使用两个不同的序列执行输入与输出 (参见 模式), 所得 code_converter 特化的模式为 bidirectional. 否则, 尝试特化 code_converter 会导致编译期错误.

参考

概要

namespace boost { namespace iostreams {

template< typename Device, 
          typename Codecvt = default_value
          typename Alloc = std::allocator<char> >
class code_converter {
public:
    typedef typename Codecvt::intern_type  char_type;
    typedef implementation-defined         category;
    code_converter();
    code_converter( const Device& dev, 
                    int buffer_size = default_value );
    code_converter( device-constructor-args...,
                    int buffer_size = default_value );
    void open( const Device& dev, 
               int buffer_size = default_value );
    void open( device-constructor-args...,
               int buffer_size = default_value );
    bool is_open() const;
    void close();
    std::locale imbue(const std::locale& loc);
    Device& operator*();
    Device* operator->();
};

} } // End namespace boost::io

模板参数

Device- 某种 设备 概念的模型; 其 字符类型 通常为 char.
Codecvt- 标准库 codecvt 刻面, 必须可默认构造. 若未指定此参数, 则 std::codecvt<wchar_t, char, std::mbstate_t> 实例将在构造或打开 code_converter 时从全局 locale 中获取.
Alloc- 标准库分配器类型 ([ISO], 20.1.5), 用于分配字符缓冲区

code_converter::code_converter

    code_converter();
    code_converter( const Device& dev, 
                    int buffer_size );
    code_converter( device-constructor-args..., 
                    int buffer_size );

第一个成员构造一个 code_converter, 不关联任何设备类型 Device 的实例. 在该实例可用于 I/O 之前, 必须调用成员函数 open().

第二个成员构造一个 code_converter, 基于给定的 Device 实例. 第二个参数决定用于代码转换的缓冲区的大小. 若已将 std::codecvt 指定为模板参数, 则会默认构造它的一个实例; 否则将复制全局的 locale, 并从中获取一个 std::codecvt<wchar_t, char, std::mbstate_t> 实例.

第三个成员构造一个 code_converter, 基于以转发参数构造的给定 Device 实例. 需注意, 若 buffer_size 不是 int, 它可能被误认成构造函数参数.

code_converter::imbue

    std::locale imbue(const std::locale& loc);

用于指定一个 locale, 在进行代码转换时将从该 locale 获取 std::codecvt 刻面. 在代码转换进行期间调用 imbue 的效果是未定义的.

若已将 std::codecvt 刻面指定为模板参数, 则此函数为空操作.

code_converter::open

     void open( const Device& dev,
                std::streamsize buffer_size = default_value );
     void open( device-constructor-args,
                std::streamsize buffer_size = default_value );

若当前没有已关联的此类实例, 则将给定的 Device 实例关联到 this 这个 code_converter 实例; 否则抛出 std::ios_base::failure. 第二个参数决定用于代码转换的缓冲区的大小. 若已将 std::codecvt 指定为模板参数, 则会默认构造它的一个实例; 否则将复制全局的 locale, 并从中获取一个 std::codecvt<wchar_t, char, std::mbstate_t> 实例.

第二个成员以转发参数构造一个 Device. 需注意, 若 buffer_size 不是 int, 它可能被误认成构造函数参数.

code_converter::is_open

    bool is_open() const;

若存在设备类型 Device 的实例, 与 this 这个 code_converter 实例相关联, 则返回 true.

code_converter::close

    void close();

解除 this 这个 code_converter 实例与当前关联的设备类型 Device 实例之间的关联, 视情况调用清理函数并销毁相关联的 Device 实例.

code_converter::operator*

    Device& operator*();

返回对与此 code_converter 实例相关联的设备实例的引用, 该实例必须处于 open 状态.

code_converter::operator->

    Device* operator->();

返回指向与此 code_converter 实例相关联的设备实例的指针, 该实例必须处于 open 状态.
