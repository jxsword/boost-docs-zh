致谢

1.35

在 1.35 版发布前的修正与优化过程中, 众多用户为 Boost.Iostreams 提交了缺陷报告和补丁. Frank Birbacher 与 Chad Walters 在诊断和修复缺陷、敦促作者恢复对该库的积极维护方面功不可没, 在此特别致谢.

1.33

本库的最初构想源自 Angelika Langer 与 Klaus Kreft 所著 Standard C++ IOStreams and Locales 一书中的示例流缓冲实现 ([Langer]). Robert Ramey 建议扩展本库以支持过滤. 此外:

  • stream_buffer 的实现得益于 Angelika Langer 与 Klaus Kreft 的工作 ([Langer], pp. 228-43).
  • 过滤流缓冲概念由 James Kanze 与 Dietmar Kühl 提出. 参见 [Kanze].
  • 概念 InputFilter 与 OutputFilter 的灵感来自 James Kanze 的 extractors 与 inserters. 此外, 组件 filtering_stream 与 filtering_streambuf 的命名借自 Kanze, 教程中的若干过滤器亦然. 参见 [Kanze].
  • 管道由 Jan Christiaan van Winkel 与 John van Krieken 引入. 参见 [van Winkel]. Dietmar Kühl 建议为 Iostreams 库添加这一功能.
  • 向过滤链添加迭代器范围与输出迭代器的机制, 灵感来自 Maxim Egorushkin 的工作. 参见 [Egorushkin].
  • 用于访问 内存映射文件 的设备基于 Craig Henderson 的工作; 参见 ([Henderson]). Jonathan Graehl 添加了若干实用特性.
  • 用于访问 文件描述符 的设备基于 Nicolai Josuttis 的工作 ([Josuttis1] 与 [Josuttis2]).
  • 数组设备与 null 设备的灵感来自 Dayle Walker 的工作.
  • 压缩与解压过滤器受到了 Jeff Garland ([Garland]) 与 Jonathan de Halleux ([de Halleux]) 工作的影响.
  • 模板 basic_stdio_filter 的灵感来自 Christopher Diggins 的工作. 参见 [Diggins].
  • 对 64 位 流偏移量 的处理由 Gareth Sylvester-Bradley 提出, 他还提供了与 Dinkumware 标准库配套使用的定位函数实现.
  • 模板 restiction 由 David Abrahams 建议. 参见 [Abrahams2].
  • Maxim Egorushkin、Larry Evans、George M. Garner、Jonathan Graehl、Robert Ramey、Rob Stewart、John Torjo、Pavel Vozenilek 与 Carlo Woods 对该库的多个版本提出了大量批评意见.
  • Angelika Langer 与 James Kanze 对异常在 Iostream 库中的恰当角色提供了宝贵见解.
  • Robert Ramey 为 Boost.Serialization 编写的文档, 是本文档中所用 Javascript 树形控件 的灵感来源.
  • Jeff Garland 担任评审经理, 并提供了有益的批评与指导.
