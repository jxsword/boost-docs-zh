引言

作为 C++ 标准库一部分的 C++ 标准模板库 (STL) 提供了在不同类型容器上执行算法的框架. 然而, 普通数组不提供 STL 容器的接口 (尽管它们提供 STL 容器的迭代器接口).

作为普通数组的替代, STL 提供了类 std::vector. 然而, std::vector<> 提供的是动态数组的语义, 即它管理数据以能够改变元素数量. 这在只需要静态大小数组的情况下会带来一些开销.

Matthew H. Austern 在其著作 Generic Programming and the STL 中介绍了一个用于静态大小普通数组的实用封装类, 称为 block. 它比普通数组更安全, 性能也不逊色. Bjarne Stroustrup 在 The C++ Programming Language 第 3 版中介绍了一个类似的类, 称为 c_array, 我 (Nicolai Josuttis) 在我的书 The C++ Standard Library - A Tutorial and Reference 中以略作修改的形式介绍了它, 称为 carray. 这里融合了这些方法的精髓, 并加入了来自 Boost 的许多反馈.

在考虑了不同的名称之后, 我们决定把这个类简单地命名为 array.

注意, 该类被建议作为下一个技术报告 (Technical Report) 的一部分, 该报告将扩展 C++ 标准 (见 http://www.open-std.org/jtc1/sc22/wg21/docs/papers/2003/n1548.htm).

更新: std::array (自 C++11 起) 已成为 C++ 标准的一部分. boost::array 与 std::array 之间的差异极小. 如果你使用 C++11, 应考虑用 std::array 替代 boost::array.

类 array 满足"可逆容器"的大部分但非全部要求 (见 C++ 标准第 23.1 节 [lib.container.requirements]). array 不是可逆 STL 容器的原因如下:

  • 不提供构造函数.

  • 元素可能具有未确定的初始值 (见 "设计理由"一节).

  • swap() 不具有常量复杂度.

  • size() 总是常量的, 取决于该类型的第二个模板实参.

  • 该容器不提供分配器支持.

它不满足"序列"的要求 (见 C++ 标准第 23.1.1 节 [lib.sequence.reqmts]), 除了:

  • front() 和 back() 均已提供.

  • operator[] 和 at() 均已提供.

修订历史

1.88.0 中的变更

  • 将文档转换为 AsciiDoc (Christian Mazakas).

  • 适当地添加了 noexcept 和 constexpr.

  • 把过时的函数标记为弃用.

  • 移除了过时的编译器变通方案.

  • 更改 array<T, 0>::begin()、cbegin()、end() 和 cend() 使其返回 nullptr, 从而启用 constexpr. 这与 std::array 的行为一致.

  • 移除了本地的 hash_value 重载; boost::hash 原生支持类数组的类型.

  • array<T, 0> 现在可以用 = {{}} 初始化.

  • 添加了 operator<=>.

  • 添加了 to_array.

类模板 array

概要

// In header: <boost/array.hpp>

template<typename T, std::size_t N>
class array {
public:

  // types

  typedef T                                     value_type;
  typedef T*                                    iterator;
  typedef const T*                              const_iterator;
  typedef std::reverse_iterator<iterator>       reverse_iterator;
  typedef std::reverse_iterator<const_iterator> const_reverse_iterator;
  typedef T&                                    reference;
  typedef const T&                              const_reference;
  typedef std::size_t                           size_type;
  typedef std::ptrdiff_t                        difference_type;

  // static constants

  static const size_type static_size = N;

  // construct/copy/destroy

  template<typename U> array& operator=(const array<U, N>&);

  // iterator support

  constexpr iterator begin() noexcept;
  constexpr const_iterator begin() const noexcept;
  constexpr const_iterator cbegin() const noexcept;

  constexpr iterator end() noexcept;
  constexpr const_iterator end() const noexcept;
  constexpr const_iterator cend() const noexcept;

  // reverse iterator support

  reverse_iterator rbegin() noexcept;
  const_reverse_iterator rbegin() const noexcept;
  const_reverse_iterator crbegin() const noexcept;

  reverse_iterator rend() noexcept;
  const_reverse_iterator rend() const noexcept;
  const_reverse_iterator crend() const noexcept;

  // capacity

  static constexpr size_type size() noexcept;
  static constexpr bool empty() noexcept;
  static constexpr size_type max_size() noexcept;

  // element access

  constexpr reference operator[](size_type);
  constexpr const_reference operator[](size_type) const;

  constexpr reference at(size_type);
  constexpr const_reference at(size_type) const;

  constexpr reference front();
  constexpr const_reference front() const;

  constexpr reference back();
  constexpr const_reference back() const;

  constexpr T* data() noexcept;
  constexpr const T* data() const noexcept;

  T* c_array() noexcept; // deprecated

  // modifiers

  swap(array<T, N>&);

  constexpr void fill(const T&);
  void assign(const T&); // deprecated

  // public data members
  T elems[N];
};

template<typename T, std::size_t N>
  constexpr auto operator<=>(const array<T, N>& x, const array<T, N>& y)
  -> decltype(x[0] <=> y[0]);
效果:

对每个 i ∈ [0..N), 若 (x[i] <=> y[i]) != 0, 则返回 x[i] <=> y[i]; 否则返回转换为返回类型的 std::strong_ordering::equal.
备注:

当 N 为 0 时, 返回类型为 std::strong_ordering, 返回值为 std::strong_ordering::equal.

设计理由

关于构造函数有一个重要的设计权衡: 我们可以把 array 实现为"聚合" (见 C++ 标准第 8.5.1 节 [dcl.init.aggr]). 这意味着:

  • 可以用以花括号括起、以逗号分隔的初始化器列表来初始化数组, 其中按递增下标顺序列出容器各元素的初始化器:

    boost::array<int,4> a = { { 1, 2, 3 } };

    注意, 如果初始化器列表中的元素较少, 则其余每个元素都会被默认初始化 (因此它有一个确定的值).

然而, 这种方法有其缺点: 不传初始化器列表意味着元素具有未确定的初始值, 因为规则规定聚合可以:

  • 没有用户声明的构造函数.

  • 没有私有或受保护的非静态数据成员.

  • 没有基类.

  • 没有虚函数.

尽管如此, 当前实现仍采用这种方法.

注意, 对于符合标准的编译器, 可以使用更少的花括号 (依据标准 8.5.1 (11)). 也就是说, 你可以像下面这样初始化数组:

boost::array<int,4> a = { 1, 2, 3 };
