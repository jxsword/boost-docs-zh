ostream

返回一个把值格式化写入 DynamicBuffer 的输出流.

概要

定义于头文件 <boost/beast/core/ostream.hpp> 

template<
    class DynamicBuffer>
implementation-defined
ostream(
    DynamicBuffer& buffer);
说明

此函数把调用者提供的 DynamicBuffer 包装进 std::ostream 派生类, 以允许 operator<< 流风格的格式化操作.

示例 
ostream(buffer) << "Hello, world!" << std::endl;
备注

在输出流销毁之前调用底层缓冲区的成员会导致未定义行为.

参数

名称

说明

buffer

一个满足 DynamicBuffer 要求的对象, 格式化输出将被放入其中.
返回值

一个派生自 std::ostream 并重定向输出的对象. 被包装的动态缓冲区不会被修改, 而是制作副本. 底层内存的所有权不发生转移, 应用程序仍负责管理其生存期. 调用者负责确保动态缓冲区在输出流的生存期内不被销毁.
