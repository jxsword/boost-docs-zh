websocket::stream::auto_fragment (1 of 2 overloads)

设置自动分片选项.

概要 
void
auto_fragment(
    bool value);
说明

决定传出的报文载荷是否被拆分为多个片段.

开启自动分片大小后, 传出的报文载荷会被拆分成多个不大于写缓冲区大小的帧.

默认设置为对报文分片.

参数

名称

说明

value

一个 bool, 指示是否应开启自动分片.
示例

设置自动分片选项:

ws.auto_fragment( true );
