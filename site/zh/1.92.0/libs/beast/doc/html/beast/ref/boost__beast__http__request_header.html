http::request_header

典型的 HTTP 请求头.

概要

定义于头文件 <boost/beast/http/message.hpp> 

template<
    class Fields = fields>
using request_header = header< true, Fields >;

此容器派生自 Fields 模板类型. 要了解此类的全部成员, 需要查看 Fields 类型的声明. 使用默认字段容器时, 这些声明位于 fields.

新构造的报文头对象的 version 被设为 HTTP/1.1. 新构造的响应对象的 result code 也被设为 status::ok.

一个 header 包含起始行和头字段.
