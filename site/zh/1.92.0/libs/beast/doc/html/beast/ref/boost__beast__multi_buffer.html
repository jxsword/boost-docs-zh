友元

名称

说明

swap

交换两个动态缓冲区.

动态缓冲区封装了一块可按需自动调整大小的内存存储, 其中内存被划分为两个区域: 可读字节后跟可写字节. 这些内存区域是动态缓冲区内部的, 但提供了对元素的直接访问, 使其能够高效地与 I/O 操作配合使用.

实现使用一个由一个或多个大小不一的字节数组组成的序列来表示可读与可写字节. 会向序列追加额外的字节数组对象, 以适应期望大小的变化. 此 outbound 容器的行为与实现最接近于 std::deque.

此类型的对象满足 DynamicBuffer 的要求, 并具有以下附加性质:

  • 当 data 为非 const 时, this 返回表示可读字节的可变缓冲区序列.
  • 由 data 与 prepare 返回的、表示可读与可写字节的缓冲区序列, 长度可能大于一.
  • 构造时可设置可配置的最大大小, 之后可再调整. 超过此大小的 prepare 调用将抛出 std::length_error.
  • 先前使用 data 获得的序列在调用 prepare 或 commit 之后仍然有效.
