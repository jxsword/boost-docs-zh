http::basic_parser::on_request_impl

在收到请求行之后调用.

概要 
void
on_request_impl(
    verb method,
    string_view method_str,
    string_view target,
    int version,
    error_code& ec);
说明

解析 HTTP 请求期间, 收到请求行之后会调用此虚函数. 只有在 isRequest == true 时才能调用它.

参数

名称

说明

method

动词枚举. 如果方法字符串不是预定义字符串之一, 此值将为 verb::unknown.

method_str

表示动词的未经修改的字符串.

target

请求目标 (request-target).

version

HTTP 版本. HTTP/1.0 为 10, HTTP/1.1 为 11.

ec

函数可以设置的输出参数, 用于指示错误. 在调用此函数之前错误会被清除.
