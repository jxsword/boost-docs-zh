http::status_class

表示状态码的类别.

概要

定义于头文件 <boost/beast/http/status.hpp> 

enum status_class
取值

名称

说明

unknown

未知状态类别.

informational

已收到请求, 继续处理.

successful

请求已被成功接收、理解并接受.

redirection

需要采取进一步操作才能完成请求.

client_error

请求包含错误语法或无法完成.

server_error

服务器未能完成明显有效的请求.
