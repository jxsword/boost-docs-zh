websocket::stream::async_ping

异步发送 websocket ping 控制帧.

概要 
template<
    class PingHandler = net::default_completion_token_t<executor_type>>
DEDUCED
async_ping(
    ping_data const& payload,
    PingHandler&& handler = net::default_completion_token_t< executor_type >{});
说明

此函数用于异步发送一个 ping 帧, 这通常会引发对端自动回复一个 pong 控制帧.

  • ping 帧已写入.
  • 发生错误.

该算法称为 组合异步操作, 是通过调用下一层的 async_write_some 函数. 程序必须确保在此操作完成之前, 没有对 ping, pong, async_ping 或 async_pong 的其他调用.

如果在 ping 帧发送之前发送或收到了关闭帧, 此完成处理器收到的错误将是 net::error::operation_aborted.

参数

名称

说明

payload

ping 报文的载荷, 可以为空. 发起函数返回后, 实现不会再访问此对象的内容.

handler

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
    error_code const & ec     // Result of operation
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将通过派发到立即执行器完成. 若未指定立即执行器, 这等同于使用 net::post.
逐操作取消

此异步操作支持以下 net::cancellation_type 值的取消:

  • net::cancellation_type::terminal
  • net::cancellation_type::total

total: 若操作因正在进行的控制操作 (如 ping/pong) 而挂起, 则取消会成功.

terminal: 在底层流支持时, 取消会成功.

terminal: 取消会使流处于未定义状态, 此时只有关闭操作保证能成功.
