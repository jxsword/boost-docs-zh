http::make_chunk_last (2 of 2 overloads)

返回一个 chunk_last.

概要

定义于头文件 <boost/beast/http/chunk_encode.hpp> 

template<
    class Trailer,
    class... Args>
chunk_last< Trailer >
make_chunk_last(
    Trailer const& trailer,
    Args&&... args);
说明

此函数构造并返回一个完整的 chunk_last, 对应包含指定 trailer 的最后一个分块.

参数

名称

说明

trailer

一个 ConstBufferSequence 或
备注

提供此函数是为了书写方便, 可省略类模板参数的指定.

参数

名称

说明

args

传递给 chunk_last 构造函数的可选参数.
