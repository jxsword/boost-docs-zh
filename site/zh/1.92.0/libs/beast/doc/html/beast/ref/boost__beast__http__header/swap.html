http::header::swap

(继承自 http::basic_fields)

返回表示尾部字段的缓冲区序列.

概要 
void
swap(
    basic_fields& other);
说明

此函数返回一个缓冲区序列, 其中保存 Accept 字段中承诺的尾部字段的序列化表示. 在调用此函数之前, Accept 字段必须包含所需的精确尾部字段, 且每个字段都必须存在. 将此容器与另一个容器交换
