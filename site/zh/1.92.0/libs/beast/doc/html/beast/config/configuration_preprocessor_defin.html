Configuration Preprocessor Definitions配置用预处理器定义

许多配置用预处理器定义可用于改变 Beast 的行为. 用户应当假定它们会给本库 API 的公开部分带来重大变更, 并确保编译并链接进程序的所有翻译单元 (通常是文件) 都使用相同的配置宏组合; 否则可能违反 ODR (单一定义规则) .

表 1.14. 特殊字段

定义

说明

BOOST_BEAST_SEPARATE_COMPILATION

启用分离编译模式, 允许用户在单个翻译单元中编译非模板实体的定义, 从而提高编译速度. 该翻译单元必须包含 boost/beast/src.hpp 才能编译这些定义.

BOOST_BEAST_ALLOW_DEPRECATED

允许在 Beast 中使用已弃用的 API.

BOOST_BEAST_FILE_BUFFER_SIZE

设置 file_body 使用的小缓冲区大小. 默认为 4096.
