websocket::stream::write_some (2 of 2 overloads)

写入部分报文数据.

概要 
template<
    class ConstBufferSequence>
std::size_t
write_some(
    bool fin,
    ConstBufferSequence const& buffers,
    error_code& ec);
说明

此函数用于发送报文的一部分.

调用将阻塞, 直到以下条件之一成立:

  • 报文数据已写入.
  • 发生错误.

该算法称为 composed operation, 它以对下一层 write_some 函数的调用实现.

如果这是新报文的开始, 报文操作码将根据 binary (或 text 选项的当前设置设为文本或二进制. 实际发送的载荷可能会根据 WebSocket 协议设置进行变换.

此函数在成功完成时总是写入一个完整的 WebSocket 帧 (而非 WebSocket 报文) , 因此在此操作完成之后执行 ping、pong 和 close 操作是良定义的.

参数

名称

说明

fin

true (若这是报文的最后一部分) .

buffers

包含要发送报文部分的缓冲区.

ec

用于指示发生了何种错误 (如无错误则不设置) .
返回值

从缓冲区发送的字节数.

返回值

输入缓冲区中被消费的字节数.
