basic_stream::async_write_some

异步写入一些数据.

概要 
template<
    class ConstBufferSequence,
    class WriteHandler = net::default_completion_token_t<Executor>>
DEDUCED
async_write_some(
    ConstBufferSequence const& buffers,
    WriteHandler&& handler = net::default_completion_token_t< Executor >{});
说明

此函数用于向底层套接字异步写入数据.

此调用总是立即返回. 异步操作将持续到以下条件之一成立:

  • 向流写入一个或多个字节.
  • 发生错误.

该算法称为 composed asynchronous operation, 它以对下一层 async_write_some 函数的调用实现. 程序必须确保在本操作完成之前不执行对 async_write_some 的其他调用.

若超时定时器在操作未完成期间到期, 操作将被取消, 完成处理器将以错误 error::timeout 被调用.

参数

名称

说明

buffers

数据要写出的缓冲区. 若缓冲区大小为零字节, 操作总是立即完成且无错误. 尽管 buffers 对象可按需复制, 底层内存块的所有权仍由调用者保留, 调用者必须保证它们在处理器被调用之前保持有效.

handler

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
    error_code error,               // Result of operation.
    std::size_t bytes_transferred   // Number of bytes written.
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将通过派发到立即执行器完成. 若未指定立即执行器, 这等同于使用 net::post.
备注

async_write_some 操作可能不会传输所请求的全部字节数. 若需要确保在异步操作完成之前发送所请求的数据量, 请考虑使用函数 net::async_write.

逐操作取消

此异步操作支持以下 net::cancellation_type 值的取消:

  • net::cancellation_type::terminal
  • net::cancellation_type::partial
  • net::cancellation_type::total

(前提是套接字的 async_write_some 操作同样支持它们. )
