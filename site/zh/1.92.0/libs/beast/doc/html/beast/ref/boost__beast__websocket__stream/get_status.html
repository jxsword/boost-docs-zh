websocket::stream::get_status

获取 permessage-deflate 扩展的状态.

概要 
void
get_status(
    permessage_deflate_status& status) const;
说明

用于在 WebSocket 握手之后检查 permessage-deflate 扩展的状态.

参数

名称

说明

status

对一个 permessage_deflate_status 对象, 状态将存储在其中.
示例

检查 permessage-deflate 扩展的状态:

permessage_deflate_status status;
ws.get_status(status);
