zlib::deflate_stream::params

更新压缩级别与策略.

概要 
void
params(
    z_params& zs,
    int level,
    Strategy strategy,
    error_code& ec);
说明

此函数动态更新压缩级别与压缩策略. level 和 strategy 的含义同 reset. 这可用于在压缩与直接复制输入数据之间切换, 或切换到需要不同策略的另一类输入数据. 若压缩级别发生变化, 目前已有的输入将按旧级别压缩 (并可能被刷新) ; 新级别只会在下一次调用 write.

在调用 params 之前, 流状态必须设置为如同调用 write 时的状态, 因为当前可用的输入可能需要被压缩并刷新. 特别是, zs.avail_out 必须非零.

返回值

Z_OK (成功时) , Z_STREAM_ERROR (源流状态不一致或参数无效时) , error::need_buffers if zs.avail_out 为零.
