zlib::Flush

Flush 选项.

概要

定义于头文件 <boost/beast/zlib/zlib.hpp> 

enum Flush
取值

名称

说明

none

无策略.

block

Flush: 在位边界上输出所有待决输出, 并保留至多七位.

partial

Flush: 在位边界上输出所有待决输出.

sync

Flush: 在字节边界上输出所有待决输出.

full

Flush: 在字节边界上输出所有待决输出并重置状态.

finish

以单步压缩剩余输入.

trees

Flush 输出, 同 Flush::block, 或在每个 deflate 块头的末尾.
说明

允许用于 deflate_stream::write 和 inflate_stream::write 函数.

详情请参见 deflate_stream::write 和 inflate_stream::write.

参见

deflate_stream::write, inflate_stream::write
