http::parser::merge_all_trailers (2 of 2 overloads)

设置是否允许解析器合并所有尾部字段.

概要 
void
merge_all_trailers(
    bool v);
说明

默认情况下, 解析器只合并一组众所周知的尾部字段. 启用此选项后, 解析器会合并报文头部分中 Trailer 头字段列出的所有尾部字段.

备注

如果处理不受信任的输入且报文头部分中的 Trailer 头字段未经过适当验证, 启用此选项可能带来安全风险.

默认值为 false, 即只合并以下众所周知的尾部字段:

  • Digest
  • Content-Digest
  • Repr-Digest
  • Signature
  • Signature-Input
  • Server-Timing
  • ETag
  • Link
  • Alt-Svc
参数

名称

说明

v

true 表示合并所有尾部字段, false 表示只合并众所周知的字段.
