buffers_prefix

返回常量或可变缓冲区序列的前缀.

概要

定义于头文件 <boost/beast/core/buffers_prefix.hpp> 

template<
    class BufferSequence>
buffers_prefix_view< BufferSequence >
buffers_prefix(
    std::size_t size,
    BufferSequence const& buffers);
说明

返回的缓冲区序列指向与传入缓冲区序列相同的内存, 但大小相同或更小. 不执行内存分配; 结果序列按惰性范围计算.

参数

名称

说明

size

返回的缓冲区序列的最大大小 (字节) . 若此值大于等于传入缓冲区序列的大小, 结果将与原缓冲区序列大小相同.

buffers

一个类型满足 BufferSequence 要求的对象. 返回的值将在其生存期内保存传入缓冲区的一份副本; 但底层内存的所有权不被转移.
返回值

表示原缓冲区序列前缀的常量缓冲区序列. 若原缓冲区序列也满足 MutableBufferSequence 的要求, 则返回的值也将是可变缓冲区序列.
