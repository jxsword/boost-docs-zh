async_write

把 BuffersGenerator 的所有输出异步写入流.

概要

定义于头文件 <boost/beast/core/buffers_generator.hpp> 

template<
    class AsyncWriteStream,
    class BuffersGenerator,
    class CompletionToken = net::default_completion_token_t<executor_type<AsyncWriteStream>>>
DEDUCED
async_write(
    AsyncWriteStream& stream,
    BuffersGenerator generator,
    CompletionToken&& token = net::default_completion_token_t< executor_type< AsyncWriteStream > >{});
说明

此函数用于把调用者提供的 BuffersGenerator 生成的所有缓冲区写入流. 函数调用总是立即返回. 异步操作将持续到以下条件之一成立:

  • 对生成器的 is_done 的调用返回 false.
  • 发生错误.

此操作以对流的 async_write_some 的零次或多次调用实现, 称为 composed operation. 程序必须确保在本操作完成之前流不执行其他写入.

参数

名称

说明

stream

数据要写入的流. 该类型必须支持 SyncWriteStream 概念.

generator

要使用的生成器.

token

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
    error_code const & error,        // result of operation
    std::size_t bytes_transferred   // the number of bytes written to the stream
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将以与使用 net::post 等效的方式进行.
