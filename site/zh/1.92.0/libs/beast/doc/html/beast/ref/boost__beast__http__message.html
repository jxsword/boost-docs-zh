http::message

用于完整 HTTP 报文的容器.

概要

定义于头文件 <boost/beast/http/message.hpp> 

template<
    bool isRequest,
    class Body,
    class Fields = fields>
class message :
    public http::header< isRequest, fields >

说明

此容器派生自 Fields 模板类型. 要了解此类的全部成员, 需要查看 Fields 类型的声明. 使用默认字段容器时, 这些声明位于 fields.

报文可以是请求或响应, 取决于 isRequest 模板参数的值. 请求和响应具有不同的类型; 如有需要, 函数可以基于该类型进行重载.

Body 模板参数类型决定用于读取或写入报文内容正文的模型.

新构造的报文对象的 version 被设为 HTTP/1.1. 新构造的响应对象的 result code 也被设为 status::ok.

模板参数

类型

说明

isRequest

如果此对象表示请求, 则为 true; 如果表示响应, 则为 false. 某些类数据成员是否存在取决于此值.

Body

满足 Body 要求的类型.

Fields

用于保存字段值对的容器类型.
