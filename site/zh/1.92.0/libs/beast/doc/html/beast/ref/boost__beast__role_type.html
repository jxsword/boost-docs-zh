role_type

本地或远端对端的角色.

概要

定义于头文件 <boost/beast/core/role.hpp> 

enum role_type
取值

名称

说明

client

流作为客户端运行.

server

流作为服务器运行.
说明

端点是客户端还是服务器会影响 teardown 的行为. teardown 行为还取决于被拆解的流的类型.

常规 TCP/IP 套接字的默认 teardown 实现如下:

  • 在客户端角色中, 会在读取连接上所有剩余数据之后发送 TCP/IP shutdown.
  • 在服务器角色中, 会在读取连接上所有剩余数据之前发送 TCP/IP shutdown.

当下层类型是 net::ssl::stream 时, 连接通过执行与角色类型 (客户端或服务器) 相应的 SSL 关闭握手来关闭.
