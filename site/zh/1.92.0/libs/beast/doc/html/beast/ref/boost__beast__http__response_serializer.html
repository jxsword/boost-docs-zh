http::response_serializer

HTTP/1 响应的序列化器.

概要

定义于头文件 <boost/beast/http/serializer.hpp> 

template<
    class Body,
    class Fields = fields>
using response_serializer = serializer< false, Body, Fields >;

此类型的对象用于把完整的 HTTP 报文序列化为八位组序列. 要使用此类, 请用要序列化的报文构造一个实例. 如果报文内容表明需要分块编码, 实现会自动执行分块编码.

序列化器产生的分块输出绝不包含分块扩展或 trailer, 且分块边界的位置未作规定. 如果调用者需要分块扩展、trailer 或对每个分块确切内容的控制, 应使用序列化器只写出报文头, 然后使用分块缓冲区序列类型 chunk_body、chunk_crlf、chunk_header 和 chunk_last 接管分块载荷的序列化.

备注

在首次调用 serializer::next 之后移动或复制序列化器会导致未定义行为. 如果需要在多个异步操作之间移动序列化器 (例如, 在调用 async_write_header 与 async_write 之间), 请尝试在堆上分配序列化器对象.
