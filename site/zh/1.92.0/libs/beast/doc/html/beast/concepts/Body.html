Body

Body 类型作为模板参数提供给 message 类. 它同时控制生成的报文对象数据成员的类型, 以及解析和序列化期间使用的算法.

关联类型

  • BodyReader
  • BodyWriter

语义, 前置/后置条件

B::value_type

message::body 成员函数的返回类型. 若它不可移动或不可复制, 包含它的报文也将不可移动或不可复制.

B::reader

若存在, 表示该正文可以被解析. 该类型必须满足 BodyReader. 实现会构造此类型的对象, 以获取用于存放解析出的正文八位组的缓冲区.

B::writer

若存在, 表示该正文是可序列化的. 该类型必须满足 BodyWriter. 实现会构造此类型的对象, 以获取表示报文正文用于序列化的缓冲区.

 
B::size(
  B::value_type body)

std::uint64_t

这个静态成员函数是可选的. 它返回 body 的载荷大小 (以字节计) , 不包括任何分块传输编码. 返回值可以为零, 表示已知该报文没有载荷. 该函数不得通过异常退出.

当该函数存在时:

* 该函数不得失败

* 调用 message::payload_size 将返回与 size 相同的值.

* 调用 message::prepare_payload 将在 "chunked" 作为最后一个编码出现时将其从 Transfer-Encoding 字段中移除, 并将 Content-Length 字段设置为返回的值.

否则, 当该函数被省略时:

* 调用 message::payload_size 将返回 boost::none.

* 调用 message::prepare_payload 将擦除 Content-Length 字段, 并在 Transfer-Encoding 字段尚未包含 "chunked" 时将其作为最后一个编码加入.

范例 
struct Body
{
    // The type of message::body when used
    struct value_type;

    /// The algorithm used during parsing
    class reader;

    /// The algorithm used during serialization
    class writer;

    /// Returns the body's payload size
    static
    std::uint64_t
    size(value_type const& body);
};

static_assert(is_body<Body>::value, "");
