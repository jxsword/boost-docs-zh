zlib::compression

压缩级别.

概要

定义于头文件 <boost/beast/zlib/zlib.hpp> 

enum compression
取值

名称

说明

none

best_speed

best_size

default_size

说明

压缩级别从 0 到 9: 1 速度最快, 9 压缩率最高.

压缩级别 0 完全不压缩, 输入数据只是逐块复制.

压缩级别 6 通常是速度与压缩率之间的默认折中.
