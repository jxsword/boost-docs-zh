websocket::stream_base::timeout::suggested

以某个角色的建议值构造超时设置.

概要 
static
timeout
suggested(
    role_type role);
说明

此构造函数以随所需角色而变化的预定义值集构造超时设置. 这些值在构造时选定, 与流上当前或实际使用的角色无关.

示例

此语句把流的超时设置设为服务器角色的建议值:

参数

名称

说明

role

websocket 流的角色 (role_type::client 或 role_type::server).
