http::parser::put

(继承自 http::basic_parser)

向解析器写入缓冲区序列.

概要 
template<
    class ConstBufferSequence>
std::size_t
put(
    ConstBufferSequence const& buffers,
    error_code& ec);
说明

此函数尝试对存储在调用者提供的缓冲区中的 HTTP 报文数据进行增量解析. 成功时, 正的返回值表示解析器取得了前进, 消耗了相应数量的字节.

某些情况下, 输入缓冲区中的八位组数量可能不足以取得前进. 这由代码 error::need_more 指示. 发生这种情况时, 调用者应把更多字节放入缓冲区序列, 并再次调用 put.

错误码 error::need_more 比较特殊. 当返回此错误时, 如果缓冲区已更新, 后续对 put 的调用可能成功. 否则, 发生错误后解析器可能无法重新启动.

参数

名称

说明

buffers

一个满足 ConstBufferSequence 要求的对象, 表示下一段报文数据. 如果此缓冲区序列的长度为 1, 实现将不会分配额外内存. 类 beast::basic_flat_buffer 是满足此要求的一种方式

ec

若发生了错误, 则设置为该错误.
返回值

缓冲区序列中被消耗的八位组数量. 即使设置了错误, 调用者也应移除这些八位组.
