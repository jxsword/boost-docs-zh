saved_handler::maybe_invoke

有条件地调用已存储的完成处理器.

概要 
bool
maybe_invoke();
说明

如果 this->has_value() == true , 则调用已存储的完成处理器; 否则什么也不做. 在调用已存储的完成处理器之前, 会释放所有已使用的动态内存. 调用之前还会重置执行器工作守卫.

返回值

如果发生了调用, 则为 true.
