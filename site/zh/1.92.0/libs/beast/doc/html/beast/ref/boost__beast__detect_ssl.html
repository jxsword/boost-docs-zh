detect_ssl

在流上检测 TLS 客户端握手.

概要

定义于头文件 <boost/beast/core/detect_ssl.hpp> 

template<
    class SyncReadStream,
    class DynamicBuffer>
bool
detect_ssl(
    SyncReadStream& stream,
    DynamicBuffer& buffer,
    error_code& ec);
说明

此函数从流读取, 以确定是否正在接收客户端握手消息.

调用将阻塞, 直到以下条件之一成立:

  • 检测到 TLS 客户端起始握手,
  • 接收到的数据对 TLS 客户端握手无效, 或
  • 发生错误.

该算法称为 composed operation, 它以对下一层 read_some 函数的调用实现.

从流读取的字节将存储在传入的动态缓冲区中; 若检测器返回 true, 该缓冲区可用于执行 TLS 握手, 否则调用者可根据预期协议消费它.

参数

名称

说明

stream

要读取的流. 此类型必须满足 SyncReadStream 的要求.

buffer

要使用的动态缓冲区. 此类型必须满足 DynamicBuffer 的要求.

ec

设置发生的错误 (如有) .
返回值

true (若缓冲区包含 TLS 客户端握手且未发生错误) , 否则为 false.
