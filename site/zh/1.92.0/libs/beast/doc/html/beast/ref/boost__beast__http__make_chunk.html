http::make_chunk

返回一个 chunk_body.

概要

定义于头文件 <boost/beast/http/chunk_encode.hpp> 

template<
    class ConstBufferSequence,
    class... Args>
chunk_body< ConstBufferSequence >
make_chunk(
    ConstBufferSequence const& buffers,
    Args&&... args);
说明

此函数构造并返回一个完整的 chunk_body, 对应由指定缓冲区序列表示的分块正文.

参数

名称

说明

buffers

表示分块正文的缓冲区.

args

传递给 chunk_body 构造函数的可选参数.
备注

提供此函数是为了书写方便, 可省略类模板参数的指定.
