说明

此解析器旨在高效解析 HTTP/1 线格式的报文. 当输入以单个连续缓冲区呈现时, 它不分配内存, 且使用最少的状态. 它会处理分块编码, 并理解 Connection、Content-Length 和 Upgrade 字段的语义. 解析器针对输入缓冲区序列由单个连续缓冲区组成的情况进行了优化. 提供了 beast::basic_flat_buffer 类, 它保证流缓冲区的输入序列恰好由一个连续缓冲区表示. 为确保解析器的最佳性能, 请将 beast::basic_flat_buffer 与 read、read_some、async_read 和 async_read_some 等 HTTP 算法配合使用. 或者, 调用者可以使用自定义技术来确保 HTTP 报文的结构化部分 (报文头或分块头) 包含在一个线性缓冲区中.

解析器的接口使用虚成员函数. 要使用此类, 请从 basic_parser 派生你的类型. 当提供字节时, 实现会进行零次或多次虚函数调用, 派生类必须实现这些虚函数.

每个虚函数都必须由派生类提供, 否则将产生编译错误. 实现会确保在每次调用虚函数之前 ec 已被清除. 如果虚函数设置了错误, 该错误会从解析器传播给调用者.

模板参数

类型

说明

isRequest

一个 bool, 指示解析器将接收请求报文还是响应报文.
备注

如果解析器遇到长度超过 4KB 的带 obs-fold 的字段值, 则产生错误.
