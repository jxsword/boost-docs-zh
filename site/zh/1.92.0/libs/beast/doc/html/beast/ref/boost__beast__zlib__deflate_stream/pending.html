zlib::deflate_stream::pending

返回输出中待决的位.

概要 
void
pending(
    unsigned* value,
    int* bits);
说明

此函数返回已生成但尚未在可用输出中提供的输出字节数和位数. 未提供的字节是因为可用输出空间已被耗尽. 未提供的输出位数在 0 到 7 之间, 这些位等待更多位加入以凑满一个完整字节. 若 pending 或 bits 为 nullptr, 则不设置这些值.

返回值

Z_OK (成功时) , 或 Z_STREAM_ERROR (源流状态不一致时) .
