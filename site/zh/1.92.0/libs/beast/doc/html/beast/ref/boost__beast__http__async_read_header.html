http::async_read_header

使用解析器从流异步读取完整的报文头.

概要

定义于头文件 <boost/beast/http/read.hpp> 

template<
    class AsyncReadStream,
    class DynamicBuffer,
    bool isRequest,
    class ReadHandler = net::default_completion_token_t<            executor_type<AsyncReadStream>>>
DEDUCED
async_read_header(
    AsyncReadStream& stream,
    DynamicBuffer& buffer,
    basic_parser< isRequest >& parser,
    ReadHandler&& handler = net::default_completion_token_t< executor_type< AsyncReadStream > >{});
说明

此函数用于把来自流的完整报文头异步读入一个 basic_parser 实例. 函数调用总是立即返回. 异步操作将持续进行, 直到以下条件之一成立:

  • basic_parser::is_header_done 返回 true
  • 发生错误.

此操作通过零次或多次调用下一层的 async_read_some 函数实现, 称为 组合操作. 程序必须保证流在此操作完成之前不执行其他读取. 实现可能从流中读出超出所读报文末尾的额外字节. 这些额外字节存储在动态缓冲区中, 必须为其后的读取保留.

如果从流读取时收到文件结束错误, 则此函数返回的错误将是:

  • error::end_of_stream, 如果没有解析出任何字节; 或
  • error::partial_message, 如果解析出一些字节但报文不完整; 否则:
  • 一次成功的结果. 下一次读取尝试将返回 error::end_of_stream
参数

名称

说明

stream

要从中读取数据的流. 该类型必须满足 AsyncReadStream 要求.

buffer

用于存放实现从流中读取的额外字节的存储空间. 这既是输入参数也是输出参数; 进入时, 解析器会先拿到动态缓冲区可读字节序列中剩余的数据. 该类型必须满足 DynamicBuffer 要求. 对象必须至少保持有效直到处理器被调用; 所有权不发生转移.

parser

要使用的解析器. 对象必须至少保持有效直到处理器被调用; 所有权不发生转移.

handler

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
    error_code const & error,        // result of operation
    std::size_t bytes_transferred   // the number of bytes consumed by the parser
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将以与使用 net::post 等效的方式进行.
备注

实现会对传入的解析器调用 basic_parser::eager, 传入值 false.

逐操作取消

此异步操作支持以下 net::cancellation_type 值的取消:

  • net::cancellation_type::terminal

如果 stream 还支持终止取消, terminal 取消会使流处于未定义状态, 此时只有关闭它才保证成功.
