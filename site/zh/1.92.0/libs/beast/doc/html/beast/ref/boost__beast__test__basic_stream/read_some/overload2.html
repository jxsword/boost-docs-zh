test::basic_stream::read_some (2 of 2 overloads)

从流读取一些数据.

概要 
template<
    class MutableBufferSequence>
std::size_t
read_some(
    MutableBufferSequence const& buffers,
    error_code& ec);
说明

该函数用于从流中读取数据. 函数调用将阻塞, 直到成功读取一个或多个字节的数据, 或者发生错误.

参数

名称

说明

buffers

用于读入数据的缓冲区.

ec

用于指示发生了何种错误 (如无错误则不设置) .
返回值

读取的字节数.

备注

read_some 操作可能不会读取全部请求字节数. 如果需要确保在阻塞操作完成之前读取所请求数量的数据, 请考虑使用函数 net::read.
