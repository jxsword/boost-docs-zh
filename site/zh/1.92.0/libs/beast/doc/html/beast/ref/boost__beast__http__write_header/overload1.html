http::write_header (1 of 2 overloads)

使用序列化器把报文头写入流.

概要

定义于头文件 <boost/beast/http/write.hpp> 

template<
    class SyncWriteStream,
    bool isRequest,
    class Body,
    class Fields>
std::size_t
write_header(
    SyncWriteStream& stream,
    serializer< isRequest, Body, Fields >& sr);
说明

此函数使用调用者提供的 HTTP/1 序列化器把报文头写入流. 调用将阻塞, 直到以下条件之一成立:

  • 函数 serializer::is_header_done 返回 true
  • 发生错误.

此操作通过一次或多次调用流的 write_some 函数实现.

参数

名称

说明

stream

数据要写入的流. 该类型必须支持 SyncWriteStream 概念.

sr

要使用的序列化器.
返回值

写入流的字节数.

异常

类型

抛出时机

[link beast.ref.boost__beast__system_error system_error]

失败时抛出.
备注

实现会对传入的序列化器调用 serializer::split, 传入值 true.
