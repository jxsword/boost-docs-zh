http::buffer_body

使用调用者提供缓冲区的 Body.

概要

定义于头文件 <boost/beast/http/buffer_body.hpp> 

struct buffer_body
类型

名称

说明

reader

用于解析正文的算法.

value_type

在报文中使用时 body 成员的类型.

writer

用于序列化正文的算法.
说明

使用此正文类型的报文可以被序列化和解析. 要使用此类, 调用者必须在流操作期间每次调用读或写之前, 把 buffer_body::value_type 的成员初始化为适当的值.
