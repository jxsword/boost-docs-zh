http::header::result (1 of 3 overloads)

响应状态码结果.

概要 
status
result() const;
说明

如果实际状态码不是已知状态码, 此函数返回 status::unknown. 请使用 result_int 以数字形式返回原始状态码.

备注

此成员仅在 isRequest == false 时可用.
