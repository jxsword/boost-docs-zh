http::string_to_field

尝试把字符串转换为字段枚举.

概要

定义于头文件 <boost/beast/http/field.hpp> 

field
string_to_field(
    string_view s);
说明

字符串比较不区分大小写.

返回值

对应的字段, 若没有已知字段匹配则为 field::unknown.
