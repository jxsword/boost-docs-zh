flat_static_buffer::reset

重置所指向的缓冲区.

概要 
void
reset(
    void* p,
    std::size_t n);
说明

此函数把内部状态重置为所提供的缓冲区. 所有输入和输出序列都会失效. 此函数允许派生类在初始化静态缓冲区之前先构造其成员.

参数

名称

说明

p

指向至少 n 字节有效存储空间的指针.

n

p 所指向的有效字节数.
异常安全

不抛出异常保证.
