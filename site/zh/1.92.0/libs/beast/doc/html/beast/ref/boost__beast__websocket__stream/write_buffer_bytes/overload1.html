websocket::stream::write_buffer_bytes (1 of 2 overloads)

设置写缓冲区大小选项.

概要 
void
write_buffer_bytes(
    std::size_t amount);
说明

设置实现发送帧所用的写缓冲区大小. 在客户端角色下掩蔽载荷数据、压缩帧或对报文数据自动分片时需要写缓冲区.

减小缓冲区大小可以降低每个连接的内存需求, 增大缓冲区大小则可以减少为写入数据而对下一层发起的调用次数.

默认设置为 4096. 最小值为 8.

写缓冲区大小只能在流未打开时更改. WebSocket 握手成功后修改此选项会导致未定义行为.

示例

设置写缓冲区大小.

ws.write_buffer_bytes(8192);
参数

名称

说明

amount

写缓冲区的大小 (字节) .
