http::chunk_header::chunk_header (3 of 5 overloads)

构造函数.

概要 
template<
    class ChunkExtensions>
chunk_header(
    std::size_t size,
    ChunkExtensions&& extensions);
说明

这会构造一个表示 chunked-body 大小和结尾 CRLF ("\r\n") 的缓冲区序列, 带有提供的分块扩展. 默认分配器用于为扩展对象提供存储.

参数

名称

说明

size

后续分块正文的大小. 该值必须大于零.

extensions

分块扩展对象. 表达式 extensions.str() 必须有效, 且返回类型必须可转换为 string_view. 此对象会按需被复制或移动, 以确保分块头对象保留分块扩展对象所提供缓冲区的所有权.
备注

仅当 ChunkExtensions 满足上述要求时, 此函数才参与重载决议.

参见

https://tools.ietf.org/html/rfc7230#section-4.1
