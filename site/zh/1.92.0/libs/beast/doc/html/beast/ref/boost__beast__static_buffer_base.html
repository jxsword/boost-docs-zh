static_buffer_base [constructor]

构造函数.
说明

动态缓冲区封装了一块可按需自动调整大小的内存存储, 其中内存被划分为两个区域: 可读字节后跟可写字节. 这些内存区域是动态缓冲区内部的, 但提供了对元素的直接访问, 使其能够高效地与 I/O 操作配合使用.

此类型的对象满足 DynamicBuffer 的要求, 并具有以下附加性质:

  • 当 data 为非 const 时, this 返回表示可读字节的可变缓冲区序列.
  • 由 data 和 prepare 返回的、表示可读和可写字节的缓冲区序列, 长度最多可达 2.
  • 所有操作都在常数时间内执行.
  • 底层存储的所有权属于派生类.
备注

变量通常使用模板类 static_buffer 来声明; 但是, 为减少模板实例化的数量, 对象应以 static_buffer_base& 的形式传递.
