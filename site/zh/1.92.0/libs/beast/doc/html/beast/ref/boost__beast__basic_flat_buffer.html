说明

动态缓冲区封装了一块可按需自动调整大小的内存存储, 其中内存被划分为两个区域: 可读字节后跟可写字节. 这些内存区域是动态缓冲区内部的, 但提供了对元素的直接访问, 使其能够高效地与 I/O 操作配合使用.

此类型的对象满足 DynamicBuffer 的要求, 并具有以下附加性质:

  • 当 data 为非 const 时, this 返回表示可读字节的可变缓冲区序列.
  • 构造时可设置可配置的最大缓冲区大小. 超出缓冲区大小的尝试将抛出 std::length_error.
  • 由 data 与 prepare 返回的、表示可读与可写字节的缓冲区序列, 其类型将为 net::const_buffer 或 net::mutable_buffer.

构造时可指定缓冲区的最大大小. 若超出此限制, 将抛出 std::length_error 异常.

备注

此类设计用于以动态缓冲区为参数的算法, 并针对输入序列或输出序列存储在单个连续缓冲区中的情形做了优化.
