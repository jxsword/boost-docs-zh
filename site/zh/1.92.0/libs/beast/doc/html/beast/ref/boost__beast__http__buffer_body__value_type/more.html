http::buffer_body::value_type::more

如果这不是最后一个缓冲区, 则为 true.

概要 
bool more = true;
说明
序列化时

如果此值为 true 且 data 为 nullptr, 错误 error::need_buffer 将从 serializer::get 返回

解析时

此字段在解析期间不使用.
