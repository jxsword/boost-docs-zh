websocket::error

由 boost::beast::websocket::stream 操作返回的错误码.

概要

定义于头文件 <boost/beast/websocket/error.hpp> 

enum error
取值

名称

说明

closed

WebSocket 流在两端都被优雅地关闭.

buffer_overflow

WebSocket 操作导致动态缓冲区溢出.

partial_deflate_block

WebSocket 流产出了不完整的 deflate 块.

message_too_big

WebSocket 报文超过了本地配置的限制.

bad_http_version

WebSocket 握手不是 HTTP/1.1.

具有此值的错误码将与 condition::handshake_failed

bad_method

WebSocket 握手的方法不是 GET.

具有此值的错误码将与 condition::handshake_failed

no_host

WebSocket 握手缺少 Host 字段.

具有此值的错误码将与 condition::handshake_failed

no_connection

WebSocket 握手缺少 Connection 字段.

具有此值的错误码将与 condition::handshake_failed

no_connection_upgrade

WebSocket 握手的 Connection 字段缺少 upgrade 令牌.

具有此值的错误码将与 condition::handshake_failed

no_upgrade

WebSocket 握手缺少 Upgrade 字段.

具有此值的错误码将与 condition::handshake_failed

no_upgrade_websocket

WebSocket 握手的 Upgrade 字段缺少 websocket 令牌.

具有此值的错误码将与 condition::handshake_failed

no_sec_key

WebSocket 握手缺少 Sec-WebSocket-Key 字段.

具有此值的错误码将与 condition::handshake_failed

bad_sec_key

WebSocket 握手的 Sec-WebSocket-Key 字段无效.

具有此值的错误码将与 condition::handshake_failed

no_sec_version

WebSocket 握手缺少 Sec-WebSocket-Version 字段.

具有此值的错误码将与 condition::handshake_failed

bad_sec_version

WebSocket 握手的 Sec-WebSocket-Version 字段无效.

具有此值的错误码将与 condition::handshake_failed

no_sec_accept

WebSocket 握手缺少 Sec-WebSocket-Accept 字段.

具有此值的错误码将与 condition::handshake_failed

bad_sec_accept

WebSocket 握手的 Sec-WebSocket-Accept 字段无效.

具有此值的错误码将与 condition::handshake_failed

upgrade_declined

WebSocket 握手被远程对端拒绝.

具有此值的错误码将与 condition::handshake_failed

bad_opcode

WebSocket 帧包含非法操作码.

具有此值的错误码将与 condition::protocol_violation

bad_data_frame

WebSocket 数据帧是意外的.

具有此值的错误码将与 condition::protocol_violation

bad_continuation

WebSocket 续帧是意外的.

具有此值的错误码将与 condition::protocol_violation

bad_reserved_bits

WebSocket 帧包含非法的保留位.

具有此值的错误码将与 condition::protocol_violation

bad_control_fragment

WebSocket 控制帧被分片.

具有此值的错误码将与 condition::protocol_violation

bad_control_size

WebSocket 控制帧大小无效.

具有此值的错误码将与 condition::protocol_violation

bad_unmasked_frame

WebSocket 帧未做掩蔽.

具有此值的错误码将与 condition::protocol_violation

bad_masked_frame

WebSocket 帧带了掩码.

具有此值的错误码将与 condition::protocol_violation

bad_size

WebSocket 帧大小不是规范形式.

具有此值的错误码将与 condition::protocol_violation

bad_frame_payload

WebSocket 帧载荷不是有效的 UTF-8.

具有此值的错误码将与 condition::protocol_violation

bad_close_code

WebSocket 关闭帧的原因码无效.

具有此值的错误码将与 condition::protocol_violation

bad_close_size

WebSocket 关闭帧的载荷大小无效.

具有此值的错误码将与 condition::protocol_violation

bad_close_payload

WebSocket 关闭帧的载荷不是有效的 UTF-8.

具有此值的错误码将与 condition::protocol_violation
