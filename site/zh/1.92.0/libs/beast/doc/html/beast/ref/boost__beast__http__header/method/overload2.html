http::header::method (2 of 2 overloads)

设置请求方法.

概要 
void
method(
    verb v);
说明

此函数会把请求的方法设置为已知动词.

参数

名称

说明

v

要设置的请求方法动词. 不能为 verb::unknown.
异常

类型

抛出时机

std::invalid_argument

当 v == verb::unknown 时.
备注

此函数仅在 isRequest == true 时可用.
