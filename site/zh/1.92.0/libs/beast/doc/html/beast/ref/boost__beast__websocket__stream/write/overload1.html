websocket::stream::write (1 of 2 overloads)

写入完整报文.

概要 
template<
    class ConstBufferSequence>
std::size_t
write(
    ConstBufferSequence const& buffers);
说明

此函数用于写入完整报文.

调用将阻塞, 直到以下条件之一成立:

  • 报文已写入.
  • 发生错误.

该算法称为 composed operation, 它以对下一层 write_some 函数的调用实现.

选项 binary 的当前设置控制报文操作码是文本还是二进制. 如果设置了 auto_fragment 选项, 报文将按需拆分成一或多帧. 实际发送的载荷内容可能会根据 WebSocket 协议设置进行变换.

名称

说明

buffers

包含要发送报文的缓冲区.
返回值

从缓冲区发送的字节数.
