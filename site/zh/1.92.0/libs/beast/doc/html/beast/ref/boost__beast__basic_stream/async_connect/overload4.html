basic_stream::async_connect (4 of 5 overloads)

通过异步尝试端点序列中的每个端点来建立连接.

概要 
template<
    class Iterator,
    class IteratorConnectHandler = net::default_completion_token_t<executor_type>>
DEDUCED
async_connect(
    Iterator begin,
    Iterator end,
    IteratorConnectHandler&& handler = net::default_completion_token_t< executor_type >{});
说明

此函数通过逐个尝试端点序列中的端点, 尝试把流连接到其中一个端点, 直到成功建立连接. 底层套接字在需要时自动打开. 自动打开的套接字在失败时不会回到关闭状态.

该算法称为 composed asynchronous operation, 它以对底层套接字 async_connect 函数的调用实现.

若超时定时器在操作未完成期间到期, 当前的连接尝试将被取消, 完成处理器将以错误 error::timeout 被调用.

参数

名称

说明

begin

指向端点序列起始处的迭代器.

end

指向端点序列末尾的迭代器.

handler

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
    // Result of operation. if the sequence is empty, set to
    // net::error::not_found. Otherwise, contains the
    // error from the last connection attempt.
    error_code const & error,

    // On success, an iterator denoting the successfully
    // connected endpoint. Otherwise, the end iterator.
    Iterator iterator
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将通过派发到立即执行器完成. 若未指定立即执行器, 这等同于使用 net::post.
逐操作取消

此异步操作支持以下 net::cancellation_type 值的取消:

  • net::cancellation_type::terminal
  • net::cancellation_type::partial
  • net::cancellation_type::total

(前提是套接字的 async_connect 操作同样支持它们. )
