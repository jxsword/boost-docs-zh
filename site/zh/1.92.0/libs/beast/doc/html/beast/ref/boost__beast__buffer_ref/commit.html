buffer_ref::commit

把字节从输出序列移至输入序列.

概要 
void
commit(
    std::size_t n);
说明
参数

名称

说明

n

从输出序列起始处追加到输入序列末尾的字节数. 输出序列的其余部分将被丢弃.

要求事先调用 prepare(x) 且其中 x >= n, 并且期间没有修改输入或输出序列的操作.

备注

如果 n 大于输出序列的大小, 则整个输出序列被移动到输入序列, 且不发出任何错误.
