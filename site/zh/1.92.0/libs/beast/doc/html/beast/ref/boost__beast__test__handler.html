说明

此完成处理器用于测试以保证行为正确性. 它设计为单一类型以减少模板实例化, 并可通过构造函数实参进行配置. 通常此类型会出现在类型列表中而不被直接实例化; 此类的实例由下面列出的辅助函数返回.

参见
