bind_front_handler

把参数绑定到完成处理器, 创建一个新处理器.

概要

定义于头文件 <boost/beast/core/bind_handler.hpp> 

template<
    class Handler,
    class... Args>
implementation-defined
bind_front_handler(
    Handler&& handler,
    Args&&... args);
说明

此函数创建一个新处理器, 被调用时以绑定的参数列表调用原始处理器. 调用时传入的任何参数将在绑定参数之后的参数列表中转发.

传入的处理器与参数被转发到返回的处理器中, 其关联分配器与关联执行器将与原始处理器相同.

示例

此函数以绑定的参数 post 指定完成处理器的调用:

template < class AsyncReadStream, class ReadHandler>
void
signal_eof (AsyncReadStream& stream, ReadHandler&& handler)
{
    net::post(
        stream.get_executor(),
        bind_front_handler (std::forward<ReadHandler> (handler),
            net::error::eof, 0));
}
参数

名称

说明

handler

要包装的处理器. 实现通过衰减复制取得处理器的所有权.

args

要绑定到处理器的参数列表. 参数被转发到返回的对象中.
