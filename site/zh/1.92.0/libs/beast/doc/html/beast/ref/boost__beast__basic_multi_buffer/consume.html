basic_multi_buffer::consume

从可读字节的开头移除字节.

概要 
void
consume(
    size_type n);
说明

从可读字节的开头移除 n 个字节.

先前使用 data 或 prepare 获得的所有缓冲区序列都将失效.

参数

名称

说明

n

要移除的字节数. 若该数大于可读字节数, 则移除所有可读字节.
异常安全

不抛出异常保证.
