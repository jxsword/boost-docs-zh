stable_async_base::allocate_stable

分配一个临时对象来保存操作状态.

概要

定义于头文件 <boost/beast/core/async_base.hpp> 

template<
    class State,
    class Handler,
    class Executor1_,
    class Allocator_,
    class... Args>
State&
allocate_stable(
    stable_async_base< Handler_, Executor1_, Allocator_ >& base,
    Args&&... args);
说明

该对象将在完成处理器被调用之前销毁, 或在操作基类被销毁时销毁.
