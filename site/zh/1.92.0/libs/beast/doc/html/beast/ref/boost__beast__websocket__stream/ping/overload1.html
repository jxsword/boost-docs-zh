websocket::stream::ping (1 of 2 overloads)

发送 websocket ping 控制帧.

概要 
void
ping(
    ping_data const& payload);
说明

此函数用于发送一个 ping 帧, 这通常会引发对端自动回复一个 pong 控制帧.

调用将阻塞, 直到下列条件之一成立:

  • ping 帧已写入.
  • 发生错误.

该算法称为 composed operation, 它以对下一层 write_some 函数的调用实现.
