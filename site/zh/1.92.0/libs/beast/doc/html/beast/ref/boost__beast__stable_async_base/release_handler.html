stable_async_base::release_handler

(继承自 async_base)

返回与此对象关联的处理器的所有权.

概要 
Handler
release_handler();
说明

此函数用于通过移动构造把处理器的所有权转移给调用者. 移动之后, 基对象上唯一有效的操作是移动构造与析构.
