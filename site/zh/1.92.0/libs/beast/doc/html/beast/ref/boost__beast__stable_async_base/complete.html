stable_async_base::complete

(继承自 async_base)

调用最终完成处理器, 可能使用 post.

概要 
template<
    class... Args>
void
complete(
    bool is_continuation,
    Args&&... args);
说明

它以转发的指定参数调用最终完成处理器. 多次调用 boost::beast::async_base::complete 或 boost::beast::async_base::complete_now 中的任何一个都是未定义行为.

用 boost::beast::allocate_stable 分配的任何临时对象都将在最终完成处理器被调用之前自动销毁.

参数

名称

说明

is_continuation

若此值为 false, 则处理器将通过 net::dispatch 提交到立即执行器. 若处理器没有立即执行器, 将通过 net::post 提交到执行器. 否则处理器将被调用, 如同调用 boost::beast::async_base::complete_now.

args

用于调用处理器的可选参数列表. 完成处理器必须能以该参数列表调用, 否则将导致编译错误.
