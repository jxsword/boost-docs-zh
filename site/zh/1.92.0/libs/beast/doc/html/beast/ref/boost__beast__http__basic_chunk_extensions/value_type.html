http::basic_chunk_extensions::value_type

迭代时的值类型.

概要 
using value_type = std::pair< string_view, string_view >;
说明

对的第一个元素是名称, 第二个元素是值, 值可以为空. 值以其原始表示存储, 不带引号或转义.
