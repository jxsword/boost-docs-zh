buffers_to_string

返回表示缓冲区序列内容的字符串.

概要

定义于头文件 <boost/beast/core/buffers_to_string.hpp> 

template<
    class ConstBufferSequence>
std::string
buffers_to_string(
    ConstBufferSequence const& buffers);
说明

此函数返回表示整个缓冲区序列的字符串. 缓冲区序列中的空字符与不可打印字符将按原样插入结果字符串. 不执行任何字符转换.

参数

名称

说明

buffers

要转换的缓冲区序列
示例

此函数把转换为字符串的缓冲区序列写入 std::cout.

template < class ConstBufferSequence>
void print(ConstBufferSequence const & buffers)
{
    std::cout << buffers_to_string(buffers) << std::endl;
}
