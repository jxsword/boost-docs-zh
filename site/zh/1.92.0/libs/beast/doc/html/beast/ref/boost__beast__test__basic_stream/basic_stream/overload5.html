test::basic_stream::basic_stream (5 of 7 overloads)

构造流.

概要 
basic_stream(
    net::io_context& ioc,
    fail_count& fc);
说明

流将以断开状态创建.

参数

名称

说明

ioc

该 io_context 对象, 流将用它来分派任何异步操作的处理器.

fc

该 fail_count 与流关联. 在流上执行的每个 I/O 操作都会使失败计数递增. 当失败计数达到其内部上限时, 将产生一个模拟失败错误.
