iequals

如果两个字符串相等 (使用不区分大小写的比较), 则返回 true.

概要

定义于头文件 <boost/beast/core/string.hpp> 

bool
iequals(
    beast::string_view lhs,
    beast::string_view rhs);
说明

大小写比较操作仅对低 ASCII 字符有定义.

参数

名称

说明

lhs

相等比较左侧的字符串

rhs

相等比较右侧的字符串
