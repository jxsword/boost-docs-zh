http::message::equal_range (2 of 2 overloads)

(继承自 http::basic_fields)

返回指向具有指定名称的字段的迭代器范围.

概要 
std::pair< const_iterator, const_iterator >
equal_range(
    string_view name) const;
说明

此函数返回指向具有指定名称的有序字段的第一个和最后一个迭代器.

备注

该范围所表示的字段是有序的. 其元素保证与报文的字段顺序一致. 这意味着用户在比较不同报文中的同名字段时无需对此范围排序.

参数

名称

说明

name

字段名.
返回值

指向同名字段的迭代器范围, 否则为空范围.
