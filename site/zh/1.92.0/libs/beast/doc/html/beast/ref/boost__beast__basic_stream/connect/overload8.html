basic_stream::connect (8 of 10 overloads)

通过尝试端点序列中的每个端点来建立连接.

概要 
template<
    class EndpointSequence,
    class ConnectCondition>
Protocol::endpoint
connect(
    EndpointSequence const& endpoints,
    ConnectCondition connect_condition,
    error_code& ec);
说明

此函数通过逐个尝试端点序列中的端点, 尝试把流连接到其中一个端点, 直到成功建立连接. 底层套接字在需要时自动打开. 自动打开的套接字在失败时不会回到关闭状态.

该算法称为 composed operation, 它以对底层套接字 connect 函数的调用实现.

参数

名称

说明

endpoints

端点序列.

connect_condition

在每次连接尝试之前调用的函数对象. 该函数对象的签名必须为:

bool connect_condition(
    error_code const & ec,
    typename Protocol::endpoint const & next);

ec 参数包含最近一次连接操作的结果. 在第一次连接尝试之前, ec 总是被设置为指示成功. next 参数是下一个要尝试的端点. 若应尝试下一个端点, 该函数对象应返回 true; 若应跳过, 则返回 false.

ec

设置为指示发生了何种错误 (如有) . 若序列为空, 设置为 net::error::not_found. 否则包含最后一次连接尝试的错误.
返回值

成功时, 为成功连接的端点; 否则为默认构造的端点.
