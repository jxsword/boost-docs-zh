websocket::stream::binary (1 of 2 overloads)

设置二进制报文写入选项.

概要 
void
binary(
    bool value);
说明

此设置控制传出报文的操作码是二进制还是文本. 该设置只在调用方开始新报文时应用. 报文开始后更改操作码, 只会在当前正在发送的报文完成之后生效.

默认设置为发送文本报文.

参数

名称

说明

value

true (若传出的报文应指示为二进制) , 或 false (若应指示为文本) .
示例

把报文类型设置为二进制.

ws.binary( true );
