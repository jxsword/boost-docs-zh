说明

这实现了一个 raw deflate 流解压器. deflate 协议是一种压缩协议, 在 "DEFLATE Compressed Data Format Specification version 1.3" 中描述, 位置在: https://tools.ietf.org/html/rfc1951

该实现是 ZLib "inflate" 重构后的 C++ 移植. 关于 ZLib 更详细的描述见 http://zlib.net/.

如果缓冲区足够大 (例如输入文件被内存映射) , 压缩可以在单步中完成; 也可以通过反复调用压缩函数完成. 后一种情况下, 应用程序必须在每次调用之前提供更多输入和/或消费输出 (提供更多输出空间) .
