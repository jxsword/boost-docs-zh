http::basic_parser::on_finish_impl

收到完整报文时调用一次.

概要 
void
on_finish_impl(
    error_code& ec);
说明

成功解析完整的 HTTP 报文之后, 此虚函数调用一次.

参数

名称

说明

ec

函数可以设置的输出参数, 用于指示错误. 在调用此函数之前错误会被清除.
