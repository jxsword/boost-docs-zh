缓冲区类型

为便于使用 ConstBufferSequence 和 MutableBufferSequence 中介绍的 Boost.Asio, Beast 把这些序列当作一类特殊的范围. 库提供了以下算法与包装器, 以惰性求值高效地变换这些范围. 变换过程中不进行内存分配; 它们只在既有且未修改的内存缓冲区之上创建轻量迭代器. 调用方保留对缓冲区的控制权; 所有权不转移.

表 1.7. 缓冲区算法与类型

名称

说明

buffer_bytes

这是 net::buffer_size 的更可靠版本, 更易使用, 也适用于可转换为 net::const_buffer 或 net::mutable_buffer.

buffers_cat

此函数返回一个新的缓冲区序列, 迭代它将遍历把所有输入缓冲区序列拼接起来所形成的序列. 借助此例程, 对流的 write_some 函数的多次调用可以合并为一次, 消除昂贵的系统调用.

buffers_cat_view

此类表示由两个或多个缓冲区序列拼接而成的缓冲区序列. 这是 buffers_cat.

buffers_front

此函数返回缓冲区序列中的第一个缓冲区; 若序列没有元素, 则返回大小为零的缓冲区.

buffers_prefix

此函数返回表示原有缓冲区前缀的新缓冲区或缓冲区序列.

buffers_prefix_view

此类表示由既有缓冲区序列的前缀构成的缓冲区序列. 这是 buffers_prefix.

buffers_range buffers_range_ref

此函数返回表示传入缓冲区序列的可迭代范围. 迭代该范围得到的值总是常量缓冲区; 若底层缓冲区序列是可变的, 则迭代得到的值是可变缓冲区. 它旨在作为编写 range-for 语句遍历缓冲区序列时的记法便利.

函数 buffers_range 保存缓冲区序列的副本, 而 buffers_range_ref 保存引用 (此时调用方必须确保被引用缓冲区序列的生存期延续到范围对象销毁之时) .

buffers_suffix

此类包装既有缓冲区序列的底层内存, 并表示原序列的一个后缀. 后缀的长度可以逐步缩短. 这使调用方能够按顺序增量地处理缓冲区序列.

buffers_to_string

此函数把缓冲区序列转换为 std::string. 可用于诊断和测试.

buffer_ref ref

此函数把要按引用传递的 beast 缓冲区转换为缓冲区引用, 后者可以按值传入 asio 函数.

它实现了 DynamicBuffer_v2' concept.

该 DynamicBuffer concept (引入于 Boost.Asio 建模支持拥有式、可调整大小范围的缓冲区序列. Beast 为动态缓冲区 concept 提供了以下额外实现:

表 1.8. 动态缓冲区实现

名称

说明

buffers_adaptor

此包装器把任何 MutableBufferSequence 适配为 DynamicBuffer, 其输入与输出区总大小的上限等于底层可变缓冲区序列的大小. 实现不进行堆分配.

flat_buffer basic_flat_buffer

保证输入与输出区都是长度为一的缓冲区序列. 构造时可设置输入与输出区总大小的可选上限. 基本容器是 AllocatorAwareContainer.

multi_buffer basic_multi_buffer

使用一个或多个大小不等的字符数组序列. 为适应字符序列大小的变化, 会向序列追加额外的字符数组对象. 基本容器是 AllocatorAwareContainer.

flat_static_buffer flat_static_buffer_base

保证输入与输出区都是长度为一的缓冲区序列. 提供动态缓冲区的设施, 其输入与输出区总大小受 constexpr 模板参数定义的上限约束. 序列的存储保存在类中; 实现不执行堆分配.

static_buffer static_buffer_base

提供环形动态缓冲区的设施, 其输入与输出区总大小受 constexpr 模板参数定义的上限约束. 实现在缓冲区操作期间从不移动内存. 序列的存储保存在类中; 实现不执行堆分配.

这些缓冲区对已分配内存提供不同的保证; stable 意味着通过调用 data 或 prepare 获得的既有可变与常量缓冲区保持有效.

注意, 复制总是需要新的 data 和 prepare.`

这两个函数便于缓冲区与标准输出流互操作.

表 1.10. 缓冲区输出流

名称

说明

make_printable

此函数包装 ConstBufferSequence, 使其可用于 operator<< 和 std::ostream.

ostream

此函数返回一个 std::ostream, 它包装一个动态缓冲区. 使用 operator<< 发送到流的字符存储在该动态缓冲区中.

提供这些类型特征是为了便于编写对缓冲区操作的编译期元函数:

表 1.11. 缓冲区算法与类型

名称

说明

buffers_iterator_type

此元函数用于确定特定缓冲区序列所使用的迭代器类型.

buffers_type

此元函数用于确定缓冲区序列列表的底层缓冲区类型. 别名的等效类型随模板类型实参而变化.

is_const_buffer_sequence

此元函数用于判断所有指定类型是否满足 ConstBufferSequence 的要求. 若每个指定类型都满足要求, 此类型别名为 std::true_type, 否则为 std::false_type.

is_mutable_buffer_sequence

此元函数用于判断所有指定类型是否满足 MutableBufferSequence 的要求. 若每个指定类型都满足要求, 此类型别名为 std::true_type, 否则为 std::false_type.
