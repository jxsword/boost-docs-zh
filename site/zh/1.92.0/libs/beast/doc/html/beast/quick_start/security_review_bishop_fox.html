Security Review (Bishop Fox) 🎦安全评审 (Bishop Fox) 🎦

2020 年, 作为打造应用开发者可以信赖的最优秀 C++ 库这一承诺的一部分, C++ Alliance 再次委托 Bishop Fox 对 Beast 库进行复测.

报告链接如下:

Beast - Hybrid Application Assessment 2020

自 2005 年以来, Bishop Fox一直为财富 1000 强企业、高科技初创公司以及全球金融机构提供安全咨询服务. Beast 聘请 Bishop Fox 评估 Boost C++ Beast HTTP/S 网络库的安全性. 以下报告详细介绍了此次评估过程中发现的问题, 评估始于 2017 年 9 月 11 日.

评估团队对 Beast 库执行了混合应用评估. Bishop Fox 的混合应用评估方法将应用渗透测试的真实攻击技术与有针对性的源代码评审相结合, 以彻底识别应用安全漏洞. 此类全面评估从对已部署应用与源代码的自动化扫描开始. 接下来, 将扫描结果分析与我的人工评审相结合, 彻底识别潜在的应用安全漏洞. 此外, 团队还对应用架构与业务逻辑进行评审, 以发现设计层面的问题. 最后, 团队对这些漏洞进行人工利用与复核, 以验证发现.
