File

The File 概念抽象了对底层文件系统中文件的访问. 为支持其他平台接口, 用户可以自行编写满足这些要求的 File 类型.

关联类型
  • file_mode
  • is_file
要求

本表中:

  • F 是一个 File 类型
  • f 是 F
  • p 是一个类型为 char const* 的值, 指向以空字符结尾的 UTF-8 编码字符串.
  • m 是 file_mode
  • n 是一个字节数, 可转换为 std::size_t
  • o 是文件中的字节偏移量, 可转换为 std::uint64_t
  • b 是任何指向内存的非 const 指针
  • c 是任何指向内存的可能为 const 的指针
  • ec 是一个类型为 error_code 的引用

F()

可默认构造

f.~F()

可析构. 若 f 引用一个打开的文件, 则首先按调用 close 的方式将其关闭, 错误被忽略.

f.is_open()

bool

返回 true, 若 f 引用一个打开的文件; 否则返回 false.

f.close(ec)

若 f 引用一个打开的文件, 此函数尝试关闭该文件. 无论是否发生错误, 后续调用 f.is_open() 都将返回 false. 该函数保证 !ec 为 true (若没有错误) , 若发生了错误则设置为相应的错误码.

f.open(p,m,ec)

尝试以 p 指定的模式打开 m 指定路径处的文件. 成功时, 后续调用 f.is_open() 将返回 true. 若 f 引用一个打开的文件, 则首先按调用 close 的方式将其关闭, 错误被忽略. 该函数保证 !ec 为 true (若没有错误) , 若发生了错误则设置为相应的错误码.

f.size(ec)

std::uint64_t

若 f 引用一个打开的文件, 此函数尝试确定文件大小并返回其值. 若 f 未引用打开的文件, 函数将把 ec 设置为 errc::invalid_argument 并返回 0. 该函数保证 !ec 为 true (若没有错误) , 若发生了错误则设置为相应的错误码.

f.pos(ec)

std::uint64_t

若 f 引用一个打开的文件, 此函数尝试确定当前文件偏移量并返回它. 若 f 未引用打开的文件, 函数将把 ec 设置为 errc::invalid_argument 并返回 0. 该函数保证 !ec 为 true (若没有错误) , 若发生了错误则设置为相应的错误码.

f.seek(o,ec)

尝试将当前文件偏移量重新定位到值 o, 它表示相对于文件开头的字节偏移量. 若 f 未引用打开的文件, 函数将把 ec 设置为 errc::invalid_argument 并立即返回. 该函数保证 !ec 为 true (若没有错误) , 若发生了错误则设置为相应的错误码.

f.read(b,n,ec)

std::size_t

尝试从 n 引用的打开文件的当前文件偏移量处读取 f 个字节. 读出的字节存储在地址 b 处的内存缓冲区中, 该缓冲区的大小必须至少为 n 字节. 函数按读取量推进文件偏移量, 并返回实际读取的字节数, 它可能小于 n. 若 f 未引用打开的文件, 函数将把 ec 设置为 errc::invalid_argument 并立即返回. 该函数保证 !ec 为 true (若没有错误) , 若发生了错误则设置为相应的错误码. 若在读取任何字节之前检测到文件结束条件, 函数将保证 !ec 为 true 且返回值为 0.

f.write(c,n,ec)

std::size_t

尝试从 n 指向的缓冲区向 c 引用的打开文件的当前文件偏移量处写入 f 个字节. c 处的内存缓冲区必须指向至少 n 字节的、待复制到文件的存储. 函数按写入量推进文件偏移量, 并返回实际写入的字节数, 它可能小于 n. 若 f 未引用打开的文件, 函数将把 ec 设置为 errc::invalid_argument 并立即返回. 该函数保证 !ec 为 true (若没有错误) , 若发生了错误则设置为相应的错误码.

范例 
struct File
{
    /** Default constructor

        There is no open file initially.
    */
    File();

    /** Destructor

        If the file is open it is first closed.
    */
    ~File();

    /// Returns `true` if the file is open
    bool
    is_open() const;

    /// Close the file if open
    void
    close(error_code& ec);

    /// Open a file at the given path with the specified mode
    void
    open(char const* path, file_mode mode, error_code& ec);

    /// Return the size of the open file
    std::uint64_t
    size(error_code& ec) const;

    /// Return the current position in the open file
    std::uint64_t
    pos(error_code& ec) const;

    /// Adjust the current position in the open file
    void
    seek(std::uint64_t offset, error_code& ec);

    /// Read from the open file
    std::size_t
    read(void* buffer, std::size_t n, error_code& ec) const;

    /// Write to the open file
    std::size_t
    write(void const* buffer, std::size_t n, error_code& ec);
};
