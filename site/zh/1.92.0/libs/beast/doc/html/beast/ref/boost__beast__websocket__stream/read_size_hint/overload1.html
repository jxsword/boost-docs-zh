websocket::stream::read_size_hint (1 of 2 overloads)

返回下一次调用 read 的建议最大缓冲区大小.

概要 
std::size_t
read_size_hint(
    std::size_t initial_size = +tcp_frame_size) const;
说明

此函数返回下一次调用 read 所传缓冲区大小的合理字节数上限. 该数值由当前帧的状态以及是否启用 permessage-deflate 扩展决定.

参数

名称

说明

initial_size

当没有可用于计算更具体值的信息时, 表示调用方期望缓冲区大小的非零值. 例如读取报文的第一个帧头时.
