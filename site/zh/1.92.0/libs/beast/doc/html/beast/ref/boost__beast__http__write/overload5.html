http::write (5 of 6 overloads)

把完整报文写入流.

概要

定义于头文件 <boost/beast/http/write.hpp> 

template<
    class SyncWriteStream,
    bool isRequest,
    class Body,
    class Fields>
std::size_t
write(
    SyncWriteStream& stream,
    message< isRequest, Body, Fields >& msg,
    error_code& ec);
说明

此函数使用 HTTP/1 把完整报文写入流. 调用将阻塞, 直到以下条件之一成立:

  • 整个报文已写入.
  • 发生错误.

此操作通过一次或多次调用流的 write_some 函数实现. 该算法会使用带空分块装饰器的临时 serializer 来生成缓冲区.

备注

仅当 is_mutable_body_writer 对 Body 返回 true 时, 此函数才参与重载决议.

参数

名称

说明

stream

数据要写入的流. 该类型必须支持 SyncWriteStream 概念.

msg

要写入的报文.

ec

若发生了错误, 则设置为该错误.
返回值

写入流的字节数.
