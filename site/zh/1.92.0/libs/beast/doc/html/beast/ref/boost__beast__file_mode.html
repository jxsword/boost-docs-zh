file_mode

文件打开模式.

概要

定义于头文件 <boost/beast/core/file_base.hpp> 

enum file_mode
取值

名称

说明

read

对现有文件的随机只读访问.

scan

对现有文件的顺序只读访问.

write

对新建或截断文件的随机读写.

此模式允许对指定文件进行随机访问读写. 如果文件在函数调用之前不存在, 则创建它, 初始大小为零字节; 否则, 如果文件已存在, 其大小将被截断为零字节.

write_new

仅对新建文件的随机读写.

此模式允许对指定文件进行随机访问读写. 文件将以零字节的初始大小创建. 如果文件在函数调用之前已存在, 则返回错误且不打开任何文件.

write_existing

对现有文件的随机只写访问.

如果文件不存在, 则产生错误.

append

追加到新文件或现有文件.

在每次写入之前, 当前文件位置应被设置为文件末尾.

  • 如果文件不存在, 则创建它.
  • 如果文件已存在, 则追加新数据.

append_existing

追加到现有文件.

在每次写入之前, 当前文件位置应被设置为文件末尾.

如果文件不存在, 则产生错误.
说明

使用 File 概念的实例打开文件时, 会用到这些模式.
