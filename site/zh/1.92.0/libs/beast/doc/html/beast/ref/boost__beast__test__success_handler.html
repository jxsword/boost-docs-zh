test::success_handler

返回一个要求成功结果的测试 CompletionHandler.

概要

定义于头文件 <boost/beast/_experimental/test/handler.hpp> 

handler
success_handler(
    boost::source_location loc = BOOST_CURRENT_LOCATION);
说明

返回的处理器可以以任何首个参数为 error_code 的签名调用. 若出现以下情况, 处理器将使测试失败:

  • 处理器被销毁而未被调用, 或
  • 处理器被调用时带有非成功的错误码.
