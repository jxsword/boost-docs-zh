http::basic_fields::at (1 of 2 overloads)

返回字段的值, 或抛出异常.

概要 
string_view const
at(
    field name) const;
说明

如果存在多个具有指定名称的字段, 则返回按插入顺序定义的第一个字段.

参数

名称

说明

name

字段的名称.
返回值

字段值.

异常

类型

抛出时机

std::out_of_range

如果未找到字段.
