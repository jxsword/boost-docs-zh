http::buffer_body::value_type

在报文中使用时 body 成员的类型.

概要

定义于头文件 <boost/beast/http/buffer_body.hpp> 

struct value_type
数据成员

名称

说明

data

指向 size 个八位组的连续内存区域的指针, 否则为 nullptr.

more

如果这不是最后一个缓冲区, 则为 true.

size

data 所指向缓冲区中的八位组数量.
