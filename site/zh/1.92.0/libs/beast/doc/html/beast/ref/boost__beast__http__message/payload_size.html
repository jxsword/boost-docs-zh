http::message::payload_size

如有可能, 返回正文的载荷大小 (以八位组计).

概要 
boost::optional< std::uint64_t >
payload_size() const;
说明

此函数调用 Body 算法来测量序列化正文容器中的八位组数量. 如果没有正文, 将返回零. 否则, 如果正文存在但其大小事先未知, 则返回 boost::none (通常表示将使用分块 Transfer-Encoding).

备注

报文中 Content-Length 字段的值不会被检查.
