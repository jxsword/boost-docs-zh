buffers_cat

连接一个或多个缓冲区序列.

概要

定义于头文件 <boost/beast/core/buffers_cat.hpp> 

template<
    class... BufferSequence>
buffers_cat_view< BufferSequence... >
buffers_cat(
    BufferSequence const&... buffers);
说明

此函数返回一个常量或可变缓冲区序列, 迭代时高效地连接输入缓冲区序列. 会复制传入的参数; 但返回的对象不取得底层内存的所有权. 应用仍负责管理被引用内存的生存期.

参数

名称

说明

buffers

要连接的缓冲区序列列表.
返回值

表示输入缓冲区序列连接结果的新缓冲区序列. 若传入的每个缓冲区序列也都是 MutableBufferSequence, 则此缓冲区序列将是 MutableBufferSequence; 否则返回的缓冲区序列将是 ConstBufferSequence.

参见

buffers_cat_view
