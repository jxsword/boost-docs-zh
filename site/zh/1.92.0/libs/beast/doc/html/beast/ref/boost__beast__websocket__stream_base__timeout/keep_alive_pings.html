websocket::stream_base::timeout::keep_alive_pings

自动 ping 设置.

概要 
bool keep_alive_pings;
说明

若设置了空闲区间, 在超时区间内没有收到数据时, 此设置会按如下方式影响流的行为:

  • 当 keep_alive_pings 为 true, 则会自动发送空闲 ping. 若再经过一个超时区间仍无数据到达, 连接将被关闭. 必须存在一个未完成的读取操作, 它将立即以错误 beast::error::timeout.
  • 当 keep_alive_pings 为 false, 若没有任何活动, 连接将被关闭. websocket 报文帧和控制帧都算作活动. 必须存在一个未完成的读取操作, 它将立即以错误 beast::error::timeout.
