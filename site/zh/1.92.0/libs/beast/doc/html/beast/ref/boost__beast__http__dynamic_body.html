http::dynamic_body

由 multi_buffer 表示的动态报文正文.

概要

定义于头文件 <boost/beast/http/dynamic_body.hpp> 

using dynamic_body = basic_dynamic_body< multi_buffer >;
类型

名称

说明

reader

用于解析正文的算法.

value_type

用于正文的容器类型.

writer

用于序列化正文的算法.
静态成员函数

名称

说明

size

返回正文的载荷大小.

此正文使用 DynamicBuffer 作为基于内存的容器来保存报文载荷. 使用此正文类型的报文可以被序列化和解析.

说明

满足 Body 的要求.
