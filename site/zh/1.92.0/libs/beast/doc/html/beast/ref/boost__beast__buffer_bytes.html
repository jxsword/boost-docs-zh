buffer_bytes

返回缓冲区或缓冲区序列中的总字节数.

概要

定义于头文件 <boost/beast/core/buffer_traits.hpp> 

template<
    class BufferSequence>
std::size_t
buffer_bytes(
    BufferSequence const& buffers);
说明

此函数返回缓冲区、缓冲区序列或可转换为缓冲区的对象中的总字节数. 具体而言, 它可以接受:

  • 一个 ConstBufferSequence 或 MutableBufferSequence
  • 一个 net::const_buffer 或 net::mutable_buffer
  • 一个可转换为 net::const_buffer

此函数设计为 net::buffer_size 的更易用替代. 它识别通过参数依赖查找找到的定制点. 调用 beast::buffer_bytes(b) 等价于执行:

using net::buffer_size;
return buffer_size(b);

此外它还处理可转换为 net::const_buffer 的类型; 这些类型不被 net::buffer_size 处理.

参数

名称

说明

buffers

要计算大小的缓冲区或缓冲区序列.
返回值

缓冲区或序列中的总字节数.
