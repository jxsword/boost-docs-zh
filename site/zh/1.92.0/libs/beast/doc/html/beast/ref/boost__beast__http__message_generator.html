说明

为 http::message 模板的任何具体实例实现 BuffersGenerator 概念.

http::message_generator 在构造时取得报文的所有权, 从接口中抹去具体类型.

这使得它非常适合在服务器应用程序中用于实现请求处理:

template < class Body, class Fields>
http::message_generator handle_request(
    string_view doc_root,
    http::request<Body, Fields>&& request);

为 BuffersGenerator 提供了 beast::write 和 beast::async_write 操作. http::message::keep_alive 属性在写入报文后即可使用.
