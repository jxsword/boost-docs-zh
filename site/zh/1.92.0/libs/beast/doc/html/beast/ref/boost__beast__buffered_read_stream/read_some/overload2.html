buffered_read_stream::read_some (2 个重载中的第 2 个)

从流读取一些数据.

概要 
template<
    class MutableBufferSequence>
std::size_t
read_some(
    MutableBufferSequence const& buffers,
    error_code& ec);
说明

该函数用于从流中读取数据. 函数调用将阻塞, 直到成功读取一个或多个字节的数据, 或者发生错误.

参数

名称

说明

buffers

读入数据所用的一个或多个缓冲区.

ec

若发生了错误, 则设置为该错误.
返回值

读取的字节数, 出错时为 0.
