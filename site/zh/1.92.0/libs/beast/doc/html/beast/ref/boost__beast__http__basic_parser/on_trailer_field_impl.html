http::basic_parser::on_trailer_field_impl

对 HTTP 尾部报文头中的每个完整字段调用一次.

概要 
void
on_trailer_field_impl(
    field name,
    string_view name_string,
    string_view value,
    error_code& ec);
说明

解析分块 HTTP 报文的尾部 (trailer) 部分期间, 每收到一个字段都会调用此虚函数.

参数

名称

说明

name

已知字段枚举值. 如果字段名未被识别, 此值将为 field::unknown.

name_string

从输入接收的字段的精确名称, 以字符串表示.

value

保存字段值的字符串.

ec

函数可以设置的输出参数, 用于指示错误. 在调用此函数之前错误会被清除.
