websocket::stream::read_some (2 of 4 overloads)

读取部分报文数据.

概要 
template<
    class DynamicBuffer>
std::size_t
read_some(
    DynamicBuffer& buffer,
    std::size_t limit,
    error_code& ec);
说明

此函数用于读取部分报文数据.

调用将阻塞, 直到以下条件之一成立:

  • 部分报文数据已接收.
  • 收到了关闭帧. 此时函数指示的错误为 error::closed.
  • 发生错误.

该算法称为 组合操作, 是通过调用下一层的 read_some 和 write_some 函数.

收到的报文数据会被追加到缓冲区. 函数 got_binary 和 got_text 可用于查询流并确定最后收到的报文的类型. 函数 is_message_done 可用于判断最后一次读取操作收到的报文是否完整.

在调用返回之前, 实现会读取传入的控制帧并自动按以下方式处理:

  • 该 control_callback 将在每个控制帧上被调用.
  • 对收到的每个 ping 帧, 都会自动发送一个 pong 帧.
  • 如果收到关闭帧, 将执行 WebSocket 关闭握手. 此时函数返回的错误为 error::closed 将被指示.
返回值

追加到缓冲区的报文载荷字节数.

参数

名称

说明

buffer

用于追加报文数据的动态缓冲区.

limit

此函数追加到缓冲区的字节数上限. 若此值为零, 将自动选择一个合理的大小.

ec

用于指示发生了何种错误 (如无错误则不设置) .
