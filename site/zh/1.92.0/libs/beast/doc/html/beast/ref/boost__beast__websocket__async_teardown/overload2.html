websocket::async_teardown (2 of 2 overloads)

开始断开一个 net::ip::tcp::socket.

概要

定义于头文件 <boost/beast/websocket/teardown.hpp> 

template<
    class Protocol,
    class Executor,
    class TeardownHandler>
void
async_teardown(
    role_type role,
    net::basic_stream_socket< Protocol, Executor >& socket,
    TeardownHandler&& handler);
说明

这开始异步拆除连接. 实现将根据用于构造套接字的 Stream 参数调用此函数的重载. 当 Stream 是用户自定义类型而不是 net::ip::tcp::socket 或任何 net::ssl::stream 时, 调用者负责提供此函数的合适重载.

备注

此函数充当定制点, 不打算被直接调用.

参数

名称

说明

role

本地端点的角色

socket

要断开的套接字.

handler

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
    error_code const & error // result of operation
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将以与使用 net::post 等效的方式进行.
逐操作取消

此异步操作支持以下 net::cancellation_type 值的取消:

  • net::cancellation_type::terminal
  • net::cancellation_type::partial
  • net::cancellation_type::total

(前提是套接字的 async_wait 操作同样支持它们. )
