buffers_type

缓冲区序列类型列表的底层缓冲区类型的类型别名.

概要

定义于头文件 <boost/beast/core/buffer_traits.hpp> 

template<
    class... BufferSequence>
using buffers_type = see-below;
说明

此元函数用于确定缓冲区序列列表的底层缓冲区类型. 别名的等效类型将随模板类型实参而变化:

  • 若列表中的每个类型都是 MutableBufferSequence, 结果类型别名将为 net::mutable_buffer, otherwise
  • 结果类型别名将为 net::const_buffer.
示例

以下代码返回缓冲区序列中的第一个缓冲区; 若实参不是缓冲区序列, 则产生编译错误:

template < class BufferSequence>
buffers_type <BufferSequence>
buffers_front (BufferSequence const & buffers)
{
    static_assert (
        net::is_const_buffer_sequence<BufferSequence>::value,
        "BufferSequence type requirements not met" );
    auto const first = net::buffer_sequence_begin (buffers);
    if (first == net::buffer_sequence_end (buffers))
        return {};
    return *first;
}
模板参数

类型

说明

BufferSequence

要检查的零个或多个类型的列表. 若此列表为空, 结果类型别名将为 net::mutable_buffer.
