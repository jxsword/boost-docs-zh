引言

Beast 是一个仅头文件的 C++ 库, 通过提供 low-level HTTP/1, WebSocket, and networking protocol 词汇类型与算法、并使用 Boost.Asio 的一致异步模型, 作为编写可互操作网络库的基础.

本库的设计目标:

  • Symmetry: 对称性: 算法与角色无关; 可构建客户端、服务器或两者.
  • Ease of Use: Boost.Asio 用户会立即理解 Beast.
  • Flexibility: 灵活性: 由用户做出重要决策, 例如缓冲区或线程管理.
  • Performance: 性能: 构建处理数千或更多连接的应用.
  • Basis for Further Abstraction. 进一步抽象的基础. 组件非常适合在其上继续构建.

本库不是客户端或服务器, 但可以用来构建这些东西. 提供了许多示例, 包括客户端和服务器, 可作为编写你自己的程序的起点.

动机

Beast 使用户能够使用 HTTP/1 与 WebSocket 创建自己的库、客户端和服务器. 由于 Beast 处理底层协议细节, 代码将更易于实现、理解和维护, 速度也更快. HTTP 与 WebSocket 协议驱动着万维网的大部分流量. 每个 web 浏览器都实现这些协议来加载网页, 并使客户端程序 (通常以 JavaScript 编写) 能够交互式通信. 拥有这些协议的标准化实现, 对 C++ 大有裨益.

Requirements要求

重要

本库面向熟悉 Boost.Asio 的程序员. 希望使用异步接口的用户应当已经知道如何使用回调或协程创建并发网络程序.

Beast requires:

  • C++11: C++11: 对大多数语言特性的可靠支持.
  • Boost: Boost: Beast 只能配合 Boost 使用, 不能与 standalone Asio 使用
  • OpenSSL: OpenSSL: 1.0.2 或更高版本. 构建测试与示例以及使用 TLS/安全套接字时需要.

已使用这些编译器测试: msvc-14+、gcc 5.0+、clang 3.6+.

源代码是header-only. 为使用 Beast 的程序在链接步骤中添加额外的库通常没有必要, 以下情况除外:

  • 使用通过调用 boost::asio::spawn 创建的协程时, 需要向程序添加 Boost.Coroutine 库.
  • 使用 boost::asio::ssl::stream 时, 需要向程序添加 OpenSSL 库.

请访问 Boost documentation, 获取如何针对你的特定环境系统构建并链接 Boost 库的说明.
