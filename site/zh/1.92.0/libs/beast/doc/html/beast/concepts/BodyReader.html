BodyReader

BodyReader 一种在线算法, 把一系列包含已解析正文八位组的缓冲区 (零个或多个) 转移到报文容器中. parser 在需要时创建此类型的实例, 并调用它零次或多次来转移缓冲区. BodyReader 的接口旨在允许把缓冲区转换为以下表示场景:

  • 把正文存储在动态缓冲区中
  • 把正文存储在用户自定义的、带自定义分配器的容器中
  • 在存储之前对传入的正文数据进行变换, 例如先进行压缩.
  • 把正文数据保存到文件

本表中:

  • R 表示一个满足 BodyReader.
  • B 表示一个 Body, 其中 std::is_same<R, B::reader>::value == true.
  • a 表示一个类型为 R.
  • b 是一个类型满足 ConstBufferSequence 要求的对象
  • h 表示一个类型为 header<isRequest, Fields>&.
  • v 表示一个类型为 Body::value_type&.
  • n 是一个类型为 boost::optional<std::uint64_t>.
  • ec 是一个类型为 error_code&.

语义, 前置/后置条件

R{h,v};

从 h 和 v 构造. h 和 v 的生存期保证不早于 R 被销毁之时结束. 读取器不得在第一次调用 h 之前访问 v 或 init 的内容, 从而允许报文的惰性构造.

a.init(n, ec)

在第一次调用 put 之前调用一次, 以完整初始化对象. 报文正文在进入该函数之前有效, 并保持有效直到读取器被销毁. 若已知正文长度, n 的值将被设置为正文的内容长度; 否则 n 将等于 boost::none. BodyReader 的实现可利用这一信息优化分配.

该函数保证 !ec 为 true (若没有错误) , 否则设置为相应的错误码.

a.put(b,ec)

std::size_t

该函数被调用以把 b 指定的缓冲区的部分或全部追加到正文表示中. 返回从 b 插入的字节数. 若插入的字节数少于总输入, 剩余输入将在下一次调用 put 时给出. 该函数保证 !ec 为 true (若没有错误) , 否则设置为相应的错误码.

a.finish(ec)

该函数在没有剩余正文八位组时被调用. 该函数保证 !ec 为 true (若没有错误) , 否则设置为相应的错误码.

is_body_reader<B>

std::true_type

std::true_type 是 B 的别名, 否则是 std::false_type 的别名.

范例 
struct BodyReader
{
    /** Construct the reader.

        @param h The header for the message being parsed

        @param body The body to store the parsed results into
    */
    template<bool isRequest, class Fields>
    BodyReader(header<isRequest, Fields>& h, value_type& body);

    /** Initialize the reader.

        This is called after construction and before the first
        call to `put`. The message is valid and complete upon
        entry.

        @param ec Set to the error, if any occurred.
    */
    void
    init(
        boost::optional<std::uint64_t> const& content_length,
        error_code& ec)
    {
        boost::ignore_unused(content_length);

        // The specification requires this to indicate "no error"
        ec = {};
    }

    /** Store buffers.

        This is called zero or more times with parsed body octets.

        @param buffers The constant buffer sequence to store.

        @param ec Set to the error, if any occurred.

        @return The number of bytes transferred from the input buffers.
    */
    template<class ConstBufferSequence>
    std::size_t
    put(ConstBufferSequence const& buffers, error_code& ec)
    {
        // The specification requires this to indicate "no error"
        ec = {};

        return buffer_bytes(buffers);
    }

    /** Called when the body is complete.

        @param ec Set to the error, if any occurred.
    */
    void
    finish(error_code& ec)
    {
        // The specification requires this to indicate "no error"
        ec = {};
    }
};
