zlib::deflate_stream::tune

微调内部压缩参数.

概要 
void
tune(
    int good_length,
    int max_lazy,
    int nice_length,
    int max_chain);
说明

压缩参数只应由理解 zlib deflate 所用最佳匹配串搜索算法的人来调整, 而且即便如此, 也只有那些针对特定输入数据执意榨取最后一点压缩率的狂热优化者才需要调整. max_lazy、good_length、nice_length 和 max_chain 参数的含义请阅读 (ZLib 的) deflate.c 源代码.
