说明

这实现了一个 ConstBufferSequence, 其中保存 CRLF ("\r\n"), 用作 chunk 中的分隔符.

要使用此类, 请把它的实例作为缓冲区序列传递给流算法:

// writes "\r\n"
net::write(stream, chunk_crlf{});
参见

https://tools.ietf.org/html/rfc7230#section-4.1
