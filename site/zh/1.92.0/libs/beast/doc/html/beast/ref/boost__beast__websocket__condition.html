websocket::condition

与错误码集合对应的错误条件.

概要

定义于头文件 <boost/beast/websocket/error.hpp> 

enum condition
取值

名称

说明

handshake_failed

WebSocket 握手失败.

此错误条件表示 WebSocket 握手失败. 如果相应的 HTTP 响应表明 keep-alive 行为, 则可以重试握手.

protocol_violation

发生了 WebSocket 协议违规.

此错误条件表示 WebSocket 连接上的远程对端发送了违反协议的数据.
