http::basic_parser::need_eof

如果报文语义要求文件结束, 则返回 true.

概要 
bool
need_eof() const;
说明

根据报文头的内容, 解析器可能需要文件结束通知才能知道正文的结尾在哪里. 如果此函数返回 true, 则当输入再也不会有更多数据时, 需要调用 put_eof.
