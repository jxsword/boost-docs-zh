http::header::result (3 of 3 overloads)

以整数设置响应状态码.

概要 
void
result(
    unsigned v);
说明

这会把状态码设置为传入的精确数字. 如果该数字不对应任何已知状态码, 函数 result 将返回 status::unknown. 请使用 result_int 获取原始状态码.

参数

名称

说明

v

要设置的状态码整数.
异常

类型

抛出时机

std::invalid_argument

当 v > 999 时.
