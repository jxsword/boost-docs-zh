make_printable

用于允许把缓冲区序列打印到 std::ostream 的辅助工具.

概要

定义于头文件 <boost/beast/core/make_printable.hpp> 

template<
    class ConstBufferSequence>
implementation-defined
make_printable(
    ConstBufferSequence const& buffers);
说明

此函数用于包装缓冲区序列, 使其可以被解释为字符并写入 std::ostream (例如 std::cout). 不进行字符转换; 不可打印字符和空字符将原样传送到输出流.

示例

此函数把缓冲区序列的大小和内容打印到标准输出:

template < class ConstBufferSequence>
void
print (ConstBufferSequence const & buffers)
{
    std::cout <<
        "Buffer size: " << buffer_bytes(buffers) << " bytes\n"
        "Buffer data: '" << make_printable(buffers) << "'\n" ;
}
参数

名称

说明

buffers

要被流式处理的、满足 ConstBufferSequence 要求的对象. 实现会复制此对象. 底层内存的所有权不发生转移, 应用程序仍负责管理其生存期.
