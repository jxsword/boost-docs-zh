websocket::permessage_deflate

permessage-deflate 扩展选项.

概要

定义于头文件 <boost/beast/websocket/option.hpp> 

struct permessage_deflate
数据成员

名称

说明

client_enable

true (在客户端角色下提供该扩展)

client_max_window_bits

客户端侧可提供的最大窗口位数.

client_no_context_takeover

true (若希望 client_no_context_takeover)

compLevel

deflate 压缩级别 0..9.

memLevel

deflate 内存级别, 1..9.

msg_size_threshold

报文被压缩所需的最小大小.

server_enable

true (在服务器角色下提供该扩展)

server_max_window_bits

服务器侧可提供的最大窗口位数.

server_no_context_takeover

true (若希望 server_no_context_takeover)
说明

这些设置控制允许压缩报文的 permessage-deflate 扩展.

备注

这些设置应在执行 WebSocket 握手之前配置.

此类型的对象与 beast::websocket::stream::set_option.
