http::header::insert (1 of 8 overloads)

(继承自 http::basic_fields)

插入一个字段.

概要 
void
insert(
    field name,
    string_view value);
说明

如果已存在一个或多个同名字段, 新字段将按序列化顺序插入到最后一个匹配名称的字段之后. 值可以为空字符串.

参数

名称

说明

name

字段名.

value

字段值.
异常

类型

抛出时机

boost::system::system_error

如果发生错误则抛出:

  • 如果 value 的大小超过 max_value_size, 错误码将为 error::header_field_value_too_large.
