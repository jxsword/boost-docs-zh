websocket::seed_prng

手动提供一次性种子以初始化 PRNG.

概要

定义于头文件 <boost/beast/websocket/stream.hpp> 

void
seed_prng(
    std::seed_seq& ss);
说明

此函数调用指定的种子序列来产生适用于伪随机数生成器的种子; 该生成器用于创建掩码和执行 WebSocket 协议握手.

如果未手动提供种子, 实现将使用 std::random_device 执行一次性种子生成. 当应用程序运行在随机设备不可靠或熵不足的环境中时, 可以使用此函数.

前置条件

在任何 websocket stream 对象构造之后, 不得再调用此函数.

参数

名称

说明

ss

对一个 std::seed_seq 的引用, 用于为伪随机数生成器提供种子. 种子序列应具有至少 256 位的熵.
参见

stream::secure_prng
