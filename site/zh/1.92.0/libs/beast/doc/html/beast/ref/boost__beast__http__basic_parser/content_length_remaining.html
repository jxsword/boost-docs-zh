http::basic_parser::content_length_remaining

如果已知, 返回剩余内容长度.

概要 
boost::optional< std::uint64_t >
content_length_remaining() const;
说明

如果报文头指定了 Content-Length, 则返回值将是载荷正文中尚未解析的剩余字节数.

备注

除非 is_header_done 会返回 true, 否则返回值未定义.
