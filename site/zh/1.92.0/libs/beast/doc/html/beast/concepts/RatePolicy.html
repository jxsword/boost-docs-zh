RatePolicy

RatePolicy 的实例与一个 basic_stream 相关联, 控制字节可被独立发送和接收的速率. 这可用于实现细粒度的带宽管理与流量控制.

关联类型
  • rate_policy_access
警告

这些要求在后续版本中可能发生非向后兼容的变更.

要求

本表中:

  • P 表示一个满足 RatePolicy 要求的类型.
  • x 表示一个类型为 P 的 xvalue
  • a 表示一个类型为 P.
  • n 表示一个类型为 std::size_t

表达式

类型

语义, 前置/后置条件

P a(x)

要求 MoveConstructible.

friend rate_policy_access

P 中要求的成员函数应为私有. rate_policy_access 必须是 P 的友元, 实现才能访问所需的成员函数.

a.available_read_bytes()

std::size_t

实现调用此函数来确定下一次读操作允许传输的最大字节数. 后续实际传输的字节数可能小于该数.

若策略返回零值, 读操作将异步等待直到下一个定时器间隔再重试. 重试发生时, 会再次调用此函数.

a.available_write_bytes()

std::size_t

实现调用此函数来确定下一次写操作允许传输的最大字节数. 后续实际传输的字节数可能小于该数.

若策略返回零值, 读操作将异步等待直到下一个定时器间隔再重试. 重试发生时, 会再次调用此函数.

a.transfer_read_bytes(n)

实现调用此函数, 通知策略最近一次读操作成功传输了 n 个字节. 策略对象可以选择性地使用该信息计算吞吐量, 和/或为确定后续查询的传输上限的算法提供依据.

a.transfer_write_bytes(n)

实现调用此函数, 通知策略最近一次写操作成功传输了 n 个字节. 策略对象可以选择性地使用该信息计算吞吐量, 和/或为确定后续查询的传输上限的算法提供依据.

a.on_timer()

实现每次内部定时器到期时都会调用此函数. 策略对象可以选择性地利用这一时机计算经过的时间与吞吐量, 和/或为确定后续查询的传输上限的算法提供依据.

范例 
class RatePolicy
{
    friend class rate_policy_access;

    std::size_t
    available_read_bytes();

    std::size_t
    available_write_bytes();

    void
    transfer_read_bytes(std::size_t);

    void
    transfer_write_bytes(std::size_t);

    void
    on_timer();
};
