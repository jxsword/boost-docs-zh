beast_close_socket

默认套接字关闭函数.

概要

定义于头文件 <boost/beast/core/stream_traits.hpp> 

template<
    class Protocol,
    class Executor>
void
beast_close_socket(
    net::basic_socket< Protocol, Executor >& sock);
说明

此函数不打算被直接调用. 相反, 使用 close_socket 时它会自动被调用. 为了支持关闭用户自定义类型或从特定用户自定义类型派生的类, 应当在对应类型所在的命名空间中重载此函数.
