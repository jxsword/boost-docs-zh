http::parser::put_eof

(继承自 http::basic_parser)

通知解析器已到达流末尾.

概要 
void
put_eof(
    error_code& ec);
说明

某些情况下, HTTP 需要知道流的结尾在哪里. 例如, 有时服务器发送不带 Content-Length 的响应, 并期望客户端一直消耗输入 (作为正文) 直到 EOF. 回调和错误仍会照常处理.

当从底层流对象读取并把错误码设置为 net::error::eof 时, 通常会调用它.

备注

仅在解析完完整报文头之后有效.

参数

名称

说明

ec

若发生了错误, 则设置为该错误.
