websocket::stream::compress (1 of 2 overloads)

设置压缩报文写入选项.

概要 
void
compress(
    bool value);
说明

此设置控制传出的报文是否应被压缩. 该设置只在以下条件满足时应用:

  • 模板参数 deflateSupported 为 true
  • 压缩已启用. 这由 stream::set_option
  • 客户端与服务器已协商 permessage-deflate 设置
  • 报文大于 permessage_deflate::msg_size_threshold

此函数允许调整每报文压缩. 报文开始后更改操作码, 只会在当前正在发送的报文完成之后生效.

默认设置为: 只要上述条件满足就压缩报文.

参数

名称

说明

value

true (若传出的报文应被压缩)
示例

对单个报文禁用压缩.

ws.compress( false );
ws.write(net::buffer(s), ec);
ws.compress( true );
