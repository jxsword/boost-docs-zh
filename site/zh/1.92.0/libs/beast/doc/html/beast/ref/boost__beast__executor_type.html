executor_type

用于确定 get_executor 返回类型的特征.

概要

定义于头文件 <boost/beast/core/stream_traits.hpp> 

template<
    class T>
using executor_type = see-below;
说明

此类型别名将是调用成员 get_exector 时返回值的类型, 对象类型为 T&.

参数

名称

说明

T

要查询的类型
返回值

从 get_executor 返回的值的类型.
