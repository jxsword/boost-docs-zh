websocket::stream::accept (5 of 6 overloads)

响应 WebSocket HTTP 升级请求.

概要 
template<
    class Body,
    class Allocator>
void
accept(
    http::request< Body, http::basic_fields< Allocator > > const& req);
说明

此函数用于执行 WebSocket 握手, 这是发送和接收报文之前必需的步骤. 在握手期间, 客户端发送 WebSocket 升级 HTTP 请求, 服务器以指示握手结果的 HTTP 响应作为回复.

调用将阻塞, 直到下列条件之一成立:

  • 响应已发送.
  • 发生错误.

该算法称为 组合操作, 是通过调用下一层的 read_some 和 write_some 函数.

如果收到有效的升级请求, 将向对端发送带 status-code 的 beast::http::status::switching_protocols 的 HTTP 响应; 否则, 操作将关联一个非成功的错误.

参数

名称

说明

req

包含 HTTP 升级请求的对象. 所有权不转移, 实现不会从其他线程访问此对象.
