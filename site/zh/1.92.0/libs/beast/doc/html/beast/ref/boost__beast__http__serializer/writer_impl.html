http::serializer::writer_impl

提供对关联 BodyWriter 的底层访问

概要 
writer&
writer_impl();
说明

此函数提供对与正文关联、由序列化器在构造时创建的写入器实例的访问. 访问此对象的行为由特定写入器及其关联正文的规范定义.

返回值

对写入器的引用.
