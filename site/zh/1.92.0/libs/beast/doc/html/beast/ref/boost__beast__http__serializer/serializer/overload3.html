http::serializer::serializer (3 of 3 overloads)

构造函数.

概要 
serializer(
    value_type& msg);
说明

实现保证在首次调用 next 之前不会访问构造时传入的报文. 这允许延迟创建报文, 例如在序列化之前填写报文头.

参数

名称

说明

msg

对要序列化的报文的引用, 它必须在序列化器的生存期内保持有效. 取决于所用的 Body 类型, 它可能是也可能不是 const 引用.
备注

仅当 Body::writer 可以从 const 报文引用构造时, 此函数才参与重载决议.
