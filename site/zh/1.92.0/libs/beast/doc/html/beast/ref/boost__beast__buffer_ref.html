buffer_ref

缓冲区引用为 Beast 缓冲区提供封装, 使其可用于 asio dynamic_buffer v1.

概要

定义于头文件 <boost/beast/core/buffer_ref.hpp> 

template<
    typename Buffer>
struct buffer_ref
类型

名称

说明

buffer_type

底层缓冲区的类型.

const_buffers_type

用于表示可读字节的 ConstBufferSequence.

mutable_buffers_type

用于表示可写字节的 MutableBufferSequence.
成员函数

名称

说明

buffer_ref [constructor]

围绕 buffer 创建缓冲区引用.
—
复制引用.

capacity

返回在不要求分配的情况下可容纳的最大字节数 (包括可读与可写) .

commit

把字节从输出序列移至输入序列.

consume

从可读字节序列中移除 n 字节.

data

返回表示可读字节的常量缓冲区序列.

max_size

返回最终可容纳的最大字节数 (包括可读与可写) .

prepare

获取表示输出序列的缓冲区列表, 其大小为给定值.

size

返回可读字节的数目.
说明

当前不支持 v2, 因此不得定义 BOOST_ASIO_NO_DYNAMIC_BUFFER_V1.

示例 
asio::tcp::socket sock;
beast::flat_buffer fb;
asio::read_until(sock, ref(fb) '\n' );
模板参数

类型

说明

Buffer

底层缓冲区
