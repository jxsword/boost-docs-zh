http::status

概要

定义于头文件 <boost/beast/http/status.hpp> 

enum status
取值

名称

说明

unknown

未知状态码.

此值表示状态码的值不在通常可识别的状态码列表中. 对精确值感兴趣的调用者应使用提供原始整数的接口.

continue_

switching_protocols

切换协议 (Switching Protocols).

此状态表示切换到新协议的请求已被服务器接受并应用. 对 WebSocket Upgrade HTTP 请求的成功响应将具有此状态码.
