http::message::prepare_payload

为正文准备报文载荷字段.

概要 
void
prepare_payload();
说明

此函数会根据正文的属性调整 Content-Length 和 Transfer-Encoding 字段值.

示例 
request<string_body> req{verb::post, "/" };
req.set(field::user_agent, "Beast" );
req.body() = "Hello, world!" ;
req.prepare_payload();
备注

在以下情况下无需调用此函数:

  • 请求不包含正文, 例如 GET 或 HEAD 请求.
  • Content-Length 和 Transfer-Encoding 已手动设置.
