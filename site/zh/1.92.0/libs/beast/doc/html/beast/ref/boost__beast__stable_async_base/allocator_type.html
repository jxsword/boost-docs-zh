stable_async_base::allocator_type

(继承自 async_base)

与此对象关联的分配器类型.

概要 
using allocator_type = net::associated_allocator_t< Handler, Allocator >;
说明

若从 boost::beast::async_base 派生的类是完成处理器, 则派生类的关联分配器将是此类型.
