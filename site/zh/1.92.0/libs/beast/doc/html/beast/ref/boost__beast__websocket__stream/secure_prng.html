websocket::stream::secure_prng

设置 PRNG 是否为密码学安全的.

概要 
void
secure_prng(
    bool value);
说明

此设置控制用于产生 WebSocket 协议所需掩码的伪随机数来源是否具有密码学质量. 当设置为 true 时, 使用强算法, 其输出不可通过观察被猜测. 当设置为 false 时, 则使用快得多的算法. 只有工作在客户端模式的流才执行掩蔽; 对工作在服务器模式的流, 此设置无效. 默认情况下, 新构造的流使用安全的 PRNG.

如果 WebSocket 流与加密的 SSL 或 TLS 下一层一起使用, 如果应用程序确知中间代理不易受缓存投毒攻击, 或者应用程序的设计使攻击者无法向流接口发送任意输入, 则可以使用更快的算法.

更多信息请查阅 WebSocket 协议 RFC.

参数

名称

说明

value

true (若 PRNG 算法应为密码学安全) .
