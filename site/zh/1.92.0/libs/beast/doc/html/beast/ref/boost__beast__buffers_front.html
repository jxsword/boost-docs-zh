buffers_front

返回缓冲区序列中的第一个缓冲区.

概要

定义于头文件 <boost/beast/core/buffers_prefix.hpp> 

template<
    class BufferSequence>
buffers_type< BufferSequence >
buffers_front(
    BufferSequence const& buffers);
说明

返回缓冲区序列中的第一个缓冲区. 若缓冲区序列是空范围, 返回的缓冲区大小将为零.

参数

名称

说明

buffers

缓冲区序列. 若序列可变, 返回的缓冲区序列也将可变; 否则返回的缓冲区序列将为常量.
