http::buffer_body::value_type::data

指向 size 个八位组的连续内存区域的指针, 否则为 nullptr.

概要 
void* data = nullptr;
说明
序列化时

如果此值为 nullptr 且 more 为 true, 错误 error::need_buffer 将从 serializer::get 返回. 否则, 序列化器将使用 data 所指向的、具有 size 个八位组有效存储的内存作为表示正文的下一个缓冲区.

解析时

如果此值为 nullptr, 错误 error::need_buffer 将从 parser::put 返回. 否则, 解析器将把正文八位组存入 data 所指向的、具有 size 个八位组有效存储的内存中. 八位组存入后, data 和 size 成员会被调整: data 递增, 指向写入数据之后的下一个八位组; 而 size 递减, 反映 data 所指向内存位置的剩余空间.
