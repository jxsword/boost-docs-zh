read_size_or_throw

返回自然的读取大小, 如果缓冲区已满则抛出异常.

概要

定义于头文件 <boost/beast/core/read_size.hpp> 

template<
    class DynamicBuffer>
std::size_t
read_size_or_throw(
    DynamicBuffer& buffer,
    std::size_t max_size);
说明

此函数检查动态缓冲区的容量、大小和最大大小. 然后根据传入的上限计算自然的读取大小. 它倾向于选择不需要重新分配的读取大小, 同时以合理的最小值避免过小的读取.

参数

名称

说明

buffer

要检查的动态缓冲区.

max_size

返回值的上限.
异常

类型

抛出时机

std::length_error

当 max_size > 0 且缓冲区已满时.
