basic_stream::expires_after

为后续逻辑操作设置超时.

概要 
void
expires_after(
    net::steady_timer::duration expiry_time);
说明

此操作把读定时器、写定时器或两者设置为在指定的经过时间后到期. 若定时器在对应异步操作未完成期间到期, 流将被关闭, 任何未完成的操作将以错误 beast::error::timeout 完成. 否则, 若定时器在没有操作未完成时到期、且到期时间未被再次设置, 下一个操作将立即超时.

定时器共同作用于到期设置之后发起的任何异步读或写, 直到到期时间被再次设置. 对 async_connect 的调用同时算作一次读和一次写.

参数

名称

说明

expiry_time

逻辑操作应被视为超时的时长.
