http::basic_parser::is_done

如果报文已完成, 则返回 true.

概要 
bool
is_done() const;
说明

在产出完整报文头且以下条件之一成立后, 报文即告完成:

  • 已设置跳过正文选项.
  • 报文语义表明没有正文.
  • 报文语义表明预期有正文, 且整个正文已解析.
