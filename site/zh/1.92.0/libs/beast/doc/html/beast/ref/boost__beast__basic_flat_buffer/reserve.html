basic_flat_buffer::reserve

保证最小容量.

概要 
void
reserve(
    std::size_t n);
说明

此函数调整内部存储 (如有必要) , 保证至少 n 字节的空间.

先前使用 data 或 prepare 获得的缓冲区序列将失效.

参数

名称

说明

n

新容量的最小字节数. 若该值大于最大大小, 则最大大小将向上调整为此值.
异常安全

基本保证.

异常

类型

抛出时机

std::length_error

若 n 大于分配器的最大分配大小.
