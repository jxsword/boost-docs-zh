FieldsWriter

FieldsWriter 提供一种算法, 为一组字段获取表示完整序列化 HTTP/1 头的缓冲区序列. 实现会在需要时构造此类型的实例, 并调用它一次来获取缓冲区.

  • W 表示一个满足 FieldsWriter 要求的类型.

  • a 是一个类型为 W.
  • f 是一个类型为 F.
  • v 是一个 unsigned 值, 表示 HTTP 版本.
  • c 是一个 unsigned, 表示 HTTP 状态码.
  • m 是一个类型为 verb.

语义, 前置/后置条件

W::const_buffers_type

满足 ConstBufferSequence 要求的类型. 这是 W::get 返回的缓冲区的类型.

W{f,v,m}

实现调用此构造函数, 以指示被序列化的字段构成 HTTP 请求的一部分. f 的生存期保证不早于 W 被销毁之时结束.

W{f,v,c}

实现调用此构造函数, 以指示被序列化的字段构成 HTTP 响应的一部分. f 的生存期保证不早于 W 被销毁之时结束.

W{f}

实现调用此构造函数, 以指示被序列化的字段构成分块编码末块尾随部分 (trailer) 的一部分. f 的生存期保证不早于 W 被销毁之时结束.

a.get()

W::const_buffers_type

在构造之后调用一次, 该函数返回一个常量缓冲区序列, 包含 HTTP 请求或响应的序列化表示, 包括最后的回车换行序列 ("\r\n") .

可以对返回的序列进行复制, 但其底层内存仍由写入器持有. 实现会在销毁 a 之前销毁缓冲区序列的所有副本.

范例 
struct FieldsWriter
{
    // The type of buffers returned by `get`
    struct const_buffers_type;

    // Constructor for requests
    FieldsWriter(Fields const& f, unsigned version, verb method);

    // Constructor for responses
    FieldsWriter(Fields const& f, unsigned version, unsigned status);

    // Returns the serialized header buffers
    const_buffers_type
    get();
};
