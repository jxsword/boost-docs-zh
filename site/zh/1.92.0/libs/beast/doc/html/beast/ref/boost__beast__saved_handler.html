说明

此容器可以保存任何完成处理器的类型擦除实例, 也可以为空. 当容器保存有值时, 实现为处理器的关联执行器维护一个 net::executor_work_guard 实例. 存储完成处理器需要动态分配内存, 并且可以选择指定分配器. 否则, 实现使用处理器的关联分配器.
