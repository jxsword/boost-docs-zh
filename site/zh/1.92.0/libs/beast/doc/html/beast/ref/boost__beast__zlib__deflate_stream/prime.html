zlib::deflate_stream::prime

向压缩输出流中插入位.

概要 
void
prime(
    int bits,
    int value,
    error_code& ec);
说明

此函数向 deflate 输出流中插入位. 其用意是在拼接时用上一个 deflate 流遗留的位来启动 deflate 输出. 因此, 此函数只能用于 raw deflate, 并且必须在初始化后的第一次 write 调用之前使用. bits 必须小于等于 16, 且 value 的最低有效位中相应数量的位将被插入输出.

返回值

error::need_buffers (内部缓冲区没有足够的空间插入这些位时) .
