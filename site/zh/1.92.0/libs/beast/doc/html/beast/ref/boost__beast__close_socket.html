close_socket

关闭套接字或类套接字对象.

概要

定义于头文件 <boost/beast/core/stream_traits.hpp> 

template<
    class Socket>
void
close_socket(
    Socket& sock);
说明

此函数尝试关闭一个表示套接字的对象. 在此语境中, 套接字是指对函数 void beast_close_socket(Socket&) 的非限定调用有良定义的对象. 函数 beast_close_socket 是一个 customization point, 允许用户自定义类型通过为相应类型重载此函数来提供执行关闭操作的算法.

由于定制点是函数调用, 将应用查找正确重载的常规规则, 包括参数依赖查找 ("ADL") 的规则. 这允许为某个提供了定制的类型派生的类继承该定制点.

为网络库类模板 net::basic_socket 提供了一个重载, 它为所有类套接字对象实现关闭算法 (因此该定制点得名) . 与 get_lowest_layer 结合使用时, 作用于分层流的通用算法可以在不知道具体类型列表的情况下关闭底层套接字.

示例 1

以下通用函数在流上同步发送一条消息, 然后关闭套接字.

template < class WriteStream>
void hello_and_close (WriteStream& stream)
{
    net::write(stream, net::const_buffer( "Hello, world!" , 13));
    close_socket(get_lowest_layer(stream));
}

为支持关闭用户自定义类型, 需要为该类型提供函数 beast_close_socket 的重载.

示例 2

以下代码声明一个包含私有套接字的用户自定义类型, 并提供关闭该私有套接字的定制点重载.

class my_socket
{
    net::ip::tcp::socket sock_;

public :
    my_socket(net::io_context& ioc)
        : sock_(ioc)
    {
    }

    friend void beast_close_socket(my_socket& s)
    {
        error_code ec;
        s.sock_.close(ec);
        // ignore the error
    }
};
