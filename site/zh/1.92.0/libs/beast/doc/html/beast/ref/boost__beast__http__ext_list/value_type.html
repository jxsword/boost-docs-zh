—
构造一个列表.

此容器允许迭代 HTTP 扩展中的参数列表. 参数列表是一系列名称/值对, 每对以分号开头. 值是可选的.

如果迭代字符串时遇到解析错误, 容器的行为将如同仅用第一个无效字符之前 (不含该字符) 的字符构成的字符串来构造列表.

BNF 
param-list  = *( OWS ";" OWS param )
param       = token OWS [ "=" OWS ( token / quoted- string ) ]

要使用此类, 请用要解析的字符串构造它, 然后使用 begin 和 end, 或用 range-for 迭代每一项:

示例 
for ( auto const & param : param_list{ ";level=9;no_context_takeover;bits=15" })
{
    std::cout << ";" << param.first;
    if (! param.second.empty())
        std::cout << "=" << param.second;
    std::cout << "\n" ;
}
说明

对的第一个元素是扩展标记, 对的第二个元素是一个可迭代容器, 保存该扩展的名称/值参数.
