buffers_prefix_view::buffers_prefix_view (2 of 3 overloads)

构造缓冲区序列前缀.

概要 
buffers_prefix_view(
    std::size_t size,
    BufferSequence const& buffers);
参数

名称

说明

size

前缀中的最大字节数. 若此值大于传入缓冲区的大小, 结果序列将表示整个输入序列.

buffers

要适配的缓冲区序列. 会复制该序列, 但不转移底层内存的所有权. 副本被保存, 生存期与视图相同.
