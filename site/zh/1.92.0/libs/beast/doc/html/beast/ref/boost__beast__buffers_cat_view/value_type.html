buffers_cat_view::value_type

解引用迭代器时返回的缓冲区类型.

概要 
using value_type = see-below;
说明

若视图中的每个缓冲区序列都是 MutableBufferSequence, 则 value_type 将为 net::mutable_buffer. 否则, value_type 将为 net::const_buffer.
