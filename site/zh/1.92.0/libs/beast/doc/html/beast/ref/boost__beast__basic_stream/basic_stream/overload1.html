basic_stream::basic_stream (1 of 3 overloads)

构造函数.

概要 
template<
    class... Args>
basic_stream(
    Args&&... args);
说明

此构造函数通过把所有参数转发给底层套接字来创建流. 之后套接字需要被打开并连接或接受, 才能在其上收发数据.
