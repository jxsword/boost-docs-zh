http::buffer_body::value_type::size

data 所指向缓冲区中的八位组数量.

概要 
std::size_t size = 0;
说明
序列化时

序列化期间如果 data 为 nullptr, 此值将被忽略. 否则, 它表示 data 所指向的有效正文八位组数量.

解析时

解析期间此字段的值会递减, 表示 data 所指向缓冲区中剩余的空闲八位组数量. 当它达到零时, 解析器将返回 error::need_buffer, 告知调用者应更新 data 和 size 的值以指向新的内存缓冲区.
