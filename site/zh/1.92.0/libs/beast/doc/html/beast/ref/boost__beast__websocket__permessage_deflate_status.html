websocket::permessage_deflate_status

permessage-deflate 扩展状态.

概要

定义于头文件 <boost/beast/websocket/stream.hpp> 

struct permessage_deflate_status
数据成员

名称

说明

active

true (若 permessage-deflate 扩展处于活动状态)

client_window_bits

客户端使用的窗口位数.

server_window_bits

服务器使用的窗口位数.
说明

这些设置指示 permessage-deflate 扩展的状态, 显示它是否处于活动状态以及所用的窗口位数.

此类型的对象与 beast::websocket::stream::get_status.
