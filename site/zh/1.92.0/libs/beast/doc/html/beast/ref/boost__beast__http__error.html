http::error

HTTP 算法和操作返回的错误码.

概要

定义于头文件 <boost/beast/http/error.hpp> 

enum error
取值

名称

说明

end_of_stream

已到达流末尾.

当尝试读取 HTTP 数据且流在任何对应新 HTTP 报文的八位组被接收之前返回错误 net::error::eof 时, 会返回此错误.

partial_message

传入的报文不完整.

解析期间到达流末尾且已收到一些八位组、但未收到整个报文时, 会发生这种情况.

need_more

需要更多缓冲区.

解析期间需要更多八位组时返回此错误. 调用者应向现有缓冲区追加更多数据, 然后重试解析操作.

unexpected_body

解析期间遇到了意外的正文.

尝试把正文八位组解析进具有 empty_body 正文类型的报文容器时, 会返回此错误.

参见

empty_body

need_buffer

需要更多缓冲区.

在以下条件下会返回此错误:

  • 使用 buffer_body 进行序列化期间. 调用者应更新正文使其指向新缓冲区, 或指示正文中没有更多八位组.
  • 使用 buffer_body 进行解析期间. 调用者应更新正文使其指向新的存储区域, 以接收更多正文八位组.

end_of_chunk

已到达分块末尾.

buffer_overflow

超过缓冲区最大值.

把 HTTP 内容读入动态缓冲区且操作会超过缓冲区最大大小时, 会返回此错误.

header_limit

超过报文头限制.

解析器检测到传入的报文头超过了配置的限制.

body_limit

超过正文限制.

解析器检测到传入的报文正文超过了配置的限制.

bad_alloc

内存分配失败.

当 basic_fields 抛出 std::bad_alloc 时, parser 会把它转换为此错误.

bad_line_ending

行结尾格式错误.

bad_method

方法无效.

bad_target

请求目标 (request-target) 无效.

bad_version

HTTP 版本无效.

bad_status

状态码无效.

bad_reason

原因短语无效.

bad_field

字段名无效.

bad_value

字段值无效.

bad_content_length

Content-Length 无效.

bad_transfer_encoding

Transfer-Encoding 无效.

bad_chunk

分块语法无效.

bad_chunk_extension

分块扩展无效.

bad_obs_fold

obs-fold 超过了内部限制.

multiple_content_length

响应包含多个相互冲突的 Content-Length.

stale_parser

解析器已失效 (stale).

尝试复用已完成报文解析的解析器时会发生这种情况. 程序必须为每个报文构造一个新的解析器. 把解析器存入 boost 或 std::optional 容器即可轻松做到这一点.

short_read

报文正文比预期的短.

尝试从文件读取时遇到意外的文件结束情况, file_body 会返回此错误.

header_field_name_too_large

报文头字段名超过 basic_fields::max_name_size.

header_field_value_too_large

报文头字段值超过 basic_fields::max_value_size.
