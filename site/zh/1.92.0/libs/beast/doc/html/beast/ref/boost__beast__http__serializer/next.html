http::serializer::next

返回序列化中的下一组缓冲区.

概要 
template<
    class Visit>
void
next(
    error_code& ec,
    Visit&& visit);
说明

此函数会尝试调用 visit 函数对象, 传入一个类型未指定的 ConstBufferSequence, 表示此对象所代表报文序列化中的下一组缓冲区.

如果序列化中没有更多缓冲区, 则不会调用访问函数. 在这种情况下, 不会指示任何错误, 且函数 is_done 将返回 true.

参数

名称

说明

ec

若发生了错误, 则设置为该错误.

visit

要调用的函数. 此对象的等价函数签名必须为:

template < class ConstBufferSequence>
void visit(error_code&, ConstBufferSequence const &);

该函数不会被复制; 如果没有发生错误, 它将在调用 next 返回之前被调用.
