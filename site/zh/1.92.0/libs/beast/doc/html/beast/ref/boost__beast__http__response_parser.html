http::response_parser

用于产出响应报文的 HTTP/1 解析器.

概要

定义于头文件 <boost/beast/http/parser.hpp> 

template<
    class Body,
    class Allocator = std::allocator<char>>
using response_parser = parser< false, Body, Allocator >;
类型

名称

说明

is_request

如果此解析器解析请求, 则为 true; 对响应则为 false.

value_type

解析器返回的报文类型.
成员函数

名称

说明

body_limit

设置载荷正文的限制.

chunked

如果 Transfer-Encoding 的最后一个值是 "chunked", 则返回 true.

content_length

如果已知, 返回 Content-Length 的可选值.

content_length_remaining

如果已知, 返回剩余内容长度.

eager

如果设置了 eager 解析选项, 则返回 true.
—
设置 eager 解析选项.

get

返回解析出的报文.

got_some

如果解析器已收到至少一个字节的输入, 则返回 true.

header_limit

设置报文头总大小的限制.

is_done

如果报文已完成, 则返回 true.

is_header_done

如果解析器已产出完整的报文头, 则返回 true.

keep_alive

如果报文具有 keep-alive 连接语义, 则返回 true.

merge_all_trailers

如果允许解析器合并所有尾部字段, 则返回 true.
—
设置是否允许解析器合并所有尾部字段.

need_eof

如果报文语义要求文件结束, 则返回 true.

on_chunk_body

设置在分块正文数据上要调用的回调.

on_chunk_header

设置在每个分块头上要调用的回调.

operator=

赋值 (不允许)

parser

构造函数 (不允许)
—
构造函数.
—
从另一个解析器构造解析器, 并更改 Body 类型.

put

向解析器写入缓冲区序列.

put_eof

通知解析器已到达流末尾.

release

返回解析出的报文的所有权.

skip

如果设置了 skip 解析选项, 则返回 true.
—
设置 skip 解析选项.

upgrade

如果报文是升级报文, 则返回 true.

~parser [destructor]

析构函数.

此类使用基本的 HTTP/1 线格式解析器把一系列八位组转换为 message, 并使用 basic_fields 容器表示字段.

模板参数

类型

说明

isRequest

指示将解析请求还是响应.

Body

用于表示正文的类型. 它必须满足 Body 的要求.

Allocator

与 basic_fields 容器一起使用的分配器类型.
备注

每个报文都需要解析器的一个新实例.
