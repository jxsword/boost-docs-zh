lowest_layer_type

用于确定流层栈最底层类型的特征 (trait).

概要

定义于头文件 <boost/beast/core/stream_traits.hpp> 

template<
    class T>
using lowest_layer_type = see-below;
说明

如果 t.next_layer() 对对象 t (类型为 T) 有良好定义, 则 lowest_layer_type<T> 将是 lowest_layer_type<decltype(t.next_layer())> 的别名; 否则它将是类型 std::remove_reference<T>.

参数

名称

说明

T

要确定其最底层类型的类型.
返回值

最底层的类型.
