http::icy_stream::write_some (1 of 2 overloads)

向流写入一些数据.

概要 
template<
    class ConstBufferSequence>
std::size_t
write_some(
    ConstBufferSequence const& buffers);
说明

该函数用于向流写入数据. 函数调用将阻塞, 直到成功写入一个或多个字节的数据, 或者发生错误.

参数

名称

说明

buffers

要写入的数据.
返回值

写入的字节数.

异常

类型

抛出时机

[link beast.ref.boost__beast__system_error system_error]

失败时抛出.
备注

write_some 操作可能不会把全部数据传输给对端. 如果需要确保在阻塞操作完成之前写入所有数据, 请考虑使用函数 net::write.
