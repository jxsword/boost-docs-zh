http::icy_stream::async_write_some

启动一次异步写入.

概要 
template<
    class ConstBufferSequence,
    class WriteHandler = net::default_completion_token_t<executor_type>>
DEDUCED
async_write_some(
    ConstBufferSequence const& buffers,
    WriteHandler&& handler = net::default_completion_token_t< executor_type >{});
说明

此函数用于向流异步写入一个或多个字节的数据. 函数调用总是立即返回.

参数

名称

说明

buffers

要写入流的数据. 尽管 buffers 对象可能会按需复制, 但底层缓冲区的所有权仍由调用者保留, 调用者必须保证它们在处理器被调用之前保持有效.

handler

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
  error_code const & error,          // Result of operation.
  std::size_t bytes_transferred     // Number of bytes written.
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将通过派发到立即执行器完成. 若未指定立即执行器, 这等同于使用 net::post.
备注

async_write_some 操作可能不会把全部数据传输给对端. 如果需要确保在异步操作完成之前写入所有数据, 请考虑使用函数 net::async_write.
