websocket::stream::handshake (1 of 4 overloads)

以客户端角色执行 WebSocket 握手.

概要 
void
handshake(
    string_view host,
    string_view target);
说明

此函数用于执行 WebSocket 握手, 这是发送和接收报文之前必需的步骤. 在握手期间, 客户端发送 WebSocket 升级 HTTP 请求, 服务器以指示握手结果的 HTTP 响应作为回复.

调用将阻塞, 直到下列条件之一成立:

  • 请求已发送且响应已收到.
  • 发生错误.

该算法称为 组合操作, 是通过调用下一层的 read_some 和 write_some 函数.

如果收到的 HTTP 响应表明服务器接受了升级 (以 status-code 的 beast::http::status::switching_protocols.

参数

名称

说明

host

远程主机的名称. HTTP 协议要求用它设置 "Host" 头字段.

target

request-target (origin-form 形式) . 服务器可以用目标来区分同一监听端口上的不同服务.
异常

类型

抛出时机

[link beast.ref.boost__beast__system_error system_error]

失败时抛出.
示例 
ws.handshake( "localhost" , "/" );
