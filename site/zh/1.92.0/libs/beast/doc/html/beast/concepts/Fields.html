Fields

Fields 是容纳 HTTP 头字段及其值的容器. 实现还会按需让容器存储请求目标以及方法与过时原因短语的非标准字符串. 满足这些要求的类型总是可以被序列化.

关联类型
  • is_fields
  • FieldsWriter
要求

本表中:

  • F 表示一个满足 Fields 要求的类型.
  • W 表示一个满足 FieldsWriter 要求的类型.
  • a 表示一个类型为 F.
  • c 表示一个类型为 F 的 (可能为 const 的) 值.
  • b 是一个类型为 bool
  • n 是一个类型为 boost::optional<std::uint64_t>.
  • s 是一个类型为 string_view.
  • v 是一个类型为 unsigned int 的值, 表示 HTTP 版本.

W

c.get_method_impl()

string_view

返回方法文本. 实现只在请求头中检索先前通过调用 set_method_impl 以非空字符串设置的方法文本时才调用此函数.

c.get_target_impl()

string_view

返回目标字符串. 实现只在请求头中调用此函数.

c.get_reason_impl()

string_view

返回过时的请求文本. 实现只在响应头中检索先前通过调用 set_reason_impl 以非空字符串设置的原因文本时才调用此函数.

c.get_chunked_impl()

bool

返回 true, 若 Transfer-Encoding 字段值指示载荷为分块编码. 以下两个条件必须同时成立:

  • 报文中存在 Transfer-Encoding 字段.
  • 字段值的最后一项是 "chunked".

c.get_keep_alive_impl(v)

bool

返回 true, 若 Connection 字段的语义与版本指示在相应的响应被发送或接收之后连接应保持打开:

  • 若 (v < 11), 则当 "keep-alive" 记号出现在 Connection 字段值中时函数返回 true; 否则函数返回 false.
  • 若 (v == 11), 则当 "close" 记号出现在 Connection 字段值中时函数返回 false; 否则函数返回 true.

c.has_content_length()

bool

返回 true, 若 Content-Length 字段存在.

a.set_method_impl(s)

存储 s 的一份副本作为方法文本, 或当 s 为空时擦除先前存储的值. 实现只在请求头中调用此函数. 若容器不支持该操作, 此函数可能抛出 std::invalid_argument.

a.set_target_impl(s)

存储 s 的一份副本作为目标, 或当 s 为空时擦除先前存储的值. 实现只在请求头中调用此函数. 若容器不支持该操作, 此函数可能抛出 std::invalid_argument.

a.set_reason_impl(s)

存储 s 的一份副本作为原因文本, 或当 s 为空时擦除先前存储的原因文本值. 实现只在请求头中调用此函数. 若容器不支持该操作, 此函数可能抛出 std::invalid_argument.

a.set_chunked_impl(b)

按如下方式调整 Transfer-Encoding 字段值:

  • 若 b 为 true, 则当 "chunked" 记号尚未位于编码列表末尾时将其追加到编码列表. 若 Transfer-Encoding 字段不存在, 将以值 "chunked" 向容器插入该字段.
  • 若 b 为 `false, 则当 "chunked" 记号位于编码列表末尾时将其从编码列表中移除. 若移除后编码列表为空, 则在关联的 FieldsWriter 序列化这些字段时不得出现 Transfer-Encoding 字段.

若调整字段值的结果为空字符串, 则从容器中移除该字段.

a.set_content_length_impl(n)

按如下方式调整 Content-Length 字段值:

  • 若 n 包含值, 则 Content-Length 字段将被设置为该值的文本表示. 容器中任何先前存在的 Content-Length 字段都会被移除.
  • 若 n 不包含值, 则容器中任何存在的 Content-Length 字段都会被移除.

a.set_keep_alive_impl(v,b)

根据 和 的值调整 v and b 字段值. 字段值按 connection-option (rfc7230) 处理.

  • 若 (v < 11 && b), 则移除值中所有出现的 "close" 记号, 并在 "keep-alive" 记号尚不存在时将其加入值中.
  • 若 (v < 11 && ! b), 则移除值中所有出现的 "close" 与 "keep-alive" 记号.
  • 若 (v == 11 && b), 则移除值中所有出现的 "keep-alive" 与 "close" 记号.
  • 若 (v == 11 && ! b), 则移除值中所有出现的 "keep-alive" 记号, 并在 "close" 记号尚不存在时将其加入值中.

若调整字段值的结果为空字符串, 则从容器中移除该字段.

范例 
class Fields
{
public:
    /// Constructed as needed when fields are serialized
    struct writer;

protected:
    /** Returns the request-method string.

        @note Only called for requests.
    */
    string_view
    get_method_impl() const;

    /** Returns the request-target string.

        @note Only called for requests.
    */
    string_view
    get_target_impl() const;

    /** Returns the response reason-phrase string.

        @note Only called for responses.
    */
    string_view
    get_reason_impl() const;

    /** Returns the chunked Transfer-Encoding setting
    */
    bool
    get_chunked_impl() const;

    /** Returns the keep-alive setting
    */
    bool
    get_keep_alive_impl(unsigned version) const;

    /** Returns `true` if the Content-Length field is present.
    */
    bool
    has_content_length_impl() const;

    /** Set or clear the method string.

        @note Only called for requests.
    */
    void
    set_method_impl(string_view s);

    /** Set or clear the target string.

        @note Only called for requests.
    */
    void
    set_target_impl(string_view s);

    /** Set or clear the reason string.

        @note Only called for responses.
    */
    void
    set_reason_impl(string_view s);

    /** Sets or clears the chunked Transfer-Encoding value
    */
    void
    set_chunked_impl(bool value);

    /** Sets or clears the Content-Length field
    */
    void
    set_content_length_impl(boost::optional<std::uint64_t>);

    /** Adjusts the Connection field
    */
    void
    set_keep_alive_impl(unsigned version, bool keep_alive);
};

static_assert(is_fields<Fields>::value,
    "Fields type requirements not met");
