http::basic_parser::on_body_init_impl

在处理正文之前调用一次.

概要 
void
on_body_init_impl(
    boost::optional< std::uint64_t > const& content_length,
    error_code& ec);
说明

此虚函数调用一次, 在处理内容正文之前 (但在收到完整报文头之后).

参数

名称

说明

content_length

如果长度已知, 为表示以字节计的内容长度的值 (可以为零长度). 否则, 该值将为 boost::none.

ec

函数可以设置的输出参数, 用于指示错误. 在调用此函数之前错误会被清除.
