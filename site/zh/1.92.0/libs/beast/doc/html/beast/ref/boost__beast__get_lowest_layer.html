get_lowest_layer

返回流层栈中的最底层.

概要

定义于头文件 <boost/beast/core/stream_traits.hpp> 

template<
    class T>
lowest_layer_type< T >&
get_lowest_layer(
    T& t);
说明

如果 t.next_layer() 有良好定义, 则返回 get_lowest_layer(t.next_layer()). 否则, 返回 t.

流层是通过组合方式包装另一个对象的类类型对象, 它满足被包装类型的部分或全部具名要求, 并可选择地改变行为. 流层的例子包括 net::ssl::stream 或 beast::websocket::stream. 流层的拥有者可以把封装传递给流算法, 与之直接交互; 也可以调用 next_layer() 来取得被封装对象的引用并访问其成员. 当需要访问下一层中封装所不具备的功能时, 这样做是必要的. 例如, websocket::stream 允许读写, 但为了建立底层连接, 必须直接调用被封装流 (如 connect) 的成员.

通常, 组合链中的最后一个对象是具体的套接字对象 (例如 net::basic_socket 或派生自它的类). 函数 get_lowest_layer 的存在是为了在执行具名要求未规定的动作时方便地取得具体套接字, 例如修改套接字选项、取消所有未完成的异步 I/O, 或关闭套接字 (可能通过使用 close_socket).

示例 
// Set non-blocking mode on a stack of stream
// layers with a regular socket at the lowest layer.
template < class Stream>
void set_non_blocking (Stream& stream)
{
    error_code ec;
    // A compile error here means your lowest layer is not the right type!
    get_lowest_layer(stream).non_blocking( true , ec);
    if (ec)
        throw system_error{ec};
}
参数

名称

说明

t

分层对象栈中要返回其最底层的那个层.
参见

close_socket, lowest_layer_type
