http::basic_parser::eager (2 of 2 overloads)

设置 eager 解析选项.

概要 
void
eager(
    bool v);
说明

通常, 解析器在成功解析一个结构化元素 (报文头、分块头或分块正文) 后即返回, 即使输入中还有剩余八位组. 在尝试先解析报文头时, 或当调用者想要检查可能被后续解析失效的信息 (例如分块扩展) 时, 这样做是必要的. eager 选项控制解析器在解析结构化元素之后, 如果缓冲区中还有剩余八位组且没有发生错误, 是否继续解析. 此选项在某些流操作期间会被自动设置或清除, 以在不改变功能的情况下提升性能.

默认设置为 false.

参数

名称

说明

v

true 表示设置 eager 解析选项, false 表示禁用它.
