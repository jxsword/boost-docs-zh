http::write_some (2 of 2 overloads)

使用序列化器把报文的一部分写入流.

概要

定义于头文件 <boost/beast/http/write.hpp> 

template<
    class SyncWriteStream,
    bool isRequest,
    class Body,
    class Fields>
std::size_t
write_some(
    SyncWriteStream& stream,
    serializer< isRequest, Body, Fields >& sr,
    error_code& ec);
说明

此函数使用调用者提供的 HTTP/1 序列化器把报文的一部分写入流. 调用将阻塞, 直到以下条件之一成立:

  • 已传输一个或多个字节.
  • 函数 serializer::is_done 返回 true
  • 流上发生错误.

此操作通过一次或多次调用流的 write_some 函数实现.

实际传输的数据量由底层流的行为控制, 并受通过调用 serializer::limit 获取或设置的序列化器缓冲区大小限制的约束. 设置限制并执行有界的工作有助于应用程序设置合理的超时, 也使应用层流量控制能够正常发挥作用, 例如在使用基于 TCP/IP 的流时.

参数

名称

说明

stream

数据要写入的流. 该类型必须支持 SyncWriteStream 概念.

sr

要使用的序列化器.

ec

用于指示发生了何种错误 (如无错误则不设置) .
返回值

写入流的字节数.

参见

async_write_some, serializer
