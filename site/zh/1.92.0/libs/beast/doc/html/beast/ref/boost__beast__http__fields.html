说明

swap

交换两个字段容器.

此容器用于存储构成 HTTP 报文中字段 (fields) 与尾部字段 (trailers) 的字段值对. 此类型的对象可迭代, 每个元素持有字段名和字段值.

字段名按原样存储, 但比较不区分大小写. 此容器的行为如同 std::multiset; 同一字段名的每次出现都有单独的值. 迭代此容器时, 字段按插入顺序呈现, 同名字段连续排列.
