websocket::close_code

关闭状态码.

概要

定义于头文件 <boost/beast/websocket/rfc6455.hpp> 

enum close_code
取值

名称

说明

normal

正常关闭; 连接已成功完成其创建时的既定用途.

going_away

端点即将离开, 原因可能是服务器故障, 也可能是浏览器正在离开建立该连接的页面.

protocol_error

端点因协议错误而终止连接.

unknown_data

连接正在被终止, 因为端点收到了它无法接受的数据类型 (例如, 纯文本端点收到了二进制数据) .

bad_payload

端点因收到了包含不一致数据的报文而终止连接 (例如文本报文中的非 UTF-8 数据) .

policy_error

端点因收到违反其策略的报文而终止连接. 这是一个通用状态码, 用于 1003 和 1009 都不适用的情况.

too_big

端点因收到了过大的数据帧而终止连接.

needs_extension

客户端因预期服务器协商一个或多个扩展而服务器没有协商而终止连接.

internal_error

服务器因遇到使其无法满足请求的意外情况而终止连接.

service_restart

服务器因正在重启而终止连接.

try_again_later

服务器因临时状况而终止连接, 例如过载而正在丢弃部分客户端.

bad_gateway

端点作为网关或代理, 从上游服务器收到了无效响应, 类似 HTTP 状态 502.

none

内部使用, 表示 "无错误".

此代码为保留值, 不得发送.

reserved1

由 WebSocket 标准保留以供将来使用.

此代码为保留值, 不得发送.

no_status

尽管预期应有状态码, 但未提供.

此代码为保留值, 不得发送.

abnormal

连接在未收到关闭帧的情况下被关闭.

此代码为保留值, 不得发送.

reserved3

由 WebSocket 标准保留以供将来使用.

此代码为保留值, 不得发送.
说明

这些代码随关闭帧一起发送.

参见

RFC 6455 7.4.1 Defined Status Codes
