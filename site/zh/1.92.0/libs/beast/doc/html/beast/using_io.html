网络

本库使用 Networking 技术规范 (计划最早于 2023 年成为 C++ 的正式组成部分) . 现有三种实现, 仅有细微差异, 其余 (函数签名与类型声明) 相同: Boost.Asio、独立版 Asio 和 networking-ts-impl. 下表展示类型为 io_context 的变量在各实现中如何声明 (包含相应头文件并使用合适的命名空间别名) :

表 1.2. Networking 实现

名称

命名空间与头示例

Boost.Asio 

#include <boost/asio/io_context.hpp>
namespace net = boost::asio;
net::io_context ioc;

Asio (独立版) 

#include <asio/io_context.hpp>
namespace net = asio;
net::io_context ioc;

networking-ts-impl 

#include <experimental/io_context>
namespace net = std::experimental::net;
net::io_context ioc;

本文档把上述三种实现互换地、统称为 Networking (或简称 networking) . Boost.Asio 与 Asio 风格的 Networking 还提供一些目前未纳入 C++ 提案、但可能出现在未来规范中的特性, 例如:

  • 串行端口
  • UNIX domain sockets
  • POSIX 信号 (如 SIGINT、SIGABORT)
  • TLS 流 (如 OpenSSL)

Boost.Beast 具体依赖 Networking 的 Boost.Asio 风格, 尽管这在将来可能改变. 虽然本库提供了 HTTP 与 WebSocket 网络协议的高性能实现, 但它依赖 networking 接口执行一般性任务, 例如域名解析 (DNS 查询) 、建立外发连接和接受传入连接. 调用方负责与 networking 交互, 把对象初始化到本库可用的正确状态.

在本文档、示例代码和实现中, 命名空间 net 用于限定 Networking 标识符. 对 Boost.Beast 而言, net 将是 boost::asio 命名空间.

为进一步提升易用性, 本库提供了大量的类型与算法. 文档的这一部分解释这些类型与算法, 提供用法示例, 也为使用 networking 提供温习材料与教程.

缩略语

本文档假定读者熟悉 Boost.Asio (使用 Beast 的前提) . 全文使用的示例代码和标识符都以下列声明生效为前提书写:

#include <boost/beast/core.hpp>
#include <boost/beast/http.hpp>
#include <boost/asio.hpp>
#include <boost/asio/ssl.hpp>
#include <iostream>
#include <thread>

//
using namespace boost::beast;
namespace net = boost::asio;
namespace ssl = boost::asio::ssl;
using tcp = net::ip::tcp;

net::io_context ioc;
net::any_io_executor work =
    net::require(ioc.get_executor(),
        net::execution::outstanding_work.tracked);
std::thread t{[&](){ ioc.run(); }};

error_code ec;
tcp::socket sock{ioc};
