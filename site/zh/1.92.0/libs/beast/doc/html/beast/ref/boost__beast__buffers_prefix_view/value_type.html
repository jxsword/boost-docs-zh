buffers_prefix_view::value_type

缓冲区列表中每个元素的类型.

概要 
using value_type = see-below;
说明

若类型 BufferSequence 满足 MutableBufferSequence 的要求, 则 value_type 为 net::mutable_buffer. 否则, value_type 为 net::const_buffer.
