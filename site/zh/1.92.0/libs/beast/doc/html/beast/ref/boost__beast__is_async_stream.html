is_async_stream

判断 T 是否满足 AsyncStream 的要求.

概要

定义于头文件 <boost/beast/core/stream_traits.hpp> 

template<
    class T>
using is_async_stream = see-below;
说明

元函数用于对模板类型执行编译期检查. 此类型将为 std::true_type, 如果 T 满足要求; 否则类型将为 std::false_type.

示例

配合 static_assert 使用:

template < class AsyncStream>
void f(AsyncStream& stream)
{
    static_assert (is_async_stream<AsyncStream>::value,
        "AsyncStream type requirements not met" );
...

配合 std::enable_if 使用 (SFINAE):

template < class AsyncStream>
typename std::enable_if<is_async_stream<AsyncStream>::value>::type
f(AsyncStream& stream);
