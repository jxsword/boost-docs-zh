DynamicBuffer

动态缓冲区封装了一块可按需自动调整大小的内存存储, 其中内存被划分为一个输入序列后跟一个输出序列. 这些内存区域是动态缓冲区内部的, 但提供了对元素的直接访问, 使其能够高效地与 I/O 操作 (如套接字的发送或接收操作) 配合使用. 写入动态缓冲区对象输出序列的数据会追加到同一对象的输入序列.

该概念的接口旨在允许以下实现策略:

  • 单个连续的八位组数组, 按需重新分配以适应八位组序列大小的变化. 这是 flat_buffer 当前提供的实现方式.
  • 一个由一个或多个八位组数组组成的序列, 每个数组大小相同. 会向序列追加额外的八位组数组对象, 以适应八位组序列大小的变化.
  • 一个由一个或多个大小不一的八位组数组组成的序列. 会向序列追加额外的八位组数组对象, 以适应字符序列大小的变化. 这是 multi_buffer 当前提供的实现方式.
关联要求
  • boost::asio::is_dynamic_buffer
  • ConstBufferSequence
  • MutableBufferSequence
要求
  • D 表示一个动态缓冲区类.
  • a 表示一个类型为 D.
  • c 表示一个类型为 D 的 (可能为 const 的) 值.
  • n 表示一个类型为 std::size_t.
  • T 表示一个满足 ConstBufferSequence 要求的类型.
  • U 表示一个满足 MutableBufferSequence 要求的类型.

c.size()

返回输入序列的大小, 单位为字节.

c.max_size()

std::size_t

返回输入序列与输出序列大小之和的允许上限.

c.capacity()

std::size_t

返回动态缓冲区在无需重新分配的情况下所能容纳的输入序列与输出序列大小之和的最大值.

c.data()

D::const_buffers_type

返回表示输入序列所关联内存的常量缓冲区序列 u, 且满足 buffer_size(u) == size().

a.prepare(n)

D::mutable_buffers_type

返回表示输出序列的可变缓冲区序列 u, 且满足 buffer_size(u) == n. 动态缓冲区按需重新分配内存. 先前通过 data() 或 prepare() 获得的所有常量或可变缓冲区序列都将失效.

抛出: length_error, 若 size() + n 超过 max_size().

a.commit(n)

把输出序列开头的 n 个字节追加到输入序列的末尾. 输出序列的剩余部分被丢弃. 如果 n 大于输出序列的大小, 则整个输出序列被追加到输入序列. 先前使用 data() 或 prepare() 获得的所有常量或可变缓冲区序列都会失效.

a.consume(n)

从输入序列的开头移除 n 个字节. 如果 n 大于输入序列的大小, 则整个输入序列被移除. 先前使用 data() 或 prepare() 获得的所有常量或可变缓冲区序列都会失效.
