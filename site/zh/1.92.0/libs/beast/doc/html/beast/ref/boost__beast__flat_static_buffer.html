flat_static_buffer

一种 DynamicBuffer, 其内部缓冲区大小固定且不进行任何内存分配.

概要

定义于头文件 <boost/beast/core/flat_static_buffer.hpp> 

template<
    std::size_t N>
class flat_static_buffer :
    public flat_static_buffer_base
类型

名称

说明

const_buffers_type

用于表示可读字节的 ConstBufferSequence.

mutable_buffers_type

用于表示可写字节的 MutableBufferSequence.
成员函数

名称

说明

base

返回此对象的 flat_static_buffer_base 部分.

capacity

返回无需分配即可容纳的输入与输出大小之和的最大值.

cdata

返回表示可读字节的常量缓冲区序列.

clear

把可读和可写字节清零.

commit

把可写字节追加到可读字节.

consume

从可读字节的开头移除字节.

data

返回表示可读字节的常量缓冲区序列.
—
返回表示可读字节的可变缓冲区序列.

flat_static_buffer [constructor]

构造函数.

max_size

返回输入与输出序列大小之和的最大值.

operator=

赋值.

prepare

返回表示可写字节的可变缓冲区序列.

size

返回可读字节的数目.
受保护成员函数

名称

说明

reset

重置所指向的缓冲区.
说明

由 data 与 prepare 返回的、表示可读与可写字节的缓冲区序列, 其类型将为 net::const_buffer 或 net::mutable_buffer.

模板参数

类型

说明

N

内部缓冲区中的字节数.
备注

为减少在推导上下文中传递此类型对象时的模板实例化数量, 接收函数的签名应改用 flat_static_buffer_base.
