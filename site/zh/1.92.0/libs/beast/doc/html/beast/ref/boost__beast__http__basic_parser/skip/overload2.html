http::basic_parser::skip (2 of 2 overloads)

设置 skip 解析选项.

概要 
void
skip(
    bool v);
说明

此选项控制解析器是否预期看到 HTTP 正文, 而不考虑某些字段 (如 Content-Length 或分块 Transfer-Encoding) 的存在与否. 视请求而定, 某些响应不带正文. 例如, 对来自隧道代理的 CONNECT 请求的 200 响应, 或对 HEAD 请求的响应. 在这些情况下, 调用者可以使用此函数告知解析器预期没有正文. 解析器将在收到报文头后认为报文已完成.

参数

名称

说明

v

true 表示设置跳过正文选项, false 表示禁用它.
备注

必须在处理任何字节之前调用此函数.
