http::verb

HTTP 请求方法动词.

概要

定义于头文件 <boost/beast/http/verb.hpp> 

enum verb
取值

名称

说明

unknown

未知方法.

此值表示请求方法字符串不是可识别的动词之一. 对方法感兴趣的调用者应使用返回原始字符串的接口.

delete_

DELETE 方法删除指定的资源.

get

GET 方法请求指定资源的一种表示.

使用 GET 的请求应只检索数据, 不应有其他影响.

head

HEAD 方法请求与 GET 请求相同的响应, 但不带响应正文.

这可用于获取写在响应头中的元信息, 而无需传输整个内容.

post

POST 方法请求服务器接受请求中包含的实体, 作为 URI 所标识 Web 资源的新从属资源.

POST 的数据例如可以是对现有资源的注释; 面向公告板、新闻组、邮件列表或评论主题的消息; 提交 Web 表单给数据处理进程所得的数据块; 或要添加到数据库的条目

put

PUT 方法请求把所包含的实体存储在提供的 URI 下.

如果 URI 指向已存在的资源, 则修改它; 如果 URI 不指向现有资源, 则服务器可以用该 URI 创建资源.

connect

CONNECT 方法把请求连接转换为透明的 TCP/IP 隧道.

这通常用于通过未加密的 HTTP 代理促成 SSL 加密通信 (HTTPS).

options

OPTIONS 方法返回服务器对指定 URL 支持的 HTTP 方法.

可以通过请求 '*' 而不是特定资源, 用它来检查 Web 服务器的功能.

trace

TRACE 方法回显收到的请求, 使客户端能够看到中间服务器做了哪些 (如果有) 更改或添加.
