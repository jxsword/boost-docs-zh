文件

在实现服务器等网络算法时, 经常需要与系统上的文件交互. Beast 定义了 文件 concept 及若干模型, 以便跨平台地与底层文件系统交互:

表 1.12. 文件类型

名称

说明

file

file 是以下实现之一的类型别名, 取决于目标平台可用的设施.

file_stdio

此 文件 实现使用包含 <cstdio>.

file_win32

这实现了一个 文件 (基于 Win32 API) . 必要时它提供对原生文件句柄的低层访问.

file_posix

对 POSIX 系统, 此类提供了 文件 的合适实现, 它包装原生文件描述符并在必要时提供.
