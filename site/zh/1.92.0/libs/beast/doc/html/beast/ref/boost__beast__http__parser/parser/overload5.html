http::parser::parser (5 of 5 overloads)

从另一个解析器构造解析器, 并更改 Body 类型.

概要 
template<
    class OtherBody,
    class... Args>
parser(
    parser< isRequest, OtherBody, Allocator >&& parser,
    Args&&... args);
说明

这通过从另一个具有不同正文类型的解析器移动构造报文头来构造新的解析器. 被构造来源的解析器不得已解析任何正文八位组或已初始化 BodyReader, 否则将产生异常.

示例 
// Deferred body type commitment
request_parser<empty_body> req0;
...
request_parser<string_body> req{std::move(req0)};

如果抛出异常, 被构造来源的解析器的状态是未定义的.

参数

名称

说明

parser

要从中构造的另一个解析器. 此调用返回后, 被构造来源的解析器只能被销毁.

args

转发给报文构造函数的可选参数.
异常

类型

抛出时机

std::invalid_argument

当被构造来源的解析器已初始化正文读取器时抛出.
备注

仅当另一个解析器使用不同的正文类型时, 此函数才参与重载决议.
