http::parser::body_limit

(继承自 http::basic_parser)

设置载荷正文的限制.

概要 
void
body_limit(
    boost::optional< std::uint64_t > v);
说明

此函数设置载荷正文允许的最大大小, 即在移除除 chunked 之外的任何编码之前的大小. 根据报文语义, 将适用以下情形之一:

  • 指定了 Content-Length 且超出限制. 在这种情况下, 解析完报文头后会立即返回结果 error::body_limit.
  • 未指定 Content-Length, 且未把 chunked 编码指定为最后一种编码. 在这种情况下, 报文结束由关联流或输入源上的文件结束指示符确定. 如果提供给解析器的正文载荷八位组数量足以超过配置的限制, 解析将失败并返回结果 error::body_limit
  • Transfer-Encoding 把 chunked 编码指定为最后一种编码. 在这种情况下, 当移除分块编码后产生的正文载荷八位组数量超过配置的限制时, 解析将失败并返回结果 error::body_limit.

在解析了任何正文八位组之后设置限制会导致未定义行为.

默认限制为请求 1MB、响应 8MB.

参数

名称

说明

v

表示正文限制的可选整数值. 如果它等于 boost::none, 则禁用正文限制.
