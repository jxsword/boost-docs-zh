http::basic_fields::find (2 of 2 overloads)

返回指向不区分大小写匹配字段名的迭代器.

概要 
const_iterator
find(
    string_view name) const;
说明

如果存在多个具有指定名称的字段, 则返回按插入顺序定义的第一个字段.

参数

名称

说明

name

字段名. 它被解释为不区分大小写的字符串.
返回值

指向匹配字段的迭代器, 若未找到匹配则为 end().
