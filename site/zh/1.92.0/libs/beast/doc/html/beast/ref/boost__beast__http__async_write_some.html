http::async_write_some

使用序列化器把报文的一部分异步写入流.

概要

定义于头文件 <boost/beast/http/write.hpp> 

template<
    class AsyncWriteStream,
    bool isRequest,
    class Body,
    class Fields,
    class WriteHandler = net::default_completion_token_t<            executor_type<AsyncWriteStream>>>
DEDUCED
async_write_some(
    AsyncWriteStream& stream,
    serializer< isRequest, Body, Fields >& sr,
    WriteHandler&& handler = net::default_completion_token_t< executor_type< AsyncWriteStream > >{});
说明

此函数使用调用者提供的 HTTP/1 序列化器把报文的一部分异步写入流. 函数调用总是立即返回. 异步操作将持续进行, 直到以下条件之一成立:

  • 已传输一个或多个字节.
  • 函数 serializer::is_done 返回 true
  • 流上发生错误.

此操作以对流的 async_write_some 的零次或多次调用实现, 称为 composed operation. 程序必须确保在本操作完成之前流不执行其他写入.

实际传输的数据量由底层流的行为控制, 并受通过调用 serializer::limit 获取或设置的序列化器缓冲区大小限制的约束. 设置限制并执行有界的工作有助于应用程序设置合理的超时, 也使应用层流量控制能够正常发挥作用, 例如在使用基于 TCP/IP 的流时.

参数

名称

说明

stream

数据要写入的流. 该类型必须支持 AsyncWriteStream 概念.

sr

要使用的序列化器. 对象必须至少保持有效直到处理器被调用; 所有权不发生转移.

handler

操作完成时要调用的完成处理器. 实现通过衰减复制取得处理器的所有权. 处理器的等效函数签名必须是:

void handler(
    error_code const & error,        // result of operation
    std::size_t bytes_transferred   // the number of bytes written to the stream
);

若处理器有关联的立即执行器, 将向它派发立即完成. 否则, 处理器不会在此函数内部被调用. 处理器的调用将以与使用 net::post 等效的方式进行.
逐操作取消

此异步操作支持以下 net::cancellation_type 值的取消:

  • net::cancellation_type::terminal

如果 stream 还支持终止取消, terminal 取消会使流处于未定义状态, 此时只有关闭它才保证成功.
