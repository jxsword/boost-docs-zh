buffered_read_stream::capacity

设置最大缓冲区大小.

概要 
void
capacity(
    std::size_t size);
说明

这会更改用于保存读取数据的内部缓冲区的最大大小. 此调用不丢弃任何字节. 若缓冲区大小设置为零, 将不再缓冲更多数据.

线程安全: 调用者负责确保从同一个隐式或显式 strand 发起调用.

参数

名称

说明

size

读缓冲区中的字节数.
备注

这是一个软限制. 若新的最大大小小于缓冲区中的数据量, 不丢弃任何字节.
