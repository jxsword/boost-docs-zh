http::basic_parser::on_chunk_header_impl

每次收到分块编码正文的新分块头时调用.

概要 
void
on_chunk_header_impl(
    std::uint64_t size,
    string_view extensions,
    error_code& ec);
说明

每次收到新的分块头时都会调用此函数. 仅在存在分块传输编码时才使用此函数.

参数

名称

说明

size

此分块的大小, 以字节为单位.

extensions

包含全部分块扩展的字符串. 可以为空, 表示不存在扩展.

ec

函数可以设置的输出参数, 用于指示错误. 在调用此函数之前错误会被清除.
