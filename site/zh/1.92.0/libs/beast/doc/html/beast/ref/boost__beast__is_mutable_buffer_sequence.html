is_mutable_buffer_sequence

判断类型列表是否满足 MutableBufferSequence 要求.

概要

定义于头文件 <boost/beast/core/buffer_traits.hpp> 

template<
    class... BufferSequence>
using is_mutable_buffer_sequence = see-below;
说明

此元函数用于判断所有指定类型是否满足可变缓冲区序列的要求. 如果每个指定类型都满足要求, 此类型别名为 std::true_type; 否则, 此类型别名为 std::false_type.

模板参数

类型

说明

BufferSequence

要检查的零个或多个类型的列表. 若此列表为空, 结果类型别名将为 std::true_type.
