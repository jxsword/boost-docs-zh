static_buffer_base::prepare

返回表示可写字节的可变缓冲区序列.

概要 
mutable_buffers_type
prepare(
    std::size_t n);
说明

返回一个表示可写字节的可变缓冲区序列, 其中恰好包含 n 字节的存储空间.

先前使用 data 或 prepare 获得的所有缓冲区序列都可能失效.

参数

名称

说明

n

返回的缓冲区序列中期望的字节数.
异常

类型

抛出时机

std::length_error

若 size() + n 超过 max_size().
异常安全

强保证.
