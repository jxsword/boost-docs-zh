说明

此封装使用一次动态内存分配, 把长度大于 1 且总大小低于预定值的缓冲区序列的写入操作扁平化. 它主要用于克服当前版本 net::ssl::stream 的性能局限, 该版本在其底层 read some 和 write some 操作中不使用 OpenSSL 的分散/聚集接口.

如果你已经在使用 ssl_stream, 通常无需直接使用此类. 下面的示例展示如何把此类与 networking 自带的 ssl 流配合使用:

示例

要在 SSL 流上使用 flat_stream 模板, 请声明一个正确类型的变量. 传递给构造函数的参数会被转发给下一层的构造函数:

flat_stream<net::ssl::stream<ip::tcp::socket>> fs{ioc, ctx};

或者, 你也可以这样写

ssl::stream<ip::tcp::socket> ss{ioc, ctx};
flat_stream<net::ssl::stream<ip::tcp::socket>&> fs{ss};

所得的流可以传递给任何操作同步或异步读写流的流算法, 例如:

  • net::read, net::async_read
  • net::write, net::async_write
  • net::read_until, net::async_read_until

该流也可以在其他流封装中用作模板参数, 例如 websocket:

websocket::stream<flat_stream<net::ssl::stream<ip::tcp::socket>>> ws{ioc, ctx};
模板参数

类型

说明

NextLayer

表示下一层的类型, 操作期间将对它进行数据读写. 对于同步操作, 该类型必须支持 SyncStream 概念. 对于异步操作, 该类型必须支持 AsyncStream 概念. 此类型通常是 net::ssl::stream 的某种变体.
