Chat Server 🎦聊天服务器 🎦

此示例演示一个 websocket 聊天服务器, 允许多个用户连接并参与实时群聊. 它附带一个用 JavaScript 与 HTML5 实现的小型前端, 可在任何浏览器中运行. 该示例配有一小时的演讲, 讨论网络概念, 随后深入讲解客户端与服务器是如何构建的. 该演讲发表于 CppCon 2018. Beast 示例中的源代码包含对原始程序的改进.
