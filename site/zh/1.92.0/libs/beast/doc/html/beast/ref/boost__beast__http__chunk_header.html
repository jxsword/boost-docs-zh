说明

这实现了一个表示 chunk 头的 ConstBufferSequence. 序列化格式如下:

chunk-header    = 1*HEXDIG chunk-ext CRLF
chunk-ext       = *( ";" chunk-ext-name [ "=" chunk-ext-val ] )
chunk-ext-name  = token
chunk-ext-val   = token / quoted-string

分块扩展是可选的. 在报文头和分块正文序列化之后, 调用者还需负责序列化最后的 CRLF ("\r\n").

此类允许调用者分段发送分块正文: 先使用此类序列化分块头, 然后通过一次或多次流写操作调用序列化分块正文.

要使用此类, 请把它的实例作为缓冲区序列传递给流算法:

// writes "400;x\r\n"
net::write(stream, chunk_header{1024, "x" });
