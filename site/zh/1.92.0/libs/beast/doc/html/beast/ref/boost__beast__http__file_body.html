http::file_body

由文件系统中的文件表示的报文正文.

概要

定义于头文件 <boost/beast/http/file_body.hpp> 

using file_body = basic_file_body< file >;
类型

名称

说明

file_type

此正文使用的 File 类型.

reader

解析时存储缓冲区的算法.

value_type

message::body 成员的类型.

writer

序列化时获取缓冲区的算法.
静态成员函数

名称

说明

size

返回正文的大小.

此类型的报文其正文由文件系统中的文件表示. 使用此正文类型解析报文时, 数据存储在 path 所指向的文件中, 该文件必须可写. 序列化时, 实现会读取该文件并把那些八位组作为正文内容呈现. 这可用于在 Web 服务中提供来自目录的内容.

模板参数

类型

说明

File

用于访问文件的实现. 此类型必须满足 File 的要求.
类型

名称

说明

native_handle_type

底层文件句柄的类型.
成员函数

名称

说明

close

若文件已打开, 则将其关闭.

is_open

若文件已打开, 则返回 true.

native_handle

返回与文件关联的原生句柄.
—
设置与文件关联的原生句柄.

open

以指定模式打开给定路径处的文件.

pos

返回已打开文件中的当前位置.

read

从已打开的文件读取.

seek

调整已打开文件中的当前位置.

size

返回已打开文件的大小.

write

写入已打开的文件.

此别名根据平台和构建设置, 被设为 File 的最佳可用实现.
