BuffersGenerator

BuffersGenerator 为顺序处理生成序列化数据提供了一种通用接口.

生成器将被要求产出缓冲区. 消费方代码会通知已消费的数据量, 并反复查询缓冲区, 直到没有更多数据可用, 或生成器指示错误状态.

通过这种方式, 序列化器可以被适配为 BuffersGenerator, 例如 http::message_generator, 它为多种具体的 http 报文类型提供类型擦除接口.

write 和 async_write 操作的重载以自由函数形式提供. 这些操作将消费 BuffersGenerator 的输出, 并分别把数据写入 SyncWriteStream 或 AsyncWriteStream 来进行处理.

语义, 前置/后置条件

G::const_buffers_type

满足 ConstBufferSequence 要求的类型. 这是 g.prepare(ec) 返回的缓冲区的类型.

c.is_done()

bool

调用以询问生成器的完成状态.

当不会再产出新缓冲区且先前产出的缓冲区已被完全消费时, 生成器即告完成.

注释: 在 prepare 完成后于其上调用 g 的结果是未指定的.

g.prepare(ec)

G::const_buffers_type

调用以要求生成器产出包含待处理数据的缓冲区.

返回的值是表示未消费数据的 ConstBufferSequence.

该函数保证 ec.failed() 为 false (若没有错误) , 否则设置为相应的错误码.

若没有可用的未消费数据, 此操作应逐步推进, 最终到达完成状态.

在完成或遇到错误之后调用 prepare 的结果由生成器实现定义. 一般来说, 不能假定这样做是有意义或安全的.

返回缓冲区的容量由生成器实现定义.

注释: 先前调用 prepare 所获得的任何缓冲区都将失效.

g.consume(n)

该函数被调用以通知生成器的消费者 (调用方) 已处理了上次调用 prepare 所返回数据的一部分.

n 的值表示已处理的数据量 (以字节计) .

当 n 超过上次调用 prepare 所返回的字节数时, consume 的行为应等同于 n 等于该字节数.

剩余未消费的数据将在后续调用 prepare 时返回.

注释: 先前调用 prepare 所获得的任何缓冲区都将失效.

is_buffers_generator<G>

std::bool_constant

std::true_type 是 G 的别名, 否则是 std::false_type 的别名.

范例 
// A buffer sequence generator
struct BuffersGenerator
{
    using const_buffers_type = net::const_buffer;

    bool is_done() const;
    const_buffers_type prepare( error_code& ec );
    void consume( std::size_t n );
};

static_assert(
    is_buffers_generator<BuffersGenerator>::value, "");
