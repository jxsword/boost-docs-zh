分层流

Networking 的 net::ssl::stream 是一个类模板, 同时满足同步与异步读写流的要求, 它以 "下一层" 对象实现, 下一层的类型由类模板参数决定. SSL 流内部构造下一层对象的实例, 同时通过观察器 net::ssl::stream::next_layer() 允许外部访问. 下面声明一个以常规 TCP/IP 套接字为下一层的 SSL 流:

net::ssl::stream<net::ip::tcp::socket> ss(ioc, ctx);

使用此设计模式的对象在 networking 中称为 "流层栈". Beast 中使用的术语是 分层流, 不过拥有下一层的特性并不限于流. 与 SSL 流一样, websocket::stream 是以下一层对象为参数的类模板. 下面声明一个以常规 TCP/IP 套接字为下一层的 websocket 流:

websocket::stream<net::ip::tcp::socket> ws(ioc);

若需要安全 WebSocket 流, 只需更改下一层的类型并相应调整构造函数实参即可:

websocket::stream<net::ssl::stream<net::ip::tcp::socket>> ws(ioc, ctx);

可以按这种方式嵌套任意深度的流层来开发更高层的抽象. 流层栈实际上形成一条编译期单链表. 位于链表末端的对象称为 最底层, 它与其他层的不同之处在于通常代表底层套接字.

Beast 自带若干分层流包装器, 以及编写和使用分层流的设施:

表 1.6. 分层流算法与类型

名称

说明

basic_stream tcp_stream

此流可用于同步与异步读写. 它允许在逻辑操作上设置超时, 并且可以为流关联执行器以调用完成处理器. 这让你只需为流设置一次 strand, 之后所有异步操作都会自动使用它.

buffered_read_stream

带缓冲的读取流满足同步与异步读写流的要求, 并额外实现了可配置的读取缓冲.

close_socket

此函数通过不加限定地调用 beast_close_socket 定制点来关闭套接字, 使套接字能在泛型上下文中以可扩展的方式关闭.

get_lowest_layer

通过递归调用 next_layer 成员函数 (逐层调用直到遇到缺少该成员的对象) 返回流层栈中的最底层. 本示例通过取得最底层中的 TCP/IP 套接字并修改套接字选项, 把分层流置为非阻塞模式:

// Set non-blocking mode on a stack of stream
// layers with a regular socket at the lowest layer.
template <class Stream>
void set_non_blocking (Stream& stream)
{
    error_code ec;
    // A compile error here means your lowest layer is not the right type!
    get_lowest_layer(stream).non_blocking(true, ec);
    if(ec)
        throw system_error{ec};
}

http::icy_stream

ICY 流把来自 Shoutcast 服务器的非标准 "ICY 200 OK" HTTP 响应透明地转换为符合规范的 200 级 HTTP 响应.

lowest_layer_type

此元函数返回表示流层栈的类型所用的最底层类型. 这是 get_lowest_layer
