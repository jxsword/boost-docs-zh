http::basic_file_body

由文件系统中的文件表示的报文正文.

概要

定义于头文件 <boost/beast/http/basic_file_body.hpp> 

template<
    class File>
struct basic_file_body
类型

名称

说明

file_type

此正文使用的 File 类型.

reader

解析时存储缓冲区的算法.

value_type

message::body 成员的类型.

writer

序列化时获取缓冲区的算法.
静态成员函数

名称

说明

size

返回正文的大小.
说明

此类型的报文其正文由文件系统中的文件表示. 使用此正文类型解析报文时, 数据存储在 path 所指向的文件中, 该文件必须可写. 序列化时, 实现会读取该文件并把那些八位组作为正文内容呈现. 这可用于在 Web 服务中提供来自目录的内容.

模板参数

类型

说明

File

用于访问文件的实现. 此类型必须满足 File 的要求.
