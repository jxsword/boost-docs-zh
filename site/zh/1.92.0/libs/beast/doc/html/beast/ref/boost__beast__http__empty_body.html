http::empty_body

空的 Body

概要

定义于头文件 <boost/beast/http/empty_body.hpp> 

struct empty_body
类型

名称

说明

reader

用于解析正文的算法.

value_type

用于正文的容器类型.

writer

用于序列化正文的算法.
静态成员函数

名称

说明

size

返回正文的载荷大小.
说明

此正文用于表示没有报文正文的报文. 如果此正文与解析器一起使用, 且解析器遇到对应报文正文的八位组, 解析器将失败并报错误 http::unexpected_body .

此正文的 Content-Length 始终为 0.
