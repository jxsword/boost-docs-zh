saved_handler::emplace (1 of 2 overloads)

把完成处理器存入容器.

概要 
template<
    class Handler,
    class Allocator>
void
emplace(
    Handler&& handler,
    Allocator const& alloc,
    net::cancellation_type cancel_type = net::cancellation_type::terminal);
说明

要求 this->has_value() == false .

参数

名称

说明

handler

要存储的完成处理器. 实现通过执行衰变复制 (decay-copy) 取得处理器的所有权.

alloc

要使用的分配器.

cancel_type

允许用于完成此操作 (op) 的取消类型.
