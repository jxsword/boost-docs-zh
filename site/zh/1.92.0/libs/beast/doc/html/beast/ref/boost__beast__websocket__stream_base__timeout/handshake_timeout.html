websocket::stream_base::timeout::handshake_timeout

握手、接受和关闭操作的时限:

概要 
duration handshake_timeout;
说明

此值表示异步握手、接受和关闭操作是否有时间限制以及该时限的长度. 若此值等于 none, 则没有时间限制. 否则, 若任一适用操作耗时超过该时限, 操作将被取消, 并向完成处理器交付超时错误.
