http::basic_parser::on_chunk_body_impl

每次收到表示正文分块的一部分的额外数据时调用.

概要 
std::size_t
on_chunk_body_impl(
    std::uint64_t remain,
    string_view body,
    error_code& ec);
说明

解析报文期间, 每收到一段正文都会调用此虚函数. 仅在不存在分块传输编码时才使用此函数.

参数

名称

说明

remain

此分块中剩余的字节数. 其中包括传入的 body 的内容. 如果此值为零, 则表示这是最后一个分块.

body

保存额外正文内容的字符串. 其中可能包含空字符或不可打印字符.

ec

函数可以设置的输出参数, 用于指示错误. 在调用此函数之前错误会被清除.
返回值

此函数应返回从 body 值中实际消耗的字节数. 本次调用未消耗的字节将在后续调用中再次提供.

参见

on_body_impl
