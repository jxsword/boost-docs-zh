http::read (1 of 4 overloads)

使用解析器从流读取完整报文.

概要

定义于头文件 <boost/beast/http/read.hpp> 

template<
    class SyncReadStream,
    class DynamicBuffer,
    bool isRequest>
std::size_t
read(
    SyncReadStream& stream,
    DynamicBuffer& buffer,
    basic_parser< isRequest >& parser);
说明

此函数用于把来自流的完整报文读入一个 basic_parser 实例. 调用将阻塞, 直到以下条件之一成立:

  • basic_parser::is_done 返回 true
  • 发生错误.

此操作通过一次或多次调用流的 read_some 函数实现. 实现可能从流中读出超出所读报文末尾的额外字节. 这些额外字节存储在动态缓冲区中, 必须为其后的读取保留.

如果从流读取时收到文件结束错误, 则此函数返回的错误将是:

  • error::end_of_stream, 如果没有解析出任何字节; 或
  • error::partial_message, 如果解析出一些字节但报文不完整; 否则:
  • 一次成功的结果. 下一次读取尝试将返回 error::end_of_stream
参数

名称

说明

stream

要从中读取数据的流. 该类型必须满足 SyncReadStream 要求.

buffer

用于存放实现从流中读取的额外字节的存储空间. 这既是输入参数也是输出参数; 进入时, 解析器会先拿到动态缓冲区可读字节序列中剩余的数据. 该类型必须满足 DynamicBuffer 要求.

parser

要使用的解析器.
返回值

解析器消耗的字节数.

异常

类型

抛出时机

[link beast.ref.boost__beast__system_error system_error]

失败时抛出.
备注

实现会对传入的解析器调用 basic_parser::eager, 传入值 true.
