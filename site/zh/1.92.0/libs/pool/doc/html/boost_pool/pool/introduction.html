引言

什么是 Pool?

池分配是一种非常快速但用途受限的内存分配方案. 有关池分配的更多信息 (也称为 简单分隔存储), 参见 concepts 概念与 简单分隔存储.

为什么应当使用 Pool?

使用 Pool 能让你对程序中内存的使用方式有更多控制. 例如, 你可能遇到这样的情况: 想在某一时刻分配一大批小对象, 然后程序运行到某个点时它们都不再需要了. 使用 pool 接口, 你可以选择运行它们的析构函数, 或者干脆把它们扔到一边不管; pool 接口将保证不会有系统内存泄漏.

何时应当使用 Pool?

当大量分配和释放小对象时, 通常会使用池. 另一种常见用法是上述情形, 即许多对象可能被从内存中丢弃.

一般而言, 当你需要以更高效的方式进行特殊内存控制时, 请使用池.

应当使用哪种池分配器?

pool_allocator 是一种更通用的方案, 致力于高效处理对任意数量连续内存块的请求.

fast_pool_allocator 也是一种通用方案, 但致力于高效处理每次一个内存块的请求; 它也能用于连续内存块, 但效果不如 pool_allocator.

如果对性能有严格要求, 应使用 fast_pool_allocator 来处理诸如 std::list 之类的容器, 并使用 pool_allocator 来处理诸如 std::vector 之类的容器.
