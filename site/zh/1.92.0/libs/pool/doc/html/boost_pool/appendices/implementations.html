附录 F: 其他实现

池分配器存在于许多编程语言中, 并有许多变体. 许多实现的开端可以在常见的编程文献中找到; 下面给出其中一些. 注意, 这些都不是完整的 Pool 实现; 大多数把 Pool 的某些方面留作用户练习. 但是, 尽管缺少某些方面, 这些示例使用的都是本文档所述简单分隔存储 (Simple Segregated Storage) 的同一底层概念.

  1. The C++ Programming Language (《C++ 程序设计语言》), 第 3 版, Bjarne Stroustrup 著, 第 19.4.2 节. 缺少的方面:
    • 不可移植.
    • 无法处理任意数量对象的分配 (这被留作练习).
    • 非线程安全.
    • 存在静态初始化问题.
  2. MicroC/OS-II: The Real-Time Kernel (《MicroC/OS-II 实时内核》), Jean J. Labrosse 著, 第 7 章与附录 B.04.
    • 简单分隔存储方案在一个实际操作系统内部工作中运用的示例.
    • 缺少的方面:
    • 不可移植 (不过这没关系, 因为它是其自身操作系统的一部分).
    • 无法处理任意数量内存区块的分配 (不过这也没关系, 因为并不需要该功能).
    • 创建和销毁 Pool 需要不符合直觉的用户代码.
  3. Efficient C++: Performance Programming Techniques (《高效 C++: 性能编程技术》), Dov Bulka 与 David Mayhew 著, 第 6 章与第 7 章.
    • 这是一个迭代开发 Pool 方案的很好示例.
    • 但是, 他们的前提 (即系统提供的分配机制效率低得无可救药) 在我测试过的所有系统上都不成立.
    • 在接受他们的结论之前, 请先在你的系统上运行他们的计时测试.
    • 缺少的方面: 创建和销毁 Pool 需要不符合直觉的用户代码.
  4. Advanced C++: Programming Styles and Idioms (《高级 C++: 编程风格与惯用法》), James O. Coplien 著, 第 3.6 节.
    • 同时包含静态与动态池化的示例, 但缺少以下方面:
    • 非线程安全.
    • 静态池化示例不可移植.
