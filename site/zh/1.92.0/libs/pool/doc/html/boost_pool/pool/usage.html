如何使用 Pool?

参见 Pool 接口 一节, 其中涵盖本库提供的各种 Pool 接口.

库结构与依赖

本库所有对外符号的前向声明位于由 #include <boost/pool/poolfwd.hpp> 纳入作用域的头文件中.

本库可能使用一些宏, 它们以 BOOST_POOL_ 为前缀. 该规则的例外是包含文件保护宏, 对于文件 xxx.hpp, 它是 BOOST_xxx_HPP.

本库定义的所有对外符号都位于命名空间 boost:: 中. 仅由实现使用的所有符号都位于命名空间 boost::details::pool 中.

仅供实现使用的每个头文件都位于子目录 /detail/ 中.

库中的任何头文件都可以自行决定包含库中的任何其他头文件或任何系统提供的头文件.
