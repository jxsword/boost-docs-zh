头文件 <boost/pool/simple_segregated_storage.hpp>

简单分隔存储.

一个简单分隔存储实现: 简单分隔存储是 Boost Pool 库背后的基本思想. 简单分隔存储是最简单、也可能是最快的内存分配/释放算法. 它首先把一个内存区块划分为固定大小的内存块. 在实现之前, 区块来自哪里并不重要. 池就是以这种方式使用简单分隔存储的某个对象.


BOOST_POOL_VALIDATE_INTERNALS
namespace boost {
  template<typename SizeType> class simple_segregated_storage;
}
