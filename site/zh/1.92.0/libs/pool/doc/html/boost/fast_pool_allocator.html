类模板 fast_pool_allocator

boost::fast_pool_allocator — 一个符合 C++ 标准库要求的分配器, 专注于分配单个内存块.

概要

// In header: <boost/pool/pool_alloc.hpp>

template<typename T, typename UserAllocator, typename Mutex, 
         unsigned NextSize, unsigned MaxSize> 
class fast_pool_allocator {
public:
  // types
  typedef T                                      value_type;     
  typedef UserAllocator                          user_allocator; 
  typedef Mutex                                  mutex;          
  typedef value_type *                           pointer;        
  typedef const value_type *                     const_pointer;  
  typedef value_type &                           reference;      
  typedef const value_type &                     const_reference;
  typedef pool< UserAllocator >::size_type       size_type;      
  typedef pool< UserAllocator >::difference_type difference_type;

  // member classes/structs/unions

  // Nested class rebind allows for transformation from fast_pool_allocator<T>
  // to fast_pool_allocator<U>.
  template<typename U> 
  struct rebind {
    // types
    typedef fast_pool_allocator< U, UserAllocator, Mutex, NextSize, MaxSize > other;
  };

  // construct/copy/destruct
  fast_pool_allocator();
  template<typename U> 
    fast_pool_allocator(const fast_pool_allocator< U, UserAllocator, Mutex, NextSize, MaxSize > &);

  // public member functions
  void construct(const pointer, const value_type &);
  void destroy(const pointer);
  bool operator==(const fast_pool_allocator &) const;
  bool operator!=(const fast_pool_allocator &) const;

  // public static functions
  static pointer address(reference);
  static const_pointer address(const_reference);
  static size_type max_size();
  static pointer allocate(const size_type);
  static pointer allocate(const size_type, const void *);
  static pointer allocate();
  static void deallocate(const pointer, const size_type);
  static void deallocate(const pointer);

  // public data members
  static const unsigned next_size;
};

说明

类模板 pool_allocator 是一种更通用的方案, 致力于高效处理对任意数量连续内存块的请求; fast_pool_allocator 也是一种通用方案, 但专注于高效处理每次一个内存块的请求; 它也能用于连续内存块, 但效果不如 pool_allocator.

如果对性能有严格要求, 应使用 fast_pool_allocator 来处理诸如 std::list 之类的容器, 并使用 pool_allocator 来处理诸如 std::vector 之类的容器.

模板参数定义如下:

T 要分配/释放的对象类型.

UserAllocator. 定义底层 Pool 从系统分配内存所使用的方法. 详见 用户分配器.

Mutex 允许用户确定底层 singleton_pool 上使用的同步类型.

NextSize 该参数的值会在底层 Pool 创建时传递给它.

MaxSize 对所用最大大小的限制.

注释

本分配器所使用的底层 singleton_pool 会构造一个 永不释放 的池实例. 这意味着该分配器所分配的内存在 main() 结束之后仍可使用, 但也可能导致某些内存检查程序报告内存泄漏.

fast_pool_allocator 公有构造/复制/析构

  1. fast_pool_allocator();

    确保仅当本分配器的实例在全局初始化期间被构造时才构造底层 singleton_pool. 完整说明见 http://svn.boost.org/trac/boost/ticket/2359 处的 ticket #2359.

  2. template<typename U> 
  fast_pool_allocator(const fast_pool_allocator< U, UserAllocator, Mutex, NextSize, MaxSize > &);

    确保仅当本分配器的实例在全局初始化期间被构造时才构造底层 singleton_pool. 完整说明见 http://svn.boost.org/trac/boost/ticket/2359 处的 ticket #2359.
