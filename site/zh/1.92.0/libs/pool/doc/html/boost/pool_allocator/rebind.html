结构体模板 rebind

boost::pool_allocator::rebind — 嵌套类 rebind 允许从 pool_allocator<T> 转换为 pool_allocator<U>.

概要

// In header: <boost/pool/pool_alloc.hpp>



// Nested class rebind allows for transformation from pool_allocator<T> to
// pool_allocator<U>.
template<typename U> 
struct rebind {
  // types
  typedef pool_allocator< U, UserAllocator, Mutex, NextSize, MaxSize > other;
};

说明

嵌套类 rebind 允许通过成员 typedef other 从 pool_allocator<T> 转换为 pool_allocator<U>.
