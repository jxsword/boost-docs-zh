头文件 <boost/pool/object_pool.hpp>

提供了一个模板类型 boost::object_pool<T, UserAllocator>, 可用于对 T 类型对象进行快速高效的内存分配. 它还提供对未释放对象的自动析构.

namespace boost {
  template<typename T, typename UserAllocator> class object_pool;
}
