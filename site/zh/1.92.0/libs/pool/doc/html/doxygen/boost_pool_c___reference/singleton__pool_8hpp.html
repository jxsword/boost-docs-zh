头文件 <boost/pool/singleton_pool.hpp>

singleton_pool 类允许相同大小的其他池接口共享同一个底层池.

头文件 singleton_pool.hpp 提供了一个模板类 singleton_pool, 它以 singleton 对象的形式提供对一个池的访问.

namespace boost {
  template<typename Tag, unsigned RequestedSize, typename UserAllocator, 
           typename Mutex, unsigned NextSize, unsigned MaxSize> 
    class singleton_pool;

  singleton_pool< Tag, RequestedSize, UserAllocator, Mutex, NextSize, MaxSize >::storage_type singleton_pool< Tag, RequestedSize, UserAllocator, Mutex, NextSize, MaxSize >::storage;
  singleton_pool< Tag, RequestedSize, UserAllocator, Mutex, NextSize, MaxSize >::object_creator singleton_pool< Tag, RequestedSize, UserAllocator, Mutex, NextSize, MaxSize >::create_object;
}
