类模板 simple_segregated_storage

boost::simple_segregated_storage — 简单分隔存储 (Simple Segregated Storage) 是最简单、也可能是最快的内存分配/释放算法. 它负责把一个内存区块划分为固定大小的内存块: 区块来自哪里由类的客户决定.

概要

// In header: <boost/pool/simple_segregated_storage.hpp>

template<typename SizeType> 
class simple_segregated_storage {
public:
  // types
  typedef SizeType size_type;

  // private member functions
  simple_segregated_storage(const simple_segregated_storage &);
  void operator=(const simple_segregated_storage &);

  // private static functions
  static void * try_malloc_n(void *&, size_type, size_type);

  // protected member functions
  void * find_prev(void *);

  // protected static functions
  static void *& nextof(void *const);

  // public member functions
  simple_segregated_storage();
  void add_block(void *const, const size_type, const size_type);
  void add_ordered_block(void *const, const size_type, const size_type);
  bool empty() const;
  void * malloc();
  void free(void *const);
  void ordered_free(void *const);
  void * malloc_n(size_type, size_type);
  void free_n(void *const, const size_type, const size_type);
  void ordered_free_n(void *const, const size_type, const size_type);

  // public static functions
  static void * segregate(void *, size_type, size_type, void * = 0);
};

说明

模板类 simple_segregated_storage 控制对内存块空闲列表的访问. 请注意这是一个非常简单的类, 其几乎所有函数都带有前置条件. 它旨在成为最快且最小的快速内存分配器 - 例如, 可用于嵌入式系统的组件. 该类把许多困难的前置条件交由用户处理 (即对齐问题).

类型为 simple_segregated_storage<SizeType> 的对象在其空闲列表为空时是空的. 若它不为空, 则当其空闲列表有序时它是有序的. 如果对 malloc() 的重复调用会产生按 std::less<void *> 判定的不断递增的值序列, 则该空闲列表是有序的. 如果空闲列表保持其顺序方向 (即有序空闲列表在成员函数调用后仍然有序), 则该成员函数是 保持顺序的.

simple_segregated_storage 私有静态函数

  1. static void * 
try_malloc_n(void *& start, size_type n, size_type partition_size);

    要求:

    (n > 0), (start != 0), (nextof(start) != 0)

    后置条件:

    (start != 0) 该函数尝试在空闲列表中从 start 开始查找 n 个大小为 partition_size 的连续内存块. 若成功, 则返回该连续序列中的最后一个内存块, 从而该序列由 [start, {retval}] 给出. 若失败, 则或者因为已到空闲列表末尾, 或者遇到了不连续的内存块. 无论哪种情况, 它都会返回 0, 并把 start 设为最后考察的内存块. 若 nextof(start) == 0, 则已到空闲列表末尾. 否则, start 指向该连续序列中的最后一个内存块, 而 nextof(start) 指向下一个连续序列中的第一个内存块 (假定空闲列表有序).

simple_segregated_storage 受保护成员函数

  1. void * find_prev(void * ptr);

    遍历 "first" 所指的空闲列表, 并返回 "ptr" 若在空闲列表中所应处于位置之前的迭代器. 若 "ptr" 应位于空闲列表开头 (即 "first" 之前), 则返回 0.

    注释

    注意此函数查找的是 ptr 若在空闲列表中所应处于位置之前的位置. 它并不查找空闲列表中 ptr 之前的条目 (除非 ptr 已在空闲列表中). 具体而言, find_prev(0) 将返回 0, 而不是空闲列表中的最后一个条目.

    返回:

    ptr 若在空闲列表中所应处于位置之前的位置.

simple_segregated_storage 受保护的静态函数

  1. static void *& nextof(void *const ptr);

    返回值只是转换为适当类型的 *ptr. ptr 不得为 0. (为了提高代码可读性 :)

    举例来说, 假定我们想在第一个内存块之后截断空闲列表. 也就是说, 我们想把 *first 设为 0; 这将得到一个只有一个条目的空闲列表. 通常的做法是先把 first 转换为指向 void 指针的指针, 然后解引用并赋值 (*static_cast<void **>(first) = 0;). 通过使用这个便捷函数可以更轻松地完成 (nextof(first) = 0;).

    返回:

    解引用后的指针.

simple_segregated_storage 公有成员函数

  1. simple_segregated_storage();

    构造空的存储区.

    后置条件:

    empty()

    		 
  2. void add_block(void *const block, const size_type nsz, 
               const size_type npartition_sz);

    添加区块 分隔该区块, 并把其空闲列表合并进 "first" 所指的空闲列表.

    要求:

    与 segregate 相同.

    后置条件:

    !empty()

    		 
  3. void add_ordered_block(void *const block, const size_type nsz, 
                       const size_type npartition_sz);

    添加区块 (按序插入列表) 这一较慢版本的 add_block 会分隔该区块, 并按正确顺序把其空闲列表合并进我们的空闲列表.

  4. bool empty() const;

    返回:

    仅当 simple_segregated_storage 为空时才为 true.

    		 
  5. void * malloc();

    创建一个内存块.

    要求:

    !empty() 将 "first" 指针递增, 使其指向下一个内存块.

    		 
  6. void free(void *const chunk);

    释放一个内存块.

    要求:

    该内存块此前已由指向同一空闲列表的 malloc() 返回.

    后置条件:

    !empty()

    		 
  7. void ordered_free(void *const chunk);

    这一较慢版本的 'free' 实现会把内存按正确顺序放回列表中.

    要求:

    该内存块此前已由指向同一空闲列表的 malloc() 返回

    后置条件:

    !empty().

    		 
  8. void * malloc_n(size_type n, size_type partition_size);

    尝试查找 n 个大小为 partition_sz 的连续内存块序列. 若找到, 则把它们全部从空闲列表移除, 并返回指向第一个的指针. 若未找到, 则返回 0. 强烈建议 (但不要求) 空闲列表是有序的, 因为除非该序列在空闲列表中也是连续的, 否则此算法将无法找到连续序列. 保持顺序. 相对于空闲列表大小为 O(N).

  9. void free_n(void *const chunks, const size_type n, 
            const size_type partition_size);

    注释

    如果你频繁地分配/释放 n 个内存块, 则应当使用有序池.

    要求:

    这些内存块此前已从 *this 分配, 且 n 与 partition_size 的值相同.

    后置条件:

    !empty() 

  10. void ordered_free_n(void *const chunks, const size_type n, 
                    const size_type partition_size);

    从有序列表中释放 n 个内存块.

    要求:

    这些内存块此前已从 *this 分配, 且 n 与 partition_size 的值相同.

    要求:

    n 不应为零 (n == 0 无效果).

simple_segregated_storage 公有静态函数

  1. static void * 
segregate(void * block, size_type nsz, size_type npartition_sz, 
          void * end = 0);

    把区块分隔为内存块.

    要求:

    npartition_sz >= sizeof(void *)

    要求:

    npartition_sz = sizeof(void *) * i, 其中 i 为某个整数

    要求:

    nsz >= npartition_sz

    要求:

    区块已正确对齐, 可容纳大小为 npartition_sz 的对象数组及 void * 数组. 上述要求保证任何指向内存块的指针 (即指向 npartition_sz 数组中元素的指针) 都可以转换为 void **.
