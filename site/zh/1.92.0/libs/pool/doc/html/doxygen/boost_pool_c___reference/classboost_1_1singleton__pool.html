类模板 singleton_pool

boost::singleton_pool

概要

// In header: <boost/pool/singleton_pool.hpp>

template<typename Tag, unsigned RequestedSize, typename UserAllocator, 
         typename Mutex, unsigned NextSize, unsigned MaxSize> 
class singleton_pool {
public:
  // types
  typedef Tag                                    tag;            
  typedef Mutex                                  mutex;            // The type of mutex used to synchonise access to this pool (default details::pool::default_mutex). 
  typedef UserAllocator                          user_allocator;   // The user-allocator used by this pool, default = default_user_allocator_new_delete. 
  typedef pool< UserAllocator >::size_type       size_type;        // size_type of user allocator. 
  typedef pool< UserAllocator >::difference_type difference_type;  // difference_type of user allocator. 

  // member classes/structs/unions

  struct object_creator {

    // public member functions
    object_creator();
    void do_nothing() const;
  };

  // private member functions
  singleton_pool();

  // public static functions
  static void * malloc();
  static void * ordered_malloc();
  static void * ordered_malloc(const size_type);
  static bool is_from(void *const);
  static void free(void *const);
  static void ordered_free(void *const);
  static void free(void *const, const size_type);
  static void ordered_free(void *const, const size_type);
  static bool release_memory();
  static bool purge_memory();

  // private static functions
  static pool_type & get_pool();

  // public data members
  static const unsigned requested_size;  // The size of each chunk allocated by this pool. 
  static const unsigned next_size;  // The number of chunks to allocate on the first allocation. 
  static pool< UserAllocator > p;  // For exposition only! 
};

说明

singleton_pool 类允许相同大小的其他池接口共享同一个池. 模板参数如下:

Tag 用户指定类型, 用于唯一标识此池: 允许存在不同的无界 singleton 池集合.

RequestedSize 成员函数 malloc() 返回的每个内存块的大小.

UserAllocator 用户分配器, 默认 = default_user_allocator_new_delete.

Mutex 此类是用于保护对底层 Pool 的并发访问的互斥量类型. 可以是任何 Boost.Thread 互斥量类型或 boost::details::pool::null_mutex. 它被暴露出来, 是为了使用户可以出于效率原因正常声明某些 singleton 池 (即带同步), 而另一些 singleton 池不带同步 (通过指定 boost::details::pool::null_mutex). 成员 typedef mutex 暴露了此模板参数的值. 此参数的默认值为 boost::details::pool::default_mutex, 它是 boost::details::pool::null_mutex (当编译器中线程支持被关闭 (因此未设置 BOOST_HAS_THREADS), 或线程支持已通过 BOOST_DISABLE_THREADS (Boost 全局禁用线程) 或 BOOST_POOL_NO_MT (仅本库) 显式禁用时) 或 boost::mutex (当编译器中线程支持被启用时) 的同义词.

NextSize 该参数的值会在底层 Pool 创建时传递给它, 并指定在第一次分配请求中要分配的内存块数量 (默认为 32). 成员 typedef static const value next_size 暴露了此模板参数的值.

MaxSize该参数的值会在底层 Pool 创建时传递给它, 并指定任一单次分配请求中要分配的最大内存块数量 (默认为 0).

备注:

底层池 p (由 singleton_pool 中的静态函数引用) 实际上以下列方式声明:

1 如果在 main() 开始之前和结束之后只有一个线程在运行, 则是线程安全的 – singleton_pool 的所有静态函数都会同步它们对 p 的访问.

2 保证在使用之前已构造 – 因此, 上面概要中的简单静态对象实际上是不正确的实现. 为保证这一点, 实际实现要复杂得多.

3 还要注意, 对每组不同的模板参数 (包括实现特有的参数), 都存在一个不同的底层池 p.

4 底层池的构造方式 "如同":

pool<UserAllocator> p(RequestedSize, NextSize, MaxSize);

重要

由 singleton 构造的底层池 永远不会被释放. 这意味着 singleton_pool 分配的内存在 main() 结束之后仍可使用, 但也可能导致某些内存检查程序报告来自 singleton_pool 的内存泄漏.

singleton_pool 公有类型

  1. typedef Tag tag;

    Tag 模板参数唯一标识此池, 并允许存在不同的无界 singleton 池集合. 例如, pool 分配器使用两个 tag 类来确保两种不同的分配器类型永远不会共享同一个底层 singleton 池. singleton_pool 实际上从不使用 Tag.

singleton_pool 私有成员函数

  1. singleton_pool();

singleton_pool 公有静态函数

  1. static void * malloc();

    等价于 SingletonPool::p.malloc(); 已同步.

  2. static void * ordered_malloc();

    等价于 SingletonPool::p.ordered_malloc(); 已同步.

  3. static void * ordered_malloc(const size_type n);

    等价于 SingletonPool::p.ordered_malloc(n); 已同步.

  4. static bool is_from(void *const ptr);

    等价于 SingletonPool::p.is_from(chunk); 已同步.

    返回:

    若 chunk 来自 SingletonPool::is_from(chunk) 则为 true

    		 
  5. static void free(void *const ptr);

    等价于 SingletonPool::p.free(chunk); 已同步.

  6. static void ordered_free(void *const ptr);

    等价于 SingletonPool::p.ordered_free(chunk); 已同步.

  7. static void free(void *const ptr, const size_type n);

    等价于 SingletonPool::p.free(chunk, n); 已同步.

  8. static void ordered_free(void *const ptr, const size_type n);

    等价于 SingletonPool::p.ordered_free(chunk, n); 已同步.

  9. static bool release_memory();

    等价于 SingletonPool::p.release_memory(); 已同步.

  10. static bool purge_memory();

    等价于 SingletonPool::p.purge_memory(); 已同步.

singleton_pool 私有静态函数

  1. static pool_type & get_pool();
