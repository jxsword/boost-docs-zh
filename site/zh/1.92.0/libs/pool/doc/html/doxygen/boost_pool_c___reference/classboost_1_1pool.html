类模板 pool

boost::pool — 一个快速的内存分配器, 保证所有已分配内存块的正确对齐.

概要

// In header: <boost/pool/pool.hpp>

template<typename UserAllocator> 
class pool :
  protected boost::simple_segregated_storage< UserAllocator::size_type >
{
public:
  // types
  typedef UserAllocator                  user_allocator;   // User allocator. 
  typedef UserAllocator::size_type       size_type;        // An unsigned integral type that can represent the size of the largest object to be allocated. 
  typedef UserAllocator::difference_type difference_type;  // A signed integral type that can represent the difference of any two pointers. 

  // private member functions
  void * malloc_need_resize();
  void * ordered_malloc_need_resize();

  // protected member functions
  simple_segregated_storage< size_type > & store();
  const simple_segregated_storage< size_type > & store() const;
  details::PODptr< size_type > find_POD(void *const) const;
  size_type alloc_size() const;
  size_type max_chunks() const;

  // protected static functions
  static bool is_from(void *const, char *const, const size_type);
  static void *& nextof(void *const);

  // public member functions
  explicit pool(const size_type, const size_type = 32, const size_type = 0);
  ~pool();
  bool release_memory();
  bool purge_memory();
  size_type get_next_size() const;
  void set_next_size(const size_type);
  size_type get_max_size() const;
  void set_max_size(const size_type);
  size_type get_requested_size() const;
  void * malloc();
  void * ordered_malloc();
  void * ordered_malloc(size_type);
  void free(void *const);
  void ordered_free(void *const);
  void free(void *const, const size_type);
  void ordered_free(void *const, const size_type);
  bool is_from(void *const) const;
};

说明

每当类型为 pool 的对象需要从系统获取内存时, 它都会向其 UserAllocator 模板参数发出请求. 请求量由倍增算法确定; 即每次分配更多系统内存时, 请求的系统内存量都会翻倍.

用户可以通过使用以下扩展来控制这一倍增算法:

用户可以向 pool 传递一个额外的构造函数参数. 该参数的类型为 size_type, 是对象第一次需要分配系统内存时向系统请求的内存块数量. 默认值为 32. 该参数不得为 0.

用户还可以向 pool 的构造函数传递一个可选的第三参数. 该参数的类型为 size_type, 用于设置已分配内存块的最大大小. 当该参数取默认值 0 时, 内存块大小没有上限.

最后, 如果倍增算法导致没有分配到任何内存, 池将回溯一次, 将内存块大小减半并重试.

UserAllocator 类型 - Pool 从系统分配内存所使用的方法.

使用类 pool 本质上有两种方式: 客户端可以调用 malloc() 和 free() 来分配和释放单个内存块, 这是使用池最有效率的方式, 但无法高效分配内存块数组. 或者, 客户端可以调用 ordered_malloc() 和 ordered_free(), 此时空闲列表将保持有序状态, 从而可以高效分配内存块数组. 但是, 当执行大量分配时, 后一种方式的性能可能较差.

pool 私有成员函数

  1. void * malloc_need_resize();

    所有存储中都没有内存; 创建一个新存储, 在调整大小后于新分配的内存中分配内存块.

    返回:

    若内存不足则为 0. 当 malloc/ordered_malloc 需要调整空闲列表大小时被调用.

    返回:

    指向内存块的指针.

    		 
  2. void * ordered_malloc_need_resize();
    当 malloc 需要调整空闲列表大小时被调用.

    所有存储中都没有内存; 创建一个新存储,

    返回:

    指向新内存块的指针.

pool 受保护成员函数

  1. simple_segregated_storage< size_type > & store();

    返回:

    指向存储的指针.

    		 
  2. const simple_segregated_storage< size_type > & store() const;

    返回:

    指向存储的指针.

    		 
  3. details::PODptr< size_type > find_POD(void *const chunk) const;
    查找列表中的哪个 POD 是 'chunk' 分配自的位置.

    查找该内存块来自哪个 PODptr 存储内存.

    返回:

    容纳该内存块的 PODptr.

    		 
  4. size_type alloc_size() const;

    本 Pool 将分配的内存块的计算大小.

    返回:

    已分配大小.

    		 
  5. size_type max_chunks() const;

    本 Pool 单次调用可分配的内存块数量的计算最大值.

pool 受保护的静态函数

  1. static bool is_from(void *const chunk, char *const i, 
                    const size_type sizeof_i);

    如果该内存块是从其他池分配的, 或可能作为未来从其他池分配的结果而返回, 则返回 false. 否则, 返回值毫无意义.

    注意此函数不可用于可靠地测试随机指针值.

    参数:

    chunk

    要检查是否来自本池的内存块.

    i

    位置 i 处、元素大小为 sizeof_i 的内存块.

    sizeof_i

    元素大小 (该区块的内存块区域大小, 而非该区块的总大小).

    返回:

    如果该内存块已分配或可能作为未来分配的结果而返回, 则为 true.

    		 
  2. static void *& nextof(void *const ptr);

    返回:

    对指针解引用. (为了提高代码可读性而提供并使用 :)

pool 公有成员函数

  1. explicit pool(const size_type nrequested_size, 
              const size_type nnext_size = 32, const size_type nmax_size = 0);

    构造一个新的空 Pool, 可用于分配大小为 RequestedSize 的内存块.

    参数:

    nrequested_size

    请求的内存块大小

    nnext_size

    该参数的类型为 size_type, 是对象第一次需要分配系统内存时向系统请求的内存块数量. 默认值为 32. 该参数不得为 0.

    nmax_size

    是一个区块内可分配的最大内存块数量.

    		 
  2. ~pool();

    析构 Pool, 释放其内存区块列表.

  3. bool release_memory();

    pool 必须是有序的. 释放所有不包含任何已分配内存块的内存区块.

    返回:

    如果至少释放了一个内存区块, 则为 true.

    		 
  4. bool purge_memory();

    pool 必须是有序的. 释放所有内存区块.

    此函数会使先前由 t 的分配函数返回的所有指针失效.

    返回:

    如果至少释放了一个内存区块, 则为 true.

    		 
  5. size_type get_next_size() const;

    下次该对象需要分配系统内存时向系统请求的内存块数量. 该值绝不应为 0.

    返回:

    next_size;

    		 
  6. void set_next_size(const size_type nnext_size);

    设置下次该对象需要分配系统内存时向系统请求的内存块数量. 该值绝不应被设为 0.

  7. size_type get_max_size() const;

    返回:

    max_size.

    		 
  8. void set_max_size(const size_type nmax_size);

    设置 max_size.

  9. size_type get_requested_size() const;

    返回:

    传入构造函数的请求大小. (该值在 Pool 对象的生命期内不会改变).

    		 
  10. void * malloc();

    分配一个内存块. 在内存区块列表中搜索含有空闲内存块的区块, 若找到则返回该空闲内存块. 否则, 创建一个新的内存区块, 并把其空闲列表加入 pool 的空闲列表,

    返回:

    来自该区块的一个空闲内存块. 若无法分配新的内存区块, 则返回 0. 摊还 O(1).

    		 
  11. void * ordered_malloc();

    与 malloc 相同, 只是会合并空闲列表以保持顺序. 摊还 O(1).

    返回:

    来自该区块的一个空闲内存块. 若无法分配新的内存区块, 则返回 0. 摊还 O(1).

    		 
  12. void * ordered_malloc(size_type n);

    获取第 n 个内存块的地址, 若尚不可用则分配新内存.

    返回:

    若分配成功, 为第 n 个内存块的地址.

    返回:

    若内存不足以容纳 n 个内存块, 则为 0.

    		 
  13. void free(void *const chunk);

    与 malloc 相同, 只是分配足够多的连续内存块以覆盖 n * requested_size 字节. 摊还 O(n).

    释放一个内存块. 注意该内存块不得为 0. O(1).

    该内存块必须此前已由 t.malloc() 或 t.ordered_malloc() 返回. 假定该内存块实际引用一个跨越 n * partition_sz 字节的内存块组, 并释放其中的每个内存块. 注意该内存块不得为 0. O(n).

    返回:

    来自该区块的一个空闲内存块. 若无法分配新的内存区块, 则返回 0. 摊还 O(1).

    		 
  14. void ordered_free(void *const chunk);

    与上面相同, 但保持顺序.

    注意该内存块不得为 0. 相对于空闲列表大小为 O(N). 该内存块必须此前已由 t.malloc() 或 t.ordered_malloc() 返回.

  15. void free(void *const chunks, const size_type n);

    假定该内存块实际引用一个内存块组.

    该内存块必须此前已由 t.ordered_malloc(n) 返回, 且跨越 n * partition_sz 字节. 释放该区块中的每个内存块. 注意该内存块不得为 0. O(n).

  16. void ordered_free(void *const chunks, const size_type n);

    假定该内存块实际引用一个跨越 n * partition_sz 字节的内存块组; 并释放该区块中的每个内存块.

    注意该内存块不得为 0. 保持顺序. O(N + n), 其中 N 为空闲列表的大小. 该内存块必须此前已由 t.malloc() 或 t.ordered_malloc() 返回.

  17. bool is_from(void *const chunk) const;

    返回:

    如果该内存块是从 u 分配的, 或可能作为未来从 u 分配的结果而返回, 则返回 true. 如果该内存块是从其他池分配的, 或可能作为未来从其他池分配的结果而返回, 则返回 false. 否则, 返回值毫无意义. 注意此函数不可用于可靠地测试随机指针值.
