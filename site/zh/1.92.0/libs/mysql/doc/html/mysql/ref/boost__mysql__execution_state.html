execution_state

为多函数 SQL 执行操作保存状态 (动态接口).

概要

定义于头文件 <boost/mysql/execution_state.hpp> 

class execution_state;
成员函数

名称

说明

affected_rows

返回与此结果集关联的 SQL 语句所影响的行数. 注意这并不是匹配的行数. 若某行被匹配但未被影响, 则不会计入此处.

complete

返回此操作生成的所有消息是否均已读取.

execution_state [constructor]

默认构造函数.
—
复制构造函数.
—
移动构造函数.

info

返回关于此结果集的附加文本信息.

is_out_params

返回当前结果集是否表示存储过程的 OUT 参数.

last_insert_id

返回与此结果集关联的 SQL 语句产生的最后插入 ID.

meta

返回查询中各列的元数据.

operator=

复制赋值.
—
移动赋值.

should_read_head

返回下一个操作是否应为读取结果集头部.

should_read_rows

返回下一个操作是否应为读取部分行.

should_start_op

返回 *this 是否处于初始状态.

warning_count

返回与此结果集关联的 SQL 语句所产生的警告数量.
说明

该类的行为类似于状态机. 当前状态可通过 should_start_op, should_read_rows, should_read_head 和 complete 访问. 这些状态互斥. 随着更多协议特性的实现, 将来可能会添加更多状态.

线程安全

不同对象: 安全.

共享对象: 不安全.
