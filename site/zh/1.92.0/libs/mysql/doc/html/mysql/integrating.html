将 Boost.MySQL 集成到你的项目中

注释

Boost 1.85 中的破坏性变更: 现在需要需编译库 Boost.Charconv. 如果你正在升级并遇到链接器错误, 请将你的可执行文件链接到 Boost::charconv CMake 目标.

仅头文件模式

使用本库最简单的方式是仅头文件模式 (默认). 你需要准备以下内容:

  • C++11 编译器 (如 gcc >=5.4、clang >=3.6 或 Visual Studio 2017 及更高版本).
  • Boost 头文件和 Boost.Charconv. 可以按照官方安装说明获取, 分别适用于 类 UNIX 系统 和 Windows, 也可以从包管理器获取. 注意, Boost.MySQL 不能与 Boost.Asio 的独立版本一起使用.
  • OpenSSL 头文件和库. 建议使用系统包管理器获取.
  • CMake.

使用以下 CMakeLists.txt, 将 main.cpp 替换为你项目的源文件:

project(boost_mysql_example LANGUAGES CXX)

find_package(Boost REQUIRED COMPONENTS charconv)
find_package(Threads REQUIRED)
find_package(OpenSSL REQUIRED)

add_executable(main main.cpp)
target_link_libraries(main PRIVATE Boost::charconv Threads::Threads OpenSSL::Crypto OpenSSL::SSL)
注释

Boost::charconv 仅在 Boost 1.85 及更高版本中可用. 如果你使用的是更旧的版本, 请改用 Boost::headers 目标.

如果你对仅头文件模式感到满意, 可以看看 第一个教程 或 任一示例 来学习如何使用本库.

分离编译模式

仅头文件模式很简单, 但可能使项目的构建时间变长. 如果是这样, 我们建议切换到分离编译模式.

要使用它, 必须将以下内容添加到恰好一个 .cpp 文件中:

// Contents of boost_mysql.cpp

// This header file contains all Boost.MySQL implementations.
// It should be included in exactly one .cpp file.
// All code using Boost.MySQL in separate build mode, including this file,
// should define BOOST_MYSQL_SEPARATE_COMPILATION.
#include <boost/mysql/src.hpp>

你的所有代码 (包括这个 .cpp 文件) 都应定义 BOOST_MYSQL_SEPARATE_COMPILATION 宏. 你的 CMakeLists.txt 可能如下所示:

project(boost_mysql_example LANGUAGES CXX)

find_package(Boost REQUIRED COMPONENTS charconv)
find_package(Threads REQUIRED)
find_package(OpenSSL REQUIRED)

add_executable(
    main
    # Contains Boost.MySQL sources via #include <boost/mysql/src.hpp>
    boost_mysql.cpp
    # List any other .cpp your exe has here
    main.cpp
)
target_link_libraries(main PRIVATE Boost::charconv Threads::Threads OpenSSL::Crypto OpenSSL::SSL)

# We need to define BOOST_MYSQL_SEPARATE_COMPILATION in any code using Boost.MySQL in separate-build mode
target_compile_definitions(main PRIVATE BOOST_MYSQL_SEPARATE_COMPILATION)

Boost.Asio 和 Boost.Beast 提供了非常类似的分离编译模式. 如果将它们与 Boost.MySQL 一起使用, 可以考虑也为它们启用分离编译.
