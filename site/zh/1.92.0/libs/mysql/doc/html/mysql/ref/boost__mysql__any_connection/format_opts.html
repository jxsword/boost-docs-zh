any_connection::format_opts

返回适合按当前连接配置格式化 SQL 的格式化选项.

概要 
system::result< format_options >
format_opts() const noexcept;
说明

如果当前字符集已知 (由 current_character_set 给出), 返回适合传给 SQL 格式化函数的值. 否则返回错误.

误差
  • client_errc::unknown_character_set 当前字符集未知时.
异常安全性

不抛出异常保证.
