ssl_mode

决定如何与服务器进行 SSL 协商.

概要

定义于头文件 <boost/mysql/ssl_mode.hpp> 

enum class ssl_mode;
取值

名称

说明

disable

绝不使用 TLS.

enable

若服务器支持 TLS 则使用 TLS, 否则回退到非加密连接.

require

始终使用 TLS; 若服务器不支持则中止连接.

便捷头文件 <boost/mysql.hpp>
