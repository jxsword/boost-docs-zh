pool_params::ssl

控制连接池创建的连接是否使用 TLS.

概要 
ssl_mode ssl {ssl_mode::enable};
说明

可能的模式参见 ssl_mode. 该选项仅在 server_address.type() == address_type::host_and_port 时相关. 无论该值如何, UNIX 套接字连接永远不会使用 TLS.
