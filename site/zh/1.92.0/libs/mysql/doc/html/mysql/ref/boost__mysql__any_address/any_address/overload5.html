any_address::any_address (5 个重载中的第 5 个)

构造包含 UNIX 套接字路径的地址.

概要 
any_address(
    unix_path value) noexcept;
说明

得到的地址包含 this->type() == address_type::unix_path、this->unix_socket_path() == value.path().

对象生命周期

*this 和 value 将拥有各自独立的生命周期 (正则值语义).

异常安全性

不抛出异常保证.
