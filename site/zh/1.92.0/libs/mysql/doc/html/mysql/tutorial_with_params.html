教程 3: 带参数的查询

到目前为止, 我们的 SQL 查询都是硬编码的字符串字面量. 然而, 大多数现实世界的用例都涉及运行包含用户提供参数的查询.

在本教程中, 我们将使用一个员工数据库. 你可以通过在 Boost.MySQL 源代码仓库中执行 example/db_setup.sql 文件来获得这个示例数据库.

employee 表定义如下:

CREATE TABLE employee(
    id INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    ... -- other fields not relevant for us
);

我们将编写一个程序, 按 ID 检索一名员工并打印其全名. 员工 ID 将由用户作为命令行参数提供. 在更现实的示例中, 你可以从文件或 HTTP 请求中获取它.

避免 SQL 注入

我们需要构建如下查询:

SELECT first_name, last_name FROM employee WHERE id = <actual-id>

把 <actual-id> 替换为用户传入的值.

由于员工 ID 不受我们控制, 必须将其视为不可信的. 我们绝不能使用原始字符串拼接来构建查询. 否则, 恶意值可能导致 SQL 注入漏洞, 这类漏洞极其严重.

Boost.MySQL 提供了两种应对方案:

  1. 在客户端动态组合查询, 使用专门的工具来避免 SQL 注入. 这种方案通用、简单, 适合一般用途.
  2. 在服务器端使用 预处理语句 进行参数替换. 这种方式更复杂, 也更适合涉及大量数值数据或重复执行同一查询的情况.

在本教程中, 我们将使用客户端生成 (在整个文档中称为 客户端 SQL 格式化 ).

使用 with_params

any_connection::async_execute 也可以处理带参数的查询. 我们需要把字符串字面量替换为对 with_params 的调用, 传入查询模板和参数的实际值:

// Execute the query with the given parameters. When executed, with_params
// expands the given query string template and sends it to the server for execution.
// {} are placeholders, as in std::format. Values are escaped as required to prevent
// SQL injection.
mysql::results result;
co_await conn.async_execute(
    mysql::with_params("SELECT first_name, last_name FROM employee WHERE id = {}", employee_id),
    result
);

查询模板使用的语法类似于 std::format. 你可以使用数字、字符串、日期、时间以及许多其他类型作为参数. 关于客户端 SQL 格式化的更多信息, 参见本页.

使用检索到的行

我们的查询可能返回一行 (如果找到员工), 也可能一行都不返回 (如果不存在具有给定 ID 的员工). 为了应对这一点:

// Did we find an employee with that ID?
if (result.rows().empty())
{
    std::cout << "Employee not found" << std::endl;
}
else
{
    // Print the retrieved details. The first field is the first name,
    // and the second, the last name.
    mysql::row_view employee = result.rows().at(0);
    std::cout << "Employee's name is: " << employee.at(0) << ' ' << employee.at(1) << std::endl;
}

连接数据库

如果你已经运行了 example/db_setup.sql, 那么 employee 表就存在于 boost_mysql_examples 数据库中. 要不加限定地使用该表, 我们需要在连接时指定一个数据库名. 实现方式是设置 connect_params::database:

// The hostname, username, password and database to use.
mysql::connect_params params;
params.server_address.emplace_host_and_port(std::string(server_hostname));
params.username = username;
params.password = password;
params.database = "boost_mysql_examples";

在协程内部创建连接

由于我们是在协程中进行连接和关闭连接, 因此把它做成局部变量更合理, 而不是作为参数传递. 回顾一下, 构建连接需要对执行上下文 (即 io_context) 的引用. 我们可以把 io_context 作为参数传给协程, 但有一种更简单的方式: 协程已经持有对它执行所在位置的引用:

// The connection will use the same executor as the coroutine
mysql::any_connection conn(co_await asio::this_coro::executor);

表达式 co_await asio::this_coro::executor 检索我们的协程正在使用的执行器. 执行器是执行上下文的轻量级句柄, 可用于创建我们的连接.

注释

co_await asio::this_coro::executor 不执行任何 I/O. 它只检索当前协程的执行器.

收尾

完成上述全部修改后, 我们的协程如下所示:

asio::awaitable<void> coro_main(
    std::string_view server_hostname,
    std::string_view username,
    std::string_view password,
    std::int64_t employee_id
)
{
    // The connection will use the same executor as the coroutine
    mysql::any_connection conn(co_await asio::this_coro::executor);

    // The hostname, username, password and database to use.
    mysql::connect_params params;
    params.server_address.emplace_host_and_port(std::string(server_hostname));
    params.username = username;
    params.password = password;
    params.database = "boost_mysql_examples";

    // Connect to the server
    co_await conn.async_connect(params);

    // Execute the query with the given parameters. When executed, with_params
    // expands the given query string template and sends it to the server for execution.
    // {} are placeholders, as in std::format. Values are escaped as required to prevent
    // SQL injection.
    mysql::results result;
    co_await conn.async_execute(
        mysql::with_params("SELECT first_name, last_name FROM employee WHERE id = {}", employee_id),
        result
    );

    // Did we find an employee with that ID?
    if (result.rows().empty())
    {
        std::cout << "Employee not found" << std::endl;
    }
    else
    {
        // Print the retrieved details. The first field is the first name,
        // and the second, the last name.
        mysql::row_view employee = result.rows().at(0);
        std::cout << "Employee's name is: " << employee.at(0) << ' ' << employee.at(1) << std::endl;
    }

    // Close the connection
    co_await conn.async_close();
}
