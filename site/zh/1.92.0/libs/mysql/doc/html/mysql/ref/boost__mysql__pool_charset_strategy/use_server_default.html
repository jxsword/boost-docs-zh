pool_charset_strategy::use_server_default

创建一个使池化连接使用服务器默认字符集的策略.

概要 
static pool_charset_strategy
use_server_default(
    character_set charset) noexcept;
说明

创建一个类型为 pool_charset_strategy_type::use_server_default 且 server_default_charset 等于传入字符集的对象.

传入的 charset 必须等于服务器配置的默认字符集. 不执行运行期检查来验证这一断言. 若不成立, 可能产生漏洞. 若不确定, 建议使用 set_to_utf8mb4.

异常安全性

不抛出异常保证.
