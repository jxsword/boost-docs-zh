formattable_ref

指向 Formattable 值的类型擦除引用.

概要

定义于头文件 <boost/mysql/format_sql.hpp> 

class formattable_ref;
成员函数

名称

说明

formattable_ref [constructor]

构造函数.
说明

该类型可持有满足 Formattable 概念的任何值的引用. formattable_ref 类型本身满足 Formattable , 因此可用作格式化函数的实参.

对象生命周期

这是一个不拥有所有权的类型. 为避免生存期问题, 只应将其用作函数实参.
