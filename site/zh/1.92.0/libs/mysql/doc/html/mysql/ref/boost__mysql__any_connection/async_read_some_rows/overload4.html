any_connection::async_read_some_rows (4 个重载中的第 4 个)

读取一批行.

概要 
template<
    class SpanElementType,
    class... StaticRow,
    class CompletionToken = with_diagnostics_t<asio::deferred_t>>
auto
async_read_some_rows(
    static_execution_state< StaticRow... >& st,
    span< SpanElementType > output,
    diagnostics& diag,
    CompletionToken&& token = {});
说明

将大小不确定的一批行读入 output 给定的存储中. 最多读取 output.size() 行. 如果 st 表示的操作还有行待读取且 output.size() > 0, 则至少读取一行.

返回读取的行数.

如果没有更多行, 或 st.should_read_rows() == false, 该函数为空操作并返回零.

将读取的行数取决于连接的缓冲区大小. 缓冲区越大, 批次越大 (有上限). 可以在构造函数中设置初始缓冲区大小. 如有需要, 缓冲区可能会被其他读取操作扩大.

该函数读取的行是持有所有权的对象, 不持有对连接内部缓冲区的任何引用 (与动态接口的对应函数不同).

类型 SpanElementType 必须是 StaticRow 参数包中某个类型的底层行类型 (即 underlying_row_t<StaticRow>... 中的某个类型). 该类型必须与 st 当前正在处理的结果集匹配. 例如, 给定 static_execution_state<T1, T2>, 当读取第二个结果集的行时, SpanElementType 必须恰好是 underlying_row_t<T2>. 否则将产生运行期错误.

该函数可以报告模式不匹配.

处理器签名

该操作的处理器签名是 void(boost::mysql::error_code, std::size_t).

Executor

中间完成处理器以及最终处理器都使用 token 的关联执行器执行, 若该标记没有关联执行器则使用 this->get_executor().

如果最终处理器有关联的立即执行器且操作立即完成, 最终处理器会被派发给它. 否则, 最终处理器的调用方式如同通过 asio::post 提交, 且绝不会在该函数内被内联调用.

对象生命周期

output 所引用的存储必须保持存活, 直到操作完成.
