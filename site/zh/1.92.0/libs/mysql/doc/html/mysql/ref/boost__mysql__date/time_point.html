date::time_point

一种 std::chrono::time_point, 可表示任何有效的 date.

概要 
using time_point = std::chrono::time_point< std::chrono::system_clock, days >;
说明

该类使用的时间点始终为本地时间, 即使其定义为使用系统时钟.
