pipeline_request

(实验性) 一个管道请求.

概要

定义于头文件 <boost/mysql/pipeline.hpp> 

class pipeline_request;
成员函数

名称

说明

add_close_statement

添加一个关闭语句阶段.

add_execute

添加一个执行文本查询的阶段.
—
添加一个执行预处理语句的阶段.

add_execute_range

添加一个执行预处理语句的阶段.

add_prepare_statement

添加一个准备语句阶段.

add_reset_connection

添加一个重置连接阶段.

add_set_character_set

添加一个设置字符集阶段.

clear

移除管道请求中的所有阶段, 使对象重新变为空.

pipeline_request [constructor]

默认构造函数.
说明

包含一组管道阶段, 完整描述管道操作要执行的工作. 调用 add_xxx 函数中的任意一个, 可向请求追加新阶段.

实验性

API 的这一部分是实验性的, 可能会在后续发布中不经通知而更改.
