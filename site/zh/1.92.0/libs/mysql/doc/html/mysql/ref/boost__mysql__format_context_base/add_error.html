format_context_base::add_error

向当前错误状态添加一个错误.

概要 
void
add_error(
    error_code ec) noexcept;
说明

自定义格式化器可用此函数报告其收到了无法格式化的值. 例如, 内置字符串格式化器在收到编码无效的字符串时就会使用它.

若在调用此函数前尚未设置错误状态, 则错误状态将更新为 ec. 否则, 该错误将被忽略. 这意味着错误状态一旦设置便无法重置.

异常安全性

不抛出异常保证.
