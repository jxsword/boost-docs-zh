connection::quit (2 个重载中的第 1 个)

通知 MySQL 服务器客户端希望结束会话, 并关闭 SSL.

概要 
void
quit(
    error_code& err,
    diagnostics& diag);
说明

向 MySQL 服务器发送 quit 请求. 如果连接正在使用 SSL, 该函数还会执行 SSL 关闭. 调用该函数后, 你应当关闭底层物理连接.

如果 Stream 模板参数满足 SocketConnection 要求, 请使用 connection::close 而不是该函数, 因为它还会负责关闭底层流.
