WritableField 与 WritableFieldTuple 概念

若某类型可用于表示要发送到服务器的语句参数值, 则它是 WritableField. 类型 T 满足 WritableField 的条件是: 它属于 此表中列出的任意类型. 未来版本中可能会添加更多类型.

类型 T 是 WritableFieldTuple 的条件是: 它是 std::tuple 特化或其引用, 且所有元素类型都满足 WritableField, 或者是对 WritableField 类型的 (可能带 cv 限定符的) 引用. 空元组满足 WritableFieldTuple.
