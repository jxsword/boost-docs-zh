statement

表示一个服务器侧预处理语句.

概要

定义于头文件 <boost/mysql/statement.hpp> 

class statement;
成员函数

名称

说明

bind

将参数绑定到语句.
—
将参数绑定到语句 (迭代器范围重载).

id

返回语句的服务器侧标识符 (按连接唯一).

num_params

返回执行该语句时应提供的参数数量.

statement [constructor]

默认构造函数.

valid

若该对象表示一个实际的服务器语句, 则返回 true.
说明

这是一个轻量级类, 持有服务器侧预处理语句的句柄.

注意 statement 的析构函数不会从服务器释放语句, 因为这涉及可能失败的网络传输.

线程安全

不同对象: 安全.

共享对象: 不安全.
