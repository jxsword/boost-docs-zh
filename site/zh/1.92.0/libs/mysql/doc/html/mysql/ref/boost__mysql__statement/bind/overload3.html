statement::bind (3 个重载中的第 3 个)

将参数绑定到语句 (迭代器范围重载).

概要 
template<
    class FieldViewFwdIterator,
    typename EnableIf = typename std::enable_if< detail::is_field_view_forward_iterator<FieldViewFwdIterator>::value>::type>
bound_statement_iterator_range< FieldViewFwdIterator >
bind(
    FieldViewFwdIterator params_first,
    FieldViewFwdIterator params_last) const;
说明

创建一个打包 *this 和语句实际参数 (表示为迭代器范围 [params_first, params_last)) 的对象. 该对象可传递给 connection::execute、connection::start_execution 或其异步版本.

此函数不涉及与服务器的通信.

前置条件

this->valid() == true

异常安全性

强保证. 仅当复制构造迭代器时抛出异常才抛出.
