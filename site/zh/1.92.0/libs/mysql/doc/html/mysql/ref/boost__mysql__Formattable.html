Formattable 概念

类型 T 满足 Formattable 的条件是: 它可以作为格式化实参传给 SQL 格式化函数, 例如 format_sql.

形式上, 设 T 为任意类型, U 为去除 T 的 cv 限定符和引用后的结果. T 满足 Formattable 的条件是以下任一为真:

  • U 满足 WritableField. 这包括标量类型和 optional.
  • 类 formatter 已针对 U 特化.
  • T 是可格式化范围或其引用. 形式上, 给定 t 类型的变量 T (可能是引用), T 是可格式化范围的条件是:
    • std::begin(t) 和 std::end(t) 返回一对可进行 (不) 相等比较的迭代器/哨兵.
    • 类型 std::decay_t<decltype(*std::begin(t))> 是 WritableField 或具有特化的 formatter. 换言之, 范围的元素类型必须是基本类型或定义了自定义格式化器, 但不能是范围.
    • U 不满足 WritableField (即 vector<unsigned char> 被格式化为 blob, 而不是序列).
  • U 是 formattable_ref.
