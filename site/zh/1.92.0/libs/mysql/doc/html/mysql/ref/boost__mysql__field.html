说明

这是一个常规的、类似 variant 的类, 可表示 MySQL 允许的任何类型. 它具有值语义 (与 field_view 不同). 库不会创建该类的实例. 当 field_view 的引用语义不适用时, 应由用户自行创建实例.

与 variant 类似, field 在任何时刻始终持有某一特定类型的值. 可通过 kind 和 is_xxx 之类的函数查询其类型, 例如 is_int64. 分别使用 as_xxx 和 get_xxx 进行受检和不带检查的值访问. 可通过调用赋值运算符, 或使用 field 和 as_xxx 返回的左值引用来修改 get_xxx.
