any_address::emplace_host_and_port

用主机和端口替换当前对象.

概要 
void
emplace_host_and_port(
    std::string hostname,
    unsigned short port = default_port);
说明

销毁当前包含的对象, 并用传入的组件构造一个新的主机和端口. 该函数可能改变 *this 所持有对象的底层类型.

构造出的对象包含 this->type() == address_type::host_and_port、this->hostname() == hostname 和 this->port() == port.

空主机名等价于 localhost.

异常安全性

基本保证. 内存分配可能抛出异常.

对象生命周期

使指向 *this 内部的视图失效.
