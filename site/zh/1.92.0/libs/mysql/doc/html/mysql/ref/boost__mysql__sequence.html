sequence

创建一个对象, 格式化时会对范围应用逐元素函数.

概要

定义于头文件 <boost/mysql/sequence.hpp> 

template<
    class Range,
    class FormatFn>
format_sequence< sequence_range_t< Range >, typename std::decay< FormatFn >::type >
sequence(
    Range&& range,
    FormatFn&& fn,
    constant_string_view glue = ", ");
说明

此函数返回的对象满足 Formattable. 格式化这类对象会对 fn 中的每个元素调用 range , 并在调用之间输出 glue. 由此产生类似于 std::ranges::views::join 的效果.

默认情况下, 此函数通过 decay 复制 range 来创建拥有所有权的对象. C 数组会被复制到 std::array 对象中. 可通过传入 std::reference_wrapper 对象禁用此行为, 它们会被转换为引用 (如同 std::make_tuple). sequence_range_t 类型特征会考虑这些变换.

正式表述如下:

  • 若 Range 是一个 (可带 cv 限定符的) C 数组引用 (依据 std::is_array<Range>), 且该数组有 N 个 U 类型的元素, 则输出范围类型为 std::array<std::remove_cv< U >, N> , 且范围的创建方式如同调用了 std::to_array.
  • 若 Range 是 std::reference_wrapper< U > 对象或其引用, 则输出范围类型为 U&. 这实际上会禁用对输入范围的复制. 所得对象将是视图类型, 由调用者负责生存期管理.
  • 否则, 输出范围类型为 std::remove_cvref_t<Range> , 并通过转发传入的 range 来创建.

FormatFn 始终会被 decay 复制到结果对象中.

粘接字符串始终以视图形式存储, 因为它通常应指向编译期常量.

类型要求

所得范围与格式化函数应当兼容, 且任何所需的复制/移动操作都应当是良定义的. 正式表述如下:

  • std::decay_t<FormatFn> 应当是与输出范围元素兼容的格式化函数. 正式要求见 format_sequence.
  • 若 Range 是 std::reference_wrapper< U > 或其引用, 则对 U 不再有进一步的要求.
  • 若 Range 是 C 数组的左值引用, 其元素应当可复制构造 (依据 std::to_array 要求).
  • 若 Range 是 C 数组的右值引用, 其元素应当可移动构造 (依据 std::to_array 要求).
  • 对 FormatFn 执行 decay 复制应当是良定义的.
异常安全性

基本保证. 传播构造输出范围和格式化函数时抛出的任何异常.
