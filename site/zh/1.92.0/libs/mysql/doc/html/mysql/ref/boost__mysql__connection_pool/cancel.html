connection_pool::cancel

停止当前所有未完成的操作, 并将池标记为已取消.

概要 
void
cancel();
说明

该函数有以下效果:

  • 停止当前未完成的 async_run 操作 (如果有的话), 它将以成功错误码完成.
  • 取消所有未完成的 async_get_connection 操作.
  • 将池标记为已取消. 后续的 async_get_connection 调用会立即失败.

该函数会立即返回, 不等待被取消的操作完成.

可以任意次数调用该函数. 后续调用没有任何效果.

前置条件

this->valid() == true

异常安全性

基本保证. 内存分配和获取互斥量可能抛出异常.

线程安全

读取内部状态句柄. 修改池状态. 如果池构造时启用了线程安全, 它可以与不修改状态句柄的其他函数并发调用.
