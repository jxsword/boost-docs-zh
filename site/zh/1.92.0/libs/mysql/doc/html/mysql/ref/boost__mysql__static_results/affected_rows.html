static_results::affected_rows

返回已执行的 SQL 语句所影响的行数.

概要 
template<
    std::size_t I = 0>
std::uint64_t
affected_rows() const noexcept;
说明

注意这并不是匹配的行数. 若某行被匹配但未被影响, 则不会计入此处.

模板参数

类型

说明

I

结果集索引. 对于返回多个结果集的操作, 可显式指定此参数以获取第 i 个结果集的受影响行数. 若不指定, 则返回第一个结果集的受影响行数.
前置条件

this->has_value() == true

异常安全性

不抛出异常保证.

复杂度

常量.
