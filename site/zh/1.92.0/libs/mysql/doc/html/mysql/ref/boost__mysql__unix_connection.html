unix_connection

(遗留) 基于 UNIX 域套接字的 MySQL 连接.

概要

定义于头文件 <boost/mysql/unix.hpp> 

using unix_connection = connection< boost::asio::local::stream_protocol::socket >;
旧式

新代码应使用 any_connection 而非 connection 及其辅助 typedef, 因为它更易使用且提供同等的性能.

便捷头文件 <boost/mysql.hpp>
