pool_params

connection_pool 的配置参数.

概要

定义于头文件 <boost/mysql/pool_params.hpp> 

struct pool_params;
数据成员

名称

说明

charset_strategy

决定连接池所创建连接使用的字符集.

connect_timeout

连接时使用的超时时间.

connection_executor

连接池所创建的各个连接使用的执行器.

database

连接池所创建的连接在连接时使用的数据库名.

initial_buffer_size

连接池所创建连接的内部缓冲区的初始大小 (字节).

initial_size

要创建的连接的初始数量.

max_size

可创建连接的最大数量.

multi_queries

是否为连接池创建的连接启用对以分号分隔的文本查询的支持.

password

连接池创建的连接应使用的密码.

ping_interval

健康检查间隔.

ping_timeout

ping 和会话重置使用的超时时间.

retry_interval

两次连接尝试之间的间隔.

server_address

决定如何建立与 MySQL 服务器的物理连接.

ssl

控制连接池创建的连接是否使用 TLS.

ssl_ctx

使用 TLS 的连接所用的 SSL 上下文.

thread_safe

启用或禁用线程安全性.

username

连接池创建的连接进行身份验证时应使用的用户名.
说明

这是一个拥有所有权的类型.

便捷头文件 <boost/mysql.hpp>
