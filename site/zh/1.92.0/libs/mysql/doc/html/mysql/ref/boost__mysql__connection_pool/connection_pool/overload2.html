connection_pool::connection_pool (3 个重载中的第 2 个)

构造连接池.

概要 
template<
    class ExecutionContext>
connection_pool(
    ExecutionContext& ctx,
    pool_params params);
说明

等价于 connection_pool(ctx.get_executor(), params).

仅当 ExecutionContext 满足 Boost.Asio 施加的 ExecutionContext 要求时, 该函数才参与重载决议.

异常安全性

强保证. 内存分配可能抛出异常.

异常

类型

抛出时机

std::invalid_argument

如果 params 包含违反 pool_params 中所述规则的值.
