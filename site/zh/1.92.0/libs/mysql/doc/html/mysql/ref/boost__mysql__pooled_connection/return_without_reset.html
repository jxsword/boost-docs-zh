pooled_connection::return_without_reset

将所拥有的连接归还连接池, 并将其标记为无需重置.

概要 
void
return_without_reset() noexcept;
说明

将连接归还连接池并将其标记为空闲. 这会跳过 any_connection::async_reset_connection 调用, 不清除会话状态.

这可以带来性能提升, 但必须谨慎使用. 未能清除会话状态可能导致资源泄漏 (预处理语句未被释放)、错误的结果以及漏洞 (因残留状态导致不同的逻辑操作相互影响).

调用此函数之前, 请先阅读关于 any_connection::async_reset_connection 的文档. 若有疑问, 请不要使用它, 让析构函数替你把连接归还连接池.

此函数返回时, *this 将不拥有任何东西 (this->valid() == false).

前置条件

this->valid() == true

异常安全性

不抛出异常保证.

线程安全

会导致 this 所指向的连接池发生变更. 仅当共享的连接池在构造时将 pool_params::thread_safe 设为 true, 此操作才是线程安全的.
