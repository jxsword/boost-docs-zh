resultset

一个拥有所有权的 resultset, 包含元数据、行和附加信息.

概要

定义于头文件 <boost/mysql/resultset.hpp> 

class resultset;
成员函数

名称

说明

affected_rows

返回此结果集的受影响行数.

has_value

返回此对象是否包含实际数据.

info

返回此结果集的附加信息.

is_out_params

返回此结果集是否表示存储过程的 OUT 参数.

last_insert_id

返回此结果集的最后插入 ID.

~resultset [destructor]

析构函数.
说明

与 results 类似, 但只能表示单个结果集 (而 results 可持有多个结果集). 可用于取得 resultset_view 的所有权.

便捷头文件 <boost/mysql.hpp>
