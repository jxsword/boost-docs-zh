handshake_params::handshake_params

初始化构造函数.

概要 
handshake_params(
    string_view username,
    string_view password,
    string_view db = "",
    std::uint16_t connection_col = handshake_params::default_collation,
    ssl_mode mode = ssl_mode::require,
    bool multi_queries = false);
异常安全性

不抛出异常保证.

参数

名称

说明

username

用于认证的用户名.

password

该用户名的密码, 可以为空.

db

要使用的数据库名, 空字符串表示不选择数据库 (默认行为).

connection_col

连接要使用的排序规则 ID. 会影响文本查询和预处理语句的解释方式. 默认为 utf8mb4_general_ci (见 default_collation), 该排序规则与 MySQL 5.x、8.x 和 MariaDB 兼容.

mode

此连接要使用的 ssl_mode ; 若连接的 Stream 不支持 SSL 则被忽略.

multi_queries

是否启用对使用 connection::execute 和 connection::start_execution 执行以分号分隔的查询的支持. 默认禁用.
