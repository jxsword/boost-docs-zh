any_connection::backslash_escapes

返回反斜杠是否被视为转义序列.

概要 
bool
backslash_escapes() const noexcept;
说明

默认情况下, 服务器将字符串值中的反斜杠视为转义字符. 可以通过启用 NO_BACKSLASH_ESCAPES SQL 模式禁用该行为.

每次涉及服务器通信的操作完成时, 服务器都会在响应中报告该模式是否启用. 连接会存储该信息, 并通过该函数提供.

  • 如果反斜杠被视为转义字符, 返回 true.
  • 如果 NO_BACKSLASH_ESCAPES 已启用, 返回 false.
  • 如果尚未建立连接, 返回 true.
  • 在改变反斜杠行为的异步操作未完成期间调用该函数, 可能返回 true 或 false.

该函数不涉及服务器通信.

异常安全性

不抛出异常保证.
