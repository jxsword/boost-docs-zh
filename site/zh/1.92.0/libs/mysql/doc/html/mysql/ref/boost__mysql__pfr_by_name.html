pfr_by_name

静态接口标记类型, 用于以基于名称的字段匹配方式使用 Boost.PFR 反射.

概要

定义于头文件 <boost/mysql/pfr.hpp> 

template<
    class T>
struct pfr_by_name;
说明

满足 StaticRow 概念的标记类型. 在静态接口中使用时, 会改变被标记类型的行为, 使其改用 Boost.PFR 而非 Boost.Describe 进行反射. 字段按名称匹配, 使用与 Boost.Describe 结构体相同的算法.

此标记的底层行类型为 T , 即 underlying_row_t<pfr_by_name<T>> 是 T 的别名.

类型 T 必须是可 PFR 反射的非 const 对象类型.

仅当宏 BOOST_PFR_CORE_NAME_ENABLED 已定义且设置为 1 时 (需要 C++20), 才定义此类型.

便捷头文件 <boost/mysql.hpp>
