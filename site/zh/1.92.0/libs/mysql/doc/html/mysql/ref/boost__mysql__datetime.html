说明

表示一个格里高利历日期和时间, 拆分为年、月、日、时、分、秒和微秒各分量, 不含时区.

该类型贴近协议, 不应用作词汇类型. 应改为通过调用 std::chrono::time_point、as_time_point、get_time_point 或 as_local_time_point 将其转换为 get_local_time_point.

从 MySQL 获取的 datetime 不包含任何时区信息. 确定时区由应用程序负责. 因此, 从该类获得的任何时间点都应解释为未指定时区中的本地时间, 类似 std::chrono::local_time. 为了兼容较旧的编译器, as_time_point 和 get_time_point 返回 system_clock 时间点. 这些时间点应解释为本地时间而非 UTC. 若编译器支持, 建议优先使用 as_local_time_point 或 get_local_time_point , 因为它们提供更准确的语义.

与 time_point 不同, 该类型允许表示 MySQL 的无效和零值 datetime. 这些值为 MySQL 所允许, 但并不表示真实的时间点.

注意: 在 MSVC 下使用 std::chrono 时区功能可能导致报告内存泄漏. 解释见 此 issue, 变通方法见 另一个 issue.
