any_connection_params

可以传递给 any_connection 构造函数的配置参数.

概要

定义于头文件 <boost/mysql/any_connection.hpp> 

struct any_connection_params;
数据成员

名称

说明

initial_buffer_size

连接缓冲区的初始大小, 单位为字节.

max_buffer_size

连接缓冲区的最大大小, 单位为字节 (默认 64MB).

ssl_context

包含 TLS 配置选项的外部 SSL 上下文.

便捷头文件 <boost/mysql.hpp>
