SocketStream 概念

SocketStream 应满足 Stream 要求. 此外, 它应有一个 lowest_layer_type 成员类型和一个 lowest_layer 成员函数, 返回一个 lowest_layer_type&, 遵循 Asio 的分层流模型. 另外, lowest_layer_type 应继承自 asio::basic_stream_socket 的某个实例化.

类型 boost::asio::basic_stream_socket<Protocol, Executor> 和 boost::asio::ssl::stream<boost::asio::basic_stream_socket<Protocol, Executor>> 满足这些要求.
