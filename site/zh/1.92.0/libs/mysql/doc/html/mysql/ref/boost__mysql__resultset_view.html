resultset_view

对 resultset 的不拥有所有权的引用.

概要

定义于头文件 <boost/mysql/resultset_view.hpp> 

class resultset_view;
成员函数

名称

说明

affected_rows

返回此结果集的受影响行数.

has_value

返回这是否为空视图.

info

返回此结果集的附加信息.

is_out_params

返回此结果集是否表示存储过程的 OUT 参数.

last_insert_id

返回此结果集的最后插入 ID.

meta

返回此结果集的元数据.

resultset_view [constructor]

构造一个满足 this->has_value() == false 的视图.

rows

返回此结果集的行.

warning_count

返回此 resultset 的警告数量.
说明

resultset_view 指向由外部对象拥有的内存, 通常是 results. 只要所指向的对象存活, 该视图以及由其获得的任何其他引用类型即保持有效.
