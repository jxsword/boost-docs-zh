runtime

由运行期值创建一个 constant_string_view.

概要

定义于头文件 <boost/mysql/constant_string_view.hpp> 

constexpr constant_string_view
runtime(
    string_view value) noexcept;
说明

可使用此函数绕过 consteval 构造函数执行的 constant_string_view 检查.

除非清楚自己在做什么, 否则不要使用此函数. consteval 检查的存在是出于安全考虑. 请确保只向相关 API 传递可信的值.

异常安全性

不抛出异常保证.

对象生命周期

返回值的生存期语义与传入的视图相同.

便捷头文件 <boost/mysql.hpp>
