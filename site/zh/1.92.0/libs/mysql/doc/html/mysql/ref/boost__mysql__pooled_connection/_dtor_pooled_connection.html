pooled_connection::~pooled_connection

析构函数.

概要 
~pooled_connection();
说明

若 this->valid() == true , 则将所拥有的连接归还连接池, 并将其标记为待重置. 若你的连接无需重置 (例如你没有变更会话状态), 请使用 return_without_reset.

线程安全

可能导致 this 所指向的连接池发生变更. 仅当共享的连接池在构造时将 pool_params::thread_safe 设为 true, 此操作才是线程安全的.
