说明

该对象可保存单结果集和多结果集查询的结果. 对于前者, 使用 meta、rows、affected_rows 等. 对于后者, 该类是 resultset 对象的随机访问集合.

线程安全

不同对象: 安全.

共享对象: 不安全.
