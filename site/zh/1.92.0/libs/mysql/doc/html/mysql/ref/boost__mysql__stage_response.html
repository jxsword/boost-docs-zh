说明

这是一个类似 variant 的类型, 与 boost::system::result 类似. 在任一时刻, 它可以包含:

  • 一个 statement. 当该阶段是成功的准备语句阶段时会出现.
  • 一个 results. 当该阶段是成功的查询或语句执行时会出现.
  • 一对 error_code 和 diagnostics. 当该阶段失败, 或成功但不产生值时会出现 (如关闭语句、重置连接和设置字符集).
实验性

API 的这一部分是实验性的, 可能会在后续发布中不经通知而更改.
