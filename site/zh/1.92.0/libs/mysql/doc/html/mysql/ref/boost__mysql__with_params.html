with_params

创建一个带参数的查询 (客户端侧 SQL 格式化), 可供执行.

概要

定义于头文件 <boost/mysql/with_params.hpp> 

template<
    class... FormattableOrRefWrapper>
with_params_t< make_tuple_element_t< FormattableOrRefWrapper >... >
with_params(
    constant_string_view query,
    FormattableOrRefWrapper&&... args);
说明

通过将传入的实参打包进一个 tuple (调用 with_params_t) 创建 std::make_tuple 对象. 依据 std::make_tuple, 参数将被 decay 复制到结果对象中. 可通过传入 std::reference_wrapper 对象禁用此行为, 它们会被转换为引用.

此函数不检查提供的查询字符串和实参. 缺少格式化实参之类的错误会在结果对象被执行时检测到. 此函数不涉及与服务器的通信.

传入的 args 必须满足 Formattable , 或者是 std::reference_wrapper<T> 且其 T 满足 Formattable.

执行请求的工作方式详见 with_params_t.

异常安全性

强保证. 复制 args 时抛出的任何异常都会被传播.

便捷头文件 <boost/mysql.hpp>
