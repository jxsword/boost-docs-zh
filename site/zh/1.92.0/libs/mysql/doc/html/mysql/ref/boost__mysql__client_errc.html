client_errc

MySQL 客户端定义的错误码.

概要

定义于头文件 <boost/mysql/client_errc.hpp> 

enum class client_errc
    : int;
取值

名称

说明

incomplete_message

从服务器收到不完整的消息 (表示反序列化错误或包不匹配).

protocol_value_error

在服务器发来的消息中发现意外的值 (表示反序列化错误或包不匹配).

server_unsupported

服务器不支持建立连接所需的最低能力.

extra_bytes

收到消息末尾有多余的字节 (表示反序列化错误或包不匹配).

sequence_number_mismatch

序列号不匹配 (通常由包不匹配引起).

unknown_auth_plugin

用户使用的身份认证插件为本库所不知.

auth_plugin_requires_ssl

(旧式) 身份认证插件要求连接使用 SSL. 该错误码已不再使用, 因为所有受支持的插件都支持明文连接.

wrong_num_params

传递给预处理语句的参数数量与实际参数数量不符.

server_doesnt_support_ssl

连接要求使用 SSL, 但服务器不接受 SSL 连接.

metadata_check_failed

静态接口检测到你的 C++ 类型定义与服务器查询返回内容之间的不匹配.

num_resultsets_mismatch

静态接口检测到传给 static_results 或 static_execution_state 的行类型数量与查询返回的结果集数量不匹配.

row_type_mismatch

传给 read_some_rows 的 StaticRow 类型与正在读取的结果集类型不符.

static_row_parsing_error

静态接口在将字段解析为 C++ 数据结构时遇到错误.

pool_not_running

从 connection_pool 获取连接的操作在池运行之前被取消. 请确保你正在调用 connection_pool::async_run.

pool_cancelled

从 connection_pool 获取连接失败, 因为池已被取消.

no_connection_available

从 connection_pool 获取连接的操作在连接可用之前被取消.

invalid_encoding

尝试解码字符串时发现了无效的字节序列.

unformattable_value

某个格式化操作无法格式化其一个实参.

format_string_invalid_syntax

向 SQL 格式化函数提供了包含无效语法的格式串.

format_string_invalid_encoding

向 SQL 格式化函数提供了包含无效字节序列的格式串.

format_string_manual_auto_mix

格式串混用了手动 (如 {0}) 和自动 (如 {}) 索引.

format_string_invalid_specifier

所提供的格式化说明符 (如 {:i}) 不受被格式化类型支持.

format_arg_not_found

未找到格式串引用的某个格式化实参. 请检查传入的格式化实参数量及其名称.

unknown_character_set

连接使用的字符集不为客户端所知. 请在调用需要已知字符集的操作之前使用 any_connection::set_character_set 或 any_connection::async_set_character_set.

max_buffer_size_exceeded

某个操作试图读写超过最大缓冲区大小的数据包. 请尝试增大 any_connection_params::max_buffer_size.

operation_in_progress

该连接当前有另一个操作正在进行. 请确保单个连接不会并行运行两个异步操作.

not_connected

请求的操作需要已建立的会话. 请在调用其他操作之前先调用 async_connect.

engaged_in_multi_function

连接当前正在进行多函数操作. 在启动任何其他操作之前, 请通过调用 async_read_some_rows 和 async_read_resultset_head 完成当前操作.

not_engaged_in_multi_function

该操作要求连接正在进行多函数操作. 请使用 async_start_execution 启动一个.

bad_handshake_packet_type

握手期间, 服务器发送了当前状态下不允许的数据包类型 (协议违规).

unknown_openssl_error

某个 OpenSSL 函数失败且未提供任何额外的诊断信息.
说明

这些错误由客户端本身产生, 而不是服务器.
