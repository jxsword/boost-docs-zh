execution_state::meta

返回查询中各列的元数据.

概要 
metadata_collection_view
meta() const noexcept;
说明

返回的集合将包含与 SQL 查询取回的列数相同的 metadata 对象, 且顺序一致.

异常安全性

不抛出异常保证.

对象生命周期

该函数返回一个具有引用语义的视图对象. 返回的视图指向 *this 所拥有的内存, 只要 *this 或从 *this 移动构造出的对象仍然存活, 该视图就保持有效.
