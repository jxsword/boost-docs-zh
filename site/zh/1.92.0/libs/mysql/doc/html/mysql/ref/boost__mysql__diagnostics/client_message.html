diagnostics::client_message

获取由客户端生成的错误消息.

概要 
string_view
client_message() const noexcept;
说明

与 server_message 不同, 客户端消息绝不包含服务器返回的任何字符串数据, 并且始终以 ASCII 编码. 若使用静态接口, 其中还可能包含 C++ 类型标识符.

异常安全性

不抛出异常保证.

对象生命周期

只要 *this 仍然存活、未被赋值或移动, 且尚未调用 clear , 返回的视图即保持有效. 移动 *this 会使该视图失效.
