make_tuple_element_t

一种类型特征, 将 std::make_tuple 所执行的变换应用于单个元素.

概要

定义于头文件 <boost/mysql/with_params.hpp> 

template<
    class T>
using make_tuple_element_t = typename std::tuple_element< 0, decltype(std::make_tuple(std::declval< T && >()))>:: type;
说明

例如:

  • make_tuple_element_t<int> 产生 int
  • make_tuple_element_t<const int&> 产生 int
  • make_tuple_element_t<std::reference_wrapper<int>> 产生 int&

更多信息请查阅 std::make_tuple 文档.

便捷头文件 <boost/mysql.hpp>
