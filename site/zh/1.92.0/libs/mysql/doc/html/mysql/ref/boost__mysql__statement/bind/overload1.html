statement::bind (3 个重载中的第 1 个)

将参数绑定到语句.

概要 
template<
    class... T>
bound_statement_tuple< std::tuple< see-below > >
bind(
    T&&... params) const;
说明

创建一个打包 *this 和语句实际参数 params 的对象. 该对象可传递给 connection::execute、connection::start_execution 及其异步版本.

参数会通过 std::tuple 复制到一个 std::make_tuple 中. 仅当 std::make_tuple(FWD(args)...) 产生 WritableFieldTuple 时, 此函数才参与重载决议. 等价于 this->bind(std::make_tuple(std::forward<T>(params)...)).

此函数不涉及与服务器的通信.

前置条件

this->valid() == true

异常安全性

强保证. 仅当构造任何内部 tuple 元素时抛出异常才抛出.
