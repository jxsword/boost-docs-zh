教程 1: hello world!

在本篇第一个教程中, 我们将编写一个简单的程序来演示基本概念. 我们将连接到服务器, 并执行查询 SELECT "Hello World!".

要运行本教程, 需要一个正在运行、监听 localhost 端口 3306 (默认端口) 的 MySQL 服务器. 你应当拥有一个有效 MySQL 用户 (用户名和密码) 的凭据. 无需其他设置.

本教程的完整程序清单可在此处找到.

我们将按以下步骤进行:

  1. 创建连接对象.
  2. 与服务器建立会话.
  3. 发出查询.
  4. 使用查询生成的行.
  5. 关闭连接.

本教程使用带异常的同步函数, 因为它们易于使用. 在后续教程中, 我们将学习如何使用更通用的异步函数.

命名空间约定

所有函数与类都位于 boost::mysql 命名空间中. 为了减少冗长, 所有示例和代码样例均使用以下命名空间别名:

namespace mysql = boost::mysql;
namespace asio = boost::asio;

连接对象

与大多数基于 Asio 的应用程序一样, 我们首先需要创建一个 asio::io_context 对象. io_context 是一个执行上下文: 它包含事件循环、文件描述符状态、定时器以及执行 I/O 所需的其他项目. 大多数应用程序只应创建单个 io_context, 即使需要多个 MySQL 连接也是如此.

然后, 我们创建一个 any_connection, 它表示与 MySQL 服务器的一条连接:

// The execution context, required to run I/O operations.
asio::io_context ctx;

// Represents a connection to the MySQL server.
mysql::any_connection conn(ctx);

连接到服务器

any_connection::connect 与服务器建立客户端会话. 它接受一个 connect_params 对象, 其中包含建立会话所需的信息:

// The hostname, username and password to use
mysql::connect_params params;
params.server_address.emplace_host_and_port(hostname);
params.username = username;
params.password = password;

// Connect to the server
conn.connect(params);

发出 SQL 查询

any_connection::execute 接受一个包含要运行的 SQL 查询的字符串, 并将其发送到服务器执行. 它返回一个 results 对象, 其中包含查询返回的行:

// Issue the SQL query to the server
const char* sql = "SELECT 'Hello world!'";
mysql::results result;
conn.execute(sql, result);

获取结果

results 是一个在内存中保存查询结果的类. 要获取我们选择的值, 可以这样写:

// Print the first field in the first row
std::cout << result.rows().at(0).at(0) << std::endl;

让我们把它分解成几个步骤:

  • results::rows 返回该对象包含的所有行. 它返回一个 rows_view, 这是一个类似二维矩阵的结构.
  • result.rows().at(0) 返回第一行, 表示为一个 row_view.
  • result.rows().at(0).at(0) 返回第一行中的第一个字段. 这是一个 field_view, 一个类似 variant 的类, 可以保存 MySQL 允许的任何类型.
  • 获得的 field_view 被流式输出到 std::cout.

关闭连接

使用完连接后, 我们可以通过调用 any_connection::close 来关闭它. 注意, 这会向 MySQL 服务器发送一个最终的 quit 包, 通知我们正在关闭连接, 因此可能失败.

// Close the connection
conn.close();
