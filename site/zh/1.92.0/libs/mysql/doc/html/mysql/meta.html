元数据

在本库的语境中, 元数据指描述通过执行 SQL 查询检索到的列的信息. metadata 类包含关于单个列的信息.

可以使用 results::meta 或 execution_state::meta 访问元数据. 查询检索到的每一列都有一个对应的 metadata 对象. 即使查询没有返回任何行 (例如对空表执行 SELECT), 元数据对象依然存在.

connection 对象关联有一个 metadata_mode, 用于描述在执行查询或语句时如何处理元数据:

  • 如果 connection::meta_mode 为 metadata_mode::minimal (默认值), 库将只保留运行该操作所需的最少数据. 不会保留列名等额外信息. 除非你显式使用元数据, 否则应保持此默认值, 因为它消耗的内存略少.
  • 如果 connection::meta_mode 为 metadata_mode::full, 库将保留服务器提供的全部信息, 包括列名.

只有 metadata 中为字符串类型的成员 (数据库名、表名和字段名) 会受此设置影响. 可以使用 connection::set_meta_mode 更改此设置.

例如:

// By default, a connection has metadata_mode::minimal
results result;
conn.execute("SELECT 1 AS my_field", result);
string_view colname = result.meta()[0].column_name();

// colname will be empty because conn.meta_mode() == metadata_mode::minimal
BOOST_TEST(colname == "");

// If you are using metadata names, set the connection's metadata_mode
conn.set_meta_mode(metadata_mode::full);
conn.execute("SELECT 1 AS my_field", result);
colname = result.meta()[0].column_name();
BOOST_TEST(colname == "my_field");
