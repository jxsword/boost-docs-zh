static_results::info

返回关于 SQL 语句执行的附加文本信息.

概要 
template<
    std::size_t I = 0>
string_view
info() const noexcept;
说明

该信息的格式由 MySQL 文档说明, 参见 此处.

无论连接的字符集为何, 返回的字符串始终使用 ASCII 编码.

模板参数

类型

说明

I

结果集索引. 对于返回多个结果集的操作, 可显式指定此参数以获取第 i 个结果集的值. 若不指定, 则返回第一个结果集的值.
前置条件

this->has_value() == true

异常安全性

不抛出异常保证.

对象生命周期

该函数返回一个具有引用语义的视图对象. 返回的视图指向 *this 所拥有的内存, 只要 *this 或从 *this 移动构造出的对象仍然存活, 该视图就保持有效.

复杂度

常量.
