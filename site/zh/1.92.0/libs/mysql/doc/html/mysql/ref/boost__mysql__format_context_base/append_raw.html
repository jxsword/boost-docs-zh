format_context_base::append_raw

向输出字符串添加原始 SQL (底层操作).

概要 
format_context_base&
append_raw(
    constant_string_view sql);
说明

向输出字符串添加未经转义的原始 SQL. 不改变错误状态.

默认情况下, 传入的 SQL 应当在编译期可用. 若需使用运行期值, 请使用 runtime.

这是一个底层函数. 通常, 请改用 format_sql_to.

异常安全性

基本保证. 内存分配可能抛出异常.

对象生命周期

传入的字符串会按需复制, 无需保持其存活.
