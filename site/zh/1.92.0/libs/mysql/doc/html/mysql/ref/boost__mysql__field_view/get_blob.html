field_view::get_blob

以 blob 的形式获取底层值 (不带检查的访问).

概要 
constexpr blob_view
get_blob() const noexcept;
前置条件

this->is_blob() == true (若违反, 将导致未定义行为).

异常安全性

不抛出异常保证.

对象生命周期

返回的视图与 *this 具有相同的生存期规则 (只要 *this 有效即有效).
