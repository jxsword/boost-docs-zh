any_connection::current_character_set

返回该连接使用的字符集.

概要 
system::result< character_set >
current_character_set() const noexcept;
说明

连接会尝试跟踪当前字符集. 但协议的缺陷可能导致字符集未知. 当字符集已知时, 该函数返回当前使用的字符集. 否则返回 client_errc::unknown_character_set.

以下函数可以修改该函数的返回值:

  • 连接之前, 字符集始终是未知的.
  • connect 和 async_connect 可能会根据请求的排序规则将当前字符集设置为已知值.
  • set_character_set 总是会将当前字符集设置为传入的值, async_set_character_set 也是如此.
  • reset_connection 和 async_reset_connection 总是会使当前字符集变为未知.
避免直接更改字符集

如果你使用 "SET NAMES utf8mb4" 等 SQL 语句直接更改连接的字符集, 客户端无法跟踪此更改, 该函数将返回不正确的结果.

误差
  • client_errc::unknown_character_set 当前字符集未知时.
异常安全性

不抛出异常保证.
