pool_params::server_address

决定如何建立与 MySQL 服务器的物理连接.

概要 
any_address server_address;
说明

连接池创建的连接将使用此地址连接到服务器. 它可以是主机和端口, 也可以是 UNIX 套接字路径. 默认为 (localhost, 3306).
