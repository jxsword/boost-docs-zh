rows::operator= (3 个重载中的第 1 个)

拷贝赋值.

概要 
rows&
operator=(
    const rows& other);
异常安全性

基本保证. 内部分配可能抛出异常.

对象生命周期

*this 的生存期将独立于 other 的生存期. 指向 rows_view 中元素的迭代器和引用 (包括 row_view 的、field_view 的和 *this 的) 将失效.

复杂度

与 this->size() * this->num_columns() 和 other.size() * other.num_columns() 成线性关系.
