static_results

保存 SQL 查询的结果 (静态接口).

概要

定义于头文件 <boost/mysql/static_results.hpp> 

template<
    class... StaticRow>
class static_results;

~static_results [destructor]

析构函数.
说明

此对象能以类型安全的方式保存单结果集和多结果集查询的结果.

模板参数

类型

说明

StaticRow

服务器将返回的行类型或行类型组. 查询返回的每个结果集都必须对应一个, 且始终至少有一个. 所有传入的类型都必须满足 StaticRow 概念.
线程安全

不同对象: 安全.

共享对象: 不安全.
