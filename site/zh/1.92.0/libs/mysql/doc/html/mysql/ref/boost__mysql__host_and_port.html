host_and_port

标识如何连接到 MySQL 服务器的主机和端口.

概要

定义于头文件 <boost/mysql/any_address.hpp> 

struct host_and_port;
数据成员

名称

说明

host

MySQL 服务器预期监听的主机名.

port

MySQL 服务器预期监听的端口.
说明

这是一个拥有所有权、具有值语义的类型.

便捷头文件 <boost/mysql.hpp>
