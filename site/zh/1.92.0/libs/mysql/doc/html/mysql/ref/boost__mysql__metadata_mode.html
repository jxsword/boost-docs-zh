metadata_mode

描述执行查询或语句时如何处理元数据.

概要

定义于头文件 <boost/mysql/metadata_mode.hpp> 

enum class metadata_mode;
取值

名称

说明

minimal

保留执行该操作所需的最少元数据. 这是最高效的模式, 但会使 metadata 类中的某些字段为空.

full

尽可能保留最多的元数据. metadata 中的所有字段均可用, 但会导致更多的分配.

便捷头文件 <boost/mysql.hpp>
