pipeline_request::add_close_statement

添加一个关闭语句阶段.

概要 
pipeline_request&
add_close_statement(
    statement stmt);
说明

创建一个关闭预处理语句的阶段. 所生成的阶段的效果等价于 conn.close_statement(stmt).

异常安全性

强保证. 内存分配可能抛出异常.

前置条件

传入的语句应当有效 (stmt.valid() == true).
