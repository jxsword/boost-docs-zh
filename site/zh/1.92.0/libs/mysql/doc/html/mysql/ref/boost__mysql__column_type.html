column_type

表示 MySQL 列的数据库类型.

概要

定义于头文件 <boost/mysql/column_type.hpp> 

enum class column_type;
取值

名称

说明

tinyint

TINYINT (有符号和无符号).

smallint

SMALLINT (有符号和无符号).

mediumint

MEDIUMINT (有符号和无符号).

int_

INT (有符号和无符号).

bigint

BIGINT (有符号和无符号).

float_

FLOAT (警告: p >= 24 的 FLOAT(p) 会创建 DOUBLE 列).

double_

DOUBLE

decimal

DECIMAL

bit

BIT

year

YEAR

time

TIME

date

DATE

datetime

DATETIME

timestamp

TIMESTAMP

char_

CHAR (任意长度)

varchar

VARCHAR (任意长度)

binary

BINARY (任意长度)

varbinary

VARBINARY (任意长度)

text

TEXT 类型 (TINYTEXT、MEDIUMTEXT、TEXT 和 LONGTEXT)

blob

BLOB 类型 (TINYBLOB、MEDIUMBLOB、BLOB 和 LONGBLOB)

enum_

ENUM

set

SET

json

JSON

geometry

GEOMETRY

unknown

不属于任何已知类型; 可能是我们不了解的新 MySQL 类型.
说明

它表示数据库类型, 与表示 C++ 类型的 field_kind 相对.

除非另有说明, 该枚举中的名称直接对应你在 CREATE TABLE 语句中创建该类型列时会使用的类型名 (例如 VARCHAR 对应 column_type::varchar).

便捷头文件 <boost/mysql.hpp>
