format_context_base::append_value

格式化一个值并将其添加到输出字符串 (底层操作).

概要 
format_context_base&
append_value(
    formattable_ref value,
    constant_string_view format_specifiers = string_view());
说明

该值会根据其类型进行格式化, 并应用传入的格式说明符. 若格式化产生错误 (例如传入了编码无效的字符串), 则可能设置错误状态.

这是一个底层函数. 通常, 请改用 format_sql_to.

异常安全性

基本保证. 内存分配可能抛出异常.

误差

错误状态可能被更新为以下错误:

  • client_errc::invalid_encoding — 当传入的字符串包含无法用当前字符集解码的字节序列时.
  • client_errc::unformattable_value — 当传入 NaN 或无穷大的 float 或 double 值时.
  • client_errc::format_string_invalid_specifier — 当 format_specifiers 包含被格式化类型不支持的说明符时.
  • 用户提供的 formatter 特化可能通过 add_error 添加的任何其他错误码.
