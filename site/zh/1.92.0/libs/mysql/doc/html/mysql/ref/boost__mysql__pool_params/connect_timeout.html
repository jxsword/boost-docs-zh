pool_params::connect_timeout

连接时使用的超时时间.

概要 
std::chrono::steady_clock::duration connect_timeout {std::chrono::seconds(20)};
说明

连接在交给用户之前会由连接池完成连接 (使用 any_connection::async_connect). 若该操作耗时超过此超时时间, 操作将被中断, 视为失败并稍后重试.

将此超时时间设为零可将其禁用.

此值不得为负.
