sequence_range_t

sequence 所产生的范围的类型.

概要

定义于头文件 <boost/mysql/sequence.hpp> 

template<
    class T>
using sequence_range_t = see-below;
说明

此类型特征可用于获取调用 sequence 所产生的范围类型. 此类型用作 Range 中的 format_sequence 模板参数.

默认情况下, sequence 会复制其输入范围, 除非使用 std::ref. C 数组会被复制到 std::array 对象中. 此类型特征会考虑这些变换.

正式地, 给定输入范围类型 T (可以是带 cv 限定符的引用):

  • 若 T 是 C 数组或其引用 (依据 std::is_array), 且数组元素的类型为 U , 则产生 std::array<std::remove_cv_t<U>, N>.
  • 若 T 是 std::reference_wrapper<U> 对象或其引用, 则产生 U&.
  • 否则, 产生 std::remove_cvref_t<T>.

示例:

  • sequence_range_t<const std::vector<int>&> 为 std::vector<int>.
  • sequence_range_t<std::reference_wrapper<std::vector<int>>> 为 std::vector<int>&.
  • sequence_range_t<std::reference_wrapper<const std::vector<int>>> 为 const std::vector<int>&.
  • sequence_range_t<int(&)[4]> 为 std::array<int, 4>.
