connect_params::server_default_charset

服务器用作默认值的字符集.

概要 
character_set server_default_charset {};
说明

如果你知道服务器配置使用的默认字符集, 可以将此值设置为一项优化. 它会影响连接跟踪当前字符集的方式 (见 any_connection::current_character_set):

  • 如果 connection_collation 被设为 invalid_collation_id, 则建立连接后, 连接的字符集将被假定为该字符集.
  • 成功执行 any_connection::async_reset_connection 后, 连接的字符集将被假定为该字符集 (重置会恢复服务器的默认值).

如果不知道服务器的默认字符集, 请将其保持值初始化状态 (默认值), 此时上述操作会使当前字符集保持未知.

设置此值时, 你是在向库承诺你的服务器已配置为使用该字符集作为默认字符集. 运行时不会检查这一点, 若未能履行此承诺可能导致安全漏洞. 仅在你清楚自己在做什么时才将其用作优化手段.
