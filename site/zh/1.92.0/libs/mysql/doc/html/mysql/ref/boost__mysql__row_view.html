说明

row_view 指向由外部实体拥有的内存 (如同 string_view). row_view 的有效性取决于其获取方式:

  • 若它由 row 对象构造而来 (通过调用 row::operator row_view()), 该视图充当对该行所分配内存的引用, 只要指向该行元素的引用有效, 它即保持有效.
  • 若它通过索引 rows 对象获得, 则同样适用.
  • 若它通过索引 rows_view 对象获得, 只要 rows_view 有效, 它即保持有效.

对无效视图调用任何成员函数将导致未定义行为.

在索引访问时 (使用迭代器、row_view::at 或 row_view::operator[]), 返回 field_view 元素, 只要 *this 所指向的底层存储有效, 这些元素即保持有效. 销毁 row_view 不会使其获得的 field_view 失效.

此类的实例通常由库创建, 而非由用户创建.
