formattable_ref::formattable_ref

构造函数.

概要 
template<
    class Formattable>
formattable_ref(
    Formattable&& value) noexcept;
说明

从具体的 Formattable 类型构造类型擦除的可格式化引用.

仅当传入的值满足 Formattable 概念且不是 formattable_ref 或其引用时, 此构造函数才会参与重载决议.

异常安全性

不抛出异常保证.

对象生命周期

该值可能以视图形式存储, 不过某些易于复制的类型可能以值形式存储.
