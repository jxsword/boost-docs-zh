connection_pool::connection_pool (3 个重载中的第 1 个)

构造连接池.

概要 
connection_pool(
    asio::any_io_executor ex,
    pool_params params);
说明

池以“未运行”状态创建. 请调用 async_run 以转换到“运行中”状态.

构造出的池始终有效 (this->valid() == true).

Executor

传入的执行器成为池执行器, 可通过 get_executor 获取. ex 的使用方式如下:

  • 如果 params.thread_safe == true, 则会用 ex 构建 strand. 该 strand 用于构建内部 I/O 对象, 如定时器.
  • 如果 params.thread_safe == false, 则直接使用 ex 构建内部 I/O 对象.
  • 如果 params.connection_executor 为空, 则使用 ex 构建单个连接, 与所选线程安全模式无关. 否则使用 params.connection_executor.
异常安全性

强保证. 内存分配可能抛出异常.

异常

类型

抛出时机

std::invalid_argument

如果 params 包含违反 pool_params 中所述规则的值.
