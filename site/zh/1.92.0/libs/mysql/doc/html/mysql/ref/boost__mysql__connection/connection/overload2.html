connection::connection (3 个重载中的第 2 个)

带缓冲区参数的初始化构造函数.

概要 
template<
    class... Args,
    class EnableIf = typename std::enable_if<std::is_constructible<Stream, Args...>::value>::type>
connection(
    const buffer_params& buff_params,
    Args&&... args);
说明

作为初始化的一部分, 会创建一个内部的 Stream 对象.

异常安全性

基本保证. 若 Stream 构造函数抛出异常或内部状态的内存分配失败, 则抛出异常.

参数

名称

说明

buff_params

为内部缓冲区指定初始大小.

args

要转发给 Stream 构造函数的实参.
