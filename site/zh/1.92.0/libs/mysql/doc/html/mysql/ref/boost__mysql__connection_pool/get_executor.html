connection_pool::get_executor

检索与此对象关联的执行器.

概要 
connection_pool::executor_type
get_executor() noexcept;
说明

返回构造池时作为第一个参数使用的执行器. 即使使用 pool_params::thread_safe 时也是如此 - 此时创建的内部 strand 永远不会暴露.

异常安全性

不抛出异常保证.

线程安全

读取内部状态句柄. 读取池状态. 如果池构造时启用了线程安全, 它可以与不修改状态句柄的其他函数并发调用.
