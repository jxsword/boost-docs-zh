results::has_value

返回该对象是否持有有效的结果.

概要 
bool
has_value() const noexcept;
说明

拥有 this->has_value() 是调用所有数据访问器的前置条件. 由 connection::execute 和 connection::async_execute 填充的对象保证具有 this->has_value() == true.

异常安全性

不抛出异常保证.

复杂度

常量.
