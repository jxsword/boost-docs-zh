connection::close (2 个重载中的第 1 个)

关闭与服务器的连接.

概要 
void
close(
    error_code& err,
    diagnostics& diag);
说明

仅当 Stream 满足 SocketStream 概念时, 该函数才可用.

发送 quit 请求, 执行 TLS 关闭 (如需要) 并关闭底层流. 请优先使用该函数而非 connection::quit.
