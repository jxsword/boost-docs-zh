pool_params::max_size

可创建连接的最大数量.

概要 
std::size_t max_size {151};
说明

当请求连接但所有连接都在使用中时, 会创建并连接新连接, 直至此上限.

默认为 MySQL 服务器默认允许的最大并发连接数. 若增大此值, 也应增大服务器的最大连接数 (通过设置 max_connections 全局变量).

此值必须 > 0 且 >= initial_size.
