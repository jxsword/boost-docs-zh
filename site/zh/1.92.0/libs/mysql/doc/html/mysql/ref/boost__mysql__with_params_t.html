with_params_t

可执行的查询格式字符串和格式化实参.

概要

定义于头文件 <boost/mysql/with_params.hpp> 

template<
    class... Formattable>
struct with_params_t;
数据成员

名称

说明

args

用于展开查询的实参.

query

要展开并执行的查询, 其中可包含 {} 占位符.
说明

包含带占位符的查询 (即 {}) 以及用于展开这些占位符的一组参数. 满足 ExecutionRequest 概念, 因此可传递给 any_connection::execute、any_connection::start_execution 及其异步版本.

执行时, 会调用客户端侧 SQL 格式化, 用提供的参数展开给定的查询. 生成的查询随后发送到服务器执行. 正式地, 给定一个 conn 类型的 any_connection 变量, 查询的生成方式如同调用了以下内容:

format_sql(
    this->query,
    conn.format_opts().value(),
    std::get<i>(this->args)... // for i in [0, sizeof...(Formattable))
);

此类型的对象通常使用 with_params 创建, 它通过调用 args 来创建 std::make_tuple.

对象生命周期

格式字符串 query 以视图形式存储, 大多数情况下应使用编译期字符串. 使用 with_params 时, args 通常包含传入参数的副本 (依据 std::make_tuple), 即使配合使用带延迟完成标记的异步函数也是安全的. 可以用 std::ref 禁用此类复制, 如同使用 std::make_tuple 时那样.

误差

传递给 any_connection::execute、any_connection::start_execution 或其异步版本时, 除常见的网络和服务器生成的错误外, with_params_t 还可能产生以下错误:

  • format_sql 产生的任何错误. 包括无效格式字符串和不可格式化实参 (如无效 UTF-8) 导致的错误.
  • 若连接在查询执行时不知道自己使用的字符集 (即 client_errc::unknown_character_set 会返回错误), 则为 any_connection::current_character_set.
