OutputString 概念

OutputString 是一种窄字符字符串类型, 可用作生成字符串操作的输出. std::string、std::basic_string<char, Traits, Allocator> 或 boost::static_string<N> 等类型满足该概念.

形式上, 类型 T 满足 OutputString 的条件是以下全部为真:

  • 它满足 std::movable 概念.
  • 具有一个 append(const char* data, std::size_t size) 成员函数, 可用于向字符串追加字符范围.
  • 具有一个 clear() 函数, 可用于移除字符串中的所有字符.
