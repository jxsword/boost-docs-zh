diagnostics::server_message

获取由服务器生成的错误消息.

概要 
string_view
server_message() const noexcept;
说明

其按照 character_set_results 字符集编码, 该字符集通常与连接的字符集一致. 其中可能包含用户输入.

异常安全性

不抛出异常保证.

对象生命周期

只要 *this 仍然存活、未被赋值或移动, 且尚未调用 clear , 返回的视图即保持有效. 移动 *this 会使该视图失效.
