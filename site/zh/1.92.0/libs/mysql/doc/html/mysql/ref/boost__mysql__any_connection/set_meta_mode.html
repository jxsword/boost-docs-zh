any_connection::set_meta_mode

Sets the metadata mode.

概要 
void
set_meta_mode(
    metadata_mode v) noexcept;
说明

将影响调用之后执行的任何查询与语句执行.

异常安全性

不抛出异常保证.

前置条件

调用此函数时不应有未完成的异步操作.

参数

名称

说明

v

The new metadata mode.
