connection_pool::~connection_pool

析构函数.

概要 
~connection_pool();
说明

按照 *this 的语义, 取消 cancel 上所有未完成的异步操作.

线程安全

修改内部状态句柄. 修改池状态. 该函数 绝不能与其他读取内部状态句柄的函数并发调用, 即使对于以 pool_params::thread_safe 设为 true 创建的池也是如此.

内部池状态的修改遵循 cancel 的语义. 如果启用了线程安全, 则可以安全地与只访问池内部状态的函数 (例如归还连接) 并发调用析构函数.
