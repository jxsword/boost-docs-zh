说明

这是一个轻量级的、类似 variant 的类型, 决定池中的连接如何设置其字符集, 以及在归还连接池时如何恢复它. 请使用 set_to_utf8mb4 和 use_server_default 工厂函数创建实例.

  • 使用 set_to_utf8mb4 (默认值) 时, 连接建立时使用排序规则 ID utf8mb4_general_ci , 并在连接归还池中并被重置之后发出一条 SET NAMES 语句. 字符集始终已知且等于 utf8mb4.
  • 使用 use_server_default 时, 连接建立时使用 invalid_collation_id 作为排序规则 ID, 从而使连接使用服务器的默认值. 重置连接后不会发出 SET NAMES 语句, 连接将再次使用服务器的默认值. 使用此值时, 必须提供服务器的默认字符集作为实参, 且它必须与服务器中实际配置的一致 (不执行运行期检查). 此选项只应用作优化手段, 且须在清楚自己在做什么的前提下使用.
