pipeline_request::add_execute_range

添加一个执行预处理语句的阶段.

概要 
pipeline_request&
add_execute_range(
    statement stmt,
    span< const field_view > params);
说明

创建一个运行 stmt 并绑定 params 中所传参数的阶段, 类似于 any_connection::execute 和 statement::bind. 例如, add_execute_range(stmt, params) 的效果等价于 conn.execute(stmt.bind(params.begin(), params.end())).

当语句的实际参数数量在编译期未知时, 可用此函数代替 add_execute.

异常安全性

强保证. 若提供的参数数量与语句所期望的参数数量不匹配则抛出异常. 此外, 内存分配也可能抛出异常.

异常

类型

抛出时机

std::invalid_argument

若 params.size() != stmt.num_params()

前置条件

传入的语句应当有效 (stmt.valid() == true).

对象生命周期

params 范围会被复制到请求中, 在此函数返回后无需保持其存活.
