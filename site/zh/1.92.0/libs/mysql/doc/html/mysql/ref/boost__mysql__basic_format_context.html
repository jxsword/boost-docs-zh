说明

增量 SQL 格式化的主接口. 与 format_context_base 不同, 该类型知晓输出字符串的实际类型. basic_format_context 持有一个 OutputString 实例. 格式化操作会向该字符串追加字符.

该类型的对象是一次性的: 一旦通过 get 取回了结果, 就不能再复用. 这是一个仅可移动 (move-only) 的类型.
