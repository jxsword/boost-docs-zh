quoting_context

标识字符串被转义时所处的上下文.

概要

定义于头文件 <boost/mysql/escape_string.hpp> 

enum class quoting_context
    : char;
取值

名称

说明

double_quote

字符串由双引号包围.

single_quote

字符串由单引号包围.

backtick

字符串由反引号包围.
