pool_params::charset_strategy

决定连接池所创建连接使用的字符集.

概要 
pool_charset_strategy charset_strategy {};
说明

控制池化连接如何管理其字符集. 默认为 pool_charset_strategy::set_to_utf8mb4 , 它通过显式设置使所有连接使用 utf8mb4.

这是一个高级设置. 更改之前请先阅读字符集跟踪的工作原理.
