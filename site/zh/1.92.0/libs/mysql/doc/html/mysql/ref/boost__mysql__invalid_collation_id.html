invalid_collation_id

一个永远无效的排序规则 ID.

概要

定义于头文件 <boost/mysql/defaults.hpp> 

constexpr
std::uint16_t invalid_collation_id = 0u;
说明

将此值作为 connect_params::connection_collation 传入, 可将连接的字符集和排序规则设为服务器的默认值. 运行 "SELECT @@GLOBAL.character_set_client;" 可查明服务器的默认字符集.

此项旨在与 connect_params::server_default_charset 配合使用.

便捷头文件 <boost/mysql.hpp>
