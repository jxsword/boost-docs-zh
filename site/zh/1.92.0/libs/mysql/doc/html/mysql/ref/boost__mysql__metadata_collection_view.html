metadata_collection_view

一组 metadata 对象的只读视图.

概要

定义于头文件 <boost/mysql/metadata_collection_view.hpp> 

using metadata_collection_view = boost::span< const metadata >;
对象生命周期

该对象不拥有 metadata 对象的存储. 这些对象通常由 results 或 execution_state 对象所拥有. 只要为 metadata 对象分配的内存仍然有效, 此视图即保持有效.

便捷头文件 <boost/mysql.hpp>
