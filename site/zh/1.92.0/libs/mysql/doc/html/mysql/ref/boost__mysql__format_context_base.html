format_context_base

具体格式化上下文的基类.

概要

定义于头文件 <boost/mysql/format_sql.hpp> 

class format_context_base;
成员函数

名称

说明

add_error

向当前错误状态添加一个错误.

append_raw

向输出字符串添加原始 SQL (底层操作).

append_value

格式化一个值并将其添加到输出字符串 (底层操作).

error_state

获取当前错误状态.

format_opts

获取格式化选项.
说明

从概念上讲, 一个格式化上下文包含:

  • 结果字符串. 输出操作向该输出字符串追加字符. format_context_base 对输出字符串的类型不敏感.
  • 格式化值所需的 format_options.
  • 一个错误状态 (error_state), 在输出操作失败时由其设置. 该错误状态会传播到 basic_format_context::get.

当你需要在不知道将要使用的实际上下文类型的情况下操作格式化上下文时 (例如在特化 formatter 时), 对此类的引用很有用.

该类不能直接实例化 — 请改用 basic_format_context. 也不要继承它.
