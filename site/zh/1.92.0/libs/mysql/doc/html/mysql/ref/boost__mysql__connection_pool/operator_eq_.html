connection_pool::operator=

移动赋值.

概要 
connection_pool&
operator=(
    connection_pool&& other);
说明

将 other 赋给 *this, 转移所有权.

该函数返回后, 如果 other.valid() == true, 则 this->valid() == true. 无论哪种情况, other 都将变为无效 (other.valid() == false).

移动一个带有未完成异步操作的连接池是安全的.

异常安全性

不抛出异常保证.

线程安全

修改 *this 和 other 的内部状态句柄. 不访问池状态. 该函数 绝不能与其他读取内部状态句柄的函数并发调用, 即使对于以 pool_params::thread_safe 设为 true 创建的池也是如此.

不访问内部池状态, 因此该函数可以与只访问池内部状态的函数 (例如归还连接) 并发调用.
