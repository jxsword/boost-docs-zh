pool_params::ssl_ctx

使用 TLS 的连接所用的 SSL 上下文.

概要 
boost::optional< asio::ssl::context > ssl_ctx {};
说明

若提供了非空值, 连接池创建的所有连接在使用 TLS 时都将使用传入的上下文. 这样可以为池创建的连接设置 TLS 选项.

若传入空值 (默认情况) 且连接需要 TLS, 连接池会创建一个带合适选项的内部 SSL 上下文.
