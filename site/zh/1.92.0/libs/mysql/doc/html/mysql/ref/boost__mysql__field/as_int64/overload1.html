field::as_int64 (2 个重载中的第 1 个)

获取底层 std::int64_t 值的引用, 否则抛出异常.

概要 
const std::int64_t&
as_int64() const;
异常安全性

强保证. 类型不匹配时抛出异常.

异常

类型

抛出时机

bad_field_access

若 !this->is_int64()

对象生命周期

只要 *this 仍然存活, 且未对 *this 调用任何会使引用失效的函数, 返回的引用即保持有效.
