metadata::original_table

返回该列所属物理表的名称.

概要 
string_view
original_table() const noexcept;
说明

例如在 "SELECT * FROM employees emp" 中, original_table() 将是 "employees".

这是可选信息 — 除非执行查询的连接具有 meta_mode() == metadata_mode::full , 否则不会填充.

异常安全性

不抛出异常保证.

对象生命周期

只要 *this 仍然存活且未被赋值或移动, 返回的引用即保持有效.
