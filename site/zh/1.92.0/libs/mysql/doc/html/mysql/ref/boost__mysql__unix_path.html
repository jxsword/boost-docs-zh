unix_path

包含一个 UNIX 套接字域路径.

概要

定义于头文件 <boost/mysql/any_address.hpp> 

struct unix_path;
数据成员

名称

说明

path

MySQL 服务器监听的 UNIX 域套接字路径.
说明

此类型在所有系统中都有定义, 与其是否支持 UNIX 套接字无关.

这是一个拥有所有权、具有值语义的类型.
