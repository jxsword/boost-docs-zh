any_connection_params::ssl_context

包含 TLS 配置选项的外部 SSL 上下文.

概要 
asio::ssl::context* ssl_context {};
说明

仅与 SSL 连接相关 (即最终使 any_connection::uses_ssl 返回 true 的连接).

如果连接被配置为使用 TLS, 会创建一个内部的 asio::ssl::stream 对象. 如果该成员被设为非空值, 该内部对象将使用传入的上下文初始化. 这是在 any_connection 中配置 TLS 选项的唯一方式.

如果连接被配置为使用 TLS 且该成员为 nullptr, 将创建一个带有合适默认选项的内部 asio::ssl::context 对象.

对象生命周期

如果设为非空, 所指对象必须保持存活, 直到从 any_connection 构造的所有 *this 对象都被销毁.
