pipeline_request::add_execute (2 个重载中的第 2 个)

添加一个执行预处理语句的阶段.

概要 
template<
    class... WritableField>
pipeline_request&
add_execute(
    statement stmt,
    const WritableField&... params);
说明

创建一个运行 stmt 并绑定 params 中所传参数的阶段, 类似于 any_connection::execute 和 statement::bind. 例如, add_execute(stmt, 42, "John") 的效果等价于 conn.execute(stmt.bind(42, "John")).

异常安全性

强保证. 若提供的参数数量与语句所期望的参数数量不匹配则抛出异常. 此外, 内存分配也可能抛出异常.

异常

类型

抛出时机

std::invalid_argument

若 sizeof...(params) != stmt.num_params()

前置条件

传入的语句应当有效 (stmt.valid() == true).

对象生命周期

params 所指向的任何对象都会被复制到请求中, 在此函数返回后无需保持其存活.

类型要求

任何满足 WritableField 的类型都可用作参数. 这包括所有可与 statement::bind 一起使用的类型, 包括标量类型、字符串、blob 和 optional.
