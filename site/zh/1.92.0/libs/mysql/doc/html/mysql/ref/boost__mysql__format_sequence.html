format_sequence

sequence 的返回类型.

概要

定义于头文件 <boost/mysql/sequence.hpp> 

template<
    class Range,
    class FormatFn>
struct format_sequence;
数据成员

名称

说明

format_function

要应用于范围中每个元素的格式化函数.

glue

在范围元素之间输出的字符串.

range

要格式化的范围.
说明

包含一个范围、一个格式化函数和一个粘接字符串. 该类型满足 Formattable 概念.

格式化时, format_function 将针对 range 中的每个元素被调用. 字符串 glue 会以原始形式输出 (依据 format_context_base::append_raw) 在格式化函数相邻两次调用之间, 产生类似于 std::ranges::views::join 的效果.

不要直接实例化该结构体 — 请改用 sequence.

类型要求
  • 表达式 std::begin(range) 和 std::end(range) 应返回一对可进行 (不) 相等比较的输入迭代器/哨兵 (sentinel).
  • 表达式 static_cast<const FormatFn&>(fn)(* std::begin(range), ctx) 应当是良构的, 其中 ctx 是一个 format_context_base&.
