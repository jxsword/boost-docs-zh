unix_ssl_connection

(遗留) 基于 UNIX 域套接字并使用 TLS 的 MySQL 连接.

概要

定义于头文件 <boost/mysql/unix_ssl.hpp> 

using unix_ssl_connection = connection< boost::asio::ssl::stream< boost::asio::local::stream_protocol::socket > >;
旧式

新代码不应使用此类. 使用 UNIX 套接字时, 建议使用明文连接.

便捷头文件 <boost/mysql.hpp>
