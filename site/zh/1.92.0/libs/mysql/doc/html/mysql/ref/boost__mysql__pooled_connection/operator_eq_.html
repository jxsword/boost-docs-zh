pooled_connection::operator=

移动赋值.

概要 
pooled_connection&
operator=(
    pooled_connection&& other) noexcept;
说明

若 this->valid() , 则将 *this 拥有的连接归还连接池, 并将其标记为待重置 (如同调用了析构函数). 然后将连接的所有权从 other 转移给 *this.

该函数返回后, 如果 other.valid() == true, 则 this->valid() == true. 无论哪种情况, other 都将变为无效 (other.valid() == false).

线程安全

可能导致 this 所指向的连接池发生变更. 仅当共享的连接池在构造时将 pool_params::thread_safe 设为 true, 此操作才是线程安全的.

异常安全性

不抛出异常保证.
