connection::async_read_resultset_head (2 个重载中的第 1 个)

读取多结果集操作中后续结果集的元数据.

概要 
template<
    class ExecutionStateType,
    class CompletionToken>
auto
async_read_resultset_head(
    ExecutionStateType& st,
    CompletionToken&& token);
说明

如果 st.should_read_head() == true, 该函数会读取下一个结果集的初始响应消息和元数据 (如果有). 如果该结果集指示失败 (例如与该结果集关联的查询包含错误), 该函数将以该错误失败.

如果 st.should_read_head() == false, 该函数为空操作.

st 可以是 execution_state 或 static_execution_state 对象.

仅当对返回多于一个结果集的语句使用多函数操作时, 该函数才有意义.

使用静态接口时, 该函数会检测当前正在读取的结果集的模式不匹配. 后续调用该函数以及 read_some_rows 还可能检测到其他错误.

处理器签名

该操作的处理器签名是 void(boost::mysql::error_code).

Executor

中间完成处理器以及最终处理器都使用 token 的关联执行器执行, 若该标记没有关联执行器则使用 this->get_executor().

如果最终处理器有关联的立即执行器且操作立即完成, 最终处理器会被派发给它. 否则, 最终处理器的调用方式如同通过 asio::post 提交, 且绝不会在该函数内被内联调用.
