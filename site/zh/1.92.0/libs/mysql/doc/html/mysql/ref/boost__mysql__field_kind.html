field_kind

表示 field 或 field_view 可能具有的各 C++ 类型.

概要

定义于头文件 <boost/mysql/field_kind.hpp> 

enum class field_kind;
取值

名称

说明

null

值为 NULL 时为以下任意一种.

int64

该 field 包含一个 std::int64_t.

uint64

该 field 包含一个 std::uint64_t.

string

该 field 包含一个字符串 (std::string 对应 field , string_view 对应 field_view).

blob

该 field 包含一个二进制字符串 (blob 对应 field , blob_view 对应 field_view).

float_

该 field 包含一个 float.

double_

该 field 包含一个 double.

date

该 field 包含一个 date.

datetime

该 field 包含一个 datetime.

time

该 field 包含一个 time.

便捷头文件 <boost/mysql.hpp>
