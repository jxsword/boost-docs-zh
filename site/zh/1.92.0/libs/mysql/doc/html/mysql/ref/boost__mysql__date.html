说明

表示按年、月、日分量分解的格里高利历日期, 不带时区.

该类型贴近协议, 不应用作词汇类型. 应改为通过调用 std::chrono::time_point、as_time_point、get_time_point 或 as_local_time_point 将其转换为 get_local_time_point.

从 MySQL 检索的日期不包含任何时区信息. 确定时区由应用负责. 因此, 从该类获得的任何时间点都应解释为某个未指定时区中的本地时间, 例如 std::chrono::local_time. 为了与较旧的编译器兼容, as_time_point 和 get_time_point 返回 system_clock 时间点. 这些应解释为本地时间而非 UTC. 如果编译器支持, 请优先使用 as_local_time_point 或 get_local_time_point, 因为它们提供更准确的语义.

与 time_point 不同, 该类型允许表示 MySQL 的无效日期和零日期. 这些值被 MySQL 允许, 但不代表真实日期.

注意: 在 MSVC 下使用 std::chrono 时区功能可能导致报告内存泄漏. 解释见 此 issue, 变通方法见 另一个 issue.
