throw_on_error

(遗留) 出错时抛出异常, 其中包含诊断信息.

概要

定义于头文件 <boost/mysql/throw_on_error.hpp> 

void
throw_on_error(
    error_code err,
    const diagnostics& diag = {});
说明

若 err 表示失败 (err.failed() == true), 则抛出派生自 error_with_diagnostics 的异常. 该异常会将 diag 提供到 error_with_diagnostics::get_diagnostics 中.

旧式

with_diagnostics 的引入几乎使此函数的所有用途变得过时. 新代码应尝试使用 with_diagnostics 而非手动检查错误.

便捷头文件 <boost/mysql.hpp>
