stage_response::as_statement

获取所包含的语句, 否则抛出异常.

概要 
statement
as_statement() const;
说明

若 *this 包含语句 (this->has_statement() == true), 则获取它. 否则抛出异常.

异常安全性

强保证. 输入无效时抛出异常.

异常

类型

抛出时机

std::invalid_argument

若 *this 不包含语句.
