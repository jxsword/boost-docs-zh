pool_params::connection_executor

连接池所创建的各个连接使用的执行器.

概要 
asio::any_io_executor connection_executor {};
说明

若此成员被设置为非空值 (即 static_cast<bool>(connection_executor) == true), 各个连接将使用此执行器创建. 否则, 连接将使用连接池的执行器 (依据 connection_pool::get_executor).
