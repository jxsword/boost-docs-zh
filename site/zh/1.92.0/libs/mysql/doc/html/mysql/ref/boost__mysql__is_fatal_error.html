is_fatal_error

检查某个错误是否需要重新连接.

概要

定义于头文件 <boost/mysql/is_fatal_error.hpp> 

bool
is_fatal_error(
    error_code ec) noexcept;
说明

对已建立的连接的操作 (如执行查询) 失败后, 连接可能仍可用于后续操作 (若错误非致命), 也可能不可用 (若错误致命). 该函数用于判定连接操作返回的错误码是否致命.

要从致命错误中恢复, 请关闭并重新建立连接.

异常安全性

不抛出异常保证.

便捷头文件 <boost/mysql.hpp>
