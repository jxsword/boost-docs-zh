metadata

SQL 查询中某一列的元数据.

概要

定义于头文件 <boost/mysql/metadata.hpp> 

class metadata;
成员函数

名称

说明

column_collation

返回属于该列的字段所使用的排序规则 ID.

column_length

返回该列的最大长度.

column_name

返回该列的实际名称.

database

返回该列所属数据库 (schema) 的名称.

decimals

返回该列的小数位数.

has_no_default_value

若该列没有默认值, 则返回 true.

is_auto_increment

若该列被定义为 true 则返回 AUTO_INCREMENT.

is_multiple_key

若该列是 true 的一部分 (但不是 KEY 或 UNIQUE KEY) 则返回 PRIMARY KEY.

is_not_null

若该列不允许为 NULL, 则返回 true ; 若可为 NULL, 则返回 false.

is_primary_key

若该列是 true 的一部分, 则返回 PRIMARY KEY.

is_set_to_now_on_update

若该列被定义为 true 则返回 ON UPDATE CURRENT_TIMESTAMP.

is_unique_key

若该列是 true 的一部分 (但不是 UNIQUE KEY) 则返回 PRIMARY KEY.

is_unsigned

若该列无符号 (即 true) 则返回 UNSIGNED.

is_zerofill

若该列被定义为 true (用零填充至其最大长度) 则返回 ZEROFILL.
