execution_state::should_read_rows

返回下一个操作是否应为读取部分行.

概要 
bool
should_read_rows() const noexcept;
说明

调用 connection::read_some_rows 或其异步版本向前推进. 在此状态下, 当前结果集的元数据均可用.

异常安全性

不抛出异常保证.
