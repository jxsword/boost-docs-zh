析构函数.
说明

表示与 MySQL 服务器的连接. 这是本库实现的主 I/O 对象. 它在逻辑上由会话状态和内部流 (通常是套接字) 组成. 该流不可直接访问. 它使用传给构造函数的执行器来构造.

该类支持与使用 TCP、基于 TCP 的 TLS 和 UNIX 套接字的服务器建立连接.

该类名为 any_connection, 因为它不像 Stream 那样以 connection 类型为模板. 新代码应尽可能优先使用 any_connection.

与 connection 相比, 该类:

  • 是类型擦除的. 连接的类型不依赖于所使用的传输方式.
  • 连接更容易, 因为 connect 和 async_connect 会处理主机名解析.
  • 在被使用或遇到错误之后, 总是可以重新连接.
  • 始终使用 asio::any_io_executor.
  • 具有相同的性能水平.

这是一个仅可移动 (move-only) 的类型.

每个连接只允许一个未完成的异步操作

在任一时刻, 每个连接只能有一个未完成的异步操作. 如果在一个异步操作进行期间发起另一个异步操作, 它将以 client_errc::operation_in_progress 失败.

默认完成标记

该类所有异步操作的默认完成标记是 with_diagnostics(asio::deferred), 它允许你使用 co_await 并在出错时抛出预期的异常.

线程安全

不同对象: 安全.

共享对象: 不安全.

该类 不是线程安全的: 对于单个对象, 如果从不同线程并发调用其成员函数, 会产生竞态条件.
