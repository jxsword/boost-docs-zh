constant_string_view::constant_string_view

consteval 构造函数.

概要 
template<
    class T>
consteval
constant_string_view(
    const T& value) noexcept;
说明

由传入的实参构造一个 string_view.

该函数是 consteval: 如果传入的值在编译期未知, 将导致编译期错误. 可以使用 runtime 函数绕过该检查. 此检查仅适用于 C++20 及以上. 更低的 C++ 标准版本不执行检查.

仅当能由传入的值构造出 string_view 时, 才会考虑该构造函数.

异常安全性

不抛出异常保证.

对象生命周期

所有权不会转移给构造出的对象. 与 string_view 一样, 用户负责保持原字符缓冲区存活.
