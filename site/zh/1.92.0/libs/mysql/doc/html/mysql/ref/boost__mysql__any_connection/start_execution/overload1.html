any_connection::start_execution (2 个重载中的第 1 个)

将一次 SQL 执行作为多函数操作启动.

概要 
template<
    class ExecutionRequest,
    class ExecutionStateType>
void
start_execution(
    ExecutionRequest&& req,
    ExecutionStateType& st,
    error_code& err,
    diagnostics& diag);
说明

写入执行请求并读取服务器的初始响应和列元数据, 但不读取生成的行或后续结果集 (如果有的话). st 可以是 execution_state 或 static_execution_state 对象.

此操作完成后, st 将被填充 execution_state::meta. 元数据将按 this->meta_mode() 填充.

如果操作生成了任何行或多于一个结果集, 在进行任何后续网络操作之前 必须通过 read_some_rows 和 read_resultset_head 将它们读取完毕. 否则, 结果是未定义的.

req 可以是可转换为 string_view 的、包含合法 SQL 的类型, 或通过调用 statement::bind 得到的已绑定预处理语句. 如果是字符串, 必须使用连接的字符集编码. 提供给 statement::bind 的任何字符串参数也应使用连接的字符集编码.

使用静态接口时, 该函数会检测第一个结果集的模式不匹配. read_resultset_head 和 read_some_rows 还可能检测到其他错误.
