connection::uses_ssl

返回连接是否协商使用了 SSL.

概要 
bool
uses_ssl() const noexcept;
说明

在使用 SSL 协商时, 该函数可用于确定当前是否使用 SSL 连接.

如果底层流不支持 SSL, 该函数总是返回 false. 对于尚未建立的连接 (尚未运行握手), 该函数总是返回 false. 如果握手失败, 返回值未定义.

异常安全性

不抛出异常保证.

返回值

连接是否正在使用 SSL.
