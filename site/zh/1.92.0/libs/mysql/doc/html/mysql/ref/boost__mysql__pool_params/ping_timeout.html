pool_params::ping_timeout

ping 和会话重置使用的超时时间.

概要 
std::chrono::steady_clock::duration ping_timeout {std::chrono::seconds(10)};
说明

若 ping (依据 any_connection::async_ping) 或会话重置 (依据 any_connection::async_reset_connection) 耗时超过此超时时间, 它们将被取消, 且操作将被视为失败.

将此超时时间设为零可将其禁用.

此值不得为负.
