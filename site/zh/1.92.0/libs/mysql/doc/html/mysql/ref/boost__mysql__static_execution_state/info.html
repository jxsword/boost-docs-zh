static_execution_state::info

返回关于此结果集的附加文本信息.

概要 
string_view
info() const noexcept;
说明

该信息的格式由 MySQL 文档说明, 参见 此处.

无论连接的字符集为何, 返回的字符串始终使用 ASCII 编码.

异常安全性

不抛出异常保证.

前置条件

this->complete() == true || this->should_read_head() == true

对象生命周期

该函数返回一个具有引用语义的视图对象. 返回的视图指向 *this 所拥有的内存, 只要 *this 或从 *this 移动构造出的对象仍然存活, 该视图就保持有效.
