stage_response::get_statement

获取所包含的语句 (不带检查的访问器).

概要 
statement
get_statement() const noexcept;
说明

若 *this 包含语句, 则获取它. 否则, 行为未定义.

前置条件

this->has_statement() == true

异常安全性

不抛出异常保证.
