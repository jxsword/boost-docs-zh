pipeline_request::add_set_character_set

添加一个设置字符集阶段.

概要 
pipeline_request&
add_set_character_set(
    character_set charset);
说明

创建一个设置连接字符集的阶段. 所生成的阶段的效果等价于 conn.set_character_set(charset).

异常安全性

强保证. 若提供的字符集名称无效 (即 charset.name 包含非 ASCII 字符) 则抛出异常. 该检查是一种加固措施, 对本库提供的字符集而言永远不会触发.

此外, 内存分配也可能抛出异常.

异常

类型

抛出时机

std::invalid_argument

若 charset.name 包含非 ASCII 字符.
前置条件

传入的字符集不应当是默认构造的 (charset.name != nullptr).
