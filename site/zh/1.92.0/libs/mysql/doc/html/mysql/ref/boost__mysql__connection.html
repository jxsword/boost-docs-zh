说明

表示与 MySQL 服务器的模板化连接.

connection 持有一个 Stream 对象, 涉及网络操作的函数会访问它, 同时还有会话状态. 可以通过 connection::stream 访问该流, 通过 connection::get_executor 访问其执行器. 该对象使用的执行器始终与底层流相同.

每个连接只允许一个未完成的异步操作

在任一时刻, 每个连接只能有一个未完成的异步操作. 如果在一个异步操作进行期间发起另一个异步操作, 它将以 client_errc::operation_in_progress 失败.

线程安全

不同对象: 安全.

共享对象: 不安全.

该类 不是线程安全的: 对于单个对象, 如果从不同线程并发调用其成员函数, 会产生竞态条件.

旧式

新代码应使用 any_connection 而不是该类, 因为它更易用且提供相同的性能水平.
