说明

建模为一个不拥有所有权的类矩阵容器. 对 rows_view 对象进行索引访问 (使用迭代器、rows_view::at 或 rows_view::operator[]) 会返回一个 row_view 对象, 表示单行. 集合中的所有行大小相同 (由 num_columns 给出).

rows_view 对象指向由外部实体拥有的内存 (如同 string_view). rows_view 对象的有效性取决于其获取方式:

  • 若它由 rows 对象构造而来 (通过调用 rows::operator rows_view()), 该视图充当对 rows 所分配内存的引用, 只要指向该 rows 元素的引用有效, 它即保持有效.
  • 若它通过调用 connection::read_some_rows 获得, 则在 connection 执行下一次网络调用或被销毁之前保持有效.

使用 row_view 对象获得的 field_view 和 rows_view 有效, 只要 *this 所指向的底层存储有效. 销毁 *this 不会使这些引用失效.

对无效视图调用任何成员函数将导致未定义行为.

此类的实例通常由库创建, 而非由用户创建.
