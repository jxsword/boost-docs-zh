field::operator field_view

构造一个 field_view , 指向 *this.

概要 
operator field_view() const noexcept;
说明

生成的 field_view 与 *this 具有相同的 kind 和值.

异常安全性

不抛出异常保证.

对象生命周期

返回的对象充当指向 *this 的引用, 只要 *this 仍然存活即保持有效.
