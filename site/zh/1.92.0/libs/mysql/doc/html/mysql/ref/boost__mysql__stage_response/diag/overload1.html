stage_response::diag (2 个重载中的第 1 个)

获取所包含的诊断信息 (左值引用访问器).

概要 
diagnostics
diag() const&;
说明

若 *this 包含错误, 则通过复制获取关联的诊断信息. 否则 (若 this->has_statement() || this->has_results()), 返回空的 diagnostics 对象.

异常安全性

强保证: 内存分配可能抛出异常.
