basic_format_context::operator=

移动赋值.

概要 
basic_format_context&
operator=(
    basic_format_context&& rhs);
说明

将 rhs 的输出字符串移动赋值给 *this 的输出字符串. *this 将拥有与 rhs 相同的格式化选项和错误状态. rhs 将处于有效但未指定的状态.

异常安全性

基本保证: 移动构造 OutputString 抛出的异常会被传播.
