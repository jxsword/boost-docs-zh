underlying_row_t

用于获取底层行类型的类型特征.

概要

定义于头文件 <boost/mysql/underlying_row.hpp> 

template<
    class StaticRow>
using underlying_row_t = see-below;
说明

给定满足 T 概念的输入类型 StaticRow , 此特征是其底层行类型的别名. 其定义如下:

  • 若 T 是标记类型, 如 pfr_by_name< U > , 则 underlying_row_t 是标记内部类型 U 的别名.
  • 若 T 不是标记类型 (例如它是 Boost.Describe 结构体或 std::tuple), 则 underlying_row_t 是 T 的别名.

例如, static_results::rows 使用此特征确定其返回类型.

便捷头文件 <boost/mysql.hpp>
