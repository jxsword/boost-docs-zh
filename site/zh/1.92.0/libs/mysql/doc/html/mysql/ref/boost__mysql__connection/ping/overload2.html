connection::ping (2 个重载中的第 2 个)

检查服务器是否存活.

概要 
void
ping();
说明

如果服务器存活, 该函数将无错误地完成. 如果不存活, 将以相关的网络或协议错误失败.

注意, 在协议层面 ping 请求与其他类型的请求一样对待, 服务器不会以任何方式优先处理. 如果服务器正忙于长时间运行的查询, ping 请求在该查询结束前不会被应答.
