教程 2: 使用 C++20 协程实现异步

在 上一个教程 中, 我们使用了同步函数. 它们简单, 但有一些局限:

  • 它们不像异步函数那样通用. 例如, 无法为同步操作设置超时.
  • 它们的扩展性不佳. 由于同步函数会阻塞调用线程直至完成, 需要创建 OS 线程来实现并行. 这扩展性不佳, 并带来多线程程序固有的复杂性.
  • 某些类 (如 connection_pool) 只提供异步接口.

因此, 我们建议始终使用异步函数. 所有兼容 Asio 的库 (包括本库) 都支持以多种风格进行异步编程. 本章将讲解如何使用 C++20 协程, 因为它们最易使用.

注释

还没有使用 C++20? 不用担心, 即使在 C++11 中也可以使用 有栈协程 和 回调.

什么是协程?

粗略地说, 它是一种可以挂起和恢复的函数, 挂起期间局部变量保持存活. 挂起发生在到达 co_await 表达式时. 这些表达式通常出现在程序执行 I/O 操作时. 当遇到这样的表达式时, 会发生以下情况:

  1. 协程发起 I/O 操作.
  2. 协程挂起, 将控制权交还给 io_context (即事件循环).
  3. 在 I/O 操作进行期间, io_context 可以运行其他操作, 例如其他协程.
  4. 当 I/O 操作完成时, io_context 会紧接着 co_await 表达式之后恢复协程.

将同步代码转换为协程

回顾上一个教程中的以下代码:

// The hostname, username and password to use
mysql::connect_params params;
params.server_address.emplace_host_and_port(hostname);
params.username = username;
params.password = password;

// Connect to the server
conn.connect(params);

// Issue the SQL query to the server
const char* sql = "SELECT 'Hello world!'";
mysql::results result;
conn.execute(sql, result);

// Print the first field in the first row
std::cout << result.rows().at(0).at(0) << std::endl;

// Close the connection
conn.close();

要将此代码转换为协程, 我们需要:

  • 将其提取到一个返回 boost::asio::awaitable<void> 的独立函数中.
  • 将同步函数 (如 any_connection::connect) 替换为异步函数 (如 any_connection::async_connect).
  • 在每个 I/O 操作前放置一个 co_await 运算符.

如此一来, 我们得到:

asio::awaitable<void> coro_main(
    mysql::any_connection& conn,
    std::string_view server_hostname,
    std::string_view username,
    std::string_view password
)
{
    // The hostname, username, password and database to use.
    // TLS is used by default.
    mysql::connect_params params;
    params.server_address.emplace_host_and_port(std::string(server_hostname));
    params.username = username;
    params.password = password;

    // Connect to the server
    co_await conn.async_connect(params);

    // Issue the SQL query to the server
    const char* sql = "SELECT 'Hello world!'";
    mysql::results result;
    co_await conn.async_execute(sql, result);

    // Print the first field in the first row
    std::cout << result.rows().at(0).at(0) << std::endl;

    // Close the connection
    co_await conn.async_close();
}

注意协程不会显式创建或返回任何 boost::asio::awaitable<void> 对象 — 这由编译器处理. 返回类型实际上是将函数标记为协程. 此处 void 表示该协程不返回任何东西.

若上述任何 I/O 操作失败, 会抛出异常. 可以通过 使用 asio::redirect_error 来阻止这一点.

运行我们的协程

与上一个教程一样, 我们首先需要创建一个 io_context 和一个连接:

// The execution context, required to run I/O operations.
asio::io_context ctx;

// Represents a connection to the MySQL server.
mysql::any_connection conn(ctx);

要运行协程, 请使用 asio::co_spawn:

// Enqueue the coroutine for execution.
// This does not wait for the coroutine to finish.
asio::co_spawn(
    // The execution context where the coroutine will run
    ctx,

    // The coroutine to run. This must be a function taking no arguments
    // and returning an asio::awaitable<T>
    [&conn, argv] { return coro_main(conn, argv[3], argv[1], argv[2]); },

    // Callback to run when the coroutine completes.
    // If any exception is thrown in the coroutine body, propagate it to terminate the program.
    [](std::exception_ptr ptr) {
        if (ptr)
        {
            std::rethrow_exception(ptr);
        }
    }
);

注意这只会调度协程. 要真正运行它, 需要调用 io_context::run. 这会阻塞调用线程, 直到所有调度的协程和 I/O 操作完成:

// Calling run will actually execute the coroutine until completion
ctx.run();
