any_connection::async_prepare_statement (2 个重载中的第 1 个)

在服务器端预处理语句.

概要 
template<
    class CompletionToken = with_diagnostics_t<asio::deferred_t>>
auto
async_prepare_statement(
    string_view stmt,
    CompletionToken&& token = {});
说明

stmt 应使用连接的字符集编码.

返回的语句具有 valid() == true.

对象生命周期

如果 CompletionToken 是延迟完成标记 (例如 use_awaitable), 则 stmt 所指向的字符串必须由调用者保持存活, 直到操作被发起.

处理器签名

该操作的处理器签名是 void(boost::mysql::error_code, boost::mysql::statement).

Executor

中间完成处理器以及最终处理器都使用 token 的关联执行器执行, 若该标记没有关联执行器则使用 this->get_executor().

如果最终处理器有关联的立即执行器且操作立即完成, 最终处理器会被派发给它. 否则, 最终处理器的调用方式如同通过 asio::post 提交, 且绝不会在该函数内被内联调用.
