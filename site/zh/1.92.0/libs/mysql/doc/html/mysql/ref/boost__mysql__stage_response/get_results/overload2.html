stage_response::get_results (2 个重载中的第 2 个)

获取所包含的结果 (不带检查的访问器).

概要 
results&&
get_results() && noexcept;
说明

若 *this 包含一个 results 对象, 则获取其引用. 否则, 行为未定义.

前置条件

this->has_results() == true

异常安全性

不抛出异常保证.

对象生命周期

只要 *this 仍然存活且未被赋值, 返回的引用即保持有效.
