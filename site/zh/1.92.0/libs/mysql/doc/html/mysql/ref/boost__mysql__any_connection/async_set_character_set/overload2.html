any_connection::async_set_character_set (2 个重载中的第 2 个)

按照 SET NAMES 的方式设置连接的字符集.

概要 
template<
    class CompletionToken = with_diagnostics_t<asio::deferred_t>>
auto
async_set_character_set(
    const character_set& charset,
    diagnostics& diag,
    CompletionToken&& token = {});
说明

通过运行一条 SET NAMES SQL 语句设置连接的字符集, 使用传入的 character_set::name 作为要设置的字符集名.

该函数还会更新 current_character_set 返回的值, 因此请优先使用该函数而非原始 SQL 语句.

如果服务器无法将字符集设置为请求的值 (例如服务器不支持请求的字符集), 该函数将失败, 这与 connect 在传入不支持的排序规则时的行为不同. 这是 MySQL 服务器的限制.

需要先建立连接, 该函数才能成功, 因为它涉及与服务器的通信.

对象生命周期

charset 会按需复制, 无需保持存活.

处理器签名

该操作的处理器签名是 void(boost::mysql::error_code).

Executor

中间完成处理器以及最终处理器都使用 token 的关联执行器执行, 若该标记没有关联执行器则使用 this->get_executor().

如果最终处理器有关联的立即执行器且操作立即完成, 最终处理器会被派发给它. 否则, 最终处理器的调用方式如同通过 asio::post 提交, 且绝不会在该函数内被内联调用.
