field::get_double (2 个重载中的第 2 个)

获取底层 double 值的引用 (不带检查的访问).

概要 
double&
get_double() noexcept;
前置条件

this->is_double() == true (若违反, 将导致未定义行为).

异常安全性

不抛出异常保证.

对象生命周期

只要 *this 仍然存活, 且未对 *this 调用任何会使引用失效的函数, 返回的引用即保持有效.
