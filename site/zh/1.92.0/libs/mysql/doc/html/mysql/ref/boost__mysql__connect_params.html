connect_params

与 any_connection 连接函数一起使用的参数.

概要

定义于头文件 <boost/mysql/connect_params.hpp> 

struct connect_params;
数据成员

名称

说明

connection_collation

用于连接的排序规则 ID.

database

要使用的数据库名, 空字符串表示不选择数据库 (默认行为).

multi_queries

是否启用对分号分隔文本查询执行的支持.

password

该用户名的密码, 可以为空.

server_address

决定如何建立与 MySQL 服务器的物理连接.

server_default_charset

服务器用作默认值的字符集.

ssl

控制是否使用 TLS.

username

用于认证的用户名.
说明

要传给 any_connection::connect 和 any_connection::async_connect. 包含服务器地址和 MySQL 握手参数. 这是一个持有所有权的类型.

便捷头文件 <boost/mysql.hpp>
