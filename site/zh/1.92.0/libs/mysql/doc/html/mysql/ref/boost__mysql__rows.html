说明

建模为一个拥有所有权、类矩阵的容器. 对 rows 对象进行索引访问 (使用迭代器、rows::at 或 rows::operator[]) 会返回一个 row_view 对象, 表示单行. 集合中的所有行大小相同 (由 num_columns 给出).

rows 对象拥有一块内存, 用于存储其元素. 在元素访问时获得的 rows_view 对象指向 rows 的内部存储. 这些视图 (以及由前者获得的任何 row_view 和 field_view) 行为类似于引用, 只要指向 rows 对象的指针、迭代器和引用保持有效, 它们即保持有效.

虽然拥有所有权, rows 是只读的. 它针对内存复用做了优化.
