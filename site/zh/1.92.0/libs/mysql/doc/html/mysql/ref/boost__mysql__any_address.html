说明

一种类似 variant 的类型, 可表示 MySQL 服务器的网络地址, 与使用的传输类型无关. 它可以包含主机和端口 (用于通过 TCP 连接) 或 UNIX 路径 (用于通过 UNIX 域套接字连接).

该类将来可能会扩展以支持 Windows 命名管道.

该类型具有值语义: 它持有所有权且是正则的 (regular).
