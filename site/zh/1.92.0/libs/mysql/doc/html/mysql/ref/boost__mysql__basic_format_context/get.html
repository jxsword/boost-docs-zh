basic_format_context::get

检索格式化操作的结果.

概要 
system::result< OutputString >
get() &&;
说明

在运行相关的格式化操作 (使用 append_raw、append_value 或 format_sql_to) 之后, 调用该函数来获取操作的总体结果.

如果 error_state 是非空错误码, 则作为错误返回它. 否则, 返回输出字符串, 并将其移动构造到 system::result 对象中.

该函数是仅可移动的: 调用后, *this 将处于有效但未指定的状态.

异常安全性

基本保证: 移动构造 OutputString 抛出的异常会被传播.
