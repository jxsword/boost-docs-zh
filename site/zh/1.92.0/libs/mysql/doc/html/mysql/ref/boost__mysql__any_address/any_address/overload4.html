any_address::any_address (5 个重载中的第 4 个)

构造包含主机和端口的地址.

概要 
any_address(
    host_and_port value) noexcept;
说明

得到的地址包含 this->type() == address_type::host_and_port、this->hostname() == value.hostname() 和 this->port() == value.port().

对象生命周期

*this 和 value 将拥有各自独立的生命周期 (正则值语义).

异常安全性

不抛出异常保证.
