get

检索底层字符串视图.
说明

当字符串函数实参除极少数情况外必须始终在编译期已知时, 会使用该类型. 例如 format_sql 格式串.

对象生命周期

该类型内部持有一个 string_view, 并遵循与 string_view 相同的生命周期规则. 我们建议仅将该类型用作函数实参, 以提供编译期检查.
