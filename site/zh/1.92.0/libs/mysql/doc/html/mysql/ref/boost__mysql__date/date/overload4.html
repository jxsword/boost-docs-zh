date::date (4 个重载中的第 4 个)

由本地时间点构造日期.

概要 
explicit constexpr
date(
    std::chrono::local_days tp);
说明

等价于构造一个 date, 所用的 time_point 满足其 time_since_epoch() 与 tp 相同.

需要 C++20 日历类型.

异常安全性

强保证. 输入无效时抛出异常.

异常

类型

抛出时机

std::out_of_range

若生成的 date 超出 [min_date, max_date] 范围.
