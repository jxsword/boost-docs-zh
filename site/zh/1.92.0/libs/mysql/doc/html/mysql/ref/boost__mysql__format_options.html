format_options

在客户端侧格式化 SQL 查询所需的设置.

概要

定义于头文件 <boost/mysql/character_set.hpp> 

struct format_options;
数据成员

名称

说明

backslash_escapes

反斜杠是否表示转义序列.

charset

连接的当前字符集.
说明

获取此类型值的推荐方式是使用 any_connection::format_opts.

便捷头文件 <boost/mysql.hpp>
