resultset::operator= (3 个重载中的第 3 个)

将 *this 的内容替换为一个 resultset_view.

概要 
resultset&
operator=(
    resultset_view v);
异常安全性

基本保证. 内部分配可能抛出异常.

对象生命周期

*this 的生存期将独立于 v 的生存期 (v 的内容会被复制到 *this 中). 从 *this 获得的视图将失效.

复杂度

对 v 和 *this 而言, 与行数和元数据大小成线性关系.
