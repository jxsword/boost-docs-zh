说明

虽然拥有所有权, row 是只读的. 它针对内存复用做了优化. 若需要变更字段, 请改用 std::vector<field> (见 row_view::as_vector 和 row::as_vector).

对象生命周期

row 对象拥有一块内存, 用于存储其元素. 在访问元素时 (使用迭代器、row::at 或 row::operator[]), 返回指向 field_view 内部存储的 row. 这些视图的行为类似于引用, 只要指向 row 的指针、迭代器和引用保持有效, 它们即保持有效.
