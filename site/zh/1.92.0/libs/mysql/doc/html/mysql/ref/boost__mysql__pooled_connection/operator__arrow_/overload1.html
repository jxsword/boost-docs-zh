pooled_connection::operator-> (2 个重载中的第 1 个)

获取此对象拥有的连接.

概要 
any_connection*
operator->() noexcept;
前置条件

该对象应当拥有一个连接 (this->valid() == true).

对象生命周期

只要 *this 或从 *this 移动构造或移动赋值而来的对象仍然存活, 返回的引用即保持有效.

异常安全性

不抛出异常保证.
