character_set

表示一个 MySQL 字符集.

概要

定义于头文件 <boost/mysql/character_set.hpp> 

struct character_set;
数据成员

名称

说明

name

字符集名称, 以 NULL 结尾的字符串.

next_char

获取字符串第一个字符的大小.
说明

默认情况下, 除非有充分理由, 否则应始终使用 utf8mb4_charset. 该结构允许你为本库扩展开箱即用不支持的字符集.

便捷头文件 <boost/mysql.hpp>
