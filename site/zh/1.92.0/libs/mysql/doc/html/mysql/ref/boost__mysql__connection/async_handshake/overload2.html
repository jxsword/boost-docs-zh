connection::async_handshake (2 个重载中的第 2 个)

执行 MySQL 层的握手.

概要 
template<
    class CompletionToken>
auto
async_handshake(
    const handshake_params& params,
    diagnostics& diag,
    CompletionToken&& token);
说明

不连接底层流. 如果 Stream 模板参数满足 SocketConnection 要求, 请使用 connection::connect 而不是该函数.

如果使用支持 SSL 的流, SSL 握手将由该函数执行.

对象生命周期

params 所指向的字符串必须由调用者保持存活, 直到操作完成, 因为库不会制作副本.

处理器签名

该操作的处理器签名是 void(boost::mysql::error_code).

Executor

中间完成处理器以及最终处理器都使用 token 的关联执行器执行, 若该标记没有关联执行器则使用 this->get_executor().

如果最终处理器有关联的立即执行器且操作立即完成, 最终处理器会被派发给它. 否则, 最终处理器的调用方式如同通过 asio::post 提交, 且绝不会在该函数内被内联调用.
