connection_pool::valid

返回对象是否处于被移动后的状态 (moved-from).

概要 
bool
valid() const noexcept;
说明

该函数总是返回 true, 例外是被移动后的池. 被移动后的对象不代表有效的池. 它们只能被赋值或销毁.

异常安全性

不抛出异常保证.

线程安全

读取内部状态句柄. 不访问池状态. 可以与其他读取状态句柄的任何函数并发调用, 例如 async_run 或 async_get_connection. 不能与修改句柄的函数 (如赋值) 并发调用, 即使 pool_params::thread_safe 设为 true 也是如此.
