any_connection::connection_id

检索与当前会话关联的连接 ID.

概要 
boost::optional< std::uint32_t >
connection_id() const noexcept;
说明

如果已建立会话, 返回其关联的连接 ID. 如果尚未建立会话 (即尚未调用 async_connect) 或会话已终止 (即已调用 async_close), 则返回空的 optional.

连接 ID 是一个 4 字节的值, 在给定时刻唯一标识一个客户端会话. 它可以与 KILL SQL 语句一起使用来取消查询和终止连接.

服务器在握手过程中会发送分配给当前会话的连接 ID. 该值会被存储并通过该函数提供. 同样的 ID 也可以通过调用 CONNECTION_ID() SQL 函数获得. 然而, 该函数更快也更可靠, 因为它不需要与服务器通信.

该函数等价于 C 连接器中的 mysql_thread_id 函数. 与官方文档所说的不同, 该函数在 64 位系统上工作正常 (见 此变更日志).

在异步操作未完成期间调用该函数是安全的, 但 async_connect 和 async_close 除外.

异常安全性

不抛出异常保证.
