connection::execute (2 个重载中的第 1 个)

执行文本查询或预处理语句.

概要 
template<
    class ExecutionRequest,
    class ResultsType>
void
execute(
    ExecutionRequest&& req,
    ResultsType& result,
    error_code& err,
    diagnostics& diag);
说明

将 req 发送到服务器执行, 并将响应读入 result. result 可以是 results 或 static_results 对象. req 应当是可转换为 string_view 的、包含合法 SQL 的类型, 或通过调用 statement::bind 得到的已绑定预处理语句. 如果是字符串, 必须使用连接的字符集编码. 提供给 statement::bind 的任何字符串参数也应使用连接的字符集编码.

此操作成功完成后, result.has_value() == true.

result 中的元数据将按 this->meta_mode() 填充.
