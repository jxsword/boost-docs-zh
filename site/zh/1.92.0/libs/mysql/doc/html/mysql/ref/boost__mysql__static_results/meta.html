static_results::meta

返回查询中各列的元数据.

概要 
template<
    std::size_t I = 0>
metadata_collection_view
meta() const noexcept;
说明

返回的集合将包含与 SQL 查询取回的列数相同的 metadata 对象, 且顺序一致. 注意这可能与 StaticRow 类型中的顺序不同, 因为列可以按名称映射或被丢弃. 此函数返回从数据库获取的表示.

模板参数

类型

说明

I

结果集索引. 对于返回多个结果集的操作, 可显式指定此参数以获取第 i 个结果集的元数据. 若不指定, 则返回第一个结果集的元数据.
前置条件

this->has_value() == true

异常安全性

不抛出异常保证.

对象生命周期

该函数返回一个具有引用语义的视图对象. 返回的视图指向 *this 所拥有的内存, 只要 *this 或从 *this 移动构造出的对象仍然存活, 该视图就保持有效.

复杂度

常量.
