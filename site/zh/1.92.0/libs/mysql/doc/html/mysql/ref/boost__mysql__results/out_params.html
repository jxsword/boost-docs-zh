results::out_params

返回存储过程调用的输出参数.

概要 
row_view
out_params() const noexcept;
说明

适用于使用预处理语句执行、并将占位符绑定到 CALL 或 OUT 参数的 INOUT 操作. 返回一行, 其中每个绑定的输出参数对应一个字段.

若此操作没有输出参数 (例如它不是 CALL), 则返回空行.

前置条件

this->has_value() == true

异常安全性

不抛出异常保证.

对象生命周期

只要 *this 仍然存活, 返回的引用以及由其获得的其他引用即保持有效. 移动操作会使引用失效.

复杂度

与 this->size() 成线性关系.
