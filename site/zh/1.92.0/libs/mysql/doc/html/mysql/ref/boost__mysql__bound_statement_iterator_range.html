bound_statement_iterator_range

以迭代器范围表示的、带有已绑定参数的语句.

概要

定义于头文件 <boost/mysql/statement.hpp> 

template<
    class FieldViewFwdIterator>
class bound_statement_iterator_range;
说明

该类满足 ExecutionRequest. 可以将此类的实例传给 connection::execute、connection::start_execution 或其异步对应函数.

便捷头文件 <boost/mysql.hpp>
