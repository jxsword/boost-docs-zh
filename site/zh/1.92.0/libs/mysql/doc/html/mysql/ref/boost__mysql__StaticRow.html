StaticRow 概念

StaticRow 是一种可用于在静态接口中对行建模的 C++ 类型 (即可以作为模板参数传给 static_results 和 static_execution_state).

形式上, 类型 T 是 StaticRow 的条件是以下任一为真:

  • 它是带有 Boost.Describe 数据注解的非 const struct (即拥有 boost::describe::has_describe_members<T>::value == true), 并且所有被描述的成员都满足 ReadableField 这个仅用于展示的概念.
  • 它是非 const 的 std::tuple 实例化, 且其所有类型都满足 ReadableField 这个仅用于展示的概念.
  • 它是 pfr_by_name 或 pfr_by_position 标记类型使用类型 Underlying 的实例化, 且
    • 可使用 Boost.PFR 反射. 对于 C++17 及更高版本, 这意味着满足 SimpleAggregate. 对于 C++14, 要求更为严格 - 更多信息见 Boost.PFR 文档.
    • 是非 const 的对象类型 (即不是 union 或内置类型).
    • 其所有字段 (由 pfr::structure_to_tuple 给出) 都满足 ReadableField.

ReadableField 是可用于对数据库行中单个值建模的 C++ 类型. 类型 F 是 ReadableField 的条件是: 它属于 此表中列出的任意类型. 可读字段类型的集合目前是固定的, 用户无法扩展. 如果你有这方面的需求, 请在仓库中 提交 issue 并说明你的用例.

字段和行的允许类型集合在未来的版本中都可能扩展.
