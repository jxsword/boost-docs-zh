pipeline_request::add_execute (2 个重载中的第 1 个)

添加一个执行文本查询的阶段.

概要 
pipeline_request&
add_execute(
    string_view query);
说明

创建一个将 query 作为 SQL 查询运行的阶段, 类似于 any_connection::execute.

异常安全性

强保证. 内存分配可能抛出异常.

对象生命周期

query 会被复制到请求中, 在此函数返回后无需保持其存活.
