date::as_time_point

将 *this 转换为 time_point (带检查的访问).

概要 
constexpr date::time_point
as_time_point() const;
说明

若编译器支持, 建议优先使用 as_local_time_point, 因为它提供更准确的语义.

异常安全性

强保证.

异常

类型

抛出时机

std::invalid_argument

若 !this->valid().
