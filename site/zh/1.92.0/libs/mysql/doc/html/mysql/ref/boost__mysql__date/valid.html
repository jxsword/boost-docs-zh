date::valid

满足以下条件时返回 true: *this 表示一个有效的 time_point.

概要 
constexpr bool
valid() const noexcept;
说明

若任一分量超出范围, 导致该日期并不表示一个实际的 time_point (例如 date(2020, 2, 30)) 或该日期不在 [min_date, max_date] 有效范围内, 则返回 false. 否则返回 true.

异常安全性

不抛出异常保证.
