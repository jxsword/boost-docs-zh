any_connection::read_some_rows (4 个重载中的第 4 个)

读取一批行.

概要 
rows_view
read_some_rows(
    execution_state& st);
说明

将读取的行数是不确定的. 如果 st 表示的操作还有行待读取, 至少会读取一行. 如果没有更多行, 或 st.should_read_rows() == false, 则返回空的 rows_view.

将读取的行数取决于连接的缓冲区大小. 缓冲区越大, 批次越大 (有上限). 可以在构造函数中设置初始缓冲区大小. 如有需要, 缓冲区可能会被其他读取操作扩大.

返回的视图指向 *this 持有的内存. 在 *this 执行下一次网络操作或被销毁之前一直有效.
