静态成员

名称

说明

default_collation

连接要使用的默认排序规则 (在 MySQL 和 MariaDB 上均为 utf8mb4_general_ci).
对象生命周期

此对象存储对字符串 (如用户名和密码) 的引用, 不复制这些值. 用户需负责让它们在需要期间保持存活.

旧式

该类与遗留的 connection 类配合使用. 新代码应改用 any_connection. 与 handshake_params 等价的是 connect_params.
