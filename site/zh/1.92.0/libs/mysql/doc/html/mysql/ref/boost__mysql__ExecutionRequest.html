ExecutionRequest 概念

执行请求表示要由服务器执行的一条 SQL 语句及其所需的参数. 它可以表示纯文本查询、带参数的客户端格式化查询, 或带参数的预处理语句句柄.

形式上, 类型 T 若满足以下任一条件, 则为 ExecutionRequest.

  • 可转换为 string_view. 此时, 执行请求包含一条要由服务器运行的文本查询.
  • bound_statement_tuple 类的实例化, 或对它的 (可能带 cv 限定符的) 引用.
  • bound_statement_iterator_range 类的实例化, 或对它的 (可能带 cv 限定符的) 引用.
  • with_params_t 类的实例化, 或对它的 (可能带 cv 限定符的) 引用.

该定义在未来版本中可能会扩展, 但上述类型仍将满足 ExecutionRequest.
