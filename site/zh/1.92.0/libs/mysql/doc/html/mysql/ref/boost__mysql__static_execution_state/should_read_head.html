static_execution_state::should_read_head

返回下一个操作是否应为读取结果集头部.

概要 
bool
should_read_head() const noexcept;
说明

调用 connection::read_resultset_head 或其异步版本向前推进. 在此状态下, 前一个结果集的元数据和 OK 数据均可用.

异常安全性

不抛出异常保证.
