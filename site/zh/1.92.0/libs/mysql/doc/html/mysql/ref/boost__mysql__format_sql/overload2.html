format_sql (2 个重载中的第 2 个)

在客户端侧组合 SQL 查询.

概要

定义于头文件 <boost/mysql/format_sql.hpp> 

std::string
format_sql(
    format_options opts,
    constant_string_view format_str,
    std::initializer_list< format_arg > args);
说明

将 format_str 按格式字符串解析, 将替换字段 (如 {}, {1} 或 {name}) 替换为 args 中提取的已格式化实参. opts 用于解析该字符串并格式化字符串实参.

格式化的执行方式, 等同于在本函数创建的上下文上调用 format_context::append_raw 和 format_context::append_value.

异常安全性

强保证. 内存分配可能抛出异常. boost::system::system_error — 当在格式化过程中发现错误时抛出. 更多信息见下文.

误差
  • client_errc::invalid_encoding — 当 args 包含无法用当前字符集解码的字节序列的字符串时.
  • client_errc::unformattable_value — 当 args 包含 NaN 或无穷大的浮点值时.
  • client_errc::format_string_invalid_specifier — 当替换字段包含被格式化类型不支持的说明符时.
  • 由用户定义的 formatter 特化产生的任何其他错误.
  • client_errc::format_string_invalid_syntax — 当 format_str 无法按格式字符串解析时.
  • client_errc::format_string_invalid_encoding — 当 format_str 包含无法用当前字符集解码的字节序列时.
  • client_errc::format_string_manual_auto_mix — 当 format_str 同时包含自动索引 ({}) 和手动索引 ({1}) 的替换字段时.
  • client_errc::format_arg_not_found — 当 format_str 所引用的实参不在 args 中时 (实参不足, 或未找到命名实参).

此重载允许使用命名实参.
