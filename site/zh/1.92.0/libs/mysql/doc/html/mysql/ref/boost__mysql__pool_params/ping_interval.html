pool_params::ping_interval

健康检查间隔.

概要 
std::chrono::steady_clock::duration ping_interval {std::chrono::seconds(10)};
说明

若某个连接处于空闲状态且超过 ping_interval 未被交给用户, 将执行一次健康检查 (使用 any_connection::async_ping). 此后会以 ping_interval 的周期发送 ping, 直到连接被交给用户或某次 ping 失败.

健康检查有两个用途:

  • 它们防止连接在无活动的时段内被关闭.
  • 它们检测网络错误并触发重连. 若没有健康检查, 交给你的可能是一些已失效但尚未被诊断出来的连接.

将此间隔设为零可禁用 ping.

此值不得为负. 它应小于服务器的空闲超时 (由 wait_timeout 会话变量决定). 否则, 服务器可能在连接池未察觉的情况下关闭连接.
