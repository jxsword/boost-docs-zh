Boost 1.90 发布

  • 修复了 Clang 19 及更高版本中因 P0522R0 支持导致的编译错误.

Boost 1.87 发布

  • 新增 concurrent_factory, 这是一个基于 Boost.Unordered 并发容器的工厂, 在多线程场景下性能极佳.
  • 已为那些操作添加标记 noexcept — 即先前文档中说明为不抛出异常的 boost::flyweight 操作 (issue #15).

Boost 1.83 发布

  • 为 boost::flyweight 增加了智能指针语法 (operator* 和 operator-> 解引用到底层值).
  • 修复了 simple_locking 所用互斥量不是递归的一种情况 (issue #12).

Boost 1.82 发布

  • 维护性工作.

Boost 1.81 发布

  • 维护性工作.

Boost 1.74 发布

  • 维护性工作.

Boost 1.73 发布

  • 维护性工作.

Boost 1.71 发布

  • 维护性工作.

Boost 1.69 发布

  • 修复了 GCC 中一些与 Boost.MPL 占位符表达式处理相关的问题.
  • 维护性修复.

Boost 1.60 发布

  • 维护性修复.

Boost 1.58 发布

  • 增加了哈希支持, 同时涵盖 std::hash 和 boost::hash. 可以选择禁用它, 以避免与用户已定义了此类支持的遗留代码冲突.
  • 维护性修复.

Boost 1.57 发布

  • 经由 Boost Serialization 增加了序列化支持.
  • flyweight 的默认构造函数在 Boost 1.56 中被改为 explicit, 这在一些初始化场景中引入了回归. 先前的非 explicit 默认构造函数已被恢复 (ticket #10439).

Boost 1.56 发布

  • 在支持变参模板的编译器中, boost::flyweight<T> 现在为 T::T 提供完美转发构造函数 (此前使用的是模拟实现).
  • flyweight 现在复制其底层类型的初始化列表构造函数和赋值运算符.
  • 修复了模块间静态初始化问题 (ticket #9553).
  • 维护性修复.

Boost 1.55 发布

  • 维护性修复.

Boost 1.45 发布

  • 修复了 intermodule_holder 在 Win32 平台上与 ticket #4606 所述 Boost.Interprocess 问题相关的挂起问题.
  • 移除了与经由 std::exit 终止程序不兼容的内部断言.

Boost 1.44 发布

  • 修复了其中一个示例中 Boost.Variant 的错误用法.

Boost 1.40 发布

  • 维护性修复.

Boost 1.39 发布

  • refcounted 组件由于实现不正确而非线程安全, 在重度使用条件下可能死锁. 该问题已得到纠正.

Boost 1.38 发布

  • Boost.Flyweight 首次发布.
