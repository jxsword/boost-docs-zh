Boost Flyweight 库


教程

享元是小型句柄类, 提供对共享公共数据的常量访问, 从而允许在合理的内存限制内管理大量实体. Boost.Flyweight 通过提供类模板 flyweight<T> 使这一常见编程惯用法易于使用, 它可作为 const T 的直接替代品.

学会使用 Boost.Flyweight 只需几分钟. 不过, 当出现特殊需求时, 库提供了广泛的定制接口, 允许用户控制和扩展以下方面:

  • 类型标签 (tagging), 用于分离使用相同基本享元类型的不同领域.
  • 所谓享元工厂的规约与参数化.
  • 对工厂实例化过程的控制.
  • 内部同步机制的规约.
  • 享元跟踪, 允许在存储值不再被任何享元对象引用时将其释放.
