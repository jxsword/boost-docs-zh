预备概念

跟踪策略辅助器提供对工厂部分功能的访问, 以便在实现关联的Tracking Policy时使用. 在下表中, TrackingHelper 是与 工厂 类型 Factory (元素类型为 Entry) 相关联的跟踪策略辅助器, h 是 Factory::handle_type 的一个值, 关联到 Factory f; check 是 Predicate 类型 Checker 的一个值, 实参类型为 Factory::handle_type.

跟踪策略辅助器要求.
表达式 返回类型 断言/注释
前/后置条件
TrackingHelper::entry(h); const Entry& 返回 f.entry(h).
TrackingHelper::erase(h,check); void 若 check(h), 则调用 f.erase(h).

TrackingHelper::erase 的执行 (包括对 check(h) 的调用) 以同步方式进行, 以防止任何其他执行线程同时访问工厂的插入或删除设施.

跟踪策略

跟踪策略定义flyweight实例化在关联到给定值的所有享元对象都被销毁时所要遵循的策略. 跟踪策略贡献了定义 flyweight 内部工厂所需的一些类型信息.

若满足以下条件, 则类型 Tracking 是一个跟踪策略:

  • 满足以下条件之一:
    1. is_tracking<Tracking>::type 是 boost::mpl::true_,
    2. Tracking 的形式为 tracking<Tracking'>.
  • 表达式 Tracking::entry_type (或当 (b) 适用时的 Tracking'::entry_type) 是一个MPL Lambda Expression, 当以不同类型 (Value,Key) 调用它时 — 其中 Value 是MoveConstructible 且可隐式转换为 const Key& — 它解析为一个MoveConstructible 类型 Entry, 该类型可隐式转换为 const Value& 和 const Key& 两者.
  • 表达式 Tracking::handle_type (或当 (b) 适用时的 Tracking'::handle_type) 是一个MPL Lambda Expression; 该表达式当以类型 (InternalHandle,TrackingHelper) 调用时 — 其中 InternalHandle 是CopyConstructible 且 CopyAssignable, 并为拷贝和赋值提供无异常保证 — 解析为一个CopyConstructible 且 CopyAssignable 类型 Handle, 后者同样为拷贝和赋值提供无异常保证, 且可从 InternalHandle 构造, 并可隐式转换为它. 在调用 TrackingHelper 时, Tracking::handle_type 是不完整类型.
Tracking::handle_type 由一个辅助器进行参数化, 该辅助器提供对与跟踪策略相关联的工厂的部分功能的访问. 该工厂关联的条目和句柄类型分别是上文定义的 Entry 和 Handle.

类模板 is_tracking

除非用户特化, is_tracking<T>::type 为 boost::mpl::true_ (当 T 派生自 tracking_marker 时), 否则为 boost::mpl::false_.

类模板 tracking

tracking<T> 是一种语法构造, 用于表明 T 是跟踪策略, 而不借助 is_tracking 类模板所提供的机制.
