依赖

要使用 Boost.Flyweight 的序列化功能, 必须链接相应的 Boost.Serialization 库模块. 除此之外, Boost.Flyweight 是一个仅头文件库, 不需要额外的目标模块. 默认的 simple_locking 锁定策略会引入对 Pthreads 库的依赖, 适用于 Boost.Config 宏 BOOST_HAS_PTHREADS 被设置的 POSIX 兼容环境.

头文件 "boost/flyweight.hpp" 概要 

#include <boost/flyweight/flyweight.hpp>
#include <boost/flyweight/hashed_factory.hpp>
#include <boost/flyweight/refcounted.hpp>
#include <boost/flyweight/simple_locking.hpp>
#include <boost/flyweight/static_holder.hpp>

这个便利头文件包含主类模板 flyweight 以及 flyweight 所使用的默认组件.
