标签

标签是形如 tag<T> 的类型, 其中 T 为任意类型. 在 Boost.Flyweight 的语境中, 标签是一种语法层面的构件, 用于区分类模板 flyweight 的实例化 — 否则这些实例化将是完全相同的. 用一个给定上下文局部的标签类型为 flyweight 实例化打标签, 可以确保该实例化的全局资源 (例如关联的工厂类) 不会被程序的其他部分无意地共享.

头文件 "boost/flyweight/tag.hpp" 概要

namespace boost{

namespace flyweights{

template<typename T>
struct tag;

} // namespace boost::flyweights

} // namespace boost

类模板 tag

对任何类型 T, tag<T> 都是 标签, 适用于 flyweight 实例化.
