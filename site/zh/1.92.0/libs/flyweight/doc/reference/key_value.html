键提取器

设 Key 为具有某种隐式等价关系的类型, Value 为可从 Key 构造的类型. 一个 DefaultConstructible 类型 KeyFromValue 若满足以下条件, 则称其为从 Value 到 Key 的键提取器:

  1. kfv(cv) 已定义且类型为 const Key&,
  2. kfv(cv) 等价于 kfv(Value(cv)),
  3. kfv(Value(k)) 等价于 k,
对每个 kfv (类型为 const KeyFromValue)、cv (类型为 const Value) 和 k (类型为 Key) 而言.

头文件 "boost/flyweight/key_value_fwd.hpp" 概要

namespace boost{

namespace flyweights{

struct no_key_from_value;

template<
  typename Key,typename Value,
  typename KeyFromValue=no_key_from_value
>
struct key_value;

} // namespace boost::flyweights

} // namespace boost

头文件 "boost/flyweight/key_value.hpp" 概要

类模板 key_value

在 flyweight 的形如 flyweight<T,...> 的实例化中, 相关联的 key_type 和 value_type 都等于 T. 形如 flyweight<key_value<Key,Value[,KeyFromValue]>,...> 的实例化允许分别指定这些类型. Key 和 Value 必须是不同的类型. 如果提供, KeyFromValue 必须是 Key Extractor, 从 Value 到 Key.
