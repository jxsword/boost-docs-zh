函数模板 indexed

boost::histogram::indexed — 在直方图单元格的矩形区域上生成带索引的 forward iterators 范围.

概要

// In header: <boost/histogram/indexed.hpp>


template<typename Histogram, typename Iterable> 
  auto indexed(Histogram && hist, Iterable && range);

说明

在基于范围的 for 循环中使用. 示例:

auto hist = make_histogram(axis::integer<>(0, 4),axis::integer<>(2, 6));axis::index_type range[2] = {{1, 3}, {0, 2}};
for (auto&& x : indexed(hist, range)) { ... }

这会跳过第一个轴的首个和末个索引, 以及第二个轴的最后两个索引.

参数:

hist

直方图的引用.

range

由元素组成的可迭代对象, 每个元素包含两个 axis::index_type 值, 标记每个轴的起始和结束索引. 可迭代对象的长度必须等于直方图的秩. 起始索引必须小于结束索引. 超出实际范围的索引范围会被缩减到实际范围 (包括下溢和溢出索引).
