结构体模板 is_inclusive

boost::histogram::axis::traits::is_inclusive — 用于检测轴是否为包含式的元函数.

概要

// In header: <boost/histogram/axis/traits.hpp>

template<typename Axis> 
struct is_inclusive {
};

说明

Doxygen 对此的呈现不佳. 这是一个元函数 (模板别名), 它接受一个轴类型并表示编译期布尔值, 根据轴是否为包含式而为 true 或 false.

包含式轴对每个可能的输入值都有区间. 换言之, 所有可能的输入值最终都落在有效单元格中, 无需跟踪需要丢弃的输入元组. 完全由包含式轴构成的直方图可以更高效地填充, 速度最多可快 2 倍.

带有下溢和溢出区间的轴总是包含式的, 但轴在其他条件下也可能是包含式的. 该元函数检查方法 constexpr static bool inclusive() 并使用其结果. 若该方法不存在, 则使用get_options<Axis> 并检查下溢和溢出位是否存在.

模板参数

  1. typename Axis

    轴类型
