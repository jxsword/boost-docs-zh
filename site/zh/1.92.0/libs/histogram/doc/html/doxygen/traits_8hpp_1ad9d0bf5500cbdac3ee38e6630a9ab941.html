函数模板 width

boost::histogram::axis::traits::width — 返回轴索引处的区间宽度.

概要

// In header: <boost/histogram/axis/traits.hpp>


template<typename Axis> 
  decltype(auto) width(const Axis & axis, index_type index);

说明

若轴没有 value 方法, 抛出 std::runtime_error. 若该方法存在且接受浮点索引, 返回axis.value(index + 1) - axis.value(index) 的结果. 若该方法存在但只接受整数索引, 返回 0.

参数:

axis

任意轴实例

index

区间索引
