类模板 boolean

boost::histogram::axis::boolean — 用于布尔数据的离散轴.

概要

// In header: <boost/histogram/axis/boolean.hpp>

template<typename MetaData> 
class boolean : public boost::histogram::axis::iterator_mixin< boolean< MetaData > >,
                public metadata_base_t< MetaData >
{
public:

  // public member functions
  explicit boolean(metadata_type = {});
  index_type index(value_type) const noexcept;
  value_type value(index_type) const noexcept;
  value_type bin(index_type) const noexcept;
  index_type size() const noexcept;
  template<typename M> bool operator==(const boolean< M > &) const noexcept;
  template<typename M> bool operator!=(const boolean< M > &) const noexcept;
  template<typename Archive> void serialize(Archive &, unsigned);

  // public static functions
  static bool inclusive() noexcept;
  static unsigned options() noexcept;
};

说明

分箱操作是零开销的直通操作, 使其成为可能的最快轴. 除可选的元数据状态外, 该轴没有内部状态. 该轴没有下溢和溢出区间. 它不能增长, 也不能被归约.

模板参数

  1. typename MetaData

    用于存储元数据的类型.

boolean 公有成员函数

  1. explicit boolean(metadata_type meta = {});
    构造 boolean 轴.

    若 meta 具有不抛出的移动构造, 则构造函数不抛出异常.

    参数:

    meta

    轴的描述.

    		 
  2. index_type index(value_type x) const noexcept;
    返回值实参对应的索引.
  3. value_type value(index_type i) const noexcept;
    返回索引实参对应的值.
  4. value_type bin(index_type i) const noexcept;
    返回索引实参对应的区间.
  5. index_type size() const noexcept;
    返回区间数量, 不含溢出和下溢区间.
  6. template<typename M> bool operator==(const boolean< M > & o) const noexcept;
  7. template<typename M> bool operator!=(const boolean< M > & o) const noexcept;
  8. template<typename Archive> void serialize(Archive & ar, unsigned);

boolean 公有静态函数

  1. static bool inclusive() noexcept;
    轴是否为包含式 (参见 axis::traits::is_inclusive).
  2. static unsigned options() noexcept;
    返回选项.
