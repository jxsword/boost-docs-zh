结构体模板 is_continuous

boost::histogram::axis::traits::is_continuous — 轴是连续的还是离散的.

概要

// In header: <boost/histogram/axis/traits.hpp>

template<typename Axis> 
struct is_continuous {
};

说明

Doxygen 对此的呈现不佳. 这是一个元函数 (模板别名), 它接受一个轴类型并返回编译期布尔值.

若布尔值为 true, 则轴是连续的 (覆盖连续的值范围). 否则它是离散的 (覆盖离散值).
