函数模板 reduce

boost::histogram::algorithm::reduce — 收缩、切片和/或重新分箱直方图的轴.

概要

// In header: <boost/histogram/algorithm/reduce.hpp>


template<typename Histogram, class... Ts> 
  Histogram reduce(const Histogram & hist, const reduce_command & opt, 
                   const Ts &... opts);

说明

返回归约后的新直方图, 且不改动原直方图.

同一轴的命令 rebin 与shrink 或slice 会自动合并, 这不是错误. 对同一轴传入shrink 与slice 命令或两个rebin 命令会触发 invalid_argument 异常. 归约带有某些不可归约轴的直方图是安全的, 只要沿其他可归约的轴进行. 尝试归约不可归约的轴会触发 invalid_argument 异常.

有一个重载允许传入 reduce_command 的可迭代对象.

参数:

hist

原直方图.

opt

第一个归约命令; 为 shrink、slice、rebin、shrink_and_rebin 或slice_or_rebin 之一.

opts

其余归约命令.
