函数模板 empty

boost::histogram::algorithm::empty — 检查是否所有直方图单元格都为空.

概要

// In header: <boost/histogram/algorithm/empty.hpp>


template<typename A, typename S> 
  auto empty(const histogram< A, S > & h, coverage cov);

说明

使用 coverage 来包含或排除下溢/溢出区间.

此算法具有 O(N) 复杂度, 其中 N 为单元格数量.

若所有单元格都为空则返回 true, 否则返回 false.
