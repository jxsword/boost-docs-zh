说明

Histogram 使用调用运算符插入数据, 类似于 Boost.Accumulators.

请使用工厂函数 (参见 make_histogram.hpp 与make_profile.hpp) 方便地创建直方图, 而不要直接调用构造函数.

请使用 indexed 范围生成器遍历已填充的直方图, 这既方便, 对多维直方图也比手写循环更快.

模板参数

  1. typename Axes

    轴类型的 std::tuple, 或某种轴类型的 std::vector 或 axis::variant

  2. typename Storage

    实现存储器接口的类

  14. template<typename Unary> auto for_each_axis(Unary && unary) const;
    对每个轴应用一元仿函数/函数.
  15. template<typename T0, class... Ts> 
  iterator operator()(const T0 & arg0, const Ts &... args);
    用值、可选权重和/或样本填充直方图.

    返回指向所定位单元格的迭代器.

    实参按顺序传递给轴对象. 若传入的实参类型无法转换为轴所接受的值类型, 或传入的实参数量不对, 将抛出 std::invalid_argument.

    可选权重

    可以使用 weight 辅助函数将可选权重作为第一个或最后一个实参传入. 若存储器元素不支持权重, 则编译失败.

    样本

    若存储器元素接受样本, 除轴实参之外, 还可通过 sample 辅助函数传入样本, 其可作为第一个或最后一个实参. sample 辅助函数可向存储器元素传递一个或多个实参. 若同时使用样本和权重, 它们可以在实参列表的开头或结尾以任意顺序传入.

    接受多个实参的轴

    若直方图包含接受 std::tuple 实参的轴, 则该轴的实参需要以std::tuple 的形式传入, 例如std::make_tuple(1.2, 2.3). 若直方图仅包含此轴而没有其他轴, 实参可以直接传入.

  16. template<class... Ts> iterator operator()(const std::tuple< Ts... > & args);
    用来自 std::tuple 的值、可选权重和/或样本填充直方图.
  17. template<typename Iterable> void fill(const Iterable & args);
    一次填充多个值到直方图.

    该实参必须是一个可迭代对象, 其大小与直方图的秩相匹配. 可迭代对象的元素可以是 1) 一个值, 或 2) 一个遍历连续值序列的可迭代对象, 或 3) 1) 与 2) 的混合形式. 子可迭代对象必须具有相同的长度.

    警告: std::vector<bool> 由于臭名昭著的 vector 对布尔类型的特化, 并不是布尔值上的连续序列. 它不能用作实参, 但任何真正连续的布尔值序列都可以 (例如std::array<bool, N> 或std::valarray<bool>).

    值按顺序传递给相应的直方图轴. 若在传入值可迭代对象的同时传入单个值, 该单个值会被视作一个由该值的多个副本组成的、长度与之匹配的可迭代对象.

    若直方图只有一个轴, 可以直接传入值的可迭代对象.

    参数:

    args

    可迭代对象, 如详细说明中所述.
