函数模板 indexed

boost::histogram::indexed — 在直方图单元格上生成由 forward iterators 组成的带索引范围.

概要

// In header: <boost/histogram/indexed.hpp>


template<typename Histogram> 
  auto indexed(Histogram && hist, coverage cov = coverage::inner);

说明

在基于范围的 for 循环中使用:

for (auto&& x : indexed(hist)) { ... }

这会生成一个优化的循环, 几乎总是比手写遍历直方图单元格的循环更快. 迭代器解引用为 indexed_range::accessor, 它具有查询当前索引和区间的方法, 且行为类似指向单元格值的指针. 返回的迭代器是前向迭代器. 它们可以存入容器, 但不能在直方图生命期结束后使用.

参数:

hist

直方图的引用.

cov

遍历全部区间或仅内部区间 (可选, 默认: 内部).

返回:

indexed_range
