类模板 integer

boost::histogram::axis::integer — 用于以单位步长覆盖整数值区间的轴.

概要

// In header: <boost/histogram/axis/integer.hpp>

template<typename Value, typename MetaData, typename Options> 
class integer : public boost::histogram::axis::iterator_mixin< integer< Value, MetaData, Options > >,
                public metadata_base_t< MetaData >
{
public:

  // public member functions
  integer() = default;
  integer(value_type, value_type, metadata_type = {}, options_type = {});
  integer(const integer &, index_type, index_type, unsigned);
  index_type index(value_type) const noexcept;
  auto update(value_type) noexcept;
  value_type value(local_index_type) const noexcept;
  decltype(auto) bin(index_type) const noexcept;
  index_type size() const noexcept;
  template<typename V, typename M, typename O> 
    bool operator==(const integer< V, M, O > &) const noexcept;
  template<typename V, typename M, typename O> 
    bool operator!=(const integer< V, M, O > &) const noexcept;
  template<typename Archive> void serialize(Archive &, unsigned);

  // public static functions
  static unsigned options() noexcept;
  static bool inclusive() noexcept;
};

说明

分箱是 O(1) 操作. 此轴的分箱甚至比 regular 轴更快.

选项 growth 与circular 互斥. 若轴使用整数且设置了growth 或circular, 则该轴不能设置选项underflow 或overflow.

模板参数

  1. typename Value

    输入值类型. 必须为整数或浮点数.

  2. typename MetaData

    用于存储元数据的类型.

  3. typename Options

    参见 boost::histogram::axis::option.

integer 公有成员函数

  1. integer() = default;
  2. integer(value_type start, value_type stop, metadata_type meta = {}, 
        options_type options = {});
    在半开整数区间 [start, stop) 上构造.

    若 start 不小于 stop, 构造函数抛出 std::invalid_argument.

    实参 meta 和 alloc 按值传递. 若将其中任一移动传入轴中而构造函数抛出异常, 其值会丢失. 若无法保证 bin 描述有效, 请勿移动.

    参数:

    start

    覆盖范围的第一个整数.

    stop

    覆盖范围最后一个整数之后的位置.

    meta

    轴的描述 (可选).

    options

    参见 boost::histogram::axis::option (可选).

    		 
  3. integer(const integer & src, index_type begin, index_type end, unsigned merge);
    由 algorithm::reduce 用于收缩和重新分箱的构造函数.
  4. index_type index(value_type x) const noexcept;
    返回值实参对应的索引.
  5. auto update(value_type x) noexcept;
    返回传入实参对应的索引和移位量 (若轴已增长).
  6. value_type value(local_index_type i) const noexcept;
    返回索引实参对应的值.
  7. decltype(auto) bin(index_type idx) const noexcept;
    返回索引实参对应的区间.
  8. index_type size() const noexcept;
    返回区间数量, 不含溢出和下溢区间.
  9. template<typename V, typename M, typename O> 
  bool operator==(const integer< V, M, O > & o) const noexcept;
  10. template<typename V, typename M, typename O> 
  bool operator!=(const integer< V, M, O > & o) const noexcept;
  11. template<typename Archive> void serialize(Archive & ar, unsigned);

integer 公有静态函数

  1. static unsigned options() noexcept;
    返回选项.
  2. static bool inclusive() noexcept;
    轴是否为包含式 (参见 axis::traits::is_inclusive).
