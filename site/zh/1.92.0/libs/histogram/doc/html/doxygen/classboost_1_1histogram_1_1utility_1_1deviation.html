类 deviation

boost::histogram::utility::deviation — 以偏差为单位表示的区间置信水平.

概要

// In header: <boost/histogram/utility/binomial_proportion_interval.hpp>


class deviation {
public:

  // public member functions
  explicit deviation(double);
  template<typename T> explicit operator T() const noexcept;
  operator confidence_level() const noexcept;
};

说明

区间随偏差值增大而变宽. 标准差对应值 1, 相当于 68.3 % 置信水平. 置信水平与偏差之间的转换基于正态分布上的双侧区间.

deviation 公有成员函数

  1. explicit deviation(double d);
    由标准差单位构造
  2. template<typename T> explicit operator T() const noexcept;
    显式转换为标准差单位
  3. operator confidence_level() const noexcept;
    隐式转换为置信水平
