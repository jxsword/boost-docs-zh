类模板 wilson_interval

boost::histogram::utility::wilson_interval — Wilson 区间.

概要

// In header: <boost/histogram/utility/wilson_interval.hpp>

template<typename ValueType> 
class wilson_interval :
  public boost::histogram::utility::binomial_proportion_interval< ValueType >
{
public:
  // types
  typedef typename wilson_interval::value_type    value_type;   
  typedef typename wilson_interval::interval_type interval_type;

  // public member functions
  explicit wilson_interval(deviation = deviation{1.0}) noexcept;
  interval_type operator()(value_type, value_type) const noexcept;
};

说明

Wilson 得分区间计算简单, 覆盖性良好. 区间自动限制在 0 与 1 之间且永不为空. 该区间是非对称的.

Wilson, E. B. (1927). "Probable inference, the law of succession, and statistical inference". Journal of the American Statistical Association. 22 (158): 209-212. doi:10.1080/01621459.1927.10502953. JSTOR 2276774.

对于比例的随机集合, 覆盖概率接近标称值. 与 Clopper-Pearson 区间不同, Wilson 得分区间不是保守的. 对某些比例取值, 区间覆盖不足, 而对相邻取值则过度覆盖. 这是 Clopper-Pearson 区间所有替代方案的共同性质.

文献中广泛推荐 Wilson 得分区间用于一般用途. 文献综述参见 R. D. Cousins, K. E. Hymes, J. Tucker, Nucl. Instrum. Meth. A 612 (2010) 388-398.

wilson_interval 公有成员函数

  1. explicit wilson_interval(deviation d = deviation{1.0}) noexcept;
    构造 Wilson 区间计算器.

    参数:

    d

    区间的标准差数量. 默认值 1 对应 68 % 置信水平. deviation 与confidence_level 对象都可用于初始化该区间.

    		 
  2. interval_type 
operator()(value_type successes, value_type failures) const noexcept;
    根据给定的成功与失败次数计算区间.

    参数:

    successes

    成功试验的次数.

    failures

    失败试验的次数.
