类模板 polymorphic_bin

boost::histogram::axis::polymorphic_bin — 保存 axis::variant 的区间数据.

概要

// In header: <boost/histogram/axis/polymorphic_bin.hpp>

template<typename RealType> 
class polymorphic_bin {
public:

  // public member functions
  polymorphic_bin(value_type, value_type);
  operator const value_type &() const noexcept;
  value_type lower() const noexcept;
  value_type upper() const noexcept;
  value_type center() const noexcept;
  value_type width() const noexcept;
  template<typename BinType> bool operator==(const BinType &) const noexcept;
  template<typename BinType> bool operator!=(const BinType &) const noexcept;
  bool is_discrete() const noexcept;
};

说明

该接口是 axis::interval_view 类的超集. 此外, 该对象可隐式转换为值类型, 等效于调用lower(). 对于离散轴, lower() == upper(), 且width() 返回零.

出于两个原因, 它并不像 axis::interval_view 那样是一个视图.

  • 依次调用 lower() 与upper() 需要各自遍历变体类型. 这很可能比在单次循环中填充所有数据更慢.

  • polymorphic_bin 可能从axis::variant 的临时实例创建, 例如在调用 histogram::axis(0) 时. 存储对轴的引用会导致悬垂引用. 与其专门修改代码来处理这种情况, 不如直接使用值而非视图, 这样更为简单.
