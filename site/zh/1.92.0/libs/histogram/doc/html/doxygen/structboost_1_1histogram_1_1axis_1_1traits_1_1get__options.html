结构体模板 get_options

boost::histogram::axis::traits::get_options — 获取轴类型的轴选项.

概要

// In header: <boost/histogram/axis/traits.hpp>

template<typename Axis> 
struct get_options {
};

说明

Doxygen 对此的呈现不佳. 这是一个元函数 (模板别名), 它接受一个轴类型并返回 boost::histogram::axis::option::bitset.

若 Axis::options() 有效且为 constexpr, get_options 即为对应的选项类型. 否则, 它是boost::histogram::axis::option::growth_t, 若轴具有方法update, 否则为boost::histogram::axis::option::none_t.

模板参数

  1. typename Axis

    轴类型
