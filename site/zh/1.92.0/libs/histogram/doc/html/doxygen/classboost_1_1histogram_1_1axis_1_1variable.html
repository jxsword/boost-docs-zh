boost::histogram::axis::variable — 实数轴上非等距区间的轴.

说明

分箱是 O(log(N)) 操作. 如果速度重要且问题领域允许, 请优先使用 regular 轴, 必要时可配合变换.

若轴有溢出区间 (默认情况), 位于最后一个区间上边缘的值会被放入溢出区间. 轴的范围表示半开区间.

若溢出区间被停用, 则位于最后一个区间上边缘的值仍计入最后一个区间. 轴的范围表示闭区间. 对于从有界区间 (通常是闭区间) 中抽取的随机数, 这是所期望的行为.

模板参数

  1. typename Value

    输入值类型, 必须为浮点数.

  2. typename MetaData

    用于存储元数据的类型.

  3. typename Options

    参见 boost::histogram::axis::option.

  4. typename Allocator

    用于动态内存管理的分配器.

variable 公有成员函数

  1. variable() = default;
  2. explicit variable(allocator_type alloc);
  3. template<typename It> 
  variable(It begin, It end, metadata_type meta = {}, 
           options_type options = {}, allocator_type alloc = {});
    由区间边缘的前向迭代器范围构造.

    若迭代器范围无效、提供的边缘少于两个或区间边缘未按升序排列, 构造函数抛出 std::invalid_argument.

    实参 meta 和 alloc 按值传递. 若将其中任一移动传入轴中而构造函数抛出异常, 其值会丢失. 若无法保证 bin 描述有效, 请勿移动.

    参数:

    begin

    边缘序列的起始.

    end

    边缘序列的结束.

    meta

    轴的描述 (可选).

    options

    参见 boost::histogram::axis::option (可选).

    alloc

    要使用的分配器实例 (可选).
