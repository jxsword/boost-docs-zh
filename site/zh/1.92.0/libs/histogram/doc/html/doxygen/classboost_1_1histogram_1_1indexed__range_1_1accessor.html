类 accessor

boost::histogram::indexed_range::accessor — 用于访问当前单元格的值和索引的轻量级视图.

概要

// In header: <boost/histogram/indexed.hpp>



// Lightweight view to access value and index of current cell.

class accessor {
public:
  // member classes/structs/unions

  // Array-like view into the current multi-dimensional index.

  class index_view {
  public:
    // types
    typedef unspecified              const_iterator;

    const_iterator begin() const noexcept;
    const_iterator end() const noexcept;
    std::size_t size() const noexcept;

};

说明

这些方法提供对当前单元格索引和区间的访问. 它的行为类似于指向单元格值的指针, 并在有限程度上也类似于引用. 为了与标准库的算法互操作, accessor 可隐式转换为单元格值. 赋值和比较会透传给单元格. accessor 与其父 indexed_range::iterator 相耦合. 父迭代器向前移动时, 关联的 accessor 也会更新. accessor 不可复制. 它们不能存入容器, 但indexed_range::iterator 可以.
