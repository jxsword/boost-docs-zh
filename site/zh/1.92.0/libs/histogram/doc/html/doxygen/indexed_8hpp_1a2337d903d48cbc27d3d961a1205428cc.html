类型 coverage

boost::histogram::coverage — 索引范围生成器的覆盖模式.

概要

// In header: <boost/histogram/indexed.hpp>


enum coverage { inner, all };

说明

定义迭代策略的选项.

inner

遍历内部区间, 排除下溢和溢出

all

遍历全部区间, 包括下溢和溢出
