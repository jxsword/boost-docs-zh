函数 crop_and_rebin

boost::histogram::algorithm::crop_and_rebin — 用于 reduce 的裁剪与重新分箱命令.

概要

// In header: <boost/histogram/algorithm/reduce.hpp>


reduce_command crop_and_rebin(double lower, double upper, unsigned merge);

说明

命令按归约实参的顺序应用于对应轴.

在一条命令中完成crop 与rebin (详情参见相应命令). 等价于对reduce 传入同一轴的两条命令.

参数:

lower

应保留的下界.

upper

应保留的上界. 若 upper 位于某区间内部, 则整个区间被移除.

merge

多少个相邻区间合并为一个.
