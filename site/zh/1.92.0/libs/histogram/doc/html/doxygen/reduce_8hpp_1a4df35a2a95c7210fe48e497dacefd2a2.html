函数 slice_and_rebin

boost::histogram::algorithm::slice_and_rebin — 用于 reduce 的切片与重新分箱命令.

概要

// In header: <boost/histogram/algorithm/reduce.hpp>


reduce_command 
slice_and_rebin(unsigned iaxis, axis::index_type begin, axis::index_type end, 
                unsigned merge, slice_mode mode = slice_mode::shrink);

说明

命令应用于给定索引的轴.

在一条命令中完成slice 与rebin (详情参见相应命令). 等价于对reduce 传入同一轴的两条命令.

参数:

iaxis

要操作的轴.

begin

应保留的第一个索引.

end

应保留的最后一个索引之后的位置.

merge

多少个相邻区间合并为一个.

mode

切片模式, 参见 slice_mode.
