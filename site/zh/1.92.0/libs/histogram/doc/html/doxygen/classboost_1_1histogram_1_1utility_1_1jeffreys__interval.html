类模板 jeffreys_interval

boost::histogram::utility::jeffreys_interval — Jeffreys 区间.

概要

// In header: <boost/histogram/utility/jeffreys_interval.hpp>

template<typename ValueType> 
class jeffreys_interval :
  public boost::histogram::utility::binomial_proportion_interval< ValueType >
{
public:
  // types
  typedef typename jeffreys_interval::value_type    value_type;   
  typedef typename jeffreys_interval::interval_type interval_type;

  // public member functions
  explicit jeffreys_interval(confidence_level = deviation{1}) noexcept;
  interval_type operator()(value_type, value_type) const noexcept;
};

说明

这是带 Jeffreys 先验的贝叶斯可信区间. 虽然它由贝叶斯方法推导, 但具有良好的覆盖性. 其区间边界接近 Wilson 区间. 此区间的一个特殊性质是等尾性: 真值位于区间之上或之下的概率近似相等.

为避免比例趋近 0 或 1 时覆盖概率趋于零, 本实现采用 L.D. Brown、T.T. Cai、A. DasGupta 在 Statistical Science 16 (2001) 101-133, doi:10.1214/ss/1009213286 论文第 4.1.2 节中描述的一种修改方法.

jeffreys_interval 公有成员函数

  1. explicit jeffreys_interval(confidence_level cl = deviation{1}) noexcept;
    构造 Jeffreys 区间计算器.

    参数:

    cl

    区间的置信水平. 默认值产生相当于一个标准差的 68 % 置信水平. deviation 与confidence_level 对象都可用于初始化该区间.

    根据给定的成功与失败次数计算区间.

    参数:

    successes

    成功试验的次数.

    failures

    失败试验的次数.
