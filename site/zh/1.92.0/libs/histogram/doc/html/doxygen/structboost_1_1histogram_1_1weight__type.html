结构体模板 weight_type

boost::histogram::weight_type — 权重持有者与类型信封.

概要

// In header: <boost/histogram/weight.hpp>

template<typename T> 
struct weight_type {

  // public member functions
  template<typename U> operator weight_type< U >() const;

  // public data members
  T value;  // Access underlying value. 
};

说明

不应直接构造这些对象, 请使用 weight() 辅助函数.

weight_type 公有成员函数

  1. template<typename U> operator weight_type< U >() const;
    当底层值类型允许时允许类型隐式转换.
