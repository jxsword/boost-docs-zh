结构体模板 is_ordered

boost::histogram::axis::traits::is_ordered — 用于检测轴是否为有序的元函数.

概要

// In header: <boost/histogram/axis/traits.hpp>

template<typename Axis> 
struct is_ordered {
};

说明

Doxygen 对此的呈现不佳. 这是一个元函数 (模板别名), 它接受一个轴类型并返回编译期布尔值. 若布尔值为 true, 则轴是有序的.

该元函数检查方法 constexpr static bool ordered() 并使用其结果. 若该方法不存在, 则当 Axis 的值类型为算术类型时返回 true, 否则返回 false.

有序轴的值类型是有序的, 即对任意 i,j,k, 索引 i < j < k 意味着 value(i) < value(j) < value(k) 或 value(i) > value(j) > value(k). 例如, integer 轴是有序的, 而 category 轴不是. 无序轴不得有下溢区间, 因为它们只有一个"其他"类别, 若溢出区间可用, 该类别即由溢出区间标识.

模板参数

  1. typename Axis

    轴类型
