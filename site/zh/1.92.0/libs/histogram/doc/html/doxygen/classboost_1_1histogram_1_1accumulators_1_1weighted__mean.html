类模板 weighted_mean

boost::histogram::accumulators::weighted_mean — 计算加权样本的均值与方差.

概要

// In header: <boost/histogram/accumulators/weighted_mean.hpp>

template<typename ValueType> 
class weighted_mean {
public:
  // types
  typedef ValueType          value_type;     
  typedef const value_type & const_reference;

  // public member functions
  weighted_mean() = default;
  template<typename T> weighted_mean(const weighted_mean< T > &);
  weighted_mean(const_reference, const_reference, const_reference, 
                const_reference);
  void operator()(const_reference);
  void operator()(const weight_type< value_type > &, const_reference);
  weighted_mean & operator+=(const weighted_mean &);
  weighted_mean & operator*=(const_reference) noexcept;
  bool operator==(const weighted_mean &) const noexcept;
  bool operator!=(const weighted_mean &) const noexcept;
  const_reference sum_of_weights() const noexcept;
  const_reference sum_of_weights_squared() const noexcept;
  value_type count() const noexcept;
  const_reference value() const noexcept;
  value_type variance() const;
  template<typename Archive> void serialize(Archive &, unsigned);
};

说明

使用 West 增量算法提高均值与方差计算的数值稳定性.

weighted_mean 公有成员函数

  1. weighted_mean() = default;
  2. template<typename T> weighted_mean(const weighted_mean< T > & o);
    允许从其他 weighted_mean 隐式转换.
  3. weighted_mean(const_reference wsum, const_reference wsum2, 
              const_reference mean, const_reference variance);
    以外部的权重和、权重平方和、均值和方差初始化.
  4. void operator()(const_reference x);
    插入样本 x.
  5. void operator()(const weight_type< value_type > & w, const_reference x);
    插入带权重 w 的样本 x.
  6. weighted_mean & operator+=(const weighted_mean & rhs);
    加上另一个 weighted_mean.
  7. weighted_mean & operator*=(const_reference s) noexcept;
    按 value 缩放.

    其效果如同所有样本都按该值缩放.

  8. bool operator==(const weighted_mean & rhs) const noexcept;
  9. bool operator!=(const weighted_mean & rhs) const noexcept;
  10. const_reference sum_of_weights() const noexcept;
    返回权重和.
  11. const_reference sum_of_weights_squared() const noexcept;
    返回权重平方和 (权重分布的方差).
  12. value_type count() const noexcept;
    返回有效计数.

    这相当于与本样本具有相同方差的无加权样本的等效数量. count() 应当用于检查value() 与variance() 是否有定义, 参见value() 与variance() 的文档. count() 可用于计算均值的方差, 即将variance() 除以count().

  13. const_reference value() const noexcept;
    返回已累加加权样本的均值.

    若 count() == 0, 则结果未定义.

  14. value_type variance() const;
    返回已累加加权样本的方差.

    若 count() == 0 或count() == 1, 则结果未定义.

  15. template<typename Archive> void serialize(Archive & ar, unsigned);
