结构体模板 bitset

boost::histogram::axis::option::bitset — 轴选项的持有者.

概要

// In header: <boost/histogram/axis/option.hpp>

template<unsigned Bits> 
struct bitset : public std::integral_constant< unsigned, Bits > {

  // public static functions
  template<unsigned B> static auto test(bitset< B >);
};

说明

bitset 公有静态函数

  1. template<unsigned B> static auto test(bitset< B >);
    若实参中所有选项标志都已设置则返回 true, 否则返回 false.
