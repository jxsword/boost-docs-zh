类模板 category

boost::histogram::axis::category — 将一组唯一值映射到区间索引.

概要

// In header: <boost/histogram/axis/category.hpp>

template<typename Value, typename MetaData, typename Options, 
         typename Allocator> 
class category : public boost::histogram::axis::iterator_mixin< category< Value, MetaData, Options, Allocator > >,
                 public metadata_base_t< MetaData >
{
public:

  // public member functions
  category() = default;
  explicit category(allocator_type);
  template<typename It> 
    category(It, It, metadata_type = {}, options_type = {}, 
             allocator_type = {});
  template<typename It, typename A> category(It, It, metadata_type, A);
  template<typename C> 
    category(const C &, metadata_type = {}, options_type = {}, 
             allocator_type = {});
  template<typename C, typename A> category(const C &, metadata_type, A);
  template<typename U> 
    category(std::initializer_list< U >, metadata_type = {}, 
             options_type = {}, allocator_type = {});
  template<typename U, typename A> 
    category(std::initializer_list< U >, metadata_type, A);
  category(const category &, index_type, index_type, unsigned);
  index_type index(const value_type &) const noexcept;
  std::pair< index_type, index_type > update(const value_type &);
  std::conditional_t< std::is_scalar< value_type >::value, value_type, const value_type & > 
  value(index_type) const;
  decltype(auto) bin(index_type) const;
  index_type size() const noexcept;
  template<typename V, typename M, typename O, typename A>

  template<typename V, typename M, typename O, typename A>

  allocator_type get_allocator() const;
  template<typename Archive> void serialize(Archive &, unsigned);

  // public static functions
  static unsigned options() noexcept;
  static bool inclusive() noexcept;
  static bool ordered() noexcept;
};

说明

该轴按构造函数中实参的顺序将一组值映射到区间. 此轴可选的溢出区间会对不属于该集合的输入值进行计数. 分箱具有 O(N) 复杂度, 但因子非常小. 对于较小的 N (典型使用情形), 它优于其他查找方式.

选项 underflow 与circular 不允许使用. 选项growth 与overflow 互斥.

模板参数

  1. typename Value

    输入值类型, 必须可进行相等比较.

  2. typename MetaData

    用于存储元数据的类型.

  3. typename Options

    参见 boost::histogram::axis::option.

  4. typename Allocator

    用于动态内存管理的分配器.

category 公有成员函数

  1. category() = default;
  2. explicit category(allocator_type alloc);
  3. template<typename It> 
  category(It begin, It end, metadata_type meta = {}, 
           options_type options = {}, allocator_type alloc = {});
    由唯一值的前向迭代器范围构造.

    若迭代器范围无效, 构造函数抛出 std::invalid_argument. 若范围包含重复值, 轴的行为未定义.

    实参 meta 和 alloc 按值传递. 若将其中任一移动传入轴中而构造函数抛出异常, 其值会丢失. 若无法保证 bin 描述有效, 请勿移动.

    参数:

    begin

    唯一值类别范围的起始.

    end

    唯一值类别范围的结束.

    meta

    轴的描述 (可选).

    options

    参见 boost::histogram::axis::option (可选).

    alloc

    要使用的分配器实例 (可选).

    		 
  4. template<typename It, typename A> 
  category(It begin, It end, metadata_type meta, A alloc);
  5. template<typename C> 
  category(const C & iterable, metadata_type meta = {}, 
           options_type options = {}, allocator_type alloc = {});
    由唯一值的可迭代序列构造轴.

    参数:

    iterable

    唯一值序列.

    meta

    轴的描述.

    options

    参见 boost::histogram::axis::option (可选).

    alloc

    要使用的分配器实例.

  category(const C & iterable, metadata_type meta, A alloc);
  7. template<typename U> 
  category(std::initializer_list< U > list, metadata_type meta = {},

    list

    std::initializer_list (唯一值).

    轴的描述.

    options

    参见 boost::histogram::axis::option (可选).

    alloc

    要使用的分配器实例.

    		 
  8. template<typename U, typename A> 
  category(std::initializer_list< U > list, metadata_type meta, A alloc);
  9. category(const category & src, index_type begin, index_type end, 
         unsigned merge);
    由 algorithm::reduce 用于收缩和重新分箱的构造函数 (不面向用户).
  10. index_type index(const value_type & x) const noexcept;
    返回值实参对应的索引.
  11. std::pair< index_type, index_type > update(const value_type & x);
    返回传入实参对应的索引和移位量 (若轴已增长).
  12. std::conditional_t< std::is_scalar< value_type >::value, value_type, const value_type & > 
value(index_type idx) const;
    返回索引实参对应的值.

    若索引越界则抛出 std::out_of_range.

  13. decltype(auto) bin(index_type idx) const;
    返回索引实参对应的值; value(...) 的别名.
  14. index_type size() const noexcept;
    返回区间数量, 不含溢出和下溢区间.

category 公有静态函数

  1. static unsigned options() noexcept;
    返回选项.
  2. static bool inclusive() noexcept;
    轴是否为包含式 (参见 axis::traits::is_inclusive).
  3. static bool ordered() noexcept;
