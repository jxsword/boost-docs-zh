类模板 wald_interval

boost::histogram::utility::wald_interval — Wald 区间或正态近似区间.

概要

// In header: <boost/histogram/utility/wald_interval.hpp>

template<typename ValueType> 
class wald_interval :
  public boost::histogram::utility::binomial_proportion_interval< ValueType >
{
public:
  // types
  typedef typename wald_interval::value_type    value_type;   
  typedef typename wald_interval::interval_type interval_type;

  // public member functions
  explicit wald_interval(deviation = deviation{1.0}) noexcept;
  interval_type operator()(value_type, value_type) const noexcept;
};

说明

Wald 区间是对称区间. 它计算简单, 但统计性质很差, 被统计学家普遍摒弃. 应当始终用其他区间替代, 例如 Wilson 区间.

利用二项分布方差的代入估计可以容易地推导出 Wald 区间, 这可能是它无处不在的原因. 若缺乏对统计理论的进一步了解, 便不易察觉这一推导存在缺陷, 也存在更好的替代方法.

Wald 区间平均而言覆盖不足. 当样本量较小或比例接近 0 或 1 时, 它并不适用. 其界限并非天然受限于 0 或 1. 若成功次数或失败次数为零, 它会产生空区间.

关于 Wald 区间的批评, 参见 (节选):

L.D. Brown, T.T. Cai, A. DasGupta, Statistical Science 16 (2001) 101-133. R. D. Cousins, K. E. Hymes, J. Tucker, Nucl. Instrum. Meth. A 612 (2010) 388-398.

wald_interval 公有成员函数

  1. explicit wald_interval(deviation d = deviation{1.0}) noexcept;
    构造 Wald 区间计算器.

    参数:

    d

    区间的标准差数量. 默认值 1 对应 68 % 置信水平. deviation 与confidence_level 对象都可用于初始化该区间.

    		 
  2. interval_type 
operator()(value_type successes, value_type failures) const noexcept;
    根据给定的成功与失败次数计算区间.

    参数:

    successes

    成功试验的次数.

    failures

    失败试验的次数.
