变更日志

Boost 1.89

  • 更新 CMake 最低版本及 CMake 中的 Python 检测
  • 改进文档
    • 添加示例, 说明如何创建接受多个不可隐式转换值类型的轴
    • 展示当每个维度的数据已是连续数据时, 如何在多维直方图上高效使用 histogram::fill
  • 不再使用已弃用的用户定义字面量运算符形式
  • 添加对使用 b2 的模块化构建结构的支持
  • 修复 MSVC 中关于类型收窄的警告
  • 新增 collector 累加器, 用于存储一个区间中的所有值
  • 对 detail 命名空间中测试和类的内部更改

Boost 1.82

  • 将 detail::span 与 detail::make_span 替换为 boost::core 中的实现
  • 文档改进
  • 在某些情况下保护 std::min 与 std::max 的使用, 由 Han Jiang 贡献 (流行的 Windows 头文件非法设置 min、max 宏, 因此需要绕行处理)
  • 新增测试, 以便在将来捕获库中未受保护的 min、max 标记的使用
  • 修复以支持最新的 clang-14 以及 gcc-11+ 中的推导指引

Boost 1.81

  • 新增 accumulators::fraction, 用于计算比例、其方差和置信区间
  • 新增比例的区间计算器: utility::clopper_pearson、utility::wilson_interval、utility::jeffreys_interval、utility::wald_interval, 可计算任意置信水平的区间
  • 新增 utility::confidence_level 与 utility::deviation 类型, 分别用于以概率或标准差倍数的形式为所有区间计算器传递置信水平
  • 修复 C++20 中的内部 static_vector 与 span

Boost 1.80

  • 修复 indexed 中的段错误: 在特定条件下尝试遍历轴大小为零 (物理或逻辑) 的直方图时
  • 移除先前已弃用的 API:
    • 类 accumulators::thread_safe: 改用 accumulators::count<T, true>
    • 方法 accumulators::sum::large 与 accumulators::sum::small: 改用 accumulators::sum::large_part 与 accumulators::sum::small_part
    • 类型别名 algorithm::reduce_option: 改用 algorithm::reduce_command
    • 模板函数 axis::traits::static_options: 改用 axis::traits::get_options
    • 模板函数 axis::traits::static_is_inclusive: 改用 axis::traits::is_inclusive
    • 类型别名 indexed::range_iterator: 改用 indexed::iterator
    • 类型别名 indexed::accessor::reference: 改用 indexed::accessor::const_reference

Boost 1.79

  • accumulators::weighted_sum 的除法支持
  • 若无溢出区间, axis::regular 与 axis::variable 现在表示闭区间; 例如在闭区间 [0, 1] 中正确划分概率时需要这一点
  • cpp17 支持: 通过推导指引设置轴的编译期选项

Boost 1.78

  • 弃用 accumulators::sum::small 与 ::large (作为 windows.h 中缺陷的变通方法)
  • 修复 accumulators::count 中损坏的除法运算符
  • 修复一维 histogram::fill 中轴为增长式且实参为单个值时的缺陷
  • 文档改进

Boost 1.77

  • indexed 现在允许遍历用户定义的矩形子范围
  • 弃用 accumulators::thread_safe, 用户应改用可选线程安全的 accumulators::count
  • 修复 accumulators::count 中损坏的缩放运算符
  • 修复 axis::integer::inclusive 中的缺陷
  • 输出流改进: 支持更多累加器, 绘制 unicode 条形图现为默认行为

Boost 1.76

  • 修复
    • 若所选范围确实与流动区间重叠, algorithm::reduce 与 crop 现在不再移除流动区间中的计数, 从而使流动区间的处理与内部区间一致
    • accumulators::mean 与 accumulators::weighted_mean 现在会在调用 operator+= 后计算正确的方差, 例如相加带累加器的直方图时; 此前计算错误, 会导致方差过小
    • 若累加器使用 operator+= 而非 operator(), 用户自定义累加器的权重支持检测在编译期会失效; 对内置 weighted_sum 的测试只是碰巧通过

Boost 1.75

  • 修复
    • axis::variable{{0, 1, inf}}.value(1) 现在返回 1 而不是 NaN
    • 若某个值为 NaN, axis::variable 构造函数现在抛出 std::invalid_argument
    • 针对一个 gcc 缺陷 (上游将在 gcc-10.x 中修复) 实现了变通方法, 该缺陷在 <boost/type_traits.hpp> 先于 <boost/histogram/axis/traits.hpp> 被包含时出现
    • 修复最新编译器版本产生的若干新警告
    • 修复按 C++20 标准编译时出现的警告
  • 文档
    • 记录了未定义行为: 当对 accumulator::mean 与 accumulator::weighted_mean 请求值和方差但累加器没有足够的条目来计算它们时
    • 在设计理由中补充说明为何对轴元数据进行相等性检查

Boost 1.74

  • 新功能
    • 新轴 boolean, 一种特殊的 integer 轴, 只有两个值且没有状态 (元数据除外)
    • 带增长式 category 轴的直方图现在即使类别不同也可相加; 输出直方图的 category 轴是输入直方图 category 轴的并集
    • 新增 axis::traits::continuous 以与 axis::traits::is_continuous 对应
  • 修复
    • 内置轴类型的 metadata() 方法现在即使轴为 const 也返回可变引用, 如文档所述
  • 文档
    • 参考中排序了头文件, 命名空间中排序了条目
    • 从模板中移除了一些内部 typename
    • 新增 sample_type 的参考
  • 其他
    • 简化内部元编程
    • 用普通 cassert 替换 Boost Assert

Boost 1.73

  • 新功能
    • 累加器
      • 新的 count 累加器, 对原始算术类型的薄包装; 可作为基类, 供想为每个区间添加任意元数据的用户使用
      • sum 新增了 value() 方法, 以与其他累加器保持一致
    • algorithm
      • reduce
        • 现在支持位置命令
        • category 轴现在支持 slice 命令
        • 新增 crop 命令, 类似 shrink, 但丢弃被移除区间的内容
        • 将 reduce_option 重命名为 reduce_command (旧名仍可用但已弃用)
      • sum 新增一个实参, 允许用户选择对所有区间求和还是仅对内部区间求和 (不含下溢和溢出)
    • axis::traits
      • 新增特征 is_ordered 与 ordered, 用于区分不同种类的 DiscreteAxis 类型; 内部用于以不同方式处理 category 轴和 integer 轴
      • 将 static_options 重命名为 get_options, 将 static_is_inclusive 重命名为 is_inclusive (旧名仍可用但已弃用)
  • 修复
    • 修复捆绑 Boost 中因路径错误而失败的 ODR 测试
    • 修复 histogram::operator*= 中可能出现在用户自定义累加器中的缺陷
    • 修复 indexed 中可能导致越过末尾位置进行算术运算的缺陷
    • 修复 accumulators::weighted_sum 中的如下缺陷: 若普通直方图加到使用 accumulators::weighted_sum 的直方图上, 其方差不会被正确计算
    • 修复如下缺陷: 使用 -ffast-math 编译会破坏 accumulators::sum
    • 修复 algorithm::reduce 使其可用于不带 *flow 区间的轴, 此前无法编译
  • 其他
    • 新增关于如何将 Boost.Histogram 用作后端的示例和文档
    • 改进关于如何使用自定义累加器和 Boost.Accumulators 的文档
    • 许多小的文档改进
    • 改进 algorithm::reduce 的文档
    • 改进实验性 cmake 构建支持
    • 在所有地方一致地使用 index_type 而不是裸 int
    • 文档中的基准测试更新

Boost 1.72

  • 新功能
    • 在 C++17 编译器上为轴类型和直方图类型提供更好的推导指引
    • 索引代码中的性能改进
    • 新的 histogram::fill 方法, 用于从值块加速填充
    • 包含 boost/histogram/ostream.hpp 时为一维直方图绘制 ASCII 条形图 (由 Przemyslaw Bartosik 贡献)
    • 传入无效轴选项会导致用户友好的编译期错误
    • 错误使用 weight() 和 sample() 会导致用户友好的编译期错误
    • algorithm::empty 在所有直方图值都等于默认值时返回 true (由 Henry Schreiner 贡献)
    • algorithm::reduce 配合 shrink 在值不是区间边缘时现在有良好定义
    • axis::traits::rank 返回该轴接受的值数量
    • axis::traits::is_continuous 返回轴是连续的还是离散的
    • axis::traits::is_inclusive 返回轴是否对任何可能的输入都有区间
    • mean 累加器的有限权重支持
    • 新增 accumulators::weighted_mean::sum_of_weights_squared 方法
  • 修复
    • clang 支持 -std=c++2a 与 -stdlib=libc++, 兼容 gcc-9
    • 修复: 填充时可以传入权重代替样本而不触发错误
    • 修复: 向 algorithm::project 传入过多索引时的段错误
    • 修复: 索引范围生成器无法用于基于 std::array 的存储器
    • 修复: weighted_mean() + weighted_mean() != weighted_mean() (由 Henry Schreiner 发现并报告)
    • 修复: axis::option::test(...) 在测试掩码中任一位置位时返回 true (现在改为掩码中所有位置位才返回 true)
    • 保护对 min、max 的调用以避免宏展开
    • 将 concepts.qbk 中的所有 crlf 替换为 lf
    • 用户向直方图传入过多轴时缺少 std::invalid_argument 的抛出
    • 修正概念章节中关于序列化支持的文档
    • 消除各种编译器版本的警告
  • 其他
    • 添加 Boost.Histogram 标志
    • 添加缺失的版权声明
    • axis::category::value 对标量类型返回副本, 否则返回 const 引用
    • 不再使用 std::ostringstream 生成异常消息, 以减少代码膨胀
    • 文档改进
      • 重构文档中的概述章节
      • 更新用户指南以演示新功能
      • 更新累加器示例
      • 概念章节说明累加器如何可选地接受权重
    • 更新基准测试代码
    • 新测试检查 b2 与 cmake 构建系统的一致性
    • 新测试检查单一定义规则 (若非模板函数未声明为 inline 则失败)
    • 序列化代码与 Boost.Serialization 解耦
    • 移除对 Boost.CallableTraits 的依赖

Boost 1.71

    • boost::histogram::algorithm::reduce
      • 新切片选项
      • 对同一轴传入的 shrink、slice 和 rebin 选项进行融合
      • 支持部分轴类型带归约支持的直方图
    • boost::histogram::algorithm::project 对静态直方图接受运行期索引
  • 修复
    • boost::histogram::algorithm::reduce 也可用于带有某些不支持归约的轴类型的直方图
    • boost::histogram::axis::traits::update 现在对 boost::histogram::axis::variant 正确工作
  • 其他
    • 100 % 测试覆盖率
    • 大幅减少内部 Boost 依赖
    • 改进文档与示例
    • 内部用 boost::variant2 替换 boost::variant
    • boost::histogram::axis::traits::is_reducible 检测可归约的轴类型
    • 内部清理与重构
    • 保证所有内置轴类型的移动不抛出异常
    • 改进内部基准测试
    • 在更高警告级别下干净编译

Boost 1.70

首次 Boost 发布, 按先前的内部计数为 4.0 版.

  • 移除 Python 绑定, 将在单独的仓库中开发
  • 除 category 轴外, 所有轴都可设为可选循环式
  • 所有轴现在支持通用附加元数据
  • 所有轴现在具有可独立配置的下溢/溢出额外区间
  • 移除 circular 轴 (它只是循环式 regular 轴)
  • 新增 indexed 适配器生成器, 用于便捷快速地遍历直方图
  • 支持可在范围上增长的轴
  • 支持接受多个值的轴 (示例: 六边形分箱)
  • 支持轮廓, 更一般地, 支持每个单元格中的任意累加器
  • 支持序列化到 xml 档案
  • 新增与 Boost.Range、Boost.Units 和 Boost.Accumulators 的兼容性
  • 为轴类型和直方图新增推导指引
  • 性能改进
  • 将 adaptive_storage 重命名为 unlimited_storage
  • 用自定义类型替换 boost::multiprecision::cpp_int, 以解耦各库
  • axis::variant 的内部简化
  • 使所有存储器的行为更像容器, 简化设计
  • 直方图支持加、减、乘、除
  • 将轴中的 operator[] 替换为显式方法 bin
  • 将轴中的 operator() 替换为显式方法 index
  • 将 boost::containers 的内部使用替换为标准库容器
  • 大幅改进的文档、参考文档、用户指南和更多示例

3.2 (不在 Boost 中)

  • 各处支持分配器
  • 内部重构

3.1 (不在 Boost 中)

  • 将 bincount 方法重命名为 size
  • 支持只有溢出而没有下溢区间的轴
  • category 轴现在默认为不属于预定义类别的"其他"输入设置区间, 使其与其他轴一致
  • NaN 现在对所有轴一致地放入溢出区间
  • 消除 MSVC 上关于安全内部转换的警告
  • 建立了 C++ 代码风格规范及相应的 .clang-format 文件
  • 在所有系统上更好地检测 Python 库
  • 通过测试更多输入错误提高代码覆盖率
  • Python 中输入错误时抛出 ValueError 而不是笼统的 RuntimeError

3.0 (不在 Boost 中)

  • 支持高效地相加多个直方图和缩放
  • 重新设计 category 轴, 作为唯一值与区间之间的一般映射
  • 重新设计轴在元素访问时返回的区间描述
  • 接口清理与简化, Python 与 C++ 接口之间更一致
  • 为直方图和轴提供迭代器以兼容 STL
  • C++ 中的 regular 轴: 允许带状态的变换
  • Python 中的 regular 轴: 支持所有 C++ 变换
  • 多态 axis::any 类型
  • 内部重构: 从 boost::mpl 和 boost::fusion 迁移到 std::tuple 和 boost::mp11
  • Windows 支持

2.0 (不在 Boost 中)

  • 新增 static_histogram (v1.0 只有 dynamic_histogram).
  • 合并 wfill(...) 与 fill(...) 接口.
  • 存储器类中支持自定义分配器.
  • 用 array_storage 替换 static_storage.
  • 用 unlimited_storage 替换 dynamic_storage, 后者增加了将区间计数器扩展为 cpp_int 的能力, 从而完全避免整数溢出.
  • 序列化使用 binary_archive 而不是 text_archive. 后者可移植, 但性能糟糕.
  • Python 接口变更: 直方图现在可迭代, 返回轴类
  • 支持归约 (移除轴的子集并返回等效直方图; 换言之, 对这些轴进行积分)

1.0 (不在 Boost 中)

  • 首个稳定版本.
