用户可以使用此处定义概念的各种新类型来扩展本库.

Axis

Axis 将输入值映射到索引. 它保存该轴特有的状态, 例如区间数量和任意元数据. 必须满足 CopyConstructible、CopyAssignable, 且为 nothrow MoveAssignable.

注释

Axis::index 不能是模板或被重载. 这是设计使然, 也是用于检测通用用户自定义轴的内部代码的局限. 构造接受多种值类型的轴的变通方法见 指南.

关联类型
  • DiscreteAxis
  • IntervalAxis
必需特性
  • A 是满足 Axis 要求的类型
  • a 是一个类型为 A
  • I 是 boost::histogram::axis::index_type 的别名

a.size()

返回轴区间数量的 const 成员函数. 从 0 到 a.size() - 1 的所有索引都必须有效并指向轴的一个区间.

a.index(v)

将值 v 映射到索引的 const 成员函数. 该映射必须是单射: 每个值必须唯一地映射到一个索引. 若值未被轴覆盖, 则返回 -1 或 a.size(). 值 -1 表示该值低于轴覆盖的最低值. 值 a.size() 表示该值高于轴覆盖的最高值. 按照约定, NaN 值被映射到 a.size().

Alloc

返回此轴使用的分配器 Alloc 的 const 成员函数. 若 A 不使用分配器, 可以省略. 若存在此成员函数, 还必须存在一个特殊的构造函数, 使 A(a.get_allocator()) 是有效表达式.

  • ar 是具有 Boost.Serialization 语义的档案中的值

a.update(v)

std::pair<I, I>

将值映射到索引 (返回对的第一个元素) 和偏移量 (返回对的第二个元素) 的非 const 成员函数. 若值未被轴覆盖, 此方法可以将当前轴大小 (old_size) 增长容纳该值所需的区间数或更多 (new_size). 若值低于轴覆盖的最低值, 返回索引 0 和偏移量 new_size - old_size. 若值高于轴覆盖的最高值, 返回索引 new_size - 1 和负偏移量 old_size - new_size. 若值在范围之外但轴未增大, 则返回等价于 a.index(v) 的索引和偏移量 0.

A(a, i, j, n)

由归约算法使用的特殊构造函数. a 是原轴实例, i 与 j 是归约后轴中要保留的索引范围. 若 n 大于 1, n 个相邻区间被合并为一个更大的单元格. 若未实现此构造函数, boost::histogram::algorithm::reduce 在尝试归约此轴时会抛出异常.

a.options()

unsigned

返回此轴的 axis options 的 static constexpr 成员函数.

a.inclusive()

bool

static constexpr 成员函数: 若轴对每个可能的输入值都有区间则返回 true, 否则返回 false. 若直方图中所有轴类型都是包含式的, 可以生成更快的代码. 带有下溢和溢出区间的轴总是包含式的. 即使缺少下溢或溢出区间, 轴也可能是包含式的. 例如, category 轴若有溢出区间或是增长式的, 则是包含式的.

a.metadata()

M&

必须存在 const 与非 const 两个成员函数, 二者都返回对与轴关联的元数据 (通常为字符串) 的可变引用.

a == b

bool

若包括任何元数据在内的所有状态变量比较相等, 返回 true. 否则返回 false. 若实现了 a == b, 也必须实现 a != b. 若未实现此二元运算符, 当轴的类型相同时, 库将它们视为相等.

a != b

bool

若实现了 a == b 则必须实现, 且必须等于 !(a == b).

os << a

std::basic_ostream<CharT, Traits>&

os 是类型 std::basic_ostream<CharT, Traits> 的值. 流出轴的文本表示. 不得修改 a.

a.serialize(ar, n)

保存到档案或从档案加载已序列化的状态. 版本号 n 在加载对象时为存储的版本, 在保存对象时为当前版本.

模型
  • boost::histogram::axis::boolean
  • boost::histogram::axis::category
  • boost::histogram::axis::integer
  • boost::histogram::axis::regular
  • boost::histogram::axis::variable

DiscreteAxis

DiscreteAxis 是 Axis 概念的两个可选细化之一, 另一个是 IntervalAxis. 此概念适用于每个区间表示单个值而非区间的轴.

离散轴可进一步分为有序与无序. 当区间索引 i < j < k 对所有 i, j, k 都意味着 value[i] < value[j] < value[k] 或 value[i] > value[j] > value[k] 时, 轴是有序的. integer axis 是有序的, category axis 是无序的.

无序离散轴不能有下溢区间. 由于没有顺序, 最多只能有一个额外区间来统计轴未处理的值. 按照约定, 溢出区间用于此目的.

关联类型
  • Axis
  • IntervalAxis
可选特性
  • A 是满足 DiscreteAxis 要求的类型
  • a 是一个类型为 A
  • V 是为转换为索引而接受的类型
  • v 是一个类型为 V
  • i 是类型 boost::histogram::axis::index_type 的值
  • AxisIter 是 RandomAccessIterator, 遍历 A 的区间
  • ReAxisIter 是反向 RandomAccessIterator, 遍历 A 的区间

IntervalAxis

IntervalAxis 是 Axis 概念的两个可选细化之一, 另一个是 DiscreteAxis. 它适用于形成具有明确上下边缘和中心的区间的有序值. 每个区间表示一段值的范围.

关联类型
  • Axis
  • DiscreteAxis
可选特性
  • A 是满足 IntervalAxis 要求的类型
  • a 是一个类型为 A
  • V 是为转换为索引而接受的类型
  • B 是表示区间范围的类型
  • v 是一个类型为 V
  • i 是类型 boost::histogram::axis::index_type 的值
  • j 是类型 boost::histogram::axis::real_index_type 的值
  • AxisIter 是 RandomAccessIterator, 遍历 A 的区间
  • ReAxisIter 是反向 RandomAccessIterator, 遍历 A 的区间

表 1.4. 有效表达式

表达式

返回

语义, 前置/后置条件

a.value(i)

V

将索引映射到值的 const 成员函数. 该映射必须是单射: 每个索引必须唯一地映射到一个值. a.value(a.index(v)) 的结果应当与 v 在极高精度上一致 (由于浮点计算的精度有限, 映射可能不精确). 若被引用对象的生命期与轴的生命期相同, 返回值可以是 const 引用. a.value(j) 应返回区间的下边缘, a.value(j+1) 返回上边缘, 而 a.value(j + 0.5) 返回中心.

Transform

Transform 实现外部与内部两个实值域之间的单调映射. 它用于扩展 regular axis. 内部域中的区间等宽, 而外部域中的区间不等宽. 必须满足 DefaultConstructible、CopyConstructible 和 CopyAssignable.

必需特性
  • T 是满足 Transform 要求的类型
  • t 是一个类型为 T
  • X 是具有浮点类型语义的类型
  • x 是一个类型为 X
  • Y 是浮点类型
  • y 是一个类型为 Y

Storage

Storage 管理区间计数器的内存, 并提供统一的类 vector 接口用于读写单元格值. 必须满足 DefaultConstructible、CopyConstructible 和 CopyAssignable.

必需特性
  • S 是满足 Storage 要求的类型
  • s 是类型 S 的值
  • i 与 n 是类型 std::size_t 的值
  • Alloc 是 S 的分配器类型

Accumulator

Accumulator 是一个消费实参以更新某些内部状态的仿函数. 必须满足 DefaultConstructible、CopyConstructible 和 CopyAssignable.

必需特性
  • A 是满足 Accumulator 要求的类型
  • a 与 b 是类型 A 的值
  • ts... 是任意类型值组成的参数包
