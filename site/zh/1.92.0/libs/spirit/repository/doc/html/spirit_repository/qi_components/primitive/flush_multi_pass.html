Qi flush_multi_pass 解析器

说明

Spirit.Qi 的 flush_multi_pass 解析器是一个原语(伪)解析器组件, 允许清空 multi_pass 迭代器的内部缓冲区. 对于可以明确不会发生回溯的文法, 清空 multi_pass 的缓冲区可能是有益的. 使用 flush_multi_pass 的一般语法为:

flush_multi_pass

它将调用 clear_queue() 成员函数, 条件是当前迭代器的类型为 multi_pass. 这将导致所有被缓冲的数据被擦除. 这也会使 multi_pass 的所有其他拷贝失效, 它们不应再被使用. 若使用了它们, 将抛出 boost::illegal_backtracking 异常. 对所有其他迭代器类型, 这是一个空操作. flush_multi_pass 生成一个总是成功且不消耗任何输入的解析器组件(非常像 eps).

头文件 
// forwards to <boost/spirit/repository/home/qi/primitive/flush_multi_pass.hpp>
#include <boost/spirit/repository/include/qi_flush_multi_pass.hpp>
概要 
flush_multi_pass
参数

flush_multi_pass 不需要任何参数.

属性

flush_multi_pass 组件不暴露任何属性(暴露的属性类型为 unused_type):

flush_multi_pass --> unused

前置条件

除了包含 Spirit.Qi 中实现的核心组件所需的主头文件外, 我们还要添加新的 flush_multi_pass 解析器所需的头文件.

#include <boost/spirit/include/qi.hpp>
#include <boost/spirit/repository/include/qi_flush_multi_pass.hpp>

为了让下面的代码更易读, 我们引入以下命名空间.

namespace spirit = boost::spirit;
using boost::spirit::repository::flush_multi_pass;

清空内部缓冲区

示例文法识别(简化的)预处理命令 #define 与 #undef, 两者都被约束为单行. 这使得可以在每个检测到的换行处删除所有内部迭代器缓冲区. 这是安全的, 因为任何行尾之后都不会发生回溯. 下面的代码片段展示了为此目的使用 flush_multi_pass 的方法.

template <typename Iterator, typename Skipper>
struct preprocessor : spirit::qi::grammar<Iterator, Skipper>
{
    // This is a simplified preprocessor grammar recognizing
    //
    //   #define MACRONAME something
    //   #undef MACRONAME
    //
    // Its sole purpose is to show an example how to use the 
    // flush_multi_pass parser. At the end of each line no backtracking can
    // occur anymore so that it's safe to clear all internal buffers in the 
    // multi_pass.
    preprocessor() : preprocessor::base_type(file)
    {
        using spirit::ascii::char_;
        using spirit::qi::eol;
        using spirit::qi::lit;

        file =
            *line
            ;

        line =  ( command |  *(char_ - eol) )
            >>  eol
            >>  flush_multi_pass
            ;

        command =
                "#define" >> *lit(' ') >> *(char_ - ' ') >> *lit(' ') >> *(char_ - eol)
            |   "#undef"  >> *lit(' ') >> *(char_ - eol)
            ;
    }

    spirit::qi::rule<Iterator, Skipper> file, line, command;
};

注释

把 flush_multi_pass 解析器组件用于 multi_pass 之外的迭代器是安全的, 因为它对解析没有任何影响.
