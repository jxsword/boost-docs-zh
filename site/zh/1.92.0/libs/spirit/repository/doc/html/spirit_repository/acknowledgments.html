致谢

Spirit 仓库是 Spirit 社区活跃成员贡献的成果. 我们要感谢所有直接做出贡献的人, 以及所有直接或间接参与讨论的人 —— 正是这些讨论催生了这些解析器与生成器组件.

以下人员直接向本仓库贡献了代码:

Aaron Graham 编写了 advance 解析器组件, 它允许解析器跳过(前进)指定次数的迭代而不执行不必要的工作.

Chris Hoeppler 提交了 confix 解析器指令, 允许把一个解析器(主体)嵌入到一个开头(前缀)与一个结尾序列(后缀)之中.

Francois Barel 贡献了 subrule 解析器与 subrule 生成器组件, 允许创建一个具名解析器或生成器并按名称引用它. 这些组件实际上是相应 rule 组件的完全静态版本.

Thomas Bernard 贡献了 keyword_list 与 kwd()[] 解析器组件, 允许定义关键字解析器.
