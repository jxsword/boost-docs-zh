Qi 关键字解析器指令

说明

kwd[], dkwd[] 与 ikwd[], idkwd[] 为解析基于关键字的输入提供了一种强大而灵活的机制. 它与 / 运算符配合工作, 构成一个高效的关键字解析循环. 该关键字解析循环不要求关键字按既定顺序出现在输入中, 同时还提供了检查某个关键字在输入中出现多少次的可能性.

kwd 指令在解析关键字时区分大小写, 而 ikwd 指令不区分大小写. 你可以在一组关键字中混用 kwd 与 ikwd 指令, 但要注意这会带来少量开销. 最好不要混用 kwd 与 ikwd 指令.

dkwd 与 idkwd 提供了一种解析 distinct 关键字的机制. 这些指令要求跳过解析器在关键字部分之后立即成功解析输入.

dkwd("keyword1")='>>int_

等价于:

lit("keyword1") >> skipper+ >> '=' >> int_

所有关键字指令都可以在关键字列表内混用.

kwd 指令与 repeat 指令非常相似, 它能够强制关键字出现次数约束, 同时相比纯 EBNF 语法或 Nabialek 技巧还提供了非常可观的提速.

头文件 
// forwards to <boost/spirit/repository/home/qi/directive/kwd.hpp>
#include <boost/spirit/repository/include/qi_kwd.hpp>
概要

表达式

语义

kwd(keyword)[subject]

把 ( "keyword" > subject) 解析零次或多次.

kwd(keyword,n)[subject]

把 ( "keyword" > subject) 解析恰好 n 次.

kwd(keyword,min, max)[subject]

把 ( "keyword" > subject) 解析至少 min 次且至多 max 次.

kwd(keyword,min, inf)[subject]

把 ( "keyword" > subject) 解析至少 min 次或更多.

对不区分大小写的关键字, 请使用 ikwd 指令. 若需要解析 distinct 关键字, 请改用 dkwd 与 idkwd 指令.

参数

参数

说明

keyword

开头(前缀)部分的解析器.

subject

关键字部分之后输入序列的解析器.

n

表示关键字必须重复的准确次数的 Int.

min

表示关键字必须重复的最少次数的 Int.

max

表示关键字必须重复的最多次数的 Int.

关键字与主体参数可以是任何有效的 spirit 解析器. 参数 n, min 和 max 是整数常量.

复杂度

总体复杂度由其主体解析器的复杂度决定. 关键字列表构造 kwd 本身的复杂度为 O(N), 其中 N 是执行的重复次数.

当所有关键字都是字符串时, 关键字列表本身的复杂度由内部 TST 内容的复杂度决定:

O(log n+k)

其中 k 是在含 n 个字符串的 TST 中要搜索的字符串长度.

当使用的关键字是复杂解析器时, 复杂度是各子解析器复杂度之和.
