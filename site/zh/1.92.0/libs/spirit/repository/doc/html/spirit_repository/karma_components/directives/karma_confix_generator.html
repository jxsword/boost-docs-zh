Karma Confix 生成器

说明

Spirit.Karma 的 confix 生成器是一个生成器指令组件, 允许把任何生成的输出嵌入到一个开头(前缀)与一个结尾(后缀)之内. 一个简单的例子是 C 注释: /* This is a C comment */ 它可以按如下方式用 confix 生成器生成: confix("/*", "*/")["This is a C comment"]. 使用 confix 的一般语法为:

confix(prefix, suffix)[subject]

这将生成一个等价于以下形式的序列

prefix << subject << suffix

使用 confix 组件而非显式序列的优点是, 能够把前缀与后缀封装到一个独立的生成器构造中. 下面的代码片段说明了这一思路:

// Define a metafunction allowing to compute the type of the confix()
// construct
namespace traits
{
    using namespace boost::spirit;

    template <typename Prefix, typename Suffix = Prefix>
    struct confix_spec
      : spirit::result_of::terminal<repository::tag::confix(Prefix, Suffix)>
    {};
};

// Define a helper function allowing to create a confix() construct from 
// arbitrary prefix and suffix generators
template <typename Prefix, typename Suffix>
typename traits::confix_spec<Prefix, Suffix>::type
confix_spec(Prefix const& prefix, Suffix const& suffix)
{
    using namespace boost::spirit;
    return repository::confix(prefix, suffix);
}

// Define a helper function to  construct a HTML tag from the tag name
inline typename traits::confix_spec<std::string>::type
tag (std::string const& tagname)
{
    return confix_spec("<" + tagname + ">", "</" + tagname + ">");
}

// Define generators for different HTML tags the HTML tag
typedef traits::confix_spec<std::string>::type ol = tag("ol");      // <ol>...</ol> 
typedef traits::confix_spec<std::string>::type li = tag("li");      // <li>...</li>

现在, 例如, 上面的定义允许用一个简单的: ol["Some text"] 生成 HTML 的 'ol' 标签(其结果是 <ol>Some text</ol>).

头文件 
// forwards to <boost/spirit/repository/home/karma/directive/confix.hpp>
#include <boost/spirit/repository/include/karma_confix.hpp>
概要 
confix(prefix, suffix)[subject]
参数

参数

说明

prefix

用于格式化开头(前缀)的生成器构造. 前缀是在 之前生成的任何输出部分, 即由 subject 所生成的输出之前的部分.

suffix

用于格式化结尾(后缀)的生成器构造. 后缀是在 之后生成的任何输出部分, 即由 subject 所生成的输出之后的部分.

subject

用于格式化 prefix 与 suffix 部分之间实际输出的生成器构造.

这三个参数本身都可以是任意复杂的生成器.

属性

confix 组件把其主体的属性类型暴露为自己的属性类型. 若 subject 不暴露任何属性(类型为 unused_type), 则 confix 也不暴露任何属性.

a: A --> confix(p, s)[a]: A
注释

这种记法贯穿 Spirit 文档, 读作: 给定 a 为生成器, A 为生成器 a 的属性类型, 那么 confix(p, s)[a] 暴露的属性类型同样将是 A.

示例

下面的示例展示了 confix 生成器的一些简单用例. 我们将通过生成不同的注释风格和一个函数原型来说明其用法(完整示例代码见此处: confix.cpp)

前置条件

除了包含 Spirit.Karma 中实现的核心组件所需的主头文件外, 我们还要添加新的 confix 生成器所需的头文件.

#include <boost/spirit/include/karma.hpp>
#include <boost/spirit/repository/include/karma_confix.hpp>

为了让下面的代码更易读, 我们引入以下命名空间.

using namespace boost::spirit;
using namespace boost::spirit::ascii;
using boost::spirit::repository::confix;

生成不同的注释风格

我们将展示如何生成不同的注释风格. 首先生成一个 C++ 注释:

// C++ comment
std::cout <<
    karma::format_delimited(
        confix("//", eol)[string],            // format description
        space,                                // delimiter
        "This is a comment"                   // data
    ) << std::endl;

这段代码片段显然会生成 // This is a comment \n . 类似地, 生成 'C' 风格的注释也证明非常直接:

// C comment
std::cout <<
    karma::format_delimited(
        confix("/*", "*/")[string],           // format description
        space,                                // delimiter
        "This is a comment"                   // data
    ) << std::endl;

它同样会生成 /* This is a comment */ .

生成函数原型

给定函数名和一个参数名 vector, 生成函数原型同样简单:

// Generate a function call with an arbitrary parameter list
std::vector<std::string> parameters;
parameters.push_back("par1");
parameters.push_back("par2");
parameters.push_back("par3");

std::cout <<
    karma::format(
        string << confix('(', ')')[string % ','],   // format description
        "func",                                     // function name
        parameters                                  // parameter names
    ) << std::endl;

它生成预期的输出: func(par1,par2,par3).
