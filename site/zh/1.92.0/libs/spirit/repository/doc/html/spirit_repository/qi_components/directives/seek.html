Qi Seek 解析器指令

说明

seek[] 解析器指令会跳过所有输入, 直到主体解析器匹配.

头文件 
// forwards to <boost/spirit/repository/home/qi/directive/seek.hpp>
#include <boost/spirit/repository/include/qi_seek.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::repository::qi::seek

所属模型

UnaryParser

记法约定

a

一个 Parser.

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

seek[a]

前进直到解析器 a 匹配.
属性

参见 复合属性记法.

表达式

属性

seek[a] 

a: A --> seek[a]: A
a: Unused --> seek[a]: Unused
复杂度

总体复杂度由其主体解析器的复杂度决定. seek 本身的复杂度为 O(N), 其中 N 是不成功匹配的次数.

注释

带跳过的查找序列

把 seek[a >> b] 与跳过一起使用是低效的, 因为当序列失败时, 回溯到的位置是未经跳过的. 解决办法是确保输入总是被预先跳过, 例如:

seek[lexeme[skip[a >> b]]]

就能解决问题.

示例

下面的示例展示了 seek[] 指令的一个简单用例, 解析 C 风格注释.(本示例的完整源码见 seek.cpp)

一些命名空间别名:

namespace qi = boost::spirit::qi;
namespace repo = boost::spirit::repository;

输入字符串及其迭代器:

std::string str("/*C-style comment*/");
iterator it = str.begin();
iterator end = str.end();

解析并显示结果:

if (qi::parse(it, end, "/*" >> repo::qi::seek["*/"]))
{
    std::cout << "-------------------------------- \n";
    std::cout << "Parsing succeeded.\n";
    std::cout << "---------------------------------\n";
}
else
{
    std::cout << "-------------------------------- \n";
    std::cout << "Unterminated /* comment.\n";
    std::cout << "-------------------------------- \n";
}
