函数对象解析器

编写与 Spirit 库其余部分良好协作的手写解析器, 最简单的方式就是编写一个函数对象解析器(functor parser).

函数对象解析器应具有如下接口:

    struct functor
    {
        typedef T result_t;

        template <typename ScannerT>
        std::ptrdiff_t
        operator()(ScannerT const& scan, result_t& result) const;
    };

其中 typedef T result_t; 是解析器的属性类型, 会被传回给匹配结果(见 In-depth: The Parser). 若解析器不需要返回属性, 它可以就是 nil_t. std::ptrdiff_t 结果是你的解析器所匹配的字符数. 负值表示不成功的匹配.

一个合规的函数对象解析器, 通过包裹在 functor_parser 模板中, 即可变换为一个良构的 Spirit 解析器:

    functor_parser<functor> functor_p;

示例

以下示例让 functor_parser 投入使用:

    struct number_parser
    {
        typedef int result_t;
        template <typename ScannerT>
        std::ptrdiff_t
        operator()(ScannerT const& scan, result_t& result) const
        {
            if (scan.at_end())
                return -1;

            char ch = *scan;
            if (ch < '0' || ch > '9')
                return -1;

            result = 0;
            std::ptrdiff_t len = 0;

            do
            {
                result = result*10 + int(ch - '0');
                ++len;
                ++scan;
            } while (!scan.at_end() && (ch = *scan, ch >= '0' && ch <= '9'));

            return len;
        }
    };

    functor_parser<number_parser> number_parser_p;

完整源代码可 在此查看. 它是 Spirit 发行包的一部分.

要进一步理解其实现, 请见 In-depth: The Scanner 中的扫描器 API 细节. 现在我们拥有一个 number_parser_p 解析器, 可以像使用任何其他 Spirit 解析器一样使用它. 示例:

    r = number_parser_p >> *(',' >> number_parser_p);
