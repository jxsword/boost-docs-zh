位置迭代器

在编写能够检测输入流格式错误的解析器时, 我们常常希望它把错误发生在输入中的位置告知用户. 经典的例子是编写检测被解析程序语法错误的编译器或解释器, 指出行号, 甚至行内发现错误的位置.

position_iterator 类是 Spirit 提供的一个工具, 它让解析器作者可以轻松实现这一功能. 概念非常简单: 该类是一个迭代器包装器, 跟踪文件内的当前位置, 包括当前文件, 行与列. 它需要一个模板参数, 应当是要包装的迭代器的类型.

要使用它, 你需要添加以下包含:

    #include <boost/spirit/iterator/position_iterator.hpp>

或者包含 Spirit 中的所有迭代器:

    #include <boost/spirit/iterator.hpp>

构造该包装器时, 需要输入序列的 begin 和 end 迭代器以及输入序列的文件名. 你还可以可选地指定起始行号与列号, 它们默认为 1. 不带参数的默认构造会创建一个通用的序列末尾(end-of-sequence)迭代器, 与标准 C++ 库的流运算符的做法类似.

被包装的迭代器必须属于输入或前向迭代器类别, position_iterator 只是继承该类别.

例如, 要从一个输入 C 字符串创建 begin 和 end 位置迭代器, 可以这样:

    char const* inputstring = "...";
    typedef position_iterator<char const*> iterator_t;

    iterator_t begin(inputstring, inputstring+strlen(inputstring));
    iterator_t end;

操作

    void set_position(file_position const&);

当你需要改变迭代器中保存的当前位置时调用此函数. 例如, 解析 C 风格的 #include 指令时, 被包含文件的输入必须这样标记: 把文件与列重新置为 1 和 1, 名称置为新文件的名称.

    file_position const& get_position() const;

调用此函数以检索当前位置.

    void set_tabchars(int);

调用此函数设置每个制表符等效的字符数. 正确跟踪列号需要该值.

file_position

file_position 是一个保存文件内位置的结构体. 其字段为:

file_position 字段
std::string file; 文件名. 最好是完整路径名
int line; 文件内的行号. 默认情况下, 第一行是第 1 行
int column; 文件内的列位置. 第一列是 1

可编译的示例见 position_iterator.cpp. 它是 Spirit 发行包的一部分.
