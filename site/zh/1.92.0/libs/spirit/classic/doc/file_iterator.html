文件迭代器

由于 Spirit 是一个带回溯的解析器, 它至少需要前向迭代器. 特别地, 输入迭代器是不够的. 很多时候, 从文件中读取解析器的输入会很方便, 但 STL 的文件迭代器是输入迭代器. 为了绕过这一限制, Spirit 提供了实用类 file_iterator, 它是一个针对文件的只读随机访问迭代器.

要使用 Spirit 文件迭代器, 只需以你想解析的文件路径创建一个文件迭代器, 然后为该文件创建一个 EOF 迭代器:

    #include <boost/spirit/iterator/file_iterator.hpp> // the header file
    file_iterator<> first("input.dat");

    if (!first)
    {
       std::cout << "Unable to open file!\n";

       // Clean up, throw an exception, whatever
       return -1;
    }

    file_iterator<> last = first.make_end();

现在你就有了一对可与 Spirit 一起使用的迭代器. 若你的解析器是完全参数化的(没有硬编码的 <char const *>), 那么只需重新定义迭代器类型为 file_iterator 即可:

    typedef char                    char_t;
    typedef file_iterator <char_t>  iterator_t;
    typedef scanner<iterator_t>     scanner_t;
    typedef rule <scanner_t>        rule_t;

    rule_t my_rule;

    // Define your rule

    parse_info<iterator_t> info = parse(first, last, my_rule);

当然, 如果你使用文法而非规则作为 parse 函数的实参, 你完全不必理会 扫描器的琐事. 你只需原样传入迭代器对和文法:

    my_grammar g;
    parse_info<iterator_t> info = parse(first, last, g);
通用迭代器

Spirit 文件迭代器可以用任何可默认构造且可赋值的类型进行参数化. 在提供了相应接口的系统上, 它透明地支持大文件(大于 2GB). 文件迭代器在 Spirit 之外也很有用. 例如, Boost.Tokenizer 包需要一个双向迭代器, file_iterator 恰好提供.

可编译的示例见 file_parser.cpp. 它是 Spirit 发行包的一部分.
