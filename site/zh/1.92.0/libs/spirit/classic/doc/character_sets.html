字符集

字符集 chset 匹配一个有限范围内的字符集合, 该范围由其模板参数 CharT 的界限决定. 此类是对作用于单字符集合的解析器的一种优化. 该模板类以字符类型 CharT 参数化, 可高效处理 8, 16, 32 乃至 64 位字符.

    template <typename CharT = char>
    class chset;

chset 可由字面量(如 'x'), ch_p 或 chlit<>, range_p 或 range<>, anychar_p 与 nothing_p(见 原语)构造, 也可从另一个 chset 拷贝构造. chset 类采用写时复制(copy-on-write)方案, 使实例可以轻松地按值传递.

稀疏位向量

为兼容 16/32 和 64 位字符, 当字符类型不大于 8 位时, chset 类静态切换为 std::bitset 实现; 否则切换为使用不相交区间的有序向量(range_run)的稀疏位/布尔集合. 该集合由区间构成, 相邻或重叠的区间会被合并.

在存在大量区间而只有少量互不相交的单个值的情况下, range_runs 非常节省空间. 搜索复杂度为 O(log n), 其中 n 为区间数.

示例:

    chset<> s1('x');
    chset<> s2(anychar_p - s1);

此外, 字符集也可以使用定义字符串构造, 其语法类似 posix 风格的正则表达式字符集, 区别在于用双引号而非方括号界定集合元素, 且没有特殊的取反 ^ 字符.

    range = anychar_p >> '-' >> anychar_p;
    set = *(range_p | anychar_p);

由于我们使用 C 字符串定义集合, 通常的 C/C++ 字面量字符串语法规则同样适用. 示例:

    chset<> s1("a-zA-Z");       // alphabetic characters
    chset<> s2("0-9a-fA-F");    // hexadecimal characters
    chset<> s3("actgACTG");     // DNA identifiers
    chset<> s4("\x7f\x7e");     // Hexadecimal 0x7F and 0x7E

标准的 Spirit 集合运算符均适用(见 运算符), 另有一个额外的字符集专用的逆(取反 ~)运算符:

字符集运算符
~a 集合取逆
a | b 集合并集
a & 集合交集
a - b 集合差集
a ^ b 集合异或

其中操作数 a 与 b 都是 chsets, 或者其中一个操作数是字面量字符, ch_p 或 chlit, range_p 或 range, anychar_p 或 nothing_p. 针对 anychar_p 与 nothing_p 操作数提供了特殊的优化重载. nothing_p 操作数被转换为空集, 而 anychar_p 操作数被转换为一个具有所用字符类型全范围元素的集合(如对无符号 8 位字符为 0-255).

一种特殊情况是 ~anychar_p 产生 nothing_p, 但 ~nothing_p 是非法的. anychar_p 的取逆是不对称的, 是单行道, 类似于把 T* 转换为 void*.

特殊转换
chset<CharT>(nothing_p) 空集
chset<CharT>(anychar_p) CharT 的全范围(如对无符号 8 位字符为 0-255)
~anychar_p nothing_p
~nothing_p 非法
