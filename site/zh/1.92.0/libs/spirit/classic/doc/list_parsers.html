列表解析器

列表解析器由特殊的预定义解析器生成器对象 list_p 生成, 它生成识别如下类型列表结构的解析器

    item >> *(delimiter >> item) >> !end

其中 item 是一个表达式, delimiter 是分隔符, end 是可选的结尾表达式. 如你所见, list_p 生成的解析器不识别空列表, 即解析器必须在输入流中找到至少一个条目才能返回成功匹配. 若你还希望匹配空列表, 可以用 operator! 把你的 list_p 变为可选. 这个实用解析器的一个有用场景是解析以逗号分隔的 C/C++ 字符串, 可以方便地表述为:

    rule<> list_of_c_strings_rule
        =   list_p(confix_p('\"', *c_escape_char_p, '\"'), ',')
        ;

confix_p 与 c_escape_char_p 解析器生成器在 此处和 此处描述.

list_p 解析器生成器对象可用于生成以下几种不同类型的列表解析器:

列表解析器
list_p

list_p 单独使用时解析以逗号分隔, 无特殊条目格式的列表, 即两个逗号之间的所有内容都作为 item 匹配, 不匹配列表的 end 记号
list_p(delimiter)

生成一个列表解析器, 它识别以给定 delimiter 分隔的列表, 并把分隔符之间的所有内容作为 item 匹配, 不匹配列表的 end 记号
list_p(item, delimiter)

生成一个列表解析器, 它识别以给定 delimiter 分隔的列表, 并基于给定的条目解析器匹配条目, 不匹配列表的 end 记号
list_p(item, delimiter, end)

生成一个列表解析器, 它识别以给定 delimiter 分隔的列表, 基于给定的 item 解析器匹配条目, 另外还识别可选的 end 表达式

list_p 的所有参数可以是单个字符, 字符串, 或者在需要更复杂解析逻辑时的辅助解析器, 每一个都会被自动转换为成功解析所需的对应解析器类型.

若 item 解析器是 action_parser_category 类型(挂接了语义动作的解析器), 我们就得做一些特殊处理. 当用户写出如下代码时就会发生这种情况:

    list_p(item[func], delim)

其中 item 是匹配列表序列中一个条目的解析器, func 是在匹配一个条目之后要调用的函数对象. 如果我们什么都不做, 生成的代码将按如下方式解析该序列:

    (item[func] - delim) >> *(delim >> (item[func] - delim))

这在大多数情况下并非用户所期望.(如果这 正是你所期望的, 请使用 list_p 生成函数中的 direct(), 它会抑制对 item 解析器的重构). 为使列表解析器按预期行为工作:

    (item - delim)[func] >> *(delim >> (item - delim)[func])

挂接在条目解析器上的 actor 必须重新挂接到 (item - delim) 解析器构造上, 这将使生成的列表解析器 "做正确的事". 这一重构借助 重构解析器完成. 此外, 若条目解析器是 unary_parser_category 类型的解析器, 还须特别小心, 例如:

    list_p(*anychar_p, ',')

若不做任何重构, 将得到

        (*anychar_p - ch_p(','))
    >> *( ch_p(',') >> (*anychar_p - ch_p(',')) )

这不会给出预期的结果(第一个 *anychar_p 会吃掉直到输入流末尾的所有输入). 因此我们必须将其重构为:

       *(anychar_p - ch_p(','))
    >> *( ch_p(',') >> *(anychar_p - ch_p(',')) )

这样将给出正确的结果.

条目解析器同时兼具上述两类问题的情况(即条目解析器是挂接了动作的一元解析器)也会得到相应处理:

    list_p((*anychar_p)[func], ',')

将按预期被解析为:

        (*(anychar_p - ch_p(',')))[func]
    >> *( ch_p(',') >> (*(anychar_p - ch_p(',')))[func] )

所需的重构借助 重构解析器实现.

列表解析器重构小结
你这样写: It is refactored to:
list_p(item, delimiter) (item - delimiter)
>> *(delimiter >> (item - delimiter))
list_p(item[func], delimiter) (item - delimiter)[func]
>> *(delimiter >> (item - delimiter)[func])
list_p(*item, delimiter) *(item - delimiter)
>> *(delimiter >> *(item - delimiter))
list_p((*item)[func], delimiter) (*(item - delimiter))[func]
>> *(delimiter >> (*(item - delimiter))[func])

list_parser.cpp 示例展示了 list_p 实用解析器的用法:

  1. 解析以 ',' 分隔, 无条目格式的简单列表
  2. 解析 CSV 列表(逗号分隔值 —— 字符串, 整数或实数)
  3. 解析记号列表(记号分隔值 —— 字符串, 整数或实数)
    动作解析器直接挂接到 list_p 生成解析器的条目部分
