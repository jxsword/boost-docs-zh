转义字符解析器

转义字符解析器是一个实用解析器, 用于解析 C/C++, LEX 或 Perl 正则表达式中使用的转义字符序列. 与 confix_p 实用解析器组合, 它对于解析包含双引号及其他转义字符的 C/C++ 字符串非常有用:

    confix_p('"', *c_escape_ch_p, '"')

转义字符解析器有两种不同类型: c_escape_ch_p 解析 C/C++ 转义字符序列, lex_escape_ch_p 解析 LEX 风格的转义字符序列. 下表列出了这些实用解析器可理解的有效字符序列.

有效转义字符序列小结
c_escape_ch_p

\b, \t, \n, \f, \r, \\, \", \', \xHH, \OOO
其中: H 是某个十六进制数字(0..9, a..f, A..F), O 是某个八进制数字(0..7)
lex_escape_ch_p

如上所述的所有 C/C++ 转义字符序列, 外加反斜杠之后的任何其他字符

若转义字符解析器上直接挂接了语义动作, 则所有有效的转义字符都会被转换为其对应的字符(即反斜杠后跟 'r' 被转换为 '\r'), 并馈送给所挂接的 actor. 解析的十六进制或八进制数字的个数取决于单个输入字符的大小. 会检测溢出, 并将生成不匹配. 当把未转义的字符传递给所挂接的动作时, lex_escape_ch_p 会为所有未列入有效 C/C++ 转义序列的字符序列剥离前导反斜杠.

不过请注意, 若语义动作挂接在最外层解析器上(例如 (*c_escape_ch_p)[some_actor], 其中动作挂接到 kleene 星生成的解析器), 则目前不会发生转换, 但转义字符仍会被正确解析. 这一限制将在库的未来版本中移除.
