可移植性

从历史上看, Spirit 支持大量编译器, 包括(在一定程度上)兼容性欠佳的编译器, 如 VC6. Spirit v1.6.x 将是支持老旧低兼容性编译器的最后一个版本. 从 Spirit v1.8.0 起, 将不再支持低兼容性编译器. 如果你仍在使用这些旧编译器之一, 你仍然可以使用 Spirit v1.6.x.

Spirit v1.6.x 之所以能在旧的不合规编译器上工作, 是因为作者们不辞辛劳地寻找变通方法来取悦这些编译器. 这一过程耗费大量时间与精力, 尤其是当遇到可怕的 ICE(即 "Internal Compiler Error")时. 有时寻找单个变通方法就要花上数天甚至数周. 有时根本没有已知的变通方法. 这极大阻碍了进展. 而且, 随着库不断进步并采用更先进的 C++ 技术, 难度更是攀升到新的高度.

Spirit v1.6.x 仍将得到支持. 维护仍会进行, 缺陷修复仍会被应用. 把 Spirit v1.8.0(和 Spirit 1.9.0)中引入的新特性向后移植到能力较弱的编译器上, 仍将有积极的开发; 希望这能得到社区贡献的推动. 我们欢迎 C++ 社区的积极支持, 尤其是那些对旧 Borland 与 MSVC++ 编译器等具有专门专长的人士.

Spirit 1.8 已经过测试, 可在这些编译器上正确编译和运行:

  1. g++ 3.1 及以上
  2. Comeau 4.24.5
  3. MSVC 7.1
  4. Intel 7.1

如果你的编译器足够合规, 那么很有可能你可以原样编译 Spirit, 或只需在此处或彼处做少量可移植性修正. 如果你的编译器已知符合 ISO/ANSI 标准却不在上面的列表中, 请告知我们. 欢迎把反馈发送到 Spirit-general mailing list [Spirit-general@lists.sourceforge.net].
