空解析器
end_p 匹配 EOF iter,iter
eps_p
eps_p(P)		 不消耗文本地匹配 iter,iter
epsilon_p
epsilon_p(P)		 同义于 eps_p iter,iter
nothing_p 总是失败 iter,iter
字符解析器
alnum_p 匹配任何字母数字字符 char
alpha_p 匹配任何字母 char
anychar_p 匹配任意字符 char
blank_p 匹配空格或制表符 char
ch_p(char) 匹配一个字符 char
chset_p(charset) 匹配集合中的一个字符 char
cntrl_p 匹配任何控制字符 char
digit_p 匹配任何数字 char
f_ch_p(func) 匹配一个字符 char
f_range_p(func1, func2) 匹配闭区间内的任何字符 char
graph_p 匹配任何非空白的可打印字符 char
lower_p 匹配任何小写字母 char
print_p 匹配任何可打印字符 char
punct_p 匹配任何标点符号 char
range_p(char1, char2) 匹配闭区间内的任何字符 char
sign_p 匹配加号或减号 bool
space_p 匹配任何空白字符 char
upper_p 匹配任何大写字母 char
xdigit_p 匹配任何十六进制数字 char
数字解析器
bin_p 匹配无符号二进制整数 numeric
hex_p 匹配无符号十六进制整数 numeric
int_p 匹配有符号十进制整数 numeric
int_parser<type, base, min, max> 匹配带 min 至 max 位数字的有符号整数 numeric
oct_p 匹配无符号八进制整数 numeric
real_p 匹配浮点数 numeric
real_parser<type, policy> 匹配浮点数 numeric
strict_real_p 匹配浮点数(要求小数点) numeric
strict_ureal_p 匹配无符号浮点数(要求小数点) numeric
uint_p 匹配无符号十进制整数 numeric
uint_parser<type, base, min, max> 匹配带 min 至 max 位数字的无符号整数 numeric
ureal_p 匹配无符号浮点数 numeric
其他词法解析器
c_escape_ch_p 匹配一个 C 转义码 char
comment_p(string)
comment_p (string1, string2)		 匹配 C++ 或 C 风格注释 iter,iter
eol_p 匹配 CR, LF 或其任意组合 iter,iter
f_str_p(func1, func2) 匹配一个字符串 iter,iter
lex_escape_ch_p 匹配一个 C 转义码或任何反斜杠转义 char
regex_p(regex) 匹配一个正则表达式 iter,iter
str_p(string)
str_p(iter1, iter2)		 匹配一个字符串 iter,iter
文本解析器
chseq_p(string)
chseq_p(iter1, iter2)		 匹配一个字符串, 其中可能内嵌空白 iter,iter
f_chseq_p(func1, func2) 匹配一个字符串, 其中可能内嵌空白 iter,iter
 
复合解析器
confix_p(open, exp, close) 匹配 open >> (exp - close) >> close
do_p[P].while_p(cond) 在条件为真时匹配(至少一次)
for_p(init, cond, step)[P] 在循环中匹配
functor_parser<func> 包装一个外部解析器
if_p(cond)[P]
if_p(cond)[P].else_p[P]		 依据条件进行匹配
lazy_p(P) 在运行期对一个解析器求值
list_p
list_p(del)
list_p(item, del)
list_p(item, del, end)		 匹配一个带分隔符的列表
repeat_p(num)[P]
repeat_p(min, max)[P]
repeat_p(min, more)[P]		 匹配多次
while_p (cond) [P] 在条件为真时匹配
通用指令
as_lower_d[P] 在匹配之前把文本转换为小写
attach_action_d[(P1 op P2)[act]] 变换为 P1 [act] op P2 [act]
lexeme_d[P] 关闭空白跳过
limit_d[P](min, max) 仅当值位于范围内时匹配
longest_d[P] 匹配候选中最长的一个
max_limit_d[P](max) 匹配条件: value <= max
min_limit_d[P](min) 匹配条件: value >= min
refactor_action_d[P1 [act] op P2] 变换为 (P1 op P2) [act]
refactor_unary_d[op1 P1 op2 P2] 变换为 op1 (P1 op2 P2)
scoped_lock_d[P](mutex) 匹配期间锁定一个互斥体
shortest_d[P] 匹配候选中最短的一个
树专用指令
access_node_d[P] 把节点值传给动作
discard_first_node_d[P] 丢弃第一个节点
discard_last_node_d[P] 丢弃最后一个节点
discard_node_d[P] 丢弃生成的节点
infix_node_d[P] 丢弃偶数位置的节点
inner_node_d[P] 丢弃第一个和最后一个节点
leaf_node_d[P] 生成一个没有子节点的单一节点
no_node_d[P] 不生成节点
root_node_d[P] 为 AST 标识根节点
token_node_d[P] 同义于 leaf_node_d
一元运算符
!P 匹配 P 或空串
*P 把 P 匹配零次或多次
+P 把 P 匹配一次或多次
~P 匹配任何非 P
二元运算符
P1 % P2 匹配由 P2 分隔的一个或多个 P1
P1 - P2 匹配 P1 但不匹配 P2
P1 >> P2 匹配 P1 后跟 P2
P1 & P2 同时匹配 P1 与 P2
P1 ^ P2 匹配 P1 或 P2, 但不同时匹配两者
P1 | P2 匹配 P1 或 P2
P1 && P2 同义于 P1 >> P2
P1 || P2 匹配 P1 | P2 | P1 >> P2
