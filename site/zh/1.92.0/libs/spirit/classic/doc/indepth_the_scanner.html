深入: 扫描器

基本扫描器 API

class scanner
value_t typedef: 扫描器迭代器的值类型
ref_t typedef: 扫描器迭代器的引用类型
bool at_end() const 若输入已耗尽则返回 true
value_t operator*() const 从输入解引用/获取一个 value_t
scanner const& operator++() 向前移动扫描器
IteratorT& first 指向当前输入位置的迭代器. 以引用方式持有
IteratorT const last 指向输入末尾的迭代器. 以值方式持有

扫描器的基本行为由策略(policy)处理. 上表所列扫描器公开成员函数的实际执行由扫描器策略实现.

三组策略支配扫描器的行为. 这些策略使以非侵入方式扩展 Spirit 成为可能. 扫描器策略允许在不要求对代码做任何潜在不稳定修改的情况下扩展核心功能. 库作者可以提供自己的策略来覆盖已有策略, 从而微调解析过程以适应自身需要. 位于核心之上的层次也可能想利用这种基于策略的机制. 抽象语法树生成, 调试器和词法分析器都属此列.

有三组策略分别支配:

  • 迭代与过滤
  • 识别与匹配
  • 语义动作的处理

iteration_policy

以下是支配迭代与过滤的默认策略:

    struct iteration_policy
    {
        template <typename ScannerT>
        void
        advance(ScannerT const& scan) const
        { ++scan.first; }

        template <typename ScannerT>
        bool at_end(ScannerT const& scan) const
        { return scan.first == scan.last; }

        template <typename T>
        T filter(T ch) const
        { return ch; }

        template <typename ScannerT>
        typename ScannerT::ref_t
        get(ScannerT const& scan) const
        { return *scan.first; }
    };
迭代与过滤策略
advance 向前移动迭代器
at_end 若输入已耗尽则返回 true
filter 过滤从输入读入的一个字符
get 从输入读入一个字符

以下代码片段演示了一个把所有字符转换为小写的简单策略:

    struct inhibit_case_iteration_policy : public iteration_policy
    {
        template <typename CharT>
        CharT filter(CharT ch) const
        { 
            return std::tolower(ch); 
        }
    };

match_policy

以下是支配识别与匹配的默认策略:

    struct match_policy
    {
        template <typename T>
        struct result 
        { 
            typedef match<T> type; 
        };

        const match<nil_t>
        no_match() const
        { 
            return match<nil_t>(); 
        }

        const match<nil_t>
        empty_match() const
        { 
            return match<nil_t>(0, nil_t()); 
        }

        template <typename AttrT, typename IteratorT>
        match<AttrT>
        create_match(
            std::size_t         length,
            AttrT const&        val,
            IteratorT const&    /*first*/,
            IteratorT const&    /*last*/) const
        { 
            return match<AttrT>(length, val); 
        }

        template <typename MatchT, typename IteratorT>
        void
        group_match(
            MatchT&             /*m*/,
            parser_id const&    /*id*/,
            IteratorT const&    /*first*/,
            IteratorT const&    /*last*/) const {}

        template <typename Match1T, typename Match2T>
        void
        concat_match(Match1T& l, Match2T const& r) const
        { 
            l.concat(r); 
        }
    };
识别与匹配
result 一个元函数, 在给定属性类型时返回一个匹配类型(见 In-depth: The Parser)
no_match 创建一个失败的匹配
empty_match 创建一个空匹配. 空匹配是成功的 epsilon 匹配(匹配长度 == 0)
create_match 在给定匹配长度, 一个属性以及指向输入中匹配部分的迭代器对时, 创建一个匹配
group_match 对于规则等非终结符, 在成功完成匹配之后调用它, 以允许后处理
concat_match 拼接两个匹配对象

action_policy

动作策略只有一个用于处理语义动作的函数:

    struct action_policy
    {
        template <typename ActorT, typename AttrT, typename IteratorT>
        void
        do_action(
            ActorT const&       actor,
            AttrT const&        val,
            IteratorT const&    first,
            IteratorT const&    last) const;
    };

默认动作策略转发到:

    actor(first, last);

若属性 val 的类型为 nil_t. 否则:

    actor(val);

scanner_policies 混合器

scanner_policies 类把上述三个扫描器策略类组合为一个:

    template <
        typename IterationPolicyT   = iteration_policy,
        typename MatchPolicyT       = match_policy,
        typename ActionPolicyT      = action_policy>
    struct scanner_policies;

这个 混合器(mixer)类继承自所有三个策略. 这个 scanner_policies 类随后被用于参数化扫描器:

    template <
        typename IteratorT = char const*,
        typename PoliciesT = scanner_policies<> >
    class scanner;

扫描器反过来继承自 PoliciesT.

重绑定策略

可以让扫描器随时重绑定(rebind)到另一组策略. 它有一个成员函数 change_policies(new_policies). 在给定一组新策略时, 该成员函数用新策略集创建一个新扫描器. 重绑定后的扫描器的结果类型可以通过调用元函数获得:

    rebind_scanner_policies<ScannerT, PoliciesT>::type

重绑定迭代器

也可以让扫描器随时重绑定到不同的迭代器类型. 它有一个成员函数 change_iterator(first, last). 在给定一对与扫描器当前持有的类型不同的新迭代器时, 该成员函数用这对新迭代器创建一个新扫描器. 重绑定后的扫描器的结果类型可以通过调用元函数获得:

    rebind_scanner_iterator<ScannerT, IteratorT>::type
