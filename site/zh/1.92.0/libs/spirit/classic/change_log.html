  • 修复了 match<T&> 的编译问题. GH#275

  • 移除了 C++17 中已弃用的 std::iterator 的使用. GH#345

1.8.7

  • 将 Spirit V1.8.x 代码库与 Spirit V2 整合. Spirit V1.8.x 现已更名为 Spirit Classic. 尽管目录结构已经改变(Spirit Classic 头文件现已移至 '$BOOST_ROOT/boost/spirit/home/classic' 目录), 我们仍创建了转发头文件, 使现有应用程序无需任何修改即可编译. 不过这些转发头文件已被弃用, 将针对每个头文件生成相应的警告. 预计这些转发头文件将来会被移除.
    现在推荐的 Spirit Classic 使用方式是从 '$BOOST_ROOT/boost/spirit/include' 目录包含头文件. Spirit Classic 的所有文件名现在都带有 'classic_' 前缀. 例如, 包含

      #include <boost/spirit/core/core.hpp>

    现在应写为:

      #include <boost/spirit/include/classic_core.hpp>

    为避免与新 Spirit V2 库发生命名空间冲突, 我们将 Spirit Classic 移入了 namespace boost::spirit::classic. 只要使用了已弃用的包含文件, 此变更就会自动失效. 这保证了现有应用程序的完全向后兼容性.
    有关此变更的更多细节请查阅文档.

1.8.6

  • 修复了一个整数溢出缺陷, 该缺陷导致对某些大整数的解析未能失败. 此缺陷由 Michael Andersen Nexø 报告并修复

1.8.5

  • 出于性能考虑, leaf_node_d/token_node_d 已被改为可一次性创建叶节点的隐式词法元素(implicit lexem). 旧的 token_node_d 仍然可用, 现更名为 reduced_node_d.
  • 现在可以对 symbols::add 进行 phoenix::bind(版本 1).

1.8.4

  • 修复了 no_actions 缺陷, 即 no_action 被递归应用的问题.
  • 针对 Boost >= V1.33.0 修复了 regex_p 解析器
  • 针对 VC++ 在 Spirit 的 file_iterators 上存在的命名空间问题实现了一种变通方法
  • 修复了树匹配策略中阻止使用 gen_pt/ast_node_d 的缺陷, 由 Jascha Wetzel 报告.
  • 使 position_iterator 可用于基于 wchar_t 的字符串.

1.8.3

  • 由 Steve Clamage 修正了 Sun C++ 的配置(见 此链接).
  • 为 sizeof(int) != sizeof(ptr_type) 的 64 位平台修复了 multi_pass_iterator.修复了阻止在多入口点文法中使用闭包的缺陷, 由 David Pierre 报告
  • 修复了阻止嵌入多入口点文法的缺陷, 由 David Pierre 报告
  • 为 escape_ch_p 的有效转义字符集合添加了 '\0'.
  • 修复了以 phoenix::actor 作为条件表达式使用 switch_p 时的缺陷.
  • __LINE__ 宏现在会在 BOOST_SPIRIT_ASSERT_EXCEPTION 中展开
  • 修复了交集解析器中的一个缺陷, 由 Yusaku Sugai 报告
  • 符号解析器在内部使用空字符. 已添加检查以确保:
    • 若字符串包含空字符, tst.add 将触发断言
    • tst.find 不匹配输入中的空字符
  • 修复了 match_attr_traits.ipp 以允许非 POD 类型通过. 之前接受省略号 "..." 的版本不允许 POD 类型通过.
  • 允许将求值为 int 的表达式作为 if_p 解析器的条件.
  • 按 Stefan Slapeta 的建议对 PT/AST 代码应用了性能改进.
  • 修复了 AST 树节点指令(inner_node_d[]、discard_first_node[]、discard_last_node[] 和 infix_node_d[])的若干问题.

1.8.1(随 Boost 1.32.0 发布)

Spirit 1.8.1 发布仅为缺陷修复版本, 未引入任何新特性.

  • Spirit 现在要求至少 Boost 1.32.0 才能正确编译
  • 移除了对旧版迭代器适配器库的支持
  • 迁移为使用新的 MPL 库
  • Spirit 已迁移为使用 Boost Software License 1.0.
  • 修复了若干解析器以更正确地支持后置跳过(post-skip).
  • 修复了 no_node_d[] 的一个缺陷.
  • 修复了 shortest_d[] 中的一个缺陷.
  • 修复了 limit_d[] 中的一个缺陷.
  • 修复了解析器遍历元代码.
  • 修复了 switch_p 中的若干缺陷.
  • 修复了 AST 生成问题, 尤其是与循环相关的解析器.
  • 修复了 multi_pass 迭代器中的若干缺陷.
    • 修复了所使用的底层迭代器在解引用运算符中返回 value_type 而非引用时的问题.
    • 修复了 iterator_traits 问题
    • 修复了一个 EOI 问题
    • 修复了与 std::cin 一起使用时的缺陷
  • 发现了定义 BOOST_SPIRIT_SINGLE_GRAMMAR_INSTANCE 时 grammar.ipp 中的一个缺陷
  • 重写了 safe_bool 以使用 CRTP —— 现在在 MWCW 上也能工作, 并修复了实现中的若干缺陷.
  • 修复并扩展了解析树代码打印的调试诊断信息.
