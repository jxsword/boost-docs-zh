辅助解析器

表达式

属性

说明

eol

Unused

匹配行尾 (\r 或 \n 或 \r\n)

eoi

Unused

匹配输入结尾 (first == last)

eps

Unused

匹配空字符串

eps(b)

Unused

如果 b 为 true, 则匹配空字符串

lazy(fp)

P 的属性, 其中 P 是 fp 的返回类型

在解析时调用 fp, 返回一个解析器 p, 随后调用它进行解析.

fp

参见上文 lazy(fp)

等价于 lazy(fp)

attr(attrib)

Attrib

不消耗/解析任何输入, 但把参数 attrib 暴露为其属性.
