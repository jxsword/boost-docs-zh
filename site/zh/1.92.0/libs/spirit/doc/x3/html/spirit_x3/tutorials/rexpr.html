RExpressions - 递归 AST!

在本示例中, 我们将进一步探索如何创建层次化的 AST. 我们将解析一个极简的类 JSON 语言, 并把结果以树的形式编译到我们的数据结构中.

rexpr 是一个解析 RExpressions 的解析器. RExpressions 是一种类似 json 极小子集的语言, 仅限于字典(由 key=value 对组成), 其值本身可以是字符串或递归的字典.

下面是一个示例:

{
    "color" = "blue"
    "size" = "29 cm."
    "position" = {
        "x" = "123"
        "y" = "456"
    }
}

这个简单的 X3 解析器旨在作为一个最小起点. 它很精简, 却完备地包含了构成规则(和文法)所需的所有必要部分, 只是没有错误处理与报告.

该示例可在这里找到: rexpr.cpp

同一个解析器, 但完备地带有错误处理与报告、更好的文件组织、文法的分离编译以及完整的测试框架, 可在如下目录中找到:

rexpr/rexpr_full/

注释

rexpr_full 是作为使用 Spirit X3 编写解析器的最佳实践而提出的标准结构.

AST

AST 如下:

namespace client { namespace ast
{
    namespace x3 = boost::spirit::x3;

    struct rexpr;

    struct rexpr_value : x3::variant<
            std::string
          , x3::forward_ast<rexpr>
        >
    {
        using base_type::base_type;
        using base_type::operator=;
    };

    typedef std::map<std::string, rexpr_value> rexpr_map;
    typedef std::pair<std::string, rexpr_value> rexpr_key_value;

    struct rexpr
    {
        rexpr_map entries;
    };
}}

x3::variant 是 Spirit X3 中的一个支撑工具, 用于扩展 Boost.Variant. 通常, 你直接开箱使用 Boost.Variant, 并用 typedef 引用某个特定的模板实例. 例如:

typedef boost::variant<std::string, int> my_variant;

我们没有那样做, 而是创建了一个 class (在本例中是 struct), 它继承自 x3::variant. 让 variant 成为子类, 你就在自己的命名空间中拥有了一个独立的类型. 你还可以掌控构造函数和赋值运算符, 并获得添加更多功能的自由.

rexpr_value 有两个 variant 成员: 它要么是一个 std::string, 要么是一个 rexpr. 由于 rexpr 递归地包含一个 rexpr_value, 它必须前向声明. 这一递归数据结构要求把 rexpr 包装在一个 x3::forward_ast 中, 如声明所示.

我们需要把我们的 rexpr struct 告知 fusion, 使其成为一等 fusion 公民:

BOOST_FUSION_ADAPT_STRUCT(
    client::ast::rexpr,
    entries
)

因此, 从本质上说, 一个 rexpr_value 值要么是一个 std::string, 要么是一个 std::map<std::string, rexpr_value>.

遍历 AST

我们添加一个用于打印 AST 的工具:

int const tabsize = 4;

struct rexpr_printer
{
    typedef void result_type;

    rexpr_printer(int indent = 0)
      : indent(indent) {}

    void operator()(rexpr const& ast) const
    {
        std::cout << '{' << std::endl;
        for (auto const& entry : ast.entries)
        {
            tab(indent+tabsize);
            std::cout << '"' << entry.first << "\" = ";
            boost::apply_visitor(rexpr_printer(indent+tabsize), entry.second);
        }
        tab(indent);
        std::cout << '}' << std::endl;
    }

    void operator()(std::string const& text) const
    {
        std::cout << '"' << text << '"' << std::endl;
    }

    void tab(int spaces) const
    {
        for (int i = 0; i < spaces; ++i)
            std::cout << ' ';
    }

    int indent;
};

遍历 AST 是一个递归过程. rexpr_printer 是一个函数对象, 其主入口是 void operator()(rexpr const& ast). 注意它如何对每个键值对使用 boost::apply_visitor 递归地调用自身的实例. 在遍历 map 中的所有元素之前和之后, 都会打印花括号以包围整个主体, 并在递归遍历的每个位置注意正确的缩进.

operator() 用于 std::string, 应当不言自明: 它只是打印双引号内的文本.

文法 
namespace client { namespace parser
{
    namespace x3 = boost::spirit::x3;
    namespace ascii = boost::spirit::x3::ascii;

    using x3::lit;
    using x3::lexeme;

    using ascii::char_;
    using ascii::string;

    x3::rule<class rexpr_value, ast::rexpr_value>
        rexpr_value = "rexpr_value";

    x3::rule<class rexpr, ast::rexpr>
        rexpr = "rexpr";

    x3::rule<class rexpr_key_value, ast::rexpr_key_value>
        rexpr_key_value = "rexpr_key_value";

    auto const quoted_string =
        lexeme['"' >> *(char_ - '"') >> '"'];

    auto const rexpr_value_def =
        quoted_string | rexpr;

    auto const rexpr_key_value_def =
        quoted_string >> '=' >> rexpr_value;

    auto const rexpr_def =
        '{' >> *rexpr_key_value >> '}';

    BOOST_SPIRIT_DEFINE(rexpr_value, rexpr, rexpr_key_value);
}}

我们声明三条规则: rexpr_value、rexpr 和 rexpr_key_value. 与之前如出一辙. 为每条规则声明的属性正是我们在上文 AST 中声明的那些结构. 这些就是我们的规则将产生的结构.

于是, 自顶向下(从起始规则开始), rexpr 被定义为花括号内零个或多个 rexpr_key_value. 这就是 kleene 星号的运用: *rexpr_key_value.

注释

请注意这一约定: 我们用 rexpr 名称作为规则名, 用 rexpr_def 作为规则定义名.

为了让文法整洁, 我们捕获 quoted_string 产生式, 这里用到 C++ auto.

rexpr_value 是一个 quoted_string, 后随赋值运算符 '=', 再后随一个 rexpr_value. rexpr_value 是一个 quoted_string 或 一个 rexpr. 这使用了备选运算符 |, 并且与规则所关联的 variant AST 映射得非常自然.

最后, 我们把规则与其定义关联起来:

BOOST_SPIRIT_DEFINE(rexpr_value, rexpr, rexpr_key_value);
