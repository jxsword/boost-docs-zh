原语组件的属性

Spirit 中的解析器是完全属性化的. Spirit.X3 的解析器总是 暴露 一个与其类型相关的属性. 这称为 合成属性, 因为它在成功匹配后返回, 表示被匹配的输入序列. 例如, 诸如 int_ 或 double_ 之类的数值解析器, 会返回由匹配到的输入序列转换而来的 int 或 double 值. 其他基础解析器组件具有其他直观的属性类型, 例如 int_ 的属性为 int, 而 ascii::char_ 的属性为 char. 基础解析器应用常规的 C++ 可转换性规则: 只要解析器的属性类型可转换为所提供的类型, 你就可以使用任何 C++ 类型来接收解析得到的值. 下面的示例展示了如何提取解析器的合成属性 (即 int 值), 提取方式是调用 API 函数 x3::parse:

int value = 0;
std::string str("123");
std::string::iterator strbegin = str.begin();
x3::parse(strbegin, str.end(), int_, value);   // value == 123

有关可用解析器原语及其属性类型的完整列表, 请参阅 X3 Parsers 各节.
