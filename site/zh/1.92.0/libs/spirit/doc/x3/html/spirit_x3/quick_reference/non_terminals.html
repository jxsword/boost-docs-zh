记法约定

Attr

合成属性. 即规则的返回类型.

ID

规则的 ID

r, r2

规则

r_def, r2_def

规则定义. 按照惯例, 名为 r 的规则应当有一个对应的、名为 r_def 的规则定义

p

一个解析器表达式

表达式

说明

rule<ID, Attr> const r = name;

规则声明. ID 是必需的. Attr 是可选的, 默认为 unused_type. name 是一个可选字符串, 用于给规则命名, 对调试和错误处理很有用.

r.name()

获取 rule 的名称

auto const r_def = p;

rule 定义

BOOST_SPIRIT_DEFINE(r, r2, ...)

将一条或多条规则 (r, r2, ...) 与它们的定义 (r_def, r2_def, ...) 关联起来
