Spirit V3.0.6 (Boost V1.73.0)

  • ADL 曾被用来查找并匹配 unused_type 流运算符, 适用于 boost::spirit::x3 命名空间中的每个类型 GH#553 GH#552
  • 不再依赖 Boost.TTI
  • 规则占位符现在是非平凡类型, 因为其拷贝构造函数会检查静态初始化灾难问题 GH#571
  • 大多数解析器现在可 constexpr 构造 GH#570
