Spirit V3.0.8 (Boost V1.76.0)

  • 修复了标准解析器在输入包含扩展字符集字符 (值高于 0x7F) 时的断言 GH#620
  • 增强调试输出以十六进制打印 Unicode 码点 GH#634
  • 在 parse_rule 中跳过规则定义绑定器的创建 GH#646
  • 以 std 中的对应实现替换 Boost.Math GH#648
  • 修复了 get<typename> 在 parse_rule 中的非限定调用问题
  • 移除了未使用的头文件 no_case_string_parse.hpp
  • 使字面量二进制解析器的构造函数不再为模板
  • 修复了 get<typename> 在 annotate_on_success::on_success 中的非限定调用问题 GH#526
  • 修复了多次遗漏 force_attribute 参数的问题. 该修复解决了当 force_attribute 被设为 true 时, 因规则定义注入上下文而导致的编译错误与编译缓慢问题 GH#651
  • 当规则占位符被构造后立即消耗时(如 auto const grammar = rule<tag>{} = parser), 跳过向上下文注入规则定义 GH#650
