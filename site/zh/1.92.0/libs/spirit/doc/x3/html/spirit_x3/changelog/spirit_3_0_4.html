Spirit V3.0.4 (Boost V1.70.0)

  • 整数解析器现在应能处理用户定义类型. GH#429
  • 注意: check_overflow 特征的默认实现现在依赖 std::numeric_limits<T>::is_bounded 而不是 boost::integer_traits<T>::is_integral.
  • 移除了对已弃用的 boost/detail/iterator.hpp 头文件的使用. GH#432
  • 移除了将序列解析为普通属性的支持. 现在此时会触发编译期错误, 而不是静默地解析该序列并将最后一个值作为结果. GH#439
  • 修复了在下列情况下将 parse_rule 与 BOOST_SPIRIT_INSTANTIATE 一同实例化的问题:
    • 规则没有属性的问题. GH#455
    • 实际属性不属于规则声明时所指定的类型. GH#456 GH#457
  • 向各位致以巨大的感谢, 感谢 Xeverous 报告了 GH#453 中的回归问题.
  • 修复了规则中不必要的属性合成以及无变换属性引用直通的问题. GH#444 GH#449 GH#452
  • 移除了损坏的 1.0#INF 解析器. 它文档匮乏且从未正常工作. GH#415 GH#458 TRAC#8699
  • 未列入文档的 make_attribute 特征因缺陷 GH#449 以及简化属性变换的需要而被移除. GH#460
  • 如果你此前用它来规避属性变换中的缺陷, 那么从本版本起应该不再需要它了.
  • 整数值解析器现在遵循 std::numeric_limits<T>::digits10 值. GH#469
  • 修复了 (Min % Base) == 0 边界情况的下溢检查. GH#469
  • 修复了 IgnoreOverflowDigits=true 整数解析器溢出时的输出值问题. GH#470
  • 容器属性元素此前是被复制而非移动. GH#472
  • 移除了 transform_attribute 中对引用的特殊处理. GH#480
