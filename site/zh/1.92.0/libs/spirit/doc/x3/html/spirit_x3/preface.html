如何使用本手册

本文档大致分为 3 个部分:

  1. 教程: 带有大量注释代码的分步指南. 旨在让用户尽快熟悉该库. 目标是通过丰富的示例和详细的说明建立用户使用该库的信心. 示例胜过千言万语, 而我们有大量的示例!
  2. 摘要: 关键主题的高层次总结. 目标是让用户对该库、关键概念、背景和理论有一个高层次的认识.
  3. 参考: 详细的正式技术参考. 我们从快速参考开始 -- 一个易于使用的表, 映射到参考正文. 参考正文从 C++ 概念开始, 随后是这些概念的模型.
