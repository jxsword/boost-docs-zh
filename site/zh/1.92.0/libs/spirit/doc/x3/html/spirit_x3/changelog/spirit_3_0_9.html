Spirit V3.0.9 (Boost V1.77.0)

  • 破坏性变更*: 可选解析器不再对序列做扁平化还原, 像 int_ >> -(int_ >> int_) 解析到 tuple<int, optional<int>, optional<int>> 这类用法在序列解析器中会产生编译错误. 这原本属于一种“缺陷特性”, 或许会在将来重新实现.
  • 修复了序列解析器中带有无属性主体的列表解析器问题. GH#663
  • 修复了序列解析器中带容器属性的可选解析器问题. GH#665
  • 修复了 error_handler 的换行/空白处理问题. GH#669 GH#670
  • 修复了 seek[...] 指令越过输入末尾的问题, 该问题由 GH#30 引入, 在预跳过后不剩任何数据时触发. GH#658 GH#683
  • 移除了规则中的回滚, 以修复 GH#670 引入的回归. GH#686
