Spirit V3.0.1 (Boost V1.67.0)

Boost V1.56.0-1.66.0 各发布版本没有版本号提升, 也没有变更日志.

  • 移除了 with_context. GH#239
  • 为 x3::variant 和 forward_ast 添加了 noexcept. GH#241
  • error_handler::position() 中 CR+LF 行的计数错误. GH#248
  • 修复了 unused_type 在 parse_into_container 中的属性情形. GH#266
  • 修复了解析到关联容器的问题. GH#289
  • 修复了 uint_parser<signed T> 中的溢出问题. GH#297
  • 通过变通方法添加了对 VS2015 Update 3 的支持. GH#308
  • 修复了包含保护宏名与 Qi 的冲突. GH#313
  • 添加了向范围 (range) 解析的支持. GH#316 TRAC#12928
  • 将迭代器概念的静态断言从 ForwardIterator 改为 ReadableIteratorConcept && ForwardTraversalConcept. GH#320
  • 重新启用了 fusion::map 支持. GH#330
  • 将 string("...") 和 attr("...") 修复为单项序列. GH#337
  • 解引用单项视图, 而不是解包序列. GH#340
  • 防止 parse_nan 解引用超出范围的迭代器. GH#351
  • 使用特征 (traits) 测试容器是否为空. GH#355
