Include

Spirit 是一个仅头文件库, 无需链接任何库. 要使用 Spirit X3, 只需包含:

#include <boost/spirit/home/x3.hpp>

要区分 Spirit 版本, 你可以查看版本文件:

#include <boost/spirit/home/x3/version.hpp>

使用预处理器定义

SPIRIT_X3_VERSION

它是一个十六进制数, 前两位决定主版本, 后两位决定次版本. 例如:

#define SPIRIT_X3_VERSION 0x3010 // version 3.10
