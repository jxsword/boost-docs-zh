解析器运算符

表达式

属性

说明

非谓词 !a

Unused

非谓词. 如果谓词 a 匹配, 则失败; 否则返回一个零长度匹配.

与谓词 &a

Unused

与谓词. 如果谓词 a 匹配, 则返回一个零长度匹配; 否则失败.

可选 -a

optional<A>

可选. 解析 a 零次或一次

Kleene *a

vector<A>

Kleene. 解析 a 零次或多次

Plus +a

vector<A>

加. 解析 a 一次或多次

备选 a | b

variant<A, B>

备选. 解析 a 或 b

序列 a >> b

tuple<A, B>

序列. 解析 a, 随后是 b

期望运算符 a > b

tuple<A, B>

期望. 解析 a, 随后是 b. b 应当在 a 匹配时也匹配, 否则抛出 expectation_failure.

差 a - b

A

差. 解析 a 但不解析 b

列表 a % b

vector<A>

列表. 解析 a (以 b 分隔) 一次或多次
