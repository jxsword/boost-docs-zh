symbols<T>

N/A

声明一个符号表 sym. T 是与每个键关联的数据类型.

 

sym.add
    (str1, val1)
    (str2, val2)
    /*...more...*/
;

N/A

向符号表 sym 添加符号. val1 和 val2 是类型为 T 的可选数据, 即与每个键关联的数据类型.

sym

T

匹配符号表 sym 中的条目. 如果成功, 返回与该键关联的数据
