快速入门

为什么你会想使用 Spirit.X3?

Spirit.X3 的设计目标是一个实用的解析工具. 从内联在 C++ 中的正式 EBNF 规范生成完全可用的解析器, 这一能力显著缩短开发时间. 程序员通常借助 scanf 这类原始工具, 用临时拼凑的技巧来处理解析. 即便是正则表达式库(如 boost regex)或扫描器(如 Boost tokenizer), 在我们需要编写更精细的解析器时也难以扩展. 用这些工具尝试编写哪怕中等复杂度的解析器, 都会导致难以理解和维护的代码.

一个首要目标是让这个工具易于使用. 当人们想到解析器生成器时, 通常的反应是 "它一定又大又复杂, 学习曲线陡峭". 事实并非如此. Spirit 被设计为完全可伸缩的. 该库按层组织. 这允许在只学习最小核心和基本概念之后, 按需学习.

为了开发简单和部署方便, 整个库仅由头文件组成, 无需链接或构建任何库. 只需把 Spirit 发行包放进你的 include 路径, 编译并运行即可. 代码大小? -- 非常紧凑 -- 基本与手写的递归下降代码相当.

我们的教程将带你了解最简单的 Spirit 示例, 在我们展示越来越多的特性和技术时, 在先前示例的基础上逐步递进. 我们会尽量让学习曲线平缓. 我们将以食谱 (cookbook) 风格呈现教程. 这种呈现方式基于我们的 BoostCon '07 和 BoostCon '08 幻灯片.
