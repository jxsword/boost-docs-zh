Spirit V3.0.7 (Boost V1.74.0)

  • 不再依赖 Boost.Locale (将 locale::conv::utf_to_utf 替换为 x3::to_utf8) 以及 Boost.Filesystem GH#596
  • 修复了 is_substitute 特征中的无限递归, 该递归曾会阻塞经由容器的递归序列 GH#461 GH#606
  • 修复了备选组件中序列解析器向容器解析的问题 GH#434 GH#605
  • 修复了带容器属性的备选解析器中的一些边角情况, 特别是其中无属性的解析器会追加一个空值的问题 GH#394 GH#603 GH#604
  • 备选/序列解析器的属性类型现在无需 MPL 即可计算, 从而消除了 MPL 对备选/序列解析器链长度的限制 GH#515 GH#607
  • 回退了 GH#534, 该改动曾使 optional<T> 能够解析到 T GH#608
  • 移除了多余的 reserve (位于 insert 之前) GH#611
  • 移除了 value_initialize 特征 GH#613
  • 移除了因错误使用 pseudo_attribute 而产生的多余移动, 该问题还曾引发 GCC 的虚假 -Wununinitlized 警告 GH#613
  • 移除了未使用的 boost/spirit/home/x3/support/utility/unrefcv.hpp 头文件
