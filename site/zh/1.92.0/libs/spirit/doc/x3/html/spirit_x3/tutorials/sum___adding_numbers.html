求和 - 把数字相加

下面是一个把以逗号分隔的数字列表求和的解析器.

好, 我们在先前的示例中略过了一些细节. 首先是我们的 include:

#include <boost/spirit/home/x3.hpp>
#include <iostream>
#include <string>

然后是一些 using 指令:

namespace x3 = boost::spirit::x3;
namespace ascii = boost::spirit::x3::ascii;

using x3::double_;
using ascii::space;
using x3::_attr;

下面是真正的解析器:

template <typename Iterator>
bool adder(Iterator first, Iterator last, double& n)
{
    auto assign = [&](auto& ctx){ n = _attr(ctx); };
    auto add = [&](auto& ctx){ n += _attr(ctx); };

    bool r = x3::phrase_parse(first, last,

        //  Begin grammar
        (
            double_[assign] >> *(',' >> double_[add])
        )
        ,
        //  End grammar

        space);

    if (first != last) // fail if we did not get a full match
        return false;
    return r;
}

本示例完整的 cpp 文件可在这里找到: sum.cpp

这几乎和我们最初的数字列表示例一样. 我们在示例的基础上逐步递进. 不过这次, 就像复数示例一样, 我们要加入智能. 有一个累加器 (double& n) 把解析出的数字相加. 解析成功时, 这个数字就是所有解析出的数字之和.

第一个 double_ 解析器附加了这个动作:

[&](auto& ctx){ n = _attr(ctx); }

这会把解析结果(实际上是 double_ 的属性)赋给 n. 第二个 double_ 解析器附着了这个动作:

[&](auto& ctx){ n += _attr(ctx); }

于是, 后续的数字累加进 n.
