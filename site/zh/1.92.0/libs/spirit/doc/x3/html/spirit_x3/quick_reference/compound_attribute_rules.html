复合属性规则

记法约定

我们将使用的记法形如:

a: A, b: B, ... --> composite-expression: composite-attribute

a, b 等是操作数. A, B 等是操作数的属性类型. composite-expression 是涉及这些操作数的表达式, 而 composite-attribute 是该复合表达式的结果属性类型.

例如:

a: A, b: B --> (a >> b): tuple<A, B>

读作: 给定 a 和 b 是解析器, A 是 a 的属性类型, B 是 b 的属性类型, 则 a >> b 的属性类型将是 tuple<A, B>.

重要

在属性表中, 我们只把 vector<A> 和 tuple<A, B...> 用作占位符. 记法 vector<A> 表示 任意 STL 容器, 其中保存 A 类型的元素; 记法 tuple<A, B...> 表示 任意 Boost.Fusion 序列, 其中保存 A、B 等元素. 最后, Unused 表示 unused_type.
