字符生成器(char_, lit)
说明

本节描述的字符生成器是:

char_ 生成器输出单个字符. char_ 生成器有一个关联的 字符编码命名空间. 在执行强制小写或大写以及处理字符范围等基本操作时需要它.

char_ 有多种形式.

char_

char_ 的无实参形式输出关联 字符编码命名空间 中的任意字符.

char_               // emits any character as supplied by the attribute
char_(ch)

char_ 的单实参形式(带一个字符实参)输出所提供的字符.

char_('x')          // emits 'x'
char_(L'x')         // emits L'x'
char_(x)            // emits x (a char)
char_(first, last)

带两个实参的 char_ 输出属性所提供字符范围中的任意字符.

char_('a','z')      // alphabetic characters
char_(L'0',L'9')    // digits

字符范围由低-高字符对创建. 这类生成器输出范围内(包括两个端点)的单个字符. 注意, 第一个字符必须 先于 第二个字符, 这是按照底层 字符编码命名空间.

字符映射本质上是平台相关的. 例如, 标准并不保证 'A' < 'Z', 这就是为什么在 Spirit2 中, 我们特意把一个特定的 字符编码命名空间 (例如 ASCII, ISO-8859-1) 附加到 char_ 生成器, 以消除这类歧义.

注释

稀疏位向量

为了容纳 16/32 和 64 位字符, 当字符类型不大于 8 位时, 字符集从 std::bitset 实现静态切换为使用不相交范围的有序向量的稀疏位/布尔集(range_run). 该集合由范围构造, 相邻或重叠的范围会被合并.

range_runs 在存在大量范围和少量单个不相交值的情况下非常节省空间. 查找复杂度为 O(log n), 其中 n 是范围的数量.

char_(def)

最后, 当给定一个字符串 (普通 C 字符串, std::basic_string 等)时, 该字符串会被视为字符集定义字符串, 其语法类似于 posix 风格的正则表达式字符集 (不同之处在于用双引号而不是方括号界定集合元素, 且没有特殊的取反 ^ 字符). 示例:

char_("a-zA-Z")     // alphabetic characters
char_("0-9a-fA-F")  // hexadecimal characters
char_("actgACTG")   // DNA identifiers
char_("\x7f\x7e")   // Hexadecimal 0x7F and 0x7E

这些生成器输出属性所提供字符范围中的任意字符.

lit(ch)

当传递单个字符时, lit 的行为类似于单实参的 char_, 区别在于 lit 不消耗属性. 普通的 char 或 wchar_t 等价于 lit.

注释

lit 被 字符串生成器, 字符生成器和数值生成器复用 (参见 有符号整数, 无符号整数 和 实数 生成器). 一般来说, 传入字符时创建字符生成器, 传入字符串时创建字符串生成器, 使用数值字面量时创建数值生成器. 例外是传入单元素字面量字符串时, 例如 lit("x"). 在这种情况下, 我们对其进行优化, 创建字符生成器而不是字符串生成器.

示例:

'x'
lit('x')
lit(L'x')
lit(c)      // c is a char
头文件

#include <boost/spirit/include/karma_char_.hpp>

名称

所属模型

PrimitiveGenerator

记法约定

ch, ch1, ch2

字符类特定的字符 (参见字符类类型), 或求值为字符类特定字符值的 惰性实参

cs

字符集说明字符串 (参见字符类类型), 或求值为字符集说明字符串的 惰性实参, 或指向以 null 结尾的字符数组的指针/引用. 该字符串规定一个字符集定义字符串, 其语法类似于 posix 风格的正则表达式字符集 (除方括号和取反字符 ^ 外).

ns

一个 字符编码命名空间.

cg

字符生成器, 字符范围生成器或字符集生成器.

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

说明

ch

生成字符字面量 ch. 该生成器从不失败 (除非底层输出流报告错误).

lit(ch)

生成字符字面量 ch. 该生成器从不失败 (除非底层输出流报告错误).

ns::char_

生成由必需属性提供的字符, 按由 ns 定义的字符集解释. 该生成器从不失败 (除非底层输出流报告错误).

ns::char_(ch)

生成字符 ch, 来自生成器初始化时使用的直接字面量值. 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.

ns::char_("c")

生成字符 c, 来自生成器初始化时使用的直接字面量值. 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.

ns::char_(ch1, ch2)

生成由必需属性提供的字符, 按由 ns 定义的字符集解释. 只要属性属于字符范围 [ch1, ch2], 生成器就成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.

ns::char_(cs)

生成由必需属性提供的字符, 按由 ns 定义的字符集解释. 只要属性属于字符集 cs, 生成器就成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.

~cg

对 cg 取反. 结果是一个取反的字符生成器, 它反转其所附加字符生成器的测试条件.

如果字符 ch 属于由 ns::char_(ch1, ch2) 定义的字符范围 -- 即其字符值 (二进制表示)按由 ns 定义的字符集解释后, 不小于 ch1 的字符值且不大于 ch2 的字符值 (即 ch1 <= ch <= ch2) -- 则视为属于该范围.

charset 参数 (传递给 ns::char_(charset)) 必须是一个包含多于一个字符的字符串. 该字符串中的每个字符都假定属于此表达式定义的字符集. 例外是 '-' 字符, 如果它不是 charset 中指定的第一个字符且不是最后一个字符, 则具有特殊含义. 如果 '-' 用于两个字符之间, 则它被解释为跨越一个字符范围. 如果字符 ch 匹配上述字符串参数指定的字符之一, 则视为属于定义的字符集 charset. 例如

属性

表达式

属性

ch

unused

lit(ch)

unused

ns::char_

Ch, 属性是必需的 (否则编译将失败). Ch 是 字符编码命名空间 的字符类型, 即 ns.

ns::char_(ch)

Ch, 属性是可选的, 如果提供了, 生成器会把属性与 ch 比较, 仅当两者相等时成功, 否则失败. Ch 是 字符编码命名空间 的字符类型, 即 ns.

ns::char_("c")

Ch, 属性是可选的, 如果提供了, 生成器会把属性与 c 比较, 仅当两者相等时成功, 否则失败. Ch 是 字符编码命名空间 的字符类型, 即 ns.

ns::char_(ch1, ch2)

Ch, 属性是必需的 (否则编译将失败), 如果属性属于字符范围 [ch1, ch2] (按由 ns 定义的字符集解释), 则生成器成功. Ch 是 字符编码命名空间 的字符类型, 即 ns.

ns::char_(cs)

Ch, 属性是必需的 (否则编译将失败), 如果属性属于字符集 cs (按由 ns 定义的字符集解释), 则生成器成功. Ch 是 字符编码命名空间 的字符类型, 即 ns.

~cg

cg 的属性
注释

除了它们通常的 Ch 类型属性之外, 所有列出的生成器还接受 boost::optional<Ch> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 Ch 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

复杂度

O(1)

ch, lit(ch), ns::char_, ns::char_(ch) 和 ns::char_("c") 的复杂度是常量, 因为所有生成器每次调用恰好输出一个字符.

字符范围生成器 (ns::char_(ch1, ch2)) 还要求常量查找时间来验证属性是否属于字符范围.

字符集生成器 (ns::char_(cs)) 还要求 O(log N) 查找时间来验证属性是否属于字符集, 其中 N 是字符集中的字符数量.

char_ 生成器的基本用法:

test_generator("A", 'A');
test_generator("A", lit('A'));

test_generator_attr("a", char_, 'a');
test_generator("A", char_('A'));
test_generator_attr("A", char_('A'), 'A');
test_generator_attr("", char_('A'), 'B');         // fails (as 'A' != 'B')

test_generator_attr("A", char_('A', 'Z'), 'A');
test_generator_attr("", char_('A', 'Z'), 'a');    // fails (as 'a' does not belong to 'A'...'Z')

test_generator_attr("k", char_("a-z0-9"), 'k');
test_generator_attr("", char_("a-z0-9"), 'A');    // fails (as 'A' does not belong to "a-z0-9")
