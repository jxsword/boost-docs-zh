Sequence 生成器(a << b)
说明

生成器序列用于把不同的, 更原始的生成器连续组合起来. 序列中的所有生成器从左到右依次调用, 只要它们成功就继续.

头文件 
// forwards to <boost/spirit/home/karma/operator/sequence.hpp>
#include <boost/spirit/include/karma_sequence.hpp>

另请参见 包含结构.

所属模型

NaryGenerator

表达式语义

仅当表达式的语义与 NaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

a << b

生成器 a 和 b 从左到右依次执行, 只要它们成功就继续. 失败的生成器会停止整个序列的执行, 并使序列也失败.

需要注意的重要一点是, 序列不会对其元素生成的输出执行任何缓冲. 这意味着任何失败的序列可能已经生成了一些输出, 这些输出 不会 被回滚.

提示

强制序列表现得像有缓冲一样的最简单方法是把它包装进一个缓冲指令中 (参见 buffer):

buffer[a << b << c]

在序列失败的情况下, 它将 不 生成任何输出.

属性

参见 复合属性记法.

表达式

属性

a << b (序列)

 

a: A, b: B --> (a << b): tuple<A, B>
a: A, b: Unused --> (a << b): A
a: Unused, b: B --> (a << b): B
a: Unused, b: Unused --> (a << b): Unused

a: A, b: A --> (a << b): vector<A>
a: vector<A>, b: A --> (a << b): vector<A>
a: A, b: vector<A> --> (a << b): vector<A>
a: vector<A>, b: vector<A> --> (a << b): vector<A>
重要

上表仅把 tuple<A, B> 和 vector<A> 用作占位符.

记法 tuple<A, B> 表示 任意双元素 fusion 序列, 其中 A 是其第一个元素的类型, 而 B 是其第二个元素的类型.

记法 vector<A> 表示 任意 STL 容器, 其中保存类型为 A 的元素.

如上表所示的属性组合与传播规则使序列有些特殊, 因为如果所有元素具有相同的属性类型, 它们可以以两种模式运行: 消耗 fusion 序列和消耗 STL 容器. 所选模式取决于所提供属性的类型.

复杂度

序列生成器的总体复杂度由其元素复杂度之和决定. 序列本身的复杂度是 O(N), 其中 N 是序列中的元素数量.
