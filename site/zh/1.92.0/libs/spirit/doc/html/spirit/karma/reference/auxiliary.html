辅助生成器

属性变换伪生成器(attr_cast)
行尾生成器(eol)
Epsilon 生成器(eps)
惰性生成器(lazy)

本模块包含不适合归入其他类别的各种辅助生成器. 它包括 attr_cast, eol, eps 和 lazy 生成器.

模块头文件 
// forwards to <boost/spirit/home/karma/auxiliary.hpp>
#include <boost/spirit/include/karma_auxiliary.hpp>

另请参见 包含结构.
