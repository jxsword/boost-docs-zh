属性解析器 (attr)
说明

属性 (Attribute) 解析器不消耗任何输入, 因此它总是匹配空字符串并总是成功. 其目的是把它指定的参数暴露为属性.

头文件 
// forwards to <boost/spirit/home/qi/auxiliary/attr.hpp>
#include <boost/spirit/include/qi_attr.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::attr // alias: boost::spirit::qi::attr

所属模型

PrimitiveParser

记法约定

a

任意类型的常量值 (例如 0.0、"Hello"), 或任意类型的变量, 或求值为任意类型的 惰性参数.

A

a 的类型; 如果它是 惰性参数, 则为其返回类型.

表达式语义

仅当表达式的语义与 PrimitiveParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

attr(a)

创建一个伪解析器, 把 a 的当前值暴露为其属性, 且在解析时不消耗任何输入.
属性

表达式

属性

attr(a)

A

复杂度

O(1)

复杂度是常量, 因为不消耗任何输入, 也不进行任何匹配.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

namespace phx = boost::phoenix;
using boost::spirit::qi::attr;

把 attr 与字面量一起使用:

std::string str;
test_parser_attr("", attr("boost"), str);
std::cout << str << std::endl;            // will print 'boost'

double d;
test_parser_attr("", attr(1.0), d);
std::cout << d << std::endl;              // will print '1.0'

把 attr 与 Boost.Phoenix 函数对象一起使用:

d = 0.0;
double d1 = 1.2;
test_parser_attr("", attr(phx::ref(d1)), d);
std::cout << d << std::endl;              // will print '1.2'
