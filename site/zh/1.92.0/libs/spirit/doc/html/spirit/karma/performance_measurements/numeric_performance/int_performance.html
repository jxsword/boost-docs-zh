比较单个 int_ 生成器的性能

这些性能测量集中在使用不同的库和方法对单个 int 整数进行默认格式化. 下面比较了这些示例的总体执行时间. 我们比较了使用 sprintf, C++ iostreams, Boost.Format 和 Spirit.Karma 的情况.

性能测试的完整源代码请参见此处: int_generator.cpp. 所有测量都是对每种格式化类型执行 1e7 次迭代完成的 (在下面所示的代码中 NUMITERATIONS 设为 1e7).

用于测量 ltoa 性能的代码:

char buffer[65]; // we don't expect more than 64 bytes to be generated here
for (int i = 0; i < MAX_ITERATION; ++i)
{
    ltoa(v[i], buffer, 10);
}

用于测量标准 C++ iostreams 性能的代码:

std::stringstream str;
for (int i = 0; i < MAX_ITERATION; ++i)
{
    str.str("");
    str << v[i];
}

用于测量 Boost.Format 性能的代码:

std::string str;
boost::format int_format("%d");
for (int i = 0; i < MAX_ITERATION; ++i)
{
    str = boost::str(int_format % v[i]);
}

用于测量 Spirit.Karma 使用普通字符缓冲区时的性能的代码:

char buffer[65]; // we don't expect more than 64 bytes to be generated here
for (int i = 0; i < MAX_ITERATION; ++i)
{
    char *ptr = buffer;
    karma::generate(ptr, int_, v[i]);
    *ptr = '\0';
}
