自动创建生成器的 API
说明

该库实现了一个特殊的 API, 为所提供的属性类型返回生成器实例. 该函数基于一组简单的匹配规则 (如下表所概述) 递归地应用于属性类型, 为该属性找到最佳匹配的生成器类型. 返回的生成器可用于为所提供的属性生成输出.

头文件 
// forwards to <boost/spirit/home/karma/auto.hpp>
#include <boost/spirit/include/karma_auto.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::karma::create_generator

boost::spirit::traits::create_generator_exists

概要 
namespace boost { namespace spirit { namespace karma
{
    template <typename Attr>
    inline <unspecified>
    create_generator();
}}}

返回的实例可以直接作为生成器 (或分隔生成器) 传递给任何 Spirit.Karma API 函数. 此外, 它还可以作为 rule 的右侧表达式赋给 rule. 仅当元函数 traits::create_generator_exists 返回 mpl::true_ 时, 此函数才会返回有效的生成器类型. 否则它将无法编译.

namespace boost { namespace spirit { namespace traits
{
    template <typename Attr>
    struct create_generator_exists;
}}}

该元函数求值为 mpl::true_, 如果 create_generator 会为给定类型 Attr 返回有效生成器.

下表概述了从属性类型到生成器类型的映射规则. 这些规则被递归应用, 以创建可用于从给定属性类型生成输出的生成器类型.

重要

生成器 long_long 和 ulong_long 的映射仅在定义了预处理器常量 BOOST_HAS_LONG_LONG 的平台上可用 (即对 long long 和 unsigned long long (64 位)有符号和无符号整数类型有本机支持的平台).
