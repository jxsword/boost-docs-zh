临时缓冲输出的生成器指令(buffer[])
说明

所有生成器组件(Alternative (|) 生成器除外)都把生成的输出直接传递给底层输出流. 如果生成器在中途失败, 到目前为止生成的输出不会被"回滚". 缓冲生成器指令可以避免生成这种不想要的输出. 它把内嵌生成器产生的输出临时重定向到一个缓冲区. 只有在内嵌生成器成功之后, 该缓冲区才会刷新到底层流, 否则将被丢弃.

头文件 
// forwards to <boost/spirit/home/karma/directive/buffer.hpp>
#include <boost/spirit/include/karma_buffer.hpp>

另请参见 包含结构.

名称

boost::spirit::buffer // alias: boost::spirit::karma::buffer

所属模型

UnaryGenerator

记法约定

a

一个生成器对象

A

生成器 a 的属性类型

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

buffer[a]

内嵌生成器 a 被调用, 但其输出被临时拦截并存储在内部缓冲区中. 如果 a 成功, 缓冲区内容被刷新到底层输出流, 否则缓冲区内容被丢弃. 只要内嵌生成器成功, 缓冲指令就成功 (除非底层输出流报告错误).
提示

如果你想让缓冲生成器无论内嵌生成器的结果如何都成功, 只需把 buffer[a] 包装在一个额外的 optional 中: -buffer[a] (参见 Optional (一元 -)).

属性

参见 复合属性记法.

表达式

属性

buffer[a] 

a: A --> buffer[a]: A
a: Unused --> buffer[a]: Unused
复杂度

缓冲生成器指令的总体复杂度由其内嵌生成器的复杂度决定. 缓冲指令生成器本身的复杂度是 O(N), 其中 N 是缓冲的字符数量.

缓冲生成器指令的基本用法. 它展示了第一个示例中生成的部分输出如何不出现在最终输出中, 因为 plus 生成器失败 (没有可用数据, 参见 Plus (一元 +)).

std::vector<double> v;                // empty container
test_generator_attr("", -buffer['[' << +double_ << ']'], v);

v.push_back(1.0);                     // now, fill the container
