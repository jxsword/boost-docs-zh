实数生成器(float_, double_ 等)
说明

real_generator 可以生成任意长度和大小的实数, 受其模板参数 Num 限制. 数值基础类型 Num 可以是用户定义的数值类型, 例如 fixed_point (定点实数)和 bignum (无限精度数), 只要该类型遵循特定的表达式要求 (有关这些要求的更多信息, 参见 下文).

头文件 
// forwards to <boost/spirit/home/karma/numeric/real.hpp>
#include <boost/spirit/include/karma_real.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::lit // alias: boost::spirit::karma::lit

boost::spirit::float_ // alias: boost::spirit::karma::float_

boost::spirit::double_ // alias: boost::spirit::karma::double_

boost::spirit::long_double // alias: boost::spirit::karma::long_double

注释

lit 被 字符串生成器, 字符生成器 和数值生成器复用. 一般来说, 传入字符时创建字符生成器, 传入字符串时创建字符串生成器, 使用数值字面量时创建数值生成器.

概要 
template <typename Num, typename RealPolicies>
struct real_generator;

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

lit(num)

使用默认格式化生成实数字面量 num (无尾随零, 使用 fixed 表示数值 fabs(n) <= 1e5 && fabs(n) > 1e-3, 其他情况使用科学计数法表示, 3 位小数, 符号仅对负字面量输出). 该生成器从不失败 (除非底层输出流报告错误).

 

float_
double_
long_double

使用默认格式化生成由必需属性提供的实数 (无尾随零, 使用 fixed 表示数值 fabs(n) <= 1e5 && fabs(n) > 1e-3, 其他情况使用科学计数法表示, 3 位小数, 符号仅对负字面量输出). 该生成器从不失败 (除非底层输出流报告错误).

 

float_(num)
double_(num)
long_double(num)

使用默认格式化生成由生成器初始化时使用的直接字面量值提供的实数 (无尾随零, 使用 fixed 表示数值 fabs(n) <= 1e5 && fabs(n) > 1e-3, 其他情况使用科学计数法表示, 3 位小数, 符号仅对负字面量输出). 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.

上表列出的所有生成器(lit(num) 除外)都是下面描述的 real_generator<Num, RealPolicies> 基本实数生成器类型的预定义特化. 可以直接使用该类型, 通过各种格式化选项创建实数生成器.

表达式

语义

 

real_generator<
    Num, RealPolicies
>()

生成由必需属性提供的类型为 Num 的实数, 使用指定的 RealPolicies. 该生成器从不失败 (除非底层输出流报告错误).

 

real_generator<
    Num, RealPolicies
>()(num)

生成由生成器初始化时使用的直接字面量值提供的类型为 Num 的实数, 使用指定的 RealPolicies. 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.
附加要求

以下列表枚举了使用某个类型 Num 来实例化 real_generator<Num, Policies> 所必须满足的要求.

要能用作 real_generator<> 的第一个模板参数, 类型 Num 必须定义:

  • 以下比较运算符: <, <=, ==, !=, > 和 >=
  • 以下数值运算符: +, -, /, * 和 %
  • 实现以下接口和语义的函数: std::fmod, std::pow, std::log10, std::lround, std::ltrunc, std::modf, std::floor 和 std::ceil. 这些函数的定义方式必须使它们能通过实参依赖查找 (ADL) 找到.
  • 类型 std::numeric_limits<Num> 的有效特化, 允许进行数值属性检查.

注释

除了它们通常的 Num 类型属性之外, 所有列出的生成器还接受 boost::optional<Num> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 Num 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

实数格式化策略

如果需要对实数进行特殊格式化, 重载策略类 real_policies<Num> 并把它用作 real_generator<> 实数生成器的模板参数. 例如:

// define a new real number formatting policy
template <typename Num>
struct scientific_policy : real_policies<Num>
{
    // we want the numbers always to be in scientific format
    static int floatfield(Num n) { return fmtflags::scientific; }
};

// define a new generator type based on the new policy
typedef real_generator<double, scientific_policy<double> > science_type;
science_type const scientific = science_type();

// use the new generator 
generate(sink, science_type(), 1.0);  // will output: 1.0e00
generate(sink, scientific, 0.1);      // will output: 1.0e-01

模板参数 Num 应当是使用重载策略类型进行格式化的类型. 同时 Num 将用作所创建实数生成器的属性类型.

实数格式化策略表达式语义

实数格式化策略应暴露以下变量和函数:

表达式

说明

 

template <typename Inserter
  , typename OutputIterator
  , typename Policies>
bool call (OutputIterator& sink, Num n
  , Policies const& p);

这是用于生成实数输出的主函数. 实数生成器调用它来执行转换. 理论上所有工作都可以在这里实现, 但最简单的方法是使用模板参数 Inserter 所指定类型提供的现有功能. 该函数的默认实现是:

template <typename Inserter, typename OutputIterator
  , typename Policies>
static bool
call (OutputIterator& sink, Num n, Policies const& p)
{
    return Inserter::call_n(sink, n, p);
}

sink 是用于生成的输出迭代器

n 是要转换的实数

p 是用于实例化此实数生成器的策略类型的实例.

 

bool force_sign(Num n);

默认行为是不要求生成符号. 如果函数 force_sign() 返回 true, 则所有生成的数都将带有符号 ('+' 或 '-', 零将用空格代替符号).

n 是要输出的实数. 这可用于根据该数值调整所需的行为.

 

bool trailing_zeros(Num n);

返回是否必须在输出的小数部分输出尾随零. 如果设置, 该标志指示实数生成器输出尾随零, 直到达到所需精度位数 (由 precision() 函数返回).

n 是要输出的实数. 这可用于根据该数值调整所需的行为.

 

int floatfield(Num n);

决定在生成的输出中使用哪种表示类型.

默认情况下, 所有绝对值为零或介于 0.001 和 100000 之间的数都将使用定点格式生成, 所有其他数将使用科学计数法表示生成.

trailing_zeros() 可用于强制在小数部分输出尾随零, 直到达到 precision() 成员函数返回的位数. 默认情况下不生成尾随零.

n 是要输出的实数. 这可用于根据该数值调整格式化标志.

返回值必须是 fmtflags::scientific (以科学计数法生成实数值)或 fmtflags::fixed (以定点记法生成实数值).

 

unsigned precision(Num n);

返回要在输出小数部分生成的最大十进制位数.

n 是要输出的实数. 这可用于根据该数值调整所需的精度. 如果指定了尾随零标志, 输出的小数部分将在适当时用零"填充".

注释: 如果尾随零标志未生效, 则适用附加语义. 参见下文 fraction_part() 函数的描述. 此外, 该精度将限制为 std::numeric_limits<T>::digits10 + 1 的值.

 

template <typename OutputIterator>
bool integer_part(OutputIterator& sink
  , Num n, bool sign, bool force_sign);

调用此函数来生成实数的整数部分.

sink 是用于生成的输出迭代器

n 是要转换实数的整数部分的绝对值 (始终为非负)

sign 是要转换的整个实数的符号.

force_sign 是一个标志, 指示即使对非负数也必须生成符号 (这与上文函数 force_sign() 返回的值相同)

返回值定义整个生成器的结果. 如果它是 false, 则不再生成进一步的输出, 并立即返回 false (同样从调用的 real_generator 返回). 如果它是 true, 则继续正常生成输出.

 

template <typename OutputIterator>
bool dot(OutputIterator& sink, Num n,
  unsigned precision);

调用此函数来生成小数点.

sink 是用于生成的输出迭代器

n 是要转换实数的小数部分. 注意该数经过了缩放, 使得它表示与前面 precision() 函数返回值对应的单位数. 即小数部分 0.01234 表示为 1234 (当函数 precision() 返回 5 时).

precision 是要输出的位数, 如上文函数 precision() 所返回

提供此参数是为了允许决定是否根本需要生成小数点.

注释: 如果 trailing_zeros 标志未生效, 则适用附加说明. 参见下文 fraction_part() 函数的描述.

返回值定义整个生成器的结果. 如果它是 false, 则不再生成进一步的输出, 并立即返回 false (同样从调用的 real_generator 返回). 如果它是 true, 则继续正常生成输出.

 

template <typename OutputIterator>
bool fraction_part(OutputIterator& sink, Num n
  , unsigned adjprec, unsigned precision);

调用此函数来生成该数的小数部分.

sink 是用于生成的输出迭代器

n 是要转换实数的小数部分. 注意该数经过了缩放, 使得它表示与前面 precision() 函数返回值对应的单位数. 即小数部分 0.01234 表示为 1234 (当函数 precision() 返回 5 时).

adjprec 是要输出的修正后的位数 (参见下文注释)

precision 是要输出的位数, 如上文函数 precision() 所返回

注释: 如果 trailing_zeros() 返回 false, 则 adjprec 参数将相对于之前 precision() 函数返回的值 (定义最大小数位数)被修正, 即把尾随零考虑在内. 例如: 实数 0.0123, 且其值 5 由 precision() 返回, 将导致:

trailing_zeros() 返回 false: n 将是 123, 而 adjprec 将是 4 (因为我们需要输出 0123)

trailing_zeros() 返回 true: n 将是 1230, 而 adjprec 将是 5 (因为我们需要输出 01230)

小数部分缺失的前导零必须由此策略函数的实现提供.

返回值定义整个生成器的结果. 如果它是 false, 则不再生成进一步的输出, 并立即返回 false (同样从调用的 real_generator 返回). 如果它是 true, 则继续正常生成输出.

 

template <typename CharEncoding,
    typename Tag, typename OutputIterator>
bool exponent(
    OutputIterator& sink, long n);

调用此函数来生成该数的指数部分 (仅当 floatfield() 函数返回 fmtflags::scientific 标志时才调用).

sink 是用于生成的输出迭代器

n 是要转换实数的 (带符号)指数部分.

模板参数 CharEncoding 和 Tag 要么是 unused_type 类型, 要么描述要应用于任何输出的字符类和转换, 这些输出可能受 lower[] 或 upper[] 指令的影响.

返回值定义整个生成器的结果. 如果它是 false, 则不再生成进一步的输出, 并立即返回 false (同样从调用的 real_generator 返回). 如果它是 true, 则继续正常生成输出.

提示

实现恰当实数格式化策略的最简单方法是从类型 real_policies<> 派生一个新类型, 同时重写需要更改的格式化方面.

复杂度

O(N), 其中 N 是表示生成的实数所需的位数.
