字符串解析器

字符串解析器 (string、lit)
符号解析器 (symbols)

本模块包含用于字符串的解析器. 目前, 本模块包括字面量和字符串解析器以及符号表.

模块头文件 
// forwards to <boost/spirit/home/qi/string.hpp>
#include <boost/spirit/include/qi_string.hpp>
