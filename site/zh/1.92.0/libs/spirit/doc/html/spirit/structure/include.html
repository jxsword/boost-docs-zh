Include

Spirit 是一个仅头文件库. 没有需要链接的库. 本节记录 Spirit 头文件的结构.

Spirit 包含五个子库, 外加一个放置公共支持类的 'support' 模块:

  • Classic
  • Qi
  • Karma
  • Lex
  • 支持

Spirit 顶层目录是:

BOOST_ROOT/boost/spirit

目前, 该目录包含:

[actor]     [attribute]     [core]      [debug]
[dynamic]   [error_handling][home]      [include]
[iterator]  [meta]          [phoenix]   [repository]
[symbols]   [tree]          [utility]

其中包括一些现已弃用的旧 v1.8 目录: actor、attribute、core、debug、dynamic、error_handling、iterator、meta、phoenix、symbols、tree 和 utility. 不能保证这些目录在未来的 Spirit 版本中仍然存在. 我们保留它们只是为了向后兼容. 请务必注意.

每个目录 (include、home 和 repository 除外) 都有一个对应的头文件, 其中包含对该目录所含每个相关 include 文件的转发包含. 例如, 存在一个 <boost/spirit/actor.hpp> 头文件, 它包含 boost/spirit/actor 目录中的所有相关文件.

要区分 Spirit 版本, 你可以查看版本文件:

<boost/spirit/version.hpp>

使用预处理器定义

SPIRIT_VERSION

它是一个十六进制数, 前两位决定主版本, 后两位决定次版本. 例如:

#define SPIRIT_VERSION 0x2010 // version 2.1

位于以下位置的 include 目录:

BOOST_ROOT/boost/spirit/include

是一个特殊的扁平目录, 包含所有 Spirit 头文件. 为了适应扁平结构, 头文件以子库名称为前缀:

  • classic_
  • karma_
  • lex_
  • phoenix1_
  • qi_
  • support_

例如, 如果你过去包含 <boost/spirit/actor.hpp> (现已弃用的头文件), 应改为包含 <boost/spirit/include/classic_actor.hpp>

如果你想简单地包含主子库名称, 可以包含:

  • <boost/spirit/include/classic.hpp>
  • <boost/spirit/include/karma.hpp>
  • <boost/spirit/include/lex.hpp>
  • <boost/spirit/include/phoenix1.hpp>
  • <boost/spirit/include/qi.hpp>
  • <boost/spirit/include/support.hpp>

home 目录:

BOOST_ROOT/boost/spirit/home

是 Spirit 真正 的家. 它是各子库实际存在的地方. home 目录包含:

[classic]   [karma]     [lex]
[qi]        [support]

照例, 这些目录有它们对应的 include 文件:

  • <boost/spirit/home/classic.hpp>
  • <boost/spirit/home/karma.hpp>
  • <boost/spirit/home/lex.hpp>
  • <boost/spirit/home/qi.hpp>
  • <boost/spirit/home/support.hpp>

各子库的 include 文件可在包含特定子库的每个子目录中找到. 子库的 include 结构在其文档中有说明. 为保持一致, 每个库都遵循与上述相同的方案.

为简单起见, 你应当使用 boost/spirit/include 处的扁平 include 目录.

关于设计理由的更多信息, 你可能想看看常见问题条目 头文件地狱.

子目录 boost/spirit/repository 不属于 Spirit 主发行版. 更多信息请参阅: Spirit 仓库.
