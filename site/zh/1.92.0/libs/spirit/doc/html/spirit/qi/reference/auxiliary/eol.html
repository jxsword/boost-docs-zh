行尾解析器 (eol)
说明

eol 解析器匹配行尾 (CR/LF 及其组合).

头文件 
// forwards to <boost/spirit/home/qi/auxiliary/eol.hpp>
#include <boost/spirit/include/qi_eol.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::eol // alias: boost::spirit::qi::eol

所属模型

PrimitiveParser

表达式语义

仅当表达式的语义与 PrimitiveParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

eol

创建匹配行尾的解析器.
属性

表达式

属性

eol

unused

复杂度

O(1)
