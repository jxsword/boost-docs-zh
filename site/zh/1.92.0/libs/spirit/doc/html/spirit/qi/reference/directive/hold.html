用于属性提交/回滚的解析器指令 (hold[])
说明

hold[] 指令帮助管理属性, 主要用于备选解析器. 它为内嵌解析器实例化一个新的属性实例. 如果内嵌解析器成功, 该属性实例的值会被复制到外层属性; 否则会被丢弃. 备选解析器通常不会回滚失败的备选项对外层属性所做的修改. 把这些备选项包装进 hold[] 指令可确保只有成功的备选项才能修改属性.

头文件 
// forwards to <boost/spirit/home/qi/directive/hold.hpp>
#include <boost/spirit/include/qi_hold.hpp>

另请参见 包含结构.

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

hold[a]

在解析 a 时创建一个新的属性实例, 只有在 a 成功之后才把结果复制到外层属性.
属性

参见 复合属性记法.

表达式

属性

hold[a] 

a: A --> hold[a]: A
a: Unused --> hold[a]: Unused
注释

hold[] 指令使用 swap() 来实现属性的回滚/提交语义. 因此, 属性类型必须能与 boost::core::invoke_swap 一起使用 (需要为 swap(attribute_type&, attribute_type&) 定义适当的重载, 或者既可移动构造又可移动赋值.

复杂度

复杂度由主体解析器 a 的复杂度决定

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::qi::hold;
using boost::spirit::qi::int_;
using boost::spirit::qi::attr;

在这里使用 hold[] 将确保 (失败的) 第一个备选项对属性造成的修改在整个解析成功后不可见.

std::vector<int> v;
test_phrase_parser_attr("123",
      hold[int_ >> ':' >> int_] | int_ >> attr(0), v);
std::cout << v[0] << "," << v[1] << std::endl;    // will output: >123,0<
