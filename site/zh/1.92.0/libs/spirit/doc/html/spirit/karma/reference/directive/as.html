强制原子提取的生成器指令(as<T>, as_string[], as_wstring[])
说明

as<T> 类强制从其消耗属性中原子提取容器类型 T. 通常, 重复生成器 (例如 Kleene (*) 等) 或暴露 vector<A> 的序列会通过遍历容器迭代器, 从作为其消耗属性提供的容器中提取元素. 在某些情况下, 这可能是不可取的. as<T> 类创建一个指令, 该指令会向其主体传递一个类型为 T 的未命名临时对象, 条件是在生成时确定从其消耗属性提取 T 是有效的. traits::valid_as<T>() 由 as<T> 调用以确定有效性; 如果返回 false, 生成器失败. 后续提取通过调用 traits::as<T>() 执行.

注释

T 必须是容器类型. 如果 traits::is_container 对 T 不返回 true, 将发生编译期错误.

头文件 
// forwards to <boost/spirit/home/karma/directive/as.hpp>
#include <boost/spirit/include/karma_as.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::as_string // alias: boost::spirit::karma::as_string

boost::spirit::as_wstring // alias: boost::spirit::karma::as_wstring

概要 
template <typename T>
struct as;
模板参数

参数

说明

默认值

T

一个容器类型.

none

所属模型

UnaryGenerator

记法约定

a

一个 Generator.

attr

提供给指令的属性.

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

as<T>()[a]

提取一个 T 实例 (来自 attr), 并调用主体生成器 a, 把该未命名临时对象作为其属性提供.

as_string[a]

等价于 as<std::string>()[a]

as_wstring[a]

等价于 as<std::wstring>()[a]

属性

参见 复合属性记法.

表达式

属性

as<T>()[a]

a: A --> as<T>()[a]: T

复杂度

复杂度由主体生成器 a 的复杂度, 以及提取类型为 T 的未命名容器的复杂度决定 (提取自属性 attr).

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::utree;
using boost::spirit::utree_type;
using boost::spirit::utf8_symbol_type;
using boost::spirit::karma::as;
using boost::spirit::karma::as_string;
using boost::spirit::karma::char_;
using boost::spirit::karma::double_;

as<T>, as_string 和 as_wstring 的简单用法:

为了用 utree 正确处理字符串拼接, 我们使用了 as_string[]. 我们还使用 as<T> 来显式提取 utree 符号节点.

typedef as<utf8_symbol_type> as_symbol_type;
as_symbol_type const as_symbol = as_symbol_type();

utree ut;
ut.push_back("xyz");
ut.push_back(1.23);

test_generator_attr("xyz1.23", as_string[*char_] << double_, ut);
test_generator_attr("xyz1.23", as<std::string>()[*char_] << double_, ut);

ut.clear();

ut.push_back(utf8_symbol_type("xyz"));
ut.push_back(1.23);

test_generator_attr("xyz1.23", as_symbol[*char_] << double_, ut);
test_generator_attr("xyz1.23", as<utf8_symbol_type>()[*char_] << double_, ut);
