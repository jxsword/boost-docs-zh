数字列表属性 - 再来一次, 有风格地

你已经看到 double_ 解析器有一个 double 属性. 所有解析器都有属性, 即使是复合解析器. 那些用运算符从基础组件组合而成的解析器, 例如列表解析器, 也有属性. 列表解析器的属性恰好是:

p % d

是 std::vector (其属性为 p). 所以, 对我们的解析器:

double_ % ','

我们将有一个属性:

std::vector<double>

那么, 这给了我们什么? 嗯, 我们可以简单地向数字列表解析器传入一个 std::vector<double>, 它会愉快地在我们的 vector 中输出结果. 为此, 我们将使用 phrase_parse 的一个变体, 带一个额外参数: 解析器的属性. 把以下参数传给 phrase_parse

  1. 指向输入开头的迭代器
  2. 指向输入末尾之后一位的迭代器
  3. 解析器对象
  4. 另一个解析器, 称为跳过解析器
  5. 解析器的属性

我们的解析器现在进一步简化为:

template <typename Iterator>
bool parse_numbers(Iterator first, Iterator last, std::vector<double>& v)
{
    using qi::double_;
    using qi::phrase_parse;
    using qi::_1;
    using ascii::space;

    bool r = phrase_parse(first, last,

        //  Begin grammar
        (
            double_ % ','
        )
        ,
        //  End grammar

        space, v);

    if (first != last) // fail if we did not get a full match
        return false;
    return r;
}

此示例的完整 cpp 文件可在此处找到: ../../example/qi/num_list4.cpp

嘿, 不再需要动作了!!! 现在我们进入了属性文法的领域. 酷吧?
