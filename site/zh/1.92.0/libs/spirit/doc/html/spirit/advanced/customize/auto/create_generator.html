为生成器定义自定义属性映射
create_generator

模板 create_generator 是用作定制点的类型. Karma 的 create_generator API 函数会调用它, 以便创建给定数据类型到生成器表达式的自定义映射. 每当遇到给定的数据类型, create_generator 都将返回该生成器表达式.

模块头文件 
// forwards to <boost/spirit/home/karma/auto.hpp>
#include <boost/spirit/include/karma_auto.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::traits

概要 
template <typename T, typename Enable>
struct create_generator
{
    typedef <unspecified> type;
    static type const& call();
};
模板参数

参数

说明

默认值

T

类型 T, 需要为其建立到生成器的自定义映射.

none

Enable

辅助模板参数, 可利用 SFINAE 有选择地启用或禁用 create_generator 的某些特化(即 boost::enable_if 或 boost::disable_if).

void

记法约定

T

任意类型.

表达式语义

表达式

语义

create_generator<T>::type

定义 call 所返回生成器表达式的类型.

create_generator<T>::call()

返回一个生成器表达式(通常这是一个 proto::expression), 用作给定类型 T 的默认生成器.
预定义特化

Spirit 为若干类型预定义了此定制点的特化. 所有预定义映射在此列出: 生成器的附加属性要求.

注释

通过为要修改的类型提供你自己的 create_generator 定制点特化, 可以重载上列类型的预定义映射.

何时实现

需要为特定类型实现定制点 create_generator, 只要希望该类型可以与 API 函数 create_generator 一起使用 (这包括使用 karma::auto_ 生成器以及基于自动创建匹配生成器类型的特殊 API 函数).

示例

有关如何使用定制点 create_generator 的示例, 请参见此处: 使用 karma::auto_ 生成器的示例.
