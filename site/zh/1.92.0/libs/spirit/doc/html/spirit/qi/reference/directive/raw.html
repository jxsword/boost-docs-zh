用于转换解析的指令 (raw[])
说明

raw[] 无视其主体解析器的属性, 转而暴露一个半开区间 [first, last), 指向输入流中被匹配的字符. raw[] 指令为主体解析器恢复经典的 Spirit 转换 (无属性) 行为.

头文件 
// forwards to <boost/spirit/home/qi/directive/raw.hpp>
#include <boost/spirit/include/qi_raw.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::raw // alias: boost::spirit::qi::raw

所属模型

UnaryParser

记法约定

a

一个 Parser.

Iter

一个 ForwardIterator 类型.

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

raw[a]

无视主体解析器 a 的属性. 转而暴露半开区间 [first, last), 指向输入流中被匹配的字符.
属性

参见 复合属性记法.

表达式

属性

raw[a] 

a: A --> raw[a]: boost::iterator_range<Iter>
a: Unused --> raw[a]: Unused
注释

参见 boost::iterator_range.

复杂度

复杂度由主体解析器 a 的复杂度决定

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::qi::raw;
using boost::spirit::ascii::alpha;
using boost::spirit::ascii::alnum;

该解析器匹配并提取 C++ 标识符:

std::string id;
test_parser_attr("James007", raw[(alpha | '_') >> *(alnum | '_')], id);
std::cout << id << std::endl; // should print James007
