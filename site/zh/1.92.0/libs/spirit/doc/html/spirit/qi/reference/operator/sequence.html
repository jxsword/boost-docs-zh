序列解析器 (a >> b)
说明

序列运算符 a >> b 按顺序解析两个或更多操作数 (a、b 等):

a >> b >> ...
头文件 
// forwards to <boost/spirit/home/qi/operator/sequence.hpp>
#include <boost/spirit/include/qi_sequence.hpp>

另请参见 包含结构.

所属模型

NaryParser

记法约定

a, b

一个 Parser

表达式语义

仅当表达式的语义与 NaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

a >> b

匹配 a, 随后是 b.
属性

参见 复合属性记法.

表达式

属性

a >> b 

a: A, b: B --> (a >> b): tuple<A, B>
a: A, b: Unused --> (a >> b): A
a: Unused, b: B --> (a >> b): B
a: Unused, b: Unused --> (a >> b): Unused

a: A, b: A --> (a >> b): vector<A>
a: vector<A>, b: A --> (a >> b): vector<A>
a: A, b: vector<A> --> (a >> b): vector<A>
a: vector<A>, b: vector<A> --> (a >> b): vector<A>
复杂度

序列解析器的总体复杂度由其各元素复杂度之和决定. 序列本身的复杂度为 O(N), 其中 N 是序列中元素的数量.

示例

一些 using 声明:

using boost::spirit::ascii::char_;
using boost::spirit::qi::_1;
using boost::spirit::qi::_2;
namespace bf = boost::fusion;

注释

下面示例的测试框架在 基础示例 一节中给出.

简单用法:

test_parser("xy", char_ >> char_);

提取属性 tuple (使用 Boost.Fusion):

bf::vector<char, char> attr;
test_parser_attr("xy", char_ >> char_, attr);
std::cout << bf::at_c<0>(attr) << ',' << bf::at_c<1>(attr) << std::endl;

提取属性 vector (使用 STL):

std::vector<char> vec;
test_parser_attr("xy", char_ >> char_, vec);
std::cout << vec[0] << ',' << vec[1] << std::endl;

使用语义动作提取属性 (使用 Boost.Phoenix):

test_parser("xy", (char_ >> char_)[std::cout << _1 << ',' << _2 << std::endl]);
