数字矩阵 - 从矩阵打印数字

本节我们将讨论 Spirit.Karma 在从更复杂 (但仍然规则) 的数据结构生成输出方面的能力. 为简单起见, 我们将使用 std::vector<std::vector<int> > 作为一种简易的矩阵表示. 但即使该数据结构看起来非常简单, 这里介绍的原理同样适用于更复杂或自定义的数据结构. 本节所讨论示例的完整源代码可在此处找到: num_matrix.cpp.
