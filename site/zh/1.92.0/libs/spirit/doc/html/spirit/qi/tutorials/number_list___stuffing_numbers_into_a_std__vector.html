数字列表 - 把数字塞入 std::vector

本示例演示一个解析以逗号分隔的数字列表的解析器. 数字使用 phoenix 插入 vector.

template <typename Iterator>
bool parse_numbers(Iterator first, Iterator last, std::vector<double>& v)
{
    using qi::double_;
    using qi::phrase_parse;
    using qi::_1;
    using ascii::space;
    using phoenix::push_back;

    bool r = phrase_parse(first, last,

        //  Begin grammar
        (
            double_[push_back(phoenix::ref(v), _1)]
                >> *(',' >> double_[push_back(phoenix::ref(v), _1)])
        )
        ,
        //  End grammar

        space);

    if (first != last) // fail if we did not get a full match
        return false;
    return r;
}

此示例的完整 cpp 文件可在此处找到: ../../example/qi/num_list2.cpp

这又与之前的解析器相同. 这次, 我们不是把数字加起来, 而是把它们塞进一个 std::vector. push_back 由 Boost.Phoenix 提供. 表达式:

push_back(ref(v), _1)

追加解析出的数字. 和之前一样, _1 是表示解析结果属性的 Boost.Phoenix 占位符. 同样和之前一样, ref(v) 告诉 Boost.Phoenix, v (即 std::vector) 是一个可变引用.
