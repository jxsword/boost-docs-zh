数字列表 - 从 std::vector 打印数字

使用列表运算符

C++ 标准库缺少一项重要特性, 即对容器进行任何格式化输出的支持. 当然, 为特定容器编写自定义输出例程相当容易, 但一次次重复这样做实在乏味. 本节我们将进一步展示 Spirit.Karma 从任意 STL 容器生成输出的更多能力. 我们将在前一节所介绍例子的基础上进行构建 (参见 热身).

本节所示示例的完整源代码可在此处找到: num_list2.cpp.

这次我们利用 Karma 的 List (%) 运算符. 列表运算符的语义与我们之前使用的序列的语义完全等价. 生成器表达式

double_ << *(',' << double_)

在语义上等价于如下生成器表达式

double_ % ','

从而简化了整体代码. 列表运算符的属性也与任何 STL 容器兼容. 这次我们改用 std::vector<double>, 而不是之前使用的 std::list<double>. 此外, 例程 generate_numbers 将容器作为模板参数, 因此它现在可用于任何存放 double 数字的 STL 容器.

template <typename OutputIterator, typename Container>
bool generate_numbers(OutputIterator& sink, Container const& v)
{
    using boost::spirit::karma::double_;
    using boost::spirit::karma::generate_delimited;
    using boost::spirit::ascii::space;

    bool r = generate_delimited(
        sink,                           // destination: output iterator
        double_ % ',',                  // the generator
        space,                          // the delimiter-generator
        v                               // the data to output 
    );
    return r;
}

注释

尽管容器是一个模板参数, Spirit.Karma 的格式化表达式 (double_ % ',') 并不依赖于所传入容器的实际类型. 此处唯一需要满足的前置条件是: 容器中存储的元素必须可转换为 double.

从任意数据生成输出

上面开发的输出例程仍然不能通用地用于所有类型的 STL 容器及其存储的任意元素. 为了可用, 容器中存储的元素仍需可转换为 double. 幸运的是, Spirit.Karma 能够在使用相同格式描述表达式的情况下输出任意数据类型. 它实现了 stream 生成器, 只要定义了匹配的标准流输出运算符, 这些生成器就能消耗任意属性类型. 也就是说, 对于任意属性类型 Attrib, 如下函数:

std::ostream& operator<< (std::ostream&, Attrib const&);

必须可用. stream 生成器将使用标准流输出运算符来生成输出.

下面的示例修改了上面所示的代码, 以使用 stream 运算符, 这使其几乎与任何数据类型兼容. 我们实现了一个自定义数据类型 complex 来演示这一点. 该示例展示了如何将这个 (或任何其他) 自定义数据类型集成到 Spirit.Karma 生成器框架中.

下面是自定义数据结构以及所需的标准流输出运算符:

// a simple complex number representation z = a + bi
struct complex
{
    complex (double a, double b = 0.0) : a(a), b(b) {}

    double a;
    double b;
};

// the streaming operator for the type complex
std::ostream&
operator<< (std::ostream& os, complex const& z)
{
    os << "{" << z.a << "," << z.b << "}";
    return os;
}

下面是从这些对象组成的 vector 生成输出的实际调用. 这次我们在生成的输出中穿插换行 (参见 eol), 将每个复数放在单独的一行:

template <typename OutputIterator, typename Container>
bool generate_numbers(OutputIterator& sink, Container const& v)
{
    using boost::spirit::karma::stream;
    using boost::spirit::karma::generate;
    using boost::spirit::karma::eol;

    bool r = generate(
        sink,                           // destination: output iterator
        stream % eol,                   // the generator
        v                               // the data to output 
    );
    return r;
}

所示代码是完全通用的, 只要容器中存储的数据项实现了标准流输出运算符, 它就可用于任何 STL 容器.
