复制属性的生成器指令(duplicate[])
说明

如果内嵌生成器是序列生成器, 指令 duplicate[] 把其属性复制到内嵌生成器的所有元素. 否则它不做任何事.

头文件 
// forwards to <boost/spirit/home/karma/directive/duplicate.hpp>
#include <boost/spirit/include/karma_duplicate.hpp>

另请参见 包含结构.

名称

boost::spirit::duplicate // alias: boost::spirit::karma::duplicate

所属模型

UnaryGenerator

记法约定

a

一个生成器对象

A

生成器 a 的属性类型

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

duplicate[a]

duplicate 指令把所提供的属性复制给内嵌序列生成器的所有元素. 对其他类型的内嵌生成器它没有效果. 只要其内嵌生成器不失败, 它就成功.
属性

参见 复合属性记法.

表达式

属性

duplicate[a] 

a: A --> duplicate[a]: A
a: tuple<A, A, ...> --> duplicate[a]: A
a: Unused --> duplicate[a]: Unused

如果 duplicate[] 指令的内嵌生成器是一个序列, 则预期该序列的所有元素要么暴露相同的属性类型, 要么暴露兼容的属性类型, 要么暴露 unused. 在这种情况下, duplicate[] 指令暴露其第一个元素的属性类型. 如果内嵌序列的元素不暴露相同的属性, duplicate[] 指令的行为是未定义的. 相应的表达式很可能无法编译.

复杂度

duplicate[] 指令的总体复杂度取决于内嵌生成器的复杂度.

test_generator_attr("2.02.0", duplicate[double_ << double_], 2.0);
test_generator_attr_delim("2.0 2.0 ", duplicate[double_ << double_], space, 2.0);
