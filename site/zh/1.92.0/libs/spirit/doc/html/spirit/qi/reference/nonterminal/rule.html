解析器 rule
说明

rule 是一个多态解析器, 充当命名占位符, 捕获赋给它的 解析表达式文法 (PEG) 表达式的行为. 为 解析表达式文法 (PEG) 表达式命名使其日后可以被引用, 并使 rule 能够调用自身. 这是最重要的机制之一, 也是递归下降解析中 "递归" 一词的由来.

头文件 
// forwards to <boost/spirit/home/qi/nonterminal/rule.hpp>
#include <boost/spirit/include/qi_rule.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::qi::rule

概要 
template <typename Iterator, typename A1, typename A2, typename A3>
struct rule;
模板参数

参数

说明

默认值

Iterator

期望该 rule 工作所用的底层迭代器类型.

none

A1, A2, A3

Signature, Skipper 或 Locals, 以任意顺序. 参见下表.

参见下表.

以下是关于模板参数的更多信息:

参数

说明

默认值

Signature

指定 rule 的合成 (返回值) 属性和继承属性 (参数). 更多信息见此处: Nonterminal.

unused_type. 当 Signature 默认为 unused_type 时, 效果等同于指定签名为 void(), 这也等价于 unused_type()

Skipper

指定 rule 的跳过器解析器. 如果希望 rule 跳过空白字符, 请指定此项. 如果不指定, 该 rule 就是一个 "隐式 lexeme", 不会跳过空格. "隐式 lexeme" rule 仍可以带跳过器调用. 在这种情况下, 该 rule 会像所有 lexeme 和基础组件一样执行预跳过.

unused_type

Locals

规定 rule 的局部变量. 参见 Nonterminal.

unused_type

所属模型

Nonterminal

记法约定

r, r2

规则

p

一个解析器表达式

Iterator

期望该 rule 工作所用的底层迭代器类型.

A1, A2, A3

Signature, Skipper 或 Locals, 以任意顺序.

表达式语义

仅当表达式的语义与 Nonterminal 不同或在其中未定义时, 才给出其语义.

表达式

说明

 

rule<Iterator, A1, A2, A3>
    r(name);

rule 声明. Iterator 是必需的. A1, A2, A3 是可选的, 可以以任意顺序指定. name 是一个可选字符串, 为 rule 命名, 对调试和错误处理很有用.

 

rule<Iterator, A1, A2, A3>
    r(r2);

复制构造 rule r, 来源是 rule r2.

r = r2;

把 rule r2 赋给 r.

r.alias()

返回 r 的别名. 该别名是一个持有对 r 的引用的解析器.

r.copy()

获取 r 的一份副本.

r = p;

rule 定义. 这等价于 r %= p (见下文), 条件是 p 中没有任何位置附加语义动作.

r %= p;

自动 rule 定义. p 的属性必须与 r 的合成属性兼容. 如果 p 解析成功, 其属性会自动传播到 r 的合成属性. 语义动作 (如果存在) 不得改变属性的类型.

r.name()

获取 rule 对象的当前名称.

r.name(name)

把 rule 对象的当前名称设置为 name.
属性

rule 的解析器属性是 T, 即其合成属性. 参见 Attribute

复杂度

复杂度由右侧 (RHS) 解析器 p 的复杂度决定

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::qi::rule;
using boost::spirit::qi::int_;
using boost::spirit::qi::locals;
using boost::spirit::qi::_1;
using boost::spirit::qi::_a;
using boost::spirit::ascii::alpha;
using boost::spirit::ascii::char_;
using boost::spirit::ascii::space_type;

基本 rule:

rule<char const*> r;
r = int_;
test_parser("123", r);

带合成属性的 rule:

rule<char const*, int()> ra;
ra = int_;
int i;
test_parser_attr("123", ra, i);
assert(i ==  123);

带跳过器和合成属性的 rule:

rule<char const*, std::vector<int>(), space_type> rs;
rs = *int_;
std::vector<int> v;
test_phrase_parser_attr("123 456 789", rs, v);
assert(v[0] ==  123);
assert(v[1] ==  456);
assert(v[2] ==  789);

带一个局部变量的 rule:

rule<char const*, locals<char> > rl;
rl = alpha[_a = _1] >> char_(_a); // get two identical characters
test_parser("aa", rl); // pass
test_parser("ax", rl); // fail
