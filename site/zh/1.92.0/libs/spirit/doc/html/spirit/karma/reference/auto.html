自动生成器

说明

本模块包含 auto_ 生成器的描述. 该生成器可用于基于所提供的属性类型自动创建生成器.

头文件 
// forwards to <boost/spirit/home/karma/auto.hpp>
#include <boost/spirit/include/karma_auto.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::auto_ // alias: boost::spirit::karma::auto_

所属模型

PrimitiveGenerator

记法约定

s

定义了到生成器类型映射的任意类型的变量实例 (元函数 traits::create_generator_exists 返回 mpl::true_), 或求值为定义了到生成器类型映射的任意类型的 惰性实参 (元函数 traits::create_generator_exists 返回 mpl::true_).

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

说明

auto_

创建与所提供属性类型兼容的生成器实例并用它生成输出. 该生成器从不失败 (除非底层输出流报告错误).

auto_(s)

创建与所提供字面量值兼容的生成器实例. 该生成器从不失败 (除非底层输出流报告错误).
附加要求

auto_ 生成器可用于为定义了到生成器类型映射的任意数据类型生成输出 (元函数 traits::create_generator_exists 返回 mpl::true_). 下表概述了从属性类型到生成器类型的预定义映射规则. 这些规则被递归应用, 以创建可用于从给定属性类型生成输出的生成器类型.

可以通过实现定制点 traits::create_generator 的特化来添加对任何自定义数据类型的支持. 该定制也可用于重定义任何预定义映射.

属性

表达式

属性

auto_

hold_any, 属性是必需的 (否则编译将失败)

auto_(s)

unused

重要

属性类型 hold_any, 由某些 auto_ 生成器暴露, 在语义和语法上等价于 Boost.Any 实现的类型. 它被加入 Spirit 是因为与 Boost.Any 相比, 它具有更好的性能和更小的占用.

注释

除了它们通常的 Attrib 类型属性之外, 所有列出的生成器还接受 boost::optional<Attrib> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 Attrib 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

复杂度

auto_ 生成器的复杂度取决于属性类型. 每种属性类型都会导致实例化不同的生成器类型, 后者决定了总体复杂度.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些包含:

#include <boost/spirit/include/karma.hpp>
#include <boost/spirit/include/support_utree.hpp>
#include <boost/phoenix/core.hpp>
#include <boost/phoenix/operator.hpp>
#include <boost/fusion/include/std_pair.hpp>
#include <boost/proto/deep_copy.hpp>
#include <iostream>
#include <string>

一些 using 声明:

using boost::spirit::karma::auto_;

以及示例中使用的类定义:

// a simple complex number representation z = a + bi
struct complex
{
    complex (double a, double b)
      : a(a), b(b)
    {}

    double a;
    double b;
};

要让 complex 数据结构能被用作 Boost.Fusion 序列, 需要以下构造. 这是必需的, 因为我们将用 Spirit.Karma 序列为该数据结构生成输出: '{' << karma::double_ << ',' << karma::double_ << '}'.

BOOST_FUSION_ADAPT_STRUCT(
    complex,
    (double, a)
    (double, b)
)

我们为 create_generator 定制点添加一个特化, 为 complex 类型定义自定义输出格式. 一般来说, create_generator 的任何特化都应返回用于为该定制点所特化的类型生成输出的 proto 表达式.

我们需要使用 proto::deep_copy, 因为表达式包含字面量('{', ',' 和 '}'), 它们通常仅以引用方式嵌入 proto 表达式. 深拷贝会把 proto 树转换为按值持有这些内容. 对于更简单的 proto 表达式(不包含对临时对象的引用), 可以省略深拷贝操作. 或者, 你也可以使用 proto::make_expr 设施来构建所需的 proto 表达式.

namespace boost { namespace spirit { namespace traits
{
    template <>
    struct create_generator<complex>
    {
        typedef proto::result_of::deep_copy<
            BOOST_TYPEOF('{' << karma::double_ << ',' << karma::double_ << '}')
        >::type type;

        static type call()
        {
            return proto::deep_copy(
                '{' << karma::double_ << ',' << karma::double_ << '}');
        }
    };
}}}

auto_ 生成器的一些用法示例:

使用 karma::string 生成器输出一个简单字符串:

test_generator_attr("abc", auto_, "abc");
test_generator("abc", auto_("abc"));

输出上面定义的 complex 数据类型的实例, 所用生成器由 complex 的定制点定义:

test_generator_attr("{1.2,2.4}", auto_, complex(1.2, 2.4));
test_generator("{1.2,2.4}", auto_(complex(1.2, 2.4)));
