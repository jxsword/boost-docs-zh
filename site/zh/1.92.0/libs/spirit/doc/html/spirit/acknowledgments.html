致谢

本版本的 Spirit 是对许多人都有贡献的 经典 Spirit 的完全重写(见下文). 但有几个人在此次重写期间已经做出了重大帮助. 我们要特别感谢他们(排名不分先后):

Eric Niebler 撰写了 Boost.Proto--没有它, 这次重写不可能实现; 还提供了示例, 并就如何以最佳方式使用 Boost.Proto 给出了建议.

Ben Hanson 向我们提供了其 Lexertl 库的早期版本, 该库已被提议纳入 Boost(作为 Boost.Lexer). 撰写本文时, 该库的 Boost 评审仍在进行中.

Francois Barel 默默而持续地工作, 使 Spirit 与新旧各版本的 gcc 保持兼容. 他不仅向 Spirit V2.1 贡献了子规则(subrules), 还始终关注那些对产生差别至关重要的小细节.

Andreas Haberstroh 校对了文档, 并修正了我们在文档最初版本中引入的那些非母语者的怪异表述.

Chris Hoeppler 与 Andreas Haberstroh 一起承担了本文档初始版本的编辑工作. Chris 做了很多事, 尤其是在我们即将发布的最后关头.

Michael Caisse (即 mjcaisse), 他是 freenode #boost IRC 上 Spirit 的热心布道者. 由于他的积极参与, 那里提出的任何 Spirit 问题都不会没有答案. 我们还要感谢他在 2.1 发布文档上的最后关头编辑工作.

Tobias Schwinger 提出了期望点, 并为早期版本完成了 GCC 移植.

Dave Abrahams 一如既往, 在 C++, 库开发, 接口, 可用性和易用性方面提供了无数建议和帮助, 审查了代码并提供了宝贵反馈, 还让我们始终保持警醒.

OvermindDL 在邮件列表上提出了许多富有创意的想法, 帮助解决了更多疑难的用户问题.

Carl Barron 早期采用了 Lexer 库并提供了宝贵反馈, 迫使我们设计出覆盖其所有用例的恰当 API. 他还为 Qi 贡献了可变参数属性 API 的早期版本.

Daniel James 改进并维护了 Quickbook--我们撰写本文档所用的工具; 还零零碎碎地提供了文档建议和编辑补丁.

Stephan Menzel 早期采用了 Qi 和 Karma, 并愿意投入时间找出难以隔离的缺陷; 还对文档提供了反馈.

Ray Burkholder 和 Dainis Polis 在最后关头对文档提供了反馈.

Steve Brandt 在编写源到源语言转换工具时努力将 Qi 和 Karma 投入实际使用. 他提出了许多令人惊叹的建议, 帮助改善了这两个库的可用性.

Bryce Leylbach (即 wash) 贡献了组件 qi::as<T>[] 和 karma::as<T>[], 参与了 utree 及其与 Qi 和 Karma 的集成工作, 添加了数值解析器字面量, 贡献了相关文档, 并在库(以及我们)理智的日常维护中提供了巨大帮助.

Mathias Gaunard 为 Lexer 提交了缺陷报告, 建议和回归测试贡献, 帮助发现了隐蔽缺陷并改善了其整体可用性.

Thomas Bernard (即 teajay) 参与了关键字解析器的开发, 并为 qi::symbols<> 组件添加了显式名称.

Robert Stewart 积极参与邮件列表, 提供了有益的评论, 示例和建议.

Thomas Taylor, Richard Crossley, Semen 和 Adalberto Castelo 在测试随 V2.5 发布的新属性处理代码时帮助隔离了若干问题.

特别感谢 spirit-devel 和 spirit-general 邮件列表: 感谢他们参与讨论, 从一开始就成为 Spirit2 预发布版本的早期采用者, 并在支持, 缺陷跟踪, 基准测试和测试等各项任务中提供帮助. 名单包括: Larry Evans, Richard Webb, Martin Wille, Dan Marsden, Cedric Venet, Allan Odgaard, Matthias Vallentin, Justinas V.D., Darid Tromer, Brian O'Kennedy, Aaron Graham, Joerg Becker.

Joao Abecasis 早期支持并参与了 Spirit2 的开发, 还时不时用几个笑话打破我的宁静.

这个名单还在不断加长... 如果你被提到了, 要感谢 Joel 和 Hartmut; 如果没有, 就去踢 Joao 一脚 :-)

来自 Spirit V1 经典版 文档的致谢

特别感谢为 经典版 Spirit 做出贡献的以下人员:

Dan Nuffer 在词法分析器, 分析树, AST, XML 解析器和 multi-pass 迭代器方面的工作, 以及管理 Spirit 网站, 编辑, 维护 CVS 和发布版本, 还有无数其他几乎被视为理所当然的杂务.

Hartmut Kaiser 在 C 解析器, C/C++ 预处理器, 实用解析器, Intel 5.0 的最初移植, Phoenix 的各项工作, 向 v1.5 的移植, 元解析器, 分组解析器方面的工作, 以及大量测试和对细节的艰辛关注.

Martin Wille 改进了 grammar 的多线程安全性, 贡献了 eol_p 解析器, 动态解析器和文档, 并且从头脑风暴, 设计到编码的几乎每个方面都发挥了积极作用. 而且, 一如既往地帮助保持 Linux 上 g++ 回归测试的常绿 :-).

Martijn W. Van Der Lee 我们的网站管理员, 并贡献了 RFC821 解析器.

Giovanni Bajo 在最后关头为 Spirit 1.8.0 做了针对 CodeWarrior 8.3 的调整. 说实话, Giovanni 没有早出现在这个名单里让我感到惭愧. 自第一个 Boost.Spirit 发布版 Spirit 1.5 以来, 他做了大量工作. 他在把 Spirit 的迭代器代码移植到新的 Boost 迭代器库(第 2 版)方面功不可没. 他还做了各种缺陷修复, 并零零散散地编写了一些测试.

Juan Carlos Arevalo-Baeza (JCAB)* 在 C++ 解析器, 位置迭代器方面的工作, 向 v1.5 的移植, 以及让邮件列表的讨论保持活跃.

Vaclav Vesely: 许多东西, no_actions 指令, 各种补丁修复, distinct 解析器, 惰性解析器, 一些 phoenix 调整和附加组件(例如 new_). 另外, *Stefan Slapeta] 及其夫人编辑了 Vaclav 的 distinct 解析器文档.

Raghavendra Satish 完成了最初的 v1.3 向 VC++ 的移植, 以及他在 Phoenix 上的工作.

Noah Stein 跟进并协助 Ragav 完成 VC++ 移植.

Hakki Dogusan, 其最初的 v1.0 Pascal 解析器.

John (EBo) David 在 VM 方面的工作, 以及在我编码时在肩后注视, 让人感觉像是在进行远程极限编程.

Chris Uzdavinis 提供了评论和宝贵建议, 并编辑了文档.

Carsten Stoll, 其在动态解析器方面的工作.

Andy Elvey 及其 conifer 解析器.

Peter Simons 提供了 RFC 日期解析器示例和教程, 并帮忙处理了一些琐碎细节.

Markus Schöpflin 建议了 end_p 解析器和许多其他巧妙的东西, 并在邮件列表中非常活跃.

Doug Gregor 担任指导, 并拥有看到别人看不到之处的能力.

Gustavo Guerra 在最后关头评审了 Spirit 并不断提供反馈, 还有零零星星的补丁(例如提出了实数解析器的新点号行为).
