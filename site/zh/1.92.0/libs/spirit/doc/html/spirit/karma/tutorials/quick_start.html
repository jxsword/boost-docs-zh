Spirit.Karma 是什么?

在关于 Spirit.Karma 的整个描述中, 我们将尽力与 Spirit.Qi 的文档保持高度一致. 理由有很多:

  • Spirit.Karma 是 Spirit.Qi 的对应物. 有人说, 它是 Spirit.Qi 之'阳'所对应的'阴'. Spirit.Karma 从内部数据结构生成字节序列, 正如 Spirit.Qi 把字节序列解析成那些 (完全相同的) 内部数据结构.
  • 两个库的结构几乎完全相同, 语义非常相似, 且都使用相同的工具构建. 两个库都实现了一种语言, 将各自领域 (解析与生成) 的特性转化为一个简单的接口.

为什么在生成输出这样简单的事情上要使用生成器库? 长期以来, 程序员们一直在使用 printf、std::stream 格式化, 或者 boost::format 已经很长时间了. 答案是 - 是的, 对于简单的输出格式化任务, 这些熟悉的工具或许是快速的解决方案. 但经验表明: 一旦格式化需求变得更加复杂, 输出生成在代码的可读性、可维护性和灵活性方面就会变得愈发具有挑战性. 最后同样重要的是, 事实证明, 使用 Spirit.Karma 的代码比使用上述任一 '直接' 方法的等价代码运行得快得多 (一些数据参见: 数值生成器的性能)

你可能会争辩说, 更复杂的任务需要更复杂的工具. 但事实证明并非如此! 整个 Spirit 库的设计目标就是易于使用, 同时又能从简单的应用扩展到非常复杂的应用.

就开发的简单性与部署的便利性而言, Spirit.Karma 与本文档其他地方对 Spirit.Qi 的描述相同: 整个库仅由头文件组成, 无需链接或构建任何库. 只需将 spirit 发行包放入 include 路径, 编译并运行即可. 代码体积? 非常紧凑, 基本上与手写代码相当.

Spirit.Karma 教程采用循序渐进的方式编写, 从最基本的内容开始, 复杂度逐步提升. 再次强调: 请记住, 输出生成与解析恰好相反. 你已经学到的关于使用 Spirit.Qi 进行解析的所有知识, 都适用于使用 Spirit.Karma 生成格式化输出. 你所要做的, 就是把 Spirit.Karma 看作 Spirit.Qi 的镜像.
