Lexer
说明

Lexer 是最基本的概念. Lexer 有一个成员函数 collect, 接受一个记号定义容器 Def, 以及词法分析器组件的记号定义需要加入的词法分析器状态的名称 (一个字符串). 它不返回任何内容 (返回类型为 void). 每个 Lexer 可以代表一个特定的模式或算法, 也可以是由其他 Lexer 组合而成的更复杂的词法分析器组件. 此外, Lexer 还暴露一个成员 add_actions, 它接受记号定义容器 Def, 不返回任何内容 (同样, 返回类型为 void).

记法约定

l

一个Lexer.

L

一个 Lexer 类型.

Def

一个记号定义容器类型.

State

用于表示词法分析器状态名的类型.

有效表达式

在下文表达式中, 词法分析器组件 l 的行为在基础概念 Lexer 中未作规定. 这些行为在后续更细化的概念及其具体模型中加以规定.

对任意 Lexer, 以下表达式必须有效:

表达式

语义

返回类型

l.collect(def, state, targetstate)

把此 Lexer 实例提供的全部记号定义添加到词法分析器状态 state (属于记号定义容器 def) 中. 匹配此记号后, 词法分析器应切换到状态 targetstate (可选)

void

l.add_actions(def)

把此 Lexer 实例提供的全部语义动作添加到记号定义容器 def 中.

void

类型表达式

表达式

说明

traits::is_lexer<L>::type

元函数: 求值为 mpl::true_, 条件是某类型 L 为 Lexer; 否则求值为 mpl::false_ (参见 MPL Boolean Constant).
后置条件

从 l.collect 返回后, 应满足以下后置条件:

  • 返回时, def 将包含 Lexer l 中定义的全部记号定义, 包括 l 内部包含的所有 Lexer.

从 l.add_actions 返回后, 应满足以下后置条件:

  • 返回时, def 将包含与 Lexer l 中定义的相应记号定义正确关联的全部语义动作, 包括 l 内部包含的所有 Lexer 所定义的语义动作.
模型

Spirit.Lex 中的所有词法分析器组件都是 Lexer 概念的模型.
