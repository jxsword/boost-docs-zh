PrimitiveLexer
说明

PrimitiveLexer 是客户端用来构建更复杂词法分析器组件的最基本构建块.

细化自

Lexer

类型表达式

表达式

说明

traits::is_primitive_lexer<L>::type

元函数: 求值为 mpl::true_, 条件是某类型 L 为 PrimitiveLexer; 否则求值为 mpl::false_ (参见 MPL Boolean Constant).
模型

以下词法分析器组件符合该模型:

  • 字符字面量 (即 'x'), char_,
  • 字符串字面量 ("abc"), std::basic_string<>, string
