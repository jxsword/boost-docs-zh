输入结尾解析器 (eoi)
说明

eoi 解析器匹配输入结尾 (当输入耗尽时返回长度为 0 的成功匹配)

头文件 
// forwards to <boost/spirit/home/qi/auxiliary/eoi.hpp>
#include <boost/spirit/include/qi_eoi.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::eoi // alias: boost::spirit::qi::eoi

所属模型

PrimitiveParser

表达式语义

仅当表达式的语义与 PrimitiveParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

eoi

创建匹配输入结尾的解析器.
属性

表达式

属性

eoi

unused

复杂度

O(1)
