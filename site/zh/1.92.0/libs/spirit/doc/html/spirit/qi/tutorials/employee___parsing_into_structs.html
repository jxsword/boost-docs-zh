Employee - 解析到结构体

这是 Spirit General List 中的常见问题: 我如何解析并把结果放进一个 C++ 结构体? 当然, 到这一步, 你已经知道使用语义动作完成此事的各种方法. 给猫剥皮的方法有很多. Spirit2 是完全属性化的, 让这件事更容易. 下一个示例演示了 Spirit2 的一些让这件事变简单的特性. 在此过程中, 你将学到:

  • 更多关于属性的内容
  • 自动 rule
  • 更多内建解析器
  • 指令

首先, 让我们创建一个表示员工的 struct:

struct employee
{
    int age;
    std::string surname;
    std::string forename;
    double salary;
};

然后, 我们需要把 employee 结构体告知 Boost.Fusion, 使其成为文法可以使用的一等 fusion 公民. 如果你还不了解 fusion, 它是一个用于处理异构数据集合 (通常称为 tuple) 的 Boost 库. Spirit 作为其基础设施的一部分大量使用 fusion.

在 fusion 看来, struct 只是一种形式的 tuple. 你可以把任何 struct 适配为完全合规的 fusion tuple:

BOOST_FUSION_ADAPT_STRUCT(
    client::employee,
    (int, age)
    (std::string, surname)
    (std::string, forename)
    (double, salary)
)

现在我们为 employee 编写解析器. 输入的形式如下:

employee{ age, "surname", "forename", salary }

上代码:

template <typename Iterator>
struct employee_parser : qi::grammar<Iterator, employee(), ascii::space_type>
{
    employee_parser() : employee_parser::base_type(start)
    {
        using qi::int_;
        using qi::lit;
        using qi::double_;
        using qi::lexeme;
        using ascii::char_;

        quoted_string %= lexeme['"' >> +(char_ - '"') >> '"'];

        start %=
            lit("employee")
            >> '{'
            >>  int_ >> ','
            >>  quoted_string >> ','
            >>  quoted_string >> ','
            >>  double_
            >>  '}'
            ;
    }

    qi::rule<Iterator, std::string(), ascii::space_type> quoted_string;
    qi::rule<Iterator, employee(), ascii::space_type> start;
};

此示例的完整 cpp 文件可在此处找到: ../../example/qi/employee.cpp

让我们一步一步地走一遍 (不一定自上而下).

template <typename Iterator>
struct employee_parser : grammar<Iterator, employee(), space_type>

employee_parser 是一个文法. 和之前一样, 我们把它做成模板, 以便针对不同的迭代器类型复用它. 文法的签名为:

employee()

意思是该解析器生成 employee 结构体. employee_parser 使用 space_type 作为其跳过器来跳过空白字符.

employee_parser() : employee_parser::base_type(start)

初始化基类.

rule<Iterator, std::string(), space_type> quoted_string;
rule<Iterator, employee(), space_type> start;

声明两个 rule: quoted_string 和 start. start 与文法本身具有相同的模板参数. quoted_string 有一个 std::string 属性.

Lexeme 
lexeme['"' >> +(char_ - '"') >> '"'];

lexeme 在从左花括号到右花括号之间禁止跳过空格. 该表达式解析带引号的字符串.

+(char_ - '"')

解析一个或多个字符, 双引号除外. 看到双引号时它会停止.

差集

表达式:

a - b

解析 a 但不解析 b. 其属性就是 A, 即 a 的属性. b 的属性被忽略. 因此, 以下的属性:

char_ - '"'

就是 char.

加 
+a

类似于 Kleene 星号. 但 +a 不是匹配所有内容, 而是匹配一个或多个. 与其相关函数 Kleene 星号一样, 其属性是一个 std::vector<A>, 其中 A 是 a 的属性. 把这些放在一起, 以下的属性

+(char_ - '"')

就是:

std::vector<char>
序列属性

那么以下的属性是什么

'"' >> +(char_ - '"') >> '"'

?

嗯, 通常, 以下的属性:

a >> b >> c

是:

fusion::vector<A, B, C>

其中 A 是 a 的属性, B 是 b 的属性, C 是 c 的属性. fusion::vector 是什么? —— 一个 tuple.

注释

如果你不明白我在说什么, 请参见: Fusion Vector. 此时去了解一下 Boost.Fusion 可能是个好主意. 在接下来的页面中你肯定会看到更多它的身影.

属性折叠

某些解析器, 特别是你看到的那些非常小的字面量解析器, 例如 '"', 没有属性.

没有属性的节点会被忽略. 在上面这样的序列中, 所有无属性的节点都会从 fusion::vector 中被过滤掉. 所以, 由于 '"' 没有属性, 而 +(char_ - '"') 有一个 std::vector<char> 属性, 整个表达式的属性本应是:

fusion::vector<std::vector<char> >

但等一下, 还有一条折叠规则: 如果属性后面跟着单个元素的 fusion::vector, 该元素会从其容器中裸露出来. 长话短说, 以下表达式的属性:

'"' >> +(char_ - '"') >> '"'

是:

std::vector<char>
自动 rule

常见如下形式的 rule:

r = p[_val = _1];

如果你有如上形式的 rule 定义, 其中 rule 右侧 (RHS) 的属性与左侧 (LHS) 的属性兼容, 那么你可以把它改写为:

r %= p;

p 的属性自动使用 r 的属性.

那么, 回到我们的 quoted_string rule:

quoted_string %= lexeme['"' >> +(char_ - '"') >> '"'];

是以下内容的简化版本:

quoted_string = lexeme['"' >> +(char_ - '"') >> '"'][_val = _1];

quoted_string rule 的属性 std::string 兼容于 右侧的属性: std::vector<char>. 右侧把解析出的属性直接就地提取到 rule 的属性中.

注释

r %= p 和 r = p 是等价的, 条件是没有与 p 关联的语义动作.

最后

现在只剩一个 rule, 即起始 rule:

start %=
    lit("employee")
    >> '{'
    >>  int_ >> ','
    >>  quoted_string >> ','
    >>  quoted_string >> ','
    >>  double_
    >>  '}'
    ;

应用上面的折叠规则, 右侧的属性为:

fusion::vector<int, std::string, std::string, double>

这些节点没有属性:

  • lit("employee")
  • '{'
  • ','
  • '}'
注释

如果你好奇的话, lit("employee") 与 "employee" 相同. 我们必须把它包装进 lit, 因为紧随其后的是 >> '{'. 你不能对一个 char[] 和一个 char 做右移 -- 你懂的, C++ 语法规则.

回想一下, start 的属性就是 employee struct:

struct employee
{
    int age;
    std::string surname;
    std::string forename;
    double salary;
};

现在一切都清楚了吧? struct employee 确实 与 fusion::vector<int, std::string, std::string, double> 兼容. 因此, start 的右侧在工作时就地使用 start 的属性 (一个 struct employee).
