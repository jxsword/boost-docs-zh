Epsilon 生成器(eps)

eps 组件家族允许创建生成空字符串的伪生成器. 这一特性有时很有用, 可以强制生成器失败或成功, 或在生成过程中插入语义动作.

说明

Epsilon (eps) 是一个多用途生成器, 输出零长度字符串.

简单形式

在其最简形式中, eps 创建一个生成空字符串且总是成功的组件:

eps       // always emits a zero-length string

这种形式通常用于无条件触发语义动作. 例如, 在一组备选失败时触发错误消息时很有用:

r = a | b | c | eps[error()]; // Call error if a, b, and c fail to generate
语义谓词

eps(b) 组件同样生成空字符串, 但仅当 b 为 true 时才成功, 否则失败. 它的惰性变体 eps(fb) 等价于 eps(b), 区别在于它会在生成时对所提供的函数 fb 求值, 并把返回值用作成功的判据.

语义谓词允许你在文法的任何位置附加条件函数. 在这种角色下, epsilon 接受一个 惰性实参, 它返回 true 或 false. 该 惰性实参 通常是一个测试, 被调用以解决文法中的歧义. 当该 惰性实参 的结果求值为 false 时, 将报告生成器失败. 否则将输出空字符串. 一般形式是:

eps_p(fb) << rest;

调用 惰性实参 fb 来进行语义测试. 如果测试返回 true, 则会对 rest 求值. 否则, 产生式将提前返回, 不再触及 rest.

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

eps

创建一个生成空字符串的组件. 总是成功.

eps(b)

创建一个生成空字符串的组件. 当 b 为 true 时成功 (除非底层输出流报告错误).

eps(fb)

创建一个生成空字符串的组件. 当 fb 在生成时返回 true 时成功 (除非底层输出流报告错误).
属性

表达式

属性

eps

unused

eps(b)

unused

eps(fb)

unused

复杂度

O(1)

复杂度是常量, 因为不生成任何输出.

eps 生成器的基本用法:

test_generator("abc", eps[std::cout << val("starting eps example")] << "abc");
test_generator("abc", eps(true) << "abc");
test_generator("", eps(false) << "abc");      // fails as eps expression is 'false'
