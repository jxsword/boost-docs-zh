有符号整数解析器 (int_ 等)
说明

int_parser 可以解析任意长度和大小的有符号整数. 这与 uint_parser 几乎相同. 唯一的区别是额外的任务: 解析数字前面的 '+' 或 '-' 符号. 类接口与 uint_parser 的相同.

int_parser 解析器可用于解析普通的原始 C/C++ 整数, 甚至用户定义的标量 (如 bigint, 无限精度整数), 只要该类型遵循特定的表达式要求 (下文有文档).

头文件 
// forwards to <boost/spirit/home/qi/numeric/int.hpp>
#include <boost/spirit/include/qi_int.hpp>

另请参见 包含结构.

注释

long_long 仅在定义了预处理器常量 BOOST_HAS_LONG_LONG 的平台上可用 (即对 signed long long (64 位) 无符号整数类型有本机支持的平台上).

注释

lit 同时被 字符解析器 和数值解析器复用. 一般而言, 传入字符时创建字符解析器, 使用数值字面量时创建数值解析器.

概要 
template <
    typename T
  , unsigned Radix
  , unsigned MinDigits
  , int MaxDigits>
struct int_parser;

使用默认基数 (10) 匹配字面量 num. 如果解析出的值不等于指定值, 解析器将失败.

 

int_parser<
    T, Radix, MinDigits, MaxDigits
>()

解析 T 类型的有符号整数, 使用基数 Radix, 最少 MinDigits 位, 最多 MaxDigits 位.

 

int_parser<
    T, Radix, MinDigits, MaxDigits
>()(num)

匹配字面量 num (T 类型), 使用基数 Radix, 最少 MinDigits 位, 最多 MaxDigits 位. 如果解析出的值不等于指定值, 解析器将失败.
重要

所有数值解析器都会基于类型 T 检查溢出情况, 该类型即相应 int_parser<> 实例化时所用的类型. 如果解析出的数字溢出该类型, 解析将失败. 请注意, 溢出检查并非基于给定属性的类型, 而仅取决于模板参数 T.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::phoenix::val;
using boost::spirit::qi::lit;
using boost::spirit::qi::int_;

基本有符号整数:

// signed int
test_parser("+12345", int_);
test_parser("-12345", int_);
test_parser("+12345", int_(12345));
test_parser("-12345", int_(-12345));
test_parser("+12345", int_(val(12345)));
test_parser("-12345", int_(val(-12345)));

// literals
test_parser("+12345", lit(12345));
test_parser("-12345", lit(-12345));
test_parser("+12345", lit(val(12345)));
test_parser("-12345", lit(val(-12345)));
