基于迭代器的解析器 API
说明

该库提供了几个自由函数, 使解析变得轻而易举. 这些解析器函数有两种形式. 第一种形式 parse 工作在字符层级. 第二种 phrase_parse 工作在短语层级, 需要跳过解析器. 两个版本都可以通过引用传入属性, 解析成功时这些属性将保存解析得到的值.

头文件 
// forwards to <boost/spirit/home/qi/parse.hpp>
#include <boost/spirit/include/qi_parse.hpp>

对于可变参数属性:

// forwards to <boost/spirit/home/qi/parse_attr.hpp>
#include <boost/spirit/include/qi_parse_attr.hpp>

API 的可变属性版本允许向解析函数传入一个或多个属性. 接受两个或更多属性的函数仅在解析器表达式为 序列 时可用. 此时, 传入的每个属性都必须与序列的相应部分匹配.

对于从给定属性类型推导正确 (匹配) 解析器类型的 API 函数:

// forwards to <boost/spirit/home/qi/detail/parse_auto.hpp>
#include <boost/spirit/include/qi_parse_auto.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::qi::parse

boost::spirit::qi::phrase_parse

boost::spirit::qi::skip_flag::postskip

boost::spirit::qi::skip_flag::dont_postskip

概要 
namespace boost { namespace spirit { namespace qi
{
    template <typename Iterator, typename Expr>
    inline bool
    parse(
        Iterator& first
      , Iterator last
      , Expr const& expr);

    template <typename Iterator, typename Expr
      , typename Attr1, typename Attr2, ..., typename AttrN>
    inline bool
    parse(
        Iterator& first
      , Iterator last
      , Expr const& expr
      , Attr1& attr1, Attr2& attr2, ..., AttrN& attrN);

    template <typename Iterator, typename Expr, typename Skipper>
    inline bool
    phrase_parse(
        Iterator& first
      , Iterator last
      , Expr const& expr
      , Skipper const& skipper
      , BOOST_SCOPED_ENUM(skip_flag) post_skip = skip_flag::postskip);

    template <typename Iterator, typename Expr, typename Skipper
      , typename Attr1, typename Attr2, ..., typename AttrN>
    inline bool
    phrase_parse(
        Iterator& first
      , Iterator last
      , Expr const& expr
      , Skipper const& skipper
      , Attr1& attr1, Attr2& attr2, ..., AttrN& attrN);

    template <typename Iterator, typename Expr, typename Skipper
      , typename Attr1, typename Attr2, ..., typename AttrN>
    inline bool
    phrase_parse(
        Iterator& first
      , Iterator last
      , Expr const& expr
      , Skipper const& skipper
      , BOOST_SCOPED_ENUM(skip_flag) post_skip
      , Attr1& attr1, Attr2& attr2, ..., AttrN& attrN);
}}}
注释

从 Spirit V2.5 (随 Boost V1.47 发布) 开始, 占位符 _val 可以用在附加到顶层解析器组件的语义动作中. 此时 _val 指作为整体给定的属性. 对于接受多个属性参数的 API 函数, _val 将指一个 Fusion vector 或属性的引用.

基于自动创建匹配解析器类型的 Spirit.Qi 解析器 API 函数:

namespace boost { namespace spirit { namespace qi
{
    template <typename Iterator, typename Attr>
    inline bool
    parse(
        Iterator& first
      , Iterator last
      , Attr& attr);


    template <typename Iterator, typename Attr, typename Skipper>
    inline bool
    phrase_parse(
        Iterator& first
      , Iterator last
      , Attr& attr
      , Skipper const& skipper
      , BOOST_SCOPED_ENUM(skip_flag) post_skip = skip_flag::postskip);
}}}

如果所有涉及的解析器组件都没有失败, 上述所有函数返回 true; 否则返回 false.

支持的最大实参数量受预处理器常量 SPIRIT_ARGUMENTS_LIMIT 限制. 该常量默认为预处理器常量 PHOENIX_LIMIT 定义的值 (后者又默认为 10).

注释

带有两个或更多属性的可变参数函数在内部把对全部传入属性的引用组合成一个 fusion::vector, 并将其作为一个组合属性转发给对应的单属性函数.

phrase_parse 函数中, 未将显式 skip_flag 作为参数之一的版本会在解析器表达式成功匹配之后调用传入的跳过器. 可以通过使用该函数的其他版本并向相应参数传入 skip_flag::dont_postskip 来禁止这一行为.

参数

说明

Iterator

ForwardIterator, 指向待解析的源.

Expr

一个可以转换为 Qi 解析器的表达式.

Skipper

用于跳过空白字符的解析器.

Attr

用于创建相应解析器类型的属性类型.

Attr1, Attr2, ..., AttrN

一个或多个属性.
