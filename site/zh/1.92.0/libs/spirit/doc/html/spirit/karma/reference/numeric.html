数值生成器

无符号整数生成器(uint_ 等)
有符号整数生成器(int_ 等)
实数生成器(float_, double_ 等)
布尔生成器(bool_)

该库包含一些用于生成布尔值, 有符号和无符号整数以及实数的预定义对象. 这些生成器是完全参数化的. 数值生成的大多数重要方面都可以进行精细调整以满足需求. 这包括基数, 指数, 小数部分等. 策略 (Policies) 控制实数生成器的行为. 有一些预定义策略涵盖最常见的实数格式, 但用户也可以在需要时提供自己的策略.

数值解析器经过精细调优 (采用循环展开和大量模板元编程), 具有可与 ltoa, ssprintf 和 _gcvt 等底层 C 函数相媲美的卓越性能. 基准测试显示其速度比对应的 C 函数快达 2 倍 (参见此处: 数值生成器的性能). 这表明你可以编写极其紧凑的泛型 C++ 代码, 即使不超越 C, 也足以与之媲美.
