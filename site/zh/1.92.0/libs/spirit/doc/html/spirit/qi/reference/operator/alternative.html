备选解析器 (a | b)
说明

备选运算符 a | b 匹配两个或更多操作数 (a、b 等) 之一:

a | b | ...

备选操作数从最左边的操作数开始, 按 "首个匹配获胜" 的原则逐个尝试. 找到成功匹配的备选项后, 解析器就结束搜索, 实质上是对其他潜在可行候选者的搜索进行短路. 这种短路隐式地赋予最左边的备选项最高优先级.

短路的执行方式与 C 或 C++ 的逻辑表达式相同; 例如 if (x < 3 || y < 2), 其中如果 x < 3, 则完全不做 y < 2 测试. 除了为备选项提供隐式的优先级规则 (鉴于其非确定性本质, 这是必要的) 之外, 短路还改善了执行时间. 如果你的备选项顺序在逻辑上无关紧要, 应尽量把 (预期) 最常见的选择放在最前面以获得最大效率.

表达式

属性

a | b 

a: A, b: B --> (a | b): variant<A, B>
a: A, b: Unused --> (a | b): optional<A>
a: A, b: B, c: Unused --> (a | b | c): optional<variant<A, B> >
a: Unused, b: B --> (a | b): optional<B>
a: Unused, b: Unused --> (a | b): Unused
a: A, b: A --> (a | b): A
注释

备选解析器不会因某个备选项失败而回滚对外层属性所做的修改. 如果你需要确保只有成功的备选项才修改外层属性, 请使用指令 hold[].

复杂度

备选解析器的总体复杂度由其各元素复杂度之和决定. 备选解析器本身的复杂度为 O(N), 其中 N 是备选项的数量.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::ascii::string;
using boost::spirit::qi::int_;
using boost::spirit::qi::_1;
using boost::variant;

简单用法:

test_parser("Hello", string("Hello") | int_);
test_parser("123", string("Hello") | int_);

提取属性 variant (使用 Boost.Variant):

variant<std::string, int> attr;
test_parser_attr("Hello", string("Hello") | int_, attr);

这应打印 "Hello". 注意: 从 variant 中提取值有更好的方法, 参见 Boost.Variant 的访问 (visitation). 此代码仅用于演示.

if (boost::get<int>(&attr))
    std::cout << boost::get<int>(attr) << std::endl;
else
    std::cout << boost::get<std::string>(attr) << std::endl;

使用语义动作配合 Boost.Phoenix 提取属性 (这应打印 123):

test_parser("123", (string("Hello") | int_)[std::cout << _1 << std::endl]);
