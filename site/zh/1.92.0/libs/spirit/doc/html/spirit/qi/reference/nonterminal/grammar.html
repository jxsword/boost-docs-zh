解析器文法
说明

文法封装了一组 rule (以及基础解析器 (PrimitiveParser) 和子文法). 文法是模块化和组合的主要机制. 文法可以组合起来形成更复杂的文法.

头文件 
// forwards to <boost/spirit/home/qi/nonterminal/grammar.hpp>
#include <boost/spirit/include/qi_grammar.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::qi::grammar

概要 
template <typename Iterator, typename A1, typename A2, typename A3>
struct grammar;
模板参数

参数

说明

默认值

Iterator

期望该 rule 工作所用的底层迭代器类型.

none

A1, A2, A3

Signature, Skipper 或 Locals, 以任意顺序. 参见下表.

参见下表.

以下是关于模板参数的更多信息:

参数

说明

默认值

Signature

规定 grammar 的合成 (返回值)属性和继承属性 (实参). 更多信息见此: Nonterminal.

unused_type. 当 Signature 默认为 unused_type 时, 效果等同于指定签名为 void(), 这也等价于 unused_type()

Skipper

指定文法的跳过器解析器. 如果希望文法跳过空白字符, 请指定此项.

unused_type

Locals

规定 grammar 的局部变量. 参见 Nonterminal.

unused_type

所属模型

Nonterminal

记法约定

g

一个 grammar

表达式语义

仅当表达式的语义与 Nonterminal 不同或在其中未定义时, 才给出其语义.

表达式

语义

 

template <typename Iterator>
struct my_grammar : grammar<Iterator, A1, A2, A3>
{
    my_grammar() : my_grammar::base_type(start, name)
    {
        // Rule definitions
        start = /* ... */;
    }

    rule<Iterator, A1, A2, A3> start;
    // more rule declarations...
};

文法定义. name 是一个可选字符串, 为文法命名, 对调试和错误处理很有用.
注释

grammar 及其起始 rule (传递给 grammar 基类构造函数的 rule) 的模板参数必须匹配, 否则你会看到编译错误.

属性

文法的解析器属性是 T, 即其合成属性. 参见 Attribute

复杂度

复杂度由其定义的复杂度决定.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::ascii::space_type;
using boost::spirit::int_;
using boost::spirit::qi::grammar;
using boost::spirit::qi::rule;

grammar 基本用法:

struct num_list : grammar<char const*, space_type>
{
    num_list() : base_type(start)
    {
        using boost::spirit::int_;
        num = int_;
        start = num >> *(',' >> num);
    }

    rule<char const*, space_type> start, num;
};

如何使用示例 grammar:

num_list nlist;
test_phrase_parser("123, 456, 789", nlist);
