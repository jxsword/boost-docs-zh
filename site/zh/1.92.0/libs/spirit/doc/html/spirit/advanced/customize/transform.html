将属性变换为其他类型(Qi 与 Karma)

transform_attribute

模板 transform_attribute 是用作属性定制点的类型. Qi 的 rule, 语义动作和 attr_cast, 以及 Karma 的 rule, 语义动作和 attr_cast 会调用它. 它用于把用户提供的属性自动变换为右侧组件(对于 rule), 语义动作或内嵌组件(对于 attr_cast)所期望的属性类型.

注释

此定制点的接口在 Boost V1.44 中发生了变化. 我们添加了 Domain 模板参数, 以便为 Spirit.Qi 和 Spirit.Karma 提供更细粒度的特化.

模块头文件 
#include <boost/spirit/home/support/attributes.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename Exposed, typename Transformed, typename Domain, typename Enable>
struct transform_attribute
{
    typedef <unspecified> type;

    static type pre(Exposed& val);
    static void post(Exposed& val, type attr);    // Qi only
    static void fail(Exposed&);                   // Qi only
};
模板参数

参数

说明

默认值

Exposed

提供给组件的、需要变换的属性类型.

none

Transformed

组件期望的、要作为变换结果提供的属性类型.

none

Domain

实例化此模板的子库的域. 通常是 qi::domain 或 karma::domain.

none

Enable

辅助模板参数, 可利用 SFINAE 有选择地启用或禁用 transform_attribute 的某些特化(即 boost::enable_if 或 boost::disable_if).

void

记法约定

Exposed

类型 Exposed 是用户传入的属性类型.

Transformed

类型 Transformed 是沿 rule 的右侧(attr_cast 的内嵌组件)传递的属性的类型.

Domain

实例化此模板的子库的域. 通常是 qi::domain 或 karma::domain.

exposed

Exposed 类型的实例.

transformed

Transformed 类型的实例.

表达式语义

表达式

语义

transform_attribute<Exposed, Transformed, Domain>::type

求值为用作变换结果的类型(要传递给 rule 的右侧或 attr_cast 的内嵌组件). 大多数情况下它等于 Transformed, 但在其他情况下可能求值为 Transformed&, 以避免多余的对象创建.

 

type transform_attribute<Exposed, Transformed, Domain>::pre(exposed)

执行 pre 变换, 在为 rule (或 attr_cast 的内嵌组件)调用右侧组件之前. 它接受用户提供的属性(类型为 Exposed), 并返回要沿组件层次向下传递的属性(类型为元函数 type 暴露的类型). 此函数会在 Qi 中以及为 Karma 而被调用.

 

void transform_attribute<Exposed, Transformed, Domain>::post(exposed, transformed)

执行 post 变换, 在为 rule (或 attr_cast 的内嵌组件)调用右侧组件之后. 它接受用户提供的原始属性和右侧(内嵌)组件返回的属性, 并应把结果传播回提供的属性实例. 此函数仅会在 Qi 中被调用.

 

void transform_attribute<Exposed, Transformed, Domain>::fail(exposed)

处理 rule (或 attr_cast 的内嵌组件)的右侧组件解析失败的情况. 此函数仅会在 Qi 中被调用.
预定义特化

模板参数

语义

Exposed, Transformed

type 求值为 Transformed; pre() 返回一个 Transformed 新实例, 从类型为 Exposed 的实参构造; post() 把 transformed 赋给 exposed.

optional<Exposed>, Transformed, typename disable_if<is_same<optional<Exposed>, Transformed> >::type

type 求值为 Transformed&; pre() 返回对 Transformed 实例的引用, 该实例存储在传入的 optional (类型为 optional<Exposed> 的实参)中, 必要时会初始化该 optional 实例; post() 不做任何事; fail() 把 optional (其实参)实例重置为未初始化状态.

Exposed&, Transformed

type 求值为 Transformed; pre() 返回一个 Transformed 新实例, 从类型为 Exposed 的实参构造; post() 把 transformed 赋给 exposed.

Attrib&, Attrib

type 求值为 Attrib&; pre() 返回其实参; post() 不做任何事.

Exposed const, Transformed

(仅在 Karma 中使用) type 求值为 Transformed; pre() 返回其实参; post() 未实现.

Attrib const&, Attrib

(仅在 Karma 中使用) type 求值为 Attrib const&; pre() 返回其实参; post() 未实现.

Attrib const, Attrib

(仅在 Karma 中使用) type 求值为 Attrib const&; pre() 返回其实参; post() 未实现.

unused_type, Attrib

type 求值为 unused_type; pre() 和 post() 不做任何事.

Attrib, unused_type

type 求值为 unused_type; pre() 和 post() 不做任何事.
何时实现

定制点 transform_attribute 需要为特定的一对类型实现: 每当提供给 rule 或 attr_cast 的属性类型无法自动变换为 rule 右侧(attr_cast 的内嵌组件)所期望的属性类型, 且上面所示的默认实现不适用时. 例如, 类型 Transformed 可能无法从类型 Exposed 构造.
