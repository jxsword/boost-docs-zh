匹配单个字符的记号
说明

本节描述的基于字符的记号定义有:

char_ 创建匹配单个字符的记号定义. char_ 记号定义与 standard 编码命名空间相关联. 在执行强制大小写转换和处理字符范围等基本操作时需要用到它.

头文件
模块头文件 
// forwards to <boost/spirit/home/lex/lexer/char_token_def.hpp>
#include <boost/spirit/include/lex_char_token_def.hpp>

另请参见 包含结构.

命名空间

名称

lex::char_

所属模型

PrimitiveLexer

记法约定

ch

来自 standard 字符集的特定于字符类的字符.

表达式语义

仅当表达式的语义与 PrimitiveLexer 不同或在其中未定义时, 才给出其语义.

表达式

说明

ch

创建匹配字符字面量 ch 的记号定义.

lex::char_(ch)

创建匹配字符 ch 的记号定义.
