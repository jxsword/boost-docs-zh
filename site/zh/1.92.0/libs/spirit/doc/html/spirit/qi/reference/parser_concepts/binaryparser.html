BinaryParser
说明

BinaryParser 是一个拥有两个主体的复合解析器: left 和 right. BinaryParser 遵循组合设计模式 (Composite Design Pattern), 允许将其主体按与 Parser 的单个实例相同的方式对待.

traits::is_binary_parser<P>::type

元函数: 求值为 mpl::true_, 条件是某类型 P 为 BinaryParser; 否则求值为 mpl::false_ (参见 MPL Boolean Constant).
不变式

对任意 BinaryParser P, 以下不变式始终成立:

  • traits::is_parser<P::left_type>::type 求值为 mpl::true_
  • traits::is_parser<P::right_type>::type 求值为 mpl::true_
