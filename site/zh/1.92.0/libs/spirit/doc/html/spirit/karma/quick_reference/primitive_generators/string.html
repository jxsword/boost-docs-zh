字符串生成器

有关 字符串生成器 的更多信息, 请参见此处.

表达式

属性

说明

str

Unused

生成 str

lit(str)

Unused

生成 str

string

Str

生成作为属性提供的字符串

string(str)

Str

生成 str, 如果提供了属性则必须匹配

symbols<Attr, T>

Attr

声明一个符号表 sym. Attr 是用作符号生成器键的原始属性的类型. T 是与每个键关联的数据类型.

 

sym.add
    (attr1, val1)
    (attr2, val2)
    /*...more...*/
;

N/A

向符号表 sym 添加符号. val1 和 val2 是类型为 T 的可选数据, 即与每个键关联的数据类型.

sym

T

输出符号表 sym 中的条目. 如果在符号表中找到该属性, 则输出相应的值. 如果 sym 不存储值, 则输出原始属性.
