Optional 生成器(-a)
说明

optional 生成器用于有条件地执行内嵌生成器. 它总是成功.

头文件 
// forwards to <boost/spirit/home/karma/operator/optional.hpp>
#include <boost/spirit/include/karma_optional.hpp>

另请参见 包含结构.

所属模型

UnaryGenerator

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

-a

生成器 a 根据属性的可用性执行. 如果其内嵌生成器成功, optional 生成器就成功 (除非底层输出流报告错误).
属性

参见 复合属性记法.

表达式

属性

-a (optional, 一元 -)

 

a: A --> -a: optional<A>
a: Unused --> -a: Unused
重要

上表仅把 optional<A> 用作占位符. 记法 optional<A> 表示数据类型 boost::optional<A>.

如果所提供的属性持有有效值, optional 生成器会执行其内嵌生成器一次. 它把其属性中持有的值转发给内嵌生成器.

需要注意的重要一点是, optional 生成器不会对其内嵌元素生成的输出执行任何缓冲. 这意味着任何失败的元素可能已经生成了一些输出, 这些输出 不会 被回滚.

提示

强制 optional 生成器表现得像有缓冲一样的最简单方法是把它包装进一个缓冲指令中 (参见 buffer):

buffer[-a]

它将 不 生成任何输出, 如果生成器 -a 失败.

复杂度

optional 生成器的总体复杂度由其内嵌生成器的复杂度决定. optional 生成器本身的复杂度是 O(1).

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些包含:

#include <boost/spirit/include/karma.hpp>
#include <boost/spirit/include/support_utree.hpp>
#include <boost/phoenix/core.hpp>
#include <boost/phoenix/operator.hpp>
#include <boost/fusion/include/std_pair.hpp>
#include <boost/proto/deep_copy.hpp>
#include <iostream>
#include <string>

一些 using 声明:

using boost::spirit::karma::double_;

optional 生成器的基本用法:

boost::optional<double> val(1.0);
test_generator_attr("1.0", -double_, val);
test_generator_attr("2.0", -double_, 2.0);

空 optional 生成器的用法和结果:

boost::optional<double> val;          // empty optional
test_generator_attr("", -double_, val);
