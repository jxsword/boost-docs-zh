解析器指令

抑制跳过的解析器指令 (lexeme[])
抑制跳过且不做预跳过的解析器指令 (no_skip[])
禁用区分大小写的解析器指令 (no_case[])
忽略属性的解析器指令 (omit[])
用于转换解析的指令 (raw[])
重复解析器指令 (repeat[])
测试解析器是否成功的指令 (matches[])
重新启用跳过的解析器指令 (skip[])
用于属性提交/回滚的解析器指令 (hold[])
强制原子赋值的解析器指令 (as<T>, as_string[], as_wstring[])
期望指令 (expect[])

本模块包含可用于增强和参数化其他解析器的各种指令. 它包括 no_case、lexeme、omit、raw、repeat、matches、no_skip、skip、hold、as<T>、as_string 和 as_wstring 指令.

模块头文件 
// forwards to <boost/spirit/home/qi/directive.hpp>
#include <boost/spirit/include/qi_directive.hpp>
