字符串生成器(string, lit)
说明

本节描述的字符串生成器是:

string 生成器输出一个字符串. string 生成器是隐式 verbatim 的: delimit 解析器不会应用在字符串的字符之间. string 生成器有一个关联的 字符编码命名空间. 在执行强制小写或大写等基本操作时需要它. 示例:

string("Hello")
string(L"Hello")
string(s)         // s is a std::string

lit 与 string 一样, 也输出一个字符串. 主要区别是 lit 不消耗属性. 像 "hello" 这样的普通字符串或 std::basic_string 等价于一个 lit. 示例:

"Hello"
lit("Hello")
lit(L"Hello")
lit(s)            // s is a std::string
头文件 
// forwards to <boost/spirit/home/karma/string/lit.hpp>
#include <boost/spirit/include/karma_string.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::lit // alias: boost::spirit::karma::lit

ns::string

在上表中, ns 表示相应字符串生成器使用的 字符编码命名空间.

所属模型

PrimitiveGenerator

记法约定

s

字符类特定的字符串 (参见字符类类型), 或求值为字符类特定字符串值的 惰性实参

S

字符类特定字符串 s 的类型.

ns

一个 字符编码命名空间.

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

说明

s

生成字符串字面量 s. 该生成器从不失败 (除非底层输出流报告错误).

lit(s)

生成字符串字面量 s. 该生成器从不失败 (除非底层输出流报告错误).

ns::string

生成由必需属性提供的字符串, 按由 ns 定义的字符集解释. 该生成器从不失败 (除非底层输出流报告错误).

ns::string(s)

生成字符串 s, 来自生成器初始化时使用的直接字面量值. 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.
注释

生成器 lit(s) 和 string(s) 既可以用字符串字面量值 (即 "abc") 初始化, 也可以用 std::basic_string<char_type, ...> 初始化, 其中 char_type 是底层字符序列所需值的类型.

注意

在 Spirit 2.4.1 及之前版本中, 生成器 string(s) 有一个未记录的特性. 给定实参 s, 只要 s 是给定属性的前缀, 生成器就会成功. 此问题已在 Spirit V2.4.2 中修复.

属性

表达式

属性

s

unused

lit(s)

unused

ns::string

S, 属性是必需的 (否则编译将失败)

ns::string(s)

S, 属性是可选的, 如果提供了, 生成器会把属性与 s 比较, 仅当两者相等时成功, 否则失败
注释

除了它们通常的 S 类型属性之外, 所有列出的生成器还接受 boost::optional<S> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 S 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

复杂度

O(N), 其中 N 是字符串生成器输出的字符数量

string 生成器的基本用法:

test_generator("abc", "abc");
test_generator("abc", lit("abc"));
test_generator("abc", lit(std::string("abc")));

test_generator_attr("abc", string, "abc");
test_generator("abc", string("abc"));
test_generator("abc", string(std::string("abc")));

test_generator_attr("abc", string("abc"), "abc");
test_generator_attr("", string("abc"), "cba");     // fails (as "abc" != "cba")
