记号定义基础组件

匹配单个字符的记号

本模块包含允许你创建记号定义的各种基础组件. 其中包括 char_ (字符字面量) 和 string (字符串字面量).

模块头文件 
// forwards to <boost/spirit/home/lex/primitives.hpp>
#include <boost/spirit/include/lex_primitives.hpp>

另请参见 包含结构.
