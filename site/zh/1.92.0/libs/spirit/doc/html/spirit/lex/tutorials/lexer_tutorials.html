Spirit.Lex 教程概述

Spirit.Lex 库在可能不同的词法分析器生成器库之上实现了若干组件. 它暴露一对迭代器, 解引用时返回由底层字符流生成的记号流. 生成的记号基于用户提供的记号定义.

目前, Spirit.Lex 构建在 Ben Hanson 的出色 Lexertl 库 (一个已被提议纳入 Boost 的库) 之上. Lexertl 提供了基于一组给定正则表达式构建状态机的必要功能. 但 Spirit.Lex 并不限于与 Lexertl 一起使用. 我们期望它能够与任何其他词法扫描器生成器库配合使用, 需要实现的只是一组暴露本文档所述良定义接口的封装对象.

注释

为清晰起见, 本文档中的所有示例都假定 Spirit.Lex 构建在 Lexertl 之上使用.

使用 Spirit.Lex 构建词法分析器具有高度可配置性, 其中大部分配置在编译期完成. 几乎所有可配置参数都有普遍实用的默认值, 使项目启动成为一件简单直接的任务. 以下是你可以调整的特性 (不完全) 列表, 用于把生成的词法分析器实例调整到实际需要:

  • 选择并定制词法分析器实例要生成的记号类型.
  • 选择并定制生成的记号实例能够保存的记号值类型.
  • 选择底层输入流的迭代器类型, 它将用作待记号化字符流的来源.
  • 定制词法分析器返回的迭代器类型, 以启用调试支持、对特定输入序列的特殊处理等.
  • 为词法分析器选择 动态 或 静态 运行期模型.

在库的开发过程中特别注意到: 无论选择哪些配置选项, 都会生成最优代码.

本节的一系列教程示例将引导你了解一些常见用例, 帮助你把握整体图景. 前两个快速上手示例 (Lex 快速上手 1 - 单词计数器: 使用 Spirit.Lex 和 Lex 快速上手 2 - 更佳单词计数器: 使用 Spirit.Lex) 在构建两个独立应用的同时介绍了 Spirit.Lex 库, 这两个应用不连接也不依赖于 Spirit 的任何其他部分. Lex 快速上手 3 - 使用解析器统计单词 一节演示了如何将词法分析器与解析器配合使用 (显然, 解析器是用 Spirit.Qi 构建的).
