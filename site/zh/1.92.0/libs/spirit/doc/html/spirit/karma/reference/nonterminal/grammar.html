生成器 Grammar
说明

grammar 封装了一组 规则 (以及原语生成器 (PrimitiveGenerator)和子 grammar). grammar 是模块化和组合的主要机制. grammar 可以组合起来形成更复杂的 grammar.

头文件 
// forwards to <boost/spirit/home/karma/nonterminal/grammar.hpp>
#include <boost/spirit/include/karma_grammar.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::karma::grammar

概要 
template <typename OutputIterator, typename A1, typename A2, typename A3>
struct grammar;
模板参数

参数

说明

默认值

OutputIterator

rule 预期工作的底层输出迭代器类型.

none

A1, A2, A3

Signature, Delimiter 或 Locals, 以任意顺序. 参见下表.

参见下表.

以下是关于模板参数的更多信息:

参数

说明

默认值

Signature

规定 grammar 的合成 (返回值)属性和继承属性 (实参). 更多信息见此: Nonterminal.

unused_type. 当 Signature 默认为 unused_type 时, 效果等同于指定签名为 void(), 这也等价于 unused_type()

Delimiter

规定 grammar 的分隔符生成器. 如果你想让 grammar 分隔生成的输出, 请指定此项.

unused_type

Locals

规定 grammar 的局部变量. 参见 Nonterminal.

unused_type

所属模型

Nonterminal

记法约定

g

一个 grammar

表达式语义

仅当表达式的语义与 Nonterminal 不同或在其中未定义时, 才给出其语义.

表达式

语义

 

template <typename OutputIterator>
struct my_grammar : grammar<OutputIterator, A1, A2, A3>
{
    my_grammar() : my_grammar::base_type(start, name)
    {
        // Rule definitions
        start = /* ... */;
    }

    rule<OutputIterator, A1, A2, A3> start;
    // more rule declarations...
};

grammar 定义. name 是一个可选字符串, 用于为 grammar 命名, 便于调试.
注释

grammar 及其起始 rule (传递给 grammar 基类构造函数的 rule) 的模板参数必须匹配, 否则你会看到编译错误.

属性

grammar 的生成器属性是 RT, 即其消耗属性. 参见 Attribute

复杂度

复杂度由其定义的复杂度决定.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::ascii::space_type;
using boost::spirit::ascii::space;
using boost::spirit::int_;
using boost::spirit::karma::grammar;
using boost::spirit::karma::rule;

grammar 基本用法:

struct num_list : grammar<output_iterator_type, space_type, std::vector<int>()>
{
    num_list() : base_type(start)
    {
        using boost::spirit::int_;
        num = int_;
        start = num << *(',' << num);
    }

    rule<output_iterator_type, space_type, std::vector<int>()> start;
    rule<output_iterator_type, space_type, int()> num;
};

如何使用示例 grammar:

num_list nlist;
std::vector<int> v;
v.push_back(123);
v.push_back(456);
v.push_back(789);
test_generator_attr_delim("123 , 456 , 789", nlist, space, v);
