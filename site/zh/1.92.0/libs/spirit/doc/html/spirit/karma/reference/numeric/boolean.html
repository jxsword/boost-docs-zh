布尔生成器(bool_)
说明

如你所料, bool_generator 可以从布尔值生成输出. bool_generator 生成器可用于从普通原始 C/C++ bool 值或用户定义的布尔类型生成输出, 只要该类型遵循特定的表达式要求 (有关这些要求的更多信息, 参见 下文)). bool_generator 是一个模板类. 模板参数可以精细调整其行为.

头文件 
// forwards to <boost/spirit/home/karma/numeric/bool.hpp>
#include <boost/spirit/include/karma_bool.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::lit // alias: boost::spirit::karma::lit

boost::spirit::bool_ // alias: boost::spirit::karma::bool_

boost::spirit::true_ // alias: boost::spirit::karma::true_

boost::spirit::false_ // alias: boost::spirit::karma::false_

注释

lit 被 字符串生成器, 字符生成器 和数值生成器复用. 一般来说, 传入字符时创建字符生成器, 传入字符串时创建字符串生成器, 使用数值 (布尔)字面量时创建数值生成器.

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

lit(b)

使用默认格式化生成布尔字面量 b (false 生成为 "false", 而 true 生成为 "true"). 该生成器从不失败 (除非底层输出流报告错误).

bool_

使用默认格式化生成由必需属性提供的布尔值 (false 生成为 "false", 而 true 生成为 "true"). 该生成器从不失败 (除非底层输出流报告错误).

bool_(b)

使用默认格式化生成由生成器初始化时使用的直接字面量值提供的布尔值 (false 生成为 "false", 而 true 生成为 "true"). 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.

true_

生成 "true". 如果该生成器有关联属性, 则只有当属性也是 true 时才成功 (除非底层输出流报告错误).

false_

生成 "false". 如果该生成器有关联属性, 则只有当属性也是 false 时才成功 (除非底层输出流报告错误).

上表列出的所有生成器(lit(num) 除外)都是下面描述的 bool_generator<B, Policies> 基本布尔生成器类型的预定义特化. 可以直接使用该类型, 通过各种格式化选项创建布尔生成器.

表达式

语义

 

bool_generator<
    B, Policies
>()

生成由必需属性提供的类型为 B 的布尔值, 使用指定的 Policies. 该生成器从不失败 (除非底层输出流报告错误).

 

bool_generator<
    B, Policies
>()(b)

生成由生成器初始化时使用的直接字面量值提供的类型为 B 的布尔值, 使用指定的 Policies. 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.
注释

所有布尔生成器都正确遵循 upper 和 lower 指令.

注释

除了它们通常的 B 类型属性之外, 所有列出的生成器还接受 boost::optional<B> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 B 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

布尔格式化策略

如果需要对布尔值进行特殊格式化, 重载策略类 bool_policies<B> 并把它用作 bool_generator<> 布尔生成器的模板参数. 例如:

struct special_bool_policy : karma::bool_policies<>
{
    template <typename CharEncoding, typename Tag
      , typename OutputIterator>
    static bool generate_false(OutputIterator& sink, bool b)
    {
        // we want to spell the names of false as eurt (true backwards)
        return string_inserter<CharEncoding, Tag>::call(sink, "eurt");
    }
};

typedef karma::bool_generator<special_bool_policy> backwards_bool_type;
backwards_bool_type const backwards_bool;

karma::generate(sink, backwards_bool, true);    // will output: true
karma::generate(sink, backwards_bool(false));   // will output: uert

模板参数 B 应当是使用重载策略类型进行格式化的类型. 同时 B 将用作所创建实数生成器的属性类型. B 的默认值是 bool.

布尔格式化策略表达式语义

布尔格式化策略应暴露以下内容:

表达式

说明

 

template <typename Inserter
  , typename OutputIterator
  , typename Policies>
bool call (OutputIterator& sink, Num n
  , Policies const& p);

这是用于生成布尔输出的主函数. 布尔生成器调用它来执行转换. 理论上所有工作都可以在这里实现, 但最简单的方法是使用模板参数 Inserter 所指定类型提供的现有功能. 该函数的默认实现是:

template <typename Inserter, typename OutputIterator
  , typename Policies>
static bool
call (OutputIterator& sink, B b, Policies const& p)
{
    return Inserter::call_n(sink, b, p);
}

sink 是用于生成的输出迭代器

b 是要转换的布尔值

p 是用于实例化此实数生成器的策略类型的实例.

 

template <typename CharEncoding,
    typename Tag, typename OutputIterator>
bool generate_false(
    OutputIterator& sink, B b);

当布尔值为 false 时调用此函数来生成它.

sink 是用于生成的输出迭代器

b 是要转换的布尔值 (该值为 false).

模板参数 CharEncoding 和 Tag 要么是 unused_type 类型, 要么描述要应用于任何输出的字符类和转换, 这些输出可能受 lower[] 或 upper[] 指令的影响.

返回值定义整个生成器的结果.

 

template <typename CharEncoding,
    typename Tag, typename OutputIterator>
bool generate_true(
    OutputIterator& sink, B b);

当布尔值为 true 时调用此函数来生成它.

sink 是用于生成的输出迭代器

b 是要转换的布尔值 (该值为 true).

模板参数 CharEncoding 和 Tag 要么是 unused_type 类型, 要么描述要应用于任何输出的字符类和转换, 这些输出可能受 lower[] 或 upper[] 指令的影响.

返回值定义整个生成器的结果.
复杂度

O(N), 其中 N 是表示生成的布尔值所需的字符数量.
