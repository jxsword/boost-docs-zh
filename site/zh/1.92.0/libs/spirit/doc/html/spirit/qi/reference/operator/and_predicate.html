与谓词解析器 (&a)
说明

句法谓词在求值另一个产生式之前断言某个条件语法得到满足. 与语义谓词 eps 类似, 句法谓词不消耗任何输入. 与谓词 (&a) 是一种肯定句法谓词, 仅当其谓词匹配时才返回零长度匹配.

头文件 
// forwards to <boost/spirit/home/qi/operator/and_predicate.hpp>
#include <boost/spirit/include/qi_and_predicate.hpp>

另请参见 包含结构.

&a

如果谓词 a 匹配, 则返回一个零长度匹配; 否则失败.
