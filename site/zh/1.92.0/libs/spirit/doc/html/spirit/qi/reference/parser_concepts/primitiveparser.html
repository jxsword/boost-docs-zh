PrimitiveParser
说明

PrimitiveParser 是客户端用来构建更复杂解析器的最基本构建块.

细化自

Parser

预跳过

进入 parse 成员函数时, PrimitiveParser 必须执行预跳过. 解析前将跳过前导的 skip 字符/记号. 只有 PrimitiveParser 需要执行此预跳过. 这通常通过调用 qi::skip_over 来完成:

qi::skip_over(f, l, skip);
类型表达式

表达式

说明

traits::is_primitive_parser<P>::type

元函数: 求值为 mpl::true_, 条件是某类型 P 为 PrimitiveParser; 否则求值为 mpl::false_ (参见 MPL Boolean Constant).
