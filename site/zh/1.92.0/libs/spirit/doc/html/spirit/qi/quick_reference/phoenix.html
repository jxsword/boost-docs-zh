Phoenix

Boost.Phoenix 使附加语义动作变得更容易. 你只需内联你的 lambda 表达式:

p[phoenix-lambda-expression]

Spirit.Qi 提供了一些 Boost.Phoenix 占位符, 用于访问 Attrib 和 Context 中难以以其他方式提取的重要信息.

Spirit.Qi 专用的 Phoenix 占位符

_1, _2... , _N

p 的第 N 个属性

_val

外围 rule 的合成属性.

_r1, _r2... , _rN

外围 rule 的第 N 个继承属性.

_a, _b... , _j

外围 rule 的局部变量(_a 指第一个).

_pass

把 false 赋给 _pass 可强制解析失败.

重要

上面提到的所有占位符都定义在命名空间 boost::spirit 中, 为了方便, 也在命名空间 boost::spirit::qi 中可用.
