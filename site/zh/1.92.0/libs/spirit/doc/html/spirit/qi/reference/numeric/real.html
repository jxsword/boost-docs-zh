实数解析器 (float_、double_ 等)
说明

real_parser 可以解析任意长度和大小的实数, 受其模板参数 T 限制. 数值基类型 T 可以是用户定义的数值类型, 例如 fixed_point (定点实数) 和 bignum (无限精度数字), 只要该类型遵循特定的表达式要求 (下文有文档).

警告

double_ 解析器和序列化器目前在某些边缘情况下会产生不正确的值. 详情参见 boostorg/spirit#804.

头文件 
// forwards to <boost/spirit/home/qi/numeric/real.hpp>
#include <boost/spirit/include/qi_real.hpp>

另请参见 包含结构.

lit 同时被 字符解析器 和数值解析器复用. 一般而言, 传入字符时创建字符解析器, 使用数值字面量时创建数值解析器.

RealPolicies

RealPolicies 模板参数是一个类, 把控制解析器行为的所有策略组合在一起. 策略控制实数解析器的行为.

默认值为 real_policies<T>. 提供默认值是为了应对最常见的情况 (实数的表示方式有很多种, 因而解析方式也有很多种). 在大多数情况下, 默认策略已经足够, 可以直接开箱即用. 它们被设计用来解析形如 nnn.fff.Eeee 的 C/C++ 风格浮点数, 其中 nnn 是整数部分, fff 是小数部分, E 是 'e' 或 'E', eee 是指数, 前面可选地带有 '-' 或 '+', 另外按照 C99 标准的强制要求以及纳入 C++0x 标准的提议, 还会额外检测 NaN 和 Inf: nan、nan(...)、inf 和 infinity (匹配不区分大小写). 这对应于以下文法:

sign
    =   lit('+') | '-'
    ;

nan
    =   no_case["nan"]
        >> -('(' >> *(char_ - ')') >> ')')
    ;

inf
    =   no_case[lit("inf") >> -lit("inity")]
    ;

floating_literal
    =   -sign >>
        (       nan
            |   inf
            |   fractional_constant >> -exponent_part
            |  +digit >> exponent_part
        )
    ;

fractional_constant
    =  *digit >> '.' >> +digit
    |  +digit >> -lit('.')
    ;

exponent_part
    =   (lit('e') | 'E') >> -sign >> +digit
    ;

有四个预定义的 RealPolicies 可直接使用:

表 4. 预定义策略

策略

说明

ureal_policies<double>

无符号.

real_policies<double>

带符号.

strict_ureal_policies<double>

无符号, 必须有小数点.

strict_real_policies<double>

带符号, 必须有小数点.

注释

整数被视为实数的子集, 因此例如 double_ 同样能识别整数 (不带小数点). 为了避免这种歧义, strict_ureal_policies 和 strict_real_policies 要求数字必须带有小数点才算成功匹配.

RealPolicies 的表达式要求

对于 RealPolicies 的模型, 以下表达式必须有效:

表达式

语义

RP::allow_leading_dot

允许前导小数点.

RP::allow_trailing_dot

允许尾随小数点.

RP::expect_dot

必须有小数点.

RP::parse_sign(f, l)

解析前缀符号 (例如 '-'). 成功则返回 true, 否则返回 false.

RP::parse_n(f, l, n)

解析小数点左侧的整数. 成功则返回 true, 否则返回 false. 成功时把结果放入 n.

RP::parse_dot(f, l)

解析小数点. 成功则返回 true, 否则返回 false.

RP::parse_frac_n(f, l, n, d)

解析小数点后的小数部分. 成功则返回 true, 否则返回 false. 成功时把结果放入 n, 并把位数放入 d

RP::parse_exp(f, l)

解析指数前缀 (例如 'e'). 成功则返回 true, 否则返回 false.

RP::parse_exp_n(f, l, n)

解析实际的指数. 成功则返回 true, 否则返回 false. 成功时把结果放入 n.

RP::parse_nan(f, l, n)

解析 NaN. 成功则返回 true, 否则返回 false. 成功时把结果放入 n.

RP::parse_inf(f, l, n)

解析 Inf. 成功则返回 true, 否则返回 false. 成功时把结果放入 n.

每当待解析的数字不以数字开头 (在成功解析可选符号之后) 时, 就会调用 parse_nan 和 parse_inf 函数.

如果找到了 NaN 或 Inf, 这些函数应返回 true. 此时属性 n 应被设置为匹配到的值 (NaN 或 Inf). 可选符号之后会自动应用.

RealPolicies 的特化

实现正确的实数解析策略的最简单方法, 是从类型 real_policies 派生一个新类型, 同时重写解析中需要改变的部分. 例如, 下面是预定义的 strict_real_policies 的实现:

template <typename T>
struct strict_real_policies : real_policies<T>
{
    static bool const expect_dot = true;
};

一个自定义实数策略:

///////////////////////////////////////////////////////////////////////////////
//  These policies can be used to parse thousand separated
//  numbers with at most 2 decimal digits after the decimal
//  point. e.g. 123,456,789.01
///////////////////////////////////////////////////////////////////////////////
template <typename T>
struct ts_real_policies : boost::spirit::qi::ureal_policies<T>
{
    //  2 decimal places Max
    template <typename Iterator, typename Attribute>
    static bool
    parse_frac_n(Iterator& first, Iterator const& last, Attribute& attr,
                 int& frac_digits)
    {
        Iterator savef = first;
        bool r = boost::spirit::qi::
            extract_uint<T, 10, 1, 2, true>::call(first, last, attr);
        if (r) {
            // Optimization note: don't compute frac_digits if T is
            // an unused_type. This should be optimized away by the compiler.
            if (!boost::is_same<T, boost::spirit::unused_type>::value)
                frac_digits = static_cast<int>(std::distance(savef, first));
        }
        return r;
    }

    //  No exponent
    template <typename Iterator>
    static bool
    parse_exp(Iterator&, Iterator const&)
    {
        return false;
    }

    //  No exponent
    template <typename Iterator, typename Attribute>
    static bool
    parse_exp_n(Iterator&, Iterator const&, Attribute&)
    {
        return false;
    }

    //  Thousands separated numbers
    template <typename Iterator, typename Accumulator>
    static bool
    parse_n(Iterator& first, Iterator const& last, Accumulator& result)
    {
        using boost::spirit::qi::uint_parser;
        namespace qi = boost::spirit::qi;

        uint_parser<unsigned, 10, 1, 3> uint3;
        uint_parser<unsigned, 10, 3, 3> uint3_3;

        if (parse(first, last, uint3, result))
        {
            Accumulator n;
            Iterator iter = first;

            while (qi::parse(iter, last, ',') && qi::parse(iter, last, uint3_3, n))
            {
                result = result * 1000 + n;
                first = iter;
            }

            return true;
        }
        return false;
    }
};

及其用法:

real_parser<double, ts_real_policies<double> > ts_real;
test_parser("123,456,789.01", ts_real);
test_parser("123,456,789.01", ts_real(123456789.01));
