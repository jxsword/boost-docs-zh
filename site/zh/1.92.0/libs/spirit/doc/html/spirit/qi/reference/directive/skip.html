重新启用跳过的解析器指令 (skip[])
说明

skip 指令是 lexeme 或 no_skip 的逆操作. lexeme 指令关闭空白字符跳过, 而 skip 指令把它重新打开. 只需把相关部分包进 skip 指令即可:

skip[a]

也可以向 skip 指令提供一个跳过解析器:

skip(p)[a] // Use `p` as a skipper for parsing `a`

这使得以下做法成为可能:

  • 在进行字符层级解析的同时执行局部的短语层级解析.
  • 在进行短语层级解析的同时, 在任意位置把当前跳过器替换为完全不同的跳过器.
头文件 
// forwards to <boost/spirit/home/qi/directive/skip.hpp>
#include <boost/spirit/include/qi_skip.hpp>

另请参见 包含结构.

表达式语义

表达式

语义

skip[a]

重新启用被 lexeme 或 no_skip 抑制的跳过器

skip(p)[a]

使用 p 作为解析 a 的跳过器
属性

参见 复合属性记法.

表达式

属性

skip[a] 

a: A --> skip[a]: A
a: Unused --> skip[a]: Unused

skip(p)[a] 

a: A --> skip(p)[a]: A
a: Unused --> skip(p)[a]: Unused
复杂度

复杂度由主体解析器 a 的复杂度决定

using boost::spirit::qi::skip;

skip[] 的简单用法:

显式指定一个跳过解析器. 该解析器解析以逗号分隔的数字, 忽略空格.

test_parser("1, 2, 3, 4, 5", skip(space)[int_ >> *(',' >> int_)]);
