流解析器 (stream、wstream 等)
说明

stream_parser 是一个基础组件, 允许把现有的标准流运算符用于输入解析并与 Spirit.Qi 集成. 它提供一个包装解析器, 把底层输入流分派给待解析的相应属性类型的流运算符. 任何值 a 要使用 stream_parser 来解析, 都会引发调用其类型 A 的标准流运算符, 例如:

std::istream& operator>> (std::istream&, A&);
头文件 
// forwards to <boost/spirit/home/qi/stream.hpp>
#include <boost/spirit/include/qi_stream.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::stream // alias: boost::spirit::qi::stream

boost::spirit::wstream // alias: boost::spirit::qi::wstream

概要 
template <typename Char, typename Attrib>
struct stream_parser;

记法约定

s

具有已定义匹配流运算符 operator>>() 的任意类型的变量实例, 或求值为任意类型的 惰性实参, 该类型具有已定义的匹配流运算符 operator>>().

表达式语义

仅当表达式的语义与 PrimitiveParser 不同或在其中未定义时, 才给出其语义.

表达式

说明

stream

为必选属性的类型调用流运算符 operator>>(). 该运算符识别的输入将是 stream 解析器的结果. 此解析器从不失败 (除非底层输入流报告错误). I/O istream 的字符类型假定为 char.

wstream

为必选属性的类型调用流运算符 operator>>(). 该运算符识别的输入将是 wstream 解析器的结果. 此解析器从不失败 (除非底层输入流报告错误). I/O istream 的字符类型假定为 wchar_t.

上表列出的所有解析器都是下文所述 stream_parser<Char> 基本流解析器类型的预定义特化. 可以直接使用此类型, 以任意底层字符类型创建流解析器.

表达式

语义

 

stream_parser<
    Char, Attrib
>()

为可选属性的类型调用流运算符 operator>>(), 该属性为 Attrib. 该运算符识别的输入将是 stream_parser<> 解析器的结果. 此解析器从不失败 (除非底层输入流报告错误). I/O istream 的字符类型假定为 Char

附加要求

上面列出的所有流解析器都要求待解析值的类型 (关联属性) 实现一个符合常规 I/O 流约定的流运算符 (其中 attribute_type 是解析时要识别的值的类型):

template <typename Istream>
Istream& operator>> (Istream& os, attribute_type& attr)
{
    // type specific input parsing
    return os;
}

流解析器会调用此运算符来收集 attribute_type 类型属性的输入.

注释

如果 stream 解析器在 match (或 phrase_match) 流操纵器内部被调用, Istream 会被传给 operator>>(), 并将已注册 (浸染) 与 match (或 phrase_match) 操纵器所使用的流相同的标准 locale 实例. 这确保在输入解析期间使用原始 I/O 流对象注册 (浸染) 的所有 facet.

属性

表达式

属性

stream

spirit::whold_any

stream_parser<Char, Attrib>()

重要

某些流解析器暴露的属性类型 spirit::hold_any 在语义和语法上都等价于 Boost.Any 实现的类型. 把它加入 Spirit 是因为它比 Boost.Any 性能更好且占用空间更小.

复杂度

O(N), 其中 N 是流解析器消耗的字符数

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

示例中使用的类定义:

// a simple complex number representation z = a + bi
struct complex
{
    complex (double a = 0.0, double b = 0.0)
      : a(a), b(b)
    {}

    double a;
    double b;
};


// define streaming operator for the type complex
std::istream&
operator>> (std::istream& is, complex& z)
{
    char lbrace = '\0', comma = '\0', rbrace = '\0';
    is >> lbrace >> z.a >> comma >> z.b >> rbrace;
    if (lbrace != '{' || comma != ',' || rbrace != '}')
        is.setstate(std::ios_base::failbit);
    return is;
}

using 声明和变量:

using boost::spirit::qi::stream;
using boost::spirit::qi::stream_parser;

使用 operator>>(istream&, std::string&) 解析一个简单字符串;

std::string str;
test_parser_attr("abc", stream, str);
std::cout << str << std::endl;                  // prints: abc

使用 operator>>(istream&, complex&) 解析我们的复杂类型;

complex c;
test_parser_attr("{1.0,2.5}", stream_parser<char, complex>(), c);
std::cout << c.a << "," << c.b << std::endl;    // prints: 1.0,2.5
