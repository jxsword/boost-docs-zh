有符号整数生成器(int_ 等)
说明

int_generator 可以生成任意长度和大小的有符号整数. 这与 uint_generator 几乎相同. 唯一的区别是额外要在数前面生成 '+' 或 '-' 符号. 类接口与 uint_generator 的相同.

int_generator 生成器可用于输出普通原始 C/C++ 整数, 甚至用户定义的标量, 例如 bigint (无限精度整数), 只要该类型遵循特定的表达式要求 (有关这些要求的更多信息, 参见 下文).

头文件 
// forwards to <boost/spirit/home/karma/numeric/int.hpp>
#include <boost/spirit/include/karma_int.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::lit // alias: boost::spirit::karma::lit

boost::spirit::short_ // alias: boost::spirit::karma::short_

boost::spirit::int_ // alias: boost::spirit::karma::int_

boost::spirit::long_ // alias: boost::spirit::karma::long_

boost::spirit::long_long // alias: boost::spirit::karma::long_long

注释

生成器 long_long 和 long_long(num) 仅在定义了预处理器常量 BOOST_HAS_LONG_LONG 的平台上可用 (即对 long long (64 位)整数类型有本机支持的平台).

注释

lit 被 字符串生成器, 字符生成器 和数值生成器复用. 一般来说, 传入字符时创建字符生成器, 传入字符串时创建字符串生成器, 使用数值字面量时创建数值生成器.

概要 
template <
    typename T
  , unsigned Radix
  , bool force_sign>
struct int_generator;

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

lit(num)

使用默认格式化生成整数字面量 num (基数为 10, 符号仅对负字面量输出). 该生成器从不失败 (除非底层输出流报告错误).

 

short_
int_
long_
long_long

使用默认格式化生成由必需属性提供的整数 (基数为 10, 符号仅对负字面量输出). 该生成器从不失败 (除非底层输出流报告错误).

 

short_(num)
int_(num)
long_(num)
long_long(num)

使用默认格式化生成由生成器初始化时使用的直接字面量值提供的整数 (基数为 10, 符号仅对负字面量输出). 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.

上表列出的所有生成器(lit(num) 除外)都是下面描述的 int_generator<Num, Radix, force_sign> 基本整数生成器类型的预定义特化. 可以直接使用该类型, 通过各种格式化选项创建整数生成器.

表达式

语义

 

int_generator<
    Num, Radix, force_sign
>()

生成由必需属性提供的类型为 Num 的整数, 使用指定的 Radix (可能值为 2, 8, 10 和 16, 默认值为 10). 如果 force_sign 为 false (默认), 符号仅对负字面量输出. 如果 force_sign 为 true, 所有数都将带符号输出, 即负数为 '-', 正数为 '+', 零为 ' '. 该生成器从不失败 (除非底层输出流报告错误).

 

int_generator<
    Num, Radix, force_sign
>()(num)

生成由生成器初始化时使用的直接字面量值提供的类型为 Num 的整数, 使用指定的 Radix (可能值为 2, 8, 10 和 16, 默认值为 10). 如果 force_sign 为 false (默认), 符号仅对负字面量输出. 如果 force_sign 为 true, 所有数都将带符号输出, 即负数为 '-', 正数为 '+', 零为 ' '. 如果该生成器有关联属性, 则只有当属性等于该直接字面量时才成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何输出.
附加要求

以下列表枚举了使用某个类型 Num 来实例化和使用 int_generator<Num, Radix, force_sign> 所必须满足的要求.

如果 boost::is_integral<Num>::value 为 true, 类型 Num 必须定义:

  • 以下比较运算符: <, <=, ==, !=, > 和 >=
  • 以下数值运算符: +, -, /, *, % 和一元 -

如果 boost::is_integral<Num>::value 为 false, 类型 Num 必须定义:

  • 以下比较运算符: <, <=, ==, !=, > 和 >=
  • 以下数值运算符: +, -, /, *, % 和一元 -
  • 实现以下接口和语义的辅助函数: std::fmod, std::fabs, std::pow, std::lround, std::ltrunc, std::floor 和 std::ceil. 这些函数的定义方式必须使它们能通过实参依赖查找 (ADL) 找到.

注释

除了它们通常的 Num 类型属性之外, 所有列出的生成器还接受 boost::optional<Num> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 Num 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

复杂度

O(N), 其中 N 是表示生成的整数所需的位数

int_ 生成器的基本用法:

test_generator("-2", lit(-2));
test_generator("-2", int_(-2));
test_generator_attr("-2", int_(-2), -2);
