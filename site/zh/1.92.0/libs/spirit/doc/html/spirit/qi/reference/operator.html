解析器运算符

备选解析器 (a | b)
与谓词解析器 (&a)
差解析器 (a - b)
期望运算符 (a > b)
Kleene 解析器 (*a)
列表解析器 (a % b)
非谓词解析器 (!a)
可选解析器 (-a)
排列解析器 (a ^ b)
加解析器 (+a)
序列解析器 (a >> b)
顺序或解析器 (a || b)

运算符被用作对象组合和嵌入的手段. 简单的解析器可以通过运算符重载组合成复合解析器, 这些重载经过精心设计, 以近似 解析表达式文法 (PEG) 的语法. 形如以下的表达式:

a | b

会产生一个新的解析器类型, 它是其操作数 a 和 b 的复合体.

本模块包含各种解析器, 当某个重载运算符与更基础的解析器构造一起使用时, 这些解析器会被实例化. 它包括备选 (|)、与谓词 (一元 &)、差 (-)、期望 (>)、Kleene 星号 (一元 *)、列表 (%)、非谓词 (!)、可选 (一元 -)、排列 (^)、加 (一元 +)、序列 (>>) 和顺序或 (||).

模块头文件 
// forwards to <boost/spirit/home/qi/operator.hpp>
#include <boost/spirit/include/qi_operator.hpp>
