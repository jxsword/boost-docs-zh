重复解析器指令 (repeat[])
说明

repeat[] 提供了更强大、更灵活的解析器重复机制. 有些文法用基本 EBNF 迭代语法 (Kleene 和 加) 来指定即便可行也非常笨拙繁琐. 示例:

  • 文件名最多只能有 255 个字符.
  • 特定位图文件格式恰好有 4096 个 RGB 颜色信息.
  • 一个 256 位二进制字符串 (1..256 个 1 或 0).
头文件 
// forwards to <boost/spirit/home/qi/directive/repeat.hpp>
#include <boost/spirit/include/qi_repeat.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::repeat // alias: boost::spirit::qi::repeat

boost::spirit::inf // alias: boost::spirit::qi::inf

所属模型

UnaryParser

记法约定

a

一个 Parser.

n, min, max

一个 int, 即任何可转换为 int 的东西; 或一个 惰性参数, 求值为任何可转换为 int 的东西.

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

repeat[a]

重复 a 零次或多次. 与 Kleene 相同.

repeat(n)[a]

把 a 恰好重复 n 次.

repeat(min, max)[a]

把 a 重复至少 min 次、至多 max 次.

repeat(min, inf)[a]

把 a 重复至少 min 次或更多 (持续到 a 失败或输入耗尽).
属性

参见 复合属性记法.

表达式

属性

repeat[a] 

a: A --> repeat[a]: vector<A>
a: Unused --> repeat[a]: Unused

repeat(n)[a] 

a: A --> repeat(n)[a]: vector<A>
a: Unused --> repeat(n)[a]: Unused

repeat(min, max)[a] 

a: A --> repeat(min, max)[a]: vector<A>
a: Unused --> repeat(min, max)[a]: Unused

repeat(min, inf)[a] 

a: A --> repeat(min, inf)[a]: vector<A>
a: Unused --> repeat(min, inf)[a]: Unused
复杂度

总体复杂度由其主体解析器的复杂度决定. repeat 本身的复杂度为 O(N), 其中 N 是要执行的重复次数.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

使用 repeat 指令, 我们现在可以写出上面的示例.

一些 using 声明:

using boost::spirit::qi::repeat;
using boost::spirit::qi::lit;
using boost::spirit::qi::uint_parser;
using boost::spirit::qi::_1;
using boost::spirit::ascii::char_;
namespace phx = boost::phoenix;

一个解析最多 255 个字符的文件名的解析器:

test_parser("batman.jpeg", repeat(1, 255)[char_("a-zA-Z_./")]);

一个解析特定位图文件格式的解析器, 该格式恰好有 4096 条 RGB 颜色信息. (就本示例而言, 我们只测试 3 条 RGB 颜色信息. )

uint_parser<unsigned, 16, 6, 6> rgb;
std::vector<unsigned> colors;
test_parser_attr("ffffff0000003f3f3f", repeat(3)[rgb], colors);
std::cout
    << std::hex
    << colors[0] << ','
    << colors[1] << ','
    << colors[2] << std::endl;

一个 256 位的二进制字符串 (1 到 256 个 1 或 0). (就本示例而言, 我们只测试 16 位. )

test_parser("1011101011110010", repeat(16)[lit('1') | '0']);

这个简单示例无法在传统 EBNF 中实际定义. 尽管某些 EBNF 变体允许比 Kleene 星号更强大的重复构造, 我们仍然只能解析固定长度的字符串. EBNF 的本性迫使重复因子为常量. 而 Spirit 允许重复因子在运行期是可变的. 我们可以编写一个接受上述输入字符串的文法. 使用 phoenix 的示例:

std::string str;
int n;
test_parser_attr("\x0bHello World",
    char_[phx::ref(n) = _1] >> repeat(phx::ref(n))[char_], str);
std::cout << n << ',' << str << std::endl;  // will print "11,Hello World"
