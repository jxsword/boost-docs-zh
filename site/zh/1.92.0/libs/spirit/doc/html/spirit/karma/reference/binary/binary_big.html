二进制大端字节序生成器
说明

本节描述的大端字节序生成器用于输出按大端字节序布局的二进制字节流.

头文件 
// forwards to <boost/spirit/home/karma/binary.hpp>
#include <boost/spirit/include/karma_binary.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::big_word // alias: boost::spirit::karma::big_word

boost::spirit::big_dword // alias: boost::spirit::karma::big_dword

boost::spirit::big_qword // alias: boost::spirit::karma::big_qword

boost::spirit::big_bin_float // alias: boost::spirit::karma::big_bin_float

boost::spirit::big_bin_double // alias: boost::spirit::karma::big_bin_double

注释

生成器 big_qword 和 big_qword(qw) 仅在定义了预处理器常量 BOOST_HAS_LONG_LONG 的平台上可用 (即对 unsigned long long (64 位)整数类型有本机支持的平台).

所属模型

PrimitiveGenerator

记法约定

w

一个 16 位二进制值, 或求值为 16 位二进制值的 惰性实参. 该值始终按本机字节序解释.

dw

一个 32 位二进制值, 或求值为 32 位二进制值的 惰性实参. 该值始终按本机字节序解释.

qw

一个 64 位二进制值, 或求值为 64 位二进制值的 惰性实参. 该值始终按本机字节序解释.

f

一个 float 二进制值, 或求值为 float 二进制值的 惰性实参. 该值始终按本机字节序解释.

d

一个 double 二进制值, 或求值为 double 二进制值的 惰性实参. 该值始终按本机字节序解释.

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

说明

big_word

以大端表示输出必需属性的最低有效 16 位的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_dword

以大端表示输出必需属性的最低有效 32 位的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_qword

以大端表示输出必需属性的最低有效 64 位的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_bin_float

以大端表示输出必需的 float 属性的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_bin_double

以大端表示输出必需的 double 属性的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_word(w)

以大端表示输出直接参数的最低有效 16 位的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_dword(dw)

以大端表示输出直接参数的最低有效 32 位的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_qword(qw)

以大端表示输出直接参数的最低有效 64 位的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_bin_float(f)

以大端表示输出直接 float 参数的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).

big_bin_double(d)

以大端表示输出直接 double 参数的二进制表示. 该生成器从不失败 (除非底层输出流报告错误).
属性

表达式

属性

big_word

boost::uint_least16_t, 属性是必需的 (否则编译将失败)

big_dword

boost::uint_least32_t, 属性是必需的 (否则编译将失败)

big_qword

boost::uint_least64_t, 属性是必需的 (否则编译将失败)

big_bin_float

float, 属性是必需的 (否则编译将失败)

big_bin_double

double, 属性是必需的 (否则编译将失败)

big_word(w)

unused

big_dword(dw)

unused

big_qword(qw)

unused

big_bin_float(f)

unused

big_bin_double(d)

unused

复杂度

O(N), 其中 N 是二进制生成器输出的字节数

大端二进制生成器的基本用法:

test_binary_generator("\x02\x01", 2, big_word(0x0201));
test_binary_generator("\x04\x03\x02\x01", 4, big_dword(0x04030201));
test_binary_generator("\x08\x07\x06\x05\x04\x03\x02\x01", 8, big_qword(0x0807060504030201LL));

test_binary_generator_attr("\x02\x01", 2, big_word, 0x0201);
test_binary_generator_attr("\x04\x03\x02\x01", 4, big_dword, 0x04030201);
test_binary_generator_attr("\x08\x07\x06\x05\x04\x03\x02\x01", 8, big_qword, 0x0807060504030201LL);
