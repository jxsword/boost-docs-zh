Spirit V2.5.8

从 V2.5.7 (Boost V1.69.0) 到 V2.5.8 (Boost V1.70.0) 的变化
  • 移除了对已弃用的 boost/detail/iterator.hpp 头文件的使用 GH#432
  • 修复了与 Boost.Endian 的宏名冲突和命名空间冲突. GH#349 GH#482
Qi 中的缺陷修复
  • 为 rule 跳过器类型问题添加了静态断言. GH#427
  • check_overflow 特征的默认实现现在依赖 std::numeric_limits<T>::is_bounded 而不是 boost::integer_traits<T>::is_integral GH#429
  • 整数解析器现在应能处理用户定义类型. GH#429
  • 注意: check_overflow 特征的默认实现现在依赖 std::numeric_limits<T>::is_bounded 而不是 boost::integer_traits<T>::is_integral.
  • 移除了损坏的 1.0#INF 解析器. 它文档匮乏且从未正常工作. GH#415 GH#458 TRAC#8699
  • 未写入文档的 make_attribute 特征被并入 transform_attribute 特征. GH#471
  • 工具函数 pre_transform、post_transform 和 fail_transform 已被移除, 改为直接使用 transform 特征的 pre/post/fail. GH#467
  • 整数值解析器现在遵循 std::numeric_limits<T>::digits10 值. GH#469
  • 修复了 (Min % Base) == 0 边界情况的下溢检查. GH#469
  • 修复了 IgnoreOverflowDigits=true 整数解析器溢出时的输出值. GH#470
  • 移除了 transform_attribute 中对引用的特殊处理. GH#480
Lex 中的缺陷修复
  • 修复了带用户指定记号类型的词法分析器默认构造函数中的未定义行为. GH#420
utree 中的缺陷修复
  • 修复了因负值左移导致 tag getter 中的未定义行为. GH#423
  • 修复了双重转换 (spirit::string -> std::string -> spirit::string). GH#462
