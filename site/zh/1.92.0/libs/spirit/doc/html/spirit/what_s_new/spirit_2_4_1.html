Spirit V2.4.1

从 V2.4 (Boost V1.44.0) 到 V2.4.1 (Boost V1.45.0) 的变化: Spirit.Qi 和 Spirit.Karma
缺陷修复
  • 修复了针对可选属性损坏的 Spirit.Qi 调试设施.
  • Spirit.Qi 自动解析器和 Spirit.Karma 自动生成器现在也能与 signed char 和 unsigned char 正确配合工作.
  • 修复了 multi_pass fixed_queue 策略中的一个缺陷.
  • 为 skip 指令启用了正确的修饰符处理.
  • 修复了 Karma 中的一个浮点数格式化问题 (TRAC#4742).
  • 修复了 repeat[] 中的一个缺陷, 该缺陷导致 first 迭代器在某些解析失败时不被重置 (参见 Stack Overflow).
