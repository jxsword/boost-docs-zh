在解析前重新初始化属性值(Qi)

clear_value

模板 clear_value 是用作属性定制点的类型. Qi 的重复解析器(Kleene, Plus, List 和 Repeat)会调用它, 以便在属性实例存入所提供的容器之后重新初始化传递给内嵌解析器的属性实例. 这个重新初始化的属性实例会在重复解析器的下一次迭代中被复用.

模块头文件 
#include <boost/spirit/home/support/attributes.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename Attrib, typename Enable>
struct clear_value
{
    static void call(Attrib& val);
};
模板参数

参数

说明

默认值

Attrib

要重新初始化的属性的类型 Attrib.

none

Enable

辅助模板参数, 可利用 SFINAE 有选择地启用或禁用 clear_value 的某些特化(即 boost::enable_if 或 boost::disable_if).

void

记法约定

Attrib

用作存储属性值的容器的类型.

attr

Attrib 类型的属性实例.

T1, T2, ...

任意类型

表达式语义

表达式

语义

 

clear_value<Attrib>::call(Attrib& attr)

以最高效的方式重新初始化 attr 所引用的实例.
预定义特化

Spirit 为若干类型预定义了此定制点的特化. 下表列出了这些类型及其暴露的类型和相应的语义:

模板参数

语义

Attrib

通过赋以默认构造的值来重新初始化.

任何类型 T, 只要其 is_container<>::type 为 mpl::true_

对传入的属性实例调用成员函数 attr.clear().

boost::optional<Attrib>

清除 optional 实例并使其保持未初始化.

boost::variant<T1, T2, ...>

对当前持有的值调用 clear_value 定制点.

fusion::tuple<T1, T2, ...>

对元组的所有元素调用 clear_value 定制点.

unused_type

不执行任何操作.
何时实现

每当一个类型要用作存储到 STL 容器中的属性, 且无法使用上面列出的特化之一重新初始化时, 就需要为该类型实现定制点 clear_value. 例如, 不可默认构造的类型, 或不暴露成员函数 clear() 的容器类型.
