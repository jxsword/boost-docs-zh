Lexer

Spirit.Lex 组件可归入几个泛化的 概念. Lexer 是最基本的概念. 所有 Spirit.Lex 组件都是 Lexer 概念的模型. PrimitiveLexer、UnaryLexer 和 NaryLexer 都是 Lexer 概念的细化.
