判断一个类型是否为字符
is_char

is_char 是一个检测给定类型是否为字符的元函数.

模块头文件 
#include <boost/spirit/home/support/string_traits.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename T>
struct is_char
{
    <unspecified>;
};
模板参数

参数

说明

默认值

T

要检测的类型.

none

记法约定

T

任意类型

表达式语义

表达式

语义

is_char<T>::type

如果 T 应被视为字符类型, 则为 mpl::true_, 否则为 mpl::false_. 通常, is_char 的任何实现都需要表现得如同一个 MPL Boolean Constant.

何时实现

对于任何使用 char 或 `wchar_t 以外的类型存储字符数据的字符串, 都需要实现此定制点.

相关的属性定制点
