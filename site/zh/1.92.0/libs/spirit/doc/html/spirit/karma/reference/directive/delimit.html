控制自动分隔的生成器指令(verbatim[], no_delimit[], delimit[])
说明

指令 delimit[], no_delimit[] 和 verbatim[] 可用于控制自动分隔. 指令 verbatim[] 和 no_delimit[] 禁用任何自动分隔, 而指令 delimit[] (重新)启用自动分隔.

头文件

对于 verbatim[] 指令:

// forwards to <boost/spirit/home/karma/directive/verbatim.hpp>
#include <boost/spirit/include/karma_verbatim.hpp>

对于 no_delimit[] 指令:

// forwards to <boost/spirit/home/karma/directive/no_delimit.hpp>
#include <boost/spirit/include/karma_no_delimit.hpp>

对于 delimit[] 指令:

// forwards to <boost/spirit/home/karma/directive/delimit.hpp>
#include <boost/spirit/include/karma_delimit.hpp>

另请参见 包含结构.

命名空间

名称

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

delimit[a]

为内嵌生成器 a 启用自动分隔, 同时使用 space 生成器作为分隔生成器. 如果在 verbatim[] 指令内部使用, 它会重新启用在该 verbatim[] 之外使用的分隔符生成器. 只要内嵌生成器成功, 该指令就成功 (除非底层输出流报告错误).

delimit(d)[a]

为内嵌生成器 a 启用自动分隔, 同时使用生成器 d 作为分隔生成器. 只要内嵌生成器成功, 该指令就成功 (除非底层输出流报告错误).

verbatim[a]

为内嵌生成器 a 禁用自动分隔. 只要内嵌生成器成功, 该指令就成功 (除非底层输出流报告错误). 如果在没有激活分隔时使用, 该指令没有效果. 当分隔激活时, 该指令执行一个后置分隔步骤 (这与 no_delimit[] 的行为不同).

no_delimit[a]

为内嵌生成器 a 禁用自动分隔. 只要内嵌生成器成功, 该指令就成功 (除非底层输出流报告错误). 如果在没有激活分隔时使用, 该指令没有效果. 当分隔激活时, 该指令不执行后置分隔步骤 (这与 verbatim[] 的行为不同).
属性

参见 复合属性记法.

表达式

属性

delimit[a] 

a: A --> delimit[a]: A
a: Unused --> delimit[a]: Unused

delimit(d)[a] 

a: A, d: D --> delimit(d)[a]: A
a: Unused, d: D --> delimit(d)[a]: Unused

verbatim[a] 

a: A --> verbatim[a]: A
a: Unused --> verbatim[a]: Unused

no_delimit[a] 

a: A --> no_delimit[a]: A
a: Unused --> no_delimit[a]: Unused
复杂度

生成器指令 delimit[], verbatim[] 和 no_delimit[] 的总体复杂度由其内嵌生成器的复杂度决定. 指令本身的复杂度是 O(1).

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些包含:

#include <boost/spirit/include/karma.hpp>
#include <iostream>
#include <string>

一些 using 声明:

using boost::spirit::karma::double_;
using boost::spirit::karma::delimit;
using boost::spirit::karma::verbatim;

delimit 生成器指令的基本用法:

test_generator_attr("[ 2.0 , 4.3 ] ",
    delimit['[' << double_ << ',' << double_ << ']'], 2.0, 4.3);
test_generator_attr("[*2.0*,*4.3*]*",
    delimit('*')['[' << double_ << ',' << double_ << ']'], 2.0, 4.3);
test_generator_attr("[2.0, 4.3 ] ",
    delimit[verbatim['[' << double_ << ','] << double_ << ']'], 2.0, 4.3);
