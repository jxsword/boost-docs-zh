重复生成器指令(repeat[])
说明

重复指令允许重复任意生成器表达式, 同时可选地指定重复次数的下限和上限. 它为重复生成器提供了更强大, 更灵活的机制. 有些文法用基本 EBNF 迭代语法 (一元 '*' 和 一元 '+') 来指定是不切实际且繁琐的, 甚至是不可能的. 示例:

  • 文件名最多只能有 255 个字符.
  • 特定位图文件格式恰好有 4096 个 RGB 颜色信息.
  • 一个 256 位二进制字符串 (1..256 个 1 或 0).
头文件 
// forwards to <boost/spirit/home/karma/directive/repeat.hpp>
#include <boost/spirit/include/karma_repeat.hpp>

另请参见 包含结构.

名称

boost::spirit::inf // alias: boost::spirit::karma::inf

所属模型

UnaryGenerator

记法约定

a

一个生成器对象

num, num1, num2

数值字面量, 任意无符号整数值, 或求值为无符号整数值的 惰性实参

inf

表示"无重复次数上限"的占位符表达式

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

repeat[a]

重复生成器 a 零次或多次. 只要其内嵌生成器 a 不失败, 该生成器就成功 (除非底层输出流报告错误). 这一 repeat[] 变体在语义上等价于 Kleene star 运算符 *a

repeat(num)[a]

恰好重复生成器 a num 次. 只要其内嵌生成器 a 不失败且关联属性 (容器) 至少包含 num 个元素, 该生成器就成功 (除非底层输出流报告错误).

repeat(num1, num2)[a]

重复生成器 a 至少 num1 次但不超过 num2 次. 只要其内嵌生成器 a 不失败且关联属性 (容器) 至少包含 num1 个元素, 该生成器就成功 (除非底层输出流报告错误). 如果关联属性 (容器) 确实包含多于 num2 个元素, 该指令把重复次数限制为 num2.

repeat(num, inf)[a]

重复生成器 a 至少 num1 次. 未设置重复次数上限. 只要其内嵌生成器 a 不失败且关联属性 (容器) 至少包含 num 个元素, 该生成器就成功 (除非底层输出流报告错误).
注释

内嵌生成器所有失败的迭代都会从所提供的属性中消耗一个元素. 只要迭代判据 (内嵌生成器成功调用的次数) 得到满足, 整个 repeat[a] 就会成功 (除非底层输出流报告错误).

属性

参见 复合属性记法.

表达式

属性

repeat[a] 

a: A --> repeat[a]: vector<A>
a: Unused --> repeat[a]: Unused

repeat(num)[a] 

a: A --> repeat(num)[a]: vector<A>
a: Unused --> repeat(num)[a]: Unused

repeat(num1, num2)[a] 

a: A --> repeat(num1, num2)[a]: vector<A>
a: Unused --> repeat(num1, num2)[a]: Unused

repeat(num, inf)[a] 

a: A --> repeat(num, inf)[a]: vector<A>
a: Unused --> repeat(num, inf)[a]: Unused
重要

上表仅把 vector<A> 用作占位符.

记法 vector<A> 表示 任意 STL 容器, 其中保存类型为 A 的元素.

需要注意的重要一点是, repeat[] 指令不会对其内嵌元素生成的输出执行任何缓冲. 这意味着任何失败的元素生成器可能已经生成了一些输出, 这些输出 不会 被回滚.

提示

强制 repeat[] 指令表现得像有缓冲一样的最简单方法是把它包装进一个缓冲指令中 (参见 buffer):

buffer[repeat[a]]

它将 不 生成任何输出, 如果生成器 repeat[a] 失败. 表达式:

repeat[buffer[a]]

如果生成器 a 在输出中途失败, 则不会生成任何部分输出. 整个表达式仍会生成由生成器 a 所有成功调用产生的输出.

复杂度

重复生成器的总体复杂度由其内嵌生成器的复杂度决定. repeat 本身的复杂度是 O(N), 其中 N 是要执行的重复次数.

一些 using 声明:

using boost::spirit::karma::double_;

repeat 生成器指令的基本用法:

std::vector<double> v;
v.push_back(1.0);
v.push_back(2.0);
v.push_back(3.0);

test_generator_attr("[1.0][2.0][3.0]", repeat['[' << double_ << ']'], v);
test_generator_attr("[1.0][2.0]", repeat(2)['[' << double_ << ']'], v);

// fails because of insufficient number of items
test_generator_attr("", repeat(4)['[' << double_ << ']'], v);
