Parser
说明

Parser 是最基本的概念. Parser 有一个成员函数 parse, 接受一对 first-last ForwardIterator 并返回 bool 作为其结果. 迭代器界定被解析的数据. 如果解析成功, Parser 的 parse 成员函数返回 true, 此时第一个迭代器相应地前移. 每个 Parser 可以代表一个特定的模式或算法, 也可以是由其他 Parser 组合而成的更复杂的解析器.

记法约定

p

一个Parser.

P

一个 Parser 类型.

Iter

一个 ForwardIterator 类型.

f, l

ForwardIterator. first/last 迭代器对.

Context

解析器的 Context 类型.

context

解析器的 Context, 或 unused.

skip

一个跳过解析器 (skip Parser), 或 unused.

attrib

一个兼容属性 (Compatible Attribute), 或 unused.

有效表达式

在下文表达式中, 解析器 p 的行为, 以及 skip 和 attrib 如何被 p 处理, 在基础概念 Parser 中未作规定. 这些行为在后续更细化的概念及其具体模型中加以规定.

对任意 Parser, 以下表达式必须有效:

表达式

语义

返回类型

 

p.parse(f, l, context, skip, attr)

匹配从 f 开始的输入序列. 成功则返回 true, 否则返回 false.

bool

p.what(context)

获取关于 Parser 的信息.

info

类型表达式

表达式

说明

P::template attribute<Context, Iter>::type

Parser 期望的属性.

traits::is_parser<P>::type

元函数: 求值为 mpl::true_, 条件是某类型 P 为 Parser; 否则求值为 mpl::false_ (参见 MPL Boolean Constant).
后置条件

从 p.parse 返回后, 应满足以下后置条件:

  • 成功匹配时, f 定位于最后一个匹配字符/记号之后.
  • 匹配失败时, 如果 skip 解析器是 unused 的, 则 f 被恢复到进入前的原始位置.
  • 匹配失败时, 如果 skip 解析器不是 unused 的, 则 f 定位于匹配 skip 的最后一个字符/记号之后.
  • 匹配失败时, attrib 的状态是未定义的.
  • 无后置跳过: 尾随的 skip 字符/记号将不会被跳过.
模型

Spirit.Qi 中的所有解析器都是 Parser 概念的模型.
