与谓词生成器(&a)
说明

与谓词生成器用于测试内嵌生成器是否成功, 而不生成任何输出. 如果内嵌生成器成功, 它就成功.

头文件 
// forwards to <boost/spirit/home/karma/operator/and_predicate.hpp>
#include <boost/spirit/include/karma_and_predicate.hpp>

另请参见 包含结构.

表达式

语义

&a

执行生成器 a 的唯一目的是测试它是否成功. 如果其内嵌生成器成功, 与谓词生成器就成功 (除非底层输出流报告错误). 与谓词从不产生任何输出.

and 生成器的实现方式是把它内嵌生成器产生的所有输出重定向到一个丢弃设备.

属性

参见 复合属性记法.

表达式

属性

&a (与谓词, 一元 &)

a: A --> &a: A

注释

与谓词的属性并不总是 unused_type, 这与 Qi 的与谓词不同. 这是必需的, 因为与谓词所附着的生成器大多数时候需要一个属性.

复杂度

与谓词生成器的总体复杂度由其内嵌生成器的复杂度决定. 与谓词生成器本身的复杂度是 O(1).

using boost::spirit::karma::double_;

与谓词生成器的基本用法:

test_generator_attr("b", &char_('a') << 'b' | 'c', 'a');
test_generator_attr("c", &char_('a') << 'b' | 'c', 'x');

test_generator_attr("abc", &string("123") << "abc" | "def", "123");
test_generator_attr("def", &string("123") << "abc" | "def", "456");
