语法图

在下一节中, 我们将讨论解析表达式文法(PEG)[3], 它是扩展巴科斯-诺尔范式(EBNF)[4] 的一种变体, 但解释不同. 使用语法图更容易理解 PEG. 语法图以图形方式表示文法. Niklaus Wirth [5] 在"Pascal User Manual"中大量使用了它. 语法图与流程图相似, 程序员很容易理解. 图与函数之间的同构关系使它们成为表示递归下降解析器的理想选择, 而递归下降解析器本质上是相互递归的函数.

从历史上看, 解析表达式文法一直只用于描述解析器的文法(这也是其名称的由来). 在 Spirit 中, 我们也为输出生成使用了非常类似的记法. 这里描述的几乎所有概念同样适用于 Spirit.Qi 解析器和 Spirit.Karma 生成器.

元素

所有图都有一个入口点和一个出口点. 箭头连接从入口点经过文法到出口点的所有可能路径.

终结符用圆角框表示. 终结符是原子的, 通常表示普通字符, 字符串或记号.

非终结符用方框表示. 图通过命名的非终结符实现模块化. 一个复杂的图可以分解为一组非终结符. 非终结符还允许递归(即非终结符可以调用自身).

谓词

下面是 PEG 谓词的语法图版本. 这些在传统语法图中是没有的. 这是我们为紧密贴合 PEG 而发明的特殊扩展.

首先, 我们引入一个新元素: 谓词:

这类似于流程图中的条件分支, 只是没有 'No' 分支, 并且总是表示解析失败.

谓词有两个版本: 与谓词 和 非谓词:

与谓词 尝试谓词 P, 如果 P 成功则成功, 否则失败. 非谓词 正好相反: 它尝试谓词 P, 如果 P 成功则失败, 否则成功. 两种版本都进行前瞻, 但无论 P 成功与否都不消耗任何输入.
