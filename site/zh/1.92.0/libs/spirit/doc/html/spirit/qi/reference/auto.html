自动解析器

说明

本模块包含 auto_ 解析器的描述. 该解析器可用于基于给定的属性类型自动创建解析器.

头文件 
// forwards to <boost/spirit/home/qi/auto.hpp>
#include <boost/spirit/include/qi_auto.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::auto_ // alias: boost::spirit::qi::auto_

所属模型

PrimitiveParser

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

说明

auto_

创建与给定属性类型兼容的解析器实例, 并将其用于输入匹配.
附加要求

auto_ 解析器可用于为任何定义了到解析器类型映射的数据类型匹配输入 (元函数 traits::create_parser_exists 返回 mpl::true_). 下表概述了从属性类型到解析器类型的预定义映射规则. 这些规则被递归应用, 以创建可用于为给定属性类型匹配输入的解析器类型.

standard::char_, standard_wide::char_

short, int, long

short_, int_, long_

ushort_, uint_, ulong_

Optional 运算符 (一元 '-')

Alternative 运算符 ('|')

可以通过实现定制点 traits::create_parser 的特化来添加对任何自定义数据类型的支持. 该定制也可用于重定义任何预定义映射.

属性

表达式

属性

auto_

hold_any

重要

属性类型 hold_any (由 auto_ 解析器暴露) 在语义和语法上都等价于 Boost.Any 实现的类型. 把它加入 Spirit 是因为与 Boost.Any 相比, 它性能更好且占用空间更小.

复杂度

auto_ 解析器的复杂度取决于给定的属性类型. 每种属性类型都会导致实例化不同的解析器类型, 这决定了总体复杂度.

下面示例的测试框架在 基础示例 一节中给出.

一些包含:

#include <boost/spirit/include/support_utree.hpp>
#include <boost/spirit/include/qi.hpp>
#include <boost/phoenix/core.hpp>
#include <boost/phoenix/operator.hpp>
#include <boost/fusion/include/adapt_struct.hpp>
#include <boost/assert.hpp>
#include <boost/predef/other/endian.h>
#include <boost/proto/deep_copy.hpp>
#include <iostream>
#include <string>
#include <cstdlib>

一些 using 声明:

using boost::spirit::qi::auto_;

以及示例中使用的类定义:

// a simple complex number representation z = a + bi
struct complex
{
    complex (double a = 0.0, double b = 0.0)
      : a(a), b(b)
    {}

    double a;
    double b;
};

要允许把 complex 数据结构用作 Boost.Fusion 序列, 需要以下构造. 这是必需的, 因为我们将用 Spirit.Qi 序列为此数据结构生成输出: '{' >> qi::double_ >> ',' >> qi::double_ >> '}'.

BOOST_FUSION_ADAPT_STRUCT(
    complex,
    (double, a)
    (double, b)
)

我们为 create_parser 定制点添加一个特化, 为该复杂类型定义自定义的输出格式. 一般来说, create_parser 的任何特化都应返回 proto 表达式, 用于为该定制点所特化的类型匹配输入.

我们需要使用 proto::deep_copy, 因为表达式包含字面量('{', ',' 和 '}'), 它们通常仅以引用方式嵌入 proto 表达式. 深拷贝会把 proto 树转换为按值持有这些内容. 对于更简单的 proto 表达式(不包含对临时对象的引用), 可以省略深拷贝操作. 或者, 你也可以使用 proto::make_expr 设施来构建所需的 proto 表达式.

namespace boost { namespace spirit { namespace traits
{
    template <>
    struct create_parser<complex>
    {
        typedef proto::result_of::deep_copy<
            BOOST_TYPEOF('{' >> qi::double_ >> ',' >> qi::double_ >> '}')
        >::type type;

        static type call()
        {
            return proto::deep_copy(
                '{' >> qi::double_ >> ',' >> qi::double_ >> '}');
        }
    };
}}}

auto_ 解析器的一些用法示例:

使用生成的解析器组件 int_ 解析一个简单整数:

int i = 0;
test_parser_attr("123", auto_, i);
std::cout << i << std::endl;                    // prints: 123

使用由所定义定制点生成的解析器, 解析上文定义的 complex 数据类型的一个实例:

complex c;
test_parser_attr("{1.2,2.4}", auto_, c);
std::cout << c.a << "," << c.b << std::endl;    // prints: 1.2,2.4
