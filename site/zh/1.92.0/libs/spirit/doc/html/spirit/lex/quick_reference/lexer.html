支持的正则表达式

表 11. 正则表达式支持

表达式

含义

x

匹配任意字符 x

.

匹配除换行符以外的任意字符 (或者可选地匹配 任意 字符)

"..."

双引号之间的所有字符均按字面量处理, 转义序列除外

[xyz]

一个字符类; 此处匹配 x、y 或 z

[abj-oZ]

含有一个范围的字符类; 匹配 a, b (从 j 到 o 的任意字母) 或一个 Z

[^A-Z]

否定字符类, 即类中字符以外的任意字符. 此处为除大写字母以外的任意字符

r*

零个或多个 r (贪婪), 其中 r 为任意正则表达式

r*?

零个或多个 r (非贪婪), 其中 r 为任意正则表达式

r+

一个或多个 r (贪婪)

r+?

一个或多个 r (非贪婪)

r?

零个或一个 r (贪婪), 即可选

r??

零个或一个 r (非贪婪), 即可选

r{2,5}

二到五个 r (贪婪)

r{2,5}?

二到五个 r (非贪婪)

r{2,}

两个或更多 r (贪婪)

r{2,}?

两个或更多 r (非贪婪)

r{4}

恰好四个 r

{NAME}

宏 NAME (见下文)

"[xyz]\"foo"

字面字符串 [xyz]\"foo

\X

如果 X 是 a、b、e、n、r、f、t 或 v, 则按 ANSI-C 解释 \x; 否则是一个字面量 X (用于转义 * 之类的运算符)

\0

NUL 字符 (ASCII 码 0)

\123

八进制值为 123 的字符

\x2a

十六进制值为 2a 的字符

\cX

命名控制字符 X.

\a

Alert (响铃) 的简写.

\b

Backspace (退格) 的简写

\e

ESC (转义字符 0x1b) 的简写

\n

newline (换行) 的简写

\r

carriage return (回车) 的简写

\f

form feed (换页) 0x0c 的简写

\t

horizontal tab (水平制表符) 0x09 的简写

\v

vertical tab (垂直制表符) 0x0b 的简写

\d

[0-9] 的简写

\D

[^0-9] 的简写

\s

[\x20\t\n\r\f\v] 的简写

\S

[^\x20\t\n\r\f\v] 的简写

\w

[a-zA-Z0-9_] 的简写

\W

[^a-zA-Z0-9_] 的简写

(r)

匹配一个 r; 括号用于改变优先级 (见下文)

(?r-s:pattern)

在解释模式时应用选项 'r' 并忽略选项 's'. 选项可以是字符 'i' 或 's' 的零个或多个组合. 'i' 表示不区分大小写. '-i' 表示区分大小写. 's' 改变 '.' 语法的含义, 使其匹配任意单个字符. '-s' 改变 '.' 的含义, 使其匹配除 '\n' 以外的任意字符.

rs

正则表达式 r 后跟正则表达式 s (一个序列)

r|s

r 或 s

^r

一个 r, 但仅位于行首时 (即刚开始扫描时, 或恰在扫描到换行符之后)

r$

一个 r, 但仅位于行尾时 (即恰在换行符之前)

注释

目前不支持 POSIX 字符类, 原因是在宽字符模式下创建它们时存在性能问题.

提示

如果你想为识别引号 ("'"、'"') 和反斜杠 (\) 之类条目的语法构建记号, 下面是可以入手的示例语法. 这里要记住的要点是: c++ 和正则表达式都会对某些结构要求用 \ 转义, 而且这种转义可能层层叠加.

quote1         = "'";            // match single "'"
quote2         = "\\\"";         // match single '"'
literal_quote1 = "\\'";          // match backslash followed by single "'"
literal_quote2 = "\\\\\\\"";     // match backslash followed by single '"'
literal_backslash = "\\\\\\\\";  // match two backslashes

正则表达式优先级
  • rs 具有最高优先级
  • r* 具有次高优先级 (+、?、{n,m} 与 * 具有相同优先级)
  • r|s 具有最低优先级
Macros

正则表达式可以被命名, 并在规则中使用语法 {NAME} 来引用, 其中 NAME 是你为该宏指定的名称. 宏名最长 30 个字符, 且必须以 _ 或字母开头. 后续字符可以是 _、-、字母或十进制数字.
