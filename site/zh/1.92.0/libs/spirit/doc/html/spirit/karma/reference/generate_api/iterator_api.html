基于迭代器的生成器 API
说明

该库提供了几个自由函数, 使生成变得轻而易举. 这些生成器函数有两种形式. 第一种形式 generate 拼接所涉及组件生成的输出, 不在其间插入任何输出. 第二种 generate_delimited 使用给定的分隔符生成器把所涉及组件生成的输出穿插分隔. 两种版本都可以通过 (常量)引用接受持有要输出属性值的属性.

头文件 
// forwards to <boost/spirit/home/karma/generate.hpp>
#include <boost/spirit/include/karma_generate.hpp>

对于可变参数属性:

// forwards to <boost/spirit/home/karma/generate_attr.hpp>
#include <boost/spirit/include/karma_generate_attr.hpp>

API 的可变参数属性版本允许向 generate 函数传递一个或多个属性. 接受两个或更多属性的函数仅在生成器表达式是 Sequence (<<) 时可用. 在这种情况下, 传递的每个属性都必须匹配序列的对应部分.

对于从所提供属性类型推导正确 (匹配) 生成器类型的 API 函数:

// forwards to <boost/spirit/home/karma/detail/generate_auto.hpp>
#include <boost/spirit/include/karma_generate_auto.hpp>

另请参见 包含结构.

注释

从 Spirit V2.5 (随 Boost V1.47 发布)开始, 占位符 _val 可以在附加到顶层生成器组件的语义动作中使用. 在这种情况下, _val 把所提供的属性作为一个整体来引用. 对于接受多个属性实参的 API 函数, _val 将引用一个 Fusion 向量或属性的引用.

基于自动创建匹配生成器类型的 Spirit.Karma 生成器 API 函数:

namespace boost { namespace spirit { namespace karma
{
    template <typename OutputIterator, typename Attr, typename Delimiter>
    inline bool
    generate_delimited(
        OutputIterator& sink
      , Attr const& attr
      , Delimiter const& delimiter
      , BOOST_SCOPED_ENUM(delimit_flag) pre_delimit = delimit_flag::dont_predelimit);

    template <typename OutputIterator, typename Attr>
    inline bool
    generate(
        OutputIterator& sink
      , Attr const& attr);
}}}

如果所涉及的所有生成器组件都没有失败, 上述所有函数返回 true, 否则返回 false. 如果在输出生成过程中底层输出流报告错误, 返回值也将是 false.

支持的最大实参数量受预处理器常量 SPIRIT_ARGUMENTS_LIMIT 限制. 该常量默认为预处理器常量 PHOENIX_LIMIT 定义的值 (后者又默认为 10).

注释

带两个或更多属性的可变参数函数在内部把所有传递属性的 (常量)引用组合成一个 fusion::vector, 并把它作为组合属性转发给接受一个属性的相应函数.

generate_delimited 函数中不把显式 delimit_flag 作为其实参之一的那些, 在开始从生成器表达式生成输出之前不会调用传递的分隔符. 可以通过使用该函数的另一个版本并向相应实参传递 delimit_flag::predelimit 来启用这一点.
