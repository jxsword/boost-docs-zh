将解析得到的属性值存入容器(Qi)

要定制 Spirit 以接受给定数据类型作为任何重复解析器(Kleene, Plus, List 和 Repeat)所解析元素的容器, 必须特化两个属性定制点: traits::container_value 和 traits::push_back_container. 本节描述这两者.
