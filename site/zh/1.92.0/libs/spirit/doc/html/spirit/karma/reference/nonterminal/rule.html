生成器 Rule
说明

rule 是一个多态生成器, 充当命名的占位符, 捕获赋给它的 PEG 表达式的行为. 为 解析表达式文法 表达式命名使其可以在以后被引用, 并使 rule 能够调用自身. 这是最重要的机制之一, 也是递归下降输出生成中"递归"一词的由来.

头文件 
// forwards to <boost/spirit/home/karma/nonterminal/rule.hpp>
#include <boost/spirit/include/karma_rule.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::karma::rule

概要 
template <typename OutputIterator, typename A1, typename A2, typename A3>
struct rule;
模板参数

参数

说明

默认值

OutputIterator

rule 预期工作的底层输出迭代器类型.

none

A1, A2, A3

Signature, Delimiter 或 Locals, 以任意顺序. 参见下表.

参见下表.

以下是关于模板参数的更多信息:

参数

说明

默认值

Signature

规定 rule 的消耗 (要输出的值)属性和继承 (实参)属性. 更多信息见此: Nonterminal.

unused_type. 当 Signature 默认为 unused_type 时, 效果等同于指定签名为 void(), 这也等价于 unused_type()

Delimiter

规定 rule 的分隔符生成器. 如果你想让 rule 分隔生成的输出, 请指定此项.

unused_type

Locals

规定 rule 的局部变量. 参见 Nonterminal.

unused_type

所属模型

Nonterminal

记法约定

r, r2

规则

g

一个生成器表达式

OutputIterator

rule 预期工作的底层输出迭代器类型.

A1, A2, A3

Signature, Delimiter 或 Locals, 以任意顺序.

表达式语义

仅当表达式的语义与 Nonterminal 不同或在其中未定义时, 才给出其语义.

表达式

说明

 

rule<OutputIterator, A1, A2, A3>
    r(name);

rule 声明. OutputIterator 是必需的. A1, A2, A3 是可选的, 可以按任意顺序指定. name 是一个可选字符串, 用于为 rule 命名, 便于调试.

 

rule<OutputIterator, A1, A2, A3>
    r(r2);

复制构造 rule r, 来源是 rule r2.

r = r2;

把 rule r2 赋给 r.

r.alias()

返回 r 的别名. 该别名是一个生成器, 持有对 r 的引用. 引用语义.

r.copy()

获取 r 的一份副本.

r = g;

rule 定义

r %= g;

自动规则定义. g 的属性应当与 r 的消耗属性兼容.

r.name()

获取 rule 对象的当前名称.

r.name(name)

把 rule 对象的当前名称设置为 name.
属性

rule 的生成器属性是 RT: rule 的消耗属性. 参见 Attribute

复杂度

复杂度由右侧 (RHS) 生成器 g 的复杂度决定

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::karma::rule;
using boost::spirit::karma::int_;
using boost::spirit::ascii::space;
using boost::spirit::ascii::space_type;

基本 rule:

rule<output_iterator_type> r;
r = int_(123);
test_generator("123", r);

带消耗属性的 rule:

rule<output_iterator_type, int()> ra;
ra = int_;
test_generator_attr("123", ra, 123);

带分隔符和消耗属性的 rule:

rule<output_iterator_type, std::vector<int>(), space_type> rs;
rs = *int_;
std::vector<int> v;
v.push_back(123);
v.push_back(456);
v.push_back(789);
test_generator_attr_delim("123 456 789", rs, space, v);
