解析器的语义动作

说明

语义动作可以附加到文法规范中的任意位置. 它们允许调用函数或函数对象, 以便提供要由附加该语义动作的解析器输出的值. 语义动作使用语法 p[] 与解析器关联, 其中 p 是任意解析器表达式.

头文件 
// forwards to <boost/spirit/home/qi/action.hpp>
#include <boost/spirit/include/qi_action.hpp>

另请参见 包含结构.

所属模型

UnaryParser

记法约定

a, p

解析器的实例 P

A

解析器暴露的属性类型 a

fa

一个具有如下签名的 (语义动作) 函数: void(Attrib&, Context, bool&). 第三个参数是一个布尔标志, 可设为 false 以强制解析器失败. Context 和布尔标志都是可选的. 更多信息见下文.

Attrib

从解析获得的属性.

Context

解析器执行上下文的类型. 更多信息见下文.

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

p[fa]

如果 p 解析成功, 则调用语义动作 fa. 函数或函数对象 fa 会获得由解析器 p 解析出的属性值, 外加一些上下文信息和一个可用于使解析失败的可变 bool 标志.

可用作语义动作的函数的可能签名是:

template <typename Attrib>
void fa(Attrib& attr);

template <typename Attrib, typename Context>
void fa(Attrib& attr, Context& context);

template <typename Attrib, typename Context>
void fa(Attrib& attr, Context& context, bool& pass);

期望该函数或函数对象通过把要用于生成输出的值赋给第一个参数 attr 来返回它. 这里 Attrib 是附加了语义动作的解析器的属性类型.

类型 Context 是解析器执行上下文的类型. 该类型未作规定, 取决于解析器被调用的上下文. 该值 context 被用 Boost.Phoenix 编写的语义动作用来访问各种依赖于上下文的属性和值. 关于语义动作中可用的 Boost.Phoenix 占位符表达式的更多信息, 参见 Nonterminal.

第三个参数 pass 可被语义动作用来强制相关解析器失败. 如果 pass 被设为 false, 动作解析器也将立即返回 false, 同时不调用 p 且不生成任何输出.

属性

表达式

属性

a[fa]

a: A --> a[fa]: A

复杂度

动作解析器的复杂度由语义动作所附加的解析器的复杂度, 以及用作语义动作的函数或函数对象的复杂度共同决定.
