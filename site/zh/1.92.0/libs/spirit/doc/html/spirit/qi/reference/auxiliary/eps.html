Epsilon 解析器 (eps)
说明

Epsilon (eps) 是一个返回零长度匹配的多用途解析器.

简单形式

在最简单的形式中, eps 匹配空字符串, 并且总是返回零长度匹配:

eps // always returns a zero-length match

这种形式通常用于无条件触发语义动作. 例如, 在一组备选失败时触发错误消息时很有用:

r = a | b | c | eps[error()]; // Call error if a, b, and c fail to match
语义谓词

语义谓词允许你把条件函数附加到文法的任何位置. 在这种角色下, epsilon 接受一个 惰性参数, 该参数返回 true 或 false. 该 惰性参数 通常是一个测试, 会被调用以解决文法中的歧义. 当 惰性参数 的结果求值为 false 时, 将报告解析失败; 否则将报告一个空匹配. 一般形式为:

eps(f) >> rest;

调用 惰性参数 f 来执行语义测试 (例如检查某个符号是否在符号表中). 如果测试返回 true, 则会对 rest 求值; 否则, 该产生式将提前返回不匹配结果, 不会触碰 rest.

头文件 
// forwards to <boost/spirit/home/qi/auxiliary/eps.hpp>
#include <boost/spirit/include/qi_eps.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::eps // alias: boost::spirit::qi::eps

所属模型

PrimitiveParser

记法约定

f

一个 惰性参数, 对 bool 求值.

表达式语义

仅当表达式的语义与 PrimitiveParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

eps

匹配空字符串 (总是匹配).

eps(f)

如果 f 求值为 true, 则返回一个零长度匹配.
属性

表达式

属性

eps

unused

复杂度

对于普通形式 (eps), 复杂度为 O(1). 对于语义谓词 (eps(f)), 复杂度由函数 f 决定.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::qi::eps;
using boost::spirit::qi::int_;
using boost::spirit::qi::_1;
namespace phx = boost::phoenix;

基本 eps:

test_parser("", eps); // always matches

本示例模拟 "经典" 的 if_p 解析器. 这里, int_ 只有在条件 c 为 true 时才会被尝试.

bool c = true; // a flag
test_parser("1234", eps(phx::ref(c) == true) >> int_);

本示例模拟 "经典" 的 while_p 解析器. 这里, 一旦条件 c 变为 true, kleene 循环就会退出. 注意, 条件 c 会被改为 false, 此时我们正在解析 4.

test_phrase_parser("1 2 3 4",
    *(eps(phx::ref(c) == true) >> int_[phx::ref(c) = (_1 == 4)]));
