非终结符

有关 Nonterminals 的更多信息, 请参见此处.

记法约定

RT

合成属性. rule 或 grammar 的返回类型.

Arg1, Arg2, ArgN

继承属性. 零个或多个参数.

L1, L2, LN

零个或多个局部变量.

r, r2

规则

g

一个 grammar

p

一个生成器表达式

my_grammar

一个用户定义的 grammar

术语

Signature

RT(Arg1, Arg2, ... ,ArgN). 签名规定合成属性(返回值)和继承属性(参数).

Locals

locals<L1, L2, ..., LN>. 局部变量.

Delimiter

分隔生成器类型

模板实参

Iterator

你将用于解析的迭代器类型.

A1, A2, A3

可以是以下之一: 1) Signature 2) Locals 3) Delimiter.

表达式

说明

rule<OutputIterator, A1, A2, A3> r(name);

rule 声明. OutputIterator 是必需的. A1, A2, A3 是可选的, 可以按任意顺序指定. name 是一个可选字符串, 用于为 rule 命名, 便于调试.

rule<OutputIterator, A1, A2, A3> r(r2);

复制构造 rule r, 来源是 rule r2.

r = r2;

把 rule r2 赋给 r. boost::shared_ptr 语义.

r.alias()

返回 r 的别名. 该别名是一个生成器, 持有对 r 的引用. 引用语义.

r.copy()

获取 r 的一份副本.

r.name(name)

设置 rule 的名称

r.name()

获取 rule 的名称

debug(r)

调试 rule r

r = g;

rule 定义

r %= g;

自动规则定义. g 的属性应当与 r 的合成属性兼容. 当 g 成功时, 其属性会自动传播到 r 的合成属性.

 

template <typename OutputIterator>
struct my_grammar : grammar<OutputIterator, A1, A2, A3>
{
    my_grammar() : my_grammar::base_type(start, name)
    {
        // Rule definitions
        start = /* ... */;
    }

    rule<OutputIterator, A1, A2, A3> start;
    // more rule declarations...
};

grammar 定义. name 是一个可选字符串, 用于为 grammar 命名, 便于调试.

my_grammar<OutputIterator> g

实例化一个 grammar

g.name(name)

设置 grammar 的名称

g.name()

获取 grammar 的名称
