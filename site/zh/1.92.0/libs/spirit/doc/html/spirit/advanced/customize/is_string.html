判断一个类型是否应被视为字符串(Qi 与 Karma)

is_string

is_string 定制点是一个模板元函数. Qi 的 字符串字面量 (lit(str)), Qi 的 字符字面量 (lit(c)), Karma 的 字符串字面量 (lit(str)), Karma 的 字符字面量 (lit(c)) 以及其他 Spirit 组件都会使用它. 它确定所提供的类型是否可以被视为字符串.

模块头文件 
#include <boost/spirit/home/support/string_traits.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename T>
struct is_string
{
    <unspecified>;
};

表达式语义

表达式

语义

is_string<T>::type

元函数的结果: 求值为 mpl::true_ (当给定类型 T 要被视为字符串时), 否则为 mpl::false_. 通常, is_string 的任何实现都需要表现得如同一个 MPL Boolean Constant.

何时实现

要使用不符合 std::string 语法和语义的用户自定义字符串类, 就需要实现此定制点.

相关的属性定制点
