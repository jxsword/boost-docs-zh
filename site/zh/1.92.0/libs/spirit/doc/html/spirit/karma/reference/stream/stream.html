流生成器(stream, wstream 等)
说明

stream_generator 是一个原语, 允许使用既有的标准流运算符进行输出生成, 并与 Spirit.Karma 集成. 它提供一个包装生成器, 把要输出的值分派给相应类型的流运算符. 任何值 a, 要使用 stream_generator 进行格式化, 都会导致调用其类型 A 的标准流运算符, 例如:

std::ostream& operator<< (std::ostream&, A const&);
头文件 
// forwards to <boost/spirit/home/karma/stream.hpp>
#include <boost/spirit/include/karma_stream.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::stream // alias: boost::spirit::karma::stream

boost::spirit::wstream // alias: boost::spirit::karma::wstream

概要 
template <typename Char>
struct stream_generator;

表达式语义

仅当表达式的语义与 PrimitiveGenerator 不同或在其中未定义时, 才给出其语义.

表达式

说明

stream

对必需属性的类型调用流运算符 operator<<(). 该运算符输出的内容将是 stream 生成器的结果. 该生成器从不失败 (除非底层输出流报告错误). I/O ostream 的字符类型假定为 char.

stream(s)

对直接值的类型调用流运算符 operator<<(), 该直接值为 s. 该运算符输出的内容将是 stream 生成器的结果. 该生成器从不失败 (除非底层输出流报告错误). I/O ostream 的字符类型假定为 char.

wstream

对必需属性的类型调用流运算符 operator<<(). 该运算符输出的内容将是 stream 生成器的结果. 该生成器从不失败 (除非底层输出流报告错误). I/O ostream 的字符类型假定为 wchar_t.

wstream(s)

对直接值的类型调用流运算符 operator<<(), 该直接值为 s. 该运算符输出的内容将是 stream 生成器的结果. 该生成器从不失败 (除非底层输出流报告错误). I/O ostream 的字符类型假定为 wchar_t.

上表列出的所有生成器都是下面描述的 stream_generator<Char> 基本流生成器类型的预定义特化. 可以直接使用该类型, 通过任意底层字符类型创建流生成器.

附加要求

上面列出的所有流生成器都要求要为其生成输出的值的类型 (直接值或关联属性) 实现一个符合通常 I/O 流约定的流运算符 (其中 attribute_type 是要为其生成输出的值的类型):

template <typename Ostream>
Ostream& operator<< (Ostream& os, attribute_type const& attr)
{
    // type specific output generation
    return os;
}

流生成器会调用此运算符来收集类型为 attribute_type 的属性的输出. 流入给定 Ostream 的所有数据最终都会由相应的流生成器实例生成.

注释

如果 stream 生成器在 format (或 format_delimited) 流操纵器内部被调用, 其 Ostream 传递给 operator<<(), 将注册 (注入) 与 format (或 format_delimited) 操纵器一起使用的流相同的标准 locale 实例. 这确保在输出生成期间使用原始 I/O 流对象注册 (注入) 的所有 facet.

重要

一些流生成器暴露的属性类型 hold_any 在语义和语法上等价于 Boost.Any 实现的类型. 它被加入 Spirit 是因为与 Boost.Any 相比, 它具有更好的性能和更小的占用.

注释

除了它们通常的 Attrib 类型属性之外, 所有列出的生成器还接受 boost::optional<Attrib> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 Attrib 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

复杂度

O(N), 其中 N 是流生成器输出的字符数量

一些包含:

#include <boost/spirit/include/karma.hpp>
#include <boost/spirit/include/support_utree.hpp>

#include <string>

一些 using 声明:

using boost::spirit::karma::stream;

以及示例中使用的类定义:

// a simple complex number representation z = a + bi
struct complex
{
    complex (double a, double b)
      : a(a), b(b)
    {}

    double a;
    double b;
};


// define streaming operator for the type complex
std::ostream&
operator<< (std::ostream& os, complex const& z)
{
    os << "{" << z.a << "," << z.b << "}";
    return os;
}

stream 生成器的基本用法:

test_generator_attr("abc", stream, "abc");
test_generator("abc", stream("abc"));
test_generator_attr("{1.2,2.4}", stream, complex(1.2, 2.4));
test_generator("{1.2,2.4}", stream(complex(1.2, 2.4)));
