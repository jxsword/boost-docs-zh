惰性解析器 (lazy)
说明

顾名思义, lazy 解析器会在解析期调用一个惰性的 Boost.Phoenix 函数, 该函数返回一个解析器. 这个解析器一旦创建, 就会被用来继续解析.

头文件 
// forwards to <boost/spirit/home/qi/auxiliary/lazy.hpp>
#include <boost/spirit/include/qi_lazy.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::lazy // alias: boost::spirit::qi::lazy

所属模型

Parser

记法约定

fp

一个 惰性参数, 求值为 Parser.

表达式语义

仅当表达式的语义与 Parser 不同或在其中未定义时, 才给出其语义.

表达式

语义

fp

从 惰性参数 fp 创建一个惰性解析器. fp 会在解析期被调用. fp 应当返回一个 Parser 对象. 随后会调用该解析器来解析输入.

lazy(fp)

从 惰性参数 fp 创建一个惰性解析器. fp 会在解析期被调用. fp 应当返回一个 Parser 对象. 随后会调用该解析器来解析输入.
属性

表达式

属性

fp

fp 返回类型的属性类型.

lazy(fp)

fp 返回类型的属性类型.
复杂度

lazy 解析器的复杂度由 fp 所返回解析器的复杂度决定.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::qi::lazy;
using boost::spirit::ascii::string;
using boost::phoenix::val;

使用 lazy:

这里, phoenix::val 表达式创建了一个在被调用时返回其参数的函数. 惰性表达式把该函数的调用推迟到解析期. 然后, 该解析器 (字符串解析器) 被投入使用. 这一切都发生在解析期.

test_parser("Hello", lazy(val(string("Hello"))));

上面的内容等价于:

test_parser("Hello", string("Hello"));
