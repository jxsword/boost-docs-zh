实数生成器

有关 数值生成器 的更多信息, 请参见此处.

表达式

属性

说明

lit(num)

Unused

生成 num

float_

float

从 float 生成实数

float_(num)

float

生成 num, 作为来自 float 的实数, 如果提供了属性则必须匹配 num

double_

double

从 double 生成实数

double_(num)

double

生成 num, 作为来自 double 的实数, 如果提供了属性则必须匹配 num

long_double

long double

从 long double 生成实数

long_double(num)

long double

生成 num, 作为来自 long double 的实数, 如果提供了属性则必须匹配 num 

real_generator<
    Num, Policies
>()

Num

使用所提供的实数格式化策略生成实数 Num 

real_generator<
    Num, Policies
>()(num)

Num

使用所提供的实数格式化策略生成实数 num, 以 Num 形式, 如果提供了属性则必须匹配
