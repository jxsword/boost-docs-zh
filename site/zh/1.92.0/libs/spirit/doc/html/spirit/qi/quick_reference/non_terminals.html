非终结符

记法约定

RT

合成属性. rule 或 grammar 的返回类型.

Arg1, Arg2, ArgN

继承属性. 零个或多个参数.

L1, L2, LN

零个或多个局部变量.

r, r2

规则

g

一个 grammar

p

一个解析器表达式

my_grammar

一个用户定义的 grammar

术语

Signature

RT(Arg1, Arg2 ... ,ArgN). 签名指定合成 (返回值) 属性和继承 (参数) 属性.

Locals

locals<L1, L2 ..., LN>. 局部变量.

跳过器

跳过解析器的类型

模板实参

Iterator

你将用于解析的迭代器类型.

A1, A2, A3

可以是以下之一: 1) Signature 2) Locals 3) Skipper.

表达式

说明

rule<Iterator, A1, A2, A3> r(name);

rule 声明. Iterator 是必需的. A1, A2, A3 是可选的, 可以以任意顺序指定. name 是一个可选字符串, 为 rule 命名, 对调试和错误处理很有用.

rule<Iterator, A1, A2, A3> r(r2);

复制构造 rule r, 来源是 rule r2.

r = r2;

把 rule r2 赋给 r.

r.alias()

返回 r 的别名. 该别名是一个持有对 r 的引用的解析器. 引用语义.

r.copy()

获取 r 的一份副本.

r.name(name)

为 rule 命名

r.name()

获取 rule 的名称

debug(r)

调试 rule r

r = p;

rule 定义

r %= p;

自动 rule 定义. p 的属性必须与 r 的合成属性兼容. 如果 p 解析成功, 其属性会自动传播到 r 的合成属性. 语义动作 (如果存在) 不得改变属性的类型.

 

template <typename Iterator>
struct my_grammar : grammar<Iterator, A1, A2, A3>
{
    my_grammar() : my_grammar::base_type(start, name)
    {
        // Rule definitions
        start = /* ... */;
    }

    rule<Iterator, A1, A2, A3> start;
    // more rule declarations...
};

文法定义. name 是一个可选字符串, 为文法命名, 对调试和错误处理很有用.

g.name(name)

为文法命名

g.name()

获取文法的名称
