求和 - 把数字相加

下面是一个把以逗号分隔的数字列表求和的解析器.

好, 我们在先前的示例中略过了一些细节. 首先是我们的 include:

#include <boost/spirit/include/qi.hpp>
#include <boost/phoenix/core.hpp>
#include <boost/phoenix/operator.hpp>
#include <iostream>
#include <string>

然后是一些 using 指令:

namespace qi = boost::spirit::qi;
namespace ascii = boost::spirit::ascii;
namespace phoenix = boost::phoenix;

using qi::double_;
using qi::_1;
using ascii::space;
using phoenix::ref;

命名空间

说明

boost::phoenix

整个 phoenix

boost::spirit

整个 spirit

boost::spirit::qi

整个 spirit.qi

boost::spirit::ascii

char_ 的 ASCII 版本及所有与字符相关的解析器. 也提供其他编码 (例如还有 ISO8859.1)

boost::spirit::arg_names

专为 spirit 定制的特殊 phoenix 占位符
注释

如果你对使用整个命名空间感到不自在, 可以放心地给你的代码加限定、使用命名空间别名等. 为了本教程的目的, 我们将为 Spirit 和 Boost.Phoenix 都呈现不带限定的名称. 不用担心, 我们总会给出完整可运行的代码, 所以你不会迷路. 实际上, 本教程中的所有示例都有对应的 cpp 文件, QuickBook (我们使用的文档工具) 会在这里作为代码片段导入.

下面是真正的解析器:

template <typename Iterator>
bool adder(Iterator first, Iterator last, double& n)
{
    bool r = qi::phrase_parse(first, last,

        //  Begin grammar
        (
            double_[ref(n) = _1] >> *(',' >> double_[ref(n) += _1])
        )
        ,
        //  End grammar

        space);

    if (first != last) // fail if we did not get a full match
        return false;
    return r;
}

此示例的完整 cpp 文件可在此处找到: ../../example/qi/sum.cpp

这几乎和我们最初的数字列表示例一样. 我们在示例的基础上逐步递进. 不过这次, 就像复数示例一样, 我们要加入智能. 有一个累加器 (double& n) 把解析出的数字相加. 解析成功时, 这个数字就是所有解析出的数字之和.

第一个 double_ 解析器附加了这个动作:

ref(n) = _1

这把解析结果 (实际上是 double_ 的属性) 赋给 n. ref(n) 告诉 Boost.Phoenix, n 是一个可变引用. _1 是表示解析结果属性的 Boost.Phoenix 占位符.

第二个 double_ 解析器附加了这个动作:

ref(n) += _1

于是, 后续的数字累加进 n.

这不算太糟, 对吧 :-) ?
