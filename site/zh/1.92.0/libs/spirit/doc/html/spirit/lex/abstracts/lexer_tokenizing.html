对输入数据进行记号化

tokenize 函数

tokenize() 函数是一个辅助函数, 它简化了以独立方式使用词法分析器的方法. 例如, 你可能有一个独立运行的词法分析器, 其所有功能需求都在词法分析器语义动作内部实现. 一个很好的例子是 word_count_lexer, 在Lex 快速上手 2 - 更好的单词计数器: 使用 Spirit.Lex一节中有更详细的描述.

template <typename Lexer>
struct word_count_tokens : lex::lexer<Lexer>
{
    word_count_tokens()
      : c(0), w(0), l(0)
      , word("[^ \t\n]+")     // define tokens
      , eol("\n")
      , any(".")
    {
        using boost::spirit::lex::_start;
        using boost::spirit::lex::_end;
        using boost::phoenix::ref;

        // associate tokens with the lexer
        this->self
            =   word  [++ref(w), ref(c) += distance(_start, _end)]
            |   eol   [++ref(c), ++ref(l)]
            |   any   [++ref(c)]
            ;
    }

    std::size_t c, w, l;
    lex::token_def<> word, eol, any;
};

对给定输入进行记号化同时丢弃所有生成的记号, 是词法分析器的一种常见应用. 出于这个原因, Spirit.Lex 提供了一个使所需代码最少的 API 函数 tokenize():

// Read input from the given file
std::string str (read_from_file(1 == argc ? "word_count.input" : argv[1]));

word_count_tokens<lexer_type> word_count_lexer;
std::string::iterator first = str.begin();

// Tokenize all the input, while discarding all generated tokens
bool r = tokenize(first, str.end(), word_count_lexer);

这段代码与Lex 快速上手 2 - 更好的单词计数器: 使用 Spirit.Lex一节中所示的更冗长的版本完全等价. 函数 tokenize() 会在两种情况下返回: 一是已到达输入末尾 (此时返回值为 true), 二是词法分析器无法在输入中匹配任何记号定义 (此时返回值为 false, 且迭代器 first 将指向输入序列中第一个未匹配的字符).

这个函数的原型是:

template <typename Iterator, typename Lexer>
bool tokenize(Iterator& first, Iterator last, Lexer const& lex
  , typename Lexer::char_type const* initial_state = 0);

其中:

Iterator& first

要进行记号化的输入序列的起点. 函数返回后, 词法分析器会更新此迭代器的值, 使其指向输入中第一个未匹配的字符.

Iterator last

要进行记号化的输入序列的终点.

Lexer const& lex

用于记号化的词法分析器实例.

Lexer::char_type const* initial_state

这个可选参数可用于指定记号化时的初始词法分析器状态.

该 tokenize() 函数的第二个重载允许指定任意函数或函数对象, 以便对每个生成的记号进行调用. 对某些应用来说这非常有用, 因为它可以避免使用词法分析器语义动作. 有关如何使用此函数的示例, 请参阅 word_count_functor.cpp:

主函数只是把给定文件加载到内存中 (作为一个 std::string), 使用正确的迭代器类型实例化记号定义模板的一个实例 (word_count_tokens<char const*>), 最后调用 lex::tokenize 并传入该计数函数对象的一个实例. 如果整个输入序列已被成功记号化, 则 lex::tokenize() 的返回值将为 true, 否则为 false.

int main(int argc, char* argv[])
{
    // these variables are used to count characters, words and lines
    std::size_t c = 0, w = 0, l = 0;

    // read input from the given file
    std::string str (read_from_file(1 == argc ? "word_count.input" : argv[1]));

    // create the token definition instance needed to invoke the lexical analyzer
    word_count_tokens<lex::lexertl::lexer<> > word_count_functor;

    // tokenize the given string, the bound functor gets invoked for each of 
    // the matched tokens
    using boost::placeholders::_1;
    char const* first = str.c_str();
    char const* last = &first[str.size()];
    bool r = lex::tokenize(first, last, word_count_functor,
        boost::bind(counter(), _1, boost::ref(c), boost::ref(w), boost::ref(l)));

    // print results
    if (r) {
        std::cout << "lines: " << l << ", words: " << w
                  << ", characters: " << c << "\n";
    }
    else {
        std::string rest(first, last);
        std::cout << "Lexical analysis failed\n" << "stopped at: \""
                  << rest << "\"\n";
    }
    return 0;
}

下面是这个 tokenize() 函数重载的原型:

template <typename Iterator, typename Lexer, typename F>
bool tokenize(Iterator& first, Iterator last, Lexer const& lex, F f
  , typename Lexer::char_type const* initial_state = 0);

其中:

Iterator& first

要进行记号化的输入序列的起点. 函数返回后, 词法分析器会更新此迭代器的值, 使其指向输入中第一个未匹配的字符.

Iterator last

要进行记号化的输入序列的终点.

Lexer const& lex

用于记号化的词法分析器实例.

F f

对每个匹配的记号都会调用一个函数或函数对象. 该函数应具有如下原型: bool f(Lexer::token_type);. 当 tokenize() 函数检测到 F 返回 `false 时将立即返回.

Lexer::char_type const* initial_state

这个可选参数可用于指定记号化时的初始词法分析器状态.
