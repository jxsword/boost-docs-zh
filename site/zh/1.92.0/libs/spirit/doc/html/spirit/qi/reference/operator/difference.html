差解析器 (a - b)
说明

差运算符 a - b 是一个二元运算符, 匹配第一个 (左侧) 操作数但不匹配第二个 (右侧). [8]

头文件 
// forwards to <boost/spirit/home/qi/operator/difference.hpp>
#include <boost/spirit/include/qi_difference.hpp>

另请参见 包含结构.

所属模型

BinaryParser

记法约定

a, b

一个 Parser

表达式语义

仅当表达式的语义与 BinaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

a - b

解析 a 但不解析 b.
属性

参见 复合属性记法.

表达式

属性

a - b 

a: A, b: B --> (a - b): A
a: Unused, b: B --> (a - b): Unused
复杂度

差解析器的复杂度由两个操作数复杂度之和决定.

[8] 与经典 Spirit 不同, 在 Spirit2 中, 如果右侧 (RHS) 是成功匹配, 则无论 RHS 是否匹配更少的字符, 该表达式都总会失败. 例如, rule lit("policeman") - "police" 将总是无法匹配. Spirit2 在解析时不统计匹配的字符数, 也没有可靠且快速的方法来检查左侧 (LHS) 是否比 RHS 匹配得更多.
