禁用区分大小写的解析器指令 (no_case[])
说明

no_case[] 指令不消耗任何输入. 实际匹配由其主体解析器完成. 其目的是强制主体解析器 (及其所有子解析器) 的匹配不区分大小写.

头文件 
// forwards to <boost/spirit/home/qi/directive/no_case.hpp>
#include <boost/spirit/include/qi_no_case.hpp>

另请参见 包含结构.

命名空间

名称

ns::no_case

在上表中, ns 表示一个 字符编码命名空间.

所属模型

no_case 的模型是其主体解析器的模型.

记法约定

a

一个 Parser.

ns

一个 字符编码命名空间.

表达式语义

仅当表达式语义与主体的概念不同或未在主体概念中定义时, 才在此处定义其语义.

表达式

语义

ns::no_case[a]

强制主体解析器 a (及其所有子解析器) 的匹配不区分大小写
属性

参见 复合属性记法.

表达式

属性

ns::no_case[a] 

a: A --> ns::no_case[a]: A
a: Unused --> ns::no_case[a]: Unused
复杂度

复杂度由主体解析器 a 的复杂度决定

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::ascii::no_case;
using boost::spirit::ascii::char_;
using boost::spirit::ascii::alnum;
using boost::spirit::qi::symbols;

no_case[] 的简单用法:

test_parser("X", no_case[char_('x')]);
test_parser("6", no_case[alnum]);

no_case[] 与符号表结合使用的更复杂用例 (更多细节参见 symbols<>):

symbols<char, int> sym;

sym.add
    ("apple", 1)    // symbol strings are added in lowercase...
    ("banana", 2)
    ("orange", 3)
;

int i;
// ...because sym is used for case-insensitive parsing
test_parser_attr("Apple", no_case[ sym ], i);
std::cout << i << std::endl;
test_parser_attr("ORANGE", no_case[ sym ], i);
std::cout << i << std::endl;
