比较多个生成器序列的性能

这些性能测量集中在使用不同的库和方法对一系列不同条目 (包括 2 个 double 浮点数)进行格式化. 下面比较了这些示例的总体执行时间. 我们比较了使用 sprintf, C++ iostreams, Boost.Format 和 Spirit.Karma 的情况.

性能测试的完整源代码请参见此处: format_performance.cpp. 所有测量都是对每种格式化类型执行 1e6 次迭代完成的 (NUMITERATIONS 设为 1e6).

用于测量 sprintf 性能的代码:

char buffer[256];
for (int i = 0; i < NUMITERATIONS; ++i) {
    sprintf(buffer, "[%-14.3f%-14.3f]", 12345.12345, 12345.12345);
}

用于测量标准 iostreams 性能的代码:

std::stringstream strm;
for (int i = 0; i < NUMITERATIONS; ++i) {
    strm.str("");
    strm << '['
      << std::setiosflags(std::ios::fixed)
      << std::left
      << std::setprecision(3)
      << std::setw(14)
      << 12345.12345
      << std::setw(14)
      << 12345.12345
      << ']';
}

用于测量 Boost.Format 性能的代码:

std::string generated;
boost::format outformat("[%-14.3f%-14.3f]");
for (int i = 0; i < NUMITERATIONS; ++i)
    generated = boost::str(outformat % 12345.12345 % 12345.12345);

下面的代码展示了如下所列的所有 Spirit.Karma 性能测量共同使用的定义:

template <typename T>
struct double3_policy : boost::spirit::karma::real_policies<T>
{
    //  we want to generate up to 3 fractional digits
    static unsigned int precision(T) { return 3; }
};

typedef boost::spirit::karma::real_generator<double, double3_policy<double> >
    double3_type;
double3_type const double3 = double3_type();

用于测量 Spirit.Karma 使用普通字符缓冲区时的性能的代码:

char buffer[256];
for (int i = 0; i < NUMITERATIONS; ++i) {
    char *p = buffer;
    generate(p
      , '[' << left_align(14)[double3] << left_align(14)[double3] << ']'
      , 12345.12345, 12345.12345);
    *p = '\0';
}
