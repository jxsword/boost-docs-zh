配合生成器使用的语义动作

说明

语义动作可以附加到文法规范中的任何位置. 它们允许调用函数或函数对象, 以提供附加了语义动作的生成器要输出的值. 语义动作使用语法 g[] 与生成器关联, 其中 g 是任意的生成器表达式.

头文件 
// forwards to <boost/spirit/home/karma/action.hpp>
#include <boost/spirit/include/karma_action.hpp>

另请参见 包含结构.

所属模型

UnaryGenerator

记法约定

a, g

生成器 G 的实例

A

生成器 a 暴露的属性类型

fa

具有签名为 void(Attrib&, Context&, bool&) 的(语义动作)函数. 第三个参数是一个布尔标志, 可以设为 false 以强制生成器失败. Context 和布尔标志都是可选的. 更多信息见下文.

Attrib

用于生成输出的属性.

Context

生成器执行上下文的类型. 更多信息见下文.

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

g[fa]

调用语义动作 fa, 先于 调用 g. 函数或函数对象 fa 应当为生成器 g 提供用于生成输出的值.

可用作语义动作的函数的可能签名是:

template <typename Attrib>
void fa(Attrib& attr);

template <typename Attrib, typename Context>
void fa(Attrib& attr, Context& context);

template <typename Attrib, typename Context>
void fa(Attrib& attr, Context& context, bool& pass);

函数或函数对象应当通过把值赋给第一个参数 attr 来返回用于生成输出的值. 这里 Attrib 是附加了语义动作的生成器的属性类型.

类型 Context 是生成器执行上下文的类型. 该类型未指定, 取决于生成器被调用的上下文. 值 context 供使用 Boost.Phoenix 编写的语义动作访问各种依赖上下文的属性和值. 有关语义动作中可用的 Boost.Phoenix 占位符表达式的更多信息, 参见 Nonterminal.

第三个参数 pass 可被语义动作用来强制关联的生成器失败. 如果 pass 被设为 false, 动作生成器也会立即返回 false, 同时不调用 g, 也不生成任何输出.

属性

表达式

属性

a[fa]

a: A --> a[fa]: A

复杂度

动作生成器的复杂度由语义动作所附加的生成器的复杂度, 以及用作语义动作的函数或函数对象的复杂度决定.

重要

请注意, 在 Spirit.Karma 中使用语义动作通常会迫使库创建属性的 副本, 这可能是代价高昂的操作. 应当始终优先考虑使用其他方式把值与特定生成器关联.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些包含:

#include <boost/spirit/include/karma.hpp>
#include <boost/spirit/include/support_utree.hpp>
#include <boost/phoenix/core.hpp>
#include <boost/phoenix/operator.hpp>
#include <boost/fusion/include/std_pair.hpp>
#include <boost/proto/deep_copy.hpp>
#include <iostream>
#include <string>

一些 using 声明:

using boost::spirit::karma::int_;
using boost::spirit::karma::string;
using boost::spirit::karma::_1;
using boost::phoenix::ref;
using boost::phoenix::val;

一些示例:

int i = 42;
test_generator("42", int_[_1 = ref(i)]);
test_generator("abc", string[_1 = val("abc")]);
