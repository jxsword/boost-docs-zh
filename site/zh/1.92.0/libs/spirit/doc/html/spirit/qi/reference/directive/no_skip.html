抑制跳过且不做预跳过的解析器指令 (no_skip[])
说明

no_skip[] 指令关闭空白字符跳过. 与 lexeme 的区别在于它在任何情况下都不做预跳过. 除此之外, 它与 lexeme 指令完全等价.

头文件 
// forwards to <boost/spirit/home/qi/directive/no_skip.hpp>
#include <boost/spirit/include/qi_no_skip.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::no_skip // alias: boost::spirit::qi::no_skip

所属模型

UnaryParser

记法约定

a

一个 Parser.

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

no_skip[a]

对主体解析器 a (及其所有子解析器) 关闭空白字符跳过. 该指令不做预跳过.
属性

参见 复合属性记法.

表达式

属性

no_skip[a] 

a: A --> no_skip[a]: A
a: Unused --> no_skip[a]: Unused
复杂度

复杂度由主体解析器 a 的复杂度决定

注释

一些 using 声明:

using boost::spirit::qi::no_skip;
using boost::spirit::qi::char_;

no_skip[] 的简单用法:

这里使用 no_skip 将防止跳过字符串 ' abc ' 之前及其字符之间的空白字符.

std::string str;
test_phrase_parser_attr("'  abc  '",
    '\'' >> no_skip[+~char_('\'')] >> '\'', str);
std::cout << str << std::endl;    // will output: >  abc  <
