对齐生成器指令(left_align[], center[], right_align[])
说明

对齐指令允许把其他生成器输出的内容左对齐, 右对齐或居中到指定宽度的列中, 同时使用任意生成器来创建填充.

头文件

对于 left_align[] 指令:

// forwards to <boost/spirit/home/karma/directive/left_alignment.hpp>
#include <boost/spirit/include/karma_left_alignment.hpp>

对于 center[] 指令:

// forwards to <boost/spirit/home/karma/directive/center_alignment.hpp>
#include <boost/spirit/include/karma_center_alignment.hpp>

对于 right_align[] 指令:

// forwards to <boost/spirit/home/karma/directive/right_alignment.hpp>
#include <boost/spirit/include/karma_right_alignment.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::left_align // alias: boost::spirit::karma::left_align

boost::spirit::center // alias: boost::spirit::karma::center

boost::spirit::right_align // alias: boost::spirit::karma::right_align

所属模型

UnaryGenerator

记法约定

a

一个生成器对象

pad

一个生成器对象, 或求值为生成器对象的 惰性实参

A, Pad

生成器 a 和 pad 的属性类型

width

数值字面量, 任意无符号整数值, 或求值为无符号整数值的 惰性实参

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

left_align[a]

生成 a, 在宽度由预处理器常量 BOOST_KARMA_DEFAULT_FIELD_LENGTH 定义 (默认: 10) 的列中左对齐, 同时使用 space 输出必要的填充. 只要其内嵌生成器 a 不失败, 该生成器就成功 (除非底层输出流报告错误).

left_align(width)[a]

生成 a, 在给定 width 宽度的列中左对齐, 同时使用 space 输出必要的填充. 只要其内嵌生成器 a 不失败, 该生成器就成功 (除非底层输出流报告错误).

left_align(pad)[a]

生成 a, 在宽度由预处理器常量 BOOST_KARMA_DEFAULT_FIELD_LENGTH 定义 (默认: 10) 的列中左对齐, 同时使用生成器 pad 输出必要的填充. 只要其内嵌生成器和填充生成器 a 与 pad 不失败, 该生成器就成功 (除非底层输出流报告错误).

left_align(width, pad)[a]

生成 a, 在给定 width 宽度的列中左对齐, 同时使用生成器 pad 输出必要的填充. 只要其内嵌生成器和填充生成器 a 与 pad 不失败, 该生成器就成功 (除非底层输出流报告错误).

center[a]

生成 a, 在宽度由预处理器常量 BOOST_KARMA_DEFAULT_FIELD_LENGTH 定义 (默认: 10) 的列中居中, 同时使用 space 输出必要的填充. 只要其内嵌生成器 a 不失败, 该生成器就成功 (除非底层输出流报告错误).

center(width)[a]

生成 a, 在给定 width 宽度的列中居中, 同时使用 space 输出必要的填充. 只要其内嵌生成器 a 不失败, 该生成器就成功 (除非底层输出流报告错误).

center(pad)[a]

生成 a, 在宽度由预处理器常量 BOOST_KARMA_DEFAULT_FIELD_LENGTH 定义 (默认: 10) 的列中居中, 同时使用生成器 pad 输出必要的填充. 只要其内嵌生成器和填充生成器 a 与 pad 不失败, 该生成器就成功 (除非底层输出流报告错误).

center(width, pad)[a]

生成 a, 在给定 width 宽度的列中居中, 同时使用生成器 pad 输出必要的填充. 只要其内嵌生成器和填充生成器 a 与 pad 不失败, 该生成器就成功 (除非底层输出流报告错误).

right_align[a]

生成 a, 在宽度由预处理器常量 BOOST_KARMA_DEFAULT_FIELD_LENGTH 定义 (默认: 10) 的列中右对齐, 同时使用 space 输出必要的填充. 只要其内嵌生成器 a 不失败, 该生成器就成功 (除非底层输出流报告错误).

right_align(width)[a]

生成 a, 在给定 width 宽度的列中右对齐, 同时使用 space 输出必要的填充. 只要其内嵌生成器 a 不失败, 该生成器就成功 (除非底层输出流报告错误).

right_align(pad)[a]

生成 a, 在宽度由预处理器常量 BOOST_KARMA_DEFAULT_FIELD_LENGTH 定义 (默认: 10) 的列中右对齐, 同时使用生成器 pad 输出必要的填充. 只要其内嵌生成器和填充生成器 a 与 pad 不失败, 该生成器就成功 (除非底层输出流报告错误).

right_align(width, pad)[a]

生成 a, 在给定 width 宽度的列中右对齐, 同时使用生成器 pad 输出必要的填充. 只要其内嵌生成器和填充生成器 a 与 pad 不失败, 该生成器就成功 (除非底层输出流报告错误).
注释

上面列出的生成器指令都不会把输出的内容限制在相应列宽之内. 如果输出的内容长于指定 (或隐含) 的列宽, 生成的输出会向右溢出该列.

如果需要把输出限制在指定列宽内, 请使用 maxwidth[] 指令, 例如:

maxwidth(8)[right_align(12)["1234567890"]]

它将输出 (不含引号):

"  123456"

复杂度

对齐生成器指令的总体复杂度由其内嵌生成器和填充生成器的复杂度决定. 左对齐指令生成器本身的复杂度是 O(1). 居中和右对齐指令生成器的复杂度是 O(N), 其中 N 是内嵌生成器和填充生成器输出的字符数量.

注释

下面示例的测试框架在 基础示例 一节中给出.

一些包含:

#include <boost/spirit/include/karma.hpp>
#include <boost/spirit/include/support_utree.hpp>
#include <boost/phoenix/core.hpp>
#include <boost/phoenix/operator.hpp>
#include <boost/fusion/include/std_pair.hpp>
#include <boost/proto/deep_copy.hpp>
#include <iostream>
#include <string>

一些 using 声明:

using boost::spirit::karma::double_;
using boost::spirit::karma::left_align;
using boost::spirit::karma::center;
using boost::spirit::karma::right_align;

对齐生成器的基本用法:

std::pair<double, double> p (1.0, 2.0);
test_generator_attr("1.0     |2.0", left_align(8)[double_] << '|' << double_, p);
test_generator_attr("   1.0  |2.0", center(8)[double_] << '|' << double_, p);
test_generator_attr("     1.0|2.0", right_align(8)[double_] << '|' << double_, p);
