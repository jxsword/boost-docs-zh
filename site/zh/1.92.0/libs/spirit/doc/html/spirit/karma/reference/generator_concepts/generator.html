Generator
说明

Generator 是最基本的概念. Generator 有一个成员函数 generate, 它接受一个 OutputIterator 并返回 bool 作为其结果. 迭代器接收正在生成的数据. 如果生成器成功, Generator 的 generate 成员函数返回 true. 每个 Generator 都可以表示特定的模式或算法, 也可以是由其他 Generator 组合而成的更复杂的生成器.

记法约定

g

一个Generator.

G

一个 Generator 类型.

OutIter

一个 OutputIterator 类型.

sink

一个 OutputIterator 实例.

Context

生成器的 Context 类型.

context

生成器的 Context, 或 unused.

delimit

分隔符 Generator, 或 unused.

attrib

兼容属性 (Compatible Attributes), 或 unused.

有效表达式

在下面的表达式中, 生成器 g 的行为, 以及 delimit 和 attrib 如何被 g 处理, 在基础 Generator 概念中未作规定. 这些内容在后续更细化的概念及其具体模型中规定.

对于任何 Generator, 以下表达式必须有效:

表达式

语义

返回类型

 

g.generate(sink, context, delimit, attrib)

通过把生成的字符/记号插入 sink 来生成输出序列. 使用 delimit 生成器进行分隔. 成功时返回 true, 否则返回 false.

bool

g.what(context)

获取关于 Generator 的信息.

info

类型表达式

表达式

说明

G::template attribute<Context>::type

Generator 的属性.

traits::is_generator<G>::type

元函数, 求值为 mpl::true_ (当某个类型 G 是 Generator 时), 否则为 mpl::false_ (参见 MPL Boolean Constant).

G::properties

一个 mpl::int_ (参见 MPL Integral Constant), 持有 karma::generator_properties 枚举中的一个值. 默认值是 generator_properties::no_properties

后置条件

从 g.generate 返回后, 应满足以下后置条件:

  • 成功生成时, sink 接收生成的字符/记号序列.
  • 无前置分隔: delimit 字符/记号不会在任何其他输出之前输出.
  • 属性 attrib 未被修改.
模型

Spirit.Karma 中的所有生成器都是 Generator 概念的模型.
