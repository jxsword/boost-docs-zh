字符分类生成器(alnum, digit 等)
说明

该库具有用于字符分类的完整的单字符生成器库. 这包括常用的 alnum, alpha, digit, xdigit 等生成器. 这些生成器有一个关联的 字符编码命名空间. 在执行强制小写或大写等基本操作时需要它.

头文件 
// forwards to <boost/spirit/home/karma/char/char_class.hpp>
#include <boost/spirit/include/karma_char_class.hpp>

另请参见 包含结构.

语义

ns::alnum

如果必需属性满足 std::isalnum 的概念 (在 字符编码命名空间 中), 生成器在输出其属性后成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何内容.

ns::space

如果可选属性满足 std::isspace 的概念 (在 字符编码命名空间 中), 生成器在输出其属性后成功 (除非底层输出流报告错误). 否则该生成器失败且不生成任何内容. 如果未提供属性, 该生成器在由 ns 定义的字符集中输出单个空格字符.

ns 的可能取值在 字符编码命名空间 一节中描述.

注释

生成器 alpha 和 alnum 如果在一个 lower[] 或 upper[] 指令中使用, 行为可能看起来出乎意料. 这两个指令还会把 std::islower 或 std::isupper 的语义额外应用于相应字符类. 一些示例:

std::string s;
std::back_insert_iterator<std::string> out(s);
generate(out, lower[alpha], 'a');               // succeeds emitting 'a'
generate(out, lower[alpha], 'A');               // fails

生成器指令 upper[] 的行为与之对应.

属性

所有列出的字符类生成器都可以接受任何属性 Ch. 所有字符类生成器(space 除外)都要求有属性, 否则将无法编译.

注释

除了它们通常的 Ch 类型属性之外, 所有列出的生成器还接受 boost::optional<Ch> 的实例. 如果 boost::optional<> 已初始化(持有值), 生成器的行为就像其属性是 Ch 的实例一样, 并输出存储在 boost::optional<> 中的值. 否则生成器将失败.

复杂度

O(1)

复杂度是常量, 因为生成器每次调用最多输出一个字符.

alpha 生成器的基本用法:

test_generator_attr("a", alpha, 'a');
test_generator_attr("A", alpha, 'A');
test_generator_attr("", alpha, '1');          // fails (as isalpha('1') is false)
test_generator_attr("A", upper[alpha], 'A');
test_generator_attr("", upper[alpha], 'a');   // fails (as isupper('a') is false)
