以原子方式从容器中提取属性值(Karma)

attribute_as

attribute_as 以原子方式从另一个类型提取某个类型的实例. as<T>[] 指令会使用该定制点.

模块头文件 
#include <boost/spirit/home/support/attributes_fwd.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename T, typename Attribute, typename Enable = void>
struct attribute_as;
模板参数

参数

说明

默认值

T

调用 attribute_as 的组件原生暴露的属性类型.

none

Attribute

用于生成输出的属性类型.

none

Enable

辅助模板参数, 可利用 SFINAE 有选择地启用或禁用 attribute_as 的某些特化(即 boost::enable_if 或 boost::disable_if).

void

记法约定

attr

Attrib 类型的实例.

表达式语义

表达式

语义

attribute_as<T, Attribute>::type

提取结果的类型.

attribute_as<T, Attribute>::call(attr)

提取并返回一个 type 实例.

attribute_as<T, Attribute>::valid_as(attr)

在运行期确定提取 type 的实例(来自 attr)是否会导致错误.
预定义特化

Spirit 为若干类型预定义了此定制点的特化. 下表列出了这些类型及其暴露的类型和相应的语义:

模板参数

语义

unused_type

暴露的 typedef type 被定义为 unused_type. 函数 call() 返回一个 unused_type 实例.
何时实现

使用 as<T>[] 指令时, 可能需要实现此定制点.
