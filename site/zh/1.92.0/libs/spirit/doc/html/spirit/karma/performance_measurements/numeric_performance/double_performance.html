比较单个 double_ 生成器的性能

这些性能测量集中在使用不同的库和方法对单个 double 浮点数进行默认格式化. 下面比较了这些示例的总体执行时间. 我们比较了使用 sprintf, C++ iostreams, Boost.Format 和 Spirit.Karma 的情况.

性能测试的完整源代码请参见此处: double_performance.cpp. 所有测量都是对每种格式化类型执行 1e6 次迭代完成的 (在下面所示的代码中 NUMITERATIONS 设为 1e6).

用于测量 sprintf 性能的代码:

char buffer[256];
for (int i = 0; i < NUMITERATIONS; ++i) {
    sprintf(buffer, "%f", 12345.12345);
}

用于测量标准 C++ iostreams 性能的代码:

std::stringstream strm;
for (int i = 0; i < NUMITERATIONS; ++i) {
    strm.str("");
    strm << 12345.12345;
}

用于测量 Boost.Format 性能的代码:

std::string generated;
boost::format double_format("%f");
for (int i = 0; i < NUMITERATIONS; ++i)
    generated = boost::str(double_format % 12345.12345);

下面的代码展示了如下所列的所有 Spirit.Karma 性能测量共同使用的定义:

using boost::spirit::karma::double_;

用于测量 Spirit.Karma 使用普通字符缓冲区时的性能的代码:

char buffer[256];
for (int i = 0; i < NUMITERATIONS; ++i) {
    char *p = buffer;
    generate(p, double_, 12345.12345);
    *p = '\0';
}
