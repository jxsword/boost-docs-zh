Phoenix

Boost.Phoenix 使附加语义动作变得更容易. 你只需内联你的 lambda 表达式:

l[phoenix-lambda-expression]

Spirit.Lex 提供了一些 Boost.Phoenix 占位符, 用于访问 Context 中难以以其他方式提取的重要信息.

Spirit.Lex 专用的 Phoenix 占位符

_start, _end

指向所匹配输入序列开头和结尾的迭代器.

_pass

把 lex::pass_flags::pass_fail 赋给 _pass 可强制当前匹配失败.

_tokenid

所匹配记号的记号 id.

_val

所匹配记号的记号值.

_state

匹配该记号时所用的词法分析器状态.

_eoi

引用输入序列当前结尾的迭代器.

提示

上表列出的所有占位符 (_eoi 除外) 都可以在语义动作内部修改, 从而改变词法分析器的行为. 它们定义在命名空间 boost::spirit::lex 中.

更多信息参见 词法分析器语义动作.
