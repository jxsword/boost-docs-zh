控制最大字段宽度的生成器指令(maxwidth[])
说明

maxwidth[] 指令允许限制 (截断) 内嵌生成器生成的输出的总长度.

头文件 
// forwards to <boost/spirit/home/karma/directive/maxwidth.hpp>
#include <boost/spirit/include/karma_maxwidth.hpp>

另请参见 包含结构.

名称

boost::spirit::maxwidth // alias: boost::spirit::karma::maxwidth

所属模型

UnaryGenerator

记法约定

a

一个生成器对象

A

生成器 a 的属性类型

num

数值字面量, 任意无符号整数值, 或求值为无符号整数值的 惰性实参

表达式语义

仅当表达式的语义与 UnaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

maxwidth[a]

把内嵌生成器输出的总长度 (包括自动分隔生成的字符) 限制为预处理器常量 BOOST_KARMA_DEFAULT_FIELD_MAXWIDTH 定义的字符数量. 任何额外的输出都会被截断. 只要内嵌生成器成功, 该指令就成功 (除非底层输出流报告错误).

maxwidth(num)[a]

把内嵌生成器输出的总长度 (包括自动分隔生成的字符) 限制为 num 定义的字符数量. 任何额外的输出都会被截断. 只要内嵌生成器成功, 该指令就成功 (除非底层输出流报告错误).
注释

maxwidth[] 生成器指令不会把生成的输出填充到指定列宽. 如果输出的内容短于指定 (或隐含) 的列宽, 生成的输出会比列宽窄.

如果输出需要始终等于指定列宽, 请使用对齐指令之一: left-align[], center[] 或 right_align[], 例如:

maxwidth(8)[left_align(8)["1234"]]

它将输出: "1234 " (不含引号).

属性

参见 复合属性记法.

表达式

属性

maxwidth[a] 

a: A --> maxwidth[a]: A
a: Unused --> maxwidth[a]: Unused

maxwidth(num)[a] 

a: A --> maxwidth(num)[a]: A
a: Unused --> maxwidth(num)[a]: Unused
复杂度

生成器指令 maxwidth[] 的总体复杂度由其内嵌生成器的复杂度决定. 指令本身的复杂度是 O(N), 其中 N 是 maxwidth 指令生成的字符数量.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些包含:

#include <boost/spirit/include/karma.hpp>
#include <iostream>
#include <string>

一些 using 声明:

using boost::spirit::karma::double_;
using boost::spirit::karma::maxwidth;
using boost::spirit::karma::left_align;
using boost::spirit::karma::right_align;

maxwidth 生成器指令的基本用法:

test_generator("01234", maxwidth(5)["0123456789"]);
test_generator("  012", maxwidth(5)[right_align(12)["0123456789"]]);
test_generator("0123    ", maxwidth(8)[left_align(8)["0123"]]);
