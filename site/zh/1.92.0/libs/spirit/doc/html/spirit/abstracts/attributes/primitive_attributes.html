原语组件的属性

Spirit 中的解析器和生成器都是完全带属性的. Spirit.Qi 解析器总是 暴露 一个与其类型相关的属性. 这称为 合成属性, 因为它在成功匹配后返回, 代表被匹配的输入序列. 例如, 数值解析器(如 int_ 或 double_)返回从被匹配输入序列转换而来的 int 或 double 值. 其他原语解析器组件具有其他直观的属性类型, 例如 int_ 具有 int, 而 ascii::char_ 具有 char. 对于原语解析器适用正常的 C++ 可转换性规则: 只要解析器的属性类型可转换为所提供的类型, 就可以使用任何 C++ 类型来接收解析得到的值. 下面的示例展示了如何提取解析器的合成属性(int 值), 即调用 API 函数 qi::parse:

int value = 0;
std::string str("123");
std::string::iterator strbegin = str.begin();
qi::parse(strbegin, str.end(), int_, value);   // value == 123

生成器的属性类型定义了该生成器为了产生输出而能够消耗的数据类型. Spirit.Karma 生成器总是 期待 一个与其类型相关的属性. 这称为 消耗属性, 需要传递给生成器. 消耗属性在多数情况下就是生成器被设计用来生成输出的那个值. 对于原语生成器, 适用正常的 C++ 可转换性规则. 任何可转换为原语生成器属性类型的数据类型都可用于提供要生成的数据. 我们给出一个与上面类似的示例, 这一次 int_ 生成器的消耗属性(int 值)被传递给 API 函数 karma::generate:

int value = 123;
std::string str;
std::back_insert_iterator<std::string> out(str);
karma::generate(out, int_, value);                // str == "123"

其他原语生成器组件具有其他直观的属性类型, 与相应的解析器组件非常相似. 例如, ascii::char_ 生成器以 char 作为消耗属性. 有关可用的解析器和生成器原语及其属性类型的完整列表, 请参见 Qi 解析器 和 Karma 生成器 章节.
