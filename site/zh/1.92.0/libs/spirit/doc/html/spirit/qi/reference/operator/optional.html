可选解析器 (-a)
说明

可选运算符 -a 是一个一元运算符, 匹配其操作数零次或一次.

头文件 
// forwards to <boost/spirit/home/qi/operator/optional.hpp>
#include <boost/spirit/include/qi_optional.hpp>

另请参见 包含结构.

所属模型

UnaryParser

记法约定

a

一个 Parser

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

-a

匹配 a 零次或一次.
属性

参见 复合属性记法.

表达式

属性

-a 

a: A --> -a: optional<A>
a: Unused --> -a: Unused
复杂度

复杂度由操作数 a 的复杂度决定

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::ascii::char_;
using boost::spirit::qi::lexeme;
using boost::spirit::qi::int_;
using boost::fusion::vector;
using boost::fusion::at_c;
using boost::optional;

解析一个人员信息: 名称 (带引号)、可选的年龄 [9] 和可选的性别, 全部以逗号分隔.

vector<std::string, optional<int>, optional<char> > attr;

test_phrase_parser_attr(
    "\"James Bond\", M"
  , lexeme['"' >> +(char_ - '"') >> '"']    // name
        >> -(',' >> int_)                   // optional age
        >> -(',' >> char_)                  // optional sex
  , attr);

// Should print: James Bond,M
std::cout << at_c<0>(attr);                 // print name
if (at_c<1>(attr))                          // print optional age
    std::cout << ',' << *at_c<1>(attr);
if (at_c<2>(attr))                          // print optional sex
    std::cout << ',' << *at_c<2>(attr);
std::cout << std::endl;


[9] James Bond 对自己的年龄很害羞 :-)
