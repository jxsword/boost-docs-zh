数值解析器

无符号整数解析器 (uint_ 等)
有符号整数解析器 (int_ 等)
实数解析器 (float_、double_ 等)
布尔解析器 (bool_)

该库包含几个用于解析有符号和无符号整数以及实数的预定义对象. 这些解析器是完全参数化的. 数值解析的大多数重要方面都可以精细调整以满足需求. 这包括基数、允许的最小和最大位数、指数、小数部分等. 策略 (policy) 控制实数解析器的行为. 有一些预定义策略覆盖了最常见的实数格式, 用户也可以在需要时提供自己的策略.

数值解析器经过精细调优 (采用循环展开和大量模板元编程), 拥有可媲美 atof、strtod、atol、strtol 等底层 C 函数的卓越性能. 基准测试显示, 其速度最高可达对应 C 实现的 4 倍. 这表明你可以编写极其紧凑的泛型 C++ 代码, 与 C 相当甚至超越 C.
