确定字符串的字符类型
char_type_of

此定制点是一个 MPL 元函数, 返回给定字符串类型的字符类型. char_type_of 处理用户自定义类型(例如 std::string)以及 C 风格字符串.

模块头文件 
#include <boost/spirit/home/support/string_traits.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename T>
struct char_type_of
{
    typedef <unspecified> type;
};

何时实现

每当实现了 traits::is_string 时, 就需要实现此定制点.
