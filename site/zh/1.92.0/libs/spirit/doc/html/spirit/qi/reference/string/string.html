字符串解析器 (string、lit)
说明

string 解析器匹配一个字符串. string 解析器是一个隐式 lexeme: skip 解析器不会应用在字符串的字符之间. string 解析器有一个关联的 字符编码命名空间. 在执行禁止区分大小写等基本操作时需要用到它. 示例:

string("Hello")
string(L"Hello")
string(s) // s is a std::string

lit 与 string 一样, 也匹配一个字符串. 主要区别在于 lit 不合成属性. 像 "hello" 这样的纯字符串或 std::basic_string 等价于一个 lit. 示例:

"Hello"
lit("Hello")
lit(L"Hello")
lit(s) // s is a std::string
头文件 
// forwards to <boost/spirit/home/qi/string/lit.hpp>
#include <boost/spirit/include/qi_lit.hpp>
命名空间

名称

boost::spirit::lit // alias: boost::spirit::qi::lit

ns::string

在上表中, ns 表示一个 字符编码命名空间.

所属模型

PrimitiveParser

记法约定

s

一个 String, 或求值为 String 的 惰性参数.

ns

一个 字符编码命名空间.

表达式语义

仅当表达式的语义与 PrimitiveParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

s

从字符串 s 创建字符串解析器.

lit(s)

从字符串 s 创建一个字符串解析器.

ns::string(s)

以 ns 编码从字符串 s 创建一个字符串解析器.
属性

表达式

属性

s

unused

lit(s)

unused

ns::string(s)

std::basic_string<T>, 其中 T 是 s 的底层字符类型.
复杂度

O(N)

其中 N 是待解析字符串中的字符数.

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::qi::lit;
using boost::spirit::ascii::string;

基本字面量:

test_parser("boost", "boost");          // plain literal
test_parser("boost", lit("boost"));     // explicit literal
test_parser("boost", string("boost"));  // ascii::string

从 std::string 

std::string s("boost");
test_parser("boost", s);            // direct
test_parser("boost", lit(s));       // explicit
test_parser("boost", string(s));    // ascii::string

使用 Boost.Phoenix 的惰性字符串

namespace phx = boost::phoenix;
test_parser("boost", phx::val("boost"));            // direct
test_parser("boost", lit(phx::val("boost")));       // explicit
test_parser("boost", string(phx::val("boost")));    // ascii::string
