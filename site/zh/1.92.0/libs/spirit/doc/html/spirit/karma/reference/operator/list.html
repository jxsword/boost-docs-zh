List 生成器(a % b)
说明

列表生成器用于把内嵌生成器的执行重复一次或多次, 并穿插另一个生成器的输出. 如果内嵌生成器至少成功执行一次, 它就成功.

头文件 
// forwards to <boost/spirit/home/karma/operator/list.hpp>
#include <boost/spirit/include/karma_list.hpp>

另请参见 包含结构.

所属模型

BinaryGenerator

表达式语义

仅当表达式的语义与 BinaryGenerator 不同或在其中未定义时, 才给出其语义.

表达式

语义

a % b

生成器 a 根据属性的可用性执行一次或多次. a 生成的输出与 b 生成的输出穿插在一起. 如果其第一个内嵌生成器至少成功执行一次, 列表生成器就成功 (除非底层输出流报告错误).

列表表达式 a % b 是 a << *(b << a) 的简写. 它们在语义上几乎等价, 区别在于 b 的属性, 在列表生成器的情况下该属性被忽略.

注释

整个 a % b 将会成功, 只要内嵌生成器 a 至少有一次调用成功 (除非底层输出流报告错误).

属性

参见 复合属性记法.

表达式

属性

a % b (列表)

 

a: A, b: B --> (a % b): vector<A>
a: Unused, b: B --> (a % b): Unused
重要

上表仅把 vector<A> 用作占位符. 记法 vector<A> 表示 任意 STL 容器, 其中保存类型为 A 的元素.

列表生成器会对所提供容器属性中的每个元素执行一次其内嵌生成器, 且只要内嵌生成器成功就继续. 其第一个生成器生成的输出会被第二个生成器生成的输出穿插. 每次迭代它都会把容器属性中的下一个连续元素传递给第一个内嵌生成器. 第二个内嵌生成器不会收到任何属性 (它以 unused_type 作为属性被调用). 因此迭代次数不会大于作为其属性传入的容器中的元素数量. 空容器会使列表生成器失败.

提示

如果你想使用列表生成器同时仍允许空属性, 可以使用 optional 运算符 (参见 Optional (一元 -)):

-(a % b)

即使所提供的容器属性不包含任何元素, 它也会成功.

复杂度

列表生成器的总体复杂度由其内嵌生成器的复杂度乘以执行的迭代次数决定. 列表生成器本身的复杂度是 O(N), 其中 N 是作为其属性传入的容器中的元素数量.
