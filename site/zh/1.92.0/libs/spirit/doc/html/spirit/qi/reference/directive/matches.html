测试解析器是否成功的指令 (matches[])
说明

matches[] 指令执行内嵌解析器并返回其是否成功匹配.

头文件 
// forwards to <boost/spirit/home/qi/directive/matches.hpp>
#include <boost/spirit/include/qi_matches.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::matches // alias: boost::spirit::qi::matches

所属模型

UnaryParser

记法约定

a

一个 Parser.

表达式语义

仅当表达式的语义与 UnaryParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

matches[a]

执行主体解析器 a, 并把其是否成功作为属性返回. 指令本身总是成功.
属性

表达式

属性

matches[a]

bool

复杂度

复杂度由主体解析器 a 的复杂度决定

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::qi::matches;
using boost::spirit::qi::int_;

该解析器尝试匹配 int, 由于匹配成功, 返回 true 作为其属性:

bool result = false;
test_parser_attr("345", matches[int_], result);
std::cout << std::boolalpha << result << std::endl; // should print: true

该解析器同样尝试匹配 int, 由于匹配失败, 返回 false 作为其属性:

result = true;
test_parser_attr("abc", matches[int_], result);
std::cout << std::boolalpha << result << std::endl; // should print: false
