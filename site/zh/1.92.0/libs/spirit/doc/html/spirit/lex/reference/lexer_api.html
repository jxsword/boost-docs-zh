词法分析器 API

说明

该库提供了几个自由函数, 使词法分析器的使用变得轻而易举. 这些函数有三种形式. 第一种形式 tokenize 简化了独立词法分析器 (不进行解析) 的使用. 第二种形式 tokenize_and_parse 将词法分析步骤与记号层级的解析相结合 (不带跳过器). 第三种 tokenize_and_phrase_parse 同样工作在记号层级, 但另外还使用了一个跳过解析器. 后两种版本可以通过引用传入属性, 解析成功时这些属性将保存解析得到的值.

头文件 
// forwards to <boost/spirit/home/lex/tokenize_and_parse.hpp>
#include <boost/spirit/include/lex_tokenize_and_parse.hpp>

对于可变参数属性:

// forwards to <boost/spirit/home/lex/tokenize_and_parse_attr.hpp>
#include <boost/spirit/include/lex_tokenize_and_parse_attr.hpp>

API 的可变属性版本允许向 API 函数传入一个或多个属性. 接受两个或更多属性的函数仅在解析器表达式为 Sequence (序列) 时可用. 此时, 传入的每个属性都必须与序列的相应部分匹配.

另请参见 包含结构.

命名空间

名称

boost::spirit::lex::tokenize

boost::spirit::lex::tokenize_and_parse

boost::spirit::lex::tokenize_and_phrase_parse

boost::spirit::qi::skip_flag::postskip

boost::spirit::qi::skip_flag::dont_postskip

概要

tokenize 函数是主要的词法分析器 API 函数之一. 它简化了使用词法分析器对给定输入序列进行记号化的过程. 其主要用途是用词法分析器对全部输入进行记号化.

这两个函数都接受一对跨越待扫描底层输入流的迭代器、词法分析器对象 (由记号定义构建), 以及一个 (可选的) 仿函数, 该仿函数会对每个生成的记号被调用. 如果没有给出函数对象 f, 生成的记号将被丢弃.

如果对输入的扫描成功 (给定输入序列被给定记号定义成功匹配), 这些函数返回 true.

参数 f 应当是一个函数 (可调用) 对象, 接受一个记号类型的参数并返回 bool, 指示是否应取消记号化. 如果它返回 false, 函数 tokenize 也将返回 false.

参数 initial_state 强制从给定的词法分析器状态开始进行词法分析. 如果省略该参数, 词法分析将从 "INITIAL" 状态开始.

template <typename Iterator, typename Lexer>
inline bool
tokenize(
    Iterator& first
  , Iterator last
  , Lexer const& lex
  , typename Lexer::char_type const* initial_state = 0);

template <typename Iterator, typename Lexer, typename F>
inline bool
tokenize(
    Iterator& first
  , Iterator last
  , Lexer const& lex
  , F f
  , typename Lexer::char_type const* initial_state = 0);

tokenize_and_parse 函数是主要的词法分析器 API 函数之一. 它简化了在解析给定输入序列时使用词法分析器作为底层记号源的过程.

这些函数接受一对跨越待解析底层输入流的迭代器、词法分析器对象 (由记号定义构建) 和解析器对象 (由解析器文法定义构建). 此外它们还可以接受解析步骤的属性.

如果解析成功 (给定输入序列被给定文法成功匹配), 该函数返回 true.

template <typename Iterator, typename Lexer, typename ParserExpr>
inline bool
tokenize_and_parse(
    Iterator& first
  , Iterator last
  , Lexer const& lex
  , ParserExpr const& expr)

template <typename Iterator, typename Lexer, typename ParserExpr
  , typename Attr1, typename Attr2, ..., typename AttrN>
inline bool
tokenize_and_parse(
    Iterator& first
  , Iterator last
  , Lexer const& lex
  , ParserExpr const& expr
  , Attr1 const& attr1, Attr2 const& attr2, ..., AttrN const& attrN);

函数 tokenize_and_phrase_parse 接受一对跨越待解析底层输入流的迭代器、词法分析器对象 (由记号定义构建) 和解析器对象 (由解析器文法定义构建). 额外的跳过器参数将在解析过程中用作跳过解析器. 此外它们还可以接受解析步骤的属性.

如果解析成功 (给定输入序列被给定文法成功匹配), 该函数返回 true.

template <typename Iterator, typename Lexer, typename ParserExpr
  , typename Skipper>
inline bool
tokenize_and_phrase_parse(
    Iterator& first
  , Iterator last
  , Lexer const& lex
  , ParserExpr const& expr
  , Skipper const& skipper
  , BOOST_SCOPED_ENUM(skip_flag) post_skip = skip_flag::postskip);

template <typename Iterator, typename Lexer, typename ParserExpr
  , typename Skipper, typename Attribute>
inline bool
tokenize_and_phrase_parse(
    Iterator& first
  , Iterator last
  , Lexer const& lex
  , ParserExpr const& expr
  , Skipper const& skipper
  , Attribute& attr);

template <typename Iterator, typename Lexer, typename ParserExpr
  , typename Skipper, typename Attribute>
inline bool
tokenize_and_phrase_parse(
    Iterator& first
  , Iterator last
  , Lexer const& lex
  , ParserExpr const& expr
  , Skipper const& skipper
  , BOOST_SCOPED_ENUM(skip_flag) post_skip, Attribute& attr);

支持的最大实参数量受预处理器常量 SPIRIT_ARGUMENTS_LIMIT 限制. 该常量默认为预处理器常量 PHOENIX_LIMIT 定义的值 (后者又默认为 10).

注释

带有两个或更多属性的可变参数函数在内部把对全部传入属性的引用组合成一个 fusion::vector, 并将其作为一个组合属性转发给对应的单属性函数.

tokenize_and_phrase_parse 函数中, 未将显式 skip_flag 作为参数之一的版本会在解析器表达式成功匹配之后调用传入的跳过器. 可以通过使用该函数的其他版本并向相应参数传入 skip_flag::dont_postskip 来禁止这一行为.

模板参数

参数

说明

Iterator

ForwardIterator, 指向待解析的底层输入序列.

Lexer

一个词法分析器 (记号定义) 对象.

F

为每个生成的记号调用的函数对象.

ParserExpr

一个可以转换为 Qi 解析器的表达式.

Skipper

用于跳过空白字符的解析器.

Attr1, Attr2, ..., AttrN

一个或多个属性.
