列表解析器 (a % b)
说明

列表运算符 a % b 是一个二元运算符, 匹配由一次或多次 a 重复组成、以 b 的出现分隔的列表. 这等价于 a >> *(b >> a).

表达式

语义

a % b

匹配由一次或多次 a 重复组成、以 b 的出现分隔的列表. 这等价于 a >> *(omit[b] >> a).
注释

列表运算符 a % b 会省略解析器 b 的属性. 如果你需要 b 对结果属性有所贡献, 请选择 a >> *(b >> a) 而不是列表运算符 a % b.

属性

参见 复合属性记法.

表达式

属性

a % b 

a: A, b: B --> (a % b): vector<A>
a: Unused, b: B --> (a % b): Unused
复杂度

列表的总体复杂度由其主体 a 的复杂度乘以重复次数决定. 列表本身的复杂度为 O(N), 其中 N 是成功重复的次数.
