规则与文法的属性

非终结符在解析器领域广为人知, 它们是利用较简单的解析器构建更复杂解析器的主要手段. 解析器世界中的非终结符非常类似于命令式编程语言中的函数. 它们可以用来为特定输入序列封装解析器表达式. 定义之后, 只要需要识别被封装的输入, 非终结符就可以作为"普通"解析器用于更复杂的表达式. Spirit.Qi 的解析器非终结符可以接受 参数(继承属性), 并且通常返回一个值(合成属性).

在定义特定的 grammar 或 rule 时, 继承属性和合成属性两者的类型都必须显式指定 (Spirit Repository 另外还提供了符合类似接口的 subrules). 例如, 下面的代码声明了一个 Spirit.Qi rule, 它暴露一个 int 作为其合成属性, 同时期待一个 double 作为其继承属性 (更多信息参见关于 Spirit.Qi Rule 的章节):

qi::rule<Iterator, int(double)> r;

在生成器世界里, 非终结符同样有用. 生成器非终结符为特定数据类型封装格式描述, 每当我们需要为该数据类型生成输出时, 就以与预定义 Spirit.Karma 生成器原语类似的方式调用相应的非终结符. Spirit.Karma 非终结符与 Spirit.Qi 非终结符非常相似. 生成器非终结符也可以接受 参数, 我们同样把这些称为继承属性. 主要区别在于它们不暴露合成属性(不像解析器那样), 而是要求一个特殊的 消耗属性. 消耗属性通常就是生成器据以生成输出的值. 即使消耗属性不会从生成器"返回", 我们仍选择使用与 Spirit.Qi 中相同的函数式声明语法. 下面的示例声明了一个 Spirit.Karma rule, 它消耗一个 double, 且不接受任何额外的继承属性.

karma::rule<OutputIterator, double()> r;

非终结符解析器和生成器的继承属性通常在调用该组件时传递给它. 这些是解析器或生成器可以接受的 参数, 可用于根据调用所在的上下文对组件进行参数化.
