惰性生成器(lazy)
说明

lazy 组件家族允许使用动态返回的生成器组件进行输出生成. 它在生成时调用提供的函数或函数对象, 把其返回值用作实际生成输出的生成器.

头文件 
// forwards to <boost/spirit/home/karma/auxiliary/lazy.hpp>
#include <boost/spirit/include/karma_lazy.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::lazy // alias: boost::spirit::karma::lazy

所属模型

Generator

记法约定

fg

求值为生成器对象的函数或函数对象 (一个暴露 Generator 的对象). 该函数将在生成时被调用.

fg 的签名应当为

G f(Unused, Context)

其中 G (函数的返回值)是要调用的生成器的类型, 而 Context 是生成器的 Context 类型 (第一个参数是 unused, 以使 Context 成为第二个参数. 这样做是为了与 语义动作 保持一致).

表达式语义

仅当表达式的语义与 Generator 不同或在其中未定义时, 才给出其语义.

表达式

语义

fg

Boost.Phoenix 函数对象 fg 将在生成时被调用. 它应当返回一个生成器实例. 随后调用该生成器以生成输出. 只要被调用的生成器也成功, 该生成器就会成功 (除非底层输出流报告错误).

lazy(fg)

该函数或函数对象将在生成时被调用. 它应当返回一个生成器实例 (注意这一版本的 lazy 不要求 fg 是 Boost.Phoenix 函数对象). 随后调用该生成器以生成输出. 只要被调用的生成器也成功, 该生成器就会成功 (除非底层输出流报告错误).
属性

表达式

属性

fg

属性类型 G, 由生成器 g 暴露, 该生成器从 fg 返回.

lazy(fg)

属性类型 G, 由生成器 g 暴露, 该生成器从 fg 返回.
复杂度

lazy 组件的复杂度由 fg 返回的生成器的复杂度决定.

#include <boost/spirit/include/karma.hpp>
#include <boost/spirit/include/support_utree.hpp>

namespace karma = boost::spirit::karma;

lazy 生成器的基本用法:

test_generator_attr("abc", karma::lazy(val(string)), "abc");
test_generator("abc", karma::lazy(val(string))[_1 = "abc"]);
