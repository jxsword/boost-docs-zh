基于流的解析器 API
说明

该库提供了几个标准 IO 操纵器 (Manipulator), 使 Spirit.Qi 的输入解析设施能够与标准输入流集成. 这些解析器操纵器有两种形式. 第一种形式 match 工作在字符层级. 第二种 phrase_match 工作在短语层级, 需要一个跳过解析器. 两个版本都可以通过引用传入属性, 解析成功时这些属性将保存解析得到的值.

头文件 
// forwards to <boost/spirit/home/qi/stream/match_manip.hpp>
#include <boost/spirit/include/qi_match.hpp>

对于可变参数属性:

// forwards to <boost/spirit/home/qi/stream/match_manip_attr.hpp>
#include <boost/spirit/include/qi_match_attr.hpp>

API 的可变属性版本允许向解析操纵器传入一个或多个属性. 接受两个或更多属性的操纵器仅在解析器表达式为 序列 时可用. 此时, 传入的每个属性都必须与序列的相应部分匹配.

对于从给定属性类型推导正确 (匹配) 解析器类型的 API 函数:

// forwards to <boost/spirit/home/qi/match_auto.hpp>
#include <boost/spirit/include/qi_match_auto.hpp>

另请参见 包含结构.

命名空间

名称

boost::spirit::qi::match

boost::spirit::qi::phrase_match

boost::spirit::qi::skip_flag::postskip

boost::spirit::qi::skip_flag::dont_postskip

概要 
namespace boost { namespace spirit { namespace qi
{
    template <typename Expr>
    inline <unspecified>
    match(
        Expr const& xpr);

    template <typename Expr
      , typename Attr1, typename Attr2, ..., typename AttrN>
    inline <unspecified>
    match(
        Expr const& xpr
      , Attr1& attr1, Attr2& attr2, ..., AttrN& attrN);

    template <typename Expr, typename Skipper>
    inline <unspecified>
    phrase_match(
        Expr const& expr
      , Skipper const& s
      , BOOST_SCOPED_ENUM(skip_flag) post_skip = skip_flag::postskip);

    template <typename Expr, typename Skipper
      , typename Attr1, typename Attr2, ..., typename AttrN>
    inline <unspecified>
    phrase_match(
        Expr const& expr
      , Skipper const& s
      , Attr1& attr1, Attr2& attr2, ..., AttrN& attrN);

    template <typename Expr, typename Skipper
      , typename Attr1, typename Attr2, ..., typename AttrN>
    inline <unspecified>
    phrase_match(
        Expr const& expr
      , Skipper const& s
      , BOOST_SCOPED_ENUM(skip_flag) post_skip
      , Attr1& attr1, Attr2& attr2, ..., AttrN& attrN);
}}}

基于自动创建匹配解析器类型的 Spirit.Qi 解析器 API 函数:

namespace boost { namespace spirit { namespace qi
{
    template <typename Attr>
    inline <unspecified>
    match(
        Attr& attr);

    template <typename Attr, typename Skipper>
    inline <unspecified>
    phrase_match(
        Attr& attr
      , Skipper const& s
      , BOOST_SCOPED_ENUM(skip_flag) post_skip = skip_flag::postskip);
}}}

上述所有函数都返回一个标准 IO 流操纵器实例 (参见 操纵器), 从输入流流入该操纵器时, 将使用内嵌的 Spirit.Qi 解析器表达式解析输入. 在调用 Spirit.Qi 解析器期间发生的任何错误 (或解析失败) 都会反映在流的状态标志中 (std::ios_base::failbit 将被设置).

支持的最大实参数量受预处理器常量 SPIRIT_ARGUMENTS_LIMIT 限制. 该常量默认为预处理器常量 PHOENIX_LIMIT 定义的值 (后者又默认为 10).

注释

带有两个或更多属性的可变参数操纵器在内部把对全部传入属性的引用组合成一个 fusion::vector, 并将其作为一个组合属性转发给对应的接受单属性的操纵器.

phrase_match 操纵器中未把显式 skip_flag 作为参数之一的版本, 会在解析器表达式成功匹配之后调用传入的跳过器. 可以通过使用该操纵器的其他版本并向相应参数传入 skip_flag::dont_postskip 来禁止这一行为.

模板参数

参数

说明

Expr

一个可以转换为 Qi 解析器的表达式.

Skipper

用于跳过空白字符的解析器.

Attr

用于创建相应解析器类型的属性类型.

Attr1, Attr2, ..., AttrN

一个或多个属性.
