复合组件的属性

Spirit.Qi 和 Spirit.Karma 为所有复合解析器和生成器(例如序列, 备选, Kleene star 等)实现了一组定义完善的属性类型传播规则. 例如, 序列的主要属性传播规则是:

库

序列属性传播规则

Qi

a: A, b: B --> (a >> b): tuple<A, B>

Karma

a: A, b: B --> (a << b): tuple<A, B>

其含义为:

设 a 与 b 为解析器(生成器), 且 A 为 a 的属性类型, B 为 b 的属性类型, 则 a >> b(a << b) 的属性类型将为 tuple<A, B>.

注释

记法 tuple<A, B> 用作持有类型 A 和 B 的任意 fusion 序列的占位表达式, 例如 boost::fusion::tuple<A, B> 或 std::pair<A, B> (更多信息参见 Boost.Fusion).

如上所见, 要使一个类型与复合表达式的属性类型兼容, 它必须

  • 要么可转换为该属性类型,
  • 要么暴露某些功能, 即它需要符合与该组件兼容的概念.

每个复合组件都实现自己的一组属性传播规则. 有关不同复合生成器如何使用属性的完整列表, 参见 解析器复合属性规则 和 生成器复合属性规则 章节.

序列解析器与生成器的属性

序列要求属性类型暴露 fusion 序列概念, 且该 fusion 序列的所有元素都必须与组件序列的对应元素兼容. 例如, 表达式:

库

序列表达式

Qi

double_ >> double_

Karma

double_ << double_

与任何持有两个类型的 fusion 序列兼容, 且这两个类型都必须与 double 兼容. fusion 序列的第一个元素必须与第一个 double_ 的属性兼容, 而 fusion 序列的第二个元素必须与第二个 double_ 的属性兼容. 假设我们拥有一个 std::pair<double, double> 的实例, 就可以直接用上面的表达式完成两件事: 解析输入以填充属性:

// the following parses "1.0 2.0" into a pair of double
std::string input("1.0 2.0");
std::string::iterator strbegin = input.begin();
std::pair<double, double> p;
qi::phrase_parse(strbegin, input.end(),
    qi::double_ >> qi::double_,       // parser grammar 
    qi::space,                        // delimiter grammar
    p);                               // attribute to fill while parsing

以及为其生成输出:

// the following generates: "1.0 2.0" from the pair filled above
std::string str;
std::back_insert_iterator<std::string> out(str);
karma::generate_delimited(out,
    karma::double_ << karma::double_, // generator grammar (format description)
    karma::space,                     // delimiter grammar
    p);                               // data to use as the attribute

(其中 karma::space 生成器用作分隔符, 使得可以在所有原语之间自动跳过/插入分隔空格).

提示

仅适用于序列: Spirit.Qi 和 Spirit.Karma 暴露了一组主要与序列配合使用的 API 函数. 与 scanf 和 printf 函数族非常相似, 这些函数允许为序列的各个元素分别传递属性. 使用 Qi 的 parse 或 Karma 的 generate() 的相应重载, 上面的表达式可以改写为:

double d1 = 0.0, d2 = 0.0;
qi::phrase_parse(begin, end, qi::double_ >> qi::double_, qi::space, d1, d2);
karma::generate_delimited(out, karma::double_ << karma::double_, karma::space, d1, d2);

其中第一个属性用于第一个 double_, 第二个属性用于第二个 double_.

备选解析器与生成器的属性

备选解析器和生成器的全部意义就在于备选. 为了存储来自不同备选的可能不同的结果(属性)类型, 我们使用数据类型 Boost.Variant. 这些组件的主要属性传播规则是:

a: A, b: B --> (a | b): variant<A, B>

备选还有第二条非常重要的属性传播规则:

a: A, b: A --> (a | b): A

这通常能显著简化问题. 如果一个备选的所有子表达式都暴露相同的属性类型, 那么整个备选也将暴露完全相同的属性类型.
