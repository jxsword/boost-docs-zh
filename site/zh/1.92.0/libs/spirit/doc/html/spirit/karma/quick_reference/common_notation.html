通用记法

记法约定

G

生成器类型

g, a, b, c, d

生成器对象

A, B, C, D

生成器 a, b, c 和 d 的属性类型

I

用于生成的迭代器类型

Unused

一个 unused_type

Context

外围 rule 的 Context 类型

attrib

一个属性值

Attrib

一个属性类型

b

一个布尔表达式

B

要在布尔表达式中解释的类型

fg

具有签名为 G(Unused, Context) 的(惰性生成器)函数

fa

具有签名为 void(Attrib&, Context, bool&) 的(语义动作)函数. 第三个参数是一个布尔标志, 可以设为 false 以强制生成器失败. Context 和布尔标志都是可选的.

outiter

接收生成输出的输出迭代器

Ch

字符类特定的字符类型(参见字符类类型)

ch, ch2

字符类特定的字符(参见字符类类型)

charset

字符集说明字符串(例如: "a-z0-9")

str

字符类特定的字符串(参见字符类类型)

Str

str 的属性: std::basic_string<T>, 其中 T 是 str 的底层字符类型

num

数值字面量, 任意整数或实数类型

Num

num 的属性: 任意整数或实数类型

tuple<>

用作 fusion 序列的占位符

vector<>

用作 STL 容器的占位符

variant<>

用作 boost::variant 的占位符

optional<>

用作 boost::optional 的占位符
