提取属性值以生成输出(Karma)

extract_from

在为某个值生成输出之前, 需要从用户提供的属性实例中提取该值. 定制点 extract_from_attribute 用于针对可能用于存储待输出值的任何数据类型适配这一提取.

注释

此定制点的接口在 Boost V1.44 中发生了变化. 我们添加了 Exposed 模板参数, 以便对所需的 Spirit.Karma 属性变换进行更细粒度的特化.

模块头文件 
#include <boost/spirit/home/karma/detail/extract_from.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename Exposed, typename Attrib, typename Enable>
struct extract_from_attribute
{
    typedef <unspecified> type;

    template <typename Context>
    static type call(Attrib const& attr, Context& context);
};
模板参数

参数

说明

默认值

Exposed

类型 Exposed, 即调用 extract_from_attribute 的组件原生暴露的属性的类型.

none

Attrib

用于生成输出的属性的类型 Attrib.

none

Enable

辅助模板参数, 可利用 SFINAE 有选择地启用或禁用 clear_value 的某些特化(即 boost::enable_if 或 boost::disable_if).

void

Context

这是当前生成器执行上下文的类型.

记法约定

Exposed

作为组件原生属性暴露的类型.

Attrib

用于生成输出的类型.

attr

Attrib 类型的属性实例.

ctx

Context 类型的实例.

表达式语义

表达式

语义

 

extract_from_attribute<Exposed, Attrib>::call(attr, ctx)

从 attr 中提取用于生成输出的值, 并将其返回给调用者.
预定义特化

Spirit 为若干类型预定义了此定制点的特化. 下表列出了这些类型及其暴露的类型和相应的语义:

模板参数

语义

Attrib

暴露的 typedef type 被定义为 Attrib const&. 函数 call() 原样按引用返回实参.

boost::optional<Attrib>

暴露的 typedef type 被定义为 Attrib const&. 函数 call() 原样按引用返回 optional<> 实参所持有的值.

boost::reference_wrapper<Attrib>

暴露的 typedef type 被定义为 Attrib const&. 函数 call() 原样按引用返回 reference_wrapper<> 实参所持有的值.

unused_type

暴露的 typedef type 被定义为 unused_type. 函数 call() 返回一个 unused_type 实例.
何时实现

每当上面所示的默认实现不适用时, 就需要为特定类型实现定制点 extract_from_attribute. 例如, 要提取的类型可能不同于 Attrib 且不可复制构造.
