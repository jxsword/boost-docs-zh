复数 - 我们的第一个复杂解析器

嗯, 这其实不是一个复杂的解析器, 而是一个解析复数的解析器. 这一次, 我们使用 Boost.Phoenix 来完成语义动作.

下面是一个用于复数的简单解析器表达式:

    '(' >> double_ >> -(',' >> double_) >> ')'
|   double_

有什么新东西? 嗯, 我们有:

  1. 备选: 例如 a | b. 先尝试 a. 如果成功, 很好; 如果不成功, 尝试下一个备选项 b.
  2. 可选: 例如 -p. 把解析器 p 匹配零次或一次.

上面给出的复数解析器读作:

  • 括号内的一个或两个实数, 以逗号分隔 (第二个数字可选)
  • 或 单个实数.

此解析器可以解析如下形式的复数:

(123.45, 987.65)
(123.45)
123.45

下面就来实现, 这次带上动作:

namespace client
{
    template <typename Iterator>
    bool parse_complex(Iterator first, Iterator last, std::complex<double>& c)
    {
        using boost::spirit::qi::double_;
        using boost::spirit::qi::_1;
        using boost::spirit::qi::phrase_parse;
        using boost::spirit::ascii::space;
        using boost::phoenix::ref;

        double rN = 0.0;
        double iN = 0.0;
        bool r = phrase_parse(first, last,

            //  Begin grammar
            (
                    '(' >> double_[ref(rN) = _1]
                        >> -(',' >> double_[ref(iN) = _1]) >> ')'
                |   double_[ref(rN) = _1]
            ),
            //  End grammar

            space);

        if (!r || first != last) // fail if we did not get a full match
            return false;
        c = std::complex<double>(rN, iN);
        return r;
    }
}

此示例的完整 cpp 文件可在此处找到: ../../example/qi/complex_number.cpp

注释

有 Boost.Phoenix 使用经验的人可能会对我们使用的占位符 (即 _1、_2 等) 感到困惑. 请注意, 我们使用的不是 Phoenix 提供的那套占位符. 注意我们是从命名空间 boost::spirit::qi 引入的占位符. 这些占位符是专门为 Spirit 定制的.

double_ 解析器附加了这个动作:

ref(n) = _1

这把解析结果 (实际上是 double_ 的属性) 赋给 n. ref(n) 告诉 Phoenix n 是一个可变引用. _1 是 Phoenix 中表示解析结果属性的占位符.
