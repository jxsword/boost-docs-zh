生成器运算符

Sequence 生成器(a << b)
Alternative 生成器(a | b)
Kleene star 生成器(*a)
Plus 生成器(+a)
List 生成器(a % b)
Optional 生成器(-a)
与谓词生成器(&a)
非谓词生成器(!a)

运算符用作对象组合和嵌入的手段. 简单生成器可以通过运算符重载组合成复合生成器, 精心设计以近似 解析表达式文法 (PEG) 的语法. 如下表达式:

a | b

产生一个新的生成器类型, 它是其操作数 a 和 b 的复合.

本模块包含各种生成器, 当重载运算符之一与更原始的生成器构造一起使用时, 它们会被实例化. 它包括序列 (a << b), 备选 (a | b), Kleene star (一元 *), plus (一元 +), optional (一元 -), 列表 (a % b), 以及两个谓词: 与 谓词 (一元 &) 和 非 谓词 (一元 !).
