Nonterminal
说明

Nonterminal 是 解析表达式文法 产生式中的一个符号, 表示一个文法片段. 非终结符可以自引用以指定递归. 这是最重要的概念之一, 也是递归下降生成中"递归"一词的由来.

细化自

Generator

签名

非终结符可以同时具有消耗属性和继承属性. Nonterminal 的 Signature 同时规定消耗属性和继承属性. 该规定使用函数声明符语法:

RT(A0, A1, A2, ..., AN)

其中 RT 是 Nonterminal 的消耗属性, 而 A0 ... AN 是 Nonterminal 的继承属性.

默认值是 void() (无消耗属性和继承属性).

属性

Nonterminal 建模一个 C++ 函数. Nonterminal 的消耗属性类似于函数返回值, 因为它是 Nonterminal 暴露的类型. 其继承属性类似于函数实参. 继承属性 (实参) 可以像任何 惰性实参 一样传入, 例如:

r(expr) // Evaluate expr at parse time and pass the result to the Nonterminal r
_val

boost::spirit::karma::_val 占位符可以在 Nonterminal 定义中的任何位置的 Boost.Phoenix 语义动作中使用. 该 Boost.Phoenix 占位符引用 Nonterminal 的 (消耗)属性. _val 占位符的行为如同对 Nonterminal 属性的不可变引用.

注释

从 Spirit V2.5 (随 Boost V1.47 发布)开始, 占位符 _val 也可以在附加到顶层生成器组件的语义动作中使用. 更多信息参见 生成器 API.

_r1...r10

boost::spirit::_r1...boost::spirit::r10 占位符可以在 Nonterminal 定义中的任何位置的 Boost.Phoenix 语义动作中使用. 这些 Boost.Phoenix 占位符引用 Nonterminal 的继承属性.

局部变量

非终结符可以有局部变量, 这些变量将在运行时在栈上创建. 添加到 Nonterminal 声明中的 locals 描述符将赋予该 Nonterminal 局部变量:

template <typename T0, typename T1, typename T2, ..., typename TN>
struct locals;

其中 T0 ... TN 是局部变量的类型, 可以在你的 Boost.Phoenix 语义动作中使用以下占位符访问:

  • boost::spirit::_a
  • boost::spirit::_b
  • boost::spirit::_c
  • boost::spirit::_d
  • boost::spirit::_e
  • boost::spirit::_f
  • boost::spirit::_g
  • boost::spirit::_h
  • boost::spirit::_i
  • boost::spirit::_j

它们对应于 Nonterminal 的局部变量 T0 ... T9.
