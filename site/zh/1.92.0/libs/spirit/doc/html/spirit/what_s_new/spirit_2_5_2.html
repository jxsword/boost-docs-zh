Spirit V2.5.2

从 V2.5.1 (Boost V1.48.0) 到 V2.5.2 (Boost V1.49.0) 的变化
  • 集成了 Vitaly Budovski 的补丁, 添加了二进制浮点解析器和生成器.
  • 修复了 TRAC#6253: 当词法分析器以 wchar_t 作为底层流类型时 lex::lexertl::generate_static_dfa 的编译错误.
  • 添加了在使用词法分析器解析时通过 qi::token(min, max) 或 qi::tokenid(min, max) 匹配记号范围的能力. 两个解析器都匹配记号 id 位于 [min, max] 范围内的任意记号.
  • 修复了 center(num)[a] 和 center(num, g)[a] 在复合生成器 (例如序列、Kleene、list 或 plus) 内部使用时的一个问题.
  • 修复了 karma::subrule (来自 仓库) (感谢 Lee Clagett 提交补丁).
  • 修复了 Spirit.Karma 示例 (感谢 Lee Clagett 提交补丁).
  • 修复了 TRAC#6368: [multi_pass] clear_queue 未转发到存储策略.
  • 修复了 Spirit.Karma 中当一个持有容器的 variant 在序列内用作生成器时的问题.
