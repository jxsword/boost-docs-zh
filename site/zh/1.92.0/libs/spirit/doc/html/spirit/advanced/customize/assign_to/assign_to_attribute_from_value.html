解析器生成值后存储属性值(Qi)
assign_to_attribute_from_value

模板 assign_to_attribute_from_value 是用作属性定制点的类型. 所有原语 Qi 解析器都会调用它, 以便在用户提供的属性不是容器类型时(is_container<T>::type 求值为 mpl::false_, 其中 T 为属性类型), 把解析得到的属性值存储到用户提供的属性实例中.

模块头文件 
#include <boost/spirit/home/qi/detail/assign_to.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename Attrib, typename T, typename Enable>
struct assign_to_attribute_from_value
{
    static void call(T const& val, Attrib& attr);
};
模板参数

参数

说明

默认值

Attrib

类型 Attrib 是用户传入的属性类型. 该类型不是容器类型(is_container<Attrib>::type 求值为 mpl::false_).

none

T

类型 T 是解析器生成的属性实例的类型.

none

Enable

辅助模板参数, 可利用 SFINAE 有选择地启用或禁用 assign_to_attribute_from_value 的某些特化(即 boost::enable_if 或 boost::disable_if).

void

记法约定

Attrib

用作存储属性值目标的类型. 保证该类型不是容器类型(is_container<Attrib>::type 求值为 mpl::false_).

attr

Attrib 类型的属性实例.

T

解析器生成的类型. 解析器使用该类型临时存储其解析得到的值.

t

T 类型的属性实例.

表达式语义

表达式

语义

 

assign_to_attribute_from_value<Attrib, T>::call(t, attr)

把值 t 复制(赋值)到属性 attr.
预定义特化

模板参数

语义

Attrib, T

把实参 t 赋给 attr.

unused_type, T

不执行任何操作.
何时实现

每当上面所示的默认实现不适用时, 就需要为特定类型实现定制点 assign_to_attribute_from_value. 例如, 类型 Attrib 可能不可复制构造.
