生成器指令

对齐生成器指令(left_align[], center[], right_align[])
重复生成器指令(repeat[])
控制自动分隔的生成器指令(verbatim[], no_delimit[], delimit[])
控制大小写敏感的生成器指令(upper[], lower[])
控制最大字段宽度的生成器指令(maxwidth[])
临时缓冲输出的生成器指令(buffer[])
消耗属性的生成器指令(omit[] 和 skip[])
复制属性的生成器指令(duplicate[])
把输出分列的生成器指令(columns[])
强制原子提取的生成器指令(as<T>, as_string[], as_wstring[])

本模块包含各种生成器指令. 它包括对齐指令 (left_align[], center[] 和 right_align[]), 重复 (repeat[]), 控制自动分隔的指令 (verbatim[], no_delimit[] 和 delimit[]), 控制大小写敏感 (upper[] 和 lower[]), 字段宽度 (maxwidth[]), 缓冲 (buffer[]), 分列 (columns[]) 以及属性处理 (duplicate[], omit[] 和 skip[]).

模块头文件 
// forwards to <boost/spirit/home/karma/directive.hpp>
#include <boost/spirit/include/karma_directive.hpp>
