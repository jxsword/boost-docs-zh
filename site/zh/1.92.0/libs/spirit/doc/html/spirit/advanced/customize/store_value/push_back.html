将解析得到的属性值存入容器(Qi)
push_back_container

模板 push_back_container 是用作属性定制点的类型. Qi 的重复解析器(Kleene, Plus, List 和 Repeat)会调用它, 以便把解析得到的属性值存入容器.

模块头文件 
#include <boost/spirit/home/support/container.hpp>

另请参见 包含结构.

注释

用户程序不需要直接包含此头文件, 因为它通常由依赖其内容的其它 Spirit 头文件包含.

命名空间

名称

boost::spirit::traits

概要 
template <typename Container, typename Attrib, typename Enable>
struct push_back_container
{
    static bool call(Container& c, Attrib const& val);
};
模板参数

参数

说明

默认值

Container

类型 Container, 需要测试它是否必须被视为容器

none

Attrib

类型 Attrib 是从定制点 traits::container_value 返回的类型, 表示要存入类型为 Container 的容器中的属性值.

none

Enable

辅助模板参数, 可利用 SFINAE 有选择地启用或禁用 push_back_container 的某些特化(即 boost::enable_if 或 boost::disable_if).

void

记法约定

C

用作存储属性值的容器的类型.

c

类型为 C 的容器实例.

[Attrib

用作存储属性值的容器的类型.

attr

Attrib 类型的属性实例.

T1, T2, ...

任意类型

表达式语义

表达式

语义

 

push_back_container<C, Attrib>::call(c, attr)

静态函数, 每当需要把属性值 attr 存入容器实例 c 时就会被调用. 该函数成功时应返回 true, 否则返回 false. 返回 false 会导致相应的解析器失败.
预定义特化

Spirit 为若干类型预定义了此定制点的特化. 下表列出了这些类型及其暴露的类型和相应的语义:

模板参数

语义

C, Attrib

把提供的属性实例 attr 存入给定容器 c, 使用的函数调用为 c.insert(c.end(), attr).

boost::optional<C>, Attrib

如果提供的 boost::optional<> 实例未初始化, 则调用适当的初始化, 然后应用定制点 push_back_container<C, Attrib>, 把 optional(类型为 C)持有的实例当作存储属性的容器.

boost::variant<T1, T2, ...>, Attrib

如果 variant 实例当前持有的值的类型 TN 满足 is_container<TN>::type 求值为 mpl::true_, 此定制点特化将应用 push_back_container<TN, Attrib>, 把 variant(类型为 TN)持有的实例当作存储属性的容器. 否则将引发断言.

unused_type

不执行任何操作.
何时实现

每当某个类型要用作替代 STL 容器的属性时, 就需要为该类型实现定制点 push_back_container. 它仅适用于解析器(Spirit.Qi). 根据经验: 每当某个类型要作为属性传递给通常暴露 STL 容器的解析器, 且该类型不暴露 STL 容器的接口(即没有等价于 c.insert(c.end(), attr) 的函数)时, 就必须实现它. 这些组件具有如下形式的属性传播规则:

a: A --> Op(a): vector<A>

其中 Op(a) 表示对组件 a 的任何有意义的操作.

相关的属性定制点

如果实现了此定制点, 以下其他定制点可能也需要实现.

名称

何时实现

traits::container_value

Qi: List, Kleene, Plus, Repeat.

traits::clear_value

Qi: List, Kleene, Plus, Repeat.

示例

下面的示例展示了库所提供的 traits::container_value 定制点的默认实现:

template <typename Container, typename T, typename Enable/* = void*/>
struct push_back_container
{
    static bool call(Container& c, T const& val)
    {
        c.insert(c.end(), val);
        return true;
    }
};

库会在适当的位置实例化此模板, 并把所提供的容器和元素类型用作模板实参. 每当需要向所提供的容器添加元素时, 成员函数 call() 就会被调用

下面的示例展示了 unused_type 的预定义特化:

template <typename Container>
bool push_back(Container&, unused_type)
{
    return true;
}

它定义了一个空的成员函数 call().
