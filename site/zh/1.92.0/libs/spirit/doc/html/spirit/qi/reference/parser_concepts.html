Spirit.Qi 解析器可归入几个泛化的 概念. Parser 是最基本的概念. 所有 Spirit.Qi 解析器都是 Parser 概念的模型. PrimitiveParser、UnaryParser、BinaryParser、NaryParser 和 Nonterminal 都是 Parser 概念的细化.
