无符号整数生成器

表达式

属性

说明

lit(num)

Unused

生成 num

ushort_

unsigned short

生成一个无符号短整数

ushort_(num)

unsigned short

以无符号短整数形式生成 num, 如果提供了属性则必须匹配

uint_

unsigned int

生成一个无符号 int

uint_(num)

unsigned int

以无符号 int 形式生成 num, 如果提供了属性则必须匹配

ulong_

unsigned long

生成一个无符号长整数

ulong_(num)

unsigned long

以无符号长整数形式生成 num, 如果提供了属性则必须匹配

ulong_long

unsigned long long

生成一个无符号 long long

ulong_long(num)

unsigned long long

以无符号 long long 形式生成 num, 如果提供了属性则必须匹配

bin

unsigned int

从 unsigned int 生成二进制整数

oct

unsigned int

从 unsigned int 生成八进制整数

hex

unsigned int

从 unsigned int 生成十六进制整数
