解析器基础

惰性实参

某些解析器 (例如基础组件和非终结符) 可以接受附加属性. 这类解析器的形式为:

p(a1, a2,..., aN)

其中 p 是一个解析器. 每个参数 (a1 ... aN) 既可以是立即值, 也可以是一个具有如下签名的函数 f:

T f(Unused, Context)

其中 T (即函数的返回值) 与期望的参数类型兼容, 而 Context 是解析器的 Context 类型 (第一个参数是 unused, 以使 Context 成为第二个参数. 这是为了与语义动作保持一致).

字符编码命名空间

某些解析器需要知道 char 或 wchar_t 操作的是哪个字符集. 例如, alnum 解析器在 ISO8859.1 与 ASCII 编码下的工作方式不同. 必要时, Spirit 会用字符集对解析器进行编码 (打标签).

Spirit 将支持的每个字符集都有一个对应的命名空间. 包括 ascii、iso8859_1、standard 和 standard_wide (将来还有 unicode). 在每个字符编码命名空间中, 我们放置带标签版本的解析器, 例如 alnum、space 等.

示例:

using boost::spirit::ascii::space; // use the ASCII space parser

命名空间:

  • boost::spirit::ascii
  • boost::spirit::iso8859_1
  • boost::spirit::standard
  • boost::spirit::standard_wide

为了便于使用, 这些命名空间中的组件也被以相同名称引入 qi 子命名空间:

  • boost::spirit::qi::ascii
  • boost::spirit::qi::iso8859_1
  • boost::spirit::qi::standard
  • boost::spirit::qi::standard_wide

我们的测试函数:

这些函数测试不带属性的解析器.

template <typename P>
void test_parser(
    char const* input, P const& p, bool full_match = true)
{
    using boost::spirit::qi::parse;

    char const* f(input);
    char const* l(f + strlen(f));
    if (parse(f, l, p) && (!full_match || (f == l)))
        std::cout << "ok" << std::endl;
    else
        std::cout << "fail" << std::endl;
}

template <typename P>
void test_phrase_parser(
    char const* input, P const& p, bool full_match = true)
{
    using boost::spirit::qi::phrase_parse;
    using boost::spirit::qi::ascii::space;

    char const* f(input);
    char const* l(f + strlen(f));
    if (phrase_parse(f, l, p, space) && (!full_match || (f == l)))
        std::cout << "ok" << std::endl;
    else
        std::cout << "fail" << std::endl;
}

print_info 实用函数打印 info 类中包含的信息.

struct printer
{
    typedef boost::spirit::utf8_string string;

    void element(string const& tag, string const& value, int depth) const
    {
        for (int i = 0; i < (depth*4); ++i) // indent to depth
            std::cout << ' ';

        std::cout << "tag: " << tag;
        if (value != "")
            std::cout << ", value: " << value;
        std::cout << std::endl;
    }
};

void print_info(boost::spirit::info const& what)
{
    using boost::spirit::basic_info_walker;

    printer pr;
    basic_info_walker<printer> walker(pr, what.tag, 0);
    boost::apply_visitor(walker, what.value);
}

语义

boost::spirit::traits::is_string<S>

元函数: 求值为 mpl::true_, 条件是某类型 S 为字符串; 否则求值为 mpl::false_ (参见 MPL Boolean Constant).

boost::spirit::traits::char_type_of<S>

返回字符串类型 S 的底层 char 类型的元函数.

boost::spirit::traits::get_c_string(s)

从 s 返回底层原始 C 字符串的函数.

boost::spirit::traits::get_begin(s)

返回一个 STL 迭代器的函数, 该迭代器从 s 获取并指向字符串开头.

boost::spirit::traits::get_end(s)

返回一个 STL 迭代器的函数, 该迭代器从 s 获取并指向字符串结尾.
模型

预定义模型包括:

  • 任意字面量字符串, 例如 "Hello, World",
  • 指向以 null 结尾的字符数组的指针/引用
  • 一个 std::basic_string<Char>

命名空间 boost::spirit::traits 对用户开放, 用户可以在其中提供自己的特化. Spirit.Qi 实现的、可用于定制解析器行为的定制点在 属性处理的定制 一节中描述.
