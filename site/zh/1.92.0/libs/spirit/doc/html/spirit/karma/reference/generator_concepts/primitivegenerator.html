PrimitiveGenerator
说明

PrimitiveGenerator 是客户端用来构建更复杂生成器的最基本构建块.

细化自

Generator

后置分隔

在退出 generate 成员函数之前, PrimitiveGenerator 需要执行一次后置分隔. 这会生成单个分隔字符/记号序列. 只有 PrimitiveGenerator 需要执行此后置分隔. 这通常通过调用 karma::delimit_out 来完成:

karma::delimit_out(sink, delimit);
类型表达式

表达式

说明

traits::is_primitive_generator<G>::type

元函数, 求值为 mpl::true_ (当某个类型 G 是 PrimitiveGenerator 时), 否则为 mpl::false_ (参见 MPL Boolean Constant).
模型

以下生成器符合此模型:

  • eol,
  • eps,
  • 数值生成器,
  • 字符生成器.
