Spirit Classic

Spirit V1.8.x 代码库已与 Spirit V2 集成. 现在称为 Spirit.Classic. 由于目录结构发生了变化 (Spirit Classic 头文件已移至 $BOOST_ROOT/boost/spirit/home/classic 目录), 我们创建了转发头文件, 让现有应用无需任何改动即可编译. 不过, 这些转发头文件已被弃用, 从 Boost V1.38 开始会为其中每个头文件生成相应警告. 这些转发头文件预计将来会被移除.

现在使用 Spirit Classic 的推荐方式是从 $BOOST_ROOT/boost/spirit/include 目录包含头文件. 此目录中的所有 Spirit Classic 头文件名称都带有 'classic_' 前缀. 例如, 包含

#include <boost/spirit/core/core.hpp>

现在应写作:

#include <boost/spirit/include/classic_core.hpp>

为避免与新的 Spirit V2 库发生命名空间冲突, 我们把 Spirit Classic 移入了命名空间 boost::spirit::classic. 一旦按照上文所述修正头文件名称, 对原命名空间 boost::spirit 的所有引用都需要调整. 作为替代, 你可以定义预处理器常量 BOOST_SPIRIT_USE_OLD_NAMESPACE, 它将强制 Spirit Classic 代码像以前一样位于命名空间 boost::spirit 中. 不过不建议这样做, 因为可能导致命名冲突.

只要使用了已弃用的 include 文件, 命名空间的更改就会自动停用. 这确保现有应用的完全向后兼容.
