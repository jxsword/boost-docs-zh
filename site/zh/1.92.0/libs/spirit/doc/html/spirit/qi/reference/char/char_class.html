字符分类解析器 (alnum、digit 等)
说明

该库拥有用于字符分类的完整的单字符解析器系列. 包括常见的 alnum、alpha、digit、xdigit 等解析器. 这些解析器有一个关联的 字符编码命名空间. 在执行禁止区分大小写等基本操作时需要用到它.

头文件 
// forwards to <boost/spirit/home/qi/char/char_class.hpp>
#include <boost/spirit/include/qi_char_class.hpp>

另请参见 包含结构.

命名空间

名称

ns::alnum

ns::alpha

ns::blank

ns::cntrl

ns::digit

ns::graph

ns::lower

ns::print

ns::punct

ns::space

ns::upper

在上表中, ns 表示一个 字符编码命名空间.

所属模型

PrimitiveParser

记法约定

ns

一个 字符编码命名空间.

表达式语义

仅当表达式的语义与 PrimitiveParser 不同或在其中未定义时, 才给出其语义.

表达式

语义

ns::alnum

匹配字母数字字符

ns::alpha

匹配字母字符

ns::blank

匹配空格或制表符

ns::cntrl

匹配控制字符

ns::digit

匹配数字

ns::graph

匹配非空格的可打印字符

ns::lower

匹配小写字母

ns::print

匹配可打印字符

ns::punct

匹配标点符号

ns::space

匹配空格、制表符、回车和换行

ns::upper

匹配大写字母

ns::xdigit

匹配十六进制数字
属性

字符编码命名空间 的字符类型 ns.

复杂度

O(N)

示例
注释

下面示例的测试框架在 基础示例 一节中给出.

一些 using 声明:

using boost::spirit::ascii::alnum;
using boost::spirit::ascii::blank;
using boost::spirit::ascii::digit;
using boost::spirit::ascii::lower;

基本用法:

test_parser("1", alnum);
test_parser(" ", blank);
test_parser("1", digit);
test_parser("a", lower);
