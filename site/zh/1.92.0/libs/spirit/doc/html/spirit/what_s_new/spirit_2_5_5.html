Spirit V2.5.5

从 V2.5.4 (Boost V1.66.0) 到 V2.5.5 (Boost V1.67.0) 的变化

Boost V1.61.0-1.66.0 发布没有版本号提升和变更日志.

Qi 或 Karma 中的缺陷修复
  • 修复了关键字指令在 C++11 上的编译. GH#256 TRAC#11493
  • 修复了子 rule 的编译. GH#279 GH#259
  • 修复了子 rule 作用域外使用缺陷. GH#284 TRAC#5270
  • 修复了顺序或运算符中的未定义行为. 底层解析器的执行顺序此前依赖于编译器. GH#310
  • Spirit 意外地依赖了 types typedef (属于 boost::optional). 新的 optional 实现中该 typedef 已被移除. GH#271 TRAC#12349
  • 修复了 BOOST_SPIRIT_NO_PREDEFINED_TERMINALS (attr_cast、confix、distinct、keywords 和 flush_multi_pass) 的问题. GH#314 TRAC#13311
  • 为 hold_any 添加了缺失的拷贝赋值运算符. GH#361 TRAC#8268
Qi 中的缺陷修复
  • 修复了备选运算符. GH#201 GH#271 TRAC#12349
  • 修复了实数解析器中的有符号整数溢出. GH#245
  • 修复了 uint_parser<signed T> 中的溢出问题. GH#297
  • 修复了 get_current_line、get_line_start, 并添加了 get_line_end. GH#304
  • 排列解析器此前总是初始化 optional. GH#319 TRAC#12473
  • 把迭代器概念的静态断言从 ForwardIterator 改为 ReadableIteratorConcept && ForwardTraversalConcept. GH#320
  • 为实数解析器添加了断言, 确保用户定义实数策略的 parse_frac_n 不返回负值, 同时防止静态分析器误报. GH#358
Karma 中的缺陷修复
  • 修复了备选运算符. GH#271
  • 修复了 no_buffering_policy 缺失拷贝构造函数的问题. GH#261
  • ostream_iterator 此前继承 std::iterator, 这在 C++17 中已被弃用. GH#345
Lex 中的缺陷修复
  • 把 id 存储为提升类型以允许枚举之外的值. GH#247
  • 修复了生成的词法分析器中 C2001 '常量中有换行符' 警告. GH#324 TRAC#11540
