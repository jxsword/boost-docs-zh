joint_view

说明

joint_view 呈现一个由两个序列拼接而成的视图.

头文件 
#include <boost/fusion/view/joint_view.hpp>
#include <boost/fusion/include/joint_view.hpp>
概要 
template <typename Sequence1, typename Sequence2>
struct joint_view;
模板参数

参数

说明

默认值

Sequence1

一个 前向序列

Sequence2

一个 前向序列

所属模型
  • 前向序列
  • 关联序列 (若 Sequence1 和 Sequence2 实现了 关联序列 模型).

记法约定

JV

一个 joint_view 类型

s1

Sequence1 的一个实例

s2

Sequence2 的一个实例

jv, jv2

joint_view 的实例

表达式语义

仅当表达式的语义与所实现模型中的定义不同或未在其中定义时, 才给出其语义.

表达式

语义

JV(s1, s2)

创建一个 joint_view, 给定序列 s1 和 s2.

JV(jv)

拷贝构造一个 joint_view, 源为另一个 joint_view jv.

jv = jv2

把一个 joint_view jv 从另一个 joint_view jv2 赋值.
示例 
vector<int, char> v1(3, 'x');
vector<std::string, int> v2("hello", 123);
joint_view<
    vector<int, char>
  , vector<std::string, int>
> view(v1, v2);
std::cout << view << std::endl;
