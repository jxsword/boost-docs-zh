内蕴函数

函数
元函数

内蕴函数构成每个 Fusion 序列 的核心接口. 这些函数的 STL 对应物通常以成员函数实现. 与 算法 不同, 内蕴函数并非对全部 序列 种类通用. 它们需要为每个 Fusion 序列[6] 单独实现.

头文件 
#include <boost/fusion/sequence/intrinsic.hpp>
#include <boost/fusion/include/intrinsic.hpp>

[6] 实践中, 许多内蕴函数都有默认实现, 在多数情况下可用
