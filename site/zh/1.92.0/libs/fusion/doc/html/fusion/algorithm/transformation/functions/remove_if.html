remove_if
说明

返回一个新序列, 包含原序列的全部元素, 但不含使给定一元函数对象求值为 true 的元素.

概要 
template<
    typename Pred,
    typename Sequence
    >
typename result_of::remove_if<Sequence const, Pred>::type remove_if(Sequence const& seq);

表 1.73. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

Pred

一个一元 MPL lambda 表达式 的模型

移除谓词

表达式语义 
remove_if<Pred>(seq);

返回类型:

  • 一个 前向序列 的模型.
  • 一个 关联序列 的模型 (若 seq 实现了 关联序列 模型).

语义: 返回一个新序列, 按原顺序包含 seq 的全部元素, 但不含使 Pred 求值为 boost::mpl::true_ 的类型的元素. 等价于 filter<boost::mpl::not_<Pred> >(seq).

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/remove_if.hpp>
#include <boost/fusion/include/remove_if.hpp>
示例 
const vector<int,double> vec(1,2.0);
assert(remove_if<is_floating_point<mpl::_> >(vec) == make_vector(1));
