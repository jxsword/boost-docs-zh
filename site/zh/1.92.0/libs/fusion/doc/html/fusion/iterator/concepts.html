概念

前向迭代器
双向迭代器
Random Access Iterator
关联迭代器
无界迭代器

Fusion 迭代器分为不同的遍历类别. 前向迭代器 是最基本的概念. 双向迭代器 是 前向迭代器 的细化. 随机访问迭代器 是 双向迭代器 的细化. 关联迭代器 是 前向迭代器、双向迭代器 或 随机访问迭代器 的细化.
