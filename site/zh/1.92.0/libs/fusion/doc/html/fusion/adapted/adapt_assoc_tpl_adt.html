BOOST_FUSION_ADAPT_ASSOC_TPL_ADT

BOOST_FUSION_ADAPT_ASSOC_TPL_ADT 是一个宏, 可用于生成全部必要的样板代码, 将任意模板类类型适配为 随机访问序列 和 关联序列 的模型.

概要 
BOOST_FUSION_ADAPT_ASSOC_TPL_ADT(
    (template_param0)(template_param1)...,
    (type_name) (specialization_param0)(specialization_param1)...,
    ([attribute_type0, attribute_const_type0,] get_expr0, set_expr0, key_type0)
    ([attribute_type1, attribute_const_type1,] get_expr1, set_expr1, key_type1)
    ...
    )
表达式语义

上述宏生成必要的代码, 将 type_name 或 type_name 的任意特化适配为 随机访问序列 和 关联序列 的模型. 序列 (template_param0)(template_param1)... 声明所使用的模板类型参数的名称. 序列 (specialization_param0)(specialization_param1)... 声明被适配为 fusion 序列的 type_name 实际特化的模板参数. ([attribute_typeN, attribute_const_typeN, get_exprN, set_exprN, key_typeN)] 五元组序列声明了被适配 fusion 序列中各元素的类型、const 类型、取值表达式、赋值表达式与键类型. get_exprN 是为获取 N 号元素而调用的表达式, 该元素取自 type_name 的实例. 该表达式可以访问名为 obj 的变量, 其类型为 type_name& 或 type_name const&, 表示 type_name 的底层实例. attribute_typeN 和 attribute_const_typeN 可指定 get_exprN 所指代的类型; 省略时, 类型通过 BOOST_TYPEOF 从 [get_exprN] 的返回类型推导得到. 在不支持可变参数宏的编译器上, 可用 auto 避免重复书写类型. set_exprN 是为设置 N 号元素而调用的表达式, 该元素位于 type_name 的实例中. 该表达式可以访问名为 obj 的变量, 其类型为 type_name&, 表示 type_name 的对应实例; 以及名为 val 的变量, 其类型为任意 const 限定引用模板类型参数 Val, 表示赋值表达式的右操作数.

以 (type_name 的实例) 调用 fusion 的内蕴序列访问 (元) 函数时, 实际返回类型是一个代理类型. 该类型可通过 get_exprN 隐式转换为属性类型, 并通过 set_exprN 把赋值转发给底层元素. 值类型 (即由 result_of::value_of、result_of::value_of_data、result_of::value_at、result_of::value_at_c 和 result_of::value_at_key 所返回的类型) 的定义: 第 N 个元素的值类型为去除 const 限定符和引用后的 attribute_typeN.

该宏应在全局作用域使用, 且 type_name 应为待适配模板类类型的全命名空间限定名.

头文件 
#include <boost/fusion/adapted/adt/adapt_assoc_adt.hpp>
#include <boost/fusion/include/adapt_assoc_adt.hpp>
示例 
namespace demo
{
    template<typename Name, typename Age>
    struct employee
    {
    private:
        Name name;
        Age age;

    public:
        void set_name(Name const& n)
        {
            name=n;
        }

        void set_age(Age const& a)
        {
            age=a;
        }

        Name const& get_name()const
        {
            return name;
        }

        Age const& get_age()const
        {
            return age;
        }
    };
}

namespace keys
{
    struct name;
    struct age;
}

BOOST_FUSION_ADAPT_ASSOC_TPL_ADT(
    (Name)(Age),
    (demo::employee) (Name)(Age),
    (Name const&, Name const&, obj.get_name(), obj.set_name(val), keys::name)
    (Age const&, Age const&, obj.get_age(), obj.set_age(val), keys::age))

demo::employee<std::string, int> e;
at_key<keys::name>(e)="Edward Norton";
at_key<keys::age>(e)=41;
//Prints 'Edward Norton is 41 years old'
std::cout << e.get_name() << " is " << e.get_age() << " years old" << std::endl;
