BOOST_FUSION_DEFINE_STRUCT_INLINE

说明

BOOST_FUSION_DEFINE_STRUCT_INLINE 是一个宏, 可用于生成全部必要的样板代码, 定义任意 struct 并将其适配为 随机访问序列 的模型. 与 BOOST_FUSION_DEFINE_STRUCT 不同, 它可在类作用域或命名空间作用域使用.

概要 
BOOST_FUSION_DEFINE_STRUCT_INLINE(
    struct_name,
    (member_type0, member_name0)
    (member_type1, member_name1)
    ...
    )
表达式语义

BOOST_FUSION_DEFINE_STRUCT_INLINE 的语义与 BOOST_FUSION_DEFINE_STRUCT 完全相同, 但有以下两点差异:

  1. BOOST_FUSION_DEFINE_STRUCT_INLINE 可在类作用域或命名空间作用域使用, 因此不接受命名空间列表参数.
  2. BOOST_FUSION_DEFINE_STRUCT_INLINE 生成的结构体带有一个基类, 因此在 C++03 中不是 POD.
头文件 
#include <boost/fusion/adapted/struct/define_struct_inline.hpp>
#include <boost/fusion/include/define_struct_inline.hpp>
示例 
// enclosing::employee is a Fusion sequence
class enclosing
{
    BOOST_FUSION_DEFINE_STRUCT_INLINE(
        employee,
        (std::string, name)
        (int, age))
};
