make_unfused
说明

创建一个 unfused 适配器, 用于给定的一元 多态函数对象. 对目标函数应用常规的 element conversion.

概要 
template <typename F>
inline typename result_of::make_unfused<F>::type
make_unfused(F const & f);
参数

参数

要求

说明

f

多态函数对象 的模型

要变换的函数.
表达式语义 
make_unfused(f);

返回类型: unfused 的一个特化.

语义: 返回一个 unfused 适配器, 用于 f.

头文件 
#include <boost/fusion/functional/generation/make_unfused.hpp>
#include <boost/fusion/include/make_unfused.hpp>
示例 
struct fused_incrementer
{
    template <class Seq>
    struct result
    {
        typedef void type;
    };

    template <class Seq>
    void operator()(Seq const & s) const
    {
        for_each(s,++boost::lambda::_1);
    }
};

void try_it()
{
    int a = 2; char b = 'X';
    make_unfused(fused_incrementer())(a,b);
    assert(a == 3 && b == 'Y');
}
