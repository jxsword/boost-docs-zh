copy
说明

把序列 src 复制到序列 dest. 它也用于把一种序列转换为另一种序列.

概要 
template <typename Seq1, typename Seq2>
typename result_of::copy<Seq1, Seq2>::type copy(Seq1 const& src, Seq2& dest);

表 1.36. 参数

参数

要求

说明

src

一个 前向序列 的模型, src 序列中包含的所有元素都应能转换为 dest 序列所包含的元素.

操作的参数

dest

一个 前向序列 的模型, e2 = e1 对于每一对元素 (e1 属于 src, e2 属于 dest) 都是有效表达式.

操作的参数

表达式语义 
copy(src, dest);

返回类型: void

语义: e2 = e1 对每一对元素 (e1 属于 src, e2 属于 dest) 执行.

复杂度

线性复杂度, 确切地为 result_of::size<Sequence>::value.

头文件 
#include <boost/fusion/algorithm/auxiliary/copy.hpp>
#include <boost/fusion/include/copy.hpp>
示例 
vector<int,int> vec(1,2);
list<int,int> ls;
copy(vec, ls);
assert(ls == make_list(1,2));
