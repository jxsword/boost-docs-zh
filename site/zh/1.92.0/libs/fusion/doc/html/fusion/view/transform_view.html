transform_view

transform_view 的一元版本在给定一元函数对象或函数指针时, 呈现其底层序列的视图. transform_view 的二元版本在给定二元函数对象或函数指针时, 呈现 2 个底层序列的视图.

头文件 
#include <boost/fusion/view/transform_view.hpp>
#include <boost/fusion/include/transform_view.hpp>
概要

一元版本 

template <typename Sequence, typename F1>
struct transform_view;

二元版本 

template <typename Sequence1, typename Sequence2, typename F2>
struct transform_view;
模板参数

参数

说明

默认值

Sequence

一个 前向序列

Sequence1

一个 前向序列

Sequence2

一个 前向序列

F1

一个一元函数对象或函数指针. boost::result_of<F1(E)>::type 是 F1 的实例以输入序列中每个元素类型 E 的值调用时的返回类型.

F2

一个二元函数对象或函数指针. boost::result_of<F2(E1, E2)>::type 是 F2 的实例以输入序列中每对对应元素类型 E1 和 E2 的值调用时的返回类型.
所属模型
  • 前向序列、双向序列 或 随机访问序列, 取决于其底层序列的遍历特性 (参见 序列遍历概念).
  • 关联序列 (若底层序列实现了 关联序列 模型, 仅一元版本的 transform_view 可用).

记法约定

TV

一个 transform_view 类型

BTV

一个二元 transform_view 类型

UTV

一个一元 transform_view 类型

f1

F1 的一个实例

f2

F2 的一个实例

s

Sequence 的一个实例

s1

Sequence1 的一个实例

s2

Sequence2 的一个实例

tv, tv2

transform_view 的实例

表达式语义

仅当表达式的语义与所实现模型中的定义不同或未在其中定义时, 才给出其语义.

表达式

语义

UTV(s, f1)

创建一个一元 transform_view, 给定序列 s 以及一元函数对象或函数指针 f1.

BTV(s1, s2, f2)

创建一个二元 transform_view, 给定序列 s1 和 s2 以及二元函数对象或函数指针 f2.

TV(tv)

拷贝构造一个 transform_view, 源为另一个 transform_view tv.

tv = tv2

把一个 transform_view tv 从另一个 transform_view tv2 赋值.
示例 
struct square
{
    template<typename Sig>
    struct result;

    template<typename U>
    struct result<square(U)>
    : remove_reference<U>
    {};

    template <typename T>
    T operator()(T x) const
    {
        return x * x;
    }
};

typedef vector<int, short, double> vector_type;
vector_type vec(2, 5, 3.3);

transform_view<vector_type, square> transform(vec, square());
std::cout << transform << std::endl;
