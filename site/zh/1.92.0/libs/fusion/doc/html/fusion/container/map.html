map

说明

map 是一个由异构类型数据元素组成的 关联序列. 每个元素都是一个键/数据对 (参见 fusion::pair), 其中键没有数据 (仅有类型). 类型同一性用于在键上施加等价关系. 一个 map 对每个键至多包含一个元素. 成员测试和元素键查找具有常数运行期复杂度 (参见 重载函数).

头文件 
#include <boost/fusion/container/map.hpp>
#include <boost/fusion/include/map.hpp>
#include <boost/fusion/container/map/map_fwd.hpp>
#include <boost/fusion/include/map_fwd.hpp>
概要 
template <
    typename T0 = unspecified
  , typename T1 = unspecified
  , typename T2 = unspecified
    ...
  , typename TN = unspecified
>
struct map;

对于 C++11 编译器, 可变参数函数接口没有上限.

对于 C++03 编译器, 可变参数类接口接受 0 到 FUSION_MAX_MAP_SIZE 个元素, 其中 FUSION_MAX_MAP_SIZE 是用户可定义的预定义最大值, 默认为 10. 示例:

map<pair<int, char>, pair<char, char>, pair<double, char> >

可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_MAP_SIZE 来更改默认值. 示例:

#define FUSION_MAX_MAP_SIZE 20

表达式语义

仅当表达式的语义与 前向序列 和 关联序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

M()

创建一个元素为默认构造的 map.

M(e0, e1,... en)

创建一个元素对为 e0...en 的 map.

M(s)

从一个 前向序列 s 拷贝构造一个 map.

m = s

把一个 map m 从 前向序列 s 赋值.
示例 
typedef map<
    pair<int, char>
  , pair<double, std::string> >
map_type;

map_type m(
    make_pair<int>('X')
  , make_pair<double>("Men"));

std::cout << at_key<int>(m) << std::endl;
std::cout << at_key<double>(m) << std::endl;
