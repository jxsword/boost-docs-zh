join
说明

给定序列类型时, 返回连接 2 个序列的结果.

概要 
template<
    typename LhSequence,
    typename RhSequence
    >
struct join
{
    typedef unspecified type;
};
表达式语义 
result_of::join<LhSequence, RhSequence>::type

返回类型:

  • 一个 前向序列 的模型.
  • 一个 关联序列 的模型 (若 LhSequence 和 RhSequence 实现了 关联序列 模型).

语义: 返回一个包含 LhSequence 的元素、后接 RhSequence 的元素的序列. 两个序列中元素的顺序保持不变.

复杂度

常量.

头文件 
#include <boost/fusion/algorithm/transformation/join.hpp>
#include <boost/fusion/include/join.hpp>
