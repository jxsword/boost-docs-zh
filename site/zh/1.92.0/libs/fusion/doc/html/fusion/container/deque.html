deque

说明

deque 是一个简单的 双向序列, 支持在两端以常数时间插入和移除元素. 与 list 和 cons 一样, 当目标序列逐个 (每次一个数据, 例如构造表达式模板时) 构造时, deque 比 vector 更高效 (尤其在编译期). 与 list 和 cons 一样, 访问每个元素的运行期代价出奇地恒定 (参见 递归内联函数).

元素的插入和移除由特殊的 deque 辅助类 front_extended_deque 和 back_extended_deque 完成.

头文件 
#include <boost/fusion/container/deque.hpp>
#include <boost/fusion/include/deque.hpp>
#include <boost/fusion/container/deque/deque_fwd.hpp>
#include <boost/fusion/include/deque_fwd.hpp>
概要 
template <typename ...Elements>
struct deque;

对于 C++11 编译器, 可变参数类接口没有上限.

对于 C++03 编译器, 可变参数类接口接受 0 到 FUSION_MAX_DEQUE_SIZE 个元素, 其中 FUSION_MAX_DEQUE_SIZE 是用户可定义的预定义最大值, 默认为 10. 示例:

deque<int, char, double>

可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_DEQUE_SIZE 来更改默认值. 示例:

#define FUSION_MAX_DEQUE_SIZE 20

表达式语义

仅当表达式的语义与 双向序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

D()

创建一个元素为默认构造的 deque.

D(e0, e1,... en)

创建一个元素为 e0...en 的 deque.

D(s)

从一个 前向序列 s 拷贝构造一个 deque.

d = s

把一个 deque d 从 前向序列 s 赋值.

at<N>(d)

从序列开头起的第 N 个元素; 参见 at.
注释

提供 at<N>(d) 是为了方便, 尽管 deque 只是 双向序列 (at 本应是 随机访问序列 的要求). at 的运行期复杂度为常数 (参见 递归内联函数). deque 的元素访问利用了运算符重载以及针对给定静态常量索引参数的适当元素获取函数的实参依赖查找 (ADL). 有趣的是, 在现代 C++ 编译器上, 这种查找非常快, 在编译期速度上可与递归模板实例化相媲美, 以至于 deque 的所有元素访问 (索引) 和迭代都依赖 ADL.

示例 
deque<int, float> d(12, 5.5f);
std::cout << at_c<0>(d) << std::endl;
std::cout << at_c<1>(d) << std::endl;
