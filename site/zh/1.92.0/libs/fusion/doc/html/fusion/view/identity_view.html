identity_view

说明

identity_view 原样呈现底层序列.

头文件 
#include <boost/fusion/view/identity_view.hpp>
#include <boost/fusion/include/identity_view.hpp>
概要 
template <typename Sequence>
struct identity_view;
模板参数

参数

说明

默认值

Sequence

一个 前向序列

所属模型
  • 一个 前向序列 的模型 (若 Sequence 是 前向序列); 否则, 一个 双向序列 的模型 (若 Sequence 是 双向序列); 否则, 一个 随机访问序列 的模型 (若 Sequence 是 随机访问序列).
  • 关联序列 (若 Sequence 实现了 关联序列 模型).

记法约定

IV

一个 identity_view 类型

s

Sequence 的一个实例

iv, iv2

identity_view 的实例

表达式语义

仅当表达式的语义与所实现模型中的定义不同或未在其中定义时, 才给出其语义.

表达式

语义

IV(s)

创建一个 identity_view, 给定序列为 s.

IV(iv)

拷贝构造一个 identity_view, 源为另一个 identity_view iv.

iv = iv2

把一个 identity_view iv 从另一个 identity_view iv2 赋值.
示例 
typedef vector<int, short, double> vector_type;
vector_type vec(2, 5, 3.3);

identity_view<vector_type> identity(vec);
std::cout << identity << std::endl; // (2 5 3.3)
