deque_tie
说明

使用 deque 序列构造一个 tie.

概要 
template <typename ...Elements>
deque<Elements&...>
deque_tie(Elements&... elements);

对于 C++11 编译器, 可变参数函数接口没有上限.

对于 C++03 编译器, 可变参数函数接受 0 到 FUSION_MAX_DEQUE_SIZE 个元素, 其中 FUSION_MAX_DEQUE_SIZE 是用户可定义的预定义最大值, 默认为 10. 可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_DEQUE_SIZE 来更改默认值. 示例:

#define FUSION_MAX_DEQUE_SIZE 20
参数

参数

说明

说明

elements

Elements 的实例

deque_tie 的实参
表达式语义 
deque_tie(elements...);

返回类型: deque<Elements&...>

语义: 创建一个引用组成的 deque, 其引用来自 elements....

头文件 
#include <boost/fusion/container/generation/deque_tie.hpp>
#include <boost/fusion/include/deque_tie.hpp>
示例 
int i = 123;
double d = 123.456;
deque_tie(i, d)
