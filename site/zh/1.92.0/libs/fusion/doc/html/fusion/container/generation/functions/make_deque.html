make_deque
说明

从一个或多个值创建一个 deque.

概要 
template <typename ...Elements>
typename result_of::make_deque<Elements...>::type
make_deque(Elements const&... elements);

对于 C++11 编译器, 可变参数函数接口没有上限.

对于 C++03 编译器, 可变参数函数接受 0 到 FUSION_MAX_DEQUE_SIZE 个元素, 其中 FUSION_MAX_DEQUE_SIZE 是用户可定义的预定义最大值, 默认为 10. 可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_DEQUE_SIZE 来更改默认值. 示例:

#define FUSION_MAX_DEQUE_SIZE 20
参数

参数

说明

说明

elements

Elements 的实例

make_deque 的实参
表达式语义 
make_deque(elements...);

返回类型: result_of::make_deque<Elements...>::type

语义: 创建一个 deque, 数据来自 elements....

头文件 
#include <boost/fusion/container/generation/make_deque.hpp>
#include <boost/fusion/include/make_deque.hpp>
示例
