set

说明

set 是一个由异构类型数据元素组成的 关联序列. 类型同一性用于在键上施加等价关系. 元素的类型就是它的键. 一个 set 对每个键至多包含一个元素. 成员测试和元素键查找具有常数运行期复杂度 (参见 重载函数).

头文件 
#include <boost/fusion/container/set.hpp>
#include <boost/fusion/include/set.hpp>
#include <boost/fusion/container/set/set_fwd.hpp>
#include <boost/fusion/include/set_fwd.hpp>
概要 
template <
    typename T0 = unspecified
  , typename T1 = unspecified
  , typename T2 = unspecified
    ...
  , typename TN = unspecified
>
struct set;

对于 C++11 编译器, 可变参数函数接口没有上限.

对于 C++03 编译器, 可变参数类接口接受 0 到 FUSION_MAX_SET_SIZE 个元素, 其中 FUSION_MAX_SET_SIZE 是用户可定义的预定义最大值, 默认为 10. 示例:

set<int, char, double>

可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_SET_SIZE 来更改默认值. 示例:

#define FUSION_MAX_SET_SIZE 20

表达式语义

仅当表达式的语义与 随机访问序列 和 关联序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

S()

创建一个元素为默认构造的 set.

S(e0, e1,... en)

创建一个元素为 e0...en 的 set.

S(fs)

从一个 前向序列 fs 拷贝构造一个 set.

s = fs

把一个 set s 从 前向序列 fs 赋值.
示例 
typedef set<int, float> S;
S s(12, 5.5f);
std::cout << at_key<int>(s) << std::endl;
std::cout << at_key<float>(s) << std::endl;
std::cout << result_of::has_key<S, double>::value << std::endl;
