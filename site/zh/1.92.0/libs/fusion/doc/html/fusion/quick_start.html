快速入门

我假定读者已经熟悉元组 (Boost.Tuple) 及其前身 std::pair. 元组是 std::pair 在多个异构元素 (三元组、四元组等) 情形下的推广. 元组差不多就是 fusion vector 的同义词.

首先, 我们包含 Fusion 的全部 序列 [2]:

#include <boost/fusion/sequence.hpp>
#include <boost/fusion/include/sequence.hpp>

让我们从一个 vector 开始 [3]:

vector<int, char, std::string> stuff(1, 'x', "howdy");
int i = at_c<0>(stuff);
char ch = at_c<1>(stuff);
std::string s = at_c<2>(stuff);

只要把 tuple 换成 vector, 把 get 换成 at_c, 这就和 Boost.Tuple 完全一样了. 实际上, 两个名称可以互换使用. 但相似之处仅此而已. 用 Fusion 的 vector 或 tuple 可以做更多事情. 让我们看一些例子.

以 XML 打印 vector

首先, 让我们包含算法:

#include <boost/fusion/algorithm.hpp>
#include <boost/fusion/include/algorithm.hpp>

现在, 让我们编写一个函数对象, 为元组中的每个成员打印形如 <type>data</type> 的 XML.

struct print_xml
{
    template <typename T>
    void operator()(T const& x) const
    {
        std::cout
            << '<' << typeid(x).name() << '>'
            << x
            << "</" << typeid(x).name() << '>'
            ;
    }
};

现在, 最后:

for_each(stuff, print_xml());

就是这样! for_each 是一个 fusion 算法. 它是一个类似于 STL 算法的泛型算法. 它遍历序列并调用用户提供的函数. 在我们的例子里, 它调用 print_xml 的 operator(), 作用于 stuff 中的每个元素.

注意

typeid(x).name() 的结果与平台相关. 这里的代码仅作说明之用. 当然你已经知道了 :-)

for_each 是泛型的. 有了 print_xml, 你可以用它打印几乎所有 Fusion 序列.

只打印指针

让我们再聪明一点. 假设我们想编写一个泛型函数, 接收任意序列, 并只对其中是指针的元素进行 XML 打印. 啊, 简单. 首先, 让我们包含 is_pointer 这个 boost 类型特征:

#include <boost/type_traits/is_pointer.hpp>

然后, 只需:

template <typename Sequence>
void xml_print_pointers(Sequence const& seq)
{
    for_each(filter_if<boost::is_pointer<_> >(seq), print_xml());
}

filter_if 是另一个 Fusion 算法. 它返回一个 filter_view, 即一个符合规范的 Fusion 序列. 该视图只反映通过给定谓词的元素. 在此例中, 谓词是 boost::is_pointer<_>. 然后, 这个"过滤视图"被传给 for_each 算法, 由它把"过滤视图"打印为 XML.

很简单, 对吧?

关联元组

好, 继续...

除 vector 外, fusion 还有其他几种序列类型可供选择. 每种序列都有自己的特性. 我们有 list、set、map, 还有大量 views, 提供呈现序列的各种方式.

Fusion 的 map 把类型与元素关联起来. 它可以作为 struct 的更巧妙替代品. 示例:

namespace fields
{
    struct name;
    struct age;
}

typedef map<
    fusion::pair<fields::name, std::string>
  , fusion::pair<fields::age, int> >
person;

map 是一个关联序列. 其元素是 Fusion 对, 与 std::pair 略有不同. Fusion 对只包含一个成员, 其类型为第二个模板参数的类型. 对的第一个类型参数用作序列中关联元素的索引. 例如, 给定一个 a_person, 其类型为 person, 你可以:

using namespace fields;
std::string person_name = at_key<name>(a_person);
int person_age = at_key<age>(a_person);

你可能会说, 为什么要费这么大劲? 嗯, 其一, 与 struct 不同, 我们面对的是泛型数据结构. 有大量设施随手可用, 有 fusion 开箱即用的, 也有他人编写的. 有了这些设施, 例如内省是免费的. 我们可以编写一个序列化函数 (好吧, 算两个, 如果把加载和保存分开算), 适用于你所有的 fusion map. 示例:

struct saver
{
    template <typename Pair>
    void operator()(Pair const& data) const
    {
        some_archive << data.second;
    }
};

template <typename Stuff>
void save(Stuff const& stuff)
{
    for_each(stuff, saver());
}

save 函数是泛型的, 对所有类型的 stuff 都适用, 无论是 person、dog 还是整个 alternate_universe.

冰山一角

而且... 我们还只是浅尝辄止! 你可以组合和扩展数据结构、从结构中移除元素、查找特定数据类型、查询元素、过滤类型以便检查、变换数据结构等. 你所看到的只是冰山一角.
