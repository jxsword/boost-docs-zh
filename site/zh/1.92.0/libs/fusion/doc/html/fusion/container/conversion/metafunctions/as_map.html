as_map
说明

返回 as_map 的结果类型.

概要 
template <typename Sequence>
struct as_map;
参数

参数

要求

说明

Sequence

一个 fusion 序列

要转换的序列.
表达式语义 
result_of::as_map<Sequence>::type;

返回类型: 一个 map, 与输入序列 Sequence 具有相同的元素.

语义: 把 fusion 序列 Sequence 转换为 map.

前置条件: 对于非关联序列, 元素被假定为 __fusion_pair__. 不得存在重复的 fusion::pair 键类型.

头文件 
#include <boost/fusion/container/map/convert.hpp>
#include <boost/fusion/include/as_map.hpp>
示例 
// from sequence of __fusion_pair__
result_of::as_map<vector<
    fusion::pair<int, char>
  , fusion::pair<double, std::string> > >::type

// from associative sequence
namespace ns
{
    struct x_member;
    struct y_member;
}
BOOST_FUSION_DEFINE_ASSOC_STRUCT(
    (ns),
    point,
    (int, x, ns::x_member)
    (int, y, ns::y_member)
)
...
result_of::as_map<ns::point>::type // __map__<__fusion_pair__<ns::x_member, int>, __fusion_pair__<ns::y_member, int> >
