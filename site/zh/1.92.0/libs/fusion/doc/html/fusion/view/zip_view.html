zip_view

说明

zip_view 呈现一个并行遍历 序列 集合的视图. zip_view 由一个 序列 构造, 该序列存放指向各成员 Sequence 的引用.

头文件 
#include <boost/fusion/view/zip_view.hpp>
#include <boost/fusion/include/zip_view.hpp>
概要 
template <typename Sequences>
struct zip_view;
模板参数

参数

说明

默认值

Sequences

一个 前向序列, 由指向其他 Fusion Sequence 的引用组成
所属模型
  • 前向序列、双向序列 或 随机访问序列, 取决于其底层序列的遍历特性 (参见 序列遍历概念).

记法约定

ZV

一个 zip_view 类型

s

Sequences 的一个实例

zv1, zv2

ZV 的实例

表达式语义

仅当表达式的语义与 前向序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

ZV(s)

创建一个 zip_view, 给定一个由指向各成员 Sequence 的引用组成的序列.

ZV(zv1)

拷贝构造一个 zip_view, 源为另一个 zip_view zv.

zv1 = zv2

把一个 zip_view zv 从另一个 zip_view zv2 赋值.
示例 
typedef vector<int,int> vec1;
typedef vector<char,char> vec2;
vec1 v1(1,2);
vec2 v2('a','b');
typedef vector<vec1&, vec2&> sequences;
std::cout << zip_view<sequences>(sequences(v1, v2)) << std::endl; // ((1 a) (2 b))
