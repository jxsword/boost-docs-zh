invoke_function_object
说明

用一个 序列 中的实参调用一个 多态函数对象.

可以显式指定第一个模板参数, 以避免复制和/或控制函数对象的 const 限定.

应用 Boost.Functional/Factory Library 可以调用构造函数.

概要 
template<
    typename Function,
    class Sequence
    >
typename result_of::invoke_function_object<Function, Sequence>::type
invoke_function_object(Function f, Sequence & s);

template<
    typename Function,
    class Sequence
    >
typename result_of::invoke_function_object<Function, Sequence const>::type
invoke_function_object(Function f, Sequence const & s);
参数

参数

要求

说明

f

多态函数对象 的模型

要调用的函数对象.

s

前向序列 的模型

实参.
表达式语义 
invoke_function_object(f,s);

返回类型: f 以 s 中的元素为实参调用时的返回类型.

语义: 调用 f, 以 s 中的元素为实参, 并返回该调用表达式的结果.

头文件 
#include <boost/fusion/functional/invocation/invoke_function_object.hpp>
示例 
struct sub
{
    template <typename Sig>
    struct result;

    template <class Self, typename T>
    struct result< Self(T,T) >
    { typedef typename remove_reference<T>::type type; };

    template<typename T>
    T operator()(T lhs, T rhs) const
    {
        return lhs - rhs;
    }
};

void try_it()
{
    sub f;
    assert(f(2,1) == invoke_function_object(f,make_vector(2,1)));
}
