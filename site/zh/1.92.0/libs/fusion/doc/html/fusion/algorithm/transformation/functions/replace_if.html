replace_if
说明

把给定序列中使一元函数对象求值为 true 的每个元素替换为新值.

概要 
template<
    typename Sequence,
    typename F,
    typename T>
typename result_of::replace_if<Sequence const, F, T>::type replace_if(
    Sequence const& seq, F f, T const& new_value);

表 1.71. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

f

一个函数对象, f(e) 对每个元素都是有效表达式且可转换为 bool, 该元素 e 取自 seq

操作的参数

new_value

任意类型

替换后的值

表达式语义 
replace_if(seq, f, new_value);

返回类型: 一个 前向序列 的模型.

语义: 返回一个新序列, 包含 seq 的全部元素, 并把 new_value 赋给使 f 求值为 true 的每个元素.

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/replace_if.hpp>
#include <boost/fusion/include/replace_if.hpp>
示例 
struct odd
{
    template<typename T>
    bool operator()(T t) const
    {
        return t % 2;
    }
};
...
assert(replace_if(make_vector(1,2), odd(), 3) == make_vector(3,2));
