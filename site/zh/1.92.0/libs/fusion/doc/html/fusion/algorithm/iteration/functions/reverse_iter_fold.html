reverse_iter_fold
说明

对于序列 seq、初始状态 initial_state 以及二元函数对象或函数指针 f, reverse_iter_fold 返回把二元 f 反复应用于上一次 f 调用的结果 (首次调用时为 inital_state) 与 seq 各元素上的迭代器的结果.

概要

    typename Sequence,
    typename State,
    typename F
    >
typename result_of::reverse_iter_fold<Sequence, State const, F>::type reverse_iter_fold(
    Sequence& seq, State const& initial_state, F f);

表 1.43. 参数

参数

要求

说明

seq

一个 双向序列 的模型

操作的参数

initial_state

任意类型

初始状态

f

f(s,it) 的返回类型为 boost::result_of<F(S,It)>::type, 其中当前状态 s 的类型为 S, 且对每个迭代器 it (类型为 It, 指向 seq 的某元素)

操作的参数

表达式语义 
reverse_iter_fold(seq, initial_state, f);

返回类型: 任意类型

语义: 等价于 f(... f(f(initial_state,itN),itN-1) ...it1), 其中 it1 ...itN 是 seq 各元素上的连续迭代器.

复杂度

线性复杂度, 恰好应用 result_of::size<Sequence>::value 次 f.

头文件 
#include <boost/fusion/algorithm/iteration/reverse_iter_fold.hpp>
#include <boost/fusion/include/reverse_iter_fold.hpp>
示例 
struct make_string
{
    typedef std::string result_type;

    template<typename T>
    std::string operator()(const std::string& str, const T& t) const
    {
        return str + boost::lexical_cast<std::string>(deref(t));
    }
};
...
const vector<int,int> vec(1,2);
assert(reverse_iter_fold(vec,std::string(""), make_string()) == "21");
