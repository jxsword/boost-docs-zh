元组创建函数

说明

TR1 描述了 2 个用于创建 TR1 Tuple 的实用函数. make_tuple 用其实参列表构建一个元组, tie 构建一个由其实参的引用组成的元组. 本节描述这些创建函数的细节.

规范 
template<typename T1, typename T2, ..., typename TN>
tuple<V1, V2, ..., VN>
make_tuple(const T1& t1, const T2& t2, ..., const TN& tn);

其中 Vi 为 X& (若 cv 未限定类型 Ti 是 reference_wrapper<X>), 否则 Vi 为 Ti.

返回: tuple<V1, V2, ..., VN>(t1, t2, ..., tN) 

template<typename T1, typename T2, ..., typename TN>
tuple<T1&, T2&, ..., TN&>
tie(T1& t1, T2& t2, ..., TN& tn);

返回: tuple<T1&, T2&, ..., TN&>(t1, t2, ..., tN). 当实参 ti 为 ignore 时, 给对应元组元素赋任何值都无效.
