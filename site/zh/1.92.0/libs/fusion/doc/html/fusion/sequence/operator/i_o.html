I/O

in
out

I/O 运算符 << 和 >> 对所有 Fusion 序列泛型地工作. I/O 运算符在命名空间 boost::fusion 中重载 [10]

operator<< 已针对泛型输出流重载, 使得 序列 通过对每个元素递归调用 operator<< 来输出. 类似地, 全局 operator>> 已被重载, 用于从泛型输入流中提取 序列, 即对每个元素递归调用 operator>>.

请注意, 要通过 fusion IO 系统显示你适配的类型, 应把相应的重载运算符引入到该类型所在的同一命名空间中.

namespace your_awesome_library
{
    using boost::fusion::operators::operator>>; // for input
    using boost::fusion::operators::operator<<; // for output
    ...

元素之间的默认分隔符是空格, 序列 被括在圆括号中. 例如:

vector<float, int, std::string> a(1.0f, 2, std::string("Howdy folks!");
cout << a;

把 vector 输出为: (1.0 2 Howdy folks!)

本库定义了三个用于更改默认行为的操纵器:

操纵器

tuple_open(arg)

定义在第一个元素之前输出的字符.

tuple_close(arg)

定义在最后一个元素之后输出的字符.

tuple_delimiter(arg)

定义元素之间的分隔字符.

tuple_open、tuple_close 和 tuple_delimiter 的实参可以是 char、wchar_t、C 字符串或宽 C 字符串.

示例:

std::cout << tuple_open('[') << tuple_close(']') << tuple_delimiter(", ") << a;

把同一个 vector a 输出为: [1.0, 2, Howdy folks!]

同样的操纵器也适用于 operator>> 和 istream. 假设 std::cin 流包含以下数据:

(1 2 3) [4:5]

如下代码:

vector<int, int, int> i;
vector<int, int> j;

std::cin >> i;
std::cin >> tuple_open('[') >> tuple_close(']') >> tuple_delimiter(':');
std::cin >> j;

把数据读入 vector i 和 j.

注意, 提取 序列 时, 若其含 std::string 或 C 风格字符串元素, 通常行不通, 因为流式 序列 表示可能无法无歧义地解析.

头文件 
#include <boost/fusion/sequence/io.hpp>
#include <boost/fusion/include/io.hpp>

[10] 位于不同命名空间中的 序列 和 视图 必须在自己的命名空间中提供自己的 I/O 运算符 (可能转发到 fusion 的 I/O 运算符), 或提升 fusion 的 I/O 运算符 (using 声明), 以便进行正确的实参依赖查找.
