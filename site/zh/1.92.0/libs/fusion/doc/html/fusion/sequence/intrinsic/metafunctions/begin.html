begin
说明

返回 begin 的结果类型.

概要 
template<typename Seq>
struct begin
{
    typedef unspecified type;
};

表 1.22. 参数

参数

要求

说明

Seq

一个 前向序列 的模型

实参序列

表达式语义 
result_of::begin<Seq>::type

返回类型:

  • 一个 前向迭代器 的模型 (若 seq 是 前向序列); 否则, 一个 双向迭代器 的模型 (若 seq 是 双向序列); 否则, 一个 随机访问迭代器 的模型 (若 seq 是 随机访问序列).
  • 一个 关联迭代器 的模型 (若 seq 是 关联序列).

语义: 返回指向 Seq 第一个元素的迭代器的类型.

头文件 
#include <boost/fusion/sequence/intrinsic/begin.hpp>
#include <boost/fusion/include/begin.hpp>
示例 
typedef vector<int> vec;
typedef result_of::begin<vec>::type it;
BOOST_MPL_ASSERT((boost::is_same<result_of::deref<it>::type, int&>))
