make_fused
说明

创建一个 fused 适配器, 用于给定的 延迟可调用对象. 对目标函数应用常规的 element conversion.

概要 
template <typename F>
inline typename result_of::make_fused<F>::type
make_fused(F const & f);
参数

参数

要求

说明

f

延迟可调用对象 的模型

要变换的函数.
表达式语义 
make_fused(f);

返回类型: fused 的一个特化.

语义: 返回一个 fused 适配器, 用于 f.

头文件 
#include <boost/fusion/functional/generation/make_fused.hpp>
#include <boost/fusion/include/make_fused.hpp>
示例 
float sub(float a, float b) { return a - b; }

void try_it()
{
    vector<int,float> a(2,2.0f);
    vector<int,float> b(1,1.5f);
    vector<float,float> c(1.0f,0.5f);
    assert(c == transform(zip(a,b), make_fused(& sub)));
    assert(c == transform(zip(a,b), make_fused(std::minus<float>())));
}
