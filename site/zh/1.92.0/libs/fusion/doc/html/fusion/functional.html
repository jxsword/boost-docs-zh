fused 与 unfused 形式

什么是函数调用?

f (a,b,c)

它是一个名字和一个元组按从左到右的顺序紧挨着书写.

虽然 C++ 语法不允许把 (a,b,c) 替换为某个 Fusion 序列, 但引入另一个函数提供了一个解决方案:

invoke(f,my_sequence)

或者, 也可以对 f 应用一个简单的变换来达到相同的效果:

f tuple <=> f' (tuple)

现在, f' 是一个一元函数, 它把传给 f 的实参作为一个元组接收; f' 是 fused 形式的 f. 从右到左阅读上面的等价关系即得逆变换: f 是 unfused 形式的 f'.

调用函数与函数对象

让泛型 C++ 代码回调客户端提供的任意函数曾是一项高度重复的任务, 因为不同函数可能在元数、调用语法以及可能成为类型一部分的其他属性上各不相同. 把实参封装为 Fusion 序列传递并把调用过程分离出来, 使 Fusion 算法可以应用于函数实参, 同时把问题简化为一种调用语法和固定的元数 (而不是任意个数的任意实参 × 若干语法变体 × 附加属性).

把 unfused 函数转换为其 fused 对应形式, 使得以 序列 为实参调用一元 多态函数对象 的算法能够执行 n 元调用.

本库提供了若干函数模板, 分别用于调用不同种类的函数, 以及把它们变换为 fused 形式的适配器. 每个变体都有对应的生成器函数模板, 为给定实参返回一个适配器实例.

应用 Boost.Functional/Factory Library 可以调用构造函数.

使 Fusion 代码可以通过函数对象接口调用

把 fused 函数转换为其 unfused 对应形式, 可以创建接受任意调用的函数对象. 换言之, 可以实现一个一元函数对象, 而不必使用 (可能大量重载的) 函数模板或函数调用运算符.

本库为该变换提供了严格类型化和泛型两种变体. 后者应与 Boost.Functional/Forward Library 结合使用, 以应对 转发问题.

两种变体都有对应的生成器函数模板, 为给定实参返回一个适配器实例.
