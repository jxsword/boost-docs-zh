flatten_view

说明

flatten_view 呈现一个以深度优先顺序递归遍历其元素的视图.

头文件 
#include <boost/fusion/view/flatten_view.hpp>
#include <boost/fusion/include/flatten_view.hpp>
概要 
template <typename Sequence>
struct flatten_view;
模板参数

参数

说明

默认值

Sequence

一个 前向序列

所属模型
  • 前向序列

记法约定

F

一个 flatten_view 类型

s

Sequence 的一个实例

f, f2

F 的实例

表达式语义

仅当表达式的语义与 前向序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

F(s)

创建一个 flatten_view, 给定序列为 s.

F(f)

拷贝构造一个 flatten_view, 源为另一个 flatten_view f.

f = f2

把一个 flatten_view f 从另一个 flatten_view f2 赋值.
示例 
typedef vector<int, int, vector<int, int>, int> sequence_type;
sequence_type seq;
flatten_view<sequence_type> flattened(seq);
copy(make_vector(1, 2, 3, 4, 5), flattened);
assert(seq == make_vector(1, 2, make_vector(3, 4), 5));
