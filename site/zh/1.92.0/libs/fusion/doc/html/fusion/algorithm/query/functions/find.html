find
说明

查找序列中给定类型的第一个元素.

概要 
template<
    typename T,
    typename Sequence
    >
typename result_of::find<Sequence const, T>::type find(Sequence const& seq);

template<
    typename T,
    typename Sequence
    >
typename result_of::find<Sequence, T>::type find(Sequence& seq);

表 1.55. 参数

参数

要求

说明

seq

一个 前向序列 的模型

要搜索的序列

T

任意类型

要查找的类型

表达式语义 
find<T>(seq)

返回类型: 一个与 seq 的迭代器具有相同迭代器类别的模型.

语义: 返回指向 seq 中第一个类型为 T 的元素的迭代器, 若不存在这样的元素, 则返回 end(seq). 等价于 find_if<boost::is_same<_, T> >(seq)

复杂度

线性复杂度. 至多进行 result_of::size<Sequence>::value 次比较.

头文件 
#include <boost/fusion/algorithm/query/find.hpp>
#include <boost/fusion/include/find.hpp>
示例 
const vector<char,int> vec('a','0');
assert(*find<int>(vec) == '0');
assert(find<double>(vec) == end(vec));
