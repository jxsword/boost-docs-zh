repetitive_view

说明

repetitive_view 呈现一个反复遍历给定 序列 的视图. 由于 repetitive_view 长度无限, 只有当某个外部条件确定终点时才能使用它. 因此, 用 repetitive_view 初始化定长序列是可以的, 但把 repetitive_view 打印到 std::cout 则不行.

头文件 
#include <boost/fusion/view/repetitive_view.hpp>
#include <boost/fusion/include/repetitive_view.hpp>
概要 
template <typename Sequence>
struct repetitive_view;
模板参数

参数

说明

默认值

Sequence

任意 Fusion 前向序列

记法约定

RV

一个 repetitive_view 类型

s

Sequences 的一个实例

rv, rv1, rv2

RV 的实例

表达式语义

表达式

返回类型

语义

RV(s)

给定底层序列创建一个 repetitive_view.

RV(rv1)

拷贝构造一个 repetitive_view, 源为另一个 repetitive_view rv1.

rv1 = rv2

把一个 repetitive_view rv1 从另一个 repetitive_view rv2 赋值.

begin(rv)

前向迭代器

end(rv)

前向迭代器

创建一个不可到达的迭代器 (因为该序列是无限的)
结果类型表达式

表达式

result_of::begin<RV>::type

result_of::end<RV>::type

示例 
typedef vector<int, char, double> vec1;
typedef vector<int, char, double, int, char> vec2;

vec1 v1(1, 'c', 2.0);
vec2 v2(repetitive_view<vec1>(v1));

std::cout << v2 << std::endl; // 1, 'c', 2.0, 1, 'c'
