make_fused_function_object
说明

创建一个 fused_function_object 适配器, 用于给定的 延迟可调用对象. 对目标函数应用常规的 element conversion.

概要 
template <typename F>
inline typename result_of::make_fused_function_object<F>::type
make_fused_function_object(F const & f);
参数

参数

要求

说明

f

多态函数对象 的模型

要变换的函数.
表达式语义 
make_fused_function_object(f);

返回类型: fused_function_object 的一个特化.

语义: 返回一个 fused_function_object 适配器, 用于 f.

头文件 
#include <boost/fusion/functional/generation/make_fused_function_object.hpp>
#include <boost/fusion/include/make_fused_function_object.hpp>
示例 
struct sub
{
    template <typename Sig>
    struct result;

    template <class Self, typename T>
    struct result< Self(T,T) >
    { typedef typename remove_reference<T>::type type; };

    template<typename T>
    T operator()(T lhs, T rhs) const
    {
        return lhs - rhs;
    }
};

void try_it()
{
    vector<int,float> a(2,2.0f);
    vector<int,float> b(1,1.5f);
    vector<int,float> c(1,0.5f);
    assert(c == transform(zip(a,b), make_fused_function_object(sub())));
}
