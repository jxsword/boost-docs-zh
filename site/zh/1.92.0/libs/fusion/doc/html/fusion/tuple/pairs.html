对

说明

TR1 Tuple 接口被规定为提供对 std::pair 的统一访问, 就像它是一个 2 元素元组一样.

规范 
tuple_size<std::pair<T1, T2> >::value

类型: 一个 MPL 整型常量

值: 返回 2, 即对中元素的个数.

tuple_element<0, std::pair<T1, T2> >::type

类型: T1

值: 返回对中第一个元素的类型

tuple_element<1, std::pair<T1, T2> >::type

类型: T2

值: 返回对中第二个元素的类型

template<int I, typename T1, typename T2>
P& get(std::pair<T1, T2>& pr);

template<int I, typename T1, typename T2>
const P& get(const std::pair<T1, T2>& pr);

类型: 若 I == 0 P 为 T1; 否则若 I == 1 P 为 T2; 否则程序为非良构.

[*返回: pr.first (若 I == 0), 否则 pr.second.
