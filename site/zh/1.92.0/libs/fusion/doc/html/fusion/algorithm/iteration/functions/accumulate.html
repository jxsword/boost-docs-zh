accumulate
说明

对于序列 seq、初始状态 initial_state 以及二元函数对象或函数指针 f, accumulate 返回把二元 f 反复应用于上一次 f 调用的结果 (首次调用时为 inital_state) 与 seq 的每个元素的结果.

概要 
template<
    typename Sequence,
    typename State,
    typename F
    >
typename result_of::accumulate<Sequence, State const, F>::type accumulate(
    Sequence& seq, State const& initial_state, F f);

template<
    typename Sequence,
    typename State,
    typename F

typename result_of::accumulate<Sequence const, State const, F>::type accumulate(

    Sequence const& seq, State& initial_state, F f);

表 1.44. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

initial_state

任意类型

初始状态

f

f(s,e) 的返回类型为 boost::result_of<F(S,E)>::type, 其中当前状态 s 的类型为 S, 且对每个元素 e (类型为 E, 取自 seq)

操作的参数

表达式语义 
accumulate(seq, initial_state, f);

返回类型: 任意类型

语义: 等价于 f(... f(f(initial_state,e1),e2) ...eN), 其中 e1 ...eN 是 seq 的连续元素.

复杂度

线性复杂度, 恰好应用 result_of::size<Sequence>::value 次 f.

头文件 
#include <boost/fusion/algorithm/iteration/accumulate.hpp>
#include <boost/fusion/include/accumulate.hpp>
示例 
struct make_string
{
    typedef std::string result_type;

    template<typename T>
    std::string operator()(const std::string& str, const T& t) const
    {
        return str + boost::lexical_cast<std::string>(t);
    }
};
...
const vector<int,int> vec(1,2);
assert(accumulate(vec,std::string(""), make_string()) == "12");
