make_list
说明

返回 make_list 的结果类型.

概要 
template <typename T0, typename T1,... typename TN>
struct make_list;

对于 C++11 编译器, 可变参数函数接口没有上限.

对于 C++03 编译器, 可变参数函数接受 0 到 FUSION_MAX_LIST_SIZE 个元素, 其中 FUSION_MAX_LIST_SIZE 是用户可定义的预定义最大值, 默认为 10. 可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_LIST_SIZE 来更改默认值. 示例:

#define FUSION_MAX_LIST_SIZE 20
参数

参数

要求

说明

T0, T1,... TN

任意类型

make_list 的模板实参
表达式语义 
result_of::make_list<T0, T1,... TN>::type

返回类型: 一个 list, 其元素类型按照 element conversion 的规则转换.

语义: 创建一个 list, 数据来自 T0, T1,... TN.

头文件 
#include <boost/fusion/container/generation/make_list.hpp>
#include <boost/fusion/include/make_list.hpp>
示例 
result_of::make_list<int, const char(&)[7], double>::type
