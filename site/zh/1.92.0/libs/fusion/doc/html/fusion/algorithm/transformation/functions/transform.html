transform
说明

对于序列 seq 和函数对象或函数指针 f, transform 返回一个新序列, 其元素通过把 f(e) 应用于每个元素 e (属于 seq) 而得到.

一元版本概要 
template<
    typename Sequence,
    typename F
    >
typename result_of::transform<Sequence const, F>::type transform(
    Sequence const& seq, F f);

表 1.68. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

f

f(e) 对每个元素 e (属于 seq) 都是有效表达式. boost::result_of<F(E)>::type 是 f 以各元素类型 (E) 的值调用时的返回类型.

变换函数

表达式语义 
transform(seq, f);

返回类型: 一个 前向序列 的模型

语义: 返回一个新序列, 包含 f(e) 对每个元素 e (位于 seq 中) 的返回值.

二元版本概要 
template<
    typename Sequence1,
    typename Sequence2,
    typename F
    >
typename result_of::transform<Sequence1 const, Sequence2 const, F>::type transform(
    Sequence1 const& seq1, Sequence2 const& seq2, F f);

表 1.69. 参数

参数

要求

说明

seq1

一个 前向序列 的模型

操作的参数

seq2

一个 前向序列 的模型

操作的参数

f

f(e1,e2) 对每一对元素 e1 (属于 seq1) 与 e2 (属于 seq2) 都是有效表达式. boost::result_of<F(E1,E2)>::type 是 f 以类型为 E1 和 E2 的元素调用时的返回类型

变换函数

返回类型: 一个 前向序列 的模型.

语义: 返回一个新序列, 包含 f(e1, e2) 对每一对元素 e1 和 e2 (分别属于 seq1 和 seq2) 的返回值.

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/transform.hpp>
#include <boost/fusion/include/transform.hpp>
示例 
struct triple
{
    typedef int result_type;

    int operator()(int t) const
    {
        return t * 3;
    };
};
...
assert(transform(make_vector(1,2,3), triple()) == make_vector(3,6,9));
