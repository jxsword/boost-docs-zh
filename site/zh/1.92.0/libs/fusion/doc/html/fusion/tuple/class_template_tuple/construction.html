Construction

说明

TR1 Tuple 类型提供了默认构造函数、为所有元素接受初始化值的构造函数、拷贝构造函数以及转换拷贝构造函数. 本节描述各种构造函数的细节.

规范

记法约定

T1 ... TN, U1 ... UN

元组元素类型

P1 ... PN

参数类型

Ti, Ui

元组第 i 个元素的类型

Pi

第 i 个参数的类型

tuple();

要求: 每个 Ti 都可默认构造.

语义: 对元组的每个元素进行默认初始化.

tuple(P1,P2,...,PN);

要求: 每个 Pi 是 Ti (当 Ti 是引用类型时), 否则是 const Ti&.

语义: 用对应参数拷贝初始化每个元素.

tuple(const tuple& t);

要求: 每个 Ti 都应可拷贝构造.

语义: 对 *this 的每个元素, 用 t 的对应元素进行拷贝构造.

template<typename U1, typename U2, ..., typename UN>
tuple(const tuple<U1, U2, ..., UN>& t);

要求: 每个 Ti 都必须能从对应的 Ui 构造.

语义: 对 *this 的每个元素, 用 t 的对应元素进行构造.
