back
说明

返回 back 的结果类型.

概要 
template<typename Seq>
struct back
{
    typedef unspecified type;
};

表 1.26. 参数

参数

要求

说明

Seq

一个 前向序列 的模型

实参序列

表达式语义 
result_of::back<Seq>::type

返回类型: 任意类型

语义: 解引用指向序列最后一个元素的迭代器所返回的类型. 等价于 result_of::deref<result_of::prior<result_of::end<Seq>::type>::type>::type.

头文件 
#include <boost/fusion/sequence/intrinsic/back.hpp>
#include <boost/fusion/include/back.hpp>
示例 
typedef vector<int,char> vec;
BOOST_MPL_ASSERT((boost::is_same<result_of::back<vec>::type, char&>));
