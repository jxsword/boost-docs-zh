BOOST_FUSION_ADAPT_ASSOC_STRUCT_NAMED

说明

BOOST_FUSION_ADAPT_ASSOC_STRUCT_NAMED 和 BOOST_FUSION_ADAPT_ASSOC_STRUCT_NAMED_NS 是两个宏, 可用于生成全部必要的样板代码, 使任意 struct 成为 随机访问序列 和 关联序列 的模型. 给定的 struct 将以给定名称进行适配.

概要 
BOOST_FUSION_ADAPT_ASSOC_STRUCT_NAMED(
    struct_name, adapted_name,
    ([member_type0,] member_name0, key_type0)
    ([member_type1,] member_name1, key_type1)
    ...
    )

BOOST_FUSION_ADAPT_ASSOC_STRUCT_NAMED_NS(
    struct_name,
    (namespace0)(namespace1)...,
    adapted_name,
    ([member_type0,] member_name0, key_type0)
    ([member_type1,] member_name1, key_type1)
    ...
    )
语义

上述宏生成必要的代码, 将 struct_name 适配为 随机访问序列 和 关联序列 的模型, 并以 adapted_name 作为被适配 struct 的名称. 序列 (namespace0)(namespace1)... 声明 adapted_name 的命名空间. 它为 adapted_name 生成带 namespace0::namespace1::... adapted_name 的全限定名. 若给定空的命名空间序列 (即展开为空的宏), 被适配视图将置于全局命名空间中. 若未给定命名空间序列 (即 BOOST_FUSION_ADAPT_STRUCT_ASSOC_NAMED), 被适配视图将置于命名空间 boost::fusion::adapted 中. (member_typeN, member_nameN, key_typeN) 三元组序列声明了序列中各 struct 成员的类型、名称和键类型.

当 member_typeN 省略或设为 auto 时, 类型通过 Boost.TypeOf 推断.

这些宏应在全局作用域使用, 且 struct_name 应为待转换 struct 的全命名空间限定名.

头文件 
#include <boost/fusion/adapted/struct/adapt_assoc_struct_named.hpp>
#include <boost/fusion/include/adapt_assoc_struct_named.hpp>
示例 
namespace demo
{
    struct employee
    {
        std::string name;
        int age;
    };
}

namespace keys
{
    struct name;
    struct age;
}

// boost::fusion::adapted::adapted_employee is now a Fusion sequence
// referring to demo::employee
BOOST_FUSION_ADAPT_ASSOC_STRUCT_NAMED(
    demo::employee, adapted_employee,
    (name, keys::name)
    (age, keys::age))

// Without BOOST_PP_VARIADICS support :
BOOST_FUSION_ADAPT_ASSOC_STRUCT_NAMED(
    demo::employee, adapted_employee,
    (auto, name, keys::name)
    (auto, age, keys::age))
