count_if
说明

给定序列和谓词类型时, 返回 count_if 的结果类型的元函数.

概要 
template<
    typename Sequence,
    typename Pred
    >
struct count_if
{
    typedef int type;
};

表 1.65. 参数

参数

要求

说明

Sequence

一个 前向序列 的模型

操作的参数

Pred

一个一元函数对象

操作的参数

表达式语义 
result_of::count_if<Sequence, Pred>::type

返回类型: int.

语义: 返回 count_if 的返回类型. 返回类型始终为 int.

复杂度

常量.

头文件 
#include <boost/fusion/algorithm/query/count_if.hpp>
#include <boost/fusion/include/count_if.hpp>
