make_cons
说明

创建一个 cons, 数据来自 car (head) 和可选的 cdr (tail).

概要 
template <typename Car>
typename result_of::make_cons<Car>::type
make_cons(Car const& car);

template <typename Car, typename Cdr>
typename result_of::make_cons<Car, Cdr>::type
make_cons(Car const& car, Cdr const& cdr);
参数

参数

要求

说明

car

Car 的实例

列表的头

cdr

Cdr 的实例

列表的尾 (可选)
表达式语义 
make_cons(car, cdr);

返回类型: result_of::make_cons<Car, Cdr>::type 或 result_of::make_cons<Car>::type

语义: 创建一个 cons, 数据来自 car (head) 和可选的 cdr (tail).

头文件 
#include <boost/fusion/container/generation/make_cons.hpp>
#include <boost/fusion/include/make_cons.hpp>
示例 
make_cons('x', make_cons(123))
