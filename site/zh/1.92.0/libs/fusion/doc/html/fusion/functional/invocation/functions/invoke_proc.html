invoke_procedure
说明

用一个 序列 中的实参调用一个 可调用对象. 调用的结果被忽略.

可以显式指定第一个模板参数, 以避免复制和/或控制函数对象的 const 限定.

对于指向类成员的指针, 相应对象可以以引用、指针或智能指针的形式指定. 对于最后一种情况, 必须定义一个独立的 get_pointer 函数 (Boost 为 std::auto_ptr 和 boost::shared_ptr 提供了该函数).

目标函数不得是指向成员对象的指针 (对这样的指针解引用而不返回任何东西没有意义, 因此未实现).

概要 
template<
    typename Function,
    class Sequence
    >
typename result_of::invoke_procedure<Function, Sequence>::type
invoke_procedure(Function f, Sequence & s);

template<
    typename Function,
    class Sequence
    >
typename result_of::invoke_procedure<Function, Sequence const>::type
invoke_procedure(Function f, Sequence const & s);
参数

参数

要求

说明

f

可调用对象 的模型

要调用的函数.

s

前向序列 的模型

实参.
表达式语义 
invoke_procedure(f,s);

返回类型: void

语义: 调用 f, 以 s 中的元素为实参.

头文件 
#include <boost/fusion/functional/invocation/invoke_procedure.hpp>
示例 
vector<int,int> v(1,2);
using namespace boost::lambda;
invoke_procedure(_1 += _2, v);
assert(front(v) == 3);
