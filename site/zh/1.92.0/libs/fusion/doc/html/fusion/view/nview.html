nview

说明

nview 呈现一个按指定顺序遍历给定 序列 的视图. nview 由任意 序列 和一个指定要遍历元素的索引列表构造而成.

头文件 
#include <boost/fusion/view/nview.hpp>
#include <boost/fusion/include/nview.hpp>
概要 
template <typename Sequence, typename Indices>
struct nview;

template <typename Sequence, int I1, int I2 = -1, ...>
typename result_of::nview<Sequence, I1, I2, ...>::type
as_nview(Sequence& s);
模板参数

参数

说明

默认值

Sequence

任意 Fusion 前向序列

Indices

一个 mpl::vector_c<int, ...>, 持有定义所需迭代顺序的索引.

I1, I2, I3...

一个指定所需迭代顺序的整数列表.

INT_MAX, 针对 I2、I3...
所属模型
  • 随机访问序列 (参见 序列遍历概念)

记法约定

NV

一个 nview 类型

s

Sequences 的一个实例

nv1, nv2

NV 的实例

表达式语义

仅当表达式的语义与 随机访问序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

NV(s)

给定一个序列和一个索引列表创建一个 nview.

NV(nv1)

拷贝构造一个 nview, 源为另一个 nview nv1.

nv1 = nv2

把一个 nview nv1 从另一个 nview nv2 赋值.

nview 内部保存一个 Fusion vector, 其中存放指向原 Fusion 序列 元素的引用

示例 
typedef vector<int, char, double> vec;
typedef mpl::vector_c<int, 2, 1, 0, 2, 0> indices;

vec v1(1, 'c', 2.0);

std::cout << nview<vec, indices>(v1) << std::endl; // (2.0 c 1 2.0 1)
std::cout << as_nview<2, 1, 1, 0>(v1) << std::endl; // (2.0 c c 1)
