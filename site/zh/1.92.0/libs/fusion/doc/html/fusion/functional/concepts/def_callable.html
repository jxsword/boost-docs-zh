延迟可调用对象

说明

能与 ResultOf utility 配合确定调用结果的 可调用对象 类型.

细化自
  • 可调用对象

注释: 一旦 C++ 支持 decltype 关键字, 所有 可调用对象 的模型也将成为 延迟可调用对象 的模型, 因为函数对象将不再需要客户端对 result_of 的支持.

记法约定

F

一个可能带 const 限定的延迟可调用对象类型

A1 ...AN

实参类型

a1 ...aN

具有 A1 ...AN 类型的对象或对象的引用

T1 ...TN

Ti 为 Ai &, 若 ai 是左值; 否则与 Ai 相同

表达式要求

表达式

类型

boost::result_of< F(T1 ...TN) >::type

以 A1 ...AN 类型实参调用的结果
模型
  • 多态函数对象 类型
  • 成员 (函数或数据) 指针类型
示例 
& a_free_function
& a_class::a_static_member_function
& a_class::a_nonstatic_data_member
& a_class::a_nonstatic_member_function
std::less<int>()
// using namespace boost;
bind(std::less<int>(), _1, 5)
// Note: Boost.Lambda expressions don't work with __boost_result_of__
fusion::make_fused_function_object(std::less<int>())
