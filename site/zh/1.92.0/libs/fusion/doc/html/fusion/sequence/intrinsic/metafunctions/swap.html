swap
说明

返回 swap 的返回类型.

概要 
template<typename Seq1, typename Seq2>
struct swap
{
    typedef void type;
};

表 1.35. 参数

参数

要求

说明

Seq1, Seq2

前向序列 的模型

被交换的序列

表达式语义 
result_of::swap<Seq1, Seq2>::type

返回类型: void, 当且仅当 Seq1 和 Seq2 都是序列; 否则为 none.

语义: 返回 swap 对类型为 Seq1 和 Seq2 的两个序列的返回类型.

头文件 
#include <boost/fusion/sequence/intrinsic/swap.hpp>
#include <boost/fusion/include/swap.hpp>
