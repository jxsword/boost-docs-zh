前向序列

说明

前向序列是元素按确定顺序排列的序列. 该顺序保证在多次迭代之间不会改变. 确定顺序的要求使得可以定义逐元素相等 (若容器的元素类型可相等比较) 和字典序 (若容器的元素类型可小于比较).

表达式语义

表达式

语义

begin(s)

指向序列第一个元素的迭代器; 参见 begin.

end(s)

序列的尾后迭代器; 参见 end.

size(s)

序列的大小; 参见 size.

empty(s)

一个布尔整型常量 c, 满足 c::value == true 当且仅当该序列为空; 参见 empty.

front(s)

序列中的第一个元素; 参见 front.
不变式

对任意前向序列 s, 以下不变式始终成立:

  • [begin(s), end(s)) 始终是一个有效区间.
  • 一个 算法, 它遍历区间 [begin(s), end(s)) 并恰好经过 s 的每个元素一次.
  • begin(s) 与 end(s)) 相同, 当且仅当 s 为空.
  • 对 s 的两次不同迭代将以相同顺序访问其元素.
