序列 Facade

说明

sequence_facade 模板提供了一个侵入式机制, 用于生成符合规范的 Fusion 序列.

概要 
template<typename Derived, typename TravesalTag, typename IsView = mpl::false_>
struct sequence_facade;
用法

sequence_facade 的使用者从 sequence_facade 的一个特化派生其序列类型, 并把派生的序列类型作为第一个模板参数传递. 第二个模板参数应为实现序列的遍历类别. 若序列是视图, 第三个参数应设为 mpl::true_.

使用者必须实现其序列类型所需的关键表达式.

表 1.106. 参数

名称

表达式

结果

sequence::template begin<Seq>::type

指向 Seq 类型序列开头的迭代器的类型

sequence::template begin<Seq>::call(seq)

指向序列 seq 开头的迭代器

sequence::template end<Seq>::type

指向 Seq 类型序列末尾的迭代器的类型

sequence::template end<Seq>::call(seq)

指向序列 seq 末尾的迭代器

sequence::template size<Seq>::type

Seq 类型序列的大小, 表示为一个 MPL 整型常量

sequence::template size<Seq>::call(seq)

序列 seq 的大小

sequence::template empty<Seq>::type

返回 mpl::true_, 条件是 Seq 没有元素; 否则返回 mpl::false_.

sequence::template empty<Seq>::call

返回一个可转换为 bool 的类型, 若序列为空则求值为 true, 否则求值为 false.

sequence::template at<Seq, N>::type

元素 N (位于 Seq 类型序列中) 的类型

sequence::template at<Seq, N>::call(seq)

元素 N (位于序列 seq 中)

sequence::template value_at<Sequence, N>::type

第 N 个元素 (位于 Seq 类型序列中) 的类型

包含
