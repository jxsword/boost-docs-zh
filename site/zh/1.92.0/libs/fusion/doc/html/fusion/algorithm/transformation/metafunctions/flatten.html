flatten
说明

给定输入序列类型时, 返回 flatten 的结果类型.

概要 
template<
    typename Sequence
    >
struct flatten
{
    typedef unspecified type;
};

表 1.105. 参数

参数

要求

说明

Sequence

一个 前向序列 的模型

操作的参数

表达式语义 
result_of::flatten<Sequence>::type

返回类型:

  • 一个 前向序列 的模型.

语义: 返回一个包含 Sequence 的所有叶子元素的序列.

复杂度

常量.

头文件 
#include <boost/fusion/algorithm/transformation/flatten.hpp>
#include <boost/fusion/include/flatten.hpp>
