reverse
说明

返回一个以逆序排列原序列元素的新序列.

概要 
template<
    typename Sequence
    >
typename result_of::reverse<Sequence const>::type reverse(Sequence const& seq);

表 1.74. 参数

参数

要求

说明

seq

一个 双向序列 的模型

操作的参数

表达式语义 
reverse(seq);

返回类型:

  • 一个 双向序列 的模型 (若 seq 是 双向序列); 否则, 为一个 随机访问序列 的模型 (若 seq 是 随机访问序列).
  • 一个 关联序列 的模型 (若 seq 实现了 关联序列 模型).

语义: 返回一个以逆序包含 seq 全部元素的新序列.

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/reverse.hpp>
#include <boost/fusion/include/reverse.hpp>
示例 
assert(reverse(make_vector(1,2,3)) == make_vector(3,2,1));
