insert_range
说明

返回一个在指定迭代器处插入了另一个序列的新序列.

概要 
template<
    typename Sequence,
    typename Pos,
    typename Range
    >
typename result_of::insert_range<Sequence const, Pos, Range>::type insert_range(
    Sequence const& seq, Pos const& pos, Range const& range);

表 1.79. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

pos

一个 前向迭代器 的模型

插入位置

range

一个 前向序列 的模型

要插入的范围

表达式语义 
insert_range(seq, pos, range);

返回类型:

  • 一个 前向序列 的模型.
  • 一个 关联序列 的模型 (若 seq 实现了 关联序列 模型).

语义: 返回一个新序列, 包含 seq 的全部元素, 以及 range 的元素 (插入于迭代器 pos 处). 所有元素都保持其在原序列中的顺序.

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/insert_range.hpp>
#include <boost/fusion/include/insert_range.hpp>
示例 
const vector<int,int> vec(1,2);
assert(insert_range(vec, next(begin(vec)), make_vector(3,4)) == make_vector(1,3,4,2));
