fused

说明

用于 延迟可调用对象 目标函数的一元 多态函数对象 适配器模板. 它接受一个 前向序列, 其中包含目标函数的实参.

目标函数的类型允许是 const 限定的或引用. const 限定会被恰当地保留和传播 (换言之, 对于 const 的目标函数对象只能使用 operator() 的 const 版本; 或者, 若目标函数对象按值保存, 则适配器为 const —— 这些语义与成员函数的 const 限定毫无关系, 后者指的是 this 所指对象的类型, 该类型由传给适配器的序列的第一个元素指定).

若目标函数是指向类成员的指针, 相应对象可以以引用、指针或智能指针的形式指定. 对于最后一种情况, 必须定义一个独立的 get_pointer 函数 (Boost 为 std::auto_ptr 和 boost::shared_ptr 提供了该函数).

头文件 
#include <boost/fusion/functional/adapter/fused.hpp>
概要 
template <typename Function>
class fused;
模板参数

参数

说明

默认值

Function

一个 延迟可调用对象

所属模型
  • 多态函数对象
  • 延迟可调用对象

记法约定

R

一个可能带 const 限定的 延迟可调用对象 类型或其引用类型

r

可转换为 R 的对象

s

一个 序列, 由 r 所接受的实参组成

f

fused<R> 的实例

表达式语义

表达式

语义

fused<R>(r)

如上所述创建一个 fused 函数, 用 r 初始化目标函数.

fused<R>()

如上所述创建一个 fused 函数, 尝试使用 R 的默认构造函数.

f(s)

调用 r, 以 s 中的元素为其实参.
示例 
fused< std::plus<long> > f;
assert(f(make_vector(1,2l)) == 3l);
