常规可调用对象

说明

一个非成员指针的 可调用对象 类型: 函数指针, 或者其对象可以立即出现在函数调用运算符左侧的类类型.

细化自
  • 可调用对象

记法约定

F

一个可能带 const 限定的延迟可调用对象类型

f

一个 F 类型的对象或对象的引用

A1 ...AN

实参类型

a1 ...aN

具有 A1 ...AN 类型的对象或对象的引用

表达式

返回类型

  • 各类函数对象
