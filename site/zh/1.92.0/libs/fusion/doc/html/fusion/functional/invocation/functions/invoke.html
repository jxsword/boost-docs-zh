invoke
说明

用一个 序列 中的实参调用一个 延迟可调用对象.

可以显式指定第一个模板参数, 以避免复制和/或控制函数对象的 const 限定.

若目标函数是指向类成员的指针, 相应对象可以以引用、指针或智能指针的形式指定. 对于最后一种情况, 必须定义一个独立的 get_pointer 函数 (Boost 为 std::auto_ptr 和 boost::shared_ptr 提供了该函数).

应用 Boost.Functional/Factory Library 可以调用构造函数.

概要 
template<
    typename Function,
    class Sequence
    >
typename result_of::invoke<Function, Sequence>::type
invoke(Function f, Sequence & s);

template<
    typename Function,
    class Sequence
    >
typename result_of::invoke<Function, Sequence const>::type
invoke(Function f, Sequence const & s);
参数

参数

要求

说明

f

一个 延迟可调用对象

要调用的函数.

s

一个 前向序列

实参.
表达式语义 
invoke(f,s);

返回类型: f 以 s 中的元素为实参调用时的返回类型.

语义: 调用 f, 以 s 中的元素为实参, 并返回该调用表达式的结果.

头文件 
#include <boost/fusion/functional/invocation/invoke.hpp>
示例 
std::plus<int> add;
assert(invoke(add,make_vector(1,1)) == 2);
