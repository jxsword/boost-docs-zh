as_map
说明

把一个 fusion 序列转换为 map.

概要 
template <typename Sequence>
typename result_of::as_map<Sequence>::type
as_map(Sequence& seq);

template <typename Sequence>
typename result_of::as_map<Sequence const>::type
as_map(Sequence const& seq);
参数

参数

要求

说明

seq

Sequence 的一个实例

要转换的序列.
表达式语义 
as_map(seq);

返回类型: result_of::as_map<Sequence>::type

语义: 把 fusion 序列 seq 转换为 map.

前置条件: 对于非关联序列, 元素被假定为 __fusion_pair__. 不得存在重复的 fusion::pair 键类型.

头文件 
#include <boost/fusion/container/map/convert.hpp>
#include <boost/fusion/include/as_map.hpp>
示例 
// from sequence of __fusion_pair__
as_map(make_vector(
    make_pair<int>('X')
  , make_pair<double>("Men")))

// from associative sequence
namespace ns
{
    struct x_member;
    struct y_member;
}
BOOST_FUSION_DEFINE_ASSOC_STRUCT(
    (ns),
    point,
    (int, x, ns::x_member)
    (int, y, ns::y_member)
)
...
as_map(ns::point(123, 456))
