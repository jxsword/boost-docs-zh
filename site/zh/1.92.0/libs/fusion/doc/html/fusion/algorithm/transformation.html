变换

函数
元函数

变换算法通过执行某种变换, 从既有序列创建新序列. 实际上, 新序列是原序列数据之上的视图.

注释

由于变换算法返回的是指向其输入实参的视图, 输入实参的生存期必须长于你希望使用结果的时期, 这一点非常重要.

头文件 
#include <boost/fusion/algorithm/transformation.hpp>
#include <boost/fusion/include/transformation.hpp>
