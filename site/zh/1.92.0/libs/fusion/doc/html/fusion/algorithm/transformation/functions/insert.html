insert
说明

返回一个新序列, 包含原序列的全部元素, 并在给定迭代器所描述的位置插入一个新元素.

概要 
template<
    typename Sequence,
    typename Pos,
    typename T
    >
typename result_of::insert<Sequence const, Pos, T>::type insert(
    Sequence const& seq, Pos const& pos, T const& t);

表 1.78. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

pos

一个 前向迭代器 的模型

插入位置

t

任意类型

要插入的值

表达式语义 
insert(seq, pos, t);

返回类型:

  • 一个 前向序列 的模型.

语义: 返回一个新序列, 按原顺序包含 seq 的全部元素, 并插入一个类型和值均为 t 的新元素于迭代器 pos 处.

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/insert.hpp>
#include <boost/fusion/include/insert.hpp>
示例 
const vector<int,int> vec(1,2);
assert(insert(vec, next(begin(vec)), 3) == make_vector(1,3,2));
