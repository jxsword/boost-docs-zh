关联序列

说明

关联序列允许基于键高效检索元素. 与 MPL 中的关联序列一样, 而与 STL 中的关联容器不同, Fusion 关联序列没有隐含的排序关系. 相反, 类型同一性被用来在键上施加等价关系. 键不检查唯一性.

注释

result_of::at_key<S, K> 返回 at_key<K>(s) 实际返回的类型. 在多数情况下, 这是一个引用. 因此, 无法用 result_of::at_key<S, K> 知道确切的元素类型. K 处的元素本身可能就是一个引用. 为此, 你可以使用 result_of::value_at_key<S, K>.

表达式语义

表达式

语义

has_key<K>(s)

一个布尔整型常量 c, 满足 c::value == true 当且仅当存在键为 k 的一个或多个元素, 位于 s 中; 参见 has_key.

at_key<K>(s)

与键 K 关联的元素 (位于序列 s 中); 参见 at.
模型
  • set
  • map
  • filter_view (其中被适配序列是 关联序列 和 前向序列)
  • iterator_range (其中被适配迭代器是 关联迭代器)
  • joint_view (其中被适配序列是 关联序列 和 前向序列)
  • reverse_view (其中被适配序列是 关联序列 和 双向序列)
  • transform_view (其中被适配序列是 关联序列 和 前向序列)
