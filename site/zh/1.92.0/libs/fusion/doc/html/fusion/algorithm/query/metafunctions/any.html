any
说明

返回 any 的结果类型的元函数.

概要 
template<
    typename Sequence,
    typename F
    >
struct any
{
    typedef bool type;
};

表 1.59. 参数

参数

要求

说明

Sequence

一个 前向序列 的模型

操作的参数

F

一个一元 多态函数对象 的模型

操作的参数

表达式语义 
result_of::any<Sequence, F>::type

返回类型: bool.

语义: 返回 any 给定类型为 Sequence 的序列和一元 多态函数对象 (其类型为 F) 时的返回类型. 返回类型始终为 bool.

复杂度

常量.

头文件 
#include <boost/fusion/algorithm/query/any.hpp>
#include <boost/fusion/include/any.hpp>
