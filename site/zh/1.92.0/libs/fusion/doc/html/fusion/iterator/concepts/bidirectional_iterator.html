双向迭代器

说明

双向迭代器遍历一个 序列, 允许每次沿任一方向移动一个元素.

记法约定

i

一个双向迭代器

I

一个双向迭代器类型

M

一个 MPL 整型常量

N

一个整型常量

细化自

前向迭代器

表达式语义

仅当表达式的语义与 前向迭代器 中的定义不同或未在其中定义时, 才给出其语义

表达式

语义

prior(i)

指向 i 前一个元素的迭代器
不变式

除 前向迭代器 的不变式外, 以下不变式始终成立:

  • prior(next(i)) == i && prior(next(i)) == next(prior(i))
  • prior(i) == advance_c<-1>(i)
  • 使用 prior 遍历序列绝不会返回之前见过的位置
模型
  • std::pair 迭代器
  • boost::array 迭代器
  • vector 迭代器
  • map 迭代器
  • single_view 迭代器
  • iterator_range (其中被适配序列是 双向序列)
  • transform_view (其中被适配序列是 双向序列)
  • reverse_view
