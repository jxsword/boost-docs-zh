pair

说明

Fusion 的 pair 类型是一个半运行期对. 半运行期对类似于 std::pair, 但与 std::pair 不同, 第一个类型不持有数据. 例如, 它被用作 map 的元素.

概要 
template <typename First, typename Second>
struct pair;

namespace result_of
{
    template <typename Pair>
    struct first;

    template <typename Pair>
    struct second;

    template <typename First, typename Second>
    struct make_pair;
}

template <typename First, typename Second>
typename result_of::make_pair<First,Second>::type
make_pair(Second const &);
模板参数

参数

说明

First

第一个类型. 它纯粹是类型, 不持有数据.

Second

第二个类型. 它包含数据.

记法约定

P

Fusion 对类型

p, p2

Fusion 对

F, S

任意类型

s

S 类型的值

o

输出流

i

输入流

表达式语义

表达式

语义

P::first_type

第一个模板参数的类型 F, 等价于 result_of::first<P>::type.

P::second_type

第二个模板参数的类型 S, 等价于 result_of::second<P>::type.

P()

默认构造.

P(s)

给定第二个类型的值 s 构造一个对.

P(p2)

从另一个对 p2 拷贝构造一个对.

p.second

从 p1 获取数据.

p = p2

把一个对 p1 从另一个对 p2 赋值.

make_pair<F>(s)

给定第一个类型 F 和第二个类型的值 s 构造一个对. 第二个类型采用 s 的类型

o << p

把 p 输出到输出流 o.

i >> p

读取 p, 来自输入流 i.

p == p2

测试两个对是否相等.

p != p2

测试两个对是否不等.
头文件 
#include <boost/fusion/support/pair.hpp>
#include <boost/fusion/include/pair.hpp>
示例 
pair<int, char> p('X');
std::cout << p << std::endl;
std::cout << make_pair<int>('X') << std::endl;
assert((p == make_pair<int>('X')));
