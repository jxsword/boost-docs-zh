元组辅助类

说明

TR1 Tuple 提供 2 个辅助特征, 用于在编译期访问元组大小和元素类型.

规范 
tuple_size<T>::value

要求: T 是任意 fusion 序列类型, 包括 tuple.

类型: MPL 整型常量

值: 序列中的元素个数. 等价于 result_of::size<T>::type.

tuple_element<I, T>::type

要求: T 是任意 fusion 序列类型, 包括 tuple. 必须满足 0 <= I < N, 否则程序为非良构.

值: 第 I 个元素 (位于 T 中) 的类型. 等价于 result_of::value_at<I,T>::type.
