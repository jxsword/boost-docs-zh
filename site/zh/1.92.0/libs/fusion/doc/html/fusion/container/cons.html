cons

说明

cons 是一个简单的 前向序列. 它是一种 lisp 风格的递归列表结构, 其中 car 是head (头), cdr 是tail (尾): 通常是另一个 cons 结构或 nil (空列表). Fusion 的 list 就构建在这个更原始的数据结构之上. 当目标序列逐个 (每次一个数据) 构造时, 它比 vector 更高效. 访问每个元素的运行期代价出奇地恒定 (参见 递归内联函数).

头文件 
#include <boost/fusion/container/list/cons.hpp>
#include <boost/fusion/include/cons.hpp>
概要 
template <typename Car, typename Cdr = nil>
struct cons;

表达式语义

仅当表达式的语义与 前向序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

nil()

创建一个空列表.

C()

创建一个元素为默认构造的 cons.

C(car)

创建一个头为 car、尾为默认构造的 cons.

C(car, cdr)

创建一个头为 car、尾为 cdr 的 cons.

C(s)

从一个 前向序列 拷贝构造一个 cons s.

l = s

把一个 cons l 从 前向序列 s 赋值.

at<N>(l)

从序列开头起的第 N 个元素; 参见 at.
注释

提供 at<N>(l) 是为了方便并与最初的 Boost.Tuple 库保持兼容, 尽管 cons 只是 前向序列 (at 本应是 随机访问序列 的要求). at 的运行期复杂度为常数 (参见 递归内联函数).

示例 
cons<int, cons<float> > l(12, cons<float>(5.5f));
std::cout << at_c<0>(l) << std::endl;
std::cout << at_c<1>(l) << std::endl;
