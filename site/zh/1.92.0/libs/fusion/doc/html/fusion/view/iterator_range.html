iterator_range

说明

iterator_range 呈现由一对迭代器界定的底层序列子区间.

头文件 
#include <boost/fusion/view/iterator_range.hpp>
#include <boost/fusion/include/iterator_range.hpp>
概要 
template <typename First, typename Last>
struct iterator_range;
模板参数

参数

说明

默认值

First

一个 fusion 迭代器

Last

一个 fusion 迭代器

所属模型
  • 前向序列、双向序列 或 随机访问序列, 取决于其底层序列的遍历特性 (参见 序列遍历概念).
  • 关联序列 (若 First 和 Last 实现了 关联迭代器 模型).

记法约定

IR

一个 iterator_range 类型

f

First 的一个实例

l

Last 的一个实例

ir, ir2

iterator_range 的实例

表达式语义

仅当表达式的语义与所实现模型中的定义不同或未在其中定义时, 才给出其语义.

表达式

语义

IR(f, l)

创建一个 iterator_range, 给定迭代器 f 和 l.

IR(ir)

拷贝构造一个 iterator_range, 源为另一个 iterator_range ir.

ir = ir2

把一个 iterator_range ir 从另一个 iterator_range ir2 赋值.
示例 
char const* s = "Ruby";
typedef vector<int, char, double, char const*> vector_type;
vector_type vec(1, 'x', 3.3, s);

typedef result_of::begin<vector_type>::type A;
typedef result_of::end<vector_type>::type B;
typedef result_of::next<A>::type C;
typedef result_of::prior<B>::type D;

C c(vec);
D d(vec);

iterator_range<C, D> range(c, d);
std::cout << range << std::endl;
