Operator !=

说明

比较 2 个迭代器是否不等.

概要 
template<
    typename I,
    typename J
    >
unspecified operator==(I const& i, J const& i);

表 1.10. 参数

参数

要求

说明

i, j

任意 fusion 迭代器

操作的参数

表达式语义

返回类型: 可转换为 bool.

语义: 等价于 !result_of::equal_to<I,J>::value, 其中 I 和 J 分别是 i 和 j 的类型.

头文件 
#include <boost/fusion/iterator/equal_to.hpp>
#include <boost/fusion/include/equal_to.hpp>
