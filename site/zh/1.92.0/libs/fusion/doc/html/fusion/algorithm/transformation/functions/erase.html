erase
说明

返回一个新序列, 包含原序列的全部元素, 但不含指定迭代器处或两个迭代器之间的元素.

概要 
template<
    typename Sequence,
    typename First
    >
typename result_of::erase<Sequence const, First>::type erase(
    Sequence const& seq, First const& it1);

template<
    typename Sequence,
    typename First,
    typename Last
    >
typename result_of::erase<Sequence const, First, Last>::type erase(
    Sequence const& seq, First const& it1, Last const& it2);

表 1.76. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

it1

一个 前向迭代器 的模型

指向 seq 内部的迭代器

it2

一个 前向迭代器 的模型

指向 seq 内部、位于 it1 之后的迭代器

表达式语义 
erase(seq, pos);

返回类型:

  • 一个 前向序列 的模型.
  • 一个 关联序列 的模型 (若 seq 实现了 关联序列 模型).

语义: 返回一个新序列, 包含 seq 的全部元素, 但不含 pos 处的元素.

erase(seq, first, last);

返回类型:

  • 一个 前向序列 的模型.
  • 一个 关联序列 的模型 (若 seq 实现了 关联序列 模型).

语义: 返回一个新序列, 按原顺序包含 seq 的全部元素, 但不含 [first,last) 范围内的元素.

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/erase.hpp>
#include <boost/fusion/include/erase.hpp>
示例 
const vector<int, double, char> vec(1, 2.0, 'c');
assert(erase(vec, next(begin(vec))) == make_vector(1, 'c'));
assert(erase(vec, next(begin(vec)), end(vec)) == make_vector(1));
