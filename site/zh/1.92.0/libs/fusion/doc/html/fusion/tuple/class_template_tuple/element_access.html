Element access

说明

TR1 Tuple 提供了 get 函数, 用于按从 0 开始的数字索引访问其元素.

规范 
template<int I, T>
RJ get(T& t);

要求: 0 < I <= N. 若 I 越界, 则程序为非良构. T 是任意 fusion 序列类型, 包括 tuple.

返回类型: RJ 等价于 result_of::at_c<I,T>::type.

返回: 对第 I 个元素 (位于 T 中) 的引用.

template<int I, typename T>
PJ get(T const& t);

要求: 0 < I <= N. 若 I 越界, 则程序为非良构. T 是任意 fusion 序列类型, 包括 tuple.

返回类型: PJ 等价于 result_of::at_c<I,T>::type.

返回: 对第 I 个元素 (位于 T 中) 的 const 引用.
