remove
说明

给定序列和移除类型时, 返回 remove 的结果类型.

概要 
template<
    typename Sequence,
    typename T
    >
struct remove
{
    typedef unspecified type;
};

表 1.93. 参数

参数

要求

说明

Sequence

一个 前向序列 的模型

操作的参数

T

任意类型

要移除此类型的元素

表达式语义 
result_of::remove<Sequence, T>::type

返回类型:

  • 一个 前向序列 的模型.
  • 一个 关联序列 的模型 (若 Sequence 实现了 关联序列 模型).

语义: 返回一个包含 Sequence 中非 T 类型元素的序列. 等价于 result_of::remove_if<Sequence, boost::is_same<mpl::_, T> >::type.

复杂度

常量.

头文件 
#include <boost/fusion/algorithm/transformation/remove.hpp>
#include <boost/fusion/include/remove.hpp>
