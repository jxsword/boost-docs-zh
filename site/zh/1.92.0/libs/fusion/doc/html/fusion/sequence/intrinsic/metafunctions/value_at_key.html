value_at_key
说明

返回 序列 中与键 Key 关联的实际元素类型.

概要 
template<
    typename Seq,
    typename Key>
struct value_at_key
{
    typedef unspecified type;
};

表 1.34. 参数

参数

要求

说明

Seq

关联序列 的模型

实参序列

Key

任意类型

键类型

表达式语义 
result_of::value_at_key<Seq, Key>::type

返回类型: 任意类型.

前置条件: has_key<Seq, Key>::type::value == true (其中 Seq 不是 无界序列)

语义: 返回键类型为 Key 的元素 (位于 Seq 中) 的实际元素类型.

头文件 
#include <boost/fusion/sequence/intrinsic/value_at_key.hpp>
#include <boost/fusion/include/value_at_key.hpp>
示例 
typedef map<pair<int, char>, pair<char, char>, pair<double, char> > mymap;
BOOST_MPL_ASSERT((boost::is_same<result_of::value_at_key<mymap, int>::type, char>));
