filter
说明

对于给定序列, filter 返回一个只包含指定类型元素的新序列.

概要 
template<
    typename T,
    typename Sequence
    >
typename result_of::filter<Sequence const, T>::type filter(Sequence const& seq);

表 1.66. 参数

参数

要求

说明

seq

一个 前向序列 的模型

操作的参数

T

任意类型

要保留的类型

表达式语义 
filter<T>(seq);

返回类型:

  • 一个 前向序列 的模型.
  • 一个 关联序列 的模型 (若 seq 实现了 关联序列 模型).

语义: 返回一个包含 seq 中所有类型为 T 的元素的序列. 等价于 filter_if<boost::same_type<_, T> >(seq).

复杂度

常数复杂度. 返回一个惰性求值的视图.

头文件 
#include <boost/fusion/algorithm/transformation/filter.hpp>
#include <boost/fusion/include/filter.hpp>
示例 
const vector<int,int,long,long> vec(1,2,3,4);
assert(filter<int>(vec) == make_vector(1,2));
