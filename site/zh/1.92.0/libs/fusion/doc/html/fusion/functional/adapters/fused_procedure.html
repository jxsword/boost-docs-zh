fused_procedure

说明

用于 可调用对象 目标函数的一元 多态函数对象 适配器模板. 它接受一个 前向序列, 其中包含目标函数的实参.

结果被丢弃, 适配器的返回类型为 void.

目标函数的类型允许是 const 限定的或引用. const 限定会被恰当地保留和传播 (换言之, 对于 const 的目标函数对象只能使用 operator() 的 const 版本; 或者, 若目标函数对象按值保存, 则适配器为 const —— 这些语义与成员函数的 const 限定毫无关系, 后者指的是 this 所指对象的类型, 该类型由传给适配器的序列的第一个元素指定).

若目标函数是指向成员函数的指针, 相应对象可以以引用、指针或智能指针的形式指定. 对于最后一种情况, 必须定义一个独立的 get_pointer 函数 (Boost 为 std::auto_ptr 和 boost::shared_ptr 提供了该函数).

目标函数不得是指向成员对象的指针 (对这样的指针解引用而不返回任何东西没有意义, 因此未实现这种情况).

表达式

语义

fused_procedure<R>(r)

如上所述创建一个 fused 函数, 用 r 初始化目标函数.

fused_procedure<R>()

如上所述创建一个 fused 函数, 尝试使用 R 的默认构造函数.

f(s)

调用 r, 以 s 中的元素为其实参.
示例 
template<class SequenceOfSequences, class Func>
void n_ary_for_each(SequenceOfSequences const & s, Func const & f)
{
    for_each(zip_view<SequenceOfSequences>(s),
        fused_procedure<Func const &>(f));
}

void try_it()
{
    vector<int,float> a(2,2.0f);
    vector<int,float> b(1,1.5f);
    using namespace boost::lambda;
    n_ary_for_each(vector_tie(a,b), _1 -= _2);
    assert(a == make_vector(1,0.5f));
}
