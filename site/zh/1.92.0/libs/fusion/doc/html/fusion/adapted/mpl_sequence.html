MPL 序列

本模块为 MPL 序列提供适配器. 包含模块头文件后, 所有 MPL 序列都将成为完全符合规范的 fusion 序列.

头文件 
#include <boost/fusion/adapted/mpl.hpp>
#include <boost/fusion/include/mpl.hpp>
所属模型
  • 前向序列 (若 MPL 序列是前向序列.)
  • 双向序列 (若 MPL 序列是双向序列.)
  • 随机访问序列 (若 MPL 序列是随机访问序列.)
示例 
mpl::vector_c<int, 123, 456> vec_c;
fusion::vector2<int, long> v(vec_c);
std::cout << at_c<0>(v) << std::endl;
std::cout << at_c<1>(v) << std::endl;

v = mpl::vector_c<int, 456, 789>();
std::cout << at_c<0>(v) << std::endl;
std::cout << at_c<1>(v) << std::endl;
双向适配

Fusion 序列也可以被适配为完全符合规范的 MPL 序列 (参见 内蕴函数). 这样, 我们可以在 MPL 与 Fusion 之间实现双向适配. 要使 Fusion 序列成为完全符合规范的 MPL 序列, 请包含:

#include <boost/fusion/mpl.hpp>

若要在 MPL 与 Fusion 之间实现双向适配, 只需包含:

#include <boost/fusion/include/mpl.hpp>

该头文件包含了所有必要的头文件.
