层级

层是所有元素皆为引用类型的序列. 它们通过调用若干 tie 函数模板来构造. 后续各节记录了各种 tier 形式.

  • list_tie
  • vector_tie
  • map_tie
  • deque_tie

示例:

int i; char c; double d;
  ...
vector_tie(i, c, d);

vector_tie 函数创建一个 vector, 其类型为 vector<int&, char&, double&>. 通过调用 make_vector(ref(i), ref(c), ref(d)) 也可以得到相同的结果 [11].

tie 可用于把另一个元组'解包'到变量中. 例如:

int i; char c; double d;
vector_tie(i, c, d) = make_vector(1,'a', 5.5);
std::cout << i << " " <<  c << " " << d;

这段代码向标准输出流打印 1 a 5.5. 类似的序列解包操作可见于 ML 和 Python 等语言. 在调用返回序列的函数时非常方便.

Ignore

还有一个名为 ignore 的对象, 允许你忽略序列赋值中的某个元素. 其设想是: 函数可能返回一个序列, 而你只对其中一部分感兴趣. 例如:

char c;
vector_tie(ignore, c) = make_vector(1, 'a');

[11] 参见 Ref utility 了解 ref 的详情
