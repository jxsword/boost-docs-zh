at_c
说明

返回从序列开头起的第 N 个元素.

概要 
template <int N, typename Sequence>
typename result_of::at_c<Sequence, N>::type
at_c(Sequence& seq);

template <int N, typename Sequence>
typename result_of::at_c<Sequence const, N>::type
at_c(Sequence const& seq);
参数

参数

要求

说明

seq

随机访问序列 的模型

我们要查看的序列.

N

一个整型常量

从序列开头起的索引.
表达式语义 
at_c<N>(seq);

返回类型: 返回对序列 seq 从开头起第 N 个元素的引用, 条件是 seq 可变且 e = o 是有效表达式 (其中 e 是从序列开头起的第 N 个元素); 否则返回一个可转换为从序列开头起第 N 个元素的类型.

前置条件: 0 <= N < size(seq) (其中 seq 不是 无界序列)

语义: 等价于

deref(advance<N>(begin(s)))
头文件 
#include <boost/fusion/sequence/intrinsic/at_c.hpp>
#include <boost/fusion/include/at_c.hpp>
示例 
vector<int, int, int> v(1, 2, 3);
assert(at_c<1>(v) == 2);
