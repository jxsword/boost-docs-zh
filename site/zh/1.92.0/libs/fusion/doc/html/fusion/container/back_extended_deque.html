back_extended_deque

说明

back_extended_deque 允许对 deque 进行后向扩展. 它与 deque 具有相同的性质.

头文件 
See deque
概要 
template <typename Deque, typename T>
struct back_extended_deque;
模板参数

参数

说明

默认值

Deque

deque 类型

T

元素类型
注释

Deque 可以是 deque、back_extended_deque 或 back_extended_deque

所属模型
  • 双向序列

记法约定

D

一个 back_extended_deque 类型

e

异构值

N

一个 MPL 整型常量

表达式语义

仅当表达式的语义与 双向序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

D(d, e)

扩展 d, 把 e 前插进去.

at<N>(d)

从序列开头起的第 N 个元素; 参见 at.
注释

更多细节参见 deque.

示例 
typedef deque<int, float> initial_deque;
initial_deque d(12, 5.5f);
back_extended_deque<initial_deque, int> d2(d, 999);
std::cout << at_c<0>(d2) << std::endl;
std::cout << at_c<1>(d2) << std::endl;
std::cout << at_c<2>(d2) << std::endl;
