BOOST_FUSION_DEFINE_ASSOC_TPL_STRUCT

说明

BOOST_FUSION_DEFINE_ASSOC_TPL_STRUCT 是一个宏, 可用于生成全部必要的样板代码, 定义任意模板 struct 并将其适配为 随机访问序列 和 关联序列 的模型.

概要 
BOOST_FUSION_DEFINE_ASSOC_TPL_STRUCT(
    (template_param0)(template_param1)...,
    (namespace0)(namespace1)...,
    struct_name,
    (member_type0, member_name0, key_type0)
    (member_type1, member_name1, key_type1)
    ...
    )

记法约定

Str

一个实例化的 struct_name

str

Str 的一个实例

e0...en

异构值

fs

一个 前向序列

表达式语义

上述宏生成必要的代码, 定义 struct_name 并将其适配为 随机访问序列 和 关联序列 的模型. 序列 (template_param0)(template_param1)... 声明所使用的模板类型参数的名称. 序列 (namespace0)(namespace1)... 声明 struct_name 的命名空间. 它为 struct_name 生成带 namespace0::namespace1::... struct_name 的全限定名. 若给定空的命名空间序列 (即展开为空的宏), 该 struct 将置于全局命名空间中. (member_typeN, member_nameN, key_typeN) 三元组序列声明了序列中各 struct 成员的类型、名称和键类型.

该宏应在全局作用域使用. 仅当表达式的语义与 随机访问序列 和 关联序列 中的定义不同或未在其中定义时, 才在此处给出其语义.

表达式

语义

Str()

创建一个 Str 的实例, 其元素为默认构造.

Str(e0, e1,... en)

创建一个 Str 的实例, 元素为 e0...en.

Str(fs)

拷贝构造一个 Str 实例, 数据来源为一个 前向序列 fs.

str = fs

从 前向序列 fs 赋值.

str.member_nameN

访问 struct 成员 member_nameN

头文件 
#include <boost/fusion/adapted/struct/define_assoc_struct.hpp>
#include <boost/fusion/include/define_assoc_struct.hpp>
示例 
namespace keys
{
    struct name;
    struct age;
}

// Any instantiated demo::employee is a Fusion sequence
BOOST_FUSION_DEFINE_ASSOC_TPL_STRUCT(
    (Name)(Age), (demo), employee,
    (Name, name, keys::name)
    (Age, age, keys::age))
