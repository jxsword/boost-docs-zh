zip
说明

把多个序列 zip 到一起, 形成一个单一序列, 其成员是各成员序列的元素组成的元组.

概要 
template<
    typename Sequence1,
    typename Sequence2,
    ...
    typename SequenceN
    >
struct zip
{
    typedef unspecified type;
};
表达式语义 
result_of::zip<Sequence1, Sequence2, ... SequenceN>::type

返回类型: 序列 Sequence1 到 SequenceN 中最具限制性的遍历类别的模型.

语义: 返回一个包含来自每个序列的元素所组成元组的序列. 例如, 对元组 (1, 2, 3) 和 ('a', 'b', 'c') 应用 zip 将返回 ((1, 'a'),(2, 'b'),(3, 'c'))

复杂度

常量.

头文件 
#include <boost/fusion/algorithm/transformation/zip.hpp>
#include <boost/fusion/include/zip.hpp>
