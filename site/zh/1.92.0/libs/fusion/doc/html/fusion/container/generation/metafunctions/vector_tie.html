vector_tie
说明

返回 vector_tie 的结果类型.

概要 
template <typename T0, typename T1,... typename TN>
struct vector_tie;

对于 C++11 编译器, 可变参数函数接口没有上限.

对于 C++03 编译器, 可变参数函数接受 0 到 FUSION_MAX_VECTOR_SIZE 个元素, 其中 FUSION_MAX_VECTOR_SIZE 是用户可定义的预定义最大值, 默认为 10. 可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_VECTOR_SIZE 来更改默认值. 示例:

#define FUSION_MAX_VECTOR_SIZE 20
参数

参数

要求

说明

T0, T1,... TN

任意类型

vector_tie 的实参
表达式语义 
result_of::vector_tie<T0, T1,... TN>::type;

返回类型: vector<T0&, T1&,... TN&>

语义: 创建一个引用组成的 vector, 其引用来自 T0, T1,... TN.

头文件 
#include <boost/fusion/container/generation/vector_tie.hpp>
#include <boost/fusion/include/vector_tie.hpp>
示例 
result_of::vector_tie<int, double>::type
