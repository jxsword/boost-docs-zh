deduce

说明

对完整实参类型应用 element conversion 的元函数.

它会移除对 const 的引用; 对数组类型的引用会被保留, 即使数组是 const. 引用包装器会被移除 (参见 Reference Wrappers)[5].

头文件 
#include <boost/fusion/support/deduce.hpp>
#include <boost/fusion/include/deduce.hpp>
概要 
namespace traits
{
    template <typename T>
    struct deduce
    {
        typedef unspecified type;
    };
}
示例 
template <typename T>
struct holder
{
    typename traits::deduce<T const &>::type element;

    holder(T const & a)
      : element(a)
    { }
};

template <typename T>
holder<T> make_holder(T const & a)
{
    return holder<T>(a);
}
参见
  • deduce_sequence

[5] 自 C++11 起, 标准引用包装器也会被移除.
