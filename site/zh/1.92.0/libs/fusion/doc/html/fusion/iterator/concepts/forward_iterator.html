前向迭代器

说明

前向迭代器遍历一个 序列, 只允许沿一个方向逐个移动其元素.

表达式

语义

next(i)

指向 i 后一个元素的迭代器

位置 i 处的元素

*i

等价于 deref(i)

不变式

以下不变式始终成立:

  • !(i == j) == (i != j)
  • next(i) == advance_c<1>(i)
  • distance(i, advance_c<N>(i)) == N
  • 使用 next 遍历该序列绝不会回到之前见过的位置
  • deref(i) 等价于 *i
  • 若 i == j, 则 *i 等价于 *j
