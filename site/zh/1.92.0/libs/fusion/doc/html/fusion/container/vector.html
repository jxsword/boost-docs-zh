vector

说明

vector 是一个由异构类型数据组成的 随机访问序列, 其结构为一个简单的 struct, 每个元素都作为成员变量保存. vector 是 Fusion 序列容器中最简单的 (含 N 个元素的 vector 就是一个有 N 个成员的 struct), 而且在许多情况下也是最高效的.

概要

编号形式 

struct vector0;

template <typename T0>
struct vector1;

template <typename T0, typename T1>
struct vector2;

template <typename T0, typename T1, typename T2>
struct vector3;

...

template <typename T0, typename T1, typename T2..., typename TN>
struct vectorN;
重要

编号形式在 C++11 中将被弃用, 并将经由别名模板提供. 这意味着你的特化可能变成编译错误. 可以使用 BOOST_FUSION_HAS_VARIADIC_VECTOR 检测它是否为别名模板.

可变参数形式 

template <
    typename T0 = unspecified
  , typename T1 = unspecified
  , typename T2 = unspecified
    ...
  , typename TN = unspecified
>
struct vector;

编号形式接受确切数量的元素. 示例:

vector3<int, char, double>

对于 C++11 编译器, 可变参数函数接口没有上限.

对于 C++03 编译器, 可变参数形式接受 0 到 FUSION_MAX_VECTOR_SIZE 个元素, 其中 FUSION_MAX_VECTOR_SIZE 是用户可定义的预定义最大值, 默认为 10. 示例:

vector<int, char, double>

可以在包含任何 Fusion 头文件之前定义预处理器常量 FUSION_MAX_VECTOR_SIZE 来更改默认值. 示例:

#define FUSION_MAX_VECTOR_SIZE 20

表达式语义

表达式

语义

V()

创建一个元素为默认构造的 vector.

V(e0, e1,... en)

创建一个元素为 e0...en 的 vector.

V(s)

从一个 前向序列 拷贝构造一个 vector s.

v = s

把一个 vector v 从 前向序列 s 赋值.
示例 
vector<int, float> v(12, 5.5f);
std::cout << at_c<0>(v) << std::endl;
std::cout << at_c<1>(v) << std::endl;
