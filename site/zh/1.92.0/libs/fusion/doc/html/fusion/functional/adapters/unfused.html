unfused

说明

用于一元 多态函数对象 目标函数的 n 元 多态函数对象 适配器模板. 调用时, 其实参被捆绑成一个由引用组成的 随机访问序列, 传递给目标函数对象.

把第二个模板参数设为 false 即可移除调用运算符的零元重载. 当结果类型计算会产生编译错误时, 这非常有用 (零元调用运算符的原型不能是模板, 因此会在类模板实例化的同时被实例化).

只接受左值实参. 要突破这一限制, 请应用 Boost.Functional/Forward Library.

目标函数的类型允许是 const 限定的或引用. const 限定会被恰当地保留和传播. 换言之, 若目标函数对象为 const, 则只能使用 operator() 的 const 版本 —— 或者, 若目标函数对象按值保存, 则适配器为 const.

头文件 
#include <boost/fusion/functional/adapter/unfused.hpp>

语义

示例 
struct fused_incrementer
{
    template <class Seq>
    struct result
    {
        typedef void type;
    };

    template <class Seq>
    void operator()(Seq const & s) const
    {
        for_each(s,++boost::lambda::_1);
    }
};

void try_it()
{
    unfused<fused_incrementer> increment;
    int a = 2; char b = 'X';
    increment(a,b);
    assert(a == 3 && b == 'Y');
}
