关系运算符

说明

TR1 Tuple 提供标准的布尔关系运算符.

规范

记法约定

T1 ... TN, U1 ... UN

元组元素类型

P1 ... PN

参数类型

Ti, Ui

元组第 i 个元素的类型

Pi

第 i 个参数的类型

template<typename T1, typename T2, ..., typename TN,
         typename U1, typename U2, ..., typename UN>
bool operator==(
    const tuple<T1, T2, ..., TN>& lhs,
    const tuple<U1, U2, ..., UN>& rhs);

要求: 对所有 i 和 1 <= i < N, get<i>(lhs) == get<i>(rhs) 都是返回可转换为 bool 类型的有效表达式.

语义: 返回 true, 当且仅当 get<i>(lhs) == get<i>(rhs) 对所有 i 成立. 对任意两个长度为零的元组 e 和 f, e == f 返回 true.

template<typename T1, typename T2, ..., typename TN,
         typename U1, typename U2, ..., typename UN>
bool operator<(
    const tuple<T1, T2, ..., TN>& lhs,
    const tuple<U1, U2, ..., UN>& rhs);

要求: 对所有 i 和 1 <= i < N, get<i>(lhs) < get<i>(rhs) 都是返回可转换为 bool 类型的有效表达式.

语义: 返回 lhs 与 rhs 之间的字典序比较结果.

template<typename T1, typename T2, ..., typename TN,
         typename U1, typename U2, ..., typename UN>
bool operator!=(
    const tuple<T1, T2, ..., TN>& lhs,
    const tuple<U1, U2, ..., UN>& rhs);

要求: 对所有 i 和 1 <= i < N, get<i>(lhs) == get<i>(rhs) 都是返回可转换为 bool 类型的有效表达式.

语义: 返回 !(lhs == rhs).

template<typename T1, typename T2, ..., typename TN,
         typename U1, typename U2, ..., typename UN>
bool operator<=(
    const tuple<T1, T2, ..., TN>& lhs,
    const tuple<U1, U2, ..., UN>& rhs);

要求: 对所有 i 和 1 <= i < N, get<i>(rhs) < get<i>(lhs) 都是返回可转换为 bool 类型的有效表达式.

语义: 返回 !(rhs < lhs) 

template<typename T1, typename T2, ..., typename TN,
         typename U1, typename U2, ..., typename UN>
bool operator>(
    const tuple<T1, T2, ..., TN>& lhs,
    const tuple<U1, U2, ..., UN>& rhs);

要求: 对所有 i 和 1 <= i < N, get<i>(rhs) < get<i>(lhs) 都是返回可转换为 bool 类型的有效表达式.

语义: 返回 rhs < lhs.

template<typename T1, typename T2, ..., typename TN,
         typename U1, typename U2, ..., typename UN>
bool operator>=(
    const tuple<T1, T2, ..., TN>& lhs,
    const tuple<U1, U2, ..., UN>& rhs);

要求: 对所有 i 和 1 <= i < N, get<i>(lhs) < get<i>(rhs) 都是返回可转换为 bool 类型的有效表达式.

语义: 返回 !(lhs < rhs).
