is_view

说明

一个元函数, 求值为 mpl::true_ (当某类型 T 是符合规范的 Fusion 视图 时), 否则为 mpl::false_. 视图是一种并不实际包含数据的特化序列. 视图持有的序列也可以是其他视图. 一般来说, 视图被其他视图按值持有, 而非视图被其他视图按引用持有. is_view 可以被特化, 以容纳提供符合规范的 Fusion 视图的客户.

概要 
namespace traits
{
    template <typename T>
    struct is_view
    {
        typedef unspecified type;
    };
}
参数

参数

要求

说明

T

任意类型

要查询的类型.
表达式语义 
typedef traits::is_view<T>::type c;

返回类型: 一个 MPL 布尔常量.

语义: 一个元函数, 求值为 mpl::true_ (当某类型 T 是符合规范的 fusion 视图时), 否则为 mpl::false_.

头文件 
#include <boost/fusion/support/is_view.hpp>
#include <boost/fusion/include/is_view.hpp>
示例 
BOOST_MPL_ASSERT_NOT(( traits::is_view<std::vector<int> > ));
BOOST_MPL_ASSERT_NOT(( traits::is_view<int> ));

using boost::mpl::_
using boost::is_pointer;
typedef vector<int*, char, long*, bool, double> vector_type;
typedef filter_view<vector_type, is_pointer<_> > filter_view_type;
BOOST_MPL_ASSERT(( traits::is_view<filter_view_type> ));
