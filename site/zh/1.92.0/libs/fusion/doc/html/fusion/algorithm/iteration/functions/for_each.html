for_each
说明

对序列的每个元素应用一元函数对象.

概要 
template<
    typename Sequence,
    typename F
    >
typename result_of::for_each<Sequence, F>::type for_each(
    Sequence& seq, F f);

表 1.45. 参数

参数

要求

说明

seq

一个 前向序列 的模型, f(e) 必须对每个元素都是有效表达式, 该元素 e 取自 seq

操作的参数

f

一个一元 常规可调用对象

操作的参数

表达式语义 
for_each(seq, f);

返回类型: void

语义: 对每个元素调用 f(e), 该元素 e 取自 seq.

复杂度

线性复杂度, 恰好应用 result_of::size<Sequence>::value 次 f.

头文件 
#include <boost/fusion/algorithm/iteration/for_each.hpp>
#include <boost/fusion/include/for_each.hpp>
示例 
struct increment
{
    template<typename T>
    void operator()(T& t) const
    {
        ++t;
    }
};
...
vector<int,int> vec(1,2);
for_each(vec, increment());
assert(vec == make_vector(2,3));
