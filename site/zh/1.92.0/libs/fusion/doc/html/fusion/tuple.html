TR1 技术报告描述了对 C++ 标准库的扩展. 其中许多扩展将被纳入 C++ 标准的下一版考量. TR1 描述了一个元组类型, 并支持把 std::pair 当作一种元组类型.

Fusion 完整支持 TR1 Tuple 接口, 以及 TR1 文档中描述的 std::pair 的扩展用法.
