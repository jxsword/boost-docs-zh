any
说明

对于序列 seq 和一元函数对象 f, any 在 f 对 seq 的至少一个元素返回 true 时返回 true.

概要 
template<
    typename Sequence,
    typename F
    >
typename result_of::any<Sequence,F>::type any(
    Sequence const& seq, F f);

表 1.52. 参数

参数

要求

说明

seq

一个 前向序列 的模型, f(e) 对每个元素必须是有效表达式且可转换为 bool, 该元素 e 取自 seq

要搜索的序列

f

一个一元函数对象

搜索谓词

Expression semantics 
any(seq, f);

返回类型: bool

语义: 当且仅当 f(e) 对某个元素求值为 true (该元素 e 取自 seq) 时, 返回 true.

复杂度

线性复杂度. 至多进行 result_of::size<Sequence>::value 次比较.

头文件 
#include <boost/fusion/algorithm/query/any.hpp>
#include <boost/fusion/include/any.hpp>
示例 
struct odd
{
    template<typename T>
    bool operator()(T t) const
    {
        return t % 2;
    }
};
...
assert(any(make_vector(1,2), odd()));
assert(!any(make_vector(2,4), odd()));
