哈希特征

<boost/unordered/hash_traits.hpp> 概要

#include <boost/container_hash/hash_is_avalanching.hpp>

namespace boost {
namespace unordered {

using boost::hash_is_avalanching;

} // namespace unordered
} // namespace boost
注释:

此头文件已弃用. 请改用 boost::hash_is_avalanching, 其定义于 <boost/container_hash/hash_is_avalanching.hpp>.

开放寻址容器和并发容器按原样使用所提供的哈希函数 Hash, 条件是 hash_is_avalanching<Hash>::value 为 true; 否则, 它们实现一个位混合后处理阶段, 以额外的计算开销为代价提高哈希质量.
