基准测试

boost::unordered_[multi]set

所有基准测试均使用 unordered_set<unsigned int> (非重复) 和 unordered_multiset<unsigned int> (重复) 创建. 源代码可在 此处 获取.

插入基准测试插入 n 个随机值, 其中 n 介于 10,000 到 300 万之间. 对于重复值基准测试, 相同的随机值平均重复 5 次.

擦除基准测试随机擦除全部 n 个元素, 直到容器为空. 按键擦除使用 erase(const key_type&) 在每次操作中移除整组等价元素.

成功查找基准测试按原始插入顺序查找全部 n 个值.

失败查找基准测试使用 n 个随机生成的整数, 但使用了不同的种子值.

boost::concurrent_(flat|node)_map

所有基准测试均使用以下配置创建:

  • oneapi::tbb::concurrent_hash_map<int, int>

  • gtl::parallel_flat_hash_map<int, int> (含 64 个子映射)

  • boost::concurrent_flat_map<int, int>

  • boost::concurrent_node_map<int, int>

源代码可在 此处 获取.

基准测试运行若干线程 T (介于 1 到 16 之间), 并发执行从 更新、成功查找 和 失败查找 中随机选择的操作. 操作中使用的键服从 Zipf 分布, 其 偏斜 参数各不相同: 偏斜度越高, 键越集中在覆盖范围的较低取值上.

boost::concurrent_flat_map 和 boost::concurrent_node_map 同时以常规和 批量访问 两种方式进行测试: 在后一种方式下, 查找键先缓冲到本地数组中, 每当缓冲区达到 bulk_visit_size 时再一次性处理.
