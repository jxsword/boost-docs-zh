类模板 unordered_multimap

boost::unordered_multimap——一种将键与另一个值关联起来的无序关联容器. 同一个键可以存储多次.

概要

// #include <boost/unordered/unordered_map.hpp>

namespace boost {
namespace unordered {

  template<class Key,
           class T,
           class Hash = boost::hash<Key>,
           class Pred = std::equal_to<Key>,
           class Allocator = std::allocator<std::pair<const Key, T>>>
  class unordered_multimap {
  public:
    // types
    using key_type             = Key;
    using mapped_type          = T;
    using value_type           = std::pair<const Key, T>;
    using hasher               = Hash;
    using key_equal            = Pred;
    using allocator_type       = Allocator;
    using pointer              = typename std::allocator_traits<Allocator>::pointer;
    using const_pointer        = typename std::allocator_traits<Allocator>::const_pointer;
    using reference            = value_type&;
    using const_reference      = const value_type&;
    using size_type            = std::size_t;
    using difference_type      = std::ptrdiff_t;

    using iterator             = implementation-defined;
    using const_iterator       = implementation-defined;
    using local_iterator       = implementation-defined;
    using const_local_iterator = implementation-defined;
    using node_type            = implementation-defined;

    // construct/copy/destroy
    unordered_multimap();
    explicit unordered_multimap(size_type n,
                                const hasher& hf = hasher(),
                                const key_equal& eql = key_equal(),
                                const allocator_type& a = allocator_type());
    template<class InputIterator>
      unordered_multimap(InputIterator f, InputIterator l,
                         size_type n = implementation-defined,
                         const hasher& hf = hasher(),
                         const key_equal& eql = key_equal(),
                         const allocator_type& a = allocator_type());
    unordered_multimap(const unordered_multimap& other);
    unordered_multimap(unordered_multimap&& other);
    template<class InputIterator>
      unordered_multimap(InputIterator f, InputIterator l, const allocator_type& a);
    explicit unordered_multimap(const Allocator& a);
    unordered_multimap(const unordered_multimap& other, const Allocator& a);
    unordered_multimap(unordered_multimap&& other, const Allocator& a);
    template<class FromRangeT, container-compatible-range<value_type> R>
      unordered_multimap(FromRangeT&&, R&& rg,
                    size_type n = implementation-defined,
                    const hasher& hf = hasher(),
                    const key_equal& eql = key_equal(),
                    const allocator_type& a = allocator_type());
    unordered_multimap(std::initializer_list<value_type> il,
                       size_type n = implementation-defined,
                       const hasher& hf = hasher(),

                       const allocator_type& a = allocator_type());
    unordered_multimap(size_type n, const allocator_type& a);

      unordered_multimap(InputIterator f, InputIterator l, size_type n, const allocator_type& a);

      unordered_multimap(InputIterator f, InputIterator l, size_type n, const hasher& hf,

    template<class FromRangeT, container-compatible-range<value_type> R>
      unordered_multimap(FromRangeT&&, R&& rg, const allocator_type& a);
    template<class FromRangeT, container-compatible-range<value_type> R>
      unordered_multimap(FromRangeT&&, R&& rg, size_type n, const allocator_type& a);
    template<class FromRangeT, container-compatible-range<value_type> R>
      unordered_multimap(FromRangeT&&, R&& rg, size_type n, const hasher& hf,

    unordered_multimap(std::initializer_list<value_type> il, const allocator_type& a);
    unordered_multimap(std::initializer_list<value_type> il, size_type n,

    unordered_multimap(std::initializer_list<value_type> il, size_type n, const hasher& hf,
                       const allocator_type& a);

    unordered_multimap& operator=(unordered_multimap&& other)

               boost::is_nothrow_move_assignable_v<Hash> &&

    unordered_multimap& operator=(std::initializer_list<value_type> il);
    allocator_type get_allocator() const noexcept;

    // iterators
    iterator       begin() noexcept;
    const_iterator begin() const noexcept;
    iterator       end() noexcept;

    const_iterator cbegin() const noexcept;
    const_iterator cend() const noexcept;

    [[nodiscard]] bool empty() const noexcept;
    size_type size() const noexcept;
    size_type max_size() const noexcept;

    template<class... Args> iterator emplace(Args&&... args);
    template<class... Args> iterator emplace_hint(const_iterator position, Args&&... args);
    iterator insert(const value_type& obj);
    iterator insert(value_type&& obj);

    node_type extract(const_iterator position);

    void      quick_erase(const_iterator position);
    void      erase_return_void(const_iterator position);
    void      swap(unordered_multimap& other)
      noexcept(boost::allocator_traits<Allocator>::is_always_equal::value &&
               boost::is_nothrow_swappable_v<Hash> &&
               boost::is_nothrow_swappable_v<Pred>);
    void      clear() noexcept;

    template<class H2, class P2>
      void merge(unordered_multimap<Key, T, H2, P2, Allocator>& source);
    template<class H2, class P2>
      void merge(unordered_multimap<Key, T, H2, P2, Allocator>&& source);
    template<class H2, class P2>
      void merge(unordered_map<Key, T, H2, P2, Allocator>& source);
    template<class H2, class P2>
      void merge(unordered_map<Key, T, H2, P2, Allocator>&& source);

    // observers
    hasher hash_function() const;
    key_equal key_eq() const;

    // map operations
    iterator         find(const key_type& k);
    const_iterator   find(const key_type& k) const;
    template<class K>
      iterator       find(const K& k);
    template<class K>
      const_iterator find(const K& k) const;
    template<typename CompatibleKey, typename CompatibleHash, typename CompatiblePredicate>
      iterator       find(CompatibleKey const& k, CompatibleHash const& hash,

    template<typename CompatibleKey, typename CompatibleHash, typename CompatiblePredicate>
      const_iterator find(CompatibleKey const& k, CompatibleHash const& hash,

    size_type        count(const key_type& k) const;
    template<class K>
      size_type      count(const K& k) const;
    bool             contains(const key_type& k) const;
    template<class K>
      bool           contains(const K& k) const;
    std::pair<iterator, iterator>               equal_range(const key_type& k);
    std::pair<const_iterator, const_iterator>   equal_range(const key_type& k) const;
    template<class K>
      std::pair<iterator, iterator>             equal_range(const K& k);
    template<class K>
      std::pair<const_iterator, const_iterator> equal_range(const K& k) const;

    // bucket interface
    size_type bucket_count() const noexcept;
    size_type max_bucket_count() const noexcept;
    size_type bucket_size(size_type n) const;
    size_type bucket(const key_type& k) const;
    template<class K> size_type bucket(const K& k) const;
    local_iterator begin(size_type n);
    const_local_iterator begin(size_type n) const;
    local_iterator end(size_type n);
    const_local_iterator end(size_type n) const;

    const_local_iterator cend(size_type n) const;

    // hash policy
    float load_factor() const noexcept;
    float max_load_factor() const noexcept;
    void max_load_factor(float z);
    void rehash(size_type n);
    void reserve(size_type n);
  };

说明

模板参数

Key

Key 必须可从容器中 Erasable (即 allocator_traits 可以销毁它).

T

T 必须可从容器中 Erasable (即 allocator_traits 可以销毁它).

Hash

一种一元函数对象类型, 充当 Key 的哈希函数. 它接受一个 Key 类型的参数, 并返回一个 std::size_t 类型的值.

Pred

一种在 Key 类型的值上实现等价关系的二元函数对象. 一种在 Key 类型的值上定义等价关系的二元函数对象. 它接受两个 Key 类型的参数并返回 bool 类型的值.

Allocator

一种 value_type 与容器的 value_type 相同的分配器. 支持使用 花式指针 的分配器.

元素被组织到桶中. 具有相同哈希码的键存储在同一个桶中.

桶数量可以通过调用 insert 自动增加, 或者作为调用 rehash 的结果而增加.

配置宏

BOOST_UNORDERED_ENABLE_SERIALIZATION_COMPATIBILITY_V0

全局定义此宏以支持载入保存在 Boost.Serialization 档案中、且由 Boost 1.84 之前版本的 Boost 所保存的 unordered_multimap.

typedef

typedef implementation-defined iterator;

一种 value_type 为 value_type 的迭代器.

迭代器类别至少为前向迭代器.

可转换为 const_iterator.

typedef implementation-defined const_iterator;

一种 value_type 为 value_type 的常量迭代器.

迭代器类别至少为前向迭代器.

typedef implementation-defined local_iterator;

一种与 iterator 具有相同 value_type、difference_type、指针和引用类型的迭代器.

local_iterator 对象可用于遍历单个桶.

typedef implementation-defined const_local_iterator;

一种与 const_iterator 具有相同 value_type、difference_type、指针和引用类型的常量迭代器.

const_local_iterator 对象可用于遍历单个桶.

typedef implementation-defined node_type;

详情参见 node_handle_map.

container-compatible-range

template<class R, class T>
  concept container_compatible_range =
    std::ranges::input_range<R> &&
    std::convertible_to<std::ranges::range_reference_t<R>, T>; // exposition only

unordered_multimap();

构造一个空容器, 使用 hasher() 作为哈希函数, key_equal() 作为键相等谓词, allocator_type() 作为分配器, 最大负载因子为 1.0.

后置条件:

size() == 0

template<class H2, class P2>

  void merge(unordered_map<Key, T, H2, P2, Allocator>&& source);

尝试 "合并" 两个容器: 遍历 source, 提取 source 中的所有节点并插入 *this.

由于 source 可能具有不同的哈希函数和键相等谓词, source 中每个节点的键会使用 this->hash_function() 重新哈希, 然后在需要时使用 this->key_eq() 进行比较.

如果 this->get_allocator() != source.get_allocator(), 此函数的行为是未定义的.

此函数不复制或移动任何元素, 而只是将节点从 source 转移到 *this.

注释:

  • 指向被转移元素的指针和引用保持有效.

  • 使指向被转移元素的迭代器失效.

  • 使属于 *this 的迭代器失效.

  • 指向 source 中未被转移元素的迭代器保持有效.

推导指引

如果以下任一条件为真, 推导指引将不参与重载决议:

  • 它有一个 InputIterator 模板参数, 但为该参数推导出的类型不符合输入迭代器 (input iterator) 的条件.

  • 它有一个 Allocator 模板参数, 但为该参数推导出的类型不符合分配器 (allocator) 的条件.

  • 它有一个 Hash 模板参数, 但为该参数推导出的类型是整数类型, 或符合分配器 (allocator) 的条件.

  • 它有一个 Pred 模板参数, 但为该参数推导出的类型符合分配器 (allocator) 的条件.

推导指引中的 size_­type 参数类型指向由该推导指引推导出的容器类型的 size_­type 成员类型. 其默认值与所选构造函数的默认值一致.

    typename std::iterator_traits<InputIterator>::value_type; // exposition only

    std::tuple_element_t<0, iter-value-type<InputIterator>>>; // exposition only

相等比较

operator==

template<class Key, class T, class Hash, class Pred, class Alloc>
  bool operator==(const unordered_multimap<Key, T, Hash, Pred, Alloc>& x,
                  const unordered_multimap<Key, T, Hash, Pred, Alloc>& y);

返回 true, 条件是 x.size() == y.size(), 且对于 x 中的每个等价键组, y 中都存在同一键的一个组, 且该组是其一个排列 (使用 operator== 比较值类型).

注释:

如果两个容器的相等谓词不等价, 则行为未定义.

operator!=

template<class Key, class T, class Hash, class Pred, class Alloc>
  bool operator!=(const unordered_multimap<Key, T, Hash, Pred, Alloc>& x,
                  const unordered_multimap<Key, T, Hash, Pred, Alloc>& y);

返回 false, 条件是 x.size() == y.size(), 且对于 x 中的每个等价键组, y 中都存在同一键的一个组, 且该组是其一个排列 (使用 operator== 比较值类型).

注释:

如果两个容器的相等谓词不等价, 则行为未定义.

Swap

template<class Key, class T, class Hash, class Pred, class Alloc>
  void swap(unordered_multimap<Key, T, Hash, Pred, Alloc>& x,
            unordered_multimap<Key, T, Hash, Pred, Alloc>& y)
    noexcept(noexcept(x.swap(y)));

交换 x 和 y 的内容.

如果声明了 Allocator::propagate_on_container_swap 且 Allocator::propagate_on_container_swap::value 为 true, 则交换两个容器的分配器. 否则, 以不相等的分配器进行交换会导致未定义行为.

效果:

x.swap(y)
抛出:

除非 key_equal 或 hasher 的复制构造函数或复制赋值运算符抛出异常, 否则不会抛出异常.
注释:

异常规范与 C++11 标准不完全相同, 因为相等谓词和哈希函数是使用它们的复制构造函数交换的.

erase_if

template<class K, class T, class H, class P, class A, class Predicate>
  typename unordered_multimap<K, T, H, P, A>::size_type
    erase_if(unordered_multimap<K, T, H, P, A>& c, Predicate pred);

遍历容器 c, 并移除所有使所提供谓词返回 true 的元素.

返回:

被移除的元素数量.
注释:

等价于:

auto original_size = c.size();
for (auto i = c.begin(), last = c.end(); i != last; ) {
  if (pred(*i)) {
    i = c.erase(i);
  } else {
    ++i;
  }
}
return original_size - c.size();

注意, 传递给 pred 的引用是非 const 的.

序列化

unordered_multimap 可以使用本库提供的 API 通过 Boost.Serialization 进行存档/取回. 普通档案和 XML 档案均受支持.

将 unordered_multimap 保存到档案

将 unordered_multimap x 的所有元素保存到档案 (XML 档案) ar.

要求:

std::remove_const<key_type>::type 和 std::remove_const<mapped_type>::type 是可序列化的 (XML 可序列化), 并且确实支持 Boost.Serialization save_construct_data/load_construct_data 协议 (由 DefaultConstructible 类型自动支持).

从档案载入 unordered_multimap

删除 unordered_multimap x 中所有预先存在的元素, 并从档案 (XML 档案) ar 插入原始 unordered_multimap other 元素的恢复副本, 这些元素之前保存到由 ar 读取的存储中.

要求:

value_type 可 EmplaceConstructible 自 (std::remove_const<key_type>::type&&, std::remove_const<mapped_type>::type&&). x.key_equal() 在功能上等价于 other.key_equal().
注释:

如果档案是用 Boost 1.84 之前的 Boost 版本保存的, 则必须全局定义配置宏 BOOST_UNORDERED_ENABLE_SERIALIZATION_COMPATIBILITY_V0, 此操作才能成功; 否则会抛出异常.

将 iterator/const_iterator 保存到档案

将 iterator (const_iterator) it 的位置信息保存到档案 (XML 档案) ar. it 可以是 end() 迭代器.

要求:

unordered_multimap x (被 it 指向) 之前已保存到 ar, 且在 x 上, 于保存 x 与保存 it 之间, 未发出任何修改操作.

从档案载入 iterator/const_iterator

使 iterator (const_iterator) it 指向原始 iterator (const_iterator) 的恢复位置, 该位置保存于由档案 (XML 档案) ar 读取的存储中.

要求:

如果 x 是 unordered_multimap (即 it 所指向者), 则要求: 在 x 上, 于加载 x 与加载 it 之间, 未发出任何修改操作.
