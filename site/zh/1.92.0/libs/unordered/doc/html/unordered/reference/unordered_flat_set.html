类模板 unordered_flat_set

boost::unordered_flat_set——一种存储唯一值的开放寻址无序关联容器.

boost::unordered_flat_set 的性能远好于 boost::unordered_set 或 std::unordered_set 的其他实现. 与基于节点的标准无序关联容器不同, boost::unordered_flat_set 的元素直接保存在桶数组中, 插入到已占用桶的操作会被转移到原始位置附近的可用桶. 这种数据布局被称为 开放寻址.

由于使用开放寻址, boost::unordered_flat_set 的接口在多个方面与 boost::unordered_set/std::unordered_set 的接口有所不同:

  • value_type 必须可移动构造.

  • 重新哈希时不保持指针稳定性.

  • begin() 不是常量时间.

  • 没有用于桶处理 (bucket_count 除外) 或节点提取/插入的 API.

  • 容器的最大负载因子由内部管理, 用户无法设置.

除此之外, boost::unordered_flat_set 在很大程度上可以作为基于节点的标准无序关联容器的直接替代品.

说明

模板参数

Key

Key 必须可 MoveInsertable 到容器中, 且可从容器中 Erasable.

Hash

一种一元函数对象类型, 充当 Key 的哈希函数. 它接受一个 Key 类型的参数, 并返回一个 std::size_t 类型的值.

Pred

一种二元函数对象, 在 Key 类型的值上定义等价关系. 它接受两个 Key 类型的参数, 并返回一个 bool 类型的值.

Allocator

一种 value_type 与容器的 value_type 相同的分配器. 支持使用 花式指针 的分配器.

容器的元素保存在一个内部 桶数组 中. 元素被插入到由其哈希码确定的桶中, 但如果该桶已被占用 (即发生 冲突), 则使用原始位置附近的一个可用桶.

桶数组的大小可以通过调用 insert/emplace 自动增加, 或者作为调用 rehash/reserve 的结果而增加. 容器的 负载因子 (元素数除以桶数) 永远不会大于 max_load_factor(), 小尺寸情形除外——此时实现可能决定允许更高的负载.

如果 hash_is_avalanching<Hash>::value 为 true, 则哈希函数按原样使用; 否则, 会添加一个位混合后处理阶段, 以额外的计算开销为代价提高哈希质量.

配置宏

BOOST_UNORDERED_ENABLE_STATS

全局定义此宏以启用容器的 统计计算. 注意, 此选项会降低许多操作的整体性能.

typedef

typedef implementation-defined iterator;

一种 value_type 为 value_type 的常量迭代器.

迭代器类别至少为前向迭代器.

可转换为 const_iterator.

typedef implementation-defined const_iterator;

一种 value_type 为 value_type 的常量迭代器.

迭代器类别至少为前向迭代器.

在必要时更改桶数组的大小, 使桶至少有 n 个, 且负载因子小于或等于最大负载因子. 在适用的情况下, 这会增大或缩小与容器关联的 bucket_count().

当 size() == 0 时, rehash(0) 会释放底层的桶数组. 如果提供的 Allocator 使用花式指针, 随后会执行一次默认分配.

使迭代器、指针和引用失效, 并改变元素的顺序.

抛出:

如果抛出异常, 该函数不产生任何效果, 除非异常是由容器的哈希函数或比较函数抛出的.

reserve

void reserve(size_type n);

等价于 a.rehash(ceil(n / a.max_load_factor())).

与 rehash 类似, 此函数可用于增大或缩小容器中的桶数量.

使迭代器、指针和引用失效, 并改变元素的顺序.

抛出:

如果抛出异常, 该函数不产生任何效果, 除非异常是由容器的哈希函数或比较函数抛出的.

推导指引

如果以下任一条件为真, 推导指引将不参与重载决议:

  • 它有一个 InputIterator 模板参数, 但为该参数推导出的类型不符合输入迭代器 (input iterator) 的条件.

  • 它有一个 Allocator 模板参数, 但为该参数推导出的类型不符合分配器 (allocator) 的条件.

  • 它有一个 Hash 模板参数, 但为该参数推导出的类型是整数类型, 或符合分配器 (allocator) 的条件.

  • 它有一个 Pred 模板参数, 但为该参数推导出的类型符合分配器 (allocator) 的条件.

推导指引中的 size_­type 参数类型指向由该推导指引推导出的容器类型的 size_­type 成员类型. 其默认值与所选构造函数的默认值一致.

iter-value-type

template<class InputIterator>
  using iter-value-type =
    typename std::iterator_traits<InputIterator>::value_type; // exposition only

convertible-to-from-range_t

template<typename FromRangeT>
  concept convertible-to-from_range_t =
    // first clause not present if std::from_range_t does not exist
    std::is_convertible_v<FromRangeT, std::from_range_t> ||
    std::is_convertible_v<FromRangeT, boost::unordered::from_range_t>; // exposition only

相等比较

operator==

template<class Key, class T, class Hash, class Pred, class Alloc>
  bool operator==(const unordered_flat_set<Key, T, Hash, Pred, Alloc>& x,
                  const unordered_flat_set<Key, T, Hash, Pred, Alloc>& y);

返回 true, 条件是 x.size() == y.size(), 且对于 x 中的每个元素, y 中都存在具有相同键和相等值 (使用 operator== 比较值类型) 的元素.

注释:

如果两个容器的相等谓词不等价, 则行为未定义.

operator!=

template<class Key, class T, class Hash, class Pred, class Alloc>
  bool operator!=(const unordered_flat_set<Key, T, Hash, Pred, Alloc>& x,
                  const unordered_flat_set<Key, T, Hash, Pred, Alloc>& y);

返回 false, 条件是 x.size() == y.size(), 且对于 x 中的每个元素, y 中都存在具有相同键和相等值 (使用 operator== 比较值类型) 的元素.

注释:

如果两个容器的相等谓词不等价, 则行为未定义.

Swap

template<class Key, class T, class Hash, class Pred, class Alloc>
  void swap(unordered_flat_set<Key, T, Hash, Pred, Alloc>& x,
            unordered_flat_set<Key, T, Hash, Pred, Alloc>& y)
    noexcept(noexcept(x.swap(y)));

交换 x 和 y 的内容.

如果声明了 Allocator::propagate_on_container_swap 且 Allocator::propagate_on_container_swap::value 为 true, 则交换两个容器的分配器. 否则, 以不相等的分配器进行交换会导致未定义行为.

效果:

x.swap(y)
抛出:

除非 key_equal 或 hasher 在交换时抛出异常, 否则不抛出任何异常.

erase_if

template<class K, class T, class H, class P, class A, class Predicate>
  typename unordered_flat_set<K, T, H, P, A>::size_type
    erase_if(unordered_flat_set<K, T, H, P, A>& c, Predicate pred);

遍历容器 c, 并移除所有使所提供谓词返回 true 的元素.

返回:

被移除的元素数量.
注释:

等价于:

auto original_size = c.size();
for (auto i = c.begin(), last = c.end(); i != last; ) {
  if (pred(*i)) {
    i = c.erase(i);
  } else {
    ++i;
  }
}
return original_size - c.size();

序列化

unordered_flat_set 可以使用本库提供的 API 通过 Boost.Serialization 进行存档/取回. 普通档案和 XML 档案均受支持.

将 unordered_flat_set 保存到档案

将 unordered_flat_set x 的所有元素保存到档案 (XML 档案) ar.

要求:

value_type 是可序列化的 (XML 可序列化), 并且支持 Boost.Serialization save_construct_data/load_construct_data 协议 (由 DefaultConstructible 类型自动支持).

从档案载入 unordered_flat_set

删除 unordered_flat_set x 中所有预先存在的元素, 并从档案 (XML 档案) ar 插入原始 unordered_flat_set other 元素的恢复副本, 这些元素之前保存到由 ar 读取的存储中.

要求:

x.key_equal() 在功能上等价于 other.key_equal().

将 iterator/const_iterator 保存到档案

将 iterator (const_iterator) it 的位置信息保存到档案 (XML 档案) ar. it 可以是 end() 迭代器.

要求:

unordered_flat_set x (被 it 指向) 之前已保存到 ar, 且在 x 上, 于保存 x 与保存 it 之间, 未发出任何修改操作.

从档案载入 iterator/const_iterator

使 iterator (const_iterator) it 指向原始 iterator (const_iterator) 的恢复位置, 该位置保存于由档案 (XML 档案) ar 读取的存储中.

要求:

如果 x 是 unordered_flat_set (即 it 所指向者), 则要求: 在 x 上, 于加载 x 与加载 it 之间, 未发出任何修改操作.
