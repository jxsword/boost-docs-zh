相等谓词与哈希函数

关联容器使用排序关系来指定元素的存储方式, 而无序关联容器则使用相等谓词和哈希函数. 例如, boost::unordered_map 声明如下:

template <
    class Key, class Mapped,
    class Hash = boost::hash<Key>,
    class Pred = std::equal_to<Key>,
    class Alloc = std::allocator<std::pair<Key const, Mapped> > >
class unordered_map;

哈希函数放在前面, 因为你可能想更改哈希函数而不更改相等谓词. 例如, 如果想使用 FNV-1a hash, 可以这样写:

boost::unordered_map<std::string, int, hash::fnv_1a>
    dictionary;

examples 目录中有 FNV-1a 的一个实现.

如果想使用不同的相等函数, 还需要使用匹配的哈希函数. 例如, 要实现大小写不敏感的字典, 需要定义大小写不敏感的相等谓词和哈希函数:

struct iequal_to
{
    bool operator()(std::string const& x,
        std::string const& y) const
    {
        return boost::algorithm::iequals(x, y, std::locale());
    }
};

struct ihash
{
    std::size_t operator()(std::string const& x) const
    {
        std::size_t seed = 0;
        std::locale locale;

        for(std::string::const_iterator it = x.begin();
            it != x.end(); ++it)
        {
            boost::hash_combine(seed, std::toupper(*it, locale));
        }

        return seed;
    }
};

然后就可以在大小写不敏感的字典中使用它:

boost::unordered_map<std::string, int, ihash, iequal_to>
    idictionary;

这是 /libs/unordered/examples/case_insensitive.hpp 中示例的简化版本, 后者还支持其他区域设置和字符串类型.

在自定义相等谓词下使用相等运算符 (==) 时要小心, 尤其是在使用函数指针时. 如果比较两个具有不同相等谓词的容器, 结果是未定义的. 对于大多数无状态函数对象, 这不可能发生——因为只能比较具有相同相等谓词的对象, 所以你知道相等谓词必然相等. 但如果使用函数指针或带状态的相等谓词 (例如 boost::function), 就可能遇到麻烦.

自定义类型

类似地, 自定义类型也可以使用自定义哈希函数:

struct point {
    int x;
    int y;
};

bool operator==(point const& p1, point const& p2)
{
    return p1.x == p2.x && p1.y == p2.y;
}

struct point_hash
{
    std::size_t operator()(point const& p) const
    {
        std::size_t seed = 0;
        boost::hash_combine(seed, p.x);
        boost::hash_combine(seed, p.y);
        return seed;
    }
};

boost::unordered_multiset<point, point_hash> points;

由于默认哈希函数是 Boost.Hash, 我们可以扩展它以支持该类型, 这样就无需显式给出哈希函数:

struct point {
    int x;
    int y;
};

bool operator==(point const& p1, point const& p2)
{
    return p1.x == p2.x && p1.y == p2.y;
}

std::size_t hash_value(point const& p) {
    std::size_t seed = 0;
    boost::hash_combine(seed, p.x);
    boost::hash_combine(seed, p.y);
    return seed;
}

// Now the default function objects work.
boost::unordered_multiset<point> points;

有关具体做法的更多细节, 请参见 Boost.Hash 文档. 注意, 它依赖于对标准的扩展——因此对无序关联容器的其他实现不起作用, 你需要显式使用 Boost.Hash.
