统计

开放寻址容器和并发容器可以配置为持续记录某些内部操作的运行统计信息, 这些操作受所提供哈希函数的质量影响.

概要

struct stats-summary-type
{
  double average;
  double variance;
  double deviation;
};

struct insertion-stats-type
{
  std::size_t        count;
  stats-summary-type probe_length;
};

struct lookup-stats-type
{
  std::size_t        count;
  stats-summary-type probe_length;
  stats-summary-type num_comparisons;
};

struct stats-type
{
  insertion-stats-type insertion;
  lookup-stats-type    successful_lookup,
                       unsuccessful_lookup;
};

stats-summary-type

提供数值序列的平均值、方差和标准差.

insertion-stats-type

提供容器执行的插入操作数量, 以及相关 探测长度 (每次操作访问的 桶组 数量) 的统计信息.

lookup-stats-type

对于成功 (找到元素) 或失败 (未找到) 的查找, 提供容器执行的操作数量, 以及相关 探测长度 (访问的 桶组 数量) 和每次操作元素比较次数的统计信息.

stats-type

提供容器执行的插入、成功查找和失败查找的统计信息. 如果所提供的哈希函数质量良好, 则:

  • 平均探测长度应接近 1.0.

  • 对于成功查找, 平均元素比较次数应接近 1.0.

  • 对于失败查找, 平均元素比较次数应接近 0.0.

这些统计信息可用于判断给定的哈希函数是否可以标记为 avalanching.
