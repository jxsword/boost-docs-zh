实现: fcontext_t、ucontext_t 与 WinFiber

fcontext_t

默认实现使用 fcontext_t. fcontext_t 基于汇编实现, 并非在所有平台上都可用. 它提供的性能远优于 ucontext_t (上下文切换所需的 CPU 周期少两个数量级; 参见 性能 一节) 和 WinFiber.

注释

由于 TIB (Windows 上的线程信息块) 在 MSDN 中未被完整描述, 可能并非所有必需的 TIB 部分都会被交换. 使用 WinFiber 实现或许是一种替代方案.

ucontext_t

作为一种替代方案, ucontext_t 可以通过以 BOOST_USE_UCONTEXT 编译并指定 b2 属性 context-impl=ucontext 来使用. ucontext_t 可能在更广泛的 POSIX 平台上可用, 但存在一些 缺点 (例如自 POSIX.1-2003 起已被弃用, 不符合 C99).

注释

callcc() 支持 分段栈, 但仅限以 ucontext_t 作为其实现时.

WinFiber

当使用 BOOST_USE_WINFIB 和 b2 属性 context-impl=winfib 时, Win32 纤程被用作 callcc() 的实现.

注释

首次调用 callcc() 时, 会通过调用 ConvertThreadToFiber() 把线程转换为 Windows 纤程. 如有需要, 用户必须显式调用 ConvertFiberToThread(), 以释放由 ConvertThreadToFiber() 分配的资源 (例如在使用 boost.context 之后).
