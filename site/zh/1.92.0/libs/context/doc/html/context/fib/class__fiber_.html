类 fiber 

#include <boost/context/fiber.hpp>

class fiber {
public:
    fiber() noexcept = default;

    ~fiber();

    fiber(fiber && other) noexcept;

    fiber & operator=(fiber && other) noexcept;

    fiber(fiber const& other) noexcept = delete;
    fiber & operator=(fiber const& other) noexcept = delete;

    fiber resume();

    template<typename Fn>
    fiber resume_with(Fn && fn);

    explicit operator bool() const noexcept;

    bool operator!() const noexcept;

    bool operator==(fiber const& other) const noexcept;

    bool operator!=(fiber const& other) const noexcept;

    bool operator<(fiber const& other) const noexcept;

    bool operator>(fiber const& other) const noexcept;

    bool operator<=(fiber const& other) const noexcept;

    bool operator>=(fiber const& other) const noexcept;

    template<typename charT,class traitsT>
    friend std::basic_ostream<charT,traitsT> &
    operator<<(std::basic_ostream<charT,traitsT> & os,fiber const& other) {

    void swap(fiber & other) noexcept;
};

构造函数 

fiber() noexcept;

效果:

创建一个无效的纤程.

抛出:

无.

析构函数 

~fiber();

效果:

若 *this 是一个有效的纤程 (例如 fiber::operator bool() 返回 true), 则销毁相关联的栈.

抛出:

无.

移动构造函数 

fiber(fiber && other) noexcept;

效果:

将底层捕获的纤程移动到 *this.

抛出:

无.

移动赋值运算符 

fiber & operator=(fiber && other) noexcept;

效果:

使用移动语义将 other 的状态移动到 *this.

抛出:

无.

成员函数 operator()() 

fiber resume();

template<typename Fn>
fiber resume_with(Fn && fn);

效果:

捕获当前纤程并恢复 *this . 函数 resume_with 用于执行函数 fn , 执行发生在 *this 的执行上下文中 (例如 fn 的栈帧被分配在 *this 的栈上).

返回:

表示被挂起的纤程的纤程.

注释:

函数 fn 需要返回 fiber.

注释:

返回的纤程通过 bool operator() 指示被挂起的纤程是否已终止 (从 context-function 返回).

成员函数 operator bool() 

explicit operator bool() const noexcept;

返回:

true, 若 *this 指向一个已捕获的纤程.

抛出:

无.

成员函数 operator!() 

bool operator!() const noexcept;

返回:

true, 若 *this 未指向一个已捕获的纤程.

抛出:

无.

成员函数 operator==() 

bool operator==(fiber const& other) const noexcept;

返回:

true, 若 *this 与 other 表示同一个纤程; 否则为 false.

抛出:

无.

成员函数 operator!=() 

bool operator!=(fiber const& other) const noexcept;

返回:

! (other == * this)

抛出:

无.

成员函数 operator<() 

bool operator<(fiber const& other) const noexcept;

返回:

true, 若 *this != other 为真, 且 fiber 值的实现定义全序将 *this 排在 other 之前; 否则为 false.

抛出:

无.

成员函数 operator>() 

bool operator>(fiber const& other) const noexcept;

返回:

other < * this

抛出:

无.

成员函数 operator<=() 

bool operator<=(fiber const& other) const noexcept;

返回:

! (other < * this)

抛出:

无.

成员函数 operator>=() 

bool operator>=(fiber const& other) const noexcept;

返回:

! (* this < other)

抛出:

无.

非成员函数 operator<<() 

template<typename charT,class traitsT>
std::basic_ostream<charT,traitsT> &
operator<<(std::basic_ostream<charT,traitsT> & os,fiber const& other);

效果:

将 other 的表示形式写入流 os.

返回:

os
