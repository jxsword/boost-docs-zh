概述

Boost.Context 是一个基础库, 在单个线程上提供一种协作式多任务处理. 通过对当前线程的当前执行状态进行抽象 —— 包括栈 (含局部变量) 与栈指针、全部寄存器与 CPU 标志位, 以及指令指针 —— 一个执行上下文表示应用程序执行路径上的一个特定位置. 这对于构建更高层的抽象非常有用, 例如 coroutines (协程)、cooperative threads (userland threads) (协作式线程 (用户态线程)), 或 C++ 中与 C# 关键字 yield 等价的机制.

callcc()/continuation 提供了挂起当前执行路径并转移执行控制的手段, 从而允许另一个上下文在当前线程上运行. 这种带状态的转移机制使一个上下文能够从嵌套函数内部挂起执行, 并在之后从挂起处恢复执行. 虽然 continuation 所表示的执行路径只在单个线程上运行, 但它可以在任意时刻迁移到另一个线程.

线程之间的 上下文切换 需要系统调用 (涉及操作系统内核), 在 x86 CPU 上可能耗费上千个 CPU 周期. 相比之下, 通过 callcc()/continuation 转移控制权只需少量 CPU 周期, 因为它在单线程内完成, 不涉及系统调用.

所有函数和类都位于命名空间 boost::context 中.

注释

本库要求 C++11!

重要

Windows 使用 fcontext_t: 关闭全局程序优化 (/GL), 并将 /EHsc 改为 /EHs (编译器假定声明为 extern "C" 的函数从不抛出 C++ 异常; /EHs 则告知编译器: 声明为 extern "C" 的函数可能抛出异常).
