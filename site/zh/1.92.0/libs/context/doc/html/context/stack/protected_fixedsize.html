类 protected_fixedsize

Boost.Context 提供类 protected_fixedsize_stack , 它满足 stack-allocator concept 概念. 它在每个栈的末尾追加一个保护页, 以防止超出栈的范围. 若访问到保护页 (读或写操作), 操作系统会产生一个段错误/访问违例.

重要

使用 protected_fixedsize_stack 代价高昂. 也就是说, 以新栈启动新协程的代价高昂; 但所分配栈的使用效率与其他栈一样高.

注释

所追加的 guard page 被 not 映射到物理内存, 仅使用虚拟地址.

#include <boost/context/protected_fixedsize.hpp>

template< typename traitsT >
struct basic_protected_fixedsize {
    typedef traitT  traits_type;

    basic_protected_fixesize(std::size_t size = traits_type::default_size());

    stack_context allocate();

    void deallocate( stack_context &);
}

typedef basic_protected_fixedsize< stack_traits > protected_fixedsize
stack_context allocate()

前置条件:

traits_type::minimum:size() <= size 与 ! traits_type::is_unbounded() && ( traits_type::maximum:size() >= size) .

效果:

分配至少 size 字节的内存, 并把指向栈的指针及其实际大小存入 sctx . 视体系结构而定 (栈向下/向上生长), 所存储的地址是栈的最高/最低地址.

void deallocate( stack_context & sctx)

前置条件:

sctx.sp 有效, traits_type::minimum:size() <= sctx.size 与 ! traits_type::is_unbounded() && ( traits_type::maximum:size() >= sctx.size) .

效果:

释放栈空间.
