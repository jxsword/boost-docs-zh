x86 与浮点环境

不使用内联汇编

一些较新的编译器 (例如面向 x86_64 和 itanium 的 MSVC 10) 不支持内联汇编 [1]. 内联汇编会生成膨胀的代码, 这在嵌入式系统上是不受欢迎的.

fcontext_t

Boost.Context 提供以汇编实现的底层 API fcontext_t, 用于提供上下文交换操作. fcontext_t 是移植到新平台时需要处理的部分.

注释

在 UNIX 系统上, 上下文切换不保存信号掩码.

fcontext_t 是一个不透明指针.


[1] MSDN 文章 'Inline Assembler'
