Requirements要求

若 Boost.Context 使用 fcontext_t (默认) 作为其实现, 则必须针对目标编译器和 CPU 体系结构进行构建. 使用 fcontext_t 时, Boost.Context 包含汇编代码, 因此在受支持的 POSIX 系统上需要 GNU as 和 GNU 预处理器, 在 Windows/x86 系统上需要 MASM, 在 Windows/arm 系统上需要 ARMasm.

注释

MASM64 (ml64.exe) 是 Microsoft Windows Driver Kit 的一部分.

重要

请注意, 在 64 位 Windows 上进行 64 位构建时, 必须在 bjam 命令行上给出 address-model=64 ; 否则将生成 32 位代码.

重要

若要交叉编译本库, 必须在 bjam 命令行上指定某些附加属性: target-os , abi , binary-format , architecture 和 address-model .

重要

Windows 使用 fcontext_t: 为了安全的 SEH, 必须在 bjam 命令行上指定属性 'asmflags=\safeseh'.

重要

Windows 使用 fcontext_t: 关闭全局程序优化 (/GL), 并将 /EHsc 改为 /EHs (编译器假定声明为 extern "C" 的函数从不抛出 C++ 异常; /EHs 则告知编译器: 声明为 extern "C" 的函数可能抛出异常).

由于本库大量使用 C++11, 因此需要一个兼容的编译器. 已知可工作的最低版本如下: Microsoft Visual Studio 2015 (msvc-14.0), GCC 4.8 (带 -std=c++11), Clang 3.4 (带 -std=c++11). 其他编译器若支持以下语言特性也可能工作: auto 声明、constexpr、缺省函数 (defaulted functions)、final、头文件 thread、头文件 tuple、lambda、noexcept、nullptr、右值引用、模板别名、thread local、变参模板.
