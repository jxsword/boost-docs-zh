x86 与浮点环境

i386

"任何需要修改 FpCsr 和 MxCsr 寄存器的过程, 必须在任何调用或返回之前保存并恢复它们 ..." [4].

x86_64
Windows

MxCsr - "修改 MxCsr 中任何非易失性字段的被调用方, 必须在返回调用方之前恢复它们. 此外, 修改了这些字段中任何一个的调用方, 必须在调用被调用方之前将其恢复为标准值 ..." [5].

FpCsr - "修改 FpCsr 中任何字段的被调用方, 必须在返回调用方之前恢复它们. 此外, 修改了这些字段中任何一个的调用方, 必须在调用被调用方之前将其恢复为标准值 ..." [6].

"MMX 与浮点栈寄存器 (MM0-MM7/ST0-ST7) 在上下文切换之间被保留. 这些寄存器没有显式的调用约定." [7].

"64 位 Microsoft 编译器不使用 ST(0)-ST(7)/MM0-MM7". [8].

"XMM6-XMM15 必须被保留" [9]

SysV

"MxCsr 寄存器的控制位由被调用方保存 (跨调用保留), 而状态位由调用方保存 (不保留). x87 状态字寄存器由调用方保存, 而 x87 控制字 (FpCsr) 由被调用方保存." [10].
