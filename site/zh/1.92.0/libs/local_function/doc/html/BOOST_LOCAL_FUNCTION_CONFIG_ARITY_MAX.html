宏 BOOST_LOCAL_FUNCTION_CONFIG_ARITY_MAX

BOOST_LOCAL_FUNCTION_CONFIG_ARITY_MAX — 局部函数所支持的最大参数数量.

概要

// In header: <boost/local_function/config.hpp>

BOOST_LOCAL_FUNCTION_CONFIG_ARITY_MAX

说明

若程序员不定义此配置宏, 其默认值为 5 (增大此数值可能增加编译时间). 由程序员定义时, 此宏必须是一个非负整数.

注释: 此宏指定局部函数参数 (不含被绑定变量) 的最大数量 (被绑定变量由 BOOST_LOCAL_FUNCTION_CONFIG_BIND_MAX 指定).

参见: 教程章节, 入门章节, BOOST_LOCAL_FUNCTION_CONFIG_BIND_MAX.
