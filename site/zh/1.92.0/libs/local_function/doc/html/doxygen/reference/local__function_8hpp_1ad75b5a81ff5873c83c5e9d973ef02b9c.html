宏 BOOST_LOCAL_FUNCTION_TYPEOF

BOOST_LOCAL_FUNCTION_TYPEOF — 该宏展开为指定被绑定变量的类型.

概要

// In header: <boost/local_function.hpp>

BOOST_LOCAL_FUNCTION_TYPEOF(bound_variable_name)

说明

该宏可在局部函数体内用于引用被绑定变量的类型, 以声明局部变量、检查 concept (使用 Boost.ConceptCheck) 等 (见进阶主题章节). 这样, 局部函数可以完全无需显式指定被绑定变量的类型来编写, 从而便于维护 (例如, 若某个被绑定变量在外围作用域中的类型发生变化, 局部函数代码无需改动).

参数:

bound_variable_name 局部函数某个被绑定变量的名称.

该宏返回的类型是完全限定的: 当指定变量按常量方式和按引用方式绑定时, 它包含额外的常量和引用限定符. 例如, 若一个名为 t、类型为 T 的变量:

  • 使用 bind t 按值绑定, 则 BOOST_LOCAL_FUNCTION_TYPEOF(t) 为 T.

  • 使用 const bind t 按常量值绑定, 则 BOOST_LOCAL_FUNCTION_TYPEOF(t) 为 const T.

  • 使用 bind& t 按引用绑定, 则 BOOST_LOCAL_FUNCTION_TYPEOF(t) 为 T&.

  • 使用 const bind& t 按常量引用绑定, 则 BOOST_LOCAL_FUNCTION_TYPEOF(t) 为 const T&.

在模板内使用时, 此宏必须以 typename 为前缀.

注释: 最好使用此宏而非 Boost.Typeof, 以减少调用 Boost.Typeof 推导类型的次数 (见进阶主题章节).

参见: 进阶主题章节, BOOST_LOCAL_FUNCTION.
