宏 BOOST_LOCAL_FUNCTION_NAME_TPL

BOOST_LOCAL_FUNCTION_NAME_TPL — 该宏用于在模板内结束一个局部函数声明并指定其名称.

概要

// In header: <boost/local_function.hpp>

BOOST_LOCAL_FUNCTION_NAME_TPL(name)

说明

在模板内声明局部函数时, 必须使用此宏而非 BOOST_LOCAL_FUNCTION_NAME. 除此之外, 此宏的语法与 BOOST_LOCAL_FUNCTION_NAME 完全相同 (更多信息见 BOOST_LOCAL_FUNCTION_NAME):

{ // Some declarative context within a template.
    ...
    result_type BOOST_LOCAL_FUNCTION_TPL(declarations) {
        ... // Body code.
    } BOOST_LOCAL_FUNCTION_NAME_TPL(qualified_name)
    ...
}

注意, 必须在此宏中使用 BOOST_LOCAL_FUNCTION_TPL 而非 BOOST_LOCAL_FUNCTION.

注释: C++03 不允许在模板之外使用 typename. 本库在内部操纵类型, 这些操作需要 typename, 但仅在模板内如此. 此宏用于向库指示外围作用域是否为模板, 以便库能正确使用 typename.

参见: 教程章节, BOOST_LOCAL_FUNCTION_NAME, BOOST_LOCAL_FUNCTION_TPL.
