宏 BOOST_LOCAL_FUNCTION

BOOST_LOCAL_FUNCTION — 该宏用于开始一个局部函数声明.

概要

// In header: <boost/local_function.hpp>

BOOST_LOCAL_FUNCTION(declarations)

说明

该宏必须在声明性上下文中使用, 它必须紧跟局部函数结果类型之后, 其后必须跟着局部函数体代码, 再之后是 BOOST_LOCAL_FUNCTION_NAME 宏 (见教程和进阶主题章节):

{ // Some declarative context.
    ...
    result_type BOOST_LOCAL_FUNCTION(declarations) {
        ... // Body code.
    } BOOST_LOCAL_FUNCTION_NAME(qualified_name)
    ...
}

通常, 异常规范可以在宏之后、函数体代码块 { ... } 之前以可选方式编写 (但异常规范仅作用于函数体代码, 而不作用于宏展开自动生成的库代码, 见进阶主题章节).

在模板内部, 必须使用特殊宏 BOOST_LOCAL_FUNCTION_TPL 和 BOOST_LOCAL_FUNCTION_NAME_TPL.

参数:

declarations 在支持变参宏的编译器上, 参数声明由以下文法定义: 
declarations:
        void | declaration_tuple | declaration_sequence
declaration_tuple:
        declaration, declaration, ...
declaration_sequence:
        (declaration) (declaration) ...
declaration:
        bound_variable | parameter | default_value | result_type
bound_variable:
        [const] bind [(variable_type)] [&] variable_name
parameter:
        [auto | register] parameter_type parameter_name
default_value:
        default parameter_default_value
result_type:
        return function_result_type
在不支持变参宏的编译器上, 不能使用 declaration_tuple: 
declarations:
        void | declaration_sequence
(词法约定: token1 | token2 表示 token1 或 token2; [token] 表示 token 或为空; {expression} 表示由该表达式产生的记号.)

注意, 在支持变参宏的编译器上, 可以使用逗号分隔声明, 使其更接近通常的 C++ 函数声明语法 (这是首选语法). 但为了可移植性, 在所有 C++ 编译器上 (无论是否支持变参宏), 这些库宏也接受以圆括号 () 分隔、写成 Boost.Preprocessor 序列形式的参数声明.

绑定对象 this 时, 必须使用特殊符号 this_ 而非 this 作为要绑定的变量名, 并且在局部函数体内也用它来访问该对象. (错误地用 this 代替 this_ 可能不会总是导致编译错误, 而且通常会导致未定义行为.)

结果类型必须在宏之前指定, 或在宏声明内以 return 为前缀指定 (但不能在两处同时指定).

在局部函数体内, 可以使用 result_type 访问结果类型, 使用 arg1_type 访问第一个参数的类型, 使用 arg2_type 访问第二个参数的类型, 等等. 被绑定变量的类型可以使用 BOOST_LOCAL_FUNCTION_TYPEOF 访问.

该宏不能可靠地在同一行上多次展开. 在这种情况下, 请改用 BOOST_LOCAL_FUNCTION_ID 宏.

局部函数参数的最大数量 (不含被绑定变量) 由配置宏 BOOST_LOCAL_FUNCTION_CONFIG_ARITY_MAX 指定. 被绑定变量的最大数量由配置宏 BOOST_LOCAL_FUNCTION_CONFIG_BIND_MAX 指定. 配置宏 BOOST_LOCAL_FUNCTION_CONFIG_LOCALS_AS_TPARAMS 可用于强制启用减少局部函数调用运行期开销的优化.

注释: 局部函数是仿函数, 因此可以赋给其他仿函数, 如 boost::function (见 Boost.Function).
