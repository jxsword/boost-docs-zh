宏 BOOST_LOCAL_FUNCTION_NAME

BOOST_LOCAL_FUNCTION_NAME — 该宏用于结束一个局部函数声明并指定其名称.

概要

// In header: <boost/local_function.hpp>

BOOST_LOCAL_FUNCTION_NAME(qualified_name)

说明

此宏必须紧跟局部函数体代码块 { ... } 之后:

{ // Some declarative context.
    ...
    result_type BOOST_LOCAL_FUNCTION(declarations) {
        ... // Body code.
    } BOOST_LOCAL_FUNCTION_NAME(qualified_name)
    ...
}

在模板内部, 必须使用特殊宏 BOOST_LOCAL_FUNCTION_TPL 和 BOOST_LOCAL_FUNCTION_NAME_TPL.

参数:

qualified_name 局部函数的名称, 可按如下方式可选地限定: 
name:
        [inline] [recursive] local_function_name
(词法约定: token1 | token2 表示 token1 或 token2; [token] 表示 token 或为空; {expression} 表示由该表达式产生的记号.)

局部函数名可以通过前缀关键字 inline 来限定 (见进阶主题章节):

BOOST_LOCAL_FUNCTION_NAME(inline local_function_name)

这会提高编译器能够内联局部函数调用的机会 (从而减少运行期). 但是, 内联局部函数不能作为模板参数传递 (例如传递给 std::for_each), 也不能赋给其他仿函数 (例如赋给 boost::function). 这在 C++03 编译器上成立, 但在 C++11 编译器上, 内联局部函数反而可以作为模板参数传递. 在 C++11 编译器上, 无需将局部函数声明为内联, 因为本库会自动使用 C++11 特有特性来内联局部函数, 同时始终允许将其作为模板参数传递. 当未定义 Boost.Config 宏 BOOST_NO_CXX11_LOCAL_CLASS_TEMPLATE_PARAMETERS 时, 此优化会自动启用, 也可以使用 BOOST_LOCAL_FUNCTION_CONFIG_LOCALS_AS_TPARAMS 强制启用.

局部函数名还可以通过前缀"关键字" recursive 来限定 (见进阶主题章节):

BOOST_LOCAL_FUNCTION_NAME(recursive local_function_name)

这允许局部函数从其函数体内递归调用自身 (与通常的 C++ 一样). 但是, 递归局部函数只应在其声明作用域内被调用 (否则结果为未定义行为). 此外, 尚未观察到任何编译器能够内联递归局部函数调用, 即使递归局部函数同时声明为内联也一样:

BOOST_LOCAL_FUNCTION(inline recursive local_function_name)

注释: 局部函数名不能是运算符 operator... 的名称, 也不能与同一外围作用域中声明的另一个局部函数同名 (但可以使用 boost::overloaded_function 重载局部函数, 见 Boost.Functional/OverloadedFunction 和进阶主题章节).
