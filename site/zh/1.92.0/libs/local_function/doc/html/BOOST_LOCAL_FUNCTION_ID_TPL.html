宏 BOOST_LOCAL_FUNCTION_ID_TPL

BOOST_LOCAL_FUNCTION_ID_TPL — 该宏允许在模板内的同一行上声明多个局部函数.

概要

// In header: <boost/local_function.hpp>

BOOST_LOCAL_FUNCTION_ID_TPL(id, declarations)

说明

在模板内的同一行上声明多个局部函数时, 必须使用此宏而非 BOOST_LOCAL_FUNCTION_TPL. 除此之外, 此宏的语法与 BOOST_LOCAL_FUNCTION_TPL 完全相同 (更多信息见 BOOST_LOCAL_FUNCTION_TPL).

参数:

id 一个可被预处理器拼接的唯一标识符记号 (__LINE__, local_function_number_1_on_line_123 等).
declarations 与 declarations 参数相同, 该参数属于 BOOST_LOCAL_FUNCTION_TPL 宏.

应照常使用 BOOST_LOCAL_FUNCTION_NAME 宏来结束多个局部函数声明中的每一个 (它将为每个局部函数指定唯一名称).

在模板之外, 应使用宏 BOOST_LOCAL_FUNCTION_ID 在同一行上声明多个局部函数.

注释: 当局部函数宏在用户自定义宏内展开时, 该宏很有用 (因为所有宏都在同一行上展开). 在某些编译器上 (例如支持非标准 __COUNTER__ 宏的 MSVC), 可能无需使用该宏, 但在同一行上展开多个局部函数宏时, 始终必须使用该宏以确保可移植性 (这是因为本库只能可靠地使用 __LINE__ 在内部生成唯一标识符).

参见: 进阶主题章节, BOOST_LOCAL_FUNCTION_TPL, BOOST_LOCAL_FUNCTION_NAME, BOOST_LOCAL_FUNCTION_ID.
