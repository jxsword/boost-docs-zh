宏 BOOST_LOCAL_FUNCTION_TPL

BOOST_LOCAL_FUNCTION_TPL — 该宏用于在模板内开始一个局部函数声明.

概要

// In header: <boost/local_function.hpp>

BOOST_LOCAL_FUNCTION_TPL(declarations)

说明

在模板内声明局部函数时, 必须使用此宏而非 BOOST_LOCAL_FUNCTION. 除此之外, 此宏的语法与 BOOST_LOCAL_FUNCTION 完全相同 (更多信息见 BOOST_LOCAL_FUNCTION):

{ // Some declarative context within a template.
    ...
    result_type BOOST_LOCAL_FUNCTION_TPL(declarations) {
        ... // Body code.
    } BOOST_LOCAL_FUNCTION_NAME_TPL(qualified_name)
    ...
}

注意, 必须在此宏中使用 BOOST_LOCAL_FUNCTION_NAME_TPL 而非 BOOST_LOCAL_FUNCTION_NAME.

该宏不能可靠地在同一行上多次展开. 在这种情况下, 请改用 BOOST_LOCAL_FUNCTION_ID_TPL 宏.

注释: C++03 不允许在模板之外使用 typename. 本库在内部操纵类型, 这些操作需要 typename, 但仅在模板内如此. 此宏用于向库指示外围作用域是否为模板, 以便库能正确使用 typename.

参见: 教程章节, BOOST_LOCAL_FUNCTION, BOOST_LOCAL_FUNCTION_ID_TPL, BOOST_LOCAL_FUNCTION_NAME_TPL.
