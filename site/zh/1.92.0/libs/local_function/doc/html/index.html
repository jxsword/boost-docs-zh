本库允许在其他函数内部以及直接在需要之处的作用域内就地编写函数.

引言

局部函数 (又称 嵌套函数) 是一种信息隐藏形式, 它有助于把过程性任务划分为只在局部有意义的子任务, 避免用与程序其他部分无关的函数、变量等使其杂乱. 因此, 局部函数补充了命名空间和类等其他结构化手段. 局部函数是许多编程语言 (尤其是 Pascal 和 Ada) 的特性, 但 C++03 缺少这一特性 (另见 [N2511]).

使用 C++11 lambda 函数, 可以为 lambda 函数命名并赋给局部变量, 从而实现局部函数. 例如 (另见 add_cxx11_lambda.cpp):

int main(void) {                            // Some local scope.
    int sum = 0, factor = 10;               // Variables in scope to bind.

    auto add = [factor, &sum](int num) {    // C++11 only.
        sum += factor * num;
    };

    add(1);                                 // Call the lambda.
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add);     // Pass it to an algorithm.

    BOOST_TEST(sum == 60);                  // Assert final summation value.
    return boost::report_errors();
}

本库支持在 C++03 与 C++11 之间可移植地编写局部函数 (并且在 C++11 编译器上性能与 lambda 函数相当). 例如 (另见 add.cpp):

int main(void) {                            // Some local scope.
    int sum = 0, factor = 10;               // Variables in scope to bind.

    void BOOST_LOCAL_FUNCTION(const bind factor, bind& sum, int num) {
        sum += factor * num;
    } BOOST_LOCAL_FUNCTION_NAME(add)

    add(1);                                 // Call the local function.
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add);     // Pass it to an algorithm.

    BOOST_TEST(sum == 60);                  // Assert final summation value.
    return boost::report_errors();
}

本库为局部函数支持以下特性:

  • 局部函数可以捕获 (或更好地说是 绑定) 外围作用域中的任意变量 (函数与其捕获的变量一起也称为闭包).
  • 局部函数体使用通常的 C++ 语句语法编写 (因此编译器错误和调试保持其通常的含义和格式).
  • 局部函数可以作为模板参数传递, 因此可以方便地用于 STL 算法及其他模板. [1]
  • 但是, 局部函数必须在声明性上下文中指定 (例如在代码中可以声明局部变量的位置), 因此不能在表达式内指定. [2]

本库与 C++11 lambda 函数、Boost.Phoenix 以及其他实现局部函数相关特性的 C++ 技术之间的比较见替代方案章节.


[1] 相对于使用局部类实现的 C++03 仿函数而言, 这是一个优势: 局部类不能作为模板参数传递 (见 [N2657] 和替代方案章节).

[2] 相对于 C++11 lambda 函数 而言, 这是一个劣势: lambda 函数还可以在表达式内指定 (见替代方案章节).
