附录: 无变参宏

本节展示面向不支持变参宏的编译器的另一种语法.

序列语法

大多数现代编译器支持 变参宏 (特别是 GCC、MSVC 和所有 C++11 编译器). 然而, 在程序员需要在不支持变参宏的编译器上使用本库的罕见情况下, 本库也允许使用 Boost.Preprocessor 序列来指定宏参数, 记号以圆括号 () 分隔:

(token1) (token2) ... // All compilers.

代替我们迄今所见、需要变参宏的逗号分隔列表:

token1, token2, ... // Only compilers with varidic macros.

例如, 以下语法在所有编译器上 (无论是否支持变参宏) 都被接受 (另见 add_seq.cpp):

int main(void) {
    int sum = 0, factor = 10;

    void BOOST_LOCAL_FUNCTION( (const bind factor) (bind& sum) (int num) ) {
        sum += factor * num;
    } BOOST_LOCAL_FUNCTION_NAME(add)

    add(1);
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add);

    BOOST_TEST(sum == 60);
    return boost::report_errors();
}

不过, 在支持变参宏的编译器上, 更推荐使用我们迄今所见的逗号分隔语法, 因为它更易读 (另见 add.cpp):

int main(void) {                            // Some local scope.
    int sum = 0, factor = 10;               // Variables in scope to bind.

    void BOOST_LOCAL_FUNCTION(const bind factor, bind& sum, int num) {
        sum += factor * num;
    } BOOST_LOCAL_FUNCTION_NAME(add)

    add(1);                                 // Call the local function.
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add);     // Pass it to an algorithm.

    BOOST_TEST(sum == 60);                  // Assert final summation value.
    return boost::report_errors();
}

注意, 在支持变参宏的编译器上, 同一组宏同时接受两种语法; 在不支持变参宏的编译器上则只接受序列语法. 最后, 在支持与不支持变参宏的编译器上, 空的局部函数参数列表始终以 void 指定:

int BOOST_LOCAL_FUNCTION(void) { // No parameter.
    return 10;
} BOOST_LOCAL_FUNCTION_NAME(ten)

BOOST_TEST(ten() == 10);
