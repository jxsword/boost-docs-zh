致谢

本节旨在致谢直接或间接参与本库设计与开发的所有人士.

非常感谢 Steven Watanabe 和 Vicente Botet 建议我使用 Boost.ScopeExit 绑定来模拟局部函数. 非常感谢 Alexander Nasonov 澄清了如何利用 Boost.ScopeExit 绑定实现局部函数, 以及他在这个方向上的早期工作.

非常感谢 Gregory Crosswhite 在他的一个项目中使用了本库的早期版本.

感谢 David Abrahams、Vicente Botet 等人建议在支持变参宏的编译器上提供变参宏语法.

感谢 Pierre Morcello 分享了一些用 Boost.ScopeExit 绑定实验实现局部函数的代码 (即使本库并非基于这些代码).

感谢 John Bytheway 检验了作者的虚仿函数技术, 该技术最初使本库能够把局部函数作为模板参数传递.

感谢 Jeffrey Lee Hellrung 建议使用"关键字" bind 绑定作用域内的变量, 并建议使用 bind(type) 可选地指定被绑定变量的类型. 感谢 Vicente Botet 建议提供一个宏向公共 API 暴露被绑定变量的类型.

感谢 Steven Watanabe、Vicente Botet、Michael Caisse、Yechezkel Mett、Joel de Guzman、Thomas Heller 等人协助编写替代方案章节, 并对各种替代方案进行性能分析.

非常感谢 Jeffrey Lee Hellrung 主持了本库的 Boost 评审. 同时感谢所有提交 Boost 评审意见的人: Andrzej Krzemienski、Edward Diener、Gregory Crosswhite、John Bytheway、Hartmut Kaiser、Krzysztof Czainski、Nat Lindon、Pierre Morcello、Thomas Heller 和 Vicente J. Botet. 感谢在 Boost 评审期间对本库发表评论的所有人.

最后, 非常感谢整个 Boost 社区和邮件列表对本库提出的宝贵意见以及对 C++ 编程语言的深刻见解.
