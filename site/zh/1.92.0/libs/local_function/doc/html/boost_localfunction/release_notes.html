发布说明

本节按时间顺序列出库各版本之间的主要变更.

版本 1.0.0 (2012-04-12)

  1. 采纳了本库 Boost 评审的全部意见.
  2. 移除了局部块 (local block) 和局部退出 (local exit).
  3. 库由 Boost.Local 更名为 Boost.LocalFunction.
  4. 在局部函数声明中也使用 this_ 代替 this (而不仅在函数体中).
  5. 进行了允许返回局部函数 (类似于闭包) 的更改.
  6. 新增 GCC lambda 和常量块示例.
  7. 把 overloaded_function 移至 Boost.Functional/OverloadedFunction.
  8. 把 BOOST_IDENTITY_TYPE 移至 Boost.Utility/IdentityType.
  9. 在显式指定被绑定类型和结果类型时, 完全移除了对 Boost.Typeof 的使用.
  10. 新增用于同行多次展开的 ..._ID 宏.
  11. 修复了 Boost 回归测试平台上的编译问题.

版本 0.2.0 (2011-05-14)

  1. 用变参和序列宏语法取代了括号语法.
  2. 对本库性能与其他方法进行了对比测试.
  3. 用转型仿函数技巧取代虚仿函数技巧 (以降低运行期).
  4. 优化了库的运行期 (重排代码, 并在接受局部类作为模板参数的编译器上不使用转型仿函数技巧).
  5. 支持内联与递归局部函数.
  6. 新增 type-of 宏以暴露被绑定类型.
  7. 允许显式指定被绑定类型.
  8. 移除了 boost::function 的使用, 转而把内部局部仿函数暴露为公共 API.
  9. 新增用于重载局部函数 (及一般仿函数) 的仿函数.
  10. 实现了局部函数、块与退出相互嵌套的支持.

版本 0.1.1 (2011-01-10)

  1. 把库源码上传至 Boost SVN sandbox.
  2. 修复了文档中的前后翻页箭头及其他小的布局问题.
  3. 在文档中新增发布说明章节.

版本 0.1.0 (2011-01-03)

  1. 与 Boost 分享以获取第一轮意见.

版本 0.0.1 (2010-12-15)

  1. 完成开发、示例与文档.
