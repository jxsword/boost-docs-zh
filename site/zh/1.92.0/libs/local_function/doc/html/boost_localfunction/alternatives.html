C++11 Lambda 函数

C++11 lambda 函数 具有本库的大部分特性, 外加一些额外特性 (另见引言章节中的示例):

  • C++11 lambda 函数 可以在表达式内定义, 而本库的局部函数只能在声明作用域定义.
  • C++11 lambda 函数 仅受 C++11 标准支持, 因此并非所有 C++ 编译器都支持. 本库的局部函数也可以在 C++03 编译器上编写 (并且在 C++11 编译器上性能与 C++11 lambda 函数 相当).
  • C++11 lambda 函数 不允许按常量引用绑定作用域内的变量. 由于变量不能按常量引用绑定, C++11 lambda 函数 只有在变量为 CopyConstructible 时才能按常量绑定, 且这种绑定需要一次 (可能代价高昂的) 额外拷贝操作. 本库则支持常量引用绑定.
  • C++11 lambda 函数 不允许在不绑定对象 this 的情况下选择性地绑定数据成员, 而本库的局部函数既可以绑定选定的数据成员, 也可以绑定整个对象 this (使用 this_).
  • C++11 lambda 函数 提供一次绑定作用域内所有变量的简写语法 (& 或 =), 而本库的局部函数始终要求逐一命名变量来绑定.

例如, 对于不可拷贝对象 (另见 noncopyable_cxx11_lambda_error.cpp 和 noncopyable_local_function.cpp):

C++11 Lambda 函数

Boost.LocalFunction 

struct n: boost::noncopyable {
    int i;
    n(int _i): i(_i) {}
};


int main(void) {
    n x(-1);

    auto f = [x](void) {    // Error: x is non-copyable, but if
        assert(x.i == -1);  // bind `&x` then `x` is not constant.
    };
    f();

    return 0;
}


struct n: boost::noncopyable {
    int i;
    n(int _i): i(_i) {}
};
BOOST_TYPEOF_REGISTER_TYPE(n) // Register for `bind& x` below.

int main(void) {
    n x(-1);

    void BOOST_LOCAL_FUNCTION(const bind& x) {  // OK: No copy
        assert(x.i == -1);                      // and constant.
    } BOOST_LOCAL_FUNCTION_NAME(f)
    f();

    return 0;
}

或者, 对于拷贝操作代价高昂的对象 (另见 expensive_copy_cxx11_lambda.cpp 和 expensive_copy_local_function.cpp):

C++11 Lambda 函数

Boost.LocalFunction 

struct n {
    int i;
    n(int _i): i(_i) {}
    n(n const& x): i(x.i) { // Some time consuming copy operation.
        for (unsigned i = 0; i < 10000; ++i) std::cout << '.';
    }
};


int main(void) {
    n x(-1);

    auto f = [x]() {        // Problem: Expensive copy, but if bind
        assert(x.i == -1);  // by `&x` then `x` is not constant.
    };
    f();

    return 0;
}


struct n {
    int i;
    n(int _i): i(_i) {}
    n(n const& x): i(x.i) { // Some time consuming copy operation.
        for (unsigned i = 0; i < 10000; ++i) std::cout << '.';
    }
};
BOOST_TYPEOF_REGISTER_TYPE(n) // Register for `bind& x` below.

int main(void) {
    n x(-1);

    void BOOST_LOCAL_FUNCTION(const bind& x) {  // OK: No copy expensive
        assert(x.i == -1);                      // copy but constant.
    } BOOST_LOCAL_FUNCTION_NAME(f)
    f();

    return 0;
}

当 C++11 lambda 函数 需要常量绑定功能时, 最好的替代方案可能是绑定一个额外声明的常量局部变量, 并将其初始化为原变量 (例如, 见 常量块, 用 C++11 lambda 函数 实现, 见示例章节).

局部仿函数

以下示例将局部函数与 C++ 局部仿函数进行比较 (另见 add_local_functor.cpp 和 add.cpp):

局部仿函数

Boost.LocalFunction 

int main(void) {
    int sum = 0, factor = 10;

    struct local_add { // Unfortunately, boilerplate code to program the class.
        local_add(int& _sum, int _factor): sum(_sum), factor(_factor) {}

        inline void operator()(int num) { // Body uses C++ statement syntax.
            sum += factor * num;
        }

    private: // Unfortunately, cannot bind so repeat variable types.
        int& sum; // Access `sum` by reference.
        const int factor; // Make `factor` constant.
    } add(sum, factor);

    add(1);
    int nums[] = {2, 3};
    // Unfortunately, cannot pass as template parameter to `std::for_each`.
    for(size_t i = 0; i < 2; ++i) add(nums[i]);

    BOOST_TEST(sum == 60);
    return boost::report_errors();
}


int main(void) {                            // Some local scope.
    int sum = 0, factor = 10;               // Variables in scope to bind.

    void BOOST_LOCAL_FUNCTION(const bind factor, bind& sum, int num) {
        sum += factor * num;
    } BOOST_LOCAL_FUNCTION_NAME(add)

    add(1);                                 // Call the local function.
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add);     // Pass it to an algorithm.

    BOOST_TEST(sum == 60);                  // Assert final summation value.
    return boost::report_errors();
}

全局仿函数

以下示例将局部函数与 C++ 全局仿函数进行比较 (另见 add_global_functor.cpp 和 add.cpp):

全局仿函数

Boost.LocalFunction 

// Unfortunately, cannot be defined locally (so not a real alternative).
struct global_add { // Unfortunately, boilerplate code to program the class.
    global_add(int& _sum, int _factor): sum(_sum), factor(_factor) {}

    inline void operator()(int num) { // Body uses C++ statement syntax.
        sum += factor * num;
    }

private: // Unfortunately, cannot bind so repeat variable types.
    int& sum; // Access `sum` by reference.
    const int factor; // Make `factor` constant.
};

int main(void) {
    int sum = 0, factor = 10;

    global_add add(sum, factor);

    add(1);
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add); // Passed as template parameter.

    BOOST_TEST(sum == 60);
    return boost::report_errors();
}


int main(void) {                            // Some local scope.
    int sum = 0, factor = 10;               // Variables in scope to bind.

    void BOOST_LOCAL_FUNCTION(const bind factor, bind& sum, int num) {
        sum += factor * num;
    } BOOST_LOCAL_FUNCTION_NAME(add)

    add(1);                                 // Call the local function.
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add);     // Pass it to an algorithm.

    BOOST_TEST(sum == 60);                  // Assert final summation value.
    return boost::report_errors();
}

但请注意, 全局仿函数不允许就地定义函数, 因此它们并非真正的局部函数替代实现.

Boost.Phoenix

以下示例将局部函数与 Boost.Phoenix 进行比较 (另见 add_phoenix.cpp 和 add.cpp):

Boost.Phoenix

Boost.LocalFunction 

int main(void) {
    using boost::phoenix::let;
    using boost::phoenix::local_names::_f;
    using boost::phoenix::cref;
    using boost::phoenix::ref;
    using boost::phoenix::arg_names::_1;

    int sum = 0, factor = 10;
    int nums[] = {1, 2, 3};

    // Passed to template, `factor` by constant, and defined in expression.
    std::for_each(nums, nums + 3, let(_f = cref(factor))[
        // Unfortunately, body cannot use C++ statement syntax.
        ( ref(sum) += _f * _1, _1 ) // Access `sum` by reference.
    ]);

    BOOST_TEST(sum == 60);
    return boost::report_errors();
}


int main(void) {                            // Some local scope.
    int sum = 0, factor = 10;               // Variables in scope to bind.

    void BOOST_LOCAL_FUNCTION(const bind factor, bind& sum, int num) {
        sum += factor * num;
    } BOOST_LOCAL_FUNCTION_NAME(add)

    add(1);                                 // Call the local function.
    int nums[] = {2, 3};
    std::for_each(nums, nums + 2, add);     // Pass it to an algorithm.

    BOOST_TEST(sum == 60);                  // Assert final summation value.
    return boost::report_errors();
}

本节比较不包括 Boost.Lambda 库, 因为该库已过时, 已被 Boost.Phoenix 取代. 此比较使用的是 Boost.Phoenix 库 3.0 版.

性能

下表比较本节介绍的各种局部函数替代方案的运行期、编译期和二进制体积.

总体而言, 本库的编译期和生成的二进制体积与其他方法相近. 经测量, 本库在 C++03 编译器上的运行期在启用编译器优化 (使用 bjam release ...) 时比其他方法更长. 不过, 在允许把局部类型作为模板参数传递的编译器上 (例如 MSVC 8.0 或启用了 C++11 特性的 GCC 4.5.3 -std=c++0x, 另见 [N2657] 和 Boost.Config 的 BOOST_NO_CXX11_LOCAL_CLASS_TEMPLATE_PARAMETERS), 本库会自动生成与最快方法同样快速的优化代码 (见下文"Boost.LocalFunction"方法). 当本库局部函数被指定为 inline (见下文"Boost.LocalFunction 内联"方法和进阶主题章节) 时, 其运行期始终与"局部仿函数"和"全局仿函数"方法相当. 但在这些情况下, 局部函数不能可靠地作为模板参数传递 (见 [N2657] 和 Boost.Config 的 BOOST_NO_CXX11_LOCAL_CLASS_TEMPLATE_PARAMETERS), 因此 std::for_each 被 for 循环取代 (在 MSVC 上, 实测 for 循环的性能反而比使用 std::for_each 更差, 事实上这一结论同样适用于局部仿函数). 最后, 在未启用编译器优化 (使用 bjam debug ...) 时, 本库的运行期始终名列最快.

注释

本库局部函数的运行期表现可以这样解释: 在符合 C++03 的编译器上 (例如未启用 -std=c++0x 的 GCC 4.5.3), 本库需要使用函数指针, 才能把局部函数类可靠地作为模板参数传递 (见 [N2657] 和实现章节). 对所有被测编译器而言, 这个函数指针都会阻止编译器的优化算法内联局部函数调用. 相反, 其他方法使用的仿函数 (例如 Boost.Phoenix) 被观察到能让所有被测编译器内联全部函数调用以进行优化. 在允许把局部类型作为模板参数传递的编译器上 (例如 MSVC 8.0 或启用了 C++11 特性的 GCC 4.5.3 -std=c++0x, 见 Boost.Config 的 BOOST_NO_CXX11_LOCAL_CLASS_TEMPLATE_PARAMETERS), 这一运行期代价并不存在, 因为本库不必使用额外的函数指针来实现局部函数调用 (它直接把局部类类型作为模板参数传递).

C++03 编译器上的这一运行期代价是否构成问题, 取决于具体应用的性能要求. 例如, 应用可能已经在使用大量间接函数调用 (函数指针、虚函数等), 此时局部函数调用所需的额外一个函数指针带来的开销, 在整个程序运行期中可能并不明显.

最后请注意, 这里呈现的分析只使用了仅含单条指令的非常简单的局部函数体 (见下文源文件). 对于为局部函数体编写更复杂指令集时本库与其他方法的相对表现, 作者尚未研究 (例如, 如果 局部函数体中更复杂的指令集会阻止某些编译器内联函数对象, 那么 C++11 lambda 函数 和 Boost.Phoenix 等其他方法 也可能 开始表现出更长的运行期, 即使启用了优化).

为测量编译期、二进制体积和运行期, 分别在库的示例目录中执行了以下命令:

> touch <FILE_NAME>.cpp                             # force recompilation
> python chrono.py bjam {release|debug} <FILE_NAME> # compile-time
> size <FILE_NAME>                                  # binary size
> ./<FILE_NAME>                                     # run-time

局部函数被调用 1e8 次, 把 vector 的所有元素相加; 运行期用 Boost.Chrono 测量, 对 10 次 vector 求和取平均 (见下文源文件).
