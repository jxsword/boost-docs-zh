宏 BOOST_LOCAL_FUNCTION_CONFIG_LOCALS_AS_TPARAMS

BOOST_LOCAL_FUNCTION_CONFIG_LOCALS_AS_TPARAMS — 指定局部函数何时可以在不引入任何运行期开销的情况下作为模板参数传递.

概要

// In header: <boost/local_function/config.hpp>

BOOST_LOCAL_FUNCTION_CONFIG_LOCALS_AS_TPARAMS

说明

若此宏被定义为 1, 本库将假定编译器允许把局部类作为模板参数传递:

template<typename T> void f(void) {}

int main(void) {
    struct local_class {};
    f<local_class>();
    return 0;
}

C++11 编译器和某些 C++03 编译器 (如 MSVC) 属于这种情况, 但对大多数 C++03 编译器 (包括 GCC) 来说一般并非如此. 这将允许本库在不引入任何运行期开销的情况下把局部函数作为模板参数传递 (具体而言, 不会阻止编译器通过内联其汇编代码来优化局部函数调用).

若此宏被定义为 0, 本库将引入与解析函数指针调用相关的运行期开销, 以便仍能把局部函数作为模板参数传递.

建议不定义此宏. 在这种情况下, 若 Boost.Config 宏 0 (针对特定编译器) 已定义, 库会自动把此宏定义为 BOOST_NO_CXX11_LOCAL_CLASS_TEMPLATE_PARAMETERS, 否则定义为 1.

参见: 入门章节, 进阶主题章节, BOOST_LOCAL_FUNCTION_NAME.
