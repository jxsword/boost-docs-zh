reverse
原型 

template<class BidirectionalRange>
BidirectionalRange& reverse(BidirectionalRange& rng);

template<class BidirectionalRange>
const BidirectionalRange& reverse(const BidirectionalRange& rng);

说明

reverse 反转一个范围. 返回对反转后范围的引用.

定义

定义于头文件 boost/range/algorithm/reverse.hpp

要求
  • BidirectionalRange 是 Bidirectional Range 概念的一个模型.
  • BidirectionalRange 是可变的.
复杂度

线性复杂度. reverse 进行 distance(rng)/2 次对 iter_swap 的调用
