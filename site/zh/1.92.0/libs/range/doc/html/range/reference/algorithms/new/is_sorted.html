is_sorted
原型 

template<class SinglePassRange>
bool is_sorted(const SinglePassRange& rng);

template<class SinglePassRange, class BinaryPredicate>
bool is_sorted(const SinglePassRange& rng, BinaryPredicate pred);

说明

is_sorted 判断范围是否已排序. 对于非谓词版本, 返回值为 true 当且仅当对于每对相邻元素 [x, y], 表达式 y < x 为 false (即 x <= y), 或者元素数量为零或一. 对于谓词版本, 返回值为 true 当且仅当对于每对相邻元素 [x, y], 表达式 pred(y, x) 为 false, 或者元素数量为零或一.

定义

定义于头文件 boost/range/algorithm_ext/is_sorted.hpp

要求
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. BinaryPredicate 是 BinaryPredicate 概念的一个模型.
  3. SinglePassRange 的值类型可转换为 BinaryPredicate 的两个实参类型.
复杂度

线性复杂度. 至多执行 distance(rng) 次比较.
