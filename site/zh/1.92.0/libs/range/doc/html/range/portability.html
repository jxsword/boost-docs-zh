可移植性

本库已投入巨大努力移植到尽可能多的编译器.

对内置数组的完整支持要求编译器支持类模板偏特化. 对于不符合标准的编译器, 得益于类型特征库 (type traits library) 中的变通办法, 仍有可能正常工作. Visual C++ 6/7.0 对数组的支持有限: 只要数组是内置类型, 就应当可以工作.

另请注意, 有些编译器无法正确进行函数模板排序. 此时必须依赖 range_iterator 和单一函数定义, 而不是针对 const 与非 const 参数的重载版本. 因此, 如果在意旧编译器, 就不应向这些函数传递右值.

为获得最大的可移植性, 应当遵循以下准则:

  1. 不要使用内置数组,
  2. 不要向 begin(), end() 和 iterator_range Range 构造函数与赋值运算符传递右值,
  3. 当你的代码本意只是只读时, 请使用 const_begin() 和 const_end(); 这也将解决大多数右值问题,
  4. 不要依赖 ADL:
    • 如果你重载函数, 请在本库的头文件之前包含该头文件,
    • 将所有重载放在命名空间 boost 中.
