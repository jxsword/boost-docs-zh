equal
原型 

template<
    class SinglePassRange1,
    class SinglePassRange2
>
bool equal(const SinglePassRange1& rng1,
           const SinglePassRange2& rng2);

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class BinaryPredicate
>
bool equal(const SinglePassRange1& rng1,
           const SinglePassRange2& rng2,
           BinaryPredicate         pred);

说明

equal 返回 true 若 distance(rng1) 等于 distance(rng2) 并且对于 x 中的每个元素 rng1 与 y (即 rng2 中的对应元素) 相等. 否则返回 false.

在此范围版本的 equal 中, 完全可以传入两个长度不等的范围.

在非谓词版本中, 若 operator== 返回 true, 则元素被视为相等. 在谓词版本中, 若 pred(x,y) 为 true, 则元素被视为相等.

定义

定义于头文件 boost/range/algorithm/equal.hpp

要求

对于非谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • SinglePassRange1 的值类型是 EqualityComparableConcept 的一个模型.
  • SinglePassRange2 的值类型是 EqualityComparableConcept 的一个模型.
  • SinglePassRange1 的值类型可与 SinglePassRange2 的值类型进行相等比较.

对于谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • BinaryPredicate 是 BinaryPredicateConcept 的一个模型.
  • SinglePassRange1 的值类型可转换为 BinaryPredicate 的第一个实参类型.
  • SinglePassRange2 的值类型可转换为 BinaryPredicate 的第二个实参类型.
复杂度

线性复杂度. 至多 min(distance(rng1), distance(rng2)) 次比较.
