从 1.55 版本升级

  1. iterator_range 现在通过实现成员函数 size(), operator[] 来实现 (经由按底层迭代器遍历类型特化的基类继承). 这通常不需要改动代码. 但确实意味着派生自 iterator_range 的类型可能需要在各个成员函数前加 this-> 前缀. 此外, 有人注意到一些调用代码依赖诸如 size() 的成员函数存在, 尽管由于 iterator_reference<Iter>::type 不是引用, 底层迭代器并非随机访问. 建议的重构是使用 boost::size(rng)
  2. 未写入文档的 iterator_range pop_front() 已被弃用, 并由 drop_front(). Similarly pop_back() has been replaced by drop_back()` 取代
