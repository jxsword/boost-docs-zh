函数 join

join 函数的意图是将两个范围拼接成一个更长的范围.

所得范围将具有作为参数提供的两个范围的最低公共遍历能力.

注意, 拼接后的范围会带来性能开销, 因为在遍历期间需要内部检查是否已到达某个范围的末尾.

概要 

template<typename SinglePassRange1, typename SinglePassRange2>
joined_range<const SinglePassRange1, const SinglePassRange2>
join(const SinglePassRange1& rng1, const SinglePassRange2& rng2)

template<typename SinglePassRange1, typename SinglePassRange2>
joined_range<SinglePassRange1, SinglePassRange2>
join(SinglePassRange1& rng1, SinglePassRange2& rng2);

对于 const 版本:

  • 前置条件: range_value<SinglePassRange2>::type 必须可转换为 range_value<SinglePassRange1>::type . range_reference<const SinglePassRange2>::type 必须可转换为 range_reference<const SinglePassRange1>::type
  • 范围类别: rng1 和 rng2 都必须是 Single Pass Range 或更高概念的模型.
  • 范围返回类型: joined_range<const SinglePassRange1, const SinglePassRange2> 它是所传递的两个范围概念中较弱者的模型.
  • 返回范围的类别: 即 rng1 与 rng2 的范围类别中的最小者

对于可变版本:

  • 前置条件: range_value<SinglePassRange2>::type 必须可转换为 range_value<SinglePassRange1>::type . range_reference<SinglePassRange2>::type 必须可转换为 range_reference<SinglePassRange1>::type
  • 范围类别: rng1 和 rng2 都必须是 Single Pass Range 或更高概念的模型.
  • 范围返回类型: joined_range<SinglePassRange1, SinglePassRange2> 它是所传递的两个范围概念中较弱者的模型.
  • 返回范围的类别: 即 rng1 与 rng2 的范围类别中的最小者
示例

表达式 join(irange(0,5), irange(5,10)) 将求值为一个表示整数范围 [0,10) 的范围
