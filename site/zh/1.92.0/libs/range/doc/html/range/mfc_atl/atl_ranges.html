ATL 范围

若在 Boost.Range 头文件之前或之后包含 <boost/range/atl.hpp>, ATL 集合与字符串即成为 Range 的模型. 下表列出 ATL 范围的遍历类别与 range_reference.

其他 Boost.Range 元函数定义如下. 设 Range 为上文列出的任意类型, Ref 与 range_reference<Range>::type 相同. range_value<Range>::type 与 remove_reference<Ref>::type 相同, range_difference<Range>::type 与 std::ptrdiff_t 相同, 并且 range_pointer<Range>::type 与 add_pointer<remove_reference<Ref>::type>::type 相同. 至于 const Range, 见下文.
