push_front
原型 

template<
    class Container,
    class SinglePassRange
    >
Container& push_front(Container& target,
                      const SinglePassRange& from);

说明

push_front 将范围 from 中的所有元素添加到容器 target 的前端

定义

定义于头文件 boost/range/algorithm_ext/push_front.hpp

要求
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. Container 支持在 begin() 处插入
  3. SinglePassRange 的值类型可转换为 Container 的值类型.
复杂度

线性复杂度. 执行 distance(from) 次赋值.
