irange

原型 

template<class Integer>
iterator_range< range_detail::integer_iterator<Integer> >
irange(Integer last);

template<class Integer>
iterator_range< range_detail::integer_iterator<Integer> >
irange(Integer first, Integer last);

template<class Integer, class StepSize>
iterator_range< range_detail::integer_iterator_with_step<Integer, StepSize> >
irange(Integer first, Integer last, StepSize step_size);

说明

irange 是一个生成整数范围的函数.

irange 允许将整数当作 Random Access Range 概念的一个模型来对待. 应当注意, first 和 last 参数表示一个半开范围.

定义

定义于头文件 boost/range/irange.hpp

要求
  1. Integer 是 Integer 概念的一个模型.
  2. StepSize 是 SignedInteger 概念的一个模型.
复杂度

常量. 由于此函数生成一个新范围, 最显著的性能开销来自对所生成范围的迭代.
