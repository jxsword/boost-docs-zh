stable_sort
原型 

template<class RandomAccessRange>
RandomAccessRange& stable_sort(RandomAccessRange& rng);

template<class RandomAccessRange>
const RandomAccessRange& stable_sort(const RandomAccessRange& rng);

template<class RandomAccessRange, class BinaryPredicate>
RandomAccessRange& stable_sort(RandomAccessRange& rng, BinaryPredicate pred);

template<class RandomAccessRange, class BinaryPredicate>
const RandomAccessRange& stable_sort(const RandomAccessRange& rng, BinaryPredicate pred);

说明

stable_sort 将 rng 中的元素按升序排序. stable_sort 保证是稳定的. 等价元素的次序得以保留.

对于不带谓词的 stable_sort 函数版本, 升序由 operator<() 定义, 即对所有相邻元素 [x,y], y < x == false

对于带谓词的 stable_sort 函数版本, 升序由 pred 定义, 即对所有相邻元素 [x,y], pred(y,x) == false

定义

定义于头文件 boost/range/algorithm/stable_sort.hpp

要求

对于不带谓词的 stable_sort 版本

  • RandomAccessRange 是 Random Access Range 概念的一个模型.
  • RandomAccessRange 是可变的.
  • RandomAccessRange 的值类型是 LessThanComparableConcept 的一个模型.
  • RandomAccessRange 值类型上的排序关系是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样

对于带谓词的 stable_sort 版本:

  • RandomAccessRange 是 Random Access Range 概念的一个模型.
  • RandomAccessRange 是可变的.
  • BinaryPredicate 是 StrictWeakOrderingConcept 的一个模型.
  • RandomAccessRange 的值类型可转换为 BinaryPredicate 的两个实参类型.
复杂度

最佳情况: O(N), 其中 N 为 distance(rng) . 最坏情况: O(N log(N)^2) 次比较, 其中 N 为 distance(rng)
