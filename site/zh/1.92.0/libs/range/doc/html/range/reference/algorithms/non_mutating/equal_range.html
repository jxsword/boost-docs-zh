equal_range
原型 

template<
    class ForwardRange,
    class Value
    >
std::pair<typename range_iterator<ForwardRange>::type,
          typename range_iterator<ForwardRange>::type>
equal_range(ForwardRange& rng, const Value& val);

template<
    class ForwardRange,
    class Value
    >
std::pair<typename range_iterator<const ForwardRange>::type,
          typename range_iterator<const ForwardRange>::type>
equal_range(const ForwardRange& rng, const Value& val);

template<
    class ForwardRange,
    class Value,
    class SortPredicate
    >
std::pair<typename range_iterator<ForwardRange>::type,
          typename range_iterator<ForwardRange>::type>
equal_range(ForwardRange& rng, const Value& val, SortPredicate pred);

template<
    class ForwardRange,
    class Value,
    class SortPredicate
    >
std::pair<typename range_iterator<const ForwardRange>::type,
          typename range_iterator<const ForwardRange>::type>
equal_range(const ForwardRange& rng, const Value& val, SortPredicate pred);

说明

equal_range 返回一个以一对迭代器表示的范围, 其中所有元素都等于 val . 若找不到等于 val 的值, 则返回空范围, 即 result.first == result.second . 对于 equal_range 的非谓词版本, 元素的相等性由 operator< 确定. 对于 equal_range 的谓词版本, 元素的相等性由 pred 确定.

定义

定义于头文件 boost/range/algorithm/equal_range.hpp

要求

对于非谓词版本:

  • ForwardRange 是 Forward Range 概念的一个模型.
  • Value 是 LessThanComparableConcept 的一个模型.
  • 类型为 Value 的对象的排序是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样
  • ForwardRange 的值类型与 Value 是同一类型.

对于谓词版本:

  • ForwardRange 是 Forward Range 概念的一个模型.
  • SortPredicate 是 StrictWeakOrderingConcept 的一个模型.
  • ForwardRange 的值类型与 Value 相同.
  • ForwardRange 的值类型可转换为 SortPredicate 的两个实参类型.
前置条件:

对于非谓词版本: rng 依据 operator< 按升序排列.

对于谓词版本: rng 依据 pred 按升序排列.

复杂度

对于随机访问范围, 复杂度为 O(log N), 否则复杂度为 O(N).
