rotate_copy
原型 

template<class ForwardRange, class OutputIterator>
OutputIterator rotate_copy(
    const ForwardRange& rng,
    typename range_iterator<ForwardRange>::type middle,
    OutputIterator out);

说明

rotate_copy 旋转范围中的元素. 它将两个范围 [begin(rng), middle) 和 [middle, end(rng)) 拷贝到 out

定义

定义于头文件 boost/range/algorithm/rotate_copy.hpp

要求
  • ForwardRange 是 Forward Range 概念的一个模型.
  • ForwardRange 是可变的.
  • OutputIterator 是 OutputIteratorConcept 的一个模型.
前置条件:
  • [begin(rng), middle) 是一个有效范围.
  • [middle, end(rng)) 是一个有效范围.
复杂度

线性复杂度. 恰好拷贝 distance(rng) 个元素.
