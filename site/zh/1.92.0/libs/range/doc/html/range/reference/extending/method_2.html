方法 2: 提供独立函数并特化元函数

此过程假定你不能 (或不希望) 修改需要符合某个 Range 概念的类型. 若非如此, 参见 方法 1.

本库中的主模板实现为: 某些函数可通过实参依赖查找 (ADL) 找到. 下面概述一个类要成为某个 Range 概念可用而必须指定的独立函数. 设 x 为该类的一个变量 (const 或 mutable)

函数

相关概念

range_begin(x)

Single Pass Range

range_end(x)

Single Pass Range

range_calculate_size(x)

可选. 这可用于指定一种以常量时间计算范围大小的机制. 默认行为是对随机访问范围返回 boost::end(x) - boost::begin(x), 对遍历能力较低的范围返回 x.size() . 通过实现 range_calculate_size (以可通过 ADL 找到的方式) 可以改变这一行为. 即使遍历类别低于随机访问的范围, 通常也能以 O(1) 计算大小.

range_begin() 和 range_end() 必须为 const 和 mutable 引用实参进行重载.

你还必须为你的类型 X 特化两个元函数:

元函数

相关概念

boost::range_mutable_iterator

Single Pass Range

boost::range_const_iterator

Single Pass Range

这里给出一个完整的示例:

#include <boost/range.hpp>
#include <iterator>         // for std::iterator_traits, std::distance()

namespace Foo
{
    //
    // Our sample UDT. A 'Pair'
    // will work as a range when the stored
    // elements are iterators.
    //
    template< class T >
    struct Pair
    {
        T first, last;
    };

} // namespace 'Foo'

namespace boost
{
    //
    // Specialize metafunctions. We must include the range.hpp header.
    // We must open the 'boost' namespace.
    //

	template< class T >
	struct range_mutable_iterator< Foo::Pair<T> >
	{
		typedef T type;
	};

	template< class T >
	struct range_const_iterator< Foo::Pair<T> >
	{
		//
		// Remark: this is defined similar to 'range_iterator'
		//         because the 'Pair' type does not distinguish
		//         between an iterator and a const_iterator.
		//
		typedef T type;
	};

} // namespace 'boost'

namespace Foo
{
	//
	// The required functions. These should be defined in
	// the same namespace as 'Pair', in this case
	// in namespace 'Foo'.
	//

	template< class T >
	inline T range_begin( Pair<T>& x )
	{
		return x.first;
	}

	template< class T >
	inline T range_begin( const Pair<T>& x )
	{
		return x.first;
	}

	template< class T >
	inline T range_end( Pair<T>& x )
	{
		return x.last;
	}

	template< class T >
	inline T range_end( const Pair<T>& x )
	{
		return x.last;
	}

} // namespace 'Foo'

#include <vector>

int main(int argc, const char* argv[])
{
	typedef std::vector<int>::iterator  iter;
	std::vector<int>                    vec;
	Foo::Pair<iter>                     pair = { vec.begin(), vec.end() };
	const Foo::Pair<iter>&              cpair = pair;
	//
	// Notice that we call 'begin' etc with qualification.
	//
	iter i = boost::begin( pair );
	iter e = boost::end( pair );
	i      = boost::begin( cpair );
	e      = boost::end( cpair );
	boost::range_difference< Foo::Pair<iter> >::type s = boost::size( pair );
	s      = boost::size( cpair );
	boost::range_reverse_iterator< const Foo::Pair<iter> >::type
	ri     = boost::rbegin( cpair ),
	re     = boost::rend( cpair );

	return 0;
}
