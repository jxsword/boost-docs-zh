remove_if
原型 

template<
    class ForwardRange,
    class UnaryPredicate
    >
typename range_iterator<ForwardRange>::type
remove_if(ForwardRange& rng, UnaryPredicate pred);

template<
    class ForwardRange,
    class UnaryPredicate
    >
typename range_iterator<const ForwardRange>::type
remove_if(const ForwardRange& rng, UnaryPredicate pred);

template<
    range_return_value re,
    class ForwardRange,
    class UnaryPredicate
    >
typename range_return<ForwardRange,re>::type
remove_if(ForwardRange& rng, UnaryPredicate pred);

template<
    range_return_value re,
    class ForwardRange,
    class UnaryPredicate
    >
typename range_return<const ForwardRange,re>::type
remove_if(const ForwardRange& rng, UnaryPredicate pred);

说明

remove_if 从 rng 移除全部元素 x 中满足 pred(x) 为 true 者. remove_if 的返回迭代器的版本返回迭代器 new_last, 使得范围 [begin(rng), new_last) 不含使 pred(x) 为 true 的元素. 范围 [new_last, end(rng)) 中的迭代器可解引用, 但元素是未指定的.

定义

定义于头文件 boost/range/algorithm/remove_if.hpp

要求
  • ForwardRange 是 Forward Range 概念的一个模型.
  • ForwardRange 是可变的.
  • UnaryPredicate 是 PredicateConcept 的一个模型.
  • ForwardRange 的值类型可转换为 UnaryPredicate 的实参类型.
复杂度

线性复杂度. remove_if 恰好应用 distance(rng) 次 pred
