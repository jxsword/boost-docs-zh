for_each
原型 

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class BinaryFunction
    >
BinaryFunction for_each(const SinglePassRange1& rng1,
                        const SinglePassRange2& rng2,
                        BinaryFunction fn);

    class SinglePassRange1,

BinaryFunction for_each(const SinglePassRange1& rng1,
                        SinglePassRange2& rng2,

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class BinaryFunction
    >
BinaryFunction for_each(SinglePassRange1& rng1,
                        const SinglePassRange2& rng2,
                        BinaryFunction fn);

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class BinaryFunction
    >
BinaryFunction for_each(SinglePassRange1& rng1,
                        SinglePassRange2& rng2,
                        BinaryFunction fn);

说明

for_each 同时向前遍历 rng1 和 rng2 . 每次迭代中, 使用来自 x 的元素 rng1 和来自 y 的对应元素 rng2 来调用 fn(x,y)

到达 rng1 或 rng2 中较短者的末尾时停止迭代. 以长度不等的范围调用此函数是安全的.

定义

定义于头文件 boost/range/algorithm_ext/for_each.hpp

要求
  1. SinglePassRange1 是 Single Pass Range 概念的一个模型.
  2. SinglePassRange2 是 Single Pass Range 概念的一个模型.
  3. BinaryFunction 是 BinaryFunctionConcept 的一个模型.
  4. SinglePassRange1 的值类型可转换为 BinaryFunction 的第一个实参类型.
  5. SinglepassRange2 的值类型可转换为 BinaryFunction 的第二个实参类型.
复杂度

线性复杂度. 恰好应用 min(distance(rng1), distance(rng2)) 次 BinaryFunction
