remove_erase_if
原型 

template<class Container, class Pred>
Container& remove_erase_if(Container& target,
                           Pred pred);

说明

remove_erase_if 从容器中移除元素 x 中满足 pred(x) 者. 这与只重新排列元素的 erase 算法形成对比.

定义

定义于头文件 boost/range/algorithm_ext/erase.hpp

要求
  1. Container 支持对迭代器范围的擦除.
  2. Pred 是 Predicate 概念的一个模型.
复杂度

线性复杂度. 与 distance(target) 成正比.
