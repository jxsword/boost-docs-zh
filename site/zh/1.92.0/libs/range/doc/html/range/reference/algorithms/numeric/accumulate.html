accumulate
原型 

template<
    class SinglePassRange,
    class Value
    >
Value accumulate(const SinglePassRange& source_rng,
                 Value init);

template<
    class SinglePassRange,
    class Value,
    class BinaryOperation
    >
Value accumulate(const SinglePassRange& source_rng,
                 Value init,
                 BinaryOperation op);

说明

accumulate 是求和的推广. 它计算一个二元运算 (非谓词版本中为 operator+), 针对 init 和 rng 中的所有元素.

返回值是上述算法的结果值.

定义

定义于头文件 boost/range/numeric.hpp

要求
对于第一个版本
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. Value 是 AssignableConcept 的一个模型.
  3. operator+ 被定义为: 左操作数类型为 Value, 右操作数为 SinglePassRange 值类型
  4. 上述运算符的返回类型可转换为 Value
对于第二个版本
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. Value 是 AssignableConcept 的一个模型.
  3. BinaryOperation 是 BinaryFunctionConcept 的一个模型.
  4. Value 可转换为 BinaryOperation 的第一个实参类型.
  5. SinglePassRange 的值类型可转换为 BinaryOperation 的第二个实参类型.
  6. BinaryOperation 的返回类型可转换为 Value
复杂度

线性复杂度. 恰好 distance(source_rng) .
