merge
原型 

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class OutputIterator
    >
OutputIterator merge(const SinglePassRange1& rng1,
                     const SinglePassRange2& rng2,
                     OutputIterator          out);

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class OutputIterator,
    class BinaryPredicate
    >
OutputIterator merge(const SinglePassRange1& rng1,
                     const SinglePassRange2& rng2,
                     OutputIterator          out,
                     BinaryPredicate         pred);

说明

merge 通过拷贝元素将两个已排序范围 rng1 和 rng2 合并为单个已排序范围. merge 是稳定的. 返回值是 out + distance(rng1) + distance(rng2).

merge 的两个版本在比较元素的方式上有所不同.

非谓词版本对范围值类型使用 operator<() . 谓词版本则使用谓词代替 operator<()

定义

定义于头文件 boost/range/algorithm/merge.hpp

要求

对于非谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • range_value<SinglePassRange1>::type 与 range_value<SinglePassRange2>::type 相同.
  • range_value<SinglePassRange1>::type 是 LessThanComparableConcept 的一个模型.
  • 对 range_value<SinglePassRange1>::type 类型对象的排序是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样
  • range_value<SinglePassRange1>::type 可转换为 OutputIterator 的值类型集合中的某一类型.

对于谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • range_value<SinglePassRange1>::type 与 range_value<SinglePassRange2>::type 相同.
  • BinaryPredicate 是 StrictWeakOrderingConcept 的一个模型.
  • SinglePassRange1 的值类型可同时转换为 BinaryPredicate 的两个实参类型.
  • range_value<SinglePassRange1>::type 可转换为 OutputIterator 的值类型集合中的某一类型.
前置条件:
对于非谓词版本:
  • rng1 的元素处于升序. 也就是说, 对于 [x,y] 的每对相邻元素 rng1, y < x == false
  • rng2 的元素处于升序. 也就是说, 对于 [x,y] 的每对相邻元素 rng2, y < x == false
  • 范围 rng1 与 [out, out + distance(rng1) + distance(rng2)) 不重叠.
  • 范围 rng2 与 [out, out + distance(rng1) + distance(rng2)) 不重叠.
  • [out, out + distance(rng1) + distance(rng2)) 是一个有效范围.
对于谓词版本:
  • rng1 的元素处于升序. 也就是说, 对于每对相邻元素 [x,y] (属于 rng1), pred(y, x) == false
  • rng2 的元素处于升序. 也就是说, 对于每对相邻元素 [x,y] (属于 rng2), pred(y, x) == false
  • 范围 rng1 与 [out, out + distance(rng1) + distance(rng2)) 不重叠.
  • 范围 rng2 与 [out, out + distance(rng1) + distance(rng2)) 不重叠.
  • [out, out + distance(rng1) + distance(rng2)) 是一个有效范围.
复杂度

线性复杂度. 若 rng1 和 rng2 均为空, 则不进行比较; 否则至多 distance(rng1) + distance(rng2) - 1 次比较.
