Forward Range

记法约定

X

A type that is a model of Forward Range.

a

Object of type X.

说明

A range X where boost::range_iterator<X>::type is a model of Forward Traversal Iterator.

细化自

Single Pass Range

Associated types

Distance type

boost::range_difference<X>::type

用于表示 Range 的两个迭代器之间距离的有符号整型. 该类型必须与迭代器的 distance 类型相同.

Size type

boost::range_size<X>::type

能表示 Range 的 distance 类型的任何非负值的无符号整型.
