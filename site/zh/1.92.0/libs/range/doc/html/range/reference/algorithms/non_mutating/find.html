find
原型 

template<class SinglePassRange, class Value>
typename range_iterator<SinglePassRange>::type
find(SinglePassRange& rng, Value val);

template<
    range_return_value re,
    class SinglePassRange,
    class Value
    >
typename range_return<SinglePassRange, re>::type
find(SinglePassRange& rng, Value val);

说明

find 中返回迭代器的版本返回范围 rng 中满足 *i == value 的第一个迭代器. 若不存在这样的迭代器, 则返回 end(rng) . 返回 range_return 的 find 版本以与上述返回迭代器相同的方式定义 found

定义

定义于头文件 boost/range/algorithm/find.hpp

要求
  • SinglePassRange 是 Single Pass Range 概念的一个模型.
  • Value 是 EqualityComparableConcept 的一个模型.
  • operator== 被定义为用于类型 Value 与 SinglePassRange 的值类型进行比较
复杂度

线性复杂度. 至多 distance(rng) 次相等比较.
