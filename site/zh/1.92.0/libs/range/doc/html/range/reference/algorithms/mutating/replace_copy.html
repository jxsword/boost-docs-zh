replace_copy
原型 

template<class ForwardRange, class OutputIterator, class Value>
OutputIterator replace_copy(const ForwardRange& rng, OutputIterator out,
                            const Value& what, const Value& with_what);

说明

replace_copy 拷贝每个元素 x (位于 rng 中), 使得输出范围 y 中对应的元素为 x == what ? with_what : x.

定义

定义于头文件 boost/range/algorithm/replace_copy.hpp

要求
  • ForwardRange 是 Forward Range 概念的一个模型.
  • ForwardRange 是可变的.
  • Value 可转换为 ForwardRange 的值类型.
  • Value 是 AssignableConcept 的一个模型.
  • OutputIterator 是 OutputIteratorConcept 的一个模型.
复杂度

线性复杂度. replace_copy 恰好执行 distance(rng) .
