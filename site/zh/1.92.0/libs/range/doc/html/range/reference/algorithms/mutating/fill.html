fill
原型 

template<class ForwardRange, class Value>
ForwardRange& fill( ForwardRange& rng, const Value& val );

说明

fill 将值 val 赋给范围 rng 中的每个元素

定义

定义于头文件 boost/range/algorithm/fill.hpp

要求
  • ForwardRange 是 Forward Range 概念的一个模型.
  • ForwardRange 是可变的.
  • Value 是 AssignableConcept 的一个模型.
  • Value 可转换为 ForwardRange 的值类型.
复杂度

线性复杂度. 恰好执行 distance(rng) 次赋值.
