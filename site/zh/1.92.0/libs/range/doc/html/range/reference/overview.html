概述

本库目前支持三类对象:

  • 类标准容器
  • std::pair<iterator,iterator>
  • 内置数组

即使主模板的行为恰好使得标准容器在默认情况下受支持, 要求却远低于标准容器的要求. 例如, 工具类 iterator_range 实现了 最小接口 (使该类成为 前向范围 所需)

更多细节另请参见 Range 概念.
