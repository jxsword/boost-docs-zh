copy_backward
原型 

template<class BidirectionalRange, class BidirectionalOutputIterator>
    BidirectionalOutputIterator
        copy_backward(const BidirectionalRange& source_rng,
                      BidirectionalOutputIterator out_it);

说明

copy_backward copies all elements from source_rng to the range [out_it - distance(source_rng), out_it).

值按逆序拷贝. 返回值是 out_it - distance(source_rng).

请特别注意, 与所有其他标准算法不同, out_it 表示输出序列的 末尾

定义

定义于头文件 boost/range/algorithm/copy_backward.hpp

要求
  • BidirectionalRange 是 Bidirectional Range 概念的一个模型.
  • OutputIterator 是 OutputIteratorConcept 的一个模型.
  • value_type (属于 Bidirectional Range 概念) 可转换为 OutputIterator 的值类型集合中的某一类型.
前置条件:
  • out_it 不是 source_rng 内的迭代器.
  • [out_it, out_it + distance(source_rng)) 是一个有效范围.
复杂度

线性复杂度. 恰好执行 distance(source_rng) 次赋值.
