random_shuffle
原型 

template<class RandomAccessRange>
RandomAccessRange& random_shuffle(RandomAccessRange& rng);

template<class RandomAccessRange>
const RandomAccessRange& random_shuffle(const RandomAccessRange& rng);

template<class RandomAccessRange, class Generator>
RandomAccessRange& random_shuffle(RandomAccessRange& rng, Generator& gen);

template<class RandomAccessRange, class Generator>
const RandomAccessRange& random_shuffle(const RandomAccessRange& rng, Generator& gen);

说明

random_shuffle 随机重新排列 rng 中的元素. 未指定 random_shuffle 的 Generator 版本使用内部随机数生成器; 指定了 random_shuffle 的 Generator 版本则改用它. 返回打乱后的范围.

定义

定义于头文件 boost/range/algorithm/random_shuffle.hpp

要求

对于不带 Generator 的版本:

  • RandomAccessRange 是 Random Access Range 概念的一个模型.

对于带 Generator 的版本:

  • RandomAccessRange 是 Random Access Range 概念的一个模型.
  • Generator 是 RandomNumberGeneratorConcept 的一个模型.
  • RandomAccessRange 的 distance 类型可转换为 Generator 的实参类型.
前置条件:
  • distance(rng) 小于 gen 的最大值.
复杂度

线性复杂度. 若 !empty(rng), 则恰好执行 distance(rng) - 1 次交换.
