从 1.45 版本升级

  1. size 除支持 Random Access Range 外, 现在还支持通过调用无限定的 range_calculate_size(rng) 函数进行扩展
  2. 现在除可用于任何 RandomAccessRange 外, 还可用于 有效的任何 SinglePassRange.boost::size(rng)
  3. 不再要求 或 distance(rng) % stride_size == 0 stride_size < distance(rng)
