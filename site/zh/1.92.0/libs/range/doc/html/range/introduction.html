引言

迄今为止, 泛型算法都是以两个或多个迭代器来规定的. 两个迭代器共同构成一个算法可以处理的值范围. 这带来了非常通用的接口, 但也导致算法的使用有些笨拙, 需要冗余地指定容器名称. 因此, 我们希望提高算法的抽象层次, 使其尽可能以 范围 来规定接口.

整个 C++ 社区中使用的最常见范围形式是标准库容器. 然而在编写算法时, 人们常常希望算法能够接受其他类型, 只要这些类型提供足够的功能来满足泛型代码的需要 前提是应用了合适的间接层 . 例如, 只要使用了合适的适配器, 原生数组通常就适合与处理容器的泛型代码一起使用. 同样, 若经过适当适配, 以空字符结尾的字符串也可以当作字符容器来对待.

因此, 本库提供了相应的手段来适配类标准容器、以空字符结尾的字符串、迭代器的 std::pairs、原生数组 (以及更多) 等类型, 使同一份泛型代码能够处理它们全部. 基本思想是利用 元函数 和独立函数再增加一层间接, 从而消除句法差异和/或语义差异.

主要优点是

  • 更简单地实现和规定泛型范围算法
  • 更灵活、紧凑且易于维护的客户端代码
  • 安全地使用内置数组 (针对遗留代码; 不然还有什么理由使用内置数组呢?)

示例 - 遍历 map 中的值 

using namespace boost;
using namespace boost::adaptors;
for_each( my_map | map_values, fn );

示例 - 遍历 map 中的键 

using namespace boost;
using namespace boost::adaptors;
for_each( my_map | map_keys, fn );

示例 - 将 map 中的偶数值按逆序压入容器 target 

using namespace boost;
using namespace boost::adaptors;
// Assume that is_even is a predicate that has been implemented elsewhere...
push_back(target, my_map | map_values | filtered(is_even()) | reversed);
