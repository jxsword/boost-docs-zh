partition
原型 

template<
    class ForwardRange,
    class UnaryPredicate
    >
typename range_iterator<ForwardRange>::type
partition(ForwardRange& rng, UnaryPredicate pred);

template<
    class ForwardRange,
    class UnaryPredicate
    >
typename range_iterator<const ForwardRange>::type
partition(const ForwardRange& rng, UnaryPredicate pred);

template<
    range_return_value re,
    class ForwardRange,
    class UnaryPredicate
    >
typename range_return<ForwardRange, re>::type
partition(ForwardRange& rng, UnaryPredicate pred);

template<
    range_return_value re,
    class ForwardRange,
    class UnaryPredicate
    >
typename range_return<const ForwardRange, re>::type
partition(const ForwardRange& rng, UnaryPredicate pred);

说明

partition 依据 rng 对 pred 中的元素进行排序, 使满足 pred 的元素排在不能满足的元素之前. 在返回单个迭代器的版本中, 返回值是中间迭代器. 在具有可配置 range_return 的版本中, found 对应于中间迭代器.

定义

定义于头文件 boost/range/algorithm/partition.hpp

要求
  • ForwardRange 是 Forward Range 概念的一个模型. 对于 C++11 之前的 C++ 版本, 底层的 std::partition 要求双向迭代器, 因此旧版库的要求是 Bidirectional Range
  • UnaryPredicate 是 PredicateConcept 的一个模型.
  • ForwardRange 的值类型可转换为 UnaryPredicate 的实参类型.
复杂度

线性复杂度. 恰好应用 distance(rng) 次 pred, 并且至多 distance(rng) / 2 次交换.
