inner_product
原型 

template<class SinglePassRange1,
         class SinglePassRange2,
         class Value>
    Value inner_product( const SinglePassRange1& rng1,
                         const SinglePassRange2& rng2,
                         Value                   init );

template<class SinglePassRange1,
         class SinglePassRange2,
         class Value,
         class BinaryOperation1,
         class BinaryOperation2>
    Value inner_product( const SinglePassRange1& rng1,
                         const SinglePassRange2& rng2,
                         Value                   init,
                         BinaryOperation1        op1,
                         BinaryOperation2        op2 );

说明

inner_product 计算范围 rng1 和 rng2 的广义内积.

关于 inner_product 算法的更多信息请参见 inner_product.

定义

定义于头文件 boost/range/numeric.hpp

要求
对于第一个版本
  1. SinglePassRange1 是 Single Pass Range 概念的一个模型.
  2. SinglePassRange2 是 Single Pass Range 概念的一个模型.
  3. Value 是 AssignableConcept 的一个模型.
  4. 若 x 是类型 Value 的对象, y 是 SinglePassRange1 值类型的对象, 并且 z 是 SinglePassRange2 值类型的对象, 则 x + y * z 有定义.
  5. 表达式 x + y * z 的结果类型可转换为 Value.
对于第二个版本
  1. SinglePassRange1 是 Single Pass Range 概念的一个模型.
  2. SinglePassRange2 是 Single Pass Range 概念的一个模型.
  3. Value 是 AssignableConcept 的一个模型.
  4. BinaryOperation1 是 BinaryFunctionConcept 的一个模型.
  5. BinaryOperation2 是 BinaryFunctionConcept 的一个模型.
  6. SinglePassRange1 的值类型可转换为 BinaryOperation2 的第一个实参类型.
  7. SinglePassRange2 的值类型可转换为 BinaryOperation2 的第二个实参类型.
  8. Value 可转换为 BinaryOperation1 的值类型.
  9. BinaryOperation2 的返回类型可转换为 BinaryOperation1 的第二个实参类型.
  10. BinaryOperation1 的返回类型可转换为 Value
前置条件:

distance(rng2) >= distance(rng1) 是一个有效范围.

复杂度

线性复杂度. 恰好 distance(rng) .
