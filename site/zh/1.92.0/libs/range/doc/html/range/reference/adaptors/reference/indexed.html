indexed
indexed 示例

语法

代码

管道

rng | boost::adaptors::indexed()

管道

rng | boost::adaptors::indexed(start_index)

函数

boost::adaptors::index(rng)

函数

boost::adaptors::index(rng, start_index)

说明

每个返回的 boost::range::index_value 之内的索引等于 start_index 加上元素相对范围起点的偏移量. 在省略 start_index 的函数版本中, 起始索引被取为 0

  • 用途: 适配 rng, 使其返回的元素带有来自 rng 的对应值以及一个数值索引
  • 返回: 一个经适配的范围, 它同时返回元素及其关联索引. 返回范围的元素类型为:

boost::range::index_value<
    typename boost::range_reference<decltype(rng)>::type,
    typename boost::range_difference<decltype(rng)>::type
>

index_value 的概要如下:

template<class T, class Indexable=std::ptrdiff_t>
class index_value : public boost::tuple<Indexable, T>
{
public:

    typedef ...unspecified...       index_type;
    typedef ...unspecified...       const_index_type;

    typedef ...unspecified...       value_type;
    typedef ...unspecified...       const_value_type;

    // ...unspecified... constructors

    index_type index();
    const_index_type index() const;

    value_type value();
    const_value_type value() const;
};

  • 范围类别: 单遍范围
  • 范围返回类型: boost::indexed_range<decltype(rng)>
  • 返回范围的类别: 即 rng 的范围类别, 当且仅当 rng 不是 双向范围. 若 rng 是 双向范围, 则返回范围的类别为 前向范围. 将 双向范围 输入降级为 前向范围 的理由是为了避免对 boost::end(rng) 进行缓慢的索引计算.
indexed 示例 

#include <boost/range/adaptor/indexed.hpp>
#include <boost/assign.hpp>
#include <iterator>
#include <iostream>
#include <vector>


int main(int argc, const char* argv[])
{
    using namespace boost::assign;
    using namespace boost::adaptors;

    std::vector<int> input;
    input += 10,20,30,40,50,60,70,80,90;

    for (const auto& element : input | indexed(0))
    {
        std::cout << "Element = " << element.value()
                  << " Index = " << element.index()
                  << std::endl;
    }

    return 0;
}

这将产生如下输出:

Element = 10 Index = 0
Element = 20 Index = 1
Element = 30 Index = 2
Element = 40 Index = 3
Element = 50 Index = 4
Element = 60 Index = 5
Element = 70 Index = 6
Element = 80 Index = 7
Element = 90 Index = 8
