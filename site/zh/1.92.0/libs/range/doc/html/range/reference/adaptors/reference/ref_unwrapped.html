ref_unwrapped
ref_unwrapped 示例

语法

代码

管道

rng | boost::adaptors::ref_unwrapped

函数

boost::adaptors::ref_unwrap(rng)

该适配器产生的范围会对范围中的所有值应用 .get() . 它适合用于迭代 std::reference_wrapper 值的范围或具有类似语义的值.

该适配器仅适用于 C++11 (及以上).

  • 前置条件: 范围的 value_type 具有 .get() const
  • 后置条件: 对于返回范围中的所有元素 x, x 是 y.get() 的结果, 其中 y 是原范围中的对应元素.
  • 范围类别: 单遍范围
  • 范围返回类型: boost::unwrap_ref_range<decltype(rng)>
  • 返回范围的类别: 即 rng 的范围类别.
ref_unwrapped 示例 

#include <boost/range/adaptor/ref_unwrapped.hpp>
#include <iostream>
#include <vector>

struct example
{
  int value;
};

int main(int argc, const char* argv[])
{
    using boost::adaptors::ref_unwrapped;

    example one{1};
    example two{2};
    example three{3};

    std::vector<std::reference_wrapper<example> > input{one, two, three};

    for (auto&& entry : input | ref_unwrapped)
    {
      std::cout << entry.value;
    }

    return 0;
}

这将产生如下输出 123.
