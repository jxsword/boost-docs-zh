从 1.34 版本升级

Boost 1.35 版本引入了本库的一些较大重构:

  1. 放弃了对字符数组的直接支持, 以便统一处理所有数组. 作为替代, 字符串算法可以使用新函数 as_literal()
  2. size 现在要求 Random Access Range . 旧的行为以 distance() 的形式提供
  3. range_size<T>::type 已被完全移除, 由 range_difference<T>::type 取代
  4. boost_range_begin() 和 boost_range_end() 已分别重命名为 range_begin() 和 range_end().
  5. range_result_iterator<T>::type 和 range_reverse_result_iterator<T>::type 已分别重命名为 range_iterator<T>::type 和 range_reverse_iterator<T>::type.
  6. 使自定义类型与本库协同工作的过程已大大简化. 详情参见 针对 UDT 扩展本库.
