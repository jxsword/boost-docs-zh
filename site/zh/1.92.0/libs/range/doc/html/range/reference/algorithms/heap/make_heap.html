make_heap
原型 

template<class RandomAccessRange>
RandomAccessRange& make_heap(RandomAccessRange& rng);

template<class RandomAccessRange>
const RandomAccessRange& make_heap(const RandomAccessRange& rng);

template<class RandomAccessRange, class Compare>
RandomAccessRange& make_heap(RandomAccessRange& rng, Compare pred);

template<class RandomAccessRange, class Compare>
const RandomAccessRange& make_heap(const RandomAccessRange& rng, Compare pred);

说明

make_heap 将 rng 转换为堆.

排序关系在非谓词版本中通过使用 operator< 确定, 在谓词版本中则通过求值 pred 确定.

定义

定义于头文件 boost/range/algorithm/heap_algorithm.hpp

要求

对于非谓词版本:

  • RandomAccessRange 是 Random Access Range 概念的一个模型.
  • RandomAccessRange 是可变的.
  • RandomAccessRange 的值类型是 LessThanComparableConcept 的一个模型.
  • 类型为 RandomAccessRange 的对象的排序是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样

对于谓词版本:

  • RandomAccessRange 是 Random Access Range 概念的一个模型.
  • RandomAccessRange 是可变的.
  • Compare 是 StrictWeakOrderingConcept 的一个模型.
  • RandomAccessRange 的值类型可转换为 Compare 的两个实参类型.
复杂度

线性复杂度. 至多 3 * distance(rng) 次比较.
