实用工具

类 iterator_range
类 sub_range
Function combine
Function join

封装一对迭代器的抽象非常有用. 标准库在某些情况下使用 std::pair, 但该类使用起来很繁琐, 因为我们需要指定两个模板实参, 而且为了所有范围算法的用途, 我们必须强制这两个模板实参相同. 此外, std::pair<iterator,iterator> 几乎不自文档化, 而更具体领域的类名则可以. 因此提供了这两个类:

  • 类 iterator_range
  • 类 sub_range
  • 函数 combine
  • 函数 join

iterator_range 类以 Forward Traversal Iterator 为模板参数, 每当需要相当通用的代码时就应使用它. sub_range 类以 Forward Range 为模板参数, 它不那么通用, 但更容易使用, 因为其模板实参更容易指定. 不过最大的区别在于 sub_range 可以传播 const 性, 因为它知道相应的 const_iterator 是什么.

这两个类都可以当作范围使用, 因为它们实现了使其自动工作所需的 最小接口.
