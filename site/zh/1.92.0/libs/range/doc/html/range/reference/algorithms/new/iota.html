iota
原型 

template<class ForwardRange, class Value>
ForwardRange& iota(ForwardRange& rng, Value x);

说明

iota 向前遍历 rng, 其中 y 中的每个元素 rng 被赋予一个等价于 x + boost::distance(boost::begin(rng), it) 的值

定义

定义于头文件 boost/range/algorithm_ext/iota.hpp

要求
  1. ForwardRange 是 Forward Range 概念的一个模型.
  2. Value 是 Incrementable 概念的一个模型.
复杂度

线性复杂度. 恰好 distance(rng) 次对 rng 的赋值.
