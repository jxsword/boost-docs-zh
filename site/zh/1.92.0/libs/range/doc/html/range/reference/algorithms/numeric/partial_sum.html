partial_sum
原型 

template<class SinglePassRange,
         class OutputIterator>
OutputIterator partial_sum(const SinglePassRange& rng,
                           OutputIterator out_it);

template<class SinglePassRange,
         class OutputIterator,
         class BinaryOperation>
OutputIterator partial_sum(const SinglePassRange& rng,
                           OutputIterator out_it,
                           BinaryOperation op);

说明

partial_sum 以与 rng 相同的方式计算 std::partial_sum(boost::begin(rng), boost::end(rng), out_it) 的广义部分和. 参见 partial_sum.

定义

定义于头文件 boost/range/numeric.hpp

要求
对于第一个版本
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. OutputIterator 是 OutputIteratorConcept 的一个模型.
  3. 若 x 和 y 是 SinglePassRange 值类型的对象, 则 x + y 有定义.
  4. x + y 的返回类型可转换为 SinglePassRange 的值类型.
  5. SinglePassRange 的值类型可转换为 OutputIterator 的值类型集合中的某一类型.
对于第二个版本
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. OutputIterator 是 OutputIteratorConcept 的一个模型.
  3. BinaryOperation 是 BinaryFunctionConcept 的一个模型.
  4. BinaryOperation 的结果类型可转换为 SinglePassRange 的值类型.
  5. SinglePassRange 的值类型可转换为 OutputIterator 的值类型集合中的某一类型.
前置条件:

[result, result + distance(rng)) 是一个有效范围.

复杂度

线性复杂度. 若 empty(rng) 则零次应用, 否则执行 distance(rng) - 1 次应用.
