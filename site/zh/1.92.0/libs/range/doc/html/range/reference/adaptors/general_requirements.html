一般要求

在生成器表达式的描述中, 使用以下记号:

  • fwdRng 是一个表达式, 其类型为 R, 该类型对 ForwardRange 建模
  • biRng 是一个表达式, 其类型为 R, 该类型对 BidirectionalRange 建模
  • rndRng 是一个表达式, 其类型为 R, 该类型对 RandomAccessRange 建模
  • pred 是一个表达式, 其类型对 UnaryPredicate 建模
  • bi_pred 是一个表达式, 其类型对 BinaryPredicate 建模
  • fun 是一个表达式, 其类型对 UnaryFunction 建模
  • value, new_value 和 old_value 是可转换为 boost::range_value<R>::type 的对象
  • n,m 是可转换为 range_difference<R>::type 的整数表达式

另请注意, boost::range_value<R>::type 必须可隐式转换为 pred, bi_pred 和 fun 的类型实参.

在以下适配器描述中, Range Category (范围类别) 指传递给适配器的范围所需的最低范围概念. 除非另有说明, 结果范围与输入范围是同一范围概念的模型.

Returned Range Category (返回范围的类别) 即返回范围的概念. 在某些情况下, 返回范围的类别低于传递给适配器的范围. 例如, filtered 适配器无论输入如何都只返回 ForwardRange, 与输入无关.

此外, 以下规则适用于任何形如下式的表达式

rng | boost::adaptors::adaptor_generator

1. 将 operator|() 应用于范围 R (总是左实参) 和范围适配器 RA (总是右实参) 会产生一个新的范围类型, 该类型可能不符合与 R 相同的范围概念.

2. operator|() 的返回类型在其他方面未作规定.

3. operator|() 通过实参依赖查找 (ADL) 找到, 因为范围适配器实现于命名空间 boost::adaptors 中.

4. operator|() 用于以 惰性 的方式添加新行为, 且从不修改其左实参.

5. 从左实参提取的所有迭代器, 都是通过带限定名的调用 boost::begin() 和 boost::end() 来提取的.

6. 除了下文的 throw 子句之外, operator|() 还可能因拷贝迭代器而抛出异常. 如果这种拷贝不会抛出异常, 那么整个表达式也不会.
