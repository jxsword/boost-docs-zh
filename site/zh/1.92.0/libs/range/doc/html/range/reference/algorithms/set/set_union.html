set_union
原型 

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class OutputIterator
    >
OutputIterator set_union(const SinglePassRange1& rng1,
                         const SinglePassRange2& rng2,
                         OutputIterator          out);

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class OutputIterator,
    class BinaryPredicate
    >
OutputIterator set_union(const SinglePassRange1& rng1,
                         const SinglePassRange2& rng2,
                         OutputIterator          out,
                         BinaryPredicate         pred);

说明

set_union 构造一个已排序范围, 它是已排序范围 rng1 和 rng2 的并集. 返回值是输出范围的末尾. 排序关系在非谓词版本中通过使用 operator< 确定, 在谓词版本中则通过求值 pred 确定.

定义

定义于头文件 boost/range/algorithm/set_algorithm.hpp

要求

对于非谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • OutputIterator 是 OutputIteratorConcept 的一个模型.
  • SinglePassRange1 与 SinglePassRange2 具有相同的值类型.
  • SinglePassRange1 的值类型是 LessThanComparableConcept 的一个模型.
  • SinglePassRange2 的值类型是 LessThanComparableConcept 的一个模型.
  • 类型为 SinglePassRange1 的对象的排序是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样
  • 类型为 SinglePassRange2 的对象的排序是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样

对于谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • OutputIterator 是 OutputIteratorConcept 的一个模型.
  • SinglePassRange1 与 SinglePassRange2 具有相同的值类型.
  • BinaryPredicate 是 StrictWeakOrderingConcept 的一个模型.
  • SinglePassRange1 的值类型可转换为 BinaryPredicate 的第一个实参类型.
  • SinglePassRange2 的值类型可转换为 BinaryPredicate 的第二个实参类型.
前置条件:

对于非谓词版本:

rng1 和 rng2 依据 operator< 按升序排序.

对于谓词版本:

rng1 和 rng2 依据 pred 按升序排序.

复杂度

线性复杂度. O(N), 其中 N 为 distance(rng1) + distance(rng2).
