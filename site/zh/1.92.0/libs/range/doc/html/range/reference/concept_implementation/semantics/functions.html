as_literal(x)

iterator_range<U> 其中 U 为 Char* 若 x 是指向字符串的指针; 否则 U 为 range_iterator<X>::type

[s,s + std::char_traits<X>::length(s)) 若 s 是 Char* 或 Char 的数组 [boost::begin(x),boost::end(x)) 否则

对指向字符串的指针或 Char 的数组为线性时间, 否则为常量时间

as_array(x)

iterator_range<X>

[boost::begin(x),boost::end(x))

当你想清楚地表明你的代码是只读的时, 以 const_ 命名的特殊函数很有用.

as_literal() 可在字符串算法库中 内部 使用, 从而正确处理字符数组.

as_array() 可与字符串算法库一起使用, 以明确字符数组被当作数组而不是字符串来处理.

注意, 上述函数应始终以限定方式调用 (boost::), 以避免 意外的 实参依赖查找 (ADL).
