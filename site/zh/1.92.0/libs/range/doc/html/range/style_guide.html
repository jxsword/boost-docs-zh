术语与风格指南

一致术语的使用对 范围 和基于范围的算法, 与对迭代器和基于迭代器的算法同样重要. 若采用一套惯用名称, 我们就可以避免误解, 并编写 自文档化 的泛型函数原型.

由于范围由特定的底层迭代器类型刻画, 每种迭代器类型对应一种范围. 因此我们可以谈论以下几种范围:

  • 值访问类别:
    • 可读范围
    • 可写范围
    • 可交换范围
    • 左值范围
  • 遍历类别:
    • Single Pass Range
    • Forward Range
    • Bidirectional Range
    • Random Access Range

注意我们如何使用了来自 新式迭代器 的类别.

注意, 迭代器 (因而范围也是如此) 有一个 遍历 属性, 以及来自 值访问 类别的一个或多个属性. 所以实际上我们主要谈论诸如以下的混合体:

  • 随机访问可读可写范围
  • 前向左值范围

按照惯例, 我们应始终像上文那样先指定 遍历 属性. 这似乎合理, 因为只会有一个 遍历 属性, 但可能有多个 值访问 属性.

不过, 如果另一个类别无关紧要, 只指定一个类别也许是合理的. 例如, iterator_range 可以从前向范围构造. 这意味着我们不关心该范围具有哪些 值访问 属性. 类似地, 可读范围将是具有最低可能 遍历 属性 (单遍) 的范围.

作为另一个例子, 考虑我们如何指定 std::sort() 的接口. 算法的接口通常更繁琐, 因为 遍历 和 值访问 属性都必须精确定义. 基于迭代器的版本如下:

template< class RandomAccessTraversalReadableWritableIterator >
void sort( RandomAccessTraversalReadableWritableIterator first,
           RandomAccessTraversalReadableWritableIterator last );

对于范围, 接口变为

template< class RandomAccessReadableWritableRange >
void sort( RandomAccessReadableWritableRange& r );
