inplace_merge
原型 

template<class BidirectionalRange>
BidirectionalRange&
inplace_merge( BidirectionalRange& rng,
               typename range_iterator<BidirectionalRange>::type middle );

template<class BidirectionalRange>
const BidirectionalRange&
inplace_merge( const BidirectionalRange& rng,
               typename range_iterator<const BidirectionalRange>::type middle );

template<class BidirectionalRange, class BinaryPredicate>
BidirectionalRange&
inplace_merge( BidirectionalRange& rng,
               typename range_iterator<BidirectionalRange>::type middle,
               BinaryPredicate pred );

template<class BidirectionalRange, class BinaryPredicate>
const BidirectionalRange&
inplace_merge( const BidirectionalRange& rng,
               typename range_iterator<const BidirectionalRange>::type middle,
               BinaryPredicate pred );

说明

inplace_merge 将两个连续的已排序范围 [begin(rng), middle) 和 [middle, end(rng)) 合并为单个已排序范围 [begin(rng), end(rng)) . 也就是说, 它从一个由两段各自升序组成的范围 [begin(rng), end(rng)) 开始, 并重新排列使整个范围升序. inplace_merge 是稳定的, 即每个输入范围内元素的相对次序均得以保留.

定义

定义于头文件 boost/range/algorithm/inplace_merge.hpp

要求

对于非谓词版本:

  • BidirectionalRange 是 Bidirectional Range 概念的一个模型.
  • BidirectionalRange 是可变的.
  • range_value<BidirectionalRange>::type 是 LessThanComparableConcept 的一个模型
  • 对 range_type<BidirectionalRange>::type 类型对象的排序是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样

对于谓词版本: * BidirectionalRange 是 Bidirectional Range 概念的一个模型. * BidirectionalRange 是可变的. * BinaryPredicate 是 StrictWeakOrderingConcept 的一个模型. * BidirectionalRange 的值类型可同时转换为 BinaryPredicate 的两个实参类型.

前置条件:
对于非谓词版本:
  • middle 位于范围 rng 中.
  • [begin(rng), middle) 处于升序. 也就是说, 对于每一对相邻元素 [x,y], y < x 为 false
  • [middle, end(rng)) 处于升序. 也就是说, 对于每一对相邻元素 [x,y], y < x 为 false
对于谓词版本:
  • middle 位于范围 rng 中.
  • [begin(rng), middle) 处于升序. 也就是说, 对于每一对相邻元素 [x,y], pred(y,x) == false
  • [middle, end(rng)) 处于升序. 也就是说, 对于每一对相邻元素 [x,y], pred(y,x) == false
复杂度

最坏情况: O(N log(N))
