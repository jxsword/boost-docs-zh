lexicographical_compare
原型 

template<
    class SinglePassRange1,
    class SinglePassRange2
    >
bool lexicographical_compare(const SinglePassRange1& rng1,
                             const SinglePassRange2& rng2);

template<
    class SinglePassRange1,
    class SinglePassRange2,
    class BinaryPredicate
    >
bool lexicographical_compare(const SinglePassRange1& rng1,
                             const SinglePassRange2& rng2,
                             BinaryPredicate pred);

说明

lexicographical_compare 逐元素地将 rng1 与 rng2 比较. 若来自 rng1 的元素小于来自 rng2 的元素, 则返回 true . 若 rng1 先于 rng2 到达末尾, 这也会使返回值为 true . 在所有其他情况下返回值为 false . 元素使用 operator< 比较 (在 lexicographical_compare 的非谓词版本中), 或使用 pred (在谓词版本中).

定义

定义于头文件 boost/range/algorithm/lexicographical_compare.hpp

要求

对于 lexicographical_compare 的非谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • SinglePassRange1 的值类型是 LessThanComparableConcept 的一个模型.
  • SinglePassRange2 的值类型是 LessThanComparableConcept 的一个模型.
  • 设 x 为 SinglePassRange1 值类型的一个对象. 设 y 为 SinglePassRange2 值类型的一个对象. x < y 必须有效. y < x 必须有效.

对于 lexicographical_compare 的谓词版本:

  • SinglePassRange1 是 Single Pass Range 概念的一个模型.
  • SinglePassRange2 是 Single Pass Range 概念的一个模型.
  • BinaryPredicate 是 BinaryPredicateConcept 的一个模型.
  • SinglePassRange1 的值类型可转换为 BinaryPredicate 的第一个实参类型.
  • SinglePassRange2 的值类型可转换为 BinaryPredicate 的第二个实参类型.
复杂度

线性复杂度. 至多 2 * min(distance(rng1), distance(rng2)) 次比较.
