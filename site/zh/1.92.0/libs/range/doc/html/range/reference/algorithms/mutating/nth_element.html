nth_element
原型 

template<class RandomAccessRange>
RandomAccessRange& nth_element(
    RandomAccessRange& rng,
    typename range_iterator<RandomAccessRange>::type nth);

template<class RandomAccessRange>
const RandomAccessRange& nth_element(
    const RandomAccessRange& rng,
    typename range_iterator<const RandomAccessRange>::type nth);

template<class RandomAccessRange>
RandomAccessRange& nth_element(
    RandomAccessRange& rng,
    typename range_iterator<RandomAccessRange>::type nth,
    BinaryPredicate sort_pred);

template<class RandomAccessRange>
const RandomAccessRange& nth_element(
    const RandomAccessRange& rng,
    typename range_iterator<const RandomAccessRange>::type nth,
    BinaryPredicate sort_pred);

说明

nth_element 对元素范围进行部分排序. nth_element 排列范围 rng 使得与迭代器 nth 对应的元素, 等于若对 rng 进行排序则该位置上应有的元素.

定义

定义于头文件 boost/range/algorithm/nth_element.hpp

要求

对于非谓词版本:

  • RandomAccessRange 是 Random Access Range 概念的一个模型.
  • RandomAccessRange 是可变的.
  • RandomAccessRange 的值类型是 LessThanComparableConcept 的一个模型.
  • RandomAccessRange 值类型上的排序关系是一个 严格弱序, 正如 LessThanComparableConcept 要求中所定义的那样

对于谓词版本:

  • RandomAccessRange 是 Random Access Range 概念的一个模型.
  • RandomAccessRange 是可变的.
  • BinaryPredicate 是 StrictWeakOrderingConcept 的一个模型.
  • RandomAccessRange 的值类型可转换为 BinaryPredicate 的两个实参类型.
复杂度

平均而言, 与 distance(rng) 成线性关系.
