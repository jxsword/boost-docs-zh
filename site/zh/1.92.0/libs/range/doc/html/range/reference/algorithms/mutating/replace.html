replace
原型 

template<
    class ForwardRange,
    class Value
    >
ForwardRange& replace(ForwardRange& rng, const Value& what, const Value& with_what);

template<
    class ForwardRange,
    class UnaryPredicate
    >
const ForwardRange& replace(const ForwardRange& rng, const Value& what, const Value& with_what);

说明

replace 将 rng 中每个等于 what 的元素替换为 with_what . 返回对 rng 的引用.

定义

定义于头文件 boost/range/algorithm/replace.hpp

要求
  • ForwardRange 是 Forward Range 概念的一个模型.
  • ForwardRange 是可变的.
  • Value 可转换为 ForwardRange 的值类型.
  • Value 是 AssignableConcept 的一个模型.
  • Value 是 EqualityComparableConcept 的一个模型, 并且可与 ForwardRange 值类型的对象进行相等比较.
复杂度

线性复杂度. replace 恰好执行 distance(rng) 次相等比较, 以及至多 distance(rng) 次赋值.
