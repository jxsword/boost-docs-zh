insert
原型 

template<
    class Container,
    class SinglePassRange
>
Container& insert(Container& target,
                  typename Container::iterator before,
                  const SinglePassRange& from);

// This overload is for target containers that do not require an insertion
// position e.g. set/map
template<
    class Container,
    class SinglePassRange
>
Container& insert(Container& target, const SinglePassRange& from);

说明

insert 将范围 from 中位于 before 迭代器之前的所有元素放入 target

定义

定义于头文件 boost/range/algorithm_ext/insert.hpp

要求
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. Container 支持在指定位置插入.
  3. SinglePassRange 的值类型可转换为 Container 的值类型.
复杂度

线性复杂度. 执行 distance(from) 次赋值.
