for_each
原型 

template<
    class SinglePassRange,
    class UnaryFunction
    >
UnaryFunction for_each(SinglePassRange& rng, UnaryFunction fun);

template<
    class SinglePassRange,
    class UnaryFunction
    >
UnaryFunction for_each(const SinglePassRange& rng, UnaryFunction fun);

说明

for_each 向前遍历 rng, 并对每个元素 x 调用 fun(x)

定义

定义于头文件 boost/range/algorithm/for_each.hpp

要求
  • SinglePassRange 是 Single Pass Range 概念的一个模型.
  • UnaryFunction 是 UnaryFunctionConcept 的一个模型.
  • UnaryFunction 不会通过其实参应用任何非常量操作.
  • SinglePassRange 的值类型可转换为 UnaryFunction 的实参类型.
复杂度

线性复杂度. 恰好 distance(rng) 次对 UnaryFunction 的调用.
