find_if
原型 

template<class SinglePassRange, class UnaryPredicate>
typename range_iterator<SinglePassRange>::type
find_if(SinglePassRange& rng, UnaryPredicate pred);

template<
    range_return_value re,
    class SinglePassRange,
    class UnaryPredicate
    >
typename range_return<SinglePassRange, re>::type
find_if(SinglePassRange& rng, UnaryPredicate pred);

说明

find_if 中返回迭代器的版本返回范围 rng 中使 pred(*i) 为 true 的第一个迭代器. 若不存在这样的迭代器, 则返回 end(rng)

find_if 中返回 range_return 的版本以与上述返回迭代器相同的方式定义 found.

定义

定义于头文件 boost/range/algorithm/find_if.hpp

要求
  • SinglePassRange 是 Single Pass Range 概念的一个模型.
  • UnaryPredicate 是 PredicateConcept 的一个模型.
  • SinglePassRange 的值类型可转换为 UnaryPredicate 的实参类型.
前置条件:

对于 i 中的每个迭代器 rng, *i 都在 UnaryPredicate 的定义域内

复杂度

线性复杂度. 至多 distance(rng) 次对 pred 的调用.
