copy_n
原型 

template<class SinglePassRange, class Size, class OutputIterator>
OutputIterator copy_n(const SinglePassRange& rng, Size n, OutputIterator out);

说明

copy_n 的提供是为了完全复刻标准算法头文件; 更可取的做法是使用 Range 适配器和扩展函数, 以更高的安全性获得相同的结果.

copy_n 将 [boost::begin(rng), boost::begin(rng) + n) 中的元素拷贝到范围 [out, out + n)

定义

定义于头文件 boost/range/algorithm_ext/copy_n.hpp

要求
  1. SinglePassRange 是 Single Pass Range 概念的一个模型.
  2. Size 是 Integer 概念的一个模型.
  3. OutputIterator 是 OutputIteratorConcept 的一个模型.
复杂度

线性复杂度. 恰好拷贝 n 个元素.
