序列化

void_cast

动机

C++ 提供了运算符 dynamic_cast<T>(U * u), 用于在运行期把指针在两种相关类型之间转换. 但是, 它只能用于多态类. 也就是说, 只能用于至少有一个虚函数的相关类. 把指针的序列化限制为只有这类类, 会削弱本库的适用性.

用法

以下函数定义在头文件 void_cast.hpp 中. 它们声明在命名空间 boost::serialization 中. 


template<class Derived, class Base>
const void_cast_detail::void_caster &
void_cast_register(
    Derived const * derived = NULL, 
    Base * const base = NULL
);

该函数"注册"一对相关类型. 它把 Derived 直接派生自 Base 的事实存入一个全局表.
  • 这种"注册"可以在程序中任何地方调用. 该表在运行期之前构建, 可在程序中任何其他地方使用.
  • 只需注册相邻的基类/派生类对. 也就是说, 
    
  void_cast_register<A, B>();
  void_cast_register<B, C>();
    会自动推导出 A 可向上转换为 C (反之亦然) 这一事实.


void *
void_upcast(
    extended_type_info const & derived_type,
    extended_type_info const & base_type,
    void * const t 
);



void *
void_downcast(
    extended_type_info const & derived_type,
    extended_type_info const & base_type,
    void * const t 
);

这些函数把 void 指针从一种类型转换为另一种. 源类型和定义类型通过传递对应 extended_type_info 记录的引用来指定. 试图在未用 void_cast_register "注册"的类型之间转换会抛出 boost::archive::archive_exception, 其值等于 unregistered_cast
