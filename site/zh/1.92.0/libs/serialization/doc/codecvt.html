utf8_codecvt_facet

template<
    typename InternType = wchar_t, 
    typename ExternType = char
> utf8_codecvt_facet

设计理由

UTF-8 是一种在数据以 8 位字符存储、且某些 ascii 字符被视为特殊字符 (即 Unix 文件系统文件名) 并比其他字符更常见的环境中编码 Unicode 文本的方法. 虽然 UTF-8 便于在文件系统上高效存储数据, 但它并非为应用程序在内存中操纵而设计. 虽然某些应用程序 (例如 Unix 的 'cat') 可以简单地忽略数据的编码, 其他应用程序应当在从文件读取时把 UTF-8 转换为 UCS-4 (更规范的 Unicode 表示) , 并在写出文件时执行相反的过程.

C++ 标准 IOStreams 提供了 std::codecvt facet, 专门用于处理这些情况. 在读取或写入文件时, std::basic_filebuf 可以调用 codecvt facet, 把数据表示从外部格式 (即 UTF-8) 转换为内部格式 (即 UCS-4) , 反之亦然. utf8_codecvt_facet 是 std::codecvt 的一个特化, 专门设计用于在 UTF-8 与 UCS-4 之间转换.

模板参数

参数说明默认值
InternType 用于表示 UCS-4 字符的内部类型. wchar_t
ExternType 用于表示 UTF-8 八位组的外部类型. char_t

要求

utf8_codecvt_facet 默认使用 char 作为外部数据类型、 wchar_t 作为内部数据类型, 但在某些体系结构上 wchar_t 不足以容纳 UCS-4 字符. 要使用其他内部类型, 你还必须特化 std::codecvt 来处理你的内部和外部类型. (任何符合标准的编译器都必须提供 std::codecvt<char,wchar_t,std::mbstate_t> ) .

用法示例

以下是一个使用该 facet 的简单示例: 
  //...
  // My encoding type
  typedef wchar_t ucs4_t;

  std::locale old_locale;
  std::locale utf8_locale(old_locale,new utf8_codecvt_facet<ucs4_t>);

  // Set a New global locale
  std::locale::global(utf8_locale);

  // Send the UCS-4 data out, converting to UTF-8
  {
    std::wofstream ofs("data.ucd");
    ofs.imbue(utf8_locale);
    std::copy(ucs4_data.begin(),ucs4_data.end(),
          std::ostream_iterator<ucs4_t,ucs4_t>(ofs));
  }

  // Read the UTF-8 data back in, converting to UCS-4 on the way in
  std::vector<ucs4_t> from_file;
  {
    std::wifstream ifs("data.ucd");
    ifs.imbue(utf8_locale);
    ucs4_t item = 0;
    while (ifs >> item) from_file.push_back(item);
  }
  //...

历史

这段代码最初是作为容器上的迭代器适配器编写的, 用于处理内存中以 UTF-8 编码的字符串. Dietmar Kuehl 建议把它作为 codecvt facet 提供会更好.
