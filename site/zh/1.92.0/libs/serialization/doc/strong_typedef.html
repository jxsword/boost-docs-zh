BOOST_STRONG_TYPEDEF

动机

typedef 为现有类型创建别名. 它不会创建可用于匹配函数或模板形参的新类型. 尝试编译以下示例即可说明这一点. 
 typedef int a; void f(int x); // (1) function to handle simple integers void f(a x); // (2) special function to handle integers of type a int main(){ int x = 1; a y; y = x; // other operations permitted as a is converted as necessary f(x); // chooses (1) f(y); // chooses (2) }
由于 typedef 不创建新类型, 这个程序无法编译出实现其明显意图的代码.

BOOST_STRONG_TYPEDEF 的用法解决了这个问题. 


 #include <boost/serialization/strong_typedef.hpp>  BOOST_STRONG_TYPEDEF(int, a) void f(int x); // (1) function to handle simple integers void f(a x); // (2) special function to handle integers of type a int main(){ int x = 1; a y; y = x; // other operations permitted as a is converted as necessary f(x); // chooses (1) f(y); // chooses (2) }
程序现在将按预期编译并运行.

用法

BOOST_STRONG_TYPEDEF 的语法被设计得与标准 typedef 类似. 因此 

BOOST_STRONG_TYPEDEF(primitive type, name)
会创建一个名为"name"的新类型, 它可替代原始类型, 但仍是不同的类型.

实现

BOOST_STRONG_TYPEDEF 是一个宏, 它生成一个名为"name"的类, 包装其原始类型的一个实例, 并提供适当的转换运算符, 使新类型可替代它所包装的类型.
