序列化

shared_ptr<class T> 重探
前面描述的 shared_ptr 序列化展示了序列化一个中等复杂类结构的直接方式. 遗憾的是, 这种做法有一些不尽如人意的特性
  • 它依赖于 shared_ptr 的 Boost 实现. shared_ptr 接口已包含在 std::tr1 中, 将来某天也许会被纳入标准 C++ 库. 只依赖公共接口的实现可以保证与 shared_ptr 的任何其他未来实现协同工作.
  • 它需要额外的宏来进行导出.

template<class Archive, class T>
inline void save(
    Archive & ar,
    const boost::shared_ptr<T> &t,
    const unsigned int /* file_version */
){
    const T * t_ptr = t.get();
    // just serialize the underlying raw pointer
    ar << boost::serialization::make_nvp("px", t_ptr);
}

template<class Archive, class T>
inline void load(
    Archive & ar,
    boost::shared_ptr<T> &t,
    const unsigned int file_version
){
    T* r;
    // recover the underlying raw pointer
    ar >> boost::serialization::make_nvp("px", r);

    // To Do - match up with other shared pointers which 
    // use this same raw pointer.
    ...
}
原则上, 这比最初的实现简单得多. 完成这段代码需要:
  1. 填补"待办事项". 这需要为 shared_ptr 实例制作一个额外的映射.
  2. 一种从指向基类的指针识别指向相同对象的指针的方法.
  3. 与用先前方法序列化的指针的向后兼容性. 这利用了序列化的类版本控制.
  4. 对 weak_ptr 的正确处理.
这项工作的成果可在 boost::serialization::shared_ptr.hpp 找到

注意, 如果你的代码需要读取在 boost 1.32 下创建的档案, 你将不得不包含以下 


#include <boost/serialization/shared_ptr_132.hpp>
#include <boost/serialization/shared_ptr.hpp>
, 而不只是 

#include <boost/serialization/shared_ptr.hpp>
