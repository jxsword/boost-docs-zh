序列化

从现有档案派生

日志档案

有时人们希望通过从随附的档案类之一派生来创建新的档案类. 库中包含一个示例程序, 演示如何从库中自带的档案派生新档案. 第一个示例是 demo_log.cpp .

这个从 xml 档案派生的档案以 xml 形式写出输出, 但不包含把数据读回应用程序所需的额外信息. 它可用于把数据导出为简单 xml 供其他应用程序使用, 或在调试时记录数据.

为此, 它从随附的 xml 档案派生, 并且针对此应用为某些类型特化了 save 函数.

序列化库是使用 C uriously R ecurring T emplate P attern ( CRTP ) 实现的. 此外, 所有公共代码都被分解到独立模块中, 以尽量减少代码重复. 这使得从现有档案派生比原本更不直接.

这个示例说明了做这类事情时必须处理的几个问题

  1. 它派生自 xml_oarchive_impl 而不是 xml_oarchive
    如 xml_oarchive.hpp 中的注释所述. xml_oarchive 实际上是 xml_oarchive_impl<xml_oarchive> 的简写名. 所以我们应当从 xml_oarchive_impl<log_archive> 派生, 而不是从 xml_oarchive. 
    
class log_archive :
    // don't derive from xml_oarchive !!!
    public xml_oarchive_impl<log_archive>
{
...
  2. 注意 log_archive 位于 <> 之间——这样做是必需的, 使基类能够把它们的 this 指针向下转换为最派生的类. 这称为 C uriously R ecurring T emplate P attern ( CRTP ) [11] . 它用于实现静态多态.
  3. 基类需要被显式授予对派生类的访问权. 这可以通过把成员设为 public, 或为基类加入 friend 声明来实现. 
    
    friend class detail::common_oarchive<log_archive>;
    friend class basic_xml_oarchive<log_archive>;
    friend class boost::serialization::save_access;
  4. 重读 档案内部机制 . 它描述了类层次结构, 使你知道应当重写什么.
  5. 基类函数通常需要显式调用. 我们通常为保存原始类型而特化函数名 save_override. 在派生类中使用某个函数名会"隐藏"基类中同名的函数. 也就是说, 函数名重载不会自动包含基类. 为解决这个问题, 可以使用: 
    
    using xml_oarchive_impl<derived_t>::save;
    void save(const unsigned int t);
    ...
    在符合标准的编译器上应当有效. 不过我发现下面这个等价写法在更多编译器上有效. 
    
    // default fall through for any types not specified here
    template<class T>
    void save(const T & t){
        xml_oarchive_impl<derived_t>::save(t);
    }
    void save(const unsigned int t);
    ...
    所以我使用后者.
  6. 基类的模板定义可能需要显式实例化. 示例中为这个目的专门包含了 
    
// explicitly instantiate for this type of binary stream
#include <boost/archive/basic_binary_oprimitive.ipp>
    . 如果不包含所需的模板定义, 程序链接时会出现未定义符号错误.
  7. 不加改动的话, 这个类无法再被进一步派生.
    使用 CRTP 的基类必须是模板, 其形参对应最派生的类. 如这里所示, 该类不满足这一条件, 因此不能用作基类. 要从此类进一步派生, 就必须按照原始 xml_oarchive 的思路重新组织. 具体来说, 它会像这样: 
    
template<class Archive>
class log_archive_impl :
    // don't derive from xml_oarchive !!!
    public xml_oarchive_impl<Archive>
{
    ...
};

// do not derive from this class !!!
class log_archive : 
    public log_archive_impl<log_archive>
{
public:
    log_archive(std::ostream & os, unsigned int flags = 0) :
        log_archive_impl<xml_oarchive>(os, flags)
    {}
};
