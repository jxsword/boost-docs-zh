宏 BOOST_SCOPE_EXIT_ALL

BOOST_SCOPE_EXIT_ALL — 此宏声明一个捕获作用域内所有变量的作用域退出 (仅限 C++11).

概要

// In header: <boost/scope_exit.hpp>

BOOST_SCOPE_EXIT_ALL(capture_list)

说明

此宏接受以 & 或 = 开头的捕获列表, 分别用于以引用或值的方式捕获作用域内的所有变量 (遵循与 C++11 lambda 相同的语法). 除此之外, 此宏的工作方式与 BOOST_SCOPE_EXIT 相同 (更多信息参见 BOOST_SCOPE_EXIT):

{ // Some local scope.
    ...
    BOOST_SCOPE_EXIT_ALL(capture_list) { // C++11 only.
        ... // Body code.
    }; // Use `;` instead of `BOOST_SCOPE_EXIT_END` (C++11 only).
    ...
}

注意, 此宏声明的作用域退出体的结尾必须用分号 ; 标记 (而不是用 BOOST_SCOPE_EXIT_END).

警告: 此宏仅在 C++11 编译器上可用 (具体而言, 在未定义 Boost.Config 宏 BOOST_NO_CXX11_LAMBDAS 的 C++11 编译器上). 它在非 C++11 编译器上没有定义, 因此在非 C++11 编译器上使用它会引发编译错误.

参数:

capture_list 在支持可变参数宏的编译器上 (另见 Boost.Config BOOST_NO_CXX11_VARIADIC_MACROS), 捕获列表语法由以下文法定义: 
capture_list:
        capture_tuple | capture_sequence
capture_tuple:
        {& | =} [, capture, capture, ...]
capture_sequence:
        {(&) | (=)} [(capture) (capture) ...]
capture:
        [&]variable | this_
在不支持可变参数宏的编译器上, capture_tuple 无法使用: 
capture_list:
        void | capture_sequence
此外, 在支持在模板外使用 typename 的 C++11 编译器上, 也可以使用 this 在成员函数作用域处捕获对象: 
capture:
        [&]variable | this_ | this
(词法约定: token1 | token2 表示 token1 或 token2; [token] 表示 token 或空; {expression} 表示由该表达式产生的记号.)

注意, 在支持可变参数宏的编译器上 (应当涵盖所有 C++11 编译器), 捕获列表可以指定为以逗号分隔的列表. 在所有编译器上, 同一个宏 BOOST_SCOPE_EXIT_ALL 也允许把捕获列表指定为 Boost.Preprocessor 序列.

捕获列表必须始终至少包含前导的 & 或 =, 因此它绝不能为 void (要编写捕获列表为空的作用域退出, 应使用 BOOST_SCOPE_EXIT(void)).

一般而言, 当需要在同一行上展开多个作用域退出声明时, 必须使用特殊宏 BOOST_SCOPE_EXIT_ALL_ID 来代替 BOOST_SCOPE_EXIT_ALL.

警告: 此宏的捕获列表遵循与 C++11 lambda 捕获完全相同的语法, 而该语法遗憾的是与 BOOST_SCOPE_EXIT 的捕获语法不同 (除非程序员定义宏 BOOST_SCOPE_EXIT_CONFIG_USE_LAMBDAS). 例如, 与 C++11 lambda 函数一样, BOOST_SCOPE_EXIT_ALL 要求通过捕获对象 this 来捕获数据成员, 而 BOOST_SCOPE_EXIT 则允许直接捕获数据成员, 无需捕获对象.

警告: 实现会在析构函数中执行作用域退出体, 因此为了符合 STL 异常安全要求, 作用域退出体绝不能抛出异常.

注释: 此宏也总是可以在模板内使用 (因此无需 BOOST_SCOPE_EXIT_ALL_TPL 宏).

参见: 教程 一节, 无可变参数宏 一节, BOOST_SCOPE_EXIT, BOOST_SCOPE_EXIT_ALL_ID.
