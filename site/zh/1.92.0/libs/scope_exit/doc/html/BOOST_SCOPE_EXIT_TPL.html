宏 BOOST_SCOPE_EXIT_TPL

BOOST_SCOPE_EXIT_TPL — 此宏是针对各种 GCC 版本的变通方案, 用于在模板内声明作用域退出.

概要

// In header: <boost/scope_exit.hpp>

BOOST_SCOPE_EXIT_TPL(capture_list)

说明

GCC 编译器的多个版本无法在函数模板内编译 BOOST_SCOPE_EXIT. 作为变通方案, 在这些情况下应使用 BOOST_SCOPE_EXIT_TPL 来代替 BOOST_SCOPE_EXIT:

{ // Some local scope.
    ...
    BOOST_SCOPE_EXIT_TPL(capture_list) {
        ... // Body code.
    } BOOST_SCOPE_EXIT_END
    ...
}

BOOST_SCOPE_EXIT_TPL 的语法与 BOOST_SCOPE_EXIT 的语法完全相同 (更多信息参见 BOOST_SCOPE_EXIT).

在 C++11 编译器上, BOOST_SCOPE_EXIT_TPL 并非必需, 因为 BOOST_SCOPE_EXIT 在支持 C++11 的 GCC 版本上总能编译. 不过, C++11 上仍然提供 BOOST_SCOPE_EXIT_TPL, 以便编写在 C++03 与 C++11 编译器之间可移植的代码. 建议在模板内始终使用 BOOST_SCOPE_EXIT_TPL 以最大化可移植性.

一般而言, 当需要在模板内的同一行上展开多个作用域退出声明时, 必须使用特殊宏 BOOST_SCOPE_EXIT_ID_TPL 来代替 BOOST_SCOPE_EXIT_TPL.

注释: 某些 GCC 版本在编译作用域退出声明时遇到的问题由以下代码说明 (另见 GCC bug 37920):

template<class T>
void f(T const& x) {
    int i = 0;
    struct local {
        typedef __typeof__(i) typeof_i;
        typedef __typeof__(x) typeof_x;
    };
    typedef local::typeof_i i_type;
    typedef local::typeof_x x_type;
}

int main(void) { f(0); }

可以通过添加 typename 来修复, 即把它放在 local::typeof_i 和 local::typeof_x 的前面 (这正是 BOOST_SCOPE_EXIT_TPL 宏的实现所采用的方法).

注释: 虽然 BOOST_SCOPE_EXIT_TPL 与 BOOST_TYPEOF_TPL 具有相同的后缀, 但它并不遵循 Boost.Typeof 约定.

参见: 教程章节, BOOST_SCOPE_EXIT, BOOST_SCOPE_EXIT_END, BOOST_SCOPE_EXIT_ID_TPL.
