宏 BOOST_SCOPE_EXIT_CONFIG_USE_LAMBDAS

BOOST_SCOPE_EXIT_CONFIG_USE_LAMBDAS — 强制使用 C++11 lambda 函数来实现作用域退出.

概要

// In header: <boost/scope_exit.hpp>

BOOST_SCOPE_EXIT_CONFIG_USE_LAMBDAS

说明

如果程序员在未定义 Boost.Config 宏 BOOST_NO_CXX11_LAMBDAS 的 C++11 编译器上定义此配置宏, BOOST_SCOPE_EXIT 和 BOOST_SCOPE_EXIT_TPL 宏将使用 C++11 lambda 函数来声明作用域退出. 默认情况下不定义此宏.

警告: 当作用域退出使用 lambda 函数实现时, 捕获列表的语法遵循与 C++11 lambda 捕获完全相同的语法, 而该语法通常与本库的旧式捕获语法不同. 例如, C++11 lambda 要求通过捕获对象 this 来捕获数据成员, 而本库始终允许直接捕获数据成员. 因此, 定义此配置宏后, BOOST_SCOPE_EXIT 和 BOOST_SCOPE_EXIT_TPL 不再向后兼容 (这正是此宏默认不定义的原因).

定义此配置宏时, 可以用分号 ; 代替 BOOST_SCOPE_EXIT_END (但建议始终使用 BOOST_SCOPE_EXIT_END 以最大化可移植性).

注释: 此配置宏不控制 BOOST_SCOPE_EXIT_ALL 的定义, 该宏在支持 C++11 lambda 函数的编译器上始终自动定义.

参见: BOOST_SCOPE_EXIT, BOOST_SCOPE_EXIT_TPL, BOOST_SCOPE_EXIT_END.
