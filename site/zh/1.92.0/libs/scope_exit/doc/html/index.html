本库允许在外围作用域退出时执行任意代码.

引言

如今, 每个 C++ 开发者都熟悉资源获取即初始化 (RAII) 技术. 它把资源的获取与释放绑定到持有该资源的变量的初始化与析构上. 有时为这样一个变量编写专门的类并不值得. 这正是 Boost.ScopeExit 发挥作用的时候.

程序员可以把资源获取直接写在代码中, 并在其旁边使用本库编写释放资源的代码. 例如 (另见 world.cpp): [1] 

void world::add_person(person const& a_person) {
    bool commit = false;

    persons_.push_back(a_person);           // (1) direct action
    // Following block is executed when the enclosing scope exits.
    BOOST_SCOPE_EXIT(&commit, &persons_) {
        if(!commit) persons_.pop_back();    // (2) rollback action
    } BOOST_SCOPE_EXIT_END

    // ...                                  // (3) other operations

    commit = true;                          // (4) disable rollback actions
}


[1] 本库的旧版本使用 Boost.Preprocessor 序列来指定被捕获变量的列表. 在保持完全向后兼容的同时, 现在也可以使用以逗号分隔的列表来指定被捕获的变量 (这是首选语法). 更多信息参见 无可变参数宏 一节.
