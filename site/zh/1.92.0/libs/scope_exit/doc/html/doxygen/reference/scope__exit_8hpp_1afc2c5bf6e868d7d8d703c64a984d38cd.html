宏 BOOST_SCOPE_EXIT_END

BOOST_SCOPE_EXIT_END — 此宏标记作用域退出体的结尾.

概要

// In header: <boost/scope_exit.hpp>

BOOST_SCOPE_EXIT_END

说明

此宏必须紧跟右花括号 }, 该括号结束 BOOST_SCOPE_EXIT 或 BOOST_SCOPE_EXIT_TPL 的函数体:

{ // Some local scope.
    ...
    BOOST_SCOPE_EXIT(capture_list) {
        ... // Body code.
    } BOOST_SCOPE_EXIT_END
    ...
}

一般而言, 当需要在同一行上展开多个作用域退出体时, 必须使用特殊宏 BOOST_SCOPE_EXIT_END_ID 来代替 BOOST_SCOPE_EXIT_END.

注释: 如果程序员在 C++11 编译器上定义了 BOOST_SCOPE_EXIT_CONFIG_USE_LAMBDAS 宏, 则可以用分号 ; 代替此宏. 不过, 为了最大化可移植性, 建议始终使用 BOOST_SCOPE_EXIT_END.

参见: 教程章节, BOOST_SCOPE_EXIT, BOOST_SCOPE_EXIT_TPL, BOOST_SCOPE_EXIT_END_ID.
