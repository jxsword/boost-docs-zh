宏 BOOST_SCOPE_EXIT_ID_TPL

BOOST_SCOPE_EXIT_ID_TPL — 在各种 GCC 版本上, 需要此宏才能在模板内的同一行上展开多个作用域退出声明.

概要

// In header: <boost/scope_exit.hpp>

BOOST_SCOPE_EXIT_ID_TPL(id, capture_list)

说明

此宏等价于 BOOST_SCOPE_EXIT_TPL, 但如果每次展开提供不同的标识符 id, 它可以在同一行上多次展开 (更多信息参见 BOOST_SCOPE_EXIT_TPL). 与 BOOST_SCOPE_EXIT_TPL 一样, 建议在模板内的同一行上多次展开作用域退出时始终使用此宏.

参数:

id 一个可由预处理器拼接的唯一标识符记号 (LINE, scope_exit_number_1_on_line_123, 字母数字记号的组合等).
capture_list 与 capture_list 参数相同, 该参数属于 BOOST_SCOPE_EXIT_TPL 宏.

注释: 当作用域退出宏在用户自定义宏内展开时, 此宏可能很有用 (因为嵌套宏会在同一行上展开). 在某些编译器上 (例如支持非标准 COUNTER 宏) 可能不必使用此宏, 但为确保在同一行上展开多个作用域退出声明时的可移植性, 始终需要使用此宏.

参见: 教程 一节, BOOST_SCOPE_EXIT_TPL, BOOST_SCOPE_EXIT_END_ID, BOOST_SCOPE_EXIT_ID, BOOST_SCOPE_EXIT_ALL_ID.
