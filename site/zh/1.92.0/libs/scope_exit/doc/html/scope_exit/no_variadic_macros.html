附录: 无变参宏

本节给出一种供不支持可变参数宏的编译器使用的替代语法.

序列语法

大多数现代编译器都支持可变参数宏 (特别是 GCC, MSVC 以及所有 C++11 编译器). [10] 不过, 在程序员需要在不支持可变参数宏的编译器上使用本库这种少见情况下, 本库也允许使用 Boost.Preprocessor 序列来指定捕获列表, 其中的记号以圆括号 () 分隔:

(capture1) (capture2) ... // All compilers.

代替我们迄今所见、需要变参宏的逗号分隔列表:

capture1, capture2, ... // Only compilers with variadic macros.

例如, 下面的语法在带与不带可变参数宏的所有编译器上都能被接受 (另见 world_seq.cpp 和 world.cpp):

Boost.Preprocessor 序列 (所有编译器)

逗号分隔列表 (仅限可变参数宏)

 

void world::add_person(person const& a_person) {
    bool commit = false;

    persons_.push_back(a_person);           // (1) direct action
    // Following block is executed when the enclosing scope exits.
    BOOST_SCOPE_EXIT( (&commit) (&persons_) ) {
        if(!commit) persons_.pop_back();    // (2) rollback action
    } BOOST_SCOPE_EXIT_END

    // ...                                  // (3) other operations

    commit = true;                          // (4) disable rollback actions
}


void world::add_person(person const& a_person) {
    bool commit = false;

    persons_.push_back(a_person);           // (1) direct action
    // Following block is executed when the enclosing scope exits.
    BOOST_SCOPE_EXIT(&commit, &persons_) {
        if(!commit) persons_.pop_back();    // (2) rollback action
    } BOOST_SCOPE_EXIT_END

    // ...                                  // (3) other operations

    commit = true;                          // (4) disable rollback actions
}

注意, 在支持可变参数宏的编译器上, 同样的宏同时接受两种语法; 而在不支持可变参数宏的编译器上, 则只接受 Boost.Preprocessor 序列语法. 本库的旧版本曾仅支持 Boost.Preprocessor 序列语法, 因此出于向后兼容的考虑, 这一语法也仍然受支持. 不过, 在本库的当前版本中, 在支持可变参数宏的编译器上, 优先使用逗号分隔语法, 因为它更具可读性.

最后, 空的捕获列表在带与不带可变参数宏的编译器上始终用 void 来指定 (另见 world_void.cpp):

struct world_t {
    std::vector<person> persons;
    bool commit;
} world; // Global variable.

void add_person(person const& a_person) {
    world.commit = false;
    world.persons.push_back(a_person);

    BOOST_SCOPE_EXIT(void) { // No captures.
        if(!world.commit) world.persons.pop_back();
    } BOOST_SCOPE_EXIT_END

    // ...

    world.commit = true;
}
