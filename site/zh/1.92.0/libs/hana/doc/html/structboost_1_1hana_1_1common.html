说明

template<typename T, typename U, optional when-based enabler>
struct boost::hana::common< T, U, enabler >

返回两个数据类型之间的公共数据类型的元函数.

common 是 std::common_type 元函数在数据类型上的自然扩展. 给定两个数据类型 T 和 U, 我们说它们共享一个公共类型 C, 其条件是: 数据类型 T 的对象和数据类型 U 的对象都可以 (使用 to) 转换为数据类型 C 的对象, 并且该转换保持相等性. 换言之, 这意味着对于任意 t1, t2 (数据类型为 T) 和 u1, u2 (数据类型为 U) 的对象, 以下定律成立:

to<C>(t1) == to<C>(t2) 当且仅当 t1 == t2
to<C>(u1) == to<C>(u2) 当且仅当 u1 == u2

common 的作用是在这样的 C 存在时为其提供一个别名. 换言之, 如果 T 和 U 有一个公共数据类型 C, 则 common<T, U>::type 就是 C 的别名. 否则, common<T, U> 就没有嵌套的 type, 并且可以在依赖上下文中使用以利用 SFINAE. 默认情况下, common 用来确定公共类型 C (即 T 与 U 的公共类型) 所遵循的确切步骤如下:

  1. 如果 T 与 U 相同, 则 C 就是 T.
  2. 否则, 如果 true ? std::declval<T>() : std::declval<U>() 是良构的, 则 C 就是对该表达式施加 std::decay 之后得到的类型. 这恰好是 std::common_type 本来会返回的类型, 只是不考虑 std::common_type 的自定义特化.
  3. 否则, 就检测不到公共数据类型, 且 common<T, U> 没有嵌套的 type 别名, 除非显式地对其进行特化.

正如第 3 点所示, 也可以 (并且有时是必要的) 为自定义数据类型的组合特化 common (位于 boost::hana 命名空间中), 当 common 的默认行为不够用时. 请注意, 支持基于 when 的特化: 当特化 common 时 (位于 boost::hana 命名空间中).

#### 要求转换保持相等性的设计理由 此决定与标准库的一个提案中的概念设计 (N3351) 一致. 此外, 如果我们不这样要求, 那么所有数据类型都会平凡地共享公共数据类型 void, 因为所有对象都可以转换为它.

// Copyright Louis Dionne 2013-2017

// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/core/common.hpp>
#include <type_traits>
namespace hana = boost::hana;
struct Person { };
struct Employee : Person { };
static_assert(std::is_same<hana::common<int, float>::type, float>{}, "");
static_assert(std::is_same<hana::common<Person, Employee>::type, Person>{}, "");
int main() { }
