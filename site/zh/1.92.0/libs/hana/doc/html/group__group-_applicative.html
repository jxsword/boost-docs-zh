Applicative
Concepts

说明

Applicative 概念表示具有提升值与组合计算能力的 Functor.

Functor 只能接受一个普通函数并将其映射到一个含值的结构上, 得到一个新的含值的结构. 直观地说, Applicative 还能接受一个值并将其提升入结构. 此外, Applicative 还能接受一个含函数的结构并将其应用到一个含值的结构上, 得到一个新的含值的结构. 通过对结构内的函数柯里化, 还可以把 n 元函数应用到 n 个含值的结构上.

注释
本文档不深入 applicative 的本质. 不过, Typeclassopedia 是一个不错的 Haskell 导向资料, 可以找到此类信息.

最小完整定义

lift 与 ap, 满足下述定律. Applicative 还必须是 Functor.

Laws

给定 Applicative F, 必须满足以下定律:

  1. 单位元
    对所有对象 xs (标签为 F(A)),
    ap(lift<F>(id), xs) == xs
  2. 组合
    对所有对象 xs (标签为 F(A)) 以及应用性中的函数 \( fs : F(B \to C) \ ), \( gs : F(A \to B) \ ),
    ap(ap(lift<F>(compose), fs, gs), xs) == ap(fs, ap(gs, xs))
    boost::hana::compose
    constexpr auto compose
    返回两个或更多函数的组合.
    定义: compose.hpp:52
  3. 同态
    对所有对象 x (标签为 A) 及函数 \( f : A \to B \ ),
    ap(lift<F>(f), lift<F>(x)) == lift<F>(f(x))
  4. 交换
    对所有对象 x (标签为 A) 以及应用性中的函数 \( fs : F(A \to B) \),
    ap(fs, lift<F>(x)) == ap(lift<F>(apply(-, x)), fs)
    boost::hana::apply
    constexpr auto apply
    以给定实参调用 Callable.
    定义: apply.hpp:40
    其中 apply(-, x) 表示把 apply 函数 (来自 Functional 模块) 部分应用到 x 实参.

由这些定律可知, Functor 在 F 上的模型将对所有对象 xs (标签为 F(A)) 及函数 \( f : A \to B \ ) 满足以下内容:

transform(xs, f) == ap(lift<F>(f), xs)

精化概念

  1. Functor (自由模型)
    由定律可知, 任何 Applicative F 都可成为 Functor, 办法是设置
    transform(xs, f) = ap(lift<F>(f), xs)

具体模型

hana::lazy, hana::optional, hana::tuple

保持结构的函数

应用性变换 (applicative transformation) 是两个 Applicative F 与 G 之间的函数 \( t : F(X) \to G(X) \ ), 其中 X 可以是任意标签, 且该函数保持 Applicative 的运算. 换言之, 对所有对象 x (标签为 X), 应用性中的函数 \( fs : F(X \to Y) \ ) 以及对象 xs (标签为 F(X)),

t(lift<F>(x)) == lift<G>(x)
t(ap(fs, xs)) == ap(t(fs), t(xs))

提升后的应用.

具体而言, ap 把一个含函数的结构应用到一个含值的结构, 并返回一个新的含值的结构. 函数应用于值的确切方式取决于 Applicative.

ap 可以以两个或更多实参调用; f 结构中的函数先被柯里化, 再应用到每个 x... 结构中的值上, 使用的是 ap 的二元形式. 注意这要求 x... 的个数必须与 f 结构中函数的元数一致. 换言之, ap(f, x1, ..., xN) 等价于

((curry(f) ap x1) ap x2) ... ap xN
boost::hana::curry

其中 x ap y 只是以中缀记法书写的 ap(x, y), 以强调左结合性.

参数

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/ap.hpp>
#include <boost/hana/assert.hpp>
#include <boost/hana/config.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/optional.hpp>
#include <boost/hana/tuple.hpp>
#include <functional>
namespace hana = boost::hana;
int main() {
// 用元组
static_assert(
hana::ap(hana::make_tuple(std::plus<>{}), hana::make_tuple(1, 2),
hana::make_tuple(3, 4, 5))
==
hana::make_tuple(
1 + 3, 1 + 4, 1 + 5,
2 + 3, 2 + 4, 2 + 5
)
, "");
// 用 optional 值
BOOST_HANA_CONSTEXPR_LAMBDA auto multiply = [](auto a, auto b, auto c) {
return a * b * c;
};
BOOST_HANA_CONSTEXPR_CHECK(
hana::ap(hana::just(multiply), hana::just(1),
hana::just(2),
hana::just(3))
==
hana::just(1 * 2 * 3)
);
BOOST_HANA_CONSTANT_CHECK(
hana::ap(hana::just(multiply), hana::just(1),
hana::nothing,
hana::just(3))
==
hana::nothing
);
}

把值提升入 Applicative 结构.

lift<A> 接受一个普通值并将其嵌入一个结构, 该结构的形状由 A Applicative 表示. 注意该值可以是一个函数, 此时创建出的结构可以 applied 到另一个含值的 Applicative 结构上.

Signature

给定 Applicative A, 签名为 \( \mathtt{lift}_A : T \to A(T) \ ).

模板参数
A一个表示值被提升到何种 Applicative 中的标签.
参数
x要提升入 applicative 的值.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/equal.hpp>
#include <boost/hana/lift.hpp>
#include <boost/hana/optional.hpp>
#include <boost/hana/tuple.hpp>
namespace hana = boost::hana;
static_assert(hana::lift<hana::tuple_tag>('x') == hana::make_tuple('x'), "");
static_assert(hana::lift<hana::optional_tag>('x') == hana::just('x'), "");
int main() { }
