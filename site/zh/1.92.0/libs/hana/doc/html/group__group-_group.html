说明

Group 概念表示这样一些 Monoid: 所有对象相对 Monoid 的二元运算都有逆元.

Group 是构建在 Monoid 之上的代数结构, 它增加了将 Monoid 的二元运算作用于集合中任意元素后求逆的能力. 具体而言, Group 是一个 Monoid (S, +), 其中每个元素 s (属于 S) 都有一个逆元 (记作 's), 满足

s + s' == s' + s == Monoid 的单位元

Group 的例子很多, 其中之一是整数上的加法 Monoid, 其中任意整数 n 的逆元是整数 -n. 此处使用的方法名指的正是这个模型.

Laws

对所有对象 x (属于 Group G), 必须满足以下定律:

plus(x, negate(x)) == zero<G>() // 右逆元
plus(negate(x), x) == zero<G>() // 左逆元

非布尔算术数据类型的自由模型

数据类型 T 在 std::is_arithmetic<T>::value 为真时即为算术类型. 对于非布尔算术数据类型 T, 其 Group 模型通过如下设置自动定义:

minus(x, y) = (x - y)
negate(x) = -x
注释
不为 bool 提供 Group 模型的理由与不为 Monoid 提供模型的理由相同.

保持结构的函数

设 A 与 B 为两个 Group. 函数 f : A -> B 被称为Group 态射, 若它保持 A 与 B 之间的群结构. 严格地说, 对所有对象 x, y (数据类型为 A),

f(plus(x, y)) == plus(f(x), f(y))

由于 Group 结构的存在, 容易证明随后还会满足:

f(negate(x)) == negate(f(x))
f(zero<A>()) == zero<B>()

具有这些性质的函数与 Group 交互良好, 因此得到了如此特殊的对待.

constexpr auto boost::hana::minus

= [](auto&& x, auto&& y) -> decltype(auto) {

两个群元素相减.

具体而言, 它对第一个实参和第二个实参的逆元执行 Monoid 运算, 因此等价于:

minus(x, y) == plus(x, negate(y))

方法的跨类型版本

minus 方法被"重载"以处理具有某些性质的不同数据类型. 具体而言, minus 对满足下列条件的不同数据类型 A 与 B 定义:

  1. A 与 B 共享一个公共数据类型 C, 由 common 元函数判定
  2. A, B 和 C 单独来看都是 Group
  3. to<C> : A -> B 与 to<C> : B -> C 都是 Group 嵌入 (由 is_embedding 元函数判定).

对满足上述性质的数据类型, minus 的定义通过设置

minus(x, y) = minus(to<C>(x), to<C>(y))
