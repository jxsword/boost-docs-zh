MonadPlus
Concepts

说明

MonadPlus 概念表示具有单子结构的 Monad.

直观地说, Monad 可视为某种容器或上下文, 而 MonadPlus 可视为能与其他容器或上下文拼接的容器或上下文. 该组合运算还必须有单位元. 例如, tuple 是 MonadPlus, 因为元组可以拼接, 且空元组充当拼接的单位元. 这与同时也是 Monoid 的 Monad 有何不同? 答案是: MonadPlus 上的单子结构不得依赖结构的内容; 它不得要求内容本身是 Monoid 才能工作.

虽然序列不是 MonadPlus 唯一可能的模型, 此处使用的方法名指的是拼接意义下序列的 MonadPlus. 本概念还包含若干推广序列运算的有用函数, 如 append, prepend 和 filter.

注释
本文档不深入 MonadPlus 概念的本质. 不过, 有一本不错的 Haskell 导向 WikiBook 深入讨论了更多细节.

最小完整定义

concat and empty

Laws

首先, MonadPlus 必须具有单子结构. 因此, 对任何 MonadPlus M, 我们要求 M(T) 是合法的单子 (monoid), 这并不奇怪. 但我们不强制 M(T) 真正建模 Hana 提供的 Monoid 概念. 此外, 对所有对象 a, b, c (数据类型为 M(T)),

// identity
concat(empty<M(T)>(), a) == a
concat(a, empty<M(T)>()) == a
// associativity
concat(a, concat(b, c)) == concat(concat(a, b), c)

把两个单子结构组合在一起.

给定两个单子结构, concat 把它们组合在一起并返回一个新的单子结构. concat 的确切定义取决于手头 MonadPlus 的具体模型, 但对序列而言, 直观上对应简单的拼接.

另请注意, 组合运算并不要求满足交换律. 换言之, 不要求

concat(xs, ys) == concat(ys, xs)

而且一般也不成立.

把一个单子结构与自身组合 n 次.

给定单子结构 xs 和非负数 n, cycle 返回一个新的单子结构, 它是把 xs 与自身组合 n 次 (用 concat 运算) 的结果. 换言之,

cycle(xs, n) == concat(xs, concat(xs, ... concat(xs, xs)))
// ^^^^^ 共 n 次

constexpr auto cycle

另请注意, 由于要求 concat 满足结合律, 也可以写作

用自定义谓词过滤单子结构.

给定一个单子结构和谓词, filter 返回一个新的单子结构, 只包含满足谓词的元素. 这是序列的常用 filter 函数的推广; 它适用于任何 MonadPlus. 直观地, filter 大致等价于:

filter(xs, pred) == flatten(transform(xs, [](auto x) {
return pred(x) ? lift<Xs>(x) : empty<Xs>();
})
boost::hana::filter
constexpr auto filter
用自定义谓词过滤单子结构.
定义: filter.hpp:65

换言之, 我们基本上是把一个包含 [x1, ..., xn] 的单子结构变成一个包含

[
pred(x1) ? [x1] : [],
pred(x2) ? [x2] : [],
...
pred(xn) ? [xn] : []
]

然后我们再对其 flatten.
