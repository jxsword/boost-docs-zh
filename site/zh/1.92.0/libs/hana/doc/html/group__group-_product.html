Concepts

说明

表示可作为两个元素的通用容器的类型.

本概念基本上表示与 std::pair 相像的类型. 建立如此精确概念的动机与 Sequence 概念背后的动机类似: 不同库中有许多不同的 std::pair 实现, 我们希望以泛型方式操纵其中任何一种.

由于 Product 基本上就是一个 pair, 本概念提供的操作不外乎取 pair 的第一个和第二个元素、由两个元素创建 pair 等类似操作, 这并不令人意外.

注释
在数学上, 本概念表示范畴论的积 (product) 类型. 这也是名称的由来.

最小完整定义

first, second and make

first 和 second 显然必须分别返回 pair 的第一个和第二个元素. make 必须接受两个实参 x 和 y, 分别表示 pair 的第一个和第二个元素, 并返回一个 pair p, 满足 first(p) == x 和 second(p) == y.

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/first.hpp>
#include <boost/hana/pair.hpp>
#include <boost/hana/second.hpp>
namespace hana = boost::hana;
static_assert(hana::first(hana::make<hana::pair_tag>(1, 'x')) == 1, "");
static_assert(hana::second(hana::make<hana::pair_tag>(1, 'x')) == 'x', "");
int main() { }

Laws

对模型 P (属于 Product), 必须满足以下定律. 对每对数据类型 X 与 Y, 必须存在唯一的函数 \( \mathtt{make} : X \times Y \to P \), 使得对每个 x, y,

x == first(make<P>(x, y))
y == second(make<P>(x, y))
注释
这条定律比通常用于定义范畴论积的泛性质弱, 但对我们的需要而言绰绰有余.

这基本上是说 Product 必须是能够容纳一对对象 (P1, P2) 的最一般对象, 仅此而已. 由于范畴论积由泛性质定义, 本概念的所有模型都同构, 且同构唯一. 换言之, 把一个 Product 转换为另一个有且只有一种方式.

first 和 second 还必须满足 移动无关性 (move-independence), 它保证可以把 Product 最优地分解为两个成员而不产生多余的拷贝.

精化概念

  1. Comparable (自由模型)
    两个 Product x 与 y 相等当且仅当逐元素相等, 且先比较第一个元素再比较第二个元素.

  2. Orderable (自由模型)
    Product 的排序采用字典序, 就如同它们是 2 元素元组一样.
  3. Foldable (自由模型)
    对 Product p 折叠等价于折叠一个按该顺序包含 first(p) 与 second(p) 的列表.
