◆ print

auto boost::hana::experimental::print

#include <boost/hana/experimental/printable.hpp>

初始值:
= [](auto const& x) -> std::string {
return tag-dispatched;
}

返回给定对象的字符串表示.

这个函数为 Hana 提供的大多数容器定义, 也为那些定义了某个 operator<< (可与 std::basic_ostream 一起使用) 的对象定义. 它可以递归地打印容器中的容器, 但不要期望有任何恰当的缩进.

此函数要求系统上可用 Boost 的其余部分. 它还要求启用 RTTI.
