Hashable
Concepts

Hashable 概念表示可以规范化为类型级哈希的对象.

在日常编程中, 哈希是在映射 (map) 中高效查找对象的重要手段. 尽管映射的实现千差万别, 利用哈希做高效查找的思路同样适用于元编程. Hashable 概念表示可以 (可能损失信息地) 概括为一个类型的对象, 适用于基于哈希的数据结构. 当然, 要使哈希行为良好, 必须遵守下文解释的一些定律.

最小完整定义

hash, 满足下述定律

Laws

首先, hana::hash 必须返回 hana::type. 此外, 对任意两个 Hashable 对象 x 和 y, 必须有

x == y implies hash(x) == hash(y)

其中 == 表示 hana::equal. 换言之, 任何两个比较相等的对象 (用 hana::equal) 必须具有相同的哈希. 但反之不成立, 两个不同的对象可能有相同的哈希. 两个不同对象具有相同哈希的情形称为碰撞 (collision).

具体模型

hana::integral_constant, hana::type, hana::string

<tt>IntegralConstant</tt> 的自由模型

任何 IntegralConstant 都是 Hashable, 做法是将其值规范化为 hana::integral_constant. 规范化后的 integral_constant 中所存值的类型, 对无符号整型是 unsigned long long, 对有符号整型是 signed long long.
