boost::hana::optional< T > 结构模板参考
数据类型

说明

template<typename ... T>
struct boost::hana::optional< T >

其有无与否在编译期已知的可选值.

一个 optional 要么包含一个值 (表示为 just(x)), 要么为空 (表示为 nothing). 本质上, hana::optional 非常类似于 boost::optional 或即将推出的 std::optional, 只不过 hana::optional 是否为空在编译期是已知的. 这对于从一个可能失败但其失败原因不重要的函数返回值特别有用. 当然, 函数是否会失败必须在编译期就知道.

这确实是hana::optional 与 std::optional 之间的一个重要区别. 不同于 std::optional<T>{} 和 std::optional<T>{x} (二者共享同一类型 std::optional<T>), hana::just(x) 和 hana::nothing 并不共享同一类型, 因为 optional 的状态必须在编译期可知. 因此, 函数返回的是 hana::just 还是 hana::nothing 必须在编译期可知, 这样编译器才能计算出该函数的返回类型. 这使得 hana::optional 非常适合静态元编程任务, 但对任何动态的东西都非常不合适.

注释
当你使用容器时, 请记住不要对其表示形式做任何假设, 除非文档向你给出这些保证. 更多细节见教程.

与 <tt>type</tt> 的互操作

当一个 just 包含一个类型为 T 的对象 (它是一个 type) 时, 它有一个嵌套的 ::type 别名, 等价于 T::type. 然而, nothing 则从不具有嵌套的 ::type 别名. 如果 t 是一个 type, 这使得 decltype(just(t)) 可以被视为一个等价于 decltype(t) 的无参元函数. 配合 sfinae 函数, 这使得 hana::optional 能够与 SFINAE 友好的元函数无缝交互. 示例:

template <typename ...>
using void_t = void;
template <typename T, typename = void>
struct has_type : std::false_type { };
template <typename T>
struct has_type<T, void_t<typename T::type>>
: std::true_type
{ };

decltype(true ? hana::traits::declval(t) : hana::traits::declval(u))
> { return {}; });

common_type_impl(hana::type_c<int>, hana::type_c<float>)

hana::just(hana::type_c<float>)

  3. Functor
    一个可选值可以被视为一个列表, 它要么包含一个元素 (just(x)), 要么完全不包含元素 (nothing). 因此, 对可选值映射一个函数等价于: 如果有值就把函数应用于该值, 否则就是 nothing:
    transform(just(x), f) == just(f(x))
    transform(nothing, f) == nothing

  4. Applicative
    首先, 一个值可以用 lift<optional_tag> 变成可选的, 它等价于 just. 其次, 可以用 ap 把一个可选值提供给一个可选函数, 它将返回 just(f(x)) — 条件是既存在函数又存在值; 否则返回 nothing:
    ap(just(f), just(x)) == just(f(x))
    ap(nothing, just(x)) == nothing
    ap(just(f), nothing) == nothing
    ap(nothing, nothing) == nothing
    简单示例:
    // Copyright Louis Dionne 2013-2017
    // Distributed under the Boost Software License, Version 1.0.
    // (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
    #include <boost/hana/ap.hpp>
    #include <boost/hana/assert.hpp>
    #include <boost/hana/equal.hpp>
    #include <boost/hana/optional.hpp>
    namespace hana = boost::hana;
    constexpr char next(char c) { return c + 1; }
    static_assert(hana::ap(hana::just(next), hana::just('x')) == hana::just('y'), "");
    BOOST_HANA_CONSTANT_CHECK(hana::ap(hana::nothing, hana::just('x')) == hana::nothing);
    BOOST_HANA_CONSTANT_CHECK(hana::ap(hana::just(next), hana::nothing) == hana::nothing);
    BOOST_HANA_CONSTANT_CHECK(hana::ap(hana::nothing, hana::nothing) == hana::nothing);
    int main() { }

  5. Monad
    Monad 模型使得组合可能失败的操作变得容易. 可以用 chain 把一个可选值 (如果存在) 提供给一个函数, 如果没有值, 它将返回 nothing. 最后, 可以用 flatten 去除 optional-optional 值中多余的可选性层级. 另请注意, | 运算符可以用来代替 chain 函数. 示例:
    // Copyright Louis Dionne 2013-2017
    // Distributed under the Boost Software License, Version 1.0.
    // (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
    #include <boost/hana/assert.hpp>
    #include <boost/hana/chain.hpp>
    #include <boost/hana/config.hpp>
    #include <boost/hana/equal.hpp>
    #include <boost/hana/flatten.hpp>
    #include <boost/hana/optional.hpp>
    namespace hana = boost::hana;
    int main() {
    BOOST_HANA_CONSTEXPR_LAMBDA auto inc = [](auto x) {
    return hana::just(x + 1);
    };
    BOOST_HANA_CONSTEXPR_CHECK(hana::chain(hana::just(1), inc) == hana::just(2));
    BOOST_HANA_CONSTANT_CHECK(hana::chain(hana::nothing, inc) == hana::nothing);
    BOOST_HANA_CONSTEXPR_CHECK(hana::flatten(hana::just(hana::just(2))) == hana::just(2));
    }

BOOST_HANA_CONSTANT_CHECK(x == hana::make_optional());

constexpr auto just_x = hana::make<hana::optional_tag>('x');
static_assert(just_x == hana::make_optional('x'), "");
BOOST_HANA_CONSTANT_CHECK(hana::is_just(just_x));

把函数应用于 optional 的内容, 并带有回退结果.

具体而言, maybe 接受一个默认值、一个函数和一个可选值. 如果该可选值是 nothing, 则返回默认值. 否则, 该函数被应用于 just 的内容.

boost::hana::capture
constexpr auto capture
创建捕获给定变量的函数.
定义: capture.hpp:45

如果调用表达式是良构的, 则调用该函数.

给定一个函数 f, sfinae 返回一个新函数, 它把 f 应用于其参数; 如果调用是良构的, 则返回 just 形式的结果, 否则返回 nothing. 换言之, 如果该表达式是良构的, 则 sfinae(f)(x...) 就是 just(f(x...)), 否则是 nothing. 然而请注意, 一个表达式 f(x...) 有可能在 SFINAE 意义上是良构的, 但实际尝试编译 f(x...) 仍然会失败. 在这种情况下, sfinae 将无法检测到它, 并且很可能会发生硬失败.

注释
提供给 sfinae 的函数不得返回 void, 因为 just(void) 是没有意义的. 如果该函数返回 void, 则会触发编译错误.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/assert.hpp>
#include <boost/hana/config.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/optional.hpp>
namespace hana = boost::hana;
int main() {
BOOST_HANA_CONSTEXPR_LAMBDA auto incr = [](auto x) -> decltype(x + 1) {
return x + 1;
};
BOOST_HANA_CONSTEXPR_CHECK(hana::sfinae(incr)(1) == hana::just(2));
struct invalid { };
BOOST_HANA_CONSTANT_CHECK(hana::sfinae(incr)(invalid{}) == hana::nothing);
}
