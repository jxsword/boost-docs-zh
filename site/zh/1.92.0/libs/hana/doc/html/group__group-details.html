宏定义文档

◆ BOOST_HANA_DISPATCH_IF

#define BOOST_HANA_DISPATCH_IF (   IMPL,
  ... 
)    IMPL

#include <boost/hana/detail/dispatch_if.hpp>

仅在条件满足时分派到给定的实现方法.

如果条件满足, 此宏等价于类型 IMPL. 否则, 它等价于一个带有名为 apply 的已删除静态函数的类型. 当发生 tag 分派错误时, 条件应为假, 而被删除的静态函数 apply 将阻止编译器生成过多的垃圾信息.

注释
当 BOOST_HANA_CONFIG_DISABLE_CONCEPT_CHECKS 被定义时, 条件总是被忽略, 此宏只展开为实现.
备注
这必须实现为宏, 因为当 BOOST_HANA_CONFIG_DISABLE_CONCEPT_CHECKS 被定义时, 我们根本不想让条件被求值.

◆ BOOST_HANA_PP_DROP_FRONT

#define BOOST_HANA_PP_DROP_FRONT (   e0,
  ... 
)    __VA_ARGS__

#include <boost/hana/detail/preprocessor.hpp>

展开为除第一个之外的全部参数.

类型定义文档

◆ has_common_embedding

template<template< typename... > class Concept, typename T , typename U >
using boost::hana::detail::has_common_embedding = typedef typename has_common_embedding_impl<Concept, T, U>::type

#include <boost/hana/detail/has_common_embedding.hpp>

返回 T 和 U 是否都具有到某个公共类型的嵌入.

如果 T 和 U 没有公共类型, 此元函数返回假.

◆ has_nontrivial_common_embedding
