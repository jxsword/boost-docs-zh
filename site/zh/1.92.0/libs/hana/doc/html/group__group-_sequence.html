说明

Sequence 概念表示通用的基于下标的序列.

与其他抽象概念相比, Sequence 概念非常具体. 它表示通用的基于下标的序列. 之所以提供这样一个具体的概念, 是因为有很多模型虽然实现方式千差万别, 行为却完全相同. 为了泛型编程的目的, 把这些数据类型归入同一个体系之下是很有用的.

事实上, 这个概念的模型不仅是相似的. 它们实际上是同构的——下面我们会定义这个说法, 它是一种严谨地表达"对外部观察者而言行为完全相同"的方式.

最小完整定义

Iterable、Foldable 和 make

Sequence 概念不提供可用作最小完整定义的基本方法; 它借用其他概念的方法并为它们附加定律. 因此, 必须在 Hana 的命名空间中特化 Sequence 元函数, 以告诉 Hana 某个类型确实是一个 Sequence. 显式特化 Sequence 元函数可以看作一个印记, 表明"该数据类型满足 `Sequence` 的附加定律", 因为这些定律无法由 Hana 自动检查.

Laws

作为 Sequence 的定律很简单, 其目标是限制可以与由其他概念提供的函数相关联的语义. 首先, Sequence 必须是有限的 Iterable (因而也是 Foldable) . 其次, 对于 Sequence tag S, make<S>(x1, ..., xn) 必须是 tag 为 S 且线性化为 [x1, ..., xn] 的对象. 这基本上确保了 tag 为 S 的对象与其线性化等价, 并且可以从这样的线性化创建 (借助 make) .

尽管理论上可以处理无限序列, 但这样做会使许多算法的实现复杂化. 为简单起见, 当前版本的库只处理有限序列. 但请注意, 这丝毫不会影响拥有无限 Searchable 和 Iterable 的潜力.

  4. Applicative (自动提供定义)

  5. Monad (自动提供定义)
    首先, flatenning (展平) 一个 Sequence 会取一个由序列组成的序列, 并把它们拼接起来得到更大的序列. 换言之,
    flatten([[a1, ..., aN], ..., [z1, ..., zM]]) == [
    a1, ..., aN, ..., z1, ..., zM
    ]
    它的行为类似于 std::tuple_cat 函数, 只是它接收的是由序列组成的序列, 而不是要展平的可变参数序列包.

constexpr auto boost::hana::drop_back

丢弃有限序列的最后 n 个元素, 并返回其余部分.

给定一个有限 Sequence xs (其线性化为 [x1, ..., xm]) 以及一个非负的 IntegralConstant n, drop_back(xs, n) 是一个与 xs 具有相同 tag 的序列, 其线性化为 [x1, ..., xm-n]. 如果不给出 n, 则默认为一个 IntegralConstant, 其值等于 1.

在 length(xs) <= n 的情况下, drop_back 会直接丢弃整个序列而不失败, 从而返回空序列.

参数
xs要从中丢弃元素的序列.
n一个非负的 IntegralConstant, 表示要从序列末尾丢弃的元素数量. 如果不给出 n, 则默认为一个 IntegralConstant, 其值等于 1.
