Struct
Concepts

说明

Struct 概念表示类似 struct 的用户自定义类型.

Struct 概念允许对用户自定义类型进行受限的编译期反射. 特别是, 它允许访问用户自定义类型的成员名称, 以及这些成员的值. Struct 还可以被折叠、查找, 并转换为某些类型的容器, 以便执行更高级的变换.

虽然理论上所有类型都可以成为 Struct, 但其中只有一部分实际值得这样看待. 更准确地说, 把一个类型做成 Struct 只在它在概念上是一个 C++ struct 时才有意义, 即主要由命名数据组成的简单聚合. 这些数据的访问方式对 Struct 概念而言大多无关紧要; 可以通过 getter 和 setter、公有成员、非成员函数来访问, 甚至可以即时生成. 重要的部分 (下文会精确说明) 是这些访问器方法应当是移动无关的.

看待 Struct 的另一种方式是把它看作一个 map, 其键是成员的名称, 值是这些成员的值. 不过, 两者存在细微差别: 例如不能向 Struct 添加成员; 而且 Struct 内部成员的顺序会影响 Struct 的相等性判定, 这对 map 则不然.

最小完整定义

accessors

Struct 的模型通过用 accessors 函数指定一个键/值对序列来创建. 该序列中一个对的第一个元素表示 Struct 某个成员的"名称", 第二个元素则是一个从对象中取出该成员的函数. "名称"不必是任何特殊形式; 它们只需是编译期 Comparable. 例如, 常见做法是提供表示成员实际名称的 hana::string 作为"名称", 但提供 hana::integral_constant 也完全可以. 值必须是函数, 当给定一个对象时, 它从中取出相应的成员.

提供 accessors 方法有几种方式, 其中一些更灵活, 另一些更方便. 首先, 可以照常通过 tag 分派来定义它.

struct Person {
std::string name;
int age;
};
// 键可以是任何东西, 只要它们是编译期可比较的.
constexpr auto name = hana::integral_c<std::string Person::*, &Person::name>;
constexpr auto age = hana::string_c<'a', 'g', 'e'>;
namespace boost { namespace hana {
template <>
struct accessors_impl<Person> {
static BOOST_HANA_CONSTEXPR_LAMBDA auto apply() {
return make_tuple(
make_pair(name, [](auto&& p) -> decltype(auto) {
return id(std::forward<decltype(p)>(p).name);
}),
make_pair(age, [](auto&& p) -> decltype(auto) {
return id(std::forward<decltype(p)>(p).age);
})
);
}
};
}}

其次, 可以提供一个嵌套的 hana_accessors_impl 类型, 它应等价于为 tag 分派而做的 accessors_impl 特化. 然而, 对于类型 S, 这种技术只在 S 的数据类型是 S 本身时才有效——除非你明确要求了其他东西, 否则情况正是如此.

struct Person {
std::string name;
int age;
struct hana_accessors_impl {
static BOOST_HANA_CONSTEXPR_LAMBDA auto apply() {
return boost::hana::make_tuple(
boost::hana::make_pair(BOOST_HANA_STRING("name"),
[](auto&& p) -> decltype(auto) {
return boost::hana::id(std::forward<decltype(p)>(p).name);
}),
boost::hana::make_pair(BOOST_HANA_STRING("age"),
[](auto&& p) -> decltype(auto) {
return boost::hana::id(std::forward<decltype(p)>(p).age);
})
);
}
};
};

最后, 最方便 (但最不灵活) 的方式是使用 BOOST_HANA_DEFINE_STRUCT、BOOST_HANA_ADAPT_STRUCT 或 BOOST_HANA_ADAPT_ADT 宏, 它们只有极少的语法开销. 关于如何使用这些宏的细节, 请参见它们的文档.

另请注意, 访问器函数并不一定要取出结构体的实际成员 (例如 x.member) . 事实上, 访问器函数可以调用自定义 getter, 甚至即时计算成员的值:

struct Person {
Person(std::string const& name, int age) : name_(name), age_(age) { }
std::string const& get_name() const { return name_; }
int get_age() const { return age_; }
private:
std::string name_;
int age_;
};
namespace boost { namespace hana {
template <>
struct accessors_impl<Person> {
static BOOST_HANA_CONSTEXPR_LAMBDA auto apply() {
return make_tuple(
make_pair(BOOST_HANA_STRING("name"), [](auto&& p) -> std::string const& {
return p.get_name();
}),
make_pair(BOOST_HANA_STRING("age"), [](auto&& p) {
return p.get_age();
})
);
}
};
}}

唯一重要的是访问器函数是移动无关的, 这个概念将在下面定义.

移动无关性

这里介绍的移动无关性概念严格定义了什么时候从一个对象"二次移动"是合法的.

共享同一定义域的一组函数 f1, ..., fn 被称为移动无关的, 如果对于定义域中的每个全新 (未被移动过) 的对象 x, 下面这些语句的任意排列都是有效的, 并且使 zk 对象保持在全新 (未被移动过) 的状态:

auto z1 = f1(std::move(x));
...
auto zn = fn(std::move(x));
注释
在某些函数返回的对象无法用 auto zk = 绑定 (例如 void 或不可移动、不可复制的类型) 的特殊情况下, 只需假定返回值被忽略即可.

直观上, 这确保了我们可以把 f1, ..., fn 视为把 x 分解为独立子对象的"访问器", 且这样做时从 x 移动的不会超过那个子对象. 这一点很重要, 因为它使我们能在库内部把 Struct 最优地分解为其组成部分.

Laws

对于任何 Struct S, accessors<S>() 序列中的访问器都必须是移动无关的 (如上所定义) .

精化概念

  1. Comparable (自由模型)
    Struct 必须是 Comparable. 具体来说, 两个 Struct (数据类型为 S) 相等, 当且仅当它们的所有成员都相等. 默认情况下, 提供了一个恰好实现这一点的 Comparable 模型 (供 Struct 的模型使用) . 特别要注意, 成员的比较按它们在 hana::members 序列中出现的顺序进行.

  2. Foldable (自由模型)
    Struct 可以被折叠: 把它看作一个由对组成的列表, 每个对包含一个成员的名称和与该成员关联的值, 顺序与它们在 hana::members 序列中出现的顺序相同. 默认情况下, 提供了一个恰好实现这一点的 Foldable 模型 (供 Struct 概念的模型使用) .
    // Copyright Louis Dionne 2013-2017
    // Distributed under the Boost Software License, Version 1.0.
    // (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
    #include <boost/hana/assert.hpp>
    #include <boost/hana/define_struct.hpp>
    #include <boost/hana/fold_left.hpp>
    #include <boost/hana/second.hpp>
    namespace hana = boost::hana;
    struct Kitten {
    BOOST_HANA_DEFINE_STRUCT(Kitten,
    (int, extremely_cute),
    (int, cute),
    (int, not_so_cute)
    );
    };
    int main() {
    constexpr Kitten kitten{5, 10, 0};
    BOOST_HANA_CONSTEXPR_CHECK(
    hana::fold_left(kitten, 0, [](auto total, auto member) {
    // first(member) 是成员的名称, 此处
    // "extremely_cute", or "cute" or "not_so_cute",
    // 而 second(member) 是它的值.
    return hana::second(member) + total;
    }) == (5 + 10 + 0)
    );
    }

auto boost::hana::BOOST_HANA_ADAPT_ADT (   ...)

#include <boost/hana/fwd/adapt_adt.hpp>

用给定的访问器定义一个 Struct 的模型.

在全局作用域使用此宏会为给定类型定义 Struct 概念的一个模型. 这可用于以特设的方式轻松适配现有的用户自定义类型. 与 BOOST_HANA_ADAPT_STRUCT 不同, 此宏要求通过提供一个执行提取的函数来指定取出每个成员的方式.

注释
此宏只在用户自定义类型 T 的 tag 是 T 本身时才起作用. 除非你明确要求了不同的东西, 否则情况正是如此; 参见 tag_of 的文档.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/accessors.hpp>
#include <boost/hana/adapt_adt.hpp>
#include <boost/hana/assert.hpp>
#include <boost/hana/core/to.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/find.hpp>
#include <boost/hana/first.hpp>
#include <boost/hana/map.hpp>
#include <boost/hana/not_equal.hpp>
#include <boost/hana/optional.hpp>
#include <boost/hana/pair.hpp>
#include <boost/hana/string.hpp>
#include <boost/hana/transform.hpp>
#include <boost/hana/tuple.hpp>
#include <string>
namespace hana = boost::hana;
namespace ns {
struct Person {
explicit Person(std::string const& name, int age)
: name_(name), age_(age)
{ }
std::string const& get_name() const { return name_; }
int get_age() const { return age_; }
private:
std::string name_;
int age_;
};
}
BOOST_HANA_ADAPT_ADT(ns::Person,
(name, [](ns::Person const& p) { return p.get_name(); }),
(age, [](ns::Person const& p) { return p.get_age(); })
);
// 成员名称是 hana::strings:
auto names = hana::transform(hana::accessors<ns::Person>(), hana::first);
BOOST_HANA_CONSTANT_CHECK(
names == hana::make_tuple(BOOST_HANA_STRING("name"), BOOST_HANA_STRING("age"))
);
int main() {
ns::Person john{"John", 30}, bob{"Bob", 40};
BOOST_HANA_RUNTIME_CHECK(hana::equal(john, john));
BOOST_HANA_RUNTIME_CHECK(hana::not_equal(john, bob));
BOOST_HANA_RUNTIME_CHECK(hana::find(john, BOOST_HANA_STRING("name")) == hana::just("John"));
BOOST_HANA_RUNTIME_CHECK(hana::find(john, BOOST_HANA_STRING("age")) == hana::just(30));
BOOST_HANA_CONSTANT_CHECK(hana::find(john, BOOST_HANA_STRING("foo")) == hana::nothing);
BOOST_HANA_RUNTIME_CHECK(hana::to_tuple(john) == hana::make_tuple(
hana::make_pair(BOOST_HANA_STRING("name"), "John"),
hana::make_pair(BOOST_HANA_STRING("age"), 30)
));
BOOST_HANA_RUNTIME_CHECK(hana::to_map(john) == hana::make_map(
hana::make_pair(BOOST_HANA_STRING("name"), "John"),
hana::make_pair(BOOST_HANA_STRING("age"), 30)
));
}

定义结构的成员, 同时使该结构成为 Struct 的模型.

在用户自定义类型的体内使用此宏会在该类型内部定义给定的成员, 同时还会为该用户自定义类型提供 Struct 概念的一个模型. 这个宏通常是定义 Struct 概念模型的最简单方式.

返回一个 Sequence, 其中包含表示数据结构访问器的各个对.

给定一个 Struct S, accessors<S>() 是一个 Sequence (其元素为 Product) , 其中每个对的第一个元素是 Struct 某个成员的"名称", 第二个元素是一个函数——给定一个具有正确数据类型的对象时, 可用它访问该成员. 如 Struct 的全局文档所述, 此序列中的访问器函数必须是移动无关的.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/accessors.hpp>
#include <boost/hana/assert.hpp>
#include <boost/hana/at.hpp>
#include <boost/hana/define_struct.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/first.hpp>
#include <boost/hana/integral_constant.hpp>
#include <boost/hana/second.hpp>
#include <boost/hana/string.hpp>
#include <string>
namespace hana = boost::hana;
struct Person {
BOOST_HANA_DEFINE_STRUCT(Person,
(std::string, name),
(unsigned short, age)
);
};
int main() {
constexpr auto accessors = hana::accessors<Person>();
BOOST_HANA_CONSTANT_CHECK(
hana::first(accessors[hana::size_c<0>]) == BOOST_HANA_STRING("name")
);
BOOST_HANA_CONSTANT_CHECK(
hana::first(accessors[hana::size_c<1>]) == BOOST_HANA_STRING("age")
);
constexpr auto get_name = hana::second(accessors[hana::size_c<0>]);
constexpr auto get_age = hana::second(accessors[hana::size_c<1>]);
Person john{"John", 30};
BOOST_HANA_RUNTIME_CHECK(get_name(john) == "John");
BOOST_HANA_RUNTIME_CHECK(get_age(john) == 30);
}
