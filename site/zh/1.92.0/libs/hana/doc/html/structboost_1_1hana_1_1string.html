boost::hana::string< implementation_defined > 结构模板参考
数据类型

说明

template<typename implementation_defined>
struct boost::hana::string< implementation_defined >

编译期字符串.

从概念上讲, hana::string 就像一个保存 integral_constant 的 tuple, 其底层类型为 char. 然而, hana::string 的接口不像 tuple 那么丰富, 因为 string 只能保存编译期字符, 而不能保存任意类型的对象.

编译期字符串用于简单的用途, 例如作为 hana::map 中的键, 或为 Struct 的成员打标签. 然而, 你可能会发现 hana::string 没有提供足够的功能, 不足以用作一个成熟的编译期字符串实现 (例如正则表达式匹配或子串查找). 实际上, 提供一个全面的字符串接口工作量很大, 目前超出了本库的范围.

注释
hana::string 的表示是实现定义的. 特别地, 不应想当然地认为模板参数是 char. 把 hana::string 的内容当作字符常量来访问的正确方式是使用 hana::unpack、.c_str() 或 hana::to<char const*>, 如下文所记载. 更多细节见教程.

转换为 <tt>char const*</tt>

hana::string 可以转换为以 constexpr 分隔的、类型为 char const* 的字符串, 方法是使用 c_str() 方法或 hana::to<char const*>. 这使得把编译期字符串变成运行期字符串变得容易. 但是请注意, 此转换不是一个嵌入, 因为 char const* 与 hana::string 不建模相同的概念.

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/assert.hpp>
#include <boost/hana/core/to.hpp>
#include <boost/hana/string.hpp>
namespace hana = boost::hana;
constexpr auto str = hana::string_c<'h', 'i'>;
// using c_str()
constexpr char const* s1 = str.c_str();
static_assert(s1[0] == 'h' && s1[1] == 'i' && s1[2] == '\0', "");
// using hana::to
constexpr char const* s2 = hana::to<char const*>(str);
static_assert(s2[0] == 'h' && s2[1] == 'i' && s2[2] == '\0', "");
int main() { }

从任何保存 <tt>char const*</tt> 的 Constant 转换

hana::string 可以从任何 Constant 创建, 条件是其底层值可转换为 char const* (方法是使用 hana::to). char const* 的内容被用来构建 hana::string 的内容.

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/assert.hpp>
#include <boost/hana/core/to.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/integral_constant.hpp>
#include <boost/hana/string.hpp>
namespace hana = boost::hana;
constexpr char const hello[] = "hello";
auto hello_constant = hana::integral_constant<char const*, hello>{};
BOOST_HANA_CONSTANT_CHECK(
hana::to_string(hello_constant) == hana::string_c<'h', 'e', 'l', 'l', 'o'>
);
int main() { }

<tt>hana::string</tt> 本身不是 <tt>Constant</tt> 的设计理由

hana::string 所保存的底层类型可以是 char const* 或者其他某种支持 constexpr 的类字符串容器. 在前一种情形下, hana::string 不可能是 Constant, 因为底层类型不会遵守若干概念的模型, 导致 value 不是保持结构的. 提供一个诸如 std::string_view 之类的支持 constexpr 的类字符串容器类型的底层值会很棒, 但目前来说有点复杂.

创建一个编译期hana::string — 由 char 类型的 integral_constant 参数包构造.

给定零个或多个 integral_constant (底层类型为 char), make<string_tag> 创建一个包含这些字符的 hana::string. 提供它主要是为了与库的其余部分保持一致, 因为在大多数情况下 hana::string_c 更便于使用.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/assert.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/string.hpp>
#include <boost/hana/tuple.hpp>
#include <boost/hana/unpack.hpp>
namespace hana = boost::hana;
constexpr auto vowels = hana::tuple_c<char, 'a', 'e', 'i', 'o', 'u', 'y'>;
constexpr auto str = hana::unpack(vowels, hana::make<hana::string_tag>);
BOOST_HANA_CONSTANT_CHECK(str == BOOST_HANA_STRING("aeiouy"));
int main() { }

从字符串字面量创建一个编译期字符串.

该字符串字面量在编译期解析, 结果以hana::string 的形式返回. 此功能是一项默认禁用的扩展; 详情见下文.

注释
目前仅支持窄字符串字面量; 如果有需求, 对更花哨的字符串字面量类型 (如宽字符或 UTF-XX) 的支持可能会在将来添加. 参见此问题.
警告
此用户定义字面量是一项扩展, 它需要一个特殊字符串字面量运算符, 而该运算符尚未成为标准的一部分. Clang 和 GCC 都支持该运算符, 并且已有多个提案希望让它进入 C++17. 然而, 由于它不是标准, 它默认是禁用的, 需要定义 BOOST_HANA_CONFIG_ENABLE_STRING_UDL 配置宏才能获得此运算符. 因此, 如果你想保持稳妥, 只需改用 BOOST_HANA_STRING 宏即可. 如果你想追求速度与激情 (我就是), 那就定义 BOOST_HANA_CONFIG_ENABLE_STRING_UDL.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/assert.hpp>
#include <boost/hana/config.hpp>
#include <boost/hana/core/is_a.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/integral_constant.hpp>
#include <boost/hana/length.hpp>
#include <boost/hana/string.hpp>
namespace hana = boost::hana;
using namespace hana::literals;
// By default, this is disabled
#ifdef BOOST_HANA_CONFIG_ENABLE_STRING_UDL
constexpr auto str = "Hello world!"_s;
BOOST_HANA_CONSTANT_CHECK(str == hana::string_c<'H', 'e', 'l', 'l', 'o', ' ',
'w', 'o', 'r', 'l', 'd', '!'>);
BOOST_HANA_CONSTANT_CHECK(hana::is_a<hana::string_tag>(str));
BOOST_HANA_CONSTANT_CHECK(hana::length(str) == hana::size_c<12>);
#endif
int main() { }
