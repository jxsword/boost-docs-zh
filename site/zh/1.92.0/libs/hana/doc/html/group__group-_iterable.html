Iterable
Concepts

说明

Iterable 概念表示支持外部迭代的数据结构.

直观地说, Iterable 可视为一种容器, 其元素可以逐个取出. Iterable 还提供判断容器何时为空的方式, 即何时没有更多元素可取.

Foldable 表示支持内部迭代并能累积结果的数据结构, 而 Iterable 概念允许反转迭代的控制权. 这比 Foldable 更灵活, 因为它允许只迭代结构的一部分. 这又使 Iterable 能处理无限结构, 而折叠这样的结构永远不会结束.

最小完整定义

at, drop_front and is_empty

<tt>Iterable</tt> 的线性化

直观地说, 对 Iterable 结构 xs 而言, 其线性化 (即 xs 的线性化) 就是把 xs 中的所有元素如同放进一个 (可能无限的) 列表中那样的序列:

linearization(xs) = [x1, x2, x3, ...]

线性化的第 n 个元素, 对 Iterable 而言, 可以用 at 函数访问. 换言之, at(xs, n) == xn.

注意, 该概念正是 线性化 概念对 Foldable 扩展到无限情形的结果. 该概念对表述 Iterable 的各种性质很有用, 文档其他地方也有使用.

Compile-time <tt>Iterable</tt>s

编译期 Iterable 是一个 Iterable, 其 is_empty 返回编译期 Logical. 这类结构允许在编译期完成迭代, 即执行迭代的"循环"可以展开, 因为结构的总长度在编译期已知.

特别要注意, 是编译期 Iterable 与有限或无限毫无关系. 例如, 可以创建一个用 integral_constant 表示毕达哥拉斯三元组的序列. 这样的序列是无限的, 但对它的迭代仍将在编译期完成. 然而, 若试图迭代该序列的全部元素, 编译器就会无限循环; 相比之下, 若该序列是运行期的, 则无限循环的是你的程序.

在本库当前版本中, 只支持编译期 Iterable. 虽然理论上也可以支持运行期 Iterable, 但如何高效实现仍是研究课题. 请关注 this issue 以了解运行期 Iterable 的当前进展.

Laws

首先, 我们要求两个 Iterable 的相等与其线性化中元素的相等相关联. 更具体地说, 若 xs 与 ys 是两个 Iterable (数据类型为 It), 则

xs == ys => at(xs, i) == at(ys, i) 对 任意 i

  2. Foldable (对有限 Iterable)
    每个有限 Iterable 都会产生 Foldable 的一个模型. 为使这些模型相互一致, 我们要求 Foldable 与 Iterable 的模型具有相同的线性化.
注释
如上所述, Iterable 也是 Searchable, 二者的模型必须一致. 结合此处给出的定律, 这也意味着 Foldable 模型 (对有限 Iterable 而言) 必须与 Searchable 模型一致.

为方便起见, 有限 Iterable 只需提供 length 的定义即可建模 Foldable 概念; 无需 (但仍可以) 定义更强大的 unpack 或 fold_left. unpack 的默认实现 (由 Iterable + length 推导) 利用了这样的事实: at(xs, i) 表示第 i 个元素 (在 xs 的线性化中), 且有限 Iterable 作为 Foldable 的线性化必须与其自身线性化相同.

◆ at

constexpr auto boost::hana::at
constexpr

#include <boost/hana/fwd/at.hpp>

初始值:
= [](auto&& xs, auto const& n) -> decltype(auto) {
return tag-dispatched;
}

返回可迭代结构的第 n 个元素.

给定 Iterable 和 IntegralConstant 下标, at 返回可迭代结构线性化中位于该下标处的元素. 具体而言, 给定一个可迭代结构 xs (线性化为 [x1, ..., xN]), at(xs, k) 等价于 xk.

若 Iterable 真的存储了它包含的元素, 则 at 必须返回左值引用、const 左值引用或右值引用, 且引用的类型必须与传给 at 的可迭代结构相匹配. 若 Iterable 并不存储它包含的元素 (即按需生成), 则该要求不适用.

参数
xs从中取元素的可迭代结构. 该可迭代结构必须至少包含 n + 1 个元素.
n一个非负的 IntegralConstant, 表示待返回元素的 0 起始下标. 以超出可迭代结构边界的下标调用 at 是错误的.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/at.hpp>
#include <boost/hana/integral_constant.hpp>
#include <boost/hana/tuple.hpp>
namespace hana = boost::hana;
constexpr auto xs = hana::make_tuple(0, '1', 2.0);
static_assert(hana::at(xs, hana::size_t<0>{}) == 0, "");
static_assert(hana::at(xs, hana::size_t<1>{}) == '1', "");
static_assert(hana::at(xs, hana::size_t<2>{}) == 2.0, "");
int main() { }

◆ drop_front

constexpr auto boost::hana::drop_front
constexpr

#include <boost/hana/fwd/drop_front.hpp>

初始值:
= [](auto&& xs[, auto const& n]) {
return tag-dispatched;
}

丢弃可迭代结构的前 n 个元素, 并返回其余部分.

给定一个 Iterable xs (线性化为 [x1, x2, ...]) 和非负的 IntegralConstant n, drop_front(xs, n) 是一个可迭代结构, 与 xs 同标签, 其线性化为 [xn+1, xn+2, ...]. 特别注意, 此函数不会以任何方式修改原可迭代结构. 若未给定 n, 则默认为一个 IntegralConstant, 其值等于 1.

若 length(xs) <= n, drop_front 会简单地丢弃整个可迭代结构而不报错, 从而返回一个空的可迭代结构. 这与 drop_front_exactly 不同: 后者要求 n <= length(xs), 但正因为这一额外保证而可以更好地优化.

参数
xs从中丢弃元素的可迭代结构.
n一个非负的 IntegralConstant, 表示要从可迭代结构中丢弃的元素个数. 若未给定 n, 则默认为一个 IntegralConstant, 其值等于 1.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/assert.hpp>
#include <boost/hana/drop_front.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/integral_constant.hpp>
#include <boost/hana/tuple.hpp>
namespace hana = boost::hana;
constexpr auto xs = hana::make_tuple(0, '1', 2.0);
static_assert(hana::drop_front(xs, hana::size_c<0>) == xs, "");
static_assert(hana::drop_front(xs, hana::size_c<1>) == hana::make_tuple('1', 2.0), "");
static_assert(hana::drop_front(xs, hana::size_c<2>) == hana::make_tuple(2.0), "");
BOOST_HANA_CONSTANT_CHECK(hana::drop_front(xs, hana::size_c<3>) == hana::make_tuple());
BOOST_HANA_CONSTANT_CHECK(hana::drop_front(xs, hana::size_c<4>) == hana::make_tuple());
// drop_front(xs) 等价于 drop_front(xs, size_t<1>)
static_assert(hana::drop_front(xs) == hana::make_tuple('1', 2.0), "");
int main() { }

从可迭代结构中丢弃元素, 直到 (但不包含) 第一个不满足 predicate 的元素.

具体而言, drop_while 返回一个可迭代结构, 包含原可迭代结构中除区间 [head, e) 之外的所有元素, 其中 head 是第一个元素, e 是第一个不满足 predicate 的元素. 若可迭代结构不是有限的, 则 predicate 必须在某个有限下标处返回假值的 Logical, 此方法才能返回.

参数

predicate一个以 predicate(x) 形式调用的函数, 其中 x 是结构中的一个元素, 返回一个 Logical, 表示 x 是否应从结构中丢弃. 在本库当前版本中, predicate 应返回编译期 Logical.

给定 Iterable 结构 xs 与谓词 pred, index_if(xs, pred) 返回一个 hana::optional, 其中含有一个 IntegralConstant, 表示第一个满足谓词的元素的下标; 若没有元素满足谓词, 则为空.

参数
xs被搜索的结构.
predicate一个以 predicate(x) 形式调用的函数, 其中 x 是 Iterable 结构中的一个元素, 返回 x 是否为所查找的元素. 在本库当前版本中, 谓词必须返回一个 IntegralConstant, 其中持有可转换为 bool 的值.
