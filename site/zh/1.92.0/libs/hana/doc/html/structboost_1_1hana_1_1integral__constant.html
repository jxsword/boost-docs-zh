说明

template<typename T, T v>
struct boost::hana::integral_constant< T, v >

整数类型的编译期值.

一个integral_constant 是一个表示编译期整数值的对象. 顾名思义, hana::integral_constant 基本上等价于 std::integral_constant, 只不过 hana::integral_constant 还提供了其他便利特性使其更易于使用, 例如算术运算符和类似的功能. 特别地, hana::integral_constant 保证继承自对应的 std::integral_constant, 因而具有相同的成员和功能. 下面几节将解释 std::integral_constant 的扩展 (由 hana::integral_constant 提供).

算术运算符

hana::integral_constant 提供返回 hana::integral_constant 的算术运算符, 以简化编译期算术的编写:

BOOST_HANA_CONSTANT_CHECK(hana::int_c<1> + hana::int_c<3> == hana::int_c<4>);
// Mixed-type operations are supported, but only when it involves a
// promotion, and not a conversion that could be lossy.
BOOST_HANA_CONSTANT_CHECK(hana::size_c<3> * hana::ushort_c<5> == hana::size_c<15>);
BOOST_HANA_CONSTANT_CHECK(hana::llong_c<15> == hana::int_c<15>);
BOOST_HANA_CONSTANT_CHECK
#define BOOST_HANA_CONSTANT_CHECK(...)
等价于 BOOST_HANA_CONSTANT_ASSERT, 但不受 BOOST_HANA_CONFIG_DISABLE_ASSERTI...
定义: assert.hpp:239

认识到这些运算符返回的是其他 integral_constant 而不是整型类型的普通值, 这一点非常重要. 实际上, 所有这些运算符的工作方式基本相同. 简而言之, 对于运算符 @,

integral_constant<T, x>{} @ integral_constant<T, y>{} == integral_constant<T, x @ y>{}

这些运算符返回 Constant 这一点非常重要, 因为只要只与其他编译期已知的值一起使用, 它就能让所有编译期已知的信息得以保留. 同样有趣的是, 每当一个 integral_constant 与普通的运行期值组合时, 结果都会是运行期值 (由于隐式转换). 总的来说, 这给了我们下表

左操作数右操作数结果
integral_constant integral_constant integral_constant
integral_constant 运行期运行期
运行期integral_constant 运行期
运行期运行期运行期

所提供的运算符的完整集合为

  • 算术: 二元 +、二元 -、/、*、%、一元 +、一元 -
  • 位运算: ~、&、|、^、<<、>>
  • 比较: ==、!=、<、<=、>、>=
  • 逻辑: ||、&&、!

使用用户定义字面量构造

integral_constant 类型的 long long 可以用 _c 用户定义字面量创建, 该字面量包含在 literals 命名空间中:

using namespace hana::literals; // contains the _c suffix
BOOST_HANA_CONSTANT_CHECK(1234_c == hana::llong_c<1234>);
BOOST_HANA_CONSTANT_CHECK(-1234_c == hana::llong_c<-1234>);
BOOST_HANA_CONSTANT_CHECK(1_c + (3_c * 4_c) == hana::llong_c<1 + (3 * 4)>);

创建一个保存给定编译期值的integral_constant.

具体而言, integral_c<T, v> 是一个 hana::integral_constant, 保存编译期值 v (其类型为整型类型 T).

模板参数
T要保存在integral_constant 中的值的类型. 它必须是整型类型.
v要保存在integral_constant 中的整型值.

Example

BOOST_HANA_CONSTANT_CHECK(hana::integral_c<int, 2> == hana::int_c<2>);
static_assert(decltype(hana::integral_c<int, 2>)::value == 2, "");

◆ operator""_c()

template<char ... c>
constexpr auto operator""_c ( )
related

从字面量创建一个hana::integral_constant.

该字面量在编译期解析, 结果以 llong<...> 的形式返回.

注释
我们使用llong<...> 而不是ullong<...>, 因为当执行类似 -1_c 的操作时, 使用无符号类型会导致意外行为. 如果我们使用了无符号类型, -1_c 就会类似于ullong<-1>, 而它实际上是ullong<something huge>.

Example

using namespace hana::literals; // contains the _c suffix
BOOST_HANA_CONSTANT_CHECK(1234_c == hana::llong_c<1234>);
BOOST_HANA_CONSTANT_CHECK(-1234_c == hana::llong_c<-1234>);
BOOST_HANA_CONSTANT_CHECK(1_c + (3_c * 4_c) == hana::llong_c<1 + (3 * 4)>);

times 允许一个无参函数被调用 n 次:

任何像样的编译器都应将其展开为

f(); f(); f();

这在几种上下文中很有用, 例如循环展开:

std::string s;
for (char c = 'x'; c <= 'z'; ++c)
hana::int_<5>::times([&] { s += c; });
BOOST_HANA_RUNTIME_CHECK(s == "xxxxxyyyyyzzzzz");
BOOST_HANA_RUNTIME_CHECK

请注意, times 实际上是一个静态函数对象, 而不只是一个静态函数. 这使得 int_<n>::times 可以被传递给高阶算法:

std::string s;
auto functions = hana::make_tuple(
[&] { s += "x"; },
[&] { s += "y"; },
[&] { s += "z"; }
);
hana::for_each(functions, hana::int_<5>::times);
BOOST_HANA_RUNTIME_CHECK(s == "xxxxxyyyyyzzzzz");
boost::hana::for_each

对 foldable 的每个元素执行一个动作, 并丢弃每次的结果.

此外, 由于静态成员既可以用 . 语法也可以用 :: 语法访问, 人们可以利用这一点 (漏洞?) 对对象调用 times, 就像对类型一样:

std::string s;
for (char c = 'x'; c <= 'z'; ++c)
hana::int_c<5>.times([&] { s += c; });
BOOST_HANA_RUNTIME_CHECK(s == "xxxxxyyyyyzzzzz");
注释
times 等价于 hana::repeat 函数, 该函数可作用于任意 IntegralConstant.

有时, 知道函数内部当前所处的索引也很有用. 这可以通过使用 times.with_index 来实现:

std::vector<int> v;
hana::int_<5>::times.with_index([&](auto index) { v.push_back(index); });
BOOST_HANA_RUNTIME_CHECK(v == std::vector<int>{0, 1, 2, 3, 4});

请记住, times 是一个函数对象, 因此它可以有子对象. with_index 只是嵌套在 times 内部的一个函数对象, 这造就了这个漂亮的小接口. 另请注意, 传递给该函数的索引是 integral_constant; 它们在编译期是已知的. 因此, 我们可以用它们做编译期的事情, 例如在 tuple 内部进行索引:

constexpr auto xs = hana::tuple_c<int, 0, 1, 2>;
hana::int_<3>::times.with_index([xs](auto index) {
BOOST_HANA_CONSTANT_CHECK(xs[index] == index);
});
注释
times.with_index(f) 保证对 f 的调用将按索引升序进行. 换言之, f 将依次以 f(0)、f(1)、f(2) 等方式被调用, 但使用 integral_constant 而不是普通整数. 传递给 times 和 times.with_index 的函数中也可以产生副作用.
