boost::hana::set< implementation_defined > 结构模板参考
数据类型

说明

template<typename implementation_defined>
struct boost::hana::set< implementation_defined >

要求键唯一、Comparable 且 Hashable 的键的基础无序容器.

set 是一个可以容纳异构键的无序容器. set 要求 (并确保) 在插入新键时不出现重复项.

注释
hana::set 的实际表示是实现定义的. 特别地, 除了有文档记载的内容之外, 不应想当然地认为模板参数的顺序以及任何额外构造函数或赋值运算符的存在是固定的. 创建 hana::set 的规范方式是通过 hana::make_set. 更多细节见教程.

  3. Searchable
    set 中的元素既是它的键也是它的值. 由于 set 的元素是唯一的, 搜索一个元素将返回唯一一个与所搜索值相等的元素, 或者 nothing. 另请注意, 可以用 operator[] 代替 at_key 函数.
    // Copyright Louis Dionne 2013-2017
    // Distributed under the Boost Software License, Version 1.0.
    // (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
    #include <boost/hana/assert.hpp>
    #include <boost/hana/at_key.hpp>
    #include <boost/hana/equal.hpp>
    #include <boost/hana/find.hpp>
    #include <boost/hana/integral_constant.hpp>
    #include <boost/hana/optional.hpp>
    #include <boost/hana/set.hpp>
    namespace hana = boost::hana;
    int main() {
    constexpr auto xs = hana::make_set(hana::int_c<0>, hana::int_c<1>, hana::int_c<2>);
    BOOST_HANA_CONSTANT_CHECK(hana::find(xs, hana::int_c<0>) == hana::just(hana::int_c<0>));
    BOOST_HANA_CONSTANT_CHECK(hana::find(xs, hana::int_c<3>) == hana::nothing);
    // operator[] is equivalent to at_key
    BOOST_HANA_CONSTANT_CHECK(xs[hana::int_c<2>] == hana::int_c<2>);
    // long_c<0> == int_<0>, and therefore int_<0> is found
    BOOST_HANA_CONSTANT_CHECK(xs[hana::long_c<0>] == hana::int_c<0>);
    }

从任意 <tt>Foldable</tt> 转换

任何 Foldable 结构都可以转换为一个 hana::set (使用 to<set_tag>). 该结构的元素必须都是编译期 Comparable. 如果结构包含重复的元素, 则结果 set 中只会出现第一次出现的那个. 更具体地说, 从 Foldable 转换等价于

to<set_tag>(xs) == fold_left(xs, make_set(), insert)

返回两个 set 的并集.

给定两个 set xs 和 ys, union_(xs, ys) 是一个新 set, 它包含 xs 的所有元素和 ys 的所有元素, 且不含重复项. 对于任意对象 x, 以下成立: x 在 hana::union_(xs, ys) 中, 当且仅当 x 在 xs 中或 x 在 ys 中.

参数
xs,ys要计算并集的两个 set.

返回两个 set 的集合论差集.

给定两个 set xs 和 ys, difference(xs, ys) 是一个新 set, 它包含 xs 中那些不被包含于 ys 的所有元素. 对于任意对象 x, 以下成立:

x ^in^ difference(xs, ys) 当且仅当 x ^in^ xs && !(x ^in^ ys)
boost::hana::set::difference
constexpr auto difference
返回两个 set 的集合论差集.
Definition: set.hpp:265

此运算不满足交换律, 即 difference(xs, ys) 不一定与 difference(ys, xs) 相同. 实际上, 考虑 xs 为空而 ys 不为空的情形. 此时, difference(xs, ys) 为空, 但 difference(ys, xs) 等于 ys. 关于该运算的对称版本, 参见 symmetric_difference.

参数
xs要从中移除值的 set 参数.
ys其值从 xs 中移除的 set.

给定两个 set xs 和 ys, symmetric_difference(xs, ys) 是一个新 set, 它包含 xs 中不被 ys 包含的所有元素, 以及 ys 中不被 xs 包含的所有元素. 两个 set 的对称差满足以下关系:

symmetric_difference(xs, ys) == union_(difference(xs, ys), difference(ys, xs))
