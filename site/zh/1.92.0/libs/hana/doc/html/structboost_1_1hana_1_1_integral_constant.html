说明

template<typename C>
struct boost::hana::IntegralConstant< C >

IntegralConstant 概念表示编译期整数值.

IntegralConstant 概念表示持有某整型类型的 constexpr 值的对象. 换言之, 它描述了 std::integral_constant 所提供的基本功能. IntegralConstant 也只是一种特殊的 Constant, 其内部值是整型.

最小完整定义

成为IntegralConstant 的要求相当简单. 首先, IntegralConstant C 必须是一个 Constant, 使得 Tag::value_type 是整型, 其中 Tag 是 C 的标签.

其次, C 必须有一个嵌套的 static constexpr 成员, 名为 value, 使得以下代码有效:

constexpr auto v = C::value;
boost::hana::value
constexpr auto value
返回与常量关联的编译期值.
定义: value.hpp:54

由于要求 Tag::value_type 必须是整型, 因此 C::value 必须是整型值.

最后, 必须特化IntegralConstant 模板 (位于 boost::hana 命名空间中), 以告知 Hana 某个类型是 IntegralConstant 的模型:

namespace boost { namespace hana {
template <>
struct IntegralConstant<your_custom_tag> {
static constexpr bool value = true;
};
}}

精化概念

  1. Constant (value 的自由实现)
    value 函数 (为成为 Constant 所必需) 对 IntegralConstants 而言可按如下方式实现:
    value<C>() == C::value
    而 to 函数仍必须显式提供, 才能使 Constant 的模型完整.
