说明

template<typename T, optional when-based enabler>
struct boost::hana::tag_of< T, enabler >

返回与 T 相关联的标签的元函数.

有几种方法可以指定 C++ 类型的标签. 如果它是用户定义的类型, 可以定义一个嵌套的 hana_tag 别名:

struct MyUserDefinedType {
using hana_tag = MyTag;
};

然而有时, C++ 类型无法被修改 (如果它来自外部库), 或者干脆不能拥有嵌套类型 (如果它不是 struct 或 class). 在这些情况下, 使用嵌套别名是不可能的, 因此还支持临时定制 (ad-hoc customization), 方式是特化 tag_of (位于 boost::hana 命名空间中):

struct i_cant_modify_this;
namespace boost { namespace hana {
template <>
struct tag_of<i_cant_modify_this> {
using type = MyTag;
};
}}

tag_of 也可以使用 when 为所有满足某个布尔条件的 C++ 类型进行特化. when 接受单个编译期布尔值, 并当且仅当该布尔值满足条件时启用对 tag_of 的特化 — 条件是该布尔值为 true. 这类似于众所周知的 C++ 惯用法: 使用一个与 std::enable_if 配合的哑模板参数并依赖 SFINAE. 例如, 我们可以这样指定所有 fusion::vector 的标签:

struct BoostFusionVector;
namespace boost { namespace hana {
template <typename T>
struct tag_of<T, when<
std::is_same<
typename fusion::traits::tag_of<T>::type,
fusion::traits::tag_of<fusion::vector<>>::type
>::value
>> {
using type = BoostFusionVector;
};
}}

另外, 当它未被特化且给定的 C++ 类型没有嵌套的 hana_tag 别名时, tag_of<T> 返回 T 本身. 这使得标签成为普通 C++ 类型的一个简单扩展. 这极其有用, 主要有两个原因. 首先, 这使得 Hana 能够为一些涉及无标签概念类型的操作采用合理的默认行为. 例如, Hana 允许用 equal 来比较任意两个定义了有效 operator== 的对象, 而无需用户做任何工作. 其次, 这也意味着如果你不需要标签的功能, 就可以完全忽略标签; 只要使用对象的普通 C++ 类型, 一切都会"直接工作".

tag_of<T> 总是等价于 tag_of<U>, 其中 U 是 T 去除所有引用和 cv 限定符后的类型. 这使得无需为所有引用和 cv 组合特化 tag_of — 否则将非常痛苦. 另外, tag_of 必须是幂等的. 换言之, 必须始终有 tag_of<tag_of<T>::type>::type 等价于 tag_of<T>::type.

提示 1
如果编译期性能是一个严重的问题, 考虑在 Hana 的命名空间中特化 tag_of 元函数. 未特化时, 该元函数必须使用 SFINAE, 这往往会带来更大的编译期开销. 对于大量使用的模板类型, 这可能会产生实质影响.

提示 2
考虑使用 tag_of_t 别名来代替 tag_of, 这可以减少在依赖上下文中的输入量.

// Copyright Louis Dionne 2013-2017

// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/core/tag_of.hpp>
#include <type_traits>
namespace hana = boost::hana;
static_assert(std::is_same<hana::tag_of<int>::type, int>{}, "");
static_assert(std::is_same<hana::tag_of<int&>::type, int>{}, "");
static_assert(std::is_same<hana::tag_of<int const&>::type, int>{}, "");
struct PersonTag;
struct Person { using hana_tag = PersonTag; };
static_assert(std::is_same<hana::tag_of<Person>::type, PersonTag>{}, "");
static_assert(std::is_same<hana::tag_of<Person volatile&&>::type, PersonTag>{}, "");
int main() { }
