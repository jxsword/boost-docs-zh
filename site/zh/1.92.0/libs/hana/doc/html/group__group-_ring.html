说明

Ring 概念表示这样一些 Group: 它们在第二个二元运算下也构成 Monoid, 且该运算对第一个运算满足分配律.

Ring 是构建在 Group 之上的代数结构, 它要求针对第二个二元运算的单子结构. 第二个二元运算必须对第一个运算满足分配律. 具体而言, Ring 是一个三元组 (S, +, *), 满足 (S, +) 是 Group, (S, *) 是 Monoid, 且 * 对 + 满足分配律, 即

x * (y + z) == (x * y) + (x * z)

第二个二元运算通常写作 *, 其单位元写作 1, 以呼应乘法意义下的整数 Ring. 此处使用的方法名指的正是这个环.

Laws

对所有对象 x, y, z (属于 Ring R), 必须满足以下定律:

mult(x, mult(y, z)) == mult(mult(x, y), z) // 结合律
mult(x, one<R>()) == x // 右单位元
mult(one<R>(), x) == x // 左单位元
mult(x, plus(y, z)) == plus(mult(x, y), mult(x, z)) // 分配律

非布尔算术数据类型的自由模型

数据类型 T 在 std::is_arithmetic<T>::value 为真时即为算术类型. 对于非布尔算术数据类型 T, 其 Ring 模型通过使用所提供的 Group 模型并按如下设置自动定义:

mult(x, y) = (x * y)
one<T>() = static_cast<T>(1)
注释
不为 bool 提供 Ring 模型的理由与不为 Monoid 和 Group 提供模型的理由相同.

保持结构的函数

设 A 与 B 为两个 Ring. 函数 f : A -> B 被称为Ring 态射, 若它保持 A 与 B 之间的环结构. 严格地说, 对所有对象 x, y (数据类型为 A),

f(plus(x, y)) == plus(f(x), f(y))
f(mult(x, y)) == mult(f(x), f(y))
f(one<A>()) == one<B>()

由于 Ring 结构的存在, 容易证明随后还会满足:

f(zero<A>()) == zero<B>()
f(negate(x)) == negate(f(x))

Ring 的结合运算.

参数
x,y两个 Ring 元素, 用 Ring 二元运算组合.

方法的跨类型版本

mult 方法被"重载"以处理具有某些性质的不同数据类型. 具体而言, mult 对满足下列条件的不同数据类型 A 与 B 定义:

  1. A 与 B 共享一个公共数据类型 C, 由 common 元函数判定
  2. A, B 和 C 单独来看都是 Ring
  3. to<C> : A -> B 与 to<C> : B -> C 都是 Ring 嵌入 (由 is_embedding 元函数判定).

对满足上述性质的数据类型, mult 的定义通过设置

mult(x, y) = mult(to<C>(x), to<C>(y))

把环元素提升到其 n 次幂.

具体而言, power(x, n) 等价于用 Ring 乘法把 x 与自身相乘 n 次. 若幂等于 zero, 则返回 Ring 的单位元 (one).

参数
x一个 Ring 元素, 被提升到其 n 次幂.
n一个非负的 IntegralConstant, 表示 x 的幂次.
注释
只有 x 的标签用于标签分派.

Example

// Copyright Louis Dionne 2013-2017
// Distributed under the Boost Software License, Version 1.0.
// (See accompanying file LICENSE.md or copy at http://boost.org/LICENSE_1_0.txt)
#include <boost/hana/assert.hpp>
#include <boost/hana/equal.hpp>
#include <boost/hana/integral_constant.hpp>
#include <boost/hana/power.hpp>
namespace hana = boost::hana;
BOOST_HANA_CONSTANT_CHECK(hana::power(hana::int_c<3>, hana::int_c<2>) == hana::int_c<3 * 3>);
static_assert(hana::power(2, hana::int_c<4>) == 16, "");
