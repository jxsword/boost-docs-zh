 ▼Concepts库所提供的概念
 Applicative Applicative 概念表示能够提升值并组合计算的 Functor
 Comonad Comonad 概念表示依赖于上下文的计算与数据
 Comparable Comparable 概念定义相等与不等
 Constant Constant 概念表示可在编译期操作的数据
 Euclidean Ring EuclideanRing 概念表示一种可交换的 Ring, 并且它还可以被赋予除法算法
 Foldable Foldable 概念表示可被归约为单个值的数据结构
 Functor Functor 概念表示可被映射的类型
 Group Group 概念表示这样的 Monoid: 其所有对象相对于 Monoid 的二元运算都存在逆元
 Hashable Hashable 概念表示可被规范化为类型层哈希的对象
 Iterable Iterable 概念表示支持外部迭代的数据结构
 Logical Logical 概念表示具有真值的类型
 Metafunction Metafunction 是一种以 hana::type 为输入并返回 hana::type 作为输出的函数
 Monad Monad 概念表示能够展平嵌套结构层次的 Applicative
 MonadPlus MonadPlus 概念表示具有幺半群结构的 Monad
 Monoid Monoid 概念表示具有带单位元的结合二元运算的数据类型
 Orderable Orderable 概念表示全序的数据类型
 Product表示双元素泛型容器的类型
 Ring Ring 概念表示这样的 Group: 它在第二种二元运算下也构成 Monoid, 且该运算对第一种运算满足分配律
 Searchable Searchable 概念表示可被查找的结构
 Sequence Sequence 概念表示泛型的基于索引的序列
 Struct Struct 概念表示类似于 struct 的用户定义类型
 Data types库所提供的通用数据类型
 Functional通用函数对象
 Core库的核心实用工具
 Experimental features可能会也可能不会进入本库的实验性功能. 这些功能不应被期望为稳定的
