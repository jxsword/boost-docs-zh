Euclidean Ring

说明

EuclideanRing 概念表示一个交换的 Ring, 并且还能附加一个除法算法.

Ring 定义了一种常被称为乘法的二元运算, 可用于把环中的两个元素组合成环中的一个新元素. Euclidean ring (也称欧几里得整环) 在此之上增加了定义一个特殊函数的能力, 该函数是整数欧几里得除法的推广.

然而, 欧几里得环还必须满足另一个性质: 不存在非零的零因子. 在 Ring (R, +, *) 中, 由公理容易推出 x * 0 == 0 对任意环元素 x 成立. 然而, 没有任何规定强制 0 是唯一把其他元素送到 0 的环元素. 因此, 在某些 Ring 中可能存在元素 x 与 y, 使得 x * y == 0, 而 x == 0 与 y == 0 都不成立. 我们称这些元素为零的因子, 即零因子. 例如, 整数模 4 的 Ring (集合 {0, 1, 2, 3}) 以加法和乘法 mod 4 作为二元运算, 就出现这种情况. 此时我们有

2 * 2 == 4
== 0 (mod 4)

循着这个思路, 欧几里得环要求其唯一的零因子是零本身. 换言之, 欧几里得环中的乘法不会把两个非零元素送到零. 另请注意, 由于 Ring 中的乘法不一定交换, 以下并不总是成立:

x * y == 0 implies y * x == 0

为严谨起见, 我们随后应区分右乘零因子与左乘零因子. 幸运的是, 欧几里得环概念要求 Ring 乘法可交换. 因此,

x * y == y * x

因而无需区分左右零因子.

欧几里得环的典型例子包括整数和域上的多项式. 此处使用的方法名指通常加法、乘法和除法运算下整数的欧几里得环.

最小完整定义

div 与 mod, 满足下述定律

Laws

为便于阅读, 我们将用 +, *, / 和 % 运算符的中缀记法表示 Monoid, Group, Ring 和 EuclideanRing 中相应方法的应用. 对所有对象 a 与 b (属于 EuclideanRing R), 必须满足以下定律:

a * b == b * a // 交换律
(a / b) * b + a % b == a if b 非zero
zero<R>() % b == zero<R>() 若 b 非zero

div(x, y) = (x / y)

广义的整数除法.

方法的跨类型版本

div 方法被"重载"以处理具有某些性质的不同数据类型. 具体而言, div 对满足下列条件的不同数据类型 A 与 B 定义:

  1. A 与 B 共享一个公共数据类型 C, 由 common 元函数判定
  2. A, B 和 C 单独来看都是 EuclideanRing
  3. to<C> : A -> B 与 to<C> : B -> C 都是 Ring 嵌入 (由 is_embedding 元函数判定).

此时, div 方法定义为

div(x, y) = div(to<C>(x), to<C>(y))

static_assert(hana::div(6, 3) == 2, "");
static_assert(hana::div(6, 4) == 1, "");

给定 EuclideanRing 的两个元素 x 和 y, 其中 y 非零, mod 返回 x 除以 y 的余数. 换言之, 可以把 mod 看作 % 的等价物.
