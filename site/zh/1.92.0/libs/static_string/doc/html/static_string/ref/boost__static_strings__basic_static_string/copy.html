basic_static_string::copy

把子字符串拷贝到另一字符串.

概要 
constexpr basic_static_string::size_type
copy(
    basic_static_string::pointer dest,
    basic_static_string::size_type count,
    basic_static_string::size_type pos = 0) const;
说明

把std::min(count, size() - pos)个字符从索引pos处开始拷贝到dest所指向的字符串中.

备注

结果字符串不以空字符结尾.

返回值

已复制的字符数.

参数

名称

说明

count

要复制的字符数.

dest

复制目标字符串.

pos

开始拷贝的索引. 该参数的默认实参为0.
异常

类型

抛出时机

std::out_of_range

pos > max_size()
