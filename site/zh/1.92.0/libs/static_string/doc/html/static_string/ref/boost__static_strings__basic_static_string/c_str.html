basic_static_string::c_str

返回指向该字符串的指针.

概要 
constexpr basic_static_string::const_pointer
c_str() const noexcept;
说明

返回指向作为存储的底层数组的指针. 返回值满足: 范围 {c_str(), c_str() + size()) 始终是有效范围, 即使容器为空.

复杂度

常量.

备注

此函数返回的值永远不会是空指针值.
