basic_static_string::find_first_not_of (5 个重载中的第 3 个)

查找第一个不属于该字符串的任一字符.

概要 
constexpr basic_static_string::size_type
find_first_not_of(
    basic_static_string::const_pointer s,
    basic_static_string::size_type pos,
    basic_static_string::size_type n) const noexcept;
说明

在字符串中从索引s开始查找第一个不在pos所指向的字符串中的字符.

复杂度

线性复杂度.

返回值

对应于{begin() + pos, end())中第一个不在{s, s + n)内的字符的索引 (若存在); 否则为npos.

参数

名称

说明

s

要忽略的字符.

pos

开始搜索的索引. 该参数的默认实参为0.

n

要忽略的字符的长度.
