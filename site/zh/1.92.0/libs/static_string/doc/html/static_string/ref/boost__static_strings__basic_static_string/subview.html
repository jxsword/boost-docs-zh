basic_static_string::subview

返回一个子字符串的字符串视图.

概要 
constexpr basic_static_string::string_view_type
subview(
    basic_static_string::size_type pos = 0,
    basic_static_string::size_type count = basic_static_string::npos) const;
说明

返回一个子字符串的视图.

异常安全

强保证.

返回值

一个引用string_view_type的{data() + pos, std::min(count, size() - pos))对象.

参数

名称

说明

pos

子字符串开始的索引. 该参数的默认实参为0.

count

子字符串的长度. 该参数的默认实参为npos.
异常

类型

抛出时机

std::out_of_range

pos > size()
