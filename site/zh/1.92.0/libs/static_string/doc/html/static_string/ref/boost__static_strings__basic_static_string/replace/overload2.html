basic_static_string::replace (14 个重载中的第 2 个)

替换字符串的一部分.

概要 
template<
    std::size_t M>
constexpr basic_static_string&
replace(
    basic_static_string::size_type pos1,
    basic_static_string::size_type n1,
    const basic_static_string< M, CharT, Traits >& str,
    basic_static_string::size_type pos2,
    basic_static_string::size_type n2 = basic_static_string::npos);
说明

把从索引rcount开始的pos1个字符替换为str.subview(pos2, n2)的内容, 其中rcount为std::min(n1, size() - pos1).

异常安全

强保证.

备注

当str的容量与调用此函数的字符串的容量不同时, 该替换不进行检查.

所有引用、指针或指向所含元素的迭代器都会失效. 任何尾后迭代器也会失效.

返回值

*this

参数

名称

说明

pos1

要替换的位置索引.

n1

要替换的字符数.

str

用于替换的字符串.

pos2

子字符串开始的索引.

n2

子字符串的长度. 该参数的默认实参为npos.
异常

类型

抛出时机

std::length_error

size() + (std::min(str.size(), n2) - rcount) > max_size()

std::out_of_range

pos1 > size()

std::out_of_range

pos2 > str.size()
