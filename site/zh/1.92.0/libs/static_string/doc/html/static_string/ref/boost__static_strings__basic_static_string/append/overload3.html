basic_static_string::append (9 个重载中的第 3 个)

追加到字符串.

概要 
template<
    std::size_t M>
constexpr basic_static_string&
append(
    const basic_static_string< M, CharT, Traits >& s,
    basic_static_string::size_type pos,
    basic_static_string::size_type count = basic_static_string::npos);
说明

把子字符串 sub 追加到字符串末尾, 其中 sub 为 s.substr(pos, count).

异常安全

强保证.

模板参数

类型

说明

M

要追加的字符串的大小.
返回值

*this

参数

名称

说明

s

要追加的字符串.

pos

子字符串开始的索引.

count

子字符串的大小. 该参数的默认实参为 npos.
异常

类型

抛出时机

std::length_error

size() + sub.size() > max_size()

std::out_of_range

pos > s.size()
