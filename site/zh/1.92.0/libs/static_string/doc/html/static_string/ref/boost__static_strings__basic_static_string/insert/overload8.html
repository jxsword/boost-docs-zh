basic_static_string::insert (11 个重载中的第 8 个)

插入到字符串中.

概要 
template<
    typename InputIterator>
constexpr basic_static_string::iterator
insert(
    basic_static_string::const_iterator pos,
    InputIterator first,
    InputIterator last);
说明

把{first, last)中的字符插入到pos所指向的字符之前.

前置条件

在pos中必须有效{data(), data() + size()},

{first, last) 应为有效范围

异常安全

强保证.

备注

所有引用、指针或指向所含元素的迭代器都会失效. 任何尾后迭代器也会失效.

模板参数

类型

说明

InputIterator

迭代器的类型.
Constraints

InputIterator满足InputIterator且不满足ForwardIterator.

返回值

指向第一个被插入字符的迭代器; 若未插入任何字符, 则为pos

参数

名称

说明

pos

要插入的位置.

first

表示要插入的第一个字符的迭代器.

last

表示要插入的最后一个字符之后位置的迭代器.
异常

类型

抛出时机

std::length_error

size() + insert_count > max_size()
