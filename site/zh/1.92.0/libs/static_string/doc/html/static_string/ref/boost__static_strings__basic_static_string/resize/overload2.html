basic_static_string::resize (2 个重载中的第 2 个)

改变字符串的大小.

概要 
constexpr void
resize(
    basic_static_string::size_type n,
    basic_static_string::value_type c);
说明

把字符串调整为包含n个字符. 若n > size(), 则追加c的副本. 否则,size()被缩减为n.

参数

名称

说明

n

要调整到的字符串大小.

c

如果大小增加, 要追加的字符.
异常

类型

抛出时机

std::out_of_range

n > max_size()
