basic_static_string::replace (14 个重载中的第 11 个)

替换字符串的一部分.

概要 
constexpr basic_static_string&
replace(
    basic_static_string::const_iterator i1,
    basic_static_string::const_iterator i2,
    basic_static_string::const_pointer s);
说明

把范围{i1, i2)中的字符替换为{s, s + len)的内容, 其中字符串len的长度为traits_type::length(s).

前置条件

应为有效范围{i1, i2)

异常安全

强保证.

备注

所有引用、指针或指向所含元素的迭代器都会失效. 任何尾后迭代器也会失效.

返回值

*this

参数

名称

说明

i1

指向要替换的第一个字符的迭代器.

i2

指向要替换的最后一个字符之后位置的迭代器.

s

用于替换的字符串.
异常

类型

抛出时机

std::length_error

size() + (len - std::distance(i1, i2)) > max_size()
