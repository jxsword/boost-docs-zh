basic_static_string::clear

清空内容.

概要 
constexpr void
clear() noexcept;
说明

擦除字符串中的所有字符. 此调用之后, size() 返回零.

复杂度

与 size() 呈线性关系.

备注

所有引用、指针或指向所含元素的迭代器都会失效. 任何尾后迭代器也会失效.
