basic_static_string::operator+= (5 个重载中的第 5 个)

追加到字符串.

概要 
template<
    typename T>
constexpr basic_static_string&
operator+=(
    const T& t);
说明

把 sv 追加到字符串末尾, 其中 sv 为 string_view_type(t).

异常安全

强保证.

模板参数

类型

说明

T

要转换的对象的类型.
Constraints 
std::is_convertible<T const&, string_view>::value &&
!std::is_convertible<T const&, char const*>::value &&
!std::is_convertible<const T&, const basic_static_string&>::value
返回值

*this

参数

名称

说明

t

要追加的字符串.
异常

类型

抛出时机

std::length_error

size() + sv.size() > max_size()
