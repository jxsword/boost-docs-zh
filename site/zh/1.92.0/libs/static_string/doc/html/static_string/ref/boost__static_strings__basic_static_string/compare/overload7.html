basic_static_string::compare (9 个重载中的第 7 个)

把一个字符串与该字符串进行比较.

概要 
template<
    typename T>
constexpr int
compare(
    const T& t) const noexcept;
说明

设s为string_view_type(t)且comp为traits_type::compare(data(), s.data(), std::min(size(), s.size()). 若comp != 0, 则结果为comp. 否则, 结果为0当size() == s.size(); 结果为-1当size() < s.size(); 其他情况下结果为1.
