basic_static_string::resize_and_overwrite

调整字符串大小并覆写其内容.

概要 
template<
    typename Operation>
constexpr void
resize_and_overwrite(
    basic_static_string::size_type n,
    Operation op);
说明

把字符串调整为包含n个字符, 并使用给定的函数对象op覆写字符串内容. 该函数对象以两个参数被调用: 指向字符串内部缓冲区的指针, 以及字符串的大小. 函数对象应返回写入缓冲区的字符数, 该数应小于等于n. 字符串大小被设为该函数对象返回的值.

异常安全

强保证. 但是, 若std::move(op)(p, count)抛出异常, 则行为未定义.

异常

类型

抛出时机

std::length_error

n > max_size()
