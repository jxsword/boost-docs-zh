basic_static_string::insert (11 个重载中的第 9 个)

插入到字符串中.

概要 
constexpr basic_static_string::iterator
insert(
    basic_static_string::const_iterator pos,
    std::initializer_list< basic_static_string::value_type > ilist);
说明

把ilist中的字符插入到pos之前.

前置条件

在pos中必须有效{data(), data() + size()}

异常安全

强保证.

备注

所有引用、指针或指向所含元素的迭代器都会失效. 任何尾后迭代器也会失效.

返回值

指向第一个被插入字符的迭代器; 若未插入任何字符, 则为pos

参数

名称

说明

pos

要插入的位置.

ilist

要从中插入的初始化列表.
异常

类型

抛出时机

std::length_error

size() + ilist.size() > max_size()
