Introduction

该库提供一种可动态调整大小的字符字符串, 具有编译期固定容量与连续的内嵌存储, 字符就放置在字符串对象自身之内. 其 API 与 std::string 非常相近.

动机

固定容量字符串在以下情况下很有用:

  • 无法进行内存分配, 例如在没有自由存储区 (free store)、只有栈与静态内存段可用的嵌入式环境中.
  • 内存分配带来不可接受的性能损失, 例如就延迟而言.
  • 需要在静态内存段中分配具有复杂生命周期的对象.
  • 需要在 constexpr 函数内使用可动态调整大小的字符串.
  • 要求 static_vector 元素的存储位置位于字符串对象自身之内 (例如为支持 memcpy 以便进行序列化).

要求

该库可在两种不同模式下使用: 独立 (standalone) 模式与依赖 Boost 模式. 该库默认为依赖 Boost 模式; 独立模式需通过配置宏显式启用.

在依赖 Boost 模式下, 该库至少需要 C++11, 此外还依赖 Boost.Core、Boost.Utility 与 Boost.ContainerHash. 在独立模式下, 需要 C++17, 但除标准库外不需要任何其他库.

设计

总体设计目标是尽可能接近 std::string 的接口与行为. 当任何操作将超过字符串的最大允许大小时, 若启用了异常, 则抛出 std::length_error. 所有会抛出异常的算法都提供强异常安全保证. 本类旨在作为 std::string 的直接替代品.

static_string 的 API 只在少数几处与 std::string 不同, 其中一处是增加了 subview 函数, 本实现对其返回字符串视图而非 static_string; 另外某些永不抛出异常的函数被标记为 noexcept, 这与 std::string 中的对应函数不同. static_string 的可用重载与 std::string 的完全相同.

迭代器

迭代器失效规则与 std::string 的不同:

  • 移动一个 static_string 会使所有迭代器失效
  • 交换两个 static_string 会使所有迭代器失效

优化

取决于用于 static_string 特化的字符类型与大小, 会使用某些优化来减小类类型的大小. 给定形如 basic_static_string<N, CharT, Traits> 的特化名称:

  • 如果 N 为 0, 则该类没有非静态数据成员. 给定两个对象 a 与 b, 其类型分别为 basic_static_string<0, T, Traits> 与 static_string<0, U, Traits>, 由 data() 返回的指针值在 T 与 U 相同时将相同.
  • 否则, 用于存储 static_string 的大小的成员的类型将是能够表示值 N 的最小标准无符号整数类型.

配置

可以通过定义配置宏来启用或禁用某些特性. 这些宏及其控制的关联特性为:

  • BOOST_STATIC_STRING_STANDALONE: 定义时, 该库进入独立模式.
