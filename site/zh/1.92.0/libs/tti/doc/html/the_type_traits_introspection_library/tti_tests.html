测试 TTI

在 libs/tti/test 子目录中有一个可用于测试 TTI 功能的 jamfile.

不带目标执行该 jamfile, 或指定目标 'tti', 将同时运行 TTI 基本部分和 TTI 变长宏部分的测试. 你可以只运行 TTI 基本部分 (即 TTI 功能的绝大多数) 的测试, 方法是在执行 jamfile时只指定 'ttinovm' 目标. 如果你只想运行 TTI 变长宏部分的测试, 请将目标指定为 'ttivm'.

TTI 库已成功通过以下编译器测试:

  • VC++ 8, 9, 10, 11, 12, 14.0, 14.1, 14.2
  • gcc 3.4.2 到 9.2
  • clang 2.8 到 9.0
  • Intel-linux 12.1 到 19.0
