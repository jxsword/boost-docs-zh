致谢

TTI 库源于我尝试取出未完成的 Concept Traits Library 中的 type_traits_ext 部分并加以扩展. 因此我首先要感谢 CTL 的作者 Terje Slettebo 和 Tobias Schwinger. 我借鉴了该库的思想和实现 (希望有所改进), 并增加了一些新功能.

我还要感谢 Joel Falcou 的帮助及其在内省方面的工作.

其中两个内省模板取自 MPL, 为完整起见以不同的名称纳入我的库, 因此我要感谢该库的 Aleksey Gurtovoy 和 David Abrahams, 以及为这些 MPL 内省宏做出工作的 Daniel Walker.

最后感谢 Anthony Williams 为一个 Visual C++ 缺陷提供了变通方案, 在成员数据的类型为复合类型时内省成员数据需要该方案.
