外围类型

用 TTI 内省的外围类型在调用宏元函数的位置必须是有效类型. 如果此时它不是有效类型, 你会收到编译器错误.

如果外围类型是有效类型但不是类、结构体或联合体类型, 你不会收到编译器错误, 但内省的结果总是返回 'false'; 对于由 BOOST_TTI_MEMBER_TYPE 生成的元函数, 则总是返回标记类型.

使用 BOOST_TTI_HAS_MEMBER_DATA、BOOST_TTI_HAS_MEMBER_FUNCTION 与 BOOST_TTI_HAS_MEMBER_FUNCTION_TEMPLATE 生成的宏元函数时, 第一个模板参数可以是外围类型, 也可以分别是成员数据或成员函数的指针. 在这些情况下, TTI 能够区分这两种可能; 并且仅当第一个模板参数是外围类型时 — 再次强调, 如果它是有效类型但不是类、结构体或联合体类型 — 你不会收到编译器错误, 但内省结果会返回 'false'.
