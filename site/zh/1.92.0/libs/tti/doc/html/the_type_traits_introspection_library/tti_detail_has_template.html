使用 BOOST_TTI_HAS_TEMPLATE 宏

TTI 宏 BOOST_TTI_HAS_TEMPLATE 内省类的内部类模板. 该宏至少必须指定要内省的类模板的名称.

两种内省形式

可用的模板内省有两种一般形式. 第一种是查找拥有任意数量、且仅为模板类型参数 (以 class 或 typename 开头的模板参数) 的类模板. 在这种形式下, 调用宏时只需指定类模板的名称. 我们将宏的这种形式称为 template type parameters 形式. 可以成功内省的此类形式类模板的一个例子是:

template<class X,typename Y,class Z,typename T> class AClassTemplate { /* etc. */ };

第二种是查找具有特定模板参数的类模板. 在这种形式下, 类模板的名称和模板参数都要传给宏.

我们将宏的这种形式称为 specific parameters 形式. 可以成功内省的此类形式类模板的一个例子是:

template<class X, template<class> class Y, int Z> BClassTemplate { /* etc. */ };

使用宏的特定形式时, 向宏传递模板参数有两点需要理解. 第一, 模板参数的类型是相关的, 但传入的模板参数的实际名称无关紧要 — 实际名称可以完全省略, 也可以与嵌套类模板本身中的名称不同. 第二, 在指代模板参数的类型时, 使用 'typename' 还是 'class' 完全可以互换, 就像在实际类模板本身中一样.

变长与非变长宏的用法

使用 BOOST_TTI_HAS_TEMPLATE 宏时, 我们要区分编译器是否支持变长宏.

通过检查宏 BOOST_PP_VARIADIC 的值, 程序员始终可以判断编译器是否支持变长宏, 前提是在包含使用 BOOST_TTI_HAS_TEMPLATE 宏所需的头文件 boost/tti/has_template.hpp 之后. 值为 1 表示编译器支持变长宏, 值为 0 表示不支持.

支持最新 C++11 标准的现代 C++ 编译器通常支持变长宏. 甚至在最新 C++11 标准之前, 一些 C++ 编译器就已经支持变长宏. 如果你认为你的编译器支持变长宏, 而在包含 boost/tti/has_template.hpp 之后 BOOST_PP_VARIADIC 仍为 0, 可以在包含 boost/tti/has_template.hpp 之前将 BOOST_PP_VARIADIC 预定义为 1.

非变长宏的用法

我们先从不支持变长宏的编译器的语法讲起, 因为这种语法也可以被支持变长宏的编译器使用. 非变长宏形式总是接受两个宏参数. 第一个宏参数始终是你要内省的类模板的名称.

第二个宏参数, 在使用宏的 specific parameters 形式时, 是以 Boost 预处理器库数组数据类型形式给出的模板参数. 在使用宏的 template type parameters 形式时, 第二个宏参数是 BOOST_PP_NIL. 若第二个参数既不是 Boost 预处理器库数组数据类型也不是 BOOST_PP_NIL, 在只支持非变长宏的编译器上会产生编译器错误.

使用 template type parameters 形式内省上述类模板的非变长宏形式为:

BOOST_TTI_TEMPLATE(AClassTemplate,BOOST_PP_NIL)
BOOST_TTI_TEMPLATE(BClassTemplate,BOOST_PP_NIL)

在第二种情况下调用元函数总是失败, 因为 BClassTemplate 并非所有参数都是模板类型参数.

使用 specific parameters 形式内省上述类模板的非变长宏形式为:

BOOST_TTI_TEMPLATE(AClassTemplate,(4,(class,typename,class,typename)))
BOOST_TTI_TEMPLATE(BClassTemplate,(3,(class, template<class> class, int)))

使用非变长的 specific parameters 形式时需要小心指定正确数量的数组参数. 如果有模板模板参数, 或者非类型模板参数的类型说明部分带有圆括号, 这有时会很棘手. 后一种情况下, 当圆括号包住逗号 ( ',' ) 时, 不要把它算作又创建了一个 Boost PP 数组元素. 两个例子:

template<void (*FunctionPointer)(int,long)> class CClassTemplate { /* etc. */ };
template<template<class,class> class T> class DClassTemplate { /* etc. */ };

BOOST_TTI_TEMPLATE(CClassTemplate,(1,(void (*)(int,long))))
BOOST_TTI_TEMPLATE(DClassTemplate,(2,(template<class,class> class)))

在使用宏内省 CClassTemplate 的情况下, Boost PP 数组参数的数量是 1, 即使 void (*FunctionPointer)(int,long) 中的记号之间有逗号分隔. 这是因为逗号位于圆括号之内.

在使用宏内省 DClassTemplate 的情况下, Boost PP 数组参数的数量是 2, 因为 template<class,class> class T 中的记号之间有逗号分隔.

变长宏的用法

有了变长宏, 无论使用宏的 template type parameters 形式还是 specific parameters 形式, BOOST_TTI_TEMPLATE 的使用语法都更容易书写. 这是因为变长宏可以接受可变数量的参数. 使用变长宏形式时, 第一个宏参数始终是你要内省的类模板的名称. 只有在使用宏的 specific parameters 形式时才需要指定更多参数, 此时宏的其余参数就是特定的模板参数.

使用 template type parameters 形式内省上面的第一个类模板时, 变长宏为:

BOOST_TTI_TEMPLATE(AClassTemplate)

使用 specific parameters 形式内省上面的其他类模板时, 变长宏为:

BOOST_TTI_TEMPLATE(BClassTemplate,class,template<class> class, int)
BOOST_TTI_TEMPLATE(CClassTemplate,void (*)(int,long))
BOOST_TTI_TEMPLATE(DClassTemplate,template<class,class> class)

这样我们既不必计算 Boost PP 数组的元组记号数量, 在使用 template type parameters 形式时也不必指定 BOOST_PP_NIL. 另外, 对于特定参数形式, 我们只需将模板参数作为变长宏的其余记号即可.

生成的元函数

无论使用变长还是非变长语法, 使用宏的任一形式都会生成一个名为 “has_template_'name_of_inner_class_template'” 的元函数.

可以通过向该元函数传入要内省的外围类型来调用它.

该元函数返回一个名为 'type' 的单一类型, 它是一个 boost::mpl::bool_. 为方便起见, 元函数直接以名为 'value' 的编译期布尔常量返回该类型的值. 根据内部类模板是否存在, 该值为 true 或 false.
