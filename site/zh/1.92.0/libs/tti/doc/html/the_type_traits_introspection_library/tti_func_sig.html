嵌套类型与函数签名

BOOST_TTI_MEMBER_TYPE 能够表示一个可能存在也可能不存在的类型, 并且随后在任何需要类型作为模板参数的其他宏元函数中使用它时不会产生编译器错误, 这一能力不应被低估. 这也是我们在内省外围类型的成员数据、成员函数或静态成员函数时, 生成的元函数有两种不同用法的原因之一.

在使用 BOOST_TTI_HAS_MEMBER_DATA、BOOST_TTI_HAS_MEMBER_FUNCTION 或 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION 并指定复合语法的情况下, 成员数据、成员函数或静态成员函数的签名是单一类型. 对于 BOOST_TTI_HAS_MEMBER_DATA, 签名是指向成员数据的指针; 对于 BOOST_TTI_HAS_MEMBER_FUNCTION, 签名是指向成员函数的指针; 对于 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION, 签名则被拆分为外围类型和复合格式的函数. 这种语法记法书写自然, 但由于这种记法, 我们无法对 BOOST_TTI_MEMBER_TYPE 中这些复合类型的潜在组成部分使用嵌套类型功能. 如果该签名 (它指定了多种类型的复合) 的任何部分无效, 就会发生编译期错误.

但在更具体的情况下, 当我们使用 BOOST_TTI_HAS_MEMBER_DATA、BOOST_TTI_HAS_MEMBER_FUNCTION 和 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION 时, 签名中的复合类型被拆分为各自的单独类型, 因此对其中任何一个单独类型使用 BOOST_TTI_MEMBER_TYPE, 即使指定的类型实际不存在也不会导致编译期错误.

几个例子足以说明问题.

给定已知类型 T 和 U, 以及假定存在的类型 Ntype 作为 U 的嵌套类型, 我们想知道类型 T 是否拥有签名为 void aMemberFunction(U::Ntype) 的成员函数.

首先使用 BOOST_TTI_HAS_MEMBER_FUNCTION 的复合形式, 我们会写:

#include <boost/tti/has_member_function.hpp>

BOOST_TTI_HAS_MEMBER_FUNCTION(aMemberFunction)

has_member_function_aMemberFunction<void (T::*)(U::Ntype)>::value;

如果嵌套类型 U::Ntype 不存在, 这会导致编译器错误. 我们确实希望避免这种情况, 所以让我们试试替代方案.

其次使用 BOOST_TTI_HAS_MEMBER_FUNCTION 的特定形式, 我们会写:

#include <boost/tti/member_type.hpp>
#include <boost/tti/has_member_function.hpp>

BOOST_TTI_HAS_MEMBER_TYPE(Ntype)
BOOST_TTI_HAS_MEMBER_FUNCTION(aMemberFunction)

typedef typename has_member_type_Ntype<U>::type OurType;
has_member_function_aMemberFunction<T,void,boost::mpl::vector<OurType> >::value;

如果嵌套类型 U::Ntype 确实存在, 且 T 确实拥有签名为 void aMemberFunction(U::Ntype) 的成员函数, 我们的 'value' 为 true, 否则为 false. 在这种情况下我们绝不会遇到编译器错误.

作为第二个示例, 我们再次使用第一个示例中的假设: 给定已知类型 T 和 U, 以及假定存在的类型 Ntype 作为 U 的嵌套类型. 但这次让我们查找签名为 void aStaticMemberFunction(U::Ntype) 的静态成员函数.

首先使用 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION 的复合形式, 我们会写:

#include <boost/tti/has_static_member_function.hpp>

BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION(aStaticMemberFunction)

has_static_member_function_aStaticMemberFunction<T,void (U::Ntype)>::value;

同样, 如果嵌套类型 U::Ntype 不存在, 这会导致编译器错误, 所以让我们试试替代方案.

其次使用 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION 的特定形式, 我们会写:

#include <boost/tti/member_type.hpp>
#include <boost/tti/has_static_member_function.hpp>

BOOST_TTI_HAS_MEMBER_TYPE(Ntype)
BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION(aStaticMemberFunction)

typedef typename has_member_type_Ntype<U>::type OurType;
has_static_member_function_aStaticMemberFunction<T,void,boost::mpl::vector<OurType> >::value;

如果嵌套类型 U::Ntype 确实存在, 且 T 确实拥有签名为 void aMemberFunction(U::Ntype) 的成员函数, 我们的 'value' 为 true, 否则为 false. 在这种情况下我们绝不会遇到编译器错误.
