宏元函数

TTI 库使用宏在当前作用域中创建用于按名称内省内部元素的元函数. 针对特定内部元素类型的每个宏都有两种形式: 简单形式中, 第一个宏参数指定内部元素的 'name', 并用于创建元函数的名称; 复杂形式中, 第一个宏参数 (称为 'trait') 指定元函数的名称, 第二个宏参数指定要内省的 'name'. 除这一差别外, 两种形式的宏创建的元函数具有完全相同的功能.

要使用这些元函数, 除非另有说明, 你可以包含主通用头文件 'boost/tti/tti.hpp'. 或者, 你也可以包含下表中给出的特定头文件.

下表按元编程者要内省其存在性的内部元素列出了这些宏. 文档中本节之后将给出每个宏元函数的更详细说明与示例. 每个宏元函数的实际语法可在参考部分找到, 所有宏元函数的用法示例可在 “使用宏元函数” 一节中找到.

在下方的模板列中只给出模板简单形式生成的名称, 因为复杂形式生成的名称总是 'trait', 其中 'trait' 是对应复杂形式宏的第一个参数.

下表中的所有内省元函数都返回一个名为 'value' 的布尔常量, 它指明内部元素是否存在. 所有元函数还有一个名为 'type' 的嵌套类型, 对每个元函数而言它是该布尔常量值的类型, 始终为 boost::mpl::bool_.
