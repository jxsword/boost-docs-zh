历史

Boost 1.73

  • 被内省的外围类型现在也可以是联合体
  • 你可以内省类/结构体、枚举或联合体的特定嵌套类型
  • 可以使用函数模板实例化来内省函数模板的嵌套类型

Boost 1.55 之后的开发

  • 向查询宏元函数的外围类型传入有效的非类类型时, 总是返回 false, 而不是产生编译器错误.
  • 向 BOOST_TTI_MEM_TYPE 宏元函数的外围类型传入有效的非类类型时, 总是返回标记类型, 而不是产生编译器错误.

Boost 1.54

  • TTI 已进入 Boost, 宏得到了简化
  • 破坏性变更
    • 无参类型元函数不再是库的一部分.
    • 现在使用单一的通用宏元函数来内省成员数据、成员函数、静态成员数据、静态成员函数、数据、函数、类型和模板.
    • 宏元函数的复合形式现已并入主宏.
    • BOOST_TTI_HAS_TYPE 元函数接受可选的第二个模板参数, 它可以是 MPL lambda 表达式.
    • BOOST_TTI_MEMBER_TYPE 元函数接受可选的标记类型.

版本 1.5

  • TTI 已被 Boost 接受. 这是根据库评审和最终用户的意见与建议为准备进入 Boost 而进行的第一轮变更. 对于基于最终用户意见和建议的每一轮变更, 我都会发布新的版本号, 以便希望跟踪该库进入 Boost 进展的最终用户了解正在发生的变化. 我的目标是完成所有变更并通过所有测试, 以便 TTI 可从 Boost trunk 复制到 Boost release 中纳入 Boost, 目标版本为 Boost 1.49.
  • 破坏性变更
    • 宏元函数不再生成在任何命名空间中, 而是直接生成在最终用户的作用域中.
    • 每个元函数宏对应的元函数类生成宏已被移除. 最终用户如愿的话可以改用 boost::mpl::quote.
    • 元函数名称生成宏已简化, 不再生成命名空间名称, 并且每个宏元函数宏对应单一的元函数名称生成宏.
    • BOOST_TTI_TRAITS_GEN 宏已被移除.
    • 单个头文件的名称已更改, 以更贴近地反映元函数宏的名称.
    • 复合成员函数宏与复合静态成员函数宏的名称已从 BOOST_TTI_HAS_COMP_MEMBER_FUNCTION 改为 BOOST_TTI_HAS_MEMBER_FUNCTION_WITH_SIG, 从 BOOST_TTI_HAS_COMP_STATIC_MEMBER_FUNCTION 改为 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION_WITH_SIG.
  • 所有模板参数名称现在对 TTI 唯一, 以避免名称冲突.
  • 无参类型元函数可以直接传入非类类型.

版本 1.4

  • 破坏性变更
    • BOOST_TTI_HAS_MEMBER (BOOST_TTI_TRAIT_HAS_MEMBER) 已更改为 BOOST_TTI_HAS_COMP_MEMBER_FUNCTION (BOOST_TTI_TRAIT_HAS_COMP_MEMBER_FUNCTION), 并且 BOOST_TTI_MTFC_HAS_MEMBER (BOOST_TTI_MTFC_TRAIT_HAS_MEMBER) 已更改为 BOOST_TTI_MTFC_HAS_COMP_MEMBER_FUNCTION (BOOST_TTI_MTFC_TRAIT_HAS_COMP_MEMBER_FUNCTION). 这一组功能现在仅支持复合语法的成员函数.
    • BOOST_TTI_HAS_STATIC_MEMBER (BOOST_TTI_TRAIT_HAS_STATIC_MEMBER) 已更改为 BOOST_TTI_HAS_COMP_STATIC_MEMBER_FUNCTION (BOOST_TTI_TRAIT_HAS_COMP_STATIC_MEMBER_FUNCTION), 并且 BOOST_TTI_MTFC_HAS_STATIC_MEMBER (BOOST_TTI_MTFC_TRAIT_HAS_STATIC_MEMBER) 已更改为 BOOST_TTI_MTFC_HAS_COMP_STATIC_MEMBER_FUNCTION (BOOST_TTI_MTFC_TRAIT_HAS_COMP_STATIC_MEMBER_FUNCTION). 这一组功能现在仅支持复合语法的静态成员函数.
    • boost::tti::mf_has_static_data 已更改为 boost::tti::mf_has_static_member_data.
  • 新增了 BOOST_TTI_HAS_STATIC_MEMBER_DATA 及其系列宏, 用于内省静态成员数据.
  • 现在支持包含特定头文件以加快编译.
  • 纳入了宏元函数名称生成宏.
  • 缩短了测试文件与测试头文件的名称.
  • 新增了关于内省函数模板的文档主题.

版本 1.3

  • 破坏性变更
    • 主头文件的名称缩短为 'boost/tti/tti.hpp' 和 'boost/tti/tti_vm.hpp'.
    • 该库遵循 Boost 的约定.
      • 将文件名改为小写字母加下划线.
      • 顶层 tti 命名空间变更为 boost::tti 命名空间.
      • 宏现在以 BOOST_TTI_ 开头, 而非先前的 TTI_.
    • 变长宏支持只能与最新版本的 variadic_macro_library (1.3+ 版) 一起工作.

版本 1.2

  • 新增了一组元函数类宏, 用于把宏元函数作为元数据传递. 这补充了使用占位符表达式把宏元函数作为元数据传递的方式.

版本 1.1

  • 库现在也可以用 gcc 3.4.2 和 gcc 3.4.5 编译.
  • 文档中增加了使用示例.
  • 在文档中, 先前提到的 “嵌套类型元函数” 现在称为 “无参类型元函数”.
  • BOOST_TTI_HAS_TYPE 和 boost::tti::mf_has_type 现在支持可选的 typedef 检查.
  • 实现了允许将复合类型当作单独类型处理的新宏元函数功能. 这些包括:
    • BOOST_TTI_HAS_MEMBER_DATA
    • BOOST_TTI_HAS_MEMBER_FUNCTION
    • BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION
  • 新的无参类型元函数 boost::tti::mf_has_static_member_function 使用新的底层宏元函数 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION. 其签名对参数类型使用可选的 MPL 前向序列, 并使用可选的 Boost function_types 标签类型.
  • 新的无参类型元函数 boost::tti::valid_member_type 和 boost::tti::mf_valid_member_type 用于检查调用 BOOST_TTI_MEMBER_TYPE 或 boost::tti::mf_member_type 元函数返回的 'type' 是否有效.
  • 破坏性变更
    • BOOST_TTI_HAS_TYPE_CHECK_TYPEDEF 和 boost::tti::mf_has_type_check_typedef 已被移除, 其功能并入 BOOST_TTI_HAS_TYPE 和 boost::tti::mf_has_type.
    • BOOST_TTI_MEMBER_TYPE 与 boost::tti::mf_member_type 不再同时返回一个 'valid' 布尔常量. 请改用 boost::tti::valid_member_type 或 boost::tti::mf_valid_member_type 元函数 (见上文).
    • boost::tti::mf_has_static_function 已被移除, 其功能移入 boost::tti::mf_has_static_member_function (见上文).
    • boost::tti::mf_member_data 使用新的底层宏元函数 BOOST_TTI_HAS_MEMBER_DATA.
    • boost::tti::mf_has_member_function 的签名已更改为对参数类型使用可选的 MPL 前向序列, 并使用可选的 Boost function_types 标签类型.
    • 所有无参类型元函数都以其对应的宏元函数参数作为一个类 — 以 Boost MPL lambda 表达式的形式 — 而不是像先前那样以模板模板参数的形式. 使用占位符表达式是将相应宏元函数传给其无参类型元函数的最简单方式.

版本 1.0

该库的初始版本.
