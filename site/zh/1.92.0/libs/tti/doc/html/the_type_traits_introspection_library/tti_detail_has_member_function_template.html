内省成员函数模板

我们可以使用下面将要说明的 TTI 功能来内省用户自定义类型的成员函数模板.

成员函数模板是作为用户自定义类型非静态成员的函数模板. 成员函数模板的一个例子是:

struct AType
  {
  template<class X,class Y,class Z> double AFuncTemplate(X x,Y * y,Z & z)
    { ...some code using x,y,z; return 0.0; }
  };

为了内省该函数模板, 我们使用成员函数模板 AFuncTemplate 的一些理论上的有效实例化. 函数模板的实例化已在前文 “内省函数模板技术” 一节中说明.

为便于说明, 我们将使用的实例化是:

double AFuncTemplate<int,long,bool>(int,long *,bool &)

TTI 内省成员函数模板 template<class X,class Y,class Z> double AFuncTemplate(X,Y *,Z &) — 它位于 AType 结构体内 — 所需要的信息如下:

  • AFuncTemplate 的名称
  • int,long,bool 的模板参数
  • AType 的外围类型
  • double 的返回类型
  • int,long *,bool & 的函数参数

生成元函数

与 TTI 内省用户自定义类型中实体的所有功能一样, 内省成员函数模板是一个两步过程. 第一步是使用宏生成元函数. 用于成员函数模板的宏是 BOOST_TTI_HAS_MEMBER_FUNCTION_TEMPLATE. 该宏接受成员函数模板的名称和实例化后的模板参数, 即上面列表中的前两项:

BOOST_TTI_HAS_MEMBER_FUNCTION_TEMPLATE(AFuncTemplate,int,long,bool)

对于不支持变长宏的编译器, 也可以使用另一种形式 (同样适用于支持变长宏的编译器): 使用 Boost PP 数组将实例化的模板参数指定为单个宏参数:

BOOST_TTI_HAS_MEMBER_FUNCTION_TEMPLATE(AFuncTemplate,(3,(int,long,bool)))

该宏基于 “has_member_function_template_'name_of_inner_member_function_template'” 的模式生成元函数, 在本例中即为 has_member_function_template_AFuncTemplate.

调用元函数

要用该宏测试我们的成员函数模板是否存在, 可以用外围类型、实例化后的返回类型和实例化后的函数参数来调用该宏创建的元函数, 得到的 value 是一个编译期布尔常量: 若成员函数模板存在则为 true, 否则为 false. 有两种做法: 既可以将所需的各个类型作为独立参数传入 (函数参数放在 MPL 前向序列中), 也可以将所需的类型组合成指向成员函数的指针类型的形式. 第一种情况写法如下:

has_member_function_template_AFuncTemplate<AType,double,boost::mpl::vector<int,long *,bool &> >::value

第二种情况写法如下:

has_member_function_template_AFuncTemplate<double (AType::*) (int,long *,bool &)>::value

两种调用在功能上是等价的.

其他注意事项

与 TTI 库中的其他宏一样, 用于生成内省成员函数模板的元函数的宏也有复杂宏形式, 最终用户可以直接指定要生成的元函数的名称. 对应的宏是 BOOST_TTI_TRAIT_HAS_MEMBER_FUNCTION_TEMPLATE, 其第一个参数是要生成的元函数的名称, 第二个参数是成员函数模板的名称, 其余参数是实例化后的模板参数. 对于我们的示例, 可以写:

BOOST_TTI_TRAIT_HAS_MEMBER_FUNCTION_TEMPLATE(AMetafunctionName,AFuncTemplate,int,long,bool)

或者使用非变长宏形式:

BOOST_TTI_TRAIT_HAS_MEMBER_FUNCTION_TEMPLATE(AMetafunctionName,AFuncTemplate,(3,(int,long,bool)))

它生成的元函数名称为 AMetafunctionName.

在其他所有方面, 生成的元函数的工作方式与前面演示的较简单宏形式完全相同.

如果你确实使用简单宏形式 (它根据你要内省的函数模板的名称生成元函数名), 而又不想记住生成元函数名称的模式, 可以使用相应的宏, 以成员函数模板的名称作为单个参数来创建合适的元函数名. 该宏名为 BOOST_TTI_HAS_MEMBER_FUNCTION_TEMPLATE_GEN, 例如

BOOST_TTI_HAS_MEMBER_FUNCTION_TEMPLATE_GEN(AFuncTemplate)

它将生成名称 has_member_function_template_AFuncTemplate.

使用长形式 (外围类型、实例化后的返回类型和实例化后的函数参数) 调用相应元函数时, 可以可选地给出第四个模板参数, 它持有一个用于指定 cv 限定的 Boost FunctionTypes 标签类型. 这意味着你可以通过指定适当的标签类型来添加 'const'、'volatile' 或两者. 不使用标签类型的替代做法是将外围类型指定为 'const'、'volatile' 或两者. 例如, 如果你将标签类型指定为 'boost::function_types::const_qualified', 或者将外围类型指定为 'const YourEnclosingType', 则被内省的成员函数模板必须是 const 函数模板才能正确匹配.

使用较短形式 (指向成员函数的指针) 调用元函数时, 可以简单地在指向成员函数语法末尾添加可能的 cv 限定, 例如 const.
