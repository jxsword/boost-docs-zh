术语

术语 “外围类型” (enclosing type) 指被内省的类型. 该类型始终是类、结构体或联合体.

术语 “内部 xxx” (inner xxx, 其中 xxx 是外围类型的某个元素) 指外围类型中的类型、模板、函数或数据. 术语 “内部元素” (inner element) 也泛指这些实体中的任何一个.

我使用术语 “嵌套类型” (nested type) 指一个类型中的另一个类型. 我使用术语 “成员函数” (member function) 或 “成员数据” (member data) 指属于外围类型的非静态函数或数据. 我使用术语 “静态成员函数” (static member function) 或 “静态成员数据” (static member data) 指属于外围类型的静态函数或数据. 我使用术语 “嵌套类模板” (nested class template) 指嵌套在外围类型中的类模板.

其他术语对于类型中 C++ 语言元素的概念可能同样有效, 但为了保持一致我选择了这些术语.

术语 “生成的元函数” (generated metafunction(s)) 指由宏生成的宏元函数.
