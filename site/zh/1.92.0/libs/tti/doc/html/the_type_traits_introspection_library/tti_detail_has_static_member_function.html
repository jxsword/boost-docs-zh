内省静态成员函数

TTI 宏 BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION 内省类的静态成员函数.

BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION 接受单个参数, 即程序员想要检查其存在性的内部静态成员函数的名称. 该宏生成一个名为 “has_static_member_function_'name_of_inner_static_member_function'” 的元函数.

该元函数可以以两种不同方式调用.

第一种方式是传入要内省的外围类型以及作为独立模板参数的静态成员函数签名. 静态成员函数签名由返回类型、以 boost::mpl 类型前向序列形式给出的可选参数类型, 以及可选的 Boost FunctionTypes 标签类型组成. 典型的 boost::mpl 类型前向序列是 boost::mpl::vector<>.

第二种方式是传入要内省的外围类型以及以函数形式给出的静态成员函数签名. 该函数的形式为:

Return_Type ( Parameter_Types )

其中 Parameter_Types 可以为空, 或者当有多个参数类型时为逗号分隔的参数类型列表.

该元函数返回一个名为 'type' 的单一类型, 它是一个 boost::mpl::bool_. 为方便起见, 元函数直接以名为 'value' 的编译期布尔常量返回该类型的值. 根据具有指定签名的内部静态成员函数是否存在, 该值为 true 或 false.

生成元函数

通过以内部静态成员函数的名称调用宏来生成元函数:

BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION(AStaticMemberFunction)

在当前作用域中生成一个名为 'has_static_member_function_AStaticMemberFunction' 的元函数.

调用元函数

通过以要内省的外围类型以及作为一系列模板参数的静态成员函数签名实例化模板来调用元函数. 或者, 也可以通过传入外围类型和作为单一函数类型的静态成员函数签名来调用元函数.

名为 'value' 的返回值是一个编译期布尔常量.

has_static_member_function_AStaticMemberFunction
  <
  Enclosing_Type,
  StaticMemberFunction_ReturnType,
  boost::mpl::vector<StaticMemberFunction_ParameterTypes>, // optional, can be any mpl forward sequence
  boost::function_types::SomeTagType                       // optional, can be any FunctionTypes tag type
  >::value

OR

has_static_member_function_AStaticMemberFunction
  <
  Enclosing_Type,
  Return_Type ( Parameter_Types )
  >::value

示例

首先我们为各种内部静态成员函数名称生成元函数:

#include <boost/tti/has_static_member_function.hpp>

BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION(function1)
BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION(function2)
BOOST_TTI_HAS_STATIC_MEMBER_FUNCTION(function3)

接下来让我们创建一些想要内省的用户自定义类型.

struct AClass { };
struct Top
  {
  static int function1();
  static AClass function2(double,short *);
  };
struct Top2
  {
  static long function2(Top &,int,bool,short,float);
  static Top * function3(long,int,AClass &);
  };

最后我们调用元函数并得到值. 这一切都发生在编译期, 做编译期模板元编程的程序员可以使用它.

我们将在下面的示例中展示这两种形式. 就期望的结果而言, 两种形式完全可以互换.

has_static_member_function_function1<Top,int>::value; // true
has_static_member_function_function1<Top,int ()>::value; // true
has_static_member_function_function1<Top2,int>::value; // false

has_static_member_function_function2<Top,AClass,boost::mpl::vector<double,short *> >::value; // true
has_static_member_function_function2<Top2,AClass,boost::mpl::vector<double,short *> >::value; // false
has_static_member_function_function2<Top2,long (Top &,int,bool,short,float)>::value; // true

has_static_member_function_function3<Top2,int ()>::value; // false
has_static_member_function_function3<Top2,Top * (long,int,AClass &)>::value; // true;

元函数的复用

该宏只编码了我们正在搜索的静态成员函数的名称, 以及我们正在外围类型中内省静态成员函数这一事实.

因此, 一旦我们创建了按名称内省静态成员函数的元函数, 就可以针对该名称, 将该元函数复用于内省任何拥有任何静态成员函数的外围类型.
