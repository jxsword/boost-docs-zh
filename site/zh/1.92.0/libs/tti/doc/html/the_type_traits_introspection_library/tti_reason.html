为什么选择 TTI 库 ?

在 Boost Type Traits 库中, 有用于查询 C++ 类型信息的编译期功能. 这些信息在模板元编程中非常有用, 与 Boost MPL 库的结构以及其他一些编译期库一起, 构成了 Boost 中大量模板元编程的基础.

Type Traits 库中基本缺失的一个领域, 是确定哪些 C++ 内部元素属于某个用户自定义类型的能力, 其中内部元素可以是一般嵌套类型、特定嵌套类型 (如类/结构体、枚举或联合体)、函数或数据成员、静态函数或静态数据成员, 或者类模板.

Boost 中已有一些这类功能, 既存在于现有库中, 也存在于他人做过工作但从未提交给 Boost 评审的库中. 现有 Boost 库的例子是 Boost MPL, 它提供了以宏和元函数形式确定外围类型是否拥有特定嵌套类型或嵌套类模板的功能. 从未提交给 Boost 的库的例子是 Concept Traits Library, 本库中与类型特征相关的大部分功能即取自该库并加以扩展.

也可能有一些高度依赖高级模板元编程技术的其他 Boost 库, 内部也拥有在编译期内省类型元素的功能. 但据我所知, 这类功能从未被整合到单个 Boost 库中. 本库正是尝试做到这一点, 为 Boost 带来一套可辨识的编译期类型内省接口, 以便其他元编程库能够按自身需要使用它们.
