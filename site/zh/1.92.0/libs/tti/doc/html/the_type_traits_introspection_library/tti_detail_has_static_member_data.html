内省静态成员数据

TTI 宏 BOOST_TTI_HAS_STATIC_MEMBER_DATA 内省类的静态成员数据.

BOOST_TTI_HAS_STATIC_MEMBER_DATA 宏接受单个参数, 即程序员想要检查其存在性的内部静态成员数据的名称. 该宏生成一个名为 “has_static_member_data_'name_of_inner_static_member_data'” 的元函数.

可以通过向该元函数传入要内省的外围类型和静态成员数据的类型来调用它.

该元函数返回一个名为 'type' 的单一类型, 它是一个 boost::mpl::bool_. 为方便起见, 元函数直接以名为 'value' 的编译期布尔常量返回该类型的值. 根据指定类型的内部静态成员数据是否存在, 该值为 true 或 false.

生成元函数

通过以内部静态成员数据的名称调用宏来生成元函数:

BOOST_TTI_HAS_STATIC_MEMBER_DATA(AStaticMemberData)

在当前作用域中生成一个名为 'has_static_member_data_AStaticMemberData' 的元函数.

调用元函数

通过以要内省的外围类型和静态成员数据的类型实例化模板来调用元函数. 名为 'value' 的返回值是一个编译期布尔常量.

has_static_member_data_AStaticMemberData<Enclosing_Type,StaticMemberData_Type>::value

示例

首先我们为各种内部成员数据名称生成元函数:

#include <boost/tti/has_static_member_data.hpp>

BOOST_TTI_HAS_STATIC_MEMBER_DATA(data1)
BOOST_TTI_HAS_STATIC_MEMBER_DATA(data2)
BOOST_TTI_HAS_STATIC_MEMBER_DATA(data3)

接下来让我们创建一些想要内省的用户自定义类型.

struct AClass
  {
  };
struct Top
  {
  static int data1;
  static AClass * data2;
  };
struct Top2
  {
  static long data1;
  static Top data3;
  };

最后我们调用元函数并得到值. 这一切都发生在编译期, 做编译期模板元编程的程序员可以使用它.

has_static_member_data_data1<Top,int>::value; // true
has_static_member_data_data1<Top,long>::value; // false
has_static_member_data_data1<Top2,int>::value; // false
has_static_member_data_data1<Top2,long>::value; // true

has_static_member_data_data2<Top,AClass *>::value; // true
has_static_member_data_data2<Top,int *>::value; // false

has_static_member_data_data3<Top2,int>::value; // false
has_static_member_data_data3<Top2,Top>::value; // true;

元函数的复用

该宏只编码了我们正在搜索的静态成员数据的名称, 以及我们正在外围类型中内省静态成员数据这一事实.

因此, 一旦我们创建了按名称内省内部静态成员数据的元函数, 就可以针对该名称, 将该元函数复用于内省任何拥有任何内部静态成员数据类型的外围类型.
