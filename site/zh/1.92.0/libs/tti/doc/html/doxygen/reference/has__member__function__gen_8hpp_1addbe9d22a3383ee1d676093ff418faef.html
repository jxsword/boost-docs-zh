宏 BOOST_TTI_HAS_MEMBER_FUNCTION_GEN

BOOST_TTI_HAS_MEMBER_FUNCTION_GEN — 为 BOOST_TTI_HAS_MEMBER_FUNCTION 生成宏元函数的名称.

概要

// In header: <boost/tti/gen/has_member_function_gen.hpp>

BOOST_TTI_HAS_MEMBER_FUNCTION_GEN(name)

说明

name = 成员函数的名称.

returns = 生成的宏元函数名称.
