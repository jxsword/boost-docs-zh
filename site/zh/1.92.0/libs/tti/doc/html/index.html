Header Files

欢迎来到 Boost Type Traits Introspection 库, 简称 TTI.

TTI 是一个在编译期按名称内省类型元素的库.

TTI 通过生成元函数的宏来工作. 元函数是具有特定语法、拥有嵌套 'type' 成员的类模板. 因此, 凡是 C++ 中可以使用类模板的地方, 都可以使用 TTI 宏. TTI 生成的元函数与 Boost MPL 库定义的其他元函数没有任何区别.

TTI 生成的元函数用于在编译期内省类型的元素, 至少总是要向每个元函数传入被内省的外围类型.

库名的由来是: 该库提供针对类型的编译期功能, 与 Boost Type Traits 库类似; 并且该库提供的功能是内省一个类型中特定元素的存在性.

这里我在非常宽泛的意义上使用 “内省” 一词. 通常, 计算机语言内省首先指按名称请求返回信息, 然后可进一步利用这些信息内省更具体的细节. 在 TTI 库中, 你必须始终知道并提供名称, 并针对正确类型的内部元素使用所提供的功能, 来查明该特定命名实体是否存在.

你也许更喜欢用 “查询” 而不是 “内省” 来表示本库所做的事情, 但在整个文档中我都使用基于 “内省” 一词的术语.

该库的功能可以概括为:

  • 提供使用一组宏在编译期内省类型的手段. 每个宏接受类型元素的名称, 并生成一个元函数, 随后可调用该元函数来确定该元素是否存在于类型中. 这些生成的元函数在文档中称为 “宏元函数”. 被内省的类型可以是类、结构体或联合体.
  • 提供为可能不存在的类型创建 typedef 的手段. 若该类型不存在, 则返回一个空标记类型作为 typedef 类型. 这个 typedef 类型可以在库的元函数中作为类型使用, 而不会产生编译期错误.

本库依赖于 Boost PP、Boost MPL、Boost Type Traits 与 Boost Function Types.

若使用本库中的变长宏, 本库还依赖于 Boost PP 库的变长宏支持.

本库是一个仅头文件库.

由于本库的依赖全部是仅头文件库, 使用 TTI 库无需构建任何库.

Header Files

有一个单一的头文件 boost/tti/tti.hpp, 它包含了本库的全部头文件.

此外, 针对库要内省的每种元素还有单独的特定头文件. 这允许对要内省的嵌套元素进行更细粒度的包含. 这些头文件是:
