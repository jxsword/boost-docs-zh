属性

类 attributes 用于指定设置协程上下文所需的参数.

enum flag_unwind_t
{
    stack_unwind,
    no_stack_unwind
};

struct attributes
{
    std::size_t     size;
    flag_unwind_t   do_unwind;

    attributes() noexcept;

    explicit attributes( std::size_t size_) noexcept;

    explicit attributes( flag_unwind_t do_unwind_) noexcept;

    explicit attributes( std::size_t size_, flag_unwind_t do_unwind_) noexcept;
};

attributes()

效果:

使用 boost::context::default_stacksize() 的默认构造函数: 协程/生成器完成后会展开栈.

抛出:

无.

attributes( std::size_t size)

效果:

参数 size 定义新协程的栈大小. 终止后展开栈.

抛出:

无.

attributes( flag_unwind_t do_unwind)

效果:

参数 do_unwind 决定终止后是否展开栈. 新协程使用默认栈大小.

抛出:

无.

attributes( std::size_t size, flag_unwind_t do_unwind)

效果:

参数 size 与 do_unwind 由用户提供.

抛出:

无.
