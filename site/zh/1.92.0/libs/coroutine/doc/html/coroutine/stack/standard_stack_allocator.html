类 standard_stack_allocator

Boost.Coroutine 提供满足 栈分配器概念 的类 standard_stack_allocator. 与 protected_stack_allocator 不同, 它不在每个栈末尾追加保护页. 内存直接由 std::malloc() 与 std::free() 管理.

注释

standard_stack_allocator 是默认的栈分配器.

#include <boost/coroutine/standard_stack_allocator.hpp>

template< typename traitsT >
struct standard_stack_allocator
{
    typedef traitT  traits_type;

    void allocate( stack_context &, std::size_t size);

    void deallocate( stack_context &);
}

typedef basic_standard_stack_allocator< stack_traits > standard_stack_allocator
void allocate( stack_context & sctx, std::size_t size)

前置条件:

traits_type::minimum_size() <= size 与 ! traits_type::is_unbounded() && ( traits_type::maximum_size() >= size).

效果:

分配至少 size 字节的内存, 并把指向栈的指针及其实际大小存入 sctx. 视体系结构而定 (栈向下/向上增长), 存储的地址是栈的最高/最低地址.

void deallocate( stack_context & sctx)

前置条件:

sctx.sp 有效, traits_type::minimum_size() <= sctx.size 且 ! traits_type::is_unbounded() && ( traits_type::maximum_size() >= sctx.size).

效果:

释放栈空间.
