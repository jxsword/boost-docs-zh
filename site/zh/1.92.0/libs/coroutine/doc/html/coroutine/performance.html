性能

Boost.Coroutine 的性能在下表所示的平台上进行了测量. 在 x86 平台上使用 rdtsc 与 boost::chrono::high_resolution_clock 并做了开销修正后进行性能测量. 每次测量都考虑了缓存预热, 且唯一运行的线程被绑定到单个 CPU.
