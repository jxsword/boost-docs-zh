类 asymmetric_coroutine<>::pull_type 

#include <boost/coroutine/asymmetric_coroutine.hpp>

template< typename R >
class asymmetric_coroutine<>::pull_type
{
public:
    pull_type() noexcept;

    template< typename Fn >
    pull_type( Fn && fn, attributes const& attr = attributes() );

    template< typename Fn, typename StackAllocator >
    pull_type( Fn && fn, attributes const& attr, StackAllocator stack_alloc);

    pull_type( pull_type const& other)=delete;

    pull_type & operator=( pull_type const& other)=delete;

    ~pull_type();

    pull_type( pull_type && other) noexcept;

    pull_type & operator=( pull_type && other) noexcept;

    operator unspecified-bool-type() const noexcept;

    bool operator!() const noexcept;

    void swap( pull_type & other) noexcept;

    pull_type & operator()();

    R get() const;
};

template< typename R >
void swap( pull_type< R > & l, pull_type< R > & r);

template< typename R >
range_iterator< pull_type< R > >::type begin( pull_type< R > &);

pull_type()

效果:

创建一个表示 not-a-coroutine 的协程.

抛出:

无.

template< typename Fn > pull_type( Fn && fn, attributes const& attr)

前置条件:

size >= minimum_stacksize(), 且在 ! is_stack_unbounded() 时 size <= maximum_stacksize().

效果:

创建一个将执行 fn 的协程, 并进入该协程. 参数 attr 决定栈的清理方式.

抛出:

在 协程函数 内部抛出的异常.

template< typename Fn, typename StackAllocator > pull_type( Fn && fn, attributes const& attr, StackAllocator const& stack_alloc)

前置条件:

size >= minimum_stacksize(), 且在 ! is_stack_unbounded() 时 size <= maximum_stacksize().

效果:

创建一个将执行 fn 的协程. 参数 attr 决定栈的清理方式. 分配/释放栈时使用 stack_alloc.

抛出:

在 协程函数 内部抛出的异常.

~pull_type()

效果:

销毁上下文并释放栈.

pull_type( pull_type && other)

效果:

将 other 的内部数据移至 *this. other 变为 not-a-coroutine.

抛出:

无.

pull_type & operator=( pull_type && other)

效果:

销毁 *this 的内部数据, 并将 other 的内部数据移至 *this. other 变为 not-a-coroutine.

抛出:

无.

operator unspecified-bool-type() const

返回:

若 *this 指向 not-a-coroutine, 或协程函数已返回 (完成), 则该函数返回 false. 否则返回 true.

抛出:

无.

bool operator!() const

返回:

若 *this 指向 not-a-coroutine, 或协程函数已返回 (完成), 则该函数返回 true. 否则返回 false.

抛出:

无.

pull_type<> & operator()()

前置条件:

*this 不是 not-a-coroutine.

效果:

执行控制权被转移给 协程函数 (不向协程函数传递参数).

抛出:

在 协程函数 内部抛出的异常.

R get() 
R    asymmetric_coroutine<R,StackAllocator>::pull_type::get();
R&   asymmetric_coroutine<R&,StackAllocator>::pull_type::get();
void asymmetric_coroutine<void,StackAllocator>::pull_type::get()=delete;

前置条件:

*this 不是 not-a-coroutine.

返回:

返回经由 asymmetric_coroutine<>::push_type::operator() 从协程函数传输来的数据.

抛出:

invalid_result

注释:

若 R 是仅可移动类型, 则只能调用一次 get(), 之后才能进行下一次 asymmetric_coroutine<>::pull_type::operator() 调用.

void swap( pull_type & other)

效果:

将 *this 的内部数据与 other 的值交换.

抛出:

无.

非成员函数 swap() 
template< typename R >
void swap( pull_type< R > & l, pull_type< R > & r);

效果:

如同执行 'l.swap( r)'.

非成员函数 begin( pull_type< R > &) 
template< typename R >
range_iterator< pull_type< R > >::type begin( pull_type< R > &);

返回:

返回一个范围迭代器 (输入迭代器).

非成员函数 end( pull_type< R > &) 
template< typename R >
range_iterator< pull_type< R > >::type end( pull_type< R > &);

返回:

返回一个结束范围迭代器 (输入迭代器).

注释:

当迭代器最初从 begin( pull_type< R > &) 获得, 或经过若干次递增操作后, 该迭代器将与 end( pull_type< R > &) 返回的迭代器相等, 此时对应的 asymmetric_coroutine<>::pull_type::operator bool 将返回 false.
