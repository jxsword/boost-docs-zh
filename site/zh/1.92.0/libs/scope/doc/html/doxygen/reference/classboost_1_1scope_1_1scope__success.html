类模板 scope_success

boost::scope::scope_success — 在离开作用域时, 若不满足失败条件则调用函数的作用域退出守护.

概要

// In header: <boost/scope/scope_success.hpp>

template<typename Func, typename Cond = exception_checker> 
class scope_success {
public:

  // public member functions
  template<typename F> explicit scope_success(F &&, bool = true);
  template<typename F, typename C> 
    explicit scope_success(F &&, C &&, bool = true);
  scope_success(scope_success &&);
  scope_success & operator=(scope_success &&) = delete;
  scope_success(scope_success const &) = delete;
  scope_success & operator=(scope_success const &) = delete;
};

说明

该作用域守护封装两个函数对象: 作用域守护动作和调用该动作的失败条件. 两个函数对象都必须可无参调用, 且可以为以下之一:

  • 具有公有 operator() 的用户自定义类.

  • 指向该类的左值引用.

  • 指向无参函数的左值引用或指针.

条件函数对象 operator() 必须返回一个可按语境转换为 true 的值 (当检测到失败且动作函数对象不允许被执行时), 否则返回 false. 此外, 失败条件函数对象 operator() 不得抛出异常, 否则动作函数对象可能不会被调用. 若未指定, 默认失败条件检查作用域是否因异常而退出: 仅当作用域正常退出时才会调用动作函数对象.

参见: scope_exit

参见: scope_fail

模板参数

  1. typename Func

    作用域守护动作函数对象类型.

  2. typename Cond = exception_checker

    作用域守护失败条件函数对象类型.

scope_success 公有成员函数

  1. template<typename F> explicit scope_success(F && func, bool active = true);
    以给定的可调用函数对象构造作用域守护.

    要求: Func 可从 func 构造. Cond 可无抛出默认构造.

    效果: 如同调用 scope_success(std::forward< F >(func), Cond(), active) 来构造作用域守护.

    抛出: 无, 除非函数对象的构造抛出异常.

    参数:

    func

    销毁时调用的可调用动作函数对象.

    active

    指示作用域守护在构造后是否应为活动状态.

    后置条件:

    this->active() == active 

  2. template<typename F, typename C> 
  explicit scope_success(F && func, C && cond, bool active = true);
    以给定的可调用动作和失败条件函数对象构造作用域守护.

    要求: Func 可从 func 构造, Cond 可从 cond 构造.

    效果: 若 Func 可从 F&& 无抛出构造, 则构造 Func, 其来源为 std::forward< F >(func), 否则其来源为 func. 若 Cond 可从 C&& 无抛出构造, 则构造 Cond, 其来源为 std::forward< C >(cond), 否则其来源为 cond.

    若 Func 或 Cond 的构造抛出异常且 active 为 true, 则在携带该异常返回之前调用 cond, 若其返回 true 再调用 func.

    抛出: 无, 除非函数对象的构造抛出异常.

    参数:

    func

    销毁时调用的可调用动作函数对象.

    cond

    可调用的失败条件函数对象.

    active

    指示作用域守护在构造后是否应为活动状态.

    后置条件:

    this->active() == active 

  3. scope_success(scope_success && that);
    移动构造作用域守护.

    要求: Func 和 Cond 可无抛出移动构造或可拷贝构造.

    效果: 若 Func 可无抛出移动构造, 则移动构造 Func, 其来源为 that 的成员, 否则拷贝构造 Func. 若 Cond 可无抛出移动构造, 则移动构造 Cond, 其来源为 that 的成员, 否则拷贝构造 Cond.

    若 Func 或 Cond 的构造抛出异常且 that.active() == true, 则在携带该异常返回之前调用 Cond 对象 (其存储于 that 中), 若其返回 true 再调用 Func 对象 (若新构造的对象构造成功则为新构造的对象, 否则为 that 中存储的原对象).

    若构造成功, 则将 that 标记为非活动状态.

    抛出: 无, 除非函数对象的移动构造抛出异常.

    参数:

    that

    移动源.

    后置条件:

    that.active() == false 

  4. scope_success & operator=(scope_success &&) = delete;
  5. scope_success(scope_success const &) = delete;
  6. scope_success & operator=(scope_success const &) = delete;
