类模板 error_code_checker

boost::scope::error_code_checker — 用于检查错误码是否指示错误的谓词.

概要

// In header: <boost/scope/error_code_checker.hpp>

template<typename ErrorCode> 
class error_code_checker {
public:
  // types
  typedef bool result_type;  // Predicate result type. 

  // public member functions
  explicit error_code_checker(ErrorCode &) noexcept;
  result_type operator()() const noexcept;
};

说明

该谓词捕获一个对外部错误码对象的引用, 并在调用时对其测试是否指示错误. 该错误码对象必须在谓词的整个生命周期内保持有效.

对于错误码对象 ec, 表达式 !ec 必须有效, 绝不抛出异常, 且返回的值可按语境转换为 bool. 若返回值转换为 false, 则视为错误指示, 谓词返回 true; 否则谓词返回 false.

错误码类型的几个示例:

  • std::error_code 或 boost::system::error_code,

  • std::expected、boost::outcome_v2::basic_outcome 或 boost::outcome_v2::basic_result,

  • int, 其中值 0 表示无错误,

  • bool, 其中值 false 表示无错误,

  • T*, 其中空指针表示无错误.

模板参数

  1. typename ErrorCode

    错误码类型.

error_code_checker 公有成员函数

  1. explicit error_code_checker(ErrorCode & ec) noexcept;
    构造谓词.

    构造时, 谓词保存对外部错误码对象的引用. 被引用的对象必须在谓词的整个生命周期内保持有效.

    抛出: 无.

  2. result_type operator()() const noexcept;
    检查错误码是否指示错误.

    抛出: 无.

    返回:

    如同 !!ec, 其中 ec 是传递给谓词构造函数的错误码对象.
