类 exception_checker

boost::scope::exception_checker — 用于检查是否正在抛出异常的谓词.

概要

// In header: <boost/scope/exception_checker.hpp>


class exception_checker {
public:
  // types
  typedef bool result_type;  // Predicate result type. 

  // public member functions
  exception_checker() noexcept;
  result_type operator()() const noexcept;
};

说明

构造时, 谓词捕获当前的未捕获异常数量, 并在其被调用时与当时的未捕获异常数量进行比较. 若数量增加, 则检测到新异常, 谓词返回 true.

注释

该谓词专为在栈上创建作用域守护的特定用例而设计. 它与 C++20 协程及类似设施 (如纤程和用户态上下文切换) 不兼容: 在这些场景中, 执行线程可能在谓词捕获未捕获异常数量之后被挂起, 然后在未捕获异常数量已发生变化的其他上下文中恢复. 类似地, 它也与以下使用模式不兼容: 谓词在构造后被缓存, 并在线程离开构造谓词的作用域之后才被调用 (例如谓词被存储为类的数据成员或命名空间作用域变量).

exception_checker 公有成员函数

  1. exception_checker() noexcept;
    构造谓词.

    构造时, 谓词保存当前的未捕获异常数量. 调用谓词时将使用该信息来检测是否正在抛出新异常.

    抛出: 无.

  2. result_type operator()() const noexcept;
    检查是否正在抛出异常.

    抛出: 无.

    返回:

    true, 若调用点的未捕获异常数量大于谓词构造点的数量; 否则为 false.
