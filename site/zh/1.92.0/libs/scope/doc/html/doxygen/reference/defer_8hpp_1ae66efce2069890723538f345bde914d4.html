宏 BOOST_SCOPE_DEFER

BOOST_SCOPE_DEFER — 该宏创建一个具有唯一名称的延迟守护.

概要

// In header: <boost/scope/defer.hpp>

BOOST_SCOPE_DEFER

说明

该宏之后应跟随一个在离开当前作用域时调用的函数对象. 用法示例:

BOOST_SCOPE_DEFER []
{
    std::cout << "Hello world!" << std::endl;
};
注释

使用该宏要求 C++17.
