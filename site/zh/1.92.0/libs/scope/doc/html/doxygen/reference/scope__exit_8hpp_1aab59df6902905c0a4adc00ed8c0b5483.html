函数模板 make_scope_exit

boost::scope::make_scope_exit — 用给定的可调用函数对象创建条件作用域守护.

概要

// In header: <boost/scope/scope_exit.hpp>


template<typename F, typename C> 
  scope_exit< typename std::decay< F >::type, typename std::decay< C >::type > 
  make_scope_exit(F && func, C && cond, bool active = true);

说明

效果: 如同调用 scope_exit< std::decay_t< F >, std::decay_t< C > >( std::forward< F >(func), std::forward< C >(cond), active) 来构造作用域守护.

参数:

func

销毁时调用的可调用动作函数对象.

cond

可调用的条件函数对象.

active

指示作用域守护在构造后是否应为活动状态.
