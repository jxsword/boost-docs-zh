类模板 unique_resource

boost::scope::unique_resource — 用于自动回收任意资源的 RAII 封装.

概要

// In header: <boost/scope/unique_resource.hpp>

template<typename Resource, typename Deleter, typename Traits = void> 
class unique_resource {
public:
  // types
  typedef Resource resource_type;  // Resource type. 
  typedef Deleter  deleter_type;   // Deleter type. 
  typedef Traits   traits_type;    // Resource traits. 

  // public member functions
  unique_resource();
  template<typename D> unique_resource(default_resource_t, D &&);
  template<typename R> explicit unique_resource(R &&);
  template<typename R, typename D> unique_resource(R &&, D &&);
  unique_resource(unique_resource const &) = delete;
  unique_resource & operator=(unique_resource const &) = delete;
  unique_resource(unique_resource &&);
  unique_resource & operator=(unique_resource &&);
  ~unique_resource();
  explicit operator bool() const noexcept;
  bool allocated() const noexcept;
  resource_type const & get() const noexcept;
  deleter_type const & get_deleter() const noexcept;
  void release() noexcept;
  void reset();
  template<typename R> void reset(R &&);
  resource_type const & operator->() const noexcept;
  auto operator*() const;
  void swap(unique_resource &);

  // friend functions
  void swap(unique_resource &, unique_resource &);
};

说明

unique_resource 对象独占地拥有被封装的资源, 并在销毁时对其调用删除器函数对象. 被封装的资源可以是满足以下任一条件的任意类型:

  • 可移动构造, 且移动构造函数标记为 noexcept; 或

  • 可拷贝构造; 或

  • 对象类型的左值引用.

删除器必须是可在资源类型的左值上调用的函数对象类型, 且必须可拷贝构造.

可以指定可选的资源特征模板参数. 当满足以下条件时, 资源特征可用于优化 unique_resource 的实现:

  • 资源类型至少存在一个被视为未分配的值 (即任何已分配的资源都不应等于某个未分配资源值). 未分配资源值无需使用删除器释放.

  • 未分配资源值中的一个可视为默认值. 构造默认资源值并将其赋给资源对象 (无论是否已分配) 都不应抛出异常.

  • 资源对象可被测试是否未分配. 此类测试不应抛出异常.

若指定, 资源特征必须是具有以下公有静态成员的类类型:

  • R make_default() noexcept - 必须返回默认资源值, 使得 std::is_constructible< Resource, R >::value && std::is_nothrow_assignable< Resource&, R >::value 为 true.

  • bool is_allocated(Resource const& res) noexcept - 必须返回 true (若 res 不是未分配资源值之一), 否则返回 false.

注意 is_allocated(make_default()) 必须始终返回 false.

当指定满足上述要求的资源特征后, unique_resource 将无需额外存储所拥有的资源对象是否需要在销毁时由删除器释放的标志. 当 unique_resource 不处于已分配状态时, 它将使用默认资源值初始化所拥有的资源对象. 此外, 还可以用未分配资源值构造 unique_resource, 这将创建处于未分配状态的 unique_resource 对象 (不会对未分配资源值调用删除器).

模板参数

  1. typename Resource

    资源类型.

  2. typename Deleter

    资源删除器函数对象类型.

  3. typename Traits = void

    可选的资源特征类型.

unique_resource 公有成员函数

  1. unique_resource();
    构造未分配的唯一资源守护.

    要求: 可构造默认 Resource 值. Deleter 可默认构造且不是函数指针.

    效果: 用默认资源值初始化 Resource 对象. 默认构造 Deleter 对象.

    抛出: 无, 除非 Resource 或 Deleter 的构造抛出异常.

    后置条件:

    this->allocated() == false 

  2. template<typename D> unique_resource(default_resource_t res, D && del);
    以给定的删除器构造未分配的唯一资源守护.

    要求: 可构造默认 Resource 值, 且 Deleter 可从 del 构造.

    效果: 用默认资源值初始化 Resource 值. 若 Deleter 可从 D&& 无抛出构造, 则构造 Deleter, 其来源为 std::forward< D >(del), 否则其来源为 del.

    抛出: 无, 除非 Resource 或 Deleter 的构造抛出异常.

    参数:

    res

    指示默认资源值的标签参数.

    del

    资源删除器函数对象.

    后置条件:

    this->allocated() == false 

  3. template<typename R> explicit unique_resource(R && res);
    以给定的资源和默认构造的删除器构造唯一资源守护.

    要求: Resource 可从 res 构造. Deleter 可默认构造且不是函数指针.

    效果: 如同调用 unique_resource(std::forward< R >(res), Deleter()) 来构造唯一资源对象.

    抛出: 无, 除非 Resource 或 Deleter 的构造抛出异常.

    参数:

    res

    资源对象.

    		 
  4. template<typename R, typename D> unique_resource(R && res, D && del);
    以给定的资源和删除器构造唯一资源守护.

    要求: Resource 可从 res 构造, 且 Deleter 可从 del 构造.

    效果: 若 Resource 可从 R&& 无抛出构造, 则构造 Resource, 其来源为 std::forward< R >(res), 否则其来源为 res. 若 Deleter 可从 D&& 无抛出构造, 则构造 Deleter, 其来源为 std::forward< D >(del), 否则其来源为 del.

    若 Resource 或 Deleter 的构造抛出异常且 res 不是未分配资源值, 则对 res 调用 del (若 Resource 构造失败), 或对已构造的 Resource 对象调用 (若 Deleter 构造失败).

    抛出: 无, 除非 Resource 或 Deleter 的构造抛出异常.

    参数:

    res

    资源对象.

    del

    资源删除器函数对象.

    后置条件:

    若 res 是未分配资源值, 则为 this->allocated() == false, 否则为 this->allocated() == true.

    		 
  5. unique_resource(unique_resource const &) = delete;
  6. unique_resource & operator=(unique_resource const &) = delete;
  7. unique_resource(unique_resource && that);
    移动构造唯一资源守护.

    要求: Resource 和 Deleter 可移动构造.

    效果: 若 Resource 可无抛出移动构造, 则移动构造 Resource, 否则拷贝构造. 若 Deleter 可无抛出移动构造, 则移动构造 Deleter, 否则拷贝构造. 将被移出的唯一资源对象置为非活动状态.

    若构造期间抛出异常, that 保持其原有状态.

    注释

    该逻辑确保发生异常时资源不会泄漏, 并仍由移动源持有.

    抛出: 无, 除非 Resource 或 Deleter 的构造抛出异常.

    参数:

    that

    移动源.

    后置条件:

    设 allocated 在操作之前等于 that.allocated(). 操作之后 this->allocated() == allocated 且 that.allocated() == false.

    		 
  8. unique_resource & operator=(unique_resource && that);
    移动赋值唯一资源守护.

    要求: Resource 和 Deleter 可移动赋值.

    效果: 调用 this->reset(). 然后, 若 Deleter 可无抛出移动赋值, 则先移动赋值 Deleter 对象, 再移动赋值 Resource 对象; 否则以相反顺序移动赋值各对象. 最后, 将被移出的唯一资源对象置为非活动状态.

    若抛出异常, that 保持其原有状态.

    注释

    不同的赋值顺序确保发生异常时资源不会泄漏, 并仍由移动源持有.

    抛出: 无, 除非 Resource 或 Deleter 的赋值抛出异常.

    参数:

    that

    移动源.

    后置条件:

    设 allocated 在操作之前等于 that.allocated(). 操作之后 this->allocated() == allocated 且 that.allocated() == false.

    		 
  9. ~unique_resource();
    若资源已分配, 则对其调用删除器函数. 销毁资源与删除器.

    抛出: 无, 除非调用删除器抛出异常.

  10. explicit operator bool() const noexcept;
    若资源已分配且将由删除器回收, 则返回 true, 否则返回 false.
    注释

    该方法不测试资源的值.

    抛出: 无.

  11. bool allocated() const noexcept;
    若资源已分配且将由删除器回收, 则返回 true, 否则返回 false.

    抛出: 无.

  12. resource_type const & get() const noexcept;
    返回资源对象的引用.

    抛出: 无.

  13. deleter_type const & get_deleter() const noexcept;
    返回删除器对象的引用.

    抛出: 无.

  14. void release() noexcept;
    将资源标记为未分配. 若资源此前已分配, 则不调用删除器.

    抛出: 无.

    后置条件:

    this->allocated() == false 

  15. void reset();
    若资源已分配, 则对其调用删除器函数并将资源标记为未分配.

    抛出: 无, 除非调用删除器抛出异常.

    后置条件:

    this->allocated() == false 

  16. template<typename R> void reset(R && res);
    将新的资源对象赋给唯一资源封装.

    效果: 调用 this->reset(). 然后, 若 Resource 可从 R&& 无抛出赋值, 则将 std::forward< R >(res) 赋给存储的资源对象, 否则赋 res.

    若 res 不是未分配资源值且操作期间抛出异常, 则在携带该异常返回之前对 res 调用存储的删除器.

    抛出: 无, 除非调用删除器抛出异常.

    参数:

    res

    要赋值的资源对象.

    后置条件:

    this->allocated() == false 

  17. resource_type const & operator->() const noexcept;
    对资源对象执行间接访问.

    要求: Resource 可解引用.

    效果: 如同调用 get(), 返回资源对象的引用.

    注释

    若 Resource 不是指针类型, 编译器将调用其 operator->. 该调用序列将持续进行, 直至获得指针.

    抛出: 无. 注意, 此次调用引发的对其他 operator-> 函数的任何隐式后续调用可能具有不同的抛出条件.

  18. auto operator*() const;
    解引用资源对象.

    要求: Resource 可解引用.

    效果: 如同调用 *get(), 返回解引用资源对象的结果.

    抛出: 无, 除非解引用资源对象抛出异常.

  19. void swap(unique_resource & that);
    交换两个唯一资源封装.

    要求: Resource 和 Deleter 可交换, 且 Resource 和 Deleter 中至少一个可无抛出交换.

    效果: 交换 *this 与 that 中存储的资源对象和删除器对象, 如同调用无限定的 swap, 且处于 std::swap 经重载决议可查找到的上下文中.

    若抛出异常且失败的交换操作支持强异常保证, 则 *this 与 that 均保持其原有状态.

    抛出: 无, 除非交换资源对象或删除器抛出异常.

    参数:

    that

    要与之交换的唯一资源封装.

unique_resource 友元函数

  1. void swap(unique_resource & left, unique_resource & right);
    交换两个唯一资源封装.

    效果: 如同 left.swap(right).
