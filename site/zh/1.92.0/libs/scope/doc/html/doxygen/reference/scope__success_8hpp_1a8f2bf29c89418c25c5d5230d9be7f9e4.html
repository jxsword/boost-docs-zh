函数模板 make_scope_success

boost::scope::make_scope_success — 用给定的动作函数对象创建 scope_success 守护.

概要

// In header: <boost/scope/scope_success.hpp>


template<typename F> 
  scope_success< typename std::decay< F >::type > 
  make_scope_success(F && func, bool active = true);

说明

效果: 如同调用 scope_success< std::decay_t< F > >(std::forward< F >(func), active) 来构造作用域守护.

参数:

func

销毁时调用的可调用函数对象.

active

指示作用域守护在构造后是否应为活动状态.
