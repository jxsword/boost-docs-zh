类模板 defer_guard

boost::scope::defer_guard — 在离开作用域时调用函数的延迟守护.

概要

// In header: <boost/scope/defer.hpp>

template<typename Func> 
class defer_guard {
public:

  // public member functions
  template<typename F> defer_guard(F &&);
  defer_guard(defer_guard const &) = delete;
  defer_guard & operator=(defer_guard const &) = delete;
  ~defer_guard();
};

说明

该作用域守护封装一个可无参调用的函数对象, 其可以为以下之一:

  • 具有公有 operator() 的用户自定义类.

  • 指向该类的左值引用.

  • 指向无参函数的左值引用或指针.

延迟守护在销毁时无条件调用被封装的函数对象.

defer_guard 公有成员函数

  1. template<typename F> defer_guard(F && func);
    以给定的可调用函数对象构造延迟守护.

    要求: Func 可从 func 构造.

    效果: 若 Func 可从 F&& 无抛出构造, 则构造 Func, 其来源为 std::forward< F >(func), 否则其来源为 func.

    若 Func 构造抛出异常, 则在携带该异常返回之前调用 func.

    抛出: 无, 除非函数对象的构造抛出异常.

    参数:

    func

    销毁时调用的可调用函数对象.

    		 
  2. defer_guard(defer_guard const &) = delete;
  3. defer_guard & operator=(defer_guard const &) = delete;
  4. ~defer_guard();
    调用被封装的可调用函数对象并销毁该可调用对象.

    抛出: 无, 除非调用该可调用对象抛出异常.
