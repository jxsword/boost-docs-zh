函数模板 make_unique_resource_checked

boost::scope::make_unique_resource_checked — 检查资源是否有效并创建 unique_resource 封装.

概要

// In header: <boost/scope/unique_resource.hpp>


template<typename Resource, typename Deleter, 
         typename Invalid = typename std::decay< Resource >::type> 
  unique_resource< typename std::decay< Resource >::type, typename std::decay< Deleter >::type > 
  make_unique_resource_checked(Resource && res, Invalid const & invalid, 
                               Deleter && del);

说明

效果: 若资源 res 不等于 invalid, 则创建处于已分配状态并拥有 res 的唯一资源封装; 否则创建处于未分配状态的唯一资源封装.

注释

若 res 等于 invalid, 该函数不会调用 del.

抛出: 无, 除非 unique_resource 的构造函数抛出异常.

参数:

res

要封装的资源.

invalid

资源的无效值.

del

对资源调用以释放它的删除器.
