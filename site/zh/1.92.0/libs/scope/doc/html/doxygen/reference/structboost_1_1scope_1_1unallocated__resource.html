结构体模板 unallocated_resource

boost::scope::unallocated_resource — 针对一个或多个未分配资源值的简单资源特征.

概要

// In header: <boost/scope/unique_resource.hpp>

template<auto DefaultValue, auto... UnallocatedValues> 
struct unallocated_resource {

  // public static functions
  static decltype(DefaultValue) make_default() noexcept;
  template<typename Resource> 
    static bool is_allocated(Resource const &) noexcept;
};

说明

该类模板为 unique_resource 生成指定一个或多个未分配资源值的资源特征. 第一个值 (在 DefaultValue 非类型模板参数中指定) 被视为默认值; 其余值在 UnallocatedValues 中列出, 为可选. 除 DefaultValue 或 UnallocatedValues 中列出的值之外的任何资源值均视为已分配.

为使生成的资源特征能够启用 unique_resource 的优化实现, 资源类型必须支持从 DefaultValue 或 UnallocatedValues 中列出的任意资源值进行无抛出构造和赋值, 以及与它们的 (不) 相等比较.

unallocated_resource 公有静态函数

  1. static decltype(DefaultValue) make_default() noexcept;
    返回默认资源值.
  2. template<typename Resource> 
  static bool is_allocated(Resource const & res) noexcept;
    测试 res 是否为已分配资源值.
