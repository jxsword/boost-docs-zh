安装与兼容性

本库是仅头文件库, 不需要单独编译. 你可以将 Boost 头文件路径加入你的项目, 包含所需的 Boost.Scope 头文件, 然后在代码中使用该头文件提供的组件.

本库至少要求 C++11 编译器. 某些特性要求 C++17 支持. 以下编译器已通过本库测试:

  • gcc 4.8 及更新版本
  • clang 3.5 及更新版本
  • MSVC 14.0 及更新版本

库组件与操作系统无关.
