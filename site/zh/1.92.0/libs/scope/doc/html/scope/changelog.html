变更日志

Boost 1.85

该库已被 Boost 接受. 根据 Boost 评审意见和条件所作的更新:

  • 将 scope_final 重命名为 defer_guard, 并将 BOOST_SCOPE_FINAL 重命名为 BOOST_SCOPE_DEFER. 感谢 Peter Dimov 在评审期间提出的建议. "defer" 这一名称已在其他编程语言中使用 (Go、Swift, 甚至已提议纳入 C), 用于类似 scope_final 的功能.
  • 从作用域守护类型中移除了 release 成员. 该方法等效于 set_active(false), 是为与 C++ Extensions for Library Fundamentals TS 兼容而存在的. Boost 评审结论指出, 与 TS 保持一致并非值得追求的目标.
  • 在 unique_resource 中新增 explicit operator bool, 用于测试资源是否处于已分配状态, 类似于 allocated 方法. 这是 Dmitry Arkhipov 在评审前提出的建议. 注意该运算符不测试资源值, 这一点与 std::optional 类似.
  • 新增 unallocated_resource 类模板, 用于简化 unique_resource 资源特征的声明. 更紧凑的 unique_resource 声明这一想法由 Janko Dedic 在其评审意见中提出.
  • 新增描述 Boost.Scope 与 Library Fundamentals TS 差异的文档章节 (见此处和此处).
  • 修改了 unique_resource 的移动构造函数, 使其在发生异常时保留源实参的原有状态. 这偏离了 TS 行为 (TS 规定对移动构造出的资源调用删除器), 但这意味着移动构造函数现在维持强异常保证.
  • 对用户指定的 unique_resource 资源特征强制执行编译期正确性检查. 改进了资源特征要求的描述.
  • 大量文档改进.
