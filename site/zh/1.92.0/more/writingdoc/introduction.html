为 Boost 编写文档

引言

Boost 对你如何编写文档没有任何要求. 如果你要提交的库已有 HTML 格式的成文文档, 没有必要为了遵循这里提出的指南而改动它. 但是, 如果你的文档不是 HTML 格式且不易转换为 HTML, 或者你正在从零开始编写一个库, 或有一个没有任何文档的库, 那么这些指南可以让文档编写容易得多.

关于 文档结构的一节描述了如何组织文档内容. 即使对已有文档的库, 这一节也可能有帮助. 如果希望把库提交给 C++ 标准委员会以期纳入标准, 则可能需要重构文档内容, 以确保内容满足库组件的明确要求 (第 17.3 节).

关于 HTML 设计的一节给出了编写 HTML 文档时应遵循的一般规则, 以呈现专业而一致的外观. 该节还包含一些可用于快速创建文档页面的模板文件.
