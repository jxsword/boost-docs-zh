欢迎使用 Boost C++ 库

Boost 提供免费的、经同行评审的可移植 C++ 源码库.

我们侧重于能与 C++ 标准库良好协作的库. Boost 库力求具有广泛的实用价值, 并可应用于众多领域. Boost 许可证鼓励商业与非商业用途.

我们的目标是确立"既有实践"并提供参考实现, 使 Boost 库最终适于标准化. 已有十个 Boost 库被收入 C++ 标准委员会的库技术报告 (TR1), 并将被纳入即将修订的 C++ 标准. 更多 Boost 库已提案列入即将推出的 TR2.

本次发布中的变更

本次发布包含对许多现有库的更新. 详情参见 发布历史.

入门

如果你的系统尚未安装 Boost, 请按照 入门指南完成安装. 不过, 如果你是通过 Windows 预构建可执行文件或预构建的 Linux 与 Unix 发行版包安装 Boost 来到本页的, 那么安装已经完成. 同样, 如果你是在所在组织的内部 Web 服务器上阅读本文, 安装多半也已完成.

目录

发布目录树几乎包含 Boost 的全部内容; 文档、源码、头文件、脚本、工具, 以及 Boost 用户可能需要的其他一切!

库文档

各个库文档的起点是 库列表页面, 其中给出每个库的简要说明, 并链接到其文档.

网站

一些具有普遍意义或经常变动的 Boost 信息只存在于 Boost 网站上. 发布包中含有指向该网站的链接, 因此在未联网的情况下浏览时, 你会偶尔看到失效链接. 不过, 使用 Boost 库所需的一切都包含在发布包内.

背景

请阅读 入门材料, 帮助你理解 Boost 究竟是什么, 并有助于向所在组织介绍 Boost.

社区

Boost 欢迎并倚重于各类个人与组织的参与. Boost 社区提供了多种参与途径.
