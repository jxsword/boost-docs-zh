示例

back 适配器

本示例包含一个状态机实现, 带有遵循 back::state_machine 接口的 API 适配器. 它有助于在遗留代码库中使用 backmp11.

无堆状态机

本示例演示一个配置为无堆执行的状态机.

它使用 boost::container::static_vector 作为事件池容器——这是默认容器 std::deque 的固定容量替代品. 注意, 该容器类型不支持完成转移; 如需完成转移, 请使用无堆 deque (例如 etl::deque).

可中断状态机

本示例演示一个用中断机制扩展的状态机.

该状态机提供暂停和恢复执行的公共 API. 这样, 它既可以从外部被中断, 也可以通过事件从内部被中断. 由于中断不需要状态切换, 它可以从被中断处立即继续.

Logger

本示例包含一个用于记录状态机活动的观察者实现. 该实现会记录事件处理的开始以及每一条被处理的转移.

运行该示例会产生如下输出:

序列化

这些示例演示如何实现 reflect(…​) 方法来序列化状态机.

序列化为 JSON 对以人类可读格式检查状态机整体状态尤为有用:

{
    "active_state_ids": [
        1 // On
    ],
    "front_end": {
        "brightness": 75
    },
    "machine_state": 1, // idle
    "states": {
        "1": {
            "times_pressed": 1
        }
    }
}

状态机接口

本示例演示如何用 favor_compile_time 策略建立通用的状态机接口.

把状态机隐藏在接口之后可以完全封装其实现——这有助于缩短编译时间、进行单元测试, 以及在分发预编译库时隐藏专有逻辑.

访问者

本示例演示访问者的用法.

一台点唱机可以播放 3 种不同类型的歌曲. 活动状态访问者报告当前正在播放哪首歌. 全状态访问者报告每首歌被播放了多少次.
