范围

到目前为止我们考察的规则有一个共同点: 它们产生的值大小固定且在编译期已知. 然而, 文法可以规定元素的重复. 例如考虑以下文法 (从 rfc7230 宽松改编) :

chunk-ext      = *( ";" token )

BNF 记法中的星号运算符表示重复, 此处是括号内表达式出现零次或多次. 这条产生式可以用函数 range_rule 来表达, 该函数返回一个规则, 允许指定规则重复规定的次数. 下面的规则匹配上文定义的 chunk-ext 文法:

constexpr auto chunk_ext_rule = range_rule(
    tuple_rule( squelch( delim_rule( ';' ) ), token_rule( alnum_chars ) ) );

该规则产生一个 range, 即一种 ForwardRange, 其值类型与传给函数的规则的值类型相同. 此处类型为 string_view, 因为该元组只有一个未压制的元素 token_rule. 可以迭代该范围来产生结果, 无需为每个元素分配内存. 以下代码:

system::result< range< core::string_view > > rv = parse( ";johndoe;janedoe;end", chunk_ext_rule );

for( auto s : rv.value() )
    std::cout << s << "\n";

产生如下输出:

johndoe
janedoe
end

有时重复难以用单个规则表达. 例如下面这个用于逗号分隔的令牌列表 (必须至少包含一个元素) 的文法:

token-list    = token *( "," token )

我们可以用 range_rule 的重载来表达它, 该重载接受两个参数: 第一次匹配使用的规则, 以及后续每次匹配使用的规则. 该函数的两个重载都有额外的可选参数, 用于指定最小重复次数, 或同时指定最小与最大重复次数. 由于我们的列表不能为空, 下面的规则完美地刻画了 token-list 文法:

constexpr auto token_list_rule = range_rule(
    token_rule( alnum_chars ),
    tuple_rule( squelch( delim_rule( ',' ) ), token_rule( alnum_chars ) ),
    1 );

以下代码:

system::result< range< core::string_view > > rv = parse( "johndoe,janedoe,end", token_list_rule );

for( auto s : rv.value() )
    std::cout << s << "\n";

产生如下输出:

johndoe
janedoe
end

更多

以下是本库提供的规则与复合规则. 更多细节请参阅相应的参考章节.

名称 说明

dec_octet_rule

匹配 0 到 255 之间的整数.

delim_rule

匹配一个字符字面量.

literal_rule

精确匹配一个字符串.

not_empty_rule

改为把匹配到的空字符串视为错误.

optional_rule

若解析失败则忽略该规则, 输入指针保持不变.

range_rule

匹配重复数量的元素.

token_rule

匹配来自某个字符集的字符串.

tuple_rule

按顺序匹配指定规则的序列.

unsigned_rule

匹配十进制形式的无符号整数.

variant_rule

匹配由规则指定的一组可选分支之一.
