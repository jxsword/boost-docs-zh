字符集

字符集表示低 ASCII 字符的一个子集, 用作构造规则的基础构件. 本库把它们建模为可用如下等价签名调用的可调用谓词:

/// Return true if ch is in the set
bool( char ch ) const noexcept;

CharSet 概念描述了这些类型在语法和语义上的要求. 这里我们声明一个包含水平与垂直空白字符的字符集类型:

struct ws_chars_t
{
    constexpr bool operator()( char c ) const noexcept
    {
        return c == '\t' || c == ' ' || c == '\r' || c == '\n';
    }
};

类型特征 is_charset 用于判断一个类型是否满足这些要求:

static_assert( is_charset< ws_chars_t >::value, "CharSet requirements not met" );

字符集始终以值的方式传递. 与规则一样, 为书写方便我们声明该类型的一个实例. constexpr 标记用于使其成为零开销抽象:

constexpr ws_chars_t ws_chars{};

为获得最佳效果, 请确保用户自定义的字符集类型是可 constexpr 构造的.

函数 find_if 和 find_if_not 用于在字符串中查找集合中第一个匹配或第一个不匹配的字符. 下面的示例跳过所有前导空白, 然后返回从第一个非空白字符到最后一个非空白字符之间的全部内容:

core::string_view get_token( core::string_view s ) noexcept
{
    auto it0 = s.data();
    auto const end = it0 + s.size();

    // find the first non-whitespace character
    it0 = find_if_not( it0, end, ws_chars );

    if( it0 == end )
    {
        // all whitespace or empty string
        return {};
    }

    // find the next whitespace character
    auto it1 = find_if( it0, end, ws_chars );

    // [it0, it1) is the part we want
    return core::string_view( it0, it1 - it0 );
}

现在可以这样调用该函数:

assert( get_token( " \t john-doe\r\n \t jane-doe\r\n") == "john-doe" );

本库提供以下常用字符集:

值 说明

alnum_chars

包含大写与小写字母以及数字.

alpha_chars

包含大写与小写字母.

digit_chars

包含十进制数字字符.

hexdig_chars

包含大写与小写十六进制数字字符.

vchars

包含可见字符 (即非空白字符) .

库中的一些字符集针对特定字符集做了优化实现, 或进行了总体优化, 其方式往往利用了标准库设施无法利用的机会. 例如, 使用流式 SIMD 扩展 2 (SSE2) 的自定义代码增强, 可用于所有 x86 与 x64 架构.

lut_chars 类型

lut_chars 类型满足 CharSet 的要求, 并提供了优化的 constexpr 实现, 在指定字符集时兼具更高的性能和更便利的记法. 编译期实例可以从字符串构造:

constexpr lut_chars vowels = "AEIOU" "aeiou";

我们可以使用 operator+ 和 operator- 记法在编译期向集合添加或移除元素. 例如, 有时字符 'y' 的发音听起来像元音:

constexpr auto vowels_and_y = vowels + 'y' + 'Y';

该类型得名于其实现方式: 一张由紧凑位组成的查找表 ("lut") . 这使得它支持多种构造方法和灵活的组合. 这里我们用 lambda 创建可见字符集合:

struct is_visible
{
    constexpr bool operator()( char ch ) const noexcept
    {
        return ch >= 33 && ch <= 126;
    }
};
constexpr lut_chars visible_chars( is_visible{} ); // (since C++11)

或者:

constexpr lut_chars visible_chars(
    [](char ch) { return ch >= 33 && ch <= 126; } ); // (since C++17)

可以使用 operator- 计算差集:

constexpr auto visible_non_vowels = visible_chars - vowels;

也可以移除单个字符:

constexpr auto visible_non_vowels_or_y = visible_chars - vowels - 'y';
