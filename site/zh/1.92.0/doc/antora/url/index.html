Boost.URL

Boost.URL 是一个可移植的 C++ 库, 提供对 "URL" (其更正式的描述见 统一资源标识符 (URI) 规范, 下文简称 rfc3986) 进行建模的容器和算法. URL 是标识抽象或物理资源的紧凑字符序列. 例如, 下面是一个有效的 URL:

https://www.example.com/path/to/file.txt?userid=1001&pages=3&results=full#page1

本库理解与 URL 相关的文法, 并提供验证、解析、检查和修改 URL 以及应用规范化或引用解析 (resolution) 算法的功能.

特性

本库虽属通用库, 但在实现和数据表示上特意照顾了需要高效、安全处理 URL 的网络程序, 包括输入来自不受信来源的情形. 库提供了按需使用错误码而非异常的接口, 大多数算法都可以选择不用动态内存分配. 本库的另一个特性是所有修改都使 URL 保持有效状态. 使用本库的代码易读、灵活且高性能. 关于这些设计原则的更多内容参见 设计理由.

Boost.URL 提供以下特性:

  • 仅要求 C++11

  • 编译快, 模板少

  • 严格遵守 rfc3986

  • 维护有效 URL 的容器

  • 无需异常即可工作的解析算法

  • 对 URL 存储与分配的控制

  • 支持 -fno-exceptions, 自动检测

  • 在嵌入式设备上同样出色的特性

本库不处理 国际化资源标识符 (IRI) . IRI 与 URL 不同, 它来自 Unicode 字符串而非低 ASCII 字符串, 由单独的规范定义.

要求

本库要求编译器至少支持 C++11.

对于标准类型, 如 std::error_code 或 std::string_view, 本库使用其对应的 Boost 等价物 boost::system::error_code 和 boost::core::string_view.

Boost.URL 在嵌入式设备上表现出色. 它可以以避免所有动态内存分配的方式使用. 此外, 如有需要, 它还提供无需异常的替代接口.

已测试的编译器

Boost.URL 已在下列编译器上测试:

  • clang: 3.8, 4, 5, 6, 7, 8, 9, 10, 11, 12

  • gcc: 4.8, 4.9, 5, 6, 7, 8, 9, 10, 11

  • msvc: 14.1, 14.2, 14.3

以及以下架构: x86、x64、ARM64、S390x.

我们不测试也不支持 gcc 8.0.1.

术语

历史上曾用各种名称指代不同形式的资源标识符, 包括 URI、URL、URN, 甚至 IRI. 随着时间推移, 在技术文献和非正式作品中, URI 与 URL 的区别已经消失. 在本库中, 我们用 URL 一词指代所有符合 rfc3986 顶层文法规则的有效字符串.

ABNF

本文档使用 rfc5234 的增广 巴科斯-诺尔范式 (ABNF) 记法来规定算法和容器所用的具体文法. 虽然使用本库并不要求完全掌握这种记法, 但它有助于理解 URL 的有效组件是如何定义的. 对于希望使用本库提供的组合器来构建解析算法的用户来说尤其如此.
