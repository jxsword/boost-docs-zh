boost::urls::params_encoded_ref

可变的编码查询参数代理

概要

声明于 <boost/url/params_encoded_ref.hpp>

class [[__visibility__]] params_encoded_ref
    : public params_encoded_base

说明

此容器把 url_base 的百分号编码查询参数暴露为双向范围, 同时允许修改底层 URL. 它直接引用 URL 的缓冲区, 因此 url 必须在代理的寿命期内保持存活.

示例

url u( "?first=John&last=Doe" );

params_encoded_ref p = u.encoded_params();

返回元素时产生的字符串具有 param_pct_view 类型并表示已编码字符串. 传给成员函数的字符串可以包含百分号转义, 对无效输入会抛出异常.

迭代器失效

对底层字符缓冲区的更改可能使引用它的迭代器失效. 通过容器进行的修改会使底层字符缓冲区的某些迭代器失效:

  • append : 仅 end().

  • assign, clear, operator= : 所有参数.

  • erase : 被擦除的参数及其后的所有参数(包括 end()).

  • insert : 插入点处及其后的所有参数(包括 end()).

  • replace, set : 被修改的参数及其后的所有参数(包括 end()).

读取与写入

尽管此类型可用于修改所引用的 URL, 它仍然是一个代理, 从 params_encoded_base 继承的每个观察者函数(例如 contains、find 和 get_or)的行为都如同 params_encoded_view 上的对应函数, 它检查当前的编码查询而不执行任何修改.
