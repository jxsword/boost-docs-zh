boost::urls::url

一个可修改的 URL 容器.

概要

声明于 <boost/url/url.hpp>

class [[__visibility__]] url
    : public url_base

说明

此容器拥有一个 url, 由空终止字符缓冲区表示, 该缓冲区通过按需执行动态内存分配来管理. 其内容可被检查和修改, 且实现维持一个有用的不变式: 对 url 的更改总是使其保持有效状态.

异常安全性

  • 标记为 noexcept 的函数提供不抛出异常保证, 否则:

  • 抛出异常的函数提供强异常安全保证.

BNF

URI-reference = URI / relative-ref

URI           = scheme ":" hier-part [ "?" query ] [ "#" fragment ]

relative-ref  = relative-part [ "?" query ] [ "#" fragment ]

absolute-URI  = scheme ":" hier-part [ "?" query ]

规范

  • Uniform Resource Identifier (URI): Generic Syntax (rfc3986)
