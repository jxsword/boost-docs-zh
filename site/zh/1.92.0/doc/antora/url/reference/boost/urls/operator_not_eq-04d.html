返回值

  • true, 若两地址不相等

  • true, 若两地址不相等, 否则为 false.

  • true, 若已解码的 lhs 不等于已解码的 rhs

  • true, 若 u0 != u1

  • true, 若 a0 != a1, 否则为 false
