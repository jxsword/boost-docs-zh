说明

pos

要赋的值. 空字符串仍算作有值. 也就是说, 该元素的 has_value 为 true.

要匹配的键. 默认情况下使用区分大小写的比较.

可选参数. 若在此传入 ignore_case, 则比较不区分大小写.
