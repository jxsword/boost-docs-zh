boost::urls::static_url::set_query

设置查询

概要

声明于 <boost/url/static_url.hpp>

static_url&
set_query(core::string_view s);

说明

此函数把查询设置为该字符串, 其可以为空. 空查询与没有查询是不同的. 字符串中的保留字符在结果中被百分号转义.

示例

assert( url( "http://example.com" ).set_query( "id=42" ).query() == "id=42" );

后置条件

this->has_query() == true && this->query() == s

异常安全性

强保证. 对 allocate 的调用可能抛出异常.

BNF

query           = *( pchar / "/" / "?" )

query-param     = key [ "=" value ]
query-params    = [ query-param ] *( "&" query-param )

规范

  • 3.4. Query (rfc3986)

  • 查询字符串 (Wikipedia)

返回值

*this

参数

名称

说明

s

要设置的字符串.

参见

encoded_params, params, remove_query, set_encoded_query.
