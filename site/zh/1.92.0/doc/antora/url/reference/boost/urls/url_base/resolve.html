boost::urls::url_base::resolve

相对于此基准 URL 解析 URL 引用

概要

声明于 <boost/url/url_base.hpp>

system::result<void>
resolve(url_view_base const& ref);

说明

此函数尝试解析 URL 引用 ref 相对此基准 URL, 方式类似于 Web 浏览器解析锚点标签.

此 URL 必须满足 URI 文法. 换句话说, 它必须包含方案.

相对引用只有在基准绝对 URI 的语境中才可用. 在 基准 URI 语境中解析相对 引用 的过程在 rfc3986 中有详细定义(见下文).

解析过程的工作方式如同把相对引用追加到基准 URI 之后, 然后将结果规范化.

给定输入的基准 URL, 此函数按如下步骤解析相对引用:

  • 确保基准 URI 至少具有方案

  • 规范化引用路径

  • 合并基准路径与引用路径

  • 规范化合并后的路径

此函数把解析结果就地放入此 URL.

若发生错误, 此 URL 的内容未指定, 并返回 boost::system::result (带有 system::error_code).

对于 ".." 段数量超过基准路径段数的异常 href, 处理方式是把未匹配的 ".." 段包含在结果中, 如 Errata 4547 所述.

示例

url base1( "/one/two/three" );
base1.resolve("four");
assert( base1.buffer() == "/one/two/four" );

url base2( "http://example.com/" )
base2.resolve("/one");
assert( base2.buffer() == "http://example.com/one" );

url base3( "http://example.com/one" );
base3.resolve("/two");
assert( base3.buffer() == "http://example.com/two" );

url base4( "http://a/b/c/d;p?q" );
base4.resolve("g#s");
assert( base4.buffer() == "http://a/b/c/g#s" );

BNF

absolute-URI  = scheme ":" hier-part [ "?" query ]

异常安全性

基本保证. 对 allocate 的调用可能抛出异常.

规范

返回值

成功时为空的 boost::system::result, 若 !base.has_scheme() 则为错误码.

参数

名称

说明

ref

要解析的 URL 引用.

参见

url, url_view.
