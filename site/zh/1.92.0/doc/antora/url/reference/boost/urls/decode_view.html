boost::urls::decode_view

对有效百分号编码字符串的引用

概要

声明于 <boost/url/decode_view.hpp>

class decode_view;

说明

这些视图引用 URL 各部分或其他组件中经过百分号编码的字符串. 特殊字符 (即不在允许字符集中的字符) 以三个字符组成的转义序列存储: 一个百分号 ('%%') 后跟对应未转义字符代码的两位十六进制数, 该字符代码视上下文可能是 UTF-8 码点的一部分.

该视图引用原始字符缓冲区, 仅在需要时才解码转义序列. 特别是, 下列操作会自动执行百分号解码, 无需分配内存:

  • 对字符串的迭代

  • 访问编码后的字符缓冲区

  • 与编码字符串或普通字符串的比较

这些对象只能从具有有效百分号编码的字符串构造, 否则构造失败. 调用者负责确保所构造视图的字符缓冲区在其生存期内保持不被修改, 直到该视图不再被访问.
