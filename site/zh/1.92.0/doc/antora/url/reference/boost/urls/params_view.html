boost::urls::params_view

非所有权的解码查询参数视图

概要

声明于 <boost/url/params_view.hpp>

class [[__visibility__]] params_view
    : public params_base

说明

此只读范围把 URL 的查询字符串解释为双向键/值对, 并在访问时应用百分号解码. 它仅引用原始字符缓冲区; 调用者必须在使用视图期间使该缓冲区保持存活.

示例

url_view u( "?first=John&last=Doe" );

params_view p = u.params();

从迭代器取得的字符串会被自动百分号解码.

迭代器失效

对底层字符缓冲区的更改可能使引用它的迭代器失效.
