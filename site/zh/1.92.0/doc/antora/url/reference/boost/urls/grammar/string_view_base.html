boost::urls::grammar::string_view_base

字符串视图的公共功能

概要

声明于 <boost/url/grammar/string_view_base.hpp>

class string_view_base;

说明

此基类用于为行为类似字符串视图的引用类型提供公共成员函数. 它不能被直接实例化; 而应从该类型派生, 并提供带有所需前置条件和不变式的构造函数.
