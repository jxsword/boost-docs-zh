boost::urls::segments_ref

可变的解码路径段代理

概要

声明于 <boost/url/segments_ref.hpp>

class [[__visibility__]] segments_ref
    : public segments_base

说明

把 url_base 的解码路径段呈现为双向范围, 其修改器会更新底层 URL. 该代理直接引用 URL 的存储, 因此在使用代理期间拥有该存储的 URL 必须保持存活.

示例

url u( "/path/to/file.txt" );

segments_ref ps = u.segments();

解引用迭代器返回的字符串中的百分号转义会被自动解码. 提供给修改函数的字符串中的保留字符会被自动百分号编码.

迭代器失效

对底层字符缓冲区的更改可能使引用它的迭代器失效. 通过容器进行的修改会使部分或全部迭代器失效:

  • push_back : 仅 end().

  • assign, clear, operator= : 所有元素.

  • erase : 被擦除的元素及其后的所有元素(包括 end()).

  • insert : 插入点处及其后的所有元素(包括 end()).

  • replace : 被修改的元素及其后的所有元素(包括 end()).
