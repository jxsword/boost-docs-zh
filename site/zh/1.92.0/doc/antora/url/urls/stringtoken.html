字符串令牌

执行百分号解码的函数在未提供特殊参数调用时, 使用 std::string 返回值. 从易用性角度这是最佳默认值; 就性能而言也是足够好的默认值, 因为许多解码后的字符串都能放进大多数标准实现提供的小缓冲区中.

url_view u("http://www.example.com/my%20file.txt");
pct_string_view sv = u.encoded_path();
assert(sv == "/my%20file.txt");
std::string s = u.path();
assert(s == "/my file.txt");

某些用例可能希望对这些算法如何在字符串中获取和存储数据有更多控制, 例如:

  • 使用非默认分配器返回字符串

  • 复用现有字符串的存储

  • 追加到现有字符串

本库提供一种名为 StringToken 的特殊定制机制, 用于控制需要输出缓冲区的算法如何获取其存储.

StringToken string_token::assign_to 可用于把解码后的值赋给现有字符串:

url_view u("http://www.example.com/my%20file.txt");
std::string s = "existing string";
u.path(string_token::assign_to(s));
assert(s == "/my file.txt");

StringToken string_token::append_to 可用于把解码后的值追加到现有字符串:

url_view u("http://www.example.com/my%20file.txt");
std::string s = "existing string";
u.path(string_token::append_to(s));
assert(s == "existing string/my file.txt");

StringToken string_token::preserve_size 可用于返回 string_view 而不是 std::string. string_view 的底层存储提供给该令牌.

url_view u("http://www.example.com/my%20file.txt");
std::string s = "existing string";
boost::core::string_view sv = u.path(string_token::preserve_size(s));
assert(sv == "/my file.txt");

未提供定制时, 默认行为是使用默认的 string_token::return_string 令牌, 它返回 std::string.

特征 string_token::is_token 可用于判断一个类型是否为 StringToken:

static_assert(
    string_token::is_token<string_token::return_string>::value);
