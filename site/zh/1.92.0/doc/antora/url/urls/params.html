查询参数

虽然查询被规定为普通字符串, 但它通常被解释为一组键值对, 通常称为 URL 参数; 本文使用 查询参数一词, 或简写为 params. 查询参数格式没有官方的标准规范, 但 W3C 建议和 HTML 5 有如下表述:

  • 查询字符串由一系列键值对组成.

  • 在每对中, 字段名与值用等号 ("=") 分隔.

  • 各对之间用 and 符号 ("&") 分隔.

  • 大多数 Web 框架允许多个值使用相同的键.

  • 键比较通常区分大小写, 但最终由接收方负责决定.

这个 URL 有两个查询参数 first 和 last, 其值分别为 "John" 和 "Doe":

https://www.example.com?first=John&last=Doe
s params( s )

"?first=John&last=Doe"

{ { "first", "John" }, { "last", "Doe" } }

与路径一样, 本库允许通过以下独立的、引用底层 URL 的双向视图类型访问参数:

参数 (param) 总是有键, 即使是空字符串. 值是可选的; 空字符串与没有值是两回事. 查询参数中缺少 = 字符解释为没有值, 而有 = 字符但没有值则解释为空字符串.

s params( s )

"?name=John"

{ { "name", "John" } }

"?=John"

{ { "", "John" } }

"?name="

{ { "name", "" } }

"?name"

{ { "name", no_value } }

为了理解查询与得到的参数范围之间的关系, 首先我们定义函数 parms, 它返回与参数容器中元素对应的参数列表:

auto parms( core::string_view s ) -> std::list< param >
{
    url_view u( s );
    std::list< param > seq;
    for( auto qp : u.params() )
        seq.push_back( qp );
    return seq;
}

s params( s )

"?first=John&last=Doe"

{ { "first", "John" }, { "last", "Doe" } }

"?id=42&unsorted"

{ { "id", "42" }, { "last", no_value } }

"?col=cust&row="

{ { "col", "cust" }, { "row", "" } }

"?justify=left&"

{ { "justify", "left" }, { "", no_value } }

"?"

{ { "", no_value } }

""

{ }

空查询字符串 ("?") 会产生包含一个空参数的序列, 这可能令人意外. 这是有意为之的设计; 否则该序列将无法与没有查询字符串的情况区分开 (上表最后两行) .

关于把查询字符串表示为参数的容器的完整细节, 请参阅参考文档.

用于整体解码路径的函数 query 和 set_query 在某个参数中含有编码分隔符时无法正确往返转换, 因为对应的解码分隔符字符不会在参数中作为字面量使用.

如果查询本身包含编码的分隔符, 重新编码时它会被解释为查询参数分隔符, 使得无法区分真正的分隔符与编码字符.

要进行无损往返转换, 请使用 encoded_query、set_encoded_query、params 或 encoded_params API.
