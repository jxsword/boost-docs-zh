概念 ObjectTransform

ObjectTransform

说明

ObjectTransform 是一种函数类型或函数指针类型, 其返回类型 Obj 是一个对象类型, 其参数是 Transform. is_callable< Obj >::value 必须为 false. ObjectTransform 被应用时, 效果是构造一个 Obj' 类型的对象 (见下文), 并把应用各 transform Tn 所得的结果作为构造参数传入.

类型 Obj 可以是一个表示编译期 lambda 表达式的模板特化. 例如, 若 Obj 为 std::pair< proto::_value, int >, 则 ObjectTransform 的结果类型通过把类型 proto::_value 替换为应用 proto::_value transform 所得的结果来计算. 对于给定的类型 Obj、Expr、State 和 Data, 我们可以说类型 Obj' 表示类型 Obj 在所有嵌套 transform 都被替换为以 Expr、State 和 Data 作为 transform 参数的应用结果之后的类型.

如果类型 Obj 不是表示编译期 lambda 表达式的模板特化, 则结果类型 Obj' 与 Obj 相同.
