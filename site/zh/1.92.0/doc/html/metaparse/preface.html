Description

Metaparse 是一个编译期解析器生成器库. Metaparse 提供了一些工具, 用于编写在编译期解析字符串字面量内容的解析器, 这使得可以把领域特定语言 (DSL) 嵌入 C++ 而不改变其原有语法 (注意: DSL 代码片段要写在字符串字面量中, 因此可能需要转义).

假设以下模板类可用于在模板元编程中表示有理数:

template <class Num, class Denom>
struct rational;

Metaparse 可以用字符串字面量构造这样的值 (实例化 rational 模板类). 我们也可以不写 rational<1, 3> , 而写 RATIONAL("1/3") , 任何符合标准的 C++11 编译器都能处理它 (并且含义相同). 这可以用 Metaparse 按如下方式实现:

using namespace boost::metaparse;

typedef
  sequence_apply2<
    rational,

    token<int_>,
    last_of<lit_c<'/'>, token<int_>>
  >
  rational_grammar;

typedef build_parser<entire_input<rational_grammar>> rational_parser;

#define RATIONAL(s) \
  (::rational_parser::apply<BOOST_METAPARSE_STRING(s)>::type::run())

注意, 这就是完整的实现. 还要注意, 这个实现可以扩展, 以在某些情况下改进错误报告.

适用范围

与 Boost.Proto 的比较
与 Boost.Spirit 的比较

Metaparse 旨在供库作者使用, 使他们的 API 遵循库所处问题领域的惯用记法.

与 Boost.Proto 的比较

Boost.Proto 是一个用于构建表达式模板的工具. 表达式模板可以通过把有效的 C++ 表达式重新解释为要用 DSL 编写的表达式来实现 DSL 嵌入.

相对于解析字符串字面量的内容 (这是 Metaparse 的方法), 这种技术有以下优点:

  • 在大多数情况下更快
  • 使用这种技术的 API 可以随着逐步推进库的 API 而"自然浮现". 转向一个全新的 DSL (拥有自己的语法) 则是相对较大的一步.

使用表达式模板进行 DSL 嵌入有以下缺点:

  • 嵌入式 DSL 的语法受限. 它必须是有效的 C++ 表达式. 对大多数库而言, 熟悉原始 DSL 的人通常还需要学习该库的语法才能理解嵌入的代码片段.

Proto 帮助基于表达式模板嵌入 DSL, 而 Metaparse 帮助基于解析字符串字面量的内容来嵌入 DSL.

与 Boost.Spirit 的比较

Spirit 是一个可用于构建解析器的工具, 它在运行期解析 (除其他外) 字符串字面量的内容; 而 Metaparse 是一个在编译期解析字符串字面量内容的工具.

使用本库的优点

本库适用于为处理具有自身记法的问题领域的 C++ 库提供 API. 用 Metaparse 构建的接口让接口的用户能够使用该领域自己的记法, 这使代码更易编写和维护. 接口的用户无需学习一套新的记法 —— 也就是受 C++ 语法约束的库作者所能提供的、试图贴近问题领域原始记法的记法. 示例问题领域包括正则表达式和 SQL 查询.

Metaparse 也可用于构建在编译期 (而非运行期, 或根本不做) 校验字符串字面量内容的库. 这有助于尽早在代码中发现 (并修复) 缺陷 (在编译期间). 一个示例问题领域是 printf.

使用 Metaparse 的代价

用 Metaparse 构建的解析器使用模板元程序处理字符串字面量的内容. 这对使用 Metaparse 的库有以下影响:

  • 用 Metaparse 构建的 API 的维护者需要理解模板元编程.
  • 字符串字面量的内容会在每次编译时 (重新) 解析. 这会影响编译器的内存消耗和编译速度.
  • 库的用户会以编译器模板错误消息的形式收到来自解析器的错误报告. (注意, Metaparse 积极尝试改进其质量, 并为解析器作者提供了 工具).

支持的平台

Metaparse 基于 C++98. 唯一的例外是 BOOST_METAPARSE_STRING 宏, 它需要 C++11 的 constexpr.

Metaparse 在以下编译器上进行积极 (在 CI 环境中) 测试:

  • GCC 4.6, 4.7, 4.8, 4.9
  • Clang 3.4, 3.5, 3.6
  • Visual C++ 2015

Metaparse 预期可在 Visual C++ 2012 和 2010 上工作.
