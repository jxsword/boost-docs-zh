版本管理

Template classes
宏

本节描述本库如何为支持多个 (不向后兼容的) 变更做准备.

模板类

本库的元素定义在 boost::metaparse::v1 命名空间中. 例如, one_char 类是 boost::metaparse::v1::one_char , 在包含 <boost/metaparse/v1/one_char.hpp> 头文件后可用.

与此同时, 本库提供了 <boost/metaparse/one_char.hpp> , 它包含 <boost/metaparse/v1/one_char.hpp> , 并包含以下内容:

namespace boost
{
  namespace metaparse
  {
    using v1::one_char;
  }
}

这使得可以把 one_char 用作 boost::metaparse::one_char.

本库的未来版本可能提供其他命名空间 (例如 v2 ). <boost/metaparse/...> 中的头文件提供本库的最新版本. 要始终获取版本 v1 , 应当使用 <boost/metaparse/v1/...> 中的头文件.

本库不使用内联命名空间, 以便在不支持它们的编译器上工作.

Macros

BOOST_METAPARSE_V1_ 为前缀. 例如 BOOST_METAPARSE_V1_STRING . 它定义在 <boost/metaparse/v1/string.hpp> 头文件中. 本库还提供了 <boost/metaparse/string.hpp> 头文件, 它包含这个宏的定义, 并提供以下定义:

#define BOOST_METAPARSE_STRING BOOST_METAPARSE_V1_STRING

这使得可以把该宏用作 BOOST_METAPARSE_STRING . 本库的未来版本可能定义这个宏的其他版本 (例如 BOOST_METAPARSE_V2_STRING ). BOOST_METAPARSE_STRING 将指向最新版本.

这种版本管理不影响可能被使用本库的代码覆盖的宏. (例如 BOOST_METAPARSE_LIMIT_STRING_SIZE)
