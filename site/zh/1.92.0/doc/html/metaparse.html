说明

Metaparse 是一个面向模板元程序的解析器生成库. 本库的目的是支持创建在编译期进行解析的解析器. 本库旨在用于为 C++ 创建嵌入式领域特定语言. 生成的解析器的输入是一个编译期字符串, 见 string. 解析过程的结果要么是一个错误, 要么是解析器作者指定的任何其他结果.

本库与 Boost.Spirit 类似, 但 Spirit 构建的解析器在运行期解析, 而 Metaparse 构建的解析器在编译期解析. 用 Metaparse 构建的解析器可以输出:

  • 类型
  • 常量值
  • 对象 (具有公有静态成员的类型)
  • 可调用的 C++ 函数 (具有公有静态方法的类型)
  • 模板元函数类

更多细节参见 编译期字符串可以构建什么? 一节.

基于 C++11 特性, 本库可以提供定义输入字符串的高级工具, 而库的其余部分也可在基于 C++98 的编译器上工作. 注意, 如果使用 Boost.Build 在 GCC 或 Clang 上构建测试与示例, 编译器不会启用 C++11 (或更新标准). 要以 C++11 模式构建测试与示例, 需要运行 b2 cxxflags="-std=c++11".

外部教程可在 https://github.com/sabel83/metaparse_tutorial#metaparse-tutorial 找到
