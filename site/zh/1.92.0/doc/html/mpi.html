引言

Boost.MPI 是一个面向高性能并行应用中消息传递的库. Boost.MPI 程序由一个或多个进程组成, 这些进程既可以通过发送和接收单独的消息进行通信 (点对点通信), 也可以作为一个组进行协调 (集合通信). 与线程环境中的通信或使用共享内存库的通信不同, Boost.MPI 的进程可以分布在许多不同的机器上, 这些机器可能运行不同的操作系统并具有不同的底层体系结构.

Boost.MPI 并不是一个全新的并行编程库. 它只是标准消息传递接口 (Message Passing Interface, MPI) 的一个对 C++ 友好的接口, MPI 是高性能分布式计算领域最流行的库接口. MPI 定义了一个可从 C、Fortran 和 C++ 使用的库接口, 并存在许多 MPI 实现. 虽然 MPI 也有 C++ 绑定, 但它们比 C 绑定多出的功能甚少. Boost.MPI 库提供了 MPI 的另一种 C++ 接口, 更好地支持现代 C++ 开发风格, 包括对用户自定义数据类型和 C++ 标准库类型的完整支持、用于集合算法的任意函数对象, 以及运用现代 C++ 库技术以保持最大效率.

目前, Boost.MPI 支持 MPI 1.1 中的大部分功能. Boost.MPI 中的薄抽象层使你可以轻松地把它与对底层 C MPI 库的调用结合起来. Boost.MPI 目前支持:

  • 通信器: Boost.MPI 支持 MPI 通信器的创建、销毁、克隆和分裂, 以及对进程组的操作.
  • 点对点通信: Boost.MPI 通过 send 和 receive 操作支持基本类型和用户自定义数据类型的点对点通信, 同时提供阻塞与非阻塞接口.
  • 集合通信: Boost.MPI 支持诸如 reduce 和 gather 之类的集合操作, 可同时使用内建类型、用户自定义类型和函数对象.
  • MPI 数据类型: Boost.MPI 可以使用 Boost.Serialization 库为用户自定义类型构建 MPI 数据类型.
  • 结构与内容分离: Boost.MPI 可以传输复杂数据结构 (列表、映射等) 的形状 (即 "骨架"), 然后单独传输其内容. 该设施为如下情况做了优化: 大型静态数据结构中的数据需要多次传输.

Boost.MPI 既可以通过其原生 C++ 绑定访问, 也可以通过其替代的 Python 接口 访问.
