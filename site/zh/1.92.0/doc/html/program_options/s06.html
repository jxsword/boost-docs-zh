致谢

我非常感谢所有通过讨论、提交修复以及作为用户而帮助本库开发的人. 看到如此多的参与令人愉快, 正是这些参与使本库远比没有这些帮助时更加出色.

在早期阶段, 与 Gennadiy Rozental、William Kempf 和 Alexander Okhotin 的讨论对本库产生了影响.

Hartmut Kaiser 是第一个在自己的项目中试用本库并发来大量建议和修复的人.

正式评审带来了大量意见和改进. Pavol Droba 帮助厘清了选项描述的语义. Gennadiy Rozental 对本库的许多方面提出了批评, 促成了各种简化. Pavel Vozenilek 对实现做了细致的评审. 以下人员提出了许多意见:
