发布说明

Boost 1.56
  • C++11 分配器模型支持由 Glen Fernandes 实现.
Boost 1.55
  • 文档由 Paul A. Bristow 使用 Quickbook、Doxygen 和 Autoindexing 重构.
  • 右值引用仿真由 Antony Polukhin 使用 Boost.Move 添加.
Boost 1.42
  • 为不需要显式析构的存储元素类型 (如 int 或 double) 新增了具有常数复杂度的 erase_begin(size_type) 和 erase_end(size_type) 方法.
  • 类似地, 修改了 clear() 方法和析构函数的实现, 对不需要显式析构的存储元素类型, 其复杂度现在是常数 (其他类型的复杂度仍为线性).
Boost 1.37 
*Added new methods is_linearized() and rotate(const_iterator).
  • 修复缺陷: #1987 使 circular_buffer.hpp 的 #include 使用绝对路径的补丁. #1852 拷贝构造函数不拷贝容量.
Boost 1.36
  • 更改了 circular_buffer(const allocator_type&) 构造函数的行为. 自本版本起, 该构造函数不分配任何内存, 容量与大小均被置为零.
  • 修复缺陷: #1919 默认构造的环形缓冲区抛出 std::bad_alloc.
Boost 1.35
  • 初始发布.
