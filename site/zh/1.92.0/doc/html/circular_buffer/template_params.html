模板参数

表 6.1. 模板参数要求

参数

要求

T

circular_buffer 中所存元素的类型. T 必须满足 Assignable 和 CopyConstructible. 此外, 若在调用 circular_buffer 的某些方法时作为默认参数提供, T 还必须满足 DefaultConstructible, 例如 insert(iterator pos, const value_type& item = value_type()). 若 circular_buffer 将与其他容器进行比较, 则还须满足 EqualityComparable 和/或 LessThanComparable.

Alloc

用于所有内部内存管理的分配器类型. Alloc 必须满足 STL 施加的分配器要求.
