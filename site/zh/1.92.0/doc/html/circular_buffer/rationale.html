设计理由

circular_buffer 的基本动机是创建一个能 与 STL 无缝协作 的容器.

此外, circular_buffer 的设计遵循以下原则:

  • 对预期应用实现最大 效率.
  • 适合 通用用途.
  • 缓冲区的行为尽可能 直观.
  • 适合通过适配器进行 特化. (circular_buffer_space_optimized 就是这样一个适配器的例子.)
  • 易于 调试. (详情参见调试支持一节.)

为实现最大效率, circular_buffer 和 circular_buffer_space_optimized 把元素存储在一段 连续的内存区域 中, 这使得:

  • 使用固定内存, 没有隐式或意外的内存分配.
  • 从头部和尾部快速常数时间地插入和移除元素.
  • 快速常数时间的元素随机访问.
  • 适合实时和性能关键的应用.

环形缓冲区的可能应用包括:

  • 存储 最近收到的样本, 新样本到来时覆写最旧的.
  • 作为 有界缓冲区 的底层容器 (参见有界缓冲区示例, 代码位于 circular_buffer_bound_example.cpp).
  • 一种 缓存 (cache), 存储指定数量的最近插入的元素.
  • 高效的固定容量 FIFO (先进先出),
  • 高效的固定容量 LIFO (后进先出) 队列, 满时移除最旧的 (最先插入的) 元素.
