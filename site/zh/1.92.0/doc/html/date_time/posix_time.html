POSIX 时间系统

引言 -- 用法示例

引言

定义一个具有纳秒/微秒分辨率和稳定计算性质的非调整时间系统. 纳秒分辨率选项为每个 ptime 使用 96 位底层存储, 而微秒分辨率为每个 ptime 使用 64 位 (细节见 构建选项) . 该时间系统使用格里高利历实现时间表示中的日期部分.

用法示例

示例 说明
时间运算 使用 ptime 和 time_duration 的几个简单计算.
打印小时 从时钟读取时间, 使用 time_iterator.
本地时间到 UTC 的转换 演示几种将本地时间转换为 UTC 时间的不同方法, 包括夏令时规则.
时间段 时间段求交与显示的一些简单示例.

引言

类 boost::posix_time::ptime 是时间点操作的主要接口. 总体而言, ptime 类一旦构造即不可变, 不过它允许赋值.

ptime 类依赖 gregorian::date 提供时间点中日期部分的接口.

创建时间的其他技术包括 时间迭代器.

Struct tm、time_t 与 FILETIME 函数

提供了将 posix_time 对象与 tm 结构相互转换的函数, 以及从 time_t 和 FILETIME 转换的函数.

语法 说明
示例
 
tm to_tm(ptime)
 将 ptime 对象转换为 tm 结构的函数. tm_isdst 字段被置为 -1. 
ptime pt(date(2005,Jan,1), time_duration(1,2,3));
tm pt_tm = to_tm(pt);
/* tm_year => 105
   tm_mon  => 0
   tm_mday => 1
   tm_wday => 6 (Saturday)
   tm_yday => 0
   tm_hour => 1
   tm_min  => 2
   tm_sec  => 3
   tm_isdst => -1 */
ptime ptime_from_tm(tm timetm)
 将 tm 结构转换为 ptime 对象的函数. 字段 tm_wday 、tm_yday 和 tm_isdst 会被忽略. 
tm pt_tm;
pt_tm.tm_year = 105;
pt_tm.tm_mon  = 0;
pt_tm.tm_mday = 1;
pt_tm.tm_hour = 1;
pt_tm.tm_min  = 2;
pt_tm.tm_sec  = 3;
ptime pt = ptime_from_tm(pt_tm);
// pt => 2005-Jan-01 01:02:03
tm to_tm(time_duration)
 将 time_duration 对象转换为 tm 结构的函数. 字段 tm_year、tm_mon、tm_mday、tm_wday、tm_yday 被置为零. tm_isdst 字段被置为 -1. 
time_duration td(1,2,3);
tm td_tm = to_tm(td);
/* tm_year => 0
   tm_mon  => 0
   tm_mday => 0
   tm_wday => 0
   tm_yday => 0
   tm_hour => 1
   tm_min  => 2
   tm_sec  => 3
   tm_isdst => -1 */
ptime from_time_t(std::time_t)
 由 time_t 参数创建 ptime. time_t 中保存的秒数被加到 1970-Jan-01 这一时间点上. 
ptime pt(not_a_date_time);
std::time_t t;
t = 1118158776;
pt = from_time_t(t);
// pt => 2005-Jun-07 15:39:36
ptime from_ftime<ptime>(FILETIME)
 由 FILETIME 结构构造 ptime 的模板函数.

ft.dwHighDateTime = 29715317;
ft.dwLowDateTime = 3865122988UL;

// pt => 2005-Jun-07 15:30:57.039582000

时间时长

引言 -- 头文件 -- 构造 -- 基于计数的构造 -- 从字符串构造 -- 访问器 -- 转换为字符串 -- 运算符 -- Struct tm 函数

引言

类 boost::posix_time::time_duration 是负责表示时间长度的基类型. 时长可以为正或为负. 通用的 time_duration 类提供了一个构造函数, 接受小时数、分钟数、秒数和小数秒数作为参数, 如下面的代码片段所示. time_duration 的分辨率可在编译时配置. 更多信息见 构建-编译器信息.

using namespace boost::posix_time;
time_duration td(1,2,3,4); //01:02:03.000000004 when resolution is nano seconds
time_duration td(1,2,3,4); //01:02:03.000004 when resolution is micro seconds

若干派生自基类 time_duration 的小型辅助类 (如下所示) , 用于适配不同的分辨率. 这些类可以缩短代码并使意图更清晰.

举个例子:

using namespace boost::posix_time;
      
time_duration td = hours(1) + seconds(10); //01:00:10
td = hours(1) + nanoseconds(5); //01:00:00.000000005

注意, 更高分辨率类 (例如 nanoseconds) 是否存在取决于库的安装方式. 更多信息见 构建-编译器信息.

另一种处理方式是利用 time_duration 的 ticks_per_second() 方法编写代码, 无论库如何编译都能移植. 计算与分辨率无关的计数的一般公式如下:

count*(time_duration_ticks_per_second / count_ticks_per_second)

例如, 假设我们想用一个表示十分之一秒的计数来构造. 也就是说, 每个 tick 是 0.1 秒.

int number_of_tenths = 5;
//create a resolution independent count -- divide by 10 since there are 
//10 tenths in a second.  
int count = number_of_tenths*(time_duration::ticks_per_second()/10);
time_duration td(1,2,3,count); //01:02:03.5 //no matter the resolution settings

时间段

引言 -- 头文件 -- 构造 -- 修改器 -- 访问器 -- 转换为字符串 -- 运算符

引言

类 boost::posix_time::time_period 提供了两个时间之间范围的直接表示. 时段通过简化程序的条件逻辑, 能够简化某些类型的计算.

以相等的起点和终点创建的时段, 或以零时长创建的时段, 称为零长度时段. 零长度时段被视为无效 (构造无效时段是完全合法的) . 对于这些时段, last 点总是比 begin 点少一个单位.

时间段示例提供了一个使用时间段的示例.

语法 说明

            ptime)
 创建 [begin, end) 形式的时段. 如果 end <= begin, 则该时段将被定义为无效.

时间迭代器

引言 -- 头文件 -- 概述 -- 运算符

引言

时间迭代器提供了在时间之间迭代的机制. 时间迭代器类似于 双向迭代器 (Bidirectional Iterators) . 不过, time_iterator 与标准迭代器不同: 没有底层序列, 只有一个计算函数. 此外, time_iterator 可以直接与 ptime 类 的实例进行比较. 因此不需要第二个迭代器来表示迭代终点, 而是可以直接使用一个时间点. 例如, 以下代码以 15 分钟的迭代间隔进行迭代. 打印小时 示例也演示了 time_iterator 的用法.

      
	#include "boost/date_time/posix_time/posix_time.hpp"
	#include <iostream>


	int
	main()
	{
	  using namespace boost::gregorian;
	  using namespace boost::posix_time;
	  date d(2000,Jan,20);
	  ptime start(d);
	  ptime end = start + hours(1);
	  time_iterator titr(start,minutes(15)); //increment by 15 minutes
	  //produces 00:00:00, 00:15:00, 00:30:00, 00:45:00
	  while (titr < end) {
	    std::cout << to_simple_string(*titr) << std::endl;
	    ++titr;
	  }
	  std::cout << "Now backward" << std::endl;
	  //produces 01:00:00, 00:45:00, 00:30:00, 00:15:00
	  while (titr > start) {
	    std::cout << to_simple_string(*titr) << std::endl;
	    --titr;
	  }
	}
