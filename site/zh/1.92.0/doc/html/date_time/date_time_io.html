日期时间 IO 系统

流上的异常处理

自 1.33 版起, date_time 库采用了一套全新的 IO 流系统. 这套新系统让用户能够充分控制日期和时间的表示方式. 定制选项可分为两组: 格式标志与字符串元素. 格式标志为日期元素的顺序和类型提供了灵活性. 定制字符串元素则允许替换内建的字符串, 例如月份名、星期名以及 IO 中使用的其他字符串.

输出系统基于 date_facet (派生自 std::facet) , 输入系统基于 date_input_facet (同样派生自 std::facet) . time 和 local_time facet 均派生自这些基类型. 输出系统使用三个格式化器对象, 而输入系统使用四个解析器对象. 这些格式化器和解析器对象同样可以定制.

需要特别注意的是, 虽然此处展示的所有示例都使用窄流 (narrow stream) , 但也提供了宽流 facet (完整列表见 IO 对象) .

还需注意, 并非所有编译器都能使用这套 IO 系统. 对于这些编译器, 先前 date_time 版本所用的 IO 系统仍然可用. 这些编译器会自动选用"旧式 IO" (legacy IO) , 不过也可以通过定义 USE_DATE_TIME_PRE_1_33_FACET_IO 手动选择旧式 IO 系统. 更多信息参见 构建-编译器信息.

流上的异常处理

在输入流处理过程中发生错误时, std::ios_base::failbit 将 (始终) 在流上置位. 也可以让错误发生时抛出异常. 要"开启"这些异常, 请调用流的 exceptions 函数并以 std::ios_base::failbit 作为参数.

// "Turning on" exceptions
date d(not_a_date_time);
std::stringstream ss;
ss.exceptions(std::ios_base::failbit);
ss.str("204-Jan-01");
ss >> d; // throws bad_year exception AND sets failbit on stream
这个新系统的一个简单示例:
//example to customize output to be "LongWeekday LongMonthname day, year"
//                                  "%A %b %d, %Y"
date d(2005,Jun,25);
date_facet* facet(new date_facet("%A %B %d, %Y"));
std::cout.imbue(std::locale(std::cout.getloc(), facet));
std::cout << d << std::endl;
// "Saturday June 25, 2005"

格式标志

这套新系统用于输出的格式标志有许多与 strftime(...) 所用的相同, 但并非全部. 其中新增了一些标志, 另一些则被改写. 输入系统只支持特定的标志, 因此并非所有可用于输出的标志都能用于输入 (我们目前正在设法改善这一状况) .

下表列出了 date_time IO 与 strftime 可用的全部标志. 带单个星号 (*) 的格式标志具有 date_time 特有的行为; 带感叹号 (!) 的标志 (目前) 不能用于输入; 带井号 (#) 的标志由系统 locale 实现, 已知在某些平台上缺失. 第一个表针对日期, 第二个表针对时间.

时段


period_formatter 和 period_parser 为 date_period、time_period (以及未来发布版本中的 local_date_time_period) 的输入和输出提供了统一的接口. 用户可以控制定界符、日期/时间组成部分的格式以及时段的表现形式. 日期/时间组成部分的格式通过 date_time 输入和输出 facet 控制.



时段形式


时段以开区间参数构造. 第一个值是起点, 包含在时段内; 末值不包含在内, 但紧跟最后一个值之后: [begin/end). 不过, 时段既可以按开区间也可以按闭区间进行流式处理.


[2003-Jan-01/2003-Dec-31] <-- period holding 365 days
[2003-Jan-01/2004-Jan-01) <-- period holding 365 days



定界符


共有四个定界符. 默认值为




"\" - 分隔符


"[" - 起始定界符


")" - 开区间结束定界符


"]" - 闭区间结束定界符




用户可以提供自定义的一组定界符. 自定义定界符可以包含空格.



定制


时段形式和定界符既可以作为构造参数设置, 也可以通过访问器函数设置. 自定义的时段解析器/格式化器随后既可作为新 facet 的构造参数使用, 也可通过访问器函数设置到既有 facet 中.

日期生成器


date_generator 格式化器和解析器允许用户使用自定义的"短语元素", 从而提供了灵活性. 这些短语元素是 date_generator 中的"间隔"词. 例如, 在 date_generator "Second Monday of March"中, "Second"和"of"是短语元素, 而"Monday"和"March"是日期元素. 日期元素的定制通过 facet 完成. 日期元素与短语元素的顺序不可更改. 解析时, date_generator 短语的所有元素都必须正确解析, 否则将抛出 ios_base::failure 异常.



定制


默认的"phrase_strings"为:



"first"
"second"
"third"
"fourth"
"fifth"
"last"
"before"
"after"
"of"



自定义的 phrase_strings 集合必须保持这一出现顺序 (例如: "1st"、"2nd"、"3rd"、"4th"、"5th"、"last"、"prior"、"past"、"in") .


使用默认 phrase_strings 以及星期几与月份的默认 facet 格式的示例:


"first Tue of Mar"


以及使用自定义 phrase_strings 的示例:


"1st Tue in Mar"



  


自定义的短语元素集合既可作为构造参数设置, 也可通过访问器函数设置. 自定义的 date_generator 解析器/格式化器随后既可作为新 facet 的构造参数使用, 也可通过访问器函数设置到既有 facet 中.


重要说明: 在 1.33 之前, partial_date 输出为"1 Jan", 其中日的数字为一位或两位. 新行为是*始终*为日输出两位数字——"01 Jan".

下面的示例展示了新 IO 代码的基本用法, 全部使用默认值. (该示例可在 libs/date_time/example/tutorial 目录中找到)


    
  date d(2004, Feb, 29);
  time_duration td(12,34,56,789);
  stringstream ss;
  ss << d << ' ' << td;
  ptime pt(not_a_date_time);
  cout << pt << endl; // "not-a-date-time"
  ss >> pt;
  cout << pt << endl; // "2004-Feb-29 12:34:56.000789"
  ss.str("");
  ss << pt << " EDT-05EDT,M4.1.0,M10.5.0";
  local_date_time ldt(not_a_date_time);
  ss >> ldt;
  cout << ldt << endl; // "2004-Feb-29 12:34:56.000789 EDT"
    
  


本示例对输入和输出 facet 使用默认设置. 默认格式使得示例中展示的这种互操作性成为可能. 注意: local_date_time 的输入流处理只能使用 POSIX 时区字符串. 默认输出格式使用时区缩写. 可以修改格式使输出与输入相匹配 (本教程稍后会看到) .



格式字符串


格式字符串控制所用日期/时间元素的顺序、类型和样式. facet 提供了一些预定义格式 (iso_format_specifier、iso_format_extended_specifier 和 default_date_format) , 但用户也可以轻松创建自己的格式.
 (续上一个示例) 
    
  local_time_facet* output_facet = new local_time_facet();
  local_time_input_facet* input_facet = new local_time_input_facet();
  ss.imbue(locale(locale::classic(), output_facet));
  ss.imbue(locale(ss.getloc(), input_facet));
  
  output_facet->format("%a %b %d, %H:%M %z");
  ss.str("");
  ss << ldt;
  cout << ss.str() << endl; // "Sun Feb 29, 12:34 EDT"

  output_facet->format(local_time_facet::iso_time_format_specifier);
  ss.str("");
  ss << ldt;
  cout << ss.str() << endl; // "20040229T123456.000789-0500"
 
  output_facet->format(local_time_facet::iso_time_format_extended_specifier);
  ss.str("");
  ss << ldt;
  cout << ss.str() << endl; // "2004-02-29 12:34:56.000789-05:00"
    
  


格式字符串并不限于日期/时间元素. 可以在格式字符串中放置额外的文字. 注意: 当输入格式中包含额外文字时, 被输入的数据也必须包含完全相同的文字.
 (续上一个示例) 
    
  // extra words in format
  string my_format("The extended ordinal time %Y-%jT%H:%M can also be \
  represented as %A %B %d, %Y");
  output_facet->format(my_format.c_str());
  input_facet->format(my_format.c_str());
  ss.str("");
  ss << ldt;
  cout << ss.str() << endl;

  // matching extra words in input 
  ss.str("The extended ordinal time 2005-128T12:15 can also be \
  represented as Sunday May 08, 2005");
  ss >> ldt;
  cout << ldt << endl;

定制特殊值的输入输出, 最好的方式是创建新的 special_values_parser 和 special_values_formatter. 新字符串可以在构造时设置 (如下例所示) .
 (续上一个示例) 
    
  // reset the formats to defaults
  output_facet->format(local_time_facet::default_time_format);
  input_facet->format(local_time_input_facet::default_time_input_format);

  // create custom special_values parser and formatter objects
  // and add them to the facets
  string sv[5] = {"nadt","neg_inf", "pos_inf", "min_dt", "max_dt" };
  vector<string> sv_names(&sv[0], &sv[5]);
  special_values_parser sv_parser(sv_names.begin(), sv_names.end());
  special_values_formatter sv_formatter(sv_names.begin(), sv_names.end());
  output_facet->special_values_formatter(sv_formatter);
  input_facet->special_values_parser(sv_parser);

  ss.str("");
  ldt = local_date_time(not_a_date_time);
  ss << ldt;
  cout << ss.str() << endl; // "nadt"
  
  ss.str("min_dt");
  ss >> ldt;
  ss.str("");
  ss << ldt;
  cout << ss.str() << endl; // "1400-Jan-01 00:00:00 UTC"

日期/时间时段


定制时段的输入输出, 最好的方式是创建新的 period_parser 和 period_formatter. 新字符串可以在构造时设置 (如下例所示) .
 (续上一个示例) 
    
  // all formats set back to defaults (not shown for brevity)

  // create our date_period
  date_period dp(date(2005,Mar,1), days(31)); // month of march

  // custom period formatter and parser
  period_formatter per_formatter(period_formatter::AS_OPEN_RANGE, 
                                 " to ", "from ", " exclusive", " inclusive" );
  period_parser per_parser(period_parser::AS_OPEN_RANGE, 
                           " to ", "from ", " exclusive" , "inclusive" );
  
  // default output
  ss.str("");
  ss << dp;
  cout << ss.str() << endl; // "[2005-Mar-01/2005-Mar-31]"
 
  // add out custom parser and formatter to  the facets
  date_output->period_formatter(per_formatter);
  date_input->period_parser(per_parser);
  
  // custom output
  ss.str("");
  ss << dp;
  cout << ss.str() << endl; // "from 2005-Feb-01 to 2005-Apr-01 exclusive"
