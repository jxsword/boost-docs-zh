如何使用本文档

本文档使用以下命名与格式约定.

  • 代码使用 fixed width font 呈现, 并带语法高亮显示.
  • 需要由你提供的可替换文本放在 italics 中.
  • 自由函数以代码字体呈现, 后跟 (), 例如 free_function().
  • 如果名称指代类模板, 其写法如下: class_template<>; 也就是说, 它以代码字体呈现, 且名称后跟 <> 以表明它是类模板.
  • 如果名称指代函数式宏, 其写法如下: MACRO(); 也就是说, 它以代码字体的大写形式呈现, 且名称后跟 () 以表明它是函数式宏. 对象式宏则不带结尾的 ().
  • 泛型编程意义上的 概念 名称以 CamelCase 形式给出.

动机

Boost.Ratio 旨在实现 C++11 的编译期比值设施, 如 N2661 - A Foundation to Sleep On 提案所述. 该文档提供了关键设计决策的背景与动机, 也是本文档大量信息的来源.

由于 C++11 现已普遍可用, 本库仅为向后兼容而保留, 并且从 Boost 1.84 开始, 它基于标准 <ratio> 头文件实现.

说明

Boost.Ratio 库提供:

  • 一个类模板 ratio, 用于指定编译期有理常数, 例如每纳秒 1/3 或每米的英寸数. ratio 表示编译期常数的编译期比值, 支持带溢出与除零保护的编译期算术.
  • 它提供 boost::ratio<N, D> 的文本表示, 形式为 std::basic_string, 这对 I/O 很有用.
