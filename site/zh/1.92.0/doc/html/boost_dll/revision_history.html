修订历史

1.0 (首个 Boost 发布版)
  • 移除了 shared_library::load_self()
  • 把 shared_library::path() 更名为 shared_library::location()
  • import_function* 与 import_variable* 函数被重构为 import* 函数
  • 移除对 'boost::string_ref' 的依赖
  • 多项 MacOS 与 Android 修复
  • 针对 import* 函数的性能与内存优化
  • 重构了 shared_library::load() 实现, 统一了各平台上 load_mode::append_decorations 的行为
  • 把 shared_library::search_symbol() 更名为 shared_library::has()
  • 移除对无用的 Windows 特有 load_library_as_* 标志的支持
  • 改进库加载失败时的错误报告
  • 为 shared_library 实现了拷贝构造函数与赋值运算符
0.2

采纳了来自 "Boost query interest" 邮件与 Boost Incubator 的意见, 实现了新特性:

  • 项目更名为 Boost.DLL.
  • 改进文档.
  • 新增 library_info 类.
  • 新增用于显式指定节的别名宏.
  • 别名现使用 "boostdll" 节.
  • 新增 symbol_location() 方法.
  • 新增 this_line_location() 方法.
0.1

Boost.Plugin 0.1 (取自 Boost.Application 的首个独立原型, 并做了大量改进)
