可移植性

BOOST_FOREACH 使用了一些相当复杂的技术, 并非所有编译器都支持. 取决于编译器的标准符合程度, 在某些场景下你可能无法使用 BOOST_FOREACH. 由于 BOOST_FOREACH 使用 Boost.Range, 它继承了 Boost.Range 的可移植性问题. 相关问题见 Boost.Range 可移植性 一节.

除了 Boost.Range 对编译器的要求之外, BOOST_FOREACH 为了正确处理右值序列还提出了额外要求. (回想一下, 右值是未命名的对象, 因此右值序列的一个例子是按值返回 std::vector<> 的函数.) 各编译器对右值和左值的处理方式各不相同. 为了应对这种情况, BOOST_FOREACH 定义了三个符合级别, 如下所述:

表 12.1. BOOST_FOREACH 符合级别

Level

含义

级别 0

最高符合级别
BOOST_FOREACH 可用于左值、右值和 const 限定的右值.

级别 1

中等符合级别
BOOST_FOREACH 可用于左值和普通右值, 但不可用于 const 限定的右值.
在这种情况下定义了 BOOST_FOREACH_NO_CONST_RVALUE_DETECTION.

级别 2

最低符合级别
BOOST_FOREACH 只可用于左值, 不可用于右值.
在这种情况下定义了 BOOST_FOREACH_NO_RVALUE_DETECTION.
