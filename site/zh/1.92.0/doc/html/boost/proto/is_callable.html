结构体模板 is_callable

boost::proto::is_callable — 一个布尔元函数, 判断某类型是否是可调用的 PolymorphicFunctionObject.

概要

// In header: <boost/proto/traits.hpp>

template<typename T> 
struct is_callable :  mpl::bool_<true-or-false> {
};

说明

proto::is_callable<> 被 proto::when<> 变换用来判断函数类型 R(A1,...An) 是 CallableTransform 还是 ObjectTransform. 前者用 proto::call<> 求值, 后者用 proto::make<> 求值. 如果 proto::is_callable<R>::value 为 true, 则该函数类型是 CallableTransform; 否则, 它是 ObjectTransform.

除非针对类型 T 特化, proto::is_callable<T>::value 按如下方式计算:

  • 如果 T 是模板类型 X<Y0,...Yn>, 其中所有 Yx 都是 x 遍历 [0,n] 时的类型, 则 proto::is_callable<T>::value 为 boost::is_same<Yn, proto::callable>::value.

  • 如果 T 派生自 proto::callable, 则 proto::is_callable<T>::value 为 true.

  • 否则, proto::is_callable<T>::value 为 false.
