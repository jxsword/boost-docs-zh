结构体模板 unexpr

boost::proto::unexpr — 让你继承一个表达式的接口, 同时向 Proto 隐藏该类型是 Proto 表达式这一事实.

概要

// In header: <boost/proto/expr.hpp>

template<typename Expr> 
struct unexpr :  Expr {
  // construct/copy/destruct
  unexpr(Expr const &);
};

说明

对于表达式类型 E, proto::is_expr<E>::value 为 true, 但 proto::is_expr<proto::unexpr<E> >::value 为 false.

unexpr 公有构造/复制/析构

  1. unexpr(Expr const & expr);
