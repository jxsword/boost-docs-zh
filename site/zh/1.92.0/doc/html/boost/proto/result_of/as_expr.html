结构体模板 as_expr

boost::proto::result_of::as_expr — 一个计算 proto::as_expr() 函数返回类型的元函数.

概要

// In header: <boost/proto/traits.hpp>

template<typename T, typename Domain = proto::default_domain> 
struct as_expr {
  // types
  typedef typename Domain::template as_expr< T >::result_type type;
};

说明

proto::result_of::as_expr<> 元函数以特定于域的方式把类型变成 Proto 表达式类型 (如果尚不是) . 它旨在用于计算可保存 proto::as_expr() 函数结果的局部变量类型.

默认行为的完整描述参见 proto::domain::as_expr<>.
