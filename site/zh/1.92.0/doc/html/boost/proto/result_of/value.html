结构体模板 value

boost::proto::result_of::value — 一个返回终结符 Proto 表达式的值类型的元函数.

概要

// In header: <boost/proto/traits.hpp>

template<typename Expr> 
struct value {
  // types
  typedef typename Expr::proto_child0 value_type;
  typedef see-below                   type;      
};

说明

value 公有类型

  1. typedef typename Expr::proto_child0 value_type;

    存储在 Expr 中的值的原始类型. 它可能是一个值或引用.

  2. typedef see-below type;

    如果 Expr 不是引用类型, 则 type 按如下方式计算:

    • T const(&)[N] 变为 T[N]

    • T[N] 变为 T[N]

    • T(&)[N] 变为 T[N]

    • R(&)(A...) 变为 R(&)(A...)

    • T const & 变为 T

    • T & 变为 T

    • T 变为 T

    如果 Expr 是非 const 引用类型, 则 type 按如下方式计算:

    • T const(&)[N] 变为 T const(&)[N]

    • T[N] 变为 T(&)[N]

    • T(&)[N] 变为 T(&)[N]

    • R(&)(A...) 变为 R(&)(A...)

    • T const & 变为 T const &

    • T & 变为 T &

    • T 变为 T &

    如果 Expr 是 const 引用类型, 则 type 按如下方式计算:

    • T const(&)[N] 变为 T const(&)[N]

    • T[N] 变为 T const(&)[N]

    • T(&)[N] 变为 T(&)[N]

    • R(&)(A...) 变为 R(&)(A...)

    • T const & 变为 T const &

    • T & 变为 T &

    • T 变为 T const &
