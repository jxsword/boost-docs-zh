结构体模板 make_expr<Tag, Domain, A...>

boost::proto::result_of::make_expr<Tag, Domain, A...> — 在指定域内计算 proto::make_expr() 函数返回类型的元函数.

概要

// In header: <boost/proto/make_expr.hpp>

template<typename Tag, typename Domain, typename... A> 
struct make_expr<Tag, Domain, A...> {
  // types
  typedef see-below type;
};

说明

计算 proto::make_expr() 函数的返回类型.

make_expr 公有类型

  1. typedef 见-下文 type;

    令 WRAP<X> 定义如下:

    • 如果 X 为 Y & 或 (可能带 cv 限定的) boost::reference_wrapper<Y>, 则 WRAP<X> 等价于 proto::result_of::as_child<Y, Domain>.

    • 否则, WRAP<X> 等价于 proto::result_of::as_expr<X, Domain>.

    如果 proto::wants_basic_expr<typename Domain::proto_generator>::value 为 true, 则令 E 为 proto::basic_expr; 否则令 E 为 proto::expr.

    如果 Tag 为 proto::tag::terminal, 则 type 是 typename WRAP<A0>::type 的 typedef.

    否则, type 是 boost::result_of<Domain(E< Tag, proto::listN< typename WRAP<A>::type...> >)>::type 的 typedef
