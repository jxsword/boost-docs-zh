结构体模板 child_c

boost::proto::result_of::child_c — 一个返回 Proto 表达式第 Nth 个子节点类型的元函数.

概要

// In header: <boost/proto/traits.hpp>

template<typename Expr, long N> 
struct child_c {
  // types
  typedef typename Expr::proto_child0 value_type;
  typedef see-below                   type;      
};

说明

一个返回 Proto 表达式第 Nth 个子节点类型的元函数. N 必须为 0 或小于 Expr::proto_arity::value.

child_c 公有类型

  1. typedef typename Expr::proto_child0 value_type;

    第 Nth 个子节点在 Expr 中的存储原始类型. 它可能是一个值或引用.

  2. typedef see-below type;

    如果 Expr 不是引用类型, 则 type 按如下方式计算:

    • T const & 变为 T

    • T & 变为 T

    • T 变为 T

    如果 Expr 是非 const 引用类型, 则 type 按如下方式计算:

    • T const & 变为 T const &

    • T & 变为 T &

    • T 变为 T &

    如果 Expr 是 const 引用类型, 则 type 按如下方式计算:

    • T const & 变为 T const &

    • T & 变为 T &

    • T 变为 T const &
