结构体模板 compose_generators

boost::proto::compose_generators — 一个复合生成器, 先对一个表达式应用一个变换, 然后把结果转发给另一个生成器作进一步变换.

概要

// In header: <boost/proto/generate.hpp>

template<typename First, typename Second> 
struct compose_generators :  proto::callable {
  // member classes/structs/unions
  template<typename This, typename Expr> 
  struct result<This(Expr)> :  
    boost::result_of<
      Second(typename boost::result_of<First(Expr)>::type)
    >
  {
  };

  // public member functions
  template<typename Expr> 
    typename boost::result_of<
      Second(typename boost::result_of<First(Expr)>::type)
    >::type 
    operator()(Expr const &) const;
};

说明

生成器旨在用作 proto::domain<> 类模板的第一个模板参数, 控制该域内的表达式是否以及如何被定制. proto::compose_generators<> 是一个复合生成器, 先对一个表达式应用一个变换, 然后把结果转发给另一个生成器作进一步变换.

compose_generators 公有成员函数

  1. template<typename Expr> 
  typename boost::result_of<
      Second(typename boost::result_of<First(Expr)>::type)
    >::type 
  operator()(Expr const & expr) const;

    参数:

    expr

    一个 Proto 表达式.

    返回:

    Second()(First()(expr))
