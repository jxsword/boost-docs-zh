结构体模板 when<Grammar, proto::external_transform>

boost::proto::when<Grammar, > — 一个把外部指定的变换与文法关联起来的文法元素. 该变换在 Data 参数中以该文法为键进行查找.

概要

// In header: <boost/proto/transform/when.hpp>

template<typename Grammar> 
struct when<Grammar, proto::external_transform> :
   
  proto::transform< when<Grammar, proto::external_transform> >
{
  // types
  typedef typename Grammar::proto_grammar proto_grammar;

  // member classes/structs/unions
  template<typename Expr, typename State, typename Data> 
  struct impl :  
    boost::remove_reference< 
      typename mpl::eval_if_c<
        proto::result_of::has_env_var<Data, proto::transforms_type>::value,
        proto::result_of::env_var<Data, proto::transforms_type>,
        proto::result_of::env_var<Data, proto::data_type>
      >::type
    >::type
      ::template when< Grammar >
        ::template impl< Expr, State, Data >
  {
  };
};

说明

使用 proto::when<> 以自定义变换覆盖文法的默认变换. 它用于通过把较小的变换关联到文法中的单个规则来组合更大的变换.

when<G, proto::external_transform> 表示相关联的变换尚不确定. 应在该变换即将被应用时进行查找. 它通过在传入的 Data 参数中查找得到, 该参数表现得像一个从文法类型到变换类型的编译期映射. 该映射以 Grammar 为键进行索引. 关联的值类型被用作要应用的变换. 这样, 同一个文法可以用来定义多种求值策略, 这些策略可以事后添加.

示例参见 proto::external_transforms.
