结构体模板 when<Grammar, R(A..., ...)>

boost::proto::when<Grammar, R(A..., ...)> — 一个把变换与文法关联起来的文法元素和 Transform.

概要

// In header: <boost/proto/transform/when.hpp>

template<typename Grammar, typename R, typename... A> 
struct when<Grammar, R(A..., ...)> :  proto::transform< when<Grammar, R(A..., ...)> > {
  // types
  typedef typename Grammar::proto_grammar proto_grammar;

  // member classes/structs/unions
  template<typename Expr, typename State, typename Data> 
  struct impl :  proto::transform_impl< Expr, State, Data > {
    // types
    typedef proto::call<R(A..., ...)>                                  call_;        // For exposition only
    typedef proto::make<R(A..., ...)>                                  make_;        // For exposition only
    typedef typename mpl::if_<proto::is_callable<R>,call_,make_>::type which;        // For exposition only
    typedef typename boost::result_of<which(Expr, State, Data)>::type  result_type;

    // public member functions
    result_type operator()(typename impl::expr_param, 
                           typename impl::state_param, 
                           typename impl::data_param) const;
  };
};

说明

使用 proto::when<> 以自定义变换覆盖文法的默认变换. 它用于通过把较小的变换关联到文法中的单个规则来组合更大的变换.

when<G, R(A..., ...)> 形式接受 CallableTransform 或 ObjectTransform 作为其第二个参数. proto::when<> 使用 proto::is_callable<R>::value 来区分两者, 并使用 proto::call<> 对 CallableTransform 求值, 用 proto::make<> 对 ObjectTransform 求值.

注: 在特化 when<G, R(A..., ...)> 中, 第一个省略号表示 C++11 风格的变参模板 (对 C++98 编译器进行了模拟) . 第二个省略号是 C 风格变参.
