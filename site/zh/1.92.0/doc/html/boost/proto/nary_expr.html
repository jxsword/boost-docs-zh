结构体模板 nary_expr

boost::proto::nary_expr — 一个用于生成带指定标签类型的 n 元表达式类型的元函数, 一个用于匹配 n 元表达式的文法元素, 以及一个 PrimitiveTransform, 其分派到 proto::pass_through<> 变换.

概要

// In header: <boost/proto/traits.hpp>

template<typename Tag, typename... A> 
struct nary_expr :  proto::transform< nary_expr<Tag, A...> > {
  // types
  typedef proto::expr< Tag, proto::listN< A... > >       type;         
  typedef proto::basic_expr< Tag, proto::listN< A... > > proto_grammar;

  // member classes/structs/unions
  template<typename Expr, typename State, typename Data> 
  struct impl :
     proto::pass_through<nary_expr>::template impl<Expr, State, Data>
  {
  };
};

说明

使用 proto::nary_expr<proto::_, proto::vararg<proto::_> > 作为文法元素来匹配任何 n 元表达式; 即任何非终结符.
