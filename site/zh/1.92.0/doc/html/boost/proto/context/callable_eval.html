结构体模板 callable_eval

boost::proto::context::callable_eval — 一个二元函数 (BinaryFunction) , 接受一个 Proto 表达式和一个可调用上下文, 并以表达式的标签和子节点作为实参调用该上下文, 实际上就是把表达式扇出.

概要

// In header: <boost/proto/context/callable.hpp>

template<typename Expr, typename Context> 
struct callable_eval {
  // types
  typedef typename boost::result_of<
    Context(
      typename Expr::proto_tag,
      typename proto::result_of::child_c<0>::type,
      ...
      typename proto::result_of::child_c<N>::type,
    )>::type
   result_type;

  // public member functions
  result_type operator()(Expr &, Context &) const;
};

说明

proto::context::callable_eval<> 要求 Context 是一个 PolymorphicFunctionObject, 能以 Expr 的标签和子节点作为表达式来调用, 如下所示:

context(typename Expr::proto_tag(), proto::child_c<0>(expr), ... proto::child_c<N>(expr))

callable_eval 公有成员函数

  1. result_type operator()(Expr & expr, Context & context) const;

    参数:

    expr

    当前表达式

    context

    可调用求值上下文

    返回:

    context(typename Expr::proto_tag(), proto::child_c<0>(expr),... proto::child_c<N>(expr))
