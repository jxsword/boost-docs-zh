结构体 data_type

boost::proto::data_type — proto::data 的类型, 它是创建变换环境时的一个键, 用于把一段数据与该类型关联.

概要

// In header: <boost/proto/transform/env.hpp>


struct data_type {

  // public member functions
  template<typename Value> env<data_type, see-below> operator=(Value &) const;
  template<typename Value> 
    env<data_type, see-below> operator=(Value const &) const;
};

说明

proto::data_type 类型连同 proto::data 全局变量一起, 使用 BOOST_PROTO_DEFINE_ENV_VAR() 宏来声明.

data_type 公有成员函数

  1. template<typename Value> 
  env<data_type, see-below> operator=(Value & value) const;
template<typename Value> 
  env<data_type, see-below> operator=(Value const & value) const;

    如果 Value 是特化 boost::reference_wrapper<T>, 该函数返回 env<data_type, T &>(value.get()).

    否则, 如果类型 Value 不可复制 (即函数、数组、抽象类型或 ostream) , 该函数返回 env<data_type, Value cv &>(value), 其中 cv 对于第二个重载为 const, 对于第一个为空.

    否则, 该函数返回 env<data_type, Value>(value).
