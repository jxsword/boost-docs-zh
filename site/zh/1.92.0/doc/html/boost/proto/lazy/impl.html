结构体模板 impl

boost::proto::lazy::impl

概要

// In header: <boost/proto/transform/lazy.hpp>


template<typename Expr, typename State, typename Data> 
struct impl :  proto::transform_impl<Expr, State, Data> {
  // types
  typedef see-below result_type;

  // public member functions
  result_type operator()(typename impl::expr_param, 
                         typename impl::state_param, 
                         typename impl::data_param) const;
};

说明

impl 公有类型

  1. typedef see-below result_type;

    proto::lazy<T>::impl<Expr,State,Data>::result_type 按如下方式计算:

    • 如果 T 形如 O(A0,…An), 则令 O' 为 boost::result_of<proto::make<O>(Expr, State, Data)>::type, 并令 T' 为 O'(A0,…An).

    • 如果 T 形如 O(A0,…An ...), 则令 O' 为 boost::result_of<proto::make<O>(Expr, State, Data)>::type, 并令 T' 为 O'(A0,…An ...).

    • 否则, 令 T' 为 boost::result_of<proto::make<T>(Expr, State, Data)>::type.

    结果类型为 boost::result_of<proto::call<T'>(Expr, State, Data)>::type .

impl 公有成员函数

  1. result_type operator()(typename impl::expr_param expr, 
                       typename impl::state_param state, 
                       typename impl::data_param data) const;

    proto::lazy<T>::impl<Expr,State,Data>::operator() 的行为如下:

    • 如果 T 形如 O(A0,…An), 则令 O' 为 boost::result_of<proto::make<O>(Expr, State, Data)>::type, 并令 T' 为 O'(A0,…An).

    • 如果 T 形如 O(A0,…An ...), 则令 O' 为 boost::result_of<proto::make<O>(Expr, State, Data)>::type, 并令 T' 为 O'(A0,…An ...).

    • 否则, 令 T' 为 boost::result_of<proto::make<T>(Expr, State, Data)>::type.

    返回:

    proto::call<T'>()(expr, state, data)
