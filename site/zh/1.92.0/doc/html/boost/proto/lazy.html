结构体模板 lazy

boost::proto::lazy — 一种 PrimitiveTransform, 它使用 proto::make<> 构建一个 CallableTransform, 然后用 proto::call<> 来应用它.

概要

// In header: <boost/proto/transform/lazy.hpp>

template<typename T> 
struct lazy :  proto::transform< lazy<T> > {
  // member classes/structs/unions
  template<typename Expr, typename State, typename Data> 
  struct impl :  proto::transform_impl<Expr, State, Data> {
    // types
    typedef see-below result_type;

    // public member functions
    result_type operator()(typename impl::expr_param, 
                           typename impl::state_param, 
                           typename impl::data_param) const;
  };
};

说明

当要应用的变换依赖于变换的当前状态时, proto::lazy<> 作为高阶变换很有用. proto::make<> 变换的调用会求值所有嵌套变换, 所得类型被当作一个 CallableTransform, 并用 proto::call<> 求值.

关于 proto::lazy<> 变换行为的完整描述, 参见嵌套类模板 proto::lazy::impl<> 的文档.
