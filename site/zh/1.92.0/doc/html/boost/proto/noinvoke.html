结构体模板 noinvoke

boost::proto::noinvoke — ObjectTransform 中的一个类型标注, 指示 Proto 在类型替换之后不要查找 ::type (嵌套于 T 中的) .

概要

// In header: <boost/proto/transform/make.hpp>

template<typename T> 
struct noinvoke {
};

说明

ObjectTransform 由 proto::make<> 求值, 它找出所有嵌套变换并用其应用结果替换它们. 如果执行了任何替换, 则首先假定结果是一个要应用的元函数; 也就是说, Proto 检查结果是否有嵌套的 ::type typedef. 如果有, 它就成为结果. proto::noinvoke<> 的目的就是防止 Proto 在这些情况下查找嵌套的 ::type typedef.

示例:

struct Test
  : proto::when<
        _
      , proto::noinvoke<
            // This remove_pointer invocation is bloked by noinvoke
            boost::remove_pointer<
                // This add_pointer invocation is *not* blocked by noinvoke
                boost::add_pointer<_>
            >
        >()
    >
{};

void test_noinvoke()
{
    typedef proto::terminal<int>::type Int;
    
    BOOST_MPL_ASSERT((
        boost::is_same<
            boost::result_of<Test(Int)>::type
          , boost::remove_pointer<Int *>
        >
    ));
    
    Int i = {42};
    boost::remove_pointer<Int *> t = Test()(i);
}
