结构体模板 listN

boost::proto::listN — proto::list1<>、proto::list2<> 等是类型序列, 用作如下类模板的第 2nd 参数: proto::expr<> 或 proto::basic_expr<>.

概要

// In header: <boost/proto/args.hpp>

template<typename... Arg> 
struct listN {
  // types
  typedef ArgM childM;  // For each M in [0,N)

  // public data members
  static const long arity;  // = N;
};

说明

类型序列, 用作如下类模板的第 2nd 参数: proto::expr<> 或 proto::basic_expr<>. 序列中的类型对应于表达式树中某个节点的各子节点. 并没有一个字面命名为"listN"的类型; 而是有一组名为 proto::list1<>、proto::list2<> 等的类型.
