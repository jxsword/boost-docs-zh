结构体模板 reverse_fold

boost::proto::reverse_fold — 一种 PrimitiveTransform, 与 proto::fold<> 变换相同, 只是它从后向前折叠而不是从前向后. 它使用 proto::_reverse 可调用 PolymorphicFunctionObject 创建序列的一个 fusion::reverse_view<>, 然后再调用 fusion::fold<>.

概要

// In header: <boost/proto/transform/fold.hpp>

template<typename Sequence, typename State0, typename Fun> 
struct reverse_fold :  proto::fold< proto::_reverse(Sequence), State0, Fun > {
};
