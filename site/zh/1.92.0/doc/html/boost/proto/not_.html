结构体模板 not_

boost::proto::not_ — 反转某个文法所匹配的表达式集合. 当用作变换时, proto::not_<> 原样返回当前表达式.

概要

// In header: <boost/proto/matches.hpp>

template<typename Grammar> 
struct not_ :  proto::transform<not_<Grammar> > {
  // types
  typedef not_ proto_grammar;

  // member classes/structs/unions
  template<typename Expr, typename State, typename Data> 
  struct impl :  proto::transform_impl<Expr, State, Data> {
    // types
    typedef Expr result_type;

    // public member functions
    Expr operator()(typename impl::expr_param, typename impl::state_param, 
                    typename impl::data_param) const;
  };
};

说明

如果表达式类型 E 不匹配文法 G, 则 E 确实 匹配 proto::not_<G>. 例如, proto::not_<proto::terminal<proto::_> > 将匹配任何非终结符.
