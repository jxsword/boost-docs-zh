结构体模板 switch_

boost::proto::switch_ — 用于匹配一组备选文法之一, 这些文法根据作为第二个模板参数传入的变换的结果类型进行查找. 如果未传入变换, 默认为 proto::tag_of<proto::_>(), 因此默认匹配基于表达式的标签类型. 当用作变换时, proto::switch_<> 应用与匹配该表达式的子文法相关联的变换.

概要

// In header: <boost/proto/matches.hpp>

template<typename Cases, typename Transform> 
struct switch_ :  proto::transform<switch_<Cases, Transform> > {
  // types
  typedef switch_ proto_grammar;

  // member classes/structs/unions
  template<typename Expr, typename State, typename Data> 
  struct impl :  
    Cases::template case_<
      typename when<_, Transform>::template impl<Expr, State, Data>::result_type 
    >::template impl<Expr, State, Data>
  {
  };
};

说明

表达式类型 E 匹配 proto::switch_<C,T>, 如果 E 匹配 C::case_<boost::result_of<proto::when<proto::_,T>(E)>::type>.

把 proto::switch_<C,T> 作为变换应用于表达式 e (类型为 E) 、状态 s (类型为 S) 和数据 d (类型为 D) 时, 等价于 C::case_<boost::result_of<proto::when<proto::_,T>(E,S,D)>::type>()(e, s, d).
