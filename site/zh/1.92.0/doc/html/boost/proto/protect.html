结构体模板 protect

boost::proto::protect — 一种防止另一个 PrimitiveTransform 在 ObjectTransform 中被应用的 PrimitiveTransform.

概要

// In header: <boost/proto/transform/make.hpp>

template<typename PrimitiveTransform> 
struct protect :  proto::transform< protect<PrimitiveTransform> > {
  // member classes/structs/unions
  template<typename, typename, typename> 
  struct impl {
    // types
    typedef PrimitiveTransform result_type;
  };
};

说明

在用 proto::make<> 或 proto::lazy<> 构建高阶变换时, 有时你希望构建以 Proto 变换为参数的类型. 在这类 lambda 风格的变换中, Proto 会不合时宜地找出所有嵌套变换并应用它们, 即使你并不想应用它们. 考虑下面这个变换, 它会把 proto::_ 在 Bar<proto::_>() 中的出现替换为 proto::terminal<int>::type:

template<typename T>
struct Bar
{};

struct Foo :
  proto::when<proto::_, Bar<proto::_>() >
{};

proto::terminal<int>::type i = {0};

int main() {
  Foo()(i);
  std::cout << typeid(Foo()(i)).name() << std::endl;
}

如果你确实想默认构造一个类型为 Bar<proto::_> 的对象, 就必须保护 _ 以免它被应用. 可以如下使用 proto::protect<>:

// OK: replace anything with Bar<_>()
struct Foo :
  proto::when<proto::_, Bar<proto::protect<proto::_> >() >
{};
