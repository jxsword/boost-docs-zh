结构体模板 convertible_to

boost::proto::convertible_to — 用于匹配可转换为某类型的终结符.

概要

// In header: <boost/proto/matches.hpp>

template<typename T> 
struct convertible_to {
};

说明

使用 proto::convertible_to<> 来匹配可转换为某个类型的终结符. 例如, 文法 proto::terminal<proto::convertible_to<int> > 会匹配任何实参可转换为整数的终结符.
