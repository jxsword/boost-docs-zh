结构体模板 domain

boost::proto::domain — 用于定义配合 proto::extends<>、BOOST_PROTO_EXTENDS() 和 BOOST_PROTO_DEFINE_OPERATORS() 使用的域标签. 一个 域 把表达式类型与一个 生成器 以及可选的一个 文法 关联起来. 它还可以有一个超域. 子域中的表达式与超域中的表达式可互操作 (即可以自由组合) . 最后, 域控制非 Proto 对象如何变成 Proto 表达式, 以及它们如何组合形成更大的 Proto 表达式.

概要

// In header: <boost/proto/domain.hpp>

template<typename Generator = proto::default_generator, 
         typename Grammar = proto::_, typename Super = unspecified> 
struct domain :  Generator {
  // types
  typedef Grammar   proto_grammar;     
  typedef Generator proto_generator;   
  typedef Super     proto_super_domain;

  // member classes/structs/unions

  // A callable unary MonomorphicFunctionObject that specifies how objects are
  // turned into Proto expressions in this domain. The resulting expression
  // object is suitable for storage in a local variable.
  template<typename T> 
  struct as_expr :  proto::callable {
    // types
    typedef see-below result_type;

    // public member functions
    result_type operator()(T &) const;
  };

  // A callable unary MonomorphicFunctionObject that specifies how objects are
  // turned into Proto expressions in this domain, for use in scenarios where
  // the resulting expression is intended to be made a child of another
  // expression.
  template<typename T> 
  struct as_child :  proto::callable {
    // types
    typedef see-below result_type;

    // public member functions
    result_type operator()(T &) const;
  };
};

说明

Generator 参数决定域内新表达式如何做后处理. 通常, 生成器把所有新表达式包装进一个包装器, 为域内的表达式赋予特定于域的行为. (参见 proto::extends<>. )

Grammar 参数决定给定的表达式在域内是否有效, 并自动禁用任何会导致创建无效表达式的运算符重载. 默认情况下, Grammar 参数默认为通配符 proto::_ , 这使得所有表达式在域内都有效.

Super 参数声明当前定义的域是 Super 的子域. 子域中的表达式可以与其超域 (以及 该超域 的超域, 等等) 中的表达式自由组合.

示例:

 template<typename Expr>
 struct MyExpr;

 struct MyGrammar
   : proto::or_< proto::terminal<_>, proto::plus<MyGrammar, MyGrammar> >
 {};

 // Define MyDomain, in which all expressions are
 // wrapped in MyExpr<> and only expressions that
 // conform to MyGrammar are allowed.
 struct MyDomain
   : proto::domain<proto::generator<MyExpr>, MyGrammar>
 {};

 // Use MyDomain to define MyExpr
 template<typename Expr>
 struct MyExpr
   : proto::extends<Expr, MyExpr<Expr>, MyDomain>
 {
     // ...
 };

domain::as_expr<> 和 domain::as_child<> 成员模板定义了非 Proto 对象如何变成 Proto 终结符, 以及 Proto 表达式在组合形成更大表达式之前应如何处理. 可以在派生域中重写它们以进行定制. 参见它们的说明, 以了解 Proto 如何使用这两个模板以及它们的默认行为.
