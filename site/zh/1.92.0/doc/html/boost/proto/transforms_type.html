结构体 transforms_type

boost::proto::transforms_type — 用于定义全局 proto::transforms 的类型, 它是一个键, 用于在变换环境中为外部变换集合创建和访问槽位.

概要

// In header: <boost/proto/transform/when.hpp>


struct transforms_type {

  // public member functions
  template<typename Value> 
    env<transforms_type, see-below> operator=(Value &) const;
  template<typename Value> 
    env<transforms_type, see-below> operator=(Value const &) const;
};

说明

proto::transforms_type 类型连同 proto::transforms 全局变量一起, 使用 BOOST_PROTO_DEFINE_ENV_VAR() 宏来声明.

transforms_type 公有成员函数

  1. template<typename Value> 
  env<transforms_type, see-below> operator=(Value & value) const;
template<typename Value> 
  env<transforms_type, see-below> operator=(Value const & value) const;

    如果 Value 是特化 boost::reference_wrapper<T>, 该函数返回 env<transforms_type, T &>(value.get()).

    否则, 如果类型 Value 不可复制 (即函数、数组、抽象类型或 ostream) , 该函数返回 env<transforms_type, Value cv &>(value), 其中 cv 对于第二个重载为 const, 对于第一个为空.

    否则, 该函数返回 env<transforms_type, Value>(value).
