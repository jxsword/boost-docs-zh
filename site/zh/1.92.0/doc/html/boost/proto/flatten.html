函数 flatten

boost::proto::flatten — 一个返回 Proto 表达式树"扁平化"视图的函数.

概要

// In header: <boost/proto/fusion.hpp>


template<typename Expr> 
  typename proto::result_of::flatten< Expr >::type const flatten(Expr & expr);
template<typename Expr> 
  typename proto::result_of::flatten< Expr const >::type const 
  flatten(Expr const & expr);

说明

对于最顶层节点标签类型为 T 的树, 扁平化序列的元素通过递归进入每个具有相同标签类型的子节点并返回那些不同类型的节点来确定. 例如, 对应于表达式 a | b | c 的 Proto 表达式树具有元素为 [a, b, c] 的扁平化视图, 尽管该树被分组为 ((a | b) | c).

返回的视图是一个 Fusion 前向序列 (Forward Sequence) .
