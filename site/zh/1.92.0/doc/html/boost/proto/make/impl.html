结构体模板 impl

boost::proto::make::impl

概要

// In header: <boost/proto/transform/make.hpp>


template<typename Expr, typename State, typename Data> 
struct impl :  proto::transform_impl< Expr, State, Data > {
  // types
  typedef see-below result_type;

  // public member functions
  result_type operator()(typename impl::expr_param, 
                         typename impl::state_param, 
                         typename impl::data_param) const;
};

说明

impl 公有类型

  1. typedef 见-下文 result_type;

    proto::make<T>::impl<Expr, State, Data>::result_type 按如下方式计算:

    如果 T 是一个 ObjectTransform, 形如 Object(A0,…An) 或 Object(A0,…An ...), 则令 O 为返回类型 Object. 否则, 令 O 为 T. 然后按如下方式计算 result_type typedef:

    • 如果 proto::is_transform<O>::value 为 true, 则令结果类型为 boost::result_of<proto::when<_, O>(Expr, State, Data)>::type . 注意发生了一次替换.

    • 如果 O 是形如 proto::noinvoke<S<X0,…Xn> > 的模板, 则结果类型按如下方式计算:

      • 对于每个 i (位于 [0,n] 中) , 令 Xi' 为 boost::result_of<proto::make<Xi>(Expr, State, Data)>::type (它递归地求值此过程) . 注意发生了一次替换. (在此情况下, 出于编译期效率的考虑, Proto 只是假定发生了一次替换. 否则就没有理由使用 proto::noinvoke<> 了. )

      • 结果类型为 S<X0',…Xn'> .

    • 如果 O 是形如 S<X0,…Xn> 的模板, 则结果类型按如下方式计算:

      • 对于每个 i (位于 [0,n] 中) , 令 Xi' 为 boost::result_of<proto::make<Xi>(Expr, State, Data)>::type (它递归地求值此过程) . 注意在此操作期间是否发生了任何替换.

      • 如果在上一步中发生了任何替换, 且 S<X0',…Xn'> 有一个嵌套的 type typedef, 则结果类型为 S<X0',…Xn'>::type .

      • 否则, 结果类型为 S<X0',…Xn'> .

    • 否则, 结果类型为 O, 并且注意没有发生任何替换.

    注意 proto::when<> 是以 proto::call<> 和 proto::make<> 为基础实现的, 因此上述过程会被递归求值.

impl 公有成员函数

  1. result_type operator()(typename impl::expr_param expr, 
                       typename impl::state_param state, 
                       typename impl::data_param data) const;

    proto::make<T>::impl<Expr,State,Data>::operator() 的行为如下:

    • 如果 T 形如 O(A0,…An), 则:

      • 如果 proto::is_aggregate<result_type>::value 为 true, 则按如下方式构造并返回一个对象 that:

        result_type that = {
  proto::when<_, A0>()(expr, state, data),
  …
  proto::when<_, An>()(expr, state, data)
};

      • 否则, 按如下方式构造并返回一个对象 that:

        result_type that(
  proto::when<_, A0>()(expr, state, data),
  …
  proto::when<_, An>()(expr, state, data)
);

    • 如果 T 形如 O(A0,…An ...), 则令 T' 为 O(A0,…An-1, S), 其中 S 是一个类型序列, 由解包表达式 An 计算而得, 计算方式如 proto::pack 的参考文档所述. 然后, 返回:

      proto::make<T'>()(expr, state, data)

    • 否则, 按如下方式构造并返回一个对象 that:

      result_type that = result_type();
