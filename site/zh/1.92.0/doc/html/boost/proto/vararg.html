结构体模板 vararg

boost::proto::vararg — 用于把文法匹配到可变数量的子表达式.

概要

// In header: <boost/proto/matches.hpp>

template<typename Grammar> 
struct vararg {
};

说明

表达式类型 proto::basic_expr<AT, proto::listN<A0,...An,U0,...Um> > 匹配文法 proto::basic_expr<BT, proto::listM<B0,...Bn,proto::vararg<V> > >, 如果 BT 为 proto::_ 或 AT, 且 Ax 匹配 Bx, 对每个 x (取自 [0,n]) , 且 Ux 匹配 V, 对每个 x (取自 [0,m]) .

例如:

// Match any function call expression, regardless
// of the number of function arguments:
struct Function :
  proto::function< proto::vararg<proto::_> >
{};

当用作变换时, proto::vararg<G> 应用 G 的变换.
