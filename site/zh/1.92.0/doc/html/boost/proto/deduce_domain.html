结构体 deduce_domain

boost::proto::deduce_domain — 一个伪域, 用于需要域参数的函数和元函数. 它表示父节点的域应当从各子节点的域推断得出.

概要

// In header: <boost/proto/domain.hpp>


struct deduce_domain {
};

说明

当 proto::deduce_domain 被用作域时——无论是显式使用, 还是由 proto::make_expr()、proto::unpack_expr() 或 Proto 的运算符重载隐式使用——Proto 将使用各子表达式的域来计算父节点的域. 其做法满足:(A) 共享同一公共超域的各域中的表达式可以互操作;(B) 位于默认域 (或其子域) 中的表达式可与 所有 表达式互操作. 规则如下:

  • 子域比其超域 更强.
  • proto::default_domain、proto::basic_default_domain 及其所有子域都比所有其他域 更弱.
  • proto::basic_default_domain 比 proto::default_domain 更弱.
  • 对每个子节点, 定义一个域集合 SN, 包含该子节点的域及其所有超域.
  • 定义集合 IS, 它是各单独集合 SN (不含 proto::default_domain 或 proto::basic_default_domain 者) 的交集.
  • 定义集合 IW, 它是各单独集合 SN (含 proto::default_domain 或 proto::basic_default_domain 者) 的交集.
  • 定义集合 P, 它是 IS 与 IW 的并集.
  • 公共域是集合 P 中最强的域, 但有下列注意事项.
  • 设 U 为所有集合 SN 的并集. 如果结果为 proto::default_domain 或 proto::basic_default_domain, 且 U 含有一个 并非 proto::default_domain 或 proto::basic_default_domain 的元素, 则是一个错误.

注: 上面的描述听起来在编译期计算开销会很大. 实际上, 这一切都可以用 C++ 函数重载来完成.
