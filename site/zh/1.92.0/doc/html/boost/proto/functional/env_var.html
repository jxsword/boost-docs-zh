结构体模板 env_var

boost::proto::functional::env_var — 一个用于取回变换环境中与特定键关联的值的一元 PolymorphicFunctionObject.

概要

// In header: <boost/proto/transform/env.hpp>

template<typename Key> 
struct env_var :  proto::callable {
  // member classes/structs/unions
  template<typename Sig> 
  struct result {
    // types
    typedef see-below type;
  };

  // public member functions
  template<typename Env> see-below operator()(Env const &) const;
};

说明

env_var 公有成员函数

  1. template<typename Env> see-below operator()(Env const & e) const;

    该函数的行为如下:

    • 如果 Key 为 proto::data_type:
      • 如果 proto::is_env<Env>::value 为 true, 返回 e[proto::data].
      • 否则, 返回 e.
    • 否则, 返回 e[Key()].

    更多信息参见 proto::env::operator[].
