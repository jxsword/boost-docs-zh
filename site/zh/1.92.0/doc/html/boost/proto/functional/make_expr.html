结构体模板 make_expr

boost::proto::functional::make_expr — 一个 PolymorphicFunctionObject, 等价于 proto::make_expr() 函数.

概要

// In header: <boost/proto/make_expr.hpp>

template<typename Tag, typename Domain = proto::deduce_domain> 
struct make_expr :  proto::callable {
  // member classes/structs/unions
  template<typename This, typename... A> 
  struct result<This(A...)> :  
    proto::result_of::make_expr< Tag, Domain, A... > {
  };

  // public member functions
  template<typename... A> 
    typename proto::result_of::make_expr< Tag, Domain, A const... >::type const 
    operator()(A const &...) const;
};

说明

在所有情况下, proto::functional::make_expr<Tag, Domain>()(a...) 等价于 proto::make_expr<Tag, Domain>(a...).

proto::functional::make_expr<Tag>()(a...) 等价于 proto::make_expr<Tag>(a...).

make_expr 公有成员函数

  1. template<typename... A> 
  typename proto::result_of::make_expr< Tag, Domain, A const... >::type const 
  operator()(A const &... a) const;

    构造一个标签类型为 Tag 且位于域 Domain 中的表达式节点.

    返回:

    proto::make_expr<Tag, Domain>(a...)
