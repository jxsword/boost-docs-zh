结构体模板 result

boost::proto::functional::env_var::result

概要

// In header: <boost/proto/transform/env.hpp>


template<typename Sig> 
struct result {
  // types
  typedef see-below type;
};

说明

编码 proto::functional::env_var::operator() 的返回类型. 这个成员模板的存在使 proto::functional::env_var 成为可与 boost::result_of<> 一起使用的有效 TR1 风格函数对象类型.

result 公有类型

  1. typedef see-below type;

    See proto::functional::env_var::operator().
