结构体模板 is_env

boost::proto::is_env — 一个用于判断某类型是否是 Proto 变换环境的布尔元函数.

概要

// In header: <boost/proto/transform/env.hpp>

template<typename T> 
struct is_env :  mpl::bool_<true-or-false> {
};

说明

is_env<T> 在下列条件下继承自 mpl::true_:

  • 如果 T 是 proto::empty_env.
  • 如果 T 是 proto::env<> 的特化.
  • 如果 T 派生自上述任意一项.
  • 如果 T 是上述任意一项的带 cv 限定变体.
  • 如果 T 是对上述任意一项的引用.

否则, is_env<T> 继承自 mpl::false_.
