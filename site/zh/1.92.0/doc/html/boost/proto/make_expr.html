函数 make_expr

boost::proto::make_expr — 构造一个具有所请求标签类型和指定域的表达式, 并以指定实参作为子节点.

概要

// In header: <boost/proto/make_expr.hpp>


template<typename Tag, typename... A> 
  typename proto::result_of::make_expr<Tag, A const...>::type const 
  make_expr(A const &... a);
template<typename Tag, typename Domain, typename... A> 
  typename proto::result_of::make_expr<Tag, Domain, A const...>::type const 
  make_expr(A const &... a);

说明

该函数模板可以在指定或不指定 Domain 模板参数的情况下调用. 如果未指定域, 则通过检查给定实参的域来推断域. 所用过程的完整描述参见 proto::deduce_domain.

令 WRAP(x) 定义如下:

  • 如果 x 是一个 boost::reference_wrapper<>, 则 WRAP(x) 等价于 proto::as_child<Domain>(x.get()).

  • 否则, WRAP(x) 等价于 proto::as_expr<Domain>(x).

如果 proto::wants_basic_expr<typename Domain::proto_generator>::value 为 true, 则令 E 为 proto::basic_expr; 否则令 E 为 proto::expr.

令 MAKE(Tag, b...) 定义为 E<Tag, proto::listN<decltype(b)...> >::make(b...).

如果 Tag 为 proto::tag::terminal, 则返回 WRAP(a0).

否则, 返回 Domain()(MAKE(Tag, WRAP(a)...)).
