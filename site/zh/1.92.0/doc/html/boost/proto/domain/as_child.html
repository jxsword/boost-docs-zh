结构体模板 as_child

boost::proto::domain::as_child — 一个可调用的一元单态函数对象 (MonomorphicFunctionObject) , 规定本域中对象如何变成 Proto 表达式, 用于结果表达式将被作为另一表达式子节点的场景.

概要

// In header: <boost/proto/domain.hpp>



// A callable unary MonomorphicFunctionObject that specifies how objects are
// turned into Proto expressions in this domain, for use in scenarios where
// the resulting expression is intended to be made a child of another
// expression.
template<typename T> 
struct as_child :  proto::callable {
  // types
  typedef see-below result_type;

  // public member functions
  result_type operator()(T &) const;
};

说明

一个一元单态函数对象 (MonomorphicFunctionObject) , 规定本域中对象如何变成 Proto 表达式. 所得表达式对象适合作为另一表达式的子节点存储. 在这种场景下, 通常更倾向于按引用存储子表达式; 或者, 对于尚不是 Proto 表达式的对象, 将其按引用包装进一个新的 Proto 终结符表达式. (与 proto::domain::as_expr 的说明对照. )

as_child 函数对象把对象变成 Proto 表达式 (如果尚不是) , 方式是使其成为按引用持有的 Proto 终结符. 已经是 Proto 表达式的对象则简单地按引用返回. 如果 wants_basic_expr<Generator>::value 为 true, 则令 E 为 proto::basic_expr; 否则令 E 为 proto::expr. 给定左值 t (类型为 T) :

  • 如果 T 不是 Proto 表达式类型, 则所得终结符为 Generator()(E<tag::terminal, term< T & > >::make(t)).
  • 否则, 结果为左值 t.

as_child 公有成员函数

  1. result_type operator()(T & t) const;

    参数:

    t

    要包装的对象.
