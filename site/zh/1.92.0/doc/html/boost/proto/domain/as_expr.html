结构体模板 as_expr

boost::proto::domain::as_expr — 一个可调用的一元单态函数对象 (MonomorphicFunctionObject) , 规定本域中对象如何变成 Proto 表达式. 所得表达式对象适合存储在局部变量中.

概要

// In header: <boost/proto/domain.hpp>



// A callable unary MonomorphicFunctionObject that specifies how objects are
// turned into Proto expressions in this domain. The resulting expression
// object is suitable for storage in a local variable.
template<typename T> 
struct as_expr :  proto::callable {
  // types
  typedef see-below result_type;

  // public member functions
  result_type operator()(T &) const;
};

说明

一个一元单态函数对象 (MonomorphicFunctionObject) , 规定本域中对象如何变成 Proto 表达式. 所得表达式对象适合存储在局部变量中. 在这种场景下, 通常更倾向于按值返回表达式; 或者, 对于尚不是 Proto 表达式的对象, 按值 (如果可能) 将其包装进一个新的 Proto 终结符表达式. (与 proto::domain::as_child 的说明对照. )

as_expr 函数对象把对象变成 Proto 表达式 (如果尚不是) , 方式是在可能的情况下使其成为按值持有的 Proto 终结符. 已经是 Proto 表达式的对象则简单地按值返回. 如果 wants_basic_expr<Generator>::value 为 true, 则令 E 为 proto::basic_expr; 否则令 E 为 proto::expr. 给定左值 t (类型为 T) :

  • 如果 T 不是 Proto 表达式类型, 则所得终结符按如下方式计算:
    • 如果 T 是函数类型、抽象类型或派生自 std::ios_base 的类型, 则令 A 为 T &.
    • 否则, 令 A 为去除了 cv 限定符的类型 T.
    然后, as_expr<T>()(t) 的结果为 Generator()(E<tag::terminal, term< A > >::make(t)).
  • 否则, 结果为转换为 (去 const) 右值的 t.

as_expr 公有成员函数

  1. result_type operator()(T & t) const;

    参数:

    t

    要包装的对象.
