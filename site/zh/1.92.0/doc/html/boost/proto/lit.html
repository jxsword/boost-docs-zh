函数 lit

boost::proto::lit — 一个用于创建 proto::literal<> 包装器的辅助函数.

概要

// In header: <boost/proto/literal.hpp>


template<typename T> proto::literal< T & > const lit(T & t);
template<typename T> proto::literal< T const & > const lit(T const & t);

说明

参数:

t

要包装的对象.

返回:

proto::literal<T &>(t)

抛出:

 不会抛出异常.

注释:

返回的值按引用持有该实参.
