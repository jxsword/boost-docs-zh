结构体模板 generator

boost::proto::generator — 一个把传给它的表达式包装进指定扩展包装器的生成器.

概要

// In header: <boost/proto/generate.hpp>

template<template< typename > class Extends> 
struct generator {
  // member classes/structs/unions
  template<typename This, typename Expr> 
  struct result<This(Expr)> {
    // types
    typedef Extends< Expr > type;
  };

  // public member functions
  template<typename Expr> Extends< Expr > operator()(Expr const &) const;
};

说明

生成器旨在用作 proto::domain<> 类模板的第一个模板参数, 控制该域内的表达式是否以及如何被定制. proto::generator<> 把传给它的每个表达式包装进 Extends<> 包装器.

generator 公有成员函数

  1. template<typename Expr> Extends< Expr > operator()(Expr const & expr) const;

    参数:

    expr

    一个 Proto 表达式

    返回:

    Extends<Expr>(expr)
