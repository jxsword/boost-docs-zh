结构体模板 reverse_fold_tree

boost::proto::reverse_fold_tree — 一种 PrimitiveTransform, 把 proto::reverse_fold<> 变换递归应用到共享同一标签类型的各子树.

概要

// In header: <boost/proto/transform/fold_tree.hpp>

template<typename Sequence, typename State0, typename Fun> 
struct reverse_fold_tree :
   proto::transform< reverse_fold_tree<Sequence, State0, Fun> >
{
  // member classes/structs/unions
  template<typename Expr, typename State, typename Data> 
  struct impl :  
    proto::reverse_fold<Sequence, State0, recurse_if_<typename Expr::proto_tag, Fun> >
      ::template impl<Expr, State, Data>
  {
  };
};

说明

proto::reverse_fold_tree<> 可用于把树扁平化为列表; 例如, 可以用 proto::reverse_fold_tree<> 把形如 a | b | c 的表达式树扁平化成形如 cons(a, cons(b, cons(c))) 的 Fusion 列表.

proto::reverse_fold_tree<> 借助一个如下定义的 recurse_if_<> 辅助工具即可容易理解:

 template<typename Tag, typename Fun>
struct recurse_if_ :
  proto::if_<
    // If the current node has type type "Tag" ...
    boost::is_same<proto::tag_of<proto::_>, Tag>(),
    // ... recurse, otherwise ...
    proto::reverse_fold<proto::_, proto::_state, recurse_if_<Tag, Fun> >,
    // ... apply the Fun transform.
    Fun
  >
{};

在按上文定义了 recurse_if_<> 的情况下, proto::reverse_fold_tree<Sequence, State0, Fun>()(expr, state, data) 等价于:

proto::reverse_fold<
  Sequence,
  State0,
  recurse_if_<typename Expr::proto_tag, Fun>
>()(expr, state, data).

其效果是把一棵树从后向前折叠, 递归进入与父节点共享标签类型的子节点.
