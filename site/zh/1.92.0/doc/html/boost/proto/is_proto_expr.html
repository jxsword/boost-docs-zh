结构体 is_proto_expr

boost::proto::is_proto_expr — 一个空类型, 用作 POD 表达式包装器的哑模板参数. 它允许参数依赖查找找到 Proto 的运算符重载.

概要

// In header: <boost/proto/extends.hpp>


struct is_proto_expr {
};

说明

proto::is_proto_expr 允许参数依赖查找找到 Proto 的运算符重载. 例如:

 template<typename T, typename Dummy = proto::is_proto_expr>
 struct my_terminal
 {
     BOOST_PROTO_BASIC_EXTENDS(
         typename proto::terminal<T>::type
       , my_terminal<T>
       , proto::default_domain
     )
 };

 // ...
 my_terminal<int> _1, _2;
 _1 + _2; // OK, uses proto::operator+

如果没有第二个 Dummy 模板参数, 名字查找将不会考虑 Proto 的运算符重载.
