结构体 pack

boost::proto::pack — 把一个表达式变成一个包含该表达式各子节点的伪参数包, 以便在 CallableTransform 或 ObjectTransform 内展开该参数包表达式.

概要

// In header: <boost/proto/transform/impl.hpp>


struct pack {
};

说明

当希望把一个表达式解包成一次函数调用或一个对象构造时, proto::pack 在 CallableTransform 和 ObjectTransform 中很有用. proto::pack 把一个 Proto 表达式变成一个伪参数包, 它可以出现在解包模式中, 并用 "..." 语法展开.

示例: 

// The following demonstrates how to use a pseudo-pack expansion
// to unpack an expression into a function call.

struct do_sum : proto::callable
{
    typedef int result_type;
    
    int operator()(int i) const { return i; }
    int operator()(int i, int j) const { return i + j; }
    int operator()(int i, int j, int k) const { return i + j + k; }
};

// Take any n-ary expression where the children are all int terminals and sum all the ints
struct sum
  : proto::when<
  
        // Match any nary expression where the children are all int terminals
        proto::nary_expr<_, proto::vararg<proto::terminal<int> > >

        // Turn the current expression into a pseudo-parameter pack, then expand it,
        // extracting the value from each child in turn.
      , do_sum(proto::_value(proto::pack(_))...)
    >
{};

int main()
{
    proto::terminal<int>::type i = {42};
    int result = sum()( i(3,5) ); // Creates a ternary functional-call expression
    std::cout << "Sum of 42, 3, and 5 : " << result << std::endl;
}

上面的程序显示:

Sum of 42, 3, and 5 : 50

在上面的例子中, 类型 proto::_value(proto::pack(_)) 是所谓的 解包模式, 如下文所述.

解包模式:

复合变换 (CallableTransform 或 ObjectTransform) 通常形如 X(A0,…An). 然而, 当复合变换中的实参列表以 C 风格变参省略号结尾 (如 X(A0,…An ...)) 时, 最后一个实参 An 会被当作一个 解包模式.

解包模式本身必须是一个复合变换; 也就是说, 它必须是表示 CallableTransform 或 ObjectTransform 的函数类型. 类型 proto::pack(_) 必须在解包模式中恰好出现一次. 当解包模式被展开时, 该类型将接受一次替换.

形如 X(A0,…An ...) 的复合变换, 在针对给定表达式 E、状态和数据求值时, 求值方式如同它是 X(A0,…An-1,S), 其中 S 是按如下方式计算的类型序列:

令 SUB(A,B) 为一个类型函数, 它把 proto::pack(_) 在 A 中的每处出现替换为 B.

  • 如果表达式 E 是终结符 (即其元数为 0) , 则 S 是包含 SUB(An, proto::_value) 的单元素序列.
  • 如果表达式 E 是非终结符, 则 S 是序列 SUB(An, proto::_child_c<0>),… SUB(An, proto::_child_c<M-1>), 其中 M 是表达式 E 的元数.
