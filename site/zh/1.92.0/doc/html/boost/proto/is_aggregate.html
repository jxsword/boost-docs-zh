结构体模板 is_aggregate

boost::proto::is_aggregate — 一个指示某类型是否需要聚合初始化的布尔元函数.

概要

// In header: <boost/proto/traits.hpp>

template<typename T> 
struct is_aggregate :  mpl::bool_<true-or-false> {
};

说明

proto::is_aggregate<> 被 proto::make<> 变换用来判断如何构造某类型 T 的对象, 给定某些初始化实参 a0,...an. 如果 proto::is_aggregate<T>::value 为 true, 则类型 T 的对象将按 T t = {a0,...an}; 初始化. 否则, 将按 T t(a0,...an) 初始化.

注: proto::expr<> 和 proto::basic_expr<> 是聚合类型.
