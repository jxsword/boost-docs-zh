函数模板 hash_value

boost::hash_value — 为 variant 类型提供哈希支持, 使 boost::hash 可以计算哈希值.

概要

// In header: <boost/variant/variant.hpp>


template<typename T1, typename T2, ..., typename TN> 
  std::size_t hash_value(const variant<T1, T2, ..., TN> & rhs);

说明

要求:

 variant 的每个有界类型都必须满足 Hashable 概念的要求.

效果:

 调用 boost::hash<T>()(x), 其中 x 是 rhs 的内容, T 是其类型.

注释:

 实际上, 该函数定义在 <boost/variant/detail/hash_variant.hpp> 头文件中.
