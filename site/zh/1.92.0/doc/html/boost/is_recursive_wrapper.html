类模板 is_recursive_wrapper

boost::is_recursive_wrapper — 判断指定类型是否为 recursive_wrapper 的特化.

概要

// In header: <boost/variant/recursive_wrapper.hpp>

template<typename T> 
class is_recursive_wrapper {
public:
  // types
  typedef unspecified type;

  // static constants
  static const bool value = unspecified;
};

说明

当且仅当 T 是 recursive_wrapper 的特化时, 值为 true.

注释: is_recursive_wrapper 是 MPL IntegralConstant 概念的一个模型.
