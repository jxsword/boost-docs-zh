类模板 visitor_ptr_t

boost::visitor_ptr_t — 把函数指针适配为静态 visitor 使用.

概要

// In header: <boost/variant/visitor_ptr.hpp>

template<typename T, typename R> 
class visitor_ptr_t : public static_visitor<R> {
public:
  // construct/copy/destruct
  explicit visitor_ptr_t(R (*)(T));

  // static visitor interfaces
  R operator()(unspecified-forwarding-type);
  template<typename U> void operator()(const U&);
};

说明

把构造时给定的函数适配为 静态 visitor 使用, 其类型为 T、结果类型为 R.

visitor_ptr_t 公有构造/复制/析构

  1. explicit visitor_ptr_t(R (*)(T));

    效果:

    		 用给定的函数构造该 visitor.

visitor_ptr_t 静态 visitor 接口

  1. R operator()(unspecified-forwarding-type operand);
template<typename U> void operator()(const U&);

    效果:

    		 如果传入类型为 T 的值或引用, 它会调用构造时给定的函数, 并适当地转发 operand.

    返回:

    		 返回函数调用的结果.

    抛出:

    		 接受类型为 T 的值或引用的重载在被调用函数抛出异常时抛出. 接受所有其他值的重载总是抛出 bad_visit.
