类模板 make_variant_over

boost::make_variant_over — 暴露一个 variant, 其有界类型为给定类型序列的元素.

概要

// In header: <boost/variant/variant.hpp>

template<typename Sequence> 
class make_variant_over {
public:
  // types
  typedef variant< unspecified > type;
};

说明

type 的行为在各方面等价于 variant< Sequence[0], Sequence[1], ... > (其中 Sequence[i] 表示第 i 个 Sequence 元素) , 只是对类型的数量没有施加上限.

注释:

  • Sequence 必须满足 MPL Sequence 概念的要求.
