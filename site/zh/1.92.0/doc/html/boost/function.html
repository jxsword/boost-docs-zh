类模板 function

boost::function — 一种广义的函数指针, 可用于回调或包装函数对象.

概要

// In header: <boost/function.hpp>

template<typename Signature> 
class function : public functionN<R, T1, T2, ..., TN> {
public:
  // types
  typedef R  result_type;         
  typedef T1 argument_type;         // If N == 1
  typedef T1 first_argument_type;   // If N == 2
  typedef T2 second_argument_type;  // If N == 2
  typedef T1 arg1_type;           
  typedef T2 arg2_type;           
     .
     .
     .
  typedef TN argN_type;           

  // static constants
  static const int arity = N;

  // member classes/structs/unions

  // Lambda library support
  template<typename Args> 
  struct sig {
    // types
    typedef result_type type;
  };

  // construct/copy/destruct
  function();
  function(const functionN&);
  function(functionN&&);
  function(const function&);
  function(function&&);
  template<typename F> function(F);
  template<typename F, typename Allocator> function(F, Allocator);
  function& operator=(const functionN&);
  function& operator=(functionN&&);
  function& operator=(const function&);
  function& operator=(function&&);
  ~function();

  // modifiers
  void swap(const function&);
  void clear();

  // capacity
  bool empty() const;
  operator safe_bool() const;
  bool operator!() const;

  // target access
  template<typename Functor> Functor* target();
  template<typename Functor> const Functor* target() const;
  template<typename Functor> bool contains(const Functor&) const;
  const std::type_info& target_type() const;

  // invocation
  result_type operator()(arg1_type, arg2_type, ..., argN_type) const;
};

// specialized algorithms
template<typename Signature> 
  void swap(function<Signature>&, function<Signature>&);

// comparison operators
template<typename Signature, typename Functor> 
  bool operator==(const function<Signature>&, Functor);
template<typename Signature, typename Functor> 
  bool operator==(Functor, const function<Signature>&);
template<typename Signature, typename Functor> 
  bool operator==(const function<Signature>&, reference_wrapper<Functor>);
template<typename Signature, typename Functor> 
  bool operator==(reference_wrapper<Functor>, const function<Signature>&);
template<typename Signature1, typename Signature2> 
  void operator==(const function<Signature1>&, const function<Signature2>&);
template<typename Signature, typename Functor> 
  bool operator!=(const function<Signature>&, Functor);
template<typename Signature, typename Functor> 
  bool operator!=(Functor, const function<Signature>&);
template<typename Signature, typename Functor> 
  bool operator!=(const function<Signature>&, reference_wrapper<Functor>);
template<typename Signature, typename Functor> 
  bool operator!=(reference_wrapper<Functor>, const function<Signature>&);
template<typename Signature1, typename Signature2> 
  void operator!=(const function<Signature1>&, const function<Signature2>&);

说明

类模板 function 是对带编号的类模板 function0、function1 等的薄封装. 它接受一个含 N 个参数的函数类型, 并会用收到的参数实例化 functionN 作为基类.

类模板 function 中所有操作的语义与底层 functionN 对象等价, 不过还需要额外的成员函数才能正确地对函数对象进行复制构造和复制赋值.

模板参数

  1. typename Signature

function 公有构造/复制/析构

  1. function();

    后置条件:

    		 this->empty()

    抛出:

    		 不会抛出异常. 
  2. function(const functionN& f);

    后置条件:

    		 保存 f 的目标的一份副本 (如果它有目标) ; 若 f.empty() 则为空.

    抛出:

    		 除非复制 f 的目标时抛出异常, 否则不会抛出. 
  3. function(functionN&& f);

    要求:

    		 兼容 C++11 的编译器.

    后置条件:

    		 将 f 的值移动到 *this. 如果实参的函数对象分配在堆上, 其缓冲区将被赋给 *this, 实参则变为空.

    抛出:

    		 除非实参的函数对象未分配在堆上且复制 f 的目标时抛出异常, 否则不会抛出. 
  4. function(const function& f);

    后置条件:

    		 保存 f 的目标的一份副本 (如果它有目标) ; 若 f.empty() 则为空.

    抛出:

    		 除非复制 f 的目标时抛出异常, 否则不会抛出. 
  5. function(function&& f);

    要求:

    		 兼容 C++11 的编译器.

    后置条件:

    		 将 f 的值移动到 *this. 如果实参的函数对象分配在堆上, 其缓冲区将被赋给 *this, 实参则变为空.

    抛出:

    		 除非实参的函数对象未分配在堆上且复制 f 的目标时抛出异常, 否则不会抛出. 
  6. template<typename F> function(F f);

    要求:

    		 F 是可从 this 调用 (Callable) 的函数对象.

    后置条件:

    		 *this 指向 f 的一份副本 (当 f 非空时) , 或为 this->empty() (当 f 为空时) . 
  7. template<typename F, typename Allocator> function(F f, Allocator alloc);

    要求:

    		 F 是可从 this 调用 (Callable) 的函数对象, Allocator 是一个分配器. Allocator 的复制构造函数和析构函数不得抛出异常.

    后置条件:

    		 *this 指向 f 的一份副本 (当 f 非空时) , 或为 this->empty() (当 f 为空时) .

    效果:

    		 如果需要内存分配, 将使用给定的分配器 (或其副本) 来分配该内存. 
  8. function& operator=(const functionN& f);

    后置条件:

    		 如果复制构造不抛出异常, *this 指向 f 的目标的一份副本 (如果它有目标) , 或当 f.empty() 时为空. 如果复制构造抛出异常, 则为 this->empty(). 
  9. function& operator=(functionN&& f);

    要求:

    		 兼容 C++11 的编译器.

    后置条件:

    		 将 f 的值移动到 *this. 如果实参的函数对象分配在堆上, 其缓冲区将被赋给 *this, 实参则变为空.

    抛出:

    		 除非实参的函数对象未分配在堆上且复制 f 的目标时抛出异常, 否则不会抛出. 
  10. function& operator=(const function& f);

    后置条件:

    		 如果 f 的目标的复制构造不抛出异常, *this 指向 f 的目标的一份副本 (如果它有目标) , 或当 f.empty() 时为空.

    抛出:

    		 当 f 的目标是无状态函数对象或对该函数对象的引用时不会抛出. 如果复制构造抛出异常, 则为 this->empty(). 
  11. function& operator=(function&& f);

    要求:

    		 兼容 C++11 的编译器.

    后置条件:

    		 将 f 的值移动到 *this. 如果实参的函数对象分配在堆上, 其缓冲区将被赋给 *this, 实参则变为空.

    抛出:

    		 除非实参的函数对象未分配在堆上且复制 f 的目标时抛出异常, 否则不会抛出. 
  12. ~function();

    效果:

    		 如果 !this->empty(), 则销毁 this 的目标.

function 修饰符

  1. void swap(const function& f);

    效果:

    		 交换 *this 与 f 的目标. 
  2. void clear();

    后置条件:

    		 this->empty()

    抛出:

    		 不会抛出异常.

function 容量

  1. bool empty() const;

    返回:

    		 false, 当 this 有目标时; 否则为 true.

    抛出:

    		 不会抛出异常. 
  2. operator safe_bool() const;

    返回:

    		 一个 safe_bool, 在布尔上下文中求值 false (当 this->empty() 时) , 否则为 true.

    抛出:

    		 不会抛出异常. 
  3. bool operator!() const;

    返回:

    		 this->empty()

    抛出:

    		 不会抛出异常.

function 目标访问

  1. template<typename Functor> Functor* target();
template<typename Functor> const Functor* target() const;

    返回:

    		 如果 this 存储了类型为 Functor 的目标, 则返回该目标的地址; 否则返回 NULL 指针.

    抛出:

    		 不会抛出异常. 
  2. template<typename Functor> bool contains(const Functor& f) const;

    返回:

    		 true, 当 this->target<Functor>() 非 NULL 且 function_equal(*(this->target<Functor>()), f) 时 
  3. const std::type_info& target_type() const;

    返回:

    		 目标函数对象的 typeid, 或 typeid(void) (当 this->empty() 时) .

    抛出:

    		 不会抛出异常.

function 调用

  1. result_type operator()(arg1_type a1, arg2_type a2, ..., argN_type aN) const;

    效果:

    		 f(a1, a2, ..., aN), 其中 f 是 *this 的目标.

    返回:

    		 如果 R 为 void, 则不返回任何值; 否则返回对 f 的调用所返回的值.

    抛出:

    		 bad_function_call, 当 this->empty() 时. 否则, 可能传播目标函数 f 抛出的任何异常.

function 特化算法

  1. template<typename Signature> 
  void swap(function<Signature>& f1, function<Signature>& f2);

    效果:

    		 f1.swap(f2)

function 比较运算符

  1. template<typename Signature, typename Functor> 
  bool operator==(const function<Signature>& f, Functor g);
template<typename Signature, typename Functor> 
  bool operator==(Functor g, const function<Signature>& f);
template<typename Signature, typename Functor> 
  bool operator==(const function<Signature>& f, reference_wrapper<Functor> g);
template<typename Signature, typename Functor> 
  bool operator==(reference_wrapper<Functor> g, const function<Signature>& f);
template<typename Signature1, typename Signature2> 
  void operator==(const function<Signature1>& f1, 
                  const function<Signature2>& f2);

    返回:

    		 当 f 存储了类型为 Functor 的对象且下列条件之一成立时为真:
    • g 的类型为 reference_wrapper<Functor> 且 f.target<Functor>() == g.get_pointer().
    • g 的类型不为 reference_wrapper<Functor> 且 function_equals(*(f.target<Functor>()), g).

    注释:

    		 function 对象不是 EqualityComparable 的.

    设计理由:

    		 safe_bool 转换打开了一个漏洞, 使得两个 function 实例可以通过 == 进行比较, 尽管这在实现上不可行. 未定义的 void operator== 封堵了这个漏洞, 确保产生编译期或链接期错误. 

  2. template<typename Signature, typename Functor> 
  bool operator!=(const function<Signature>& f, Functor g);
template<typename Signature, typename Functor> 
  bool operator!=(Functor g, const function<Signature>& f);
template<typename Signature, typename Functor> 
  bool operator!=(const function<Signature>& f, reference_wrapper<Functor> g);
template<typename Signature, typename Functor> 
  bool operator!=(reference_wrapper<Functor> g, const function<Signature>& f);
template<typename Signature1, typename Signature2> 
  void operator!=(const function<Signature1>& f1, 
                  const function<Signature2>& f2);

    返回:

    		 当 f 未存储类型为 Functor 的对象, 或存储了类型为 Functor 的对象且下列条件之一成立时为真:
    • g 的类型为 reference_wrapper<Functor> 且 f.target<Functor>() != g.get_pointer().
    • g 的类型不为 reference_wrapper<Functor> 且 !function_equals(*(f.target<Functor>()), g).

    注释:

    		 function 对象不是 EqualityComparable 的.

    设计理由:

    		 safe_bool 转换打开了一个漏洞, 使得两个 function 实例可以通过 != 进行比较, 尽管这在实现上不可行. 未定义的 void operator!= 封堵了这个漏洞, 确保产生编译期或链接期错误.
