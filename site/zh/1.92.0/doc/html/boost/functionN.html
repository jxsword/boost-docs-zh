类模板 functionN

boost::functionN — 一组广义的函数指针, 可用于回调或包装函数对象.

概要

class functionN : public function_base {
public:
  // types
  typedef R  result_type;

  static const int arity = N;

    // types
    typedef result_type type;
  };

  // construct/copy/destruct
  functionN();
  functionN(const functionN&);
  functionN(functionN&&);
  template<typename F> functionN(F);
  template<typename F, typename Allocator> functionN(F, Allocator);

  functionN& operator=(functionN&&);

  void swap(const functionN&);

  bool empty() const;

  // invocation
  result_type operator()(arg1_type, arg2_type, ..., argN_type) const;
};

说明

类模板 functionN 实际上是一族相关类 function0、function1 等, 直至某个由实现定义的上限. 在此语境中, N 指参数的数量.

functionN 公有构造/复制/析构

  1. functionN();

    后置条件:

    		 this->empty()

    抛出:

    		 不会抛出异常. 
  2. functionN(const functionN& f);

    后置条件:

    		 保存 f 的目标的一份副本 (如果它有目标) ; 若 f.empty() 则为空.

    抛出:

    		 除非复制 f 的目标时抛出异常, 否则不会抛出. 
  3. functionN(functionN&& f);

    要求:

    		 兼容 C++11 的编译器.

    后置条件:

    		 将 f 的值移动到 *this. 如果实参的函数对象分配在堆上, 其缓冲区将被赋给 *this, 实参则变为空.

    抛出:

    		 除非实参的函数对象未分配在堆上且复制 f 的目标时抛出异常, 否则不会抛出. 
  4. template<typename F> functionN(F f);

    要求:

    		 F 是可从 this 调用 (Callable) 的函数对象.

    后置条件:

    		 *this 指向 f 的一份副本 (当 f 非空时) , 或为 this->empty() (当 f 为空时) . 
  5. template<typename F, typename Allocator> functionN(F f, Allocator alloc);

    要求:

    		 F 是可从 this 调用 (Callable) 的函数对象, Allocator 是一个分配器. Allocator 的复制构造函数和析构函数不得抛出异常.

    后置条件:

    		 *this 指向 f 的一份副本 (当 f 非空时) , 或为 this->empty() (当 f 为空时) .

    效果:

    		 如果需要内存分配, 将使用给定的分配器 (或其副本) 来分配该内存. 
  6. functionN& operator=(const functionN& f);

    后置条件:

    		 如果复制构造不抛出异常, *this 指向 f 的目标的一份副本 (如果它有目标) , 或当 f.empty() 时为空. 如果复制构造抛出异常, 则为 this->empty(). 
  7. functionN& operator=(functionN&& f);

    要求:

    		 兼容 C++11 的编译器.

    后置条件:

    		 将 f 的值移动到 *this. 如果实参的函数对象分配在堆上, 其缓冲区将被赋给 *this, 实参则变为空.

    抛出:

    		 除非实参的函数对象未分配在堆上且复制 f 的目标时抛出异常, 否则不会抛出. 
  8. ~functionN();

    效果:

    		 如果 !this->empty(), 则销毁 this 的目标.

functionN 修饰符

  1. void swap(const functionN& f);

    效果:

    		 交换 *this 与 f 的目标. 
  2. void clear();

    后置条件:

    		 this->empty()

functionN 容量

  1. bool empty() const;

    返回:

    		 false, 当 this 有目标时; 否则为 true.

    抛出:

    		 不会抛出异常. 
  2. operator safe_bool() const;

    返回:

    		 一个 safe_bool, 在布尔上下文中求值 false (当 this->empty() 时) , 否则为 true.

    抛出:

    		 不会抛出异常. 
  3. bool operator!() const;

    返回:

    		 this->empty()

    抛出:

    		 不会抛出异常.

functionN 目标访问

  1. template<typename Functor> Functor* target();
template<typename Functor> const Functor* target() const;

    返回:

    		 如果 this 存储了类型为 Functor 的目标, 则返回该目标的地址; 否则返回 NULL 指针.

    抛出:

    		 不会抛出异常. 
  2. template<typename Functor> bool contains(const Functor& f) const;

    返回:

    		 true, 当 this->target<Functor>() 非 NULL 且 function_equal(*(this->target<Functor>()), f) 时 
  3. const std::type_info& target_type() const;

    返回:

    		 目标函数对象的 typeid, 或 typeid(void) (当 this->empty() 时) .

    抛出:

    		 不会抛出异常.

functionN 调用

  1. result_type operator()(arg1_type a1, arg2_type a2, ..., argN_type aN) const;

    效果:

    		 f(a1, a2, ..., aN), 其中 f 是 *this 的目标.

    返回:

    		 如果 R 为 void, 则不返回任何值; 否则返回对 f 的调用所返回的值.

    抛出:

    		 bad_function_call, 当 this->empty() 时. 否则, 可能传播目标函数 f 抛出的任何异常.

functionN 特化算法

  1. template<typename T1, typename T2, ..., typename TN> 
  void swap(functionN<T1, T2, ..., TN>& f1, functionN<T1, T2, ..., TN>& f2);

    效果:

    		 f1.swap(f2)

functionN 比较运算符

  1. template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator==(const functionN<T1, T2, ..., TN>& f, Functor g);
template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator==(Functor g, const functionN<T1, T2, ..., TN>& f);
template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator==(const functionN<T1, T2, ..., TN>& f, 
                  reference_wrapper<Functor> g);
template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator==(reference_wrapper<Functor> g, 
                  const functionN<T1, T2, ..., TN>& f);
template<typename T1, typename T2, ..., typename TN, typename U1, typename U2, 
         ..., typename UN> 
  void operator==(const functionN<T1, T2, ..., TN>& f1, 
                  const functionN<U1, U2, ..., UN>& f2);

    返回:

    		 当 f 存储了类型为 Functor 的对象且下列条件之一成立时为真:
    • g 的类型为 reference_wrapper<Functor> 且 f.target<Functor>() == g.get_pointer().
    • g 的类型不为 reference_wrapper<Functor> 且 function_equal(*(f.target<Functor>()), g).

    注释:

    		 functionN 对象不是 EqualityComparable 的.

    设计理由:

    		 safe_bool 转换打开了一个漏洞, 使得两个 functionN 实例可以通过 == 进行比较, 尽管这在实现上不可行. 未定义的 void operator== 封堵了这个漏洞, 确保产生编译期或链接期错误. 

  2. template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator!=(const functionN<T1, T2, ..., TN>& f, Functor g);
template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator!=(Functor g, const functionN<T1, T2, ..., TN>& f);
template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator!=(const functionN<T1, T2, ..., TN>& f, 
                  reference_wrapper<Functor> g);
template<typename T1, typename T2, ..., typename TN, typename Functor> 
  bool operator!=(reference_wrapper<Functor> g, 
                  const functionN<T1, T2, ..., TN>& f);
template<typename T1, typename T2, ..., typename TN, typename U1, typename U2, 
         ..., typename UN> 
  void operator!=(const functionN<T1, T2, ..., TN>& f1, 
                  const functionN<U1, U2, ..., UN>& f2);

    返回:

    		 当 f 未存储类型为 Functor 的对象, 或存储了类型为 Functor 的对象且下列条件之一成立时为真:
    • g 的类型为 reference_wrapper<Functor> 且 f.target<Functor>() != g.get_pointer().
    • g 的类型不为 reference_wrapper<Functor> 且 !function_equal(*(f.target<Functor>()), g).

    注释:

    		 functionN 对象不是 EqualityComparable 的.

    设计理由:

    		 safe_bool 转换打开了一个漏洞, 使得两个 functionN 实例可以通过 != 进行比较, 尽管这在实现上不可行. 未定义的 void operator!= 封堵了这个漏洞, 确保产生编译期或链接期错误.
