类 trackable

boost::signals2::trackable — 为使用最初 Boost.Signals 库中 boost::signals::trackable 类的代码提供便利的移植支持.

概要

// In header: <boost/signals2/trackable.hpp>


class trackable {
public:
  // construct/copy/destruct
  trackable();
  trackable(const trackable&);
  trackable& operator=(const trackable&);
  ~trackable();
};

说明

不建议在新代码中使用 trackable 类. trackable 类不是线程安全的, 因为 trackable 对象在 trackable 析构函数中断开其关联的连接. 由于 trackable 析构函数要等到所有派生类的析构函数完成之后才会运行, 这留下了一个窗口期: 部分析构的对象仍可能持有活跃连接.

在 Boost.Signals2 中进行自动连接管理的首选方法是使用 shared_ptr 管理被跟踪对象的生命期, 并使用 signals2::slot::track 方法跟踪其生命期.

trackable 类在绑定到槽中的对象 (通过指针或引用) 被销毁时提供信号与槽的自动断开. trackable 类只能用作某个其他类的公有基类; 这样使用时, 该类可以被绑定到用作槽的一部分的函数对象. trackable 对象跟踪其所参与的信号-槽连接集合的方式未指明.

trackable 的实际使用取决于对任何可能包含指向可跟踪对象的指针或引用的类型是否存在适当的 visit_each 重载.

trackable 公有构造/复制/析构

  1. trackable();

    效果:

    把已连接槽的列表设为空.

    抛出:

    不会抛出异常.

    		 
  2. trackable(const trackable& other);

    效果:

    把已连接槽的列表设为空.

    抛出:

    不会抛出异常.

    设计理由:

    信号-槽连接只能通过调用显式的 connect 方法创建, 因此在可跟踪对象被复制时不能在这里创建.

    		 
  3. trackable& operator=(const trackable& other);

    效果:

    把已连接槽的列表设为空.

    返回:

    *this

    抛出:

    不会抛出异常.

    设计理由:

    信号-槽连接只能通过调用显式的 connect 方法创建, 因此在可跟踪对象被复制时不能在这里创建.

    		 
  4. ~trackable();

    效果:

    断开所有包含可通过 visit_each 找到的指向此可跟踪对象的指针或引用的信号/槽连接.
