类 connection

boost::signals2::connection — 查询/断开信号-槽连接.

概要

// In header: <boost/signals2/connection.hpp>


class connection {
public:
  // construct/copy/destruct
  connection();
  connection(const connection&);
  connection(connection&&);
  connection& operator=(const connection&);
  connection& operator=(connection&&);

  // connection management
  void disconnect() const;
  bool connected() const;

  // blocking
  bool blocked() const;

  // modifiers
  void swap(connection&);

  // comparisons
  bool operator==(const connection&) const;
  bool operator!=(const connection&) const;
  bool operator<(const connection&) const;
};

// specialized algorithms
void swap(connection&, connection&);

说明

signals2::connection 类表示一个信号 (Signal) 与一个槽 (Slot) 之间的连接. 它是一个轻量对象, 能够查询信号与槽当前是否已连接, 并断开信号与槽. 查询或断开连接总是安全的.

线程安全

connection 类的方法是线程安全的, swap 和赋值运算符除外. 当这两个操作之一正在进行时, 不应并发访问一个 connection 对象. 不过, 在另一个线程中访问另一个 connection 对象总是安全的, 即使这两个 connection 对象互为副本且指向同一个底层连接.

connection 公有构造/复制/析构

  1. connection();

    效果:

    把当前表示的连接设置为 NULL 连接.

    后置条件:

    !this->connected().

    抛出:

    不会抛出异常.

    		 
  2. connection(const connection& other);

    效果:

    this 引用 other 所引用的连接.

    抛出:

    不会抛出异常.

    		 
  3. connection(connection&& other);

    移动构造函数.

    效果:

    this 引用 other 原先引用的连接. 被移动的 other 不再引用任何连接.

    抛出:

    不会抛出异常.

    		 
  4. connection& operator=(const connection& rhs);

    效果:

    this 引用 rhs 所引用的连接.

    抛出:

    不会抛出异常.

    		 
  5. connection& operator=(connection&& rhs);

    移动赋值.

    效果:

    this 引用 rhs 原先引用的连接. 被移动的 rhs 不再引用任何连接.

    抛出:

    不会抛出异常.

connection 连接管理

  1. void disconnect() const;

    效果:

    如果 this->connected(), 则断开 this 引用的信号与槽; 否则, 此操作为无操作 (no-op) .

    后置条件:

    !this->connected().

    		 
  2. bool connected() const;

    返回:

    true, 如果 this 引用一个仍然活跃 (已连接) 的非 NULL 连接; 否则为 false.

    抛出:

    不会抛出异常.

connection 阻塞

  1. bool blocked() const;

    查询该连接是否被阻塞. 连接可以通过创建一个 boost::signals2::shared_connection_block 对象来阻塞.

    返回:

    true, 如果关联的槽已断开连接或被阻塞; 否则为 false.

    抛出:

    不会抛出异常.

connection 修饰符

  1. void swap(connection& other);

    效果:

    交换 this 与 other 中引用的连接.

    抛出:

    不会抛出异常.

connection 比较

  1. bool operator==(const connection& other) const;

    返回:

    true, 如果 this 与 other 引用同一个连接或都引用 NULL 连接; 否则为 false.

    抛出:

    不会抛出异常.

    		 
  2. bool operator!=(const connection& other) const;

    返回:

    !(*this == other)

    抛出:

    不会抛出异常.

    		 
  3. bool operator<(const connection& other) const;

    返回:

    true, 如果按某种未指明的排序 this 引用的连接先于 other 引用的连接; 否则为 false.

    抛出:

    不会抛出异常.

connection 特化算法

  1. void swap(connection& x, connection& y);

    效果:

    x.swap(y)

    抛出:

    不会抛出异常.
