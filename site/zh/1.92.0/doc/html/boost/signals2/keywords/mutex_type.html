类模板 mutex_type

boost::signals2::keywords::mutex_type — signal_type 的模板关键字.

概要

// In header: <boost/signals2/signal_type.hpp>

template<typename Mutex> 
class mutex_type : public unspecified-type {
};

说明

该类是一个模板关键字, 可用于把被包装的 Mutex 模板类型作为命名参数传给 signal_type 元函数.

该类的代码通过调用 Boost.Parameter 库的一个宏生成: BOOST_PARAMETER_TEMPLATE_KEYWORD(mutex_type)
