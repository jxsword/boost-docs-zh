类 postconstructor_invoker

boost::signals2::postconstructor_invoker — 为用 deconstruct() 创建的对象传递实参并运行后构造函数.

概要

// In header: <boost/signals2/deconstruct.hpp>


class postconstructor_invoker {
public:

  // public methods
  operator const shared_ptr<T> &();
  const shared_ptr<T> & postconstruct();
  template<typename A1> const shared_ptr<T> & postconstruct(A1);
  template<typename A1, typename A2> 
    const shared_ptr<T> & postconstruct(A1, A1);
  template<typename A1, typename A2, ..., typename AN> 
    const shared_ptr<T> & postconstruct(A1, A1, ..., A1);
};

说明

postconstructor_invoker 类型的对象由对 deconstruct() 工厂函数的调用返回. 这些对象既可以被立即赋给一个 shared_ptr (此时该类的转换运算符会通过不带实参调用 postconstruct 来执行转换) , 也可以由用户调用某个 postconstruct 方法显式转换为 shared_ptr.

postconstructor_invoker 公有方法

  1. operator const shared_ptr<T> &();

    该转换运算符的效果与显式地不带实参调用 postconstruct 方法相同.

  2. const shared_ptr<T> & postconstruct();
template<typename A1> const shared_ptr<T> & postconstruct(A1 a1);
template<typename A1, typename A2> 
  const shared_ptr<T> & postconstruct(A1 a1, A1 a2);
template<typename A1, typename A2, ..., typename AN> 
  const shared_ptr<T> & postconstruct(A1 a1, A1 a2, ..., A1 aN);

    postconstruct 方法会对 adl_postconstruct() 进行非限定调用, 然后返回 shared_ptr——它被包装在 postconstructor_invoker 对象内, 由 deconstruct() 完成. 传给 adl_postconstruct() 调用的前两个实参总是 shared_ptr (拥有由 deconstruct() 所创建的对象) , 其后是一个指向同一对象的普通指针. 为方便起见, 该普通指针在被传给 adl_postconstruct 之前总是会被转换为指向非 const 类型. 传给 adl_postconstruct 的其余实参就是用户可能传给 postconstruct 方法的任何实参.
