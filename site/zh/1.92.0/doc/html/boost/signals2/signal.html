类模板 signal

boost::signals2::signal — 安全的多播回调.

概要

// In header: <boost/signals2/signal.hpp>

template<typename Signature, 
         typename Combiner = boost::signals2::optional_last_value<R>, 
         typename Group = int, typename GroupCompare = std::less<Group>, 
         typename SlotFunction = boost::function<Signature>, 
         typename ExtendedSlotFunction = boost::function<R (const connection &, T1, T2, ..., TN)>, 
         typename Mutex = boost::signals2::mutex> 
class signal : public boost::signals2::signal_base {
public:
  // types
  typedef Signature                                                                          signature_type;             
  typedef typename Combiner::result_type                                                     result_type;                
  typedef Combiner                                                                           combiner_type;              
  typedef Group                                                                              group_type;                 
  typedef GroupCompare                                                                       group_compare_type;         
  typedef SlotFunction                                                                       slot_function_type;         
  typedef typename signals2::slot<Signature, SlotFunction>                                   slot_type;                  
  typedef ExtendedSlotFunction                                                               extended_slot_function_type;
  typedef typename signals2::slot<R (const connection &, T1, ..., TN), ExtendedSlotFunction> extended_slot_type;         
  typedef typename SlotFunction::result_type                                                 slot_result_type;           
  typedef unspecified                                                                        slot_call_iterator;         
  typedef T1                                                                                 argument_type;                // Exists iff arity == 1
  typedef T1                                                                                 first_argument_type;          // Exists iff arity == 2
  typedef T2                                                                                 second_argument_type;         // Exists iff arity == 2

  // static constants
  static const int arity = N;  // The number of arguments taken by the signal.

  // member classes/structs/unions
  template<unsigned n> 
  class arg {
  public:
    // types
    typedef Tn type;  // The type of the signal's (n+1)th argument
  };

  // construct/copy/destruct
  signal(const combiner_type& = combiner_type(), 
         const group_compare_type& = group_compare_type());
  signal(signal &&);
  signal& operator=(signal &&);

  // connection management
  connection connect(const slot_type&, connect_position = at_back);
  connection connect(const group_type&, const slot_type&, 
                     connect_position = at_back);
  connection connect_extended(const extended_slot_type&, 
                              connect_position = at_back);
  connection connect_extended(const group_type&, const extended_slot_type&, 
                              connect_position = at_back);
  void disconnect(const group_type&);
  template<typename S> void disconnect(const S&);
  void disconnect_all_slots();
  bool empty() const;
  std::size_t num_slots() const;

  // invocation
  result_type operator()(arg<0>::type, arg<1>::type, ..., arg<N-1>::type);
  result_type operator()(arg<0>::type, arg<1>::type, ..., arg<N-1>::type) const;

  // combiner access
  combiner_type combiner() const;
  void set_combiner(const combiner_type&);

  // modifiers
  void swap(signal&);

  // misc
  bool null() const;
};

// specialized algorithms
template<typename Signature, typename Combiner, typename Group, 
         typename GroupCompare, typename SlotFunction, 
         typename ExtendedSlotFunction, typename Mutex> 
  void swap(signal<Signature, Combiner, Group, GroupCompare, SlotFunction, ExtendedSlotFunction, Mutex>&, 
            signal<Signature, Combiner, Group, GroupCompare, SlotFunction, ExtendedSlotFunction, Mutex>&);

说明

关于如何使用 signal 类的更多信息, 参见 教程.

模板参数

  1. typename Signature

  3. typename Group = int
  4. typename GroupCompare = std::less<Group>
  5. typename SlotFunction = boost::function<Signature>

signal 公有类型

  1. typedef typename signals2::slot<R (const connection &, T1, ..., TN), ExtendedSlotFunction> extended_slot_type;

    extended_slot_type 的槽可以使用 connect_extended 方法连接到信号. extended_slot_type 在其签名中有一个额外的 signals2::connection 实参, 使槽函数能够访问它与触发它的信号之间的连接.

  2. typedef typename SlotFunction::result_type slot_result_type;

    这是对传给信号组合器的输入迭代器解引用时返回的类型.

  3. typedef 未指明 slot_call_iterator;

    信号被触发时传给组合器的输入迭代器类型.

signal 公有构造/复制/析构

  1. signal(const combiner_type& combiner = combiner_type(), 
       const group_compare_type& compare = group_compare_type());

    效果:

    初始化信号使其不含任何槽, 把给定的组合器复制到内部存储, 并保存给定的组比较函数对象用于比较组.

    后置条件:

    this->empty()

    		 
  2. signal(signal && other);

    移动构造函数.

    后置条件:

    other.null()

    抛出:

    不会抛出异常.

    		 
  3. signal& operator=(signal && rhs);

    移动赋值.

    后置条件:

    rhs.null()

    抛出:

    不会抛出异常.

signal 连接管理

  1. connection connect(const slot_type& slot, connect_position at = at_back);
connection connect(const group_type& group, const slot_type& slot, 
                   connect_position at = at_back);

    效果:

    把信号 this 连接到传入的槽. 如果该槽不活跃 (即槽的被跟踪对象中有任何已被销毁) , 则对 connect 的调用是无操作. 如果调用的是 connect 的第二个版本, 则该槽与给定的组相关联. at 参数指定槽应连接到哪里: at_front 表示槽将被连接到槽列表或槽组的开头, at_back 表示槽将被连接到槽列表或槽组的末尾.

    返回:

    一个 signals2::connection 对象, 引用信号与槽之间新建的连接; 如果槽不活跃, 则返回一个已断开的连接.

    抛出:

    该例程满足强异常保证: 抛出的任何异常都会导致槽不连接到信号.

    复杂度:

    连接不带组名的槽时为常数时间, 连接到特定组时与组数成对数关系.

    注释:

    未指明在信号正在调用期间连接一个槽是否会导致该槽被立即调用.

    		 
  2. connection connect_extended(const extended_slot_type& slot, 
                            connect_position at = at_back);
connection connect_extended(const group_type& group, 
                            const extended_slot_type& slot, 
                            connect_position at = at_back);

    connect_extended 方法的工作方式与 connect 方法相同, 只是它们接受 extended_slot_type 类型的槽. 如果槽需要访问它与触发它的信号之间的连接 (例如希望断开或阻塞自己的连接) , 这会很有用.

  3. void disconnect(const group_type& group);
template<typename S> void disconnect(const S& slot_func);

    效果:

    如果参数是 (可转换为) 组名, 则断开给定组中的所有槽. 否则, 断开所有与给定槽函数相等的槽.

    注意, slot_func 实参不应是一个实际的 signals2::slot 对象 (它甚至不支持 operator==) , 而应是你最初建立连接时包装在 signals2::slot 内的那个函数对象.

    抛出:

    除非用户析构函数或相等运算符 == 抛出异常, 否则不会抛出. 如果其中任何一个抛出异常, 则可能不会断开所有槽.

    复杂度:

    如果给定了组, 则为 O(lg g) + k, 其中 g 是信号中的组数, k 是该组中的槽数. 否则, 与连接到信号的槽数成线性关系.

    		 
  4. void disconnect_all_slots();

    效果:

    断开连接到信号的所有槽.

    后置条件:

    this->empty().

    抛出:

    如果断开某个槽导致抛出异常, 则可能不会断开所有槽.

    复杂度:

    与信号已知的槽数成线性关系.

    注释:

    可在信号生命期内的任何时刻调用, 包括在调用信号的槽期间.

    		 
  5. bool empty() const;

    返回:

    true, 如果没有槽连接到信号; 否则为 false.

    抛出:

    不会抛出异常.

    复杂度:

    与信号已知的槽数成线性关系.

    设计理由:

    槽可以在任何时刻断开连接, 包括在这些槽本身被调用期间. 因此, 实现可能必须搜索已断开连接的槽的列表, 以确定是否仍有槽处于连接状态.

    		 
  6. std::size_t num_slots() const;

    返回:

    连接到信号的槽数

    抛出:

    不会抛出异常.

    复杂度:

    与信号已知的槽数成线性关系.

    设计理由:

    槽可以在任何时刻断开连接, 包括在这些槽本身被调用期间. 因此, 实现可能必须搜索已断开连接的槽的列表, 以确定仍有多少槽处于连接状态.

signal 调用

  1. result_type operator()(arg<0>::type a1, arg<1>::type a2, ..., 
                       arg<N-1>::type aN);
result_type operator()(arg<0>::type a1, arg<1>::type a2, ..., 
                       arg<N-1>::type aN) const;

    效果:

    用一个 slot_call_iterator 范围 [first, last) 调用组合器, 该范围对应于对连接到信号 *this 的各槽的调用序列. 解引用此范围中的迭代器会引发一次使用给定参数集 (a1, a2, ..., aN) 的槽调用, 其结果从迭代器解引用操作返回.

    返回:

    组合器返回的结果.

    抛出:

    如果槽调用抛出异常, 或组合器没有解引用某个给定槽之后的任何槽, 则内部已连接槽列表中该槽之后的所有槽都不会被调用.

    注释:

    只有与实际被解引用的迭代器相关联的槽才会被调用. 对同一迭代器的多次解引用不会导致多次槽调用, 因为槽的返回值会被缓存.

    函数调用运算符的 const 版本会以 const 方式调用组合器, 而非 const 版本则会以非 const 方式调用组合器.

signal 组合器访问

  1. combiner_type combiner() const;

    返回:

    所存储组合器的一份副本.

    抛出:

    不会抛出异常.

    		 
  2. void set_combiner(const combiner_type& combiner);

    效果:

    把一个新组合器复制进信号, 供以后的信号触发使用.

    抛出:

    不会抛出异常.

signal 修饰符

  1. void swap(signal& other);

    效果:

    交换 this 与 other 中引用的信号.

    抛出:

    不会抛出异常.

signal 杂项

  1. bool null() const;

    返回:

    false 用于正常信号, true 用于信号被移动之后. 空信号是信号被移动后留下的无功能空壳. 它们不能被触发, 也不能连接槽.

    抛出:

    不会抛出异常.

    注释:

    空信号可以被销毁、交换或移动赋值. 此外, 可以在空信号上调用下列方法:

    disconnect 和 disconnect_all_slots
    无效果
    empty
    返回 true
    null
    返回 true
    num_slots
    返回 0

    对空信号的任何其他操作都是无效的.

signal 特化算法

  1. template<typename Signature, typename Combiner, typename Group, 
         typename GroupCompare, typename SlotFunction, 
         typename ExtendedSlotFunction, typename Mutex> 
  void swap(signal<Signature, Combiner, Group, GroupCompare, SlotFunction, ExtendedSlotFunction, Mutex>& x, 
            signal<Signature, Combiner, Group, GroupCompare, SlotFunction, ExtendedSlotFunction, Mutex>& y);

    效果:

    x.swap(y)

    抛出:

    不会抛出异常.
