类模板 signal_type

boost::signals2::signal_type — 使用命名参数指定 boost::signals2::signal 的模板类型参数.

概要

// In header: <boost/signals2/signal_type.hpp>

template<typename A0, typename A1 = boost::parameter::void_, 
         typename A2 = boost::parameter::void_, 
         typename A3 = boost::parameter::void_, 
         typename A4 = boost::parameter::void_, 
         typename A5 = boost::parameter::void_, 
         typename A6 = boost::parameter::void_> 
class signal_type {
public:
  // types
  typedef implementation-detail                                           signature_type;             
  typedef implementation-detail                                           combiner_type;              
  typedef implementation-detail                                           group_type;                 
  typedef implementation-detail                                           group_compare_type;         
  typedef implementation-detail                                           slot_function_type;         
  typedef implementation-detail                                           extended_slot_function_type;
  typedef implementation-detail                                           mutex_type;                 
  typedef typename signal<signature_type, combiner_type, ..., mutex_type> type;                       
};

说明

signal_type 元函数使用 Boost.Parameter 库, 允许用户以命名参数的方式指定 signals2::signal 的模板类型参数. 所得信号类型通过 signal_type::type typedef 提供. 命名的模板类型参数可以增强代码的可读性, 并为指定拥有大量模板参数的类提供便利.

模板类型参数可以按位置传递, 类似于直接把它们传给 signals2::signal 类. 或者, 也可以通过把它们包装进 boost::signals2::keywords 命名空间中提供的某个模板关键字类, 以命名模板参数的方式传递. 支持的模板关键字有: keywords::signature_type、keywords::combiner_type、keywords::group_type、keywords::group_compare_type、keywords::slot_function_type、keywords::extended_slot_function_type 和 keywords::mutex_type.

未指定的模板类型参数的默认类型与 signal 类的默认类型相同.

当你只想把信号的少数几个模板类型参数从默认值改掉, 而且你想改的参数靠近信号模板参数列表的末尾时, 命名的模板类型参数尤其方便. 例如, 如果你只想改变信号的 Mutex 模板类型参数, 可以这样写:

namespace bs2 = boost::signals2;
using namespace bs2::keywords;
bs2::signal_type<void (), mutex_type<bs2::dummy_mutex> >::type sig;

作为对比, 直接使用 signal 类指定相同的类型如下:

namespace bs2 = boost::signals2;
bs2::signal
  <
    void (),
    bs2::optional_last_value<void>,
    int,
    std::less<int>,
    boost::function<void ()>,
    boost::function<void (const connection &)>,
    bs2::dummy_mutex
  > sig;
