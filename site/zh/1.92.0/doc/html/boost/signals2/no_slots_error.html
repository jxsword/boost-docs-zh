类 no_slots_error

boost::signals2::no_slots_error — 表示一个组合器无法合成返回值.

概要

// In header: <boost/signals2/last_value.hpp>


class no_slots_error : public std::exception {
public:
  virtual const char *  what() const;
};

说明

no_slots_error 异常可能由 signals2::last_value 抛出, 当它运行但无法从其输入迭代器获得任何结果时.
