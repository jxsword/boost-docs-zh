类 shared_connection_block

boost::signals2::shared_connection_block — 阻塞信号与槽之间的连接.

概要

// In header: <boost/signals2/shared_connection_block.hpp>


class shared_connection_block {
public:
  // construct/copy/destruct
  shared_connection_block(const boost::signals2::connection & = connection(), 
                          bool = true);
  shared_connection_block(const boost::signals2::shared_connection_block &);
  shared_connection_block& 
  operator=(const boost::signals2::shared_connection_block &);
  ~shared_connection_block();

  // connection blocking
  void unblock();
  void block();
  bool blocking() const;

  // miscellaneous methods
  boost::signals2::connection connection() const;
};

说明

一个 shared_connection_block 对象会阻塞一个连接, 使关联的槽在关联的信号被触发时不执行. 该连接将保持阻塞, 直到引用该连接的每个 shared_connection_block 都释放其阻塞. shared_connection_block 在被销毁或其 unblock 方法被调用时释放其阻塞.

一个 shared_connection_block 即使在构造其所用的 signals2::connection 对象已被销毁、或它引用的连接已被断开之后, 仍然可以安全使用.

注意, 如果关联的槽在连接阻塞生效时已经在执行过程中, 阻塞连接并不能保证该槽已完成执行. 这类似于断开连接的行为: 阻塞连接不会等待该连接关联的槽完成执行. 在多线程环境中, 如果连接阻塞与信号触发并发发生, 或在单线程环境中, 如果某个槽阻塞其自身连接, 就可能出现这种情况.

shared_connection_block 公有构造/复制/析构

  1. shared_connection_block(const boost::signals2::connection & conn = connection(), 
                        bool initially_blocking = true);

    效果:

    创建一个 shared_connection_block, 它可以阻塞 conn 所引用的连接. shared_connection_block 初始就会阻塞该连接, 当且仅当 initially_blocking 参数为 true. 通过调用 unblock 方法或销毁 shared_connection_block 对象可以释放对该连接的阻塞.

    默认构造一个 shared_connection_block 会得到一个引用 NULL 连接的 shared_connection_block. 这样的 shared_connection_block 使用起来是安全的, 但在它被赋值为另一个引用真实连接的 shared_connection_block 之前没有太大用处.

    后置条件:

    this->blocking() == initially_blocking

    		 
  2. shared_connection_block(const boost::signals2::shared_connection_block & other);

    效果:

    复制构造一个 shared_connection_block, 它引用与 other 相同的连接.

    后置条件:

    this->connection() == other.connection()

    this->blocking() == other.blocking()

    		 
  3. shared_connection_block& 
operator=(const boost::signals2::shared_connection_block & rhs);

    效果:

    使 this 引用与 rhs 相同的连接.

    后置条件:

    this->connection() == rhs.connection()

    this->blocking() == rhs.blocking()

    抛出:

    不会抛出异常.

    		 
  4. ~shared_connection_block();

    效果:

    如果 blocking() 为 true, 则释放连接阻塞.

shared_connection_block 连接阻塞

  1. void unblock();

    效果:

    如果 blocking() 为 true, 则释放连接阻塞. 注意, 由于其他 shared_connection_block 对象, 该连接可能仍保持阻塞.

    后置条件:

    this->blocking() == false.

    		 
  2. void block();

    效果:

    如果 blocking() 为 false, 则重新对连接施加阻塞.

    后置条件:

    this->blocking() == true.

    		 
  3. bool blocking() const;

    返回:

    true, 如果 this 正在对该连接施加阻塞.

    注释:

    this->blocking() == true 蕴含该连接的 connection::blocked() == true. 然而, this->blocking() == false 不一定蕴含 connection::blocked() == false, 因为该连接可能被另一个 shared_connection_block 对象阻塞.

shared_connection_block 其他方法

  1. boost::signals2::connection connection() const;

    返回:

    针对 this 所引用连接的一个连接对象.
