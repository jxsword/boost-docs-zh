类模板 last_value

boost::signals2::last_value — 对一个 InputIterator 序列求值并返回序列中的最后一个值.

概要

// In header: <boost/signals2/last_value.hpp>

template<typename T> 
class last_value {
public:
  // types
  typedef T result_type;

  // invocation
  template<typename InputIterator> 
    result_type operator()(InputIterator, InputIterator) const;
};

说明

last_value 类是最初 Signals 库中信号的默认 Combiner 模板参数类型. Signals2 使用 optional_last_value 作为默认值, 它不会抛出异常.

last_value 调用

  1. template<typename InputIterator> 
  result_type operator()(InputIterator first, InputIterator last) const;

    效果:

    尝试对序列 [first, last) 中的每个迭代器解引用.

    返回:

    最后一次成功迭代器解引用的结果.

    抛出:

    no_slots_error, 如果没有迭代器被成功解引用, 除非 last_value 的模板类型为 void.

特化

  • 类 last_value<void>
