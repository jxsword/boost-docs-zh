类 dummy_mutex

boost::signals2::dummy_mutex — 什么都不做的假互斥量.

概要

// In header: <boost/signals2/dummy_mutex.hpp>


class dummy_mutex : public noncopyable {
public:
  void lock();
  bool try_lock();
  void unlock();
};

说明

如果你不关心线程安全, 可能希望把 dummy_mutex 类用作你的信号的 Mutex 模板类型. 这可以带来略快的性能, 因为 dummy_mutex 不执行任何实际的加锁.

void lock();

无效果.

bool try_lock();

无效果.

返回:

true.

 
void unlock();

无效果.
