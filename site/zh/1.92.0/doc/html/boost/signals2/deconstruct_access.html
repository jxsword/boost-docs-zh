类 deconstruct_access

boost::signals2::deconstruct_access — 让 deconstruct 能够访问私有/受保护构造函数.

概要

// In header: <boost/signals2/deconstruct.hpp>


class deconstruct_access {
};

说明

把 deconstruct_access 声明为你类的友元, 将使 deconstruct 工厂函数能够访问你类的私有和受保护构造函数. 将私有构造函数与 deconstruct_access 结合使用会很有用, 可以确保可后构造或可前析构的对象总是通过 deconstruct 正确创建.
