类 scoped_connection

boost::signals2::scoped_connection — 把信号-槽连接的生命期限定到特定作用域.

概要

// In header: <boost/signals2/connection.hpp>


class scoped_connection : public connection {
public:
  // construct/copy/destruct
  scoped_connection();
  scoped_connection(const connection&);
  scoped_connection(scoped_connection&&);
  scoped_connection(connection&&);
  scoped_connection& operator=(const connection&);
  scoped_connection& operator=(scoped_connection&&);
  scoped_connection& operator=(connection&&);
  ~scoped_connection();

  // public methods
  connection release();
private:
  // construct/copy/destruct
  scoped_connection(const scoped_connection&);
  scoped_connection& operator=(const scoped_connection&);
};

说明

一个在析构时自动断开连接的 connection.

线程安全

scoped_connection 类的方法 (包括从其基类 connection 继承的方法) 是线程安全的, signals2::connection::swap、release 和赋值运算符除外. 当这些操作中任何一个正在进行时, 不应并发访问一个 scoped_connection 对象. 不过, 在另一个线程中访问另一个 connection 对象总是安全的, 即使它引用同一个底层信号-槽连接.

scoped_connection 公有构造/复制/析构

  1. scoped_connection();

    默认构造一个空的 scoped_connection.

    后置条件:

    connected() == false

    抛出:

    不会抛出异常.

    		 
  2. scoped_connection(const connection& other);

    效果:

    this 引用 other 所引用的连接.

    后置条件:

    connected() == other.connected()

    抛出:

    不会抛出异常.

    		 
  3. scoped_connection(scoped_connection&& other);

    移动构造函数.

    效果:

    this 引用 other 原先引用的连接. 被移动的 other 不再引用任何连接.

    抛出:

    不会抛出异常.

    		 
  4. scoped_connection(connection&& other);

    移动构造函数.

    效果:

    this 引用 other 原先引用的连接. 被移动的 other 不再引用任何连接.

    抛出:

    不会抛出异常.

    		 
  5. scoped_connection& operator=(const connection& rhs);

    从非 scoped 连接进行复制赋值.

    效果:

    this 引用 rhs 所引用的连接. 如果 this 已引用另一个连接, 旧连接将先被断开.

    后置条件:

    connected() == other.connected()

    抛出:

    不会抛出异常.

    		 
  6. scoped_connection& operator=(scoped_connection&& rhs);

    移动赋值.

    效果:

    this 引用 rhs 原先引用的连接. 被移动的 rhs 不再引用任何连接. 如果 this 已引用另一个连接, 旧连接将先被断开.

    抛出:

    不会抛出异常.

    		 
  7. scoped_connection& operator=(connection&& rhs);

    移动赋值.

    效果:

    this 引用 rhs 原先引用的连接. 被移动的 rhs 不再引用任何连接. 如果 this 已引用另一个连接, 旧连接将先被断开.

    抛出:

    不会抛出异常.

    		 
  8. ~scoped_connection();

    效果:

    如果 this->connected(), 则断开信号-槽连接.

scoped_connection 公有方法

  1. connection release();

    效果:

    释放该连接, 使 scoped_connection 在被销毁或重新赋值时不会断开它. 此调用完成后, scoped_connection 被重置为 NULL 连接.

    后置条件:

    connected() == false

    返回:

    一个 connection 对象, 引用被 scoped_connection 释放的连接.

scoped_connection 私有构造/复制/析构

  1. scoped_connection(const scoped_connection& other);

    scoped_connection 类不可复制. 它只能从非 scoped 的 connection 对象进行复制构造.

  2. scoped_connection& operator=(const scoped_connection& rhs);

    scoped_connection 类不可复制. 它只能从非 scoped 的 connection 对象进行复制赋值.
