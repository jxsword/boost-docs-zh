类 mutex

boost::signals2::mutex — 一个实现 Boost.Thread 的 Lockable 概念的仅头文件互斥量.

概要

// In header: <boost/signals2/mutex.hpp>


class mutex {
public:
  void lock();
  bool try_lock();
  void unlock();
};

说明

mutex 类实现 Boost.Thread 的 Lockable 概念, 并且是信号的默认 Mutex 模板参数类型. 如果 boost 已在你的编译器中检测到线程支持, mutex 类将映射到 Windows 上的 CRITICAL_SECTION 或 POSIX 上的 pthread_mutex. 如果未检测到线程支持, mutex 的行为将类似于 dummy_mutex. 当 boost 检测到线程支持时, 头文件 boost/config.hpp 会定义宏 BOOST_HAS_THREADS. 用户可以通过在包含任何 boost 头文件之前定义 BOOST_DISABLE_THREADS 来全局禁用 boost 中的线程支持.

如果你已经在使用 Boost.Thread 库, 可能更倾向于改用其 boost::mutex 类作为你的信号的互斥量类型.

如果该信号只被单个线程使用, 你可能希望使用线程不安全的信号. 在这种情况下, 你可能更倾向于使用 signals2::dummy_mutex 类作为你的信号的 Mutex 模板类型.

void lock();

锁定互斥量.

bool try_lock();

以非阻塞方式尝试锁定互斥量.

返回:

true (成功时) .

 
void unlock();

解锁互斥量.
