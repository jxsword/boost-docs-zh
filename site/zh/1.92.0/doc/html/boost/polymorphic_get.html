函数 polymorphic_get

boost::polymorphic_get — 从给定的 variant 中检索指定类型的值.

概要

// In header: <boost/variant/polymorphic_get.hpp>


template<typename U, typename T1, typename T2, ..., typename TN> 
  U * polymorphic_get(variant<T1, T2, ..., TN> * operand);
template<typename U, typename T1, typename T2, ..., typename TN> 
  const U * polymorphic_get(const variant<T1, T2, ..., TN> * operand);
template<typename U, typename T1, typename T2, ..., typename TN> 
  U & polymorphic_get(variant<T1, T2, ..., TN> & operand);
template<typename U, typename T1, typename T2, ..., typename TN> 
  const U & polymorphic_get(const variant<T1, T2, ..., TN> & operand);

说明

求值为 polymorphic_strict_get, 如果 BOOST_VARIANT_USE_RELAXED_GET_BY_DEFAULT 未定义. 如果 BOOST_VARIANT_USE_RELAXED_GET_BY_DEFAULT 已定义, 则求值为 polymorphic_relaxed_get.

建议: 在新代码中使用 polymorphic_get 且不定义 BOOST_VARIANT_USE_RELAXED_GET_BY_DEFAULT. 这样 polymorphic_get 就能提供更多编译期检查, 其行为也更接近 C++ 标准库中的 std::get.
