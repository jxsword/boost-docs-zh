类模板 variant

boost::variant — 安全、通用、基于栈的可辨识联合容器.

概要

// In header: <boost/variant/variant.hpp>

template<typename T1, typename T2 = unspecified, ..., 
         typename TN = unspecified> 
class variant {
public:
  // types
  typedef unspecified types;

  // construct/copy/destruct
  variant();
  variant(const variant &);
  variant(variant &&);
  template<typename T> variant(T &);
  template<typename T> variant(const T &);
  template<typename T> variant(T &&);
  template<typename U1, typename U2, ..., typename UN> 
    variant(variant<U1, U2, ..., UN> &);
  template<typename U1, typename U2, ..., typename UN> 
    variant(const variant<U1, U2, ..., UN> &);
  template<typename U1, typename U2, ..., typename UN> 
    variant(variant<U1, U2, ..., UN> &&);
  ~variant();

  // modifiers
  void swap(variant &);
  variant & operator=(const variant &);
  variant & operator=(variant &&);
  template<typename T> variant & operator=(const T &);
  template<typename T> variant & operator=(T &&);

  // queries
  int which() const;
  bool empty() const;
  const std::type_info & type() const;

  // relational
  bool operator==(const variant &) const;
  template<typename U> void operator==(const U &) const;
  bool operator!=(const variant &) const;
  template<typename U> void operator!=(const U &) const;
  bool operator<(const variant &) const;
  template<typename U> void operator<(const U &) const;
  bool operator>(const variant &) const;
  template<typename U> void operator>(const U &) const;
  bool operator<=(const variant &) const;
  template<typename U> void operator<=(const U &) const;
  bool operator>=(const variant &) const;
  template<typename U> void operator>=(const U &) const;
};

说明

variant 类模板 (受 Andrei Alexandrescu 的同名类启发 [Ale01A]) 是一个高效的、支持递归的有界可辨识联合值类型, 能够包含任何值类型 (POD 或非 POD) . 它支持从任何可转换为其某个有界类型的类型构造, 或从源 variant 构造——其各有界类型均可转换为目标 variant 的某个有界类型. 此外, 通过 apply_visitor, variant 支持编译期检查的类型安全访问; 通过 get, variant 支持运行期检查的类型安全值检索.

注释:

  • variant 的有界类型通过嵌套 typedef types 暴露, 它是一个与 MPL 兼容的序列 (Sequence) , 包含任何 visitor 访问 variant 时必须处理的类型集合.
  • variant 的所有成员至少满足异常安全的基本保证. 也就是说, 即使之前的操作失败, 对 variant 的所有操作仍保持有定义.
  • 指定为 variant 模板实参的每个类型都必须满足 BoundedType 概念的要求.
  • 指定为 variant 模板实参的每个类型在去除限定符后必须彼此不同. 因此, 例如, variant<int, int> 和 variant<int, const int> 都具有未定义行为.
  • variant 的符合标准的实现必须允许至少十个类型作为模板实参. 允许实参的确切数量由预处理宏 BOOST_VARIANT_LIMIT_TYPES 暴露. (参见 make_variant_over, 它给出一种通过 MPL 或兼容序列的元素来指定 variant 的有界类型、从而克服此限制的方法. )

variant 公有构造/复制/析构

  1. variant();

    要求:

    		 variant 的第一个有界类型 (即 T1) 必须满足 DefaultConstructible [20.1.4] 概念的要求.

    后置条件:

    		 *this 的内容为第一个有界类型 (即 T1) 的默认值.

    抛出:

    		 可能因 T1 的默认构造函数引发的任何异常而失败. 
  2. variant(const variant & other);

    后置条件:

    		 *this 的内容是 other 内容的副本.

    抛出:

    		 可能因 other 所含类型的复制构造函数引发的任何异常而失败. 
  3. variant(variant && other);

    要求:

    		 兼容 C++11 的编译器.

    后置条件:

    		 *this 的内容是从 other 的内容移动构造而来.

    抛出:

    		 可能因 other 所含类型的移动构造函数引发的任何异常而失败. 
  4. template<typename T> variant(T & operand);

    要求:

    		 T 必须可无歧义地转换为某个有界类型 (即 T1、T2 等) .

    后置条件:

    		 *this 的内容是 operand 到某个有界类型的最佳转换, 由标准重载解析规则确定.

    抛出:

    		 可能因 operand 到某个有界类型的转换引发的任何异常而失败. 
  5. template<typename T> variant(const T & operand);

    注释:

    		 语义与前一个构造函数相同, 但允许从临时对象构造. 
  6. template<typename T> variant(T && operand);

    要求:

    		 兼容 C++11 的编译器.

    注释:

    		 语义与前一个构造函数相同, 但如果 operand 是右值则允许移动构造. 
  7. template<typename U1, typename U2, ..., typename UN> 
  variant(variant<U1, U2, ..., UN> & operand);

    要求:

    		 每一个 U1、U2、...、UN 都必须具有到某个有界类型 (即 T1、T2、...、TN) 的无歧义转换.

    后置条件:

    		 如果 variant<U1, U2, ..., UN> 本身就是某个有界类型, 则 *this 的内容是 operand 的副本. 否则, *this 的内容是 operand 的内容到某个有界类型的最佳转换, 由标准重载解析规则确定.

    抛出:

    		 如果 variant<U1, U2, ..., UN> 本身就是某个有界类型, 则可能因 variant<U1, U2, ..., UN> 的复制构造函数引发的任何异常而失败. 否则, 可能因 operand 的内容到某个有界类型的转换引发的任何异常而失败. 
  8. template<typename U1, typename U2, ..., typename UN> 
  variant(const variant<U1, U2, ..., UN> & operand);

    注释:

    		 语义与前一个构造函数相同, 但允许从临时对象构造. 
  9. template<typename U1, typename U2, ..., typename UN> 
  variant(variant<U1, U2, ..., UN> && operand);

    要求:

    		 兼容 C++11 的编译器.

    注释:

    		 语义与前一个构造函数相同, 但允许移动构造. 
  10. ~variant();

    效果:

    		 销毁 *this 的内容.

    抛出:

    		 不会抛出异常.

variant 修饰符

  1. void swap(variant & other);

    要求:

    		 每个有界类型都必须满足 MoveAssignable 概念的要求.

    效果:

    		 交换 *this 与 other 的内容.

    抛出:

    		 如果 other 所含类型与 *this 所含类型相同, 则可能因 swap (作用于 *this 与 other 的内容) 引发的任何异常而失败. 否则, 可能因所含类型的移动或复制构造函数之一引发的任何异常而失败. 此外, 在内存不足时, 可能因 std::bad_alloc 而失败 (为什么?) . 
  2. variant & operator=(const variant & rhs);

    要求:

    		 每个有界类型都必须满足 Assignable 概念的要求.

    效果:

    		 如果 rhs 所含类型与 *this 所含类型相同, 则把 rhs 的内容赋给 *this 的内容. 否则, 使 *this 的内容成为 rhs 内容的副本, 并销毁 *this 先前的内容.

    抛出:

    		 如果 rhs 所含类型与 *this 所含类型相同, 则可能因把 rhs 的内容赋给内容 *this 所引发的任何异常而失败. 否则, 可能因 rhs 所含类型的复制构造函数引发的任何异常而失败. 此外, 在内存不足时, 可能因 std::bad_alloc 而失败 (为什么?) . 
  3. variant & operator=(variant && rhs);

    要求:
    • 兼容 C++11 的编译器.
    • 每个有界类型都必须满足 MoveAssignable 概念的要求.

    效果:

    		 如果 rhs 所含类型与 *this 所含类型相同, 则把 rhs 的内容移动赋给 *this 的内容. 否则, 移动构造 *this, 使用 rhs 的内容, 并销毁 *this 先前的内容.

    抛出:

    		 如果 rhs 所含类型与 *this 所含类型相同, 则可能因把 rhs 的内容移动赋给内容 *this 所引发的任何异常而失败. 否则, 可能因 rhs 所含类型的移动构造函数引发的任何异常而失败. 此外, 在内存不足时, 可能因 std::bad_alloc 而失败 (为什么?) . 
  4. template<typename T> variant & operator=(const T & rhs);

    要求:
    • T 必须可无歧义地转换为某个有界类型 (即 T1、T2 等) .
    • 每个有界类型都必须满足 Assignable 概念的要求.

    效果:

    		 如果 *this 所含类型为 T, 则把 rhs 赋给 *this 的内容. 否则, 使 *this 的内容为 rhs 到某个有界类型的最佳转换 (由标准重载解析规则确定) , 并销毁 *this 先前的内容.

    抛出:

    		 如果 *this 所含类型为 T, 则可能因把 rhs 赋给内容 *this 所引发的任何异常而失败. 否则, 可能因 rhs 到某个有界类型的转换引发的任何异常而失败. 此外, 在内存不足时, 可能因 std::bad_alloc 而失败 (为什么?) . 
  5. template<typename T> variant & operator=(T && rhs);

    要求:
    • 兼容 C++11 的编译器.
    • rhs 是一个右值. 否则将使用前一个运算符.
    • T 必须可无歧义地转换为某个有界类型 (即 T1、T2 等) .
    • 每个有界类型都必须满足 MoveAssignable 概念的要求.

    效果:

    		 如果 *this 所含类型为 T, 则把 rhs 移动赋给 *this 的内容. 否则, 使 *this 的内容为 rhs 到某个有界类型的最佳转换 (由标准重载解析规则确定) , 并销毁 *this 先前的内容 (转换通常通过移动构造完成) .

    抛出:

    		 如果 *this 所含类型为 T, 则可能因把 rhs 移动赋给内容 *this 所引发的任何异常而失败. 否则, 可能因 rhs 到某个有界类型的转换引发的任何异常而失败. 此外, 在内存不足时, 可能因 std::bad_alloc 而失败 (为什么?) .

variant 查询

  1. int which() const;

    返回:

    		 *this 所含类型在有界类型集合中的从零起算的索引. (例如, 如果在一个 variant<int, std::string> 对象 (含一个 std::string) 上调用, which() 将返回 1. )

    抛出:

    		 不会抛出异常. 
  2. bool empty() const;

    返回:

    		 false: variant 总是恰好包含其有界类型之一. (更多信息参见 "Never-Empty" 保证 一节. )

    设计理由:

    		 提供与 boost::any 的泛型兼容性.

    抛出:

    		 不会抛出异常. 
  3. const std::type_info & type() const;

    注释:

    		 boost::variant 使用 Boost.TypeIndex 库, 因此实际返回的是 const boost::typeindex::type_info &. 即使关闭 RTTI, 此方法也可用.

    返回:

    		 typeid(x), 其中 x 是 *this 的内容.

    抛出:

    		 不会抛出异常.

variant 关系运算

  1. bool operator==(const variant & rhs) const;
template<typename U> void operator==(const U &) const;
    相等比较.

    注释:

    		 返回 void 的重载只是为了禁止把运算符的右侧隐式转换为 variant; 因此, 使用它会 (有意地) 导致编译期错误.

    要求:

    		 variant 的每个有界类型都必须满足 EqualityComparable 概念的要求.

    返回:

    		 true, 如果 which() == rhs.which() 且 content_this == content_rhs, 其中 content_this 是 *this 的内容, content_rhs 是 rhs 的内容.

    抛出:

    		 如果 which() == rhs.which(), 则可能因 operator==(T,T) 引发的任何异常而失败, 其中 T 是 *this 的所含类型. 
  2. bool operator!=(const variant & rhs) const;
template<typename U> void operator!=(const U &) const;
    不等比较.

    注释:

    		 返回 void 的重载只是为了禁止把运算符的右侧隐式转换为 variant; 因此, 使用它会 (有意地) 导致编译期错误.

    要求:

    		 variant 的每个有界类型都必须满足 EqualityComparable 概念的要求.

    返回:

    		 true, 如果 !(*this == rhs).

    抛出:

    		 如果 which() == rhs.which(), 则可能因 operator==(T,T) 引发的任何异常而失败, 其中 T 是 *this 的所含类型. 
  3. bool operator<(const variant & rhs) const;
template<typename U> void operator<(const U &) const;
    小于比较.

    注释:

    		 返回 void 的重载只是为了禁止把运算符的右侧隐式转换为 variant; 因此, 使用它会 (有意地) 导致编译期错误.

    要求:

    		 variant 的每个有界类型都必须满足 LessThanComparable 概念的要求.

    返回:

    		 如果 which() == rhs.which(), 则: content_this < content_rhs, 其中 content_this 是 *this 的内容, content_rhs 是 rhs 的内容. 否则: which() < rhs.which().

    抛出:

    		 如果 which() == rhs.which(), 则可能因 operator<(T,T) 引发的任何异常而失败, 其中 T 是 *this 的所含类型. 
  4. bool operator>(const variant & rhs) const;
template<typename U> void operator>(const U &) const;
    大于比较.

    注释:

    		 返回 void 的重载只是为了禁止把运算符的右侧隐式转换为 variant; 因此, 使用它会 (有意地) 导致编译期错误.

    要求:

    		 variant 的每个有界类型都必须满足 LessThanComparable 概念的要求.

    返回:

    		 如果 rhs < *this 则为 true.

    抛出:

    		 可能因 operator<(T,T) 引发的任何异常而失败, 其中 T 是 *this 的所含类型. 
  5. bool operator<=(const variant & rhs) const;
template<typename U> void operator<=(const U &) const;
    小于等于比较.

    注释:

    		 返回 void 的重载只是为了禁止把运算符的右侧隐式转换为 variant; 因此, 使用它会 (有意地) 导致编译期错误.

    要求:

    		 variant 的每个有界类型都必须满足 LessThanComparable 概念的要求.

    返回:

    		 如果 !(*this > rhs) 则为 true.

    抛出:

    		 可能因 operator<(T,T) 引发的任何异常而失败, 其中 T 是 *this 的所含类型. 
  6. bool operator>=(const variant & rhs) const;
template<typename U> void operator>=(const U &) const;
    大于等于比较.

    注释:

    		 返回 void 的重载只是为了禁止把运算符的右侧隐式转换为 variant; 因此, 使用它会 (有意地) 导致编译期错误.

    要求:

    		 variant 的每个有界类型都必须满足 LessThanComparable 概念的要求.

    返回:

    		 如果 !(*this < lhs) 则为 true.

    抛出:

    		 可能因 operator<(T,T) 引发的任何异常而失败, 其中 T 是 *this 的所含类型.
