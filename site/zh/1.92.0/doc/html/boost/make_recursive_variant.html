类模板 make_recursive_variant

boost::make_recursive_variant — 简化递归 variant 类型的声明.

概要

// In header: <boost/variant/recursive_variant.hpp>

template<typename T1, typename T2 = unspecified, ..., 
         typename TN = unspecified> 
class make_recursive_variant {
public:
  // types
  typedef boost::variant< unspecified > type;
};

说明

type 的行为在各方面等价于某个 variant< U1, U2, ..., UN >, 其中每个类型 Ui 都是相应类型 Ti 经过一个变换函数后的结果. 下面的伪代码描述了这个变换的行为 (称之为 substitute) :

  • 若 Ti 为 boost::recursive_variant_ 则: variant< U1, U2, ..., UN >;
  • 否则若 Ti 形如 X * 则: substitute(X) *;
  • 否则若 Ti 形如 X & 则: substitute(X) &;
  • 否则若 Ti 形如 R (*)( X1, X2, ..., XN ) 则: substitute(R) (*)( substitute(X1), substitute(X2), ..., substitute(XN) );
  • 否则若 Ti 形如 F < X1, X2, ..., XN > 则: F< substitute(X1), substitute(X2), ..., substitute(XN) >;
  • 否则: Ti.

注意 cv 限定符会被保留, 而且实际过程通常要更复杂一些. 不过, 上面的描述确实传达了其本质思想, 也说明了替换的范围.

make_recursive_variant 的用法在 "配合 make_recursive_variant 的递归类型" 一节中演示.

可移植性: 由于若干编译器存在标准符合性问题, make_recursive_variant 并非普遍受支持. 在这些编译器上, 该库通过定义预处理符号 BOOST_VARIANT_NO_FULL_RECURSIVE_VARIANT_SUPPORT 来表明缺乏支持.
