宏 BOOST_PROTO_typename_A

BOOST_PROTO_typename_A — 生成形如 typename A0, typename A1, … typename AN-1 的序列.

概要

// In header: <boost/proto/repeat.hpp>

BOOST_PROTO_typename_A(N)

说明

供 BOOST_PROTO_REPEAT() 与 BOOST_PROTO_LOCAL_ITERATE() 宏配合使用.

BOOST_PROTO_typename_A(N) 生成形如以下的序列:

typename A0, typename A1, … typename AN-1
