增广式 CRC 函数 

#include <boost/cstdint.hpp>  // for boost::uintmax_t
#include <boost/integer.hpp>  // for boost::uint_t
#include <cstddef>            // for std::size_t

namespace boost
{
    template < std::size_t Bits, uintmax_t TruncPoly >
    typename uint_t<Bits>::fast  augmented_crc( void const *buffer,
     std::size_t byte_count, typename uint_t<Bits>::fast initial_remainder
     = 0u  );
}

boost::augmented_crc 函数计算数据块的增广式 CRC. 与 boost::crc 一样, 前两个模板参数是 WIDTH 和 POLY. 不过, INIT 已改为函数参数, 位于数据块的起始地址和字节长度之后, 若未给出则默认为零.

该函数使用最原始的模 2 除法, 因此放弃了 REFIN, REFOUT 和 XOROUT 属性, 将它们设为 0 或 false. 与 boost::crc 的另一个区别是, 非零的 INIT 在与该函数一起使用时必须进行偏斜处理. (当前没有提供任何转换函数.)

augmented_crc 函数也可以从分布式数据计算 CRC:

unsigned  combined_acrc_16( int block_count, ... )
{
    using namespace std;

    va_list   ap;
    unsigned  result = 0u;

    va_start( ap, block_count );
    if ( block_count <= 0 )
        goto finish;

    void const *  bs = va_arg( ap, void const * );
    size_t        bl = va_arg( ap, size_t );

    result = boost::augmented_crc<16, 0x1021u>( bs, bl );
    while ( --block_count )
    {
        bs = va_arg( ap, void const * );
        bl = va_arg( ap, size_t );
        result = boost::augmented_crc<16, 0x1021u>( bs, bl, result );
    }

finish:
    va_end( ap );
    return result;
}

任何 CRC 操作都不会抛出异常, 因此在各变参宏调用之间不需要额外的保护. 由于没有输出反射或异或掩码, 把上一次运行的结果作为下一次运行的初始余数传入非常容易.

C 风格的可变参数例程是宏或可能是宏.

这些参数基于 boost::crc_xmodem_t.

由于 augmented_crc 不知道你的数据何时结束, 你必须提供增广内容, 即 WIDTH 个零位或预期的校验和. 增广内容可以放在最后一个数据块的末尾, 也可以通过一次额外的调用给出. 注意, 如果使用预期的校验和作为增广内容, 其位必须按大端顺序排列. 由于 augmented_crc 按字节读取, 而增广内容假定按位读取, 因此只有当 WIDTH 是每字节位数的倍数时, 增广才有效 (CHAR_BIT).
