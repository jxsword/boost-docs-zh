贡献者

Michael Barr mbarr@netrino.com

撰写了 “CRC Implementation Code in C” 一文, 是一篇不太令人困惑的 CRC 算法实现指南. (最初以 “Slow and Steady Never Lost the Race” 为题发表在 Embedded Systems Programming 2000 年 1 月刊第 37–46 页. 其网络版曾名为 Easier Said Than Done.)

Daryle Walker

发起本库, 并贡献了理论型与优化型 CRC 计算类模板以及 CRC 计算函数模板. 贡献了测试与示例代码.

Ross N. Williams

撰写了 A Painless Guide to CRC Error Detection Algorithms, 一份权威的 CRC 信息来源.
