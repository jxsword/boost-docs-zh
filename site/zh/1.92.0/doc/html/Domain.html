概念 Domain

Domain

说明

Domain 在表达式与所谓的生成器 (generator) 之间建立关联, 生成器是一个把默认域中的表达式映射为此 Domain 中等价表达式的函数. 它还把表达式与一个文法相关联, 此 Domain 中的所有表达式都必须符合该文法.

关联类型

  • proto_grammar

    Domain::proto_grammar

    此 Domain 中每个表达式都必须符合的文法.

  • proto_generator

    Domain::proto_generator

    一个一元多态函数, 接受默认域中的表达式并产生此 Domain 中的表达式.

  • proto_super_domain

    Domain::proto_super_domain

    作为此域的超级域 (super-domain) 的那个 Domain (如果存在这样的域). 如果不存在, 则它是某个未指明的类型.

  • result_type

    boost::result_of<Domain(Expr)>::type

    对指定表达式类型应用 proto_generator 所得结果的类型. 该结果必须建模 Expr. 与 result_type 相关联的域类型 (result_type::proto_domain) 必须与此 Domain 为同一类型.

  • as_expr_result_type

    Domain::as_expr<Object>::result_type

    把某个类型转换为此域中 Proto 表达式类型所得的结果. 例如, 在计算用于保存 Proto 表达式的变量类型时会用到它. as_expr_result_type 建模 Expr.

  • as_child_result_type

    Domain::as_child<Object>::result_type

    把某个类型转换为此域中 Proto 表达式类型所得的结果. 例如, 用于计算适合作为子节点存储在表达式树中的对象类型. as_child_result_type 建模 Expr.

记法

Domain
在 Domain 概念中扮演 domain-type 角色的类型.
Expr
在 Domain 概念中扮演 expression-type 角色的类型.
Object
在 Domain 概念中扮演 object-type 角色的类型.
d
Domain 类型的对象
e
Expr 类型的对象
o
Object 类型的对象

有效表达式

名称 表达式 类型 语义

应用生成器

d(e)

result_type

对指定表达式应用 proto_generator 所得的结果.

作为表达式

Domain::as_expr< Object >()(o)

as_expr_result_type

把某个对象转换为此域中的 Proto 表达式所得的结果. 它返回一个适合存储在变量中的 Proto 表达式对象. 它应返回一个新对象, 该对象可以是对传入对象的副本.

作为子节点

Domain::as_child< Object >()(o)

as_child_result_type

把某个对象转换为此域中的 Proto 表达式所得的结果. 它返回一个适合作为子节点存储在表达式树中的对象, 该对象可以只是对传入对象的引用.
