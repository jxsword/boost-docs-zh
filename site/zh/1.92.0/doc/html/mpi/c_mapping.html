从 C MPI 到 Boost.MPI 的映射

本节提供一些表格, 把标准 C MPI 的函数和常量映射到其 Boost.MPI 对应物. 对于已经熟悉 MPI 的 C 或 Fortran 接口的用户, 或者要把现有并行程序移植到 Boost.MPI 的用户, 这些表格最为有用.

注意, 这并不是完美的一对一映射: Boost.MPI 有时会以对最终用户透明的方式使用 C API 的函数. 例如, MPI_Probe and friends 可用于实现异步 send/recv.

Boost.MPI 不为 MPI 派生数据类型功能提供直接封装. 作为替代, Boost.MPI 依靠 Boost.Serialization 库为用户自定义类构造 MPI 数据类型. 用户自定义数据类型 一节描述了这一机制, 它用于通过 is_mpi_datatype 标记为 "MPI 数据类型" 的类型.

下面的派生数据类型表描述了哪些 C++ 类型对应 C MPI 数据类型构造器的功能. 在构建某种形式的数据类型时, Boost.MPI 实际上可能并不使用所列出的 C MPI 函数. 由于 Boost.MPI 构建的实际数据类型通常对用户是隐藏的, 这些操作中许多由 Boost.MPI 在内部调用.

MPI 的打包设施把值存入连续缓冲区, 之后可以通过 MPI 传输, 再通过 MPI 的解包设施解包为独立的值. 与数据类型一样, Boost.MPI 为 MPI 的打包和解包设施提供了一个抽象接口. 具体而言, 两个档案类 packed_oarchive 和 packed_iarchive 可用于使用 MPI 的设施对连续缓冲区进行打包或解包.

MPI 定义了几个特殊的通信器, 包括 MPI_COMM_WORLD(包含本地进程可与之通信的所有进程)、MPI_COMM_SELF(只包含本地进程)和 MPI_COMM_EMPTY(不包含任何进程). 这些特殊通信器都是 Boost.MPI 中 communicator 类的实例.
