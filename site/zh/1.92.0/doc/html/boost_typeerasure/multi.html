带多个参数的函数

(本节示例的源代码见 multi.cpp)

操作可以带多于一个的 any 实参. 我们以二元加法为例.

typedef any<
    mpl::vector<
        copy_constructible<>,
        typeid_<>,
        addable<>,
        ostreamable<>
    >
> any_type;
any_type x(10);
any_type y(7);
any_type z(x + y);
std::cout << z << std::endl; // prints 17

这 不是一个多方法 (multimethod). + 各实参的底层类型必须相同, 否则行为未定义. 本示例是正确的, 因为两个实参持有的都是 int.

注释

加上 relaxed 后, 若实参类型不对, 将抛出异常而不是产生未定义行为.

addable<> 要求各实参的类型完全相同. 但这并未覆盖加法的所有用法. 例如, 指针算术接受一个指针和一个整数并返回一个指针. 我们可以通过给每个相关类型指定一个占位符来捕捉多个类型之间的这种关系. 我们让占位符 _a 代表指针, 占位符 _b 代表整数.

int array[5];

typedef mpl::vector<
    copy_constructible<_a>,
    copy_constructible<_b>,
    typeid_<_a>,
    addable<_a, _b, _a>
> requirements;

我们的新概念 addable<_a, _b, _a> 捕捉了指针加法的规则: _a + _b -> _a.

此外, 我们不能再独立地捕捉这两个变量.

any<requirements, _a> ptr(&array[0]); // illegal

这行不通, 因为本库在捕捉概念绑定时需要知道 _b 绑定到的类型. 我们需要在构造 any 时指定两个占位符的绑定.

typedef mpl::map<mpl::pair<_a, int*>, mpl::pair<_b, int> > types;
any<requirements, _a> ptr(&array[0], make_binding<types>());
any<requirements, _b> idx(2, make_binding<types>());
any<requirements, _a> x(ptr + idx);
// x now holds array + 2

现在 + 的实参不再是同一类型, 我们要求两个实参都认同 _a 映射到 int*, 且 _b 映射到 int.

我们还可以使用 tuple 来避免显式写出映射. tuple 只是一个便利类, 它把它从所有实参得到的占位符绑定组合起来.

tuple<requirements, _a, _b> t(&array[0], 2);
any<requirements, _a> y(get<0>(t) + get<1>(t));
