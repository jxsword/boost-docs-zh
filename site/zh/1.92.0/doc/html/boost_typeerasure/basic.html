基本用法

(本节示例的源代码见 basic.cpp)

本库的主类是 any. any 可以存储满足我们指定的任意要求的对象. 这些要求以 MPL 序列的形式传给 any.

注释

MPL 序列组合了多个概念. 在只想要单个概念的罕见情形下, 无需用 MPL 序列包裹.

any<mpl::vector<copy_constructible<>, typeid_<>, relaxed> > x(10);
int i = any_cast<int>(x); // i == 10

copy_constructible 是一个内建概念, 允许我们复制和销毁对象. typeid_ 提供运行期类型信息, 使我们可以使用 any_cast. relaxed 启用了各种有用的默认行为. 若没有 relaxed, any 将 精确 只支持你所指定的内容, 此外别无其他. 特别是, 它允许对 any 进行默认构造和赋值.

现在, 这个示例做的事不多. x 大致等价于一个 boost::any. 我们可以通过添加一些运算符使它更有意思, 例如 operator++ 和 operator<<.

any<
    mpl::vector<
        copy_constructible<>,
        typeid_<>,
        incrementable<>,
        ostreamable<>
    >
> x(10);
++x;
std::cout << x << std::endl; // prints 11

本库为大多数 C++ 运算符提供了概念, 但这显然无法覆盖所有用例; 我们常常需要定义自己的要求. 我们以若干 STL 容器所定义的 push_back 成员为例.

BOOST_TYPE_ERASURE_MEMBER(push_back)

void append_many(any<has_push_back<void(int)>, _self&> container) {
    for(int i = 0; i < 10; ++i)
        container.push_back(i);
}

我们使用宏 BOOST_TYPE_ERASURE_MEMBER 来定义一个名为 has_push_back 的概念. 当使用 has_push_back 时, 必须告知它函数的签名 void(int). 这意味着我们存储在 any 中的类型必须有一个形如下面的成员:

void push_back(int);

因此, 我们可以调用 append_many, 其实参可用 std::vector<int>、std::list<int> 或 std::vector<long> (因为 int 可转换为 long), 但不能用 std::list<std::string> 或 std::set<int>.

另外, 注意 append_many 必须直接作用于其实参, 不能制作副本. 为处理这一点, 我们使用 _self& 作为 any 的第二个实参. _self 是一个 placeholder. 通过使用 _self&, 我们表明该 any 存储的是对外部对象的引用, 而不是分配自己的对象.

成员函数可以是 const 的.

BOOST_TYPE_ERASURE_MEMBER(empty)
bool is_empty(any<has_empty<bool() const>, const _self&> x) {
    return x.empty();
}

对于自由函数, 我们可以使用宏 BOOST_TYPE_ERASURE_FREE.

BOOST_TYPE_ERASURE_FREE(getline)
std::vector<std::string> read_lines(any<has_getline<bool(_self&, std::string&)>, _self&> stream)
{
    std::vector<std::string> result;
    std::string tmp;
    while(getline(stream, tmp))
        result.push_back(tmp);
    return result;
}

has_getline 的用法与上文中的 has_push_back 非常相似. 区别在于占位符 _self 是在函数签名中传入的, 而不是作为单独的实参.

placeholder 不必是第一个实参. 我们同样可以轻易地把它作为第二个实参.

void read_line(any<has_getline<bool(std::istream&, _self&)>, _self&> str)
{
    getline(std::cin, str);
}
