概念定义

概念 (Concept) 对存储在 any 中的类型定义了一组约束.

概念有三种.

  1. 本库定义了许多 预定义概念. 其中大多数等同于用户自定义概念, 但少数需要特殊处理.
  2. 用户可以按如下所述定义自己的原始概念. 宏 BOOST_TYPE_ERASURE_MEMBER 和 BOOST_TYPE_ERASURE_FREE 定义的就是这种形式的概念.
  3. 任何元素都是概念的 MPL Forward Sequence 也是一个概念. 这使得概念可以轻松组合.

每个原始概念定义一个函数. 原始概念必须是类模板的特化, 带有一个名为 apply 的静态成员函数, 当该函数由 call 分派时执行. 该模板只能接受模板类型参数, 不允许非类型模板参数和模板模板参数.

概念的模板参数可以涉及占位符. 以下情形会被考虑.

  • 每个模板实参可以是带 cv 限定和/或引用限定的占位符类型.
  • 若模板实参是函数类型, 则其参数和返回类型可以是带 cv/引用限定的占位符.

任何其他占位符都被忽略.

概念通过从原始值构造 any, 或通过构造 binding 来实例化. 当概念以一组特定的类型绑定实例化时, 每个占位符都绑定到一个无 cv 限定的非引用类型. 将模板实参列表中的每个占位符替换为其绑定的类型之后, 必须满足以下条件.

  • 绑定概念中 apply 的实参数量必须与未绑定概念中的实参数量相同.
  • 绑定概念中 apply 的实参和返回类型可以按如下方式从未绑定概念中对应的实参和返回类型推导得到: 若未绑定概念中的实参是带可选 cv 限定和引用限定的占位符, 则绑定概念中的实参可通过替换该占位符得到. 否则, 未绑定概念中的实参必须与绑定概念中的实参相同.
// Correct.
template<class T = _self>
struct foo1 {
  static void apply(const T& t) { t.foo(); }
};

// Wrong.  The signature of apply is different from the
// primary template
template<>
struct foo1<int> {
  static void apply(int i);
};

// Wrong.  A concept must be a template
struct foo2 {
  static void apply(const _self&);
};

// Wrong. apply must be static
template<class T = _self>
struct foo3 {
  void apply(const T&);
};

// Wrong.  apply cannot be overloaded
template<class T = _self>
struct foo3 {
  static void apply(T&);
  static void apply(const T&);
};

// Wrong.  Only top level placeholders are detected
template<class T>
struct foo4;
template<class T>
struct foo4<boost::mpl::vector<T> > {
  static void apply(const T&);
};

// Wrong.  Template template parameters are not allowed.
template<template<class> class T>
struct foo5
{
    static void apply(T<int>&);
};
