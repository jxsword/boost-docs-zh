引言

C++ 中的动态多态要求对象 (例如派生自抽象基类的类的实例) 通过间接指针访问, 因为在使用点无法得知它们实际的类型与大小. 因此, 常规容器无法直接存储多态对象: 通常的变通方法是使用指向堆上分配元素的指针的容器. 在现代计算机体系结构上, 这种模式会带来两类低效:

  • 堆分配造成的内存不连续会降低 CPU 缓存性能.
  • 对实际类型各不相同的多态对象序列执行虚操作, 会导致分支预测失败并降低执行速度.

当特定的遍历顺序对用户应用无关紧要时, Boost.PolyCollection 提出了一种替代数据结构, 它恢复内存连续性并按元素的具体类型进行打包. 本库提供四个容器类模板:

  • boost::base_collection
  • boost::function_collection
  • boost::any_collection
  • boost::variant_collection

分别处理 C++ 中可用的四种不同类型的动态多态:

  • 经典的基类/派生类 (OOP) 多态.
  • 以 std::function 精神进行的函数包装.
  • 所谓鸭子类型, 由 Boost.TypeErasure 实现.
  • 封闭多态, 即可接受类型的列表在编译期指定, 如 std::variant.

这些容器的接口紧贴标准容器的接口. 此外, 本库提供了许多标准库算法的版本 (包括 std::for_each), 具有更高的性能, 并提供一项称为类型复原的特殊功能, 允许用户代码就所存储元素的具体类型提供线索, 从而为内联与去虚化相关的效率提升创造更多机会.

注释

Boost.PolyCollection 是一个仅头文件库. 需要 C++11 支持. 该库已验证可在 Visual Studio 2015、GCC 4.8 与 Clang 3.5 上工作.
