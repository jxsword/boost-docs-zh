教程

基本技能

本节开头的教程程序介绍使用 asio 工具集所需的基本概念. 在深入网络编程的复杂世界之前, 这些教程程序使用简单的异步定时器讲解基本技能.

  • Timer.1 - 同步使用定时器
  • Timer.2 - 异步使用定时器
  • Timer.3 - 将参数绑定到完成处理器
  • Timer.4 - 将成员函数用作完成处理器
  • Timer.5 - 在多线程程序中同步完成处理器

套接字入门

本节的教程程序展示如何使用 asio 开发简单的客户端和服务器程序. 这些教程程序围绕同时支持 TCP 和 UDP 的 daytime 协议展开.

前三个教程程序使用 TCP 实现 daytime 协议.

  • Daytime.1 - 同步 TCP daytime 客户端
  • Daytime.2 - 同步 TCP daytime 服务器
  • Daytime.3 - 异步 TCP daytime 服务器

接下来三个教程程序使用 UDP 实现 daytime 协议.

  • Daytime.4 - 同步 UDP daytime 客户端
  • Daytime.5 - 同步 UDP daytime 服务器
  • Daytime.6 - 异步 UDP daytime 服务器

本节最后一个教程程序展示 asio 如何让 TCP 和 UDP 服务器轻松合并成一个程序.

  • Daytime.7 - TCP/UDP 组合异步服务器
