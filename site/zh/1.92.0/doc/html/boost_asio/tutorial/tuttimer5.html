Timer.5 - 在多线程程序中同步完成处理器

本教程演示在多线程程序中使用 strand 类模板同步完成处理器.

前四个教程通过只从一个线程调用 boost::asio::io_context::run() 函数来回避处理器同步问题. 如你所知, asio 库保证完成处理器只会从当前正在调用 boost::asio::io_context::run() 的线程中被调用. 因此, 只从一个线程调用 boost::asio::io_context::run() 就能确保完成处理器不会并发运行.

在使用 asio 开发应用程序时, 单线程方法通常是最好的起点. 其缺点是给程序 (尤其是服务器) 带来的限制, 包括:

  • 当处理器可能需要很长时间才能完成时, 响应性较差.
  • 无法在多处理器系统上扩展.

如果你发现程序遇到这些限制, 一种替代方法是让多个线程调用 boost::asio::io_context::run(). 然而, 由于这允许处理器并发执行, 当处理器可能访问共享的非线程安全资源时, 我们需要一种同步方法.

#include <functional>
#include <iostream>
#include <thread>
#include <boost/asio.hpp>

我们首先定义一个名为 printer 的类, 它与上一个教程中的类类似. 这个类将在上一个教程的基础上并行运行两个定时器.

class printer
{
public:

除了初始化一对 boost::asio::steady_timer 成员之外, 构造函数还初始化 strand_ 成员, 即一个 boost::asio::strand<boost::asio::io_context::executor_type> 类型的对象.

strand 类模板是一种执行器适配器, 它保证对于通过它分发的处理器, 正在执行的处理器会先完成, 下一个处理器才会开始. 无论有多少线程在调用 boost::asio::io_context::run(), 这一保证都成立. 当然, 这些处理器仍可能与未通过 strand 分发的处理器、或通过另一个 strand 对象分发的处理器并发执行.

  printer(boost::asio::io_context& io)
    : strand_(boost::asio::make_strand(io)),
      timer1_(io, boost::asio::chrono::seconds(1)),
      timer2_(io, boost::asio::chrono::seconds(1)),
      count_(0)
  {

发起异步操作时, 每个完成处理器都被"绑定"到一个 boost::asio::strand<boost::asio::io_context::executor_type> 对象. boost::asio::bind_executor() 函数返回一个新的处理器, 它自动通过 strand 对象分发其包含的处理器. 通过把处理器绑定到同一个 strand, 我们确保它们不会并发执行.

    timer1_.async_wait(boost::asio::bind_executor(strand_,
          std::bind(&printer::print1, this)));

    timer2_.async_wait(boost::asio::bind_executor(strand_,
          std::bind(&printer::print2, this)));
  }

  ~printer()
  {
    std::cout << "Final count is " << count_ << std::endl;
  }

在多线程程序中, 如果异步操作的处理器访问共享资源, 就应当对它们进行同步. 在本教程中, 处理器使用的共享资源 (print1 和 print2) 是 std::cout 和 count_ 数据成员.

  void print1()
  {
    if (count_ < 10)
    {
      std::cout << "Timer 1: " << count_ << std::endl;
      ++count_;

      timer1_.expires_at(timer1_.expiry() + boost::asio::chrono::seconds(1));

      timer1_.async_wait(boost::asio::bind_executor(strand_,
            std::bind(&printer::print1, this)));
    }
  }

  void print2()
  {
    if (count_ < 10)
    {
      std::cout << "Timer 2: " << count_ << std::endl;
      ++count_;

      timer2_.expires_at(timer2_.expiry() + boost::asio::chrono::seconds(1));

      timer2_.async_wait(boost::asio::bind_executor(strand_,
            std::bind(&printer::print2, this)));
    }
  }

private:
  boost::asio::strand<boost::asio::io_context::executor_type> strand_;
  boost::asio::steady_timer timer1_;
  boost::asio::steady_timer timer2_;
  int count_;
};

main 函数现在使 boost::asio::io_context::run() 从两个线程被调用: 主线程和一个额外线程. 这是通过一个 boost::thread 对象实现的.

与单线程调用时一样, 只要还有"工作"要做, 对 boost::asio::io_context::run() 的并发调用就会继续执行. 后台线程直到所有异步操作完成才退出.

int main()
{
  boost::asio::io_context io;
  printer p(io);
  std::thread t([&]{ io.run(); });
  io.run();
  t.join();

  return 0;
}
