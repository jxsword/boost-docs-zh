Timer.1 - 同步使用定时器

本教程程序通过展示如何对定时器执行阻塞等待来介绍 asio.

我们从包含必要的头文件开始.

只需包含 "asio.hpp" 头文件, 即可使用所有 asio 类.

#include <iostream>
#include <boost/asio.hpp>

所有使用 asio 的程序都至少需要一个 I/O 执行上下文, 例如 io_context 或 thread_pool 对象. I/O 执行上下文提供对 I/O 功能的访问. 我们在 main 函数的开头声明一个 io_context 类型的对象.

int main()
{
  boost::asio::io_context io;

接下来我们声明一个 boost::asio::steady_timer 类型的对象. 提供 I/O 功能 (本例中是定时器功能) 的 asio 核心类总是以执行器或执行上下文 (如 io_context) 的引用作为其第一个构造函数参数. 构造函数的第二个参数把定时器的到期时间设为从现在起 5 秒.

  boost::asio::steady_timer t(io, boost::asio::chrono::seconds(5));

在这个简单示例中, 我们对定时器执行阻塞等待. 也就是说, 对 steady_timer::wait() 的调用不会返回, 直到定时器到期, 即定时器创建 5 秒后 (而不是从等待开始时算起).

定时器总是处于两种状态之一: "已到期" 或 "未到期". 如果在已到期的定时器上调用 steady_timer::wait() 函数, 它将立即返回.

  t.wait();

最后我们打印必不可少的 "Hello, world!" 消息, 以显示定时器何时到期.

  std::cout << "Hello, world!" << std::endl;

  return 0;
}
