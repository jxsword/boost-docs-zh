Timer.4 - 将成员函数用作完成处理器

在本教程中, 我们将了解如何把类成员函数用作完成处理器. 程序的执行结果应与教程 Timer.3 中的程序完全相同.

#include <functional>
#include <iostream>
#include <boost/asio.hpp>

与前面的教程程序中把自由函数 print 定义为完成处理器不同, 现在我们定义一个名为 printer 的类.

class printer
{
public:

该类的构造函数将接受 io_context 对象的引用, 并在初始化 timer_ 成员时使用它. 用于关闭程序的计数器现在也是该类的成员.

  printer(boost::asio::io_context& io)
    : timer_(io, boost::asio::chrono::seconds(1)),
      count_(0)
  {

函数 std::bind 对类成员函数和自由函数同样适用. 由于所有非静态类成员函数都有一个隐式的 this 参数, 我们需要把 this 绑定到函数. 与教程 Timer.3 一样, std::bind 把我们的完成处理器 (现在是成员函数) 转换为一个函数对象, 可以像它具有签名 void(const boost::system::error_code&) 一样来调用.

你会注意到这里没有指定 boost::asio::placeholders::error 占位符, 因为 print 成员函数不接受错误对象作为参数.

    timer_.async_wait(std::bind(&printer::print, this));
  }

在类的析构函数中, 我们将打印计数器的最终值.

  ~printer()
  {
    std::cout << "Final count is " << count_ << std::endl;
  }

print 成员函数与教程 Timer.3 中的 print 函数非常相似, 区别在于它现在操作类的数据成员, 而不是把定时器和计数器作为参数传入.

  void print()
  {
    if (count_ < 5)
    {
      std::cout << count_ << std::endl;
      ++count_;

      timer_.expires_at(timer_.expiry() + boost::asio::chrono::seconds(1));
      timer_.async_wait(std::bind(&printer::print, this));
    }
  }

private:
  boost::asio::steady_timer timer_;
  int count_;
};

main 函数比之前简单得多, 它现在先声明一个局部 printer 对象, 然后照常运行 io_context.

int main()
{
  boost::asio::io_context io;
  printer p(io);
  io.run();

  return 0;
}
