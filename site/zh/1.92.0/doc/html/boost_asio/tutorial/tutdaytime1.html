Daytime.1 - 同步 TCP daytime 客户端

本教程程序展示如何使用 asio 实现 TCP 客户端应用程序.

我们从包含必要的头文件开始.

#include <array>
#include <iostream>
#include <boost/asio.hpp>

本应用程序的目的是访问 daytime 服务, 因此我们需要用户指定服务器.

using boost::asio::ip::tcp;

int main(int argc, char* argv[])
{
  try
  {
    if (argc != 2)
    {
      std::cerr << "Usage: client <host>" << std::endl;
      return 1;
    }

所有使用 asio 的程序都至少需要一个 I/O 执行上下文, 例如 io_context 对象.

    boost::asio::io_context io_context;

我们需要把作为应用程序参数指定的服务器名转换为 TCP 端点. 为此, 我们使用 ip::tcp::resolver 对象.

    tcp::resolver resolver(io_context);

解析器接收主机名和服务名, 并将其转换为端点列表. 我们使用服务器名执行一次 resolve 调用, 服务器名在 argv[1] 中指定, 服务名在此处为 "daytime".

端点列表通过 ip::tcp::resolver::results_type 类型的对象返回. 该对象是一个范围 (range), 具有 begin() 和 end() 成员函数, 可用于遍历结果.

    tcp::resolver::results_type endpoints =
      resolver.resolve(argv[1], "daytime");

现在我们创建并连接套接字. 上面获得的端点列表可能同时包含 IPv4 和 IPv6 端点, 因此我们需要逐个尝试, 直到找到可用的端点. 这样客户端程序就不依赖于特定的 IP 版本. boost::asio::connect() 函数会自动为我们完成这一工作.

    tcp::socket socket(io_context);
    boost::asio::connect(socket, endpoints);

连接已打开. 现在我们只需从 daytime 服务读取响应.

我们使用 std::array 来保存接收到的数据. boost::asio::buffer() 函数会自动确定数组的大小, 以帮助防止缓冲区溢出. 除了 std::array, 我们也可以使用 char [] 或 std::vector.

    for (;;)
    {
      std::array<char, 128> buf;
      boost::system::error_code error;

      size_t len = socket.read_some(boost::asio::buffer(buf), error);

当服务器关闭连接时, ip::tcp::socket::read_some() 函数将以 boost::asio::error::eof 错误退出, 我们由此知道该退出循环.

      if (error == boost::asio::error::eof)
        break; // Connection closed cleanly by peer.
      else if (error)
        throw boost::system::system_error(error); // Some other error.

      std::cout.write(buf.data(), len);
    }

最后, 处理可能抛出的任何异常.

  }
  catch (std::exception& e)
  {
    std::cerr << e.what() << std::endl;
  }
