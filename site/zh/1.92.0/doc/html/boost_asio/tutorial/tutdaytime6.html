    udp_server server(io_context);

构造函数初始化一个套接字, 使其监听 UDP 端口 13.

  udp_server(boost::asio::io_context& io_context)
    : socket_(io_context, udp::endpoint(udp::v4(), 13))

    start_receive();

private:
  void start_receive()
  {

函数 ip::udp::socket::async_receive_from() 会使应用程序在后台监听新请求. 当收到这样的请求时, io_context 对象将以两个实参调用 handle_receive() 函数: 一个 boost::system::error_code 类型的值, 指示操作成功还是失败; 以及一个 size_t 值 bytes_transferred, 指明接收的字节数.

    socket_.async_receive_from(
        boost::asio::buffer(recv_buffer_), remote_endpoint_,
        std::bind(&udp_server::handle_receive, this,
          boost::asio::placeholders::error,
          boost::asio::placeholders::bytes_transferred));
  }

函数 handle_receive() 将为客户端请求提供服务.

  void handle_receive(const boost::system::error_code& error,
      std::size_t /*bytes_transferred*/)
  {

error 参数包含异步操作的结果. 由于我们只提供 1 字节的 recv_buffer_ 来容纳客户端的请求, 如果客户端发送更大的内容, io_context 对象会返回错误. 如果出现这样的错误, 我们可以忽略.

    if (!error)
    {

确定要发送的内容.

      std::shared_ptr<std::string> message(
          new std::string(make_daytime_string()));

现在我们调用 ip::udp::socket::async_send_to() 向客户端提供数据.

      socket_.async_send_to(boost::asio::buffer(*message), remote_endpoint_,
          std::bind(&udp_server::handle_send, this, message,
            boost::asio::placeholders::error,
            boost::asio::placeholders::bytes_transferred));

发起异步操作时, 如果使用 std::bind, 则只能指定与处理器参数列表匹配的实参. 在本程序中, 两个实参占位符 (boost::asio::placeholders::error 和 boost::asio::placeholders::bytes_transferred) 本可以都移除.

开始监听下一个客户端请求.

      start_receive();

此客户端请求的后续操作现在由 handle_send() 负责.

    }
  }
