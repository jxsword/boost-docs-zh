Timer.3 - 将参数绑定到完成处理器

在本教程中, 我们将修改教程 Timer.2 中的程序, 使定时器每秒触发一次. 这将展示如何向处理器函数传递额外参数.

#include <functional>
#include <iostream>
#include <boost/asio.hpp>

要使用 asio 实现重复定时器, 你需要在完成处理器中修改定时器的到期时间, 然后启动新的异步等待. 显然, 这意味着完成处理器需要能够访问定时器对象. 为此, 我们给 print 函数添加两个新参数:

  • 一个指向定时器对象的指针; 以及
  • 一个计数器, 以便在定时器第六次触发时停止程序

在参数列表末尾.

void print(const boost::system::error_code& /*e*/,
    boost::asio::steady_timer* t, int* count)
{

如上所述, 本教程程序使用一个计数器在定时器第六次触发时停止运行. 然而你会注意到, 程序没有显式调用要求 io_context 停止. 回想教程 Timer.2 中我们学到: 当没有更多"工作"要做时, boost::asio::io_context::run() 函数即完成. 当 count 达到 5 时不启动定时器的新异步等待, io_context 就会耗尽工作并停止运行.

  if (*count < 5)
  {
    std::cout << *count << std::endl;
    ++(*count);

接下来我们把定时器的到期时间从上一个到期时间顺延一秒. 通过相对于旧到期时间计算新到期时间, 我们可以确保定时器不会因处理处理器的任何延迟而偏离整秒刻度.

    t->expires_at(t->expiry() + boost::asio::chrono::seconds(1));

然后我们在定时器上启动新的异步等待. 如你所见, 函数 std::bind 用于把额外参数与你的完成处理器关联起来. steady_timer::async_wait() 函数期望具有签名 void(const boost::system::error_code&) 的处理器函数 (或函数对象). 绑定额外参数会把你的 print 函数转换为一个与该签名正确匹配的函数对象.

在本例中, std::bind 的 boost::asio::placeholders::error 实参是传递给处理器的错误对象的具名占位符. 发起异步操作时, 如果使用 std::bind, 则只能指定与处理器参数列表匹配的实参. 在教程 Timer.4 中你会看到, 若完成处理器不需要该参数, 此占位符可以省略.

    t->async_wait(std::bind(print,
          boost::asio::placeholders::error, t, count));
  }
}

int main()
{
  boost::asio::io_context io;

新增了 count 变量, 以便在定时器第六次触发时停止程序.

  int count = 0;
  boost::asio::steady_timer t(io, boost::asio::chrono::seconds(1));

与第 4 步一样, 从 steady_timer::async_wait() 中调用 main 时, 我们为 print 函数绑定了所需的额外参数.

  t.async_wait(std::bind(print,
        boost::asio::placeholders::error, &t, &count));

  io.run();

最后, 为证明 count 变量确实在 print 处理器函数中使用, 我们将打印它的新值.

  std::cout << "Final count is " << count << std::endl;

  return 0;
}
