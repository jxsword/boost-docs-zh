Daytime.2 - 同步 TCP daytime 服务器

本教程程序展示如何使用 asio 实现 TCP 服务器应用程序.

#include <ctime>
#include <iostream>
#include <string>
#include <boost/asio.hpp>

using boost::asio::ip::tcp;

我们定义函数 make_daytime_string() 来创建要发回给客户端的字符串. 该函数将在我们所有的 daytime 服务器应用程序中复用.

std::string make_daytime_string()
{
  using namespace std; // For time_t, time and ctime;
  time_t now = time(0);
  return ctime(&now);
}

int main()

    boost::asio::io_context io_context;

需要创建一个 ip::tcp::acceptor 对象来监听新连接. 它被初始化为监听 IP 版本 4 的 TCP 端口 13.

    tcp::acceptor acceptor(io_context, tcp::endpoint(tcp::v4(), 13));

这是一个迭代服务器, 也就是说它一次处理一个连接. 创建一个表示与客户端连接的套接字, 然后等待连接.

    for (;;)
    {
      tcp::socket socket(io_context);
      acceptor.accept(socket);

客户端正在访问我们的服务. 确定当前时间, 并把该信息传递给客户端.

      std::string message = make_daytime_string();

      boost::system::error_code ignored_error;
      boost::asio::write(socket, boost::asio::buffer(message), ignored_error);
    }
  }

最后, 处理任何异常.

  catch (std::exception& e)
  {
    std::cerr << e.what() << std::endl;
  }

  return 0;
}
