Daytime.3 - 异步 TCP daytime 服务器

main() 函数 
int main()
{
  try
  {

我们需要创建一个服务器对象来接受传入的客户端连接. io_context 对象提供服务器对象将使用的 I/O 服务 (如套接字).

    boost::asio::io_context io_context;
    tcp_server server(io_context);

运行 io_context 对象, 让它代表你执行异步操作.

    io_context.run();
  }
  catch (std::exception& e)
  {
    std::cerr << e.what() << std::endl;
  }

  return 0;
}
tcp_server 类 
class tcp_server
{
public:

构造函数初始化一个接受器, 使其监听 TCP 端口 13.

  tcp_server(boost::asio::io_context& io_context)
    : io_context_(io_context),
      acceptor_(io_context, tcp::endpoint(tcp::v4(), 13))
  {
    start_accept();
  }

private:

函数 start_accept() 创建套接字并启动异步接受操作以等待新连接.

  void start_accept()
  {
    tcp_connection::pointer new_connection =
      tcp_connection::create(io_context_);

    acceptor_.async_accept(new_connection->socket(),
        std::bind(&tcp_server::handle_accept, this, new_connection,
          boost::asio::placeholders::error));
  }

当 handle_accept() 发起的异步接受操作完成时, 会调用函数 start_accept(). 它为客户端请求提供服务, 然后调用 start_accept() 启动下一个接受操作.

  void handle_accept(tcp_connection::pointer new_connection,
      const boost::system::error_code& error)
  {
    if (!error)
    {
      new_connection->start();
    }

    start_accept();
  }
tcp_connection 类

我们将使用 shared_ptr 和 enable_shared_from_this, 因为我们希望只要有操作引用 tcp_connection 对象, 就让它保持存活.

class tcp_connection
  : public std::enable_shared_from_this<tcp_connection>
{
public:
  typedef std::shared_ptr<tcp_connection> pointer;

  static pointer create(boost::asio::io_context& io_context)
  {
    return pointer(new tcp_connection(io_context));
  }

  tcp::socket& socket()
  {
    return socket_;
  }

在函数 start() 中, 我们调用 boost::asio::async_write() 向客户端提供数据. 注意, 我们使用的是 boost::asio::async_write() 而非 ip::tcp::socket::async_write_some() 以确保整个数据块被发送.

  void start()
  {

要发送的数据存储在类成员 message_ 中, 因为我们需要保证数据在异步操作完成之前保持有效.

    message_ = make_daytime_string();

发起异步操作时, 如果使用 std::bind, 则只能指定与处理器参数列表匹配的实参. 在本程序中, 两个实参占位符 (boost::asio::placeholders::error 和 boost::asio::placeholders::bytes_transferred) 本可以都移除, 因为它们没有在 handle_write() 中使用.

    boost::asio::async_write(socket_, boost::asio::buffer(message_),
        std::bind(&tcp_connection::handle_write, shared_from_this(),
          boost::asio::placeholders::error,
          boost::asio::placeholders::bytes_transferred));

此客户端连接的后续操作现在由 handle_write() 负责.

  }

private:
  tcp_connection(boost::asio::io_context& io_context)
    : socket_(io_context)
  {
  }

  void handle_write(const boost::system::error_code& /*error*/,
      size_t /*bytes_transferred*/)
  {
  }

  tcp::socket socket_;
  std::string message_;
};
移除未使用的处理器参数

你可能已经注意到, error 和 bytes_transferred 参数没有在 handle_write() 函数体中使用. 如果不需要参数, 可以把它们从函数中移除, 使其看起来像:

void handle_write()
{
}

然后, 用于发起调用的 boost::asio::async_write() 调用可以改为仅仅:

boost::asio::async_write(socket_, boost::asio::buffer(message_),
    std::bind(&tcp_connection::handle_write, shared_from_this()));
