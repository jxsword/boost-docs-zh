Timer.2 - 异步使用定时器

本教程程序通过修改教程 Timer.1 中的程序使其对定时器执行异步等待, 演示如何使用 asio 的异步功能.

#include <iostream>
#include <boost/asio.hpp>

使用 asio 的异步功能意味着提供一个 完成标记, 它决定结果如何交付给 完成处理器 (当 异步操作 完成时). 在本程序中, 我们定义一个名为 print 的函数, 在异步等待结束时调用.

void print(const boost::system::error_code& /*e*/)
{
  std::cout << "Hello, world!" << std::endl;
}

int main()
{
  boost::asio::io_context io;

  boost::asio::steady_timer t(io, boost::asio::chrono::seconds(5));

接下来, 与教程 Timer.1 中的阻塞等待不同, 我们调用 steady_timer::async_wait() 函数执行异步等待. 调用该函数时, 我们传入上面定义的 print 函数.

  t.async_wait(&print);

最后, 我们必须对 io_context 对象调用 boost::asio::io_context::run() 成员函数.

asio 库保证完成处理器只会从当前正在调用 boost::asio::io_context::run() 的线程中被调用. 因此, 如果不调用 boost::asio::io_context::run() 函数, 异步等待完成时的完成处理器将永远不会被调用.

只要还有"工作"要做, boost::asio::io_context::run() 函数也会继续运行. 在本例中, 工作是定时器上的异步等待, 因此该调用直到定时器到期且完成处理器返回后才会返回.

必须记住, 在调用 boost::asio::io_context::run() 之前要先给 io_context 一些工作去做. 例如, 如果省略上面对 steady_timer::async_wait() 的调用, io_context 就没有任何工作可做, 因而 boost::asio::io_context::run() 会立即返回.

  io.run();

  return 0;
}
