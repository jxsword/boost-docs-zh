Daytime.4 - 同步 UDP daytime 客户端

本教程程序展示如何使用 asio 实现 UDP 客户端应用程序.

#include <array>
#include <iostream>
#include <boost/asio.hpp>

using boost::asio::ip::udp;

应用程序的开头与 TCP daytime 客户端基本相同.

int main(int argc, char* argv[])
{
  try
  {
    if (argc != 2)
    {
      std::cerr << "Usage: client <host>" << std::endl;
      return 1;
    }

    boost::asio::io_context io_context;

我们使用 ip::udp::resolver 对象, 根据主机名和服务名找到要使用的正确远程端点. 通过 ip::udp::v4() 实参, 查询被限定为只返回 IPv4 端点.

    udp::resolver resolver(io_context);
    udp::endpoint receiver_endpoint =
      *resolver.resolve(udp::v4(), argv[1], "daytime").begin();

函数 ip::udp::resolver::resolve() 保证在不失败的情况下至少返回一个端点. 这意味着可以直接对返回值解引用.

由于 UDP 是面向数据报的, 我们不会使用流套接字. 创建一个 ip::udp::socket 并发起与远程端点的联系.

    udp::socket socket(io_context);
    socket.open(udp::v4());

    std::array<char, 1> send_buf  = {{ 0 }};
    socket.send_to(boost::asio::buffer(send_buf), receiver_endpoint);

现在我们需要准备好接收服务器发回给我们的任何内容. 我方接收服务器响应的端点将由 ip::udp::socket::receive_from() 初始化.

    std::array<char, 128> recv_buf;
    udp::endpoint sender_endpoint;
    size_t len = socket.receive_from(
        boost::asio::buffer(recv_buf), sender_endpoint);

    std::cout.write(recv_buf.data(), len);
  }

最后, 处理可能抛出的任何异常.

  catch (std::exception& e)
  {
    std::cerr << e.what() << std::endl;
  }

  return 0;
}
