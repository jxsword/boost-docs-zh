比较两个执行器是否相等.

系统执行器表示一种执行上下文, 其中允许函数在任意线程上运行. 当建立 blocking.never 属性时, 系统执行器会将函数调度到某个未指定的系统线程池上运行. 当建立 blocking.possibly 或 blocking.always 属性时, 执行器会立即调用该函数.
