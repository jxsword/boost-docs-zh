write

write 函数是一个组合操作, 在返回之前向流写入一定数量的数据.

在返回之前, 向流写入所提供的全部数据.

template<
    typename SyncWriteStream,
    typename ConstBufferSequence>
std::size_t write(
    SyncWriteStream & s,
    const ConstBufferSequence & buffers,
    constraint_t< is_const_buffer_sequence< ConstBufferSequence >::value >  = 0);
