dynamic_string_buffer

把 basic_string 适配到 DynamicBuffer 要求.

template<
    typename Elem,
    typename Traits,
    typename Allocator>
class dynamic_string_buffer
类型

名称

说明

const_buffers_type

用于表示引用底层内存的常量缓冲区序列的类型.

mutable_buffers_type

用于表示引用底层内存的可变缓冲区序列的类型.
成员函数

名称

说明

capacity

获取缓冲区在不触发重新分配的情况下可以增长到的最大大小.

commit

DynamicBuffer_v1: 把字节从输出序列移到输入序列.

consume

DynamicBuffer_v1: 从输入序列中移除字符. DynamicBuffer_v2: 从底层内存的开头消耗指定数量的字节.

data

DynamicBuffer_v1: 获取表示输入序列的缓冲区列表.
—
DynamicBuffer_v2: 获取表示底层内存的缓冲区序列.

dynamic_string_buffer [constructor]

从 string 构造一个动态缓冲区.
—
DynamicBuffer_v2: 复制构造一个动态缓冲区.
—
移动构造一个动态缓冲区.

grow

DynamicBuffer_v2: 把底层内存增长指定的字节数.

max_size

获取动态缓冲区的最大大小.

prepare

DynamicBuffer_v1: 获取表示输出序列的缓冲区列表, 其大小为给定值.

shrink

DynamicBuffer_v2: 把底层内存收缩指定的字节数.

size

DynamicBuffer_v1: 获取输入序列的大小. DynamicBuffer_v2: 获取底层内存的当前大小.

要求 sizeof(Elem) == 1.

要求

头文件: boost/asio/buffer.hpp

便捷头文件: boost/asio.hpp
