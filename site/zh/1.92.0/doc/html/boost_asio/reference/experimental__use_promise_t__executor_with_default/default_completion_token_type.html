experimental::use_promise_t::executor_with_default::default_completion_token_type

指定 use_promise_t 作为默认完成标记类型.

typedef use_promise_t< Allocator > default_completion_token_type;
类型

名称

说明

allocator_type

分配器类型. 该分配器用于为给定的异步操作构造 promise 对象.

executor_with_default

适配一个执行器, 把 use_promise_t 完成标记添加为默认完成标记.
成员函数

名称

说明

as_default_on [static]

用于把 I/O 对象适配为以 use_promise_t 作为默认完成标记类型的函数辅助工具.

get_allocator

获取分配器.

rebind

指定一个替代分配器.

use_promise_t [constructor]

使用默认构造的分配器构造.
—
使用指定的分配器构造.
要求

头文件: boost/asio/experimental/use_promise.hpp

便捷头文件: 无
