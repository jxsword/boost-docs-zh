execution::inline_exception_handling_t

一种属性, 描述执行器对被提交函数在 execute 中内联执行时抛出的异常的处理方式作出何种保证.

struct inline_exception_handling_t
类型

名称

说明

capture_t

指示如果被提交函数对象被内联执行, 调用执行器的执行函数将捕获其抛出的任何异常的子属性. 捕获的异常会被转发给执行器定义的处理机制.

propagate_t

指示如果被提交函数对象被内联执行, 调用执行器的执行函数将传播其抛出的任何异常的子属性.

terminate_t

指示如果被提交函数对象被内联执行, 调用执行器的执行函数将在其抛出异常时终止程序的子属性.

polymorphic_query_result_type
