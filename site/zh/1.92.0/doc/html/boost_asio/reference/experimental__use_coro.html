experimental::use_coro

一个 完成标记 对象, 表示当前正在执行的可恢复协程.

constexpr use_coro_t use_coro;

用法示例参见 boost::asio::use_coro_t 的文档.

要求

头文件: boost/asio/experimental/use_coro.hpp

便捷头文件: 无
