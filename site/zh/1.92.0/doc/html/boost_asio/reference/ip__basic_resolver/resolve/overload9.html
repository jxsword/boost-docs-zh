ip::basic_resolver::resolve (10 个重载中的第 9 个)

对端点执行反向解析, 得到条目列表.

results_type resolve(
    const endpoint_type & e);

此函数用于将一个端点解析为端点条目列表.

参数

e

确定将返回哪些端点的端点对象.

返回值

表示端点条目列表的范围对象. 成功调用此函数保证返回非空范围.

异常

boost::system::system_error

失败时抛出.
