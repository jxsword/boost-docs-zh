ip::basic_resolver::async_resolve (5 个重载中的第 5 个)

对端点执行异步反向解析, 得到条目列表.

template<
    typename ResolveToken = default_completion_token_t<executor_type>>
DEDUCED async_resolve(
    const endpoint_type & e,
    ResolveToken && token = default_completion_token_t< executor_type >());

此函数用于将一个端点异步解析为端点条目列表. 它是 异步操作 的发起函数, 并且总是立即返回.

参数

e

确定将返回哪些端点的端点对象.

token

用于产生完成处理器的 完成标记, 该处理器会在解析完成时被调用. 可用的完成标记包括 use_future, use_awaitable, yield_context, 或具有正确完成签名的函数对象. 完成处理器的函数签名必须是:

void handler(
  const boost::system::error_code& error, // Result of operation.
  resolver::results_type results // Resolved endpoints as a range.
);

无论异步操作是否立即完成, 完成处理器都不会在此函数内部被调用. 若立即完成, 将以等同于使用 async_immediate 的方式调用处理器.

成功的解析操作保证会向处理器传递一个非空范围.

完成签名 
void(boost::system::error_code, results_type)
