ip::basic_resolver_results 类模板用于为解析器返回的结果定义一个范围.

解引用结果迭代器所得到的迭代器 value_type 为:

const basic_resolver_entry<InternetProtocol>
备注

为向后兼容, ip::basic_resolver_results 派生自 ip::basic_resolver_iterator. 此派生关系已弃用.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

要求

头文件: boost/asio/ip/basic_resolver.hpp

便捷头文件: boost/asio.hpp
