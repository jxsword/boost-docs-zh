defer (7 个重载中的第 2 个)

提交一个完成标记或函数对象以供执行.

template<
    typename Executor,
    typename NullaryToken = default_completion_token_t<Executor>>
auto defer(
    const Executor & ex,
    NullaryToken && token = default_completion_token_t< Executor >(),
    constraint_t<(execution::is_executor< Executor >::value &&can_require< Executor, execution::blocking_t::never_t >::value)||is_executor< Executor >::value >  = 0);

此函数使用指定的执行器提交对象以供执行. 函数对象会排队等待执行, 并且在从 defer() 返回之前绝不会从当前线程调用.

使用 defer() 而不是 post, 表示调用者希望执行器延迟函数对象的排队. 当函数对象表示当前调用上下文的延续时, 这可以让执行器优化排队.

参数

ex

目标执行器.

token

将用于产生完成处理器的 完成标记. 完成处理器的函数签名必须为:

void handler();
返回值

此函数返回 async_initiate<NullaryToken, void()>(Init{ex}, token), 其中 Init 是一个定义如下的函数对象类型:

class Init
{
public:
  using executor_type = Executor;
  explicit Init(const Executor& ex) : ex_(ex) {}
  executor_type get_executor() const noexcept { return ex_; }
  template <typename CompletionHandler>
    void operator()(CompletionHandler&& completion_handler) const;
private:
  Executor ex_; // exposition only
};

函数调用运算符: Init:

  • 通过执行以下操作, 获取处理器关联的执行器对象 ex1 (类型为 Ex1):

    auto ex1 = get_associated_executor(completion_handler, ex);

  • 通过执行以下操作, 获取处理器关联的分配器对象 alloc:

    auto alloc = get_associated_allocator(completion_handler);

  • 如果 execution::is_executor<Ex1>::value 为 true, 则构造一个函数对象 f, 它带有成员 executor_ (以 prefer(ex1, execution::outstanding_work.tracked) 初始化)、成员 handler_ (是 completion_handler 的 decay 拷贝), 以及一个执行以下操作的函数调用运算符:

    auto a = get_associated_allocator(handler_); prefer(executor_, execution::allocator(a)).execute(std::move(handler_));

  • 如果 execution::is_executor<Ex1>::value 为 false, 则构造一个函数对象 f, 它带有成员 work_ (以 make_work_guard(ex1) 初始化)、成员 handler_ (是 completion_handler 的 decay 拷贝), 以及一个执行以下操作的函数调用运算符:

    auto a = get_associated_allocator(handler_); work_.get_executor().dispatch(std::move(handler_), a); work_.reset();

  • 如果 execution::is_executor<Executor>::value 为 true, 则执行

    prefer( require(ex, execution::blocking.never), execution::relationship.continuation, execution::allocator(alloc) ).execute(std::move(f));

  • 如果 execution::is_executor<Executor>::value 为 false, 则执行

    ex.defer(std::move(f), alloc);
