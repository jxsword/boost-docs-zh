basic_socket_iostream::expires_at

以绝对时间设置流的到期时间.

void expires_at(
    const time_point & expiry_time);

此函数设置与流关联的到期时间. 在此时间之后执行的流操作(无法使用内部缓冲区完成的操作)将以错误 boost::asio::error::operation_aborted 失败.

参数

expiry_time

要用于流的到期时间.
