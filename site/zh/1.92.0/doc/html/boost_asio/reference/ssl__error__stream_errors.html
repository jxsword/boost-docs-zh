ssl::error::stream_errors 

enum stream_errors

取值

stream_truncated

在 ssl 流优雅关闭之前, 底层流已关闭.

unspecified_system_error

底层 SSL 库返回了系统错误, 但未提供更多信息.

unexpected_result

底层 SSL 库的某次函数调用产生了意外的结果.

要求

头文件: boost/asio/ssl/error.hpp

便捷头文件: boost/asio/ssl.hpp
