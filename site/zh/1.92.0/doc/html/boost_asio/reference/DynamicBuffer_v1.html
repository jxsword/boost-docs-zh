动态缓冲区要求 (版本 1)

动态缓冲区封装了可按需自动调整大小的内存存储, 其中内存被划分为一个输入序列后接一个输出序列. 这些内存区域是动态缓冲区序列的内部区域, 但提供了对元素的直接访问, 使它们能够高效地与 I/O 操作 (例如套接字的 send 或 receive 操作) 一起使用. 写入动态缓冲区序列对象的输出序列的数据会被追加到同一对象的输入序列.

动态缓冲区类型 X 除满足下面列出的要求外, 还应满足 MoveConstructible (C++ Std, [moveconstructible]) 类型的要求.

在下表中, X 表示一个动态缓冲区类, x 表示类型为 X& 的值, x1 表示类型为 const X& 的值, n 表示类型为 size_t 的值, 而 u 表示一个标识符.

类型

断言/注释
前置/后置条件

X::const_buffers_type

满足 ConstBufferSequence 要求的类型.

此类型表示与输入序列关联的内存.

X::mutable_buffers_type

满足 MutableBufferSequence 要求的类型.

此类型表示与输出序列关联的内存.

x1.size()

size_t

返回输入序列的大小, 单位为字节.

x1.max_size()

size_t

返回输入序列与输出序列大小之和的允许上限.

x1.capacity()

size_t

返回动态缓冲区在无需重新分配的情况下所能容纳的输入序列与输出序列大小之和的最大值.

x1.data()

X::const_buffers_type

返回一个常量缓冲区序列 u, 它表示与输入序列关联的内存, 并且满足 buffer_size(u) == size().

x.prepare(n)

X::mutable_buffers_type

要求: size() + n <= max_size().

返回一个表示输出序列的可变缓冲区序列 u, 并且满足 buffer_size(u) == n. 动态缓冲区按需重新分配内存. 先前使用 data() 或 prepare() 获得的所有常量或可变缓冲区序列都会失效.

抛出: length_error, 如果 size() + n > max_size().

x.commit(n)

把输出序列开头的 n 个字节追加到输入序列的末尾. 输出序列的剩余部分被丢弃. 如果 n 大于输出序列的大小, 则整个输出序列被追加到输入序列. 先前使用 data() 或 prepare() 获得的所有常量或可变缓冲区序列都会失效.

x.consume(n)

从输入序列的开头移除 n 个字节. 如果 n 大于输入序列的大小, 则整个输入序列被移除. 先前使用 data() 或 prepare() 获得的所有常量或可变缓冲区序列都会失效.
