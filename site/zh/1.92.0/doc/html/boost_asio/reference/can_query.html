can_query

一种类型特征, 用于判定 query 表达式是否良构.

template<
    typename T,
    typename Property>
struct can_query :
  public integral_constant< bool, automatically_determined >

类模板 can_query 是一个特征, 派生自 true_type 的条件是表达式 boost::asio::query(std::declval<T>(), std::declval<Property>()) 良构; 否则派生自 false_type.

要求

头文件: boost/asio/query.hpp

便捷头文件: boost/asio.hpp
