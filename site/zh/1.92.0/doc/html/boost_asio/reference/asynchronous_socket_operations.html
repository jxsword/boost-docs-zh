对异步套接字操作的要求

在本库中, 异步套接字操作指带有前缀 async_ 的那些成员函数.

对对象 s, 程序可发起异步套接字操作, 使得存在多个同时未决的异步操作.

当有多个未决的异步读操作作用于 s时:

— 不具有实参 flags (类型为 socket_base::message_flags) ; 或

— 具有实参 flags (类型为 socket_base::message_flags) , 但 (flags & socket_base::message_out_of_band) == 0

则 buffers 按这些操作发出的顺序填充. 这些操作的完成处理器的调用顺序未指定.

当有多个未决的异步读操作作用于 s、且具有实参 flags (类型为 socket_base::message_flags) , 其中 (flags & socket_base::message_out_of_band) != 0, 则 buffers 按这些操作发出的顺序填充.

当有多个未决的异步写操作作用于 s时, buffers 按这些操作发出的顺序传输. 这些操作的完成处理器的调用顺序未指定.
