ssl::verify_mode

对端验证的位掩码类型.

typedef int verify_mode;

可能的取值有:

  • ssl::verify_none
  • ssl::verify_peer
  • ssl::verify_fail_if_no_peer_cert
  • ssl::verify_client_once
要求

头文件: boost/asio/ssl/verify_mode.hpp

便捷头文件: boost/asio/ssl.hpp
