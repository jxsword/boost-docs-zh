partial_cancel_after_timer

一种函数对象类型, 用于适配 完成标记, 在超时后取消操作.

template<
    typename Clock,
    typename WaitTraits = boost::asio::wait_traits<Clock>,
    typename Executor = any_io_executor>
class partial_cancel_after_timer
成员函数

名称

说明

operator()

适配完成标记, 指定完成处理器的各实参应合并为单个元组实参.

partial_cancel_after_timer [constructor]

指定超时时长和取消类型的构造函数.
数据成员

名称

说明

cancel_type_

timeout_

timer_

也可直接用作完成标记, 此时它适配异步操作的默认完成标记 (若无默认值可用, 则为 deferred) .

要求

头文件: boost/asio/cancel_after.hpp
