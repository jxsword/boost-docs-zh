default_completion_token_t 

typedef typename default_completion_token< T >::type default_completion_token_t;
类型

名称

说明

type

如果 T 有嵌套类型 default_completion_token_type, 则为 T::default_completion_token_type. 否则 typedef 类型为 boost::asio::deferred_t.

如果特化中的 T 模板参数是用户自定义类型, 程序可以特化此特征类型.

此特征的特化可以提供嵌套 typedef type, 它是一个可默认构造的完成标记类型.

如果没有其他特化, 默认完成标记类型是 deferred_t.

要求

头文件: boost/asio/default_completion_token.hpp

便捷头文件: boost/asio.hpp
