basic_yield_context::operator[]

返回一个设置指定 error_code 的 yield 上下文.

basic_yield_context operator[](
    boost::system::error_code & ec) const;

默认情况下, 当 yield 上下文与异步操作一起使用时, 非成功的 error_code 会被转换为 system_error 并抛出. 此运算符可用于指定一个 error_code 对象, 改为将异步操作的结果设置到该对象中. 例如:

template <typename Executor>
void my_coroutine(basic_yield_context<Executor> yield)
{
  ...
  std::size_t n = my_socket.async_read_some(buffer, yield[ec]);
  if (ec)
  {
    // An error occurred.
  }
  ...
}
