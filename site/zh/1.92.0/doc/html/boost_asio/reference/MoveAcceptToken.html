移动接受标记要求

移动接受标记是 完成标记, 其完成签名为 void(error_code, typename Protocol::socket) 或 void(error_code, typename Protocol::socket::template rebind_executor<Executor>::other), 用于接受器类模板的类型 Protocol.

示例

自由函数用作移动接受标记:

void accept_handler(
    const boost::system::error_code& ec, boost::asio::ip::tcp::socket s)
{
  ...
}

移动接受标记函数对象:

struct accept_handler
{
  ...
  void operator()(
      const boost::system::error_code& ec, boost::asio::ip::tcp::socket s)
  {
    ...
  }
  ...
};

lambda 用作移动接受标记:

acceptor.async_accept(...,
    [](const boost::system::error_code& ec, boost::asio::ip::tcp::socket s)
    {
      ...
    });

使用 std::bind() 适配为移动接受标记的类非静态成员函数:

void my_class::accept_handler(
    const boost::system::error_code& ec, boost::asio::ip::tcp::socket socket)
{
  ...
}
...
boost::asio::async_accept(...,
    std::bind(&my_class::accept_handler,
      this, std::placeholders::_1,
      std::placeholders::_2));

将 use_future 用作移动接受标记:

std::future<boost::asio::ip::tcp::socket> f =
  acceptor.async_accept(..., boost::asio::use_future);
...
try
{
  boost::asio::ip::tcp::socket s = f.get();
  ...
}
catch (const system_error& e)
{
  ...
}

将 use_awaitable 用作移动接受标记:

boost::asio::awaitable<void> my_coroutine()
{
  try
  {
    ...
    boost::asio::ip::tcp::socket s =
      co_await acceptor.async_accept(
          ..., boost::asio::use_awaitable);
    ...
  }
  catch (const system_error& e)
  {
    ...
  }
}
