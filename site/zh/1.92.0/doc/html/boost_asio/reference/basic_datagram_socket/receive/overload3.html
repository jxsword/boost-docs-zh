basic_datagram_socket::receive (3 个重载中的第 3 个)

在已连接的套接字上接收一些数据.

template<
    typename MutableBufferSequence>
std::size_t receive(
    const MutableBufferSequence & buffers,
    socket_base::message_flags flags,
    boost::system::error_code & ec);

此函数用于在数据报套接字上接收数据. 函数调用将阻塞, 直至成功收到数据或发生错误.

参数

buffers

接收数据所用的一份或多份缓冲区.

flags

指定如何进行接收调用的标志.

ec

用于指示发生了何种错误 (如无错误则不设置) .

返回值

接收到的字节数.

备注

receive 操作只能用于已连接的套接字. 要在未连接的数据报套接字上接收数据, 请使用 receive_from 函数.
