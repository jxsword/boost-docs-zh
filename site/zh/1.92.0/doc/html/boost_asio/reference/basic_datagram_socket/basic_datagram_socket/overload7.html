basic_datagram_socket::basic_datagram_socket (10 个重载中的第 7 个)

在现有原生套接字上构造一个 basic_datagram_socket.

basic_datagram_socket(
    const executor_type & ex,
    const protocol_type & protocol,
    const native_handle_type & native_socket);

此构造函数创建一个数据报套接字对象, 以持有现有的原生套接字.

参数

ex

套接字默认用于分发在该套接字上执行的任何异步操作的处理器所用的 I/O 执行器.

protocol

指定要使用的协议参数的对象.

native_socket

新的底层套接字实现.

异常

boost::system::system_error

失败时抛出.
