basic_stream_socket::receive (3 个重载中的第 1 个)

在套接字上接收一些数据.

template<
    typename MutableBufferSequence>
std::size_t receive(
    const MutableBufferSequence & buffers);

此函数用于在流式套接字上接收数据. 函数调用将阻塞, 直到已成功接收一个或多个字节的数据, 或者发生错误.

参数

buffers

接收数据所用的一份或多份缓冲区.

返回值

接收到的字节数.

异常

boost::system::system_error

失败时抛出. 错误码 boost::asio::error::eof 表示连接已被对端关闭.

备注

receive 操作可能不会接收全部请求的字节数. 如果需要确保在阻塞操作完成之前收到所请求的数据量, 请使用 read 函数.

示例

要接收单个数据缓冲区, 请按如下方式使用 buffer 函数:

socket.receive(boost::asio::buffer(data, size));

有关一次性接收多个缓冲区, 以及如何将其用于数组、boost::array 或 std::vector 的信息, 参见 buffer 文档.
