basic_stream_socket::async_wait

继承自 basic_socket.

异步等待套接字变为可读、可写, 或存在待处理的错误条件.

template<
    typename WaitToken = default_completion_token_t<executor_type>>
DEDUCED async_wait(
    wait_type w,
    WaitToken && token = default_completion_token_t< executor_type >());

此函数用于异步等待套接字进入可读、可写或错误条件状态. 它是 异步操作 的发起函数, 并且总是立即返回.

参数

w

指定所期望的套接字状态.

token

将用于产生完成处理器的 完成标记, 该处理器将在等待完成时被调用. 可能的完成标记包括 use_future、use_awaitable、yield_context, 或具有正确完成签名的函数对象. 完成处理器的函数签名必须为:

void handler(
  const boost::system::error_code& error // Result of operation.
);

无论异步操作是否立即完成, 完成处理器都不会在此函数内部被调用. 若立即完成, 将以等同于使用 async_immediate 的方式调用处理器.

完成签名 
void(boost::system::error_code)
示例 
void wait_handler(const boost::system::error_code& error)
{
  if (!error)
  {
    // Wait succeeded.
  }
}

...

boost::asio::ip::tcp::socket socket(my_context);
...
socket.async_wait(boost::asio::ip::tcp::socket::wait_read, wait_handler);
逐操作取消

在 POSIX 或 Windows 操作系统上, 此异步操作支持对以下 cancellation_type 值进行取消:

  • cancellation_type::terminal
  • cancellation_type::partial
  • cancellation_type::total
