basic_stream_socket::close (2 个重载中的第 2 个)

继承自 basic_socket.

关闭套接字.

void close(
    boost::system::error_code & ec);

此函数用于关闭套接字. 任何异步发送、接收或连接操作都会被立即取消, 并以 boost::asio::error::operation_aborted 错误完成.

参数

ec

设置为指示发生了何种错误 (若有) . 注意, 即使函数指示发生错误, 底层描述符也会被关闭.

示例 
boost::asio::ip::tcp::socket socket(my_context);
...
boost::system::error_code ec;
socket.close(ec);
if (ec)
{
  // An error occurred.
}
备注

为使已连接套接字的优雅关闭行为可移植, 请在关闭套接字之前调用 shutdown().
