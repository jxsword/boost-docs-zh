basic_stream_socket::open (2 个重载中的第 1 个)

继承自 basic_socket.

使用指定的协议打开套接字.

void open(
    const protocol_type & protocol = protocol_type());

此函数打开套接字, 使其使用指定的协议.

参数

protocol

指定要使用的协议参数的对象.

异常

boost::system::system_error

失败时抛出.

示例 
boost::asio::ip::tcp::socket socket(my_context);
socket.open(boost::asio::ip::tcp::v4());
