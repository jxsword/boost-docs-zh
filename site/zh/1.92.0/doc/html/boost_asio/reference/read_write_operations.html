读写操作的要求

读操作是一种把数据读入可变缓冲区序列实参的操作, 实参类型满足 MutableBufferSequence 要求. 可变缓冲区序列指定数据应存放的内存. 读操作在继续处理序列中的下一个缓冲区之前, 必须始终先填满当前缓冲区.

写操作是一种从常量缓冲区序列实参写出数据的操作, 实参类型满足 ConstBufferSequence 要求. 常量缓冲区序列指定要写出的数据所在的内存. 写操作在继续处理序列中的下一个缓冲区之前, 必须始终先完整写出当前缓冲区.

若读或写操作同时也是 异步操作, 则该操作应维护缓冲区序列的一个或多个副本, 直至操作不再需要访问序列中缓冲区所指定的内存. 程序应确保内存保持有效, 直至:

— 缓冲区序列的最后一个副本被销毁, 或

— 异步操作的完成处理器被调用,

whichever comes first.
