disposition_traits

用于把任意错误类型适配为处置结果的特征类型.

template<
    typename T>
struct disposition_traits
成员函数

名称

说明

not_an_error [static]

确定处置结果是否表示无错误.

throw_exception [static]

如果处置结果表示错误, 则抛出异常.

to_exception_ptr [static]

把处置结果转换为 exception_ptr.

可以针对用户自定义类型特化此类型, 使 asio 能把它们当作处置结果处理.

主特征未定义.

要求

头文件: boost/asio/disposition.hpp

便捷头文件: boost/asio.hpp
