async_result< std::packaged_task< Result(Args...)>, Signature >

async_result 针对 std::packaged_task 的偏特化.

template<
    typename Result,
    typename... Args,
    typename Signature>
class async_result< std::packaged_task< Result(Args...)>, Signature >
类型

名称

说明

completion_handler_type

打包任务 (packaged task) 即为具体完成处理器类型.

return_type

发起函数的返回类型是从打包任务获得的 future.
成员函数

名称

说明

async_result

构造函数从打包任务中提取 future.

get

返回打包任务的 future.
要求

头文件: boost/asio/packaged_task.hpp
