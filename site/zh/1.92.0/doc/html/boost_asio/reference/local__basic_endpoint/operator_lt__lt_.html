local::basic_endpoint::operator<<

将端点输出为字符串.

template<
    typename Elem,
    typename Traits,
    typename Protocol>
std::basic_ostream< Elem, Traits > & operator<<(
    std::basic_ostream< Elem, Traits > & os,
    const basic_endpoint< Protocol > & endpoint);

用于为指定端点输出人类可读的字符串.

参数

os

字符串要写入的输出流.

endpoint

要写入的端点.

返回值

输出流.
