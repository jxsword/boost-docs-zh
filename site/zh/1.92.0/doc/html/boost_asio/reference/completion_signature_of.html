completion_signature_of

completion_signature_of 特征用于确定异步操作的完成签名.

template<
    typename T,
    typename... Args>
struct completion_signature_of
类型

名称

说明

type

类模板 completion_signature_of 是一个特征, 其成员类型别名 type 表示由表达式 T(Args..., token) 操作发起的异步操作的完成签名, 其中 token 是一个未指定的完成标记类型. 如果该异步操作不是恰好有一个完成签名, 则该特征的实例化是良构的, 但成员类型别名 type 会被省略. 如果表达式 T(Args..., token) 不是异步操作, 则该特征的使用是非良构的.

要求

头文件: boost/asio/async_result.hpp

便捷头文件: boost/asio.hpp
