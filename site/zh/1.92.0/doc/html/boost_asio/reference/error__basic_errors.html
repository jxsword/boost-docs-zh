error::basic_errors 

enum basic_errors

取值

access_denied

权限被拒绝.

address_family_not_supported

协议不支持该地址族.

address_in_use

地址已被占用.

already_connected

传输端点已连接.

already_started

操作已经在进行中.

broken_pipe

管道破裂.

connection_aborted

连接已中止.

connection_refused

连接被拒绝.

connection_reset

连接被对端重置.

bad_descriptor

错误的文件描述符.

fault

错误的地址.

host_unreachable

没有到达主机的路由.

in_progress

操作正在进行中.

interrupted

系统调用被中断.

invalid_argument

无效参数.

message_size

消息过长.

name_too_long

名称过长.

network_down

网络已断开.

network_reset

网络因复位断开了连接.

network_unreachable

网络不可达.

no_descriptors

打开的文件过多.

no_buffer_space

没有可用的缓冲区空间.

no_memory

无法分配内存.

no_permission

操作不被允许.

no_protocol_option

协议不可用.

no_such_device

没有此设备.

not_connected

传输端点未连接.

not_socket

对非套接字执行套接字操作.

operation_aborted

操作已取消.

operation_not_supported

操作不受支持.

shut_down

传输端点关闭后无法发送.

timed_out

连接超时.

try_again

资源暂时不可用.

would_block

套接字已标记为非阻塞, 而请求的操作会阻塞.

要求

头文件: boost/asio/error.hpp

便捷头文件: boost/asio.hpp
