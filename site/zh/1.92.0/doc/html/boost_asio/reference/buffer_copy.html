buffer_copy

buffer_copy 函数用于把字节从源缓冲区 (或缓冲区序列) 复制到目标缓冲区 (或缓冲区序列).

把字节从源缓冲区序列复制到目标缓冲区序列.

template<
    typename MutableBufferSequence,
    typename ConstBufferSequence>
std::size_t buffer_copy(
    const MutableBufferSequence & target,
    const ConstBufferSequence & source);
  » more...

把有限数量的字节从源缓冲区序列复制到目标缓冲区序列.

template<
    typename MutableBufferSequence,
    typename ConstBufferSequence>
std::size_t buffer_copy(
    const MutableBufferSequence & target,
    const ConstBufferSequence & source,
    std::size_t max_bytes_to_copy);
  » more...

buffer_copy 函数有两种形式:

  • 2 个实参的形式: buffer_copy(target, source)
  • 3 个实参的形式: buffer_copy(target, source, max_bytes_to_copy)

两种形式都返回实际复制的字节数. 复制的字节数取以下两者中的较小者:

  • buffer_size(target)
  • buffer_size(source)
  • If 指定时即取 max_bytes_to_copy.

无论复制操作中使用的缓冲区大小如何, 这都能防止缓冲区溢出.

注意, buffer_copy 是基于 memcpy 实现的, 因此它不能用于在重叠的内存区域之间进行复制.

要求

头文件: boost/asio/buffer.hpp

便捷头文件: boost/asio.hpp
