缓冲区对象将一段连续的内存区域表示为一个由指针和以字节为单位的长度组成的二元组. 形如 {void*, size_t} 的元组指定一块可变 (可修改) 的内存区域. 类似地, 形如 {const void*, size_t} 的元组指定一块 const (不可修改) 的内存区域. 这两种形式分别对应 mutable_buffer 和 const_buffer 这两个类. 为对应 C++ 的转换规则, mutable_buffer 可隐式转换为 const_buffer, 而相反的转换则不被允许.

最简单的用例是读取或写入一个指定长度的缓冲区:

sock.send(boost::asio::buffer(data, size));

在上面的示例中, buffer 的返回值满足 ConstBufferSequence 概念的要求, 因此可以直接传递给套接字的 write 函数. 为可修改内存创建的缓冲区也满足 MutableBufferSequence 概念的要求.

单个缓冲区可由 POD 元素的内置数组、std::vector、std::array 或 boost::array 创建. 这通过自动确定缓冲区的大小来帮助防止缓冲区越界:

char d1[128];
size_t bytes_transferred = sock.receive(boost::asio::buffer(d1));

std::vector<char> d2(128);
bytes_transferred = sock.receive(boost::asio::buffer(d2));

std::array<char, 128> d3;
bytes_transferred = sock.receive(boost::asio::buffer(d3));

boost::array<char, 128> d4;
bytes_transferred = sock.receive(boost::asio::buffer(d4));

在上面三种情况下, 所创建的缓冲区长度都恰好为 128 字节. 注意, 在创建或使用缓冲区时, vector 绝不会自动调整大小. 缓冲区的大小通过 vector 的 size() 成员函数确定, 而不是其 capacity.

访问缓冲区内容

可以使用 data() 和 size() 成员函数访问缓冲区的内容:

boost::asio::mutable_buffer b1 = ...;
std::size_t s1 = b1.size();
unsigned char* p1 = static_cast<unsigned char*>(b1.data());

boost::asio::const_buffer b2 = ...;
std::size_t s2 = b2.size();
const void* p2 = b2.data();

data() 成员函数允许违反类型安全, 因此在应用程序代码中使用它时应仔细斟酌.

为方便起见, 提供了 buffer_size 函数, 它既适用于缓冲区, 也适用于缓冲区序列 (即满足 ConstBufferSequence 或 MutableBufferSequence 类型要求的类型) . 在这种情况下, 该函数返回序列中所有缓冲区的总大小.

缓冲区复制

buffer_copy 函数可用于在各个缓冲区与缓冲区序列之间复制原始字节.

特别是, 与 buffer_size 函数一起使用时, buffer_copy 函数可用于将缓冲区序列线性化. 例如:

vector<const_buffer> buffers = ...;

vector<unsigned char> data(boost::asio::buffer_size(buffers));
boost::asio::buffer_copy(boost::asio::buffer(data), buffers);

注意, buffer_copy 是基于 memcpy 实现的, 因此它不能用于在重叠的内存区域之间进行复制.

缓冲区失效

缓冲区对象对其所引用的内存不拥有任何所有权. 应用程序有责任确保内存区域保持有效, 直到 I/O 操作不再需要它为止. 当内存不再可用时, 就称该缓冲区已失效.

对于接受 std::vector 类型参数的 buffer 重载, 任何使 vector 中元素的引用、指针或迭代器失效的 vector 操作都会使返回的缓冲区对象失效 (C++ 标准, [sequence.reqmts]) .

对于接受 std::basic_string 类型参数的 buffer 重载, 返回的缓冲区对象按照针对使 string 元素的引用、指针和迭代器失效所定义的规则而失效 (C++ 标准, [string.require]) .

缓冲区运算

缓冲区对象可以通过简单的运算以安全的方式进行操作, 这有助于防止缓冲区越界. 考虑按如下方式初始化的一个数组:

boost::array<char, 6> a = { 'a', 'b', 'c', 'd', 'e' };

缓冲区对象 b1 使用如下代码创建:

b1 = boost::asio::buffer(a);

表示整个数组 { 'a', 'b', 'c', 'd', 'e' }. buffer 函数的第二个可选参数可用于以字节为单位限制缓冲区的大小:

b2 = boost::asio::buffer(a, 3);

使得 b2 表示数据 { 'a', 'b', 'c' }. 即使 size 参数超过数组的实际大小, 所创建缓冲区对象的大小也会被限制为数组大小.

可以对现有缓冲区应用偏移量以创建新缓冲区:

b3 = b1 + 2;

其中 b3 将被设置为表示 { 'c', 'd', 'e' }. 如果偏移量超过现有缓冲区的大小, 则新创建的缓冲区将为空.

可以同时指定偏移量和大小, 以创建对应于现有缓冲区内特定字节范围的缓冲区:

b4 = boost::asio::buffer(b1 + 1, 3);

这样 b4 将引用字节 { 'b', 'c', 'd' }.

缓冲区与分散-聚集 I/O

要使用多个缓冲区进行读写 (即分散-聚集 I/O) , 可将多个缓冲区对象赋入支持 MutableBufferSequence (用于读) 或 ConstBufferSequence (用于写) 概念的容器:

char d1[128];
std::vector<char> d2(128);
boost::array<char, 128> d3;

boost::array<mutable_buffer, 3> bufs1 = {
  boost::asio::buffer(d1),
  boost::asio::buffer(d2),
  boost::asio::buffer(d3) };
bytes_transferred = sock.receive(bufs1);

std::vector<const_buffer> bufs2;
bufs2.push_back(boost::asio::buffer(d1));
bufs2.push_back(boost::asio::buffer(d2));
bufs2.push_back(boost::asio::buffer(d3));
bytes_transferred = sock.send(bufs2);
缓冲区字面量

_buf 字面量后缀定义于命名空间 boost::asio::buffer_literals 中, 可用于从字符串、二进制整数和十六进制整数字面量创建 const_buffer 对象. 例如:

using namespace boost::asio::buffer_literals;

boost::asio::const_buffer b1 = "hello"_buf;
boost::asio::const_buffer b2 = 0xdeadbeef_buf;
boost::asio::const_buffer b3 = 0x0123456789abcdef0123456789abcdef_buf;
boost::asio::const_buffer b4 = 0b1010101011001100_buf;

注意, 与缓冲区字面量关联的内存在程序的生命周期内有效. 这意味着该缓冲区可以安全地用于异步操作.
