executor_arg

一个特殊值, 类似于 std::nothrow, 用于消解接受执行器实参的构造函数之间的歧义.

constexpr executor_arg_t executor_arg;

参见 executor_arg_t 与 uses_executor 以了解更多信息.

要求

头文件: boost/asio/uses_executor.hpp

便捷头文件: boost/asio.hpp
