any_completion_handler::operator()

函数调用运算符.

template<
    typename... Args>
auto operator()(
    Args &&... args);

以提供的实参调用目标完成处理器.

此函数只能调用一次, 因为目标处理器会被移走. 多态包装随后处于空状态.

若多态包装为空, 则抛出 std::bad_function_call.
