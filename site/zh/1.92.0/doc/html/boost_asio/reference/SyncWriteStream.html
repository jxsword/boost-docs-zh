面向缓冲区的同步写入流要求

类型 X 满足 SyncWriteStream 要求, 如果它满足下面列出的要求.

在下表中, a 表示类型为 X 的值, cb 表示满足 ConstBufferSequence 要求的 (可能为 const 的) 值, ec 表示类型为 error_code 的对象.

表 33. SyncWriteStream 要求

操作

类型

语义, 前置/后置条件

a.write_some(cb)
a.write_some(cb,ec)

size_t

满足 写操作 的要求.

若 buffer_size(cb) > 0, 则向流 a 写入来自缓冲区序列 cb 的一个或多个字节的数据. 若成功, 设置 ec 使 !ec 为 true, 并返回写入的字节数. 若发生错误, 设置 ec 使 !!ec 为 true, 并返回 0.

若 buffer_size(cb) == 0, 则该操作不得阻塞. 设置 ec 使 !ec 为 true, 并返回 0.
