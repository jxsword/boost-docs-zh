socket_base

socket_base 类用作 basic_stream_socket 和 basic_datagram_socket 类模板的基类, 以便有一个公共位置来定义 shutdown_type 和枚举.

说明

bytes_readable

debug

启用套接字级调试的套接字选项.

发送保活 (keep-alive) 报文的套接字选项.
