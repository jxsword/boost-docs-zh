Internet 协议要求

类型 X 满足 InternetProtocol 要求, 若其满足 AcceptableProtocol 的要求, 以及下面列出的附加要求.

在下表中, a 表示类型为 X 的 (可能为 const 的) 值, b 表示类型为 X 的 (可能为 const 的) 值.

a == b
