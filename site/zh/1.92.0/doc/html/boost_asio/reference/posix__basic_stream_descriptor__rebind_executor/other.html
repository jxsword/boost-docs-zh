posix::basic_stream_descriptor 类模板提供异步和阻塞的面向流描述符功能.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

若底层操作系统调用也是线程安全的, 则同步的 read_some 与 write_some 操作彼此之间是线程安全的. 这意味着允许在单个描述符对象上并发调用这些同步操作. 其他同步操作, 例如 close, 则不是线程安全的.
