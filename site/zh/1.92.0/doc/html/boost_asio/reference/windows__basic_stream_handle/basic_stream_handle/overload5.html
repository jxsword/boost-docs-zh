windows::basic_stream_handle::basic_stream_handle (5 of 6 overloads)

从另一个句柄移动构造流句柄.

basic_stream_handle(
    basic_stream_handle && other);

此构造函数把流句柄从一个对象移动到另一个对象.

参数

other

移动来源的另一个流句柄对象.

备注

移动之后, 被移动的对象所处的状态等同于使用 basic_stream_handle(const executor_type&) 构造函数构造后的状态.
