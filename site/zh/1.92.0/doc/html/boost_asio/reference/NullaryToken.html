无参标记要求

无参标记是 完成标记, 其完成签名为 void().

示例

自由函数用作无参标记:

void nullary_handler()
{
  ...
}

无参标记函数对象:

struct nullary_handler
{
  ...
  void operator()()
  {
    ...
  }
  ...
};

lambda 用作无参标记:

boost::asio::post(...,
    []()
    {
      ...
    });

使用 std::bind() 适配为无参标记的类非静态成员函数:

void my_class::nullary_handler()
{
  ...
}
...
boost::asio::post(...,
    std::bind(&my_class::nullary_handler, this));

使用 boost::bind() 适配为无参标记的类非静态成员函数:

void my_class::nullary_handler()
{
  ...
}
...
boost::asio::post(...,
    boost::bind(&my_class::nullary_handler, this));

将 use_future 用作无参标记:

std::future<void> f = boost::asio::post(..., boost::asio::use_future);
...
f.get();

将 use_awaitable 用作无参标记:

boost::asio::awaitable<void> my_coroutine()
{
  ...
  co_await boost::asio::post(..., boost::asio::use_awaitable);
  ...
}
