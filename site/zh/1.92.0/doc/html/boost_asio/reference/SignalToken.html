信号标记要求

信号标记是 完成标记, 其完成签名为 void(error_code, int).

示例

自由函数用作信号标记:

void signal_handler(
    const boost::system::error_code& ec,
    int signal_number)
{
  ...
}

信号标记函数对象:

struct signal_handler
{
  ...
  void operator()(
      const boost::system::error_code& ec,
      int signal_number)
  {
    ...
  }
  ...
};

lambda 用作信号标记:

signal_set.async_wait(...,
    [](const boost::system::error_code& ec,
      int signal_number)
    {
      ...
    });

使用 std::bind() 适配为信号标记的类非静态成员函数:

void my_class::signal_handler(
    const boost::system::error_code& ec,
    int signal_number)
{
  ...
}
...
signal_set.async_wait(...,
    std::bind(&my_class::signal_handler,
      this, std::placeholders::_1,
      std::placeholders::_2));

使用 boost::bind() 适配为信号标记的类非静态成员函数:

void my_class::signal_handler(
    const boost::system::error_code& ec,
    int signal_number)
{
  ...
}
...
signal_set.async_wait(...,
    boost::bind(&my_class::signal_handler,
      this, boost::asio::placeholders::error,
      boost::asio::placeholders::signal_number));

将 use_future 用作信号标记:

std::future<int> f = signal_set.async_wait(..., boost::asio::use_future);
...
try
{
  int signo = f.get();
  ...
}
catch (const system_error& e)
{
  ...
}

将 use_awaitable 用作信号标记:

boost::asio::awaitable<void> my_coroutine()
{
  try
  {
    ...
    int signo =
      co_await signal_set.async_wait(
          ..., boost::asio::use_awaitable);
    ...
  }
  catch (const system_error& e)
  {
    ...
  }
}
