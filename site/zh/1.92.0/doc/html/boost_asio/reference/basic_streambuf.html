basic_streambuf

基于 std::streambuf 的可自动调整大小的缓冲区类.

template<
    typename Allocator = std::allocator<char>>
class basic_streambuf :
  public std::streambuf,
  noncopyable

basic_streambuf 类派生自 std::streambuf, 用于将 streambuf 的输入序列和输出序列与一个或多个字符数组关联起来. 这些字符数组是 basic_streambuf 对象内部的, 但提供了对数组元素的直接访问, 以便它们能够高效地用于 I/O 操作. 写入 basic_streambuf 对象输出序列的字符会被追加到同一对象的输入序列.

basic_streambuf 类的公共接口旨在允许以下实现策略:

  • 单个连续字符数组, 根据需要重新分配以适应字符序列大小的变化. 这是 Asio 当前使用的实现方式.
  • 由一个或多个字符数组组成的序列, 其中每个数组大小相同. 额外的字符数组对象会追加到该序列中, 以适应字符序列大小的变化.
  • 由一个或多个大小不同的字符数组组成的序列. 额外的字符数组对象会追加到该序列中, 以适应字符序列大小的变化.

basic_streambuf 的构造函数接受一个 size_t 参数, 指定输入序列和输出序列大小之和的最大值. 在 basic_streambuf 对象的生命周期内, 以下不变式成立:

size() <= max_size()

任何在成功时会导致不变式被违反的成员函数都应抛出 std::length_error 类的异常.

basic_streambuf 的构造函数接受一个 Allocator 参数. 构造函数和所有成员函数在每个 basic_streambuf 对象的生命周期内执行的任何内存分配都使用该参数的副本.

示例

从 streambuf 直接写入套接字:

boost::asio::streambuf b;
std::ostream os(&b);
os << "Hello, World!\n";

// try sending some data in input sequence
size_t n = sock.send(b.data());

b.consume(n); // sent data is removed from input sequence

从套接字直接读入 streambuf:

boost::asio::streambuf b;

// reserve 512 bytes in output sequence
boost::asio::streambuf::mutable_buffers_type bufs = b.prepare(512);

size_t n = sock.receive(bufs);

// received data is "committed" from output sequence to input sequence
b.commit(n);

std::istream is(&b);
std::string s;
is >> s;
