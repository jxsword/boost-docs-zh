basic_deadline_timer::expires_from_now (3 个重载中的第 1 个)

以相对于当前时间的方式获取定时器的到期时间.

duration_type expires_from_now() const;

此函数可用于获取定时器当前的到期时间. 定时器是否已到期不影响此值.
