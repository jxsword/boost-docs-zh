basic_deadline_timer::expires_from_now (3 个重载中的第 3 个)

以相对于当前时间的方式设置定时器的到期时间.

std::size_t expires_from_now(
    const duration_type & expiry_time,
    boost::system::error_code & ec);

此函数设置到期时间. 所有待处理的异步等待操作都将被取消. 每个被取消操作的处理器将以 boost::asio::error::operation_aborted 错误码被调用.

参数

expiry_time

定时器要使用的到期时间.

ec

用于指示发生了何种错误 (如无错误则不设置) .

返回值

被取消的异步操作的数量.

备注

若在调用 expires_from_now() 时定时器已经到期, 则异步等待操作的处理器将:

  • 已被调用; 或
  • 已被排入队列, 将在近期被调用.

这些处理器无法再被取消, 因此会收到一个指示等待操作成功完成的错误码.
