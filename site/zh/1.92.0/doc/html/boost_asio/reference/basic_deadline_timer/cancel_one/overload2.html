basic_deadline_timer::cancel_one (2 个重载中的第 2 个)

取消一个正在等待该定时器的异步操作.

std::size_t cancel_one(
    boost::system::error_code & ec);

此函数强制完成针对该定时器的一个待处理异步等待操作. 处理器按 FIFO (先进先出) 顺序取消. 被取消操作的处理器将以 boost::asio::error::operation_aborted 错误码被调用.

取消定时器不会改变其到期时间.

参数

ec

用于指示发生了何种错误 (如无错误则不设置) .

返回值

被取消的异步操作的数量. 即为 0 或 1.

备注

若在调用 cancel_one() 时定时器已经到期, 则异步等待操作的处理器将:

  • 已被调用; 或
  • 已被排入队列, 将在近期被调用.

这些处理器无法再被取消, 因此会收到一个指示等待操作成功完成的错误码.
