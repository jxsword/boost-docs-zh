等待标记要求

等待标记是 完成标记, 其完成签名为 void(error_code).

示例

自由函数用作等待标记:

void wait_handler(
    const boost::system::error_code& ec)
{
  ...
}

等待标记函数对象:

struct wait_handler
{
  ...
  void operator()(
      const boost::system::error_code& ec)
  {
    ...
  }
  ...
};

lambda 用作等待标记:

socket.async_wait(...,
    [](const boost::system::error_code& ec)
    {
      ...
    });

使用 std::bind() 适配为等待标记的类非静态成员函数:

void my_class::wait_handler(
    const boost::system::error_code& ec)
{
  ...
}
...
socket.async_wait(...,
    std::bind(&my_class::wait_handler,
      this, std::placeholders::_1));

使用 boost::bind() 适配为等待标记的类非静态成员函数:

void my_class::wait_handler(
    const boost::system::error_code& ec)
{
  ...
}
...
socket.async_wait(...,
    boost::bind(&my_class::wait_handler,
      this, boost::asio::placeholders::error));

将 use_future 用作等待标记:

std::future<void> f = socket.async_wait(..., boost::asio::use_future);
...
try
{
  f.get();
}
catch (const system_error& e)
{
  ...
}

将 use_awaitable 用作等待标记:

boost::asio::awaitable<void> my_coroutine()
{
  try
  {
    ...
    co_await socket.async_wait(..., boost::asio::use_awaitable);
    ...
  }
  catch (const system_error& e)
  {
    ...
  }
}
