ip::basic_endpoint::basic_endpoint (5 个重载中的第 2 个)

使用端口号构造端点, 端口号按主机的字节序指定. IP 地址将是任意地址 (即 INADDR_ANY 或 in6addr_any). 此构造函数通常用于接受新连接.

basic_endpoint(
    const InternetProtocol & internet_protocol,
    port_type port_num);
示例

要初始化端口为 1234 的 IPv4 TCP 端点, 可用:

boost::asio::ip::tcp::endpoint ep(boost::asio::ip::tcp::v4(), 1234);

要指定端口为 9876 的 IPv6 UDP 端点, 可用:

boost::asio::ip::udp::endpoint ep(boost::asio::ip::udp::v6(), 9876);
