销毁信号集.

basic_signal_set 类提供对一或多个信号的发生执行异步等待的能力.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

示例

执行异步等待:

void handler(
    const boost::system::error_code& error,
    int signal_number)
{
  if (!error)
  {
    // A signal occurred.
  }
}

...

// Construct a signal set registered for process termination.
boost::asio::signal_set signals(my_context, SIGINT, SIGTERM);

// Start an asynchronous wait for one of the signals to occur.
signals.async_wait(handler);
信号通知的排队

如果信号已注册到 signal_set, 并且在没有任何等待处理器时信号发生, 则该信号通知会被排队. 对该 signal_set 的下一个 async_wait 操作会使该通知出队. 如果多个通知被排队, 后续的 async_wait 操作会一次一个地将它们出队. 信号通知按信号编号升序的顺序出队.

如果从 signal_set 中移除某个信号编号(使用 remove 或 erase 成员函数), 则该信号的任何已排队通知都会被丢弃.

信号的多次注册

同一信号编号可以注册到不同的 signal_set 对象. 当信号发生时, 会为每个 signal_set 对象调用一个处理器.

注意, 多次注册仅对使用 Asio 注册的信号有效. 应用程序不得同时使用 signal() 或 sigaction() 等函数注册信号处理器.

POSIX 平台上的信号屏蔽

POSIX 允许使用 sigprocmask() 和 pthread_sigmask() 等函数阻塞信号. 要使信号能够被投递, 程序必须确保使用 signal_set 对象注册的任何信号在至少一个线程中未被阻塞.
