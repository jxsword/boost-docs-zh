basic_streambuf_ref

将 basic_streambuf 适配为满足动态缓冲区序列类型要求.

template<
    typename Allocator = std::allocator<char>>
class basic_streambuf_ref
类型

名称

说明

const_buffers_type

用于将输入序列表示为缓冲区列表的类型.

mutable_buffers_type

用于将输出序列表示为缓冲区列表的类型.
成员函数

名称

说明

basic_streambuf_ref [构造函数]

为给定的 basic_streambuf 对象构造一个 basic_streambuf_ref.
—
复制构造一个 basic_streambuf_ref.
—
移动构造一个 basic_streambuf_ref.

capacity

获取动态缓冲区的当前容量.

commit

把字节从输出序列移至输入序列.

consume

从输入序列中移除字符.

data

获取表示输入序列的缓冲区列表.

max_size

获取动态缓冲区的最大大小.

prepare

获取表示输出序列的缓冲区列表, 其大小为给定值.

size

获取输入序列的大小.
要求

头文件: boost/asio/basic_streambuf.hpp

便捷头文件: boost/asio.hpp
