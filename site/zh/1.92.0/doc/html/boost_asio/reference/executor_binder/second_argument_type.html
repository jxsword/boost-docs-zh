executor_binder::second_argument_type

函数第二个实参的类型.

typedef see_below second_argument_type;

second_argument_type 的类型取决于包装器目标对象的类型 T:

  • 若 T 是接受两个实参的函数类型的指针, 则 second_argument_type 是 T 的返回类型的同义词;
  • 若 T 是具有成员类型 first_argument_type 的类类型, 则 second_argument_type 是 T::second_argument_type 的同义词;
  • 否则不定义 second_argument_type.
要求

头文件: boost/asio/bind_executor.hpp

便捷头文件: boost/asio.hpp
