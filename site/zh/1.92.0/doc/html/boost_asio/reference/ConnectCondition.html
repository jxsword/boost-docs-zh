连接条件要求

类型 X 满足 ConnectCondition 要求, 如果它满足 Destructible (C++Std [destructible]) 和 CopyConstructible (C++Std [copyconstructible]) 的要求, 以及下面列出的附加要求.

在下表中, x 表示类型为 X 的值, ec 表示类型为 error_code 的 (可能为 const 的) 值, 而 ep 表示某个满足 endpoint 要求的类型的 (可能为 const 的) 值.

表 10. ConnectCondition 要求

表达式

返回类型

断言/注释
前置/后置条件

x(ec, ep)

bool

返回 true, 表示 connect 或 async_connect 算法应当尝试连接到端点 ep. 否则, 返回 false, 表示算法不应尝试连接到端点 ep, 而应跳到序列中的下一个端点.
