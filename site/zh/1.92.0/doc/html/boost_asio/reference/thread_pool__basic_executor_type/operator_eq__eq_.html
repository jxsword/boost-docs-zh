thread_pool::basic_executor_type::operator==

比较两个执行器是否相等.

bool operator==(
    const basic_executor_type & a,
    const basic_executor_type & b);

如果两个执行器指向同一个底层线程池, 则它们相等.

要求

头文件: boost/asio/thread_pool.hpp

便捷头文件: boost/asio.hpp
