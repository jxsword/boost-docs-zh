时间特征要求

在下表中, X 表示时间类型 Time 的时间特征类, t、t1 与 t2 表示类型为 Time 的值, d 表示类型为 X::duration_type 的值.

表 34. TimeTraits 要求

表达式

返回类型

断言/注释
前置/后置条件

X::time_type

Time

表示一个绝对时间. 必须支持默认构造, 并满足 CopyConstructible 与 Assignable 的要求.

X::duration_type

表示两个绝对时间之间的差值. 必须支持默认构造, 并满足 CopyConstructible 与 Assignable 的要求. 时长可为正、负或零.

X::now();

time_type

返回当前时间.

X::add(t, d);

time_type

返回将时长 d 加到绝对时间 t 上所得到的新绝对时间.

X::subtract(t1, t2);

duration_type

返回将 t2 从 t1 中扣除所得到的时长.

X::less_than(t1, t2);

bool

返回 t1 是否应被视为小于 t2.

X::to_posix_duration(d);

date_time::time_duration_type

返回 date_time::time_duration_type 值, 其最接近地表示时长 d.
