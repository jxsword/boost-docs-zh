该 inline_or_executor 类模板按如下方式适配一个既有执行器:

  • 投递的函数对象 (或当 blocking 属性设置为 blocking.never) 则提交给被包装的执行器; 且
  • 分派的函数对象 (或当 blocking 为 blocking.always 或 blocking.possibly) 则内联执行.
