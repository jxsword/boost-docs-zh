ssl::context::use_rsa_private_key (2 个重载中的第 1 个)

使用内存缓冲区中的 RSA 私钥.

void use_rsa_private_key(
    const const_buffer & private_key,
    file_format format);

此函数用于把 RSA 私钥从缓冲区加载到上下文中.

参数

private_key

包含 RSA 私钥的缓冲区.

format

私钥格式 (ASN.1 或 PEM).

异常

boost::system::system_error

失败时抛出.

备注

调用 SSL_CTX_use_RSAPrivateKey 或 SSL_CTX_use_RSAPrivateKey_ASN1.
