ssl::context::operator=

从另一个对象移动赋值上下文.

context & operator=(
    context && other);

此赋值运算符将 SSL 上下文从一个对象移动到另一个对象.

参数

other

移动来源的另一个上下文对象.

备注

移动之后, 移出的对象上仅以下操作有效: * 销毁.

  • 作为移动赋值的目标.
