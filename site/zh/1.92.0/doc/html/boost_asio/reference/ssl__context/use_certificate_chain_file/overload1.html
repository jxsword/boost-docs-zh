ssl::context::use_certificate_chain_file (2 个重载中的第 1 个)

使用文件中的证书链.

void use_certificate_chain_file(
    const std::string & filename);

此函数用于把证书链从文件加载到上下文中.

参数

filename

包含证书的文件的名称. 文件必须使用 PEM 格式.

异常

boost::system::system_error

失败时抛出.

备注

Calls SSL_CTX_use_certificate_chain_file.
