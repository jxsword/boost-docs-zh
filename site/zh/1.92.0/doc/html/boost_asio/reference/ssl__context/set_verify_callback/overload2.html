ssl::context::set_verify_callback (2 个重载中的第 2 个)

设置用于验证对端证书的回调.

template<
    typename VerifyCallback>
void set_verify_callback(
    VerifyCallback callback,
    boost::system::error_code & ec);

此函数用于指定回调函数, 当实现需要验证对端证书时会调用它.

参数

callback

用于验证证书的函数对象. 处理器的函数签名必须是:

bool verify_callback(
  bool preverified, // True if the certificate passed pre-verification.
  verify_context& ctx // The peer certificate and other context.
);

若证书通过验证, 回调的返回值为 true, 否则为 false.

ec

用于指示发生了何种错误 (如无错误则不设置) .

备注

Calls SSL_CTX_set_verify.
