ssl::context::use_certificate (2 个重载中的第 1 个)

使用内存缓冲区中的证书.

void use_certificate(
    const const_buffer & certificate,
    file_format format);

此函数用于把证书从缓冲区加载到上下文中.

参数

certificate

包含证书的缓冲区.

format

证书格式 (ASN.1 或 PEM).

异常

boost::system::system_error

失败时抛出.

备注

调用 SSL_CTX_use_certificate 或 SSL_CTX_use_certificate_ASN1.
