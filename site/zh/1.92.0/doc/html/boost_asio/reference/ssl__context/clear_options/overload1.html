ssl::context::clear_options (2 个重载中的第 1 个)

清除上下文上的选项.

void clear_options(
    options o);

此函数可用于配置上下文使用的 SSL 选项.

参数

o

选项的位掩码. 可用的选项值定义于 ssl::context_base 类中. 指定的选项若当前在上下文上已启用, 则会被清除.

异常

boost::system::system_error

失败时抛出.

备注

Calls SSL_CTX_clear_options.
