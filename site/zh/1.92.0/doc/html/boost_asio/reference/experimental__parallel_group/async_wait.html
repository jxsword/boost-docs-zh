experimental::parallel_group::async_wait

为该组操作发起一次异步等待.

template<
    typename CancellationCondition,
    typename CompletionToken>
DEDUCED async_wait(
    CancellationCondition cancellation_condition,
    CompletionToken && token);

启动该组并异步等待完成.

参数

cancellation_condition

一个函数对象, 在组内某个操作完成时被调用, 用于决定是否取消其余操作. 该函数对象会接收已完成操作的处理器实参. 要触发对其余操作的取消, 它必须返回一个不等于 cancellation_type 值, 其值不同于 boost::asio::cancellation_type::none.

token

一个 完成标记, 其签名由一个 std::array<std::size_t, N> 指示操作的完成顺序, 其后是所有操作的完成处理器实参.

本库提供以下 cancellation_condition 类型:

  • experimental::wait_for_all
  • experimental::wait_for_one
  • experimental::wait_for_one_error
  • experimental::wait_for_one_success
