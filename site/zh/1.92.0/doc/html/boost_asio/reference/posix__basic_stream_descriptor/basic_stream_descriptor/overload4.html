posix::basic_stream_descriptor::basic_stream_descriptor (6 个重载中的第 4 个)

基于现有原生描述符构造流描述符.

template<
    typename ExecutionContext>
basic_stream_descriptor(
    ExecutionContext & context,
    const native_handle_type & native_descriptor,
    constraint_t< is_convertible< ExecutionContext &, execution_context & >::value >  = 0);

此构造函数创建一个流描述符对象, 用于持有现有原生描述符.

参数

context

一种执行上下文, 它提供描述符默认用来为在该描述符上执行的任何异步操作分发处理器的 I/O 执行器.

native_descriptor

新的底层描述符实现.

异常

boost::system::system_error

失败时抛出.
