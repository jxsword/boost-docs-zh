posix::basic_stream_descriptor::write_some (2 个重载中的第 2 个)

向描述符写入一些数据.

template<
    typename ConstBufferSequence>
std::size_t write_some(
    const ConstBufferSequence & buffers,
    boost::system::error_code & ec);

此函数用于向流描述符写入数据. 函数调用将阻塞, 直至成功写入数据的一个或多个字节, 或发生错误.

参数

buffers

要写入描述符的一个或多个数据缓冲区.

ec

用于指示发生了何种错误 (如无错误则不设置) .

返回值

写入的字节数. 如果发生错误则返回 0.

备注

write_some 操作可能不会将全部数据传输给对端. 如果需要确保在阻塞操作完成之前写入全部数据, 请使用 write 函数.
