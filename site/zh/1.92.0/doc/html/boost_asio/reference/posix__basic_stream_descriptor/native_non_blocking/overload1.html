posix::basic_stream_descriptor::native_non_blocking (3 个重载中的第 1 个)

继承自 posix::basic_descriptor.

获取原生描述符实现的非阻塞模式.

bool native_non_blocking() const;

此函数用于获取底层原生描述符的非阻塞模式. 该模式对描述符对象同步操作的行为没有影响.

返回值

若底层描述符处于非阻塞模式, 则为 true, 此时直接系统调用可能以 boost::asio::error::would_block (或等效的系统错误) 失败.

备注

当前非阻塞模式由描述符对象缓存. 因此, 如果非阻塞模式是直接在原生描述符上设置的, 返回值可能不正确.
