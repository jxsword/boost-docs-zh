posix::basic_stream_descriptor::native_non_blocking (3 个重载中的第 3 个)

继承自 posix::basic_descriptor.

设置原生描述符实现的非阻塞模式.

void native_non_blocking(
    bool mode,
    boost::system::error_code & ec);

此函数用于修改底层原生描述符的非阻塞模式. 它对描述符对象同步操作的行为没有影响.

参数

mode

若为 true, 底层描述符将进入非阻塞模式, 直接系统调用可能以 boost::asio::error::would_block (或等效的系统错误) 失败.

ec

设置为指示发生了何种错误 (若有) . 若 mode 为 false, 但 non_blocking() 的当前值为 true, 则此函数以 boost::asio::error::invalid_argument 失败, 因为该组合没有意义.
