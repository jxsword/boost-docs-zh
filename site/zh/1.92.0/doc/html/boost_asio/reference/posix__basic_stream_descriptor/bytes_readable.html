posix::basic_stream_descriptor::bytes_readable

继承自 posix::descriptor_base.

获取可在不阻塞的情况下读取的数据量的 I/O 控制命令.

typedef implementation_defined bytes_readable;

实现 FIONREAD I/O 控制命令.

示例 
boost::asio::posix::stream_descriptor descriptor(my_context);
...
boost::asio::descriptor_base::bytes_readable command(true);
descriptor.io_control(command);
std::size_t bytes_readable = command.get();
要求

头文件: boost/asio/posix/basic_stream_descriptor.hpp

便捷头文件: boost/asio.hpp
