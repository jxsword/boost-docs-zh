ssl::verify_client_once

在重新协商时不请求客户端证书. 除非设置了 ssl::verify_peer, 否则忽略此选项.

const int verify_client_once = implementation_defined;
要求

头文件: boost/asio/ssl/verify_mode.hpp

便捷头文件: boost/asio/ssl.hpp
