可获取的套接字选项要求

类型 X 满足 GettableSocketOption 要求, 如果它满足下面列出的要求.

在下表中, a 表示类型为 X 的 (可能为 const 的) 值, b 表示类型为 X 的值, p 表示满足 Protocol 要求的 (可能为 const 的) 值, s 表示可转换为 size_t 的某类型的 (可能为 const 的) 值, 并以字节为单位表示大小.

表 21. 可扩展实现的 GettableSocketOption 要求

表达式

类型

断言/注释
前置/后置条件

a.level(p)

int

返回一个值, 适合作为 level 实参传递给 POSIX getsockopt() (或等价函数) .

a.name(p)

int

返回一个值, 适合作为 option_name 实参传递给 POSIX getsockopt() (或等价函数) .

b.data(p)

void*

返回一个指针, 适合作为 option_value 实参传递给 POSIX getsockopt() (或等价函数) .

a.size(p)

size_t

返回一个值, 在执行适当的整数转换后, 适合作为 option_len 实参传递给 POSIX getsockopt() (或等价函数) .

b.resize(p,s)

后置条件: b.size(p) == s.
在函数成功完成后, 将 option_len 实参中包含的值传递给 POSIX getsockopt() (或等价函数) . 若套接字选项对象 b 不支持指定的大小, 则允许抛出异常.
