ip::basic_resolver_iterator::reference

对迭代器应用 operator*() 所得结果的类型.

typedef const basic_resolver_entry< InternetProtocol > & reference;
类型

名称

说明

endpoint_type

与端点条目关联的端点类型.

protocol_type

与端点条目关联的协议类型.
成员函数

名称

说明

basic_resolver_entry [constructor]

默认构造函数.
—
以指定的端点、主机名和服务名构造.

endpoint

获取与该条目关联的端点.

host_name

获取与该条目关联的主机名.

operator endpoint_type

转换为与该条目关联的端点.

service_name

获取与该条目关联的服务名.

ip::basic_resolver_entry 类模板描述解析器返回的一个条目.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

要求

头文件: boost/asio/ip/basic_resolver_iterator.hpp

便捷头文件: boost/asio.hpp
