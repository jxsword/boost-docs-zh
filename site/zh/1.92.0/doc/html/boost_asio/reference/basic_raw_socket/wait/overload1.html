basic_raw_socket::wait (2 个重载中的第 1 个)

继承自 basic_socket.

等待套接字变为可读、可写, 或存在待处理的错误条件.

void wait(
    wait_type w);

此函数用于执行阻塞等待, 直至套接字进入可读、可写或错误条件状态.

参数

w

指定所期望的套接字状态.

示例

等待套接字变为可读.

boost::asio::ip::tcp::socket socket(my_context);
...
socket.wait(boost::asio::ip::tcp::socket::wait_read);
