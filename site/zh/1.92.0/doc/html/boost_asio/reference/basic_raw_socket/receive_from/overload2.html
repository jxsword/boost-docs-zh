basic_raw_socket::receive_from (3 个重载中的第 2 个)

接收原始数据以及发送方的端点.

template<
    typename MutableBufferSequence>
std::size_t receive_from(
    const MutableBufferSequence & buffers,
    endpoint_type & sender_endpoint,
    socket_base::message_flags flags);

此函数用于接收原始数据. 函数调用将阻塞, 直到数据被成功接收或发生错误.

参数

buffers

接收数据所用的一份或多份缓冲区.

sender_endpoint

一个端点对象, 接收数据远程发送方的端点.

flags

指定如何进行接收调用的标志.

返回值

接收到的字节数.

异常

boost::system::system_error

失败时抛出.
