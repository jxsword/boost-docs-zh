basic_raw_socket::async_connect

继承自 basic_socket.

启动异步连接.

template<
    typename ConnectToken = default_completion_token_t<executor_type>>
DEDUCED async_connect(
    const endpoint_type & peer_endpoint,
    ConnectToken && token = default_completion_token_t< executor_type >());

此函数用于将套接字异步连接到指定的远程端点. 它是 异步操作 的发起函数, 并且总是立即返回.

若套接字尚未打开, 则自动打开. 若连接失败且套接字是自动打开的, 套接字不会回到关闭状态.

参数

peer_endpoint

套接字将连接到的远程端点. 将按需复制该端点对象.

token

将用于产生完成处理器的 完成标记, 该处理器将在连接完成时被调用. 可能的完成标记包括 use_future、use_awaitable、yield_context, 或具有正确完成签名的函数对象. 完成处理器的函数签名必须为:

void handler(
  const boost::system::error_code& error // Result of operation.
);

无论异步操作是否立即完成, 完成处理器都不会在此函数内部被调用. 若立即完成, 将以等同于使用 async_immediate 的方式调用处理器.

完成签名 
void(boost::system::error_code)
示例 
void connect_handler(const boost::system::error_code& error)
{
  if (!error)
  {
    // Connect succeeded.
  }
}

...

boost::asio::ip::tcp::socket socket(my_context);
boost::asio::ip::tcp::endpoint endpoint(
    boost::asio::ip::address::from_string("1.2.3.4"), 12345);
socket.async_connect(endpoint, connect_handler);
逐操作取消

在 POSIX 或 Windows 操作系统上, 此异步操作支持对以下 cancellation_type 值进行取消:

  • cancellation_type::terminal
  • cancellation_type::partial
  • cancellation_type::total
