用于指定文件名、行号和函数名的构造函数.

use_awaitable_t 类及其值 use_awaitable 用于表示当前正在执行的协程. 该完成标记可作为处理器传递给异步操作. 例如:

awaitable<void> my_coroutine()
{
  std::size_t n = co_await my_socket.async_read_some(buffer, use_awaitable);
  ...
}

与 co_await 一起使用时, 发起函数 (async_read_some, 即上例中的函数) 会挂起当前协程. 当异步操作完成时协程恢复执行, 并返回操作的结果.

要求
