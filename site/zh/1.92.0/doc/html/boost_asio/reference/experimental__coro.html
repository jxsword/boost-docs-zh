experimental::coro

可恢复协程的主类型.

template<
    typename Yield = void,
    typename Return = void,
    typename Executor = any_io_executor,
    typename Allocator = std::allocator<void>>
struct coro
类型

名称

说明

allocator_type

分配器类型.

completion_handler

async_resume 使用的完成处理器类型.

error_type

协程的错误类型. noexcept 协程为 void.

executor_type

执行器类型.

input_type

可以传入对称协程的值. 非对称协程为 void.

promise_type

协程内部的 promise 类型.

result_type

co_await 或 async_resume 接收的类型. 它是 yield 与 return 的组合.

return_type

可以通过 co_return 传出的类型.

signature_type

async_resume 使用的签名.

traits

协程的特征. 详见 boost::asio::experimental::coro_traits.

yield_type

可以通过 co_yield 传出的类型.
成员函数

名称

说明

async_resume

恢复执行协程.

coro [constructor]

默认构造函数, 给出一个无效的协程.
—
移动构造函数.
—

get_allocator

获取所用的分配器.

get_executor

获取所用的执行器.

is_open

检查协程是否处于打开状态, 即是否可以恢复执行.

operator bool

检查协程是否处于打开状态, 即是否可以恢复执行.

operator co_await

用于不带输入值的协程的运算符.

operator()

用于带输入值的协程的运算符.

operator=

移动赋值.

~coro [destructor]

析构函数. 若其持有一个有效协程, 则销毁该协程.
数据成员

名称

说明

is_noexcept [static]

协程是否为 noexcept.

模板参数 Yield 指定 co_yield 使用的类型或签名, Return 指定 co_return 所用的类型, 且 Executor 指定底层执行器类型.
