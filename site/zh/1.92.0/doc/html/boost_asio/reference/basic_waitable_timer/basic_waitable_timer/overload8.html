basic_waitable_timer::basic_waitable_timer (8 个重载中的第 8 个)

从另一个 basic_waitable_timer 移动构造.

template<
    typename Executor1>
basic_waitable_timer(
    basic_waitable_timer< Clock, WaitTraits, Executor1 > && other,
    constraint_t< is_convertible< Executor1, Executor >::value >  = 0);

此构造函数将一个定时器从一个对象移动到另一个对象.

参数

other

移动来源的另一个 basic_waitable_timer 对象.

备注

移动之后, 被移动的对象所处的状态等同于使用 basic_waitable_timer(const executor_type&) 构造函数构造后的状态.
