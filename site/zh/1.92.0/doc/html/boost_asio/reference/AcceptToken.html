接受标记要求

接受标记是一个 完成标记, 针对完成签名 void(error_code).

示例

以自由函数作为接受标记:

void accept_handler(
    const boost::system::error_code& ec)
{
  ...
}

作为接受标记的函数对象:

struct accept_handler
{
  ...
  void operator()(
      const boost::system::error_code& ec)
  {
    ...
  }
  ...
};

以 lambda 作为接受标记:

acceptor.async_accept(...,
    [](const boost::system::error_code& ec)
    {
      ...
    });

使用 std::bind() 适配为接受标记的非静态类成员函数:

void my_class::accept_handler(
    const boost::system::error_code& ec)
{
  ...
}
...
acceptor.async_accept(...,
    std::bind(&my_class::accept_handler,
      this, std::placeholders::_1));

使用 boost::bind() 适配为接受标记的非静态类成员函数:

void my_class::accept_handler(
    const boost::system::error_code& ec)
{
  ...
}
...
acceptor.async_accept(...,
    boost::bind(&my_class::accept_handler,
      this, boost::asio::placeholders::error));

使用 use_future 作为接受标记:

std::future<void> f = acceptor.async_accept(..., boost::asio::use_future);
...
try
{
  f.get();
}
catch (const system_error& e)
{
  ...
}

使用 use_awaitable 作为接受标记:

boost::asio::awaitable<void> my_coroutine()
{
  try
  {
    ...
    co_await acceptor.async_accept(..., boost::asio::use_awaitable);
    ...
  }
  catch (const system_error& e)
  {
    ...
  }
}
