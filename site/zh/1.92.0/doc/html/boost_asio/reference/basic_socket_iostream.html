basic_socket_iostream

套接字的 iostream 接口.

template<
    typename Protocol,
    typename Clock = chrono::steady_clock,
    typename WaitTraits = wait_traits<Clock>>
class basic_socket_iostream :
  public std::basic_iostream< char >
类型

名称

说明

clock_type

时钟类型.

duration

时长类型.

endpoint_type

端点类型.

protocol_type

协议类型.

time_point

时间类型.
成员函数

名称

说明

basic_socket_iostream [构造函数]

构造一个 basic_socket_iostream 但不建立连接.
—
从提供的套接字构造一个 basic_socket_iostream.
—
从另一个对象移动构造一个 basic_socket_iostream.
—
建立到与解析器查询对应的端点的连接.

close

关闭连接.

connect

建立到与解析器查询对应的端点的连接.

error

获取与流关联的最后一个错误.

expires_after

以相对当前时间的方式设置流的到期时间.

expires_at

以绝对时间设置流的到期时间.

expiry

以绝对时间获取流的到期时间.

operator=

从另一个对象移动赋值一个 basic_socket_iostream.

rdbuf

返回指向底层 streambuf 的指针.

socket

获取底层套接字的引用.
