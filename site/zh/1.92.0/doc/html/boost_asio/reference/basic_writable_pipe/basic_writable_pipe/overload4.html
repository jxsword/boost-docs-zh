basic_writable_pipe::basic_writable_pipe (6 个重载中的第 4 个)

在现有的原生管道上构造一个 basic_writable_pipe.

template<
    typename ExecutionContext>
basic_writable_pipe(
    ExecutionContext & context,
    const native_handle_type & native_pipe,
    constraint_t< is_convertible< ExecutionContext &, execution_context & >::value >  = 0);

此构造函数创建一个管道对象以持有现有的原生管道.

参数

context

一种执行上下文, 它提供管道默认将用于为在其上执行的任何异步操作分派处理器的 I/O 执行器.

native_pipe

A native pipe.

异常

boost::system::system_error

失败时抛出.
