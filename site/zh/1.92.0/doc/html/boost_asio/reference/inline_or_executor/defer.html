inline_or_executor::defer

请求 inline_or_executor 调用给定的函数对象.

template<
    typename Function,
    typename Allocator>
void defer(
    Function && f,
    const Allocator & a) const;

此函数用于请求执行器执行给定的函数对象. 函数对象绝不会在此函数内部执行, 而是由底层执行器的 defer 函数进行调度.

参数

f

要调用的函数对象. 执行器将根据需要复制处理器对象. 函数对象的函数签名必须是:

void function();
a

执行器可用于分配函数调用所需内部存储的分配器.
