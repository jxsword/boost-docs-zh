inline_or_executor::execute

请求 inline_or_executor 调用给定的函数对象.

template<
    typename Function>
constraint_t< traits::execute_member< const Executor &, Function >::is_valid, void > execute(
    Function && f) const;

此函数用于请求 inline_or_executor 执行给定的函数对象. 函数对象将内联执行, 或按照底层执行器的属性执行.

参数

f

要调用的函数对象. 执行器将根据需要复制处理器对象. 函数对象的函数签名必须是:

void function();
