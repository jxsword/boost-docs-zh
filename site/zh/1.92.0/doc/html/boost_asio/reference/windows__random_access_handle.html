windows::random_access_handle

随机访问句柄典型用法的 typedef.

typedef basic_random_access_handle random_access_handle;
类型

名称

说明

rebind_executor

把句柄类型重绑定到另一个执行器.

executor_type

与该对象关联的执行器的类型.

lowest_layer_type

overlapped_handle 始终是最底层.

native_handle_type

句柄的原生表示.
成员函数

名称

说明

assign

将现有的原生句柄赋给句柄.

async_read_some_at

在指定偏移量处启动异步读取.

async_write_some_at

在指定偏移量处启动异步写入.

basic_random_access_handle [constructor]

构造未打开的随机访问句柄.
—
在现有原生句柄上构造随机访问句柄.
—
从另一个句柄移动构造随机访问句柄.
—
从另一执行器类型的句柄移动构造随机访问句柄.

cancel

取消与该句柄关联的所有异步操作.

close

关闭句柄.

get_executor

获取与该对象关联的执行器.

is_open

确定句柄是否已打开.

lowest_layer

获取对最底层的引用.
—
获取对最底层的 const 引用.

native_handle

获取原生句柄表示.

operator=

从另一个句柄移动赋值随机访问句柄.
—
从另一执行器类型的句柄移动赋值随机访问句柄.

read_some_at

在句柄的指定偏移量处读取一些数据.

release

释放底层原生句柄的所有权.

write_some_at

向句柄的指定偏移量处写入一些数据.

windows::basic_random_access_handle 类提供异步和阻塞的随机访问句柄功能.

线程安全

不同 对象: 安全.

共享 对象: 不安全.
