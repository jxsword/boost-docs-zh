等待特征要求

basic_waitable_timer 模板使用等待特征, 允许程序定制 wait 与 async_wait 的行为. [注: 等待特征的可能用途包括:
— 启用基于非实时时钟的定时器.
— 确定基于实际时钟 (wallclock) 的定时器对系统时间变化的响应速度.
— 纠正误差或将超时舍入到边界.
— 防止时长溢出. 也就是说, 程序可将定时器的到期时间 e 设为 Clock::max() (意味着永不到达) 或 Clock::min() (意味着始终在过去) . 因此, 将定时器到期前的时长计算为 e - Clock::now() 可能导致溢出. —注结束]

对类型 Clock (其满足 Clock 要求, C++Std [time.clock.req]) 而言, 若类型 X 满足下面列出的要求, 则其满足 WaitTraits 要求.

在下表中, t 表示类型为 Clock::time_point 的 (可能为 const 的) 值; d 表示类型为 Clock::duration 的 (可能为 const 的) 值.
