experimental::as_single_t

一个 完成标记 适配器, 用于指定把完成处理器的实参合并为单个实参.

template<
    typename CompletionToken>
class as_single_t
类型

名称

说明

as_default_on_t

把 I/O 对象适配为以 as_single_t 作为默认完成标记类型的类型别名.

default_constructor_tag

标记类型, 用于防止"默认"构造函数被用于转换.

executor_with_default

适配一个执行器, 把 as_single_t 完成标记添加为默认完成标记.

构造函数.
数据成员

名称

说明

token_

该 experimental::as_single_t 类用于表示: 完成处理器的所有实参都应合并为一个实参传递. 如果已有一个实参, 则该实参按原样传递. 如果有多个实参, 这些实参首先被移动到一个 std::tuple, 然后把该元组传递给完成处理器.
