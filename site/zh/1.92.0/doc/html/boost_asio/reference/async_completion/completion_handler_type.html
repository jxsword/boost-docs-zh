async_result 特征是一个定制点, 用于 异步操作 的发起函数内部. 该特征组合了:

  • 描述异步操作将传递给完成处理器的实参的完成签名 (或多个签名) ;
  • 调用者提供的 完成标记 类型; 以及
  • 操作的内部实现.

该特征的特化必须满足 async_result 要求, 并负责确定:

  • 在异步操作结束时将被调用的具体完成处理器类型;
  • 发起函数的返回类型;
  • 如何获得发起函数的返回值; 以及
  • 如何以及何时通过调用所提供的发起函数对象来启动操作.

此模板可为用户定义的完成标记类型特化. 主模板假定 CompletionToken 已经是一个具体的完成处理器.

备注

为了向后兼容, 主模板实现了与 async_result 特征的遗留形式相关联的成员类型与函数. 这些成员在下面的文档中标注为“遗留”. 为满足 async_result 要求, 用户对这一特征的特化无需实现这些成员.

一般而言, 异步操作的实现者应使用 async_initiate 函数, 而不是直接使用 async_result 特征.

关于 async_result 与 async_initiate 所扮演角色的更详细讨论, 参见 完成标记 的概述文档.
