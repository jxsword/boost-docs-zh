ip::basic_resolver_query

传递给解析器的一个查询.

template<
    typename InternetProtocol>
class basic_resolver_query :
  public ip::resolver_query_base
类型

名称

说明

flags

一种位掩码类型 (C++ Std [lib.bitmask.types]) .

protocol_type

与端点查询关联的协议类型.
成员函数

名称

说明

basic_resolver_query [constructor]

以任意协议的指定服务名构造.
—
以给定协议的指定服务名构造.
—
以任意协议的指定主机名和服务名构造.
—
以给定协议的指定主机名和服务名构造.
—
从另一个对象拷贝构造 basic_resolver_query.
—
从另一个对象移动构造 basic_resolver_query.

hints

获取与该查询关联的提示.

host_name

获取与该查询关联的主机名.

service_name

获取与该查询关联的服务名.
数据成员

名称

说明

address_configured [static]

仅当系统配置了非回环 IPv4 地址时才返回 IPv4 地址. 仅当系统配置了非回环 IPv6 地址时才返回 IPv6 地址.

all_matching [static]

若与 v4_mapped 一起使用, 返回所有匹配的 IPv6 和 IPv4 地址.

canonical_name [static]

确定查询中指定主机的规范名称.

numeric_host [static]

主机名应被视为定义 IPv4 或 IPv6 地址的数字字符串, 不应尝试进行名称解析.

numeric_service [static]

服务名应被视为定义端口号的数字字符串, 不应尝试进行名称解析.

passive [static]

指示返回的端点旨在用作本地绑定的套接字端点.

v4_mapped [static]

若查询的协议族指定为 IPv6, 则在未找到 IPv6 地址时返回 IPv4 映射的 IPv6 地址.

ip::basic_resolver_query 类模板描述可传递给解析器的查询.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

要求

头文件: boost/asio/ip/basic_resolver_query.hpp

便捷头文件: boost/asio.hpp
