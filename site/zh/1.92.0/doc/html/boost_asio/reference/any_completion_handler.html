any_completion_handler 类模板是完成处理器的多态包装, 它通过类型擦除接口传播关联执行器、关联分配器与关联取消槽.

使用 any_completion_handler 时, 需将一个或多个完成签名为模板参数. 这些签名决定了可通过多态接口传递给处理器的实参.

any_completion_handler 的典型用途包括:

  • 异步操作实现的分离编译.
  • 实现异步操作与虚函数之间的互操作性.
