dynamic_string_buffer::dynamic_string_buffer (3 个重载中的第 1 个)

从 string 构造一个动态缓冲区.

dynamic_string_buffer(
    std::basic_string< Elem, Traits, Allocator > & s,
    std::size_t maximum_size = (std::numeric_limits< std::size_t >::max)());
参数

s

用作动态缓冲区后备存储的 string. 该对象保存对 string 的引用, 用户负责确保在 dynamic_string_buffer 对象及其副本被使用期间, string 对象保持有效.

DynamicBuffer_v1: string 中任何已有数据都被视为动态缓冲区的输入序列.

参数

maximum_size

以字节为单位指定缓冲区的最大大小.
