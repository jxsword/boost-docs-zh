dynamic_string_buffer::prepare

DynamicBuffer_v1: 获取表示输出序列的缓冲区列表, 其大小为给定值.

mutable_buffers_type prepare(
    std::size_t n);

确保输出序列能容纳 n 个字节, 并按需调整 basic_string 对象的大小.

返回值

一个 mutable_buffers_type 类型的对象, 满足 MutableBufferSequence 要求, 表示输出序列开头大小为 n 的 basic_string 内存.

异常

std::length_error

如果 size() + n > max_size().

备注

任何修改输入序列或输出序列的 dynamic_string_buffer 或 basic_string 成员函数都会使返回的对象失效.
