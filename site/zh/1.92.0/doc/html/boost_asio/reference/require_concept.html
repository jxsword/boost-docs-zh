require_concept

将强制概念的属性应用于对象的定制点.

constexpr unspecified require_concept = unspecified;

名称 require_concept 表示一个定制点对象. 表达式 boost::asio::require_concept(E, P) (对于某些子表达式 E 和 P, 类型分别为 T = decay_t<decltype(E)> 和 Prop = decay_t<decltype(P)>) 表达式等价于:

  • 若 is_applicable_property_v<T, Prop> && Prop::is_requirable_concept 不是值为 true 的良构常量表达式, 则 boost::asio::require_concept(E, P) 非良构.
  • 否则, E 适用于以下情形: 表达式 Prop::template static_query_v<T> == Prop::value() 是值为 true 的良构常量表达式.
  • 否则, (E).require_concept(P) 适用于以下情形: 表达式 (E).require_concept(P) 良构.
  • 否则, require_concept(E, P) 适用于以下情形: 表达式 require_concept(E, P) 在不包含 require_concept 定制点对象声明的上下文中执行重载决议后为有效表达式.
  • 否则, boost::asio::require_concept(E, P) 非良构.
要求

头文件: boost/asio/require_concept.hpp

便捷头文件: boost/asio.hpp
