服务要求

类是 服务, 若其公开且无歧义地派生自 execution_context::service, 或公开且无歧义地派生自身一个服务. 对服务 S 而言, S::key_type 应为有效并表示一个类型 (C++Std [temp.deduct]) , is_base_of_v<typename S::key_type, S> 应为 true, 且 S 应满足 Destructible 要求 (C++Std [destructible]) .

所有服务构造函数的第一个形参应为指向 execution_context 的左值引用. 该形参表示 execution_context 对象, 即服务对象所属的一组服务. [注: 这些构造函数可由 make_service 函数调用. —注结束]

服务应提供一个显式构造函数, 其唯一形参为指向 execution_context 的左值引用. [注: 该构造函数可由 use_service 函数调用. —注结束]

class my_service : public execution_context::service
{
public:
  typedef my_service key_type;
  explicit my_service(execution_context& ctx);
  my_service(execution_context& ctx, int some_value);
private:
  virtual void shutdown() noexcept override;
  ...
};

服务的 shutdown 成员函数应销毁该服务所持有的所有用户定义函数对象副本.
