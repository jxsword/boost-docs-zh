write (1 of 16 overloads)

在返回之前, 向流写入所提供的全部数据.

template<
    typename SyncWriteStream,
    typename ConstBufferSequence>
std::size_t write(
    SyncWriteStream & s,
    const ConstBufferSequence & buffers,
    constraint_t< is_const_buffer_sequence< ConstBufferSequence >::value >  = 0);

此函数用于向流写入一定数量的字节数据. 调用将阻塞, 直到以下条件之一成立:

  • 所提供缓冲区中的全部数据均已写入. 即已传输的字节数等于各缓冲区大小之和.
  • 发生了错误.

此操作通过零次或多次调用流的 write_some 函数来实现.

参数

s

数据要写入的流. 其类型必须支持 SyncWriteStream 概念.

buffers

包含待写入数据的一个或多个缓冲区. 缓冲区大小之和表示写入流的最大字节数.

返回值

传输的字节数.

异常

boost::system::system_error

失败时抛出.

示例

要写入单个数据缓冲区, 请按如下方式使用 buffer 函数:

boost::asio::write(s, boost::asio::buffer(data, size));

有关一次性写入多个缓冲区, 以及如何将其用于数组、boost::array 或 std::vector 的信息, 参见 buffer 文档.

备注

此重载等价于调用:

boost::asio::write(
   s, buffers,
   boost::asio::transfer_all());
