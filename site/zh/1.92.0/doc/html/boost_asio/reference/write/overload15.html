write (15 of 16 overloads)

在返回之前, 向流写入一定数量的数据.

template<
    typename SyncWriteStream,
    typename DynamicBuffer_v2,
    typename CompletionCondition>
std::size_t write(
    SyncWriteStream & s,
    DynamicBuffer_v2 buffers,
    CompletionCondition completion_condition,
    constraint_t< is_dynamic_buffer_v2< DynamicBuffer_v2 >::value >  = 0,
    constraint_t< is_completion_condition< CompletionCondition >::value >  = 0);

此函数用于向流写入一定数量的字节数据. 调用将阻塞, 直到以下条件之一成立:

  • 所提供的动态缓冲区序列中的全部数据均已写入.
  • completion_condition 函数对象返回 0.

此操作通过零次或多次调用流的 write_some 函数来实现.

参数

s

数据要写入的流. 其类型必须支持 SyncWriteStream 概念.

buffers

从中写入数据的动态缓冲区序列. 已成功写入的数据会自动从缓冲区中移除.

completion_condition

将被调用以判定写操作是否完成的函数对象. 该函数对象的签名必须为:

std::size_t completion_condition(
  // Result of latest write_some operation.
  const boost::system::error_code& error,

  // Number of bytes transferred so far.
  std::size_t bytes_transferred
);

返回值 0 表示写操作已完成. 非零返回值表示下一次调用流的 write_some 函数时要写入的最大字节数.

返回值

传输的字节数.

异常

boost::system::system_error

失败时抛出.
