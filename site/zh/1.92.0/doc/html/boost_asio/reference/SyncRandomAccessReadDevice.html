面向缓冲区的同步随机访问读取设备要求

在下表中, a 表示一个同步随机访问读取设备对象, o 表示类型为 boost::uint64_t 的偏移量, mb 表示满足 可变缓冲区序列 要求的对象, ec 表示类型为 error_code 的对象.

表 30. 面向缓冲区的同步随机访问读取设备要求

操作

类型

语义, 前置/后置条件

a.read_some_at(o, mb);

size_t

等价于:

error_code ec;
size_t s = a.read_some_at(o, mb, ec);
if (ec) throw system_error(ec);
return s;

a.read_some_at(o, mb, ec);

size_t

从设备 a 的偏移量 o 处读取一个或多个字节的数据.

可变缓冲区序列 mb 指定数据应存放的内存. read_some_at 操作应始终先完全填满序列中的一个缓冲区, 再继续处理下一个.

若成功, 返回读取的字节数并设置 ec 使 !ec 为 true. 若发生错误, 返回 0 并设置 ec 使 !!ec 为 true.

若序列 mb 中所有缓冲区的总大小为 0, 则函数应立即返回 0.
