basic_streambuf::prepare

获取表示输出序列的缓冲区列表, 具有给定的大小.

mutable_buffers_type prepare(
    std::size_t n);

确保输出序列能够容纳 n 个字符, 并根据需要重新分配字符数组对象.

返回值

一个 mutable_buffers_type 类型的对象, 满足 MutableBufferSequence 要求, 表示输出序列开头的字符数组对象, 使得缓冲区大小之和为 n.

异常

std::length_error

如果 size() + n > max_size().

备注

返回的对象会被任何修改输入序列或输出序列的 basic_streambuf 成员函数置为无效.
