basic_streambuf::data

获取表示输入序列的缓冲区列表.

const_buffers_type data() const;
返回值

一个 const_buffers_type 类型的对象, 满足 ConstBufferSequence 要求, 表示输入序列中的所有字符数组.

备注

返回的对象会被任何修改输入序列或输出序列的 basic_streambuf 成员函数置为无效.
