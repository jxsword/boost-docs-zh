buffers_iterator::reference

对迭代器应用 operator*() 所得结果的类型.

typedef const_or_non_const_ByteType & reference;

如果缓冲区序列存储的缓冲区对象可转换为 mutable_buffer, 则此类型是对非 const ByteType 的引用; 否则, 是对 const ByteType 的引用.

要求

头文件: boost/asio/buffers_iterator.hpp

便捷头文件: boost/asio.hpp
