use_awaitable

一种 完成标记 对象, 表示当前正在执行的协程.

constexpr use_awaitable_t use_awaitable;

用法示例参见 use_awaitable_t 的文档.

要求

头文件: boost/asio/use_awaitable.hpp

便捷头文件: boost/asio.hpp
