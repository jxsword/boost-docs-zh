read_until (24 个重载中的第 15 个)

把数据读入 streambuf, 直至某个函数对象指示匹配.

template<
    typename SyncReadStream,
    typename Allocator,
    typename MatchCondition>
std::size_t read_until(
    SyncReadStream & s,
    boost::asio::basic_streambuf< Allocator > & b,
    MatchCondition match_condition,
    constraint_t< is_match_condition< MatchCondition >::value >  = 0);

此函数用于把数据读入指定的 streambuf, 直至用户定义的匹配条件函数对象作用于该 streambuf 所含数据时指示成功匹配. 调用将阻塞, 直至下列条件之一成立:

  • 匹配条件函数对象返回一个 std::pair, 其第二个元素的求值结果为 true.
  • 发生了错误.

此操作通过对流的 read_some 函数的零次或多次调用实现. 若匹配条件函数对象已指示匹配, 函数将立即返回.

参数

s

要从中读取数据的流. 该类型必须支持 SyncReadStream 概念.

b

要读入数据的 streambuf 对象.

match_condition

将被调用以判定是否存在匹配的函数对象. 该函数对象的签名必须为:

pair<iterator, bool> match_condition(iterator begin, iterator end);

其中 iterator 表示类型:

buffers_iterator<basic_streambuf<Allocator>::const_buffers_type>

迭代器参数 begin 与 end 定义了要扫描以判定是否存在匹配的字节范围. 返回值的 first 成员是一个迭代器, 标记匹配函数已消费字节的末端之后的位置. 该迭代器用于为匹配条件的任何后续调用计算 begin 参数. 若已找到匹配, 返回值的 second 成员为 true, 否则为 false.

返回值

streambuf 的读取区中已被匹配函数完全消费的字节数.

异常

boost::system::system_error

失败时抛出.

备注

read_until 操作成功后, streambuf 中可能在匹配函数对象的部分之后还包含其他数据. 应用程序通常会把这些数据留在 streambuf 中, 供后续的 read_until 操作查看.

备注

is_match_condition 类型特征的默认实现对函数指针以及具有 result_type typedef 的函数对象求值为 true. 对其他用户定义函数对象必须对其特化.

示例

把数据读入 streambuf 直至遇到空白字符:

typedef boost::asio::buffers_iterator<
    boost::asio::streambuf::const_buffers_type> iterator;

std::pair<iterator, bool>
match_whitespace(iterator begin, iterator end)
{
  iterator i = begin;
  while (i != end)
    if (std::isspace(*i++))
      return std::make_pair(i, true);
  return std::make_pair(i, false);
}
...
boost::asio::streambuf b;
boost::asio::read_until(s, b, match_whitespace);

把数据读入 streambuf 直到找到匹配的字符:

class match_char
{
public:
  explicit match_char(char c) : c_(c) {}

  template <typename Iterator>
  std::pair<Iterator, bool> operator()(
      Iterator begin, Iterator end) const
  {
    Iterator i = begin;
    while (i != end)
      if (c_ == *i++)
        return std::make_pair(i, true);
    return std::make_pair(i, false);
  }

private:
  char c_;
};

namespace asio {
  template <> struct is_match_condition<match_char>
    : public boost::true_type {};
} // namespace asio
...
boost::asio::streambuf b;
boost::asio::read_until(s, b, match_char('a'));
