read_until (24 个重载中的第 11 个)

把数据读入 streambuf, 直至其中包含指定分隔符.

template<
    typename SyncReadStream,
    typename Allocator>
std::size_t read_until(
    SyncReadStream & s,
    boost::asio::basic_streambuf< Allocator > & b,
    string_view delim);

此函数用于把数据读入指定的 streambuf, 直至该 streambuf 的读取区 (get area) 包含指定分隔符. 调用将阻塞, 直至下列条件之一成立:

  • streambuf 的读取区包含指定分隔符.
  • 发生了错误.

此操作通过对流的 read_some 函数的零次或多次调用实现. 若 streambuf 的读取区已包含该分隔符, 函数将立即返回.

参数

s

要从中读取数据的流. 该类型必须支持 SyncReadStream 概念.

b

要读入数据的 streambuf 对象.

delim

分隔符字符串.

返回值

streambuf 的读取区中直至并包含分隔符的字节数.

异常

boost::system::system_error

失败时抛出.

备注

read_until 操作成功后, streambuf 中可能在分隔符之后还包含其他数据. 应用程序通常会把这些数据留在 streambuf 中, 供后续的 read_until 操作查看.

示例

把数据读入 streambuf 直至遇到换行符:

boost::asio::streambuf b;
boost::asio::read_until(s, b, "\r\n");
std::istream is(&b);
std::string line;
std::getline(is, line);

read_until 操作成功完成后, 缓冲区 b 包含该分隔符:

{ 'a', 'b', ..., 'c', '\r', '\n', 'd', 'e', ... }

随后对 std::getline 的调用会提取包括换行符 (该换行符被丢弃) 在内的全部数据, 使字符串 line 包含:

{ 'a', 'b', ..., 'c', '\r' }

剩余数据如下保留在缓冲区 b 中:

{ 'd', 'e', ... }

这些数据可能是新行的开头, 将由后续的 read_until 操作提取.
