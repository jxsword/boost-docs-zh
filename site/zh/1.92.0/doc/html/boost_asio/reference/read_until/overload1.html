read_until (24 个重载中的第 1 个)

把数据读入动态缓冲区序列, 直至其中包含指定分隔符.

template<
    typename SyncReadStream,
    typename DynamicBuffer_v1>
std::size_t read_until(
    SyncReadStream & s,
    DynamicBuffer_v1 && buffers,
    char delim,
    constraint_t< is_dynamic_buffer_v1< decay_t< DynamicBuffer_v1 > >::value >  = 0,
    constraint_t< !is_dynamic_buffer_v2< decay_t< DynamicBuffer_v1 > >::value >  = 0);

此函数用于把数据读入指定的动态缓冲区序列, 直至该动态缓冲区序列的读取区 (get area) 包含指定分隔符. 调用将阻塞, 直至下列条件之一成立:

  • 动态缓冲区序列的读取区包含指定分隔符.
  • 发生了错误.

此操作通过对流的 read_some 函数的零次或多次调用实现. 若动态缓冲区序列的读取区已包含该分隔符, 函数将立即返回.

参数

s

要从中读取数据的流. 该类型必须支持 SyncReadStream 概念.

buffers

要读入数据的动态缓冲区序列.

delim

分隔符字符.

返回值

动态缓冲区序列的读取区中直至并包含分隔符的字节数.

异常

boost::system::system_error

失败时抛出.

备注

read_until 操作成功后, 动态缓冲区序列中可能在分隔符之后还包含其他数据. 应用程序通常会把这些数据留在动态缓冲区序列中, 供后续的 read_until 操作查看.

示例

把数据读入 std::string 直至遇到换行符:

std::string data;
std::size_t n = boost::asio::read_until(s,
    boost::asio::dynamic_buffer(data), '\n');
std::string line = data.substr(0, n);
data.erase(0, n);

read_until 操作成功完成后, 字符串 data 包含该分隔符:

{ 'a', 'b', ..., 'c', '\n', 'd', 'e', ... }

随后对 substr 的调用会提取包括分隔符在内的全部数据, 使字符串 line 包含:

{ 'a', 'b', ..., 'c', '\n' }

调用 erase 之后, 剩余数据如下保留在缓冲区 b 中:

{ 'd', 'e', ... }

这些数据可能是新行的开头, 将由后续的 read_until 操作提取.
