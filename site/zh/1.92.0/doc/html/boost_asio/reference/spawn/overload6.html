spawn (6 个重载中的第 6 个)

启动一个新的有栈协程, 继承另一个协程的执行器.

template<
    typename Executor,
    typename StackAllocator,
    typename F,
    typename CompletionToken = default_completion_token_t<Executor>>
auto spawn(
    const basic_yield_context< Executor > & ctx,
    allocator_arg_t ,
    StackAllocator && stack_allocator,
    F && function,
    CompletionToken && token = default_completion_token_t< Executor >(),
    constraint_t< is_executor< Executor >::value||execution::is_executor< Executor >::value >  = 0);

此函数用于使用指定的栈分配器启动一个新的有栈协程.

参数

ctx

将当前协程标识为新协程的父协程. 这指定新协程应继承父协程的执行器. 例如, 若父协程在特定的 strand 中执行, 则新协程将在同一 strand 中执行.

stack_allocator

指定用于分配底层协程栈的分配器. 该类型必须满足 Boost.Context 库定义的栈分配器概念.

function

协程函数. 该函数必须可以按如下签名调用:

void function(basic_yield_context<Executor> yield);
token

用于处理协程完成通知的 完成标记. 若返回类型 R (即 function 的返回类型) 为 void, 完成处理器的函数签名必须是:

void handler(std::exception_ptr);

否则, 完成处理器的函数签名必须为:

void handler(std::exception_ptr, R);
完成签名 
void(std::exception_ptr, R)

其中 R 是该函数对象的返回类型.

逐操作取消

新执行线程以仅支持 cancellation_type::terminal 值的取消状态创建. 要更改取消状态, 请调用 basic_yield_context 的成员函数 reset_cancellation_state.
