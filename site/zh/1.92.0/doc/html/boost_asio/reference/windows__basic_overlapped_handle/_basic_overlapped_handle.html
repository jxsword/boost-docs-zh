windows::basic_overlapped_handle::~basic_overlapped_handle

受保护的析构函数, 以防止通过此类型删除.

~basic_overlapped_handle();

此函数销毁句柄, 如同调用 cancel 一样取消与该句柄关联的任何未完成异步等待操作.
