signal_set_base::flags

表示向集合添加信号时可指定的各种标志类型的枚举.

enum flags

取值

none

Bitmask representing no flags.

restart

影响可中断函数的行为: 如果函数在被指定信号中断时本应以 error::interrupted 失败, 则改为重新启动该函数且不以 error::interrupted 失败.

no_child_stop

当子进程停止或已停止的子进程继续时, 不要生成 SIGCHLD.

no_child_wait

当子进程终止时, 不要将其转变为僵尸进程.

dont_care

特殊值, 表示信号注册不关心设置了哪些标志, 因此不会与同一信号的任何先前注册发生冲突.
