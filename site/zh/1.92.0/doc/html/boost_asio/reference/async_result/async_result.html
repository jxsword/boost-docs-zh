async_result::async_result

(遗留. ) 从给定的处理器构造异步结果.

async_result(
    completion_handler_type & h);

使用特化的 async_result 时, 构造函数有机会初始化与完成处理器关联的某些状态, 这些状态随后由发起函数返回.
