experimental::coro::async_resume (2 个重载中的第 1 个)

恢复执行协程.

template<
    typename CompletionToken>
DEDUCED async_resume(
    CompletionToken && token);
参数

token

异步恢复所用的完成标记.

注意

以 noexcept 签名调用无效协程属于未定义行为.

备注

此重载仅适用于不带输入值的协程.
