experimental::coro::traits

协程的特征. 详见 experimental::coro_traits 以了解详情.

typedef coro_traits< Yield, Return, Executor > traits;
类型

名称

说明

completion_handler

async_resume 使用的完成处理器类型.

error_type

协程的错误类型. noexcept 协程为 void.

input_type

可以传入对称协程的值. 非对称协程为 void.

result_type

co_await 或 async_resume 接收的类型. 它是 yield 与 return 的组合.

return_type

可以通过 co_return 传出的类型.

signature_type

async_resume 使用的签名.

yield_type

可以通过 co_yield 传出的类型.
数据成员

名称

说明

is_noexcept [static]

协程是否为 noexcept.

模板参数 Yield 指定 co_yield 使用的类型或签名, Return 指定 co_return 所用的类型, 且 Executor 指定底层执行器类型.

要求

头文件: boost/asio/experimental/coro.hpp

便捷头文件: 无
