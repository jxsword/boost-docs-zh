io_context::strand::operator!=

比较两个 strand 是否不等.

bool operator!=(
    const strand & a,
    const strand & b);

如果两个 strand 引用相同的有序、非并发状态, 则它们相等.

要求

头文件: boost/asio/io_context_strand.hpp

便捷头文件: boost/asio.hpp
