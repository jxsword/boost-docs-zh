io_context::strand::wrap

(已弃用: 请改用 bind_executor.) 创建一个新的处理器, 该处理器会在 strand 上自动分派被包装的处理器.

template<
    typename Handler>
unspecified wrap(
    Handler handler);

此函数用于创建一个新的处理器函数对象, 该对象被调用时会自动把被包装的处理器传递给 strand 的分派函数.

参数

handler

要包装的处理器. strand 会按需复制该处理器对象. 处理器的函数签名必须是:

void handler(A1 a1, ... An an);
返回值

一个函数对象, 被调用时会把被包装的处理器传递给 strand 的分派函数. 给定一个具有如下签名的函数对象:

R f(A1 a1, ... An an);

如果像下面这样把这个函数对象传递给 wrap 函数:

strand.wrap(f);

则返回值是一个具有如下签名的函数对象

void g(A1 a1, ... An an);

该对象被调用时执行的代码等价于:

boost::asio::dispatch(strand, boost::bind(f, a1, ... an));
