uses_executor

uses_executor 特征检测类型 T 是否具有可从 Executor 类型转换而来的关联执行器.

template<
    typename T,
    typename Executor>
struct uses_executor :
  public false_type

满足 BinaryTypeTrait 要求. Asio 库提供派生自 false_type 的定义. 对于可用执行器构造的用户自定义类型 T (其构造函数的第一个实参类型为 executor_arg_t, 第二个实参可从 Executor 类型转换而来), 程序可将此模板特化为派生自 true_type.

要求

头文件: boost/asio/uses_executor.hpp

便捷头文件: boost/asio.hpp
