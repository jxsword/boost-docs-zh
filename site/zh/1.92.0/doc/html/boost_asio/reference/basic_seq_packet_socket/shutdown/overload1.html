basic_seq_packet_socket::shutdown (2 个重载中的第 1 个)

继承自 basic_socket.

禁用套接字上的发送或接收.

void shutdown(
    shutdown_type what);

此函数用于禁用发送操作、接收操作或两者.

参数

what

决定不再允许哪些类型的操作.

异常

boost::system::system_error

失败时抛出.

示例

关闭套接字的发送侧:

boost::asio::ip::tcp::socket socket(my_context);
...
socket.shutdown(boost::asio::ip::tcp::socket::shutdown_send);
