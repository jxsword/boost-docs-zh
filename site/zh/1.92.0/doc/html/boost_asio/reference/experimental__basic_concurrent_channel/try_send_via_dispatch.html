experimental::basic_concurrent_channel::try_send_via_dispatch

尝试以非阻塞方式发送一条消息, 并使用分派语义调用接收操作的完成处理器.

template<
    typename... Args>
bool try_send_via_dispatch(
    Args &&... args);

若缓冲区已满且没有正在等待的接收操作, 则失败.

接收操作的完成处理器可能会在此函数内部被调用.

返回值

true, 成功时为 false, 失败时为
