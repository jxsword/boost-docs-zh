posix::descriptor_base::wait_type

等待类型.

enum wait_type

取值

wait_read

等待描述符变为可读就绪.

wait_write

等待描述符变为可写就绪.

wait_error

等待描述符出现待处理的错误条件.

用于 descriptor::wait() 与 descriptor::async_wait().
