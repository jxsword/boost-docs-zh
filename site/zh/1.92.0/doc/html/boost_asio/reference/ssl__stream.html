ssl::stream

使用 SSL 提供面向流的功能.

    typename Stream>

  public ssl::stream_base,

stream 类模板使用 SSL 提供异步和阻塞的面向流功能.

线程安全

不同 对象: 安全.

共享 对象: 不安全. 应用程序还必须确保所有异步操作都在同一个隐式或显式 strand 内执行.

示例

要把 SSL 流模板与 ip::tcp::socket 一起使用, 你可以这样写:

boost::asio::io_context my_context;
boost::asio::ssl::context ctx(boost::asio::ssl::context::sslv23);
boost::asio::ssl::stream<boost::asio::ip::tcp::socket> sock(my_context, ctx);
