ip::basic_endpoint

描述用于与协议版本无关的 IP 套接字的端点.

template<
    typename InternetProtocol>
class basic_endpoint
类型

名称

说明

data_type

端点结构的类型. 该类型取决于套接字层的底层实现.

protocol_type

与该端点关联的协议类型.
成员函数

名称

说明

address

获取与该端点关联的 IP 地址.
—
设置与该端点关联的 IP 地址.

basic_endpoint [constructor]

默认构造函数.
—
使用端口号构造端点, 端口号按主机的字节序指定. IP 地址将是任意地址 (即 INADDR_ANY 或 in6addr_any). 此构造函数通常用于接受新连接.
—
使用端口号和 IP 地址构造端点. 此构造函数可用于在特定接口上接受连接, 或用于连接到远程端点.
—
拷贝构造函数.
—
移动构造函数.

capacity

以原生类型表示获取端点的容量.

data

以原生类型表示获取底层端点.

operator=

从另一个端点赋值.
—
从另一个端点移动赋值.

port

获取与该端点关联的端口. 端口号始终按主机的字节序表示.
—
设置与该端点关联的端口. 端口号始终按主机的字节序表示.

protocol

与该端点关联的协议.

resize

以原生类型表示设置端点的底层大小.

size

以原生类型表示获取端点的底层大小.

将端点输出为字符串.

ip::basic_endpoint 类模板描述一种可与特定套接字关联的端点.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

要求

头文件: boost/asio/ip/basic_endpoint.hpp

便捷头文件: boost/asio.hpp
