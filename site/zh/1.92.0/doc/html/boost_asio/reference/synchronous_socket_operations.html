对同步套接字操作的要求

本节中, 同步套接字操作 指那些规定为两个重载 (其中一个带 error_code& 类型参数, 另一个不带) 的成员函数:

R f(A1 a1, A2 a2, ..., AN aN);
R f(A1 a1, A2 a2, ..., AN aN, error_code& ec);

对于对象 s, 其同步套接字操作可能阻塞调用线程的条件 (C++Std [defns.block]) 按如下方式确定.

If:

— s.non_blocking() == true,

— 同步套接字操作以某个 POSIX 函数规定, 而该函数不是 poll(),

— 该 POSIX 函数在其失败条件中列出 EWOULDBLOCK 或 EAGAIN 的情形, 并且

— 操作的效果无法立即确立

那么同步套接字操作不得阻塞调用线程. [注: 并且操作的效果不会确立. —注毕]

否则, 同步套接字操作应阻塞调用线程, 直到操作效果确立.
