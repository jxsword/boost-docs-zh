experimental::channel_traits::rebind

把特征重绑定到一组新的签名.

template<
    typename... NewSignatures>
struct rebind
类型

名称

说明

other

此嵌套结构必须有一个唯一的嵌套类型 other, 它为指定的一组签名别名一个特征类型.

要求

头文件: boost/asio/experimental/channel_traits.hpp

便捷头文件: 无
