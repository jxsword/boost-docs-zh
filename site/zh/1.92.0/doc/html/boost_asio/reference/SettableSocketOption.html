可设置的套接字选项要求

类型 X 满足 SettableSocketOption 要求, 如果它满足下面列出的要求.

在下表中, a 表示类型为 X 的 (可能为 const 的) 值, p 表示满足 Protocol 要求的 (可能为 const 的) 值, u 表示一个标识符.

表 29. 可扩展实现的 SettableSocketOption 要求

表达式

类型

断言/注释
前置/后置条件

a.level(p)

int

返回一个值, 适合作为 level 实参传递给 POSIX setsockopt() (或等价函数) .

a.name(p)

int

返回一个值, 适合作为 option_name 实参传递给 POSIX setsockopt() (或等价函数) .

a.data(p)

const void*

返回一个指针, 适合作为 option_value 实参传递给 POSIX setsockopt() (或等价函数) .

a.size(p)

size_t

返回一个值, 在执行适当的整数转换后, 适合作为 option_len 实参传递给 POSIX setsockopt() (或等价函数) .
