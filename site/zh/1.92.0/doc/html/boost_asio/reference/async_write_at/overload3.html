async_write_at (4 个重载中的第 3 个)

启动一个在指定偏移量处写入所提供全部数据的异步操作.

template<
    typename AsyncRandomAccessWriteDevice,
    typename Allocator,
    typename WriteToken = default_completion_token_t<        typename AsyncRandomAccessWriteDevice::executor_type>>
DEDUCED async_write_at(
    AsyncRandomAccessWriteDevice & d,
    uint64_t offset,
    basic_streambuf< Allocator > & b,
    WriteToken && token = default_completion_token_t< typename AsyncRandomAccessWriteDevice::executor_type >(),
    constraint_t< !is_completion_condition< WriteToken >::value >  = 0);

此函数用于在指定偏移量处向随机访问设备异步写入一定数量的字节. 它是 异步操作 的发起函数, 并且总是立即返回. 异步操作将持续进行, 直至下列条件之一成立:

  • 所提供的 basic_streambuf 中的全部数据均已写入.
  • 发生了错误.

此操作通过对设备的 async_write_some_at 函数的零次或多次调用实现, 被称为组合操作. 程序必须确保在该操作完成之前, 设备不执行任何重叠的写操作 (例如 async_write_at、设备的 async_write_some_at 函数, 或任何其他执行写入的组合操作) . 若各操作由其偏移量与待写字节数所定义的区域相交, 则这些操作是重叠的.

参数

d

要写入数据的目标设备. 其类型必须支持 AsyncRandomAccessWriteDevice 概念.

offset

写入数据的偏移量.

b

要从中写出数据的 basic_streambuf 对象. streambuf 的所有权由调用者保留, 调用者必须保证其在完成处理器被调用前保持有效.

token

将用于产生完成处理器的 完成标记, 该处理器将在写入完成时被调用. 可能的完成标记包括 use_future、use_awaitable、yield_context, 或具有正确完成签名的函数对象. 完成处理器的函数签名必须为:

void handler(
  // Result of operation.
  const boost::system::error_code& error,

  // Number of bytes written from the buffers. If an error
  // occurred, this will be less than the sum of the buffer sizes.
  std::size_t bytes_transferred
);

无论异步操作是否立即完成, 完成处理器都不会在此函数内部被调用. 若立即完成, 将以等同于使用 async_immediate 的方式调用处理器.

完成签名 
void(boost::system::error_code, std::size_t)
逐操作取消

此异步操作支持对以下 cancellation_type 值进行取消:

  • cancellation_type::terminal
  • cancellation_type::partial

(前提是 AsyncRandomAccessWriteDevice 类型的 async_write_some_at 操作同样支持它们. )
