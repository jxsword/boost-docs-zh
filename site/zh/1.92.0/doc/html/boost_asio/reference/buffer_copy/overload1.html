buffer_copy (2 个重载中的第 1 个)

把字节从源缓冲区序列复制到目标缓冲区序列.

template<
    typename MutableBufferSequence,
    typename ConstBufferSequence>
std::size_t buffer_copy(
    const MutableBufferSequence & target,
    const ConstBufferSequence & source);
参数

target

一个可修改的缓冲区序列, 表示字节将要复制到的内存区域.

source

一个不可修改的缓冲区序列, 表示字节将要从中复制的内存区域.

返回值

复制的字节数.

备注

复制的字节数取以下两者中的较小者:

  • buffer_size(target)
  • buffer_size(source)

此函数基于 memcpy 实现, 因此不能用于在重叠的内存区域之间进行复制.
