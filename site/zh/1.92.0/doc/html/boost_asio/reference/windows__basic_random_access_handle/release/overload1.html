windows::basic_random_access_handle::release (1 of 2 overloads)

继承自 windows::basic_overlapped_handle.

释放底层原生句柄的所有权.

native_handle_type release();

此函数使所有未完成的异步操作立即结束, 且被取消操作的处理器将收到 boost::asio::error::operation_aborted 错误. 随后原生句柄的所有权转移给调用者.

异常

boost::system::system_error

失败时抛出.

备注

此函数在 Windows 8.1 之前的 Windows 版本上不受支持, 在这些平台上将以 boost::asio::error::operation_not_supported 失败.
