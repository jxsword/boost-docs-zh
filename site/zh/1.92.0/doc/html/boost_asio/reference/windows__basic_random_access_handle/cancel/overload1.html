windows::basic_random_access_handle::cancel (1 of 2 overloads)

继承自 windows::basic_overlapped_handle.

取消与该句柄关联的所有异步操作.

void cancel();

此函数使所有未完成的异步读取或写入操作立即结束, 被取消操作的处理器将收到 boost::asio::error::operation_aborted 错误.

异常

boost::system::system_error

失败时抛出.
