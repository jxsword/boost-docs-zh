windows::basic_random_access_handle::write_some_at (2 of 2 overloads)

向句柄的指定偏移量处写入一些数据.

template<
    typename ConstBufferSequence>
std::size_t write_some_at(
    uint64_t offset,
    const ConstBufferSequence & buffers,
    boost::system::error_code & ec);

此函数用于向随机访问句柄写入数据. 函数调用将阻塞, 直到已成功写入一个或多个字节的数据, 或者发生错误.

参数

offset

写入数据的偏移量.

buffers

一个或多个要写入句柄的数据缓冲区.

ec

用于指示发生了何种错误 (如无错误则不设置) .

返回值

写入的字节数. 如果发生错误则返回 0.

备注

write_some 操作可能不会将全部数据传输给对端. 如果需要确保在阻塞操作完成之前写入全部数据, 请使用 write_at 函数.
