basic_random_access_file::basic_random_access_file (10 个重载中的第 1 个)

构造一个未打开的 basic_random_access_file.

basic_random_access_file(
    const executor_type & ex);

此构造函数初始化一个文件但不打开它. 必须先打开文件, 然后才能从中读取或向其写入数据.

参数

ex

文件默认用于分发在该文件上执行的任何异步操作的处理器所用的 I/O 执行器.
