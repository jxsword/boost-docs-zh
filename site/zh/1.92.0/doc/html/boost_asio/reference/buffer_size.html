buffer_size

获取缓冲区序列中的总字节数.

template<
    typename BufferSequence>
std::size_t buffer_size(
    const BufferSequence & b);

buffer_size 函数确定缓冲区序列中所有缓冲区的总大小, 计算方式如下:

size_t total_size = 0;
auto i = boost::asio::buffer_sequence_begin(buffers);
auto end = boost::asio::buffer_sequence_end(buffers);
for (; i != end; ++i)
{
  const_buffer b(*i);
  total_size += b.size();
}
return total_size;

BufferSequence 模板参数可以满足 ConstBufferSequence 或 MutableBufferSequence 类型要求之一.

要求

头文件: boost/asio/buffer.hpp

便捷头文件: boost/asio.hpp
