cancellation_state

取消状态用于在组合中串联信号和槽.

class cancellation_state
成员函数

名称

说明

cancellation_state [constructor]

构造一个未连接的取消状态.
—
构造并连接到父槽, 以创建新的子槽.

cancelled

返回已被触发的取消类型.

clear

清除指定的取消类型 (如果它们已被触发).

slot

返回与该状态关联的单个子槽.
要求

头文件: boost/asio/cancellation_state.hpp

便捷头文件: boost/asio.hpp
