用于指定文件名、行号和函数名的构造函数.

该 use_coro_t 类及其值 use_coro, 用于表示可被当前可恢复协程等待的操作. 该完成标记可以作为处理器传递给异步操作. 例如:

coro<void> my_coroutine(tcp::socket my_socket)
{
  std::size_t n = co_await my_socket.async_read_some(buffer, use_coro);
  ...
}

与 co_await 一起使用时, 发起函数 (async_read_some, 即上例中的函数) 会挂起当前协程. 当异步操作完成时协程恢复执行, 并返回操作的结果.

注意这个完成标记并不是效率最高的 (要获得最高效率, 请使用默认完成标记 boost::asio::deferred) 但确实提供类型擦除, 因为它总是返回一个 coro.

要求

头文件: boost/asio/experimental/use_coro.hpp

便捷头文件: 无
