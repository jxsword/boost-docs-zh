basic_file::seek_basis

继承自 file_base.

文件中定位 (seek) 的基准.

enum seek_basis

取值

seek_set

定位到绝对位置.

seek_cur

定位到相对于当前文件位置的偏移量.

seek_end

定位到相对于文件末尾的偏移量.
