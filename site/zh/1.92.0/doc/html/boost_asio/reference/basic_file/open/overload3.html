basic_file::open (4 个重载中的第 3 个)

使用指定的路径打开文件.

void open(
    const std::string & path,
    file_base::flags open_flags);

此函数打开文件, 使其使用指定的路径.

参数

path

标识要打开的文件的路径名.

open_flags

决定文件应如何打开的一组标志.

异常

boost::system::system_error

失败时抛出.

必须恰好指定以下 file_base::flags 值之一:

  • flags::read_only
  • flags::write_only
  • flags::read_write

此外, 下列标志可按位或组合:

  • flags::append
  • flags::create
  • flags::exclusive
  • flags::truncate
  • flags::sync_all_on_write
示例 
boost::asio::stream_file file(my_context);
file.open("/path/to/my/file", boost::asio::stream_file::read_only);
