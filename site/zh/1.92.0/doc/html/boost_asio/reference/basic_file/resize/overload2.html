basic_file::resize (2 个重载中的第 2 个)

更改文件的大小.

void resize(
    uint64_t n,
    boost::system::error_code & ec);

此函数将文件调整为指定的大小 (以字节为单位) . 若当前文件大小超过 n, 则丢弃多余数据. 若当前大小小于 n, 则扩展文件并以零填充.

参数

n

文件的新大小.

ec

用于指示发生了何种错误 (如无错误则不设置) .
