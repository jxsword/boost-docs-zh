该 generic::basic_endpoint 类模板描述一种可以与任何套接字类型关联的端点.

备注

套接字类型的 sockaddr 类型必须能够放入一个 sockaddr_storage 结构.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

要求

头文件: boost/asio/generic/datagram_protocol.hpp

便捷头文件: boost/asio.hpp
