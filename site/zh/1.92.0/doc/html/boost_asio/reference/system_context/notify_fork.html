system_context::notify_fork

继承自 execution_context.

通知 execution_context 通知 fork 相关事件.

void notify_fork(
    fork_event event);

此函数用于通知 execution_context 进程即将 fork, 或刚刚完成 fork. 这使得 execution_context 及其包含的服务执行任何必要的清理维护, 以确保 fork 之后能正确运行.

当其他任何 execution_context 函数, 或与 execution_context 的派生类正在另一线程中被调用时, 不得调用此函数. 不过, 在完成处理器内调用此函数是安全的, 前提是没有其他线程正在访问 execution_context 或其派生类.

参数

event

一个 fork 相关事件.

异常

boost::system::system_error

失败时抛出. 若通知失败, 则 execution_context 对象不应再被使用, 应将其销毁.

示例

下面的代码演示了如何使用 notify_fork() 函数:

my_execution_context.notify_fork(execution_context::fork_prepare);
if (fork() == 0)
{
  // This is the child process.
  my_execution_context.notify_fork(execution_context::fork_child);
}
else
{
  // This is the parent process.
  my_execution_context.notify_fork(execution_context::fork_parent);
}
备注

对于 svc (属于 execution_context 集合), 执行 svc->notify_fork();. 处理 fork_prepare 事件时, 服务按服务对象生存期开始的相反顺序被访问. 否则, 服务按服务对象生存期开始的顺序被访问.
