常量缓冲区序列要求

常量缓冲区序列表示一组可用作操作输入的内存区域, 例如套接字的 send 操作.

类型 X 满足 ConstBufferSequence 要求, 如果它满足 Destructible (C++Std [destructible]) 和 CopyConstructible (C++Std [copyconstructible]) 的要求, 以及下面列出的附加要求.

在下表中, x 表示类型为 X 的 (可能为 const 的) 值, 而 u 表示一个标识符.

后置条件:

  boost::asio::buffer_sequence_begin(x),
  boost::asio::buffer_sequence_end(x),
  boost::asio::buffer_sequence_begin(u),
  boost::asio::buffer_sequence_end(u),
  [](const const_buffer& b1,
     const const_buffer& b2)
   {
     return b1.data() == b2.data()
         && b1.size() == b2.size();
   })
