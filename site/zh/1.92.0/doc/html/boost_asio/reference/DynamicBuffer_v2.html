动态缓冲区要求 (版本 2)

动态缓冲区封装了可按需自动调整大小的内存存储.

动态缓冲区类型 X 除须满足下面列出的要求外, 还须满足 CopyConstructible (C++ Std, [copyconstructible]) 类型的要求.

在下表中, X 表示一个动态缓冲区类, x 表示类型为 X& 的值, x1 表示类型为 const X& 的值, pos 与 n 表示类型为 size_t 的值, 而 u 表示一个标识符.

表 14. DynamicBuffer_v2 要求

表达式

类型

断言/注释
前置/后置条件

X::const_buffers_type

满足 ConstBufferSequence 要求的类型.

此类型将底层内存表示为 @c const_buffer 对象的序列.

X::mutable_buffers_type

满足 MutableBufferSequence 要求的类型.

此类型将底层内存表示为 @c mutable_buffer 对象的序列.

x1.size()

size_t

返回底层内存的大小 (以字节为单位) .

x1.max_size()

size_t

返回底层内存允许的最大大小.

x1.capacity()

size_t

返回底层内存无需重新分配即可增长到的最大大小.

x1.data(pos, n)

X::const_buffers_type

返回常量缓冲区序列 u, 其表示从偏移量 pos 开始的底层内存, 且 buffer_size(u) <= n.

x.data(pos, n)

X::mutable_buffers_type

返回可变缓冲区序列 u, 其表示从偏移量 pos 开始的底层内存, 且 buffer_size(u) <= n.

x.grow(n)

要求: size() + n <= max_size().

扩展底层内存, 使其在末尾可容纳额外的 n 个字节. 动态缓冲区按需重新分配内存. 先前使用 data() 获得的所有常量或可变缓冲区序列均失效.

抛出: length_error, 若 size() + n > max_size().

x.shrink(n)

从底层内存的末尾移除 n 个字节. 若 n 大于底层内存的大小, 则清空整个底层内存. 先前使用 data() 获得的所有常量或可变缓冲区序列均失效.

x.consume(n)

从底层内存的开头移除 n 个字节. 若 n 大于底层内存的大小, 则清空整个底层内存. 先前使用 data() 获得的所有常量或可变缓冲区序列均失效.
