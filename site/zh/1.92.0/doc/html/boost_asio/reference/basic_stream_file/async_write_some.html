basic_stream_file::async_write_some

启动一次异步写入.

template<
    typename ConstBufferSequence,
    typename WriteToken = default_completion_token_t<executor_type>>
DEDUCED async_write_some(
    const ConstBufferSequence & buffers,
    WriteToken && token = default_completion_token_t< executor_type >());

此函数用于向流式文件异步写入数据. 它是 异步操作 的发起函数, 并总是立即返回.

参数

buffers

一个或多个要写入文件的数据缓冲区. 虽然 buffers 对象可能根据需要被复制, 但底层内存块的所有权仍由调用者保留, 调用者必须保证它们在完成处理器被调用之前保持有效.

token

将用于产生完成处理器的 完成标记, 该处理器将在写入完成时被调用. 可能的完成标记包括 use_future、use_awaitable、yield_context, 或具有正确完成签名的函数对象. 完成处理器的函数签名必须为:

void handler(
  const boost::system::error_code& error, // Result of operation.
  std::size_t bytes_transferred // Number of bytes written.
);

无论异步操作是否立即完成, 完成处理器都不会在此函数内部被调用. 若立即完成, 将以等同于使用 async_immediate 的方式调用处理器.

完成签名 
void(boost::system::error_code, std::size_t)
备注

write 操作可能不会将全部数据传输给对端. 如果需要确保在异步操作完成之前写入全部数据, 请使用 async_write 函数.

示例

要写入单个数据缓冲区, 请按如下方式使用 buffer 函数:

file.async_write_some(boost::asio::buffer(data, size), handler);

有关一次性写入多个缓冲区, 以及如何将其用于数组、boost::array 或 std::vector 的信息, 参见 buffer 文档.

逐操作取消

在 POSIX 或 Windows 操作系统上, 此异步操作支持对以下 cancellation_type 值进行取消:

  • cancellation_type::terminal
  • cancellation_type::partial
  • cancellation_type::total
