basic_stream_file::basic_stream_file (10 个重载中的第 8 个)

在现有原生文件上构造一个 basic_stream_file.

template<
    typename ExecutionContext>
basic_stream_file(
    ExecutionContext & context,
    const native_handle_type & native_file,
    constraint_t< is_convertible< ExecutionContext &, execution_context & >::value, defaulted_constraint >  = defaulted_constraint());

此构造函数初始化一个流式文件对象以持有现有的原生文件.

参数

context

一个执行上下文, 其提供文件默认用于分发在该文件上执行的任何异步操作的处理器所用的 I/O 执行器.

native_file

新的底层文件实现.

异常

boost::system::system_error

失败时抛出.
