basic_stream_file::cancel (2 个重载中的第 2 个)

继承自 basic_file.

取消与该文件关联的所有异步操作.

void cancel(
    boost::system::error_code & ec);

此函数使所有未决的异步读写操作立即结束, 被取消操作的处理器将收到 boost::asio::error::operation_aborted 错误.

参数

ec

用于指示发生了何种错误 (如无错误则不设置) .

备注

在 Windows XP、Windows Server 2003 及更早版本的 Windows 上运行时, 对 cancel() 的调用将总是以 boost::asio::error::operation_not_supported 失败, 除非定义了 BOOST_ASIO_ENABLE_CANCELIO. 然而, CancelIo 函数有两个在启用之前应当考虑的问题:

  • 它只会取消在当前线程中发起的异步操作.
  • 它可能看似无误地完成, 但取消未完成操作的请求可能被操作系统静默忽略. 它是否生效似乎取决于所安装的驱动程序.

要获得可移植的取消行为, 请考虑使用 close() 函数同时取消未决操作并关闭文件.

在 Windows Vista、Windows Server 2008 及更高版本上运行时, 总是使用 CancelIoEx 函数. 该函数没有上述问题.
