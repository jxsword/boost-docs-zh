async_read (8 个重载中的第 4 个)

启动一个从流中读取一定量数据的异步操作.

template<
    typename AsyncReadStream,
    typename DynamicBuffer_v1,
    typename CompletionCondition,
    typename ReadToken = default_completion_token_t<        typename AsyncReadStream::executor_type>>
DEDUCED async_read(
    AsyncReadStream & s,
    DynamicBuffer_v1 && buffers,
    CompletionCondition completion_condition,
    ReadToken && token = default_completion_token_t< typename AsyncReadStream::executor_type >(),
    constraint_t< is_dynamic_buffer_v1< decay_t< DynamicBuffer_v1 > >::value >  = 0,
    constraint_t< !is_dynamic_buffer_v2< decay_t< DynamicBuffer_v1 > >::value >  = 0,
    constraint_t< is_completion_condition< CompletionCondition >::value >  = 0);

此函数用于从流中异步读取一定数量的字节. 它是 异步操作 的发起函数, 并且总是立即返回. 异步操作将持续进行, 直至下列条件之一成立:

  • 指定的动态缓冲区序列已满 (即已达到最大大小) .
  • completion_condition 函数对象返回 0.

此操作通过对流的 async_read_some 函数的零次或多次调用实现, 被称为组合操作. 程序必须确保在该操作完成之前, 流不执行任何其他读操作 (例如 async_read、流的 async_read_some 函数, 或任何其他执行读取的组合操作) .

参数

s

要从中读取数据的流. 其类型必须支持 AsyncReadStream 概念.

buffers

要读入数据的动态缓冲区序列. 尽管 buffers 对象可按需复制, 但底层内存块的所有权仍由调用者保留, 调用者必须保证这些内存块在完成处理器被调用前保持有效.

completion_condition

将被调用以判定读操作是否完成的函数对象. 该函数对象的签名必须为:

std::size_t completion_condition(
  // Result of latest async_read_some operation.
  const boost::system::error_code& error,

  // Number of bytes transferred so far.
  std::size_t bytes_transferred
);

返回值 0 表示读操作已完成. 非零返回值表示下一次调用流的 async_read_some 函数时要读取的最大字节数.

token

将用于产生完成处理器的 完成标记, 该处理器将在读取完成时被调用. 可能的完成标记包括 use_future、use_awaitable、yield_context, 或具有正确完成签名的函数对象. 完成处理器的函数签名必须为:

void handler(
  // Result of operation.
  const boost::system::error_code& error,

  // Number of bytes copied into the buffers. If an error
  // occurred, this will be the number of bytes successfully
  // transferred prior to the error.
  std::size_t bytes_transferred
);

无论异步操作是否立即完成, 完成处理器都不会在此函数内部被调用. 若立即完成, 将以等同于使用 async_immediate 的方式调用处理器.

完成签名 
void(boost::system::error_code, std::size_t)
逐操作取消

此异步操作支持对以下 cancellation_type 值进行取消:

  • cancellation_type::terminal
  • cancellation_type::partial

(前提是 AsyncReadStream 类型的 async_read_some 操作同样支持它们. )
