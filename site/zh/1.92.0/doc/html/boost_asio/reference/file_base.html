file_base

该 file_base 类被用作 basic_stream_file 与 basic_random_access_file 类模板的基类, 这样我们就有一个定义标志的公共位置.

class file_base
类型

名称

说明

flags

一种位掩码类型 (C++ Std [lib.bitmask.types]) .

seek_basis

文件中定位 (seek) 的基准.
受保护成员函数

名称

说明

~file_base [destructor]

受保护的析构函数, 以防止通过此类型删除.
数据成员

名称

说明

append [static]

以追加模式打开文件.

create [static]

若文件不存在则创建文件.

exclusive [static]

确保创建新文件. 必须与 create 组合使用.

read_only [static]

以只读方式打开文件.

read_write [static]

以读写方式打开文件.

sync_all_on_write [static]

打开文件, 使写操作自动将文件数据与元数据同步到磁盘.

truncate [static]

打开文件并截断其所有既有内容.

write_only [static]

以只写方式打开文件.
