socket_base::shutdown_type

关闭套接字的不同方式.

enum shutdown_type

取值

shutdown_receive

关闭套接字的接收侧.

shutdown_send

关闭套接字的发送侧.

shutdown_both

同时关闭套接字的发送与接收.
