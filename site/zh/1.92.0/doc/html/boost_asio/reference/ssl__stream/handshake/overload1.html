ssl::stream::handshake (1 of 4 overloads)

执行 SSL 握手.

void handshake(
    handshake_type type);

此函数用于在流上执行 SSL 握手. 函数调用将阻塞, 直到握手完成或发生错误.

参数

type

要执行的握手类型, 即作为客户端还是作为服务器.

异常

boost::system::system_error

失败时抛出.
