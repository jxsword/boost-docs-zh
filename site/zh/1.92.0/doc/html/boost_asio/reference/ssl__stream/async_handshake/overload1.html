ssl::stream::async_handshake (1 of 2 overloads)

启动异步 SSL 握手.

template<
    typename HandshakeToken = default_completion_token_t<executor_type>>
DEDUCED async_handshake(
    handshake_type type,
    HandshakeToken && token = default_completion_token_t< executor_type >());

此函数用于在流上异步执行 SSL 握手. 它是 异步操作 的发起函数, 且总是立即返回.

参数

type

要执行的握手类型, 即作为客户端还是作为服务器.

token

将用于产生完成处理器的 完成标记, 该完成处理器会在握手完成时被调用. 可用的完成标记包括 use_future、use_awaitable、yield_context 或具有正确完成签名的函数对象. 完成处理器的函数签名必须是:

void handler(
  const boost::system::error_code& error // Result of operation.
);

无论异步操作是否立即完成, 完成处理器都不会在此函数内部被调用. 若立即完成, 将以等同于使用 async_immediate 的方式调用处理器.

完成签名 
void(boost::system::error_code)
逐操作取消

此异步操作支持对以下 cancellation_type 值进行取消:

  • cancellation_type::terminal
  • cancellation_type::partial

如果 Stream 类型的 async_read_some 和 async_write_some 操作也支持它们.
