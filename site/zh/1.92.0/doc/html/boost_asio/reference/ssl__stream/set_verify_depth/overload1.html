ssl::stream::set_verify_depth (1 of 2 overloads)

设置对端验证深度.

void set_verify_depth(
    int depth);

此函数可用于配置流允许的最大验证深度.

参数

depth

允许的证书链验证最大深度.

异常

boost::system::system_error

失败时抛出.

备注

Calls SSL_set_verify_depth.
