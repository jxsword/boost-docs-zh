ssl::stream::native_handle

以原生类型获取底层实现.

native_handle_type native_handle();

此函数可用于获得上下文的底层实现. 其目的是允许访问未以其他方式提供的上下文功能.

示例

native_handle() 函数返回 SSL* 类型的指针, 适合传递给 SSL_get_verify_result 和 SSL_get_peer_certificate: 等函数

boost::asio::ssl::stream<boost::asio::ip::tcp::socket> sock(io_ctx, ctx);

// ... establish connection and perform handshake ...

if (X509* cert = SSL_get_peer_certificate(sock.native_handle()))
{
  if (SSL_get_verify_result(sock.native_handle()) == X509_V_OK)
  {
    // ...
  }
}
