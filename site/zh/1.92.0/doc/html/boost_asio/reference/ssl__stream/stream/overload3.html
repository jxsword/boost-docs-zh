ssl::stream::stream (3 个重载中的第 3 个)

从另一个流移动构造.

stream(
    stream && other);
参数

other

移动来源的另一个流对象. 其上不得有关联的未完成异步操作. 移动之后, other 处于有效但未指定的状态, 此时唯一安全的操作是销毁, 或作为移动赋值的目标.
