ssl::stream::stream (2 of 3 overloads)

从现有原生实现构造流.

template<
    typename Arg>
stream(
    Arg && arg,
    native_handle_type handle,
    std::size_t input_buffer_size = 0,
    std::size_t output_buffer_size = 0);

此构造函数创建流并初始化底层流对象. 成功时, 原生实现的所有权转移给流, 并在流销毁时清理.

参数

arg

用于初始化底层流的参数.

handle

一个现有的原生 SSL 实现.

input_buffer_size

用于保存从底层流接收的加密数据的内部缓冲区大小 (字节). 更大的缓冲区允许每次从底层流读取时解密更多数据. 值为零表示选择默认大小.

output_buffer_size

用于保存要写入底层流的加密数据的内部缓冲区大小 (字节). 更大的缓冲区允许单次写入向底层流发送更多数据. 值为零表示选择默认大小.
