ssl::stream::write_some (1 of 2 overloads)

向流写入一些数据.

template<
    typename ConstBufferSequence>
std::size_t write_some(
    const ConstBufferSequence & buffers);

该函数用于向流写入数据. 函数调用将阻塞, 直到成功写入一个或多个字节的数据, 或者发生错误.

参数

buffers

要写入的数据.

返回值

写入的字节数.

异常

boost::system::system_error

失败时抛出.

备注

write_some 操作可能不会将全部数据传输给对端. 如果需要确保在阻塞操作完成之前写入全部数据, 请使用 write 函数.
