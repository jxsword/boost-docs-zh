basic_signal_set::basic_signal_set (8 个重载中的第 7 个)

构造一个信号集并添加三个信号.

basic_signal_set(
    const executor_type & ex,
    int signal_number_1,
    int signal_number_2,
    int signal_number_3);

此构造函数创建一个信号集并注册三个信号.

参数

ex

信号集默认将用于为在其上执行的任何异步操作分派处理器的 I/O 执行器.

signal_number_1

要添加的第一个信号编号.

signal_number_2

要添加的第二个信号编号.

signal_number_3

要添加的第三个信号编号.

备注

此构造函数等价于执行:

boost::asio::signal_set signals(ex);
signals.add(signal_number_1);
signals.add(signal_number_2);
signals.add(signal_number_3);
