basic_signal_set::add (4 个重载中的第 4 个)

向 signal_set 添加一个带指定标志的信号.

void add(
    int signal_number,
    flags_t f,
    boost::system::error_code & ec);

此函数将指定信号添加到集合中. 如果该信号已在集合中, 则没有任何效果.

flags::dont_care 以外的标志需要操作系统支持 sigaction 调用; 如果不支持, 此函数将以 error::operation_not_supported 失败.

如果先前的活动注册或本次指定的标志值中任何一方不是 flags::dont_care, 则指定的标志将与同一信号先前的活动注册发生冲突. 在这种情况下, add 将以 error::invalid_argument 失败.

参数

signal_number

要添加到集合中的信号.

f

用于修改指定信号行为的标志.

ec

用于指示发生了何种错误 (如无错误则不设置) .
