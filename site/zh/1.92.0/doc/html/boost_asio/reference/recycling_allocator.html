recycling_allocator

在线程本地存储中缓存内存块以供重用的分配器.

    typename T>
class recycling_allocator

recycling_allocator [constructor]

Default constructor.
—
Converting constructor.

recycling_allocator 采用一种简单策略: 若当前线程正在运行 io_context, 或是 thread_pool 的一部分, 则将有限数量的小内存块缓存到线程本地存储中.

要求

头文件: boost/asio/recycling_allocator.hpp

便捷头文件: boost/asio.hpp
