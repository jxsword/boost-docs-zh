cancellation_state::cancellation_state (4 个重载中的第 2 个)

构造并连接到父槽, 以创建新的子槽.

template<
    typename CancellationSlot>
constexpr cancellation_state(
    CancellationSlot slot);

初始化取消状态, 使其只允许终止取消. 等价于 cancellation_state(slot, enable_terminal_cancellation()).

参数

slot

该状态将要连接到的父取消槽.
