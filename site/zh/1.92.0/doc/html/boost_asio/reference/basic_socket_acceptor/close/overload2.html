basic_socket_acceptor::close (2 个重载中的第 2 个)

关闭接受器.

void close(
    boost::system::error_code & ec);

此函数用于关闭接受器. 任何异步接受操作都将被立即取消.

在再次使用接受器执行套接字接受操作之前, 需要先调用 open().

参数

ec

用于指示发生了何种错误 (如无错误则不设置) .

示例 
boost::asio::ip::tcp::acceptor acceptor(my_context);
...
boost::system::error_code ec;
acceptor.close(ec);
if (ec)
{
  // An error occurred.
}
