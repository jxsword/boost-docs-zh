basic_socket_acceptor::open (2 个重载中的第 2 个)

使用指定的协议打开接受器.

void open(
    const protocol_type & protocol,
    boost::system::error_code & ec);

此函数打开套接字接受器, 使其使用指定的协议.

参数

protocol

指定要使用哪个协议的对象.

ec

用于指示发生了何种错误 (如无错误则不设置) .

示例 
boost::asio::ip::tcp::acceptor acceptor(my_context);
boost::system::error_code ec;
acceptor.open(boost::asio::ip::tcp::v4(), ec);
if (ec)
{
  // An error occurred.
}
