basic_socket_acceptor::basic_socket_acceptor (10 个重载中的第 6 个)

构造一个在给定端点上打开的接受器.

template<
    typename ExecutionContext>
basic_socket_acceptor(
    ExecutionContext & context,
    const endpoint_type & endpoint,
    bool reuse_addr = true,
    constraint_t< is_convertible< ExecutionContext &, execution_context & >::value >  = 0);

此构造函数创建一个接受器并自动打开它, 在指定端点上侦听新连接.

参数

context

一种执行上下文, 它提供接受器默认将用于为在其上执行的任何异步操作分派处理器的 I/O 执行器.

endpoint

本地机器上的一个端点, 接受器将在其上侦听新连接.

reuse_addr

构造函数是否应设置套接字选项 socket_base::reuse_address.

异常

boost::system::system_error

失败时抛出.

备注

此构造函数等价于以下代码:

basic_socket_acceptor<Protocol> acceptor(my_context);
acceptor.open(endpoint.protocol());
if (reuse_addr)
  acceptor.set_option(socket_base::reuse_address(true));
acceptor.bind(endpoint);
acceptor.listen();
