basic_socket_acceptor::basic_socket_acceptor (10 个重载中的第 1 个)

构造一个接受器但不打开它.

basic_socket_acceptor(
    const executor_type & ex);

此构造函数创建一个接受器但不打开它侦听新连接. 必须先调用 open() 函数, 接受器才能接受新的套接字连接.

参数

ex

接受器默认将用于为在其上执行的任何异步操作分派处理器的 I/O 执行器.
