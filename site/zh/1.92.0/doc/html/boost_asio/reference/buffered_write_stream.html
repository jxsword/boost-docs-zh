buffered_write_stream

为流的写相关操作添加缓冲.

template<
    typename Stream>
class buffered_write_stream :
  noncopyable
类型

名称

说明

executor_type

与该对象关联的执行器的类型.

lowest_layer_type

最底层的类型.

next_layer_type

下一层的类型.
成员函数

名称

说明

async_flush

启动一个异步刷新操作.

async_read_some

启动一个异步读操作. 将要读入数据的缓冲区必须在异步操作的生存期内保持有效.

async_write_some

启动一个异步写操作. 正在写入的数据必须在异步操作的生存期内保持有效.

buffered_write_stream [constructor]

进行构造, 传递指定的实参来初始化下一层.

close

关闭流.

flush

把缓冲区中的所有数据刷新到下一层. 返回最后一次写操作写入下一层的字节数. 失败时抛出异常.
—
把缓冲区中的所有数据刷新到下一层. 返回最后一次写操作写入下一层的字节数, 发生错误时返回 0.

get_executor

获取与该对象关联的执行器.

in_avail

确定在不阻塞的情况下可以读取的数据量.

lowest_layer

获取对最底层的引用.
—
获取对最底层的 const 引用.

next_layer

获取下一层的引用.

peek

查看流上的传入数据. 返回读取的字节数. 失败时抛出异常.
—
查看流上的传入数据. 返回读取的字节数, 发生错误时返回 0.

read_some

从流中读取一些数据. 返回读取的字节数. 失败时抛出异常.
—
从流中读取一些数据. 返回读取的字节数, 发生错误时返回 0.

write_some

把给定的数据写入流. 返回写入的字节数. 失败时抛出异常.
—
把给定的数据写入流. 返回写入的字节数, 发生错误且错误处理器未抛出异常时返回 0.
数据成员

名称

说明

default_buffer_size [static]

默认缓冲区大小.

buffered_write_stream 类模板可用于为流的同步和异步写操作添加缓冲.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

要求

头文件: boost/asio/buffered_write_stream.hpp

便捷头文件: boost/asio.hpp
