io_context::stopped

确定 io_context 对象已停止.

bool stopped() const;

此函数用于确定一个 io_context 对象是否已停止, 无论是通过显式调用 stop(), 还是因为无工作可做而停止. 当一个 io_context 对象已停止, 对 run(), run_one(), poll() 或 poll_one() 的调用将立即返回, 不调用任何处理器.

返回值

true 如果 io_context 对象已停止, 否则为 false.
