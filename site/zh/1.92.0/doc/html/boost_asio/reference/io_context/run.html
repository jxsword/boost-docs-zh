io_context::run

运行 io_context 对象的事件处理循环.

count_type run();

该 run() 函数阻塞, 直到所有工作完成且不再有要分派的处理器, 或直到 io_context 已停止.

多个线程可以调用 run() 函数来建立线程池, io_context 可以在其中执行处理器. 池中所有等待的线程都是等价的, io_context 可以选择其中任何一个线程来调用处理器.

从 run() 函数的正常返回意味着 io_context 对象已停止 (stopped() 函数返回 true). 后续对 run(), run_one(), poll() 或 poll_one() 的调用将立即返回, 除非先前调用了 restart().

返回值

已执行的处理器数量.

备注

调用 run() 函数, 而该线程当前正在调用 run(), run_one(), run_for(), run_until(), poll() 或 poll_one() 之一, 且目标是同一 io_context 对象, 则可能引入死锁的潜在风险. 避免这种情况是调用者的责任.

该 poll() 函数也可用于分派就绪处理器, 但不阻塞.
