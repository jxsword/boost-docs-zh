io_context::restart

重新启动 io_context, 为后续 run() 调用做准备.

void restart();

在任何第二次或之后的一组对 run(), run_one(), poll() 或 poll_one() 函数的任何第二次或之后的一组调用之前, 都必须调用此函数, 前提是这些函数的上一次调用因 io_context 已停止或无工作可做而返回. 在调用 restart()该 io_context 对象的 stopped() 函数将返回 false.
