io_context::run_until

运行 io_context 对象的事件处理循环直至指定的时间.

template<
    typename Clock,
    typename Duration>
std::size_t run_until(
    const chrono::time_point< Clock, Duration > & abs_time);

该 run_until() 函数阻塞, 直到所有工作完成且不再有要分派的处理器, 直到 io_context 已停止, 或到达指定的时间.

参数

abs_time

该调用可以阻塞到的时间点.

返回值

已执行的处理器数量.
