io_context::~io_context

析构函数.

~io_context();

在销毁时, io_context 会执行以下操作序列:

  • 对于 svc (属于 io_context 集合), 按服务对象生存期开始的相反顺序, 执行 svc->shutdown().
  • 已调度到 io_context, 或任何关联的 strand, 都会被销毁.
  • 对于 svc (属于 io_context 集合), 按服务对象生存期开始的相反顺序, 执行 delete static_cast<io_context::service*>(svc).
备注

上述销毁序列使程序可以借助 shared_ptr<>. 当对象的生命期与某个连接 (或其他某个异步操作序列) 的生命期绑定在一起时, 一个 shared_ptr (指向该对象) 会被绑定到与其相关联的所有异步操作的处理器中. 其工作方式如下:

  • 当单个连接结束时, 所有相关联的异步操作都会完成. 相应的处理器对象被销毁, 并且所有指向这些对象的 shared_ptr 引用都被销毁.
  • 要关闭整个程序, io_context 函数 stop() 来尽快终止所有 run() 调用尽快返回. io_context 析构函数销毁所有处理器, 使所有指向连接对象的 shared_ptr 引用全部被销毁.
