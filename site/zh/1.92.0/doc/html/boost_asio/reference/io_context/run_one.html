io_context::run_one

运行 io_context 对象的事件处理循环, 以执行至多一个处理器.

count_type run_one();

该 run_one() 函数阻塞, 直到分派了一个处理器, 或直到 io_context 已停止.

返回值

已执行的处理器数量. 返回值为零意味着 io_context 对象已停止 (stopped() 函数返回 true). 后续对 run(), run_one(), poll() 或 poll_one() 的调用将立即返回, 除非先前调用了 restart().

备注

调用 run_one() 函数, 而该线程当前正在调用 run(), run_one(), run_for(), run_until(), poll() 或 poll_one() 之一, 且目标是同一 io_context 对象, 则可能引入死锁的潜在风险. 避免这种情况是调用者的责任.
