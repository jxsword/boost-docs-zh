prefer_result

确定 prefer 表达式的结果类型的类型特征.

template<
    typename T,
    typename... Properties>
struct prefer_result
类型

名称

说明

type

prefer 表达式的结果.

类模板 prefer_result 是一个特征 (traits), 用于确定表达式 boost::asio::prefer(std::declval<T>(), std::declval<Properties>()...) 的结果类型.

要求

头文件: boost/asio/prefer.hpp

便捷头文件: boost/asio.hpp
