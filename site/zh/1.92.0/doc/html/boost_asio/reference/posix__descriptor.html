posix::descriptor

posix::basic_descriptor 典型用法的 typedef.

typedef basic_descriptor descriptor;
类型

名称

说明

rebind_executor

将描述符类型重绑定到其他执行器.

bytes_readable

获取可在不阻塞的情况下读取的数据量的 I/O 控制命令.

executor_type

与该对象关联的执行器的类型.

lowest_layer_type

描述符始终是最底层.

native_handle_type

描述符的原生表示.

wait_type

等待类型.

名称

说明

assign

将现有原生描述符赋给该描述符.

async_wait

异步等待描述符变为可读、可写或存在待处理的错误条件.

basic_descriptor [constructor]

构造描述符但不打开它.

—

—
从另一执行器类型的描述符移动构造 basic_descriptor.

cancel

取消与该描述符关联的所有异步操作.

close

关闭描述符.

get_executor

获取与该对象关联的执行器.

io_control

is_open

lowest_layer

release

受保护成员函数

名称

说明

~basic_descriptor [destructor]

受保护的析构函数, 以防止通过此类型删除.

posix::basic_descriptor 类模板提供封装 POSIX 描述符的能力.

线程安全

不同 对象: 安全.
