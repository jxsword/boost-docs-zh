detached_t::as_default_on_t

类型别名, 用于适配 I/O 对象以使用 detached_t 作为其默认完成标记类型.

typedef typename T::template rebind_executor< executor_with_default< typename T::executor_type > >::other as_default_on_t;
类型

名称

说明

default_completion_token_type

指定 detached_t 作为默认完成标记类型.
成员函数

名称

说明

executor_with_default [constructor]

从内层执行器类型构造适配后的执行器.
—
把指定的执行器转换为内层执行器类型, 然后用它构造适配后的执行器.
要求

头文件: boost/asio/detached.hpp

便捷头文件: boost/asio.hpp
