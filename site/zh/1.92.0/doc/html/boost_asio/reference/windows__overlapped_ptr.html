windows::overlapped_ptr

包装处理器以创建用于重叠 I/O 的 OVERLAPPED 对象.

class overlapped_ptr :
  noncopyable
成员函数

名称

说明

complete

为重叠操作投递完成通知. 释放所有权.

get

获取所包含的 OVERLAPPED 对象.

overlapped_ptr [constructor]

构造空的 overlapped_ptr.
—
构造 overlapped_ptr 以包含指定的处理器.

release

释放 OVERLAPPED 对象的所有权.

reset

重置为空.
—
重置为包含指定的处理器, 并释放当前的 OVERLAPPED 对象 (如有).

~overlapped_ptr [destructor]

析构函数自动释放 OVERLAPPED 对象 (除非已释放).

一种特殊用途的智能指针, 用于包装应用程序处理器, 使其可作为 LPOVERLAPPED 参数传递给重叠 I/O 函数.

线程安全

不同 对象: 安全.

共享 对象: 不安全.

要求

头文件: boost/asio/windows/overlapped_ptr.hpp

便捷头文件: boost/asio.hpp
