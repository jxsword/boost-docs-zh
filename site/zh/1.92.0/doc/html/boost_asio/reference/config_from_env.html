config_from_env

通过读取环境变量来配置执行上下文.

class config_from_env :
  public execution_context::service_maker
成员函数

名称

说明

config_from_env [constructor]

以默认前缀 "asio" 构造.
—
以指定的前缀构造.

make

向指定的执行上下文添加一个具体服务.

环境变量名的构成方式是: 把前缀、节名和键名用下划线作为分隔符拼接, 然后把结果字符串转换为大写.

示例 
boost::asio::io_context my_io_context{
   boost::asio::config_from_env{"my_app"}};
要求

头文件: boost/asio/config.hpp

便捷头文件: boost/asio.hpp
