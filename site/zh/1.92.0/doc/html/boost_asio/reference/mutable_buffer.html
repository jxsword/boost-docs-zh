mutable_buffer 类提供了可修改缓冲区的安全表示. 它不拥有底层数据, 因此复制或赋值的代价很低.

访问缓冲区内容

可以使用 data() 和 size() 成员函数访问缓冲区的内容:

boost::asio::mutable_buffer b1 = ...;
std::size_t s1 = b1.size();
unsigned char* p1 = static_cast<unsigned char*>(b1.data());

data() 成员函数允许违反类型安全, 因此在应用程序代码中使用它时应仔细斟酌.
