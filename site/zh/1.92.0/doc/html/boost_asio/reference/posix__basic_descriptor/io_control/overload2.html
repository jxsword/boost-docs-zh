posix::basic_descriptor::io_control (2 个重载中的第 2 个)

在描述符上执行 IO 控制命令.

template<
    typename IoControlCommand>
void io_control(
    IoControlCommand & command,
    boost::system::error_code & ec);

此函数用于在描述符上执行 IO 控制命令.

参数

command

要在描述符上执行的 IO 控制命令.

ec

用于指示发生了何种错误 (如无错误则不设置) .

参见
  • posix::descriptor_base::bytes_readable
示例

获取准备好可读取的字节数:

boost::asio::posix::stream_descriptor descriptor(my_context);
...
boost::asio::posix::stream_descriptor::bytes_readable command;
boost::system::error_code ec;
descriptor.io_control(command, ec);
if (ec)
{
  // An error occurred.
}
std::size_t bytes_readable = command.get();
