posix::basic_descriptor::release

释放对原生描述符实现的所有权.

native_handle_type release();

此函数可用于获得描述符的底层表示. 调用此函数之后, is_open() 返回 false. 关闭描述符由调用者负责.

所有未完成的异步读或写操作都将立即结束, 被取消操作的处理器将收到 boost::asio::error::operation_aborted 错误.
