该 experimental::basic_concurrent_channel 类模板用于在同一应用的不同部分之间发送消息. 消息 被定义为一组传递给完成处理器的实参, 而通道支持的消息集合由其 Traits 与 Signatures... 模板参数指定. 消息可以通过异步或非阻塞的同步操作发送和接收.

除非自定义特征, 应用通常会使用 experimental::concurrent_channel 别名模板. 例如:

void send_loop(int i, steady_timer& timer,
    concurrent_channel<void(error_code, int)>& ch)
{
  if (i < 10)
  {
    timer.expires_after(chrono::seconds(1));
    timer.async_wait(
        [i, &timer, &ch](error_code error)
        {
          if (!error)
          {
            ch.async_send(error_code(), i,
                [i, &timer, &ch](error_code error)
                {
                  if (!error)
                  {
                    send_loop(i + 1, timer, ch);
                  }
                });
          }
        });
  }
  else
  {
    ch.close();
  }
}

void receive_loop(concurent_channel<void(error_code, int)>& ch)
{
  ch.async_receive(
      [&ch](error_code error, int i)
      {
        if (!error)
        {
          std::cout << "Received " << i << "\n";
          receive_loop(ch);
        }
      });
}
线程安全

不同 对象: 安全.

共享 对象: 安全.

该 experimental::basic_concurrent_channel 类模板是线程安全的, 通常用于在不同线程上运行的应用代码之间传递消息. 若要在单线程或同一 strand 上运行的代码之间传递消息, 请考虑使用 experimental::basic_channel 及其别名模板 experimental::channel, 以便在单线程或同一 strand 上运行的代码之间传递消息.
