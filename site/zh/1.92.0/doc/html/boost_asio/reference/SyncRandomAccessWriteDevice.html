面向缓冲区的同步随机访问写入设备要求

在下表中, a 表示一个同步随机访问写入设备对象, o 表示类型为 boost::uint64_t 的偏移量, cb 表示满足 常量缓冲区序列 要求的对象, ec 表示类型为 error_code 的对象.

表 31. 面向缓冲区的同步随机访问写入设备要求

操作

类型

语义, 前置/后置条件

a.write_some_at(o, cb);

size_t

等价于:

error_code ec;
size_t s = a.write_some(o, cb, ec);
if (ec) throw system_error(ec);
return s;

a.write_some_at(o, cb, ec);

size_t

向设备 a 的偏移量 o 处写入一个或多个字节的数据.

常量缓冲区序列 cb 指定待写数据所在的内存. write_some_at 操作应始终先完整写入序列中的一个缓冲区, 再继续处理下一个.

若成功, 返回写入的字节数并设置 ec 使 !ec 为 true. 若发生错误, 返回 0 并设置 ec 使 !!ec 为 true.

若序列 cb 中所有缓冲区的总大小为 0, 则函数应立即返回 0.
