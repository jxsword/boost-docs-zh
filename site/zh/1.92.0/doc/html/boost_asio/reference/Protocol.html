协议要求

类型 X 满足 Protocol 要求, 若其满足 Destructible (C++Std [destructible]) 、CopyConstructible (C++Std [copyconstructible]) 与 CopyAssignable (C++Std [copyassignable]) 的要求, 以及下面列出的附加要求.

类型 X 的拷贝或移动操作均不得通过异常退出.
