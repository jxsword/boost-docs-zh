basic_io_object::get_io_context

获取与对象关联的 io_context.

boost::asio::io_context & get_io_context();

此函数可用于获取 I/O 对象用于分发异步操作处理器的 io_context 对象.

返回值

对 I/O 对象将用于分发处理器的 io_context 对象的引用. 所有权不转移给调用者.
