端点要求

类型 X 满足 Endpoint 要求, 若其满足 Destructible (C++Std [destructible]) 、DefaultConstructible (C++Std [defaultconstructible]) 、CopyConstructible (C++Std [copyconstructible]) 与 CopyAssignable (C++Std [copyassignable]) 的要求, 以及下面列出的附加要求.

类型 X 的默认构造函数与移动操作不得通过异常退出.

在下表中, a 表示类型为 X 的 (可能为 const 的) 值, 而 u 表示一个标识符.

在下表中, a 表示类型为 X 的 (可能为 const 的) 值, b 表示类型为 X 的值, s 表示可转换为 size_t 的某类型的 (可能为 const 的) 值, 并以字节为单位表示大小.

表 16. 可扩展实现的端点要求

表达式

类型

断言/注释
前置/后置条件

a.data()

const void*

返回一个指针, 适合作为 address 实参传递给 POSIX connect() 之类的函数, 或作为 dest_addr 实参传递给 POSIX sendto() 之类的函数. 实现应对该指针执行 static_cast, 将其转换为 const sockaddr*.

b.data()

void*

返回一个指针, 适合作为 address 实参传递给 POSIX accept()、getpeername()、getsockname() 与 recvfrom() 之类的函数. 实现应对该指针执行 static_cast, 将其转换为 sockaddr*.

a.size()

size_t

返回一个值, 在执行适当的整数转换后, 适合作为 address_len 实参传递给 POSIX connect() 之类的函数, 或作为 dest_len 实参传递给 POSIX sendto() 之类的函数.

b.resize(s)

前置条件: s >= 0
后置条件: a.size() == s
在函数成功完成后, 将 address_len 实参中包含的值传递给 POSIX accept()、getpeername()、getsockname() 与 recvfrom() 之类的函数. 若与端点对象 a 关联的协议不支持指定的大小, 则允许抛出异常.

a.capacity()

size_t

返回一个值, 在执行适当的整数转换后, 适合作为 address_len 实参传递给 POSIX accept()、getpeername()、getsockname() 与 recvfrom() 之类的函数.
