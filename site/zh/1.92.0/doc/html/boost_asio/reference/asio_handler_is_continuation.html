asio_handler_is_continuation

处理器的默认延续函数.

bool asio_handler_is_continuation(
    ... );

异步操作可表示与当前处理器关联的异步控制流的延续. 实现可利用这一信息来优化处理器的调度.

为自己的处理器实现 asio_handler_is_continuation, 以指示处理器何时表示一个延续.

延续钩子的默认实现返回 false.

示例 
class my_handler;

bool asio_handler_is_continuation(my_handler* context)
{
  return true;
}
要求

头文件: boost/asio/handler_continuation_hook.hpp

便捷头文件: boost/asio.hpp
