取消槽要求

类型 X 满足 CancellationSlot 要求, 如果它满足 CopyConstructible (C++Std [copyconstructible]) 和 Destructible (C++Std [destructible]) 的要求, 以及下面列出的附加要求.

在下表中, x1 和 x2 表示类型为 X 的 (可能为 const 的) 值, mx1 表示类型为 X 的亡值, H 表示满足 CancellationHandler 的类型, h 表示类型为 H 的亡值, 而 u0 到 uN 表示标识符.

表 8. CancellationSlot 要求

表达式

类型

断言/注释
前置/后置条件

X u(x1);

不得因异常退出.

后置条件: u == x1.

X u(mx1);

不得因异常退出.

后置条件: u 等于 mx1 的先前值.

x1 == x2

bool

返回 true, 仅当 x1 与 x2 可以以相同效果互换时.
operator== 应当是自反的、对称的和传递的, 并且不得因异常退出.

x1 != x2

bool

与 !(x1 == x2) 相同.

x1.is_connected()

bool

返回 false, 仅当该槽永远不会导致调用使用 assign 或 emplace 附加到槽上的处理器时.

x1.has_handler()

bool

如果已有处理器附加到该槽, 则返回 true.

x1.assign(h)

H&

销毁附加到槽上的现有处理器 (如有) , 并附加处理器 h 的以移动构造得到的衰减副本.

返回对新附加处理器的引用.

后置条件: x1.has_handler() == true.

x1.emplace<H>(u0, ..., uN)

H&

要求 is_constructible<H, decltype(u0), ..., decltype(u0)>::value 为真.

销毁附加到槽上的现有处理器 (如有) , 并附加一个类型为 H、以指定实参 u0, ..., uN 构造的处理器.

返回对新附加处理器的引用.

后置条件: x1.has_handler() == true.

x1.clear()

后置条件: x1.has_handler() == false.
