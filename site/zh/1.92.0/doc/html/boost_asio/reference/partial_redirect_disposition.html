partial_redirect_disposition

一种函数对象类型, 用于适配 完成标记, 把异步操作产生的任何处置结果捕获到变量中.

template<
    typename Disposition>
class partial_redirect_disposition
成员函数

名称

说明

operator()

适配完成标记, 指定完成处理器应把处置结果值捕获到变量中.

partial_redirect_disposition [constructor]

指定用于捕获处置结果值的变量的构造函数.
数据成员

名称

说明

d_

也可直接用作完成标记, 此时它适配异步操作的默认完成标记 (若无默认值可用, 则为 deferred) .

要求

头文件: boost/asio/redirect_disposition.hpp

便捷头文件: boost/asio.hpp
