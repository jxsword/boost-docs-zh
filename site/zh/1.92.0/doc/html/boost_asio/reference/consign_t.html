consign_t

一种完成标记类型, 用于指定完成处理器应随其携带附加值.

template<
    typename CompletionToken,
    typename... Values>
class consign_t
成员函数

名称

说明

consign_t [constructor]

构造函数.

此完成标记适配器通常用于使对象 (例如智能指针) 的至少一个副本保持存活, 直到完成处理器被调用.
