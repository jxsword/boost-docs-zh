basic_readable_pipe::release (2 个重载中的第 2 个)

释放底层原生管道的所有权.

native_handle_type release(
    boost::system::error_code & ec);

此函数使所有未完成的异步读取操作立即结束, 被取消操作的处理器将收到 boost::asio::error::operation_aborted 错误. 原生管道的所有权随后转移给调用者.

参数

ec

用于指示发生了何种错误 (如无错误则不设置) .

备注

此函数在 Windows 8.1 之前的 Windows 版本上不受支持, 在这些平台上将以 boost::asio::error::operation_not_supported 失败.
