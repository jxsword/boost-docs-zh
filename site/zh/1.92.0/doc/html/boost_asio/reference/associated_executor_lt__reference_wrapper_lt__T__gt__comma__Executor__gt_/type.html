associated_executor< reference_wrapper< T >, Executor >::type

将 type 转发到针对解包类型 T 的关联器特化.

typedef associated_executor< T, Executor >::type type;
类型

名称

说明

type

若 T 具有嵌套类型 executor_type, 则为 T::executor_type. 否则为 Executor.
成员函数

名称

说明

get [static]

若 T 具有嵌套类型 executor_type, 则返回 t.get_executor(). 否则返回 type().
—
若 T 具有嵌套类型 executor_type, 则返回 t.get_executor(). 否则返回 ex.

若特化中的 T 模板参数是用户定义类型, 则程序可特化此特征类型. 模板参数 Executor 应为满足 Executor 要求的类型.

特化应满足下列要求, 其中 t 是对类型为 T 的对象的 const 引用, e 是类型为 Executor 的对象.

  • 提供嵌套 typedef type, 标识一个满足 Executor 要求的类型.
  • 提供名为 get 的 noexcept 静态成员函数, 可按 get(t) 调用, 返回类型为 type 或对 type 的 (可能为 const 的) 引用.
  • 提供名为 get 的 noexcept 静态成员函数, 可按 get(t,e) 调用, 返回类型为 type 或对 type 的 (可能为 const 的) 引用.
要求

头文件: boost/asio/associated_executor.hpp

便捷头文件: boost/asio.hpp
