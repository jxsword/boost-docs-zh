该 io_context::strand 类提供投递和分派处理器的能力, 并保证这些处理器中不会有任何两个并发执行.

处理器的调用顺序

给定:

  • 一个 strand 对象 s
  • 一个对象 a 满足完成处理器要求
  • 一个对象 a1, 它是实现对 a 由实现所创建
  • 一个对象 b 满足完成处理器要求
  • 一个对象 b1, 它是实现对 b 由实现所创建

如果以下任一条件成立:

  • s.post(a) happens-before s.post(b)
  • s.post(a) happens-before s.dispatch(b), 其中后者在 strand 之外执行
  • s.dispatch(a) happens-before s.post(b), 其中前者在 strand 之外执行
  • s.dispatch(a) happens-before s.dispatch(b), 其中两者都在 strand 之外执行

则 a() happens-before b()

注意在以下情况中:

async_op_1(..., s.wrap(a));
async_op_2(..., s.wrap(b));

第一个异步操作的完成将执行 s.dispatch(a), 而第二个将执行 s.dispatch(b), 但两者执行的先后顺序未指定. 也就是说, 你无法断言其中一个是否 happens-before 另一个. 因此上述条件均不满足, 也不会作出任何顺序保证.

备注

实现不保证通过不同 strand 对象投递或分派的处理器会被并发调用.

线程安全

不同 对象: 安全.

共享 对象: 安全.
