experimental::promise

即时操作所用的一次性句柄.

template<
    typename Signature = void(),
    typename Executor = boost::asio::any_io_executor,
    typename Allocator = std::allocator<void>>
struct promise
类型

名称

说明

value_type

promise 返回的值.
成员函数

名称

说明

cancel

取消 promise. 通常通过析构函数完成.

completed

检查 promise 是否已经完成.

operator()

等待 promise 就绪.

promise [constructor]

~promise [destructor]

销毁 promise 并取消操作.

Signature

操作的签名.

Executor

promise 要使用的执行器 (取自操作).

Allocator

promise 使用的分配器. 可以通过 use_allocator 设置.

promise 可用于发起一个稍后完成的异步操作. 如果 promise 在完成之前被销毁, 操作会收到取消信号, 结果将被忽略.

promise 满足 async_operation 的要求.

示例

在单个协程中进行读写.

awaitable<void> read_write_some(boost::asio::ip::tcp::socket & sock,
    boost::asio::mutable_buffer read_buf, boost::asio::const_buffer to_write)
{
  auto p = boost::asio::async_read(read_buf,
      boost::asio::experimental::use_promise);
  co_await boost::asio::async_write_some(to_write);
  co_await p;
}
