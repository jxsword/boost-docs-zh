设置协程在已被取消的情况下尝试挂起时是否抛出异常.

basic_yield_context 类是一个完成标记类型, 用于表示当前正在执行的有栈协程. basic_yield_context 对象可作为完成标记传递给异步操作. 例如:

template <typename Executor>
void my_coroutine(basic_yield_context<Executor> yield)
{
  ...
  std::size_t n = my_socket.async_read_some(buffer, yield);
  ...
}

发起函数 (上例中的 async_read_some) 会挂起当前协程. 当异步操作完成时协程恢复执行, 操作的结果随之返回.
