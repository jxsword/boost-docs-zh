I/O 对象服务要求

I/O 对象服务必须满足 服务 的要求, 以及下面列出的要求.

在下表中, X 表示一个 I/O 对象服务类, a 与 ao 表示类型为 X 的值, b 与 c 表示类型为 X::implementation_type 的值, u 表示一个标识符.
