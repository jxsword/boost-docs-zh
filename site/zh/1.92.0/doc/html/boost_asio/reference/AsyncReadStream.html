面向缓冲区的异步读流要求

类型 X 满足 AsyncReadStream 要求, 如果它满足下面列出的要求.

在下表中, a 表示类型为 X 的值, mb 表示满足 MutableBufferSequence 要求的 (可能为 const 的) 值, 而 t 是完成标记.

表 6. AsyncReadStream 要求

操作

类型

语义, 前置/后置条件

a.get_executor()

满足 Executor 要求 的类型.

返回关联的 I/O 执行器.

a.async_read_some(mb,t)

返回类型根据 异步操作 的要求确定.

满足 读操作 与 异步操作 的要求, 完成签名为 void(error_code ec, size_t n).

如果 buffer_size(mb) > 0, 则发起一个异步操作, 从流 a 读取一个或多个字节的数据到缓冲区序列 mb 中. 如果成功, ec 被设置为使得 !ec 为 true, 且 n 是读取的字节数. 如果发生了错误, ec 被设置为使得 !!ec 为 true, 且 n 为 0. 如果已从流中读出全部数据, 且流执行了有序关闭, ec 为 stream_errc::eof, 且 n 为 0.

如果 buffer_size(mb) == 0, 操作立即完成. ec 被设置为使得 !ec 为 true, 且 n 为 0.
