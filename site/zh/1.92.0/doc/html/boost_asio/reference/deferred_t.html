deferred_t 类用于指示异步操作应返回一个函数对象, 该函数对象本身是一个发起函数. deferred_t 对象可以作为完成标记传递给异步操作, 通常作为默认完成标记:

auto my_deferred_op = my_socket.async_read_some(my_buffer);

或者通过显式传递特殊值 boost::asio::deferred:

auto my_deferred_op
 = my_socket.async_read_some(my_buffer,
     boost::asio::deferred);

发起函数 (上例中的 async_read_some) 返回一个函数对象, 该函数对象将惰性地发起操作.
