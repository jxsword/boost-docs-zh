execution::relationship_t

一种属性, 用于描述所提交的任务是否代表调用方上下文的延续.

struct relationship_t
类型

名称

说明

continuation_t

一个子属性, 表明执行器代表调用方上下文的延续.

fork_t

一个子属性, 表明执行器不代表调用方上下文的延续.

polymorphic_query_result_type

对 any_executor 查询所返回的类型.
