serial_port_base

serial_port_base 类用作 basic_serial_port 类模板的基类, 以便有一个公共位置来定义串口选项.

class serial_port_base
类型

名称

说明

baud_rate

允许更改波特率的串口选项.

character_size

允许更改字符大小的串口选项.

flow_control

允许更改流控制的串口选项.

parity

允许更改奇偶校验的串口选项.

stop_bits

允许更改停止位数的串口选项.
受保护成员函数

名称

说明

~serial_port_base [destructor]

受保护的析构函数, 以防止通过此类型删除.
要求

头文件: boost/asio/serial_port_base.hpp

便捷头文件: boost/asio.hpp
