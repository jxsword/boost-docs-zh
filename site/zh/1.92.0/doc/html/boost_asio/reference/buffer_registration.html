buffer_registration

自动向执行上下文注册和注销缓冲区.

template<
    typename MutableBufferSequence,
    typename Allocator>
class buffer_registration
类型

名称

说明

allocator_type

用于为缓冲区容器分配存储空间的分配器类型.

const_iterator

注册缓冲区上的 const 迭代器类型.

iterator

注册缓冲区上的迭代器类型.
成员函数

名称

说明

获取指定索引处的缓冲区.

begin

获取注册缓冲区序列的起始迭代器.

buffer_registration [constructor]

size

~buffer_registration [destructor]

注销缓冲区.

为保证可移植性, 应用程序应当假定每个执行上下文只允许一次注册.
