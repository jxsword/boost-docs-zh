is_disposition

用于测试类型是否满足处置结果 (disposition) 要求的特征 (traits).

template<
    typename T>
struct is_disposition :
  public integral_constant< bool, automatically_determined >

要成为有效的处置结果 (disposition), 类型必须支持不抛异常的默认构造、移动构造和移动赋值, 并且必须存在针对该类型的 disposition_traits 模板特化, 提供以下静态成员函数: * not_an_error: 接受一个 const T& 类型的实参, 并返回一个 bool.

  • throw_exception: 接受一个 T 类型的实参. 此函数的调用者不得传入使 not_an_error 返回 true 的处置结果值. 此函数不得返回.
  • to_exception_ptr: 接受一个 T 类型的实参, 并返回一个 std::exception_ptr 类型的值.
要求

头文件: boost/asio/disposition.hpp

便捷头文件: boost/asio.hpp
