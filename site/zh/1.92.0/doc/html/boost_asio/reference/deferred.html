deferred

一种 完成标记 对象, 用于指定异步操作应返回一个函数对象, 以惰性地启动该操作.

constexpr deferred_t deferred;

用法示例参见 deferred_t 的文档.

要求

头文件: boost/asio/deferred.hpp

便捷头文件: boost/asio.hpp
