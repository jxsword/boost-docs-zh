dynamic_vector_buffer::const_buffers_type

用于表示引用底层内存的常量缓冲区序列的类型.

typedef const_buffer const_buffers_type;

operator+

创建一个新的不可修改缓冲区, 相对于另一个缓冲区的起始处偏移.

const_buffer 类提供了不可修改缓冲区的安全表示. 它不拥有底层数据, 因此复制或赋值的代价很低.

访问缓冲区内容

可以使用 data() 和 size() 成员函数访问缓冲区的内容:

boost::asio::const_buffer b1 = ...;
std::size_t s1 = b1.size();
const unsigned char* p1 = static_cast<const unsigned char*>(b1.data());

data() 成员函数允许违反类型安全, 因此在应用程序代码中使用它时应仔细斟酌.
