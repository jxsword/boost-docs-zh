dynamic_vector_buffer::data (3 个重载中的第 2 个)

DynamicBuffer_v2: 获取表示底层内存的缓冲区序列.

mutable_buffers_type data(
    std::size_t pos,
    std::size_t n);
参数

pos

缓冲区序列中要表示的第一个字节的位置

n

缓冲区序列中要返回的字节数. 如果底层内存较短, 则缓冲区序列表示所有可用的字节.

返回值

一个 mutable_buffers_type 类型的对象, 满足 MutableBufferSequence 要求, 表示 vector 内存.

备注

任何调整 vector 大小或擦除 vector 内容的 dynamic_vector_buffer 或 vector 成员函数都会使返回的对象失效.
