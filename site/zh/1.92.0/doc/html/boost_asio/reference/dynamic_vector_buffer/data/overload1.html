dynamic_vector_buffer::data (3 个重载中的第 1 个)

DynamicBuffer_v1: 获取表示输入序列的缓冲区列表.

const_buffers_type data() const;
返回值

一个 const_buffers_type 类型的对象, 满足 ConstBufferSequence 要求, 表示输入序列中的 vector 内存.

备注

任何修改输入序列或输出序列的 dynamic_vector_buffer 或 vector 成员函数都会使返回的对象失效.
