dynamic_vector_buffer::max_size

获取动态缓冲区的最大大小.

std::size_t max_size() const;
返回值

DynamicBuffer_v1: 输入序列和输出序列大小之和所允许的最大值. DynamicBuffer_v2: 底层内存允许的最大大小.
