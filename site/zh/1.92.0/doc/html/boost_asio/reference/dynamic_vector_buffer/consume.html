dynamic_vector_buffer::consume

DynamicBuffer_v1: 从输入序列中移除字符. DynamicBuffer_v2: 从底层内存的开头消耗指定数量的字节.

void consume(
    std::size_t n);

DynamicBuffer_v1: 从输入序列的开头移除 n 个字符.

备注

如果 n 大于输入序列的大小, 则整个输入序列被消费, 且不发出任何错误.

DynamicBuffer_v2: 从 vector 的开头擦除 n 个字节. 如果 n 大于 vector 的当前大小, 则 vector 被清空.
