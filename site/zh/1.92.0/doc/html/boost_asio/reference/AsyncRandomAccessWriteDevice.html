面向缓冲区的异步随机访问写设备要求

在下表中, a 表示一个异步写流对象, o 表示类型为 boost::uint64_t 的偏移量, cb 表示满足 常量缓冲区序列 要求的对象, 而 h 表示满足 写处理器 要求的对象.

表 5. 面向缓冲区的异步随机访问写设备要求

操作

类型

语义, 前置/后置条件

a.get_executor()

满足 Executor 要求 的类型.

返回关联的 I/O 执行器.

a.async_write_some_at(o, cb, h);

void

发起一个异步操作, 把一个或多个字节的数据写入设备 a 的偏移 o 处. 该操作通过 I/O 执行器 a.get_executor() 执行, 并遵循 异步操作 要求.

常量缓冲区序列 cb 指定待写数据所在的内存. async_write_some_at 操作必须先把序列中的一个缓冲区完全写完, 再继续处理下一个.

实现必须维护 cb 的一个或多个副本, 直到写操作不再需要访问序列中缓冲区所指定的内存为止. 程序必须确保内存一直有效, 直到:

— cb 的最后一个副本被销毁, 或者

— 异步写操作的处理器被调用,

以先到者为准.

如果序列中所有缓冲区的总大小 cb 为 0, 异步写操作应立即完成, 并把 0 作为指定写入字节数的处理器实参传入.
