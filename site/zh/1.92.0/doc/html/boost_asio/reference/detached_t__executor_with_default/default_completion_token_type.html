detached_t::executor_with_default::default_completion_token_type

指定 detached_t 作为默认完成标记类型.

typedef detached_t default_completion_token_type;
类型

名称

说明

as_default_on_t

类型别名, 用于适配 I/O 对象以使用 detached_t 作为其默认完成标记类型.

executor_with_default

适配执行器, 添加 detached_t 完成标记作为默认值.
成员函数

名称

说明

as_default_on [static]

函数辅助工具, 用于适配 I/O 对象以使用 detached_t 作为其默认完成标记类型.

detached_t [constructor]

构造函数.

detached_t 类用于指示异步操作被分离, 即没有完成处理器等待操作的结果. detached_t 对象可以作为处理器传递给异步操作, 通常使用特殊值 boost::asio::detached. 例如:

my_socket.async_send(my_buffer, boost::asio::detached);
要求

头文件: boost/asio/detached.hpp

便捷头文件: boost/asio.hpp
