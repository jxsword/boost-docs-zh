query

查询属性值的定制点.

constexpr unspecified query = unspecified;

名称 query 表示一个定制点对象. 表达式 boost::asio::query(E, P) (对于某些子表达式 E 和 P, 类型分别为 T = decay_t<decltype(E)> 和 Prop = decay_t<decltype(P)>) 表达式等价于:

  • 若 is_applicable_property_v<T, Prop> 不是值为 true 的良构常量表达式, 则 boost::asio::query(E, P) 非良构.
  • 否则, Prop::template static_query_v<T> 适用于以下情形: 表达式 Prop::template static_query_v<T> 是良构常量表达式.
  • 否则, (E).query(P) 适用于以下情形: 表达式 (E).query(P) 良构.
  • 否则, query(E, P) 适用于以下情形: 表达式 query(E, P) 在不包含 query 定制点对象声明的上下文中执行重载决议后为有效表达式.
  • 否则, boost::asio::query(E, P) 非良构.
要求

头文件: boost/asio/query.hpp

便捷头文件: boost/asio.hpp
