ip::basic_resolver_query::address_configured

继承自 ip::resolver_base.

仅当系统配置了非回环 IPv4 地址时才返回 IPv4 地址. 仅当系统配置了非回环 IPv6 地址时才返回 IPv6 地址.

static const flags address_configured = implementation_defined;
