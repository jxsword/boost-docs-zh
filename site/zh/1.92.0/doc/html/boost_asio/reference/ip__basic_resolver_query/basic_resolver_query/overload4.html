ip::basic_resolver_query::basic_resolver_query (6 个重载中的第 4 个)

以给定协议的指定主机名和服务名构造.

basic_resolver_query(
    const protocol_type & protocol,
    const std::string & host,
    const std::string & service,
    resolver_query_base::flags resolve_flags = address_configured);

此构造函数通常用于为与远程主机的通信执行名称解析.

参数

protocol

协议对象, 通常表示互联网协议的 IPv4 或 IPv6 版本.

host

标识位置的字符串. 可以是描述性名称, 也可以是数字地址字符串. 若为空字符串且指定了 passive 标志, 解析得到的端点适用于本地服务绑定. 若为空字符串且未指定 passive, 解析得到的端点将使用回环地址.

service

标识所请求服务的字符串. 可以是描述性名称, 也可以是对应端口号的数字字符串. 可以为空字符串, 此时所有解析得到的端点的端口号都为 0.

resolve_flags

一组确定如何执行名称解析的标志. 默认标志适用于与远程主机的通信.

备注

在 POSIX 系统上, 主机名可在文件 /etc/hosts 中本地定义. 在 Windows 上, 主机名可在文件 c:\windows\system32\drivers\etc\hosts 中定义. 远程主机名的解析通过 DNS 执行. 操作系统在解析主机名时可能使用其他位置 (例如 Windows 上的 NETBIOS 名称).

在 POSIX 系统上, 服务名通常定义在文件 /etc/services 中. 在 Windows 上, 服务名可在文件 c:\windows\system32\drivers\etc\services 中找到. 操作系统在解析服务名时可能使用其他位置.
