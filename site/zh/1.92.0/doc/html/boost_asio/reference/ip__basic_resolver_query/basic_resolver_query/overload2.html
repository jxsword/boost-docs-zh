ip::basic_resolver_query::basic_resolver_query (6 个重载中的第 2 个)

以给定协议的指定服务名构造.

basic_resolver_query(
    const protocol_type & protocol,
    const std::string & service,
    resolver_query_base::flags resolve_flags = passive|address_configured);

此构造函数通常用于为特定协议版本的本地服务绑定执行名称解析.

参数

protocol

协议对象, 通常表示互联网协议的 IPv4 或 IPv6 版本.

service

标识所请求服务的字符串. 可以是描述性名称, 也可以是对应端口号的数字字符串.

resolve_flags

一组确定如何执行名称解析的标志. 默认标志适用于本地服务绑定.

备注

在 POSIX 系统上, 服务名通常定义在文件 /etc/services 中. 在 Windows 上, 服务名可在文件 c:\windows\system32\drivers\etc\services 中找到. 操作系统在解析服务名时可能使用其他位置.
