完成条件要求

完成条件是与算法 read、async_read、write 和 async_write 一起使用的函数对象, 用于确定算法何时完成数据传输.

类型 X 满足 CompletionCondition 要求, 如果它满足 Destructible (C++Std [destructible]) 和 MoveConstructible (C++Std [moveconstructible]) 的要求, 以及下面列出的附加要求.

在下表中, x 表示类型为 X 的值, ec 表示类型为 error_code 的 (可能为 const 的) 值, 而 n 表示类型为 size_t 的 (可能为 const 的) 值.

表 9. CompletionCondition 要求

表达式

返回类型

断言/注释
前置/后置条件

x(ec, n)

size_t

设 n 为读或写算法到目前为止已传输的字节总数.

返回算法下一次执行 read_some、async_read_some、write_some 或 async_write_some 操作时要传输的最大字节数. 返回 0 表示算法已完成.
