basic_io_object

(已弃用) 所有 I/O 对象的基类.

template<
    typename IoObjectService>
class basic_io_object
类型

名称

说明

executor_type

与该对象关联的执行器的类型.

implementation_type

I/O 对象的底层实现类型.

service_type

将用于提供 I/O 操作的服务的类型.
成员函数

名称

说明

get_executor

获取与该对象关联的执行器.

get_io_context

获取与对象关联的 io_context.

get_io_service

获取与对象关联的 io_context.
受保护成员函数

名称

说明

basic_io_object [constructor]

构造一个 basic_io_object.
—
移动构造一个 basic_io_object.
—
对 basic_io_object 执行转换性移动构造.

get_implementation

获取 I/O 对象的底层实现.

get_service

获取与 I/O 对象关联的服务.

operator=

移动赋值一个 basic_io_object.

~basic_io_object [destructor]

受保护的析构函数, 以防止通过此类型删除.
备注

所有 I/O 对象均不可拷贝. 不过, 在使用 C++0x 时, 某些 I/O 对象确实支持移动构造与移动赋值.

要求

头文件: boost/asio/basic_io_object.hpp

便捷头文件: boost/asio.hpp
