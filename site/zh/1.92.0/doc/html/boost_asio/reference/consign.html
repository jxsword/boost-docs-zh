consign

一种完成标记适配器, 用于指定完成处理器应随其携带附加值.

template<
    typename CompletionToken,
    typename... Values>
constexpr consign_t< decay_t< CompletionToken >, decay_t< Values >... > consign(
    CompletionToken && completion_token,
    Values &&... values);

此完成标记适配器通常用于使对象 (例如智能指针) 的至少一个副本保持存活, 直到完成处理器被调用.

要求

头文件: boost/asio/consign.hpp

便捷头文件: boost/asio.hpp
