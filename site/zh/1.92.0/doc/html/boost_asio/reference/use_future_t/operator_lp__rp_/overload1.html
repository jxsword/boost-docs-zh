use_future_t::operator() (1 of 2 overloads)

把函数对象包装为打包任务 (packaged task).

template<
    typename Function>
unspecified operator()(
    Function && f) const;

package 函数用于把函数对象适配为打包任务 (packaged task). 当此适配器作为完成标记传递给异步操作时, 函数对象的结果通过 std::future 返回.

示例 
std::future<std::size_t> fut =
  my_socket.async_read_some(buffer,
    use_future([](boost::system::error_code ec, std::size_t n)
      {
        return ec ? 0 : n;
      }));
...
std::size_t n = fut.get();
