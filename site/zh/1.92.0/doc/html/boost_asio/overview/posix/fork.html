Fork

Boost.Asio 支持使用 fork() 系统调用的程序. 只要程序在适当的时机调用 io_context.notify_fork(), Boost.Asio 就会重新创建内部文件描述符 (例如用于唤醒反应器的 "self-pipe trick" 描述符) . 该通知通常按如下方式执行:

io_context_.notify_fork(boost::asio::io_context::fork_prepare);
if (fork() == 0)
{
  io_context_.notify_fork(boost::asio::io_context::fork_child);
  ...
}
else
{
  io_context_.notify_fork(boost::asio::io_context::fork_parent);
  ...
}

用户定义的服务也可以通过重写 io_context::service::notify_fork() 虚函数而具备 fork 感知能力.

注意, 任何可以通过 Boost.Asio 公共 API 访问的文件描述符 (例如 basic_socket<>、posix::stream_descriptor 等底层的描述符) 在 fork 期间不会被改变. 程序需要自行按需管理它们.

参见

io_context::notify_fork()、io_context::fork_event、io_context::service::notify_fork()、Fork 示例.
