面向流的文件描述符

Boost.Asio 加入了一些类, 允许对 POSIX 文件描述符 (如管道、标准输入输出以及各种设备) 执行同步和异步读写操作.

这些类还为常规文件提供有限的支持. 这种支持假设操作系统提供的底层读写操作永远不会以 EAGAIN 或 EWOULDBLOCK 失败. (对于带缓冲的文件 I/O, 这一假设通常成立. ) 文件描述符上的同步和异步读写操作会成功, 但 I/O 总是立即执行. 等待操作, 以及涉及 boost::asio::null_buffers 的操作, 得不到可移植的支持.

例如, 要对标准输入输出执行读写操作, 可以创建以下对象:

posix::stream_descriptor in(my_io_context, ::dup(STDIN_FILENO));
posix::stream_descriptor out(my_io_context, ::dup(STDOUT_FILENO));

它们随后被用作同步或异步的读写流. 这意味着这些对象可以与 read()、async_read()、write()、async_write()、read_until() 或 async_read_until() 中的任何自由函数一起使用.

参见

posix::stream_descriptor、Chat 示例 (C++11).

注释

只有在目标操作系统支持时, POSIX 流描述符才会在编译期可用. 程序可以测试宏 BOOST_ASIO_HAS_POSIX_STREAM_DESCRIPTOR 来确定是否受支持.
