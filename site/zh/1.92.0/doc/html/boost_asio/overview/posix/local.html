UNIX 域套接字

Boost.Asio 为 UNIX 域套接字 (也称为本地套接字) 提供基本支持. 最简单的用法是创建一对已连接的套接字. 下面的代码:

local::stream_protocol::socket socket1(my_io_context);
local::stream_protocol::socket socket2(my_io_context);
local::connect_pair(socket1, socket2);

会创建一对面向流的套接字. 要对面向数据报的套接字做同样的事情, 请使用:

local::datagram_protocol::socket socket1(my_io_context);
local::datagram_protocol::socket socket2(my_io_context);
local::connect_pair(socket1, socket2);

UNIX 域套接字服务器可以通过把接受器绑定到一个端点来创建, 方式与 TCP 服务器大致相同:

::unlink("/tmp/foobar"); // Remove previous binding.
local::stream_protocol::endpoint ep("/tmp/foobar");
local::stream_protocol::acceptor acceptor(my_io_context, ep);
local::stream_protocol::socket socket(my_io_context);
acceptor.accept(socket);

连接到该服务器的客户端可能如下所示:

local::stream_protocol::endpoint ep("/tmp/foobar");
local::stream_protocol::socket socket(my_io_context);
socket.connect(ep);

Boost.Asio 并不直接支持跨 UNIX 域套接字传输文件描述符或凭据, 但可以通过 native_handle() 成员函数访问套接字的底层描述符来实现.

参见

local::connect_pair、local::datagram_protocol、local::datagram_protocol::endpoint、local::datagram_protocol::socket、local::stream_protocol、local::stream_protocol::acceptor、local::stream_protocol::endpoint、local::stream_protocol::iostream、local::stream_protocol::socket、UNIX 域套接字示例.

注释

只有在目标操作系统支持时, UNIX 域套接字才会在编译期可用. 程序可以测试宏 BOOST_ASIO_HAS_LOCAL_SOCKETS 来确定是否受支持.
