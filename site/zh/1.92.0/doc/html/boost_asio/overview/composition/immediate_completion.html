定制立即完成

associated_immediate_executor 关联器特征 (associator trait) 与 bind_immediate_executor 函数共同提供了定制完成处理器执行方式的能力, 适用于异步操作立即完成的情形.

当受支持的操作立即完成时 (即, 在发起函数之内) , 会获取关联的立即执行器, 完成处理器会经由该执行器交付, 就如同在该执行器上使用 boost::asio::dispatch 一样. 默认情况下, 立即执行器会经由操作的 I/O 执行器, 如同使用 boost::asio::post 那样交付完成处理器.

例如, 要允许对 async_read_some 操作的完成处理器进行递归调用, 我们可以指定立即完成经由一个 inline_executor 交付:

my_socket.async_read_some(my_buffer,
    bind_immediate_executor(
      inline_executor(),
      [](error_code e, size_t n)
      {
        // ...
      }
    )
  );

目前, 基于反应器的套接字和描述符上的异步操作, 以及通道上的异步操作, 均支持立即执行.

注意: 在启用完成处理器的立即执行时, 必须注意确保不会发生无界递归和栈溢出. 此外, 使用立即完成可能会影响完成处理器调度的公平性, 有可能使其他待处理工作陷入饥饿.

参见

associated_immediate_executor, bind_immediate_executor.
