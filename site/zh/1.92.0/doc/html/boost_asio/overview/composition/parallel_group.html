协调并行操作

注释

这是一项实验性特性.

experimental::make_parallel_group 函数可用于启动并行执行的工作, 并等待其中一个或全部操作完成. parallel_group 实现了对未完成操作的自动取消. 例如:

experimental::make_parallel_group(
    [&](auto token)
    {
      return stream.async_read_some(boost::asio::buffer(data), token);
    },
    [&](auto token)
    {
      return timer.async_wait(token);
    }
  ).async_wait(
    experimental::wait_for_one(),
    [](
        std::array<std::size_t, 2> completion_order,
        boost::system::error_code ec1, std::size_t n1,
        boost::system::error_code ec2
    )
    {
      // ...
    }
  );

组的完成条件可以使用所提供的四个函数对象 wait_for_all、wait_for_one、wait_for_one_success、wait_for_one_error 之一来指定, 也可以使用自定义函数.

parallel_group 设施还可以与 deferred 组合使用, 如下所示:

experimental::make_parallel_group(
    stream.async_read_some(boost::asio::buffer(data), deferred),
    timer.async_wait(experimental::deferred)
  ).async_wait(
    // ...
  );

注意: 为了获得最大的灵活性, parallel_group 不会自动把执行器传播给组内的操作.

参见

experimental::make_parallel_group、experimental::parallel_group、并行组示例 (C++11) 、并行组示例 (C++14) .
