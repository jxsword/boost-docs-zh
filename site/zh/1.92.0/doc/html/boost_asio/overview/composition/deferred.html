延迟操作

deferred 完成标记会把对异步操作发起函数的一次调用转换为一个接受完成标记的函数对象. 例如:

auto deferred_op =
  timer.async_wait(
    boost::asio::deferred);
...
std::move(deferred_op)(
    [](boost::system::error_code ec){ ... });

或者:

auto deferred_op =
  timer.async_wait(
    boost::asio::deferred);
...
std::future<void> =
  std::move(deferred_op)(
    boost::asio::use_future);

deferred 标记还支持链式调用, 以创建简单的组合:

auto deferred_op =
  timer.async_wait(
    boost::asio::deferred(
      [&](boost::system::error_code ec)
      {
        timer.expires_after(
            std::chrono::seconds(1));

        return timer.async_wait(
            boost::asio::deferred);
      });
...
std::future<void> = std::move(deferred_op)(boost::asio::use_future);
deferred 作为默认完成标记

Boost.Asio 提供的大多数异步操作都有一个默认完成标记. 尽管可以通过指定自定义执行器来更改这个默认标记, 但它通常是 boost::asio::deferred. 这意味着我们可以省略标记, 直接写成:

auto deferred_op = timer.async_wait();
