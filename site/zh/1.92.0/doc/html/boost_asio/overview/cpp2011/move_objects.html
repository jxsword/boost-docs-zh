可移动 I/O 对象

当移动支持可用时 (通过右值引用) , Boost.Asio 允许对套接字、串口、POSIX 描述符和 Windows 句柄进行移动构造和移动赋值.

移动支持让你可以编写如下代码:

tcp::socket make_socket(io_context& i)
{
  tcp::socket s(i);
  ...
  std::move(s);
}

或者:

class connection : public enable_shared_from_this<connection>
{
private:
  tcp::socket socket_;
  ...
public:
  connection(tcp::socket&& s) : socket_(std::move(s)) {}
  ...
};

...

class server
{
private:
  tcp::acceptor acceptor_;
  ...
  void handle_accept(error_code ec, tcp::socket socket)
  {
    if (!ec)
      std::make_shared<connection>(std::move(socket))->go();
    acceptor_.async_accept(...);
  }
  ...
};

以及:

std::vector<tcp::socket> sockets;
sockets.push_back(tcp::socket(...));

提醒一句: 没有任何东西阻止你在还有未完成的异步操作时移动这些对象, 但这样做不太可能是个好主意. 特别是, async_read() 这类组合操作会保存对流对象的引用. 在组合操作进行期间移动对象, 意味着该组合操作可能试图访问一个已被移出的对象.

移动支持会在 g++ 4.5 及更高版本中自动启用 (使用 -std=c++0x 或 -std=gnu++0x 编译器选项时) . 可以通过定义 BOOST_ASIO_DISABLE_MOVE 将其禁用, 或通过定义 BOOST_ASIO_HAS_MOVE 为其他编译器显式启用. 注意, 这些宏也影响 可移动处理器 的可用性.
