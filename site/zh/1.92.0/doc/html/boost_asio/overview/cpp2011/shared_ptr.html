共享指针

Boost.Asio 的实现可以优先使用 std::shared_ptr<> 和 std::weak_ptr<>, 而非对应的 Boost 版本.

对标准智能指针的支持会在 g++ 4.3 及更高版本中自动启用 (使用 -std=c++0x 或 -std=gnu++0x 编译器选项时) , 同样适用于 Microsoft Visual C++ 10. 可以通过定义 BOOST_ASIO_DISABLE_STD_SHARED_PTR 将其禁用, 或通过定义 BOOST_ASIO_HAS_STD_SHARED_PTR 为其他编译器显式启用.
