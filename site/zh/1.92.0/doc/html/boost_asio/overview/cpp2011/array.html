数组容器

在标准库提供 std::array<> 的地方, Boost.Asio:

  • 为 buffer() 函数提供重载.
  • 优先使用它而非 boost::array<>, 用于 ip::address_v4::bytes_type 和 ip::address_v6::bytes_type 类型.
  • 在实现中需要固定大小数组类型的地方, 优先使用它而非 boost::array<>.

对 std::array<> 的支持会在 g++ 4.3 及更高版本中自动启用 (使用 -std=c++0x 或 -std=gnu++0x 编译器选项时) , 同样适用于 Microsoft Visual C++ 10. 可以通过定义 BOOST_ASIO_DISABLE_STD_ARRAY 将其禁用, 或通过定义 BOOST_ASIO_HAS_STD_ARRAY 为其他编译器显式启用.
