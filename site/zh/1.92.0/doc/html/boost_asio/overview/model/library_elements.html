支撑性库元素

Boost.Asio 异步模型由下表所列的库元素支撑.

库元素

说明

completion_signature concept

定义有效的完成签名形式.

completion_handler_for concept

判断完成处理器对于给定的一组完成签名是否可调用.

async_result 特征

把完成签名和完成标记转换成具体的完成处理器, 并启动操作.

async_initiate 函数

用于简化 async_result 特征使用的辅助函数.

completion_token_for concept

判断完成标记对于给定的一组完成签名是否会产生完成处理器.

associator 特征

在各层抽象之间自动传播所有关联器.

associated_executor 特征、associated_executor_t 类型别名和 get_associated_executor 函数

定义异步代理的关联执行器.

associated_allocator 特征、associated_allocator_t 类型别名和 get_associated_allocator 函数

定义异步代理的关联分配器.

associated_cancellation_slot 特征、associated_cancellation_slot_t 类型别名和 get_associated_cancellation_slot 函数

定义异步代理的关联取消槽.
