更高层的抽象

本节介绍的异步模型为定义更高层的抽象提供了基础. Boost.Asio 在这个核心模型之上构建, 以提供额外的设施, 例如:

  • 诸如 sockets 和 timers 之类的 I/O 对象, 在此模型之上暴露异步操作.
  • 具体执行器, 例如 io_context 执行器、thread_pool 执行器, 以及保证完成处理器非并发执行的 strand 适配器.
  • 促成不同组合机制的完成标记, 例如 C++ coroutines、stackful coroutines、futures 和 deferred operations.
  • 针对 C++ 协程的高层支持, 它组合了执行器与取消槽支持, 从而实现 并发异步代理的轻松协调.

为了让用户能更轻松地编写遵循此模型的自己的异步操作, Boost.Asio 还提供了辅助函数 async_compose.
