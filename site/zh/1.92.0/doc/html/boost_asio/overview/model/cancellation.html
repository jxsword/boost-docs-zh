取消

在 Boost.Asio 中, 许多对象 (如套接字和定时器) 通过其 close 或 cancel 成员函数支持对未完成的异步操作进行对象级取消. 不过, 某些异步操作还支持单独的、有针对性的取消. 这种按操作取消是通过规定每个异步代理都有一个关联的 取消槽 来实现的.

为支持取消, 异步操作会向代理的槽中安装一个取消处理器. 取消处理器是一个函数对象, 当用户向该槽发出取消信号时会被调用. 由于取消槽与单个代理相关联, 该槽一次至多持有一个处理器, 安装新处理器会覆盖任何先前安装的处理器. 因此, 同一个槽会在代理内的后续异步操作中被复用.

当异步操作包含多个子代理时, 取消特别有用. 例如, 一个子代理可能已经完成, 而另一个子代理随后被取消, 因为它的副作用不再需要.
