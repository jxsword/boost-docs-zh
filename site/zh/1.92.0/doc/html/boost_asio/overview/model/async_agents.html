异步代理

异步代理是异步操作的顺序组合. 每个异步操作都被视为作为某个异步代理的一部分而运行, 即使该代理只包含这一个操作. 异步代理是一种可以与其他代理并发执行工作的实体. 异步代理之于异步操作, 就如同线程之于同步操作.

然而, 异步代理是一个纯粹的概念性构造, 让我们能够就程序中异步操作的上下文和组合进行推理. "异步代理"这一名称并未出现在库中, 使用哪种具体机制[1]来组合代理中的异步操作也并不重要.
