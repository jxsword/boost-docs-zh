套接字 iostream

Boost.Asio 提供了一些在套接字之上实现 iostream 的类. 它们隐藏了与端点解析、协议无关性等相关的复杂细节. 要建立一个连接, 可以简单地这样写:

ip::tcp::iostream stream("www.boost.org", "http");
if (!stream)
{
  // Can't connect.
}

iostream 类还可以与接受器配合使用来创建简单的服务器. 例如:

io_context ioc;

ip::tcp::endpoint endpoint(tcp::v4(), 80);
ip::tcp::acceptor acceptor(ioc, endpoint);

for (;;)
{
  ip::tcp::iostream stream;
  acceptor.accept(stream.socket());
  ...
}

可以通过调用 expires_at() 或 expires_from_now() 来设置超时, 以确立一个期限. 超过该期限后发生的任何套接字操作都会使 iostream 进入 "bad" 状态.

例如, 一个像这样的简单客户端程序:

ip::tcp::iostream stream;
stream.expires_from_now(boost::posix_time::seconds(60));
stream.connect("www.boost.org", "http");
stream << "GET /LICENSE_1_0.txt HTTP/1.0\r\n";
stream << "Host: www.boost.org\r\n";
stream << "Accept: */*\r\n";
stream << "Connection: close\r\n\r\n";
stream.flush();
std::cout << stream.rdbuf();

如果所有套接字操作加起来耗时超过 60 秒, 就会失败.

如果确实发生了错误, 可以使用 iostream 的 error() 成员函数从最近的系统调用中取得错误码:

if (!stream)
{
  std::cout << "Error: " << stream.error().message() << "\n";
}
参见

ip::tcp::iostream、basic_socket_iostream、iostreams 示例.

注释

这些 iostream 模板只支持 char, 不支持 wchar_t, 并且不执行任何代码转换.
