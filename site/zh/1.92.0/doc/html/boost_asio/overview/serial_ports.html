串口

Boost.Asio 提供了以可移植方式创建和操作串口的类. 例如, 串口可以这样打开:

serial_port port(my_io_context, name);

其中 name 在 Windows 上类似 "COM1", 在 POSIX 平台上类似 "/dev/ttyS0".

打开后, 串口可以用作 stream. 这意味着这些对象可以与 read()、async_read()、write()、async_write()、read_until() 或 async_read_until() 中的任何自由函数一起使用.

串口实现还包括用于配置端口波特率、流控制类型、奇偶校验、停止位和字符大小的选项类.

参见

serial_port、serial_port_base、serial_port_base::baud_rate、serial_port_base::flow_control、serial_port_base::parity、serial_port_base::stop_bits、serial_port_base::character_size.

注释

串口在所有 POSIX 平台上都可用. 对于 Windows, 只有在使用 I/O 完成端口后端 (默认) 时, 串口才在编译期可用. 程序可以测试宏 BOOST_ASIO_HAS_SERIAL_PORT 来确定是否受支持.
