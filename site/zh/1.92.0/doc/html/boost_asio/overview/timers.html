定时器

长时间运行的 I/O 操作通常会有一个完成期限. 这些期限可以表示为绝对时间, 但通常是相对当前时间计算的.

举一个简单的例子, 要以相对时间对定时器执行同步等待操作, 可以这样写:

io_context i;
...
steady_timer t(i);
t.expires_after(chrono::seconds(5));
t.wait();

更常见的情况是, 程序对定时器执行异步等待操作:

void handler(boost::system::error_code ec) { ... }
...
io_context i;
...
steady_timer t(i);
t.expires_after(chrono::milliseconds(400));
t.async_wait(handler);
...
i.run();

与定时器关联的期限也可以作为绝对时间获取:

steady_timer::time_point time_of_expiry = t.expiry();

这样可以组合定时器:

steady_timer t2(i);
t2.expires_at(t.expiry() + chrono::seconds(30));
