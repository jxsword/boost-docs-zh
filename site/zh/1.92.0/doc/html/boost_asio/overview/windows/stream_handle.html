面向流的 HANDLE

Boost.Asio 包含一些类, 允许对 Windows 的 HANDLE (例如命名管道) 执行异步读写操作.

例如, 要对一个命名管道执行异步操作, 可以创建以下对象:

HANDLE handle = ::CreateFile(...);
windows::stream_handle pipe(my_io_context, handle);

它们随后被用作同步或异步的读写流. 这意味着这些对象可以与 read()、async_read()、write()、async_write()、read_until() 或 async_read_until() 中的任何自由函数一起使用.

HANDLE 所引用的内核对象必须支持与 I/O 完成端口一起使用 (这意味着支持命名管道, 但不支持匿名管道和控制台流) .

参见

windows::stream_handle.

注释

Windows 流 HANDLE 只有在以 Windows 为目标平台且使用 I/O 完成端口后端 (默认) 时才在编译期可用. 程序可以测试宏 BOOST_ASIO_HAS_WINDOWS_STREAM_HANDLE 来确定是否受支持.
