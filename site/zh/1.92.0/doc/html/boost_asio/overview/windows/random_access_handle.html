随机访问 HANDLE

Boost.Asio 提供了 Windows 特有的类, 允许对引用常规文件的 HANDLE 执行异步读写操作.

例如, 要对一个文件执行异步操作, 可以创建以下对象:

HANDLE handle = ::CreateFile(...);
windows::random_access_handle file(my_io_context, handle);

可以使用 read_some_at()、async_read_some_at()、write_some_at() 或 async_write_some_at() 成员函数之一从该句柄读取或写入数据. 不过, 与流上的等价函数 (read_some() 等) 一样, 这些函数只要求在单次操作中传输一个或多个字节. 因此, 人们创建了名为 read_at()、async_read_at()、write_at() 和 async_write_at() 的自由函数, 反复调用相应的 *_some_at() 函数, 直到所有数据传输完毕.

参见

windows::random_access_handle.

注释

Windows 随机访问 HANDLE 只有在以 Windows 为目标平台且使用 I/O 完成端口后端 (默认) 时才在编译期可用. 程序可以测试宏 BOOST_ASIO_HAS_WINDOWS_RANDOM_ACCESS_HANDLE 来确定是否受支持.
