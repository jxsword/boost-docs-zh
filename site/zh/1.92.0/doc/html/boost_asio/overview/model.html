异步模型

本节对 Boost.Asio 库核心的异步模型进行高层概述. 该模型将异步操作确立为异步组合的基本构件, 同时将其与组合机制解耦. Boost.Asio 中的异步操作支持回调、future (急切式与延迟式均可) 、纤程、协程, 以及尚未设想出来的方式. 这使应用程序员可以基于恰当的权衡来选择某种方式.
