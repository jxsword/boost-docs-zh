信号处理

Boost.Asio 通过一个名为 signal_set 的类支持信号处理. 程序可以把一个或多个信号加入该集合, 然后执行一次 async_wait() 操作. 当其中某个信号发生时, 指定的处理器会被调用. 同一个信号编号可以在多个 signal_set 对象中注册, 但该信号编号必须只与 Boost.Asio 一起使用.

void handler(
    const boost::system::error_code& error,
    int signal_number)
{
  if (!error)
  {
    // A signal occurred.
  }
}

...

// Construct a signal set registered for process termination.
boost::asio::signal_set signals(io_context, SIGINT, SIGTERM);

// Start an asynchronous wait for one of the signals to occur.
signals.async_wait(handler);

信号处理在 Windows 上同样可用, 因为 Microsoft Visual C++ 运行时库会把 Ctrl+C 之类的控制台事件映射到等价的信号.
