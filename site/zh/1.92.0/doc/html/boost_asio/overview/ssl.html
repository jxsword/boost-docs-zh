SSL

Boost.Asio 包含用于基本 SSL 支持的类和类模板. 这些类允许在现有流 (例如 TCP 套接字) 之上叠加加密通信.

在创建加密流之前, 应用程序必须构造一个 SSL 上下文对象. 该对象用于设置 SSL 选项, 例如验证模式、证书文件等. 举例来说, 客户端侧的初始化可能类似于:

ssl::context ctx(ssl::context::sslv23);
ctx.set_verify_mode(ssl::verify_peer);
ctx.load_verify_file("ca.pem");

要对 TCP 套接字使用 SSL, 可以这样写:

ssl::stream<ip::tcp::socket> ssl_sock(my_io_context, ctx);

要执行特定于套接字的操作, 例如建立出站连接或接受入站连接, 必须先用 ssl::stream 模板的 lowest_layer() 成员函数获取底层套接字:

ip::tcp::socket::lowest_layer_type& sock = ssl_sock.lowest_layer();
sock.connect(my_endpoint);

在某些使用场景中, 底层流对象的生存期需要长于 SSL 流, 此时模板参数应当是对该流类型的引用:

ip::tcp::socket sock(my_io_context);
ssl::stream<ip::tcp::socket&> ssl_sock(sock, ctx);

在通过加密连接传输或接收数据之前, 必须先执行 SSL 握手. 这通过 ssl::stream 模板的 handshake() 或 async_handshake() 成员函数完成.

连接建立后, SSL 流对象被用作同步或异步的读写流. 这意味着这些对象可以与 read()、async_read()、write()、async_write()、read_until() 或 async_read_until() 中的任何自由函数一起使用.

证书验证

Boost.Asio 提供了多种方法来配置 SSL 证书的验证方式:

  • ssl::context::set_default_verify_paths()
  • ssl::context::set_verify_mode()
  • ssl::context::set_verify_callback()
  • ssl::context::load_verify_file()
  • ssl::stream::set_verify_mode()
  • ssl::stream::set_verify_callback()

为了简化按 RFC 6125 规则 (传输层安全上下文中的身份验证) 验证证书的使用场景, Boost.Asio 以函数对象的形式提供了一个可复用的验证回调:

  • ssl::host_name_verification

下面的示例演示按 HTTPS 所用规则验证远程主机的证书:

using boost::asio::ip::tcp;
namespace ssl = boost::asio::ssl;
typedef ssl::stream<tcp::socket> ssl_socket;

// Create a context that uses the default paths for
// finding CA certificates.
ssl::context ctx(ssl::context::sslv23);
ctx.set_default_verify_paths();

// Open a socket and connect it to the remote host.
boost::asio::io_context io_context;
ssl_socket sock(io_context, ctx);
tcp::resolver resolver(io_context);
tcp::resolver::query query("host.name", "https");
boost::asio::connect(sock.lowest_layer(), resolver.resolve(query));
sock.lowest_layer().set_option(tcp::no_delay(true));

// Perform SSL handshake and verify the remote host's
// certificate.
sock.set_verify_mode(ssl::verify_peer);
sock.set_verify_callback(ssl::host_name_verification("host.name"));
sock.handshake(ssl_socket::client);

// ... read and write as normal ...
SSL 与线程

SSL 流对象自身不做任何加锁. 因此, 所有异步 SSL 操作都必须在隐式或显式的 strand 中执行, 这一点至关重要. 注意, 这意味着在单线程程序中不需要任何同步 (因此也不会产生加锁开销) .

参见

ssl::context、ssl::host_name_verification、ssl::stream、SSL 示例 (C++11).

注释

使用 Boost.Asio 的 SSL 支持需要 OpenSSL. 当应用程序需要使用未被 Boost.Asio 封装的 OpenSSL 功能时, 可以通过调用 ssl::context::native_handle() 或 ssl::stream::native_handle() 获取底层 OpenSSL 类型.
