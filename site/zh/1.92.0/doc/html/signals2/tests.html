验收测试

检验 类型 说明 如果失败...

connection_test.cpp

run

测试 boost::signals2::connection 和 boost::signals2::scoped_connection 对象的功能, 包括 release() 和 swap().

  

dead_slot_test.cpp

run

确保用已经过期的槽调用 connect 实际上不会连接到该槽.

  

deconstruct_test.cpp

run

测试 boost::signals2::deconstruct 的后构造/前析构功能.

  

deletion_test.cpp

run

测试槽的删除.

  

ordering_test.cpp

run

测试槽组排序.

  

regression_test.cpp

run

测试过去出现过的各种缺陷, 确保它们已被修复并保持修复状态.

  

signal_test.cpp

run

使用 boost::signals2::signal 类模板对信号/槽连接和调用进行基本测试.

  

track_test.cpp

run

测试信号和槽的自动连接管理.
