作为容器的属性树

每个属性树节点都建模 ReversibleSequence 概念, 提供对其直接子节点的访问. 这意味着对 ptree 的迭代(它等同于其根节点——每个 ptree 节点同时也是以它为起点的子树)只遍历层级结构中的一层. 无法一次遍历整棵树.

务必记住: 属性序列 不 按键排序, 它保持插入顺序, 非常类似 std::list. 按名快速访问子节点由单独的查找结构提供. 不要在节点子级上使用期望有序序列的算法(如 binary_search).

属性树还暴露了第二个类容器接口, 称为关联视图(associative view). 其迭代器类型是嵌套类型 assoc_iterator (以及对应的 const 版本 const_assoc_iterator). 使用 ordered_begin() 和 ordered_end() 可以得到全部子节点的有序视图.

关联视图同样提供 find() 和 equal_range() 成员, 它们返回 assoc_iterator, 其余语义与 std::map 中同名成员相同.

可以使用 to_iterator() 成员函数从 assoc_iterator 得到普通迭代器. 反向转换则不可行.
