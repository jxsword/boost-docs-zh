兼容性

属性树使用了类模板偏特化, 库并未尝试绕开对它的支持缺失. 因此本库极可能无法用于 Visual C++ 7.0 或更早版本, 以及 gcc 2.x.

属性树已在下列编译器上测试(回归测试编译并成功运行):

  • Visual C++ 8.0
  • gcc 3.4.2 (MinGW)
  • gcc 3.3.5 (Linux)
  • gcc 3.4.4 (Linux)
  • gcc 4.3.3 (Linux)
  • Intel C++ 9.0 (Linux)

设计原理

  1. 为什么 get 有 3 个版本? 不能只有一个吗? 这三个版本反映了在多个不同应用程序中多年使用属性树积累的经验. 在此期间我曾努力设计一种统一、正确的 get 函数形式, 但失败了. 我知道以下三种基本使用模式:
    • 把数据给我拿过来, 拿不到我不管. 用于程序员相当确定数据存在时. 或者用于课后作业. 或者当你的项目明天就是最后期限的时候.
    • 取数据, 取不到就回退为默认值. 用于允许省略相关键的场合. 一些类似工具(Windows INI 文件访问函数)就是这样实现的.
    • 取数据, 但相比数据本身, 我更关心你是否取到了. 用于需要根据 get 成功与否改变控制流的场合, 或用于检查键是否存在.

后续开发

  • 更健壮的 XML 解析器.
