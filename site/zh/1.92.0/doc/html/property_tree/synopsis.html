属性树概要

本库的核心组件是 basic_ptree 类模板. 该类的实例就是属性树. 它以键类型、数据类型和键比较策略为模板参数; ptree, wptree, iptree 和 wiptree 是使用预定义模板参数组合的 basic_ptree 的 typedef. 属性树基本上是一个略微简化了的标准容器(最接近的是 std::list), 外加一组额外的成员函数. 这些函数为访问属性树中存储的数据提供了简单而高效的途径, 它们是 get, put, get_value, put_value, get_child, put_child 的各种变体. 此外还有一个直接访问节点数据的 data 函数.

更多信息参见 basic_ptree class template synopsis.
