术语

[basic.align]

对象类型拥有 对齐要求, 它对该类型的对象可被分配的地址施加限制. 对齐 是一个由实现定义的整数值, 表示给定对象可被分配的相继地址之间的字节数. 对象类型对该类型的每一个对象都施加对齐要求; 可以使用对齐说明符请求更严格的对齐.

基本对齐 由一个小于或等于实现在所有上下文中支持的最大对齐的对齐表示, 后者等于 alignof(std::max_align_t). 类型所需要的对齐, 在该类型被用作完整对象的类型与被用作子对象的类型时可能不同. [示例:

  1. struct B { long double d; };
  2. struct D : virtual B { char c; };

当 D 是完整对象的类型时, 它将拥有一个 B 类型的子对象, 因此它必须按 long double 适当地对齐. 如果 D 作为另一个同样拥有 B 虚基类的对象的子对象出现, 则 B 子对象可能是另一个子对象的一部分, 从而降低了对 D 子对象的对齐要求. —示例结束] alignof 运算符的结果反映该类型在完整对象情形下的对齐要求.

扩展对齐 由一个大于 alignof(std::max_align_t) 的对齐表示. 是否支持任何扩展对齐以及支持它们的具体上下文, 由实现定义. 拥有扩展对齐要求的类型是 超对齐类型. [注释: 每一个超对齐类型本身是、或包含一个适用扩展对齐的类类型 (可能通过非静态数据成员实现) . —注释结束]

对齐表示为类型 std::size_t 的值. 有效对齐仅包括对基本类型由 alignof 表达式返回的那些值, 外加一组由实现定义的额外值, 该集合可以为空. 每一个对齐值都应是 2 的非负整数次幂.

对齐存在从 较弱 到 较强 或 更严格 的顺序. 更严格的对齐拥有更大的对齐值. 满足某个对齐要求的地址也满足任何更弱的有效对齐要求.

完整类型的对齐要求可以使用 alignof 表达式查询. 此外, 类型 char、signed char 和 unsigned char 应拥有最弱的对齐要求. [注释: 这使得字符类型可以被用作对齐内存区域的底层类型. —注释结束]

比较对齐是有意义的, 并给出显而易见的结果:

  • 两个对齐在其数值相等时相等.
  • 两个对齐在其数值不相等时不相同.
  • 当一个对齐大于另一个时, 它表示更严格的对齐.

[注释: 运行期指针对齐函数可用于在缓冲区内获得一个对齐的指针; 本库中的对齐存储模板可用于获得对齐的存储. —注释结束]

如果实现不支持在特定上下文中对特定扩展对齐的请求, 则程序非良构. 此外, 对动态存储的运行期分配请求若无法满足所请求的对齐, 应被视为分配失败.
