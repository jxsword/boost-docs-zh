align

void* align(std::size_t alignment, std::size_t size, void*& ptr, std::size_t& space);

头文件

#include <boost/align/align.hpp>

效果

如果有可能将 size 字节的按 alignment 对齐的存储空间放入 ptr 所指向、长度为 space 的缓冲区中, 则该函数会把 ptr 更新为指向此类存储空间的首个可能地址, 并从 space 中减去用于对齐所耗费的字节数. 否则, 该函数不做任何事.

要求
  • alignment 必须是 2 的幂
  • ptr 必须指向至少 space 字节的连续存储空间
返回
如果所请求的对齐缓冲区无法放入可用空间, 则为空指针; 否则为 ptr 调整后的值.
注释

该函数会更新其 ptr 与 space 实参, 以便可以对同一缓冲区以可能不同的 alignment 与 size 实参重复调用.

aligned_alloc

void* aligned_alloc(std::size_t alignment, std::size_t size);

头文件

#include <boost/align/aligned_alloc.hpp>

效果

为一个对象分配空间, 其对齐由 alignment 指定, 大小由 size 指定, 其值是不确定的.

要求

alignment 必须是 2 的幂.

返回

空指针, 或指向已分配空间的指针.

注释

在某些平台上, 所分配的空间可能略大于 size 字节, 以便留出对齐所需的余量.

aligned_free

void aligned_free(void* ptr);

头文件

#include <boost/align/aligned_alloc.hpp>

效果

使 ptr 所指向的空间被释放, 即重新可用于后续分配. 如果 ptr 是空指针, 则不执行任何操作. 否则, 如果该实参与 aligned_alloc() 函数先前返回的指针不匹配, 或者该空间已被对 aligned_free() 的调用释放, 则行为未定义.

要求

ptr 是空指针, 或是 aligned_alloc() 函数先前返回且尚未被对 aligned_free() 的调用释放的指针.

返回

aligned_free() 函数不返回值.

aligned_allocator

template<class T, std::size_t Alignment = 1> class aligned_allocator;

头文件

#include <boost/align/aligned_allocator.hpp>

注释

将 aligned_allocator 与最小 Alignment 值一起使用, 通常仅对非基于节点的容器 (例如 vector) 有用. 对于基于节点的容器 (例如 list) , 拥有最小对齐的将是节点对象而非值类型对象.

  2. typedef T* pointer;
  3. typedef const T* const_pointer;
  4. typedef void* void_pointer;
  5. typedef const void* const_void_pointer;
  6. typedef std::add_lvalue_reference_t<T> reference;
  7. typedef std::add_lvalue_reference_t<const T> const_reference;
  8. typedef std::size_t size_type;
  9. typedef std::ptrdiff_t difference_type;
  10. typedef std::true_type propagate_on_container_move_assignment;
  11. typedef std::true_type is_always_equal;
  12. template<class U> struct rebind { typedef aligned_allocator<U, Alignment> other; };
构造函数

aligned_allocator() = default;

效果

构造分配器.

template<class U> aligned_allocator(const aligned_allocator<U, Alignment>&) noexcept;

效果

构造分配器.

成员函数

除析构函数外, aligned_allocator 的成员函数不得因不同线程对这些成员函数的并发调用而引入数据竞争. 对这些函数的调用 -- 当其分配或释放某个特定存储单元时 -- 应处于单一全序之中, 且在此顺序中每一次这样的释放调用都应先于下一次分配 (如有) .

pointer allocate(size_type size, const_void_pointer = 0);

返回

一个指针, 指向大小为 n * sizeof(T) 的存储数组的初始元素, 其对齐取指定的最小对齐与 T 类型对象对齐两者中的最大值.

备注

该存储通过调用 aligned_alloc(std::size_t, std::size_t) 获得.

抛出

如果无法获得存储空间, 则抛出 std::bad_alloc.

void deallocate(pointer ptr, size_type);

要求

效果

备注

使用 aligned_free(void*).

size_type max_size() const noexcept;

返回

最大的值 N, 对该值调用 allocate(N) 可能成功.

aligned_allocator_adaptor

template<class Allocator, std::size_t Alignment = 1> class aligned_allocator_adaptor;

头文件

#include <boost/align/aligned_allocator_adaptor.hpp>

注释

该适配器可与指针类型为智能指针的 C++11 Allocator 一起使用, 而适配器可以选择只暴露原始指针类型.

  2. typedef value_type* pointer;
  3. typedef const value_type* const_pointer;
  4. typedef void* void_pointer;
  5. typedef const void* const_void_pointer;
  6. typedef std::size_t size_type;
  7. typedef std::ptrdiff_t difference_type;
  8. template<class U> struct rebind { typedef aligned_allocator_adaptor<typename std::allocator_traits<Allocator>::template rebind_alloc<U>, Alignment> other; };
构造函数

aligned_allocator_adaptor() = default;

效果

对 Allocator 基类进行值初始化.

template<class A> aligned_allocator_adaptor(A&& alloc) noexcept;

要求

Allocator 必须可以从 A 构造.

效果

将 Allocator 基类初始化为 std::forward<A>(alloc).

template<class U> aligned_allocator_adaptor(const aligned_allocator_adaptor<U, Alignment>& other) noexcept;

要求

Allocator 必须可以从 A 构造.

效果

将 Allocator 基类初始化为 other.base().

成员函数

Allocator& base() noexcept;

返回

static_cast<Allocator&>(*this)

const Allocator& base() const noexcept;

返回

static_cast<const Allocator&>(*this)

pointer allocate(size_type size);

返回

一个指针, 指向大小为 n * sizeof(value_type) 的存储数组的初始元素, 其对齐取指定的最小对齐与 value_type 类型对象对齐两者中的最大值.

备注

该存储通过调用 A2::allocate() 获得, 调用对象为 a2, 其中 a2 的类型为 A2, 是 base() 的重绑定副本, 其 value_type 由实现定义.

抛出

如果无法获得存储空间, 则抛出由 A2::allocate() 抛出的异常.

pointer allocate(size_type size, const_void_pointer hint);

要求

hint 是通过在任何等价的分配器对象上调用 allocate() 而获得的值, 否则为空指针.

返回

一个指针, 指向大小为 n * sizeof(value_type) 的存储数组的初始元素, 其对齐取指定的最小对齐与 value_type 类型对象对齐两者中的最大值.

备注

该存储通过调用 A2::allocate() 获得, 调用对象为 a2, 其中 a2 的类型为 A2, 是 base() 的重绑定副本, 其 value_type 由实现定义.

抛出

如果无法获得存储空间, 则抛出由 A2::allocate() 抛出的异常.

void deallocate(pointer ptr, size_type size);

要求
  • ptr 必须是从 allocate() 获得的指针值
  • size 必须等于作为第一个实参传给 allocate() 调用 (该调用返回了 ptr) 的值.
效果
释放 ptr 所引用的存储空间.
注释

使用 A2::deallocate(), 调用对象为 a2, 其中 a2 的类型为 A2, 是 base() 的重绑定副本, 其 value_type 由实现定义.

aligned_delete

class aligned_delete;

头文件

#include <boost/align/aligned_delete.hpp>

成员运算符

template<class T> void operator()(T* ptr) noexcept(noexcept(ptr->~T()));

效果

调用 ~T() (作用于 ptr) 以销毁对象, 然后调用 aligned_free() (作用于 ptr) 以释放已分配的内存.

注释

如果 T 是不完整类型, 则程序非良构.

alignment_of

alignment_of

template<class T> struct alignment_of;

头文件

#include <boost/align/alignment_of.hpp>

值

类型 T 的对齐要求, 表示为类型 std::size_t 的整型常量. 当 T 是引用数组类型时, 该值应为被引用类型的对齐值. 当 T 是数组类型时, 该值应为元素类型的对齐值.

要求

T 必须是完整对象类型、其数组, 或指向这些类型之一的引用.

宏

BOOST_ALIGN_ASSUME_ALIGNED

BOOST_ALIGN_ASSUME_ALIGNED

BOOST_ALIGN_ASSUME_ALIGNED(ptr, alignment)

头文件

#include <boost/align/assume_aligned.hpp>

要求
  • alignment 必须是 2 的幂
  • ptr 必须是可变的
效果
可能会以实现特定的方式修改 ptr, 以将其对齐方式告知编译器.
