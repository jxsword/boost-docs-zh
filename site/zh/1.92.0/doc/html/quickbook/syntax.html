语法摘要

注释

QuickBook 文档由一个或多个块组成. 段落或 C++ 代码片段就是块的例子. 某些块具有特殊标记. 除了拥有自己文法 (C++ 或 Python) 的代码片段外, 块由一个或多个短语组成. 短语可以是简单的连续字符串. 短语可以带有特殊标记. 被标记的短语可以递归地包含其他短语, 但不能包含块. 终结符 (terminal) 是自足的块级或短语级元素, 不嵌套任何内容.

块通常由两个行尾符 (块终结符) 界定. 每个块中的短语不能包含块终结符. 这样, 诸如未匹配闭括号之类的语法错误就不会失控而破坏单个块之后的内容.
