变更日志

版本 1.1 - Boost 1.33.0

  • 首个纳入 boost 的版本.

版本 1.3 - Boost 1.34.0 至 1.34.1

  • QuickBook 文件包含 [include].
  • 更好的 xml 输出 (美观的排版). 请查看生成的 XML.
  • 回归测试设施: 确保无论如何更改 QuickBook, 你的文档始终兼容 (完全向后兼容).
  • 代码清理与重构.
  • 允许在 doc-info 中使用短语标记.
  • 通过 ``code`` (双反引号) 的预格式化代码块, 例如允许在表格和列表中放置代码.
  • QuickBook 版本化; 允许完全向后兼容. 必须在 doc-info 头部添加 [quickbook 1.3] 才能启用新特性. 否则, QuickBook 会假定该文档是 1.3 之前的文档.

  • 更好 (直观) 的段落终止. 某些标记可以终止段落. 例如:

    [section x]
blah...
[endsect]
  • 完整限定的小节与标题. 小节名会拼接到 ID 上以避免冲突. 例如: doc_name.sect_name.sub_sect_name.sub_sub_sect_name
  • 改进代码片段中 &nbsp; 和空白字符的处理.
  • 当 input_directory 与 output_directory 不同时, [xinclude] 会修正目标 XML 文件的相对路径.
  • 允许无标题表格.
  • 允许在小节标题中使用短语标记.
  • 允许从代码、代码块和行内代码逃逸回 QuickBook.
  • 脚注, 使用 [footnote This is the footnote] 语法.
  • 修复后处理器对未识别的转义 XML 代码的缺陷.
  • 可替换文本, 使用 [~replacement] 语法.

版本 1.4 - Boost 1.35.0 至 1.40.0

  • 通用头文件
  • 代码更改以支持完全递归 (即收集器和 push/pop 函数)
  • 各种代码清理/维护
  • 模板!
  • [conceptref], 用于引用 BoostBook <concept> 实体.
  • 允许转义空格. 被转义的空格会从输出中移除. 语法: \ .
  • 现在允许嵌套注释.
  • QuickBook 块可以嵌套在注释内.
  • 导入设施.
  • 导入代码上的标注 (callout)
  • 简单标记现在可以跨越整个块.
  • 妙语, 提示框 和表格单元格 (见 表格) 现在可以包含段落.
  • \n 和 [br] 现已弃用.
  • 条件生成. 类似 C++ 的 #ifdef.
  • 通过 --include-path (-I) 选项, 在可扩展的搜索路径中搜索被包含和被导入的文件.

版本 1.5 - Boost 1.41.0 至 1.42.0

  • 支持在文档信息中使用多个版权条目.
  • 改进的 SVG 支持.
  • [globalref], 用于引用 BoostBook <global> 实体.
  • 出错即失败.
  • 修复实参过多或含尾部空格的模板导致的崩溃.
  • 改进对代码块中意外字符的处理.
  • 改进对代码块中未匹配转义的处理.
  • 支持 python 片段.
  • teletype 源模式.
  • 在模板中使用静态作用域, 应该直观得多.
  • 接受 section: 与小节 id 之间的空格.
  • 支持表格 id.

版本 1.5.1 - Boost 1.43.0

  • 改进后处理器的块元素列表. table, entry 和 varlistentry 被视为块. replaceable 被视为行内元素.
  • 检查模板中 [section] 和 [endsect] 标签是否配对.
  • 添加 unicode 转义字符, 例如 \u03B1 表示 α.
  • 支持带 unicode 字节顺序标记的 UTF-8 文件.
  • 不允许在简单标记中使用 [ . 修复了标点不匹配导致的一些错误.
  • 添加命令行标志以在命令行定义宏, 例如 quickbook "-D__italic_foo__=/foo/" .

版本 1.5.2 - Boost 1.44.0

  • 使用 cygwin 1.7 API 以更好地处理路径.
  • 改进的 boostbook 生成:
    • 正确地对文档信息进行 XML 编码.
    • 避免生成空段落.
    • 不再将块模板包装在段落中.
    • 若对 docbook 文档类型使用了无效的 doc_info 成员则发出警告.
    • 修复了产生无效 boostbook 的一些其他原因, 尽管在某些地方仍会生成无效的 boostbook.
  • 改进的文法:
    • 支持在库的 doc_info 中使用多个分类.
    • docinfo 中作者之间不再要求逗号.
    • 允许空的文档主体.
    • 仅包含注释的行不再被解释为段落分隔.
    • 如果一行以注释开头, 即使后面跟着空白或列表字符, 也将其解释为段落.
    • 不再把多个连续空行当作多个段落分隔.
  • 修复重复图像属性检测.
  • 修复多次使用代码片段的问题.
  • quickbook 1.6 的早期工作, 可使用 [quickbook 1.6] 版本开关启用, 但在未来的版本中可能发生变化.
    • 为标题自动生成 id 时, 使用 quickbook 源码而非生成的 docbook.
    • 修复被包含文件中的 id 生成. 它此前未正确使用主文档的 documentation id.
    • 包含不同版本的文件后, 正确恢复 quickbook 版本开关.

版本 1.5.3 - Boost 1.45.0

  • 修复定义宏的命令行标志.
  • 修复代码块解析器的几个问题:
    • 无缩进的注释现在会结束代码块.
    • 代码块后面不再必须跟一个空行.
  • 改进模板和导入代码块中的文件位置跟踪.
  • 为标注列表生成更好的标记.
  • 在 docbook 中, 变长列表条目只能有一个 listitem, 因此如果条目有多个值, 则将它们合并为一个 listitem.
  • 支持嵌套代码片段.
  • 支持文档信息注释中的嵌套块.
  • 回退文档信息的 xml 转义, 它破坏了一些文档文件 (现在是 1.6 的特性).
  • quickbook 1.6 的进一步工作, 仍不稳定.
    • 允许标题拥有 id, 使用语法: [heading:id title].
    • 对文档字段进行 XML 转义, 并提供转义以支持在 ASCII 中编码 unicode.

版本 1.5.4 - Boost 1.46.1

Boost 1.46.0:

  • 添加对文档信息中 lang 属性的支持.
  • 改进的锚点实现. 特别是在小节或标题前使用锚点时.
  • 修复了更多将包含注释的行当作空行处理的问题.
  • 允许在条件短语中使用 import、include 和 xinclude. 未来的版本将允许更多块元素.
  • 重排文法的结构.
  • 使用 filesystem 3. 移除 cygwin 1.5 支持.

Boost 1.46.1:

  • 针对 64 位 linux 上 g++ 4.4 的优化缺陷采取变通处理.

版本 1.5.5 - Boost 1.47

  • 调整标题的锚点位置.
  • 将 quickbook 路径硬编码到 quickbook 测试工具中. 这意味着可以从多个位置使用它们.
  • 为 boostbook bridgehead 元素生成 id. 这使得 html 更加一致, 因为 docbook 会在元素没有 id 时生成随机 id.
  • 改进 windows 上的 unicode 支持. 现在可以从命令行使用 unicode, 并且支持 unicode 文件名. unicode 输出仍稍显薄弱.
  • 检查 windows 路径, 并对其发出警告.
  • 修复 windows 上的相对路径检测.
  • 撤回 [br] 的弃用, 在生成无效 boostbook 时打印一条警告.
  • 修复空 category 属性的处理.
  • 将来自解析器的数据存储在动态数据结构中. 这简化了实现, 并使解析更复杂的数据结构更加容易.
  • 改进未知 doc info 属性的错误消息.
  • 更丰富的版权语法. 现在可以理解: [copyright 2001-2006, 2010 One person, 2008 Another person].
  • 修复简单标记的分隔符检查.
  • 允许嵌套更多块元素.
  • 改回对列表使用无效标记. 它生成更好的 html.
  • 改进列表的锚点位置.
  • 在代码片段中透传注释.
  • 对 __FILENAME__ 宏使用相对路径.
  • 重写 xinclude 路径生成器, 使其不再使用已弃用的 filesystem 函数.
  • 允许在语法高亮代码的注释内使用 quickbook 转义.
  • Quickbook 1.6:
    • 将源模式更改的作用范围限定在做出更改的文件内.
    • 列表的显式标记. 例如 [ordered_list [item1][item2]] 或 [itemized_list [item1][item2]].

版本 1.5.6 - Boost 1.48

  • 对转义的标点进行 xml 编码 (例如 \< 会被正确编码为 <).
  • 重命名重复的生成 id.
  • 在文档末尾关闭未关闭的小节 (仍会对其发出警告).
  • 用于标题的新锚点标记, 希望能生成更好的 pdf.
  • 从后处理输出中移除代码周围的一些空白.

版本 1.5.7 - Boost 1.49

  • 若干内部更改.
  • 一些改进的错误消息.
  • 更好地处理在短语上下文中展开的块模板.
  • 避免空的简单标记 (即 // 不再被视为斜体的空白).
  • 用于标题的更好锚点标记, 应该更利于打印 - 由 John Maddock 建议.
  • id 生成器的进一步改进.
  • 如果文档末尾有小节未关闭, 则在生成的标记中关闭它们.
  • 尝试在代码块的开头和结尾更好地处理空白.
  • 处理紧跟锚点之后的列表.
  • 使水平线后跟多行注释的情况更合理一些.
  • 更好地支持 docinfo 中的空 id 和空标题.
  • 修复 SVG 处理中的一些轻微回归.
  • 更好地处理无效的命令行宏.
  • 自动构建 quickbook 时, 构建 release 版本.
  • 1.6 的许多更改:
    • 将模板的作用范围限定在包含它们的文件内.
    • 支持导入模板和宏.
    • 从源文件包含顶层 quickbook 块.
    • 在被包含的 quickbook 文件中使用 doc info 块.
    • 更好地处理同名宏.
    • block 元素.
    • 更好地处理重要标点 (例如转义、方括号).
    • 支持在链接、锚点、图像、include 等中使用转义.
    • 改进的表格标题语法.
    • 嵌套在列表中的段落.
    • 新的 docinfo 属性:
      • compatibility-mode 使升级文档成为可能而不破坏 id.
      • xmlbase 用于转义的 xi:include.
    • 允许某些 docinfo 属性在 doc info 块之前使用, 或在没有 doc info 块时使用 (quickbook, compatibility-mode, source-mode)
    • 只为图像添加显式 alt 文本.
    • 不要把 '行内' 代码块放在段落内.

版本 1.5.8 - Boost 1.50

  • 使用 --output-deps 将依赖写入文件 (#6691).
  • 修复列表中小节标签的处理.
  • 修复列表中缩进的代码块.
  • 修复语法高亮器对 UTF-8 码点的处理. 此前把每个字节当作一个字符. 仍然不能处理组合码点.
  • 内部更改:
    • 大量的结构调整.
    • 停止使用 'v3' filesystem 路径与命名空间, 它现在是默认版本.
    • 移除别扭的侵入式引用计数实现, 避免了一个 gcc 内部编译器错误 (#6794), 但这也是一种更简洁的实现.
  • 1.6 的更改:
    • 更好地处理链接值中的方括号.
    • 改进对 include 路径中转义字符的处理.
  • 开始开发 1.7:
    • 单个实体的源模式.
    • 代码块中的标注.
    • docinfo 块中的转义 docbook.
    • 开始实现从链接值调用模板.

版本 1.5.9 - Boost 1.54

  • 当代码块以制表符和空格混合缩进时, 将缩进转换为空格.
  • 在 C++ 语法高亮器中, 修复 # 的语法高亮, 使其用于行首的预处理语句, 并在其他位置作为 'special' 字符 (#8510, #8511)
  • 向语法高亮器添加 C++11 关键字 (#8541).
  • 用于 --output-deps 格式化的隐藏选项. 并非真正供公众使用
  • 暂时还没有.
  • 1.6 的更改:
    • 更好的模板实参解析, 使其能理解诸如转义标记之类的内容.
    • 支持在 doc info 块中使用宏.
  • 内部更改:
    • 转换为使用 boost::string_ref.
    • 清理 source map 实现 (用于在模板和代码片段等中获取错误消息的正确位置).

版本 1.6.0 - Boost 1.55

  • 将列表中的嵌套块从 1.6 中移除, 移至 1.7. (不过仍然可以在列表中嵌套块元素).
  • 嵌套块元素之后不再中断列表.
  • 写入依赖文件时检查错误.
  • 改进的列表标记.
  • 使以标点标识符转义模板成为非法. 以字母数字标识符转义模板仍然没问题.
  • 修复文件开头代码块的检测.
  • 对 change_log.qbk 宏的内容进行 XML 编码.
  • 1.7 的更改:
    • 在错误的上下文中使用元素将产生错误.
    • 若短语元素的主体无法解析则报错.
    • 嵌套块中的列表标记.
    • 允许在短语模板中使用块元素.
    • 在短语模板中放入段落分隔 (即空行) 将成为错误.
  • 内部更改:
    • 清理 id 管理器实现.

版本 1.6.1

  • 更好的链接 URI 编码.
  • 对属性值的额外验证.
  • 1.7 的更改:
    • 改进的源模式标记:
      • 适用于列表和段落.
      • 如果源模式在被标记元素内发生更改, 该更改现在会在元素之后持续生效.
      • 被标记的小节现在会对整个小节使用该源模式.
    • 从 anchor、role 和 include 元素调用模板.
    • 对在属性值中调用的模板更严格地处理.
    • glob 支持.

版本 1.6.2 - Boost 1.61

  • 为 xinclude 生成更好的文件 URL.

版本 1.6.3 - Boost 1.64

  • 改进了某些错误消息.
  • 修复 --no-self-linked-headers 选项.
  • 在帮助文本中隐藏 'debug' 命令行选项.
  • 更改测试与构建设置以支持持续集成.
  • 修复无实参调用模板时的崩溃. 仅影响 quickbook 版本低于 1.5 的文件.

版本 1.6.4 - Boost 1.65

  • 对所有语言版本的更改:
    • endsect 现在可以拥有 id, 如果它与当前小节不匹配则报错.
  • 1.7 的更改:
    • 现在可以在宏未定义时写出条件内容, 使用 [?!macro_name content].
  • 支持使用 --strict 参数进行严格解析. 这仍在开发中, 因此可能会添加新的错误.
  • --no-output 命令行参数, 用于处理 quickbook 文档但不实际生成任何文件.

版本 1.7.0 - Boost 1.66

  • 最后一个能用 C++03 编译的版本.
  • 对某些警告与错误消息的小幅改进.
  • 不再规范化依赖列表中的路径.
  • 修复 xmlbase 与现有 xinclude 基目录相同的情况.

版本 1.7.1 - Boost 1.67

  • 现在使用 C++11, 不再用 C++03 编译器测试.
  • 修复使用新版 Spirit 解析转义 docbook 的问题.
  • 使用 clang-format 重新格式化代码.

版本 1.7.2 - Boost 1.68

  • 更多使用 C++11 特性.

  • 一些基本的 HTML 直接生成 (即不使用 BoostBook). 在命令行使用 --output-format html 生成分块 HTML, 使用 --output-format onehtml 生成单个 HTML 页面.

    使用 --boost-root path 选项传入 boost 发行版的根路径也很有用. 或者在 boost 之外使用时, 用 --css-path 和 --graphics-path 选项.

    虽然这尚未达到生产可用, 但对快速预览 quickbook 文档的更改可能有用, 尤其是在你没有配置 boostbook 的情况下.
