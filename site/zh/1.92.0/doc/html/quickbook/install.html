安装与配置

Mac OS X
Windows 2000, XP, 2003, Vista, 7
Debian, Ubuntu

本节提供在几种操作系统下安装与配置 BoostBook 和 Quickbook 的一些指南. 安装之前, 你需要一份 boost 的本地副本, 并安装随附的 bjam 版本 (或更高版本).

Mac OS X

使用 macports 的 Mac OS X
Mac OS X Snow Leopard (或更高)

在 OS X 上安装的最简单方法是使用 macports. 如果你不想使用 macports 且使用的是 Snow Leopard 或更高版本, 可参见后文的说明. 更早版本的 OS X 需要使用 macports 之类的工具安装 xsltproc

使用 macports 的 Mac OS X

首先安装 libxslt, docbook-xsl 和 docbook-xml-4.2 软件包:

sudo port install libxslt docbook-xsl docbook-xml-4.2

接下来, 我们需要配置 Boost Build 来编译 BoostBook 文件. 将以下内容添加到你的 user-config.jam 文件中, 它应位于你的主目录. 如果没有, 就创建一个包含此文本的文件. 关于设置 user-config.jam 的更多信息, 参见 Boost Build 文档.

using xsltproc
    : /opt/local/bin/xsltproc
    ;

using boostbook
    : /opt/local/share/xsl/docbook-xsl/
    : /opt/local/share/xml/docbook/4.2
    ;

以上步骤足以获得可用的 BoostBook 设置. Quickbook 会在需要时自动构建. 如果你想避免这些重新构建:

  1. 进入 Quickbook 的源码目录 (BOOST_ROOT/tools/quickbook).
  2. 执行 bjam 来构建该工具.
  3. 把生成的 quickbook 二进制文件 (位于 BOOST_ROOT/dist/bin) 复制到一个安全的地方. 传统位置是 /usr/local/bin

  4. 将以下内容添加到你的 user-config.jam 文件中, 使用 quickbook 可执行文件的完整路径:

    using quickbook
    : /usr/local/bin/quickbook
    ;

如果你需要构建使用 Doxygen 的文档, 还需要安装它:

sudo port install doxygen

然后在你的 user-config.jam 中添加:

using doxygen ;

或者, 你也可以从官方 doxygen dmg 安装. 这在 下一节的末尾.

Mac OS X Snow Leopard (或更高)

本节由 Julio M. Merino Vidal 贡献

下文假定你想把所有必要的工具安装到系统级位置, 使机器上的任何用户都能访问它们. 因此, 所有文件都将放在 /usr/local 层级中. 如果你不想这样, 可选择其他前缀, 例如 ~/Applications, 以进行单用户安装.

Snow Leopard 预装了 xsltproc 及所有相关库, 因此无需采取额外步骤来设置它们. 未来的版本很可能也会包含它们, 但这些说明可能不适用于更早的版本.

开始之前:

  1. 下载 Docbook XML 4.2 并解压到 /usr/local/share/xml/docbook/4.2 内.
  2. 下载最新的 Docbook XSL 版本并解压. 注意要下载正确的文件, 有时 'looking for the latest version' 链接会指向另一个文件. 文件名的形式应为 docbook-xsl-1.nn.n.tar.bz2, 没有诸如 -ns.tar.bz2 或 -doc.tar.bz2 之类的后缀. 将结果放入 /usr/local/share/xsl/docbook

  3. 将以下内容添加到你的 user-config.jam 文件中, 它应位于你的主目录 (/Users/<your_username>) 中. 你必须已经在某处拥有它, 否则你无法构建 Boost (即缺少工具配置).

    using xsltproc ;

using boostbook
    : "/usr/local/share/xsl/docbook"
    : "/usr/local/share/xml/docbook/4.2"
    ;

以上步骤足以获得可用的 BoostBook 设置. Quickbook 会在需要时自动构建. 如果你想避免这些重新构建, 并改为安装系统级的 Quickbook:

  1. 进入 Quickbook 的源码目录 (BOOST_ROOT/tools/quickbook).
  2. 执行 bjam 来构建该工具.
  3. 把生成的 quickbook 二进制文件 (位于 BOOST_ROOT/dist/bin) 复制到一个安全的地方. 按照前面的例子, 你可以把它安装到: /usr/local/bin

  4. 将以下内容添加到你的 user-config.jam 文件中:

    using quickbook
    : "/usr/local/bin/quickbook" ;
    ;

此外, 如果你需要构建使用 Doxygen 的文档, 那么也需要安装它:

  1. 前往 下载区 获取 Mac OS X 的磁盘映像 (dmg 文件).
  2. 打开磁盘映像, 并将 Doxygen 应用程序拖到你的 Applications 文件夹中进行安装.

  3. 将以下内容添加到你的 user-config.jam 文件中:

    using doxygen
    : /Applications/Doxygen.app/Contents/Resources/doxygen
    ;

Windows 2000、XP、2003、Vista、7

本节由 Julio M. Merino Vidal 贡献

以下说明适用于任何基于 Windows 2000 的 Windows 系统, 包括 Windows XP、Windows 2003 Server、Windows Vista 和 Windows 7. 下文所示路径取自一台 Windows Vista 机器; 如果你运行的是更早的版本, 则需要调整它们以匹配你的系统.

  1. 首先, 你需要有 xsltproc 的 Windows 版副本. 获取该工具的方法有很多, 但为了简单起见, 请使用 Igor Zlatkovic 制作的 二进制包 . 至少, 你需要下载以下软件包: iconv, zlib, libxml2 和 libxslt
  2. 将所有这些包解压到同一目录, 使层级结构中出现唯一的 bin, include 和 lib 目录. 这些说明使用 C:\Users\example\Documents\boost\xml 作为所有文件的根.
  3. 在命令行中, 进入 bin 目录并运行 xsltproc.exe 以确保它能工作. 屏幕上应显示用法信息.
  4. 下载 Docbook XML 4.2 并解压到上面使用的同一目录. 即: C:\Users\example\Documents\boost\xml\docbook-xml
  5. 下载最新的 Docbook XSL 版本并解压, 同样解压到之前使用的目录. 注意要下载正确的文件, 有时 'looking for the latest version' 链接会指向另一个文件. 文件名的形式应为 docbook-xsl-1.nn.n.tar.bz2, 没有诸如 -ns.tar.bz2 或 -doc.tar.bz2 之类的后缀. 为方便起见, 将解压时创建的目录重命名为 docbook-xsl (跳过版本名): C:\Users\example\Documents\boost\xml\docbook-xsl

  6. 将以下内容添加到你的 user-config.jam 文件中, 它应位于你的主目录 (%HOMEDRIVE%%HOMEPATH%) 中. 你必须已经在某处拥有它, 否则你无法构建 Boost (即缺少工具配置).

    using xsltproc
    : "C:/Users/example/Documents/boost/xml/bin/xsltproc.exe"
    ;

using boostbook
    : "C:/Users/example/Documents/boost/xml/docbook-xsl"
    : "C:/Users/example/Documents/boost/xml/docbook-xml"
    ;

以上步骤足以获得可用的 BoostBook 设置. Quickbook 会在需要时自动构建. 如果你想避免这些重新构建:

  1. 进入 Quickbook 的源码目录 (BOOST_ROOT\tools\quickbook).
  2. 执行 bjam 来构建该工具.
  3. 把生成的 quickbook.exe 二进制文件 (位于 BOOST_ROOT\dist\bin) 复制到一个安全的地方. 按照前面的例子, 你可以把它安装到: C:\Users\example\Documents\boost\xml\bin

  4. 将以下内容添加到你的 user-config.jam 文件中:

    using quickbook
    : "C:/Users/example/Documents/boost/xml/bin/quickbook.exe"
    ;

Debian、Ubuntu

以下说明适用于 Debian 及其衍生版. 它们基于 Ubuntu Edgy 安装, 但应当也适用于其他基于 Debian 的系统. 它们假定你已经为你的 boost 副本安装了适当版本的 bjam.

首先安装 xsltproc, docbook-xsl 和 docbook-xml 软件包. 例如, 使用 apt-get:

sudo apt-get install xsltproc docbook-xsl docbook-xml

如果你打算构建 boost 的文档, 还需要安装 doxygen 软件包.

接下来, 我们需要配置 Boost Build 来编译 BoostBook 文件. 将以下内容添加到你的 user-config.jam 文件中, 它应位于你的主目录. 如果没有, 就创建一个包含此文本的文件. 关于设置 user-config.jam 的更多信息, 参见 Boost Build 文档.

using xsltproc ;

using boostbook
    : /usr/share/xml/docbook/stylesheet/nwalsh
    : /usr/share/xml/docbook/schema/dtd/4.2
    ;

# Remove this line if you're not using doxygen
using doxygen ;

以上步骤足以获得可用的 BoostBook 设置. Quickbook 会在需要时自动构建. 如果你想避免这些重新构建:

  1. 进入 Quickbook 的源码目录 (BOOST_ROOT/tools/quickbook).
  2. 执行 bjam 来构建该工具.
  3. 把生成的 quickbook 二进制文件 (位于 BOOST_ROOT/dist/bin) 复制到一个安全的地方. 传统位置是 /usr/local/bin

  4. 将以下内容添加到你的 user-config.jam 文件中, 使用 quickbook 可执行文件的完整路径:

    using quickbook
    : /usr/local/bin/quickbook
    ;
