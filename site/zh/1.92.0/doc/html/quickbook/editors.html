Scintilla 文本编辑器

本节由 Dean Michael Berris 贡献

Scintilla 文本编辑器 (SciTE) 是一个用于 Win32 和 X 的免费源代码编辑器. 它使用 SCIntilla 源代码编辑组件.

提示

SciTE 可从 http://www.scintilla.org/SciTE.html 下载

编辑 quickbook 文件时, 你可以使用以下设置来高亮 quickbook 标签.

qbk=*.qbk
lexer.*.qbk=props
use.tabs.$(qbk)=0
tab.size.$(qbk)=4
indent.size.$(qbk)=4
style.props.32=$(font.base)
comment.stream.start.props=[/
comment.stream.end.props=]
comment.box.start.props=[/
comment.box.middle.props=
comment.box.end.props=]
注释

感谢 Rene Rivera 提供上述 SciTE 设置.

boost::hs::quickbook

boost::hs::quickbook 是一个设计用于配合 Katepart 工作的语法高亮. 它可用于 KWrite、Kate、Konqueror 和 KDevelop, 并支持 Quickbook 1.4 的全部构造, 包括表格、列表、模板和宏.

代码折叠

boost::hs 远不止简单的着色. 你可以让编辑器做的一件有用的事是标记区域. 它们显示为一条灰色细线, 每个区域都可以独立折叠或展开.

自动注释 / 取消注释

另一个重要特性是可以自动注释或取消注释某段代码 (工具 - 注释). 已注释的区域只需在光标位于其中时调用 取消注释 命令即可取消注释.

关于 boost::hs

boost::hs::quickbook 是 boost::hs 的一个组件, boost::hs 是针对 C++、doxygen、Boost.Build jamfile 和 QuickBook 的语法高亮. boost::hs 有自己的页面 这里.

注释

boost::hs::cpp 支持 QuickBook 代码导入注释样式!

安装 boost::hs

目前正在进行将 boost::hs 推向 KatePart 项目上游的工作. 几个月后 KDE 或许会原生支持 Quickbook! 眼下你必须下载并安装它.

你可以从 这里 下载 boost::hs.

注释

boost::hs::quickbook 和 boost::hs::cpp 的副本可在 boost/tools/quickbook/extra/katepart 中获取.

要将它安装好, 你必须把 katepart/syntax/ 文件夹中的内容复制到你机器上相应的 katepart 语法文件夹. 通常该文件夹位于 /usr/share/apps/katepart/syntax . 随附有一个名为 install.sh 的 bash 脚本, 可将文件复制到该文件夹.
