常见问题 (FAQ)

我可以将 QuickBook 用于非 Boost 文档吗?

只需稍加额外工作, QuickBook 就可用于非 Boost 文档.

本常见问题由 Michael Marcin 贡献

使用 BoostBook 构建 HTML 文档时, 文件中会加入一个 Boost C++ Libraries 头部. 当使用 QuickBook 为 Boost 之外的项目编写文档时, 这并不可取. 这一行为可以在 BoostBook 层面通过指定一些 XSLT 选项来覆盖. 使用 Boost Build 版本 2 (BBv2) 时, 可以通过向 BoostBook 目标声明添加参数来实现.

例如:

using quickbook ;

xml my_doc : my_doc.qbk ;

boostbook standalone
    :
        my_doc
    :
        <xsl:param>boost.image.src=images/my_project_logo.png
        <xsl:param>boost.image.alt="\"My Project\""
        <xsl:param>boost.image.w=100
        <xsl:param>boost.image.h=50
        <xsl:param>nav.layout=none
    ;

有没有把 BoostBook 文档转换为 QuickBook 的简便方法?

有一个样式表可以把 Boostbook 生成的 HTML 显示为 quickbook 源码, 见 http://svn.boost.org/trac/boost/wiki/QuickbookSourceStylesheetProject, 这样把 BoostBook 转换为 QuickBook (依我看它编辑和维护起来容易得多) 就只是剪切粘贴的工作了.
