命令行用法

命令行选项

QuickBook 通常由构建工具运行, 但如果你想手动运行它, 用起来非常简单. 基本用法是:

quickbook filename.qbk

如果成功, 将打印出类似如下内容:

Generating Output File: filename.xml

命令行选项

--help

打印 quickbook 所支持选项的摘要, 然后退出.

--version

打印 quickbook 可执行文件的版本, 然后退出.

--no-pretty-print

禁用 XML 美化打印. 通常 quickbook 会将输出送入一个生成一致 XML 缩进的后处理器, 此标志禁用该功能.

--strict

严格模式. 为可能的问题添加额外错误, 包括未关闭的小节, 以及不匹配任何标签或模板的方括号.

--no-self-linked-headers

默认情况下, quickbook 生成的 docbook 标题会链接到自身, 这样在网页浏览器中可以通过右键点击标题并复制链接来获得该标题的链接. 这需要生成稍微奇怪的 boostbook 标记, 因此此标志禁用该特性并生成普通标题.

--indent

美化打印器中使用的缩进.

--linewidth

美化打印器中使用的行宽.

--input-file path

用于显式指定该实参是输入文件. 通常不必使用, 因为你可以直接写:

quickbook filename.qbk

. 但如果你愿意, 也可以写:

quickbook --input-file filename.qbk

. 如果文件路径可能与选项混淆, 这会很有用, 例如使用名为 --filename.qbk 的文件:

quickbook --input-file --filename.qbk

只能指定一个输入文件.

--output-file path

显式指定要生成的文件的路径. 默认情况下, 就是输入文件名并把扩展名替换为 .xml.

--no-output

不写出 boostbook 文件. 这对检查文档没有语法错误, 或者与 --output-deps 一起运行很有用. 如果同时定义了 --output-file-path, 则会覆盖此项.

--output-deps path

将 quickbook 读入的所有文件的完整路径写到给定路径. 这对构建工具很有用, 使其能判断何时需要重新构建文档.

--ms-errors

使用 Microsoft Visual Studio 风格的错误与警告消息格式, 使 Visual Studio IDE 能够识别它们.

--include-path path, -I path

将给定路径添加到 include 路径, 可多次指定.

--define macro, -D macro

定义一个 quickbook 宏. 它可以带值:

quickbook -D __foo__=bar

或者你也可以只定义一个空宏:

quickbook -D __foo__

这对 条件生成 很有用.

--image-location path

图像元素相对的路径. 这只用于读取 SVG 细节.
