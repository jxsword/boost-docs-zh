头文件 <boost/proto/context/callable.hpp>

proto::context::callable_context<> 的定义——它是一个用于 proto::eval() 的求值上下文, 把每个节点展开并以表达式的组成部分调用派生上下文类型. 若派生上下文没有处理该节点的重载, 则回退到某个其他上下文.

namespace boost {
  namespace proto {
    namespace context {
      template<typename Expr, typename Context> struct callable_eval;
      template<typename Context, 
               typename DefaultCtx = proto::context::default_context> 
        struct callable_context;
    }
  }
}
