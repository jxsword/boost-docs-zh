类 cartesian_communicator

boost::mpi::cartesian_communicator — 具有笛卡尔拓扑的 MPI 通信器.

概要

// In header: <boost/mpi/cartesian_communicator.hpp>


class cartesian_communicator : public boost::mpi::communicator {
public:

  // public member functions
  cartesian_communicator(const MPI_Comm &, comm_create_kind);
  cartesian_communicator(const communicator &, const cartesian_topology &, 
                         bool = false);
  cartesian_communicator(const cartesian_communicator &, 
                         const std::vector< int > &);
  int ndims() const;
  int rank(const std::vector< int > &) const;
  std::pair< int, int > shifted_ranks(int, int) const;
  std::vector< int > coordinates(int) const;
  void topology(cartesian_topology &, std::vector< int > &) const;
  cartesian_topology topology() const;
  int rank() const;
};

说明

cartesian_communicator 是一种拓扑以网格形式表达的通信器. 笛卡尔通信器具有与 (内) 通信器相同的功能, 但还允许查询进程之间的关系以及网格的属性.

cartesian_communicator 公有成员函数

  1. cartesian_communicator(const MPI_Comm & comm, comm_create_kind kind);

    基于具有笛卡尔拓扑的 MPI 通信器 comm 构建新的 Boost.MPI 笛卡尔通信器.

    comm 可以是任何有效的 MPI 通信器. 如果 comm 是 MPI_COMM_NULL, 则会创建一个空通信器 (不能用于通信), 且 kind 参数被忽略. 否则, kind 参数决定 Boost.MPI 通信器与 comm: 的关联方式

    • 如果 kind 是 comm_duplicate, 则复制 (duplicate) comm 以创建新的通信器. 当 Boost.MPI 通信器 (及其所有副本) 被销毁时, 该新通信器将被释放. 仅当底层 MPI 实现支持 MPI 2.0 时才允许此选项; MPI 1.x 不提供互联通信器的复制.

    • 如果 kind 是 comm_take_ownership, 则取得 comm 的所有权. 当所有 Boost.MPI 通信器离开作用域时, 它将被自动释放.

    • 如果 kind 是 comm_attach, 则此 Boost.MPI 通信器将引用现有的 MPI 通信器 comm, 但当 Boost.MPI 通信器离开作用域时不会释放 comm. 仅当通信器由用户管理时才应使用此选项.

  2. cartesian_communicator(const communicator & comm, 
                       const cartesian_topology & dims, bool reorder = false);

    创建一个新的通信器, 其拓扑由给定的笛卡尔结构描述. 笛卡尔结构中顶点的索引将被假定为通信器内进程的秩. 笛卡尔结构中的顶点数可以少于通信器中的进程数; 在这种情况下, 得到的通信器将是一个 NULL 通信器.

    参数:

    comm

    新的笛卡尔通信器将基于的通信器.

    dims

    新通信器的笛卡尔维度. size 指示维度的数量. 某些维度可以设为零, 此时相应的维度值由系统决定.

    reorder

    是否允许 MPI 重新排列返回的通信器中的进程秩, 以更好地优化通信. 如果为 false, 则返回的通信器中每个进程的秩将精确匹配该进程在原通信器中的秩.

    		 
  3. cartesian_communicator(const cartesian_communicator & comm, 
                       const std::vector< int > & keep);

    创建一个新的笛卡尔通信器, 其拓扑是现有笛卡尔通信器拓扑的子集.

    参数:

    comm

    原通信器.

    keep

    一个数组, 包含要从现有通信器保留的维度.

    		 
  4. int ndims() const;

    获取底层拓扑的维度数量.

  5. int rank(const std::vector< int > & coords) const;

    返回给定坐标处进程的秩.

    参数:

    coords

    坐标. 其大小必须与通信器的拓扑相匹配.

    		 
  6. std::pair< int, int > shifted_ranks(int dim, int disp) const;

    返回通过移位得到的源进程和目标进程的秩.

    参数:

    dim

    发生移位的维度. 0 <= dim <= ndim().

    disp

    移位偏移量, 可为正 (向上) 或负 (向下).

    		 
  7. std::vector< int > coordinates(int rk) const;

    提供给定秩的进程的坐标.

    参数:

    rk

    此通信器中的秩.

    返回:

    坐标.

    		 
  8. void topology(cartesian_topology & dims, std::vector< int > & coords) const;

    获取此进程在网格中的拓扑和坐标.

  9. cartesian_topology topology() const;

    获取网格的拓扑.

  10. int rank() const;
    确定正在执行的进程在通信器中的秩.

    此例程等价于 MPI_Comm_rank.

    返回:

    进程在通信器中的秩, 其值位于 [0, size()) 内
