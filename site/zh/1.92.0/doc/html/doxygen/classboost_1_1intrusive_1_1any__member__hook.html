类模板 any_member_hook

boost::intrusive::any_member_hook

概要

// In header: <boost/intrusive/any_hook.hpp>

template<class ... Options> 
class any_member_hook : public make_any_member_hook::type {
public:

  // public member functions
  any_member_hook() noexcept;
  any_member_hook(const any_member_hook &) noexcept;
  any_member_hook & operator=(const any_member_hook &) noexcept;
  ~any_member_hook();
  bool is_linked() const noexcept;
};

说明

把此钩子存储在要插入侵入式容器的类中.

该钩子接受以下选项: void_pointer<> 和 link_mode<>.

link_mode<> 将指定钩子的链接模式 (normal_link 或 safe_link).

void_pointer<> 是钩子内部及配置为使用此钩子的容器将要使用的指针类型.

any_member_hook 公有成员函数

  1. any_member_hook() noexcept;

    效果: 若 link_mode 为 或 safe_link, 则把节点初始化为未链接状态.

    抛出: 无.

  2. any_member_hook(const any_member_hook &) noexcept;

    效果: 若 link_mode 为 或 safe_link, 则把节点初始化为未链接状态. 实参被忽略.

    抛出: 无.

    设计理由: 提供复制构造函数使使用该钩子的类符合 STL 规范, 而无需用户做额外工作. swap 可用于模拟移动语义.

  3. any_member_hook & operator=(const any_member_hook &) noexcept;

    效果: 空函数. 实参被忽略.

    抛出: 无.

    设计理由: 提供赋值运算符使使用该钩子的类符合 STL 规范, 而无需用户做额外工作. swap 可用于模拟移动语义.

  4. ~any_member_hook();

    效果: 若 link_mode 为 normal_link, 析构函数不做任何事 (即不生成代码). 若 link_mode 为 safe_link 且对象存储在容器中, 将触发断言.

    抛出: 无.

  5. bool is_linked() const noexcept;

    前置条件: link_mode 必须为 safe_link.

    返回: 若节点属于某个容器则为 true, 否则为 false. 此函数可用于测试 container::iterator_to 是否会返回有效的迭代器.

    复杂度: 常数
