说明

类模板 slist 是一种侵入式容器, 封装一个单向链表. 可以用这种列表从应用程序中榨取最后一点性能. 遗憾的是, 微小的收益伴随着一些重大缺陷. 许多成员函数无法像标准容器那样高效实现. 为克服这一限制, 不得不引入一些语义相当不寻常的其他成员函数.

模板参数 T 是容器要管理的类型. 用户可以指定附加选项; 若未提供选项, 则使用默认选项.

容器支持以下选项: base_hook<>/member_hook<>/value_traits<>、constant_time_size<>、size_type<>、linear<> 和 cache_last<>.

slist 的迭代器是前向迭代器. slist 提供一个名为 "previous" 的静态函数来计算给定迭代器的前一个迭代器. 此函数具有线性复杂度. 为提高可用性 (尤其是与 '*_after' 函数配合时), 定义了 ++end() == begin() 和 previous(begin()) == end(). 还定义了一个新的特殊函数 "before_begin()", 它返回指向列表开头之前一个位置的迭代器: ++before_begin() == begin()

slist 公有成员函数

  1. slist();

    效果: 构造一个空列表.

    复杂度: 常数

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况).

  2. explicit slist(const value_traits & v_traits);

    效果: 构造一个空列表.

    复杂度: 常数

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况).

  3. template<typename Iterator> 
  slist(Iterator b, Iterator e, 
        const value_traits & v_traits = value_traits());

    要求: 解引用迭代器必须产生 value_type 类型的左值.

    效果: 构造一个等于 [b ,e) 的列表.

    复杂度: 与 distance(b, e) 成线性关系. 不调用复制构造函数.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况).

  4. slist(slist && x);

    效果: 构造一个从另一容器移动资源的容器. 内部 value 特征被移动构造, 属于 x 的节点 (表示 "end" 的节点除外) 被链接到 *this.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 的移动构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 value 特征的移动构造函数抛出异常.

  5. slist & operator=(slist && x);

    效果: 等价于 swap

  6. ~slist();

    效果: 若是安全模式或 auto-unlink 值, 析构函数不做任何事 (即不生成代码). 否则它使所有元素脱离此容器. 此时列表中的对象不会被删除 (即不调用析构函数), 但根据 value_traits 模板参数, 钩子会被设置为默认值.

    复杂度: 若为安全模式或 auto-unlink 值, 则与列表中的元素数量成线性关系; 否则为常数.

  7. void clear() noexcept;

    效果: 擦除容器的所有元素.

    抛出: 无.

    复杂度: 若为安全模式或 auto-unlink 的 value_type, 则与列表中的元素数量成线性关系; 否则为常数时间.

    注释: 使被擦除元素的迭代器 (但非引用) 失效.

  8. template<typename Disposer> void clear_and_dispose(Disposer disposer) noexcept;

    要求: Disposer::operator()(pointer) 不应抛出异常.

    效果: 擦除容器的所有元素. 对被移除的元素调用 Disposer::operator()(pointer).

    抛出: 无.

    复杂度: 与列表中的元素数量成线性关系.

    注释: 使被擦除元素的迭代器失效.

  9. void push_front(reference value) noexcept;

  34. template<typename Cloner, typename Disposer> 
  void clone_from(const slist & src, Cloner cloner, Disposer disposer);

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(const_reference ) 从 src 克隆所有元素并插入到 *this 中.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常.
