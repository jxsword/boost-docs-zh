全局 _s

boost::xpressive::_s — 匹配空白字符.

概要

// In header: <boost/xpressive/regex_primitives.hpp>

unspecified _s;

说明

'_s' 匹配单个空白字符. 正则特征用于确定哪些字符是空白字符. 使用 ~_s 匹配非空白字符.

重要

_s 类似 perl 中的 \s. ~_s 类似 perl 中的 \S.
