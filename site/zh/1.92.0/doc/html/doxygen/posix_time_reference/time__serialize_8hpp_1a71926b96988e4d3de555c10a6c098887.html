函数模板 load_td

boost::serialization::load_td — 使用序列化库载入 posix_time::time_duration 对象的函数.

概要

// In header: <boost/date_time/posix_time/time_serialize.hpp>


template<typename TimeResTraitsSize, typename Archive> 
  void load_td(Archive & ar, posix_time::time_duration & td);

说明

time_duration 对象在序列化时分解为 4 部分: 类型为 time_duration 类中定义的 hour_type, min_type, sec_type 与 fractional_seconds_type
