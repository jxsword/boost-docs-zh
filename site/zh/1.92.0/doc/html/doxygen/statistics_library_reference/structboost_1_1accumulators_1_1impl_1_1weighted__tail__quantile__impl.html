boost::accumulators::impl::weighted_tail_quantile_impl — 基于加权样本次序统计量的尾分位数估计 (适用于左尾与右尾)

说明

基于加权样本次序统计量 、水平为 的尾分位数估计量 由 (左尾) 与 (右尾) 给出, 其中 \f[ \lambda = \inf\left\{ l \left| \frac{1}{\bar{w}_n}\sum_{i=1}^{l} w_i \geq \alpha \right. \right\} \f]

且 \f[ \rho = \sup\left\{ r \left| \frac{1}{\bar{w}_n}\sum_{i=r}^{n} w_i \geq (1 - \alpha) \right. \right\}, \f]

为样本数量, 为所有权重之和.
