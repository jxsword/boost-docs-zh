结构体模板 weighted_density_impl

boost::accumulators::impl::weighted_density_impl — 加权样本的直方图密度估计器.

概要

// In header: <boost/accumulators/statistics/weighted_density.hpp>

template<typename Sample, typename Weight> 
struct weighted_density_impl : public accumulator_base {
  // types
  typedef numeric::functional::fdiv< Weight, std::size_t >::result_type float_type;    
  typedef std::vector< std::pair< float_type, float_type > >            histogram_type;
  typedef std::vector< float_type >                                     array_type;    
  typedef iterator_range< typename histogram_type::iterator >           result_type;   

  // public member functions
  template<typename Args> weighted_density_impl(Args const &);
  template<typename Args> void operator()(Args const &);
  template<typename Args> result_type result(Args const &) const;
  template<typename Archive> void serialize(Archive &, const unsigned int);
};

说明

直方图密度估计器返回样本分布的直方图. 各 bin 的位置与大小用可指定数量的缓存样本 (cache_size) 确定. 缓存样本的最小值与最大值之间的范围被划分为若干等宽的 bin (num_bins). 此外, 还会添加一个下溢 bin 和一个上溢 bin, 用于捕获未来的下溢与上溢样本. bin 一旦确定, 缓存样本及后续所有样本都会被加入正确的 bin. 最后返回一个 std::pair 范围, 每个 pair 含有 bin 的位置 (下界) 与权重之和 (用所有权重之和归一化) .
