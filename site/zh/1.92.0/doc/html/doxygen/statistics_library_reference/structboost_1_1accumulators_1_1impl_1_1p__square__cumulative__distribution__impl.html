结构体模板 p_square_cumulative_distribution_impl

boost::accumulators::impl::p_square_cumulative_distribution_impl — 使用 算法计算累积分布的直方图.

概要

// In header: <boost/accumulators/statistics/p_square_cumul_dist.hpp>

template<typename Sample> 
struct p_square_cumulative_distribution_impl : public accumulator_base {
  // types
  typedef numeric::functional::fdiv< Sample, std::size_t >::result_type float_type;    
  typedef std::vector< float_type >                                     array_type;    
  typedef std::vector< std::pair< float_type, float_type > >            histogram_type;
  typedef iterator_range< typename histogram_type::iterator >           result_type;   

  // public member functions
  template<typename Args> p_square_cumulative_distribution_impl(Args const &);
  template<typename Args> void operator()(Args const &);
  template<typename Args> result_type result(Args const &) const;
  template<typename Archive> void serialize(Archive &, const unsigned int);
};

说明

基于 算法, 在不存储样本的情况下动态计算样本累积分布的直方图. 返回的直方图具有可指定数量 (num_cells) 的等概率 (而非等宽) 单元格.

更多细节参见

R. Jain and I. Chlamtac, 无需存储观测值即可动态计算分位数与直方图的 P^2 算法, Communications of the ACM, Volume 28 (October), Number 10, 1985, p. 1076-1085.
