结构体模板 extended_p_square_impl

boost::accumulators::impl::extended_p_square_impl — 使用扩展 算法的多分位数估计.

概要

// In header: <boost/accumulators/statistics/extended_p_square.hpp>

template<typename Sample> 
struct extended_p_square_impl : public accumulator_base {
  // types
  typedef numeric::functional::fdiv< Sample, std::size_t >::result_type float_type; 
  typedef std::vector< float_type >                                     array_type; 
  typedef unspecified                                                   result_type;

  // public member functions
  template<typename Args> extended_p_square_impl(Args const &);
  template<typename Args> void operator()(Args const &);
  result_type result(dont_care) const;
  template<typename Archive> void serialize(Archive &, const unsigned int);
};

说明

用于在不存储样本的情况下估计若干分位数的扩展 算法. 设要估计 个分位数 . 该算法不存储完整的样本累积分布, 而是只维护 个主标记与 个中间标记, 其位置随每个样本更新, 其高度按需用分段抛物线公式调整. 这些中心标记的高度就是分位数的当前估计, 以迭代器范围返回.

更多细节参见

K. E. E. Raatikainen, Simultaneous estimation of several quantiles, Simulation, Volume 49, Number 4 (October), 1986, p. 159-164.

扩展 算法推广了 算法, 出自

R. Jain and I. Chlamtac, 无需存储观测值即可动态计算分位数与直方图的 P^2 算法, Communications of the ACM, Volume 28 (October), Number 10, 1985, p. 1076-1085.
