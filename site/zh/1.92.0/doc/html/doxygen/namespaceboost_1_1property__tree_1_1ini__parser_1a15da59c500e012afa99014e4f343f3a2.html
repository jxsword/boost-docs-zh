函数模板 write_ini

boost::property_tree::ini_parser::write_ini

概要

// In header: <boost/property_tree/ini_parser.hpp>


template<typename Ptree> 
  void write_ini(std::basic_ostream< typename Ptree::key_type::value_type > & stream, 
                 const Ptree & pt, int flags = 0);

说明

把属性树转换为 INI 并写入给定输出流.

参数:

stream

属性树的 INI 表示要写入的流.

pt

要转换为 INI 并输出的属性树.

flags

写入 INI 文件时使用的标志. 目前不支持任何标志.

要求:

pt 的根不能有数据.

要求:

pt 的键不能同时拥有数据与子节点.

要求:

pt 的深度不能超过两层.

要求:

pt 的任何给定层级上都不能有重复键.

抛出:

 ini_parser_error 在把属性树转换为 INI 或写入输出流出错时.
