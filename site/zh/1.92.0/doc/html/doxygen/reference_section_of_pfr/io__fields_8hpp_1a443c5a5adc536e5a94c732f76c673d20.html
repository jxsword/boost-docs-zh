函数模板 io_fields

boost::pfr::io_fields

概要

// In header: <boost/pfr/io_fields.hpp>


template<typename T> BOOST_PFR_BEGIN_MODULE_EXPORT auto io_fields(T && value);

说明

IO 操纵器, 逐字段读/写 简单聚合 value.

示例: 

struct my_struct {
    int i;
    short s;
};

std::ostream& operator<<(std::ostream& os, const my_struct& x) {
    return os << boost::pfr::io_fields(x);  // Equivalent to: os << "{ " << x.i << " ," <<  x.s << " }"
}

std::istream& operator>>(std::istream& is, my_struct& x) {
    return is >> boost::pfr::io_fields(x);  // Equivalent to: is >> "{ " >> x.i >> " ," >>  x.s >> " }"
}

boost::pfr::io_fields 的输入与输出流运算符是对称的, 即若每个字段的流运算符对称, 把值写出再读回就能得到原值.

参见 : '聚合的自定义打印' 介绍了如何实现自定义格式的操纵器.
