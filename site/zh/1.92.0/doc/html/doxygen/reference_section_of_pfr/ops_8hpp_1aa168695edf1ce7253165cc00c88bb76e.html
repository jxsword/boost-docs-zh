函数模板 lt

boost::pfr::lt — 使用 lhs 与 rhs 自身的比较与转换运算符进行小于比较; 若无可用运算符, 则返回 boost::pfr::lt_fields (lhs, rhs).

概要

// In header: <boost/pfr/ops.hpp>


template<typename T, typename U> unspecified lt(const T & lhs, const U & rhs);

说明

返回:

若 lhs 小于 rhs 则为 true, 否则为 false
