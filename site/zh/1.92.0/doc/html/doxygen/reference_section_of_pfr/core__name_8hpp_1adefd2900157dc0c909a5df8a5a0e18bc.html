函数模板 names_as_array

boost::pfr::names_as_array — 创建一个 std::array, 由 简单聚合T 的字段名构成.

概要

// In header: <boost/pfr/core_name.hpp>


template<typename T> 
  std::array< std::string_view, boost::pfr::tuple_size_v< T > > 
  names_as_array();

说明

示例: 

struct my_struct { int i, short s; };
std::array<std::string_view, 2> a = boost::pfr::names_as_array<my_struct>();
assert(a[0] == "i");
