函数模板 io

boost::pfr::io

概要

// In header: <boost/pfr/io.hpp>


template<typename T> BOOST_PFR_BEGIN_MODULE_EXPORT auto io(T && value);

说明

IO 操纵器, 使用 简单聚合 value 的 IO 流运算符对其进行读/写; 若运算符不可用, 则使用 boost::pfr::io_fields .

示例: 

struct my_struct { int i; short s; };
my_struct x;
std::stringstream ss;
ss << "{ 12, 13 }";
ss >> boost::pfr::io(x);
assert(x.i == 12);
assert(x.s == 13);

参见 : '聚合的自定义打印' 介绍了如何实现自定义格式的操纵器.
