类型定义 tuple_size

tuple_size

概要

// In header: <boost/pfr/tuple_size.hpp>


template<typename T> 
using tuple_size = unspecified;

说明

具有 static const 成员变量 value, 保存 T 的字段数量. 对满足 简单聚合 的任何 T 都有效.

示例: 

std::array<int, boost::pfr::tuple_size<my_structure>::value > a;
