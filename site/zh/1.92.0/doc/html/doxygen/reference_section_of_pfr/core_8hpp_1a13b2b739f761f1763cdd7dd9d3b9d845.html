类型定义 tuple_element

tuple_element — tuple_element 有一个成员 typedef type, 返回 简单聚合 T 中索引为 I 的字段的类型.

概要

// In header: <boost/pfr/core.hpp>


template<std::size_t I, typename T> 
using tuple_element = unspecified;

说明

示例: 

std::vector< boost::pfr::tuple_element<0, my_structure>::type > v;
