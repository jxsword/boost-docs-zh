类型 comm_create_kind

boost::mpi::comm_create_kind — 用于描述如何把 C 的 MPI_Comm 收入 Boost.MPI 通信器的枚举.

概要

// In header: <boost/mpi/communicator.hpp>



enum comm_create_kind { comm_duplicate, comm_take_ownership, comm_attach };

说明

此枚举的值决定 Boost.MPI 通信器在用 MPI 通信器构造时的行为. 选项如下:

  • comm_duplicate: 复制 MPI_Comm 通信器以创建新的通信器 (例如通过 MPI_Comm_dup). 当 Boost.MPI 通信器 (及其所有副本) 被销毁时, 这个新的 MPI_Comm 通信器将被自动释放.

  • comm_take_ownership: 取得通信器的所有权. 当所有 Boost.MPI 通信器离开作用域时, 它将被自动释放. 此选项不得与 MPI_COMM_WORLD 一起使用.

  • comm_attach: Boost.MPI 通信器将引用现有的 MPI 通信器, 但在 Boost.MPI 通信器离开作用域时不会释放它. 仅当通信器由用户或 MPI 库管理时 (例如 MPI_COMM_WORLD) 才应使用此选项.
