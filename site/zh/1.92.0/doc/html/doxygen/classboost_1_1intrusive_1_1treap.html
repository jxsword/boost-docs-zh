说明

类模板 treap 是一种侵入式树堆容器, 用于构造侵入式 set 和 multiset 容器. 仅当 key_compare 对象与 priority_compare 对象不抛出异常时, 不抛出保证才成立.

模板参数 T 是容器要管理的类型. 用户可以指定附加选项; 若未提供选项, 则使用默认选项.

容器支持以下选项: base_hook<>/member_hook<>/value_traits<>、constant_time_size<>、size_type<>、compare<>、priority<> 和 priority_of_value<>

  2. treap();

    效果: 构造一个空容器.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 value_compare/priority_compare 对象的复制构造函数抛出异常. 基本保证.

  4. template<typename Iterator> 
  treap(bool unique, Iterator b, Iterator e, 
        const key_compare & cmp = key_compare(), 
        const priority_compare & pcmp = priority_compare(), 
        const value_traits & v_traits = value_traits());

    要求: 解引用迭代器必须产生 value_type 类型的左值. cmp 必须是诱导严格弱序的比较函数.

    效果: 构造一个空容器并插入 [b, e) 中的元素.

    复杂度: 若 [b, e) 已按 comp 排序则为 N 的线性, 否则为 N * log N, 其中 N 是 first 与 last 之间的距离.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 key_compare/priority_compare 对象的复制构造函数/operator() 抛出异常. 基本保证.

  5. treap(treap && x);

    效果: 构造一个从另一容器移动资源的容器. 内部比较对象与 value 特征被移动构造, 属于 x 的节点 (表示 "end" 的节点除外) 被链接到 *this.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 的移动构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或比较对象的移动构造函数抛出异常.

  6. treap & operator=(treap && x);

    效果: 等价于 swap

  7. ~treap();

    复杂度: 与 *this 中包含的元素数成线性关系.

  35. template<typename Cloner, typename Disposer> 
  void clone_from(const treap & src, Cloner cloner, Disposer disposer);

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点等价的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(const_reference ) 从 src 克隆所有元素并插入到 *this 中. 从源容器复制谓词.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常或谓词复制赋值抛出异常. 基本保证.

  43. std::pair< iterator, bool > 
insert_unique_check(const key_type & key, const priority_type & prio, 
                    insert_commit_data & commit_data);

    效果: 使用用户提供的键 (而非值本身) 检查一个值是否可以插入容器.

    返回: 若存在等价值, 返回包含指向已存在值的迭代器和 false 的对组. 若该值可以插入, 返回的对组布尔成员为 true, 并填充 "commit_data", 该数据应与 "insert_commit" 函数一起使用.

  bounded_range(const KeyType & lower_key, const KeyType & upper_key, 
                KeyTypeKeyCompare comp, bool left_closed, bool right_closed) const;

    要求: lower_key 是一个值, 使得 *this 按 comp(nk, lower_key) 划分 (若 left_closed 为 true); 否则按 !comp(lower_key, nk) 划分.

    upper_key 是一个值, 使得 *this 按 !comp(upper_key, nk) 划分 (若 right_closed 为 true); 否则按 comp(nk, upper_key) 划分.

    upper_key 按 comp 不得先于 lower_key [comp(upper_key, lower_key) 应为 false]

    若 lower_key 等价于 upper_key [!comp(upper_key, lower_key) && !comp(lower_key, upper_key)], 则 ('left_closed' || 'right_closed') 必须为 false.

    效果: 返回满足以下条件的对组:

    first = lower_bound(lower_key, comp) 若 left_closed, 否则 upper_bound(lower_key, comp)

    second = upper_bound(upper_key, comp) 若 right_closed, 否则 lower_bound(upper_key, comp)

    复杂度: 对数.

    抛出: 若 comp 抛出异常.

    注释: 对 lower_key 和 upper_key 分别调用 upper_bound 与 lower_bound 可能不如此函数高效.

    注释: 实验性函数, 接口在后续版本中可能变更.

  91. pointer unlink_leftmost_without_rebalance() noexcept;

    效果: 从容器中解除最左节点的链接.

    复杂度: 平均复杂度为常数时间.

    抛出: 无.

    注释: 此函数会破坏容器, 此后容器只能用于更多的 unlink_leftmost_without_rebalance 调用. 此函数通常用于实现容器的逐步受控销毁.

  92. void replace_node(iterator replace_this, reference with_this) noexcept;

    要求: replace_this 必须是 *this 的有效迭代器, 且 with_this 不得插入任何容器中.

    效果: 用 with_this 替换 replace_this 在容器中的位置. 容器无需重新平衡.

    复杂度: 常数.

    抛出: 无.

    注释: 若按排序规则 with_this 与 *replace_this 不等价, 此函数将破坏容器排序不变式. 此函数比擦除再插入节点更快, 因为无需重新平衡或比较.

  93. void remove_node(reference value) noexcept;

    效果: 从容器中移除 "value".

    抛出: 无.

    复杂度: 对数时间.

    注释: 此静态函数只适用于具有无状态比较函子的非常数时间大小容器.

    若用户以常数时间大小容器或有状态比较函子调用此函数, 将产生编译错误.
