类模板 queue

boost::lockfree::queue

概要

// In header: <boost/lockfree/queue.hpp>

template<typename T, typename... Options> 
class queue {
public:
  // types
  typedef T                                 value_type;
  typedef implementation_defined::allocator allocator; 
  typedef implementation_defined::size_type size_type; 

  // public member functions
  bool is_lock_free(void) const;
  queue(void);
  template<typename U, typename Enabler = std::enable_if< has_capacity > > 
    explicit queue(typename boost::allocator_rebind< node_allocator, U >::type const &);
  template<typename Enabler = std::enable_if< has_capacity > > 
    explicit queue(allocator const &);
  template<typename Enabler = std::enable_if< !has_capacity > > 
    explicit queue(size_type);
  template<typename U, typename Enabler = std::enable_if< !has_capacity > > 
    queue(size_type, 
          typename boost::allocator_rebind< node_allocator, U >::type const &);
  template<typename Enabler = std::enable_if< !has_capacity > > 
    queue(size_type, allocator const &);
  queue(const queue &) = delete;
  queue & operator=(const queue &) = delete;
  queue(queue &&) = delete;
  queue & operator=(queue &&) = delete;
  void reserve(size_type);
  void reserve_unsafe(size_type);
  ~queue(void);
  bool empty(void) const;
  bool push(const T &);
  bool push(T &&);
  bool bounded_push(const T &);
  bool bounded_push(T &&);
  bool unsynchronized_push(const T &);
  bool unsynchronized_push(T &&);
  bool pop(T &);
  template<typename U, 
           typename Enabler = std::enable_if_t< std::is_constructible< U, T&& >::value > > 
    bool pop(U &);
  std::optional< T > pop(uses_optional_t);
  template<typename U> std::optional< U > pop(uses_optional_t);
  bool unsynchronized_pop(T &);
  template<typename U, 
           typename Enabler = std::enable_if_t< std::is_constructible< U, T&& >::value > > 
    bool unsynchronized_pop(U &);
  template<typename Functor> bool consume_one(Functor &&);
  template<typename Functor> size_t consume_all(Functor &&);
};

说明

queue 类提供多写者/多读者队列, push 与 pop 是无锁的, 构造/析构必须同步. 它使用自由列表进行内存管理, 被释放的节点被推入自由列表, 在队列销毁前不会归还操作系统.

策略:

  • boost::lockfree::fixed_sized, 默认为 boost::lockfree::fixed_sized<false>
    可用于在 push 期间完全禁用动态内存分配, 以确保无锁行为.
    若数据结构配置为固定大小, 内部节点存储在数组中, 并通过数组索引寻址. 这把队列的可能大小限制为索引类型可寻址的元素数量 (通常为 2**16-2), 但在缺少双宽度比较交换指令的平台上, 这是实现无锁的最佳方式.

  • boost::lockfree::capacity, 可选
    若此模板实参传给选项, 队列的大小将在编译期设置.
    此选项隐含 fixed_sized<true>

  • boost::lockfree::allocator, 默认为 boost::lockfree::allocator<std::allocator<void>>
    指定用于内部自由列表的分配器

要求:

  • T 必须有复制构造函数

  • T 必须有平凡复制赋值运算符

  • T 必须有平凡析构函数

queue 公有成员函数

  1. bool is_lock_free(void) const;

    警告

    它只检查队列头尾节点和自由列表是否能以无锁方式修改. 在大多数平台上, 若此返回为 true, 则整个实现是无锁的. 使用 c++0x 风格原子操作时, 无法提供完全精确的实现, 因为需要测试每个内部节点, 而若后续节点还会从操作系统分配, 这是不可能的.

    返回:

    若实现是无锁的则为 true.

  14. ~queue(void);

    销毁队列, 从自由列表释放所有节点.

  15. bool empty(void) const;

    检查队列是否为空

    注释

    仅在没有其他线程修改队列时, 结果才是准确的. 因此在程序逻辑中使用该值通常并不实用.

    返回:

    若队列为空则为 true, 否则为 false

    		 
  16. bool push(const T & t);

    把对象 t 推入队列.

    注释

    线程安全. 若内部内存池耗尽且内存池不是固定大小, 将从操作系统分配新节点. 该操作可能不是无锁的.

    后置条件:

    若能分配内部节点, 对象将被推入队列

    返回:

    若 push 操作成功则为 true.
