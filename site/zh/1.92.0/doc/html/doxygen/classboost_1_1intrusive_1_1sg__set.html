说明

类模板 sg_set 是一种侵入式容器, 模仿 C++ 标准中所述 std::sg_set 接口的大部分内容.

模板参数 T 是容器要管理的类型. 用户可以指定附加选项; 若未提供选项, 则使用默认选项.

容器支持以下选项: base_hook<>/member_hook<>/value_traits<>、floating_point<>、size_type<> 和 compare<>.

sg_set 公有成员函数

  1. sg_set();

    效果: 构造一个空容器.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 key_compare 对象的复制构造函数抛出异常. 基本保证.

  2. explicit sg_set(const key_compare & cmp, 
                const value_traits & v_traits = value_traits());
  3. template<typename Iterator> 
  sg_set(Iterator b, Iterator e, const key_compare & cmp = key_compare(), 
         const value_traits & v_traits = value_traits());
  4. sg_set(sg_set && x);

    效果: 构造一个从另一容器移动资源的容器. 内部比较对象与 value 特征被移动构造, 属于 x 的节点 (表示 "end" 的节点除外) 被链接到 *this.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 的移动构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或比较对象的移动构造函数抛出异常.

  5. sg_set & operator=(sg_set && x);

    效果: 等价于 swap

  6. ~sg_set();

    效果: 使所有元素脱离此容器. 集合中的对象不会被删除 (即不调用析构函数), 但根据 value_traits 模板参数, 节点会被重新初始化, 因此可以重用.

    复杂度: 与 *this 中包含的元素数成线性关系.

    抛出: 无.

  27. template<typename Cloner, typename Disposer> 
  void clone_from(const sg_set & src, Cloner cloner, Disposer disposer);

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点等价的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(const_reference ) 从 src 克隆所有元素并插入到 *this 中. 从源容器复制谓词.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常或谓词复制赋值抛出异常. 基本保证. 补充说明: 它还会从源容器复制 alpha 因子.

  28. template<typename Cloner, typename Disposer> 
  void clone_from(sg_set && src, Cloner cloner, Disposer disposer);

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点等价的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(reference) 从 src 克隆所有元素并插入到 *this 中. 从源容器复制谓词.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常或谓词复制赋值抛出异常. 基本保证.

    注释: 此版本可以修改源容器, 适用于实现移动语义. 补充说明: 它还会从源容器复制 alpha 因子.

    要求: 解引用迭代器必须产生 value_type 类型的左值.

    效果: 尝试把范围的每个元素插入容器.

    复杂度: 插入范围通常为 O(N * log(N)), 其中 N 是范围的大小. 但若该范围已按 value_comp() 排序, 则为 N 的线性.

  36. iterator insert_commit(reference value, 
                       const insert_commit_data & commit_data) noexcept;

    要求: value 必须是 value_type 类型的左值. commit_data 必须来自先前对 "insert_check" 的调用. 在填充 "commit_data" 的 "insert_check" 与 "insert_commit" 调用之间, 不得有对象被插入或从容器中擦除.

    效果: 使用先前 "insert_check" 填充的 "commit_data" 所获得的信息把 value 插入容器.

    返回: 指向新插入对象的迭代器.

    复杂度: 常量时间.

    抛出: 无.

    注释: 此函数只有先前执行过 "insert_check" 填充 "commit_data" 时才有意义. 在 "insert_check" 与 "insert_commit" 调用之间不得插入或擦除任何值.

  37. iterator insert_before(const_iterator pos, reference value) noexcept;

    要求: value 必须是左值, "pos" 必须是有效迭代器 (或 end), 且按谓词插入后必须是 value 的后继

    效果: 把 x 插入到容器中 "pos" 之前.

    复杂度: 常量时间.

    抛出: 无.

    注释: 此函数不检查前置条件, 因此若 "pos" 不是 "value" 的后继, 容器排序不变式将被破坏. 这是仅供高级用户出于性能原因使用的低层函数.

  38. void push_back(reference value) noexcept;

    要求: value 必须是左值, 且不得小于已插入的最大键

    效果: 把 x 插入到容器的最后一个位置.

    复杂度: 常量时间.

    抛出: 无.

    注释: 此函数不检查前置条件, 因此若 value 小于已插入的最大键, 容器排序不变式将被破坏. 此函数比使用 "insert_before" 略高效. 这是仅供高级用户出于性能原因使用的低层函数.

  68. std::pair< iterator, iterator >

  69. template<typename KeyType, typename KeyTypeKeyCompare> 
  std::pair< iterator, iterator > 
  bounded_range(const KeyType & lower_key, const KeyType & upper_key, 
                KeyTypeKeyCompare comp, bool left_closed, bool right_closed);

    要求: lower_key 是一个值, 使得 *this 按 comp(nk, lower_key) 划分 (若 left_closed 为 true); 否则按 !comp(lower_key, nk) 划分.

    upper_key 是一个值, 使得 *this 按 !comp(upper_key, nk) 划分 (若 right_closed 为 true); 否则按 comp(nk, upper_key) 划分.

    upper_key 按 comp 不得先于 lower_key [comp(upper_key, lower_key) 应为 false]

    若 lower_key 等价于 upper_key [!comp(upper_key, lower_key) && !comp(lower_key, upper_key)], 则 ('left_closed' || 'right_closed') 必须为 false.

    效果: 返回满足以下条件的对组:

    first = lower_bound(lower_key, comp) 若 left_closed, 否则 upper_bound(lower_key, comp)

    second = upper_bound(upper_key, comp) 若 right_closed, 否则 lower_bound(upper_key, comp)

    复杂度: 对数.

    抛出: 若 comp 抛出异常.

    注释: 对 lower_key 和 upper_key 分别调用 upper_bound 与 lower_bound 可能不如此函数高效.

    注释: 实验性函数, 接口在后续版本中可能变更.
