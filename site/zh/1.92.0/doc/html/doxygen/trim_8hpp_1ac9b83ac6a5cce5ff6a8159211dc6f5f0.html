函数模板 trim_right_copy_if

boost::trim_right_copy_if — 右修剪 - 参数化.

概要

// In header: <boost/algorithm/string/trim.hpp>


template<typename OutputIteratorT, typename RangeT, typename PredicateT> 
  OutputIteratorT 
  trim_right_copy_if(OutputIteratorT Output, const RangeT & Input, 
                     PredicateT IsSpace);

说明

移除输入中的所有尾随空格.
所提供的谓词用于判定哪些字符被视为空格. 结果是输入的修剪副本. 它作为序列返回, 或复制到输出迭代器

注释

此函数的第二个变体提供强异常安全保证

参数:

Output

结果将被复制到的输出迭代器

Input

一个输入范围

IsSpace

标识空格的一元谓词

返回:

指向最后插入字符之后位置的输出迭代器, 或输入的副本
