类 group

boost::mpi::group — group 是对 communicator 内进程子集的表示.

概要

// In header: <boost/mpi/group.hpp>


class group {
public:

  // public member functions
  group();
  group(const MPI_Group &, bool);
  optional< int > rank() const;
  int size() const;
  template<typename InputIterator, typename OutputIterator> 
    OutputIterator 
    translate_ranks(InputIterator, InputIterator, const group &, 
                    OutputIterator);
  operator bool() const;
  operator MPI_Group() const;
  template<typename InputIterator> group include(InputIterator, InputIterator);
  template<typename InputIterator> group exclude(InputIterator, InputIterator);
};

说明

类 group 允许创建通信器内进程的任意子集. 可以计算两个群组的并集, 交集或差集, 或者通过明确包含或排除某些进程来创建新群组. 给定一个群组, 可以创建一个仅包含该群组中进程的新通信器.

group 公有成员函数

  1. group();
    构造空群组.
  2. group(const MPI_Group & in_group, bool adopt);
    从 MPI_Group 构造群组.

    此例程允许构造 Boost.MPI group, 其来源是 C 的 MPI_Group. group 对象可以 (可选地) 采用 MPI_Group, 此后 group 对象将负责释放 MPI_Group, 即当 group 的最后一个副本消失时.

    参数:

    in_group

    MPI_Group, 用于构造此 group.

    adopt

    group 是否应采用 MPI_Group. 若为 true, 当最后一个副本被销毁时, group 对象 (或其副本之一) 将释放该群组 (通过 MPI_Comm_free). 否则, 用户负责调用 MPI_Group_free.

    		 
  3. optional< int > rank() const;
    确定调用进程在群组中的秩.

    此例程等价于 MPI_Group_rank.

    返回:

    调用进程在群组中的秩, 其值位于 [0, size()) 内. 如果调用进程不在群组中, 则返回空值.

    		 
  4. int size() const;
    确定群组中的进程数量.

    此例程等价于 MPI_Group_size.

    返回:

    群组中的进程数量.

    		 
  5. template<typename InputIterator, typename OutputIterator> 
  OutputIterator 
  translate_ranks(InputIterator first, InputIterator last, 
                  const group & to_group, OutputIterator out);
    将一个群组中的秩转换为另一群组中相同进程的秩.

    此例程将迭代器范围 [first, last) 中的每个整数秩值从当前群组转换为 to_group 中相应进程的秩值. 相应的秩值通过输出迭代器 out 写出. 当当前群组中的秩与 to_group 中的秩没有对应关系时, 将值 MPI_UNDEFINED 写入输出迭代器.

    参数:

    first

    当前群组中秩的迭代器范围的起始.

    last

    当前群组中秩的迭代器范围的末端之后.

    to_group

    我们要将秩转换到的群组.

    out

    转换后的秩将写入的输出迭代器.

    返回:

    输出迭代器, 指向最后写入的秩之后一步.

    		 
  6. operator bool() const;
    确定群组是否非空.

    返回:

    若群组非空则为 true, 若为空则为 false.

    		 
  7. operator MPI_Group() const;
    获取与此群组关联的底层 MPI_Group.

    返回:

    此对象操纵的 MPI_Group 句柄. 如果此对象表示空群组, 则返回 MPI_GROUP_EMPTY.

    		 
  8. template<typename InputIterator> 
  group include(InputIterator first, InputIterator last);
    创建一个新群组, 包含当前群组中进程的一个子集.

    此例程创建一个新的 group, 其中仅包含当前群组中列于整数迭代器范围 [first, last) 内的进程. 等价于 MPI_Group_incl.

    first 要包含的秩的迭代器范围的起始.

    last 要包含的秩的迭代器范围的末端之后.

    返回:

    一个新的群组, 包含当前群组中秩位于 [first, last) 的进程.

    		 
  9. template<typename InputIterator> 
  group exclude(InputIterator first, InputIterator last);
    由当前群组中的所有进程创建新群组, 排除进程的特定子集.

    此例程创建一个新的 group, 包含当前群组中的所有进程, 但秩列于整数迭代器范围 [first, last) 内的进程除外. 等价于 MPI_Group_excl.

    first 要排除的秩的迭代器范围的起始.

    last 要排除的秩的迭代器范围的末端之后.

    返回:

    一个新的群组, 包含当前群组中的所有进程, 但当前群组中秩位于 [first, last) 的进程除外.
