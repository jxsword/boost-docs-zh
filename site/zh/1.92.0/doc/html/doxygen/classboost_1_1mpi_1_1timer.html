类 timer

boost::mpi::timer — 提供对 MPI 计时设施访问的简单计时器.

概要

// In header: <boost/mpi/timer.hpp>


class timer {
public:

  // public member functions
  timer();
  void restart();
  double elapsed() const;
  double elapsed_max() const;
  double elapsed_min() const;

  // public static functions
  static bool time_is_global();
};

说明

类 timer 是对 MPI 计时设施的简单封装, 模仿 Boost Timer 库的接口.

timer 公有成员函数

  1. timer();

    初始化计时器

    后置条件:

    elapsed() == 0 

  2. void restart();

    重新启动计时器.

    后置条件:

    elapsed() == 0 

  3. double elapsed() const;

    返回自上次构造或重置以来经过的时间量, 以秒为单位.

  4. double elapsed_max() const;

    返回 elapsed() 最大可能值的估计值. 注意, 此例程在某些系统上可能返回过高的值.

  5. double elapsed_min() const;

    返回 elapsed() 可能返回的最小非零值. 这是计时器的分辨率.

timer 公有静态函数

  1. static bool time_is_global();

    确定经过时间值是全局时间还是本地处理器时间.
