说明

类模板 bstree 是一种非平衡的侵入式二叉搜索树容器. 仅当 key_compare 对象不抛出异常时, 不抛出保证才成立.

复杂度保证仅在树平衡时成立; 若树完全失衡, 对数复杂度将增加到线性.

模板参数 T 是容器要管理的类型. 用户可以指定附加选项; 若未提供选项, 则使用默认选项.

容器支持以下选项: base_hook<>/member_hook<>/value_traits<>、constant_time_size<>、size_type<> 和 compare<>.

bstree 公有成员函数

  1. bstree();

    效果: 构造一个空容器.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 key_compare 对象的复制构造函数抛出异常. 基本保证.

  2. explicit bstree(const key_compare & cmp, 
                const value_traits & v_traits = value_traits());

    效果: 用给定的比较函数与特征构造一个空容器.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 key_compare 对象的复制构造函数抛出异常. 基本保证.

  3. template<typename Iterator> 
  bstree(bool unique, Iterator b, Iterator e, 
         const key_compare & cmp = key_compare(), 
         const value_traits & v_traits = value_traits());

    要求: 解引用迭代器必须产生 value_type 类型的左值. cmp 必须是诱导严格弱序的比较函数.

    效果: 构造一个空容器并插入 [b, e) 中的元素.

    复杂度: 若 [b, e) 已按 comp 排序则为 N 的线性, 否则为 N * log N, 其中 N 是 first 与 last 之间的距离.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 key_compare 对象的复制构造函数/operator() 抛出异常. 基本保证.

  4. bstree(bstree && x);

    效果: 构造一个从另一容器移动资源的容器. 内部比较对象与 value 特征被移动构造, 属于 x 的节点 (表示 "end" 的节点除外) 被链接到 *this.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 的移动构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或比较对象的移动构造函数抛出异常.

  5. bstree & operator=(bstree && x);

    效果: 等价于 swap

  6. ~bstree();

    效果: 使所有元素脱离此容器. 集合中的对象不会被删除 (即不调用析构函数), 但根据 value_traits 模板参数, 节点会被重新初始化, 因此可以重用.

    复杂度: 与 *this 中包含的元素数成线性关系.

    抛出: 无.

  27. template<typename Cloner, typename Disposer> 
  void clone_from(const bstree & src, Cloner cloner, Disposer disposer);

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点等价的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(const_reference ) 从 src 克隆所有元素并插入到 *this 中. 从源容器复制谓词.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常或谓词复制赋值抛出异常. 基本保证.

  28. template<typename Cloner, typename Disposer> 
  void clone_from(bstree && src, Cloner cloner, Disposer disposer);

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点等价的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(reference) 从 src 克隆所有元素并插入到 *this 中. 从源容器复制谓词.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常或谓词复制赋值抛出异常. 基本保证.

    注释: 此版本可以修改源容器, 适用于实现移动语义.

  37. template<typename KeyType, typename KeyTypeKeyCompare> 
  std::pair< iterator, bool > 
  insert_unique_check(const KeyType & key, KeyTypeKeyCompare comp, 
                      insert_commit_data & commit_data);

    要求: comp 必须是诱导与 key_compare 相同严格弱序的比较函数. 区别在于 comp 把任意键与容器中的值进行比较.

    效果: 使用用户提供的键 (而非值本身) 检查一个值是否可以插入容器.

    返回: 若存在等价值, 返回包含指向已存在值的迭代器和 false 的对组. 若该值可以插入, 返回的对组布尔成员为 true, 并填充 "commit_data", 该数据应与 "insert_commit" 函数一起使用.

    复杂度: 平均复杂度至多为对数级.

    抛出: 若 comp 排序函数抛出异常. 强保证.

    注释: 构造 value_type 代价高昂时可用此函数提升性能: 若存在等价值, 已构造的对象必须丢弃. 很多时候, 节点中用于施加排序的部分比 value_type 的构造代价低得多, 此函数提供了用该部分检查插入是否会成功的机会.

    若检查成功, 用户可以构造 value_type 并使用 "insert_commit" 以常数时间插入对象. 这使插入的总复杂度为对数级: check(O(log(N)) + commit(O(1)).

    "commit_data" 仅在容器没有更多对象被插入或擦除的情况下, 对随后的 "insert_commit" 保持有效.

    要求: comp 必须是诱导与 key_compare 相同严格弱序的比较函数. 区别在于 comp 把任意键与容器中的值进行比较.

    效果: 使用用户提供的键 (而非值本身) 检查一个值是否可以插入容器, 并以 "hint" 作为插入位置提示.

    返回: 若存在等价值, 返回包含指向已存在值的迭代器和 false 的对组. 若该值可以插入, 返回的对组布尔成员为 true, 并填充 "commit_data", 该数据应与 "insert_commit" 函数一起使用.

    复杂度: 一般为对数; 但若 t 恰好插在 hint 之前, 则为均摊常数时间.

    抛出: 若 comp 排序函数抛出异常. 强保证.

    注释: 构造 value_type 代价高昂时可用此函数提升性能: 若存在等价值, 已构造的对象必须丢弃. 很多时候, 构造中用于施加排序的部分比 value_type 的构造代价低得多, 此函数提供了用该键检查插入是否会成功的机会.

    若检查成功, 用户可以构造 value_type 并使用 "insert_commit" 以常数时间插入对象. 这可使插入的总复杂度为常数时间: check(O(1)) + commit(O(1)).

    "commit_data" 仅在容器没有更多对象被插入或擦除的情况下, 对随后的 "insert_commit" 保持有效.

    效果: 用 with_this 替换 replace_this 在容器中的位置. 容器无需重新平衡.

    复杂度: 常数.

    抛出: 无.

    注释: 若按排序规则 with_this 与 *replace_this 不等价, 此函数将破坏容器排序不变式. 此函数比擦除再插入节点更快, 因为无需重新平衡或比较.

  81. template<typename T, class ... Options2> 
  void merge_unique(bstree< T, Options2... > &);

    要求: "source" 容器的 Options 只能在比较函数方面与 *this 不同.

    效果: 尝试提取 source 中的每个元素, 并使用 *this 的比较对象将其插入 a. 若 a 中存在键与 source 中某元素的键等价的元素, 则该元素不会从 source 中提取.

    后置条件: 指向 source 被转移元素的指针和引用仍指向那些相同的元素, 但作为 *this 的成员. 引用被转移元素的迭代器将继续指向其元素, 但现在表现为 *this 的迭代器, 而非 source 的迭代器.

    抛出: 除非比较对象抛出异常, 否则不抛出.

    复杂度: N log(a.size() + N) (N 的值为 source.size())
