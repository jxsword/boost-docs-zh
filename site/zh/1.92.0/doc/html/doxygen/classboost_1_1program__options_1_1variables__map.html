类 variables_map

boost::program_options::variables_map

概要

// In header: <boost/program_options/variables_map.hpp>


class variables_map : public boost::program_options::abstract_variables_map,
                      public std::map< std::string, variable_value >
{
public:

  // public member functions
  variables_map();
  variables_map(const abstract_variables_map *);
  const variable_value & operator[](const std::string &) const;
  void clear();
  void notify();

  // private member functions
  virtual const variable_value & get(const std::string &) const;

  // friend functions
  BOOST_PROGRAM_OPTIONS_DECL void 
  store(const basic_parsed_options< char > &, variables_map &, bool = false);
};

说明

在真实映射中存储变量的具体变量映射.

此类派生自 std::map<std::string, variable_value>, 因此可以使用所有 map 运算符来检查其内容.

variables_map 公有成员函数

  1. variables_map();
  2. variables_map(const abstract_variables_map * next);
  3. const variable_value & operator[](const std::string & name) const;
  4. void clear();
  5. void notify();

variables_map 私有成员函数

  1. virtual const variable_value & get(const std::string & name) const;

    abstract_variables_map::get 的实现, 在 *this 中执行 'find'.

variables_map 友元函数

  1. BOOST_PROGRAM_OPTIONS_DECL void 
store(const basic_parsed_options< char > & options, variables_map & xm, 
      bool utf8 = false);

    将 'options' 中定义的所有选项存入 'm'. 如果 'm' 已有某选项的非默认值, 则该值不会被更改, 即使 'options' 指定了某个值.
