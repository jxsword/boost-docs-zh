函数模板 adaptive_sort

boost::movelib::adaptive_sort

概要

// In header: <boost/move/algo/adaptive_sort.hpp>


template<typename RandIt, typename RandRawIt, typename Compare> 
  void adaptive_sort(RandIt first, RandIt last, Compare comp, 
                     RandRawIt uninitialized, 
                     typename iter_size< RandIt >::type uninitialized_len);

说明

效果: 按比较函数对象 "comp" 以升序对范围 [first, last) 中的元素排序. 该排序是稳定的 (保证保留相等元素的顺序). 若提供额外的原始存储, 性能会有所提升.

要求:

  • RandIt 必须满足 ValueSwappable 和 RandomAccessIterator 的要求.

  • 解引用 RandIt 得到的类型必须满足 MoveAssignable 和 MoveConstructible 的要求.

参数:

  • first, last: 要排序的元素范围

  • comp: 比较函数对象, 若第一个参数按序排在第二个参数之前则返回 true.

  • uninitialized, uninitialized_len: 以 "uninitialized" 为起点的原始存储, 能够容纳 "uninitialized_len" 个 iterator_traits<RandIt>::value_type 类型的元素. 当 uninitialized_len 为 ceil(std::distance(first, last)/2) 时性能最佳.

抛出: 若 comp 抛出异常, 或解引用 RandIt 得到的类型的移动构造函数、移动赋值或 swap 抛出异常.

复杂度: 始终为 K x O(Nxlog(N)) 次比较和移动赋值/构造/交换. 即使没有额外内存, 比较次数也接近最小值. 当 uninitialized_len 为 ceil(std::distance(first, last)/2) 时, 数据移动的常数因子最小. 当 uninitialized_len 为 ceil(sqrt(std::distance(first, last)))*2 时即可获得相当不错的性能.

注意: 实验性实现, 尚未达到生产可用.
