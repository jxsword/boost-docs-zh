函数模板 after

boost::xpressive::after — 后行断言 (look-behind).

概要

// In header: <boost/xpressive/regex_primitives.hpp>


template<typename Expr> unspecified after(Expr const & expr);

说明

若 expr 子表达式会在序列中当前位置减 N 处匹配 (N 是 expr 的宽度), 则 after(expr) 成功. expr 不包含在匹配中. 例如, 若当前位置在 "foo" 之后, 则 after("foo") 成功. 后行断言可用按位取反运算符取反.

重要

after(expr) 等价于 perl 的 (?<=...) 扩展. ~after(expr) 是否定后行断言, 等价于 perl 的 (?<!...) 扩展.

参数:

expr

要放入前行断言的子表达式.

要求:

expr 不能匹配可变数量的字符.
