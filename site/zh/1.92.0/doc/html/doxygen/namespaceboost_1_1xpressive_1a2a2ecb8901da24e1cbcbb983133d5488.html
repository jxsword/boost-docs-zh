函数模板 range

boost::xpressive::range — 匹配一个字符范围.

概要

// In header: <boost/xpressive/regex_primitives.hpp>


template<typename Char> unspecified range(Char ch_min, Char ch_max);

说明

匹配范围 [ch_min, ch_max] 中的任何字符.

参数:

ch_min

要匹配范围的下端.

ch_max

要匹配范围的上端.
