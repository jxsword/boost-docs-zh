类模板 basic_parsed_options

boost::program_options::basic_parsed_options

概要

// In header: <boost/program_options/parsers.hpp>

template<typename charT> 
class basic_parsed_options {
public:

  // public member functions
  explicit basic_parsed_options(const options_description *, int = 0);

  // public data members
  std::vector< basic_option< charT > > options;
  const options_description * description;
  int m_options_prefix;
};

说明

解析输入源的结果. 此类的主要用途是把信息从解析器组件传递到值存储组件. 此类本身意义不大.

basic_parsed_options 公有成员函数

  1. explicit basic_parsed_options(const options_description * xdescription, 
                              int options_prefix = 0);

basic_parsed_options 公有数据成员

  1. std::vector< basic_option< charT > > options;

    在源中找到的选项.

  2. const options_description * description;

    用于解析的选项描述. 解析器应返回传给它们的 option_description 实例的指针, 生命周期问题由调用者负责. 可以为 NULL.

  3. int m_options_prefix;

    主要用于异常中的诊断消息. 生成这些结果的解析器的规范选项前缀, 取决于 basic_command_line_parser::style() 或 cmdline::style() 的设置. 按 command_line_style 枚举的优先顺序为: allow_long allow_long_disguise allow_dash_for_short allow_slash_for_short
