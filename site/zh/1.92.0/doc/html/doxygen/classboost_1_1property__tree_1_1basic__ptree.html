说明

属性树的主结构. 属性树是一种分层数据结构, 每个节点中有一个类型为 Data 的元素, 以及一个有序的子节点序列, 子节点还由类型为 Key 的非唯一键标识.

键等价性由 KeyCompare 定义, 它是定义严格弱序的谓词.

属性树为其直接子节点的 (键-节点) 对定义了类似 Container 的接口. 迭代器是双向的. 节点序列按插入顺序而非键顺序保存.

basic_ptree 公有类型

  1. typedef basic_ptree< Key, Data, KeyCompare > self_type;

    引用此 basic_ptree<C,K,P,A> 类型的更简单方式. 注意它是私有的, 仅为 doxygen 而公开.

  50. self_type & get_child(const path_type & path);

    获取给定路径处的子节点, 否则抛出 ptree_bad_path.

    注释

    取决于路径, 每一层的结果可能不完全确定, 即如果同一个键出现多次, 未指定选择哪个子节点. 这可能导致即使存在具有该路径的后代节点, 路径也无法解析. 示例:

    a -> b -> c
  -> b

    如果对 "b" 的解析选择第一个这样的节点, 则路径 "a.b.c" 将成功; 如果选择第二个, 则失败.
