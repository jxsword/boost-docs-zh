结构体模板 concept_interface

boost::type_erasure::concept_interface

概要

// In header: <boost/type_erasure/concept_interface.hpp>

template<typename Concept, typename Base, typename ID, typename Enable = void> 
struct concept_interface : public Base {
};

说明

可以特化 concept_interface 类来为 any 添加行为. any 继承自所有相关的 concept_interface 特化.

concept_interface 可针对基本概念或复合概念进行特化. 若概念 C1 包含另一个概念 C2, 则库保证 concept_interface 针对 C2 的特化是针对 C1 的特化的基类. 这意味着 C1 可以安全地覆盖 C2 的成员.

concept_interface 只能针对用户自定义概念进行特化. 库拥有其自身内建概念的特化.

元函数 derived、rebind_any 与 as_param (可应用于 Base) 对于确定 concept_interface 中定义的函数的实参类型与返回类型很有用.

为分派函数, 请使用 call.

模板参数

  1. typename Concept

    我们要为其特化 concept_interface 的概念. 它的某个占位符应为 ID.

  2. typename Base

    此类的基类. concept_interface 的特化必须公有继承自此类型.

  3. typename ID

    表示此类型的占位符.

  4. typename Enable = void

    可用于 SFINAE 的哑参数.
