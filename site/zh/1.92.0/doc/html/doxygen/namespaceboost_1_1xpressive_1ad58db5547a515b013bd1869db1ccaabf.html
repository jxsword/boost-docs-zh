函数模板 imbue

boost::xpressive::imbue — 指定正则特征或 std::locale.

概要

// In header: <boost/xpressive/regex_primitives.hpp>


template<typename Locale> unspecified imbue(Locale const & loc);

说明

imbue() 指示正则引擎在匹配 regex 时使用指定的特征或 locale. 整个表达式必须使用相同的特征/locale. 例如, 下面为 regex 指定了一个 locale: std::locale loc; sregex rx = imbue(loc)(+digit);

参数:

loc

std::locale 或正则特征对象.
