结构体 relaxed

boost::type_erasure::relaxed

概要

// In header: <boost/type_erasure/relaxed.hpp>


struct relaxed : public boost::mpl::vector0<> {
};

说明

这个特殊概念启用多种有用的默认行为, 使 any 的表现如同普通对象. 默认情况下, any 把所有操作转发给底层类型, 只提供其 Concept 中指定的操作.

具体而言, relaxed 启用以下功能:

  • 可以把原始值赋给 any. 这将替换 any 所存储的值. (但注意, 若存在 assignable, 则它优先. )

  • any 的赋值在无法使用 assignable 时 (要么因为缺少 assignable, 要么因为所存类型不匹配) 会改用构造函数.

  • 允许 any 的默认构造, 并创建一个空 any.

  • equality_comparable: 若类型不匹配, 将返回 false.

  • less_than_comparable: 若类型不匹配, 排序将按照 std::type_info::before 进行.

  • 若传给任何其他函数的实参不匹配, 将抛出 bad_function_call 异常而不是产生未定义行为.
