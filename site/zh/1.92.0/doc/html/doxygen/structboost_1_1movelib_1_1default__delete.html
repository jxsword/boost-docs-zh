结构体模板 default_delete

boost::movelib::default_delete

概要

// In header: <boost/move/default_delete.hpp>

template<typename T> 
struct default_delete {

  // public member functions
  default_delete();
  default_delete(const default_delete &);
  default_delete & operator=(const default_delete &);
  template<typename U> default_delete(const default_delete< U > &) noexcept;
  template<typename U> 
    default_delete & operator=(const default_delete< U > &) noexcept;
  template<typename U> void operator()(U *) const noexcept;
  void operator()(std::nullptr_t) const noexcept;
};

说明

类模板 default_delete 用作类模板 unique_ptr 的默认删除器 (析构策略) .

模板参数

  1. typename T

    要删除的类型. 它可以是不完整类型

default_delete 公有成员函数

  1. default_delete();

    默认构造函数.

  2. default_delete(const default_delete &);

    平凡复制构造函数

  3. default_delete & operator=(const default_delete &);

    平凡赋值

  4. template<typename U> 
  default_delete(const default_delete< U > & BOOST_MOVE_DOCIGN) noexcept;

    效果: 从另一个 default_delete 对象构造 default_delete<underline> object.</underline>

    <underline>Remarks: This constructor shall not participate in overload resolution unless:

    • If T is not an array type and U* is implicitly convertible to T*.

    • If T is an array type and U* is a more CV qualified pointer to remove_extent<T>::type.

    </underline>

  5. template<typename U> 
  default_delete & operator=(const default_delete< U > &) noexcept;

    效果: 从另一个 default_delete 对象构造 default_delete<underline> object.</underline>

    <underline>Remarks: This constructor shall not participate in overload resolution unless:

    • If T is not an array type and U* is implicitly convertible to T*.

    • If T is an array type and U* is a more CV qualified pointer to remove_extent<T>::type.

    </underline>

  6. template<typename U> void operator()(U * ptr) const noexcept;

    效果: 若 T 不是数组类型, 则对 static_cast<T*>(ptr) 调用 delete; 否则对 static_cast<remove_extent<T>::type*>(ptr) 调用 delete[].

    备注: 若 U 是不完整类型, 则程序非良构. 除非以下情形, 此运算符不得参与重载决议:

    • T 不是数组类型且 U* 可转换为 T*, 或

    • T 是数组类型, 且 remove_cv<U>::type 与 remove_cv<remove_extent<T>::type>::type 是相同的类型, 并且 U* 可转换为 remove_extent<T>::type*.

  7. void operator()(std::nullptr_t) const noexcept;

    效果: 等同于 (this)(static_cast<element_type>(nullptr)).
