函数 this_line_location

boost::dll::this_line_location

概要

// In header: <boost/dll/runtime_symbol_info.hpp>


boost::dll::fs::path this_line_location(std::error_code & ec);

说明

成功时返回包含当前代码行 (调用 this_line_location() 方法所在行) 的二进制对象的完整路径与名称.

参数:

ec

将被设置为操作结果的变量.

抛出:

 内存不足时抛出 std::bad_alloc. 不接受 boost::dll::fs::error_code 的重载还会抛出 boost::dll::fs::system_error.
