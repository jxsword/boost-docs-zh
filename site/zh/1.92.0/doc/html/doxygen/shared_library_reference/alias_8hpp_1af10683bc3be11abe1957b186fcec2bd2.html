宏 BOOST_DLL_ALIAS_SECTIONED

BOOST_DLL_ALIAS_SECTIONED — 与 BOOST_DLL_ALIAS 相同, 但把别名放入用户指定的节.

概要

// In header: <boost/dll/alias.hpp>

BOOST_DLL_ALIAS_SECTIONED(FunctionOrVar, AliasName, SectionName)

说明

示例: 

namespace foo {
  void bar(std::string&);

  BOOST_DLL_ALIAS_SECTIONED(foo::bar, foo_bar, sect_1) // section "sect_1" now exports "foo_bar"
}

参数:

AliasName

别名的名称. 必须是有效 C 标识符.

FunctionOrVar

要为其创建别名的函数或变量.

SectionName

节名. 必须是不带引号、不超过 8 字节的有效 C 标识符.
