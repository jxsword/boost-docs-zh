宏 BOOST_DLL_AUTO_ALIAS

BOOST_DLL_AUTO_ALIAS — 以未修饰的别名导出变量或函数.

概要

// In header: <boost/dll/alias.hpp>

BOOST_DLL_AUTO_ALIAS(FunctionOrVar)

说明

在 C++ 修饰名很长时该宏很有用. 例如, 某个 void boost::foo(std::string) 函数名在修饰后会变成类似 N5boostN3foosE 的样子. 用 N5boostN3foosE 名导入函数并不友好, 尤其考虑到不同编译器有不同的修饰方案.*

必须在声明 FunctionOrVar 的作用域中使用. FunctionOrVar 必须是有效 C 名称, 即不得包含 ::.

全局命名空间中的函数或变量不得与 FunctionOrVar 同名.

把所有别名放入二进制文件的 "boostdll" 只读节. 与 BOOST_DLL_ALIAS(FunctionOrVar, FunctionOrVar) 几乎相同.

示例: 

namespace foo {
  void bar(std::string&);
  BOOST_DLL_AUTO_ALIAS(bar)
}

参见: BOOST_DLL_ALIAS 用于以不同名称创建别名.

参数:

FunctionOrVar

要为其创建未修饰别名的函数或变量.
