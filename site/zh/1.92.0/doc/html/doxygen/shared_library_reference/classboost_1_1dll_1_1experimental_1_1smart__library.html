类 smart_library

boost::dll::experimental::smart_library — 该类是 shared_library 的扩展, 允许加载 C++ 符号.

概要

// In header: <boost/dll/smart_library.hpp>


class smart_library {
public:
  // types
  typedef unspecified mangled_storage;

  // public member functions
  const shared_library & shared_lib() const noexcept;
  const mangled_storage & symbol_storage() const noexcept;
  mangled_storage & symbol_storage() noexcept;
  smart_library() = default;
  smart_library(const boost::dll::fs::path &, 
                load_mode::type = load_mode::default_mode);
  smart_library(const boost::dll::fs::path &, boost::dll::fs::error_code &, 
                load_mode::type = load_mode::default_mode);
  smart_library(const boost::dll::fs::path &, load_mode::type, 
                boost::dll::fs::error_code &);
  smart_library(const smart_library &) = default;
  smart_library(smart_library &&) = default;
  explicit smart_library(const shared_library &) noexcept;
  explicit smart_library(shared_library &&) noexcept;
  ~smart_library() = default;
  void load(const boost::dll::fs::path &, 
            load_mode::type = load_mode::default_mode);
  void load(const boost::dll::fs::path &, boost::dll::fs::error_code &, 
            load_mode::type = load_mode::default_mode);
  void load(const boost::dll::fs::path &, load_mode::type, 
            boost::dll::fs::error_code &);
  template<typename T> T & get_variable(const std::string &) const;
  template<typename Func> Func & get_function(const std::string &) const;
  template<typename Class, typename Func> 
    unspecified get_mem_fn(const std::string &) const;
  template<typename Signature> 
    constructor< Signature > get_constructor() const;
  template<typename Class> destructor< Class > get_destructor() const;
  template<typename Class> const std::type_info & get_type_info() const;
  template<typename Alias> void add_type_alias(const std::string &);
  void unload() noexcept;
  bool is_loaded() const noexcept;
  explicit operator bool() const noexcept;
  bool has(const char *) const noexcept;
  bool has(const std::string &) const noexcept;
  smart_library & assign(const smart_library &);
  void swap(smart_library &) noexcept;
};

说明

该类允许以类型安全的方式加载重载函数, 成员函数, 构造函数与变量. 它还允许覆写类, 使之以不同名称声明时也能加载.

警告

实验性功能, 依赖平台特定 C++ 修饰的不完整实现. 若遇到问题, 请提交包含修复与测试的 PR 到 https://github.com/boostorg/dll

目前已知的限制:

成员函数必须定义在类外才能导出. 即:

//not exported:
struct BOOST_SYMBOL_EXPORT my_class { void func() {} };
//exported
struct BOOST_SYMBOL_EXPORT my_class { void func(); };
void my_class::func() {}

按当前分析, 第一种版本在 MSVC 中确实会被导出. MinGW 也会导出它, 在它之前写有 BOOST_SYMBOL_EXPORT. 要在 Windows 上允许这一点, 可以使用 BOOST_DLL_MEMBER_EXPORT, 使 MinGW 与 MSVC 都能提供这些函数. 但这在 Linux 的 gcc 上不起作用.

成员的直接初始化. 在 Linux 上, 使用分配式构造函数时, 以下成员变量 i 不会被初始化:

struct BOOST_SYMBOL_EXPORT my_class { int i; my_class() : i(42) {} };

但当值在构造函数内部设置时不会出现这种情况.

  22. template<typename Alias> void add_type_alias(const std::string & name);

    该函数可用于添加类型别名.

    当要导入的类未在宿主侧声明时使用.

    示例:

    smart_library lib("test_lib.so");

lib.add_type_alias<MyAlias>("MyClass"); //when using MyAlias, the library will look for MyClass

//get the destructor of MyClass
destructor<MyAlias> dtor = lib.get_destructor<MyAlias>();

    重要

    若别名类型对导入的类来说不够大, 将导致未定义行为.

    警告

    别名只应用于类型签名, 不会替换带作用域名称中的记号.

    参数:

    name

    别名所对应类的名称.
