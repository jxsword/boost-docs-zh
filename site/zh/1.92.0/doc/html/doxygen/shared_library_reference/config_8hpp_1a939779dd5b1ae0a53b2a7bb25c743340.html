类型定义 path

path

概要

// In header: <boost/dll/config.hpp>


typedef std::conditional_t< BOOST_DLL_USE_STD_FS, std::filesystem::path, boost::filesystem::path > path;

说明

为 std::filesystem::path 的别名, 若用户定义了 BOOST_DLL_USE_STD_FS; 否则为 boost::filesystem::path 的别名.
