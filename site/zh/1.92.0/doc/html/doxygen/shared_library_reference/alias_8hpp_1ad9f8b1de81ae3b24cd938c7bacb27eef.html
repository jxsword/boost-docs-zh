宏 BOOST_DLL_ALIAS

BOOST_DLL_ALIAS — 为导出的函数或变量创建别名.

概要

// In header: <boost/dll/alias.hpp>

BOOST_DLL_ALIAS(FunctionOrVar, AliasName)

说明

在 C++ 修饰名很长时该宏很有用. 例如, 某个 void boost::foo(std::string) 函数名在修饰后会变成类似 N5boostN3foosE 的样子. 用 N5boostN3foosE 名导入函数并不友好, 尤其考虑到不同编译器有不同的修饰方案. AliasName 是不被修饰的名字, 可用作可移植的导入名.

可用于任何命名空间, 包括全局命名空间. FunctionOrVar 必须完全限定, 以便能取其地址. 允许为单个变量/函数创建多个不同别名.

确保 AliasName 在每个库/可执行文件内唯一. 全局命名空间中的函数或变量不得与 AliasName 同名.

不同翻译单元中的相同 AliasName 必须指向同一个 FunctionOrVar.

把所有别名放入二进制文件的 "boostdll" 只读节. 等价于 BOOST_DLL_ALIAS_SECTIONED(FunctionOrVar, AliasName, boostdll).

示例: 

namespace foo {
  void bar(std::string&);

  BOOST_DLL_ALIAS(foo::bar, foo_bar)
}

BOOST_DLL_ALIAS(foo::bar, foo_bar_another_alias_name)

参见: BOOST_DLL_ALIAS_SECTIONED 用于在特定节中创建别名.

参数:

AliasName

别名的名称. 必须是有效 C 标识符.

FunctionOrVar

要为其创建别名的函数或变量.
