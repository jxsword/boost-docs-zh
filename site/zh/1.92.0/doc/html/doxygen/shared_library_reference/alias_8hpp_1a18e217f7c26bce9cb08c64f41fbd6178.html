宏 BOOST_DLL_SELECTANY

BOOST_DLL_SELECTANY — 允许链接器选择该符号的任意一处出现, 而不是在链接期以 'multiple definitions' 错误失败的宏.

概要

// In header: <boost/dll/alias.hpp>

BOOST_DLL_SELECTANY

说明

由于链接器在导出弱符号方面的问题, 该宏在 Android, IBM XL C/C++ 与 MinGW+Windows 上不起作用 (参见 https://code.google.com/p/android/issues/detail?id=70206, https://sourceware.org/bugzilla/show_bug.cgi?id=17480)
