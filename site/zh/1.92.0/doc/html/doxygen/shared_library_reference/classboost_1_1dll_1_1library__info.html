类 library_info

boost::dll::library_info — 能从库或二进制文件提取不同信息的类. 目前在所有平台上支持 ELF, MACH-O 与 PE 格式.

概要

// In header: <boost/dll/library_info.hpp>


class library_info : private noncopyable {
public:

  // public member functions
  explicit library_info(const boost::dll::fs::path &, bool = true);
  std::vector< std::string > sections();
  std::vector< std::string > symbols();
  std::vector< std::string > symbols(const char *);
  std::vector< std::string > symbols(const std::string &);
};

说明

library_info 公有成员函数

  1. explicit library_info(const boost::dll::fs::path & library_path, 
                      bool throw_if_not_native_format = true);

    打开指定路径的文件, 并为信息提取做准备.

    参数:

    library_path

    要从中提取信息的二进制文件的路径.

    throw_if_not_native_format

    若操作系统不支持该文件格式, 则抛出异常.

    抛出:

    		 基于 std::exception 的异常. 
  2. std::vector< std::string > sections();

    返回:

    二进制文件中存在的节的列表.

    抛出:

    		 基于 std::exception 的异常. 
  3. std::vector< std::string > symbols();

    返回:

    二进制文件中存在的所有节的可导出符号的列表.

    抛出:

    		 基于 std::exception 的异常. 
  4. std::vector< std::string > symbols(const char * section_name);

    这是一个为便利而提供的重载成员函数. 它与上述函数的区别仅在于所接受的参数.

    参数:

    section_name

    要从中返回符号名的节的名称.

    返回:

    指定节中的符号列表.

    抛出:

    		 基于 std::exception 的异常. 
  5. std::vector< std::string > symbols(const std::string & section_name);
