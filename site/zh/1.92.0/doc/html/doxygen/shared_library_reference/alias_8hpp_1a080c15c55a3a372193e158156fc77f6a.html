宏 BOOST_DLL_FORCE_NO_WEAK_EXPORTS

BOOST_DLL_FORCE_NO_WEAK_EXPORTS

概要

// In header: <boost/dll/alias.hpp>

BOOST_DLL_FORCE_NO_WEAK_EXPORTS

说明

定义此宏以禁用导出弱符号并开始使用 BOOST_DLL_FORCE_ALIAS_INSTANTIATION. 这可用于规避链接器问题, 或测试程序与不支持导出弱符号的链接器的兼容性.
