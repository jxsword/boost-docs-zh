类模板 string_path

boost::property_tree::string_path — 默认路径类. 路径是值的序列. 各组值由分隔符值分隔, 分隔符默认为 '.' 转换为序列的值类型. 然后将该组值传给转换器以得到键.

概要

// In header: <boost/property_tree/string_path.hpp>

template<typename String, typename Translator> 
class string_path {
public:
  // types
  typedef Translator::external_type key_type; 
  typedef String::value_type        char_type;

  // private member functions
   BOOST_STATIC_ASSERT((is_same< String, typename Translator::internal_type >::value));
  s_c_iter cstart() const;

  // public member functions
  explicit string_path(char_type = char_type('.'));
  string_path(const String &, char_type = char_type('.'), 
              Translator = Translator());
  string_path(const char_type *, char_type = char_type('.'), 
              Translator = Translator());
  string_path(const string_path &);
  string_path & operator=(const string_path &);
  key_type reduce();
  bool empty() const;
  bool single() const;
  char_type separator() const;
  std::string dump() const;
  string_path & operator/=(const string_path &);

  // friend functions
  string_path operator/(string_path, const string_path &);
};

说明

如果以 std::string 和 id_translator<std::string> 实例化, 则它接受形如 "one.two.three.four" 的路径.

模板参数

  1. typename String

    任何 Sequence. 如果该序列不支持随机访问迭代, 则路径拼接假定在末尾插入会保持迭代器有效.

  2. typename Translator

    internal_type == String 的转换器.

string_path 私有成员函数

  1.  BOOST_STATIC_ASSERT((is_same< String, typename Translator::internal_type >::value));
  2. s_c_iter cstart() const;

string_path 公有成员函数

  1. explicit string_path(char_type separator = char_type('.'));
    创建空路径.
  2. string_path(const String & value, char_type separator = char_type('.'), 
            Translator tr = Translator());
    通过解析给定字符串创建路径.

    参数:

    value

    描述路径的序列 (可含分隔符), 例如 "one.two.three".

    separator

    解析时使用的分隔符. 默认为 '.'.

    tr

    此路径用于将各个部分转换为键的转换器.

    		 
  3. string_path(const char_type * value, char_type separator = char_type('.'), 
            Translator tr = Translator());
    通过解析给定字符串创建路径.

    参数:

    value

    以零结尾的值数组. 仅当零结尾对你的类型有意义且你的序列支持由此构造时使用. 适用于字符串字面量.

    separator

    解析时使用的分隔符. 默认为 '.'.

    tr

    此路径用于将各个部分转换为键的转换器.

    		 
  4. string_path(const string_path & o);
  5. string_path & operator=(const string_path & o);
  6. key_type reduce();
    从路径前端取下一个元素并返回它.
  7. bool empty() const;
    测试路径是否为空.
  8. bool single() const;
    测试路径是否只含单个元素, 即不含分隔符.
  9. char_type separator() const;
    获取此路径使用的分隔符.
  10. std::string dump() const;
  11. string_path & operator/=(const string_path & o);
    将另一个路径附加到此路径之后.

    要求:

    o 的分隔符与此路径的相同, 或 o 没有分隔符

string_path 友元函数

  1. string_path operator/(string_path p1, const string_path & p2);
    拼接两个路径组件.
