函数 get

boost::mpi::get — 返回一个属性映射, 把通信器图拓扑中的顶点映射到它们的索引值.

概要

// In header: <boost/mpi/graph_communicator.hpp>


identity_property_map get(vertex_index_t, const graph_communicator &);

说明

由于顶点就是通信器中的秩, 返回的属性映射是恒等属性映射.
