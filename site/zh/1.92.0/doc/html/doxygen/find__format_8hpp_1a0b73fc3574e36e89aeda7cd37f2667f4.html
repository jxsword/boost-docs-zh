函数模板 find_format_copy

boost::find_format_copy — 通用替换算法.

概要

// In header: <boost/algorithm/string/find_format.hpp>


template<typename OutputIteratorT, typename RangeT, typename FinderT, 
         typename FormatterT> 
  OutputIteratorT 
  find_format_copy(OutputIteratorT Output, const RangeT & Input, 
                   FinderT Finder, FormatterT Formatter);

说明

使用查找器搜索子串. 使用格式化器格式化该子串并替换输入中的内容. 结果是输入的修改副本. 它作为序列返回或复制到输出迭代器.

注释

此函数的第二个变体提供强异常安全保证

参数:

Output

结果将被复制到的输出迭代器

Input

一个输入序列

Finder

用于搜索要替换的匹配的查找器对象

Formatter

用于格式化匹配的格式化器对象

返回:

指向最后插入字符之后的输出迭代器, 或输入的修改副本
