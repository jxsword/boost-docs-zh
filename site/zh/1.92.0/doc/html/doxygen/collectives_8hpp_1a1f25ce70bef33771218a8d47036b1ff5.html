函数 reduce

boost::mpi::reduce — 将每个进程存储的值合并为根进程处的单一值.

概要

// In header: <boost/mpi/collectives.hpp>


template<typename T, typename Op> 
  void reduce(const communicator & comm, const T & in_value, T & out_value, 
              Op op, int root);
template<typename T, typename Op> 
  void reduce(const communicator & comm, const T & in_value, Op op, int root);
template<typename T, typename Op> 
  void reduce(const communicator & comm, const T * in_values, int n, 
              T * out_values, Op op, int root);
template<typename T, typename Op> 
  void reduce(const communicator & comm, const T * in_values, int n, Op op, 
              int root);

说明

reduce 是一种集合算法, 它将每个进程存储的值合并为 root 处的单一值. 值可以任意方式合并, 通过函数对象指定. 值的类型 T 可以是可序列化的类型或具有关联 MPI 数据类型的类型. 可以把此操作看作一次 gather, 目标为 root, 随后对收集到的值执行 std::accumulate(), 并使用运算 op.

当类型 T 具有关联的 MPI 数据类型时, 此例程调用 MPI_Reduce 执行归约. 如果可能, 将使用内建 MPI 操作; 否则, reduce() 将为 MPI_Reduce 调用创建自定义 MPI_Op.

参数:

comm

发生归约的通信器.

in_value

要与每个其他进程的本地值合并的本地值. 对于归约数组, in_values 包含指向本地值的指针. 此时, n 是要归约的值数量. 归约对每个 n 值独立进行, 该值由 in_values 所引用. 例如, 对 n 值的数组调用 reduce, 就像把 reduce 分开调用 n 次, in_values 与 out_values 中的每个位置各一次.

out_value

将接收归约运算的结果, 但仅对 root 进程如此. 非根进程可以省略此参数; 如果选择提供, 它将保持不变. 对于归约数组, out_values 包含指向输出值存储位置的指针.

op

将类型 T 的两个值合并为第三个类型 T 值的二元运算. 对于具有关联 MPI 数据类型的类型 T, op 要么被转换为 MPI_Op (通过 MPI_Op_create), 要么 (如果可能) 直接映射到内建 MPI 操作. 更多细节见 is_mpi_op, 位于 operations.hpp 头文件中. 对于任何非内建操作, 交换性将由 is_commmutative 特征决定 (也在 operations.hpp 中): 鼓励用户将可交换操作标记为可交换, 因为这给实现提供了更大的余地来优化归约操作.

root

将接收最终合并值的进程 ID 号. 此值在所有进程上必须相同.
