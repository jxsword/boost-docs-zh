函数 get_capture_stacktraces_at_throw

boost::stacktrace::this_thread::get_capture_stacktraces_at_throw

概要

// In header: <boost/stacktrace/this_thread.hpp>


bool get_capture_stacktraces_at_throw();

说明

若未调用过 set_capture_stacktraces_at_throw(false) 且 boost_stacktrace_from_exception 已链接到当前二进制文件, 则返回 true.

实现 https://wg21.link/p2370r1

返回:

当前执行线程是否启用了栈跟踪捕获, 以及 boost::stacktrace::basic_stacktrace::from_current_exception 是否可能返回非空栈跟踪.
