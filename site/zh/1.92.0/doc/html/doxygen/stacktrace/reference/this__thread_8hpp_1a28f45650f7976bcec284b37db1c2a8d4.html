函数 set_capture_stacktraces_at_throw

boost::stacktrace::this_thread::set_capture_stacktraces_at_throw — 以等于 true 的 enable 参数调用该函数时, 若 boost_stacktrace_from_exception 库已链接到当前二进制文件, 则启用当前执行线程在异常对象构造时捕获栈跟踪; 否则禁用.

概要

// In header: <boost/stacktrace/this_thread.hpp>


void set_capture_stacktraces_at_throw(bool enable = true);
