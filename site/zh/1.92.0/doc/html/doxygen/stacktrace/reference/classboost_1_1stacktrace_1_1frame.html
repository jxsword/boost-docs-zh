类 frame

boost::stacktrace::frame — 存储帧/函数地址并可在运行期获取其相关信息的类.

概要

// In header: <boost/stacktrace/detail/frame_decl.hpp>


class frame {
public:
  // types
  typedef unspecified native_frame_ptr_t;

  // public member functions
  frame() noexcept;
  frame(const frame &) = default;
  frame & operator=(const frame &) = default;
  explicit frame(native_frame_ptr_t) noexcept;
  template<typename T> explicit frame(T *) noexcept;
  std::string name() const;
  native_frame_ptr_t address() const noexcept;
  std::string source_file() const;
  std::size_t source_line() const;
  explicit constexpr operator bool() const noexcept;
  bool empty() const noexcept;
};

说明

frame 公有成员函数

  1. frame() noexcept;
    构造引用 NULL 地址的 frame. 调用 source_file() 与 source_line() 将返回空字符串. 调用 source_line() 将返回 0.

    复杂度: O(1).

    异步处理器安全性: 安全.

    抛出:

    		 无. 
  2. frame(const frame &) = default;
    拷贝构造 frame.

    复杂度: O(1).

    异步处理器安全性: 安全.

    抛出:

    		 无. 
  3. frame & operator=(const frame &) = default;
    拷贝赋值 frame.

    复杂度: O(1).

    异步处理器安全性: 安全.

    抛出:

    		 无. 
  4. explicit frame(native_frame_ptr_t addr) noexcept;
    构造引用 addr 的 frame, 之后可用平台特定特性生成关于该地址的信息.

    复杂度: O(1).

    异步处理器安全性: 安全.

    抛出:

    		 无. 
  5. template<typename T> explicit frame(T * function_addr) noexcept;
    构造引用 function_addr 的 frame, 之后可用平台特定特性生成关于该函数的信息.

    复杂度: O(1).

    异步处理器安全性: 安全.

    抛出:

    		 无. 
  6. std::string name() const;

    复杂度: 未知 (大量平台特定工作).

    异步处理器安全性: 不安全.

    返回:

    帧的名称 (人类可读形式的函数名).

    抛出:

    		 若内存不足以构造结果字符串, 则抛出 std::bad_alloc. 
  7. native_frame_ptr_t address() const noexcept;

    复杂度: O(1).

    异步处理器安全性: 安全.

    返回:

    帧函数的地址.

    抛出:

    		 无. 
  8. std::string source_file() const;

    复杂度: 未知 (大量平台特定工作).

    异步处理器安全性: 不安全.

    返回:

    帧函数定义所在源文件的路径. 若 this->source_line() == 0, 返回空字符串.

    抛出:

    		 若内存不足以构造结果字符串, 则抛出 std::bad_alloc. 
  9. std::size_t source_line() const;

    复杂度: 未知 (大量平台特定工作).

    异步处理器安全性: 不安全.

    返回:

    帧函数定义所在源文件中的代码行.

    抛出:

    		 若内存不足以构造内部所需字符串, 则抛出 std::bad_alloc. 
  10. explicit constexpr operator bool() const noexcept;
    检查 frame 是否未引用 NULL 地址.

    复杂度: O(1)

    异步处理器安全性: 安全.

    返回:

    true, 若 this->address() != 0

    		 
  11. bool empty() const noexcept;
    检查 frame 是否引用 NULL 地址.

    复杂度: O(1)

    异步处理器安全性: 安全.

    返回:

    true, 若 this->address() == 0
