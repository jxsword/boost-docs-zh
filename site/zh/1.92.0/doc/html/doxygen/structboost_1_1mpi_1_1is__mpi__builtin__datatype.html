结构体模板 is_mpi_builtin_datatype

boost::mpi::is_mpi_builtin_datatype — 判断给定 C++ 类型是否存在内建 MPI 数据类型的类型特征.

概要

// In header: <boost/mpi/datatype.hpp>

template<typename T> 
struct is_mpi_builtin_datatype : public boost::mpl::or_< is_mpi_integer_datatype< T >, is_mpi_floating_point_datatype< T >, is_mpi_logical_datatype< T >, is_mpi_complex_datatype< T >, is_mpi_byte_datatype< T > >
{
};

说明

该类型特征判断何时存在从 C++ 类型到 MPI 类型的直接映射. 例如, C++ 的 int 类型直接映射到 MPI 类型 MPI_INT. 当从类型 T 到某个 MPI 类型存在直接映射时, is_mpi_builtin_datatype 将派生自 mpl::true_, 且该 MPI 数据类型可通过 get_mpi_datatype 访问.

一般而言, 用户无需特化此特征. 但是, 如果你有一个只能直接映射到 MPI 内建类型之一的额外 C++ 类型, 请特化此特征或与 MPI 数据类型类别对应的特征之一 (is_mpi_integer_datatype、is_mpi_floating_point_datatype、is_mpi_logical_datatype、is_mpi_complex_datatype 或 is_mpi_builtin_datatype) . is_mpi_builtin_datatype 在与 MPI 数据类型类别对应的任一特征派生 mpl::true_ 时派生 mpl::true_.
