结构体 regex_error

boost::xpressive::regex_error — 类 regex_error 定义了作为异常抛出、用于报告从表示正则表达式的字符串到有限状态机转换过程中错误的对象的类型.

概要

// In header: <boost/xpressive/regex_error.hpp>


struct regex_error : public std::runtime_error, public boost::exception {

  // public member functions
  explicit regex_error(regex_constants::error_type, char const * = "");
  regex_constants::error_type code() const;
  virtual ~regex_error();
};

说明

regex_error 公有成员函数

    构造类 regex_error 的对象.

    参数:

    code

    此 regex_error 所表示的 error_type.

    str

    此 regex_error 的消息字符串.

    后置条件:

    code() == code

    error_type 值的访问器

    返回:

    类 regex_error 的析构函数
