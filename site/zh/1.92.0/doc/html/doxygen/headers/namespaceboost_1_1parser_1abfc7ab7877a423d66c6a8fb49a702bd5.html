函数模板 if_

boost::parser::if_

概要

// In header: <boost/parser/parser.hpp>


template<typename Predicate> auto if_(Predicate pred);

说明

返回一个 if_directive, 若给定谓词 pred 为 false 则失败, 否则应用另一个解析器. 例如在 if_(pred)[p] 中, p 仅在 pred 为 true 时才被应用.
