类模板 linear_congruential_engine

boost::random::linear_congruential_engine

说明

类模板 linear_congruential_engine 的实例化是 伪随机数生成器 的模型. 线性同余伪随机数生成器见如下文献:

"Mathematical methods in large-scale computing units", D. H. Lehmer, Proc. 2nd Symposium on Large-Scale Digital Calculating Machines, Harvard University Press, 1951, pp. 141-146

设 x(n) 表示某伪随机数生成器返回的数列. 对线性同余生成器有 x(n+1) := (a * x(n) + c) mod m. 生成器的参数为 x(0)、a、c、m. 模板参数 IntType 应为一个整型, 其大小必须足以容纳 a、c 和 m 的值. 模板参数 a 与 c 必须小于 m.

注释: 生成器的质量在很大程度上取决于参数的选择. 用户代码应改用参数设置合理的生成器, 例如 minstd_rand.

linear_congruential_engine 公有成员函数

  1. linear_congruential_engine();

    构造一个 linear_congruential_engine, 使用默认种子

  2. explicit linear_congruential_engine(IntType x0);

    构造一个 linear_congruential_engine, 以 x0 播种.

  3. template<typename SeedSeq> explicit linear_congruential_engine(SeedSeq & seq);

    构造一个 linear_congruential_engine, 以调用 seq.generate() 所产生的值播种.

  4. template<typename It> linear_congruential_engine(It & first, It last);

    构造一个 linear_congruential_engine, 以取自迭代器范围 [first, last) 的值播种, 并调整 first 使其指向最后一个所用元素之后的元素. 若元素不足, 则抛出 std::invalid_argument.

    first 和 last 必须是输入迭代器.

  5. void seed();

    调用 seed(default_seed)

  6. void seed(IntType x0_);

    若 c mod m 为零且 x0 mod m 为零, 则将生成器的当前值改为 1. 否则将其改为 x0 mod m. 若 c 为零, 则 [1,m) 范围内不同的种子将使生成器处于不同的状态. 若 c 不为零, 则该范围为 [0,m).

  7. template<typename SeedSeq> void seed(SeedSeq & seq);

    使用来自 SeedSeq 的值播种一个 linear_congruential_engine.

  8. template<typename It> void seed(It & first, It last);

    以取自迭代器范围 [first, last) 的值播种一个 linear_congruential_engine, 并调整 first 使其指向最后一个所用元素之后的元素. 若元素不足, 则抛出 std::invalid_argument.

    first 和 last 必须是输入迭代器.

  9. IntType operator()();

    返回 linear_congruential_engine 的下一个值.

  10. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

  11. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

linear_congruential_engine 公有静态函数

  1. static result_type min();

    返回 linear_congruential_engine 可产生的最小值.

  2. static result_type max();

    返回 linear_congruential_engine 可产生的最大值.
