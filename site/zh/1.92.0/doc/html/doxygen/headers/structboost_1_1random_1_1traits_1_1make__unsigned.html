结构体模板 make_unsigned

boost::random::traits::make_unsigned — 将实参类型 T 转换为无符号类型.

概要

// In header: <boost/random/traits.hpp>

template<typename T> 
struct make_unsigned {
};

说明

此特征有一个成员 type, 即与 T 对应的无符号类型. 注意, 若 T 是有符号的, 则成员 type 应定义一个比 T 多一位精度的类型. 对于内建类型, 此特征默认为 boost::make_unsigned<T>::type. 对于用户定义类型, 它仅断言实参类型 T 是无符号整数 (使用 std::numeric_limits). 其他情形可提供用户定义的特化.
