类 random_device

boost::random_device

概要

// In header: <boost/random/random_device.hpp>


class random_device : private noncopyable {
public:
  // types
  typedef unsigned int result_type;

  // public static functions
  static result_type min();
  static result_type max();

  // public member functions
  random_device();
  explicit random_device(const std::string &);
  ~random_device();
  double entropy() const;
  unsigned int operator()();
  template<typename Iter> void generate(Iter, Iter);

  // public data members
  static const bool has_fixed_range;
};

说明

类 random_device 是 非确定性随机数生成器 的模型. 它使用一个或多个由实现定义的随机过程来产生均匀分布的非确定性随机数序列. 在无法提供非确定性随机数生成器的环境中, 不应实现类 random_device. 参见

"Randomness Recommendations for Security", D. Eastlake, S. Crocker, J. Schiller, Network Working Group, RFC 1750, December 1994

以作进一步讨论.

注释

某些操作系统对计算机硬件的抽象程度使得难以以非侵入方式监视随机过程. 不过, 有几个操作系统确实为此提供了专用设备. 仅用标准 C++ 似乎无法模拟这一功能, 因此用户应注意该类可能并非在所有平台上都可用.

Linux 平台实现说明

在 Linux 操作系统上, token 被解释为一个文件系统路径. 假定该路径表示一个产生非确定性随机数流的操作系统伪设备. 该伪设备不应发出错误或文件结束信号, 否则将抛出 std::ios_base::failure. 默认情况下, random_device 使用 /dev/urandom 伪设备获取随机数. 另一个选择是指定 /dev/random 伪设备, 若熵池没有更多可用随机位, 它会在读取时阻塞.

Windows 平台实现说明

在 Windows 操作系统上, token 被解释为一个加密服务提供程序的名称. 默认情况下 random_device 使用 MS_DEF_PROV.

性能

测试程序 nondet_random_speed.cpp 在紧密循环中测量上述算法的 random_device.hpp 实现的执行时间. 性能评估环境为 Intel(R) Core(TM) i7 CPU Q 840 @ 1.87GHz, 1867 Mhz, 搭配 Visual C++ 2010 与 Microsoft Windows 7 Professional, 以及 gcc 4.4.5 与 Ubuntu Linux 2.6.35-25-generic.

平台 每次调用耗时 [微秒]
Windows 2.9
Linux 1.7

测量误差估计为 +/- 1 usec.

random_device 公有静态函数

  1. static result_type min();

    返回 random_device 可产生的最小值.

  2. static result_type max();

    返回 random_device 可产生的最大值.

random_device 公有成员函数

  1. random_device();

    构造一个 random_device, 可选用默认设备.

  2. explicit random_device(const std::string & token);

    构造一个 random_device, 可选用给定的 token 作为访问说明 (例如 URL), 指向某个由实现定义的用于监视随机过程的服务.

  3. ~random_device();
  4. double entropy() const;

    返回: 对 operator() 所返回随机数的熵估计, 范围从 min() 到 log2( max()+1). 确定性随机数生成器 (例如伪随机数引擎) 的熵为 0.

    抛出: Nothing.

  5. unsigned int operator()();

    返回 [min, max] 范围内的随机值.

  6. template<typename Iter> void generate(Iter begin, Iter end);

    用随机 32 位值填充一个范围.
