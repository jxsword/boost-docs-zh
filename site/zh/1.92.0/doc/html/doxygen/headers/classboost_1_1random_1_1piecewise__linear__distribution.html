说明

类 piecewise_linear_distribution 是一个 随机分布 模型.

piecewise_linear_distribution 公有成员函数

  1. piecewise_linear_distribution();

    创建一个新的 piecewise_linear_distribution, 其产生在 [0, 1) 范围内均匀分布的值.

  2. template<typename IntervalIter, typename WeightIter> 
  piecewise_linear_distribution(IntervalIter first_interval, 
                                IntervalIter last_interval, 
                                WeightIter first_weight);

    由包含区间边界与边界处权重的两个迭代器范围构造一个 piecewise_linear_distribution. 若边界少于两个, 则等价于默认构造函数, 并创建产生在 [0, 1) 范围内均匀分布的值的分布.

    区间边界值必须严格递增, 且权重数必须等于区间边界数. 多余的权重将被忽略.

    例如,

    double intervals[] = { 0.0, 1.0, 2.0 };
double weights[] = { 0.0, 1.0, 0.0 };
piecewise_constant_distribution<> dist(
    &intervals[0], &intervals[0] + 3, &weights[0]);

    产生一个三角形分布.

  3. template<typename T, typename F> 
  piecewise_linear_distribution(std::initializer_list< T > il, F f);

    由包含区间边界的 initializer_list 与指定权重的一元函数构造一个 piecewise_linear_distribution. 每个权重通过在相应区间边界处调用该函数确定.

    若 initializer_list 少于两个元素, 则等价于默认构造函数, 该分布将产生在 [0, 1) 范围内均匀分布的值.

  4. template<typename IntervalsRange, typename WeightsRange> 
  piecewise_linear_distribution(const IntervalsRange & intervals_arg, 
                                const WeightsRange & weights_arg);

    由保存区间边界与权重的 Boost.Range 范围构造一个 piecewise_linear_distribution. 若区间边界少于两个, 则等价于默认构造函数, 该分布将产生在 [0, 1) 范围内均匀分布的值. 权重数必须等于区间边界数.

  5. template<typename F> 
  piecewise_linear_distribution(std::size_t nw, RealType xmin, RealType xmax, 
                                F f);

    构造一个近似某函数的 piecewise_linear_distribution. 分布范围为 [xmin, xmax). 该范围被划分为 nw 个等长区间, 权重通过在区间边界处调用一元函数 f 求得.

  6. explicit piecewise_linear_distribution(const param_type & param);

    由其参数构造一个 piecewise_linear_distribution.

  7. template<typename URNG> RealType operator()(URNG & urng) const;

    返回按 piecewise_linear_distribution 参数分布的值.

  8. template<typename URNG> 
  RealType operator()(URNG & urng, const param_type & param) const;

    返回按 param 指定参数分布的值.

  9. result_type min() const;

    返回分布能产生的最小值.

  10. result_type max() const;

    返回分布能产生的最大值.

  11. std::vector< RealType > densities() const;

    返回一个 vector, 包含区间边界处的概率密度.

  12. std::vector< RealType > intervals() const;

    返回一个包含区间边界的 vector.

  13. param_type param() const;

    返回分布的参数.

  14. void param(const param_type & param);

    设置分布的参数.

  15. void reset();

    效果: 调用 reset 之后, 分布的后续使用不依赖于任何引擎在调用 reset 之前产生的值.

    如果传入相同的生成器时两个分布可能返回不同的值序列, 则返回 true.
