结构体模板 if_directive

boost::parser::if_directive

概要

// In header: <boost/parser/parser.hpp>

template<typename Predicate> 
struct if_directive {

  // public member functions
  template<typename Parser2> 
    auto operator[](parser_interface< Parser2 >) const noexcept;

  // public data members
  Predicate pred_;
};

说明

将序列解析器 (其第一个解析器是带谓词的 epsilon_parser) 表示为指令 (例如 if_(pred)[p]).

if_directive 公有成员函数

  1. template<typename Parser2> 
  auto operator[](parser_interface< Parser2 > rhs) const noexcept;
