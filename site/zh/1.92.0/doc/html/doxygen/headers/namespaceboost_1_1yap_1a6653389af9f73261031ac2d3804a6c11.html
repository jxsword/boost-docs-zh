函数 op_string

boost::yap::op_string

概要

// In header: <boost/yap/print.hpp>


char const * op_string(expr_kind kind);

说明

返回 char const * 字符串, 即与 kind 关联的 C++ 运算符的拼写. 对于非运算符种类 expr_kind::expr_ref 与 expr_kind::terminal, 它分别返回特殊值 "ref" 与 "term".
