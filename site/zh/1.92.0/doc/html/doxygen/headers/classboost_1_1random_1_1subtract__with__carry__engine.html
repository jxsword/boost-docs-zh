类模板 subtract_with_carry_engine

boost::random::subtract_with_carry_engine

概要

// In header: <boost/random/subtract_with_carry.hpp>

template<typename IntType, std::size_t w, std::size_t s, std::size_t r> 
class subtract_with_carry_engine {
public:
  // types
  typedef IntType result_type;

  // public member functions
  subtract_with_carry_engine();
  explicit subtract_with_carry_engine(IntType);
  template<typename SeedSeq> explicit subtract_with_carry_engine(SeedSeq &);
  template<typename It> subtract_with_carry_engine(It &, It);
  void seed();
  void seed(IntType);
  template<typename SeedSeq> void seed(SeedSeq &);
  template<typename It> void seed(It &, It);
  result_type operator()();
  void discard(boost::uintmax_t);
  template<typename It> void generate(It, It);

  // public static functions
  static result_type min();
  static result_type max();

  // friend functions
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, 
               const subtract_with_carry_engine &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, 
               const subtract_with_carry_engine &);
  bool operator==(const subtract_with_carry_engine &, 
                  const subtract_with_carry_engine &);
  bool operator!=(const subtract_with_carry_engine &, 
                  const subtract_with_carry_engine &);

  // public data members
  static const std::size_t word_size;
  static const std::size_t long_lag;
  static const std::size_t short_lag;
  static const uint32_t default_seed;
  static const bool has_fixed_range;
  static const result_type modulus;
};

说明

subtract_with_carry_engine 的实例化是 伪随机数生成器 的模型. 算法见如下文献:

"A New Class of Random Number Generators", George Marsaglia and Arif Zaman, Annals of Applied Probability, Volume 1, Number 3 (1991), 462-480.

subtract_with_carry_engine 公有成员函数

  1. subtract_with_carry_engine();

    构造一个新的 subtract_with_carry_engine, 并以默认种子播种.

  2. explicit subtract_with_carry_engine(IntType value);

    构造一个新的 subtract_with_carry_engine, 并以 value 播种.

  3. template<typename SeedSeq> explicit subtract_with_carry_engine(SeedSeq & seq);

    构造一个新的 subtract_with_carry_engine, 并以 seq.generate() 产生的值播种.

  4. template<typename It> subtract_with_carry_engine(It & first, It last);

    构造一个新的 subtract_with_carry_engine, 并以范围中的值播种. first 被更新为指向最后所消费值之后的位置. 若范围中没有足够的元素填满生成器的整个状态, 则抛出 std::invalid_argument.

  5. void seed();

    用默认种子为生成器播种.

  6. void seed(IntType value);
  7. template<typename SeedSeq> void seed(SeedSeq & seq);

    用 seq.generate() 产生的值为生成器播种.

  8. template<typename It> void seed(It & first, It last);

    以范围中的值播种该生成器. 更新 first 使其指向最后所消费值之后的位置. 若范围中没有足够的元素填满生成器的整个状态, 则抛出 std::invalid_argument.

  9. result_type operator()();

    返回生成器的下一个值.

  10. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

  11. template<typename It> void generate(It first, It last);

    用随机值填充一个范围.

subtract_with_carry_engine 公有静态函数

  1. static result_type min();

    返回生成器可产生的最小值.

  2. static result_type max();

    返回生成器可产生的最大值.

subtract_with_carry_engine 友元函数

  1. template<typename CharT, typename Traits>

             const subtract_with_carry_engine & f);

  4. bool operator!=(const subtract_with_carry_engine & lhs,
