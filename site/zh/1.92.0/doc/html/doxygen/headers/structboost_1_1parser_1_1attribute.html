结构体模板 attribute

boost::parser::attribute

概要

// In header: <boost/parser/parser.hpp>

template<typename R, typename Parser> 
struct attribute {
  // types
  typedef unspecified initial_type;
  typedef unspecified type;        
};

说明

一个类型特征, 求值为解析器 Parser 解析范围 R 时的属性类型, 如同调用 parse(r, parser) (使用某个 R r 与 Parser parser). 注意这意味着指向以空字符结尾的字符串的指针是 R 支持的类型. 结果不会包装在 std::optional 中, 而调用 parse() 的结果则会. 若 Parser 不产生属性, 则结果是无属性哨兵类型 none.
