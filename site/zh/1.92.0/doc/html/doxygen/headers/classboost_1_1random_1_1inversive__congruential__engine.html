说明

类模板 inversive_congruential_engine 的实例化是 伪随机数生成器 的模型. 它使用的逆同余算法 (ICG) 见如下文献:

"Inversive pseudorandom number generators: concepts, results and links", Peter Hellekalek, In: "Proceedings of the 1995 Winter Simulation Conference", C. Alexopoulos, K. Kang, W.R. Lilegdon, and D. Goldsman (editors), 1995, pp. 255-262. ftp://random.mat.sbg.ac.at/pub/data/wsc95.ps

输出序列由 x(n+1) = (a*inv(x(n)) - b) (mod p) 定义, 其中 x(0)、a、b 与素数 p 是生成器的参数. 表达式 inv(k) 表示 k 在模 p 整数域中的乘法逆元, 且 inv(0) := 0.

模板参数 IntType 应为一个有符号整型, 其大小足以容纳 p; a、b 和 p 是生成器的参数. 模板参数 val 是由 validation 检查的验证值.

注释

当前实现使用欧几里得算法计算乘法逆元. 因此, 逆同余生成器比其他生成器慢约 10-20 倍 (见 section"performance"). 不过该论文提到减速仅为 3 倍, 所以欧几里得算法在计算乘法逆元方面可能并非最优.

inversive_congruential_engine 公有成员函数

  1. inversive_congruential_engine();

    构造一个 inversive_congruential_engine, 以默认种子播种.

  2. explicit inversive_congruential_engine(IntType x0);

    构造一个 inversive_congruential_engine, 以 x0 播种.

  3. template<typename SeedSeq> 
  explicit inversive_congruential_engine(SeedSeq & seq);

    构造一个 inversive_congruential_engine, 以调用 seq.generate() 所产生的值播种.

  4. template<typename It> inversive_congruential_engine(It & first, It last);

    构造一个 inversive_congruential_engine, 以取自迭代器范围 [first, last) 的值播种, 并调整 first 使其指向最后一个所用元素之后的元素. 若元素不足, 则抛出 std::invalid_argument.

    first 和 last 必须是输入迭代器.

  5. void seed();

    调用 seed(default_seed)

  6. void seed(IntType x0);

    若 c mod m 为零且 x0 mod m 为零, 则将生成器的当前值改为 1. 否则将其改为 x0 mod m. 若 c 为零, 则 [1,m) 范围内不同的种子将使生成器处于不同的状态. 若 c 不为零, 则该范围为 [0,m).

  7. template<typename SeedSeq> void seed(SeedSeq & seq);

    使用来自 SeedSeq 的值播种一个 inversive_congruential_engine.

  8. template<typename It> void seed(It & first, It last);

    以取自迭代器范围 [first, last) 的值播种一个 inversive_congruential_engine, 并调整 first 使其指向最后一个所用元素之后的元素. 若元素不足, 则抛出 std::invalid_argument.

    first 和 last 必须是输入迭代器.

  9. IntType operator()();

    返回生成器的下一个输出.

  10. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

  11. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

    如果两个生成器将产生不同的输出序列则返回 true.
