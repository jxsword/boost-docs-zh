boost::random::weibull_distribution

template<typename RealType = double> 
class weibull_distribution {
public:
  // types
  typedef RealType result_type;
  typedef RealType input_type;

说明

Weibull 分布是带两个参数 a 与 b 的实数值分布, 产生 >= 0 的值.

它具有 .

weibull_distribution 公有成员函数

  1. explicit weibull_distribution(RealType a = 1.0, RealType b = 1.0);

    由 "a" 与 "b" 参数构造一个 weibull_distribution.

    要求: a > 0 && b > 0

  2. explicit weibull_distribution(const param_type & param);

    从参数构造 weibull_distribution.

  3. template<typename URNG> RealType operator()(URNG & urng) const;

    返回按 weibull_distribution 分布的随机变量.

  4. template<typename URNG> 
  RealType operator()(URNG & urng, const param_type & param) const;

    返回服从 Weibull 分布的随机变量, 参数由 param 指定.

  5. RealType a() const;

    返回分布的 "a" 参数.

  6. RealType b() const;

    返回分布的 "b" 参数.

  7. RealType min() const;

    返回分布能产生的最小值.

  8. RealType max() const;

    返回分布能产生的最大值.

  9. param_type param() const;

    返回分布的参数.

  10. void param(const param_type & param);

    设置分布的参数.

  11. void reset();

    效果: 调用 reset 之后, 分布的后续使用不依赖于任何引擎在调用 reset 之前产生的值.

weibull_distribution 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const weibull_distribution & wd);

    把 weibull_distribution 写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const weibull_distribution & wd);

    读取 weibull_distribution, 来源为 std::istream.

  3. bool operator==(const weibull_distribution & lhs, 
                const weibull_distribution & rhs);

    如果给定相同的生成器时两个 weibull_distribution 实例将返回相同的值序列, 则返回 true.

  4. bool operator!=(const weibull_distribution & lhs, 
                const weibull_distribution & rhs);

    如果给定相同的生成器时两个 weibull_distribution 实例将返回不同的值序列, 则返回 true.
