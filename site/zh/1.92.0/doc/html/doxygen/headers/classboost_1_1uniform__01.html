类模板 uniform_01

boost::uniform_01

概要

// In header: <boost/random/uniform_01.hpp>

template<typename RealType = double> 
class uniform_01 {
public:
  // types
  typedef RealType input_type; 
  typedef RealType result_type;

  // public member functions
  result_type min() const;
  result_type max() const;
  void reset();
  template<typename Engine> result_type operator()(Engine &);
};

说明

分布函数 uniform_01 是 随机分布 的模型. 每次调用时, 它返回在 [0..1) 范围内均匀分布的随机浮点值.

模板参数 RealType 应表示一个类浮点值类型, 支持二元运算符 +、- 和 /.

注释: 当前实现有缺陷, 因为它可能无法用随机位填满整个尾数. 我不确定如何高效地用一个 (尚待发明的) boost::bigfloat 类来填充随机位. 也许该引入一个 traits 类了.

uniform_01 公有成员函数

  1. result_type min() const;
  2. result_type max() const;
  3. void reset();
  4. template<typename Engine> result_type operator()(Engine & eng);
