类模板 discrete_distribution

boost::random::discrete_distribution

概要

// In header: <boost/random/discrete_distribution.hpp>

template<typename IntType = int, typename WeightType = double> 
class discrete_distribution {
public:
  // types
  typedef WeightType input_type; 
  typedef IntType    result_type;

  // member classes/structs/unions

  class param_type {
  public:
    // types
    typedef discrete_distribution distribution_type;

    // public member functions
    param_type();
    template<typename Iter> param_type(Iter, Iter);
    param_type(const std::initializer_list< WeightType > &);
    template<typename Range> explicit param_type(const Range &);
    template<typename Func> param_type(std::size_t, double, double, Func);
    std::vector< WeightType > probabilities() const;

    // friend functions
    template<typename CharT, typename Traits> 
      std::basic_ostream< CharT, Traits > & 
      operator<<(std::basic_ostream< CharT, Traits > &, const param_type &);
    template<typename CharT, typename Traits> 
      std::basic_istream< CharT, Traits > & 
      operator>>(std::basic_istream< CharT, Traits > &, const param_type &);
    bool operator==(const param_type &, const param_type &);
    bool operator!=(const param_type &, const param_type &);
  };

  // public member functions
  discrete_distribution();
  template<typename Iter> discrete_distribution(Iter, Iter);
  discrete_distribution(std::initializer_list< WeightType >);
  template<typename Range> explicit discrete_distribution(const Range &);
  template<typename Func> 
    discrete_distribution(std::size_t, double, double, Func);
  explicit discrete_distribution(const param_type &);
  template<typename URNG> IntType operator()(URNG &) const;
  template<typename URNG> IntType operator()(URNG &, const param_type &) const;
  result_type min() const;
  result_type max() const;
  std::vector< WeightType > probabilities() const;
  param_type param() const;
  void param(const param_type &);
  void reset();

  // friend functions
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, 
               const discrete_distribution &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, 
               const discrete_distribution &);
  bool operator==(const discrete_distribution &, 
                  const discrete_distribution &);
  bool operator!=(const discrete_distribution &, 
                  const discrete_distribution &);
};

说明

类 discrete_distribution 满足 random distribution 概念. 它产生 [0, n) 范围内的整数, 产生每个值的概率由分布的参数指定.

discrete_distribution 公有成员函数

  1. discrete_distribution();

    创建一个新的 discrete_distribution 对象, 具有 和 .

  2. template<typename Iter> discrete_distribution(Iter first, Iter last);

    从迭代器范围构造 discrete_distribution. 如果 first == last, 等价于默认构造函数. 否则, 范围中的值表示分布可能值的权重.

  3. discrete_distribution(std::initializer_list< WeightType > wl);

    构造 discrete_distribution, 来源为 std::initializer_list. 如果 initializer_list 为空, 等价于默认构造函数. 否则, initializer_list 中的值表示分布可能值的权重. 例如, 给定分布

    discrete_distribution<> dist{1, 4, 5};

    0 的概率为 1/10, 1 的概率为 2/5, 2 的概率为 1/2, 且不可能有其他值.

  4. template<typename Range> explicit discrete_distribution(const Range & range);

    从 Boost.Range 范围构造 discrete_distribution. 如果范围为空, 等价于默认构造函数. 否则, 范围中的值表示分布可能值的权重.

  5. template<typename Func> 
  discrete_distribution(std::size_t nw, double xmin, double xmax, Func fw);

    构造一个近似某个函数的 discrete_distribution. 如果 nw 为零, 等价于默认构造函数. 否则, 分布的范围为 [0, nw), 权重通过以均匀分布在 和 之间的值调用 fw 得到, 其中 .

  6. explicit discrete_distribution(const param_type & param);

    从参数构造 discrete_distribution.

  7. template<typename URNG> IntType operator()(URNG & urng) const;

    返回按 discrete_distribution 参数分布的值.

  8. template<typename URNG> 
  IntType operator()(URNG & urng, const param_type & param) const;

    返回按 param 指定参数分布的值.

  9. result_type min() const;

    返回分布能产生的最小值.

  10. result_type max() const;

    返回分布能产生的最大值.

  11. std::vector< WeightType > probabilities() const;

    返回包含分布每个值概率的向量. 例如, 给定

    discrete_distribution<> dist = { 1, 4, 5 };
std::vector<double> p = dist.param();

    向量 p 将包含 {0.1, 0.4, 0.5}.

    如果 WeightType 是整数类型, 则权重将原样返回.

  12. param_type param() const;

    返回分布的参数.

  13. void param(const param_type & param);

    设置分布的参数.

  14. void reset();

    效果: 调用 reset 之后, 分布的后续使用不依赖于任何引擎在调用 reset 之前产生的值.

discrete_distribution 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const discrete_distribution & dd);

    把分布写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const discrete_distribution & dd);

    从 std::istream 读取分布

  3. bool operator==(const discrete_distribution & lhs, 
                const discrete_distribution & rhs);

    如果传入相同的生成器时两个分布将返回相同的值序列, 则返回 true.

  4. bool operator!=(const discrete_distribution & lhs, 
                const discrete_distribution & rhs);

    如果传入相同的生成器时两个分布可能返回不同的值序列, 则返回 true.
