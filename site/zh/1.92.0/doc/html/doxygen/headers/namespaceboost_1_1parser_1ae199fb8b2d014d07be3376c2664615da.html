全局 punct

boost::parser::punct

概要

// In header: <boost/parser/parser.hpp>

unspecified punct;

说明

标点字符解析器. 匹配全部 Unicode 标点类 (即 "Pc"、"Pd"、"Pe"、"Pf"、"Pi"、"Ps" 与 "Po").
