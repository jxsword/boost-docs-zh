结构体模板 minimal_expr

boost::yap::minimal_expr

概要

// In header: <boost/yap/algorithm_fwd.hpp>

template<expr_kind Kind, typename Tuple> 
struct minimal_expr {

  // public data members
  static expr_kind const kind;
  Tuple elements;
};

说明

当 YAP 没有被告知使用的表达式模板时, 用作 YAP 内部某些操作返回的表达式模板. 例如, 若 transform() 通过转换现有表达式的元素来创建新表达式, 它会尝试使用现有表达式的表达式模板来创建新表达式. 若现有表达式不是由表达式模板构造因而没有这样的模板, 则使用 minimal_expr.
