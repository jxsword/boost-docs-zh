类 rand48

boost::rand48

概要

// In header: <boost/random/linear_congruential.hpp>


class rand48 {
public:
  // types
  typedef boost::uint32_t result_type;

  // public static functions
  static uint32_t min();
  static uint32_t max();

  // public member functions
  rand48();
  explicit rand48(result_type);
  template<typename SeedSeq> explicit rand48(SeedSeq &);
  template<typename It> rand48(It &, It);
  void seed();
  void seed(result_type);
  template<typename It> void seed(It &, It);
  template<typename SeedSeq> void seed(SeedSeq &);
  uint32_t operator()();
  void discard(boost::uintmax_t);
  template<typename Iter> void generate(Iter, Iter);

  // friend functions
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, const rand48 &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, rand48 &);
  bool operator==(const rand48 &, const rand48 &);
  bool operator!=(const rand48 &, const rand48 &);

  // public data members
  static const bool has_fixed_range;
};

说明

类 rand48 满足 pseudo-random number generator 概念. 它使用线性同余算法, 参数为 a = 0x5DEECE66D, c = 0xB, m = 2**48. 它给出的结果与某些系统上可用的 lrand48() 函数相同 (假定未调用 lcong48).

它仅在 uint64_t 作为整数类型提供的系统上可用, 以便例如在类内静态常量和/或带有大 uint64_t 数值的枚举定义能够工作.

rand48 公有静态函数

  1. static uint32_t min();

    返回生成器能产生的最小值

  2. static uint32_t max();

    返回生成器能产生的最大值

rand48 公有成员函数

  1. rand48();

    用默认种子为生成器播种.

  2. explicit rand48(result_type x0);

    构造 rand48 生成器, x(0) := (x0 << 16) | 0x330e.

  3. template<typename SeedSeq> explicit rand48(SeedSeq & seq);

    用 seq.generate() 产生的值为生成器播种.

  4. template<typename It> rand48(It & first, It last);

    使用来自迭代器范围的值为生成器播种, 并把 first 更新为指向最后消费的值之后.

  5. void seed();

    用默认种子为生成器播种.

  6. void seed(result_type x0);

    把生成器的当前值 x(n) 改为 (x0 << 16) | 0x330e.

  7. template<typename It> void seed(It & first, It last);

    使用来自迭代器范围的值为生成器播种, 并把 first 更新为指向最后消费的值之后.

  8. template<typename SeedSeq> void seed(SeedSeq & seq);

    用 seq.generate() 产生的值为生成器播种.

  9. uint32_t operator()();

    返回生成器的下一个值.

  10. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

  11. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

rand48 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, const rand48 & r);

    把 rand48 写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, rand48 & r);

    读取 rand48, 来源为 std::istream.

  3. bool operator==(const rand48 & x, const rand48 & y);

    如果两个生成器将产生相同的值序列则返回 true.

  4. bool operator!=(const rand48 & x, const rand48 & y);

    如果两个生成器将产生不同的值序列则返回 true.
