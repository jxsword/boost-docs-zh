结构体模板 transform_replace_view

boost::parser::transform_replace_view

概要

// In header: <boost/parser/transform_replace.hpp>

template<std::ranges::viewable_range V, std::move_constructible F, 
         typename Parser, typename GlobalState, typename ErrorHandler, 
         typename SkipParser> 
struct transform_replace_view {
  // member classes/structs/unions
  template<bool Const> 
  struct iterator {
    // types
    typedef unspecified                         I;             
    typedef unspecified                         S;             
    typedef unspecified                         ref_t_iter;    
    typedef BOOST_PARSER_SUBRANGE< ref_t_iter > reference_type;
    typedef unspecified                         base_type;     

    // public member functions
    iterator() = default;
    iterator(unspecified);
    iterator & operator++();
    reference_type operator*() const;
  };
  template<bool Const> 
  struct sentinel {
  };

  // public member functions
  transform_replace_view() = default;
  transform_replace_view(V, 
                         parser_interface< Parser, GlobalState, ErrorHandler > const &, 
                         parser_interface< SkipParser > const &, F, 
                         trace = trace::off);
  transform_replace_view(V, 
                         parser_interface< Parser, GlobalState, ErrorHandler > const &, 
                         F, trace = trace::off);
  V base() const;
  V base();
  F const & f() const;
  auto begin();
  auto end();
  auto begin() const;
  auto end() const;
};

说明

产生给定范围 base 的子范围序列. 每个子范围要么是 base 中不匹配给定解析器 parser 的子范围, 要么是 f(*boost::parser::parse(match, parser)), 其中 f 是给定的可调用对象, match 是匹配的子范围.

除模板参数约束外, F 必须可以用 Parser 的属性类型调用; V 与 F 产生的范围类型 "`Rf`" 必须是 char 的范围, 或必须具有相同的 UTF 格式; 且 V 与 Rf 必须满足 std::ranges::join_view 中所述的相同兼容性要求.
