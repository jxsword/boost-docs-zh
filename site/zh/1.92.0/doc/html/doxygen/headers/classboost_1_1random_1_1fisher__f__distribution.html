boost::random::fisher_f_distribution

概要

// In header: <boost/random/fisher_f_distribution.hpp>

template<typename RealType = double> 
class fisher_f_distribution {
public:
  // types
  typedef RealType result_type;
  typedef RealType input_type; 

  // member classes/structs/unions

  class param_type {
  public:

说明

Fisher F 分布是以 m 和 n 为两个参数的实数值分布.

它具有 .

fisher_f_distribution 公有成员函数

  1. explicit fisher_f_distribution(RealType m = 1.0, RealType n = 1.0);

    从 "m" 和 "n" 参数构造 fisher_f_distribution.

    要求: m > 0 and n > 0

  2. explicit fisher_f_distribution(const param_type & param);

    从参数构造 fisher_f_distribution.

  3. template<typename URNG> RealType operator()(URNG & urng);

    返回按 F 分布分布的随机变量.

  4. template<typename URNG> 
  RealType operator()(URNG & urng, const param_type & param) const;

    返回按 F 分布分布且由 param 指定参数的随机变量.

  5. RealType m() const;

    返回分布的 "m" 参数.

  6. RealType n() const;

    返回分布的 "n" 参数.

  7. RealType min() const;

    返回分布能产生的最小值.

  8. RealType max() const;

    返回分布能产生的最大值.

  9. param_type param() const;

    返回分布的参数.

  10. void param(const param_type & param);

    设置分布的参数.

  11. void reset();

    效果: 调用 reset 之后, 分布的后续使用不依赖于任何引擎在调用 reset 之前产生的值.

fisher_f_distribution 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const fisher_f_distribution & fd);

    把 fisher_f_distribution 写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const fisher_f_distribution & fd);

    读取 fisher_f_distribution, 来源为 std::istream.

  3. bool operator==(const fisher_f_distribution & lhs, 
                const fisher_f_distribution & rhs);

    如果给定相同的生成器时两个 fisher_f_distribution 实例将返回相同的值序列, 则返回 true.

  4. bool operator!=(const fisher_f_distribution & lhs, 
                const fisher_f_distribution & rhs);

    如果给定相同的生成器时两个 fisher_f_distribution 实例将返回不同的值序列, 则返回 true.
