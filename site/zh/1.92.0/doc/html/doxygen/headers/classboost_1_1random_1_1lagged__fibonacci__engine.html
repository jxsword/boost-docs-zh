类模板 lagged_fibonacci_engine

boost::random::lagged_fibonacci_engine

概要

// In header: <boost/random/lagged_fibonacci.hpp>

template<typename UIntType, int w, unsigned int p, unsigned int q> 
class lagged_fibonacci_engine {
public:
  // types
  typedef UIntType result_type;

  // public static functions
  static result_type min();
  static result_type max();

  // public member functions
  lagged_fibonacci_engine();
  explicit lagged_fibonacci_engine(UIntType);
  template<typename SeedSeq> explicit lagged_fibonacci_engine(SeedSeq &);
  template<typename It> lagged_fibonacci_engine(It &, It);
  void seed();
  void seed(UIntType);
  template<typename SeedSeq> void seed(SeedSeq &);
  template<typename It> void seed(It &, It);
  result_type operator()();
  template<typename Iter> void generate(Iter, Iter);
  void discard(boost::uintmax_t);

  // friend functions
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, 
               const lagged_fibonacci_engine &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, 
               const lagged_fibonacci_engine &);
  bool operator==(const lagged_fibonacci_engine &, 
                  const lagged_fibonacci_engine &);
  bool operator!=(const lagged_fibonacci_engine &, 
                  const lagged_fibonacci_engine &);

  // public data members
  static const bool has_fixed_range;
  static const int word_size;
  static const unsigned int long_lag;
  static const unsigned int short_lag;
  static const UIntType default_seed;
};

说明

类模板 lagged_fibonacci_engine 的实例化是 伪随机数生成器 的模型. 它使用带两个滞后量 p 与 q: 的滞后斐波那契算法: x(i) = x(i-p) + x(i-q) (mod 2w), 其中 p > q.

lagged_fibonacci_engine 公有静态函数

  1. static result_type min();

    返回生成器可产生的最小值.

  2. static result_type max();

    返回生成器可产生的最大值.

lagged_fibonacci_engine 公有成员函数

  1. lagged_fibonacci_engine();

    创建一个新的 lagged_fibonacci_engine 并调用 seed().

  2. explicit lagged_fibonacci_engine(UIntType value);

    创建一个新的 lagged_fibonacci_engine 并调用 seed(value).

  3. template<typename SeedSeq> explicit lagged_fibonacci_engine(SeedSeq & seq);

    创建一个新的 lagged_fibonacci_engine 并调用 seed(seq).

  4. template<typename It> lagged_fibonacci_engine(It & first, It last);

    创建一个新的 lagged_fibonacci_engine 并调用 seed(first, last).

  5. void seed();

    调用 seed(default_seed).

  6. void seed(UIntType value);

    将生成器的状态设为由 minstd_rand0 生成器产生的值.

  7. template<typename SeedSeq> void seed(SeedSeq & seq);

    使用 seq 产生的值设置生成器的状态.

  8. template<typename It> void seed(It & first, It last);

    将生成器的状态设为迭代器范围 [first, last) 中的值. 若 [first, last) 范围内元素不足, 则抛出 std::invalid_argument.

  9. result_type operator()();

    返回生成器的下一个值.

  10. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

  11. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

lagged_fibonacci_engine 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const lagged_fibonacci_engine & f);

    把生成器的文本表示写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const lagged_fibonacci_engine & f);

    从 std::istream 读取生成器的文本表示.

  3. bool operator==(const lagged_fibonacci_engine & x_, 
                const lagged_fibonacci_engine & y_);

    如果两个生成器将产生相同的输出序列则返回 true.

  4. bool operator!=(const lagged_fibonacci_engine & lhs, 
                const lagged_fibonacci_engine & rhs);

    如果两个生成器将产生不同的输出序列则返回 true.
