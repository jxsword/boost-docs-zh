宏 BOOST_YAP_USER_UNARY_OPERATOR

BOOST_YAP_USER_UNARY_OPERATOR

概要

// In header: <boost/yap/user_macros.hpp>

BOOST_YAP_USER_UNARY_OPERATOR(op_name, expr_template, result_expr_template)

说明

为一元运算符 op_name 定义运算符重载, 每个重载接受一个从 expr_template 实例化的表达式, 并返回一个从表达式模板 result_expr_template 实例化的表达式. 为限定符 const &、& 与 && 各定义一个重载. 对于左值引用重载, 实参以引用方式捕获进结果表达式. 对于右值引用重载, 实参被移入结果表达式.

示例:















 参数: 











expr_template


重载所适用的表达式模板. expr_template 必须是 ExpressionTemplate.






op_name


要重载的运算符; 它必须是 一元 枚举项之一 (位于 expr_kind 中), 不带 expr_kind:: 限定.






result_expr_template


用于实例化结果表达式的表达式模板. result_expr_template 必须是 ExpressionTemplate.
