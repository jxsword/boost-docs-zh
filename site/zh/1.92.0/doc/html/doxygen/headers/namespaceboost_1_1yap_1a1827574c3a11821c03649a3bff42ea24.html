函数模板 value

boost::yap::value

概要

// In header: <boost/yap/algorithm.hpp>


template<typename T> decltype(auto) value(T && x);

说明

将 x 的唯一元素转发给调用者, 必要时先调用 deref() (当 x 是引用表达式时), 或将 x 原样转发给调用者.

更正式地:

  • 若 x 不是表达式, 则将 x 转发给调用者.

  • 否则, 若 x 是引用表达式, 则结果为 value(deref(x)).

  • 否则, 若 x 是只有一个值的表达式 (一元表达式或终端表达式), 则结果是 x 被转发后的第一个元素.

  • 否则, 将 x 转发给调用者.
