宏 BOOST_YAP_USER_UDT_ANY_IF_ELSE

BOOST_YAP_USER_UDT_ANY_IF_ELSE

概要

// In header: <boost/yap/user_macros.hpp>

BOOST_YAP_USER_UDT_ANY_IF_ELSE(expr_template, udt_trait)

说明

定义一个函数 if_else(), 其作用类似于三元运算符 (?:), 因为三元运算符不能由用户重载. if_else() 的返回类型是从表达式模板 expr_template 实例化的表达式.

if_else() 的每个参数可以是任何 不是 表达式的类型. 至少一个参数必须是类型 T, 使得

udt_trait<std::remove_cv_t<std::remove_reference_t<T>>>::value

为真. 每个参数都被包装在终端表达式中.

expr_template


用于实例化结果表达式的表达式模板. expr_template 必须是 ExpressionTemplate.






udt_trait


用于约束哪些类型可接受为 if_else() 模板参数的特征模板.
