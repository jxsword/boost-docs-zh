结构体模板 expression

boost::yap::expression

概要

// In header: <boost/yap/expression.hpp>

template<expr_kind Kind, typename Tuple> 
struct expression {
  // types
  typedef Tuple tuple_type;

  // public member functions
  expression();
  expression(tuple_type &&);
  decltype(auto) value();
  decltype(auto) left();
  decltype(auto) right();

  // public data members
  static const expr_kind kind;
  tuple_type elements;
};

说明

提供所有运算符重载的引用表达式模板.

注释

由于 Doxygen 的限制, 此处列出的 value()、left()、right() 与各运算符重载中的每一个都是三个成员函数的替身. 对于每个函数 f, 此处列出的是:

return_type f ();

但实际上有三个函数:

return_type f () const &;
return_type f () &;
return_type f () &&;

expression 公有成员函数

  1. expression();

    默认构造函数. 不做任何事情.

  2. expression(tuple_type && rhs);

    将 rhs 移入唯一的数据成员 elements.

  3. decltype(auto) value();

    一个便捷成员函数, 分派到自由函数 value().

  4. decltype(auto) left();

    一个便捷成员函数, 分派到自由函数 left().

  5. decltype(auto) right();

    一个便捷成员函数, 分派到自由函数 right().
