函数模板 search

boost::parser::search

概要

// In header: <boost/parser/search.hpp>


template<parsable_range R, typename Parser, typename GlobalState, 
         typename ErrorHandler> 
  auto search(R && r, 
              parser_interface< Parser, GlobalState, ErrorHandler > const & parser, 
              trace trace_mode = trace::off);

说明

返回解析器 parser 在 r 中首个匹配的子范围. 此函数具有与 std::ranges::search() 类似的接口与语义. 在 C++20 及更高版本中返回 std::ranges::dangling, 若 r 是不可借用的右值.
