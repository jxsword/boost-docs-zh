类模板 independent_bits_engine

boost::random::independent_bits_engine

概要

// In header: <boost/random/independent_bits.hpp>

template<typename Engine, std::size_t w, typename UIntType> 
class independent_bits_engine {
public:
  // types
  typedef Engine              base_type;       
  typedef UIntType            result_type;     
  typedef Engine::result_type base_result_type;

  // public static functions
  static result_type min();
  static result_type max();

  // public member functions
  independent_bits_engine();
  explicit independent_bits_engine(base_result_type);
  template<typename SeedSeq> explicit independent_bits_engine(SeedSeq &);
  independent_bits_engine(const base_type &);
  template<typename It> independent_bits_engine(It &, It);
  void seed();
  void seed(base_result_type);
  template<typename SeedSeq> void seed(SeedSeq &);
  template<typename It> void seed(It &, It);
  result_type operator()();
  template<typename Iter> void generate(Iter, Iter);
  void discard(boost::uintmax_t);
  const base_type & base() const;

  // friend functions
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, 
               const independent_bits_engine &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, 
               const independent_bits_engine &);
  bool operator==(const independent_bits_engine &, 
                  const independent_bits_engine &);
  bool operator!=(const independent_bits_engine &, 
                  const independent_bits_engine &);

  // public data members
  static const bool has_fixed_range;
};

说明

类模板 independent_bits_engine 的实例化是一个 伪随机数生成器 模型. 它通过组合对基引擎的一次或多次调用, 生成分布在 [0, 2^w) 区间内的随机数.

要求: 0 < w <= std::numeric_limits<UIntType>::digits

independent_bits_engine 公有静态函数

  1. static result_type min();

    返回生成器可产生的最小值.

  2. static result_type max();

    返回生成器可产生的最大值.

independent_bits_engine 公有成员函数

  1. independent_bits_engine();

    使用基生成器的默认构造函数构造一个 independent_bits_engine.

  2. explicit independent_bits_engine(base_result_type seed);

    构造 independent_bits_engine, 以 seed 作为两个基生成器的构造实参.

  3. template<typename SeedSeq> explicit independent_bits_engine(SeedSeq & seq);

    构造一个 independent_bits_engine, 并以 seq 作为基生成器的构造函数实参.

  4. independent_bits_engine(const base_type & base_arg);

    构造一个 independent_bits_engine, 通过复制 base.

  5. template<typename It> independent_bits_engine(It & first, It last);

    以输入迭代器 first 和 last 定义的范围中的值构造 independent_bits_engine. first 将被修改为指向最后一个使用的元素之后.

    抛出: std::invalid_argument, 若输入范围太小.

    异常安全性: 基本

  6. void seed();

    使用基生成器的默认种子播种一个 independent_bits_engine.

  7. void seed(base_result_type seed);

    播种一个 independent_bits_engine, 并以 seed 作为基生成器的种子.

  8. template<typename SeedSeq> void seed(SeedSeq & seq);

    播种一个 independent_bits_engine, 并用 seq 播种基生成器.

  9. template<typename It> void seed(It & first, It last);

    以输入迭代器 first 和 last 定义的范围中的值为 independent_bits_engine 播种. first 将被修改为指向最后一个使用的元素之后.

    抛出: std::invalid_argument, 若输入范围太小.

    异常安全性: 基本

  10. result_type operator()();

    返回生成器的下一个值.

  11. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

  12. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

  13. const base_type & base() const;

independent_bits_engine 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const independent_bits_engine & r);

    将生成器的文本表示写入一个 std::ostream. 引擎的文本表示即基引擎的文本表示.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const independent_bits_engine & r);

    读取 independent_bits_engine 的状态, 来源为 std::istream.

  3. bool operator==(const independent_bits_engine & x, 
                const independent_bits_engine & y);

    返回: 当且仅当两个 independent_bits_engines 将产生相同的值序列时为 true.

  4. bool operator!=(const independent_bits_engine & lhs, 
                const independent_bits_engine & rhs);

    返回: 当且仅当两个 independent_bits_engines 将产生不同的值序列时为 true.
