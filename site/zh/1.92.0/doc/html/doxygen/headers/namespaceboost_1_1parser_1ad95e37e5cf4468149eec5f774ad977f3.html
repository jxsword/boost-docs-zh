函数模板 repeat

boost::parser::repeat

概要

// In header: <boost/parser/parser.hpp>


template<typename T> repeat_directive< T, T > repeat(T n);

说明

返回一个 repeat_directive, 恰好重复 n 次, 其 operator[] 返回一个 parser_interface<repeat_parser<P>>, 来自给定类型为 parser_interface<P> 的解析器.
