boost::random::chi_squared_distribution

概要

template<typename RealType = double> 
class chi_squared_distribution {
public:
  // types
  typedef RealType result_type;
  typedef RealType input_type; 

  // member classes/structs/unions

  class param_type {
  public:

说明

卡方分布是只有一个参数 n 的实数值分布. 该分布产生的值 > 0.

分布函数为 .

chi_squared_distribution 公有成员函数

  1. explicit chi_squared_distribution(RealType n = 1);

    构造一个 chi_squared_distribution 对象. n 是分布的参数.

    要求: t >=0 && 0 <= p <= 1

  2. explicit chi_squared_distribution(const param_type & param);

    从参数构造 chi_squared_distribution 对象.

  3. template<typename URNG> RealType operator()(URNG & urng);

    返回按卡方分布分布的随机变量.

  4. template<typename URNG> 
  RealType operator()(URNG & urng, const param_type & param) const;

    返回按卡方分布分布且由 param 指定参数的随机变量.

  5. RealType n() const;

    返回分布的 n 参数.

  6. RealType min() const;

    返回分布能产生的最小值.

  7. RealType max() const;

    返回分布能产生的最大值.

  8. param_type param() const;

    返回分布的参数.

  9. void param(const param_type & param);

    设置分布的参数.

  10. void reset();

    效果: 调用 reset 之后, 分布的后续使用不依赖于任何引擎在调用 reset 之前产生的值.

chi_squared_distribution 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const chi_squared_distribution & c2d);

    把分布的参数写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             chi_squared_distribution & c2d);

    从 std::istream 读取分布的参数.

  3. bool operator==(const chi_squared_distribution & lhs, 
                const chi_squared_distribution & rhs);

    如果给定相同的生成器时两个分布将产生相同的值序列, 则返回 true.

  4. bool operator!=(const chi_squared_distribution & lhs, 
                const chi_squared_distribution & rhs);

    如果给定相同的生成器时两个分布可能产生不同的值序列, 则返回 true.
