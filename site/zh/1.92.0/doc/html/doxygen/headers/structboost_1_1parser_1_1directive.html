结构体模板 directive

boost::parser::directive

概要

// In header: <boost/parser/parser.hpp>

template<template< class > class Parser> 
struct directive {

  // public member functions
  template<typename Parser2> 
    auto operator[](parser_interface< Parser2 >) const noexcept;
};

说明

将无参数的高阶解析器 (例如 omit_parser) 表示为指令 (例如 omit[other_parser]).

directive 公有成员函数

  1. template<typename Parser2> 
  auto operator[](parser_interface< Parser2 > rhs) const noexcept;
