全局 transform_replace

boost::parser::transform_replace

概要

// In header: <boost/parser/transform_replace.hpp>

unspecified transform_replace;

说明

一个范围适配器对象 ([range.adaptor.object]). 给定子表达式 E 与 P、Q、R 以及 'S', 各表达式 replace(E, P)、replace(E, P, Q)、replace(E, P, Q, R) 与 replace(E, P, Q, R, S) 分别表达式等价于 replace_view(E, P)、replace_view(E, P, Q)、replace_view(E, P, Q, R)、replace_view(E, P, Q, R, S).
