函数模板 _params

boost::parser::_params

概要

// In header: <boost/parser/parser_fwd.hpp>


template<typename Context> decltype(auto) _params(Context const & context);

说明

返回对传递给最底层规则 r 的一个或多个参数的引用, 方式是将 r 用作 r.with(param0, param1, ... paramN); 多个值将存储在 parser::tuple 中. 若没有最底层规则, 或该规则未获得任何参数, 则返回 none.
