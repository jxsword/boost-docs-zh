函数模板 switch_

boost::parser::switch_

概要

// In header: <boost/parser/parser.hpp>


template<typename T> auto switch_(T x);

说明

返回一个类似 switch 的解析器. 所得解析器使用给定值 x 从以下值/解析器对中选择一个, 并应用所选的解析器. x 可以是直接使用的值, 也可以是一元可调用对象 (接受解析上下文的引用并返回要使用的值). 你可以使用返回解析器的调用运算符添加更多值/解析器分支, 例如 switch_(x)(y1, p1)(y2, p2). 与传给此函数的 x 一样, 每个 yN 值都可以是一个值或一元可调用对象.
