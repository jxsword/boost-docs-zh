类模板 triangle_distribution

boost::random::triangle_distribution

概要

// In header: <boost/random/triangle_distribution.hpp>

template<typename RealType = double> 
class triangle_distribution {
public:
  // types
  typedef RealType input_type; 
  typedef RealType result_type;

  // member classes/structs/unions

  class param_type {
  public:
    // types
    typedef triangle_distribution distribution_type;

    // public member functions
    explicit param_type(RealType = 0.0, RealType = 0.5, RealType = 1.0);

    RealType b() const;
    RealType c() const;

    // friend functions
    template<typename CharT, typename Traits>

                  const triangle_distribution &);

说明

triangle_distribution 的实例化是 随机分布 的模型. 一个 triangle_distribution 有三个参数 a、b 与 c, 分别是该分布的最小值、最可能值与最大值.

triangle_distribution 公有成员函数

  1. explicit triangle_distribution(RealType a = 0.0, RealType b = 0.5, 
                               RealType c = 1.0);

    构造一个 triangle_distribution, 参数为 a、b 与 c.

    前置条件: a <= b <= c.

  2. explicit triangle_distribution(const param_type & param);

    从参数构造 triangle_distribution.

  3. result_type a() const;

    返回该分布的 a 参数

  4. result_type b() const;

    返回该分布的 b 参数

  5. result_type c() const;

    返回该分布的 c 参数

  6. RealType min() const;

    返回分布能产生的最小值.

  7. RealType max() const;

    返回分布能产生的最大值.

  8. param_type param() const;

    返回分布的参数.

  9. void param(const param_type & param);

    设置分布的参数.

  10. void reset();

    效果: 调用 reset 之后, 分布的后续使用不依赖于任何引擎在调用 reset 之前产生的值.

  11. template<typename Engine> result_type operator()(Engine & eng);

    返回服从三角形分布的随机变量.

  12. template<typename Engine> 
  result_type operator()(Engine & eng, const param_type & param);

    返回服从三角形分布的随机变量, 参数由 param 指定.

triangle_distribution 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const triangle_distribution & td);

    把分布写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const triangle_distribution & td);

    从 std::istream 读取分布.

  3. bool operator==(const triangle_distribution & lhs, 
                const triangle_distribution & rhs);

    如果给定相同的生成器时两个分布将产生相同的值序列, 则返回 true.

  4. bool operator!=(const triangle_distribution & lhs, 
                const triangle_distribution & rhs);

    如果给定相同的生成器时两个分布可能产生不同的值序列, 则返回 true.
