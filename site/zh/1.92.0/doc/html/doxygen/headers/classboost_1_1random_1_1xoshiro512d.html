类 xoshiro512d

boost::random::xoshiro512d

概要

// In header: <boost/random/xoshiro.hpp>


class xoshiro512d {
public:

  // public member functions
  std::uint64_t next_int() noexcept;
  result_type next() noexcept;

  // public static functions
  static constexpr min() noexcept;
  static constexpr max() noexcept;
};

说明

这是 xoshiro512+ 1.0, 我们的浮点数生成器, 状态大小更大. 建议使用其高位进行浮点数生成, 因为它比 xoshiro512** 略快. 它通过了我们所知的所有测试, 最低三位除外, 这三位可能无法通过线性度测试 (且仅此测试); 因此若低线性复杂度不被视为问题 (通常如此), 它也可用于生成 64 位输出.

建议使用符号测试提取随机布尔值, 使用右移提取位的子集.

必须对状态进行播种, 使其不全为零. 若你有一个 64 位种子, 建议先播种一个 splitmix64 生成器, 并用其输出填充 s.
