类模板 shuffle_order_engine

boost::random::shuffle_order_engine

概要

// In header: <boost/random/shuffle_order.hpp>

template<typename UniformRandomNumberGenerator, std::size_t k> 
class shuffle_order_engine {
public:
  // types
  typedef UniformRandomNumberGenerator base_type;  
  typedef base_type::result_type       result_type;

  // public member functions
  shuffle_order_engine();
  explicit shuffle_order_engine(result_type);
  template<typename SeedSeq> explicit shuffle_order_engine(SeedSeq &);
  explicit shuffle_order_engine(const base_type &);
  explicit shuffle_order_engine(base_type &&);
  template<typename It> shuffle_order_engine(It &, It);
  void seed();
  void seed(result_type);
  template<typename SeedSeq> void seed(SeedSeq &);
  template<typename It> void seed(It &, It);
  const base_type & base() const;
  result_type operator()();
  void discard(boost::uintmax_t);
  template<typename Iter> void generate(Iter, Iter);

  // public static functions
  static result_type min();
  static result_type max();

  // friend functions
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, 
               const shuffle_order_engine &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, 
               const shuffle_order_engine &);
  bool operator==(const shuffle_order_engine &, const shuffle_order_engine &);
  bool operator!=(const shuffle_order_engine &, const shuffle_order_engine &);

  // public data members
  static const bool has_fixed_range;
  static const std::size_t buffer_size;
  static const std::size_t table_size;
};

说明

类模板 shuffle_order_engine 的实例化是 伪随机数生成器 的模型. 它混合某个 (通常为 linear_congruential_engine) 均匀随机数生成器 的输出以获得更好的统计性质. 算法见如下文献:

"Improving a poor random number generator", Carter Bays and S.D. Durham, ACM Transactions on Mathematical Software, Vol 2, No. 1, March 1976, pp. 59-64. http://doi.acm.org/10.1145/355666.355670

基生成器的输出缓存在长度为 k 的数组中. 每个输出 X(n) 还有第二个作用: 它给出一个数组索引, X(n+1) 将从该处取回. 用过的数组元素会被基生成器的新输出替换.

模板参数为基生成器与数组长度 k, 后者应在 100 左右.

shuffle_order_engine 公有成员函数

  1. shuffle_order_engine();

    通过调用基生成器的默认构造函数构造一个 shuffle_order_engine.

    复杂度: 恰好调用基生成器 k+1 次.

  2. explicit shuffle_order_engine(result_type s);

    通过以参数 seed 调用基生成器的单参构造函数构造一个 shuffle_output_engine.

    复杂度: 恰好调用基生成器 k+1 次.

  3. template<typename SeedSeq> explicit shuffle_order_engine(SeedSeq & seq);
  4. explicit shuffle_order_engine(const base_type & rng);

    通过使用所提供生成器的副本构造一个 shuffle_output_engine.

    前置条件: 模板实参 UniformRandomNumberGenerator 应表示一个可复制构造 (CopyConstructible) 类型.

    复杂度: 恰好调用基生成器 k+1 次.

  5. explicit shuffle_order_engine(base_type && rng);
  6. template<typename It> shuffle_order_engine(It & first, It last);
  7. void seed();
  8. void seed(result_type seed);

    以参数 seed 调用基生成器的单参 seed 方法, 并重新初始化内部缓冲数组.

    复杂度: 恰好调用基生成器 k+1 次.

  9. template<typename SeedSeq> void seed(SeedSeq & seq);

    以参数 seq 调用基生成器的单参 seed 方法, 并重新初始化内部缓冲数组.

    复杂度: 恰好调用基生成器 k+1 次.

  10. template<typename It> void seed(It & first, It last);
  11. const base_type & base() const;
  12. result_type operator()();
  13. void discard(boost::uintmax_t z);

    将生成器前进 z 步.

  14. template<typename Iter> void generate(Iter first, Iter last);

    用伪随机值填充一个范围.

shuffle_order_engine 公有静态函数

  1. static result_type min();

    返回生成器可产生的最小值.

  2. static result_type max();

    返回生成器可产生的最大值.

shuffle_order_engine 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const shuffle_order_engine & s);

    把 shuffle_order_engine 写入 std::ostream.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const shuffle_order_engine & s);

    读取 shuffle_order_engine, 来源为 std::istream.

  3. bool operator==(const shuffle_order_engine & x, 
                const shuffle_order_engine & y);

    如果两个生成器将产生相同的序列则返回 true.

  4. bool operator!=(const shuffle_order_engine & lhs, 
                const shuffle_order_engine & rhs);

    如果两个生成器将产生不同的序列则返回 true.
