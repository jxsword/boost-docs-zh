全局 separate

boost::parser::separate

概要

// In header: <boost/parser/parser.hpp>

separate_directive separate;

说明

separate_directive, 其 operator[] 返回一个 parser_interface<P2>, 来自给定类型为 parser_interface<P> 的解析器, 其中 P 是一个 seq_parser. P2 与 P 相同, 区别在于其 CombiningGroups 模板参数被替换为一个标记类型, 该类型阻止每个子解析器的属性与任何其他子解析器的属性合并.
