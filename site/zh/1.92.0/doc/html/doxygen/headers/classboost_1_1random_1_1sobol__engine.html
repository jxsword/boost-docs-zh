类模板 sobol_engine

boost::random::sobol_engine

概要

// In header: <boost/random/sobol.hpp>

template<typename UIntType, unsigned w, 
         typename SobolTables = default_sobol_table> 
class sobol_engine {
public:
  // types
  typedef UIntType result_type;

  // public member functions
  explicit sobol_engine(std::size_t);
  std::size_t dimension() const;
  void seed();
  void seed(UIntType);
  result_type operator()();
  void discard(boost::uintmax_t);

  // public static functions
  static result_type min();
  static result_type max();

  // friend functions
  bool operator==(const sobol_engine &, const sobol_engine &);
  bool operator!=(const sobol_engine &, const sobol_engine &);
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, const sobol_engine &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, const sobol_engine &);
};

说明

类模板 sobol_engine 的实例化是 拟随机数生成器 的模型. sobol_engine 使用如下文献所述的算法:

[Bratley+Fox, TOMS 14, 88 (1988)] and [Antonov+Saleev, USSR Comput. Maths. Math. Phys. 19, 252 (1980)]

重要

sobol_engine 会跳过序列开头的平凡零点. 例如, uniform_01 分布的 2 维 Sobol 序列的开头如下:

0.5, 0.5,
0.75, 0.25,
0.25, 0.75,
0.375, 0.375,
0.875, 0.875,
...

在以下文档中, X 表示模板 sobol_engine 返回 UIntType 类型对象的具体类, u 与 v 是 X 的值.

某些成员函数可能抛出 std::range_error 类型的异常. 这发生在拟随机定义域耗尽、生成器无法再产生更多值的时候. 低差异序列的长度由 给出.

sobol_engine 公有成员函数

  1. explicit sobol_engine(std::size_t s);

    效果: 构造默认的 s 维 Sobol 拟随机数生成器.

    抛出: bad_alloc, invalid_argument, range_error.

  2. std::size_t dimension() const;

    返回: 准随机域的维度.

    抛出: 无.

  3. void seed();
    抛出: nothing.

    效果: 将拟随机数生成器状态重置为默认构造所给的状态. 等价于 u.seed(0).

  4. void seed(UIntType init);
    抛出: range_error.

    效果: 实际上把准随机数生成器的状态设为准随机域中的第 init 个向量, 该域为 s 维, 其中 s == X::dimension().

    X u, v;
for(int i = 0; i < N; ++i)
    for( std::size_t j = 0; j < u.dimension(); ++j )
        u();
v.seed(N);
assert(u() == v());


  5. result_type operator()();

    返回: 每次调用返回 s 维 (s = X::dimension()) 向量的下一个元素. 当所有元素用尽后, X::operator() 以下一个 s 维向量的起始元素重新开始.

    抛出: range_error.

  6. void discard(boost::uintmax_t z);

    效果: 推进 *this 的状态, 如同执行了 z 次连续的 X::operator() 调用.

    X u = v;
for(int i = 0; i < N; ++i)
    u();
v.discard(N);
assert(u() == v());

    抛出: range_error.

sobol_engine 公有静态函数

  1. static result_type min();

    返回: operator() 返回值集合的紧下界.

    抛出: 无.

  2. static result_type max();

    返回: operator() 返回值集合的紧上界.

    抛出: 无.

sobol_engine 友元函数

  1. bool operator==(const sobol_engine & x, const sobol_engine & y);

    如果两个生成器将产生相同的输出序列则返回 true.

  2. bool operator!=(const sobol_engine & lhs, const sobol_engine & rhs);

    如果两个生成器将产生不同的输出序列则返回 true.

  3. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, const sobol_engine & s);

    把生成器的文本表示写入 std::ostream.

  4. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, const sobol_engine & s);

    从 std::istream 读取生成器的文本表示.
