类模板 additive_combine_engine

boost::random::additive_combine_engine

概要

// In header: <boost/random/additive_combine.hpp>

template<typename MLCG1, typename MLCG2> 
class additive_combine_engine {
public:
  // types
  typedef MLCG1              first_base; 
  typedef MLCG2              second_base;
  typedef MLCG1::result_type result_type;

  // public static functions
  static result_type min();
  static result_type max();

  // public member functions
  additive_combine_engine();
  explicit additive_combine_engine(result_type);
  template<typename SeedSeq> explicit additive_combine_engine(SeedSeq &);
  additive_combine_engine(typename MLCG1::result_type, 
                          typename MLCG2::result_type);
  template<typename It> additive_combine_engine(It &, It);
  void seed();
  void seed(result_type);
  template<typename SeedSeq> void seed(SeedSeq &);
  void seed(typename MLCG1::result_type, typename MLCG2::result_type);
  template<typename It> void seed(It &, It);
  result_type operator()();
  template<typename Iter> void generate(Iter, Iter);
  void discard(boost::uintmax_t);

  // friend functions
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, 
               const additive_combine_engine &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, 
               const additive_combine_engine &);
  bool operator==(const additive_combine_engine &, 
                  const additive_combine_engine &);
  bool operator!=(const additive_combine_engine &, 
                  const additive_combine_engine &);

  // public data members
  static const bool has_fixed_range;
};

说明

类模板 additive_combine_engine 的实例化满足 pseudo-random number generator 概念. 它组合两个乘性 linear_congruential_engine 数生成器, 即 c = 0 的生成器. 其描述见

"Efficient and Portable Combined Random Number Generators", Pierre L'Ecuyer, Communications of the ACM, Vol. 31, No. 6, June 1988, pp. 742-749, 774

模板参数 MLCG1 和 MLCG2 应表示两个不同的 linear_congruential_engine 数生成器, 且各自的 c = 0. 每次调用返回随机数 X(n) := (MLCG1(n) - MLCG2(n)) mod (m1 - 1), 其中 m1 表示 MLCG1 的模数.

  1. static result_type min();

    返回生成器能产生的最小值

  2. static result_type max();

    返回生成器能产生的最大值

additive_combine_engine 公有成员函数

  1. additive_combine_engine();

    使用两个基生成器的默认构造函数构造 additive_combine_engine.

  2. explicit additive_combine_engine(result_type seed);

    构造 additive_combine_engine, 以 seed 作为两个基生成器的构造实参.

  3. template<typename SeedSeq> explicit additive_combine_engine(SeedSeq & seq);

    构造 additive_combine_engine, 以 seq 作为两个基生成器的构造实参.

    警告

    此函数的语义可能变化. seed_seq 的设计是一次性生成所有种子, 但这里独立地为两个基引擎播种, 很可能最终给两者相同的序列.

  4. additive_combine_engine(typename MLCG1::result_type seed1, 
                        typename MLCG2::result_type seed2);

    构造 additive_combine_engine, 分别以 seed1 和 seed2 作为第一个和第二个基生成器的构造实参.

  5. template<typename It> additive_combine_engine(It & first, It last);

    以输入迭代器 first 和 last 定义的范围中的值构造 additive_combine_engine. first 将被修改为指向最后一个使用的元素之后.

    抛出: std::invalid_argument, 若输入范围太小.

    异常安全性: 基本

  6. void seed();

    使用两个基生成器的默认种子为 additive_combine_engine 播种.

  7. void seed(result_type seed);

    为 additive_combine_engine 播种, 以 seed 作为两个基生成器的种子.

  8. template<typename SeedSeq> void seed(SeedSeq & seq);

    为 additive_combine_engine 播种, 以 seq 为两个基生成器播种.

    见对应构造函数的警告.

  9. void seed(typename MLCG1::result_type seed1, 
          typename MLCG2::result_type seed2);

    为 additive_combine 生成器播种, 分别以 seed1 和 seed2 作为第一个和第二个基生成器的种子.

  10. template<typename It> void seed(It & first, It last);

    以输入迭代器 first 和 last 定义的范围中的值为 additive_combine_engine 播种. first 将被修改为指向最后一个使用的元素之后.

    抛出: std::invalid_argument, 若输入范围太小.

    异常安全性: 基本

  11. result_type operator()();

    返回生成器的下一个值.

  12. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

  13. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

additive_combine_engine 友元函数

  1. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, 
             const additive_combine_engine & r);

    把 additive_combine_engine 的状态写入 std::ostream. additive_combine_engine 的文本表示是第一个基生成器的文本表示后跟第二个基生成器的文本表示.

  2. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, 
             const additive_combine_engine & r);

    读取 additive_combine_engine 的状态, 来源为 std::istream.

  3. bool operator==(const additive_combine_engine & x, 
                const additive_combine_engine & y);

    返回: 当且仅当两个 additive_combine_engines 将产生相同的值序列时为 true.

  4. bool operator!=(const additive_combine_engine & lhs, 
                const additive_combine_engine & rhs);

    返回: 当且仅当两个 additive_combine_engines 将产生不同的值序列时为 true.
