类 xoshiro128f

boost::random::xoshiro128f

概要

// In header: <boost/random/xoshiro.hpp>


class xoshiro128f {
public:

  // public member functions
  std::uint32_t next_int() noexcept;
  result_type next() noexcept;

  // public static functions
  static constexpr min() noexcept;
  static constexpr max() noexcept;
};

说明

这是 xoshiro128+ 1.0, 我们用于 32 位浮点数的最佳且最快的 32 位生成器. 建议使用其高位进行浮点数生成, 因为它比 xoshiro128** 略快. 它通过了我们所知的所有测试 (线性度测试除外), 因为其最低四位具有低线性复杂度; 因此若低线性复杂度不被视为问题 (通常如此), 它也可用于生成 32 位输出.

建议使用符号测试提取随机布尔值, 使用右移提取位的子集.

必须对状态进行播种, 使其不全为零.
