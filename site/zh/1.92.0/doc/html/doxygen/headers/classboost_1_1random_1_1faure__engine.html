类模板 faure_engine

boost::random::faure_engine

概要

// In header: <boost/random/faure.hpp>

template<typename RealType, typename SeqSizeT, 
         typename PrimeTable = default_faure_prime_table> 
class faure_engine {
public:
  // types
  typedef RealType result_type;

  // friend functions
  bool operator==(const faure_engine &, const faure_engine &);
  bool operator!=(const faure_engine &, const faure_engine &);
  template<typename CharT, typename Traits> 
    std::basic_ostream< CharT, Traits > & 
    operator<<(std::basic_ostream< CharT, Traits > &, const faure_engine &);
  template<typename CharT, typename Traits> 
    std::basic_istream< CharT, Traits > & 
    operator>>(std::basic_istream< CharT, Traits > &, const faure_engine &);

  // public static functions
  static result_type min();
  static result_type max();

  // public member functions
  explicit faure_engine(std::size_t);
  void seed(SeqSizeT = 0);
  std::size_t dimension() const;
  result_type operator()();
  void discard(boost::uintmax_t);
};

说明

类模板 faure_engine 的实例化满足 quasi-random number generator 概念. faure_engine 使用下述文献描述的算法

Henri Faure, 与以 s 为基数的记数制相关联的序列的偏差 (Discrepance de suites associees a un systeme de numeration (en dimension s)), Acta Arithmetica, Volume 41, 1982, pages 337-351.

Bennett Fox, Algorithm 647: Implementation and Relative Efficiency of Quasirandom Sequence Generators, ACM Transactions on Mathematical Software, Volume 12, Number 4, December 1986, pages 362-376.

在以下文档中, X 表示模板 faure_engine 的具体类, 其返回类型 RealType 的对象, u 和 v 是 X 的值.

某些成员函数可能抛出类型为 std::bad_alloc 的异常.

faure_engine 友元函数

  1. bool operator==(const faure_engine & x, const faure_engine & y);

    如果两个生成器将产生相同的输出序列则返回 true.

  2. bool operator!=(const faure_engine & lhs, const faure_engine & rhs);

    如果两个生成器将产生不同的输出序列则返回 true.

  3. template<typename CharT, typename Traits> 
  std::basic_ostream< CharT, Traits > & 
  operator<<(std::basic_ostream< CharT, Traits > & os, const faure_engine & s);

    把生成器的文本表示写入 std::ostream.

  4. template<typename CharT, typename Traits> 
  std::basic_istream< CharT, Traits > & 
  operator>>(std::basic_istream< CharT, Traits > & is, const faure_engine & s);

    从 std::istream 读取生成器的文本表示.

faure_engine 公有静态函数

  1. static result_type min();

    返回: operator() 返回值集合的紧下界.

    抛出: 无.

  2. static result_type max();

    返回: operator() 返回值集合的紧上界.

    抛出: 无.

faure_engine 公有成员函数

  1. explicit faure_engine(std::size_t s);

    效果: 构造 s 维的默认 Faure 准随机数生成器.

    抛出: bad_alloc, invalid_argument.

  2. void seed(SeqSizeT init = 0);

    效果: 实际上把准随机数生成器的状态设为准随机域中的第 init 个向量, 该域为 s 维, 其中 s == X::dimension().

    X u, v;
for(int i = 0; i < N; ++i)
    for( std::size_t j = 0; j < u.dimension(); ++j )
        u();
v.seed(N);
assert(u() == v());

    抛出: bad_alloc.

  3. std::size_t dimension() const;

    返回: 准随机域的维度.

    抛出: 无.

  4. result_type operator()();

    返回: 每次调用返回 s 维 (s = X::dimension()) 向量的下一个元素. 当所有元素用尽后, X::operator() 以下一个 s 维向量的起始元素重新开始.

    抛出: range_error.

  5. void discard(boost::uintmax_t z);

    效果: 推进 *this 的状态, 如同执行了 z 次连续的 X::operator() 调用.

    X u = v;
for(int i = 0; i < N; ++i)
    u();
v.discard(N);
assert(u() == v());

    抛出: range_error. 抛出: bad_alloc.
