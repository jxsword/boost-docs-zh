类模板 variate_generator

boost::variate_generator

概要

// In header: <boost/random/variate_generator.hpp>

template<typename Engine, typename Distribution> 
class variate_generator {
public:
  // types
  typedef helper_type::value_type   engine_value_type;
  typedef Engine                    engine_type;      
  typedef Distribution              distribution_type;
  typedef Distribution::result_type result_type;      

  // public member functions
  variate_generator(Engine, Distribution);
  result_type operator()();
  template<typename T> result_type operator()(const T &);
  engine_value_type & engine();
  const engine_value_type & engine() const;
  distribution_type & distribution();
  const distribution_type & distribution() const;
  result_type min() const;
  result_type max() const;
};

说明

随机变量生成器用于将随机数生成器与随机数分布组合起来. Boost.Random 提供了大量 生成器 与 分布 可供选择.

模板参数 Engine 的实参应为 U、U& 或 U* 形式, 其中 U 是 均匀随机数生成器 的模型. 此时成员 engine_value_type 指称 U (而非指向 U 的指针或引用).

variate_generator 的特化满足 CopyConstructible 的要求. 除非模板参数 Engine 为 U& 形式, 否则它们还满足 Assignable 的要求.

本节所述所有函数的复杂度为常数. 除构造函数外, 本节所述函数均不抛出异常.

variate_generator 公有成员函数

  1. variate_generator(Engine e, Distribution d);

    构造一个 variate_generator 对象, 其关联的 均匀随机数生成器 为 eng, 关联的 随机分布 为 d.

    抛出: Engine 或 Distribution 的复制构造函数所抛出的异常.

  2. result_type operator()();

    返回: distribution()(engine())

  3. template<typename T> result_type operator()(const T & value);

    返回: distribution()(engine(), value).

  4. engine_value_type & engine();

    返回: 对关联的均匀随机数生成器的引用.

  5. const engine_value_type & engine() const;

    返回: 对关联的均匀随机数生成器的引用.

  6. distribution_type & distribution();

    返回: 对关联的 随机分布 的引用.

  7. const distribution_type & distribution() const;

    返回: 对关联的随机分布的引用.

  8. result_type min() const;

    前置条件: distribution().min() 合式

    返回: distribution().min() 

  9. result_type max() const;

    前置条件: distribution().max() 合式

    返回: distribution().max()
