宏 BOOST_YAP_USER_LITERAL_PLACEHOLDER_OPERATOR

BOOST_YAP_USER_LITERAL_PLACEHOLDER_OPERATOR

概要

// In header: <boost/yap/user_macros.hpp>

BOOST_YAP_USER_LITERAL_PLACEHOLDER_OPERATOR(expr_template)

说明

定义用户定义字面量模板, 创建从表达式模板 expr_template 实例化的字面量占位符. 建议将它放在自己的命名空间中.

参数:

expr_template

用于实例化结果表达式的表达式模板. expr_template 必须是 ExpressionTemplate.
