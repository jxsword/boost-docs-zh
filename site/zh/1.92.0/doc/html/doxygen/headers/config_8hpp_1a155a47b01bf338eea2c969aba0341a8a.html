宏 BOOST_PARSER_DISABLE_CONCEPTS

BOOST_PARSER_DISABLE_CONCEPTS

概要

// In header: <boost/parser/config.hpp>

BOOST_PARSER_DISABLE_CONCEPTS

说明

在 C++20 模式下构建时, 若编译器定义了 __cpp_lib_concepts, Boost.Parser 会自动使用 concept 来约束模板. 若要禁用 concept, 请定义此宏.
