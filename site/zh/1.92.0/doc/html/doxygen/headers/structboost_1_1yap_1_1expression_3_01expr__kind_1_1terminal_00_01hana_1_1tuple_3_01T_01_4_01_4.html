结构体模板 expression<expr_kind::terminal, hana::tuple< T >>

boost::yap::expression<expr_kind::terminal, hana::tuple< T >>

概要

// In header: <boost/yap/expression.hpp>

template<typename T> 
struct expression<expr_kind::terminal, hana::tuple< T >> {
  // types
  typedef hana::tuple< T > tuple_type;

  // public member functions
  expression();
  expression(T &&);
  expression(hana::tuple< T > const &);
  expression(hana::tuple< T > &&);
  decltype(auto) value();
  decltype(auto) left();
  decltype(auto) right();

  // public data members
  static const expr_kind kind;
  tuple_type elements;
};

说明

引用表达式模板的终端表达式特化.

注释

由于 Doxygen 的限制, value() 成员与此处列出的各运算符重载中的每一个都是三个成员函数的替身. 对于每个函数 f, 此处列出的是:

return_type f ();

但实际上有三个函数:

return_type f () const &;
return_type f () &;
return_type f () &&;

expression 公有成员函数

  1. expression();

    默认构造函数. 不做任何事情.

  2. expression(T && t);

    将 t 转发进 elements.

  3. expression(hana::tuple< T > const & rhs);

    将 rhs 复制进唯一的数据成员 elements.

  4. expression(hana::tuple< T > && rhs);

    将 rhs 移入唯一的数据成员 elements.

  5. decltype(auto) value();

    一个便捷成员函数, 分派到自由函数 value().

  6. decltype(auto) left();

    一个便捷成员函数, 分派到自由函数 left().

  7. decltype(auto) right();

    一个便捷成员函数, 分派到自由函数 right().
