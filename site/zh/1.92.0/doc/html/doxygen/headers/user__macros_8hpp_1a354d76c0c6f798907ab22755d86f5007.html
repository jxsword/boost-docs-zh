宏 BOOST_YAP_USER_CALL_OPERATOR

BOOST_YAP_USER_CALL_OPERATOR

概要

// In header: <boost/yap/user_macros.hpp>

BOOST_YAP_USER_CALL_OPERATOR(expr_template)

说明

为接受任意数量参数的调用运算符 ("operator()") 定义运算符重载, 每个重载产生从表达式模板 expr_template 实例化的表达式. 为限定符 const &、& 与 && 各定义一个重载. 对于左值引用重载, *this 以引用方式捕获进结果表达式. 对于右值引用重载, *this 被移入结果表达式.

每个所定义重载的 u 参数可以是任何类型, 包括表达式. 每个非表达式参数都被包装在终端表达式中.

示例:















 参数: 










expr_template


用于实例化结果表达式的表达式模板. expr_template 必须是 ExpressionTemplate.
