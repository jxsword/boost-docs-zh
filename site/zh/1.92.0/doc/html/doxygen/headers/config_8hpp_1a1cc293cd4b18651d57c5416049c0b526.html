宏 BOOST_PARSER_ASSERT

BOOST_PARSER_ASSERT

概要

// In header: <boost/parser/config.hpp>

BOOST_PARSER_ASSERT(condition)

说明

断言给定条件为真. 若用户定义了宏 BOOST_PARSER_NO_RUNTIME_ASSERTIONS, 则 BOOST_PARSER_ASSERT 展开为编译期的 static_assert(); 否则展开为运行期的 BOOST_ASSERT(). 注意, 定义 BOOST_DISABLE_ASSERTS 会禁用 C assert 的使用, 即使 BOOST_ASSERT 不可用也是如此.
