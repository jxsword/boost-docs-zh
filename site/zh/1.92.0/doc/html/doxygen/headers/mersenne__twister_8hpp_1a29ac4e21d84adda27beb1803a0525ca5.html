类型定义 mt11213b

mt11213b

概要

// In header: <boost/random/mersenne_twister.hpp>


typedef mersenne_twister_engine< uint32_t, 32, 351, 175, 19, 0xccab8ee7, 11, 0xffffffff, 7, 0x31b6ab00, 15, 0xffe50000, 17, 1812433253 > mt11213b;

说明

特化 mt11213b 与 mt19937 来自以下文献:

"Mersenne Twister: 一个 623 维均衡分布的伪随机数生成器", Makoto Matsumoto and Takuji Nishimura, ACM Transactions on Modeling and Computer Simulation: Special Issue on Uniform Random Number Generation, Vol. 8, No. 1, January 1998, pp. 3-30.
