类模板 lagged_fibonacci_01_engine

boost::random::lagged_fibonacci_01_engine

概要

template<typename RealType, int w, unsigned int p, unsigned int q>

说明

类模板 lagged_fibonacci_01 的实例化是 伪随机数生成器 的模型. 它使用带两个滞后量 p 与 q 的滞后斐波那契算法, 以浮点运算求值: x(i) = x(i-p) + x(i-q) (mod 1), 其中 p > q. 参见

"Uniform random number generators for supercomputers", Richard Brent, Proc. of Fifth Australian Supercomputer Conference, Melbourne, Dec. 1992, pp. 704-706.

注释

生成器的质量在很大程度上取决于参数的选择. 用户代码应改用参数设置合理的生成器, 例如 lagged_fibonacci607.

该生成器需要大量内存来存储其状态数组. 例如, lagged_fibonacci607 约需 4856 字节, 而 lagged_fibonacci44497 约需 350 KBytes.

lagged_fibonacci_01_engine 公有成员函数

  1. lagged_fibonacci_01_engine();

    构造一个 lagged_fibonacci_01 生成器并调用 seed().

  2. explicit lagged_fibonacci_01_engine(uint32_t value);

    构造一个 lagged_fibonacci_01 生成器并调用 seed(value).

  3. template<typename SeedSeq> explicit lagged_fibonacci_01_engine(SeedSeq & seq);

    构造一个 lagged_fibonacci_01 生成器并调用 seed(gen).

  4. template<typename It> lagged_fibonacci_01_engine(It & first, It last);
  5. void seed();

    调用 seed(default_seed).

  6. void seed(boost::uint32_t value);

    以构造函数参数值构造一个 minstd_rand0 生成器, 并以该值调用 seed. [1, 2147483647) 范围内不同的种子将产生状态不同的生成器. 其他种子等价于该范围内的某个种子. 详情参见 linear_congruential_engine.

  7. template<typename SeedSeq> void seed(SeedSeq & seq);

    为 lagged_fibonacci_01_engine 播种, 使用 seq.generate 产生的值.

  8. template<typename It> void seed(It & first, It last);

    使用迭代器范围 [first, last) 中的值播种此 lagged_fibonacci_01_engine. 若范围内元素不足, 则抛出 std::invalid_argument.

  9. result_type operator()();

    返回生成器的下一个值.

  10. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

  11. void discard(boost::uintmax_t z);

    把生成器的状态推进 z.

  1. static result_type min();

  2. static result_type max();
