说明

类模板 mersenne_twister_engine 的实例化是 伪随机数生成器 的模型. 它使用如下文献所述的算法:

"Mersenne Twister: 一个 623 维均衡分布的伪随机数生成器", Makoto Matsumoto and Takuji Nishimura, ACM Transactions on Modeling and Computer Simulation: Special Issue on Uniform Random Number Generation, Vol. 8, No. 1, January 1998, pp. 3-30.

注释

Boost 版本是从零实现的, 并未派生自或使用上述 WWW 站点提供的 mt19937.c. 不过已验证二者产生相同的输出.

2005 年 4 月修改了从整数播种的方式, 以解决一个 缺陷.

生成器的质量在很大程度上取决于参数的选择. 用户代码应改用参数设置合理的生成器, 例如 mt19937.

该生成器需要大量内存来存储其状态数组. 例如, mt11213b 约需 1408 字节, 而 mt19937 约需 2496 字节.

mersenne_twister_engine 公有成员函数

  1. mersenne_twister_engine();

    构造一个 mersenne_twister_engine 并调用 seed().

  2. explicit mersenne_twister_engine(UIntType value);

    构造一个 mersenne_twister_engine 并调用 seed(value).

  3. template<typename It> mersenne_twister_engine(It & first, It last);
  4. template<typename SeedSeq> explicit mersenne_twister_engine(SeedSeq & seq);

    构造一个 mersenne_twister_engine 并调用 seed(gen).

    注释

    复制构造函数总是优先于模板构造函数被选用.

  5. void seed();

    调用 seed(default_seed).

  6. void seed(UIntType value);

    将状态 x(0) 设为 v mod 2w. 然后迭代地将 x(i) 设为 (i + f * (x(i-1) xor (x(i-1) rshift w-2))) mod 2w, 其中 i = 1 .. n-1. x(n) 是 operator() 返回的第一个值.

  7. template<typename SeeqSeq> void seed(SeeqSeq & seq);

    使用 seq.generate() 产生的值播种一个 mersenne_twister_engine.

  8. template<typename It> void seed(It & first, It last);

    使用迭代器范围中的值设置生成器的状态.

  9. result_type operator()();

    产生生成器的下一个值.

  10. template<typename Iter> void generate(Iter first, Iter last);

    用随机值填充一个范围

  11. void discard(boost::uintmax_t z);

    将生成器的状态前进 z 步. 等价于

    for(unsigned long long i = 0; i < z; ++i) {
    gen();
}
