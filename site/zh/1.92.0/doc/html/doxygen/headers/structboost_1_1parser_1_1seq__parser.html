结构体模板 seq_parser

boost::parser::seq_parser

概要

// In header: <boost/parser/parser_fwd.hpp>

template<typename ParserTuple, typename BacktrackingTuple, 
         typename CombiningGroups> 
struct seq_parser {
};

说明

按顺序应用 ParserTuple 中的每个解析器. 当且仅当所有子解析器都成功时解析成功. 产生的属性是一个 std::tuple, 其备选类型为 ParserTuple 中各解析器产生的属性类型. BacktrackingTuple 模板参数是一个 parser::tuple, 其元素为 std::bool_constant 值. 第 i 个这样的值指示当第 i 个解析器失败时是否允许回溯.
