函数模板 import_alias

boost::dll::import_alias

概要

// In header: <boost/dll/import.hpp>


template<typename T> 
  result_type import_alias(const boost::dll::fs::path & lib, 
                           const char * name, 
                           load_mode::type mode = load_mode::default_mode);

说明

返回持有从已加载库导入符号的可调用对象或 std::shared_ptr<T> (若定义了 BOOST_DLL_USE_BOOST_SHARED_PTR 则为 boost::shared_ptr<T>). 返回值对已加载共享库的使用进行引用计数, 因而在返回值的所有副本销毁完毕之前, 该库不会卸载.

若以相同符号名调用 boost::dll::shared_library::has(const char* ) 函数返回了 true, 则本次调用将成功.

要按 非别名 导入符号, 请使用 boost::dll::import 方法.

示例: 

std::function<int(int)> f = import_alias<int(int)>("test_lib.so", "integer_func_alias_name");

auto f_cpp11 = import_alias<int(int)>("test_lib.so", "integer_func_alias_name");

std::shared_ptr<int> i = import_alias<int>("test_lib.so", "integer_alias_name");



模板 参数 T: 要导入的符号别名的类型. 必须显式指定.


xmlonly <link linkend='boost.dll.fs.system_error'>boost::dll::fs::system_error</link> 若符号不存在或 DLL/DSO 未加载. 接受路径的重载在内存不足时还会抛出 std::bad_alloc.











 参数: 











lib


要从中加载函数的共享库的路径或共享库对象.






name


要导入的函数或变量的以空字符结尾的 C 或 C++ 修饰名. 可处理 std::string, char*, const char*.






mode


加载库时将使用的模式.











返回:


若 T 是函数类型, 为可调用对象; 若 T 是对象类型, 为 std::shared_ptr<T> (若定义了 BOOST_DLL_USE_BOOST_SHARED_PTR 则为 boost::shared_ptr<T>).
