函数模板 import_class

boost::dll::experimental::import_class

概要

// In header: <boost/dll/import_class.hpp>


template<typename T, typename ... Args> 
  imported_class< T > 
  import_class(smart_library lib, std::size_t size, Args... args);

说明

返回 imported_class 实例, 可用它调用或导入更多函数. 它持有 smart_libray 的一份副本, 因此该对象看不到后加的 type_aliases.

少数编译器实现了分配式构造函数, 无需知道大小即可构造类. 这不可移植, 因此应始终提供类的实际大小.

示例: 

auto import_class<class type_alias, const std::string&, std::size_t>(lib, "class_name", 20, "param1", 42);

本例中, 我们通过一个接受 std::string 的 const 引用与 std::size_t 参数的构造函数, 构造大小为 20 的 "class_name" 类实例, 该实例以 "type_alias" 作为别名.

xmlonly <link linkend='boost.dll.fs.system_error'>boost::dll::fs::system_error</link> 若符号不存在或 DLL/DSO 未加载. 接受路径的重载在内存不足时还会抛出 std::bad_alloc.

参数:

lib

要从中加载函数的共享库的路径或共享库对象.

模板参数:

T

类类型或别名

Args

构造函数实参列表.

返回:

类对象.
