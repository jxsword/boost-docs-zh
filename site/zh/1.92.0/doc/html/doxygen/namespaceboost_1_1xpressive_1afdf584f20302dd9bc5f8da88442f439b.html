函数模板 as_xpr

boost::xpressive::as_xpr — 把字面量变成正则表达式.

概要

// In header: <boost/xpressive/regex_primitives.hpp>


template<typename Literal> unspecified as_xpr(Literal const & literal);

说明

使用 as_xpr() 把字面量变成正则表达式. 例如, "foo" >> "bar" 无法编译, 因为右移运算符的两个操作数都是 const char*, 而这样的运算符并不存在. 请改用 as_xpr("foo") >> "bar".

除字符串字面量外, as_xpr() 也可用于字符字面量. 例如, as_xpr('a') 将匹配一个 'a'. 还可以对字符字面量取反, 如 ~as_xpr('a'), 它将匹配 'a' 以外的任意一个字符.
