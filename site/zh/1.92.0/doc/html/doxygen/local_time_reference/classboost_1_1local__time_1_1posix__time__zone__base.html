类模板 posix_time_zone_base

boost::local_time::posix_time_zone_base — 由 POSIX 时区字符串构造的时区类.

概要

// In header: <boost/date_time/local_time/posix_time_zone.hpp>

template<typename CharT> 
class posix_time_zone_base :
  public date_time::time_zone_base< posix_time::ptime, CharT >
{
public:
  // types
  typedef boost::posix_time::time_duration                                                           time_duration_type;     
  typedef date_time::time_zone_names_base< CharT >                                                   time_zone_names;        
  typedef date_time::time_zone_base< posix_time::ptime, CharT >                                      base_type;              
  typedef base_type::string_type                                                                     string_type;            
  typedef CharT                                                                                      char_type;              
  typedef base_type::stringstream_type                                                               stringstream_type;      
  typedef boost::char_separator< char_type, std::char_traits< char_type > >                          char_separator_type;    
  typedef boost::tokenizer< char_separator_type, typename string_type::const_iterator, string_type > tokenizer_type;         
  typedef tokenizer_type::iterator                                                                   tokenizer_iterator_type;

  // public member functions
  posix_time_zone_base(const string_type &);
  virtual ~posix_time_zone_base();
  virtual string_type std_zone_abbrev() const;
  virtual string_type dst_zone_abbrev() const;
  virtual string_type std_zone_name() const;
  virtual string_type dst_zone_name() const;
  virtual bool has_dst() const;
  virtual posix_time::ptime dst_local_start_time(gregorian::greg_year) const;
  virtual posix_time::ptime dst_local_end_time(gregorian::greg_year) const;
  virtual time_duration_type base_utc_offset() const;
  virtual time_duration_type dst_offset() const;
  virtual string_type to_posix_string() const;

  // private member functions
  void calc_zone(const string_type &);
  void calc_rules(const string_type &, const string_type &);
  void M_func(const string_type &, const string_type &);
  void julian_no_leap(const string_type &, const string_type &);
  void julian_day(const string_type &, const string_type &);

  // private static functions
  static std::string td_as_string(const time_duration_type &);
};

说明

POSIX 时区字符串的形式为:
"std offset dst [offset],start[/time],end[/time]" (无空格). 'std' 指定时区缩写.
'offset' 是相对 UTC 的偏移.
'dst' 指定夏令时期间的时区缩写.
第二个偏移是 DST 期间改变的小时数. 默认=1
'start' 与 'end' 是 DST 生效 (与失效) 的日期.
'offset' 的形式为: [+|-]hh[:mm[:ss]] {h=0-23, m/s=0-59}
'time' 与 'offset' 形式相同. 时间默认=02:00:00
'start' 与 'end' 可以是三种形式之一:
Mm.w.d {month=1-12, week=1-5 (5 总是最后一周), day=0-6}
Jn {n=1-365, 闰年也不计入 Feb29}
n {n=0-365, 闰年计入 Feb29}
示例 "PST-5PDT01:00:00,M4.1.0/02:00:00,M10.1.0/02:00:00"
在以下条件下会抛出异常:
无效的日期规格 (见 date 类)
针对: boost::local_time::bad_offset 异常会被抛出:
DST 起始或结束偏移为负或超过 24 小时
UTC 时区大于 +14 小时或小于 -12 小时
针对: boost::local_time::bad_adjustment 异常会被抛出:
DST 调整量达到或超过 24 小时 (正或负)

注意 UTC 时区偏移可以大于 +12: http://www.worldtimezone.com/utc/utc+1200.html

posix_time_zone_base 公有成员函数

  1. posix_time_zone_base(const string_type & s);
    从 POSIX 时区字符串构造.
  2. virtual ~posix_time_zone_base();
  3. virtual string_type std_zone_abbrev() const;
    不处于夏令时的时区字符串 (例如: EST)
  4. virtual string_type dst_zone_abbrev() const;
    夏令时期间时区的字符串 (如: EDT)

    对于没有 DST 的时区, 使用空字符串

  5. virtual string_type std_zone_name() const;
    非夏令时期间时区的字符串 (如: Eastern Standard Time)

    完整的 STD 名称不会从 POSIX 时区字符串中提取. 因此, 用 STD 缩写代替

  6. virtual string_type dst_zone_name() const;
    夏令时期间时区的字符串 (如: Eastern Daylight Time)

    完整的 DST 名称不会从 POSIX 时区字符串中提取. 因此, 用 STD 缩写代替. 对于没有 DST 的时区, 使用空字符串

  7. virtual bool has_dst() const;
    如果时区使用夏令时调整则为 true, 否则为 false.
  8. virtual posix_time::ptime dst_local_start_time(gregorian::greg_year y) const;
    夏令时开始的本地时间, 若 has_dst 为 false 则为 NADT.
  9. virtual posix_time::ptime dst_local_end_time(gregorian::greg_year y) const;
    夏令时结束的本地时间, 若 has_dst 为 false 则为 NADT.
  10. virtual time_duration_type base_utc_offset() const;
    时区相对 UTC 的基础偏移量 (例如: -07:30:00)
  11. virtual time_duration_type dst_offset() const;
    DST 生效期间进行的前调或后调量.
  12. virtual string_type to_posix_string() const;
    返回此对象的 POSIX time_zone 字符串.

posix_time_zone_base 私有成员函数

  1. void calc_zone(const string_type & obj);

    提取 STD 与 DST 的时区缩写, 以及发生的时移偏移与偏移量. 目前不会提取完整的时区名称, 因此用缩写代替

  2. void calc_rules(const string_type & start, const string_type & end);
  3. void M_func(const string_type & s, const string_type & e);
  4. void julian_no_leap(const string_type & s, const string_type & e);
    儒略日. 即使在闰年也不计入 Feb29.
  5. void julian_day(const string_type & s, const string_type & e);
    儒略日. 总是计入 Feb29, 但在非闰年抛出异常.

posix_time_zone_base 私有静态函数

  1. static std::string td_as_string(const time_duration_type & td);
    抛出异常时使用的辅助函数
