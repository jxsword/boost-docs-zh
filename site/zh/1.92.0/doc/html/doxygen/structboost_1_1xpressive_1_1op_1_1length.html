结构体 length

boost::xpressive::op::length — length 是一个用于获取 sub_match 长度的 PolymorphicFunctionObject.

概要

// In header: <boost/xpressive/regex_actions.hpp>


struct length {
  // member classes/structs/unions
  template<typename Sig> 
  struct result {
  };
  template<typename This, typename Sub> 
  struct result<This(Sub)> {
    // types
    typedef remove_reference< Sub >::type::difference_type type;
  };

  // public member functions
  template<typename Sub> Sub::difference_type operator()(Sub const &) const;
};

说明

length 公有成员函数

  1. template<typename Sub> Sub::difference_type operator()(Sub const & sub) const;

    参数:

    sub

    该 sub_match 对象.

    返回:

    sub.length()
