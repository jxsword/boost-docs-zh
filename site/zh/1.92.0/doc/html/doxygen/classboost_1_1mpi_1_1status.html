类 status

boost::mpi::status — 包含关于已接收或可接收消息的信息.

概要

// In header: <boost/mpi/status.hpp>


class status {
public:

  // public member functions
  status();
  status(MPI_Status const &);
  int source() const;
  int tag() const;
  int error() const;
  bool cancelled() const;
  template<typename T> optional< int > count() const;
  operator MPI_Status &();
  operator const MPI_Status &() const;

  // public data members
  mutable int m_count;
};

说明

此结构包含关于已接收 (通过 communicator::recv) 或可接收 (从 communicator::probe 或 communicator::iprobe 返回) 的消息的状态信息. 它允许访问消息的源, 消息标签, 错误码 (很少使用) 或已传输的元素数量.

status 公有成员函数

  1. status();
  2. status(MPI_Status const & s);
  3. int source() const;

    获取消息的源.

  4. int tag() const;

    获取消息标签.

  5. int error() const;

    获取错误码.

  6. bool cancelled() const;

    确定与此对象关联的通信是否已成功取消.

  7. template<typename T> optional< int > count() const;

    确定消息中包含的类型为 T 的元素数量. 类型 T 必须有关联的数据类型, 即 is_mpi_datatype<T> 必须派生 mpl::true_. 当类型 T 与传输的类型不匹配时, 此例程将返回空的 optional<int>.

    返回:

    消息中 T 元素的数量 (如果可以确定).

    引用底层 MPI_Status
