结构体模板 pointer_traits

boost::intrusive::pointer_traits

概要

// In header: <boost/intrusive/pointer_traits.hpp>

template<typename Ptr> 
struct pointer_traits {
  // types
  typedef Ptr              pointer;        
  typedef unspecified_type element_type;   
  typedef unspecified_type difference_type;
  template<typename U> 
  using rebind = unspecified;
  typedef unspecified_type reference;      

  // public static functions
  static pointer pointer_to(reference) noexcept;
  template<typename UPtr> 
    static pointer static_cast_from(const UPtr &) noexcept;
  template<typename UPtr> 
    static pointer const_cast_from(const UPtr &) noexcept;
  template<typename UPtr> 
    static pointer dynamic_cast_from(const UPtr &) noexcept;
};

说明

pointer_traits 是 C++11 std::pointer_traits 类的实现, 并带有诸如转换之类的一些扩展.

pointer_traits 为类指针类型的某些属性提供统一接口.

注释: 当定义与 BI 库一起使用的自定义指针或引用族时, 请确保通过 pointer_traits 接口 (*_cast_from 与 pointer_to) 访问的公有静态转换函数, 能够 在不调用隐式构造函数的情况下 在 const 与非 const 的被指成员类型之间正确转换. 建议将这些转换实现为函数模板, 其中模板实参为被转换对象的类型.

pointer_traits 公有类型

  1. typedef Ptr pointer;

    此 pointer_traits 实例化所查询的指针类型

  2. typedef unspecified_type element_type;

    若存在 Ptr::element_type 这样的类型, 则为其; 否则, 若 Ptr 是 SomePointer<T, Args> 形式的类模板实例化 (其中 Args 为零个或多个类型实参) , 则为 T; 否则, 该特化是非良构的.

  3. typedef unspecified_type difference_type;

    若存在 Ptr::difference_type 这样的类型, 则为其; 否则为 std::ptrdiff_t.

  4. template<typename U> using rebind = unspecified;

    Ptr::rebind<underline> 若存在这样的类型; 否则, 若 Ptr 是 SomePointer<T, Args> 形式的类模板实例化 (其中 Args 为零个或多个类型实参) , 则为 SomePointer<U, Args>; 否则, rebind 的实例化是非良构的. </underline>

    <underline>对于 C++03 与 C++11 的可移植代码, 应使用 

    typename rebind_pointer<U>::type
    而非 rebind<underline> 来获得指向 U 的指针. </underline></underline>

  5. typedef unspecified_type reference;

    若存在 Ptr::reference 这样的类型 (非标准扩展) , 则为其; 否则为 element_type &

pointer_traits 公有静态函数

  1. static pointer pointer_to(reference r) noexcept;

    备注: 若 element_type 为 (可能带 cv 限定符的) void, 则 r 的类型未指明; 否则为 element_type &.

    返回: 通过调用 Ptr::pointer_to(reference) 得到的指向 r 的可解引用指针. 非标准扩展: 若该函数不存在, 则返回 pointer(addressof(r));

    注释: 对于不符合标准的编译器, 只检查是否存在名为 pointer_to 的成员函数.

  2. template<typename UPtr> 
  static pointer static_cast_from(const UPtr & uptr) noexcept;

    备注: 非标准扩展.

    返回: 通过调用静态模板函数 Ptr::static_cast_from(UPpr/const UPpr &) 得到的指向 r 的可解引用指针. 若该函数不存在, 则返回 pointer_to(static_cast<element_type&>(*uptr))

    注释: 对于不符合标准的编译器, 只检查是否存在名为 static_cast_from 的成员函数.

  3. template<typename UPtr> 
  static pointer const_cast_from(const UPtr & uptr) noexcept;

    备注: 非标准扩展.

    返回: 通过调用静态模板函数 Ptr::const_cast_from<UPtr>(UPpr/const UPpr &) 得到的指向 r 的可解引用指针. 若该函数不存在, 则返回 pointer_to(const_cast<element_type&>(*uptr))

    注释: 对于不符合标准的编译器, 只检查是否存在名为 const_cast_from 的成员函数.

  4. template<typename UPtr> 
  static pointer dynamic_cast_from(const UPtr & uptr) noexcept;

    备注: 非标准扩展.

    返回: 通过调用静态模板函数 Ptr::dynamic_cast_from<UPtr>(UPpr/const UPpr &) 得到的指向 r 的可解引用指针. 若该函数不存在, 则返回 pointer_to(dynamic_cast<element_type>(&*uptr))

    注释: 对于不符合标准的编译器, 只检查是否存在名为 dynamic_cast_from 的成员函数.
