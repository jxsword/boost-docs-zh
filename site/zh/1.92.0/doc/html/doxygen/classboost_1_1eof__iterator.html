类模板 eof_iterator

boost::eof_iterator

概要

// In header: <boost/program_options/eof_iterator.hpp>

template<typename Derived, typename ValueType> 
class eof_iterator :
  public iterator_facade< Derived, const ValueType, forward_traversal_tag >
{
public:

  // public member functions
  eof_iterator();

  // protected member functions
  ValueType & value();
  void found_eof();

  // private member functions
  void increment();
  bool equal(const eof_iterator &) const;
  const ValueType & dereference() const;
};

说明

'eof_iterator' 类适用于构造前向迭代器的场景: 迭代器从某个源提取数据, 并且很容易检测到 'eof' (即没有数据的情况). 一个明显的例子是从文件中读取行.

直接使用 'iterator_facade' 实现此类迭代器需要创建一个带三个核心操作和几个构造函数的类. 使用 'eof_iterator' 时, 派生类只需定义一个获取新值的方法, 外加几个构造函数.

基本思想是迭代器有一个 'eof' 位. 只有当两个迭代器的 'eof' 位都已置位时, 它们才相等. 'get' 方法要么获取新值, 要么设置 'eof' 位.

具体来说, 派生类应定义:

  1. 默认构造函数, 创建带 'eof' 位的迭代器. 构造函数体应调用此处定义的 'found_eof' 方法.

  2. 另一个构造函数. 它应初始化迭代器操作中使用的某个 '数据指针', 然后调用 'get'.

  3. 'get' 方法. 它应按如下方式工作:

    • 查看某个 '数据指针' 以确定是否有新元素可用; 若没有, 应调用 'found_eof'.

    • 提取新元素并存储到 'value' 方法返回的位置.

    • 前移数据指针.

本质上, 'get' 方法兼具 'increment' 与 'dereference' 的功能. 这非常适合数据提取会隐式移动数据指针的情况, 例如流操作.

eof_iterator 公有成员函数

  1. eof_iterator();

eof_iterator 受保护成员函数

  1. ValueType & value();

    返回派生类应用来存储下一个值的引用.

  2. void found_eof();

    应由派生类调用, 以指示它无法产生下一个元素.

eof_iterator 私有成员函数

  1. void increment();
  2. bool equal(const eof_iterator & other) const;
  3. const ValueType & dereference() const;
