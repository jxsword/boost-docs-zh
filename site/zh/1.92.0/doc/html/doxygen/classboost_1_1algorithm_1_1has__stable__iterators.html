类模板 has_stable_iterators

boost::algorithm::has_stable_iterators — 迭代器稳定特征.

概要

// In header: <boost/algorithm/string/sequence_traits.hpp>

template<typename T> 
class has_stable_iterators {
public:
  // types
  typedef mpl::bool_< has_stable_iterators< T >::value > type;

  // public data members
  static const bool value;
};

说明

此特征指定序列具有稳定迭代器. 这意味着 insert/erase/replace 等操作不会使迭代器失效.
