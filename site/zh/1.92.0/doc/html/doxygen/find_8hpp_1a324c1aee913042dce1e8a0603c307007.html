函数模板 find_token

boost::find_token — 查找标记算法.

概要

// In header: <boost/algorithm/string/find.hpp>


template<typename RangeT, typename PredicateT> 
  iterator_range< typename range_iterator< RangeT >::type > 
  find_token(RangeT & Input, PredicateT Pred, 
             token_compress_mode_type eCompress = token_compress_off);

说明

在字符串中查找给定的标记. 标记是匹配给定谓词的字符. 如果启用了标记压缩模式, 相邻标记被视为一个匹配.

注释

此函数提供强异常安全保证

参数:

Input

输入字符串.

Pred

用于标识标记的一元谓词

eCompress

启用/禁用相邻标记的压缩

返回:

分隔匹配的 iterator_range. 返回的迭代器为 RangeT::iterator 或 RangeT::const_iterator, 取决于输入参数的常量性.
