结构体模板 match_results

boost::xpressive::match_results — 类模板 match_results<> 以 sub_match 对象集合的形式保存 regex_match() 或 regex_search() 的结果.

概要

// In header: <boost/xpressive/match_results.hpp>

template<typename BidiIter> 
struct match_results {
  // types
  typedef iterator_value< BidiIter >::type      char_type;          
  typedef unspecified                           string_type;        
  typedef std::size_t                           size_type;          
  typedef sub_match< BidiIter >                 value_type;         
  typedef iterator_difference< BidiIter >::type difference_type;    
  typedef value_type const &                    reference;          
  typedef value_type const &                    const_reference;    
  typedef unspecified                           iterator;           
  typedef unspecified                           const_iterator;     
  typedef unspecified                           nested_results_type;

  // public member functions
  match_results();
  match_results(match_results< BidiIter > const &);
  ~match_results();
  match_results< BidiIter > & operator=(match_results< BidiIter > const &);
  size_type size() const;
  bool empty() const;
  difference_type length(size_type = 0) const;
  difference_type position(size_type = 0) const;
  string_type str(size_type = 0) const;
  template<typename Sub> const_reference operator[](Sub const &) const;
  const_reference prefix() const;
  const_reference suffix() const;
  const_iterator begin() const;
  const_iterator end() const;
  operator bool_type() const;
  bool operator!() const;
  regex_id_type regex_id() const;
  nested_results_type const & nested_results() const;
  template<typename Format, typename OutputIterator> 
    OutputIterator 
    format(OutputIterator, Format const &, 
           regex_constants::match_flag_type = regex_constants::format_default, 
           unspecified = 0) const;
  template<typename OutputIterator> 
    OutputIterator 
    format(OutputIterator, char_type const *, 
           regex_constants::match_flag_type = regex_constants::format_default) const;
  template<typename Format, typename OutputIterator> 
    string_type format(Format const &, 
                       regex_constants::match_flag_type = regex_constants::format_default, 
                       unspecified = 0) const;
  string_type format(char_type const *, 
                     regex_constants::match_flag_type = regex_constants::format_default) const;
  void swap(match_results< BidiIter > &);
  template<typename Arg> match_results< BidiIter > & let(Arg const &);
};

说明

类模板 match_results<> 表示由若干序列组成的集合, 代表一次正则表达式匹配的结果. 集合所需的存储由类 match_results<> 的成员函数按需分配与释放.

类模板 match_results<> 符合 (lib.sequence.reqmts) 中规定的 Sequence 要求, 只是只支持为 const 限定的 Sequence 定义的操作.

  5. size_type size() const;

    若 *this 表示一次成功匹配的结果, 则返回被匹配正则表达式中带标记子表达式的数量加一. 否则返回 0.

  6. bool empty() const;

    返回 size() == 0.

  7. difference_type length(size_type sub = 0) const;

    返回 (*this)[sub].length().

  8. difference_type position(size_type sub = 0) const;

    若 !(*this)[sub].matched 则返回 -1. 否则返回 std::distance(base, (*this)[sub].first), 其中 base 是被搜索序列的起始迭代器. [注 - 除非它是 regex_iterator 重复搜索的一部分, 否则 base 与 prefix().first 相同 - 注完]

  9. string_type str(size_type sub = 0) const;

    返回 (*this)[sub].str().

  10. template<typename Sub> const_reference operator[](Sub const & sub) const;

    返回对表示匹配了带标记子表达式 sub 的序列的 sub_match 对象的引用. 若 sub == 0, 则返回对表示匹配整个正则表达式的序列的 sub_match 对象的引用. 若 sub >= size(), 则返回表示未匹配子表达式的 sub_match 对象.

  11. const_reference prefix() const;

    返回对表示从被匹配/搜索字符串的开头到所找到匹配开头的字符序列的 sub_match 对象的引用.

    要求:

    (*this)[0].matched 为 true

  19. template<typename Format, typename OutputIterator> 
  OutputIterator 
  format(OutputIterator out, Format const & fmt, 
         regex_constants::match_flag_type flags = regex_constants::format_default, 
         unspecified = 0) const;

    若 Format 满足 ForwardRange 或是以空字符结尾的字符串, 此函数把 fmt 中的字符序列复制到 OutputIterator out. 对于 fmt 中的每个格式说明符或转义序列, 将其替换为它所表示的字符, 或 *this 中它所引用的序列. flags 中指定的位掩码决定识别哪些格式说明符或转义序列. 默认情况下, 使用 ECMA-262、ECMAScript Language Specification 第 15 章第 5.4.11 节 String.prototype.replace 所用的格式.

    否则, 若 Format 满足 Callable<match_results<BidiIter>, OutputIterator, regex_constants::match_flag_type>, 此函数返回 fmt(*this, out, flags).

    否则, 若 Format 满足 Callable<match_results<BidiIter>, OutputIterator>, 此函数返回 fmt(*this, out).

    否则, 若 Format 满足 Callable<match_results<BidiIter> >, 此函数返回 std::copy(x.begin(), x.end(), out), 其中 x 是调用 fmt(*this) 的结果.

  21. template<typename Format, typename OutputIterator> 
  string_type format(Format const & fmt, 
                     regex_constants::match_flag_type flags = regex_constants::format_default, 
                     unspecified = 0) const;

    若 Format 满足 ForwardRange 或是以空字符结尾的字符串, 此函数返回字符序列 fmt 的副本. 对于 fmt 中的每个格式说明符或转义序列, 将其替换为它所表示的字符, 或 *this 中它所引用的序列. flags 中指定的位掩码决定识别哪些格式说明符或转义序列. 默认情况下, 使用 ECMA-262、ECMAScript Language Specification 第 15 章第 5.4.11 节 String.prototype.replace 所用的格式.

    否则, 若 Format 满足 Callable<match_results<BidiIter>, OutputIterator, regex_constants::match_flag_type>, 此函数返回一个 string_type 对象 x, 它通过调用 fmt(*this, out, flags) 填充, 其中 out 为 back_insert_iterator (指向 x) .

    否则, 若 Format 满足 Callable<match_results<BidiIter>, OutputIterator>, 此函数返回一个 string_type 对象 x, 它通过调用 fmt(*this, out) 填充, 其中 out 为 back_insert_iterator (指向 x) .

    否则, 若 Format 满足 Callable<match_results<BidiIter> >, 此函数返回 fmt(*this).
