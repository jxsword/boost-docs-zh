类型 level

boost::mpi::threading::level — 指定支持的线程级别.

概要

// In header: <boost/mpi/environment.hpp>


enum level { single, funneled, serialized, multiple };

说明

基于 MPI 2 标准/8.7.3

single

只有一个线程会执行.

funneled

只有主线程会进行 MPI 调用.

进程可以是多线程的, 但只有主线程会进行 MPI 调用 (所有 MPI 调用都 <lsquo></lsquo>funneled<rsquo></rsquo> 到主线程).

serialized

同一时间只有一个线程进行 MPI 调用.

进程可以是多线程的, 且多个线程可以进行 MPI 调用, 但一次只有一个: 不会从两个不同线程并发进行 MPI 调用 (所有 MPI 调用都是 <lsquo></lsquo>serialized<rsquo></rsquo> 的).

multiple

多个线程可以进行 MPI 调用.

多个线程可以调用 MPI, 没有限制.
