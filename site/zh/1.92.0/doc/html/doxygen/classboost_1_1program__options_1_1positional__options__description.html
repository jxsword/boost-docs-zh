类 positional_options_description

boost::program_options::positional_options_description

概要

// In header: <boost/program_options/positional_options.hpp>


class positional_options_description {
public:

  // public member functions
  positional_options_description();
  positional_options_description & add(const char *, int);
  unsigned max_total_count() const;
  const std::string & name_for_position(unsigned) const;
};

说明

描述位置选项.

此类用于推测位置选项的选项名. 位置选项在命令行上指定, 并通过位置识别. 该类使用用户提供的信息将名称与每个位置选项相关联, 或指出没有已知名称.

基本假设是只有位置选项自身的相对顺序才有意义, 任何穿插其间的普通选项都不会影响位置选项的解释.

用户通过以下方式初始化该类: 指定前 N 个位置选项应赋予名称 X1, 随后 M 个选项应赋予名称 X2, 依此类推.

positional_options_description 公有成员函数

  1. positional_options_description();
  2. positional_options_description & add(const char * name, int max_count);

    指定接下来的最多 'max_count' 个位置选项应被赋予 'name'. '-1' 表示 '无限制'. 在以 'max_value' 等于 '-1' 调用之后, 不能再调用 'add'.

  3. unsigned max_total_count() const;

    返回可存在的位置选项的最大数量. 可返回 (numeric_limits<unsigned>::max)() 以表示数量无限制.

  4. const std::string & name_for_position(unsigned position) const;

    返回应与 'position' 处的位置选项关联的名称. 前置条件: position < max_total_count()
