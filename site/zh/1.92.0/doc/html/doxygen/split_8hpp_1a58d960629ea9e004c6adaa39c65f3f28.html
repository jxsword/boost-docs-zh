函数模板 split

boost::split — 切分算法.

概要

// In header: <boost/algorithm/string/split.hpp>


template<typename SequenceSequenceT, typename RangeT, typename PredicateT> 
  SequenceSequenceT & 
  split(SequenceSequenceT & Result, RangeT && Input, PredicateT Pred, 
        token_compress_mode_type eCompress = token_compress_off);

说明

分词表达式. 该函数等价于 C 的 strtok. 输入序列被切分成记号, 由分隔符隔开. 分隔符通过谓词给出.

每个部分都会被复制并作为新元素加入输出容器. 因此结果容器必须能容纳匹配结果的副本 (以兼容结构如 std::string) 或其引用 (例如使用 iterator range 类). 这类容器的示例有 std::vector<std::string> 或 std::list<boost::iterator_range<std::string::iterator>>

注释

结果中原有的内容将被覆盖.

注释

此函数提供强异常安全保证

参数:

Result

能容纳子串引用副本的容器

Input

将被搜索的容器.

Pred

用于识别分隔符的谓词. 若给定元素是分隔符, 该谓词应返回 true.

eCompress

若 eCompress 实参设为 token_compress_on, 相邻分隔符合并在一起. 否则, 每两个分隔符界定一个记号.

返回:

结果的引用
