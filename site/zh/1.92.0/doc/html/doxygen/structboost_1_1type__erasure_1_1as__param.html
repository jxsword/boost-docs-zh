结构体模板 as_param

boost::type_erasure::as_param — 创建 param 的元函数.

概要

// In header: <boost/type_erasure/param.hpp>

template<typename Any, typename T> 
struct as_param {
  // types
  typedef unspecified type;
};

说明

若 T 是 (带 cv/引用限定的) 占位符, 则返回 param<concept_of<Any>::type, T>; 否则返回 T. 此元函数旨在用于 concept_interface 特化中的函数实参.

参见: derived、rebind_any
