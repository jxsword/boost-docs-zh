结构体模板 is_mpi_op

boost::mpi::is_mpi_op — 判断函数对象是否有关联的 MPI_Op.

概要

// In header: <boost/mpi/operations.hpp>

template<typename Op, typename T> 
struct is_mpi_op : public boost::mpl::false_ {
};

说明

该特征判断函数对象类型 Op 与实参类型 T 一起使用时是否有关联的 MPI_Op. 若有, is_mpi_op<Op,T> 将派生自 mpl::false_, 并包含一个静态成员函数 op, 它不接受实参但返回关联的 MPI_Op 值. 例如, is_mpi_op<std::plus<int>,int>::op() 返回 MPI_SUM.

用户可以为任何其他类模板特化 is_mpi_op——只要它们映射到具有 MPI_Op 等价物的运算, 例如按位或、逻辑与或最大值. 不过, 鼓励用户尽可能使用 functional 与 boost/mpi/operations.hpp 头文件中的标准函数对象. 对于只有一个模板形参的函数对象类模板, 特化 is_builtin_mpi_op 可能更容易.
