结构体模板 spsc_value

boost::lockfree::spsc_value

概要

// In header: <boost/lockfree/spsc_value.hpp>

template<typename T, typename... Options> 
struct spsc_value {

  // public member functions
  explicit spsc_value();
  explicit spsc_value(T);
  void write(T &&);
  void write(const T &);
  bool read(T &);
  std::optional< T > read(uses_optional_t);
  template<typename Functor> bool consume(Functor &&);
};

说明

spcs_value 提供一个单写者/单读者的值, 由三重缓冲实现

策略:

  • boost::lockfree::allow_multiple_reads, 默认为 boost::lockfree::allow_multiple_reads<false>
    若允许多次读取, 写入 spsc_value 的值可被读取多次, 但不能移出该实例. 若不允许多次读取, 该类的行为相当于一个写时覆盖的单元素队列

spsc_value 公有成员函数

  1. explicit spsc_value();

    构造一个 spsc_value

    若配置为 boost::lockfree::allow_multiple_reads<true>, 则将其初始化为默认构造的值

  2. explicit spsc_value(T value);

    构造一个 spsc_value, 初始化为给定的值

  3. void write(T && value);

    把 value 写入 spsc_value

    注释

    线程安全且无等待

    要求:

    只允许一个线程向 spsc_value 写入数据

    后置条件:

    对象将被写入 spsc_value

    		 
  4. void write(const T & value);

    把 value 写入 spsc_value

    注释

    线程安全且无等待

    要求:

    只允许一个线程向 spsc_value 写入数据

    后置条件:

    对象将被写入 spsc_value

    		 
  5. bool read(T & ret);

    读取 spsc_value

    注释

    线程安全且无等待

    要求:

    只允许一个线程向 spsc_value 写入数据

    后置条件:

    若读取成功, 对象将被复制到 ret.

    返回:

    true, 若读取成功则为该值; 若 spsc_value 配置为 boost::lockfree::allow_multiple_reads<false> 且没有可读取的值, 则为 false

    		 
  6. std::optional< T > read(uses_optional_t);

    读取 spsc_value 的内容, 返回一个 optional

    注释

    线程安全且无等待

    要求:

    只允许一个线程向 spsc_value 写入数据

    返回:

    std::optional 成功时含有值, std::nullopt 表示 spsc_value 配置为 boost::lockfree::allow_multiple_reads<false> 且没有可读取的值

    		 
  7. template<typename Functor> bool consume(Functor && f);

    通过函子消费值

    从 spsc_value 读取元素并对该对象应用函子

    注释

    线程安全且不阻塞 (前提是函子线程安全且不阻塞)

    返回:

    true, 若元素已被消费
