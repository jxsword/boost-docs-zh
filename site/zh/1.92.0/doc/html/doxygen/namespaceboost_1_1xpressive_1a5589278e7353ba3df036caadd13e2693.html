boost::xpressive::space — 匹配空白字符.

概要

// In header: <boost/xpressive/regex_primitives.hpp>

unspecified space;

说明

正则特征用于确定哪些字符是空白字符. 要匹配任何非空白字符, 请使用 ~space.

重要

space 等价于 perl 中的 /[[:space:]]/. ~space 等价于 perl 中的 /[[:^space:]]/.
