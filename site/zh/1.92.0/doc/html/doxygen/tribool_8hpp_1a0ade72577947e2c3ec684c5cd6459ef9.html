函数 indeterminate

boost::indeterminate — 表示 tribool 不确定值的关键字与测试函数.

概要

// In header: <boost/logic/tribool.hpp>


BOOST_CONSTEXPR bool indeterminate(tribool x, unspecified dummy = unspecified);

说明

indeterminate 函数有双重角色. 第一个角色是作为一元函数, 判断 tribool 值是否处于 "indeterminate" 状态. 第二个角色是作为表示不确定值的关键字 (就像 "true" 与 "false" 表示真与假状态一样) . 若你不喜欢 "indeterminate" 这个名称而想用别的名称, 参见宏 BOOST_TRIBOOL_THIRD_STATE.

返回:

x.value == tribool::indeterminate_value

抛出:

 不会抛出异常.
