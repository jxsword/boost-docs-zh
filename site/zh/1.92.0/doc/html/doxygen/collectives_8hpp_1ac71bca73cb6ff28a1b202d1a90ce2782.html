函数 scatter

boost::mpi::scatter — 把根进程存储的值分散到通信器内的所有进程.

概要

// In header: <boost/mpi/collectives.hpp>


template<typename T> 
  void scatter(const communicator & comm, const std::vector< T > & in_values, 
               T & out_value, int root);
template<typename T> 
  void scatter(const communicator & comm, const T * in_values, T & out_value, 
               int root);
template<typename T> 
  void scatter(const communicator & comm, T & out_value, int root);
template<typename T> 
  void scatter(const communicator & comm, const std::vector< T > & in_values, 
               T * out_values, int n, int root);
template<typename T> 
  void scatter(const communicator & comm, const T * in_values, T * out_values, 
               int n, int root);
template<typename T> 
  void scatter(const communicator & comm, T * out_values, int n, int root);

说明

scatter 是一种集合算法, 它把 root 进程存储的值 (在一个向量中) 分散到通信器中的所有进程. 向量 out_values (仅在 root 处有效) 按对应值将被发送到的进程号索引. 值的类型 T 可以是可序列化的类型或具有关联 MPI 数据类型的类型.

当类型 T 具有关联的 MPI 数据类型时, 此例程调用 MPI_Scatter 来分散值.

参数:

comm

发生分散 (scatter) 的通信器.

in_values

一个向量或指向存储的指针, 将包含要发送给每个进程的值, 按进程秩索引. 对于非根进程, 此参数可以省略. 不过, 如果仍提供了它, 它将保持不变.

out_value

每个进程接收的值. 分散值数组时, out_values 指向每个进程将接收的 n 个值.

root

将分散这些值的进程 ID 号. 此值在所有进程上必须相同.
