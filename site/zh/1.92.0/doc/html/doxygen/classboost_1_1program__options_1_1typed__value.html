类模板 typed_value

boost::program_options::typed_value

概要

// In header: <boost/program_options/value_semantic.hpp>

template<typename T, typename charT = char> 
class typed_value : public boost::program_options::value_semantic_codecvt_helper< char >,
                    public boost::program_options::typed_value_base
{
public:

  // public member functions
  typed_value(T *);
  typed_value * default_value(const T &);
  typed_value * default_value(const T &, const std::string &);
  typed_value * implicit_value(const T &);
  typed_value * value_name(const std::string &);
  typed_value * implicit_value(const T &, const std::string &);
  typed_value * notifier(function1< void, const T & >);
  typed_value * composing();
  typed_value * multitoken();
  typed_value * zero_tokens();
  typed_value * required();
  virtual std::string name() const;
  virtual bool is_composing() const;
  virtual unsigned min_tokens() const;
  virtual unsigned max_tokens() const;
  virtual bool is_required() const;
  void xparse(boost::any &, const std::vector< std::basic_string< charT > > &) const;
  virtual bool apply_default(boost::any &) const;
  virtual void notify(const boost::any &) const;
  virtual const std::type_info & value_type() const;
};

说明

处理特定类型值的类.

typed_value 公有成员函数

  1. typed_value(T * store_to);

    构造函数. 'store_to' 参数指定在值确定后存储到哪里. 该参数可以为 NULL.

  2. typed_value * default_value(const T & v);

    指定默认值, 在未显式指定时使用. 类型 'T' 应为 ostream 提供 operator<<.

  3. typed_value * default_value(const T & v, const std::string & textual);

    指定默认值, 在未显式指定时使用. 与上面的重载不同, 类型 'T' 无须为 ostream 提供 operator<<, 但默认值的文本表示必须由用户提供.

  4. typed_value * implicit_value(const T & v);

    指定隐式值, 当给出选项但没有相邻值时使用. 使用它意味着显式值是可选的.

  5. typed_value * value_name(const std::string & name);

    指定帮助消息中用于该值的名称.

  6. typed_value * implicit_value(const T & v, const std::string & textual);

    指定隐式值, 当给出选项但没有相邻值时使用. 使用它意味着显式值是可选的, 但如果给出, 则必须与选项严格相邻, 即 '-ovalue' 或 '–option=value'. 给出 '-o' 或 '–option' 将应用隐式值. 与上面的重载不同, 类型 'T' 无须为 ostream 提供 operator<<, 但默认值的文本表示必须由用户提供.

  7. typed_value * notifier(function1< void, const T & > f);

    指定在最终值确定时要调用的函数.

  8. typed_value * composing();

    指定该值是可组合的. 说明见 'is_composing' 方法.

  9. typed_value * multitoken();

    指定该值可跨越多个标记.

  10. typed_value * zero_tokens();

    指定不得为该选项的值提供任何标记, 即只有选项的存在才有意义. 要使此类选项有用, 应特化 'validate' 函数, 或同时使用 'implicit_value' 方法. 大多数情况下, 可以用 'bool_switch' 函数代替使用此方法.

  11. typed_value * required();

    指定该值必须出现.

  12. virtual std::string name() const;

    返回选项的名称. 该名称仅对自动帮助消息有意义.

  13. virtual bool is_composing() const;

    如果来自不同源的值应当组合, 则返回 true. 否则, 使用第一个源的值, 其他源的值被丢弃.

  14. virtual unsigned min_tokens() const;

    该选项在命令行上应存在的最少标记数量.

  15. virtual unsigned max_tokens() const;

    该选项在命令行上应存在的最多标记数量.

  16. virtual bool is_required() const;

    如果必须给出值则返回 true. 非可选值

  17. void xparse(boost::any & value_store, 
            const std::vector< std::basic_string< charT > > & new_tokens) const;

    创建 'validator' 类的实例并调用其 operator() 执行实际转换.

  18. virtual bool apply_default(boost::any & value_store) const;

    如果之前通过调用 'default_value' 指定了默认值, 则将该值存入 'value_store'. 如果已存储默认值则返回 true.

  19. virtual void notify(const boost::any & value_store) const;

    如果创建 *this 时指定了存储值的变量地址, 则将值存储到那里. 否则不做任何事.

  20. virtual const std::type_info & value_type() const;
