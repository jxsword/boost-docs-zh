函数 scatterv

boost::mpi::scatterv — 与 boost::mpi::scatter 类似, 区别在于根进程存储的值数量不必是通信器大小的倍数.

概要

// In header: <boost/mpi/collectives.hpp>

说明

参数:

comm

发生分散 (scatter) 的通信器.

in_values

一个向量或指向存储的指针, 将包含要发送给每个进程的值, 按进程秩索引. 对于非根进程, 此参数可以省略. 不过, 如果仍提供了它, 它将保持不变.

sizes

包含每个非根进程将接收的元素数量的向量.

displs

一个向量, 其第 i 项指定相对于 in_values 的位移, 从该位移处取出要发送给进程 i 的外发数据. 省略 displs 的重载版本假定数据在 root 进程处是连续的.

out_values

每个进程接收的值数组.

out_size

对每个非根进程, 这里将包含 out_values 的大小.

root

将分散这些值的进程 ID 号. 此值在所有进程上必须相同.
