类模板 slist_base_hook

boost::intrusive::slist_base_hook

概要

// In header: <boost/intrusive/slist_hook.hpp>

template<class ... Options> 
class slist_base_hook : public make_slist_base_hook::type {
public:

  // public member functions
  slist_base_hook() noexcept;
  slist_base_hook(const slist_base_hook &) noexcept;
  slist_base_hook & operator=(const slist_base_hook &) noexcept;
  ~slist_base_hook();
  void swap_nodes(slist_base_hook &) noexcept;
  bool is_linked() const noexcept;
  void unlink() noexcept;
};

说明

从 slist_base_hook 派生一个类, 以便把对象存储在列表中. slist_base_hook 持有维护列表所需的数据, 并为列表提供合适的 value_traits 类.

该钩子接受以下选项: tag<>、void_pointer<> 和 link_mode<>.

tag<> 定义用于标识节点的标签. 相同的标签值可用于不同的类; 但若一个类派生自多个 list_base_hook, 则每个 list_base_hook 都需要其唯一的标签.

link_mode<> 将指定钩子的链接模式 (normal_link、auto_unlink 或 safe_link).

void_pointer<> 是钩子内部及配置为使用此钩子的容器将要使用的指针类型.

slist_base_hook 公有成员函数

  1. slist_base_hook() noexcept;

    效果: 若 link_mode 为 auto_unlink 或 safe_link, 则把节点初始化为未链接状态.

    抛出: 无.

  2. slist_base_hook(const slist_base_hook &) noexcept;

    效果: 若 link_mode 为 auto_unlink 或 safe_link, 则把节点初始化为未链接状态. 实参被忽略.

    抛出: 无.

    设计理由: 提供复制构造函数使使用该钩子的类符合 STL 规范, 而无需用户做额外工作. swap 可用于模拟移动语义.

  3. slist_base_hook & operator=(const slist_base_hook &) noexcept;

    效果: 空函数. 实参被忽略.

    抛出: 无.

    设计理由: 提供赋值运算符使使用该钩子的类符合 STL 规范, 而无需用户做额外工作. swap 可用于模拟移动语义.

  4. ~slist_base_hook();

    效果: 若 link_mode 为 normal_link, 析构函数不做任何事 (即不生成代码). 若 link_mode 为 safe_link 且对象存储在 slist 中, 将触发断言. 若 link_mode 为 auto_unlink 且 is_linked() 为 true, 则节点被解除链接.

    抛出: 无.

  5. void swap_nodes(slist_base_hook & other) noexcept;

    效果: 交换两个节点会交换与这些节点相关的元素在一个或两个容器中的位置. 也就是说, 若节点 this 是元素 e1 的一部分, 节点 x 是元素 e2 的一部分, 且两个元素分别包含在容器 s1 和 s2 中, 则交换操作后 e1 位于 s2 中 e2 的位置, e2 位于 s1 中 e1 的位置. 若其中一个元素不在任何容器中, 则交换操作后另一个元素也不在容器中. 与这些节点相关的指向 e1 和 e2 的迭代器失效.

    复杂度: 常数

    抛出: 无.

  6. bool is_linked() const noexcept;

    前置条件: link_mode 必须为 safe_link 或 auto_unlink.

    返回: 若节点属于某个容器则为 true, 否则为 false. 此函数可用于测试 slist::iterator_to 是否会返回有效的迭代器.

    抛出: 无.

    复杂度: 常数

  7. void unlink() noexcept;

    效果: 若节点已插入容器, 则移除该节点. 仅当 link_mode 为 auto_unlink 时才允许此函数.

    抛出: 无.
