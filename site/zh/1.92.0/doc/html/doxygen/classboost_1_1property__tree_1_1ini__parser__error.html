类 ini_parser_error

boost::property_tree::ini_parser_error

概要

// In header: <boost/property_tree/ini_parser.hpp>


class ini_parser_error : public file_parser_error {
public:

  // public member functions
  ini_parser_error(const std::string &, const std::string &, unsigned long);
};

说明

表示解析 INI 格式数据时发生错误.

ini_parser_error 公有成员函数

  1. ini_parser_error(const std::string & message, const std::string & filename, 
                 unsigned long line);

    构造一个 ini_parser_error

    参数:

    message

    描述解析器错误的消息.

    filename

    被解析且含有错误的文件的名称.

    line

    给定文件中遇到错误的行.
