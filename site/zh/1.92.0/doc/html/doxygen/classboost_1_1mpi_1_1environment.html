类 environment

boost::mpi::environment — 初始化, 终结和查询 MPI 环境.

概要

// In header: <boost/mpi/environment.hpp>


class environment : private noncopyable {
public:

  // public member functions
  explicit environment(bool = true);
  explicit environment(threading::level, bool = true);
  environment(int &, char **&, bool = true);
  environment(int &, char **&, threading::level, bool = true);
  ~environment();

  // public static functions
  static void abort(int);
  static bool initialized();
  static bool finalized();
  static int max_tag();
  static int collectives_tag();
  static optional< int > host_rank();
  static optional< int > io_rank();
  static std::string processor_name();
  static threading::level thread_level();
  static bool is_main_thread();
  static std::pair< int, int > version();
  static std::string library_version();
};

说明

类 environment 用于初始化, 终结和查询 MPI 环境. 它通常用在程序的 main() 函数中, 该函数会创建一个 environment 实例, 并以传递给程序的实参进行初始化:

int main(int argc, char* argv[])
{
  mpi::environment env(argc, argv);
}

environment 的实例在其构造函数中初始化 MPI (通过调用 MPI_Init), 并在其析构函数中终结 MPI (正常终止时调用 MPI_Finalize, 未捕获异常时调用 MPI_Abort).

不强制使用 environment. 用户可以选择手动调用 MPI_Init 和 MPI_Finalize. 在这种情况下, 不需要 environment 对象. 不过, 如果创建了这样的对象, 它在构造或析构时都不会做任何事.

environment 公有成员函数

  1. explicit environment(bool abort_on_exception = true);

    初始化 MPI 环境.

    如果 MPI 环境尚未初始化, 则通过调用 MPI_Init 初始化 MPI. 由于此构造函数不接受命令行实参 (argc 和 argv), 因此仅当底层 MPI 实现支持调用 MPI_Init 并传入 NULL 实参时才可用, 这由宏 BOOST_MPI_HAS_NOARG_INITIALIZATION 指示.

    参数:

    abort_on_exception

    若为 true, 当此对象因未捕获异常而被析构时, 将中止程序.

    		 
  2. explicit environment(threading::level mt_level, 
                     bool abort_on_exception = true);

    初始化 MPI 环境.

    如果 MPI 环境尚未初始化, 则通过调用 MPI_Init_thread 初始化 MPI. 由于此构造函数不接受命令行实参 (argc 和 argv), 因此仅当底层 MPI 实现支持调用 MPI_Init 并传入 NULL 实参时才可用, 这由宏 BOOST_MPI_HAS_NOARG_INITIALIZATION 指示.

    参数:

    mt_level

    所需的线程支持级别.

    abort_on_exception

    若为 true, 当此对象因未捕获异常而被析构时, 将中止程序.

    		 
  3. environment(int & argc, char **& argv, bool abort_on_exception = true);

    初始化 MPI 环境.

    如果 MPI 环境尚未初始化, 则通过调用 MPI_Init 初始化 MPI.

    参数:

    argc

    argv 中提供的实参数量, 即传入程序 main 函数的数量.

    argv

    通过 main 传给程序的实参字符串数组.

    abort_on_exception

    若为 true, 当此对象因未捕获异常而被析构时, 将中止程序.

    		 
  4. environment(int & argc, char **& argv, threading::level mt_level, 
            bool abort_on_exception = true);

    初始化 MPI 环境.

    如果 MPI 环境尚未初始化, 则通过调用 MPI_Init_thread 初始化 MPI.

    参数:

    argc

    argv 中提供的实参数量, 即传入程序 main 函数的数量.

    argv

    通过 main 传给程序的实参字符串数组.

    mt_level

    所需的线程支持级别

    abort_on_exception

    若为 true, 当此对象因未捕获异常而被析构时, 将中止程序.

    		 
  5. ~environment();

    关闭 MPI 环境.

    如果此 environment 对象曾用于初始化 MPI 环境, 且 MPI 环境尚未关闭 (终结), 则此析构函数将关闭 MPI 环境. 在正常情况下, 这只涉及调用 MPI_Finalize. 然而, 如果析构是未捕获异常的结果, 且构造函数的 abort_on_exception 参数值为 true, 则此析构函数将调用 MPI_Abort 并传入 MPI_COMM_WORLD, 以结果码 -1 中止整个 MPI 程序.

environment 公有静态函数

  1. static void abort(int errcode);

    中止所有 MPI 进程.

    中止所有 MPI 进程并返回到环境. 具体行为由底层 MPI 实现定义. 这等价于调用 MPI_Abort 并传入 MPI_COMM_WORLD.

    参数:

    errcode

    返回给环境的错误码.

    返回:

    不会返回.

    		 
  2. static bool initialized();

    确定 MPI 环境是否已初始化.

    此例程等价于调用 MPI_Initialized.

    返回:

    true, 若 MPI 环境已初始化.

    		 
  3. static bool finalized();

    确定 MPI 环境是否已终结.

    此例程等价于调用 MPI_Finalized.

    返回:

    true, 若 MPI 环境已终结.

    		 
  4. static int max_tag();

    获取最大标签值.

    返回 send/receive 操作的 tag 参数可使用的最大值. 此值会比 MPI_TAG_UB 的值略小, 因为 Boost.MPI 实现为集合操作保留了一些标签.

    返回:

    最大标签值.

    		 
  5. static int collectives_tag();

    用于集合操作的标签值.

    返回 Boost.MPI 实现为集合操作保留的标签值. 虽然不允许用户使用此标签发送或接收消息, 但在监视通信模式时它可能有用.

    返回:

    用于集合操作的标签值.

    		 
  6. static optional< int > host_rank();

    获取主机进程的秩 (如果存在).

    如果存在主机进程, 此例程返回该进程的秩. 否则返回空的 optional<int>. MPI 未定义主机进程的含义: 请查阅 MPI 实现的文档. 此例程检查 MPI_HOST 在 MPI_COMM_WORLD 上的属性值.

    返回:

    主机进程的秩 (如果存在).

    		 
  7. static optional< int > io_rank();

    获取可执行输入/输出的进程的秩.

    此例程返回可通过标准 C 和 C++ I/O 设施执行输入/输出的进程的秩. 如果每个进程都能使用标准设施执行 I/O, 此例程将返回 any_source; 如果没有进程能执行 I/O, 此例程将不返回值 (空的 optional). 此例程检查 MPI_IO 在 MPI_COMM_WORLD 上的属性值.

    返回:

    可执行 I/O 的进程的秩; 如果每个进程都能执行 I/O 则为 any_source; 如果没有进程能执行 I/O 则无值.

    		 
  8. static std::string processor_name();

    获取此处理器的名称.

    此例程返回此处理器的名称. 名称的实际形式未指定, 但可能由底层 MPI 实现提供文档. 此例程实现为对 MPI_Get_processor_name 的调用.

    返回:

    此处理器的名称.

    		 
  9. static threading::level thread_level();

    查询当前的线程支持级别.

  10. static bool is_main_thread();

    我们是否在主线程中?

  11. static std::pair< int, int > version();
    MPI 版本.

    返回包含版本号和子版本号的 pair.

  12. static std::string library_version();
    MPI 库实现版本字符串.

    此例程返回一个包含附加库版本信息的字符串. 该版本字符串的实际形式未指定, 但可能由底层 MPI 实现提供文档. 此例程实现为对 MPI_Get_library_version 的调用, 该调用自 MPI-3 起可用. 在较旧的实现上将返回空字符串.
