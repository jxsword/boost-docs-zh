函数 all_reduce

boost::mpi::all_reduce — 将每个进程存储的值合并为对所有进程可用的单一值.

概要

// In header: <boost/mpi/collectives.hpp>


template<typename T, typename Op> 
  void all_reduce(const communicator & comm, const T * value, int n, 
                  T * out_value, Op op);
template<typename T, typename Op> 
  void all_reduce(const communicator & comm, const T & value, T & out_value, 
                  Op op);
template<typename T, typename Op> 
  T all_reduce(const communicator & comm, const T & value, Op op);
template<typename T, typename Op> 
  void all_reduce(const communicator & comm, inplace_t< T * > value, int n, 
                  Op op);
template<typename T, typename Op> 
  void all_reduce(const communicator & comm, inplace_t< T > value, Op op);

说明

all_reduce 是一种集合算法, 它将每个进程存储的值合并为对所有进程可用的单一值. 值以用户定义的方式合并, 通过函数对象指定. 值的类型 T 可以是可序列化的类型或具有关联 MPI 数据类型的类型. 可以把此操作看作 all_gather, 随后对收集到的值执行 std::accumulate(), 并使用运算 op.

当类型 T 具有关联的 MPI 数据类型时, 此例程调用 MPI_Allreduce 执行归约. 如果可能, 将使用内建 MPI 操作; 否则, all_reduce() 将为 MPI_Allreduce 调用创建自定义 MPI_Op.

如果包装在 inplace_t 对象中, 则同时使用输入和 $c out_value, 本地值将被覆盖 (为包装提供了便捷函数 inplace).

参数:

comm

发生归约的通信器.

value

要与每个其他进程的本地值合并的本地值. 对于归约数组, in_values 是指向要归约的本地值的指针, n 是要归约的值数量. 更多信息见 reduce.

n

指示数组类型缓冲区的大小.

out_value

将接收归约运算的结果. 如果省略此参数, 则改为返回外发值.

op

将类型 T 的两个值合并并返回第三个类型 T 值的二元运算. 对于具有关联 MPI 数据类型的类型 T, op 要么被转换为 MPI_Op (通过 MPI_Op_create), 要么 (如果可能) 直接映射到内建 MPI 操作. 更多细节见 is_mpi_op, 位于 operations.hpp 头文件中. 对于任何非内建操作, 交换性将由 is_commmutative 特征决定 (也在 operations.hpp 中): 鼓励用户将可交换操作标记为可交换, 因为这给实现提供了更大的余地来优化归约操作.

返回:

如果未提供 out_value 参数, 则返回归约运算的结果.
