类模板 any

boost::type_erasure::any

概要

// In header: <boost/type_erasure/any.hpp>

template<typename Concept, typename T = _self> 
class any {
public:

  // public member functions
  any();
  template<typename U> any(U &&);
  template<typename U, typename Map> any(U &&, const static_binding< Map > &);
  any(const any &);
  template<typename Concept2, typename Tag2> 
    any(const any< Concept2, Tag2 > &);
  template<typename Concept2, typename Tag2, typename Map> 
    any(const any< Concept2, Tag2 > &, const static_binding< Map > &);
  template<typename Concept2, typename Tag2> 
    any(const any< Concept2, Tag2 > &, const binding< Concept > &);
  template<class... U> explicit any(U &&...);
  template<class... U> explicit any(const binding< Concept > &, U &&...);
  template<typename U> any & operator=(U &&);
  ~any();
};

说明

类模板 any 可以存储任何建模特定 Concept 的对象. 它在运行期把 Concept 定义的所有函数分派到所含类型.

参见: concept_of, placeholder_of, any_cast, is_empty, binding_of, typeid_of

模板参数

  1. typename Concept

    存储的类型应建模的 Concept.

  2. typename T = _self

    指定此类型是什么的 placeholder.

any 公有成员函数

  1. any();

    构造一个空的 any.

    除非另有说明, 对空 any 的所有操作都会导致 bad_function_call 异常. 空 any 的复制构造函数会创建另一个空 any. 空 any 的析构函数是无操作. 比较运算符将所有空 any 视为相等. typeid_of 应用于空 any 会返回 typeid(void).

    Concept 中不包含 relaxed 的 any 永远不会为空.

    参见: is_empty

    要求:

    relaxed 必须在 Concept 中.

    抛出:

    		 无. 
  2. template<typename U> any(U && data);

    构造一个 any 来持有 data 的副本. Concept 将以占位符 T 绑定到 U 进行实例化.

    注释

    如果实参是 any, binding 或 static_binding, 此构造函数绝不会匹配.

    参数:

    data

    要存储在 any 中的对象.

    要求:

    U 是 Concept 的模型.

    要求:

    U 必须是 CopyConstructible 的.

    要求:

    Concept 除 T 外不得引用任何非推导占位符.

    抛出:

    		 std::bad_alloc, 或 U 的复制构造函数抛出的任何异常. 
  3. template<typename U, typename Map> 
  any(U && data, const static_binding< Map > & binding);

    构造一个 any 来持有 data 的副本, 并显式指定占位符绑定.

    注释

    如果实参是 any, 此构造函数绝不会匹配.

    参数:

    data

    要存储在 any 中的对象.

    binding

    指定所有占位符应绑定到的类型.

    要求:

    U 是 Concept 的模型.

    要求:

    U 必须是 CopyConstructible 的.

    要求:

    Map 是一个 MPL 映射, 对 Concept 引用的每个非推导占位符都有相应条目.

    要求:

    T 必须 映射到 U (在 Map 中).

    抛出:

    		 std::bad_alloc, 或 U 的复制构造函数抛出的任何异常. 
  4. any(const any & other);

    复制一个 any.

    参数:

    other

    要复制的对象.

    要求:

    Concept 必须包含 constructible<T(const T&)>. (copy_constructible<T> 已包含它)

    抛出:

    		 std::bad_alloc, 或所含类型的复制构造函数抛出的任何异常. 
  5. template<typename Concept2, typename Tag2> 
  any(const any< Concept2, Tag2 > & other);

    从要求更严格的 any 向上转换为要求更弱的 any.

    参数:

    other

    要复制的对象.

    要求:

    Concept 必须包含 constructible<T(const T&)>.

    要求:

    Concept 除 T 外不得引用任何非推导占位符.

    要求:

    用 T 替换 Tag2 后, Concept2 的要求必须是 Concept 要求的超集.

    抛出:

    		 std::bad_alloc, 或所含类型的复制构造函数抛出的任何异常. 
  6. template<typename Concept2, typename Tag2, typename Map> 
  any(const any< Concept2, Tag2 > & other, 
      const static_binding< Map > & binding);

    从另一个 any 构造 any.

    参数:

    other

    要复制的对象.

    binding

    指定两个概念所使用的占位符之间的映射.

    要求:

    Concept 必须包含 constructible<T(const T&)>.

    要求:

    Map 必须是一个 MPL 映射, 其键为 Concept 使用的所有非推导占位符, 值为 Concept2 中对应的占位符.

    要求:

    按 Map 替换占位符后, Concept2 的要求必须是 Concept 要求的超集.

    抛出:

    		 std::bad_alloc, 或所含类型的复制构造函数抛出的任何异常. 
  7. template<typename Concept2, typename Tag2> 
  any(const any< Concept2, Tag2 > & other, const binding< Concept > & binding);

    从另一个 any 构造 any.

    警告

    此构造函数有潜在危险, 因为它无法在编译期检查实参是否匹配.

    参数:

    other

    要复制的对象.

    binding

    指定占位符到实际类型的绑定.

    要求:

    Concept 必须包含 constructible<T(const T&)>.

    要求:

    other 中存储的类型必须与 binding 所期望的类型相匹配.

    后置条件:

    binding_of(*this) == binding

    抛出:

    		 std::bad_alloc, 或所含类型的复制构造函数抛出的任何异常. 
  8. template<class... U> explicit any(U &&... arg);

    调用所含类型的构造函数. 绑定将从实参推导.

    注释

    如果可以调用任何其他构造函数, 则绝不会选择此构造函数.

    参数:

    arg

    要传给底层构造函数的实参.

    要求:

    Concept 必须包含一个可以用这些实参调用的 constructible 实例.

    要求:

    至少有一个实参必须是 any, 且与 this 具有相同的 Concept.

    要求:

    所有作为 any 的实参的绑定必须相同.

    抛出:

    		 std::bad_alloc, 或所含类型的构造函数抛出的任何异常. 
  9. template<class... U> 
  explicit any(const binding< Concept > & binding, U &&... arg);

    调用所含类型的构造函数.

    参数:

    binding

    指定占位符到实际类型的绑定.

    arg

    要传给底层构造函数的实参.

    要求:

    Concept 必须包含匹配的 constructible 实例.

    要求:

    每个作为 any 的实参的所含类型, 必须与 binding 指定的类型相同.

    后置条件:

    binding_of(*this) == binding

    抛出:

    		 std::bad_alloc, 或所含类型的构造函数抛出的任何异常. 
  10. template<typename U> any & operator=(U && other);

    赋值给 any.

    如果没有合适的 assignable 重载可用, 且 relaxed 存在于 Concept 中, 则退回到从 other 构造.

    注释

    如果 U 是一个 any, 则可以根据 other 中存储的类型动态决定是否使用构造.

    抛出:

    		 所含类型的赋值运算符抛出的任何异常. 退回到构造时, 抛出 std::bad_alloc 或所含类型的移动 (或复制) 构造函数抛出的任何异常. 在这种情况下, 移动赋值提供强异常保证. 调用所含类型的 (移动) 赋值运算符时, 异常保证取决于所含类型提供的保证. 
  11. ~any();

    要求:

    Concept 包含 destructible<T>.
