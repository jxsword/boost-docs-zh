结构体模板 derived

boost::type_erasure::derived

概要

// In header: <boost/type_erasure/derived.hpp>

template<typename T> 
struct derived {
  // types
  typedef unspecified type;
};

说明

给定其任意基类时, 返回完整 any 类型的元函数. 它主要用于实现 concept_interface.

参见: rebind_any、as_param
