说明

类模板 unordered_multiset 是一种侵入式容器, 模仿 C++ TR1 中所述 std::tr1::unordered_multiset 接口的大部分内容.

unordered_multiset 是一种半侵入式容器: 要存储在容器中的每个对象都必须包含合适的钩子, 但容器还需要额外的辅助内存才能工作: unordered_multiset 需要在构造函数中传入一个指向 bucket_type 类型数组的指针. 该桶数组必须具有与容器至少相同的生存期. 这使得 unordered_multiset 的使用比纯侵入式容器更复杂. bucket_type 可默认构造、可复制且可赋值

模板参数 T 是容器要管理的类型. 用户可以指定附加选项; 若未提供选项, 则使用默认选项.

容器支持以下选项: base_hook<>/member_hook<>/value_traits<>、constant_time_size<>、size_type<>、hash<> 和 equal<> bucket_traits<>、power_2_buckets<> 和 cache_begin<>.

unordered_multiset 只提供前向迭代器, 但提供 4 种迭代器类型: 用于遍历整个容器的 iterator 和 const_iterator, 以及用于遍历存储在单个桶中的值的 local_iterator 和 const_local_iterator. 局部迭代器更快也更小.

不建议使用非常数时间大小的 unordered_multiset, 因为若干关键函数 (如 "empty()") 会变成非常数时间函数. 非常数时间大小的 unordered_multiset 主要用于支持 auto-unlink 钩子.

unordered_multiset 与 std::unordered_set 不同, 不执行自动重哈希, 也不提供与负载因子相关的函数. 可以显式请求重哈希, 用户必须提供自那一刻起使用的新桶数组.

由于不执行自动重哈希, 插入或擦除元素时迭代器从不失效. 只有重哈希时迭代器才失效.

  17. template<typename Cloner, typename Disposer> 
  void clone_from(const unordered_multiset & src, Cloner cloner,

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点比较相等且哈希相同的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(const_reference ) 从 src 克隆所有元素并插入到 *this 中. 哈希函数与相等性谓词从源容器复制.

    若 store_hash 选项为 true, 此方法不使用哈希函数.

    若有任何操作抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 或 hasher 抛出异常, 或哈希或相等性谓词的复制抛出异常. 基本保证.

    注释: 已插入元素的键发生变化 (例如键为字符串时语言环境改变) 但唯一性与哈希特性保持不变时使用此函数, 这样快速的整体重哈希即可恢复 *this 的不变式, 无需再次提取并重新插入所有元素.

    抛出: 若 hasher 函子抛出异常. 基本保证.
