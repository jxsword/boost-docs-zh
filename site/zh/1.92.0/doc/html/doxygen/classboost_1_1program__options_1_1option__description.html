类 option_description

boost::program_options::option_description

概要

// In header: <boost/program_options/options_description.hpp>


class option_description {
public:

  enum match_result { no_match, full_match, approximate_match };

  // public member functions
  option_description();
  option_description(const char *, const value_semantic *);
  option_description(const char *, const value_semantic *, const char *);
  virtual ~option_description();
  match_result match(const std::string &, bool, bool, bool) const;
  const std::string & key(const std::string &) const;
  std::string canonical_display_name(int = 0) const;
  const std::string & long_name() const;
  const std::pair< const std::string *, std::size_t > long_names() const;
  const std::string & description() const;
  shared_ptr< const value_semantic > semantic() const;
  std::string format_name() const;
  std::string format_parameter() const;

  // private member functions
  option_description & set_names(const char *);
};

说明

描述一个可能的命令行/配置文件选项. 选项的属性有两类: 第一类以语法方式描述选项, 仅用于校验输入; 第二类影响选项的解释, 例如其默认值, 或最终确定值时应调用的函数. 执行解析的例程从不使用第二类属性 —— 它们没有副作用.

参见: options_description

option_description 公有成员函数

  1. option_description();
  2. option_description(const char * name, const value_semantic * s);

    用传入的数据初始化对象.

    注意: 若能把第二个参数改为 auto_ptr 以显式传递所有权会更好. 不幸的是, 经常需要创建派生自 'value_semantic' 的类型的对象: options_description d; d.add_options()("a", parameter<int>("n")->default_value(1)); 这里, 'parameter' 返回的静态类型应派生自 value_semantic.

    可惜, auto_ptr 的派生类到基类转换并不真正可行, 见 http://www.open-std.org/jtc1/sc22/wg21/docs/papers/2000/n1232.pdf http://www.open-std.org/jtc1/sc22/wg21/docs/cwg_defects.html#84

    因此, 我们只能使用普通的旧式指针. 此外, 也不期望用户直接使用该构造函数.

    'name' 参数按以下规则解释:

    • 如果 'name' 中没有 "," 字符, 则它指定长名

    • 否则, "," 之前的部分指定长名, 之后的部分指定短名.

  3. option_description(const char * name, const value_semantic * s, 
                   const char * description);

    用传入的数据初始化该类.

  4. virtual ~option_description();
  5. match_result 
match(const std::string & option, bool approx, bool long_ignore_case, 
      bool short_ignore_case) const;

    给定输入源中指定的 'option', 如果 'option' 指定 *this, 则返回 'true'.

  6. const std::string & key(const std::string & option) const;

    返回应标识该选项的键, 尤其在 variables_map 类中. 'option' 参数是来自输入源的选项拼写. 如果选项名包含 '*', 则返回 'option'. 如果指定了长名, 则为长名, 否则为带前缀 '-' 的短名.

  7. std::string canonical_display_name(int canonical_option_style = 0) const;

    返回选项描述的规范名, 以便用户识别匹配的选项. 1) 对于短选项 ('-', '/'), 返回带前缀的短名. 2) 对于长选项 ('–' / '-'), 返回带前缀的第一个长名. 3) 其余情况, 返回第一个长名 (如果存在) 或短名, 不带前缀.

  8. const std::string & long_name() const;
  9. const std::pair< const std::string *, std::size_t > long_names() const;
  10. const std::string & description() const;
    此选项的说明.
  11. shared_ptr< const value_semantic > semantic() const;
    选项值的语义.
  12. std::string format_name() const;
    返回适合用于用法消息的选项名.
  13. std::string format_parameter() const;

    返回适合用于用法消息的参数名及其属性.
