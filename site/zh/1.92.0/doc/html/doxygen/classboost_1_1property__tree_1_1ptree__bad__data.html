类 ptree_bad_data

boost::property_tree::ptree_bad_data — 表示从给定值到属性树 data_type 的转换 (或反向) 失败的错误. 派生自 ptree_error.

概要

// In header: <boost/property_tree/exceptions.hpp>


class ptree_bad_data : public boost::property_tree::ptree_error {
public:

  // public member functions
  template<typename T> ptree_bad_data(const std::string &, const T &);
  template<typename T> T data() const;
};

说明

ptree_bad_data 公有成员函数

  1. template<typename T> ptree_bad_data(const std::string & what, const T & data);
    以给定的消息和数据实例化 ptree_bad_data.

    参数:

    what

    与此错误关联的消息.

    data

    与此错误关联且为转换失败来源的值.

    		 
  2. template<typename T> T data() const;
    获取与此错误关联的数据. 它是转换失败的源值. 你需要显式指定其类型.
