函数模板 swap

boost::swap — 交换两个 circular_buffer 的内容.

概要

// In header: <boost/circular_buffer/base.hpp>


template<typename T, typename Alloc> 
  void swap(circular_buffer< T, Alloc > & lhs, 
            circular_buffer< T, Alloc > & rhs);

说明

复杂度. 常数 (相对于 circular_buffer 的大小).

迭代器失效. 使两个 circular_buffer 的所有迭代器失效. (但另一方面, 这些迭代器仍指向相同的元素, 只是位于另一个容器中. 若要依赖这一特性, 必须关闭 Debug Support, 否则一旦使用这种已失效的迭代器, 断言就会报错. )

参见: swap(circular_buffer<T, Alloc>&)

参数:

lhs

circular_buffer, 其内容将与 rhs 交换.

rhs

circular_buffer, 其内容将与 lhs 交换.

后置条件:

lhs 包含 rhs 的元素, 反之亦然.

抛出:

 无.
