函数模板 operator<=

boost::operator<= — 逐元素比较两个 circular_buffer, 判断左操作数是否小于等于右操作数.

概要

// In header: <boost/circular_buffer/base.hpp>


template<typename T, typename Alloc> 
  bool operator<=(const circular_buffer< T, Alloc > & lhs, 
                  const circular_buffer< T, Alloc > & rhs);

说明

复杂度. 线性 (相对于 circular_buffer 的大小).

迭代器失效. 不会使任何迭代器失效.

参见: operator<(const circular_buffer<T,Alloc>&, const circular_buffer<T,Alloc>&)

参数:

lhs

要比较的 circular_buffer.

rhs

要比较的 circular_buffer.

返回:

!(rhs < lhs)

抛出:

 无.
