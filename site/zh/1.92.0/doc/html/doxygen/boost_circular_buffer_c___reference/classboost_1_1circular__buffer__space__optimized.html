  1. typedef cb_details::capacity_control< size_type > capacity_type;

    空间优化的环形缓冲区的容量控制器.

    参见: details.hpp 中的 capacity_control.

    class capacity_control
    {
    size_type m_capacity; // Available capacity.
    size_type m_min_capacity; // Minimum capacity.
    public:
    capacity_control(size_type capacity, size_type min_capacity = 0)
    : m_capacity(capacity), m_min_capacity(min_capacity)
    {};
    size_type capacity() const { return m_capacity; }
    size_type min_capacity() const { return m_min_capacity; }
    operator size_type() const { return m_capacity; }
    };

    总是 capacity >= min_capacity.

    capacity() 表示 circular_buffer_space_optimized 的容量, 而 min_capacity() 决定其内部缓冲区的最小分配大小.

    capacity_control 的转换构造函数允许从类似 size_type 的类型隐式转换, 从而确保创建 circular_buffer_space_optimized 实例时与其他 STL 容器兼容.

    另一方面, 运算符 size_type() 提供到 size_type 的隐式转换, 使得对 circular_buffer_space_optimized 容量的处理方式与 circular_buffer 中相同.

    更改 circular_buffer_space_optimized 的容量 (以及最小保证分配内存量).

    异常安全性. 强保证.

    复杂度. 线性 (相对于 min[size(), capacity_ctrl.capacity()]).

    注释

    要显式清掉额外分配的内存, 可使用 shrink-to-fit 技术:

    boost::circular_buffer_space_optimized<int> cb(1000);
    ...
    boost::circular_buffer_space_optimized<int>(cb).swap(cb);

    有关 STL 中 shrink-to-fit 技术的更多信息, 参见 http://www.gotw.ca/gotw/054.htm.

    参见: rset_capacity(const capacity_type&), resize(size_type, const_reference)

    参数:

    capacity_ctrl

    新的容量控制器.

    后置条件:

    capacity() == capacity_ctrl && size() <= capacity_ctrl.capacity()

    若当前存储在 circular_buffer_space_optimized 中的元素数量大于期望的新容量, 则会移除 [size() - capacity_ctrl.capacity()] 的 末尾 若干元素, 且新大小将等于 capacity_ctrl.capacity().
