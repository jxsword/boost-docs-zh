结构体模板 is_mpi_datatype

boost::mpi::is_mpi_datatype — 判断 C++ 类型能否映射到 MPI 数据类型的类型特征.

概要

// In header: <boost/mpi/datatype.hpp>

template<typename T> 
struct is_mpi_datatype : public boost::mpi::is_mpi_builtin_datatype< T > {
};

说明

该类型特征判断是否有可能构建一个表示某个 C++ 数据类型的 MPI 数据类型. 当可行时, is_mpi_datatype 派生自 mpl::true_, 且该 MPI 数据类型可通过 get_mpi_datatype 访问.

对于任何映射到内建 MPI 数据类型的 C++ 类型 (参见 is_mpi_builtin_datatype) , is_mpi_datatype 平凡地为真. 此外, 任何 POD ("Plain Old Data") 类型, 若其包含的成员本身可用 MPI 数据类型表示, 则该类型自身也可表示为 MPI 数据类型. 例如, point3d 类 (包含三个 double 值) 可以表示为 MPI 数据类型. 为此, 首先使该数据类型可序列化 (使用 Boost.Serialization 库) ; 然后针对该点类型特化 is_mpi_datatype 特征, 使其派生 mpl::true_: 

namespace boost { namespace mpi {
  template<> struct is_mpi_datatype<point>
    : public mpl::true_ { };
} }
