类 graph_communicator

boost::mpi::graph_communicator — 具有图拓扑的 MPI 通信器.

概要

// In header: <boost/mpi/graph_communicator.hpp>


class graph_communicator : public boost::mpi::communicator {
public:

  // public member functions
  graph_communicator(const MPI_Comm &, comm_create_kind);
  template<typename Graph> 
    explicit graph_communicator(const communicator &, const Graph &, 
                                bool = false);
  template<typename Graph, typename RankMap> 
    explicit graph_communicator(const communicator &, const Graph &, RankMap, 
                                bool = false);
};

说明

graph_communicator 是一种拓扑以图形式表达的通信器. 图通信器具有与 (内) 通信器相同的功能, 但还允许查询进程之间的关系. 这些关系通过图表达, 使用 Boost Graph Library 定义的接口. graph_communicator 类满足 BGL 的 Graph, Incidence Graph, Adjacency Graph, Vertex List Graph 和 Edge List Graph 概念的要求.

graph_communicator 公有成员函数

  1. graph_communicator(const MPI_Comm & comm, comm_create_kind kind);

    基于具有图拓扑的 MPI 通信器 comm 构建新的 Boost.MPI 图通信器.

    comm 可以是任何有效的 MPI 通信器. 如果 comm 是 MPI_COMM_NULL, 则会创建一个空通信器 (不能用于通信), 且 kind 参数被忽略. 否则, kind 参数决定 Boost.MPI 通信器与 comm: 的关联方式

    • 如果 kind 是 comm_duplicate, 则复制 (duplicate) comm 以创建新的通信器. 当 Boost.MPI 通信器 (及其所有副本) 被销毁时, 该新通信器将被释放. 仅当底层 MPI 实现支持 MPI 2.0 时才允许此选项; MPI 1.x 不提供互联通信器的复制.

    • 如果 kind 是 comm_take_ownership, 则取得 comm 的所有权. 当所有 Boost.MPI 通信器离开作用域时, 它将被自动释放.

    • 如果 kind 是 comm_attach, 则此 Boost.MPI 通信器将引用现有的 MPI 通信器 comm, 但当 Boost.MPI 通信器离开作用域时不会释放 comm. 仅当通信器由用户管理时才应使用此选项.

  2. template<typename Graph> 
  explicit graph_communicator(const communicator & comm, const Graph & graph, 
                              bool reorder = false);

    创建一个新的通信器, 其拓扑由给定的图描述. 图中顶点的索引将被假定为通信器内进程的秩. 图中的顶点数可以少于通信器中的进程数; 在这种情况下, 得到的通信器将是一个 NULL 通信器.

    参数:

    comm

    新的图通信器将基于的通信器.

    graph

    任何满足 Boost Graph Library 中 Incidence Graph 和 Vertex List Graph 概念要求的类型. 该图的结构将成为返回的通信器的拓扑.

    reorder

    是否允许 MPI 重新排列返回的通信器中的进程秩, 以更好地优化通信. 如果为 false, 则返回的通信器中每个进程的秩将精确匹配该进程在原通信器中的秩.

    		 
  3. template<typename Graph, typename RankMap> 
  explicit graph_communicator(const communicator & comm, const Graph & graph, 
                              RankMap rank, bool reorder = false);

    创建一个新的通信器, 其拓扑由给定的图描述. 秩映射 (rank) 给出从图中的顶点到通信器内秩的映射. 图中的顶点数可以少于通信器中的进程数; 在这种情况下, 得到的通信器将是一个 NULL 通信器.

    参数:

    comm

    新的图通信器将基于的通信器. rank 中的秩指此通信器中的进程.

    graph

    任何满足 Boost Graph Library 中 Incidence Graph 和 Vertex List Graph 概念要求的类型. 该图的结构将成为返回的通信器的拓扑.

    rank

    此映射将 graph 中的顶点转换为当前通信器内的秩. 它必须是可读属性映射 (Readable Property Map, 参见 Boost Property Map 库), 其键类型为 graph 的顶点类型, 值类型为 int.

    reorder

    是否允许 MPI 重新排列返回的通信器中的进程秩, 以更好地优化通信. 如果为 false, 则返回的通信器中每个进程的秩将精确匹配该进程在原通信器中的秩.
