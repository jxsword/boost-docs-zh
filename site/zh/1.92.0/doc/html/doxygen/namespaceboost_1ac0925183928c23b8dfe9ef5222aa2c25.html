boost::move_if_not_lvalue_reference

概要

// In header: <boost/move/utility_core.hpp>


template<typename T> 
  output_reference move_if_not_lvalue_reference(input_reference);

说明

效果: 调用 boost::move, 若 input_reference 不是左值引用. 否则返回该引用
