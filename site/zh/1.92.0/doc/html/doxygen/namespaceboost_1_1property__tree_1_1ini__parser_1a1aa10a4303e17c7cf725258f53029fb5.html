函数 validate_flags

boost::property_tree::ini_parser::validate_flags

概要

// In header: <boost/property_tree/ini_parser.hpp>


bool validate_flags(int flags);

说明

判断 flags 是否可用于 ini_parser.

参数:

flags

要检查其作为 ini_parser 标志有效性的值.

返回:

若标志有效则为 true, 否则为 false.
