结构体模板 placeholder

boost::xpressive::placeholder — 用于定义在语义动作中代表变量的占位符.

概要

// In header: <boost/xpressive/regex_actions.hpp>

template<typename T, int I = 0> 
struct placeholder {

  // public member functions
  unspecified operator=(T &) const;
  unspecified operator=(T const &) const;
};

说明

使用 placeholder<> 定义一个占位符, 以便在语义动作中代表真实对象. 占位符的使用使带动作的正则表达式只需定义一次, 就能在多种语境中重用, 从正则表达式定义时尚不存在的对象读取和写入.

使用 placeholder<> 的方式是: 创建一个 placeholder<T> 类型的对象, 并在语义动作中使用该对象, 其用法与你打算使用 T 类型对象的方式完全一致.

placeholder<int> _i;
placeholder<double> _d;

sregex rex = ( some >> regex >> here )
    [ ++_i, _d *= _d ];

然后, 在使用 regex_search()、regex_match() 或 regex_replace() 进行模式匹配时, 传入一个 match_results<> 对象, 其中包含正则表达式对象语义动作中各占位符的绑定. 可以像下面这样调用 match_results::let 来创建这些绑定:

int i = 0;
double d = 3.14;

smatch what;
what.let(_i = i)
    .let(_d = d);

if(regex_match("some string", rex, what))
   // i and d mutated here

若执行的语义动作含有未绑定的占位符, 将抛出 regex_error 类型的异常.

更多信息参见 xpressive::let() 的讨论以及用户指南中的 "引用非局部变量" 一节.

示例: 

// Define a placeholder for a map object:
placeholder<std::map<std::string, int> > _map;

// Match a word and an integer, separated by =>,
// and then stuff the result into a std::map<>
sregex pair = ( (s1= +_w) >> "=>" >> (s2= +_d) )
    [ _map[s1] = as<int>(s2) ];

// Match one or more word/integer pairs, separated
// by whitespace.
sregex rx = pair >> *(+_s >> pair);

// The string to parse
std::string str("aaa=>1 bbb=>23 ccc=>456");

// Here is the actual map to fill in:
std::map<std::string, int> result;

// Bind the _map placeholder to the actual map
smatch what;
what.let( _map = result );

// Execute the match and fill in result map
if(regex_match(str, what, rx))
{
    std::cout << result["aaa"] << '\n';
    std::cout << result["bbb"] << '\n';
    std::cout << result["ccc"] << '\n';
}

模板参数

  1. typename T

    此占位符所代表对象的类型.

  2. int I = 0

    一个可选的标识符, 可用于把此占位符与同一语义动作中恰好具有相同类型的其他占位符区分开.

placeholder 公有成员函数

  1. unspecified operator=(T & t) const;

    参数:

    t

    要与此占位符关联的对象

    返回:

    一个未指明类型的对象, 记录 t 与 *this 的关联.

    		 
  2. unspecified operator=(T const & t) const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
