类 tribool

boost::logic::tribool — 三态布尔类型.

概要

// In header: <boost/logic/tribool.hpp>


class tribool {
public:
  enum value_t;

  // public member functions
  tribool() noexcept;
  tribool(bool) noexcept;
  tribool(indeterminate_keyword_t) noexcept;
  explicit BOOST_CONSTEXPR operator bool() const noexcept;

  // public data members
  enum boost::logic::tribool::value_t value;
};

说明

三态布尔值可以是 true, false 或 indeterminate.

tribool 公有成员函数

  1. tribool() noexcept;

    以值 'false' 构造一个新的三态布尔值.

    抛出:

    		 不会抛出异常. 
  2. tribool(bool initial_value) noexcept;

    以给定的布尔值构造一个新的三态布尔值, 该值可以是 true 或 false.

    抛出:

    		 不会抛出异常. 
  3. tribool(indeterminate_keyword_t) noexcept;

    以 indeterminate 值构造一个新的三态布尔值.

    抛出:

    		 不会抛出异常. 
  4. explicit BOOST_CONSTEXPR operator bool() const noexcept;

    在布尔上下文中使用三态布尔值. 仅当该三态布尔值确定为 true 时, 才会在布尔上下文中求值为 true.

    返回:

    若三态布尔值为 true 则为 true, 否则为 false

    抛出:

    		 不会抛出异常.
