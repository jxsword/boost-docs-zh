结构体模板 throw_

boost::xpressive::op::throw_ — throw_<> 是一个用于抛出异常的 PolymorphicFunctionObject.

概要

// In header: <boost/xpressive/regex_actions.hpp>

template<typename Except> 
struct throw_ {
  // types
  typedef void result_type;

  // public member functions
  void operator()() const;
  template<typename A0> void operator()(A0 const &) const;
  template<typename A0, typename A1> 
    void operator()(A0 const &, A1 const &) const;
  template<typename A0, typename A1, typename A2> 
    void operator()(A0 const &, A1 const &, A2 const &) const;
};

说明

模板参数

  1. typename Except

    要抛出对象的类型.

throw_ 公有成员函数

  1. void operator()() const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
  2. template<typename A0> void operator()(A0 const & a0) const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
  3. template<typename A0, typename A1> 
  void operator()(A0 const & a0, A1 const & a1) const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
  4. template<typename A0, typename A1, typename A2> 
  void operator()(A0 const & a0, A1 const & a1, A2 const & a2) const;

    注释

    此函数使用 BOOST_THROW_EXCEPTION 宏来实际抛出异常. 参见 Boost.Exception 库的文档.

    参数:

    a0

    构造函数的第一个实参

    a1

    构造函数的第二个实参

    a2

    构造函数的第三个实参
