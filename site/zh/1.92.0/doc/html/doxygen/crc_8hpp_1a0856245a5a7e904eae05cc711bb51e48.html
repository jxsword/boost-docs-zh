函数模板 crc

boost::crc — 计算内存块的 (未增广) CRC.

概要

// In header: <boost/crc.hpp>


template<std::size_t Bits, unspecified TruncPoly, unspecified InitRem, 
         unspecified FinalXor, bool ReflectIn, bool ReflectRem> 
  unspecified crc(void const * buffer, std::size_t byte_count);

说明

计算一次 CRC 运行的多项式余数, 假定 buffer 和 byte_count 描述的内存块表示多项式被除数. 除法步骤经过调整, 使结果直接给出校验和, 无须用占位字节增广内存块. 首个字节被视为最高位, 后续字节依次降低.

注释

未增广风格的 CRC 运行以调整过的顺序执行模 2 多项式除法. 提取 (未处理) 校验和所需的末尾 Bits 个零值位被虚拟地移到消息开头附近. 这是可行的, 因为 XOR 运算满足交换律和结合律. 这也意味着你可以在任何时候获得校验和. 由于数据按字节读取, 可以使用预计算的余数变化表 (作为 XOR 掩码) 来加速计算.

参数:

buffer

内存块的起始地址.

byte_count

内存块中的字节数.

模板参数:

Bits

模 2 多项式除数的阶数. (RMCA 中的 Width)

TruncPoly

除数多项式的低阶系数. 最高阶系数被省略且总被假定为 1. (RMCA 中的 Poly)

InitRem

多项式余数的 (未增广) 初始状态. (RMCA 中的 Init)

FinalXor

在可能的反射之后, 返回之前应用于输出余数的 (XOR) 位掩码. (RMCA 中的 XorOut)

ReflectIn

如果为 True, 则输入字节按最低位优先读取, 否则按最高位优先读取. (RMCA 中的 RefIn)

ReflectRem

如果为 True, 则输出余数在应用 XOR 掩码之前先进行反射. (RMCA 中的 RefOut)

要求:

0 < Bits <= std::numeric_limits<uintmax_t>::digits

返回:

校验和, 即最后一次 (中间) 余数加上任何输出处理.
