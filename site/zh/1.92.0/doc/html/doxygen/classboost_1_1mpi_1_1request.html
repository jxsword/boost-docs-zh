说明

此结构包含关于非阻塞发送或接收的信息, 将分别由 isend 或 irecv 返回.

request 公有成员函数

  1. request();

    构造一个 NULL 请求.

  2. status wait();

    等待与此请求关联的通信完成, 然后返回描述该通信的 status 对象.

  3. optional< status > test();

    确定与此请求关联的通信是否已成功完成. 如果是, 则返回描述该通信的 status 对象. 否则, 返回空的 optional<>, 表示通信尚未完成. 注意, 一旦 test() 返回了 status 对象, 请求即已完成, 不应再调用 wait().

  4. void cancel();

    取消未完成的通信, 假定它尚未完成.

  5. optional< MPI_Request & > trivial();

    实现此请求的简单 MPI 请求 (如果它是简单请求). 对大多数用户可能无关.

  6. bool active() const;

    此请求是否可能尚未完成?

  7. void preserve(boost::shared_ptr< void > d);
