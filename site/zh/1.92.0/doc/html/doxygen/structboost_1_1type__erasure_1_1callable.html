结构体模板 callable

boost::type_erasure::callable

概要

// In header: <boost/type_erasure/callable.hpp>

template<typename Sig, typename F = _self> 
struct callable {

  // public static functions
  static R apply(F &, T...);
};

说明

callable 概念允许 any 保存函数对象. Sig 的解释方式与 Boost.Function 相同, 只是实参和返回类型允许是占位符. F 必须是 placeholder.

可以同时使用多个 callable 实例. 重载决议正常工作. 注意, 与 Boost.Function 不同, callable 不提供 result_type. 不过, 它支持 boost::result_of.

callable 公有静态函数

  1. static R apply(F & f, T... arg);

    R 是 Sig 的结果类型, T 是 Sig 的实参类型.
