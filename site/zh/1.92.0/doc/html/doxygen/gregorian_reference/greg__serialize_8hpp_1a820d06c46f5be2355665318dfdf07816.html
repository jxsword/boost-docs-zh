函数 BOOST_DATE_TIME_SPLIT_FREE

boost::serialization::BOOST_DATE_TIME_SPLIT_FREE

概要

// In header: <boost/date_time/gregorian/greg_serialize.hpp>


 BOOST_DATE_TIME_SPLIT_FREE(::boost::gregorian::date);

说明

为 gregorian::date 执行序列化的方法 —— 拆分为 load/save

日期被序列化为字符串以便传输和存储. 虽然存储用于操作日期的内部整数会更高效, 但这是一种不稳定的方案.
