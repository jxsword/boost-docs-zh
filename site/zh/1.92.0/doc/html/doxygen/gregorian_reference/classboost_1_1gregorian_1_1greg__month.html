类 greg_month

boost::gregorian::greg_month — 表示格里高利日历中月份的包装类.

概要

// In header: <boost/date_time/gregorian/greg_month.hpp>


class greg_month : public greg_month_rep {
public:
  // types
  typedef date_time::months_of_year month_enum;

  // public member functions
  greg_month(month_enum);
  greg_month(value_type);
  BOOST_CXX14_CONSTEXPR operator value_type() const;
  BOOST_CXX14_CONSTEXPR value_type as_number() const;
  BOOST_CXX14_CONSTEXPR month_enum as_enum() const;
  const char * as_short_string() const;
  const char * as_long_string() const;
  const wchar_t * as_short_wstring() const;
  const wchar_t * as_long_wstring() const;
  const char * as_short_string(char) const;
  const char * as_long_string(char) const;
  const wchar_t * as_short_string(wchar_t) const;
  const wchar_t * as_long_string(wchar_t) const;
};

说明

greg_month 公有成员函数

  1. greg_month(month_enum theMonth);
    从 months_of_year 枚举构造月份.
  2. greg_month(value_type theMonth);
    从 short 值构造.
  3. BOOST_CXX14_CONSTEXPR operator value_type() const;
    把值转回 short.
  4. BOOST_CXX14_CONSTEXPR value_type as_number() const;
    以 1 到 12 的数字返回月份.
  5. BOOST_CXX14_CONSTEXPR month_enum as_enum() const;
  6. const char * as_short_string() const;
    返回月份的 3 字符英文字符串, 例如: Jan, Feb, Mar, Apr.
  7. const char * as_long_string() const;
    以英文返回月份全名字符串, 例如: January, February.
  8. const wchar_t * as_short_wstring() const;
    返回月份的 3 字符英文 wchar_t 字符串, 例如: Jan, Feb, Mar, Apr.
  9. const wchar_t * as_long_wstring() const;
    以英文 wchar_t 字符串返回月份全名, 例如: January, February.
  10. const char * as_short_string(char) const;
  11. const char * as_long_string(char) const;
  12. const wchar_t * as_short_string(wchar_t) const;
  13. const wchar_t * as_long_string(wchar_t) const;
