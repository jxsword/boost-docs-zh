类 greg_year

boost::gregorian::greg_year — 表示年份 (范围 1400 - 9999)

概要

// In header: <boost/date_time/gregorian/greg_year.hpp>


class greg_year : public greg_year_rep {
public:

  // public member functions
  greg_year(value_type);
  BOOST_CXX14_CONSTEXPR operator value_type() const;
};

说明

这个小类允许把整数值简单转换为格里高利日历的年份. 目前只允许 1400 到 9999 的范围. 该范围的两端目前有些随意, 但它们是当前库测试的界限. 因此未来可能会放宽.

greg_year 公有成员函数

  2. BOOST_CXX14_CONSTEXPR operator value_type() const;
