类 greg_day

boost::gregorian::greg_day — 表示月内的一天 (范围 1 - 31)

概要

// In header: <boost/date_time/gregorian/greg_day.hpp>


class greg_day : public greg_day_rep {
public:

  // public member functions
  greg_day(value_type);
  BOOST_CXX14_CONSTEXPR value_type as_number() const;
  BOOST_CXX14_CONSTEXPR operator value_type() const;
};

说明

这个小类允许把整数值简单转换为标准格里高利日历的月内日期. 该类型会自动进行范围检查, 因此超出 1-31 范围的值将引发 bad_day_of_month 异常

  3. BOOST_CXX14_CONSTEXPR operator value_type() const;
