函数模板 copy_or_move

boost::copy_or_move

概要

// In header: <boost/move/algorithm.hpp>


template<typename I, typename F> F copy_or_move(I f, I l, F r);

说明

效果:

for (; first != last; ++result, ++first)
   *result = *first;

返回: result

注: 提供该函数是因为某些 STL 实现中的 std::uninitialized_copy 与 move_iterator 不兼容
