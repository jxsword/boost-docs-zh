函数模板 read_xml

boost::property_tree::read_xml

概要

// In header: <boost/property_tree/xml_parser.hpp>


template<typename Ptree> 
  void read_xml(std::basic_istream< typename Ptree::key_type::value_type > & stream, 
                Ptree & pt, int flags = 0);

说明

从输入流读取 XML 并将其转换为属性树.

注释

清空属性树的现有内容. 出错时属性树不被修改.

注释

XML 属性被放在名为 <xmlattr> 的键下.

参数:

stream

从中读取属性树的流.

pt

要填充的属性树.

flags

控制解析器行为的标志. 支持以下标志:

  • no_concat_text – 阻止把文本节点拼接进属性树的 datastring. 而是把它们放入单独的 <xmltext> 字符串.

  • no_comments – 跳过 XML 注释.

  • trim_whitespace – 去除文本首尾空白, 并合并空白序列.

抛出:

 xml_parser_error 在反序列化属性树出错时.
