函数模板 get_default_indeterminate_name

boost::logic::get_default_indeterminate_name — 返回一个字符串, 其中含有具有给定字符类型 T 的 tribool 不确定值的默认名称.

概要

// In header: <boost/logic/tribool_io.hpp>


template<typename T> std::basic_string< T > get_default_indeterminate_name();

说明

当没有 locale 支持或流的 locale 不含 indeterminate_name 刻面时, tribool 的输入输出流运算符使用此例程.
