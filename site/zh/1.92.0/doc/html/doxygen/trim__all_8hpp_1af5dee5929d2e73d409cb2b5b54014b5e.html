函数模板 trim_fill_if

boost::trim_fill_if — 填充修剪.

概要

// In header: <boost/algorithm/string/trim_all.hpp>


template<typename SequenceT, typename RangeT, typename PredicateT> 
  void trim_fill_if(SequenceT & Input, const RangeT & Fill, 
                    PredicateT IsSpace);

说明

移除输入中的所有前导与尾随空格, 并把每一块连续空格替换为用户定义的填充字符串. 输入序列被原地修改.

参数:

Input

一个输入序列

Fill

用于填充内部空格的字符串

IsSpace

标识空格的一元谓词
