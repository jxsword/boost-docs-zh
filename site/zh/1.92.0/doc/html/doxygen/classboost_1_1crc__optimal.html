类模板 crc_optimal

boost::crc_optimal — 表驱动 CRC 计算器, 可用作函数对象.

概要

// In header: <boost/crc.hpp>

template<std::size_t Bits, unspecified TruncPoly, unspecified InitRem, 
         unspecified FinalXor, bool ReflectIn, bool ReflectRem> 
class crc_optimal {
public:
  // types
  typedef unspecified value_type;

  // public member functions
  explicit crc_optimal(value_type = initial_remainder);
  value_type get_truncated_polynominal() const;
  value_type get_initial_remainder() const;
  value_type get_final_xor_value() const;
  bool get_reflect_input() const;
  bool get_reflect_remainder() const;
  value_type get_interim_remainder() const;
  void reset(value_type = initial_remainder);
  void process_byte(unsigned char);
  void process_block(void const *, void const *);
  void process_bytes(void const *, std::size_t);
  value_type checksum() const;
  void operator()(unsigned char);
  value_type operator()() const;

  // public data members
  static const std::size_t bit_count;  // A copy of Bits provided for meta-programming purposes.    
  static const value_type truncated_polynominal;  // A copy of TruncPoly provided for meta-programming purposes. 
  static const value_type initial_remainder;  // A copy of InitRem provided for meta-programming purposes. 
  static const value_type final_xor_value;  // A copy of FinalXor provided for meta-programming purposes. 
  static const bool reflect_input;  // A copy of ReflectIn provided for meta-programming purposes. 
  static const bool reflect_remainder;  // A copy of ReflectRem provided for meta-programming purposes. 
};

说明

此类型的对象计算提交数据的 CRC 校验和, 数据可通过几种不同的分组方式分批输入. 模 2 多项式除法步骤按字节执行, 并借助预计算表辅助. 该除法使用改进算法, 因此任何数据都必须是未增广的.

<xrefsect><xreftitle>待办</xreftitle><xrefdescription>

去掉 TruncPoly 的默认值. 选择除数是一个有许多因素的重要决策, 默认值永远没有用, 尤其是糟糕的默认值.

</xrefdescription></xrefsect>

模板参数

  1. std::size_t Bits

    模 2 多项式除数的阶数. (RMCA 中的 Width)

  2. unspecified TruncPoly

    除数多项式的低阶系数. 最高阶系数被省略且总被假定为 1. 默认为 0, 即唯一的非零项是 xBits 的隐式项. (RMCA 中的 Poly)

  3. unspecified InitRem

    多项式余数的 (未增广) 初始状态. 若省略则默认为 0. (RMCA 中的 Init)

  4. unspecified FinalXor

    应用于输出余数的 (XOR) 位掩码, 在可能的反射之后、返回之前应用. 若省略则默认为 0 (即不改变任何位). (RMCA 中的 XorOut)

  5. bool ReflectIn

    若 true, 输入字节按最低位优先读取, 否则按最高位优先读取. 若省略则默认为 false. (RMCA 中的 RefIn)

  6. bool ReflectRem

    若 true, 输出余数在应用 XOR 掩码之前先做反射. 若省略则默认为 false. (RMCA 中的 RefOut)

crc_optimal 公有类型

  1. typedef unspecified value_type;

    此类型用于 CRC 计算, 也是返回的校验和、返回或提交的余数、(截断) 除数或 XOR 掩码的类型. 它是内建的无符号整数类型.

crc_optimal 公有成员函数

  1. explicit crc_optimal(value_type init_rem = initial_remainder);
    创建一个计算器, 需要时给出初始余数.

    构造 crc_optimal 对象, 带有在接收输入时处理的特定 CRC 公式. 初始余数可以被覆盖.

    参数:

    init_rem

    多项式余数的 (未增广) 初始状态. 若省略则默认为 initial_remainder.

    后置条件:

    truncated_polynominal == this->get_truncated_polynominal()

    后置条件:

    initial_remainder == this->get_initial_remainder()

    后置条件:

    final_xor_value == this->get_final_xor_value()

    后置条件:

    reflect_input == this->get_reflect_input()

    后置条件:

    reflect_remainder == this->get_reflect_remainder()

    后置条件:

    init_rem == this->get_interim_remainder()

    后置条件:

    (reflect_remainder ? REFLECT(init_rem) : init_rem) ^ final_xor_value == this->checksum() 

  2. value_type get_truncated_polynominal() const;
    返回 (截断的) 多项式除数.

    返回多项式除数的一种表示. 第 2i 位的值是多项式 xi 项系数的值. x(bit_count) 项被省略的位始终为 1.

    返回:

    按位打包的系数列表. 若 value_type 的位长超过 bit_count, 则较高位上的值应被忽略 (包括 x(bit_count) 的任何值), 因为它们不受约束.

    		 
  3. value_type get_initial_remainder() const;
    返回构造期间设置的多项式余数.

    返回在提交任何输入之前多项式余数的一种表示. 第 2i 位的值是多项式 xi 项系数的值.

    返回:

    按位打包的系数列表. 若 value_type 的位长超过 bit_count, 则较高位上的值应被忽略, 因为它们不受约束.

    		 
  4. value_type get_final_xor_value() const;
    返回输出处理期间使用的 XOR 掩码.

    返回创建校验和时要使用的掩码. 该掩码用于按位方式对中间余数表示执行的异或 (XOR) 运算 (在任何反射之后, 若 get_reflect_remainder() 返回 true).

    返回:

    位掩码. 若 value_type 的位长超过 bit_count, 则较高位上的值应被忽略, 因为它们不受约束.

    		 
  5. bool get_reflect_input() const;
    检查输入字节在处理前是否会被反射.

    返回提交的字节在用于更新中间余数之前是否会被 "反射". 只有按字节操作 process_byte、process_block 和 process_bytes 受影响.

  6. bool get_reflect_remainder() const;
    检查余数在输出处理期间是否会被反射.

    指示返回校验和时中间余数在传入 XOR 掩码阶段之前是否会被 "反射".

  7. value_type get_interim_remainder() const;
    返回基于已处理位的余数.

    返回自构造或上次 reset 调用以来所有输入提交之后多项式余数的一种表示. 第 2i 位的值是多项式 xi 项系数的值. 若 CRC 处理在此处中断, 请保留返回的值, 并用它从上次中断处启动下一个 CRC 计算器 (通过 reset(value_type) 或构造). 下一个计算器的其他参数必须与此计算器兼容.

    返回:

    按位打包的系数列表. 若 value_type 的位长超过 bit_count, 则较高位上的值应被忽略, 因为它们不受约束. 该值未应用任何输出处理 (反射或 XOR 掩码).

    		 
  8. void reset(value_type new_rem = initial_remainder);
    把中间余数改为给定值或初始值.

    把中间多项式余数改为 new_rem, 清除先前提交的输入的任何影响. 第 2i 位的值是多项式 xi 项系数的值.

    参数:

    new_rem

    从此点开始的多项式余数的 (未增广) 状态, 未应用任何输出处理. 若省略则默认为 this->get_initial_remainder().

    后置条件:

    new_rem == this->get_interim_remainder()

    后置条件:

    ((this->get_reflect_remainder() ? REFLECT(new_rem) : new_rem) ^ this->get_final_xor_value()) == this->checksum() 

  9. void process_byte(unsigned char byte);
    提交单个字节进行输入处理.

    用一个字节的改进 CRC 除法步骤更新中间余数. 若 this->get_reflect_input() 为 false, 字节内的位从最高位向下处理, 否则从最低位向上处理.

    注释

    任何模 2 多项式除法在按字节读取数据时, 都可以使用预计算余数变化表 (作为 XOR 掩码) 来加速计算.

    参数:

    byte

    新的输入字节.

    后置条件:

    中间余数通过 CHAR_BIT 次模 2 多项式除法更新, 其中除法步骤针对未增广 CRC 做了改进.

    		 
  10. void process_block(void const * bytes_begin, void const * bytes_end);
    以迭代器对方式提交内存块进行输入处理.

    用多个字节的改进 CRC 除法步骤更新中间余数. 若 this->get_reflect_input() 为 false, 每个字节内的位从最高位向下处理, 否则从最低位向上处理. 字节本身从 bytes_begin 指向的字节开始处理, 通过前向迭代直到到达 bytes_end, 把这两个指针当作指向 unsigned char 对象.

    注释

    任何模 2 多项式除法在按字节读取数据时, 都可以使用预计算余数变化表 (作为 XOR 掩码) 来加速计算.

    参数:

    bytes_begin

    内存块的起始地址.

    bytes_end

    指向内存块最后一个字节地址之后一字节处, 若不读取任何字节则为 bytes_begin.

    要求:

    bytes_end 必须等于 bytes_begin, 若后者为 NULL 或未指向有效缓冲区.

    要求:

    bytes_end 若不等于 bytes_begin, 则必须指向 bytes_begin 所指缓冲区内部或其后一字节处.

    要求:

    bytes_end 必须可以从 bytes_begin 通过有限次字节指针前向递增到达.

    后置条件:

    中间余数通过 CHAR_BIT * (((unsigned char const *) bytes_end) - ((unsigned char const *) bytes_begin)) 次模 2 多项式除法更新, 其中除法步骤针对未增广 CRC 做了改进.

    		 
  11. void process_bytes(void const * buffer, std::size_t byte_count);
    以指针和大小方式提交内存块进行输入处理.

    用多个字节的改进 CRC 除法步骤更新中间余数. 若 this->get_reflect_input() 为 false, 每个字节内的位从最高位向下处理, 否则从最低位向上处理. 字节本身从 buffer 指向的字节开始处理, 前向迭代 (如同被指向对象为 unsigned char), 直到读满 byte_count 个字节.

    注释

    任何模 2 多项式除法在按字节读取数据时, 都可以使用预计算余数变化表 (作为 XOR 掩码) 来加速计算.

    参数:

    buffer

    内存块的起始地址.

    byte_count

    内存块中的字节数.

    要求:

    byte_count 必须等于 0, 若 buffer 为 NULL 或未指向有效内存.

    要求:

    若 buffer 指向有效内存内部, 则该内存块从该点起必须至少还有 byte_count 个有效字节已分配.

    后置条件:

    中间余数通过 CHAR_BIT * byte_count 次模 2 多项式除法更新, 其中除法步骤针对未增广 CRC 做了改进.

    		 
  12. value_type checksum() const;
    返回已处理位的校验和.

    计算自构造或上次调用 reset 以来所有已提交位的校验和. 该校验和是原始校验和, 即所有模 2 多项式除法完成后的 (中间) 余数加上任何输出处理.

    注释

    由于校验和用于比较, 任何较高位 (当 value_type 的位长超过 bit_count 时) 都将被置为 0.

    返回:

    (this->get_reflect_remainder() ? REFLECT(this->get_interim_remainder()) : this->get_interim_remainder()) ^ this->get_final_xor_value()

    		 
  13. void operator()(unsigned char byte);
    提交单个字节进行输入处理, 适用于 STL.

    用一个字节的改进 CRC 除法步骤更新中间余数. 若 this->get_reflect_input() 为 false, 字节内的位从最高位向下处理, 否则从最低位向上处理. 此函数旨在为想用 std::for_each 或类似范围处理算法处理字节流的代码提供函数对象接口. 由于其中一些算法按值传递函数对象, 请务必把结果复制回此对象, 以便记住更新.

    注释

    任何模 2 多项式除法在按字节读取数据时, 都可以使用预计算余数变化表 (作为 XOR 掩码) 来加速计算.

    参数:

    byte

    新的输入字节.

    后置条件:

    中间余数通过 CHAR_BIT 次模 2 多项式除法更新, 其中除法步骤针对未增广 CRC 做了改进.

    		 
  14. value_type operator()() const;
    返回已处理位的校验和, 适用于 STL.

    计算自构造或上次调用 reset 以来所有已提交位的校验和. 该校验和是原始校验和, 即所有模 2 多项式除法完成后的 (中间) 余数加上任何输出处理. 此函数旨在为想接收数据的代码提供函数对象接口, 例如 std::generate_n 或类似的数据处理算法. 注意, 若此对象在两次修改操作之间多次作为生成器使用, 将始终返回相同的值.

    注释

    由于校验和用于比较, 任何较高位 (当 value_type 的位长超过 bit_count 时) 都将被置为 0.

    返回:

    (this->get_reflect_remainder() ? REFLECT(this->get_interim_remainder()) : this->get_interim_remainder()) ^ this->get_final_xor_value()
