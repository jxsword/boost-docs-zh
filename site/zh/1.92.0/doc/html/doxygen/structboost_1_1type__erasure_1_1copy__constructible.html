结构体模板 copy_constructible

boost::type_erasure::copy_constructible

概要

// In header: <boost/type_erasure/builtin.hpp>

template<typename T = _self> 
struct copy_constructible : public boost::mpl::vector< constructible< _self(const _self &)>, destructible< _self > >
{
};

说明

copy_constructible 概念允许对象被复制与销毁.

注释

此概念的定义与 C++ 2003 的 [lib.copyconstructible] 一致. 它与 C++11 中同名概念并不等价.
