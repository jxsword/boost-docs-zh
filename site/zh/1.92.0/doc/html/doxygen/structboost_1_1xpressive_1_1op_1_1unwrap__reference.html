结构体 unwrap_reference

boost::xpressive::op::unwrap_reference — unwrap_reference 是一个用于解开 boost::reference_wrapper<> 的 PolymorphicFunctionObject.

概要

// In header: <boost/xpressive/regex_actions.hpp>


struct unwrap_reference {
  // member classes/structs/unions
  template<typename Sig> 
  struct result {
  };
  template<typename This, typename Ref> 
  struct result<This(Ref &)> {
    // types
    typedef boost::unwrap_reference< Ref >::type & type;
  };
  template<typename This, typename Ref> 
  struct result<This(Ref)> {
    // types
    typedef boost::unwrap_reference< Ref >::type & type;
  };

  // public member functions
  template<typename T> T & operator()(boost::reference_wrapper< T >) const;
};

说明

unwrap_reference 公有成员函数

  1. template<typename T> T & operator()(boost::reference_wrapper< T > r) const;

    参数:

    r

    要解开的 boost::reference_wrapper<T>.

    返回:

    static_cast<T &>(r)
