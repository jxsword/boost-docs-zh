全局 set

boost::xpressive::set — 用于创建字符集.

概要

// In header: <boost/xpressive/regex_primitives.hpp>

unspecified set;

说明

使用 'set' 标识符创建字符集有两种方式. 最简单的是创建集合中字符的逗号分隔列表, 如 (set= 'a','b','c'). 此集合将匹配 'a'、'b' 或 'c'. 另一种方式是把集合定义为 set 下标运算符的实参. 例如, set[ 'a' | range('b','c') | digit ] 将匹配 'a'、'b'、'c' 或数字字符.

要对集合取补, 应用 '~' 运算符. 例如, ~(set= 'a','b','c') 将匹配任何不是 'a'、'b' 或 'c' 的字符.

集合可以由其他集合 (可能取补) 组合而成. 例如, set[ ~digit | ~(set= 'a','b','c') ].
