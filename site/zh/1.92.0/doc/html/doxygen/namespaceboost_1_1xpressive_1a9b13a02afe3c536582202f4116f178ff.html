函数模板 construct

boost::xpressive::construct — 一个惰性函数, 用于构造指定类型的对象.

概要

// In header: <boost/xpressive/regex_actions.hpp>


template<typename T, typename ... Args> 
  unspecified construct(Args const &... args);

说明

参数:

args

构造函数的实参.

模板参数:

T

要构造的对象类型.

返回:

一个惰性对象, 求值时返回 T(xs...), 其中 xs... 是对惰性实参 args... 求值的结果.
