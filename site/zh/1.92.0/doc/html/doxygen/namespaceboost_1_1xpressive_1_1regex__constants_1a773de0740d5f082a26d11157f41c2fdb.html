类型 syntax_option_type

boost::xpressive::regex_constants::syntax_option_type

概要

// In header: <boost/xpressive/regex_constants.hpp>


enum syntax_option_type { ECMAScript = 0, icase = 1 << 1, nosubs = 1 << 2, 
                          optimize = 1 << 3, collate = 1 << 4, 
                          single_line = 1 << 10, not_dot_null = 1 << 11, 
                          not_dot_newline = 1 << 12, 
                          ignore_white_space = 1 << 13 };

说明

用于自定义正则表达式语法的标志

ECMAScript

指定正则表达式引擎识别的文法使用其正常语义: 即与 ECMA-262 (ECMAScript 语言规范, 第 15 章第 10 部分, RegExp (正则表达式) 对象) 中给出的语义相同 (FWD.1).

icase

指定正则表达式与字符容器序列的匹配应不区分大小写.

nosubs

指定当正则表达式与字符容器序列匹配时, 不在所提供的 match_results 结构中存储子表达式匹配.

optimize

指定正则表达式引擎应更关注正则表达式匹配的速度, 而较少关注正则表达式对象构造的速度. 除此之外, 它对程序输出没有可检测的影响.

collate

指定 "[a-b]" 形式的字符范围应区分 locale.

single_line

指定 ^ 与 $ 元字符不匹配内部换行. 注意这与 perl 默认行为相反. 它是 perl /m (多行) 修饰符的逆.

not_dot_null

指定 . 元字符不匹配空字符 \0.

not_dot_newline

指定 . 元字符不匹配换行字符 \n.

ignore_white_space

指定未转义的空白不重要.
