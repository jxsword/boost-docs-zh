类模板 static_local_time_adjustor

boost::date_time::static_local_time_adjustor — 在编译期嵌入本地时间调整规则.

概要

// In header: <boost/date_time/local_time_adjustor.hpp>

template<typename time_type, typename dst_rules, typename utc_offset_rules> 
class static_local_time_adjustor : public dst_rules, public utc_offset_rules {
public:
  // types
  typedef time_type::time_duration_type time_duration_type;
  typedef time_type::date_type          date_type;         

  // public static functions
  static time_duration_type utc_to_local_offset(const time_type &);
  static time_duration_type 
  local_to_utc_offset(const time_type &, 
                      date_time::dst_flags = date_time::calculate);
};

说明

static_local_time_adjustor 公有静态函数

  1. static time_duration_type utc_to_local_offset(const time_type & t);
    基于 dst 和 UTC 偏移量计算从 UTC 时间到本地的偏移量.

    逻辑如下. 从 UTC 时间开始, 使用偏移量为未进行 dst 调整的本地时间创建标签. 然后以未调整的本地时间调用 dst_rules::local_is_dst. 该函数的结果要么明确判定初始本地时间处于 dst, 要么返回非法或歧义结果. 非法结果只出现在 dst 结束时 (标签被跳过), 表示 dst 已经结束. 歧义结果意味着需要通过进行 dst 调整再重新检查. 如果 dst 偏移量加到 UTC 时间上且重新检查证明无歧义, 则已越过边界. 如果仍有歧义, 则尚未越过边界, dst 仍然生效.

    TODO —— 检查是否所有 dst 偏移量都为正. 如果不是, 算法需要检查这一点并反转非法/歧义逻辑.

    参数:

    t

    用于计算到本地时间偏移量的 UTC 时间. 此调整依赖于以下关于 DST 边界偏移量工作方式的观察. 由于 UTC 时间标签单调递增, 我们可以判断给定的本地时间是否处于 DST, 从而适当调整偏移量.

    		 
  2. static time_duration_type 
local_to_utc_offset(const time_type & t, 
                    date_time::dst_flags dst = date_time::calculate);
    在给定本地时间的情况下获取到 UTC 的偏移量.
