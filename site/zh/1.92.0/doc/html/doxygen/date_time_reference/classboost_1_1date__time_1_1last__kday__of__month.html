类模板 last_kday_of_month

boost::date_time::last_kday_of_month — 计算诸如 1 月的最后一个星期日之类的内容.

概要

// In header: <boost/date_time/date_generators.hpp>

template<typename date_type> 
class last_kday_of_month :
  public boost::date_time::year_based_generator< date_type >
{
public:
  // types
  typedef date_type::calendar_type        calendar_type;   
  typedef calendar_type::day_of_week_type day_of_week_type;
  typedef calendar_type::month_type       month_type;      
  typedef calendar_type::year_type        year_type;       
  typedef date_type::duration_type        duration_type;   

  // public member functions
  last_kday_of_month(day_of_week_type, month_type);
  virtual date_type get_date(year_type) const;
  month_type month() const;
  day_of_week_type day_of_week() const;
  virtual std::string to_string() const;
};

说明

用于查找节日和夏令时的实用生成器函数对象. 获取月末的最后一天, 然后计算与前一个星期几的差值.

模板参数

  1. typename date_type

    导出 day_of_week, month_type 等的日期类.

last_kday_of_month 公有成员函数

  1. last_kday_of_month(day_of_week_type dow, month_type m);
    指定日期规格, 如 'April' 中最后一个 'Sunday'.

    参数:

    dow

    星期几, 例如: Sunday, Monday 等

    m

    年中的月份, 例如: Jan, Feb, Mar 等

    		 
  2. virtual date_type get_date(year_type year) const;
    在给定特定年份时返回具体日期.
  3. month_type month() const;
  4. day_of_week_type day_of_week() const;
  5. virtual std::string to_string() const;
    返回适合用于 POSIX 时区字符串的字符串.

    返回格式为 "M4.5.0" 的字符串 ==> 4 月的最后一个星期日.
