类模板 period

boost::date_time::period — 提供在日期时间系统中实用的通用时间段类型.

概要

// In header: <boost/date_time/period.hpp>

template<typename point_rep, typename duration_rep> 
class period : private boost::less_than_comparable< period< point_rep, duration_rep >, boost::equality_comparable< period< point_rep, duration_rep > > >
{
public:
  // types
  typedef point_rep    point_type;   
  typedef duration_rep duration_type;

  // public member functions
  period(point_rep, point_rep);
  period(point_rep, duration_rep);
  BOOST_CXX14_CONSTEXPR point_rep begin() const;
  BOOST_CXX14_CONSTEXPR point_rep end() const;
  BOOST_CXX14_CONSTEXPR point_rep last() const;
  BOOST_CXX14_CONSTEXPR duration_rep length() const;
  BOOST_CXX14_CONSTEXPR bool is_null() const;
  BOOST_CXX14_CONSTEXPR bool operator==(const period &) const;
  BOOST_CXX14_CONSTEXPR bool operator<(const period &) const;
  BOOST_CXX14_CONSTEXPR void shift(const duration_rep &);
  BOOST_CXX14_CONSTEXPR void expand(const duration_rep &);
  BOOST_CXX14_CONSTEXPR bool contains(const point_rep &) const;
  BOOST_CXX14_CONSTEXPR bool contains(const period &) const;
  BOOST_CXX14_CONSTEXPR bool intersects(const period &) const;
  BOOST_CXX14_CONSTEXPR bool is_adjacent(const period &) const;
  BOOST_CXX14_CONSTEXPR bool is_before(const point_rep &) const;
  BOOST_CXX14_CONSTEXPR bool is_after(const point_rep &) const;
  BOOST_CXX14_CONSTEXPR period intersection(const period &) const;
  BOOST_CXX14_CONSTEXPR period merge(const period &) const;
  BOOST_CXX14_CONSTEXPR period span(const period &) const;
};

说明

此模板使用一个类表示时间段内的时间点, 使用另一个类表示时长. 因此, 当数量与时长表示相同时 (例如在常规数字域中), 此类不适用.

可以通过提供起点和时长, 或起点和终点来指定时间段 (终点不属于时间段, 而是其后 1 个单位). 如果 end_point <= begin_point 或给定的时长 <= 0, 则时间段为无效. 任何有效时间段对 is_null() 都返回 false.

零长度时间段也被视为无效. 零长度时间段是起点和终点相同, 或给定时长的值为零的时间段. 对于零长度时间段, last 点将比起点小一个单位.

当 begin 与 last 相同时, 时间段的长度为一个单位.

处理时间段的最佳方式通常是提供起点和时长. 因此, day1 + 7 days 是一个周时间段, 它包含整个第一天和另外 6 天 (例如: Sun 到 Sat).

period 公有成员函数

  1. period(point_rep first_point, point_rep end_point);
    创建从 begin 到 last 的时间段, 例如: [begin,end)

    如果 end <= begin, 则时间段无效

  2. period(point_rep first_point, duration_rep len);
    创建 [begin, begin+len) 的时间段

    如果 len <= 0, 则时间段无效

  3. BOOST_CXX14_CONSTEXPR point_rep begin() const;
    返回时间段中的第一个元素.
  4. BOOST_CXX14_CONSTEXPR point_rep end() const;
    返回最后一个元素之后的一个.
  5. BOOST_CXX14_CONSTEXPR point_rep last() const;
    返回时间段中的最后一项.
  6. BOOST_CXX14_CONSTEXPR duration_rep length() const;
    返回时间段的长度.
  7. BOOST_CXX14_CONSTEXPR bool is_null() const;
    如果时间段格式不正确 (长度为零或更小) 则为 true
  8. BOOST_CXX14_CONSTEXPR bool operator==(const period & rhs) const;
    相等运算符.
  9. BOOST_CXX14_CONSTEXPR bool operator<(const period & rhs) const;
    严格关系, 定义为 rhs.last <= lhs.last.
  10. BOOST_CXX14_CONSTEXPR void shift(const duration_rep & d);
    把起点和终点平移指定的量.
  11. BOOST_CXX14_CONSTEXPR void expand(const duration_rep & d);

    在两端按时长扩大时间段的尺寸.

  12. BOOST_CXX14_CONSTEXPR bool contains(const point_rep & point) const;
    如果点位于时间段内则为 true, 零长度时间段不包含任何点.
  13. BOOST_CXX14_CONSTEXPR bool contains(const period & other) const;
    如果此时间段完全包含 (或等于) 另一个时间段则为 true.
  14. BOOST_CXX14_CONSTEXPR bool intersects(const period & other) const;
    如果时间段以任何方式重叠则为 true.
  15. BOOST_CXX14_CONSTEXPR bool is_adjacent(const period & other) const;
    如果时间段相邻且没有间隙则为 true.
  16. BOOST_CXX14_CONSTEXPR bool is_before(const point_rep & point) const;
    如果整个时间段都在传入点之前, 即 end <= t, 则为 true.
  17. BOOST_CXX14_CONSTEXPR bool is_after(const point_rep & point) const;
    如果整个时间段都在之前, 即 t < start, 则为 true.
  18. BOOST_CXX14_CONSTEXPR period intersection(const period & other) const;
    返回交集时间段; 若无交集则返回无效范围.
  19. BOOST_CXX14_CONSTEXPR period merge(const period & other) const;
    返回相交时间段的并集 —— 或 null 时间段.
  20. BOOST_CXX14_CONSTEXPR period span(const period & other) const;
    以最早起点和最晚终点合并两个时间段.
