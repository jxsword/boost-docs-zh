类模板 ymd_formatter

boost::date_time::ymd_formatter — 使用格式化策略把 ymd 转换为标准字符串.

概要

// In header: <boost/date_time/date_formatting_limited.hpp>

template<typename ymd_type, typename format_type> 
class ymd_formatter {
public:

  // public static functions
  static std::string ymd_to_string(ymd_type);
  static std::basic_string< charT > ymd_to_string(ymd_type);
};

说明

ymd_formatter 公有静态函数

  1. static std::string ymd_to_string(ymd_type ymd);
    使用格式化策略把 ymd 转换为标准字符串.

    这是使用基于年-月-日的日期信息处理日期格式化的标准代码. 此函数使用 format_type 控制字符串是否包含分隔符字符, 以及 (如果包含) 分隔符是什么. 此外, 它可以按格式化策略的控制把月份格式化为整数或字符串

  2. static std::basic_string< charT > ymd_to_string(ymd_type ymd);
    使用格式化策略把 ymd 转换为标准字符串.

    这是使用基于年-月-日的日期信息处理日期格式化的标准代码. 此函数使用 format_type 控制字符串是否包含分隔符字符, 以及 (如果包含) 分隔符是什么. 此外, 它可以按格式化策略的控制把月份格式化为整数或字符串
