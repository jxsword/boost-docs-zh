类模板 simple_exception_policy

boost::CV::simple_exception_policy — 用于简化 constrained_value 策略创建过程的模板.

概要

// In header: <boost/date_time/constrained_value.hpp>

template<typename rep_type, rep_type min_value, rep_type max_value, 
         typename exception_type> 
class simple_exception_policy {
public:
  // types
  typedef rep_type value_type;

  // member classes/structs/unions

  struct exception_wrapper : public exception_type {

    // public member functions
    operator std::out_of_range() const;
  };

  // public static functions
  static BOOST_CONSTEXPR rep_type min BOOST_PREVENT_MACRO_SUBSTITUTION();
  static BOOST_CONSTEXPR rep_type max BOOST_PREVENT_MACRO_SUBSTITUTION();
  static void on_error(rep_type, rep_type, violation_enum);
};

说明

simple_exception_policy 公有静态函数

  1. static BOOST_CONSTEXPR rep_type min BOOST_PREVENT_MACRO_SUBSTITUTION();
  2. static BOOST_CONSTEXPR rep_type max BOOST_PREVENT_MACRO_SUBSTITUTION();
  3. static void on_error(rep_type, rep_type, violation_enum);
