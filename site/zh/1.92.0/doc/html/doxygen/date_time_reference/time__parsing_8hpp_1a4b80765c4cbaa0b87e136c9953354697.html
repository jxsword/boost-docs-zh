函数模板 parse_delimited_time_duration

boost::date_time::parse_delimited_time_duration — 从带分隔符的字符串创建 time_duration 对象.

概要

// In header: <boost/date_time/time_parsing.hpp>


template<typename time_duration> 
  time_duration parse_delimited_time_duration(const std::string & s);

说明

字符串的预期格式为 "[-]h[h][:mm][:ss][.fff]". 如果提供的小数位数大于时长类型的精度, 则多余的数字将被截断.

如果字符串的第一个字符是 '-', 则会创建负时长; 所有其他 '-' 将被视为分隔符. 接受的分隔符为 "-:,.".
