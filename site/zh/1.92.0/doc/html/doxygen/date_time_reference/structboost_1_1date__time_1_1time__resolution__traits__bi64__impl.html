结构体 time_resolution_traits_bi64_impl

boost::date_time::time_resolution_traits_bi64_impl — time_resolution_traits 实现类型的特征结构体

概要

// In header: <boost/date_time/time_resolution_traits.hpp>


struct time_resolution_traits_bi64_impl {
  // types
  typedef boost::int64_t int_type; 
  typedef boost::int64_t impl_type;

  // public static functions
  static BOOST_CXX14_CONSTEXPR int_type as_number(impl_type);
  static BOOST_CXX14_CONSTEXPR bool is_adapted();
};

说明

time_resolution_traits_bi64_impl 公有静态函数

  1. static BOOST_CXX14_CONSTEXPR int_type as_number(impl_type i);
  2. static BOOST_CXX14_CONSTEXPR bool is_adapted();
    用于确定实现的类型是 int_adapter 还是 int.
