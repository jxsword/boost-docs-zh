说明

用于时间类型基于格式的输出的刻面. 此类支持使用格式字符串输出时间. 除日期元素格式化的标志外, 允许的格式标志还包括:

  • x X => 默认格式 - 允许向默认格式添加更多标志 (即 "%x %X %z")

  • f => 小数秒 ".123456"

  • F => 小数秒或无: 类似小数秒, 但当小数秒 == 0 时为空

  • s => 带小数秒的秒 "02.123" (这与 "%S%f 相同) - %S => 秒 "02" - %z => 时区缩写 "EDT" - %Z => 时区全名 "Eastern Daylight Time"
