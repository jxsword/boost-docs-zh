类模板 dst_calculator

boost::date_time::dst_calculator — 用于计算 dst 转换信息的动态类.

概要

// In header: <boost/date_time/dst_rules.hpp>

template<typename date_type_, typename time_duration_type_> 
class dst_calculator {
public:
  // types
  typedef time_duration_type_ time_duration_type;
  typedef date_type_          date_type;         

  // public static functions
  static time_is_dst_result 
  process_local_dst_start_day(const time_duration_type &, unsigned int, long);
  static time_is_dst_result 
  process_local_dst_end_day(const time_duration_type &, unsigned int, long);
  static time_is_dst_result 
  local_is_dst(const date_type &, const time_duration_type &, 
               const date_type &, const time_duration_type &, 
               const date_type &, const time_duration_type &, 
               const time_duration_type &);
  static time_is_dst_result 
  local_is_dst(const date_type &, const time_duration_type &, 
               const date_type &, unsigned int, const date_type &, 
               unsigned int, long);
};

说明

dst_calculator 公有静态函数

  1. static time_is_dst_result 
process_local_dst_start_day(const time_duration_type & time_of_day, 
                            unsigned int dst_start_offset_minutes, 
                            long dst_length_minutes);
    在 dst 开始日检查本地时间偏移量.

    在此 dst 转换中, 转换边界与边界加偏移量之间的时间标签是无效时间. 如果在边界之前, 则仍不在 dst 中.

    参数:

    time_of_day

    本地时间的日内时间偏移量

    dst_start_offset_minutes

    dst 开始的本地日偏移量

    dst_length_minutes

    时钟前调的分钟数

    		 
  2. static time_is_dst_result 
process_local_dst_end_day(const time_duration_type & time_of_day, 
                          unsigned int dst_end_offset_minutes, 
                          long dst_length_minutes);
    在 dst 最后一天检查本地时间偏移量.

    这是 DST 结束日的计算. 在该日, 转换时刻减 dst 长度之前的时间 (在美国为凌晨 1 点) 仍处于 dst. 上述时刻与切换时刻之间的时间有歧义. start_offset 之后的时间不在 dst 中.

    参数:

    time_of_day

    本地时间的日内时间偏移量

    dst_end_offset_minutes

    dst 结束的本地日内时刻

    		 
  3. static time_is_dst_result 
local_is_dst(const date_type & current_day, 
             const time_duration_type & time_of_day, 
             const date_type & dst_start_day, 
             const time_duration_type & dst_start_offset, 
             const date_type & dst_end_day, 
             const time_duration_type & dst_end_offset, 
             const time_duration_type & dst_length);
    计算给定的本地时间是否为 dst.

    确定时间是否真的处于 DST. 同时检查无效和歧义时间.

    参数:

    current_day

    要检查 dst 的日期

    time_of_day

    要检查的日内时间偏移量

    dst_start_day

    给定地区的 dst 起始日

    dst_start_offset

    dst 边界的日内时间偏移量

    dst_end_day

    给定地区的 dst 结束日

    dst_end_offset

    以 dst 表示的 dst 边界的日内时间偏移量

    		 
  4. static time_is_dst_result 
local_is_dst(const date_type & current_day, 
             const time_duration_type & time_of_day, 
             const date_type & dst_start_day, 
             unsigned int dst_start_offset_minutes, 
             const date_type & dst_end_day, 
             unsigned int dst_end_offset_minutes, long dst_length_minutes);
    计算给定的本地时间是否为 dst.

    确定时间是否真的处于 DST. 同时检查无效和歧义时间.

    参数:

    current_day

    要检查 dst 的日期

    time_of_day

    要检查的日内时间偏移量

    dst_start_day

    给定地区的 dst 起始日

    dst_start_offset_minutes

    dst 边界的日内偏移量 (例如美国为 120, 即 02:00:00)

    dst_end_day

    给定地区的 dst 结束日

    dst_end_offset_minutes

    以 dst 表示的 dst 边界的日内偏移量 (例如美国为 120, 即 02:00:00)

    dst_length_minutes

    dst 调整的长度 (例如: 美国为 60)
