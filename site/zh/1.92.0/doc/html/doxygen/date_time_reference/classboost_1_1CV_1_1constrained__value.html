类模板 constrained_value

boost::CV::constrained_value — 用于指定受限基本值类型的模板.

概要

// In header: <boost/date_time/constrained_value.hpp>

template<typename value_policies> 
class constrained_value {
public:
  // types
  typedef value_policies::value_type value_type;

  // public member functions
  constrained_value(value_type);
  BOOST_CXX14_CONSTEXPR constrained_value & operator=(value_type);
  BOOST_CXX14_CONSTEXPR operator value_type() const;

  // public static functions
  static BOOST_CONSTEXPR value_type max BOOST_PREVENT_MACRO_SUBSTITUTION();
  static BOOST_CONSTEXPR value_type min BOOST_PREVENT_MACRO_SUBSTITUTION();

  // private member functions
  BOOST_CXX14_CONSTEXPR void assign(value_type);
};

说明

此模板提供了一种快速生成具有受限范围的整数类型的方法. 该类型支持指定最小值, 最大值和错误处理策略.

value 策略 一个类, 通过 min 和 max 函数提供范围限制, 并提供 on_error 函数决定如何处理错误. 常见策略是断言或抛出异常. on_error 会同时收到当前值和出错的新值.

constrained_value 公有成员函数

  1. constrained_value(value_type value);
  2. BOOST_CXX14_CONSTEXPR constrained_value & operator=(value_type v);
  3. BOOST_CXX14_CONSTEXPR operator value_type() const;
    强制转换为表示类型.

constrained_value 公有静态函数

  1. static BOOST_CONSTEXPR value_type max BOOST_PREVENT_MACRO_SUBSTITUTION();
    返回允许的最大值 (特征方法)
  2. static BOOST_CONSTEXPR value_type min BOOST_PREVENT_MACRO_SUBSTITUTION();
    返回允许的最小值 (特征方法)

constrained_value 私有成员函数

  1. BOOST_CXX14_CONSTEXPR void assign(value_type value);
