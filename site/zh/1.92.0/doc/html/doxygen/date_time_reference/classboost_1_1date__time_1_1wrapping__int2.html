类模板 wrapping_int2

boost::date_time::wrapping_int2 — 用于在顶端回绕的回绕整数 (警告: 只能用带符号类型实例化)

概要

// In header: <boost/date_time/wrapping_int.hpp>

template<typename int_type_, int_type_ wrap_min, int_type_ wrap_max> 
class wrapping_int2 {
public:
  // types
  typedef int_type_ int_type;

  // public static functions
  static BOOST_CONSTEXPR int_type wrap_value();
  static BOOST_CONSTEXPR int_type min_value();

  // public member functions
  wrapping_int2(int_type);
  BOOST_CONSTEXPR int_type as_int() const;
  BOOST_CONSTEXPR operator int_type() const;
  template<typename IntT> BOOST_CXX14_CONSTEXPR IntT add(IntT);
  template<typename IntT> BOOST_CXX14_CONSTEXPR IntT subtract(IntT);

  // private member functions
  template<typename IntT> BOOST_CXX14_CONSTEXPR IntT calculate_wrap(IntT);
};

说明

名字不好, 为修一个 bug 的快速实现 —— 以后再修!! 它允许回绕在 0 以外的值处重新开始.

wrapping_int2 公有静态函数

  1. static BOOST_CONSTEXPR int_type wrap_value();
  2. static BOOST_CONSTEXPR int_type min_value();

wrapping_int2 公有成员函数

  1. wrapping_int2(int_type v);

    如果初始化值超出 [wrap_min, wrap_max] 的范围, 值将被初始化为最接近的 min 或 max

  2. BOOST_CONSTEXPR int_type as_int() const;
    显式转换方法.
  3. BOOST_CONSTEXPR operator int_type() const;
  4. template<typename IntT> BOOST_CXX14_CONSTEXPR IntT add(IntT v);
    加法, 返回执行的回绕次数.

    返回值的符号将指示回绕的方向. 例如: 加一个负数可能发生向下回绕, 这将以负返回值指示. 如果发生了向上回绕, 将返回正值

  5. template<typename IntT> BOOST_CXX14_CONSTEXPR IntT subtract(IntT v);
    如果发生向下回绕, 减法将返回 '-d' ('d' 为回绕次数)

    返回值的符号将指示回绕的方向. 例如: 减一个负数可能发生向上回绕, 这将以正返回值指示. 如果发生了向下回绕, 将返回负值

wrapping_int2 私有成员函数

  1. template<typename IntT> BOOST_CXX14_CONSTEXPR IntT calculate_wrap(IntT wrap);
