函数模板 parse_date

boost::date_time::parse_date — 解析带分隔符日期的通用函数 (例如: 2002-02-10)

概要

// In header: <boost/date_time/date_parsing.hpp>


template<typename date_type> 
  date_type parse_date(const std::string & s, int order_spec = ymd_order_iso);

说明

接受的格式为: "2003-02-10", " 2003-Feb-10" 或 "2003-Feburary-10". 月, 日, 年在实参字符串中的出现顺序可以通过传入适当的 ymd_order_spec 来适应
