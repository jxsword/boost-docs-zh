函数模板 convert_string_type

boost::date_time::convert_string_type — 把字符串从一种 value_type 转换为另一种.

概要

// In header: <boost/date_time/string_convert.hpp>


template<typename InputT, typename OutputT> 
  std::basic_string< OutputT > 
  convert_string_type(const std::basic_string< InputT > & inp_str);

说明

把 wstring 转换为 string (或把 string 转换为 wstring). 如果两个模板参数类型相同, 则返回输入字符串的副本.
