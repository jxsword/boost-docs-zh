函数模板 check

boost::xpressive::check — 用于向正则表达式添加用户自定义断言.

概要

// In header: <boost/xpressive/regex_actions.hpp>


template<typename T> unspecified check(T const & t);

说明

用户自定义断言 是一种语义动作, 它对一个布尔 lambda 求值, 若求值为 false, 则使匹配在字符串中的该位置失败. 这会引发回溯, 因此匹配最终仍可能成功.

要在 regex 中使用 check() 指定用户自定义断言, 请使用以下语法:

sregex s = (_d >> _d)[check( XXX )]; // XXX is a custom assertion

该断言用一个 sub_match<> 对象求值, 该对象界定字符串中与断言所附加的子表达式匹配的部分.

check() 可与接受 sub_match<> 对象的普通谓词一起使用, 如下:

// A predicate that is true IFF a sub-match is
// either 3 or 6 characters long.
struct three_or_six
{
    bool operator()(ssub_match const &sub) const
    {
        return sub.length() == 3 || sub.length() == 6;
    }
};

// match words of 3 characters or 6 characters.
sregex rx = (bow >> +_w >> eow)[ check(three_or_six()) ] ;

或者, check() 可用于定义内联自定义断言, 其语法与定义语义动作的语法相同. 以下代码与上面等价:

// match words of 3 characters or 6 characters.
sregex rx = (bow >> +_w >> eow)[ check(length(_)==3 || length(_)==6) ] ;

在自定义断言内, _ 是 sub_match<> 的占位符, 该对象界定字符串中与自定义断言所附加的子表达式匹配的部分.

参数:

t

UnaryPredicate 对象或布尔语义动作.
