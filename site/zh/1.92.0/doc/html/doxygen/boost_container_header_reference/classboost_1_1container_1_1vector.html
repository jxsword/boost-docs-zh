类模板 vector

boost::container::vector

说明

vector 是一种支持随机访问元素、在末尾以常数时间插入和移除元素、在开头或中间以线性时间插入和移除元素的序列. vector 中的元素数量可动态变化; 内存管理是自动的.

模板参数

  1. typename T

    存储在 vector 中的对象类型

  2. typename A = void

    用于所有内部内存管理的分配器, 使用 void 表示默认分配器

  3. typename Options = void

    由 boost::container::vector_options 产生的类型.

vector 公有成员函数

  1. vector();

    效果: 构造一个 vector, 以分配器作为参数.

    抛出: 无.

    复杂度: 常数.

  2. explicit vector(const allocator_type & a) noexcept;

    效果: 构造一个 vector, 以分配器作为参数.

    抛出: 无

    复杂度: 常数.

  3. explicit vector(size_type n);

    效果: 构造一个 vector 并插入 n 个按值初始化的值.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的值初始化抛出异常.

    复杂度: 与 n 成线性.

  4. explicit vector(size_type n, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 vector, 并插入 n 个按值初始化的值.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的值初始化抛出异常.

    复杂度: 与 n 成线性.

  5. vector(size_type n, default_init_t);

    效果: 构造一个将使用分配器 a 的副本的 vector, 并插入 n 个默认初始化的值.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的默认初始化抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展

  6. vector(size_type n, default_init_t, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 vector, 并插入 n 个默认初始化的值.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的默认初始化抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展

  7. vector(size_type n, const T & value);

    效果: 构造一个 vector 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  8. vector(size_type n, const T & value, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 vector, 并插入 value 的 n 个副本.

    抛出: 若分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  9. template<typename InIt> vector(InIt first, InIt last);

    效果: 构造一个 vector 并在 vector 中插入范围 [first, last) 的副本.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  10. template<typename InIt> 
  vector(InIt first, InIt last, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 vector, 并在 vector 中插入范围 [first, last) 的副本.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  11. vector(const vector & x);

    效果: 复制构造一个 vector.

    后置条件: x == *this.

    抛出: 若 allocator_type 的分配抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与 x 包含的元素数成线性.

  12. vector(vector && x) noexcept;

    效果: 移动构造函数. 把 x 的资源移交给 *this.

    抛出: 无

    复杂度: 常数.

  13. vector(std::initializer_list< value_type > il, 
       const allocator_type & a = allocator_type());

    效果: 构造一个将使用分配器 a 的副本的 vector, 并在 vector 中插入范围 [il.begin(), il.last()) 的副本

    抛出: 若 T 的接受解引用 initializer_list 迭代器的构造函数抛出异常.

    复杂度: 与范围 [il.begin(), il.end()) 成线性.

  14. vector(const vector & x, const allocator_type & a);

    效果: 使用指定的分配器复制构造一个 vector.

    后置条件: x == *this.

    抛出: 若分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 x 包含的元素数成线性.

  15. vector(vector && x, const allocator_type & a);

    效果: 使用指定分配器的移动构造函数. 若 a == allocator_type(), 则把 x 的资源移交给 *this. 否则把 x 的值复制到 *this.

    抛出: 若分配或 T 的复制构造函数抛出异常.

    复杂度: 若 a == x.get_allocator() 则为常数, 否则为线性.

  16. ~vector() noexcept;

    效果: 销毁 vector. 所有存储的值被销毁, 已使用的内存被释放.

    抛出: 无.

    复杂度: 与元素数量成线性.

  17. vector & operator=(const vector & x);

    效果: 使 *this 包含与 x 相同的元素.

    后置条件: this->size() == x.size(). *this 包含 x 的每个元素的副本.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动构造/赋值抛出异常.

    复杂度: 与 x 中元素数量成线性.

  18. vector & operator=(std::initializer_list< value_type > il);

    效果: 使 *this 容器包含 il 中的元素.

    复杂度: 与范围 [il.begin(), il.end()) 成线性.

  19. vector & operator=(vector && x);

    效果: 移动赋值. x 的所有值被移交给 *this.

    后置条件: x.empty(). *this 包含函数调用前 x 拥有的所有元素.

    抛出: 若 allocator_traits_type::propagate_on_container_move_assignment 为 false 且 (分配抛出异常或 value_type 的移动构造函数抛出异常)

    复杂度: 若 allocator_traits_type::propagate_on_container_move_assignment 为 true 或 this->get>allocator() == x.get_allocator() 则为常数, 否则为线性.

  20. template<typename InIt> void assign(InIt first, InIt last);

    效果: 把范围 [first, last) 赋给 *this.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动构造/赋值抛出异常, 或 T 的从解引用 InpIt 构造/赋值抛出异常.

    复杂度: 与 n 成线性.

  21. void assign(std::initializer_list< T > il);

    效果: 把范围 [il.begin(), il.end()) 赋给 *this.

    抛出: 若内存分配抛出异常, 或 T 的从解引用 iniializer_list 迭代器构造的构造函数抛出异常.

  22. template<typename FwdIt> void assign(FwdIt first, FwdIt last);

    效果: 把范围 [first, last) 赋给 *this.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动构造/赋值抛出异常, 或 T 的从解引用 InpIt 构造/赋值抛出异常.

    复杂度: 与 n 成线性.

  23. void assign(size_type n, const value_type & val);

    效果: 把 val 的 n 个副本赋给 *this.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动构造/赋值抛出异常.

    复杂度: 与 n 成线性.

  24. allocator_type get_allocator() const noexcept;

    效果: 返回内部分配器的副本.

    抛出: 若分配器的复制构造函数抛出异常.

    复杂度: 常数.

  25. stored_allocator_type & get_stored_allocator() noexcept;

    抛出: 无

    注释: 非标准扩展.

  26. const stored_allocator_type & get_stored_allocator() const noexcept;

    效果: 返回对内部分配器的引用.

    抛出: 无

    复杂度: 常数.

  27. iterator begin() noexcept;

  29. iterator end() noexcept;

    效果: 返回指向反转后 vector 开头的 const_reverse_iterator.

    抛出: 无.

    复杂度: 常数.

  33. reverse_iterator rend() noexcept;

    效果: 返回指向反转后 vector 末尾的 reverse_iterator.

    抛出: 无.

    复杂度: 常数.

  34. const_reverse_iterator rend() const noexcept;

    效果: 返回指向反转后 vector 末尾的 const_reverse_iterator.

    抛出: 无.

  35. const_iterator cbegin() const noexcept;

    效果: 返回指向 vector 中第一个元素的 const_iterator.

    抛出: 无.

    效果: 返回指向 vector 末尾的 const_iterator.

    抛出: 无.

    复杂度: 常数.

  37. const_reverse_iterator crbegin() const noexcept;

    效果: 返回指向反转后 vector 开头的 const_reverse_iterator.

    抛出: 无.

    复杂度: 常数.

  38. const_reverse_iterator crend() const noexcept;

    效果: 返回指向反转后 vector 末尾的 const_reverse_iterator.

    抛出: 无.

    复杂度: 常数.

  39. bool empty() const noexcept;

    效果: 若 vector 不包含任何元素则返回 true.

    抛出: 无.

    复杂度: 常数.

  40. size_type size() const noexcept;

    效果: 返回 vector 中包含的元素数量.

    抛出: 无.

    复杂度: 常数.

  41. size_type max_size() const noexcept;

    效果: 返回 vector 的最大可能大小.

    抛出: 无.

    复杂度: 常数.

  42. void resize(size_type new_size);

    效果: 在末尾插入或擦除元素, 使大小变为 n. 新元素按值初始化.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动或值初始化抛出异常.

    复杂度: 与 size() 和 new_size 之差成线性.

  43. void resize(size_type new_size, default_init_t);

    效果: 在末尾插入或擦除元素, 使大小变为 n. 新元素按默认初始化.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动或默认初始化抛出异常.

    复杂度: 与 size() 和 new_size 之差成线性.

    注释: 非标准扩展

  44. void resize(size_type new_size, const T & x);

    效果: 在末尾插入或擦除元素, 使大小变为 n. 新元素从 x 复制构造.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动构造函数抛出异常.

    复杂度: 与 size() 和 new_size 之差成线性.

  45. size_type capacity() const noexcept;

    效果: 已为其分配内存的元素数量. capacity() 总是大于或等于 size().

    抛出: 无.

    复杂度: 常数.

  46. void reserve(size_type new_cap);

    效果: 若 n 小于或等于 capacity(), 此调用无效果. 否则, 它是请求分配额外内存. 若请求成功, 则 capacity() 大于或等于 n; 否则 capacity() 不变. 无论哪种情况, size() 都不变.

    抛出: 若内存分配抛出异常, 或 T 的复制/移动构造函数抛出异常.

  47. void shrink_to_fit();

    效果: 尝试释放之前分配所创建的多余内存. vector 大小不变

    抛出: 若内存分配抛出异常, 或 T 的复制/移动构造函数抛出异常.

    复杂度: 与 size() 成线性.

  48. reference front() noexcept;

    要求: !empty()

    效果: 返回对容器第一个元素的引用.

    抛出: 无.

    复杂度: 常数.

    要求: !empty()

    效果: 返回对容器第一个元素的 const 引用.

    抛出: 无.

    复杂度: 常数.

  50. reference back() noexcept;

    效果: 返回对容器最后一个元素的引用.

    复杂度: 常数.

  51. const_reference back() const noexcept;

    效果: 返回对容器最后一个元素的 const 引用.

    抛出: 无.

    复杂度: 常数.

    效果: 返回对容器开头第 n 个元素的引用.

    抛出: 无.

    复杂度: 常数.

  53. const_reference operator[](size_type n) const noexcept;

    要求: size() > n.

    效果: 返回对容器开头第 n 个元素的 const 引用.

    抛出: 无.

    复杂度: 常数.

  54. iterator nth(size_type n) noexcept;

    要求: size() >= n.

    效果: 返回指向容器开头第 n 个元素的迭代器. 若 n == size() 则返回 end().

    抛出: 无.

    复杂度: 常数.

    注释: 非标准扩展

  55. const_iterator nth(size_type n) const noexcept;

    要求: size() >= n.

    效果: 返回指向容器开头第 n 个元素的 const_iterator. 若 n == size() 则返回 end().

    抛出: 无.

    复杂度: 常数.

    注释: 非标准扩展

  56. size_type index_of(iterator p) noexcept;

    要求: begin() <= p <= end().

    效果: 返回 p 所指向元素的索引; 若 p == end() 则返回 size().

    抛出: 无.

    复杂度: 常数.

    注释: 非标准扩展

  57. size_type index_of(const_iterator p) const noexcept;

    要求: begin() <= p <= end().

    效果: 返回 p 所指向元素的索引; 若 p == end() 则返回 size().

    抛出: 无.

    复杂度: 常数.

    注释: 非标准扩展

  58. reference at(size_type n);

    要求: size() > n.

    效果: 返回对容器开头第 n 个元素的引用.

    抛出: range_error, 若 n >= size()

    复杂度: 常数.

  59. const_reference at(size_type n) const;

    要求: size() > n.

    效果: 返回对容器开头第 n 个元素的 const 引用.

    抛出: range_error, 若 n >= size()

    复杂度: 常数.

  60. T * data() noexcept;

    返回: 一个指针, 使得 [data(),data() + size()) 是有效范围. 对于非空 vector, data() == &front().

    抛出: 无.

    复杂度: 常数.

  61. const T * data() const noexcept;

    返回: 一个指针, 使得 [data(),data() + size()) 是有效范围. 对于非空 vector, data() == &front().

    抛出: 无.

    复杂度: 常数.

  62. template<class ... Args> reference emplace_back(Args &&... args);

    效果: 在 vector 的末尾插入一个用 std::forward<Args>(args)... 构造的 T 类型对象.

    返回: 对所创建对象的引用.

    抛出: 若内存分配抛出异常、就地构造函数抛出异常, 或 T 的复制/移动构造函数抛出异常.

    复杂度: 均摊常数时间.

  63. template<class ... Args> bool stable_emplace_back(Args &&... args);

    效果: 在 vector 的末尾插入一个用 std::forward<Args>(args)... 构造的 T 类型对象.

    抛出: 若就地构造函数抛出异常.

    复杂度: 常量时间.

    注释: 非标准扩展.

  64. template<class ... Args> reference unchecked_emplace_back(Args &&... args);

    要求: 在调用此函数之前 size() < capacity() 必须为真. 否则行为未定义.

    效果: 在 vector 的末尾插入一个用 std::forward<Args>(args)... 构造的 T 类型对象.

    抛出: 若就地构造函数抛出异常.

    复杂度: 常量时间.

    注释: 非标准扩展.

    效果: 在 position 之前插入一个用 std::forward<Args>(args)... 构造的 T 类型对象

    抛出: 若内存分配抛出异常、就地构造函数抛出异常, 或 T 的复制/移动构造/赋值抛出异常.

    复杂度: 若 position 为 end(), 则为均摊常数时间, 否则为线性时间.

  66. void push_back(const T & x);

  69. void unchecked_push_back(T && x);

  71. iterator insert(const_iterator position, T && x);

    效果: 在 position 之前插入一个新元素并使用 x 的资源.

    抛出: 若内存分配抛出异常.

    复杂度: 若 position 为 end(), 则为均摊常数时间, 否则为线性时间.

  72. iterator insert(const_iterator p, size_type n, const T & x);

    要求: p 必须是 *this 的有效迭代器.

    效果: 在 pos 之前插入 x 的 n 个副本.

    返回: 指向第一个被插入元素的迭代器; 若 n 为 0 则为 p.

    抛出: 若内存分配抛出异常或 T 的复制/移动构造函数抛出异常.

    复杂度: 与 n 成线性.

  73. template<typename InIt> 
  iterator insert(const_iterator pos, InIt first, InIt last);

    要求: p 必须是 *this 的有效迭代器.

    效果: 在 pos 之前插入 [first, last) 范围的副本.

    返回: 指向第一个被插入元素的迭代器; 若 first == last 则为 pos.

    抛出: 若内存分配抛出异常、T 的从解引用 InpIt 构造的构造函数抛出异常, 或 T 的复制/移动构造/赋值抛出异常.

    复杂度: 与 boost::container::iterator_distance [first, last) 成线性.

    抛出: 若内存分配抛出异常、T 的从解引用 InpIt 构造的构造函数抛出异常, 或 T 的复制/移动构造/赋值抛出异常.

    复杂度: 与 boost::container::iterator_distance [first, last) 成线性.

    注释: 此函数避免了对向前和双向迭代器线性计算 boost::container::iterator_distance[first, last), 以及对输入迭代器逐个插入. 这是非标准扩展.
