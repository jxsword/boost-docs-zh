函数 new_delete_resource

boost::container::pmr::new_delete_resource

概要

// In header: <boost/container/pmr/global_resource.hpp>


memory_resource * new_delete_resource();

说明

返回: 指向从 memory_resource 派生的类型的静态存储期对象的指针, 可作为使用全局 operator new 和全局 operator delete 分配内存的资源. 每次调用此函数都返回相同的值. 对返回值 p 和内存资源 r, p->is_equal(r) 返回 &r == p.
