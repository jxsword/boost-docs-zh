结构模板 relocate_on

boost::container::relocate_on

概要

// In header: <boost/container/options.hpp>

template<std::size_t Fraction> 
struct relocate_on {
};

说明

这些选项指定 devector 的重定位策略.

可作为参数传递给该选项的预定义重定位上限为: boost::container::relocate_on_66 boost::container::relocate_on_75 boost::container::relocate_on_80 boost::container::relocate_on_85 boost::container::relocate_on_90

若未指定此选项, 容器将使用默认值.

注释: 仅在一端重复插入 (仅尾部插入或仅头部插入) 通常在使用 relocate_on_66 时导致一次重定位, 而在使用 relocate_on_90 时导致两次重定位.
