说明

flat_multimap 是一种支持等价键 (可能包含同一键值的多份副本) 的关联容器, 并支持基于键快速检索另一类型 T 的值.

flat_multimap 满足容器、可逆容器和关联容器的全部要求. 对于 flat_multimap<Key,T>, key_type 是 Key, value_type 是 std::pair<Key,T> (与 std::multimap<Key, T> 的 value_type 为 std::pair<const Key, T> 不同).

flat_multimap 类似于 std::multimap, 但它实现为有序序列容器. 底层序列容器默认为 vector, 但也可以使用用户提供的类 vector 序列容器 (如 static_vector 或 small_vector).

使用类 vector 序列容器意味着向 flat_multimap 插入新元素可能使先前的迭代器和引用失效 (除非该序列容器是 stable_vector 或提供稳定指针和引用的类似容器). 同样, 擦除元素可能使指向被擦除元素之后 (键更大) 元素的迭代器和引用失效.

此容器提供随机访问迭代器.

模板参数

  1. typename Key

    是映射的 key_type

  2. typename T
  3. typename Compare = std::less<Key>

    是键的排序函数 (例如 std::less<Key>).

  4. typename AllocatorOrContainer = new_allocator< std::pair< Key, T> >

    为以下二者之一:

    • 用于分配 value_type 的分配器 (例如 allocator< std::pair<Key, T> > ). (此时 sequence_type 将为 vector<value_type, AllocatorOrContainer>)

    • 用作底层 sequence_type 的 SequenceContainer. 它必须是具有随机访问迭代器的类 vector 序列容器.
