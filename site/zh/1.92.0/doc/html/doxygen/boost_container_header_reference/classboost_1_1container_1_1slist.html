说明

slist 是单向链表: 一种每个元素链接到下一个元素但不链接到前一个元素的 list. 也就是说, 它是一个支持前向遍历但不支持后向遍历、且以 (均摊) 常数时间插入和移除元素的序列. 与 list 一样, slist 具有以下重要性质: 插入和拼接不会使指向 list 元素的迭代器失效, 甚至移除也只会使指向被移除元素的迭代器失效. 迭代器的顺序可能改变 (即 slist<T>::iterator 在 list 操作后可能具有与之前不同的前驱或后继), 但迭代器本身不会被失效或指向不同的元素, 除非这种失效或变更被显式执行.

slist 与 list 的主要区别在于 list 的迭代器是双向迭代器, 而 slist 的迭代器是前向迭代器. 这意味着 slist 的通用性不如 list; 但通常双向迭代器并非必要. 通常应使用 slist, 除非确实需要 list 的额外功能, 因为单向链表比双向链表更小更快.

重要的性能说明: 与所有其他序列一样, slist 定义了成员函数 insert 和 erase. 然而, 粗心地使用这些成员函数会导致极慢的程序. 问题在于 insert 的第一个实参是迭代器 p, 它在 p 之前插入新元素. 这意味着 insert 必须找到 p 之前的迭代器; 对 list 而言这是常数时间操作, 因为 list 具有双向迭代器, 但对 slist 而言, 它必须通过从头遍历 list 到 p 来找到该迭代器. 换句话说: 在 slist 开头附近以外的任何位置, insert 和 erase 都是慢操作.

slist 提供成员函数 insert_after 和 erase_after, 它们是常数时间操作: 应尽可能始终使用 insert_after 和 erase_after. 若发现 insert_after 和 erase_after 不能满足需要, 且经常需要在 list 中间使用 insert 和 erase, 则可能应使用 list 而不是 slist.

模板参数

  1. typename T

    存储在 list 中的对象类型

  2. typename Allocator = void

    用于所有内部内存管理的分配器, 使用 void 表示默认分配器

slist 公有成员函数

  1. slist();

    效果: 构造一个 list, 以分配器作为参数.

    抛出: 若 allocator_type 的复制构造函数抛出异常.

    复杂度: 常数.

  2. explicit slist(const allocator_type & a) noexcept;

    效果: 构造一个 list, 以分配器作为参数.

    抛出: 无

    复杂度: 常数.

  3. explicit slist(size_type n);

    效果: 构造一个 list 并插入 n 个按值初始化的 value_type.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认构造或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  4. slist(size_type n, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 list, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认构造或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  5. explicit slist(size_type n, const value_type & x, 
               const allocator_type & a = allocator_type());

    效果: 构造一个将使用分配器 a 的副本的 list, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认构造或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  6. template<typename InpIt> 
  slist(InpIt first, InpIt last, const allocator_type & a = allocator_type());

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  7. slist(std::initializer_list< value_type > il, 
      const allocator_type & a = allocator_type());

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 std::initializer_list 迭代器的构造函数抛出异常.

    复杂度: 与范围 [il.begin(), il.end()) 成线性.

  8. slist(const slist & x);

    效果: 复制构造一个 list.

    后置条件: x == *this.

    抛出: 若 allocator_type 的默认构造函数

    复杂度: 与 x 包含的元素数成线性.

  9. slist(slist && x) noexcept;

    效果: 移动构造函数. 把 x 的资源移交给 *this.

    抛出: 若 allocator_type 的复制构造函数抛出异常.

    复杂度: 常数.

  10. slist(const slist & x, const allocator_type & a);

    效果: 使用指定的分配器复制构造一个 list.

    复杂度: 与 x 包含的元素数成线性.

  11. slist(slist && x, const allocator_type & a);

    效果: 使用指定分配器的移动构造函数. 把 x 的资源移交给 *this.

  12. ~slist() noexcept;

  16. void assign(size_type n, const T & val);
