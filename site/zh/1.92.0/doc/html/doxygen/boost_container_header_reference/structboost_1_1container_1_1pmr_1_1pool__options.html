结构 pool_options

boost::container::pmr::pool_options

概要

// In header: <boost/container/pmr/pool_options.hpp>


struct pool_options {

  // public member functions
  pool_options();

  // public data members
  std::size_t max_blocks_per_chunk;
  std::size_t largest_required_pool_block;
};

说明

pool_options 的成员构成一组用于池资源的构造选项. 每个选项对池资源行为的影响如下所述:

  • std::size_t max_blocks_per_chunk: 一次性从上游内存资源分配以补充池的最大块数. 如果 max_blocks_per_chunk 的值为零或大于实现定义的上限, 则改用该上限. 实现可以选择使用比此字段指定值更小的值, 并且可能对不同池使用不同的值.

  • std::size_t largest_required_pool_block: 必须通过池化机制满足的最大分配大小. 试图分配大于此阈值的单个块时, 将直接从上游内存资源分配. 如果 largest_required_pool_block 为零或大于实现定义的上限, 则改用该上限. 实现可以选择比此字段指定值更大的直通阈值.
