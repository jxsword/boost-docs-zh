说明

small_vector 是一种针对包含少量元素情形优化的类 vector 容器. 它在自身内部预留了一些元素, 当实际元素数量低于该预留阈值时, 可避免使用动态存储分配.

small_vector<T, N, Allocator, Options> 可转换为 small_vector_base<T, Allocator, Options>, 后者与预留元素容量无关, 因此客户端代码无需针对 N 实参模板化.

所有 boost::container::vector 成员函数都被继承. 详见 vector 文档.

对 vector 容量的任何更改, 包括通过 shrink_to_fit 方法减小其大小, 都会导致该 vector 永久切换到动态分配的存储.

模板参数

  1. typename T

    存储在 small_vector 中的对象类型

  2. std::size_t N

    存储在 small_vector 内部的预留元素数量. 它应小于 Allocator::max_size();

  3. typename Allocator = void

    当元素数量超过 N 时用于内存管理的分配器. 使用 void 表示默认分配器

  4. typename Options = void

    由 boost::container::small_vector_options 产生的类型.

  8. small_vector(size_type n, const value_type & v, const allocator_type & a);

    效果: 从 small_vector_base (任意 N) 复制构造一个 small_vector. 分配器通过在 other 的分配器上调用 allocator_traits::select_on_container_copy_construction 获得.

    抛出: 若分配抛出异常或 T 的复制构造函数抛出异常.

    效果: 从 small_vector_base (任意 N) 移动构造一个 small_vector, 并转移其分配器. 若 other 持有动态分配的存储, 则窃取其资源; 否则其元素被移动到本对象的内部存储.

    抛出: 若必须移动元素时 T 的移动构造函数抛出异常.

    抛出: 若必须移动元素时 T 的移动构造函数抛出异常.

    复杂度: 若 other 持有动态存储则为常数, 否则与 other.size() 成线性.

  23. void shrink_to_fit();

    效果: 尝试把 capacity() 减小到当前 size(). 一旦容量改变, 容器就永久切换到动态分配的存储, 即使所得大小能放入内部缓冲区.

    抛出: 若内存分配抛出异常或 T 的复制/移动构造函数抛出异常.

    复杂度: 与 size() 成线性.
