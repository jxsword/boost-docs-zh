说明

list 是双向链表. 也就是说, 它是一个既支持前向又支持后向遍历、且在开头、末尾或中间以 (均摊) 常数时间插入和移除元素的序列. list 具有以下重要性质: 插入和拼接不会使指向 list 元素的迭代器失效, 甚至移除也只会使指向被移除元素的迭代器失效. 迭代器的顺序可能改变 (即 list<T>::iterator 在 list 操作后可能具有与之前不同的前驱或后继), 但迭代器本身不会被失效或指向不同的元素, 除非这种失效或变更被显式执行.

模板参数

  1. typename T

    存储在 list 中的对象类型

  2. typename Allocator = void

    用于所有内部内存管理的分配器, 使用 void 表示默认分配器

list 公有成员函数

  1. list();

    效果: 默认构造一个 list.

    抛出: 若 allocator_type 的默认构造函数抛出异常.

    复杂度: 常数.

  2. explicit list(const allocator_type & a) noexcept;

    效果: 构造一个 list, 以分配器作为参数.

    抛出: 无

    复杂度: 常数.

  3. explicit list(size_type n);

    效果: 构造一个 list 并插入 n 个按值初始化的 value_type.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认构造或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  4. list(size_type n, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 list, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认构造或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  5. list(size_type n, const T & value, 
     const ValueAllocator & a = ValueAllocator());

    效果: 构造一个将使用分配器 a 的副本的 list, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认构造或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  6. list(const list & x);

    效果: 复制构造一个 list.

    后置条件: x == *this.

    抛出: 若 allocator_type 的默认构造函数抛出异常.

    复杂度: 与 x 包含的元素数成线性.

  7. list(list && x) noexcept;

    效果: 移动构造函数. 把 x 的资源移交给 *this.

    抛出: 若 allocator_type 的复制构造函数抛出异常.

    复杂度: 常数.

  8. list(const list & x, const allocator_type & a);

    效果: 使用指定的分配器复制构造一个 list.

    后置条件: x == *this.

    抛出: 若 allocator_type 的默认构造函数或复制构造函数抛出异常.

    复杂度: 与 x 包含的元素数成线性.

  9. list(list && x, const allocator_type & a);

    效果: 使用指定分配器的移动构造函数. 把 x 的资源移交给 *this.

    抛出: 若分配或 value_type 的复制构造函数抛出异常.

    复杂度: 若 a == x.get_allocator() 则为常数, 否则为线性.

  10. template<typename InpIt> 
  list(InpIt first, InpIt last, const ValueAllocator & a = ValueAllocator());

    效果: 构造一个将使用分配器 a 的副本的 list, 并在 list 中插入范围 [first, last) 的副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  11. list(std::initializer_list< value_type > il, 
     const ValueAllocator & a = ValueAllocator());

    效果: 构造一个将使用分配器 a 的副本的 list, 并在 list 中插入范围 [il.begin(), il.end()) 的副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 std::initializer_list 迭代器的构造函数抛出异常.

    复杂度: 与范围 [il.begin(), il.end()) 成线性.

  12. ~list() noexcept;

    效果: 销毁 list. 所有存储的值被销毁, 已使用的内存被释放.

    抛出: 无.

    复杂度: 与元素数量成线性.

  13. list & operator=(const list & x);

    效果: 使 *this 包含与 x 相同的元素.

    后置条件: this->size() == x.size(). *this 包含 x 的每个元素的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 x 中元素数量成线性.

  14. list & operator=(list && x);

    效果: 移动赋值. x 的所有值被移交给 *this.

    后置条件: x.empty(). *this 包含函数调用前 x 拥有的所有元素.

    抛出: 若 allocator_traits_type::propagate_on_container_move_assignment 为 false 且 (分配抛出异常或 value_type 的移动构造函数抛出异常)

    复杂度: 若 allocator_traits_type::propagate_on_container_move_assignment 为 true 或 this->get>allocator() == x.get_allocator() 则为常数, 否则为线性.

  15. list & operator=(std::initializer_list< value_type > il);

    效果: 使 *this 包含与 il 相同的元素.

    后置条件: this->size() == il.size(). *this 包含 x 的每个元素的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 x 中元素数量成线性.

  16. void assign(size_type n, const T & val);

    效果: 把 val 的 n 个副本赋给 *this.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  17. template<typename InpIt> void assign(InpIt first, InpIt last);

    复杂度: 与距离 [il.begin(), il.end()) 成线性.

  56. void pop_back() noexcept;

  57. iterator erase(const_iterator p) noexcept;

  59. void swap(list & x);

    抛出: 无.
