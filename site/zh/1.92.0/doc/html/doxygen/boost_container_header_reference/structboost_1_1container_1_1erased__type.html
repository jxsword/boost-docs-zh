结构体 erased_type

boost::container::erased_type

概要

// In header: <boost/container/uses_allocator_fwd.hpp>


struct erased_type {
};

说明

erased_type 结构体是一个空结构体, 在实际类型 T 于运行期确定的情形下充当 T 的占位符. 例如, 嵌套类型 allocator_type 在使用类型擦除分配器的类中是 erased_type 的别名.
