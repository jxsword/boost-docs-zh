说明

map 是一种支持唯一键 (每个键值最多包含一个) 的关联容器, 并支持基于键快速检索另一类型 T 的值. map 类支持双向迭代器.

map 满足容器、可逆容器和关联容器的全部要求. 此容器存储的 value_type 是 value_type, 即 std::pair<const Key, T>.

模板参数

  1. typename Key

    是映射的 key_type

  2. typename T

    是 mapped_type 

  3. typename Compare = std::less<Key>

    是键的排序函数 (例如 std::less<Key>).

  4. typename Allocator = void

    是用于分配 value_type 的分配器 (例如 allocator< std::pair<const Key, T> > ).

  5. typename Options = tree_assoc_defaults

    是使用 boost::container::tree_assoc_options 生成的一种打包选项类型.
