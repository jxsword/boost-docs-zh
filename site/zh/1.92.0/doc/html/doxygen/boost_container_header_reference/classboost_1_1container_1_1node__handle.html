类模板 node_handle

boost::container::node_handle

概要

// In header: <boost/container/node_handle.hpp>

template<typename NodeAllocator, typename KeyMapped = void> 
class node_handle {
public:
  // types
  typedef priv_value_t                                                     value_type;         
  typedef keymapped_t::key_type                                            key_type;           
  typedef keymapped_t::mapped_type                                         mapped_type;        
  typedef nator_traits::template portable_rebind_alloc< value_type >::type allocator_type;     
  typedef priv_node_t                                                      container_node_type;

  // friend functions
  void swap(node_handle &, node_handle &);

  // public member functions
  node_handle() noexcept;
  node_handle(node_pointer, const nallocator_type &) noexcept;
  template<typename KeyMapped2> 
    node_handle(node_handle< NodeAllocator, KeyMapped2 > &&, 
                typename dtl::enable_if_c<((unsigned) dtl::is_same< KeyMapped, void >::value+(unsigned) dtl::is_same< KeyMapped2, void >::value)==1u >::type * = 0) noexcept;
  node_handle(node_handle &&) noexcept;
  ~node_handle() noexcept;
  node_handle & operator=(node_handle &&) noexcept;
  value_type & value() const noexcept;
  key_type & key() const noexcept;
  mapped_type & mapped() const noexcept;
  allocator_type get_allocator() const;
  explicit operator bool() const noexcept;
  bool empty() const noexcept;
  void swap(node_handle &);
  node_pointer release() noexcept;
  node_pointer get() const noexcept;
  nallocator_type & node_alloc() noexcept;
  const nallocator_type & node_alloc() const noexcept;
};

说明

node_handle 是从关联容器接受单个元素所有权的对象. 它可用于把该所有权转移到具有兼容节点的另一个容器. 具有兼容节点的容器拥有相同的节点句柄类型. 元素可在同一行中的容器类型之间双向转移:.

具有兼容节点的容器类型

map<K, T, C1, A> <-> map<K, T, C2, A>

map<K, T, C1, A> <-> multimap<K, T, C2, A>

set<K, C1, A> <-> set<K, C2, A>

set<K, C1, A> <-> multiset<K, C2, A>

若节点句柄非空, 则它包含一个与元素被提取时容器的分配器相等的分配器. 若节点句柄为空, 则它不包含分配器.

node_handle 友元函数

  1. void swap(node_handle & x, node_handle & y);

    效果: x.swap(y).

node_handle 公有成员函数

  1. node_handle() noexcept;

    效果: 把 m_ptr 初始化为 nullptr.

    后置条件: this->empty() 

  2. node_handle(node_pointer p, const nallocator_type & al) noexcept;

    效果: 构造一个 node_handle 对象, 用 p 初始化内部指针. 若 p != nullptr, 则从 al 复制构造内部分配器.

  3. template<typename KeyMapped2> 
  node_handle(node_handle< NodeAllocator, KeyMapped2 > && nh, 
              typename dtl::enable_if_c<((unsigned) dtl::is_same< KeyMapped, void >::value+(unsigned) dtl::is_same< KeyMapped2, void >::value)==1u >::type * = 0) noexcept;

    效果: 构造一个 node_handle 对象, 用相关 nh 的内部指针初始化内部指针, 并把 nullptr 赋给后者. 若 nh 的内部指针不是 nullptr, 则用 nh 的内部分配器移动构造内部分配器并销毁 nh 的内部分配器.

    后置条件: nh.empty()

    注释: 仅当节点句柄的 KeyMapped 模板参数中只有一个是 void 时, 两个 node_handle 才是相关的.

  4. node_handle(node_handle && nh) noexcept;

    效果: 构造一个 node_handle 对象, 用 nh 的内部指针初始化内部指针, 并把 nullptr 赋给后者. 若 nh 的内部指针不是 nullptr, 则用 nh 的内部分配器移动构造内部分配器并销毁 nh 的内部分配器.

    后置条件: nh.empty()

  5. ~node_handle() noexcept;

    效果: 若 !this->empty(), 则通过调用 allocator_traits<impl_defined>::destroy 销毁 c 所指向的 container_node_type 对象中的 value_type 子对象, 然后通过调用 nator_traits::rebind_traits<container_node_type>::deallocate 释放 m_ptr.

  6. node_handle & operator=(node_handle && nh) noexcept;

    要求: this->empty(), 或 nator_traits::propagate_on_container_move_assignment 为 true, 或 node_alloc() == nh.node_alloc().

    效果: 若 m_ptr != nullptr, 则通过调用 nator_traits::destroy 销毁 m_ptr 所指向的 container_node_type 对象中的 value_type 子对象, 然后通过调用 nator_traits::deallocate 释放 m_ptr. 把 nh.m_ptr 赋给 m_ptr. 若 this->empty() 或 nator_traits::propagate_on_container_move_assignment 为 true, 则把 nh.node_alloc() 移动赋给 node_alloc(). 把 nullptr 赋给 nh.m_ptr, 并把 nullopt 赋给 nh.node_alloc().

    返回: *this.

    抛出: 无.

  7. value_type & value() const noexcept;

    要求: empty() == false.

    返回: 对 m_ptr 所指向的 container_node_type 对象中 value_type 子对象的引用

    抛出: 无.

  8. key_type & key() const noexcept;

    要求: empty() == false.

    返回: 对 m_ptr 所指向的 container_node_type 对象中 value_type 子对象的 key_type 成员的非 const 引用.

    抛出: 无.

    要求: 允许通过返回的引用修改键.

  9. mapped_type & mapped() const noexcept;

    要求: empty() == false.

    返回: 对 m_ptr 所指向的 container_node_type 对象中 value_type 子对象的 mapped_type 成员的引用

    抛出: 无.

  10. allocator_type get_allocator() const;

    要求: empty() == false.

    返回: 内部持有的分配器的副本.

    抛出: 无.

  11. explicit operator bool() const noexcept;

    返回: m_ptr != nullptr.

  12. bool empty() const noexcept;

    返回: m_ptr == nullptr.

  13. void swap(node_handle & nh);

    要求: this->empty(), 或 nh.empty(), 或 nator_traits::propagate_on_container_swap 为 true, 或 node_alloc() == nh.node_alloc().

    效果: 调用 swap(m_ptr, nh.m_ptr). 若 this->empty(), 或 nh.empty(), 或 nator_traits::propagate_on_- container_swap 为 true, 则调用 swap(node_alloc(), nh.node_alloc()).

  14. node_pointer release() noexcept;

    效果: 若 this->empty() 返回 nullptr, 否则返回 m_ptr 并把 m_ptr 重置为 nullptr 并销毁内部分配器.

    后置条件: this->empty()

    注释: 非标准扩展

  15. node_pointer get() const noexcept;

    效果: 返回 m_ptr.

    注释: 非标准扩展

  16. nallocator_type & node_alloc() noexcept;

    效果: 返回对内部节点分配器的引用.

    注释: 非标准扩展

  17. const nallocator_type & node_alloc() const noexcept;

    效果: 返回对内部节点分配器的引用.

    注释: 非标准扩展
