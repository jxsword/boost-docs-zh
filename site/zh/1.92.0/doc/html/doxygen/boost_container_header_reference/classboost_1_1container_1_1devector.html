说明

一种类 vector 的序列容器, 提供前端和后端操作 (例如 push_front/pop_front/push_back/pop_back), 复杂度为均摊常数.

建模 SequenceContainer、ReversibleContainer 和 AllocatorAwareContainer 概念.

要求:

  • T 必须可 MoveInsertable 到 devector 中.

  • T 必须可 Erasable 于任意 devector<T, allocator_type, GP>.

  • GrowthFactor 和 Allocator 必须建模同名概念或为 void.

定义: 若 T 要么可无异常移动构造, 要么可无异常复制构造, 则其为 NothrowConstructible.

定义: 若 T 要么可无异常移动赋值, 要么可无异常复制赋值, 则其为 NothrowAssignable.

异常: 异常规范假定 T 可无异常 Destructible.

大多数提供强异常保证的方法假定 T 要么具有标记为 noexcept 的移动构造函数, 要么可 CopyInsertable 到 devector 中. 若并非如此且移动构造函数抛出异常, 则保证失效, 效果未指定.

除 抛出 子句中指定的异常外, 当要求以下指定概念之一时, T 的下列操作可能抛出异常:

  • DefaultInsertable: 默认构造函数

  • MoveInsertable: 移动构造函数

  • CopyInsertable: 复制构造函数

  • DefaultConstructible: 默认构造函数

  • EmplaceConstructible: 由给定实参选择的构造函数

  • MoveAssignable: 移动赋值运算符

  • CopyAssignable: 复制赋值运算符

此外, 不是所有 noexcept 方法都会在内存分配失败时抛出分配器抛出的异常. 此类方法也会抛出 length_error, 若容量超过 max_size().

备注: 若某方法使一些迭代器失效, 它也会使指向这些已失效迭代器所指向元素的引用和指针失效.

devector 公有成员函数

  1. devector() noexcept;

    效果: 构造一个空的 devector.

    后置条件: empty() && front_free_capacity() == 0 && back_free_capacity() == 0.

    复杂度: 常数.

  2. explicit devector(const allocator_type & allocator) noexcept;

    效果: 使用指定的分配器构造一个空的 devector.

    后置条件: empty() && front_free_capacity() == 0 && back_free_capacity() == 0.

    复杂度: 常数.

  3. devector(size_type n, reserve_only_tag_t, 
         const allocator_type & allocator = allocator_type());

    效果: 使用指定的分配器构造一个空的 devector, 并预留 n 个槽位, 如同调用了 reserve(n).

    后置条件: empty() && capacity() >= n.

    异常: 强异常保证.

    复杂度: 常数.

  4. devector(size_type front_free_cap, size_type back_free_cap, 
         reserve_only_tag_t, 
         const allocator_type & allocator = allocator_type());

    效果: 使用指定的分配器构造一个空的 devector, 并至少预留 front_free_cap + back_free_cap 个槽位, 如同调用了 reserve_front(front_cap) 和 reserve_back(back_cap).

    后置条件: empty() && front_free_capacity() >= front_free_cap && back_free_capacity() >= back_free_cap.

    异常: 强异常保证.

    复杂度: 常数.

  5. explicit devector(size_type n, 
                  const allocator_type & allocator = allocator_type());

    效果: 使用指定的分配器构造一个含 n 个按值初始化元素的 devector.

    要求: T 必须可 DefaultInsertable 到 *this 中.

    后置条件: size() == n.

    异常: 强异常保证.

    复杂度: 与 n 成线性.

  6. explicit devector(size_type n, default_init_t, 
                  const allocator_type & allocator = allocator_type());

    效果: 使用指定的分配器构造一个含 n 个默认初始化元素的 devector.

    要求: T 必须 [DefaultInsertable] 到 *this 中.

    后置条件: size() == n.

    异常: 强异常保证.

    复杂度: 与 n 成线性.

  7. devector(size_type n, const T & value, 
         const allocator_type & allocator = allocator_type());

    效果: 使用指定的分配器构造一个含 n 个 value 副本的 devector.

    要求: T 必须可 CopyInsertable 到 *this 中.

    后置条件: size() == n.

    异常: 强异常保证.

    复杂度: 与 n 成线性.

  8. template<typename InputIterator> 
  devector(InputIterator first, InputIterator last, 
           const allocator_type & allocator = allocator_type());

    效果: 使用指定的分配器构造一个等于范围 [first,last) 的 devector.

    要求: T 必须可 EmplaceConstructible 到 *this 中, 实参为 *first. 若指定迭代器不满足向前迭代器要求, T 还必须可 MoveInsertable 到 *this 中.

    后置条件: size() == boost::container::iterator_distance(first, last)

    异常: 强异常保证.

    复杂度: 若迭代器 first 和 last 属于向前、双向或随机访问类别, 则只进行 N 次 T 的复制构造函数调用 (其中 N 是 first 与 last 之间的距离), 至多一次分配且无重新分配. 若它们只是输入迭代器, 则进行 O(N) 次 T 的复制构造函数调用, 并进行 O(log(N)) 次重新分配.

    备注: 范围 [first,last) 中的每个迭代器都应恰好被解引用一次, 除非抛出异常.

  9. devector(const devector & x);

    效果: 复制构造一个 devector.

    要求: T 必须可 CopyInsertable 到 *this 中.

    后置条件: this->size() == x.size().

    异常: 强异常保证.

    复杂度: 与 x 的大小成线性.

  10. devector(const devector & x, const allocator_type & allocator);

    效果: 使用指定的分配器复制构造一个 devector.

    要求: T 必须可 CopyInsertable 到 *this 中.

    后置条件: *this == x.

    异常: 强异常保证.

    复杂度: 与 x 的大小成线性.

  11. devector(devector && rhs) noexcept;

    效果: 把 rhs 的资源移交给 *this.

    抛出: 无.

    后置条件: *this 具有与操作前 rhs 相同的值. rhs 处于未指定但有效的状态.

    异常: 若 noexcept 不成立则为强异常保证.

    复杂度: 常数.

  12. devector(devector && rhs, const allocator_type & allocator);

    效果: 使用指定的分配器把 rhs 的资源移交给 *this.

    抛出: 若分配或 T 的移动构造函数抛出异常.

    后置条件: *this 具有与操作前 rhs 相同的值. rhs 处于未指定但有效的状态.

    异常: 若 noexcept 不成立则为强异常保证.

    复杂度: 若 allocator != rhs.get_allocator() 则为线性, 否则为常数.

  13. devector(const std::initializer_list< T > & il, 
         const allocator_type & allocator = allocator_type());

    等价于: devector(il.begin(), il.end(), allocator).

  14. ~devector() noexcept;

    效果: 销毁 devector. 所有存储的值被销毁, 已使用的内存 (如有) 被释放.

    复杂度: 与 *this 的大小成线性.

  15. devector & operator=(const devector & rhs);

    效果: 把 x 的元素复制到 *this. 先前持有的元素被复制赋值或销毁.

    要求: T 必须可 CopyInsertable 到 *this 中.

    后置条件: this->size() == x.size(), *this 的元素按相同顺序是 x 中元素的副本.

    返回: *this.

    异常: 若 T 为 NothrowConstructible 且允许传播分配器 (propagate_on_container_copy_assignment 为 true) 则为强异常保证, 否则为基本异常保证.

    复杂度: 与 x 和 *this 的大小成线性.

  16. devector & operator=(devector && x);

    效果: 把 x 的元素移动到 *this. 先前持有的元素被移动/复制赋值或销毁.

    要求: T 必须可 MoveInsertable 到 *this 中.

    后置条件: x 处于未指定但有效的状态.

    返回: *this.

    异常: 若 noexcept 不成立则为基本异常保证.

    复杂度: 若 allocator_traits_type::propagate_on_container_move_assignment 为 true 或 this->get>allocator() == x.get_allocator() 则为常数, 否则为线性.

  17. devector & operator=(std::initializer_list< T > il);

    效果: 把 il 的元素复制到 *this. 先前持有的元素被复制赋值或销毁.

    要求: T 必须可 CopyInsertable 到 *this 中且可 CopyAssignable.

    后置条件: this->size() == il.size(), *this 的元素按相同顺序是 il 中元素的副本.

    异常: 若 T 可从 T 和 NothrowConstructible 无异常复制赋值则为强异常保证, 否则为基本异常保证.

    返回: *this.

    复杂度: 与 il 和 *this 的大小成线性.

  18. template<typename InputIterator> 
  void assign(InputIterator first, InputIterator last);

    效果: 把 *this 的元素替换为 [first,last) 的副本. 先前持有的元素被复制赋值或销毁.

    要求: T 必须可 EmplaceConstructible 自 *first. 若指定迭代器不满足向前迭代器要求, T 还必须可 MoveInsertable 到 *this 中.

    前置条件: first 和 last 不是指向 *this 的迭代器.

    后置条件: size() == N, 其中 N 是 first 与 last 之间的距离.

    异常: 若 T 可从 *first 和 NothrowConstructible 无异常复制赋值则为强异常保证, 否则为基本异常保证.

    复杂度: 与 first 和 last 之间的距离成线性. 若迭代器 first 和 last 属于向前、双向或随机访问类别, 至多进行一次重新分配. 若它们只是输入迭代器, 则进行 O(log(N)) 次重新分配.

    备注: 范围 [first,last) 中的每个迭代器都应恰好被解引用一次, 除非抛出异常.

  19. void assign(size_type n, const T & u);

    后置条件: sz == size().

    要求: T 必须可 CopyInsertable 到 *this 中.

    异常: 强异常保证.

    复杂度: 与 *this 和 sz 的大小成线性.

  48. void resize_back(size_type sz);

  79. template<class... Args> 
  iterator emplace(const_iterator position, Args &&... args);

    返回: 指向新构造元素的迭代器.

    要求: T 必须可 CopyInsertable 到 *this 中且可 CopyAssignable.

    返回: 指向第一个被插入元素的迭代器, 或 position, 若 n 为零.

    异常: 若 T 为 NothrowConstructible 且 NothrowAssignable 则为强异常保证, 否则为基本异常保证.

    复杂度: 与 *this 和 n 的大小成线性.

  83. template<typename InputIterator> 
  iterator insert(const_iterator position, InputIterator first, 
                  InputIterator last);

    效果: 在 position 所指向元素之前复制构造若干元素, 以 first 和 last 所指范围中的每个元素作为构造函数实参. 若需要重新分配则使迭代器失效.

    要求: T 必须可 EmplaceConstructible 到 *this 中, 实参为 *first. 若指定迭代器不满足向前迭代器要求, T 还必须可 MoveInsertable 到 *this 中且可 MoveAssignable.

    前置条件: first 和 last 不是指向 *this 的迭代器.

    返回: 指向第一个被插入元素的迭代器, 或 position, 若 first == last.

    复杂度: 与 *this 和 N 的大小成线性 (其中 N 是 first 与 last 之间的距离). 只进行 N 次 T 的构造函数调用, 且若迭代器 first 和 last 属于向前、双向或随机访问类别则无重新分配. 若它们只是输入迭代器, 则进行 2N 次 T 的复制构造函数调用并进行 O(log(N)) 次重新分配.

    异常: 若 T 为 NothrowConstructible 且 NothrowAssignable 则为强异常保证, 否则为基本异常保证.

    备注: 范围 [first,last) 中的每个迭代器都应恰好被解引用一次, 除非抛出异常.

    效果: 销毁 position 所指向的元素并将其从 devector 中移除. 使迭代器失效.

    效果: 销毁 devector 中的所有元素. 使所有指向 devector 元素的引用、指针和迭代器失效.
