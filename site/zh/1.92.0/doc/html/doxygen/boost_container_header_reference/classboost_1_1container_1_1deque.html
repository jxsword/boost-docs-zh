boost::container::deque

class deque : public deque_impl< T, void, false, void > {

说明

双端队列是一种支持随机访问元素、在序列末尾以常数时间插入和移除元素、在序列中间以线性时间插入和移除元素的序列.

模板参数

  1. typename T

    存储在 deque 中的对象类型

  2. typename Allocator = void
  3. typename Options = void

    由 boost::container::deque_options 产生的类型.

deque 公有成员函数

  1. deque();

    效果: 默认构造一个 deque.

    抛出: 若 allocator_type 的默认构造函数抛出异常.

    复杂度: 常数.

  2. explicit deque(const allocator_type & a) noexcept;

    效果: 构造一个 deque, 以分配器作为参数.

    抛出: 无

    复杂度: 常数.

  3. explicit deque(size_type n);

    效果: 构造一个 deque 并插入 n 个按值初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的值初始化抛出异常.

    复杂度: 与 n 成线性.

  4. deque(size_type n, default_init_t);

    效果: 构造一个 deque 并插入 n 个默认初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认初始化或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展

  5. explicit deque(size_type n, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 deque, 并插入 n 个按值初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的值初始化抛出异常.

    复杂度: 与 n 成线性.

  6. deque(size_type n, default_init_t, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 deque, 并插入 n 个默认初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认初始化或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展

  7. deque(size_type n, const value_type & value);

    效果: 构造一个将使用分配器 a 的副本的 deque, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  8. deque(size_type n, const value_type & value, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 deque, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  9. template<typename InIt> deque(InIt first, InIt last);

    效果: 构造一个将使用分配器 a 的副本的 deque, 并在 deque 中插入范围 [first, last) 的副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  10. template<typename InIt> deque(InIt first, InIt last, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 deque, 并在 deque 中插入范围 [first, last) 的副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  11. deque(std::initializer_list< value_type > il, 
      const allocator_type & a = allocator_type());

    效果: 构造一个将使用分配器 a 的副本的 deque, 并在 deque 中插入范围 [il.begin(), il.end()) 的副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 std::initializer_list 迭代器的构造函数抛出异常.

    复杂度: 与范围 [il.begin(), il.end()) 成线性.

  12. deque(const deque & x);

    效果: 复制构造一个 deque.

    后置条件: x == *this.

    复杂度: 与 x 包含的元素数成线性.

  13. deque(deque && x) noexcept;

    效果: 移动构造函数. 把 x 的资源移交给 *this.

    抛出: 若 allocator_type 的复制构造函数抛出异常.

    复杂度: 常数.

  14. deque(const deque & x, const allocator_type & a);

    效果: 使用指定的分配器复制构造一个 vector.

    后置条件: x == *this.

    抛出: 若分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 x 包含的元素数成线性.

  15. deque(deque && x, const allocator_type & a);

    效果: 使用指定分配器的移动构造函数. 若 a == allocator_type(), 则把 x 的资源移交给 *this. 否则把 x 的值复制到 *this.

    抛出: 若分配或 T 的复制构造函数抛出异常.

    复杂度: 若 a == x.get_allocator() 则为常数, 否则为线性.

  16. ~deque() noexcept;

    效果: 销毁 deque. 所有存储的值被销毁, 已使用的内存被释放.

    抛出: 无.

    复杂度: 与元素数量成线性.

  17. deque & operator=(const deque & x);

    效果: 使 *this 包含与 x 相同的元素.

    后置条件: this->size() == x.size(). *this 包含 x 的每个元素的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 x 中元素数量成线性.

  18. deque & operator=(deque && x);

    效果: 移动赋值. x 的所有值被移交给 *this.

    抛出: 若 allocator_traits_type::propagate_on_container_move_assignment 为 false 且 (分配抛出异常或 value_type 的移动构造函数抛出异常)

    复杂度: 若 allocator_traits_type::propagate_on_container_move_assignment 为 true 或 this->get_allocator() == x.get_allocator() 则为常数, 否则为线性.

  19. deque & operator=(std::initializer_list< value_type > il);

    效果: 使 *this 包含与 il 相同的元素.

    后置条件: this->size() == il.size(). *this 包含 il 的每个元素的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 il 中元素数量成线性.

  20. void assign(size_type n, const value_type & val);

    效果: 把 val 的 n 个副本赋给 *this.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  21. template<typename InputIterator>

  42. void reserve_back(size_type n);

    要求: 容器必须是 "reservable" (is_reservable == true)

    效果: 若 n 小于或等于 back_capacity() 或容器不可预留, 此调用无效果. 否则, 它是请求分配额外内存. 若请求成功, 则 back_capacity() 大于或等于 n; 否则 back_capacity() 不变. 无论哪种情况, size() 都不变.

    抛出: 若内存分配抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展.

  43. void reserve_front(size_type n);

    效果: 若 n 小于或等于 front_capacity() 或容器不可预留, 此调用无效果. 否则, 它是请求分配额外内存. 若请求成功, 则 front_capacity() 大于或等于 n; 否则 front_capacity() 不变. 无论哪种情况, size() 都不变.

    抛出: 无.

    复杂度: 常数.

    注释: 非标准扩展

  56. size_type index_of(iterator p);

    抛出: 无.

    复杂度: 常数.

    注释: 非标准扩展

  57. size_type index_of(const_iterator p) const;

    抛出: 无.

    复杂度: 常数.

    注释: 非标准扩展

  58. reference at(size_type n);

  59. const_reference at(size_type n) const;

    复杂度: 均摊常数时间

  61. template<class... Args> reference emplace_back(Args &&... args);

    效果: 在 deque 的末尾插入一个用 std::forward<Args>(args)... 构造的 T 类型对象.

    返回: 对所创建对象的引用.

    抛出: 若内存分配抛出异常或就地构造函数抛出异常.

    复杂度: 均摊常数时间

  62. template<class... Args> iterator emplace(const_iterator p, Args &&... args);

    要求: p 必须是 *this 的有效迭代器.

    效果: 在 p 之前插入一个用 std::forward<Args>(args)... 构造的 T 类型对象

    抛出: 若内存分配抛出异常或就地构造函数抛出异常.

    复杂度: 若 p 为 end() 或 begin(), 则为均摊常数时间, 否则为线性时间.

  63. void push_front(const value_type & x);

    效果: 在 deque 的开头插入 x 的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 均摊常数时间.

  64. void push_front(value_type && x);

    效果: 在 deque 的开头构造一个新元素, 并把 x 的资源移交给这个新元素.

    抛出: 若内存分配抛出异常.

    复杂度: 均摊常数时间.

  65. void push_back(const value_type & x);

    效果: 在 deque 的末尾插入 x 的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 均摊常数时间.

  66. void push_back(value_type && x);

    效果: 在 deque 的末尾构造一个新元素, 并把 x 的资源移交给这个新元素.

    抛出: 若内存分配抛出异常.

    复杂度: 均摊常数时间.

  67. iterator insert(const_iterator p, const T & x);

    要求: p 必须是 *this 的有效迭代器.

    效果: 在 p 之前插入 x 的副本.

    返回: 指向被插入元素的迭代器.

    抛出: 若内存分配抛出异常或 x 的复制构造函数抛出异常.

    复杂度: 若 p 为 end() 或 begin(), 则为均摊常数时间, 否则为线性时间.

  68. iterator insert(const_iterator p, T && x);

    要求: p 必须是 *this 的有效迭代器.

    效果: 在 p 之前插入一个新元素并使用 x 的资源.

    返回: 指向被插入元素的迭代器.

    抛出: 若内存分配抛出异常.

    复杂度: 若 p 为 end() 或 begin(), 则为均摊常数时间, 否则为线性时间.

  69. iterator insert(const_iterator pos, size_type n, const value_type & x);

    要求: pos 必须是 *this 的有效迭代器.

    效果: 在 pos 之前插入 x 的 n 个副本.

    返回: 指向第一个被插入元素的迭代器; 若 n 为 0 则为 pos.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  70. template<typename InIt> 
  iterator insert(const_iterator pos, InIt first, InIt last);

    要求: pos 必须是 *this 的有效迭代器.

    效果: 在 pos 之前插入 [first, last) 范围的副本.

    返回: 指向第一个被插入元素的迭代器; 若 first == last 则为 pos.

    抛出: 若内存分配抛出异常、T 的从解引用 InIt 构造的构造函数抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与距离 [first, last) 成线性.

  71. iterator insert(const_iterator pos, std::initializer_list< value_type > il);

    要求: pos 必须是 *this 的有效迭代器.

    效果: 在 pos 之前插入 [il.begin(), il.end()) 范围的副本.

    返回: 指向第一个被插入元素的迭代器; 若 il.begin() == il.end() 则为 pos.

    抛出: 若内存分配抛出异常、T 的从解引用 std::initializer_list 构造的构造函数抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与距离 [il.begin(), il.end()) 成线性.

  72. void pop_front();

    效果: 从 deque 中移除第一个元素.

    抛出: 无.

    复杂度: 常量时间.

  73. void pop_back();

    效果: 从 deque 中移除最后一个元素.

    抛出: 无.

    复杂度: 常量时间.

  74. iterator erase(const_iterator first, const_iterator last);

    效果: 擦除 p 处的元素.

    抛出: 无.

    复杂度: 与 pos 和最后一个元素之间的元素数成线性 (若 pos 接近末尾), 或与第一个元素成线性 (若 pos 接近开头). 若 pos 是第一个或最后一个元素则为常数. 效果: 擦除 [first, last) 所指向的元素.

    抛出: 无.

    复杂度: 与 first 和 last 之间的距离加上 pos 与最后一个元素之间的元素数 (若 pos 接近末尾) 或与第一个元素之间的距离 (若 pos 接近开头) 成线性.

  75. void swap(deque & x);

    效果: 交换 *this 与 x 的内容.

    抛出: 无.

    复杂度: 常数.

  76. void clear();

    效果: 擦除 deque 的所有元素.

    抛出: 无.

    复杂度: 与 deque 中元素数量成线性.
