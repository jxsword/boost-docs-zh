结构体模板 deque_options

boost::container::deque_options

概要

// In header: <boost/container/options.hpp>

template<class ... Options> 
struct deque_options {
  // types
  typedef implementation_defined type;
};

说明

辅助元函数, 把各选项组合成单一类型, 供 boost::container::deque 使用. 支持的选项有: boost::container::block_bytes / boost::container::segment_bytes、boost::container::block_size / boost::container::segment_size、boost::container::stored_size
