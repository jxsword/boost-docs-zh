结构模板 throw_on_overflow

boost::container::throw_on_overflow

概要

// In header: <boost/container/options.hpp>

template<bool ThrowOnOverflow> 
struct throw_on_overflow {
};

说明

该选项指定当静态容量不足以容纳所需值时容器是否抛出异常. 如果指定 false, 容量不足将触发 BOOST_ASSERT, 若断言返回, 则为未定义行为, 这可能带来更好的 static_vector 性能. 默认值为 true.
