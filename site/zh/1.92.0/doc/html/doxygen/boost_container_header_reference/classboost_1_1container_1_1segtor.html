说明

segtor ("segmented vector" 的缩写) 是一种序列容器, 支持随机访问元素、在末尾以常数时间插入和移除元素, 以及在中间以线性时间插入和移除元素.

它是 boost::container::deque 的单端版本: 它提供 push_back、pop_back、emplace_back 等, 但不提供 push_front、pop_front 或 emplace_front.

模板参数

  1. typename T

    存储在 segtor 中的对象类型

  2. typename Allocator = void

    用于所有内部内存管理的分配器, 使用 void 表示默认分配器

  3. typename Options = void

    由 boost::container::segtor_options 产生的类型.

segtor 公有成员函数

  1. segtor();

    效果: 默认构造一个 segtor.

    抛出: 若 allocator_type 的默认构造函数抛出异常.

    复杂度: 常数.

  2. explicit segtor(const allocator_type & a) noexcept;

    效果: 构造一个 segtor, 以分配器作为参数.

    抛出: 无

    复杂度: 常数.

  3. explicit segtor(size_type n);

    效果: 构造一个 segtor 并插入 n 个按值初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的值初始化抛出异常.

    复杂度: 与 n 成线性.

  4. segtor(size_type n, default_init_t);

    效果: 构造一个 segtor 并插入 n 个默认初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认初始化或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展

  5. explicit segtor(size_type n, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 segtor, 并插入 n 个按值初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的值初始化抛出异常.

    复杂度: 与 n 成线性.

  6. segtor(size_type n, default_init_t, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 segtor, 并插入 n 个默认初始化的值.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的默认初始化或复制构造函数抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展

  7. segtor(size_type n, const value_type & value);

    效果: 构造一个将使用分配器 a 的副本的 segtor, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  8. segtor(size_type n, const value_type & value, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 segtor, 并插入 value 的 n 个副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与 n 成线性.

  9. template<typename InIt> segtor(InIt first, InIt last);

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  10. template<typename InIt> 
  segtor(InIt first, InIt last, const allocator_type & a);

    效果: 构造一个将使用分配器 a 的副本的 segtor, 并插入范围 [first, last) 的副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 InIt 的构造函数抛出异常.

    复杂度: 与范围 [first, last) 成线性.

  11. segtor(std::initializer_list< value_type > il, 
       const allocator_type & a = allocator_type());

    效果: 构造一个将使用分配器 a 的副本的 segtor, 并插入范围 [il.begin(), il.end()) 的副本.

    抛出: 若 allocator_type 的默认构造函数抛出异常, 或 T 的接受解引用 std::initializer_list 迭代器的构造函数抛出异常.

    复杂度: 与范围 [il.begin(), il.end()) 成线性.

  12. segtor(const segtor & x);

    效果: 复制构造一个 segtor.

    后置条件: x == *this.

    复杂度: 与 x 包含的元素数成线性.

  13. segtor(segtor && x) noexcept;

    效果: 移动构造函数. 把 x 的资源移交给 *this.

    抛出: 若 allocator_type 的复制构造函数抛出异常.

    复杂度: 常数.

  14. segtor(const segtor & x, const allocator_type & a);

    效果: 使用指定的分配器复制构造一个 segtor.

    后置条件: x == *this.

    抛出: 若分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 x 包含的元素数成线性.

  15. segtor(segtor && x, const allocator_type & a);

    效果: 使用指定分配器的移动构造函数. 若 a == allocator_type(), 则把 x 的资源移交给 *this. 否则把 x 的值复制到 *this.

    抛出: 若分配或 T 的复制构造函数抛出异常.

    复杂度: 若 a == x.get_allocator() 则为常数, 否则为线性.

  16. ~segtor() noexcept;

    效果: 销毁 segtor. 所有存储的值被销毁, 已使用的内存被释放.

    抛出: 无.

    复杂度: 与元素数量成线性.

  17. segtor & operator=(const segtor & x);

    效果: 使 *this 包含与 x 相同的元素.

    后置条件: this->size() == x.size(). *this 包含 x 的每个元素的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 x 中元素数量成线性.

  18. segtor & operator=(segtor && x);

    效果: 移动赋值. x 的所有值被移交给 *this.

    抛出: 若 allocator_traits_type::propagate_on_container_move_assignment 为 false 且 (分配抛出异常或 value_type 的移动构造函数抛出异常)

    复杂度: 若 allocator_traits_type::propagate_on_container_move_assignment 为 true 或 this->get_allocator() == x.get_allocator() 则为常数, 否则为线性.

  19. segtor & operator=(std::initializer_list< value_type > il);

    效果: 使 *this 包含与 il 相同的元素.

    后置条件: this->size() == il.size(). *this 包含 il 的每个元素的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 与 il 中元素数量成线性.

  20. void reserve(size_type n);

    要求: 容器必须是 "reservable" (is_reservable == true)

    效果: 若 n 小于或等于 capacity() 或容器不可预留, 此调用无效果. 否则, 它是请求分配额外内存. 若请求成功, 则 capacity() 大于或等于 n; 否则 capacity() 不变. 无论哪种情况, size() 都不变.

    抛出: 若内存分配抛出异常.

    复杂度: 与 n 成线性.

    注释: 非标准扩展.

    复杂度: 与距离 [il.begin(), il.end()) 成线性.

  59. iterator erase(const_iterator p) noexcept;

    效果: 擦除 p 处的元素.

    抛出: 无.

    复杂度: 与 pos 和最后一个元素之间的元素数成线性 (若 pos 接近末尾), 或与第一个元素成线性 (若 pos 接近开头). 若 pos 是第一个或最后一个元素则为常数.

  60. iterator erase(const_iterator first, const_iterator last) noexcept;

    效果: 擦除 [first, last) 所指向的元素.

    抛出: 无.

    复杂度: 与 first 和 last 之间的距离加上 pos 与最后一个元素之间的元素数 (若 pos 接近末尾) 或与第一个元素之间的距离 (若 pos 接近开头) 成线性.

  61. void push_back(const value_type & x);

    效果: 在容器的末尾插入 x 的副本.

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    复杂度: 均摊常数时间.

  62. void push_back(value_type && x);

    效果: 在容器的末尾构造一个新元素, 并把 x 的资源移交给这个新元素.

    抛出: 若内存分配抛出异常.

    复杂度: 均摊常数时间.

  63. void pop_back() noexcept;

    效果: 从容器中移除最后一个元素.

    抛出: 无.

    复杂度: 常量时间.

  64. void resize(size_type new_size);

    效果: 在末尾插入或擦除元素, 使大小变为 n. 新元素按值初始化.

    抛出: 若内存分配抛出异常, 或 T 的构造函数抛出异常.

    复杂度: 与 size() 和 new_size 之差成线性.

  65. void resize(size_type new_size, default_init_t);

    效果: 在末尾插入或擦除元素, 使大小变为 n. 新元素按默认初始化.

    抛出: 若内存分配抛出异常, 或 T 的构造函数抛出异常.

    复杂度: 与 size() 和 new_size 之差成线性.

    注释: 非标准扩展

  66. void resize(size_type new_size, const value_type & x);

    效果: 在末尾插入或擦除元素, 使大小变为 n. 新元素从 x 复制构造.

    抛出: 若内存分配抛出异常, 或 T 的复制构造函数抛出异常.

    复杂度: 与 size() 和 new_size 之差成线性.

  67. void swap(segtor & x);

    效果: 交换 *this 与 x 的内容.

    抛出: 无.

    复杂度: 常数.

segtor 公有静态函数

  1. static size_type get_segment_size() noexcept;

    效果: 返回每段/每块的连续元素数量. 与 get_block_size() 相同.

    抛出: 无.

    复杂度: 常数.

  2. static size_type get_block_size() noexcept;

    效果: 返回每段/每块的连续元素数量. 与 get_segment_size() 相同.

    抛出: 无.

    复杂度: 常数.

segtor 友元函数

  1. bool operator==(const segtor & x, const segtor & y);

    效果: 若 x 与 y 相等则返回 true

    复杂度: 与容器中元素数量成线性.

  2. bool operator!=(const segtor & x, const segtor & y);

    效果: 若 x 与 y 不相等则返回 true

    复杂度: 与容器中元素数量成线性.

  3. bool operator<(const segtor & x, const segtor & y);

    效果: 若 x 小于 y 则返回 true

    复杂度: 与容器中元素数量成线性.

  4. bool operator>(const segtor & x, const segtor & y);

    效果: 若 x 大于 y 则返回 true

    复杂度: 与容器中元素数量成线性.

  5. bool operator<=(const segtor & x, const segtor & y);

    效果: 若 x 小于或等于 y 则返回 true

    复杂度: 与容器中元素数量成线性.

  6. bool operator>=(const segtor & x, const segtor & y);

    效果: 若 x 大于或等于 y 则返回 true

    复杂度: 与容器中元素数量成线性.

    效果: x.swap(y)

    复杂度: 常数.
