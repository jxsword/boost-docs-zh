类模板 static_vector

boost::container::static_vector — 具有固定容量的可变大小数组容器.

说明

static_vector 是一种类似 boost::container::vector 的序列容器, 具有可改变大小的连续存储, 同时具有 boost::array 的静态分配、低开销和固定容量.

static_vector 是一种支持随机访问元素、在末尾以常数时间插入和移除元素、在开头或中间以线性时间插入和移除元素的序列. 由于元素像数组一样存储在对象自身内部, static_vector 中的元素数量可以动态变化, 直到固定容量. 然而, 与必须在实例化时构造所有元素的 C 数组或 std::array 不同, 对象在插入 static_vector 时才被初始化. static_vector 的行为使得在具有复杂对象生命周期要求的情形下能够使用静态分配的元素, 否则这些情形无法轻易做到.

错误处理. 若 throw_on_overflow 选项为 true (默认行为), 超出容量的插入在启用异常时抛出 bad_alloc(), 未启用时调用 throw_bad_alloc(). 若 throw_on_overflow 选项为 false, 超出容量的插入导致未定义行为.

若在 at() 中执行越界访问, 启用异常时抛出 out_of_range, 未启用时调用 throw_out_of_range().

模板参数

  1. typename T

    将要存储的元素类型.

  2. std::size_t Capacity

    static_vector 可存储的最大元素数量, 在编译期固定.

  3. typename Options = void

    由 boost::container::static_vector_options 产生的类型. 若未指定选项, 默认设置 throw_on_overflow<true> 选项.
