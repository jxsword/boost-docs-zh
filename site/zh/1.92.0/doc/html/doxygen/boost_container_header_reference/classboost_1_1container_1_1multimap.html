说明

multimap 是一种支持等价键 (可能包含同一键值的多份副本) 的关联容器, 并支持基于键快速检索另一类型 T 的值. multimap 类支持双向迭代器.

multimap 满足容器、可逆容器和关联容器的全部要求. 此容器存储的 value_type 是 value_type, 即 std::pair<const Key, T>.

模板参数

  1. typename Key

    是映射的 key_type

  2. typename T
  3. typename Compare = std::less<Key>

    是键的排序函数 (例如 std::less<Key>).

  4. typename Allocator = new_allocator< std::pair< const Key, T> >

    是用于分配 value_type 的分配器 (例如 allocator< std::pair<const Key, T> > ).

  5. typename Options = tree_assoc_defaults

    是使用 boost::container::tree_assoc_options 生成的一种打包选项类型.

    效果/返回: 若 nh 为空, 则无效果并返回 end(). 否则, 插入 nh 拥有的元素并返回指向新插入元素的迭代器. 若存在包含键与 nh.key() 等价元素的范围, 则该元素插入到该范围的末尾. nh 总是被清空.

    复杂度: 对数

  57. iterator insert(const_iterator hint, node_type && nh);

    效果: 与 insert(node_type && nh) 相同, 但元素被插入到尽可能靠近 "hint" 之前的位置.

    复杂度: 一般为对数, 但若元素恰好插入 "hint" 之前则为均摊常数.

  58. iterator erase(const_iterator p);

    效果: 擦除 p 所指向的元素.

    返回: 返回指向在元素被擦除之前紧跟 q 的元素的迭代器. 若不存在这样的元素, 返回 end().

    复杂度: 均摊常数时间

  59. size_type erase(const key_type & x);

    效果: 若存在, 擦除容器中键与 x 等价的元素.

    返回: 返回被擦除元素的数量.

    复杂度: log(size()) + count(k)

  60. iterator erase(const_iterator first, const_iterator last);

    效果: 擦除范围 [first, last) 中的所有元素.

    返回: 返回 last.

    复杂度: log(size())+N, 其中 N 是 first 到 last 的距离.

  61. template<typename K> size_type erase(K && k);

    要求: 仅当 key_compare::is_transparent 存在时此重载才可用.

    效果: 若存在, 擦除容器中键与 x 等价的元素.

    返回: 返回被擦除元素的数量.

  62. node_type extract(const key_type & k);

    效果: 移除容器中第一个键与 k 等价的元素.

    返回: 若找到则为拥有该元素的 node_type, 否则为空的 node_type.

    复杂度: log(size()).

  63. template<typename K> node_type extract(K && k);

    返回: 拥有该元素的 node_type, 否则为空的 node_type.

  65. template<typename C2> 
  void merge(multimap< Key, T, C2, Allocator, Options > & source);

    要求: this->get_allocator() == source.get_allocator().

    效果: 提取 source 中的每个元素, 并使用 *this 的比较对象将其插入 a.

    后置条件: 指向 source 被转移元素的指针和引用仍指向那些相同的元素, 但作为 *this 的成员. 引用被转移元素的迭代器将继续指向其元素, 但现在表现为 *this 的迭代器, 而非 source 的迭代器.

    抛出: 除非比较对象抛出异常, 否则不抛出.

    复杂度: N log(size() + N) (N 的值为 source.size())

  1. bool operator==(const multimap & x, const multimap & y);

  2. bool operator!=(const multimap & x, const multimap & y);

    效果: 若 x 与 y 不相等则返回 true

    复杂度: 与容器中元素数量成线性.

    效果: 若 x 小于 y 则返回 true

    复杂度: 与容器中元素数量成线性.

    效果: 若 x 大于 y 则返回 true

    复杂度: 与容器中元素数量成线性.

  5. bool operator<=(const multimap & x, const multimap & y);

    效果: 若 x 小于或等于 y 则返回 true

    复杂度: 与容器中元素数量成线性.

  6. bool operator>=(const multimap & x, const multimap & y);

    效果: 若 x 大于或等于 y 则返回 true

    复杂度: 与容器中元素数量成线性.
