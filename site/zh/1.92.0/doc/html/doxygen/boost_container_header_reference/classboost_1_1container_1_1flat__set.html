说明

flat_set 是一种存储 Key 类型对象的排序关联容器 (Sorted Associative Container). 它还是唯一关联容器 (Unique Associative Container), 即没有两个元素是相同的.

flat_set 类似于 std::set, 但它实现为有序序列容器. 底层序列容器默认为 vector, 但也可以使用用户提供的类 vector 序列容器 (如 static_vector 或 small_vector).

使用类 vector 序列容器意味着向 flat_set 插入新元素可能使先前的迭代器和引用失效 (除非该序列容器是 stable_vector 或提供稳定指针和引用的类似容器). 同样, 擦除元素可能使指向被擦除元素之后 (键更大) 元素的迭代器和引用失效.

此容器提供随机访问迭代器.

模板参数

  1. typename Key

    是要插入集合 (set) 的类型, 同时也是 key_type

  2. typename Compare = std::less<Key>

    是用于对键排序的比较函数对象

  3. typename AllocatorOrContainer = new_allocator<Key>

    为以下二者之一:

    • 用于分配 value_type 的分配器 (例如 allocator< std::pair<Key, T> > ). (此时 sequence_type 将为 vector<value_type, AllocatorOrContainer>)

    • 用作底层 sequence_type 的 SequenceContainer. 它必须是具有随机访问迭代器的类 vector 序列容器.

  46. void reserve(size_type cnt);

    抛出: 若内存分配抛出异常或 T 的复制构造函数抛出异常.

    注释: 若 capacity() 小于 "cnt", 指向值的迭代器和引用可能失效.

    注释: 若插入了元素, 可能使元素失效.
