函数 throw_runtime_error

boost::container::throw_runtime_error

概要

// In header: <boost/container/throw_exception.hpp>


void throw_runtime_error(const char * str);

说明

Boost.Container 调用的异常回调, 用于报告只能在运行期检测到的错误.

  • 如果未定义 BOOST_NO_EXCEPTIONS 且未定义 BOOST_CONTAINER_USE_STD_EXCEPTIONS, 则抛出 boost::container::runtime_error(str).

  • 如果未定义 BOOST_NO_EXCEPTIONS 且定义了 BOOST_CONTAINER_USE_STD_EXCEPTIONS, 则抛出 std::runtime_error(str).

  • 如果定义了 BOOST_NO_EXCEPTIONS 且未定义 BOOST_CONTAINER_USER_DEFINED_THROW_CALLBACKS, 则调用 BOOST_ASSERT_MSG(!"boost::container runtime_error thrown", str), 若前者返回则调用 std::abort().

  • 如果同时定义了 BOOST_NO_EXCEPTIONS 和 BOOST_CONTAINER_USER_DEFINED_THROW_CALLBACKS, 用户必须提供实现, 且该函数不应返回.
