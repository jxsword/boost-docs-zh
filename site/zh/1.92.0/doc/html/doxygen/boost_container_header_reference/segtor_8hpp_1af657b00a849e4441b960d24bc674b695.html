函数模板 erase

boost::container::erase

概要

// In header: <boost/container/segtor.hpp>


template<typename T, typename A, typename O, typename U> 
  segtor< T, A, O >::size_type erase(segtor< T, A, O > & c, const U & v);

说明

效果: 从容器 c 中擦除所有与 v 比较相等的元素.

复杂度: 线性.
