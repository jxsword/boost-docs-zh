结构模板 stored_size

boost::container::stored_size

概要

// In header: <boost/container/options.hpp>

template<typename StoredSizeType> 
struct stored_size {
};

说明

该选项指定用户希望容器用来在内部保存大小相关信息 (如当前大小、当前容量) 的无符号整数类型.

如果所用最大 capacity() 有限, 用户可以尝试使用 8 位、16 位 (如 32 位机器上) 或 32 位大小类型 (如 64 位机器上) , 看看能否节省一些内存, 对空容器尤其如此. 这可能因更好的缓存利用而潜在地提升性能.

请注意, 对齐要求可能使理论上的空间节省无法实现. 示例: vector 包含一个指针和两个大小类型 (分别用于 size 和 capacity) ; 在 32 位机器上, 8 位大小类型 (总大小: 4 字节指针 + 2 x 1 字节大小 = 6 字节) 相比两个 16 位大小类型并不能节省空间, 因为 vector 通常要求 32 位对齐, 大小会被舍入到 8 字节. 在 64 位机器上, 16 位大小类型相比 32 位大小类型通常也节省不了内存. 请实测最终容器的大小, 不要想当然地认为更小的 stored_size 总能得到更小的 sizeof(container). 最终可能既得不到任何 sizeof 的缩减, 又严重限制了容器的最大大小.

如果用户试图插入的元素多于 stored_size 可表示的数量, 容器将抛出 length_error.

如果未指定该选项, 将使用 allocator_traits<A>::size_type (通常为 std::size_t) 在容器内部存储大小相关信息.

模板参数

  1. typename StoredSizeType

    无符号整数类型. 它必须小于 size_type (从 allocator_traits<A>::size_type 推导得出) 的大小, 或与之相同.
