类模板 hub

boost::container::hub

概要

// In header: <boost/container/hub.hpp>

template<typename T, typename Allocator = void> 
class hub {
public:
  // types
  typedef implementation_defined                                       allocator_type;          // new_allocator<T> is if Allocator is void, an alias for Allocator otherwise. 
  typedef T                                                            value_type;            
  typedef typename allocator_traits< allocator_type >::pointer         pointer;               
  typedef typename allocator_traits< allocator_type >::const_pointer   const_pointer;         
  typedef T &                                                          reference;             
  typedef const T &                                                    const_reference;       
  typedef typename allocator_traits< allocator_type >::size_type       size_type;             
  typedef typename allocator_traits< allocator_type >::difference_type difference_type;       
  typedef unspecified                                                  iterator;              
  typedef unspecified                                                  const_iterator;        
  typedef std::reverse_iterator< iterator >                            reverse_iterator;      
  typedef std::reverse_iterator< const_iterator >                      const_reverse_iterator;

  // public member functions
  hub();
  explicit hub(const allocator_type &) noexcept;
  explicit hub(size_type, const allocator_type & = allocator_type());
  hub(size_type, const T &, const allocator_type & = allocator_type());
  template<typename InputIterator> 
    hub(InputIterator, InputIterator, 
        const allocator_type & = allocator_type());
  template<std::ranges::input_range< T > R> 
    hub(from_range_t, R &&, const allocator_type & = allocator_type());
  hub(const hub &);
  hub(const hub &, const allocator_type &);
  hub(hub &&) noexcept;
  hub(hub &&, const allocator_type &);
  hub(std::initializer_list< T >, const allocator_type & = allocator_type());
  ~hub();
  hub & operator=(const hub &);
  hub & operator=(hub &&);
  hub & operator=(std::initializer_list< T >);
  template<typename InputIterator> void assign(InputIterator, InputIterator);
  template<std::ranges::input_range< T > R> void assign_range(R &&);
  void assign(size_type, const T &);
  void assign(std::initializer_list< T >);
  allocator_type get_allocator() const noexcept;
  iterator begin() noexcept;
  const_iterator begin() const noexcept;
  iterator end() noexcept;
  const_iterator end() const noexcept;
  reverse_iterator rbegin() noexcept;
  const_reverse_iterator rbegin() const noexcept;
  reverse_iterator rend() noexcept;
  const_reverse_iterator rend() const noexcept;
  const_iterator cbegin() const noexcept;
  const_iterator cend() const noexcept;
  const_reverse_iterator crbegin() const noexcept;
  const_reverse_iterator crend() const noexcept;
  bool empty() const noexcept;
  size_type size() const noexcept;
  size_type max_size() const noexcept;
  size_type capacity() const noexcept;
  void reserve(size_type);
  void shrink_to_fit();
  void trim_capacity() noexcept;
  void trim_capacity(size_type) noexcept;
  template<typename... Args> iterator emplace(Args &&...);
  template<typename... Args> iterator emplace_hint(const_iterator, Args &&...);
  iterator insert(const T &);
  iterator insert(const_iterator, const T &);
  iterator insert(T &&);
  iterator insert(const_iterator, T &&);
  void insert(std::initializer_list< T >);
  template<std::ranges::input_range< T > R> void insert_range(R &&);
  template<typename InputIterator> void insert(InputIterator, InputIterator);
  void insert(size_type, const T &);
  iterator erase(const_iterator);
  void erase_void(const_iterator);
  iterator erase(const_iterator, const_iterator);
  void swap(hub &);
  void clear() noexcept;
  void splice(hub &);
  void splice(hub &&);
  template<typename BinaryPredicate = std::equal_to<T> > 
    size_type unique(BinaryPredicate = BinaryPredicate());
  template<typename Compare = std::less<T> > void sort(Compare = Compare());
  iterator get_iterator(const_pointer);
  const_iterator get_iterator(const_pointer) const;
};

说明

hub 是一种支持常数时间插入和擦除以及元素稳定性的容器: 指向元素的指针和迭代器在元素被擦除之前保持有效. 它是 C++26 std::hive 的近乎直接替换且更紧凑的替代品.

hub 的元素存储在 块 (blocks) 中, 每块是具有固定元素容量的连续内存. 插入位置由容器选择, 容器可复用先前被擦除元素的内存. 至少含有一个元素的块称为 活跃 (active) 块; 内部保留以供将来复用的空块称为 保留 (reserved) 块. 保留块在所有活跃块都满之前不会被使用, 且只通过 shrink_to_fit、trim_capacity 或容器析构来释放. 只有当所有块都已满或用户执行 reserve 操作时才会分配新块.

hub<T, Allocator> 是 Container、ReversibleContainer、AllocatorAwareContainer 和 SequenceContainer 的一个模型, 但有以下例外: 不提供运算符 == 和 !=, 且形如 insert(position,\ ...) 或 emplace(position,\ ...) 的位置插入不被提供或忽略 position 实参. 其迭代器建模 LegacyBidirectionalIterator.

异常安全性: 除明确注明外, 所有非 const 成员函数 (以及以非 const 引用接受 hub 的自由函数) 提供基本异常保证, 而所有 const 成员函数 (以及以 const 引用接受 hub 的自由函数) 提供强保证.

模板参数

  1. typename T

    hub 中存储元素的 cv 未限定对象类型.

  2. typename Allocator = void

    value_type 为 T 的分配器. 若为 void (默认), 则使用 boost::container::new_allocator<T>.

hub 公有成员函数

  1. hub();

    效果: 构造一个空的 hub, 使用 allocator_type() 作为分配器.

    要求: allocator_type 可默认构造.

    复杂度: 常数.

  2. explicit hub(const allocator_type & al_) noexcept;

    效果: 使用指定的分配器构造一个空的 hub.

    复杂度: 常数.

  3. explicit hub(size_type n, const allocator_type & al_ = allocator_type());

    效果: 使用指定的分配器构造一个含 n 个默认插入元素的 hub.

    要求: T 可 DefaultInsertable 到 hub 中.

    复杂度: 与 n 成线性.

  4. hub(size_type n, const T & x, const allocator_type & al_ = allocator_type());

    效果: 使用指定的分配器构造一个含 value 的 n 个副本的 hub.

    要求: T 可 CopyInsertable 到 hub 中.

    复杂度: 与 n 成线性.

  5. template<typename InputIterator> 
  hub(InputIterator first, InputIterator last, 
      const allocator_type & al_ = allocator_type());

    效果: 使用指定的分配器构造一个等于范围 [first, last) 的 hub.

    复杂度: 与 std::distance(first, last) 成线性.

  6. template<std::ranges::input_range< T > R> 
  hub(from_range_t, R && rg, const allocator_type & al_ = allocator_type());

    效果: 使用指定的分配器构造一个等于范围 rg 的 hub.

    复杂度: 与 std::ranges::distance(rg) 成线性.

  7. hub(const hub & x);

    效果: 构造一个等于 x 的 hub. 第二个重载使用给定的分配器.

    要求: T 可 CopyInsertable 到 hub 中.

    复杂度: 与 x.size() 成线性.

  8. hub(const hub & x, const allocator_type & al_);

    效果: 使用给定的分配器构造一个等于 x 的 hub.

    要求: T 可 CopyInsertable 到 hub 中.

    复杂度: 与 x.size() 成线性.

  9. hub(hub && x) noexcept;

    效果: 移动构造函数. 元素块从 x 移入 *this; 指向 x 元素的指针、引用和迭代器保持有效, 但现在指向 *this.

    后置条件: x.empty() 为 true.

    复杂度: 常数.

  10. hub(hub && x, const allocator_type & al_);

    效果: allocator_type 扩展的移动构造函数. 若 alloc 等于 x.get_allocator(), 元素块被移动 (指向 x 的迭代器/指针作为 *this 的成员保持有效); 否则每个元素被移动到 *this, 且指向 x 的引用、指针和迭代器失效.

    要求: 当分配器可能不相等时, T 必须 MoveInsertable.

    后置条件: x.empty() 为 true.

    复杂度: 常数; 若元素被逐个移动, 则与 x.size() 成线性.

  11. hub(std::initializer_list< T > il, 
    const allocator_type & al_ = allocator_type());

    效果: 使用指定的分配器构造一个等于 il 的 hub.

    要求: T 可 CopyInsertable 到 hub 中.

    复杂度: 与 il.size() 成线性.

  12. ~hub();

    效果: 销毁所有元素并释放所有块.

    复杂度: 与 size() 加上块数成线性.

  13. hub & operator=(const hub & x);

    效果: 复制赋值. 现有元素被复制赋值或销毁, x 的元素被复制到 *this, 保持其相对顺序.

    要求: T 可 CopyInsertable 到 hub 中且可 CopyAssignable.

    复杂度: 与 size() + x.size() 成线性.

  14. hub & operator=(hub && x);

    效果: 移动赋值. 现有元素被移动赋值或销毁. 若分配器在移动赋值时传播或两个分配器相等, 元素块从 x 移动 (指向 x 的迭代器/指针作为 *this 的成员保持有效); 否则 x 的每个元素被移动到 *this, 且指向 x 的引用、指针和迭代器失效.

    要求: 当元素被逐个移动时, T 必须 MoveInsertable 且可 MoveAssignable.

    后置条件: x.empty() 为 true.

    复杂度: 与 size() 成线性; 若元素被逐个移动, 则与 x.size() 成线性.

  15. hub & operator=(std::initializer_list< T > il);

    效果: 用 il 的副本替换 *this 的内容.

    复杂度: 与 size() + il.size() 成线性.

  16. template<typename InputIterator> 
  void assign(InputIterator first, InputIterator last);

    效果: 用范围 [first, last) 的副本替换 *this 的内容.

    复杂度: 与 size() + std::distance(first, last) 成线性.

  17. template<std::ranges::input_range< T > R> void assign_range(R && rg);

    效果: 用范围 rg 中元素的副本替换 *this 的内容.

    复杂度: 与 size() + std::ranges::distance(rg) 成线性.

  18. void assign(size_type n, const T & x);

    效果: 用 x 的 n 个副本替换 *this 的内容.

    复杂度: 与 size() + n 成线性.

  19. void assign(std::initializer_list< T > il);

    效果: 用 il 的副本替换 *this 的内容.

    复杂度: 与 size() + il.size() 成线性.

  20. allocator_type get_allocator() const noexcept;

    效果: 返回与 *this 关联的分配器的副本.

    复杂度: 常数.

  21. iterator begin() noexcept;

    效果: 返回指向第一个元素的迭代器; 若为空则返回 end(). const 重载返回 const_iterator. 复杂度: 常数.

  22. const_iterator begin() const noexcept;
  23. iterator end() noexcept;

    效果: 返回尾后迭代器. end 迭代器是稳定的: 不会被插入或擦除失效. const 重载返回 const_iterator. 复杂度: 常数.

  24. const_iterator end() const noexcept;
  25. reverse_iterator rbegin() noexcept;

    效果: 反向和 const 迭代器访问器, 语义如常. 复杂度: 常数.

  26. const_reverse_iterator rbegin() const noexcept;
  27. reverse_iterator rend() noexcept;
  28. const_reverse_iterator rend() const noexcept;
  29. const_iterator cbegin() const noexcept;
  30. const_iterator cend() const noexcept;
  31. const_reverse_iterator crbegin() const noexcept;
  32. const_reverse_iterator crend() const noexcept;
  33. bool empty() const noexcept;

    效果: 若 hub 不包含任何元素则返回 true.

    复杂度: 常数.

  34. size_type size() const noexcept;

    效果: 返回 hub 中的元素数量.

    复杂度: 常数.

  35. size_type max_size() const noexcept;

    效果: 返回 hub 的最大可能大小.

    复杂度: 常数.

  36. size_type capacity() const noexcept;

    效果: 返回 *this 在无需分配更多元素块的情况下可容纳的元素总数.

    复杂度: 常数.

  37. void reserve(size_type n);

    效果: 若 n <= capacity() 则无效果; 否则通过分配保留块增加 capacity().

    后置条件: capacity() >= n.

    抛出: 若 n > max_size(), 以及分配器抛出的任何异常.

    复杂度: 与分配的保留块数成线性.

    注释: 所有引用、指针和迭代器 (包括尾后迭代器) 保持有效.

  38. void shrink_to_fit();

    效果: 需要时重新分配元素, 使活跃块数最小化, 并释放随之产生的保留块. 若 capacity() 已等于 size() 则无效果. 若 T 在重新分配期间抛出异常, 效果未指定.

    要求: T 可 MoveInsertable 到 hub 中.

    复杂度: 若发生重新分配则与 size() 成线性, 加上与保留块数成线性.

    注释: 若发生重新分配, 元素的顺序可能改变, 且指向元素的所有引用、指针和迭代器失效.

  39. void trim_capacity() noexcept;

    效果: 释放所有保留块, 相应减小 capacity().

    复杂度: 与释放的保留块数成线性.

    注释: 所有引用、指针和迭代器 (包括尾后迭代器) 保持有效.

  40. void trim_capacity(size_type n) noexcept;

    效果: 若 n >= capacity() 则无效果; 否则通过释放保留块把 capacity() 减小到不低于 n.

    复杂度: 与释放的保留块数成线性.

    注释: 所有引用、指针和迭代器 (包括尾后迭代器) 保持有效.

  41. template<typename... Args> iterator emplace(Args &&... args);

    效果: 在容器选择的位置插入一个用 std::forward<Args>(args)... 构造的 T 类型对象. 若抛出异常则无效果. args 可直接或间接引用 *this 中的值.

    要求: T 必须可从 args EmplaceConstructible 到 hub 中.

    返回: 指向新元素的迭代器.

    复杂度: 常数. 恰好构造一个 T 类型对象.

  42. template<typename... Args> 
  iterator emplace_hint(const_iterator, Args &&... args);

    效果: 等价于 emplace(std::forward<Args>(args)...); 提示被忽略.

    返回: 指向新元素的迭代器.

    复杂度: 常数.

  43. iterator insert(const T & x);

    效果: 在容器选择的位置插入 x 的副本 (或移动 x); 接受提示的重载忽略提示. 等价于 emplace(std::forward<decltype(x)>(x)).

    返回: 指向新元素的迭代器.

    复杂度: 常数.

  44. iterator insert(const_iterator, const T & x);
  45. iterator insert(T && x);
  46. iterator insert(const_iterator, T && x);
  47. void insert(std::initializer_list< T > il);

    效果: 插入 il 中元素的副本. 等价于 insert(il.begin(), il.end()).

    复杂度: 与 il.size() 成线性.

  48. template<std::ranges::input_range< T > R> void insert_range(R && rg);

    效果: 插入 rg 中元素的副本. rg 中的每个迭代器恰好被解引用一次.

    要求: T 必须可从 *ranges::begin(rg) EmplaceConstructible 到 hub 中, 且 rg 与 *this 不重叠.

    复杂度: 与插入的元素数成线性; 每个元素构造一个 T 类型对象.

  49. template<typename InputIterator> 
  void insert(InputIterator first, InputIterator last);

    效果: 插入 [first, last) 中元素的副本. 范围中的每个迭代器恰好被解引用一次.

    要求: T 必须可从 *first EmplaceConstructible 到 hub 中, 且 [first, last) 与 *this 不重叠.

    复杂度: 与插入的元素数成线性; 每个元素构造一个 T 类型对象.

  50. void insert(size_type n, const T & x);

    效果: 插入 x 的 n 个副本.

    要求: T 可 CopyInsertable 到 hub 中.

    复杂度: 与 n 成线性; 每个元素构造一个 T 类型对象.

  51. iterator erase(const_iterator pos);

    效果: 擦除 pos 所指向的元素.

    返回: 指向被擦除元素之后元素的迭代器.

    复杂度: 常数.

    注释: 使引用、指针和指向被擦除元素的迭代器失效.

  52. void erase_void(const_iterator pos);

    效果: 擦除 pos 所指向的元素. 等价于 erase(pos) 但不返回任何内容.

    复杂度: 常数.

    注释: 由于无需计算返回迭代器, 可能比 erase(pos) 更快. 使引用、指针和指向被擦除元素的迭代器失效.

  53. iterator erase(const_iterator first, const_iterator last);

    效果: 擦除范围 [first, last) 中的元素.

    返回: 指向最后一个被擦除元素之后元素的迭代器.

    复杂度: 与被擦除元素数成线性.

    注释: 使引用、指针和指向被擦除元素的迭代器失效.

  54. void swap(hub & x);

    效果: 交换 *this 与 x 的内容及 capacity().

    复杂度: 常数.

  55. void clear() noexcept;

    效果: 擦除所有元素. 保留块被保留.

    复杂度: 与 size() 成线性.

  56. void splice(hub & x);

    效果: 把 x 的内容插入 *this, 并使 x 变为空. 指向 x 被移动元素的指针和引用现在指向 *this; 迭代器继续指向其元素, 但表现为 *this 的迭代器. x 的保留块不会被转移.

    要求: get_allocator() == x.get_allocator() 且 std::addressof(x) != this.

    复杂度: 与 x 的块数加上 *this 的块数成线性.

  57. void splice(hub && x);
    效果: 等价于 splice(x).
  58. template<typename BinaryPredicate = std::equal_to<T> > 
  size_type unique(BinaryPredicate pred = BinaryPredicate());

    效果: 从每组连续等价元素中擦除除第一个元素外的所有元素, 即擦除 [begin() + 1, end()) 中每个满足 pred(*i, *(i - 1)) 为 true 的元素 i.

    要求: pred 是等价关系.

    返回: 被擦除元素的数量.

    抛出: 除非 pred 抛出异常, 否则不抛出.

    复杂度: 对于非空 hub 恰好应用 pred size() - 1 次, 否则不应用.

    注释: 使引用、指针和指向被擦除元素的迭代器失效.

  59. template<typename Compare = std::less<T> > void sort(Compare comp = Compare());

    效果: 按 comp 对 *this 排序. 若 comp 或对 T 的任何操作抛出异常, *this 处于有效但未指定的状态; 若在分配内部内存时抛出异常, 则无效果.

    要求: T 可 MoveInsertable 到 hub 中, 可 MoveConstructible、可 MoveAssignable 且可 Swappable.

    复杂度: O(N*log(N)) 次比较, 其中 N 为 size().

    注释: 可能分配内存. 指向元素的引用、指针和迭代器可能失效. 排序不稳定.

  60. iterator get_iterator(const_pointer p);

    效果: 返回引用与 p 相同元素的迭代器.

    要求: p 指向 *this 中的一个元素.

    抛出: 无.

    复杂度: 与 *this 中活跃块数成线性.

  61. const_iterator get_iterator(const_pointer p) const;

    效果: 返回引用与 p 相同元素的 const_iterator.

    要求: p 指向 *this 中的一个元素.

    抛出: 无.

    复杂度: 与 *this 中活跃块数成线性.
