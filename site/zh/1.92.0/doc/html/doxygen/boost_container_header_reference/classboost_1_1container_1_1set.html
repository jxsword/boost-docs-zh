说明

set 是一种支持唯一键 (每个键值最多包含一个) 的关联容器, 并支持快速检索键本身. set 类支持双向迭代器.

set 满足容器、可逆容器和关联容器的全部要求. set 还提供针对唯一键描述的大多数操作.

模板参数

  1. typename Key

    是要插入集合 (set) 的类型, 同时也是 key_type

  2. typename Compare = std::less<Key>

    是用于对键排序的比较函数对象

  3. typename Allocator = new_allocator<Key>

    是用于为此容器分配内存的分配器

  4. typename Options = void

    是使用 boost::container::tree_assoc_options 生成的一种打包选项类型.

    抛出: 除非比较对象抛出异常, 否则不抛出.

    复杂度: N log(size() + N) (N 的值为 source.size())
