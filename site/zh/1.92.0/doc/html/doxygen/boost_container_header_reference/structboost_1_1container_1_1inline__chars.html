结构体模板 inline_chars

boost::container::inline_chars

概要

// In header: <boost/container/options.hpp>

template<std::size_t InlineChars> 
struct inline_chars {
};

说明

此选项指定希望在容器中内联保存的字符数量.

值零表示默认值 (在 32 位系统上通常为 10 个字符, 在 64 位系统上为 22 个字符).

模板参数

  1. std::size_t InlineChars

    无符号整数值. 由于内部数据结构设计, 不支持大于 127 的值.
