函数模板 vector

boost::container::vector

概要

// In header: <boost/container/vector.hpp>


template<typename InputIterator, typename Allocator> 
   vector(InputIterator, InputIterator, Allocator const &);

说明

推导指引: 允许 vector 从迭代器范围 [first, last) 构造, 从 InputIterator 的值类型推导元素类型并从所提供的分配器取得分配器类型.
