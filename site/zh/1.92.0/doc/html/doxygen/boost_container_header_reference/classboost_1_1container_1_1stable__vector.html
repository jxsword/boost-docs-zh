说明

stable_vector 由 Joaquin M. Lopez Munoz 最初开发, 是以节点容器实现的 std::vector 直接替代品, 提供迭代器和引用稳定性.

以下是取自作者博客 (Introducing stable_vector) 的细节:

我们给出 stable_vector, 一种完全符合 STL 的稳定容器, 提供除元素连续性之外的 std::vector 大多数特性.

一般性质: stable_vector 满足容器、可逆容器和序列的全部要求, 并提供 std::vector 中存在的所有可选操作. 与 std::vector 一样, 迭代器是随机访问的. stable_vector 不提供元素连续性; 作为交换, 容器是稳定的, 即只要元素未被擦除, 指向 stable_vector 元素的引用和迭代器就保持有效, 且被赋以 end() 返回值的迭代器始终有效, 直到相关联的 stable_vector 被销毁.

操作复杂度: stable_vector 操作的 big-O 复杂度与 std::vector 完全一致. 一般而言, 在序列末尾插入/删除是常数时间, 其他位置为线性. 与 std::vector 不同, stable_vector 内部不执行任何与插入新元素或删除已存元素不完全对应的 value_type 析构、复制或赋值操作, 这有时可以在性能上补偿每元素多做指针操作和一次额外分配的额外负担.

异常安全性: 由于 stable_vector 内部不会到处复制元素, 某些操作提供比 std::vector 更强的异常安全保证.

模板参数

  1. typename T

    存储在 stable_vector 中的对象类型

  2. typename Allocator = void

    用于所有内部内存管理的分配器
