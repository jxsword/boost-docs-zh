结构体模板 growth_factor

boost::container::growth_factor

概要

// In header: <boost/container/options.hpp>

template<typename GrowthFactor> 
struct growth_factor {
};

说明

此选项设置器指定底层 vector 的增长因子策略.

GrowthFactor 函数对象必须提供以下接口:

template<class SizeType>
SizeType operator()(SizeType cur_cap, SizeType add_min_cap, SizeType max_cap) const;

其中:

  • cur_cap 是当前容量

  • add_min_cap 是我们希望达到的最小额外容量

  • max_cap 是分配器或其他因素允许的最大容量.

实现应返回 cur_cap + add_min_cap 与 max_cap 之间的值. 实现应处理增长因子产生的潜在回绕, 并始终以正确的值成功返回.

可作为此选项实参传递的预定义增长因子有: boost::container::growth_factor_50、boost::container::growth_factor_60 和 boost::container::growth_factor_100

若未指定此选项, 容器将使用默认值.

模板参数

  1. typename GrowthFactor

    实现增长因子的函数对象
