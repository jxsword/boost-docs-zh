类型定义 string_options_t

string_options_t

概要

// In header: <boost/container/options.hpp>


template<class ... Options> 
using string_options_t = typename boost::container::string_options< Options... >::type;

说明

辅助别名元函数, 把各选项组合成单一类型, 供 boost::container::string 使用.
