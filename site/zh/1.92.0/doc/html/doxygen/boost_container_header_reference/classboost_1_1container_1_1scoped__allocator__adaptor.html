boost::container::scoped_allocator_adaptor

class scoped_allocator_adaptor :
  public dtl::scoped_allocator_adaptor_base< OuterAlloc, InnerAllocs... >

说明

此类是 std::scoped_allocator_adaptor 的 C++03 兼容实现. 类模板 scoped_allocator_adaptor 是一种分配器模板, 它指定容器要使用的内存资源 (外层分配器, 如同其他分配器一样), 并指定要传递给容器内每个元素构造函数的内层分配器资源.

此适配器以一个外层分配器类型和零个或多个内层分配器类型实例化. 若只以一个分配器类型实例化, 则内层分配器成为 scoped_allocator_adaptor 本身, 从而对容器及容器内每个元素使用相同的分配器资源, 若元素本身也是容器, 则对其元素递归如此. 若以多于一个分配器实例化, 第一个分配器是容器使用的外层分配器, 第二个分配器被传递给容器元素的构造函数, 若元素本身也是容器, 第三个分配器被传递给元素的元素, 依此类推. 若容器嵌套的深度大于分配器的数量, 则对于任何剩余的递归, 最后一个分配器被重复使用, 如同单分配器的情形.

[注释: scoped_allocator_adaptor 派生自外层分配器类型, 因此在大多数表达式中可替代外层分配器类型. -end note]

在 construct 成员函数中, OUTERMOST(x) 为 x, 若 x 没有 outer_allocator() 成员函数; 否则为 OUTERMOST(x.outer_allocator()); OUTERMOST_ALLOC_TRAITS(x) 为 allocator_traits<decltype(OUTERMOST(x))>.

[注释: OUTERMOST(x) 和 OUTERMOST_ALLOC_TRAITS(x) 是递归操作. outer_allocator() 的定义有责任确保递归终止. 对 scoped_allocator_adaptor 的所有实例化它都会终止. -end note]

scoped_allocator_adaptor 公有类型

  1. typedef allocator_traits< OuterAlloc > outer_traits_type;

    类型: 仅用于 exposition

  2. typedef base_type::inner_allocator_type inner_allocator_type;

    类型: scoped_allocator_adaptor<OuterAlloc>, 若 sizeof...(InnerAllocs) 为零; 否则为 scoped_allocator_adaptor<InnerAllocs...>.

  3. typedef base_type::is_always_equal is_always_equal;

    类型: 一种具有常量布尔 value == true 的类型, 若 allocator_traits<Allocator>:: propagate_on_container_copy_assignment::value 对任意 Allocator (属于集合 OuterAlloc 和 InnerAllocs...) 均非 true, 否则为 false. typedef typename base_type:: propagate_on_container_copy_assignment propagate_on_container_copy_assignment; ! 类型: 一种具有常量布尔 value == true 的类型, 若 !allocator_traits<Allocator>:: propagate_on_container_move_assignment::value 对任意 Allocator (属于集合 OuterAlloc 和 InnerAllocs...) 均非 true, 否则为 false. typedef typename base_type:: propagate_on_container_move_assignment propagate_on_container_move_assignment;

    ! 类型: 一种具有常量布尔 value == true 的类型, 若 ! allocator_traits<Allocator>:: propagate_on_container_swap::value 对任意 Allocator (属于集合 OuterAlloc 和 InnerAllocs...) 均非 true, 否则为 false. typedef typename base_type:: propagate_on_container_swap propagate_on_container_swap;

    ! 类型: 一种具有常量布尔 value == true 的类型, 若 !allocator_traits<Allocator>:: is_always_equal::value 对 Allocator (属于集合 OuterAlloc 和 InnerAllocs...) 中的所有值均为 true, 否则为 false.

scoped_allocator_adaptor 公有成员函数

  1. scoped_allocator_adaptor();

    效果: 对 OuterAlloc 基类和内层分配器对象进行值初始化.

  2. ~scoped_allocator_adaptor();
  3. scoped_allocator_adaptor(const scoped_allocator_adaptor & other);

    效果: 用 other 中相应的分配器初始化适配器内的每个分配器.

  4. scoped_allocator_adaptor(scoped_allocator_adaptor && other);

    效果: 用 other 中相应的分配器移动构造适配器内的每个分配器.

  5. template<typename OuterA2> 
  scoped_allocator_adaptor(OuterA2 && outerAlloc, 
                           const InnerAllocs &... innerAllocs);

    要求: OuterAlloc 必须可从 OuterA2 构造.

    效果: 用 boost::forward<OuterA2>(outerAlloc) 初始化 OuterAlloc 基类, 用 innerAllocs... 初始化内层 (从而用实参列表中相应的分配器递归初始化适配器内的每个分配器).

  6. template<typename OuterA2> 
  scoped_allocator_adaptor(const scoped_allocator_adaptor< OuterA2, InnerAllocs... > & other);

    要求: OuterAlloc 必须可从 OuterA2 构造.

    效果: 用 other 中相应的分配器初始化适配器内的每个分配器.

  7. template<typename OuterA2> 
  scoped_allocator_adaptor(scoped_allocator_adaptor< OuterA2, InnerAllocs... > && other);

    要求: OuterAlloc 必须可从 OuterA2 构造.

    效果: 用 other 中相应的分配器右值初始化适配器内的每个分配器.

  8. scoped_allocator_adaptor & operator=(const scoped_allocator_adaptor & other);
  9. scoped_allocator_adaptor & operator=(scoped_allocator_adaptor && other);
  10. void swap(scoped_allocator_adaptor & r);

    效果: 交换 *this 与 r.

  11. outer_allocator_type & outer_allocator() noexcept;

    返回: static_cast<OuterAlloc&>(*this).

  12. const outer_allocator_type & outer_allocator() const noexcept;

    返回: static_cast<const OuterAlloc&>(*this).

  13. inner_allocator_type & inner_allocator() noexcept;

    返回: 若 sizeof...(InnerAllocs) 为零则为 *this; 否则为 inner.

  14. inner_allocator_type const & inner_allocator() const noexcept;

    返回: 若 sizeof...(InnerAllocs) 为零则为 *this; 否则为 inner.

  15. size_type max_size() const noexcept;

    返回: allocator_traits<OuterAlloc>:: max_size(outer_allocator()).

  16. template<typename T> void destroy(T * p) noexcept;

    效果: 调用 OUTERMOST_ALLOC_TRAITS(*this):: destroy(OUTERMOST(*this), p).

  17. pointer allocate(size_type n);

    返回: allocator_traits<OuterAlloc>::allocate(outer_allocator(), n).

  18. pointer allocate(size_type n, const_void_pointer hint);

    返回: allocator_traits<OuterAlloc>::allocate(outer_allocator(), n, hint).

  19. void deallocate(pointer p, size_type n);

    效果: allocator_traits<OuterAlloc>::deallocate(outer_allocator(), p, n).

  20. scoped_allocator_adaptor select_on_container_copy_construction() const;

    返回: 一个新的 scoped_allocator_adaptor 对象, 其中适配器内的每个分配器 Allocator 都从对 *this 中相应分配器调用 allocator_traits<Allocator>::select_on_container_copy_construction() 的结果初始化.

  21. template<typename T, class ... Args> void construct(T * p, Args &&... args);

    效果: 1) 若 uses_allocator<T, inner_allocator_type>::value 为 false 则调用 OUTERMOST_ALLOC_TRAITS(*this):: construct(OUTERMOST(*this), p, std::forward<Args>(args)...).

    2) 否则, 若 uses_allocator<T, inner_allocator_type>::value 为 true 且 is_constructible<T, allocator_arg_t, inner_allocator_type, Args...>:: value 为 true, 则调用 OUTERMOST_ALLOC_TRAITS(*this):: construct(OUTERMOST(*this), p, allocator_arg, inner_allocator(), std::forward<Args>(args)...).

    3) 否则, 若 uses_allocator<T, inner_allocator_type>::value 为 true 且 is_constructible<T, Args..., inner_allocator_type>:: value 为 true, 则调用 OUTERMOST_ALLOC_TRAITS(*this):: construct(OUTERMOST(*this), p, std::forward<Args>(args)..., inner_allocator()).

    [注释: 在不支持高级 decltype SFINAE 的编译器上, is_constructible 无法实现, 因此该条件将替换为 constructible_with_allocator_suffix<T>:: value. -end note]

    4) 否则, 程序非良构.

    [注释: 若 uses_allocator 求值为 true 但特定构造函数不接受分配器, 将产生错误. 此定义防止把内层分配器传递给所包含元素时静默失败. -end note]

scoped_allocator_adaptor 友元函数
