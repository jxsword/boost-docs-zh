结构 relocate_on_66

boost::container::relocate_on_66

概要

// In header: <boost/container/options.hpp>


struct relocate_on_66 {
};

说明

该重定位条件选项指定: 当插入应发生的一侧没有空间且内存使用率低于 66% (2/3) 时, 容器将重定位所有元素
