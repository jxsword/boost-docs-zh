类 monotonic_buffer_resource

boost::container::pmr::monotonic_buffer_resource

概要

// In header: <boost/container/pmr/monotonic_buffer_resource.hpp>


class monotonic_buffer_resource :
  public boost::container::pmr::memory_resource
{
public:

  // public member functions
  explicit monotonic_buffer_resource(memory_resource * = 0) noexcept;
  explicit monotonic_buffer_resource(std::size_t, memory_resource * = 0) noexcept;
  monotonic_buffer_resource(void *, std::size_t, memory_resource * = 0) noexcept;
  monotonic_buffer_resource(const monotonic_buffer_resource &) = delete;
  monotonic_buffer_resource 
  operator=(const monotonic_buffer_resource &) = delete;
  ~monotonic_buffer_resource();
  void release() noexcept;
  memory_resource * upstream_resource() const noexcept;
  std::size_t remaining_storage(std::size_t, std::size_t &) const noexcept;
  std::size_t remaining_storage(std::size_t = 1u) const noexcept;
  const void * current_buffer() const noexcept;
  std::size_t next_buffer_size() const noexcept;

  virtual bool do_is_equal(const memory_resource &) const noexcept;

  // public data members
  BOOST_STATIC_CONSTEXPR std::size_t initial_next_buffer_size;
};

说明

monotonic_buffer_resource 是一种专用内存资源, 用于在以下场景中实现极快的内存分配: 内存用于构建少量对象, 然后在内存资源对象被销毁时一次性全部释放. 它具有以下性质:

  • 对 deallocate 的调用无效果, 因此消耗的内存单调增长, 直到资源被销毁.

  • 程序可以提供一个初始缓冲区, 分配器用它来满足内存请求.

  • 当初始缓冲区 (如有) 耗尽时, 它从构造时提供的上游内存资源获取额外的缓冲区. 每个额外缓冲区都比前一个大, 呈几何级数增长.

  • 它设计为一次只由一个控制线程访问. 具体而言, 对 allocate 和 deallocate 的调用彼此不同步.

  • 它拥有已分配的内存并在销毁时释放, 即使某些已分配块尚未调用 deallocate.

monotonic_buffer_resource 公有成员函数

  1. explicit monotonic_buffer_resource(memory_resource * upstream = 0) noexcept;

    要求: upstream 应是有效内存资源的地址或 nullptr

    效果: 若 upstream 不是 nullptr, 则把内部资源设置为 upstream, 否则设置为 get_default_resource(). 把内部 current_buffer 设置为 nullptr, 并把内部 next_buffer_size 设置为实现定义的大小.

  2. explicit monotonic_buffer_resource(std::size_t initial_size, 
                                   memory_resource * upstream = 0) noexcept;

    要求: upstream 应是有效内存资源的地址或 nullptr, 且 initial_size 应大于零.

    效果: 若 upstream 不是 nullptr, 则把内部资源设置为 upstream, 否则设置为 get_default_resource(). 把内部 current_buffer 设置为 nullptr, 并把 next_buffer_size 设置为至少 initial_size.

  3. monotonic_buffer_resource(void * buffer, std::size_t buffer_size, 
                          memory_resource * upstream = 0) noexcept;

    要求: upstream 应是有效内存资源的地址或 nullptr, buffer_size 应不大于 buffer 的字节数.

    效果: 若 upstream 不是 nullptr, 则把内部资源设置为 upstream, 否则设置为 get_default_resource(). 把内部 current_buffer 设置为 buffer, 并把 next_buffer_size 设置为 buffer_size (但不小于实现定义的大小), 然后按实现定义的增长因子 (不必是整数) 增加 next_buffer_size.

  4. monotonic_buffer_resource(const monotonic_buffer_resource &) = delete;
  5. monotonic_buffer_resource 
operator=(const monotonic_buffer_resource &) = delete;
  6. ~monotonic_buffer_resource();

    效果: 调用 this->release().

  7. void release() noexcept;

    效果: 必要时调用 upstream_resource()->deallocate() 以释放所有已分配的内存. 把 *this 重置为构造时的初始状态. [Note: 即使从此处分配的某些块尚未从此处释放, 内存也会释放回 upstream_resource(). - end note]

  8. memory_resource * upstream_resource() const noexcept;

    返回: 内部资源的值.

  9. std::size_t remaining_storage(std::size_t alignment, 
                              std::size_t & wasted_due_to_alignment) const noexcept;

    返回: 指定对齐可用的存储字节数, 以及因请求对齐而浪费的字节数.

    注释: 非标准扩展.

  10. std::size_t remaining_storage(std::size_t alignment = 1u) const noexcept;

    返回: 指定对齐可用的存储字节数.

    注释: 非标准扩展.

  11. const void * current_buffer() const noexcept;

    返回: 指向当前空闲存储起始处的地址.

    注释: 非标准扩展.

  12. std::size_t next_buffer_size() const noexcept;

    返回: 当前缓冲区耗尽后为下一个缓冲区将请求的字节数.

    注释: 非标准扩展.

monotonic_buffer_resource 受保护成员函数

  1. virtual void * do_allocate(std::size_t bytes, std::size_t alignment);

    返回: 指向大小至少为 bytes 的已分配存储的指针. 所分配内存的大小和对齐应满足从 memory_resource 派生的类的要求.

    效果: 若内部 current_buffer 中的未用空间能容纳具有指定 bytes 和对齐的块, 则从内部 current_buffer 分配返回块; 否则把内部 current_buffer 设置为 upstream_resource()->allocate(n, m), 其中 n 不小于 max(bytes, next_buffer_size) 且 m 不小于对齐, 并按实现定义的增长因子 (不必是整数) 增加 next_buffer_size, 然后从新分配的内部 current_buffer 分配返回块.

    抛出: 除非 upstream_resource()->allocate() 抛出异常, 否则不抛出.

  2. virtual void 
do_deallocate(void * p, std::size_t bytes, std::size_t alignment) noexcept;

    效果: 无

    抛出: 无

    备注: 此资源使用的内存单调增长, 直到其销毁.

  3. virtual bool do_is_equal(const memory_resource & other) const noexcept;

    返回: this == dynamic_cast<const monotonic_buffer_resource*>(&other).

monotonic_buffer_resource 公有数据成员

  1. BOOST_STATIC_CONSTEXPR std::size_t initial_next_buffer_size;

    首次调用上游分配器时默认将请求的字节数

    注释: 非标准扩展.
