结构模板 uses_allocator

boost::container::uses_allocator

概要

// In header: <boost/container/uses_allocator.hpp>

template<typename T, typename AllocArg> 
struct uses_allocator {
};

说明

备注: 自动检测 T 是否具有嵌套的 allocator_type, 该嵌套成员可从 AllocArg 转换而来. 满足 BinaryTypeTrait 要求 ([meta.rqmts] 20.4.1). 该特征用于指示类型 T 是否支持 uses-allocator 构造.

uses-allocator 构造 协议指定了三种约定, 用于把分配器实参 alloc_arg (类型为 AllocArg) 在任意数量实参 (在本说明中记为 args...) 之外传递给某类型 T 的构造函数:

  • 如果 T 不使用兼容的分配器 (uses_allocator<T, AllocArg>::value 为 false), 则忽略 alloc_arg, 并将 T 构造为 T(args...)

  • 否则, 如果 uses_allocator<T, AllocArg>::value 为 true 且 T 可构造为 T(std::allocator_arg, alloc_arg, args...), 则 uses-allocator 构造采用此形式.

  • 否则, 如果 T 可构造为 T(args..., alloc_arg), 则 uses-allocator 构造采用此形式.

  • 否则, 作为 Boost.Container 提供的非标准扩展, 忽略 alloc_arg 并调用 T(args...). (注意: 提供此扩展是为了增强向后兼容性, 针对那些未考虑 uses-allocator 构造而创建、声明了 allocator_type 类型但未准备好接受额外分配器实参的类型)

结果: uses_allocator<T, AllocArg>::value == true, 若类型 T::allocator_type 存在, 且 is_convertible<AllocArg, T::allocator_type>::value == true 或 T::allocator_type 是 erased_type 的别名. 否则为 False.

注释: 程序可特化此类型, 把 uses_allocator<X>::value 定义为 true, 针对用户定义类型的 T, 若 T 没有嵌套的 allocator_type, 但仍可用指定的 AllocArg 进行构造, 且满足以下任一情况: 构造函数的第一个实参类型为 allocator_arg_t 且第二个实参类型为 AllocArg, 或者构造函数的最后一个实参类型为 AllocArg.
