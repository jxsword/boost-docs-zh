结构模板 tree_assoc_options

boost::container::tree_assoc_options

概要

// In header: <boost/container/options.hpp>

template<class ... Options> 
struct tree_assoc_options {
  // types
  typedef implementation_defined type;
};

说明

辅助元函数, 用于把多个选项组合成单个类型, 供 boost::container::set, boost::container::multiset boost::container::map 和 boost::container::multimap 使用. 受支持的选项为: boost::container::optimize_size 和 boost::container::tree_type
