说明

basic_string 类表示一个字符序列 (Sequence). 它包含序列的全部常规操作, 此外还包含搜索和拼接等标准字符串操作.

basic_string 类由字符类型以及该类型的字符特征 (Character Traits) 参数化.

此类的性能特征与 vector<> 非常相似, 例如, 它不执行引用计数或写时复制, 并且两个字符串的拼接是 O(N) 操作.

basic_string 的某些成员函数使用一种不寻常的位置和范围指定方法. 除了使用迭代器的常规方法外, basic_string 的许多成员函数使用单个 size_type 类型的值 pos 表示位置 (此时该位置为 begin() + pos), 并且 basic_string 的许多成员函数使用 pos 和 n 两个值表示范围. 此时 pos 是范围的开头, n 是其大小. 即该范围是 [begin() + pos, begin() + pos + n).

注意, C++ 标准并未规定 basic_string 操作的复杂度. 在本实现中, basic_string 的性能特征与 vector 非常相似: 访问单个字符是 O(1), 而复制和拼接是 O(N).

在本实现中, begin()、end()、rbegin()、rend()、operator[]、c_str() 和 data() 不会使迭代器失效. 在本实现中, 迭代器只会被显式更改字符串内容的成员函数所失效.

模板参数

  1. typename CharT

    其包含的字符类型.

  2. typename Traits = std::char_traits<CharT>

    字符特征 (Character Traits) 类型, 封装基本的字符操作

  3. typename Allocator = void

    分配器, 用于内部内存管理.

  4. typename Options = void

    由 boost::container::string_options 产生的类型.
