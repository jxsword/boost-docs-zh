函数 set_default_resource

boost::container::pmr::set_default_resource

概要

// In header: <boost/container/pmr/global_resource.hpp>


memory_resource * set_default_resource(memory_resource * r);

说明

效果: 若 r 非空, 则把默认内存资源指针的值设置为 r, 否则把默认内存资源指针设置为 new_delete_resource().

后置条件: get_default_resource() == r.

返回: 默认内存资源指针的先前值.

备注: 调用 set_default_resource 和 get_default_resource 函数不应产生数据竞争. 对 set_default_resource 函数的调用应与后续对 set_default_resource 和 get_default_resource 函数的调用同步.
