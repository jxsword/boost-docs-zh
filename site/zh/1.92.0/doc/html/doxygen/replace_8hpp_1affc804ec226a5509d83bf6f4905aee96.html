函数模板 replace_last_copy

boost::replace_last_copy — 替换最后一个算法.

概要

// In header: <boost/algorithm/string/replace.hpp>


template<typename OutputIteratorT, typename Range1T, typename Range2T, 
         typename Range3T> 
  OutputIteratorT 
  replace_last_copy(OutputIteratorT Output, const Range1T & Input, 
                    const Range2T & Search, const Range3T & Format);

说明

用格式字符串替换输入中查找字符串的最后一个匹配. 结果是输入的一个修改后的副本. 它以序列形式返回, 或复制到输出迭代器.

注释

此函数的第二个变体提供强异常安全保证

参数:

Output

结果将被复制到的输出迭代器

Input

输入字符串

Search

要搜索的子串

Format

替换字符串

返回:

指向最后插入字符之后位置的输出迭代器, 或输入的修改后副本
