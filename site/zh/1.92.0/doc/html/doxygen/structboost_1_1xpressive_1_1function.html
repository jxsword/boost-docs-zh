结构体模板 function

boost::xpressive::function — 一元元函数, 把普通函数对象类型转换为延迟函数对象的类型, 供 xpressive 语义动作使用.

概要

// In header: <boost/xpressive/regex_actions.hpp>

template<typename PolymorphicFunctionObject> 
struct function {
  // types
  typedef proto::terminal< PolymorphicFunctionObject >::type type;
};

说明

使用 xpressive::function<> 把普通的多态函数对象类型转换为一种类型, 该类型可用于声明对象, 以便在 xpressive 语义动作中使用.

例如, 全局对象 xpressive::push_back 可用于创建把值压入容器的延迟动作. 它用 xpressive::function<> 定义如下:

xpressive::function<xpressive::op::push_back>::type const push_back = {};

其中 op::push_back 是把第二个实参压入第一个实参的普通函数对象. 如此定义后, xpressive::push_back 可在语义动作中如下使用:

namespace xp = boost::xpressive;
using xp::_;
std::list<int> result;
std::string str("1 23 456 7890");
xp::sregex rx = (+_d)[ xp::push_back(xp::ref(result), xp::as<int>(_) ]
    >> *(' ' >> (+_d)[ xp::push_back(xp::ref(result), xp::as<int>(_) ) ]);
