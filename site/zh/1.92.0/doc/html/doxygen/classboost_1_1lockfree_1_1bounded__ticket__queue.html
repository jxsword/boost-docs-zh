说明

基于 Dmitry Vyukov 的有界 MPMC 队列 (即 "Vyukov turnstile" 转闸) 的有界票据队列 (reference).

该队列使用固定大小的单元环形缓冲区, 每个单元由单调递增的票据 (序号) 保护. 生产者与消费者仅通过推进该票据来协调.

该数据结构是可线性化的.

注意事项.

  • 多生产者 push 不是无锁的. 通过 CAS 认领了一个槽位但随后被挂起的并发生产者, 一旦环形缓冲区回绕到该槽位, 就可能阻塞所有其他生产者. 实际上抢占时间很短, 但硬实时系统应优先采用单生产者配置.

  • 多消费者 pop 不是无锁的. 存在与多生产者 push 对称的停滞风险. 硬实时场景请优先使用 single_consumer<true>.

  • 不公平性. 基于 CAS 的槽位预留不提供任何 FIFO 或公平性保证.

策略.

  • boost::lockfree::capacity (可选):
    在编译期设置队列容量. 意味着使用静态存储缓冲区, 且不允许指定分配器.

  • boost::lockfree::allocator (默认 std::allocator<void>).
    用于单元存储的分配器. 仅在运行期指定容量时有效.

  • boost::lockfree::single_producer (默认 false):
    若为 true, 只有一个线程调用 push. push 变为无等待.

  • boost::lockfree::single_consumer (默认 false):
    若为 true, 只有一个线程调用 pop. pop 变为无等待.

要求.

  • T 必须可复制构造或可移动构造, 取决于使用哪个 push 重载.

  • T 必须可移动构造且可移动赋值.

bounded_ticket_queue 公有成员函数

  1. bool is_lock_free() const;

    在单生产者与单消费者模式下队列是无等待的 (不使用 CAS). 对于多消费者或多生产者配置, 只检查使用 CAS 的原子位置.

    返回:

    若实现是无锁的则为 true.

    		 
  2. bounded_ticket_queue();

    构造具有编译期容量的队列.

    存储在静态缓冲区中分配; 不执行堆分配.

    要求:

    必须指定 capacity<> 实参 >= 2.

    		 
  3. template<typename Enabler = std::enable_if< !has_capacity > > 
  explicit bounded_ticket_queue(size_type n);

    构造具有运行期容量的队列.

    参数:

    n

    队列容量. 必须 >= 2. 不要求为 2 的幂, 但 2 的幂大小会使用快速掩码路径.

    要求:

    必须 不得 指定 capacity<> 实参.

    		 
  4. template<typename Enabler = std::enable_if< !has_capacity > > 
  bounded_ticket_queue(size_type n, allocator const & alloc);

    构造具有运行期容量和自定义分配器的队列.

    参数:

    n

    队列容量. 必须 >= 2.

    alloc

    用于单元存储的分配器. 其 value_type 被重绑定为 cell.

    要求:

    必须 不得 指定 capacity<> 实参.

    		 
  5. bounded_ticket_queue(const bounded_ticket_queue &) = delete;
  6. bounded_ticket_queue & operator=(const bounded_ticket_queue &) = delete;

  10. bool empty() const;

    检查队列是否为空.

    注释

    返回:

    若队列为空则为 true, 否则为 false.

    		 
  11. size_type capacity() const;

    返回:

    队列的容量.

    		 
  12. bool push(const T & t);

    把一个值推入队列.

    注释

    线程安全. 多个生产者可以并发调用 push. 从不分配内存.

    返回:

    若值被推入则为 true, 若队列已满则为 false.

    		 
  13. bool push(T && t);
  14. bool pop(T & ret);

    从队列弹出一个元素.

    返回:

    若弹出元素则为 true, 若队列为空则为 false.

    		 
  15. template<typename U, 
         typename Enabler = typename std::enable_if< std::is_constructible< U, T&& >::value >::type> 
  bool pop(U & ret);

    从队列弹出一个元素.

    返回:

  16. std::optional< T > pop(uses_optional_t);

    弹出一个元素, 返回 std::optional<T>.

    返回:

    成功时包含该值的 std::optional, 若队列为空则为 std::nullopt.

    		 
  17. template<typename U> std::optional< U > pop(uses_optional_t);

    弹出一个元素, 返回 std::optional.

    模板参数:

    U

    接收弹出值的类型; T 必须可转换为 U.

    返回:

    成功时包含该值的 std::optional<U>, 若队列为空则为 std::nullopt.

    		 
  18. template<typename Functor> bool consume_one(Functor && f);

    通过函子消费一个元素.

    把一个元素从槽位移出, 把产生的右值传给函子, 并在函子返回后释放该槽位以供重用.

    返回:

    若消费了元素则为 true.

    		 
  19. template<typename Functor> size_t consume_all(Functor && f);

    通过函子消费所有元素.

    顺序弹出所有元素并对每个元素应用函子.

    返回:

    被消费的元素数量.
