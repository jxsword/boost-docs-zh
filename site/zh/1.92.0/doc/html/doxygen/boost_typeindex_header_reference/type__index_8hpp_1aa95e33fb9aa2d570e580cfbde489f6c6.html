宏 BOOST_TYPE_INDEX_REGISTER_CLASS

BOOST_TYPE_INDEX_REGISTER_CLASS

概要

// In header: <boost/type_index.hpp>

BOOST_TYPE_INDEX_REGISTER_CLASS

说明

BOOST_TYPE_INDEX_REGISTER_CLASS 用于帮助模拟 RTTI. 将此宏放入多态类的 public 部分以允许运行期类型检测.

根据 typeid() 是否可用, 此宏将展开为空或虚辅助函数 virtual const type_info& boost_type_info_type_id_runtime_() const noexcept.

示例: 

class A {
public:
    BOOST_TYPE_INDEX_REGISTER_CLASS
    virtual ~A(){}
};

struct B: public A {
    BOOST_TYPE_INDEX_REGISTER_CLASS
};

struct C: public B {
    BOOST_TYPE_INDEX_REGISTER_CLASS
};

...

C c1;
A* pc1 = &c1;
assert(boost::typeindex::type_id<C>() == boost::typeindex::type_id_runtime(*pc1));
