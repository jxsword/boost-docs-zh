类型定义 type_info

type_info

概要

// In header: <boost/type_index.hpp>


typedef type_index::type_info_t type_info;

说明

根据编译器标志, 将使用 type_info 的最优实现作为默认的 boost::typeindex::type_info.

可能是 std::type_info、boost::typeindex::detail::ctti_data 或某个用户定义的类.

type_info 并非 可复制或可默认构造的. 它同样 不可 赋值!
