类型定义 type_index

type_index

概要

// In header: <boost/type_index.hpp>


typedef platform_specific type_index;

说明

根据编译器标志, 将使用 type_index 的最优实现作为默认的 boost::typeindex::type_index.

可能是 boost::typeindex::stl_type_index、boost::typeindex::ctti_type_index 或用户定义的 type_index 类.

参见 boost::typeindex::type_index_facade 以了解 type_index 函数的完整说明.
