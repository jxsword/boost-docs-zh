函数模板 type_id_runtime

boost::typeindex::type_id_runtime

概要

// In header: <boost/type_index.hpp>


template<typename T> type_index type_id_runtime(const T & runtime_val);

说明

功能与 C++ typeid(rtti_val) 调用完全相同的函数, 但返回 boost::type_index.

返回指定类型的运行期信息.

要求: RTTI 可用, 或 Base 与 Derived 类必须用 BOOST_TYPE_INDEX_REGISTER_CLASS 标记.

示例: 

struct Base { virtual ~Base(){} };
struct Derived: public Base  {};
...
Derived d;
Base& b = d;
type_index ti = type_id_runtime(b);
std::cout << ti.pretty_name();  // Outputs 'Derived'

参数:

runtime_val

必须返回其运行期类型的变量.

返回:

boost::typeindex::type_index (带有指定变量的信息).

抛出:

 无.
