函数模板 runtime_pointer_cast

boost::typeindex::runtime_pointer_cast — 创建智能指针的新实例, 其存储的指针通过 runtime_cast 从 u 的存储指针获得.

概要

// In header: <boost/type_index/runtime_cast/boost_shared_ptr_cast.hpp>


template<typename T, typename U, template< class > class SmartPointer> 
  BOOST_TYPE_INDEX_BEGIN_MODULE_EXPORT auto 
  runtime_pointer_cast(SmartPointer< U > const & u);

说明

新 shared_ptr 将与 u 共享所有权, 除非 runtime_pointer_cast 执行的 runtime_cast 返回空指针, 此时它为空.

模板参数:

T

希望返回其指针的目标类型.

U

u 所指向源实例的完整类类型.

返回:

若存在从 U* 到 T* 的有效转换, 则返回一个 boost::shared_ptr<T>, 它指向与 u 适当偏移的地址. 若不存在这样的转换, 则返回 boost::shared_ptr<T>();
