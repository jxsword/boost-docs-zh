类模板 type_index_facade

boost::typeindex::type_index_facade

概要

// In header: <boost/type_index/type_index_facade.hpp>

template<typename Derived, typename TypeInfo> 
class type_index_facade {
public:
  // types
  typedef TypeInfo type_info_t;

  // public member functions
  const char * name() const noexcept;
  std::string pretty_name() const;
  bool equal(const Derived &) const noexcept;
  bool before(const Derived &) const noexcept;
  std::size_t hash_code() const noexcept;

  // protected member functions
  const char * raw_name() const noexcept;
  const type_info_t & type_info() const noexcept;

  // protected static functions
  template<typename T> static Derived type_id() noexcept;
  template<typename T> static Derived type_id_with_cvr() noexcept;
  template<typename T> static Derived type_id_runtime(const T &) noexcept;
};

说明

此类负责比较运算符、哈希函数和 ostream 运算符. 将此类用作公开基类来定义新的符合 type_info 的类.

示例: 

class stl_type_index: public type_index_facade<stl_type_index, std::type_info> 
{
public:
    using type_info_t = std::type_info;
private:
    const type_info_t* data_;

public:
    stl_type_index(const type_info_t& data) noexcept
        : data_(&data)
    {}
// ...
};

注释

请查看受保护的方法. 它们 并未 定义于 type_index_facade 中. 受保护成员函数 raw_name() 必须 在 Derived 类中定义. 其余方法均为必须实现的.

参见: 'Making a custom type_index' 一节提供了关于创建自己的 type_index (使用 type_index_facade) 的更多信息.

模板参数

  1. typename Derived

    派生自 type_index_facade 的类.

  2. typename TypeInfo

    将用作基类型 type_info 类的类.

type_index_facade 公有成员函数

  1. const char * name() const noexcept;

    可重写: 此函数 可以 在 Derived 类中重写. 重写 必须 不抛出异常.

    返回:

    类型的名称. 默认返回 Derived::raw_name().

    		 
  2. std::string pretty_name() const;

    可重写: 此函数 可以 在 Derived 类中重写. 重写可以抛出异常.

    返回:

    人类可读的类型名称. 默认返回 Derived::name().

    		 
  3. bool equal(const Derived & rhs) const noexcept;

    可重写: 此函数 可以 在 Derived 类中重写. 重写 必须 不抛出异常.

    返回:

    若两个类型相等则为 true. 默认按 raw_name() 比较类型.

    		 
  4. bool before(const Derived & rhs) const noexcept;

    可重写: 此函数 可以 在 Derived 类中重写. 重写 必须 不抛出异常.

    返回:

    若 rhs 大于 this 则为 true. 默认按 raw_name() 比较类型.

    		 
  5. std::size_t hash_code() const noexcept;

    可重写: 此函数 可以 在 Derived 类中重写. 重写 必须 不抛出异常.

    注释

    Derived 类的头文件 必须 包含 <boost/container_hash/hash.hpp>, 除非 此函数在 Derived 类中被重写为不使用 boost::hash_range().

    返回:

    类型的哈希码. 默认按 raw_name() 对类型做哈希.

type_index_facade 受保护成员函数

  1. const char * raw_name() const noexcept;

    可重写: 此函数 必须 在 Derived 类中重写. 重写 必须 不抛出异常.

    返回:

    指向不可读/原始类型名称的指针.

    		 
  2. const type_info_t & type_info() const noexcept;

    可重写: 此函数 可以 在 Derived 类中重写. 重写 必须 不抛出异常.

    返回:

    底层低级 type_info_t 的 const 引用.

type_index_facade 受保护的静态函数

  1. template<typename T> static Derived type_id() noexcept;

    这是用于创建 Derived 类实例的工厂方法. 若 Derived 与 boost::typeindex::type_index 类型相同, boost::typeindex::type_id() 将调用此方法.

    可重写: 此函数 可以 在 Derived 类中重写并设为 public. 重写 必须 不抛出异常. 重写 必须 移除 T 的 const、volatile、&& 和 & 修饰符.

    模板参数:

    T

    要为其创建 type_index 的类型.

    返回:

    type_index (对应类型 T).

    		 
  2. template<typename T> static Derived type_id_with_cvr() noexcept;

    这是用于创建 Derived 类实例的工厂方法. 若 Derived 与 boost::typeindex::type_index 类型相同, boost::typeindex::type_id_with_cvr() 将调用此方法.

    可重写: 此函数 可以 在 Derived 类中重写并设为 public. 重写 必须 不抛出异常. 重写 必须 不得 移除 T 的 const、volatile、&& 和 & 修饰符.

    模板参数:

    T

    要为其创建 type_index 的类型.

    返回:

    type_index (对应类型 T).

    		 
  3. template<typename T> 
  static Derived type_id_runtime(const T & variable) noexcept;

    这是用于创建 Derived 类实例的工厂方法. 若 Derived 与 boost::typeindex::type_index 类型相同, boost::typeindex::type_id_runtime(const T&) 将调用此方法.

    可重写: 此函数 可以 在 Derived 类中重写并设为 public.

    参数:

    variable

    其运行期类型将存储在 type_index 中的变量.

    返回:

    type_index (带有变量的运行期类型).
