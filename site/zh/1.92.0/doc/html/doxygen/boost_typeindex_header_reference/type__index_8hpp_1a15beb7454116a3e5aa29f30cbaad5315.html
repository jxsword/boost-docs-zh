函数模板 type_id_with_cvr

boost::typeindex::type_id_with_cvr

概要

// In header: <boost/type_index.hpp>


template<typename T> type_index type_id_with_cvr();

说明

为类型 T 构造 boost::typeindex::type_index 实例的函数. 不移除 T 的 const、volatile、& 和 && 修饰符.

若 T 没有 const、volatile、& 和 && 修饰符, 则返回与调用 type_id<T>() 完全相同的结果.

示例: 

type_index ti = type_id_with_cvr<int&>();
std::cout << ti.pretty_name();  // Outputs 'int&'

模板参数:

T

要为其创建 type_index 的类型.

返回:

boost::typeindex::type_index (带有指定类型 T 的信息).

抛出:

 无.
