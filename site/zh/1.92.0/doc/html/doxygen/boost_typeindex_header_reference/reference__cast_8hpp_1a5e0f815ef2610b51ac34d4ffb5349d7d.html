函数模板 runtime_cast

boost::typeindex::runtime_cast — 沿继承层次安全地将类引用向上、向下和横向转换.

概要

// In header: <boost/type_index/runtime_cast/reference_cast.hpp>


template<typename T, typename U> 
  std::add_lvalue_reference< T >::type runtime_cast(U & u);

说明

模板参数:

T

期望的目标类型. 与 dynamic_cast 一样, 必须是指向完整类类型的指针.

U

源实例 u 的完整类类型.

返回:

若存在从 U& 到 T 的有效转换, 则返回一个 T, 它引用与 u 适当偏移的地址. 若不存在这样的转换, 则抛出 boost::typeindex::bad_runtime_cast.
