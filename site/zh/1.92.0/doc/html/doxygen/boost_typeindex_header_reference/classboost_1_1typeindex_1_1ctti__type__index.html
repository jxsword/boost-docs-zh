类 ctti_type_index

boost::typeindex::ctti_type_index

概要

// In header: <boost/type_index/ctti_type_index.hpp>


class ctti_type_index {
public:
  // types
  typedef unspecified type_info_t;

  // private member functions
  std::size_t get_raw_name_length() const noexcept;
  explicit ctti_type_index(const char *) noexcept;

  // public member functions
  ctti_type_index() noexcept;
  ctti_type_index(const type_info_t &) noexcept;
  const type_info_t & type_info() const noexcept;
  const char * raw_name() const noexcept;
  const char * name() const noexcept;
  std::string pretty_name() const;
  std::size_t hash_code() const noexcept;
  bool equal(const ctti_type_index &) const noexcept;
  bool before(const ctti_type_index &) const noexcept;

  // public static functions
  template<typename T> static ctti_type_index type_id() noexcept;
  template<typename T> static ctti_type_index type_id_with_cvr() noexcept;
  template<typename T> 
    static ctti_type_index type_id_runtime(const T &) noexcept;
};

说明

此类是一个包装器, 其行为与 stl_type_index 完全一致, 但不要求 RTTI 支持. 有关 函数 的 描述 请参见 type_index_facade.

在兼容 C++14 的编译器上, 此类可在编译期使用, 且以下函数被标记为 constexpr:

  • 默认构造函数

  • 复制构造函数与赋值运算

  • 类方法: name()、before(const ctti_type_index& rhs)、equal(const ctti_type_index& rhs)

  • 静态方法 type_id<T>()、type_id_with_cvr<T>()

  • 比较运算符

此外, 从 C++14 开始, name() 函数总是输出类型的 pretty_name(). 例如, 以下静态断言成立:

static_assert(
    boost::typeindex::ctti_type_index:::type_id<int>().name()
    == std::string_view{"int"}
);

在 C++11 下此类产生的类型名称略长于 stl_type_index, 更多信息请参见 "Code Bloat".
