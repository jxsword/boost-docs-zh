类型 match_flag_type

boost::xpressive::regex_constants::match_flag_type

概要

// In header: <boost/xpressive/regex_constants.hpp>



enum match_flag_type { match_default = 0, match_not_bol = 1 << 1, 
                       match_not_eol = 1 << 2, match_not_bow = 1 << 3, 
                       match_not_eow = 1 << 4, match_any = 1 << 7, 
                       match_not_null = 1 << 8, match_continuous = 1 << 10, 
                       match_partial = 1 << 11, match_prev_avail = 1 << 12, 
                       format_default = 0, format_sed = 1 << 13, 
                       format_perl = 1 << 14, format_no_copy = 1 << 15, 
                       format_first_only = 1 << 16, format_literal = 1 << 17, 
                       format_all = 1 << 18 };

说明

用于自定义正则表达式算法行为的标志

match_default

指定正则表达式的匹配按 ECMA-262 (ECMAScript 语言规范, 第 15 章第 10 部分, RegExp (正则表达式) 对象) 中的正常规则进行, 不做任何修改 (FWD.1)

match_not_bol

指定表达式 "^" 不应与子序列 [first,first) 匹配.

match_not_eol

指定表达式 "\$" 不应与子序列 [last,last) 匹配.

match_not_bow

指定表达式 "\\b" 不应与子序列 [first,first) 匹配.

match_not_eow

指定表达式 "\\b" 不应与子序列 [last,last) 匹配.

match_any

指定若可能存在多个匹配, 则任何匹配都是可接受的结果.

match_not_null

指定表达式不能与空序列匹配.

match_continuous

指定表达式必须匹配从 first 开始的子序列.

match_partial

指定若找不到匹配, 则可以返回匹配 [from, last) (其中 from != last), 前提是存在某个字符序列 [from,to), [from,last) 是它的前缀, 且它会导致完全匹配.

match_prev_avail

指定 –first 是有效的迭代器位置; 设置此标志时, 正则表达式算法 (RE.7) 与迭代器 (RE.8) 将忽略 match_not_bol 与 match_not_bow 标志.

format_default

指定当正则表达式匹配要被新字符串替换时, 新字符串按 ECMA-262 (ECMAScript 语言规范) 第 15 章 5.4.11 节 String.prototype.replace 中 ECMAScript replace 函数所用的规则构造 (FWD.1). 此外, 在搜索与替换操作中, 正则表达式的所有不重叠出现都会被定位并替换, 输入中未匹配表达式的部分将原样复制到输出字符串.

format_sed

指定当正则表达式匹配要被新字符串替换时, 新字符串按 IEEE Std 1003.1-2001 (可移植操作系统接口 (POSIX), Shell 与工具) 中 Unix sed 实用程序所用的规则构造.

format_perl

指定当正则表达式匹配要被新字符串替换时, 新字符串按 ECMA-262 (ECMAScript 语言规范) 第 15 章 5.4.11 节 String.prototype.replace 中 ECMAScript replace 函数所用规则的实现定义超集构造 (FWD.1).

format_no_copy

在搜索替换操作中指定时, 被搜索的字符容器序列中与正则表达式匹配的部分不会被复制到输出字符串.

format_first_only

在搜索替换操作中指定时, 只替换正则表达式的第一次出现.

format_literal

把格式化字符串当作字面量.

format_all

指定启用所有语法扩展, 包括条件替换 (?ddexpression1:expression2).
