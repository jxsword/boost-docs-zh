函数模板 augmented_crc

boost::augmented_crc — 计算内存块的 CRC, 增广由用户提供.

概要

// In header: <boost/crc.hpp>


template<std::size_t Bits, unspecified TruncPoly> 
  unspecified augmented_crc(void const * buffer, std::size_t byte_count, 
                            unspecified initial_remainder = 0u);

说明

计算一次 CRC 运行的多项式余数, 假定 buffer 和 byte_count 描述的内存块表示多项式被除数. 首个字节被视为最高位, 后续字节依次降低. 在一个字节内, 最高位优先读取 (对应 RMCA 中的 RefIn = False). 查看此函数文档的其他部分, 了解如何获得和/或使用校验和.

注释

增广风格的 CRC 运行使用直接的模 2 多项式除法. 由于数据按字节读取, 可以使用预计算的余数变化表 (作为 XOR 掩码) 来加速计算.

注释

仅读取内存块会得到中间余数, 而非最终校验和. 要得到校验和, 请在块之后直接分配 Bits / CHAR_BIT 个字节并用零值填充, 然后扩展 byte_count 以包含这些额外字节. 如果返回值不等于你单独提供的校验和, 则数据块已损坏.

注释

另一种执行校验的方法是使用零字节扩展方法, 但用你单独给出的校验和替换零值. 校验和必须按大端序加载. 此时, 如果返回值不为零, 则确认数据块或给定校验和损坏.

注释

两种校验和技术假定 CRC 运行按位执行, 而此函数按字节工作. 这意味着只有当 CHAR_BIT 能整除 Bits 时才能使用这些技术!

参数:

buffer

内存块的起始地址.

byte_count

内存块中的字节数.

initial_remainder

多项式余数的初始状态, 省略时默认为零. 如果你要分多次读取内存块, 请把上一次运行的返回值放在这里. (注意, RMCA 参数列表给出的初始余数 (如 Init) 假定初始余数处于其 未增广 状态, 因此你需要转换该值以使其适合此函数. 我目前未提供转换例程.)

模板参数:

Bits

模 2 多项式除数的阶数. (RMCA 中的 Width)

TruncPoly

除数多项式的低阶系数. 最高阶系数被省略且总被假定为 1. (RMCA 中的 Poly)

要求:

0 < Bits <= std::numeric_limit<uintmax_t>::digits

返回:

中间余数, 如果未使用增广. 如果使用了增广, 则为特殊值 (见注释). 对该值不进行输出处理. (按 RMCA 术语, RefOut 为 False, XorOut 为 0.)
