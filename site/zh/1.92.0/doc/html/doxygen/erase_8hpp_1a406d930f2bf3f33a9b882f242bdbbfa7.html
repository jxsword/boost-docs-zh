函数模板 erase_head_copy

boost::erase_head_copy — 擦除头部算法.

概要

// In header: <boost/algorithm/string/erase.hpp>


template<typename OutputIteratorT, typename RangeT> 
  OutputIteratorT 
  erase_head_copy(OutputIteratorT Output, const RangeT & Input, int N);

说明

从输入中移除头部. 头部是给定大小的序列前缀. 如果序列短于所需长度, 则整个字符串被视为头部. 结果是输入的修改副本. 它作为序列返回或复制到输出迭代器.

注释

此函数的第二个变体提供强异常安全保证

参数:

Output

结果将被复制到的输出迭代器

Input

输入字符串

N

头部长度. 对于 N>=0, 至多提取 N 个字符. 对于 N<0, 提取 size(Input)-|N| 个字符.

返回:

指向最后插入字符之后的输出迭代器, 或输入的修改副本
