宏 BOOST_MPI_HOMOGENEOUS

BOOST_MPI_HOMOGENEOUS — 如果你运行在异构环境中, 请注释掉此宏.

概要

// In header: <boost/mpi/config.hpp>

BOOST_MPI_HOMOGENEOUS

说明

启用此标志时, 我们假定某些简单的类 POD 类型可以不付出可移植序列化的代价进行传输.

如果你的平台不是同构的, 且必须执行可移植的序列化/反序列化, 请注释掉它.

如果这样做, 请检查你的 MPI 实现是否支持那种环境.
