类型 link_mode_type

boost::intrusive::link_mode_type

概要

// In header: <boost/intrusive/link_mode.hpp>


enum link_mode_type { normal_link, safe_link, auto_unlink };

说明

此枚举定义可为 Boost.Intrusive 容器定义的 value_traits 类型

normal_link

若此链接策略在 value_traits 类中被指定为 link_mode, 则配置了此类 value_traits 的容器不会把被擦除值的钩子设为默认状态. 容器也不会检查新值的钩子是否已默认初始化.

safe_link

若此链接策略在 value_traits 类中被指定为 link_mode, 则配置了此类 value_traits 的容器会把被擦除值的钩子设为默认状态. 容器也会检查新值的钩子是否已默认初始化.

auto_unlink

与 "safe_link" 相同, 但用户类型是自动解除链接类型, 因此具有常数时间 size 特性的容器与配置了此策略的 value_traits 不兼容. 容器也知道可以不使用容器提供的任何函数而静默地从容器中擦除值.
