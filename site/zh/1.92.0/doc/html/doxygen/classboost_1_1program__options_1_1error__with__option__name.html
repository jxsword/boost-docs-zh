说明

库中大多数异常类的基类.

替换模板中参数名占位符的值, 以生成人类可读的错误消息

占位符由 % 符号包围: example% boost::format 的简易版

如果缺少参数名, 则执行默认替换, 以免丑陋的占位符残留在原地.

选项以规范形式显示. 这是 解析后 的选项名最无歧义的形式, 对应于 option_description::format_name(), 即 print_usage() 所显示的内容

规范形式取决于选项是以短形式还是长形式指定, 使用连字符还是斜杠, 还是不带前缀 (来自配置文件)
