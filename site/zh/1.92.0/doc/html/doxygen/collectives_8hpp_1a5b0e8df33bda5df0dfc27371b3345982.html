函数 broadcast

boost::mpi::broadcast — 把一个值从根进程广播到所有其他进程.

概要

// In header: <boost/mpi/collectives.hpp>


template<typename T> 
  void broadcast(const communicator & comm, T & value, int root);
template<typename T> 
  void broadcast(const communicator & comm, T * values, int n, int root);
template<typename T> 
  void broadcast(const communicator & comm, skeleton_proxy< T > & value, 
                 int root);
template<typename T> 
  void broadcast(const communicator & comm, const skeleton_proxy< T > & value, 
                 int root);

说明

broadcast 是一种集合算法, 它把值从任意的 root 进程传输到属于给定通信器的所有其他进程. broadcast 算法可以传输任何 Serializable 值, 具有关联 MPI 数据类型的值, 打包档案, 骨架以及骨架的内容; 完整列表见通信器的 send 原语. 类型 T 对属于通信器 comm 的所有进程必须相同, 除非正在传输打包档案: 使用打包档案时, 根进程发送 packed_oarchive 或 packed_skeleton_oarchive, 而其他进程分别接收 packed_iarchive 或 packed_skeleton_iarchve.

当类型 T 具有关联的 MPI 数据类型时, 此例程调用 MPI_Bcast 执行广播.

参数:

comm

发生广播的通信器.

value

要传输的值 (或多个值, 如果提供了 n), 当 comm 的秩等于 root 时传输; 当 comm 的秩不等于 root 时接收. 当 value 是 skeleton_proxy 时, 只会广播对象的骨架. 在这种情况下, root 将根据代理中持有的对象构建骨架, 而所有非根进程将根据从根进程发送的骨架重塑其代理中持有的对象.

root

将传输该值的进程的秩/进程 ID.
