函数模板 move

boost::move

概要

// In header: <boost/move/algo/move.hpp>


template<typename I, typename O> O move(I f, I l, O result);

说明

效果: 把范围 [first,last) 中的元素移入范围 [result,result + (last - first)), 从 first 开始直到 last. 对每个非负整数 n < (last-first), 执行 *(result + n) = boost::move (*(first + n)).

效果: result + (last - first).

要求: result 不得在范围 [first,last) 内.

复杂度: 恰好 last - first 次移动赋值.
