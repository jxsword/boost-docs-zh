函数模板 find_first

boost::find_first — 查找首个算法.

概要

// In header: <boost/algorithm/string/find.hpp>


template<typename Range1T, typename Range2T> 
  iterator_range< typename range_iterator< Range1T >::type > 
  find_first(Range1T & Input, const Range2T & Search);

说明

在输入中搜索子串的第一次出现.

注释

此函数提供强异常安全保证

参数:

Input

将被搜索的字符串.

Search

要搜索的子串.

返回:

分隔匹配的 iterator_range. 返回的迭代器为 RangeT::iterator 或 RangeT::const_iterator, 取决于输入参数的常量性.
