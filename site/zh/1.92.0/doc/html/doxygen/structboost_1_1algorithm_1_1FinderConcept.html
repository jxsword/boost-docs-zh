结构体模板 FinderConcept

boost::algorithm::FinderConcept — Finder 概念.

概要

// In header: <boost/algorithm/string/concept.hpp>

template<typename FinderT, typename IteratorT> 
struct FinderConcept {

  // public member functions
  void constraints();
};

说明

定义 Finder 概念. Finder 是一个函子, 用于选择字符串的任意部分. 搜索在由起始与结束迭代器指定的范围上进行.

查找操作的结果必须可转换为 iterator_range.

FinderConcept 公有成员函数

  1. void constraints();
