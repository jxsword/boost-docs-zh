结构体 mark_tag

boost::xpressive::mark_tag — 子匹配占位符类型, 用于在静态正则表达式中创建命名捕获.

概要

// In header: <boost/xpressive/regex_primitives.hpp>


struct mark_tag {

  // private static functions
  static unspecified make_tag(int);

  // public member functions
  mark_tag(int);
};

说明

mark_tag 是全局子匹配占位符 s0、s1 等的类型. 你可以用 mark_tag 类型创建自己的子匹配占位符, 使其名称更有意义. 这大致相当于动态正则表达式的"命名捕获"特性.

要创建命名的子匹配占位符, 请用一个唯一的整数初始化它. 该整数只需在所用占位符的正则表达式内唯一. 然后, 你可以在静态正则表达式中使用它: 把子表达式赋给它即可创建子匹配, 或用它回引已创建的子匹配.

mark_tag number(1); // "number" is now equivalent to "s1"
// Match a number, followed by a space and the same number again
sregex rx = (number = +_d) >> ' ' >> number;

在成功的 regex_match() 或 regex_search() 之后, 子匹配占位符可用于索引 match_results<> 对象以取得相应的子匹配.

mark_tag 私有静态函数

  1. static unspecified make_tag(int mark_nbr);

mark_tag 公有成员函数

  1. mark_tag(int mark_nbr);
    初始化一个 mark_tag 占位符.

    参数:

    mark_nbr

    唯一标识此 mark_tag 的整数 (在此 mark_tag 将被使用的静态正则表达式内) .

    要求:

    mark_nbr > 0
