说明

类模板 list 是一种侵入式容器, 模仿 C++ 标准中所述 std::list 接口的大部分内容.

模板参数 T 是容器要管理的类型. 用户可以指定附加选项; 若未提供选项, 则使用默认选项.

容器支持以下选项: base_hook<>/member_hook<>/value_traits<>、constant_time_size<> 和 size_type<>.

list 公有成员函数

  1. list();

    效果: 构造一个空列表.

    复杂度: 常数

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况).

  2. explicit list(const value_traits & v_traits);

    效果: 构造一个空列表.

    复杂度: 常数

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况).

  3. template<typename Iterator> 
  list(Iterator b, Iterator e, const value_traits & v_traits = value_traits());

    要求: 解引用迭代器必须产生 value_type 类型的左值.

    效果: 构造一个等于范围 [first,last) 的列表.

    复杂度: 与 distance(b, e) 成线性关系. 不调用复制构造函数.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况).

  4. list(list && x);

    效果: 构造一个从另一容器移动资源的容器. 内部 value 特征被移动构造, 属于 x 的节点 (表示 "end" 的节点除外) 被链接到 *this.

    复杂度: 常数.

    抛出: 若 value_traits::node_traits::node 的移动构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 value 特征的移动构造函数抛出异常.

  5. list & operator=(list && x);

    效果: 等价于 swap

  6. ~list();

    效果: 若不是安全模式或 auto-unlink 的 value_type, 析构函数不做任何事 (即不生成代码). 否则它使所有元素脱离此容器. 此时列表中的对象不会被删除 (即不调用析构函数), 但根据 ValueTraits 模板参数, 钩子会被设置为默认值.

    抛出: 无.

    复杂度: 若为安全模式或 auto-unlink 值, 则与列表中的元素数量成线性关系; 否则为常数.

  7. void push_back(reference value) noexcept;

    要求: value 必须是左值.

    效果: 把值插入列表末尾. 不调用复制构造函数.

    抛出: 无.

    复杂度: 常数.

    注释: 不影响迭代器和引用的有效性.

  8. void push_front(reference value) noexcept;

    要求: value 必须是左值.

    效果: 把值插入列表开头. 不调用复制构造函数.

    抛出: 无.

    复杂度: 常数.

    注释: 不影响迭代器和引用的有效性.

  9. void pop_back() noexcept;

    效果: 擦除列表的最后一个元素. 不调用析构函数.

    抛出: 无.

    复杂度: 常数.

    注释: 使被擦除元素的迭代器 (但非引用) 失效.

    抛出: 无.

    复杂度: 常数.

  41. template<typename Cloner, typename Disposer> 
  void clone_from(const list & src, Cloner cloner, Disposer disposer);

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点等价的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(const_reference ) 从 src 克隆所有元素并插入到 *this 中.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常. 基本保证.

  42. template<typename Cloner, typename Disposer> 
  void clone_from(list && src, Cloner cloner, Disposer disposer);

    要求: Disposer::operator()(pointer) 不应抛出异常. Cloner 应产生与原节点等价的节点.

    效果: 调用 Disposer::operator()(pointer) 擦除 *this 中的所有元素, 调用 Cloner::operator()(reference) 从 src 克隆所有元素并插入到 *this 中.

    若 cloner 抛出异常, 所有被克隆的元素将被解除链接, 并通过调用 Disposer::operator()(pointer) 释放.

    复杂度: 与被擦除元素加上被插入元素的数量成线性关系.

    抛出: 若 cloner 抛出异常. 基本保证.

    抛出: 无.

    复杂度: 常数.

    注释: 从 list x 获得的值的迭代器现在指向本 list 的元素. 本 list 的迭代器和所有引用不会失效.

  49. void splice(const_iterator p, list & x, const_iterator f, const_iterator e) noexcept;

    要求: p 必须是 *this 的有效迭代器. f 与 e 必须指向列表 x 中包含的元素.

    效果: 把 f 与 e 所指向的范围从列表 x 转移到此列表中 p 所指向元素之前. 不调用析构函数或复制构造函数.

    注释: 从 list x 获得的值的迭代器现在指向本 list 的元素. 本 list 的迭代器和所有引用不会失效.

    要求: p 必须是 *this 的有效迭代器. f 与 e 必须指向列表 x 中包含的元素. n == distance(f, e)

    效果: 把 f 与 e 所指向的范围从列表 x 转移到此列表中 p 所指向元素之前. 不调用析构函数或复制构造函数.

    抛出: 无.

  51. void sort();

    效果: 此函数按 operator < 对列表 *this 排序. 排序是稳定的, 即等价元素的相对顺序保持不变.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或 operator < 抛出异常. 基本保证.

    注释: 迭代器和引用不会失效.

    复杂度: 比较次数约为 N log N, 其中 N 是 list 的大小.

  52. template<typename Predicate> void sort(Predicate p);

    要求: p 必须是诱导严格弱序的比较函数

    效果: 此函数按 p 对列表 *this 排序. 排序是稳定的, 即等价元素的相对顺序保持不变.

    抛出: 若 value_traits::node_traits::node 构造函数抛出异常 (预定义的 Boost.Intrusive 钩子不会发生这种情况), 或谓词抛出异常. 基本保证.

    注释: 若使用 list_base_hook<> 或 list_member_hook, 此操作不会抛出异常. 迭代器和引用不会失效.

    复杂度: 比较次数约为 N log N, 其中 N 是 list 的大小.

  53. void merge(list & x);

    效果: 此函数移除 x 的所有元素, 并按 operator < 的顺序插入到 *this 中. 合并是稳定的; 即若 *this 中的一个元素与 x 中的一个元素等价, 则 *this 的元素将排在 x 的元素之前.

    抛出: 若 operator < 抛出异常. 基本保证.

    复杂度: 此函数是线性时间: 至多执行 size() + x.size() - 1 次比较.

    注释: 迭代器和引用不会失效

  54. template<typename Predicate> void merge(list & x, Predicate p);

    要求: p 必须是引发严格弱序的比较函数, 且 *this 与 x 都必须已按该顺序排序. list x 与 *this 必须不同.

    效果: 此函数移除 x 的所有元素, 并依序插入 *this. 合并是稳定的; 即若 *this 的一个元素与 x 的一个元素等价, 则 *this 的元素将排在 x 的元素之前.

    抛出: 若谓词抛出异常. 基本保证.

    复杂度: 此函数是线性时间: 至多执行 size() + x.size() - 1 次比较.

    注释: 迭代器和引用不会失效.

    注释: 未被移除元素的相对顺序不变, 且指向未移除元素的迭代器保持有效.
