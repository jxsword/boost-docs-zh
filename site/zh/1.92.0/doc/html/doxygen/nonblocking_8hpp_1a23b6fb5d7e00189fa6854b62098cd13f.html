函数 wait_some

boost::mpi::wait_some — 等待一些非阻塞请求完成.

概要

// In header: <boost/mpi/nonblocking.hpp>


template<typename BidirectionalIterator, typename OutputIterator> 
  std::pair< OutputIterator, BidirectionalIterator > 
  wait_some(BidirectionalIterator first, BidirectionalIterator last, 
            OutputIterator out);
template<typename BidirectionalIterator> 
  BidirectionalIterator 
  wait_some(BidirectionalIterator first, BidirectionalIterator last);

说明

本例程接受存储在迭代器范围 [first,last) 中的一组请求, 并等待其中至少一个请求完成. 然后完成所有它能完成的请求, 把输入序列划分为两部分: 前面是待处理请求, 后面是已完成请求. 若提供了输出迭代器, 将为每个已完成的请求输出 status 对象. 本例程提供与 MPI_Waitsome 等价的功能.

参数:

first

表示请求对象序列起始的迭代器.

last

表示请求对象序列结尾的迭代器. 它不能等于 first.

out

若提供了该参数, 与已完成请求对应的 status 对象将通过该输出迭代器输出.

返回:

若提供了 out 参数, 返回一个 pair, 其中包含输出迭代器 out (所有 status 对象都已写入之后) 以及指向第一个已完成请求的迭代器. 若未提供 out 参数, 则只输出指向第一个已完成请求的迭代器.
