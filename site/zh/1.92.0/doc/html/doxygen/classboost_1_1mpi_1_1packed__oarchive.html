类 packed_oarchive

boost::mpi::packed_oarchive — 将二进制数据打包到 MPI 缓冲区中的档案.

概要

// In header: <boost/mpi/packed_oarchive.hpp>


class packed_oarchive : public oprimitive {
public:

  // public member functions
  packed_oarchive(MPI_Comm const &, buffer_type &,

说明

packed_iarchive 类是一个 Archiver (如 Boost.Serialization 库中那样), 用于将二进制数据打包到缓冲区以便通过 MPI 传输. 它可操作任何 Serializable 数据类型, 并将使用底层 MPI 实现的 MPI_Pack 函数执行序列化.

packed_oarchive 公有成员函数

  1. packed_oarchive(MPI_Comm const & comm, buffer_type & b, 
                unsigned int flags = boost::archive::no_header);

    构造一个 packed_oarchive, 用于通过给定的 MPI 通信器传输数据, 并带有初始缓冲区.

    参数:

    comm

    发送此档案所用的通信器.

    b

    将被填充序列化对象二进制表示的用户自定义缓冲区.

    flags
