结构体模板 placeholder_of

boost::type_erasure::placeholder_of

概要

// In header: <boost/type_erasure/placeholder_of.hpp>

template<typename T> 
struct placeholder_of {
  // types
  typedef unspecified type;
};

说明

返回与某个 any 对应的 (带 const/引用限定的) 占位符的元函数. 它也适用于 any 的所有基类, 因此可应用于 Base 参数 (即 concept_interface 的形参) .
