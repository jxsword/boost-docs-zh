类模板 basic_managed_mapped_file

boost::interprocess::basic_managed_mapped_file

概要

// In header: <boost/interprocess/managed_mapped_file.hpp>

template<typename CharType, typename AllocationAlgorithm, 
         template< class IndexConfig > class IndexType> 
class basic_managed_mapped_file {
public:
  // types
  typedef implementation_defined size_type;

  // public member functions
  basic_managed_mapped_file() noexcept;
  basic_managed_mapped_file(create_only_t, const char *, size_type, 
                            const void * = 0, 
                            const permissions & = permissions());
  basic_managed_mapped_file(open_or_create_t, const char *, size_type, 
                            const void * = 0, 
                            const permissions & = permissions());
  basic_managed_mapped_file(open_only_t, const char *, const void * = 0);
  basic_managed_mapped_file(open_copy_on_write_t, const char *, 
                            const void * = 0);
  basic_managed_mapped_file(open_read_only_t, const char *, const void * = 0);
  basic_managed_mapped_file(create_only_t, const wchar_t *, size_type, 
                            const void * = 0, 
                            const permissions & = permissions());
  basic_managed_mapped_file(open_or_create_t, const wchar_t *, size_type, 
                            const void * = 0, 
                            const permissions & = permissions());
  basic_managed_mapped_file(open_only_t, const wchar_t *, const void * = 0);
  basic_managed_mapped_file(open_copy_on_write_t, const wchar_t *, 
                            const void * = 0);
  basic_managed_mapped_file(open_read_only_t, const wchar_t *, 
                            const void * = 0);
  basic_managed_mapped_file(basic_managed_mapped_file &&) noexcept;
  basic_managed_mapped_file & operator=(basic_managed_mapped_file &&) noexcept;
  ~basic_managed_mapped_file();
  void swap(basic_managed_mapped_file &) noexcept;
  bool flush();

  // public static functions
  static bool grow(const char *, size_type);
  static bool shrink_to_fit(const char *);
  static bool grow(const wchar_t *, size_type);
  static bool shrink_to_fit(const wchar_t *);
};

说明

一种基础的映射文件命名对象创建类. 初始化映射文件. 从 basic_managed_memory_impl<CharType, AllocationAlgorithm, IndexType> 继承所有基本功能

basic_managed_mapped_file 公有类型

  1. typedef implementation_defined size_type;

    足以表示 basic_managed_mapped_file 大小的无符号整数类型.

basic_managed_mapped_file 公有成员函数

  1. basic_managed_mapped_file() noexcept;

    创建映射文件并创建和放置段管理器. 这可能抛出异常.

  2. basic_managed_mapped_file(create_only_t, const char * name, size_type size, 
                          const void * addr = 0, 
                          const permissions & perm = permissions());

    创建映射文件并创建和放置段管理器. 这可能抛出异常.

  3. basic_managed_mapped_file(open_or_create_t, const char * name, size_type size, 
                          const void * addr = 0, 
                          const permissions & perm = permissions());

    若段尚未创建, 则创建映射文件并创建和放置段管理器; 若段已创建, 则连接到该段. 这可能抛出异常.

  4. basic_managed_mapped_file(open_only_t, const char * name, 
                          const void * addr = 0);

    连接到已创建的映射文件及其段管理器. 这可能抛出异常.

  5. basic_managed_mapped_file(open_copy_on_write_t, const char * name, 
                          const void * addr = 0);

    以 copy_on_write 模式连接到已创建的映射文件及其段管理器. 这可能抛出异常.

  6. basic_managed_mapped_file(open_read_only_t, const char * name, 
                          const void * addr = 0);

    以只读模式连接到已创建的映射文件及其段管理器. 这可能抛出异常.

  7. basic_managed_mapped_file(create_only_t, const wchar_t * name, size_type size, 
                          const void * addr = 0, 
                          const permissions & perm = permissions());

    创建映射文件并创建和放置段管理器. 这可能抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  8. basic_managed_mapped_file(open_or_create_t, const wchar_t * name,

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  12. basic_managed_mapped_file(basic_managed_mapped_file && moved) noexcept;

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  13. basic_managed_mapped_file & 
operator=(basic_managed_mapped_file && moved) noexcept;

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  14. ~basic_managed_mapped_file();

    销毁 *this 并指示调用进程已结束对该资源的使用. 析构函数将释放系统为该进程使用此资源而分配的所有系统资源. 之后仍可通过调用 open 构造函数重载再次打开该资源. 要从系统中擦除该资源, 请使用 remove().

  15. void swap(basic_managed_mapped_file & other) noexcept;

    交换 *this 与 other 所管理的托管映射内存的所有权. 绝不抛出异常.

  16. bool flush();

    将缓存数据刷新到文件. 绝不抛出异常

basic_managed_mapped_file 公有静态函数

    尝试调整映射文件的大小, 以便为更多对象腾出空间.

    该函数不同步, 因此不得有其他线程或进程正在读写该文件

    由于底层文件增长后内存会被重新映射, 因此它不能与使用原生指针的段一起工作.
