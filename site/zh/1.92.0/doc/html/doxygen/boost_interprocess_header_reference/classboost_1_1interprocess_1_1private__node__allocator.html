类模板 private_node_allocator

boost::interprocess::private_node_allocator

概要

// In header: <boost/interprocess/allocators/private_node_allocator.hpp>

template<typename T, typename SegmentManager, std::size_t NodesPerBlock> 
class private_node_allocator {
public:
  // types
  typedef implementation_defined::segment_manager segment_manager;
  typedef segment_manager::void_pointer           void_pointer;   
  typedef implementation_defined::pointer         pointer;        
  typedef implementation_defined::const_pointer   const_pointer;  
  typedef T                                       value_type;     
  typedef unspecified                             reference;      
  typedef unspecified                             const_reference;
  typedef segment_manager::size_type              size_type;      
  typedef segment_manage::difference_type         difference_type;

  // member classes/structs/unions
  template<typename T2> 
  struct rebind {
    // types
    typedef private_node_allocator< T2, SegmentManager, NodesPerBlock > other;
  };

  // private member functions
  template<typename T2, typename SegmentManager2, std::size_t N2> 
    private_node_allocator & 
    operator=(const private_node_allocator< T2, SegmentManager2, N2 > &);
  private_node_allocator & operator=(const private_node_allocator &);

  // public member functions
  private_node_allocator(segment_manager *);
  private_node_allocator(const private_node_allocator &);
  private_node_allocator(private_node_allocator &&);
  template<typename T2> 
    private_node_allocator(const private_node_allocator< T2, SegmentManager, NodesPerBlock > &);
  ~private_node_allocator();
  node_pool_t * get_node_pool() const;
  segment_manager * get_segment_manager() const;
  size_type max_size() const;
  pointer allocate(size_type, cvoid_pointer = 0);
  void deallocate(const pointer &, size_type);
  void deallocate_free_blocks();
  pointer address(reference) const;
  const_pointer address(const_reference) const;
  template<typename U, class ... Args> void construct(U *, Args &&...);
  size_type size(const pointer &) const;
  void allocate_many(size_type, size_type, multiallocation_chain &);
  void allocate_many(const size_type *, size_type, multiallocation_chain &);
  void deallocate_many(multiallocation_chain &);
  pointer allocate_one();
  void allocate_individual(size_type, multiallocation_chain &);
  void deallocate_one(const pointer &);
  void deallocate_individual(multiallocation_chain &);

  // friend functions
  void swap(self_t &, self_t &);
};

说明

一种以段管理器为内存来源的 STL 节点分配器. 其内部指针类型与 "typename SegmentManager::void_pointer" 类型相同 (原生指针或智能指针). 这使得该分配器可以被放置在共享内存、内存映射文件等之中... 该分配器拥有自己的节点池. NodesPerBlock 是分配器节点耗尽时一次性分配的节点数

private_node_allocator 私有成员函数

  1. template<typename T2, typename SegmentManager2, std::size_t N2> 
  private_node_allocator & 
  operator=(const private_node_allocator< T2, SegmentManager2, N2 > &);

    赋值不可来自相关的 private_node_allocator 

  2. private_node_allocator & operator=(const private_node_allocator &);

    赋值不可来自另一 private_node_allocator

private_node_allocator 公有成员函数

  1. private_node_allocator(segment_manager * segment_mngr);

    从段管理器构造. 如果节点池不存在, 则构造一个节点池. 递增关联节点池的引用计数. 可能抛出 boost::interprocess::bad_alloc 

  2. private_node_allocator(const private_node_allocator & other);

    从另一 private_node_allocator 复制构造. 递增关联节点池的引用计数. 绝不抛出异常

  3. private_node_allocator(private_node_allocator && other);

    从另一对象移动构造. 递增关联节点池的引用计数并接管缓存. 绝不抛出异常

  4. template<typename T2> 
  private_node_allocator(const private_node_allocator< T2, SegmentManager, NodesPerBlock > & other);

    从相关的 private_node_allocator 复制构造. 如果节点池不存在, 则构造一个节点池. 递增关联节点池的引用计数. 可能抛出 boost::interprocess::bad_alloc 

  5. ~private_node_allocator();

    析构函数, 当引用计数降为零时从内存中移除 node_pool_t. 绝不抛出异常

  6. node_pool_t * get_node_pool() const;

    返回指向节点池的指针. 绝不抛出异常

  7. segment_manager * get_segment_manager() const;

    返回段管理器. 绝不抛出异常

  8. size_type max_size() const;

    返回可分配的元素数量. 从不抛出异常

  9. pointer allocate(size_type count, cvoid_pointer hint = 0);

    为 count 个元素的数组分配内存. 如果没有足够的内存, 抛出 boost::interprocess::bad_alloc 

  10. void deallocate(const pointer & ptr, size_type count);

    释放已分配的内存. 从不抛出异常

  11. void deallocate_free_blocks();

    释放池中所有空闲块

  12. pointer address(reference value) const;

    返回可变对象的地址. 绝不抛出异常 该函数已弃用, 未来将被移除

  13. const_pointer address(const_reference value) const;

    返回不可变对象的地址. 绝不抛出异常 该函数已弃用, 未来将被移除

  14. template<typename U, class ... Args> void construct(U * p, Args &&... args);

    要求: 使用分配器实参 uses_segment_manager_t 和附加构造函数实参 std::forward<Args>(args)... 对 T 进行 uses-allocator 构造必须合式. [注释: 对于不使用分配器的类型, uses-allocator 构造总是合式的. - end note]

    效果: 通过 uses-allocator 构造在 p 处构造一个 T 对象, 分配器实参可从 segment_manager* 构造, 构造函数实参为 std::forward<Args>(args)....

    抛出: 除非 T 的构造函数抛出异常, 否则不抛出.

  15. size_type size(const pointer & p) const;

    返回 p 指向的先前已分配内存最多能容纳的对象数. 该大小仅适用于通过 allocate、allocation_command 和 allocate_many 分配的内存. 该函数已弃用, 未来将被移除

  16. void allocate_many(size_type elem_size, size_type num_elements, 
                   multiallocation_chain & chain);

    在连续内存块中分配多个大小为 elem_size 的元素. 最少分配数量为 min_elements, 首选和最大数量为 preferred_elements. 实际分配的元素数量将被赋给 received_size. 这些元素必须用 deallocate(...) 释放 该函数已弃用, 未来将被移除

  17. void allocate_many(const size_type * elem_sizes, size_type n_elements, 
                   multiallocation_chain & chain);

    在连续内存块中分配 n_elements 个元素, 每个元素大小为 elem_sizes[i]. 这些元素必须被释放 该函数已弃用, 未来将被移除

  18. void deallocate_many(multiallocation_chain & chain);

    在连续内存块中分配多个大小为 elem_size 的元素. 最少分配数量为 min_elements, 首选和最大数量为 preferred_elements. 实际分配的元素数量将被赋给 received_size. 这些元素必须用 deallocate(...) 释放 该函数已弃用, 未来将被移除

  19. pointer allocate_one();

    仅分配一个对象. 用此函数分配的内存只能用 deallocate_one() 释放. 如果没有足够的内存, 抛出 boost::interprocess::bad_alloc 

  20. void allocate_individual(size_type num_elements, 
                         multiallocation_chain & chain);

    在连续内存块中分配多个大小 == 1 的元素. 最少分配数量为 min_elements, 首选和最大数量为 preferred_elements. 实际分配的元素数量将被赋给 received_size. 用此函数分配的内存只能用 deallocate_one() 释放.

  21. void deallocate_one(const pointer & p);

    释放先前用 allocate_one() 分配的内存. 切勿使用 deallocate_one 释放用 allocate_one() 以外其他函数分配的内存. 从不抛出异常

  22. void deallocate_individual(multiallocation_chain & chain);

    在连续内存块中分配多个大小 == 1 的元素. 最少分配数量为 min_elements, 首选和最大数量为 preferred_elements. 实际分配的元素数量将被赋给 received_size. 用此函数分配的内存只能用 deallocate_one() 释放.

private_node_allocator 友元函数

  1. void swap(self_t & alloc1, self_t & alloc2);

    交换分配器. 不抛出异常. 若两个分配器位于不同的内存段, 则结果未定义.
