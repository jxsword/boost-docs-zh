类 interprocess_semaphore

boost::interprocess::interprocess_semaphore

概要

// In header: <boost/interprocess/sync/interprocess_semaphore.hpp>


class interprocess_semaphore {
public:

  // public member functions
  interprocess_semaphore(unsigned int);
  ~interprocess_semaphore();
  void post();
  void wait();
  bool try_wait();
  template<typename TimePoint> bool timed_wait(const TimePoint &);
};

说明

封装一个可放置在共享内存中、可在进程间共享的 interprocess_semaphore. 允许限时加锁尝试

interprocess_semaphore 公有成员函数

  1. interprocess_semaphore(unsigned int initialCount);

    以给定的初始计数创建一个 interprocess_semaphore. 出错时抛出 interprocess_exception. *<zwj></zwj>/

  2. ~interprocess_semaphore();

    销毁 interprocess_semaphore. 不抛出异常

  3. void post();

    递增 interprocess_semaphore 的计数. 若有进程/线程因等待 interprocess_semaphore 而被阻塞, 则其中一个进程将从其等待函数中成功返回. 出错时抛出 interprocess_exception 异常.

  4. void wait();

    递减 interprocess_semaphore. 若 interprocess_semaphore 的值不大于零, 则调用进程/线程阻塞, 直到能够递减该计数. 出错时抛出 interprocess_exception 异常.

  5. bool try_wait();

    若 interprocess_semaphore 的值大于零, 则递减 interprocess_semaphore 并返回 true. 若值不大于零则返回 false. 出错时抛出 interprocess_exception 异常.

  6. template<typename TimePoint> bool timed_wait(const TimePoint & abs_time);

    若 interprocess_semaphore 的值大于零, 则递减 interprocess_semaphore 并返回 true. 否则, 等待 interprocess_semaphore 被释放或超时. 若超时, 函数返回 false. 若 interprocess_semaphore 被释放, 函数返回 true. 出错时抛出 sem_exception
