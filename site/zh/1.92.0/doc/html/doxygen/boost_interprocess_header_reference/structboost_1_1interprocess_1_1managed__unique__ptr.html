结构模板 managed_unique_ptr

boost::interprocess::managed_unique_ptr

概要

// In header: <boost/interprocess/smart_ptr/unique_ptr.hpp>

template<typename T, typename ManagedMemory> 
struct managed_unique_ptr {
  // types
  typedef boost::movelib::unique_ptr< T, typename ManagedMemory::template deleter< T >::type > type;
};

说明

返回可在给定托管段类型中构造的类型 T 唯一指针的类型, 使用 boost::interprocess::deleter 删除器.
