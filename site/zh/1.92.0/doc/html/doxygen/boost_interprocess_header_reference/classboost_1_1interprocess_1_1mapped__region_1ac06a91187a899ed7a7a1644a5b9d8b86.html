类型 advice_types

boost::interprocess::mapped_region::advice_types

概要

// In header: <boost/interprocess/mapped_region.hpp>


enum advice_types { advice_normal, advice_sequential, advice_random, 
                    advice_willneed, advice_dontneed };

说明

此枚举指定应用程序可向映射区域实现声明的区域使用行为.

advice_normal

指定应用程序对区域的使用行为没有任何建议. 若未对一段内存给出建议, 这是默认特征.

advice_sequential

指定应用程序期望从低地址到高地址顺序访问区域. 一旦某个页被访问, 实现可以降低该区域内其前面各页的优先级.

advice_random

指定应用程序期望以随机顺序访问区域, 预取可能没有好处.

advice_willneed

指定应用程序期望在近期访问区域. 实现可以预取区域内的页.

advice_dontneed

指定应用程序期望在近期不会访问区域. 实现可以卸载该范围内的页以节省系统资源.
