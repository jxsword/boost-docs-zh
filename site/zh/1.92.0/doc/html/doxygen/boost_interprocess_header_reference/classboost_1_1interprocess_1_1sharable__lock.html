类模板 sharable_lock

boost::interprocess::sharable_lock

概要

// In header: <boost/interprocess/sync/sharable_lock.hpp>

template<typename SharableMutex> 
class sharable_lock {
public:
  // types
  typedef SharableMutex mutex_type;

  // public member functions
  sharable_lock() noexcept;
  explicit sharable_lock(mutex_type &);
  sharable_lock(mutex_type &, defer_lock_type);
  sharable_lock(mutex_type &, accept_ownership_type);
  sharable_lock(mutex_type &, try_to_lock_type);
  template<typename TimePoint> sharable_lock(mutex_type &, const TimePoint &);
  sharable_lock(sharable_lock< mutex_type > &&) noexcept;
  template<typename T> sharable_lock(upgradable_lock< T > &&, unspecified = 0);
  template<typename T> sharable_lock(scoped_lock< T > &&, unspecified = 0);
  ~sharable_lock();
  sharable_lock & operator=(sharable_lock< mutex_type > &&);
  void lock();
  bool try_lock();
  template<typename TimePoint> bool timed_lock(const TimePoint &);
  template<typename TimePoint> bool try_lock_until(const TimePoint &);
  template<typename Duration> bool try_lock_for(const Duration &);
  void unlock();
  bool owns() const noexcept;
  operator unspecified_bool_type() const noexcept;
  mutex_type * mutex() const noexcept;
  mutex_type * release() noexcept;
  void swap(sharable_lock< mutex_type > &) noexcept;
};

说明

sharable_lock 旨在为 Mutex 执行共享加锁 (如读锁)、解锁、尝试共享加锁和限时共享加锁 (递归与否) 等任务. Mutex 无需提供所有这些功能. 若 sharable_lock<Mutex> 的使用者未使用 Mutex 不提供的功能, 不会有任何影响. 互斥量所有权可在多个 sharable_lock 之间共享, 也可与单个 upgradable_lock 共享. sharable_lock 不支持复制语义. 但 sharable_lock 支持通过 transfer_lock 语法从 sharable_lock、upgradable_lock 和 scoped_lock 转移所有权. *<zwj></zwj>/

sharable_lock 公有成员函数

  1. sharable_lock() noexcept;

    效果: 默认构造一个 sharable_lock. 后置条件: owns() == false 且 mutex() == 0.

  2. explicit sharable_lock(mutex_type & m);

    效果: m.lock_sharable(). 后置条件: owns() == true 且 mutex() == &m. 注释: 该构造函数将取得互斥量的共享所有权. 若另一线程已以独占所有权 (scoped_lock) 拥有该互斥量, 此线程将阻塞直到互斥量被释放. 若另一线程以共享或可升级所有权拥有该互斥量, 则不会阻塞. 此构造函数是否处理递归加锁取决于互斥量.

  3. sharable_lock(mutex_type & m, defer_lock_type);

    后置条件: owns() == false 且 mutex() == &m. 注释: 该构造函数不会取得互斥量的所有权. 对被引用的互斥量不产生任何影响.

  4. sharable_lock(mutex_type & m, accept_ownership_type);

    后置条件: owns() == true 且 mutex() == &m. 注释: 该构造函数假定互斥量已被共享锁定. 对被引用的互斥量不产生任何影响.

  5. sharable_lock(mutex_type & m, try_to_lock_type);

    效果: m.try_lock_sharable() 后置条件: mutex() == &m, owns() == 构造函数内执行的 m.try_lock_sharable() 的返回值. 注释: 若无需等待即可取得互斥量的共享所有权, 该构造函数将取得所有权. 此构造函数是否处理递归加锁取决于互斥量. 若 mutex_type 不支持 try_lock_sharable, 实例化此构造函数将在编译期失败, 但除此之外没有影响.

  6. template<typename TimePoint> 
  sharable_lock(mutex_type & m, const TimePoint & abs_time);

    效果: m.timed_lock_sharable(abs_time) 后置条件: mutex() == &m, owns() == 构造函数内执行的 m.timed_lock_sharable() 的返回值. 注释: 若能在指定时间内取得互斥量的共享所有权, 该构造函数将取得所有权. 此构造函数是否处理递归加锁取决于互斥量. 若 mutex_type 不支持 timed_lock_sharable, 实例化此构造函数将在编译期失败, 但除此之外没有影响.

  7. sharable_lock(sharable_lock< mutex_type > && upgr) noexcept;

    后置条件: mutex() == upgr.mutex(), owns() == 构造前 upgr.owns() 的值, 构造后 upgr.owns() == false. 注释: 若 upgr sharable_lock 拥有该互斥量, 所有权将以无阻塞方式移交给此 sharable_lock; 若 upgr sharable_lock 不拥有该互斥量, 此 sharable_lock 也不拥有. 只有移动构造的 sharable_lock 才匹配此签名. 未移动的 sharable_lock 可通过表达式 "boost::move(lock);" 移动. 此构造函数不改变互斥量的状态, 只可能改变其拥有者.

  8. template<typename T> 
  sharable_lock(upgradable_lock< T > && upgr, unspecified = 0);

    效果: 若 upgr.owns() 为真, 则对被引用的互斥量调用 unlock_upgradable_and_lock_sharable(). 后置条件: mutex() == 构造前 upgr.mutex() 的值, upgr.mutex() == 0, owns() == 构造前 upgr.owns() 的值, 构造后 upgr.owns() == false. 注释: 若 upgr 已锁定, 此构造函数将在解锁 upgr 的同时锁定此 sharable_lock. 只有移动构造的 sharable_lock 才匹配此签名. 未移动的 upgradable_lock 可通过表达式 "boost::move(lock);" 移动. *<zwj></zwj>/

  9. template<typename T> sharable_lock(scoped_lock< T > && scop, unspecified = 0);

    效果: 若 scop.owns() 为真, 则对被引用的互斥量调用 unlock_and_lock_sharable(). 后置条件: mutex() == 构造前 scop.mutex() 的值, scop.mutex() == 0, owns() == 构造前 scop.owns() 的值, 构造后 scop.owns() == false. 注释: 若 scop 已锁定, 此构造函数将把独占所有权转移为此 sharable_lock 的共享所有权. 只有移动构造的 scoped_lock 才匹配此签名. 未移动的 scoped_lock 可通过表达式 "boost::move(lock);" 移动.

  10. ~sharable_lock();

    效果: 若 (owns()) 则 mp_mutex->unlock_sharable(). 注释: 析构行为确保互斥量锁不被泄漏.

  11. sharable_lock & operator=(sharable_lock< mutex_type > && upgr);

    效果: 若调用前 owns() 为真, 则对 mutex() 调用 unlock_sharable(). *this 获得 upgr 的状态, upgr 被置为默认构造状态. 注释: 对于递归互斥量, 赋值前 this 与 upgr 可能同时拥有该互斥量. 此时赋值后 this 仍拥有该互斥量 (而 upgr 不拥有), 但互斥量的锁定计数会减一.

  12. void lock();

    效果: 若 mutex() == 0 或已锁定, 则抛出 lock_exception() 异常. 对被引用的互斥量调用 lock_sharable(). 后置条件: owns() == true. 注释: sharable_lock 从不拥有互斥量的状态变为拥有互斥量的状态, 必要时阻塞.

  13. bool try_lock();

    效果: 若 mutex() == 0 或已锁定, 则抛出 lock_exception() 异常. 对被引用的互斥量调用 try_lock_sharable(). 后置条件: owns() == mutex()->try_lock_sharable() 的返回值. 注释: sharable_lock 从不拥有互斥量的状态变为拥有互斥量的状态, 但前提是不需要阻塞. 若 mutex_type 不支持 try_lock_sharable(), 实例化此函数将在编译期失败, 但除此之外没有影响.

  14. template<typename TimePoint> bool timed_lock(const TimePoint & abs_time);

    效果: 若 mutex() == 0 或已锁定, 则抛出 lock_exception() 异常. 对被引用的互斥量调用 timed_lock_sharable(abs_time). 后置条件: owns() == mutex()->timed_lock_sharable(elps_time) 的返回值. 注释: sharable_lock 从不拥有互斥量的状态变为拥有互斥量的状态, 但前提是能在指定时间间隔内取得所有权. 若 mutex_type 不支持 timed_lock_sharable(), 实例化此函数将在编译期失败, 但除此之外没有影响.

  15. template<typename TimePoint> bool try_lock_until(const TimePoint & abs_time);

    效果: 若 mutex() == 0 或已锁定, 则抛出 lock_exception() 异常. 对被引用的互斥量调用 try_lock_shared_until(abs_time). 后置条件: owns() == mutex()->timed_lock_sharable(elps_time) 的返回值. 注释: sharable_lock 从不拥有互斥量的状态变为拥有互斥量的状态, 但前提是能在指定时间间隔内取得所有权. 若 mutex_type 不支持 timed_lock_sharable(), 实例化此函数将在编译期失败, 但除此之外没有影响.

    注释: 类似于 timed_lock, 但采用类 std 接口

  16. template<typename Duration> bool try_lock_for(const Duration & dur);

    效果: 若 mutex() == 0 或已锁定, 则抛出 lock_exception() 异常. 对被引用的互斥量调用 try_lock_shared_until(abs_time). 后置条件: owns() == mutex()->timed_lock_sharable(elps_time) 的返回值. 注释: sharable_lock 从不拥有互斥量的状态变为拥有互斥量的状态, 但前提是能在指定时间间隔内取得所有权. 若 mutex_type 不支持 timed_lock_sharable(), 实例化此函数将在编译期失败, 但除此之外没有影响.

    注释: 类似于 timed_lock, 但采用类 std 接口

  17. void unlock();

    效果: 若 mutex() == 0 或未锁定, 则抛出 lock_exception() 异常. 对被引用的互斥量调用 unlock_sharable(). 后置条件: owns() == false. 注释: sharable_lock 从拥有互斥量的状态变为不拥有互斥量的状态.

  18. bool owns() const noexcept;

    效果: 若此 scoped_lock 已获得被引用的互斥量, 则返回 true.

  19. operator unspecified_bool_type() const noexcept;

    转换为 bool. 返回 owns().

  20. mutex_type * mutex() const noexcept;

    效果: 返回指向被引用互斥量的指针, 若没有可引用的互斥量则返回 0.

  21. mutex_type * release() noexcept;

    效果: 返回指向被引用互斥量的指针, 若没有可引用的互斥量则返回 0. 后置条件: mutex() == 0 且 owns() == false.

  22. void swap(sharable_lock< mutex_type > & other) noexcept;

    效果: 与被移动的锁交换状态. 抛出: 无.
