类模板 segment_manager_base

boost::interprocess::segment_manager_base

概要

// In header: <boost/interprocess/segment_manager.hpp>

template<typename MemoryAlgorithm> 
class segment_manager_base : private MemoryAlgorithm {
public:
  // types
  typedef segment_manager_base< MemoryAlgorithm > segment_manager_base_type;
  typedef MemoryAlgorithm::void_pointer           void_pointer;             
  typedef MemoryAlgorithm::mutex_family           mutex_family;             
  typedef MemoryAlgorithm                         memory_algorithm;         

  // public member functions
  segment_manager_base(size_type, size_type);
  size_type get_size() const;
  size_type get_free_memory() const;
  void * allocate(size_type, const std::nothrow_t &);
  void * allocate(size_type);
  void * allocate_aligned(size_type, size_type, const std::nothrow_t &);
  void * allocate_aligned(size_type, size_type);
  void deallocate(void *);
  void grow(size_type);
  void shrink_to_fit();
  bool all_memory_deallocated();
  bool check_sanity();
  void zero_free_memory();
  size_type size(const void *) const;
  MemoryAlgorithm & get_memory_algorithm();
  const MemoryAlgorithm & get_memory_algorithm() const;

  // public static functions
  static size_type get_min_size(size_type);

  // public data members
  static const std::size_t MemAlignment;
  static const size_type PayloadPerAllocation;
};

说明

此对象是段管理器的公开基类. 此类只依赖于内存分配算法, 实现所有与命名或唯一对象无关的分配功能.

存储指向 segment_manager 的引用会使持有类依赖于索引类型和字符类型. 当不希望这种依赖且只需要匿名与原始内存分配时, segment_manager_base 是正确选择.

segment_manager_base 公有成员函数

  1. segment_manager_base(size_type sz, size_type reserved_bytes);

    构造函数 segment_manager_base

    "size" 是正在构造基本段管理器的内存段的大小.

    "reserved_bytes" 是内存算法对象自身末尾之后的字节数, 内存算法将把这些字节排除在动态分配之外

    可能抛出异常

  2. size_type get_size() const;

    返回内存段的大小

  3. size_type get_free_memory() const;

    返回内存段的空闲字节数

  4. void * allocate(size_type nbytes, const std::nothrow_t &);

    分配 nbytes 字节. 此函数仅用于单段管理. 绝不抛出异常

  5. void * allocate(size_type nbytes);

    分配 nbytes 字节. 失败时抛出 boost::interprocess::bad_alloc 

  6. void * allocate_aligned(size_type nbytes, size_type alignment, 
                        const std::nothrow_t &);

    分配 nbytes 字节. 此函数仅用于单段管理. 绝不抛出异常

  7. void * allocate_aligned(size_type nbytes, size_type alignment);

    分配 nbytes 字节. 此函数仅用于单段管理. 失败时抛出 bad_alloc 

  8. void deallocate(void * addr);

    释放 addr 指向的、用 allocate/allocate_aligned() 分配的字节

  9. void grow(size_type extra_size);

    把托管内存增加 extra_size 字节. 这只适用于单段管理.

  10. void shrink_to_fit();

    把托管内存减少到最小. 这只适用于单段管理.

  11. bool all_memory_deallocated();

    返回所用内存算法的 "all_memory_deallocated()" 函数的结果

  12. bool check_sanity();

    返回所用内存算法的 "check_sanity()" 函数的结果

  13. void zero_free_memory();

    把内存算法的空闲内存 (尚未分配的内存) 写零

  14. size_type size(const void * ptr) const;
    返回 ptr 指向的先前分配缓冲区的大小.
  15. MemoryAlgorithm & get_memory_algorithm();

    返回内部内存算法的引用. 此函数适用于构造后需要额外配置选项的自定义内存算法. 绝不抛出异常. 此函数只应由高级用户使用.

  16. const MemoryAlgorithm & get_memory_algorithm() const;

    返回内部内存算法的 const 引用. 此函数适用于构造后需要额外配置选项的自定义内存算法. 绝不抛出异常. 此函数只应由高级用户使用.

segment_manager_base 公有静态函数

  1. static size_type get_min_size(size_type size);

    获得段管理器所需的最小大小

segment_manager_base 公有数据成员

  1. static const size_type PayloadPerAllocation;

    此常量指示内存算法每次分配所关联的有效载荷大小
