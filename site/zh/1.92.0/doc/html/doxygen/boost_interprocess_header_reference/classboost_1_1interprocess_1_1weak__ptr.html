类模板 weak_ptr

boost::interprocess::weak_ptr

概要

// In header: <boost/interprocess/smart_ptr/weak_ptr.hpp>

template<typename T, typename A, typename D> 
class weak_ptr {
public:
  // types
  typedef T element_type;
  typedef T value_type;  

  // public member functions
  weak_ptr();
  template<typename Y> weak_ptr(weak_ptr< Y, A, D > const &);
  template<typename Y> weak_ptr(shared_ptr< Y, A, D > const &);
  template<typename Y> weak_ptr & operator=(weak_ptr< Y, A, D > const &);
  template<typename Y> weak_ptr & operator=(shared_ptr< Y, A, D > const &);
  shared_ptr< T, A, D > lock() const;
  long use_count() const;
  bool expired() const;
  void reset();
  void swap(this_type &);
};

说明

weak_ptr 类模板存储对已由 shared_ptr 管理的对象的 "弱引用". 要访问该对象, 可以使用 shared_ptr 构造函数或成员函数 lock 把 weak_ptr 转换为 shared_ptr. 当指向该对象的最后一个 shared_ptr 消失且对象被删除后, 从引用已删除对象的 weak_ptr 实例获取 shared_ptr 的尝试将失败: 构造函数将抛出 bad_weak_ptr 类型的异常, weak_ptr::lock 将返回空的 shared_ptr.

每个 weak_ptr 都满足 C++ 标准库的 CopyConstructible 和 Assignable 要求, 因此可以在标准库容器中使用. 比较运算符也已提供, 使 weak_ptr 可用于标准库的关联容器.

weak_ptr 的操作绝不抛出异常.

类模板以 T (被指向对象的类型) 为模板参数.

weak_ptr 公有成员函数

  1. weak_ptr();

    效果: 构造一个空的 weak_ptr. 后置条件: use_count() == 0.

  2. template<typename Y> weak_ptr(weak_ptr< Y, A, D > const & r);

    效果: 若 r 为空, 则构造一个空的 weak_ptr; 否则构造一个与 r 共享所有权的 weak_ptr, 如同存储 r 中指针的副本一样.

    后置条件: use_count() == r.use_count().

    抛出: 无.

  3. template<typename Y> weak_ptr(shared_ptr< Y, A, D > const & r);

    效果: 若 r 为空, 则构造一个空的 weak_ptr; 否则构造一个与 r 共享所有权的 weak_ptr, 如同存储 r 中指针的副本一样.

    后置条件: use_count() == r.use_count().

    抛出: 无.

  4. template<typename Y> weak_ptr & operator=(weak_ptr< Y, A, D > const & r);

    效果: 等价于 weak_ptr(r).swap(*this).

    抛出: 无.

    注释: 实现可以通过不同方式满足这些效果 (及其隐含保证), 而不创建临时对象.

  5. template<typename Y> weak_ptr & operator=(shared_ptr< Y, A, D > const & r);

    效果: 等价于 weak_ptr(r).swap(*this).

    抛出: 无.

    注释: 实现可以通过不同方式满足这些效果 (及其隐含保证), 而不创建临时对象.

  6. shared_ptr< T, A, D > lock() const;

    返回: expired() ? shared_ptr<T>() : shared_ptr<T>(*this).

    抛出: 无.

  7. long use_count() const;

    返回: 若 *this 为空则为 0; 否则为与 *this 共享所有权的 shared_ptr 对象数量.

    抛出: 无.

    注释: use_count() 不一定高效. 只用于调试和测试目的, 不要用于生产代码.

  8. bool expired() const;

    返回: use_count() == 0.

    抛出: 无.

    注释: expired() 可能比 use_count() 更快.

  9. void reset();

    效果: 等价于: weak_ptr().swap(*this).

  10. void swap(this_type & other);

    效果: 交换两个智能指针的内容.

    抛出: 无.
