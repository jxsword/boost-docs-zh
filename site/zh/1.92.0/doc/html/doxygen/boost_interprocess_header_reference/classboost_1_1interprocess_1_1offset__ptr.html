boost::interprocess::offset_ptr

说明

一种存储指针与其所指向对象之间偏移量的智能指针. 由于指针与被指向对象的地址无关, 只要指针与被指向对象仍相隔相同的偏移量即可, 因此具有特殊性质. 该特性使 offset_ptr 成为一种可放置在共享内存以及在每个进程映射到不同地址的内存映射文件中的智能指针.

b>注释: 出于性能原因, offset_ptr 使用大多数平台上都存在的实现定义特性:

  • 假定 nullptr 的 OffsetType 表示为 (OffsetType)零.

  • 假定对从指针获得的 OffsetType 执行递增等价于先递增指针再将其转换回 OffsetType.

模板参数

  1. typename PointedType

    被指向对象的类型.

  2. typename DifferenceType

    能够表示对指针进行算术运算的有符号整数类型

  3. typename OffsetType

    能够表示两个指针经 reinterpret_cast 转为无符号整数后的距离的无符号整数类型. 该类型应至少与 std::uintptr_t 大小相同. 在某些系统上, 使用 64 位偏移量可以在 32 位与 64 位进程之间通信.

  4. std::size_t OffsetAlignment

    内部存储的 OffsetType 的对齐. 在某些系统上, 可能需要将其对齐到 64 位, 以便使用 64 位偏移量在 32 位与 64 位进程之间通信.
