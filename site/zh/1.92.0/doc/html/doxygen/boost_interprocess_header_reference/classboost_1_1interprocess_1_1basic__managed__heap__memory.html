类模板 basic_managed_heap_memory

boost::interprocess::basic_managed_heap_memory

概要

// In header: <boost/interprocess/managed_heap_memory.hpp>

template<typename CharType, typename AllocationAlgorithm, 
         template< class IndexConfig > class IndexType> 
class basic_managed_heap_memory {
public:
  // types
  typedef base_t::size_type size_type;

  // public member functions
  basic_managed_heap_memory() noexcept;
  ~basic_managed_heap_memory();
  basic_managed_heap_memory(size_type);
  basic_managed_heap_memory(basic_managed_heap_memory &&) noexcept;
  basic_managed_heap_memory & operator=(basic_managed_heap_memory &&) noexcept;
  bool grow(size_type);
  void swap(basic_managed_heap_memory &) noexcept;
};

说明

一种基础的堆内存命名对象创建类. 初始化堆内存段. 从 basic_managed_memory_impl<CharType, AllocationAlgorithm, IndexType>*<zwj></zwj>/ 继承所有基本功能

basic_managed_heap_memory 公有成员函数

  1. basic_managed_heap_memory() noexcept;

    默认构造函数. 不做任何事. 与移动语义结合使用时很有用

  2. ~basic_managed_heap_memory();

    析构函数. 释放持有托管数据的堆内存. 绝不抛出异常.

  3. basic_managed_heap_memory(size_type size);

    创建堆内存并初始化段管理器. 这可能抛出异常.

  4. basic_managed_heap_memory(basic_managed_heap_memory && moved) noexcept;
    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常.
  5. basic_managed_heap_memory & 
operator=(basic_managed_heap_memory && moved) noexcept;
    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常.
  6. bool grow(size_type extra_bytes);

    尝试调整内部堆内存的大小, 以便为更多对象腾出空间. 警告: 如果内存被重新分配, 所有对象将被二进制复制到新缓冲区. 要使用此函数, 在此缓冲区中构造的所有指针必须是偏移指针, 否则结果未定义. 如果增长成功则返回 true, 这样就有一些额外的字节可用于分配新对象. 如果返回 false, 则堆内存分配失败.

  7. void swap(basic_managed_heap_memory & other) noexcept;

    交换 *this 与 other 所管理的托管堆内存的所有权. 绝不抛出异常.
