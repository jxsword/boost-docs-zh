类 xsi_shared_memory

boost::interprocess::xsi_shared_memory

概要

// In header: <boost/interprocess/xsi_shared_memory.hpp>


class xsi_shared_memory {
public:

  // public member functions
  xsi_shared_memory() noexcept;
  xsi_shared_memory(open_only_t, int);
  xsi_shared_memory(create_only_t, const xsi_key &, std::size_t, 
                    const permissions & = permissions());
  xsi_shared_memory(open_or_create_t, const xsi_key &, std::size_t, 
                    const permissions & = permissions());
  xsi_shared_memory(open_only_t, const xsi_key &);
  xsi_shared_memory(xsi_shared_memory &&) noexcept;
  xsi_shared_memory & operator=(xsi_shared_memory &&) noexcept;
  void swap(xsi_shared_memory &) noexcept;
  ~xsi_shared_memory();
  int get_shmid() const noexcept;
  mapping_handle_t get_mapping_handle() const noexcept;

  // public static functions
  static bool remove(int);
};

说明

一种封装 XSI (System V) 共享内存的类. 与 shared_memory_object 不同, xsi_shared_memory 需要一个有效的 xsi_key 来标识共享内存对象.

警告: XSI 共享内存与进程间可移植共享内存 (boost::interprocess::shared_memory_object) 之间无法相互通信.

xsi_shared_memory 公有成员函数

  1. xsi_shared_memory() noexcept;

    默认构造函数. 表示一个空的 xsi_shared_memory.

  2. xsi_shared_memory(open_only_t, int shmid);

    用先前获得的 shmid (可能来自另一进程) 初始化 *this. 这种较低层级的初始化方式允许在没有键的情况下映射共享内存.

  3. xsi_shared_memory(create_only_t, const xsi_key & key, std::size_t size, 
                  const permissions & perm = permissions());

    从 'key' 创建大小为 "size"、权限为 "perm" 的新 XSI 共享内存. 若共享内存先前已存在, 则抛出错误.

  4. xsi_shared_memory(open_or_create_t, const xsi_key & key, std::size_t size, 
                  const permissions & perm = permissions());

    用标识符 'key' 打开现有共享内存, 或从标识符 'key' 创建大小为 "size"、权限为 "perm" 的新 XSI 共享内存.

  5. xsi_shared_memory(open_only_t, const xsi_key & key);

    尝试用标识符 'key' 打开 XSI 共享内存. 若共享内存先前不存在, 则抛出错误.

  6. xsi_shared_memory(xsi_shared_memory && moved) noexcept;

    将 "moved" 的共享内存对象所有权移交给 *this. 调用后, "moved" 不再表示任何共享内存对象. 不抛出异常

  7. xsi_shared_memory & operator=(xsi_shared_memory && moved) noexcept;

    将 "moved" 的共享内存所有权移交给 *this. 调用后, "moved" 不再表示任何共享内存. 不抛出异常

  8. void swap(xsi_shared_memory & other) noexcept;
    交换两个 xsi_shared_memory. 不抛出异常.
  9. ~xsi_shared_memory();

    销毁 *this. 共享内存不会被销毁, 只是断开此连接. 请使用 remove() 销毁共享内存.

  10. int get_shmid() const noexcept;

    返回标识共享内存的共享内存 ID

  11. mapping_handle_t get_mapping_handle() const noexcept;

    返回映射句柄. 绝不抛出异常

xsi_shared_memory 公有静态函数

  1. static bool remove(int shmid);

    从系统中擦除由 shmid 标识的 XSI 共享内存对象. 出错时返回 false. 绝不抛出异常
