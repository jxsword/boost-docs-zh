类 interprocess_condition

boost::interprocess::interprocess_condition

概要

// In header: <boost/interprocess/sync/interprocess_condition.hpp>


class interprocess_condition {
public:

  // public member functions
  interprocess_condition();
  ~interprocess_condition();
  void notify_one();
  void notify_all();
  template<typename L> void wait(L &);
  template<typename L, typename Pr> void wait(L &, Pr);
  template<typename L, typename TimePoint> 
    bool timed_wait(L &, const TimePoint &);
  template<typename L, typename TimePoint, typename Pr> 
    bool timed_wait(L &, const TimePoint &, Pr);
  template<typename L, typename TimePoint> 
    cv_status wait_until(L &, const TimePoint &);
  template<typename L, typename TimePoint, typename Pr> 
    bool wait_until(L &, const TimePoint &, Pr);
  template<typename L, typename Duration> 
    cv_status wait_for(L &, const Duration &);
  template<typename L, typename Duration, typename Pr> 
    bool wait_for(L &, const Duration &, Pr);
};

说明

此类是一个可放置在共享内存或内存映射文件中的条件变量. 销毁 std::condition_variable_any 类型的对象

与 C++11 的 std::condition_variable 不同, 若所有线程仅被通知而尚未退出各自的等待函数, 则调用析构函数是不安全的. 要求它们已退出各自的等待函数.

interprocess_condition 公有成员函数

  1. interprocess_condition();
    构造一个 interprocess_condition. 出错时抛出 interprocess_exception.
  2. ~interprocess_condition();

    销毁 *this 并释放系统资源.

  3. void notify_one();

    若有线程正在 *this 上等待, 则将该线程状态改为就绪; 否则没有任何效果.

  4. void notify_all();

    将所有在 *this 上等待的线程状态改为就绪. 若没有等待的线程, notify_all() 没有任何效果.

  5. template<typename L> void wait(L & lock);

    释放与 lock 关联的 interprocess_mutex 对象上的锁, 阻塞当前执行线程, 直到被对 this->notify_one() 或 this->notify_all() 的调用唤醒, 然后重新获取该锁.

  6. template<typename L, typename Pr> void wait(L & lock, Pr pred);

    等价于: while (!pred()) wait(lock)

  7. template<typename L, typename TimePoint> 
  bool timed_wait(L & lock, const TimePoint & abs_time);

    释放与 lock 关联的 interprocess_mutex 对象上的锁, 阻塞当前执行线程, 直到被对 this->notify_one() 或 this->notify_all() 的调用唤醒, 或到达时间 abs_time, 然后重新获取该锁. 返回: 若到达时间 abs_time 则为 false, 否则为 true.

  8. template<typename L, typename TimePoint, typename Pr> 
  bool timed_wait(L & lock, const TimePoint & abs_time, Pr pred);

    等价于: while (!pred()) { if (!timed_wait(lock, abs_time)) return pred(); } return true;

  9. template<typename L, typename TimePoint> 
  cv_status wait_until(L & lock, const TimePoint & abs_time);

    与 timed_wait 相同, 但此函数仿照标准库接口设计.

  10. template<typename L, typename TimePoint, typename Pr> 
  bool wait_until(L & lock, const TimePoint & abs_time, Pr pred);

    与 timed_wait 相同, 但此函数仿照标准库接口设计.

  11. template<typename L, typename Duration> 
  cv_status wait_for(L & lock, const Duration & dur);

    与 timed_wait 相同, 但此函数仿照标准库接口设计并使用相对超时.

  12. template<typename L, typename Duration, typename Pr> 
  bool wait_for(L & lock, const Duration & dur, Pr pred);

    与 timed_wait 相同, 但此函数仿照标准库接口设计并使用相对超时
