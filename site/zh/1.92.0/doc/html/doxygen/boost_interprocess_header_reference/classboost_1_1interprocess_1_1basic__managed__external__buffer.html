boost::interprocess::basic_managed_external_buffer

概要

// In header: <boost/interprocess/managed_external_buffer.hpp>

template<typename CharType, typename AllocationAlgorithm, 
         template< class IndexConfig > class IndexType> 
class basic_managed_external_buffer {
public:
  // types
  typedef base_t::size_type size_type;

  // public member functions
  basic_managed_external_buffer() noexcept;
  basic_managed_external_buffer(open_only_t, void *, size_type);
  basic_managed_external_buffer(basic_managed_external_buffer &&) noexcept;
  basic_managed_external_buffer &

  void grow(size_type);
  void swap(basic_managed_external_buffer &) noexcept;
};

说明

一种基础的用户内存命名对象创建类. 从 basic_managed_memory_impl<CharType, AllocationAlgorithm, IndexType>*<zwj></zwj>/ 继承所有基本功能

basic_managed_external_buffer 公有成员函数

  1. basic_managed_external_buffer() noexcept;

    默认构造函数. 不做任何事. 与移动语义结合使用时很有用

  2. basic_managed_external_buffer(open_only_t, void * addr, size_type size);

    创建并放置段管理器. 这可能抛出异常 用户提供的外部内存应对齐到 alignof(std::max_align_t) 与要在该内存内构造的任何超对齐类型的最严格对齐之间的最大值. basic_managed_external_buffer (create_only_t, void *addr, size_type size) { 检查对齐是否正确 BOOST_ASSERT((0 == (((std::size_t)addr) & (AllocationAlgorithm::Alignment - size_type(1u))))); if(!base_t::create_impl(addr, size)){ throw interprocess_exception("Could not initialize buffer in basic_managed_external_buffer constructor"); } }

    !创建并放置段管理器. 这可能抛出异常 !用户提供的外部内存应对齐到 alignof(std::max_align_t) 与要在该内存内构造的任何超对齐类型的最严格对齐之间的最大值.

  3. basic_managed_external_buffer(basic_managed_external_buffer && moved) noexcept;
    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常.
  4. basic_managed_external_buffer & 
operator=(basic_managed_external_buffer && moved) noexcept;
    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常.
  5. void grow(size_type extra_bytes);

    尝试调整内部堆内存的大小, 以便为更多对象腾出空间.

  6. void swap(basic_managed_external_buffer & other) noexcept;

    交换 *this 与 other 所管理的托管堆内存的所有权. 绝不抛出异常.
