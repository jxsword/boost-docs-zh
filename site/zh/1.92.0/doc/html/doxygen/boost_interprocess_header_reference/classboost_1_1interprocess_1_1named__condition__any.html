类 named_condition_any

boost::interprocess::named_condition_any

概要

// In header: <boost/interprocess/sync/named_condition_any.hpp>


class named_condition_any {
public:

  // public member functions
  named_condition_any(create_only_t, const char *, 
                      const permissions & = permissions());
  named_condition_any(open_or_create_t, const char *,

  named_condition_any(create_only_t, const wchar_t *,

  named_condition_any(open_or_create_t, const wchar_t *, 
                      const permissions & = permissions());

  void notify_one();
  void notify_all();
  template<typename L> void wait(L &);

说明

一种可按名称创建的全局条件变量. 此条件变量设计为与 named_mutex 一起使用, 不能放置在共享内存或内存映射文件中.

named_condition_any 公有成员函数

  1. named_condition_any(create_only_t, const char * name, 
                    const permissions & perm = permissions());

    以名称创建一个全局条件变量. 若无法创建该条件变量, 抛出 interprocess_exception 

  2. named_condition_any(open_or_create_t, const char * name, 
                    const permissions & perm = permissions());

    打开或创建具有名称的全局条件变量. 若创建该条件变量, 此调用等价于 named_condition_any(create_only_t, ... ); 若该条件变量已创建, 此调用等价于 named_condition_any(open_only_t, ... ). 不抛出异常

  3. named_condition_any(open_only_t, const char * name);

    若该条件变量先前已创建, 则以名称打开全局条件变量. 若先前未创建, 此函数抛出 interprocess_exception.

  4. named_condition_any(create_only_t, const wchar_t * name, 
                    const permissions & perm = permissions());

    以名称创建一个全局条件变量. 若无法创建该条件变量, 抛出 interprocess_exception

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  5. named_condition_any(open_or_create_t, const wchar_t * name, 
                    const permissions & perm = permissions());

    打开或创建具有名称的全局条件变量. 若创建该条件变量, 此调用等价于 named_condition_any(create_only_t, ... ); 若该条件变量已创建, 此调用等价于 named_condition_any(open_only_t, ... ). 不抛出异常

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  6. named_condition_any(open_only_t, const wchar_t * name);

    若该条件变量先前已创建, 则以名称打开全局条件变量. 若先前未创建, 此函数抛出 interprocess_exception.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  7. ~named_condition_any();

    销毁 *this 并指示调用进程已结束对该资源的使用. 析构函数将释放系统为该进程使用此资源而分配的所有系统资源. 之后仍可通过调用 open 构造函数重载再次打开该资源. 要从系统中擦除该资源, 请使用 remove().

  8. void notify_one();

    若有线程在 this 上等待, 则将该线程状态改为就绪; 否则没有任何效果. <zwj></zwj>/

  9. void notify_all();

    将所有在 *this 上等待的线程状态改为就绪. 若没有等待的线程, notify_all() 没有任何效果.

  10. template<typename L> void wait(L & lock);

    释放与 lock 关联的 named_mutex 对象上的锁, 阻塞当前执行线程, 直到被对 this->notify_one() 或 this->notify_all() 的调用唤醒, 然后重新获取该锁.

  11. template<typename L, typename Pr> void wait(L & lock, Pr pred);

    等价于: while (!pred()) wait(lock)

  12. template<typename L, typename TimePoint> 
  bool timed_wait(L & lock, const TimePoint & abs_time);

    释放与 lock 关联的 named_mutex 对象上的锁, 阻塞当前执行线程, 直到被对 this->notify_one() 或 this->notify_all() 的调用唤醒, 或到达时间 abs_time, 然后重新获取该锁. 返回: 若到达时间 abs_time 则为 false, 否则为 true.

  13. template<typename L, typename TimePoint, typename Pr> 
  bool timed_wait(L & lock, const TimePoint & abs_time, Pr pred);

    等价于: while (!pred()) { if (!timed_wait(lock, abs_time)) return pred(); } return true;

  14. template<typename L, typename TimePoint> 
  cv_status wait_until(L & lock, const TimePoint & abs_time);

    与 timed_wait 相同, 但此函数仿照标准库接口设计.

  15. template<typename L, typename TimePoint, typename Pr> 
  bool wait_until(L & lock, const TimePoint & abs_time, Pr pred);

    与 timed_wait 相同, 但此函数仿照标准库接口设计.

  16. template<typename L, typename Duration> 
  cv_status wait_for(L & lock, const Duration & dur);

    与 timed_wait 相同, 但此函数仿照标准库接口设计并使用相对超时.

  17. template<typename L, typename Duration, typename Pr> 
  bool wait_for(L & lock, const Duration & dur, Pr pred);

    与 timed_wait 相同, 但此函数仿照标准库接口设计并使用相对超时

named_condition_any 公有静态函数

  1. static bool remove(const char * name);

    从系统中擦除一个命名条件变量. 出错时返回 false. 绝不抛出异常.

  2. static bool remove(const wchar_t * name);

    从系统中擦除一个命名条件变量. 出错时返回 false. 绝不抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).
