类 xsi_key

boost::interprocess::xsi_key

概要

// In header: <boost/interprocess/xsi_key.hpp>


class xsi_key {
public:

  // public member functions
  xsi_key();
  explicit xsi_key(key_t);
  xsi_key(const char *, boost::uint8_t);
  key_t get_key() const;
};

说明

一种封装 XSI (System V) key_t 类型的类. 该类型用 ftok 从 path 和 id 计算 key_t、把 key 设为指定值, 或用默认构造函数把 key 设为 IPC_PRIVATE.

xsi_key 公有成员函数

  1. xsi_key();

    默认构造函数. 表示一个私有 xsi_key.

  2. explicit xsi_key(key_t key);
    用指定值创建新的 XSI key. 构造函数声明为 explicit 以避免与 shmid 的歧义.
  3. xsi_key(const char * path, boost::uint8_t id);

    用调用 ftok (使用路径 "path" 和 id "id") 获得的键创建大小为 "size"、权限为 "perm" 的新 XSI 共享内存. 若共享内存先前已存在, 则抛出错误.

  4. key_t get_key() const;
    返回内部 key_t 值.
