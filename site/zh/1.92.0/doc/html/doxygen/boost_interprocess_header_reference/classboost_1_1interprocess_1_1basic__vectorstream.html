类模板 basic_vectorstream

boost::interprocess::basic_vectorstream

概要

// In header: <boost/interprocess/streams/vectorstream.hpp>

template<typename CharVector, typename CharTraits> 
class basic_vectorstream :
  public std::basic_iostream< CharVector::value_type, CharTraits >
{
public:
  // types
  typedef CharVector                                                              vector_type;
  typedef std::basic_ios< typenameCharVector::value_type, CharTraits >::char_type char_type;  
  typedef std::basic_ios< char_type, CharTraits >::int_type                       int_type;   
  typedef std::basic_ios< char_type, CharTraits >::pos_type                       pos_type;   
  typedef std::basic_ios< char_type, CharTraits >::off_type                       off_type;   
  typedef std::basic_ios< char_type, CharTraits >::traits_type                    traits_type;

  // public member functions
  basic_vectorstream(std::ios_base::openmode = std::ios_base::in|std::ios_base::out);
  template<typename VectorParameter> 
    basic_vectorstream(const VectorParameter &, 
                       std::ios_base::openmode = std::ios_base::in|std::ios_base::out);
  basic_vectorbuf< CharVector, CharTraits > * rdbuf() const;
  void swap_vector(vector_type &);
  const vector_type & vector() const;
  void reserve(typename vector_type::size_type);
  void clear();
};

说明

一种 basic_iostream 类, 持有由 CharVector 模板参数指定的字符向量作为其格式化缓冲区. 该向量必须具有连续存储, 如 std::vector、boost::interprocess::vector 或 boost::interprocess::basic_string

basic_vectorstream 公有成员函数

  1. basic_vectorstream(std::ios_base::openmode mode = std::ios_base::in|std::ios_base::out);

    构造函数. 若 vector_type 的默认构造函数抛出异常, 则抛出异常.

  2. template<typename VectorParameter> 
  basic_vectorstream(const VectorParameter & param, 
                     std::ios_base::openmode mode = std::ios_base::in|std::ios_base::out);

    构造函数. 若 vector_type(const VectorParameter &param) 抛出异常, 则抛出异常.

  3. basic_vectorbuf< CharVector, CharTraits > * rdbuf() const;
  4. void swap_vector(vector_type & vect);

    将底层向量与传入的向量交换. 此函数会重置流中的读/写位置. 不抛出异常.

  5. const vector_type & vector() const;

    返回内部向量的 const 引用. 不抛出异常.

  6. void reserve(typename vector_type::size_type size);

    调用内部向量的 reserve() 方法. 将流重置到第一个位置. 若内部向量的 reserve 抛出异常, 则抛出异常.

  7. void clear();

    调用内部向量的 clear() 方法. 将流重置到第一个位置.
