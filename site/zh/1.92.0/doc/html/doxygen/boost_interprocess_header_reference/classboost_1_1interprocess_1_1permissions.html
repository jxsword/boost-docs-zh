类 permissions

boost::interprocess::permissions

概要

// In header: <boost/interprocess/permissions.hpp>


class permissions {
public:

  // public member functions
  permissions(os_permissions_type) noexcept;
  permissions() noexcept;
  void set_default() noexcept;
  void set_unrestricted() noexcept;
  void set_permissions(os_permissions_type) noexcept;
  os_permissions_type get_permissions() const noexcept;
};

说明

permissions 类表示要设置给共享内存或文件的权限, 可以用常见的权限表示来构造: Windows 上的 SECURITY_ATTRIBUTES 指针, 或 UNIX 上的 rwx chmod 按位或整数.

permissions 公有成员函数

  1. permissions(os_permissions_type type) noexcept;

    从用户提供的操作系统相关权限构造一个 permissions 对象.

  2. permissions() noexcept;

    构造默认 permissions 对象: Windows 上为空安全属性指针, UNIX 上为 0644.

  3. void set_default() noexcept;

    将权限设为默认值: Windows 上为空安全属性指针, UNIX 上为 0644.

  4. void set_unrestricted() noexcept;

    将权限设为不受限访问: Windows 上为空 DACL, UNIX 上为 0666.

  5. void set_permissions(os_permissions_type perm) noexcept;

    从用户提供的操作系统相关权限设置权限.

  6. os_permissions_type get_permissions() const noexcept;

    返回存储的操作系统相关权限
