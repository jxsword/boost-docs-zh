类 windows_shared_memory

boost::interprocess::windows_shared_memory

概要

// In header: <boost/interprocess/windows_shared_memory.hpp>


class windows_shared_memory {
public:

  // public member functions
  windows_shared_memory() noexcept;
  windows_shared_memory(create_only_t, const char *, mode_t, std::size_t, 
                        const permissions & = permissions());
  windows_shared_memory(open_or_create_t, const char *, mode_t, std::size_t, 
                        const permissions & = permissions());
  windows_shared_memory(open_only_t, const char *, mode_t);
  windows_shared_memory(create_only_t, const wchar_t *, mode_t, std::size_t, 
                        const permissions & = permissions());
  windows_shared_memory(open_or_create_t, const wchar_t *, mode_t, 
                        std::size_t, const permissions & = permissions());
  windows_shared_memory(open_only_t, const wchar_t *, mode_t);
  windows_shared_memory(windows_shared_memory &&) noexcept;
  windows_shared_memory & operator=(windows_shared_memory &&) noexcept;
  void swap(windows_shared_memory &) noexcept;
  ~windows_shared_memory();
  const char * get_name() const noexcept;
  mode_t get_mode() const noexcept;
  mapping_handle_t get_mapping_handle() const noexcept;
  offset_t get_size() const noexcept;
};

说明

一种封装原生 Windows 共享内存的类, 该共享内存实现为页面文件的文件映射. 与 shared_memory_object 不同, windows_shared_memory 没有内核持久性: 当所有进程销毁了用于同一共享内存的全部 windows_shared_memory 对象和映射区域, 或进程结束/崩溃时, 共享内存即被销毁.

警告: Windows 原生共享内存与进程间可移植共享内存 (boost::interprocess::shared_memory_object) 之间无法相互通信.

windows_shared_memory 公有成员函数

  1. windows_shared_memory() noexcept;

    默认构造函数. 表示一个空的 windows_shared_memory.

  2. windows_shared_memory(create_only_t, const char * name, mode_t mode, 
                      std::size_t size, 
                      const permissions & perm = permissions());

    以名称 "name" 创建至少大小为 "size" 的新原生共享内存, 访问模式为 "mode". 若文件先前已存在, 则抛出错误.

  3. windows_shared_memory(open_or_create_t, const char * name, mode_t mode, 
                      std::size_t size, 
                      const permissions & perm = permissions());

    尝试以名称 "name" 创建至少大小为 "size" 的共享内存对象, 访问模式为 "mode". 若文件先前已存在, 则尝试以 "mode" 模式打开它; 否则抛出错误.

  4. windows_shared_memory(open_only_t, const char * name, mode_t mode);

    尝试以名称 "name" 和访问模式 "mode" 打开共享内存对象. 若文件先前不存在, 则抛出错误.

  5. windows_shared_memory(create_only_t, const wchar_t * name, mode_t mode, 
                      std::size_t size, 
                      const permissions & perm = permissions());

    以名称 "name" 创建至少大小为 "size" 的新原生共享内存, 访问模式为 "mode". 若文件先前已存在, 则抛出错误.

  6. windows_shared_memory(open_or_create_t, const wchar_t * name, mode_t mode, 
                      std::size_t size, 
                      const permissions & perm = permissions());

    尝试以名称 "name" 创建至少大小为 "size" 的共享内存对象, 访问模式为 "mode". 若文件先前已存在, 则尝试以 "mode" 模式打开它; 否则抛出错误.

  7. windows_shared_memory(open_only_t, const wchar_t * name, mode_t mode);

    尝试以名称 "name" 和访问模式 "mode" 打开共享内存对象. 若文件先前不存在, 则抛出错误.

  8. windows_shared_memory(windows_shared_memory && moved) noexcept;

    将 "moved" 的共享内存对象所有权移交给 *this. 调用后, "moved" 不再表示任何共享内存对象. 不抛出异常

  9. windows_shared_memory & operator=(windows_shared_memory && moved) noexcept;

    将 "moved" 的共享内存所有权移交给 *this. 调用后, "moved" 不再表示任何共享内存. 不抛出异常

  10. void swap(windows_shared_memory & other) noexcept;
    交换两个 shared_memory_object. 不抛出异常.
  11. ~windows_shared_memory();

    销毁 *this. 销毁后所有映射区域仍然有效. 当引用该共享内存的所有映射区域和 windows_shared_memory 对象都被销毁时, 操作系统将销毁该共享内存.

  12. const char * get_name() const noexcept;
    返回共享内存的名称.
  13. mode_t get_mode() const noexcept;
    返回访问模式.
  14. mapping_handle_t get_mapping_handle() const noexcept;
    返回映射句柄. 绝不抛出异常.
  15. offset_t get_size() const noexcept;

    返回 Windows 共享内存的大小. 它是构造函数中传入的 "size" 按 4K 向上取整的大小.
