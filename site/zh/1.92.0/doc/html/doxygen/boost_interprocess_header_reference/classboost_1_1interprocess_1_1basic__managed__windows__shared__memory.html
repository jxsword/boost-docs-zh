类模板 basic_managed_windows_shared_memory

boost::interprocess::basic_managed_windows_shared_memory

概要

         template< class IndexConfig > class IndexType>

说明

一种基础的 Windows 托管共享内存创建类. 初始化共享内存段. 从 basic_managed_memory_impl<CharType, AllocationAlgorithm, IndexType> 继承所有基本功能 与 basic_managed_shared_memory 不同, 它没有内核持久性: 当所有进程销毁了用于同一共享内存的全部 windows_shared_memory 对象和映射区域, 或进程结束/崩溃时, 共享内存即被销毁.

警告: basic_managed_windows_shared_memory 与 basic_managed_shared_memory 之间无法相互通信.

basic_managed_windows_shared_memory 公有成员函数

  1. basic_managed_windows_shared_memory() noexcept;

    默认构造函数. 不做任何事. 与移动语义结合使用时很有用

  2. basic_managed_windows_shared_memory(create_only_t, const char * name, 
                                    size_type size, const void * addr = 0, 
                                    const permissions & perm = permissions());

    创建共享内存并创建和放置段管理器. 这可能抛出异常.

  3. basic_managed_windows_shared_memory(open_or_create_t, const char * name, 
                                    size_type size, const void * addr = 0, 
                                    const permissions & perm = permissions());

    若段尚未创建, 则创建共享内存并创建和放置段管理器; 若段已创建, 则连接到该段. 这可能抛出异常.

  4. basic_managed_windows_shared_memory(open_only_t, const char * name, 
                                    const void * addr = 0);

    连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  5. basic_managed_windows_shared_memory(open_copy_on_write_t, const char * name, 
                                    const void * addr = 0);

    以 copy_on_write 模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  6. basic_managed_windows_shared_memory(open_read_only_t, const char * name, 
                                    const void * addr = 0);

    以只读模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  7. basic_managed_windows_shared_memory(open_or_create_t, const wchar_t * name, 
                                    size_type size, const void * addr = 0, 
                                    const permissions & perm = permissions());

    若段尚未创建, 则创建共享内存并创建和放置段管理器; 若段已创建, 则连接到该段. 这可能抛出异常.

  8. basic_managed_windows_shared_memory(open_only_t, const wchar_t * name, 
                                    const void * addr = 0);

    连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  9. basic_managed_windows_shared_memory(open_copy_on_write_t, 
                                    const wchar_t * name, 
                                    const void * addr = 0);

    以 copy_on_write 模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  10. basic_managed_windows_shared_memory(open_read_only_t, const wchar_t * name, 
                                    const void * addr = 0);

    以只读模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  11. basic_managed_windows_shared_memory(basic_managed_windows_shared_memory && moved) noexcept;

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  12. basic_managed_windows_shared_memory & 
operator=(basic_managed_windows_shared_memory && moved) noexcept;

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  13. ~basic_managed_windows_shared_memory();

    销毁 *this 并指示调用进程已结束对该资源的使用. 销毁后所有映射区域仍然有效. 当引用该共享内存的所有映射区域和 basic_managed_windows_shared_memory 对象都被销毁时, 操作系统将销毁该共享内存.

  14. void swap(basic_managed_windows_shared_memory & other) noexcept;

    交换 *this 与 other 所管理的托管映射内存的所有权. 绝不抛出异常.
