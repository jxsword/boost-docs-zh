类 mapped_region

boost::interprocess::mapped_region

概要

// In header: <boost/interprocess/mapped_region.hpp>


class mapped_region {
public:
  enum advice_types;

  // public member functions
  template<typename MemoryMappable> 
    mapped_region(const MemoryMappable &, mode_t, offset_t = 0, 
                  std::size_t = 0, const void * = 0, 
                  map_options_t = default_map_options);
  mapped_region() noexcept;
  mapped_region(mapped_region &&) noexcept;
  ~mapped_region();
  mapped_region & operator=(mapped_region &&) noexcept;
  void swap(mapped_region &) noexcept;
  std::size_t get_size() const noexcept;
  void * get_address() const noexcept;
  mode_t get_mode() const noexcept;
  bool flush(std::size_t = 0, std::size_t = 0, bool = true);
  bool shrink_by(std::size_t, bool = true);
  bool advise(advice_types);

  // public static functions
  static std::size_t get_page_size() noexcept;
};

说明

mapped_region 类表示从 memory_mappable 对象创建的一部分或区域.

操作系统映射的区域可能比请求的区域大, 因为区域必须是页大小的整数倍, 但 mapped_region 始终指向用户指定的区域.

mapped_region 公有成员函数

  1. template<typename MemoryMappable> 
  mapped_region(const MemoryMappable & mapping, mode_t mode, 
                offset_t offset = 0, std::size_t size = 0, 
                const void * address = 0, 
                map_options_t map_options = default_map_options);

    创建映射内存 "mapping" 的映射区域, 起始偏移为 "offset", 映射大小为 "size". 映射可以只读、读写或写时复制方式打开.

    "mapping" 对象必须是非空的可映射类型 (文件、共享内存等), 否则函数可能失败. 在尝试映射空对象并获得错误之前, 请检查 shared_memory_object/file_mappingget_size() != 0.

    "size" 参数必须大于零, 否则函数将失败

    如果指定了地址, 则偏移量和地址都必须是页大小的整数倍.

    映射使用 "default_map_options" 创建. 该标志依赖于操作系统, 除非用户需要指定特殊选项, 否则不应更改.

    在 Windows 系统上, "map_options" 是作为 "dwDesiredAccess" 传递给 "MapViewOfFileEx" 的 DWORD 值. 如果传入 "default_map_options", 则它被初始化为零. "map_options" 与 FILE_MAP_[COPY|READ|WRITE] 进行异或.

    在 UNIX 系统和 POSIX 映射上, "map_options" 是作为 "flags" 传递给 "mmap" 的 int 值. 如果指定了 "default_map_options", 则若该选项存在则初始化为 MAP_NOSYNC, 否则初始化为零. "map_options" 与 MAP_PRIVATE 或 MAP_SHARED 进行异或.

    在 UNIX 系统和 XSI 映射上, "map_options" 是作为 "shmflg" 传递给 "shmat" 的 int 值. 如果指定了 "default_map_options", 则它被初始化为零. 需要时 "map_options" 与 SHM_RDONLY 进行异或.

    操作系统分配的页可能多于 size/page_size(), 但 get_address() 始终返回传入此函数的地址 (若非空), get_size() 将返回指定的大小.

  2. mapped_region() noexcept;

    默认构造函数. 地址将为 0 (nullptr), 大小将为 0. 不抛出异常

  3. mapped_region(mapped_region && other) noexcept;

    移动构造函数. *this 将接管 "other" 区域的所有权而构造, "other" 则被置于默认构造状态.

  4. ~mapped_region();

    销毁映射区域. 不抛出异常

  5. mapped_region & operator=(mapped_region && other) noexcept;

    移动赋值. 若 *this 拥有一个内存映射区域, 则该区域将被销毁, *this 将接管 "other" 的内存映射区域.

  6. void swap(mapped_region & other) noexcept;

    将该 mapped_region 与另一映射区域交换

  7. std::size_t get_size() const noexcept;
    返回映射的大小. 绝不抛出异常.
  8. void * get_address() const noexcept;

    返回映射的基地址. 绝不抛出异常.

  9. mode_t get_mode() const noexcept;

    返回构造 mapped_region 时使用的映射模式. 绝不抛出异常.

  10. bool flush(std::size_t mapping_offset = 0, std::size_t numbytes = 0, 
           bool async = true);

    将映射内存中的一个字节范围刷新到磁盘. 若 'async' 为 true, 函数将在刷新操作完成之前返回; 若 'async' 为 false, 函数将在数据写入底层设备后返回 (即对于映射文件, 操作系统缓存的信息被写入磁盘). 绝不抛出异常. 若操作无法执行则返回 false.

  11. bool shrink_by(std::size_t bytes, bool from_back = true);

    收缩当前映射区域. 如果收缩后不再需要先前映射的某个内存页, 访问该页可能触发段错误. 视操作系统而定, 此操作可能失败 (XSI 共享内存)、解除存储提交并释放部分虚拟地址空间 (例如 POSIX), 或释放部分物理内存但不释放任何虚拟地址空间 (Windows). 成功时返回 true. 绝不抛出异常.

  12. bool advise(advice_types advise);

    就应用程序对区域内数据的预期使用行为向实现提供建议. 实现可利用该信息优化对区域数据的处理. 此函数不影响区域内内存访问的语义, 但可能影响访问性能. 若实现不认识该建议类型, 函数返回 false; 否则返回 true.

mapped_region 公有静态函数

  1. static std::size_t get_page_size() noexcept;

    返回页大小. 该大小是系统映射一个可内存映射的源时将使用的最小内存, 并会限制可映射的地址与偏移.
