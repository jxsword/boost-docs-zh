函数 ustime_delay_milliseconds

boost::interprocess::ustime_delay_milliseconds

概要

// In header: <boost/interprocess/timed_utils.hpp>


ustime ustime_delay_milliseconds(unsigned msecs);

说明

返回一个未来时间点的工具函数, 该时间点距现在 "msecs" 毫秒.
