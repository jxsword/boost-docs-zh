类模板 basic_managed_xsi_shared_memory

boost::interprocess::basic_managed_xsi_shared_memory

概要

// In header: <boost/interprocess/managed_xsi_shared_memory.hpp>

template<typename CharType, typename AllocationAlgorithm, 
         template< class IndexConfig > class IndexType> 
class basic_managed_xsi_shared_memory {
public:
  // types
  typedef base_t::size_type size_type;

  // public member functions
  ~basic_managed_xsi_shared_memory();
  basic_managed_xsi_shared_memory() noexcept;
  basic_managed_xsi_shared_memory(create_only_t, const xsi_key &, std::size_t, 
                                  const void * = 0, 
                                  const permissions & = permissions());
  basic_managed_xsi_shared_memory(open_or_create_t, const xsi_key &, 
                                  std::size_t, const void * = 0, 
                                  const permissions & = permissions());
  basic_managed_xsi_shared_memory(open_read_only_t, const xsi_key &, 
                                  const void * = 0);
  basic_managed_xsi_shared_memory(open_only_t, const xsi_key &, 
                                  const void * = 0);
  basic_managed_xsi_shared_memory(basic_managed_xsi_shared_memory &&) noexcept;
  basic_managed_xsi_shared_memory & 
  operator=(basic_managed_xsi_shared_memory &&) noexcept;
  void swap(basic_managed_xsi_shared_memory &) noexcept;
  int get_shmid() const noexcept;

  // public static functions
  static bool remove(int);
};

说明

一种基础的 X/Open 系统接口 (XSI) 共享内存命名对象创建类. 初始化共享内存段. 从 basic_managed_memory_impl<CharType, AllocationAlgorithm, IndexType> 继承所有基本功能

basic_managed_xsi_shared_memory 公有成员函数

  1. ~basic_managed_xsi_shared_memory();

    销毁 *this 并指示调用进程已结束对该资源的使用. 析构函数将释放系统为该进程使用此资源而分配的所有系统资源. 之后仍可通过调用 open 构造函数重载再次打开该资源. 要从系统中擦除该资源, 请使用 remove().

  2. basic_managed_xsi_shared_memory() noexcept;

    默认构造函数. 不做任何事. 与移动语义结合使用时很有用

  3. basic_managed_xsi_shared_memory(create_only_t, const xsi_key & key, 
                                std::size_t size, const void * addr = 0, 
                                const permissions & perm = permissions());

    创建共享内存并创建和放置段管理器. 这可能抛出异常.

  4. basic_managed_xsi_shared_memory(open_or_create_t, const xsi_key & key, 
                                std::size_t size, const void * addr = 0, 
                                const permissions & perm = permissions());

    若段尚未创建, 则创建共享内存并创建和放置段管理器; 若段已创建, 则连接到该段. 这可能抛出异常.

  5. basic_managed_xsi_shared_memory(open_read_only_t, const xsi_key & key, 
                                const void * addr = 0);

    以只读模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  6. basic_managed_xsi_shared_memory(open_only_t, const xsi_key & key, 
                                const void * addr = 0);

    连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  7. basic_managed_xsi_shared_memory(basic_managed_xsi_shared_memory && moved) noexcept;

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  8. basic_managed_xsi_shared_memory & 
operator=(basic_managed_xsi_shared_memory && moved) noexcept;

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  9. void swap(basic_managed_xsi_shared_memory & other) noexcept;

    交换 *this 与 other 所管理的托管共享内存的所有权. 绝不抛出异常.

  10. int get_shmid() const noexcept;

basic_managed_xsi_shared_memory 公有静态函数

  1. static bool remove(int shmid);

    从系统中擦除由 shmid 标识的 XSI 共享内存对象. 出错时返回 false. 绝不抛出异常
