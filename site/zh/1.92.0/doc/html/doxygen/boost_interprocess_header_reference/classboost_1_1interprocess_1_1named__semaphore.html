类 named_semaphore

boost::interprocess::named_semaphore

概要

// In header: <boost/interprocess/sync/named_semaphore.hpp>


class named_semaphore {
public:

  // public member functions
  named_semaphore(create_only_t, const char *, unsigned int, 
                  const permissions & = permissions());
  named_semaphore(open_or_create_t, const char *, unsigned int, 
                  const permissions & = permissions());
  named_semaphore(open_only_t, const char *);
  named_semaphore(create_only_t, const wchar_t *, unsigned int, 
                  const permissions & = permissions());
  named_semaphore(open_or_create_t, const wchar_t *, unsigned int, 
                  const permissions & = permissions());
  named_semaphore(open_only_t, const wchar_t *);
  ~named_semaphore();
  void post();
  void wait();
  bool try_wait();
  template<typename TimePoint> bool timed_wait(const TimePoint &);

  // public static functions
  static bool remove(const char *);
  static bool remove(const wchar_t *);
};

说明

具有全局名称的信号量, 因此可以从不同进程找到它. 支持多种资源共享模式与高效的确认机制.

named_semaphore 公有成员函数

  1. named_semaphore(create_only_t, const char * name, unsigned int initialCount, 
                const permissions & perm = permissions());

    以名称和初始计数创建一个全局信号量. 若无法创建该信号量, 抛出 interprocess_exception 

  2. named_semaphore(open_or_create_t, const char * name, 
                unsigned int initialCount, 
                const permissions & perm = permissions());

    以名称和初始计数打开或创建一个全局信号量. 若创建该信号量, 此调用等价于 named_semaphore(create_only_t, ...); 若该信号量已创建, 此调用等价于 named_semaphore(open_only_t, ... ), 且 initialCount 被忽略.

  3. named_semaphore(open_only_t, const char * name);

    若该信号量先前已创建, 则以名称打开全局信号量. 若先前未创建, 此函数抛出 interprocess_exception.

  4. named_semaphore(create_only_t, const wchar_t * name, 
                unsigned int initialCount, 
                const permissions & perm = permissions());

    以名称和初始计数创建一个全局信号量. 若无法创建该信号量, 抛出 interprocess_exception

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  5. named_semaphore(open_or_create_t, const wchar_t * name, 
                unsigned int initialCount, 
                const permissions & perm = permissions());

    以名称和初始计数打开或创建一个全局信号量. 若创建该信号量, 此调用等价于 named_semaphore(create_only_t, ...); 若该信号量已创建, 此调用等价于 named_semaphore(open_only_t, ... ), 且 initialCount 被忽略.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  6. named_semaphore(open_only_t, const wchar_t * name);

    若该信号量先前已创建, 则以名称打开全局信号量. 若先前未创建, 此函数抛出 interprocess_exception.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  7. ~named_semaphore();

    销毁 *this 并指示调用进程已结束对该资源的使用. 析构函数将释放系统为该进程使用此资源而分配的所有系统资源. 之后仍可通过调用 open 构造函数重载再次打开该资源. 要从系统中擦除该资源, 请使用 remove().

  8. void post();

    递增信号量计数. 若有进程/线程因等待信号量而被阻塞, 则其中一个进程将从其等待函数中成功返回. 出错时抛出 interprocess_exception 异常.

  9. void wait();

    递减信号量. 若信号量的值不大于零, 则调用进程/线程阻塞, 直到能够递减该计数. 出错时抛出 interprocess_exception 异常.

  10. bool try_wait();

    若信号量的值大于零, 则递减信号量并返回 true. 若值不大于零则返回 false. 出错时抛出 interprocess_exception 异常.

  11. template<typename TimePoint> bool timed_wait(const TimePoint & abs_time);

    若信号量的值大于零, 则递减信号量并返回 true. 否则, 等待信号量被释放或超时. 若超时, 函数返回 false. 若信号量被释放, 函数返回 true. 出错时抛出 sem_exception

named_semaphore 公有静态函数

  1. static bool remove(const char * name);

    从系统中擦除一个命名信号量. 出错时返回 false. 绝不抛出异常.

  2. static bool remove(const wchar_t * name);

    从系统中擦除一个命名信号量. 出错时返回 false. 绝不抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).
