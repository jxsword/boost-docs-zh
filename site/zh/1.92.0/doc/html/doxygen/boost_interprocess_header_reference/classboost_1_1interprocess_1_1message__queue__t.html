类模板 message_queue_t

boost::interprocess::message_queue_t

概要

// In header: <boost/interprocess/ipc/message_queue.hpp>

template<typename VoidPointer> 
class message_queue_t {
public:
  // types
  typedef VoidPointer                                                                             void_pointer;   
  typedef boost::intrusive::pointer_traits< void_pointer >::template rebind_pointer< char >::type char_ptr;       
  typedef boost::intrusive::pointer_traits< char_ptr >::difference_type                           difference_type;
  typedef boost::container::dtl::make_unsigned< difference_type >::type                           size_type;      

  // public member functions
  message_queue_t(create_only_t, const char *, size_type, size_type, 
                  const permissions & = permissions());
  message_queue_t(open_or_create_t, const char *, size_type, size_type, 
                  const permissions & = permissions());
  message_queue_t(open_only_t, const char *);
  message_queue_t(create_only_t, const wchar_t *, size_type, size_type, 
                  const permissions & = permissions());
  message_queue_t(open_or_create_t, const wchar_t *, size_type, size_type, 
                  const permissions & = permissions());
  message_queue_t(open_only_t, const wchar_t *);
  message_queue_t(size_type, size_type);
  ~message_queue_t();
  void send(const void *, size_type, unsigned int);
  bool try_send(const void *, size_type, unsigned int);
  template<typename TimePoint> 
    bool timed_send(const void *, size_type, unsigned int, const TimePoint &);
  void receive(void *, size_type, size_type &, unsigned int &);
  bool try_receive(void *, size_type, size_type &, unsigned int &);
  template<typename TimePoint> 
    bool timed_receive(void *, size_type, size_type &, unsigned int &, 
                       const TimePoint &);
  size_type get_max_msg() const;
  size_type get_max_msg_size() const;
  size_type get_num_msg() const;

  // public static functions
  static bool remove(const char *);
  static bool remove(const wchar_t *);
};

说明

一种允许进程之间发送消息的类.

message_queue_t 公有成员函数

  1. message_queue_t(create_only_t, const char * name, size_type max_num_msg, 
                size_type max_msg_size, 
                const permissions & perm = permissions());

    创建名为 "name" 的进程共享消息队列. 该消息队列的最大消息数为 "max_num_msg", 最大消息大小为 "max_msg_size". 出错时或队列先前已创建时抛出异常.

  2. message_queue_t(open_or_create_t, const char * name, size_type max_num_msg, 
                size_type max_msg_size, 
                const permissions & perm = permissions());

    打开或创建名为 "name" 的进程共享消息队列. 若创建队列, 最大消息数为 "max_num_msg", 最大消息大小为 "max_msg_size". 若队列先前已创建, 则打开该队列并忽略 "max_num_msg" 与 "max_msg_size" 参数. 出错时抛出异常.

  3. message_queue_t(open_only_t, const char * name);

    打开先前创建的名为 "name" 的进程共享消息队列. 若队列先前未创建或没有空闲资源, 则抛出错误.

  4. message_queue_t(create_only_t, const wchar_t * name, size_type max_num_msg, 
                size_type max_msg_size, 
                const permissions & perm = permissions());

    创建名为 "name" 的进程共享消息队列. 该消息队列的最大消息数为 "max_num_msg", 最大消息大小为 "max_msg_size". 出错时或队列先前已创建时抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  5. message_queue_t(open_or_create_t, const wchar_t * name, size_type max_num_msg, 
                size_type max_msg_size, 
                const permissions & perm = permissions());

    打开或创建名为 "name" 的进程共享消息队列. 若创建队列, 最大消息数为 "max_num_msg", 最大消息大小为 "max_msg_size". 若队列先前已创建, 则打开该队列并忽略 "max_num_msg" 与 "max_msg_size" 参数. 出错时抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  6. message_queue_t(open_only_t, const wchar_t * name);

    打开先前创建的名为 "name" 的进程共享消息队列. 若队列先前未创建或没有空闲资源, 则抛出错误.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  7. message_queue_t(size_type max_num_msg, size_type max_msg_size);

    在匿名内存中创建进程共享消息队列. 该消息队列的最大消息数为 "max_num_msg", 最大消息大小为 "max_msg_size". 出错时抛出异常.

  8. ~message_queue_t();

    销毁 *this 并指示调用进程已结束对该资源的使用. 销毁后所有已打开的消息队列仍然有效. 析构函数将释放系统为该进程使用此资源而分配的所有系统资源. 之后仍可通过调用 open 构造函数重载再次打开该资源. 要从系统中擦除消息队列, 请使用 remove().

  9. void send(const void * buffer, size_type buffer_size, unsigned int priority);

    把缓冲区 "buffer" 中大小为 "buffer_size" 的消息以优先级 "priority" 发送到消息队列. 若消息队列已满, 发送者被阻塞. 出错时抛出 interprocess_error.

  10. bool try_send(const void * buffer, size_type buffer_size, 
              unsigned int priority);

    把缓冲区 "buffer" 中大小为 "buffer_size" 的消息以优先级 "priority" 通过消息队列发送. 若消息队列已满, 发送者不被阻塞并返回 false, 否则返回 true. 出错时抛出 interprocess_error.

  11. template<typename TimePoint> 
  bool timed_send(const void * buffer, size_type buffer_size, 
                  unsigned int priority, const TimePoint & abs_time);

    把缓冲区 "buffer" 中大小为 "buffer_size" 的消息以优先级 "priority" 发送到消息队列. 若消息队列已满, 发送者将持续重试直到到达时间 "abs_time". 消息成功发送则返回 true. 到达超时则返回 false. 出错时抛出 interprocess_error.

  12. void receive(void * buffer, size_type buffer_size, size_type & recvd_size, 
             unsigned int & priority);

    从消息队列接收消息. 消息存储在大小为 "buffer_size" 的缓冲区 "buffer" 中. 收到的消息大小为 "recvd_size", 优先级为 "priority". 若消息队列为空, 接收者被阻塞. 出错时抛出 interprocess_error.

  13. bool try_receive(void * buffer, size_type buffer_size, size_type & recvd_size, 
                 unsigned int & priority);

    从消息队列接收消息. 消息存储在大小为 "buffer_size" 的缓冲区 "buffer" 中. 收到的消息大小为 "recvd_size", 优先级为 "priority". 若消息队列为空, 接收者不被阻塞并返回 false, 否则返回 true. 出错时抛出 interprocess_error.

  14. template<typename TimePoint> 
  bool timed_receive(void * buffer, size_type buffer_size, 
                     size_type & recvd_size, unsigned int & priority, 
                     const TimePoint & abs_time);

    从消息队列接收消息. 消息存储在大小为 "buffer_size" 的缓冲区 "buffer" 中. 收到的消息大小为 "recvd_size", 优先级为 "priority". 若消息队列为空, 接收者将持续重试直到到达时间 "abs_time". 消息成功发送则返回 true. 到达超时则返回 false. 出错时抛出 interprocess_error.

  15. size_type get_max_msg() const;

    返回队列允许的最大消息数. 消息队列必须先前已打开或创建, 否则返回 0. 绝不抛出异常

  16. size_type get_max_msg_size() const;

    返回队列允许的最大消息大小. 消息队列必须先前已打开或创建, 否则返回 0. 绝不抛出异常

  17. size_type get_num_msg() const;

    返回当前存储的消息数量. 绝不抛出异常

message_queue_t 公有静态函数

  1. static bool remove(const char * name);

    从系统中移除消息队列. 出错时返回 false. 绝不抛出异常

  2. static bool remove(const wchar_t * name);

    从系统中移除消息队列. 出错时返回 false. 绝不抛出异常

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).
