类模板 basic_managed_shared_memory

boost::interprocess::basic_managed_shared_memory

概要

// In header: <boost/interprocess/managed_shared_memory.hpp>

template<typename CharType, typename AllocationAlgorithm, 
         template< class IndexConfig > class IndexType> 
class basic_managed_shared_memory {
public:

  // public member functions
  ~basic_managed_shared_memory();
  basic_managed_shared_memory();
  basic_managed_shared_memory(create_only_t, const char *, size_type, 
                              const void * = 0, 
                              const permissions & = permissions());
  basic_managed_shared_memory(open_or_create_t, const char *, size_type, 
                              const void * = 0, 
                              const permissions & = permissions());
  basic_managed_shared_memory(open_copy_on_write_t, const char *, 
                              const void * = 0);
  basic_managed_shared_memory(open_read_only_t, const char *, 
                              const void * = 0);
  basic_managed_shared_memory(open_only_t, const char *, const void * = 0);
  basic_managed_shared_memory(create_only_t, const wchar_t *, size_type, 
                              const void * = 0, 
                              const permissions & = permissions());
  basic_managed_shared_memory(open_or_create_t, const wchar_t *, size_type, 
                              const void * = 0, 
                              const permissions & = permissions());
  basic_managed_shared_memory(open_copy_on_write_t, const wchar_t *, 
                              const void * = 0);
  basic_managed_shared_memory(open_read_only_t, const wchar_t *, 
                              const void * = 0);
  basic_managed_shared_memory(open_only_t, const wchar_t *, const void * = 0);
  basic_managed_shared_memory(basic_managed_shared_memory &&);
  basic_managed_shared_memory & operator=(basic_managed_shared_memory &&);
  void swap(basic_managed_shared_memory &);

  // public static functions
  static bool grow(const char *, size_type);
  static bool shrink_to_fit(const char *);
  static bool grow(const wchar_t *, size_type);
  static bool shrink_to_fit(const wchar_t *);
};

说明

一种基础的共享内存命名对象创建类. 初始化共享内存段. 从 basic_managed_memory_impl<CharType, AllocationAlgorithm, IndexType>*<zwj></zwj>/ 继承所有基本功能

basic_managed_shared_memory 公有成员函数

  1. ~basic_managed_shared_memory();

    销毁 *this 并指示调用进程已结束对该资源的使用. 析构函数将释放系统为该进程使用此资源而分配的所有系统资源. 之后仍可通过调用 open 构造函数重载再次打开该资源. 要从系统中擦除该资源, 请使用 remove().

  2. basic_managed_shared_memory();

    默认构造函数. 不做任何事. 与移动语义结合使用时很有用

  3. basic_managed_shared_memory(create_only_t, const char * name, size_type size, 
                            const void * addr = 0, 
                            const permissions & perm = permissions());

    创建共享内存并创建和放置段管理器. 这可能抛出异常.

  4. basic_managed_shared_memory(open_or_create_t, const char * name, 
                            size_type size, const void * addr = 0, 
                            const permissions & perm = permissions());

    若段尚未创建, 则创建共享内存并创建和放置段管理器; 若段已创建, 则连接到该段. 这可能抛出异常.

  5. basic_managed_shared_memory(open_copy_on_write_t, const char * name, 
                            const void * addr = 0);

    以 copy_on_write 模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  6. basic_managed_shared_memory(open_read_only_t, const char * name, 
                            const void * addr = 0);

    以只读模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  7. basic_managed_shared_memory(open_only_t, const char * name, 
                            const void * addr = 0);

    连接到已创建的共享内存及其段管理器. 这可能抛出异常.

  8. basic_managed_shared_memory(create_only_t, const wchar_t * name, 
                            size_type size, const void * addr = 0, 
                            const permissions & perm = permissions());

    创建共享内存并创建和放置段管理器. 这可能抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  9. basic_managed_shared_memory(open_or_create_t, const wchar_t * name, 
                            size_type size, const void * addr = 0, 
                            const permissions & perm = permissions());

    若段尚未创建, 则创建共享内存并创建和放置段管理器; 若段已创建, 则连接到该段. 这可能抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  10. basic_managed_shared_memory(open_copy_on_write_t, const wchar_t * name, 
                            const void * addr = 0);

    以 copy_on_write 模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  11. basic_managed_shared_memory(open_read_only_t, const wchar_t * name, 
                            const void * addr = 0);

    以只读模式连接到已创建的共享内存及其段管理器. 这可能抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  12. basic_managed_shared_memory(open_only_t, const wchar_t * name, 
                            const void * addr = 0);

    连接到已创建的共享内存及其段管理器. 这可能抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  13. basic_managed_shared_memory(basic_managed_shared_memory && moved);

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  14. basic_managed_shared_memory & operator=(basic_managed_shared_memory && moved);

    将 "moved" 托管内存的所有权移交给 *this. 不抛出异常

  15. void swap(basic_managed_shared_memory & other);

    交换 *this 与 other 所管理的托管共享内存的所有权. 绝不抛出异常.

basic_managed_shared_memory 公有静态函数

  1. static bool grow(const char * shmname, size_type extra_bytes);

    尝试调整托管共享内存对象的大小, 以便为更多对象腾出空间.

    该函数不同步, 因此不得有其他线程或进程正在读写该文件

    由于底层共享内存增长后内存会被重新映射, 因此它不能与使用原生指针的段一起工作.

  2. static bool shrink_to_fit(const char * shmname);

    尝试调整托管共享内存的大小以最小化文件大小.

    该函数不同步, 因此不得有其他线程或进程正在读写该文件

  3. static bool grow(const wchar_t * shmname, size_type extra_bytes);

    尝试调整托管共享内存对象的大小, 以便为更多对象腾出空间.

    该函数不同步, 因此不得有其他线程或进程正在读写该文件

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

    尝试调整托管共享内存的大小以最小化文件大小.

    该函数不同步, 因此不得有其他线程或进程正在读写该文件
