类 named_mutex

boost::interprocess::named_mutex

概要

// In header: <boost/interprocess/sync/named_mutex.hpp>


class named_mutex {
public:

  // public member functions
  named_mutex(create_only_t, const char *, 
              const permissions & = permissions());
  named_mutex(open_or_create_t, const char *, 
              const permissions & = permissions());
  named_mutex(open_only_t, const char *);
  named_mutex(create_only_t, const wchar_t *, 
              const permissions & = permissions());
  named_mutex(open_or_create_t, const wchar_t *, 
              const permissions & = permissions());
  named_mutex(open_only_t, const wchar_t *);
  ~named_mutex();
  void unlock();
  void lock();
  bool try_lock();
  template<typename TimePoint> bool timed_lock(const TimePoint &);
  template<typename TimePoint> bool try_lock_until(const TimePoint &);
  template<typename Duration> bool try_lock_for(const Duration &);

  // public static functions
  static bool remove(const char *);
  static bool remove(const wchar_t *);
};

说明

具有全局名称的互斥量, 因此可以从不同进程找到它. 此互斥量不能放置在共享内存中, 每个进程应拥有自己的 named_mutex.

named_mutex 公有成员函数

  1. named_mutex(create_only_t, const char * name, 
            const permissions & perm = permissions());

    以名称创建一个全局互斥量. 出错时抛出 interprocess_exception.

  2. named_mutex(open_or_create_t, const char * name, 
            const permissions & perm = permissions());

    打开或创建具有名称的全局互斥量. 若创建该互斥量, 此调用等价于 named_mutex(create_only_t, ... ); 若该互斥量已创建, 此调用等价于 named_mutex(open_only_t, ... ). 不抛出异常

  3. named_mutex(open_only_t, const char * name);

    若该互斥量先前已创建, 则以名称打开全局互斥量. 若先前未创建, 此函数抛出 interprocess_exception.

  4. named_mutex(create_only_t, const wchar_t * name, 
            const permissions & perm = permissions());

    以名称创建一个全局互斥量. 出错时抛出 interprocess_exception.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  5. named_mutex(open_or_create_t, const wchar_t * name, 
            const permissions & perm = permissions());

    打开或创建具有名称的全局互斥量. 若创建该互斥量, 此调用等价于 named_mutex(create_only_t, ... ); 若该互斥量已创建, 此调用等价于 named_mutex(open_only_t, ... ). 不抛出异常

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  6. named_mutex(open_only_t, const wchar_t * name);

    若该互斥量先前已创建, 则以名称打开全局互斥量. 若先前未创建, 此函数抛出 interprocess_exception.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).

  7. ~named_mutex();

    销毁 *this 并指示调用进程已结束对该资源的使用. 析构函数将释放系统为该进程使用此资源而分配的所有系统资源. 之后仍可通过调用 open 构造函数重载再次打开该资源. 要从系统中擦除该资源, 请使用 remove().

  8. void unlock();

    解锁先前已锁定的互斥量.

  9. void lock();

    要求: 调用线程不拥有该互斥量.

    锁定互斥量; 若互斥量已被锁定则休眠等待. 发现严重错误时抛出 interprocess_exception

    注释: 若已拥有所有权的线程调用此函数, 程序可能死锁. 若实现能检测到死锁, 则可能抛出异常.

  10. bool try_lock();

    要求: 调用线程不拥有该互斥量.

    尝试锁定互斥量: 若互斥量已被锁定则返回 false, 成功则返回 true. 发现严重错误时抛出 interprocess_exception

    注释: 若已拥有所有权的线程调用此函数, 程序可能死锁. 若实现能检测到死锁, 则可能抛出异常.

  11. template<typename TimePoint> bool timed_lock(const TimePoint & abs_time);

    要求: 调用线程不拥有该互斥量.

    尝试锁定互斥量直到时间 abs_time: 超时则返回 false, 加锁成功则返回 true. 发现严重错误时抛出 interprocess_exception

    注释: 若已拥有所有权的线程调用此函数, 程序可能死锁. 若实现能检测到死锁, 则可能抛出异常.

  12. template<typename TimePoint> bool try_lock_until(const TimePoint & abs_time);

    与 timed_lock 相同, 但此函数仿照标准库接口设计.

  13. template<typename Duration> bool try_lock_for(const Duration & dur);

    与 timed_lock 相同, 但此函数仿照标准库接口设计.

named_mutex 公有静态函数

  1. static bool remove(const char * name);

    从系统中擦除一个命名互斥量. 出错时返回 false. 绝不抛出异常.

  2. static bool remove(const wchar_t * name);

    从系统中擦除一个命名互斥量. 出错时返回 false. 绝不抛出异常.

    注释: 该函数仅在提供原生 wchar_t API 的操作系统上可用 (例如 Windows).
