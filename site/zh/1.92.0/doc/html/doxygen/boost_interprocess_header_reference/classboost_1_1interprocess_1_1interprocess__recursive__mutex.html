类 interprocess_recursive_mutex

boost::interprocess::interprocess_recursive_mutex

概要

// In header: <boost/interprocess/sync/interprocess_recursive_mutex.hpp>


class interprocess_recursive_mutex {
public:

  // public member functions
  interprocess_recursive_mutex();
  ~interprocess_recursive_mutex();
  void lock();
  bool try_lock();
  template<typename TimePoint> bool timed_lock(const TimePoint &);
  template<typename TimePoint> bool try_lock_until(const TimePoint &);
  template<typename Duration> bool try_lock_for(const Duration &);
  void unlock();
};

说明

封装一个可放置在共享内存中、可在进程间共享的 interprocess_mutex. 允许同一进程多次加锁调用. 允许限时加锁尝试

interprocess_recursive_mutex 公有成员函数

  1. interprocess_recursive_mutex();

    构造函数. 出错时抛出 interprocess_exception.

  2. ~interprocess_recursive_mutex();

    析构函数. 若在调用析构函数后仍有进程使用该互斥量, 则结果未定义. 不抛出异常.

  3. void lock();

    效果: 调用线程尝试获得该互斥量的所有权; 若另一线程已拥有该互斥量, 则等待直到能够获得所有权. 若某线程取得了互斥量的所有权, 该互斥量必须由同一线程解锁. 互斥量解锁的次数必须与其加锁的次数相同. 抛出: 出错时抛出 interprocess_exception.

    注释: 若已拥有所有权的线程调用此函数, 程序不应死锁.

  4. bool try_lock();

    尝试锁定 interprocess_mutex: 若 interprocess_mutex 已被锁定则返回 false, 成功则返回 true. 互斥量解锁的次数必须与其加锁的次数相同. 抛出: 发现严重错误时抛出 interprocess_exception

    注释: 若已拥有所有权的线程调用此函数, 程序不应死锁.

  5. template<typename TimePoint> bool timed_lock(const TimePoint & abs_time);

    尝试锁定 interprocess_mutex: 若在 abs_time 之前无法锁定 interprocess_mutex, 则返回 false. 互斥量解锁的次数必须与其加锁的次数相同. 抛出: 发现严重错误时抛出 interprocess_exception

    注释: 若已拥有所有权的线程调用此函数, 程序不应死锁.

  6. template<typename TimePoint> bool try_lock_until(const TimePoint & abs_time);

    与 timed_lock 相同, 但此函数仿照标准库接口设计.

  7. template<typename Duration> bool try_lock_for(const Duration & dur);

    与 timed_lock 相同, 但此函数仿照标准库接口设计.

  8. void unlock();

    效果: 调用线程释放该互斥量的独占所有权. 若互斥量支持递归加锁, 互斥量解锁的次数必须与其加锁的次数相同. 抛出: 出错时抛出 interprocess_exception.
