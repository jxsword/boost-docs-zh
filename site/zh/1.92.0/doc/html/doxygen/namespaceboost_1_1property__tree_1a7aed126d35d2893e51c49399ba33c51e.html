函数模板 read_json

boost::property_tree::read_json

概要

// In header: <boost/property_tree/json_parser.hpp>


template<typename Ptree> 
  void read_json(std::basic_istream< typename Ptree::key_type::value_type > & stream, 
                 Ptree & pt);

说明

从给定流读取 JSON 并将其转换为属性树.

注释

清空属性树的现有内容. 出错时属性树不被修改.

注释

JSON 数组的项被转换为名为空的 ptree 键. 对象的成员被转换为命名键.

注释

JSON 数据可以是字符串、数值或字面量 "null"、"true" 与 "false" 之一. 解析期间, 以上任何一种都会被原样复制到 ptree 数据字符串中.

参数:

stream

从中读取属性树的流.

pt

要填充的属性树.

抛出:

 json_parser_error 在反序列化属性树出错时.
