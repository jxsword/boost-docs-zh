宏 BOOST_MPI_CHECK_RESULT

BOOST_MPI_CHECK_RESULT

概要

// In header: <boost/mpi/exception.hpp>

BOOST_MPI_CHECK_RESULT(MPIFunc, Args)

说明

以实参 Args (带括号) 调用 MPI 例程 MPIFunc. 如果结果不是 MPI_SUCCESS, 则根据 BOOST_NO_EXCEPTIONS 使用 boost::throw_exception 抛出异常或中止.
