函数模板 adl_move_swap_ranges

boost::adl_move_swap_ranges

概要

// In header: <boost/move/adl_move_swap.hpp>


template<typename ForwardIt1, typename ForwardIt2> 
  ForwardIt2 adl_move_swap_ranges(ForwardIt1 first1, ForwardIt1 last1, 
                                  ForwardIt2 first2);

说明

使用 boost::adl_move_swap 在范围 [first1, last1) 与从 first2 开始的另一个范围之间交换元素.

参数: first1, last1 - 要交换的第一组元素范围 first2 - 要交换的第二组元素范围的起始

类型 requirements:

  • ForwardIt1, ForwardIt2 必须满足 ForwardIterator 的要求.

  • ForwardIt1 与 ForwardIt2 解引用后的类型必须满足 Swappable 的要求

返回值: 指向以 first2 开始的范围中最后被交换元素之后元素的迭代器.
