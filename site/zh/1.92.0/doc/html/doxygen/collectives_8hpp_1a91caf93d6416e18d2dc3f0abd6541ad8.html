函数 scan

boost::mpi::scan — 对通信器中所有进程的值计算前缀归约.

概要

// In header: <boost/mpi/collectives.hpp>


template<typename T, typename Op> 
  void scan(const communicator & comm, const T & in_value, T & out_value, 
            Op op);
template<typename T, typename Op> 
  T scan(const communicator & comm, const T & in_value, Op op);
template<typename T, typename Op> 
  void scan(const communicator & comm, const T * in_values, int n, 
            T * out_values, Op op);

说明

scan 是一种集合算法, 它把每个进程存储的值与秩更小的所有进程的值合并. 值可以任意合并, 通过函数对象 op 指定. 值的类型 T 可以是可序列化的类型或具有关联 MPI 数据类型的类型. 可以把此操作看作到某个进程的 gather, 随后对收集到的值执行 std::prefix_sum(), 使用运算 op. 第 i 个进程返回 std::prefix_sum() 发出的第 i 个值.

当类型 T 具有关联的 MPI 数据类型时, 此例程调用 MPI_Scan 执行归约. 如果可能, 将使用内建 MPI 操作; 否则, scan() 将为 MPI_Scan 调用创建自定义 MPI_Op.

参数:

comm

发生前缀归约的通信器.

in_value

要与其他进程的本地值合并的本地值. 对于数组变体, in_values 参数指向将被合并的 n 个本地值.

out_value

如果提供, 第 i 个进程将接收值 op(in_value[0], op(in_value[1], op(..., in_value[i]) ... )). 对于数组变体, out_values 包含指向容纳 n 个输出值的存储的指针. 前缀归约对每个 n 值独立进行, 该值由 in_values 所引用. 例如, 对 n 值的数组调用 scan, 就像把 scan 分开调用 n 次, in_values 与 out_values 中的每个位置各一次.

op

将类型 T 的两个值合并为第三个类型 T 值的二元运算. 对于具有关联 MPI 数据类型的类型 T, op 要么被转换为 MPI_Op (通过 MPI_Op_create), 要么 (如果可能) 直接映射到内建 MPI 操作. 更多细节见 is_mpi_op, 位于 operations.hpp 头文件中. 对于任何非内建操作, 交换性将由 is_commmutative 特征决定 (也在 operations.hpp 中).

返回:

如果未提供 out_value 参数, 则返回前缀归约的结果.
