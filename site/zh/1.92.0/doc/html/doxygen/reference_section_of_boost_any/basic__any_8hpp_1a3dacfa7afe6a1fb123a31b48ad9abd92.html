函数模板 any_cast

boost::anys::any_cast

概要

// In header: <boost/any/basic_any.hpp>


template<typename ValueType, std::size_t OptimizeForSize, 
         std::size_t OptimizeForAlignment> 
  const ValueType * 
  any_cast(const basic_any< OptimizeForSize, OptimizeForAlignment > * operand);

说明

返回:

指向 operand 中存储的 ValueType 的 const 指针, 若 operand 不包含指定的 ValueType 则为 nullptr.
