函数模板 any_cast

boost::any_cast

概要

// In header: <boost/any.hpp>


template<typename ValueType> ValueType * any_cast(any * operand);

说明

返回:

指向 operand 中存储的 ValueType 的指针, 若 operand 不包含指定的 ValueType 则为 nullptr.
