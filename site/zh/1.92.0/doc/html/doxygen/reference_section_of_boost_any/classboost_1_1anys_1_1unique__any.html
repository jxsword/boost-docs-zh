类 unique_any

boost::anys::unique_any — 其实例可持有任意类型实例 (包括不可拷贝与不可移动类型) 的类.

概要

// In header: <boost/any/unique_any.hpp>


class unique_any {
public:

  // public member functions
  unique_any();
  unique_any(unique_any &&);
  template<typename T> 
    unique_any(T &&, 
               typename std::enable_if<!std::is_same< T &&, boost::any && >::value >::type * = nullptr);
  template<typename BoostAny> 
    unique_any(BoostAny &&, 
               typename std::enable_if< std::is_same< BoostAny &&, boost::any && >::value >::type * = nullptr) noexcept;
  template<typename T, class... Args> 
    explicit unique_any(in_place_type_t< T >, Args &&...);
  template<typename T, typename U, class... Args> 
    explicit unique_any(in_place_type_t< T >, std::initializer_list< U >, 
                        Args &&...);
  ~unique_any();
  unique_any & operator=(unique_any &&);
  template<typename T> unique_any & operator=(T &&);
  template<typename T, class... Args> 
    std::decay< T >::type & emplace(Args &&...);
  template<typename T, typename U, class... Args> 
    std::decay< T >::type & emplace(std::initializer_list< U >, Args &&...);
  void reset() noexcept;
  void swap(unique_any &) noexcept;
  bool has_value() const noexcept;
  const boost::typeindex::type_info & type() const noexcept;
};

说明

unique_any 公有成员函数

  1. unique_any();

    后置条件:

    this->has_value() 为 false.

    		 
  2. unique_any(unique_any && other);

    移动构造函数, 把 other 的内容移入新实例并把 other 置空.

    后置条件:

    other->has_value() 为 false.

    抛出:

    		 无. 
  3. template<typename T> 
  unique_any(T && value, 
             typename std::enable_if<!std::is_same< T &&, boost::any && >::value >::type * = nullptr);

    转发 value, 使新实例的内容具有类型 std::decay_t<T>, 值为转发前的 value.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 
  4. template<typename BoostAny> 
  unique_any(BoostAny && value, 
             typename std::enable_if< std::is_same< BoostAny &&, boost::any && >::value >::type * = nullptr) noexcept;

    把 boost::any 的内容移入 *this.

    后置条件:

    value.empty() 为真.

    抛出:

    		 无. 
  5. template<typename T, class... Args> 
  explicit unique_any(in_place_type_t< T >, Args &&... args);

    就地构造 T (来源为转发的 args...), 使 *this 的内容在类型上与 std::decay_t<T> 等价.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 
  6. template<typename T, typename U, class... Args> 
  explicit unique_any(in_place_type_t< T >, std::initializer_list< U > il, 
                      Args &&... args);

    就地构造 T (来自 li 与转发的 args...), 使 *this 的初始内容在类型上与 std::decay_t<T> 等价.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 
  7. ~unique_any();

    释放在管理实例时使用的全部资源.

    抛出:

    		 无. 
  8. unique_any & operator=(unique_any && rhs);

    把 rhs 的内容移入当前实例, 丢弃先前内容, 使新内容在类型与值上都与移动前的 rhs 内容等价; 若 rhs.empty() 为空则为空.

    后置条件:

    rhs->empty() 为 true

    抛出:

    		 无. 
  9. template<typename T> unique_any & operator=(T && rhs);

    转发 rhs, 丢弃先前内容, 使新内容在类型与值上都与转发前的 rhs 等价.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 赋值满足异常安全的强保证. 
  10. template<typename T, class... Args> 
  std::decay< T >::type & emplace(Args &&... args);

    就地构造 T (来源为转发的 args...), 丢弃先前内容, 使 *this 的内容在类型上与 std::decay_t<T> 等价.

    返回:

    指向 *this 内容的引用.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 
  11. template<typename T, typename U, class... Args> 
  std::decay< T >::type & 
  emplace(std::initializer_list< U > il, Args &&... args);

    就地构造 T (来自 li 与转发的 args...), 丢弃先前内容, 使 *this 的内容在类型上与 std::decay_t<T> 等价.

    返回:

    指向 *this 内容的引用.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 
  12. void reset() noexcept;

    后置条件:

    this->has_value() 为 false.

    		 
  13. void swap(unique_any & rhs) noexcept;

    交换 *this 与 rhs 的内容.

    返回:

    *this

    抛出:

    		 无. 
  14. bool has_value() const noexcept;

    返回:

    true, 若实例非空; 否则为 false.

    抛出:

    		 无. 
  15. const boost::typeindex::type_info & type() const noexcept;

    适用于针对编译期已知或仅运行期可知的类型进行查询.

    返回:

    若实例非空, 为所含值的 typeid; 否则为 typeid(void).
