类模板 basic_any

boost::anys::basic_any — 支持自定义小对象优化的类, 其实例可持有满足 ValueType 要求的任意类型实例. 若不确定, 请改用 boost::any.

概要

// In header: <boost/any/basic_any.hpp>

template<std::size_t OptimizeForSize, std::size_t OptimizeForAlignment> 
class basic_any {
public:

  // public member functions
  basic_any() noexcept;
  template<typename ValueType> basic_any(const ValueType &);
  basic_any(const basic_any &);
  basic_any(basic_any &&) noexcept;
  template<typename ValueType> 
    basic_any(ValueType &&, 
              typename std::enable_if<!std::is_same< basic_any &, ValueType >::value >::type * = 0, 
              typename std::enable_if<!std::is_const< ValueType >::value >::type * = 0);
  ~basic_any() noexcept;
  basic_any & swap(basic_any &) noexcept;
  basic_any & operator=(const basic_any &);
  basic_any & operator=(basic_any &&) noexcept;
  template<typename ValueType> basic_any & operator=(ValueType &&);
  bool empty() const noexcept;
  void clear() noexcept;
  const boost::typeindex::type_info & type() const noexcept;

  // public data members
  static std::size_t buffer_size;
  static std::size_t buffer_align;
};

说明

boost::anys::basic_any 是 boost::any 的直接替代品, 通过 OptimizeForSize 与 OptimizeForAlignment 模板参数提供对小对象优化的控制.

某些应用需要 boost::any 的功能, 又知道被存对象的典型/最大大小, 并希望避免动态内存分配开销. 为方便起见, 这类应用可为 boost::anys::basic_any 创建 typedef, 把 OptimizeForSize 与 OptimizeForAlignment 模板参数分别设为类型的典型/最大大小与对齐. 存储大小与对齐不超过 OptimizeForSize 与 OptimizeForAlignment 值的可无抛出移动构造类型时, 将避免内存分配.

否则直接使用 boost::any.

basic_any 公有成员函数

  1. basic_any() noexcept;

    后置条件:

    this->empty() 为 true.

    		 
  2. template<typename ValueType> basic_any(const ValueType & value);

    复制 value, 使新实例的初始内容在类型与值上都与 value 等价.

    若 ValueType 可无抛出移动构造且 sizeof(value) <= OptimizeForSize 且 alignof(value) <= OptimizeForAlignment, 则不进行动态分配.

    抛出:

    		 std::bad_alloc, 或所含类型的拷贝构造函数引发的任何异常. 
  3. basic_any(const basic_any & other);

    拷贝构造函数, 把 other 的内容复制到新实例中, 使任何内容在类型与值上都与 other 的内容等价; 若 other 为空则为空.

    抛出:

    		 可能以 std::bad_alloc 异常失败, 或因所含类型的拷贝构造函数引发异常. 
  4. basic_any(basic_any && other) noexcept;

    移动构造函数, 把 other 的内容移入新实例并把 other 置空.

    后置条件:

    other->empty() 为 true

    抛出:

    		 无. 
  5. template<typename ValueType> 
  basic_any(ValueType && value, 
            typename std::enable_if<!std::is_same< basic_any &, ValueType >::value >::type * = 0, 
            typename std::enable_if<!std::is_const< ValueType >::value >::type * = 0);

    转发 value, 使新实例的初始内容在类型与值上都与转发前的 value 等价.

    若 ValueType 可无抛出移动构造且 sizeof(value) <= OptimizeForSize 且 alignof(value) <= OptimizeForAlignment, 则不进行动态分配.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 
  6. ~basic_any() noexcept;

    释放在管理实例时使用的全部资源.

    抛出:

    		 无. 
  7. basic_any & swap(basic_any & rhs) noexcept;

    交换 *this 与 rhs 的内容.

    返回:

    *this

    抛出:

    		 无. 
  8. basic_any & operator=(const basic_any & rhs);

    把 rhs 的内容复制到当前实例, 丢弃先前内容, 使新内容在类型与值上都与 rhs 的内容等价; 若 rhs.empty() 为空则为空.

    抛出:

    		 std::bad_alloc, 或所含类型的拷贝构造函数引发的任何异常. 赋值满足异常安全的强保证. 
  9. basic_any & operator=(basic_any && rhs) noexcept;

    把 rhs 的内容移入当前实例, 丢弃先前内容, 使新内容在类型与值上都与移动前的 rhs 内容等价; 若 rhs.empty() 为空则为空.

    后置条件:

    rhs->empty() 为 true

    抛出:

    		 无. 
  10. template<typename ValueType> basic_any & operator=(ValueType && rhs);

    转发 rhs, 丢弃先前内容, 使新内容在类型与值上都与转发前的 rhs 等价.

    若 ValueType 可无抛出移动构造且 sizeof(value) <= OptimizeForSize 且 alignof(value) <= OptimizeForAlignment, 则不进行动态分配.

    抛出:

    		 std::bad_alloc, 或所含类型的移动或拷贝构造函数引发的任何异常. 赋值满足异常安全的强保证. 
  11. bool empty() const noexcept;

    返回:

    true, 若实例为空; 否则为 false.

    抛出:

    		 无. 
  12. void clear() noexcept;

    后置条件:

    this->empty() 为 true

    		 
  13. const boost::typeindex::type_info & type() const noexcept;

    适用于针对编译期已知或仅运行期可知的类型进行查询.

    返回:

    若实例非空, 为所含值的 typeid; 否则为 typeid(void).
