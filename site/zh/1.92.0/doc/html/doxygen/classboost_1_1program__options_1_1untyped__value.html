类 untyped_value

boost::program_options::untyped_value

概要

// In header: <boost/program_options/value_semantic.hpp>


class untyped_value :
  public boost::program_options::value_semantic_codecvt_helper< char >
{
public:

  // public member functions
  untyped_value(bool = false);
  virtual std::string name() const;
  virtual unsigned min_tokens() const;
  virtual unsigned max_tokens() const;
  virtual bool is_composing() const;
  virtual bool is_required() const;
  virtual void xparse(boost::any &, const std::vector< std::string > &) const;
  virtual bool apply_default(boost::any &) const;
  virtual void notify(const boost::any &) const;
};

说明

指定值的简单处理方式的类: 值为字符串类型, 且只允许一个标记.

untyped_value 公有成员函数

  1. untyped_value(bool zero_tokens = false);
  2. virtual std::string name() const;

    返回选项的名称. 该名称仅对自动帮助消息有意义.

  3. virtual unsigned min_tokens() const;

    该选项在命令行上应存在的最少标记数量.

  4. virtual unsigned max_tokens() const;

    该选项在命令行上应存在的最多标记数量.

  5. virtual bool is_composing() const;

    如果来自不同源的值应当组合, 则返回 true. 否则, 使用第一个源的值, 其他源的值被丢弃.

  6. virtual bool is_required() const;

    如果必须给出值则返回 true. 非可选值

  7. virtual void 
xparse(boost::any & value_store, 
       const std::vector< std::string > & new_tokens) const;

    如果 'value_store' 已初始化, 或 new_tokens 有多个元素, 则抛出异常. 否则, 将 'new_tokens' 中的第一个字符串不经任何修改地赋给 'value_store'.

  8. virtual bool apply_default(boost::any &) const;

    什么都不做.

  9. virtual void notify(const boost::any &) const;

    什么都不做.
