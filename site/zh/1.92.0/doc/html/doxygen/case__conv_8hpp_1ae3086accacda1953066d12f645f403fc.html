函数模板 to_lower_copy

boost::to_lower_copy — 转换为小写.

概要

// In header: <boost/algorithm/string/case_conv.hpp>


template<typename OutputIteratorT, typename RangeT> 
  OutputIteratorT 
  to_lower_copy(OutputIteratorT Output, const RangeT & Input, 
                const std::locale & Loc = std::locale());

说明

输入序列的每个元素都被转换为小写. 结果为输入转换为小写后的副本. 它作为序列返回, 或复制到输出迭代器.

注释

此函数的第二个变体提供强异常安全保证

参数:

Output

结果将被复制到的输出迭代器

Input

一个输入范围

Loc

用于转换的 locale

返回:

指向最后插入字符之后位置的输出迭代器, 或输入的副本
