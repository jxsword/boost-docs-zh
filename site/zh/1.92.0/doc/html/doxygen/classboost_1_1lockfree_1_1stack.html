boost::lockfree::stack

概要

// In header: <boost/lockfree/stack.hpp>

template<typename T, typename... Options> 
class stack {
public:
  // types
  typedef T                                 value_type;
  typedef implementation_defined::allocator allocator; 
  typedef implementation_defined::size_type size_type; 

  // public member functions
  bool is_lock_free(void) const;
  explicit stack(void);
  template<typename U, typename Enabler = std::enable_if< has_capacity > > 
    explicit stack(typename boost::allocator_rebind< node_allocator, U >::type const &);
  template<typename Enabler = std::enable_if< has_capacity > > 
    explicit stack(allocator const &);
  template<typename Enabler = std::enable_if< !has_capacity > > 
    explicit stack(size_type);
  stack(const stack &) = delete;
  stack & operator=(const stack &) = delete;
  stack(stack &&) = delete;
  stack & operator=(stack &&) = delete;
  template<typename U, typename Enabler = std::enable_if< !has_capacity > > 
    stack(size_type, 
          typename boost::allocator_rebind< node_allocator, U >::type const &);
  template<typename Enabler = std::enable_if< !has_capacity > > 
    stack(size_type, node_allocator const &);
  template<typename Enabler = std::enable_if< !has_capacity > > 
    void reserve(size_type);
  template<typename Enabler = std::enable_if< !has_capacity > > 
    void reserve_unsafe(size_type);
  ~stack(void);
  bool push(const T &);
  bool push(T &&);
  bool bounded_push(const T &);
  bool bounded_push(T &&);
  template<typename ConstIterator> 
    ConstIterator push(ConstIterator, ConstIterator);
  template<std::size_t Extent> size_type push(boost::span< const T, Extent >);
  template<typename ConstIterator> 
    ConstIterator bounded_push(ConstIterator, ConstIterator);
  template<std::size_t Extent> 
    size_type bounded_push(boost::span< const T, Extent >);
  bool unsynchronized_push(const T &);
  bool unsynchronized_push(T &&);
  template<typename ConstIterator> 
    ConstIterator unsynchronized_push(ConstIterator, ConstIterator);
  template<std::size_t Extent> 
    size_type unsynchronized_push(boost::span< const T, Extent >);
  bool pop(T &);
  template<typename U, 
           typename Enabler = std::enable_if_t< std::is_convertible< T, U >::value > > 
    bool pop(U &);
  std::optional< T > pop(uses_optional_t);
  template<typename U> std::optional< U > pop(uses_optional_t);
  bool unsynchronized_pop(T &);
  template<typename U, 
           typename Enabler = std::enable_if_t< std::is_convertible< T, U >::value > >

  template<typename Functor> size_t consume_all_atomic(Functor &&);

说明

stack 类提供多写者/多读者栈, push 与 pop 是无锁的, 构造/析构必须同步. 它使用自由列表进行内存管理, 被释放的节点被推入自由列表, 在栈销毁前不会归还操作系统.

策略:

  • boost::lockfree::fixed_sized<>, 默认为 boost::lockfree::fixed_sized<false>
    可用于在 push 期间完全禁用动态内存分配, 以确保无锁行为.
    若数据结构配置为固定大小, 内部节点存储在数组中, 并通过数组索引寻址. 这把栈的可能大小限制为索引类型可寻址的元素数量 (通常为 2**16-2), 但在缺少双宽度比较交换指令的平台上, 这是实现无锁的最佳方式.

  • boost::lockfree::capacity<>, 可选
    若此模板实参传给选项, 栈的大小将在编译期设置.
    此选项隐含 fixed_sized<true>

  • boost::lockfree::allocator<>, 默认为 boost::lockfree::allocator<std::allocator<void>>
    指定用于内部自由列表的分配器

要求:

  • T 必须有复制构造函数或移动构造函数

stack 公有成员函数

  1. bool is_lock_free(void) const;

    警告

    它只检查栈顶节点和自由列表是否能以无锁方式修改. 在大多数平台上, 若此返回为 true, 则整个实现是无锁的. 使用 c++0x 风格原子操作时, 无法提供完全精确的实现, 因为需要测试每个内部节点, 而若后续节点还会从操作系统分配, 这是不可能的.

    返回:

    若实现是无锁的则为 true.

  15. bool push(const T & v);

    把对象 t 推入栈.

    注释

    线程安全. 若内部内存池耗尽且内存池不是固定大小, 将从操作系统分配新节点. 该操作可能不是无锁的.

    后置条件:

    若能分配内部节点, 对象将被推入栈

    返回:

    若 push 操作成功则为 true.

    抛出:

    		 若内存分配器抛出异常

  37. bool empty(void) const;

    注释

    它只保证在函数执行期间的某个时刻栈曾经为空. 由于栈可能被其他线程修改, 在程序逻辑中使用该值通常并不实用.

    返回:

    若栈为空则为 true.
