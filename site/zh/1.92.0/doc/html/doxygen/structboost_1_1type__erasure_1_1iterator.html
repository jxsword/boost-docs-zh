结构体模板 iterator

boost::type_erasure::iterator

概要

// In header: <boost/type_erasure/iterator.hpp>

template<typename Traversal, typename T = _self, 
         typename Reference = boost::use_default, 
         typename DifferenceType = std::ptrdiff_t> 
struct iterator {
  // types
  typedef unspecified    value_type;     
  typedef Reference      reference;      
  typedef DifferenceType difference_type;
};

说明

iterator 概念可用于任何迭代器类别.

迭代器的 value_type 是推导得到的. 要强制其为特定类型, 请使用 same_type 概念.

示例:

mpl::vector<
  iterator<boost::forward_traversal_tag>,
  same_type<iterator<boost::forward_traversal_tag>::value_type, int> > int_it;

模板参数

  1. typename Traversal

    必须是 boost::incrementable_traversal_tag、boost::single_pass_traversal_tag、boost::forward_traversal_tag、boost::bidirectional_traversal_tag 与 boost::random_access_traversal_tag 之一.

  2. typename T = _self

    表示迭代器的占位符.

  3. typename Reference = boost::use_default

    引用类型. 若为 boost::use_default, 则 reference 将为 value_type&.

  4. typename DifferenceType = std::ptrdiff_t

    迭代器的 difference_type.
