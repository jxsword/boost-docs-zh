函数模板 load

boost::property_tree::load

概要

// In header: <boost/property_tree/ptree_serialization.hpp>


template<typename Archive, typename K, typename D, typename C> 
  void load(Archive & ar, basic_ptree< K, D, C > & t, const unsigned int);

说明

从给定档案反序列化属性树.

注释

除从常规档案反序列化外, 此函数还支持从要求名-值对的档案加载, 例如 XML 档案. 格式应为 boost::property_tree::save 所用的格式.

参数:

ar

从中加载序列化属性树的档案. 该档案应符合 Boost.Serialization 库所规定的 concept.

t

要反序列化的属性树.

后置条件:

t 将包含来自 ar 的反序列化数据.
