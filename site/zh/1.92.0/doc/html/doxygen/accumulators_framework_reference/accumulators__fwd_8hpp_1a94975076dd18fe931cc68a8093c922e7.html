BOOST_ACCUMULATORS_MAX_ARGS

概要

// In header: <boost/accumulators/accumulators_fwd.hpp>

BOOST_ACCUMULATORS_MAX_ARGS

说明

可为 accumulator_set 的累加函数指定的最大参数数量. 默认为 15.
