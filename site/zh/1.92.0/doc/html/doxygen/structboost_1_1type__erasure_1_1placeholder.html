结构体 placeholder

boost::type_erasure::placeholder

概要

// In header: <boost/type_erasure/placeholder.hpp>


struct placeholder {
};

说明

占位符在整个库中被大量使用. 每个占位符都必须派生自 placeholder. 库开箱即用地提供了若干占位符, 但如果你想要更具描述性的名称, 也欢迎自定义. 占位符 _self 比较特殊: 它在一切可能之处被用作默认值.

究竟什么是占位符? 占位符在概念中充当模板形参的替代物. 库在把对象存入 any 时, 会自动把概念中使用的所有占位符替换为实际涉及的类型.

例如, 在下面的代码中,

any<copy_constructible<_a>, _a> x(1);

库看到我们正在构造一个 any, 它使用 _a 占位符与 int. 于是它把 _a 绑定到 int, 并实例化 copy_constructible<int>.

当涉及多个占位符时, 你必须使用 tuple, 或显式传递绑定, 但替换机制仍以相同方式工作.
