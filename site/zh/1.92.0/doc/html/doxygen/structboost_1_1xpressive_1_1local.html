结构体模板 local

boost::xpressive::local — local<> 是对存储在 local 自身内值的引用的惰性封装. 它用于 xpressive 语义动作内部.

概要

// In header: <boost/xpressive/regex_actions.hpp>

template<typename T> 
struct local : public proto::terminal::type {

  // public member functions
  local();
  explicit local(T const &);
  T & get();
  T const & get() const;
};

说明

下面是如何在语义动作中使用 local<> 的示例.

using namespace boost::xpressive;
local<int> i(0);
std::string str("1!2!3?");
// count the exciting digits, but not the
// questionable ones.
sregex rex = +( _d [ ++i ] >> '!' );
regex_search(str, rex);
assert( i.get() == 2 );

注释

正如 "local" 之名所示, local<> 对象以及引用它们的正则表达式绝不应离开局部作用域. local 对象中存储的值会在 local<>'s 生命周期结束时销毁, 任何仍持有该 local<> 的正则表达式对象将留下悬垂引用.

模板参数

  1. typename T

    局部变量的类型.

local 公有成员函数

  1. local();
    存储一个类型为 T 的默认构造值.
  2. explicit local(T const & t);
    存储一个类型为 T 的默认构造值.

    参数:

    t

    初始值.

    		 
  3. T & get();
    获取被封装的值.
  4. T const & get() const;
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
