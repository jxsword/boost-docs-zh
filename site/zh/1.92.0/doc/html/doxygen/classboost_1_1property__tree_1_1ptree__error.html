类 ptree_error

boost::property_tree::ptree_error — 所有属性树错误类的基类. 派生自 std::runtime_error. 调用成员函数 what 可获得与错误关联的人类可读消息.

概要

// In header: <boost/property_tree/exceptions.hpp>


class ptree_error : public std::runtime_error {
public:

  // public member functions
  ptree_error(const std::string &);
};

说明

ptree_error 公有成员函数

  1. ptree_error(const std::string & what);
    以给定的消息实例化 ptree_error.

    参数:

    what

    与此错误关联的消息.
