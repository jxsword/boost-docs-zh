结构体模板 c_regex_traits

boost::xpressive::c_regex_traits — 封装标准 C locale 函数, 供 basic_regex<> 类模板使用.

概要

// In header: <boost/xpressive/traits/c_regex_traits.hpp>

template<typename Char> 
struct c_regex_traits {
  // types
  typedef Char                           char_type;      
  typedef std::basic_string< char_type > string_type;    
  typedef unspecified                    locale_type;    
  typedef unspecified                    char_class_type;
  typedef regex_traits_version_2_tag     version_tag;    
  typedef unspecified                    base_type;      

  // public member functions
  c_regex_traits(locale_type const & = locale_type());
  bool operator==(c_regex_traits< char_type > const &) const;
  bool operator!=(c_regex_traits< char_type > const &) const;
  string_type fold_case(char_type) const;
  locale_type imbue(locale_type);

  // public static functions
  static char_type widen(char);
  static unsigned char hash(char_type);
  static char_type translate(char_type);
  static char_type translate_nocase(char_type);
  static char_type tolower(char_type);
  static char_type toupper(char_type);
  static bool in_range(char_type, char_type, char_type);
  static bool in_range_nocase(char_type, char_type, char_type);
  template<typename FwdIter> static string_type transform(FwdIter, FwdIter);
  template<typename FwdIter> 
    static string_type transform_primary(FwdIter, FwdIter);
  template<typename FwdIter> 
    static string_type lookup_collatename(FwdIter, FwdIter);
  template<typename FwdIter> 
    static char_class_type lookup_classname(FwdIter, FwdIter, bool);
  static bool isctype(char_type, char_class_type);
  static int value(char_type, int);
  static locale_type getloc();
};

说明

c_regex_traits 公有成员函数

  1. c_regex_traits(locale_type const & loc = locale_type());

    初始化 c_regex_traits 对象以使用全局 C locale.

  2. bool operator==(c_regex_traits< char_type > const &) const;

    检查两个 c_regex_traits 对象是否相等

    返回:

    true. 

  3. bool operator!=(c_regex_traits< char_type > const &) const;

    检查两个 c_regex_traits 对象是否不相等

    返回:

    false. 

  4. string_type fold_case(char_type ch) const;

    返回一个 string_type, 其中包含与传入字符在忽略大小写时比较相等的所有字符. 仅当 has_fold_case<c_regex_traits<Char> >value 为 true 时才能调用此函数.

    参数:

    ch

    源字符.

    返回:

    string_type, 其中包含忽略大小写时等于 ch 的所有字符

    		 
  5. locale_type imbue(locale_type loc);

    无操作

c_regex_traits 公有静态函数

  1. static char_type widen(char ch);

    把 char 转换为 Char

    参数:

    ch

    源字符.

    返回:

    若 Char 为 char 则为 ch; 若 Char 为 wchar_t 则为 std::btowc(ch).

    		 
  2. static unsigned char hash(char_type ch);

    返回 [0, UCHAR_MAX] 范围内 Char 的哈希值

    参数:

    ch

    源字符.

    返回:

    0 到 UCHAR_MAX 之间 (含) 的一个值.

    		 
  3. static char_type translate(char_type ch);

    无操作

    参数:

    ch

    源字符.

    返回:

    ch 

  4. static char_type translate_nocase(char_type ch);

    使用当前全局 C locale 把字符转换为小写.

    参数:

    ch

    源字符.

    返回:

    若 Char 为 char 则为 std::tolower(ch); 若 Char 为 wchar_t 则为 std::towlower(ch).

    		 
  5. static char_type tolower(char_type ch);

    使用当前全局 C locale 把字符转换为小写.

    参数:

    ch

    源字符.

    返回:

    若 Char 为 char 则为 std::tolower(ch); 若 Char 为 wchar_t 则为 std::towlower(ch).

    		 
  6. static char_type toupper(char_type ch);

    使用当前全局 C locale 把字符转换为大写.

    参数:

    ch

    源字符.

    返回:

    若 Char 为 char 则为 std::toupper(ch); 若 Char 为 wchar_t 则为 std::towupper(ch).

    		 
  7. static bool in_range(char_type first, char_type last, char_type ch);

    检查字符是否在字符范围内.

    参数:

    first

    范围的下界 (含) .

    last

    范围的上界 (含) .

    ch

    源字符.

    返回:

    first <= ch && ch <= last. 

  8. static bool in_range_nocase(char_type first, char_type last, char_type ch);

    检查字符是否在字符范围内, 忽略大小写.

    重要

    默认实现不做正确的 Unicode 大小写折叠, 但这是用标准 C locale 函数所能做到的最佳结果.

    参数:

    first

    范围的下界 (含) .

    last

    范围的上界 (含) .

    ch

    源字符.

    返回:

    in_range(first, last, ch) || in_range(first, last, tolower(ch)) || in_range(first, last, toupper(ch)) 

  9. template<typename FwdIter> 
  static string_type transform(FwdIter begin, FwdIter end);

    返回迭代器范围 [F1, F2) 所指定字符序列的排序键, 使得如果字符序列 [G1, G2) 排在字符序列 [H1, H2) 之前, 则 v.transform(G1, G2) < v.transform(H1, H2).

    重要

    当前未使用

  10. template<typename FwdIter> 
  static string_type transform_primary(FwdIter begin, FwdIter end);

    返回迭代器范围 [F1, F2) 所指定字符序列的排序键, 使得如果在不考虑字符大小写的情况下字符序列 [G1, G2) 排在字符序列 [H1, H2) 之前, 则 v.transform_primary(G1, G2) < v.transform_primary(H1, H2).

    重要

    当前未使用

  11. template<typename FwdIter> 
  static string_type lookup_collatename(FwdIter begin, FwdIter end);

    返回表示由迭代器范围 [F1, F2) 指定的字符序列构成的排序元素的字符序列. 如果该字符序列不是有效的排序元素, 则返回空字符串.

    重要

    当前未使用

  12. template<typename FwdIter> 
  static char_class_type 
  lookup_classname(FwdIter begin, FwdIter end, bool icase);

    对由指定字符序列表示的字符类名, 返回对应的位掩码表示.

    参数:

    begin

    指向表示字符类名的字符序列起点的向前迭代器.

    end

    字符序列的终点.

    icase

    指定返回的位掩码是否应表示该字符类的不区分大小写版本.

    返回:

    表示字符类的位掩码.

    		 
  13. static bool isctype(char_type ch, char_class_type mask);

    将字符与字符类位掩码进行测试.

    参数:

    ch

    要测试的字符.

    mask

    用于测试的字符类位掩码.

    要求:

    mask 是 lookup_classname 返回的位掩码, 或多个此类掩码按位或的结果.

    返回:

    若字符属于任一指定字符类则为 true, 否则为 false.

    		 
  14. static int value(char_type ch, int radix);

    把数字字符转换为它所表示的整数.

    参数:

    ch

    该数字字符.

    radix

    用于转换的基数.

    要求:

    radix 是 8、10 或 16 之一.

    返回:

    若 ch 不是数字字符则为 -1, 否则为该字符的整数值. 若 char_type 为 char, 则使用 std::strtol 进行转换. 若 char_type 为 wchar_t, 则使用 std::wcstol.

    		 
  15. static locale_type getloc();

    无操作
