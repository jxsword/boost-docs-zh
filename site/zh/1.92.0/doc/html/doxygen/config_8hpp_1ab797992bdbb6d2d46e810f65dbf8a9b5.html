宏 BOOST_MPI_CALLING_CONVENTION

BOOST_MPI_CALLING_CONVENTION — 指定底层 C MPI 回调将使用的调用约定.

概要

// In header: <boost/mpi/config.hpp>

BOOST_MPI_CALLING_CONVENTION

说明

这是一个 Windows 专用宏, 将在内部用于声明任何将用作 MPI 回调的函数的调用约定, 例如在 MPI_Op_create 调用中内部定义的函数. 此宏可能只对希望绕过 Boost.MPI 并在某些情况下注册自己回调的用户有用, 例如通过 MPI_Op_create.
