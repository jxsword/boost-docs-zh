类 typed_value_base

boost::program_options::typed_value_base

概要

// In header: <boost/program_options/value_semantic.hpp>


class typed_value_base {
public:

  // public member functions
  virtual const std::type_info & value_type() const = 0;
  virtual ~typed_value_base();
};

说明

所有具有固定类型且愿意向外界宣告此类型的选项的基类. 任何你想查明其类型的 'value_semantics' 都可以 dynamic_cast 为 typed_value_base. 如果转换成功, 即可调用 'type' 方法.

typed_value_base 公有成员函数

  1. virtual const std::type_info & value_type() const = 0;
  2. virtual ~typed_value_base();
