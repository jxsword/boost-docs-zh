宏 BOOST_TRIBOOL_THIRD_STATE

BOOST_TRIBOOL_THIRD_STATE — 为 tribool 的第三种状态声明一个新名称.

概要

// In header: <boost/logic/tribool.hpp>

BOOST_TRIBOOL_THIRD_STATE(Name)

说明

使用此宏为 tribool 的第三种状态声明一个新名称. 此状态可以有任意数量的新名称 (除 indeterminate 之外) , 它们彼此等价. 新名称将被置于宏展开所在的命名空间中.

示例: BOOST_TRIBOOL_THIRD_STATE(true_or_false)

tribool x(true_or_false); // 可能设置 x 的值 if (true_or_false(x)) { // 无法确定 x 的值 }
