类 intercommunicator

boost::mpi::intercommunicator — 不同群组的进程之间的通信设施.

概要

// In header: <boost/mpi/intercommunicator.hpp>


class intercommunicator : public boost::mpi::communicator {
public:

  // public member functions
  intercommunicator(const MPI_Comm &, comm_create_kind);
  intercommunicator(const communicator &, int, const communicator &, int);
  int local_size() const;
  boost::mpi::group local_group() const;
  int local_rank() const;
  int remote_size() const;
  boost::mpi::group remote_group() const;
  communicator merge(bool) const;
};

说明

类 intercommunicator 提供来自不同群组的进程之间的通信设施. 互联通信器总是与两个进程群组相关联: 一个本地进程群组, 包含发起 MPI 操作的进程 (例如 send 操作中的发送方); 一个远程进程群组, 包含作为 MPI 操作目标的进程.

虽然互联通信器的点对点操作与内部通信器 (intracommunicator, 仅在单个进程群组内通信) 基本相同, 但与互联通信器的所有通信都发生在本地群组的进程与远程群组的进程之间; 群组内的通信必须使用另一个 (内部) 通信器.

intercommunicator 公有成员函数

  1. intercommunicator(const MPI_Comm & comm, comm_create_kind kind);

    基于 MPI 互联通信器 comm 构建新的 Boost.MPI 互联通信器.

    comm 可以是任何有效的 MPI 互联通信器. 如果 comm 是 MPI_COMM_NULL, 则会创建一个空通信器 (不能用于通信), 且 kind 参数被忽略. 否则, kind 参数决定 Boost.MPI 通信器与 comm: 的关联方式

    • 如果 kind 是 comm_duplicate, 则复制 (duplicate) comm 以创建新的通信器. 当 Boost.MPI 通信器 (及其所有副本) 被销毁时, 该新通信器将被释放. 仅当底层 MPI 实现支持 MPI 2.0 时才允许此选项; MPI 1.x 不提供互联通信器的复制.

    • 如果 kind 是 comm_take_ownership, 则取得 comm 的所有权. 当所有 Boost.MPI 通信器离开作用域时, 它将被自动释放.

    • 如果 kind 是 comm_attach, 则此 Boost.MPI 通信器将引用现有的 MPI 通信器 comm, 但当 Boost.MPI 通信器离开作用域时不会释放 comm. 仅当通信器由用户管理时才应使用此选项.

  2. intercommunicator(const communicator & local, int local_leader, 
                  const communicator & peer, int remote_leader);

    构造一个新的互联通信器, 其本地群组为 local, 远程群组为 peer. 之后即可使用该互联通信器在两个群组的进程之间通信. 此构造函数等价于调用 MPI_Intercomm_create.

    参数:

    local

    包含将进入本地群组的所有进程的内部通信器.

    local_leader

    local 内部通信器中将作为其领导者的秩.

    peer

    包含将进入远程群组的所有进程的内部通信器.

    remote_leader

    peer 群组中将作为其领导者的秩.

    		 
  3. int local_size() const;

    返回本地群组的大小, 即属于该群组的本地进程数量.

  4. boost::mpi::group local_group() const;

    返回本地群组, 包含此互联通信器中的所有本地进程.

  5. int local_rank() const;

    返回此进程在本地群组中的秩.

  6. int remote_size() const;

    返回远程群组的大小, 即属于远程群组的进程数量.

  7. boost::mpi::group remote_group() const;

    返回远程群组, 包含此互联通信器中的所有远程进程.

  8. communicator merge(bool high) const;

    将此互联通信器中的本地群组和远程群组合并为一个新的内部通信器, 其中包含两个群组进程的并集. 此方法等价于 MPI_Intercomm_merge.

    参数:

    high

    此群组中的进程是否应比另一群组中的进程拥有更高的秩号. 特定群组内的每个进程应具有相同的 high 值.

    返回:

    新的合并后的内部通信器
