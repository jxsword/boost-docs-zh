类模板 indeterminate_name

boost::logic::indeterminate_name — 指定 tribool 不确定值名称的 locale 刻面.

概要

// In header: <boost/logic/tribool_io.hpp>

template<typename CharT> 
class indeterminate_name :
  public std::locale::facet, private boost::noncopyable
{
public:
  // types
  typedef CharT                      char_type;  
  typedef std::basic_string< CharT > string_type;

  // public member functions
  indeterminate_name();
  explicit indeterminate_name(const string_type &);
  string_type name() const;

  // public data members
  static std::locale::id id;  // Uniquily identifies this facet with the locale. 
};

说明

当指定了 std::boolalpha 时, 该刻面用于对 tribool 值执行 I/O. 仅当 C++ 标准库实现支持 locale 时, 此类模板才可用.

indeterminate_name 公有成员函数

  1. indeterminate_name();
    用默认名称构造该刻面.
  2. explicit indeterminate_name(const string_type & initial_name);
    用给定的不确定值名称构造该刻面.
  3. string_type name() const;
    返回不确定值的名称.
