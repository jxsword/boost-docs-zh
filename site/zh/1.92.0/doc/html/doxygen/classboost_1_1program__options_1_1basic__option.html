类模板 basic_option

boost::program_options::basic_option

概要

// In header: <boost/program_options/option.hpp>

template<typename charT> 
class basic_option {
public:

  // public member functions
  basic_option();
  basic_option(const std::string &, const std::vector< std::string > &);

  // public data members
  std::string string_key;
  int position_key;
  std::vector< std::basic_string< charT > > value;
  std::vector< std::basic_string< charT > > original_tokens;
  bool unregistered;
  bool case_insensitive;
};

说明

在输入源中找到的选项. 包含一个键和一个值. 键可以是字符串 (选项名), 也可以是整数 (在输入源中的位置) —— 适用于未指定名称的情况. 后者仅适用于命令行. 模板参数指定用于存储选项值的 char 类型.

basic_option 公有成员函数

  1. basic_option();
  2. basic_option(const std::string & xstring_key, 
             const std::vector< std::string > & xvalue);

basic_option 公有数据成员

  1. std::string string_key;

    此选项的字符串键. 特意与模板参数无关.

  2. int position_key;

    此选项的位置键. 所有没有显式名称的选项从 0 开始按顺序编号. 如果选项有显式名称, 则 'position_key' 等于 -1. 在名称被隐式添加的情况下, position_key 和 string_key 可能都被指定.

  3. std::vector< std::basic_string< charT > > value;

    选项的值

  4. std::vector< std::basic_string< charT > > original_tokens;

    此选项由之创建的原始未更改标记.

  5. bool unregistered;

    若选项未被识别则为 true. 在这种情况下, 'string_key' 和 'value' 是对源进行纯语法解析的结果. 原始标记可从 "original_tokens" 成员恢复.

  6. bool case_insensitive;

    若 string_key 必须以不区分大小写的方式处理则为 true.
