结构体模板 root_typeof_helper

boost::units::root_typeof_helper

概要

// In header: <boost/units/operators.hpp>

template<typename Radicand, typename Index> 
struct root_typeof_helper {
  // types
  typedef unspecified type;  // specifies the result type 

  // public static functions
  static BOOST_CONSTEXPR type value(const Radicand &);
};

说明

root 用于以编译期已知索引对运行期对象取根的辅助工具. 此模板旨在被特化. 所有特化必须符合此处所示的接口. 对于整数实参 N, Index 将是传给 pow 的类型, 或 static_rational<N>.

root_typeof_helper 公有静态函数

  1. static BOOST_CONSTEXPR type value(const Radicand & base);
    执行运行期计算.
