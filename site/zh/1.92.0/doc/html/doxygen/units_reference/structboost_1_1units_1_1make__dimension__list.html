结构体模板 make_dimension_list

boost::units::make_dimension_list

概要

// In header: <boost/units/dimension.hpp>

template<typename Seq> 
struct make_dimension_list {
  // types
  typedef unspecified type;
};

说明

把维度列表约简为基数形式. 该算法合并重复的基本维度标签, 并按标签序数值对结果列表排序. 保证解析为相同维度的维度列表
由相同的类型表示.

实参应为一个 MPL forward sequence, 其中包含 dim 模板的实例.

结果同样是 MPL forward sequence. 它还支持以下元函数, 以便作为维度使用.

  • mpl::plus 仅对两个相等的维度定义, 并原样返回实参.

  • mpl::minus 仅对两个相等的维度定义, 并原样返回实参.

  • mpl::negate 将原样返回其实参.

  • mpl::times 对任意维度定义, 并将对应指数相加.

  • mpl::divides 对任意维度定义, 并从左操作数的对应指数中减去右操作数的指数. 缺失的基本维度标签假定指数为零.

  • static_power 接受一个维度和一个 static_rational, 把该维度的所有指数乘以该 static_rational.

  • static_root 接受一个维度和一个 static_rational, 把该维度的所有指数除以该 static_rational.
