宏 BOOST_UNITS_DEFINE_CONVERSION_OFFSET

BOOST_UNITS_DEFINE_CONVERSION_OFFSET

概要

// In header: <boost/units/absolute.hpp>

BOOST_UNITS_DEFINE_CONVERSION_OFFSET(From, To, type_, value_)

说明

定义两个绝对单位之间偏移量的宏. 要求值以目标单位表示, 例如

BOOST_UNITS_DEFINE_CONVERSION_OFFSET(celsius_base_unit, fahrenheit_base_unit, double, 32.0);

BOOST_UNITS_DEFINE_CONVERSION_FACTOR 还需要指定转换因子. 与 BOOST_UNITS_DEFINE_CONVERSION_FACTOR 类似, 此宏同时定义正向与反向转换, 因此像上面那样定义从 celsius 到 fahrenheit 的转换, 也会定义从 fahrenheit 到 celsius 的逆转换.
