函数模板 operator<<

boost::units::operator<<

概要

// In header: <boost/units/io.hpp>


template<typename Char, typename Traits, typename Dimension, typename System> 
  std::basic_ostream< Char, Traits > & 
  operator<<(std::basic_ostream< Char, Traits > & os, 
             const unit< Dimension, System > & u);

说明

以基本单位及其指数列表的形式打印 unit. @c symbol_format 输出例如 "m s^-1" 或 "J". @c name_format 输出例如 "meter second^-1" 或 "joule". @c raw_format 输出例如 "m s^-1" 或 "meter kilogram^2 second^-2". @c typename_format 输出类型名本身 (目前仅在 GCC 上做 demangle) .
