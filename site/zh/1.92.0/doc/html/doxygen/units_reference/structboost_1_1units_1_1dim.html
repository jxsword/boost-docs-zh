结构体模板 dim

boost::units::dim — 单个基本维度的维度标签/指数对.

概要

// In header: <boost/units/dim.hpp>

template<typename T, typename V> 
struct dim {
  // types
  typedef dim         type;      
  typedef unspecified tag;       
  typedef T           tag_type;  
  typedef V           value_type;
};

说明

dim 类表示单个维度标签/维度指数对. 即 dim<tag_type,value_type> 是一个对, 其中 tag_type 表示所表示的基本维度, value_type 以 static_rational 的形式表示该基本维度的指数. tag_type 必须派生自 base_dimension 的某个特化. 为以下 Boost.MPL 元函数提供了特化 - @c mpl::plus 针对两个 @c dim - @c mpl::minus 针对两个 @c dim - @c mpl::negate 针对一个 @c dim

这些元函数都只作用于指数, 并要求 dim 操作数具有相同的基本维度标签. 此外, 支持与 static_rational 相乘和相除. - @c mpl::times 针对一个 @c static_rational 与一个 @c dim (两种顺序均可) - @c mpl::divides 针对一个 @c static_rational 与一个 @c dim (两种顺序均可)

这些元函数同样只作用于指数.
