类模板 static_rational

boost::units::static_rational

概要

// In header: <boost/units/static_rational.hpp>

template<integer_type N, integer_type D = 1> 
class static_rational {
public:
  // types
  typedef unspecified                               tag; 
  typedef static_rational< Numerator, Denominator > type;  // static_rational<N,D> reduced by GCD 

  // public static functions
  static BOOST_CONSTEXPR integer_type numerator();
  static BOOST_CONSTEXPR integer_type denominator();

  // public member functions
  static_rational();

  // public data members
  BOOST_STATIC_CONSTEXPR integer_type Numerator;
  BOOST_STATIC_CONSTEXPR integer_type Denominator;
};

说明

这是编译期有理数的一个实现, 其中 static_rational<N,D> 表示分子为 N、分母为 D 的有理数. 由于 static_rational 的多个等价值 (例如 static_rational<6,2>==static_rational<3>) 可能引起歧义, 静态有理数应始终通过 static_rational<N,D>::type 访问. 模板特化阻止了零分母的实例化 (即 static_rational<N,0>) . 以下编译期算术运算符只为 static_rational 变量提供 (long 与 static_rational 之间没有定义运算符) :

  • mpl::negate

  • mpl::plus

  • mpl::minus

  • mpl::times

  • mpl::divides

static_power 与 static_root 都未对 static_rational 定义. 这是因为模板类型不能是浮点值, 而有理数的幂与根可能产生浮点值.

static_rational 公有静态函数

  1. static BOOST_CONSTEXPR integer_type numerator();
  2. static BOOST_CONSTEXPR integer_type denominator();

static_rational 公有成员函数

  1. static_rational();
