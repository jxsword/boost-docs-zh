结构体模板 homogeneous_system

boost::units::homogeneous_system

概要

// In header: <boost/units/homogeneous_system.hpp>

template<typename L> 
struct homogeneous_system {
};

说明

能唯一表示任何可由线性无关基本单位集合组合而成单位的系统. 把具有这种系统的单位重新绑定到不同维度是安全的.

不要直接构造此模板. 请改用 make_system.
