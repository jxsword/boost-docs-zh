宏 BOOST_UNITS_DEFAULT_CONVERSION

BOOST_UNITS_DEFAULT_CONVERSION

概要

// In header: <boost/units/conversion.hpp>

BOOST_UNITS_DEFAULT_CONVERSION(Source, Dest)

说明

指定在没有直接转换可用时应用的默认转换. Source 是一个基本单位. Dest 是任何具有相同维度的单位.
