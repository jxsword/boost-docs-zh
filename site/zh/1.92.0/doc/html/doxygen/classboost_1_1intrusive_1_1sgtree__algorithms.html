说明

sgtree_algorithms 以一个 NodeTraits 类配置, 该类封装要操作的节点的信息. NodeTraits 必须支持以下接口:

Typedefs:

node: 构成二叉搜索树的节点的类型

node_ptr: 指向节点的指针

const_node_ptr: 指向 const 节点的指针

静态函数:

static node_ptr get_parent(const_node_ptr n);

static void set_parent(node_ptr n, node_ptr parent);

static node_ptr get_left(const_node_ptr n);

static void set_left(node_ptr n, node_ptr left);

static node_ptr get_right(const_node_ptr n);

static void set_right(node_ptr n, node_ptr right);

sgtree_algorithms 公有静态函数

  1. static node_ptr get_header(const_node_ptr n) noexcept;

    要求: 'n' 是树中的节点或头节点.

    效果: 返回树的头节点.

    复杂度: 对数.

    抛出: 无.

  2. static node_ptr begin_node(const_node_ptr header) noexcept;

    要求: 'header' 是树的头节点.

    效果: 返回树的第一个节点; 若树为空则返回头节点.

    复杂度: 常量时间.

    抛出: 无.

  3. static node_ptr end_node(const_node_ptr header) noexcept;

    要求: 'header' 是树的头节点.

    效果: 返回树的头节点.

    复杂度: 常量时间.

    抛出: 无.

  4. static void swap_tree(node_ptr header1, node_ptr header2) noexcept;

    要求: header1 与 header2 必须是两棵树的头节点.

    效果: 交换两棵树. 函数返回后, header1 将包含指向第二棵树的链接, header2 将包含指向第一棵树的链接.

    复杂度: 常数.

    抛出: 无.

  5. static void swap_nodes(node_ptr node1, node_ptr node2) noexcept;

    要求: node1 与 node2 不能是两棵树的头节点.

    效果: 交换两个节点. 函数返回后, node1 被插入到函数调用前 node2 的位置; node2 被插入到函数调用前 node1 的位置.

    复杂度: 对数.

    抛出: 无.

    注释: 若按排序规则 node1 与 node2 不等价, 此函数将破坏容器排序不变式.

    实验性函数

    复杂度: 常数.

    抛出: 无.

    注释: 若按排序规则 node1 与 node2 不等价, 此函数将破坏容器排序不变式.
