类型 style_t

boost::program_options::command_line_style::style_t

概要

// In header: <boost/program_options/cmdline.hpp>


enum style_t { allow_long = 1, allow_short = allow_long << 1, 
               allow_dash_for_short = allow_short << 1, 
               allow_slash_for_short = allow_dash_for_short << 1, 
               long_allow_adjacent = allow_slash_for_short << 1, 
               long_allow_next = long_allow_adjacent << 1, 
               short_allow_adjacent = long_allow_next << 1, 
               short_allow_next = short_allow_adjacent << 1, 
               allow_sticky = short_allow_next << 1, 
               allow_guessing = allow_sticky << 1, 
               long_case_insensitive = allow_guessing << 1, 
               short_case_insensitive = long_case_insensitive << 1, 
               case_insensitive = (long_case_insensitive | short_case_insensitive), 
               allow_long_disguise = short_case_insensitive << 1, 
               unix_style = (allow_short | short_allow_adjacent | short_allow_next | allow_long | long_allow_adjacent | long_allow_next | allow_sticky | allow_guessing | allow_dash_for_short), 
               default_style = unix_style };

说明

选项的各种可能样式.

有以 "--" 开头的长选项, 以及以 "-" 或 "/" 开头的短选项. 两种都可以允许或禁止, 见 allow_long 和 allow_short. 短选项所允许的字符也是可配置的.

选项的值可以在与名称相同的标记中指定 ("--foo=bar"), 也可以在下一个标记中指定.

可以用与短选项相同的字符引入长选项, 见 allow_long_disguise.

此外还支持猜测 (仅指定选项的前缀) 和不区分大小写的处理.

allow_long
允许 "--long_name" 样式.
allow_short
允许 "-<单字符" 样式.
allow_dash_for_short
允许短选项使用 "-".
allow_slash_for_short
允许短选项使用 "/".
long_allow_adjacent

允许长选项的选项参数在同一个标记中, 如 --foo=10

long_allow_next

允许长选项的选项参数在下一个标记中.

short_allow_adjacent

允许短选项的选项参数在同一个标记中.

short_allow_next

允许短选项的选项参数在下一个标记中.

allow_sticky

允许将多个短选项合并在一起, 使 "-s -k" 变成 "-sk". 除最后一个外, 所有选项都不得接受参数. 例如, 如果 "-s" 接受参数, 则 "k" 会被当作参数, 而不是另一个短选项. DOS 风格的短选项不能粘连.

allow_guessing

允许长选项使用缩写拼写, 只要它们能无歧义地识别长选项. 若启用猜测, 则任何长选项名都不应是其他长选项名的前缀.

long_case_insensitive

忽略长选项的大小写差异.

short_case_insensitive

忽略短选项的大小写差异.

case_insensitive

忽略所有选项的大小写差异.

allow_long_disguise

允许长选项使用单个选项起始字符, 例如 -foo=10

unix_style

大致传统的 unix 风格.

default_style

默认样式.
