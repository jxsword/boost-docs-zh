函数模板 trim_right

boost::trim_right — 右修剪.

概要

// In header: <boost/algorithm/string/trim.hpp>


template<typename SequenceT> 
  void trim_right(SequenceT & Input, const std::locale & Loc = std::locale());

说明

移除输入中的所有尾随空格. 输入序列被原地修改.

参数:

Input

一个输入序列

Loc

用于 'space' 分类判断的 locale
