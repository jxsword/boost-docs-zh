函数 all_to_all

boost::mpi::all_to_all — 从每个进程向所有其他进程发送数据.

概要

// In header: <boost/mpi/collectives.hpp>


template<typename T> 
  void all_to_all(const communicator & comm, 
                  const std::vector< T > & in_values, 
                  std::vector< T > & out_values);
template<typename T> 
  void all_to_all(const communicator & comm, const T * in_values, 
                  T * out_values);
template<typename T> 
  void all_to_all(const communicator & comm, 
                  const std::vector< T > & in_values, int n, 
                  std::vector< T > & out_values);
template<typename T> 
  void all_to_all(const communicator & comm, const T * in_values, int n, 
                  T * out_values);

说明

all_to_all 是一种集合算法, 它把 p 个值从每个进程传输到每个其他进程. 在进程 i 上, in_values 向量的第 j 个值被发送到进程 j, 并放置在 out_values 向量的第 i 个位置, 该向量位于进程 j. 值的类型 T 可以是可序列化的类型或具有关联 MPI 数据类型的类型. 如果提供了 n, 则会从一个进程向另一个进程传输 n 个值的数组.

当类型 T 具有关联的 MPI 数据类型时, 此例程调用 MPI_Alltoall 来分散值.

参数:

comm

发生 all-to-all 通信的通信器.

in_values

包含要发送给每个进程的值的向量或指向存储的指针, 按进程 ID 号索引.

out_values

一个向量或指向存储的指针, 将被更新以包含从其他进程接收的值. out_values 中的第 j 个值将来自秩为 j 的进程.
