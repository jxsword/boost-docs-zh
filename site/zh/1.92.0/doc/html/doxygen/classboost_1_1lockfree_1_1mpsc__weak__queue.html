说明

基于 Dmitry Vyukov 的 MPSC 算法的多生产者/单消费者队列.

push 与 pop 方法在有限条指令内执行 (无等待执行), 但队列整体并不严格意义上无锁 (参见限制).

默认情况下, 自由列表管理节点内存. 被释放的节点在内部回收, 而不是归还操作系统, 直到队列销毁.

限制. 关于此算法限制的一篇很好的文章见 Ode to a Vyukov Queue.

  • Push 原子性: push 先交换尾指针再链接前一节点. 若生产者线程在这两步之间终止或停滞, 队列将变得不一致. 消费者会看到断链并停止交付元素, 直到生产者完成链接. 若生产者永久终止, 队列将永久损坏.

  • 不可线性化: 每个生产者的 FIFO 顺序得到保持, 但并发生产者之间不存在全局顺序. 当并发 push 正在进行时, 即使队列非空, pop 也可能返回 false.

策略.

  • boost::lockfree::freelist (默认 true):
    启用时, 被释放的节点进入内部自由列表以供重用, 避免重复分配. 禁用时, 由分配器处理每次分配与释放. 分配器操作可能不是无锁的.

  • boost::lockfree::fixed_sized (默认 false):
    启用时, push 绝不执行动态分配, 保证无锁行为. 节点驻留在按索引寻址的固定数组中. 容量受索引类型范围限制 (通常为 2^16-2). 在缺少双宽度 CAS 的平台上进行无锁操作时必须使用此选项.

  • boost::lockfree::capacity (可选):
    在编译期设置队列大小. 隐含 fixed_sized<true>.

  • boost::lockfree::allocator (默认 std::allocator<void>).

要求.

  • T 必须可移动构造.

  • T 必须可移动赋值.

注释

仅支持一个消费者线程. 支持多个生产者线程.

mpsc_weak_queue 公有成员函数

  1. bool is_lock_free() const;

    警告

    仅检查头部、尾部和自由列表是否能以无锁方式修改. 在大多数平台上, 若返回 true, 则整个实现是无锁的.

    返回:

    若实现是无锁的则为 true.

  14. bool empty() const;

    检查队列是否为空.

    注释

    仅在没有其他线程并发修改队列时, 结果才是准确的.

    返回:

    若队列为空则为 true, 否则为 false.

    		 
  15. bool push(const T & t);

    把一个值推入队列.

    注释

    线程安全. 多个生产者可以并发调用 push. 当内存池耗尽且内存池不是固定大小时, 通过分配器分配新节点, 该操作可能不是无锁的.

    返回:

    若值被推入则为 true, 若节点分配失败则为 false.

  17. template<typename Enabler = std::enable_if< use_freelist > > 
  bool bounded_push(const T & t);

    把值推入队列而不分配内存.

    注释

    线程安全. 多个生产者可以并发调用 bounded_push. 与 push 不同, bounded_push 绝不分配内存; 当自由列表耗尽时它会失败.

    返回:

    若值被推入则为 true, 若自由列表为空则为 false.

    抛出:

    		 若节点构造期间分配器抛出异常, 则抛出 std::bad_alloc.

  21. bool pop(T & ret);

    从队列弹出一个元素.

    注释

    线程安全且无等待. 应只有一个消费者线程调用 pop. 即使操作失败, 输出实参也可能被修改. 当并发 push 正在进行时, 即使队列非空, pop 也可能返回 false (参见限制).

    返回:

    若弹出元素则为 true, 若队列为空则为 false.
