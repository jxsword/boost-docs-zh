函数模板 test_any

boost::mpi::test_any — 测试是否有任一非阻塞请求已完成.

概要

// In header: <boost/mpi/nonblocking.hpp>


template<typename ForwardIterator> 
  optional< std::pair< status, ForwardIterator > > 
  test_any(ForwardIterator first, ForwardIterator last);

说明

本例程接受存储在迭代器范围 [first,last) 中的一组请求, 并测试其中是否有请求已完成. 本例程与 wait_any 类似, 但不会阻塞等待请求完成. 它提供与 MPI_Testany 等价的功能.

参数:

first

表示请求对象序列起始的迭代器.

last

表示请求对象序列结尾的迭代器.

返回:

若有未决请求已完成, 则返回一个 pair, 包含与已完成操作对应的状态对象以及指向已完成请求的迭代器; 否则返回空的 optional<>.
