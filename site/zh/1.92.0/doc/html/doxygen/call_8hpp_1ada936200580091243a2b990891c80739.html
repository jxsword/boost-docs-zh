函数 call

boost::type_erasure::call

概要

// In header: <boost/type_erasure/call.hpp>


template<typename Concept, typename Op, class... U> 
  unspecified call(const binding< Concept > & binding, const Op &, 
                   U &&... args);
template<typename Op, class... U> unspecified call(const Op &, U &&... args);

说明

分派一个类型擦除的函数.

Op 必须是 Concept 中存在的基础概念. 其签名决定 call 的实参如何处理. 若实参是一个 placeholder, call 期望一个使用该 placeholder 的 any. 该 any 由 call 解包. 它存储的类型必须与 binding 指定的类型相同. Op 签名中不是占位符的实参将原样传递.

若未指定 binding, 将从实参推导. 这自然要求至少有一个实参是 any. 此时, 所有 any 实参必须具有相同的 binding.

示例:

typedef mpl::vector<
  copy_constructible<_b>,
  addable<_a, int, _b> > concept;
any<concept, _a> a = ...;
any<concept, _b> b(call(addable<_a, int, _b>(), a, 10));

addable 的签名为 _b(const _a&, const int&)

返回:

运算的结果. 若 Op 签名的结果类型是一个占位符, 结果将被转换为相应的 any 类型.

抛出:

 bad_function_call, 若 relaxed 在 Concept 中且存在类型不匹配.
