说明

这是二叉搜索树的一种实现. 搜索树中的节点对其子节点和父节点都有引用. 这使得可以从给定节点遍历整棵树, 使迭代器的实现成为指向节点的指针. 在树的顶部有一个特殊用途的节点. 该节点的 parent 指针指向树的根, 其 left 指针指向树中最左边的节点, right 指针指向最右边的节点. 此节点用于表示 end 迭代器. +---------+ header------------------------------>| | | | +----------(left)--------| |--------(right)---------+ | +---------+ | | | | | | (parent) | | | | | | | | +---------+ | root of tree ..|......................> | | | | | D | | | | | | | +----<mdash></mdash>+------<mdash></mdash>+----<mdash></mdash>+ |

bstree_algorithms 以一个 NodeTraits 类配置, 该类封装要操作的节点的信息. NodeTraits 必须支持以下接口:

Typedefs:

node: 构成二叉搜索树的节点的类型

node_ptr: 指向节点的指针

const_node_ptr: 指向 const 节点的指针

静态函数:

static node_ptr get_parent(const_node_ptr n);

static void set_parent(node_ptr n, node_ptr parent);

static node_ptr get_left(const_node_ptr n);

static void set_left(node_ptr n, node_ptr left);

static node_ptr get_right(const_node_ptr n);

static void set_right(node_ptr n, node_ptr right);

bstree_algorithms 公有静态函数

  1. static node_ptr begin_node(const_node_ptr header) noexcept;

    要求: 'header' 是树的头节点.

    效果: 返回树的第一个节点; 若树为空则返回头节点.

    复杂度: 常量时间.

    抛出: 无.

  2. static node_ptr end_node(const_node_ptr header) noexcept;

    要求: 'header' 是树的头节点.

    效果: 返回树的头节点.

    复杂度: 常量时间.

    抛出: 无.

  3. static node_ptr root_node(const_node_ptr header) noexcept;

    要求: 'header' 是树的头节点.

    效果: 若存在则返回树的根, 否则返回头节点

    复杂度: 常量时间.

    抛出: 无.

  4. static bool unique(const_node_ptr n) noexcept;

    要求: 'n' 是树中的节点, 或由 init(...) 或 init_node 初始化的节点.

    效果: 若节点由 init() 或 init_node() 初始化则返回 true.

    复杂度: 常量时间.

    抛出: 无.

  5. static node_ptr get_header(const_node_ptr n);

    复杂度: 对数.

    抛出: 无.

  6. static void swap_nodes(node_ptr node1, node_ptr node2) noexcept;

    要求: node1 与 node2 不能是两棵树的头节点.

    效果: 交换两个节点. 函数返回后, node1 被插入到函数调用前 node2 的位置; node2 被插入到函数调用前 node1 的位置.

    复杂度: 对数.

    抛出: 无.

    注释: 若按排序规则 node1 与 node2 不等价, 此函数将破坏容器排序不变式.

    效果: 使用先前 "insert_check" 填充的 "commit_data" 所获得的信息把 new_node 插入集合.

    复杂度: 常量时间.

    抛出: 无.

    注释: 此函数只有先前执行过 "insert_unique_check" 填充 "commit_data" 时才有意义. 在 "insert_check" 与 "insert_commit" 调用之间不得插入或擦除任何值.

  30. template<typename KeyType, typename KeyNodePtrCompare> 
  static std::pair< node_ptr, bool > 
  insert_unique_check(const_node_ptr header, const KeyType & key, 
                      KeyNodePtrCompare comp, 
                      insert_commit_data & commit_data);

    要求: "header" 必须是树的头节点. KeyNodePtrCompare 是一个函数对象, 它诱导的严格弱序与创建该树时使用的严格弱序兼容. NodePtrCompare 把 KeyType 与一个 node_ptr 进行比较.

    效果: 按 "comp" 检查树中是否存在等价于 "key" 的节点, 并在不存在等价节点时获取实现常数时间节点插入所需的信息.

    返回: 若存在等价值, 返回包含指向已存在节点的 node_ptr 和 false 的对组. 若不存在等价键可插入, 返回对组的布尔成员为 true, 并填充 "commit_data", 该数据应与 "insert_commit" 函数一起使用以实现常数时间的插入函数.

    复杂度: 平均复杂度至多为对数级.

    抛出: 若 "comp" 抛出异常.

    注释: 构造节点代价高昂且用户不希望树中存在两个等价节点时可用此函数提升性能: 若存在等价值, 已构造的对象必须丢弃. 很多时候, 节点中用于施加排序的部分比节点本身的构造代价低得多, 此函数提供了用该部分检查插入是否会成功的机会.

    若检查成功, 用户可以构造节点并使用 "insert_commit" 以常数时间插入节点. 这使插入的总复杂度为对数级: check(O(log(N)) + commit(O(1)).

    "commit_data" 仅在集合没有更多对象被插入或擦除的情况下, 对随后的 "insert_unique_commit" 保持有效.

  39. template<typename Cloner, typename Disposer> 
  static void clone(const_node_ptr source_header, node_ptr target_header, 
                    Cloner cloner, Disposer disposer);

    要求: "cloner" 必须是一个接受 node_ptr 并返回其新克隆节点的函数对象. "disposer" 必须接受一个 node_ptr 且不应抛出异常.

    效果: 首先对树中除头节点外的每个节点调用 void disposer::operator()(node_ptr) 清空目标树.

    然后, 克隆 "source_header" 所指向的整棵树, 用 node_ptr Cloner::operator()(node_ptr) 克隆每个源节点以获得目标树的节点. 若 "cloner" 抛出异常, 被克隆的目标节点将用 void disposer(node_ptr ) 释放.

    复杂度: 与源树的元素数量加上调用此函数时目标树的元素数量成线性关系.

    抛出: 若 cloner 函子抛出异常. 若发生这种情况, 目标节点将被释放.
