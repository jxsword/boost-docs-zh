宏 BOOST_MPI_BCAST_BOTTOM_WORKS_FINE

BOOST_MPI_BCAST_BOTTOM_WORKS_FINE — 表示 MPI_Bcast 支持 MPI_BOTTOM.

概要

// In header: <boost/mpi/config.hpp>

BOOST_MPI_BCAST_BOTTOM_WORKS_FINE

说明

某些实现的 MPI_Bcast 在 MPI_BOTTOM 方面有问题. BullX MPI 和 LAM 似乎属于此类, 至少在某些版本上是. broacast_test.cpp 测试 test_skeleton_and_content 可用于检测这一点.
