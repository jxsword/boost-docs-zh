类型 error_type

boost::xpressive::regex_constants::error_type

概要

// In header: <boost/xpressive/regex_constants.hpp>



enum error_type { error_collate, error_ctype, error_escape, error_subreg, 
                  error_brack, error_paren, error_brace, error_badbrace, 
                  error_range, error_space, error_badrepeat, error_complexity, 
                  error_stack, error_badref, error_badmark, 
                  error_badlookbehind, error_badrule, error_badarg, 
                  error_badattr, error_internal };

说明

regex_error 类型使用的错误码

error_collate

表达式包含无效的排序元素名称.

error_ctype

表达式包含无效的字符类名称.

error_escape

表达式包含无效的转义字符或末尾悬挂的转义符.

error_subreg

表达式包含无效的反向引用.

error_brack

表达式包含不匹配的 [ 与 ].

error_paren

表达式包含不匹配的 ( 与 ).

error_brace

表达式包含不匹配的 { 与 }.

error_badbrace

表达式在 {} 表达式中包含无效的范围.

error_range

表达式包含无效的字符范围, 例如 [b-a].

error_space

内存不足, 无法把表达式转换为有限状态机.

error_badrepeat

*?+{ 之一前面没有有效的正则表达式.

error_complexity

对正则表达式尝试匹配的复杂度超过了预设级别.

error_stack

内存不足, 无法判断正则表达式能否匹配指定的字符序列.

error_badref

嵌套 regex 未初始化.

error_badmark

命名捕获的无效使用.

error_badlookbehind

检测到创建变宽后行断言的尝试.

error_badrule

检测到规则的无效使用.

error_badarg

动作的一个参数未绑定.

error_badattr

尝试从未初始化的属性读取.

error_internal

发生了内部错误.
