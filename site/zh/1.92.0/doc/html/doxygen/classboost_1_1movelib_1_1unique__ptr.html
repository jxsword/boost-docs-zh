类模板 unique_ptr

boost::movelib::unique_ptr

概要

// In header: <boost/move/unique_ptr.hpp>

template<typename T, typename D = default_delete<T> > 
class unique_ptr {
public:
  // types
  typedef see_documentation pointer;     
  typedef see_documentation element_type;
  typedef D                 deleter_type;

  // public member functions
  unique_ptr(const unique_ptr &) = delete;
  unique_ptr & operator=(const unique_ptr &) = delete;
  unique_ptr() noexcept;
  unique_ptr(std::nullptr_t) noexcept;
  template<typename Pointer> explicit unique_ptr(Pointer p ) noexcept;
  template<typename Pointer> 
    unique_ptr(Pointer, see_documentation d1 ) noexcept;
  unique_ptr(std::nullptr_t, see_documentation) noexcept;
  template<typename Pointer> 
    unique_ptr(Pointer, see_documentation d2 ) noexcept;
  unique_ptr(std::nullptr_t, see_documentation) noexcept;
  unique_ptr(unique_ptr &&) noexcept;
  template<typename U, typename E> 
    unique_ptr(BOOST_RV_REF_BEG_IF_CXX11  unique_ptr< U, E > BOOST_RV_REF_END_IF_CXX11 u ) noexcept;
  ~unique_ptr();
  unique_ptr & operator=(unique_ptr &&) noexcept;
  template<typename U, typename E> 
    unique_ptr & operator=(unique_ptr< U, E > &&) noexcept;
  unique_ptr & operator=(std::nullptr_t) noexcept;
  element_type & operator*() const noexcept;
  element_type & operator[](std::size_t) const noexcept;
  pointer operator->() const noexcept;
  pointer get() const noexcept;
  D & get_deleter() noexcept;
  const D & get_deleter() const noexcept;
  explicit operator bool() const noexcept;
  pointer release() noexcept;
  template<typename Pointer> void reset(Pointer) noexcept;
  void reset() noexcept;
  void reset(std::nullptr_t) noexcept;
  void swap(unique_ptr &) noexcept;
};

说明

独占指针 (unique pointer) 是一种拥有另一个对象并通过指针管理该另一对象的对象.

更确切地说, 独占指针是一个对象 u, 它存储着指向另一个对象 p 的指针, 并在 u 自身被销毁时 (例如离开块作用域时) 释放 p. 在这种语境下, 称 u 拥有 p.

u 释放 p 所用的机制称为 p 的关联删除器, 它是一个函数对象, 正确调用它将导致 p 被适当处置 (通常是删除).

记 u.p 表示 u 存储的指针, u.d 表示关联删除器. 应请求时, u 可以用另一个指针和删除器重置 (替换) u.p 和 u.d, 但必须先通过关联删除器妥善处置其拥有的对象, 此种替换才能视为完成.

此外, u 可以应请求将所有权转移给另一个独占指针 u2. 此种转移完成后, 以下后置条件成立:

  • u2.p 等于转移前的 u.p,

  • u.p 等于 nullptr, 且

  • 若转移前的 u.d 维护着状态, 则该状态已转移给 u2.d.

与 reset 的情况一样, u2 必须先通过转移前的关联删除器妥善处置其转移前拥有的对象, 所有权转移才能视为完成.

由本子条款规定的 unique_ptr 模板实例化得到的类型 U 的每个对象, 都具有上文规定的独占指针的严格所有权语义. 为部分满足这些语义, 每个这样的 U 都是可移动构造 (MoveConstructible) 且可移动赋值 (MoveAssignable) 的, 但不可复制构造 (CopyConstructible) 也不可复制赋值 (CopyAssignable). unique_ptr 的模板参数 T 可以是不完整类型.

unique_ptr 的用途包括: 为动态分配的内存提供异常安全, 将动态分配内存的所有权传递给函数, 以及从函数返回动态分配的内存.

如果 T 是数组类型 (例如 unique_ptr<MyType[]>), 接口会稍有改变:

  • 指向 T 的派生类型的指针会被构造函数和 reset 拒绝.

  • 不提供观察器 operator* 和 operator->.

  • 提供索引观察器 operator[].

模板参数

  1. typename T

    提供所存储指针的类型.

  2. typename D = default_delete<T>

    删除器类型:

    • 模板参数 D 的默认类型是 default_delete. 客户端提供的模板实参 D 应为函数对象类型, 到函数的左值引用, 或到函数对象类型的左值引用; 给定类型 D 的值 d 和类型 unique_ptr<T, D>::pointer 的值 ptr, 表达式 d(ptr) 必须有效, 且其效果是按该删除器适当的方式处置该指针.

    • 如果删除器的类型 D 不是引用类型, D 应满足 Destructible 的要求.

    • 如果类型 remove_reference<D>::type::pointer 存在, 它应满足 NullablePointer 的要求.

unique_ptr 公有类型

  1. typedef see_documentation pointer;

    如果类型 remove_reference<D>::type::pointer 存在, 则它是 remove_reference<D>::type::pointer 的同义词. 否则它是 T* 的同义词.

  2. typedef see_documentation element_type;

    如果 T 是数组类型, 则 element_type 等于 T. 否则, 如果 T 是 U[] 形式的类型, 则 element_type 等于 U.

unique_ptr 公有成员函数

  1. unique_ptr(const unique_ptr &) = delete;
  2. unique_ptr & operator=(const unique_ptr &) = delete;
  3. unique_ptr() noexcept;

    要求: D 应满足 DefaultConstructible 的要求, 且该构造不得抛出异常.

    效果: 构造一个不拥有任何对象的 unique_ptr 对象, 对存储的指针和存储的删除器进行值初始化.

    后置条件: get() == nullptr. get_deleter() 返回对存储的删除器的引用.

    备注: 如果此构造函数以指针类型或引用类型实例化模板实参 D, 则程序非良构.

  4. unique_ptr(std::nullptr_t) noexcept;

    效果: 与 unique_ptr() (默认构造函数) 相同.

  5. template<typename Pointer> 
  explicit unique_ptr(Pointer p  BOOST_MOVE_DOCIGN) noexcept;

    要求: D 应满足 DefaultConstructible 的要求, 且该构造不得抛出异常.

    效果: 构造拥有 p 的 unique_ptr, 用 p 初始化存储的指针, 并对存储的删除器进行值初始化.

    后置条件: get() == p. get_deleter() 返回对存储的删除器的引用.

    备注: 如果此构造函数以指针类型或引用类型实例化模板实参 D, 则程序非良构. 除非以下条件成立, 否则此构造函数不参与重载决议:

    • 如果 T 不是数组类型, 且 Pointer 可隐式转换为 pointer.

    • 如果 T 是数组类型, 且 Pointer 是指向 element_type 的 CV 限定更强的指针.

  6. template<typename Pointer> 
  unique_ptr(Pointer p, see_documentation d1  BOOST_MOVE_DOCIGN) noexcept;

    此构造函数的签名取决于 D 是否为引用类型.

    • 如果 D 是非引用类型 A, 则签名为 unique_ptr(pointer p, const A& d).

    • 如果 D 是左值引用类型 A&, 则签名为 unique_ptr(pointer p, A& d).

    • 如果 D 是左值引用类型 const A&, 则签名为 unique_ptr(pointer p, const A& d).

    要求: 以下两者之一:

    • D 不是左值引用类型, 且 d 是左值或 const 右值. D 应满足 CopyConstructible 的要求, 且 D 的复制构造函数不得抛出异常. 此 unique_ptr 将持有 d 的一份副本.

    • D 是左值引用类型, 且 d 是左值. D 所引用的类型不必可复制构造 (CopyConstructible) 也不必可移动构造 (MoveConstructible). 此 unique_ptr 将持有引用左值 d 的 D.

    效果: 构造拥有 p 的 unique_ptr 对象, 用 p 初始化存储的指针, 并按上述描述初始化删除器.

    后置条件: get() == p. get_deleter() 返回对存储的删除器的引用. 如果 D 是引用类型, 则 get_deleter() 返回对左值 d 的引用.

    备注: 除非以下条件成立, 否则此构造函数不参与重载决议:

    • 如果 T 不是数组类型, 且 Pointer 可隐式转换为 pointer.

    • 如果 T 是数组类型, 且 Pointer 是指向 element_type 的 CV 限定更强的指针.

  7. unique_ptr(std::nullptr_t, see_documentation d1) noexcept;

    效果: 效果与 template<class Pointer> unique_ptr(Pointer p, deleter_arg_type1 d1) 相同, 另外还有 get() == nullptr 

  8. template<typename Pointer> 
  unique_ptr(Pointer p, see_documentation d2  BOOST_MOVE_DOCIGN) noexcept;

    此构造函数的签名取决于 D 是否为引用类型.

    • 如果 D 是非引用类型 A, 则签名为 unique_ptr(pointer p, A&& d).

    • 如果 D 是左值引用类型 A&, 则签名为 unique_ptr(pointer p, A&& d).

    • 如果 D 是左值引用类型 const A&, 则签名为 unique_ptr(pointer p, const A&& d).

    要求: 以下两者之一:

    • D 不是左值引用类型, 且 d 是非 const 右值. D 应满足 MoveConstructible 的要求, 且 D 的移动构造函数不得抛出异常. 此 unique_ptr 将持有由 d 移动构造而来的值.

    • D 是左值引用类型且 d 是右值, 则程序非良构.

    效果: 构造拥有 p 的 unique_ptr 对象, 用 p 初始化存储的指针, 并按上述描述初始化删除器.

    后置条件: get() == p. get_deleter() 返回对存储的删除器的引用. 如果 D 是引用类型, 则 get_deleter() 返回对左值 d 的引用.

    备注: 除非以下条件成立, 否则此构造函数不参与重载决议:

    • 如果 T 不是数组类型, 且 Pointer 可隐式转换为 pointer.

    • 如果 T 是数组类型, 且 Pointer 是指向 element_type 的 CV 限定更强的指针.

  9. unique_ptr(std::nullptr_t, see_documentation d2) noexcept;

    效果: 效果与 template<class Pointer> unique_ptr(Pointer p, deleter_arg_type2 d2) 相同, 另外还有 get() == nullptr 

  10. unique_ptr(unique_ptr && u) noexcept;

    要求: 如果 D 不是引用类型, D 应满足 MoveConstructible 的要求. 从类型 D 的右值构造删除器不得抛出异常.

    效果: 通过将所有权从 u 转移到 *this 来构造 unique_ptr. 如果 D 是引用类型, 则此删除器从 u 的删除器复制构造; 否则, 此删除器从 u 的删除器移动构造.

    后置条件: get() 产生构造之前 u.get() 产生的值. get_deleter() 返回对由 u.get_deleter() 构造的存储删除器的引用. 如果 D 是引用类型, 则 get_deleter() 与 u.get_deleter() 都引用同一个左值删除器.

  11. template<typename U, typename E> 
  unique_ptr(BOOST_RV_REF_BEG_IF_CXX11  unique_ptr< U, E > BOOST_RV_REF_END_IF_CXX11 u  BOOST_MOVE_DOCIGN) noexcept;

    要求: 如果 E 不是引用类型, 从类型 E 的右值构造删除器必须是良构的且不得抛出异常. 否则, E 是引用类型, 从类型 E 的左值构造删除器必须是良构的且不得抛出异常.

    备注: 除非以下条件成立, 否则此构造函数不参与重载决议:

    • unique_ptr<U, E>::pointer 可隐式转换为 pointer,

    • U 不是数组类型, 且

    • D 是引用类型且 E 与 D 类型相同; 或 D 不是引用类型且 E 可隐式转换为 D.

    效果: 通过将所有权从 u 转移到 *this 来构造 unique_ptr. 如果 E 是引用类型, 则此删除器从 u 的删除器复制构造; 否则, 此删除器从 u 的删除器移动构造.

    后置条件: get() 产生构造之前 u.get() 产生的值. get_deleter() 返回对由 u.get_deleter() 构造的存储删除器的引用.

  12. ~unique_ptr();

    要求: 表达式 get_deleter()(get()) 必须良构, 行为必须有良好定义, 且不得抛出异常.

    效果: 如果 get() == nullpt1r, 则无效果. 否则 get_deleter()(get()).

    注意: 使用 default_delete 要求 T 是完整类型

  13. unique_ptr & operator=(unique_ptr && u) noexcept;

    要求: 如果 D 不是引用类型, D 应满足 MoveAssignable 的要求, 且从类型 D 的右值赋值删除器不得抛出异常. 否则, D 是引用类型; remove_reference<D>::type 应满足 CopyAssignable 的要求, 且从类型 D 的左值赋值删除器不得抛出异常.

    效果: 将所有权从 u 转移到 *this, 如同先调用 reset(u.release()) 再调用 get_deleter() = std::forward<D>(u.get_deleter()).

    返回: *this.

  14. template<typename U, typename E> 
  unique_ptr & operator=(unique_ptr< U, E > && u) noexcept;

    要求: 如果 E 不是引用类型, 从类型 E 的右值赋值删除器必须是良构的且不得抛出异常. 否则, E 是引用类型, 从类型 E 的左值赋值删除器必须是良构的且不得抛出异常.

    备注: 除非以下条件成立, 否则此运算符不参与重载决议:

    • unique_ptr<U, E>::pointer 可隐式转换为 pointer, 且

    • U 不是数组类型.

    效果: 将所有权从 u 转移到 *this, 如同先调用 reset(u.release()) 再调用 get_deleter() = std::forward<E>(u.get_deleter()).

    返回: *this.

  15. unique_ptr & operator=(std::nullptr_t) noexcept;

    效果: reset().

    后置条件: get() == nullptr

    返回: *this.

  16. element_type & operator*() const noexcept;

    要求: get() != nullptr.

    返回: *get().

    备注</b: 如果 T 是数组类型, 则程序非良构. 

  17. element_type & operator[](std::size_t i) const noexcept;

    要求: i 小于存储指针所指向数组中的元素数量.

    返回: get()[i].

    备注</b: 如果 T 不是数组类型, 则程序非良构. 

  18. pointer operator->() const noexcept;

    要求: get() != nullptr.

    返回: get().

    注意: 典型用法通常要求 T 是完整类型.

    备注</b: 如果 T 是数组类型, 则程序非良构. 

  19. pointer get() const noexcept;

    返回: 存储的指针.

  20. D & get_deleter() noexcept;

    返回: 对存储的删除器的引用.

  21. const D & get_deleter() const noexcept;

    返回: 对存储的删除器的引用.

  22. explicit operator bool() const noexcept;

    返回: 返回: get() != nullptr.

  23. pointer release() noexcept;

    后置条件: get() == nullptr.

    返回: 调用 release 开始时 get() 所具有的值.

  24. template<typename Pointer> void reset(Pointer p) noexcept;

    要求: 表达式 get_deleter()(get()) 必须良构, 行为必须有良好定义, 且不得抛出异常.

    效果: 将 p 赋给存储的指针, 然后如果存储指针的旧值 old_p 不等于 nullptr, 则调用 get_deleter()(old_p). 注意: 这些操作的顺序很重要, 因为调用 get_deleter() 可能销毁 *this.

    后置条件: get() == p. 注意: 如果调用 get_deleter() 销毁了 *this, 则此后置条件不成立, 因为 this->get() 不再是有效的表达式.

    备注: 除非以下条件成立, 否则此构造函数不参与重载决议:

    • 如果 T 不是数组类型, 且 Pointer 可隐式转换为 pointer.

    • 如果 T 是数组类型, 且 Pointer 是指向 element_type 的 CV 限定更强的指针.

  25. void reset() noexcept;

    要求: 表达式 get_deleter()(get()) 必须良构, 行为必须有良好定义, 且不得抛出异常.

    效果: 将 nullptr 赋给存储的指针, 然后如果存储指针的旧值 old_p 不等于 nullptr, 则调用 get_deleter()(old_p). 注意: 这些操作的顺序很重要, 因为调用 get_deleter() 可能销毁 *this.

    后置条件: get() == p. 注意: 如果调用 get_deleter() 销毁了 *this, 则此后置条件不成立, 因为 this->get() 不再是有效的表达式.

  26. void reset(std::nullptr_t) noexcept;

    效果: 与 reset() 相同

  27. void swap(unique_ptr & u) noexcept;

    要求: get_deleter() 应可交换 (swappable), 且在 swap 下不得抛出异常.

    效果: 对 *this 与 u 的存储指针和存储删除器调用 swap.
