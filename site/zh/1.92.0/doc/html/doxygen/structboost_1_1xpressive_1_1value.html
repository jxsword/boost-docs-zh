结构体模板 value

boost::xpressive::value — value<> 是可在 xpressive 语义动作中使用的值的惰性封装.

概要

// In header: <boost/xpressive/regex_actions.hpp>

template<typename T> 
struct value :
  public proto::extends< proto::terminal< T >::type, value< T > >
{

  // public member functions
  value();
  explicit value(T const &);
  T & get();
  T const & get() const;
};

说明

下面是展示 value<> 何处有用的示例.

sregex good_voodoo(boost::shared_ptr<int> pi)
{
    using namespace boost::xpressive;
    // Use val() to hold the shared_ptr by value:
    sregex rex = +( _d [ ++*val(pi) ] >> '!' );
    // OK, rex holds a reference count to the integer.
    return rex;
}

在上面的代码中, xpressive::val() 是返回 value<> 对象的函数. 若此处未使用 val(), 运算 ++*pi 将被急切地求值一次, 而不是在正则表达式匹配发生时惰性求值.

模板参数

  1. typename T

    要存储值的类型.

value 公有成员函数

  1. value();
    存储一个默认构造的 T.
  2. explicit value(T const & t);
    存储 t 的副本.

    参数:

    t

    初始值.

    		 
  3. T & get();
    这是一个为方便使用而提供的重载成员函数. 它与上述函数仅在所接受的参数上有所不同.
  4. T const & get() const;
    获取存储的值.
