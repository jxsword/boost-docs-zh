函数模板 let

boost::xpressive::let — 在构造 regex_iterator 或 regex_token_iterator 时, 把语义动作中的局部变量绑定到占位符.

概要

// In header: <boost/xpressive/regex_actions.hpp>


template<typename... ArgBindings> unspecified let(ArgBindings const &... args);

说明

xpressive::let() 与 match_results::let() 的用途相同; 即把占位符绑定到一个局部值. 其目的是允许定义带语义动作的 regex, 使之引用尚不存在的对象. 语义动作不直接引用对象, 而是引用占位符, 占位符的值可在之后通过 let 表达式 指定. let 表达式 用 let() 创建, 并会传递给 regex_iterator 或 regex_token_iterator 的构造函数.

更多讨论参见用户指南中的 "引用非局部变量" 一节.

示例: 

// Define a placeholder for a map object:
placeholder<std::map<std::string, int> > _map;

// Match a word and an integer, separated by =>,
// and then stuff the result into a std::map<>
sregex pair = ( (s1= +_w) >> "=>" >> (s2= +_d) )
    [ _map[s1] = as<int>(s2) ];

// The string to parse
std::string str("aaa=>1 bbb=>23 ccc=>456");

// Here is the actual map to fill in:
std::map<std::string, int> result;

// Create a regex_iterator to find all the matches
sregex_iterator it(str.begin(), str.end(), pair, let(_map=result));
sregex_iterator end;

// step through all the matches, and fill in
// the result map
while(it != end)
    ++it;

std::cout << result["aaa"] << '\n';
std::cout << result["bbb"] << '\n';
std::cout << result["ccc"] << '\n';

以上代码输出:

1
23
456

参数:

args

一组参数绑定, 其中每个参数绑定都是一个赋值表达式, 其左侧必须是 placeholder<X> (对某个 X) 的实例, 右侧是 X 类型的左值.
