函数模板 register_skeleton_and_content

boost::mpi::python::register_skeleton_and_content — 注册一个类型以便在 Python 中使用 skeleton/content 机制.

概要

// In header: <boost/mpi/python.hpp>


template<typename T> 
  void register_skeleton_and_content(const T & value = T(), 
                                     PyTypeObject * type = 0);

说明

skeleton/content 机制在 Python 中只能用于之前已通过调用本函数注册过的 C++ 类型. 发送方与接收方都必须注册该类型. 允许对同一类型 T 多次调用本函数, 但每个进程每种类型只需调用一次. 类型 T 必须是 Serializable 的.

参数:

value

类型为 T 的样本对象, 若未指定 type, 将用它确定与 T 关联的 Python 类型.

type

与 C++ 类型 T 关联的 Python 类型. 若未提供, 将从同一值 value 推导.
