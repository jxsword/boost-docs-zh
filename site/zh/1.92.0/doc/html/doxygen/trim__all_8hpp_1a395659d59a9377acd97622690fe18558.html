函数模板 trim_all_if

boost::trim_all_if — 全修剪.

概要

// In header: <boost/algorithm/string/trim_all.hpp>


template<typename SequenceT, typename PredicateT> 
  void trim_all_if(SequenceT & Input, PredicateT IsSpace);

说明

移除输入中的所有前导与尾随空格, 并把其余所有空格压缩为单个字符. 输入序列被原地修改.

参数:

Input

一个输入序列

IsSpace

标识空格的一元谓词
