函数模板 trim_copy

boost::trim_copy — 修剪.

概要

// In header: <boost/algorithm/string/trim.hpp>


template<typename SequenceT> 
  SequenceT trim_copy(const SequenceT & Input, 
                      const std::locale & Loc = std::locale());

说明

移除输入中的所有前导与尾随空格. 结果是输入的修剪副本

注释

此函数提供强异常安全保证

参数:

Input

一个输入序列

Loc

用于 'space' 分类判断的 locale

返回:

输入的修剪副本
