结构体模板 FormatterConcept

boost::algorithm::FormatterConcept — Formatter 概念.

概要

// In header: <boost/algorithm/string/concept.hpp>

template<typename FormatterT, typename FinderT, typename IteratorT> 
struct FormatterConcept {

  // public member functions
  void constraints();
};

说明

定义 Formatter 概念. Formatter 是一个函子, 它获取查找操作的结果并以特定方式对其进行变换.

结果必须是一个 container_traits 支持的容器, 或对它的引用.

FormatterConcept 公有成员函数

  1. void constraints();
