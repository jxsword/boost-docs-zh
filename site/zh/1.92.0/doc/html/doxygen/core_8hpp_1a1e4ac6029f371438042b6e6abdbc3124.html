宏 BOOST_RV_REF_END

BOOST_RV_REF_END

概要

// In header: <boost/move/core.hpp>

BOOST_RV_REF_END

说明

此宏用于在标记为 BOOST_COPYABLE_AND_MOVABLE 或 BOOST_MOVABLE_BUT_NOT_COPYABLE 的模板类的移动构造函数和移动赋值中实现可移植语法. 由于宏对逗号分隔的模板实参有问题, 模板实参必须以 BOOST_RV_REF_BEG 开始并以 BOOST_RV_REF_END 结束
