结构体模板 pointer_plus_bits

boost::intrusive::pointer_plus_bits

概要

// In header: <boost/intrusive/pointer_plus_bits.hpp>

template<typename Pointer, std::size_t NumBits> 
struct pointer_plus_bits {
};

说明

此类应当具有用于在指针中嵌入额外信息位的静态方法. 这只是一个声明, 没有默认实现, 因为嵌入这些位的操作随指针类型而异.

若检测到某个指针类型的 has_pointer_plus_bits<>::value 非零, 则其实现可以利用这些操作将信息位嵌入指针.
