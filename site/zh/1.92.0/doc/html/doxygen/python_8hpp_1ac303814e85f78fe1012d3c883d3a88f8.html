函数模板 register_serialized

boost::mpi::python::register_serialized — 注册类型 T 以便在 Boost.MPI 中直接序列化.

概要

// In header: <boost/mpi/python.hpp>


template<typename T> 
  void register_serialized(const T & value = T(), PyTypeObject * type = 0);

说明

register_serialized 函数注册一个 C++ 类型, 以便在 Boost.MPI 中直接序列化. 在序列化表示 C++ 值的 Python 对象时, 直接序列化会省用 Python pickle 包. 直接序列化既能提升序列化性能 (Python pickle 可能非常低效), 也使不支持 pickle 的 Python 包装 C++ 对象能够被序列化.

参数:

value

类型 T 的样本值. 可用它计算与 C++ 类型 T 关联的 Python 类型.

type

与 C++ 类型 T 关联的 Python 类型. 若未提供, 将从同一值 value 推导.
