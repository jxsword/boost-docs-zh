函数模板 skip

boost::xpressive::skip — 指定匹配正则表达式时跳过哪些字符.

概要

// In header: <boost/xpressive/regex_primitives.hpp>


template<typename Skip> unspecified skip(Skip const & skip);

说明

skip() 指示正则引擎在匹配正则表达式时跳过某些字符. 它对编写忽略空白的正则表达式最有用. 例如, 下面指定了一个跳过空白与标点的正则表达式:

// A sentence is one or more words separated by whitespace
// and punctuation.
sregex word = +alpha;
sregex sentence = skip(set[_s | punct])( +word );

在上例中, 它的工作方式是在正则表达式中的每个基元之前插入 keep(*set[_s | punct]). "基元"包括字符串、字符集与嵌套 regex 等终端. 一个最终的 *set[_s | punct] 被添加到正则表达式末尾. 上面指定的正则表达式 sentence 等价于以下内容:

sregex sentence = +( keep(*set[_s | punct]) >> word )
                       >> *set[_s | punct];
重要

跳过不影响嵌套 regex 的处理方式, 因为它们被视为原子. 字符串字面量也被视为原子, 即字符串字面量内部不做跳过. 因此 skip(_s)("this that") 与 skip(_s)("this" >> as_xpr("that")) 不同. 前者仅在 "this" 与 "that" 之间只有一个空格时才匹配; 后者会跳过 "this" 与 "that" 之间的任何与全部空白.

参数:

skip

指定要跳过哪些字符的正则表达式.
