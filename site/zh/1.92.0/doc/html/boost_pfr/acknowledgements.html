致谢

非常感谢 Bruno Dutra 展示了在 C++14 中精确反射可聚合初始化类型的技术 (Manual type registering/structured bindings might be unnecessary).

非常感谢 Alexandr Poltavsky 最初实现了 BOOST_PFR_USE_LOOPHOLE == 1 技术并在 其博客中进行了描述.

非常感谢 Chris Beck 实现了检测偏移量并获取字段地址的功能, 避免了对布局兼容结构体进行 reinterpret_cast 所导致的未定义行为.

非常感谢参与正式评审的 Boost 社区成员, 特别是 Benedek Thaler、Steven Watanabe 和 Andrzej Krzemienski.
