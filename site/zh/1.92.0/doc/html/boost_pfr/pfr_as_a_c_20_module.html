将 PFR 用作 C++20 模块

注意

C++20 PFR 模块支持尚处于早期阶段, 目标、标志和行为未来可能发生变化

如果使用较新的 CMake, 请定义 CMake 选项 -DBOOST_USE_MODULES=1 来构建 C++20 模块, 并使 Boost::pfr CMake 构建目标提供该模块. 此后即可显式使用 C++20 模块 boost.pfr:

#include <iostream>
#include <string>

import boost.pfr;

struct some_person {
    std::string name;
    unsigned birth_year;
};

int main() {
    some_person val{"Edgar Allan Poe", 1809};

    std::cout << boost::pfr::get<0>(val)                // No macro!
        << " was born in " << boost::pfr::get<1>(val);  // Works with any aggregate!

    std::cout << '\n' << boost::pfr::io(val);           // Outputs: {"Edgar Allan Poe", 1809}
    std::cout << "\n." << boost::pfr::get_name<0, some_person>()
        << '=' << val.name << '\n';                     // Outputs: .name=Edgar Allan Poe
}

Boost::pfr CMake 目标使得可以在不同翻译单元中混用 PFR 库的包含与导入. 此外, 如果定义了 BOOST_USE_MODULES 宏, 则所有 boost/pfr/... 包含都会隐式执行 import boost.pfr;, 无需更改现有代码即可获得模块的全部好处.

注释

为了缩短编译时间, 请确保 import std; 在构建 boost.pfr 模块时可用 (CMake 日志中应出现一条 'Using import std;' 消息) .

如果不使用 CMake, 则可以基于 modules/boost_pfr.cppm 文件手动构建该模块.

对于手动模块构建, clang 编译器可以使用以下命令:

cd pfr/module
clang++ -I ../include -std=c++20 --precompile -x c++-module boost_pfr.cppm

之后, 即可按以下方式使用该模块:

clang++ -std=c++20 -fmodule-file=boost_pfr.pcm boost_pfr.pcm usage_sample.cpp
