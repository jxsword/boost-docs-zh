宏 BOOST_PROTO_BASIC_EXTENDS

BOOST_PROTO_BASIC_EXTENDS — 用于创建向 Proto 表达式模板添加成员的表达式包装器, 例如 proto::extends<>, 同时保留表达式包装器的 POD 特性.

概要

// In header: <boost/proto/extends.hpp>

BOOST_PROTO_BASIC_EXTENDS(Expr, Derived, Domain)

说明

BOOST_PROTO_BASIC_EXTENDS() 添加使一个 struct 成为有效 Proto 表达式扩展所需的基本 typedef、成员函数和数据成员. 它 不 添加任何会使包含它的 struct 变为非 POD 的构造函数、虚函数或访问控制区块.

Expr 是外围 struct 所扩展的 Proto 表达式. Derived 是外围 struct 的类型. Domain 是此表达式扩展所属的 Proto 域. (参见 proto::domain<>.) 若指定的域是依赖类型, 可在其前面加上 "typename"

BOOST_PROTO_BASIC_EXTENDS() 向其外围 struct 添加恰好一个 Expr 类型的数据成员.

若 Domain 参数是依赖类型, 可将其指定为 typename Domain, 例如 BOOST_PROTO_BASIC_EXTENDS(Expr, Derived, typename Domain)

示例:

template< class Expr >
struct my_expr;

struct my_domain
  : proto::domain< proto::pod_generator< my_expr > >
{};

template< class Expr >
struct my_expr
{
    // OK, this makes my_expr<> a valid Proto expression extension.
    // my_expr<> does /not/ have overloaded assignment, subscript,
    // and function call operators that build expression templates, however.
    BOOST_PROTO_BASIC_EXTENDS(Expr, my_expr, my_domain)
};

// OK, my_expr<> is POD, so this is statically initialized:
my_expr< proto::terminal<int>::type > const _1 = {{1}};
