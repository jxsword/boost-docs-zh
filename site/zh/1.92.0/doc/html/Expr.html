概念 Expr

Expr

说明

Expr 表示表达式树中的一个带标签节点. Expr 的子节点本身必须满足 Expr 概念. Expr 有一个表示子节点数量的元数 (arity). 如果子节点数量为零, 则 Expr 还有一个值. Expr 还有一个关联的 Domain.

关联类型

  • proto_tag

    Expr::proto_tag

    Expr 的标签类型.

  • proto_args

    Expr::proto_args

    一个类型列表, 表示子节点的类型; 若 Expr 的元数为 0, 则表示终端值的类型.

  • proto_arity

    Expr::proto_arity

    Expr 的元数 (子节点数量). proto_arity 是一个 MPL 整型常量.

  • proto_grammar

    Expr::proto_grammar

    一个 typedef, 表示等价于 Expr 的 proto::basic_expr<> 的一个实例化. 若两个表达式类型具有相同的 proto_tag、proto_args 和 proto_arity, 则它们等价.

  • proto_base_expr

    Expr::proto_base_expr

    一个 typedef, 表示等价于 Expr 的 proto::expr<> 或 proto::basic_expr<> 的一个实例化. 若两个表达式类型具有相同的 proto_tag、proto_args 和 proto_arity, 则它们等价.

  • proto_derived_expr

    Expr::proto_derived_expr

    Expr 的 typedef.

  • proto_domain

    Expr::proto_domain

    Expr 的 Domain. proto_domain 建模 Domain.

  • proto_childN

    Expr::proto_childN

    Expr 第 N 个子节点的类型. 要求 0 == N::value || N::value < proto_arity::value

记法

Expr
在 Expr 概念中扮演 expression-type 角色的类型.
Tag
在 Expr 概念中扮演 tag-type 角色的类型.
Domain
在 Expr 概念中扮演 domain-type 角色的类型.
N
在 Expr 概念中扮演 mpl-integral-constant-type 角色的类型.
e
Expr 类型的对象

有效表达式

名称 表达式 类型 语义

获取第 N 个子节点

boost::proto::child< N >(e)

proto_childN

从此 Expr 中提取第 N 个子节点. 要求 N::value < proto_arity::value.

获取终端值

boost::proto::value(e)

proto_child0

从终端 Expr 中提取值. 要求 0 == proto_arity::value.

获取基对象

e.proto_base()

proto_base_expr

返回一个 proto::expr<> 或 proto::basic_expr<> 类型的对象, 它等价于 e.
