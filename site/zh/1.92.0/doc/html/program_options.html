引言

program_options 库允许程序开发者通过命令行和配置文件等常规方式, 从用户那里获取程序选项, 即 (名称, 值) 对.

为什么要使用这样一个库, 它为什么比用直接的手写代码解析命令行更好?

  • 更容易. 声明选项的语法很简单, 库本身也很小. 诸如将选项值转换为所需类型并存入程序变量之类的事情都会自动处理.

  • 错误报告更好. 命令行的所有问题都会被报告, 而手写代码可能只是错误地解析了输入. 此外, 用法消息可以自动生成, 避免与实际选项列表不同步.

  • 选项可以从任何地方读取. 命令行迟早会无法满足你的用户, 你会想要配置文件, 甚至环境变量. 这些都可以轻松添加.
