什么是属性树?

Property Tree 库提供了一种数据结构, 用于存储任意深度嵌套的值树, 树的每一层都由某个键进行索引. 树的每个节点存储它自己的值, 以及其子节点及其键的有序列表. 该树支持通过路径 (多个键的拼接) 方便地访问任意节点.

此外, 本库为多种可以用这种树表示的数据格式提供了解析器与生成器, 包括 XML、INI 与 JSON.

属性树是通用的数据结构, 但特别适合保存配置数据. 该树提供自己的、树专用的接口, 且每个节点对其子节点而言也是一个 STL 兼容的 Sequence.

因此, 从概念上讲, 一个节点可以被视为如下结构:

struct ptree
{
   data_type data;                         // data associated with the node
   list< pair<key_type, ptree> > children; // ordered list of named children
};

key_type 与 data_type 都可以在一定程度上配置, 但通常是 std::string 或 std::wstring, 并且解析器只能处理这种类型的树.

许多软件项目在其生命周期的某个时刻都会开发一个类似的工具, 属性树也正是以同样的方式起源的. 我们希望这个库能让许多人免于重复造轮子.
