配置宏
断言如何表现?

定义 BOOST_NO_CXX11_STATIC_ASSERT 后, 用户可以选择静态断言的报告方式. 定义

  • BOOST_CHRONO_USES_STATIC_ASSERT: 想使用 Boost.StaticAssert 时定义它.
  • BOOST_CHRONO_USES_MPL_ASSERT: 想使用 Boost.MPL 静态断言时定义它.
  • BOOST_CHRONO_USES_ARRAY_ASSERT: 想使用内部静态断言时定义它.

默认行为如同定义了 BOOST_CHRONO_USES_ARRAY_ASSERT.

未定义 BOOST_CHRONO_USES_MPL_ASSERT 时, 以下符号按如下方式定义

#define BOOST_CHRONO_A_DURATION_REPRESENTATION_CAN_NOT_BE_A_DURATION \
    "A duration representation can not be a duration"
#define BOOST_CHRONO_SECOND_TEMPLATE_PARAMETER_OF_DURATION_MUST_BE_A_STD_RATIO \
    "Second template parameter of duration must be a boost::ratio"
#define BOOST_CHRONO_DURATION_PERIOD_MUST_BE_POSITIVE \
    "duration period must be positive"
#define BOOST_CHRONO_SECOND_TEMPLATE_PARAMETER_OF_TIME_POINT_MUST_BE_A_BOOST_CHRONO_DURATION \
    "Second template parameter of time_point must be a boost::chrono::duration"

依据所使用的静态断言系统, 你将通过符号或文字获得失败断言的提示.

不提供混合错误处理

定义 BOOST_CHRONO_DONT_PROVIDE_HYBRID_ERROR_HANDLING 时, 库不提供混合错误处理原型:

Clock::time_point Clock::now(system::error_code&ec=boost::throws());

这使库更接近标准, 并避免对 Boost.System 的依赖, 从而使 Boost.Chrono 可以成为仅头文件库.

默认定义 BOOST_CHRONO_PROVIDE_HYBRID_ERROR_HANDLING.

如何把 Boost.Chrono 用作仅头文件库?

定义 BOOST_CHRONO_HEADER_ONLY 时, 库为仅头文件形式.

若另外定义了 BOOST_USE_WINDOWS_H, 则会包含 <windows.h>; 否则使用 boost/detail/win 中的文件, 以减少包含 <windows.h> 的影响.

然而, 你仍需定义 BOOST_CHRONO_DONT_PROVIDE_HYBRID_ERROR_HANDLING 或链接 Boost.System.

时间相关特征 (Traits)
元函数 treat_as_floating_point<> 
template <class Rep> struct treat_as_floating_point
    : boost::is_floating_point<Rep> {};

duration 模板使用 treat_as_floating_point 特征来帮助判断某种刻度周期 (tick period) 的 duration 能否转换为具有不同刻度周期的另一种 duration. 若 treat_as_floating_point<Rep>::value 为 true, 则 Rep 是浮点类型, 各 duration 之间允许隐式转换. 否则, 隐式可转换性取决于各 duration 的刻度周期. 若 Rep 是模拟浮点类型的类类型, Rep 的作者可以特化 treat_as_floating_point, 使 duration 把该 Rep 当作浮点类型对待. 否则, Rep 被假定为整型或模拟整型的类.

类模板 duration_values 
template <class Rep>
struct duration_values
{
public:
    static constexpr Rep zero();
    static constexpr Rep max();
    static constexpr Rep min();
};

duration 模板使用 duration_values 特征来构造 duration 表示 (rep) 的特殊值 (Rep). 之所以这样做, 是因为表示可能是具有某些行为的类类型, 需要其他实现来返回这些特殊值. 此时, 该类类型的作者应特化 duration_values 以返回所指明的值.

静态成员函数 zero() 
static constexpr Rep zero();

返回: Rep(0). 注释: Rep(0) 之所以用来代替 Rep(), 是因为 Rep() 可能另有含义, 比如表示未初始化的值.

备注: 返回值对应加法单位元.

静态成员函数 max() 
static constexpr Rep max();

返回: numeric_limits<Rep>::max().

备注: 返回值比较大于 zero().

静态成员函数 min() 
static constexpr Rep min();

返回: numeric_limits<Rep>::lowest().

备注: 返回值比较小于等于 zero().

common_type 特化 
template <class Rep1, class Period1, class Rep2, class Period2>
struct common_type<chrono::duration<Rep1, Period1>, chrono::duration<Rep2, Period2> >
{
    typedef chrono::duration<typename common_type<Rep1, Rep2>::type, see bellow> type;
};

duration (由 common_type 特化指明) 的周期是 Period1 与 Period2 的最大公约数. 其计算方法是: 构造一个 ratio, 其分子为 Period1::num 与 Period2::num 的最大公约数, 分母为 Period1::den 与 Period2::den 的最小公倍数.

注释: typedef type 是刻度周期尽可能大的 duration, 使得两个 duration 实参都能无需除法即可转换为它. 此类型的表示应能容纳这一转换产生的任何值, 当涉及浮点 duration 时可能有舍入误差例外 (但不会有截断误差).

类模板 duration<>

duration 度量两个时间点 (time_point) 之间的时间. duration 具有一个保存刻度 (tick) 计数的表示和一个刻度周期. 刻度周期是从一个刻度到另一个刻度所经历的时间量, 以秒为单位, 用 ratio 表示为有理常数.

namespace boost { namespace chrono {

    template <class Rep, class Period>
    class duration {
    public:
        typedef Rep rep;
        typedef Period period;
    private:
        rep rep_; // exposition only
    public:
        constexpr duration();
        template <class Rep2>
        constexpr explicit duration(const Rep2& r);

        template <class Rep2, class Period2>
        constexpr duration(const duration<Rep2, Period2>& d);

        duration& operator=(const duration&) = default;

        constexpr rep count() const;

        constexpr duration  __duration__op_plus();
        constexpr duration  __duration__op_minus();
        duration& operator++();
        duration  operator++(int);
        duration& operator--();
        duration  operator--(int);

        duration& operator+=(const duration& d);
        duration& operator-=(const duration& d);

        duration& operator*=(const rep& rhs);
        duration& operator/=(const rep& rhs);
        duration& operator%=(const rep& rhs);
        duration& operator%=(const duration& rhs);

        static constexpr duration zero();
        static constexpr duration min();
        static constexpr duration max();
    };

}}

Rep 必须是算术类型或模拟算术类型的类, 否则给出编译诊断. 若 duration 实例化时 Rep 的类型是 duration, 则发出编译诊断.

Period 必须是 ratio 的实例化, 否则给出编译诊断.

Period::num 必须为正, 否则给出编译诊断.

示例:

  • duration<long, ratio<60> > 用 long 保存分钟计数.
  • duration<long long, milli> 用 long long 保存毫秒计数.
  • duration<double, ratio<1, 30> > 用 double 保存计数, 刻度周期为 1/30 秒 (刻度频率 30 Hz).

duration 的以下成员不会抛出异常, 除非对表示 (rep) 的相应操作抛出异常.

构造函数 duration() 
constexpr duration();

效果: 构造一个 duration 类型的对象, 在 C++98 中以 duration_values<rep>::zero() 初始化, 或在定义了 BOOST_CHRONO_DURATION_DEFAULTS_TO_ZERO 时初始化; 否则时长未初始化.

构造函数duration(const Rep2&) 
template <class Rep2>
constexpr explicit duration(const Rep2& r);

备注: Rep2 可隐式转换为 rep, 且

  • treat_as_floating_point<rep>::value 为 true, 或
  • !treat_as_floating_point<rep>::value && !treat_as_floating_point<Rep2>::value 为 true.

若不满足这些约束, 此构造函数不参与重载决议. Note: 该要求防止用浮点表示构造基于整型的 duration. 这种构造很容易让人对 duration 的值产生困惑.

示例: 

duration<int, milli> d(3.5);  // do not compile
duration<int, milli> d(3);    // ok

效果: 构造一个 duration 类型的对象.

后置条件: count() == static_cast<rep>(r).

构造函数duration(const duration&) 
template <class Rep2, class Period2>
constexpr duration(const duration<Rep2, Period2>& d);

备注: treat_as_floating_point<rep>::value, 或 ratio_divide<Period2, period>::type::den == 1, 否则此构造函数不参与重载决议. note 该要求防止在基于整型的 duration 之间转换时出现隐式截断错误. 这种构造很容易让人对 duration 的值产生困惑.

  • 否则若 CF::num != 1 与 CF::den == 1, 则返回 ToDuration(static_cast<typename ToDuration::rep>(static_cast<CR>(d.count()) * static_cast<CR>(CF::num)))
  • 否则若 CF::num == 1 与 CF::den != 1, 则返回 ToDuration(static_cast<typename ToDuration::rep>(static_cast<CR>(d.count()) / static_cast<CR>(CF::den)))
  • 否则返回 ToDuration(static_cast<typename ToDuration::rep>(static_cast<CR>(d.count()) * static_cast<CR>(CF::num) / static_cast<CR>(CF::den)))

从区间 [s,end) 按模式 [pattern,pat_end) 提取时长.

参数:

  • s: start input stream iterator
  • end: end input stream iterator
  • ios: 对一个 ios_base 的引用
  • err: ios_base 状态
  • d: 时长
  • pattern: 格式化模式的起点
  • pat_end: 格式化模式的终点

要求: [s, end) and [pattern, pat_end) 必须是有效区间.

效果: 函数首先求值 err = std::ios_base::goodbit.

然后基于 Rep 计算一个中间表示, 规则如下:

  • 若 Rep 是浮点类型, 则中间表示为 long double.
  • 否则若 Rep 是有符号整型, 则中间表示为 long long.
  • 否则若 Rep 是无符号整型, 则中间表示为 unsigned long long.
  • 否则中间表示为 Rep.

接下来, 默认构造以下局部变量: r (中间表示类型) 与 rt (类型 rt_ratio).

然后进入一个循环, 每次迭代从 s 读取零个或多个字符. 除非下文另有说明, 循环在以下条件中第一个成立时终止:

  • 表达式 pattern == pat_end 求值为 true.
  • 表达式 err == std::ios_base::goodbit 求值为 false.
  • 表达式 s == end 求值为 true, 此时函数求值 err = std::ios_base::eofbit | std::ios_base::failbit.
  • 模式的下一个元素等于 '%', 其后跟一个转换说明符字符 format. 若区间 [pattern,pat_end) 中的元素数量不足以无歧义地确定转换规格是否完整有效, 则函数求值 err = std::ios_base::failbit. 否则, 函数求值 s = get_value(s, end, ios, err, r) (当转换规格为 'v' 时) 且 s = get_value(s, end, ios, err, rt) (当转换规格为 'u' 时). 若 err == std::ios_base::goodbit 求值为真, 函数把 pattern 递增到刚好越过转换规格末端的位置, 并继续循环.
  • 表达式 isspace(*pattern, ios.getloc()) 求值为 true, 此时函数先递增 pattern 直到 pattern == pat_end || !isspace(*pattern, ios.getloc()) 求值为 true, 然后推进 s 直到 s == end || !isspace(*s, ios.getloc()) 为 true, 最后恢复循环.
  • 从 s 读取的下一个字符与 pattern 所指元素在不区分大小写的比较中匹配, 此时函数求值 ++pattern, ++s 并继续循环. 否则, 函数求值 err = std::ios_base::failbit.

若已成功解析时长表示值与单位说明符, 则计算 (rt.num/rt.den)/(Period::num/Period::den) (化为最简形式). 若此比值无法在不溢出的情况下存储, 则求值 err = std::ios_base::failbit. 否则把该除法的结果存入 num 与 den.

若除法未导致溢出, 则计算 r * num / den (以避免中间溢出). 若 r 是整型且该计算不精确, 则求值 err = std::ios_base::failbit. 若计算结果会溢出 Rep, 则求值 err = std::ios_base::failbit. 否则 r * num / den 的结果用于构造一个 duration<Rep, Period>, 并赋给 d.

返回: s, 即指向最后一个可确定为有效时长的一部分的字符之后的迭代器.

要求: [pattern,pat_end) 必须是有效区间.

效果: 函数首先求值 err = std::ios_base::goodbit. 然后进入一个循环, 每次迭代从 s 读取零个或多个字符. 除非下文另有说明, 循环在以下条件中第一个成立时终止:

  • 表达式 pattern == pat_end 求值为 true.
  • 表达式 err == std::ios_base::goodbit 求值为 false.
  • 表达式 s == end 求值为 true, 此时函数求值 err = std::ios_base::eofbit | std::ios_base::failbit.
  • 模式的下一个元素等于 '%', 其后跟一个转换说明符字符; 调用函数 get_duration 或 get_epoch, 依据格式是 'd' 或 'e'. 若区间 [pattern,pat_end) 中的元素数量不足以无歧义地确定转换规格是否完整有效, 则函数求值 err |= std::ios_base::failbit. 否则, 函数求值 s = do_get(s, end, ios, err, d). 若 err == std::ios_base::goodbit 求值为真, 函数把 pattern 递增到刚好越过转换规格末端的位置, 并继续循环.
  • 表达式 isspace(*pattern, ios.getloc()) 求值为 true, 此时函数先递增 pattern 直到 pattern == pat_end || !isspace(*pattern, ios.getloc()) 求值为 true, 然后推进 s 直到 s == end || !isspace(*s, ios.getloc()) 为 true, 最后恢复循环.
  • 从 s 读取的下一个字符与 pattern 所指元素在不区分大小写的比较中匹配, 此时函数求值 ++pattern, ++s 并继续循环. 否则, 函数求值 err = std::ios_base::failbit.

效果: 表现为一个格式化输出函数. 构造 sentry 对象后, 若 sentry 转换为 true, 则设置一个 tz 的局部变量 timezone 遍历到 get_timezone(os). 此外, 用 get_time_fmt() 获得的格式字符串被记录为一对 const CharT*. 若流没有 time_punct 刻面, 则这对 const CharT* 表示空区间.

接着, tp 被转换为一个 time_t, 而这个 time_t 被转换为一个 tm. The conversion to tm 的转换使用 gmtime (若可用), 当时区为 utc 时; 否则使用 localtime (若可用).

使用 std::time_put 刻面 (存储在 os 中), 此插入器使用 tm 以及存储在该 time_punct 刻面中的格式化字符串向流写入字符, 除非该刻面缺失或提供了空字符串.

若格式化字符串为空, 则按如下方式输出:

首先使用 tm 输出 "%F %H:%M:"

接着输出一个 double, 表示 tm 中存储的秒数加上 tp 所表示的小数秒. 格式应为 ios::fixed, 且精度应足以精确表示 system_clock::duration (例如, 若 system_clock::period 为 micro, 精度应足以在小数点后输出六位). 若秒数小于 10, 输出应以前缀 '0'.

最后, 若 tz 为 local, 则使用模式 " %z" 输出 tm; 否则向流追加序列 " +0000".

若任一步骤失败, 调用 os.setstate(ios_base::failbit | ios_base::badbit).

返回: os
