AUTO, AUTO_TPL

BOOST_AUTO 宏模拟 C++ 中提议的 auto 关键字.

用法
BOOST_AUTO(var,expr)
BOOST_AUTO_TPL(var,expr)

参数

var

要用表达式初始化的变量

expr

一个有效的 C++ 表达式

备注

如果你想在模板上下文中使用 auto, 请使用 BOOST_AUTO_TPL(expr), 它会处理 typename 关键字——位于 auto 表达式内部.

示例代码
int main()
{
    length::meter a(5);
    force::newton b(6);
    BOOST_AUTO(c, a * b);
}

COMPLIANT

BOOST_TYPEOF_COMPLIANT 宏可用于强制启用模拟模式. 如果你的编译器默认使用其他模式, 例如原生 typeof 或 Microsoft 专用技巧, 而你想使用模拟模式 (例如出于可移植性原因), 请定义它.

INCREMENT_REGISTRATION_GROUP

BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP 宏确保不同头文件中的类型注册获得唯一标识符.

用法
#include BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP()
备注

在每个执行注册的 cpp/hpp 文件中指定一次, 位于任何注册之前.

示例代码
#include BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP()

class X;
BOOST_TYPEOF_REGISTER_TYPE(X)

INTEGRAL

BOOST_TYPEOF_INTEGRAL 宏用于通过 BOOST_TYPEOF_REGISTER_TEMPLATE 注册整型模板参数的场合.

对 enum 与依赖的整型模板参数很有用.

用法
BOOST_TYPEOF_INTEGRAL(x)

参数

x

一个完全限定的整型类型或枚举

备注

内置类型 (int、bool、long、unsigned long 等) 已实现简短语法. 其他非类型模板参数 (例如成员指针) 不受支持.

示例代码
#include BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP()

namespace foo
{
    enum color {red, green, blue};

    template<color C0,typename T1>
    class class_with_enum {};

    template<typename T0,T0 I1>
    class class_with_dependent_non_type {};
}

BOOST_TYPEOF_REGISTER_TEMPLATE(foo::class_with_enum,
    (BOOST_TYPEOF_INTEGRAL(foo::color))
    (typename)
    )

BOOST_TYPEOF_REGISTER_TEMPLATE(foo::class_with_dependent_non_type,
    (typename)
    (BOOST_TYPEOF_INTEGRAL(P0))
    )

LIMIT_FUNCTION_ARITY

BOOST_TYPEOF_LIMIT_FUNCTION_ARITY 宏定义函数支持多少个参数, 适用于函数、函数指针、函数引用与成员函数指针. 默认值为 10. 如果希望 Typeof 库处理更多参数的函数, 请重新定义.

MESSAGES

在包含 boost/typeof/typeof.hpp 之前定义 BOOST_TYPEOF_MESSAGE, 以包含消息 "using typeof emulation" 与 "using native typeof". 默认情况下不显示这些消息.

LIMIT_SIZE

BOOST_TYPEOF_LIMIT_SIZE 宏定义用于编码类型的编译期序列的大小. 默认值为 50. 如果希望 Typeof 库处理非常复杂的类型, 可以增大它, 不过这种可能性受编译器支持的模板参数最大数量的限制. 另一方面, 如果你只使用非常简单的类型, 减小该数字可能有助于提升编译期性能.

REGISTER_TYPE

BOOST_TYPEOF_REGISTER_TYPE 宏告知 Typeof 库某个类型的存在

用法
BOOST_TYPEOF_REGISTER_TYPE(x)

参数

x

一个完全限定的类型

备注

必须在全局命名空间中使用

示例代码
#include BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP()

namespace foo
{
    class bar {};
    enum color {red, green, blue};
}

BOOST_TYPEOF_REGISTER_TYPE(foo::bar)
BOOST_TYPEOF_REGISTER_TYPE(foo::color)

REGISTER_TEMPLATE

BOOST_TYPEOF_REGISTER_TEMPLATE 宏告知 Typeof 库某个模板的存在并描述其参数

用法
BOOST_TYPEOF_REGISTER_TEMPLATE(x, n)
BOOST_TYPEOF_REGISTER_TEMPLATE(x, seq)

参数

x

一个完全限定的模板

n

模板实参的数量. 仅当所有模板实参都是类型名时有效

seq

模板实参的序列. 当存在整型或模板模板参数时必须使用

备注

必须在全局命名空间中使用.

本库允许注册带有类型、整型与模板模板参数的模板:

  • 类型模板参数由 (class) 或 (typename) 序列元素描述
  • 众所周知整型类型的模板参数可以只提供其类型来描述, 如 (unsigned int). 支持以下众所周知整型类型:
    • [signed/unsigned] char
    • [unsigned] short
    • [unsigned] int
    • [unsigned] long
    • unsigned
    • bool
    • size_t
  • 枚举与整型类型的 typedef 需要用 BOOST_TYPEOF_INTEGRAL 宏显式描述, 如 (BOOST_TYPEOF_INTEGRAL(MyEnum))
  • 模板模板参数用 BOOST_TYPEOF_TEMPLATE 宏描述, 例如: (BOOST_TYPEOF_TEMPLATE((class)(unsigned int))). 当全部为类型参数时, 可以简写为 (BOOST_TYPEOF_TEMPLATE(2)) 这样的形式. 不支持嵌套的模板模板参数.
示例代码
#include BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP()

namespace foo
{
    template<typename T0, typename T1>
    class simple_template {};

    template<typename T0, int I1>
    class class_with_integral_constant {};
}

BOOST_TYPEOF_REGISTER_TEMPLATE(foo::simple_template, 2)
BOOST_TYPEOF_REGISTER_TEMPLATE(foo::class_with_integral_constant, (typename)(int))

TEMPLATE

BOOST_TYPEOF_TEMPLATE 宏在使用 BOOST_TYPEOF_REGISTER_TEMPLATE 注册模板模板参数的场合使用.

用法
BOOST_TYPEOF_TEMPLATE(n)
BOOST_TYPEOF_TEMPLATE(seq)

参数

n

模板实参的数量. 仅当所有模板实参都是类型名时有效

seq

模板实参的序列. 当嵌套模板中存在整型常量时必须使用

备注

不能用于注册嵌套的模板模板参数.

示例代码
#include BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP()

namespace foo
{
    enum color {red, green, blue};

    template<color C0, template<typename> class T1>
    class nested_template_class {};

    template<template<typename, unsigned char> class T1>
    class nested_with_integral {};
}

BOOST_TYPEOF_REGISTER_TEMPLATE(foo::nested_template_class,
    (foo::color)
    (BOOST_TYPEOF_TEMPLATE(1))
    )

BOOST_TYPEOF_REGISTER_TEMPLATE(foo::nested_with_integral,
    (BOOST_TYPEOF_TEMPLATE((typename)(unsigned char)))
    )

TYPEOF, TYPEOF_TPL

BOOST_TYPEOF 宏计算表达式的类型, 但移除顶层限定符, const&

用法
BOOST_TYPEOF(expr)
BOOST_TYPEOF_TPL(expr)

参数

expr

一个可绑定到 const T& 的有效 C++ 表达式

备注

如果你想在模板上下文中使用 typeof, 请使用 BOOST_TYPEOF_TPL(expr), 它会处理 typename 关键字——位于 typeof 表达式内部.

示例代码
template<typename A, typename B>
struct result_of_conditional
{
    typedef BOOST_TYPEOF_TPL(true?A():B()) type;
};

template<typename A, typename B>
result_of_conditional<A, B>::type min(const A& a,const B& b)
{
    return a < b ? a : b;
}

TYPEOF_NESTED_TYPEDEF, TYPEOF_NESTED_TYPEDEF_TPL

TYPEOF_NESTED_TYPEDEF 宏的工作方式与 'TYPEOF' 宏大致相同, 但绕开了若干编译器缺陷.

用法
BOOST_TYPEOF_NESTED_TYPEDEF(name,expr)
BOOST_TYPEOF_NESTED_TYPEDEF_TPL(name,expr)

参数

name

一个有效标识符, 用于将 typeof 操作嵌套其中

expr

一个可绑定到 const T& 的有效 C++ 表达式

备注

'typeof_nested_typedef' 把 'typeof' 操作嵌套在一个结构体内部. 通过这种方式, 'typeof' 操作可以拆分为两个步骤, 从而消除若干编译器 (尤其是 VC7.1 与 VC8.0) 的混淆. 这也移除了 BOOST_TYPEOF_LIMIT_SIZE 施加的限制, 让你可以对大得多的表达式使用 'typeof'.

如果你想在模板上下文中使用 typeof_nested_typedef, 请使用 BOOST_TYPEOF_NESTED_TYPEDEF_TPL(name,expr), 它会处理 typename 关键字——位于 typeof 表达式内部.

'typeof_nested_typedef' 不能在函数/块作用域使用.

示例代码
template<typename A, typename B>
struct result_of_conditional
{
    BOOST_TYPEOF_NESTED_TYPEDEF_TPL(nested,true?A():B())
    typedef typename nested::type type;
};

template<typename A, typename B>
result_of_conditional<A, B>::type min(const A& a,const B& b)
{
    return a < b ? a : b;
}
