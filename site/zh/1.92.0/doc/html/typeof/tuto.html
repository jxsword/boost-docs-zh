教程

要开始使用 typeof, 请包含 typeof 头文件:

#include <boost/typeof/typeof.hpp>

要在编译期推导表达式的类型, 请使用 BOOST_TYPEOF 宏:

namespace ex1
{
    typedef BOOST_TYPEOF(1 + 0.5) type;

    BOOST_STATIC_ASSERT((is_same<type, double>::value));
}

在依赖上下文中, 请用 BOOST_TYPEOF_TPL 代替 BOOST_TYPEOF:

namespace ex2
{
    template<class T, class U>
    BOOST_TYPEOF_TPL(T() + U()) add(const T& t, const U& u)
    {
        return t + u;
    };

    typedef BOOST_TYPEOF(add('a', 1.5)) type;

    BOOST_STATIC_ASSERT((is_same<type, double>::value));
}

上面的例子之所以可行, 是因为 Typeof 库了解基本类型, 例如 int、double、char 等. Typeof 库还了解标准 C++ 库定义的大多数类型与模板, 但需要包含相应的头文件才能利用这一点:

#include <boost/typeof/std/utility.hpp>

namespace ex3
{
    BOOST_AUTO(p, make_pair(1, 2));

    BOOST_STATIC_ASSERT((is_same<BOOST_TYPEOF(p), pair<int, int> >::value));
}

这里 <boost/typeof/std/utility.hpp> 包含 <utility>, 并包含对其中定义的模板的了解. 这一命名约定普遍适用, 例如要让 Typeof 库处理 std::vector, 请包含 <boost/typeof/std/vector.hpp>, 等等.

要从变量初始化所用的表达式推导该变量的类型, 请使用 BOOST_AUTO 宏 (依赖上下文中用 BOOST_AUTO_TPL:

#include <boost/typeof/std/string.hpp>

namespace ex4
{
    BOOST_AUTO(p, new int[20]);

    BOOST_STATIC_ASSERT((is_same<BOOST_TYPEOF(p), int*>::value));
}

BOOST_TYPEOF 与 BOOST_AUTO 都会剥离顶层限定符. 因此, 例如要分配一个引用, 必须显式指定:

namespace ex5
{
    string& hello()
    {
        static string s = "hello";
        return s;
    }

    BOOST_AUTO(&s, hello());
}

为了更好地理解这一语法, 注意它会展开为:

BOOST_TYPEOF(hello()) &s = hello();

如果你定义了自己的类型, Typeof 库无法处理它, 除非你让它知道这个类型. 你通过 "注册" 该类型/模板来告知 Typeof 库.

任何注册类型/模板的源文件或头文件, 都必须在执行任何注册之前包含以下一行:

#include BOOST_TYPEOF_INCREMENT_REGISTRATION_GROUP()

此后即可注册类型:

namespace ex6
{
    struct MyType
    {};
}

BOOST_TYPEOF_REGISTER_TYPE(ex6::MyType)

注册必须在全局命名空间的上下文中进行; 必须使用完全限定的类型名称.

一个文件中可以注册任意数量的类型, 每个类型独占一行.

一旦你的类型被注册, Typeof 库就可以在任何上下文中处理它:

namespace ex6
{
    typedef BOOST_TYPEOF(make_pair(1, MyType())) type;

    BOOST_STATIC_ASSERT((is_same<type, pair<int, MyType> >::value));
}

模板的注册方式是指定其完全限定名, 并描述其参数. 在最简单的情况下, 当所有参数都是类型参数时, 只需指定它们的数量:

namespace ex7
{
    template<class T, class U>
    struct MyTemplate
    {};
}

BOOST_TYPEOF_REGISTER_TEMPLATE(ex7::MyTemplate, 2)

namespace ex7
{
    typedef BOOST_TYPEOF(make_pair(1, MyTemplate<int, ex6::MyType>())) type;

    BOOST_STATIC_ASSERT((is_same<type,
        pair<int, MyTemplate<int, ex6::MyType> >
    >::value));
}

当模板带有整型模板参数时, 所有参数都需要在预处理器序列中描述:

namespace ex8
{
    template<class T, int n>
    struct MyTemplate
    {};
}

BOOST_TYPEOF_REGISTER_TEMPLATE(ex8::MyTemplate, (class)(int))

namespace ex8
{
    typedef BOOST_TYPEOF(make_pair(1, MyTemplate<ex7::MyTemplate<ex6::MyType, int>, 0>())) type;

    BOOST_STATIC_ASSERT((is_same<type,
        pair<int, MyTemplate<ex7::MyTemplate<ex6::MyType, int>, 0> >
    >::value));
}
