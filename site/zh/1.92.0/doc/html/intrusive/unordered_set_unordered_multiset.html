自定义桶特征

Boost.Intrusive 还提供了哈希容器, 这些容器对于实现快速查找容器非常有用. 这些容器 (unordered_set 和 unordered_multiset) 是半侵入式容器: 除了存储在 value_type 中的钩子之外, 它们还需要额外的内存. 该额外内存必须在容器的构造函数中传入.

与 C++ TR1 无序关联容器 (它们也是哈希容器) 不同, 这些半侵入式容器的内容不会为了维持负载因子而重新哈希: 那需要内存管理, 而侵入式容器完全不实现任何内存管理. 不过, 用户可以传入一个新的桶数组来请求显式的重新哈希. 这还提供了相比 TR1 无序关联容器的一个额外保证: 向容器 插入元素时迭代器不会失效.

与 TR1 无序关联容器一样, 重新哈希会使迭代器失效, 改变元素之间的顺序并改变元素所在的桶, 但不会使指向元素的指针或引用失效.

除了预期的哈希和相等函数对象之外, Boost.Intrusive 无序关联容器的构造函数还接受一个参数, 指定容器要使用的辅助桶向量.

unordered_set 和 unordered_multiset 性能说明

哈希容器的体积开销适中: 每个值 1 个指针, 外加每个容器一个桶数组. 桶数组元素的大小通常为一个指针. 为了获得性能良好的哈希容器, 桶长度通常与容器包含的元素数量相同, 因此一个均衡良好的哈希容器 (bucket_count() 等于 size()) 的等效开销为每个元素两个指针.

空的非常数时间 size unordered_set 或 unordered_multiset 的大小也是 bucket_count() 个指针.

在哈希容器中, 插入, 擦除和查找具有均摊常数时间复杂度. 但某些最坏情况保证是线性的. 每个操作的复杂度保证参见 unordered_set 或 unordered_multiset.

当心非常数时间 size 的哈希容器: 某些操作 (如 empty()) 具有线性复杂度, 这与其他 Boost.Intrusive 容器不同.

unordered_set 和 unordered_multiset 的钩子

unordered_set 和 unordered_multiset 共享相同的钩子. 这是一个优势, 因为同一个用户类型可以先插入 unordered_multiset, 然后再插入 unordered_set, 而无需更改用户类的定义.

template <class ...Options>
class unordered_set_base_hook;
  • unordered_set_base_hook: 用户类公开派生自 unordered_set_base_hook, 以使其与 unordered_set/unordered_multiset 兼容.
template <class ...Options>
class unordered_set_member_hook;
  • unordered_set_member_hook: 用户类包含一个公有的 unordered_set_member_hook, 以使其与 unordered_set/unordered_multiset 兼容.

unordered_set_base_hook 和 unordered_set_member_hook 接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • tag<class Tag> (仅用于基类钩子): 该参数用作标签 (tag), 因此可以从多个基类钩子派生. 默认: tag<default_tag>.
  • link_mode<link_mode_type LinkMode>: 链接策略. 默认: link_mode<safe_link>.
  • void_pointer<class VoidPointer>: 钩子内部使用的指针类型, 并会传播到容器. 默认: void_pointer<void*>.

除此之外, 这些钩子还提供额外选项:

  • store_hash<bool Enabled>: 该选项在钩子中预留额外空间, 以在对象引入容器后存储其哈希值. 使用该选项时, 无序容器会将计算出的哈希值存储在钩子中, 重新哈希操作将无需重新计算值的哈希. 当重新哈希频繁或对值进行哈希是较慢操作时, 该选项会改善无序容器的性能. 默认: store_hash<false>.
  • optimize_multikey<bool Enabled>: 该选项在钩子中预留额外空间, 用于在无序多重集合中对相等元素进行分组, 当向这些容器插入大量相等值时可显著改善性能. 默认: optimize_multikey<false>.

unordered_set 和 unordered_multiset 容器 

template<class T, class ...Options>
class unordered_set;

template<class T, class ...Options>
class unordered_multiset;

如前所述, 无序容器需要一个辅助数组才能工作. Boost.Intrusive 无序容器以一个名为 bucket_traits 的类型打包接收该辅助数组 (它也可以由容器选项定制). 所有无序容器在其构造函数中接收一个 bucket_traits 对象. 默认的 bucket_traits 类用一个指向桶数组的指针及其大小进行初始化:

#include <boost/intrusive/unordered_set.hpp>

using namespace boost::intrusive;

struct MyClass : public unordered_set_base_hook<>
{};

typedef unordered_set<MyClass>::bucket_type     bucket_type;
typedef unordered_set<MyClass>::bucket_traits   bucket_traits;

int main()
{
   bucket_type buckets[100];
   unordered_set<MyClass> uset(bucket_traits(buckets, 100));
   return 0;
}

每个哈希容器都需要 自己的桶特征, 即 自己的桶向量. 两个哈希容器 不能共享相同的 bucket_type 元素. 桶数组 必须 在使用它的容器被销毁之 后 才能销毁, 否则结果未定义.

unordered_set 和 unordered_multiset 接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • base_hook<class Hook> / member_hook<class T, class Hook, Hook T::* PtrToMember> / value_traits<class ValueTraits>: 指定用于配置容器的钩子类型或值特征. (要了解值特征, 请参见 具有自定义 ValueTraits 的容器 一节.)
  • constant_time_size<bool Enabled>: 激活常数时间 size() 操作. 默认: constant_time_size<true>
  • size_type<typename SizeType>: 指定用于存储容器 size 的类型. 默认: size_type<std::size_t>

它们还可以接受附加选项:

  • equal<class Equal>: 容器中待插入对象的相等函数. 默认: equal< std::equal_to<T> >
  • hash<class Hash>: 容器中使用的哈希函数. 默认: 对标量类型进行哈希的内部哈希仿函数; 对非标量类型触发对 hash_value 的无限定调用 (boost::hash<T> 兼容协议). 如果 ADL 调用未找到可行的候选, 且用户已包含 boost/container_hash/hash.hpp 并在其中找到可行候选, 则尝试调用 boost::hash<T>(). 否则失败.
  • bucket_traits<class BucketTraits>: 一个包装无序容器要使用的桶向量的类型. 默认: 一个由桶数组的地址和大小初始化的类型, 并在内部存储这两个变量.
  • power_2_buckets<bool Enabled>: 用户保证只使用长度为 2 的幂的桶数组. 容器随后将使用掩码而非模运算从哈希值获得桶编号. 掩码比模运算更快, 对某些应用来说模运算可能带来相当大的开销. 在调试模式下, 如果用户提供的桶长度不是 2 的幂, 将触发断言. 默认: power_2_buckets<false>.
  • cache_begin<bool Enabled>: 注释: 该选项与 auto_unlink 钩子不兼容. 由于其内部结构, 查找无序容器的第一个元素 (begin() 操作) 是均摊常数时间. 如果容器在内部缓存第一个元素的位置, 可以加速 begin() 以及与之相关的其他操作 (如 clear()). 这会给容器的体积带来一个指针的额外开销. 默认: cache_begin<false>.
  • compare_hash<bool Enabled>: 注释: 该选项要求钩子中使用 store_hash<true> 选项. 当比较函数开销较大时 (例如具有长公共前缀的字符串), 有时 (特别是当负载因子较高, 或 unordered_multiset 中有许多相等元素且钩子中未激活 optimize_multikey<> 时) 相等函数会成为性能问题. 两个相等的值必须具有相等的哈希, 因此在使用比较仿函数之前先比较两个元素的哈希值可以加速某些实现.
  • incremental<bool Enabled>: 激活增量哈希 (也称为线性哈希). 该选项蕴含 power_2_buckets<true>, 且容器将要求 2 的幂个桶. 有关增量哈希的更多信息, 请参见 Wikipedia 上的 Linear hash 默认: incremental<false>
  • key_of_value<class KeyOfValueFunctionObject>: 一个函数对象, 定义待存储值类型的 key_type. 该类型将允许类似映射的接口. 详细信息参见 配合 set 和 multiset 的 map 与 multimap 式接口. 默认: key_type 等于 value_type (set 式接口).

示例

现在让我们看一个同时使用两种钩子和两种容器的小示例:

#include <boost/intrusive/unordered_set.hpp>
#include <vector>
#include <functional>

using namespace boost::intrusive;

class MyClass : public unordered_set_base_hook<>
{               //This is a derivation hook
   int int_;

   public:
   unordered_set_member_hook<> member_hook_; //This is a member hook

   MyClass(int i)
      :  int_(i)
   {}

   friend bool operator== (const MyClass &a, const MyClass &b)
   {  return a.int_ == b.int_;  }

   friend std::size_t hash_value(const MyClass &value)
   {  return std::size_t(value.int_); }
};

//Define an unordered_set that will store MyClass objects using the base hook
typedef unordered_set<MyClass>    BaseSet;

//Define an unordered_multiset that will store MyClass using the member hook
typedef member_hook<MyClass, unordered_set_member_hook<>, &MyClass::member_hook_>
   MemberOption;
typedef unordered_multiset< MyClass, MemberOption>  MemberMultiSet;

int main()
{
   typedef std::vector<MyClass>::iterator VectIt;

   //Create a vector with 100 different MyClass objects
   std::vector<MyClass> values;
   for(int i = 0; i < 100; ++i)  values.push_back(MyClass(i));

   //Create a copy of the vector
   std::vector<MyClass> values2(values);

   //Create a bucket array for base_set
   BaseSet::bucket_type base_buckets[100];

   //Create a bucket array for member_multi_set
   MemberMultiSet::bucket_type member_buckets[200];

   //Create unordered containers taking buckets as arguments
   BaseSet base_set(BaseSet::bucket_traits(base_buckets, 100));
   MemberMultiSet member_multi_set
      (MemberMultiSet::bucket_traits(member_buckets, 200));

   //Now insert values's elements in the unordered_set
   for(VectIt it(values.begin()), itend(values.end()); it != itend; ++it)
      base_set.insert(*it);

   //Now insert values's and values2's elements in the unordered_multiset
   for(VectIt it(values.begin()), itend(values.end()), it2(values2.begin())
      ; it != itend; ++it, ++it2){
      member_multi_set.insert(*it);
      member_multi_set.insert(*it2);
   }

   //Now find every element
   {
      VectIt it(values.begin()), itend(values.end());

      for(; it != itend; ++it){
         //base_set should contain one element for each key
         if(base_set.count(*it) != 1)           return 1;
         //member_multi_set should contain two elements for each key
         if(member_multi_set.count(*it) != 2)   return 1;
      }
   }
   return 0;
}

自定义桶特征

除了使用默认的 bucket_traits 类来存储桶数组之外, 用户还可以使用 bucket_traits<> 选项定义自己的类来存储桶数组. 用户自定义的桶特征必须满足以下接口:

class my_bucket_traits
{
   bucket_ptr        bucket_begin();
   const_bucket_ptr  bucket_begin() const;
   std::size_t bucket_count() const;
};

下面的桶特征只存储一个指向桶数组的指针, 但大小是编译期常量. 注意在定义无序容器之前, 使用辅助工具 unordered_bucket 和 unordered_bucket_ptr 来获取桶的类型及其指针:

#include <boost/intrusive/unordered_set.hpp>
#include <vector>

using namespace boost::intrusive;

//A class to be inserted in an unordered_set
class MyClass : public unordered_set_base_hook<>
{
   int int_;

   public:
   MyClass(int i = 0) : int_(i)
   {}

   friend bool operator==(const MyClass &l, const MyClass &r)
      {  return l.int_ == r.int_;   }
   friend std::size_t hash_value(const MyClass &v)
   {  //Use your favorite hash function, like boost::hash or std::hash
      return std::size_t(v.int_);
   }
};

//Define the base hook option
typedef base_hook< unordered_set_base_hook<> >     BaseHookOption;

//Obtain the types of the bucket and the bucket pointer
typedef unordered_bucket<BaseHookOption>::type     BucketType;
typedef unordered_bucket_ptr<BaseHookOption>::type BucketPtr;

//The custom bucket traits.
class custom_bucket_traits
{
   public:
   static const int NumBuckets = 100;

   custom_bucket_traits(BucketPtr buckets)
      :  buckets_(buckets)
   {}

   //Functions to be implemented by custom bucket traits
   BucketPtr   bucket_begin() const {  return buckets_;  }
   std::size_t bucket_count() const {  return NumBuckets;}

   private:
   BucketPtr buckets_;
};

//Define the container using the custom bucket traits
typedef unordered_set<MyClass, bucket_traits<custom_bucket_traits> > BucketTraitsUset;

int main()
{
   typedef std::vector<MyClass>::iterator VectIt;
   std::vector<MyClass> values;

   //Fill values
   for(int i = 0; i < 100; ++i)  values.push_back(MyClass(i));

   //Now create the bucket array and the custom bucket traits object
   BucketType buckets[custom_bucket_traits::NumBuckets];
   custom_bucket_traits btraits(buckets);

   //Now create the unordered set
   BucketTraitsUset uset(btraits);

   //Insert the values in the unordered set
   for(VectIt it(values.begin()), itend(values.end()); it != itend; ++it)
      uset.insert(*it);

   return 0;
}
