概念小结

以下是在后续章节中将用到的基本概念的小结:

概念简要小结

Node Algorithms

一个包含类型定义 (typedef) 和静态函数的类, 定义了可应用于一群 node 的基本操作. 它独立于节点定义, 并使用描述节点的 NodeTraits 模板参数进行配置.

Node Traits

一个定义 node 类型, 关联信息以及遍历节点和将节点插入节点群的基本操作的类.

Hook

用户必须作为基类或成员添加的类, 以使用户类与侵入式容器兼容. 钩子封装一个 node

Value Traits

一个包含类型定义 (typedef) 和操作的类, 用于从用户类获取 Node Algorithms 将使用的节点, 以及执行逆操作.

Intrusive Container

一种存储具有所需钩子的用户类的容器类型. 它接受一个 ValueTraits 模板参数作为配置信息.

Semi-Intrusive Container

类似于侵入式容器, 但半侵入式容器需要额外的内存 (例如辅助数组) 才能工作.
