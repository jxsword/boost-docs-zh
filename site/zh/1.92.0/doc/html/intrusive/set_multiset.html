侵入式关联容器: set, multiset, rbtree

set、multiset 与 rbtree 钩子
set、multiset 与 rbtree 容器
示例

Boost.Intrusive 还提供了关联容器, 这些容器在创建更复杂的关联容器 (例如维护一个或多个具有不同排序语义的索引的容器) 时非常有用. 与大多数 STL 关联容器实现一样, Boost.Intrusive 关联容器基于红黑树.

这些容器的内存开销通常为 3 个指针加 1 个位 (考虑对齐问题, 这意味着 3 个指针加一个整数). 如果指针具有偶对齐 (在大多数系统中通常如此), 该大小可缩减为 3 个指针.

空的非常数时间 size set, multiset 或 rbtree 的大小也是 3 个指针加一个整数 (以体积优化时为 3 个指针). 这些容器在许多操作 (如查找, 插入, 擦除等) 中具有对数复杂度. set 和 multiset 是标准 std::set 和 std::multiset 容器的侵入式等价物.

rbtree 是 set 和 multiset 容器的超集, 提供插入唯一键和多重键的函数.

set, multiset 和 rbtree 的钩子

set, multiset 和 rbtree 共享相同的钩子. 这是一个优势, 因为同一个用户类型可以先插入 multiset, 然后再插入 set, 而无需更改用户类的定义.

template <class ...Options>
class set_base_hook;
  • set_base_hook: 用户类公开派生自 set_base_hook, 以使其与 set/multiset 兼容.
template <class ...Options>
class set_member_hook;
  • set_member_hook: 用户类包含一个公有的 set_member_hook, 以使其与 set/multiset 兼容.

set_base_hook 和 set_member_hook 接受 如何使用 Boost.Intrusive 一节中说明的相同选项, 外加一个体积优化选项:

  • tag<class Tag> (仅用于基类钩子): 该参数用作标签 (tag), 因此可以从多个基类钩子派生. 默认: tag<default_tag>.
  • link_mode<link_mode_type LinkMode>: 链接策略. 默认: link_mode<safe_link>.
  • void_pointer<class VoidPointer>: 钩子内部使用的指针类型, 并会传播到容器. 默认: void_pointer<void*>.
  • optimize_size<bool Enable>: 钩子将针对体积而非速度进行优化. 如果指针对齐为偶数, 钩子会将红黑树节点的颜色位嵌入父指针中. 在某些平台上, 优化体积可能会略微降低速度性能, 因为访问父指针和颜色属性时需要掩码操作; 在其他平台上, 此选项由于改善了内存局部性而提升性能. 默认: optimize_size<false>.

set, multiset 和 rbtree 容器 

template <class T, class ...Options>
class set;

template <class T, class ...Options>
class multiset;

template <class T, class ...Options>
class rbtree;

这些容器接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • base_hook<class Hook> / member_hook<class T, class Hook, Hook T::* PtrToMember> / value_traits<class ValueTraits>: 指定用于配置容器的钩子类型或值特征. (要了解值特征, 请参见 具有自定义 ValueTraits 的容器 一节.)
  • constant_time_size<bool Enabled>: 激活常数时间 size() 操作. 默认: constant_time_size<true>
  • size_type<typename SizeType>: 指定用于存储容器 size 的类型. 默认: size_type<std::size_t>

它们还可以接受一个附加选项:

  • compare<class Compare>: 容器中待插入对象的比较函数. 比较仿函数必须产生严格弱序. 默认: compare< std::less<key_type> >
  • key_of_value<class KeyOfValueFunctionObject>: 一个函数对象, 定义待存储值类型的 key_type. 该类型将允许类似映射的接口. 详细信息参见 配合 set 和 multiset 的 map 与 multimap 式接口. 默认: key_type 等于 value_type (set 式接口).

示例

现在让我们看一个同时使用两种钩子和两种容器的小示例:

#include <boost/intrusive/set.hpp>
#include <vector>
#include <functional>
#include <cassert>

using namespace boost::intrusive;

                  //This is a base hook optimized for size
class MyClass : public set_base_hook<optimize_size<true> >
{
   int int_;

   public:
   //This is a member hook
   set_member_hook<> member_hook_;

   MyClass(int i)
      :  int_(i)
      {}
   friend bool operator< (const MyClass &a, const MyClass &b)
      {  return a.int_ < b.int_;  }
   friend bool operator> (const MyClass &a, const MyClass &b)
      {  return a.int_ > b.int_;  }
   friend bool operator== (const MyClass &a, const MyClass &b)
      {  return a.int_ == b.int_;  }
};

//Define a set using the base hook that will store values in reverse order
typedef set< MyClass, compare<std::greater<MyClass> > >     BaseSet;

//Define an multiset using the member hook
typedef member_hook<MyClass, set_member_hook<>, &MyClass::member_hook_> MemberOption;
typedef multiset< MyClass, MemberOption>   MemberMultiset;

int main()
{
   typedef std::vector<MyClass>::iterator VectIt;

   //Create several MyClass objects, each one with a different value
   std::vector<MyClass> values;
   for(int i = 0; i < 100; ++i)  values.push_back(MyClass(i));

   BaseSet baseset;
   MemberMultiset membermultiset;

   //Check that size optimization is activated in the base hook
   assert(sizeof(set_base_hook<optimize_size<true> >) == 3*sizeof(void*));
   //Check that size optimization is deactivated in the member hook
   assert(sizeof(set_member_hook<>) > 3*sizeof(void*));

   //Now insert them in the reverse order in the base hook set
   for(VectIt it(values.begin()), itend(values.end()); it != itend; ++it){
      baseset.insert(*it);
      membermultiset.insert(*it);
   }

   //Now test sets
   {
      BaseSet::reverse_iterator rbit(baseset.rbegin());
      MemberMultiset::iterator mit(membermultiset.begin());
      VectIt it(values.begin()), itend(values.end());

      //Test the objects inserted in the base hook set
      for(; it != itend; ++it, ++rbit)
         if(&*rbit != &*it)   return 1;

      //Test the objects inserted in the member hook set
      for(it = values.begin(); it != itend; ++it, ++mit)
         if(&*mit != &*it) return 1;
   }
   return 0;
}
