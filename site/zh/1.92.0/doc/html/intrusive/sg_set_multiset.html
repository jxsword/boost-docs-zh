基于替罪羊树的侵入式关联容器: sg_set, sg_multiset 和 sgtree

sg_set、sg_multiset 与 sgtree 容器
示例

替罪羊树是一种自平衡二叉搜索树, 它提供最坏情况 O(log n) 的查找时间以及 O(log n) 的均摊插入和删除时间. 与其他提供最坏情况 O(log n) 查找时间的自平衡二叉搜索树不同, 与普通二叉搜索树相比, 替罪羊树没有额外的每节点开销.

如果一半的节点位于根的左侧, 一半位于右侧, 则称该二叉搜索树是权重平衡的. a 高度平衡树由以下等式定义:

height(tree) <= log1/a(tree.size())

  • a == 1: 形成链表的树被认为是平衡的.
  • a == 0.5: 只有完美平衡的二叉树才被认为是平衡的.

替罪羊树是松散 a 高度平衡的, 因此:

height(tree) <= log1/a(tree.size()) + 1

替罪羊树支持 0.5 到 1 之间的任何 a. 如果 a 较大, 树进行再平衡的频率较低, 插入更快但查找较慢. 较小的 a 值可改善查找时间. Boost.Intrusive 中实现的替罪羊树利用替罪羊树的灵活性, 提供了 在运行时更改 a 的可能. 有关替罪羊树的更多信息, 请参见 Wikipedia 条目.

替罪羊树也有一些缺点:

  • 它们需要在根节点上额外存储数据 (例如树的大小) 以实现具有对数复杂度的操作, 因此无法提供 auto_unlink 钩子. 空替罪羊树的体积也会显著增大.
  • 判断树是否失衡所需的操作需要浮点运算, 例如 log1/a. 如果系统没有浮点运算 (如某些嵌入式系统), 替罪羊树的操作可能会变慢.

Boost.Intrusive 提供了 3 个基于替罪羊树的容器: sg_set, sg_multiset 和 sgtree. 前两个类似于 set 或 multiset, 后者是一种泛化, 同时提供插入唯一键和多重键的函数.

使用 Boost.Intrusive 钩子时, 这些容器的内存开销为 3 个指针.

空的 sg_set, sg_multiset 或 sgtree 的大小也是 3 个指针, 两个整数和两个浮点值 (在大多数系统上相当于 7 个指针的大小).

Boost.Intrusive 替罪羊关联容器不使用自己的钩子类型, 而是使用普通的二叉搜索树钩子. 有关这些钩子的更多信息, 请参见 二叉搜索树钩子: bs_set_base_hook 和 bs_set_member_hook 一节.

sg_set, sg_multiset 和 sgtree 容器 

template <class T, class ...Options>
class sg_set;

template <class T, class ...Options>
class sg_multiset;

template <class T, class ...Options>
class sgtree;

这些容器接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • base_hook<class Hook> / member_hook<class T, class Hook, Hook T::* PtrToMember> / value_traits<class ValueTraits>: 指定用于配置容器的钩子类型或值特征. (要了解值特征, 请参见 具有自定义 ValueTraits 的容器 一节.)
  • size_type<typename SizeType>: 指定用于存储容器 size 的类型. 默认: size_type<std::size_t>

它们还可以接受附加选项:

  • compare<class Compare>: 容器中待插入对象的比较函数. 比较仿函数必须产生严格弱序. 默认: compare< std::less<key_type> >
  • floating_point<bool Enable>: 当该选项停用时, 替罪羊树失去在运行时更改平衡因子 a 的能力, 但空容器的体积会减小, 且不执行浮点运算, 通常会提升容器性能. 该选项激活时使用的固定 a 因子为 1/sqrt(2) ~ 0,70711. 默认: floating_point<true>
  • key_of_value<class KeyOfValueFunctionObject>: 一个函数对象, 定义待存储值类型的 key_type. 该类型将允许类似映射的接口. 详细信息参见 配合 set 和 multiset 的 map 与 multimap 式接口. 默认: key_type 等于 value_type (set 式接口).

示例

现在让我们看一个使用二叉搜索树钩子以及 sg_set/ sg_multiset 容器的小示例:

#include <boost/intrusive/sg_set.hpp>
#include <vector>
#include <functional>
#include <cassert>

using namespace boost::intrusive;

class MyClass : public bs_set_base_hook<>
{
   int int_;

   public:
   //This is a member hook
   bs_set_member_hook<> member_hook_;

   MyClass(int i)
      :  int_(i)
      {}
   friend bool operator< (const MyClass &a, const MyClass &b)
      {  return a.int_ < b.int_;  }
   friend bool operator> (const MyClass &a, const MyClass &b)
      {  return a.int_ > b.int_;  }
   friend bool operator== (const MyClass &a, const MyClass &b)
      {  return a.int_ == b.int_;  }
};

//Define an sg_set using the base hook that will store values in reverse order
//and won't execute floating point operations.
typedef sg_set
   < MyClass, compare<std::greater<MyClass> >, floating_point<false> >   BaseSet;

//Define an multiset using the member hook
typedef member_hook<MyClass, bs_set_member_hook<>, &MyClass::member_hook_> MemberOption;
typedef sg_multiset< MyClass, MemberOption>   MemberMultiset;

int main()
{
   typedef std::vector<MyClass>::iterator VectIt;

   //Create several MyClass objects, each one with a different value
   std::vector<MyClass> values;
   for(int i = 0; i < 100; ++i)  values.push_back(MyClass(i));

   BaseSet baseset;
   MemberMultiset membermultiset;

   //Now insert them in the reverse order in the base hook sg_set
   for(VectIt it(values.begin()), itend(values.end()); it != itend; ++it){
      baseset.insert(*it);
      membermultiset.insert(*it);
   }

   //Change balance factor
   membermultiset.balance_factor(0.9f);

   //Now test sg_sets
   {
      BaseSet::reverse_iterator rbit(baseset.rbegin());
      MemberMultiset::iterator mit(membermultiset.begin());
      VectIt it(values.begin()), itend(values.end());

      //Test the objects inserted in the base hook sg_set
      for(; it != itend; ++it, ++rbit)
         if(&*rbit != &*it)   return 1;

      //Test the objects inserted in the member hook sg_set
      for(it = values.begin(); it != itend; ++it, ++mit)
         if(&*mit != &*it) return 1;
   }
   return 0;
}
