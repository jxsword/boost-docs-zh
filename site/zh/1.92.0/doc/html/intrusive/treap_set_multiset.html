基于 treap 的侵入式关联容器: treap_set, treap_multiset 和 treap

treap_set、treap_multiset 与 treap 容器
基于树堆的侵入式容器的异常安全性
示例

名称 treap 是 tree (树) 和 heap (堆) 的混合词, 表明 Treap 同时展现二叉搜索树和堆的性质. treap 是一种按键排序节点同时也按优先级属性排序节点的二叉搜索树. 节点的排列使得键构成二叉搜索树, 且优先级服从最大堆序性质.

  • 如果 v 是 u 的左后代, 则 key[v] < key[u];
  • 如果 v 是 u 的右后代, 则 key[v] > key[u];
  • 如果 v 是 u 的孩子, 则 priority[v] <= priority[u];

如果优先级不是随机的, 树通常会不平衡; 这种较差的理论平均情况行为可能被更好的期望情况行为所弥补, 因为最重要的项将靠近根. 这意味着最重要的对象将比较不重要的项被更快地检索到, 并且对于具有相同键的项, 最重要的对象会先被找到. 这些性质对某些应用很重要.

优先级比较将像键比较一样通过一个存储在侵入式容器中的函数对象提供. 这意味着优先级可以存储在要引入 treap 的值中, 或者在运行中计算 (通过哈希或类似方式).

Boost.Intrusive 提供了 3 个基于 treap 的容器: treap_set, treap_multiset 和 treap. 前两个类似于 set 或 multiset, 后者是一种泛化, 同时提供插入唯一键和多重键的函数.

使用 Boost.Intrusive 钩子时, 这些容器的内存开销为 3 个指针.

空的 treap_set, treap_multiset 或 treap 的大小也是 3 个指针加一个整数 (假设键和优先级比较为空函数对象且为常数时间 size).

Boost.Intrusive treap 关联容器不使用自己的钩子类型, 而是使用普通的二叉搜索树钩子. 有关这些钩子的更多信息, 请参见 二叉搜索树钩子: bs_set_base_hook 和 bs_set_member_hook 一节.

treap_set, treap_multiset 和 treap 容器 

template <class T, class ...Options>
class treap_set;

template <class T, class ...Options>
class treap_multiset;

template <class T, class ...Options>
class treap;

这些容器接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • base_hook<class Hook> / member_hook<class T, class Hook, Hook T::* PtrToMember> / value_traits<class ValueTraits>: 指定用于配置容器的钩子类型或值特征. (要了解值特征, 请参见 具有自定义 ValueTraits 的容器 一节.)
  • constant_time_size<bool Enabled>: 激活常数时间 size() 操作. 默认: constant_time_size<true>
  • size_type<typename SizeType>: 指定用于存储容器 size 的类型. 默认: size_type<std::size_t>

它们还可以接受附加选项:

  • compare<class Compare>: 容器中待插入对象的比较函数. 比较仿函数必须产生严格弱序. 默认: compare< std::less<key_type> >
  • priority_of_value<class PriorityOfValue>: 一个函数对象, 指定 treap 容器的优先级类型 (priority_type) 以及从值类型获取它的运算符. 默认: priority_type 等于 value_type (set 式接口).
  • priority<class PriorityCompare>: 容器中待插入对象的优先级比较函数. 比较仿函数必须产生严格弱序. 默认: priority< priority_compare<priority_type> >
  • key_of_value<class KeyOfValueFunctionObject>: 一个函数对象, 定义待存储值类型的 key_type. 该类型将允许类似映射的接口. 详细信息参见 配合 set 和 multiset 的 map 与 multimap 式接口. 默认: key_type 等于 value_type (set 式接口).

默认的 priority_compare<T> 对象函数将调用一个无限定函数 priority_order, 传入两个 const T 引用作为参数; 如果第一个参数具有更高优先级 (它会被更快地搜索到), 则应返回 true, 从而产生严格弱序. 该函数将通过 ADL 查找找到, 因此用户只需在与类相同的命名空间中定义一个 priority_order 函数:

struct MyType
{
   friend bool priority_order(const MyType &a, const MyType &b)
   {...}
};

或者

namespace mytype {

struct MyType{ ... };

bool priority_order(const MyType &a, const MyType &b)
{...}

}  //namespace mytype {

基于 treap 的侵入式容器的异常安全

一般来说, 侵入式容器提供强异常安全保证, 但 treap 容器必须处理两个可能抛出异常的仿函数 (一个用于值排序, 另一个用于优先级排序). 此外, treap 的擦除操作需要基于优先级排序函数的旋转, 这个问题会降低通常的 erase(const_iterator) 无抛出保证. 不过, 在这些情况下 intrusive 提供了可能的最强行为. 总结如下:

  • 如果优先级排序仿函数不抛出异常, 基于 treap 的容器提供的保证与其他基于树的容器完全相同.
  • 如果优先级排序仿函数抛出异常, 基于 treap 的容器提供强保证.

示例

现在让我们看一个使用二叉搜索树钩子以及 treap_set/ treap_multiset 容器的小示例:

#include <boost/intrusive/treap_set.hpp>
#include <vector>
#include <functional>
#include <cassert>

using namespace boost::intrusive;

class MyClass : public bs_set_base_hook<> //This is a base hook
{
   int int_;
   unsigned int prio_;

   public:
   //This is a member hook
   bs_set_member_hook<> member_hook_;

   MyClass(int i, unsigned int prio)  :  int_(i), prio_(prio)
      {}

   unsigned int get_priority() const
   {  return this->prio_;   }

   //Less and greater operators
   friend bool operator< (const MyClass &a, const MyClass &b)
      {  return a.int_ < b.int_;  }
   friend bool operator> (const MyClass &a, const MyClass &b)
      {  return a.int_ > b.int_;  }
   //Default priority compare
   friend bool priority_order (const MyClass &a, const MyClass &b)
      {  return a.prio_ < b.prio_;  }  //Lower value means higher priority
   //Inverse priority compare
   friend bool priority_inverse_order (const MyClass &a, const MyClass &b)
      {  return a.prio_ > b.prio_;  }  //Higher value means higher priority
};

struct inverse_priority
{
   bool operator()(const MyClass &a, const MyClass &b) const
   {  return priority_inverse_order(a, b); }
};


//Define an treap_set using the base hook that will store values in reverse order
typedef treap_set< MyClass, compare<std::greater<MyClass> > >     BaseSet;

//Define an multiset using the member hook that will store
typedef member_hook<MyClass, bs_set_member_hook<>, &MyClass::member_hook_> MemberOption;
typedef treap_multiset
   < MyClass, MemberOption, priority<inverse_priority> > MemberMultiset;

int main()
{
   typedef std::vector<MyClass>::iterator VectIt;

   //Create several MyClass objects, each one with a different value
   std::vector<MyClass> values;
   for(std::size_t i = 0; i < 100u; ++i)  values.push_back(MyClass((int)i, unsigned(i % 10)));

   BaseSet baseset;
   MemberMultiset membermultiset;

   //Now insert them in the sets
   for(VectIt it(values.begin()), itend(values.end()); it != itend; ++it){
      baseset.insert(*it);
      membermultiset.insert(*it);
   }

   //Now test treap_sets
   {
      BaseSet::reverse_iterator rbit(baseset.rbegin());
      MemberMultiset::iterator mit(membermultiset.begin());
      VectIt it(values.begin()), itend(values.end());

      //Test the objects inserted in the base hook treap_set
      for(; it != itend; ++it, ++rbit)
         if(&*rbit != &*it)   return 1;

      //Test the objects inserted in the member hook treap_set
      for(it = values.begin(); it != itend; ++it, ++mit)
         if(&*mit != &*it) return 1;

      //Test priority order
      for(int i = 0; i < 100; ++i){
         if(baseset.top()->get_priority() != static_cast<unsigned int>(i/10))
            return 1;
         if(membermultiset.top()->get_priority() != 9u - static_cast<unsigned int>(i/10))
            return 1;
         baseset.erase(baseset.top());
         membermultiset.erase(membermultiset.top());
      }
   }
   return 0;
}
