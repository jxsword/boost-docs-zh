具有等价键的有序关联容器中的稳定性与带提示插入

Boost.Intrusive 具有等价键的有序关联容器遵循 C++ 标准库缺陷报告 #233 的决议, 提供稳定性保证, 该决议在文档 对 LWG 问题 233 的评论: 关联容器中的插入提示 中有说明. 这意味着:

  • 不带提示的插入 成员函数总是在相等范围的 upper bound 处插入.
  • 带提示的插入 成员函数在提示节点与新节点的键等价时, 将新值插入到 提示之前.
  • 实现了 Andrew Koenig 的 尽可能靠近提示 提案. 新元素总是插入到尽可能靠近提示的位置. 因此, 例如, 如果存在等价值的子序列, 以 a.begin() 作为提示意味着新元素应插入到该子序列之前, 即使 a.begin() 相距很远. 这使得代码可以始终以简单的方式追加 (或前插) 一个相等范围, 例如: m.insert(m.end(), new_node); 或 m.insert(m.begin(), new_node);
