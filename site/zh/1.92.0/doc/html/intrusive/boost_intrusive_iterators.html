Boost.Intrusive 迭代器特性

空前向迭代器
Scary 迭代器

空正向迭代器

Boost.Intrusive 实现了 C++14 空正向迭代器, 这是 C++14 引入的特性. 这意味着相等和不等比较对所有指向同一底层序列的迭代器以及值初始化迭代器都有定义.

值初始化迭代器的行为如同指向同一空序列末尾之后的位置:

list<MyType> l = { ... };
auto ni = list<MyType>::iterator();
auto nd = list<MyType2>::iterator();
ni == ni; // True.
nd != nd; // False.
ni == nd; // Won't compile.

Scary 迭代器

题为 SCARY Iterator Assignment and Initialization 的论文 N2913 提出了一项要求: 标准容器的迭代器类型不得依赖除容器的 value_type, difference_type, pointer type 和 const_pointer 类型之外的任何类型实参. 特别地, 按照该提案, 标准容器迭代器的类型不应依赖于容器的 key_compare, hasher, key_equal 或 allocator 类型.

该论文证明了 SCARY 操作对于使用 STL 组件高效实现常见设计模式至关重要. 它表明, 支持 SCARY 操作的实现通过消除迭代器和算法模板的冗余特化来减少目标代码膨胀.

Boost.Intrusive 容器与标准容器略有不同. 特别是, 它们没有分配器参数, 并且可以用 STL 式容器中没有的附加选项进行配置. 因此 Boost.Intrusive 提供了自己的 SCARY iterator 实现: 当容器配置的选项不改变 值 <-> 节点 转换时, 迭代器类型不会改变. 更具体地说, 以下选项和条件保证迭代器类型保持不变:

  • 所有容器: size_type<>, constant_time_size<>,
  • slist: cache_last<>, linear<>,
  • unordered_[multi]set: hash<>, equal<>, power_2_buckets<>, cache_begin<>.
  • 所有树状容器 ([multi]set, avl_[multi]set, sg_[multi]set, bs_[multi]set, splay_[multi]set, treap_[multi]set): compare<>.
  • treap_[multi]set: priority<>
  • bs_[multi]set, sg_[multi]set, treap_[multi]set, splay_[multi]set: 配置相同选项时, 它们共享相同的迭代器类型.
