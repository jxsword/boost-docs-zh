二叉搜索树钩子: bs_set_base_hook 和 bs_set_member_hook

二叉搜索树钩子可用于多种树状容器, 这些容器在再平衡操作中不需要任何额外元数据. 这有很多优点, 因为二叉搜索树钩子还可用于在普通二叉搜索树, splay 树, 替罪羊树 (scapegoat tree) 和 treap 容器中插入值.

template <class ...Options>
class bs_set_base_hook;
  • bs_set_base_hook: 用户类公开派生自该类, 以使其与上述基于树的容器兼容.
template <class ...Options>
class bs_set_member_hook;
  • bs_set_member_hook: 用户类包含一个该类的公有成员, 以使其与上述基于树的容器兼容.

bs_set_base_hook 和 bs_set_member_hook 接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • tag<class Tag> (仅用于基类钩子): 该参数用作标签 (tag), 因此可以从多个基类钩子派生. 默认: tag<default_tag>.
  • link_mode<link_mode_type LinkMode>: 链接策略. 默认: link_mode<safe_link>.
  • void_pointer<class VoidPointer>: 钩子内部使用的指针类型, 并会传播到容器. 默认: void_pointer<void*>.
