什么是自动断链钩子?

Boost.Intrusive 提供了具有独特特性的额外钩子:

  • 当钩子的析构函数被调用时, 钩子会检查节点是否已插入容器. 如果是, 钩子会从容器中移除该节点.
  • 钩子有一个名为 unlink() 的成员函数, 如果用户愿意, 可以随时使用它将节点从容器中断链, 而无需任何对容器的引用.

这些钩子的额外开销与其对应的非自动断链钩子完全相同, 但有一个限制: 它们只能与 非常数时间 size 容器一起使用. 原因如下:

  • 自动断链钩子不存储对其所插入容器的任何引用.
  • 只有具有非常数时间 size() 的容器才允许在不引用容器的情况下从容器中移除对象.

这种自动断链特性在某些应用中很有用, 但必须 非常谨慎地使用:

  • 如果多个线程使用同一个容器, 自动断链钩子的析构函数将在没有任何线程同步的情况下被调用, 因此移除对象是线程不安全的.
  • 容器内容会在不直接修改容器的情况下静默改变. 这可能导致令人意外的效果.

这些自动断链钩子还具有安全模式特性:

  • 钩子的构造函数会将钩子置于一个已知良好的默认状态.
  • 每次将对象插入侵入式容器时, 容器都会检查钩子是否处于已知良好的默认状态. 如果不是, 将触发断言.
  • 每次从侵入式容器中擦除对象时, 容器都会将擦除的对象置于已知良好的默认状态.

自动断链钩子示例

下面看一个自动断链钩子的示例:

#include <boost/intrusive/list.hpp>
#include <cassert>

using namespace boost::intrusive;

typedef list_base_hook<link_mode<auto_unlink> > auto_unlink_hook;

class MyClass : public auto_unlink_hook
               //This hook removes the node in the destructor
{
   int int_;

   public:
   MyClass(int i = 0)   :  int_(i)  {}
   int  get_int()    { return int_; }
   void unlink()     {  auto_unlink_hook::unlink(); }
   bool is_linked()  {  return auto_unlink_hook::is_linked();  }
};

//Define a list that will store values using the base hook
//The list can't have constant-time size!
typedef list< MyClass, constant_time_size<false> > List;

int main()
{
   //Create the list
   List l;
   {
      //Create myclass and check it's linked
      MyClass myclass;
      assert(myclass.is_linked() == false);

      //Insert the object
      l.push_back(myclass);

      //Check that we have inserted the object
      assert(l.empty() == false);
      assert(&l.front() == &myclass);
      assert(myclass.is_linked() == true);

      //Now myclass' destructor will unlink it
      //automatically
   }

   //Check auto-unlink has been executed
   assert(l.empty() == true);

   {
      //Now test the unlink() function

      //Create myclass and check it's linked
      MyClass myclass;
      assert(myclass.is_linked() == false);

      //Insert the object
      l.push_back(myclass);

      //Check that we have inserted the object
      assert(l.empty() == false);
      assert(&l.front() == &myclass);
      assert(myclass.is_linked() == true);

      //Now unlink the node
      myclass.unlink();

      //Check auto-unlink has been executed
      assert(l.empty() == true);
   }
   return 0;
}

自动断链钩子与具有常数时间 size() 的容器

如前所述, Boost.Intrusive 自动断链钩子与具有常数时间 size() 的容器不兼容, 因此如果尝试用自动断链钩子的 value_traits 定义这样的容器, 将得到一条静态断言:

#include <boost/intrusive/list.hpp>

using boost::intrusive;

struct MyTag;

class MyClass : public list_base_hook< link_mode<auto_unlink> >
{/**/};

list <MyClass, constant_time_size<true> > bad_list;

int main()
{
   bad_list list;
   return 0;
}

将导致类似如下的错误:

  error : use of undefined type 'boost::STATIC_ASSERTION_FAILURE<false>'

指向类似这样的代码:

//Constant-time size is incompatible with auto-unlink hooks!
BOOST_STATIC_ASSERT(!(constant_time_size && ((int)value_traits::link_mode == (int)auto_unlink)));

这样, 如果尝试在常数时间 size 容器中使用自动断链钩子, 程序将无法编译.
