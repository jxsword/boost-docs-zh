基于 AVL 树的侵入式关联容器: avl_set, avl_multiset 和 avltree

avl_set、avl_multiset 与 avltree 钩子
avl_set、avl_multiset 与 avltree 容器
示例

与红黑树类似, AVL 树是平衡二叉树. AVL 树经常与红黑树相比较, 因为它们支持相同的操作集, 并且两者的基本操作都需要 O(log n) 时间. AVL 树比红黑树更严格地保持平衡, 导致插入和删除较慢但检索更快, 因此对于查找密集型应用, AVL 树的性能优于红黑树.

Boost.Intrusive 提供了 3 个基于 AVL 树的容器: avl_set, avl_multiset 和 avltree. 前两个类似于 set 或 multiset, 后者是一种泛化, 同时提供插入唯一键和多重键的函数.

使用 Boost.Intrusive 钩子时, 这些容器的内存开销通常为 3 个指针和 2 个位 (由于对齐, 这通常意味着 3 个指针加一个整数). 如果指针具有 4 字节对齐 (在 32 位系统中通常如此), 该大小可缩减为 3 个指针.

空的非常数时间 size avl_set, avl_multiset 或 avltree 的大小也是 3 个指针加一个整数 (以体积优化时为 3 个指针).

avl_set, avl_multiset 和 avltree 的钩子

avl_set, avl_multiset 和 avltree 共享相同的钩子.

template <class ...Options>
class avl_set_base_hook;
  • avl_set_base_hook: 用户类公开派生自该类, 以使其与基于 AVL 树的容器兼容.
template <class ...Options>
class avl_set_member_hook;
  • set_member_hook: 用户类包含一个该类的公有成员, 以使其与基于 AVL 树的容器兼容.

avl_set_base_hook 和 avl_set_member_hook 接受 如何使用 Boost.Intrusive 一节中说明的相同选项, 外加一个优化节点体积的选项:

  • tag<class Tag> (仅用于基类钩子): 该参数用作标签 (tag), 因此可以从多个基类钩子派生. 默认: tag<default_tag>.
  • link_mode<link_mode_type LinkMode>: 链接策略. 默认: link_mode<safe_link>.
  • void_pointer<class VoidPointer>: 钩子内部使用的指针类型, 并会传播到容器. 默认: void_pointer<void*>.
  • optimize_size<bool Enable>: 钩子将针对体积而非速度进行优化. 如果指针对齐为 4 的倍数, 钩子会将 AVL 树节点的平衡位嵌入父指针中. 在某些平台上, 优化体积可能会略微降低速度性能, 因为访问父指针和平衡因子属性时需要掩码操作; 在其他平台上, 此选项由于改善了内存局部性而提升性能. 默认: optimize_size<false>.

avl_set, avl_multiset 和 avltree 容器 

template <class T, class ...Options>
class avl_set;

template <class T, class ...Options>
class avl_multiset;

template <class T, class ...Options>
class avltree;

这些容器接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • base_hook<class Hook> / member_hook<class T, class Hook, Hook T::* PtrToMember> / value_traits<class ValueTraits>: 指定用于配置容器的钩子类型或值特征. (要了解值特征, 请参见 具有自定义 ValueTraits 的容器 一节.)
  • constant_time_size<bool Enabled>: 激活常数时间 size() 操作. 默认: constant_time_size<true>
  • size_type<typename SizeType>: 指定用于存储容器 size 的类型. 默认: size_type<std::size_t>

它们还可以接受一个附加选项:

  • compare<class Compare>: 容器中待插入对象的比较函数. 比较仿函数必须产生严格弱序. 默认: compare< std::less<key_type> >
  • key_of_value<class KeyOfValueFunctionObject>: 一个函数对象, 定义待存储值类型的 key_type. 该类型将允许类似映射的接口. 详细信息参见 配合 set 和 multiset 的 map 与 multimap 式接口. 默认: key_type 等于 value_type (set 式接口).

示例

现在让我们看一个同时使用两种钩子以及 avl_set/ avl_multiset 容器的小示例:

#include <boost/intrusive/avl_set.hpp>
#include <vector>
#include <functional>
#include <cassert>

using namespace boost::intrusive;

                  //This is a base hook optimized for size
class MyClass : public avl_set_base_hook<optimize_size<true> >
{
   int int_;

   public:
   //This is a member hook
   avl_set_member_hook<> member_hook_;

   MyClass(int i)
      :  int_(i)
      {}
   friend bool operator< (const MyClass &a, const MyClass &b)
      {  return a.int_ < b.int_;  }
   friend bool operator> (const MyClass &a, const MyClass &b)
      {  return a.int_ > b.int_;  }
   friend bool operator== (const MyClass &a, const MyClass &b)
      {  return a.int_ == b.int_;  }
};

//Define an avl_set using the base hook that will store values in reverse order
typedef avl_set< MyClass, compare<std::greater<MyClass> > >     BaseSet;

//Define an multiset using the member hook
typedef member_hook<MyClass, avl_set_member_hook<>, &MyClass::member_hook_> MemberOption;
typedef avl_multiset< MyClass, MemberOption>   MemberMultiset;

int main()
{
   typedef std::vector<MyClass>::iterator VectIt;

   //Create several MyClass objects, each one with a different value
   std::vector<MyClass> values;
   for(int i = 0; i < 100; ++i)  values.push_back(MyClass(i));

   BaseSet baseset;
   MemberMultiset membermultiset;

   //Check that size optimization is activated in the base hook
   assert(sizeof(avl_set_base_hook<optimize_size<true> >) == 3*sizeof(void*));
   //Check that size optimization is deactivated in the member hook
   assert(sizeof(avl_set_member_hook<>) > 3*sizeof(void*));

   //Now insert them in the sets
   for(VectIt it(values.begin()), itend(values.end()); it != itend; ++it){
      baseset.insert(*it);
      membermultiset.insert(*it);
   }

   //Now test avl_sets
   {
      BaseSet::reverse_iterator rbit(baseset.rbegin());
      MemberMultiset::iterator mit(membermultiset.begin());
      VectIt it(values.begin()), itend(values.end());

      //Test the objects inserted in the base hook avl_set
      for(; it != itend; ++it, ++rbit)
         if(&*rbit != &*it)   return 1;

      //Test the objects inserted in the member hook avl_set
      for(it = values.begin(); it != itend; ++it, ++mit)
         if(&*mit != &*it) return 1;
   }
   return 0;
}
