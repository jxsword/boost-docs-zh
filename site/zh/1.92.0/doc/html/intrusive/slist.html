侵入式单链表: slist

slist 钩子
slist 容器
示例

slist 是 Boost.Intrusive 中最简单的侵入式容器: 单链表. 它强加的内存开销为每个节点 1 个指针. 空的非常数时间 size slist 的大小是 1 个指针. 不过, 这种轻量级的内存开销也带来了缺点: 许多操作具有线性时间复杂度, 甚至包括一些通常是常数时间的操作, 如 swap. slist 只提供正向迭代器.

在大多数情况下, 双向链表更可取, 因为它以稍大的体积开销提供更多的常数时间函数. 然而, 对于某些应用 (如构建更精细的容器), 单链表因其低体积开销而必不可少.

slist 的钩子

与 Boost.Intrusive 的其他容器一样, slist 有两种钩子类型:

template <class ...Options>
class slist_base_hook;
  • slist_base_hook: 用户类公开派生自 slist_base_hook, 以使其与 slist 兼容.
template <class ...Options>
class slist_member_hook;
  • slist_member_hook: 用户类包含一个公有的 slist_member_hook, 以使其与 slist 兼容.

slist_base_hook 和 slist_member_hook 接受 如何使用 Boost.Intrusive 一节中说明的相同选项:

  • tag<class Tag> (仅用于基类钩子): 该参数用作标签 (tag), 因此可以从多个 slist 钩子派生. 默认: tag<default_tag>.
  • link_mode<link_mode_type LinkMode>: 链接策略. 默认: link_mode<safe_link>.
  • void_pointer<class VoidPointer>: 钩子内部使用的指针类型, 并会传播到容器. 默认: void_pointer<void*>.

slist 容器 

template <class T, class ...Options>
class slist;

slist 接受 如何使用 Boost.Intrusive 一节中说明的选项:

  • base_hook<class Hook> / member_hook<class T, class Hook, Hook T::* PtrToMember> / value_traits<class ValueTraits>: 指定用于配置容器的钩子类型或值特征. (要了解值特征, 请参见 具有自定义 ValueTraits 的容器 一节.)
  • constant_time_size<bool Enabled>: 激活常数时间 size() 操作. 默认: constant_time_size<true>
  • size_type<typename SizeType>: 指定用于存储容器 size 的类型. 默认: size_type<std::size_t>.

slist 可以接受附加选项:

  • linear<bool Enable>: 单链表实现为以空结尾的链表而非循环链表. 这允许 O(1) swap, 但会失去一些操作, 如 container_from_end_iterator.
  • cache_last<bool Enable>: slist 还存储一个指向单链表最后一个元素的指针. 这允许 O(1) swap, splice_after(iterator, slist &) 并使链表提供新函数, 如 push_back(reference) 和 back(). 自然地, 空链表的体积会增大 sizeof(void_pointer), 并且缓存的最后节点指针必须在每次操作中更新, 这可能带来轻微的性能影响.

auto_unlink 钩子在使用 linear<true> 和/或 cache_last<true> 选项时不可用. 如果使用 auto_unlink 钩子并指定了这些选项, 将触发静态断言.

示例

现在让我们看一个同时使用两种钩子的小示例:

#include <boost/intrusive/slist.hpp>
#include <vector>

using namespace boost::intrusive;

                  //This is a base hook
class MyClass : public slist_base_hook<>
{
   int int_;

   public:
   //This is a member hook
   slist_member_hook<> member_hook_;

   MyClass(int i)
      :  int_(i)
   {}
};

//Define an slist that will store MyClass using the public base hook
typedef slist<MyClass> BaseList;

//Define an slist that will store MyClass using the public member hook
typedef member_hook<MyClass, slist_member_hook<>, &MyClass::member_hook_> MemberOption;
typedef slist<MyClass, MemberOption> MemberList;

int main()
{
   typedef std::vector<MyClass>::iterator VectIt;
   typedef std::vector<MyClass>::reverse_iterator VectRit;

   //Create several MyClass objects, each one with a different value
   std::vector<MyClass> values;
   for(int i = 0; i < 100; ++i)  values.push_back(MyClass(i));

   BaseList baselist;
   MemberList memberlist;

   //Now insert them in the reverse order in the base hook list
   for(VectIt it(values.begin()), itend(values.end()); it != itend; ++it)
      baselist.push_front(*it);

   //Now insert them in the same order as in vector in the member hook list
   for(BaseList::iterator it(baselist.begin()), itend(baselist.end())
      ; it != itend; ++it){
      memberlist.push_front(*it);
   }

   //Now test lists
   {
      BaseList::iterator bit(baselist.begin());
      MemberList::iterator mit(memberlist.begin());
      VectRit rit(values.rbegin()), ritend(values.rend());
      VectIt  it(values.begin()), itend(values.end());

      //Test the objects inserted in the base hook list
      for(; rit != ritend; ++rit, ++bit)
         if(&*bit != &*rit)   return 1;

      //Test the objects inserted in the member hook list
      for(; it != itend; ++it, ++mit)
         if(&*mit != &*it)    return 1;
   }

   return 0;
}
