引言

有时需要一种泛型 (这里指 一般通用 意义上的泛型, 而非 基于模板的编程) 类型: 真正可变的变量, 能够容纳许多其他更具体类型的值, 而不是 C++ 常规的严格静态类型. 我们可以区分出三种基本的泛型类型:

  • 转换类型: 可以容纳若干可能值类型之一的类型, 例如 int 与 string, 并可在它们之间自由转换, 例如把 5 解释为 "5", 或反之. 这类类型在脚本语言和其他解释型语言中很常见. boost::lexical_cast 就支持此类转换功能.
  • 判别类型: 包含不同类型的值但不尝试在它们之间进行转换的类型, 即 5 被严格地作为 int 保存, 既不隐式转换为 "5", 也不隐式转换为 5.0. 它们对解释持无所谓态度但对类型保持感知, 这实际上使它们成为安全的单一值泛型容器, 不会因歧义转换而产生意外.
  • 非判别类型: 可以引用任何东西但对其底层实际类型一无所知的类型, 把所有形式的访问和解释都交给程序员. 这一领域由 void * 主导, 它为出人意料的未定义行为留下了大量空间.

boost::any 类 (基于 Kevlin Henney 在 Valued Conversions (C++ Report 12(7), 2000 年 7/8 月) 一文中所描述的同名类) 是基于第二种类别的变体值类型. 它支持对任何值类型的拷贝, 以及严格针对其类型的安全检查式值提取. 类似的设计若提供更合适的运算符, 可用于泛化函数适配器 any_function、泛化迭代器适配器 any_iterator, 以及其他需要统一运行期处理但只支持编译期模板参数一致性的对象类型.

boost::anys::unique_any 类 (基于 🐙 userver 框架 中的 utils::AnyMovable 类) 是基于第二种类别的变体值类型. 它支持严格针对其类型的安全检查式值提取以及值所有权的传递. 可以把 boost::anys::unique_any 看作 boost::any (或 std::any) 的替代品, 它不要求对所保存的类型进行拷贝或移动构造.
