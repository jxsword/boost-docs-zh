引言

“为什么要花五天时间手工编程, 而你可以用生命中的五年把它自动化?”

-- Terrence Parr, ANTLR/PCCTS 作者

这么说吧, QuickBook 最初是一个周末黑客项目. 它原本旨在作为使用 Spirit 的示例应用. 它是什么? 你现在看到的这份文档就是由 QuickBook 自动生成的. 这些文件由一个主文件生成:

quickbook.qbk

这个名为 QuickDoc 的古怪工具永不消亡; 得益于 Eric Niebler 复活了该项目, 使其生成 BoostBook 而非 HTML, 它进化成了一个更加古怪的工具. BoostBook 文档格式是 DocBook 的扩展, 后者是一种基于 SGML 或 XML 的描述文档的格式.

提示

使用 QuickBook 不需要了解任何关于 BoostBook 或 DocBook 的知识. 对 DocBook 的基本了解可能有帮助, 但应该不是必需的. 对于真正高级的内容, 你将需要了解 DocBook, 但起初可以忽略它, 或许一直如此.

QuickBook 是一种 WikiWiki 风格的文档工具, 面向 C++ 文档, 使用简单的规则和标记来完成简单的格式化任务. QuickBook 扩展了 WikiWiki 的概念. 与 WikiWiki 一样, QuickBook 文档是简单的文本文件. 单个 QuickBook 文档可以生成一套完全链接的精美 HTML 和 PostScript/PDF 文档, 包含图像和语法着色的源代码.

特性包括:

  • 生成 BoostBook XML, 进而生成 HTML、PostScript 和 PDF
  • 用简单标记链接到 Doxygen 生成的实体
  • 用于简单文本替换的宏系统
  • 用简单标记表示斜体、粗体、预格式化文本、简介块、代码示例、表格、URL、锚点、图像等
  • 代码示例的自动语法着色
  • CSS 支持
