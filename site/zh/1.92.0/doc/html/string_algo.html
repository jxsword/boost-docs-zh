引言

字符串算法库提供了 STL 中缺失的字符串相关算法的泛型实现. 它是对 STL 算法库的扩展, 包括裁剪、大小写转换、谓词以及查找/替换函数. 所有这些函数都有多种变体, 便于针对特定需求选择最合适的一种.

本实现并不限于与特定容器 (如 std::basic_string) 一起工作, 而是尽可能通用. 这种泛化并不损害性能, 因为算法在能带来性能提升时会使用容器特有的特性.

重要提示: 在本文档中, 我们使用术语 字符串 表示存储在任意容器中的 字符 序列. 字符串 不限于 std::basic_string, 字符 也不必是 char 或 wchar_t, 尽管它们是最常见的候选. 有关受支持字符串类型的精确规范, 请查阅 设计章节.

库接口的函数和类定义在命名空间 boost::algorithm 中, 并通过 using 声明提升到命名空间 boost 中.

文档分为若干部分. 快速入门可先阅读 用法 一节, 再阅读 快速参考. 设计主题、概念 和 设计理由 解释了库的设计与结构, 并说明应如何使用. 完整的实用工具与算法列表见 参考. 参考中的函数和类按定义它们的头文件组织. 参考中包含指向库中每个实体的详细说明的链接.
