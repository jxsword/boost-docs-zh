可移动但不可复制的类型

有些类型不适合复制语义, 但仍然可以使其可移动. 例如:

  • unique_ptr (非共享, 不可复制的所有权)
  • 表示执行线程的类型
  • 表示文件描述符的类型

通过使这类类型可移动 (尽管仍不可复制), 它们的用处大大增加. 可移动但不可复制的类型可以从工厂函数按值返回:

file_descriptor create_file(/* ... */);
//...
file_descriptor data_file;
//...
data_file = create_file(/* ... */);  // No copies!

在上面的示例中, 只要来源 file_descriptor 是右值, 底层文件句柄就会从一个对象传递到另一个对象. 任何时刻仍然只有一个底层文件句柄, 且同一时间只有一个 file_descriptor 拥有它.

要用可移植语法编写一个可移动但不可复制的类型, 你需要遵循以下简单步骤:

  • 把下面的宏放在 private 部分: BOOST_MOVABLE_BUT_NOT_COPYABLE(classname)
  • 编写一个以 BOOST_RV_REF(classname) 作为参数的移动构造函数和移动赋值运算符

下面是使用可移植语法的 file descriptor 定义:

#include <boost/move/utility_core.hpp>
#include <stdexcept>

class file_descriptor
{
   int os_descr_;

   private:
   BOOST_MOVABLE_BUT_NOT_COPYABLE(file_descriptor)

   public:
   explicit file_descriptor(const char *filename)              //Constructor
      : os_descr_(operating_system_open_file(filename))
   {
      if(!os_descr_)
         throw std::runtime_error("file not found");
   }

   ~file_descriptor()                                          //Destructor
   {  if(os_descr_)  operating_system_close_file(os_descr_);  }

   file_descriptor(BOOST_RV_REF(file_descriptor) x)            // Move ctor
      :  os_descr_(x.os_descr_)
   {  x.os_descr_ = 0;  }

   file_descriptor& operator=(BOOST_RV_REF(file_descriptor) x) // Move assign
   {
      if(os_descr_) operating_system_close_file(os_descr_);
      os_descr_   = x.os_descr_;
      x.os_descr_ = 0;
      return *this;
   }

   bool empty() const   {  return os_descr_ == 0;  }
};
