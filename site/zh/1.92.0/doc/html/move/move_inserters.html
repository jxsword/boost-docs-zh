移动插入器

与标准插入迭代器类似, 可以用与写入数组相同的方式来处理移动插入. 本库提供了一种特殊的迭代器适配器, 称为移动插入迭代器. 使用常规的迭代器类时,

while (first != last) *result++ = *first++;

会把范围 [first,last) 复制到以 result 开始的范围中. 若 result 是移动插入迭代器, 同样的代码将把相应元素移动插入到容器中. 这一机制使本库中所有复制算法都能以移动插入模式而非常规覆盖模式工作. 本库提供 3 种移动插入迭代器及其辅助函数:

// Note: C models Container
template <typename C>
class back_move_insert_iterator;

template <typename C>
back_move_insert_iterator<C> back_move_inserter(C& x);

template <typename C>
class front_move_insert_iterator;

template <typename C>
front_move_insert_iterator<C> front_move_inserter(C& x);

template <typename C>
class move_insert_iterator;

template <typename C>
move_insert_iterator<C> move_inserter(C& x, typename C::iterator it);

移动插入迭代器由一个容器构造, 如果插入位置既不在容器开头也不在容器末尾, 则还可以由指向插入位置的一个容器迭代器构造. 插入迭代器满足输出迭代器的要求. operator* 返回移动插入迭代器本身. 在插入迭代器上定义了赋值 operator=(T& x), 以允许向它们写入, 它把 x 插入到插入迭代器所指向位置的正前方. 换句话说, insert iterator 就像一个指向容器中插入发生位置的游标. back_move_iterator 把元素移动插入到容器末尾, front_insert_iterator 把元素移动插入到容器开头, 而 move_insert_iterator 把元素移动插入到迭代器在容器中所指向的位置. back_move_inserter, front_move_inserter 和 move_inserter 是从一个容器构造插入迭代器的三个函数. 下面是使用它们的示例:

#include <boost/move/iterator.hpp>
#include <boost/container/list.hpp>
#include "movable.hpp"
#include <cassert>
#include <algorithm>

using namespace ::boost::container;

typedef list<movable> list_t;
typedef list_t::iterator l_iterator;

template<class MoveInsertIterator>
void test_move_inserter(list_t &l2, MoveInsertIterator mit)
{
   //Create a list with 10 default constructed objects
   list<movable> l(10);
   assert(!l.begin()->moved());
   l2.clear();

   //Move insert into l2 containers
   std::copy(l.begin(), l.end(), mit);

   //Check size and status
   assert(l2.size() == l.size());
   assert(l.begin()->moved());
   assert(!l2.begin()->moved());
}

int main()
{
   list_t l2;
   test_move_inserter(l2, boost::back_move_inserter(l2));
   test_move_inserter(l2, boost::front_move_inserter(l2));
   test_move_inserter(l2, boost::move_inserter(l2, l2.end()));
   return 0;
}
