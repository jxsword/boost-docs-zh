实现可复制且可移动的类

Copyable and movable classes in C++0x
Copyable and movable classes in portable syntax for both C++03 and C++0x compilers

C++0x 中的可复制且可移动类

考虑一个拥有资源并提供复制语义 (复制构造函数和赋值运算符) 的简单句柄类. 例如, 一个 clone_ptr 可能拥有一个指针, 并出于复制目的对其调用 clone():

template <class T>
class clone_ptr
{
   private:
   T* ptr;

   public:
   // construction
   explicit clone_ptr(T* p = 0) : ptr(p) {}

   // destruction
   ~clone_ptr() { delete ptr; }

   // copy semantics
   clone_ptr(const clone_ptr& p)
      : ptr(p.ptr ? p.ptr->clone() : 0) {}

   clone_ptr& operator=(const clone_ptr& p)
   {
      if (this != &p)
      {
         T *p = p.ptr ? p.ptr->clone() : 0;
         delete ptr;
         ptr = p;
      }
      return *this;
   }

   // move semantics
   clone_ptr(clone_ptr&& p)
      : ptr(p.ptr) { p.ptr = 0; }

   clone_ptr& operator=(clone_ptr&& p)
   {
      if(this != &p)
      {
         std::swap(ptr, p.ptr);
         delete p.ptr;
         p.ptr = 0;
      }
      return *this;
   }

   // Other operations...
};

clone_ptr 具有预期的复制构造函数和赋值语义, 复制时复制资源. 注意, 复制构造或赋值一个 clone_ptr 是相对昂贵的操作:

clone_ptr<Base> p1(new Derived());
// ...
clone_ptr<Base> p2 = p1;  // p2 and p1 each own their own pointer

clone_ptr 是你可能在当今 C++ 书籍中见到的代码, 除了标记为 move semantics 的部分之外. 该部分是用 C++0x 的 rvalue references 实现的. 你可以在以下论文中找到关于右值引用的一些很好的介绍和教程:

  • A Brief Introduction to Rvalue References
  • Rvalue References: C++0x Features in VC10, Part 2

当已知复制的来源是一个 rvalue (例如临时对象) 时, 可以通过窃取来源的指针 (没有人会注意到!) 来避免可能昂贵的 clone() 操作. 上面的移动构造函数正是这样做的, 它让右值处于默认构造的状态. 移动赋值运算符做的也是同样的事, 只是会先释放旧资源.

现在, 当代码试图复制一个右值 clone_ptr, 或者该代码显式允许把复制来源视为右值 (使用 boost::move) 时, 该操作将执行得快得多.

clone_ptr<Base> p1(new Derived());
// ...
clone_ptr<Base> p2 = boost::move(p1);  // p2 now owns the pointer instead of p1
p2 = clone_ptr<Base>(new Derived());   // temporary is moved to p2
}

用可移植语法实现适用于 C++03 与 C++0x 编译器的可复制且可移动类

对于不支持 rvalue references 的编译器, 移动语义的许多方面都可以模拟, Boost.Move 为此提供了工具. 使用 Boost.Move, 我们可以编写 clone_ptr, 使其既能在支持右值引用的编译器上工作, 也能在符合 C++03 的编译器上工作. 你只需遵循以下简单步骤:

  • 把下面的宏放在 private 部分: BOOST_COPYABLE_AND_MOVABLE(classname)
  • 复制构造函数保持原样.
  • 编写一个以 BOOST_COPY_ASSIGN_REF(classname) 作为参数的复制赋值运算符
  • 编写一个以 BOOST_RV_REF(classname) 作为参数的移动构造函数和移动赋值运算符

让我们看看它们如何应用到 clone_ptr:

template <class T>
class clone_ptr
{
   private:
   // Mark this class copyable and movable
   BOOST_COPYABLE_AND_MOVABLE(clone_ptr)
   T* ptr;

   public:
   // Construction
   explicit clone_ptr(T* p = 0) : ptr(p) {}

   // Destruction
   ~clone_ptr() { delete ptr; }

   clone_ptr(const clone_ptr& p) // Copy constructor (as usual)
      : ptr(p.ptr ? p.ptr->clone() : 0) {}

   clone_ptr& operator=(BOOST_COPY_ASSIGN_REF(clone_ptr) p) // Copy assignment
   {
      if (this != &p){
         T *tmp_p = p.ptr ? p.ptr->clone() : 0;
         delete ptr;
         ptr = tmp_p;
      }
      return *this;
   }

   //Move semantics...
   clone_ptr(BOOST_RV_REF(clone_ptr) p)            //Move constructor
      : ptr(p.ptr) { p.ptr = 0; }

   clone_ptr& operator=(BOOST_RV_REF(clone_ptr) p) //Move assignment
   {
      if (this != &p){
         delete ptr;
         ptr = p.ptr;
         p.ptr = 0;
      }
      return *this;
   }
};

问题: 对于不拥有资源的类型怎么办? (例如 std::complex?)

在这种情况下无需做任何工作. 复制构造函数已经是最优的.
