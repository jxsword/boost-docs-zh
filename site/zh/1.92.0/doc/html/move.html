重要

为了在 C++03 模式下使用仅可移动值的容器, 你需要使用支持移动语义的容器, 例如 Boost.Container 的容器

已测试的编译器

Boost.Move 已在以下编译器/平台上测试:

  • Visual C++ >= 7.1.
  • GCC >= 4.1.
警告

GCC < 4.3 和 MSVC < 9.0 已被弃用, 将在下一个版本中移除.
