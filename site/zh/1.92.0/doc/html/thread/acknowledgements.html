致谢

最初的 Boost.Thread 由 William Kempf 编写, 众多其他人亦有贡献. 这个新版本最初源于一次以全新代码、按照 William Kempf 的设计重写 Boost.Thread 的尝试, 以便能够按 Boost Software License 发布. 然而, 由于 C++ 标准委员会一直在积极讨论为 C++ 标准化一个线程库, 本库也随之演进以反映相关提案, 同时尽可能保持向后兼容.

特别要感谢 Roland Schwarz, 他为最初的 Boost.Thread 库投入了大量时间和代码, 并一直积极参与重写工作. 将平台特定实现拆分到独立目录的方案正是由 Roland 设计的, 他的投入为提升当前实现的质量做出了很大贡献.

同样要感谢 Peter Dimov、Howard Hinnant、Alexander Terekhov、Chris Thomasson 以及其他人对代码实现细节提出的意见.
