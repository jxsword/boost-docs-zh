时间要求

已弃用

自 Boost 1.50.0 起, Boost.Thread 库对标准 C++11 中定义的所有需要超时的操作使用 Boost.Chrono 库. 这些包括 (但不限于) :

  • boost::this_thread::sleep_for
  • boost::this_thread::sleep_until
  • boost::thread::try_join_for
  • boost::thread::try_join_until
  • boost::condition_variable::wait_for
  • boost::condition_variable::wait_until
  • boost::condition_variable_any::wait_for
  • boost::condition_variable_any::wait_until
  • TimedLockable::try_lock_for
  • TimedLockable::try_lock_until

已弃用

Typedef system_time
非成员函数 get_system_time()

Boost 1.35.0 中引入的、使用 Boost.Date_Time 库的与时间相关的函数已弃用. 这些包括 (但不限于) :

  • boost::this_thread::sleep()
  • timed_join()
  • timed_wait()
  • timed_lock()

对于接受绝对时间参数的重载, 需要一个 boost::system_time 类型的对象. 通常, 这通过向当前时间 (通过对 boost::get_system_time() 的调用获得) 加上一个时长来获得. 例如:

boost::system_time const timeout=boost::get_system_time() + boost::posix_time::milliseconds(500);

extern bool done;
extern boost::mutex m;
extern boost::condition_variable cond;

boost::unique_lock<boost::mutex> lk(m);
while(!done)
{
    if(!cond.timed_wait(lk,timeout))
    {
        throw "timed out";
    }
}

对于接受 TimeDuration 参数的重载, 可以使用任何满足 Boost.Date_Time Time Duration requirements 的类型的对象, 例如:

boost::this_thread::sleep(boost::posix_time::milliseconds(25));

boost::mutex m;
if(m.timed_lock(boost::posix_time::nanoseconds(100)))
{
    //  ...
}

Typedef system_time 

#include <boost/thread/thread_time.hpp>

typedef boost::posix_time::ptime system_time;

有关 boost::posix_time::ptime 的文档参见 Boost.Date_Time 库.

非成员函数 get_system_time() 

#include <boost/thread/thread_time.hpp>

system_time get_system_time();

返回:

当前时间.

抛出:

无.
