动机

基于 C++ Concurrency in Action 一书中定义的 scoped_thread 类, Boost.Thread 定义了一个线程封装类: 当线程在析构时仍处于 joinable 状态, 它不调用 terminate, 而是执行以模板参数给出的特定操作.

C++ Concurrency in Action 中定义的 scoped_thread 类更接近于 strict_scoped_thread 类——后者不允许对被封装线程做任何修改; 而 Boost.Thread 提供的 scoped_thread 类则提供与 thread 相同的非弃用接口.

Tutorial

作用域线程 (Scoped Threads) 是对线程的封装, 允许用户指定在销毁时执行什么操作. 常见用途之一是在销毁时 join 线程, 这也是默认行为. 这是它与 thread 的唯一区别: thread 在析构时若线程仍处于 joinable 状态会调用 std::terminate(), 而 strict_scoped_thread<> 或 scoped_thread<> 在 joinable 时会 join 该线程.

strict_scoped_thread 与 scoped_thread 的区别在于: strict_scoped_thread 完全隐藏其拥有的线程, 用户除了执行以参数给出的特定操作外对该线程无能为力; 而 scoped_thread 提供与 thread 相同的接口, 并转发所有操作.

boost::strict_scoped_thread<> t1((boost::thread(f)));
//t1.detach(); // compile fails
boost::scoped_thread<> t2((boost::thread(f)));
t2.detach();

    t.detach();
  }

函数对象 join_if_joinable 

struct join_if_joinable
{
  template <class Thread>
  void operator()(Thread& t)
  {
    if (t.joinable())
    {
      t.join();
    }
  }
};

函数对象 interrupt_and_join_if_joinable 

struct interrupt_and_join_if_joinable
{
  template <class Thread>
  void operator()(Thread& t)
  {
    t.interrupt();
    if (t.joinable())
    {
      t.join();
    }
  }
};

一种 RAII thread 封装, 附加一个特定的销毁器 (destroyer) , 允许掌控销毁时可以执行的操作.

CallableThread: 一个可调用对象 void(thread&).

默认值为 join_if_joinable.

若 thread 处于 joinable 状态, thread 的析构函数会终止程序. 此封装可用于在销毁之前 join 线程.

#include <boost/thread/scoped_thread.hpp>

template <class CallableThread, class Thread = thread>
class scoped_thread
{
  thread t_; // for exposition purposes only
public:
    scoped_thread() noexcept;
    scoped_thread(const scoped_thread&) = delete;
    scoped_thread& operator=(const scoped_thread&) = delete;

    explicit scoped_thread(thread&& th) noexcept;
    template <typename F&&, typename ...Args>
    explicit scoped_thread(F&&, Args&&...);

    ~scoped_thread();

    // move support
    scoped_thread(scoped_thread && x) noexcept;
    scoped_thread& operator=(scoped_thread && x) noexcept;

    void swap(scoped_thread& x) noexcept;

    typedef thread::id id;

    id get_id() const noexcept;

    bool joinable() const noexcept;
    void join();
#ifdef BOOST_THREAD_USES_CHRONO
    template <class Rep, class Period>
    bool try_join_for(const chrono::duration<Rep, Period>& rel_time);
    template <class Clock, class Duration>
    bool try_join_until(const chrono::time_point<Clock, Duration>& t);
#endif

    void detach();

    static unsigned hardware_concurrency() noexcept;
    static unsigned physical_concurrency() noexcept;

    typedef thread::native_handle_type native_handle_type;
    native_handle_type native_handle();

#if defined BOOST_THREAD_PROVIDES_INTERRUPTIONS
    void interrupt();
    bool interruption_requested() const noexcept;
#endif


};

一种 RAII thread 封装, 附加一个特定的销毁器 (destroyer) , 允许掌控销毁时可以执行的操作.

CallableThread: 一个 void(thread&) 类型的可调用对象. 默认值为 join_if_joinable.

若线程处于 joinable 状态, thread 的析构函数会终止程序. 此封装可用于在销毁之前 join 线程.

备注: scoped_thread 不是 thread, 因为 thread 并未设计为可作为多态类型被派生.

无论如何, scoped_thread 可以用在 thread 可用的绝大多数场合, 因为除了构造之外, 它具有相同的非弃用接口.

示例 
boost::scoped_thread<> t((boost::thread(F)));
t.interrupt();

默认构造函数 

scoped_thread() noexcept;

效果:

构造一个封装 Not-a-Thread 的 scoped_thread 实例.

后置条件:

this->get_id()==thread::id()

抛出:

无

移动构造函数 

scoped_thread(scoped_thread&& other) noexcept;

效果:

将 other 所管理的 scoped_thread (若存在) 的所有权转移给新构造的 scoped_thread 实例.

后置条件:

other.get_id()==thread::id() 与 get_id() 返回 other.get_id() 在构造之前的值

抛出:

无

移动赋值运算符 

scoped_thread& operator=(scoped_thread&& other) noexcept;

效果:

将 other 所管理的 scoped_thread (若存在) 的所有权转移给 *this, 在此之前先调用 CallableThread()(t_).

后置条件:

other->get_id()==thread::id() 与 get_id() 返回 other.get_id() 在赋值之前的值.

抛出:

无: CallableThread()(t_) 在 join 线程时不应抛出异常, 因为该作用域变量位于线程函数之外的作用域中.

移动构造自 thread 

scoped_thread(thread&& t);

效果:

将 other 所管理的 thread (若存在) 的所有权转移给新构造的 scoped_thread 实例.

后置条件:

other.get_id()==thread::id(), 且 get_id() 返回构造之前 other.get_id() 的值.

抛出:

无
