我们将单位定义为一组基本单位, 其中每个基本单位都可以带有任意有理数指数. 因此, 对应于力量纲的 SI 单位是 kg m s^-2, 其中 kg、m 和 s 都是基本单位. 我们使用单位制 (如 SI) 的概念来指定从量纲到特定单位的映射, 这样就不必显式指定基本单位, 而只需请求某个量纲在特定单位制中的表示.

与量纲一样, 单位是纯粹的编译期变量, 没有关联的值. 单位遵循与量纲相同的代数; 单位制的存在确保了不同系统中具有相同约化量纲的单位 (如英尺和米) 不会在计算中被无意混用.

可以设想两种不同类型的单位制:

  • 同构单位制:保存一组线性无关的基本单位、可用于表示许多不同量纲的单位制. 例如, SI 单位制有七个基本量纲及与之对应的七个基本单位. 它可以表示仅使用这七个基本量纲的任何单位. 因此它是一个 homogeneous_system.
  • 异构单位制:存储所涉及的每个基本单位的指数的单位制称为异构单位制. 有些单位只能以这种方式表示. 例如, 以 m ft 表示的面积本质上是异构的, 因为米和英尺的基本单位具有相同的量纲. 因此, 仅存储一个量纲和一组基本单位并不能得到唯一解. 需要异构单位的一个实际例子是航空领域的一个经验公式: H = (r/C)^2, 其中 H 是以英尺计的雷达波束高度, r 是以海里计的雷达距离. 为了强制该公式的量纲正确性, 常量 C 必须表示为“海里每英尺^(1/2)”, 混合了两种不同的长度基本单位.

单位由unit 模板类实现, 该类定义于boost/units/unit.hpp :

template<class Dim,class System> class unit;

除了支持编译期量纲分析运算之外, 还为unit 变量提供了 +、-、* 和 / 运行期运算符. 由于与幂和方根相关联的量纲必须在编译期计算, 因此无法为std::pow 提供对unit 正确工作的重载. 这些运算通过自由函数pow 和root 支持, 它们以整数和static_rational 值为模板参数, 可接受任何已定义工具类power_typeof_helper 和root_typeof_helper 的类型作为参数.

基本单位

基本单位的定义方式与基本量纲非常相似.

template<class Derived, class Dimensions, long N> struct base_unit { ... };

同样, 负序数是保留的.

举例来说, 下面我们将基于上文给出的基本量纲实现 SI 单位制的一个子集, 演示构建一个功能完备的单位制所需的所有步骤. 首先, 我们简单地定义一个单位制, 其中包含常用单位的类型定义:

struct meter_base_unit : base_unit<meter_base_unit, length_dimension, 1> { };
struct kilogram_base_unit : base_unit<kilogram_base_unit, mass_dimension, 2> { };
struct second_base_unit : base_unit<second_base_unit, time_dimension, 3> { };

typedef make_system<
    meter_base_unit,
    kilogram_base_unit,
    second_base_unit>::type mks_system;

/// unit typedefs
typedef unit<dimensionless_type,mks_system>      dimensionless;

typedef unit<length_dimension,mks_system>        length;
typedef unit<mass_dimension,mks_system>          mass;
typedef unit<time_dimension,mks_system>          time;

typedef unit<area_dimension,mks_system>          area;
typedef unit<energy_dimension,mks_system>        energy;

宏BOOST_UNITS_STATIC_CONSTANT 由boost/units/static_constant.hpp 提供, 以便在头文件中进行 ODR 安全且线程安全的常量定义. 然后, 我们为受支持的单位定义一些常量, 以简化变量的定义:

/// unit constants 
BOOST_UNITS_STATIC_CONSTANT(meter,length);
BOOST_UNITS_STATIC_CONSTANT(meters,length);
BOOST_UNITS_STATIC_CONSTANT(kilogram,mass);
BOOST_UNITS_STATIC_CONSTANT(kilograms,mass);
BOOST_UNITS_STATIC_CONSTANT(second,time);
BOOST_UNITS_STATIC_CONSTANT(seconds,time);

BOOST_UNITS_STATIC_CONSTANT(square_meter,area);
BOOST_UNITS_STATIC_CONSTANT(square_meters,area);
BOOST_UNITS_STATIC_CONSTANT(joule,energy);
BOOST_UNITS_STATIC_CONSTANT(joules,energy);

如果需要支持单位的文本输出, 还可以为每个基本量纲标签特化base_unit_info 类:

template<> struct base_unit_info<test::meter_base_unit>
{
    static std::string name()               { return "meter"; }
    static std::string symbol()             { return "m"; }
};

kilogram_base_unit 和second_base_unit 也作类似处理. 该库的未来版本将提供更灵活的系统, 通过刻面/本地化 (facet/locale) 类机制支持国际化. name() 和symbol() 是base_unit_info 的两个方法, 分别提供基本单位的全称和简称. 有了这些定义, 我们就有了单位制的雏形, 可用于确定任意单位计算的约化量纲.

带缩放的基本单位

现在, 还可以把一个基本单位定义为另一个基本单位的倍数. 例如, 库实际上定义kilogram_base_unit 的方式大致如下

struct gram_base_unit : boost::units::base_unit<gram_base_unit, mass_dimension, 1> {};
typedef scaled_base_unit<gram_base_unit, scale<10, static_rational<3> > > kilogram_base_unit;

这基本上把千克定义为克的 10^3 倍.

这种方法有几个优点.

  • 相比把它们当作相互独立的单位, 这更好地反映了这些单位的真实含义.
  • 如果定义了克或千克与其他某些单位之间的转换, 只需一个特化, 它就会自动对千克和克都生效.
  • 类似地, 如果克的符号定义为“g”, 那么千克的符号无需任何额外工作就会是“kg”.

带缩放的单位

我们也可以把unit 作为一个整体进行缩放, 而不是缩放组成它的各个基本单位. 为此, 我们使用元函数make_scaled_unit. 该特性的主要动机是boost/units/systems/si/prefixes.hpp 中定义的米制前缀.

它的用法示例很简单.

typedef make_scaled_unit<si::time, scale<10, static_rational<-9> > >::type nanosecond;

nanosecond 是unit 的一个特化, 可以在量中正常使用.

quantity<nanosecond> t(1.0 * si::seconds);
std::cout << t << std::endl;    // prints 1e9 ns
