快速入门

在讨论本库的基础内容之前, 我们先定义几个下文中将频繁使用的术语:

  • 基本量纲:基本量纲宽泛地定义为所关心的可测量实体; 在传统量纲分析中, 基本量纲包括长度 ([L])、质量 ([M])、时间 ([T]) 等, 但对可以使用哪些基本量纲并没有具体限制. 基本量纲本质上是一种标签类型, 其本身不提供任何量纲分析功能.
  • 量纲:零个或多个基本量纲的集合, 每个基本量纲可以带有不同的有理数次幂. 例如, 长度 = [L]^1、面积 = [L]^2、速度 = [L]^1/[T]^1 以及能量 = [M]^1 [L]^2/[T]^2 都是量纲.
  • 基本单位:基本单位表示某一量纲的一种具体度量. 例如, 长度是距离的抽象度量, 而米是距离的一个具体基本单位. 转换通过基本单位来定义. 与基本量纲非常相似, 基本单位也是一种标签类型, 仅用于定义单位, 不支持量纲分析代数.
  • 单位:带有理数指数的一组基本单位, 例如 m^1、kg^1、m^1/s^2.
  • 单位制:单位制是表示某一特定问题所关心的全部可测量实体的基本单位的集合. 例如, SI 单位制定义了七个基本单位:长度 ([L]) 以米计、质量 ([M]) 以千克计、时间 ([T]) 以秒计、电流 ([I]) 以安培计、温度 ([theta]) 以开尔文计、物质的量 ([N]) 以摩尔计, 以及发光强度 ([J]) 以坎德拉计. SI 系统内所有可测量的实体都可以表示为这七个基本单位的整数幂或有理数次幂的乘积.
  • 量:量表示一个单位的具体数量. 因此, 米是 SI 系统中长度的基本单位, 而 5.5 米则是该系统中的一个长度量.

首先我们给出两个简短的教程. Tutorial1 演示SI 单位的使用. 在包含相应的系统头文件以及我们将要用到的各种 SI 单位的头文件 (所有 SI 单位可用boost/units/systems/si.hpp 一次包含) 和量 I/O 的头文件 (boost/units/io.hpp) 之后, 我们定义一个函数, 计算以牛顿为单位施加的力在以米为单位的指定距离上所做的功 (以焦耳为单位) , 并将结果输出到std::cout. quantity 类接受第二个模板参数作为其值类型; 若未另行指定, 该参数默认为double. 为了展示在量纲计算中使用用户自定义类型的便捷性, 我们还给出了使用std::complex<double> 作为值类型计算复阻抗的代码:

#include <complex>
#include <iostream>

#include <boost/typeof/std/complex.hpp>

#include <boost/units/systems/si/energy.hpp>
#include <boost/units/systems/si/force.hpp>
#include <boost/units/systems/si/length.hpp>
#include <boost/units/systems/si/electric_potential.hpp>
#include <boost/units/systems/si/current.hpp>
#include <boost/units/systems/si/resistance.hpp>
#include <boost/units/systems/si/io.hpp>

using namespace boost::units;
using namespace boost::units::si;

constexpr
quantity<energy>
work(const quantity<force>& F, const quantity<length>& dx)
{
    return F * dx; // Defines the relation: work = force * distance.
}

int main()
{
    /// Test calculation of work.
    quantity<force>     F(2.0 * newton); // Define a quantity of force.
    quantity<length>    dx(2.0 * meter); // and a distance,
    quantity<energy>    E(work(F,dx));  // and calculate the work done.

    std::cout << "F  = " << F << std::endl
              << "dx = " << dx << std::endl
              << "E  = " << E << std::endl
              << std::endl;

    /// Test and check complex quantities.
    typedef std::complex<double> complex_type; // double real and imaginary parts.

    // Define some complex electrical quantities.
    quantity<electric_potential, complex_type> v = complex_type(12.5, 0.0) * volts;
    quantity<current, complex_type>            i = complex_type(3.0, 4.0) * amperes;
    quantity<resistance, complex_type>         z = complex_type(1.5, -2.0) * ohms;

    std::cout << "V   = " << v << std::endl
              << "I   = " << i << std::endl
              << "Z   = " << z << std::endl
              // Calculate from Ohm's law voltage = current * resistance.
              << "I * Z = " << i * z << std::endl
              // Check defined V is equal to calculated.
              << "I * Z == V? " << std::boolalpha << (i * z == v) << std::endl
              << std::endl;
    return 0;
}

上述代码的意图和功能应当显而易见; 其输出为:

F  = 2 N
dx = 2 m
E  = 4 J

V   = (12.5,0) V
I   = (3,4) A
Z   = (1.5,-2) Ohm
I*Z = (12.5,0) V
I*Z == V? true

虽然本库力图让简单的量纲计算易于编码, 但它绝不与任何特定单位制 (SI 或其他) 绑定. 相反, 它提供了一个高度灵活的编译期量纲分析系统, 支持任意的基本量纲集合、单位的有理数次幂以及显式的量转换. 这一切都通过模板元编程技术实现. 借助现代优化编译器, 与没有单位检查的相同代码相比, 量计算不会产生任何运行期开销.
