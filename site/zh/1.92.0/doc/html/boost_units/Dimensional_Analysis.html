量纲分析

量纲分析的概念通常在物理和工程类入门课程的早期讲授, 其方法是让各种量的物理测量单位连同其数值一起参与方程的推导, 以此判断方程或计算的正确性. 常用的标准单位制有若干种, 其中最突出的是国际单位制 (也称为 SI 或 MKS (米-千克-秒) , MKS 是 SI 系统的公制前身, 其名称源于该系统所依据的三个基本单位) . SI 是唯一的官方国际标准单位制, 在科学和工程中被广泛使用. 其他常见单位制包括CGS (厘米-克-秒) 单位制, 以及在美国和其他地方某些问题领域仍在使用的英制单位制. 在物理学中, 还存在若干在专门分支学科中常用的其他单位制, 它们统称为自然单位制. 当表示不同可测量量的量相互组合时, 量纲分析提供了评估所得计算一致性的手段. 例如, 两个长度之和仍是长度, 而两个长度之积是面积, 长度与面积之和则没有定义. 许多函数 (如 exp、log 等) 的参数必须是无量纲量, 这一点通过在量纲分析的框架下考察它们的级数展开即可轻易证明. 本库便于在涉及带量纲的量的代码中酌情强制执行这类限制.

在下面的讨论中, 我们将量纲分析视为一种抽象, 其中任意一组单位遵循特定代数的规则. 我们将基本量纲与有理指数的配对称为基本量纲, 将由任意多个基本量纲组成的列表称为复合量纲, 或简称量纲. 特别地, 给定一组基本量纲, 记作, 以及一组有理指数, 任何可能的 (复合) 量纲都可写为.

量纲分析库的用户应当能够指定任意的基本量纲列表以构造复合量纲, 其中可能包含重复的标签. 例如, 能量应当既可以表示为、或, 也可以表示为质量、长度、时间的聚合指数分别为 1、2 和 -2 的任何其他排列. 为了能够对任意的量纲集合进行计算, 所有复合量纲都必须能约化为一个无歧义的最终复合量纲, 我们将其称为约化量纲, 它满足:

  1. 基本量纲按一致的方式排序
  2. 指数为零的量纲被省略. 注意, 约化量纲所含基本量纲数不会超过 (每个不同的基本量纲对应一个) , 但可能更少.

在我们的实现中, 基本量纲与标签类型相关联. 由于我们最终会将复合量纲表示为类型列表 (typelist) , 因此必须提供某种机制来对基本量纲标签排序, 以便能够把任意复合量纲转换为约化量纲. 为此, 我们为每个基本量纲分配一个唯一的整数. base_dimension 类 (见boost/units/base_dimension.hpp) 采用奇异递归模板模式 (CRTP) 技术, 以确保为基本量纲指定的序数是唯一的:

template<class Derived, long N> struct base_dimension { ... };

由此, 我们可以如下定义长度、质量和时间的基本量纲:

/// base dimension of length
struct length_base_dimension : base_dimension<length_base_dimension,1> { };
/// base dimension of mass
struct mass_base_dimension : base_dimension<mass_base_dimension,2> { };
/// base dimension of time
struct time_base_dimension : base_dimension<time_base_dimension,3> { };

需要特别注意的是, 只要每个标签具有唯一且可枚举的值, 顺序的选择就完全是任意的; 非唯一的序数将在编译期被标记为错误. 负序数保留供库使用. 为了定义与这些基本量纲相对应的复合量纲, 我们只需使用dim 类封装基本量纲与static_rational 指数的配对, 构造出符合 MPL 规范的基本量纲类型列表. make_dimension_list 类则充当包装器, 确保结果类型符合约化量纲的形式:

typedef make_dimension_list<
    boost::mpl::list< dim< length_base_dimension,static_rational<1> > >
>::type   length_dimension;

typedef make_dimension_list<
    boost::mpl::list< dim< mass_base_dimension,static_rational<1> > >
>::type     mass_dimension;

typedef make_dimension_list<
    boost::mpl::list< dim< time_base_dimension,static_rational<1> > >
>::type     time_dimension;

使用base_dimension 提供的便捷 typedef 也可以轻松做到这一点:

typedef length_base_dimension::dimension_type    length_dimension;
typedef mass_base_dimension::dimension_type      mass_dimension;
typedef time_base_dimension::dimension_type      time_dimension;

这样, 上面的代码就与完整的类型列表定义完全等价. 复合量纲同样通过类型列表来定义:

typedef make_dimension_list<
    boost::mpl::list< dim< length_base_dimension,static_rational<2> > >
>::type   area_dimension;

typedef make_dimension_list<
    boost::mpl::list< dim< mass_base_dimension,static_rational<1> >,
                      dim< length_base_dimension,static_rational<2> >,
                      dim< time_base_dimension,static_rational<-2> > >
>::type    energy_dimension;

库还为整数幂的复合量纲提供了一个便捷类:

typedef derived_dimension<length_base_dimension,2>::type  area_dimension;
typedef derived_dimension<mass_base_dimension,1,
                          length_base_dimension,2,
                          time_base_dimension,-2>::type   energy_dimension;
