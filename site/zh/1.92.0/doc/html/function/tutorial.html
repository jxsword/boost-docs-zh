Boost.Function 有两种语法形式: 首选形式和可移植形式. 首选形式更贴近 C++ 语言, 并减少了需要考虑的独立模板参数数量, 通常还能提高可读性; 然而, 由于编译器缺陷, 并非所有平台都支持首选形式. 兼容形式在 Boost.Function 支持的所有编译器上都能工作. 请查阅下表以确定你的编译器应使用哪种语法形式.

首选语法 可移植语法
  • GNU C++ 2.95.x、3.0.x 及更高版本
  • Comeau C++ 4.2.45.2
  • SGI MIPSpro 7.3.0
  • Intel C++ 5.0、6.0
  • Compaq 的 cxx 6.2
  • Microsoft Visual C++ 7.1 及更高版本
  • 任何支持首选语法的编译器
  • Microsoft Visual C++ 6.0、7.0
  • Borland C++ 5.5.1
  • Sun WorkShop 6 update 2 C++ 5.3
  • Metrowerks CodeWarrior 8.1

如果你的编译器未出现在此列表中, 请尝试首选语法并把结果报告到 Boost 邮件列表, 以便我们保持该表的最新状态.

基本用法

函数包装器的定义只需用期望的返回类型和参数类型 (表述为一个 C++ 函数类型) 来实例化 function 类模板. 可以提供任意数量的参数, 直至某个由实现定义的上限 (默认最大值为 10). 以下声明了一个函数对象包装器 f, 它接受两个 int 参数并返回一个 float:

首选语法 可移植语法 
boost::function<float (int x, int y)> f;
 
boost::function2<float, int, int> f;

默认情况下, 函数对象包装器是空的, 因此我们可以创建一个函数对象来赋给 f:

struct int_div { 
  float operator()(int x, int y) const { return ((float)x)/y; }; 
};

f = int_div();

现在我们可以使用 f 来执行底层函数对象 int_div:

std::cout << f(5, 3) << std::endl;

我们可以随意把任何兼容的函数对象赋给 f. 如果 int_div 被声明为接受两个 long 操作数, 隐式转换会自动应用于实参, 无需用户干预. 对参数类型的唯一限制是它们必须可拷贝构造 (CopyConstructible), 因此我们甚至可以使用引用和数组:

首选语法
 
boost::function<void (int values[], int n, int& sum, float& avg)> sum_avg;

可移植语法
 
boost::function4<void, int*, int, int&, float&> sum_avg;
 

void do_sum_avg(int values[], int n, int& sum, float& avg)
{
  sum = 0;
  for (int i = 0; i < n; i++)
    sum += values[i];
  avg = (float)sum / n;
}

sum_avg = &do_sum_avg;

调用一个实际并未包含函数对象的函数对象包装器是对前置条件的违反, 就像试图通过空函数指针进行调用一样, 会抛出 bad_function_call 异常). 我们可以在布尔上下文中使用它来检查函数对象包装器是否为空 (如果包装器非空, 其求值为 true), 或者将它与 0 比较. 例如:

if (f)
  std::cout << f(5, 3) << std::endl;
else
  std::cout << "f has no target, so it is unsafe to call" << std::endl;

或者, empty() 方法将返回包装器是否为空.

最后, 我们可以通过把它赋值为 0 或调用 clear() 成员函数来清除函数目标, 例如:

f = 0;

自由函数

自由函数指针可以被视为带有 const 函数调用运算符的单例函数对象, 因此可以直接与函数对象包装器一起使用:

float mul_ints(int x, int y) { return ((float)x) * y; }

f = &mul_ints;

注意, & 其实并非必需, 除非你恰好在使用 Microsoft Visual C++ 6.0 版.

成员函数

在许多系统中, 回调常常会调用特定对象的成员函数. 这通常被称为 "参数绑定", 超出了 Boost.Function 的范围. 不过, 直接使用成员函数是受支持的, 因此以下代码是有效的:

struct X {
  int foo(int);
};

首选语法 可移植语法 
boost::function<int (X*, int)> f;

f = &X::foo;
  
X x;
f(&x, 5);
 
boost::function2<int, X*, int> f;

f = &X::foo;
  
X x;
f(&x, 5);

有一些支持参数绑定的库. 下面概述了三个这样的库:

  • Bind. 该库允许为任何函数对象绑定参数. 它轻量且非常可移植.

  • C++ 标准库. 结合使用 std::bind1st 和 std::mem_fun, 可以绑定成员函数指针的对象以配合 Boost.Function 使用:

    首选语法 可移植语法 
      boost::function<int (int)> f;
X x;
f = std::bind1st(
      std::mem_fun(&X::foo), &x);
f(5); // Call x.foo(5)
    		 
      boost::function1<int, int> f;
X x;
f = std::bind1st(
      std::mem_fun(&X::foo), &x);
f(5); // Call x.foo(5)

  • Lambda 库. 该库提供了强大的组合机制, 可用非常自然的 C++ 语法构造函数对象. Lambda 要求编译器对 C++ 标准有较好的符合度.

函数对象的引用

在某些情况下, 让 Boost.Function 克隆函数对象代价高昂 (或在语义上不正确). 在这些情况下, 可以要求 Boost.Function 只保留对实际函数对象的引用. 这可以通过 ref 和 cref 函数来包装对函数对象的引用实现:

首选语法 可移植语法 
stateful_type a_function_object;
boost::function<int (int)> f;
f = boost::ref(a_function_object);

boost::function<int (int)> f2(f);
 
stateful_type a_function_object;
boost::function1<int, int> f;
f = boost::ref(a_function_object);

boost::function1<int, int> f2(f);

在这里, f 不会复制 a_function_object, 当 f2 以 f 对 a_function_object 的引用为目标时也不会复制. 此外, 在使用函数对象引用时, Boost.Function 在赋值或构造期间不会抛出异常.

比较 Boost.Function 函数对象

函数对象包装器可以通过 == 或 != 与任何可存储在包装器中的函数对象进行比较. 如果函数对象包装器包含该类型的函数对象, 则会将其与给定的函数对象进行比较 (该函数对象必须满足 EqualityComparable 或重载了 boost::function_equal). 例如:

int compute_with_X(X*, int);

f = &X::foo;
assert(f == &X::foo);
assert(&compute_with_X != f);

当与 reference_wrapper 的实例比较时, 是将 reference_wrapper 中对象的地址与函数对象包装器所存储对象的地址进行比较:

a_stateful_object so1, so2;
f = boost::ref(so1);
assert(f == boost::ref(so1));
assert(f == so1); // Only if a_stateful_object is EqualityComparable
assert(f != boost::ref(so2));
