历史与兼容性说明

  • 1.52.0 版:

    • 新增移动构造函数与移动赋值运算符 (仅适用于支持 C++11 右值引用的编译器). 原始补丁由 Antony Polukhin 贡献.

  • 1.37.0 版:

    • 改进了 Boost.Function 的 swap() 操作对大型函数对象的性能. 原始补丁由 Niels Dekker 贡献.

    • 新增头文件 <boost/function/function_typeof.hpp>, 为在 Boost.Function 对象上使用 Boost.Typeof 库提供支持.

    • 新增头文件 <boost/function/function_fwd.hpp>, 为在 Boost.Function 对象上使用 Boost.Typeof 库提供支持.

    • target() 函数现在会尊重以引用方式存储 (使用 boost::reference_wrapper) 的函数对象的 cv 限定符, 使得指向 const 函数对象的引用不能被当作指向非 const 函数对象的引用来访问.

  • 1.36.0 版:

    • Boost.Function 现在按照 C++ 委员会提案 N2308, 以与 C++0x 中相同的方式实现了分配器支持. 这一变更移除了 Allocator 模板参数 (原先存在于 boost::function 中), 改为接受一个实参的构造函数. 虽然这是一个向后不兼容的变更, 但它可能只影响少数用户. 对 Function 的这一变更由 Emil Dotchevski 贡献, 他也是相应 C++ 委员会提案的作者.

  • 1.34.0 版:

    • Boost.Function 现在实现了小缓冲区优化, 在拷贝或构造存储小型函数对象的 Boost.Function 对象时可显著提升性能. 例如, bind(&X:foo, &x, _1, _2) 被放入 Boost.Function 对象时不需要堆分配. 注意, 一些异常安全性保证有所改变: 赋值提供基本异常保证, 而 swap() 可能抛出异常.

  • 1.30.0 版:

    • 1.29.0 版中弃用的所有特性都已从 Boost.Function 中移除.

    • boost::function 和 boost::functionN 对象可以被赋值为 0 (语义上等价于调用 clear()), 也可以与 0 比较 (语义上等价于调用 empty()).

    • Boost.Function 代码现在完全由 Preprocessor 库生成, 因此现在可以为任意数量的参数生成 boost::function 和 boost::functionN 类模板.

    • 引入了 boost::bad_function_call 异常类.

  • 1.29.0 版: Boost.Function 进行了部分重新设计, 以最小化接口并使其更简洁. 旧版 Boost.Function 中一些很少使用或从未使用的特性已被弃用, 并将在不久的将来移除. 以下是被弃用特性的列表、弃用可能造成的影响, 以及如何调整你的代码:

    • boost::function 类模板的语法已经改变. 旧语法 (例如 boost::function<int, float, double, std::string>) 已改为更自然的语法 boost::function<int (float, double, std::string)>, 其中所有返回类型和参数类型都编码在单个函数类型参数中. 其他任何模板参数 (例如 Allocator) 都跟在这个单一参数之后.

      针对这一变更的解决方法取决于编译器的能力: 如果你的编译器支持模板偏特化并能解析函数类型 (大多数都可以), 请修改代码以使用新语法 (推荐), 或者直接使用语法未变的 functionN 类之一. 如果你的编译器不支持模板偏特化或函数类型, 则必须采用后一种方案, 使用带编号的 Boost.Function 类. 该方案只需把 boost::function<void, int, int> 这类类型改为 boost::function2<void, int, int> (在类名末尾加上函数参数的数量).

      对带 boost::function 类模板旧语法的支持还会保留一段时间, 但最终将被移除, 以便我们能够提供更好的错误消息和链接兼容性.

    • 调用策略模板参数 (Policy) 已被弃用并将被移除. 这个很少使用的特性没有直接的等价物.

    • mixin 模板参数 (Mixin) 已被弃用并将被移除. 这个很少使用的特性没有直接的等价物.

    • set 方法已被弃用并将被移除. 请改用赋值运算符.
