什么是 BOOST_FOREACH?

在 C++ 中, 编写一个遍历序列的循环非常繁琐. 我们要么使用迭代器 (这需要相当数量的样板代码), 要么使用 std::for_each() 算法并把循环体移入一个谓词 (这需要的样板代码不比前者少, 还迫使我们把逻辑搬离其使用之处). 相比之下, 一些其他语言 (如 Perl) 提供专门的 "foreach" 构造来自动完成这一过程. BOOST_FOREACH 就是 C++ 的这样一种构造. 它为我们遍历序列, 使我们免于直接处理迭代器或编写谓词.

BOOST_FOREACH 的设计目标是易用和高效. 它不做任何动态分配, 不进行虚函数调用或通过函数指针的调用, 也不进行任何对编译器优化器不透明的调用. 这带来了近乎最优的代码生成; BOOST_FOREACH 的性能通常与等价的手写循环相差不到几个百分点. 而且虽然 BOOST_FOREACH 是一个宏, 但它表现得非常好: 它对参数只求值一次, 不会带来令人讨厌的意外.

Hello, world!

下面是一个示例程序, 它使用 BOOST_FOREACH 遍历 std::string 的内容.

#include <string>
#include <iostream>
#include <boost/foreach.hpp>

int main()
{
    std::string hello( "Hello, world!" );

    BOOST_FOREACH( char ch, hello )
    {
        std::cout << ch;
    }

    return 0;
}

这个程序输出如下:

Hello, world!

支持的序列类型

BOOST_FOREACH 遍历序列. 但究竟什么才算序列? 由于 BOOST_FOREACH 构建在 Boost.Range 之上, 它自动支持 Boost.Range 认可的序列类型. 具体来说, BOOST_FOREACH 可用于满足 Single Pass Range Concept 的类型. 例如, 我们可以把 BOOST_FOREACH 用于:

  • STL 容器
  • 数组
  • 以空字符结尾的字符串 (char 和 wchar_t)
  • 迭代器的 std::pair
注释

对 STL 容器的支持非常宽泛; 任何看起来像 STL 容器的东西都算数. 如果它有嵌套的 iterator 和 const_iterator 类型, 以及 begin() 和 end() 成员函数, BOOST_FOREACH 就会自动知道如何遍历它. boost::iterator_range<> 和 boost::sub_range<> 正是这样与 BOOST_FOREACH 协同工作的.

请参阅 可扩展性 一节, 了解如何让 BOOST_FOREACH 用于其他类型.

示例

下面的一些示例展示了我们可以使用 BOOST_FOREACH 的各种不同方式.

遍历 STL 容器:

std::list<int> list_int( /*...*/ );
BOOST_FOREACH( int i, list_int )
{
    // do something with i
}

遍历数组, 并带协变性 (即循环变量的类型与容器的元素类型不完全相同):

short array_short[] = {1,2,3};
BOOST_FOREACH( int i, array_short )
{
    // The short was implicitly converted to an int
}

预先声明循环变量, 并在循环体中使用 break、continue 和 return:

std::deque<int> deque_int( /*...*/ );
int i = 0;
BOOST_FOREACH( i, deque_int )
{
    if( i == 0 ) return;
    if( i == 1 ) continue;
    if( i == 2 ) break;
}

以引用方式遍历序列, 并修改底层序列:

short array_short[] = { 1, 2, 3 };
BOOST_FOREACH( short & i, array_short )
{
    ++i;
}
// array_short contains {2,3,4} here

用嵌套的 BOOST_FOREACH 循环遍历向量的向量. 在此示例中, 请注意循环体外围的花括号并非必需:

std::vector<std::vector<int> > matrix_int;
BOOST_FOREACH( std::vector<int> & row, matrix_int )
    BOOST_FOREACH( int & i, row )
        ++i;

遍历按值返回序列的表达式 (即右值):

extern std::vector<float> get_vector_float();
BOOST_FOREACH( float f, get_vector_float() )
{
    // Note: get_vector_float() will be called exactly once
}

反向遍历:

std::list<int> list_int( /*...*/ );
BOOST_REVERSE_FOREACH( int i, list_int )
{
    // do something with i
}

在某些较旧的编译器上, 遍历右值不起作用. 请查看 可移植性 一节, 确认你的编译器是否支持此功能.

让 BOOST_FOREACH 更美观

有人抱怨 BOOST_FOREACH 这个名字太长. ALL CAPS 看起来确实容易让人厌倦. 这也许是真的, 但 BOOST_FOREACH 只是遵循 Boost 命名约定 而已. 不过这并不意味着你只能用它. 如果你想使用别的标识符 (比如 foreach_), 可以简单地这样做:

#define foreach_         BOOST_FOREACH
#define foreach_r_       BOOST_REVERSE_FOREACH

仅当你确定所选标识符不会在代码中造成命名冲突时才这样做.

注释

不要使用 #define foreach_(x,y) BOOST_FOREACH(x,y). 如果实参本身是宏, 这可能出问题, 会导致这些宏被额外展开一次. 请改用上面所示的形式.

最后提醒一句. 很多人使用 foreach 宏作为 BOOST_FOREACH 的简写形式. 我不鼓励这样做. 它会在 BOOST_FOREACH 宏自身内部引起命名冲突, 因为 foreach 是一个命名空间的名字. 此外, foreach 是一个相当常见的标识符; 连 Qt 都把它定义为宏. 如果你坚持使用 foreach, 可以尝试类似这样的做法:

#include <boost/foreach.hpp>

namespace boost
{
    // Suggested work-around for https://svn.boost.org/trac/boost/ticket/6131
    namespace BOOST_FOREACH = foreach;
}

#define foreach   BOOST_FOREACH

这能规避你可能遇到的 部分 问题, 但不是全部. 建议改用别的标识符.
