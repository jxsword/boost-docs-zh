引言

一个环形缓冲区.

说明

circular buffer (环形缓冲区, 也称为 ring 或 cyclic buffer) 一词指内存中用于存储传入数据的一块区域. 当缓冲区填满时, 新数据从缓冲区开头写入并覆盖旧数据.

boost::circular_buffer 是一个符合 STL 标准的容器.

它是一种类似于 std::list 或 std::deque 的序列. 它支持随机访问迭代器、在缓冲区开头或结尾的常量时间插入和擦除操作, 以及与 std 算法的互操作性.

circular_buffer 专门设计用于提供 固定容量 的存储. 当其容量耗尽时, 新插入的元素将导致元素被覆盖, 覆盖位置在缓冲区的开头或结尾 (取决于所使用的插入操作).

circular_buffer 只在创建时、显式调整容量时, 或者为适应改变大小 (resize) 或赋值 (assign) 操作而必要时才分配内存.

还有一个 circular_buffer_space_optimized 版本可用.

circular_buffer_space_optimized 是 circular_buffer 的一种变体, 它 在创建时不会一次性分配全部内存, 而是按需分配内存.

预测性内存分配与典型的 std::vector 实现类似. 当容器大小减小时, 内存会被自动释放.

空间优化版环形缓冲区的内存分配过程. 容量控制器的 min_capacity 表示已分配内存的最小保证量. 已分配内存绝不会低于此值. min_capacity 的默认值设为 0. min_capacity 可以通过构造函数参数 () capacity_control 或函数 set_capacity 来设置.

当然, 空间优化版本会稍慢一些.
