说明

Proto 是一个用于在 C++ 中构建嵌入式领域特定语言的框架. 它提供了构造、类型检查、转换和执行 表达式模板[27] 的工具. 更具体地说, Proto 提供:

  • 一个表达式树数据结构.
  • 一种为表达式附加额外行为和成员的机制.
  • 用于从表达式构建树的运算符重载.
  • 用于定义表达式必须符合的文法的实用工具.
  • 一种可扩展的、立即执行表达式模板的机制.
  • 一组可扩展的树变换, 可应用于表达式树.

动机

表达式模板是 C++ 库开发者用来定义面向特定问题领域的嵌入式迷你语言的一种高级技术. 该技术已被用于创建高效且易用的线性代数库, 以及用可读的语法定义 C++ 解析器生成器. 但开发这样的库需要编写大量不可读且难以维护的模板咒语. Boost.Proto 简化了 领域特定的嵌入式语言 (EDSL) 的开发. 使用 Proto 定义你的迷你语言的原语, 让 Proto 处理运算符重载和表达式解析树的构造. 通过向表达式树传入函数对象来立即对其求值. 或者通过定义你的迷你语言的文法 (辅以 Proto 提供或由你定义的各种树变换) 来变换表达式树. 然后使用该文法, 为无效表达式向用户给出简短而可读的语法错误提示! 不再有咒语 -- 用 Proto 开发的表达式模板库是声明式的且可读的.

简言之, Proto 是一个用于定义 EDSL 的 EDSL.

如何使用本文档

本文档使用以下命名与格式约定.

  • 代码使用 fixed width font 呈现, 并带语法高亮显示.
  • 需要由你提供的可替换文本放在 italics 中.
  • 如果名称指代自由函数, 则像这样给出: free_function(); 也就是说, 它以代码字体呈现, 并且其名称后跟 () 以表明它是自由函数.
  • 如果名称指代类模板, 其写法如下: class_template<>; 也就是说, 它以代码字体呈现, 且名称后跟 <> 以表明它是类模板.
  • 如果名称指代函数式宏, 其写法如下: MACRO(); 也就是说, 它以代码字体的大写形式呈现, 且名称后跟 () 以表明它是函数式宏. 对象式宏则不带结尾的 ().
  • 泛型编程意义上的 概念 名称以 CamelCase 形式给出.
