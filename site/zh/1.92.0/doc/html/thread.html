概述

Boost.Thread 让可移植的 C++ 代码能够使用多个共享数据的执行线程. 它提供用于管理线程本身的类和函数, 还提供用于在线程之间同步数据或为各个线程提供数据独立副本的其他设施.

Boost.Thread 库最初由 William E. Kempf 编写和设计 (第 1 版).

Anthony Williams 版本 (第 2 版) 是一次重大重写, 力求紧贴提交给 C++ 标准委员会的各项提案, 尤其是 N2497, N2320, N2184, N2139 与 N2094

Vicente J. Botet Escriba 从第 3 版开始进行适配, 以符合已获接受的 C++11 Thread 库 (使用 Boost.Chrono 与 Boost.Move) 以及 Howard Hinnant 的 Shared Locking 提案 (向上转换除外). 另外还加入了一些次要的非标准特性, 如线程属性、reverse_lock、shared_lock_guard.

要使用这里描述的类和函数, 可以包含每个类或函数说明中指定的具体头文件, 也可以包含线程库的主头文件:

#include <boost/thread.hpp>

该头文件会依次包含所有其他头文件.
