引言

Boost.Units 库以通用且可扩展的方式实现量纲分析的 C++ 方案, 把它当作一个泛型编译期元编程问题来处理. 在适当的编译器优化下, 它不会引入任何运行期开销, 因而在性能关键代码中也可以使用本库进行量纲检查. 本库为任意单位系统模型和任意值类型提供单位与量 (定义为单位及其关联值) 的支持, 并提供细粒度的通用单位转换设施. 库中提供完整的 SI 和 CGS 单位系统, 以及以度、弧度、梯度和转为单位的角度系统, 和以开尔文、摄氏度和华氏度为单位的温度系统. 库的架构设计充分考虑了灵活性与可扩展性; 示例部分展示了添加新单位和新单位转换的简便性.

为了实现没有运行期开销的复杂编译期量纲分析计算, Boost.Units 大量依赖 Boost 元编程库 (MPL) 和模板元编程技术, 因此对编译器遵循 ISO 标准的程度要求相当高. 目前, 它已在以下编译器/平台上成功编译并通过测试:

  1. Mac OSX 10.4 上的 g++ 4.0.1
  2. Mac OSX 10.4 上的 Intel CC 9.1、10.0 和 10.1
  3. Windows XP 上的 g++ 3.4.4、4.2.3 和 4.3.0
  4. Windows XP 上的 Microsoft Visual C++ 7.1、8.0 和 9.0
  5. Windows XP 上的 Comeau 4.3.10.1 beta2
  6. Windows XP 上的 Metrowerks CodeWarrior 9.2.
  7. Solaris 和 Linux 上的 Sun CC 5.9

以下编译器/平台已知 不能 工作:

  1. g++ 3.3.x
  2. Windows XP 上的 Microsoft Visual C++ 6.0
  3. Windows XP 上的 Microsoft Visual C++ 7.0
  4. Windows XP 上的 Metrowerks CodeWarrior 8.0.
  5. Borland 的所有版本.
