基本用法

tribool 类的行为类似于内置的 bool 类型, 但用于三态布尔逻辑. 三种状态分别是 true、false 以及 indeterminate, 其中前两种状态等价于 C++ bool 类型的状态, 最后一种状态表示未知的布尔值 (可能是 true 或 false, 我们不知道).

tribool 类支持从 bool 值与字面量进行的转换, 并支持它自己的 indeterminate 关键字:

tribool b(true);
b = false;
b = indeterminate;
tribool b2(b);

tribool 支持到 bool 的转换以便在条件语句中使用. 到 bool 的转换将为 true, 当 tribool 的值恒为真时; 否则为 false. 因此, 下面的惯用法可用于确定 tribool 当前处于三种状态中的哪一种:

tribool b = some_operation();
if (b) {
  // b is true
}
else if (!b) {
  // b is false
}
else {
  // b is indeterminate
}

tribool 支持三态逻辑运算符 ! (取反)、&& (AND) 与 || (OR), 可作用于 bool 与 tribool 值. 例如:

tribool x = some_op();
tribool y = some_other_op();
if (x && y) {
  // both x and y are true
}
else if (!(x && y)) {
  // either x or y is false
}
else {
  // neither x nor y is false, but we don't know that both are true

  if (x || y) {
    // either x or y is true
  }
}

类似地, tribool 通过运算符 == 与 != 支持三态相等比较. 这些运算符与 C++ 的“常规”相等运算符不同, 因为它们返回 tribool——因为我们可能并不知道比较的结果 (试着比较 true 与 indeterminate). 例如:

tribool x(true);
tribool y(indeterminate);

assert(x == x); // okay, x == x returns true
assert(x == true); // okay, can compare tribools and bools

indeterminate 关键字 (表示 indeterminate tribool 值) 兼作检查 tribool 的值是否为不确定状态的函数, 例如:

tribool x = try_to_do_something_tricky();
if (indeterminate(x)) {
  // value of x is indeterminate
}
else {
  // report success or failure of x
}

tribool 的所有逻辑运算符与方法在 C++11 中都标记为 constexpr. 这意味着 tribool 可以在编译期表达式中使用:

constexpr tribool x = (tribool(true) || tribool(indeterminate));
static_assert(x, "Must be true!");
注释
某些编译器在编译期求值 tribool::operator safe_bool() 时可能会有问题.

重命名不确定状态

除了实现提供的 indeterminate 之外, 用户可以使用 BOOST_TRIBOOL_THIRD_STATE 宏为不确定值引入额外的关键字. 例如, 下面的宏实例化 (在全局作用域) 将引入关键字 maybe 作为 indeterminate 的同义词 (同样位于 boost 命名空间中):

BOOST_TRIBOOL_THIRD_STATE(maybe)
tribool x = maybe;
if (maybe(x)) { /* ... */ }

tribool 输入/输出

tribool 对象可以通过包含 boost/logic/tribool_io.hpp 头文件从流中读取和写入, 方式与 bool 值非常相似. 当 boolalpha 标志未在输入/输出流上设置时, 整数值 0、1、2 分别对应 tribool 值 false、true 与 indeterminate. 当流上设置了 boolalpha 时, 可以用任意字符串表示这三个值, 默认为 "false"、"true" 与 "indeterminate". 例如:

tribool x;
cin >> x; // Type "0", "1", or "2" to get false, true, or indeterminate
cout << boolalpha << x; // Produces "false", "true", or "indeterminate"

tribool 的输入与输出对流当前的区域设置敏感. 与 false 和 true 值关联的字符串包含在标准 std::numpunct 刻面 (facet) 中, 而命名不确定类型的字符串包含在 indeterminate_name 刻面中. 要替换不确定状态的名称, 你需要为流 imbue 一个包含 indeterminate_name 刻面的本地环境, 例如:

BOOST_TRIBOOL_THIRD_STATE(maybe)
locale global;
locale test_locale(global, new indeterminate_name<char>("maybe"));
cout.imbue(test_locale);
tribool x(maybe);
cout << boolalpha << x << endl; // Prints "maybe"

如果你的 C++ 标准库实现不支持本地环境, tribool 输入/输出仍然可以工作, 但当 boolalpha 被设置时, 你将无法自定义打印/解析的字符串.
