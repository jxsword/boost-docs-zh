变更

  • boost 1.91.0 :
    • 新增 C++20 模块支持.
  • boost 1.86.0 :
    • 修复了 std::basic_string_view 和 boost::basic_string_view 中包含一个或多个 \0 字符时的转换问题. 该问题于 1.85.0 中引入.
  • boost 1.85.0 :
    • 大幅重写了内部逻辑, 将优化路径与基于 C++ 标准库 IO 的流分离开:
      • 基于 C++ 标准库的流如今在更少情形下才被构造, 从而带来 更好的性能;
      • 更少的模板实例化与更简单的代码;
      • 始终使用 std::char_traits (不要使用来自输入/输出类型的自定义 traits, 因为这会导致链接期或运行期错误);
      • 不再支持 volatile 输入类型, 与 C++ 标准库的趋势保持一致.
    • 优化了从 std::basic_string_view 与 boost::basic_string_view 进行的转换
    • 移除了对 Boost.NumericConversion 与 Boost.MPL 的依赖. 修复了浮点类型转换为算术类型时的部分情形.
    • 本库现在可与 -fno-sanitize-recover=integer 正常配合工作.
  • boost 1.84.0 :
    • 不再支持 C++98 与 C++03.
  • boost 1.56.0 :
    • 新增了 boost::conversion::try_lexical_convert 函数.
  • boost 1.54.0 :
    • 修复了 boost::int128_type 与 boost::uint128_type 转换中的一些问题. 若 std::numeric_limits 未针对 128 位类型特化, 且 boost::lexical_cast 无法执行转换, 则会在编译期提示用户.
  • boost 1.54.0 :
    • 新增了转换 boost::int128_type 与 boost::uint128_type 类型的代码 (需要 GCC 4.7 或更高版本).
    • 到指针的转换现在将无法通过编译, 而不是在运行期抛出异常.
    • 恢复了获取 lexical_cast 函数指针的能力 (该能力在 1.53.0 中损坏).
  • boost 1.53.0 :
    • 为用户自定义类型提供了大幅改进的输入/输出流检测.
  • boost 1.52.0 :
    • 恢复了在 MSVC-2003 上的编译 (该能力在 1.51.0 中损坏).
    • 新增了 lexical_cast(const CharType* chars, std::size_t count) 函数重载.
  • boost 1.51.0 :
    • boost::array<character_type, N> 与 std::array<character_type, N> 转换具有更好的性能与更少的内存占用.
  • boost 1.50.0 :
    • boost::bad_lexical_cast 异常现在全局可见, 即使代码以 -fvisibility=hidden 编译也能捕获它.
    • 现在可以在禁用异常的情况下编译本库.
    • boost::iterator_range<character_type*> 转换具有更好的性能与更少的内存占用, 并修复了若干缺陷.
  • boost 1.49.0 :
    • 恢复了对 typedef 化的 wchar_t 的支持 (Visual Studio 编译标志 /Zc:wchar_t-).
    • boost::container::basic_string 转换具有更好的性能与更少的内存占用.
  • boost 1.48.0 :
    • 新增了在任意平台上处理 Inf 与 NaN 的代码.
    • 到 float 类型的转换具有更好的性能与更少的内存占用 (若 sizeof(double) < sizeof(long double), 到 double 类型亦然).
  • boost 1.47.0 :
    • 针对 "C" 及其他不带数字分组 (number grouping) 的 locale 进行了优化.
    • unsigned char 与 signed char 转换具有更好的性能与更少的内存占用.
    • 到算术类型的转换具有更好的性能与更少的内存占用.
    • 算术类型到算术类型的转换具有更好的性能与更少的内存占用.
    • 在某些转换中直接从 Source 构造 Target (例如从字符串到字符串、从字符数组到字符串、从字符到字符等转换).
  • boost 1.34.0 :
    • 许多 Source 与 Target 类型组合的性能都得到了提升. 更多细节请参阅 Alexander Nasonov 的文章 Fine Tuning for lexical_cast, Overload #74, August 2006 (PDF).
  • boost 1.33.0 :
    • 参数采用 const 引用传递. 这要求类模板的部分特化, 因此在 MSVC 6 上不可行, 那里仍使用原来的按值传递.
    • 对 MSVC 6 的支持已被弃用, 并将在未来的 Boost 版本中移除.
  • 更早版本 :
    • lexical_cast 的旧版本在读写浮点数时使用默认流精度. 对于存在对应 std::numeric_limits 特化的数值类型, 当前版本现在会选择相匹配的精度.
    • lexical_cast 的旧版本不支持任何基于宽字符的类型之间的转换. 对于在语言和库层面都完整支持宽字符的编译器, lexical_cast 现在支持从 wchar_t、wchar_t * 与 std::wstring 到 wchar_t 与 std::wstring 的转换.
    • lexical_cast 的旧版本假定常规的流提取运算符足以读取值. 然而, 字符串 I/O 是不对称的, 其结果是空格扮演 I/O 分隔符的角色, 而非字符串内容. 当前版本为 std::string 以及 (在受支持的场合) std::wstring 修复了这一错误: lexical_cast<std::string>("Hello, World") 现在会成功, 而不是抛出 bad_lexical_cast 异常而失败.
    • lexical_cast 的旧版本允许到指针的不安全且无意义的转换. 当前版本对到指针的转换会抛出 bad_lexical_cast: lexical_cast<char *>("Goodbye, World") 现在抛出异常, 而不是导致未定义行为.
