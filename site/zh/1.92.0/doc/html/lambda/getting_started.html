安装本库

本库仅由头文件组成, 因此没有安装过程. boost 包含目录必须位于包含路径上. 有若干头文件, 各自提供不同的功能:

  • lambda/lambda.hpp 为不同的 C++ 运算符定义 lambda 表达式, 参见 "运算符表达式"一节.

  • lambda/bind.hpp 定义了最多接受 9 个实参的 bind 函数, 参见 "绑定表达式"一节.

  • lambda/if.hpp 为 if 语句和条件运算符定义了 lambda 函数等价物, 参见 "控制结构的 lambda 表达式"一节 (包含 lambda.hpp) .

  • lambda/loops.hpp 为循环结构定义了 lambda 函数等价物, 参见 "控制结构的 lambda 表达式"一节.

  • lambda/switch.hpp 为 switch 语句定义了 lambda 函数等价物, 参见 "控制结构的 lambda 表达式"一节.

  • lambda/construct.hpp 提供了用于编写带构造函数、析构函数、new 和 delete 调用的 lambda 表达式的工具, 参见 "构造与析构"一节 (包含 lambda.hpp) .

  • lambda/casts.hpp 提供各种 cast 的 lambda 版本, 以及 sizeof 和 typeid, 参见 "Cast 表达式"一节.

  • lambda/exceptions.hpp 提供在 lambda 函数中抛出和捕获异常的工具, "异常"一节 (包含 lambda.hpp) .

  • lambda/algorithm.hpp 以及 lambda/numeric.hpp (对照标准 algortihm 以及 numeric 头文件) 允许嵌套的 STL 算法调用, 参见 "嵌套 STL 算法调用"一节.

包中任何其他头文件均属内部使用. 此外, 本库还依赖于另外两个 Boost 库—— Tuple (元组) [tuple] 库和 type_traits [type_traits] 库——以及头文件 boost/ref.hpp .

所有定义都位于命名空间 boost::lambda 及其子命名空间中.

本文档使用的约定

在大多数代码示例中, 我们省略 std 以及 boost::lambda 命名空间中名字的命名空间前缀. 假定隐式 using 声明

using namespace std;
using namespace boost::lambda;

处于生效状态.
