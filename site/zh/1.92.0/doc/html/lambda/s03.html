lambda 表达式入门

动机

标准模板库 (STL) [STL94]——现为 C++ 标准库 [C++98]的一部分——是一个泛型容器与算法库. STL 算法通常通过 函数对象 (function objects) 操作容器元素. 这些函数对象作为实参传递给算法.

任何能用函数调用语法调用的 C++ 构造都是函数对象. STL 为一些常见情形 (例如 plus、 less 以及 not1) 包含了预定义的函数对象. 举例来说, 标准 plus 模板的一种可能实现是:

template <class T> 
struct plus : public binary_function<T, T, T> {
  T operator()(const T& i, const T& j) const {
    return i + j; 
  }
};

基类 binary_function<T, T, T> 包含该函数对象实参类型和返回类型的 typedef, 这些是使函数对象 可适配 (adaptable) 所必需的.

除了上面那样的基本函数对象类之外, STL 还包含 binder (绑定器) 模板, 通过把可适配二元函数对象的某个实参固定为常量值来创建一元函数对象. 例如, 不必显式地编写如下函数对象类:

class plus_1 {
  int _i;
public:
  plus_1(const int& i) : _i(i) {}
  int operator()(const int& j) { return _i + j; }
};

等价的功能可以用 plus 模板和一个 binder 模板 (bind1st) 来实现. 例如, 下面两个表达式创建的函数对象功能完全相同; 被调用时, 都返回把 1 加到函数对象实参上的结果:

plus_1(1)
bind1st(plus<int>(), 1)

后一行中的子表达式 plus<int>() 是一个计算两个整数之和的二元函数对象, bind1st 部分绑定第一个实参为 1来调用这个函数对象. 作为使用上述函数对象的例子, 下面的代码把 1 加到某个容器 a 的每个元素上, 并把结果输出到标准输出流 cout.

transform(a.begin(), a.end(), ostream_iterator<int>(cout),
          bind1st(plus<int>(), 1));

为了使 binder 模板更普遍适用, STL 包含 适配器 (adaptors) , 用于使函数的指针或引用、以及成员函数的指针可适配. 最后, 一些 STL 实现还包含函数组合操作, 作为对标准的扩展 [SGI02].

所有这些工具都指向同一个目标: 让在 STL 算法调用中指定 无名函数 (unnamed functions) 成为可能, 换句话说, 把代码片段作为实参传给函数. 然而, 这一目标只是部分达成. 上面的简单示例表明, 用标准工具定义无名函数相当麻烦. 涉及仿函数、适配器、binder 和函数组合操作的复杂表达式往往难以理解. 此外, 在应用标准工具时还有显著的限制. 例如, 标准 binder 只允许绑定二元函数的一个实参; 对于三元 (3-ary) 、四元 (4-ary) 等函数没有 binder.

Boost Lambda 库为上述问题提供了解决方案:

  • 无名函数可以用直观的语法轻松创建. 上面的示例可以写成:

    transform(a.begin(), a.end(), ostream_iterator<int>(cout), 
          1 + _1);

    或者甚至更直观地写成:

    for_each(a.begin(), a.end(), cout << (1 + _1));

  • 实参绑定方面的大部分限制都被消除, 实际上任何 C++ 函数的任意实参都可以绑定.

  • 不需要单独的函数组合操作, 因为函数组合是隐式支持的.

lambda 表达式引论

部分函数应用
术语

lambda 表达式在函数式编程语言中很常见. 它们的语法因语言 (以及 lambda 演算的不同形式) 而异, 但 lambda 表达式的基本形式是:

lambda x1 ... xn.e

lambda 表达式定义一个无名函数, 由以下部分组成:

  • 该函数的参数: x1 ... xn.

  • 根据参数 x1 ... xn计算函数值的表达式 e.

lambda 表达式的一个简单例子是

lambda x y.x+y

应用 lambda 函数意味着用实际实参替换形式参数:

(lambda x y.x+y) 2 3 = 2 + 3 = 5

在 C++ 版本的 lambda 表达式中, lambda x1 ... xn 部分缺失, 形式参数具有预定义的名字. 在本库的当前版本中, 有三个这样的预定义形式参数, 称为 占位符 (placeholders) : _1、 _2 以及 _3. 它们指代由 lambda 表达式定义的函数的第一、第二和第三个实参. 例如, 定义

lambda x y.x+y

是

_1 + _2

因此, C++ lambda 表达式没有语法关键字. 把占位符用作操作数即意味着该运算符调用是 lambda 表达式. 不过, 这仅对运算符调用成立. 包含函数调用、控制结构、cast 等的 lambda 表达式需要特殊的语法构造. 最重要的是, 函数调用需要被包在 bind 函数中. 举例来说, 考虑 lambda 表达式:

lambda x y.foo(x,y)

其 C++ 对应物不是 foo(_1, _2), 而是:

bind(foo, _1, _2)

我们把这类 C++ lambda 表达式称为 绑定表达式 (bind expressions) .

lambda 表达式定义一个 C++ 函数对象, 因此函数应用语法就像调用任何其他函数对象, 例如: (_1 + _2)(i, j).

部分函数应用

绑定表达式实际上是一种 部分函数应用 (partial function application) . 在部分函数应用中, 函数的部分实参被绑定到固定值. 结果是另一个函数, 其实参可能更少. 当用未绑定的实参调用这个新函数时, 它以已绑定实参与未绑定实参合并后的实参列表调用原函数.

术语

lambda 表达式定义一个函数. C++ lambda 表达式在被求值时会具体地构造一个函数对象, 即仿函数 (functor) . 我们用 lambda 仿函数 (lambda functor) 这个名字来指代这类函数对象. 因此, 在本文采用的术语中, 对 lambda 表达式求值的结果就是一个 lambda 仿函数.
