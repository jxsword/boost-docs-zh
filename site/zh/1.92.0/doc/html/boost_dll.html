动机

在运行期为现有软件应用添加特定功能在许多情况下都很有用. 这类扩展 (即插件) 通常使用运行时加载的动态库模块 (DLL、SO/DSO) 实现.

本库旨在以一种可移植的跨平台方式简化使用 C++ 的插件开发.

本库提供跨平台的可移植方式来:

  • 加载库
  • 导入任意原生函数和变量
  • 为 C++ 修饰名函数和符号创建别名
  • 查询库的节和导出符号
  • 自加载与自查询
  • 通过导出符号获取程序和模块的位置
