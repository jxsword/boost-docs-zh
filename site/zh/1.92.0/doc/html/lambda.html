概述

Boost Lambda 库 (下文简称 BLL) 是一个 C++ 模板库, 它为 C++ 实现了一种lambda 抽象. 该术语源自函数式编程与 lambda 演算, 其中 lambda 抽象定义一个无名函数. BLL 的主要动机是为 STL 算法提供灵活便捷的手段来定义无名函数对象. 在解释这个库的内容时, 一行代码胜过千言万语; 下面这行代码输出某个 STL 容器 a 的元素, 以空格分隔:

for_each(a.begin(), a.end(), std::cout << _1 << ' ');

表达式 std::cout << _1 << ' ' 定义了一个一元函数对象. 变量 _1 是该函数的参数, 是实际参数的占位符. 在 for_each 的每次迭代中, 该函数都会以 a 的一个元素作为实际参数被调用. 这个实际参数被代入占位符, 并对函数的“函数体”进行求值.

BLL 的本质是让你能够在 STL 算法的调用处直接定义小的无名函数对象, 例如上面的那个.
