设计理由

YAP 表达式中捕获值的退化

Boost.YAP 的主要目标是成为一个易于使用、易于理解的库, 用于运用表达式模板编程技术.

因此, Boost.YAP 表达树中节点的表示方式与 C++ 内建表达式中节点的表示方式相匹配是非常重要的. 这使识别和操作表达式树各部分的心智模型在 C++ 内建树与 Boost.YAP 树之间保持一致.

尽管这会带来一些小麻烦 (例如, Boost.YAP 终结符不能包含数组), 但一致的编程模型带来的好处更为重要.

引用表达式

Boost.YAP 表达式可以作为子表达式用来构建更大的表达式. expr_kind::expr_ref 的存在就是让我们能够做到这一点而不产生不必要的复制或移动. 考虑 v2 与 v3 .

lazy_vector v2{{std::vector<double>(4, 2.0)}};
lazy_vector v3{{std::vector<double>(4, 3.0)}};

现在考虑这个表达式:

double d1 = (v2 + v3)[2];

若不使用引用语义, 我们如何在求值之前就捕获这个表达式, 而不复制或移动这些向量? 做不到. 我们必须对 v2 与 v3 子表达式取引用, 以避免复制或移动.

这是有代价的. 处理 expr_kind::expr_ref 表达式会使户代码复杂化. 替代方案 —— 默默地产生复制/移动, 或禁止用子表达式构建更大的表达式 —— 更糟.
