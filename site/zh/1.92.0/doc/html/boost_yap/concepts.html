概念

Expression

Expression (表达式) 是 Boost.YAP 的核心概念. 它必须至少包含一个 expr_kind 以及一个值的 boost::hana::tuple<> .

以下是 Expression 的要求摘要. 在下表中, E 是一个满足 Expression 的类型; e 是类型 E 的对象; Tuple 是 boost::hana::tuple<> 的一个实例; 而 t 是类型 Tuple 的对象.

ExpressionTemplate

ExpressionTemplate 是任何具有两个参数的模板: 当以一个 expr_kind 和一个 boost::hana::tuple<> 实例化时, 结果是一个 Expression .

Transform

transform() 把 Transform 作为其第二个参数. Transform 是一个 Callable , 它接受表达式并返回不受约束类型的值. Transform 可以使用两类重载: ExpressionTransform 与 TagTransform .

一个 Transform 可以有任意数量的重载, 包括没有重载.

ExpressionTransform

ExpressionTransform 把一个 Expression 作为其唯一参数. 下面是一些示例.

这个重载接受任何 Expression :

struct xform
{
    template <typename Expr>
    auto operator() (Expr const & expr)
    {
        // ...
    }
};

这个重载接受满足其模板参数所施加约束的任何类型的 Expression :

template <typename Expr1, typename Expr2, typename Expr3>
decltype(auto) xform (
    boost::yap::expression<
        boost::yap::expr_kind::plus,
        boost::hana::tuple<
            boost::yap::expression<
                boost::yap::expr_kind::multiplies,
                boost::hana::tuple<
                    Expr1,
                    Expr2
                >
            >,
            Expr3
        >
    > const & expr
) {
    // ...
}

这个重载只接受特定类型:

decltype(auto) xform (
    decltype(term<number>{{0.0}} * number{} + number{}) const & expr
) {
    // ...
}

TagTransform

TagTransform 把一个标签类型 (tag-type) 作为其第一个参数, 并把表达式的各个元素作为其余参数.

标签的命名规则是: 具有 expr_kind expr_kind::foo 的表达式的标签命名为 foo_tag . 下面是一些示例.

这个重载接受任何包含 user::number 的终结符 (或对这种终结符的引用):

struct xform
{
    decltype(auto) operator() (boost::yap::terminal_tag, user::number const & n)
    {
        // ...
    }
};

这个重载接受任何包含一对 user::number 终结符 (或对终结符的引用) 的加法表达式:

decltype(auto) xform (boost::yap::plus_tag, user::number lhs, user::number rhs)
{
    // ...
}

这个重载接受任何取负表达式:

struct xform
{
    template <typename Expr>
    decltype(auto) operator() (boost::yap::negate_tag, Expr const & expr)
    {
        // ...
    }
};

这个重载接受任何具有两个终结符 (或对终结符的引用, 其中包含可转换为 double 的值) 的调用表达式:

struct xform
{
    decltype(auto) operator() (boost::yap::call_tag, tag_type, double a, double b)
    {
        // ...
    }
}
