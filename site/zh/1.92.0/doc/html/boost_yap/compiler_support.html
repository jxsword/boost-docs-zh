编译器支持

Boost.YAP 针对 C++14 与 C++17 标准编写. 若 C++17 特性存在则使用之, 否则是 C++14 代码.

Boost.YAP 还大量使用 Boost.Hana, 因此只有支持 Hana 的编译器才能用于构建 Boost.YAP.

Clang 3.8 及更高版本 (对应 XCode 7.3 或更高版本), 以及 GCC 6 及更高版本应当可以工作.

MSVC++ version 14.15 (Visual Studio 2017 version 15.8) 获得部分支持. 所有测试均通过, 但在某些示例中可能发现一些编译错误.
