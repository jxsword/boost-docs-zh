教程: closure 与 adaptor

下面是 boost::stl_interfaces::closure:

    /** An invocable consisting of a contained invocable `f`.  Calling
        `operator()` with some argument `t` calls `f(t)` and returns the
        result.  This type is typically used to capture a the result of a call
        to `bind_back()`. */
    template<typename F>
    struct closure : range_adaptor_closure<closure<F>>
    {
        constexpr closure(F f) : f_(std::move(f)) {}

#if BOOST_STL_INTERFACES_USE_CONCEPTS
        template<typename T>
        requires std::invocable<F const &, T>
#else
        template<
            typename T,
            typename Enable =
                std::enable_if_t<detail::is_invocable_v<F const &, T>>>
#endif
        constexpr decltype(auto) operator()(T && t) const &
        {
            return f_((T &&) t);
        }

#if BOOST_STL_INTERFACES_USE_CONCEPTS
        template<typename T>
        requires std::invocable<F &&, T>
#else
        template<
            typename T,
            typename Enable = std::enable_if_t<detail::is_invocable_v<F &&, T>>>
#endif
        constexpr decltype(auto) operator()(T && t) &&
        {
            return std::move(f_)((T &&) t);
        }

    private:
        [[no_unique_address]] F f_;
    };

如你所见, 它继承自 boost::stl_interfaces::range_adaptor_closure, 其唯一的成员函数是一个调用运算符, 转发给它据以构造的函数 F. 它的存在只是为了把某个构造特定视图的函数适配成可在管道表达式中使用的形式.

adaptor 略有不同; 它在本质上就像 closure 一样运作, 只要你以调用其 operator() 所需的全部实参 (即调用其函数 F 所需的全部实参) 调用它 - 它只是构造一个视图. 但是, 如果你传入除第一个实参之外的所有实参, 它会返回一个绑定了所有这些实参的 closure:

    /** Adapts an invocable `f` as a view adaptor.  Calling
        `operator(args...)` will either: call `f(args...)` and return the
        result, if `f(args...)` is well-formed; or return
        `closure(stl_interfaces::bind_back(f, args...))` otherwise. */
    template<typename F>
    struct adaptor
    {
        constexpr adaptor(F f) : f_(std::move(f)) {}

        // clang-format off
        template<typename... Args>
        constexpr auto operator()(Args &&... args) const
        // clang-format on
        {
#if BOOST_STL_INTERFACES_USE_CONCEPTS
            if constexpr (std::is_invocable_v<F const &, Args...>) {
                return f_((Args &&) args...);
            } else {
                return closure(
                    stl_interfaces::bind_back(f_, (Args &&) args...));
            }
#else
            return detail::adaptor_impl<
                F const &,
                detail::is_invocable_v<F const &, Args...>,
                Args...>::call(f_, (Args &&) args...);
#endif
        }

    private:
        [[no_unique_address]] F f_;
    };

这让你既可以把它用作视图构造器 (例如 take(range, 3)), 也可以用作闭包构造器 (例如 range | take(3)).

重要

由于 adaptor 的工作方式, 你的视图的构造函数应当始终把视图参数放在其他任何参数之前. 否则, bind_back() 与 closure 的组合很可能做不出什么有用的事情.
