v1 与 v2 命名空间, 以及 C++20 概念的使用

对本库的大部分内容而言, 存在两个接口: 一个位于命名空间 boost::stl_interfaces::v1, 另一个位于 boost::stl_interfaces::v2. v1 版本使用 SFINAE 约束模板, v2 版本使用概念, 包括 C++20 的标准概念.

当使用符合标准的 C++20 编译器构建时, 编译器会定义宏 __cpp_lib_concepts, 表明该编译器支持概念, 并在 std 与 std::ranges 中提供标准概念. 当 Boost.STLInterfaces 看到 __cpp_lib_concepts 宏已定义时, 它内联 v2 命名空间; 否则内联 v1 命名空间.

作为用户的最终结果是: 对于某个函数或类型 foo, 若它有 v1 与 v2 两个版本, 你可以使用 boost::stl_interfaces::foo, 在 C++14 或 C++17 模式下构建时会得到 boost::stl_interfaces::v1::foo, 在 C++20 及更高模式下构建时会得到 boost::stl_interfaces::v2::foo.

如果你使用的早期 C++20 实现声称支持概念, 但在构建 Boost.STLInterfaces 的 C++20 代码时出问题, 可以禁用 v2 命名空间, 方法是定义 BOOST_STL_INTERFACES_DISABLE_CONCEPTS. ]
