本库与 Boost.Iterator 的关系

Boost.Iterator 是 Boost 中已有的库, 已经存在很长时间了.

然而, 它试图解决大量与迭代器相关的问题, 而不只是如何从零编写迭代器. 要把它现代化以用于 C++11 及更高版本也不容易. 具体来说:

- Boost.Iterator 包含大量迭代器适配器; 这些适配器已被 C++20 ranges 取代而失去意义.

- Boost.Iterator 的 iterator_facade 模板并不限于现有的标准 C++ 迭代器类别; 那是一项从未进入标准 C++ 的实验, 徒增不必要的复杂性.

- Boost.Iterator 的 iterator_facade 是针对 C++98 编写的, 因此对 constexpr 与 noexcept 并不友好.

- Boost.Iterator 的 iterator_facade 不支持代理迭代器, 而 C++20 迭代器概念完全支持代理迭代器.

- 还有机会减少用户为使用 iterator_facade 而必须编写的代码量.

- Boost.Iterator 包含两个模板 iterator_facade 与 iterator_adaptor, 它们代表了在尽量少写代码的前提下编写新迭代器的两种方式. 若能把两者的功能合入一个模板会很不错, 但按现状很难统一这两个模板.

基于这些原因, 引入一个新的 Boost 库似乎比直接修补 Boost.Iterator 的 iterator_facade 与 iterator_adaptor 模板的缺陷更为合适.
