教程: reverse_iterator

有一个 std::reverse_iterator 模板, 自 C++98 起就存在. 在 C++20 中它与代理迭代器兼容, 并且对 constexpr 与 noexcept 友好. 如果你使用 C++20 或更高版本, 直接使用 std::reverse_iterator. 对于针对更早 C++ 版本构建的代码, 可以使用 reverse_iterator.

关于它没有太多可写的; 它的工作方式与 std::reverse_iterator 完全一样.
