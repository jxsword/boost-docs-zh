多态转换

polymorphic_downcast
polymorphic_cast
polymorphic_pointer_cast

指向多态对象 (定义了至少一个虚函数的类的对象) 的指针有时会被向下转换 (downcast) 或横向转换 (crosscast). 向下转换指从基类转换为派生类. 横向转换指跨越继承层次图进行转换, 例如在 Y 图层次中从一个基类转换到另一个基类.

这类转换可以用旧式转换完成, 但绝不推荐这种做法. 旧式转换严重缺乏类型安全性, 可读性差, 并且难以用搜索工具定位.

polymorphic_downcast

C++ 内置的 static_cast 可用于高效地向下转换指向多态对象的指针, 但对被转换指针实际指向错误派生类的情况不提供错误检测. polymorphic_downcast 模板在非调试编译中保持了 static_cast 的效率, 但在调试编译中通过 assert() 增加了安全性, 确保 dynamic_cast 成功.

polymorphic_downcast 应用于你确信应当成功的向下转换. 错误检查仅在未定义 NDEBUG 的翻译单元中进行, 方式如下

assert( dynamic_cast<Derived>(x) == x )

其中 x 是源指针. 这种方法不仅确保返回非零指针, 还确保在存在多重继承时它也是正确的. 尝试使用 polymorphic_downcast 进行横向转换将无法编译.

警告

由于 polymorphic_downcast 使用了 assert(), 如果 NDEBUG 在各翻译单元中的定义不一致, 它将违反单一定义规则 (ODR). 参见 ISO Std 3.2

示例: 
#include <boost/polymorphic_cast.hpp>
...
class Fruit { public: virtual ~Fruit(){}; ... };
class Banana : public Fruit { ... };
...
void f( Fruit * fruit ) {
  // ... logic which leads us to believe it is a Banana
  Banana * banana = boost::polymorphic_downcast<Banana*>(fruit);
  ...
}

polymorphic_cast

C++ 内置的 dynamic_cast 可用于指向多态对象的指针的向下转换与横向转换, 但以返回值 0 的形式通知错误既不便测试, 更糟的是容易忘记测试. dynamic_cast 的抛出异常形式作用于引用, 通过丑陋的表达式 &dynamic_cast<T&>(*p) 可作用于指针, 当 p 为 0 时会导致未定义行为. polymorphic_cast 模板对指针执行 dynamic_cast, 若 dynamic_cast 返回 0 则抛出异常.

对于横向转换, 或者转换的成功与否只能在运行期确定时, 或者效率不重要时, 首选 polymorphic_cast.

C++ 内置的 dynamic_cast 必须用于转换引用而非指针. 它也是唯一可用于检查给定接口是否受支持的转换; 在这种情况下, 返回 0 并不是错误条件.

polymorphic_pointer_cast

polymorphic_downcast 与 polymorphic_cast 仅适用于内置指针类型, 而 polymorphic_pointer_downcast 与 polymorphic_pointer_cast 是更通用的版本, 支持任何使以下表达式有效的指针类型:

对于 polymorphic_pointer_downcast:

static_pointer_cast<Derived>(p);
dynamic_pointer_cast<Derived>(p);

对于 polymorphic_pointer_cast:

dynamic_pointer_cast<Derived>(p);
!p; // conversion to bool with negation

这包括 C++ 内置指针、std::shared_ptr、boost::shared_ptr、boost::intrusive_ptr 等.

示例: 
#include <boost/polymorphic_pointer_cast.hpp>

class Fruit { public: virtual ~Fruit(){} };
class Banana : public Fruit {};

// Use one of these:
using FruitPtr = Fruit*;
using FruitPtr = std::shared_ptr<Fruit>;
using FruitPtr = boost::shared_ptr<Fruit>;
using FruitPtr = boost::intrusive_ptr<Fruit>;

void f(FruitPtr fruit) {
  // ... logic which leads us to believe it is a banana
  auto banana = boost::polymorphic_pointer_downcast<Banana>(fruit);
  ...
}
