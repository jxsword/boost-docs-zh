数据结构

Data Structure Configuration

boost.heap 提供以下数据结构:

boost::heap::priority_queue

priority_queue 类是对 STL 堆函数的封装. 它把堆实现为构建在 std::vector 之上的容器适配器, 且不可变.

boost::heap::d_ary_heap

D 叉堆 是二叉堆的推广, 每个非叶节点有 N 个孩子. 分支因子较低时, 堆的高度更大, 但寻找最大孩子节点所需的比较次数也更多. D 叉堆实现为基于 std::vector 的容器适配器.

该数据结构可配置为可变的. 这是通过把值存储在 std::list 内实现的.

boost::heap::binomial_heap

二项堆 是基于节点的堆, 实现为一组阶数逐段不同的二项树. 最重要的堆操作的最坏情形复杂度为 O(log n). 与 D 叉堆不同, 二项堆还可以在 O(log n) 内合并.

boost::heap::fibonacci_heap

斐波那契堆 是基于节点的堆, 实现为由堆序树构成的森林. 它们提供比二项堆更好的均摊性能. 除 pop() 和 erase() 之外, 最重要的堆操作具有常量均摊复杂度.

boost::heap::pairing_heap

配对堆 是自调整的基于节点的堆. 尽管设计与实现相当简单, 其复杂度分析至今尚未解决. 详情请查阅:

Pettie, Seth (2005), "Towards a final analysis of pairing heaps", Proc. 46th Annual IEEE Symposium on Foundations of Computer Science, pp. 174–183

boost::heap::skew_heap

斜堆 是自调整的基于节点的堆. 尽管对树结构没有任何约束, 所有堆操作都可以在 O(log n) 内完成.

数据结构配置

这些数据结构可以用 Boost.Parameter 风格的模板进行配置.

boost::heap::compare

定义堆序的谓词, 可选 (默认为 boost::heap::compare<std::less<T> >)

boost::heap::allocator

用于内部内存管理的分配器, 可选 (默认为 boost::heap::allocator<std::allocator<T> >)

boost::heap::stable

配置堆使用 稳定堆序, 可选 (默认为 boost::heap::stable<false>).

boost::heap::mutable_

配置堆为可变. boost::heap::d_ary_heap 和 boost::heap::skew_heap 必须配置此策略才能启用 可变性接口.

boost::heap::stability_counter_type

配置用于稳定性计数器的整数类型, 可选 (默认为 boost::heap::stability_counter_type<boost::uintmax_t>). 更多细节请查阅 稳定性 一节.

boost::heap::constant_time_size

指定 size() 应具有线性还是常量复杂度. 该实参仅对基于节点的堆数据结构可用, 若可用则为可选 (默认为 boost::heap::constant_time_size<true>)

boost::heap::arity

指定 D 叉堆的分支因子. 详情请查阅 boost::heap::d_ary_heap 的类参考

boost::heap::store_parent_pointer

在堆节点中存储父指针. 此策略仅在 boost::heap::skew_heap 中可用.
