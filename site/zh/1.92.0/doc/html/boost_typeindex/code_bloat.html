代码膨胀

在没有 RTTI 时, TypeIndex 库会从使用 boost::typeindex::stl_type_index 类切换到 boost::typeindex::ctti_type_index. boost::typeindex::ctti_type_index 使用宏来获取传给 type_id() 和 type_id_with_cvr() 函数的每个类型的函数名完整文本表示.

在 C++11 模式下, 这会导致二进制文件中出现很长的字符串:

static const char* boost::detail::ctti<T>::n() [with T = int]
static const char* boost::detail::ctti<T>::n() [with T = user_defined_type]

从 C++14 开始, 这些字符串会短得多, 并且只包含实际的类型名称:

int
user_defined_type

在启用 RTTI 的情况下, 二进制文件中始终是较短的字符串:

i
17user_defined_type
