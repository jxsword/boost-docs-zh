制作自定义 type_index

基础
在运行期获取 type info
在整个代码中使用新的 type info

有时可能需要创建你自己的类型信息系统. 如果你希望存储更多关于类型的信息 (平凡可拷贝性、类型大小、常用函数的指针...) 或者你对更紧凑的类型表示形式有自己的想法, 这可能会很有用.

基础

以下示例展示如何创建和使用用户自定义的 type_info. 无论是否启用 RTTI 都可用.

考虑用户仅在 typeid() 中使用这些类型的情况:

#include <vector>
#include <string>

namespace my_namespace {

class my_class;
struct my_struct;

using my_classes = std::vector<my_class>;
using my_string = std::string;

} // namespace my_namespace

在这种情况下, 用户可能希望节省二进制文件中的空间并创建自己的类型系统. 为此添加了 detail::typenum<> 元函数. 该函数会根据输入类型 T 返回不同的数值.

#include <boost/type_index/type_index_facade.hpp>

namespace my_namespace { namespace detail {
    template <class T> struct typenum;
    template <> struct typenum<void>{       enum {value = 0}; };
    template <> struct typenum<my_class>{   enum {value = 1}; };
    template <> struct typenum<my_struct>{  enum {value = 2}; };
    template <> struct typenum<my_classes>{ enum {value = 3}; };
    template <> struct typenum<my_string>{  enum {value = 4}; };

#ifdef BOOST_MSVC
#pragma warning(push)
#pragma warning(disable: 4510 4512 4610) // non-copyable non-constructable type
#endif

    // my_typeinfo structure is used to save type number
    struct my_typeinfo {
        const char* const type_;
    };

#ifdef BOOST_MSVC
#pragma warning(pop)
#endif

    const my_typeinfo infos[5] = {
        {"void"}, {"my_class"}, {"my_struct"}, {"my_classes"}, {"my_string"}
    };

    template <class T>
    inline const my_typeinfo& my_typeinfo_construct() {
        return infos[typenum<T>::value];
    }
}} // my_namespace::detail

my_type_index 是用户创建的 type_index 类. 如果在此阶段有疑问, 你随时可以查看 <boost/type_index/ctti_type_index.hpp> 或 <boost/type_index/stl_type_index.hpp> 文件. type_index_facade 的文档也可能有用.

由于我们不打算重写 type_index_facade::hash_code(), 我们必须额外包含 <boost/container_hash/hash.hpp>.

#include <boost/container_hash/hash.hpp>

参见 my_type_index 的实现:

namespace my_namespace {

class my_type_index: public boost::typeindex::type_index_facade<my_type_index, detail::my_typeinfo> {
    const detail::my_typeinfo* data_;

public:
    using type_info_t = detail::my_typeinfo;

    inline my_type_index() noexcept
        : data_(&detail::my_typeinfo_construct<void>())
    {}

    inline my_type_index(const type_info_t& data) noexcept
        : data_(&data)
    {}

    inline const type_info_t&  type_info() const noexcept {
        return *data_;
    }

    inline const char*  raw_name() const noexcept {
        return data_->type_;
    }

    inline std::string  pretty_name() const {
        return data_->type_;
    }

    template <class T>
    inline static my_type_index type_id() noexcept {
        return detail::my_typeinfo_construct<T>();
    }

    template <class T>
    inline static my_type_index type_id_with_cvr() noexcept {
        return detail::my_typeinfo_construct<T>();
    }

    template <class T>
    inline static my_type_index type_id_runtime(const T& variable) noexcept;
};

} // namespace my_namespace

注意我们使用了 boost::typeindex::type_index_facade 类作为基类. 该类负责所有的辅助函数和运算符 (比较、哈希、流输出等).

最后, 我们可以使用 my_type_index 类来获取类型索引:

my_type_index
    cl1 = my_type_index::type_id<my_class>(),
    st1 = my_type_index::type_id<my_struct>(),
    st2 = my_type_index::type_id<my_struct>(),
    vec = my_type_index::type_id<my_classes>()
;

assert(cl1 != st1);
assert(st2 == st1);
assert(vec.pretty_name() == "my_classes");
assert(cl1.pretty_name() == "my_class");

在运行期获取类型信息

通常, 要启用运行期类型信息, 需要用某个宏注册类. 让我们看看如何实现 MY_TYPEINDEX_REGISTER_CLASS 宏以用于我们的 my_type_index 类:

namespace my_namespace { namespace detail {

    template <class T>
    inline const my_typeinfo& my_typeinfo_construct_ref(const T*) {
        return my_typeinfo_construct<T>();
    }

#define MY_TYPEINDEX_REGISTER_CLASS                                             \
    virtual const my_namespace::detail::my_typeinfo& type_id_runtime() const {  \
        return my_namespace::detail::my_typeinfo_construct_ref(this);           \
    }

}} // namespace my_namespace::detail

现在有了 MY_TYPEINDEX_REGISTER_CLASS, 让我们实现一个 my_type_index::type_id_runtime 方法:

namespace my_namespace {
    template <class T>
    my_type_index my_type_index::type_id_runtime(const T& variable) noexcept {
        // Classes that were marked with `MY_TYPEINDEX_REGISTER_CLASS` will have a
        // `type_id_runtime()` method.
        return variable.type_id_runtime();
    }
}

考虑 my_class 和 my_struct 是多态类的情形:

namespace my_namespace {

class my_class {
public:
    MY_TYPEINDEX_REGISTER_CLASS
    virtual ~my_class() {}
};

struct my_struct: public my_class {
    MY_TYPEINDEX_REGISTER_CLASS
};

} // namespace my_namespace

现在下面的示例可以编译并正常运行.

my_struct str;
my_class& reference = str;
assert(my_type_index::type_id<my_struct>() == my_type_index::type_id_runtime(reference));

在全部代码中使用新的类型信息

有一种简单的方法可以强制 boost::typeindex::type_id 使用你自己的 type_index 类.

我们只需将 BOOST_TYPE_INDEX_USER_TYPEINDEX 定义为你的类型索引类头文件的完整路径:

// BOOST_TYPE_INDEX_USER_TYPEINDEX must be defined *BEFORE* first inclusion of <boost/type_index.hpp>
#define BOOST_TYPE_INDEX_USER_TYPEINDEX <user_defined_typeinfo.hpp>
#include <boost/type_index.hpp>

你还需要向你的 "user_defined_typeinfo.hpp" 头文件添加一些 typedef 和宏:

#define BOOST_TYPE_INDEX_REGISTER_CLASS MY_TYPEINDEX_REGISTER_CLASS
namespace boost { namespace typeindex {
    using type_index = my_namespace::my_type_index;
}}

就是这样! 现在所有 TypeIndex 全局方法和 typedef 都将使用你的类:

boost::typeindex::type_index worldwide = boost::typeindex::type_id<my_classes>();
assert(worldwide.pretty_name() == "my_classes");
assert(worldwide == my_type_index::type_id<my_classes>());
