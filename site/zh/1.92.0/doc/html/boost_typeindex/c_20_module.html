C++20 模块

注意

C++20 模块支持尚处于早期阶段, 构建目标、编译标志和行为在未来都可能发生变化.

如果使用较新的 CMake, 请定义 CMake 选项 -DBOOST_USE_MODULES=1 来构建 C++20 模块, 并使 Boost::type_index CMake 构建目标提供该模块. 此后即可显式使用 C++20 模块 boost.type_index:

#include <iostream>

import boost.type_index;

int main() {
    std::cout << boost::typeindex::type_id_with_cvr<const int>();  // Outputs: const int
}

该 Boost::type_index CMake 构建目标使得可以在不同翻译单元中混用该库的头文件包含与模块导入. 此外, 如果定义了 BOOST_USE_MODULES 宏, 那么所有 boost/type_index/... 包含都会隐式执行 import boost.type_index;, 从而无需更改现有代码即可获得模块的全部好处.

注释

为了缩短编译时间, 请确保 import std; 在构建 boost.type_index 模块时可用 (CMake 日志中应出现一条 'Using import std;' 消息) .

如果不使用 CMake, 则可以基于 modules/boost_type_index.cppm 文件手动构建该模块.

对于手动模块构建, clang 编译器可以使用以下命令:

cd type_index/modules
clang++ -I ../include -std=c++20 --precompile -x c++-module boost_type_index.cppm

之后, 即可按以下方式使用该模块:

clang++ -std=c++20 -fmodule-file=boost_type_index.pcm boost_type_index.pcm usage_sample.cpp
