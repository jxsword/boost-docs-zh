RTTI 模拟的限制

定义 BOOST_TYPE_INDEX_FUNCTION_SIGNATURE 宏
修复 pretty_name() 与 name() 的输出

TypeIndex 已在许多编译器上经过测试并成功运行.

警告

在关闭 RTTI 时, 在不同模块的匿名命名空间中定义的完全同名的类可能被混同:

// In A.cpp
namespace { struct user_defined{}; }
type_index foo_a() { return type_id<user_defined>(); }

// In B.cpp
namespace { struct user_defined{}; }
type_index foo_b() { return type_id<user_defined>(); }

// In main.cpp
assert(foo_a() != foo_b()); // will fail on some compilers

存在该限制的编译器: GCC、CLANG、Intel.

测试: 该测试可通过运行 testing_crossmodule_anonymous_no_rtti 进行, 它构建自 ../../../b2, 位于 type_index/test/ 目录.

定义 BOOST_TYPE_INDEX_FUNCTION_SIGNATURE 宏

如果你在编译期间遇到以下错误

TypeIndex library could not detect your compiler.
Please make the BOOST_TYPE_INDEX_FUNCTION_SIGNATURE macro use
correct compiler macro for getting the whole function name.
Define BOOST_TYPE_INDEX_CTTI_USER_DEFINED_PARSING to correct value after that.

那么你正在使用的是一个未在本库测试过的编译器.

BOOST_TYPE_INDEX_FUNCTION_SIGNATURE 必须定义为一个编译器特定的宏, 该宏输出包含模板参数的 完整 函数签名.

修正 pretty_name() 和 name() 的输出

如果 boost::typeindex::ctti_type_index::type_id<int>().pretty_name() 的输出

  • 返回的不只是 int, 还有 int 周围的大量文本
  • 或者根本没有返回类型

那么你正在使用的是一个未在本库测试过的编译器, 你需要设置 BOOST_TYPE_INDEX_CTTI_USER_DEFINED_PARSING 宏.

以下是简要说明:

  1. 获取 boost::typeindex::ctti_type_index::type_id<int>().pretty_name() 的输出
  2. 将 BOOST_TYPE_INDEX_CTTI_USER_DEFINED_PARSING 定义为 (skip_at_begin, skip_at_end, false, ""), 其中
    • skip_at_begin 等于输出中第一次出现 int 之前的字符数
    • skip_at_end 等于输出中最后一次出现 int 之后的字符数
  3. 检查 boost::typeindex::ctti_type_index::type_id<int>().name_demangled() 返回 "int"
  4. 如果它未返回 int, 则将 BOOST_TYPE_INDEX_CTTI_USER_DEFINED_PARSING 定义为 (skip_at_begin, skip_at_end, true, "T = "), 其中
    • skip_at_begin 在第 2 步中等于 skip_at_begin
    • skip_at_end 在第 2 步中等于 skip_at_end
    • "T = " 等于输出中紧邻 int 之前的字符数
  5. (可选, 但强烈推荐) 提交 工单 以请求将你的编译器加入受支持编译器列表. 请包含传给 BOOST_TYPE_INDEX_CTTI_USER_DEFINED_PARSING 宏的参数.

考虑下面的示例:

boost::typeindex::ctti_type_index::type_id<int>().raw_name() 返回 "const char *__cdecl boost::detail::ctti<int>::n(void)". 那么你应将 skip_at_begin 设为 sizeof("const char *__cdecl boost::detail::ctti<") - 1, 并将 skip_at_end 设为 sizeof(">::n(void)") - 1.

#define BOOST_TYPE_INDEX_CTTI_USER_DEFINED_PARSING (39, 6, false, "")

另一个示例:

boost::typeindex::ctti_type_index::type_id<int>().raw_name() 返回 "static const char *boost::detail::ctti<int>::n() [T = int]"". 那么你应将 skip_at_begin 设为 sizeof("static const char *boost::detail::ctti<") - 1, 将 skip_at_end 设为 sizeof("]") - 1, 并将宏的最后一个参数设为 "T = ".

#define BOOST_TYPE_INDEX_CTTI_USER_DEFINED_PARSING (39, 1, true, "T = ")
