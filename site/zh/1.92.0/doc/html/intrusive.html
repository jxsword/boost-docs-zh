Boost.Intrusive 简介

Boost.Intrusive 是一个向 C++ 世界展示若干侵入式容器的库. 侵入式容器是特殊的容器, 与非侵入式容器 (如 STL 容器) 相比, 它们提供更好的性能与异常安全保证.

侵入式容器的性能优势使其成为高效构建多索引容器等复杂容器的理想构件, 也适合设计内存分配算法等高性能代码.

侵入式容器过去和现在都在 C 中被广泛使用, 但由于不支持侵入式技术的标准容器的存在, 它们在 C++ 中逐渐被遗忘. Boost.Intrusive 希望通过将实现封装在类 STL 接口中来推动侵入式容器的使用. 因此, 任何熟悉标准容器的人都可以轻松使用 Boost.Intrusive.

构建 Boost.Intrusive

使用 Boost.Intrusive 无需编译任何内容, 因为它是一个仅头文件库. 只需将 Boost 头文件目录加入编译器的包含路径即可.

已测试的编译器

Boost.Intrusive 已在以下编译器/平台上测试:

  • Visual C++ >= 7.1.
  • GCC >= 4.1.
警告

GCC < 4.3 和 MSVC < 9.0 已被弃用, 将在下一个版本中移除.
