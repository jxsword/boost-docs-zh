ratio 是一个在指定编译期有理数常量时很有用的设施. 它支持编译期有理数算术, 并提供防溢出与防除零保护. 这样的设施非常适合高效表示三分之一个纳秒, 或者用米来指定英寸 (例如 254/10000 米——ratio 会将其约简为 127/5000 米).

类模板 ratio<> 
template <std::intmax_t N, std::intmax_t D>
class ratio {
public:
    static constexpr std::intmax_t num;
    static constexpr std::intmax_t den;
    typedef ratio<num, den> type;
};

若 ratio 以 D == 0 实例化, 或 N 与 D 的绝对值无法表示, 则会发出诊断. 注释: 这些规则确保避免无穷比值, 且对任何负输入都存在一个可表示的正的绝对值. 在补码表示中, 这排除了最负的值.

成员 num 和 den 将是模板实参 N 和 D 的规范化值, 计算方式如下. 设 gcd 表示 N 的绝对值与 D 的绝对值的最大公约数. 那么:

  • num 的值为 sign(N)*sign(D)*abs(N)/gcd.
  • den 的值为 abs(D)/gcd.

嵌套 typedef type 表示此 ratio 类型的规范化形式. 由于模板实参不一定是规范化的, 在需要模板实参的规范化形式时应使用它.

两个 ratio 类 ratio<N1,D1> 与 ratio<N2,D2> 具有相同的规范化形式, 当 ratio<N1,D1>::type 与 ratio<N2,D2>::type 是同一类型时.

ratio 算术

对本节中的每个类模板, 其每个模板参数都指代一个 ratio. 若实现因溢出而无法形成指定的 ratio, 则会发出诊断.

ratio_add<> 
template <class R1, class R2> using ratio_add = /* see below */;

ratio_add<R1, R2> 是 ratio<R1::num * R2::den + R2::num * R1::den, R1::den * R2::den>::type 的同义词.

ratio_subtract<> 
template <class R1, class R2> using ratio_subtract = /* see below */;

ratio_subtract<R1, R2> 是 ratio<R1::num * R2::den - R2::num * R1::den, R1::den * R2::den>::type 的同义词.

ratio_multiply<> 
template <class R1, class R2> using ratio_multiply = /* see below */;

ratio_multiply<R1, R2> 是 ratio<R1::num * R2::num, R1::den * R2::den>::type 的同义词.

ratio_divide<> 
template <class R1, class R2> using ratio_divide = /* see below */;

ratio_divide<R1, R2> 是 ratio<R1::num * R2::den, R2::num * R1::den>::type 的同义词.

ratio_gcd<>

Boost.Chrono 使用了这一对 C++ 标准的扩展.

template <class R1, class R2> using ratio_gcd = /* see below */;

ratio_gcd<R1, R2> 是 ratio<GCD(R1::num, R2::num), LCM(R1::den, R2::den)>::type 的同义词.

ratio 比较
ratio_equal<> 
template <class R1, class R2>  struct ratio_equal
    : public std::integral_constant<bool, [/see below] > {};

若 R1::num == R2::num && R1::den == R2::den, 则 ratio_equal 继承自 true_type, 否则继承自 false_type.

ratio_not_equal<> 
template <class R1, class R2>  struct ratio_not_equal
    : public std::integral_constant<bool, !ratio_equal<R1, R2>::value> {};
ratio_less<> 
template <class R1, class R2>
struct ratio_less
    : public std::integral_constant<bool, [/see below] > {};

若 R1::num * R2::den < R2::num * R1::den, 则 ratio_less 继承自 true_type, 否则继承自 false_type.

ratio_less_equal<> 
template <class R1, class R2> struct ratio_less_equal
    : public std::integral_constant<bool, !ratio_less<R2, R1>::value> {};
ratio_greater<> 
template <class R1, class R2> struct ratio_greater
    : public std::integral_constant<bool, ratio_less<R2, R1>::value> {};
ratio_greater_equal<> 
template <class R1, class R2> struct ratio_greater_equal
    : public std::integral_constant<bool, !ratio_less<R1, R2>::value> {};

类模板 ratio_string<> 
template <class Ratio, class CharT>
struct ratio_string
{
    static std::basic_string<CharT> symbol();
    static std::basic_string<CharT> prefix();
    static std::basic_string<CharT> short_name(); // DEPRECATED V2
    static std::basic_string<CharT> long_name(); // DEPRECATED V2
};

类模板 ratio_string 提供适合字符类型 charT 的相关比值的文本表示.

主模板提供通用字符串. 特化提供相同的静态成员函数, 但这些函数返回国际计量大会 (General Conference on Weights and Measures) 规定的英文 SI 前缀和符号名称.

静态成员函数 prefix() 
template<class Ratio, class CharT>
basic_string<charT>
ratio_string<Ratio, CharT>::prefix();

返回: 形如 [Ratio::num/Ratio::den] 的 basic_string

示例: ratio_string<ratio<2, 60>, wchar_t>::prefix() 返回 L"[1/30]".

静态成员函数 symbol() 
template<class Ratio, class CharT>
basic_string<charT>
ratio_string<Ratio, CharT>::symbol();

返回: prefix().

针对 ratio_string<>
