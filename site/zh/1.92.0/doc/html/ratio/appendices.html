附录 B: 设计理由

为什么 ratio 需要来自具有相同规范化形式的 ratio 的拷贝构造与赋值

当前的 N3000 不允许对具有相同规范化形式的 ratio 类实例进行拷贝构造或赋值.

这个简单的示例

ratio<1,3> r1;
ratio<3,9> r2;
r1 = r2; // (1)

在 (1) 处编译失败. 另一个示例

ratio<1,3> r1;
ratio_subtract<ratio<2,3>,ratio<1,3> > r2=r1;  // (2)

表达式 ratio_subtract<ratio<2,3>,ratio<1,3> > 的类型可能是 ratio<3,9>, 这样编译可能在 (2) 处失败. 它也可能是 ratio<1,3>, 此时编译成功.

为什么 ratio 需要嵌套的 normalizer typedef type

LWG 1281 问题的当前决议承认需要嵌套类型 typedef, 因此 Boost.Ratio 跟随 std::ratio 可能的最终版本.

附录 C: 实现说明

Boost.Ratio 如何尽量避免编译期有理数算术溢出?

当结果本可表示, 但简单套用算术规则会导致溢出时, 例如 ratio_multiply<ratio<INTMAX_MAX,2>,ratio<2,INTMAX_MAX>> 可约简为 ratio<1,1>, 而 ratio<INTMAX_MAX*2,INTMAX_MAX*2> 的直接结果会导致溢出.

Boost.Ratio 实现了一些简化, 以减少溢出的可能性. 总体思路是:

  • num 和 den 的 ratio<> 字段是规范化的.
  • 对某些可能溢出的乘积使用 gcd, 并在做乘法之前先化简.
  • 使用一些等价关系, 避免可能上溢或下溢的加法或减法.

以下小节更详细地讨论每种情形.

ratio_add

在

(n1/d1)+(n2/d2)=(n1*d2+n2*d1)/(d1*d2)

中, n1*d2+n2*d1 或 d1*d2 都可能溢出.

( (n1 * d2)  + (n2 * d1) )
--------------------------
         (d1 * d2)

对 num 和 den 同时除以 gcd(d1,d2)

( (n1 * (d2/gcd(d1,d2)))  + (n2 * (d1/gcd(d1,d2))) )
----------------------------------------------------
               ((d1 * d2) / gcd(d1,d2))

在分子上乘以并除以 gcd(n1,n2)

( ((gcd(n1,n2)*(n1/gcd(n1,n2))) * (d2/gcd(d1,d2)))  +
  ((gcd(n1,n2)*(n2/gcd(n1,n2))) * (d1/gcd(d1,d2)))
)
--------------------------------------------------
         ( (d1 * d2) / gcd(d1,d2) )

对 gcd(n1,n2) 作因式分解

( gcd(n1,n2) *
  ( ((n1/gcd(n1,n2)) * (d2/gcd(d1,d2))) + ((n2/gcd(n1,n2)) * (d1/gcd(d1,d2))) )
)
-------------------------------------------------------------------------------
                            ( (d1 * d2) / gcd(d1,d2) )

重新组合

( gcd(n1,n2) *
  ( ((n1/gcd(n1,n2)) * (d2/gcd(d1,d2))) + ((n2/gcd(n1,n2)) * (d1/gcd(d1,d2))) )
)
-------------------------------------------------------------------------------
                          ( (d1 / gcd(d1,d2)) * d2 )

除以 (d1 / gcd(d1,d2))

( ( gcd(n1,n2) / (d1 / gcd(d1,d2)) ) *
  ( ((n1/gcd(n1,n2)) * (d2/gcd(d1,d2))) + ((n2/gcd(n1,n2)) * (d1/gcd(d1,d2))) )
)
-------------------------------------------------------------------------------
                                       d2

除以 d2

( gcd(n1,n2) / (d1 / gcd(d1,d2)) ) *
( ((n1/gcd(n1,n2)) * (d2/gcd(d1,d2))) + ((n2/gcd(n1,n2)) * (d1/gcd(d1,d2))) / d2 )

该表达式对应于两个比值的乘积, 其溢出风险较小, 因为初始的分子和分母在大多数情况下都已除以了一个 gcd.

对于 ratio_subtract, 推理相同.

ratio_multiply

在

(n1/d1)*(n2/d2)=((n1*n2)/(d1*d2))

n1*n2 或 d1*d2 都可能溢出.

对分子和分母除以 gcc(n1,d2)

(((n1/gcc(n1,d2))*n2)
---------------------
(d1*(d2/gcc(n1,d2))))

除以 gcc(n2,d1)

((n1/gcc(n1,d2))*(n2/gcc(n2,d1)))
---------------------------------
((d1/gcc(n2,d1))*(d2/gcc(n1,d2)))

至此, 所有初始分子和分母都已被约简, 从而避免了溢出.

对于 ratio_divide, 推理类似.

ratio_less

为了求值

(n1/d1)<(n2/d2)

而不转向浮点数, 使用了两种技术:

  • 首先比较分子的符号.

若 sign(n1) < sign(n2), 结果为真.

若 sign(n1) == sign(n2), 则在把分子变为正数之后, 结果取决于下式

  • 当符号相同时, 所用的技术是使用整数除法和取模.

记 Qi 为 ni 与 di 的整数除法, Mi 为 ni 与 di 的取模.

ni = Qi * di + Mi and Mi < di

形式

((n1*d2)<(d1*n2))

我们得到

(((Q1 * d1 + M1)*d2)<(d1*((Q2 * d2 + M2))))

展开

((Q1 * d1 * d2)+ (M1*d2))<((d1 * Q2 * d2) + (d1*M2))

除以 d1*d2

Q1 + (M1/d1) < Q2 + (M2/d2)

若 Q1=Q2, 结果取决于

(M1/d1) < (M2/d2)

若 M1==0==M2, 结果为假

若 M1=0 且 M2!=0, 结果为真

若 M1!=0 且 M2==0, 结果为假

若 M1!=0 且 M2!=0, 结果取决于

(d2/M2) < (d1/M1)

若 Q1!=Q2, 下式的结果

Q1 + (M1/d1) < Q2 + (M2/d2)

仅取决于 Q1 和 Q2, 因为 Qi 是整数且 (Mi/di) <1 (由于 Mi<di).

若 Q1>Q2, 则 Q1==Q2+k, k>=1

Q2+k + (M1/d1) < Q2 + (M2/d2)
k + (M1/d1) < (M2/d2)
k < (M2/d2) - (M1/d1)

但 0 到 1 之间的两个数之差不可能大于 1, 因此结果为假.

若 Q2>Q1, 则 Q2==Q1+k, k>=1

Q1 + (M1/d1) < Q1+k + (M2/d2)
(M1/d1) < k + (M2/d2)
(M1/d1) - (M2/d2) < k

该式恒为真, 因此结果为真.
