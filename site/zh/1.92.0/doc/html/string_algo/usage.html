第一个示例

使用这些算法非常直接. 我们来看第一个示例:

    #include <boost/algorithm/string.hpp>
    using namespace std;
    using namespace boost;
    
    // ...

    string str1(" hello world! ");
    to_upper(str1);  // str1 == " HELLO WORLD! "
    trim(str1);      // str1 == "HELLO WORLD!"

    string str2=
       to_lower_copy(
          ireplace_first_copy(
             str1,"hello","goodbye")); // str2 == "goodbye world!"

该示例把 str1 转换为大写, 并修剪字符串开头和末尾的空白. 然后创建 str2 作为 str1 的副本, 其中 "hello" 被替换为 "goodbye". 本示例演示了库中使用的几个重要概念:

  • 容器参数: 与 STL 算法不同, 参数并不只以迭代器形式指定. STL 约定提供了极大的灵活性, 但也有一些局限. 由于容器要拆成两个参数传入, 算法无法 堆叠 使用, 因此无法使用另一个算法的返回值. 写 to_lower(str1) 比写 to_lower(str1.begin(), str1.end()) 容易得多.

    Boost.Range 的魔力提供了处理不同字符串类型的统一方式. 若确需传递一对迭代器, 可以使用 boost::iterator_range 把迭代器打包成具有兼容接口的结构.

  • 副本 vs. 原地修改: 库中的许多算法执行对输入的变换. 变换可以就地完成 (修改输入序列), 也可以创建变换后输入的副本 (保持输入不变). 这两种方式没有优劣之分, 各有优缺点. 因此, 库同时提供两者.

  • 算法堆叠: 副本版本返回变换后的输入作为结果, 因此可以在一个表达式中简单地串联多个变换 (即可以写 trim_copy(to_upper_copy(s))). 原地修改版本返回 void, 以避免误用.

  • 命名: 命名遵循标准 C++ 库的约定. 若同一算法既有副本版本又有原地修改版本, 则修改版本无后缀, 副本版本带后缀 _copy. 某些算法带有前缀 i (例如 ifind_first()). 该前缀表示算法以不区分大小写的方式工作.

要使用本库, 请包含 boost/algorithm/string.hpp 头文件. 若需要 regex 相关函数, 请包含 boost/algorithm/string_regex.hpp 头文件.

大小写转换

STL 有一种不错的大小写转换方式. 遗憾的是, 它只能转换单个字符, 而我们想转换整个字符串,

    string str1("HeLlO WoRld!");
    to_upper(str1); // str1=="HELLO WORLD!"

to_upper() 与 to_lower() 使用指定的 locale 转换字符串中字符的大小写.

更多信息请参见 boost/algorithm/string/case_conv.hpp 的参考文档.

谓词与分类

库的一部分处理与字符串相关的谓词. 考虑这个示例:

    bool is_executable( string& filename )
    {
        return 
            iends_with(filename, ".exe") ||
            iends_with(filename, ".com");
    }

    // ...
    string str1("command.com");
    cout 
        << str1
        << (is_executable(str1)? "is": "is not") 
        << "an executable" 
        << endl; // prints "command.com is an executable"
    
    //..
    char text1[]="hello";
    cout 
        << text1 
        << (all( text1, is_lower() )? " is": " is not")
        << " written in the lower case" 
        << endl; // prints "hello is written in the lower case"

这些谓词在各种条件下判定子串是否包含于输入字符串. 条件包括: 字符串以子串开头、以子串结尾、直接包含子串, 或两个字符串相等. 更多细节请参见 boost/algorithm/string/predicate.hpp 的参考文档.

注意, 如果我们用 "hello world" 作为测试的输入, 它会输出 "hello world is not written in the lower case", 因为输入字符串中的空格不是小写字母.

此外, 算法 all() 检查容器的所有元素是否满足谓词指定的条件. 该谓词可以是任何一元谓词, 但库提供了一组实用的字符串相关谓词和组合器, 开箱即用. 它们位于 boost/algorithm/string/classification.hpp 头文件中. 分类谓词可以用逻辑组合器组合成更复杂的表达式. 例如: is_from_range('a','z') || is_digit()

修剪

解析用户输入时, 字符串常常带有不需要的开头或结尾字符. 要去掉它们, 需要修剪函数:

    string str1="     hello world!     ";
    string str2=trim_left_copy(str1);   // str2 == "hello world!     "
    string str3=trim_right_copy(str1);  // str3 == "     hello world!"
    trim(str1);                         // str1 == "hello world!"

    string phone="00423333444";
    // remove leading 0 from the phone number
    trim_left_if(phone,is_any_of("0")); // phone == "423333444"

可以修剪字符串右侧、左侧或两侧的空白. 而对于需要移除空白以外内容的情况, 还有 _if 变体. 使用这些变体, 用户可以指定一个函数对象来选择要移除的 空白. 可以使用上一段提到的 is_digit() 等分类谓词. 详情参见 boost/algorithm/string/trim.hpp 的参考文档.

查找算法

库中包含一组查找算法. 下面是一个示例:

    char text[]="hello dolly!";
    iterator_range<char*> result=find_last(text,"ll");

    transform( result.begin(), result.end(), result.begin(), bind2nd(plus<char>(), 1) );
    // text = "hello dommy!"            

    to_upper(result); // text == "hello doMMy!"

    // iterator_range is convertible to bool
    if(find_first(text, "dolly"))
    {
        cout << "Dolly is there" << endl;
    }

我们使用 find_last() 在 text 中搜索 "ll". 结果以 boost::iterator_range 给出. 该范围界定输入中满足查找条件的部分, 在本例中即 "ll" 的最后一次出现. 可以看到, find_last() 算法的输入也可以是 char[], 因为 Boost.Range 支持该类型. 接下来的几行对结果进行变换. 注意 boost::iterator_range 具有常见的 begin() 与 end() 方法, 因此可以像任何其他 STL 容器一样使用. 它还可以转换为 bool, 因此用查找算法做简单的包含性检查非常方便.

查找算法位于 boost/algorithm/string/find.hpp.

替换算法

查找算法可用于搜索字符串的特定部分. 替换则更进一步: 找到匹配部分后, 用其他内容替换它. 替换内容由原内容经某种变换计算得到.

    string str1="Hello  Dolly,   Hello World!"
    replace_first(str1, "Dolly", "Jane");      // str1 == "Hello  Jane,   Hello World!"
    replace_last(str1, "Hello", "Goodbye");    // str1 == "Hello  Jane,   Goodbye World!"
    erase_all(str1, " ");                      // str1 == "HelloJane,GoodbyeWorld!"
    erase_head(str1, 6);                       // str1 == "Jane,GoodbyeWorld!"

替换与擦除函数的完整列表请参见 参考. 库为常见用法提供了大量预定义函数, 同时也允许你定义满足特定需求的自定义 replace(). 有一个泛型函数 find_format() 接受两个参数: 第一个是 Finder 对象, 第二个是 Formatter 对象. Finder 对象是一个函数对象, 负责搜索要替换的部分. Formatter 对象取 Finder 的结果 (通常是对找到子串的引用) 并为其生成替代内容. 替换算法把两者结合起来, 完成所需的替换.

请参考 boost/algorithm/string/replace.hpp, boost/algorithm/string/erase.hpp 与 boost/algorithm/string/find_format.hpp 的参考文档.

查找迭代器

查找迭代器是查找算法的扩展. 它不再只搜索字符串的一个部分, 而是允许我们遍历所有匹配指定准则的子串. 该设施使用 Finder 对字符串进行增量搜索. 解引用查找迭代器会得到一个 boost::iterator_range 对象, 界定当前的匹配.

提供两个迭代器 find_iterator 与 split_iterator. 前者遍历用指定 Finder 找到的子串, 后者遍历这些子串之间的间隙.

    string str1("abc-*-ABC-*-aBc");
    // Find all 'abc' substrings (ignoring the case)
    // Create a find_iterator
    typedef find_iterator<string::iterator> string_find_iterator;
    for(string_find_iterator It=
            make_find_iterator(str1, first_finder("abc", is_iequal()));
        It!=string_find_iterator();
        ++It)
    {
        cout << copy_range<std::string>(*It) << endl;
    }

    // Output will be:
    // abc
    // ABC
    // aBC
    
    typedef split_iterator<string::iterator> string_split_iterator;
    for(string_split_iterator It=
        make_split_iterator(str1, first_finder("-*-", is_iequal()));
        It!=string_split_iterator();
        ++It)
    {
        cout << copy_range<std::string>(*It) << endl;
    }

    // Output will be:
    // abc
    // ABC
    // aBC

注意, 查找迭代器只有一个模板参数, 即基础迭代器类型. Finder 在运行期指定. 这使得我们可以为常见的字符串类型 typedef 一个查找迭代器并复用它. 此外, make_*_iterator 函数可以帮助为特定范围构造查找迭代器.

参考文档见 boost/algorithm/string/find_iterator.hpp.

拆分

拆分算法是查找迭代器针对一个常见使用场景的扩展. 这些算法使用查找迭代器, 并把所有匹配存入提供的容器. 该容器必须能够保存提取子串的副本 (如 std::string) 或引用 (如 iterator_range).

提供两个算法. find_all() 找出字符串在输入中的所有副本, split() 把输入拆分为若干部分.

    string str1("hello abc-*-ABC-*-aBc goodbye");

    typedef vector< iterator_range<string::iterator> > find_vector_type;
    
    find_vector_type FindVec; // #1: Search for separators
    ifind_all( FindVec, str1, "abc" ); // FindVec == { [abc],[ABC],[aBc] }

    typedef vector< string > split_vector_type;
    
    split_vector_type SplitVec; // #2: Search for tokens
    split( SplitVec, str1, is_any_of("-*"), token_compress_on ); // SplitVec == { "hello abc","ABC","aBc goodbye" }

[hello] 表示界定该子串的 iterator_range.

第一个示例展示如何构造一个容器来保存对所有提取子串的引用. 算法 ifind_all() 把所有与 "abc" 不区分大小写相等的子串的引用放入 FindVec.

第二个示例使用 split() 把字符串 str1 按字符 '-' 或 '*' 分隔的部分拆开, 并放入 SplitVec. 可以指定相邻分隔符是否合并.

更多信息请参见参考文档: boost/algorithm/string/split.hpp.
