构建

整个库以头文件形式提供. 但某些算法的 regex 变体依赖于 Boost.Regex 库. 所有此类算法都分离在 boost/algorithm/string_regex.hpp 中. 若使用该头文件, 应用程序必须与 Boost.Regex 库链接.

示例

展示库基本用法的示例位于 libs/algorithm/string/example 目录. 库的每个部分都有单独的文件. 请遵循 boost 构建指南, 使用 bjam 构建示例. 要成功构建 regex 示例, 需要 Boost.Regex 库.

测试

本库的全套测试用例位于 libs/algorithm/string/test 目录. 测试用例可使用 boost 构建系统执行. 算法的正则表达式变体的测试需要 Boost.Regex 库.

Portability

本库已成功通过以下编译器的编译和测试:

  • Microsoft Visual C++ 7.0
  • Microsoft Visual C++ 7.1
  • GCC 3.2
  • GCC 3.3.1

特定编译器的更多信息请参见 Boost 回归测试表.

在不支持偏特化的平台上存在已知限制. 库依赖于实现正确的 std::iterator_traits 类. 如果编译器附带的标准库有问题, String Algorithm Library 就无法正常工作. 通常这意味着原生指针迭代器无法与库函数配合使用.
