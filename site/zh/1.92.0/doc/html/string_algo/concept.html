Finder 概念

Finder 是一个在容器中搜索任意部分的函数对象. 搜索结果以 iterator_range 的形式给出, 用于界定被选中的部分.

表 2.14. 有效表达式

表达式 返回类型 效果
f(i,j) 可转换为 iterator_range<Iter> 在区间 [i,j) 上执行搜索并返回搜索结果

各种算法都需要在容器中执行搜索, Finder 是此类搜索操作的泛化, 使算法可以抽象掉搜索细节. 例如, 泛型替换算法可以替换输入的任意部分, 而 Finder 就用于选出目标部分.

注意, 只要求查找器能对特定的迭代器类型工作. 不过, Finder 操作可以定义为模板, 使 Finder 能用于任何迭代器.

示例

  • 以类实现的 Finder. 该 Finder 总是返回整个输入作为匹配. operator() 是模板, 因此该查找器可用于任何迭代器类型. 
    struct simple_finder
{
    template<typename ForwardIteratorT>
    boost::iterator_range<ForwardIteratorT> operator()(
        ForwardIteratorT Begin,
        ForwardIteratorT End )
    {
        return boost::make_range( Begin, End );
    }
};
  • 函数形式的 Finder. Finder 可以是任何函数对象. 也就是说, 任何具有所需签名的普通函数同样可以用作 Finder. 但是, 这样的函数只能用于特定的迭代器类型. 
    boost::iterator_range<std::string> simple_finder(
    std::string::const_iterator Begin,
    std::string::const_iterator End )
{
    return boost::make_range( Begin, End );
}

Formatter 概念

Formatter 由 replace 算法 使用, 并与查找器紧密配合. Formatter 是一个函数对象, 它取 Finder 操作的结果并按特定方式进行变换. Formatter 的操作可以利用特定查找器提供的附加信息, 例如 regex_formatter() 使用 regex_finder() 的匹配信息来格式化 formatter 操作的结果.

表 2.15. 有效表达式

表达式 返回类型 效果
fmt(f(i,j)) 一种容器类型, 可通过容器特征访问 对查找器操作的结果进行格式化

与查找器类似, Formatter 是格式化操作的泛化. 当查找器选出输入的一部分时, Formatter 接收该选择并对其执行某种格式化. 算法可以借助 Formatter 抽象掉格式化细节.

示例

  • 以类实现的 Formatter. 该 Formatter 不执行任何格式化, 只是重新打包并返回匹配结果. operator() 是模板, 因此该 Formatter 可用于任何 Finder 类型. 
    struct simple_formatter
{
    template<typename FindResultT>
    std::string operator()( const FindResultT& Match )
    {
        std::string Temp( Match.begin(), Match.end() );
        return Temp;
    }
};
  • 函数形式的 Formatter. 与 Finder 类似, Formatter 可以是任何函数对象. 但作为函数, 它只能与特定的 Finder 类型配合使用. 
    std::string simple_formatter( boost::iterator_range<std::string::const_iterator>& Match )
{
    std::string Temp( Match.begin(), Match.end() );
    return Temp;
}
