locale (本地化环境)

locale 与字符串处理关系非常密切. 它们包含字符集相关的信息, 例如用于转换字符的大小写以及对字符进行分类.

C++ 允许同时使用多个不同的 locale 实例. 如果算法以某种需要使用 locale 的方式操作数据, 就必须有指定 locale 的途径. 但是, 对大多数应用来说一个 locale 实例就足够了, 而让用户在每一处需要的地方都指明使用哪个 locale 会非常繁琐.

所幸 C++ 标准允许指定 全局 locale (通过静态成员函数 std:locale::global()). 在不提供显式信息的情况下实例化 std::locale 类时, 该实例将以 全局 locale 初始化. 这意味着, 若算法需要 locale, 它应当有一个 std::locale 参数, 其默认值为 std::locale(). 需要显式指定 locale 的用户可以这么做, 否则将使用 全局 locale.

正则表达式

正则表达式是文本处理的重要组成部分. 因此, 本库也为某些算法提供了 regex 变体. 本库并不试图取代 Boost.Regex, 只是把其功能包装在新接口中. 作为本库的一部分, regex 算法可以与其他组件无缝集成, 带来额外价值.
